<span style="margin-left: 2em"><sub class="note-jiao">校：此卷刊本所未有據日抄島根本校錄</sub></span>  
<span style="margin-left: 1em">測夜時法叙目</span>  
<span style="margin-left: 2em">夫日晷以定晝之時刻取太陽影之所到固明且確</span>  
<span style="margin-left: 2em">矣夜之時刻何以測之曰取亦有晷焉如星晷壺漏</span>  
<span style="margin-left: 2em">之類是也但星晷作之甚難且百年宜更未可久用</span>  
<span style="margin-left: 2em">壺漏易用難調亦難確據惟測星求時爲公法最爲</span>  
<span style="margin-left: 2em">定準只算宜精密不可輕率其法亦以太陽爲主蓋</span>  
<span style="margin-left: 2em">定太陽過距子午圈度分若干時刻者<sub class="note-jiao">校：若干原作若于當誤而</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">改</sub>乃天行之度量也太陽東西行滿一周成一日黃</span>  
<span style="margin-left: 2em">道上西東行滿一周成一年故太陽之行爲年日時</span>  
<span style="margin-left: 2em">刻之本如月二十七日滿天一周謂之太陰年五緯</span>  
<span style="margin-left: 2em">亦有本年然皆不明不順未可取用惟準諸太陽者</span>  
<span style="margin-left: 2em">爲確若測時或用恆星五緯太陰<sub class="note-jiao">校：太陰原作大陰今改</sub>皆可</span>  
<span style="margin-left: 2em">但先求月星本時<sub class="note-yuan">距子午圈若干度</sub>次變爲太陽之時乃值</span>  
<span style="margin-left: 2em">所用之時也古人測時之法多端各有本論今但譯</span>  
<span style="margin-left: 2em">夜中測時三種以驗交食時刻一測星一星晷一壺</span>
