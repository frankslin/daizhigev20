<span style="margin-left: 2em"><sub class="note-jiao">校：此卷刊本所未有據日抄島根本校錄</sub></span>  
<span style="margin-left: 1em">测夜时法叙目</span>  
<span style="margin-left: 2em">夫日晷以定昼之时刻取太阳影之所到固明且确</span>  
<span style="margin-left: 2em">矣夜之时刻何以测之曰取亦有晷焉如星晷壶漏</span>  
<span style="margin-left: 2em">之类是也但星晷作之甚难且百年宜更未可久用</span>  
<span style="margin-left: 2em">壶漏易用难调亦难确据惟测星求时为公法最为</span>  
<span style="margin-left: 2em">定准只算宜精密不可轻率其法亦以太阳为主盖</span>  
<span style="margin-left: 2em">定太阳过距子午圈度分若干时刻者<sub class="note-jiao">校：若干原作若于當誤而</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">改</sub>乃天行之度量也太阳东西行满一周成一日黄</span>  
<span style="margin-left: 2em">道上西东行满一周成一年故太阳之行为年日时</span>  
<span style="margin-left: 2em">刻之本如月二十七日满天一周谓之太阴年五纬</span>  
<span style="margin-left: 2em">亦有本年然皆不明不顺未可取用惟准诸太阳者</span>  
<span style="margin-left: 2em">为确若测时或用恒星五纬太阴<sub class="note-jiao">校：太陰原作大陰今改</sub>皆可</span>  
<span style="margin-left: 2em">但先求月星本时<sub class="note-yuan">距子午圈若干度</sub>次变为太阳之时乃值</span>  
<span style="margin-left: 2em">所用之时也古人测时之法多端各有本论今但译</span>  
<span style="margin-left: 2em">夜中测时三种以验交食时刻一测星一星晷一壶</span>  
<span style="margin-left: 2em">漏各列其法于左</span>
