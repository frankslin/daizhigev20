<span style="margin-left: 2em">解正球上大圈相交之度分<sub class="note-jiao">校：清刊本此前有測量全義八卷標題</sub></span>  
<span style="margin-left: 1em">正球之大圈有三種一爲赤道二爲斜截赤道之圈<sub class="note-yuan">如黃</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">道等</sub>三爲直截赤道之圈<sub class="note-yuan">直截赤道者截赤道爲直角其極如正球之地平圈各處</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">午圈時圈等</sub>三者相交相距是生多種三角形</span>  
<span style="margin-left: 6em">如己甲庚爲赤道丁丙寅爲黃道相交於</span>  
<span style="margin-left: 6em">丙爲斜角戊爲己庚赤道圈之一極<sub class="note-yuan">極者球面</sub></span>  
<span style="margin-left: 6em"><sub class="note-yuan">上大圈之心凡分球宜用球體之心體之心不可得而以大圈之心當之故不名心</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">名極亦即軸之兩端也</sub>從戊極作戊甲乙辛圈辛爲赤道之又</span>  
<span style="margin-left: 2em">一極戊甲辛弧截赤道於甲爲直角亦截黃道於乙</span>  
<span style="margin-left: 2em">成甲乙丙直角曲線形也此形之乙至丙爲黃道之</span>  
<span style="margin-left: 2em">經度丙至甲爲赤道之經度乙甲爲乙點距赤道之</span>  
<span style="margin-left: 2em">度<sub class="note-yuan">即赤道之緯度</sub>丙爲赤黃二道之交角乙爲過兩極圈與</span>  
<span style="margin-left: 2em">黃道之交角甲爲過極圈與赤道之交角<sub class="note-yuan">即直角</sub>一形</span>  
<span style="margin-left: 2em">有三角三邊凡六種先有三可求其餘</span>  
<span style="margin-left: 1em">一題凡有兩道極相距之度分<sub class="note-yuan">交角之度分同</sub>及一道之經度</span>  
<span style="margin-left: 2em">分求其餘</span>  
<span style="margin-left: 6em">如丙角爲二十三度三十一分三十〇秒</span>  
<span style="margin-left: 6em">丙乙爲黃道經三十度<sub class="note-yuan">如大梁等一宫</sub>求其緯度</span>  
<span style="margin-left: 2em">乙甲<sub class="note-yuan">過極圈之一弧</sub>此爲直角形有丙角及直角之對邊丙</span>  
<span style="margin-left: 2em">乙求其餘三</span>  
<span style="margin-left: 2em">一求黃道若干度之赤道緯度<sub class="note-yuan">即乙甲邊</sub>法<sub class="note-yuan">見本篇七卷直角形捷法</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">第七設</sub>爲全數與丙角之正弦<sub class="note-yuan">三九九一六</sub>若乙丙弧之正</span>  
<span style="margin-left: 2em">弦<sub class="note-yuan">五〇〇〇〇</sub>與乙甲弧之正弦<sub class="note-yuan">一九九五七</sub>查得一十一度</span>  
<span style="margin-left: 2em">三十〇分四十秒即黃道經三十度之赤道緯度</span>  
<span style="margin-left: 2em">二求正球同升之度甲丙<sub class="note-yuan">若甲乙邊爲正球之地平弧即丙甲丙乙兩弧必同</sub></span>  
<span style="margin-left: 5em"><sub class="note-yuan">出入名正球同升之弧也又若甲乙爲子午圈即丙甲丙乙爲同過子午圈之兩點名雖</sub></span>  
<span style="margin-left: 5em"><sub class="note-yuan">不同其理無二詳見左方</sub>法爲全數與丙角之餘弦<sub class="note-yuan">九一六九</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">〇〇</sub>若乙丙之正切線<sub class="note-yuan">五七七三五</sub>與甲丙邊之正切線<sub class="note-yuan">五二</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">九三〇</sub>查得二十七度五十三分四十三秒</span>  
<span style="margin-left: 2em">三求乙角<sub class="note-yuan">即黃道與子午等過極圈之交角</sub>法爲全數與乙丙之割</span>  
<span style="margin-left: 5em">線若丙角之餘切線與乙角之切線<sub class="note-yuan">若知黃白二道</sub></span>  
<span style="margin-left: 5em"><sub class="note-yuan">交角之度及太陰之本行經度可知其去離南北之度而定食限之度見月離曆及本表</sub></span>  
<span style="margin-left: 2em">用上三法可作兩道各度分相距之緯度表又可作</span>  
<span style="margin-left: 2em">每度之同直升表又可作每度與過極圈之交角表</span>  
<span style="margin-left: 2em">三者其用甚大爲推步日食根本又因第一求可定</span>  
<span style="margin-left: 2em">月及五星距黃道之度</span>  
<span style="margin-left: 2em">附同升解</span>  
<span style="margin-left: 2em">黃赤二道交於春秋二分必相截爲兩平分若別大</span>  
<span style="margin-left: 2em">圈截兩道其交角從本圈之體勢直斜不一</span>  
<span style="margin-left: 2em">其一大圈過兩道之兩極必與兩道相交爲直角則</span>  
<span style="margin-left: 2em">從兩道之交至大圈之交其兩道之弧必等此大圈</span>  
<span style="margin-left: 2em">爲極至交圈也因過赤黃兩道之極與兩道爲直角</span>  
<span style="margin-left: 2em">則從春分迄夏至兩道之弧必等爲九十度也</span>  
<span style="margin-left: 2em">其二大圈獨過一道之兩極<sub class="note-yuan">如過北極則赤道極也</sub>此大圈與</span>  
<span style="margin-left: 2em">所過極之本圈必相交爲直角若與所不過之道則</span>  
<span style="margin-left: 2em">否從春分至過極圈之交所截黃赤兩道之弧必不</span>  
<span style="margin-left: 2em">等<sub class="note-yuan">蓋兩道與過極圈交而作角必有鈍有銳爲異類故也</sub>而此兩道之兩弧<sub class="note-yuan">從春</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">分起數</sub>名正球同升或同降之度<sub class="note-yuan">正球內升降之度必等蓋地平爲過極之</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">一圈也欹球則否</sub>亦名同過子午圈之度<sub class="note-yuan">蓋子午圈亦過赤道之極</sub></span>  
<span style="margin-left: 2em">如過極圈截黃道大梁初度<sub class="note-yuan">去離春分三十經度</sub>截赤道二十</span>  
<span style="margin-left: 2em">八度弱或正球黃道大梁初度與赤道二十八度弱</span>  
<span style="margin-left: 2em">同升同降或同過子午圈反之亦謂正球赤道二十</span>  
<span style="margin-left: 2em">八度弱與黃道三十度同升同降同過子午圈其理</span>  
<span style="margin-left: 2em">皆同若春分迄夏至於黃道第一象限順數之秋分</span>  
<span style="margin-left: 2em">遡夏至則否用所得赤道升度以減象限所存數又</span>  
<span style="margin-left: 2em">加一象限九十度得黃道某點之正升度</span>  
<span style="margin-left: 2em">如鶉尾初度距秋分三十度從秋分算得赤道同升</span>  
<span style="margin-left: 2em">之度二十八以減夏秋九十度得六十二以加春夏</span>  
<span style="margin-left: 2em">一象限得一百五十二爲鶉尾初從春分起與赤道</span>  
<span style="margin-left: 2em">同升之度</span>  
<span style="margin-left: 2em">若秋分迄冬至用所得赤道升度與春秋二象限一</span>  
<span style="margin-left: 2em">百八十度并得黃道從春分至某點之正升度</span>  
<span style="margin-left: 2em">如大火初距秋分三十度從秋分算得升度二十八</span>  
<span style="margin-left: 2em">以加春秋一百八十度得二百〇八度爲大火初從</span>  
<span style="margin-left: 2em">春分起與赤道同升之度</span>  
<span style="margin-left: 2em">若從春分遡冬至則用所得赤道升度以減象限得</span>  
<span style="margin-left: 2em">數與春分迄春分三象限二百七十度并得黃道從</span>  
<span style="margin-left: 2em">春分至某點之正升度</span>  
<span style="margin-left: 2em">如娵訾初距春分三十度從春分算得升度二十八</span>  
<span style="margin-left: 2em">以減春夏九十度得六十二以加春分迄春分二百</span>  
<span style="margin-left: 2em">七十二度<sub class="note-jiao">校：春分迄春分疑冬至迄春分之誤</sub>得三百三十二度爲娵</span>  
<span style="margin-left: 2em">訾初從春分起與赤道同升之度</span>  
<span style="margin-left: 2em">其三大圈不過兩道之極如欹球地平大圈截黃赤</span>  
<span style="margin-left: 2em">二道皆爲斜角因赤道高下作角必不等其三角形</span>  
<span style="margin-left: 2em">之腰亦不等則從春分計某地兩道同升之兩弧數</span>  
<span style="margin-left: 2em">名欹球同升之度</span>  
<span style="margin-left: 2em">如順天府赤道約高五十度設大梁初度從地平上</span>  
<span style="margin-left: 2em">升因本法推赤道上之同升度一十八<sub class="note-yuan">從春分起數</sub>則大</span>  
<span style="margin-left: 2em">梁初度及赤道一十八度爲某欹球同升之兩點</span>  
<span style="margin-left: 2em">若欲定其斜入則倒球取之用彼球之卯當此球之</span>  
<span style="margin-left: 2em">酉用彼球之升爲此球之降則某點爲彼球之斜同</span>  
<span style="margin-left: 2em">升即此球之斜同入</span>  
<span style="margin-left: 2em">如順天府北極出地約四十度有夏至同升之度欲</span>  
<span style="margin-left: 2em">求其同降則用南極出地五十度之彼球以彼球之</span>  
<span style="margin-left: 2em">冬至爲此球之夏至則彼球冬至之同升度即此方</span>  
<span style="margin-left: 2em">夏至之同降度</span>  
<span style="margin-left: 2em">已上言正球有正升度欹球有斜升度此兩數相減</span>  
<span style="margin-left: 2em">之較名兩升之差</span>  
<span style="margin-left: 2em">如大梁初度之正同升二十八度順天府大梁初度</span>  
<span style="margin-left: 2em">之斜同升一十八度其較十度即順天府大梁初度</span>  
<span style="margin-left: 2em">之升差</span>  
<span style="margin-left: 2em">已上所說用渾球解之則易明</span>  
<span style="margin-left: 1em">二題有黃道經緯度求兩道交角之度</span>  
<span style="margin-left: 5em">如上有直角之對邊乙丙及其旁邊甲乙而</span>  
<span style="margin-left: 5em">求丙角求乙角求赤道之弧甲丙俱用本書</span>  
<span style="margin-left: 2em">七卷十設因設數難定不須詳別</span>  
<span style="margin-left: 1em">三題設兩道交角之度及黃道某點之緯度而求其點</span>  
<span style="margin-left: 2em">之黃道經度</span>  
<span style="margin-left: 5em">如丙爲交角丁甲其對邊之緯弧求丙甲赤</span>  
<span style="margin-left: 5em">道之弧<sub class="note-yuan">見七卷三設</sub>爲全與丙角之餘切線若甲</span>  
<span style="margin-left: 2em">丁弧之切線與甲丙邊之正弦<sub class="note-yuan">此即赤道經度凡經緯二數恆相連</sub>求</span>

<span style="margin-left: 6em">線若丙角之正弦與丁角之正弦<sub class="note-yuan">三角形各形有</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">十設各設三求今約取其必用者解之</sub></span>

<span style="margin-left: 5em"><sub class="note-yuan">與過極圈之交角</sub>求丁丙<sub class="note-yuan">黃道同升之弧</sub>求甲丁<sub class="note-yuan">黃道上某點之緯度</sub></span>  
<span style="margin-left: 5em"><sub class="note-yuan">法見七卷第二設</sub></span>  
<span style="margin-left: 2em">解欹球上大圈相交之度分</span>  
<span style="margin-left: 1em">正球上大圈有三種欹球則有四種地平圈一也天頂</span>  
<span style="margin-left: 2em">圈二也地平左右之次舍侣圈三也日出入之時圈</span>  
<span style="margin-left: 2em">四也與正球之三而七矣七圈者相交相距其理甚</span>  
<span style="margin-left: 2em">繁其用甚大</span>  
<span style="margin-left: 1em">一題有赤道與地平交角之度<sub class="note-yuan">子午圈過天頂亦過赤道極則交角之度與極</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">出地平上之餘度必等</sub>又有黃道某點之緯若某點或升或降</span>  
<span style="margin-left: 2em">在地平求黃道與地平交角之度</span>  
<span style="margin-left: 6em">如圖癸丙甲爲地平壬寅戊爲赤道丁丙</span>  
<span style="margin-left: 6em">庚爲黃道己爲二道之交丙爲黃道地平</span>  
<span style="margin-left: 6em">之交從赤道極乙點過丙至赤道上寅點</span>

<span style="margin-left: 2em">度丙乙其餘也即甲丙乙直角形之丙角爲過極圈</span>  
<span style="margin-left: 2em">與地平之交角又丁丙乙爲黃道與過極圈之交角</span>  
<span style="margin-left: 2em">兩角并得丁丙甲角　用前正球一題第三求得乙</span>  
<span style="margin-left: 2em">丙丁角<sub class="note-yuan">彼云乙角</sub>次甲丙乙形甲乙爲極出地之高若干</span>
