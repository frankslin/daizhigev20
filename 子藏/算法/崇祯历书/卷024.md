## 崇禎曆書卷之二十四　康熙奏疏

*康熙八年九月至康熙十二年十二月十九日*

<span style="margin-left: 2em">奏疏十</span>  
<span style="margin-left: 12em">康熙八年九月禮部題本</span>  
<span style="margin-left: 3em">禮部</span>  
<span style="margin-left: 2em">題爲請</span>  
<span style="margin-left: 1em">旨事該臣等議得湯若望通微教師之名既復行給還</span>  
<span style="margin-left: 3em">照伊原品級</span>  
<span style="margin-left: 1em">賜卹應照原任通政使司通政使加二級又加一級掌</span>  
<span style="margin-left: 3em">欽天監印務事湯若望給與合葬之價並給與一</span>

<span style="margin-left: 1em">遣官讀文致祭祭文內院撰擬奉</span>  
<span style="margin-left: 1em">旨依議</span>  
<span style="margin-left: 3em">康熙八年九月　　日</span>  
<span style="margin-left: 13em">康熙八年十月御祭文</span>  
<span style="margin-left: 3em">康熙八年十月　　　日臣利類思臣安文思臣</span>  
<span style="margin-left: 3em">南懷仁於</span>  
<span style="margin-left: 1em">勅賜通微教師通政使司通政使加二級又加一級管</span>  
<span style="margin-left: 3em">欽天監印務事臣湯若望墓前設香案跪接</span>  
<span style="margin-left: 1em">御祭文一道</span>  
<span style="margin-left: 1em">遣禮部官一員致祭</span>  
<span style="margin-left: 1em">皇帝諭祭原任通政使司通政使加二級又加一級管</span>  
<span style="margin-left: 3em">欽天監印務事湯若望之靈曰鞠躬盡瘁臣子之</span>  
<span style="margin-left: 3em">芳蹤卹死報勤</span>  
<span style="margin-left: 2em">國家之盛典爾湯若望來自西域曉習天文特畀象</span>  
<span style="margin-left: 3em">曆之司爰錫通微教師之號遽爾長逝朕用悼焉</span>  
<span style="margin-left: 3em">特加</span>  
<span style="margin-left: 1em">恩卹</span>  
<span style="margin-left: 1em">遣官致祭嗚呼聿垂不朽之榮庶享匪躬之報爾如有</span>  
<span style="margin-left: 2em">知尚克歆享</span>  
<span style="margin-left: 12em">康熙八年賜湯若望勅諭</span>  
<span style="margin-left: 2em">朕惟國家肇造鴻業以授時定曆爲急務羲和而後</span>  
<span style="margin-left: 2em">如漢洛下閎張衡唐李淳風僧一行諸人於曆法代</span>  
<span style="margin-left: 2em">有損益獨於日月朔望交會分秒之數錯誤尚多以</span>  
<span style="margin-left: 2em">致氣候刻應不驗至於有元郭守敬號爲精密然經</span>  
<span style="margin-left: 2em">緯之度尚未能符合天行其後晷度亦遂積差矣爾</span>  
<span style="margin-left: 2em">湯若望來自西洋涉海十萬里明末居京師精於象</span>  
<span style="margin-left: 2em">緯閎通曆法其時大學士徐光啓特薦於朝令修曆</span>  
<span style="margin-left: 2em">局中一時專家治曆如魏文奎等推測之法實不及</span>  
<span style="margin-left: 2em">爾但以遠人之故多忌成功歷十餘年終不見用朕</span>  
<span style="margin-left: 2em">承</span>  
<span style="margin-left: 1em">天眷定鼎之初爰諮爾姓名爲朕修大清時憲曆迄於</span>  
<span style="margin-left: 2em">有成可謂勤矣爾又能潔身持行盡心迺事董率群</span>  
<span style="margin-left: 2em">官可謂忠矣比之古洛下閎諸人不既優乎今特錫</span>  
<span style="margin-left: 2em">爾嘉名爲通微教師餘守秩如故俾知天生賢人佐</span>  
<span style="margin-left: 2em">佑定曆補數千年之闕略成一代之鴻書非偶然也</span>  
<span style="margin-left: 2em">爾其益懋厥修以服厥官傳之史冊豈不美哉故諭</span>  
<span style="margin-left: 9em">康熙九年六月初九日禮部題本</span>  
<span style="margin-left: 3em">禮部</span>  
<span style="margin-left: 2em">題爲請</span>  
<span style="margin-left: 1em">旨事查得欽天監監正楊光先已經革職所遺監正員</span>  
<span style="margin-left: 3em">缺應補將左監副胡振鉞擬正右監副李光顯擬</span>  
<span style="margin-left: 3em">陪俟</span>  
<span style="margin-left: 1em">命下臣部之日移送吏部題授可也臣等未敢擅便謹</span>  
<span style="margin-left: 3em">題請</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 3em">康熙八年三月初七日題康熙九年六月初九日</span>  
<span style="margin-left: 3em">奉</span>  
<span style="margin-left: 1em">旨曆法天文既係南懷仁料理其欽天監監正員缺不</span>  
<span style="margin-left: 2em">必補授</span>  
<span style="margin-left: 7em">康熙九年七月二十三日南懷仁奏本</span>  
<span style="margin-left: 3em">欽天監治理曆法臣南懷仁謹</span>  
<span style="margin-left: 2em">奏爲曆法賾奧需材俸薄難以鼓勵仰祈</span>  
<span style="margin-left: 1em">聖恩破格作養以光</span>  
<span style="margin-left: 1em">大典以勉後效事竊照治曆明時爲堯舜首命之官即</span>  
<span style="margin-left: 3em">歷代以來皆屬清班迨至明末始輕視其事賤視</span>  
<span style="margin-left: 3em">其官以致人才寥落術業不精日差日遠所由來</span>  
<span style="margin-left: 3em">也夫曆學義理宏深如天之高星辰之遠七政形</span>  
<span style="margin-left: 3em">體之大小所麗之高下相距之近遠太陽之盈縮</span>  
<span style="margin-left: 3em">太陰之遲疾五緯行度之留退順逆相合相衝伏</span>  
<span style="margin-left: 3em">見凌犯之日時刻分與日月交食之時刻分秒方</span>  
<span style="margin-left: 3em">位及諸曜視氣等差種種所以然之理最難推究</span>  
<span style="margin-left: 3em">苟非使其餘裕從容即恬心力學之士雖討論亦</span>  
<span style="margin-left: 3em">莫得其精臣自受事以來召致官生開局講肄按</span>  
<span style="margin-left: 3em">期考試務使理數兼通有裨</span>  
<span style="margin-left: 2em">國家億萬年曆典之用奈何官微俸薄陞轉無階窶</span>  
<span style="margin-left: 3em">貧有慮以故鼓勵不前難期成效其滿官據五官</span>  
<span style="margin-left: 3em">正屯主祜等呈稱欽天監原無滿洲官員職等於</span>  
<span style="margin-left: 3em">部院衙門俸深年久因曉漢文陞入本監原非通</span>  
<span style="margin-left: 3em">曉天文曆法</span>  
<span style="margin-left: 2em">題授今六部大小衙門滿洲官員盡皆按旗陞轉惟</span>  
<span style="margin-left: 3em">職等十有餘員六年加俸二級不與陞轉情實可</span>  
<span style="margin-left: 3em">矜等情其漢官雖久經習業然品秩既卑俸祿益</span>  
<span style="margin-left: 3em">薄上之無功名陞轉之望下之有妻子啼饑之苦</span>  
<span style="margin-left: 3em">即有聰敏之資志日消於衣食何能精業臣以爲</span>  
<span style="margin-left: 3em">滿官原係按旗陞轉之官合無仍照舊例與以陞</span>  
<span style="margin-left: 3em">轉各衙門則滿員無偏枯之嘆矣至於漢官似應</span>  
<span style="margin-left: 3em">一體邀</span>  
<span style="margin-left: 2em">恩升轉或</span>  
<span style="margin-left: 2em">賜量加品級品加則俸增庶小臣之日夜勤勞以趨</span>  
<span style="margin-left: 2em">國事者亦得沾蘇息之恩而可藉手以報</span>  
<span style="margin-left: 1em">朝廷矣又本監天文生輪日講肄更番測候勞苦困頓</span>  
<span style="margin-left: 3em">且每年進曆例有頂帶伏乞</span>  
<span style="margin-left: 1em">勅部議復頂帶以鼓趨向則臣黽勉以求作人圖報</span>  
<span style="margin-left: 1em">皇上之微忱庶幾有濟也緣係陳請事理貼黃難盡仰</span>  
<span style="margin-left: 3em">乞</span>  
<span style="margin-left: 1em">皇上俯賜全覽</span>  
<span style="margin-left: 1em">勅部議復施行爲此具本親齎謹具奏</span>  
<span style="margin-left: 1em">聞</span>  
<span style="margin-left: 3em">康熙九年七月二十三日奏本月二十七日奏</span>  
<span style="margin-left: 1em">旨該部議奏</span>  
<span style="margin-left: 8em">康熙九年九月二十七日禮部題本</span>  
<span style="margin-left: 3em">禮部</span>  
<span style="margin-left: 2em">題爲曆法賾奧需材俸薄難以鼓勵仰祈</span>  
<span style="margin-left: 1em">聖恩破格作養以光</span>  
<span style="margin-left: 1em">大典以勉後效事禮科抄出治理曆法南懷仁奏前事</span>  
<span style="margin-left: 3em">內開康熙九年七月二十三日奏本月二十七日</span>  
<span style="margin-left: 3em">奉</span>  
<span style="margin-left: 1em">旨該部議奏欽此欽遵於七月二十八日到部該臣等</span>  
<span style="margin-left: 3em">議得據治理曆法南懷仁疏稱滿官原係按旗陞</span>  
<span style="margin-left: 3em">轉之官合無仍照舊例與以陞轉各衙門則滿官</span>  
<span style="margin-left: 3em">無偏枯之嘆矣至於漢官亦應一體邀</span>  
<span style="margin-left: 2em">恩陞轉或</span>  
<span style="margin-left: 2em">賜量加品級本監天文生每年進曆例有頂帶並乞</span>  
<span style="margin-left: 3em">議覆頂帶以鼓趨嚮等語查滿漢官陞轉加級事</span>  
<span style="margin-left: 3em">隸吏部應請</span>  
<span style="margin-left: 1em">勅下吏部議覆查得會典並無定有天文生頂帶順治</span>  
<span style="margin-left: 3em">二年定例舉人生員外郎耆老定有頂帶天文生</span>  
<span style="margin-left: 3em">並未定有頂帶今欽天監天文生請給頂帶之處</span>  
<span style="margin-left: 3em">無容議臣等未敢擅便謹題請</span>  
<span style="margin-left: 1em">旨康熙九年八月十一日題本月十四日奉</span>  
<span style="margin-left: 1em">旨天文生應否給與頂帶著會同吏部議奏欽此欽遵</span>  
<span style="margin-left: 3em">於本月十五日到部該臣等會議得查會典內並</span>  
<span style="margin-left: 3em">順治二年所定之例舉人生員外郎耆老等令服</span>  
<span style="margin-left: 3em">頂帶其天文生並無令服頂帶之例所請天文生</span>  
<span style="margin-left: 3em">頂帶無容再議可也臣等未敢擅便謹題請</span>  
<span style="margin-left: 1em">旨康熙九年九月初七日題本月初九日奉</span>  
<span style="margin-left: 1em">旨天文關係重大不可不鼓勵習學伊等應給何品頂</span>  
<span style="margin-left: 3em">帶著再議具奏欽此欽遵於本月初十日到部該</span>  
<span style="margin-left: 3em">臣等會同再議得先該臣等二部具題內開會典</span>  
<span style="margin-left: 3em">及順治二年所定之例舉人生員外郎耆老等令</span>  
<span style="margin-left: 3em">服頂帶其天文生並無令服頂帶之例所請天文</span>  
<span style="margin-left: 3em">生頂帶無容再議等因具題奉</span>  
<span style="margin-left: 1em">旨天文關係重大不可不鼓勵習學伊等應給何品頂</span>  
<span style="margin-left: 3em">帶著再議具奏欽此查得欽天監天文生陞轉博</span>  
<span style="margin-left: 3em">士博士係從九品今天文生進曆之日許服九品</span>  
<span style="margin-left: 3em">頂帶可也臣等未敢擅便謹題請</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 3em">康熙九年九月二十七日題本月三十日奉</span>  
<span style="margin-left: 1em">旨天文生議止於進曆之日服頂帶不合著給與從九</span>  
<span style="margin-left: 2em">品頂帶照例補用</span>  
<span style="margin-left: 7em">康熙十年六月二十七日南懷仁奏本</span>  
<span style="margin-left: 3em">欽天監治理曆法臣南懷仁謹</span>  
<span style="margin-left: 2em">奏爲曆法天文已復</span>  
世祖垂憲兄屬精習成材被陷流徙伏乞代題仰籲  
<span style="margin-left: 1em">皇恩俯賜赦回以勷厥用事據本監博士鮑英華鮑選</span>  
<span style="margin-left: 3em">呈前事內稱胞兄鮑英齊荷</span>  
<span style="margin-left: 2em">國厚恩歷陞本監司曆效忠守法臨履冰兢闔監官</span>  
<span style="margin-left: 3em">員共聞共見禍遭亡賴積棍楊光先倚恃權奸妄</span>  
<span style="margin-left: 3em">變</span>  
世祖成法欺世盜名濫竊監正之職凡本監各官精通新  
<span style="margin-left: 2em">法能專其事者盡遭陷害有至於正法者有流徙者</span>  
<span style="margin-left: 2em">有革職者痛兄英齊止因精習新法觸迕光先遂視</span>  
<span style="margin-left: 2em">爲仇讎不置兄於死不已於是捏稱職兄受紙行王</span>  
<span style="margin-left: 2em">永柱之賄以作餽伊之禮朦朧題參及下部鞠審永</span>  
<span style="margin-left: 2em">柱三訊三刑仰天抵死無跡可認已經回</span>  
<span style="margin-left: 2em">奏無奈棍先權勢燻灼見覆</span>  
<span style="margin-left: 2em">奏招由盡屬子虛自知誑疏罔</span>  
<span style="margin-left: 1em">上惟恐反坐遂調別司復審又因永柱足脛潰腐刑不</span>  
<span style="margin-left: 3em">能忍於再四以故違心屈認餽兄銀貳拾兩冀免</span>  
<span style="margin-left: 3em">一時之死至稱餽伊銀拾貳兩實無其事特棍先</span>  
<span style="margin-left: 3em">欲加之罪耳比兄見永柱之認乃事之大者既已</span>  
<span style="margin-left: 3em">屈供成招則知誣枉之罪不能免於奸黨之阱故</span>  
<span style="margin-left: 3em">於餽先禮銀之小節不必再辯蓋恐觸其嚴刑徒</span>  
<span style="margin-left: 3em">受苦於無用之地亦即隨口應認聽其胡盧提以</span>  
<span style="margin-left: 3em">成獄耳向使兄罪果當其實亦當援天文生犯罪</span>  
<span style="margin-left: 3em">習業已成能專其事者照例問罪仍在本監應役</span>  
<span style="margin-left: 3em">之典況兄本非罪爲棍先之所誣乎今查本監官</span>  
<span style="margin-left: 3em">員凡受光先之誣陷而至死者俱蒙</span>  
<span style="margin-left: 1em">皇恩賜祭以卹冤魂其有無辜革職者盡獲邀</span>  
<span style="margin-left: 1em">恩起復以昭誣枉獨兄英齊遭先陷阱未蒙昭雪尚在</span>  
<span style="margin-left: 3em">流徙地方今天文曆法諳練者少兄係精習成材</span>  
<span style="margin-left: 3em">竄非其罪伏乞代題仰邀</span>  
<span style="margin-left: 1em">聖恩憐察奸邪之陷害</span>  
<span style="margin-left: 1em">准賜赦回不惟兄冤得白職等亦感佩無既矣等情到</span>  
<span style="margin-left: 3em">臣該臣看得天文曆法係人間僻學精習者難得</span>  
<span style="margin-left: 3em">與別衙門官員不同鮑英齊原屬精習之人在監</span>  
<span style="margin-left: 3em">效職二十餘年能專其事具有成績嗣因楊光先</span>  
<span style="margin-left: 3em">變行舊法之時凡屬諳練新法者意在剪鋤盡淨</span>  
<span style="margin-left: 3em">英齊所習原係新法光先見其迕己亦借端參革</span>  
<span style="margin-left: 3em">流徙查本監官員凡受光先之誣陷者俱蒙</span>  
<span style="margin-left: 1em">聖鑒開釋鮑英齊事亦在誣陷之中情實可矜今據鮑</span>  
<span style="margin-left: 3em">英華等具情前來臣從曆法天文需人起見故敢</span>  
<span style="margin-left: 3em">冒瀆</span>  
<span style="margin-left: 1em">聖慈伏乞</span>  
<span style="margin-left: 1em">睿鑒施行緣係據情陳請事理字稍逾格統祈</span>  
<span style="margin-left: 1em">鑒原爲此具本親齎謹具奏</span>
