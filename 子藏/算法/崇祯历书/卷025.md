## 崇祯历书卷之二十五　康熙奏疏

*康熙十三年正月二十九日至康熙十七年七月十一日*

<span style="margin-left: 2em">奏疏十一</span>  
<span style="margin-left: 6em">康熙十三年正月二十九日南怀仁奏本</span>  
<span style="margin-left: 3em">钦天监治理历法臣南怀仁谨</span>  
<span style="margin-left: 2em">奏为恭际</span>  
<span style="margin-left: 1em">钦造之仪象告成益幸合天之历法有据谨按器阐明</span>  
<span style="margin-left: 3em">著有书表缮尘</span>  
<span style="margin-left: 1em">御览以光</span>  
<span style="margin-left: 2em">国典事窃惟古帝王之治历所以正天运定岁功而</span>  
<span style="margin-left: 3em">节宣和气为布政敷化之基诚为邦之首务也粤</span>  
<span style="margin-left: 3em">稽尧之命羲和也则曰钦若昊天历象日月星辰</span>  
<span style="margin-left: 3em">敬授人时而舜于受命之初在璇玑玉衡以齐七</span>  
<span style="margin-left: 3em">政盖以为治莫大于明时明时莫先于观象观象</span>  
<span style="margin-left: 3em">莫先于制器虞书之文可考也迨于后而其制荡</span>  
<span style="margin-left: 3em">于秦火西汉以来改历者七十余次创法者十有</span>  
<span style="margin-left: 3em">三家而其中肇造仪象者不多概见即间有所创</span>  
<span style="margin-left: 3em">铸或适于一时之用而不能经远或合于一事之</span>  
<span style="margin-left: 3em">宜而无当全用制器尚象盖若斯之难也我</span>  
<span style="margin-left: 1em">大清聿兴定鼎膺历数改正朔简用新法命为时宪历</span>  
<span style="margin-left: 3em">颁行天下事事密合天行故修政历法先臣汤若</span>  
<span style="margin-left: 3em">望屡奉</span>  
世祖章皇帝恩纶褒美将所进呈历指诸书宣付史馆新  
<span style="margin-left: 3em">法之善于斯概可睹已然历法虽已久行犹未铸</span>  
<span style="margin-left: 3em">有仪象于康熙四年内忽挺险之徒出而挠乱成</span>  
<span style="margin-left: 3em">宪妄用弊法迄于四载矫诬天常历典大坏幸我</span>  
<span style="margin-left: 1em">皇上乾纲独运洞察臣之所推验与天密合者为是复</span>  
<span style="margin-left: 3em">用时宪新法续蒙部议新造仪器并安设仪器台</span>  
<span style="margin-left: 3em">基应听工部俱照南怀仁所指速造奉有依议之</span>  
<span style="margin-left: 1em">旨钦此以部臣之庀材督造并臣之指授呕心以及监</span>  
<span style="margin-left: 3em">员之毕力供事今工已次第告竣业将诸仪安列</span>  
<span style="margin-left: 3em">于观象台上自是诸仪参互并测于以顺天而求</span>  
<span style="margin-left: 3em">合当无有弗合者矣然历有理有数有象有器盖</span>  
<span style="margin-left: 3em">历非明夫理则舛而理非数则无以显其微数非</span>  
<span style="margin-left: 3em">象则无以通其变象非器则无以得其精则今之</span>  
<span style="margin-left: 3em">诸仪是器也而理与数与象咸寓焉故诸仪有作</span>  
<span style="margin-left: 3em">之法有用之法有安定与夫一切运动坚固之法</span>  
<span style="margin-left: 3em">凡此非见诸发挥精粗具举则是惟臣知之而人</span>  
<span style="margin-left: 3em">不知岂所以公诸天下而垂永久之意乎以故融</span>  
<span style="margin-left: 3em">贯旧闻抒以心得覃精研虑缕析条分而且推类</span>  
<span style="margin-left: 3em">旁通绘图比切有说有表次为一十六卷名曰新</span>  
<span style="margin-left: 3em">制灵台仪象志要使肄业之官生服习心喻不致</span>  
<span style="margin-left: 3em">扞格而难操传之后世亦得凭是而有所考究焉</span>  
<span style="margin-left: 3em">此臣之所为仰答</span>  
<span style="margin-left: 1em">皇上委畀以典历之命而尽愚分之所当然也洪惟我</span>  
<span style="margin-left: 1em">皇上聪明天纵</span>  
<span style="margin-left: 1em">圣学日新则此象数之言实有切于治历明时之学以</span>  
<span style="margin-left: 3em">之敷陈</span>  
<span style="margin-left: 1em">黼座而备</span>  
<span style="margin-left: 2em">乙夜之观其于</span>  
<span style="margin-left: 1em">皇上钦若授时之治未必无补</span>  
<span style="margin-left: 1em">高深于万一也谨兹缮写编次成帙恭进</span>  
<span style="margin-left: 1em">御览抑臣更有请焉是书理数兼明图表备载樊然其</span>  
<span style="margin-left: 3em">不齐也钞誊不易绘画为艰使非版行势难尽人</span>  
<span style="margin-left: 3em">而给且无以遗久仰祈</span>  
<span style="margin-left: 1em">勅部镂版一副交臣印刷以资给发官生则守是业者</span>  
<span style="margin-left: 3em">皆手习一编而无阙如之憾矣至于与事诸员皆</span>  
<span style="margin-left: 3em">急公勤慎克底有成伏望我</span>  
<span style="margin-left: 1em">皇上悯其微劳量加优叙以鼓后效则亦</span>  
<span style="margin-left: 2em">国家酬庸激劝之典也臣从历法起见字多逾额如</span>  
<span style="margin-left: 3em">果刍荛可采伏乞</span>

<span style="margin-left: 2em">进呈臣无任悚仄屏营之至为此具本亲赍具</span>
