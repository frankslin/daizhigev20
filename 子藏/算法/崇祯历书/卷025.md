## 崇禎曆書卷之二十五　康熙奏疏

*康熙十三年正月二十九日至康熙十七年七月十一日*

<span style="margin-left: 2em">奏疏十一</span>  
<span style="margin-left: 6em">康熙十三年正月二十九日南懷仁奏本</span>  
<span style="margin-left: 3em">欽天監治理曆法臣南懷仁謹</span>  
<span style="margin-left: 2em">奏爲恭際</span>  
<span style="margin-left: 1em">欽造之儀象告成益幸合天之曆法有據謹按器闡明</span>  
<span style="margin-left: 3em">著有書表繕塵</span>  
<span style="margin-left: 1em">御覽以光</span>  
<span style="margin-left: 2em">國典事竊惟古帝王之治曆所以正天運定歲功而</span>  
<span style="margin-left: 3em">節宣和氣爲布政敷化之基誠爲邦之首務也粵</span>  
<span style="margin-left: 3em">稽堯之命羲和也則曰欽若昊天曆象日月星辰</span>  
<span style="margin-left: 3em">敬授人時而舜於受命之初在璿璣玉衡以齊七</span>  
<span style="margin-left: 3em">政蓋以爲治莫大於明時明時莫先於觀象觀象</span>  
<span style="margin-left: 3em">莫先於制器虞書之文可考也迨於後而其制蕩</span>  
<span style="margin-left: 3em">於秦火西漢以來改曆者七十餘次創法者十有</span>  
<span style="margin-left: 3em">三家而其中肇造儀象者不多概見即間有所創</span>  
<span style="margin-left: 3em">鑄或適於一時之用而不能經遠或合於一事之</span>  
<span style="margin-left: 3em">宜而無當全用制器尚象蓋若斯之難也我</span>  
<span style="margin-left: 1em">大清聿興定鼎膺曆數改正朔簡用新法命爲時憲曆</span>  
<span style="margin-left: 3em">頒行天下事事密合天行故修政曆法先臣湯若</span>  
<span style="margin-left: 3em">望屢奉</span>  
世祖章皇帝恩綸褒美將所進呈曆指諸書宣付史館新  
<span style="margin-left: 3em">法之善於斯概可睹已然曆法雖已久行猶未鑄</span>  
<span style="margin-left: 3em">有儀象於康熙四年內忽挺險之徒出而撓亂成</span>  
<span style="margin-left: 3em">憲妄用弊法迄於四載矯誣天常曆典大壞幸我</span>  
<span style="margin-left: 1em">皇上乾綱獨運洞察臣之所推驗與天密合者爲是復</span>  
<span style="margin-left: 3em">用時憲新法續蒙部議新造儀器併安設儀器臺</span>  
<span style="margin-left: 3em">基應聽工部俱照南懷仁所指速造奉有依議之</span>  
<span style="margin-left: 1em">旨欽此以部臣之庀材督造並臣之指授嘔心以及監</span>  
<span style="margin-left: 3em">員之畢力供事今工已次第告竣業將諸儀安列</span>  
<span style="margin-left: 3em">於觀象臺上自是諸儀參互並測於以順天而求</span>  
<span style="margin-left: 3em">合當無有弗合者矣然曆有理有數有象有器蓋</span>  
<span style="margin-left: 3em">曆非明夫理則舛而理非數則無以顯其微數非</span>  
<span style="margin-left: 3em">象則無以通其變象非器則無以得其精則今之</span>  
<span style="margin-left: 3em">諸儀是器也而理與數與象咸寓焉故諸儀有作</span>  
<span style="margin-left: 3em">之法有用之法有安定與夫一切運動堅固之法</span>  
<span style="margin-left: 3em">凡此非見諸發揮精粗具舉則是惟臣知之而人</span>  
<span style="margin-left: 3em">不知豈所以公諸天下而垂永久之意乎以故融</span>  
<span style="margin-left: 3em">貫舊聞抒以心得覃精研慮縷析條分而且推類</span>  
<span style="margin-left: 3em">旁通繪圖比切有說有表次爲一十六卷名曰新</span>  
<span style="margin-left: 3em">制靈臺儀象志要使肄業之官生服習心喻不致</span>  
<span style="margin-left: 3em">扞格而難操傳之後世亦得憑是而有所考究焉</span>  
<span style="margin-left: 3em">此臣之所爲仰答</span>  
<span style="margin-left: 1em">皇上委畀以典曆之命而盡愚分之所當然也洪惟我</span>  
<span style="margin-left: 1em">皇上聰明天縱</span>  
<span style="margin-left: 1em">聖學日新則此象數之言實有切於治曆明時之學以</span>  
<span style="margin-left: 3em">之敷陳</span>  
<span style="margin-left: 1em">黼座而備</span>  
<span style="margin-left: 2em">乙夜之觀其於</span>  
<span style="margin-left: 1em">皇上欽若授時之治未必無補</span>  
<span style="margin-left: 1em">高深於萬一也謹茲繕寫編次成帙恭進</span>  
<span style="margin-left: 1em">御覽抑臣更有請焉是書理數兼明圖表備載樊然其</span>  
<span style="margin-left: 3em">不齊也鈔謄不易繪畫爲艱使非版行勢難盡人</span>  
<span style="margin-left: 3em">而給且無以遺久仰祈</span>  
<span style="margin-left: 1em">勅部鏤版一副交臣印刷以資給發官生則守是業者</span>  
<span style="margin-left: 3em">皆手習一編而無闕如之憾矣至於與事諸員皆</span>  
<span style="margin-left: 3em">急公勤慎克底有成伏望我</span>  
<span style="margin-left: 1em">皇上憫其微勞量加優敘以鼓後效則亦</span>  
<span style="margin-left: 2em">國家酬庸激勸之典也臣從曆法起見字多逾額如</span>  
<span style="margin-left: 3em">果芻蕘可採伏乞</span>  
<span style="margin-left: 1em">睿鑒施行臣謹將所著書表稽首</span>  
<span style="margin-left: 2em">進呈臣無任悚仄屏營之至爲此具本親齎具</span>  
<span style="margin-left: 2em">奏以</span>  
<span style="margin-left: 1em">聞</span>  
<span style="margin-left: 3em">康熙十三年正月二十九日具奏二月初三日奉</span>  
<span style="margin-left: 1em">旨曆法天文關係大典據奏儀象告成製造精密南懷</span>  
<span style="margin-left: 2em">仁殫心料理勤勞可嘉著從優議敘具奏余著一並</span>  
<span style="margin-left: 2em">議奏該部知道書圖併發</span>  
<span style="margin-left: 6em">康熙十三年三月二十八日對哈納題本</span>  
<span style="margin-left: 3em">太子太保文華殿大學士管吏部尚書事臣對哈</span>  
<span style="margin-left: 3em">納等謹</span>  
<span style="margin-left: 2em">題爲恭際</span>  
<span style="margin-left: 1em">欽造之儀象告成益幸合天之曆法有據今按器闡明</span>  
<span style="margin-left: 3em">著有書表繕塵</span>  
<span style="margin-left: 1em">御覽以光</span>  
<span style="margin-left: 2em">國典事吏科抄出該禮部尚書哈爾哈齊等題前事</span>  
<span style="margin-left: 3em">內開禮科抄出欽天監治理曆法南懷仁奏前事</span>  
<span style="margin-left: 3em">康熙十三年正月二十九日奏二月初三日奉</span>  
<span style="margin-left: 1em">旨曆法天文關係大典據奏儀象告成製造精密南懷</span>  
<span style="margin-left: 2em">仁殫心料理勤勞可嘉著從優議敘具奏餘著一併</span>  
<span style="margin-left: 2em">議奏該部知道書圖併發欽此欽遵於本月初四日</span>  
<span style="margin-left: 3em">到部查得康熙八年八月臣部具題內開該臣等</span>  
<span style="margin-left: 3em">議得見在觀象臺舊簡儀等三件儀器若仍存在</span>  
<span style="margin-left: 3em">臺則南懷仁新造六件儀器難以安設俟南懷仁</span>  
<span style="margin-left: 3em">所造新儀器造成時將簡儀等舊儀器應移於臺</span>  
<span style="margin-left: 3em">下廂房收存令當值滿漢官員看守換班交付當</span>  
<span style="margin-left: 3em">值官員既稱臺上板房一間遮蔽儀器應移在臺</span>  
<span style="margin-left: 3em">東靠臺將門向臺造作風杆因礙測驗將風桿應</span>  
<span style="margin-left: 3em">移在北方其新造儀器併安設儀器臺基應聽工</span>  
<span style="margin-left: 3em">部具照南懷仁所指式樣速造可也等因具題奉</span>  
<span style="margin-left: 1em">旨依議欽遵在案查儀器告成作何議敘之處臣部並</span>  
<span style="margin-left: 3em">無檔案可稽又會典內開正統四年及景泰六年</span>  
<span style="margin-left: 3em">製造渾儀簡儀黃道晷影堂等儀器亦未開作何</span>  
<span style="margin-left: 3em">議敘之處查檔案內順治三年六月准吏部咨稱</span>  
<span style="margin-left: 3em">會同禮部看得湯若望創立新法勤勞懋著業蒙</span>  
<span style="margin-left: 1em">聖恩敘賚茲據禮臣查照前朝欽天監碑記吳昊以監</span>  
<span style="margin-left: 3em">正於弘治十年陞太常寺少卿今湯若望應加太</span>  
<span style="margin-left: 3em">常寺少卿職銜仍管欽天監監正事至賞賚出自</span>  
<span style="margin-left: 1em">聖恩非臣等所敢擬議等因奉</span>  
<span style="margin-left: 1em">旨是湯若望准加太常寺少卿職銜仍管欽天監監正</span>  
<span style="margin-left: 2em">事各欽遵在案該臣等議得南懷仁奏稱臣指授嘔</span>  
<span style="margin-left: 3em">心業將諸儀安列於觀象臺上以故覃精研慮繪</span>  
<span style="margin-left: 3em">圖表次爲一十六卷名曰新制靈臺儀象志是書</span>  
<span style="margin-left: 3em">樊然其不齊也使非版行勢難盡人而給且無以</span>  
<span style="margin-left: 3em">遺久仰祈</span>  
<span style="margin-left: 1em">勅部鏤版一副交臣印刷以資給發官生則守是業者</span>  
<span style="margin-left: 3em">皆手習一編而無闕如之憾矣至於與事諸員皆</span>  
<span style="margin-left: 3em">急公勤慎克底有成伏望我</span>  
<span style="margin-left: 1em">皇上憫其微勞量加優敘以鼓後效等因具題奉</span>  
<span style="margin-left: 1em">旨曆法天文關係大典據奏儀象告成製造精密南懷</span>  
<span style="margin-left: 2em">仁殫心料理勤勞可嘉著從優議敘具奏餘著一並</span>  
<span style="margin-left: 2em">議奏該部知道書圖併發欽此將南懷仁從優議敘</span>  
<span style="margin-left: 3em">及與事諸員議敘之處應交與吏部議既稱使非</span>  
<span style="margin-left: 3em">版行勢難盡人而給且無以遺久等語相應仍交</span>  
<span style="margin-left: 3em">與南懷仁酌量刊刷散給官生可也臣等未敢擅</span>  
<span style="margin-left: 3em">便謹題請</span>  
<span style="margin-left: 1em">旨康熙十三年二月二十二日題本月二十四日奉</span>  
<span style="margin-left: 1em">旨依議欽此欽遵於二月廿七日抄出到部隨移劄欽</span>  
<span style="margin-left: 3em">天監取在事各官職名去後於康熙十三年三月</span>  
<span style="margin-left: 3em">十二日據欽天監呈送監正宜塔喇監副安泰左</span>  
<span style="margin-left: 3em">監副加一級李光顯此三員率領官生供事工部</span>  
<span style="margin-left: 3em">員外郎翁英七品筆帖式加一級圖齊哈此二員</span>  
<span style="margin-left: 3em">監造諸儀右監副劉蘊德春官正孫有本秋官正</span>  
<span style="margin-left: 3em">徐瑚博士寧完壁博士加一級孫有容博士焦秉</span>  
<span style="margin-left: 3em">貞原任五官司歷革職今在欽天監辦事鮑英齊</span>  
<span style="margin-left: 3em">此七員監造諸器按式較對規制得宜懋著勤勞</span>  
<span style="margin-left: 3em">秋官正張問明靈臺郎加一級李光大靈臺郎邵</span>  
<span style="margin-left: 3em">泰衢主簿殷鎧支從八品俸博士加二級劉應昌</span>  
<span style="margin-left: 3em">支從八品俸博士加一級鮑英華博士加一級鮑</span>  
<span style="margin-left: 3em">選博士張登科從九品天文生薛宗胤蕭盡禮馮</span>  
<span style="margin-left: 3em">方慶朱世貴張文臣席以恭此十四員安置星座</span>  
<span style="margin-left: 3em">測對儀象繕繪書圖克盡厥職等語又於康熙十</span>  
<span style="margin-left: 3em">三年三月十七日咨呈內稱將本監與事堂屬官</span>  
<span style="margin-left: 3em">員及朝夕同事之工部監造員外郎筆帖式等職</span>  
<span style="margin-left: 3em">名已經開列呈送外其工部督造之堂官及監視</span>  
<span style="margin-left: 3em">司屬官員職名理合再行呈送一並議敘但係大</span>  
<span style="margin-left: 3em">部官員本監未便開送應行文工部移取題敘至</span>  
<span style="margin-left: 3em">本監供事滿員如五官正加俸二級魏成格五官</span>  
<span style="margin-left: 3em">正屯主祜主簿阿莫索峩靈臺郎加俸二級鰲海</span>  
<span style="margin-left: 3em">靈臺郎索博靈臺郎蘇來博士賈善七品筆帖式</span>  
<span style="margin-left: 3em">加一級三虎七品筆帖式加一級三寶七品筆帖</span>  
<span style="margin-left: 3em">式加一級吳隆古七品筆帖式吳格七品筆帖式</span>  
<span style="margin-left: 3em">加一級愛玉璽無品筆帖式阿達禪此十三員自</span>  
<span style="margin-left: 3em">創造新儀數載以來悉心供事著有勤勞相應一</span>  
<span style="margin-left: 3em">體議敘等因呈送到部該臣等議得禮部疏稱南</span>  
<span style="margin-left: 3em">懷仁疏稱臣指授嘔心業將諸儀安列於觀象臺</span>  
<span style="margin-left: 3em">上至於與事諸員皆急公勤慎克底有成量加優</span>  
<span style="margin-left: 3em">敘以鼓後效等因具題奉</span>  
<span style="margin-left: 1em">旨曆法天文關係大典據奏議象告成製造精密南懷</span>  
<span style="margin-left: 2em">仁殫心料理勤勞可嘉著從優議敘具奏餘著</span>  
<span style="margin-left: 2em">一並議奏該部知道書圖併發欽此將南懷仁從優</span>  
<span style="margin-left: 3em">議敘及與事之員議敘之處應交與吏部議等語</span>  
<span style="margin-left: 3em">查明季以來儀象俱未修成其修造官員未有作</span>  
<span style="margin-left: 3em">何議敘之例順治三年因湯若望創立新法加太</span>  
<span style="margin-left: 3em">常寺少卿銜仍管欽天監監正事漢品級考內開</span>  
<span style="margin-left: 3em">欽天監監正陞加京官銜仍管欽天監事等語查</span>  
<span style="margin-left: 3em">康熙八年六月內禮部具題將南懷仁仍留欽天</span>  
<span style="margin-left: 3em">監監副之職南懷仁具奏請辭奉</span>  
<span style="margin-left: 1em">旨南懷仁控辭官職其曆法天文一切事務俱殫心料</span>  
<span style="margin-left: 3em">理情詞懇切准其所請在案南懷仁見今無官以</span>  
<span style="margin-left: 3em">閑散治理曆法天文各項儀象關係大典南懷仁</span>  
<span style="margin-left: 3em">親身指示修製告成應從優議敘將南懷仁授爲</span>  
<span style="margin-left: 3em">欽天監監正加太常寺少卿職銜歷查舊例無有</span>  
<span style="margin-left: 3em">製造儀象告成者亦無有將在事工部官員欽天</span>  
<span style="margin-left: 3em">監各官議敘之例順治三年新曆告成止將湯若</span>  
<span style="margin-left: 3em">望議敘並未議及欽天監別項官員且在事官員</span>  
<span style="margin-left: 3em">係南懷仁指示修造相應將工部堂司官員筆帖</span>

<span style="margin-left: 3em">正月二十九日因監副安泰請</span>  
<span style="margin-left: 1em">旨爲四方覘驗舊法之日食臣不得不</span>  
<span style="margin-left: 3em">題各省日食之食分以免臨時日食之誤測庶見</span>  
<span style="margin-left: 3em">舊新兩法之疏密臣查舊曆日食向以京師之食</span>  
<span style="margin-left: 3em">分頒行各省從無推算外省日食之法今天下各</span>  
<span style="margin-left: 3em">省日食之分秒多寡不同者原爲理之必然及數</span>  
<span style="margin-left: 3em">十年新法效驗所證蓋所謂日食者無他乃月體</span>  
<span style="margin-left: 3em">在太陽及人目中遮蔽日光致人目不能見故凡</span>  
<span style="margin-left: 3em">有日食則日月人目三者必在一直視線上若有</span>  
<span style="margin-left: 3em">一者離線則不食矣其視線正對兩曜之中心則</span>  
<span style="margin-left: 3em">謂之全食若離中心近遠若干則其食有多寡之</span>  
<span style="margin-left: 3em">分但北方人目之視線不可以爲南方人目之視</span>  
<span style="margin-left: 3em">線故北方之食分不可以爲南方之食分明矣即</span>  
<span style="margin-left: 3em">東西方亦然此爲日食彼方此方有無之根由耳</span>  
<span style="margin-left: 3em">又新法之日食頒行天下三十餘年其各省之食</span>  
<span style="margin-left: 3em">分有多寡不同爲天下萬目所共睹又有此一省</span>  
<span style="margin-left: 3em">數分秒彼一省全無皆與本法所預推密合屢驗</span>  
<span style="margin-left: 3em">今本年五月初一日舊法之食分不過爲京師之</span>  
<span style="margin-left: 3em">食分則各省所驗之食分既與京師不同斷不可</span>  
<span style="margin-left: 3em">以京師之食分同一例觀也又京師之所無不可</span>  
<span style="margin-left: 3em">以爲外省之所無如本年京師之日食依新法不</span>  
<span style="margin-left: 3em">過二十微而廣東雲南等多有三四分有餘者康</span>  
<span style="margin-left: 3em">熙八年京師之日食不過五分數十秒而廣東見</span>  
<span style="margin-left: 3em">食十分有餘即比京師又多四分有餘者比例而</span>  
<span style="margin-left: 3em">觀則先年與今年無異也若依舊法則京師與各</span>  
<span style="margin-left: 3em">省皆同而兩法疏密豈待今日而見其驗已久矣</span>  
<span style="margin-left: 3em">今將日食各省不同之總圖理解並各省之食分</span>  
<span style="margin-left: 3em">開列</span>  
<span style="margin-left: 2em">進呈</span>  
<span style="margin-left: 1em">御覽臣從曆法起見字多逾格貼黃難盡統祈鑒宥爲</span>  
<span style="margin-left: 3em">此具本親齎謹具</span>  
<span style="margin-left: 2em">奏聞</span>  
<span style="margin-left: 1em">奉旨天文曆法關係重大這本著與安泰所奏一並議</span>  
<span style="margin-left: 3em">奏該部知道</span>

<span style="margin-left: 3em">欽天監治理曆法加太常寺卿加一級臣南懷仁</span>  
<span style="margin-left: 3em">謹</span>  
<span style="margin-left: 2em">奏爲陳明測驗日食事竊惟測天之理莫深於曆法</span>  
<span style="margin-left: 3em">而曆法之疏密莫驗於交食然非窮理未有能明</span>  
<span style="margin-left: 3em">於斯者也欽惟我</span>  
<span style="margin-left: 1em">皇上睿智廣運學邃知天每於</span>

<span style="margin-left: 1em">聖聰更有加也臣以知曆於順治十七年</span>

<span style="margin-left: 3em">與夏至相近此兩次日食其所測之時刻與所預</span>  
<span style="margin-left: 3em">推者密合但所驗之食分與所預推間有不同者</span>

<span style="margin-left: 3em">曆指六卷日躔曆指新曆測驗紀略等書論曰清</span>  
<span style="margin-left: 3em">濛之氣者地中游氣時時上騰入夜爲多其質輕</span>  
<span style="margin-left: 3em">微略似澄清之水能映小爲大升卑爲高試於水</span>  
<span style="margin-left: 3em">中置一物斜視之則本小者見之爲大本低者見</span>  
<span style="margin-left: 3em">之爲高故日月出入人從地平上望之比於中天</span>  
<span style="margin-left: 3em">則大也交食曆指六卷中論清濛徑差有曰隆慶</span>  
<span style="margin-left: 3em">元年丁卯三月朔日食依日月周徑本法則月魄</span>  
<span style="margin-left: 3em">應全掩太陽之外尚餘二分半乃遠西測候至食</span>  
<span style="margin-left: 3em">甚時二曜以心正會反見日光贏而月魄週圍有</span>  
<span style="margin-left: 3em">光如金環然蓋清濛氣所爲也又云萬曆二十八</span>  
<span style="margin-left: 3em">年庚子六月朔遠西測得日食五分有半依本地</span>  
<span style="margin-left: 3em">原推正應四分較多一分有半此皆清濛氣使然</span>  
<span style="margin-left: 3em">耳書中所載此等日食之驗與其所以然者難以</span>  
<span style="margin-left: 3em">枚舉今本月初一日酉正二刻依新法所推月魄</span>  
<span style="margin-left: 3em">掩日光不過二十微則日月兩曜之周邊相摩切</span>  
<span style="margin-left: 3em">如今所進呈之第一圖有然又兩曜因與地平相</span>  
<span style="margin-left: 3em">近在濛氣之中則其本體照映開展比在天中更</span>  
<span style="margin-left: 3em">加廣大因而兩周之邊相入切至月魄掩日光之</span>  
<span style="margin-left: 3em">數秒如今所進呈之第二圖有然此其所測與其</span>  
<span style="margin-left: 3em">所推稍異者乃由於清濛氣之差也假若兩曜高</span>  
<span style="margin-left: 3em">離地平則無濛氣並其所映本食之秒亦全無矣</span>  
<span style="margin-left: 3em">又清濛氣之差有多寡不等隨其濛氣於四時中</span>  
<span style="margin-left: 3em">或厚薄清濁陰晴蚤暮隨時隨地各有不同因此</span>  
<span style="margin-left: 3em">不能預定凡有日出入帶食之分所驗與所推其</span>  
<span style="margin-left: 3em">不同者正此故也如本月朔當食之時假若濛氣</span>  
<span style="margin-left: 3em">加厚則其所映之食分更多矣但濛氣差可致食</span>  
<span style="margin-left: 3em">分有差不能致時刻有差若照舊法所推食分加</span>  
<span style="margin-left: 3em">入濛氣之差則日應失光七分有餘今所測失光</span>  
<span style="margin-left: 3em">不及一分則共差六分有餘論其所食之時刻則</span>  
<span style="margin-left: 3em">其初虧先天六刻其復圓後天二刻先後共差約</span>  
<span style="margin-left: 3em">有八刻又於本日太陽未入之前既經測驗復圓</span>  
<span style="margin-left: 3em">則其推帶食二分全錯明矣故明乎清濛氣差之</span>  
<span style="margin-left: 3em">理則新法所預推日食之微並食之時刻與已經</span>  
<span style="margin-left: 3em">測驗者皆密合可知也新法係</span>  
<span style="margin-left: 2em">熙朝定典交食爲曆學之明徵臣在曆言曆故不得</span>  
<span style="margin-left: 3em">不反覆披陳以仰佐</span>  
<span style="margin-left: 1em">高深於萬一耳臣不勝悚仄惶恐之至康熙十五年五</span>
