<span style="margin-left: 2em">曆象以齊七政今首日躔者何也曰七政運行各有</span>  
<span style="margin-left: 2em">一道二極各有三百六十經緯度其度分又各有實</span>  
<span style="margin-left: 2em">經緯視經緯其會合有實會視會實望視望樊然不</span>  
<span style="margin-left: 2em">齊首日躔者乃所以齊之也日躔之能齊七政奈何</span>  
<span style="margin-left: 2em">曰凡測量之法必自其根始如度樹之短長地其根</span>  
<span style="margin-left: 2em">也度舟行之遠近水次其根也度天行之根有二其</span>  
<span style="margin-left: 2em">一在天行之內歲首是也古法以今歲之十一月冬</span>  
<span style="margin-left: 2em">至爲來年之天正歲首冬至者則日軌高度分之極</span>  
<span style="margin-left: 2em">少日躔赤道緯之極南也其一在天行之外曆元是</span>  
<span style="margin-left: 2em">也自昔推曆元者必求上古之積年後來歲實稍密</span>  
<span style="margin-left: 2em">即無數可論故至授時而廢不用矣授時以至元辛</span>  
<span style="margin-left: 2em">巳爲曆年以其氣應爲根而求通積以歲實而一得</span>  
<span style="margin-left: 2em">冬至然此所得者皆平年之冬至非定冬至也今法</span>  
<span style="margin-left: 2em">以崇禎元年戊辰冬至日子正初刻爲曆元依恆年</span>  
<span style="margin-left: 2em">表求其根數爲平冬至因以法加減之爲定冬至定</span>  
<span style="margin-left: 2em">冬至者歲歲加減初無通積可求蓋日軌度之真極</span>  
<span style="margin-left: 2em">少日躔緯之真極南也是則天行之兩根舍日躔皆</span>  
<span style="margin-left: 2em">無從取之矣曰此兩根者六曜皆有行度皆可用以</span>  
<span style="margin-left: 2em">爲歲首爲曆元何獨日躔乃可乎曰此其故有二其</span>  
<span style="margin-left: 2em">一七曜之中獨日躔之行甚順也其一以他曜測不</span>  
<span style="margin-left: 2em">若以日躔測甚便也何謂甚順太陽之行與本天之</span>  
<span style="margin-left: 2em">本行相合爲一繇黃道帯之最中無出入歲月日時</span>  
<span style="margin-left: 2em">各平行有恆度分無永短如是者皆終古不易他曜</span>  
<span style="margin-left: 2em">之行於本天本行之外各有小輪各有緯距度各有</span>  
<span style="margin-left: 2em">遲疾留逆時時不等雖有定法而似無法何能爲他</span>  
<span style="margin-left: 2em">行之法譬如畸零不齊之布帛宜以十寸之尺度之</span>  
<span style="margin-left: 2em">若以畸零度畸零無乃欲齊而棼之乎故六曜者畸</span>  
<span style="margin-left: 2em">零之布帛日躔者十寸之尺也若恆星之東行與日</span>  
<span style="margin-left: 2em">相似亦可謂順矣乃行度最遲必六十餘年而一度</span>  
<span style="margin-left: 2em">二萬五千二百餘年而一周推步者欲求其變動之</span>  
<span style="margin-left: 2em">數卒世而不一得也且考恆星之經度必用太陽之</span>  
<span style="margin-left: 2em">經度自非二分二至爲其準則何從定之星之古測</span>  
<span style="margin-left: 2em">今測更多不合或曰順行或曰否人自爲說又何從</span>  
<span style="margin-left: 2em">定之豈若日躔之歲月日時俱可測驗俱可推算哉</span>  
<span style="margin-left: 2em">何謂甚便日光甚大用闚筩諸器即分秒可得諸星</span>  
<span style="margin-left: 2em">體微光眇測候頗難月體大矣而去地甚近其視差</span>  
<span style="margin-left: 2em">甚大已亦不能爲主古今法考月離經度者必因其</span>  
<span style="margin-left: 2em">食甚時刻考太陽之經度加半天周得太陰之經度</span>  
<span style="margin-left: 2em">故自昔名曆家先測太陽定其行度經度次及月五</span>  
<span style="margin-left: 2em">星恆星之行度經緯度以爲定法是知日行者諸行</span>  
<span style="margin-left: 2em">之本也然曆法首步氣朔兹有氣而未及朔何也曰</span>  
<span style="margin-left: 2em">朔望者日與月比論乃得之也未論月離未可論朔</span>  
<span style="margin-left: 2em">望也其不及歲差何也曰歲差者日與恆星比論乃</span>  
<span style="margin-left: 2em">得之也未論恆星未可論歲差也今以本法諸義著</span>  
<span style="margin-left: 2em">於篇綴之立成表二卷以資推算焉</span>

<span style="margin-left: 3em">定南北線第一</span>  
<span style="margin-left: 1em">一法天正春秋分日或前一日或後一日亦可午正前</span>  
<span style="margin-left: 2em">後植表臬視表末景所至輙作點爲識次作直線聯</span>  
<span style="margin-left: 2em">諸點即卯酉線其垂線即子午南北線何故爲兩分</span>  
<span style="margin-left: 2em">日行赤道下表景自朝至暮止作一直線前後各一</span>  
<span style="margin-left: 2em">日尚未覺有曲線也</span>  
<span style="margin-left: 1em">二法不拘日月於午前用象限儀測得日軌高即於表</span>  
<span style="margin-left: 2em">末景作識午後用本儀測得日軌與午前所取同高</span>  
<span style="margin-left: 2em">亦於表末景作識以直線聯兩點即卯酉線何故爲</span>  
<span style="margin-left: 2em">東西等高則同經兩經間平分其所容之經即子午</span>  
<span style="margin-left: 2em">經圈</span>  
<span style="margin-left: 2em">右二法不論何物但其體勢可當表臬者即用之</span>  
<span style="margin-left: 1em">三法不拘日月以植表根一點爲心多作平行圈視午</span>  
<span style="margin-left: 6em">前景末切某圈作點午後待景再切原圈</span>  
<span style="margin-left: 6em">作點聯兩點作直線爲卯酉如上圖甲爲</span>  
<span style="margin-left: 6em">表根點以爲心多作丙乙等圈甲乙爲午</span>  
<span style="margin-left: 2em">前景甲丙爲午後景乙丙平分於丁作甲丁垂線至</span>  
<span style="margin-left: 2em">乙丙線爲子午</span>  
<span style="margin-left: 2em">右第一法必待春秋分第二第三法恆日可用但論</span>  
<span style="margin-left: 2em">其理俱未能定卯酉之真線何故爲太陽本行去離</span>  
<span style="margin-left: 2em">赤道以前以後終歲終古皆不作周圈而作螺旋圈</span>  
<span style="margin-left: 2em">也欲得真線別有本法</span>

<span style="margin-left: 2em">在極東<sub class="note-yuan">用此即定線一夕得可</sub></span>  
<span style="margin-left: 2em">若無本器用兩表之法兩表者一定表其體與地平</span>  
<span style="margin-left: 2em">爲垂線一游表其直邊亦與地平爲垂線先以二表</span>

<span style="margin-left: 12em">星漸移而東則遷游表隨</span>  
<span style="margin-left: 12em">東至不復東而止移西亦</span>  
<span style="margin-left: 12em">如之末從定表望兩游表</span>  
<span style="margin-left: 12em">各以直線聯之成三角形</span>  
<span style="margin-left: 2em">平分其角作南北正線</span>  
<span style="margin-left: 2em">或以權繫垂線可當表但須權末極銳與垂線相應</span>  
<span style="margin-left: 2em">以切地平定點</span>  
<span style="margin-left: 1em">已上諸法必以夜及午正時若或早或晚隨時求之則</span>  
<span style="margin-left: 2em">有別法先定一表景之直線以此線當地平上之太</span>  
<span style="margin-left: 2em">陽經圈即於此時用測器取日軌高以得南北正線</span>  
<span style="margin-left: 2em">如後圖作甲乙丙丁圈其心戊甲丙爲地平丙上數</span>  
<span style="margin-left: 2em">本地赤道出地之度如順天府五十度即至己從己</span>  
<span style="margin-left: 2em">作徑線徑線之或北或南取本日日躔離赤道距等</span>  
<span style="margin-left: 2em">度爲己壬作壬癸線爲赤道距等圈次從丙甲上數</span>  
<span style="margin-left: 2em">日軌高度分如高三十度得子作子丑線即本時地</span>  
<span style="margin-left: 2em">平上之太陽緯圈也此線交壬癸距圈於卯從卯向</span>  
<span style="margin-left: 2em">甲丙地平引作酉卯辰垂線取子丑緯圈上子午半</span>
