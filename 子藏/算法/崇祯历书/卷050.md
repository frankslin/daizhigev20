<span style="margin-left: 2em">一道二极各有三百六十经纬度其度分又各有实</span>  
<span style="margin-left: 2em">经纬视经纬其会合有实会视会实望视望樊然不</span>  
<span style="margin-left: 2em">齐首日躔者乃所以齐之也日躔之能齐七政奈何</span>  
<span style="margin-left: 2em">曰凡测量之法必自其根始如度树之短长地其根</span>  
<span style="margin-left: 2em">也度舟行之远近水次其根也度天行之根有二其</span>  
<span style="margin-left: 2em">一在天行之内岁首是也古法以今岁之十一月冬</span>  
<span style="margin-left: 2em">至为来年之天正岁首冬至者则日轨高度分之极</span>  
<span style="margin-left: 2em">少日躔赤道纬之极南也其一在天行之外历元是</span>  
<span style="margin-left: 2em">也自昔推历元者必求上古之积年后来岁实稍密</span>  
<span style="margin-left: 2em">即无数可论故至授时而废不用矣授时以至元辛</span>  
<span style="margin-left: 2em">巳为历年以其气应为根而求通积以岁实而一得</span>  
<span style="margin-left: 2em">冬至然此所得者皆平年之冬至非定冬至也今法</span>  
<span style="margin-left: 2em">以崇祯元年戊辰冬至日子正初刻为历元依恒年</span>  
<span style="margin-left: 2em">表求其根数为平冬至因以法加减之为定冬至定</span>  
<span style="margin-left: 2em">冬至者岁岁加减初无通积可求盖日轨度之真极</span>  
<span style="margin-left: 2em">少日躔纬之真极南也是则天行之两根舍日躔皆</span>  
<span style="margin-left: 2em">无从取之矣曰此两根者六曜皆有行度皆可用以</span>  
<span style="margin-left: 2em">为岁首为历元何独日躔乃可乎曰此其故有二其</span>

<span style="margin-left: 2em">若以日躔测甚便也何谓甚顺太阳之行与本天之</span>  
<span style="margin-left: 2em">本行相合为一繇黄道帯之最中无出入岁月日时</span>  
<span style="margin-left: 2em">各平行有恒度分无永短如是者皆终古不易他曜</span>
