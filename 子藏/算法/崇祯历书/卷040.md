<span style="margin-left: 1em"><sub class="note-yuan">　　　　　　　　　　　　　　　　　　　　孫嗣烈焦應旭</sub></span>  
<span style="margin-left: 1em">取地平線法　增題一<sub class="note-jiao">校：清刊本此前有測</sub></span>  
<span style="margin-left: 6em">　<sub class="note-yuan">量全義三卷標題</sub></span>  
<span style="margin-left: 5em">凡測高深廣遠必用直角者以小句股求大</span>  
<span style="margin-left: 5em">句股也地平爲句所測高爲股股者垂線也</span>  
<span style="margin-left: 5em">垂線之末加權焉以定地平有本器本論今</span>  
<span style="margin-left: 5em">用象限與矩度則於器心施權線平直相切</span>  
<span style="margin-left: 6em">於象限之邊其表邊所向之處別立他表</span>  
<span style="margin-left: 6em">則他表與器之心爲平行線如一圖甲乙</span>  
<span style="margin-left: 6em">爲物高丙上加器表邊在上旁以權線準</span>  
<span style="margin-left: 6em">之從丙直視至甲定甲爲他表則甲丙線</span>  
<span style="margin-left: 6em">爲地面上平行線何者垂線從天頂向地</span>  
<span style="margin-left: 6em">心與地面上平線爲直角故也</span>  
<span style="margin-left: 6em">若道里相距太遠難定其高下之較何者</span>  
<span style="margin-left: 6em">地面爲地球之一分弧分也遠則目與物</span>  
<span style="margin-left: 6em">爲弧背所隔不相及矣法以相距之遠分</span>  
<span style="margin-left: 6em">爲若干分每兩分定其高下之較末以各</span>  
<span style="margin-left: 8em">較加減之得總高下之較如二圖甲</span>  
<span style="margin-left: 8em">乙相距四里許乙上加器別立丙表</span>  
<span style="margin-left: 8em">令乙與丙等高丙上加器別立丁表</span>  
<span style="margin-left: 8em">令丙與丁等高丁上加器望甲令甲</span>  
<span style="margin-left: 8em">與丁等高次量各表距地各幾何加</span>  
<span style="margin-left: 8em">減之得甲乙之較</span>  
<span style="margin-left: 8em">值兩地之間爲山城所隔如三圖量</span>  
<span style="margin-left: 8em">乙距丙幾何令乙與丙平丙之表端</span>  
<span style="margin-left: 8em">爲丁距戊幾何令丁與戊平戊下取</span>  
<span style="margin-left: 8em">己與丙平戊己距庚辛表幾何定己</span>  
<span style="margin-left: 7em">與庚平戊與辛平庚辛距壬癸表幾何</span>  
<span style="margin-left: 7em">令辛庚與壬癸平從壬癸望甲令癸與</span>  
<span style="margin-left: 7em">甲平次以丁丙己戊并庚辛壬癸并兩</span>  
<span style="margin-left: 7em">數相減餘爲兩地高下之較如近乙之</span>  
<span style="margin-left: 7em">丁丙與己戊并多於近甲之庚辛與壬</span>  
<span style="margin-left: 7em">癸并則乙下而甲高深淺反之</span>  
<span style="margin-left: 7em">若山城中窮于用器則于山腰用之又</span>  
<span style="margin-left: 7em">別有簡法曰山頂戊用器求甲與乙之</span>  
<span style="margin-left: 7em">深兩數之較則高下之較<sub class="note-yuan">四圖</sub></span>  
<span style="margin-left: 7em">如在乙欲測甲高乙上用器令乙與丁</span>  
<span style="margin-left: 2em">平則量丁乙之遠而求甲丁之深<sub class="note-yuan">五圖</sub></span>  
<span style="margin-left: 1em">矩尺測量法　增題二</span>  
<span style="margin-left: 2em">法曰如一圖欲於丁測甲乙之高丁上立表表端爲</span>  
<span style="margin-left: 9em">山口矩尺之直角加焉以己戊尺</span>  
<span style="margin-left: 9em">向高際乙稍移就之令己戊乙爲</span>  
<span style="margin-left: 9em">直線次從戊己尺上依直線向地</span>  
<span style="margin-left: 9em">平得丙成丁戊丙甲乙丙相似兩</span>  
<span style="margin-left: 2em">形則丙丁與丁戊若丙甲與乙甲以高求遠則戊丁</span>  
<span style="margin-left: 2em">與丁丙若乙甲與甲丙</span>  
<span style="margin-left: 2em">若據高求遠如二圖丁丙與戊丁若戊丁與丁乙若</span>  
<span style="margin-left: 6em">因遠求高則戊丁與丁丙若乙丁與戊丁</span>  
<span style="margin-left: 6em">論曰戊丁乙戊丁丙兩形有丁直角丁丙</span>  
<span style="margin-left: 6em">戊丙戊丁并爲一直角丙戊乙亦爲直角</span>  
<span style="margin-left: 6em">兩角內減丁戊丙角餘戊丙丁丁戊乙兩</span>  
<span style="margin-left: 6em">角等夫直角形有兩角等即形相似則丙</span>  
<span style="margin-left: 2em">角之對邊戊丁也乙戊丁角之對邊丁乙也其比例</span>  
<span style="margin-left: 9em">必等</span>  
<span style="margin-left: 9em">求井之深則於井口邊甲上立表</span>  
<span style="margin-left: 9em">向井底乙向地平之丁成甲丁丙</span>  
<span style="margin-left: 9em">丙戊乙兩形相似是丙甲當廣甲</span>  
<span style="margin-left: 2em">丁當深也</span>  
<span style="margin-left: 1em">測極遠別法　增題三</span>  
<span style="margin-left: 7em">兩郡邑相距太遠以高求遠表法爲窮</span>  
<span style="margin-left: 7em">則用四表遇地面不平四表法又窮別</span>  
<span style="margin-left: 7em">法每邑取一高若山巔若樓臺若林木</span>  
<span style="margin-left: 7em">俱可或并爲諸物又地平爲他物所礙</span>  
<span style="margin-left: 2em">則又窮當於氣清日朗風恬時燒狼烟直上作兩處</span>  
<span style="margin-left: 2em">之表次于近山之頂取甲取乙甲山上加象限向所</span>  
<span style="margin-left: 2em">測之丁與丙又向乙山定丙甲丁乙甲丁兩角乙山</span>  
<span style="margin-left: 2em">上加象限向甲向丁向丙定丁乙丙甲乙丙兩角夫</span>  
<span style="margin-left: 7em">甲乙丙形有甲乙邊乙甲兩角可求甲</span>  
<span style="margin-left: 7em">丙邊甲乙丁形有甲乙邊甲乙兩角可</span>  
<span style="margin-left: 7em">求甲丁邊未甲丁丙形有甲丙甲丁兩</span>  
<span style="margin-left: 7em">邊可求丁丙相距之遠若一次不能測</span>  
<span style="margin-left: 7em">則分測之如以甲乙測丁丙以乙辛測</span>  
<span style="margin-left: 7em">丙戊以辛庚測戊己</span>  
<span style="margin-left: 1em">量高遠深　增題四</span>  
<span style="margin-left: 7em">用方木表承以鼎足之跗垂權取直表</span>  
<span style="margin-left: 7em">端以下一尺或五寸用一十或一百平</span>  
<span style="margin-left: 7em">分之下作方孔長寸許廣三分貫以横</span>  
<span style="margin-left: 8em">表游移無定亦以十或百平分之縱</span>  
<span style="margin-left: 8em">横作直角</span>  
<span style="margin-left: 8em">解曰如一圖欲測甲乙之高丙上立</span>  
<span style="margin-left: 8em">表横表游移令丁戊乙爲直線成丁</span>  
<span style="margin-left: 8em">戊己丁乙庚兩相似形即丁己若干</span>  
<span style="margin-left: 8em">分與己戊一百分若丁庚與乙庚加</span>  
<span style="margin-left: 8em">甲庚得全高</span>  
<span style="margin-left: 8em">以高求遠則戊己一百分與丁己若</span>  
<span style="margin-left: 8em">干分若乙庚與庚丁減丁己得甲丙</span>  
<span style="margin-left: 8em">遠物在下目在上如二圖令戊丁丙</span>  
<span style="margin-left: 10em">作直線則戊己與己丁若戊甲</span>  
<span style="margin-left: 10em">與甲丙</span>  
<span style="margin-left: 10em">若無高求遠則用重表如三圖</span>  
<span style="margin-left: 10em">以丑壬兩測之較當庚癸相距</span>  
<span style="margin-left: 10em">之遠</span>  
<span style="margin-left: 10em">高上測高用重表再測但須定</span>  
<span style="margin-left: 10em">表横用游表直用在丙得己丙</span>  
<span style="margin-left: 10em">在丁得丁戊其較庚己以當丙</span>  
<span style="margin-left: 10em">丁横表己辛以當甲乙</span>  
<span style="margin-left: 10em">在一高測兩下在丁向乙向丙</span>  
<span style="margin-left: 2em">定横表之兩數則丁戊當丁甲戊辛當甲丙己辛當</span>  
<span style="margin-left: 2em">乙丙己戊當甲乙用五圖以遠求高其理亦同以遠</span>  
<span style="margin-left: 2em">求深或井口上立柱用四圖以井口之度求深用二</span>  
<span style="margin-left: 2em">圖</span>  
<span style="margin-left: 1em">造象限儀法<sub class="note-yuan">篇中或省曰象限或曰儀</sub></span>  
<span style="margin-left: 8em">用銅或木板作圈四分之一去板邊</span>  
<span style="margin-left: 8em">三分作甲乙直線平面中任取丙爲</span>  
<span style="margin-left: 8em">心甲爲界作甲丁虛圈交甲乙線于</span>  
<span style="margin-left: 8em">戊從戊過丙作直線交甲丁圈于丁</span>  
<span style="margin-left: 8em">從甲至丁作直線成丁甲乙直角<sub class="note-yuan">幾何</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">用法</sub>次以甲爲心去版邊一二分取乙爲界作乙庚圈即</span>  
<span style="margin-left: 1em">四分全圈之一象限也圈限外餘版剡去之次離乙庚</span>  
<span style="margin-left: 1em">弧以內約二分作相似弧兩弧間平分各度分又同前</span>  
<span style="margin-left: 1em">作相似弧兩弧間識其十度或五度從庚從乙皆可起</span>  
<span style="margin-left: 1em">算互用之庚後作小孔貫以權線至甲<sub class="note-yuan">若作兩指尺可不用權線</sub></span>  
<span style="margin-left: 7em">窺衡一名指尺銅爲之首爲小圜徑三</span>  
<span style="margin-left: 7em">四分從心出直線名指線以定度分所</span>  
<span style="margin-left: 7em">至也廣三分厚一分長與象限之半徑</span>  
<span style="margin-left: 2em">等上設二表一近心一近秒秒以鉤鉤象限邊令游</span>  
<span style="margin-left: 2em">移而不脫表形方高廣約四三分中作直線鑢通之</span>  
<span style="margin-left: 8em">下爲小孔表之下端爲半枘入尺中</span>  
<span style="margin-left: 8em">令兩表之前後兩縫兩孔皆相對不</span>  
<span style="margin-left: 8em">爽毫髮于指線爲垂線象限邊上亦</span>  
<span style="margin-left: 8em">設二表如上法蓋測量法每用兩指</span>  
<span style="margin-left: 8em">線以定兩測所在也或作兩指尺同</span>  
<span style="margin-left: 8em">心同線可定可移尤便</span>  
<span style="margin-left: 8em">如圖以木爲架上爲半圈兩端開山</span>  
<span style="margin-left: 8em">口深三四寸以受象限</span>  
<span style="margin-left: 8em">用象限法</span>  
<span style="margin-left: 2em">架口受象限之甲乙邊以庚甲線取平焉儀面正對</span>  
<span style="margin-left: 2em">所測物從窺衡覷物與指線相參直得指線如弧所</span>  
<span style="margin-left: 2em">當度分則從乙至指線者地平上之高也從指線至</span>  
<span style="margin-left: 2em">庚距天頂之高也</span>  
<span style="margin-left: 8em">次法以架口受象限之弧甲心上別</span>  
<span style="margin-left: 8em">用權線下垂過弧甲庚邊上立表游</span>  
<span style="margin-left: 8em">移覷表與物參直審權線之度定物</span>  
<span style="margin-left: 8em">之高從乙角起者地平上之高也從</span>  
<span style="margin-left: 8em">庚角起者距天頂之高也</span>  
<span style="margin-left: 2em">三法若地或平或欹則別作圓轉之架上端爲球空</span>  
<span style="margin-left: 2em">大半作實球與空球等入空中鐵枘指外徑二分長</span>  
<span style="margin-left: 6em">寸許旋轉廻斡不出大球之口空球旁加</span>  
<span style="margin-left: 6em">螺旋三具俟實球之體定而固之　儀後</span>  
<span style="margin-left: 6em">面中心作孔受實球之枘用時以枘入孔</span>  
<span style="margin-left: 6em">轉儀得其面與所測物爲直線以螺旋固</span>  
<span style="margin-left: 2em">之</span>  
<span style="margin-left: 2em">象限之用有二一定儀如首圖其一邊與地平爲平</span>  
<span style="margin-left: 2em">行線以窺衡定地平上之度一游儀如二圖用權線</span>  
<span style="margin-left: 2em">其理同也何者游表邊與定衡同向一物作平行線</span>  
<span style="margin-left: 2em">定儀之立邊與游儀之權線作平行線則窺衡與立</span>  
<span style="margin-left: 2em">邊所作角表邊與權線所作角等弧亦等</span>  
<span style="margin-left: 1em">造矩度法</span>  
<span style="margin-left: 2em">用銅木板作正方直角形如象限法任用一角爲心</span>  
<span style="margin-left: 7em">兩旁作直角兩線如甲乙甲丙次用元</span>  
<span style="margin-left: 7em">度乙丙各爲心各作小弧交于丁次作</span>  
<span style="margin-left: 7em">丙丁乙丁兩線成甲乙丙丁正方形各</span>  
<span style="margin-left: 7em">邊作一百分每對邊分以直線相聯成</span>  
<span style="margin-left: 7em">網目形器小每五分十分作直線器大</span>  
<span style="margin-left: 2em">更細分之</span>  
<span style="margin-left: 2em">角止作心加窺衡加權線任用架具於前</span>  
<span style="margin-left: 2em">定儀于立邊書高深平邊書遠游儀于表旁邊書遠</span>  
<span style="margin-left: 2em">對邊書高深以便別識</span>  
<span style="margin-left: 7em">約法象限弧之內空作矩度其窺衡指</span>  
<span style="margin-left: 7em">線上分即矩度邊之分是指線當權線</span>  
<span style="margin-left: 7em">也爲用殊大若欲取最小之分則加兩</span>  
<span style="margin-left: 7em">窺衡兩指線相合爲一線用時分指焉</span>  
<span style="margin-left: 2em">安衡法管端之小圜心開圓孔象限心則方孔爲螺</span>  
<span style="margin-left: 2em">柱當圓爲圓當方爲方末圓而加螺旋焉仍以螺旋</span>  
<span style="margin-left: 2em">固之分象限法先三分之用元度庚乙兩角各爲心</span>  
<span style="margin-left: 2em">取庚辛乙寅得庚寅寅辛辛乙爲三分而等各又三</span>  
<span style="margin-left: 2em">分之爲九分又各半之爲十八大分取四大分又五</span>  
<span style="margin-left: 2em">分之用元度每大分之界爲心左右參差定點每大</span>
