<span style="margin-left: 6em">　<sub class="note-yuan">量全义三卷标题</sub></span>  
<span style="margin-left: 5em">凡测高深广远必用直角者以小句股求大</span>  
<span style="margin-left: 5em">句股也地平为句所测高为股股者垂线也</span>  
<span style="margin-left: 5em">垂线之末加权焉以定地平有本器本论今</span>  
<span style="margin-left: 5em">用象限与矩度则于器心施权线平直相切</span>  
<span style="margin-left: 6em">于象限之边其表边所向之处别立他表</span>  
<span style="margin-left: 6em">则他表与器之心为平行线如一图甲乙</span>  
<span style="margin-left: 6em">为物高丙上加器表边在上旁以权线准</span>  
<span style="margin-left: 6em">之从丙直视至甲定甲为他表则甲丙线</span>  
<span style="margin-left: 6em">为地面上平行线何者垂线从天顶向地</span>  
<span style="margin-left: 6em">心与地面上平线为直角故也</span>  
<span style="margin-left: 6em">若道里相距太远难定其高下之较何者</span>  
<span style="margin-left: 6em">地面为地球之一分弧分也远则目与物</span>  
<span style="margin-left: 6em">为弧背所隔不相及矣法以相距之远分</span>  
<span style="margin-left: 6em">为若干分每两分定其高下之较末以各</span>  
<span style="margin-left: 8em">较加减之得总高下之较如二图甲</span>  
<span style="margin-left: 8em">乙相距四里许乙上加器别立丙表</span>  
<span style="margin-left: 8em">令乙与丙等高丙上加器别立丁表</span>  
<span style="margin-left: 8em">令丙与丁等高丁上加器望甲令甲</span>  
<span style="margin-left: 8em">与丁等高次量各表距地各几何加</span>  
<span style="margin-left: 8em">减之得甲乙之较</span>  
<span style="margin-left: 8em">值两地之间为山城所隔如三图量</span>  
<span style="margin-left: 8em">乙距丙几何令乙与丙平丙之表端</span>

<span style="margin-left: 7em">与庚平戊与辛平庚辛距壬癸表几何</span>

<span style="margin-left: 7em">癸并则乙下而甲高深浅反之</span>

<span style="margin-left: 1em">矩尺测量法　增题二</span>  
<span style="margin-left: 2em">法曰如一图欲于丁测甲乙之高丁上立表表端为</span>  
<span style="margin-left: 9em">山口矩尺之直角加焉以己戊尺</span>  
<span style="margin-left: 9em">向高际乙稍移就之令己戊乙为</span>  
<span style="margin-left: 9em">直线次从戊己尺上依直线向地</span>  
<span style="margin-left: 9em">平得丙成丁戊丙甲乙丙相似两</span>  
<span style="margin-left: 2em">形则丙丁与丁戊若丙甲与乙甲以高求远则戊丁</span>  
<span style="margin-left: 2em">与丁丙若乙甲与甲丙</span>  
<span style="margin-left: 2em">若据高求远如二图丁丙与戊丁若戊丁与丁乙若</span>  
<span style="margin-left: 6em">因远求高则戊丁与丁丙若乙丁与戊丁</span>  
<span style="margin-left: 6em">论曰戊丁乙戊丁丙两形有丁直角丁丙</span>  
<span style="margin-left: 6em">戊丙戊丁并为一直角丙戊乙亦为直角</span>  
<span style="margin-left: 6em">两角内减丁戊丙角余戊丙丁丁戊乙两</span>  
<span style="margin-left: 6em">角等夫直角形有两角等即形相似则丙</span>  
<span style="margin-left: 2em">角之对边戊丁也乙戊丁角之对边丁乙也其比例</span>  
<span style="margin-left: 9em">必等</span>  
<span style="margin-left: 9em">求井之深则于井口边甲上立表</span>  
<span style="margin-left: 9em">向井底乙向地平之丁成甲丁丙</span>  
<span style="margin-left: 9em">丙戊乙两形相似是丙甲当广甲</span>  
<span style="margin-left: 2em">丁当深也</span>  
<span style="margin-left: 1em">测极远别法　增题三</span>  
<span style="margin-left: 7em">两郡邑相距太远以高求远表法为穷</span>  
<span style="margin-left: 7em">则用四表遇地面不平四表法又穷别</span>  
<span style="margin-left: 7em">法每邑取一高若山巅若楼台若林木</span>

<span style="margin-left: 7em">用方木表承以鼎足之跗垂权取直表</span>  
<span style="margin-left: 7em">端以下一尺或五寸用一十或一百平</span>

<span style="margin-left: 1em">造象限仪法<sub class="note-yuan">篇中或省曰象限或曰仪</sub></span>  
<span style="margin-left: 8em">用铜或木板作圈四分之一去板边</span>  
<span style="margin-left: 8em">三分作甲乙直线平面中任取丙为</span>  
<span style="margin-left: 8em">心甲为界作甲丁虚圈交甲乙线于</span>  
<span style="margin-left: 8em">戊从戊过丙作直线交甲丁圈于丁</span>  
<span style="margin-left: 8em">从甲至丁作直线成丁甲乙直角<sub class="note-yuan">几何</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">用法</sub>次以甲为心去版边一二分取乙为界作乙庚圈即</span>  
<span style="margin-left: 1em">四分全圈之一象限也圈限外余版剡去之次离乙庚</span>  
<span style="margin-left: 1em">弧以内约二分作相似弧两弧间平分各度分又同前</span>  
<span style="margin-left: 1em">作相似弧两弧间识其十度或五度从庚从乙皆可起</span>  
<span style="margin-left: 1em">算互用之庚后作小孔贯以权线至甲<sub class="note-yuan">若作两指尺可不用权线</sub></span>  
<span style="margin-left: 7em">窥衡一名指尺铜为之首为小圜径三</span>  
<span style="margin-left: 7em">四分从心出直线名指线以定度分所</span>  
<span style="margin-left: 7em">至也广三分厚一分长与象限之半径</span>  
<span style="margin-left: 2em">等上设二表一近心一近秒秒以钩钩象限边令游</span>  
<span style="margin-left: 2em">移而不脱表形方高广约四三分中作直线鑢通之</span>  
<span style="margin-left: 8em">下为小孔表之下端为半枘入尺中</span>  
<span style="margin-left: 8em">令两表之前后两缝两孔皆相对不</span>  
<span style="margin-left: 8em">爽毫发于指线为垂线象限边上亦</span>  
<span style="margin-left: 8em">设二表如上法盖测量法每用两指</span>  
<span style="margin-left: 8em">线以定两测所在也或作两指尺同</span>  
<span style="margin-left: 8em">心同线可定可移尤便</span>  
<span style="margin-left: 8em">如图以木为架上为半圈两端开山</span>  
<span style="margin-left: 8em">口深三四寸以受象限</span>  
<span style="margin-left: 8em">用象限法</span>  
<span style="margin-left: 2em">架口受象限之甲乙边以庚甲线取平焉仪面正对</span>  
<span style="margin-left: 2em">所测物从窥衡觑物与指线相参直得指线如弧所</span>  
<span style="margin-left: 2em">当度分则从乙至指线者地平上之高也从指线至</span>  
<span style="margin-left: 2em">庚距天顶之高也</span>  
<span style="margin-left: 8em">次法以架口受象限之弧甲心上别</span>  
<span style="margin-left: 8em">用权线下垂过弧甲庚边上立表游</span>  
<span style="margin-left: 8em">移觑表与物参直审权线之度定物</span>  
<span style="margin-left: 8em">之高从乙角起者地平上之高也从</span>  
<span style="margin-left: 8em">庚角起者距天顶之高也</span>  
<span style="margin-left: 2em">三法若地或平或欹则别作圆转之架上端为球空</span>  
<span style="margin-left: 2em">大半作实球与空球等入空中铁枘指外径二分长</span>  
<span style="margin-left: 6em">寸许旋转廻斡不出大球之口空球旁加</span>  
<span style="margin-left: 6em">螺旋三具俟实球之体定而固之　仪后</span>  
<span style="margin-left: 6em">面中心作孔受实球之枘用时以枘入孔</span>  
<span style="margin-left: 6em">转仪得其面与所测物为直线以螺旋固</span>  
<span style="margin-left: 2em">之</span>  
<span style="margin-left: 2em">象限之用有二一定仪如首图其一边与地平为平</span>  
<span style="margin-left: 2em">行线以窥衡定地平上之度一游仪如二图用权线</span>  
<span style="margin-left: 2em">其理同也何者游表边与定衡同向一物作平行线</span>  
<span style="margin-left: 2em">定仪之立边与游仪之权线作平行线则窥衡与立</span>  
<span style="margin-left: 2em">边所作角表边与权线所作角等弧亦等</span>  
<span style="margin-left: 1em">造矩度法</span>  
<span style="margin-left: 2em">用铜木板作正方直角形如象限法任用一角为心</span>  
<span style="margin-left: 7em">两旁作直角两线如甲乙甲丙次用元</span>  
<span style="margin-left: 7em">度乙丙各为心各作小弧交于丁次作</span>  
<span style="margin-left: 7em">丙丁乙丁两线成甲乙丙丁正方形各</span>  
<span style="margin-left: 7em">边作一百分每对边分以直线相联成</span>  
<span style="margin-left: 7em">网目形器小每五分十分作直线器大</span>  
<span style="margin-left: 2em">更细分之</span>  
<span style="margin-left: 2em">角止作心加窥衡加权线任用架具于前</span>  
<span style="margin-left: 2em">定仪于立边书高深平边书远游仪于表旁边书远</span>  
<span style="margin-left: 2em">对边书高深以便别识</span>  
<span style="margin-left: 7em">约法象限弧之内空作矩度其窥衡指</span>  
<span style="margin-left: 7em">线上分即矩度边之分是指线当权线</span>  
<span style="margin-left: 7em">也为用殊大若欲取最小之分则加两</span>  
<span style="margin-left: 7em">窥衡两指线相合为一线用时分指焉</span>  
<span style="margin-left: 2em">安衡法管端之小圜心开圆孔象限心则方孔为螺</span>  
<span style="margin-left: 2em">柱当圆为圆当方为方末圆而加螺旋焉仍以螺旋</span>  
<span style="margin-left: 2em">固之分象限法先三分之用元度庚乙两角各为心</span>  
<span style="margin-left: 2em">取庚辛乙寅得庚寅寅辛辛乙为三分而等各又三</span>  
<span style="margin-left: 2em">分之为九分又各半之为十八大分取四大分又五</span>  
<span style="margin-left: 2em">分之用元度每大分之界为心左右参差定点每大</span>  
<span style="margin-left: 2em">分中各有五小分得九十平分度也或取六大分作</span>
