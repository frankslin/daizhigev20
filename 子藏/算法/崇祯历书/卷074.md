<span style="margin-left: 2em">五緯天各距地<sub class="note-yuan">第一章</sub></span>  
<span style="margin-left: 1em">月離曆指第二十六章求月距地之高其法有五又求</span>  
<span style="margin-left: 2em">太陽距地其法有三皆以地半徑爲度又各法因高</span>  
<span style="margin-left: 2em">差<sub class="note-yuan">亦名視差地半徑差等</sub>或日月交食爲本</span>  
<span style="margin-left: 1em">恆星曆指三卷中亦測恆星之遠借用五星之測略定</span>  
<span style="margin-left: 2em">土星之高并亦得恆星在上之高今因五緯無視差</span>  
<span style="margin-left: 2em"><sub class="note-yuan">土木二星甚遠其視差不過數秒如無差難測水星常在蒙氣中亦不能測火星或有視差然不足爲測</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">其高之本說見下</sub>欲測其高法有二算或用古圖或新圖各</span>  
<span style="margin-left: 2em">有本論如左</span>  
<span style="margin-left: 1em">左古圖以地爲日月五星恆星諸天之心設諸曜各居</span>  
<span style="margin-left: 2em">一層天其厚內函有小輪<sub class="note-yuan">亦名歲輪</sub>各層相切而無空又</span>  
<span style="margin-left: 2em">各層上下有兩面下內爲凹上外爲凸</span>  
<span style="margin-left: 1em">各天之厚因函小輪其小輪于地有近有遠如兩心差</span>  
<span style="margin-left: 2em">之理則各天之厚爲小輪全徑及兩心差之倍分數</span>  
<span style="margin-left: 2em"><sub class="note-yuan">謂分數者蓋各有均圈于最高減距高去兩心差之幾分</sub>圖上各天小輪比本天</span>  
<span style="margin-left: 2em">許小以指外有兩心差數</span>  
<span style="margin-left: 1em">本曆測各星小輪及兩心差定本天半徑皆爲十萬分</span>  
<span style="margin-left: 2em">若加小輪半徑及兩心差數必得其最高距地若干</span>  
<span style="margin-left: 2em">若減之則得最卑距地若干如圖</span>  
<span style="margin-left: 1em">系凡設一層天上面距地若干度<sub class="note-yuan">以地半徑爲一度</sub>必得次層</span>  
<span style="margin-left: 2em">下面距地之若干度蓋兩面中無空隙又設內面所</span>  
<span style="margin-left: 2em">距若干度及次層上下兩面距本心比例以三率法</span>  
<span style="margin-left: 2em">求之并可得其厚距地之度法曰依內面距本心多</span>  
<span style="margin-left: 2em">寡分數得度多寡則上距分之某數必亦可知其度</span>  
<span style="margin-left: 1em">月離設三家之數以測定其距地之度今所爲第谷法</span>  
<span style="margin-left: 2em">曰太陰大距地爲六十地半徑有六十分之三十六</span>  
<span style="margin-left: 2em">或百分之六十</span>  
<span style="margin-left: 1em">水星天兩心差爲六八二二<sub class="note-yuan">十萬分爲全本天半徑下同</sub>小輪半徑</span>  
<span style="margin-left: 2em">爲三八五〇〇兩數并之<sub class="note-yuan">水星均圈法凡在最高不減其距地見本曆指</sub>又</span>  
<span style="margin-left: 2em">加半徑<sub class="note-yuan">全數</sub>得一四五三二二乃水星最大距之數又</span>  
<span style="margin-left: 2em">前兩數相并於全數內減之得五四六七八乃極近</span>  
<span style="margin-left: 2em">之數也置極近數爲六十度有六十分之三十六乃</span>  
<span style="margin-left: 2em">月天極高數也以此度數或約爲五分之三乘極高</span>  
<span style="margin-left: 2em">之數以小距數除之得一六一乃水星天上面距地</span>  
<span style="margin-left: 2em">之度也</span>  
<span style="margin-left: 1em">金星在水星上則其下面距地爲一六一<sub class="note-yuan">奇零不算</sub>設金星</span>  
<span style="margin-left: 2em">兩心差爲三二〇八用其半因有均圈用其半他星倣此<sub class="note-jiao">校：以上小字原爲</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">正文據文淵本校正</sub>爲一六〇四小輪半徑爲七二二四八兩</span>  
<span style="margin-left: 2em">數并加于全數得大距數爲一七三八五二又兩數</span>  
<span style="margin-left: 2em">相并減于全數得二六一四八爲近距之數法以內</span>  
<span style="margin-left: 2em">面距度之數乘大距數以近距數除之得一〇七一</span>  
<span style="margin-left: 2em">乃金星外面距地之度數也</span>  
<span style="margin-left: 1em">太陽有本法求其中距地得一一四十二地半徑諸家</span>  
<span style="margin-left: 2em">小異以求大距或用均圈<sub class="note-yuan">見日躔曆有表</sub>或不用均圈兩法</span>  
<span style="margin-left: 2em">略差今不用只因太陽兩心差求之得近距爲一一</span>  
<span style="margin-left: 2em">〇一遠距爲一一八二</span>  
<span style="margin-left: 2em">問太陽天內面切金星外面是也今因太陽本算其</span>  
<span style="margin-left: 2em">內面盈金星外面三十度兩算不合何也曰此測難</span>  
<span style="margin-left: 2em">求其密其較雖盈三十度以全數計之不及百分之</span>  
<span style="margin-left: 2em">三數則小矣又曰所測定各天之數皆以日月星諸</span>  
<span style="margin-left: 2em">體之心爲測其體之厚未嘗入數必月及水星金星</span>  
<span style="margin-left: 2em">各數略大而後算始無差又曰所用之數乃新圖之</span>  
<span style="margin-left: 2em">數不謂各曜各麗一天而相切故其數于此論不合</span>  
<span style="margin-left: 2em">或曰星體到本天最高在此其天或仍厚幾許要未</span>  
<span style="margin-left: 2em">可知所定之數亦其大略而已</span>  
<span style="margin-left: 1em">火星兩心差爲一九六〇取五分之三<sub class="note-yuan">均圈心距地心爲三分不同心</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">圈心距地心五分</sub>爲一一七六〇小輪極大半徑<sub class="note-yuan">有盈有縮故用大數</sub></span>  
<span style="margin-left: 2em">爲六五八〇〇兩數并之加于全數得遠大距爲一</span>  
<span style="margin-left: 2em">七七五六〇兩數并之減于全數得近小距爲二二</span>  
<span style="margin-left: 2em">四四〇用法以太陽大距數一一八二乘火星遠大</span>  
<span style="margin-left: 2em">距數以近距除之得九三五二乃火星外面距地之</span>  
<span style="margin-left: 2em">度數或木星天內面距地之數也</span>  
<span style="margin-left: 1em">木星兩心差爲九一六〇用其半得四五八〇小輪半</span>  
<span style="margin-left: 2em">徑爲一九二九四兩數并加全數得一二三八七四</span>  
<span style="margin-left: 2em">乃木星遠大距數兩數并減于全數得小距數爲七</span>  
<span style="margin-left: 2em">六一二六依前法以內面乘大距以小距數除之得</span>  
<span style="margin-left: 2em">一五二一七乃木星上面距地之數或土星下面距</span>  
<span style="margin-left: 2em">地之度數也</span>  
<span style="margin-left: 1em">土星兩心差爲一一六二八用其半得五八一四小輪</span>  
<span style="margin-left: 2em">心半徑爲一〇四二六兩數并加于全數得一一六</span>  
<span style="margin-left: 2em">二四〇乃土星大距數也若以前兩數并減于全數</span>  
<span style="margin-left: 2em">得小距數爲八三七六〇依前法乘除得二一一一</span>  
<span style="margin-left: 2em">七乃土星上面距地之數或恆星天距地之數也</span>  
<span style="margin-left: 1em">右算皆用古圖以明今測之數然亞耳罷德于唐僖宗</span>  
<span style="margin-left: 2em">廣明右算得水星本天中距地爲一百一十五度金</span>  
<span style="margin-left: 2em">星中距爲六百一十八度火星中距爲四千五百八</span>  
<span style="margin-left: 2em">十四度木星中距一萬〇千四百二十三度土星中</span>  
<span style="margin-left: 2em">距爲一萬五千八百度恆星中距爲一萬九千度</span>  
<span style="margin-left: 1em">因各星距地及其體之視徑亦并可推其大小下有本</span>  
<span style="margin-left: 2em">篇</span>  
<span style="margin-left: 2em">用新圖算各星距地<sub class="note-yuan">第二章</sub></span>  
<span style="margin-left: 1em">新圖以地爲太陽太陰恆星所行之心別五緯以太陽</span>  
<span style="margin-left: 2em">爲本行之心又土木火三星以太陽所行之圈爲古</span>  
<span style="margin-left: 2em">法所謂年歲圈即上所用法今非其真因用本法</span>  
<span style="margin-left: 1em">又新圖不言各星各有一天而強星在本重之內但各</span>  
<span style="margin-left: 2em">所行之輪或相切或相割耳</span>  
<span style="margin-left: 1em">土木火三星以太陽爲本行之心又因其心從太陽即</span>  
<span style="margin-left: 2em">以太陽所行之輪爲人目所見每年各星之行<sub class="note-yuan">見本曆指</sub></span>  
<span style="margin-left: 16em">欲知小輪于本</span>  
<span style="margin-left: 16em">天及兩心差各</span>  
<span style="margin-left: 16em">數比例則設太</span>  
<span style="margin-left: 16em">陽距地若干可</span>  
<span style="margin-left: 16em">得各星距地若</span>  
<span style="margin-left: 16em">干如圖設甲乙</span>  
<span style="margin-left: 16em"><sub class="note-yuan">日距地或小輪半徑</sub>乙丙</span>  
<span style="margin-left: 16em"><sub class="note-yuan">星本天半徑爲全數</sub>及丙</span>  
<span style="margin-left: 16em">丁<sub class="note-yuan">兩心之差</sub>又設甲</span>  
<span style="margin-left: 16em">乙爲若干度依</span>  
<span style="margin-left: 2em">法可得乙丙丙丁各線之度并之得甲丁乃星距地</span>  
<span style="margin-left: 2em">之度也上三星之法無二今置土星各圈之數如上</span>  
<span style="margin-left: 2em">用三率法甲乙<sub class="note-yuan">小輪半徑</sub>爲一〇四二六得距地爲一千</span>  
<span style="margin-left: 2em">一百四十二度<sub class="note-yuan">太陽中距度</sub>今乙丙全數<sub class="note-yuan">本天半徑</sub>得若干算</span>  
<span style="margin-left: 2em">得一〇九五三有奇又丙丁五八一四<sub class="note-yuan">兩心半差</sub>得六三</span>  
<span style="margin-left: 2em">六以甲乙乙丙丙丁三線之數并之得一二九三二</span>  
<span style="margin-left: 2em">度或地半徑乃土星大距地之數也若于乙丙全數</span>  
<span style="margin-left: 2em">或乙戊半徑數內減去甲乙及戊己<sub class="note-yuan">與丙丁等</sub>一七七八</span>  
<span style="margin-left: 2em">得九一七五乃土星近距數若求其中距地<sub class="note-yuan">引數爲三宮九</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">宮</sub>得一〇五五〇</span>  
<span style="margin-left: 1em">木星用法如上求得大距度數爲六一九〇中距爲三</span>  
<span style="margin-left: 2em">九九〇近距爲五九一九</span>  
<span style="margin-left: 1em">火星用法求得大距爲二九九八中距爲一七四五近</span>  
<span style="margin-left: 2em">距爲二二二</span>  
<span style="margin-left: 1em">下金水二星因不圍地球其算法與上三星略不等如</span>  
<span style="margin-left: 2em">圖甲乙爲日距之線或小輪心距地之線乙丙爲小</span>  
<span style="margin-left: 2em">輪之半徑以乙甲加減得大小兩距之數</span>  
<span style="margin-left: 9em">金星兩心差半之得一六〇四并</span>  
<span style="margin-left: 9em">加小輪半徑得一七三八五二用</span>  
<span style="margin-left: 9em">法乙甲全數<sub class="note-yuan">本天半徑</sub>得距地二四二</span>  
<span style="margin-left: 2em">度今算乙丙分數得度爲八四三以加于甲丙得一</span>  
<span style="margin-left: 2em">九八五乃金星距地之度數也若減之得三百度乃</span>  
<span style="margin-left: 2em">近距之度也</span>  
<span style="margin-left: 1em">水星以法求之得大距度爲一六五九小距爲六二五</span>  
<span style="margin-left: 2em">度</span>
