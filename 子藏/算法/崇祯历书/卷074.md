<span style="margin-left: 1em">月离历指第二十六章求月距地之高其法有五又求</span>  
<span style="margin-left: 2em">太阳距地其法有三皆以地半径为度又各法因高</span>  
<span style="margin-left: 2em">差<sub class="note-yuan">亦名视差地半径差等</sub>或日月交食为本</span>  
<span style="margin-left: 1em">恒星历指三卷中亦测恒星之远借用五星之测略定</span>  
<span style="margin-left: 2em">土星之高并亦得恒星在上之高今因五纬无视差</span>  
<span style="margin-left: 2em"><sub class="note-yuan">土木二星甚远其视差不过数秒如无差难测水星常在蒙气中亦不能测火星或有视差然不足为测</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">其高之本说见下</sub>欲测其高法有二算或用古图或新图各</span>  
<span style="margin-left: 2em">有本论如左</span>  
<span style="margin-left: 1em">左古图以地为日月五星恒星诸天之心设诸曜各居</span>  
<span style="margin-left: 2em">一层天其厚内函有小轮<sub class="note-yuan">亦名岁轮</sub>各层相切而无空又</span>  
<span style="margin-left: 2em">各层上下有两面下内为凹上外为凸</span>  
<span style="margin-left: 1em">各天之厚因函小轮其小轮于地有近有远如两心差</span>  
<span style="margin-left: 2em">之理则各天之厚为小轮全径及两心差之倍分数</span>  
<span style="margin-left: 2em"><sub class="note-yuan">谓分数者盖各有均圈于最高减距高去两心差之几分</sub>图上各天小轮比本天</span>  
<span style="margin-left: 2em">许小以指外有两心差数</span>  
<span style="margin-left: 1em">本历测各星小轮及两心差定本天半径皆为十万分</span>  
<span style="margin-left: 2em">若加小轮半径及两心差数必得其最高距地若干</span>  
<span style="margin-left: 2em">若减之则得最卑距地若干如图</span>  
<span style="margin-left: 1em">系凡设一层天上面距地若干度<sub class="note-yuan">以地半径为一度</sub>必得次层</span>  
<span style="margin-left: 2em">下面距地之若干度盖两面中无空隙又设内面所</span>  
<span style="margin-left: 2em">距若干度及次层上下两面距本心比例以三率法</span>  
<span style="margin-left: 2em">求之并可得其厚距地之度法曰依内面距本心多</span>  
<span style="margin-left: 2em">寡分数得度多寡则上距分之某数必亦可知其度</span>  
<span style="margin-left: 1em">月离设三家之数以测定其距地之度今所为第谷法</span>  
<span style="margin-left: 2em">曰太阴大距地为六十地半径有六十分之三十六</span>  
<span style="margin-left: 2em">或百分之六十</span>  
<span style="margin-left: 1em">水星天两心差为六八二二<sub class="note-yuan">十万分为全本天半径下同</sub>小轮半径</span>  
<span style="margin-left: 2em">为三八五〇〇两数并之<sub class="note-yuan">水星均圈法凡在最高不减其距地见本历指</sub>又</span>  
<span style="margin-left: 2em">加半径<sub class="note-yuan">全数</sub>得一四五三二二乃水星最大距之数又</span>  
<span style="margin-left: 2em">前两数相并于全数内减之得五四六七八乃极近</span>  
<span style="margin-left: 2em">之数也置极近数为六十度有六十分之三十六乃</span>  
<span style="margin-left: 2em">月天极高数也以此度数或约为五分之三乘极高</span>  
<span style="margin-left: 2em">之数以小距数除之得一六一乃水星天上面距地</span>  
<span style="margin-left: 2em">之度也</span>  
<span style="margin-left: 1em">金星在水星上则其下面距地为一六一<sub class="note-yuan">奇零不算</sub>设金星</span>

<span style="margin-left: 2em"><sub class="note-yuan">正文据文渊本校正</sub>为一六〇四小轮半径为七二二四八两</span>

<span style="margin-left: 2em">相并减于全数得二六一四八为近距之数法以内</span>  
<span style="margin-left: 2em">面距度之数乘大距数以近距数除之得一〇七一</span>  
<span style="margin-left: 2em">乃金星外面距地之度数也</span>
