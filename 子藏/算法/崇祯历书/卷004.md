## 崇祯历书卷之四　崇祯奏疏

*崇祯四年九月初八日至崇祯五年四月二十九日*

<span style="margin-left: 2em">缘起四</span>  
<span style="margin-left: 8em">崇祯四年九月初八日徐光启题本</span>  
<span style="margin-left: 3em">礼部尚书兼翰林院学士协理詹事府事加俸一</span>  
<span style="margin-left: 3em">级督修历法臣徐光启谨</span>  
<span style="margin-left: 2em">题为日食分数非多历法藉为明证谨具数上</span>  
<span style="margin-left: 1em">闻略陈义据以祈</span>  
<span style="margin-left: 1em">圣鉴以待候騐事案照本年六月十一日该臣</span>  
<span style="margin-left: 2em">题为月食事本年十月十五日夜望月食十三日奉</span>  
<span style="margin-left: 1em">圣旨览奏并图象知道了该部知道钦此其本月辛丑</span>  
<span style="margin-left: 3em">朔仍该日食为是二分以上未及三分例不救护</span>  
<span style="margin-left: 3em">止应具本题</span>  
<span style="margin-left: 1em">知然臣窃思之论救护可以例免通行论历法正宜详</span>  
<span style="margin-left: 3em">加测验盖历不差不改不验不用如日月交食皆</span>  
<span style="margin-left: 3em">天验之大者而月食在夜加时早晚苦无定据壶</span>  
<span style="margin-left: 3em">漏迟速自昔以为难凭星算切凖台官业已传习</span>  
<span style="margin-left: 3em">又独谙者知之不能共见也惟日食明白易晓按</span>  
<span style="margin-left: 3em">晷定时无可迁就无容隐匿故历法疎密独此最</span>  
<span style="margin-left: 3em">为的证况臣等翻译纂辑渐次就绪而向后交食</span>  
<span style="margin-left: 3em">为期尚远此时不一指实与该监诸臣明白共见</span>  
<span style="margin-left: 3em">即历成之后臣等之术无凭取验诸臣在事何从</span>  
<span style="margin-left: 3em">强其必信而安意习之谚曰千闻不如一见未经</span>  
<span style="margin-left: 3em">目击而以口舌争以书数传虽唇焦笔秃无益也</span>  
<span style="margin-left: 3em">非独此也是日之必当测候臣等于此有四说焉</span>  
<span style="margin-left: 3em">按日食有时差旧法用距午为限中前宜减中后</span>  
<span style="margin-left: 3em">宜加以定加时早晚若食在正中则无时差不用</span>  
<span style="margin-left: 3em">加减故台官相传谓日食加时有差多在早晚日</span>  
<span style="margin-left: 3em">中必合独今此食既在日中而加时则旧术在后</span>  
<span style="margin-left: 3em">新术在前当差三刻以上所以然者七政运行皆</span>  
<span style="margin-left: 3em">依黄道不繇赤道旧法所谓中乃赤道之午中而</span>  
<span style="margin-left: 3em">不知所谓中者黄道之正中也黄赤二道之中独</span>  
<span style="margin-left: 3em">冬夏二至乃得同度余日渐次相离今十月朔去</span>  
<span style="margin-left: 3em">冬至度数尚远两中之差二十三度有奇岂可仍</span>  
<span style="margin-left: 3em">因食限近午不加不减乎若食在二至又正午相</span>  
<span style="margin-left: 3em">值果可无差即食于他时而不在日中即差之原</span>  
<span style="margin-left: 3em">尚多亦复难办适际此日又值此时足为显证是</span>  
<span style="margin-left: 3em">可验时差之正术一也交食之法既无差误及至</span>  
<span style="margin-left: 3em">临期实候其加时又或少有后先此则不因天度</span>  
<span style="margin-left: 3em">而因地度地度者地之经度也本方之地经度未</span>  
<span style="margin-left: 3em">得真率则加时难定其法必从交食时测验数次</span>  
<span style="margin-left: 3em">乃可较勘画一今此食依新术测候其加时刻分</span>  
<span style="margin-left: 3em">或先后未合当取从前所记地经度分斟酌改定</span>  
<span style="margin-left: 3em">此可以求里差之真率二也台官见臣等述譔颇</span>  
<span style="margin-left: 3em">多推算甚繁疑为不可几及之事若云差违几刻</span>  
<span style="margin-left: 3em">宜当改正即葸然惧矣繇未能根极要领故也即</span>  
<span style="margin-left: 3em">如时差一法溺于所闻但知中无加减而不知中</span>  
<span style="margin-left: 3em">分黄赤今一经目见一经口授人人知加时之因</span>  
<span style="margin-left: 3em">黄道人人知黄道极之岁一周天奈何以赤道之</span>  
<span style="margin-left: 3em">午正为黄道之中限乎一时发覆蹊径了然何足</span>  
<span style="margin-left: 3em">为难而臣等又取黄道中限随时随地算就立成</span>  
<span style="margin-left: 3em">监官已经誊录临时用之最为简便其他诸术亦</span>  
<span style="margin-left: 3em">多类此足以明学习之甚易三也该监诸臣所最</span>  
<span style="margin-left: 3em">苦者惟从来议历之人诋为擅改不知其斤斤墨</span>  
<span style="margin-left: 3em">守者郭守敬之法即欲改不能也守敬之法加胜</span>  
<span style="margin-left: 3em">于前多矣而谓其至竟无差亦不能也如时差等</span>  
<span style="margin-left: 3em">术盖非一人一世之聪明所能揣测必因千百年</span>  
<span style="margin-left: 3em">之积候而后智者会通立法若前无绪业即守敬</span>  
<span style="margin-left: 3em">不能骤得之况诸臣乎人虽上智于未传之法岂</span>  
<span style="margin-left: 3em">能自知有而后尽心焉可矣此足以明疎失之非</span>  
<span style="margin-left: 3em">辜四也有此四者即分数甚少亦宜详加测候以</span>  
<span style="margin-left: 3em">求显验故敢冒昧上</span>  
<span style="margin-left: 1em">闻伏乞</span>  
<span style="margin-left: 1em">勅下该监量拨历科官生到局该监到台各豫定晷景</span>  
<span style="margin-left: 3em">临时依法瞻测则分数毕呈疎密具见密合则向</span>  
<span style="margin-left: 3em">来述作不为空言有差则向后各法因之裁定其</span>  
<span style="margin-left: 3em">于历事深为裨益所以当诣局者观象台日晷甚</span>  
<span style="margin-left: 3em">小仪器稍粗臣局有石晷木仪似为详密又难移</span>  
<span style="margin-left: 3em">动故须分投实候以相印证也为此谨将本日日</span>  
<span style="margin-left: 3em">食分秒时刻起复方位九服异同并具图象一并</span>

<span style="margin-left: 2em">进伏祈</span>  
<span style="margin-left: 1em">圣明裁度施行缘系日食事理未敢擅便谨</span>
