## 崇禎曆書卷之四　崇禎奏疏

*崇禎四年九月初八日至崇禎五年四月二十九日*

<span style="margin-left: 2em">緣起四</span>  
<span style="margin-left: 8em">崇禎四年九月初八日徐光啓題本</span>  
<span style="margin-left: 3em">禮部尚書兼翰林院學士協理詹事府事加俸一</span>  
<span style="margin-left: 3em">級督修曆法臣徐光啓謹</span>  
<span style="margin-left: 2em">題爲日食分數非多曆法藉爲明證謹具數上</span>  
<span style="margin-left: 1em">聞略陳義據以祈</span>  
<span style="margin-left: 1em">聖鑒以待候騐事案照本年六月十一日該臣</span>  
<span style="margin-left: 2em">題爲月食事本年十月十五日夜望月食十三日奉</span>  
<span style="margin-left: 1em">聖旨覽奏并圖象知道了該部知道欽此其本月辛丑</span>  
<span style="margin-left: 3em">朔仍該日食爲是二分以上未及三分例不救護</span>  
<span style="margin-left: 3em">止應具本題</span>  
<span style="margin-left: 1em">知然臣竊思之論救護可以例免通行論曆法正宜詳</span>  
<span style="margin-left: 3em">加測驗蓋曆不差不改不驗不用如日月交食皆</span>  
<span style="margin-left: 3em">天驗之大者而月食在夜加時早晚苦無定據壺</span>  
<span style="margin-left: 3em">漏遲速自昔以爲難憑星算切凖臺官業已傳習</span>  
<span style="margin-left: 3em">又獨諳者知之不能共見也惟日食明白易曉按</span>  
<span style="margin-left: 3em">晷定時無可遷就無容隱匿故曆法疎密獨此最</span>  
<span style="margin-left: 3em">爲的證況臣等翻譯纂輯漸次就緒而向後交食</span>  
<span style="margin-left: 3em">爲期尚遠此時不一指實與該監諸臣明白共見</span>  
<span style="margin-left: 3em">即曆成之後臣等之術無憑取驗諸臣在事何從</span>  
<span style="margin-left: 3em">強其必信而安意習之諺曰千聞不如一見未經</span>  
<span style="margin-left: 3em">目擊而以口舌爭以書數傳雖唇焦筆秃無益也</span>  
<span style="margin-left: 3em">非獨此也是日之必當測候臣等於此有四說焉</span>  
<span style="margin-left: 3em">按日食有時差舊法用距午爲限中前宜減中後</span>  
<span style="margin-left: 3em">宜加以定加時早晚若食在正中則無時差不用</span>  
<span style="margin-left: 3em">加減故臺官相傳謂日食加時有差多在早晚日</span>  
<span style="margin-left: 3em">中必合獨今此食既在日中而加時則舊術在後</span>  
<span style="margin-left: 3em">新術在前當差三刻以上所以然者七政運行皆</span>  
<span style="margin-left: 3em">依黃道不繇赤道舊法所謂中乃赤道之午中而</span>  
<span style="margin-left: 3em">不知所謂中者黃道之正中也黃赤二道之中獨</span>  
<span style="margin-left: 3em">冬夏二至乃得同度餘日漸次相離今十月朔去</span>  
<span style="margin-left: 3em">冬至度數尚遠兩中之差二十三度有奇豈可仍</span>  
<span style="margin-left: 3em">因食限近午不加不減乎若食在二至又正午相</span>  
<span style="margin-left: 3em">值果可無差即食于他時而不在日中即差之原</span>  
<span style="margin-left: 3em">尚多亦復難辦適際此日又值此時足爲顯證是</span>  
<span style="margin-left: 3em">可驗時差之正術一也交食之法既無差誤及至</span>  
<span style="margin-left: 3em">臨期實候其加時又或少有後先此則不因天度</span>  
<span style="margin-left: 3em">而因地度地度者地之經度也本方之地經度未</span>  
<span style="margin-left: 3em">得真率則加時難定其法必從交食時測驗數次</span>  
<span style="margin-left: 3em">乃可較勘畫一今此食依新術測候其加時刻分</span>  
<span style="margin-left: 3em">或先後未合當取從前所記地經度分斟酌改定</span>  
<span style="margin-left: 3em">此可以求里差之真率二也臺官見臣等述譔頗</span>  
<span style="margin-left: 3em">多推算甚繁疑爲不可幾及之事若云差違幾刻</span>  
<span style="margin-left: 3em">宜當改正即葸然懼矣繇未能根極要領故也即</span>  
<span style="margin-left: 3em">如時差一法溺於所聞但知中無加減而不知中</span>  
<span style="margin-left: 3em">分黃赤今一經目見一經口授人人知加時之因</span>  
<span style="margin-left: 3em">黃道人人知黃道極之歲一周天奈何以赤道之</span>  
<span style="margin-left: 3em">午正爲黃道之中限乎一時發覆蹊徑了然何足</span>  
<span style="margin-left: 3em">爲難而臣等又取黃道中限隨時隨地算就立成</span>  
<span style="margin-left: 3em">監官已經謄錄臨時用之最爲簡便其他諸術亦</span>  
<span style="margin-left: 3em">多類此足以明學習之甚易三也該監諸臣所最</span>  
<span style="margin-left: 3em">苦者惟從來議曆之人詆爲擅改不知其斤斤墨</span>  
<span style="margin-left: 3em">守者郭守敬之法即欲改不能也守敬之法加勝</span>  
<span style="margin-left: 3em">于前多矣而謂其至竟無差亦不能也如時差等</span>  
<span style="margin-left: 3em">術蓋非一人一世之聰明所能揣測必因千百年</span>  
<span style="margin-left: 3em">之積候而後智者會通立法若前無緒業即守敬</span>  
<span style="margin-left: 3em">不能驟得之况諸臣乎人雖上智于未傳之法豈</span>  
<span style="margin-left: 3em">能自知有而後盡心焉可矣此足以明疎失之非</span>  
<span style="margin-left: 3em">辜四也有此四者即分數甚少亦宜詳加測候以</span>  
<span style="margin-left: 3em">求顯驗故敢冒昧上</span>  
<span style="margin-left: 1em">聞伏乞</span>  
<span style="margin-left: 1em">勅下該監量撥曆科官生到局該監到臺各豫定晷景</span>  
<span style="margin-left: 3em">臨時依法瞻測則分數畢呈疎密具見密合則向</span>  
<span style="margin-left: 3em">來述作不爲空言有差則向後各法因之裁定其</span>  
<span style="margin-left: 3em">於曆事深爲裨益所以當詣局者觀象臺日晷甚</span>  
<span style="margin-left: 3em">小儀器稍粗臣局有石晷木儀似爲詳密又難移</span>  
<span style="margin-left: 3em">動故須分投實候以相印證也爲此謹將本日日</span>  
<span style="margin-left: 3em">食分秒時刻起復方位九服異同并具圖象一并</span>  
<span style="margin-left: 3em">上</span>  
<span style="margin-left: 2em">進伏祈</span>  
<span style="margin-left: 1em">聖明裁度施行緣係日食事理未敢擅便謹</span>  
<span style="margin-left: 2em">題請</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 4em">計開</span>

<span style="margin-left: 6em">刻并起復方位</span>  
<span style="margin-left: 5em">日食二分一十二秒依大統曆日體十分推</span>  
<span style="margin-left: 6em">算</span>

<span style="margin-left: 6em">北</span>

<span style="margin-left: 6em">北</span>  
<span style="margin-left: 4em">計食限內凡七刻八十三分二十四秒</span>

<span style="margin-left: 5em">食甚月離白道經度未至中交二度一十五</span>

<span style="margin-left: 4em">月緯度距黃道北實行七十五分二十二秒不</span>

<span style="margin-left: 2em">京師順天府見食二分一十二秒</span>  
<span style="margin-left: 5em">河南陜西山東三省俱見食一分內外人目</span>  
<span style="margin-left: 6em">難見與不見食略同</span>  
<span style="margin-left: 2em">南京應天府以南全不見食</span>

<span style="margin-left: 1em">聖旨這日食分數着該監局各預定晷景臨期分投測</span>  
<span style="margin-left: 2em">驗以相印證述旨內覽字誤鑒辛丑誤辛亥改正行</span>

<span style="margin-left: 2em">該部知道欽此欽遵於今月初一日到局督率欽天</span>  
<span style="margin-left: 3em">監秋官正周胤五官司曆劉有慶漏刻博士劉承</span>  
<span style="margin-left: 3em">志天文生周士昌薛文燦西洋陪臣<sub class="note-jiao">校：清刊本西洋陪臣作同</sub></span>  
<span style="margin-left: 3em"><sub class="note-yuan">兩遠臣</sub>羅雅谷湯若望及在局知曆人等預將原推</span>  
<span style="margin-left: 3em">時刻點定日晷調定壺漏又將測高儀器推定食</span>  
<span style="margin-left: 3em">甚刻分應得此時日軌高于地平三十五度四十</span>  
<span style="margin-left: 3em">分又于密室中斜開一隙置窺筩眼鏡以測虧復</span>  
<span style="margin-left: 3em">畫日體分數圖板以定食分各安頓訖候至午正</span>  
<span style="margin-left: 3em">二刻內方見初虧則臣等所推實先天半刻有奇</span>  
<span style="margin-left: 3em">至正四刻食甚儀上得日高三十五度四十分係</span>  
<span style="margin-left: 3em">司曆劉有慶守測實爲密合至未初三刻內已見</span>  
<span style="margin-left: 3em">復圓則臣等所推又後天一刻有奇而食甚分數</span>  
<span style="margin-left: 3em">以窺筩映照實未及二分比原推亦少半分以下</span>  
<span style="margin-left: 3em">此諸官生人等衆目所共見也臣于本月初八日</span>  
<span style="margin-left: 3em">疏中開列四欵其第二言本方之里差經度未得</span>  
<span style="margin-left: 3em">真率則加時難定故欲因此一食斟酌改正今食</span>  
<span style="margin-left: 3em">甚之度分密合則經度里差似己的確無煩更改</span>  
<span style="margin-left: 3em">蓋交食經度以食甚爲主故也獨食分加時未及</span>  
<span style="margin-left: 3em">原推者蓋因太陽光大昔人言日食須至一分以</span>  
<span style="margin-left: 3em">上乃得見之而臣前疏亦言今食在河南山東陜</span>  
<span style="margin-left: 3em">西等處食止一分內外人目難見與不見食略同</span>  
<span style="margin-left: 3em">今因此推究知日光閃燦惟食及四五分以上者</span>  
<span style="margin-left: 3em">乃得與原推相合若分數原少者其見食更少故</span>  
<span style="margin-left: 3em">一分內外者與不見食略同則二分有奇者所見</span>  
<span style="margin-left: 3em">宜不及二分也食分既少則食限時刻因之亦少</span>  
<span style="margin-left: 3em">矣然惟密室窺筩形象分明故得此分數時刻與</span>  
<span style="margin-left: 3em">該監官生明白共見不能不信若不用此法止憑</span>  
<span style="margin-left: 3em">目力則眩耀不真或用水盆映照亦蕩搖難定恐</span>  
<span style="margin-left: 3em">所見者僅可一分以上加時或止三四刻也今交</span>
