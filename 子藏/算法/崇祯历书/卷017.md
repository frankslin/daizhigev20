## 崇禎曆書卷之十七　順治奏疏

*順治元年十一月十一日至順治二年二月初一日*

<span style="margin-left: 2em">奏疏三</span>  
<span style="margin-left: 7em">順治元年十一月十一日湯若望奏本</span>  
<span style="margin-left: 3em">修政曆法遠臣湯若望爲敬陳本局應行緊要新</span>  
<span style="margin-left: 3em">法事宜等事該本局奏前事奉有禮部一併看了</span>  
<span style="margin-left: 3em">來說之</span>  
<span style="margin-left: 1em">旨本月初九日准</span>  
<span style="margin-left: 3em">貴同手本稱奉</span>  
<span style="margin-left: 2em">堂諭即將曆法書表所刻小板送部査閱如果憊壊</span>  
<span style="margin-left: 3em">缺畧不堪另行翻譯大字所需板片刷印刊刻工</span>  
<span style="margin-left: 3em">價紙張并渾天星球等三器合用物料造作工價</span>  
<span style="margin-left: 3em">一一開報以憑入奏無煩再請等因到司移會到</span>  
<span style="margin-left: 3em">局查照得本局前疏稱將闡發新法奧義曆指并</span>  
<span style="margin-left: 3em">推布七政立成諸表約成數十卷再加詳訂用官</span>  
<span style="margin-left: 3em">樣大字格式刊刻</span>  
<span style="margin-left: 1em">進呈藏之</span>  
<span style="margin-left: 2em">內府以成</span>  
<span style="margin-left: 1em">一代鴻謨之意非以原刻聊備教授推算之小板漫爲</span>  
<span style="margin-left: 1em">進藏而褻</span>  
<span style="margin-left: 1em">鉅典也其小板原係遠人自行刊刻所有缺畧不堪者</span>  
<span style="margin-left: 3em">遠人自能修補可以仍供推算之用赤不因其憊</span>  
<span style="margin-left: 3em">壞始議另行翻譯以溷珍藏况充棟之板未昜搬</span>  
<span style="margin-left: 3em">送查閱即欲另刊官様大字板片去繁就簡約有</span>  
<span style="margin-left: 3em">一千餘塊謹將小樣書表刷印數葉附</span>  
<span style="margin-left: 3em">覧便知其詳至於測驗儀器向經承造黃赤星球</span>  
<span style="margin-left: 3em">二種費止有千餘金今益地平經緯全儀論工價</span>  
<span style="margin-left: 3em">約增十分之五總之俱屬創製精工造完始見勸</span>  
<span style="margin-left: 3em">輸念切原不欲耑請錢粮其他一切物料板片工</span>  
<span style="margin-left: 3em">價等項自應隨時斟酌務求節省似難預爲臆度</span>  
<span style="margin-left: 3em">懸擬者也合用手本回覆前去</span>

<span style="margin-left: 3em">業蒙</span>
