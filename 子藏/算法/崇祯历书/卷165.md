<span style="margin-left: 3em">浑天仪制度</span>  
<span style="margin-left: 1em">仪中诸圈宜合天上相应之圈而相合必有定处大小</span>  
<span style="margin-left: 2em">皆如法乃始成一浑仪也但前以所分之仪平与不</span>  
<span style="margin-left: 2em">平定图大小之异今则不然而以能合一器各不失</span>  
<span style="margin-left: 2em">乎应天之理者为则因有三圈内外相等为赤道及</span>  
<span style="margin-left: 2em">两过极圈又有二圈内等而外异为子午及地平圈</span>  
<span style="margin-left: 2em">又二圈外等而内异为太阴本圈及过罗计以从黄</span>  
<span style="margin-left: 2em">极之小圈余则各不等各依本仪大小定度焉</span>  
<span style="margin-left: 3em">制内外等圈</span>  
<span style="margin-left: 1em">论过极圈为浑仪之脊骨须先从此圈制起而诸圈依</span>  
<span style="margin-left: 2em">之可定任用银或铜制二圈为匾形各厚约半分<sub class="note-yuan">此就</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">径过六七寸者论耳其余以仪大小为度后倣此</sub>阔约二分<sub class="note-yuan">以其上能刻度与字为则</sub>大</span>  
<span style="margin-left: 2em">小任意两面磨之使光复如法圈之安于铜板上<sub class="note-yuan">小銲</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">銲住</sub>以求中心随用规器齐其内外之周边并于面上</span>  
<span style="margin-left: 2em">作圈线以别度与字之间处必于刻度处缩之刻字</span>  
<span style="margin-left: 2em">处宽之乃度居外而字居内也其度数每面为三百</span>  
<span style="margin-left: 2em">六十至五线稍引长至十其线径过圈面而字乃识</span>  
<span style="margin-left: 2em">度之数者从正对之二处起至九十度于正对之二</span>  
<span style="margin-left: 2em">处止乃初界为赤道交二圈之限末界其二圈自相</span>  
<span style="margin-left: 2em">交之点因以定南北极焉须各圈以两面度及字彼</span>  
<span style="margin-left: 2em">此准对而两圈尤以诸面皆等为务<sub class="note-yuan">诸圈当磨之使光乃复齐之使</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">平刻度等皆倣此</sub>圈制矣必以十字直角交之使合法于止</span>  
<span style="margin-left: 2em">数正对之界圈各开小方孔其孔较圈面有半一内</span>  
<span style="margin-left: 2em">一外若公母笋者然乃用铜成二圆条厚分半余长</span>  
<span style="margin-left: 2em">五六分一大端开十字方孔以受二圈之交点一小</span>  
<span style="margin-left: 2em">端不令开孔少锐之便入子午圈以当仪枢复于二</span>  
<span style="margin-left: 2em">圈各起数正对之界与赤道圈如前法各开半孔直</span>  
<span style="margin-left: 2em">角相交以为总合之处如图甲乙为二圈相交之地</span>  
<span style="margin-left: 2em">加丙丁各条利其坚且当天枢故向内开孔以受仪</span>  
<span style="margin-left: 2em">枢向外小锐以入子午圈中为南北极戊己庚辛皆</span>  
<span style="margin-left: 13em">圈腰之孔皆距极等乃</span>  
<span style="margin-left: 13em">所以受赤道圈者盖二</span>  
<span style="margin-left: 13em">圈既交必少制之使不</span>  
<span style="margin-left: 13em">紧便于入赤道圈矣随</span>  
<span style="margin-left: 13em">从二圈相交之点任于</span>  
<span style="margin-left: 13em">一圈上数二十三度半</span>  
<span style="margin-left: 13em">其正相对处皆等复用</span>  
<span style="margin-left: 13em">二铜条一端开小孔少</span>  
<span style="margin-left: 2em">许入其处一端向内任意长短又开一小孔备以受</span>  
<span style="margin-left: 2em">月本圈者<sub class="note-yuan">如前图壬癸皆指铜条小孔自显于壬</sub>即月圈本极可当黄</span>  
<span style="margin-left: 2em">道极乃其圈必为过冬夏二至之圈</span>  
<span style="margin-left: 2em">赤道圈周分三百六十度二面俱等顺书其数亦二</span>  
<span style="margin-left: 2em">面同乃初度与九十度及一百八十度与二百七十</span>  
<span style="margin-left: 2em">度皆应开孔则初度与一百八十度所交之圈必为</span>  
<span style="margin-left: 2em">定春秋二分过极圈九十度与二百七十度为限冬</span>  
<span style="margin-left: 2em">夏二至过极圈之交界盖春分得初度右行九十度</span>  
<span style="margin-left: 2em">为夏至递而秋分而冬至至三百六十度止渐又至</span>  
<span style="margin-left: 2em">春分矣即此可以查升度其制法与制二圈同内外</span>  
<span style="margin-left: 2em">周边以规器齐之各面以圈线分度与字度居外字</span>  
<span style="margin-left: 2em">居内皆如前圈图可不赘</span>  
<span style="margin-left: 3em">制内等外不等圈</span>  
<span style="margin-left: 1em">论子午及地平圈内周边之齐同较前三圈约宽一分</span>  
<span style="margin-left: 2em">盖安高弧与时盘必使诸圈利于旋转势不得不少</span>  
<span style="margin-left: 2em">处其盈也且分四象限以九十度正对之合处为止</span>  
<span style="margin-left: 2em">而度反居内字反居外其子午圈之两面度数同地</span>  
<span style="margin-left: 2em">平独用一面惟度数外更增以时与刻故较子午必</span>  
<span style="margin-left: 2em">倍其体也今详各圈之所异子午为诸圈所倚较他</span>  
<span style="margin-left: 2em">圈独厚乃取其坚而濶与之等或微过焉其一面于</span>  
<span style="margin-left: 2em">度数初起处各加一铜耳以便于受天枢因枢左右</span>  
<span style="margin-left: 2em">有钉或螺旋转安于圈面故如图甲乙为各数初起</span>  
<span style="margin-left: 10em">之界并为南北二极而丙丁正</span>  
<span style="margin-left: 10em">对处则各满一象限乃正戊己</span>  
<span style="margin-left: 10em">及壬辛为铜耳长尽于安钉濶</span>  
<span style="margin-left: 10em">止于圈面之半厚以与圈能开</span>  
<span style="margin-left: 10em">孔容天枢为则故本面当仪之</span>  
<span style="margin-left: 10em">正中临用时或安高弧或就时</span>  
<span style="margin-left: 2em">盘定时皆以此面为界前卷所谓子午圈正面是也</span>  
<span style="margin-left: 2em">地平或安于木架上厚薄不拘独下面用三四铜钉</span>  
<span style="margin-left: 2em">透入木中使之固且令不随子午圈起动焉或不用</span>  
<span style="margin-left: 2em">木架而用铜架止令数处倚于铜柱亦可自立其子</span>  
<span style="margin-left: 12em">午正对处各开一口深与</span>  
<span style="margin-left: 12em">子午圈及铜耳之濶等宽</span>  
<span style="margin-left: 12em">如其圈与铜耳之厚取其</span>  
<span style="margin-left: 12em">便于高下出入已耳如图</span>  
<span style="margin-left: 12em">内层分三百六十度为四</span>  
<span style="margin-left: 12em">象限每象限各九十度外</span>  
<span style="margin-left: 12em">层周分刻数并十二大时</span>  
<span style="margin-left: 12em">乃午在南子在北甲乙其</span>  
<span style="margin-left: 2em">口也宽窄之势以紧容子午圈及铜耳为度而子午</span>  
<span style="margin-left: 2em">圈之面则又平分地平居浑仪之中焉</span>  
<span style="margin-left: 3em">制外等内不等圈</span>  
<span style="margin-left: 1em">因太阴本圈用以显交食者故体势稍小居仪之中距</span>  
<span style="margin-left: 2em">日约远应随浑仪旋转又能依左右那动乃代月轮</span>  
<span style="margin-left: 2em">从黄道并出黄道内外者必更借一轮与之等以支</span>  
<span style="margin-left: 2em">之法本轮两面皆无度数独以十字平分为四界即</span>  
<span style="margin-left: 2em">于正相对二界上各安铜条外出少许各条于末端</span>  
<span style="margin-left: 2em">少锐用以入黄极所出二铜条中即安于前所云过</span>  
<span style="margin-left: 2em">冬夏二至之圈者复于彼二界向内斜开小孔深入</span>  
<span style="margin-left: 2em">圈面之半以其能受月轮圈且得出入黄道内外其</span>  
<span style="margin-left: 2em">太阴圈外周与前圈等齐内周畧濶为其另加竖圈</span>  
<span style="margin-left: 2em">为月轮所附以旋转者亦无度数独一面分四界为</span>  
<span style="margin-left: 2em">正中二交阴阳二历之限故于交处外开小孔与前</span>  
<span style="margin-left: 2em">圈斜孔相交加以铜结入圈其中以固之从交处向</span>  
<span style="margin-left: 2em">左因其圈偏内即以所交为正交内半圈皆阴历从</span>  
<span style="margin-left: 9em">此而圈复偏外即以所交为中交</span>  
<span style="margin-left: 9em">外半圈皆阳历如图甲乙丙丁为</span>  
<span style="margin-left: 9em">所借圈于正对处载铜条为乙丁</span>  
<span style="margin-left: 9em">乙处少锐应入南黄极丁之锐入</span>  
<span style="margin-left: 9em">北黄极即月本轮随之转因以得</span>  
<span style="margin-left: 9em">阴阳历黄道内外者是其甲丙相</span>  
<span style="margin-left: 2em">交处<sub class="note-yuan">一正一中</sub>必居黄道正下使月可得南北纬度其加</span>  
<span style="margin-left: 2em">戊己二结者以总合二圈故也庚辛为太阴本圈载</span>  
<span style="margin-left: 2em">前四限于其上<sub class="note-yuan">二交左右可识日月食限多寡须依法</sub>其内周加竖圈</span>  
<span style="margin-left: 7em">为壬癸周约等濶半分余即月轮所倚</span>  
<span style="margin-left: 7em">以旋转者其南黄极于甲乙丙丁圈内</span>  
<span style="margin-left: 2em">出小表为子表末正向阴历限为太阴本圈之中心</span>  
<span style="margin-left: 2em">乃开小圆孔内载一铜弧如弓形以此弧之一末安</span>  
<span style="margin-left: 2em">其心一末带月转如上图甲为入心之钩乙即附于</span>  
<span style="margin-left: 2em">竖圈之背使月轮自倚其正面以旋动然未安赤道</span>  
<span style="margin-left: 2em">之前不可不预备此免后安置之烦耳</span>  
<span style="margin-left: 3em">制内外不等圈</span>  
<span style="margin-left: 1em">全不等圈者即黄道高弧及时圈是小大形势各不一</span>  
<span style="margin-left: 2em">盖黄道有二一在外围仪周为匾圈任宽十二或十</span>  
<span style="margin-left: 2em">六度虽总分三百六十度然复依十二宫为界其横</span>  
<span style="margin-left: 2em">线每三十度为一宫限引长之为全线每十五度为</span>  
<span style="margin-left: 2em">一节亦引半线以别之度分细界于中一边书节气</span>  
<span style="margin-left: 2em">一边书二十八宿各以本度得节气而宫名可免矣</span>  
<span style="margin-left: 2em">一在内制与赤道及余圈等独一面书度数各以三</span>  
<span style="margin-left: 2em">十度为限大小较他圈不等外边周与赤道及过极</span>  
<span style="margin-left: 2em">圈之内周等齐任于三十度正对之界开小口用以</span>  
<span style="margin-left: 2em">合乎过冬夏二至极圈所留之口内边周开一深圈</span>  
<span style="margin-left: 2em">即从南黄极中出铜弧如弓形其一末入枢心一末</span>  
<span style="margin-left: 2em">带日轮于深圈中转俱不异于月轮焉如图上圆形</span>  
<span style="margin-left: 11em">为黄道圈之正面甲乙为口</span>  
<span style="margin-left: 11em">丙为带日轮之弓形开小圆</span>  
<span style="margin-left: 11em">眼于丁加钩于戊乃戊钩在</span>  
<span style="margin-left: 11em">本圈之背日轮在前能对度</span>  
<span style="margin-left: 11em">数旋转其下长方形为黄道</span>  
<span style="margin-left: 11em">带之一方<sub class="note-yuan">举一以槩其余</sub>中线为太</span>  
<span style="margin-left: 2em">阳躔道左右刻度春秋二分迭易之以便观也先将</span>  
<span style="margin-left: 2em">内黄道圈如法安住<sub class="note-yuan">以其缝入内合之或钉或銲令刻度分者向北</sub>其外圈</span>  
<span style="margin-left: 2em"><sub class="note-yuan">黄道匾圈</sub>务令春秋分准合过极圈之中以与赤道交夏</span>  
<span style="margin-left: 2em">至则过赤道北<sub class="note-yuan">在内</sub>而冬至则又过赤道南<sub class="note-yuan">在外</sub>其点亦</span>  
<span style="margin-left: 2em">与极圈合乃圈所应合之四界微开小孔以钉固之</span>

<span style="margin-left: 5em">合黄道之濶如法扣之使紧丙为弯形铜以</span>  
<span style="margin-left: 5em">冷制之得硬体安放进退如意</span>  
<span style="margin-left: 2em">高弧为匾圈四分之一以地平或子午圈之内边为</span>  
<span style="margin-left: 2em">长短之则宽取其能容度数及所刻字一端中开小</span>  
<span style="margin-left: 2em">孔以能抱合天顶不脱一端加一小足度数外复余</span>  
<span style="margin-left: 2em">少许能入地平初度之下如笋之有所受者然其书</span>  
<span style="margin-left: 11em">度分从下而上如图甲为上</span>  
<span style="margin-left: 11em">口度末齐子午面乙为小足</span>  
<span style="margin-left: 11em">初度倚地平余入其下但天</span>  
<span style="margin-left: 2em">顶与高弧全依北极出地度安置故更有天顶为丙</span>  
<span style="margin-left: 2em">中开一长方口以入子午圈下留小钉为戊安住高</span>
