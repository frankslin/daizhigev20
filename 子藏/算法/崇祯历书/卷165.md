<span style="margin-left: 1em"><sub class="note-yuan">　　　　　　　　　　　　　　　　　　　　朱光大孫有本</sub></span>  
<span style="margin-left: 3em">渾天儀製度</span>  
<span style="margin-left: 1em">儀中諸圈宜合天上相應之圈而相合必有定處大小</span>  
<span style="margin-left: 2em">皆如法乃始成一渾儀也但前以所分之儀平與不</span>  
<span style="margin-left: 2em">平定圖大小之異今則不然而以能合一器各不失</span>  
<span style="margin-left: 2em">乎應天之理者爲則因有三圈內外相等爲赤道及</span>  
<span style="margin-left: 2em">兩過極圈又有二圈內等而外異爲子午及地平圈</span>  
<span style="margin-left: 2em">又二圈外等而內異爲太陰本圈及過羅計以從黃</span>  
<span style="margin-left: 2em">極之小圈餘則各不等各依本儀大小定度焉</span>  
<span style="margin-left: 3em">製內外等圈</span>  
<span style="margin-left: 1em">論過極圈爲渾儀之脊骨須先從此圈製起而諸圈依</span>  
<span style="margin-left: 2em">之可定任用銀或銅製二圈爲匾形各厚約半分<sub class="note-yuan">此就</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">徑過六七寸者論耳其餘以儀大小爲度後倣此</sub>闊約二分<sub class="note-yuan">以其上能刻度與字爲則</sub>大</span>  
<span style="margin-left: 2em">小任意兩面磨之使光復如法圈之安于銅板上<sub class="note-yuan">小銲</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">銲住</sub>以求中心隨用規器齊其內外之周邊並於面上</span>  
<span style="margin-left: 2em">作圈線以別度與字之間處必于刻度處縮之刻字</span>  
<span style="margin-left: 2em">處寬之乃度居外而字居內也其度數每面爲三百</span>  
<span style="margin-left: 2em">六十至五線稍引長至十其線徑過圈面而字乃識</span>  
<span style="margin-left: 2em">度之數者從正對之二處起至九十度于正對之二</span>  
<span style="margin-left: 2em">處止乃初界爲赤道交二圈之限末界其二圈自相</span>  
<span style="margin-left: 2em">交之點因以定南北極焉須各圈以兩面度及字彼</span>  
<span style="margin-left: 2em">此準對而兩圈尤以諸面皆等爲務<sub class="note-yuan">諸圈當磨之使光乃復齊之使</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">平刻度等皆倣此</sub>圈製矣必以十字直角交之使合法于止</span>  
<span style="margin-left: 2em">數正對之界圈各開小方孔其孔較圈面有半一內</span>  
<span style="margin-left: 2em">一外若公母筍者然乃用銅成二圓條厚分半餘長</span>  
<span style="margin-left: 2em">五六分一大端開十字方孔以受二圈之交點一小</span>  
<span style="margin-left: 2em">端不令開孔少銳之便入子午圈以當儀樞復于二</span>  
<span style="margin-left: 2em">圈各起數正對之界與赤道圈如前法各開半孔直</span>  
<span style="margin-left: 2em">角相交以爲總合之處如圖甲乙爲二圈相交之地</span>  
<span style="margin-left: 2em">加丙丁各條利其堅且當天樞故向內開孔以受儀</span>  
<span style="margin-left: 2em">樞向外小銳以入子午圈中爲南北極戊己庚辛皆</span>  
<span style="margin-left: 13em">圈腰之孔皆距極等乃</span>  
<span style="margin-left: 13em">所以受赤道圈者蓋二</span>  
<span style="margin-left: 13em">圈既交必少制之使不</span>  
<span style="margin-left: 13em">緊便于入赤道圈矣隨</span>  
<span style="margin-left: 13em">從二圈相交之點任于</span>  
<span style="margin-left: 13em">一圈上數二十三度半</span>  
<span style="margin-left: 13em">其正相對處皆等復用</span>  
<span style="margin-left: 13em">二銅條一端開小孔少</span>  
<span style="margin-left: 2em">許入其處一端向內任意長短又開一小孔備以受</span>  
<span style="margin-left: 2em">月本圈者<sub class="note-yuan">如前圖壬癸皆指銅條小孔自顯于壬</sub>即月圈本極可當黃</span>  
<span style="margin-left: 2em">道極乃其圈必爲過冬夏二至之圈</span>  
<span style="margin-left: 2em">赤道圈周分三百六十度二面俱等順書其數亦二</span>  
<span style="margin-left: 2em">面同乃初度與九十度及一百八十度與二百七十</span>  
<span style="margin-left: 2em">度皆應開孔則初度與一百八十度所交之圈必爲</span>  
<span style="margin-left: 2em">定春秋二分過極圈九十度與二百七十度爲限冬</span>  
<span style="margin-left: 2em">夏二至過極圈之交界蓋春分得初度右行九十度</span>  
<span style="margin-left: 2em">爲夏至遞而秋分而冬至至三百六十度止漸又至</span>  
<span style="margin-left: 2em">春分矣即此可以查升度其製法與製二圈同內外</span>  
<span style="margin-left: 2em">周邊以規器齊之各面以圈線分度與字度居外字</span>  
<span style="margin-left: 2em">居內皆如前圈圖可不贅</span>  
<span style="margin-left: 3em">製內等外不等圈</span>  
<span style="margin-left: 1em">論子午及地平圈內周邊之齊同較前三圈約寬一分</span>  
<span style="margin-left: 2em">蓋安高弧與時盤必使諸圈利于旋轉勢不得不少</span>  
<span style="margin-left: 2em">處其盈也且分四象限以九十度正對之合處爲止</span>  
<span style="margin-left: 2em">而度反居內字反居外其子午圈之兩面度數同地</span>  
<span style="margin-left: 2em">平獨用一面惟度數外更增以時與刻故較子午必</span>  
<span style="margin-left: 2em">倍其體也今詳各圈之所異子午爲諸圈所倚較他</span>  
<span style="margin-left: 2em">圈獨厚乃取其堅而濶與之等或微過焉其一面于</span>  
<span style="margin-left: 2em">度數初起處各加一銅耳以便于受天樞因樞左右</span>  
<span style="margin-left: 2em">有釘或螺旋轉安于圈面故如圖甲乙爲各數初起</span>  
<span style="margin-left: 10em">之界并爲南北二極而丙丁正</span>  
<span style="margin-left: 10em">對處則各滿一象限乃正戊己</span>  
<span style="margin-left: 10em">及壬辛爲銅耳長盡于安釘濶</span>  
<span style="margin-left: 10em">止于圈面之半厚以與圈能開</span>  
<span style="margin-left: 10em">孔容天樞爲則故本面當儀之</span>  
<span style="margin-left: 10em">正中臨用時或安高弧或就時</span>  
<span style="margin-left: 2em">盤定時皆以此面爲界前卷所謂子午圈正面是也</span>  
<span style="margin-left: 2em">地平或安于木架上厚薄不拘獨下面用三四銅釘</span>  
<span style="margin-left: 2em">透入木中使之固且令不隨子午圈起動焉或不用</span>  
<span style="margin-left: 2em">木架而用銅架止令數處倚于銅柱亦可自立其子</span>  
<span style="margin-left: 12em">午正對處各開一口深與</span>  
<span style="margin-left: 12em">子午圈及銅耳之濶等寬</span>  
<span style="margin-left: 12em">如其圈與銅耳之厚取其</span>  
<span style="margin-left: 12em">便于高下出入已耳如圖</span>  
<span style="margin-left: 12em">內層分三百六十度爲四</span>  
<span style="margin-left: 12em">象限每象限各九十度外</span>  
<span style="margin-left: 12em">層周分刻數並十二大時</span>  
<span style="margin-left: 12em">乃午在南子在北甲乙其</span>  
<span style="margin-left: 2em">口也寬窄之勢以緊容子午圈及銅耳爲度而子午</span>  
<span style="margin-left: 2em">圈之面則又平分地平居渾儀之中焉</span>  
<span style="margin-left: 3em">製外等內不等圈</span>  
<span style="margin-left: 1em">因太陰本圈用以顯交食者故體勢稍小居儀之中距</span>  
<span style="margin-left: 2em">日約遠應隨渾儀旋轉又能依左右那動乃代月輪</span>  
<span style="margin-left: 2em">從黃道并出黃道內外者必更借一輪與之等以支</span>  
<span style="margin-left: 2em">之法本輪兩面皆無度數獨以十字平分爲四界即</span>  
<span style="margin-left: 2em">于正相對二界上各安銅條外出少許各條于末端</span>  
<span style="margin-left: 2em">少銳用以入黃極所出二銅條中即安于前所云過</span>  
<span style="margin-left: 2em">冬夏二至之圈者復于彼二界向內斜開小孔深入</span>  
<span style="margin-left: 2em">圈面之半以其能受月輪圈且得出入黃道內外其</span>  
<span style="margin-left: 2em">太陰圈外周與前圈等齊內周畧濶爲其另加竪圈</span>  
<span style="margin-left: 2em">爲月輪所附以旋轉者亦無度數獨一面分四界爲</span>  
<span style="margin-left: 2em">正中二交陰陽二曆之限故于交處外開小孔與前</span>  
<span style="margin-left: 2em">圈斜孔相交加以銅結入圈其中以固之從交處向</span>  
<span style="margin-left: 2em">左因其圈偏內即以所交爲正交內半圈皆陰曆從</span>  
<span style="margin-left: 9em">此而圈復偏外即以所交爲中交</span>  
<span style="margin-left: 9em">外半圈皆陽曆如圖甲乙丙丁爲</span>  
<span style="margin-left: 9em">所借圈于正對處載銅條爲乙丁</span>  
<span style="margin-left: 9em">乙處少銳應入南黃極丁之銳入</span>  
<span style="margin-left: 9em">北黃極即月本輪隨之轉因以得</span>  
<span style="margin-left: 9em">陰陽曆黃道內外者是其甲丙相</span>  
<span style="margin-left: 2em">交處<sub class="note-yuan">一正一中</sub>必居黃道正下使月可得南北緯度其加</span>  
<span style="margin-left: 2em">戊己二結者以總合二圈故也庚辛爲太陰本圈載</span>  
<span style="margin-left: 2em">前四限于其上<sub class="note-yuan">二交左右可識日月食限多寡須依法</sub>其內周加竪圈</span>  
<span style="margin-left: 7em">爲壬癸周約等濶半分餘即月輪所倚</span>  
<span style="margin-left: 7em">以旋轉者其南黃極于甲乙丙丁圈內</span>  
<span style="margin-left: 2em">出小表爲子表末正向陰曆限爲太陰本圈之中心</span>  
<span style="margin-left: 2em">乃開小圓孔內載一銅弧如弓形以此弧之一末安</span>  
<span style="margin-left: 2em">其心一末帶月轉如上圖甲爲入心之鈎乙即附于</span>  
<span style="margin-left: 2em">竪圈之背使月輪自倚其正面以旋動然未安赤道</span>  
<span style="margin-left: 2em">之前不可不預備此免後安置之煩耳</span>  
<span style="margin-left: 3em">製內外不等圈</span>  
<span style="margin-left: 1em">全不等圈者即黃道高弧及時圈是小大形勢各不一</span>  
<span style="margin-left: 2em">蓋黃道有二一在外圍儀周爲匾圈任寬十二或十</span>  
<span style="margin-left: 2em">六度雖總分三百六十度然復依十二宮爲界其橫</span>  
<span style="margin-left: 2em">線每三十度爲一宮限引長之爲全線每十五度爲</span>  
<span style="margin-left: 2em">一節亦引半線以別之度分細界于中一邊書節氣</span>  
<span style="margin-left: 2em">一邊書二十八宿各以本度得節氣而宮名可免矣</span>  
<span style="margin-left: 2em">一在內製與赤道及餘圈等獨一面書度數各以三</span>  
<span style="margin-left: 2em">十度爲限大小較他圈不等外邊周與赤道及過極</span>  
<span style="margin-left: 2em">圈之內周等齊任于三十度正對之界開小口用以</span>  
<span style="margin-left: 2em">合乎過冬夏二至極圈所留之口內邊周開一深圈</span>  
<span style="margin-left: 2em">即從南黃極中出銅弧如弓形其一末入樞心一末</span>  
<span style="margin-left: 2em">帶日輪于深圈中轉俱不異于月輪焉如圖上圓形</span>  
<span style="margin-left: 11em">爲黃道圈之正面甲乙爲口</span>  
<span style="margin-left: 11em">丙爲帶日輪之弓形開小圓</span>  
<span style="margin-left: 11em">眼于丁加鈎于戊乃戊鈎在</span>  
<span style="margin-left: 11em">本圈之背日輪在前能對度</span>  
<span style="margin-left: 11em">數旋轉其下長方形爲黃道</span>  
<span style="margin-left: 11em">帶之一方<sub class="note-yuan">舉一以槩其餘</sub>中線爲太</span>  
<span style="margin-left: 2em">陽躔道左右刻度春秋二分迭易之以便觀也先將</span>  
<span style="margin-left: 2em">內黃道圈如法安住<sub class="note-yuan">以其縫入內合之或釘或銲令刻度分者向北</sub>其外圈</span>  
<span style="margin-left: 2em"><sub class="note-yuan">黃道匾圈</sub>務令春秋分準合過極圈之中以與赤道交夏</span>  
<span style="margin-left: 2em">至則過赤道北<sub class="note-yuan">在內</sub>而冬至則又過赤道南<sub class="note-yuan">在外</sub>其點亦</span>  
<span style="margin-left: 2em">與極圈合乃圈所應合之四界微開小孔以釘固之</span>  
<span style="margin-left: 2em">復依黃道外圈之濶更製小表爲測景表如圖甲乙</span>  
<span style="margin-left: 5em">合黃道之濶如法扣之使緊丙爲彎形銅以</span>  
<span style="margin-left: 5em">冷製之得硬體安放進退如意</span>  
<span style="margin-left: 2em">高弧爲匾圈四分之一以地平或子午圈之內邊爲</span>  
<span style="margin-left: 2em">長短之則寬取其能容度數及所刻字一端中開小</span>  
<span style="margin-left: 2em">孔以能抱合天頂不脫一端加一小足度數外復餘</span>  
<span style="margin-left: 2em">少許能入地平初度之下如筍之有所受者然其書</span>  
<span style="margin-left: 11em">度分從下而上如圖甲爲上</span>  
<span style="margin-left: 11em">口度末齊子午面乙爲小足</span>  
<span style="margin-left: 11em">初度倚地平餘入其下但天</span>  
<span style="margin-left: 2em">頂與高弧全依北極出地度安置故更有天頂爲丙</span>  
<span style="margin-left: 2em">中開一長方口以入子午圈下留小釘爲戊安住高</span>  
<span style="margin-left: 2em">弧其丁爲螺旋宜入丙孔定住子午圈可任游移用</span>  
<span style="margin-left: 2em">也時盤以銅爲實圓形其勢少拱取其與儀圓體相</span>  
<span style="margin-left: 2em">合中心緊抱北極之樞能隨諸圈轉亦能自轉其時</span>  
<span style="margin-left: 2em">刻自右而左書之盤周以之安于子午圈內而子午</span>  
<span style="margin-left: 2em">圈正面可當切時之表或時盤在子午圈外定住不</span>  
<span style="margin-left: 2em">移盤之上必須加一銅尺以指時刻其尺緊與樞抱</span>  
<span style="margin-left: 2em">能隨諸圈轉必能自轉與前盤同第盤周所分時刻</span>  
<span style="margin-left: 9em">從左而右與前盤異焉如圖甲乙</span>  
<span style="margin-left: 9em">爲時盤在子午圈內即丙丁爲子</span>  
<span style="margin-left: 9em">午圈能自切時刻戊己爲時盤在</span>  
<span style="margin-left: 2em">子午圈外樞端出中心爲庚辛爲時尺乃隨儀周轉</span>  
<span style="margin-left: 2em">以指南刻者</span>  
<span style="margin-left: 2em">以上諸圈如法合成隨安置于架中必使子午圈半</span>  
<span style="margin-left: 2em">在地平上半在下而負儀之柱長短務如法必先試</span>  
<span style="margin-left: 2em">之而後乃定住所開之孔亦與地平之孔等以其能</span>  
<span style="margin-left: 2em">凾子午圈及兩耳可游行不碍也架之下安指南針</span>  
<span style="margin-left: 2em">必線與子午圈正合或與之爲平行臨用時一與針</span>  
<span style="margin-left: 2em">對而本儀之南北得即東西可定矣</span>  
<span style="margin-left: 3em">製天地球十二長圓形法</span>  
<span style="margin-left: 1em">凡造渾球可任意大小界黃赤道等圈其上又依度數</span>  
<span style="margin-left: 2em">帶入諸星此元法也但其功甚難故別爲簡法先製</span>  
<span style="margin-left: 2em">星圖及地圖刊于平板以楮印之糊于球面必合因</span>  
<span style="margin-left: 2em">其圖形爲長圓設長直線以三十平分之從第一分</span>  
<span style="margin-left: 2em">爲心十一分爲界作弧漸次以往止于十二弧後復</span>  
<span style="margin-left: 2em">從下對前弧亦如前作十二弧得十二長圓形如前</span>  
<span style="margin-left: 2em">圖其中橫線應球上黃赤等道兩末至極中諸弧並</span>  
<span style="margin-left: 2em">其中順直線者皆應經圈令弧自得圓自能應其圈</span>  
<span style="margin-left: 2em">形獨中之直線較弧反短倘不伸之使長便不能至</span>  
<span style="margin-left: 2em">二極又或伸之使長必令球畧大中腰必寬即長圓</span>  
<span style="margin-left: 2em">形腰線亦應長矣故楮雖宜堅且耐終末得全合欲</span>  
<span style="margin-left: 2em">免楮闕更有捷法求小圈與大圈之比例以限長圓</span>  
<span style="margin-left: 2em">形之旁線大約線稍曲畧就中線而中線無伸長之</span>  
<span style="margin-left: 2em">患可易合法曰全數與小圈相距之餘弦如三百六</span>  
<span style="margin-left: 2em">十度與小圈全周或如九十度與小圈一象限或如</span>  
<span style="margin-left: 2em">一度與小圈一度之分秒得弧後餘數復以六十相</span>  
<span style="margin-left: 2em">乘以全數減得分數再乘再減即得秒數如求黃道</span>  
<span style="margin-left: 2em">一宮三十度應如距四十度小圈之弧乃距度之餘</span>  
<span style="margin-left: 2em">弦爲七六六〇四與三十相乘總數二二九八一二</span>  
<span style="margin-left: 2em">〇與全數相減得二十二度餘數與六十相乘總數</span>  
<span style="margin-left: 2em">五八八七二〇〇復與全數相減得五十八分今將</span>  
<span style="margin-left: 2em">球上三十度帶于比例尺百平分線上爲長圓形之</span>  
<span style="margin-left: 2em">腰線又使之與長直線以直角平分相交遂于比例</span>  
<span style="margin-left: 2em">尺約取二十三度帶腰線形左右于直線四十度之</span>  
<span style="margin-left: 2em">距界而各等圈弧依距度推求取于比例尺得直線</span>  
<span style="margin-left: 2em">兩旁曲線應過之界以成其長圓形</span>  
<span style="margin-left: 2em">或不必算即設直線得大圈與球徑之比例<sub class="note-yuan">一百五十七與</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">五十或三百一十四與一百皆約爲準</sub>爲甲乙十二平分之爲橫線以</span>  
<span style="margin-left: 2em">直角交大線之界乃于中線以丙爲心以最近左右</span>  
<span style="margin-left: 16em">橫線爲界作圓</span>  
<span style="margin-left: 16em">圈宜從丁戊平</span>  
<span style="margin-left: 16em">分每邊十二分</span>  
<span style="margin-left: 2em">而每正對點以直線相連使線過每止于本橫線如</span>  
<span style="margin-left: 2em">圖蓋從甲丁乙甲戊乙依其交點兩旁過曲線必爲</span>  
<span style="margin-left: 2em">長圓形準與球面合即得之矣隨以楮殻或銅木等</span>  
<span style="margin-left: 2em">板依之裁製一長圓形皆以中橫線正對爲黃赤道</span>  
<span style="margin-left: 2em">線臨點星畫地圖時分黃赤道三百六十度以定經</span>  
<span style="margin-left: 2em">長圓形任一邊分一百八十度以定緯<sub class="note-yuan">球製已以于子午圈定緯</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">因以點星盡地圖用虛緯度亦足</sub>其十二星圖等圓形皆以中橫線</span>  
<span style="margin-left: 2em">爲黃道以兩末爲南北各黃極因諸星依黃經緯度</span>  
<span style="margin-left: 2em">點入故橫線內外各引赤道及冬夏至等線而赤道</span>  
<span style="margin-left: 2em">獨分爲度餘皆依本緯相距總于球上合爲圓圈也</span>  
<span style="margin-left: 2em">地圖亦分十二形但中橫線指赤道分爲度餘內外</span>  
<span style="margin-left: 2em">線即冬夏二至南北兩極圈各于本緯取定也其每</span>  
<span style="margin-left: 2em">距十度橫過線者乃與赤道平行線而過赤道線每</span>  
<span style="margin-left: 2em">距十度至二極中點復合者爲經度線其中能量各</span>  
<span style="margin-left: 2em">處東西之距且可較赤道上度因得各處實度化之</span>  
<span style="margin-left: 2em">爲里又于十二點<sub class="note-yuan">赤道上四點赤道內外相距等各又爲四點</sub>出彎線各</span>  
<span style="margin-left: 2em">三十二以定方向者乃用以分舟行海上之道耳今</span>  
<span style="margin-left: 2em">總天地各球十二等形如左</span>  
<span style="margin-left: 3em">天地各球十二長圓形圖</span>  
<span style="margin-left: 2em">因前圖未盡圓形至二極中尚差十度故復以此圓</span>  
<span style="margin-left: 2em">圈補之各以十二平分而中心當極可合前圖成圓</span>  
<span style="margin-left: 2em">球也臨糊時先從此圈始次將長圖各于相應之界</span>  
<span style="margin-left: 2em">連接之<sub class="note-yuan">法詳之後篇</sub>球製已完必地平子午圈高弧及時</span>  
<span style="margin-left: 2em">盤指南針等與渾儀同乃可以全球之用但前圖大</span>  
<span style="margin-left: 2em">小有定則而子午地平必依其則以爲徑今定其式</span>  
<span style="margin-left: 2em">如左與圈內周之邊等即球與圈相問之空俱在算</span>  
<span style="margin-left: 2em">內而天地球圈同一式矣</span>  
<span style="margin-left: 3em">製球法</span>  
<span style="margin-left: 1em">球之製全取其準與便準則必貴極圓以能合天載諸</span>  
<span style="margin-left: 2em">圈與度數相對便則以輕爲最體雖大尤宜易爲遷</span>  
<span style="margin-left: 2em">動設以銅爲之欲其薄且圓固不易製即用木體質</span>  
<span style="margin-left: 2em">渾實亦不便于移置莫若以木板數塊漸合成球繪</span>  
<span style="margin-left: 2em">天地等圖于其上或糊前長圓形亦可蓋球未合時</span>  
<span style="margin-left: 2em">內鑿之使空而已合後外得旋圓使之與圖符或用</span>  
<span style="margin-left: 2em">楮須預備一木模塗膏于上并用堅楮依前所備長</span>  
<span style="margin-left: 2em">圓形裁十二圓外有二小圈心宜通以抱模樞易于</span>  
<span style="margin-left: 2em">進乃自塗以膏餘十二圓必先漬以水兩末微糊圈</span>  
<span style="margin-left: 2em">上使其周盡圍模面次用楮裁圓形漸次合之以滿</span>  
<span style="margin-left: 2em">其體之厚爲度<sub class="note-yuan">厚一分餘</sub>乃更造一半圈任用銅或鐵與</span>  
<span style="margin-left: 2em">應製之球面等以爲驗圓之圈<sub class="note-yuan">以長圓圖之徑取正一面宜合樞之中心</sub></span>  
<span style="margin-left: 2em">安樞上而樞又自安于本架二竪柱上乃令球轉高</span>  
<span style="margin-left: 2em">者去之低者補之必漸得圓乃止也取球法先備其</span>  
<span style="margin-left: 2em">樞隨用兩木較球徑長數寸製爲方形其中起槽以</span>  
<span style="margin-left: 2em">藏銅絲爲球之極兩木已合自中左右量球內空之</span>  
<span style="margin-left: 2em">徑<sub class="note-yuan">以除球體之一倍得之</sub>于各界留結兩結間木以旋轉爲圓</span>  
<span style="margin-left: 2em">任厚若干于球未合之先安本樞即從外入小釘至</span>  
<span style="margin-left: 4em">兩結中定住球如圖甲乙爲樞之結相距與楮</span>  
<span style="margin-left: 4em">球內面等丙丁皆出球外之銳中凾銅絲乃球</span>  
<span style="margin-left: 4em">合後亦去之與面爲平欲取球即于架轉依驗</span>  
<span style="margin-left: 4em">圈之中線界球腰線以十二平分從第一至第</span>  
<span style="margin-left: 4em">七分界依驗圈面至兩極引線得正中分球次</span>  
<span style="margin-left: 4em">本線之左右各加平行線各距等依之切楮二</span>  
<span style="margin-left: 4em">三層復界中線又橫加數短線必于中線開球</span>  
<span style="margin-left: 4em">依橫線得合爲法球取矣遂于中安樞復合二</span>  
<span style="margin-left: 2em">半圓用膠封固之縫宜合之堅後轉球試樞居其中</span>  
<span style="margin-left: 2em">否乃隨窒之綰于內結務令球得均匀若少有偏即</span>  
<span style="margin-left: 2em">詳其輕處鑽小孔製一木螺絲轉如下</span>  
<span style="margin-left: 2em">圖以甲爲柄乙入球內有數小孔實鉛其中得平乃</span>  
<span style="margin-left: 2em">止其出球之柄亦去之與球面等焉</span>  
<span style="margin-left: 3em">上長圓圖于球面法</span>  
<span style="margin-left: 1em">欲上圖先于球面加以白楮安球于架依驗圈之中線</span>  
<span style="margin-left: 2em">復界腰線于上以爲赤道又分赤道爲四象限使于</span>  
<span style="margin-left: 2em">各界依驗圈面過線至兩極中以爲二分二至之極</span>  
<span style="margin-left: 2em">圈次下球于銅樞上貫以楮板如尺狀從樞心出直</span>  
<span style="margin-left: 2em">線使之順球至赤道上爲點乃自點至樞心分九十</span>  
<span style="margin-left: 2em">度裁其半依長圓形圖以赤或黃道爲腰線用楮尺</span>  
<span style="margin-left: 2em">先于球面爲線令與圖上之線相應如設赤道爲天</span>  
<span style="margin-left: 2em">中即依楮尺距各極二十三度半爲點以界兩極圈</span>  
<span style="margin-left: 2em">又距六十六度半爲點以界冬夏二至圈更分赤道</span>  
<span style="margin-left: 2em">爲十二界各界過線至兩極中合即得經圈并爲長</span>  
<span style="margin-left: 2em">圓形所依而上界如法黏合矣若設黃道爲天中即</span>  
<span style="margin-left: 2em">先依楮尺于二至經圈正對處點二十三度半爲黃</span>  
<span style="margin-left: 2em">道極後必用曲腰規器以黃極爲心以二分經圈交</span>  
<span style="margin-left: 2em">赤道爲界作圈得黃道又合規器任意多寡從各黃</span>  
<span style="margin-left: 2em">極爲圈得與黃道爲平行乃總應平分以爲十二長</span>  
<span style="margin-left: 2em">圓圖之界而皆取準于經圈也諸圈已分用楮尺依</span>  
<span style="margin-left: 2em">分界至黃極中引線兩線間得長圓形之界故將圖</span>  
<span style="margin-left: 2em">于周線中截之先將一半黏上後復合其餘半皆以</span>  
<span style="margin-left: 2em">其線合球上線者爲準而種種俱得法矣然天球或</span>  
<span style="margin-left: 2em">依前驗圈或依新安子午圈各宜界二十八宿線過</span>  
<span style="margin-left: 2em">本宿距星與前界經圈同但線不必至二極中正于</span>  
<span style="margin-left: 2em">恆見與恆不見之界圈可總之依本北極出地度取</span>  
<span style="margin-left: 2em">則而地球則無線可加也矣</span>  
<span style="margin-left: 3em">附黃赤全儀說</span>  
<span style="margin-left: 1em">全儀共有四圈一赤道圈一黃道圈其赤道圈正居天</span>  
<span style="margin-left: 2em">中一面分二十八宿各距宿度分一面分三百六十</span>  
<span style="margin-left: 2em">平度當天上經度而黃道則斜交赤道圈上兩相交</span>  
<span style="margin-left: 2em">處即春秋二分兩相距最遠界即冬夏二至圈上一</span>  
<span style="margin-left: 2em">面依本道分十二宮一面仍分二十八宿其各宿大</span>  
<span style="margin-left: 2em">小則依本黃極測定故異于赤道宿度矣次子午圈</span>  
<span style="margin-left: 2em">以直角交黃赤兩圈乃從赤道內外各分九十平度</span>  
<span style="margin-left: 2em">其距赤道最遠之界則爲南北兩極而極之兩端各</span>  
<span style="margin-left: 2em">出一鐵軸令全儀懸安其上以利旋轉焉三圈內又</span>  
<span style="margin-left: 2em">一圈爲定經度圈亦名測景圈或安赤極下依赤道</span>  
<span style="margin-left: 2em">旋或安黃極下依黃道旋乃任兩道公用者于赤極</span>  
<span style="margin-left: 2em">上另置一盤周分時刻曰時盤隨全儀運轉亦有時</span>  
<span style="margin-left: 2em">能自轉令正午與太陽躔度相對因以定時者復有</span>  
<span style="margin-left: 2em">一小表任游移兩道上一面開一長孔深入景圈而</span>  
<span style="margin-left: 2em">以螺旋定住一面所開孔較短而中有一銳尖以指</span>  
<span style="margin-left: 2em">度分</span>  
<span style="margin-left: 1em">儀架前後竪兩木柱而以全儀懸置其上其前柱之端</span>  
<span style="margin-left: 2em">出一銅弧分度數者乃約畧中華南北之廣依各北</span>  
<span style="margin-left: 2em">極出地數以上下其南極者如　京師北極出地四</span>  
<span style="margin-left: 2em">十度則南極度入地四十度廣東極南之地北極出</span>  
<span style="margin-left: 2em">地二十度則南極應入地二十度是以上至二十下</span>  
<span style="margin-left: 2em">至四十度也後柱端一銅表如手形者乃用以指時</span>  
<span style="margin-left: 2em">刻蓋隨全儀之遠近以爲進退者架之下有三螺旋</span>  
<span style="margin-left: 2em">則因前後或左右以起全架令與地平相準而復設</span>  
<span style="margin-left: 2em">一垂線以考之又設以羅針以定子午大槩爲測時</span>  
<span style="margin-left: 2em">計也</span>  
<span style="margin-left: 3em">安儀法</span>  
<span style="margin-left: 1em">凡測天之儀必以諸圈正對天上所設之圈令其似直</span>  
<span style="margin-left: 2em">者應直似橫者應橫乃可蓋日月經緯諸星本圈上</span>  
<span style="margin-left: 2em">所得度分乃天上實行度分也今本儀或測諸曜實</span>  
<span style="margin-left: 2em">行度分或測晝夜相當時刻必先以其圈與天上所</span>  
<span style="margin-left: 2em">設之圈取正而後徐議測法焉</span>  
<span style="margin-left: 1em">依本北極出地數起儀而以地平取準復以羅針取定</span>  
<span style="margin-left: 2em">子午向次用垂線于後柱之左右相較務令線與柱</span>  
<span style="margin-left: 2em">上下爲平行則全儀之東西正矣否則以後螺旋進</span>  
<span style="margin-left: 2em">退之蓋垂線遠于東者則架宜東起或西下遠于西</span>  
<span style="margin-left: 2em">者反是末以前螺旋于地平取正南北蓋懸垂線于</span>  
<span style="margin-left: 2em">子午圈本極出地度上令線下過正相對之度亦與</span>  
<span style="margin-left: 2em">上同如上在四十度下亦過四十度則地平之南北</span>  
<span style="margin-left: 2em">正矣否則又以前螺旋或出或入便可如法</span>  
<span style="margin-left: 1em">定子午線法用黃道正面上查本日太陽躔度移測景</span>  
<span style="margin-left: 2em">圈正居其下以表如法定住令全儀漸轉若得黃道</span>  
<span style="margin-left: 2em">圈與測景圈內並無日光則子午正矣如兩圈內不</span>  
<span style="margin-left: 2em">能并得景必稍那其架之前或後至兩圈內無光乃</span>  
<span style="margin-left: 2em">止</span>  
<span style="margin-left: 3em">用儀法</span>  
<span style="margin-left: 1em">測五緯宿度法從北極中出三線一線直過儀心以穿</span>  
<span style="margin-left: 2em">南極謂之內線餘二線俱從赤道上復合于南極謂</span>  
<span style="margin-left: 2em">之外線而遠近可任意游移者臨測時將外一線界</span>  
<span style="margin-left: 2em">定某宿初度令與內線并天上本宿距星相參直復</span>  
<span style="margin-left: 2em">移一線與所欲測之本緯星正對亦令其與內線共</span>  
<span style="margin-left: 2em">在一線上測兩星同見其間度即相距之實度而緯</span>  
<span style="margin-left: 2em">星所在之宮度即本星赤道上宿度若欲依黃道測</span>  
<span style="margin-left: 2em">之則移景圈與線于黃極下法與赤道同所得度即</span>  
<span style="margin-left: 2em">黃道宿度</span>  
<span style="margin-left: 1em">測恆星相距度法用二十八宿距星以外一線安本宿</span>  
<span style="margin-left: 2em">初度以一線正對當測之星俱取與內線相參直或</span>  
<span style="margin-left: 2em">另測儀所未載之恆星須先查恆星經緯表依本經</span>  
<span style="margin-left: 2em">度識之本圈上測時移線于所識處即因以同測他</span>  
<span style="margin-left: 2em">星必兩線中得兩星依本道相距之經度<sub class="note-yuan">黃赤同一法</sub></span>  
<span style="margin-left: 1em">測星黃經度依常法以恆星求經緯諸星經度即可得</span>  
<span style="margin-left: 2em">其恆星所居今恆星有本行較黃道終古如一而較</span>  
<span style="margin-left: 2em">赤道不能爲一欲求其實處必從太陽躔度可定法</span>  
<span style="margin-left: 2em">安景圈于黃極下對定太陽本日躔度于日未出之</span>  
<span style="margin-left: 2em">先任取一恆星<sub class="note-yuan">測五星不異</sub>測其與太陰或太白相距若</span>  
<span style="margin-left: 2em">千度候太陽出地平上轉儀正對令黃道圈與景圈</span>  
<span style="margin-left: 2em">內無日光乃止而復測太白得其距太陽度與前所</span>  
<span style="margin-left: 2em">測兩星之距度相加即本星距太陽黃經度或日未</span>  
<span style="margin-left: 2em">入之先依此法先與太白同測太陽後以太白并測</span>  
<span style="margin-left: 2em">恆星終亦得恆星距太陽度則其本黃道經度也</span>  
<span style="margin-left: 1em">測星赤經度法移景圈安本赤極下或晨測夕測俱與</span>  
<span style="margin-left: 2em">前同第景圈既正交赤道即于黃道爲斜絡不能實</span>  
<span style="margin-left: 2em">指兩道相當之度須先查升度表以黃道度取赤道</span>  
<span style="margin-left: 2em">上相應度依之安表于本赤道上如前法測之即得</span>  
<span style="margin-left: 2em">本赤道經度如測星赤緯度從春分點中出二線一</span>  
<span style="margin-left: 2em">線直過儀心以穿秋分點可當內線一線從子午圈</span>  
<span style="margin-left: 2em">上過復合于內線之元點可當外線遠近任意游移</span>  
<span style="margin-left: 2em">臨測時亦如測赤經度法將外一線那對所欲測之</span>  
<span style="margin-left: 2em">星亦令其與內線相參直從子午圈上視其距赤道</span>  
<span style="margin-left: 2em">南北度即得星緯南北若干度</span>  
<span style="margin-left: 1em">測太陽定時法先查太陽本日赤道度<sub class="note-yuan">用升度表求之</sub>約爲景</span>  
<span style="margin-left: 2em">圈對黃道本度所指轉時盤午正與景圈相對後轉</span>  
<span style="margin-left: 2em">全儀至黃景二圈內無光則後指所指即本時刻如</span>  
<span style="margin-left: 2em">未安景圈先以外線在赤道太陽本度對時盤午正</span>  
<span style="margin-left: 2em">即午正線後以目窺之必得線過赤道南者或在北</span>  
<span style="margin-left: 2em">者及午正者皆合一線則準而時刻亦依前法求之</span>  
<span style="margin-left: 2em">乃得</span>  
<span style="margin-left: 1em">測恆星定時法先對時盤于太陽相應赤道本度皆與</span>  
<span style="margin-left: 2em">前同後任用二十八宿距星即以外線定本宿初度</span>  
<span style="margin-left: 2em">或別用大星須先查本星赤經度識之本圈以定線</span>  
<span style="margin-left: 2em">臨測轉全儀令內外兩線與本星及人目相參直則</span>  
<span style="margin-left: 2em">後指所指時刻即本時刻</span>  
<span style="margin-left: 1em">測交食凡交食有三端可測一爲食之時其法與晝夜</span>  
<span style="margin-left: 2em">測時無異第月食時或夜有微雲星體不顯乃以測</span>  
<span style="margin-left: 2em">月爲法必先安景圈于太陽實度并對時盤午正臨</span>  
<span style="margin-left: 2em">測時以太陽所正衝景圈用以窺月體令內線與外</span>  
<span style="margin-left: 2em">線參直則後指所指時刻即食甚時刻可合天若初</span>  
<span style="margin-left: 2em">虧復圓因太陰先未正對太陽或後已過彼此約差</span>  
<span style="margin-left: 2em">半度<sub class="note-yuan">東行之度</sub>化爲時得二三分則先減後加于見測之</span>  
<span style="margin-left: 2em">時亦可合天一爲食之分別有本儀此不論一爲方</span>  
<span style="margin-left: 2em">位因人目不能正對太陽故止于測月食以黃道圈</span>  
<span style="margin-left: 2em">及景圈取法蓋太陰當食時恆在黃道或黃道內外</span>  
<span style="margin-left: 2em">相近處今儀器既與天合則諸圈亦合天上之圈惟</span>  
<span style="margin-left: 2em">順黃道及景圈窺太陰缺光之邊則以二圈所向與</span>  
<span style="margin-left: 2em">月虧之邊相較即可得其方位矣</span>  
<span style="margin-left: 1em">測北極出地高法用羅經或別求定子午線以正本儀</span>  
<span style="margin-left: 2em">之南北次安景圈與太陽依赤道所算度分正對而</span>  
<span style="margin-left: 2em">前漸起儀令黃道圈與景圈皆無日光隨以螺旋定</span>  
<span style="margin-left: 2em">住則即前極高弧上得本地北極高度或以垂線于</span>  
<span style="margin-left: 2em">子午圈上下所得相應之度即本方極高度</span>  
<span style="margin-left: 1em">若以本儀製日晷先如法安儀令子午圈竪立合天<sub class="note-yuan">以垂</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">線考正是</sub>時盤上之午正與本圈對準後將白紙一幅依</span>  
<span style="margin-left: 2em">當製之晷或立或倒或在儀左右安之使從赤道上</span>  
<span style="margin-left: 2em">每三度四十五分出線至本紙上所得點引長之爲</span>  
<span style="margin-left: 2em">時刻線假如欲製地平晷必安紙在儀下與地平面</span>  
<span style="margin-left: 2em">平行即順赤道側以目下視引線至紙上作識或用</span>  
<span style="margin-left: 2em">二三點連之得直線乃赤道線依本線從子午圈交</span>  
<span style="margin-left: 2em">赤道角上下正視之得點爲午正處次轉儀任時盤</span>  
<span style="margin-left: 2em">所行一刻二刻以至于盡亦如前作識<sub class="note-yuan">依時盤刻數與依赤道度</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">同覺此更簡便</sub>得午前或午後一邊之時刻線則他邊之刻</span>  
<span style="margin-left: 2em">數等其相距亦與之等次求晷之心以引其時刻線</span>  
<span style="margin-left: 2em">立表法當于時之距午遠者任指一刻作識隨于赤</span>  
<span style="margin-left: 2em">道往南較遠者順切子午圈視下紙作識從本刻引</span>  
<span style="margin-left: 2em">線過此又從午正引與赤道以直角交之線至此其</span>  
<span style="margin-left: 2em">兩線交處即晷之心也若製立晷宜竪紙在儀後法</span>  
<span style="margin-left: 2em">與前同獨出線立表心當向北極後求之若製東西</span>  
<span style="margin-left: 2em">晷宜竪紙于正東或西法亦同但時刻線皆爲平行</span>  
<span style="margin-left: 2em">線而表則正居赤道卯酉線上其長短以四十五度</span>  
<span style="margin-left: 2em">之切線取規故恆自心至上或下十二刻量之爲止</span>  
<span style="margin-left: 2em">若諸偏晷即依偏度多寡安紙與前同一法其求心</span>  
<span style="margin-left: 2em">立表惟以目隨內線至極爲安表之地必斜出於晷</span>  
<span style="margin-left: 2em">面以當天樞是也總之偏地平晷倣正地平晷表作</span>  
<span style="margin-left: 2em">式偏立晷倣正立晷表作式各依或以北極或以赤</span>  
<span style="margin-left: 2em">道高取之若欲以直角立表即用儀心爲表位其長</span>  
<span style="margin-left: 2em">短俱依切線即本儀半徑矣黃赤全儀之用約不外</span>
