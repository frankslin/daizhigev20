<span style="margin-left: 2em">视差以人目为主第一　四章</span>  
<span style="margin-left: 1em">前言实会中会视时食限等皆日月食之公法也是皆</span>  
<span style="margin-left: 2em">准于地心今再论月食生于地景景生于日故天上</span>  
<span style="margin-left: 2em">之实食即人所见之视食无二食也日食不然有天</span>  
<span style="margin-left: 2em">上之实食有人所见之视食其食分之有无多寡加</span>  
<span style="margin-left: 2em">时之早晚先后各各不同推步日食难于太阴者以</span>  
<span style="margin-left: 2em">此其推算视食则依人目与地面为准</span>  
<span style="margin-left: 3em">视会</span>  
<span style="margin-left: 1em">凡交会者必参相直不参直不相掩也日之有实食也</span>  
<span style="margin-left: 2em">地心与月与日参居一线之上也其有视食也人目</span>  
<span style="margin-left: 2em">与月与日参居一线之上也人目居地面之上与地</span>  
<span style="margin-left: 2em">心相距之差为大地之半径则所见日食与实食恒</span>  
<span style="margin-left: 2em">偏左偏右分为两直线各至于宗动天其所指不得</span>  
<span style="margin-left: 2em">同度分是生视差而人目所参对之线不得为实会</span>  
<span style="margin-left: 2em">而特为视会</span>  
<span style="margin-left: 2em">如图甲为地心乙为地面丙为天顶若丁为日戊为</span>  
<span style="margin-left: 2em">月即在甲丙一直线上则实会即为视会因地心与</span>  
<span style="margin-left: 2em">人目无分线故也若日在辛必月在壬方与地面乙</span>  
<span style="margin-left: 2em">作一线为视会矣若月至己与地心甲作一线则实</span>  
<span style="margin-left: 6em">会也今言交食惟以目见为凭故日食全</span>  
<span style="margin-left: 6em">论视会若所居地面不同即食分多寡加</span>  
<span style="margin-left: 6em">时早晏亦随之异也又视会实会在日月</span>  
<span style="margin-left: 6em">本天皆无度分可指而全依宗动天之黄</span>  
<span style="margin-left: 2em">道圈度分则此实会线所指谓之实度视会线所指</span>  
<span style="margin-left: 2em">谓之视度如图甲辛线所指为黄道之庚则庚为太</span>  
<span style="margin-left: 2em">阳之实度若乙目视辛日至黄道癸视己月至黄道</span>  
<span style="margin-left: 2em">午则癸为太阳之视度午为太阴之视度也</span>  
<span style="margin-left: 3em">日月目见之度非实度</span>  
<span style="margin-left: 1em">譬之画图者作平圆形则一举手一运规即得矣若欲</span>  
<span style="margin-left: 2em">为螺旋线先须依法作识又依法作线乃成形焉测</span>  
<span style="margin-left: 2em">天之法亦犹是耳今欲知日月缠离东西南北亦转</span>  
<span style="margin-left: 2em">仪闚表一览可知若欲定其本行所在则非聊一寓</span>  
<span style="margin-left: 2em">目遽能得之必先后累测度分展转较勘乃可定也</span>  
<span style="margin-left: 2em">假令目居地之中心<sub class="note-yuan">地之心即宗动天之心</sub>极目所见则有恒</span>  
<span style="margin-left: 2em">星以当彼界两界中间有日月五星是名七曜七曜</span>  
<span style="margin-left: 2em">相视有远有近无有同者即论一曜亦各时远时近</span>  
<span style="margin-left: 2em">无时同者是则目所能见也然因目所见得其视度</span>  
<span style="margin-left: 2em">于彼界因以视度测其与某恒星相距若干度分因</span>  
<span style="margin-left: 2em">以是度推其实与地相距若干远近则可谓即目所</span>  
<span style="margin-left: 2em">见遂得其实行能分别其去地远近则不可何者七</span>  
<span style="margin-left: 2em">政诸本天虽居恒星天之内乃不见火木土等内天</span>  
<span style="margin-left: 2em">之星以本体能掩最外之恒星则何从辩其内外远</span>  
<span style="margin-left: 2em">近乎又目所见者太阴太阳二体相若何从知其内</span>  
<span style="margin-left: 2em">外之相距绝远二体之小大绝不相等乎内天之两</span>  
<span style="margin-left: 2em">星参对于外天之两经星目见之能知外者之两相</span>  
<span style="margin-left: 2em">距甚远内者之两相距不甚远乎是三者皆目力难</span>  
<span style="margin-left: 2em">凭之效也或曰是则然矣测量之法皆凭目所见也</span>  
<span style="margin-left: 2em">则可废乎曰何可废也惟测内天之星得彼界所指</span>  
<span style="margin-left: 2em">之点以为即在恒星之天聊可得之矣何者凡用在</span>  
<span style="margin-left: 2em">界之弧以测其辏心之角无弗真者目测恒星之天</span>  
<span style="margin-left: 2em">其在地面与其在地心也无以异<sub class="note-yuan">地居恒星天中止当一点</sub>若测</span>  
<span style="margin-left: 2em">内天诸曜目虽不在地心相距亦不甚远故测日月</span>  
<span style="margin-left: 2em">五星于彼界上得点即与实度相近<sub class="note-yuan">曰聊可得之曰距不甚远曰近</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">其实度皆因有地半径视差故</sub>但恒星有时不见或与内天诸曜不</span>  
<span style="margin-left: 2em">相值故历家以地平代恒星更用远视之器以助目</span>  
<span style="margin-left: 2em">力得日月五星之视度分依法推步乃正得其实度</span>  
<span style="margin-left: 2em">分矣</span>  
<span style="margin-left: 3em">人目差</span>  
<span style="margin-left: 1em">两目赅存不惟相助以为明相代以备患亦能彼此互</span>  
<span style="margin-left: 2em">用以察物之远近盖各以其心<sub class="note-yuan">目睛最中之一点为心</sub>受外物</span>  
<span style="margin-left: 2em">之象其过心之两直线至物体则相遇为两腰两睛</span>  
<span style="margin-left: 2em">心自相距为底成三角形因以其比例之大小别物</span>  
<span style="margin-left: 2em">距目之远近是谓目差缘此可推天上之视差以小</span>  
<span style="margin-left: 2em">喻大其理一也若物大远于人目则底线极小两腰</span>  
<span style="margin-left: 2em">极长是过睛心之两径线与平行无异正如地球比</span>  
<span style="margin-left: 2em">恒星天之高特以一点为底视差无所繇生矣</span>  
<span style="margin-left: 2em">如图两目之心为甲为乙目所视之物为丙若甲乙</span>  
<span style="margin-left: 2em">线可比于甲丙线<sub class="note-yuan">可比者不甚远则有比例</sub>则两戊己径线渐相</span>  
<span style="margin-left: 2em">就如己而相遇于丙若物更相近为丁则两径速相</span>  
<span style="margin-left: 8em">就为辛庚<sub class="note-yuan">甲乙丙及甲乙丁两三角形皆等边又同一底线则</sub></span>  
<span style="margin-left: 8em"><sub class="note-yuan">丁角大于丙角而丁甲乙角必小于丙甲乙角</sub>而两目之光</span>  
<span style="margin-left: 8em">线皆从己歛向于庚自觉所视之物</span>  
<span style="margin-left: 2em">变远为近矣若物与目相去甚远则无比例者因两</span>  
<span style="margin-left: 2em">径绝难相就绝难相遇故也今借此理明视差之公</span>  
<span style="margin-left: 2em">理如本图设丁物之前有横堵为壬癸令甲目独视</span>  
<span style="margin-left: 2em">丁物则所见若在壬令乙目独视丁则所见反在癸</span>  
<span style="margin-left: 2em">而丁前丁后两交角形必相似即丁物亦不远于壬</span>  
<span style="margin-left: 2em">不远于癸盖视之目分两线为交角即能分本物之</span>  
<span style="margin-left: 2em">远近也若不能分两线即不能分远近</span>  
<span style="margin-left: 3em">地半径差</span>  
<span style="margin-left: 1em">目视星欲辨六曜<sub class="note-yuan">月五星也</sub>在恒星之内势不能也则当借</span>  
<span style="margin-left: 2em">地体之大补目力之不及法用地半径为底以推测</span>  
<span style="margin-left: 2em">量所指之界即可得七政远近上下各居本天之实</span>  
<span style="margin-left: 2em">处如图甲乙两目相距为底则二寸耳今以两地相</span>  
<span style="margin-left: 2em">距数千里或数里当之以为底如甲为顺天府乙为</span>  
<span style="margin-left: 2em">广州府丁为太阴两人同测之一在甲一在乙因此</span>  
<span style="margin-left: 2em">大底之远近比于各距太阴之两腰得大小之比例</span>  
<span style="margin-left: 2em">则甲丁及乙丁两直线必觉彼此相就以趋于丁矣</span>  
<span style="margin-left: 2em">再使壬癸为列宿天之两恒星<sub class="note-yuan">或壬癸为太阳之全体壬当其南周癸当</sub></span>  
<span style="margin-left: 8em"><sub class="note-yuan">其北周</sub>测者一从甲见太阴丁若在壬</span>  
<span style="margin-left: 8em">以本体合于一星之体<sub class="note-yuan">或太阴之南周齐太阳之</sub></span>  
<span style="margin-left: 8em"><sub class="note-yuan">南周</sub>一从乙测太阴反在癸转就北以</span>  
<span style="margin-left: 2em">合于他星<sub class="note-yuan">或太阳之北周</sub>若甲乙两测之距愈相远即所见</span>  
<span style="margin-left: 2em">丁月两指之极高亦愈相远<sub class="note-yuan">一偏南一偏北东西亦同</sub>而人在甲</span>  
<span style="margin-left: 2em">能见太阴掩日为日食人在乙即不可得见矣以此</span>  
<span style="margin-left: 2em">壬癸当宗动天上之弧正所谓视差与前言目见之</span>  
<span style="margin-left: 2em">小视差其理一也第两人相距千里万里同时并测</span>  
<span style="margin-left: 2em">太阴其势甚难故立别法代之<sub class="note-yuan">详见本书第六卷下文畧言之</sub>假令</span>  
<span style="margin-left: 2em">人正居地心推其所得太阴距天顶应若干度分又</span>  
<span style="margin-left: 2em">同时居地面者实测太阴距天顶得若干度分两度</span>  
<span style="margin-left: 2em">之差即所谓视差也如图甲乙丙为地球丁为天顶</span>  
<span style="margin-left: 7em">甲戊丁直线所至也若太阴在此线左</span>  
<span style="margin-left: 7em">右为己从甲地心测月见之当在庚自</span>  
<span style="margin-left: 7em">地面乙测之乃在辛则先推定丁甲庚</span>  
<span style="margin-left: 2em">角或所当之丁庚弧后推丁乙辛角或所当之丁辛</span>  
<span style="margin-left: 2em">弧<sub class="note-yuan">乙距甲与乙距丁无比例甲乙至小故</sub>以两角或两弧相减得视差</span>  
<span style="margin-left: 2em">之弧庚辛</span>  
<span style="margin-left: 2em">问一星距天顶测其宗动天上所指度分在地心测</span>  
<span style="margin-left: 2em">之则距近在地面测之则距远若论角则地面之乙</span>  
<span style="margin-left: 2em">角大于地心之甲角何以证之其故何也曰因其一</span>
