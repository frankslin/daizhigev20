<span style="margin-left: 2em">視差以人目爲主第一　四章</span>  
<span style="margin-left: 1em">前言實會中會視時食限等皆日月食之公法也是皆</span>  
<span style="margin-left: 2em">準於地心今再論月食生於地景景生於日故天上</span>  
<span style="margin-left: 2em">之實食即人所見之視食無二食也日食不然有天</span>  
<span style="margin-left: 2em">上之實食有人所見之視食其食分之有無多寡加</span>  
<span style="margin-left: 2em">時之早晚先後各各不同推步日食難於太陰者以</span>  
<span style="margin-left: 2em">此其推算視食則依人目與地面爲準</span>  
<span style="margin-left: 3em">視會</span>  
<span style="margin-left: 1em">凡交會者必參相直不參直不相掩也日之有實食也</span>  
<span style="margin-left: 2em">地心與月與日參居一線之上也其有視食也人目</span>  
<span style="margin-left: 2em">與月與日參居一線之上也人目居地面之上與地</span>  
<span style="margin-left: 2em">心相距之差爲大地之半徑則所見日食與實食恆</span>  
<span style="margin-left: 2em">偏左偏右分爲兩直線各至於宗動天其所指不得</span>  
<span style="margin-left: 2em">同度分是生視差而人目所參對之線不得爲實會</span>  
<span style="margin-left: 2em">而特爲視會</span>  
<span style="margin-left: 2em">如圖甲爲地心乙爲地面丙爲天頂若丁爲日戊爲</span>  
<span style="margin-left: 2em">月即在甲丙一直線上則實會即爲視會因地心與</span>  
<span style="margin-left: 2em">人目無分線故也若日在辛必月在壬方與地面乙</span>  
<span style="margin-left: 2em">作一線爲視會矣若月至己與地心甲作一線則實</span>  
<span style="margin-left: 6em">會也今言交食惟以目見爲憑故日食全</span>  
<span style="margin-left: 6em">論視會若所居地面不同即食分多寡加</span>  
<span style="margin-left: 6em">時早晏亦随之異也又視會實會在日月</span>  
<span style="margin-left: 6em">本天皆無度分可指而全依宗動天之黃</span>  
<span style="margin-left: 2em">道圈度分則此實會線所指謂之實度視會線所指</span>  
<span style="margin-left: 2em">謂之視度如圖甲辛線所指爲黃道之庚則庚爲太</span>  
<span style="margin-left: 2em">陽之實度若乙目視辛日至黃道癸視己月至黃道</span>  
<span style="margin-left: 2em">午則癸爲太陽之視度午爲太陰之視度也</span>  
<span style="margin-left: 3em">日月目見之度非實度</span>  
<span style="margin-left: 1em">譬之畫圖者作平圓形則一舉手一運規即得矣若欲</span>  
<span style="margin-left: 2em">爲螺旋線先須依法作識又依法作線乃成形焉測</span>  
<span style="margin-left: 2em">天之法亦猶是耳今欲知日月纏離東西南北亦轉</span>  
<span style="margin-left: 2em">儀闚表一覽可知若欲定其本行所在則非聊一寓</span>  
<span style="margin-left: 2em">目遽能得之必先後累測度分展轉較勘乃可定也</span>  
<span style="margin-left: 2em">假令目居地之中心<sub class="note-yuan">地之心即宗動天之心</sub>極目所見則有恆</span>  
<span style="margin-left: 2em">星以當彼界兩界中間有日月五星是名七曜七曜</span>  
<span style="margin-left: 2em">相視有遠有近無有同者即論一曜亦各時遠時近</span>  
<span style="margin-left: 2em">無時同者是則目所能見也然因目所見得其視度</span>  
<span style="margin-left: 2em">於彼界因以視度測其與某恆星相距若干度分因</span>  
<span style="margin-left: 2em">以是度推其實與地相距若干遠近則可謂即目所</span>  
<span style="margin-left: 2em">見遂得其實行能分別其去地遠近則不可何者七</span>  
<span style="margin-left: 2em">政諸本天雖居恆星天之內乃不見火木土等內天</span>  
<span style="margin-left: 2em">之星以本體能掩最外之恆星則何從辯其內外遠</span>  
<span style="margin-left: 2em">近乎又目所見者太陰太陽二體相若何從知其內</span>  
<span style="margin-left: 2em">外之相距絕遠二體之小大絕不相等乎內天之兩</span>  
<span style="margin-left: 2em">星參對於外天之兩經星目見之能知外者之兩相</span>  
<span style="margin-left: 2em">距甚遠內者之兩相距不甚遠乎是三者皆目力難</span>  
<span style="margin-left: 2em">憑之效也或曰是則然矣測量之法皆憑目所見也</span>  
<span style="margin-left: 2em">則可廢乎曰何可廢也惟測內天之星得彼界所指</span>  
<span style="margin-left: 2em">之點以爲即在恆星之天聊可得之矣何者凡用在</span>  
<span style="margin-left: 2em">界之弧以測其輳心之角無弗真者目測恆星之天</span>  
<span style="margin-left: 2em">其在地面與其在地心也無以異<sub class="note-yuan">地居恆星天中止當一點</sub>若測</span>  
<span style="margin-left: 2em">內天諸曜目雖不在地心相距亦不甚遠故測日月</span>  
<span style="margin-left: 2em">五星於彼界上得點即與實度相近<sub class="note-yuan">曰聊可得之曰距不甚遠曰近</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">其實度皆因有地半徑視差故</sub>但恆星有時不見或與內天諸曜不</span>  
<span style="margin-left: 2em">相值故曆家以地平代恆星更用遠視之器以助目</span>  
<span style="margin-left: 2em">力得日月五星之視度分依法推步乃正得其實度</span>  
<span style="margin-left: 2em">分矣</span>  
<span style="margin-left: 3em">人目差</span>  
<span style="margin-left: 1em">兩目賅存不惟相助以爲明相代以備患亦能彼此互</span>  
<span style="margin-left: 2em">用以察物之遠近蓋各以其心<sub class="note-yuan">目睛最中之一點爲心</sub>受外物</span>  
<span style="margin-left: 2em">之象其過心之兩直線至物體則相遇爲兩腰兩睛</span>  
<span style="margin-left: 2em">心自相距爲底成三角形因以其比例之大小別物</span>  
<span style="margin-left: 2em">距目之遠近是謂目差緣此可推天上之視差以小</span>  
<span style="margin-left: 2em">喻大其理一也若物大遠於人目則底線極小兩腰</span>  
<span style="margin-left: 2em">極長是過睛心之兩徑線與平行無異正如地球比</span>  
<span style="margin-left: 2em">恆星天之高特以一點爲底視差無所繇生矣</span>  
<span style="margin-left: 2em">如圖兩目之心爲甲爲乙目所視之物爲丙若甲乙</span>  
<span style="margin-left: 2em">線可比於甲丙線<sub class="note-yuan">可比者不甚遠則有比例</sub>則兩戊己徑線漸相</span>  
<span style="margin-left: 2em">就如己而相遇於丙若物更相近爲丁則兩徑速相</span>  
<span style="margin-left: 8em">就爲辛庚<sub class="note-yuan">甲乙丙及甲乙丁兩三角形皆等邊又同一底線則</sub></span>  
<span style="margin-left: 8em"><sub class="note-yuan">丁角大於丙角而丁甲乙角必小於丙甲乙角</sub>而兩目之光</span>  
<span style="margin-left: 8em">線皆從己歛向於庚自覺所視之物</span>  
<span style="margin-left: 2em">變遠爲近矣若物與目相去甚遠則無比例者因兩</span>  
<span style="margin-left: 2em">徑絕難相就絕難相遇故也今借此理明視差之公</span>  
<span style="margin-left: 2em">理如本圖設丁物之前有橫堵爲壬癸令甲目獨視</span>  
<span style="margin-left: 2em">丁物則所見若在壬令乙目獨視丁則所見反在癸</span>  
<span style="margin-left: 2em">而丁前丁後兩交角形必相似即丁物亦不遠於壬</span>  
<span style="margin-left: 2em">不遠於癸蓋視之目分兩線爲交角即能分本物之</span>  
<span style="margin-left: 2em">遠近也若不能分兩線即不能分遠近</span>  
<span style="margin-left: 3em">地半徑差</span>  
<span style="margin-left: 1em">目視星欲辨六曜<sub class="note-yuan">月五星也</sub>在恆星之內勢不能也則當借</span>  
<span style="margin-left: 2em">地體之大補目力之不及法用地半徑爲底以推測</span>  
<span style="margin-left: 2em">量所指之界即可得七政遠近上下各居本天之實</span>  
<span style="margin-left: 2em">處如圖甲乙兩目相距爲底則二寸耳今以兩地相</span>  
<span style="margin-left: 2em">距數千里或數里當之以爲底如甲爲順天府乙爲</span>  
<span style="margin-left: 2em">廣州府丁爲太陰兩人同測之一在甲一在乙因此</span>  
<span style="margin-left: 2em">大底之遠近比於各距太陰之兩腰得大小之比例</span>  
<span style="margin-left: 2em">則甲丁及乙丁兩直線必覺彼此相就以趨於丁矣</span>  
<span style="margin-left: 2em">再使壬癸爲列宿天之兩恆星<sub class="note-yuan">或壬癸爲太陽之全體壬當其南周癸當</sub></span>  
<span style="margin-left: 8em"><sub class="note-yuan">其北周</sub>測者一從甲見太陰丁若在壬</span>  
<span style="margin-left: 8em">以本體合於一星之體<sub class="note-yuan">或太陰之南周齊太陽之</sub></span>  
<span style="margin-left: 8em"><sub class="note-yuan">南周</sub>一從乙測太陰反在癸轉就北以</span>  
<span style="margin-left: 2em">合於他星<sub class="note-yuan">或太陽之北周</sub>若甲乙兩測之距愈相遠即所見</span>  
<span style="margin-left: 2em">丁月兩指之極高亦愈相遠<sub class="note-yuan">一偏南一偏北東西亦同</sub>而人在甲</span>  
<span style="margin-left: 2em">能見太陰掩日爲日食人在乙即不可得見矣以此</span>  
<span style="margin-left: 2em">壬癸當宗動天上之弧正所謂視差與前言目見之</span>  
<span style="margin-left: 2em">小視差其理一也第兩人相距千里萬里同時並測</span>  
<span style="margin-left: 2em">太陰其勢甚難故立別法代之<sub class="note-yuan">詳見本書第六卷下文畧言之</sub>假令</span>  
<span style="margin-left: 2em">人正居地心推其所得太陰距天頂應若干度分又</span>  
<span style="margin-left: 2em">同時居地面者實測太陰距天頂得若干度分兩度</span>  
<span style="margin-left: 2em">之差即所謂視差也如圖甲乙丙爲地球丁爲天頂</span>  
<span style="margin-left: 7em">甲戊丁直線所至也若太陰在此線左</span>  
<span style="margin-left: 7em">右爲己從甲地心測月見之當在庚自</span>  
<span style="margin-left: 7em">地面乙測之乃在辛則先推定丁甲庚</span>  
<span style="margin-left: 2em">角或所當之丁庚弧後推丁乙辛角或所當之丁辛</span>  
<span style="margin-left: 2em">弧<sub class="note-yuan">乙距甲與乙距丁無比例甲乙至小故</sub>以兩角或兩弧相減得視差</span>  
<span style="margin-left: 2em">之弧庚辛</span>  
<span style="margin-left: 2em">問一星距天頂測其宗動天上所指度分在地心測</span>  
<span style="margin-left: 2em">之則距近在地面測之則距遠若論角則地面之乙</span>  
<span style="margin-left: 2em">角大於地心之甲角何以證之其故何也曰因其一</span>  
<span style="margin-left: 2em">遠一近如圖太陰在本天其距頂之弧爲己戊己戊</span>  
<span style="margin-left: 2em">之距地心甲與其距地面乙遠近之差則目所能識</span>  
<span style="margin-left: 7em">也所能分也<sub class="note-yuan">因地之半徑與月本天之半徑有比例故</sub>則目</span>
