## 崇祯历书卷之三十二　新法表异卷上

<span style="margin-left: 2em">中历之古测乃知古测晨夕二留日时折半以求合</span>  
<span style="margin-left: 2em">伏之时非法也又其所用表晷简平等仪皆与星行</span>  
<span style="margin-left: 2em">之道绝不相似而用以测五星则非其器也大约测</span>  
<span style="margin-left: 2em">五星须用黄赤全仪弧矢仪经纬象限等与其行相</span>  
<span style="margin-left: 2em">类者而又常较之于恒星乃可得其准也</span>  
<span style="margin-left: 1em">已上畧引书目皆归历原以全修历之学阙一不可古</span>  
<span style="margin-left: 2em">之论历者或务改历元如气应等或务正定岁差不</span>  
<span style="margin-left: 2em">则求之合朔求之五星求之宿度而已总皆挂一漏</span>  
<span style="margin-left: 2em">万其法立穷必如新法乃为无歉且此外更著学历</span>  
<span style="margin-left: 2em">要书如割圆法八线表视学几何要法测量全义浑</span>  
<span style="margin-left: 2em">天仪用法比例规筹算开方等法以为旁通之学而</span>  
<span style="margin-left: 2em">历学于是乎大备后有学者宜究心焉</span>

<span style="margin-left: 3em">总说</span>  
<span style="margin-left: 1em">帝王图治求端于天历事由是兴焉炎帝八节俶农功</span>  
<span style="margin-left: 1em">也轩辕甲子系日成也帝喾序星征天象也尧置闰月</span>  
<span style="margin-left: 1em">四时乃定舜造玑衡七政以齐夏后周人其教渐详月</span>  
<span style="margin-left: 1em">令记于戴礼协纪载于箕畴自是以迨春秋率岁登台</span>  
<span style="margin-left: 1em">测验日至然而闰多失置晦朔国殊疎舛为甚六历出</span>  
<span style="margin-left: 1em">于周秦之际后人疑其伪作而今不可考矣汉初张苍</span>  
<span style="margin-left: 1em">承秦用颛顼历洛下闳太初刘歆三统始立积年日法</span>  
<span style="margin-left: 1em">以为推步之准后世因之而行之愈不能久者不知顺</span>  
<span style="margin-left: 1em">天求合之道也其后李梵造四分历七十余年而仪式</span>  
<span style="margin-left: 1em">方备又百三十年刘洪造乾象历始减岁余创制月行</span>  
<span style="margin-left: 1em">迟疾阴阳黄赤交错以合天度为推步师表又百八十</span>  
<span style="margin-left: 1em">年后秦姜岌造三纪历始以月食冲检知太阳躔度所</span>  
<span style="margin-left: 1em">在又五十七年宋何承天造元嘉历始悟测景以定冬</span>  
<span style="margin-left: 1em">至又六十五年祖冲之造大明历始悟太阳有岁差及</span>  
<span style="margin-left: 1em">极星去不动处有一度余又五十二年北齐张子信始</span>  
<span style="margin-left: 1em">悟日月交道有表里五星有迟留伏逆又三十三年刘</span>  
<span style="margin-left: 1em">焯造皇极历始知日行有盈缩又三十五年唐传仁均</span>  
<span style="margin-left: 1em">造戊寅元历颇采旧仪高宗时李淳风造麟德历以古</span>  
<span style="margin-left: 1em">历章蔀元首分度不齐始为总法用进朔以避晦日晨</span>  
<span style="margin-left: 1em">月见又六十三年开元时僧一行造大衍历始以月朔</span>  
<span style="margin-left: 1em">建为四大三小诸法较密又九十四年穆宗时徐昴造</span>  
<span style="margin-left: 1em">宣明历始悟日食有气刻时三差又二百三十六年徽</span>  
<span style="margin-left: 1em">宗时姚舜辅造纪元历始悟食甚泛余差数又一百七</span>  
<span style="margin-left: 1em">十余年元郭守敬造授时历兼综前术时创新意然亦</span>  
<span style="margin-left: 1em">仅能度越前代诸家而求其密合天行垂之永久而无</span>  
<span style="margin-left: 1em">敝终未能也明初作大统历袭授时之成法二百余年</span>  
<span style="margin-left: 1em">不知变通讹舛特甚万历间曾议改修至崇祯己巳乃</span>  
<span style="margin-left: 1em">召望等前来著书演器历成亟欲颁行恭遇</span>  
圣朝建鼎遂用新法造时宪宝历颁行天下岂非一代之  
<span style="margin-left: 1em">兴必有一代之历预修二十年以备</span>  
兴朝万年之法传哉於戏盛矣古来治历者称七十余家  
<span style="margin-left: 1em">考之前史仅四十有余人而已畧引各朝各历继以</span>  
本朝新历之凡概以质诸世之知历者精粗疎密展卷即
