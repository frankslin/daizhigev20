## 崇禎曆書卷之三十二　新法表異捲上

<span style="margin-left: 2em">中曆之古測乃知古測晨夕二留日時折半以求合</span>  
<span style="margin-left: 2em">伏之時非法也又其所用表晷簡平等儀皆與星行</span>  
<span style="margin-left: 2em">之道絕不相似而用以測五星則非其器也大約測</span>  
<span style="margin-left: 2em">五星須用黃赤全儀弧矢儀經緯象限等與其行相</span>  
<span style="margin-left: 2em">類者而又常較之于恒星乃可得其準也</span>  
<span style="margin-left: 1em">已上畧引書目皆歸曆原以全修曆之學闕一不可古</span>  
<span style="margin-left: 2em">之論曆者或務改曆元如氣應等或務正定歲差不</span>  
<span style="margin-left: 2em">則求之合朔求之五星求之宿度而已總皆掛一漏</span>  
<span style="margin-left: 2em">萬其法立窮必如新法乃爲無歉且此外更著學曆</span>  
<span style="margin-left: 2em">要書如割圓法八線表視學幾何要法測量全義渾</span>  
<span style="margin-left: 2em">天儀用法比例規籌算開方等法以爲旁通之學而</span>  
<span style="margin-left: 2em">曆學于是乎大備後有學者宜究心焉</span>  
<span style="margin-left: 1em">崇禎曆書卷之三十一終</span>  
<span style="margin-left: 1em">崇禎曆書卷之三十二</span>  
<span style="margin-left: 2em">新法表異卷上<sub class="note-jiao">校：據清刊本補錄</sub></span>  
<span style="margin-left: 1em">勅錫通微教師加二品通政使司通政使掌欽天監印務事臣湯若望著</span>  
<span style="margin-left: 3em">總說</span>  
<span style="margin-left: 1em">帝王圖治求端于天曆事由是興焉炎帝八節俶農功</span>  
<span style="margin-left: 1em">也軒轅甲子系日成也帝嚳序星徵天象也堯置閏月</span>  
<span style="margin-left: 1em">四時乃定舜造璣衡七政以齊夏后周人其教漸詳月</span>  
<span style="margin-left: 1em">令記于戴禮協紀載于箕疇自是以迨春秋率歲登臺</span>  
<span style="margin-left: 1em">測驗日至然而閏多失置晦朔國殊疎舛爲甚六曆出</span>  
<span style="margin-left: 1em">于周秦之際後人疑其僞作而今不可考矣漢初張蒼</span>  
<span style="margin-left: 1em">承秦用顓頊曆洛下閎太初劉歆三統始立積年日法</span>  
<span style="margin-left: 1em">以爲推步之準後世因之而行之愈不能久者不知順</span>  
<span style="margin-left: 1em">天求合之道也其後李梵造四分曆七十餘年而儀式</span>  
<span style="margin-left: 1em">方備又百三十年劉洪造乾象曆始减歲餘創制月行</span>  
<span style="margin-left: 1em">遲疾陰陽黃赤交錯以合天度爲推步師表又百八十</span>  
<span style="margin-left: 1em">年後秦姜岌造三紀曆始以月食衝檢知太陽躔度所</span>  
<span style="margin-left: 1em">在又五十七年宋何承天造元嘉曆始悟測景以定冬</span>  
<span style="margin-left: 1em">至又六十五年祖沖之造大明曆始悟太陽有歲差及</span>  
<span style="margin-left: 1em">極星去不動處有一度餘又五十二年北齊張子信始</span>  
<span style="margin-left: 1em">悟日月交道有表裏五星有遲留伏逆又三十三年劉</span>  
<span style="margin-left: 1em">焯造皇極曆始知日行有盈縮又三十五年唐傳仁均</span>  
<span style="margin-left: 1em">造戊寅元曆頗采舊儀高宗時李淳風造麟德曆以古</span>  
<span style="margin-left: 1em">曆章蔀元首分度不齊始爲總法用進朔以避晦日晨</span>  
<span style="margin-left: 1em">月見又六十三年開元時僧一行造大衍曆始以月朔</span>  
<span style="margin-left: 1em">建爲四大三小諸法較密又九十四年穆宗時徐昴造</span>  
<span style="margin-left: 1em">宣明曆始悟日食有氣刻時三差又二百三十六年徽</span>  
<span style="margin-left: 1em">宗時姚舜輔造紀元曆始悟食甚汎餘差數又一百七</span>  
<span style="margin-left: 1em">十餘年元郭守敬造授時曆兼綜前術時創新意然亦</span>  
<span style="margin-left: 1em">僅能度越前代諸家而求其密合天行垂之永久而無</span>  
<span style="margin-left: 1em">敝終未能也明初作大統曆襲授時之成法二百餘年</span>  
<span style="margin-left: 1em">不知變通訛舛特甚萬曆間曾議改修至崇禎己巳乃</span>  
<span style="margin-left: 1em">召望等前來著書演器曆成亟欲頒行恭遇</span>  
聖朝建鼎遂用新法造時憲寶曆頒行天下豈非一代之  
<span style="margin-left: 1em">興必有一代之曆預修二十年以備</span>  
興朝萬年之法傳哉於戲盛矣古來治曆者稱七十餘家  
<span style="margin-left: 1em">考之前史僅四十有餘人而已畧引各朝各曆繼以</span>  
本朝新曆之凡概以質諸世之知曆者精粗疎密展卷即  
<span style="margin-left: 1em">得夫孰得而掩乎</span>  
<span style="margin-left: 2em">漢</span>  
<span style="margin-left: 1em">武帝太初元年丁丑洛下閎鄧平造太初曆</span>  
<span style="margin-left: 1em">成帝綏和二年甲寅劉歆造三統曆</span>  
<span style="margin-left: 2em">積年一十四萬四千五百一十一</span>  
<span style="margin-left: 2em">日法八十一</span>  
<span style="margin-left: 2em">二曆同法歆即衍閎平之法而爲三統非有異也曆</span>  
<span style="margin-left: 2em">家立積年日法以準推步蓋始諸此其法以律起曆</span>  
<span style="margin-left: 2em">說多傅會初稱脗合積漸後天至元和初失天益遠</span>  
<span style="margin-left: 2em">晦朔弦望差天一日宿差五度</span>  
<span style="margin-left: 2em">後漢</span>  
<span style="margin-left: 1em">章帝元和二年乙酉李梵編訢造四分曆</span>  
<span style="margin-left: 2em">積年一萬五百六十一</span>  
<span style="margin-left: 2em">日法四</span>  
<span style="margin-left: 2em">是時舊曆舛甚乃詔梵等另造新曆乃以二十五刻</span>  
<span style="margin-left: 2em">爲歲實小餘以四分度之一爲斗分天數與日數齊</span>  
<span style="margin-left: 2em">而日無盈縮月無遲疾止用一平朔步曆疎謬可知</span>  
<span style="margin-left: 2em">至永光十五年七月甲辰造黃道銅儀</span>  
<span style="margin-left: 1em">獻帝建安十一年丙戌劉洪造乾象曆</span>  
<span style="margin-left: 2em">積年八千四百五十二</span>  
<span style="margin-left: 2em">日法一千四百五十七</span>  
<span style="margin-left: 2em">漢曆三統四分皆四分之一餘分太强劉洪始覺冬</span>  
<span style="margin-left: 2em">至後天乃减歲餘更以五百八十九爲紀法百四十</span>  
<span style="margin-left: 2em">五爲斗分考冬至日日在斗二十二度精思二十餘</span>  
<span style="margin-left: 2em">年始悟月行遲速之理創列差率以囿進退損益之</span>  
<span style="margin-left: 2em">數又知月行陰陽交錯于黃道表裏日行黃道于赤</span>  
<span style="margin-left: 2em">道宿度復進有退作乾象曆</span>  
<span style="margin-left: 2em">魏</span>  
<span style="margin-left: 1em">明帝景初元年丁巳楊偉造景初曆</span>  
<span style="margin-left: 2em">積年五千零八十九</span>  
<span style="margin-left: 2em">日法四千五百五十九</span>  
<span style="margin-left: 2em">先是黃初中韓翊因乾象曆减斗分太過後必先天</span>  
<span style="margin-left: 2em">乃少益斗分作黃初曆至是楊偉忿翊之非復作此</span>  
<span style="margin-left: 2em">曆行之乾象黃初二曆參校多年更相是非無時而</span>  
<span style="margin-left: 2em">决至於景初大槩不出乾象範圍而其推五星尤爲</span>  
<span style="margin-left: 2em">疎濶</span>  
<span style="margin-left: 2em">晉</span>  
<span style="margin-left: 1em">武帝太元九年甲申姜岌造三紀曆</span>  
<span style="margin-left: 2em">岌病古今諸曆斗分皆疎以致日月交會無驗復作</span>  
<span style="margin-left: 2em">三紀曆其言曰治曆之道必審日月之行然後可以</span>  
<span style="margin-left: 2em">上考天時下察地化一失其本則四時變移矣于是</span>  
<span style="margin-left: 2em">考古今斗分疎密不同法數各異殷歷斗分粗故不</span>  
<span style="margin-left: 2em">施于今乾象斗分細故不通于古景初斗分雖在粗</span>  
<span style="margin-left: 2em">細之中而日之所在乃差四度日月虧已皆不及其</span>  
<span style="margin-left: 2em">次假使日在東井而食以月驗之乃在參六度差違</span>  
<span style="margin-left: 2em">乃爾安可以考天時治人事乎乃作三紀曆歲實小</span>  
<span style="margin-left: 2em">餘二四六八三八朔實餘五三〇五九五轉終餘五</span>  
<span style="margin-left: 2em">五四五一〇交終餘三二一六一三凡八萬三千八</span>  
<span style="margin-left: 2em">百四十一算較前爲詳而交終之多則與景初同于</span>  
<span style="margin-left: 2em">五星亦未見考正其獨創者則以月蝕衝檢日宿度</span>  
<span style="margin-left: 2em">所在爲曆術者宗焉惜其曆未見之施行也</span>  
<span style="margin-left: 2em">宋</span>  
<span style="margin-left: 1em">文帝元嘉二十年癸未何承天造元嘉曆</span>  
<span style="margin-left: 2em">積年六千五百四十一</span>  
<span style="margin-left: 2em">日法七百五十二</span>  
<span style="margin-left: 2em">承天病前曆昧于日所在之宿度又合朔交食不在</span>  
<span style="margin-left: 2em">朔望因比歲考校于元嘉二十年作元嘉曆行之其</span>  
<span style="margin-left: 2em">上表畧曰漢代雜候清臺以昏明中星課日所在雖</span>  
<span style="margin-left: 2em">不可見月盈則食必當其衝以月推日則躔次可知</span>  
<span style="margin-left: 2em">焉堯典日永星火以正仲夏今季夏則火中又宵中</span>  
<span style="margin-left: 2em">星虛以殷仲秋今季秋則虛中邇來二千七百餘年</span>  
<span style="margin-left: 2em">以中星檢之所差二十七八度則堯冬至日在須女</span>  
<span style="margin-left: 2em">十度左右也漢太初歴冬至在牽牛初後漢四分魏</span>  
<span style="margin-left: 2em">景初法同在斗二十一臣以月蝕檢之則景初今之</span>  
<span style="margin-left: 2em">冬至應在斗十七又以土圭測景考較二至差三日</span>  
<span style="margin-left: 2em">有餘然則今之二至非天之二至也宜隨時遷改以</span>  
<span style="margin-left: 2em">取其合乃以一百九十二章積三千六百四十八年</span>  
<span style="margin-left: 2em">爲元法以七百五十二爲日法又改歲實小餘爲二</span>  
<span style="margin-left: 2em">四六七一朔實餘爲五三〇五八五轉終餘爲五五</span>  
<span style="margin-left: 2em">四五二一交終餘爲三二一六〇四于是曆成較前</span>  
<span style="margin-left: 2em">爲密至武帝時祖冲之覺其疎謬乃議改曆</span>  
<span style="margin-left: 1em">武帝大明七年癸卯祖冲之造大明曆</span>  
<span style="margin-left: 2em">積年五萬二千七百五十七</span>  
<span style="margin-left: 2em">日法三千九百三十九</span>  
<span style="margin-left: 2em">冲之因元嘉畧于置法乖遠已見作大明曆法上之</span>  
<span style="margin-left: 2em">其言曰何承天意存改革而置法簡畧今已乖遠日</span>  
<span style="margin-left: 2em">月所在差覺三度二至晷景幾失一日五星伏見至</span>  
<span style="margin-left: 2em">差四旬留逆進退或移兩宿分至乖失則節閏非正</span>  
<span style="margin-left: 2em">宿度違天則伺察無準臣率愚瞽更剙新曆是即大</span>  
<span style="margin-left: 2em">明曆也四應等稍加改易而其改易之意有二內一</span>  
<span style="margin-left: 2em">欵因冬至宿度古今不同謂天數既差則七曜宿度</span>  
<span style="margin-left: 2em">漸與曆舛乖謬既著輙應改制今令冬至所在歲歲</span>  
<span style="margin-left: 2em">微差此言得之</span>  
<span style="margin-left: 2em">魏</span>  
<span style="margin-left: 1em">明帝正光二年辛丑龍祥李業興造正光曆</span>  
<span style="margin-left: 2em">積年一十六萬八千五百九</span>  
<span style="margin-left: 2em">日法七萬四千九百五十二</span>  
<span style="margin-left: 2em">時龍祥等九家曆合爲一曆以李業興爲主改元正</span>  
<span style="margin-left: 2em">光名正光曆魏書稱元起壬子律始黃鍾考古合今</span>  
<span style="margin-left: 2em">可爲最密今就其曆考之大約踵宋曆爲之者</span>  
<span style="margin-left: 2em">東魏</span>  
<span style="margin-left: 1em">靜帝興和二年庚申李業興造興和曆</span>  
<span style="margin-left: 2em">積年二十萬四千七百三十七</span>  
<span style="margin-left: 2em">日法二十萬八千五百三十</span>  
<span style="margin-left: 2em">壬子曆氣朔稍違熒惑失次四星出伏曆亦乖舛興</span>  
<span style="margin-left: 2em">和元年齊獻武王入鄴復命李業興改正武王上言</span>  
<span style="margin-left: 2em">之得詔施行　考洛京已來四十餘歲五星出沒歲</span>  
<span style="margin-left: 2em">星鎮星太白業興曆首尾恒中及有差處不過一日</span>  
<span style="margin-left: 2em">二日一度兩度他曆之失動校十日十度熒惑一星</span>  
<span style="margin-left: 2em">伏見體自無常或不應度祖冲之曆多甲子曆十日</span>  
<span style="margin-left: 2em">六度何承天曆不及三十日二十九度今曆還與壬</span>  
<span style="margin-left: 2em">子同不有加增辰星一星沒多見少及其見時與曆</span>  
<span style="margin-left: 2em">無舛今此亦依壬子元不改太白辰星唯起夕合爲</span>  
<span style="margin-left: 2em">異業興以天道高遠測步難精五行伏留推考不易</span>  
<span style="margin-left: 2em">人自仰闚未能盡密但取其見伏大歸畧其中間小</span>  
<span style="margin-left: 2em">謬如此曆便可行若專據所見之驗不取出沒之效</span>  
<span style="margin-left: 2em">則曆數之道其幾廢矣</span>  
<span style="margin-left: 2em">北齊</span>  
<span style="margin-left: 1em">文宣帝天保元年庚午宋景業造天保曆</span>  
<span style="margin-left: 2em">積年一十一萬一千二百五十七</span>  
<span style="margin-left: 2em">日法二萬三千六百六十</span>  
<span style="margin-left: 2em">文宣受禪景業奉命叶圖讖造天保曆行之後武平</span>  
<span style="margin-left: 2em">七年董峻鄭元偉立議非之畧曰景業有心改作不</span>  
<span style="margin-left: 2em">會真理乃使日之所在差至八度節氣後天閏先一</span>  
<span style="margin-left: 2em">月朔望虧食既未能知其表裏遲疾之曆步又不可</span>  
<span style="margin-left: 2em">以傍通妄設平分虛退冬至冬至虛退則日數减于</span>  
<span style="margin-left: 2em">周年平分妄設故加時差于異日五星見伏有違二</span>  
<span style="margin-left: 2em">旬遲疾逆留或乖兩宿又是年六月戊申朔太陽虧</span>  
<span style="margin-left: 2em">劉孝孫言食於卯時張孟賓言食於申時鄭元偉董</span>  
<span style="margin-left: 2em">峻言食於辰時宋景業言食於巳時至月食乃於卯</span>  
<span style="margin-left: 2em">申之間其言皆不能中大都五代諸曆家俱踵元嘉</span>  
<span style="margin-left: 2em">大明故法改換章蔀斗分妄自各立門戸争相妒競</span>  
<span style="margin-left: 2em">以塗人耳目如是而已</span>
