## 崇禎曆書卷之三十三　新法表異卷下

<span style="margin-left: 2em">新法表異卷下</span>  
<span style="margin-left: 1em">勅錫通微教師加二品通政使司通政使掌欽天監印務事臣湯若望著</span>  
<span style="margin-left: 2em">國朝</span>  
<span style="margin-left: 1em">前明自改曆已來新法著聞于世久矣猥以國家多事</span>  
<span style="margin-left: 1em">頒行有待乃歲次甲申恭遇</span>  
聖朝建鼎本年八月一驗日食時刻分秒方位無差奉有  
<span style="margin-left: 1em">新法盡善盡美之　旨遂用新法造時憲書頒行天下</span>  
<span style="margin-left: 1em">天時人事巧相會合豈偶然哉時憲曆書<sub class="note-jiao">校：文淵本時憲曆書作算</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">書</sub>共計百卷覃思竭精黙符乾造理明數著度越前朝</span>  
<span style="margin-left: 1em">謹撮舉其凡概如左</span>  
<span style="margin-left: 2em">天地經緯</span>  
<span style="margin-left: 1em">天有經緯地亦有之蓋大地隨人所止依天頂以分四</span>  
<span style="margin-left: 1em">方東西爲經南北爲緯曆家不明各方經緯之度則無</span>  
<span style="margin-left: 1em">以知幅𢄙相距之數即所推太陽節氣與五星經度凌</span>  
<span style="margin-left: 1em">犯及交食時刻日食分數行之一方不能通之各方矣</span>  
<span style="margin-left: 1em">至于日出日入晝夜長短並準地緯定之方適于用須</span>  
<span style="margin-left: 1em">知天地經緯相應古云地方言其德耳</span>  
<span style="margin-left: 1em">地形實圓月食時闇虛之圓是其景也周偏生物戴履</span>  
<span style="margin-left: 1em">不殊各以覩日爲晝兩極下極寒以半載爲晝夜赤道</span>  
<span style="margin-left: 1em">下極暑以二分爲夏二至爲冬北行累日北星漸出南</span>  
<span style="margin-left: 1em">星漸沒由是推之形圓明矣大約二百五十里當天之</span>  
<span style="margin-left: 1em">一度經緯皆然</span>  
<span style="margin-left: 2em">諸曜異天</span>  
<span style="margin-left: 1em">諸曜各天高卑相距遠甚此創論也然有實驗姑舉二</span>  
<span style="margin-left: 1em">端一驗以測法試立表于此于一線上窺二星其距表</span>  
<span style="margin-left: 1em">正等而其射景則長短不等豈非高者長而卑者短乎</span>  
<span style="margin-left: 1em">一驗以視差設月與星在天實行同度人從地面視之</span>  
<span style="margin-left: 1em">皆有差分然月差一度有餘星差有少至數分者此何</span>  
<span style="margin-left: 1em">以故差少者高差多者卑也舊曆測驗不精認作同天</span>  
<span style="margin-left: 1em">爲誤匪小</span>  
<span style="margin-left: 2em">圜心不同</span>  
<span style="margin-left: 1em">太陽本圜與地不同心二心相距古今不等即加减亦</span>  
<span style="margin-left: 1em">異即今二百年後其數小變乃能測審差數以爲萬年</span>  
<span style="margin-left: 1em">通變之法舊法不知也</span>  
<span style="margin-left: 2em">蒙氣有差</span>  
<span style="margin-left: 1em">欲測七政經緯度分先須定本地之蒙氣差蓋地中時</span>  
<span style="margin-left: 1em">有游氣上騰其質輕微雖不能隱蔽天象却能映小爲</span>  
<span style="margin-left: 1em">大升卑爲高故日月出入人從地平上望之比于中天</span>  
<span style="margin-left: 1em">則大星座出入人從地平上望之比于中天則廣此映</span>  
<span style="margin-left: 1em">小爲大也定望日時地在日月之間人在地平無兩見</span>  
<span style="margin-left: 1em">之理而恒得兩見或日未西沒而已見月食于東日已</span>  
<span style="margin-left: 1em">東出而尚見月食于西或高山之上見日月出入以較</span>  
<span style="margin-left: 1em">曆家算定時刻每先升後墜此升卑爲高也且蒙氣又</span>  
<span style="margin-left: 1em">有厚薄有高下近水與浮虛之地氣盛則厚而高堅燥</span>  
<span style="margin-left: 1em">之地氣减則薄而下厚且高則映象愈大升像愈高薄</span>  
<span style="margin-left: 1em">且下則映像不甚大升像亦不甚高大約地勢不等氣</span>  
<span style="margin-left: 1em">勢亦不等故受蒙者其勢亦不等欲定日躔月離五星</span>  
<span style="margin-left: 1em">列宿等之緯度若非先定本地之蒙氣差終難密合也</span>  
<span style="margin-left: 2em">測算異古</span>  
<span style="margin-left: 1em">天氣渾圓其面與諸道相割所生三弧形不一而足乃</span>  
<span style="margin-left: 1em">古法測天惟以句股爲本用平立定三差總是平形豈</span>  
<span style="margin-left: 1em">能測圓又句與股交爲直角一遇斜角其法立窮新法</span>  
<span style="margin-left: 1em">測以天弧三角形算以割圓八線表是爲以圓齊圓遇</span>  
<span style="margin-left: 1em">直遇斜無往不合且其用甚大其法甚簡弧矢諸線乘</span>  
<span style="margin-left: 1em">除一次即得非若句股必須展轉商求累時方成一率</span>  
<span style="margin-left: 1em">也</span>  
<span style="margin-left: 2em">測算皆依黃道</span>  
<span style="margin-left: 1em">日行由黃道中線月與五星亦皆出入黃道內外不行</span>  
<span style="margin-left: 1em">赤道曆家測天若但用赤道儀所得經度宿次尚非本</span>  
<span style="margin-left: 1em">曜在天之宮次新法就其所得又通以黃赤通率表乃</span>  
<span style="margin-left: 1em">與天行密合且月星之距赤極古今不同而其距黃極</span>  
<span style="margin-left: 1em">則皆終古如一以此新法日月五星皆依黃道起算即</span>  
<span style="margin-left: 1em">恒星亦從黃極以定歲差</span>  
<span style="margin-left: 2em">改定諸應</span>  
<span style="margin-left: 1em">七政本行各分平實二行乃平行起算之根是即某曜</span>  
<span style="margin-left: 1em">某日時刻躔某宮之數其名爲應新法改定諸應悉從</span>  
<span style="margin-left: 1em">天聰二年戊辰前冬至後己卯日第一子正爲始</span>  
<span style="margin-left: 2em">節氣求真</span>  
<span style="margin-left: 1em">舊法平節氣非天上真節氣也蓋太陽之行有盈有縮</span>  
<span style="margin-left: 1em">而盈縮又各不等舊法平分氣策一十五萬二一八四</span>  
<span style="margin-left: 1em">三七五以爲歲周二十四分之一是以平數定節氣不</span>  
<span style="margin-left: 1em">免違天矣于是節氣之差或以時計或以日計至若春</span>  
<span style="margin-left: 1em">分則後天二日秋分則先天二日爲誤匪小新法悉皆</span>  
<span style="margin-left: 1em">改定</span>  
<span style="margin-left: 2em">盈縮真限</span>  
<span style="margin-left: 1em">歲實生于日躔由日輪之轂漸近地心其數浸消往曆</span>  
<span style="margin-left: 1em">强欲齊之今古不相通矣授時創立消長上考往古百</span>  
<span style="margin-left: 1em">年加一下驗將來百年减一此說爲近然而據算測天</span>  
<span style="margin-left: 1em">則又未合者須知日有最高最卑二點盈縮遲疾從此</span>  
<span style="margin-left: 1em">而生乃舊法以高卑二點泥在二至遂以二至爲盈縮</span>  
<span style="margin-left: 1em">之定限非也新法精詳測候見春分至立夏行四十五</span>  
<span style="margin-left: 1em">度有奇立秋至秋分亦行四十五度有奇其行度等而</span>  
<span style="margin-left: 1em">中間所曆時日不等又時日多寡世世不等即秋分至</span>  
<span style="margin-left: 1em">立冬立春至春分亦然因知日行最高卑度上古在二</span>  
<span style="margin-left: 1em">至前今世在二至後六度有奇則二至後六日乃真盈</span>  
<span style="margin-left: 1em">縮之限而沿守授時者猶從二至起算如此歲實安得</span>  
<span style="margin-left: 1em">齊也今用授時消分爲平歲更以最高卑差加减之爲</span>  
<span style="margin-left: 1em">定歲因計最高最卑之各一點每年自行四十五秒</span>  
<span style="margin-left: 2em">表測二分</span>  
<span style="margin-left: 1em">舊以圭表測冬至非法之善也蓋表景長短之差上應</span>  
<span style="margin-left: 1em">太陽南北之行顯則俱顯微則俱微二至前後三日內</span>  
<span style="margin-left: 1em">太陽一日南北行爲天度六十分之一設表長一丈冬</span>  
<span style="margin-left: 1em">至兩日之景約差一分三十秒準此細求之應差一秒</span>  
<span style="margin-left: 1em">爲六刻七分然而圭上一秒之差人目不能無誤且景</span>  
<span style="margin-left: 1em">符之光線較濶不止數秒一秒得六刻有奇如差三秒</span>  
<span style="margin-left: 1em">即爲二十刻矣又安所得準也新法獨用春秋二分蓋</span>  
<span style="margin-left: 1em">是時太陽一日南北行二十四分景差一寸二分縱令</span>  
<span style="margin-left: 1em">測差一二秒算不滿刻所差無幾較二至爲最密</span>  
<span style="margin-left: 2em">太陽出入及晨昏限</span>  
<span style="margin-left: 1em">諸方北極出地度數不同太陽出入時刻因以各別大</span>  
<span style="margin-left: 1em">統曆自永樂後造自燕都乃猶從江南起算且又執一</span>  
<span style="margin-left: 1em">方以槩天下則都城與諸方晝夜長短並與天違甚至</span>  
<span style="margin-left: 1em">日月東西帶食所測不合所算矣新法雖從京都起算</span>  
<span style="margin-left: 1em">而諸方各有加减然後各得真正時刻即論晨昏舊以</span>  
<span style="margin-left: 1em">二刻半爲限新以十八度爲限然而太陽行此十八度</span>  
<span style="margin-left: 1em">各宮又各不同因是有五刻七刻之別若北極出地七</span>  
<span style="margin-left: 1em">十二度以上之處則夏月晨昏相切雖至中夜亦未甚</span>  
<span style="margin-left: 1em">有黯黑也</span>  
<span style="margin-left: 2em">晝夜不等</span>  
<span style="margin-left: 1em">晝夜之分曆家皆從子午起算一歲行度日日不等其</span>  
<span style="margin-left: 1em">差較一刻有奇新法獨明其故有二一緣黃道夏遲冬</span>  
<span style="margin-left: 1em">疾差四分餘一緣黃赤二道廣狹不同距則率度必不</span>  
<span style="margin-left: 1em">同分也</span>  
<span style="margin-left: 2em">改定時刻</span>  
<span style="margin-left: 1em">晝夜定爲九十六刻蓋一晝一夜平分十有二時時各</span>  
<span style="margin-left: 1em">八刻積十二時爲九十六刻其于推算甚便舊增四刻</span>  
<span style="margin-left: 1em">凑成百數求整齊耳乃其分派百刻則謂每時八刻又</span>  
<span style="margin-left: 1em">三分之一則是每時有一奇零益爲繁瑣矣且舊法亦</span>  
<span style="margin-left: 1em">自知百刻之不適于用也其于推交食求時差分仍用</span>  
<span style="margin-left: 1em">九十六刻爲法定之則舊增四刻爲贅矣</span>  
<span style="margin-left: 2em">置閏不同</span>  
<span style="margin-left: 1em">餘氣歸終積而爲閏凡閏之月太陽之躔某宮先後會</span>  
<span style="margin-left: 1em">月者二是本月之內太陽不及交宮因無中氣遂置爲</span>  
<span style="margin-left: 1em">閏月乃舊法置閏用平節氣非也新法用太陽所躔天</span>  
<span style="margin-left: 1em">度之定節氣與舊不同</span>  
<span style="margin-left: 2em">太陰加减</span>  
<span style="margin-left: 1em">月與五星本輪之外皆有次輪所以行度益繁就月言</span>  
<span style="margin-left: 1em">之同心輪負本輪之心而右本輪又負次輪之心而左</span>  
<span style="margin-left: 1em">俱一周而復月復循次輪而右半周而復次輪半徑半</span>  
<span style="margin-left: 1em">于本輪半徑并之得五度弱爲二弦唯朔望月在本輪</span>  
<span style="margin-left: 1em">內規不須次輪加减止一加减已足餘日則于一加减</span>  
<span style="margin-left: 1em">外另有二三均數多寡不等</span>  
<span style="margin-left: 2em">月行高卑遲疾</span>  
<span style="margin-left: 1em">舊曆言太陰最高得疾最卑得遲且以圭表測而得之</span>  
<span style="margin-left: 1em">非也太陰遲疾是入轉內事表測高下是入交內事若</span>  
<span style="margin-left: 1em">云交即是轉緣何交終轉終兩率互異明是二法豈容</span>  
<span style="margin-left: 1em">混推以交道之高下爲轉率之遲疾也交轉既是二行</span>  
<span style="margin-left: 1em">而月行轉周之上又復左旋所以最高向西行則極遲</span>  
<span style="margin-left: 1em">最卑向東行乃極疾正與舊法相反五星高下遲疾亦</span>  
<span style="margin-left: 1em">皆準此</span>  
<span style="margin-left: 2em">朔後西見</span>  
<span style="margin-left: 1em">合朔以後月夕西見或遲或疾甚有差至三日者新法</span>  
<span style="margin-left: 1em">獨明其故有三一因月視行度視行爲疾段則疾見遲</span>  
<span style="margin-left: 1em">段則遲見一因黃道升降有斜有正正必疾見斜必遲</span>  
<span style="margin-left: 1em">見一因白道在緯南緯北凡在陰曆疾見陽曆遲見也</span>  
<span style="margin-left: 1em">此外又有北極出地不同之故并朦朧分與氣差諸異</span>  
<span style="margin-left: 1em">所以遲疾恒不能齊也</span>  
<span style="margin-left: 2em">交行加减</span>  
<span style="margin-left: 1em">正交中交行度古定一日逆行三分終古皆爲平行今</span>  
<span style="margin-left: 1em">細測之有時月在交上以平求之必不相合因設一加</span>  
<span style="margin-left: 1em">减爲交行均數</span>  
<span style="margin-left: 2em">月緯距度</span>  
<span style="margin-left: 1em">太陰緯度舊法以交食分數及交泛等測定黃白二道</span>  
<span style="margin-left: 1em">相距五度因以爲率不知朔望外距交尚有損益其至</span>  
<span style="margin-left: 1em">大之距計五度又三分之一也又遇一月兩食則二弦</span>  
<span style="margin-left: 1em">又須另用儀測方能審知距度幾何彼拘泥五度豈能</span>  
<span style="margin-left: 1em">合天</span>  
<span style="margin-left: 2em">交食有無</span>  
<span style="margin-left: 1em">交食有無惟于入交限定之入交適當交點必食即前</span>  
<span style="margin-left: 1em">後距點不遠亦食不則不食蓋距交近則其度狹狹則</span>  
<span style="margin-left: 1em">小于兩半徑故食距交遠則其度廣廣則月與景過而</span>  
<span style="margin-left: 1em">不相涉矣何食之有然此論交前後也又當論交左右</span>  
<span style="margin-left: 1em">視太陰與黃道之緯度相距幾何度分月食則以距度</span>  
<span style="margin-left: 1em">較月與景兩半徑并日食則以距度較日月兩半徑并</span>  
<span style="margin-left: 1em">而距度爲小則食若大則過而不相涉等則過而僅相</span>  
<span style="margin-left: 1em">切皆不得食也但距度在月爲實距度而在日爲視距</span>  
<span style="margin-left: 1em">度此則不同耳</span>  
<span style="margin-left: 2em">日月食限不同</span>  
<span style="margin-left: 1em">食限者日月行兩道各推其經度距交若干爲有食之</span>  
<span style="margin-left: 1em">始也然而日與月不同月食則太陰與地景相過兩周</span>  
<span style="margin-left: 1em">相切以其兩視半徑較白道距黃道度又以距度推交</span>  
<span style="margin-left: 1em">周度定食限若日食則雖太陽與太陰相遇兩周相切</span>  
<span style="margin-left: 1em">而其兩視半徑未可遂以之定兩道之距度爲有視差</span>  
<span style="margin-left: 1em">故必加入視差而後得距度因知特論半徑則日食之</span>  
<span style="margin-left: 1em">二徑狹月食之二徑廣論日食之限乃反大于月食之</span>  
<span style="margin-left: 1em">限以視差也</span>  
<span style="margin-left: 2em">日月食分異同</span>  
<span style="margin-left: 1em">食分多寡惟于距度定之距度在月食爲太陰心實距</span>  
<span style="margin-left: 1em">地景之心兩心愈近食分愈多愈遠則食分愈少矣在</span>  
<span style="margin-left: 1em">日食爲日月兩心之距距近食多距遠食少與月食同</span>  
<span style="margin-left: 1em">但日食不據實距而據視距蓋定朔爲實交會天下所</span>  
<span style="margin-left: 1em">同而人見食分多寡則東西南北各異所以然者皆視</span>  
<span style="margin-left: 1em">度所爲也</span>  
<span style="margin-left: 2em">實會中會以地心爲主</span>  
<span style="margin-left: 1em">實會者以地心所出直線上至黃道者爲主而日月五</span>  
<span style="margin-left: 1em">星兩居此線之上則實會也即南北相距非同一點而</span>  
<span style="margin-left: 1em">總在此線正對之過黃極圈亦爲實會蓋過黃極圈者</span>  
<span style="margin-left: 1em">過黃道之兩極而交會于黃道分黃道爲四直角者也</span>  
<span style="margin-left: 1em">則從旁視之雖地心各出一線南北異緯而從黃極視</span>  
<span style="margin-left: 1em">之即見地心所出二線東西同經是南北正對如一線</span>  
<span style="margin-left: 1em">也是故謂之實會若月與五星各居其本輪之周地心</span>  
<span style="margin-left: 1em">所出線上至黃道而兩本輪之心俱當此線之上則爲</span>  
<span style="margin-left: 1em">月與五星之中會日無本輪本行圈與地爲不同心兩</span>  
<span style="margin-left: 1em">心所出則有兩線此兩線者若爲平行線而月本輪之</span>  
<span style="margin-left: 1em">心正居地心線上則是日與月之中會也蓋實會既以</span>  
<span style="margin-left: 1em">地心線射太陰之體爲主則此地心線過小輪之心謂</span>  
<span style="margin-left: 1em">之中會矣若以不同心圈之平行線論之因日月各有</span>  
<span style="margin-left: 1em">本圈即本圈心皆與地心<sub class="note-yuan">即黃道心</sub>有相距之度分即日月</span>  
<span style="margin-left: 1em">循各本圈之周右行所過黃道經度必時時有差<sub class="note-yuan">與地不同</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">心故也</sub>其從地心出直線過日月之體上至黃道此所指</span>  
<span style="margin-left: 1em">者爲日月之實行度分也設從地心更出一平行直線</span>  
<span style="margin-left: 1em">與本圈心所出直線偕平行而上至黃道此所指者爲</span>  
<span style="margin-left: 1em">日月之平行度分也蓋太陽心線與地心一線平行太</span>  
<span style="margin-left: 1em">陰心線亦與地心一線平行但時多不相遇至相遇時</span>  
<span style="margin-left: 1em">兩地心線合爲一線則是日月之中相會若太陽實行</span>  
<span style="margin-left: 1em">之直線與太陰實行之直線合爲一線則是日月之實</span>  
<span style="margin-left: 1em">相會合會望會皆有中有實其理不異</span>  
<span style="margin-left: 2em">視會以地面爲主</span>  
<span style="margin-left: 1em">前言實會中會食限等皆日月食之公法也皆是準于</span>  
<span style="margin-left: 1em">地心然有視會新法所創也夫月食生于地景景生于</span>  
<span style="margin-left: 1em">日故天上之實食即人所見之視食無二食也日食不</span>  
<span style="margin-left: 1em">然有天上之實食有人所見之視食其食分之有無多</span>  
<span style="margin-left: 1em">寡兩各不同推步日食難于太陰者以此其推算視食</span>  
<span style="margin-left: 1em">則依人目與地面爲準蓋人目居地面之上與地心相</span>  
<span style="margin-left: 1em">距之差爲大地之半徑則所見之食與實食分兩直線</span>  
<span style="margin-left: 1em">各至宗動天各有所指度分是生視差而人目所見之</span>  
<span style="margin-left: 1em">食非實會也特爲視會</span>  
<span style="margin-left: 2em">黃道九十度爲東西差之中限</span>  
<span style="margin-left: 1em">地半徑三差恒垂向下但高卑差線以天頂爲宗下至</span>  
<span style="margin-left: 1em">地平爲直角南北差者變太陰距黃道之度以黃道極</span>  
<span style="margin-left: 1em">爲宗下至黃道爲直角東西差則黃道上弧也故論天</span>  
<span style="margin-left: 1em">頂則高卑差爲正下南北差爲斜下而東西差獨中限</span>  
<span style="margin-left: 1em">之一線爲正下一線以外或左或右皆斜下論黃道則</span>  
<span style="margin-left: 1em">南北差恒爲股東西差恒爲句高卑差恒爲弦至中限</span>  
<span style="margin-left: 1em">則股弦爲一線無句矣所謂中限者黃道出地平東西</span>  
<span style="margin-left: 1em">各九十度之限也舊法以子午圈爲中限新曆以黃道</span>  
<span style="margin-left: 1em">出地之最高度爲中限<sub class="note-yuan">東西各九十度即是最高</sub>兩法皆于中前减</span>  
<span style="margin-left: 1em">時差使視食先于實食皆于中後加時差使視食後于</span>  
<span style="margin-left: 1em">實食第所主中限不同則有宜多而少宜少而多或宜</span>  
<span style="margin-left: 1em">加反减宜减反加凡加時不得合天多緣于此</span>  
<span style="margin-left: 2em">三視差</span>  
<span style="margin-left: 1em">視會即實會者惟當天頂之一點爲然過此則以地半</span>  
<span style="margin-left: 1em">徑以日月距地之遠測太陽及太陰實有三種視差其</span>  
<span style="margin-left: 1em">法以地半徑爲一邊以太陽太陰各距地之遠爲一邊</span>  
<span style="margin-left: 1em">以二曜高度爲一邊成三角形用以得高卑差一也又</span>  
<span style="margin-left: 1em">偏南而變緯度得南北差二也以黃道九十度限偏左</span>  
<span style="margin-left: 1em">偏右而變經度得東西差三也因東西視差故太陽與</span>  
<span style="margin-left: 1em">太陰會有先後遲疾之變二曜之會在黃平象限度東</span>  
<span style="margin-left: 1em">即未得實會而先得視會若在黃平象限西則先得實</span>  
<span style="margin-left: 1em">會而後得視會所謂中前宜减中後宜加也因南北視</span>  
<span style="margin-left: 1em">差故太陰距度有廣狹食分有大小之變如人在夏至</span>  
<span style="margin-left: 1em">之北測太陰得南北視差即以加于太陰實距南度或</span>  
<span style="margin-left: 1em">以减于實距北度又東西南北兩視差皆以黃平象限</span>  
<span style="margin-left: 1em">爲主日距九十度限漸近東西差漸小南北差漸大近</span>  
<span style="margin-left: 1em">之極則無東西差而南北差與高卑差合爲一矣距九</span>  
<span style="margin-left: 1em">十度限漸遠南北差漸小東西差漸大遠之極則無南</span>  
<span style="margin-left: 1em">北差而東西差與高卑差又合爲一矣蓋三差恒爲句</span>  
<span style="margin-left: 1em">股形高卑其弦南北其股東西其句至極南則弦與股</span>  
<span style="margin-left: 1em">合至極東極西則弦與句合也</span>  
<span style="margin-left: 2em">外三差</span>  
<span style="margin-left: 1em">交食有東西南北高卑三差皆生于地徑然更有外三</span>  
<span style="margin-left: 1em">差不生于地徑而生于氣氣有輕重有厚薄各因時因</span>  
<span style="margin-left: 1em">地而三光之視度爲之變易一曰清蒙高差是近于地</span>  
<span style="margin-left: 1em">平爲地平所生清蒙之氣變易高下也二曰清蒙徑差</span>  
<span style="margin-left: 1em">亦因地上蒙氣而人目所見日徑之大小變易也三曰</span>  
<span style="margin-left: 1em">本氣徑差本氣者四行之一即素問所謂大氣地面以</span>  
<span style="margin-left: 1em">上月天以下充塞太空者是也此比清蒙氣更爲精微</span>  
<span style="margin-left: 1em">無有形質而亦能變易太陽之光照使目所見之視度</span>  
<span style="margin-left: 1em">隨地隨時小大不一也此外三差之義振古未聞近始</span>  
<span style="margin-left: 1em">得之然論交食至此于理爲盡矣</span>  
<span style="margin-left: 2em">虧復不一</span>  
<span style="margin-left: 1em">日食初虧復圓時刻多寡不一此非二時拆半之說也</span>  
<span style="margin-left: 1em">其故蓋在視差夫視差能變實行爲視行則用視差以</span>  
<span style="margin-left: 1em">較食甚前後不免參差又安能令視行前後同一乎新</span>  
<span style="margin-left: 1em">法直以視行推變時刻則初虧復圓時刻不一之故了</span>  
<span style="margin-left: 1em">然矣</span>  
<span style="margin-left: 2em">交食異算</span>  
<span style="margin-left: 1em">諸方各依地經推算交食時刻及日食分夫諸方所見</span>  
<span style="margin-left: 1em">日月出没及在天中各有前後不同即所得交食時刻</span>  
<span style="margin-left: 1em">互異日月二食皆同一理但日食又因視差隨地不一</span>  
<span style="margin-left: 1em">即太陰視距不一而所見食分亦因以判焉</span>  
<span style="margin-left: 2em">日食變差</span>  
<span style="margin-left: 1em">日食古來有推食不食者或算入限不真或夜食而誤</span>  
<span style="margin-left: 1em">爲晨夕此皆不足置論獨有據法應食而實不見食無</span>  
<span style="margin-left: 1em">可柰何遂云日度失行誣天甚矣朝臣有稱賀者罔上</span>  
<span style="margin-left: 1em">甚矣據新法變差而論必係此日此地之南北差變爲</span>  
<span style="margin-left: 1em">東西差故論天行則地心與日月兩心相參直實不失</span>  
<span style="margin-left: 1em">食而從人目所見則日月相距近變爲遠實不得食然</span>  
<span style="margin-left: 1em">惟此地爲然若在他方未必不漸見食并全見食也此</span>  
<span style="margin-left: 1em">亦千百年偶遇一二次非常有者也</span>  
<span style="margin-left: 2em">推前驗後</span>  
<span style="margin-left: 1em">交食之法上推往古下驗將來百千萬年當如指掌若</span>  
<span style="margin-left: 1em">悉用古法推步窮年累月不可得竟矣今用新法諸表</span>  
<span style="margin-left: 1em">遠遡唐虞下沿萬祀開卷瞭然不費功力如春秋以來</span>  
<span style="margin-left: 1em">有比月書食者有不書日不書朔者依法考求斷其是</span>  
<span style="margin-left: 1em">非定其日朔至易也又至當也至欲累求向後若干年</span>  
<span style="margin-left: 1em">應得若干食是皆不用全表但檢交周度表便可得之</span>  
<span style="margin-left: 2em">五星準日</span>  
<span style="margin-left: 1em">推算五星皆以太陽爲準其近太陽而伏則疾行其對</span>  
<span style="margin-left: 1em">太陽而衝則退行且太陽之行又遲疾不一則推五星</span>  
<span style="margin-left: 1em">宜于各本行外并太陽遲疾之行俱入算內始爲得之</span>  
<span style="margin-left: 1em">乃舊法于合伏日數時多時寡徒以本星段目定之故</span>  
<span style="margin-left: 1em">不免有差一二度者計日則或十日或半月矣新法改</span>  
<span style="margin-left: 1em">正</span>  
<span style="margin-left: 2em">伏見密合</span>  
<span style="margin-left: 1em">五星伏見各以距太陽之度分爲限顧舊法惟用黃道</span>  
<span style="margin-left: 1em">距度如謂太陽在降婁初度歲星在十五度即定爲見</span>  
<span style="margin-left: 1em">限非也須知五星有緯南緯北之分黃道又有正斜升</span>  
<span style="margin-left: 1em">降之勢各宫不同所以加减各異此理未明故有差至</span>  
<span style="margin-left: 1em">一二旬或一月甚且推見而實伏推伏而實見者新法</span>  
<span style="margin-left: 1em">改正</span>  
<span style="margin-left: 2em">五星緯度</span>  
<span style="margin-left: 1em">太陰本道斜交黃道因生距度與陰陽二曆即五星亦</span>  
<span style="margin-left: 1em">然五星相距緯度多寡不一而其斜交黃道莫不與月</span>  
<span style="margin-left: 1em">同理故其兩交亦曰正交中交其在南在北兩半周亦</span>  
<span style="margin-left: 1em">曰陰陽二曆從是各定加减方可合天又土木火三星</span>  
<span style="margin-left: 1em">衝太陽緯大合伏太陽緯小金水順伏緯小逆伏緯大</span>  
<span style="margin-left: 1em">新法一一詳求舊未能也</span>  
<span style="margin-left: 2em">金水伏見</span>  
<span style="margin-left: 1em">金星或合太陽而不伏水星離太陽而不見所以然者</span>  
<span style="margin-left: 1em">金緯甚大凡逆行緯在北七度餘而合太陽于壽星大</span>  
<span style="margin-left: 1em">火二宮則雖與日合其光不伏一日晨夕兩見者皆坐</span>  
<span style="margin-left: 1em">此故水緯僅四度餘設令緯向是南合太陽于壽星嗣</span>  
<span style="margin-left: 1em">後雖離四度夕猶不見也合太陽于降婁嗣後雖離四</span>  
<span style="margin-left: 1em">度晨猶不見也此二則用渾儀一測便見非舊法所能</span>  
<span style="margin-left: 1em">知也</span>  
<span style="margin-left: 2em">五星測法</span>  
<span style="margin-left: 1em">測五星須用恒星爲準測時用黃道儀或弧矢等儀將</span>  
<span style="margin-left: 1em">所測緯星視距二恒星若干度分依法布算乃得本星</span>  
<span style="margin-left: 1em">真經緯度分又或繪圈亦可免算</span>  
<span style="margin-left: 2em">恒星東移</span>  
<span style="margin-left: 1em">恒星以黃極爲極故各宿距星行度時近赤極亦或時</span>  
<span style="margin-left: 1em">遠赤極蓋行漸近極即赤極所出過距星線漸密而其</span>  
<span style="margin-left: 1em">本宿赤道弧較小行漸遠極即過距星線漸疎其本宿</span>  
<span style="margin-left: 1em">赤道弧則較大此由二道各極不同非距星有異行或</span>  
<span style="margin-left: 1em">易位也即如觜宿距星漢測距參二度唐測一度宋測</span>  
<span style="margin-left: 1em">一度迄半度元測五分今測之不啻無分且侵入參宿</span>  
<span style="margin-left: 1em">二十四分此其明驗也然其故至今日始明又宋時所</span>  
<span style="margin-left: 1em">定十二宮次各在某宿度今皆不然正因恒星有本行</span>  
<span style="margin-left: 1em">宿度已東移十餘度矣舊法未諳故所算日月五星過</span>  
<span style="margin-left: 1em">宮俱多舛錯新法改正</span>  
<span style="margin-left: 2em">繪星大備</span>  
<span style="margin-left: 1em">舊法繪星僅依河南見界即中國所見之星亦未全備</span>  
<span style="margin-left: 1em">新法周天皆有不但全備中國見界而已又新法所定</span>  
<span style="margin-left: 1em">二十八宿先後大小俱合天象其分恒星大小有六等</span>  
<span style="margin-left: 1em">之別前此未聞又依各星光測各星性爲天文占驗大</span>  
<span style="margin-left: 1em">用亦新法所創有也</span>  
<span style="margin-left: 2em">天漢破疑</span>  
<span style="margin-left: 1em">天漢斜絡天體與天異色昔稱雲漢疑爲白氣者非也</span>  
<span style="margin-left: 1em">新法測以遠鏡始知是無算小星攢聚成形即積尸氣</span>  
<span style="margin-left: 1em">等亦然足破從前謬解</span>  
<span style="margin-left: 2em">四餘删改</span>  
<span style="margin-left: 1em">羅㬋即白道之正交乃太陰自南遡北交于黃道之一</span>  
<span style="margin-left: 1em">點點有本行而羅㬋正對之點即爲計都即爲中交矣</span>  
<span style="margin-left: 1em">月孛乃月所行極高之點至此其行極遲孛者悖也謂</span>  
<span style="margin-left: 1em">其交轉兩行若相悖云爾乃從前日者之流指羅計月</span>  
<span style="margin-left: 1em">孛爲星謂其所躔宿度各有吉凶惑世誣民莫此爲甚</span>  
<span style="margin-left: 1em">至于紫氣一餘細考諸曜實無此種行度欲測候無象</span>  
<span style="margin-left: 1em">可明欲推算無數可定欲論述又無理可據明係前人</span>  
<span style="margin-left: 1em">妄増後人傅會今俱改删</span>  
<span style="margin-left: 2em">測器大備</span>  
<span style="margin-left: 1em">欲齊七政首重璣衡所藉以驗合改差者器也古曆尚</span>  
<span style="margin-left: 1em">有數種近代靈臺所存惟有圭表景符簡儀渾象等器</span>

<span style="margin-left: 1em">天環天球紀限儀渾蓋簡平儀黃赤全儀日星等晷諸</span>  
<span style="margin-left: 1em">器或用推諸曜或用審經緯或用測極或用求時盡皆</span>  
<span style="margin-left: 1em">精妙而其最巧最奇則所製遠鏡更爲窺天要具用之</span>
