## 崇祯历书卷之三十三　新法表异卷下

<span style="margin-left: 2em">新法表异卷下</span>  
<span style="margin-left: 1em">勅锡通微教师加二品通政使司通政使掌钦天监印务事臣汤若望著</span>  
<span style="margin-left: 2em">国朝</span>  
<span style="margin-left: 1em">前明自改历已来新法著闻于世久矣猥以国家多事</span>  
<span style="margin-left: 1em">颁行有待乃岁次甲申恭遇</span>  
圣朝建鼎本年八月一验日食时刻分秒方位无差奉有  
<span style="margin-left: 1em">新法尽善尽美之　旨遂用新法造时宪书颁行天下</span>  
<span style="margin-left: 1em">天时人事巧相会合岂偶然哉时宪历书<sub class="note-jiao">校：文淵本時憲曆書作算</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">书</sub>共计百卷覃思竭精黙符乾造理明数著度越前朝</span>  
<span style="margin-left: 1em">谨撮举其凡概如左</span>  
<span style="margin-left: 2em">天地经纬</span>  
<span style="margin-left: 1em">天有经纬地亦有之盖大地随人所止依天顶以分四</span>  
<span style="margin-left: 1em">方东西为经南北为纬历家不明各方经纬之度则无</span>  
<span style="margin-left: 1em">以知幅𢄙相距之数即所推太阳节气与五星经度凌</span>  
<span style="margin-left: 1em">犯及交食时刻日食分数行之一方不能通之各方矣</span>  
<span style="margin-left: 1em">至于日出日入昼夜长短并准地纬定之方适于用须</span>  
<span style="margin-left: 1em">知天地经纬相应古云地方言其德耳</span>  
<span style="margin-left: 1em">地形实圆月食时暗虚之圆是其景也周偏生物戴履</span>  
<span style="margin-left: 1em">不殊各以覩日为昼两极下极寒以半载为昼夜赤道</span>  
<span style="margin-left: 1em">下极暑以二分为夏二至为冬北行累日北星渐出南</span>  
<span style="margin-left: 1em">星渐没由是推之形圆明矣大约二百五十里当天之</span>  
<span style="margin-left: 1em">一度经纬皆然</span>  
<span style="margin-left: 2em">诸曜异天</span>  
<span style="margin-left: 1em">诸曜各天高卑相距远甚此创论也然有实验姑举二</span>  
<span style="margin-left: 1em">端一验以测法试立表于此于一线上窥二星其距表</span>  
<span style="margin-left: 1em">正等而其射景则长短不等岂非高者长而卑者短乎</span>  
<span style="margin-left: 1em">一验以视差设月与星在天实行同度人从地面视之</span>  
<span style="margin-left: 1em">皆有差分然月差一度有余星差有少至数分者此何</span>  
<span style="margin-left: 1em">以故差少者高差多者卑也旧历测验不精认作同天</span>  
<span style="margin-left: 1em">为误匪小</span>  
<span style="margin-left: 2em">圜心不同</span>  
<span style="margin-left: 1em">太阳本圜与地不同心二心相距古今不等即加减亦</span>  
<span style="margin-left: 1em">异即今二百年后其数小变乃能测审差数以为万年</span>  
<span style="margin-left: 1em">通变之法旧法不知也</span>  
<span style="margin-left: 2em">蒙气有差</span>  
<span style="margin-left: 1em">欲测七政经纬度分先须定本地之蒙气差盖地中时</span>  
<span style="margin-left: 1em">有游气上腾其质轻微虽不能隐蔽天象却能映小为</span>  
<span style="margin-left: 1em">大升卑为高故日月出入人从地平上望之比于中天</span>  
<span style="margin-left: 1em">则大星座出入人从地平上望之比于中天则广此映</span>  
<span style="margin-left: 1em">小为大也定望日时地在日月之间人在地平无两见</span>  
<span style="margin-left: 1em">之理而恒得两见或日未西没而已见月食于东日已</span>  
<span style="margin-left: 1em">东出而尚见月食于西或高山之上见日月出入以较</span>  
<span style="margin-left: 1em">历家算定时刻每先升后坠此升卑为高也且蒙气又</span>  
<span style="margin-left: 1em">有厚薄有高下近水与浮虚之地气盛则厚而高坚燥</span>  
<span style="margin-left: 1em">之地气减则薄而下厚且高则映象愈大升像愈高薄</span>  
<span style="margin-left: 1em">且下则映像不甚大升像亦不甚高大约地势不等气</span>  
<span style="margin-left: 1em">势亦不等故受蒙者其势亦不等欲定日躔月离五星</span>  
<span style="margin-left: 1em">列宿等之纬度若非先定本地之蒙气差终难密合也</span>  
<span style="margin-left: 2em">测算异古</span>  
<span style="margin-left: 1em">天气浑圆其面与诸道相割所生三弧形不一而足乃</span>  
<span style="margin-left: 1em">古法测天惟以句股为本用平立定三差总是平形岂</span>  
<span style="margin-left: 1em">能测圆又句与股交为直角一遇斜角其法立穷新法</span>  
<span style="margin-left: 1em">测以天弧三角形算以割圆八线表是为以圆齐圆遇</span>  
<span style="margin-left: 1em">直遇斜无往不合且其用甚大其法甚简弧矢诸线乘</span>  
<span style="margin-left: 1em">除一次即得非若句股必须展转商求累时方成一率</span>  
<span style="margin-left: 1em">也</span>  
<span style="margin-left: 2em">测算皆依黄道</span>  
<span style="margin-left: 1em">日行由黄道中线月与五星亦皆出入黄道内外不行</span>  
<span style="margin-left: 1em">赤道历家测天若但用赤道仪所得经度宿次尚非本</span>  
<span style="margin-left: 1em">曜在天之宫次新法就其所得又通以黄赤通率表乃</span>  
<span style="margin-left: 1em">与天行密合且月星之距赤极古今不同而其距黄极</span>  
<span style="margin-left: 1em">则皆终古如一以此新法日月五星皆依黄道起算即</span>  
<span style="margin-left: 1em">恒星亦从黄极以定岁差</span>  
<span style="margin-left: 2em">改定诸应</span>  
<span style="margin-left: 1em">七政本行各分平实二行乃平行起算之根是即某曜</span>  
<span style="margin-left: 1em">某日时刻躔某宫之数其名为应新法改定诸应悉从</span>  
<span style="margin-left: 1em">天聪二年戊辰前冬至后己卯日第一子正为始</span>  
<span style="margin-left: 2em">节气求真</span>  
<span style="margin-left: 1em">旧法平节气非天上真节气也盖太阳之行有盈有缩</span>  
<span style="margin-left: 1em">而盈缩又各不等旧法平分气策一十五万二一八四</span>  
<span style="margin-left: 1em">三七五以为岁周二十四分之一是以平数定节气不</span>  
<span style="margin-left: 1em">免违天矣于是节气之差或以时计或以日计至若春</span>  
<span style="margin-left: 1em">分则后天二日秋分则先天二日为误匪小新法悉皆</span>  
<span style="margin-left: 1em">改定</span>  
<span style="margin-left: 2em">盈缩真限</span>  
<span style="margin-left: 1em">岁实生于日躔由日轮之毂渐近地心其数浸消往历</span>  
<span style="margin-left: 1em">强欲齐之今古不相通矣授时创立消长上考往古百</span>  
<span style="margin-left: 1em">年加一下验将来百年减一此说为近然而据算测天</span>  
<span style="margin-left: 1em">则又未合者须知日有最高最卑二点盈缩迟疾从此</span>  
<span style="margin-left: 1em">而生乃旧法以高卑二点泥在二至遂以二至为盈缩</span>  
<span style="margin-left: 1em">之定限非也新法精详测候见春分至立夏行四十五</span>  
<span style="margin-left: 1em">度有奇立秋至秋分亦行四十五度有奇其行度等而</span>  
<span style="margin-left: 1em">中间所历时日不等又时日多寡世世不等即秋分至</span>  
<span style="margin-left: 1em">立冬立春至春分亦然因知日行最高卑度上古在二</span>  
<span style="margin-left: 1em">至前今世在二至后六度有奇则二至后六日乃真盈</span>  
<span style="margin-left: 1em">缩之限而沿守授时者犹从二至起算如此岁实安得</span>  
<span style="margin-left: 1em">齐也今用授时消分为平岁更以最高卑差加减之为</span>  
<span style="margin-left: 1em">定岁因计最高最卑之各一点每年自行四十五秒</span>  
<span style="margin-left: 2em">表测二分</span>  
<span style="margin-left: 1em">旧以圭表测冬至非法之善也盖表景长短之差上应</span>  
<span style="margin-left: 1em">太阳南北之行显则俱显微则俱微二至前后三日内</span>  
<span style="margin-left: 1em">太阳一日南北行为天度六十分之一设表长一丈冬</span>  
<span style="margin-left: 1em">至两日之景约差一分三十秒准此细求之应差一秒</span>  
<span style="margin-left: 1em">为六刻七分然而圭上一秒之差人目不能无误且景</span>  
<span style="margin-left: 1em">符之光线较濶不止数秒一秒得六刻有奇如差三秒</span>  
<span style="margin-left: 1em">即为二十刻矣又安所得准也新法独用春秋二分盖</span>  
<span style="margin-left: 1em">是时太阳一日南北行二十四分景差一寸二分纵令</span>  
<span style="margin-left: 1em">测差一二秒算不满刻所差无几较二至为最密</span>  
<span style="margin-left: 2em">太阳出入及晨昏限</span>  
<span style="margin-left: 1em">诸方北极出地度数不同太阳出入时刻因以各别大</span>  
<span style="margin-left: 1em">统历自永乐后造自燕都乃犹从江南起算且又执一</span>  
<span style="margin-left: 1em">方以槩天下则都城与诸方昼夜长短并与天违甚至</span>  
<span style="margin-left: 1em">日月东西带食所测不合所算矣新法虽从京都起算</span>  
<span style="margin-left: 1em">而诸方各有加减然后各得真正时刻即论晨昏旧以</span>  
<span style="margin-left: 1em">二刻半为限新以十八度为限然而太阳行此十八度</span>  
<span style="margin-left: 1em">各宫又各不同因是有五刻七刻之别若北极出地七</span>  
<span style="margin-left: 1em">十二度以上之处则夏月晨昏相切虽至中夜亦未甚</span>  
<span style="margin-left: 1em">有黯黑也</span>  
<span style="margin-left: 2em">昼夜不等</span>  
<span style="margin-left: 1em">昼夜之分历家皆从子午起算一岁行度日日不等其</span>  
<span style="margin-left: 1em">差较一刻有奇新法独明其故有二一缘黄道夏迟冬</span>  
<span style="margin-left: 1em">疾差四分余一缘黄赤二道广狭不同距则率度必不</span>  
<span style="margin-left: 1em">同分也</span>  
<span style="margin-left: 2em">改定时刻</span>  
<span style="margin-left: 1em">昼夜定为九十六刻盖一昼一夜平分十有二时时各</span>  
<span style="margin-left: 1em">八刻积十二时为九十六刻其于推算甚便旧增四刻</span>  
<span style="margin-left: 1em">凑成百数求整齐耳乃其分派百刻则谓每时八刻又</span>  
<span style="margin-left: 1em">三分之一则是每时有一奇零益为繁琐矣且旧法亦</span>  
<span style="margin-left: 1em">自知百刻之不适于用也其于推交食求时差分仍用</span>  
<span style="margin-left: 1em">九十六刻为法定之则旧增四刻为赘矣</span>  
<span style="margin-left: 2em">置闰不同</span>  
<span style="margin-left: 1em">余气归终积而为闰凡闰之月太阳之躔某宫先后会</span>  
<span style="margin-left: 1em">月者二是本月之内太阳不及交宫因无中气遂置为</span>  
<span style="margin-left: 1em">闰月乃旧法置闰用平节气非也新法用太阳所躔天</span>  
<span style="margin-left: 1em">度之定节气与旧不同</span>  
<span style="margin-left: 2em">太阴加减</span>  
<span style="margin-left: 1em">月与五星本轮之外皆有次轮所以行度益繁就月言</span>  
<span style="margin-left: 1em">之同心轮负本轮之心而右本轮又负次轮之心而左</span>  
<span style="margin-left: 1em">俱一周而复月复循次轮而右半周而复次轮半径半</span>  
<span style="margin-left: 1em">于本轮半径并之得五度弱为二弦唯朔望月在本轮</span>  
<span style="margin-left: 1em">内规不须次轮加减止一加减已足余日则于一加减</span>  
<span style="margin-left: 1em">外另有二三均数多寡不等</span>  
<span style="margin-left: 2em">月行高卑迟疾</span>  
<span style="margin-left: 1em">旧历言太阴最高得疾最卑得迟且以圭表测而得之</span>  
<span style="margin-left: 1em">非也太阴迟疾是入转内事表测高下是入交内事若</span>  
<span style="margin-left: 1em">云交即是转缘何交终转终两率互异明是二法岂容</span>  
<span style="margin-left: 1em">混推以交道之高下为转率之迟疾也交转既是二行</span>  
<span style="margin-left: 1em">而月行转周之上又复左旋所以最高向西行则极迟</span>  
<span style="margin-left: 1em">最卑向东行乃极疾正与旧法相反五星高下迟疾亦</span>  
<span style="margin-left: 1em">皆准此</span>  
<span style="margin-left: 2em">朔后西见</span>  
<span style="margin-left: 1em">合朔以后月夕西见或迟或疾甚有差至三日者新法</span>  
<span style="margin-left: 1em">独明其故有三一因月视行度视行为疾段则疾见迟</span>  
<span style="margin-left: 1em">段则迟见一因黄道升降有斜有正正必疾见斜必迟</span>  
<span style="margin-left: 1em">见一因白道在纬南纬北凡在阴历疾见阳历迟见也</span>  
<span style="margin-left: 1em">此外又有北极出地不同之故并朦胧分与气差诸异</span>  
<span style="margin-left: 1em">所以迟疾恒不能齐也</span>  
<span style="margin-left: 2em">交行加减</span>  
<span style="margin-left: 1em">正交中交行度古定一日逆行三分终古皆为平行今</span>  
<span style="margin-left: 1em">细测之有时月在交上以平求之必不相合因设一加</span>  
<span style="margin-left: 1em">减为交行均数</span>  
<span style="margin-left: 2em">月纬距度</span>  
<span style="margin-left: 1em">太阴纬度旧法以交食分数及交泛等测定黄白二道</span>  
<span style="margin-left: 1em">相距五度因以为率不知朔望外距交尚有损益其至</span>  
<span style="margin-left: 1em">大之距计五度又三分之一也又遇一月两食则二弦</span>  
<span style="margin-left: 1em">又须另用仪测方能审知距度几何彼拘泥五度岂能</span>  
<span style="margin-left: 1em">合天</span>  
<span style="margin-left: 2em">交食有无</span>  
<span style="margin-left: 1em">交食有无惟于入交限定之入交适当交点必食即前</span>  
<span style="margin-left: 1em">后距点不远亦食不则不食盖距交近则其度狭狭则</span>  
<span style="margin-left: 1em">小于两半径故食距交远则其度广广则月与景过而</span>  
<span style="margin-left: 1em">不相涉矣何食之有然此论交前后也又当论交左右</span>  
<span style="margin-left: 1em">视太阴与黄道之纬度相距几何度分月食则以距度</span>  
<span style="margin-left: 1em">较月与景两半径并日食则以距度较日月两半径并</span>  
<span style="margin-left: 1em">而距度为小则食若大则过而不相涉等则过而仅相</span>  
<span style="margin-left: 1em">切皆不得食也但距度在月为实距度而在日为视距</span>  
<span style="margin-left: 1em">度此则不同耳</span>  
<span style="margin-left: 2em">日月食限不同</span>  
<span style="margin-left: 1em">食限者日月行两道各推其经度距交若干为有食之</span>  
<span style="margin-left: 1em">始也然而日与月不同月食则太阴与地景相过两周</span>  
<span style="margin-left: 1em">相切以其两视半径较白道距黄道度又以距度推交</span>  
<span style="margin-left: 1em">周度定食限若日食则虽太阳与太阴相遇两周相切</span>  
<span style="margin-left: 1em">而其两视半径未可遂以之定两道之距度为有视差</span>  
<span style="margin-left: 1em">故必加入视差而后得距度因知特论半径则日食之</span>  
<span style="margin-left: 1em">二径狭月食之二径广论日食之限乃反大于月食之</span>  
<span style="margin-left: 1em">限以视差也</span>  
<span style="margin-left: 2em">日月食分异同</span>  
<span style="margin-left: 1em">食分多寡惟于距度定之距度在月食为太阴心实距</span>  
<span style="margin-left: 1em">地景之心两心愈近食分愈多愈远则食分愈少矣在</span>  
<span style="margin-left: 1em">日食为日月两心之距距近食多距远食少与月食同</span>  
<span style="margin-left: 1em">但日食不据实距而据视距盖定朔为实交会天下所</span>  
<span style="margin-left: 1em">同而人见食分多寡则东西南北各异所以然者皆视</span>  
<span style="margin-left: 1em">度所为也</span>  
<span style="margin-left: 2em">实会中会以地心为主</span>  
<span style="margin-left: 1em">实会者以地心所出直线上至黄道者为主而日月五</span>  
<span style="margin-left: 1em">星两居此线之上则实会也即南北相距非同一点而</span>  
<span style="margin-left: 1em">总在此线正对之过黄极圈亦为实会盖过黄极圈者</span>  
<span style="margin-left: 1em">过黄道之两极而交会于黄道分黄道为四直角者也</span>  
<span style="margin-left: 1em">则从旁视之虽地心各出一线南北异纬而从黄极视</span>  
<span style="margin-left: 1em">之即见地心所出二线东西同经是南北正对如一线</span>  
<span style="margin-left: 1em">也是故谓之实会若月与五星各居其本轮之周地心</span>  
<span style="margin-left: 1em">所出线上至黄道而两本轮之心俱当此线之上则为</span>  
<span style="margin-left: 1em">月与五星之中会日无本轮本行圈与地为不同心两</span>  
<span style="margin-left: 1em">心所出则有两线此两线者若为平行线而月本轮之</span>  
<span style="margin-left: 1em">心正居地心线上则是日与月之中会也盖实会既以</span>  
<span style="margin-left: 1em">地心线射太阴之体为主则此地心线过小轮之心谓</span>  
<span style="margin-left: 1em">之中会矣若以不同心圈之平行线论之因日月各有</span>  
<span style="margin-left: 1em">本圈即本圈心皆与地心<sub class="note-yuan">即黄道心</sub>有相距之度分即日月</span>  
<span style="margin-left: 1em">循各本圈之周右行所过黄道经度必时时有差<sub class="note-yuan">与地不同</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">心故也</sub>其从地心出直线过日月之体上至黄道此所指</span>  
<span style="margin-left: 1em">者为日月之实行度分也设从地心更出一平行直线</span>  
<span style="margin-left: 1em">与本圈心所出直线偕平行而上至黄道此所指者为</span>  
<span style="margin-left: 1em">日月之平行度分也盖太阳心线与地心一线平行太</span>  
<span style="margin-left: 1em">阴心线亦与地心一线平行但时多不相遇至相遇时</span>  
<span style="margin-left: 1em">两地心线合为一线则是日月之中相会若太阳实行</span>  
<span style="margin-left: 1em">之直线与太阴实行之直线合为一线则是日月之实</span>  
<span style="margin-left: 1em">相会合会望会皆有中有实其理不异</span>  
<span style="margin-left: 2em">视会以地面为主</span>  
<span style="margin-left: 1em">前言实会中会食限等皆日月食之公法也皆是准于</span>  
<span style="margin-left: 1em">地心然有视会新法所创也夫月食生于地景景生于</span>  
<span style="margin-left: 1em">日故天上之实食即人所见之视食无二食也日食不</span>  
<span style="margin-left: 1em">然有天上之实食有人所见之视食其食分之有无多</span>  
<span style="margin-left: 1em">寡两各不同推步日食难于太阴者以此其推算视食</span>  
<span style="margin-left: 1em">则依人目与地面为准盖人目居地面之上与地心相</span>  
<span style="margin-left: 1em">距之差为大地之半径则所见之食与实食分两直线</span>  
<span style="margin-left: 1em">各至宗动天各有所指度分是生视差而人目所见之</span>  
<span style="margin-left: 1em">食非实会也特为视会</span>  
<span style="margin-left: 2em">黄道九十度为东西差之中限</span>  
<span style="margin-left: 1em">地半径三差恒垂向下但高卑差线以天顶为宗下至</span>  
<span style="margin-left: 1em">地平为直角南北差者变太阴距黄道之度以黄道极</span>  
<span style="margin-left: 1em">为宗下至黄道为直角东西差则黄道上弧也故论天</span>  
<span style="margin-left: 1em">顶则高卑差为正下南北差为斜下而东西差独中限</span>  
<span style="margin-left: 1em">之一线为正下一线以外或左或右皆斜下论黄道则</span>  
<span style="margin-left: 1em">南北差恒为股东西差恒为句高卑差恒为弦至中限</span>  
<span style="margin-left: 1em">则股弦为一线无句矣所谓中限者黄道出地平东西</span>  
<span style="margin-left: 1em">各九十度之限也旧法以子午圈为中限新历以黄道</span>  
<span style="margin-left: 1em">出地之最高度为中限<sub class="note-yuan">东西各九十度即是最高</sub>两法皆于中前减</span>  
<span style="margin-left: 1em">时差使视食先于实食皆于中后加时差使视食后于</span>  
<span style="margin-left: 1em">实食第所主中限不同则有宜多而少宜少而多或宜</span>  
<span style="margin-left: 1em">加反减宜减反加凡加时不得合天多缘于此</span>  
<span style="margin-left: 2em">三视差</span>  
<span style="margin-left: 1em">视会即实会者惟当天顶之一点为然过此则以地半</span>  
<span style="margin-left: 1em">径以日月距地之远测太阳及太阴实有三种视差其</span>  
<span style="margin-left: 1em">法以地半径为一边以太阳太阴各距地之远为一边</span>  
<span style="margin-left: 1em">以二曜高度为一边成三角形用以得高卑差一也又</span>  
<span style="margin-left: 1em">偏南而变纬度得南北差二也以黄道九十度限偏左</span>  
<span style="margin-left: 1em">偏右而变经度得东西差三也因东西视差故太阳与</span>  
<span style="margin-left: 1em">太阴会有先后迟疾之变二曜之会在黄平象限度东</span>  
<span style="margin-left: 1em">即未得实会而先得视会若在黄平象限西则先得实</span>  
<span style="margin-left: 1em">会而后得视会所谓中前宜减中后宜加也因南北视</span>  
<span style="margin-left: 1em">差故太阴距度有广狭食分有大小之变如人在夏至</span>  
<span style="margin-left: 1em">之北测太阴得南北视差即以加于太阴实距南度或</span>  
<span style="margin-left: 1em">以减于实距北度又东西南北两视差皆以黄平象限</span>  
<span style="margin-left: 1em">为主日距九十度限渐近东西差渐小南北差渐大近</span>  
<span style="margin-left: 1em">之极则无东西差而南北差与高卑差合为一矣距九</span>  
<span style="margin-left: 1em">十度限渐远南北差渐小东西差渐大远之极则无南</span>  
<span style="margin-left: 1em">北差而东西差与高卑差又合为一矣盖三差恒为句</span>  
<span style="margin-left: 1em">股形高卑其弦南北其股东西其句至极南则弦与股</span>  
<span style="margin-left: 1em">合至极东极西则弦与句合也</span>  
<span style="margin-left: 2em">外三差</span>  
<span style="margin-left: 1em">交食有东西南北高卑三差皆生于地径然更有外三</span>  
<span style="margin-left: 1em">差不生于地径而生于气气有轻重有厚薄各因时因</span>  
<span style="margin-left: 1em">地而三光之视度为之变易一曰清蒙高差是近于地</span>  
<span style="margin-left: 1em">平为地平所生清蒙之气变易高下也二曰清蒙径差</span>  
<span style="margin-left: 1em">亦因地上蒙气而人目所见日径之大小变易也三曰</span>  
<span style="margin-left: 1em">本气径差本气者四行之一即素问所谓大气地面以</span>  
<span style="margin-left: 1em">上月天以下充塞太空者是也此比清蒙气更为精微</span>  
<span style="margin-left: 1em">无有形质而亦能变易太阳之光照使目所见之视度</span>

<span style="margin-left: 2em">亏复不一</span>  
<span style="margin-left: 1em">日食初亏复圆时刻多寡不一此非二时拆半之说也</span>  
<span style="margin-left: 1em">其故盖在视差夫视差能变实行为视行则用视差以</span>  
<span style="margin-left: 1em">较食甚前后不免参差又安能令视行前后同一乎新</span>  
<span style="margin-left: 1em">法直以视行推变时刻则初亏复圆时刻不一之故了</span>  
<span style="margin-left: 1em">然矣</span>  
<span style="margin-left: 2em">交食异算</span>  
<span style="margin-left: 1em">诸方各依地经推算交食时刻及日食分夫诸方所见</span>  
<span style="margin-left: 1em">日月出没及在天中各有前后不同即所得交食时刻</span>  
<span style="margin-left: 1em">互异日月二食皆同一理但日食又因视差随地不一</span>  
<span style="margin-left: 1em">即太阴视距不一而所见食分亦因以判焉</span>  
<span style="margin-left: 2em">日食变差</span>  
<span style="margin-left: 1em">日食古来有推食不食者或算入限不真或夜食而误</span>  
<span style="margin-left: 1em">为晨夕此皆不足置论独有据法应食而实不见食无</span>  
<span style="margin-left: 1em">可柰何遂云日度失行诬天甚矣朝臣有称贺者罔上</span>

<span style="margin-left: 1em">东西差故论天行则地心与日月两心相参直实不失</span>  
<span style="margin-left: 1em">食而从人目所见则日月相距近变为远实不得食然</span>  
<span style="margin-left: 1em">惟此地为然若在他方未必不渐见食并全见食也此</span>  
<span style="margin-left: 1em">亦千百年偶遇一二次非常有者也</span>  
<span style="margin-left: 2em">推前验后</span>  
<span style="margin-left: 1em">交食之法上推往古下验将来百千万年当如指掌若</span>

<span style="margin-left: 1em">远溯唐虞下沿万祀开卷了然不费功力如春秋以来</span>

<span style="margin-left: 2em">五星准日</span>

<span style="margin-left: 1em">五星伏见各以距太阳之度分为限顾旧法惟用黄道</span>

<span style="margin-left: 2em">五星纬度</span>  
<span style="margin-left: 1em">太阴本道斜交黄道因生距度与阴阳二历即五星亦</span>

<span style="margin-left: 1em">曰阴阳二历从是各定加减方可合天又土木火三星</span>

<span style="margin-left: 1em">测五星须用恒星为准测时用黄道仪或弧矢等仪将</span>

<span style="margin-left: 2em">四余删改</span>  
<span style="margin-left: 1em">罗㬋即白道之正交乃太阴自南溯北交于黄道之一</span>  
<span style="margin-left: 1em">点点有本行而罗㬋正对之点即为计都即为中交矣</span>

<span style="margin-left: 1em">欲齐七政首重玑衡所借以验合改差者器也古历尚</span>

<span style="margin-left: 1em">浑有平有全有隅其平而隅者较之浑而全者径广三</span>  
<span style="margin-left: 1em">倍分细十倍黄赤分器莫不精审旧法未能也</span>  
<span style="margin-left: 2em">日晷备用</span>  
<span style="margin-left: 1em">单论求时则晷为最准盖古法时牌不分方土为用最</span>  
<span style="margin-left: 1em">拙新法之创斯晷必预定各方北极出地之度以故随</span>  
<span style="margin-left: 1em">处可用且无拘垣壁正侧咸可制造或用罗针或不用</span>  
<span style="margin-left: 1em">罗针且又能于一面视太阳所躔节气宫次度分及定</span>  
<span style="margin-left: 1em">日之高度定黄道各时之出没其称最者则地平晷立</span>  
<span style="margin-left: 1em">晷百游晷通光晷等数种他若柱晷瓦晷碗晷十字晷</span>  
<span style="margin-left: 1em">等或正或欹之类不啻数十种而此外更有星晷及测</span>  
<span style="margin-left: 1em">月之器以为夜中测时之需云</span>
