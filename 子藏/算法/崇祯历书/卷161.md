## 崇禎曆書卷之一百六十一　渾天儀說卷一

<span style="margin-left: 1em">渾天用法序<sub class="note-jiao">校：據奎章閣本校錄</sub></span>  
<span style="margin-left: 2em">夫人戴天履地塊然中處至詢以三光之運行大塊</span>  
<span style="margin-left: 2em">所凝住或謙讓未遑焉乃亶其聰明至上下古今不</span>  
<span style="margin-left: 2em">可紀極之人物政事徽惡廢興靡不窮搜强識而誇</span>  
<span style="margin-left: 2em">淹貫顧於有生以來與我踵頂俱覆載精氣相維結</span>  
<span style="margin-left: 2em">光曜所煦照未能須臾離者輒委之若迂若誕鮮有</span>  
<span style="margin-left: 2em">過而問者抑獨何歟故參賛上矣次莫如知則夫晰</span>  
<span style="margin-left: 2em">其理者求其故考其數者步其行器固未可廢也而</span>  
<span style="margin-left: 2em">用斯要焉粤自堯欽曆數舜察璣衡是爲渾天鼻祖</span>  
<span style="margin-left: 2em">第其製久湮後人倣作如陶弘景類自兩極二道外</span>  
<span style="margin-left: 2em">罔所發明于適用蔑如也星球之製起于中古即甘</span>  
<span style="margin-left: 2em">石諸家無過以黃黑赤別其姓氏而星座僅取步天</span>  
<span style="margin-left: 2em">見界限于南極即仰參玄象尚多掛漏安問摶捖妙</span>  
<span style="margin-left: 2em">用而裨于曆數哉乃西儒道未湯先生味韶羅先生</span>  
<span style="margin-left: 2em">奉</span>  
<span style="margin-left: 1em">命修曆自遠來賓爰授法爲渾儀星球之製儀則設爲</span>  
<span style="margin-left: 2em">子午地平過極諸圈併黃赤而六焉且高弧時牌遊</span>  
<span style="margin-left: 2em">表以佐其用球則自見界羣星外凡有度可稽南極</span>  
<span style="margin-left: 2em">未考者莫不珠聯璧綴以補其遺而高弧時牌用同</span>  
<span style="margin-left: 2em">渾儀半圈則所獨焉其周天列曜斯犂然俱備矣道</span>  
<span style="margin-left: 2em">未先生又以用法未明無以詔來兹乃更闡其奥旨</span>  
<span style="margin-left: 2em">疏爲款列纚纚數萬餘言彙成五卷併儀球諸晷進</span>  
<span style="margin-left: 2em">呈</span>  
<span style="margin-left: 1em">御覽蒙</span>  
<span style="margin-left: 1em">勅靈臺諸臣進先生等於</span>  
<span style="margin-left: 1em">大內虛心講求焉仰見</span>  
<span style="margin-left: 1em">聖明之留神欽若真度超千古矣藩臣李子竊與共事</span>  
<span style="margin-left: 2em">讀其書而志怡神酣如濟川得舟撥雲見日而不能</span>  
<span style="margin-left: 2em">已於讃述也其提挈原始則乾象坤維總屬圓理是</span>  
<span style="margin-left: 2em">器也而道存其間矣縷分妙用則揆度定時不爽纖</span>  
<span style="margin-left: 2em">芒雖形也而神明其用矣攷究占驗則分宮起舍細</span>  
<span style="margin-left: 2em">抉玄微一旋轉之頃也而天人窮其藴矣要以北極</span>  
<span style="margin-left: 2em">高度立其基而凡以求黃赤之經緯諸曜之出没晝</span>  
<span style="margin-left: 2em">夜之永短五緯之見與伏各距之時與度至昧爽有</span>  
<span style="margin-left: 2em">時刻而交食有方位莫不取足於一掬之儀球而衆</span>  
<span style="margin-left: 2em">理咸備其爲用也顧不大哉且以勾股立算未能合</span>  
<span style="margin-left: 2em">天乃闡明圓線三角形以盡諸弧之變而洞交角之</span>  
<span style="margin-left: 2em">理尤信握籌而算無若按儀而考之爲便捷也又微</span>  
<span style="margin-left: 2em">乎其微矣至依法以製多形日晷特餘事耳大都先</span>  
<span style="margin-left: 2em">生之學窮天極地而中察人倫通三才之謂儒先生</span>  
<span style="margin-left: 2em">真其人哉故始則法天以制器若立其模繼乃因器</span>  
<span style="margin-left: 2em">以著用如啓其籥此籥啓而衆妙之門闢鉅之而行</span>  
<span style="margin-left: 2em">曆數稽災祥細之而推命理前民事其範圍無外而</span>  
<span style="margin-left: 2em">總不離此球儀之用爲機權耳真功侔參賛者乎而</span>  
<span style="margin-left: 2em">知不足言矣</span>  
<span style="margin-left: 1em">聖明方</span>  
<span style="margin-left: 1em">欽若昊天先生等應運而至將爲</span>  
<span style="margin-left: 1em">國家定非嘗之大典而垂無疆之寶曆余小子將聿觀</span>  
<span style="margin-left: 2em">厥成以免塊然之誚也先生之明德遠矣哉是爲序</span>  
<span style="margin-left: 2em">時</span>  
<span style="margin-left: 2em">崇禎九年日躔壽星之次</span>  
<span style="margin-left: 1em">督修曆法山東布政使司右參政李天經書于修曆公</span>  
<span style="margin-left: 2em">署</span>  
<span style="margin-left: 3em">渾天儀目錄</span>  
<span style="margin-left: 1em">日月諸星之行俱屬曆家専務因前累測之規即可定</span>  
<span style="margin-left: 2em">後應行若干度分或以算得或以儀器簡得此非一</span>  
<span style="margin-left: 2em">時一人之事已也蓋遍考古今前後所紀天行之度</span>  
<span style="margin-left: 2em">一一推入算中必至累黍不差然後繪圖製器以發</span>  
<span style="margin-left: 2em">明其所繇來因而設有多圈大小正斜各依本行自</span>  
<span style="margin-left: 2em">然之理逼真現前則但查本圈合成之儀而諸曜之</span>  
<span style="margin-left: 2em">或前或後或左或右視若指掌舉向之測與算或可</span>  
<span style="margin-left: 2em">不煩誠度數家至簡至妙之法也</span>  
<span style="margin-left: 2em">諸曜行有二等一晝夜一周此公行也即屬宗動遲</span>  
<span style="margin-left: 2em">速各行不等此自行也即屬諸曜之本行製儀者欲</span>  
<span style="margin-left: 2em">盡倣諸行非多設其制以盡其用不可乃有設一宗</span>  
<span style="margin-left: 2em">動以爲諸曜之歸而多種行度俱可并存其上則渾</span>  
<span style="margin-left: 2em">天儀是也儀之面本類宗動用之而經緯諸曜如在</span>  
<span style="margin-left: 2em">本天即黃赤二圈初未異于在下諸天所設之圈可</span>  
<span style="margin-left: 2em">槩見也</span>

<span style="margin-left: 3em">渾天儀圖</span>  
<span style="margin-left: 1em">古今儀有多種其間最公而易明者無如渾天儀蓋不</span>  
<span style="margin-left: 2em">獨以圓形象天且其所載諸象及諸圈悉存天上之</span>  
<span style="margin-left: 2em">象與圈凡大小遠近之比例但一設圈必與天上之</span>  
<span style="margin-left: 2em">圈應故同一渾形而分虛實兩等其實者以儀面當</span>  
<span style="margin-left: 2em">圓體圖列星或地于面上並顯黃赤兩道乃所借名</span>  
<span style="margin-left: 2em">曰天球地球者是其虛者特有其圈以聯絡黃赤二</span>  
<span style="margin-left: 2em">道等實圈爲法而中無實體外無球面猶存以公名</span>  
<span style="margin-left: 2em">曰渾天儀者是近或獨取其圈或圈與球合成一儀</span>  
<span style="margin-left: 2em">其分圈尚有大小有多寡然彼此約等故總圖之如</span>  
<span style="margin-left: 2em">左</span>  
<span style="margin-left: 16em">凡儀上諸圈因</span>  
<span style="margin-left: 16em">以顯諸曜之行</span>  
<span style="margin-left: 16em">者必分爲三百</span>  
<span style="margin-left: 16em">六十平度或盡</span>  
<span style="margin-left: 16em">書或止以一象</span>  
<span style="margin-left: 16em">限<sub class="note-yuan">九十度</sub>爲度其</span>  
<span style="margin-left: 16em">圈之大小則以</span>  
<span style="margin-left: 16em">所分平與不平</span>  
<span style="margin-left: 16em">有別大者必平</span>  
<span style="margin-left: 16em">分其儀體有六</span>  
<span style="margin-left: 2em">焉如兩道兩過極圈子午及地平圈而地平子午恆</span>  
<span style="margin-left: 2em">定不移小者即在大圈之左右與大圈爲平行原無</span>  
<span style="margin-left: 2em">定數任意多寡之惟以利用取規焉凡旋轉之圈俱</span>  
<span style="margin-left: 2em">貫入子午南北二處而承子午圈者地平也地平圈</span>  
<span style="margin-left: 2em">平置架上不動而子午圈則可上可下以應各方北</span>  
<span style="margin-left: 2em">極出地之度承架短柱任用幾端第須長短必等總</span>  
<span style="margin-left: 2em">期上爲極平以負地平耳架下設一羅針以審方位</span>  
<span style="margin-left: 2em">子午圈內安一時盤取本圈能切時刻詳見後製法</span>  
<span style="margin-left: 2em">中</span>  
<span style="margin-left: 3em">渾天儀之原</span>  
<span style="margin-left: 1em">一天爲大圓地實居其中心　天在最外能範圍乎萬</span>  
<span style="margin-left: 2em">物則必有最寬之界以容物于內其爲獨圓形也必</span>  
<span style="margin-left: 2em">矣且又旋轉不停動無滯礙恆如是而未嘗出乎其</span>  
<span style="margin-left: 2em">界猶得不謂之圓乎論其體之精微超越有形之美</span>  
<span style="margin-left: 2em">宜乎有形之物美好完全自與天體應總之以容以</span>  
<span style="margin-left: 2em">動以體俱足爲圓形之徴如此故分天體而爲日爲</span>  
<span style="margin-left: 2em">月爲星亦莫非圓形焉何也以到處所現之象無不</span>  
<span style="margin-left: 2em">具有圓體耳就其本行論之各曜在小輪上去離左</span>  
<span style="margin-left: 2em">右曾未變弧面而太陰太白俱有上下弦豈非圓形</span>  
<span style="margin-left: 2em">在中漸顯借日之光以爲完缺乎</span>  
<span style="margin-left: 2em">地在天之中心故天體旋轉恆半出地平上半在其</span>  
<span style="margin-left: 2em">下因知地未嘗偏左右也其晝夜長短無他原可徴</span>  
<span style="margin-left: 2em">獨見其夏之日冬之夜相較皆等或距春秋分前後</span>  
<span style="margin-left: 2em">兩日此所加必彼所減則距赤道內外必等因知地</span>  
<span style="margin-left: 2em">正居赤道圈下又未嘗偏內外矣試使地果不居天</span>  
<span style="margin-left: 2em">中何以太陰對日而望必相距半天而始食于地景</span>  
<span style="margin-left: 2em">乎何以四大原行中輕重諸物以去天遠近爲趨避</span>  
<span style="margin-left: 2em">之規乎<sub class="note-yuan">輕者求在上與天近愈輕愈就近矣重者求在下與天遠愈重愈遠而趨至中心矣今之</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">重物惟以倚地爲恆規而地豈不居天之中乎</sub></span>  
<span style="margin-left: 2em">或曰人視日月出沒似在其近處則在地平左右之</span>  
<span style="margin-left: 2em">天未必與天頂等曰人從此處視彼遠物之界必中</span>  
<span style="margin-left: 2em">有實體可以約畧其遠不然則遠近無從可得今自</span>  
<span style="margin-left: 2em">地平至日月出沒之界渾無實體以間之故若與天</span>  
<span style="margin-left: 2em">近且若與天接矣試令一人立河之東一人立河之</span>  
<span style="margin-left: 2em">西使從遠處視之祗覺兩人並立不復知兩人中尚</span>  
<span style="margin-left: 2em">有河焉因知人目視遠易亂而視天亦然故見恆星</span>  
<span style="margin-left: 2em">在地平與在天頂小大等其測之也則在地面如在</span>  
<span style="margin-left: 2em">地心此其故何哉蓋天之大地實無與之比且若不</span>  
<span style="margin-left: 2em">能分之一點焉雖距目遠近其差爲地半徑<sub class="note-yuan">約一萬五千里</sub></span>  
<span style="margin-left: 2em">而畢竟見與測了無異耳</span>  
<span style="margin-left: 1em">一天之旋行不一故設有多圈　天地共一心在萬有</span>  
<span style="margin-left: 2em">形物之中以過心之徑線爲樞以兩界至天上爲兩</span>  
<span style="margin-left: 2em">點乃其極之旋動無終始界夫距兩極愈遠勢愈寬</span>  
<span style="margin-left: 2em">而行愈速在上者能帶下以旋此宗動所原矣既爲</span>  
<span style="margin-left: 2em">宗動一切在下諸天隨之以行故以赤道之兩極爲</span>  
<span style="margin-left: 2em">共極而日月星所繇以出沒晝夜所繇以攸分也又</span>  
<span style="margin-left: 2em">在下諸天各有旋轉各有樞有極總依黃道南北極</span>  
<span style="margin-left: 2em">爲極因以見恆星及諸曜各有本行各行有遲速不</span>  
<span style="margin-left: 2em">等故上下設有多重次第布列而最上者爲宗動天</span>  
<span style="margin-left: 2em">經星天次之緯星天又次之太陽居其中土木火居</span>  
<span style="margin-left: 2em">其上金水月居其下若層叠包裹之也或不以右旋</span>  
<span style="margin-left: 2em">論本行而止設七政俱隨宗動左旋微有遲速不同</span>  
<span style="margin-left: 2em">焉則即以各行度不及滿一周天者以當本行其理</span>  
<span style="margin-left: 2em">一也</span>  
<span style="margin-left: 2em">或曰經緯諸星各有本行各行又自有異何從而知</span>  
<span style="margin-left: 2em">之曰以人目共足證也如日月五星彼此相離相近</span>  
<span style="margin-left: 2em">或在赤道內外隨時不一或距恆星與極遠近無定</span>  
<span style="margin-left: 2em">人雖至愚誰不見之則從此累測前後所得漸有其</span>  
<span style="margin-left: 2em">數反復推求大槩恆星七十年行一度與恆星稍近</span>  
<span style="margin-left: 2em">者爲土星三十年一周天次木星行十二年次火星</span>  
<span style="margin-left: 2em">二年次日次金水星俱一年下此則月也爲二十七</span>  
<span style="margin-left: 2em">日有奇而一周天蓋距地愈遠去宗動愈近得本行</span>  
<span style="margin-left: 2em">較遲而隨宗動反行速矣</span>  
<span style="margin-left: 1em">一天之旋動共歸二等惟宗動與本行而已　凡移物</span>  
<span style="margin-left: 2em">使動必以所至之限別之遠近遲速皆倚頼者也今</span>  
<span style="margin-left: 2em">天之旋行雖各遲速不同尚不至爲異類無可止限</span>  
<span style="margin-left: 2em">又天左右並行若相反而不害其爲異蓋緣黃赤二</span>  
<span style="margin-left: 2em">極不一故今依赤極左旋此在下諸天所同必二十</span>  
<span style="margin-left: 2em">四小時一周乃下以從上者正如舟行水面並渡所</span>  
<span style="margin-left: 2em">載之人使之與岸遠耳又依黃極右旋各天遲速不</span>  
<span style="margin-left: 2em">等故曰本行乃因下以逆上者正如舟本順流而行</span>  
<span style="margin-left: 2em">而所載之人則自舟首至尾爲退行耳試以玻璃瓶</span>  
<span style="margin-left: 2em">注水其中令在內之水右旋而却轉瓶左旋則必見</span>  
<span style="margin-left: 2em">水隨瓶轉而實已右旋矣是瓶其宗動之西行而水</span>  
<span style="margin-left: 2em">本向東者乃亦隨而西耳</span>  
<span style="margin-left: 1em">一地與海并渾得圓形　論東西圓即以諸曜出沒徴</span>  
<span style="margin-left: 2em">向使形非圓而或方或平面或多平面則凡居同面</span>  
<span style="margin-left: 2em">者宜同時見諸曜之東出而今不然也又或爲中凹</span>  
<span style="margin-left: 2em">形則在西先見者宜在東反後見乂或其面長圓如</span>  
<span style="margin-left: 2em">柱或三角等形面向東西底向南北則宜近兩極恆</span>  
<span style="margin-left: 2em">見與不恆見之星必到處皆同北方見北斗未入南</span>  
<span style="margin-left: 2em">方亦因之又或本形面向南北底向東西則亦宜諸</span>  
<span style="margin-left: 2em">星出沒盡面必同時而今俱不然也是除渾圓一形</span>  
<span style="margin-left: 2em">無能合諸曜東西行之景也</span>  
<span style="margin-left: 2em">論南北圓即以兩極出入徴設地爲平面或四平面</span>  
<span style="margin-left: 2em">方形或角平面等形則凡居同面者宜見此極出地</span>  
<span style="margin-left: 2em">之度與彼極入地之度遠近總如一設地南北中凹</span>  
<span style="margin-left: 2em">則宜距極近反見之低距極遠反見之高又設面爲</span>  
<span style="margin-left: 2em">長形即無異于前論而今亦不然也且于兩極高庳</span>  
<span style="margin-left: 2em">之度較于地面進退之廣有定比例而知地體必爲</span>  
<span style="margin-left: 2em">圓形無疑矣至若海附地以爲圓與地同理漂海者</span>  
<span style="margin-left: 2em">每見島從遠望之有若山巔漸近之而後知其爲島</span>  
<span style="margin-left: 2em">也是亦圓形之一徴也</span>  
<span style="margin-left: 2em">或曰地與海之圓亦各自爲圓形未必并爲一球曰</span>  
<span style="margin-left: 2em">合地與海爲一圓形即因月食之闇虛恆爲圓而知</span>  
<span style="margin-left: 2em">射景之體原不離乎圓也蓋大地與水共有向萬物</span>  
<span style="margin-left: 2em">中心之性必以其體相趨而就矣<sub class="note-yuan">地與水皆重物地中之空水即實之</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">故</sub>今見平原之中突出一山或疑地不就圓球而不</span>  
<span style="margin-left: 2em">知此無異于蟻遊麥場無從損地之形且地特以其</span>  
<span style="margin-left: 2em">大體肖球面耳豈真如車輪器物之渾圓毫無低昂</span>  
<span style="margin-left: 2em">處乎况其畧不就圓形者亦因其體之堅硬故耳</span>  
<span style="margin-left: 3em">隨天圓形地居中心之驗</span>  
<span style="margin-left: 1em">天以圓形包地在中心其驗有二其一爲諸星隨宗動</span>  
<span style="margin-left: 2em">繞地一周或在東西或正過天頂或偏南北其距地</span>  
<span style="margin-left: 2em">遠近恆如一人目視之時有大小疏密不同乃地之</span>  
<span style="margin-left: 2em">蒙氣使然非星之有遠近也即在天頂每較在地平</span>  
<span style="margin-left: 2em">更小者亦豎視橫視之間氣之多寡已耳其二天每</span>  
<span style="margin-left: 2em">半出地上半入地下蓋地居天之中正如一點而人</span>  
<span style="margin-left: 2em">目依地面周視之故無不得見其半乃所得之界即</span>  
<span style="margin-left: 2em">所謂地平是也地平之大圈以天頂爲極平分目所</span>  
<span style="margin-left: 2em">能視之天與不能視之天使正對南北二極以直角</span>  
<span style="margin-left: 2em">交赤道圈此名爲正渾儀依此體勢可當正球設使</span>  
<span style="margin-left: 2em">二極一在上一在下不以直角交赤道即名爲斜渾</span>  
<span style="margin-left: 2em">儀因之亦可當斜球也</span>  
<span style="margin-left: 2em">地平有二等一屬目人在地平面或海面周無所阻</span>  
<span style="margin-left: 2em">之物而目之見界及之即人可當中心周界爲圈約</span>  
<span style="margin-left: 2em">得半徑爲六十餘里此外不及見地而天已半出其</span>  
<span style="margin-left: 2em">上矣一屬心人在地與海之上雖四周無物以碍之</span>  
<span style="margin-left: 2em">而目力不能盡見天體止以諸曜之可見者顯其半</span>  
<span style="margin-left: 2em">出半入之理已耳蓋本圈定諸星出沒能見與否必</span>  
<span style="margin-left: 2em">分爲四象限而各象限得九十度則自正東及正西</span>  
<span style="margin-left: 2em">起至正南及正北止此子午圈之定位所繇分矣</span>  
<span style="margin-left: 2em">子午圈爲大圈必過天頂及赤道南北二極因而平</span>  
<span style="margin-left: 2em">分赤道等爲平行之小圈以之定正子午焉蓋以直</span>  
<span style="margin-left: 2em">道交地平本圈可當高弧亦可當緯度圈隨處以諸</span>  
<span style="margin-left: 2em">曜至中之高定赤道高與極出地高及諸星之緯度</span>  
<span style="margin-left: 2em">亦自較較不爽者</span>  
<span style="margin-left: 2em">又地平子午二圈當天外圈故不随天行轉而隨地</span>  
<span style="margin-left: 2em">每見地平各處不同子午除正南北外其餘方亦自</span>  
<span style="margin-left: 2em">不同且實無算今曆家祗記一度一圈其不同者共</span>  
<span style="margin-left: 2em">一百八十取其足用已耳而本儀僅僅一地平一子</span>  
<span style="margin-left: 2em">午蓋亦約畧諸圈而爲之用也</span>  
<span style="margin-left: 3em">隨宗動之驗</span>  
<span style="margin-left: 1em">渾儀倚南北極如樞一晝夜旋一周令諸星并行各爲</span>  
<span style="margin-left: 2em">圈大小不等各圈以極爲心自距極遠近又不等譬</span>  
<span style="margin-left: 2em">之車輪然其轂外之廣較輻中之狹遠近遲速皆異</span>  
<span style="margin-left: 2em">而其復于元處也則同試令去極最遠之處有星隨</span>  
<span style="margin-left: 2em">天行爲圈則較兩極左右之圈必大此即赤道圈也</span>  
<span style="margin-left: 2em">赤道平分天體相交于地平恆得半在上半在下自</span>  
<span style="margin-left: 2em">有其樞極亦皆與天地共一公樞極故有距天頂與</span>  
<span style="margin-left: 2em">本極出地等者則總得晝夜平矣其所以名宗動帶</span>  
<span style="margin-left: 2em">者亦因其正居兩極之中令渾天平分南北故也</span>  
<span style="margin-left: 2em">依赤道測宗動可定時刻蓋每一小時行十五度每</span>  
<span style="margin-left: 2em">二十四小時行天一周此終古不易之定法也雖太</span>  
<span style="margin-left: 2em">陽等曜順黃道行而黃道斜絡天上昇降亦不一又</span>  
<span style="margin-left: 2em">安所得諸曜出沒之限而齊之以定則哉故曰舍赤</span>  
<span style="margin-left: 2em">道別無可以測宗動也</span>  
<span style="margin-left: 2em">較諸星出沒之時于出沒之限亦惟距赤道北者在</span>  
<span style="margin-left: 2em">地平上之時多而在下少蓋距赤道愈遠則出愈早</span>  
<span style="margin-left: 2em">而沒愈遲其距赤道南者在地平上之時少而在下</span>  
<span style="margin-left: 2em">反多蓋在赤道之極南則出愈遲而沒愈早設一星</span>  
<span style="margin-left: 2em">距南一距北皆等則在北居地平上之時較在南居</span>  
<span style="margin-left: 2em">地平下之時必等反之而北居下南居上其時亦等</span>  
<span style="margin-left: 2em">惟在赤道上者則得見與不見之時等即得東西出</span>  
<span style="margin-left: 2em">入之處亦等總之星距赤道北或與極高之餘度等</span>  
<span style="margin-left: 2em">必不入地平距赤道南或亦與極高之餘度等亦必</span>  
<span style="margin-left: 2em">不出地平雖繞極而上下然相去卒不遠也此北斗</span>  
<span style="margin-left: 2em">之宿常見而老人星常隱者順天府極高使然也甚</span>  
<span style="margin-left: 2em">至數百年後恆星之本行已移南北之距度非故則</span>  
<span style="margin-left: 2em">前之不見者見前之不隱者隱或亦理勢之所必有</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 3em">隨本行之驗</span>  
<span style="margin-left: 1em">有謂諸曜依宗動每日西行其所不及滿一周天之度</span>  
<span style="margin-left: 2em">者即其本行<sub class="note-yuan">即蔡註謂日行繞地一周不及一度月不及十三度是也亦曰右行或東行</sub></span>  
<span style="margin-left: 2em">此解諸曜無兩種行度相反之理其說亦是但未詳</span>  
<span style="margin-left: 2em">本行之所以然蓋諸曜本行原不以正東正西與赤</span>  
<span style="margin-left: 2em">道平相距其斜迤赤道之上者時在內時在外而內</span>  
<span style="margin-left: 2em">與外又等則必更有一極以爲諸行之樞所謂黃道</span>  
<span style="margin-left: 2em">之極是也既極與道異于赤極赤道則東西二行自</span>  
<span style="margin-left: 2em">不相悖而諸曜右旋之名所繇來矣</span>  
<span style="margin-left: 2em">黃道爲大圈恆斜交赤道圈上而兩圈相交約得直</span>  
<span style="margin-left: 2em">角四之一雖古今相距較二道畧有變易而今實得</span>  
<span style="margin-left: 2em">二十三度三十一分三十秒因斜交名爲斜圈故以</span>  
<span style="margin-left: 2em">黃道爲七政本行之道太陽繇中道行以心随線名</span>  
<span style="margin-left: 2em">曰躔道乃依之每日行一度月五星常出入內外各</span>  
<span style="margin-left: 2em">距之不等各行遲速不等而相距最遠者爲金火二</span>  
<span style="margin-left: 2em">星約八度設南北共一十六度之廣者即全黃道也</span>  
<span style="margin-left: 2em">或有限其寬于十二度者則從三百六十度起見即</span>  
<span style="margin-left: 2em">一宮得一度之比例也又曰經周得十二宮應緯度</span>  
<span style="margin-left: 2em">寬十二度其理同也</span>  
<span style="margin-left: 2em">黃道交赤道正相對之點爲春秋二分其距赤道最</span>  
<span style="margin-left: 2em">遠亦正相對之點爲冬夏二至以四季分四象限各</span>  
<span style="margin-left: 2em">象限得九十度<sub class="note-yuan">或三宮</sub>黃極距赤道極亦如兩道最相</span>  
<span style="margin-left: 2em">距之極七政依此以行皆以距太陽爲會望遠近之</span>  
<span style="margin-left: 2em">序而其本行歸黃道與宗動歸赤道無異也古有以</span>  
<span style="margin-left: 2em">周天分十二宮一宮分三十度算在列宿天者蓋不</span>  
<span style="margin-left: 2em">知恆星有本行而今已東移如許矣因設一次宮曰</span>  
<span style="margin-left: 2em">從宗動天算</span>  
<span style="margin-left: 2em">或問分黃道十二宮何故曰太陰行黃道每歲十三</span>  
<span style="margin-left: 2em">轉其與太陽會合者惟十二次又各會合之處不同</span>  
<span style="margin-left: 2em">故分黃道爲十二宮也即如太陰行天一周約得二</span>  
<span style="margin-left: 2em">十八日其命爲二十八宿者大率繇此每宮分三十</span>  
<span style="margin-left: 2em">度者因太陽一日約行一度越三十日已過一宮是</span>  
<span style="margin-left: 2em">以總分三百六十度而大小諸圈悉依之也今諸星</span>  
<span style="margin-left: 6em">距黃道遠近命爲入某宮次者何曰曆家</span>  
<span style="margin-left: 6em">設黃極出圈線其過各宮初度自此極至</span>  
<span style="margin-left: 6em">彼極總爲十二半圈凡黃道上之星在彼</span>  
<span style="margin-left: 6em">此極中居圈內者曰入某宮如上圖設甲</span>  
<span style="margin-left: 2em">爲北極乙爲黃道自極過黃道半圈爲甲丙甲丁則</span>  
<span style="margin-left: 2em">星在丙與丁線之間任距黃道南北遠近必共入一</span>  
<span style="margin-left: 2em">宮矣</span>  
<span style="margin-left: 2em">十二宮或分南北即以赤道爲初末之限自降婁而</span>  
<span style="margin-left: 2em">大梁而實沈而鶉首而鶉火鶉尾爲北六宮自壽星</span>  
<span style="margin-left: 2em">而大火而析木而星紀而玄枵娵訾爲南六宮或以</span>  
<span style="margin-left: 2em">左右較分即冬夏二至爲初末之限自冬至迄春分</span>  
<span style="margin-left: 2em">爲行盈自夏至迄秋分爲行縮又或以正對宮度相</span>  
<span style="margin-left: 2em">較則北初宮與南初宮北末宮與南末宮得彼此距</span>  
<span style="margin-left: 2em">度加減之數必等</span>  
<span style="margin-left: 3em">太陽及太陰本行合宗動之驗</span>  
<span style="margin-left: 1em">太陽爲時日之原一日約東行一度于黃道爲正而于</span>  
<span style="margin-left: 2em">赤道恆爲斜或在兩道之交或北上或南下絕無定</span>  
<span style="margin-left: 2em">居故無一定之時此四季所繇以變易也迨加以宗</span>  
<span style="margin-left: 2em">動即見其出沒之廣不一晝夜之長短有變如日在</span>  
<span style="margin-left: 2em">降婁初度爲春分則出正東沒正西晝與夜皆等自</span>  
<span style="margin-left: 2em">此以往漸斜去赤道北出沒較前爲廣矣晝長而夜</span>  
<span style="margin-left: 2em">短至夏至爲最矣乃從夏至而退行一度其出其沒</span>  
<span style="margin-left: 2em">其晝其夜與前所得等漸退行漸與前等惟過秋分</span>  
<span style="margin-left: 2em">而太陽行赤道南則于前後相對宮度有定比例彼</span>  
<span style="margin-left: 2em">之所廣此之所狭彼之所長此之所短若相背而馳</span>  
<span style="margin-left: 2em">者然</span>  
<span style="margin-left: 2em">黃道上四點得太陽躔之爲春夏秋冬而即可當各</span>  
<span style="margin-left: 2em">時之極此過極圈所繇也乃過極圈有二一過兩極</span>  
<span style="margin-left: 2em">以并過春秋分爲極分交圈一過兩極以并過冬夏</span>  
<span style="margin-left: 2em">至爲極至交圈因而共當渾儀之脊骨蓋各與赤道</span>  
<span style="margin-left: 2em">以直角交即漸去內外至兩赤極之中亦自以直角</span>  
<span style="margin-left: 2em">相交則總得八三角形而各形之弧各成一象限各</span>  
<span style="margin-left: 2em">皆九十度因可以定太陽及諸曜距兩道內外之緯</span>  
<span style="margin-left: 2em">度又名緯度圈即兩道及兩道之極亦可以得相距</span>  
<span style="margin-left: 2em">度分</span>  
<span style="margin-left: 2em">太陰依本行随黃道約二十九日有奇而與太陽會</span>  
<span style="margin-left: 2em">故并論宗動則出沒之廣在地平上下之時皆從赤</span>  
<span style="margin-left: 2em">道緯倣太陽爲則且無本光借光于日因體厚不能</span>  
<span style="margin-left: 2em">透所借之光故依本行距日遠近不等有時顯全光</span>  
<span style="margin-left: 2em">有時少顯其光只至正相望而食于地景正相會而</span>  
<span style="margin-left: 2em">能自以其體掩日原光又依宗動使下地視之時有</span>  
<span style="margin-left: 2em">先後方位各異茲有本論聊述一二如此</span>  
<span style="margin-left: 3em">隨地圓形之驗</span>  
<span style="margin-left: 1em">曆家論地與海并爲圓形以應天上之經緯者何蓋每</span>  
<span style="margin-left: 2em">見日月交食東西時刻各先後不等此即地東西圓</span>  
<span style="margin-left: 2em">之驗夫時之先後取規于度在天十五度爲一小時</span>  
<span style="margin-left: 2em">在地亦然而大地彼此相距約二百五十里爲一度</span>  
<span style="margin-left: 2em">如西安府較順天府恆早二刻餘而見食其見諸曜</span>  
<span style="margin-left: 2em">出地平反遲二刻<sub class="note-yuan">東西相距八度半故</sub>因知地以圓體自掩諸</span>  
<span style="margin-left: 2em">曜之光使在東者先得之而徐及在西者耳非天旋</span>  
<span style="margin-left: 2em">之有異也又見各北極出地不同諸曜之在子午線</span>  
<span style="margin-left: 2em">上者距地遠近因之有異此即南北圓之驗夫極與</span>  
<span style="margin-left: 2em">諸星之高漸消或長必與里數相應如極高四十度</span>  
<span style="margin-left: 2em">南去一千里必下四度距天頂之南星反高起四度</span>  
<span style="margin-left: 2em">矣因知地以圓體或自低昂其南北各度之弧亦非</span>  
<span style="margin-left: 2em">極與星有異也</span>  
<span style="margin-left: 2em">論天總分三容渾儀亦倣之天有正有斜有平行設</span>  
<span style="margin-left: 2em">使南北極等赤道爲過頂圈則以直角交地平即爲</span>  
<span style="margin-left: 2em">正球得晝夜恆等諸曜之出沒或上或下恆如一蓋</span>  
<span style="margin-left: 2em">惟此天之容距赤道左右圈各自爲平分故諸星隨</span>  
<span style="margin-left: 2em">宗動之旋轉自等又使北極正居天頂以赤道合地</span>  
<span style="margin-left: 2em">平即爲平行球此則無晝夜之遞換亦無諸曜每日</span>  
<span style="margin-left: 7em">出沒之行惟太陽半年在地平上恆見</span>  
<span style="margin-left: 7em">不隱半年在地平下恆隱不見蓋以黃</span>  
<span style="margin-left: 7em">道斜交地平春秋二節令距北半圈者</span>  
<span style="margin-left: 7em">在上距南半圈者在下而距赤道南北</span>  
<span style="margin-left: 7em">平圈皆與地平爲平行故諸星居之亦</span>  
<span style="margin-left: 7em">平行又天下總屬南北二極或正居赤</span>  
<span style="margin-left: 7em">道下者少而在赤道左右兩極之間者</span>  
<span style="margin-left: 7em">多此不拘相距多寡即爲斜球蓋凡平</span>  
<span style="margin-left: 7em">行圈皆與地平爲斜切或多半在地平</span>  
<span style="margin-left: 7em">上少半在下或少半在上多半在下或</span>  
<span style="margin-left: 2em">去赤道向上極之圈以大半出向下極之圈以大半</span>  
<span style="margin-left: 2em">入蓋極愈高而上下之弧愈不平此即晝夜之所以</span>  
<span style="margin-left: 2em">異而諸曜自有其出沒之時近兩極處亦有恆見與</span>  
<span style="margin-left: 2em">恆不見之星所繇也</span>  
<span style="margin-left: 3em">渾天儀赤道平行圈</span>  
<span style="margin-left: 1em">前六圈者皆渾儀之大圈也乃更加小圈于赤道南北</span>  
<span style="margin-left: 2em">各二十三度有奇爲冬至晝短夜長圈夏至晝長夜</span>  
<span style="margin-left: 2em">短圈或再于二至圈之南北距赤道最遠而小以赤</span>  
<span style="margin-left: 2em">極爲心黃極爲界爲南北兩極圈此四圈并赤道圈</span>  
<span style="margin-left: 2em">分天與地共爲五帶中一帶乃赤道下也地甚熱在</span>  
<span style="margin-left: 2em">末之兩帶距赤道遠地反甚寒惟中末之間得煖氣</span>  
<span style="margin-left: 2em">四時不變萬物利于長養何者冬夏二至之圈限太</span>  
<span style="margin-left: 2em">陽繞地之界令其在圈內過頂恆分晝夜畧等太陽</span>  
<span style="margin-left: 2em">正照下地生熱南北兩極之圈限黃赤二極之距爲</span>  
<span style="margin-left: 10em">晝長出十二時之初界<sub class="note-yuan">在十二時內晝</sub></span>  
<span style="margin-left: 10em"><sub class="note-yuan">長之恆法惟南北極圈以往或太陽漸不入得晝爲一二日漸</sub></span>  
<span style="margin-left: 10em"><sub class="note-yuan">長至數月或漸不出得夜長如前故兩極圈爲晝長出十二時</sub></span>

<span style="margin-left: 10em">斜正照不甚偏得氣勢平故也</span>  
<span style="margin-left: 10em">如圖中爲赤道左右各二十二</span>

<span style="margin-left: 2em">之界又南北各餘二十三度至兩極下即末帶之界</span>  
<span style="margin-left: 2em">也古傳中末帶內寒暑過當誤謂人跡罕到而不知</span>  
<span style="margin-left: 2em">邇來大西人周行天下實見中帶人民甚衆風景不</span>  
<span style="margin-left: 2em">亞于他國雖晝夜平等而日之熱常消于夜之凉若</span>  
<span style="margin-left: 2em">末帶因未盡遊不得其詳然北帶內有青土在北諸</span>  
<span style="margin-left: 2em">國極高七十度外冬雖寒夏日之久足以補之其本</span>  
<span style="margin-left: 2em">儀不置此四圈者以黃極能限二赤極圈界而本道</span>  
<span style="margin-left: 2em">最距赤道之邊又能指二至圈即可當五帶云</span>  
<span style="margin-left: 3em">渾天儀增圈</span>  
<span style="margin-left: 1em">本儀內外增設者亦共四圈但在外者不必全圈一爲</span>  
<span style="margin-left: 2em">象限用當高弧上自天頂下至地平一爲半圈用當</span>  
<span style="margin-left: 2em">立象在子午圈之左右竪合子午倒合地平共當六</span>  
<span style="margin-left: 2em">圈古設此六圈皆在黃極中相交因名十二宮圈今</span>  
<span style="margin-left: 2em">設于子午交地平處平分赤道十二弧總黃道及渾</span>  
<span style="margin-left: 2em">天爲十二舍故名天容圈亦名立象圈本圈隨極出</span>  
<span style="margin-left: 2em">地各處不等全與地平同或起或伏順地平而東西</span>  
<span style="margin-left: 2em">地平乃一與七舍之初界子午圈當四與十焉其象</span>  
<span style="margin-left: 2em">限之高弧以直角交地平任游移安置過日月諸星</span>  
<span style="margin-left: 2em">之度故于本弧可求諸曜出地高度並黃平象限等</span>  
<span style="margin-left: 2em">用以螺旋安游表于天頂依各地平爲規儀內又置</span>  
<span style="margin-left: 2em">太陽本圈安黃道線下度分合黃道上內又一圈爲</span>  
<span style="margin-left: 2em">太陰本圈較太陽圈少斜依本行取則焉或南或北</span>  
<span style="margin-left: 2em">時時不一故有正交爲太陰往北之界有中交爲太</span>  
<span style="margin-left: 2em">陰往南之界而本圈依黃道旋其兩交之自行約十</span>  
<span style="margin-left: 2em">九年一周諸圈俱負本曜安黃樞上以顯二曜會望</span>  
<span style="margin-left: 2em">及互相照之理焉</span>  
<span style="margin-left: 3em">天球</span>  
<span style="margin-left: 1em">天球爲實面儀得大圈與前同惟極至極分兩圈可免</span>  
<span style="margin-left: 2em">以子午圈當之足矣儀面布列經星依本黃赤二道</span>  
<span style="margin-left: 2em">經緯度點定其不置緯星者因緯星遲速無定行且</span>  
<span style="margin-left: 2em">南北不一臨用以他色識之度分上可也論經星在</span>  
<span style="margin-left: 2em">七政上距地極遠彼此相距有定度終古如一故西</span>  
<span style="margin-left: 2em">曆名爲恆星而七政則游行如奕遂稱曰游星焉</span>  
<span style="margin-left: 2em">凡星行度距黃赤內外顯體質大小天下皆同其在</span>  
<span style="margin-left: 2em">天頂遠近分合座位立像命名或正照斜照紀數多</span>  
<span style="margin-left: 2em">寡天下皆異西曆依恆星本行以黃道爲天之中內</span>  
<span style="margin-left: 2em">外諸象總有六十經黃道者十二宮在內者二十一</span>  
<span style="margin-left: 2em">象餘皆在南或依本然模彷人物取其名或因性情</span>  
<span style="margin-left: 2em">類某人物而借名各象星数不等各星以所居體勢</span>  
<span style="margin-left: 2em">得稱古未詳南極之星止四十八象即盡西國之見</span>  
<span style="margin-left: 2em">界今本國人多遊赤道以南往往見南極下諸星因</span>  
<span style="margin-left: 2em">以兩極爲界增象得滿六十焉大統依見界紀星凡</span>  
<span style="margin-left: 2em">遠南極三十六度者<sub class="note-yuan">從中州爲見界</sub>俱不入圖總分爲三垣</span>  
<span style="margin-left: 2em">二十八宿二百八十餘座乃象與名天球因之其所</span>  
<span style="margin-left: 2em">占宮度則依經緯取則就中微渺難測從未定度分</span>  
<span style="margin-left: 2em">者悉去之而以近南極者補之得渾天之全圖焉學</span>  
<span style="margin-left: 2em">者欲識星當從七政始七政別于恆星約有三緣恆</span>  
<span style="margin-left: 2em">星多閃爍七政否恆星彼此有定距未嘗自爲那移</span>  
<span style="margin-left: 2em">七政總無定距亦無合轍之行恆星一仰視間恍若</span>  
<span style="margin-left: 2em">深邃七政目之如近且各易爲辨別如金星隨太陽</span>  
<span style="margin-left: 2em">前後出沒最遠爲四十八度體大而光異他星晝或</span>  
<span style="margin-left: 2em">可見木星次之色雖同體與光少殺距日遠近無限</span>  
<span style="margin-left: 2em">火星小而暗紅燁燁顫動與金木體色各別土星體</span>  
<span style="margin-left: 2em">與火等色青而光滯行動最遲水星光耀似金星色</span>  
<span style="margin-left: 2em">稍紅體質獨小更近太陽前後焉</span>  
<span style="margin-left: 2em">恆星大小凡六等積氣易識以色論有黃如北河白</span>  
<span style="margin-left: 2em">如狼星紅如心宿大星青如老人星以光論有盛如</span>  
<span style="margin-left: 2em">五車微如虛宿中等如畢宿大星或以芒角閃爍論</span>  
<span style="margin-left: 2em">有閃多如南河閃少如軒轅大星中等如左肩如玉</span>  
<span style="margin-left: 2em">井大星以形象論如南北斗其象似斗貫索得圓形</span>  
<span style="margin-left: 2em">天津似弓勾陳大星<sub class="note-yuan">今當北極</sub>體雖小周無他星可比總</span>  
<span style="margin-left: 2em">之各依本象本度圖之球上與天體脗合焉</span>  
<span style="margin-left: 3em">地球</span>  
<span style="margin-left: 1em">地球倣地之原形必爲圓面儀其得大圈與天球同惟</span>  
<span style="margin-left: 2em">黃道地上無定處故可不用夫天球因二十八宿而</span>  
<span style="margin-left: 2em">以南北引圈線過各宿距星則地球亦因子午線有</span>  
<span style="margin-left: 2em">先後以引其圈乃東西任距十度或十五度而南北</span>  
<span style="margin-left: 2em">各作小圈與赤道爲平行以顯南北之距焉古西士</span>  
<span style="margin-left: 2em">紀東西地經一百八十度極西爲福島極東爲日本</span>  
<span style="margin-left: 2em">紀南北地緯約八十度極南爲利未亞月山極北爲</span>  
<span style="margin-left: 2em">都力乃謂大地總當一島在北冰海南印度海及大</span>  
<span style="margin-left: 2em">東與大西洋之中此外似無地矣今則不然三百年</span>  
<span style="margin-left: 2em">以來漂海者恆繞利未亞之渾洲至過其赤道極南</span>  
<span style="margin-left: 2em">之地爲大浪山距赤道外三十五度復繞北至新增</span>  
<span style="margin-left: 2em">辣距赤道內七十八度又徑過日本東西繞地一周</span>  
<span style="margin-left: 2em">尋得新洲南北各大塊中以小峡接連總較古所識</span>  
<span style="margin-left: 2em">東西地約等雖南極下未及登岸不詳其內境然順</span>  
<span style="margin-left: 2em">濱而行似亦無所不經矣</span>  
<span style="margin-left: 2em">天設圈有大小每圈俱分爲三百六十度則凡數等</span>  
<span style="margin-left: 2em">而圈之大小度之廣狭因之乃地亦依此爲則故地</span>  
<span style="margin-left: 2em">上依六圈行則凡度相應之里數等依小圈亦有廣</span>  
<span style="margin-left: 2em">狹如距赤道四十度平行圈下之里數較赤道正下</span>  
<span style="margin-left: 2em">之里數必少若距六十七十等之平行圈尤少則求</span>  
<span style="margin-left: 2em">地周里數若干以大圈爲準而左右小圈惟以距中</span>  
<span style="margin-left: 2em">遠近推相當之比例焉里之長短各國所用雖異其</span>  
<span style="margin-left: 2em">實終同西國有十五里一度者有十七里半又二十</span>  
<span style="margin-left: 2em">二里又六十里者古謂五百里應一度波斯國算十</span>  
<span style="margin-left: 2em">六里阿辣比五十里莫卧爾三十五里印度以大牛</span>  
<span style="margin-left: 2em">鳴聲所至爲一里不知一度應幾許牛鳴矣至大明</span>  
<span style="margin-left: 2em">則約二百五十里爲一度周地總得九萬餘里乃量</span>  
<span style="margin-left: 2em">里有定則古今所同如論古小里一百弓爲一里四</span>  
<span style="margin-left: 2em">肘爲一弓二十四橫指爲一肘四橫麥粒爲一指欲</span>  
<span style="margin-left: 2em">以步求里則應一百二十步爲一里步依幾何法每</span>  
<span style="margin-left: 2em">得五脚一脚約十六橫指</span>  
<span style="margin-left: 2em">西國人步行或漂海者累考南北直路上一度下所</span>  
<span style="margin-left: 2em">應里數當如前外以日景查對如日輪占本圜若干</span>  
<span style="margin-left: 2em">其地面正應之下立竪晷必無景今使日在夏至全</span>  
<span style="margin-left: 2em">徑爲三十分占本圜七百二十分之一地面亦應大</span>  
<span style="margin-left: 2em">圈七百二十分之一立表無景古查定同時無表景</span>  
<span style="margin-left: 2em">之地徑寬二百五十餘小里故以二百五十乘七百</span>  
<span style="margin-left: 2em">二十得十八萬即地周行之里數也大明輿地圖以</span>  
<span style="margin-left: 2em">方格限里數查自順天府至應天府二千二百里至</span>  
<span style="margin-left: 2em">杭州府二千七百里至南昌府三千里至廣州府四</span>  
<span style="margin-left: 2em">千八百里因前後北極出地差度乃求每度應里數</span>  
<span style="margin-left: 2em">若干如應天府較京師差八度南昌差十一度以二</span>  
<span style="margin-left: 2em">百七十二里推一度杭州差十度則用二百七十里</span>  
<span style="margin-left: 2em">廣州差十七度則用二百八十二里所推里數畧不</span>  
<span style="margin-left: 2em">合者或測極高未必確而查竪晷無景亦未必定故</span>  
<span style="margin-left: 2em">止以二百五十小里約計之可也若折中多寡以二</span>  
<span style="margin-left: 2em">百七十里論當得九萬七千二百爲地球一周之里</span>  
<span style="margin-left: 2em">數置零數不用尚有九萬餘里</span>  
<span style="margin-left: 2em">渾天儀不置五帶內中末之四圈而地球則異是蓋</span>  
<span style="margin-left: 2em">居地不同處多以其四圈爲時變天勢地境異同之</span>  
<span style="margin-left: 2em">界先以日景分別之在中帶內者得兩日景時射景</span>  
<span style="margin-left: 2em">正北時射正南在中末界間者得單日景必恆射北</span>  
<span style="margin-left: 2em">或射南在末界內者得轉景恆旋繞無定向是也其</span>  
<span style="margin-left: 2em">居中帶赤道下者因得正天必見諸星出沒晝夜皆</span>  
<span style="margin-left: 2em">平太陽去回兩過其天頂每年有兩夏兩冬<sub class="note-yuan">一去一來故有</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">兩冬夏</sub>雖至冬不寒樹不脱葉居本帶邊如夏至下者</span>  
<span style="margin-left: 2em">以北極圈爲恆見反以南極爲不見之界此二界間</span>  
<span style="margin-left: 2em">之星<sub class="note-yuan">除在赤道下者</sub>得見與不見之異晝夜爲不平太陽惟</span>  
<span style="margin-left: 2em">在夏至則過天頂餘皆偏南總得一冬一夏居中末</span>  
<span style="margin-left: 2em">帶間者最得斜天經星恆多不沒晝夜愈不平太陽</span>  
<span style="margin-left: 2em">恆偏南其二至一冬一夏爲定然居本帶之北者得</span>  
<span style="margin-left: 2em">自北極至夏至圈之星恆不沒日躔夏至乃得晝長</span>  
<span style="margin-left: 2em">十二大時躔冬至反得夜長十二大時晝夜甚不平</span>  
<span style="margin-left: 2em">太陽多偏南止躔夏至之時近地平即如偏北也居</span>  
<span style="margin-left: 2em">北極正下者得竪天以赤道爲地平故以赤道爲見</span>  
<span style="margin-left: 2em">星之界在北者恆見在南者恆不得見六越月爲一</span>  
<span style="margin-left: 2em">晝六越月爲一夜無夏天止太陽行北時得寒氣少</span>  
<span style="margin-left: 2em">退耳凡此皆居赤道以北之境也居南者亦然惟得</span>  
<span style="margin-left: 2em">正相反之序如此爲冬彼爲夏此晝長彼夜長此景</span>  
<span style="margin-left: 2em">在北彼景在南故耳</span>  
<span style="margin-left: 2em">以赤道距平行之圈取方向之異同大約分二等或</span>  
<span style="margin-left: 2em">并得子午與平行圈同居赤道南北亦同惟相距之</span>  
<span style="margin-left: 2em">界在赤道正相反之處此大西與大明則然必得四</span>  
<span style="margin-left: 2em">季皆同晝夜長短如一惟日月諸星出沒先後之時</span>  
<span style="margin-left: 2em">不同耳或獨得子午圈同而平行圈之南北相距等</span>  
<span style="margin-left: 2em">其距界以赤道爲限此大明與馬力肚<sub class="note-yuan">南極地國</sub>則然得</span>  
<span style="margin-left: 2em">午正與子正皆同出沒之時爲異四季晝夜長短恆</span>  
<span style="margin-left: 2em">相反此冬彼爲夏此晝長彼夜長又或獨得子午圈</span>  
<span style="margin-left: 2em">同而平行距圈與赤道之距界正相反此即大明與</span>  
<span style="margin-left: 2em">大東銀河之較也得地平同但因天頂相反故四季</span>  
<span style="margin-left: 2em">與晝夜出沒等時恆互異如圖甲乙皆在赤道之北</span>  
<span style="margin-left: 2em">屬第一等甲丙一在北一在南屬第二等甲丁在正</span>

<span style="margin-left: 2em">漸長之刻定界如夏日長二刻即設一圈長四刻設</span>  
<span style="margin-left: 2em">第二圈以此遞設之必皆以太陽距春秋分內外漸</span>

<span style="margin-left: 6em">序初得度多而時少後得時多而度少如</span>  
<span style="margin-left: 6em">上圖外圈爲子午圈中引直線者皆赤道</span>
