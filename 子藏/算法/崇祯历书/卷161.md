## 崇祯历书卷之一百六十一　浑天仪说卷一

<span style="margin-left: 1em">浑天用法序<sub class="note-jiao">校：據奎章閣本校錄</sub></span>  
<span style="margin-left: 2em">夫人戴天履地块然中处至询以三光之运行大块</span>  
<span style="margin-left: 2em">所凝住或谦让未遑焉乃亶其聪明至上下古今不</span>  
<span style="margin-left: 2em">可纪极之人物政事徽恶废兴靡不穷搜强识而夸</span>  
<span style="margin-left: 2em">淹贯顾于有生以来与我踵顶俱覆载精气相维结</span>  
<span style="margin-left: 2em">光曜所煦照未能须臾离者辄委之若迂若诞鲜有</span>  
<span style="margin-left: 2em">过而问者抑独何欤故参賛上矣次莫如知则夫晰</span>  
<span style="margin-left: 2em">其理者求其故考其数者步其行器固未可废也而</span>  
<span style="margin-left: 2em">用斯要焉粤自尧钦历数舜察玑衡是为浑天鼻祖</span>  
<span style="margin-left: 2em">第其制久湮后人倣作如陶弘景类自两极二道外</span>  
<span style="margin-left: 2em">罔所发明于适用蔑如也星球之制起于中古即甘</span>  
<span style="margin-left: 2em">石诸家无过以黄黑赤别其姓氏而星座仅取步天</span>  
<span style="margin-left: 2em">见界限于南极即仰参玄象尚多挂漏安问抟捖妙</span>  
<span style="margin-left: 2em">用而裨于历数哉乃西儒道未汤先生味韶罗先生</span>  
<span style="margin-left: 2em">奉</span>  
<span style="margin-left: 1em">命修历自远来宾爰授法为浑仪星球之制仪则设为</span>  
<span style="margin-left: 2em">子午地平过极诸圈并黄赤而六焉且高弧时牌游</span>  
<span style="margin-left: 2em">表以佐其用球则自见界群星外凡有度可稽南极</span>  
<span style="margin-left: 2em">未考者莫不珠联璧缀以补其遗而高弧时牌用同</span>  
<span style="margin-left: 2em">浑仪半圈则所独焉其周天列曜斯犂然俱备矣道</span>  
<span style="margin-left: 2em">未先生又以用法未明无以诏来兹乃更阐其奥旨</span>  
<span style="margin-left: 2em">疏为款列纚纚数万余言汇成五卷并仪球诸晷进</span>  
<span style="margin-left: 2em">呈</span>  
<span style="margin-left: 1em">御览蒙</span>  
<span style="margin-left: 1em">勅灵台诸臣进先生等于</span>  
<span style="margin-left: 1em">大内虚心讲求焉仰见</span>  
<span style="margin-left: 1em">圣明之留神钦若真度超千古矣藩臣李子窃与共事</span>  
<span style="margin-left: 2em">读其书而志怡神酣如济川得舟拨云见日而不能</span>  
<span style="margin-left: 2em">已于讃述也其提挈原始则乾象坤维总属圆理是</span>  
<span style="margin-left: 2em">器也而道存其间矣缕分妙用则揆度定时不爽纤</span>  
<span style="margin-left: 2em">芒虽形也而神明其用矣攷究占验则分宫起舍细</span>  
<span style="margin-left: 2em">抉玄微一旋转之顷也而天人穷其蕴矣要以北极</span>  
<span style="margin-left: 2em">高度立其基而凡以求黄赤之经纬诸曜之出没昼</span>  
<span style="margin-left: 2em">夜之永短五纬之见与伏各距之时与度至昧爽有</span>  
<span style="margin-left: 2em">时刻而交食有方位莫不取足于一掬之仪球而众</span>  
<span style="margin-left: 2em">理咸备其为用也顾不大哉且以勾股立算未能合</span>  
<span style="margin-left: 2em">天乃阐明圆线三角形以尽诸弧之变而洞交角之</span>  
<span style="margin-left: 2em">理尤信握筹而算无若按仪而考之为便捷也又微</span>  
<span style="margin-left: 2em">乎其微矣至依法以制多形日晷特余事耳大都先</span>  
<span style="margin-left: 2em">生之学穷天极地而中察人伦通三才之谓儒先生</span>  
<span style="margin-left: 2em">真其人哉故始则法天以制器若立其模继乃因器</span>  
<span style="margin-left: 2em">以著用如启其籥此籥启而众妙之门辟巨之而行</span>  
<span style="margin-left: 2em">历数稽灾祥细之而推命理前民事其范围无外而</span>  
<span style="margin-left: 2em">总不离此球仪之用为机权耳真功侔参賛者乎而</span>  
<span style="margin-left: 2em">知不足言矣</span>

<span style="margin-left: 3em">浑天仪目录</span>  
<span style="margin-left: 1em">日月诸星之行俱属历家専务因前累测之规即可定</span>  
<span style="margin-left: 2em">后应行若干度分或以算得或以仪器简得此非一</span>  
<span style="margin-left: 2em">时一人之事已也盖遍考古今前后所纪天行之度</span>  
<span style="margin-left: 2em">一一推入算中必至累黍不差然后绘图制器以发</span>  
<span style="margin-left: 2em">明其所繇来因而设有多圈大小正斜各依本行自</span>  
<span style="margin-left: 2em">然之理逼真现前则但查本圈合成之仪而诸曜之</span>  
<span style="margin-left: 2em">或前或后或左或右视若指掌举向之测与算或可</span>  
<span style="margin-left: 2em">不烦诚度数家至简至妙之法也</span>  
<span style="margin-left: 2em">诸曜行有二等一昼夜一周此公行也即属宗动迟</span>  
<span style="margin-left: 2em">速各行不等此自行也即属诸曜之本行制仪者欲</span>  
<span style="margin-left: 2em">尽倣诸行非多设其制以尽其用不可乃有设一宗</span>  
<span style="margin-left: 2em">动以为诸曜之归而多种行度俱可并存其上则浑</span>  
<span style="margin-left: 2em">天仪是也仪之面本类宗动用之而经纬诸曜如在</span>  
<span style="margin-left: 2em">本天即黄赤二圈初未异于在下诸天所设之圈可</span>

<span style="margin-left: 3em">浑天仪图</span>  
<span style="margin-left: 1em">古今仪有多种其间最公而易明者无如浑天仪盖不</span>  
<span style="margin-left: 2em">独以圆形象天且其所载诸象及诸圈悉存天上之</span>  
<span style="margin-left: 2em">象与圈凡大小远近之比例但一设圈必与天上之</span>  
<span style="margin-left: 2em">圈应故同一浑形而分虚实两等其实者以仪面当</span>  
<span style="margin-left: 2em">圆体图列星或地于面上并显黄赤两道乃所借名</span>  
<span style="margin-left: 2em">曰天球地球者是其虚者特有其圈以联络黄赤二</span>  
<span style="margin-left: 2em">道等实圈为法而中无实体外无球面犹存以公名</span>  
<span style="margin-left: 2em">曰浑天仪者是近或独取其圈或圈与球合成一仪</span>  
<span style="margin-left: 2em">其分圈尚有大小有多寡然彼此约等故总图之如</span>  
<span style="margin-left: 2em">左</span>  
<span style="margin-left: 16em">凡仪上诸圈因</span>  
<span style="margin-left: 16em">以显诸曜之行</span>  
<span style="margin-left: 16em">者必分为三百</span>  
<span style="margin-left: 16em">六十平度或尽</span>  
<span style="margin-left: 16em">书或止以一象</span>

<span style="margin-left: 16em">有别大者必平</span>  
<span style="margin-left: 16em">分其仪体有六</span>  
<span style="margin-left: 2em">焉如两道两过极圈子午及地平圈而地平子午恒</span>  
<span style="margin-left: 2em">定不移小者即在大圈之左右与大圈为平行原无</span>  
<span style="margin-left: 2em">定数任意多寡之惟以利用取规焉凡旋转之圈俱</span>  
<span style="margin-left: 2em">贯入子午南北二处而承子午圈者地平也地平圈</span>  
<span style="margin-left: 2em">平置架上不动而子午圈则可上可下以应各方北</span>  
<span style="margin-left: 2em">极出地之度承架短柱任用几端第须长短必等总</span>  
<span style="margin-left: 2em">期上为极平以负地平耳架下设一罗针以审方位</span>  
<span style="margin-left: 2em">子午圈内安一时盘取本圈能切时刻详见后制法</span>  
<span style="margin-left: 2em">中</span>  
<span style="margin-left: 3em">浑天仪之原</span>  
<span style="margin-left: 1em">一天为大圆地实居其中心　天在最外能范围乎万</span>  
<span style="margin-left: 2em">物则必有最宽之界以容物于内其为独圆形也必</span>  
<span style="margin-left: 2em">矣且又旋转不停动无滞碍恒如是而未尝出乎其</span>  
<span style="margin-left: 2em">界犹得不谓之圆乎论其体之精微超越有形之美</span>  
<span style="margin-left: 2em">宜乎有形之物美好完全自与天体应总之以容以</span>  
<span style="margin-left: 2em">动以体俱足为圆形之徴如此故分天体而为日为</span>  
<span style="margin-left: 2em">月为星亦莫非圆形焉何也以到处所现之象无不</span>  
<span style="margin-left: 2em">具有圆体耳就其本行论之各曜在小轮上去离左</span>  
<span style="margin-left: 2em">右曾未变弧面而太阴太白俱有上下弦岂非圆形</span>  
<span style="margin-left: 2em">在中渐显借日之光以为完缺乎</span>  
<span style="margin-left: 2em">地在天之中心故天体旋转恒半出地平上半在其</span>  
<span style="margin-left: 2em">下因知地未尝偏左右也其昼夜长短无他原可徴</span>  
<span style="margin-left: 2em">独见其夏之日冬之夜相较皆等或距春秋分前后</span>  
<span style="margin-left: 2em">两日此所加必彼所减则距赤道内外必等因知地</span>  
<span style="margin-left: 2em">正居赤道圈下又未尝偏内外矣试使地果不居天</span>  
<span style="margin-left: 2em">中何以太阴对日而望必相距半天而始食于地景</span>  
<span style="margin-left: 2em">乎何以四大原行中轻重诸物以去天远近为趋避</span>  
<span style="margin-left: 2em">之规乎<sub class="note-yuan">轻者求在上与天近愈轻愈就近矣重者求在下与天远愈重愈远而趋至中心矣今之</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">重物惟以倚地为恒规而地岂不居天之中乎</sub></span>  
<span style="margin-left: 2em">或曰人视日月出没似在其近处则在地平左右之</span>  
<span style="margin-left: 2em">天未必与天顶等曰人从此处视彼远物之界必中</span>  
<span style="margin-left: 2em">有实体可以约畧其远不然则远近无从可得今自</span>  
<span style="margin-left: 2em">地平至日月出没之界浑无实体以间之故若与天</span>  
<span style="margin-left: 2em">近且若与天接矣试令一人立河之东一人立河之</span>  
<span style="margin-left: 2em">西使从远处视之祗觉两人并立不复知两人中尚</span>  
<span style="margin-left: 2em">有河焉因知人目视远易乱而视天亦然故见恒星</span>  
<span style="margin-left: 2em">在地平与在天顶小大等其测之也则在地面如在</span>  
<span style="margin-left: 2em">地心此其故何哉盖天之大地实无与之比且若不</span>  
<span style="margin-left: 2em">能分之一点焉虽距目远近其差为地半径<sub class="note-yuan">约一万五千里</sub></span>  
<span style="margin-left: 2em">而毕竟见与测了无异耳</span>  
<span style="margin-left: 1em">一天之旋行不一故设有多圈　天地共一心在万有</span>  
<span style="margin-left: 2em">形物之中以过心之径线为枢以两界至天上为两</span>  
<span style="margin-left: 2em">点乃其极之旋动无终始界夫距两极愈远势愈宽</span>  
<span style="margin-left: 2em">而行愈速在上者能带下以旋此宗动所原矣既为</span>  
<span style="margin-left: 2em">宗动一切在下诸天随之以行故以赤道之两极为</span>  
<span style="margin-left: 2em">共极而日月星所繇以出没昼夜所繇以攸分也又</span>  
<span style="margin-left: 2em">在下诸天各有旋转各有枢有极总依黄道南北极</span>  
<span style="margin-left: 2em">为极因以见恒星及诸曜各有本行各行有迟速不</span>  
<span style="margin-left: 2em">等故上下设有多重次第布列而最上者为宗动天</span>  
<span style="margin-left: 2em">经星天次之纬星天又次之太阳居其中土木火居</span>  
<span style="margin-left: 2em">其上金水月居其下若层叠包裹之也或不以右旋</span>  
<span style="margin-left: 2em">论本行而止设七政俱随宗动左旋微有迟速不同</span>  
<span style="margin-left: 2em">焉则即以各行度不及满一周天者以当本行其理</span>  
<span style="margin-left: 2em">一也</span>  
<span style="margin-left: 2em">或曰经纬诸星各有本行各行又自有异何从而知</span>  
<span style="margin-left: 2em">之曰以人目共足证也如日月五星彼此相离相近</span>  
<span style="margin-left: 2em">或在赤道内外随时不一或距恒星与极远近无定</span>  
<span style="margin-left: 2em">人虽至愚谁不见之则从此累测前后所得渐有其</span>  
<span style="margin-left: 2em">数反复推求大槩恒星七十年行一度与恒星稍近</span>  
<span style="margin-left: 2em">者为土星三十年一周天次木星行十二年次火星</span>  
<span style="margin-left: 2em">二年次日次金水星俱一年下此则月也为二十七</span>  
<span style="margin-left: 2em">日有奇而一周天盖距地愈远去宗动愈近得本行</span>  
<span style="margin-left: 2em">较迟而随宗动反行速矣</span>  
<span style="margin-left: 1em">一天之旋动共归二等惟宗动与本行而已　凡移物</span>  
<span style="margin-left: 2em">使动必以所至之限别之远近迟速皆倚頼者也今</span>  
<span style="margin-left: 2em">天之旋行虽各迟速不同尚不至为异类无可止限</span>  
<span style="margin-left: 2em">又天左右并行若相反而不害其为异盖缘黄赤二</span>  
<span style="margin-left: 2em">极不一故今依赤极左旋此在下诸天所同必二十</span>  
<span style="margin-left: 2em">四小时一周乃下以从上者正如舟行水面并渡所</span>  
<span style="margin-left: 2em">载之人使之与岸远耳又依黄极右旋各天迟速不</span>  
<span style="margin-left: 2em">等故曰本行乃因下以逆上者正如舟本顺流而行</span>  
<span style="margin-left: 2em">而所载之人则自舟首至尾为退行耳试以玻璃瓶</span>  
<span style="margin-left: 2em">注水其中令在内之水右旋而却转瓶左旋则必见</span>  
<span style="margin-left: 2em">水随瓶转而实已右旋矣是瓶其宗动之西行而水</span>  
<span style="margin-left: 2em">本向东者乃亦随而西耳</span>  
<span style="margin-left: 1em">一地与海并浑得圆形　论东西圆即以诸曜出没徴</span>  
<span style="margin-left: 2em">向使形非圆而或方或平面或多平面则凡居同面</span>  
<span style="margin-left: 2em">者宜同时见诸曜之东出而今不然也又或为中凹</span>  
<span style="margin-left: 2em">形则在西先见者宜在东反后见乂或其面长圆如</span>  
<span style="margin-left: 2em">柱或三角等形面向东西底向南北则宜近两极恒</span>  
<span style="margin-left: 2em">见与不恒见之星必到处皆同北方见北斗未入南</span>  
<span style="margin-left: 2em">方亦因之又或本形面向南北底向东西则亦宜诸</span>  
<span style="margin-left: 2em">星出没尽面必同时而今俱不然也是除浑圆一形</span>  
<span style="margin-left: 2em">无能合诸曜东西行之景也</span>  
<span style="margin-left: 2em">论南北圆即以两极出入徴设地为平面或四平面</span>  
<span style="margin-left: 2em">方形或角平面等形则凡居同面者宜见此极出地</span>  
<span style="margin-left: 2em">之度与彼极入地之度远近总如一设地南北中凹</span>  
<span style="margin-left: 2em">则宜距极近反见之低距极远反见之高又设面为</span>  
<span style="margin-left: 2em">长形即无异于前论而今亦不然也且于两极高庳</span>  
<span style="margin-left: 2em">之度较于地面进退之广有定比例而知地体必为</span>  
<span style="margin-left: 2em">圆形无疑矣至若海附地以为圆与地同理漂海者</span>  
<span style="margin-left: 2em">每见岛从远望之有若山巅渐近之而后知其为岛</span>  
<span style="margin-left: 2em">也是亦圆形之一徴也</span>  
<span style="margin-left: 2em">或曰地与海之圆亦各自为圆形未必并为一球曰</span>  
<span style="margin-left: 2em">合地与海为一圆形即因月食之暗虚恒为圆而知</span>  
<span style="margin-left: 2em">射景之体原不离乎圆也盖大地与水共有向万物</span>  
<span style="margin-left: 2em">中心之性必以其体相趋而就矣<sub class="note-yuan">地与水皆重物地中之空水即实之</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">故</sub>今见平原之中突出一山或疑地不就圆球而不</span>  
<span style="margin-left: 2em">知此无异于蚁游麦场无从损地之形且地特以其</span>  
<span style="margin-left: 2em">大体肖球面耳岂真如车轮器物之浑圆毫无低昂</span>  
<span style="margin-left: 2em">处乎况其畧不就圆形者亦因其体之坚硬故耳</span>  
<span style="margin-left: 3em">随天圆形地居中心之验</span>  
<span style="margin-left: 1em">天以圆形包地在中心其验有二其一为诸星随宗动</span>  
<span style="margin-left: 2em">绕地一周或在东西或正过天顶或偏南北其距地</span>  
<span style="margin-left: 2em">远近恒如一人目视之时有大小疏密不同乃地之</span>  
<span style="margin-left: 2em">蒙气使然非星之有远近也即在天顶每较在地平</span>  
<span style="margin-left: 2em">更小者亦竖视横视之间气之多寡已耳其二天每</span>  
<span style="margin-left: 2em">半出地上半入地下盖地居天之中正如一点而人</span>  
<span style="margin-left: 2em">目依地面周视之故无不得见其半乃所得之界即</span>  
<span style="margin-left: 2em">所谓地平是也地平之大圈以天顶为极平分目所</span>  
<span style="margin-left: 2em">能视之天与不能视之天使正对南北二极以直角</span>  
<span style="margin-left: 2em">交赤道圈此名为正浑仪依此体势可当正球设使</span>  
<span style="margin-left: 2em">二极一在上一在下不以直角交赤道即名为斜浑</span>  
<span style="margin-left: 2em">仪因之亦可当斜球也</span>  
<span style="margin-left: 2em">地平有二等一属目人在地平面或海面周无所阻</span>  
<span style="margin-left: 2em">之物而目之见界及之即人可当中心周界为圈约</span>  
<span style="margin-left: 2em">得半径为六十余里此外不及见地而天已半出其</span>  
<span style="margin-left: 2em">上矣一属心人在地与海之上虽四周无物以碍之</span>  
<span style="margin-left: 2em">而目力不能尽见天体止以诸曜之可见者显其半</span>  
<span style="margin-left: 2em">出半入之理已耳盖本圈定诸星出没能见与否必</span>  
<span style="margin-left: 2em">分为四象限而各象限得九十度则自正东及正西</span>  
<span style="margin-left: 2em">起至正南及正北止此子午圈之定位所繇分矣</span>  
<span style="margin-left: 2em">子午圈为大圈必过天顶及赤道南北二极因而平</span>  
<span style="margin-left: 2em">分赤道等为平行之小圈以之定正子午焉盖以直</span>  
<span style="margin-left: 2em">道交地平本圈可当高弧亦可当纬度圈随处以诸</span>  
<span style="margin-left: 2em">曜至中之高定赤道高与极出地高及诸星之纬度</span>  
<span style="margin-left: 2em">亦自较较不爽者</span>  
<span style="margin-left: 2em">又地平子午二圈当天外圈故不随天行转而随地</span>  
<span style="margin-left: 2em">每见地平各处不同子午除正南北外其余方亦自</span>  
<span style="margin-left: 2em">不同且实无算今历家祗记一度一圈其不同者共</span>  
<span style="margin-left: 2em">一百八十取其足用已耳而本仪仅仅一地平一子</span>  
<span style="margin-left: 2em">午盖亦约畧诸圈而为之用也</span>  
<span style="margin-left: 3em">随宗动之验</span>  
<span style="margin-left: 1em">浑仪倚南北极如枢一昼夜旋一周令诸星并行各为</span>  
<span style="margin-left: 2em">圈大小不等各圈以极为心自距极远近又不等譬</span>  
<span style="margin-left: 2em">之车轮然其毂外之广较辐中之狭远近迟速皆异</span>  
<span style="margin-left: 2em">而其复于元处也则同试令去极最远之处有星随</span>  
<span style="margin-left: 2em">天行为圈则较两极左右之圈必大此即赤道圈也</span>  
<span style="margin-left: 2em">赤道平分天体相交于地平恒得半在上半在下自</span>  
<span style="margin-left: 2em">有其枢极亦皆与天地共一公枢极故有距天顶与</span>  
<span style="margin-left: 2em">本极出地等者则总得昼夜平矣其所以名宗动带</span>  
<span style="margin-left: 2em">者亦因其正居两极之中令浑天平分南北故也</span>  
<span style="margin-left: 2em">依赤道测宗动可定时刻盖每一小时行十五度每</span>  
<span style="margin-left: 2em">二十四小时行天一周此终古不易之定法也虽太</span>  
<span style="margin-left: 2em">阳等曜顺黄道行而黄道斜络天上升降亦不一又</span>  
<span style="margin-left: 2em">安所得诸曜出没之限而齐之以定则哉故曰舍赤</span>  
<span style="margin-left: 2em">道别无可以测宗动也</span>  
<span style="margin-left: 2em">较诸星出没之时于出没之限亦惟距赤道北者在</span>  
<span style="margin-left: 2em">地平上之时多而在下少盖距赤道愈远则出愈早</span>  
<span style="margin-left: 2em">而没愈迟其距赤道南者在地平上之时少而在下</span>  
<span style="margin-left: 2em">反多盖在赤道之极南则出愈迟而没愈早设一星</span>  
<span style="margin-left: 2em">距南一距北皆等则在北居地平上之时较在南居</span>  
<span style="margin-left: 2em">地平下之时必等反之而北居下南居上其时亦等</span>  
<span style="margin-left: 2em">惟在赤道上者则得见与不见之时等即得东西出</span>  
<span style="margin-left: 2em">入之处亦等总之星距赤道北或与极高之余度等</span>  
<span style="margin-left: 2em">必不入地平距赤道南或亦与极高之余度等亦必</span>  
<span style="margin-left: 2em">不出地平虽绕极而上下然相去卒不远也此北斗</span>  
<span style="margin-left: 2em">之宿常见而老人星常隐者顺天府极高使然也甚</span>  
<span style="margin-left: 2em">至数百年后恒星之本行已移南北之距度非故则</span>  
<span style="margin-left: 2em">前之不见者见前之不隐者隐或亦理势之所必有</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 3em">随本行之验</span>  
<span style="margin-left: 1em">有谓诸曜依宗动每日西行其所不及满一周天之度</span>  
<span style="margin-left: 2em">者即其本行<sub class="note-yuan">即蔡注谓日行绕地一周不及一度月不及十三度是也亦曰右行或东行</sub></span>  
<span style="margin-left: 2em">此解诸曜无两种行度相反之理其说亦是但未详</span>  
<span style="margin-left: 2em">本行之所以然盖诸曜本行原不以正东正西与赤</span>  
<span style="margin-left: 2em">道平相距其斜迤赤道之上者时在内时在外而内</span>  
<span style="margin-left: 2em">与外又等则必更有一极以为诸行之枢所谓黄道</span>  
<span style="margin-left: 2em">之极是也既极与道异于赤极赤道则东西二行自</span>  
<span style="margin-left: 2em">不相悖而诸曜右旋之名所繇来矣</span>  
<span style="margin-left: 2em">黄道为大圈恒斜交赤道圈上而两圈相交约得直</span>  
<span style="margin-left: 2em">角四之一虽古今相距较二道畧有变易而今实得</span>  
<span style="margin-left: 2em">二十三度三十一分三十秒因斜交名为斜圈故以</span>  
<span style="margin-left: 2em">黄道为七政本行之道太阳繇中道行以心随线名</span>  
<span style="margin-left: 2em">曰躔道乃依之每日行一度月五星常出入内外各</span>  
<span style="margin-left: 2em">距之不等各行迟速不等而相距最远者为金火二</span>  
<span style="margin-left: 2em">星约八度设南北共一十六度之广者即全黄道也</span>  
<span style="margin-left: 2em">或有限其宽于十二度者则从三百六十度起见即</span>  
<span style="margin-left: 2em">一宫得一度之比例也又曰经周得十二宫应纬度</span>  
<span style="margin-left: 2em">宽十二度其理同也</span>  
<span style="margin-left: 2em">黄道交赤道正相对之点为春秋二分其距赤道最</span>  
<span style="margin-left: 2em">远亦正相对之点为冬夏二至以四季分四象限各</span>  
<span style="margin-left: 2em">象限得九十度<sub class="note-yuan">或三宫</sub>黄极距赤道极亦如两道最相</span>  
<span style="margin-left: 2em">距之极七政依此以行皆以距太阳为会望远近之</span>  
<span style="margin-left: 2em">序而其本行归黄道与宗动归赤道无异也古有以</span>  
<span style="margin-left: 2em">周天分十二宫一宫分三十度算在列宿天者盖不</span>  
<span style="margin-left: 2em">知恒星有本行而今已东移如许矣因设一次宫曰</span>  
<span style="margin-left: 2em">从宗动天算</span>  
<span style="margin-left: 2em">或问分黄道十二宫何故曰太阴行黄道每岁十三</span>  
<span style="margin-left: 2em">转其与太阳会合者惟十二次又各会合之处不同</span>  
<span style="margin-left: 2em">故分黄道为十二宫也即如太阴行天一周约得二</span>  
<span style="margin-left: 2em">十八日其命为二十八宿者大率繇此每宫分三十</span>  
<span style="margin-left: 2em">度者因太阳一日约行一度越三十日已过一宫是</span>  
<span style="margin-left: 2em">以总分三百六十度而大小诸圈悉依之也今诸星</span>  
<span style="margin-left: 6em">距黄道远近命为入某宫次者何曰历家</span>  
<span style="margin-left: 6em">设黄极出圈线其过各宫初度自此极至</span>  
<span style="margin-left: 6em">彼极总为十二半圈凡黄道上之星在彼</span>  
<span style="margin-left: 6em">此极中居圈内者曰入某宫如上图设甲</span>  
<span style="margin-left: 2em">为北极乙为黄道自极过黄道半圈为甲丙甲丁则</span>  
<span style="margin-left: 2em">星在丙与丁线之间任距黄道南北远近必共入一</span>  
<span style="margin-left: 2em">宫矣</span>  
<span style="margin-left: 2em">十二宫或分南北即以赤道为初末之限自降娄而</span>  
<span style="margin-left: 2em">大梁而实沈而鹑首而鹑火鹑尾为北六宫自寿星</span>  
<span style="margin-left: 2em">而大火而析木而星纪而玄枵娵訾为南六宫或以</span>  
<span style="margin-left: 2em">左右较分即冬夏二至为初末之限自冬至迄春分</span>  
<span style="margin-left: 2em">为行盈自夏至迄秋分为行缩又或以正对宫度相</span>  
<span style="margin-left: 2em">较则北初宫与南初宫北末宫与南末宫得彼此距</span>  
<span style="margin-left: 2em">度加减之数必等</span>  
<span style="margin-left: 3em">太阳及太阴本行合宗动之验</span>  
<span style="margin-left: 1em">太阳为时日之原一日约东行一度于黄道为正而于</span>  
<span style="margin-left: 2em">赤道恒为斜或在两道之交或北上或南下绝无定</span>  
<span style="margin-left: 2em">居故无一定之时此四季所繇以变易也迨加以宗</span>  
<span style="margin-left: 2em">动即见其出没之广不一昼夜之长短有变如日在</span>  
<span style="margin-left: 2em">降娄初度为春分则出正东没正西昼与夜皆等自</span>  
<span style="margin-left: 2em">此以往渐斜去赤道北出没较前为广矣昼长而夜</span>  
<span style="margin-left: 2em">短至夏至为最矣乃从夏至而退行一度其出其没</span>  
<span style="margin-left: 2em">其昼其夜与前所得等渐退行渐与前等惟过秋分</span>  
<span style="margin-left: 2em">而太阳行赤道南则于前后相对宫度有定比例彼</span>  
<span style="margin-left: 2em">之所广此之所狭彼之所长此之所短若相背而驰</span>  
<span style="margin-left: 2em">者然</span>  
<span style="margin-left: 2em">黄道上四点得太阳躔之为春夏秋冬而即可当各</span>  
<span style="margin-left: 2em">时之极此过极圈所繇也乃过极圈有二一过两极</span>  
<span style="margin-left: 2em">以并过春秋分为极分交圈一过两极以并过冬夏</span>  
<span style="margin-left: 2em">至为极至交圈因而共当浑仪之脊骨盖各与赤道</span>  
<span style="margin-left: 2em">以直角交即渐去内外至两赤极之中亦自以直角</span>  
<span style="margin-left: 2em">相交则总得八三角形而各形之弧各成一象限各</span>  
<span style="margin-left: 2em">皆九十度因可以定太阳及诸曜距两道内外之纬</span>  
<span style="margin-left: 2em">度又名纬度圈即两道及两道之极亦可以得相距</span>  
<span style="margin-left: 2em">度分</span>  
<span style="margin-left: 2em">太阴依本行随黄道约二十九日有奇而与太阳会</span>  
<span style="margin-left: 2em">故并论宗动则出没之广在地平上下之时皆从赤</span>  
<span style="margin-left: 2em">道纬倣太阳为则且无本光借光于日因体厚不能</span>  
<span style="margin-left: 2em">透所借之光故依本行距日远近不等有时显全光</span>  
<span style="margin-left: 2em">有时少显其光只至正相望而食于地景正相会而</span>  
<span style="margin-left: 2em">能自以其体掩日原光又依宗动使下地视之时有</span>  
<span style="margin-left: 2em">先后方位各异兹有本论聊述一二如此</span>  
<span style="margin-left: 3em">随地圆形之验</span>  
<span style="margin-left: 1em">历家论地与海并为圆形以应天上之经纬者何盖每</span>  
<span style="margin-left: 2em">见日月交食东西时刻各先后不等此即地东西圆</span>  
<span style="margin-left: 2em">之验夫时之先后取规于度在天十五度为一小时</span>  
<span style="margin-left: 2em">在地亦然而大地彼此相距约二百五十里为一度</span>  
<span style="margin-left: 2em">如西安府较顺天府恒早二刻余而见食其见诸曜</span>

<span style="margin-left: 3em">天球</span>  
<span style="margin-left: 1em">天球为实面仪得大圈与前同惟极至极分两圈可免</span>  
<span style="margin-left: 2em">以子午圈当之足矣仪面布列经星依本黄赤二道</span>

<span style="margin-left: 3em">地球</span>  
<span style="margin-left: 1em">地球倣地之原形必为圆面仪其得大圈与天球同惟</span>  
<span style="margin-left: 2em">黄道地上无定处故可不用夫天球因二十八宿而</span>  
<span style="margin-left: 2em">以南北引圈线过各宿距星则地球亦因子午线有</span>  
<span style="margin-left: 2em">先后以引其圈乃东西任距十度或十五度而南北</span>  
<span style="margin-left: 2em">各作小圈与赤道为平行以显南北之距焉古西士</span>  
<span style="margin-left: 2em">纪东西地经一百八十度极西为福岛极东为日本</span>

<span style="margin-left: 2em">辣距赤道内七十八度又径过日本东西绕地一周</span>  
<span style="margin-left: 2em">寻得新洲南北各大块中以小峡接连总较古所识</span>  
<span style="margin-left: 2em">东西地约等虽南极下未及登岸不详其内境然顺</span>  
<span style="margin-left: 2em">滨而行似亦无所不经矣</span>  
<span style="margin-left: 2em">天设圈有大小每圈俱分为三百六十度则凡数等</span>  
<span style="margin-left: 2em">而圈之大小度之广狭因之乃地亦依此为则故地</span>  
<span style="margin-left: 2em">上依六圈行则凡度相应之里数等依小圈亦有广</span>  
<span style="margin-left: 2em">狭如距赤道四十度平行圈下之里数较赤道正下</span>
