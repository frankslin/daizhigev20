<span style="margin-left: 1em">上三論古今無疑其不同者古曰五星之行皆以地心</span>  
<span style="margin-left: 2em">爲本天之心今曰五星以太陽之體爲心古曰各星</span>  
<span style="margin-left: 2em">自有本天重重包裹不能相通而天體皆爲實體今</span>  
<span style="margin-left: 2em">曰諸圈能相入即能相通不得爲實體古曰土木火</span>  
<span style="margin-left: 2em">星恆居太陽之外今曰火星有時在太陽之內</span>  
<span style="margin-left: 3em">解曰用遠鏡見金星如月<sub class="note-yuan">見本篇</sub>有晦朔弦望必有</span>  
<span style="margin-left: 3em">時在太陽之上有時在下又火星獨對衝太陽時</span>  
<span style="margin-left: 3em">其體大其視差較太陽爲大則此時庳于太陽水</span>  
<span style="margin-left: 3em">星木星土星不能以正論定其高庳但以遲行疾</span>  
<span style="margin-left: 3em">行聊可證之</span>
