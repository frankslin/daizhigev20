<span style="margin-left: 1em">曆指第十五卷　交食七</span>  
<span style="margin-left: 3em">測食分</span>  
<span style="margin-left: 1em">算食而不測食將何以攷其法非强天即自欺故必隨</span>  
<span style="margin-left: 2em">測隨算了了於目了了於手則視差視徑時分俱準</span>  
<span style="margin-left: 2em">而法乃得矣</span>  
<span style="margin-left: 3em">測太陰食分</span>  
<span style="margin-left: 1em">常法全頼目力因分太陽徑爲一十分太陰徑亦如之</span>  
<span style="margin-left: 2em">食甚時則以所見不食之徑約略不能見之餘分設</span>  
<span style="margin-left: 2em">并見失光之體庶幾所食有半者依此以測猶可此</span>  
<span style="margin-left: 2em">外則多有謬焉何也太陰未食以前欲用器測全徑</span>  
<span style="margin-left: 2em">食甚時又測光所存之餘徑此際甚難<sub class="note-yuan">其光微又無從定中線故</sub></span>  
<span style="margin-left: 2em">且不正合于法今補此闕用太陰地景兩徑之比例</span>  
<span style="margin-left: 2em">及太陰見缺之邊如圖地景心在丙得乙戊辛弧爲</span>  
<span style="margin-left: 7em">邊太陰心在甲以其乙丁辛邊弧入景</span>  
<span style="margin-left: 7em">中爲所缺自乙至辛作直線更一直線</span>  
<span style="margin-left: 7em">聯其兩心及兩邊交切之界于乙或辛</span>  
<span style="margin-left: 2em">爲甲乙乙丙及甲丙而甲丙及乙辛以直角相交于</span>  
<span style="margin-left: 2em">己使太陰入景之邊乙丁辛爲六十度因半之于丁</span>  
<span style="margin-left: 2em">得乙丁對乙甲己角爲三十度必餘角甲乙己爲六</span>  
<span style="margin-left: 2em">十度<sub class="note-yuan">甲己乙直角故</sub>甲乙割線二萬乙己止一萬則以甲乙</span>  
<span style="margin-left: 2em">與乙丙之比例<sub class="note-yuan">一與三是</sub>乙丙得六萬爲丙乙己角之割</span>  
<span style="margin-left: 2em">線查八十度二十四分本角之切線五九一二三六</span>  
<span style="margin-left: 2em">爲丙己而甲己爲甲乙己角之切線一七三二〇五</span>  
<span style="margin-left: 2em">兩切線爲甲丁及丙戊所減<sub class="note-yuan">甲丁與甲乙丙戊與丙乙自相等</sub>餘丁</span>  
<span style="margin-left: 2em">己二六七九五戊己八七六四并之得三五五五九</span>  
<span style="margin-left: 2em">爲甲乙二萬分比例之分因以推太陰之食分蓋設</span>  
<span style="margin-left: 2em">太陰半徑得一十六分與之相乘用二萬除得食二</span>  
<span style="margin-left: 2em">分五十一秒<sub class="note-yuan">度數之分</sub>即徑分止有五十三秒以此測雖</span>  
<span style="margin-left: 2em">微有差所推徑分終近矣</span>  
<span style="margin-left: 3em">測太陽食分</span>  
<span style="margin-left: 1em">密室中對太陽開小圓孔以受其光因孔小出光之體</span>  
<span style="margin-left: 2em">大則所正照之光必爲角形其底在太陽其角在孔</span>  
<span style="margin-left: 2em">之中夫光一入內又復展開爲角形以致底所對之</span>  
<span style="margin-left: 2em">牆轉其原形以上爲下以左爲右使牆與光直角相</span>  
<span style="margin-left: 2em">遇則底爲圓形不則爲圓長形使孔不圓且小則光</span>  
<span style="margin-left: 2em">底在牆或彷彿孔形而所像太陽之形大都不真何</span>  
<span style="margin-left: 2em">也太陽孔牆三者皆有遠近大小之比例蓋孔距牆</span>  
<span style="margin-left: 2em">得其本徑數與太陽所距本徑數等則光底在牆必</span>  
<span style="margin-left: 2em">像太陽圓形及孔之多邊形各等爲雜形若兩徑數</span>  
<span style="margin-left: 2em">不等而太陽距牆得徑數多則光底失去原形轉隨</span>  
<span style="margin-left: 2em">孔形得徑數少則光底必因之愈少故測食者恆設</span>  
<span style="margin-left: 2em">孔小而圓乃可遠近無差因以牆上所缺之形徵太</span>  
<span style="margin-left: 2em">陽所食之分法以規器于紙上先畫大小不等數圓</span>  
<span style="margin-left: 2em">圈各以徑分之其徑以十或更密平分之臨測室中</span>  
<span style="margin-left: 2em">以圈受光不拘遠近任用大小圈全以脗合于光爲</span>  
<span style="margin-left: 2em">準既合便轉紙使其圈徑橫過餘光形中平分兩角</span>  
<span style="margin-left: 2em">則光缺之界即所食分數方光與圈合時遂以筆于</span>  
<span style="margin-left: 2em">光景間微識三四小點求心因之作圈略得太陰掩</span>  
<span style="margin-left: 2em">太陽大小之比例如圖甲乙丙丁爲太陽食外之餘</span>  
<span style="margin-left: 2em">光正與甲乙丙圈界相合其心在戊其徑與丁以直</span>  
<span style="margin-left: 6em">角交景而平分甲及丙兩光角則得太陽</span>  
<span style="margin-left: 6em">食七分有奇更取三點爲甲丁丙以己爲</span>  
<span style="margin-left: 6em">心<sub class="note-yuan">幾何三卷二十四題</sub>以甲丁丙辛爲太陰乃以己</span>  
<span style="margin-left: 2em">丁較戊乙亦得日月兩徑大小之比例</span>  
<span style="margin-left: 3em">日食射光之容</span>  
<span style="margin-left: 1em">測日食以最微之孔對照之西土用綠色玻瓈僅見日</span>  
<span style="margin-left: 2em">周俱掩去餘耀反照則用水盤欲細則以平面鏡所</span>  
<span style="margin-left: 2em">接之光反射牆上可略得分明第對照水中反照皆</span>  
<span style="margin-left: 2em">非實測之法惟射光于牆略近然因尚容次光亂其</span>  
<span style="margin-left: 2em">景猶未足故前以密室測食之分爲本法今再全解</span>  
<span style="margin-left: 2em">之欲光從外入室內以其形正彷原形盡乎大小之</span>  
<span style="margin-left: 2em">比例倘孔非最小<sub class="note-yuan">幾何稱無分點之小</sub>而圓則太陽食照必畧</span>  
<span style="margin-left: 2em">變其餘光之角形爲不彷原之一又太陰掩太陽其</span>  
<span style="margin-left: 2em">徑略小即失天上視徑之比例爲不彷原之二因徑</span>  
<span style="margin-left: 2em">小所食之分較天上之真分亦少爲不彷原之三三</span>  
<span style="margin-left: 7em">者皆歸一緣蓋接光之孔稍廣則從中</span>  
<span style="margin-left: 7em">心攝太陽之形全顯于牆或紙亦併周</span>  
<span style="margin-left: 7em">孔邊之每點全進焉乃每點所進射之</span>  
<span style="margin-left: 7em">形雖圓其出外與孔之圓不平行而每</span>  
<span style="margin-left: 7em">點射形之公界復與之平行且內抱中</span>  
<span style="margin-left: 2em">心所射之形亦與之平行如圖乙丙丁界內爲光即</span>  
<span style="margin-left: 2em">太陽總形也其內圈壬庚癸爲孔之廣因圓故其受</span>  
<span style="margin-left: 2em">光至平面亦圓第太陽大不可比其光一入復寬爲</span>  
<span style="margin-left: 2em">戊己辛形與內圈平行以其中心甲與太陽正對故</span>  
<span style="margin-left: 2em">以遠近之比例可推本形甲戊半徑與太陽視半徑</span>  
<span style="margin-left: 2em">大小之比例然庚內圈之點射太陽形爲丙己辛較</span>  
<span style="margin-left: 2em">于中圈更以戊丙徑線出外<sub class="note-yuan">戊丙與甲庚孔之半徑等</sub>而壬癸及</span>  
<span style="margin-left: 2em">餘點皆射圓形則外得乙丙丁總圈其甲丙與太陽</span>  
<span style="margin-left: 2em">半徑無大小之比例以遠近可推也又因原形入室</span>  
<span style="margin-left: 2em">內必借孔形以兩形合別爲雜形今測太陽設圓孔</span>  
<span style="margin-left: 2em">原形無從可變<sub class="note-yuan">除上爲下左爲右</sub>而食之時其自變形露角</span>  
<span style="margin-left: 2em">射于密室內又與孔之圓形不合因而損其角似圓</span>  
<span style="margin-left: 2em">矣如圖太陽食之餘光實爲甲乙丙丁乃從甲孔之</span>  
<span style="margin-left: 6em">心射入以丙丁乙弧不異于孔形而丁甲</span>  
<span style="margin-left: 6em">乙角形則異矣故本界四周以孔半徑展</span>  
<span style="margin-left: 6em">開<sub class="note-yuan">甲戊丙己乙辛丁壬皆半徑</sub>外得戊辛己壬爲總界</span>  
<span style="margin-left: 2em">與前圖所解同則以辛己壬弧元合于孔形而壬戊</span>  
<span style="margin-left: 2em">辛亦必彷之其彷之之規必依孔半徑故丁乙各爲</span>  
<span style="margin-left: 2em">心得壬癸及辛庚弧皆變爲圓角耳</span>  
<span style="margin-left: 3em">室中測食日月兩徑有定差</span>  
<span style="margin-left: 1em">依本食圖丁甲乙弧爲太陰掩太陽之邊其心在癸從</span>  
<span style="margin-left: 2em">癸心出直線至丁至甲至乙又乙丙丁中原形使之</span>  
<span style="margin-left: 2em">過庚爲圈而從其甲心引直線至壬至辛至己因甲</span>  
<span style="margin-left: 2em">乙丙丁爲日食餘光之真形實合于原則癸甲與甲</span>  
<span style="margin-left: 7em">丙或癸乙與甲乙癸丁與甲丁<sub class="note-yuan">甲丙甲乙甲丁</sub></span>  
<span style="margin-left: 7em"><sub class="note-yuan">皆太陽半徑癸甲癸乙癸丁皆太陰半徑</sub>得真大小之比例</span>  
<span style="margin-left: 7em">亦與原視半徑全合今密室之中辛己</span>  
<span style="margin-left: 7em">壬戊光形實以甲戊孔之半徑周展其</span>  
<span style="margin-left: 2em">界則太陽亦展半徑自甲致之于壬于辛于己而甲</span>  
<span style="margin-left: 2em">辛與甲癸太陽半徑之比例必過甲乙與本甲癸之</span>  
<span style="margin-left: 2em">比例太陰半徑亦然移癸甲爲癸戊其癸丁癸乙皆</span>  
<span style="margin-left: 2em">曲而小故甲乙與癸戊之比例又大于甲乙與癸甲</span>  
<span style="margin-left: 2em">之比例而甲辛愈大<sub class="note-yuan">因甲辛大于甲乙故</sub>可徴兩徑在光形密</span>  
<span style="margin-left: 2em">室之中比于兩徑實在食時必依孔之廣狹變其大</span>  
<span style="margin-left: 2em">小未嘗正合焉</span>  
<span style="margin-left: 3em">室內測食食之分有定差</span>  
<span style="margin-left: 7em">依前圖總光界辛己壬弧以加壬丁辛</span>  
<span style="margin-left: 7em">弧作全圈則甲乙元爲食分與丙乙太</span>  
<span style="margin-left: 7em">陽全徑實得比例今總光形之徑己丁</span>  
<span style="margin-left: 7em">較之丙乙長兩孔之半徑<sub class="note-yuan">即己丙及乙丁</sub>故本</span>  
<span style="margin-left: 2em">徑與食分變比例因而甲乙比于己丁線不如比于</span>  
<span style="margin-left: 2em">丙乙線得大小之理若丁戊<sub class="note-yuan">光形食之分</sub>則既乙丁與甲</span>  
<span style="margin-left: 2em">戊等亦自與甲乙相等可徴其大小之比例在光形</span>  
<span style="margin-left: 2em">有失矣</span>  
<span style="margin-left: 1em">或問測食與算食分數不合而每每所測分數恆不及</span>  
<span style="margin-left: 2em">必因食形假耳今欲改爲真形從何法得曰以太陰</span>  
<span style="margin-left: 2em">半徑加孔半徑于太陽餘光之內反減之各依本心</span>  
<span style="margin-left: 2em">光形內作弧得甲庚丙癸原正形即從甲太陽形心</span>  
<span style="margin-left: 2em">及丁太陰形心推定也</span>  
<span style="margin-left: 3em">定食分及兩徑比例必係真光形</span>
