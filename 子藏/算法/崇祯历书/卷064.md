<span style="margin-left: 1em">历指第十五卷　交食七</span>  
<span style="margin-left: 3em">测食分</span>  
<span style="margin-left: 1em">算食而不测食将何以攷其法非强天即自欺故必随</span>  
<span style="margin-left: 2em">测随算了了于目了了于手则视差视径时分俱准</span>  
<span style="margin-left: 2em">而法乃得矣</span>  
<span style="margin-left: 3em">测太阴食分</span>  
<span style="margin-left: 1em">常法全頼目力因分太阳径为一十分太阴径亦如之</span>  
<span style="margin-left: 2em">食甚时则以所见不食之径约略不能见之余分设</span>  
<span style="margin-left: 2em">并见失光之体庶几所食有半者依此以测犹可此</span>  
<span style="margin-left: 2em">外则多有谬焉何也太阴未食以前欲用器测全径</span>  
<span style="margin-left: 2em">食甚时又测光所存之余径此际甚难<sub class="note-yuan">其光微又无从定中线故</sub></span>  
<span style="margin-left: 2em">且不正合于法今补此阙用太阴地景两径之比例</span>  
<span style="margin-left: 2em">及太阴见缺之边如图地景心在丙得乙戊辛弧为</span>  
<span style="margin-left: 7em">边太阴心在甲以其乙丁辛边弧入景</span>  
<span style="margin-left: 7em">中为所缺自乙至辛作直线更一直线</span>  
<span style="margin-left: 7em">联其两心及两边交切之界于乙或辛</span>  
<span style="margin-left: 2em">为甲乙乙丙及甲丙而甲丙及乙辛以直角相交于</span>  
<span style="margin-left: 2em">己使太阴入景之边乙丁辛为六十度因半之于丁</span>  
<span style="margin-left: 2em">得乙丁对乙甲己角为三十度必余角甲乙己为六</span>  
<span style="margin-left: 2em">十度<sub class="note-yuan">甲己乙直角故</sub>甲乙割线二万乙己止一万则以甲乙</span>  
<span style="margin-left: 2em">与乙丙之比例<sub class="note-yuan">一与三是</sub>乙丙得六万为丙乙己角之割</span>  
<span style="margin-left: 2em">线查八十度二十四分本角之切线五九一二三六</span>  
<span style="margin-left: 2em">为丙己而甲己为甲乙己角之切线一七三二〇五</span>  
<span style="margin-left: 2em">两切线为甲丁及丙戊所减<sub class="note-yuan">甲丁与甲乙丙戊与丙乙自相等</sub>余丁</span>  
<span style="margin-left: 2em">己二六七九五戊己八七六四并之得三五五五九</span>  
<span style="margin-left: 2em">为甲乙二万分比例之分因以推太阴之食分盖设</span>  
<span style="margin-left: 2em">太阴半径得一十六分与之相乘用二万除得食二</span>  
<span style="margin-left: 2em">分五十一秒<sub class="note-yuan">度数之分</sub>即径分止有五十三秒以此测虽</span>  
<span style="margin-left: 2em">微有差所推径分终近矣</span>  
<span style="margin-left: 3em">测太阳食分</span>  
<span style="margin-left: 1em">密室中对太阳开小圆孔以受其光因孔小出光之体</span>  
<span style="margin-left: 2em">大则所正照之光必为角形其底在太阳其角在孔</span>  
<span style="margin-left: 2em">之中夫光一入内又复展开为角形以致底所对之</span>  
<span style="margin-left: 2em">墙转其原形以上为下以左为右使墙与光直角相</span>  
<span style="margin-left: 2em">遇则底为圆形不则为圆长形使孔不圆且小则光</span>  
<span style="margin-left: 2em">底在墙或仿佛孔形而所像太阳之形大都不真何</span>  
<span style="margin-left: 2em">也太阳孔墙三者皆有远近大小之比例盖孔距墙</span>  
<span style="margin-left: 2em">得其本径数与太阳所距本径数等则光底在墙必</span>  
<span style="margin-left: 2em">像太阳圆形及孔之多边形各等为杂形若两径数</span>  
<span style="margin-left: 2em">不等而太阳距墙得径数多则光底失去原形转随</span>  
<span style="margin-left: 2em">孔形得径数少则光底必因之愈少故测食者恒设</span>  
<span style="margin-left: 2em">孔小而圆乃可远近无差因以墙上所缺之形征太</span>  
<span style="margin-left: 2em">阳所食之分法以规器于纸上先画大小不等数圆</span>  
<span style="margin-left: 2em">圈各以径分之其径以十或更密平分之临测室中</span>  
<span style="margin-left: 2em">以圈受光不拘远近任用大小圈全以脗合于光为</span>  
<span style="margin-left: 2em">准既合便转纸使其圈径横过余光形中平分两角</span>  
<span style="margin-left: 2em">则光缺之界即所食分数方光与圈合时遂以笔于</span>  
<span style="margin-left: 2em">光景间微识三四小点求心因之作圈略得太阴掩</span>  
<span style="margin-left: 2em">太阳大小之比例如图甲乙丙丁为太阳食外之余</span>  
<span style="margin-left: 2em">光正与甲乙丙圈界相合其心在戊其径与丁以直</span>  
<span style="margin-left: 6em">角交景而平分甲及丙两光角则得太阳</span>  
<span style="margin-left: 6em">食七分有奇更取三点为甲丁丙以己为</span>  
<span style="margin-left: 6em">心<sub class="note-yuan">几何三卷二十四题</sub>以甲丁丙辛为太阴乃以己</span>  
<span style="margin-left: 2em">丁较戊乙亦得日月两径大小之比例</span>  
<span style="margin-left: 3em">日食射光之容</span>  
<span style="margin-left: 1em">测日食以最微之孔对照之西土用绿色玻瓈仅见日</span>  
<span style="margin-left: 2em">周俱掩去余耀反照则用水盘欲细则以平面镜所</span>  
<span style="margin-left: 2em">接之光反射墙上可略得分明第对照水中反照皆</span>  
<span style="margin-left: 2em">非实测之法惟射光于墙略近然因尚容次光乱其</span>  
<span style="margin-left: 2em">景犹未足故前以密室测食之分为本法今再全解</span>  
<span style="margin-left: 2em">之欲光从外入室内以其形正彷原形尽乎大小之</span>  
<span style="margin-left: 2em">比例倘孔非最小<sub class="note-yuan">几何称无分点之小</sub>而圆则太阳食照必畧</span>  
<span style="margin-left: 2em">变其余光之角形为不彷原之一又太阴掩太阳其</span>  
<span style="margin-left: 2em">径略小即失天上视径之比例为不彷原之二因径</span>  
<span style="margin-left: 2em">小所食之分较天上之真分亦少为不彷原之三三</span>  
<span style="margin-left: 7em">者皆归一缘盖接光之孔稍广则从中</span>  
<span style="margin-left: 7em">心摄太阳之形全显于墙或纸亦并周</span>  
<span style="margin-left: 7em">孔边之每点全进焉乃每点所进射之</span>  
<span style="margin-left: 7em">形虽圆其出外与孔之圆不平行而每</span>  
<span style="margin-left: 7em">点射形之公界复与之平行且内抱中</span>  
<span style="margin-left: 2em">心所射之形亦与之平行如图乙丙丁界内为光即</span>  
<span style="margin-left: 2em">太阳总形也其内圈壬庚癸为孔之广因圆故其受</span>  
<span style="margin-left: 2em">光至平面亦圆第太阳大不可比其光一入复宽为</span>  
<span style="margin-left: 2em">戊己辛形与内圈平行以其中心甲与太阳正对故</span>  
<span style="margin-left: 2em">以远近之比例可推本形甲戊半径与太阳视半径</span>  
<span style="margin-left: 2em">大小之比例然庚内圈之点射太阳形为丙己辛较</span>  
<span style="margin-left: 2em">于中圈更以戊丙径线出外<sub class="note-yuan">戊丙与甲庚孔之半径等</sub>而壬癸及</span>  
<span style="margin-left: 2em">余点皆射圆形则外得乙丙丁总圈其甲丙与太阳</span>  
<span style="margin-left: 2em">半径无大小之比例以远近可推也又因原形入室</span>  
<span style="margin-left: 2em">内必借孔形以两形合别为杂形今测太阳设圆孔</span>  
<span style="margin-left: 2em">原形无从可变<sub class="note-yuan">除上为下左为右</sub>而食之时其自变形露角</span>  
<span style="margin-left: 2em">射于密室内又与孔之圆形不合因而损其角似圆</span>  
<span style="margin-left: 2em">矣如图太阳食之余光实为甲乙丙丁乃从甲孔之</span>  
<span style="margin-left: 6em">心射入以丙丁乙弧不异于孔形而丁甲</span>  
<span style="margin-left: 6em">乙角形则异矣故本界四周以孔半径展</span>  
<span style="margin-left: 6em">开<sub class="note-yuan">甲戊丙己乙辛丁壬皆半径</sub>外得戊辛己壬为总界</span>  
<span style="margin-left: 2em">与前图所解同则以辛己壬弧元合于孔形而壬戊</span>  
<span style="margin-left: 2em">辛亦必彷之其彷之之规必依孔半径故丁乙各为</span>  
<span style="margin-left: 2em">心得壬癸及辛庚弧皆变为圆角耳</span>  
<span style="margin-left: 3em">室中测食日月两径有定差</span>  
<span style="margin-left: 1em">依本食图丁甲乙弧为太阴掩太阳之边其心在癸从</span>  
<span style="margin-left: 2em">癸心出直线至丁至甲至乙又乙丙丁中原形使之</span>  
<span style="margin-left: 2em">过庚为圈而从其甲心引直线至壬至辛至己因甲</span>  
<span style="margin-left: 2em">乙丙丁为日食余光之真形实合于原则癸甲与甲</span>  
<span style="margin-left: 7em">丙或癸乙与甲乙癸丁与甲丁<sub class="note-yuan">甲丙甲乙甲丁</sub></span>  
<span style="margin-left: 7em"><sub class="note-yuan">皆太阳半径癸甲癸乙癸丁皆太阴半径</sub>得真大小之比例</span>  
<span style="margin-left: 7em">亦与原视半径全合今密室之中辛己</span>  
<span style="margin-left: 7em">壬戊光形实以甲戊孔之半径周展其</span>  
<span style="margin-left: 2em">界则太阳亦展半径自甲致之于壬于辛于己而甲</span>  
<span style="margin-left: 2em">辛与甲癸太阳半径之比例必过甲乙与本甲癸之</span>  
<span style="margin-left: 2em">比例太阴半径亦然移癸甲为癸戊其癸丁癸乙皆</span>  
<span style="margin-left: 2em">曲而小故甲乙与癸戊之比例又大于甲乙与癸甲</span>  
<span style="margin-left: 2em">之比例而甲辛愈大<sub class="note-yuan">因甲辛大于甲乙故</sub>可徴两径在光形密</span>  
<span style="margin-left: 2em">室之中比于两径实在食时必依孔之广狭变其大</span>  
<span style="margin-left: 2em">小未尝正合焉</span>  
<span style="margin-left: 3em">室内测食食之分有定差</span>  
<span style="margin-left: 7em">依前图总光界辛己壬弧以加壬丁辛</span>  
<span style="margin-left: 7em">弧作全圈则甲乙元为食分与丙乙太</span>  
<span style="margin-left: 7em">阳全径实得比例今总光形之径己丁</span>  
<span style="margin-left: 7em">较之丙乙长两孔之半径<sub class="note-yuan">即己丙及乙丁</sub>故本</span>  
<span style="margin-left: 2em">径与食分变比例因而甲乙比于己丁线不如比于</span>  
<span style="margin-left: 2em">丙乙线得大小之理若丁戊<sub class="note-yuan">光形食之分</sub>则既乙丁与甲</span>  
<span style="margin-left: 2em">戊等亦自与甲乙相等可徴其大小之比例在光形</span>  
<span style="margin-left: 2em">有失矣</span>  
<span style="margin-left: 1em">或问测食与算食分数不合而每每所测分数恒不及</span>  
<span style="margin-left: 2em">必因食形假耳今欲改为真形从何法得曰以太阴</span>  
<span style="margin-left: 2em">半径加孔半径于太阳余光之内反减之各依本心</span>  
<span style="margin-left: 2em">光形内作弧得甲庚丙癸原正形即从甲太阳形心</span>  
<span style="margin-left: 2em">及丁太阴形心推定也</span>  
<span style="margin-left: 3em">定食分及两径比例必系真光形</span>  
<span style="margin-left: 1em">推算食分以定多寡法以两曜视径较于距度求之今</span>  
<span style="margin-left: 2em">欲于所测对验亦以日月两径以其两心相距几何</span>  
<span style="margin-left: 2em">即可得矣但测时因太阳行速依前法于形中点号</span>  
<span style="margin-left: 2em">以求径并距孔时远时近就景于先所画圈亦不易</span>  
<span style="margin-left: 2em">故纸距孔须定度<sub class="note-yuan">用窥管前开小孔后置白牌彼此以平行相照</sub>可免多圈</span>
