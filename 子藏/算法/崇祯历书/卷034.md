<span style="margin-left: 3em">似食实食说<sub class="note-yuan">第一</sub></span>  
<span style="margin-left: 1em">人恒言日食月食矣輙概混焉不知月实食日则似食</span>  
<span style="margin-left: 1em">而实非食也何者日为诸光之宗永无亏损月星皆借</span>  
<span style="margin-left: 1em">光焉朔则月与日为一线月正会于线上而在地与日</span>  
<span style="margin-left: 1em">之间月本厚体厚体能隔日光于下于是日若无光而</span>  
<span style="margin-left: 1em">光实未尝失也恶得而谓之食望则日月相对而日光</span>  
<span style="margin-left: 11em">正照之月体正受之人目正</span>  
<span style="margin-left: 11em">视之月光满矣此时若日月</span>  
<span style="margin-left: 11em">正相对如一线而地体适当</span>  
<span style="margin-left: 11em">线上则在日与月之间而地</span>  
<span style="margin-left: 11em">亦厚体厚体隔日光于此面</span>  
<span style="margin-left: 11em">而射影于彼面月在影中实</span>  
<span style="margin-left: 11em">失其所借之光是为食也然</span>  
<span style="margin-left: 11em">其食特地与月之失日光耳</span>  
<span style="margin-left: 11em">而其光之失因光在地面与</span>  
<span style="margin-left: 11em">月体之上地与月互相遮掩</span>  
<span style="margin-left: 1em">耳日固自若也总之日也月也地也使三体并不居一</span>  
<span style="margin-left: 1em">直线则更无食矣若食则日体恒居一直线之界末而</span>  
<span style="margin-left: 1em">彼界则月体地体叠居焉月体居界末则月面之日光</span>  
<span style="margin-left: 1em">食于地影矣地影居界末则地之日光食于月影矣</span>  
<span style="margin-left: 3em">实会中会似会说<sub class="note-yuan">第二</sub></span>  
<span style="margin-left: 1em">夫日月星宿之会总名也第有实会有中会有似会实</span>  
<span style="margin-left: 1em">会者以地心所出直线上至黄道者为主而日月五星</span>  
<span style="margin-left: 1em">政当此线则是实相会也如后图日在甲月在乙地心</span>  
<span style="margin-left: 1em">在丙甲乙丙线直至黄道圜之丁是也即南北相距不</span>  
<span style="margin-left: 1em">同在一点而总在此线正对之过枢圜亦为实会盖过</span>  
<span style="margin-left: 14em">枢圜者过黄道之两</span>  
<span style="margin-left: 14em">极而交会于黄道分</span>  
<span style="margin-left: 14em">黄道为四直角者也</span>  
<span style="margin-left: 14em">则从北而视南虽不</span>  
<span style="margin-left: 14em">在地心所出之一线</span>  
<span style="margin-left: 14em">却与地心所出之一</span>  
<span style="margin-left: 14em">线东西不偏而正相</span>  
<span style="margin-left: 14em">对犹一线矣故为实</span>  
<span style="margin-left: 14em">会也然月与五星居</span>  
<span style="margin-left: 14em">小轮之边地心所出</span>  
<span style="margin-left: 1em">线上至黄道而小轮之心正当此线者则为月与五星</span>  
<span style="margin-left: 1em">之中会也但日无小轮而日天本圜与地不同心两心</span>  
<span style="margin-left: 1em">所出必有两线此两线若为平行而月轮之心正当居</span>  
<span style="margin-left: 1em">地心线者则是日月中会也夫实会既以地心线射七</span>  
<span style="margin-left: 1em">政之体为主今此地心线过于小轮之心则谓之中会</span>  
<span style="margin-left: 1em">矣如地心为丙日天之圜心为戊月小轮之心为己日</span>  
<span style="margin-left: 1em">在甲甲日与戊心之戊甲径线而从地心丙出线至黄</span>  
<span style="margin-left: 1em">道辛平行乃是中会矣然实会中会俱准于地心而吾</span>  
<span style="margin-left: 1em">人所居乃在地面而从心所对一线从面所对又一线</span>  
<span style="margin-left: 1em">惟正当天顶之圜则两线同在一线与实会无异过此</span>  
<span style="margin-left: 1em">而偏左偏右即分两线矣今人所见日食皆地面上人</span>  
<span style="margin-left: 1em">目所对之线也日月在地心所对之线为实会则在人</span>  
<span style="margin-left: 1em">目所对之线不得为实会而特为似会矣如后<sub class="note-jiao">校：文淵本</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">后字脱</sub>第二图地心为丙地面为壬天顶为癸癸壬丙定</span>  
<span style="margin-left: 1em">为一直线也若甲日乙月即在癸丙线上则实会并是</span>  
<span style="margin-left: 1em">似会矣若日在子月在丑与地面壬为一线则似会也</span>  
<span style="margin-left: 1em">必月至寅与地心丙为一线方为实会耳则是实会在</span>  
<span style="margin-left: 1em">午前必先于似会实会在午后必后于似会也惟日食</span>  
<span style="margin-left: 1em">全以似会故地有不同而食之分数时候因之所以随</span>  
<span style="margin-left: 1em">地所见亦不同也第合朔论实会交食论似会实会似</span>  
<span style="margin-left: 9em">会之线在日月本天无度分而全</span>  
<span style="margin-left: 9em">依宗动天上黄道圜十二宫之度</span>  
<span style="margin-left: 9em">分则必当极论会线至黄道之处</span>  
<span style="margin-left: 9em">实会线所至谓之实处似会线所</span>  
<span style="margin-left: 9em">至谓之似处矣以实会线上之日</span>  
<span style="margin-left: 9em">月为据而目视日至黄道有日似</span>  
<span style="margin-left: 9em">处目视月至黄道有月似处得其</span>  
<span style="margin-left: 9em">似处可以较实处之距度矣如第</span>  
<span style="margin-left: 9em">二图子寅丙为实会线至黄道卯</span>  
<span style="margin-left: 9em">则卯为实处若壬目视子日至黄</span>  
<span style="margin-left: 1em">道辰视寅月至黄道午则辰为日似处午为月似处也</span>  
<span style="margin-left: 1em">然所用既皆实会似会而并论中会者凡地与日圜不</span>  
<span style="margin-left: 1em">同心而与列宿天则同心心同则径同而日圜之心在</span>  
<span style="margin-left: 1em">列宿天心与地心之上则日圜之径亦在列宿天径与</span>  
<span style="margin-left: 1em">地径之上列宿天之径割日圜为大小两分两分虽有</span>  
<span style="margin-left: 1em">大小而各应黄道之一百八十度此空度隔度之所出</span>  
<span style="margin-left: 1em">故不得不辩夫必用地中会线者求准对日与黄道迟</span>  
<span style="margin-left: 1em">速不均不平之本动又因而求实会之准则焉</span>  
<span style="margin-left: 3em">食之征<sub class="note-yuan">第三</sub></span>

<span style="margin-left: 15em">之较月食更难焉</span>  
<span style="margin-left: 15em">第观日月似会之</span>  
<span style="margin-left: 15em">时其距度比日月</span>  
<span style="margin-left: 15em">之半径或大或等</span>  
<span style="margin-left: 15em">者必无食也小则</span>  
<span style="margin-left: 15em">必食矣愈小则食</span>  
<span style="margin-left: 15em">愈大矣考之在龙</span>  
<span style="margin-left: 15em">头龙尾若正当头</span>  
<span style="margin-left: 15em">尾或与头尾不甚</span>  
<span style="margin-left: 15em">远则当测其食否</span>  
<span style="margin-left: 15em">若与龙头龙尾相</span>  
<span style="margin-left: 1em">远而月似会之距度过三十四分则无食矣可不必测</span>  
<span style="margin-left: 1em">矣月食则于望日求之月之距望若小于月半径与地</span>  
<span style="margin-left: 1em">半影者必食也其食之处定在龙头龙尾之两傍十三</span>  
<span style="margin-left: 1em">度三分度之一过此则月之行道不相涉而不相掩矣</span>  
<span style="margin-left: 1em">如甲子年八月望日月经龙尾不远则应测其食而考</span>  
<span style="margin-left: 1em">其所经之躔度乃在黄道白羊宫三度五十六分四十</span>  
<span style="margin-left: 1em">一秒其躔道距度则五分三十六秒矣夫月半径得十</span>  
<span style="margin-left: 1em">六分四十三秒而地影之半径则四十五分十三秒二</span>  
<span style="margin-left: 1em">数并之即为六十一分五十六秒距度止五分三十六</span>  
<span style="margin-left: 1em">秒是最小于月径及地影之半而全体必尽食地影必</span>  
<span style="margin-left: 1em">且有余矣若乙丑年八月望日其月在龙尾双鱼宫二</span>  
<span style="margin-left: 1em">十三度半夫月半径十七分十五秒而地影之半径则</span>  
<span style="margin-left: 1em">四十六分三十七秒二数并之得六十三分五十二秒</span>  
<span style="margin-left: 1em">月距躔道四十八分二秒则小过于地影之半径而月</span>  
<span style="margin-left: 1em">体必半入地影而不得全食也</span>  
<span style="margin-left: 3em">食之处<sub class="note-yuan">第四</sub></span>  
<span style="margin-left: 1em">龙头龙尾者何是日躔之两界月食所经之处也昔人</span>  
<span style="margin-left: 1em">测日月之食必在躔之二处而月之距此益远则距度</span>  
<span style="margin-left: 1em">益广广者象腹则其所起所止象头尾矣十二宫右旋</span>  
<span style="margin-left: 1em">从头至尾则左旋而此头尾二处非定于二宫但设为</span>  
<span style="margin-left: 13em">多圜嫌于繁混故止取</span>  
<span style="margin-left: 13em">龙之头尾以略征之也</span>  
<span style="margin-left: 13em">如上图甲丁乙为日躔</span>  
<span style="margin-left: 13em">圜甲丙乙为月行圜两</span>  
<span style="margin-left: 13em">圜交于甲于乙而从甲</span>  
<span style="margin-left: 13em">上升左旋至丙至乙故</span>  
<span style="margin-left: 13em">甲为头乙为尾丙丁相</span>  
<span style="margin-left: 13em">距最广为腹也但甲在</span>  
<span style="margin-left: 13em">白羊宫则乙在天称宫</span>  
<span style="margin-left: 13em">而腹在磨羯宫若甲在</span>  
<span style="margin-left: 1em">双鱼宫则乙在室女宫而腹在人马宫凡十九年乃复</span>  
<span style="margin-left: 1em">原处故日月之食不十九年不能在本躔同宫同度也</span>  
<span style="margin-left: 3em">日月地影之径说<sub class="note-yuan">第五</sub></span>  
<span style="margin-left: 1em">日月之径原自平分今因日在本圜月在小轮有远有</span>  
<span style="margin-left: 1em">近近则见其径大远则见其径小又地影者是日与地</span>  
<span style="margin-left: 1em">所生故日之远近亦能为影之大小也然无有食而月</span>  
<span style="margin-left: 1em">不居本圜之高处第就月居小轮日居本圜则每食自</span>  
<span style="margin-left: 1em">不同而其径之大小与小轮与日本圜无一定之规则</span>  
<span style="margin-left: 1em">惟用日月之本动方可考定今考月体本动之法每四</span>  
<span style="margin-left: 1em">刻若行半度则知其径亦半度矣日体每四刻若行二</span>  
<span style="margin-left: 1em">分三十秒须以十三乘之则知其径十三倍于二分三</span>  
<span style="margin-left: 1em">十秒矣此系一定之常法但日月之行时刻不均故以</span>  
<span style="margin-left: 1em">是法测其体之大小未免少差盖日愈髙其体愈觉小</span>  
<span style="margin-left: 1em">其动亦愈觉迟日愈下其体愈觉大其行亦愈觉速月</span>  
<span style="margin-left: 1em">在小轮其高下迟速亦然其考地影之法须先定日之</span>  
<span style="margin-left: 1em">最远处月径假有三十三分即以三率法求月体于影</span>  
<span style="margin-left: 1em">如五与十三之比例即等于三十三与八十五零五分</span>  
<span style="margin-left: 1em">之四之比例也若日不在最远先当考日之居所离最</span>  
<span style="margin-left: 1em">远处几何度次考日行比最远处几何疾以疾行之度</span>  
<span style="margin-left: 1em">减去地影则得所求矣</span>  
<span style="margin-left: 16em">食大小迟速辩</span>  
<span style="margin-left: 16em"><sub class="note-yuan">第六</sub></span>  
<span style="margin-left: 14em">夫距度广狭实为月</span>  
<span style="margin-left: 14em">食大小迟速之分故</span>  
<span style="margin-left: 14em">望日之月视其进地</span>  
<span style="margin-left: 14em">影厚处则其食迟进</span>  
<span style="margin-left: 14em">地影浅处则其食速</span>  
<span style="margin-left: 14em">朔日之月视其似会</span>  
<span style="margin-left: 14em">少偏日躔或似会大</span>  
<span style="margin-left: 14em">偏日躔而其故总由</span>  
<span style="margin-left: 8em">日月远乎龙之头尾也望日之月在</span>  
<span style="margin-left: 8em">头尾正躔则月食至大至深若少偏</span>  
<span style="margin-left: 8em">而躔影之半径与月体之半径等则</span>  
<span style="margin-left: 8em">虽全食而即复若距躔影又远则食</span>  
<span style="margin-left: 8em">不全也若日虽全食亦不能久因月</span>  
<span style="margin-left: 8em">径之似处小仅能遮日体而须臾便</span>  
<span style="margin-left: 8em">过故但能全掩不能久掩也今欲知</span>  
<span style="margin-left: 8em">食分大几何必须定其分数几何葢</span>  
<span style="margin-left: 8em">西洋取日月本体为十二平分移此</span>  
<span style="margin-left: 8em">分寸量月所经之处若日月食十二</span>  
<span style="margin-left: 1em">分有余者是谓至全至大之食也但欲精察不谬月食</span>  
<span style="margin-left: 1em">则究食甚时月道距躔道几何日食则究食甚时月似</span>  
<span style="margin-left: 1em">处距实会几何</span>  
<span style="margin-left: 3em">经候几何<sub class="note-yuan">第七</sub></span>  
<span style="margin-left: 1em">欲知食之经候几何须知日月之本动设若日月本动</span>  
<span style="margin-left: 1em">相同则月必不能进影进亦必不复出矣今月行黄道</span>  
<span style="margin-left: 1em">比日甚速能逐及于日而又过日前故但较月过速日</span>  
<span style="margin-left: 1em">过迟之两候即知日月食经候得几何也此有算就立</span>  
<span style="margin-left: 1em">成凡某时刻日月当食其本动之度几何则以日过迟</span>  
<span style="margin-left: 1em">之少数减去月过速之多数次取立成视月多行之度</span>  
<span style="margin-left: 1em">几何则得盖以过速之多数除初食至食甚之度数即</span>  
<span style="margin-left: 1em">系初食至食甚经候之度分也食甚至复圆亦如之顾</span>  
<span style="margin-left: 1em">日食之中前中后与月食有异盖日食惟在躔道九十</span>  
<span style="margin-left: 1em">度正天中者中前中后均平无异若其食偏在东西即</span>  
<span style="margin-left: 1em">有异矣偏东则初食至食甚短于食甚至复圆偏西则</span>  
<span style="margin-left: 1em">食甚至复圆短于初食至食甚故求日食毫厘不差必</span>  
<span style="margin-left: 1em">须较看日月行动先后两时刻度分其一在未食前其</span>  
<span style="margin-left: 1em">一挨复圆后而初食至食甚度分用以除食前一时刻</span>  
<span style="margin-left: 1em">度分食甚至复圆度分用以除复圆后一时刻度分即</span>  
<span style="margin-left: 1em">是日食中前中后之经候度分也</span>  
<span style="margin-left: 3em">日食月食辩第八<sub class="note-jiao">校：文淵本辯作辨</sub></span>  
<span style="margin-left: 1em">夫日食与月食固自有异盖月食天下皆同而日食则</span>  
<span style="margin-left: 1em">否日食此地速彼地迟此地见多彼地见少此地见偏</span>  
<span style="margin-left: 1em">南彼地见偏北无有相同者也而月食则凡地面见之</span>  
<span style="margin-left: 1em">者大小同焉迟速同焉经候同焉唯所居不同子午线</span>  
<span style="margin-left: 1em">者则时刻不同矣盖月一入影失其借光更无处可见</span>  
<span style="margin-left: 1em">其光也</span>

<span style="margin-left: 1em">朔之时刻日月之真方位及月离躔道之距度考南北</span>  
<span style="margin-left: 1em">东西差每处不同日月每时行几何度分与夫月进地</span>  
<span style="margin-left: 1em">影食甚时以较太阳行度几何迟速及他种种议论种</span>
