## 崇禎曆書卷之三十四　測食上卷

<span style="margin-left: 2em">測食<sub class="note-jiao">校：據清刊本補錄日抄本作交食蒙求</sub></span>  
<span style="margin-left: 1em">西洋測畧序</span>  
<span style="margin-left: 2em">占步之法與混阙並興如三厄爰定干支始制逮至</span>  
<span style="margin-left: 2em">羲曆軒圖撓推隷算其浚起者耳上下數千年業擅</span>  
<span style="margin-left: 2em">專門如樟慎史墨淳風道茂虞喜何承天洛下閎郭</span>  
<span style="margin-left: 2em">守敬輩攻是道者慮難更僕然猶曰星官曆師精神</span>  
<span style="margin-left: 2em">職業萃於此乃義裁成欽若帝王先務而聖門第一</span>  
<span style="margin-left: 2em">流傳心於夏正首兢兢馬嗣是以降如康成精算於</span>  
<span style="margin-left: 2em">渾天張衡殫思於靈憲高光歲差之辨盧照隙渾儀</span>  
<span style="margin-left: 2em">之賦以至寶儼預占奎聚邵堯夫巧立差法沈存中</span>  
<span style="margin-left: 2em">考定兩極此皆學海儒宗祠林韻士仰觀凶覽不遺</span>  
<span style="margin-left: 2em">餘力毋亦以理数之源同天人之旨一範圍通知自</span>  
<span style="margin-left: 2em">是學者分內事歟</span>  
<span style="margin-left: 1em">明興景運聿隆偉人輩出道德文章皆項相望獨治曆</span>  
<span style="margin-left: 2em">一法薦紳先生罕此論述予生長僻陋甕天爲畛每</span>  
<span style="margin-left: 2em">誦管公明家雞野鶩之言重增嘆息爲縫掖居里中</span>  
<span style="margin-left: 2em">聞有西域遠人此遊</span>  
<span style="margin-left: 2em">上國圓象曆法精密罕儷掫欣然神往焉通籍以還</span>  
<span style="margin-left: 2em">風塵鞅當重來</span>  
<span style="margin-left: 2em">都中獲聆緒論初若河漢疑信半之徐而繹思皆爲</span>  
<span style="margin-left: 2em">歸宿其說往往就目前實際而窮極至大推見至隱</span>  
<span style="margin-left: 2em">舉凡廣漠纎忽符茀不爽恨才識寡尠莫窺津畔然</span>  
<span style="margin-left: 2em">已不啻望我於海若之洋矣先達鉅公多與之遊因</span>  
<span style="margin-left: 2em">譯有測蝕畧一編爲占步嚆矢其副墨則予小子得</span>  
<span style="margin-left: 2em">而寓目焉將付梨棗以公同志不揣蕪鄙粗述梗概</span>  
<span style="margin-left: 2em">乃若其人誠心質行善詮名理風土雅殊旨趣原一</span>  
<span style="margin-left: 2em">始信鵝湖南北海之說未爲虛語予方守儒门功令</span>  
<span style="margin-left: 2em">夫暇入其凶中然一有味乎其言則曆象直糟粕耳</span>  
<span style="margin-left: 1em">天啓五年歲次乙丑季夏吉旦嚴陵汪喬年撰</span>  
<span style="margin-left: 1em">測食</span>  
<span style="margin-left: 14em">大西湯若望述</span>  
<span style="margin-left: 3em">總論</span>  
<span style="margin-left: 1em">天學家究日月諸星之理設爲圜界以論其運動支分</span>  
<span style="margin-left: 1em">爲五隨應焉</span>  
<span style="margin-left: 1em">其一論從月星之本圜小輪而應其居所不一時或正</span>  
<span style="margin-left: 1em">行時或退行</span>  
<span style="margin-left: 1em">其二論月星之隨應太陽如臣庶之應其君也其光之</span>  
<span style="margin-left: 1em">消長及其東西出没無不隨而應之</span>  
<span style="margin-left: 1em">其三論月星與太陽相近相遠相會相對或三一或四</span>  
<span style="margin-left: 1em">一或六一何謂三一是全圜三分之一也如上下弦即</span>  
<span style="margin-left: 1em">全圜四分之一之類</span>  
<span style="margin-left: 1em">其四論月星應日躔赤道之遠近離躔道謂之黃道緯</span>  
<span style="margin-left: 1em">度離赤道謂之赤道緯度</span>  
<span style="margin-left: 1em">其五論月星顯示人目之別垂象向地之異如會望似</span>  
<span style="margin-left: 1em">似實似之類此支之隨應倍切于彼四支者以能快人</span>  
<span style="margin-left: 1em">覩而不難證也</span>  
<span style="margin-left: 1em">本篇于前四支尚不具論僅論其第五支然欲采諸子</span>  
<span style="margin-left: 1em">之成法而全述之懼浩瀚難盡兹獨摘其最切于食義</span>  
<span style="margin-left: 1em">者釐爲上下二篇上述食之梗概下窮食之義理以豁</span>  
<span style="margin-left: 1em">初習天蔀者之一二疑云爾</span>  
<span style="margin-left: 4em">復</span>  
<span style="margin-left: 2em">大冢宰崧翁李老先生命測月食書</span>  
<span style="margin-left: 4em">今歲仲春之望據歷月復應食望奉</span>  
<span style="margin-left: 2em">命測算造次呈</span>  
<span style="margin-left: 2em">覽猥蒙</span>  
<span style="margin-left: 3em">軫念孤旅候</span>  
<span style="margin-left: 1em">命邸中以所測說轉達春曹隨蒙</span>  
<span style="margin-left: 2em">大宗伯林老先生差官至寓取稿伏惟</span>  
<span style="margin-left: 2em">盛德弘仁不遺遐遠誠</span>  
<span style="margin-left: 2em">上國之柔遠而風慕義之極思也第匆遽間即以所</span>  
<span style="margin-left: 3em">測原幅輕褻于</span>  
<span style="margin-left: 2em">當世大人之前思之殊爲悚慄兹承</span>  
<span style="margin-left: 2em">嚴命測算望不敢以所食分秒時刻一圖漫爾塞責</span>  
<span style="margin-left: 3em">故忘其固陋輙拾小邦之遺軌述食理之梗概敬</span>  
<span style="margin-left: 3em">呈</span>  
<span style="margin-left: 2em">台階以塵</span>  
<span style="margin-left: 2em">清目或不即見笑于</span>  
<span style="margin-left: 2em">大方也兹書上篇略言食之所以然下篇則言食之</span>  
<span style="margin-left: 3em">義理倘不以人廢言而游心于食之所以然究其</span>  
<span style="margin-left: 3em">義理之所歸則于天學七政或不無少裨也伏乞</span>  
<span style="margin-left: 2em">台臺留神于若天齊政而鄭重兹學更祈于</span>  
<span style="margin-left: 3em">退食之暇俯</span>  
<span style="margin-left: 3em">賜删削則遠人不勝拜</span>

<span style="margin-left: 3em">似食實食說<sub class="note-yuan">第一</sub></span>  
<span style="margin-left: 1em">人恒言日食月食矣輙概混焉不知月實食日則似食</span>  
<span style="margin-left: 1em">而實非食也何者日爲諸光之宗永無虧損月星皆借</span>  
<span style="margin-left: 1em">光焉朔則月與日爲一線月正會於線上而在地與日</span>  
<span style="margin-left: 1em">之間月本厚體厚體能隔日光於下於是日若無光而</span>  
<span style="margin-left: 1em">光實未嘗失也惡得而謂之食望則日月相對而日光</span>  
<span style="margin-left: 11em">正照之月體正受之人目正</span>  
<span style="margin-left: 11em">視之月光滿矣此時若日月</span>  
<span style="margin-left: 11em">正相對如一線而地體適當</span>  
<span style="margin-left: 11em">線上則在日與月之間而地</span>  
<span style="margin-left: 11em">亦厚體厚體隔日光於此面</span>  
<span style="margin-left: 11em">而射影於彼面月在影中實</span>  
<span style="margin-left: 11em">失其所借之光是爲食也然</span>  
<span style="margin-left: 11em">其食特地與月之失日光耳</span>  
<span style="margin-left: 11em">而其光之失因光在地面與</span>  
<span style="margin-left: 11em">月體之上地與月互相遮掩</span>  
<span style="margin-left: 1em">耳日固自若也總之日也月也地也使三體並不居一</span>  
<span style="margin-left: 1em">直線則更無食矣若食則日體恒居一直線之界末而</span>  
<span style="margin-left: 1em">彼界則月體地體叠居焉月體居界末則月面之日光</span>  
<span style="margin-left: 1em">食於地影矣地影居界末則地之日光食於月影矣</span>  
<span style="margin-left: 3em">實會中會似會說<sub class="note-yuan">第二</sub></span>  
<span style="margin-left: 1em">夫日月星宿之會總名也第有實會有中會有似會實</span>  
<span style="margin-left: 1em">會者以地心所出直線上至黃道者爲主而日月五星</span>  
<span style="margin-left: 1em">政當此線則是實相會也如後圖日在甲月在乙地心</span>  
<span style="margin-left: 1em">在丙甲乙丙線直至黃道圜之丁是也即南北相距不</span>  
<span style="margin-left: 1em">同在一點而總在此線正對之過樞圜亦爲實會蓋過</span>  
<span style="margin-left: 14em">樞圜者過黃道之兩</span>  
<span style="margin-left: 14em">極而交會於黃道分</span>  
<span style="margin-left: 14em">黃道爲四直角者也</span>  
<span style="margin-left: 14em">則從北而視南雖不</span>  
<span style="margin-left: 14em">在地心所出之一線</span>  
<span style="margin-left: 14em">却與地心所出之一</span>  
<span style="margin-left: 14em">線東西不偏而正相</span>  
<span style="margin-left: 14em">對猶一線矣故爲實</span>  
<span style="margin-left: 14em">會也然月與五星居</span>  
<span style="margin-left: 14em">小輪之邊地心所出</span>  
<span style="margin-left: 1em">線上至黃道而小輪之心正當此線者則爲月與五星</span>  
<span style="margin-left: 1em">之中會也但日無小輪而日天本圜與地不同心兩心</span>  
<span style="margin-left: 1em">所出必有兩線此兩線若爲平行而月輪之心正當居</span>  
<span style="margin-left: 1em">地心線者則是日月中會也夫實會既以地心線射七</span>  
<span style="margin-left: 1em">政之體爲主今此地心線過於小輪之心則謂之中會</span>  
<span style="margin-left: 1em">矣如地心爲丙日天之圜心爲戊月小輪之心爲己日</span>  
<span style="margin-left: 1em">在甲甲日與戊心之戊甲徑線而從地心丙出線至黃</span>  
<span style="margin-left: 1em">道辛平行乃是中會矣然實會中會俱準於地心而吾</span>  
<span style="margin-left: 1em">人所居乃在地面而從心所對一線從面所對又一線</span>  
<span style="margin-left: 1em">惟正當天頂之圜則兩線同在一線與實會無異過此</span>  
<span style="margin-left: 1em">而偏左偏右即分兩線矣今人所見日食皆地面上人</span>  
<span style="margin-left: 1em">目所對之線也日月在地心所對之線爲實會則在人</span>  
<span style="margin-left: 1em">目所對之線不得爲實會而特爲似會矣如後<sub class="note-jiao">校：文淵本</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">後字脫</sub>第二圖地心爲丙地面爲壬天頂爲癸癸壬丙定</span>  
<span style="margin-left: 1em">爲一直線也若甲日乙月即在癸丙線上則實會併是</span>  
<span style="margin-left: 1em">似會矣若日在子月在丑與地面壬爲一線則似會也</span>  
<span style="margin-left: 1em">必月至寅與地心丙爲一線方爲實會耳則是實會在</span>  
<span style="margin-left: 1em">午前必先於似會實會在午後必後於似會也惟日食</span>  
<span style="margin-left: 1em">全以似會故地有不同而食之分數時候因之所以隨</span>  
<span style="margin-left: 1em">地所見亦不同也第合朔論實會交食論似會實會似</span>  
<span style="margin-left: 9em">會之線在日月本天無度分而全</span>  
<span style="margin-left: 9em">依宗動天上黃道圜十二宫之度</span>  
<span style="margin-left: 9em">分則必當極論會線至黃道之處</span>  
<span style="margin-left: 9em">實會線所至謂之實處似會線所</span>  
<span style="margin-left: 9em">至謂之似處矣以實會線上之日</span>  
<span style="margin-left: 9em">月爲據而目視日至黃道有日似</span>  
<span style="margin-left: 9em">處目視月至黃道有月似處得其</span>  
<span style="margin-left: 9em">似處可以較實處之距度矣如第</span>  
<span style="margin-left: 9em">二圖子寅丙爲實會線至黃道卯</span>  
<span style="margin-left: 9em">則卯爲實處若壬目視子日至黃</span>  
<span style="margin-left: 1em">道辰視寅月至黃道午則辰爲日似處午爲月似處也</span>  
<span style="margin-left: 1em">然所用既皆實會似會而并論中會者凡地與日圜不</span>  
<span style="margin-left: 1em">同心而與列宿天則同心心同則徑同而日圜之心在</span>  
<span style="margin-left: 1em">列宿天心與地心之上則日圜之徑亦在列宿天徑與</span>  
<span style="margin-left: 1em">地徑之上列宿天之徑割日圜爲大小兩分兩分雖有</span>  
<span style="margin-left: 1em">大小而各應黃道之一百八十度此空度隔度之所出</span>  
<span style="margin-left: 1em">故不得不辯夫必用地中會線者求準對日與黃道遲</span>  
<span style="margin-left: 1em">速不均不平之本動又因而求實會之準則焉</span>  
<span style="margin-left: 3em">食之徵<sub class="note-yuan">第三</sub></span>  
<span style="margin-left: 1em">凡日月相會未必皆食惟因會之有似有實而悉其差</span>  
<span style="margin-left: 15em">之遠近幾何此必</span>  
<span style="margin-left: 15em">須測驗而後得凡</span>  
<span style="margin-left: 15em">人居赤道北者月</span>  
<span style="margin-left: 15em">之似處比實處恒</span>  
<span style="margin-left: 15em">若偏南若偏低者</span>  
<span style="margin-left: 15em">然夫月在日與目</span>  
<span style="margin-left: 15em">之一直線上不偏</span>  
<span style="margin-left: 15em">斜不低昴乃能掩</span>  
<span style="margin-left: 15em">日而爲食若精察</span>  
<span style="margin-left: 15em">之較月食更難焉</span>  
<span style="margin-left: 15em">第觀日月似會之</span>  
<span style="margin-left: 15em">時其距度比日月</span>  
<span style="margin-left: 15em">之半徑或大或等</span>  
<span style="margin-left: 15em">者必無食也小則</span>  
<span style="margin-left: 15em">必食矣愈小則食</span>  
<span style="margin-left: 15em">愈大矣考之在龍</span>  
<span style="margin-left: 15em">頭龍尾若正當頭</span>  
<span style="margin-left: 15em">尾或與頭尾不甚</span>  
<span style="margin-left: 15em">遠則當測其食否</span>  
<span style="margin-left: 15em">若與龍頭龍尾相</span>  
<span style="margin-left: 1em">遠而月似會之距度過三十四分則無食矣可不必測</span>  
<span style="margin-left: 1em">矣月食則於望日求之月之距望若小於月半徑與地</span>  
<span style="margin-left: 1em">半影者必食也其食之處定在龍頭龍尾之兩傍十三</span>  
<span style="margin-left: 1em">度三分度之一過此則月之行道不相涉而不相掩矣</span>  
<span style="margin-left: 1em">如甲子年八月望日月經龍尾不遠則應測其食而考</span>  
<span style="margin-left: 1em">其所經之躔度乃在黃道白羊宫三度五十六分四十</span>  
<span style="margin-left: 1em">一秒其躔道距度則五分三十六秒矣夫月半徑得十</span>  
<span style="margin-left: 1em">六分四十三秒而地影之半徑則四十五分十三秒二</span>  
<span style="margin-left: 1em">數併之即爲六十一分五十六秒距度止五分三十六</span>  
<span style="margin-left: 1em">秒是最小於月徑及地影之半而全體必盡食地影必</span>  
<span style="margin-left: 1em">且有餘矣若乙丑年八月望日其月在龍尾雙魚宫二</span>  
<span style="margin-left: 1em">十三度半夫月半徑十七分十五秒而地影之半徑則</span>  
<span style="margin-left: 1em">四十六分三十七秒二數併之得六十三分五十二秒</span>  
<span style="margin-left: 1em">月距躔道四十八分二秒則小過於地影之半徑而月</span>  
<span style="margin-left: 1em">體必半入地影而不得全食也</span>  
<span style="margin-left: 3em">食之處<sub class="note-yuan">第四</sub></span>  
<span style="margin-left: 1em">龍頭龍尾者何是日躔之兩界月食所經之處也昔人</span>  
<span style="margin-left: 1em">測日月之食必在躔之二處而月之距此益遠則距度</span>  
<span style="margin-left: 1em">益廣廣者象腹則其所起所止象頭尾矣十二宫右旋</span>  
<span style="margin-left: 1em">從頭至尾則左旋而此頭尾二處非定於二宫但設爲</span>  
<span style="margin-left: 13em">多圜嫌於繁混故止取</span>  
<span style="margin-left: 13em">龍之頭尾以略徵之也</span>  
<span style="margin-left: 13em">如上圖甲丁乙爲日躔</span>  
<span style="margin-left: 13em">圜甲丙乙爲月行圜兩</span>  
<span style="margin-left: 13em">圜交於甲於乙而從甲</span>  
<span style="margin-left: 13em">上升左旋至丙至乙故</span>  
<span style="margin-left: 13em">甲爲頭乙爲尾丙丁相</span>  
<span style="margin-left: 13em">距最廣爲腹也但甲在</span>  
<span style="margin-left: 13em">白羊宫則乙在天稱宫</span>  
<span style="margin-left: 13em">而腹在磨羯宫若甲在</span>  
<span style="margin-left: 1em">雙魚宫則乙在室女宫而腹在人馬宫凡十九年乃復</span>  
<span style="margin-left: 1em">原處故日月之食不十九年不能在本躔同宫同度也</span>  
<span style="margin-left: 3em">日月地影之徑說<sub class="note-yuan">第五</sub></span>  
<span style="margin-left: 1em">日月之徑原自平分今因日在本圜月在小輪有遠有</span>  
<span style="margin-left: 1em">近近則見其徑大遠則見其徑小又地影者是日與地</span>  
<span style="margin-left: 1em">所生故日之遠近亦能爲影之大小也然無有食而月</span>  
<span style="margin-left: 1em">不居本圜之高處第就月居小輪日居本圜則每食自</span>  
<span style="margin-left: 1em">不同而其徑之大小與小輪與日本圜無一定之規則</span>  
<span style="margin-left: 1em">惟用日月之本動方可考定今考月體本動之法每四</span>  
<span style="margin-left: 1em">刻若行半度則知其徑亦半度矣日體每四刻若行二</span>  
<span style="margin-left: 1em">分三十秒須以十三乘之則知其徑十三倍於二分三</span>  
<span style="margin-left: 1em">十秒矣此係一定之常法但日月之行時刻不均故以</span>  
<span style="margin-left: 1em">是法測其體之大小未免少差蓋日愈髙其體愈覺小</span>  
<span style="margin-left: 1em">其動亦愈覺遲日愈下其體愈覺大其行亦愈覺速月</span>  
<span style="margin-left: 1em">在小輪其高下遲速亦然其考地影之法須先定日之</span>  
<span style="margin-left: 1em">最遠處月徑假有三十三分即以三率法求月體於影</span>  
<span style="margin-left: 1em">如五與十三之比例即等於三十三與八十五零五分</span>  
<span style="margin-left: 1em">之四之比例也若日不在最遠先當考日之居所離最</span>  
<span style="margin-left: 1em">遠處幾何度次考日行比最遠處幾何疾以疾行之度</span>  
<span style="margin-left: 1em">減去地影則得所求矣</span>  
<span style="margin-left: 16em">食大小遲速辯</span>  
<span style="margin-left: 16em"><sub class="note-yuan">第六</sub></span>  
<span style="margin-left: 14em">夫距度廣狹實爲月</span>  
<span style="margin-left: 14em">食大小遲速之分故</span>  
<span style="margin-left: 14em">望日之月視其進地</span>  
<span style="margin-left: 14em">影厚處則其食遲進</span>  
<span style="margin-left: 14em">地影淺處則其食速</span>  
<span style="margin-left: 14em">朔日之月視其似會</span>  
<span style="margin-left: 14em">少偏日躔或似會大</span>  
<span style="margin-left: 14em">偏日躔而其故總由</span>  
<span style="margin-left: 8em">日月遠乎龍之頭尾也望日之月在</span>  
<span style="margin-left: 8em">頭尾正躔則月食至大至深若少偏</span>  
<span style="margin-left: 8em">而躔影之半徑與月體之半徑等則</span>  
<span style="margin-left: 8em">雖全食而即復若距躔影又遠則食</span>  
<span style="margin-left: 8em">不全也若日雖全食亦不能久因月</span>  
<span style="margin-left: 8em">徑之似處小僅能遮日體而須臾便</span>  
<span style="margin-left: 8em">過故但能全掩不能久掩也今欲知</span>  
<span style="margin-left: 8em">食分大幾何必須定其分數幾何葢</span>  
<span style="margin-left: 8em">西洋取日月本體爲十二平分移此</span>  
<span style="margin-left: 8em">分寸量月所經之處若日月食十二</span>  
<span style="margin-left: 1em">分有餘者是謂至全至大之食也但欲精察不謬月食</span>  
<span style="margin-left: 1em">則究食甚時月道距躔道幾何日食則究食甚時月似</span>  
<span style="margin-left: 1em">處距實會幾何</span>  
<span style="margin-left: 3em">經候幾何<sub class="note-yuan">第七</sub></span>  
<span style="margin-left: 1em">欲知食之經候幾何須知日月之本動設若日月本動</span>  
<span style="margin-left: 1em">相同則月必不能進影進亦必不復出矣今月行黃道</span>  
<span style="margin-left: 1em">比日甚速能逐及於日而又過日前故但較月過速日</span>  
<span style="margin-left: 1em">過遲之兩候即知日月食經候得幾何也此有算就立</span>  
<span style="margin-left: 1em">成凡某時刻日月當食其本動之度幾何則以日過遲</span>  
<span style="margin-left: 1em">之少數減去月過速之多數次取立成視月多行之度</span>  
<span style="margin-left: 1em">幾何則得蓋以過速之多數除初食至食甚之度數即</span>  
<span style="margin-left: 1em">係初食至食甚經候之度分也食甚至復圓亦如之顧</span>  
<span style="margin-left: 1em">日食之中前中後與月食有異蓋日食惟在躔道九十</span>  
<span style="margin-left: 1em">度正天中者中前中後均平無異若其食偏在東西即</span>  
<span style="margin-left: 1em">有異矣偏東則初食至食甚短於食甚至復圓偏西則</span>  
<span style="margin-left: 1em">食甚至復圓短於初食至食甚故求日食毫釐不差必</span>  
<span style="margin-left: 1em">須較看日月行動先後兩時刻度分其一在未食前其</span>  
<span style="margin-left: 1em">一挨復圓後而初食至食甚度分用以除食前一時刻</span>  
<span style="margin-left: 1em">度分食甚至復圓度分用以除復圓後一時刻度分即</span>  
<span style="margin-left: 1em">是日食中前中後之經候度分也</span>  
<span style="margin-left: 3em">日食月食辯第八<sub class="note-jiao">校：文淵本辯作辨</sub></span>  
<span style="margin-left: 1em">夫日食與月食固自有異蓋月食天下皆同而日食則</span>  
<span style="margin-left: 1em">否日食此地速彼地遲此地見多彼地見少此地見偏</span>  
<span style="margin-left: 1em">南彼地見偏北無有相同者也而月食則凡地面見之</span>  
<span style="margin-left: 1em">者大小同焉遲速同焉經候同焉唯所居不同子午線</span>  
<span style="margin-left: 1em">者則時刻不同矣蓋月一入影失其借光更無處可見</span>  
<span style="margin-left: 1em">其光也</span>  
<span style="margin-left: 1em">右所舉不過略言食之固然與夫所以然耳若精求合</span>  
<span style="margin-left: 1em">朔之時刻日月之真方位及月離躔道之距度考南北</span>  
<span style="margin-left: 1em">東西差每處不同日月每時行幾何度分與夫月進地</span>  
<span style="margin-left: 1em">影食甚時以較太陽行度幾何遲速及他種種議論種</span>  
<span style="margin-left: 1em">種見解是書皆未及言俱各有本論及立成井井臚列</span>  
<span style="margin-left: 1em">俟翻譯後開卷一目便已了然</span>
