## 崇禎曆書卷之十二　崇禎奏疏

*崇禎十一年三月十八日至崇禎十二年五月十六日*

<span style="margin-left: 2em">緣起十二</span>  
<span style="margin-left: 7em">崇禎十一年三月十八日李天經題本</span>  
<span style="margin-left: 3em">督修曆法山東按察使司按察使照京官例正三</span>  
<span style="margin-left: 3em">品支俸臣李天經謹</span>  
<span style="margin-left: 2em">題爲遠臣盡瘁身殞優賚屢</span>  
<span style="margin-left: 1em">旨久虛懇乞</span>  
<span style="margin-left: 1em">勅部速覆以酬前勞以慰忠魂事切照修曆遠臣羅雅</span>  
<span style="margin-left: 3em">谷者係原任督修曆法故輔臣徐光啓于崇禎三</span>  
<span style="margin-left: 3em">年五月內因遠臣鄧玉函病故修曆乏人具疏上</span>  
<span style="margin-left: 1em">請內稱訪得諸臣同學尚有湯若望羅雅谷二臣者其</span>  
<span style="margin-left: 3em">術業與玉函相埒而年力正强堪以効用伏乞</span>  
<span style="margin-left: 1em">勅下就便移文敦諭二臣并行所在官司資給前來庶</span>  
<span style="margin-left: 3em">令人出所長早奏厥績等因本月十九日奉</span>  
<span style="margin-left: 1em">聖旨曆法方在改修湯若望等既可訪用着地方官資</span>  
<span style="margin-left: 2em">給前來該衙門知道欽此欽遵隨于本年七月內據</span>  
<span style="margin-left: 3em">河南開封府知府袁楷具文資給羅雅谷前來本</span>  
<span style="margin-left: 3em">月初六日故輔臣徐光啓題奉</span>  
<span style="margin-left: 1em">聖旨羅雅谷准朝見供事該部知道當經</span>  
<span style="margin-left: 2em">朝見赴局供事九載于兹公同遠臣湯若望等譔成</span>  
<span style="margin-left: 3em">曆法書表一百四十餘卷繕製新式儀器十數種</span>  
<span style="margin-left: 3em">見在</span>  
<span style="margin-left: 1em">御前且于數年已來指教臺官嘔心瀝血其日躔月離</span>  
<span style="margin-left: 3em">雖已傳授習熟幾于穎禿唇焦臣與輔臣曾已屢</span>  
<span style="margin-left: 3em">疏列名首叙叠奉有紀錄酌議之</span>  
<span style="margin-left: 1em">旨在部未經議覆復于九年七月內因醜盧內犯戎政</span>  
<span style="margin-left: 3em">及都察院等衙門交薦奉有羅雅谷等即着隨營</span>  
<span style="margin-left: 3em">指授以折狂氛有功從優叙賚之</span>  
<span style="margin-left: 1em">旨兩臣即登陴指授義切同仇嗣因城守叙勞復奉有</span>  
<span style="margin-left: 3em">羅雅谷等修曆演器著有勤勞自當從優叙賚之</span>  
<span style="margin-left: 1em">旨兹無論一時同叙之大小文武臣工俱膺擢陞秩級</span>  
<span style="margin-left: 3em">即捐助如吳守義者亦荷</span>  
<span style="margin-left: 1em">勅賜建坊奬勵祇因兩臣守素學道不願官職已經禮</span>  
<span style="margin-left: 3em">部題</span>  
<span style="margin-left: 1em">准各給房一所田數頃</span>  
<span style="margin-left: 1em">欽允在案而兩臣又苦于書役之谿欲難饜豪强之覇</span>  
<span style="margin-left: 3em">占可虞爲是具疏控辭復荷</span>  
<span style="margin-left: 1em">聖明不忍冺其前勞仍</span>  
<span style="margin-left: 1em">勅禮部另議兩臣翹首望</span>  
<span style="margin-left: 1em">恩已成隔歲有本局博士等官不忍坐視向隅乃于今</span>  
<span style="margin-left: 3em">春二月間具呈禮部堂司已批即題隨經祠祭司</span>  
<span style="margin-left: 3em">郎中何三省循例具稿每人每月各給湯飯桌半</span>  
<span style="margin-left: 3em">張廩米一石并纂修酒食等項以見</span>  
<span style="margin-left: 2em">朝供事之日爲始照例補給向後仍令關支等因呈</span>  
<span style="margin-left: 3em">堂批行臣等伏念兩臣自任事已來每日止共領</span>  
<span style="margin-left: 3em">光祿寺下程銀三分米四合清苦奚堪且以造曆</span>  
<span style="margin-left: 3em">未成如魏文魁者生叨湯飯殁徼秩級之外尚蒙</span>  
<span style="margin-left: 3em">照前補其俸廩父子沾</span>  
<span style="margin-left: 1em">恩而谷等造曆有成守城著績兩奉有優賚之</span>  
<span style="margin-left: 1em">旨較之自應加優况若各給田房價值奚啻數千金今</span>  
<span style="margin-left: 3em">每人補給湯飯爲數不多即每月各補一張在</span>  
<span style="margin-left: 1em">聖恩或弗靳予豈意復逾一月尚未</span>  
<span style="margin-left: 2em">題覆至曆法名仍大統新局推測屢近</span>  
<span style="margin-left: 1em">明旨昭然其所以旁求更正一節曾未見該監虛心商</span>  
<span style="margin-left: 3em">及于臣僅見其通同妬嫉仍蹈游移之故轍而不</span>  
<span style="margin-left: 3em">遵畫一之</span>  
<span style="margin-left: 1em">屢旨尚爾侈言再測狃舊憚新正嗟</span>  
<span style="margin-left: 1em">頒布無期河清難俟而遠臣羅雅谷又以積勞成疾忽</span>  
<span style="margin-left: 3em">于三月十三日一旦溘然長逝矣然此臣之忠懐</span>  
<span style="margin-left: 3em">素藴學術淵微推測不憚于燠寒著作奚分乎晝</span>  
<span style="margin-left: 3em">夜以致年未艾而鬚髪早白甘貧淡而面鵠形鳩</span>  
<span style="margin-left: 3em">氣息奄奄既已致身于</span>  
<span style="margin-left: 1em">聖世而遺骸之埋瘞不無有望于</span>  
<span style="margin-left: 1em">皇仁伏乞</span>  
<span style="margin-left: 1em">聖明勅下該部即如所議速爲</span>  
<span style="margin-left: 2em">題覆俾湯若望之生者得以資其朝夕而羅雅谷之</span>  
<span style="margin-left: 3em">死者得以充其殯埋庶我</span>  
<span style="margin-left: 2em">國家澤枯之</span>  
<span style="margin-left: 1em">德與柔遠之仁足以遠播于遐陬而兩臣修曆與城守</span>  
<span style="margin-left: 3em">之微勞亦不致終歸冺滅矣臣于此又有</span>  
<span style="margin-left: 1em">請焉伏查臣局曆法書器久已告成業蒙</span>  
<span style="margin-left: 1em">聖明判斷畫一將疎遠者散遣回籍差誤者准令更正</span>  
<span style="margin-left: 3em">獨留新法之推測屢近者存監學習今羅雅谷雖</span>  
<span style="margin-left: 3em">已物故而交食七政經緯與夫氣節晦朔弦望等</span>  
<span style="margin-left: 3em">項臣局各官俱素嫻推算然教習臺官不無賴于</span>  
<span style="margin-left: 3em">遠臣湯若望也此臣曆學專門精深博洽足以辦</span>  
<span style="margin-left: 3em">此但苦一人之精力有限又有本等道業誠恐指</span>  
<span style="margin-left: 3em">授與旁通兩事難以獨肩自稱若望同學見有汪</span>  
<span style="margin-left: 3em">爾斐者推測素諳年力正壯堪以訪用伏乞</span>  
<span style="margin-left: 1em">聖明勅下容臣移文所在官司資給前來共襄</span>  
<span style="margin-left: 1em">大典其于治曆明時不無小補矣至若遠臣羅雅谷殁</span>  
<span style="margin-left: 3em">于</span>  
<span style="margin-left: 2em">王事萬里孤魂不堪歸襯見有利瑪竇之例可援其</span>  
<span style="margin-left: 1em">會典亦有成例可考優䘏</span>  
<span style="margin-left: 1em">特典出自</span>  
<span style="margin-left: 1em">聖裁非臣之所敢擅議也</span>  
<span style="margin-left: 3em">崇禎十一年三月十八日具</span>  
<span style="margin-left: 2em">題二十四日奉</span>  
<span style="margin-left: 1em">聖旨該部看議速覆</span>  
<span style="margin-left: 7em">崇禎十一年四月二十二日禮部題本</span>  
<span style="margin-left: 3em">禮部</span>  
<span style="margin-left: 2em">題爲遵</span>  
<span style="margin-left: 1em">旨酌議恭請</span>  
<span style="margin-left: 1em">聖裁事祠祭清吏司案呈案查先該本部題覆修政曆</span>  
<span style="margin-left: 3em">法遠臣羅雅谷等奏爲</span>  
<span style="margin-left: 1em">聖明柔遠過渥微臣圖報未遑謹預辭</span>  
<span style="margin-left: 1em">欽允田房以表忠藎事等因崇禎十年九月十七日奉</span>  
<span style="margin-left: 1em">聖旨羅雅谷等奏辭田房不必再行查給該部還另議</span>  
<span style="margin-left: 2em">具奏欽此欽遵抄部送司隨准督修曆法山東按察</span>  
<span style="margin-left: 3em">使李天經手本開稱城守叙錄谷等幸叨優叙但</span>  
<span style="margin-left: 3em">緣兩臣不願官秩題</span>  
<span style="margin-left: 1em">准查給田房具疏控辭既蒙</span>  
<span style="margin-left: 1em">勅部另議可不亟爲另行措處給與兩臣自行搆置仍</span>  
<span style="margin-left: 3em">一面比照鄉民吳守義等見行事例題</span>  
<span style="margin-left: 1em">請建坊奬勵等因在案又經移文曆局備查兩臣來京</span>  
<span style="margin-left: 3em">修曆日期去後續據李天經手本內開陪臣<sub class="note-jiao">校：清刊本</sub></span>  
<span style="margin-left: 3em"><sub class="note-yuan">陪臣改作遠臣</sub>羅雅谷自崇禎三年七月初六日見</span>  
<span style="margin-left: 2em">朝供事陪臣<sub class="note-jiao">校：同前條</sub>湯若望自崇禎三年十二月初二</span>  
<span style="margin-left: 3em">日見</span>  
<span style="margin-left: 2em">朝供事迄今已及八載每日止領光祿寺下程銀三</span>  
<span style="margin-left: 3em">分米四合似未足供日用清苦堪念既奉另議之</span>  
<span style="margin-left: 1em">旨相應題</span>  
<span style="margin-left: 1em">請回覆前來正在查議題覆間又該督修曆法山東按</span>  
<span style="margin-left: 3em">察使司按察使照京官例正三品支俸李天經題</span>  
<span style="margin-left: 3em">爲遠臣盡瘁身殞等事<sub class="note-yuan">云云</sub>非臣之所敢擅議也</span>  
<span style="margin-left: 3em">等因崇禎十一年三月二十四日奉</span>  
<span style="margin-left: 1em">聖旨該部看議速覆欽此欽遵抄出到部送司所據陪</span>  
<span style="margin-left: 3em">臣<sub class="note-jiao">校：同前條</sub>羅雅谷已經物故請乞</span>  
<span style="margin-left: 1em">優䘏一節即已行查主客司今據手本內稱備查卷案</span>  
<span style="margin-left: 3em">無憑稽考回覆前來隨經移文曆局確查前疏所</span>  
<span style="margin-left: 3em">引遠臣利瑪竇等</span>  
<span style="margin-left: 1em">䘏典成例係于何年月日題覆備錄過司以憑議覆去</span>  
<span style="margin-left: 3em">後續據修曆按察使李天經手本開稱該本司備</span>  
<span style="margin-left: 3em">查利瑪竇優䘏原疏係萬曆三十八年四月二十</span>  
<span style="margin-left: 3em">三日本部署部事左侍郎吳道南主客司郎中林</span>  
<span style="margin-left: 3em">茂槐等題給葬地奉</span>  
<span style="margin-left: 1em">聖旨是隨經署府事府丞黃吉士查給阜城門外二里</span>  
<span style="margin-left: 3em">溝籍没私剙佛寺三十八間地基二十畝付竇塋</span>  
<span style="margin-left: 3em">葬此前疏所引之成例也復查</span>  
<span style="margin-left: 1em">大明會典內一欵凡夷使病故如係陪臣<sub class="note-jiao">校：同前條</sub>未到京</span>  
<span style="margin-left: 3em">者本部題請翰林院撰祭文所在布政司備祭品</span>  
<span style="margin-left: 3em">遣本司堂上官致祭仍置地塋葬立石封識到京</span>  
<span style="margin-left: 3em">病故者行順天府給棺祠祭司諭祭今羅雅谷正</span>  
<span style="margin-left: 3em">與典例相符且係奉</span>  
<span style="margin-left: 1em">召來京又兼修曆演器屢著勤勞兩奉有優賚之</span>  
<span style="margin-left: 1em">旨未及叨</span>  
<span style="margin-left: 1em">恩而身先物故例應破格</span>  
<span style="margin-left: 1em">優䘏但據遠臣<sub class="note-jiao">校：達當爲遠字之誤今改</sub>湯若望呈稱望等俱係守</span>  
<span style="margin-left: 3em">素學道之人生既不敢萌服官之榮想死亦不敢</span>  
<span style="margin-left: 3em">徼逾分之榮施惟乞題補湯飯酒食銀兩俾生者</span>  
<span style="margin-left: 3em">得以資其朝夕殁者得以充其殞埋令彼自行塋</span>  
<span style="margin-left: 3em">搆仍冀比照吳守義見行事例</span>  
<span style="margin-left: 1em">勅賜扁坊聽其自行置辦則見我</span>  
<span style="margin-left: 2em">國家一字之褒榮踰華袞庶于勞勩酬而澤枯柔遠</span>  
<span style="margin-left: 3em">之</span>  
<span style="margin-left: 1em">仁渥矣等因通查案呈到部看得西洋陪臣<sub class="note-jiao">校：清刊本陪臣改作</sub></span>  
<span style="margin-left: 3em"><sub class="note-yuan">遠臣</sub>羅雅谷湯若望城守効勞部院題叙奉有羅雅</span>  
<span style="margin-left: 3em">谷等修曆演器著有勤勞自當從優叙賚之</span>  
<span style="margin-left: 1em">旨隨經本部議給無碍田房又經兩臣具疏控辭奉有</span>  
<span style="margin-left: 3em">田房不必再給另議具奏之</span>  
<span style="margin-left: 1em">旨臣等再四思維各部寺錢糧關正額者無容議惟陰</span>  
<span style="margin-left: 3em">陽事例銀雖交兌在户部與臣部相表裏然支給</span>  
<span style="margin-left: 3em">之間殊有未便所未敢輕議酌無可酌隨據博士</span>  
<span style="margin-left: 3em">楊之華等呈稱陪臣<sub class="note-jiao">校：同前條</sub>羅雅谷湯若望修曆在</span>  
<span style="margin-left: 3em">局供事迄今兩名每日止領光祿寺下程銀三分</span>  
<span style="margin-left: 3em">米四合不足資其朝夕覆看得光祿寺湯飯一節</span>  
<span style="margin-left: 3em">在</span>  
<span style="margin-left: 1em">朝廷于遠人既有大官餼贍之</span>  
<span style="margin-left: 2em">典而來賓者祇受有名比照魏文魁例查補以優異</span>  
<span style="margin-left: 3em">之隨經移查</span>  
<span style="margin-left: 2em">朝見供事日期去後在魏文魁修曆未成業蒙</span>  
<span style="margin-left: 1em">恩賜兩臣以萬里梯航殫精步算測驗多合用襄欽若</span>  
<span style="margin-left: 1em">大典且其抉祕指授遠折狂氛而歸忠盡瘁功尤足紀</span>  
<span style="margin-left: 3em">按數補給誠不爲過此臣等之初議也隨經督修</span>  
<span style="margin-left: 3em">曆法李天經開載羅雅谷湯若望</span>  
<span style="margin-left: 2em">朝見供事俱在崇禎三年間臣等更屈指扣算未免</span>  
<span style="margin-left: 3em">歲計有餘積少成多若得按數補給則浩蕩出于</span>  
<span style="margin-left: 1em">皇仁使之仰戴</span>  
<span style="margin-left: 2em">中國聖人之高厚而慕義頌德于無窮矣利瑪竇</span>  
<span style="margin-left: 1em">優䘏一節萬曆三十八年曾經</span>  
<span style="margin-left: 1em">賜給墳地據若望等自稱不敢邀逾分之榮其學道守</span>
