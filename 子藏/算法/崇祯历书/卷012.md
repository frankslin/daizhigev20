## 崇祯历书卷之十二　崇祯奏疏

*崇祯十一年三月十八日至崇祯十二年五月十六日*

<span style="margin-left: 2em">缘起十二</span>  
<span style="margin-left: 7em">崇祯十一年三月十八日李天经题本</span>  
<span style="margin-left: 3em">督修历法山东按察使司按察使照京官例正三</span>  
<span style="margin-left: 3em">品支俸臣李天经谨</span>  
<span style="margin-left: 2em">题为远臣尽瘁身殒优赉屡</span>  
<span style="margin-left: 1em">旨久虚恳乞</span>  
<span style="margin-left: 1em">勅部速覆以酬前劳以慰忠魂事切照修历远臣罗雅</span>  
<span style="margin-left: 3em">谷者系原任督修历法故辅臣徐光启于崇祯三</span>  
<span style="margin-left: 3em">年五月内因远臣邓玉函病故修历乏人具疏上</span>  
<span style="margin-left: 1em">请内称访得诸臣同学尚有汤若望罗雅谷二臣者其</span>  
<span style="margin-left: 3em">术业与玉函相埒而年力正强堪以効用伏乞</span>  
<span style="margin-left: 1em">勅下就便移文敦谕二臣并行所在官司资给前来庶</span>  
<span style="margin-left: 3em">令人出所长早奏厥绩等因本月十九日奉</span>  
<span style="margin-left: 1em">圣旨历法方在改修汤若望等既可访用着地方官资</span>  
<span style="margin-left: 2em">给前来该衙门知道钦此钦遵随于本年七月内据</span>  
<span style="margin-left: 3em">河南开封府知府袁楷具文资给罗雅谷前来本</span>  
<span style="margin-left: 3em">月初六日故辅臣徐光启题奉</span>  
<span style="margin-left: 1em">圣旨罗雅谷准朝见供事该部知道当经</span>  
<span style="margin-left: 2em">朝见赴局供事九载于兹公同远臣汤若望等譔成</span>  
<span style="margin-left: 3em">历法书表一百四十余卷缮制新式仪器十数种</span>  
<span style="margin-left: 3em">见在</span>  
<span style="margin-left: 1em">御前且于数年已来指教台官呕心沥血其日躔月离</span>  
<span style="margin-left: 3em">虽已传授习熟几于颖秃唇焦臣与辅臣曾已屡</span>  
<span style="margin-left: 3em">疏列名首叙叠奉有纪录酌议之</span>  
<span style="margin-left: 1em">旨在部未经议覆复于九年七月内因丑卢内犯戎政</span>  
<span style="margin-left: 3em">及都察院等衙门交荐奉有罗雅谷等即着随营</span>  
<span style="margin-left: 3em">指授以折狂氛有功从优叙赉之</span>  
<span style="margin-left: 1em">旨两臣即登陴指授义切同仇嗣因城守叙劳复奉有</span>  
<span style="margin-left: 3em">罗雅谷等修历演器著有勤劳自当从优叙赉之</span>  
<span style="margin-left: 1em">旨兹无论一时同叙之大小文武臣工俱膺擢升秩级</span>  
<span style="margin-left: 3em">即捐助如吴守义者亦荷</span>  
<span style="margin-left: 1em">勅赐建坊奖励祇因两臣守素学道不愿官职已经礼</span>  
<span style="margin-left: 3em">部题</span>  
<span style="margin-left: 1em">准各给房一所田数顷</span>  
<span style="margin-left: 1em">钦允在案而两臣又苦于书役之溪欲难餍豪强之覇</span>  
<span style="margin-left: 3em">占可虞为是具疏控辞复荷</span>  
<span style="margin-left: 1em">圣明不忍冺其前劳仍</span>  
<span style="margin-left: 1em">勅礼部另议两臣翘首望</span>  
<span style="margin-left: 1em">恩已成隔岁有本局博士等官不忍坐视向隅乃于今</span>  
<span style="margin-left: 3em">春二月间具呈礼部堂司已批即题随经祠祭司</span>  
<span style="margin-left: 3em">郎中何三省循例具稿每人每月各给汤饭桌半</span>  
<span style="margin-left: 3em">张廪米一石并纂修酒食等项以见</span>  
<span style="margin-left: 2em">朝供事之日为始照例补给向后仍令关支等因呈</span>  
<span style="margin-left: 3em">堂批行臣等伏念两臣自任事已来每日止共领</span>  
<span style="margin-left: 3em">光禄寺下程银三分米四合清苦奚堪且以造历</span>  
<span style="margin-left: 3em">未成如魏文魁者生叨汤饭殁徼秩级之外尚蒙</span>  
<span style="margin-left: 3em">照前补其俸廪父子沾</span>  
<span style="margin-left: 1em">恩而谷等造历有成守城著绩两奉有优赉之</span>  
<span style="margin-left: 1em">旨较之自应加优况若各给田房价值奚啻数千金今</span>  
<span style="margin-left: 3em">每人补给汤饭为数不多即每月各补一张在</span>  
<span style="margin-left: 1em">圣恩或弗靳予岂意复逾一月尚未</span>  
<span style="margin-left: 2em">题覆至历法名仍大统新局推测屡近</span>  
<span style="margin-left: 1em">明旨昭然其所以旁求更正一节曾未见该监虚心商</span>  
<span style="margin-left: 3em">及于臣仅见其通同妬嫉仍蹈游移之故辙而不</span>  
<span style="margin-left: 3em">遵画一之</span>  
<span style="margin-left: 1em">屡旨尚尔侈言再测狃旧惮新正嗟</span>  
<span style="margin-left: 1em">颁布无期河清难俟而远臣罗雅谷又以积劳成疾忽</span>  
<span style="margin-left: 3em">于三月十三日一旦溘然长逝矣然此臣之忠懐</span>  
<span style="margin-left: 3em">素蕴学术渊微推测不惮于燠寒著作奚分乎昼</span>  
<span style="margin-left: 3em">夜以致年未艾而须髪早白甘贫淡而面鹄形鸠</span>  
<span style="margin-left: 3em">气息奄奄既已致身于</span>  
<span style="margin-left: 1em">圣世而遗骸之埋瘗不无有望于</span>  
<span style="margin-left: 1em">皇仁伏乞</span>  
<span style="margin-left: 1em">圣明勅下该部即如所议速为</span>  
<span style="margin-left: 2em">题覆俾汤若望之生者得以资其朝夕而罗雅谷之</span>  
<span style="margin-left: 3em">死者得以充其殡埋庶我</span>  
<span style="margin-left: 2em">国家泽枯之</span>  
<span style="margin-left: 1em">德与柔远之仁足以远播于遐陬而两臣修历与城守</span>  
<span style="margin-left: 3em">之微劳亦不致终归冺灭矣臣于此又有</span>  
<span style="margin-left: 1em">请焉伏查臣局历法书器久已告成业蒙</span>  
<span style="margin-left: 1em">圣明判断画一将疎远者散遣回籍差误者准令更正</span>  
<span style="margin-left: 3em">独留新法之推测屡近者存监学习今罗雅谷虽</span>  
<span style="margin-left: 3em">已物故而交食七政经纬与夫气节晦朔弦望等</span>  
<span style="margin-left: 3em">项臣局各官俱素娴推算然教习台官不无赖于</span>  
<span style="margin-left: 3em">远臣汤若望也此臣历学专门精深博洽足以办</span>  
<span style="margin-left: 3em">此但苦一人之精力有限又有本等道业诚恐指</span>  
<span style="margin-left: 3em">授与旁通两事难以独肩自称若望同学见有汪</span>  
<span style="margin-left: 3em">尔斐者推测素谙年力正壮堪以访用伏乞</span>  
<span style="margin-left: 1em">圣明勅下容臣移文所在官司资给前来共襄</span>  
<span style="margin-left: 1em">大典其于治历明时不无小补矣至若远臣罗雅谷殁</span>  
<span style="margin-left: 3em">于</span>  
<span style="margin-left: 2em">王事万里孤魂不堪归衬见有利玛窦之例可援其</span>  
<span style="margin-left: 1em">会典亦有成例可考优䘏</span>  
<span style="margin-left: 1em">特典出自</span>  
<span style="margin-left: 1em">圣裁非臣之所敢擅议也</span>  
<span style="margin-left: 3em">崇祯十一年三月十八日具</span>  
<span style="margin-left: 2em">题二十四日奉</span>  
<span style="margin-left: 1em">圣旨该部看议速覆</span>  
<span style="margin-left: 7em">崇祯十一年四月二十二日礼部题本</span>  
<span style="margin-left: 3em">礼部</span>  
<span style="margin-left: 2em">题为遵</span>  
<span style="margin-left: 1em">旨酌议恭请</span>  
<span style="margin-left: 1em">圣裁事祠祭清吏司案呈案查先该本部题覆修政历</span>  
<span style="margin-left: 3em">法远臣罗雅谷等奏为</span>  
<span style="margin-left: 1em">圣明柔远过渥微臣图报未遑谨预辞</span>  
<span style="margin-left: 1em">钦允田房以表忠荩事等因崇祯十年九月十七日奉</span>  
<span style="margin-left: 1em">圣旨罗雅谷等奏辞田房不必再行查给该部还另议</span>  
<span style="margin-left: 2em">具奏钦此钦遵抄部送司随准督修历法山东按察</span>  
<span style="margin-left: 3em">使李天经手本开称城守叙录谷等幸叨优叙但</span>  
<span style="margin-left: 3em">缘两臣不愿官秩题</span>  
<span style="margin-left: 1em">准查给田房具疏控辞既蒙</span>  
<span style="margin-left: 1em">勅部另议可不亟为另行措处给与两臣自行搆置仍</span>  
<span style="margin-left: 3em">一面比照乡民吴守义等见行事例题</span>  
<span style="margin-left: 1em">请建坊奖励等因在案又经移文历局备查两臣来京</span>  
<span style="margin-left: 3em">修历日期去后续据李天经手本内开陪臣<sub class="note-jiao">校：清刊本</sub></span>  
<span style="margin-left: 3em"><sub class="note-yuan">陪臣改作远臣</sub>罗雅谷自崇祯三年七月初六日见</span>  
<span style="margin-left: 2em">朝供事陪臣<sub class="note-jiao">校：同前條</sub>汤若望自崇祯三年十二月初二</span>  
<span style="margin-left: 3em">日见</span>  
<span style="margin-left: 2em">朝供事迄今已及八载每日止领光禄寺下程银三</span>  
<span style="margin-left: 3em">分米四合似未足供日用清苦堪念既奉另议之</span>  
<span style="margin-left: 1em">旨相应题</span>  
<span style="margin-left: 1em">请回复前来正在查议题覆间又该督修历法山东按</span>  
<span style="margin-left: 3em">察使司按察使照京官例正三品支俸李天经题</span>  
<span style="margin-left: 3em">为远臣尽瘁身殒等事<sub class="note-yuan">云云</sub>非臣之所敢擅议也</span>  
<span style="margin-left: 3em">等因崇祯十一年三月二十四日奉</span>  
<span style="margin-left: 1em">圣旨该部看议速覆钦此钦遵抄出到部送司所据陪</span>  
<span style="margin-left: 3em">臣<sub class="note-jiao">校：同前條</sub>罗雅谷已经物故请乞</span>  
<span style="margin-left: 1em">优䘏一节即已行查主客司今据手本内称备查卷案</span>  
<span style="margin-left: 3em">无凭稽考回复前来随经移文历局确查前疏所</span>  
<span style="margin-left: 3em">引远臣利玛窦等</span>  
<span style="margin-left: 1em">䘏典成例系于何年月日题覆备录过司以凭议覆去</span>  
<span style="margin-left: 3em">后续据修历按察使李天经手本开称该本司备</span>  
<span style="margin-left: 3em">查利玛窦优䘏原疏系万历三十八年四月二十</span>  
<span style="margin-left: 3em">三日本部署部事左侍郎吴道南主客司郎中林</span>  
<span style="margin-left: 3em">茂槐等题给葬地奉</span>  
<span style="margin-left: 1em">圣旨是随经署府事府丞黄吉士查给阜城门外二里</span>  
<span style="margin-left: 3em">沟籍没私剙佛寺三十八间地基二十亩付窦茔</span>  
<span style="margin-left: 3em">葬此前疏所引之成例也复查</span>  
<span style="margin-left: 1em">大明会典内一欵凡夷使病故如系陪臣<sub class="note-jiao">校：同前條</sub>未到京</span>

<span style="margin-left: 1em">召来京又兼修历演器屡著勤劳两奉有优赉之</span>  
<span style="margin-left: 1em">旨未及叨</span>  
<span style="margin-left: 1em">恩而身先物故例应破格</span>  
<span style="margin-left: 1em">优䘏但据远臣<sub class="note-jiao">校：達當爲遠字之誤今改</sub>汤若望呈称望等俱系守</span>  
<span style="margin-left: 3em">素学道之人生既不敢萌服官之荣想死亦不敢</span>

<span style="margin-left: 3em">搆仍冀比照吴守义见行事例</span>  
<span style="margin-left: 1em">勅赐扁坊听其自行置办则见我</span>  
<span style="margin-left: 2em">国家一字之褒荣逾华衮庶于劳勚酬而泽枯柔远</span>  
<span style="margin-left: 3em">之</span>  
<span style="margin-left: 1em">仁渥矣等因通查案呈到部看得西洋陪臣<sub class="note-jiao">校：清刊本陪臣改作</sub></span>  
<span style="margin-left: 3em"><sub class="note-yuan">远臣</sub>罗雅谷汤若望城守効劳部院题叙奉有罗雅</span>

<span style="margin-left: 3em">之间殊有未便所未敢轻议酌无可酌随据博士</span>  
<span style="margin-left: 3em">杨之华等呈称陪臣<sub class="note-jiao">校：同前條</sub>罗雅谷汤若望修历在</span>  
<span style="margin-left: 3em">局供事迄今两名每日止领光禄寺下程银三分</span>  
<span style="margin-left: 3em">米四合不足资其朝夕覆看得光禄寺汤饭一节</span>  
<span style="margin-left: 3em">在</span>  
<span style="margin-left: 1em">朝廷于远人既有大官饩赡之</span>  
<span style="margin-left: 2em">典而来宾者祇受有名比照魏文魁例查补以优异</span>  
<span style="margin-left: 3em">之随经移查</span>  
<span style="margin-left: 2em">朝见供事日期去后在魏文魁修历未成业蒙</span>

<span style="margin-left: 3em">岁计有余积少成多若得按数补给则浩荡出于</span>  
<span style="margin-left: 1em">皇仁使之仰戴</span>  
<span style="margin-left: 2em">中国圣人之高厚而慕义颂德于无穷矣利玛窦</span>  
<span style="margin-left: 1em">优䘏一节万历三十八年曾经</span>  
<span style="margin-left: 1em">赐给坟地据若望等自称不敢邀逾分之荣其学道守</span>  
<span style="margin-left: 3em">素相应允从不必另议</span>
