<span style="margin-left: 3em">大测者测三角形法也凡测算皆以此测彼而此</span>  
<span style="margin-left: 3em">一彼一不可得测九章算多以三测一独句股章</span>  
<span style="margin-left: 3em">以二测一则皆三角形也其不言句股者句与股</span>  
<span style="margin-left: 3em">交必为直角直角者正方角也遇斜角则句股穷</span>  
<span style="margin-left: 3em">矣分斜角为两直角亦句股也遇或不可得分又</span>  
<span style="margin-left: 3em">穷矣三角形之理非句股可尽故不名句股也句</span>  
<span style="margin-left: 3em">股之易测者直线也平面也测天则圜面曲线非</span>  
<span style="margin-left: 3em">句股所能得也故有弧矢弦割圜之法弧者曲线</span>  
<span style="margin-left: 3em">弦矢者直线也以弧求弧无法可得必以直线曲</span>  
<span style="margin-left: 3em">弧相当相准乃可得之相当相准者围径之法也</span>  
<span style="margin-left: 3em">而围与径终古无相准之率古云径一围三实围</span>  
<span style="margin-left: 3em">以内二径之六弦非围也祖冲之密率云径七围</span>  
<span style="margin-left: 3em">二十二则其外切线也非围也刘徽密率云径五</span>  
<span style="margin-left: 3em">十围百五十七则又其内弦也非围也或推至万</span>  
<span style="margin-left: 3em">万亿以上然而小损即内弦小益即外切线也终</span>  
<span style="margin-left: 3em">非围也历家以句股开方展转商求累时方成一</span>  
<span style="margin-left: 3em">率然不能离径一围三之法即祖率已繁不复能</span>  
<span style="margin-left: 3em">用况徽率乎况万万亿以上乎是以甚难而实谬</span>  
<span style="margin-left: 3em">今西法以周天一象限分为半弧而各取其正半</span>  
<span style="margin-left: 3em">弦其术从二径六弦始以次求得六宗率皆度数</span>  
<span style="margin-left: 3em">之正义无可疑者次求三要法相分相准以求各</span>  
<span style="margin-left: 3em">率而得各弧之正半弦又以其余弧之正弦为余</span>  
<span style="margin-left: 3em">弦以余弦减半径为矢弧之外与正弦平行而交</span>  
<span style="margin-left: 3em">于割线者为切线以他半径截弧之一端而交于</span>  
<span style="margin-left: 3em">切线者为割线其与余弦平行者则余切线也即</span>  
<span style="margin-left: 3em">正割一线交于余切线而止者余割线也以正弦</span>  
<span style="margin-left: 3em">减半径者余矢也总之为八线其弧度分为五千</span>  
<span style="margin-left: 3em">四百每一度分有八线焉合之为四万三千二百</span>  
<span style="margin-left: 3em">率也其用之则一形中有三边三角任有其三可</span>  
<span style="margin-left: 3em">得其余三也凡测候所得者皆弧度分也以此二</span>  
<span style="margin-left: 3em">三弧求彼一弧先简此弧之某直线与彼弧之某</span>  
<span style="margin-left: 3em">直线推算得数简表即得彼弧之度分不劳余力</span>  
<span style="margin-left: 3em">不费晷刻为之者劳用之者逸方之句股开方以</span>  
<span style="margin-left: 3em">测圆者甚易而实是也然则必无差乎曰有之或</span>  
<span style="margin-left: 3em">在其末位如半径设十万则所差者十万分之一</span>  
<span style="margin-left: 3em">也设千万则所差者千万分之一也历家推演至</span>  
<span style="margin-left: 3em">微纤以下率皆弃去即谓之无差亦可故论此法</span>  
<span style="margin-left: 3em">者谓于推步术中为农夫之剡耜工匠之利器矣</span>  
<span style="margin-left: 3em">测天者所必须大于他测故名大测其解义六篇</span>

<span style="margin-left: 1em">因明篇第一</span>  
<span style="margin-left: 1em">总论　三十二条</span>  
<span style="margin-left: 1em">三角形者一形而三边容有三角也</span>  
<span style="margin-left: 7em">如上图甲乙丙为平面三角形丁戊己</span>  
<span style="margin-left: 7em">为球面三角形</span>  
<span style="margin-left: 1em">三角形各以两边容一角此两边为角形之两腰第三</span>  
<span style="margin-left: 2em">边为角形之底</span>  
<span style="margin-left: 2em">如前甲乙丙形若以甲乙甲丙为两腰则容乙甲丙</span>  
<span style="margin-left: 2em">角<sub class="note-yuan">第二字为所指角</sub>乙丙其底也余二同丁戊己亦同</span>  
<span style="margin-left: 1em">各边向一角者名为对角</span>  
<span style="margin-left: 2em">如前甲乙线向丙角者名为对丙角甲丙向乙名为</span>  
<span style="margin-left: 2em">对乙角</span>  
<span style="margin-left: 1em">角以何为尺度一弧之心在交点从心引出线为两腰</span>  
<span style="margin-left: 2em">而弧在两腰之间此弧即此角之尺度</span>  
<span style="margin-left: 6em">如上乙甲丙角其尺度则丁丙或戊己皆</span>  
<span style="margin-left: 6em">是其法甲为心其界或近如丁丙或远如</span>  
<span style="margin-left: 6em">戊己</span>  
<span style="margin-left: 1em">大测法分圈三百六十为度度析百分<sub class="note-yuan">中历</sub>或六十分<sub class="note-yuan">远西</sub></span>  
<span style="margin-left: 2em">分或百析为秒递析为百至纤而止<sub class="note-yuan">中历</sub>或析为六十</span>  
<span style="margin-left: 2em">秒递析为六十至十位而止<sub class="note-yuan">远西</sub></span>  
<span style="margin-left: 2em">圈愈大其度分亦愈大</span>  
<span style="margin-left: 1em">两弧之分数等其圈等则弧亦等其圈不等弧亦不等</span>  
<span style="margin-left: 2em">其不等之两弧名相似弧</span>  
<span style="margin-left: 2em">如上丁丙虽小于戊己而同对甲角即同为若干度</span>  
<span style="margin-left: 2em">分之弧也</span>  
<span style="margin-left: 1em">圈四分之一为九十度</span>  
<span style="margin-left: 1em">有弧不足九十度则其外至九十者名余弧亦曰较弧</span>  
<span style="margin-left: 5em">亦曰差弧</span>  
<span style="margin-left: 5em">如甲丁弧四十度则丁至丙五十度为余弧</span>  
<span style="margin-left: 2em">有弧大于象限<sub class="note-yuan">在九十以上</sub>名为过弧</span>  
<span style="margin-left: 5em">如甲乙弧大于甲丁过九十度则丁乙为过</span>  
<span style="margin-left: 5em">弧</span>  
<span style="margin-left: 5em">半圈界一百八十度</span>  
<span style="margin-left: 2em">有弧小于半圈则其外至百八十度者名为半圈之</span>  
<span style="margin-left: 5em">较弧</span>  
<span style="margin-left: 5em">如甲乙弧小于甲乙丙半圈则乙丙为其较</span>  
<span style="margin-left: 5em">弧</span>  
<span style="margin-left: 1em">凡交角俱相等</span>  
<span style="margin-left: 1em">如甲与乙丙与丁皆交角相等<sub class="note-yuan">见几何第一卷十五题</sub>如戊与己</span>  
<span style="margin-left: 5em">亦交角相等</span>  
<span style="margin-left: 1em">角有二类一直角一斜角</span>  
<span style="margin-left: 1em">凡直角其度皆九十</span>  
<span style="margin-left: 1em">斜角有二类一锐角一钝角</span>  
<span style="margin-left: 1em">钝角者其度大于象限</span>  
<span style="margin-left: 1em">锐角者其度小于象限</span>  
<span style="margin-left: 1em">角之余与弧同理<sub class="note-yuan">或曰较角或曰差角</sub></span>  
<span style="margin-left: 1em">有两角并在一线上为同方角并之等于两直角</span>  
<span style="margin-left: 5em">如上甲与乙丙与丁皆是</span>  
<span style="margin-left: 1em">同方两角等于两直角故彼角为此角之较</span>  
<span style="margin-left: 2em">如前乙角即甲之较甲亦乙之较</span>  
<span style="margin-left: 1em">三角形或三边等或两边等或三不等</span>  
<span style="margin-left: 1em">三角形两腰等其底线上两角亦等底上两角等则两</span>  
<span style="margin-left: 2em">腰亦等<sub class="note-yuan">见几何一卷第五</sub></span>  
<span style="margin-left: 1em">三边形之三角等则三边亦等</span>  
<span style="margin-left: 1em">三角形之角有二类一为直角三边形一为斜角三边</span>  
<span style="margin-left: 1em">形直角三边形形内止有一直角</span>  
<span style="margin-left: 1em">直角三边形之对直角边名弦两腰名句股<sub class="note-yuan">远西句股俱名垂线</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">互用之</sub></span>  
<span style="margin-left: 1em">斜角形其角皆斜</span>  
<span style="margin-left: 1em">斜角形有二类一曰锐角一曰钝角</span>  
<span style="margin-left: 1em">钝角形止有一钝角</span>  
<span style="margin-left: 1em">锐角形三皆锐角</span>  
<span style="margin-left: 1em">三角形有二类一曰平面上形一曰球上形</span>  
<span style="margin-left: 1em">论平面上三角形〇十一条</span>  
<span style="margin-left: 1em">平面上三角形有三种一直线一曲线一杂线大测所</span>  
<span style="margin-left: 2em">论皆直线也</span>  
<span style="margin-left: 1em">凡等角两三边形其在等角旁之各两腰线相与为比</span>  
<span style="margin-left: 2em">例必等而对等角之边为相似边<sub class="note-yuan">几何六卷第四题</sub></span>  
<span style="margin-left: 1em">凡两三角形其角两边之比例等即两形为等角形而</span>  
<span style="margin-left: 2em">对各相似边之角各等<sub class="note-yuan">几何六卷第五此二题为大测之根本不用开方直以</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">比例得之法至简用至大也</sub></span>  
<span style="margin-left: 7em">如上图甲乙丙丁戊己两形甲与丁乙</span>  
<span style="margin-left: 7em">与戊丙与己皆等角其旁各两腰之比</span>  
<span style="margin-left: 7em">例等者十与六若五与三也更之则十</span>  
<span style="margin-left: 2em">与五若六与三也反之则六与十若三与五也凡两</span>  
<span style="margin-left: 2em">形中各对相当等角之边皆相似之边如甲丙对乙</span>  
<span style="margin-left: 6em">丁己对戊而乙戊为等角者即甲丙丁己</span>  
<span style="margin-left: 6em">为相似之边也</span>  
<span style="margin-left: 1em">三角形之外角与相对之内两角并等<sub class="note-yuan">几何一卷之三十二</sub></span>  
<span style="margin-left: 5em">如上甲乙丙形之乙甲两角并与甲丙丁角</span>  
<span style="margin-left: 5em">等</span>  
<span style="margin-left: 1em">三角形之三角并等于两直角</span>  
<span style="margin-left: 7em">如上图丁己庚直角与乙角等其甲丙</span>  
<span style="margin-left: 7em">二角并与丁己戊角等</span>  
<span style="margin-left: 1em">平面上三角形止有一直角或一钝角其余二必皆锐</span>  
<span style="margin-left: 2em">角</span>  
<span style="margin-left: 1em">三边形内之第三角为前两角之余角何者为前两角</span>  
<span style="margin-left: 2em">不满二直角故</span>  
<span style="margin-left: 1em">直角旁之两腰其能与弦等能等者谓两腰上两方形</span>  
<span style="margin-left: 2em">并与弦上方形等也<sub class="note-yuan">几何一卷之四七</sub></span>  
<span style="margin-left: 7em">此理之用为先得二边以求第三边如</span>  
<span style="margin-left: 7em">甲乙丙形先得甲乙乙丙两边而求第</span>  
<span style="margin-left: 7em">三边法以甲乙三自之为九乙丙四自</span>  
<span style="margin-left: 2em">之为十六并得二十五与甲丙之实等开方得甲丙</span>  
<span style="margin-left: 2em">弦五若先得直角旁之一腰如甲乙三又得甲丙弦</span>  
<span style="margin-left: 2em">五而求乙丙则以甲丙自之得二十五乙甲自之得</span>  
<span style="margin-left: 2em">九相减之较十六开方得乙丙四</span>  
<span style="margin-left: 1em">直角形之两等边有数则其弦无数可推若弦有数则</span>  
<span style="margin-left: 2em">两等边无数可推</span>  
<span style="margin-left: 6em">如上甲乙甲丙各三自之各九并之得十</span>  
<span style="margin-left: 6em">八乙丙上实十八开方得四余实二分之</span>  
<span style="margin-left: 6em">或为八分之二或为九分之二八分之二</span>  
<span style="margin-left: 2em">则大于其真率九分之二则小于真率其乙丙真率</span>  
<span style="margin-left: 2em">无数可得更细分之亦复不尽</span>  
<span style="margin-left: 1em">直角三边形之两锐角彼锐为此锐之余</span>  
<span style="margin-left: 2em">如乙丙二锐角丙为余角为三角并等二直角此二</span>  
<span style="margin-left: 6em">锐应等一直角乙一角不足一直角故丙</span>  
<span style="margin-left: 6em">角为乙角与直角相减之较</span>  
<span style="margin-left: 1em">平边三角形在圈内其各角之度数皆为其对弧度数</span>  
<span style="margin-left: 2em">之半</span>  
<span style="margin-left: 6em">如上甲乙丙形三边等分圈为三各弧俱</span>  
<span style="margin-left: 6em">一百二十度本形之三角等二直角并得</span>  
<span style="margin-left: 6em">一百八十则对弧百二十度倍于对角六</span>  
<span style="margin-left: 2em">十也</span>

<span style="margin-left: 3em">　<sub class="note-yuan">论后有〇字</sub></span>

<span style="margin-left: 2em">先得其三而测其余三也<sub class="note-yuan">测三角形者止测其线非测其容测或作推或作解</sub></span>

<span style="margin-left: 1em">测三角形必藉<sub class="note-jiao">校：藉原作籍當訛今改</sub>同比例法<sub class="note-yuan">亦曰三率法</sub>同比例</span>  
<span style="margin-left: 2em">者四率同比例先有三而求第四也故三角形之六</span>  
<span style="margin-left: 2em">率其比例欲定其分数欲明</span>  
<span style="margin-left: 1em">三角形六率之比例其中用弧者最为难定何者圆线</span>  
<span style="margin-left: 2em">与直线之比例从古至今未有其法故</span>  
<span style="margin-left: 1em">三角形何以有弧曰球上三角形其三边皆弧也其三</span>  
<span style="margin-left: 2em">角皆弧角也即平面三角形其可以直线测者三边</span>  
<span style="margin-left: 2em">耳欲测其角非弧不得而弧为圆线无数可测故测</span>  
<span style="margin-left: 2em">弧者必求其与弧相当之直线</span>  
<span style="margin-left: 1em">与弧相当之直线者割圆界而求其直线之分与弧分</span>  
<span style="margin-left: 2em">相当者是也</span>  
<span style="margin-left: 1em">割圆之直线有四一曰弦一名通弦二曰半弦皆在圆</span>  
<span style="margin-left: 2em">界内三曰切线在圆界外四曰割线在圆界之内外</span>  
<span style="margin-left: 1em">弦者直线在圈内从此点至彼点分圈为两分</span>  
<span style="margin-left: 1em">凡弦皆对两弧一上一下</span>  
<span style="margin-left: 6em">如上图甲乙为弦分甲丙乙丁圈为两分</span>  
<span style="margin-left: 6em">甲丁乙为大分甲丙乙为小分则甲乙弦</span>  
<span style="margin-left: 6em">上当甲丙乙小弧下当甲丁乙大弧</span>  
<span style="margin-left: 1em">正弧者从弧作垂线至全径上</span>  
<span style="margin-left: 5em">如上图从丁作甲乙之垂线若从丁直至戊</span>  
<span style="margin-left: 5em">则为通弦故丁丙为半弦</span>  
<span style="margin-left: 1em">半弦又有二种有正弦有倒弦</span>

<span style="margin-left: 5em">庚弧必得乙庚弦故百八十度之弧必得百</span>  
<span style="margin-left: 2em">八十度之弦也因此术既繁且难后从简便则以半</span>  
<span style="margin-left: 2em">弦当之为各半弦可当上下两弧故不过一象限而</span>  
<span style="margin-left: 2em">足也</span>  
<span style="margin-left: 6em">如上图辛壬半弦当乙壬小弧亦当壬己</span>  
<span style="margin-left: 6em">甲大弧庚己半弦当乙己小弧亦当己甲</span>  
<span style="margin-left: 6em">大弧且一象限之外无切线亦无割线故</span>  
<span style="margin-left: 2em">用半圈之全不如象限之半也</span>  
<span style="margin-left: 1em">大测表不止有各弧之各度数亦有其各分数<sub class="note-yuan">欲极详亦可析</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">分为十为六也但少用耳</sub></span>  
<span style="margin-left: 1em">作大测表先定半径为若干分愈多愈细</span>  
<span style="margin-left: 1em">凡割圆四线大抵皆不尽之数无论全数不尽即以畸</span>  
<span style="margin-left: 2em">零法命其分亦不能尽故大测表不得谓其不差但</span>  
<span style="margin-left: 2em">所差甚少不至半径全数中之一耳</span>  
<span style="margin-left: 2em">假如半径为千万表中诸线中不至差千万分之一</span>  
<span style="margin-left: 2em">分自一以内或半或大或少不能无差而微乎微矣</span>  
<span style="margin-left: 2em">故作表中半径必用极大之数最少者一万以上或</span>  
<span style="margin-left: 2em">至百万千万或至万万可也<sub class="note-yuan">七位即千万八位即万万</sub></span>  
<span style="margin-left: 1em">定半径之全数即可求一象限内各弧各度分之半弦</span>  
<span style="margin-left: 2em">以此半弦可求得其切线割线</span>  
<span style="margin-left: 1em">凡半径用数少即差多<sub class="note-yuan">如用千则差千之一用万则差万之一</sub>用极大之</span>  
<span style="margin-left: 2em">数即难推<sub class="note-yuan">如用万万以上数极繁矣</sub>今定为几何则可曰凡半径</span>  
<span style="margin-left: 2em">之数其中之小分与半弧度分之小分大约相等而</span>  
<span style="margin-left: 2em">上之即是中数</span>  
<span style="margin-left: 2em">假如欲测有分之弧问半径应定几何分曰一象限</span>  
<span style="margin-left: 2em">九十度每度六十分则一象限五千四百分又古率</span>  
<span style="margin-left: 2em">圆与径之比例大畧为二十二与七则象限弧与半</span>  
<span style="margin-left: 2em">径之比例若十一与七</span>  
<span style="margin-left: 5em">如上图周二十二四分之则一象限为五又</span>  
<span style="margin-left: 5em">半径七二分之则三又半此二比例有畸零</span>  
<span style="margin-left: 5em">之数故各倍之为十一与七也</span>  
<span style="margin-left: 2em">今用同比例法<sub class="note-yuan">即三率法</sub>以象限十一为第一数以半径</span>  
<span style="margin-left: 2em">七为第二数以象限五千四百分为第三数而求得</span>  
<span style="margin-left: 2em">第四数为三千四百三十六故半径分为三千四百</span>  
<span style="margin-left: 2em">三十六则半径之各分略象等于一象限之各分五</span>  
<span style="margin-left: 6em">千四百也故用大数最少一万为与五千</span>  
<span style="margin-left: 6em">相近用此乃可推有分之弧也</span>  
<span style="margin-left: 6em">欲推弧分之秒亦用此法其象限为三十</span>  
<span style="margin-left: 2em">二万四千秒依三率法十一与七若三十二万四千</span>  
<span style="margin-left: 2em">与二十〇万六千一百八十二其半径细分与象限</span>  
<span style="margin-left: 2em">之分秒相等而上之必用百万</span>  
<span style="margin-left: 1em">表原篇第三</span>  
<span style="margin-left: 1em">表原者作表之原本也测圆无法必以直线直线与圆</span>
