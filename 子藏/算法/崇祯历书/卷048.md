<span style="margin-left: 3em">大測目錄</span>  
<span style="margin-left: 3em">大測者測三角形法也凡測算皆以此測彼而此</span>  
<span style="margin-left: 3em">一彼一不可得測九章算多以三測一獨句股章</span>  
<span style="margin-left: 3em">以二測一則皆三角形也其不言句股者句與股</span>  
<span style="margin-left: 3em">交必爲直角直角者正方角也遇斜角則句股窮</span>  
<span style="margin-left: 3em">矣分斜角爲兩直角亦句股也遇或不可得分又</span>  
<span style="margin-left: 3em">窮矣三角形之理非句股可盡故不名句股也句</span>  
<span style="margin-left: 3em">股之易測者直線也平面也測天則圜面曲線非</span>  
<span style="margin-left: 3em">句股所能得也故有弧矢弦割圜之法弧者曲線</span>  
<span style="margin-left: 3em">弦矢者直線也以弧求弧無法可得必以直線曲</span>  
<span style="margin-left: 3em">弧相當相準乃可得之相當相準者圍徑之法也</span>  
<span style="margin-left: 3em">而圍與徑終古無相準之率古云徑一圍三實圍</span>  
<span style="margin-left: 3em">以內二徑之六弦非圍也祖冲之密率云徑七圍</span>  
<span style="margin-left: 3em">二十二則其外切線也非圍也劉徽密率云徑五</span>  
<span style="margin-left: 3em">十圍百五十七則又其內弦也非圍也或推至萬</span>  
<span style="margin-left: 3em">萬億以上然而小損即內弦小益即外切線也終</span>  
<span style="margin-left: 3em">非圍也曆家以句股開方展轉商求累時方成一</span>  
<span style="margin-left: 3em">率然不能離徑一圍三之法即祖率已繁不復能</span>  
<span style="margin-left: 3em">用况徽率乎况萬萬億以上乎是以甚難而實謬</span>  
<span style="margin-left: 3em">今西法以周天一象限分爲半弧而各取其正半</span>  
<span style="margin-left: 3em">弦其術從二徑六弦始以次求得六宗率皆度數</span>  
<span style="margin-left: 3em">之正義無可疑者次求三要法相分相準以求各</span>  
<span style="margin-left: 3em">率而得各弧之正半弦又以其餘弧之正弦爲餘</span>  
<span style="margin-left: 3em">弦以餘弦減半徑爲矢弧之外與正弦平行而交</span>  
<span style="margin-left: 3em">於割線者爲切線以他半徑截弧之一端而交於</span>  
<span style="margin-left: 3em">切線者爲割線其與餘弦平行者則餘切線也即</span>  
<span style="margin-left: 3em">正割一線交於餘切線而止者餘割線也以正弦</span>  
<span style="margin-left: 3em">減半徑者餘矢也總之爲八線其弧度分爲五千</span>  
<span style="margin-left: 3em">四百每一度分有八線焉合之爲四萬三千二百</span>  
<span style="margin-left: 3em">率也其用之則一形中有三邊三角任有其三可</span>  
<span style="margin-left: 3em">得其餘三也凡測候所得者皆弧度分也以此二</span>  
<span style="margin-left: 3em">三弧求彼一弧先簡此弧之某直線與彼弧之某</span>  
<span style="margin-left: 3em">直線推算得數簡表即得彼弧之度分不勞餘力</span>  
<span style="margin-left: 3em">不費晷刻爲之者勞用之者逸方之句股開方以</span>  
<span style="margin-left: 3em">測圓者甚易而實是也然則必無差乎曰有之或</span>  
<span style="margin-left: 3em">在其末位如半徑設十萬則所差者十萬分之一</span>  
<span style="margin-left: 3em">也設千萬則所差者千萬分之一也曆家推演至</span>  
<span style="margin-left: 3em">微纖以下率皆棄去即謂之無差亦可故論此法</span>  
<span style="margin-left: 3em">者謂於推步術中爲農夫之剡耜工匠之利器矣</span>  
<span style="margin-left: 3em">測天者所必須大於他測故名大測其解義六篇</span>  
<span style="margin-left: 3em">分爲二卷八線表九十度分爲六卷如左</span>

<span style="margin-left: 1em">因明篇第一</span>  
<span style="margin-left: 1em">總論　三十二條</span>  
<span style="margin-left: 1em">三角形者一形而三邊容有三角也</span>  
<span style="margin-left: 7em">如上圖甲乙丙爲平面三角形丁戊己</span>  
<span style="margin-left: 7em">爲球面三角形</span>  
<span style="margin-left: 1em">三角形各以兩邊容一角此兩邊爲角形之兩腰第三</span>  
<span style="margin-left: 2em">邊爲角形之底</span>  
<span style="margin-left: 2em">如前甲乙丙形若以甲乙甲丙爲兩腰則容乙甲丙</span>  
<span style="margin-left: 2em">角<sub class="note-yuan">第二字爲所指角</sub>乙丙其底也餘二同丁戊己亦同</span>  
<span style="margin-left: 1em">各邊向一角者名爲對角</span>  
<span style="margin-left: 2em">如前甲乙線向丙角者名爲對丙角甲丙向乙名爲</span>  
<span style="margin-left: 2em">對乙角</span>  
<span style="margin-left: 1em">角以何爲尺度一弧之心在交點從心引出線爲兩腰</span>  
<span style="margin-left: 2em">而弧在兩腰之間此弧即此角之尺度</span>  
<span style="margin-left: 6em">如上乙甲丙角其尺度則丁丙或戊己皆</span>  
<span style="margin-left: 6em">是其法甲爲心其界或近如丁丙或遠如</span>  
<span style="margin-left: 6em">戊己</span>  
<span style="margin-left: 1em">大測法分圈三百六十爲度度析百分<sub class="note-yuan">中曆</sub>或六十分<sub class="note-yuan">遠西</sub></span>  
<span style="margin-left: 2em">分或百析爲秒遞析爲百至纖而止<sub class="note-yuan">中曆</sub>或析爲六十</span>  
<span style="margin-left: 2em">秒遞析爲六十至十位而止<sub class="note-yuan">遠西</sub></span>  
<span style="margin-left: 2em">圈愈大其度分亦愈大</span>  
<span style="margin-left: 1em">兩弧之分數等其圈等則弧亦等其圈不等弧亦不等</span>  
<span style="margin-left: 2em">其不等之兩弧名相似弧</span>  
<span style="margin-left: 2em">如上丁丙雖小于戊己而同對甲角即同爲若干度</span>  
<span style="margin-left: 2em">分之弧也</span>  
<span style="margin-left: 1em">圈四分之一爲九十度</span>  
<span style="margin-left: 1em">有弧不足九十度則其外至九十者名餘弧亦曰較弧</span>  
<span style="margin-left: 5em">亦曰差弧</span>  
<span style="margin-left: 5em">如甲丁弧四十度則丁至丙五十度爲餘弧</span>  
<span style="margin-left: 2em">有弧大于象限<sub class="note-yuan">在九十以上</sub>名爲過弧</span>  
<span style="margin-left: 5em">如甲乙弧大于甲丁過九十度則丁乙爲過</span>  
<span style="margin-left: 5em">弧</span>  
<span style="margin-left: 5em">半圈界一百八十度</span>  
<span style="margin-left: 2em">有弧小于半圈則其外至百八十度者名爲半圈之</span>  
<span style="margin-left: 5em">較弧</span>  
<span style="margin-left: 5em">如甲乙弧小于甲乙丙半圈則乙丙爲其較</span>  
<span style="margin-left: 5em">弧</span>  
<span style="margin-left: 1em">凡交角俱相等</span>  
<span style="margin-left: 1em">如甲與乙丙與丁皆交角相等<sub class="note-yuan">見幾何第一卷十五題</sub>如戊與己</span>  
<span style="margin-left: 5em">亦交角相等</span>  
<span style="margin-left: 1em">角有二類一直角一斜角</span>  
<span style="margin-left: 1em">凡直角其度皆九十</span>  
<span style="margin-left: 1em">斜角有二類一銳角一鈍角</span>  
<span style="margin-left: 1em">鈍角者其度大于象限</span>  
<span style="margin-left: 1em">銳角者其度小于象限</span>  
<span style="margin-left: 1em">角之餘與弧同理<sub class="note-yuan">或曰較角或曰差角</sub></span>  
<span style="margin-left: 1em">有兩角并在一線上爲同方角并之等于兩直角</span>  
<span style="margin-left: 5em">如上甲與乙丙與丁皆是</span>  
<span style="margin-left: 1em">同方兩角等于兩直角故彼角爲此角之較</span>  
<span style="margin-left: 2em">如前乙角即甲之較甲亦乙之較</span>  
<span style="margin-left: 1em">三角形或三邊等或兩邊等或三不等</span>  
<span style="margin-left: 1em">三角形兩腰等其底線上兩角亦等底上兩角等則兩</span>  
<span style="margin-left: 2em">腰亦等<sub class="note-yuan">見幾何一卷第五</sub></span>  
<span style="margin-left: 1em">三邊形之三角等則三邊亦等</span>  
<span style="margin-left: 1em">三角形之角有二類一爲直角三邊形一爲斜角三邊</span>  
<span style="margin-left: 1em">形直角三邊形形內止有一直角</span>  
<span style="margin-left: 1em">直角三邊形之對直角邊名弦兩腰名句股<sub class="note-yuan">遠西句股俱名垂線</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">互用之</sub></span>  
<span style="margin-left: 1em">斜角形其角皆斜</span>  
<span style="margin-left: 1em">斜角形有二類一曰銳角一曰鈍角</span>  
<span style="margin-left: 1em">鈍角形止有一鈍角</span>  
<span style="margin-left: 1em">銳角形三皆銳角</span>  
<span style="margin-left: 1em">三角形有二類一曰平面上形一曰球上形</span>  
<span style="margin-left: 1em">論平面上三角形〇十一條</span>  
<span style="margin-left: 1em">平面上三角形有三種一直線一曲線一雜線大測所</span>  
<span style="margin-left: 2em">論皆直線也</span>  
<span style="margin-left: 1em">凡等角兩三邊形其在等角旁之各兩腰線相與爲比</span>  
<span style="margin-left: 2em">例必等而對等角之邊爲相似邊<sub class="note-yuan">幾何六卷第四題</sub></span>  
<span style="margin-left: 1em">凡兩三角形其角兩邊之比例等即兩形爲等角形而</span>  
<span style="margin-left: 2em">對各相似邊之角各等<sub class="note-yuan">幾何六卷第五此二題爲大測之根本不用開方直以</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">比例得之法至簡用至大也</sub></span>  
<span style="margin-left: 7em">如上圖甲乙丙丁戊己兩形甲與丁乙</span>  
<span style="margin-left: 7em">與戊丙與己皆等角其旁各兩腰之比</span>  
<span style="margin-left: 7em">例等者十與六若五與三也更之則十</span>  
<span style="margin-left: 2em">與五若六與三也反之則六與十若三與五也凡兩</span>  
<span style="margin-left: 2em">形中各對相當等角之邊皆相似之邊如甲丙對乙</span>  
<span style="margin-left: 6em">丁己對戊而乙戊爲等角者即甲丙丁己</span>  
<span style="margin-left: 6em">爲相似之邊也</span>  
<span style="margin-left: 1em">三角形之外角與相對之內兩角并等<sub class="note-yuan">幾何一卷之三十二</sub></span>  
<span style="margin-left: 5em">如上甲乙丙形之乙甲兩角并與甲丙丁角</span>  
<span style="margin-left: 5em">等</span>  
<span style="margin-left: 1em">三角形之三角并等于兩直角</span>  
<span style="margin-left: 7em">如上圖丁己庚直角與乙角等其甲丙</span>  
<span style="margin-left: 7em">二角并與丁己戊角等</span>  
<span style="margin-left: 1em">平面上三角形止有一直角或一鈍角其餘二必皆銳</span>  
<span style="margin-left: 2em">角</span>  
<span style="margin-left: 1em">三邊形內之第三角爲前兩角之餘角何者爲前兩角</span>  
<span style="margin-left: 2em">不滿二直角故</span>  
<span style="margin-left: 1em">直角旁之兩腰其能與弦等能等者謂兩腰上兩方形</span>  
<span style="margin-left: 2em">并與弦上方形等也<sub class="note-yuan">幾何一卷之四七</sub></span>  
<span style="margin-left: 7em">此理之用爲先得二邊以求第三邊如</span>  
<span style="margin-left: 7em">甲乙丙形先得甲乙乙丙兩邊而求第</span>  
<span style="margin-left: 7em">三邊法以甲乙三自之爲九乙丙四自</span>  
<span style="margin-left: 2em">之爲十六并得二十五與甲丙之實等開方得甲丙</span>  
<span style="margin-left: 2em">弦五若先得直角旁之一腰如甲乙三又得甲丙弦</span>  
<span style="margin-left: 2em">五而求乙丙則以甲丙自之得二十五乙甲自之得</span>  
<span style="margin-left: 2em">九相減之較十六開方得乙丙四</span>  
<span style="margin-left: 1em">直角形之兩等邊有數則其弦無數可推若弦有數則</span>  
<span style="margin-left: 2em">兩等邊無數可推</span>  
<span style="margin-left: 6em">如上甲乙甲丙各三自之各九并之得十</span>  
<span style="margin-left: 6em">八乙丙上實十八開方得四餘實二分之</span>  
<span style="margin-left: 6em">或爲八分之二或爲九分之二八分之二</span>  
<span style="margin-left: 2em">則大于其真率九分之二則小于真率其乙丙真率</span>  
<span style="margin-left: 2em">無數可得更細分之亦復不盡</span>  
<span style="margin-left: 1em">直角三邊形之兩銳角彼銳爲此銳之餘</span>  
<span style="margin-left: 2em">如乙丙二銳角丙爲餘角爲三角并等二直角此二</span>  
<span style="margin-left: 6em">銳應等一直角乙一角不足一直角故丙</span>  
<span style="margin-left: 6em">角爲乙角與直角相減之較</span>  
<span style="margin-left: 1em">平邊三角形在圈內其各角之度數皆爲其對弧度數</span>  
<span style="margin-left: 2em">之半</span>  
<span style="margin-left: 6em">如上甲乙丙形三邊等分圈爲三各弧俱</span>  
<span style="margin-left: 6em">一百二十度本形之三角等二直角并得</span>  
<span style="margin-left: 6em">一百八十則對弧百二十度倍于對角六</span>  
<span style="margin-left: 2em">十也</span>  
<span style="margin-left: 1em">平面兩三角形在圈內同底兩形之頂相連成一四邊</span>  
<span style="margin-left: 2em">形此形內有兩對角線則此形相對之各兩邊各相</span>  
<span style="margin-left: 2em">偕爲兩直角形并與兩對角線相偕爲直角形等</span>  
<span style="margin-left: 9em">如上甲乙丙甲丁丙兩三角形在</span>

<span style="margin-left: 4em">丁丙形丁爲直角其乙丙爲兩鈍角若丁戊己</span>  
<span style="margin-left: 4em">形則其戊爲銳角其己爲鈍角甲戊己形則其</span>  
<span style="margin-left: 2em">戊爲鈍角其己爲銳角</span>  
<span style="margin-left: 1em">球上直角三邊形有兩銳角則其對直角之直角三邊</span>

<span style="margin-left: 2em">如前乙丁丙是</span>  
<span style="margin-left: 1em">球上直角三邊形有一銳一鈍角其銳角之相對三角</span>  
<span style="margin-left: 2em">形亦有一直角兩銳角</span>  
<span style="margin-left: 5em">如上圖丁乙丙三邊形丙爲直角丁爲銳角</span>  
<span style="margin-left: 5em">乙爲鈍角即丁銳角之相對乙丙戊形其丙</span>  
<span style="margin-left: 5em">爲直角<sub class="note-yuan">與乙丙丁并等兩直角</sub>其乙與戊爲兩銳角</span>  
<span style="margin-left: 1em">球上三邊形有多直角其對直角之各弧皆爲一象限</span>  
<span style="margin-left: 5em">如甲爲直角乙丙弧對之爲一象限餘二同</span>  
<span style="margin-left: 5em"><sub class="note-yuan">此圖爲三直角題言多者以該二直角也</sub></span>  
<span style="margin-left: 1em">球上三邊形有二直角若第三爲銳角即對角之弧小</span>  
<span style="margin-left: 2em">于象限若鈍角即對角之弧大于象限</span>  
<span style="margin-left: 8em">如上丁戊己形丁戊皆直角己爲銳</span>  
<span style="margin-left: 8em">角即對己之丁戊弧小于象限甲乙</span>  
<span style="margin-left: 8em">丙形甲丙皆直角乙爲鈍角則對乙</span>  
<span style="margin-left: 2em">之甲丙弧大于象限</span>

<span style="margin-left: 2em">角</span>  
<span style="margin-left: 1em">球上斜三角形俱銳角者其相對三角形有兩鈍角一</span>  
<span style="margin-left: 4em">銳角</span>  
<span style="margin-left: 4em">如上甲乙丙形三皆銳角即相對丁乙丙形其</span>  
<span style="margin-left: 4em">乙丙爲兩鈍角丁爲銳角</span>  
<span style="margin-left: 1em">球上三邊形俱鈍角者其相對三角形有兩銳角一鈍</span>  
<span style="margin-left: 2em">角</span>  
<span style="margin-left: 5em">如上甲乙丙形三皆鈍角即相對乙丙丁形</span>  
<span style="margin-left: 5em">其乙丙爲銳銳角丁爲鈍角</span>  
<span style="margin-left: 1em">球上三角形之三角并大于兩直角</span>  
<span style="margin-left: 2em">有二直角即大何況一直一鈍以上</span>

<span style="margin-left: 1em">總論　二十六條<sub class="note-jiao">校：梵蒂岡本總</sub></span>  
<span style="margin-left: 3em">　<sub class="note-yuan">論後有〇字</sub></span>  
<span style="margin-left: 1em">三角形有六率三角三邊是也測三角形者於六率中</span>  
<span style="margin-left: 2em">先得其三而測其餘三也<sub class="note-yuan">測三角形者止測其線非測其容測或作推或作解</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">下文通用</sub></span>  
<span style="margin-left: 1em">測三角形必藉<sub class="note-jiao">校：藉原作籍當訛今改</sub>同比例法<sub class="note-yuan">亦曰三率法</sub>同比例</span>  
<span style="margin-left: 2em">者四率同比例先有三而求第四也故三角形之六</span>  
<span style="margin-left: 2em">率其比例欲定其分數欲明</span>  
<span style="margin-left: 1em">三角形六率之比例其中用弧者最爲難定何者圓線</span>  
<span style="margin-left: 2em">與直線之比例從古至今未有其法故</span>  
<span style="margin-left: 1em">三角形何以有弧曰球上三角形其三邊皆弧也其三</span>  
<span style="margin-left: 2em">角皆弧角也即平面三角形其可以直線測者三邊</span>  
<span style="margin-left: 2em">耳欲測其角非弧不得而弧爲圓線無數可測故測</span>  
<span style="margin-left: 2em">弧者必求其與弧相當之直線</span>  
<span style="margin-left: 1em">與弧相當之直線者割圓界而求其直線之分與弧分</span>  
<span style="margin-left: 2em">相當者是也</span>  
<span style="margin-left: 1em">割圓之直線有四一曰弦一名通弦二曰半弦皆在圓</span>  
<span style="margin-left: 2em">界內三曰切線在圓界外四曰割線在圓界之內外</span>  
<span style="margin-left: 1em">弦者直線在圈內從此點至彼點分圈爲兩分</span>  
<span style="margin-left: 1em">凡弦皆對兩弧一上一下</span>  
<span style="margin-left: 6em">如上圖甲乙爲弦分甲丙乙丁圈爲兩分</span>  
<span style="margin-left: 6em">甲丁乙爲大分甲丙乙爲小分則甲乙弦</span>  
<span style="margin-left: 6em">上當甲丙乙小弧下當甲丁乙大弧</span>  
<span style="margin-left: 1em">正弧者從弧作垂線至全徑上</span>  
<span style="margin-left: 5em">如上圖從丁作甲乙之垂線若從丁直至戊</span>  
<span style="margin-left: 5em">則爲通弦故丁丙爲半弦</span>  
<span style="margin-left: 1em">半弦又有二種有正弦有倒弦</span>  
<span style="margin-left: 1em">正半弦是直線在半圈內從弧作垂線至徑上分半圈</span>  
<span style="margin-left: 2em">爲不等之兩分一大弧一小弧此半弦當小弧亦當</span>  
<span style="margin-left: 2em">當大弧<sub class="note-yuan">當者爲小弧之半弦亦爲大弧之半弦</sub></span>  
<span style="margin-left: 5em">如上圖從己弧下至甲乙全徑上作己庚垂</span>  
<span style="margin-left: 5em">線分甲丙乙半圈爲不等兩分乙己弧爲小</span>  
<span style="margin-left: 5em">分己丙甲弧爲大分則己庚爲己乙小弧之</span>  
<span style="margin-left: 2em">半弦又爲己丙甲大弧之半弦</span>  
<span style="margin-left: 1em">正半弦從一點作兩半弦第一爲前半弦第二爲從半</span>  
<span style="margin-left: 2em">弦<sub class="note-jiao">校：從疑後字之訛</sub>又爲餘弧弦又爲較弦又爲差弦</span>  
<span style="margin-left: 2em">如前圖先論己庚即爲前半弦其己戊即爲後半弦</span>  
<span style="margin-left: 2em">又爲餘爲較者乙己丙弧九十度乙己不足九十度</span>  
<span style="margin-left: 2em">則己丙爲餘弧亦爲較弧故己戊爲其餘弦較弦也</span>  
<span style="margin-left: 1em">前後兩半弦其能等于半徑</span>  
<span style="margin-left: 5em">如上圖庚己爲前弦當乙己弧己戊爲後弦</span>  
<span style="margin-left: 5em">當己丙餘弧戊己弦等于丁庚<sub class="note-yuan">幾何一卷三十四</sub>則</span>  
<span style="margin-left: 5em">丁己半徑上方與庚己己戊上兩方并等故</span>  
<span style="margin-left: 2em">云兩半弦之能等于半徑</span>  
<span style="margin-left: 2em">論曰兩半弦互爲垂線則己庚丁爲直角而對直角</span>  
<span style="margin-left: 2em">之弦己丁上方與勾股上兩方并等<sub class="note-yuan">幾何一卷四十七</sub></span>  
<span style="margin-left: 2em">系直角三邊形內有半徑亦有一半弦即可求後半</span>  
<span style="margin-left: 2em">弦法曰半徑上方形實減半弦上方形實其較即後</span>  
<span style="margin-left: 2em">半弦上方形之實開方得後半弦</span>  
<span style="margin-left: 2em">如丙乙半徑十甲乙前半弦六而有丙甲乙直角今</span>  
<span style="margin-left: 6em">求丙甲後半弦其法丙乙自之爲百甲乙</span>  
<span style="margin-left: 6em">自之爲三十六相減餘六十四即甲丙方</span>  
<span style="margin-left: 2em">之實平方開之得八</span>  
<span style="margin-left: 1em">兩正弦之較與紀限左右距等弧之半弦等<sub class="note-yuan">六十度爲紀限</sub></span>  
<span style="margin-left: 6em">解曰甲乙丙象限內有丙己小弧丙己戊</span>  
<span style="margin-left: 6em">丁大弧丙戊弧爲六十度而戊己戊丁兩</span>  
<span style="margin-left: 6em">弧等其兩半弦一爲己辛一爲丁庚兩半</span>  
<span style="margin-left: 2em">弦之較爲丁癸題言丁癸較與己壬半弦壬丁半弦</span>  
<span style="margin-left: 2em">各等</span>  
<span style="margin-left: 2em">論曰試作一己子線則丁己子成三邊等角形何也</span>  
<span style="margin-left: 2em">此形中有子丁壬壬己子兩三角形此兩角形等又</span>  
<span style="margin-left: 2em">何也子戊同腰而丁壬壬己兩腰等則丁壬己壬兩</span>  
<span style="margin-left: 2em">直角亦等而丁子子己兩底亦等子丁己子己丁兩</span>  
<span style="margin-left: 2em">角亦等又丙戊弧既六十度其餘戊乙弧必三十度</span>  
<span style="margin-left: 2em">其乙甲戊角爲三十度角甲乙庚丁既平行甲戊線</span>  
<span style="margin-left: 2em">截二線于子即內外角等而丁子戊角亦三十度戊</span>  
<span style="margin-left: 2em">子己角亦三十度是丁子己爲六十度角也丁與己</span>  
<span style="margin-left: 2em">與全子三角既等兩直角<sub class="note-yuan">一卷三十二</sub>則共爲一百八十</span>  
<span style="margin-left: 2em">度於中減全子角六十度則丁己兩角百二十度而</span>  
<span style="margin-left: 2em">此兩角既等即各得六十度則此形之三角三邊俱</span>  
<span style="margin-left: 2em">等夫丁己己子兩線等則己癸垂線所分之丁癸子</span>  
<span style="margin-left: 2em">癸兩直角亦等而己癸同腰則丁癸與癸子必等丁</span>  
<span style="margin-left: 2em">癸爲丁子之半丁壬爲丁己之半全線等則所分必</span>  
<span style="margin-left: 2em">等是丁癸與丁壬等與壬己亦等</span>  
<span style="margin-left: 2em">系題兩弧各有其正半弦兩半弦至弧之點在六十</span>  
<span style="margin-left: 2em">度之左右而距度點等其前兩正半弦之較即後兩</span>  
<span style="margin-left: 2em">半弦如前圖丙己戊弧六十度丙己弧五十度己戊</span>  
<span style="margin-left: 2em">弧十度丙己之正半弦己辛簡表先得七千六百六</span>  
<span style="margin-left: 2em">十丙丁弧七十度丁戊弧亦十度丙丁弧之正半弦</span>  
<span style="margin-left: 2em">爲丁庚先得九千三百九十六今求丁戊弧之半弦</span>  
<span style="margin-left: 2em">其法以己辛丁庚兩半弦相減得丁癸較一千七百</span>  
<span style="margin-left: 2em">三十六即丁戊弧十度之丁壬半弦<sub class="note-yuan">此設數半徑一萬</sub></span>  
<span style="margin-left: 1em">倒弦者餘弦與全數之較本名爲矢</span>  
<span style="margin-left: 4em">如上圖甲丙徑以乙丁正半弦分徑爲二分一</span>  
<span style="margin-left: 4em">爲甲丁一爲丁丙其丁丙即乙丁正半弦之倒</span>  
<span style="margin-left: 4em">弦也</span>  
<span style="margin-left: 1em">矢有二有大有小</span>  
<span style="margin-left: 2em">如上圖甲丁爲大矢與甲乙弧相當丁丙爲小矢與</span>  
<span style="margin-left: 2em">乙丙弧相當</span>  
<span style="margin-left: 1em">矢加于餘半弦即半徑</span>  
<span style="margin-left: 2em">如上圖乙己爲乙丁正弦之餘弦以加丁丙即半徑</span>  
<span style="margin-left: 2em">爲乙己與丁戊等故</span>  
<span style="margin-left: 1em">切線者弧之外有線爲徑一端之垂線半徑爲底線而</span>  
<span style="margin-left: 2em">交於截弧之弦線<sub class="note-yuan">弦線者勾股之弦非弧矢之弦也</sub></span>  
<span style="margin-left: 5em">如上圖戊丙弧乙丙爲半徑從丙出垂線至</span>  
<span style="margin-left: 5em">丁又從乙出線截戊丙弧于戊而與丁丙線</span>  
<span style="margin-left: 5em">交于丁即丁丙爲切線與戊丙弧相當也</span>  
<span style="margin-left: 1em">割線者從心過弧之一端而交于切線</span>  
<span style="margin-left: 2em">如上圖乙戊丁線爲割線與戊丙弧相當也故戊丙</span>  
<span style="margin-left: 2em">弧在三角形內其句爲半徑其股爲切線其弦爲割</span>  
<span style="margin-left: 2em">線皆與戊丙弧相當之直線</span>
