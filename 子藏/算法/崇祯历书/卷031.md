## 崇禎曆書卷之三十一　曆法西傳

<span style="margin-left: 1em">能見太白有上下弦能見歲星旁四小星又填星爲撱</span>  
<span style="margin-left: 1em">形旁附有兩小星昂宿星三十餘鬼宿中之積尸氣以</span>  
<span style="margin-left: 1em">至光體微渺之星用此奚啻多數十倍抑且界限分明</span>  
<span style="margin-left: 1em">光耀璀璨噫造器至此異甚矣</span>  
<span style="margin-left: 3em">時晷</span>  
<span style="margin-left: 1em">凡日月交食會合五星凌歷犯守其時刻所由取準者</span>  
<span style="margin-left: 1em">賴有時晷也然而大地之廣時非合一古法不分方土</span>  
<span style="margin-left: 1em">第用時牌揆景以定者非也新法製晷但須預定本方</span>  
<span style="margin-left: 1em">北極出地之度隨在隨處雖垣墻正側皆可製造能于</span>  
<span style="margin-left: 1em">一晷之而視太陽所躔節氣宫次度分及定日之高度</span>  
<span style="margin-left: 1em">并黃道各時出没其稱最者則地平晷立晷百游晷通</span>  
<span style="margin-left: 1em">光晷數種他若柱晷瓦晷碗晷十字晷等不下數十餘</span>  
<span style="margin-left: 1em">種而此外又有星晷與測月之器以爲夜中測時之需</span>  
<span style="margin-left: 1em">云若遇陰雨則又有自嗚鐘沙水等漏之製水漏與古</span>  
<span style="margin-left: 1em">壺漏異古或以水入壺而時箭浮新製以水出壺而時</span>  
<span style="margin-left: 1em">牌轉壺體並不開孔似爲勝之</span>

<span style="margin-left: 1em">崇禎曆書卷之三十一</span>  
<span style="margin-left: 2em">曆法西傳<sub class="note-jiao">校：據清刊本補錄日抄本作西曆目錄</sub></span>  
<span style="margin-left: 1em">勅錫通玄教師加二品通政使司通政使掌欽天監印務事臣湯若望著</span>  
<span style="margin-left: 3em">引說</span>  
<span style="margin-left: 1em">凡學非能驟成莫不始于格物以致其知而後從而推</span>  
<span style="margin-left: 2em">廣從而精詳焉以故古人因目所見心悟頓啓紀而</span>  
<span style="margin-left: 2em">驗之接續成書以詔來世乃成一學即曆學亦然矣</span>  
<span style="margin-left: 2em">其初所悟者槩不出日月交食及冬夏四正五緯凌</span>  
<span style="margin-left: 2em">犯等獨目易見者數事因而再求之然後乃知月有</span>  
<span style="margin-left: 2em">本道焉交食有期有率焉又因而推廣之精詳之以</span>  
<span style="margin-left: 2em">及他數他理而曆學始爲大全此始原泉一脉涓涓</span>  
<span style="margin-left: 2em">流而爲壑浸假而百川彙集由湖由江以入于海浩</span>  
<span style="margin-left: 2em">浩乎無涯際矣後有好學者留思古人之學參以已</span>  
<span style="margin-left: 2em">見曾無幾許而附以傳世是爲坐收其成豈可擅稱</span>  
<span style="margin-left: 2em">超悟屈抑前功哉余著曆書百卷大要取之古人而</span>  
<span style="margin-left: 2em">又括以曆引今復爲此編先明西曆古書大指而次</span>  
<span style="margin-left: 2em">則遂及余書蓋一則著新法非一人之法非近創之</span>  
<span style="margin-left: 2em">法良由博古深思參互考訂以得一真無容妄議一</span>  
<span style="margin-left: 2em">則令後之人便于循習曉暢數百年後測審差數推</span>  
<span style="margin-left: 2em">往知來善于變通也或疑中西異法如格碍何余謂</span>  
<span style="margin-left: 2em">天行無隱</span>  
<span style="margin-left: 1em">君命非私曆至今日中人亦西學矣且即就中曆而論</span>  
<span style="margin-left: 3em">其根亦本于西如列宿距星皆同又列宿有屬太</span>  
<span style="margin-left: 3em">陽者四屬太陰者四亦同是知根本既同而清其</span>  
<span style="margin-left: 3em">枝幹通其脉絡有成書在展卷研求無不可見豈</span>  
<span style="margin-left: 3em">足相難哉學者勉之可也</span>  
<span style="margin-left: 3em">西古曆法</span>  
<span style="margin-left: 1em">西庠之學其大者有五科一道科二治科三理科四醫</span>  
<span style="margin-left: 2em">科五文科而理科中旁出一支爲度數之學此一支</span>  
<span style="margin-left: 2em">又分爲七家曰數學家曰幾何家曰視學家曰音律</span>  
<span style="margin-left: 2em">家曰輕重家曰曆學家曰地理家七家俱統于度數</span>  
<span style="margin-left: 2em">要皆師傳曹習確有根據者也若多祿某既西洋曆</span>  
<span style="margin-left: 2em">學名師在郭守敬前一千百有餘年漢順帝永建時</span>  
<span style="margin-left: 2em">人著書一部計十有三卷</span>  
<span style="margin-left: 2em">第一卷</span>  
<span style="margin-left: 3em">詳証曆學大指如諸星運行天體渾圓地與海共</span>  
<span style="margin-left: 3em">爲一球也居天與空氣之正中地較天大不過一</span>  
<span style="margin-left: 3em">點等項次著角理不但以句股測直線之長短且</span>  
<span style="margin-left: 3em">用曲線三角形量天是爲以圓齊圓所得諸星相</span>  
<span style="margin-left: 3em">距度分最準又求二至相距幾何度分在赤道內</span>  
<span style="margin-left: 3em">外幾何度分并二曜相離最遠爲幾何度分設黃</span>  
<span style="margin-left: 3em">道緯度求赤道相應經度設黃道經度求赤道相</span>  
<span style="margin-left: 3em">應緯度</span>  
<span style="margin-left: 2em">第二卷</span>  
<span style="margin-left: 3em">論宗動天設黃道在地平上之點求其距赤道之</span>  
<span style="margin-left: 3em">地平弧設日之高求正側各景之長短又求黃道</span>  
<span style="margin-left: 3em">各點之半晝弦解正儀晝夜等衆星常見之故偏</span>  
<span style="margin-left: 3em">儀二至規下歲一次無景距赤道愈遠晝夜愈不</span>  
<span style="margin-left: 3em">等而兩極下每歲爲一晝夜</span>  
<span style="margin-left: 2em">第三卷</span>  
<span style="margin-left: 3em">考太陽行求二分時刻辯二至氣至時難求時刻</span>  
<span style="margin-left: 3em">求歲實與每日太陽平行乃作平行立成表又推</span>  
<span style="margin-left: 3em">論日行用同心規及小輪或同心及不同心合一</span>  
<span style="margin-left: 3em">之理推地心與日規相距幾何遠隨求太陽景遠</span>  
<span style="margin-left: 3em">點<sub class="note-yuan">亦名最高</sub>定太陽曆元及太陽行度每日不等之數</span>  
<span style="margin-left: 2em">第四卷</span>  
<span style="margin-left: 3em">論太陰行証求太陰真行度即月食可考月有遲</span>  
<span style="margin-left: 3em">疾太三行乃求月平行併月每日緯度即以齊月</span>  
<span style="margin-left: 3em">諸行或用同心圈及小輪或不用同心圈二法同</span>  
<span style="margin-left: 3em">理設三月食求同心規及小輪兩半徑以定月諸</span>  
<span style="margin-left: 3em">行曆元又求月行正交中交之時推二交逆行之</span>  
<span style="margin-left: 3em">數</span>  
<span style="margin-left: 2em">第五卷</span>  
<span style="margin-left: 3em">解月自行以求月經緯度必用小輪推月加减立</span>  
<span style="margin-left: 3em">成表求月之更大緯度與月之地半徑差度復求</span>  
<span style="margin-left: 3em">日月二輪與地球半徑之比例及日月與地景之</span>  
<span style="margin-left: 3em">似徑<sub class="note-yuan">地景其形如角所求之徑乃月所過截地景之處</sub>又求月半徑及景</span>  
<span style="margin-left: 3em">半徑與地半徑之比例求日真徑求日遠于地求</span>  
<span style="margin-left: 3em">景之長大<sub class="note-yuan">已上三求皆以地半徑爲度</sub>求日月地之比例<sub class="note-yuan">原書稱三</sub></span>  
<span style="margin-left: 3em"><sub class="note-yuan">大即日月與地</sub>設日月之遠求地半徑差推視差立成表</span>  
<span style="margin-left: 3em">比日月兩視差分月視差有三種</span>  
<span style="margin-left: 2em">第六卷</span>  
<span style="margin-left: 3em">解日月合會求日月平朔平望併定朔定望時及</span>  
<span style="margin-left: 3em">其宫度分求地景及月半徑定日月食限論日月</span>  
<span style="margin-left: 3em">半年中能再食月食後五閱月中能再食七閱月</span>  
<span style="margin-left: 3em">中不再食日于五閱月中各地能兩食七閱月中</span>  
<span style="margin-left: 3em">一地能兩食日于三十日中一地不能再食更求</span>  
<span style="margin-left: 3em">月正緯度設月真所在求視所在求月正會前後</span>  
<span style="margin-left: 3em">四列之視行及日月似會<sub class="note-yuan">即日食</sub>即求日食初虧食</span>  
<span style="margin-left: 3em">甚復圓三時定日食分秒</span>  
<span style="margin-left: 2em">第七卷</span>  
<span style="margin-left: 3em">論諸恒星遠近終古如一証其晝夜行外別有他</span>  
<span style="margin-left: 3em">行論其順天經行以黃道極爲本極定歲差度設</span>  
<span style="margin-left: 3em">三星相距以二星經緯度求第三星經緯度詳測</span>  
<span style="margin-left: 3em">星法</span>  
<span style="margin-left: 2em">第八卷</span>  
<span style="margin-left: 3em">論天漢起没詳天漢中大星所在及衆星拱向并</span>  
<span style="margin-left: 3em">其出入設黃道經緯度求赤道緯度等</span>  
<span style="margin-left: 2em">第九卷</span>  
<span style="margin-left: 3em">求五星每年及每日平行解五星大小輪理求水</span>  
<span style="margin-left: 3em">星之本行求水星最高求水星大小圈半徑比例</span>  
<span style="margin-left: 3em">又求水星小輪上平行以求水星各行曆元</span>  
<span style="margin-left: 2em">第十卷</span>  
<span style="margin-left: 3em">解金水二星之行求金星最高及不同心輪與小</span>  
<span style="margin-left: 3em">輪半徑比例設時定金星諸行曆元求土木火三</span>  
<span style="margin-left: 3em">星之小輪及小輪之本行<sub class="note-yuan">亦名歳行</sub>設火星三處求其</span>  
<span style="margin-left: 3em">最高測從地心至不同心圈其遠幾何求火星小</span>  
<span style="margin-left: 3em">輪之半徑推火星平行定火星諸行之曆元</span>  
<span style="margin-left: 2em">第十一卷</span>  
<span style="margin-left: 3em">解土木二星之理即求地心與木星本心之差及</span>  
<span style="margin-left: 3em">木星本輪與小輪之半徑并其平行定木星之曆</span>  
<span style="margin-left: 3em">元後設土星三次舍以求其最高求土星小輪之</span>  
<span style="margin-left: 3em">半徑而定其曆元設五星之平行求其實經度</span>  
<span style="margin-left: 2em">第十二卷</span>  
<span style="margin-left: 3em">解五政行度有退留疾等之故即求其留界及逆</span>  
<span style="margin-left: 3em">行之半弧更求金星左右距日之極大弧度并水</span>  
<span style="margin-left: 3em">星與日最遠度</span>  
<span style="margin-left: 2em">第十三卷</span>  
<span style="margin-left: 3em">論齊五星緯度之法求火木土三星各本圈及黃</span>  
<span style="margin-left: 3em">道交角并定其緯度論五星伏見先求火木土三</span>  
<span style="margin-left: 3em">星伏見相距之時次求金水二星伏見及其相距</span>  
<span style="margin-left: 3em">之時</span>  
<span style="margin-left: 1em">已上十三卷屬多祿某所著除右引各目外尚有三百</span>  
<span style="margin-left: 2em">餘欵可爲曆曆之綱維推步之宗祖也但其辭句太</span>  
<span style="margin-left: 2em">古淺學罕能習之故諸名家更互演譯各有論著今</span>  
<span style="margin-left: 2em">不及敘</span>  
<span style="margin-left: 1em">後又有亞而封所乃極西寶祐時人身居王位自諳曆</span>  
<span style="margin-left: 2em">學指數萬金錢訪求四方知曆之人務依先師所著</span>  
<span style="margin-left: 2em">創立成表以佐推算諸曜之法其功不在多祿某下</span>  
<span style="margin-left: 2em">緣屬祖述成書故今亦不及敘</span>  
<span style="margin-left: 1em">又其後四百年有歌白尼驗多祿某法雖全備微欠曉</span>  
<span style="margin-left: 2em">明乃別作新圖著書六卷今爲序次之如左</span>  
<span style="margin-left: 2em">第一卷</span>  
<span style="margin-left: 3em">天動以圓解</span>  
<span style="margin-left: 2em">第二卷</span>  
<span style="margin-left: 3em">天并七曜圖解衆星各及其次舍解</span>  
<span style="margin-left: 2em">第三卷</span>  
<span style="margin-left: 3em">論歲差而証其行較古有異論歲實求太陽最遠</span>  
<span style="margin-left: 3em">點及隨年日時太陽躔度</span>  
<span style="margin-left: 2em">第四卷</span>  
<span style="margin-left: 3em">取古今月食各三度求月小輪之徑求大輪小輪</span>  
<span style="margin-left: 3em">之比例并月經緯度推日月交食</span>  
<span style="margin-left: 2em">第五卷</span>  
<span style="margin-left: 3em">求五星平行用古今各三測經度求大小兩輪之</span>  
<span style="margin-left: 3em">比例等終求其正經宫度分</span>  
<span style="margin-left: 2em">第六卷</span>  
<span style="margin-left: 3em">求五星緯度</span>  
<span style="margin-left: 1em">已上歌白尼所著後人多祖述焉有西滿者嘗証多祿</span>  
<span style="margin-left: 2em">某歌白尼兩家之法惟一麻日諾又取歌白尼測法</span>  
<span style="margin-left: 2em">更爲多祿某之圖益見其理無二矣</span>  
<span style="margin-left: 1em">近六十年西土有多名家先後繼起較前人用測更精</span>  
<span style="margin-left: 2em">立法更盡造圖更美其一未葉大因悟不同心規與</span>  
<span style="margin-left: 2em">小輪難于推算于是更創蛋形圖以解天文根本設</span>  
<span style="margin-left: 2em">七政三測求最遠點又求地心與不同心差又求各</span>  
<span style="margin-left: 2em">輪比例等理其二第谷竭四十年心力窮究曆學備</span>  
<span style="margin-left: 2em">諸巧器以測天度不爽分秒第谷本大家饍養知曆</span>  
<span style="margin-left: 2em">人造器市書計用二十萬金著書計六卷</span>  
<span style="margin-left: 2em">第一卷</span>  
<span style="margin-left: 3em">取二分真氣至時</span>  
<span style="margin-left: 2em">第二卷</span>  
<span style="margin-left: 3em">取北極之高并解前人之謬解蒙氣反光之差取</span>  
<span style="margin-left: 3em">二至真氣至時并解二至難得真時之故求太陽</span>  
<span style="margin-left: 3em">最遠點并地心與太陽心之差求加减數証最遠</span>  
<span style="margin-left: 3em">點之行度及太陽平行求歲實并推立成表用立</span>  
<span style="margin-left: 3em">成求日躔宫度而考其法</span>  
<span style="margin-left: 2em">第三卷</span>  
<span style="margin-left: 3em">以二十一月食求月平行設月行新圖以齊月行</span>  
<span style="margin-left: 3em">用兩大規及三小輪詳其所以然推立成并其用</span>  
<span style="margin-left: 3em">法仍各設假如求月緯度加圖及立成表算法因</span>  
<span style="margin-left: 3em">求月食又求月與地相距幾何立推交食法因測</span>  
<span style="margin-left: 3em">五緯之真經緯度先考列宿之真經緯度</span>  
<span style="margin-left: 2em">第四卷</span>  
<span style="margin-left: 3em">解測星應用儀器乃駁古測有誤取金星與日與</span>  
<span style="margin-left: 3em">某星相距度以求某星距日度分幾何取近黃赤</span>  
<span style="margin-left: 3em">二道距度并之以合周天全度復取六星之距度</span>  
<span style="margin-left: 3em">以經度相併適合周天之全度求角宿經緯度以</span>  
<span style="margin-left: 3em">起周天之度再求近赤道十二星經緯度証星之</span>  
<span style="margin-left: 3em">黃道緯度今古不同求星之經度并解其時八百</span>  
<span style="margin-left: 3em">餘星之真經緯度<sub class="note-yuan">五十三年前</sub>復加百餘星赤道經緯</span>  
<span style="margin-left: 3em">度說</span>  
<span style="margin-left: 2em">第五卷</span>  
<span style="margin-left: 3em">解其時新見大客星計十二章一詳初起及漸大</span>  
<span style="margin-left: 3em">至與金星等并漸减二取附某宫星以定其經緯</span>

<span style="margin-left: 2em">儀必以儀上極與本地之極高下相當即經緯皆相</span>  
<span style="margin-left: 2em">當故測星者使無子午以正東西升降無極高以正</span>  
<span style="margin-left: 2em">南北高下即一切推算之法無從措手若視差就地</span>  
<span style="margin-left: 2em">半徑差論恒星以距地遠得免就清蒙差論則恒星</span>  
<span style="margin-left: 2em">近地平必皆有之測時宜用减矣</span>  
<span style="margin-left: 1em">第二卷測恒星黃赤本行其行黃道上即歲差也中曆</span>  
<span style="margin-left: 2em">論歲差有曰未能測其所以然第以全曆推之二萬</span>  
<span style="margin-left: 2em">六千八百八十年差一周天每歲差一分三十餘秒</span>  
<span style="margin-left: 2em">上推至帝嚳甲子四十年日在虛六度至夏王不降</span>  
<span style="margin-left: 2em">乙未三十五年日退入女宿商武乙丙寅四年日退</span>  
<span style="margin-left: 2em">入牛宿周簡王丁亥十二年日退入斗宿宋度宗戊</span>  
<span style="margin-left: 2em">辰四年日退入箕宿四度二分餘且言此定算也又</span>  
<span style="margin-left: 2em">或測日度者以月食衝求之可謂巧矣然而皆非也</span>  
<span style="margin-left: 2em">夫每歲所差甚少月食分數頗寛安得借此求彼此</span>  
<span style="margin-left: 2em">其謬一謂日退者即日逆行古來測日但有盈縮有</span>  
<span style="margin-left: 2em">公行有本行退逆之行理所必無此其謬二既言未</span>  
<span style="margin-left: 2em">測其所以然何從而得一定之算此其謬三西法則</span>  
<span style="margin-left: 2em">以黃道二分二至爲界據古所測某恒星距界之度</span>  
<span style="margin-left: 2em">從而復測之乃見遷移以較中古上古此星離冬至</span>  
<span style="margin-left: 2em">漸遠如前此居冬至者虛也今已順行東去繼之者</span>  
<span style="margin-left: 2em">爲女爲牛爲斗又後爲箕矣是知歲差係恒星前行</span>  
<span style="margin-left: 2em">與七政依黃道本行無異此爲真所以然非日退之</span>  
<span style="margin-left: 2em">說也且西測星非詳得其分秒置不用非三四器三</span>  
<span style="margin-left: 2em">四人同時並得在一分以內者置不用此新法所以</span>  
<span style="margin-left: 2em">獨密也所得歲差定數爲五十一秒<sub class="note-yuan">依六十算</sub>由此得恒</span>  
<span style="margin-left: 2em">星歲實小餘爲二十四刻九分又約二十七秒乃古</span>  
<span style="margin-left: 2em">今不易之則也</span>  
<span style="margin-left: 2em">問星歲無差既有定算如此曆家不用以推年日何</span>  
<span style="margin-left: 2em">曰立歲限以定所爲主如四時如二至二分等日行</span>  
<span style="margin-left: 2em">皆有定所星算雖定而其右旋于各節氣恒無定所</span>  
<span style="margin-left: 2em">故難用推年日也</span>  
<span style="margin-left: 2em">考黃赤道宿度今古變易緣諸星隨黃道斜交赤道</span>  
<span style="margin-left: 2em">故也每見太陽之行黃道夏日距赤道北冬距其南</span>  
<span style="margin-left: 2em">逐年如此豈非由二道斜交之故乎曆家同時測日</span>  
<span style="margin-left: 2em">經而兩道上所測度分必異又所差日各不等此爲</span>  
<span style="margin-left: 2em">日經之變如從兩極各出直線以交日心引之徑過</span>  
<span style="margin-left: 2em">以至赤道兩線必不復會于一點以是知日經緯在</span>  
<span style="margin-left: 2em">赤道恒變即恒星亦然逐漸右旋即赤道宿度逐漸</span>  
<span style="margin-left: 2em">有變其數多寡前後必異惟黃道經度則終古如一</span>  
<span style="margin-left: 2em">而星亦終古如一斗恒似斗尾恒似鈎古二星在一</span>  
<span style="margin-left: 2em">直線者今時亦然彼此相距皆同也</span>  
<span style="margin-left: 2em">累測黃赤兩道恒星之經度以推古今各宿積及本</span>  
<span style="margin-left: 2em">度並載曆指讀者以參觜不仍舊次爲疑不知宿在</span>  
<span style="margin-left: 2em">黃赤二道原有分別其依黃道不變之度分參前觜</span>  
<span style="margin-left: 2em">後終古恒然若依赤道而論在昔雖先觜後參而近</span>  
<span style="margin-left: 2em">自二百年來則參先而觜後矣蓋因兩道從兩極出</span>  
<span style="margin-left: 2em">線以定度數故有異也</span>  
<span style="margin-left: 1em">第三卷以黃道經緯變赤道經緯及繪星圖數法蓋星</span>  
<span style="margin-left: 2em">之去離赤道無恒而其去離黃道有恒即黃赤二道</span>  
<span style="margin-left: 2em">之相距亦如有恒以兩有恒求一無恒則依曲線三</span>  
<span style="margin-left: 2em">角形以乘除三率等法推算可得若直欲從赤道求</span>  
<span style="margin-left: 2em">之無由而得矣緣星行依黃道以向赤道時有遷移</span>  
<span style="margin-left: 2em">故也</span>  
<span style="margin-left: 2em">繪圖舊以恒隱圈界爲總圖界星偏河南之南不復</span>  
<span style="margin-left: 2em">有圖矣新法因見隱圈南北隨地不同故以兩極爲</span>  
<span style="margin-left: 2em">心以赤道爲界或又簡以中土恒見之圈爲界繪總</span>  
<span style="margin-left: 2em">星圖閩粤以北可見諸星無不具載至圖內正斜各</span>  
<span style="margin-left: 2em">圈直曲各線依星本經緯應入其中者本卷一一詳</span>  
<span style="margin-left: 2em">之乃除天漢積屍氣等無算小星外凡可見可測者</span>  
<span style="margin-left: 2em">別以六等令星在圖在天大小異形無不相肖</span>  
<span style="margin-left: 1em">月離曆指計四卷首卷論測月平行策及遅疾如减正</span>  
<span style="margin-left: 2em">數如各種行度一隨宗動天日一周行二依本天順</span>  
<span style="margin-left: 2em">白道自西而東平行此或以太陽爲界從合朔起算</span>  
<span style="margin-left: 2em">或以宫次節氣爲界從各點起算謂之交周滿一周</span>  
<span style="margin-left: 2em">謂交終三依本輪自行從東而西然依輪之上順行</span>  
<span style="margin-left: 2em">依輪之下則逆本天而行但緣月行甚疾地面但見</span>  
<span style="margin-left: 2em">其遲不見其逆此行謂之轉行滿一周謂轉終四隨</span>  
<span style="margin-left: 2em">次輪乃本輪之周復有一小輪其心隨本輪左旋月</span>  
<span style="margin-left: 2em">在其上則又右旋滿一周名爲次轉終也五爲交行</span>  
<span style="margin-left: 2em">月行白道出入黃道西行所交于黃道中線兩點一</span>  
<span style="margin-left: 2em">名正交一名中交舊所稱羅計是也外又一次輪實</span>  
<span style="margin-left: 2em">測則有而據之以推度數頗微無大用又一面輪使</span>  
<span style="margin-left: 2em">月一面恒照下向地此亦無關疎密皆置不論</span>  
<span style="margin-left: 2em">論測月平行乃因視差及蒙氣差參錯難分月體且</span>  
<span style="margin-left: 2em">月體恒虧無從測心以此測月最繁度分難得其準</span>  
<span style="margin-left: 2em">須按西古今法于月食時驗而知之晉史姜岌亦以</span>  
<span style="margin-left: 2em">月食衝驗太陽所在然而考太陽之躔度易考太陰</span>  
<span style="margin-left: 2em">之離度難在姜爲倒用兩率皆疎矣且平行亦非一</span>  
<span style="margin-left: 2em">食可驗也蓋任用一食僅得當時之行度何由遽定</span>  
<span style="margin-left: 2em">平行必擇前後兩食各率均齊者以爲兩限然後取</span>  
<span style="margin-left: 2em">其中積平分之庶免日去地時近時遠所生闇虛時</span>  
<span style="margin-left: 2em">大時小與夫月轉時遲時疾時在最高時在最卑諸</span>  
<span style="margin-left: 2em">凡月行不平之緣也但欲得此前後食務須求之記</span>  
<span style="margin-left: 2em">載今考二十一史天文志但記有年月日而畧時刻</span>  
<span style="margin-left: 2em">分秒無已借西曆補之</span>  
<span style="margin-left: 2em">論測正中交行度蓋月本國之自行度曰轉行及于</span>  
<span style="margin-left: 2em">黃道曰交而轉滿一周曰交終其在後不及轉之度</span>  
<span style="margin-left: 2em">即謂兩交之逆行也測法亦用月食考古無傳仍依</span>  
<span style="margin-left: 2em">西史如前法用兩月食測其前後各率均齊得交逆</span>  
<span style="margin-left: 2em">行日三分十一秒歲十九度零十九秒四十三微此</span>  
<span style="margin-left: 2em">爲二千年前古測後史各加密測推得交行每年盈</span>  
<span style="margin-left: 2em">一秒四十二纎應减</span>  
<span style="margin-left: 2em">論用不同心圈與用小輪名異理同皆藉以分布度</span>  
<span style="margin-left: 2em">數解明七政盈縮遲疾之行乃公借古今測定本輪</span>  
<span style="margin-left: 2em">之大小遠近之比例以求加减差立推算各表之法</span>  
<span style="margin-left: 2em">然而創始難工增修易善曆家積功二千餘生至近</span>  
<span style="margin-left: 2em">代測驗而後漸次加精較古爲密也</span>  
<span style="margin-left: 2em">終定太陰諸行曆元宜命一定地以憑起算即依本</span>  
<span style="margin-left: 2em">地初度初分爲準以加以减推算各地本時本曜之</span>  
<span style="margin-left: 2em">各所在度分此法從古未有且測北極出地中率不</span>  
<span style="margin-left: 2em">合蓋前人未悟地半徑差與蒙氣差于二至所測之</span>  
<span style="margin-left: 2em">高應有加减故未得真高也</span>  
<span style="margin-left: 1em">二卷論測次輪次加减遲疾及半徑差月徑地景徑等</span>  
<span style="margin-left: 2em">乃引古今西史月天諸輪之圖解各所遲疾行之理</span>  
<span style="margin-left: 2em">并經緯隨時度分更推假如令數與圖互相發明因</span>  
<span style="margin-left: 2em">知欲求月離真所非一均數可定蓋雖加减本輪之</span>  
<span style="margin-left: 2em">自行度可得定朔定望緣距限在五度內故然而二</span>  
<span style="margin-left: 2em">弦及弦左右之自行差則異于朔望其距限大至七</span>  
<span style="margin-left: 2em">度半强矣故據次輪之自行加减立第二均數于理</span>  
<span style="margin-left: 2em">爲盡從是可得太陰之視行實經度</span>  
<span style="margin-left: 2em">次定交周交行及交行之曆元皆于月食取法蓋須</span>  
<span style="margin-left: 2em">前後兩月食其距太陽之最高遠近均等兩食分等</span>  
<span style="margin-left: 2em">兩食之在陰曆陽曆正交中交亦畧等則因兩食之</span>  
<span style="margin-left: 2em">中積而得交會及交終之數依此用三率法以各數</span>  
<span style="margin-left: 2em">推得交行之度分又得月平行距交之度並其平行</span>  
<span style="margin-left: 2em">距宫次或節氣之度雨數之較爲三分十一秒是爲</span>  
<span style="margin-left: 2em">兩交一日逆行之數所謂羅計行度也若交行之曆</span>  
<span style="margin-left: 2em">元亦于兩月食得其諸率各等則必并得其距交亦</span>  
<span style="margin-left: 2em">等蓋交終由兩食之經時而知今定交應則因兩食</span>  
<span style="margin-left: 2em">之月距交等度考其中積時自行滿交周外即得其</span>  
<span style="margin-left: 2em">距交幾何度分是曆元也遂命曰某年天正冬至爲</span>  
<span style="margin-left: 2em">曆元而某處某府爲曆元本所</span>  
<span style="margin-left: 2em">又次測黃白二道相距度分法求月軌極高以免諸</span>  
<span style="margin-left: 2em">視差加减故乃得距赤度分去减黃赤距度餘爲黃</span>  
<span style="margin-left: 2em">白距度此西古今通法中曆黃白相距恒大于西術</span>  
<span style="margin-left: 2em">謬矣其推月食恒小于天驗殆緣于此</span>  
<span style="margin-left: 2em">論月視差此因地半徑而生與他曜同但月天視地</span>  
<span style="margin-left: 2em">爲近爲卑則地與本天各半徑之比例其視差並大</span>  
<span style="margin-left: 2em">古今累測得數無異約一度故測太陰先得其視高</span>  
<span style="margin-left: 2em">乃以地半徑差加之得數又以蒙氣差减之此爲實</span>  
<span style="margin-left: 2em">高如反推則得其實高乃以地半徑差减之得數又</span>  
<span style="margin-left: 2em">以蒙氣差加之此爲視高具見本表但蒙氣之差因</span>  
<span style="margin-left: 2em">地因時所在各異必求本地勢本時刻之確數定之</span>  
<span style="margin-left: 2em">終測月徑地景徑或由月食測定食分并推求其自</span>  
<span style="margin-left: 2em">行距交距黃道等率而得或以測太陽之似徑比于</span>  
<span style="margin-left: 2em">地而并記其月距地設三角形推月與地各徑又地</span>  
<span style="margin-left: 2em">半徑之比例而兩徑可定</span>  
<span style="margin-left: 1em">三卷論測日月地大小近遠之比例引古今法數種先</span>  
<span style="margin-left: 2em">求各視徑大小如日食時月視徑隨地不等其各視</span>  
<span style="margin-left: 2em">徑與實徑大小絕異又如月視地爲小月天視六曜</span>  
<span style="margin-left: 2em">天爲小去人又近後定日月之實徑推各體之容詳</span>  
<span style="margin-left: 2em">測日月各距地之高論月天象數及諸月表之原</span>  
<span style="margin-left: 1em">四卷論測太陰見伏光體并四餘辯天行無紫氣等引</span>  
<span style="margin-left: 2em">古今交食以証新法並爲後學之資蓋因中史失載</span>  
<span style="margin-left: 2em">交食分秒及陰陽曆與太陽之距最高太陰之自行</span>  
<span style="margin-left: 2em">度分等後人無憑推步以資修改故悉取之西史</span>  
<span style="margin-left: 1em">交食曆指第一卷詳太陽光景地景及日食之故先引</span>  
<span style="margin-left: 2em">界說如何爲暗體原光照光次光滿光又如何爲初</span>  
<span style="margin-left: 2em">景次景滿景蓋食生于景景生于光滿景非暗也稱</span>  
<span style="margin-left: 2em">光暗之中即日月食可辨</span>  
<span style="margin-left: 2em">凡交食或地食光于月景爲日食或月體食光于地</span>  
<span style="margin-left: 2em">景爲月食乃日月地三球各體大小不等有靜有動</span>  
<span style="margin-left: 2em">去人有遠有近當求其大小遠近之比例推其施光</span>  
<span style="margin-left: 2em">受光之體勢乃得交食之體勢今設兩球大小等一</span>  
<span style="margin-left: 2em">暗一明明者半面施光暗者半面受光無分遠近未</span>  
<span style="margin-left: 2em">有交食者也若明球小暗球大暗以小半受光明以</span>  
<span style="margin-left: 2em">大半施光此爲太陰照地而地受其隔日之光也凡</span>  
<span style="margin-left: 2em">大施小受施以小半受以大半二體彌近大者施光</span>  
<span style="margin-left: 2em">之小半彌小小者受光之大半彌大此即日居最卑</span>  
<span style="margin-left: 2em">而食之勢也若夫小施大受則又二體彌遠而施者</span>  
<span style="margin-left: 2em">亦彌小受者亦彌大此月食之分數有多有少而月</span>  
<span style="margin-left: 2em">近地居景厚處食分多遠地居景薄處食分少總由</span>  
<span style="margin-left: 2em">大小遠近之比例而生也</span>  
<span style="margin-left: 2em">又詳景之處所在受光之背面乃因月與地勢能出</span>  
<span style="margin-left: 2em">景在日食則爲月景下至于地月食則爲地景上至</span>  
<span style="margin-left: 2em">于月景形爲角形緣出景之圓體與太陽大于地于</span>  
<span style="margin-left: 2em">月之倍數相當也月望月有食乃地景隔日光令月</span>  
<span style="margin-left: 2em">不受照有時失滿光有時全失光月朔日有食乃月</span>  
<span style="margin-left: 2em">隔日光令地不受照有處射滿景有處存少光皆係</span>  
<span style="margin-left: 2em">景之作用也至論月在景之光色或赤或雜或青黑</span>  
<span style="margin-left: 2em">色皆有占驗或生于氣景或映于旁光或染于近地</span>  
<span style="margin-left: 2em">之清蒙氣皆能令月現種種色也論食之期二景既</span>  
<span style="margin-left: 2em">隨日月所至終古不爽即有定候一在定朔一在定</span>  
<span style="margin-left: 2em">望當食必食多寡先後上下千百世可知此則本卷</span>  
<span style="margin-left: 2em">益加詳焉</span>  
<span style="margin-left: 1em">第二卷詳交食諸類及推交食之原與簡法蓋日月之</span>  
<span style="margin-left: 2em">行雖有隅照方照六合照等悉無交食獨相會相望</span>  
<span style="margin-left: 2em"><sub class="note-yuan">亦名合會照會</sub>有食詳之則有實會中會視會之別皆爲推</span>  
<span style="margin-left: 2em">步之原三會或較于地心或較于地面各異實會中</span>  
<span style="margin-left: 2em">會相距又無定度必先推求各元法從本天大小圈</span>  
<span style="margin-left: 2em">以曆元並以三角形細推乃能成表爲密求法以便</span>  
<span style="margin-left: 2em">後人蓋因得其所以然而後握簡御繁無難也</span>  
<span style="margin-left: 1em">第三卷求推交食依人目所見儀器所測之時刻及所</span>  
<span style="margin-left: 2em">食分數之原必應改實時爲視時而此地此時見食</span>  
<span style="margin-left: 2em">彼地則異時見食也故可隨地推交食之有無又可</span>  
<span style="margin-left: 2em">上推往古下驗將來萬年悉如指掌若食分之多寡</span>  
<span style="margin-left: 2em">既原于日月地景之各視半徑則定視徑分秒之數</span>  
<span style="margin-left: 2em">逆計太陰居最高或最卑本視徑差地景即因太陽</span>  
<span style="margin-left: 2em">居高居卑不同其照地生景之差以得各實差然後</span>  
<span style="margin-left: 2em">食分可得而定矣</span>  
<span style="margin-left: 1em">第四卷詳食限食甚前後時及繪食圖以解各食向位</span>  
<span style="margin-left: 2em">論限日與月不同蓋雖同以所行各道經度距交幾</span>  
<span style="margin-left: 2em">何爲有食之始然而月食則太陰與地景遇因而兩</span>  
<span style="margin-left: 2em">周相切即以兩視半徑並較白道距黃道度推交周</span>  
<span style="margin-left: 2em">度以定食限日食則太陽與太陰遇雖亦兩周相切</span>  
<span style="margin-left: 2em">而有視差必先加入視差而後得距度定其食限也</span>  
<span style="margin-left: 2em">惟其食限各異故推太陰越五月能再食越七月不</span>  
<span style="margin-left: 2em">再食而太陽越五月七月皆能再食</span>  
<span style="margin-left: 2em">至于食分則以距度求之蓋兩周之心相距之度也</span>  
<span style="margin-left: 2em">在月食則爲太陰心實距地景之心愈近食分愈多</span>  
<span style="margin-left: 2em">在日食則爲日月兩心以視度相距其近遠不依實</span>  
<span style="margin-left: 2em">度而依目視之所及爲準此即月食分天下皆同而</span>  
<span style="margin-left: 2em">日食分隨人目東西南北各異之原也</span>  
<span style="margin-left: 2em">食分以緯度而定食甚前後時刻則並以經緯而定</span>  
<span style="margin-left: 2em">蓋太陰本時距度多寡不同即入景淺深亦不同淺</span>  
<span style="margin-left: 2em">則歷時少深則歷時多此蓋從緯定也若就經論太</span>  
<span style="margin-left: 2em">陰之自行時疾時遲緯與視徑雖同而自行每食不</span>  
<span style="margin-left: 2em">同即所得時刻亦必不同但太陰入景之弧與出景</span>  
<span style="margin-left: 2em">之弧畧等故依其行弧推食甚前之時倍之隨得食</span>  
<span style="margin-left: 2em">甚後至復圓之時乃日食時刻則又以視差有異焉</span>  
<span style="margin-left: 2em">交食圖列方位方位者日月失光之面所向之方也</span>  
<span style="margin-left: 2em">法先考本食是陰曆或陽曆更考黃道是斜交地平</span>  
<span style="margin-left: 2em">與否蓋黃道斜交日月亦依以斜行食時方向必異</span>  
<span style="margin-left: 2em">不可不審也故繪圖以一直線過日月二心審其與</span>  
<span style="margin-left: 2em">地面相遇之勢乃定日食方位過日景二心審其與</span>  
<span style="margin-left: 2em">地平相遇之勢乃定月食方位舊法徒以陰陽二曆</span>  
<span style="margin-left: 2em">求之疎矣驗時安得合乎</span>  
<span style="margin-left: 1em">第五卷詳日月視差及日食掩地面幾何凡推步日食</span>  
<span style="margin-left: 2em">要以人目爲主目見之會非實會而視會也此差雖</span>  
<span style="margin-left: 2em">由地半徑生<sub class="note-yuan">以人目在地面不在地心故</sub>更爲人目差分別有三</span>  
<span style="margin-left: 2em">等一高卑差以天頂爲限一南北差以黃道爲限此</span>  
<span style="margin-left: 2em">限能變諸曜緯度一東西差以黃道九十度爲限其</span>  
<span style="margin-left: 2em">左右能變經度及時刻測此三差悉用三角形因設</span>  
<span style="margin-left: 2em">地半徑爲一邊日月各距地高爲一邊各距地面之</span>  
<span style="margin-left: 2em">遠爲一邊測之乃得高弧或正或斜交于黃道以四</span>  
<span style="margin-left: 2em">方分視差然東西南北二差又時有變務彼此相較</span>  
<span style="margin-left: 2em">展轉推求可也</span>  
<span style="margin-left: 2em">論日食之掩地面必係全食或係應不見光之地面</span>  
<span style="margin-left: 2em">又或本日太陽適在最卑而其視徑大似太陰之視</span>  
<span style="margin-left: 2em">徑若此則雖二曜之心合而周邊大小微異乃見金</span>  
<span style="margin-left: 2em">環焉又總論見食之地其廣幾何且見食進退一分</span>  
<span style="margin-left: 2em">應地面幾何由是以推各國各省能見食與否並食</span>  
<span style="margin-left: 2em">分多寡等義</span>  
<span style="margin-left: 1em">第六卷依原算日食以顯推表及其所用之所以然必</span>  
<span style="margin-left: 2em">以視差求視會因詳前引三差恒垂向下高卑差爲</span>  
<span style="margin-left: 2em">正下南北差爲斜下東西差獨中限之一線爲正左</span>  
<span style="margin-left: 2em">右皆斜此是太陰所變距黃道度及順黃道經度用</span>  
<span style="margin-left: 2em">以加减時刻並求食分可矣但除地半徑差外別有</span>  
<span style="margin-left: 2em">三差名外差不生于日月地而生于氣一曰清蒙高</span>  
<span style="margin-left: 2em">差乃地所出清蒙之氣能變易高下二曰清蒙徑差</span>  
<span style="margin-left: 2em">日月居其中隨變本徑之大小三曰本氣徑差本氣</span>  
<span style="margin-left: 2em">者即月天以下空中氣也較清蒙爲更精微亦能變</span>  
<span style="margin-left: 2em">太陽之光照令目所見之視度視徑隨地隨時大小</span>  
<span style="margin-left: 2em">不一也</span>  
<span style="margin-left: 1em">第七卷測考食分方位及時刻務推與測並行以自驗</span>  
<span style="margin-left: 2em">其法密與否西曆家創法之初審之于天以求其當</span>  
<span style="margin-left: 2em">然成法之後復考之于天以証其必然正此意也交</span>  
<span style="margin-left: 2em">食推法既備前卷本卷則引測交食多寡之式如測</span>  
<span style="margin-left: 2em">日月各食分或于室內或于室外以真光形如遠鏡</span>  
<span style="margin-left: 2em">等承其射光之容即食分多寡可得非舊法水盤所</span>  
<span style="margin-left: 2em">能及也至二曜食時所向之方位或正或偏測與算</span>  
<span style="margin-left: 2em">合不爽毫末又日月或全或零食之時其變形之限</span>  
<span style="margin-left: 2em">如二食所共者初虧食甚復圓月食所獨者食既生</span>  
<span style="margin-left: 2em">光皆可得其準也</span>  
<span style="margin-left: 1em">五緯曆指一卷公論定各星古今次序測五星平行均</span>  
<span style="margin-left: 2em">數據古傳太陰最近地其次爲水爲金爲日而火而</span>  
<span style="margin-left: 2em">水而土而恒星古又謂諸天皆以地心爲本心今測</span>  
<span style="margin-left: 2em">則惟日月與恒星爲然五星各與地不同心即各視</span>  
<span style="margin-left: 2em">差及各高卑距地遠近可徴也</span>  
<span style="margin-left: 2em">五星諸行較恒星與太陽而得古今其法也乃先記</span>  
<span style="margin-left: 2em">其各平行而因各本行圈皆與地爲不同心圈并亦</span>  
<span style="margin-left: 2em">定其本行而更以古今圖樣解之且增以新測五星</span>  
<span style="margin-left: 2em">左右異像焉</span>  
<span style="margin-left: 1em">第二卷至六卷每卷測定五緯一星之最高及本天與</span>  
<span style="margin-left: 2em">地中兩心之差並各星表曆元以得各自行及歲行</span>  
<span style="margin-left: 2em">加减等度分但金水二星之行相似與火木土異蓋</span>  
<span style="margin-left: 2em">火木土或會或衝太陽以其實行爲歲行之界而金</span>  
<span style="margin-left: 2em">水即以太陽平行爲本天之平行其本天不出太陽</span>  
<span style="margin-left: 2em">之本輪因加小均輪以齊其順逆行天一周有二伏</span>  
<span style="margin-left: 2em">二見之時非彼三星每歲一會一衝太陽可比也又</span>  
<span style="margin-left: 2em">火星或以其行甚曲可以其行之遲疾不等有時四</span>  
<span style="margin-left: 2em">五旬日行過一宫有時二百餘日不及一宫行似無</span>  
<span style="margin-left: 2em">法兹窮究其理以著于圖定其經緯高卑之行使測</span>  
<span style="margin-left: 2em">與推諸用法皆明也</span>  
<span style="margin-left: 1em">第七卷論五星緯行推其與恒星或互相照或同出入</span>  
<span style="margin-left: 2em">以定其凌犯近遠見伏諸類蓋舍緯行南北多寡而</span>  
<span style="margin-left: 2em">止論經行即凌犯諸類無從得其全也故引古今累</span>  
<span style="margin-left: 2em">測遊星之緯記其各本道與黃道之交角並繪圖用</span>  
<span style="margin-left: 2em">三角形所推兩道濶狹以顯其實相距之比例又定</span>  
<span style="margin-left: 2em">五星各本天交行而較火木土于金水詳其緯從何</span>  
<span style="margin-left: 2em">而生從何而有異同也</span>  
<span style="margin-left: 1em">第八卷著諸曜凌犯相照伏見之原解七政遲疾二行</span>  
<span style="margin-left: 2em">五星留逆順合衝各情並著表繪圖求入宫入宿等</span>  
<span style="margin-left: 2em">法并論農家占歲醫家療疾人預知天時之雨暘皆</span>  
<span style="margin-left: 2em">由日月五星所命又定月大月小節氣閏月諸法</span>  
<span style="margin-left: 1em">第九卷依古今法測五星各距地之遠近以推其降施</span>  
<span style="margin-left: 2em">之力測各視徑及實徑之大小定其凌犯及諸照之</span>  
<span style="margin-left: 2em">密合查五星光色以考其照物之性情蓋星皆借日</span>  
<span style="margin-left: 2em">光之分而所發光色各異有如鏡者有如水者有如</span>  
<span style="margin-left: 2em">金者殆由各染本體之色而然又據新法新測以考</span>  
<span style="margin-left: 2em">中歷之古測乃知古測晨夕二留日時折半以求合</span>  
<span style="margin-left: 2em">伏之時非法也又其所用表晷簡平等儀皆與星行</span>  
<span style="margin-left: 2em">之道絕不相似而用以測五星則非其器也大約測</span>  
<span style="margin-left: 2em">五星須用黃赤全儀弧矢儀經緯象限等與其行相</span>  
<span style="margin-left: 2em">類者而又常較之於恆星乃可得其準也</span>  
<span style="margin-left: 1em">已上畧引書目皆歸歷原以全修歷之學闕一不可古</span>  
<span style="margin-left: 2em">之論歷者或務改曆元如氣應等或務正定歲差不</span>  
<span style="margin-left: 2em">則求之合朔求之五星求之宿度而已總皆掛一漏</span>  
<span style="margin-left: 2em">萬其法立窮必如新法乃爲無歉且此外更著學歷</span>  
<span style="margin-left: 2em">要書如割圓法八線表視學幾何要法測量全義渾</span>  
<span style="margin-left: 2em">天儀用法比例規籌算開方等法以爲旁通之學而</span>  
<span style="margin-left: 2em">歷學於是乎大備後有學者宜究心焉</span>
