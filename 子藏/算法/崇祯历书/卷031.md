<span style="margin-left: 1em">第三卷以黄道经纬变赤道经纬及绘星图数法盖星</span>

<span style="margin-left: 2em">别以六等令星在图在天大小异形无不相肖</span>

<span style="margin-left: 2em">分秒无已借西历补之</span>

<span style="margin-left: 2em">即谓两交之逆行也测法亦用月食考古无传仍依</span>  
<span style="margin-left: 2em">西史如前法用两月食测其前后各率均齐得交逆</span>  
<span style="margin-left: 2em">行日三分十一秒岁十九度零十九秒四十三微此</span>  
<span style="margin-left: 2em">为二千年前古测后史各加密测推得交行每年盈</span>  
<span style="margin-left: 2em">一秒四十二纎应减</span>  
<span style="margin-left: 2em">论用不同心圈与用小轮名异理同皆借以分布度</span>  
<span style="margin-left: 2em">数解明七政盈缩迟疾之行乃公借古今测定本轮</span>  
<span style="margin-left: 2em">之大小远近之比例以求加减差立推算各表之法</span>  
<span style="margin-left: 2em">然而创始难工增修易善历家积功二千余生至近</span>

<span style="margin-left: 2em">合盖前人未悟地半径差与蒙气差于二至所测之</span>

<span style="margin-left: 2em">白距度此西古今通法中历黄白相距恒大于西术</span>  
<span style="margin-left: 2em">谬矣其推月食恒小于天验殆缘于此</span>  
<span style="margin-left: 2em">论月视差此因地半径而生与他曜同但月天视地</span>  
<span style="margin-left: 2em">为近为卑则地与本天各半径之比例其视差并大</span>  
<span style="margin-left: 2em">古今累测得数无异约一度故测太阴先得其视高</span>  
<span style="margin-left: 2em">乃以地半径差加之得数又以蒙气差减之此为实</span>  
<span style="margin-left: 2em">高如反推则得其实高乃以地半径差减之得数又</span>  
<span style="margin-left: 2em">以蒙气差加之此为视高具见本表但蒙气之差因</span>  
<span style="margin-left: 2em">地因时所在各异必求本地势本时刻之确数定之</span>  
<span style="margin-left: 2em">终测月径地景径或由月食测定食分并推求其自</span>  
<span style="margin-left: 2em">行距交距黄道等率而得或以测太阳之似径比于</span>  
<span style="margin-left: 2em">地而并记其月距地设三角形推月与地各径又地</span>

<span style="margin-left: 1em">三卷论测日月地大小近远之比例引古今法数种先</span>

<span style="margin-left: 2em">径与实径大小绝异又如月视地为小月天视六曜</span>

<span style="margin-left: 2em">测日月各距地之高论月天象数及诸月表之原</span>

<span style="margin-left: 2em">古今交食以证新法并为后学之资盖因中史失载</span>

<span style="margin-left: 2em">望当食必食多寡先后上下千百世可知此则本卷</span>  
<span style="margin-left: 2em">益加详焉</span>  
<span style="margin-left: 1em">第二卷详交食诸类及推交食之原与简法盖日月之</span>

<span style="margin-left: 2em">后人盖因得其所以然而后握简御繁无难也</span>  
<span style="margin-left: 1em">第三卷求推交食依人目所见仪器所测之时刻及所</span>  
<span style="margin-left: 2em">食分数之原必应改实时为视时而此地此时见食</span>  
<span style="margin-left: 2em">彼地则异时见食也故可随地推交食之有无又可</span>  
<span style="margin-left: 2em">上推往古下验将来万年悉如指掌若食分之多寡</span>  
<span style="margin-left: 2em">既原于日月地景之各视半径则定视径分秒之数</span>  
<span style="margin-left: 2em">逆计太阴居最高或最卑本视径差地景即因太阳</span>  
<span style="margin-left: 2em">居高居卑不同其照地生景之差以得各实差然后</span>  
<span style="margin-left: 2em">食分可得而定矣</span>  
<span style="margin-left: 1em">第四卷详食限食甚前后时及绘食图以解各食向位</span>  
<span style="margin-left: 2em">论限日与月不同盖虽同以所行各道经度距交几</span>  
<span style="margin-left: 2em">何为有食之始然而月食则太阴与地景遇因而两</span>  
<span style="margin-left: 2em">周相切即以两视半径并较白道距黄道度推交周</span>  
<span style="margin-left: 2em">度以定食限日食则太阳与太阴遇虽亦两周相切</span>  
<span style="margin-left: 2em">而有视差必先加入视差而后得距度定其食限也</span>  
<span style="margin-left: 2em">惟其食限各异故推太阴越五月能再食越七月不</span>  
<span style="margin-left: 2em">再食而太阳越五月七月皆能再食</span>  
<span style="margin-left: 2em">至于食分则以距度求之盖两周之心相距之度也</span>  
<span style="margin-left: 2em">在月食则为太阴心实距地景之心愈近食分愈多</span>  
<span style="margin-left: 2em">在日食则为日月两心以视度相距其近远不依实</span>  
<span style="margin-left: 2em">度而依目视之所及为准此即月食分天下皆同而</span>  
<span style="margin-left: 2em">日食分随人目东西南北各异之原也</span>  
<span style="margin-left: 2em">食分以纬度而定食甚前后时刻则并以经纬而定</span>  
<span style="margin-left: 2em">盖太阴本时距度多寡不同即入景浅深亦不同浅</span>  
<span style="margin-left: 2em">则历时少深则历时多此盖从纬定也若就经论太</span>  
<span style="margin-left: 2em">阴之自行时疾时迟纬与视径虽同而自行每食不</span>  
<span style="margin-left: 2em">同即所得时刻亦必不同但太阴入景之弧与出景</span>  
<span style="margin-left: 2em">之弧畧等故依其行弧推食甚前之时倍之随得食</span>  
<span style="margin-left: 2em">甚后至复圆之时乃日食时刻则又以视差有异焉</span>  
<span style="margin-left: 2em">交食图列方位方位者日月失光之面所向之方也</span>  
<span style="margin-left: 2em">法先考本食是阴历或阳历更考黄道是斜交地平</span>  
<span style="margin-left: 2em">与否盖黄道斜交日月亦依以斜行食时方向必异</span>  
<span style="margin-left: 2em">不可不审也故绘图以一直线过日月二心审其与</span>  
<span style="margin-left: 2em">地面相遇之势乃定日食方位过日景二心审其与</span>  
<span style="margin-left: 2em">地平相遇之势乃定月食方位旧法徒以阴阳二历</span>  
<span style="margin-left: 2em">求之疎矣验时安得合乎</span>  
<span style="margin-left: 1em">第五卷详日月视差及日食掩地面几何凡推步日食</span>  
<span style="margin-left: 2em">要以人目为主目见之会非实会而视会也此差虽</span>  
<span style="margin-left: 2em">由地半径生<sub class="note-yuan">以人目在地面不在地心故</sub>更为人目差分别有三</span>  
<span style="margin-left: 2em">等一高卑差以天顶为限一南北差以黄道为限此</span>  
<span style="margin-left: 2em">限能变诸曜纬度一东西差以黄道九十度为限其</span>  
<span style="margin-left: 2em">左右能变经度及时刻测此三差悉用三角形因设</span>  
<span style="margin-left: 2em">地半径为一边日月各距地高为一边各距地面之</span>  
<span style="margin-left: 2em">远为一边测之乃得高弧或正或斜交于黄道以四</span>  
<span style="margin-left: 2em">方分视差然东西南北二差又时有变务彼此相较</span>  
<span style="margin-left: 2em">展转推求可也</span>  
<span style="margin-left: 2em">论日食之掩地面必系全食或系应不见光之地面</span>  
<span style="margin-left: 2em">又或本日太阳适在最卑而其视径大似太阴之视</span>  
<span style="margin-left: 2em">径若此则虽二曜之心合而周边大小微异乃见金</span>  
<span style="margin-left: 2em">环焉又总论见食之地其广几何且见食进退一分</span>  
<span style="margin-left: 2em">应地面几何由是以推各国各省能见食与否并食</span>  
<span style="margin-left: 2em">分多寡等义</span>  
<span style="margin-left: 1em">第六卷依原算日食以显推表及其所用之所以然必</span>  
<span style="margin-left: 2em">以视差求视会因详前引三差恒垂向下高卑差为</span>  
<span style="margin-left: 2em">正下南北差为斜下东西差独中限之一线为正左</span>  
<span style="margin-left: 2em">右皆斜此是太阴所变距黄道度及顺黄道经度用</span>  
<span style="margin-left: 2em">以加减时刻并求食分可矣但除地半径差外别有</span>  
<span style="margin-left: 2em">三差名外差不生于日月地而生于气一曰清蒙高</span>  
<span style="margin-left: 2em">差乃地所出清蒙之气能变易高下二曰清蒙径差</span>  
<span style="margin-left: 2em">日月居其中随变本径之大小三曰本气径差本气</span>  
<span style="margin-left: 2em">者即月天以下空中气也较清蒙为更精微亦能变</span>  
<span style="margin-left: 2em">太阳之光照令目所见之视度视径随地随时大小</span>  
<span style="margin-left: 2em">不一也</span>  
<span style="margin-left: 1em">第七卷测考食分方位及时刻务推与测并行以自验</span>  
<span style="margin-left: 2em">其法密与否西历家创法之初审之于天以求其当</span>  
<span style="margin-left: 2em">然成法之后复考之于天以证其必然正此意也交</span>  
<span style="margin-left: 2em">食推法既备前卷本卷则引测交食多寡之式如测</span>  
<span style="margin-left: 2em">日月各食分或于室内或于室外以真光形如远镜</span>  
<span style="margin-left: 2em">等承其射光之容即食分多寡可得非旧法水盘所</span>  
<span style="margin-left: 2em">能及也至二曜食时所向之方位或正或偏测与算</span>  
<span style="margin-left: 2em">合不爽毫末又日月或全或零食之时其变形之限</span>  
<span style="margin-left: 2em">如二食所共者初亏食甚复圆月食所独者食既生</span>  
<span style="margin-left: 2em">光皆可得其准也</span>

<span style="margin-left: 2em">数据古传太阴最近地其次为水为金为日而火而</span>

<span style="margin-left: 2em">其各平行而因各本行圈皆与地为不同心圈并亦</span>
