## 崇禎曆書卷之十五　順治奏疏

*順治元年五月十一日至順治元年八月初一日*

<span style="margin-left: 2em">奏疏一<sub class="note-jiao">校：以下據日藏康熙續本補錄</sub></span>  
<span style="margin-left: 8em">順治元年五月十一日湯若望奏本</span>  
<span style="margin-left: 3em">修政曆法臣湯若望謹</span>  
<span style="margin-left: 2em">奏爲懇乞</span>  
<span style="margin-left: 1em">聖明垂鑒遠旅孤踪格外施恩事臣自大西洋八萬里</span>  
<span style="margin-left: 3em">航海來</span>  
<span style="margin-left: 2em">京不婚不宦專以昭事</span>

天主聖教爲本勸人忠  
<span style="margin-left: 1em">君孝親貞廉守法爲務臣自購置</span>  
天主堂聖母堂共一所朝夕焚修祈求普祐迄今住京二  
<span style="margin-left: 3em">十餘年于崇禎二年間因舊曆舛訛奉前朝勅旨</span>  
<span style="margin-left: 3em">修政曆法推測日月交食五星躔度悉合</span>

<span style="margin-left: 3em">進內庭擬欲頒行幸逢</span>  
<span style="margin-left: 1em">大清聖國俯念燕民遭賊荼毒</span>  
<span style="margin-left: 1em">躬行天討伐罪吊民萬姓焚頂没世難忘此乃</span>  
天主上帝寵之四方隆以  
<span style="margin-left: 1em">君師之任救天下蒼生于水火者也茲臣仰讀</span>  
<span style="margin-left: 2em">內院傳示</span>  
<span style="margin-left: 1em">令旨中東西三城居民搬移于南北二城以便大兵憇</span>  
<span style="margin-left: 3em">息是誠</span>  
<span style="margin-left: 1em">聖明軫恤便民至意敢不即便欽遵但念臣住居宣武</span>  
<span style="margin-left: 3em">門內城下中城地方房屋半爲賊火焚燬僅存</span>  
天主聖母二堂并小屋數椽朝夕在內虔誠誦禱况臣八  
<span style="margin-left: 3em">萬里萍踪一身之外並無親戚可倚殊爲孤孑堪</span>  
<span style="margin-left: 3em">憐且堂中所供</span>  
<span style="margin-left: 1em">聖像龕座重大而西方帶來經書不下三千餘部內及</span>  
<span style="margin-left: 3em">性命微言外及曆算屯農水利一切生財大道莫</span>  
<span style="margin-left: 3em">不備載至于翻譯已刻修曆書板數架充棟誠恐</span>  
<span style="margin-left: 3em">倉猝那移必多散失而臣數十年拮据勤勞無由</span>  
<span style="margin-left: 3em">效用矣伏乞</span>  
<span style="margin-left: 1em">皇上軫念孤忠</span>  
<span style="margin-left: 1em">特賜柔遠之典倘蒙</span>  
<span style="margin-left: 1em">俯准微臣仍舊居住使臣得以安意精修祝延</span>  
<span style="margin-left: 1em">聖壽而保存經典書籍異圖報于異日</span>  
<span style="margin-left: 1em">洪德如天感</span>  
<span style="margin-left: 1em">恩無地矣臣爲此激切冒瀆</span>  
<span style="margin-left: 1em">天聰惟</span>  
<span style="margin-left: 1em">聖明俯宥垂察施行臣不勝瞻仰惶悚待</span>  
<span style="margin-left: 1em">命之至爲此具本親賫謹具奏</span>  
<span style="margin-left: 1em">聞</span>

<span style="margin-left: 3em">再事推算可以運旋即得也其地平日晷上有三</span>  
<span style="margin-left: 3em">角形表能使時刻以應節氣爲准臨用須以羅經</span>  
<span style="margin-left: 3em">針正對子午則表中銳影自不爽指以驗天道之</span>
