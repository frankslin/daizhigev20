<span style="margin-left: 1em">表法篇第四</span>  
<span style="margin-left: 2em">既得前六宗率更用三要法作表</span>  
<span style="margin-left: 1em">要法一　前後兩弦其能等于半徑<sub class="note-yuan">圖說系法俱見本</sub></span>  
<span style="margin-left: 4em">　<sub class="note-yuan">篇總論第十二條</sub></span>  
<span style="margin-left: 1em">要法二　有各弧之前後兩弦求倍本弧之正弦</span>  
<span style="margin-left: 6em">如上甲戊弧三十五度其正弦爲戊己得</span>  
<span style="margin-left: 6em">五七三五七六四其餘弦即乙己得八一</span>  
<span style="margin-left: 6em">九一五二〇今以此二弦求倍甲戊而爲</span>  
<span style="margin-left: 2em">甲丁弧之正弦其法以乙戊半徑千萬爲第一率以</span>  
<span style="margin-left: 2em">戊己正弦爲第二率以乙壬餘弦爲第三率即得壬</span>  
<span style="margin-left: 2em">庚第四率與辛癸等爲四六九八四六二倍之得丁</span>  
<span style="margin-left: 2em">癸爲九三九六九二四其弧甲丁七十度</span>  
<span style="margin-left: 2em">論曰乙戊己與乙壬甲兩三角形比例等則乙己與</span>  
<span style="margin-left: 2em">乙壬等而戊己與甲壬亦等乙己與乙壬等故乙壬</span>  
<span style="margin-left: 2em">爲餘弦也而乙壬庚乙戊己兩形之比例等故第四</span>  
<span style="margin-left: 2em">率爲壬庚壬庚與辛癸同爲直角形之邊故等又丁</span>  
<span style="margin-left: 2em">壬戊戊壬甲同爲直角則甲戊戊丁兩弧等甲壬壬</span>  
<span style="margin-left: 2em">丁兩弦亦等而丁辛與壬庚亦等故倍辛癸得丁癸</span>  
<span style="margin-left: 2em">也又丁辛壬壬庚甲兩形之三邊俱等依句股法得</span>  
<span style="margin-left: 2em">甲庚邊倍之爲甲癸以減半徑得癸乙爲餘弦</span>  
<span style="margin-left: 1em">要法三　各弧之全弦上方與其正半弦上偕其矢上</span>  
<span style="margin-left: 2em">兩方并等</span>  
<span style="margin-left: 2em">句股術也</span>  
<span style="margin-left: 2em">如上甲丁弧之正弦爲丁辛其矢爲甲辛此兩線上</span>  
<span style="margin-left: 6em">方并與甲丁上方等</span>  
<span style="margin-left: 6em">系法有一弧之正弦及其餘弦而求其半</span>  
<span style="margin-left: 6em">弧之正弦</span>  
<span style="margin-left: 2em">如上甲丁弧其正弦爲丁辛餘弦爲乙辛而求甲戊</span>  
<span style="margin-left: 2em">弧之甲己半弦其法于甲乙半徑減乙辛餘弦得甲</span>  
<span style="margin-left: 2em">辛矢其上方偕丁辛半弦上方并與甲丁通弦上方</span>  
<span style="margin-left: 2em">等開方得甲丁線半之得甲己爲甲戊弧之正弦其</span>  
<span style="margin-left: 2em">數如上甲丁弧三十度其半弦丁辛爲五〇〇〇〇</span>  
<span style="margin-left: 2em">〇〇乙辛餘弦爲八六六〇二五四以減全半徑得</span>  
<span style="margin-left: 2em">甲辛矢一三三九七四六丁辛上方爲二五〇〇〇</span>  
<span style="margin-left: 2em">〇〇〇〇〇〇〇〇〇甲辛上方爲一七九四九一</span>  
<span style="margin-left: 2em">九三四四五一六并之得二六七九四九一九三四</span>  
<span style="margin-left: 2em">四五一六開方得甲丁線五一七六三六〇即甲丁</span>  
<span style="margin-left: 2em">弧三十度之弦也半之爲甲己半弦得二五八八一</span>  
<span style="margin-left: 2em">九〇其弧十五度</span>  
<span style="margin-left: 1em">用前三要法即大測表大畧可作又有簡法二題其用</span>  
<span style="margin-left: 2em">甚便但非恆有</span>  
<span style="margin-left: 2em">簡法一　兩正弦之較與六十度左右距等弧之正</span>  
<span style="margin-left: 2em">弦等<sub class="note-yuan">見本卷第二篇</sub></span>  
<span style="margin-left: 2em">解曰甲乙丙象限內有丙己小弧丙己戊丁大弧丙</span>  
<span style="margin-left: 6em">戊弧爲六十度而戊己戊丁兩弧等其前</span>  
<span style="margin-left: 6em">兩正弦一爲己辛一爲丁庚其較丁癸題</span>  
<span style="margin-left: 6em">言丁癸較與己壬壬丁兩正弦各等</span>  
<span style="margin-left: 2em">論曰試作一己子線則丁己子成三邊等角形何也</span>  
<span style="margin-left: 2em">此形中有子丁壬壬己子兩三角形此兩角形等又</span>  
<span style="margin-left: 2em">何也子壬同腰而丁壬壬己兩腰等則丁壬己壬兩</span>  
<span style="margin-left: 2em">直角亦等而丁子子己兩底亦等子丁己子己丁兩</span>  
<span style="margin-left: 2em">角亦等又丙戊弧既六十度其餘戊乙弧必三十度</span>  
<span style="margin-left: 2em">而乙甲戊角爲三十度角甲乙庚丁既平行甲戊線</span>  
<span style="margin-left: 2em">截二線于子即內外角等而丁子戊角亦三十度戊</span>  
<span style="margin-left: 2em">子己角亦三十度是丁子己爲六十度角也丁與全</span>  
<span style="margin-left: 2em">己全子三角既等兩直角<sub class="note-yuan">一之三十二</sub>則共爲一百八十</span>  
<span style="margin-left: 2em">度于中減全子角六十度則丁己兩全角百二十度</span>  
<span style="margin-left: 2em">而此兩角既等即各得六十度則此形之三角三邊</span>  
<span style="margin-left: 2em">俱等夫丁己己子兩線等則己癸垂線所分之丁癸</span>  
<span style="margin-left: 2em">子癸兩直角亦等而己癸同腰則丁癸與癸子必等</span>  
<span style="margin-left: 2em">丁癸爲丁子之半丁壬爲丁己之半全線等則所分</span>  
<span style="margin-left: 2em">必等是丁癸與丁壬等與壬己亦等</span>  
<span style="margin-left: 2em">系題兩弧各有其正半弦兩半弦至弧之點在六十</span>  
<span style="margin-left: 2em">度之左右而距度點等則前兩正半弦之較即後兩</span>  
<span style="margin-left: 2em">半弦如圖丙己戊弧六十度丙己弧五十度己戊弧</span>  
<span style="margin-left: 2em">十度丙己之正半弦己辛先得七千六百六十丙丁</span>  
<span style="margin-left: 2em">弧七十度丁戊弧亦十度丙丁弧之正半弦爲丁庚</span>  
<span style="margin-left: 2em">先得九千三百九十六今求丁戊弧之半弦其法以</span>  
<span style="margin-left: 2em">己辛丁庚兩半弦相減得丁癸較一千七百三十六</span>  
<span style="margin-left: 2em">即丁戊弧十度之丁壬半弦<sub class="note-yuan">此數半徑設一萬</sub></span>  
<span style="margin-left: 2em">次系有六十度左右相離弧之正弦一率又有其原</span>  
<span style="margin-left: 2em">正弦一率而求其相對之彼正弦其法有二一以大</span>  
<span style="margin-left: 2em">求小一以小求大以大求小者用大弧之正弦與相</span>  
<span style="margin-left: 2em">離弧之正弦相減其較爲小弧之正弦<sub class="note-yuan">餘則稱餘倒則稱倒</sub>以</span>  
<span style="margin-left: 2em">小求大者用相離弧之半弦加小弧之半弦即大弧</span>  
<span style="margin-left: 2em">之半弦</span>  
<span style="margin-left: 2em">如上丁壬離弧之正弦即己壬與丁癸較等爲一千</span>  
<span style="margin-left: 2em">七百三十六丁庚大弦爲九千三百九十六相減得</span>  
<span style="margin-left: 2em">癸庚七千六六〇即己丙弧之己辛小弦反之丁癸</span>  
<span style="margin-left: 2em">較爲一千七百三十六<sub class="note-yuan">即丁壬離弦</sub>以加于癸庚<sub class="note-yuan">即辛己小弦</sub></span>  
<span style="margin-left: 2em">七千六百六十得丁庚大弦九千三百九十六</span>  
<span style="margin-left: 2em">用此法于象限內先得半弦六十率用加減法即得</span>  
<span style="margin-left: 2em">其餘三十率</span>  
<span style="margin-left: 2em">簡法二　有兩弧不等之各正弦又有其各餘弦而</span>  
<span style="margin-left: 2em">求兩弧<sub class="note-jiao">校：弧原作弦據文淵本改</sub>相加相減弧之各正弦其法有</span>  
<span style="margin-left: 2em">二一相加一相減相加者以前弧之正弦乘後弧之</span>  
<span style="margin-left: 2em">餘弦以後弧之正弦乘前弧之餘弦各得數并之爲</span>  
<span style="margin-left: 2em">實以半徑爲法而一得兩弧相加爲總弧之正弦</span>  
<span style="margin-left: 6em">相減者亦如前法互乘得各數相減餘爲</span>  
<span style="margin-left: 6em">實以半徑爲法而一爲兩弧相減弧之正</span>  
<span style="margin-left: 6em">弦</span>  
<span style="margin-left: 2em">如上甲乙前弧二十度乙丙後弧十五度總三十五</span>  
<span style="margin-left: 2em">度其差五度甲乙弧之半弦爲三四二〇二〇一其</span>  
<span style="margin-left: 2em">餘弧甲丁之半弦爲九三九六九二六乙丙弧之半</span>  
<span style="margin-left: 2em">弦爲二五八八一九〇其餘弧乙丁之半弦爲九六</span>  
<span style="margin-left: 2em">五九二五八以甲乙半弦與丙丁餘弦之半乘得三</span>  
<span style="margin-left: 2em">三〇三六六〇三八七〇八五八以乙丙半弦與甲</span>

<span style="margin-left: 1em">表用四　有弧求其大小矢</span>

<span style="margin-left: 4em">矢數得乙丙小矢爲二一〇九一五九以減全</span>

<span style="margin-left: 2em">四一以減半徑得小矢</span>  
<span style="margin-left: 1em">測平篇第六</span>  
<span style="margin-left: 1em">測平者測平面上三角形也凡此形皆有六率曰三邊</span>  
<span style="margin-left: 2em">曰三角角無測法必以割圓線測之其比例甚多今</span>  
<span style="margin-left: 2em">用四法以爲根本依此四根法可用大測表測一切</span>  
<span style="margin-left: 2em">平面三角形亦執簡御繁之術也凡測三角形皆用</span>  
<span style="margin-left: 2em">三率法<sub class="note-yuan">即同比例</sub>三率法又以相似兩三角形<sub class="note-yuan">幾何六卷四</sub>爲</span>  
<span style="margin-left: 2em">宗下文詳之</span>  
<span style="margin-left: 1em">根法一　各三角形之兩邊與其各對角兩正弦比例</span>  
<span style="margin-left: 2em">等一云右邊與左邊若左角之弦與右角之弦</span>  
<span style="margin-left: 2em">如上甲乙丙平面三角形其甲丙兩爲銳角即以甲</span>  
<span style="margin-left: 4em">爲心甲乙爲半徑作乙戊弧次作乙己垂線即</span>  
<span style="margin-left: 4em">乙戊弧之正弦亦即甲角之正弦也又以甲乙</span>  
<span style="margin-left: 4em">爲度從丙截取丙庚從丙心庚界作庚辛弧又</span>  
<span style="margin-left: 4em">作垂線庚丁即庚辛弧與丙角之正弦也題言</span>  
<span style="margin-left: 2em">乙角之甲乙右邊與乙丙左邊若左角丙之庚丁正</span>  
<span style="margin-left: 2em">弦與右角甲之乙己正弦</span>  
<span style="margin-left: 2em">論曰乙丙己三角形有乙己庚丁兩平行線即乙丙</span>  
<span style="margin-left: 2em">與乙己若庚丙與庚丁而丙庚原與甲乙等即乙丙</span>  
<span style="margin-left: 2em">與乙己若甲乙與庚丁更之即甲乙與乙丙若庚丁</span>  
<span style="margin-left: 2em">與乙己如上甲乙丙形乙爲直角有丙乙丁戊兩平</span>  
<span style="margin-left: 5em">行線即甲丙與丙乙若甲丁與丁戊而乙丙</span>  
<span style="margin-left: 5em">與甲丁等即甲丙與丙乙若丙乙與丁戊反</span>  
<span style="margin-left: 5em">之則丙角之丙乙右邊與丙甲左邊若左角</span>  
<span style="margin-left: 5em">甲之丁戊弦與右角乙之丙乙弦</span>  
<span style="margin-left: 2em">如上甲乙丙形乙爲鈍角其正弦丙壬而甲戊線與</span>  
<span style="margin-left: 5em">乙丙等甲角之正弦爲戊己題言丙角之甲</span>  
<span style="margin-left: 5em">丙右邊與丙乙左邊若左角乙之丙壬弦與</span>  
<span style="margin-left: 5em">右角甲之戊己弦何也試于形外引甲乙至</span>  
<span style="margin-left: 5em">丁作丙丁線與丙乙等即丁角與乙銳角等</span>  
<span style="margin-left: 2em">依首條甲丙與丙丁若丙壬與戊己即甲丙與丙乙</span>  
<span style="margin-left: 2em">亦若丙壬與戊己</span>  
<span style="margin-left: 5em">總論之各三角形各兩邊之比例與兩對角</span>  
<span style="margin-left: 5em">之兩正弦比例等者何也試于形外作切圈</span>  
<span style="margin-left: 5em">則三邊爲三弦而本形之各邊皆爲各對角</span>  
<span style="margin-left: 2em">之通弦即乙丙邊與甲乙邊若甲角之弦與丙角之</span>  
<span style="margin-left: 2em">弦也當已即是豈止同比例而已乎夫全與全半與</span>  
<span style="margin-left: 2em">半比例等則各半弦與各通弦之比例亦等</span>  
<span style="margin-left: 2em">此題爲用對角根本</span>  
<span style="margin-left: 1em">根法二　各三角形以大角爲心小邊爲半徑作圈而</span>  
<span style="margin-left: 2em">截兩邊各爲圈內外兩線即底線與兩腰并若腰之</span>  
<span style="margin-left: 2em">外分與底之外分</span>  
<span style="margin-left: 5em">如上甲乙丙形其小邊甲丙其底乙丙以甲</span>  
<span style="margin-left: 5em">爲心甲丙爲半徑作圈截底于戊截大腰于</span>  
<span style="margin-left: 5em">庚題言乙丙底與乙甲甲丙兩腰并若腰外</span>  
<span style="margin-left: 5em">分乙庚與底外分乙戊</span>  
<span style="margin-left: 2em">論曰試作乙己引出線即甲己與甲丙等而乙己與</span>  
<span style="margin-left: 2em">兩腰并等乙己乙庚矩內形與乙丙乙戊矩內形兩</span>  
<span style="margin-left: 2em">容等<sub class="note-yuan">幾何三卷三五</sub>即兩形邊爲互相視之邊而乙己與乙</span>  
<span style="margin-left: 2em">丙若乙戊與乙庚既得乙戊底外分以減全底得戊</span>  
<span style="margin-left: 2em">丙半之得垂線所至爲丁丙</span>  
<span style="margin-left: 2em">此題爲用垂線根本</span>  
<span style="margin-left: 1em">根法三　有兩角并之數又有其各正弦之比例求兩</span>  
<span style="margin-left: 2em">分角之數</span>  
<span style="margin-left: 2em">如上乙甲丙角有其弧乙辛丙之數其兩分之大角</span>  
<span style="margin-left: 2em">爲乙甲壬小角爲壬甲丙未得數但知大角正弦乙</span>  
<span style="margin-left: 5em">丁小角正弦丙戊之比例亦未得數而求兩</span>  
<span style="margin-left: 5em">分角之數其法以乙辛丙弧兩平分于辛作</span>  
<span style="margin-left: 5em">甲辛線乙甲辛辛甲丙兩角等而辛甲壬角</span>  
<span style="margin-left: 2em">爲半弧與小弧之差又爲大弧與小弧之半差次截</span>  
<span style="margin-left: 2em">辛庚弧與辛戊等作甲庚線即庚甲壬角爲大小兩</span>  
<span style="margin-left: 2em">弧之差夫乙丙者總角之弦乙丑平分弧之正弦而</span>  
<span style="margin-left: 2em">己辛爲乙辛半弧之切線辛癸爲辛丙半弧之切線</span>  
<span style="margin-left: 2em">此二線等而辛壬辛庚各爲半差弧之切線亦等又</span>  
<span style="margin-left: 2em">乙丁子子丙戊兩形爲兩正弦上三角形此兩形之</span>  
<span style="margin-left: 2em">丁與戊皆直角又同底即兩正弦之對角爲子上兩</span>  
<span style="margin-left: 2em">交角亦等<sub class="note-yuan">幾何一卷十題</sub>而丁乙子子丙戊兩角亦等<sub class="note-yuan">幾何一卷</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">三二</sub>則兩形爲相似形而乙丁正弦與丙戊正弦若乙</span>  
<span style="margin-left: 2em">子與子丙<sub class="note-yuan">幾何六卷四</sub>先既有乙丁丙戊兩正弦之比例</span>  
<span style="margin-left: 2em">即得乙子與子丙之比例而又得乙子與子丙之較</span>  
<span style="margin-left: 2em">爲子寅夫乙丙己癸兩線同爲甲辛半徑上之垂線</span>  
<span style="margin-left: 5em">即平行甲乙丙甲己癸兩形之各角等即爲</span>  
<span style="margin-left: 5em">相似之形<sub class="note-yuan">六卷四</sub>而兩形內所分之各兩三角</span>  
<span style="margin-left: 5em">形如甲庚癸甲寅丙之類俱相似即以兩線</span>  
<span style="margin-left: 2em">之并數乙丙爲第一率以兩線之差數子寅爲第二</span>  
<span style="margin-left: 2em">率以兩半弧之兩切線己癸爲第三率則得兩差弧</span>  
<span style="margin-left: 2em">之切線庚壬爲第四率矣而此比例稍繁別有簡者</span>  
<span style="margin-left: 2em">則半之曰丙丑與子丑若癸辛與壬辛也有更簡者</span>  
<span style="margin-left: 2em">則曰乙丙與子寅若辛癸與辛壬也今用第三法云</span>  
<span style="margin-left: 2em">乙丙爲兩邊之并數子寅其較數辛癸爲兩角總數</span>  
<span style="margin-left: 2em">內半弧之切線而辛壬爲大小兩角較弧之切線既</span>  
<span style="margin-left: 2em">得辛壬切線即得辛甲壬角以加乙甲辛半角即得</span>  
<span style="margin-left: 2em">乙甲壬大角以減辛甲丙半角即得壬甲丙小角</span>  
<span style="margin-left: 2em">以數明之乙甲丙角爲四十度所包大小兩隱角爲</span>  
<span style="margin-left: 2em">乙甲壬壬甲丙其兩正弦乙丁丙戊之比例爲七與</span>  
<span style="margin-left: 2em">四即乙子子丙之比例亦七與四而乙丙之總數如</span>  
<span style="margin-left: 2em">十一平分之于丑即乙丑丑丙各得五有半而乙辛</span>  
<span style="margin-left: 2em">辛丙兩弧各二十度又以大線七與半線相減餘一</span>  
<span style="margin-left: 2em">有半以半線五有半與小線四相減亦餘一有半又</span>  
<span style="margin-left: 2em">甲辛爲半徑即辛丙二十度弧之切線辛癸爲三六</span>  
<span style="margin-left: 2em">三九七〇二即以丑丙五有半爲第一率以辛癸切</span>

<span style="margin-left: 2em">壬角爲五度四十〇分八秒以減辛丙二十度餘壬</span>  
<span style="margin-left: 2em">甲小角一十四度一十九分五十二秒以加半弧乙</span>  
<span style="margin-left: 2em">辛得乙甲壬大角二十五度四十〇分八秒</span>  
<span style="margin-left: 2em">此題爲用切線根本</span>  
<span style="margin-left: 1em">根法四　凡直角三邊形之各邊皆能爲半徑</span>  
<span style="margin-left: 2em">其一以弦線爲半徑作弧即餘兩腰包直角者各爲</span>  
<span style="margin-left: 2em">其對角之正弦</span>  
<span style="margin-left: 6em">如上甲乙丙形其乙丙爲對直角之弦線</span>  
<span style="margin-left: 6em">以爲半徑作丁丙弧即甲丙小腰爲對角</span>  
<span style="margin-left: 6em">乙之正弦甲乙大腰爲對角丙之正弦</span>  
<span style="margin-left: 2em">其二以大腰爲半徑即小腰爲小角之切線而弦線</span>  
<span style="margin-left: 5em">爲小角之割線</span>  
<span style="margin-left: 5em">如上甲乙大腰爲半徑即甲丙小腰爲乙小</span>  
<span style="margin-left: 5em">角之切線而乙丙爲乙角之割線</span>  
<span style="margin-left: 2em">其三以小腰爲半徑即大腰爲大角之切線而弦線</span>  
<span style="margin-left: 2em">爲大角之割線</span>  
<span style="margin-left: 2em">如上甲丙小腰爲半徑即甲乙大腰爲丙大角之切</span>  
<span style="margin-left: 5em">線而乙丙弦線爲其割線</span>  
<span style="margin-left: 2em">此題爲用割圓各線根本</span>
