<span style="margin-left: 1em">要法一　前后两弦其能等于半径<sub class="note-yuan">图说系法俱见本</sub></span>  
<span style="margin-left: 4em">　<sub class="note-yuan">篇总论第十二条</sub></span>  
<span style="margin-left: 1em">要法二　有各弧之前后两弦求倍本弧之正弦</span>  
<span style="margin-left: 6em">如上甲戊弧三十五度其正弦为戊己得</span>  
<span style="margin-left: 6em">五七三五七六四其余弦即乙己得八一</span>  
<span style="margin-left: 6em">九一五二〇今以此二弦求倍甲戊而为</span>  
<span style="margin-left: 2em">甲丁弧之正弦其法以乙戊半径千万为第一率以</span>  
<span style="margin-left: 2em">戊己正弦为第二率以乙壬余弦为第三率即得壬</span>  
<span style="margin-left: 2em">庚第四率与辛癸等为四六九八四六二倍之得丁</span>  
<span style="margin-left: 2em">癸为九三九六九二四其弧甲丁七十度</span>  
<span style="margin-left: 2em">论曰乙戊己与乙壬甲两三角形比例等则乙己与</span>  
<span style="margin-left: 2em">乙壬等而戊己与甲壬亦等乙己与乙壬等故乙壬</span>  
<span style="margin-left: 2em">为余弦也而乙壬庚乙戊己两形之比例等故第四</span>  
<span style="margin-left: 2em">率为壬庚壬庚与辛癸同为直角形之边故等又丁</span>  
<span style="margin-left: 2em">壬戊戊壬甲同为直角则甲戊戊丁两弧等甲壬壬</span>  
<span style="margin-left: 2em">丁两弦亦等而丁辛与壬庚亦等故倍辛癸得丁癸</span>  
<span style="margin-left: 2em">也又丁辛壬壬庚甲两形之三边俱等依句股法得</span>  
<span style="margin-left: 2em">甲庚边倍之为甲癸以减半径得癸乙为余弦</span>  
<span style="margin-left: 1em">要法三　各弧之全弦上方与其正半弦上偕其矢上</span>  
<span style="margin-left: 2em">两方并等</span>  
<span style="margin-left: 2em">句股术也</span>  
<span style="margin-left: 2em">如上甲丁弧之正弦为丁辛其矢为甲辛此两线上</span>  
<span style="margin-left: 6em">方并与甲丁上方等</span>  
<span style="margin-left: 6em">系法有一弧之正弦及其余弦而求其半</span>  
<span style="margin-left: 6em">弧之正弦</span>  
<span style="margin-left: 2em">如上甲丁弧其正弦为丁辛余弦为乙辛而求甲戊</span>  
<span style="margin-left: 2em">弧之甲己半弦其法于甲乙半径减乙辛余弦得甲</span>  
<span style="margin-left: 2em">辛矢其上方偕丁辛半弦上方并与甲丁通弦上方</span>  
<span style="margin-left: 2em">等开方得甲丁线半之得甲己为甲戊弧之正弦其</span>  
<span style="margin-left: 2em">数如上甲丁弧三十度其半弦丁辛为五〇〇〇〇</span>  
<span style="margin-left: 2em">〇〇乙辛余弦为八六六〇二五四以减全半径得</span>  
<span style="margin-left: 2em">甲辛矢一三三九七四六丁辛上方为二五〇〇〇</span>  
<span style="margin-left: 2em">〇〇〇〇〇〇〇〇〇甲辛上方为一七九四九一</span>  
<span style="margin-left: 2em">九三四四五一六并之得二六七九四九一九三四</span>  
<span style="margin-left: 2em">四五一六开方得甲丁线五一七六三六〇即甲丁</span>  
<span style="margin-left: 2em">弧三十度之弦也半之为甲己半弦得二五八八一</span>  
<span style="margin-left: 2em">九〇其弧十五度</span>  
<span style="margin-left: 1em">用前三要法即大测表大畧可作又有简法二题其用</span>  
<span style="margin-left: 2em">甚便但非恒有</span>  
<span style="margin-left: 2em">简法一　两正弦之较与六十度左右距等弧之正</span>  
<span style="margin-left: 2em">弦等<sub class="note-yuan">见本卷第二篇</sub></span>  
<span style="margin-left: 2em">解曰甲乙丙象限内有丙己小弧丙己戊丁大弧丙</span>  
<span style="margin-left: 6em">戊弧为六十度而戊己戊丁两弧等其前</span>  
<span style="margin-left: 6em">两正弦一为己辛一为丁庚其较丁癸题</span>  
<span style="margin-left: 6em">言丁癸较与己壬壬丁两正弦各等</span>  
<span style="margin-left: 2em">论曰试作一己子线则丁己子成三边等角形何也</span>  
<span style="margin-left: 2em">此形中有子丁壬壬己子两三角形此两角形等又</span>  
<span style="margin-left: 2em">何也子壬同腰而丁壬壬己两腰等则丁壬己壬两</span>  
<span style="margin-left: 2em">直角亦等而丁子子己两底亦等子丁己子己丁两</span>  
<span style="margin-left: 2em">角亦等又丙戊弧既六十度其余戊乙弧必三十度</span>  
<span style="margin-left: 2em">而乙甲戊角为三十度角甲乙庚丁既平行甲戊线</span>  
<span style="margin-left: 2em">截二线于子即内外角等而丁子戊角亦三十度戊</span>  
<span style="margin-left: 2em">子己角亦三十度是丁子己为六十度角也丁与全</span>  
<span style="margin-left: 2em">己全子三角既等两直角<sub class="note-yuan">一之三十二</sub>则共为一百八十</span>  
<span style="margin-left: 2em">度于中减全子角六十度则丁己两全角百二十度</span>  
<span style="margin-left: 2em">而此两角既等即各得六十度则此形之三角三边</span>  
<span style="margin-left: 2em">俱等夫丁己己子两线等则己癸垂线所分之丁癸</span>  
<span style="margin-left: 2em">子癸两直角亦等而己癸同腰则丁癸与癸子必等</span>  
<span style="margin-left: 2em">丁癸为丁子之半丁壬为丁己之半全线等则所分</span>  
<span style="margin-left: 2em">必等是丁癸与丁壬等与壬己亦等</span>  
<span style="margin-left: 2em">系题两弧各有其正半弦两半弦至弧之点在六十</span>  
<span style="margin-left: 2em">度之左右而距度点等则前两正半弦之较即后两</span>  
<span style="margin-left: 2em">半弦如图丙己戊弧六十度丙己弧五十度己戊弧</span>  
<span style="margin-left: 2em">十度丙己之正半弦己辛先得七千六百六十丙丁</span>  
<span style="margin-left: 2em">弧七十度丁戊弧亦十度丙丁弧之正半弦为丁庚</span>  
<span style="margin-left: 2em">先得九千三百九十六今求丁戊弧之半弦其法以</span>  
<span style="margin-left: 2em">己辛丁庚两半弦相减得丁癸较一千七百三十六</span>  
<span style="margin-left: 2em">即丁戊弧十度之丁壬半弦<sub class="note-yuan">此数半径设一万</sub></span>  
<span style="margin-left: 2em">次系有六十度左右相离弧之正弦一率又有其原</span>  
<span style="margin-left: 2em">正弦一率而求其相对之彼正弦其法有二一以大</span>  
<span style="margin-left: 2em">求小一以小求大以大求小者用大弧之正弦与相</span>  
<span style="margin-left: 2em">离弧之正弦相减其较为小弧之正弦<sub class="note-yuan">余则称余倒则称倒</sub>以</span>  
<span style="margin-left: 2em">小求大者用相离弧之半弦加小弧之半弦即大弧</span>  
<span style="margin-left: 2em">之半弦</span>  
<span style="margin-left: 2em">如上丁壬离弧之正弦即己壬与丁癸较等为一千</span>  
<span style="margin-left: 2em">七百三十六丁庚大弦为九千三百九十六相减得</span>  
<span style="margin-left: 2em">癸庚七千六六〇即己丙弧之己辛小弦反之丁癸</span>  
<span style="margin-left: 2em">较为一千七百三十六<sub class="note-yuan">即丁壬离弦</sub>以加于癸庚<sub class="note-yuan">即辛己小弦</sub></span>  
<span style="margin-left: 2em">七千六百六十得丁庚大弦九千三百九十六</span>  
<span style="margin-left: 2em">用此法于象限内先得半弦六十率用加减法即得</span>  
<span style="margin-left: 2em">其余三十率</span>  
<span style="margin-left: 2em">简法二　有两弧不等之各正弦又有其各余弦而</span>  
<span style="margin-left: 2em">求两弧<sub class="note-jiao">校：弧原作弦據文淵本改</sub>相加相减弧之各正弦其法有</span>

<span style="margin-left: 1em">根法一　各三角形之两边与其各对角两正弦比例</span>  
<span style="margin-left: 2em">等一云右边与左边若左角之弦与右角之弦</span>  
<span style="margin-left: 2em">如上甲乙丙平面三角形其甲丙两为锐角即以甲</span>  
<span style="margin-left: 4em">为心甲乙为半径作乙戊弧次作乙己垂线即</span>  
<span style="margin-left: 4em">乙戊弧之正弦亦即甲角之正弦也又以甲乙</span>  
<span style="margin-left: 4em">为度从丙截取丙庚从丙心庚界作庚辛弧又</span>  
<span style="margin-left: 4em">作垂线庚丁即庚辛弧与丙角之正弦也题言</span>  
<span style="margin-left: 2em">乙角之甲乙右边与乙丙左边若左角丙之庚丁正</span>  
<span style="margin-left: 2em">弦与右角甲之乙己正弦</span>  
<span style="margin-left: 2em">论曰乙丙己三角形有乙己庚丁两平行线即乙丙</span>  
<span style="margin-left: 2em">与乙己若庚丙与庚丁而丙庚原与甲乙等即乙丙</span>  
<span style="margin-left: 2em">与乙己若甲乙与庚丁更之即甲乙与乙丙若庚丁</span>  
<span style="margin-left: 2em">与乙己如上甲乙丙形乙为直角有丙乙丁戊两平</span>  
<span style="margin-left: 5em">行线即甲丙与丙乙若甲丁与丁戊而乙丙</span>  
<span style="margin-left: 5em">与甲丁等即甲丙与丙乙若丙乙与丁戊反</span>  
<span style="margin-left: 5em">之则丙角之丙乙右边与丙甲左边若左角</span>  
<span style="margin-left: 5em">甲之丁戊弦与右角乙之丙乙弦</span>  
<span style="margin-left: 2em">如上甲乙丙形乙为钝角其正弦丙壬而甲戊线与</span>  
<span style="margin-left: 5em">乙丙等甲角之正弦为戊己题言丙角之甲</span>

<span style="margin-left: 2em">为半弧与小弧之差又为大弧与小弧之半差次截</span>

<span style="margin-left: 2em">己辛为乙辛半弧之切线辛癸为辛丙半弧之切线</span>  
<span style="margin-left: 2em">此二线等而辛壬辛庚各为半差弧之切线亦等又</span>  
<span style="margin-left: 2em">乙丁子子丙戊两形为两正弦上三角形此两形之</span>  
<span style="margin-left: 2em">丁与戊皆直角又同底即两正弦之对角为子上两</span>  
<span style="margin-left: 2em">交角亦等<sub class="note-yuan">几何一卷十题</sub>而丁乙子子丙戊两角亦等<sub class="note-yuan">几何一卷</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">三二</sub>则两形为相似形而乙丁正弦与丙戊正弦若乙</span>  
<span style="margin-left: 2em">子与子丙<sub class="note-yuan">几何六卷四</sub>先既有乙丁丙戊两正弦之比例</span>  
<span style="margin-left: 2em">即得乙子与子丙之比例而又得乙子与子丙之较</span>
