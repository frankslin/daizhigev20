## 崇祯历书卷之三　崇祯奏疏

*崇祯三年十月十七日至崇祯四年八月初一日*

<span style="margin-left: 2em">缘起三</span>  
<span style="margin-left: 3em">崇祯三年十月十七日徐光启奏本<sub class="note-jiao">校：清刊本無此條</sub></span>  
<span style="margin-left: 3em">礼部尚书兼翰林院学士协理詹事府事督修历</span>  
<span style="margin-left: 3em">法臣徐光启谨</span>  
<span style="margin-left: 2em">奏为月食事臣于九月十九日具题前事二十三日</span>  
<span style="margin-left: 3em">奉</span>  
<span style="margin-left: 1em">圣旨这月食分秒时刻并起复方位各历推算互异卿</span>  
<span style="margin-left: 2em">至期率同监督司官及该监官生登台测候审验具</span>  
<span style="margin-left: 2em">奏该部知道钦此钦遵于今十月十六日夜</span>  
<span style="margin-left: 3em">望率同监督司官梁衍泗及该监堂属官生叶震</span>  
<span style="margin-left: 3em">春等到台测验臣用新造候时星晷一具逐时逐</span>  
<span style="margin-left: 3em">刻测候到寅正一刻九十分算外见初亏东北至</span>  
<span style="margin-left: 3em">卯正初刻七十分算外食甚约一十一分以上难</span>  
<span style="margin-left: 3em">定秒微因暗虚体大三倍于月掩月西行食甚时</span>  
<span style="margin-left: 3em">刻颇久适遇阴云遮掩以至月入地平无从考其</span>  
<span style="margin-left: 3em">巳未复光分数较臣原题月食分秒起复方位似</span>  
<span style="margin-left: 3em">不甚远至该监官生于台下就壶漏二器多寡稍</span>  
<span style="margin-left: 3em">有异同似不难较勘画一也臣钦奉</span>  
<span style="margin-left: 1em">明旨理合回</span>  
<span style="margin-left: 2em">奏为此具本谨具奏</span>  
<span style="margin-left: 1em">闻</span>  
<span style="margin-left: 3em">崇祯三年十月十七日具题二十四日奉</span>  
<span style="margin-left: 1em">圣旨考验历法全在交食览奏台官用器不同测时互</span>  
<span style="margin-left: 2em">异还着较勘画一具奏</span>  
<span style="margin-left: 6em">崇祯三年十一月二十四日徐光启题本</span>  
<span style="margin-left: 3em">礼部尚书兼翰林院学士协理詹事府事督修历</span>  
<span style="margin-left: 3em">法臣徐光启谨</span>  
<span style="margin-left: 2em">题为奉</span>  
<span style="margin-left: 1em">旨回奏事臣于十月十七日登台测候月食具本回奏</span>  
<span style="margin-left: 2em">奉</span>  
<span style="margin-left: 1em">圣旨考验历法全在交食览奏台官用器不同测时互</span>  
<span style="margin-left: 2em">异还著较勘画一具奏钦此钦遵随行督率该</span>  
<span style="margin-left: 3em">监堂属官并知历人等到台前后较勘三次设立</span>  
<span style="margin-left: 3em">表臬及用合式罗经于本台日晷简仪立运仪正</span>  
<span style="margin-left: 3em">方案上较定本地子午真线以为定时根本据法</span>  
<span style="margin-left: 3em">当制造如式日晷以定昼时造星晷以定夜时造</span>  
<span style="margin-left: 3em">正线罗经以定子午若晨昏阴雨当造如式行漏</span>  
<span style="margin-left: 3em">与该监所有铜漏比验画一以济二晷所不及但</span>  
<span style="margin-left: 3em">备办界画工力甚细今工尚未竣而较勘略定理</span>  
<span style="margin-left: 3em">合先行奏</span>  
<span style="margin-left: 1em">闻臣等窃照定时之法当议者五事一曰壶漏二曰指</span>  
<span style="margin-left: 3em">南针三曰表臬四曰仪五曰晷其一壶漏等器规</span>  
<span style="margin-left: 3em">制甚多今所用者水漏也然水有新旧滑濇则迟</span>  
<span style="margin-left: 3em">疾异漏管有时而塞有时而磷则缓急异定漏之</span>  
<span style="margin-left: 3em">初必于午正初刻此刻一误无所不误虽调品如</span>  
<span style="margin-left: 3em">法终无益也故壶漏者特以济晨昏阴雨晷仪表</span>  
<span style="margin-left: 3em">臬所不及而非定时之本所谓本者必准于天行</span>  
<span style="margin-left: 3em">则用表用仪用晷昼测日夜测星是已其二指南</span>  
<span style="margin-left: 3em">针者今术人恒用以定南北凡辨方正位皆取则</span>  
<span style="margin-left: 3em">焉然所得子午非真子午向来言阴阳者多云泊</span>  
<span style="margin-left: 3em">于丙午之间今以法考之实各处不同在</span>  
<span style="margin-left: 2em">京师则偏东五度四十分若凭以造晷则冬至午正</span>  
<span style="margin-left: 3em">先天一刻四十四分有奇夏至午正先天五十一</span>  
<span style="margin-left: 3em">分有奇然此偏东之度必造针用磁悉皆合法其</span>  
<span style="margin-left: 3em">数如此若今术人所用短针双针磁石同居之针</span>  
<span style="margin-left: 3em">杂乱无法所差度分或多或少无定数也今观象</span>  
<span style="margin-left: 3em">台有赤道日晷一座及正方案臣等以法考之其</span>  
<span style="margin-left: 3em">正方案偏东二度日晷先天半刻计在当时亦用</span>  
<span style="margin-left: 3em">罗经与表臬㕘定故差数为少若专用罗经者恐</span>  
<span style="margin-left: 3em">所差刻分多少亦无定数而大抵皆失于先天据</span>  
<span style="margin-left: 3em">此以候交食时刻即其失不尽在推步也今但用</span>  
<span style="margin-left: 3em">表臬或仪器以求子午真线或依偏针加减别造</span>  
<span style="margin-left: 3em">正线罗经以与旧晷较勘差数立见矣三曰表臬</span>  
<span style="margin-left: 3em">者即周礼匠人置槷之法识日出入之景参诸日</span>  
<span style="margin-left: 3em">中之景以正方位今法置小表于地平午正前后</span>  
<span style="margin-left: 3em">累测日景以求相等之两长景即为东西因得中</span>  
<span style="margin-left: 3em">间最短之景即为真子午其术更为简便也四曰</span>  
<span style="margin-left: 3em">仪者本台原有立运仪用以测验七政高度臣等</span>  
<span style="margin-left: 3em">即用以较定子午于午前累测日高度分至于长</span>  
<span style="margin-left: 3em">极而消则因最高之度即得最短之景此午正时</span>  
<span style="margin-left: 3em">南北真线也五曰晷者造成平面晷体依前仪器</span>  
<span style="margin-left: 3em">表臬南针三法参互考合务得子午卯酉真线因</span>  
<span style="margin-left: 3em">以法分布时刻加入节气诸线即成平面日晷若</span>  
<span style="margin-left: 3em">今时所用圆石欹晷是为赤道晷亦用所得子午</span>  
<span style="margin-left: 3em">线较定此二晷者皆可得天正时刻所谓昼测日</span>  
<span style="margin-left: 3em">也若测星之晷亦即周礼夜考极星之法然周时</span>  
<span style="margin-left: 3em">北极一星正与真北极同壤今时久密移此星去</span>  
<span style="margin-left: 3em">极三度有奇周官旧法不复可用故用重盘星晷</span>  
<span style="margin-left: 3em">上盘书时刻下盘书节气展转相加依近极二星</span>  
<span style="margin-left: 3em">用时指垂权测知天正时刻所谓夜测星也总五</span>  
<span style="margin-left: 3em">事而论之壶漏用物用其分数南针用物用其性</span>  
<span style="margin-left: 3em">情然皆非天不因非人不成惟表惟仪惟晷悉本</span>  
<span style="margin-left: 3em">天行私智谬巧无容其间故可为候时造历之准</span>  
<span style="margin-left: 3em">式也今若于准表准仪准针任用一事因之以造</span>  
<span style="margin-left: 3em">日星二晷又因二晷以较定壶漏用加减轻重之</span>  
<span style="margin-left: 3em">法令迟疾如意则天正时刻人人通知在在画一</span>  
<span style="margin-left: 3em">矣如是而交食时刻尚有后先则失在推步也然</span>  
<span style="margin-left: 3em">而推步之学其中事理有须申明奏</span>  
<span style="margin-left: 1em">闻者盖历自汉迄元一千三百五十年凡六十八改而</span>  
<span style="margin-left: 3em">后有授时之法是皆从粗入精先迷后得谓古法</span>  
<span style="margin-left: 3em">良是后来失传误改者皆谬论也自元至今又三</span>  
<span style="margin-left: 3em">百五十年略无修正并郭守敬之遗书一百余卷</span>  
<span style="margin-left: 3em">悉皆散逸徒取其仅存之粗迹为</span>  
<span style="margin-left: 1em">熙朝之大典讵是事宜而昔日台官阻挠特甚此则前</span>  
<span style="margin-left: 3em">代历家义所不敢出也近蒙</span>  
<span style="margin-left: 1em">圣明加意厘正诸臣专已成心悉已捐除而见臣等著</span>  
<span style="margin-left: 3em">述稍繁似有畏难之意不知其中有理有义有法</span>  
<span style="margin-left: 3em">有数理不明不能立法义不辨不能著数明理辨</span>  
<span style="margin-left: 3em">义推究颇难法立数著遵循甚易即所谓明理辨</span>  
<span style="margin-left: 3em">义者在今日则能者从之在他日则传之其人令</span>  
<span style="margin-left: 3em">可据为修改地耳非必在台诸臣悉皆晓畅也若</span>  
<span style="margin-left: 3em">立成诸表皆先为一定之法一成之数如旧用测</span>  
<span style="margin-left: 3em">圆术求距度一率即须展转乘除穷日之力而臣</span>  
<span style="margin-left: 3em">等翻译原文二万一千六百率又改从大统加减</span>  
<span style="margin-left: 3em">演算为三万六千率用之推步展卷即得其他诸</span>  
<span style="margin-left: 3em">法亦多类此此则今之愈繁乃后之愈简以臣等</span>  
<span style="margin-left: 3em">之甚难开诸臣之甚易何足畏哉此臣等所尝面</span>  
<span style="margin-left: 3em">谕而今以入</span>
