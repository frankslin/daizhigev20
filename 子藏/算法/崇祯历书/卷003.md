## 崇禎曆書卷之三　崇禎奏疏

*崇禎三年十月十六日至崇禎三年九月二十日*

<span style="margin-left: 2em">緣起三</span>  
<span style="margin-left: 3em">崇禎三年十月十七日徐光啓奏本<sub class="note-jiao">校：清刊本無此條</sub></span>  
<span style="margin-left: 3em">禮部尚書兼翰林院學士協理詹事府事督修曆</span>  
<span style="margin-left: 3em">法臣徐光啓謹</span>  
<span style="margin-left: 2em">奏爲月食事臣于九月十九日具題前事二十三日</span>  
<span style="margin-left: 3em">奉</span>  
<span style="margin-left: 1em">聖旨這月食分秒時刻并起復方位各曆推算互異卿</span>  
<span style="margin-left: 2em">至期率同監督司官及該監官生登臺測候審驗具</span>  
<span style="margin-left: 2em">奏該部知道欽此欽遵於今十月十六日夜</span>  
<span style="margin-left: 3em">望率同監督司官梁衍泗及該監堂屬官生葉震</span>  
<span style="margin-left: 3em">春等到臺測驗臣用新造候時星晷一具逐時逐</span>  
<span style="margin-left: 3em">刻測候到寅正一刻九十分算外見初虧東北至</span>  
<span style="margin-left: 3em">卯正初刻七十分算外食甚約一十一分以上難</span>  
<span style="margin-left: 3em">定秒微因闇虛體大三倍於月掩月西行食甚時</span>  
<span style="margin-left: 3em">刻頗久適遇陰雲遮掩以至月入地平無從考其</span>  
<span style="margin-left: 3em">巳未復光分數較臣原題月食分秒起復方位似</span>  
<span style="margin-left: 3em">不甚遠至該監官生於臺下就壺漏二器多寡稍</span>  
<span style="margin-left: 3em">有異同似不難較勘畫一也臣欽奉</span>  
<span style="margin-left: 1em">明旨理合回</span>  
<span style="margin-left: 2em">奏爲此具本謹具奏</span>  
<span style="margin-left: 1em">聞</span>  
<span style="margin-left: 3em">崇禎三年十月十七日具題二十四日奉</span>  
<span style="margin-left: 1em">聖旨考驗曆法全在交食覽奏臺官用器不同測時互</span>  
<span style="margin-left: 2em">異還着較勘畫一具奏</span>  
<span style="margin-left: 6em">崇禎三年十一月二十四日徐光啓題本</span>  
<span style="margin-left: 3em">禮部尚書兼翰林院學士協理詹事府事督修曆</span>  
<span style="margin-left: 3em">法臣徐光啓謹</span>  
<span style="margin-left: 2em">題爲奉</span>  
<span style="margin-left: 1em">旨回奏事臣於十月十七日登臺測候月食具本回奏</span>  
<span style="margin-left: 2em">奉</span>  
<span style="margin-left: 1em">聖旨考驗曆法全在交食覽奏臺官用器不同測時互</span>  
<span style="margin-left: 2em">異還著較勘畫一具奏欽此欽遵隨行督率該</span>  
<span style="margin-left: 3em">監堂屬官并知曆人等到臺前後較勘三次設立</span>  
<span style="margin-left: 3em">表臬及用合式羅經於本臺日晷簡儀立運儀正</span>  
<span style="margin-left: 3em">方案上較定本地子午真線以爲定時根本據法</span>  
<span style="margin-left: 3em">當製造如式日晷以定晝時造星晷以定夜時造</span>  
<span style="margin-left: 3em">正線羅經以定子午若晨昏陰雨當造如式行漏</span>  
<span style="margin-left: 3em">與該監所有銅漏比驗畫一以濟二晷所不及但</span>  
<span style="margin-left: 3em">備辦界畫工力甚細今工尚未竣而較勘略定理</span>  
<span style="margin-left: 3em">合先行奏</span>  
<span style="margin-left: 1em">聞臣等竊照定時之法當議者五事一曰壺漏二曰指</span>  
<span style="margin-left: 3em">南針三曰表臬四曰儀五曰晷其一壺漏等器規</span>  
<span style="margin-left: 3em">制甚多今所用者水漏也然水有新舊滑濇則遲</span>  
<span style="margin-left: 3em">疾異漏管有時而塞有時而磷則緩急異定漏之</span>  
<span style="margin-left: 3em">初必于午正初刻此刻一誤無所不誤雖調品如</span>  
<span style="margin-left: 3em">法終無益也故壺漏者特以濟晨昏陰雨晷儀表</span>  
<span style="margin-left: 3em">臬所不及而非定時之本所謂本者必準於天行</span>  
<span style="margin-left: 3em">則用表用儀用晷晝測日夜測星是已其二指南</span>  
<span style="margin-left: 3em">針者今術人恒用以定南北凡辨方正位皆取則</span>  
<span style="margin-left: 3em">焉然所得子午非真子午向來言陰陽者多云泊</span>  
<span style="margin-left: 3em">于丙午之間今以法考之實各處不同在</span>  
<span style="margin-left: 2em">京師則偏東五度四十分若憑以造晷則冬至午正</span>  
<span style="margin-left: 3em">先天一刻四十四分有奇夏至午正先天五十一</span>  
<span style="margin-left: 3em">分有奇然此偏東之度必造針用磁悉皆合法其</span>  
<span style="margin-left: 3em">數如此若今術人所用短針雙針磁石同居之針</span>  
<span style="margin-left: 3em">雜亂無法所差度分或多或少無定數也今觀象</span>  
<span style="margin-left: 3em">臺有赤道日晷一座及正方案臣等以法考之其</span>  
<span style="margin-left: 3em">正方案偏東二度日晷先天半刻計在當時亦用</span>  
<span style="margin-left: 3em">羅經與表臬㕘定故差數爲少若專用羅經者恐</span>  
<span style="margin-left: 3em">所差刻分多少亦無定數而大抵皆失于先天據</span>  
<span style="margin-left: 3em">此以候交食時刻即其失不盡在推步也今但用</span>  
<span style="margin-left: 3em">表臬或儀器以求子午真線或依偏針加減別造</span>  
<span style="margin-left: 3em">正線羅經以與舊晷較勘差數立見矣三曰表臬</span>  
<span style="margin-left: 3em">者即周禮匠人置槷之法識日出入之景參諸日</span>  
<span style="margin-left: 3em">中之景以正方位今法置小表於地平午正前後</span>  
<span style="margin-left: 3em">累測日景以求相等之兩長景即爲東西因得中</span>  
<span style="margin-left: 3em">間最短之景即爲真子午其術更爲簡便也四曰</span>  
<span style="margin-left: 3em">儀者本臺原有立運儀用以測驗七政高度臣等</span>  
<span style="margin-left: 3em">即用以較定子午於午前累測日高度分至於長</span>  
<span style="margin-left: 3em">極而消則因最高之度即得最短之景此午正時</span>  
<span style="margin-left: 3em">南北真線也五曰晷者造成平面晷體依前儀器</span>  
<span style="margin-left: 3em">表臬南針三法參互考合務得子午卯酉真線因</span>  
<span style="margin-left: 3em">以法分布時刻加入節氣諸線即成平面日晷若</span>  
<span style="margin-left: 3em">今時所用圓石欹晷是爲赤道晷亦用所得子午</span>  
<span style="margin-left: 3em">線較定此二晷者皆可得天正時刻所謂晝測日</span>  
<span style="margin-left: 3em">也若測星之晷亦即周禮夜考極星之法然周時</span>  
<span style="margin-left: 3em">北極一星正與真北極同壤今時久密移此星去</span>  
<span style="margin-left: 3em">極三度有奇周官舊法不復可用故用重盤星晷</span>  
<span style="margin-left: 3em">上盤書時刻下盤書節氣展轉相加依近極二星</span>  
<span style="margin-left: 3em">用時指垂權測知天正時刻所謂夜測星也總五</span>  
<span style="margin-left: 3em">事而論之壺漏用物用其分數南針用物用其性</span>  
<span style="margin-left: 3em">情然皆非天不因非人不成惟表惟儀惟晷悉本</span>  
<span style="margin-left: 3em">天行私智謬巧無容其間故可爲候時造曆之準</span>  
<span style="margin-left: 3em">式也今若于准表准儀准針任用一事因之以造</span>  
<span style="margin-left: 3em">日星二晷又因二晷以較定壺漏用加減輕重之</span>  
<span style="margin-left: 3em">法令遲疾如意則天正時刻人人通知在在畫一</span>  
<span style="margin-left: 3em">矣如是而交食時刻尚有後先則失在推步也然</span>  
<span style="margin-left: 3em">而推步之學其中事理有須申明奏</span>  
<span style="margin-left: 1em">聞者蓋曆自漢迄元一千三百五十年凡六十八改而</span>  
<span style="margin-left: 3em">後有授時之法是皆從粗入精先迷後得謂古法</span>  
<span style="margin-left: 3em">良是後來失傳誤改者皆謬論也自元至今又三</span>  
<span style="margin-left: 3em">百五十年略無修正并郭守敬之遺書一百餘卷</span>  
<span style="margin-left: 3em">悉皆散逸徒取其僅存之粗迹爲</span>  
<span style="margin-left: 1em">熙朝之大典詎是事宜而昔日臺官阻撓特甚此則前</span>  
<span style="margin-left: 3em">代曆家義所不敢出也近蒙</span>  
<span style="margin-left: 1em">聖明加意釐正諸臣專已成心悉已捐除而見臣等著</span>  
<span style="margin-left: 3em">述稍繁似有畏難之意不知其中有理有義有法</span>  
<span style="margin-left: 3em">有數理不明不能立法義不辨不能著數明理辨</span>  
<span style="margin-left: 3em">義推究頗難法立數著遵循甚易即所謂明理辨</span>  
<span style="margin-left: 3em">義者在今日則能者從之在他日則傳之其人令</span>  
<span style="margin-left: 3em">可據爲修改地耳非必在臺諸臣悉皆曉暢也若</span>  
<span style="margin-left: 3em">立成諸表皆先爲一定之法一成之數如舊用測</span>  
<span style="margin-left: 3em">圓術求距度一率即須展轉乘除窮日之力而臣</span>  
<span style="margin-left: 3em">等翻譯原文二萬一千六百率又改從大統加減</span>  
<span style="margin-left: 3em">演算爲三萬六千率用之推步展卷即得其他諸</span>  
<span style="margin-left: 3em">法亦多類此此則今之愈繁乃後之愈簡以臣等</span>  
<span style="margin-left: 3em">之甚難開諸臣之甚易何足畏哉此臣等所嘗面</span>  
<span style="margin-left: 3em">諭而今以入</span>  
<span style="margin-left: 1em">告庶諸臣知臣言之不欺旁觀者知曆法歴理一成俱</span>  
<span style="margin-left: 3em">成遠尋前緒下啓來兹實未易也緣係奉</span>  
<span style="margin-left: 1em">旨回奏事理除赤道晷恒是先天半刻可用原晷修改</span>  
<span style="margin-left: 3em">或臨時扣減定算平面晷可於正方案界畫其星</span>  
<span style="margin-left: 3em">晷行漏羅經待工完之日付該監臺官施用并指</span>  
<span style="margin-left: 3em">授造法用法外合應先行回奏爲此具本謹具題</span>  
<span style="margin-left: 1em">知</span>  
<span style="margin-left: 3em">崇禎三年十一月二十四日二十八日奉</span>  
<span style="margin-left: 1em">聖旨曆學甚微其理數法象必須悉心互參不可偏執</span>  
<span style="margin-left: 2em">覽奏製器測晷及指傳臺官等事具見詳審知道了</span>  
<span style="margin-left: 2em">該部知道</span>  
<span style="margin-left: 7em">崇禎三年十二月初二日徐光啓奏本</span>  
<span style="margin-left: 3em">禮部尚書兼翰林院學士協理詹事府事督修曆</span>  
<span style="margin-left: 3em">法臣徐光啓</span>  
<span style="margin-left: 2em">奏爲因病再申前</span>  
<span style="margin-left: 1em">請懇祈</span>  
<span style="margin-left: 1em">聖鑒以完</span>  
<span style="margin-left: 1em">大典事臣等近推本年十一月十八日冬至時刻用儀</span>  
<span style="margin-left: 3em">器三事累測日躔如法布算與該監原推不合而</span>  
<span style="margin-left: 3em">該監原推與近來議曆者所言又不合欲求畫一</span>  
<span style="margin-left: 3em">使人人曉暢確然無疑當於臬表二器酌就一巧</span>  
<span style="margin-left: 3em">便之法因于二十八日前往觀象臺再行備細考</span>  
<span style="margin-left: 3em">驗計畫不意偶然失足顛墜臺下致傷腰膝不能</span>  
<span style="margin-left: 3em">動履見今延醫調治據例止應註籍未宜輙以上</span>  
<span style="margin-left: 1em">聞而在臣特不得不言者爲修曆事務勢難闕人故也</span>  
<span style="margin-left: 3em">案查去年七月十一日禮部爲日食事條陳四欵</span>  
<span style="margin-left: 3em">內一欵言治曆重事須博訪遍求選擇共事庶集</span>  
<span style="margin-left: 3em">衆思以底成績則又俟督領之臣另行斟酌題</span>  
<span style="margin-left: 1em">請等因本月十四日奉</span>  
<span style="margin-left: 1em">聖旨這修改曆法四欵俱依議徐光啓見在本部著一</span>  
<span style="margin-left: 2em">切督領李之藻速與起補蚤來供事該部知道欽此</span>  
<span style="margin-left: 3em">續于本年七月二十六日臣復具</span>  
<span style="margin-left: 2em">奏爲恭承</span>  
<span style="margin-left: 1em">明命自揣無能謹陳愚見以祈</span>  
<span style="margin-left: 1em">聖明採擇事內開專門名家亦宜兼收容臣等隨時訪</span>  
<span style="margin-left: 3em">求有立法超卓陳義精當者具實奏</span>  
<span style="margin-left: 1em">聞以待</span>  
<span style="margin-left: 1em">簡用等因八月初一日奉</span>  
<span style="margin-left: 1em">聖旨這條議曆法立論簡確列欵明備修正歲差等事</span>  
<span style="margin-left: 2em">測驗推步參合諸家西法自宜兼收用人精擇毋濫</span>  
<span style="margin-left: 2em">李之藻着速催前來儀象急用工部委官督造度數</span>  
<span style="margin-left: 2em">旁通有關庶績一并分曹料理該衙門知道欽此臣</span>  
<span style="margin-left: 2em">自兹奉</span>  
<span style="margin-left: 1em">命以後料理未幾旋遭虜警<sub class="note-jiao">校：清刊本虜警改作報警</sub>輟業逾時今</span>  
<span style="margin-left: 3em">秋纔欲續成而寺臣李之藻物故目下算數測候</span>  
<span style="margin-left: 3em">謄寫員役雖不乏人而釋義演文講究潤色較勘</span>  
<span style="margin-left: 3em">試驗獨臣一身即使強健踰人尚苦茫無究竟況</span>  
<span style="margin-left: 3em">今疾困支離卧病一日則誤一日之事以<sub class="note-yuan">此再申前</sub></span>  
<span style="margin-left: 1em">請伏乞</span>  
<span style="margin-left: 1em">勅下吏禮二部商求堪用人員更簡數輩前來供事若</span>  
<span style="margin-left: 3em">使臣醫藥遂效可速于</span>  
<span style="margin-left: 1em">告成如或痊可未期亦便于承接矣臣昨具疏以較勘</span>  
<span style="margin-left: 3em">時刻回</span>  
<span style="margin-left: 2em">奏伏奉</span>  
<span style="margin-left: 1em">聖旨曆學甚微其曆數法象必須悉心互參不可偏執</span>  
<span style="margin-left: 2em">覽奏製器測晷及指傳臺官等事具見詳審知道了</span>  
<span style="margin-left: 2em">該部知道欽此仰見我</span>  
<span style="margin-left: 1em">皇上通微之</span>  
<span style="margin-left: 1em">睿慮無窮之</span>  
<span style="margin-left: 1em">教思臣自今以往敢不夙夜佩服無論一已原無特見</span>  
<span style="margin-left: 3em">不敢偏執即載籍有異同衆論有彼此亦不敢偏</span>  
<span style="margin-left: 3em">狥而惟以七政運行爲本昔元統李德芳爭言曆</span>  
<span style="margin-left: 3em">事</span>  
高皇帝曰二統皆難憑只驗七政行度交會無差者爲是  
<span style="margin-left: 3em">洋洋</span>
