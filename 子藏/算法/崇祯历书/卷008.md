## 崇禎曆書卷之八　崇禎奏疏

*崇禎七年十二月初三日至崇禎八年四月初四日*

<span style="margin-left: 2em">緣起八</span>  
<span style="margin-left: 7em">崇禎七年十二月初三日李天經題本</span>  
<span style="margin-left: 3em">督修曆法山東布政使司右參政臣李天經謹</span>  
<span style="margin-left: 2em">題爲遵</span>  
<span style="margin-left: 1em">旨恭進曆書併奏繳錢糧事該臣于十一月二十四日</span>  
<span style="margin-left: 3em">具有謹陳儀器始末等事一疏接奉</span>

<span style="margin-left: 2em">合何得因所見不符輙思引退着照舊供職該部知</span>  
<span style="margin-left: 2em">道欽此欽遵臣捧讀</span>  
<span style="margin-left: 1em">明綸不勝感激涕零臣何人斯叨此</span>

<span style="margin-left: 3em">患內惕憂危之情病勢日深豈敢假託以誑</span>  
<span style="margin-left: 1em">君父然恭承</span>  
<span style="margin-left: 1em">明命曷敢不勉結前局更圖新効以盡臣子報稱之萬</span>  
<span style="margin-left: 3em">一而後遂私請乎除稍痊即</span>

<span style="margin-left: 3em">以來詳加較閲今繕寫已完外加二卷悉照原題</span>  
<span style="margin-left: 3em">恭呈</span>  
<span style="margin-left: 1em">御覽前後五次所</span>  
<span style="margin-left: 2em">進共計成書一百三十七卷其間著定交食七政各</span>  
<span style="margin-left: 3em">有二百恒年表可爲二百年內推算之法又有太</span>  
<span style="margin-left: 3em">陽太陰永表可爲千百年後再算之根又各有曆</span>  
<span style="margin-left: 3em">指以晰諸行之理并究舊法所以差謬之原頗明</span>  
<span style="margin-left: 3em">且盡如甲戌乙亥日躔細行二冊其節氣先後晨</span>  
<span style="margin-left: 3em">昏出入異于大統舊法可見一端此書進</span>  
<span style="margin-left: 2em">呈而前局結矣乃臣以新効自期者兹蒙</span>  
<span style="margin-left: 1em">聖恩任以參證曆法又</span>  
<span style="margin-left: 1em">命臣詳稽互質以求脗合是臣未竟之業也大槩新法</span>  
<span style="margin-left: 3em">與舊法之不同所當參證者約有二十餘欵容臣</span>  
<span style="margin-left: 3em">條列奏</span>  
<span style="margin-left: 2em">奪外輔臣前後支取過户禮工三部錢糧銀八百七</span>  
<span style="margin-left: 3em">十三兩五錢皆輔臣取給各項之用比因疾劇故</span>  
<span style="margin-left: 3em">疏</span>  
<span style="margin-left: 1em">請待臣銷算臣受事之日止收冊二本錢糧毫未經手</span>

<span style="margin-left: 5em">朔望之外別有損益分一加減不足以盡之</span>  
<span style="margin-left: 6em">舊法定太陰平行一日爲十三度有奇算</span>  
<span style="margin-left: 7em">朔望別有加法減法大數爲五度有奇</span>  
<span style="margin-left: 7em">然兩弦時多寡不一此加減法不足以</span>  
<span style="margin-left: 7em">齊之即授時亦言月朔望時一日平行</span>  
<span style="margin-left: 7em">十三度有奇朔望外平行數不足似明</span>  
<span style="margin-left: 7em">其理未著其法今于加減外再用一加</span>  
<span style="margin-left: 7em">減名爲二三均數理明而數亦盡</span>  
<span style="margin-left: 5em">緯度不能定于五度時多時寡</span>  
<span style="margin-left: 6em">緯度難定五度古今曆家俱言之以交食</span>  
<span style="margin-left: 7em">分數及交泛等測定黃白二道相距約</span>  
<span style="margin-left: 7em">五度然朔望外兩道距度有損有益大</span>  
<span style="margin-left: 7em">距計五度三分度之一若一月有兩食</span>  
<span style="margin-left: 7em">其弦時用儀求距黃道度五度未能合</span>  
<span style="margin-left: 7em">天</span>  
<span style="margin-left: 5em">交行有損益分</span>  
<span style="margin-left: 6em">羅㬋計都即正交中交行度古定交行一</span>  
<span style="margin-left: 7em">日逆行三分千百年俱爲平行今細測</span>  
<span style="margin-left: 7em">之月有時在交上以平求之必不合算</span>  
<span style="margin-left: 7em">因設一加減爲交行均數</span>  
<span style="margin-left: 5em">天行無紫炁</span>  
<span style="margin-left: 6em">舊謂紫炁生于閏餘又曰紫炁爲木之餘</span>  
<span style="margin-left: 7em">氣今細考諸曜此種行度無從而得無</span>  
<span style="margin-left: 7em">象可明欲推算無數可定欲論述又無</span>  
<span style="margin-left: 7em">理可據展轉商求則知作者爲妄增後</span>  
<span style="margin-left: 7em">來爲傅會鄙俚不經無庸置辨</span>  
<span style="margin-left: 4em">交食</span>  
<span style="margin-left: 5em">日月景徑分恒不一</span>  
<span style="margin-left: 6em">日月有時行最高有時行最痺因高痺遂</span>  
<span style="margin-left: 7em">相距有遠近蓋近則見大遠則見小又</span>  
<span style="margin-left: 7em">因遠近得太陰過景有時厚或有時薄</span>  
<span style="margin-left: 7em">所以徑分不能爲一</span>  
<span style="margin-left: 5em">日食午正非中限乃以黃道九十度限爲中</span>  
<span style="margin-left: 7em">限</span>  
<span style="margin-left: 6em">南北東西差皆以視度與實度相較而得</span>  
<span style="margin-left: 7em">則日月之實度俱依黃道而視度安得</span>  
<span style="margin-left: 7em">不從黃道論其初末以求中限乎且黃</span>  
<span style="margin-left: 7em">道出地平上兩象限自有其高也亦自</span>  
<span style="margin-left: 7em">有其中也此理未明則有宜多而少宜</span>  
<span style="margin-left: 7em">少而多或宜加反減宜減反加者凡日</span>  
<span style="margin-left: 7em">食加時不得合天皆緣于此</span>  
<span style="margin-left: 5em">日食初虧復圓時刻多寡恒不一非二時折</span>  
<span style="margin-left: 7em">半之說</span>

<span style="margin-left: 7em">前後鮮有不參差者夫視差既食甚前</span>  
<span style="margin-left: 7em">後不一又安能令視行前後一乎今以</span>

<span style="margin-left: 7em">爲一也明矣</span>
