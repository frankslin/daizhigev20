<span style="margin-left: 4em">交食</span>  
<span style="margin-left: 5em">日月景径分恒不一</span>  
<span style="margin-left: 6em">日月有时行最高有时行最痺因高痺遂</span>  
<span style="margin-left: 7em">相距有远近盖近则见大远则见小又</span>  
<span style="margin-left: 7em">因远近得太阴过景有时厚或有时薄</span>  
<span style="margin-left: 7em">所以径分不能为一</span>  
<span style="margin-left: 5em">日食午正非中限乃以黄道九十度限为中</span>  
<span style="margin-left: 7em">限</span>
