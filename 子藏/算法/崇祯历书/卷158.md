<span style="margin-left: 3em">二減法</span>  
<span style="margin-left: 1em">減者一大幾何減去一小幾何餘幾何也亦謂之除以</span>  
<span style="margin-left: 1em">大數書于上應減數書于下亦零對零十對十百對百</span>  
<span style="margin-left: 1em">也次於每位對除之若除數多於原數則借前位一以</span>  
<span style="margin-left: 1em">除之蓋前位之一即本位之十也除完則得餘數</span>  
<span style="margin-left: 6em">假如有銀三十〇萬〇一百七十六兩三</span>  
<span style="margin-left: 6em">錢四分內除去二十九萬八千六百四十</span>

<span style="margin-left: 6em">二三除二存一次位上數〇下數九借前</span>

<span style="margin-left: 2em">借前一成一〇除八存二四位上數一下數六借前</span>  
<span style="margin-left: 2em">一成一一除六存五五位上數七下數四七除四存</span>  
<span style="margin-left: 2em">三六位上數六下數三六除三存三七位上數三下</span>

<span style="margin-left: 2em">借前一成一四除五存九該存一千五百三十二兩</span>  
<span style="margin-left: 2em">四錢九分</span>  
<span style="margin-left: 3em">三命分二法</span>  
<span style="margin-left: 1em">命分者一大幾何已分幾何尚餘幾何今應命此餘者</span>  
<span style="margin-left: 1em">爲幾何分之幾何也又所餘之小幾何再分得幾何今</span>  
<span style="margin-left: 1em">應命此得者爲幾何分之幾何也前解曰法數爲母餘</span>  
<span style="margin-left: 1em">數爲子如法數一六八餘數四九即命爲一百六十八</span>  
<span style="margin-left: 1em">分之四十九後解曰得數爲子得數前位爲母如得數</span>  
<span style="margin-left: 1em">一位則前位爲十得數六即命爲十分之六得數二位</span>  
<span style="margin-left: 1em">則前位爲百得數三四即命爲百分之三十四得數三</span>  
<span style="margin-left: 1em">位則前位爲千得數二八三即命爲千分之二百八十</span>  
<span style="margin-left: 1em">三得數四五位以上推此第前位定于一數十則一十</span>  
<span style="margin-left: 1em">百則一百千則一千萬則一萬<sub class="note-yuan">前一法即九章之命分法亦即幾何原本之命</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">比例法後一法即九章之小數如衡有錢分釐毫量有尺寸分釐曆有分秒微纖也</sub></span>  
<span style="margin-left: 2em">用法<sub class="note-yuan">凡四條</sub></span>  
<span style="margin-left: 3em">一乘法</span>  
<span style="margin-left: 1em">乘數有實有法先將實數依號查籌從左向右齊列其</span>  
<span style="margin-left: 1em">兩籌相並所成平行線斜方形合成一位方形內之數</span>  
<span style="margin-left: 1em">并爲一數矣次以籌之方位爲法數如法數是五則視</span>  
<span style="margin-left: 1em">兩籌第五方是九則視兩籌第九方即得數矣若法有</span>  
<span style="margin-left: 1em">二數則先查法尾所得數橫列之次查法首所得數進</span>  
<span style="margin-left: 1em">一位橫列之末用加法并之得數法有三數以上依此</span>  
<span style="margin-left: 1em">推顯</span>  
<span style="margin-left: 2em">解曰乘者陞也九九陞積之義也數有二一爲實一</span>  
<span style="margin-left: 2em">爲法可互用大畧以位數多者爲實可也用籌則如</span>  
<span style="margin-left: 2em">實數列籌自左而右次視法數依籌之同數格上橫</span>  
<span style="margin-left: 2em">取之并得商數列書之更視次法如前得次商數進</span>  
<span style="margin-left: 2em">一位書初商之下三以上倣此商畢并諸商數即乘</span>  
<span style="margin-left: 2em">得之數</span>  
<span style="margin-left: 2em">假如八十三爲實以四乘之先列八三兩籌視其第</span>  
<span style="margin-left: 2em">四格八號籌下左半斜方有三兩籌合一斜方有二</span>  
<span style="margin-left: 2em">一并作三三號籌下右半斜方有二并爲三百三十</span>  
<span style="margin-left: 2em">二也</span>  
<span style="margin-left: 2em">又如每銀一錢糴米九升五合今有銀三兩五錢問</span>  
<span style="margin-left: 10em">該米若干則以三五爲實九五</span>  
<span style="margin-left: 10em">爲法先查實數二籌齊列次視</span>  
<span style="margin-left: 10em">法尾五查二籌第五橫行內數</span>  
<span style="margin-left: 10em">是一七五另列再視法首九查</span>  
<span style="margin-left: 10em">二籌第九橫行內數有三一五</span>  
<span style="margin-left: 10em">進一位列于前得數之下併之</span>  
<span style="margin-left: 2em">得三三二五該米三石三斗二升五合</span>  
<span style="margin-left: 2em">又如有米一斗賣錢一百二十五文今有米一十八</span>  
<span style="margin-left: 2em">石三斗問該錢若干則以一八三爲實一二五爲法</span>  
<span style="margin-left: 2em">先查實數三籌齊列次視法尾五查三籌第五橫行</span>  
<span style="margin-left: 9em">內數是九一五另列次視法次二</span>  
<span style="margin-left: 9em">查三籌第二橫行內數是三六六</span>  
<span style="margin-left: 9em">進一位列于前得數之下次視法</span>  
<span style="margin-left: 9em">首一查三籌第一橫行內數是一</span>  
<span style="margin-left: 9em">八三又進一位列于前得二數之</span>  
<span style="margin-left: 9em">下併之得二二八七五該錢二萬</span>  
<span style="margin-left: 2em">二千八百七十五文</span>  
<span style="margin-left: 2em">如法數有〇則徑作一〇以當其位再查法數如前</span>  
<span style="margin-left: 2em">如六八三爲實三〇〇爲法則作二〇乃查三籌之</span>  
<span style="margin-left: 2em">第三橫行內數從二〇左進書之餘倣此<sub class="note-jiao">校：倣原訛作放今改</sub></span>  
<span style="margin-left: 3em">二除法</span>  
<span style="margin-left: 1em">除法有實有法有商先將法數依號查籌從左向右齊</span>  
<span style="margin-left: 1em">列次于諸籌從上至下查橫行內連數之等于實數或</span>  
<span style="margin-left: 1em">畧少于實數者在第幾行即是初商數如在第一行即</span>  
<span style="margin-left: 1em">得數是一在第九行即得數是九也次以查得之數減</span>  
<span style="margin-left: 1em">其實數如已盡則止知有初商未盡則知宜有再商也</span>  
<span style="margin-left: 1em">有再商者即再查橫行內數之等于存實或畧少于存</span>  
<span style="margin-left: 1em">實者在第幾行即是再商數又以查得之數減其存數</span>  
<span style="margin-left: 1em">如前又未盡則更有三商亦如上法三以上倣此若初</span>  
<span style="margin-left: 1em">得已除實數未盡乃實數次位無實則知當有〇位即</span>  
<span style="margin-left: 1em">作一〇以當次商或三位俱無則知得有二〇即又作</span>  
<span style="margin-left: 1em">一〇以當三商乃從後數查之若雖有餘數而其數小</span>  
<span style="margin-left: 1em">于法數是爲不盡法法之數用命分法</span>  
<span style="margin-left: 2em">解曰除法者分率之法也有實有法先列實次以法</span>  
<span style="margin-left: 2em">數平分之故古九章法名爲實如法而一或省曰而</span>  
<span style="margin-left: 2em">一也除法有二一歸除一商除商除者古法歸除則</span>  
<span style="margin-left: 2em">後來捷法珠算可任用之若書算籌算必獨用商除</span>  
<span style="margin-left: 2em">也用籌則先如法數列籌自左而右別列實數簡籌</span>  
<span style="margin-left: 2em">之某格與實數相合者或畧少于實數者以減實即</span>  
<span style="margin-left: 2em">初商數也若未盡即如前再商三商以上皆如之又</span>  
<span style="margin-left: 2em">未盡則以法命之</span>  
<span style="margin-left: 2em">假如列實一百〇八以三十六爲法除之簡三六兩</span>  
<span style="margin-left: 2em">籌列之視其第三格六號籌下右半斜方有八中各</span>  
<span style="margin-left: 2em">斜方有一九共十進一位成百即一百〇八除實盡</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 2em">又如有米九升五合價銀一錢今有米三石三斗二</span>  
<span style="margin-left: 2em">升五合問該銀若干以三三二五爲實九五爲法先</span>  
<span style="margin-left: 2em">以法數二籌齊列次于各行橫數內求三三二有則</span>  
<span style="margin-left: 2em">徑減實數無則取其畧少者二八五以二八五減三</span>  
<span style="margin-left: 2em">三二餘四七五爲實而此二八五數乃在第三行即</span>  
<span style="margin-left: 11em">三爲初商數次視第五行有</span>  
<span style="margin-left: 11em">四七五正與餘實相等減盡</span>  
<span style="margin-left: 11em">即五爲次商數是三五爲得</span>  
<span style="margin-left: 11em">數也該銀三兩五錢</span>  
<span style="margin-left: 11em">又如每錢三百七十四文買</span>  
<span style="margin-left: 11em">米一斗今有錢八萬七千一</span>  
<span style="margin-left: 2em">百四十二文問該米若干以八七一四二爲實三七</span>  
<span style="margin-left: 2em">四爲法先以法數三籌齊列次視各行橫數內求八</span>  
<span style="margin-left: 2em">七一無則取其畧少者七四八以七四八減八七一</span>  
<span style="margin-left: 2em">餘一二三四二爲實而此七四八乃在第二行即二</span>  
<span style="margin-left: 11em">爲初商數次視各行中無一</span>  
<span style="margin-left: 11em">二三四及畧少者惟第三行</span>  
<span style="margin-left: 11em">有一一二二以一一二二減</span>  
<span style="margin-left: 11em">一二三四餘一一二二爲實</span>  
<span style="margin-left: 11em">即三爲次商數次視第三行</span>  
<span style="margin-left: 11em">有一一二二正與餘實相等</span>  
<span style="margin-left: 11em">除盡即三爲三商數該米二</span>  
<span style="margin-left: 11em">十三石三斗</span>  
<span style="margin-left: 2em">若積數爲八七二四八尚有一〇六爲餘實再欲細</span>  
<span style="margin-left: 2em">分即用命分第一法以餘數一〇六爲子法數三七</span>  
<span style="margin-left: 2em">四爲母即命爲三百七十四分之一百〇六</span>  
<span style="margin-left: 2em">或用命分第二法于餘實一〇六後加一〇依上法</span>  
<span style="margin-left: 2em">再分之得二又加一〇再分之得八又加一〇再分</span>  
<span style="margin-left: 2em">之得三得數爲二八三凡三位即命爲一千之二百</span>  
<span style="margin-left: 2em">八十三</span>  
<span style="margin-left: 3em">三開平方法</span>  
<span style="margin-left: 1em">開平方有積數有商數商有方法有廉法隅法置積爲</span>  
<span style="margin-left: 1em">實從末位下作一點向前隔一位作一點每一點當作</span>  
<span style="margin-left: 1em">一商次視平方籌內自乘之數有與實首相等者即除</span>  
<span style="margin-left: 1em">之若無相等則取其相近之畧少者除之但實首以左</span>  
<span style="margin-left: 1em">第一點爲主若點前無位則自乘止于零數如一四九</span>  
<span style="margin-left: 1em">是也若點前有一位則自乘應有十數如十六至八十</span>  
<span style="margin-left: 1em">一是也而此乘數在第幾格則第幾數即初商數如所</span>  
<span style="margin-left: 1em">用數是九九爲三之自乘在第三格即三爲商數也若</span>  
<span style="margin-left: 1em">有二點者即以初商數倍之如一倍爲二三倍爲六也</span>  
<span style="margin-left: 1em">即查所倍之籌列于方籌之左如四倍爲八即取第八</span>  
<span style="margin-left: 1em">籌九倍爲十八即取第一第八兩籌也次視諸籌橫行</span>  
<span style="margin-left: 1em">內數之與存實相等者除之而此數在第幾格則第幾</span>  
<span style="margin-left: 1em">數即次商數如在第五格即五爲次商數也不盡以法</span>  
<span style="margin-left: 1em">命之三點以上倣此</span>  
<span style="margin-left: 2em">解曰開平方者即自乘還原也而法實相同無從置</span>  
<span style="margin-left: 2em">算故以積求形必用方廉隅三法商除之如有積一</span>  
<span style="margin-left: 2em">百商其根<sub class="note-yuan">根者一邊之數四邊皆同</sub>十即盡實此獨用方法無用</span>  
<span style="margin-left: 2em">廉隅矣若一百二十一初商十除實百餘二十一則</span>  
<span style="margin-left: 2em">倍初商方根爲廉法<sub class="note-yuan">任加于初商實一角之旁兩邊故曰廉兩廉故倍初商根</sub>次</span>  
<span style="margin-left: 2em">商一以乘廉得二十以一爲隅法實盡則百二十一</span>  
<span style="margin-left: 2em">之積開其根得十一也在籌則右行自一至九者即</span>  
<span style="margin-left: 2em">方根數也左二行即方根自乘之數自乘之數止于</span>  
<span style="margin-left: 2em">二位故隔一位作點查實下作幾點知方根當幾位</span>  
<span style="margin-left: 2em">也法先于左第一點上一位或二位爲乘數平行求</span>  
<span style="margin-left: 2em">得其根適足則已不合則用其少者餘實以待次商</span>  
<span style="margin-left: 2em">也左點或一位或二位者點在實首則乘數爲單數</span>  
<span style="margin-left: 6em">點在實首之次位則乘數爲十數也</span>  
<span style="margin-left: 6em">如上圖先以第一點求初商根爲方法乙</span>  
<span style="margin-left: 6em">爲方積也不盡爲二點之實以初商根倍</span>  
<span style="margin-left: 2em">之爲廉法甲丙之長邊也次商若干即以爲隅法丁</span>  
<span style="margin-left: 2em">方之一邊也并二廉一隅法以除實甲乙丙丁平方</span>  
<span style="margin-left: 2em">也不盡三商之商而不盡者以法命之其籌法先列</span>  
<span style="margin-left: 2em">本籌得初商次商則列廉法籌于本籌之左本籌之</span>  
<span style="margin-left: 2em">自乘數即隅積也其根隅法也次查所列籌何格中</span>  
<span style="margin-left: 2em">平行并數可當廉法之幾倍及隅方積得其根以除</span>  
<span style="margin-left: 2em">實即得設實下有二點則左一點之根爲十數右一</span>  
<span style="margin-left: 2em">點之根爲單數故廉法籌爲十數本籌數爲單數也</span>  
<span style="margin-left: 10em">三點以上倣此</span>  
<span style="margin-left: 10em">假如有積六百二十五別列爲</span>  
<span style="margin-left: 10em">實從末位五向前隔一位各作</span>  
<span style="margin-left: 10em">一點即知商二位也點在實首</span>  
<span style="margin-left: 10em">六爲單數視方籌內自乘之數</span>  
<span style="margin-left: 10em">無六其下九過實用其上四實</span>  
<span style="margin-left: 10em">之近少數也平行向右取二爲</span>  
<span style="margin-left: 9em">方法<sub class="note-yuan">即方根</sub>另列之爲初商即以四</span>  
<span style="margin-left: 9em"><sub class="note-yuan">百</sub>減六<sub class="note-yuan">百</sub>存二<sub class="note-yuan">百</sub>以并次點之實</span>  
<span style="margin-left: 9em">得二二五爲餘實次倍初商根得</span>  
<span style="margin-left: 9em">四爲廉法<sub class="note-yuan">廉有二故倍方根</sub>取四號籌列</span>  
<span style="margin-left: 9em">方籌左于列籌內并數取其合餘</span>  
<span style="margin-left: 9em">實或近少于餘實者至五格適合</span>
