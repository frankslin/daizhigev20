<span style="margin-left: 1em">曆指第十二卷　交食四</span>  
<span style="margin-left: 2em">食限第一</span>  
<span style="margin-left: 1em">食限者日月行兩道各推其經度距交若干爲有食之</span>  
<span style="margin-left: 2em">始也而日與月不同月食則太陰與地景相遇兩周</span>  
<span style="margin-left: 2em">相切以其兩視半徑較白道距黃道度人以距度推</span>  
<span style="margin-left: 2em">交周度定食限若日食則太陽與太陰相遇雖兩周</span>  
<span style="margin-left: 2em">相切其兩視半徑未可定兩道之距度爲有視差必</span>  
<span style="margin-left: 2em">以之相加而得距度故特論半徑則日食之二徑狹</span>  
<span style="margin-left: 2em">月食之二徑廣論日食之限反大於月食之限以視</span>  
<span style="margin-left: 2em">差也</span>  
<span style="margin-left: 3em">太陰食限</span>  
<span style="margin-left: 1em">表中地景半徑最大者先定四十七分太陰半徑最大</span>  
<span style="margin-left: 2em">者一十七分二十〇秒并得一度〇四分二十〇秒</span>  
<span style="margin-left: 2em">日月兩道之距在此數以內可有月食<sub class="note-yuan">可食者可不食也</sub>以</span>  
<span style="margin-left: 2em">此距度推其相值之交常得一十二度二十八分爲</span>  
<span style="margin-left: 2em">月食限推法最大距度<sub class="note-yuan">四度五十八分半</sub>與象限九十度若</span>  
<span style="margin-left: 2em">距度與交常之弧也其最小者地半徑定四十三分</span>  
<span style="margin-left: 2em">月半徑一十五分一十五秒并得五十八分一十五</span>  
<span style="margin-left: 2em">秒若距度與之等者依前法推交常度得一十一度</span>  
<span style="margin-left: 2em">一十六分此限以內月過景必有食<sub class="note-yuan">必食者無不食也</sub>也抑</span>  
<span style="margin-left: 2em">此兩者皆論實望時之食限耳若論平望其限尤寬</span>  
<span style="margin-left: 7em">如圖甲乙爲黃道甲丙當白道乙爲地</span>  
<span style="margin-left: 7em">景心丙爲太陰心月切景在丁其最大</span>  
<span style="margin-left: 7em">兩半徑爲乙丙得一度〇四分二十〇</span>  
<span style="margin-left: 7em">秒則相值之甲丙得一十二度二十八</span>  
<span style="margin-left: 2em">分爲定望食限設平望尚在前爲戊則戊平望距丙</span>  
<span style="margin-left: 2em">定望最遠者二度三十八分有奇爲丙戊弧以加甲</span>  
<span style="margin-left: 2em">丙弧得甲戊一十五度〇六分有奇爲太陰切景之</span>  
<span style="margin-left: 2em">時以其心距兩交之度西古史多祿某定實望之食</span>  
<span style="margin-left: 2em">限一十二度一十二分中望之食限一十五度一十</span>  
<span style="margin-left: 2em">二分其所定視半徑最小之食限一十〇度五十〇</span>  
<span style="margin-left: 2em">分</span>  
<span style="margin-left: 1em">何謂平望距定望最遠得二度三十八分曰太陽均度</span>  
<span style="margin-left: 2em">最大者二度〇三分一十五秒太陰均度最大者四</span>  
<span style="margin-left: 2em">度五十八分二十七秒并得七度〇一分四十二秒</span>  
<span style="margin-left: 2em">爲兩交時日月以實度相距極遠之弧也從此太陰</span>  
<span style="margin-left: 2em">逐及于日行訖七度〇二分此時間太陽又自行三</span>  
<span style="margin-left: 2em">十二分二十八秒太陰又須逐及更行三十二分此</span>  
<span style="margin-left: 2em">時間太陽又行三分弱共爲三十五分以加太陽均</span>  
<span style="margin-left: 2em">度得二度三十八分爲日月之實會望距其中望也</span>  
<span style="margin-left: 7em">如圖甲乙爲地心所出過本輪心直線</span>  
<span style="margin-left: 7em">至黃道乙指中會太陰實行在丙太陽</span>  
<span style="margin-left: 7em">實行在丁總丙丁弧七度〇二分太陰</span>  
<span style="margin-left: 7em">行至丁太陽己過丁而前又逐及之終</span>  
<span style="margin-left: 2em">合于己故丁己弧三十五分加乙丁共得乙己中實</span>  
<span style="margin-left: 2em">兩會相距二度三十八分</span>  
<span style="margin-left: 3em">太陽食限</span>  
<span style="margin-left: 1em">表中太陽之最大半徑一十五分三十〇秒太陰之最</span>  
<span style="margin-left: 2em">大半徑一十七分二十〇秒并得三十二分五十〇</span>  
<span style="margin-left: 2em">秒所謂二徑折半也以此推相值之交常爲六度四</span>  
<span style="margin-left: 2em">十〇分是太陽不論視差不分南北正居實會之食</span>  
<span style="margin-left: 2em">限也第日食不在天頂即有高庳視差太陰每偏而</span>  
<span style="margin-left: 2em">在下交會時以此差故或就近于太陽或移遠隨地</span>  
<span style="margin-left: 2em">隨時各各不同安得以實度遽定日食之限乎測太</span>  
<span style="margin-left: 2em">陰交食時最大高庳差得一度〇四分<sub class="note-yuan">因距遠五十四地半徑故</sub></span>  
<span style="margin-left: 2em">減太陽之最大高庳差三分餘一度〇一分<sub class="note-yuan">此爲太陰偏南</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">之極多者凡日食時必有一方能見其然是爲大地公共之最大差</sub>以加二徑折半得</span>  
<span style="margin-left: 2em">總視距度一度三十三分五十〇秒外此即無日食</span>  
<span style="margin-left: 2em">在其內則可食依前法求食限得兩交前後各一十</span>  
<span style="margin-left: 2em">八度五十〇分爲兩大視徑折半之限也若以小半</span>  
<span style="margin-left: 2em">徑求食限與前差度并得一度三十一分有奇推相</span>  
<span style="margin-left: 2em">值之交周度一十七度四十八分爲小視徑折半之</span>  
<span style="margin-left: 2em">日食限若日月會入此限內者日必食但非總大地</span>  
<span style="margin-left: 2em">能見必有地能見耳若以中會論食限又須加入實</span>  
<span style="margin-left: 2em">會距中會之度其最大弧三度則中會有食之限二</span>  
<span style="margin-left: 6em">十餘度如圖甲乙爲黃道甲戊爲白道太</span>  
<span style="margin-left: 6em">陰以實度在己以視度在丙太陽乙與太</span>  
<span style="margin-left: 6em">陰丙視相切于丁則己丙爲高庳差己戊</span>  
<span style="margin-left: 6em">爲東西差而丙戊爲南北差南北差之最</span>  
<span style="margin-left: 2em">大者一度〇一分以加乙丙爲總距度乙戊若乙丙</span>  
<span style="margin-left: 2em">爲大折半<sub class="note-yuan">二徑折半省曰折半</sub>推得甲戊食限一十八度五十</span>  
<span style="margin-left: 2em">〇分或以小折半乙丙加丙戊得甲戊一十七度四</span>  
<span style="margin-left: 2em">十八分設中會更在前爲辛得食限甲辛更多于甲</span>  
<span style="margin-left: 2em">戊</span>  
<span style="margin-left: 3em">求北中界日食限</span>  
<span style="margin-left: 1em">北中界者地居赤道之北南不至赤道北不至北極也</span>  
<span style="margin-left: 2em">今依南方極出地十八度北方極出地四十二度定</span>  
<span style="margin-left: 2em">日食之限則最廣者太陰距南其交常度七度三十</span>  
<span style="margin-left: 2em">一分太陰距北其交常度一十七度三十五分爲可</span>  
<span style="margin-left: 2em">食之限最狹者太陰距南交常七度距北交常一十</span>  
<span style="margin-left: 2em">六度五十三分爲必食之限其所繇廣狹者因二徑</span>  
<span style="margin-left: 2em">折半有大有小即相會時所當距度不同故所限交</span>  
<span style="margin-left: 2em">周度亦異也太陰分南北而定最大日食之限有二</span>  
<span style="margin-left: 2em">義其一論地總本界中有一方焉距北之最大者以</span>  
<span style="margin-left: 2em">十七度爲限又有一方焉距南之最大者以七度爲</span>  
<span style="margin-left: 2em">限非謂一方所見距北可得十七距南又可得七也</span>  
<span style="margin-left: 2em">其一論黃道度謂本界中有地有時太陰或南或北</span>  
<span style="margin-left: 2em">距天頂最遠則其視距度最大以加于太陰實距度</span>  
<span style="margin-left: 2em">得其最大限在北可至十七度在南可得七度亦非</span>  
<span style="margin-left: 2em">謂諸宮交會皆可得七度十七度之限也今試于本</span>  
<span style="margin-left: 2em">界中論地先論其極高四十度者又於本地論時先</span>  
<span style="margin-left: 2em">論其不甚遠於天頂者如日月交會在夏至鶉首宮</span>  
<span style="margin-left: 2em">初度設當時不會於正午其高庳差變爲南北差者</span>  
<span style="margin-left: 2em">必少而所增視距度亦少即所得者不爲其最大限</span>  
<span style="margin-left: 2em">必設實會正午月距黃道北得其高弧七十三度二</span>  
<span style="margin-left: 2em">十八分以推高庳差一十八分〇八秒全變爲太陰</span>  
<span style="margin-left: 2em">南北差依法加於二徑折半得五十〇分五十八秒</span>  
<span style="margin-left: 2em">爲黃白兩道之視距度則所值交周度得一十〇度</span>  
<span style="margin-left: 2em">爲順天府北極同高地黃道本度月距北日食之最</span>  
<span style="margin-left: 2em">大限可食也設月距南則二徑折半共三十二分五</span>  
<span style="margin-left: 2em">十〇秒反減太陰南北差一十八分〇八秒得兩道</span>  
<span style="margin-left: 2em">視距一十四分四十二秒所值交周止二度五十〇</span>  
<span style="margin-left: 2em">分爲本地本度月距南日食之大限可食也次論其</span>  
<span style="margin-left: 2em">甚遠于天頂者設日月在冬至星紀宮初度會亦正</span>  
<span style="margin-left: 2em">午其高弧二十六度三十〇分推得高庳差即南北</span>  
<span style="margin-left: 2em">差五十六分二十四秒加二徑折半得黃北兩道總</span>  
<span style="margin-left: 2em">距一度二十九分一十四秒爲月實距南所推最大</span>  
<span style="margin-left: 2em">日可食之限一十七度二十四分所以然者人目所</span>  
<span style="margin-left: 2em">見日月以兩心合會必在太陰所離視道交黃道之</span>  
<span style="margin-left: 2em">處距其兩道實交尚一十一度又本南北差減二徑</span>  
<span style="margin-left: 2em">折半得距度二十三分三十四秒相當者得四度三</span>  
<span style="margin-left: 2em">十二分爲太陰尚不及實交未過黃道南而以視差</span>  
<span style="margin-left: 2em">故人目所見則已過交出日食限之外矣如圖丙爲</span>  
<span style="margin-left: 7em">太陰丁爲太陽甲爲黃白兩道之實交</span>  
<span style="margin-left: 7em">論實距度則日月至甲宜相掩而食今</span>  
<span style="margin-left: 7em">冬至南北差甚大太陰之視行循丙乙</span>  
<span style="margin-left: 7em">視道尚在己距甲遠即己切太陽周入</span>  
<span style="margin-left: 7em">日食之限後太陽丁行黃道至乙與太</span>  
<span style="margin-left: 7em">陰視道相遇是爲視交即二曜以兩心</span>  
<span style="margin-left: 7em">合會能全食若更前至辛日月亦未及</span>  
<span style="margin-left: 2em">實交甲太陰實未過黃道南而視行則己過太陽之</span>  
<span style="margin-left: 2em">南即丙不能掩日亦不能切日不食矣可見太陰實</span>  
<span style="margin-left: 2em">距北在己爲順天府同緯地最大食限得一十七度</span>  
<span style="margin-left: 2em">有奇至辛遂出食限之外况過甲而後實距南其視</span>  
<span style="margin-left: 2em">度距太陽甚遠安得尚有食乎再于本界中論地論</span>  
<span style="margin-left: 2em">其極高一十八度者先設日月在冬至星紀宮初度</span>  
<span style="margin-left: 2em">實會在正午得高弧四十八度三十〇分高庳差全</span>  
<span style="margin-left: 2em">變爲南北差四十一分五十八秒加二徑折半總得</span>  
<span style="margin-left: 2em">兩道相距一度一十四分四十八秒外此無日食在</span>  
<span style="margin-left: 2em">其內可食相值之食限一十四度三十二分其食甚</span>  
<span style="margin-left: 2em">亦未至實交也若行至實交則太陰以視度過交而</span>  
<span style="margin-left: 2em">南四十一分五十八秒矣以較二徑折半則視距爲</span>  
<span style="margin-left: 2em">大不已出兩食限之外乎安得有食設日月會于夏</span>  
<span style="margin-left: 6em">至鶉首宮初度此在天頂北五度三十〇</span>  
<span style="margin-left: 6em">分得高弧八十四度三十〇分推南北差</span>  
<span style="margin-left: 6em">得六分〇八秒以加二徑折半得三十八</span>  
<span style="margin-left: 6em">分五十八秒爲太陰入陽曆兩道相距度</span>  
<span style="margin-left: 6em">二曜至此即以周相切推得日食限七度</span>  
<span style="margin-left: 6em">三十一分若月距北則兩半徑減南北差</span>  
<span style="margin-left: 6em">餘二十六分五十二秒僅得五度一十〇</span>  
<span style="margin-left: 2em">分爲日食限也如圖地居夏至之南目視丙月則偏</span>
