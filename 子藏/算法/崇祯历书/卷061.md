<span style="margin-left: 1em">历指第十二卷　交食四</span>  
<span style="margin-left: 2em">食限第一</span>  
<span style="margin-left: 1em">食限者日月行两道各推其经度距交若干为有食之</span>  
<span style="margin-left: 2em">始也而日与月不同月食则太阴与地景相遇两周</span>  
<span style="margin-left: 2em">相切以其两视半径较白道距黄道度人以距度推</span>  
<span style="margin-left: 2em">交周度定食限若日食则太阳与太阴相遇虽两周</span>  
<span style="margin-left: 2em">相切其两视半径未可定两道之距度为有视差必</span>  
<span style="margin-left: 2em">以之相加而得距度故特论半径则日食之二径狭</span>  
<span style="margin-left: 2em">月食之二径广论日食之限反大于月食之限以视</span>  
<span style="margin-left: 2em">差也</span>  
<span style="margin-left: 3em">太阴食限</span>  
<span style="margin-left: 1em">表中地景半径最大者先定四十七分太阴半径最大</span>  
<span style="margin-left: 2em">者一十七分二十〇秒并得一度〇四分二十〇秒</span>  
<span style="margin-left: 2em">日月两道之距在此数以内可有月食<sub class="note-yuan">可食者可不食也</sub>以</span>  
<span style="margin-left: 2em">此距度推其相值之交常得一十二度二十八分为</span>  
<span style="margin-left: 2em">月食限推法最大距度<sub class="note-yuan">四度五十八分半</sub>与象限九十度若</span>  
<span style="margin-left: 2em">距度与交常之弧也其最小者地半径定四十三分</span>  
<span style="margin-left: 2em">月半径一十五分一十五秒并得五十八分一十五</span>  
<span style="margin-left: 2em">秒若距度与之等者依前法推交常度得一十一度</span>  
<span style="margin-left: 2em">一十六分此限以内月过景必有食<sub class="note-yuan">必食者无不食也</sub>也抑</span>  
<span style="margin-left: 2em">此两者皆论实望时之食限耳若论平望其限尤宽</span>  
<span style="margin-left: 7em">如图甲乙为黄道甲丙当白道乙为地</span>  
<span style="margin-left: 7em">景心丙为太阴心月切景在丁其最大</span>  
<span style="margin-left: 7em">两半径为乙丙得一度〇四分二十〇</span>  
<span style="margin-left: 7em">秒则相值之甲丙得一十二度二十八</span>  
<span style="margin-left: 2em">分为定望食限设平望尚在前为戊则戊平望距丙</span>  
<span style="margin-left: 2em">定望最远者二度三十八分有奇为丙戊弧以加甲</span>  
<span style="margin-left: 2em">丙弧得甲戊一十五度〇六分有奇为太阴切景之</span>  
<span style="margin-left: 2em">时以其心距两交之度西古史多禄某定实望之食</span>  
<span style="margin-left: 2em">限一十二度一十二分中望之食限一十五度一十</span>  
<span style="margin-left: 2em">二分其所定视半径最小之食限一十〇度五十〇</span>  
<span style="margin-left: 2em">分</span>  
<span style="margin-left: 1em">何谓平望距定望最远得二度三十八分曰太阳均度</span>  
<span style="margin-left: 2em">最大者二度〇三分一十五秒太阴均度最大者四</span>  
<span style="margin-left: 2em">度五十八分二十七秒并得七度〇一分四十二秒</span>  
<span style="margin-left: 2em">为两交时日月以实度相距极远之弧也从此太阴</span>  
<span style="margin-left: 2em">逐及于日行讫七度〇二分此时间太阳又自行三</span>  
<span style="margin-left: 2em">十二分二十八秒太阴又须逐及更行三十二分此</span>  
<span style="margin-left: 2em">时间太阳又行三分弱共为三十五分以加太阳均</span>  
<span style="margin-left: 2em">度得二度三十八分为日月之实会望距其中望也</span>  
<span style="margin-left: 7em">如图甲乙为地心所出过本轮心直线</span>  
<span style="margin-left: 7em">至黄道乙指中会太阴实行在丙太阳</span>  
<span style="margin-left: 7em">实行在丁总丙丁弧七度〇二分太阴</span>  
<span style="margin-left: 7em">行至丁太阳己过丁而前又逐及之终</span>  
<span style="margin-left: 2em">合于己故丁己弧三十五分加乙丁共得乙己中实</span>  
<span style="margin-left: 2em">两会相距二度三十八分</span>  
<span style="margin-left: 3em">太阳食限</span>  
<span style="margin-left: 1em">表中太阳之最大半径一十五分三十〇秒太阴之最</span>  
<span style="margin-left: 2em">大半径一十七分二十〇秒并得三十二分五十〇</span>  
<span style="margin-left: 2em">秒所谓二径折半也以此推相值之交常为六度四</span>  
<span style="margin-left: 2em">十〇分是太阳不论视差不分南北正居实会之食</span>  
<span style="margin-left: 2em">限也第日食不在天顶即有高庳视差太阴每偏而</span>  
<span style="margin-left: 2em">在下交会时以此差故或就近于太阳或移远随地</span>  
<span style="margin-left: 2em">随时各各不同安得以实度遽定日食之限乎测太</span>  
<span style="margin-left: 2em">阴交食时最大高庳差得一度〇四分<sub class="note-yuan">因距远五十四地半径故</sub></span>  
<span style="margin-left: 2em">减太阳之最大高庳差三分余一度〇一分<sub class="note-yuan">此为太阴偏南</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">之极多者凡日食时必有一方能见其然是为大地公共之最大差</sub>以加二径折半得</span>  
<span style="margin-left: 2em">总视距度一度三十三分五十〇秒外此即无日食</span>  
<span style="margin-left: 2em">在其内则可食依前法求食限得两交前后各一十</span>  
<span style="margin-left: 2em">八度五十〇分为两大视径折半之限也若以小半</span>  
<span style="margin-left: 2em">径求食限与前差度并得一度三十一分有奇推相</span>  
<span style="margin-left: 2em">值之交周度一十七度四十八分为小视径折半之</span>  
<span style="margin-left: 2em">日食限若日月会入此限内者日必食但非总大地</span>  
<span style="margin-left: 2em">能见必有地能见耳若以中会论食限又须加入实</span>  
<span style="margin-left: 2em">会距中会之度其最大弧三度则中会有食之限二</span>  
<span style="margin-left: 6em">十余度如图甲乙为黄道甲戊为白道太</span>  
<span style="margin-left: 6em">阴以实度在己以视度在丙太阳乙与太</span>  
<span style="margin-left: 6em">阴丙视相切于丁则己丙为高庳差己戊</span>  
<span style="margin-left: 6em">为东西差而丙戊为南北差南北差之最</span>  
<span style="margin-left: 2em">大者一度〇一分以加乙丙为总距度乙戊若乙丙</span>  
<span style="margin-left: 2em">为大折半<sub class="note-yuan">二径折半省曰折半</sub>推得甲戊食限一十八度五十</span>  
<span style="margin-left: 2em">〇分或以小折半乙丙加丙戊得甲戊一十七度四</span>  
<span style="margin-left: 2em">十八分设中会更在前为辛得食限甲辛更多于甲</span>  
<span style="margin-left: 2em">戊</span>  
<span style="margin-left: 3em">求北中界日食限</span>  
<span style="margin-left: 1em">北中界者地居赤道之北南不至赤道北不至北极也</span>  
<span style="margin-left: 2em">今依南方极出地十八度北方极出地四十二度定</span>  
<span style="margin-left: 2em">日食之限则最广者太阴距南其交常度七度三十</span>  
<span style="margin-left: 2em">一分太阴距北其交常度一十七度三十五分为可</span>  
<span style="margin-left: 2em">食之限最狭者太阴距南交常七度距北交常一十</span>  
<span style="margin-left: 2em">六度五十三分为必食之限其所繇广狭者因二径</span>  
<span style="margin-left: 2em">折半有大有小即相会时所当距度不同故所限交</span>  
<span style="margin-left: 2em">周度亦异也太阴分南北而定最大日食之限有二</span>  
<span style="margin-left: 2em">义其一论地总本界中有一方焉距北之最大者以</span>  
<span style="margin-left: 2em">十七度为限又有一方焉距南之最大者以七度为</span>  
<span style="margin-left: 2em">限非谓一方所见距北可得十七距南又可得七也</span>  
<span style="margin-left: 2em">其一论黄道度谓本界中有地有时太阴或南或北</span>  
<span style="margin-left: 2em">距天顶最远则其视距度最大以加于太阴实距度</span>  
<span style="margin-left: 2em">得其最大限在北可至十七度在南可得七度亦非</span>  
<span style="margin-left: 2em">谓诸宫交会皆可得七度十七度之限也今试于本</span>  
<span style="margin-left: 2em">界中论地先论其极高四十度者又于本地论时先</span>  
<span style="margin-left: 2em">论其不甚远于天顶者如日月交会在夏至鹑首宫</span>  
<span style="margin-left: 2em">初度设当时不会于正午其高庳差变为南北差者</span>  
<span style="margin-left: 2em">必少而所增视距度亦少即所得者不为其最大限</span>  
<span style="margin-left: 2em">必设实会正午月距黄道北得其高弧七十三度二</span>  
<span style="margin-left: 2em">十八分以推高庳差一十八分〇八秒全变为太阴</span>  
<span style="margin-left: 2em">南北差依法加于二径折半得五十〇分五十八秒</span>  
<span style="margin-left: 2em">为黄白两道之视距度则所值交周度得一十〇度</span>  
<span style="margin-left: 2em">为顺天府北极同高地黄道本度月距北日食之最</span>  
<span style="margin-left: 2em">大限可食也设月距南则二径折半共三十二分五</span>  
<span style="margin-left: 2em">十〇秒反减太阴南北差一十八分〇八秒得两道</span>  
<span style="margin-left: 2em">视距一十四分四十二秒所值交周止二度五十〇</span>  
<span style="margin-left: 2em">分为本地本度月距南日食之大限可食也次论其</span>  
<span style="margin-left: 2em">甚远于天顶者设日月在冬至星纪宫初度会亦正</span>  
<span style="margin-left: 2em">午其高弧二十六度三十〇分推得高庳差即南北</span>  
<span style="margin-left: 2em">差五十六分二十四秒加二径折半得黄北两道总</span>  
<span style="margin-left: 2em">距一度二十九分一十四秒为月实距南所推最大</span>  
<span style="margin-left: 2em">日可食之限一十七度二十四分所以然者人目所</span>  
<span style="margin-left: 2em">见日月以两心合会必在太阴所离视道交黄道之</span>  
<span style="margin-left: 2em">处距其两道实交尚一十一度又本南北差减二径</span>  
<span style="margin-left: 2em">折半得距度二十三分三十四秒相当者得四度三</span>  
<span style="margin-left: 2em">十二分为太阴尚不及实交未过黄道南而以视差</span>  
<span style="margin-left: 2em">故人目所见则已过交出日食限之外矣如图丙为</span>  
<span style="margin-left: 7em">太阴丁为太阳甲为黄白两道之实交</span>  
<span style="margin-left: 7em">论实距度则日月至甲宜相掩而食今</span>  
<span style="margin-left: 7em">冬至南北差甚大太阴之视行循丙乙</span>  
<span style="margin-left: 7em">视道尚在己距甲远即己切太阳周入</span>  
<span style="margin-left: 7em">日食之限后太阳丁行黄道至乙与太</span>  
<span style="margin-left: 7em">阴视道相遇是为视交即二曜以两心</span>  
<span style="margin-left: 7em">合会能全食若更前至辛日月亦未及</span>  
<span style="margin-left: 2em">实交甲太阴实未过黄道南而视行则己过太阳之</span>  
<span style="margin-left: 2em">南即丙不能掩日亦不能切日不食矣可见太阴实</span>  
<span style="margin-left: 2em">距北在己为顺天府同纬地最大食限得一十七度</span>  
<span style="margin-left: 2em">有奇至辛遂出食限之外况过甲而后实距南其视</span>  
<span style="margin-left: 2em">度距太阳甚远安得尚有食乎再于本界中论地论</span>  
<span style="margin-left: 2em">其极高一十八度者先设日月在冬至星纪宫初度</span>  
<span style="margin-left: 2em">实会在正午得高弧四十八度三十〇分高庳差全</span>  
<span style="margin-left: 2em">变为南北差四十一分五十八秒加二径折半总得</span>  
<span style="margin-left: 2em">两道相距一度一十四分四十八秒外此无日食在</span>  
<span style="margin-left: 2em">其内可食相值之食限一十四度三十二分其食甚</span>  
<span style="margin-left: 2em">亦未至实交也若行至实交则太阴以视度过交而</span>  
<span style="margin-left: 2em">南四十一分五十八秒矣以较二径折半则视距为</span>  
<span style="margin-left: 2em">大不已出两食限之外乎安得有食设日月会于夏</span>

<span style="margin-left: 2em">体之全径为十二平分则最大食得二十二分五十</span>  
<span style="margin-left: 2em">四秒也如命为十平分则最大食得一十九分〇五</span>  
<span style="margin-left: 2em">秒也又此二类者皆系太阴及地景之视径虽距度</span>  
<span style="margin-left: 2em">同分而大小多寡犹多变易设距度恒为二十五分</span>

<span style="margin-left: 3em">月食起复行度</span>
