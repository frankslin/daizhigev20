## 崇禎曆書卷之二　崇禎奏疏

*崇禎二年七月二十六日至崇禎三年九月二十日*

<span style="margin-left: 2em">緣起二</span>  
<span style="margin-left: 7em">崇禎二年七月二十六日徐光啓奏本</span>  
<span style="margin-left: 3em">太子賓客禮部左侍郎兼翰林院侍讀學士臣徐</span>  
<span style="margin-left: 3em">光啓謹</span>  
<span style="margin-left: 2em">奏爲恭承</span>  
<span style="margin-left: 1em">恩命自揣無能謹陳愚見以祈</span>  
<span style="margin-left: 1em">聖明採擇事臣以庸愚備員佐禮曠官素食每抱兢慙</span>  
<span style="margin-left: 3em">頃因日食不合伏蒙</span>  
<span style="margin-left: 1em">欽允臣部所請修改曆法臣以昔年舊議厠名其間欽</span>  
<span style="margin-left: 3em">奉</span>  
<span style="margin-left: 1em">聖旨這修改曆法事宜四欵俱依議徐光啓見在本部</span>  
<span style="margin-left: 2em">着一切督領李之藻速與起補蚤來供事該部知道</span>  
<span style="margin-left: 2em">欽此欽遵臣聞</span>  
<span style="margin-left: 1em">命自</span>  
<span style="margin-left: 1em">天有如蚉負雖知才識短淺而</span>  
<span style="margin-left: 1em">君父之命所不敢辭除報名</span>  
<span style="margin-left: 2em">廷</span>  
<span style="margin-left: 1em">謝外切念曆數一家今爲絕學而臣濱海豎儒無從師</span>  
<span style="margin-left: 3em">授萬曆四十等年禮臣謬相推舉者亦爲臣能虛</span>  
<span style="margin-left: 3em">心採聽庶或因人成事以襄</span>  
<span style="margin-left: 1em">大典非謂臣能剙立矩矱自勝前人也十八年來益加</span>  
<span style="margin-left: 3em">衰老舊學遺忘勉肩重任亦率循素志廣集衆長</span>  
<span style="margin-left: 3em">冀幸得當以報</span>  
<span style="margin-left: 1em">欽命而已臣惟古來言曆者有二誤其一則元史曆議</span>  
<span style="margin-left: 3em">言考古證今日度失行者十事夫已則不合而歸</span>  
<span style="margin-left: 3em">咎于天謬之甚也其一則宋儒言天必有一定之</span>  
<span style="margin-left: 3em">數今失傳耳夫古之曆法當時則合者多矣非不</span>  
<span style="margin-left: 3em">自謂已定久而又復不合則豈有一定可拘哉臣</span>  
<span style="margin-left: 3em">所聞者天行有恆數而無齊數也有恆者如夏至</span>  
<span style="margin-left: 3em">日長冬至日短終古不易不齊者如長極漸短短</span>  
<span style="margin-left: 3em">極漸長終歲之間無一相似歲法如此他法皆然</span>  
<span style="margin-left: 3em">以至百千萬年了無相似而用法商求仍歸輳合</span>  
<span style="margin-left: 3em">遲速永短悉依期限此天地之所以爲大也今所</span>  
<span style="margin-left: 3em">求者每遇一差必尋其所以差之故每用一法必</span>  
<span style="margin-left: 3em">論其所以不差之故上推遠古下驗將來必期一</span>  
<span style="margin-left: 3em">一無爽日月交食五星凌犯必期事事密合又須</span>  
<span style="margin-left: 3em">窮原極本著爲明白簡易之說使一覽了然百世</span>  
<span style="margin-left: 3em">之後人人可以從事遇有少差因可隨時隨事依</span>  
<span style="margin-left: 3em">法修改且度數既明又可旁通衆務濟時適用此</span>  
<span style="margin-left: 3em">則臣之所志而非臣之所能故不無望於衆思羣</span>  
<span style="margin-left: 3em">力之助也謹陳急要事宜四欵分三十三條上</span>  
<span style="margin-left: 1em">御覽伏惟</span>  
<span style="margin-left: 1em">聖明裁擇施行事緒繁多有踰限制懇祈</span>  
<span style="margin-left: 1em">聖鑒臣不勝激切惶悚待</span>  
<span style="margin-left: 1em">命之至爲此具本謹具奏</span>  
<span style="margin-left: 1em">聞</span>  
<span style="margin-left: 3em">計開</span>  
<span style="margin-left: 4em">一曆法修正十事</span>  
<span style="margin-left: 5em">其一議歲差每歲東行漸長漸短之數以正</span>  
<span style="margin-left: 6em">古來百年五十年六十六年等多寡互異</span>  
<span style="margin-left: 6em">之說</span>  
<span style="margin-left: 5em">其二議歲實小餘昔多今少漸次改易及日</span>  
<span style="margin-left: 6em">景長短歲歲不同之因以定冬至以正氣</span>  
<span style="margin-left: 6em">朔</span>  
<span style="margin-left: 5em">其三每日測驗日行經度以定盈縮加減真</span>  
<span style="margin-left: 6em">率東西南北高下之差以步日躔</span>  
<span style="margin-left: 5em">其四夜測月行經緯度數以定交轉遲疾真</span>  
<span style="margin-left: 6em">率東西南北高下之差以步月離</span>  
<span style="margin-left: 5em">其五密測列宿經緯行度以定七政盈縮遲</span>  
<span style="margin-left: 6em">疾順逆違離遠近之數</span>  
<span style="margin-left: 5em">其六密測五星經緯行度以定小輪行度遲</span>  
<span style="margin-left: 6em">疾留逆伏見之數東西南北高下之差以</span>  
<span style="margin-left: 6em">推步凌犯</span>  
<span style="margin-left: 5em">其七推變黃赤道廣狹度數密測二道距度</span>  
<span style="margin-left: 6em">及月五星各道與黃道相距之度以定交</span>  
<span style="margin-left: 6em">轉</span>  
<span style="margin-left: 5em">其八議日月去交遠近及真會似會之因以</span>  
<span style="margin-left: 6em">定距午時差之真率以正交食</span>  
<span style="margin-left: 5em">其九測日行考知二極出入地度數以定周</span>  
<span style="margin-left: 6em">天緯度以齊七政因月食考知東西相距</span>  
<span style="margin-left: 6em">地輪經度以定交食時刻</span>  
<span style="margin-left: 5em">其十依唐元法隨地測驗二極出入地度數</span>  
<span style="margin-left: 6em">地輪經緯以定晝夜晨昏永短以正交食</span>  
<span style="margin-left: 6em">有無多寡先後之數</span>  
<span style="margin-left: 5em">右十事俱目前切要其餘備細條目未敢凟</span>  
<span style="margin-left: 5em">陳伏乞</span>  
<span style="margin-left: 1em">聖裁</span>  
<span style="margin-left: 4em">一修曆用人三事</span>  
<span style="margin-left: 5em">其一中外臣僚臣部所舉南冏臣李之藻已</span>  
<span style="margin-left: 6em">蒙</span>  
<span style="margin-left: 1em">錄用仍令蚤來其餘果有耑門名家亦宜兼收容臣等</span>  
<span style="margin-left: 6em">隨時訪求有立法超卓陳義精當者具實</span>  
<span style="margin-left: 6em">奏</span>  
<span style="margin-left: 1em">聞以待</span>  
<span style="margin-left: 1em">簡用</span>  
<span style="margin-left: 5em">其二用西法</span>  
高皇帝嘗得回回曆法稱爲乾方先聖之書令詞臣吳伯  
<span style="margin-left: 6em">宗等與馬沙亦黑同事翻譯至今傳用惜</span>  
<span style="margin-left: 6em">亦年遠漸差萬曆間西洋歸化陪臣<sub class="note-jiao">校：清刊本歸化陪臣改作天學遠臣</sub>利瑪竇等尤精其術四十等</span>  
<span style="margin-left: 6em">年曾經部覆推舉今其同伴龍華民鄧玉</span>  
<span style="margin-left: 6em">函二臣見居</span>  
<span style="margin-left: 1em">賜寺<sub class="note-jiao">校：清刊本寺改作宇</sub>必得其書其法方可以較正訛謬增補</span>  
<span style="margin-left: 6em">闕略蓋其術業既精積驗復久若以大統</span>  
<span style="margin-left: 6em">舊法與之會通歸一則事半而功倍矣</span>  
<span style="margin-left: 5em">其三修曆合用人員如測驗推步製造儀器</span>  
<span style="margin-left: 6em">及能書善算者臣部已經條列但目前未</span>  
<span style="margin-left: 6em">能齊集姑就見在堪任者著令効用再俟</span>  
<span style="margin-left: 6em">訪求招致有實用者半年之後聽臣部類</span>  
<span style="margin-left: 6em">齊考試各取所長不敢濫收以滋糜費考</span>  
<span style="margin-left: 6em">後在事諸人若著述論議推算簿籍造作</span>  
<span style="margin-left: 6em">儀象凡係</span>  
<span style="margin-left: 2em">進呈及見用存貯者俱冊記本人姓名使各見所長</span>  
<span style="margin-left: 6em">且在今可以上下其食他日可以差次其</span>  
<span style="margin-left: 6em">功至諸人所用廩糧本折容臣部分理司</span>  
<span style="margin-left: 6em">官酌量案呈另行具</span>  
<span style="margin-left: 2em">奏伏乞</span>  
<span style="margin-left: 1em">聖裁</span>  
<span style="margin-left: 4em">一急用儀象十事</span>  
<span style="margin-left: 5em">其一造七政象限大儀六座　俱方八尺木</span>  
<span style="margin-left: 6em">匡銅邊木架</span>  
<span style="margin-left: 5em">其二造列宿紀限大儀三座　俱方八尺木</span>  
<span style="margin-left: 6em">匡銅邊木架</span>  
<span style="margin-left: 5em">其三造平渾懸儀三架　用銅圓徑八寸厚</span>  
<span style="margin-left: 6em">四分</span>  
<span style="margin-left: 5em">其四造交食儀一具　用銅木料方二尺以</span>  
<span style="margin-left: 6em">上</span>  
<span style="margin-left: 5em">其五造列宿經緯天球儀一架　用木料油</span>  
<span style="margin-left: 6em">漆大小不拘</span>  
<span style="margin-left: 5em">其六造萬國經緯地球儀一架　用木料油</span>  
<span style="margin-left: 6em">漆大小不拘</span>  
<span style="margin-left: 5em">其七造節氣時刻平面日晷三具　用石長</span>  
<span style="margin-left: 6em">五尺以上廣三尺以上</span>  
<span style="margin-left: 5em">其八造節氣時刻轉盤星晷三具　用銅徑</span>  
<span style="margin-left: 6em">一尺厚二分</span>  
<span style="margin-left: 5em">其九造候時鍾三架　用鐵大小不拘</span>  
<span style="margin-left: 5em">其十裝修測候七政交食遠鏡三架　用銅</span>  
<span style="margin-left: 6em">鐵木料</span>  
<span style="margin-left: 5em">右諸事俱目前急用餘可接續製造者未敢</span>  
<span style="margin-left: 6em">備開其舊法須用銅者爲費不貲今兼以</span>  
<span style="margin-left: 6em">銅鐵木料成造小者全用銅鐵總計所費</span>  
<span style="margin-left: 6em">數亦不多懇祈</span>  
<span style="margin-left: 1em">勅下工部隨時應用臣部依前覆議按季類</span>  
<span style="margin-left: 2em">奏但木料止堪暫用事完仍須精銅鑄式以垂永久</span>  
<span style="margin-left: 6em">伏乞</span>  
<span style="margin-left: 1em">聖裁</span>  
<span style="margin-left: 4em">一度數旁通十事</span>  
<span style="margin-left: 5em">其一曆象既正除天文一家言災祥禍福律</span>  
<span style="margin-left: 6em">例所禁外若考求七政行度情性下合地</span>  
<span style="margin-left: 6em">宜則一切晴雨水旱可以約略豫知修救</span>  
<span style="margin-left: 6em">修備于民生財計大有利益</span>  
<span style="margin-left: 5em">其二度數既明可以測量水地一切䟽濬河</span>  
<span style="margin-left: 6em">渠築治堤岸灌溉田畝動無失策有益民</span>  
<span style="margin-left: 6em">事</span>  
<span style="margin-left: 5em">其三度數與樂律相通明于度數即能考正</span>  
<span style="margin-left: 6em">音律制造器具于修定雅樂可以相資</span>  
<span style="margin-left: 5em">其四兵家營陣器械及築治城臺池隍等皆</span>  
<span style="margin-left: 6em">須度數爲用精于其法有裨邊計</span>  
<span style="margin-left: 5em">其五算學久廢官司計會多委任胥吏錢榖</span>  
<span style="margin-left: 6em">之司關係尤大度數既明凡九章諸術皆</span>  
<span style="margin-left: 6em">有簡當捷要之法習業甚易理財之臣尤</span>  
<span style="margin-left: 6em">所亟須</span>  
<span style="margin-left: 5em">其六營建屋宇橋梁等明于度數者力省功</span>  
<span style="margin-left: 6em">倍且經度堅固千萬年不圮不壊</span>  
<span style="margin-left: 5em">其七精于度數者能造作機器力小任重及</span>  
<span style="margin-left: 6em">風水輪盤諸事以治水用水與凡一切器</span>  
<span style="margin-left: 6em">具皆有利便之法以前民用以利民生</span>  
<span style="margin-left: 5em">其八天下輿地其南北東西縱橫相距紆直</span>  
<span style="margin-left: 6em">廣袤及山海原隰高深廣遠皆可用法測</span>  
<span style="margin-left: 6em">量道里尺寸悉無謬誤</span>  
<span style="margin-left: 5em">其九醫藥之家宜審運氣曆數既明可以察</span>  
<span style="margin-left: 6em">知日月五星躔次與病體相視乖和順逆</span>  
<span style="margin-left: 6em">因而藥石針砭不致差誤大爲生民利益</span>  
<span style="margin-left: 5em">其十造作鍾漏以知時刻分秒若日月星晷</span>  
<span style="margin-left: 6em">不論公私處所南北東西欹斜坳突皆可</span>  
<span style="margin-left: 6em">安置施用使人人能分更分漏以率作興</span>  
<span style="margin-left: 6em">事屢省考成</span>  
<span style="margin-left: 5em">右十條于民事似爲關切臣聞之周髀算經</span>  
<span style="margin-left: 5em">云禹之所以治天下者句股之所繇生也蓋</span>  
<span style="margin-left: 5em">凡物有形有質莫不資于度數故耳此須接</span>  
<span style="margin-left: 5em">續講求若得同事多人亦可分曹速就伏乞</span>  
<span style="margin-left: 1em">聖裁</span>  
<span style="margin-left: 3em">崇禎二年七月二十六日本年八月初一日奉</span>  
<span style="margin-left: 1em">聖旨這條議曆法立論簡確列欵明備修正歲差等事</span>  
<span style="margin-left: 2em">測驗推步參合諸家西法自宜兼收用人精擇毋濫</span>  
<span style="margin-left: 2em">李之藻著速催前來儀象急用工部委官督造度數</span>  
<span style="margin-left: 2em">旁通有關庶繢一併分曹料理該衙門知道</span>  
<span style="margin-left: 7em">崇禎二年九月二十三日徐光啓題本</span>  
<span style="margin-left: 3em">太子賓客禮部左侍郎兼翰林院侍讀學士督修</span>  
<span style="margin-left: 3em">曆法臣徐光啓謹</span>  
<span style="margin-left: 2em">題爲欽奉</span>  
<span style="margin-left: 1em">明旨修改曆法謹開列事宜請乞</span>  
<span style="margin-left: 1em">聖裁事照得臣於本年七月十四日奉</span>  
<span style="margin-left: 1em">聖旨督領修曆事務即于次日選用知曆人并匠役等</span>  
<span style="margin-left: 3em">製造儀器原題大儀九座今因工料未敷先完三</span>  
<span style="margin-left: 3em">座畧可給用已移置本局安頓訖今月十五日祗</span>  
<span style="margin-left: 3em">領</span>  
<span style="margin-left: 1em">勅書并本部鑄給</span>  
<span style="margin-left: 1em">欽降關防隨行欽天監擇日具題奉</span>  
<span style="margin-left: 1em">旨已於本月二十二日開局訖所有合用官生人等支</span>  
<span style="margin-left: 3em">給并儀器工料謹酌量中數列欵具題請</span>  
<span style="margin-left: 1em">旨伏惟</span>  
<span style="margin-left: 1em">聖明裁定</span>  
<span style="margin-left: 1em">勅下各該衙門欽遵施行</span>  
<span style="margin-left: 3em">一支給</span>  
<span style="margin-left: 4em">一協理分理官各一員光祿寺日給酒食等項</span>  
<span style="margin-left: 5em">似應同纂修官照品支給</span>  
<span style="margin-left: 4em">一欽天監官原題選取官三員今據稱曆官七</span>  
<span style="margin-left: 5em">員藝能相等而局中又不必七員俱到合無</span>  
<span style="margin-left: 5em">日輪二員供事其二員似應照纂修館署丞</span>  
<span style="margin-left: 5em">等官事例支給</span>  
<span style="margin-left: 4em">一後有取用官員俱斟酌前例一體給與</span>  
<span style="margin-left: 4em">一西洋歸化陪臣二名萬曆間原有光祿寺下</span>  
<span style="margin-left: 5em">程廩給似應該寺酌量照舊給與</span>
