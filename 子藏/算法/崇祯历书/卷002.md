## 崇祯历书卷之二　崇祯奏疏

*崇祯二年七月二十六日至崇祯三年九月二十日*

<span style="margin-left: 2em">缘起二</span>  
<span style="margin-left: 7em">崇祯二年七月二十六日徐光启奏本</span>  
<span style="margin-left: 3em">太子宾客礼部左侍郎兼翰林院侍读学士臣徐</span>  
<span style="margin-left: 3em">光启谨</span>

<span style="margin-left: 1em">恩命自揣无能谨陈愚见以祈</span>  
<span style="margin-left: 1em">圣明采择事臣以庸愚备员佐礼旷官素食每抱兢慙</span>  
<span style="margin-left: 3em">顷因日食不合伏蒙</span>  
<span style="margin-left: 1em">钦允臣部所请修改历法臣以昔年旧议厕名其间钦</span>  
<span style="margin-left: 3em">奉</span>  
<span style="margin-left: 1em">圣旨这修改历法事宜四欵俱依议徐光启见在本部</span>  
<span style="margin-left: 2em">着一切督领李之藻速与起补蚤来供事该部知道</span>  
<span style="margin-left: 2em">钦此钦遵臣闻</span>  
<span style="margin-left: 1em">命自</span>  
<span style="margin-left: 1em">天有如蚉负虽知才识短浅而</span>  
<span style="margin-left: 1em">君父之命所不敢辞除报名</span>  
<span style="margin-left: 2em">廷</span>  
<span style="margin-left: 1em">谢外切念历数一家今为绝学而臣滨海竖儒无从师</span>  
<span style="margin-left: 3em">授万历四十等年礼臣谬相推举者亦为臣能虚</span>  
<span style="margin-left: 3em">心采听庶或因人成事以襄</span>  
<span style="margin-left: 1em">大典非谓臣能剙立矩矱自胜前人也十八年来益加</span>  
<span style="margin-left: 3em">衰老旧学遗忘勉肩重任亦率循素志广集众长</span>  
<span style="margin-left: 3em">冀幸得当以报</span>  
<span style="margin-left: 1em">钦命而已臣惟古来言历者有二误其一则元史历议</span>  
<span style="margin-left: 3em">言考古证今日度失行者十事夫已则不合而归</span>  
<span style="margin-left: 3em">咎于天谬之甚也其一则宋儒言天必有一定之</span>  
<span style="margin-left: 3em">数今失传耳夫古之历法当时则合者多矣非不</span>  
<span style="margin-left: 3em">自谓已定久而又复不合则岂有一定可拘哉臣</span>  
<span style="margin-left: 3em">所闻者天行有恒数而无齐数也有恒者如夏至</span>  
<span style="margin-left: 3em">日长冬至日短终古不易不齐者如长极渐短短</span>  
<span style="margin-left: 3em">极渐长终岁之间无一相似岁法如此他法皆然</span>  
<span style="margin-left: 3em">以至百千万年了无相似而用法商求仍归辏合</span>  
<span style="margin-left: 3em">迟速永短悉依期限此天地之所以为大也今所</span>  
<span style="margin-left: 3em">求者每遇一差必寻其所以差之故每用一法必</span>  
<span style="margin-left: 3em">论其所以不差之故上推远古下验将来必期一</span>  
<span style="margin-left: 3em">一无爽日月交食五星凌犯必期事事密合又须</span>  
<span style="margin-left: 3em">穷原极本著为明白简易之说使一览了然百世</span>  
<span style="margin-left: 3em">之后人人可以从事遇有少差因可随时随事依</span>  
<span style="margin-left: 3em">法修改且度数既明又可旁通众务济时适用此</span>  
<span style="margin-left: 3em">则臣之所志而非臣之所能故不无望于众思群</span>
