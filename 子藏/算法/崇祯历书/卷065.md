## 崇禎曆書卷之六十五　古今交食考

<span style="margin-left: 1em">古今交食考<sub class="note-jiao">校：據奎章閣本校錄</sub></span>  
<span style="margin-left: 1em">欽命山東布政使司右參政李天經督修</span>  
<span style="margin-left: 2em">極西耶穌會士湯若望　譔　大理寺評事王應遴</span>  
<span style="margin-left: 1em">　　　　　　　　　　　　　　　　　　　仝參</span>  
<span style="margin-left: 6em">龍華民　　　訪舉司曆鄔明著</span>  
<span style="margin-left: 1em">　同　會　　　　　訂</span>  
<span style="margin-left: 6em">羅雅谷　　　訪舉中書朱廷樞　校</span>  
<span style="margin-left: 1em">　<sub class="note-jiao">校：校諱作較今改清刊本署名不同錄之於左</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">古今交食考明山東布政使司右參政李天經督修</sub></span>  
<span style="margin-left: 1em">　　　　　</span>  
<span style="margin-left: 1em"><sub class="note-yuan">　　　　　　　　　　　　　　　　　　　　王應遴　孫有本　　　　湯若望　譔　　</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">修政曆法極西耶穌會士門人朱廷樞　鮑英齊　受法　　　　　　　　　　　羅雅谷訂</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">　　　　　　　　　　　　　　　　　　　　鄔明著劉蘊德</sub></span>  
<span style="margin-left: 3em">日食<sub class="note-yuan">俱從本北極出地度分考算計二十一條</sub></span>  
<span style="margin-left: 4em">書<sub class="note-jiao">校：清刊本書作書經</sub></span>  
<span style="margin-left: 1em">胤征　惟仲康肇位四海乃季秋月朔辰弗集于房</span>  
<span style="margin-left: 2em">按唐大衍曆作仲康五年癸巳歲九月庚戌朔日食</span>  
<span style="margin-left: 2em">在房二度元授時曆亦稱仲康五年癸巳九月庚戌</span>  
<span style="margin-left: 2em">朔交泛二十六日五千四百二十一分依此得太陰</span>  
<span style="margin-left: 2em">尚距交前約九度新法亦推得九度二十三分然皆</span>  
<span style="margin-left: 2em">中會時平行若視會時實行則交常度爲五宮一十</span>  
<span style="margin-left: 2em">八度一十七分因得實距一度餘在陰曆本食距加</span>  
<span style="margin-left: 2em">減時限<sub class="note-yuan">即黃平象限東</sub>甚遠必得時差多氣差反少因氣差</span>  
<span style="margin-left: 2em">止一十六分爲實距分所減餘視距四十四分乃并</span>  
<span style="margin-left: 2em">日月兩半徑得三十一分三十三秒以較視距分尚</span>  
<span style="margin-left: 2em">不及則月不能掩日而癸巳年九月庚戌朔絕無食</span>  
<span style="margin-left: 2em">又以曆年考之仲康五年無癸巳乃丙寅也癸巳去</span>  
<span style="margin-left: 2em">丙寅後二十七年就使九月朔日有食亦非書所載</span>  
<span style="margin-left: 2em">之食况本不食乎新法推得仲康時僅四年與五年</span>  
<span style="margin-left: 2em">正交與秋分近兩曜已入食限其餘年交距秋遠雖</span>  
<span style="margin-left: 2em">兩曜會合入食限內應食者有之不在季秋月朔與</span>  
<span style="margin-left: 2em">書所載無與惟四年乙丑九月壬辰朔太陽躔壽星</span>  
<span style="margin-left: 2em">一十度三十分實交周一十一宮二十七度二十分</span>  
<span style="margin-left: 2em">得太陽實距黃道南一十七分二十秒即入食限與</span>  
<span style="margin-left: 2em">秋分近但加氣差五十分三十餘秒較兩半徑并距</span>  
<span style="margin-left: 2em">度太大必不食况此乃定朔之距度而定朔在酉正</span>  
<span style="margin-left: 2em">一刻外<sub class="note-yuan">依今加減表算</sub>日入巳二刻矣若視會必須加時即</span>  
<span style="margin-left: 2em">二曜絕無視距因得食甚尚在酉正後六刻餘併無</span>  
<span style="margin-left: 2em">帶食試更西去四刻或少加時<sub class="note-yuan">不依今加減表</sub>存定朔於地</span>  
<span style="margin-left: 2em">平上且依北極出地一十八度算<sub class="note-yuan">雲南交趾等處因與二曜益近故</sub></span>  
<span style="margin-left: 2em">其定朔則在酉初一刻得視會與日入不甚遠應見</span>  
<span style="margin-left: 2em">帶食第氣差爲三十八分以加實距總得四十六分</span>  
<span style="margin-left: 2em">與二曜半徑并相較亦無食蓋繇氣差加以實距使</span>  
<span style="margin-left: 2em">太陰偏南不能掩日非獨加減時故也若五年丙寅</span>  
<span style="margin-left: 2em">季秋月丙戌朔太陽平行躔壽星初度五十一分與</span>  
<span style="margin-left: 2em">書所載之房宿合實交周爲〇宮五度二十四分查</span>  
<span style="margin-left: 2em">表得實距北二十八分而以氣差一十三分相減餘</span>  
<span style="margin-left: 2em">一十五分爲二曜半徑并所減餘一十六分三十八</span>  
<span style="margin-left: 2em">秒推得見食五分三十餘秒但依古安邑及北極出</span>  
<span style="margin-left: 2em">地三十六度用今加減表算定朔應在次日丁亥太</span>  
<span style="margin-left: 2em">陽出之前時差應減因得食甚不可見試東去一二</span>  
<span style="margin-left: 2em">時必能見食何也蓋太陰實距北得氣差使之掩日</span>  
<span style="margin-left: 2em">九州內有處可見如以二十八分查太陰視差表中</span>  
<span style="margin-left: 2em">行得上橫行高度應六十三度餘二十七度爲二曜</span>  
<span style="margin-left: 2em">距天頂度因以太陽實躔查黃道九十度表所得側</span>  
<span style="margin-left: 2em">對二十七度者乃北極出地二十五度即全見食地</span>  
<span style="margin-left: 2em">也<sub class="note-yuan">因設二曜在正九十度上絕無時差而氣差全變爲高下差即所減去前二十八分故</sub>距此</span>  
<span style="margin-left: 2em">南北內外亦應見食惟分數多寡不一耳設東來一</span>  
<span style="margin-left: 2em">時依北極出地二十五度算得氣差二分四十五秒</span>  
<span style="margin-left: 2em">爲實距所減餘二十五分四十秒即視距分與二曜</span>  
<span style="margin-left: 2em">半徑并相較餘六分應推見食二分論定朔此時二</span>  
<span style="margin-left: 2em">曜高尚有一十七度在辰初二刻<sub class="note-yuan">日出卯正前約二分</sub>雖時差</span>  
<span style="margin-left: 2em">復有所減能使視會在卯前不見食甚然可多見帶</span>  
<span style="margin-left: 2em">食至復圓而曚氣差亦畧補地半徑差使日月可早</span>  
<span style="margin-left: 2em">出總之論中土之西不能見食非太陰不甚掩太陽</span>  
<span style="margin-left: 2em">乃時差無從得算蓋時差必先求定朔定朔即依加</span>  
<span style="margin-left: 2em">減所得而加減復歸太陽本圜心去離地心故但二</span>  
<span style="margin-left: 2em">心相距古今不等<sub class="note-yuan">見日躔曆指</sub></span>  
<span style="margin-left: 2em">即加減亦異新法爲求均度止立二百恆年表者亦</span>  
<span style="margin-left: 2em">以見此後數未免畧變至求所變幾何止可及中古</span>  
<span style="margin-left: 2em">未能及上古乃書僅云仲康五年辰弗集于房此外</span>  
<span style="margin-left: 2em">不紀食于何時測于何方見食若干分儻因之退求</span>  
<span style="margin-left: 2em">二心之距依法立表自可得其食之必然况與年月</span>  
<span style="margin-left: 2em">宿度俱符者乎再帝堯時大槩春在昴秋在房仲康</span>  
<span style="margin-left: 2em">去堯未遠俱依此爲定故得日在季秋月朔遂謂辰</span>  
<span style="margin-left: 2em">弗集于房其實房漸移東是日尚居氐宿末度非真</span>  
<span style="margin-left: 2em">至于房也或因不準得時刻誤以他年且晦朔不明</span>  
<span style="margin-left: 2em">及謂太陰距遠不能掩日之光亦滋惑矣</span>  
<span style="margin-left: 3em">詩</span>  
<span style="margin-left: 1em">小雅　十月之交朔日辛卯日有食之亦孔之醜<sub class="note-yuan">大夫</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">王</sub>　<sub class="note-yuan">刺幽</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">也</sub></span>  
<span style="margin-left: 2em">案周正建子十月乃夏之八月是在周幽王六年乙</span>  
<span style="margin-left: 2em">丑歲十月辛卯朔授時推是日辰正四刻合朔交泛</span>  
<span style="margin-left: 2em">一十四日五十七刻入食限梁太史令虞鄺唐僧一</span>  
<span style="margin-left: 2em">行亦步得是日日食今以法依本地去順天府西約</span>  
<span style="margin-left: 2em">減二刻考之是日定朔己初三刻內一十分太陽實</span>  
<span style="margin-left: 2em">躔鶉尾宮〇四度三十九分算以時差得減一時三</span>  
<span style="margin-left: 2em">十六分乃得食甚在辰正初刻〇四分授時得辰正</span>  
<span style="margin-left: 2em">四刻未推地經加減故于視會時得實交周〇宮八</span>  
<span style="margin-left: 2em">度五十九分查表得實距四十六分三十六秒減氣</span>  
<span style="margin-left: 2em">差一十五分一十六秒餘太陰視距在黃道北三十</span>  
<span style="margin-left: 2em">一分二十秒與兩曜半徑并相減餘三十一秒則得</span>  
<span style="margin-left: 2em">食分止三十秒耳授時推交泛一十四日等數欲以</span>  
<span style="margin-left: 2em">正交起算則與日月不合若從中交起算則得平交</span>  
<span style="margin-left: 2em">周與新法所得去正交北畧遠雖能入食限亦不過</span>  
<span style="margin-left: 2em">此食分矣</span>  
<span style="margin-left: 3em">春秋</span>  
<span style="margin-left: 1em">襄公　二十有四年秋七月甲子朔日有食之既</span>  
<span style="margin-left: 2em">案魯春秋仍用周正七月乃夏正建寅之五月也今</span>  
<span style="margin-left: 2em">以法考之是月甲子日未正二刻定朔申初初刻〇</span>  
<span style="margin-left: 2em">八分食甚實交周〇宮〇三度二十二分二十秒實</span>  
<span style="margin-left: 2em">距度一十七分三十二秒因在黃道北減氣差一十</span>  
<span style="margin-left: 2em">六分一十二秒得視距一分二十秒應見全食且本</span>  
<span style="margin-left: 2em">月徑大于日徑掩太陽邊周有奇經稱日既政與法</span>  
<span style="margin-left: 2em">密合</span>  
<span style="margin-left: 1em">襄公　二十有七年冬十有二月乙亥朔日有食之</span>  
<span style="margin-left: 2em">傳曰十有一月乙亥朔日有食之</span>  
<span style="margin-left: 2em">案周十二月即夏十月依法推步本月不入食限且</span>  
<span style="margin-left: 2em">無乙亥朔惟十一月則夏之九月也是月新法推得</span>  
<span style="margin-left: 2em">定朔在巳初一刻一十分食甚在辰初四刻內一十</span>  
<span style="margin-left: 2em">二分實交周度五宮二十八度二十三分在陰曆實</span>  
<span style="margin-left: 2em">距分八分三十四秒與氣差一十六分五十三秒相</span>  
<span style="margin-left: 2em">減餘視距八分一十九秒減兩半徑并數查表得食</span>  
<span style="margin-left: 2em">分七分六十三秒月朔則以傳所載爲是</span>  
<span style="margin-left: 1em">漢景帝中三年甲午歲九月戊戌晦日食幾盡</span>  
<span style="margin-left: 2em">今以法考之是日定朔依本地算在午初一刻〇分</span>  
<span style="margin-left: 2em">四十六秒日實引一十一宮〇一度三十七分三十</span>  
<span style="margin-left: 2em">八秒月實引四宮一十四度四十九分四十八秒太</span>  
<span style="margin-left: 2em">陽實躔大火宮一十四度二十四分二十一秒黃平</span>  
<span style="margin-left: 2em">限在壽星宮一十三度〇七分初東西差二十二分</span>  
<span style="margin-left: 2em">四十二秒次東西差三十〇分四十八秒應減一時</span>  
<span style="margin-left: 2em">〇五分一十四秒爲巳正初刻一十〇分三十二秒</span>  
<span style="margin-left: 2em">食甚因得實交周〇宮〇九度〇八分五十八秒太</span>  
<span style="margin-left: 2em">陰實距黃道北四十七分二十四秒改視距九分二</span>  
<span style="margin-left: 2em">十四秒應食七分四十餘秒則是十月戊戌日日食</span>  
<span style="margin-left: 2em">而漢曆誤推爲晦何也</span>  
<span style="margin-left: 1em">漢成帝河平元年癸巳歲四月己亥晦日食不盡如鈎</span>  
<span style="margin-left: 2em">劉向云日蚤食時從西北虧起</span>  
<span style="margin-left: 2em">今以法考之是日乃五月己亥朔非四月晦也日實</span>  
<span style="margin-left: 2em">引六宮〇九度一十九分二十一秒月實引六宮二</span>  
<span style="margin-left: 2em">十二度一十七分三十八秒本地定朔在巳正二刻</span>  
<span style="margin-left: 2em">〇九分四十四秒太陽實躔實沈宮二十四度一十</span>  
<span style="margin-left: 2em">八分四十七秒因得初東西差一十六分五十四秒</span>  
<span style="margin-left: 2em">次東西差二十二分四十三秒爲巳初三刻〇四分</span>  
<span style="margin-left: 2em">二十一秒食甚太陰實距黃道北一十六分四十七</span>  
<span style="margin-left: 2em">秒內減氣差一十四分二十六秒爲視距二分二十</span>  
<span style="margin-left: 2em">一秒應九分半有奇所云日食不盡如鈎脗與法合</span>  
<span style="margin-left: 2em">及先一時查表得東西差三十五分二十一秒月行</span>  
<span style="margin-left: 2em">分三十二分一十六秒視行一十九分三十八秒應</span>  
<span style="margin-left: 2em">辰正初刻一十一分初虧正劉向所謂蚤食時也夫</span>  
<span style="margin-left: 2em">上下千百年而分數時刻一一不爽如此則此日之</span>  
<span style="margin-left: 2em">推步爲何如哉</span>  
<span style="margin-left: 1em">漢安帝延光四年乙丑歲三月戊午朔日食隴西酒泉</span>  
<span style="margin-left: 2em">朔方各以狀上史官不覺</span>  
<span style="margin-left: 2em">今以法考之是日定朔依本地算未正二刻〇三分</span>  
<span style="margin-left: 2em">日實引四宮一十度三十六分月實引三宮〇五度</span>  
<span style="margin-left: 2em">二十七分太陽實躔降婁二十九度〇九分初東西</span>  
<span style="margin-left: 2em">差五十二分一十二秒次東西差五十六分四十一</span>  
<span style="margin-left: 2em">秒因得加時一時五十三分食甚在申正一刻一十</span>  
<span style="margin-left: 2em">分此時實交周〇宮〇六度二十三分即太陰實距</span>  
<span style="margin-left: 2em">北三十二分五十秒氣差一十二分五十二秒因實</span>  
<span style="margin-left: 2em">距改爲視距度一十九分五十八秒應得食分三分</span>  
<span style="margin-left: 2em">八十四秒夫時在申正已非夜食可比食及三分亦</span>  
<span style="margin-left: 2em">不得藉口不救三方各以狀上而史官不覺漢之曆</span>  
<span style="margin-left: 2em">法可知矣每讀兩漢前後史誤朔爲晦至差一二日</span>  
<span style="margin-left: 2em">當食失推郡縣以聞者屢屢漢人又安得爲知曆哉</span>  
<span style="margin-left: 1em">陳宣帝太建八年即周建德五年齊後主武平七年丙</span>  
<span style="margin-left: 2em">申歲周書六月戊申朔日食齊載六月戊申朔太陽</span>  
<span style="margin-left: 2em">初虧劉孝孫言食于卯時張孟賔言食于申時鄭元</span>  
<span style="margin-left: 2em">偉董峻言食于辰時宋景業言食于巳時至日食乃</span>
