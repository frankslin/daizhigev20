<span style="margin-left: 1em">胤征　惟仲康肇位四海乃季秋月朔辰弗集于房</span>  
<span style="margin-left: 2em">按唐大衍历作仲康五年癸巳岁九月庚戌朔日食</span>  
<span style="margin-left: 2em">在房二度元授时历亦称仲康五年癸巳九月庚戌</span>  
<span style="margin-left: 2em">朔交泛二十六日五千四百二十一分依此得太阴</span>  
<span style="margin-left: 2em">尚距交前约九度新法亦推得九度二十三分然皆</span>  
<span style="margin-left: 2em">中会时平行若视会时实行则交常度为五宫一十</span>  
<span style="margin-left: 2em">八度一十七分因得实距一度余在阴历本食距加</span>  
<span style="margin-left: 2em">减时限<sub class="note-yuan">即黄平象限东</sub>甚远必得时差多气差反少因气差</span>  
<span style="margin-left: 2em">止一十六分为实距分所减余视距四十四分乃并</span>  
<span style="margin-left: 2em">日月两半径得三十一分三十三秒以较视距分尚</span>  
<span style="margin-left: 2em">不及则月不能掩日而癸巳年九月庚戌朔绝无食</span>  
<span style="margin-left: 2em">又以历年考之仲康五年无癸巳乃丙寅也癸巳去</span>  
<span style="margin-left: 2em">丙寅后二十七年就使九月朔日有食亦非书所载</span>  
<span style="margin-left: 2em">之食况本不食乎新法推得仲康时仅四年与五年</span>  
<span style="margin-left: 2em">正交与秋分近两曜已入食限其余年交距秋远虽</span>  
<span style="margin-left: 2em">两曜会合入食限内应食者有之不在季秋月朔与</span>  
<span style="margin-left: 2em">书所载无与惟四年乙丑九月壬辰朔太阳躔寿星</span>  
<span style="margin-left: 2em">一十度三十分实交周一十一宫二十七度二十分</span>  
<span style="margin-left: 2em">得太阳实距黄道南一十七分二十秒即入食限与</span>  
<span style="margin-left: 2em">秋分近但加气差五十分三十余秒较两半径并距</span>  
<span style="margin-left: 2em">度太大必不食况此乃定朔之距度而定朔在酉正</span>  
<span style="margin-left: 2em">一刻外<sub class="note-yuan">依今加减表算</sub>日入巳二刻矣若视会必须加时即</span>  
<span style="margin-left: 2em">二曜绝无视距因得食甚尚在酉正后六刻余并无</span>  
<span style="margin-left: 2em">带食试更西去四刻或少加时<sub class="note-yuan">不依今加减表</sub>存定朔于地</span>  
<span style="margin-left: 2em">平上且依北极出地一十八度算<sub class="note-yuan">云南交趾等处因与二曜益近故</sub></span>  
<span style="margin-left: 2em">其定朔则在酉初一刻得视会与日入不甚远应见</span>  
<span style="margin-left: 2em">带食第气差为三十八分以加实距总得四十六分</span>  
<span style="margin-left: 2em">与二曜半径并相较亦无食盖繇气差加以实距使</span>  
<span style="margin-left: 2em">太阴偏南不能掩日非独加减时故也若五年丙寅</span>  
<span style="margin-left: 2em">季秋月丙戌朔太阳平行躔寿星初度五十一分与</span>  
<span style="margin-left: 2em">书所载之房宿合实交周为〇宫五度二十四分查</span>  
<span style="margin-left: 2em">表得实距北二十八分而以气差一十三分相减余</span>  
<span style="margin-left: 2em">一十五分为二曜半径并所减余一十六分三十八</span>  
<span style="margin-left: 2em">秒推得见食五分三十余秒但依古安邑及北极出</span>  
<span style="margin-left: 2em">地三十六度用今加减表算定朔应在次日丁亥太</span>  
<span style="margin-left: 2em">阳出之前时差应减因得食甚不可见试东去一二</span>  
<span style="margin-left: 2em">时必能见食何也盖太阴实距北得气差使之掩日</span>  
<span style="margin-left: 2em">九州内有处可见如以二十八分查太阴视差表中</span>  
<span style="margin-left: 2em">行得上横行高度应六十三度余二十七度为二曜</span>  
<span style="margin-left: 2em">距天顶度因以太阳实躔查黄道九十度表所得侧</span>  
<span style="margin-left: 2em">对二十七度者乃北极出地二十五度即全见食地</span>  
<span style="margin-left: 2em">也<sub class="note-yuan">因设二曜在正九十度上绝无时差而气差全变为高下差即所减去前二十八分故</sub>距此</span>  
<span style="margin-left: 2em">南北内外亦应见食惟分数多寡不一耳设东来一</span>  
<span style="margin-left: 2em">时依北极出地二十五度算得气差二分四十五秒</span>  
<span style="margin-left: 2em">为实距所减余二十五分四十秒即视距分与二曜</span>  
<span style="margin-left: 2em">半径并相较余六分应推见食二分论定朔此时二</span>  
<span style="margin-left: 2em">曜高尚有一十七度在辰初二刻<sub class="note-yuan">日出卯正前约二分</sub>虽时差</span>  
<span style="margin-left: 2em">复有所减能使视会在卯前不见食甚然可多见带</span>  
<span style="margin-left: 2em">食至复圆而曚气差亦畧补地半径差使日月可早</span>  
<span style="margin-left: 2em">出总之论中土之西不能见食非太阴不甚掩太阳</span>  
<span style="margin-left: 2em">乃时差无从得算盖时差必先求定朔定朔即依加</span>  
<span style="margin-left: 2em">减所得而加减复归太阳本圜心去离地心故但二</span>

<span style="margin-left: 2em">不纪食于何时测于何方见食若干分傥因之退求</span>
