<span style="margin-left: 1em">用圭表以测日高见表度说有五题今引用之详见本</span>  
<span style="margin-left: 2em">篇</span>  
<span style="margin-left: 2em">一地球在天之中<sub class="note-yuan">云天中者在恒星天宗动之中也七政则否说见历指</sub></span>  
<span style="margin-left: 2em">二日轮随本天周动下向地平其环转皆平行故地</span>  
<span style="margin-left: 2em">体之上立表取景亦平行<sub class="note-yuan">日有最高最高冲不得为平行此之然者以测日高</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">所差甚微可置弗论耳</sub></span>  
<span style="margin-left: 2em">三地球小于日轮从日轮下视地球止<sub class="note-jiao">校：止原作上訛今改</sub>于</span>  
<span style="margin-left: 2em">一点<sub class="note-yuan">若细测细推则地与日有比例有地半径差非大圆仪测候不可得算此聊畧取景不能及此</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">说见历指</sub></span>  
<span style="margin-left: 2em">四地本圆体<sub class="note-yuan">山高海深或疑非圆不知高深甚微如一大圆径数十丈加之一芥损之毫末</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">不害为圆</sub></span>  
<span style="margin-left: 2em">五表端为地心<sub class="note-yuan">以此测恒星则可若日月五星则以地平距地心之半径为差测七政本</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">天距地之度分安得弃而不用乎特所差甚微此姑不用可耳</sub></span>  
<span style="margin-left: 2em">分表用全数或百分或千分欲得其度分数从八线</span>  
<span style="margin-left: 2em">表取之</span>  
<span style="margin-left: 2em">造表有二法一为直表以取正景表直则为平圭一</span>  
<span style="margin-left: 2em">为横表以取倒景表横则为立圭其法畧同</span>  
<span style="margin-left: 2em">凡圭与表必相与为直角直角者从表末施垂线系</span>  
<span style="margin-left: 2em">以末锐之权下至表面所切圭面之一点即以起算</span>  
<span style="margin-left: 2em">是直角也<sub class="note-yuan">取景以表末为主不论表之体势</sub>圭欲极平立圭欲极直</span>  
<span style="margin-left: 2em">平圭者或为渠以水准之或为准平之器以定之立</span>  
<span style="margin-left: 2em">圭则以垂权正之分圭之度即用分表之度圭之长</span>  
<span style="margin-left: 2em">倍表极愈下表当加长量作之</span>  
<span style="margin-left: 2em">日升表前即表后得景则表圭日光成三角形表为</span>  
<span style="margin-left: 2em">股圭为句日光为弦表为半径全数圭为切线日光</span>  
<span style="margin-left: 2em">为割线<sub class="note-yuan">见本书一卷论直角形法</sub>查八线表切线数得度分即日</span>  
<span style="margin-left: 2em">躔天顶度分以减象限得日高度分</span>  
<span style="margin-left: 2em">按元史言表短则分秒难别表长则景虚而淡又以</span>  
<span style="margin-left: 2em">表端测晷所得者日体上边之景实非中景郭守敬</span>  
<span style="margin-left: 2em">辈创为景符今台官遵用之郭氏此法既得实景复</span>  
<span style="margin-left: 2em">得中景可谓思致玄通度越前人矣其制以铜叶博</span>  
<span style="margin-left: 2em">二寸长加博之二中穿一窍若针芥然以方閵为跌</span>  
<span style="margin-left: 2em">一端设为机轴令可开阖搘以一端使其势斜倚北</span>  
<span style="margin-left: 2em">高南下往来迁就于虚景之中窍达日光仅如米许</span>  
<span style="margin-left: 2em">隐然见横梁于中令台官以方木代铜便于旋转以</span>  
<span style="margin-left: 2em">隙缝代圆窍易于得景其理则同</span>  
<span style="margin-left: 2em">或问景符之得实景则从隙孔透光至于圭面不至</span>  
<span style="margin-left: 2em">散越其理甚明矣若用景符而得中景其理谓何曰</span>  
<span style="margin-left: 2em">此属度数家之视学也具有本论今畧借五题解之</span>  
<span style="margin-left: 2em">一曰有光之体自发光必以直线射光至所照之物</span>  
<span style="margin-left: 2em">二曰有光之多体同照光复者必深而各体之本光</span>  
<span style="margin-left: 2em">不乱</span>  
<span style="margin-left: 2em">三曰有大光体中有暗体分光体为二即一光体为</span>  
<span style="margin-left: 2em">有光之两体</span>  
<span style="margin-left: 2em">四曰光体射光过小圆孔若所照不远则光仍如本</span>  
<span style="margin-left: 2em">光体之形</span>  
<span style="margin-left: 2em">五曰两光体各射光过小孔反照之上体之光在下</span>  
<span style="margin-left: 2em">下体之光在上右在左左在右</span>  
<span style="margin-left: 2em">用横梁暗体也分日轮为上下二分即成两光体两</span>  
<span style="margin-left: 2em">之两光过隙则日上分之光在下下分之光在上横</span>  
<span style="margin-left: 2em">梁在上下之间实得中景塔影倒垂义同于此</span>  
<span style="margin-left: 2em">若不用梁用表末而欲得中景即定用郭氏旧式用</span>  
<span style="margin-left: 2em">圆孔迁就于虚景之中令见半圈之光此半光者弦</span>  
<span style="margin-left: 2em">必在下弧必在上而其弦则表末之景也盖日轮半</span>  
<span style="margin-left: 2em">在表末之上半在表末之下而上下相易故</span>
