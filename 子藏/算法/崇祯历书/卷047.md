<span style="margin-left: 2em">用法　此儀之用有二一以測日月星之高度距度</span>  
<span style="margin-left: 2em">曆學所用一以測高深廣遠地學所用<sub class="note-yuan">測地法畧見第三卷增題</sub></span>  
<span style="margin-left: 2em">今所解者測天之用法也</span>

<span style="margin-left: 2em">其首貫衡于衡管之中左右出等旋螺固之權繩取</span>

<span style="margin-left: 2em">度分即日月之距天頂度分以減象限得地平上高</span>  
<span style="margin-left: 2em">度分</span>  
<span style="margin-left: 2em">論曰如圖衡之甲端爲心半衡甲乙之百分爲半徑</span>  
<span style="margin-left: 2em">乙丁幹四百爲切線甲乙既爲橫表則甲端之景至</span>  
<span style="margin-left: 9em">幹面爲戊倒景也此戊景所得實</span>  
<span style="margin-left: 9em">日體下邊辛上之景謂之視景若</span>  
<span style="margin-left: 9em">日心庚所出景當從甲至己爲正</span>  
<span style="margin-left: 9em">景其較爲日體之半徑<sub class="note-yuan">日體約三十分半之</sub></span>  
<span style="margin-left: 9em"><sub class="note-yuan">約十五分</sub>則所得距天頂之數應減十</span>  
<span style="margin-left: 9em">五分何者爲庚之距頂近于辛也</span>  
<span style="margin-left: 9em">所得地平高度應加十五分何者</span>  
<span style="margin-left: 9em">庚之距地遠于辛也如是爲所求</span>  
<span style="margin-left: 9em">之正度分也若用壬癸正表則寅</span>

<span style="margin-left: 2em">而日心庚所出正景爲丑則所得距天頂之度應加</span>

<span style="margin-left: 2em">者即古之窺管窺簫也管孔大即測驗未真今欲造</span>  
<span style="margin-left: 2em">一管其孔僅大于黍米或小于芥子長數尺欲以之</span>  
<span style="margin-left: 2em">從上照而得日景以之從下覷而見星體則無法可</span>  
<span style="margin-left: 2em">作故用窺衡焉測日之衡長與儀等廣與定度平分</span>  
<span style="margin-left: 2em">其廣去其半而不盡其一端所不盡者其長與廣之</span>  
<span style="margin-left: 2em">元度等是爲衡首衡首之制剡爲圓形形之心是爲</span>  
<span style="margin-left: 2em">衡之心亦即爲儀之心從心出線至于衡之末依半</span>  
<span style="margin-left: 2em">衡之邊作一直線名曰指線近衡之兩端各立一銅</span>  
<span style="margin-left: 6em">版其形長方廣四則高六可也是名窺表</span>  
<span style="margin-left: 6em">立表與衡之平面爲直角表之兩面各取</span>  
<span style="margin-left: 6em">中作指線之垂線名曰心線兩心線之上</span>  
<span style="margin-left: 6em">去衡面等各作一點是爲表心表之近衡</span>  
<span style="margin-left: 6em">心者曰上表上表從心作圓孔最大者無</span>

<span style="margin-left: 5em">轉儀及衡左右下上之必合乃止次視指線</span>  
<span style="margin-left: 2em">之末所當度分即所求之度分</span>

<span style="margin-left: 1em">一分法　凡平圓面從心出四線四平分之每分爲一</span>  
<span style="margin-left: 2em">象限分度者或以全或以一象限其分法有二一舊</span>  
<span style="margin-left: 2em">法一新法舊法用象限平面直角爲心弧邊爲界自</span>  
<span style="margin-left: 2em">外而內作四十五距等平行圈外一圈分九十次內</span>  
<span style="margin-left: 2em">二分八十九次三分八十八次四分八十七如是遞</span>  
<span style="margin-left: 2em">減一分以至四十五弧爲四十五分每弧之端識以</span>  
<span style="margin-left: 2em">命弧之數每弧之分遇十遇五各識之加窺衡加權</span>  
<span style="margin-left: 2em">線以架承之</span>  
<span style="margin-left: 2em">用法凡測日月星之高用權線或窺衡之指線必切</span>  
<span style="margin-left: 2em">一弧之一分　若切外一圈之一分因弧爲九十度</span>  
<span style="margin-left: 2em">即所切爲所求正度　若切向內某弧之一分則以</span>  
<span style="margin-left: 2em">本弧之若干分爲一率以所截某分爲二率以九十</span>  
<span style="margin-left: 2em">爲三率推第四率得度不盡以六十乘之以本弧分</span>  
<span style="margin-left: 2em">數除之得分又不盡又如前乘之除之得秒又不盡</span>  
<span style="margin-left: 2em">又如前乘之除之得微</span>  
<span style="margin-left: 2em">假如截第二十圈之四十分本弧之分數爲七十則</span>  
<span style="margin-left: 2em">七十與四十若九十與某數算得五十一不盡三十</span>  
<span style="margin-left: 3em">六十乘之七十除之得二十五不盡五十〇再乘</span>  
<span style="margin-left: 2em">再除得四十二不盡六十　再乘再除得五十一總</span>  
<span style="margin-left: 2em">之得五十一度二十五分四十二秒五十一微　如</span>  
<span style="margin-left: 2em">取數欲密如前再乘除之欲簡視所餘滿半收爲一</span>  
<span style="margin-left: 2em">不滿去之</span>

<span style="margin-left: 2em">所至悉得度分秒微可謂巧思絕人矣然而分圈己</span>  
<span style="margin-left: 2em">繁悉分諸圈則又繁每求一率當乘除數四則又繁</span>  
<span style="margin-left: 2em">垂線所至交于多分遇有二三疑似亦難辨決且儀</span>  
<span style="margin-left: 2em">面平實體質過重以彼材物造爲空中之儀豈不倍</span>  
<span style="margin-left: 2em">大故近來名史改用後法焉</span>

<span style="margin-left: 2em">弧不容分矣今以直角爲心邊爲界作弧次內復作</span>  
<span style="margin-left: 2em">一弧兩弧相距爲五十分半徑之一約每兩度兩弧</span>
