<span style="margin-left: 1em">宗動篇第三</span>  
<span style="margin-left: 1em">總論二條　論宗動有二端一言本天之點與線二言</span>  
<span style="margin-left: 2em">本天之運動</span>  
<span style="margin-left: 2em">三曜皆有兩種運動宜以兩物測之猶布帛之用尺</span>  
<span style="margin-left: 2em">度也七政恆星皆一日一周自東而西則以赤道爲</span>  
<span style="margin-left: 2em">其尺度又各有遲速本行自西而東則以黃道爲其</span>  
<span style="margin-left: 2em">尺度凡動天皆宗于宗動天故黃赤二道皆繫焉<sub class="note-yuan">三曜</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">者日月星也</sub></span>  
<span style="margin-left: 1em">論本天之點與線　凡三章</span>  
<span style="margin-left: 1em">論赤道七條　赤道于諸大圈爲最尊其義有三不知</span>  
<span style="margin-left: 2em">赤道則諸大圈無從可解一也赤道之理特爲易明</span>  
<span style="margin-left: 2em">二也一日一周乃七政恆星之公運動赤道主之三</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 2em">其兩極即大圜之兩極何者爲本道與天元赤道相</span>  
<span style="margin-left: 2em">合爲一線動靜雖異終古不離也</span>  
<span style="margin-left: 2em">大圜之心中圈之心赤道之心地之心同是一點爲</span>  
<span style="margin-left: 2em">赤道與大圈中圈同爲大圈故也</span>  
<span style="margin-left: 2em">赤道既爲大圈其分數亦有半圈有象限有三百六</span>  
<span style="margin-left: 2em">十度及分秒其算數則從一至三百六十與黃道地</span>  
<span style="margin-left: 2em">平異黃道分十二宫各以三十爲限地平分四象各</span>  
<span style="margin-left: 2em">以九十爲限故赤道亦有過極經圈一百八十爲用</span>  
<span style="margin-left: 2em">甚大其左右旁各有距等侣圈<sub class="note-yuan">即緯圈</sub>每至極各九十</span>  
<span style="margin-left: 2em">不甚爲用爲與天元緯度一一同線故</span>  
<span style="margin-left: 2em">其用則以赤道之經緯度測各點之所在命爲各點</span>  
<span style="margin-left: 2em">赤道經緯度</span>  
<span style="margin-left: 5em">如上圖赤道上任設甲點從赤道初點乙數</span>  
<span style="margin-left: 5em">至甲爲幾度分即甲點之赤道經度分也爲</span>  
<span style="margin-left: 5em">在赤道上故無緯度</span>  
<span style="margin-left: 5em">若所設甲點在赤道外則於過極大圈數甲</span>  
<span style="margin-left: 5em">點至赤道交即定赤道初點至設點之經度</span>  
<span style="margin-left: 5em">爲六甲點至赤道即所容之緯度爲五</span>  
<span style="margin-left: 2em">凡分南北大分獨六合之內<sub class="note-yuan">即大圜也</sub>及日以赤道分之</span>  
<span style="margin-left: 2em">他則否</span>  
<span style="margin-left: 1em">論黃道十條　黃道亦大圈也兩交於赤道兩交之間</span>  
<span style="margin-left: 2em">最遠於赤道者二十三度有奇</span>  
<span style="margin-left: 5em">黃道之兩極去赤道兩極亦二十三度有奇</span>  
<span style="margin-left: 5em">與二道相離最遠之數同也</span>  
<span style="margin-left: 5em">如上圖甲至丙爲黃赤二道相離最遠之二</span>  
<span style="margin-left: 2em">十三度有奇則庚至戊亦黃赤二極相離之二十三</span>  
<span style="margin-left: 2em">度有奇</span>  
<span style="margin-left: 2em">黃道分數其四象限三百六十度與赤道同又十二</span>  
<span style="margin-left: 2em">分之爲宫二十四分之爲節氣七十二分之爲候與</span>  
<span style="margin-left: 2em">赤道異十二宫曰玄枵娵訾降婁大梁實沈鶉首鶉</span>  
<span style="margin-left: 2em">火鶉尾壽星大火析木星紀後曆家從便命之曰子</span>  
<span style="margin-left: 2em">亥戌酉申未午巳辰卯寅丑</span>  
<span style="margin-left: 2em">節氣曰冬至小寒大寒立春雨水驚蟄春分清明穀</span>  
<span style="margin-left: 2em">雨立夏小滿芒種夏至小暑大暑立秋處暑白露秋</span>  
<span style="margin-left: 2em">分寒露霜降立冬小雪大雪每一節分爲三候節氣</span>  
<span style="margin-left: 2em">中以二至二分爲主</span>  
<span style="margin-left: 2em">黃赤道交處爲春秋分相離最遠爲冬夏至</span>  
<span style="margin-left: 2em">黃道左右各八度以定月五星出入之道名爲月五</span>  
<span style="margin-left: 2em">星道<sub class="note-yuan">又名六曜道下文通用</sub>諸曜出入于黃道度多寡不同最</span>  
<span style="margin-left: 2em">遠者八度也又總名爲黃道帶<sub class="note-yuan">古法左右各六度</sub></span>  
<span style="margin-left: 14em">如上圖平分二十四</span>  
<span style="margin-left: 14em">氣者爲黃道帶甲至</span>  
<span style="margin-left: 14em">乙廣八度丁戊己庚</span>  
<span style="margin-left: 14em">爲赤道圈辛壬癸爲</span>  
<span style="margin-left: 14em">夏至圈子丑寅爲冬</span>  
<span style="margin-left: 14em">至圈丙則地心也</span>  
<span style="margin-left: 2em">周天分十二宫非獨宗動天之面也凡六合之內<sub class="note-yuan">即大</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">圜</sub>一切所有從宗動之面下至地心皆以十二分之</span>  
<span style="margin-left: 2em">故凡言宫者有四義</span>  
<span style="margin-left: 5em">其一黃道帶上有一長方面爲甲乙丙丁甲</span>  
<span style="margin-left: 5em">乙長三十度乙丙廣十六度凡七政彗孛等</span>  
<span style="margin-left: 5em">從地心作直線過本點至此面之某度分即</span>  
<span style="margin-left: 2em">命爲本點在本宫之某度分也</span>  
<span style="margin-left: 7em">其二以甲乙丙丁爲面從地心戊出四</span>  
<span style="margin-left: 7em">線上至方面之甲乙丙丁各角成銳角</span>  
<span style="margin-left: 7em">體凡六合之內一切所有但入此銳體</span>  
<span style="margin-left: 2em">中即命爲在本宫之某度分</span>  
<span style="margin-left: 5em">其三爲宗動天之內規面十二分之一以黃</span>  
<span style="margin-left: 5em">道兩大經圈各至極之己庚爲首尾中相去</span>  
<span style="margin-left: 5em">三十度之辛壬爲腰其中容即此分面也則</span>  
<span style="margin-left: 2em">凡諸點之在其面或在其下者皆命爲在本宫之某</span>  
<span style="margin-left: 5em">度分</span>  
<span style="margin-left: 5em">其四己辛庚壬爲面從面分至地心癸爲橘</span>  
<span style="margin-left: 5em">房體則入此體中者皆命爲本宫之某度分</span>  
<span style="margin-left: 2em">黃道有經度<sub class="note-yuan">一名長度</sub>有緯度<sub class="note-yuan">一名廣度</sub>從黃道作過極圈以</span>  
<span style="margin-left: 2em">定其經度法與赤道同但本道本極異耳若起算從</span>  
<span style="margin-left: 2em">春分始其義有二一爲是黃赤道二大圈之交也二</span>  
<span style="margin-left: 2em">爲其爲大圜之中中者二極之間也</span>  
<span style="margin-left: 2em">黃道之過極圈容其各緯度限各經度其左右侣圈</span>  
<span style="margin-left: 2em">限其各緯度容各經度</span>  
<span style="margin-left: 1em">黃道比論八條　比論者一與赤道比一與地平圈比</span>  
<span style="margin-left: 2em">一與地平南北圈比</span>  
<span style="margin-left: 2em">與赤道比論　黃赤道之交爲春秋分從此作過極</span>  
<span style="margin-left: 2em">大圈名爲極分交圈從二道最遠處作過極大圈爲</span>  
<span style="margin-left: 2em">極至交圈此二大圈分黃赤道各爲四分每分各爲</span>  
<span style="margin-left: 2em">九十度</span>  
<span style="margin-left: 5em">如上圖甲乙爲赤道極丙丁爲赤道戊己爲</span>  
<span style="margin-left: 5em">黃道庚爲二道之交則甲庚乙爲極分交圈</span>  
<span style="margin-left: 5em">甲丙己丁爲極至交圈</span>  
<span style="margin-left: 2em">黃赤道相距不用黃道之緯度<sub class="note-yuan">經緯線交爲直角一名廣度</sub>而用</span>  
<span style="margin-left: 2em">赤道之緯度<sub class="note-yuan">從黃道出線與黃道爲斜角至赤道作直角名偏度</sub>如降婁宫三</span>  
<span style="margin-left: 2em">十度若用廣度則相距十三度今用偏度則十二度</span>  
<span style="margin-left: 2em">半所以然者爲黃道斜迤若用廣度則分及一象限</span>  
<span style="margin-left: 2em">無法可分矣不若用赤道之平直四象皆通也<sub class="note-yuan">本以黃道</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">之三十度立算而用赤道之侶圈且與赤道爲直角與黃道爲斜角故名爲赤道上之黃道偏度非從赤</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">道目爲偏度也其在赤道自名旁度侶度</sub>黃道一象限九十度各有其偏</span>  
<span style="margin-left: 2em">度最遠者二十三度有奇不言三百六十者餘三象</span>  
<span style="margin-left: 2em">限與一同理故也</span>  
<span style="margin-left: 5em">如上圖甲丙爲黃道弧若廣度則值丙乙<sub class="note-jiao">校：文</sub></span>  
<span style="margin-left: 5em"><sub class="note-yuan">淵本甲乙作丙乙是今改</sub>偏度則值丙丁<sub class="note-jiao">校：文淵本甲丁作丙丁是今改</sub></span>  
<span style="margin-left: 5em">即作庚丙丁辛去離圈丙丁在其上爲距度</span>  
<span style="margin-left: 2em">測黃道弧之經度亦不用黃道之經度而用赤道之</span>  
<span style="margin-left: 2em">經度如降婁宫本三十度以赤道測之則二十七度</span>  
<span style="margin-left: 2em">爲此宫之黃道斜而長赤道直而狹故不命降婁一</span>  
<span style="margin-left: 2em">次黃道上之長度曰三十而命赤道上之黃道升度</span>  
<span style="margin-left: 2em">曰二十七也<sub class="note-yuan">本以黃道之三十度立算而用赤道之經度二十七其去離圈亦與赤道爲直</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">角名爲赤道上之黃道升度非從赤道目爲升度也在赤道自名上度</sub></span>  
<span style="margin-left: 6em">如上圖甲乙爲黃道弧若長度則值甲丁</span>  
<span style="margin-left: 6em">升度則值甲丙於赤道上命甲丙曰黃道</span>  
<span style="margin-left: 6em">之升度</span>  
<span style="margin-left: 2em">從黃赤交至北最遠黃道圈上有九十度每度作一</span>  
<span style="margin-left: 2em">圈與赤道之距等圈平行其初圈則赤道也其第九</span>  
<span style="margin-left: 2em">十即爲夏至圈南迄冬至亦然是名日轍圈亦曰日</span>  
<span style="margin-left: 6em">距圈</span>  
<span style="margin-left: 6em">如上圖甲乙爲赤道丙丁爲黃道辛丁爲</span>  
<span style="margin-left: 6em">冬至圈丙庚爲夏至圈己戊等皆其日距</span>  
<span style="margin-left: 2em">圈也</span>  
<span style="margin-left: 2em">赤道緯圈去極二十三度有奇者過黃道極名爲極</span>  
<span style="margin-left: 2em">圈南北同</span>  
<span style="margin-left: 6em">如上圖甲乙爲黃道丙丁爲黃道極過此</span>  
<span style="margin-left: 6em">二極之赤道緯圈爲丙己爲戊丁名南北</span>  
<span style="margin-left: 6em">極圈</span>  
<span style="margin-left: 2em">與地平圈比論　黃道與地平相遇作角其角隨時</span>  
<span style="margin-left: 2em">隨地大小不同正偏球皆然平球則否</span>  
<span style="margin-left: 2em">與地平南北圈比論　兩圈交而作角自六十六度</span>  
<span style="margin-left: 2em">有奇而至九十九十爲二至則直角六十六爲二分</span>  
<span style="margin-left: 2em">則銳角</span>  
<span style="margin-left: 1em">論本天之運動　凡四章</span>  
<span style="margin-left: 1em">總論一條　宗動天常平行終古無遲疾赤道繫焉故</span>  
<span style="margin-left: 2em">其行亦終古無遲疾</span>  
<span style="margin-left: 1em">諸點與地平比論十八條　凡先在地平下不見後見</span>  
<span style="margin-left: 2em">在地平上爲出反是爲入</span>  
<span style="margin-left: 2em">凡平球各點見地平上者皆與地平平行無出入七</span>  
<span style="margin-left: 5em">政則否</span>  
<span style="margin-left: 5em">如上圖甲乙爲地平與赤道同線丙丁等爲</span>  
<span style="margin-left: 5em">距等圈凡戊己等點皆與地平平行獨七政</span>  
<span style="margin-left: 2em">循黃道行則否</span>  
<span style="margin-left: 2em">若黃道極在天頂則黃道每日一次與地平爲一線</span>  
<span style="margin-left: 2em">一瞬則六宫在地平上六宫在地平下矣此非圖像</span>  
<span style="margin-left: 2em">可明視渾球則得之離黃道極圈而外則出入皆有</span>  
<span style="margin-left: 2em">法一宫先出一宫繼之<sub class="note-jiao">校：文淵本二宮作一宮是今改</sub>入亦然若黃</span>  
<span style="margin-left: 2em">道極圈之內赤道極之外則反是</span>  
<span style="margin-left: 2em">欲測各點運行視其出入于地平測法必以赤道之</span>  
<span style="margin-left: 2em">升度爲其尺度也何者赤道恆平行是名有法是爲</span>  
<span style="margin-left: 2em">有准分之尺度故</span>  
<span style="margin-left: 2em">平球而外凡各宫出地平上在黃道俱三十度赤道</span>  
<span style="margin-left: 2em">則有長短測法俱不用黃道之長度而用赤道上之</span>  
<span style="margin-left: 2em">黃道升度</span>  
<span style="margin-left: 5em">如北極出地十度爲丙乙其黃道初宫出地</span>  
<span style="margin-left: 5em">爲丁戊三十度則截取赤道先與黃道初度</span>  
<span style="margin-left: 5em">同出今與黃道第三十度同在地平線上者</span>  
<span style="margin-left: 2em">爲己戊得二十四度弱是爲黃道初宫之地升度凡</span>  
<span style="margin-left: 2em">論時刻及各點出入皆用之不用丁戊也</span>  
<span style="margin-left: 2em">凡測升度有二或連或斷連者俱初宫初度起至本</span>  
<span style="margin-left: 2em">點依前法視赤道同出度即得若有別設二點在黃</span>  
<span style="margin-left: 2em">道上欲測二點之升度是爲斷也法以前點視初宫</span>  
<span style="margin-left: 2em">相距之升度幾何是爲前升度以後點距初宫之升</span>  
<span style="margin-left: 2em">度幾何是爲總升度於總升度中減去前升度即得</span>  
<span style="margin-left: 2em">後升度</span>  
<span style="margin-left: 6em">如上圖乙甲爲別設點求其升度則丙乙</span>  
<span style="margin-left: 6em">爲戊丁之升度是前升度戊甲爲丙甲之</span>  
<span style="margin-left: 6em">升度是總升度次于戊甲減戊丁所存丁</span>  
<span style="margin-left: 2em">甲是乙甲之後升度</span>  
<span style="margin-left: 2em">問黃道弧而用赤道之升度爲其不等故也亦有等</span>  
<span style="margin-left: 2em">者乎曰有之論正球則黃赤道從二分二至起算各</span>  
<span style="margin-left: 2em">出地九十度其黃道弧與升度等周天之中其相等</span>  
<span style="margin-left: 2em">者四而已</span>  
<span style="margin-left: 2em">問正球黃赤道之四象限其升度與弧俱等者何故</span>  
<span style="margin-left: 2em">曰黃赤道俱爲二大圈相等則所分之相似圈分俱</span>  
<span style="margin-left: 2em">等一也又極至極分二大圈定黃赤道爲四象限此</span>  
<span style="margin-left: 2em">二大圈出入地時即地平與四象限之交相合爲一</span>  
<span style="margin-left: 2em">線故黃道之象限交必與赤道之象限交偕出偕入</span>  
<span style="margin-left: 2em">二也</span>  
<span style="margin-left: 2em">若欹球則黃道之半圈從分起從分止與赤道升降</span>  
<span style="margin-left: 2em">度等而周天之中其相等者二何者黃赤道二分之</span>  
<span style="margin-left: 2em">交同時至地平即二大半圈必相等故</span>  
<span style="margin-left: 2em">欹球二相等之外其他升度與黃道弧皆不等</span>  
<span style="margin-left: 2em">問二象限同升常自不等何以至九十度則等曰黃</span>  
<span style="margin-left: 2em">道弧與升度從初宫初度始每度之升度各有差初</span>  
<span style="margin-left: 2em">差漸多後差漸少漸近漸少至極遠而平故也過二</span>  
<span style="margin-left: 2em">至則反是</span>  
<span style="margin-left: 2em">若正球則四象限之黃道弧與升度常相似其差甚</span>  
<span style="margin-left: 2em">少不過三度欹球則所差絕多</span>  
<span style="margin-left: 9em">如上正球甲乙赤道軸即地平故</span>  
<span style="margin-left: 9em">丁丙弧與丁戊升度相似欹球北</span>  
<span style="margin-left: 9em">極面則辛壬弧與辛癸升度所差</span>  
<span style="margin-left: 2em">多</span>  
<span style="margin-left: 2em">升降有二有正升降有斜升降各弧與升度同出入</span>  
<span style="margin-left: 2em">若赤道上升度大于黃道弧謂之正升降小者謂之</span>  
<span style="margin-left: 2em">斜升降愈大愈正爲黃道與地平爲角近于直角愈</span>  
<span style="margin-left: 2em">小愈斜爲遠于直角</span>  
<span style="margin-left: 2em">正球但有四宫爲正升冬夏至前後各二宫是也冬</span>  
<span style="margin-left: 2em">至先後者析木星紀夏至前後者實沈鶉首餘八宫</span>  
<span style="margin-left: 2em">有斜者有半斜者</span>  
<span style="margin-left: 2em">若欹球則恆有六宫爲正升正升謂之遲升</span>  
<span style="margin-left: 2em">斜升謂之疾升欹球有六宫焉正球有八宫焉</span>  
<span style="margin-left: 2em">問欹球之正升者六爲何宫曰若北極出地一度至</span>  
<span style="margin-left: 2em">六十六度則鶉首鶉火鶉尾壽星大火析木是也此</span>  
<span style="margin-left: 2em">六宫則正升正升則斜降南極出地者反是</span>  
<span style="margin-left: 2em">球愈欹則黃道與地平爲角亦愈斜</span>  
<span style="margin-left: 1em">以升降比論四條　論正球黃道上兩點去離二至二</span>  
<span style="margin-left: 2em">分<sub class="note-yuan">亦名爲四大點</sub>各等則其升度亦等</span>  
<span style="margin-left: 2em">其相對之宫升度亦等如降婁壽星各二十七之類</span>  
<span style="margin-left: 2em">是也</span>  
<span style="margin-left: 2em">若欹球則相對宫之升度各不等</span>  
<span style="margin-left: 2em">有兩點去春秋分大點等則其升度亦等</span>  
<span style="margin-left: 1em">以正欹球比論二條　從降婁至鶉尾六宫欹球之升</span>  
<span style="margin-left: 2em">度小而正球大從壽星至娵訾六宫反是</span>  
<span style="margin-left: 2em">有兩弧在黃道上相對相等其正球之兩升度并爲</span>  
<span style="margin-left: 2em">一率欹球之兩升度并爲一率此兩率等</span>  
<span style="margin-left: 1em">以黃道之出入比論<sub class="note-yuan">即升降度</sub>五條　各宫各弧各點</span>  
<span style="margin-left: 9em"><sub class="note-yuan">之合也</sub></span>  
<span style="margin-left: 2em">之出度必等于入度<sub class="note-yuan">不論正偏球</sub></span>  
<span style="margin-left: 2em">各宫之出入度并與相對宫之出入度并等</span>  
<span style="margin-left: 2em">欹球各宫之出入度雖等而正斜不等此正升則彼</span>  
<span style="margin-left: 2em">斜降此斜升則彼正降</span>  
<span style="margin-left: 2em">一宫一弧在正球有升度在欹球有升度此兩升度</span>  
<span style="margin-left: 2em">相減之較名升差</span>  
<span style="margin-left: 9em">如上圖降婁一宫在正球之地升</span>  
<span style="margin-left: 9em">度二十六爲甲乙北極出地四十</span>  
<span style="margin-left: 9em">度之欹球地升度十六爲丁己以</span>  
<span style="margin-left: 2em">二率相減得十度是爲兩球升度之差<sub class="note-yuan">省曰升差</sub></span>  
<span style="margin-left: 2em">正球之升降度從地平起算可從地平南北圈起算</span>  
<span style="margin-left: 2em">亦可爲赤道與地平圈與南北圈相遇俱爲直角故</span>  
<span style="margin-left: 2em">等欹球則否必用地平也</span>  
<span style="margin-left: 1em">太陽篇第四<sub class="note-yuan">不稱日者篇中有時日之日故別言之月稱太陰同</sub></span>  
<span style="margin-left: 1em">總論　宗動天之下則有列宿又下則塡星則歲星則</span>  
<span style="margin-left: 2em">熒惑何以序先太陽其義有三一列宿與六曜之理</span>  
<span style="margin-left: 2em">皆繫太陽不先論此不得論彼二理較易明先明其</span>  
<span style="margin-left: 2em">易難者并易三萬光之原諸曜皆從受光焉月若其</span>  
<span style="margin-left: 2em">配星其從也</span>  
<span style="margin-left: 1em">從本體論　凡三章</span>  
<span style="margin-left: 2em">論太陽之形象本是圓體　圓有面有體太陽之爲</span>  
<span style="margin-left: 2em">圓面舉目即是不待言矣其爲圓體何從知之曰凡</span>  
<span style="margin-left: 2em">物未有有面無體者太陽之爲物大矣知其必有體</span>  
<span style="margin-left: 2em">也凡自然生者初生者無物不圓太陽之生亦本自</span>  
<span style="margin-left: 2em">然曾無雕琢初生則然曾無遷變又諸體中圓爲最</span>  
<span style="margin-left: 2em">尊以太陽較天下有形之物亦是最尊知其必爲圓</span>  
<span style="margin-left: 2em">體也</span>  
<span style="margin-left: 2em">論太陽之大　欲知物大先知其徑徑有二一爲視</span>  
<span style="margin-left: 2em">徑視徑者人目所視也舊云太陽之徑一度近來測</span>  
<span style="margin-left: 2em">驗實止半度</span>  
<span style="margin-left: 6em">如上圖甲乙乙丁丁戊爲宗動天內規面</span>  
<span style="margin-left: 6em">之三度人從辛視太陽之己庚徑于天度</span>  
<span style="margin-left: 6em">僅得乙丙不滿乙丁之一度約如乙丙者</span>  
<span style="margin-left: 1em">七百二十則滿黃道周故知視徑爲半度也</span>  
<span style="margin-left: 2em">一爲本徑欲知本徑先論其去地之遠太陽去地有</span>  
<span style="margin-left: 2em">時近有時遠折取中數則以地全徑爲度<sub class="note-yuan">里數太多難計故以</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">地徑之里數爲其尺度也地之周約九萬里其全徑約三萬里</sub>二十四其地徑自之</span>  
<span style="margin-left: 2em">得五百七十六是太陽去地之中數也<sub class="note-yuan">其比例云地之徑與太陽</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">去地之半徑若一與五百七十六也</sub>既知其視徑又得其去地之遠因</span>  
<span style="margin-left: 2em">以割圓術求其本徑得太陽之容大于地之容一百</span>  
<span style="margin-left: 2em">餘倍也<sub class="note-yuan">割圓術有專書二徑相比見幾何原本第十二卷第十八題容者體之容算術謂之立圓</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">積非徑線亦非面也其算法後篇詳</sub></span>  
<span style="margin-left: 2em">論太陽之光　日爲大光六合之內無微不照有不</span>  
<span style="margin-left: 2em">透明之物隔之則生影地在天中體小于日故影漸</span>  
<span style="margin-left: 2em">遠漸殺以至于盡其影之長不至太陽之衝</span>  
<span style="margin-left: 6em">如上圖甲乙爲日丙丁爲地其影至戊而</span>  
<span style="margin-left: 6em">止不至己</span>  
<span style="margin-left: 6em">太陽面上有黑子或一或二或三四而止</span>  
<span style="margin-left: 2em">或大或小恒于太陽東西徑上行其道止一線行十</span>  
<span style="margin-left: 2em">四日而盡前者盡則後者繼之其大者能減太陽之</span>  
<span style="margin-left: 2em">光先時或疑爲金水二星考其躔度則又不合近有</span>  
<span style="margin-left: 2em">望遠鏡乃知其體不與日體爲一又不若雲霞之去</span>  
<span style="margin-left: 2em">日極遠特在其面而不審爲何物</span>  
<span style="margin-left: 1em">從運動論　凡五章</span>  
<span style="margin-left: 2em">太陽之動有二其一與黃赤道比論其一與地平比</span>  
<span style="margin-left: 2em">論與黃赤道比論　如從冬至一點起算行天一日</span>  
<span style="margin-left: 2em">一周明日不在冬至即此一圈作螺旋一周次日復</span>  
<span style="margin-left: 2em">然迄夏至點行一百八十餘周而通作一螺旋線也</span>  
<span style="margin-left: 2em">第冬至線與次日一周線相離甚近以次漸遠迄春</span>  
<span style="margin-left: 2em">分而甚遠過此漸近迄夏至而甚近過此又漸遠如</span>  
<span style="margin-left: 2em">是循環無窮耳詳見後篇</span>  
<span style="margin-left: 2em">又冬至初日之線其螺圈甚小次日漸大至春分甚</span>  
<span style="margin-left: 2em">大過此漸小迄夏至而甚小如是小大循環者何也</span>  
<span style="margin-left: 2em">爲緯圈中冬夏至皆小圈赤道爲大圈故也從冬至</span>  
<span style="margin-left: 2em">迄夏至此爲成歲之半矣若從夏至迄冬至亦作螺</span>  
<span style="margin-left: 2em">旋行每日一周百八十餘日通作一螺旋線但此線</span>  
<span style="margin-left: 2em">非復前線而別作一線每日與前線作一交耳此爲</span>  
<span style="margin-left: 2em">成歲之全也</span>  
<span style="margin-left: 2em">如圖作螺旋圈不能爲三百六十作二十四以明其</span>  
<span style="margin-left: 2em">意已上所說螺旋線是太陽之體理實作如是運動</span>  
<span style="margin-left: 2em">無可疑者但螺旋則無法之線也以此測候亦復無</span>  
<span style="margin-left: 2em">法可立故天官家別用他術如下文</span>  
<span style="margin-left: 2em">測候之術　如用春分起算初日從初點循赤道行</span>  
<span style="margin-left: 2em">迄一周是爲一日明日即不在赤道而在其第二圈</span>  
<span style="margin-left: 2em">又不直距于初點而東西相去爲黃道之一長度其</span>  
<span style="margin-left: 2em">南北距度即不及一度也此一周即爲赤道之一距</span>  
<span style="margin-left: 2em">等圈矣太陽恒在黃道下行故無黃道之廣度至第</span>  
<span style="margin-left: 2em">三日復作第三距等圈與次日同凡九十日行黃道</span>  
<span style="margin-left: 2em">九十度即于赤道旁作九十距等圈其第九十則夏</span>  
<span style="margin-left: 2em">至圈夏至圈去春分圈止二十三度半故太陽之行</span>  
<span style="margin-left: 2em">亦如是而止此九十距等線以當全螺線之半也用</span>  
<span style="margin-left: 2em">此術則從夏至迄秋分亦有九十距等線其線即春</span>  
<span style="margin-left: 2em">夏距等之原線矣</span>  
<span style="margin-left: 2em">至秋分即復行赤道一日無距度距圈與前春分日</span>  
<span style="margin-left: 2em">所行同線相對其兩對處則有極分交圈以爲之限</span>  
<span style="margin-left: 2em">也自春迄秋二分之間行一百八十度黃道長度與</span>  
<span style="margin-left: 2em">赤道之距度其數皆等從秋分而後每日作一距等</span>  
<span style="margin-left: 2em">圈其第九十則冬至圈也凡諸距度圈皆交于黃道</span>  
<span style="margin-left: 2em">獨二至之兩圈切于黃道爲其行至是盡矣其兩盡</span>  
<span style="margin-left: 2em">處則極至交圈爲之限也秋分迄冬至亦二十三度</span>  
<span style="margin-left: 2em">半與其迄夏至等故其間距等圈與其迄夏至之距</span>  
<span style="margin-left: 2em">等圈亦等從冬至以後亦依前所行距等原線以迄</span>  
<span style="margin-left: 2em">春分而歲成矣</span>  
<span style="margin-left: 2em">太陽之行恒在黃道下無廣度亦恒在兩至之內故</span>  
<span style="margin-left: 2em">兩至之內皆爲太陽所行之道而太陽每日行一度</span>  
<span style="margin-left: 2em">弱故兩至間之距等圈凡一百八十二有奇每一圈</span>  
<span style="margin-left: 2em">歲兩經焉如此術即分太陽所行爲二路其一分計</span>  
<span style="margin-left: 2em">每日所行各行于赤道侣圈皆在兩赤道極之間其</span>  
<span style="margin-left: 2em">二總計每歲所行皆行于黃道在兩黃道極之間其</span>  
<span style="margin-left: 2em">一日一周于黃道爲一長度于赤道上不及一上度</span>  
<span style="margin-left: 2em">此一上度弱者名爲黃道一日之升度黃道之升度</span>  
<span style="margin-left: 2em">每宫與赤道不等故每日黃道之升度一一不等<sub class="note-yuan">見本</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">設表</sub></span>  
<span style="margin-left: 2em">螺旋合術與黃赤分術比論　論合術則自東而西</span>  
<span style="margin-left: 2em">每日不及一度故云日遲論分術則自西而東每日</span>  
<span style="margin-left: 2em">循黃道行一度故云日疾其實一也但螺旋于理甚</span>  
<span style="margin-left: 2em">合而無法可推分術則分數易明其間即有參差不</span>  
<span style="margin-left: 2em">能及一微一纖非儀象可測故曆家專用分術<sub class="note-yuan">加減法也</sub></span>  
<span style="margin-left: 2em">以便推步</span>  
<span style="margin-left: 2em">與地平比論　太陽至地平上爲出爲明從東而西</span>  
<span style="margin-left: 2em">沒于地平下爲入爲晦</span>  
<span style="margin-left: 2em">論正球春分日太陽出于東方行赤道赤道即東西</span>  
<span style="margin-left: 2em">圈漸升至頂極即至南北圈爲極高之弧此地平以</span>  
<span style="margin-left: 2em">上之半晝分也亦謂之東半晝弧午正後漸降至地</span>  
<span style="margin-left: 2em">平謂之西半晝弧東西合則爲全弧行盡全弧爲一</span>  
<span style="margin-left: 2em">晝</span>  
<span style="margin-left: 2em">其一日之中地平上凡有表即得影日出則爲無窮</span>  
<span style="margin-left: 2em">之西影漸短至頂僅得一點<sub class="note-yuan">或云是爲無影安得一點不知無表即無影若</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">令表離于地平即有與表等大之影</sub>午正後影漸長至地平復爲無窮</span>  
<span style="margin-left: 2em">之東影日既入地平下則有朦朧分<sub class="note-yuan">一名昏度一名黃昏</sub>行地</span>  
<span style="margin-left: 2em">平之低度十八<sub class="note-yuan">低度者非黃道赤道之度乃地平之緯度也在下故名低度在上名高度</sub></span>  
<span style="margin-left: 2em">後此爲夜</span>  
<span style="margin-left: 6em">如上圖甲乙爲赤道即東西圈丙甲丁爲</span>

<span style="margin-left: 2em">能生火又用玻瓈圓球對日而成折照亦能出火其</span>  
<span style="margin-left: 2em">故爲何光于天下爲最尊熱于四大物情中<sub class="note-yuan">四大情者一熱</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">二冷三燥四濕</sub>亦爲最尊以尊生尊是其理也其次亦能生</span>  
<span style="margin-left: 2em">冷亦能生燥亦能生濕爲光本非熱非冷非燥非濕</span>  
<span style="margin-left: 2em">而其中有精足當四情故能生熱生冷生燥生濕也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">如仁中無芽葉花實而其精足當四物故能生四物也</sub>夫光之爲體若其發而</span>  
<span style="margin-left: 2em">及物何爲施之不盡若其不發則一切所受爲從何</span>  
<span style="margin-left: 2em">來故其體其用總非人間意量所及</span>  
<span style="margin-left: 2em">光之外別有施者不屬光也此有二證其一海潮大</span>  
<span style="margin-left: 2em">小不因于光亦不因于冷熱燥濕譬如磁石吸鐵別</span>  
<span style="margin-left: 2em">有相攝相受者則受者爲所施攝者爲能施也又如</span>  
<span style="margin-left: 2em">懷胎生子七月生則長八月生則殀無不驗者此亦</span>  
<span style="margin-left: 2em">非因于光亦非因于四情亦如磁鐵有別相攝受者</span>  
<span style="margin-left: 2em">故也</span>  
<span style="margin-left: 2em">從上二能知天于下土盖有四德一曰覆冒一曰包</span>  
<span style="margin-left: 2em">函一曰生育一曰保存也假令不動亦有此德而又</span>  
<span style="margin-left: 2em">加之運動于此若此于彼若彼變化無端真非思議</span>  
<span style="margin-left: 2em">所及矣</span>  
<span style="margin-left: 1em">遷變　四條</span>  
<span style="margin-left: 2em">凡物遷變首運動</span>  
<span style="margin-left: 2em">天之運動皆環行何者天體單獨無二故共運動亦</span>  
<span style="margin-left: 2em">應單獨無二環行者單獨無二之行也何謂單行曰</span>  
<span style="margin-left: 2em">凡動如人如鳥獸如風皆襍亂無法之行也單行有</span>  
<span style="margin-left: 2em">二一曰垂線一曰圓線石在空中下墜于地此爲垂</span>  
<span style="margin-left: 2em">線一切循環無端者皆爲圓線垂線之動勢盡而止</span>  
<span style="margin-left: 2em">惟圓線獨爲無窮天以覆函生存下土者也故不能</span>  
<span style="margin-left: 2em">不爲無窮不能不爲環行矣</span>  
<span style="margin-left: 2em">天之運動恒不去其本所論其各分無一不動而其</span>  
<span style="margin-left: 2em">全體無一分動</span>  
<span style="margin-left: 2em">天之運動有四異其一甚疾一刻分中行幾萬里如</span>  
<span style="margin-left: 2em">鳥如矢如礟如霹靂皆非所及其二恒平行<sub class="note-yuan">其中遲速別有</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">故實無一不平行者詳見後論</sub>若非一一平行即測候之術無從可</span>  
<span style="margin-left: 2em">用其三恒久不已其四萬物之動此爲首何者天下</span>  
<span style="margin-left: 2em">之動于此焉繫故也若無此動即無四季即無生物</span>  
<span style="margin-left: 2em">問運動而外更有遷變乎曰論其體則無變何者爲</span>  
<span style="margin-left: 2em">在最上物無及其際者故不能受變于物論其情則</span>  
<span style="margin-left: 2em">有變如月星無光因于日光變而有光一也又如日</span>
