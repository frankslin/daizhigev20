<span style="margin-left: 1em">宗动篇第三</span>  
<span style="margin-left: 1em">总论二条　论宗动有二端一言本天之点与线二言</span>  
<span style="margin-left: 2em">本天之运动</span>  
<span style="margin-left: 2em">三曜皆有两种运动宜以两物测之犹布帛之用尺</span>  
<span style="margin-left: 2em">度也七政恒星皆一日一周自东而西则以赤道为</span>  
<span style="margin-left: 2em">其尺度又各有迟速本行自西而东则以黄道为其</span>  
<span style="margin-left: 2em">尺度凡动天皆宗于宗动天故黄赤二道皆系焉<sub class="note-yuan">三曜</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">者日月星也</sub></span>  
<span style="margin-left: 1em">论本天之点与线　凡三章</span>  
<span style="margin-left: 1em">论赤道七条　赤道于诸大圈为最尊其义有三不知</span>  
<span style="margin-left: 2em">赤道则诸大圈无从可解一也赤道之理特为易明</span>  
<span style="margin-left: 2em">二也一日一周乃七政恒星之公运动赤道主之三</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 2em">其两极即大圜之两极何者为本道与天元赤道相</span>  
<span style="margin-left: 2em">合为一线动静虽异终古不离也</span>  
<span style="margin-left: 2em">大圜之心中圈之心赤道之心地之心同是一点为</span>  
<span style="margin-left: 2em">赤道与大圈中圈同为大圈故也</span>  
<span style="margin-left: 2em">赤道既为大圈其分数亦有半圈有象限有三百六</span>  
<span style="margin-left: 2em">十度及分秒其算数则从一至三百六十与黄道地</span>  
<span style="margin-left: 2em">平异黄道分十二宫各以三十为限地平分四象各</span>  
<span style="margin-left: 2em">以九十为限故赤道亦有过极经圈一百八十为用</span>  
<span style="margin-left: 2em">甚大其左右旁各有距等侣圈<sub class="note-yuan">即纬圈</sub>每至极各九十</span>  
<span style="margin-left: 2em">不甚为用为与天元纬度一一同线故</span>  
<span style="margin-left: 2em">其用则以赤道之经纬度测各点之所在命为各点</span>  
<span style="margin-left: 2em">赤道经纬度</span>  
<span style="margin-left: 5em">如上图赤道上任设甲点从赤道初点乙数</span>  
<span style="margin-left: 5em">至甲为几度分即甲点之赤道经度分也为</span>  
<span style="margin-left: 5em">在赤道上故无纬度</span>  
<span style="margin-left: 5em">若所设甲点在赤道外则于过极大圈数甲</span>  
<span style="margin-left: 5em">点至赤道交即定赤道初点至设点之经度</span>  
<span style="margin-left: 5em">为六甲点至赤道即所容之纬度为五</span>  
<span style="margin-left: 2em">凡分南北大分独六合之内<sub class="note-yuan">即大圜也</sub>及日以赤道分之</span>  
<span style="margin-left: 2em">他则否</span>  
<span style="margin-left: 1em">论黄道十条　黄道亦大圈也两交于赤道两交之间</span>  
<span style="margin-left: 2em">最远于赤道者二十三度有奇</span>  
<span style="margin-left: 5em">黄道之两极去赤道两极亦二十三度有奇</span>  
<span style="margin-left: 5em">与二道相离最远之数同也</span>  
<span style="margin-left: 5em">如上图甲至丙为黄赤二道相离最远之二</span>  
<span style="margin-left: 2em">十三度有奇则庚至戊亦黄赤二极相离之二十三</span>  
<span style="margin-left: 2em">度有奇</span>  
<span style="margin-left: 2em">黄道分数其四象限三百六十度与赤道同又十二</span>  
<span style="margin-left: 2em">分之为宫二十四分之为节气七十二分之为候与</span>  
<span style="margin-left: 2em">赤道异十二宫曰玄枵娵訾降娄大梁实沈鹑首鹑</span>  
<span style="margin-left: 2em">火鹑尾寿星大火析木星纪后历家从便命之曰子</span>  
<span style="margin-left: 2em">亥戌酉申未午巳辰卯寅丑</span>  
<span style="margin-left: 2em">节气曰冬至小寒大寒立春雨水惊蛰春分清明谷</span>  
<span style="margin-left: 2em">雨立夏小满芒种夏至小暑大暑立秋处暑白露秋</span>  
<span style="margin-left: 2em">分寒露霜降立冬小雪大雪每一节分为三候节气</span>  
<span style="margin-left: 2em">中以二至二分为主</span>  
<span style="margin-left: 2em">黄赤道交处为春秋分相离最远为冬夏至</span>  
<span style="margin-left: 2em">黄道左右各八度以定月五星出入之道名为月五</span>  
<span style="margin-left: 2em">星道<sub class="note-yuan">又名六曜道下文通用</sub>诸曜出入于黄道度多寡不同最</span>  
<span style="margin-left: 2em">远者八度也又总名为黄道带<sub class="note-yuan">古法左右各六度</sub></span>  
<span style="margin-left: 14em">如上图平分二十四</span>  
<span style="margin-left: 14em">气者为黄道带甲至</span>  
<span style="margin-left: 14em">乙广八度丁戊己庚</span>  
<span style="margin-left: 14em">为赤道圈辛壬癸为</span>  
<span style="margin-left: 14em">夏至圈子丑寅为冬</span>  
<span style="margin-left: 14em">至圈丙则地心也</span>  
<span style="margin-left: 2em">周天分十二宫非独宗动天之面也凡六合之内<sub class="note-yuan">即大</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">圜</sub>一切所有从宗动之面下至地心皆以十二分之</span>  
<span style="margin-left: 2em">故凡言宫者有四义</span>  
<span style="margin-left: 5em">其一黄道带上有一长方面为甲乙丙丁甲</span>  
<span style="margin-left: 5em">乙长三十度乙丙广十六度凡七政彗孛等</span>  
<span style="margin-left: 5em">从地心作直线过本点至此面之某度分即</span>  
<span style="margin-left: 2em">命为本点在本宫之某度分也</span>  
<span style="margin-left: 7em">其二以甲乙丙丁为面从地心戊出四</span>  
<span style="margin-left: 7em">线上至方面之甲乙丙丁各角成锐角</span>  
<span style="margin-left: 7em">体凡六合之内一切所有但入此锐体</span>  
<span style="margin-left: 2em">中即命为在本宫之某度分</span>  
<span style="margin-left: 5em">其三为宗动天之内规面十二分之一以黄</span>  
<span style="margin-left: 5em">道两大经圈各至极之己庚为首尾中相去</span>  
<span style="margin-left: 5em">三十度之辛壬为腰其中容即此分面也则</span>  
<span style="margin-left: 2em">凡诸点之在其面或在其下者皆命为在本宫之某</span>  
<span style="margin-left: 5em">度分</span>  
<span style="margin-left: 5em">其四己辛庚壬为面从面分至地心癸为橘</span>  
<span style="margin-left: 5em">房体则入此体中者皆命为本宫之某度分</span>  
<span style="margin-left: 2em">黄道有经度<sub class="note-yuan">一名长度</sub>有纬度<sub class="note-yuan">一名广度</sub>从黄道作过极圈以</span>  
<span style="margin-left: 2em">定其经度法与赤道同但本道本极异耳若起算从</span>  
<span style="margin-left: 2em">春分始其义有二一为是黄赤道二大圈之交也二</span>  
<span style="margin-left: 2em">为其为大圜之中中者二极之间也</span>  
<span style="margin-left: 2em">黄道之过极圈容其各纬度限各经度其左右侣圈</span>  
<span style="margin-left: 2em">限其各纬度容各经度</span>  
<span style="margin-left: 1em">黄道比论八条　比论者一与赤道比一与地平圈比</span>  
<span style="margin-left: 2em">一与地平南北圈比</span>  
<span style="margin-left: 2em">与赤道比论　黄赤道之交为春秋分从此作过极</span>  
<span style="margin-left: 2em">大圈名为极分交圈从二道最远处作过极大圈为</span>  
<span style="margin-left: 2em">极至交圈此二大圈分黄赤道各为四分每分各为</span>  
<span style="margin-left: 2em">九十度</span>  
<span style="margin-left: 5em">如上图甲乙为赤道极丙丁为赤道戊己为</span>  
<span style="margin-left: 5em">黄道庚为二道之交则甲庚乙为极分交圈</span>  
<span style="margin-left: 5em">甲丙己丁为极至交圈</span>  
<span style="margin-left: 2em">黄赤道相距不用黄道之纬度<sub class="note-yuan">经纬线交为直角一名广度</sub>而用</span>  
<span style="margin-left: 2em">赤道之纬度<sub class="note-yuan">从黄道出线与黄道为斜角至赤道作直角名偏度</sub>如降娄宫三</span>  
<span style="margin-left: 2em">十度若用广度则相距十三度今用偏度则十二度</span>  
<span style="margin-left: 2em">半所以然者为黄道斜迤若用广度则分及一象限</span>  
<span style="margin-left: 2em">无法可分矣不若用赤道之平直四象皆通也<sub class="note-yuan">本以黄道</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">之三十度立算而用赤道之侣圈且与赤道为直角与黄道为斜角故名为赤道上之黄道偏度非从赤</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">道目为偏度也其在赤道自名旁度侣度</sub>黄道一象限九十度各有其偏</span>  
<span style="margin-left: 2em">度最远者二十三度有奇不言三百六十者余三象</span>  
<span style="margin-left: 2em">限与一同理故也</span>  
<span style="margin-left: 5em">如上图甲丙为黄道弧若广度则值丙乙<sub class="note-jiao">校：文</sub></span>  
<span style="margin-left: 5em"><sub class="note-yuan">渊本甲乙作丙乙是今改</sub>偏度则值丙丁<sub class="note-jiao">校：文淵本甲丁作丙丁是今改</sub></span>  
<span style="margin-left: 5em">即作庚丙丁辛去离圈丙丁在其上为距度</span>  
<span style="margin-left: 2em">测黄道弧之经度亦不用黄道之经度而用赤道之</span>  
<span style="margin-left: 2em">经度如降娄宫本三十度以赤道测之则二十七度</span>  
<span style="margin-left: 2em">为此宫之黄道斜而长赤道直而狭故不命降娄一</span>  
<span style="margin-left: 2em">次黄道上之长度曰三十而命赤道上之黄道升度</span>  
<span style="margin-left: 2em">曰二十七也<sub class="note-yuan">本以黄道之三十度立算而用赤道之经度二十七其去离圈亦与赤道为直</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">角名为赤道上之黄道升度非从赤道目为升度也在赤道自名上度</sub></span>  
<span style="margin-left: 6em">如上图甲乙为黄道弧若长度则值甲丁</span>  
<span style="margin-left: 6em">升度则值甲丙于赤道上命甲丙曰黄道</span>  
<span style="margin-left: 6em">之升度</span>  
<span style="margin-left: 2em">从黄赤交至北最远黄道圈上有九十度每度作一</span>  
<span style="margin-left: 2em">圈与赤道之距等圈平行其初圈则赤道也其第九</span>  
<span style="margin-left: 2em">十即为夏至圈南迄冬至亦然是名日辙圈亦曰日</span>

<span style="margin-left: 6em">冬至圈丙庚为夏至圈己戊等皆其日距</span>  
<span style="margin-left: 2em">圈也</span>  
<span style="margin-left: 2em">赤道纬圈去极二十三度有奇者过黄道极名为极</span>

<span style="margin-left: 6em">如上图甲乙为黄道丙丁为黄道极过此</span>  
<span style="margin-left: 6em">二极之赤道纬圈为丙己为戊丁名南北</span>

<span style="margin-left: 2em">随地大小不同正偏球皆然平球则否</span>

<span style="margin-left: 1em">论本天之运动　凡四章</span>  
<span style="margin-left: 1em">总论一条　宗动天常平行终古无迟疾赤道系焉故</span>  
<span style="margin-left: 2em">其行亦终古无迟疾</span>  
<span style="margin-left: 1em">诸点与地平比论十八条　凡先在地平下不见后见</span>  
<span style="margin-left: 2em">在地平上为出反是为入</span>  
<span style="margin-left: 2em">凡平球各点见地平上者皆与地平平行无出入七</span>  
<span style="margin-left: 5em">政则否</span>  
<span style="margin-left: 5em">如上图甲乙为地平与赤道同线丙丁等为</span>  
<span style="margin-left: 5em">距等圈凡戊己等点皆与地平平行独七政</span>  
<span style="margin-left: 2em">循黄道行则否</span>  
<span style="margin-left: 2em">若黄道极在天顶则黄道每日一次与地平为一线</span>  
<span style="margin-left: 2em">一瞬则六宫在地平上六宫在地平下矣此非图像</span>  
<span style="margin-left: 2em">可明视浑球则得之离黄道极圈而外则出入皆有</span>  
<span style="margin-left: 2em">法一宫先出一宫继之<sub class="note-jiao">校：文淵本二宮作一宮是今改</sub>入亦然若黄</span>  
<span style="margin-left: 2em">道极圈之内赤道极之外则反是</span>  
<span style="margin-left: 2em">欲测各点运行视其出入于地平测法必以赤道之</span>  
<span style="margin-left: 2em">升度为其尺度也何者赤道恒平行是名有法是为</span>  
<span style="margin-left: 2em">有准分之尺度故</span>  
<span style="margin-left: 2em">平球而外凡各宫出地平上在黄道俱三十度赤道</span>  
<span style="margin-left: 2em">则有长短测法俱不用黄道之长度而用赤道上之</span>  
<span style="margin-left: 2em">黄道升度</span>  
<span style="margin-left: 5em">如北极出地十度为丙乙其黄道初宫出地</span>  
<span style="margin-left: 5em">为丁戊三十度则截取赤道先与黄道初度</span>  
<span style="margin-left: 5em">同出今与黄道第三十度同在地平线上者</span>  
<span style="margin-left: 2em">为己戊得二十四度弱是为黄道初宫之地升度凡</span>  
<span style="margin-left: 2em">论时刻及各点出入皆用之不用丁戊也</span>  
<span style="margin-left: 2em">凡测升度有二或连或断连者俱初宫初度起至本</span>  
<span style="margin-left: 2em">点依前法视赤道同出度即得若有别设二点在黄</span>  
<span style="margin-left: 2em">道上欲测二点之升度是为断也法以前点视初宫</span>  
<span style="margin-left: 2em">相距之升度几何是为前升度以后点距初宫之升</span>  
<span style="margin-left: 2em">度几何是为总升度于总升度中减去前升度即得</span>  
<span style="margin-left: 2em">后升度</span>  
<span style="margin-left: 6em">如上图乙甲为别设点求其升度则丙乙</span>  
<span style="margin-left: 6em">为戊丁之升度是前升度戊甲为丙甲之</span>

<span style="margin-left: 1em">总论　宗动天之下则有列宿又下则塡星则岁星则</span>  
<span style="margin-left: 2em">荧惑何以序先太阳其义有三一列宿与六曜之理</span>  
<span style="margin-left: 2em">皆系太阳不先论此不得论彼二理较易明先明其</span>  
<span style="margin-left: 2em">易难者并易三万光之原诸曜皆从受光焉月若其</span>

<span style="margin-left: 1em">从本体论　凡三章</span>  
<span style="margin-left: 2em">论太阳之形象本是圆体　圆有面有体太阳之为</span>  
<span style="margin-left: 2em">圆面举目即是不待言矣其为圆体何从知之曰凡</span>  
<span style="margin-left: 2em">物未有有面无体者太阳之为物大矣知其必有体</span>  
<span style="margin-left: 2em">也凡自然生者初生者无物不圆太阳之生亦本自</span>  
<span style="margin-left: 2em">然曾无雕琢初生则然曾无迁变又诸体中圆为最</span>  
<span style="margin-left: 2em">尊以太阳较天下有形之物亦是最尊知其必为圆</span>  
<span style="margin-left: 2em">体也</span>  
<span style="margin-left: 2em">论太阳之大　欲知物大先知其径径有二一为视</span>  
<span style="margin-left: 2em">径视径者人目所视也旧云太阳之径一度近来测</span>  
<span style="margin-left: 2em">验实止半度</span>  
<span style="margin-left: 6em">如上图甲乙乙丁丁戊为宗动天内规面</span>  
<span style="margin-left: 6em">之三度人从辛视太阳之己庚径于天度</span>  
<span style="margin-left: 6em">仅得乙丙不满乙丁之一度约如乙丙者</span>  
<span style="margin-left: 1em">七百二十则满黄道周故知视径为半度也</span>  
<span style="margin-left: 2em">一为本径欲知本径先论其去地之远太阳去地有</span>

<span style="margin-left: 2em">余倍也<sub class="note-yuan">割圆术有专书二径相比见几何原本第十二卷第十八题容者体之容算术谓之立圆</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">积非径线亦非面也其算法后篇详</sub></span>  
<span style="margin-left: 2em">论太阳之光　日为大光六合之内无微不照有不</span>  
<span style="margin-left: 2em">透明之物隔之则生影地在天中体小于日故影渐</span>

<span style="margin-left: 2em">四日而尽前者尽则后者继之其大者能减太阳之</span>

<span style="margin-left: 1em">从运动论　凡五章</span>  
<span style="margin-left: 2em">太阳之动有二其一与黄赤道比论其一与地平比</span>

<span style="margin-left: 2em">非复前线而别作一线每日与前线作一交耳此为</span>

<span style="margin-left: 2em">意已上所说螺旋线是太阳之体理实作如是运动</span>  
<span style="margin-left: 2em">无可疑者但螺旋则无法之线也以此测候亦复无</span>

<span style="margin-left: 2em">迄一周是为一日明日即不在赤道而在其第二圈</span>  
<span style="margin-left: 2em">又不直距于初点而东西相去为黄道之一长度其</span>  
<span style="margin-left: 2em">南北距度即不及一度也此一周即为赤道之一距</span>  
<span style="margin-left: 2em">等圈矣太阳恒在黄道下行故无黄道之广度至第</span>  
<span style="margin-left: 2em">三日复作第三距等圈与次日同凡九十日行黄道</span>  
<span style="margin-left: 2em">九十度即于赤道旁作九十距等圈其第九十则夏</span>  
<span style="margin-left: 2em">至圈夏至圈去春分圈止二十三度半故太阳之行</span>  
<span style="margin-left: 2em">亦如是而止此九十距等线以当全螺线之半也用</span>  
<span style="margin-left: 2em">此术则从夏至迄秋分亦有九十距等线其线即春</span>  
<span style="margin-left: 2em">夏距等之原线矣</span>  
<span style="margin-left: 2em">至秋分即复行赤道一日无距度距圈与前春分日</span>  
<span style="margin-left: 2em">所行同线相对其两对处则有极分交圈以为之限</span>  
<span style="margin-left: 2em">也自春迄秋二分之间行一百八十度黄道长度与</span>  
<span style="margin-left: 2em">赤道之距度其数皆等从秋分而后每日作一距等</span>  
<span style="margin-left: 2em">圈其第九十则冬至圈也凡诸距度圈皆交于黄道</span>  
<span style="margin-left: 2em">独二至之两圈切于黄道为其行至是尽矣其两尽</span>

<span style="margin-left: 1em">太阴篇第五</span>  
<span style="margin-left: 1em">五纬在二曜之上今先太阴者何故一凡论年月日时</span>  
<span style="margin-left: 2em">皆以二曜定之二其理较五纬特为易明三太阴体</span>  
<span style="margin-left: 2em">大昼时亦见四太阴之能力亚于太阳五纬无能及</span>  
<span style="margin-left: 2em">之</span>  
<span style="margin-left: 1em">从本体论</span>  
<span style="margin-left: 2em">论太阴之形象　本是圆体与太阳同虽有晦朔弦</span>  
<span style="margin-left: 2em">望不害为圆详见后论</span>  
<span style="margin-left: 2em">论太阴之大　太阴去人时近时远折取中数八其</span>  
<span style="margin-left: 2em">地半径自之得六十四半径为三十二全径是太阴</span>  
<span style="margin-left: 2em">去地之中数也</span>  
<span style="margin-left: 2em">其视径去人愈近愈大愈远愈小折取中数亦得半</span>  
<span style="margin-left: 2em">度与太阳等</span>  
<span style="margin-left: 2em">其本径则小于地球地之容大于月约三十倍也</span>  
<span style="margin-left: 2em">论太阴之光　本自无光受光于太阳故本球之光</span>  
<span style="margin-left: 2em">恒得半以上因太阳之体大于其体故</span>  
<span style="margin-left: 8em">如上图甲乙为日丙丁为月径因日</span>  
<span style="margin-left: 8em">大故受光至于戊己</span>  
<span style="margin-left: 2em">太阴面上黑象有二种其一今人人所见黑白异色</span>  
<span style="margin-left: 2em">者是其二小者则日日不同非远镜不能见也详见</span>  
<span style="margin-left: 2em">后论</span>  
<span style="margin-left: 1em">从运动论</span>  
<span style="margin-left: 2em">太阴之运动有二其一一日一周随宗动天行与六</span>  
<span style="margin-left: 2em">曜同公动也其二循白道<sub class="note-yuan">白道月之本道一名月道下文通用</sub>日行十</span>  
<span style="margin-left: 2em">三度有奇迄二十七日有奇而一周本动也因太阳</span>  
<span style="margin-left: 2em">同行二十七日有奇则过周二十七度有奇故又二</span>  
<span style="margin-left: 2em">日有奇乃及于日而与之会</span>  
<span style="margin-left: 2em">白道不与黄道同线而两交于黄道<sub class="note-yuan">两交名正交中交亦名天首天</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">尾亦名龙头龙尾亦名罗计</sub>两半交去黄道五度有奇故每行一</span>  
<span style="margin-left: 2em">周在黄道下者二交初交中是也他详后论</span>  
<span style="margin-left: 1em">时篇第六　十三条</span>  
<span style="margin-left: 1em">既明二曜之体又明二曜之运次因其运动以得时时</span>  
<span style="margin-left: 2em">者何物凡诸有形之物必有变革变革多端中有迁</span>  
<span style="margin-left: 2em">运一端因其迁运先后从而测量剖分之则为时也</span>  
<span style="margin-left: 2em">问草木鸟兽人事皆有变革迁运亦可用以为时何</span>  
<span style="margin-left: 2em">必二曜曰凡立术有三法一须公共一须分明一须</span>  
<span style="margin-left: 2em">永久惟二曜则然他无有足比者故也</span>  
<span style="margin-left: 2em">时之准分尺度一日是也一日者何太阳行一周而</span>  
<span style="margin-left: 2em">过赤道上之一升度弱<sub class="note-yuan">当黄道一度</sub>者是也日之起算有</span>  
<span style="margin-left: 2em">四法或以早或以晚或以昼之中或以夜之中</span>  
<span style="margin-left: 2em">日有大小分大者为昼夜小者为时辰时辰者十二</span>  
<span style="margin-left: 2em">分日之一也<sub class="note-yuan">西历为二十四分之一</sub></span>  
<span style="margin-left: 2em">常静天之上有二大圈皆过两极而分赤道为四平</span>  
<span style="margin-left: 2em">分其一过顶即子午圈其一过东西点<sub class="note-yuan">东西点者赤道交于地平</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">是东西之㝡中</sub>即卯酉圈从卯至午其间又有二圈为辰为</span>  
<span style="margin-left: 2em">巳从午至酉其间又有二圈为未为申此六圈者终</span>  
<span style="margin-left: 2em">古不动凡三曜至某圈上即为某时也<sub class="note-yuan">十二时辰不止日也月所</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">至即为月之十二时星所至即为星之十二时</sub>其起算亦有四法或用子或</span>  
<span style="margin-left: 2em">用午或用卯或用酉</span>  
<span style="margin-left: 2em">时又有刻每时八刻一日则九十六刻东西所同用</span>  
<span style="margin-left: 2em">星官家用百刻取整数易算也</span>  
<span style="margin-left: 2em">刻又析为百分分析为百秒递为百以至微西法每</span>  
<span style="margin-left: 2em">刻为十五分分析为六十秒递分之皆以六十也</span>  
<span style="margin-left: 2em">其积日者以日加之初加为一旬一旬者甲至癸十</span>  
<span style="margin-left: 2em">日再加为一月一月者太阴行一周而与日会也<sub class="note-yuan">称一</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">月者有二义一为二十七日有奇而周于天一为二十九日有奇而及于日因交会之理分明故不用月</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">周而用朔实也</sub>月之分也两分之为朔望四分之为晦朔弦</span>  
<span style="margin-left: 2em">望</span>  
<span style="margin-left: 2em">太阳行一周三百六十五日四分日之一弱为一岁</span>  
<span style="margin-left: 2em">谓之太阳年其起算亦有四法一从冬至一从春分</span>  
<span style="margin-left: 2em"><sub class="note-yuan">测天用之</sub>一从秋分<sub class="note-yuan">论二十八宿起于角亢在秋分后</sub>一从夏至<sub class="note-yuan">古时或用之</sub></span>  
<span style="margin-left: 2em">用太阳年者四年而闰一日为四分之一也四百年</span>  
<span style="margin-left: 2em">而减一闰为弱也</span>  
<span style="margin-left: 2em">凡论岁以太阳为法太阴行十二周为一岁者为其</span>  
<span style="margin-left: 2em">近于太阳年也是谓之太阴年用太阴年者岁积气</span>  
<span style="margin-left: 2em">盈朔虚十日有奇三年一闰为十日故五年再闰十</span>  
<span style="margin-left: 2em">九年七闰为有奇故</span>  
<span style="margin-left: 2em">太阳年之分也二分之为半岁周四分之为四季八</span>  
<span style="margin-left: 2em">分之为分至启闭<sub class="note-yuan">立春立夏为启立秋立冬为闭</sub>十二分之为节二</span>  
<span style="margin-left: 2em">十四分之为节气中气七十二分之为候</span>  
<span style="margin-left: 2em">其积年者以年加之十二年为一纪三十年为一世</span>  
<span style="margin-left: 2em">六十年亦为一纪</span>  
<span style="margin-left: 1em">恒星篇第七</span>  
<span style="margin-left: 1em">向己说常静宗动二天二天之下则恒星天也畧论其</span>  
<span style="margin-left: 2em">凡有四其一为几何其二为貌状其三为能力其四</span>  
<span style="margin-left: 2em">为迁变</span>  
<span style="margin-left: 1em">几何　六条</span>  
<span style="margin-left: 2em">万物中形天为最大大有二义一在上所最远故最</span>  
<span style="margin-left: 2em">大二能力最大故其体亦大</span>  
<span style="margin-left: 2em">其形象为圆球何以知之天体最为精纯无襍最为</span>  
<span style="margin-left: 2em">单独无二圆之为象亦无襍亦无二体性如此故其</span>  
<span style="margin-left: 2em">形象亦当如此又运行最疾者莫如圆体他体则滞</span>  
<span style="margin-left: 2em">碍也</span>  
<span style="margin-left: 2em">其去地最远远之数以地之半径为度最近处得一</span>  
<span style="margin-left: 2em">万四千度自此以上非人思力所及知也此端似为</span>  
<span style="margin-left: 2em">难信证见后篇</span>  
<span style="margin-left: 2em">其所在万物之最上</span>  
<span style="margin-left: 2em">其质最细何以徴之常在上不霣坠知为轻虚细密</span>  
<span style="margin-left: 2em">也其质又极精纯为无他夹襍故</span>  
<span style="margin-left: 1em">貌状　一条</span>  
<span style="margin-left: 2em">天下之物皆以颜色为其美餙颜色之外别有二美</span>  
<span style="margin-left: 2em">餙一为透彻一为光耀也颜色之美美之下分明光</span>  
<span style="margin-left: 2em">之美美之上分何者其形妙好异于他色一也人之</span>  
<span style="margin-left: 2em">见之无不喜悦二也他物不能自见其美惟光能自</span>  
<span style="margin-left: 2em">见三也他物有色惟光能发扬其美妙四也有此四</span>  
<span style="margin-left: 2em">者故为天下真宝天最尊于万物故一切颜色不足</span>  
<span style="margin-left: 2em">为其文餙惟光为其餙矣或云天望之苍苍然苍非</span>  
<span style="margin-left: 2em">色耶何谓无色曰苍苍非色也太空之中气盈其处</span>  
<span style="margin-left: 2em">气亦无色气积极厚则成苍苍之色譬之玻瓈本自</span>  
<span style="margin-left: 2em">透明畧无他色积之数重则成苍色太空中色亦犹</span>  
<span style="margin-left: 2em">此耳</span>  
<span style="margin-left: 1em">能力　四条</span>  
<span style="margin-left: 2em">天之下济其于下土有大能力何以徴之运行一周</span>  
<span style="margin-left: 2em">成为四季凉燠寒暑万物藉为生长收藏一也世间</span>  
<span style="margin-left: 2em">微物无不各有能力稍大则能力称之天如彼其大</span>  
<span style="margin-left: 2em">也知其能力与之等大二也</span>  
<span style="margin-left: 2em">天之能力下及每用二器其一光也其一施也光不</span>  
<span style="margin-left: 2em">独能照天下亦能作热如用洼镜对日而成返照则</span>  
<span style="margin-left: 2em">能生火又用玻瓈圆球对日而成折照亦能出火其</span>  
<span style="margin-left: 2em">故为何光于天下为最尊热于四大物情中<sub class="note-yuan">四大情者一热</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">二冷三燥四湿</sub>亦为最尊以尊生尊是其理也其次亦能生</span>  
<span style="margin-left: 2em">冷亦能生燥亦能生湿为光本非热非冷非燥非湿</span>  
<span style="margin-left: 2em">而其中有精足当四情故能生热生冷生燥生湿也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">如仁中无芽叶花实而其精足当四物故能生四物也</sub>夫光之为体若其发而</span>  
<span style="margin-left: 2em">及物何为施之不尽若其不发则一切所受为从何</span>  
<span style="margin-left: 2em">来故其体其用总非人间意量所及</span>  
<span style="margin-left: 2em">光之外别有施者不属光也此有二证其一海潮大</span>  
<span style="margin-left: 2em">小不因于光亦不因于冷热燥湿譬如磁石吸铁别</span>  
<span style="margin-left: 2em">有相摄相受者则受者为所施摄者为能施也又如</span>  
<span style="margin-left: 2em">怀胎生子七月生则长八月生则殀无不验者此亦</span>  
<span style="margin-left: 2em">非因于光亦非因于四情亦如磁铁有别相摄受者</span>  
<span style="margin-left: 2em">故也</span>

<span style="margin-left: 2em">所及矣</span>  
<span style="margin-left: 1em">迁变　四条</span>  
<span style="margin-left: 2em">凡物迁变首运动</span>  
<span style="margin-left: 2em">天之运动皆环行何者天体单独无二故共运动亦</span>  
<span style="margin-left: 2em">应单独无二环行者单独无二之行也何谓单行曰</span>  
<span style="margin-left: 2em">凡动如人如鸟兽如风皆襍乱无法之行也单行有</span>  
<span style="margin-left: 2em">二一曰垂线一曰圆线石在空中下坠于地此为垂</span>  
<span style="margin-left: 2em">线一切循环无端者皆为圆线垂线之动势尽而止</span>  
<span style="margin-left: 2em">惟圆线独为无穷天以覆函生存下土者也故不能</span>  
<span style="margin-left: 2em">不为无穷不能不为环行矣</span>  
<span style="margin-left: 2em">天之运动恒不去其本所论其各分无一不动而其</span>  
<span style="margin-left: 2em">全体无一分动</span>  
<span style="margin-left: 2em">天之运动有四异其一甚疾一刻分中行几万里如</span>  
<span style="margin-left: 2em">鸟如矢如礟如霹雳皆非所及其二恒平行<sub class="note-yuan">其中迟速别有</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">故实无一不平行者详见后论</sub>若非一一平行即测候之术无从可</span>  
<span style="margin-left: 2em">用其三恒久不已其四万物之动此为首何者天下</span>  
<span style="margin-left: 2em">之动于此焉系故也若无此动即无四季即无生物</span>  
<span style="margin-left: 2em">问运动而外更有迁变乎曰论其体则无变何者为</span>  
<span style="margin-left: 2em">在最上物无及其际者故不能受变于物论其情则</span>  
<span style="margin-left: 2em">有变如月星无光因于日光变而有光一也又如日</span>
