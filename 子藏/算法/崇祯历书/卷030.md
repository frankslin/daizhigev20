## 崇祯历书卷之三十　新法历引

<span style="margin-left: 2em">新法历引<sub class="note-jiao">校：據清刊本補入</sub></span>  
<span style="margin-left: 1em">勅锡通玄教师加二品通政使司通政使掌钦天监印务事臣汤若望删定</span>  
<span style="margin-left: 3em">历学维新</span>  
<span style="margin-left: 1em">历学有法有用法者测各重天之运行体势以审诸曜</span>  
<span style="margin-left: 1em">出入隐现以求本行轨道以定准则也用者取本法测</span>  
<span style="margin-left: 1em">定之分数随方随时以推步日月五星次舍冲照交食</span>  
<span style="margin-left: 1em">凌犯顺逆等情也二者阙一不可然而立法难矣语云</span>  
<span style="margin-left: 1em">毫厘之差千里之谬在历学为尤甚中国自汉迄元造</span>  
<span style="margin-left: 1em">历者七十余辈立法者仅十有三家且皆不免乖违后</span>  
<span style="margin-left: 1em">人难凭致用有谓得一冬至之正时即为密近者非也</span>  
<span style="margin-left: 1em">测冬至之于历术未及百分之一闻一知百世无其人</span>  
<span style="margin-left: 1em">有谓得一岁实一朔实及转终交终等策为已定者非</span>  
<span style="margin-left: 1em">也此皆诸曜平行之率何由遽定视行有谓测率四应</span>  
<span style="margin-left: 1em">可以无忒者非也此不过推算平行之界而已有谓多</span>  
<span style="margin-left: 1em">测交食稽其某法先天某法后天而后汇计筹策折中</span>  
<span style="margin-left: 1em">取之者亦非也历家法数繁琐用以算步交食不下四</span>  
<span style="margin-left: 1em">十余条究竟何项何欵可以折中取半者因知古来修</span>  
<span style="margin-left: 1em">改门户虽岐实则互相依傍间有出一二新意亦未必</span>  
<span style="margin-left: 1em">洞晓本元迹其大端犹不过截前至后通计所差加减</span>  
<span style="margin-left: 1em">乘除分派各岁之下便谓修改已耳即使仅合一时岂</span>  
<span style="margin-left: 1em">能施诸久远后惟授时历庶称精密顾其法亦未尽善</span>  
<span style="margin-left: 1em">在当日已有推食不食食而失推之弊何况沿袭至于</span>  
<span style="margin-left: 1em">今日哉他若回回历者其历元为西域所定使非中历</span>  
<span style="margin-left: 1em">先推太阳躔度至春分之日彼亦茫然无据以得支于</span>  
<span style="margin-left: 1em">以合中国所用岁月也况其历元巳历千年不可复用</span>  
<span style="margin-left: 1em">乎兹惟新法悉本之西洋治历名家曰多禄某曰亚而</span>  
<span style="margin-left: 1em">封所曰歌白泥曰第谷四人者盖西国之于历学师传</span>  
<span style="margin-left: 1em">曹习人自为家而是四家者首为后学之所推重著述</span>  
<span style="margin-left: 1em">既繁测验益密立法致用俱臻至极旅辈采其精详究</span>  
<span style="margin-left: 1em">其奥赜而又参以独得发所未发焉更审今测以广古</span>  
<span style="margin-left: 1em">测必求合天年世互考中西名例半皆仍旧合异归同</span>  
<span style="margin-left: 1em">成书已进</span>  
阙庭新法已行天下用彰  
昭代历典度越前古暨质诸来祀虽亿万年永不爽云  
<span style="margin-left: 3em">地球</span>  
<span style="margin-left: 1em">地在天之中心常静不动与天相较不啻稊米之于乔</span>  
<span style="margin-left: 1em">岳也其形浑圆古谓方者盖指其德耳凡居处地球者</span>  
<span style="margin-left: 1em">其视日景之不同分有五带其中则自赤道南北各以</span>  
<span style="margin-left: 1em">二十三度半为限<sub class="note-yuan">此即二极出地之高</sub>名为煖带居其下者午正</span>  
<span style="margin-left: 1em">立表揆日测景必自射南射北顾每岁必有二日其表</span>  
<span style="margin-left: 1em">无景即春秋二分太阳正过其天顶之日也<sub class="note-yuan">此指正居赤道下者</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">春秋二分目中无景过春分则景在南过秋分则景在北</sub>此带惟一又于其南其北</span>  
<span style="margin-left: 1em">各自二十三度半外各截至六十六度半为限名为温</span>  
<span style="margin-left: 1em">带其下居南者表景恒射南居北者表景恒射北岁有</span>  
<span style="margin-left: 1em">一日其景极短然太阳则不经其天顶矣此带有二以</span>  
<span style="margin-left: 1em">上三带皆太阳每日有出有入者也又于南北二方自</span>  
<span style="margin-left: 1em">六十六度半外各底其极名为冷带其下或表景周围</span>  
<span style="margin-left: 1em">旋转有日太阳绕其地恒见有日太阳绕其地恒隐隐</span>  
<span style="margin-left: 1em">见之候或久至半岁或数月不等此带亦二是为大地</span>  
<span style="margin-left: 1em">共分五带之槩也因此推知距赤道之南北二方其气</span>  
<span style="margin-left: 1em">候必相反如太阳躔星纪宫向北之方为冬至向南之</span>  
<span style="margin-left: 1em">方为夏至春秋二分以及诸节莫不皆然又因此推知</span>  
<span style="margin-left: 1em">地球为人所止以天顶而分四方亦可界为三百六十</span>  
<span style="margin-left: 1em">度以合天行东西为经测以赤道南北为纬测以子午</span>  
<span style="margin-left: 1em"><sub class="note-yuan">规名解见下篇</sub>但测南北者有二极以为之端欲测东西则须</span>  
<span style="margin-left: 1em">先定一所以为起界<sub class="note-yuan">新历悉以京师为起界他方虽未亲测亦据舆图以定其经纬</sub>而</span>  
<span style="margin-left: 1em">后地之经纬皆可得而明焉苟不谙此则无以知幅𢄙</span>  
<span style="margin-left: 1em">相距之数而诸方太阳节气五星经度凌犯交食时刻</span>  
<span style="margin-left: 1em">日食分秒悉无从推步矣<sub class="note-yuan">日食南北东西各不同月食分数皆同但东西不同时耳</sub></span>  
<span style="margin-left: 1em">且不惟是即古测今测岁实之异日出日入昼夜永短</span>  
<span style="margin-left: 1em">之差咸取准于地之纬度所系大矣其可忽诸</span>  
<span style="margin-left: 3em">天道</span>  
<span style="margin-left: 1em">天体浑沦穹然莫辨必也相形酌理判立界限以为依</span>  
<span style="margin-left: 1em">据而后推测之功可施则夫设立诸规以著象数为用</span>  
<span style="margin-left: 1em">甚大且急较为历家首务也新法总有四大规一曰地</span>  
<span style="margin-left: 1em">平一曰赤道一曰黄道一曰子午四规阙一不可盖地</span>  
<span style="margin-left: 1em">平规者从人足所附极目四望之界而设也人附地面</span>  
<span style="margin-left: 1em">所可望见者天之半耳其半恒绕于地下人不可得而</span>  
<span style="margin-left: 1em">见也即此可见不可见之界而诸曜由是而出入明暗</span>  
<span style="margin-left: 1em">昼夜由是而分因设此规剖为四象以应四方象各限</span>  
<span style="margin-left: 1em">以九十度是为地平经度而各曜出入之方位以辨矣</span>  
<span style="margin-left: 1em">又自地平上至天顶设距等圈以为地平纬度而各曜</span>  
<span style="margin-left: 1em">渐升之度以明各曜出地离赤道之纬度并北极出地</span>  
<span style="margin-left: 1em">之数皆可得而稽之矣赤道规者从南北二极相距正</span>  
<span style="margin-left: 1em">中之界而设也古曰天行健又曰天左旋左旋而行健</span>  
<span style="margin-left: 1em">则知南北必有其极矣极也者天体永久不动之两点</span>  
<span style="margin-left: 1em">周天倚为环动之枢者也<sub class="note-yuan">极非星也云极星者盖指其最近极之星以命耳</sub>如</span>  
<span style="margin-left: 1em">一极出地必一极入地其出入之度惟均历家乃于二</span>  
<span style="margin-left: 1em">极相距最中之界设有赤道一规平分天体为南北南</span>  
<span style="margin-left: 1em">者为外为阳而北者为内为阴其亘于天中也终古不</span>  
<span style="margin-left: 1em">易推步者毕赖之为准则无容置议也本规列度三百</span>  
<span style="margin-left: 1em">有六十辰十有二刻九十有六天体一日一周之运于</span>  
<span style="margin-left: 1em">是焉纪昼夜刻分之永短于是焉定黄道出入之广狭</span>  
<span style="margin-left: 1em">于是焉齐春秋二分之晷景于是焉限南北纬算于是</span>  
<span style="margin-left: 1em">焉起大地全圆于是焉度凡此皆其用也黄道规者从</span>  
<span style="margin-left: 1em">太阳旋周一岁之界而设也盖太阳行天一岁所周轨</span>  
<span style="margin-left: 1em">迹旋以成规定名黄道本规斜络于赤道具半在南最</span>  
<span style="margin-left: 1em">南界为冬至其半在北最北界为夏至二道相交之两</span>  
<span style="margin-left: 1em">点为春秋分以故四平分之为象限限各九十度者是</span>  
<span style="margin-left: 1em">即二分二至四正之限也总计为三百六十度十二剖</span>  
<span style="margin-left: 1em">之为宫二十四剖之为节气七十二剖之为候盖用以</span>  
<span style="margin-left: 1em">节七曜列宿之行用以审日月交食之限至较著也子</span>  
<span style="margin-left: 1em">午规者从诸曜升降度适中之界而设也太阳一日旋</span>  
<span style="margin-left: 1em">天一周见于东方渐升至高为正午此地平以上东半</span>  
<span style="margin-left: 1em">昼分过午向西渐底地平是为西半昼分乃谓之降地</span>  
<span style="margin-left: 1em">曜皆然于此升降度之中界立有一规名为子午诸曜</span>  
<span style="margin-left: 1em">际此谓为在子在午是规透过赤道及地平各二极其</span>  
<span style="margin-left: 1em">偕赤道地平而交为直角也恒然不动但人在地面南</span>  
<span style="margin-left: 1em">北迁此规惟一东西迁则随在各异也<sub class="note-yuan">与地平同</sub>已上四规</span>  
<span style="margin-left: 1em">各有本用所系非小历家测候欲求七政行度会望等</span>  
<span style="margin-left: 1em">诸法舍此无从措手以此未言象数先以详明诸规为</span>  
<span style="margin-left: 1em">首务也</span>  
<span style="margin-left: 3em">一系赤道有恒动恒不动二用恒不动者以定各</span>  
<span style="margin-left: 4em">方时刻恒动者以相交相割于黄道也俗谓赤</span>  
<span style="margin-left: 4em">道有二者盖即指此二用非实有二道也</span>  
<span style="margin-left: 3em">二系赤道正居天顶则两极适与地平相当至若</span>  
<span style="margin-left: 4em">赤道斜交地平之所则极出地度数即赤道距</span>  
<span style="margin-left: 4em">天顶度数矣其经度即过极圈纬度即距等圈</span>  
<span style="margin-left: 4em">也</span>  
<span style="margin-left: 3em">三系黄道与赤道斜交故其极自有本极谓之黄</span>  
<span style="margin-left: 4em">极黄极者恒星与太阳本行之枢也论二道最</span>  
<span style="margin-left: 4em">远之距<sub class="note-yuan">即南至北至之距</sub>今古不同今测定为天度二</span>  
<span style="margin-left: 4em">十三度三十一分三十秒上古较多数十分后</span>  
<span style="margin-left: 4em">此则渐减矣</span>  
<span style="margin-left: 3em">四系周天诸道用立多规以便测验但其为规也</span>  
<span style="margin-left: 4em">非止旋周一线而已盖一满平圆面也面为各</span>  
<span style="margin-left: 4em">曜之所经行故谓之道某曜在某面上即谓之</span>  
<span style="margin-left: 4em">在某道云</span>  
<span style="margin-left: 3em">历元</span>  
<span style="margin-left: 1em">所谓历元者乃以诸曜之平行同时而求各所历数历</span>  
<span style="margin-left: 1em">家因之用为起算之根也新法则以天聪戊辰前太阳</span>  
<span style="margin-left: 1em">过天正冬至后第一子正为历元其日干则己卯也斯</span>  
<span style="margin-left: 1em">时太阳躔星纪宫初度五十三分太阴在六宫初度五</span>  
<span style="margin-left: 1em">十分他曜皆以此时行度为准不用冬至时刻与旧历</span>  
<span style="margin-left: 1em">异缘冬至有正有平最难得其真率也夫历元为诸算</span>  
<span style="margin-left: 1em">先资稍有舛忒即诸行皆谬矣况诸曜终岁细行莫不</span>  
<span style="margin-left: 1em">以子正起算又安用冬至时刻为哉</span>  
<span style="margin-left: 3em">历算</span>  
<span style="margin-left: 1em">旧以周天判为三百六十五度又四分度之一所谓日</span>  
<span style="margin-left: 1em">度也盖以太阳之行黄道日一度度析百分分析百秒</span>  
<span style="margin-left: 1em">且又均之分为宫次气候法用奇零势难齐一且天度</span>  
<span style="margin-left: 1em">者岁实之日分也中历所用岁实诸家多寡不等是其</span>  
<span style="margin-left: 1em">分天非一定之术而为游移之法欲以是决定诸曜之</span>  
<span style="margin-left: 1em">行岂不难乎若天新法之分周天历度也即于天度以</span>  
<span style="margin-left: 1em">三百六十平剖之度析六十分分析六十秒盖六十者</span>  
<span style="margin-left: 1em">半之则为三十三之一则二十四之一则十五余任剖</span>  
<span style="margin-left: 1em">析皆为自然而然之分往古历纪未始繁载但于测得</span>  
<span style="margin-left: 1em">之数曰某度几何分之一而已错综离合其于历算甚</span>  
<span style="margin-left: 1em">便也请言历算夫历之为数袛就天行无假淹贯九章</span>  
<span style="margin-left: 1em">而其所须用者加减乘除开方五法古用觚棱近便珠</span>  
<span style="margin-left: 1em">算西法第资毫颕今复有算筹之创简捷尤甚矣所谓</span>  
<span style="margin-left: 1em">加法者以类相比并多分以成全如度并度分并分秒</span>  
<span style="margin-left: 1em">并秒时刻并时刻是也此须知定位及进位之法如积</span>  
<span style="margin-left: 1em">六十秒为一分积六十分为一度秒进于分之位分进</span>  
<span style="margin-left: 1em">于度之位而与他度分秒并之若加时刻则以十五分</span>  
<span style="margin-left: 1em">进一刻四刻进一时二十四时进一日二十四西法谓</span>  
<span style="margin-left: 1em">之小时也此加法也减与加反用稽所余其法先须较</span>  
<span style="margin-left: 1em">数多寡多中减寡理数易明若于少内减多必立借法</span>  
<span style="margin-left: 1em">以通其变如借度化分借分化秒为本类以用之乘法</span>  
<span style="margin-left: 1em">者九九互积之义有实数有法数凡单数乘度分秒不</span>  
<span style="margin-left: 1em">变位若度乘度复生多度分乘分以生秒秒乘秒以生</span>  
<span style="margin-left: 1em">微则皆变位<sub class="note-yuan">分秒相生皆指奇零而言</sub>此不可不知也除法者以少</span>  
<span style="margin-left: 1em">剖多分分除减意也为法有二或以单数商除亦不变</span>  
<span style="margin-left: 1em">位苟分度不尽即以余度化分除之分秒亦然开方者</span>  
<span style="margin-left: 1em">以化法求其微数用筹乘除然后再受为度或用三率</span>  
<span style="margin-left: 1em">法亦可是五法者尽历算矣然而新历之算诸星经纬</span>  
<span style="margin-left: 1em">及交食等项也盖有二术其一取所图各宿曜本行规</span>  
<span style="margin-left: 1em">之半径并其所设某日平行<sub class="note-yuan">即本圈上之弧</sub>用诸三角形法推</span>  
<span style="margin-left: 1em">演乃可得经纬细行或交食之分数时刻此术最为缜</span>  
<span style="margin-left: 1em">密果能精心于此即诸天周行轨迹隐微罔不洞然其</span>  
<span style="margin-left: 1em">二以先所推定诸表握算设如某日某刻欲求太阳经</span>  
<span style="margin-left: 1em">度则第用加减二法检表二三次以求即可得其宫度</span>  
<span style="margin-left: 1em">较之中历节气求经朔之法简便数倍余如五星太阴</span>  
<span style="margin-left: 1em">等曜以及交食皆各有表可稽火星兼用乘除他则但</span>  
<span style="margin-left: 1em">资加减立法虽难致用则易然而一趋超径万一操觚</span>  
<span style="margin-left: 1em">小失恐并迷昧元初之理所以二术不可偏废皆为推</span>  
<span style="margin-left: 1em">步家之所朝夕从事者也</span>  
<span style="margin-left: 3em">句股</span>  
<span style="margin-left: 1em">句股之术从来尚矣古九章周髀载之究不过一三边</span>  
<span style="margin-left: 1em">直角形而已垂线为股横线为句斜线为弦测量家立</span>  
<span style="margin-left: 1em">表代股平圭代句而景为其弦善斯术者高深广远无</span>  
<span style="margin-left: 1em">不可求而测天之为用尤大然而旧法虽有三元五和</span>  
<span style="margin-left: 1em">五较等用不过设二求三且泥于直角一形若遇斜角</span>  
<span style="margin-left: 1em">弧角无以措用矣新法变而通之既名其公曰三角形</span>  
<span style="margin-left: 1em">又审其平面球面曲线杂线锐角钝角之别即知天为</span>  
<span style="margin-left: 1em">圜体宜测以弧宿曜近远诸道互交宜测以多类之弧</span>  
<span style="margin-left: 1em">遂生多类之三弧形于是各形咸备有三弧三角互设</span>  
<span style="margin-left: 1em">三以求余三是谓以圆齐圆于法为善故虽天道隐微</span>  
<span style="margin-left: 1em">象数零杂未有能遁焉者也</span>  
<span style="margin-left: 3em">割圆</span>  
<span style="margin-left: 1em">割圜古法亦即以圜求圜之意但古法设弧以求弦矢</span>  
<span style="margin-left: 1em">欵目四十余项颇为艰繁新法易之以表开卷即得盖</span>  
<span style="margin-left: 1em">因圜形之弧与角总代以直线数种稽其数名为八线</span>  
<span style="margin-left: 1em">表云夫圜形半径为本规六平分之通弦若二半径各</span>  
<span style="margin-left: 1em">自乘之并而开方可得本规四平分之通弦用几何诸</span>  
<span style="margin-left: 1em">法又可得各度分之通弦其各弧及其通弦折半乃得</span>  
<span style="margin-left: 1em">正弦正弧有弦弧即有其矢矣故天不另立表也通弦</span>  
<span style="margin-left: 1em">之外有切线割线通弦全在规内切线全在规外线从</span>  
<span style="margin-left: 1em">规心出于规周之外则为割线然而弧有正有余弦矢</span>  
<span style="margin-left: 1em">切割四者因亦各有正余如一象限为本表之限或于</span>  
<span style="margin-left: 1em">限内取几何度谓为正弧其或逾九十度者即谓之余</span>  
<span style="margin-left: 1em">矣正余各有弦矢割切四线都为八线也</span>  
<span style="margin-left: 3em">恒星</span>  
<span style="margin-left: 1em">恒星亦名列星亦名经星云恒者谓其象终古不易也</span>  
<span style="margin-left: 1em">云经者以别于五纬南北行之义其数甚伙莫能穷尽</span>  
<span style="margin-left: 1em">就中有光体渺微非目可及非仪可测者畧而不录其</span>  
<span style="margin-left: 1em">在等第之内已经新法测定者南北二极共一千七百</span>  
<span style="margin-left: 1em">二十有五星稽其大小分为六等第一等大星如五帝</span>  
<span style="margin-left: 1em">座织女类者一十有七二等如帝星开阳类者五十有</span>  
<span style="margin-left: 1em">七三等如太子少卫类者八十有五四等如上将柱史</span>  
<span style="margin-left: 1em">类者三百八十有九五等如上相虎贲类者三百二十</span>  
<span style="margin-left: 1em">有三六等如天皇大帝后宫类者二百九十有五此皆</span>  
<span style="margin-left: 1em">有名之星计共一千一百六十有六余皆无名者矣至</span>  
<span style="margin-left: 1em">于天汉斜络天体古昔多谬解迩来窥以远镜知是无</span>  
<span style="margin-left: 1em">算小星接攅一带即如积尸气等亦小星攅聚以成第</span>  
<span style="margin-left: 1em">非人目所能辨遂作如是观耳小者不足论论其大者</span>  
<span style="margin-left: 1em">古历以周天诸星分为三垣二十八宿各定有名位座</span>  
<span style="margin-left: 1em">次每座每宿星数多寡不齐顾其所谓宿者盖取七曜</span>  
<span style="margin-left: 1em">经行止宿之义且用以便测算经度又为其各能主施</span>  
<span style="margin-left: 1em">德也西古历亦列二十八舍所定二十八距星皆与中</span>  
<span style="margin-left: 1em">古脗合第觜距西用天关为小异耳此二十八宿者各</span>  
<span style="margin-left: 1em">以一字命名分注每日之下内以房虚星昂四宿为属</span>  
<span style="margin-left: 1em">太阳之日心危毕张为属太阴之日此外五纬各属四</span>  
<span style="margin-left: 1em">宿每以七日为期每日各属一宿西历亦然西经传上</span>  
<span style="margin-left: 1em">古有一大师名诺厄者广宣历理以遍万国则亦有所</span>  
<span style="margin-left: 1em">本也</span>  
<span style="margin-left: 3em">一系星之命名多系借义非可过泥虚名便谓实</span>  
<span style="margin-left: 4em">有其验比如贯索一星中以其象囹圄名以贯</span>  
<span style="margin-left: 4em">索西以其象冠冕名以冠冕一吉一凶全由人</span>  
<span style="margin-left: 4em">意岂天星实然乎至谓诸星情性不同旉施互</span>  
<span style="margin-left: 4em">异是又理所必然不得槩置弗论也故总图于</span>  
<span style="margin-left: 4em">某星属某纬者咸附注之</span>  
<span style="margin-left: 3em">二系图星之法有二一浑球有南北二极有地平</span>  
<span style="margin-left: 4em">子午诸规界判黄赤二道运之能肖天体旋转</span>  
<span style="margin-left: 4em">以审各星经纬度分以辨星中出没以测夜时</span>  
<span style="margin-left: 4em">甚便也一平面图虽乏以上诸用然诸星位置</span>  
<span style="margin-left: 4em">宫度瞭若视掌为用亦大因有多种之分曰见</span>  
<span style="margin-left: 4em">界图以北极为心其最南隐于地中星极非此</span>  
<span style="margin-left: 4em">方人目可见者则截出之一曰赤道图黄道图</span>  
<span style="margin-left: 4em">二者各以其极为心其道为界盖皆以天之南</span>  
<span style="margin-left: 4em">北平剖为二图者也曰分星图依黄道分天为</span>  
<span style="margin-left: 4em">二十图均赋经纬署以维辰按图指陈天象莫</span>  
<span style="margin-left: 4em">晰于此外有浑盖所用天盘以极为心截冬至</span>  
<span style="margin-left: 4em">规为界亦图星于仪上肖天运动以觇诸星出</span>  
<span style="margin-left: 4em">没升降又有平仪从二极剖天为南六宫北六</span>  
<span style="margin-left: 4em">宫二面亦绘辰宿可代浑仪旋转至若古传星</span>  
<span style="margin-left: 4em">经图步天歌等虽亦分有宿座便于观览而经</span>  
<span style="margin-left: 4em">纬度分悉皆茫然挂漏于测候无用也</span>  
<span style="margin-left: 3em">星中出没</span>  
<span style="margin-left: 1em">太阳右旋一日一度终岁行天一周必复与某恒星合</span>  
<span style="margin-left: 1em">又必有某星与之冲历家无从测其合者测得其冲者</span>  
<span style="margin-left: 1em">谓为岁差所从来矣然由本方极出地度恒星有出没</span>  
<span style="margin-left: 1em">者亦有不出不没者如京师北极出地四十度则星距</span>  
<span style="margin-left: 1em">极四十度以外皆为恒见而距南极四十度以内者在</span>  
<span style="margin-left: 1em">京皆不能见矣至论恒星见伏亦由太阳右旋至某宿</span>  
<span style="margin-left: 1em">度附近之星光为日夺故不能见迨太阳去离渐远则</span>  
<span style="margin-left: 1em">此星光渐升东方见而不伏矣缘是而升至午点即曰</span>  
<span style="margin-left: 1em">中星此其星中出没在立象学为用甚距而历家但于</span>  
<span style="margin-left: 1em">中夜资之以定时刻而已</span>  
<span style="margin-left: 3em">日轨</span>  
<span style="margin-left: 1em">太阳之行黄道也论其积岁平分之数新法以天度计</span>  
<span style="margin-left: 1em">为五十九分八秒有奇所谓平行度分是也然平行齐</span>  
<span style="margin-left: 1em">而实行则固非齐矣冬盈而夏缩矣所以然者盖缘黄</span>  
<span style="margin-left: 1em">道圈与日轮天不同心而黄道之心即地球心是日轮</span>  
<span style="margin-left: 1em">天与地球不同心也心既不同则日行距地近远不等</span>  
<span style="margin-left: 1em">距近即行疾疾则所行之度过于平行而为盈每冬月</span>  
<span style="margin-left: 1em">一日计行一度一分有奇以较平行盈二分矣距远即</span>  
<span style="margin-left: 1em">行迟迟则所行之度不及平行而为缩每夏月一日计</span>  
<span style="margin-left: 1em">行五十七分有奇以较平行则缩二分矣盈缩相差若</span>  
<span style="margin-left: 1em">此岂可谓之齐乎终岁之间但逢最高限最卑限二日</span>  
<span style="margin-left: 1em">平实二行度数惟一此外两行之较日日不等新法因</span>  
<span style="margin-left: 1em">其或过或不及也故有加分减分谓之加减差盖以有</span>  
<span style="margin-left: 1em">恒率之平行为根而以加减差定之然后差而不差非</span>  
<span style="margin-left: 1em">齐而齐矣至论太阳之入某宫次以分节气也亦有平</span>  
<span style="margin-left: 1em">实二算盖算平行十五日二十一刻有奇为一节气乃</span>  
<span style="margin-left: 1em">一岁二十四平分之一耳若用躔度之日以算则冬夏</span>  
<span style="margin-left: 1em">不齐冬一节气为十四日八十四刻有奇夏一节气为</span>  
<span style="margin-left: 1em">十五日七十二刻有奇总由夏迟冬疾故其差如此皆</span>  
<span style="margin-left: 1em">非旧历之所解也</span>  
<span style="margin-left: 3em">系太阳天距地极远之点谓之最高极近之点谓</span>  
<span style="margin-left: 4em">之最高冲<sub class="note-yuan">亦名最卑</sub>此二点者乃盈缩二行之界古</span>  
<span style="margin-left: 4em">法于冬夏二至谓其恒在一点其实非也按古</span>  
<span style="margin-left: 4em">今诸测皆各不齐古测最高在夏至前数度今</span>  
<span style="margin-left: 4em">则在后六度矣以此推知一年之内太阳自行</span>  
<span style="margin-left: 4em">四十五秒也</span>  
<span style="margin-left: 3em">年月</span>  
<span style="margin-left: 1em">纪年者何太阳随列宿东行旋天一周之期也太阳之</span>  
<span style="margin-left: 1em">行界二其一从某宫次度分行天一周而复于元度其</span>  
<span style="margin-left: 1em">数为三百六十五日二十四刻二十一分有奇其一为</span>  
<span style="margin-left: 1em">太阳会于列宿天之某星行天一周而复与元星会但</span>  
<span style="margin-left: 1em">其星每岁有本行故须加本行以定岁而其所须加者</span>  
<span style="margin-left: 1em">新法定为五十一秒所谓岁差也然而日历纪年惟以</span>  
<span style="margin-left: 1em">全日推算不用小余如以太阳十二次会合太阴为岁</span>  
<span style="margin-left: 1em">也为三百五十四日每二年三年而闰一月中历是已</span>  
<span style="margin-left: 1em">如以太阳周十二宫次为岁也为三百六十五日每四</span>  
<span style="margin-left: 1em">年而闰一日西历是已此纪年之槩也纪月有二或因</span>  
<span style="margin-left: 1em">太阴会朔一次以定谓太阴之月或因太阳行一宫次</span>  
<span style="margin-left: 1em">以定谓太阳之月顾其十二分年之一分则一也一月</span>  
<span style="margin-left: 1em">之终分有大尽小尽者比如初朔子正苟二朔者过二</span>  
<span style="margin-left: 1em">十九日外而不及第三十日之子正则谓之小过子正</span>  
<span style="margin-left: 1em">则谓之大大则二朔同一天干小则不同矣故有三十</span>  
<span style="margin-left: 1em">日弱时刻不及者历家不得名大或二十九日强而时</span>  
<span style="margin-left: 1em">刻已逾者历家仍不得名小也且宇内地度不同而月</span>  
<span style="margin-left: 1em">之大小因以互异比如京师第二朔在子初二刻未到</span>  
<span style="margin-left: 1em">子正其月为小而西安此朔则已在子正初刻又当为</span>  
<span style="margin-left: 1em">大尽矣地度愈远时刻愈差非可强而同之也月有闰</span>  
<span style="margin-left: 1em">者太阳躔一宫之时与月会合二次以成者也其月因</span>  
<span style="margin-left: 1em">无中气故谓之闰但古法置闰用平节气而新法用太</span>  
<span style="margin-left: 1em">阳所躔天度节气故闰有合有否或先后一月不等也</span>  
<span style="margin-left: 3em">昼夜晨昏</span>  
<span style="margin-left: 1em">太阳随宗动天西行一周而复于元界谓之一日东升</span>  
<span style="margin-left: 1em">西降循环无端其在历家起算判定一界以为依据则</span>  
<span style="margin-left: 1em">恒以太阳在子在午为准也论从子午起算之日每岁</span>  
<span style="margin-left: 1em">实行度分日日不等差较一刻有余盖缘黄道夏迟冬</span>  
<span style="margin-left: 1em">疾差余四分而黄赤二道又广狭异距则率度必不同</span>  
<span style="margin-left: 1em">分此其所当审者也今论昼夜太阳在地平上人目可</span>  
<span style="margin-left: 1em">得而覩谓之昼太阳渐隐地平之下人目无见则谓之</span>  
<span style="margin-left: 1em">夜是昼夜者全由人居以分随方<sub class="note-yuan">极出地若干</sub>随时<sub class="note-yuan">太阳躔某宫</sub></span>  
<span style="margin-left: 1em">其昼夜刻分皆可依法推算焉然而法算与目见恒异</span>  
<span style="margin-left: 1em">盖太阳体大算法皆以体心出地为昼始而人目以一</span>  
<span style="margin-left: 1em">见日轮即为昼始又日出没升降度有斜正不同又地</span>  
<span style="margin-left: 1em">平各曜出没之界受清蒙气有变凡此皆非人目能辨</span>  
<span style="margin-left: 1em">故历家立有视差法也一昼一夜平分为十二时时各</span>  
<span style="margin-left: 1em">八刻一日十二时共刻九十有六此恒率也其昼夜永</span>  
<span style="margin-left: 1em">短递迁之故则不但日行南陆北陆不同而已亦由北</span>  
<span style="margin-left: 1em">极出地高卑互异而永短因焉比如赤道正过天顶之</span>  
<span style="margin-left: 1em">地两极合于地平其昼夜均停绝无永短又极在天顶</span>  
<span style="margin-left: 1em">赤道与地平平行其下昼夜亦无长短之较但太阳百</span>  
<span style="margin-left: 1em">八十日恒见百八十日恒隐耳此外诸方各有永短顾</span>  
<span style="margin-left: 1em">其一岁之中昼夜均停者四日握算者引而伸之据四</span>  
<span style="margin-left: 1em">日之一日逐渐加减因得九十日之昼夜长短随可以</span>  
<span style="margin-left: 1em">推终岁之数也再论晨昏是分昼分夜之二界也太阳</span>  
<span style="margin-left: 1em">将出未出数刻之前其光东发星光渐为所夺是名为</span>  
<span style="margin-left: 1em">晨太阳已入回光返照亦经数刻始逌然灭尽是名为</span>  
<span style="margin-left: 1em">昏其久暂分数亦因冬夏而分短长新法以日在地平</span>  
<span style="margin-left: 1em">下十八度内为晨昏之限但太阳行此十八度又各方</span>  
<span style="margin-left: 1em">各宫不等因有五刻七刻十刻之别若论极高七十二</span>  
<span style="margin-left: 1em">度以上之度则夏月晨昏相切虽至丙夜无甚黯黑也</span>  
<span style="margin-left: 3em">太阴</span>  
<span style="margin-left: 1em">太阴之行参错不一推步筹算为力倍艰苟或分秒乖</span>  
<span style="margin-left: 1em">违交食岂能密合故必细审其行度所以然而后可立</span>  
<span style="margin-left: 1em">法致用也盖月较诸曜本旋之外行复多种第一曰平</span>  
<span style="margin-left: 1em">行一日十三度有奇但此行之界凡四一界是从某官</span>  
<span style="margin-left: 1em">次度分起算此界定而不动二界为本天之最高此非</span>  
<span style="margin-left: 1em">定界每日自顺天右行七分有奇是月距本天最高一</span>  
<span style="margin-left: 1em">日为十三度三分有奇也故其平行二十七日三十刻</span>  
<span style="margin-left: 1em">有奇为一周已复于宫次元度又必再行二十三刻有</span>  
<span style="margin-left: 1em">奇为二十七日五十三刻始能及于本天之最高此行</span>  
<span style="margin-left: 1em">新法谓之月自行中历于此周谓之转周满一周谓之</span>  
<span style="margin-left: 1em">转终其最高则行八年有奇而周天谓之月孛三界为</span>  
<span style="margin-left: 1em">黄白二道相交之所所谓正交中交此界亦自有行乃</span>  
<span style="margin-left: 1em">逆行也<sub class="note-yuan">自东而西</sub>每日三分有奇则月平行距正交一日为</span>  
<span style="margin-left: 1em">十三度十三分有奇至二十七日二十七刻减交行之</span>  
<span style="margin-left: 1em">一度二十三分得二十七日十五刻有奇月乃回于元</span>  
<span style="margin-left: 1em">界历谓之交终四界是与太阳去离太阳一日约行一</span>  
<span style="margin-left: 1em">度则太阴距太阳为十二度十分有奇至二十九日五</span>  
<span style="margin-left: 1em">十三刻有奇逐及太阳复与之会历谓朔策是也凡上</span>  
<span style="margin-left: 1em">四行总归第一平行其第二行曰小轮每一朔内行满</span>  
<span style="margin-left: 1em">轮周二次每日为二十四度有奇<sub class="note-yuan">若以不同心圈论此即太阴中距圈也</sub></span>  
<span style="margin-left: 1em">因有此行复生第二损益加减分云第二者盖于朔望</span>  
<span style="margin-left: 1em">所用加减分外再加再减故也此行中历所无以上太</span>  
<span style="margin-left: 1em">阴诸行新法定其轨辙不外三者均圈一不同心圈一</span>  
<span style="margin-left: 1em">小轮一然不同心圈与小轮名异而理实同历家资以</span>  
<span style="margin-left: 1em">推算两用互推所得之数正等也</span>  
<span style="margin-left: 3em">一系月道惟一古谓月行九道者乃白道正交行</span>  
<span style="margin-left: 4em">及四正阴阳二历各异命之因有八名加以公</span>  
<span style="margin-left: 4em">名共有九耳非真有九道也白道两交黄道论</span>  
<span style="margin-left: 4em">最远之距谓为五度此系二历未甚大差之数</span>  
<span style="margin-left: 4em">新法测得凡朔望外相距皆过五度上下二弦</span>  
<span style="margin-left: 4em">则为五度一十七分三十秒推知二道相交之</span>  
<span style="margin-left: 4em">角非定而不动者要其广狭之行恒以十五日</span>  
<span style="margin-left: 4em">为限也</span>  
<span style="margin-left: 3em">二系合朔后月夕西见迟疾不一甚有差至三日</span>  
<span style="margin-left: 4em">者其故有三一因月视行度视行为疾段则疾</span>  
<span style="margin-left: 4em">见迟段则迟见一因黄道升降或斜或正正必</span>  
<span style="margin-left: 4em">疾见斜必迟见一因白道在纬南纬北凡在阴</span>  
<span style="margin-left: 4em">历疾见阳历迟见也此外又有极出地之不同</span>  
<span style="margin-left: 4em">朦胧分与炁差诸异所以迟疾难齐也</span>  
<span style="margin-left: 3em">交食</span>  
<span style="margin-left: 1em">凡日月之行二十九日有奇而东西同度谓之会朔至</span>  
<span style="margin-left: 1em">若日行在黄道近交人视为与日同经同纬是人目与</span>  
<span style="margin-left: 1em">月日相参直而月魄正隔日光于人目则为日食日食</span>  
<span style="margin-left: 1em">者非日失其光光为月掩耳凡太阴距太阳百八十度</span>  
<span style="margin-left: 1em">而正与之冲谓之望若当冲时月行近于两交必入地</span>  
<span style="margin-left: 1em">景而为暗虚此乃月日同在一线而地居其中间日光</span>  
<span style="margin-left: 1em">为地所阻不能射照月体则月失其光而为月食此日</span>  
<span style="margin-left: 1em">月二食者躔度有恒持筹推步分秒确然而历家各法</span>  
<span style="margin-left: 1em">之疎密于此更难掩也试言其畧黄白二道相交之二</span>  
<span style="margin-left: 1em">所名正交中交凡日月行及二交为同度同度则有食</span>  
<span style="margin-left: 1em">矣然而论交又须论限及交而在限内则食限外则不</span>  
<span style="margin-left: 1em">食此不可不审也顾限度诸方不一盖太阳于诸方之</span>  
<span style="margin-left: 1em">地平高度不同而阴阳二历之各限亦异论煖带下之</span>  
<span style="margin-left: 1em">地二历互相受变如白道向南极半周有时在天顶及</span>  
<span style="margin-left: 1em">黄道之中势必反谓为阴历白道向北平周是时在黄</span>  
<span style="margin-left: 1em">道外势必反谓为阳历故其下日食之限莫得而定之</span>  
<span style="margin-left: 1em">也他域更近于北必阴历限多阳历限少更近于南必</span>  
<span style="margin-left: 1em">阳历限多阴历限少比如京师近北约算阳历八度阴</span>  
<span style="margin-left: 1em">历二十一度则知日月相会凡在阳历近二交八度在</span>  
<span style="margin-left: 1em">阴历近二交二十一度其下必见日食而过此限以往</span>  
<span style="margin-left: 1em">则否即北可以推南莫不以远近分多寡矣然而二历</span>  
<span style="margin-left: 1em">食限之度有异者其故盖在月轮月轮比日最近于地</span>  
<span style="margin-left: 1em">而月又小于地人目见月之所又在地面不在地心故</span>  
<span style="margin-left: 1em">以月天论地平虽天与地球皆为平分直过其心而人</span>  
<span style="margin-left: 1em">在地面高所以视天地之两界则似地球与月天非平</span>  
<span style="margin-left: 1em">分也少半在上多半在下而差约一度故以本法推算</span>  
<span style="margin-left: 1em">月已出正地平其于人目所视之地平尚少一度此其</span>  
<span style="margin-left: 1em">较谓之视差盖惟月在天顶正地平与视地平之极皆</span>  
<span style="margin-left: 1em">以一直线合于天顶无有视差过此左右不免有差愈</span>  
<span style="margin-left: 1em">远天顶愈近地平差必愈甚夫视差无他恒降下月体</span>  
<span style="margin-left: 1em">数十分耳设令日月同度同在近交之南又因同度并</span>  
<span style="margin-left: 1em">在正地平上高二十度则太阳于视地平为十九度五</span>  
<span style="margin-left: 1em">十八分祗降二分太阴于视地平为十九度直降一度</span>  
<span style="margin-left: 1em">矣而日月二差之较为五十八分故以算论虽二曜同</span>  
<span style="margin-left: 1em">高同度而人目视之太阴恒下于太阳一度弱不掩日</span>  
<span style="margin-left: 1em">光则不食若二曜在地平上高七十度则太阳无视差</span>  
<span style="margin-left: 1em">太阴视差止二十分其降于太阳亦止二十分势必相</span>  
<span style="margin-left: 1em">切或至掩数分而成食若二曜在交北又当以太阴算</span>  
<span style="margin-left: 1em">在太阳之上庶因视差所降而掩阳光以为食也顾此</span>  
<span style="margin-left: 1em">二地平之差又分二类一加减交食分数谓之气差一</span>  
<span style="margin-left: 1em">加减时刻谓之时差历算之艰且剧莫过于此所最当</span>  
<span style="margin-left: 1em">究心者也</span>  
<span style="margin-left: 3em">系日食之全与不全其故有二一由天上之行一</span>  
<span style="margin-left: 4em">由食时地平上高弧之度故均一食也有见全</span>  
<span style="margin-left: 4em">食者有见食多寡不等者有全不见食者就南</span>  
<span style="margin-left: 4em">北论见食地界设如北京见全食其南北谷距</span>  
<span style="margin-left: 4em">四十五度之地为万一千有余里皆见有食然</span>  
<span style="margin-left: 4em">而多寡不等就东西论各距六十度为万五千</span>  
<span style="margin-left: 4em">有余里各见食而分数多寡亦不等焉即月食</span>  
<span style="margin-left: 4em">时刻南北亦有不同而东西为甚也</span>  
<span style="margin-left: 3em">三余</span>  
<span style="margin-left: 1em">三余旧加紫气名为四余亦谓之四隐曜然详求天行</span>  
<span style="margin-left: 1em">实无紫气且绝无当于推步之术故西法弃而不录第</span>  
<span style="margin-left: 1em">取三余一罗㬋一计都一月孛罗㬋即白道之正交计</span>  
<span style="margin-left: 1em">都即中交也月道自南溯北以交于黄道之一点此点</span>  
<span style="margin-left: 1em">有本行每日左旋三分有奇而罗㬋正对之点即为计</span>  
<span style="margin-left: 1em">都盖两规斜络其两交之二点必正相对也月孛是月</span>  
<span style="margin-left: 1em">所行圈极高极远之点谓月离于是其行极迟其体见</span>  
<span style="margin-left: 1em">极小盖孛云者指其交转两行相悖之义故其平行右</span>  
<span style="margin-left: 1em">旋每日七分有奇是三点者土木火诸星本圈亦有之</span>  
<span style="margin-left: 1em">名义皆同第其各行不同耳古历悉所未谙悉置不推</span>  
<span style="margin-left: 1em">不录新法用算五星之纬故于本历名详其名数云独</span>  
<span style="margin-left: 1em">惜日者之流以罗计月孛等名皆指为星谓其所躔宿</span>  
<span style="margin-left: 1em">度各有吉凶用以推人禄命不知周天诸道诸点皆人</span>  
<span style="margin-left: 1em">所设以便揆算其行度耳并非实物何与吉凶至紫气</span>  
<span style="margin-left: 1em">一曜或谓生于闰余或谓土木相会或谓古人以是纪</span>  
<span style="margin-left: 1em">直年宿故二十八年而一周天都无义理可考故月离</span>  
<span style="margin-left: 1em">历指详论其必无是曜也</span>  
<span style="margin-left: 3em">五纬异行</span>  
<span style="margin-left: 1em">土木火金水五曜名为纬星者谓其日有近南近北之</span>  
<span style="margin-left: 1em">行与恒星异也夫五纬之行各有二种其一为本行如</span>  
<span style="margin-left: 1em">填星约三十年行天一周日二分岁星约十二年一周</span>  
<span style="margin-left: 1em">天日五分荧惑将满二年一周天日三十五分太白辰</span>  
<span style="margin-left: 1em">星皆随太阳每年旋天一周各有盈缩各有加减分各</span>  
<span style="margin-left: 1em">有本天之最高与最冲即其最高又各有本行论其行</span>  
<span style="margin-left: 1em">界亦分四种非若回回历总一最高也其二在于本行</span>  
<span style="margin-left: 1em">之外西法称为歳行盖各星会太阳一次成一周也因</span>  
<span style="margin-left: 1em">此岁行之规<sub class="note-yuan">亦名小轮</sub>推知各星顺逆留疾诸情故依新法</span>  
<span style="margin-left: 1em">图五纬各有一不同心圈一均圈一小轮凡星在小轮</span>  
<span style="margin-left: 1em">极远之所必合太阳其行顺而疾其体见小凡在小轮</span>  
<span style="margin-left: 1em">极近之所其行逆而疾其体见大土木火行逆则冲太</span>  
<span style="margin-left: 1em">阳金水行逆夕伏而合行顺晨伏而合其各顺行转逆</span>  
<span style="margin-left: 1em">逆行转顺之两中界为留留非不行乃际于极迟行之</span>  
<span style="margin-left: 1em">所也留段前后或顺或逆皆有迟行其土木火行逆即</span>  
<span style="margin-left: 1em">冲太阳而金水则否者缘土木火之本天大皆以太阳</span>  
<span style="margin-left: 1em">为心而包地得与太阳冲而金水之本天虽亦以太阳</span>  
<span style="margin-left: 1em">为心而不包地不能冲太阳也金水不能冲太阳而能</span>  
<span style="margin-left: 1em">与之离金离太阳四十八度水离二十四度</span>  
<span style="margin-left: 3em">五纬纬行</span>  
<span style="margin-left: 1em">太阳之行因黄道斜交于赤道故其距赤道之纬南纬</span>  
<span style="margin-left: 1em">北也各二十三度有半以成二至是黄道者太阳之轨</span>  
<span style="margin-left: 1em">迹也太阴本道又斜交于黄道最远之距为五度以生</span>  
<span style="margin-left: 1em">阴阳二历五星之道虽相距纬度各异而其斜络黄道</span>  
<span style="margin-left: 1em">则与月道同理故皆借月道诸名名之其两交之所亦</span>  
<span style="margin-left: 1em">谓正交中交其在南在北两半周亦谓阴阳二历审是</span>  
<span style="margin-left: 1em">而五星纬行庶可详求矣盖各本道外之岁行小轮恒</span>  
<span style="margin-left: 1em">与黄道为平行而又斜交于本道其上半恒在黄本二</span>  
<span style="margin-left: 1em">道中凡道躔于此则减本道之纬其下半恒在本道外</span>  
<span style="margin-left: 1em">星躔于此则加其纬然此小轮之纬向则恒不变如土</span>  
<span style="margin-left: 1em">星三十年行天一周其在正中二交之下必无纬度分</span>  
<span style="margin-left: 1em">十五年恒北十五年恒南耳凡冲太阳因在小轮下半</span>  
<span style="margin-left: 1em">即加本道纬度凡会太阳因在小轮上半即减纬度他</span>  
<span style="margin-left: 1em">星亦犹是也其或行近于地小轮加纬益多太白至夕</span>  
<span style="margin-left: 1em">伏合之际因其近地其纬几及八度矣中历不谙纬行</span>  
<span style="margin-left: 1em">之原一见金星在纬南北七八九度即詑谓本星失行</span>  
<span style="margin-left: 1em">岂非诬乎又中历亦有五星南北纬行图亦界以黄道</span>  
<span style="margin-left: 1em">本道似矣但其逆行之迹恒作一斜方形此甚非也五</span>  
<span style="margin-left: 1em">纬不行直线安得方形以此新法图分二种一设人在</span>  
<span style="margin-left: 1em">地仰观天上进退诸行故于上三星冲太阳下二星夕</span>  
<span style="margin-left: 1em">伏时第作一仅似之圆形凡冲太阳如在本道交上则</span>  
<span style="margin-left: 1em">不作圆形即仿佛一之字形而已一各星近远于地之</span>  
<span style="margin-left: 1em">图要皆旧历所未谙也</span>  
<span style="margin-left: 3em">五星伏见</span>  
<span style="margin-left: 1em">五星之光与日相较譬犹萤火之于庭燎光本非灭第</span>  
<span style="margin-left: 1em">为大光所夺人莫能睹耳旧历亦晓此理故用黄道距</span>  
<span style="margin-left: 1em">度以定诸星伏见如谓太阳在降娄初度岁星在十五</span>  
<span style="margin-left: 1em">度即以为见限似矣然而诸星各有纬南纬北之分黄</span>  
<span style="margin-left: 1em">道有正斜升降之势各宫不同何得泥距度以定限乎</span>  
<span style="margin-left: 1em">新法定限惟以地平为主缘地平障蔽日光能使星或</span>  
<span style="margin-left: 1em">伏或见耳夫日之下于地平其光渐杀所谓晨昏此晨</span>  
<span style="margin-left: 1em">昏光之久暂四时不等即冥漠等矣而星见时刻又自</span>  
<span style="margin-left: 1em">不等所以然者太阳由黄道而下地平或十度或十五</span>  
<span style="margin-left: 1em">度或至三十度有奇原自不等而星在黄道南相距必</span>  
<span style="margin-left: 1em">多数度在北相距必少数度其限岂可泥乎大畧土木</span>  
<span style="margin-left: 1em">火三星较太阳行迟行后太阳夕伏晨见金水二星顺</span>  
<span style="margin-left: 1em">天东旋较太阳行疾行先太阳晨伏夕见逆行反是其</span>  
<span style="margin-left: 1em">与太阳遇也亦夕伏晨见太阴行较太阳更疾晨伏夕</span>  
<span style="margin-left: 1em">见至于金星之纬不及八度则凡逆行合太阳于寿星</span>  
<span style="margin-left: 1em">大火二宫而其纬又在北七度以上虽与日合其光不</span>  
<span style="margin-left: 1em">伏一日晨夕皆可见之水星之纬惟四度余若其纬向</span>  
<span style="margin-left: 1em">南合太阳于寿星此后去离夕必不见合太阳于降娄</span>  
<span style="margin-left: 1em">此后去离晨必不见金合而不伏水离而不见此二故</span>  
<span style="margin-left: 1em">者浑仪解之他如恒星亦有夕伏晨见者一因黄道之</span>  
<span style="margin-left: 1em">经纬度一因其小大等第即为见伏之限故亦可推也</span>  
<span style="margin-left: 3em">测太阳</span>  
<span style="margin-left: 1em">诸曜森罗太阳其宗主也或推或测必首太阳顾其应</span>  
<span style="margin-left: 1em">测之行不外三种一曰盈缩之限一曰盈缩细行一曰</span>  
<span style="margin-left: 1em">盈初缩末之所中历之测太阳未尝及此三行即所测</span>  
<span style="margin-left: 1em">止冬夏二至犹未尽善也其法立八尺表用景符器于</span>  
<span style="margin-left: 1em">冬至前后三四日测定三景因以三景之较数求太阳</span>  
<span style="margin-left: 1em">到冬至时刻其法未尝不是所以为未尽善者盖表景</span>  
<span style="margin-left: 1em">短长乃太阳行南行北所生论其近二至之候南北之</span>  
<span style="margin-left: 1em">行极微计一日所行天度有分半者有一分者有半分</span>  
<span style="margin-left: 1em">者乃于冬至近期建表寻丈而其所得二景差为一分</span>  
<span style="margin-left: 1em">二厘<sub class="note-yuan">量度则云分秒量景则云丈尺分厘</sub>厘为八刻而此一二厘间相差</span>  
<span style="margin-left: 1em">甚微彼景符曷能定之况景符光线恒占数厘或更稍</span>  
<span style="margin-left: 1em">为进退其失弥甚是恒差数十刻也若测夏至则倍难</span>  
<span style="margin-left: 1em">矣今新法用八线表法查古所遗之数以用于推步庶</span>  
<span style="margin-left: 1em">称密近耳然又不但用表亦时用别法以相济也比如</span>  
<span style="margin-left: 1em">春秋二分太阳之南北行较大日行天度二十四分乃</span>  
<span style="margin-left: 1em">于其前后数日先测极出地度得赤道高次用象限仪</span>  
<span style="margin-left: 1em">测日轨高不免相差一分而其于本算日轨入交点时</span>  
<span style="margin-left: 1em">刻则约差四刻耳较之以寻丈表测冬至差厘数而乖</span>

<span style="margin-left: 3em">测恒星</span>  
<span style="margin-left: 1em">测星之法不一大要以太阳为主而以太阴或太白或</span>  
<span style="margin-left: 1em">岁星为中次任取某星为界互相测度即得其度法于</span>  
<span style="margin-left: 1em">太阳将入之时测月或太白或岁星其距太阳度分若</span>  
<span style="margin-left: 1em">干日既没再测月或太白或岁星其与某星相距度分</span>  
<span style="margin-left: 1em">若干合两测即得太阳与此星之距然后查太阳本日</span>  
<span style="margin-left: 1em">躔某宫度则知此星所在宫度矣测一星之经度如此</span>  
<span style="margin-left: 1em">他星可以类推于是又测此星出地平之最高即其距</span>

<span style="margin-left: 1em">二其一以黄极为枢每岁东行五十一秒有奇而其距</span>  
<span style="margin-left: 1em">本极之纬度则亘古无变其一则因赤道以算其经纬</span>  
<span style="margin-left: 1em">南北星位古今大异如尧时外屏星全座在赤道南今</span>  
<span style="margin-left: 1em">则在北角宿古在北者今亦在南星纬变易类多如此</span>  
<span style="margin-left: 1em">至以赤道论各宿距度亦有异者如觜宿距星上古为</span>  
<span style="margin-left: 1em">三度历代递减今且侵入参宿二十四分他宿互有损</span>

<span style="margin-left: 3em">测太阴</span>  
<span style="margin-left: 1em">太阴行度所当测定者五一迟疾之限一迟疾初末一</span>  
<span style="margin-left: 1em">月孛行一每日细行一交行五测有一不详月离之违</span>  
<span style="margin-left: 1em">合难齐矣又月有气差时差<sub class="note-yuan">即地半径所生</sub>所测之经纬度分</span>  
<span style="margin-left: 1em">于正度分复有相较以此测月于七政中为最难旧历</span>  
<span style="margin-left: 1em">用表于午正测定三景以求之越四载而得一次测验</span>  
<span style="margin-left: 1em">之时九载而复推定疑太拙矣新法用三会食推算其</span>  
<span style="margin-left: 1em">法以食甚正对太阳得月经度以食甚分秒得距交若</span>  
<span style="margin-left: 1em">干以各食中积时日刻数不等并得天上所行不等度</span>  
<span style="margin-left: 1em">分于是用本法以求月天之孛或最高<sub class="note-yuan">即极迟之行</sub>亦遂得</span>  
<span style="margin-left: 1em">平视二行相较之度以简御繁法莫善于此矣其测上</span>  
<span style="margin-left: 1em">下二弦经度亦有本法盖弦乃太阴实距太阳或东或</span>  
<span style="margin-left: 1em">西九十度即周天四分之一也先以本仪测定其限次</span>  
<span style="margin-left: 1em">用法算其平行因其加分恒与所测差二度余赖有二</span>

<span style="margin-left: 3em">测五纬</span>  
<span style="margin-left: 1em">上三星为土木火与太阳相冲会然于冲会之二时各</span>  
<span style="margin-left: 1em">无岁行加减分缘其会太阳即在岁行圈之最高而冲</span>  
<span style="margin-left: 1em">之即在其最卑于实行为合故也须知实行与平行不</span>

<span style="margin-left: 1em"><sub class="note-yuan">太阳躔度推算</sub>得此冲经度即有中积天度日数及本星随日</span>

<span style="margin-left: 1em">较难法先于或晨或昏求其与太阳距度者数次然后</span>

<span style="margin-left: 1em">为本二留之限各星不同即所躔天度亦不同然而星</span>  
<span style="margin-left: 1em">在二留非冲太阳乃折中之度故本之以测岁行也下</span>

<span style="margin-left: 3em">测器</span>
