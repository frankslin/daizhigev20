## 崇禎曆書卷之三十　新法歷引

<span style="margin-left: 2em">新法歷引<sub class="note-jiao">校：據清刊本補入</sub></span>  
<span style="margin-left: 1em">勅錫通玄教師加二品通政使司通政使掌欽天監印務事臣湯若望删定</span>  
<span style="margin-left: 3em">曆學維新</span>  
<span style="margin-left: 1em">曆學有法有用法者測各重天之運行體勢以審諸曜</span>  
<span style="margin-left: 1em">出入隱現以求本行軌道以定準則也用者取本法測</span>  
<span style="margin-left: 1em">定之分數隨方隨時以推步日月五星次舍衝照交食</span>  
<span style="margin-left: 1em">凌犯順逆等情也二者闕一不可然而立法難矣語云</span>  
<span style="margin-left: 1em">毫釐之差千里之謬在曆學爲尤甚中國自漢迄元造</span>  
<span style="margin-left: 1em">曆者七十餘輩立法者僅十有三家且皆不免乖違後</span>  
<span style="margin-left: 1em">人難憑致用有謂得一冬至之正時即爲密近者非也</span>  
<span style="margin-left: 1em">測冬至之于曆術未及百分之一聞一知百世無其人</span>  
<span style="margin-left: 1em">有謂得一歲實一朔實及轉終交終等策爲已定者非</span>  
<span style="margin-left: 1em">也此皆諸曜平行之率何由遽定視行有謂測率四應</span>  
<span style="margin-left: 1em">可以無忒者非也此不過推算平行之界而已有謂多</span>  
<span style="margin-left: 1em">測交食稽其某法先天某法後天而後彙計籌策折中</span>  
<span style="margin-left: 1em">取之者亦非也曆家法數繁瑣用以算步交食不下四</span>  
<span style="margin-left: 1em">十餘條究竟何項何欵可以折中取半者因知古來修</span>  
<span style="margin-left: 1em">改門户雖岐實則互相依傍間有出一二新意亦未必</span>  
<span style="margin-left: 1em">洞曉本元跡其大端猶不過截前至後通計所差加减</span>  
<span style="margin-left: 1em">乘除分派各歲之下便謂修改已耳即使僅合一時豈</span>  
<span style="margin-left: 1em">能施諸久遠後惟授時曆庶稱精密顧其法亦未盡善</span>  
<span style="margin-left: 1em">在當日已有推食不食食而失推之弊何况沿襲至于</span>  
<span style="margin-left: 1em">今日哉他若回回曆者其曆元爲西域所定使非中曆</span>  
<span style="margin-left: 1em">先推太陽躔度至春分之日彼亦茫然無據以得支于</span>  
<span style="margin-left: 1em">以合中國所用歲月也况其曆元巳歷千年不可復用</span>  
<span style="margin-left: 1em">乎兹惟新法悉本之西洋治曆名家曰多祿某曰亞而</span>  
<span style="margin-left: 1em">封所曰歌白泥曰第谷四人者蓋西國之于曆學師傳</span>  
<span style="margin-left: 1em">曹習人自爲家而是四家者首爲後學之所推重著述</span>  
<span style="margin-left: 1em">既繁測驗益密立法致用俱臻至極旅輩採其精詳究</span>  
<span style="margin-left: 1em">其奥賾而又參以獨得發所未發焉更審今測以廣古</span>  
<span style="margin-left: 1em">測必求合天年世互考中西名例半皆仍舊合異歸同</span>  
<span style="margin-left: 1em">成書已進</span>  
闕庭新法已行天下用彰  
昭代曆典度越前古暨質諸來祀雖億萬年永不爽云  
<span style="margin-left: 3em">地球</span>  
<span style="margin-left: 1em">地在天之中心常靜不動與天相較不啻稊米之于喬</span>  
<span style="margin-left: 1em">嶽也其形渾圓古謂方者蓋指其德耳凡居處地球者</span>  
<span style="margin-left: 1em">其視日景之不同分有五帶其中則自赤道南北各以</span>  
<span style="margin-left: 1em">二十三度半爲限<sub class="note-yuan">此即二極出地之高</sub>名爲煖帶居其下者午正</span>  
<span style="margin-left: 1em">立表揆日測景必自射南射北顧每歲必有二日其表</span>  
<span style="margin-left: 1em">無景即春秋二分太陽正過其天頂之日也<sub class="note-yuan">此指正居赤道下者</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">春秋二分目中無景過春分則景在南過秋分則景在北</sub>此帶惟一又於其南其北</span>  
<span style="margin-left: 1em">各自二十三度半外各截至六十六度半爲限名爲温</span>  
<span style="margin-left: 1em">帶其下居南者表景恒射南居北者表景恒射北歲有</span>  
<span style="margin-left: 1em">一日其景極短然太陽則不經其天頂矣此帶有二以</span>  
<span style="margin-left: 1em">上三帶皆太陽每日有出有入者也又于南北二方自</span>  
<span style="margin-left: 1em">六十六度半外各底其極名爲冷帶其下或表景周圍</span>  
<span style="margin-left: 1em">旋轉有日太陽繞其地恒見有日太陽繞其地恒隱隱</span>  
<span style="margin-left: 1em">見之候或久至半歲或數月不等此帶亦二是爲大地</span>  
<span style="margin-left: 1em">共分五帶之槩也因此推知距赤道之南北二方其氣</span>  
<span style="margin-left: 1em">候必相反如太陽躔星紀宫向北之方爲冬至向南之</span>  
<span style="margin-left: 1em">方爲夏至春秋二分以及諸節莫不皆然又因此推知</span>  
<span style="margin-left: 1em">地球爲人所止以天頂而分四方亦可界爲三百六十</span>  
<span style="margin-left: 1em">度以合天行東西爲經測以赤道南北爲緯測以子午</span>  
<span style="margin-left: 1em"><sub class="note-yuan">規名解見下篇</sub>但測南北者有二極以爲之端欲測東西則須</span>  
<span style="margin-left: 1em">先定一所以爲起界<sub class="note-yuan">新曆悉以京師爲起界他方雖未親測亦據輿圖以定其經緯</sub>而</span>  
<span style="margin-left: 1em">後地之經緯皆可得而明焉苟不諳此則無以知幅𢄙</span>  
<span style="margin-left: 1em">相距之數而諸方太陽節氣五星經度凌犯交食時刻</span>  
<span style="margin-left: 1em">日食分秒悉無從推步矣<sub class="note-yuan">日食南北東西各不同月食分數皆同但東西不同時耳</sub></span>  
<span style="margin-left: 1em">且不惟是即古測今測歲實之異日出日入晝夜永短</span>  
<span style="margin-left: 1em">之差咸取準于地之緯度所係大矣其可忽諸</span>  
<span style="margin-left: 3em">天道</span>  
<span style="margin-left: 1em">天體渾淪穹然莫辨必也相形酌理判立界限以爲依</span>  
<span style="margin-left: 1em">據而後推測之功可施則夫設立諸規以著象數爲用</span>  
<span style="margin-left: 1em">甚大且急較爲曆家首務也新法總有四大規一曰地</span>  
<span style="margin-left: 1em">平一曰赤道一曰黃道一曰子午四規闕一不可蓋地</span>  
<span style="margin-left: 1em">平規者從人足所附極目四望之界而設也人附地面</span>  
<span style="margin-left: 1em">所可望見者天之半耳其半恒繞于地下人不可得而</span>  
<span style="margin-left: 1em">見也即此可見不可見之界而諸曜由是而出入明暗</span>  
<span style="margin-left: 1em">晝夜由是而分因設此規剖爲四象以應四方象各限</span>  
<span style="margin-left: 1em">以九十度是爲地平經度而各曜出入之方位以辨矣</span>  
<span style="margin-left: 1em">又自地平上至天頂設距等圈以爲地平緯度而各曜</span>  
<span style="margin-left: 1em">漸升之度以明各曜出地離赤道之緯度并北極出地</span>  
<span style="margin-left: 1em">之數皆可得而稽之矣赤道規者從南北二極相距正</span>  
<span style="margin-left: 1em">中之界而設也古曰天行健又曰天左旋左旋而行健</span>  
<span style="margin-left: 1em">則知南北必有其極矣極也者天體永久不動之兩點</span>  
<span style="margin-left: 1em">周天倚爲環動之樞者也<sub class="note-yuan">極非星也云極星者蓋指其最近極之星以命耳</sub>如</span>  
<span style="margin-left: 1em">一極出地必一極入地其出入之度惟均曆家乃於二</span>  
<span style="margin-left: 1em">極相距最中之界設有赤道一規平分天體爲南北南</span>  
<span style="margin-left: 1em">者爲外爲陽而北者爲內爲陰其亘于天中也終古不</span>  
<span style="margin-left: 1em">易推步者畢賴之爲準則無容置議也本規列度三百</span>  
<span style="margin-left: 1em">有六十辰十有二刻九十有六天體一日一周之運于</span>  
<span style="margin-left: 1em">是焉紀晝夜刻分之永短于是焉定黃道出入之廣狹</span>  
<span style="margin-left: 1em">于是焉齊春秋二分之晷景于是焉限南北緯算于是</span>  
<span style="margin-left: 1em">焉起大地全圓于是焉度凡此皆其用也黃道規者從</span>  
<span style="margin-left: 1em">太陽旋周一歲之界而設也蓋太陽行天一歲所周軌</span>  
<span style="margin-left: 1em">蹟旋以成規定名黃道本規斜絡于赤道具半在南最</span>  
<span style="margin-left: 1em">南界爲冬至其半在北最北界爲夏至二道相交之兩</span>  
<span style="margin-left: 1em">點爲春秋分以故四平分之爲象限限各九十度者是</span>  
<span style="margin-left: 1em">即二分二至四正之限也總計爲三百六十度十二剖</span>  
<span style="margin-left: 1em">之爲宫二十四剖之爲節氣七十二剖之爲候蓋用以</span>  
<span style="margin-left: 1em">節七曜列宿之行用以審日月交食之限至較著也子</span>  
<span style="margin-left: 1em">午規者從諸曜升降度適中之界而設也太陽一日旋</span>  
<span style="margin-left: 1em">天一周見于東方漸升至高爲正午此地平以上東半</span>  
<span style="margin-left: 1em">晝分過午向西漸底地平是爲西半晝分乃謂之降地</span>  
<span style="margin-left: 1em">曜皆然于此升降度之中界立有一規名爲子午諸曜</span>  
<span style="margin-left: 1em">際此謂爲在子在午是規透過赤道及地平各二極其</span>  
<span style="margin-left: 1em">偕赤道地平而交爲直角也恒然不動但人在地面南</span>  
<span style="margin-left: 1em">北遷此規惟一東西遷則隨在各異也<sub class="note-yuan">與地平同</sub>已上四規</span>  
<span style="margin-left: 1em">各有本用所係非小曆家測候欲求七政行度會望等</span>  
<span style="margin-left: 1em">諸法舍此無從措手以此未言象數先以詳明諸規爲</span>  
<span style="margin-left: 1em">首務也</span>  
<span style="margin-left: 3em">一系赤道有恒動恒不動二用恒不動者以定各</span>  
<span style="margin-left: 4em">方時刻恒動者以相交相割于黃道也俗謂赤</span>  
<span style="margin-left: 4em">道有二者蓋即指此二用非實有二道也</span>  
<span style="margin-left: 3em">二系赤道正居天頂則兩極適與地平相當至若</span>  
<span style="margin-left: 4em">赤道斜交地平之所則極出地度數即赤道距</span>  
<span style="margin-left: 4em">天頂度數矣其經度即過極圈緯度即距等圈</span>  
<span style="margin-left: 4em">也</span>  
<span style="margin-left: 3em">三系黃道與赤道斜交故其極自有本極謂之黃</span>  
<span style="margin-left: 4em">極黃極者恒星與太陽本行之樞也論二道最</span>  
<span style="margin-left: 4em">遠之距<sub class="note-yuan">即南至北至之距</sub>今古不同今測定爲天度二</span>  
<span style="margin-left: 4em">十三度三十一分三十秒上古較多數十分後</span>  
<span style="margin-left: 4em">此則漸减矣</span>  
<span style="margin-left: 3em">四系周天諸道用立多規以便測驗但其爲規也</span>  
<span style="margin-left: 4em">非止旋周一線而已蓋一滿平圓面也面爲各</span>  
<span style="margin-left: 4em">曜之所經行故謂之道某曜在某面上即謂之</span>  
<span style="margin-left: 4em">在某道云</span>  
<span style="margin-left: 3em">曆元</span>  
<span style="margin-left: 1em">所謂曆元者乃以諸曜之平行同時而求各所曆數曆</span>  
<span style="margin-left: 1em">家因之用爲起算之根也新法則以天聰戊辰前太陽</span>  
<span style="margin-left: 1em">過天正冬至後第一子正爲曆元其日干則己卯也斯</span>  
<span style="margin-left: 1em">時太陽躔星紀宫初度五十三分太陰在六宫初度五</span>  
<span style="margin-left: 1em">十分他曜皆以此時行度爲準不用冬至時刻與舊曆</span>  
<span style="margin-left: 1em">異緣冬至有正有平最難得其真率也夫曆元爲諸算</span>  
<span style="margin-left: 1em">先資稍有舛忒即諸行皆謬矣况諸曜終歲細行莫不</span>  
<span style="margin-left: 1em">以子正起算又安用冬至時刻爲哉</span>  
<span style="margin-left: 3em">曆算</span>  
<span style="margin-left: 1em">舊以周天判爲三百六十五度又四分度之一所謂日</span>  
<span style="margin-left: 1em">度也蓋以太陽之行黃道日一度度析百分分析百秒</span>  
<span style="margin-left: 1em">且又均之分爲宫次氣候法用奇零勢難齊一且天度</span>  
<span style="margin-left: 1em">者歲實之日分也中曆所用歲實諸家多寡不等是其</span>  
<span style="margin-left: 1em">分天非一定之術而爲游移之法欲以是决定諸曜之</span>  
<span style="margin-left: 1em">行豈不難乎若天新法之分周天曆度也即于天度以</span>  
<span style="margin-left: 1em">三百六十平剖之度析六十分分析六十秒蓋六十者</span>  
<span style="margin-left: 1em">半之則爲三十三之一則二十四之一則十五餘任剖</span>  
<span style="margin-left: 1em">析皆爲自然而然之分往古曆紀未始繁載但于測得</span>  
<span style="margin-left: 1em">之數曰某度幾何分之一而已錯綜離合其于曆算甚</span>  
<span style="margin-left: 1em">便也請言曆算夫曆之爲數袛就天行無假淹貫九章</span>  
<span style="margin-left: 1em">而其所須用者加减乘除開方五法古用觚稜近便珠</span>  
<span style="margin-left: 1em">算西法第資毫頴今復有算籌之創簡捷尤甚矣所謂</span>  
<span style="margin-left: 1em">加法者以類相比併多分以成全如度併度分併分秒</span>  
<span style="margin-left: 1em">併秒時刻併時刻是也此須知定位及進位之法如積</span>  
<span style="margin-left: 1em">六十秒爲一分積六十分爲一度秒進于分之位分進</span>  
<span style="margin-left: 1em">于度之位而與他度分秒并之若加時刻則以十五分</span>  
<span style="margin-left: 1em">進一刻四刻進一時二十四時進一日二十四西法謂</span>  
<span style="margin-left: 1em">之小時也此加法也减與加反用稽所餘其法先須較</span>  
<span style="margin-left: 1em">數多寡多中减寡理數易明若于少內减多必立借法</span>  
<span style="margin-left: 1em">以通其變如借度化分借分化秒爲本類以用之乘法</span>  
<span style="margin-left: 1em">者九九互積之義有實數有法數凡单數乘度分秒不</span>  
<span style="margin-left: 1em">變位若度乘度復生多度分乘分以生秒秒乘秒以生</span>  
<span style="margin-left: 1em">微則皆變位<sub class="note-yuan">分秒相生皆指奇零而言</sub>此不可不知也除法者以少</span>  
<span style="margin-left: 1em">剖多分分除减意也爲法有二或以单數商除亦不變</span>  
<span style="margin-left: 1em">位苟分度不盡即以餘度化分除之分秒亦然開方者</span>  
<span style="margin-left: 1em">以化法求其微數用籌乘除然後再受爲度或用三率</span>  
<span style="margin-left: 1em">法亦可是五法者盡曆算矣然而新曆之算諸星經緯</span>  
<span style="margin-left: 1em">及交食等項也蓋有二術其一取所圖各宿曜本行規</span>  
<span style="margin-left: 1em">之半徑并其所設某日平行<sub class="note-yuan">即本圈上之弧</sub>用諸三角形法推</span>  
<span style="margin-left: 1em">演乃可得經緯細行或交食之分數時刻此術最爲縝</span>  
<span style="margin-left: 1em">密果能精心於此即諸天周行軌迹隱微罔不洞然其</span>  
<span style="margin-left: 1em">二以先所推定諸表握算設如某日某刻欲求太陽經</span>  
<span style="margin-left: 1em">度則第用加减二法檢表二三次以求即可得其宫度</span>  
<span style="margin-left: 1em">較之中曆節氣求經朔之法簡便數倍餘如五星太陰</span>  
<span style="margin-left: 1em">等曜以及交食皆各有表可稽火星兼用乘除他則但</span>  
<span style="margin-left: 1em">資加减立法雖難致用則易然而一趨超徑萬一操觚</span>  
<span style="margin-left: 1em">小失恐并迷昧元初之理所以二術不可偏廢皆爲推</span>  
<span style="margin-left: 1em">步家之所朝夕從事者也</span>  
<span style="margin-left: 3em">句股</span>  
<span style="margin-left: 1em">句股之術從來尚矣古九章周髀載之究不過一三邊</span>  
<span style="margin-left: 1em">直角形而已垂線爲股横線爲句斜線爲弦測量家立</span>  
<span style="margin-left: 1em">表代股平圭代句而景爲其弦善斯術者高深廣遠無</span>  
<span style="margin-left: 1em">不可求而測天之爲用尤大然而舊法雖有三元五和</span>  
<span style="margin-left: 1em">五較等用不過設二求三且泥于直角一形若遇斜角</span>  
<span style="margin-left: 1em">弧角無以措用矣新法變而通之既名其公曰三角形</span>  
<span style="margin-left: 1em">又審其平面球面曲線雜線銳角鈍角之別即知天爲</span>  
<span style="margin-left: 1em">圜體宜測以弧宿曜近遠諸道互交宜測以多類之弧</span>  
<span style="margin-left: 1em">遂生多類之三弧形于是各形咸備有三弧三角互設</span>  
<span style="margin-left: 1em">三以求餘三是謂以圓齊圓于法爲善故雖天道隱微</span>  
<span style="margin-left: 1em">象數零雜未有能遁焉者也</span>  
<span style="margin-left: 3em">割圓</span>  
<span style="margin-left: 1em">割圜古法亦即以圜求圜之意但古法設弧以求弦矢</span>  
<span style="margin-left: 1em">欵目四十餘項頗爲艱繁新法易之以表開卷即得蓋</span>  
<span style="margin-left: 1em">因圜形之弧與角總代以直線數種稽其數名爲八線</span>  
<span style="margin-left: 1em">表云夫圜形半徑爲本規六平分之通弦若二半徑各</span>  
<span style="margin-left: 1em">自乘之并而開方可得本規四平分之通弦用幾何諸</span>  
<span style="margin-left: 1em">法又可得各度分之通弦其各弧及其通弦折半乃得</span>  
<span style="margin-left: 1em">正弦正弧有弦弧即有其矢矣故天不另立表也通弦</span>  
<span style="margin-left: 1em">之外有切線割線通弦全在規內切線全在規外線從</span>  
<span style="margin-left: 1em">規心出于規周之外則爲割線然而弧有正有餘弦矢</span>  
<span style="margin-left: 1em">切割四者因亦各有正餘如一象限爲本表之限或于</span>  
<span style="margin-left: 1em">限內取幾何度謂爲正弧其或逾九十度者即謂之餘</span>  
<span style="margin-left: 1em">矣正餘各有弦矢割切四線都爲八線也</span>  
<span style="margin-left: 3em">恒星</span>  
<span style="margin-left: 1em">恒星亦名列星亦名經星云恒者謂其象終古不易也</span>  
<span style="margin-left: 1em">云經者以別于五緯南北行之義其數甚夥莫能窮盡</span>  
<span style="margin-left: 1em">就中有光體渺微非目可及非儀可測者畧而不錄其</span>  
<span style="margin-left: 1em">在等第之內已經新法測定者南北二極共一千七百</span>  
<span style="margin-left: 1em">二十有五星稽其大小分爲六等第一等大星如五帝</span>  
<span style="margin-left: 1em">座織女類者一十有七二等如帝星開陽類者五十有</span>  
<span style="margin-left: 1em">七三等如太子少衛類者八十有五四等如上將柱史</span>  
<span style="margin-left: 1em">類者三百八十有九五等如上相虎賁類者三百二十</span>  
<span style="margin-left: 1em">有三六等如天皇大帝后宫類者二百九十有五此皆</span>  
<span style="margin-left: 1em">有名之星計共一千一百六十有六餘皆無名者矣至</span>  
<span style="margin-left: 1em">于天漢斜絡天體古昔多謬解邇來窺以遠鏡知是無</span>  
<span style="margin-left: 1em">算小星接攅一帶即如積尸氣等亦小星攅聚以成第</span>  
<span style="margin-left: 1em">非人目所能辨遂作如是觀耳小者不足論論其大者</span>  
<span style="margin-left: 1em">古曆以周天諸星分爲三垣二十八宿各定有名位座</span>  
<span style="margin-left: 1em">次每座每宿星數多寡不齊顧其所謂宿者蓋取七曜</span>  
<span style="margin-left: 1em">經行止宿之義且用以便測算經度又爲其各能主施</span>  
<span style="margin-left: 1em">德也西古曆亦列二十八舍所定二十八距星皆與中</span>  
<span style="margin-left: 1em">古脗合第觜距西用天關爲小異耳此二十八宿者各</span>  
<span style="margin-left: 1em">以一字命名分註每日之下內以房虛星昂四宿爲屬</span>  
<span style="margin-left: 1em">太陽之日心危畢張爲屬太陰之日此外五緯各屬四</span>  
<span style="margin-left: 1em">宿每以七日爲期每日各屬一宿西曆亦然西經傳上</span>  
<span style="margin-left: 1em">古有一大師名諾厄者廣宣曆理以遍萬國則亦有所</span>  
<span style="margin-left: 1em">本也</span>  
<span style="margin-left: 3em">一系星之命名多係借義非可過泥虛名便謂實</span>  
<span style="margin-left: 4em">有其驗比如貫索一星中以其象囹圄名以貫</span>  
<span style="margin-left: 4em">索西以其象冠冕名以冠冕一吉一凶全由人</span>  
<span style="margin-left: 4em">意豈天星實然乎至謂諸星情性不同旉施互</span>  
<span style="margin-left: 4em">異是又理所必然不得槩置弗論也故總圖于</span>  
<span style="margin-left: 4em">某星屬某緯者咸附註之</span>  
<span style="margin-left: 3em">二系圖星之法有二一渾球有南北二極有地平</span>  
<span style="margin-left: 4em">子午諸規界判黃赤二道運之能肖天體旋轉</span>  
<span style="margin-left: 4em">以審各星經緯度分以辨星中出没以測夜時</span>  
<span style="margin-left: 4em">甚便也一平面圖雖乏以上諸用然諸星位置</span>  
<span style="margin-left: 4em">宫度瞭若視掌爲用亦大因有多種之分曰見</span>  
<span style="margin-left: 4em">界圖以北極爲心其最南隱于地中星極非此</span>  
<span style="margin-left: 4em">方人目可見者則截出之一曰赤道圖黃道圖</span>  
<span style="margin-left: 4em">二者各以其極爲心其道爲界蓋皆以天之南</span>  
<span style="margin-left: 4em">北平剖爲二圖者也曰分星圖依黃道分天爲</span>  
<span style="margin-left: 4em">二十圖均賦經緯署以維辰按圖指陳天象莫</span>  
<span style="margin-left: 4em">晰于此外有渾蓋所用天盤以極爲心截冬至</span>  
<span style="margin-left: 4em">規爲界亦圖星于儀上肖天運動以覘諸星出</span>  
<span style="margin-left: 4em">没升降又有平儀從二極剖天爲南六宫北六</span>  
<span style="margin-left: 4em">宫二面亦繪辰宿可代渾儀旋轉至若古傳星</span>  
<span style="margin-left: 4em">經圖步天歌等雖亦分有宿座便于觀覽而經</span>  
<span style="margin-left: 4em">緯度分悉皆茫然掛漏于測候無用也</span>  
<span style="margin-left: 3em">星中出没</span>  
<span style="margin-left: 1em">太陽右旋一日一度終歲行天一周必復與某恒星合</span>  
<span style="margin-left: 1em">又必有某星與之衝曆家無從測其合者測得其衝者</span>  
<span style="margin-left: 1em">謂爲歲差所從來矣然由本方極出地度恒星有出没</span>  
<span style="margin-left: 1em">者亦有不出不没者如京師北極出地四十度則星距</span>  
<span style="margin-left: 1em">極四十度以外皆爲恒見而距南極四十度以內者在</span>  
<span style="margin-left: 1em">京皆不能見矣至論恒星見伏亦由太陽右旋至某宿</span>  
<span style="margin-left: 1em">度附近之星光爲日奪故不能見迨太陽去離漸遠則</span>  
<span style="margin-left: 1em">此星光漸升東方見而不伏矣緣是而升至午點即曰</span>  
<span style="margin-left: 1em">中星此其星中出没在立象學爲用甚距而曆家但于</span>  
<span style="margin-left: 1em">中夜資之以定時刻而已</span>  
<span style="margin-left: 3em">日軌</span>  
<span style="margin-left: 1em">太陽之行黃道也論其積歲平分之數新法以天度計</span>  
<span style="margin-left: 1em">爲五十九分八秒有奇所謂平行度分是也然平行齊</span>  
<span style="margin-left: 1em">而實行則固非齊矣冬盈而夏縮矣所以然者蓋緣黃</span>  
<span style="margin-left: 1em">道圈與日輪天不同心而黃道之心即地球心是日輪</span>  
<span style="margin-left: 1em">天與地球不同心也心既不同則日行距地近遠不等</span>  
<span style="margin-left: 1em">距近即行疾疾則所行之度過于平行而爲盈每冬月</span>  
<span style="margin-left: 1em">一日計行一度一分有奇以較平行盈二分矣距遠即</span>  
<span style="margin-left: 1em">行遲遲則所行之度不及平行而爲縮每夏月一日計</span>  
<span style="margin-left: 1em">行五十七分有奇以較平行則縮二分矣盈縮相差若</span>  
<span style="margin-left: 1em">此豈可謂之齊乎終歲之間但逢最高限最卑限二日</span>  
<span style="margin-left: 1em">平實二行度數惟一此外兩行之較日日不等新法因</span>  
<span style="margin-left: 1em">其或過或不及也故有加分减分謂之加减差蓋以有</span>  
<span style="margin-left: 1em">恒率之平行爲根而以加减差定之然後差而不差非</span>  
<span style="margin-left: 1em">齊而齊矣至論太陽之入某宫次以分節氣也亦有平</span>  
<span style="margin-left: 1em">實二算蓋算平行十五日二十一刻有奇爲一節氣乃</span>  
<span style="margin-left: 1em">一歲二十四平分之一耳若用躔度之日以算則冬夏</span>  
<span style="margin-left: 1em">不齊冬一節氣爲十四日八十四刻有奇夏一節氣爲</span>  
<span style="margin-left: 1em">十五日七十二刻有奇總由夏遲冬疾故其差如此皆</span>  
<span style="margin-left: 1em">非舊曆之所解也</span>  
<span style="margin-left: 3em">系太陽天距地極遠之點謂之最高極近之點謂</span>  
<span style="margin-left: 4em">之最高衝<sub class="note-yuan">亦名最卑</sub>此二點者乃盈縮二行之界古</span>  
<span style="margin-left: 4em">法于冬夏二至謂其恒在一點其實非也按古</span>  
<span style="margin-left: 4em">今諸測皆各不齊古測最高在夏至前數度今</span>  
<span style="margin-left: 4em">則在後六度矣以此推知一年之內太陽自行</span>  
<span style="margin-left: 4em">四十五秒也</span>  
<span style="margin-left: 3em">年月</span>  
<span style="margin-left: 1em">紀年者何太陽隨列宿東行旋天一周之期也太陽之</span>  
<span style="margin-left: 1em">行界二其一從某宫次度分行天一周而復于元度其</span>  
<span style="margin-left: 1em">數爲三百六十五日二十四刻二十一分有奇其一爲</span>  
<span style="margin-left: 1em">太陽會于列宿天之某星行天一周而復與元星會但</span>  
<span style="margin-left: 1em">其星每歲有本行故須加本行以定歲而其所須加者</span>  
<span style="margin-left: 1em">新法定爲五十一秒所謂歲差也然而日曆紀年惟以</span>  
<span style="margin-left: 1em">全日推算不用小餘如以太陽十二次會合太陰爲歲</span>  
<span style="margin-left: 1em">也爲三百五十四日每二年三年而閏一月中曆是已</span>  
<span style="margin-left: 1em">如以太陽周十二宫次爲歲也爲三百六十五日每四</span>  
<span style="margin-left: 1em">年而閏一日西曆是已此紀年之槩也紀月有二或因</span>  
<span style="margin-left: 1em">太陰會朔一次以定謂太陰之月或因太陽行一宫次</span>  
<span style="margin-left: 1em">以定謂太陽之月顧其十二分年之一分則一也一月</span>  
<span style="margin-left: 1em">之終分有大盡小盡者比如初朔子正苟二朔者過二</span>  
<span style="margin-left: 1em">十九日外而不及第三十日之子正則謂之小過子正</span>  
<span style="margin-left: 1em">則謂之大大則二朔同一天干小則不同矣故有三十</span>  
<span style="margin-left: 1em">日弱時刻不及者曆家不得名大或二十九日强而時</span>  
<span style="margin-left: 1em">刻已逾者曆家仍不得名小也且宇內地度不同而月</span>  
<span style="margin-left: 1em">之大小因以互異比如京師第二朔在子初二刻未到</span>  
<span style="margin-left: 1em">子正其月爲小而西安此朔則已在子正初刻又當爲</span>  
<span style="margin-left: 1em">大盡矣地度愈遠時刻愈差非可强而同之也月有閏</span>  
<span style="margin-left: 1em">者太陽躔一宫之時與月會合二次以成者也其月因</span>  
<span style="margin-left: 1em">無中氣故謂之閏但古法置閏用平節氣而新法用太</span>  
<span style="margin-left: 1em">陽所躔天度節氣故閏有合有否或先後一月不等也</span>  
<span style="margin-left: 3em">晝夜晨昏</span>  
<span style="margin-left: 1em">太陽隨宗動天西行一周而復于元界謂之一日東升</span>  
<span style="margin-left: 1em">西降循環無端其在曆家起算判定一界以爲依據則</span>  
<span style="margin-left: 1em">恒以太陽在子在午爲準也論從子午起算之日每歲</span>  
<span style="margin-left: 1em">實行度分日日不等差較一刻有餘蓋緣黃道夏遲冬</span>  
<span style="margin-left: 1em">疾差餘四分而黃赤二道又廣狹異距則率度必不同</span>  
<span style="margin-left: 1em">分此其所當審者也今論晝夜太陽在地平上人目可</span>  
<span style="margin-left: 1em">得而覩謂之晝太陽漸隱地平之下人目無見則謂之</span>  
<span style="margin-left: 1em">夜是晝夜者全由人居以分隨方<sub class="note-yuan">極出地若干</sub>隨時<sub class="note-yuan">太陽躔某宮</sub></span>  
<span style="margin-left: 1em">其晝夜刻分皆可依法推算焉然而法算與目見恒異</span>  
<span style="margin-left: 1em">蓋太陽體大算法皆以體心出地爲晝始而人目以一</span>  
<span style="margin-left: 1em">見日輪即爲晝始又日出没升降度有斜正不同又地</span>  
<span style="margin-left: 1em">平各曜出没之界受清蒙氣有變凡此皆非人目能辨</span>  
<span style="margin-left: 1em">故曆家立有視差法也一晝一夜平分爲十二時時各</span>  
<span style="margin-left: 1em">八刻一日十二時共刻九十有六此恒率也其晝夜永</span>  
<span style="margin-left: 1em">短遞遷之故則不但日行南陸北陸不同而已亦由北</span>  
<span style="margin-left: 1em">極出地高卑互異而永短因焉比如赤道正過天頂之</span>  
<span style="margin-left: 1em">地兩極合於地平其晝夜均停絕無永短又極在天頂</span>  
<span style="margin-left: 1em">赤道與地平平行其下晝夜亦無長短之較但太陽百</span>  
<span style="margin-left: 1em">八十日恒見百八十日恒隱耳此外諸方各有永短顧</span>  
<span style="margin-left: 1em">其一歲之中晝夜均停者四日握算者引而伸之據四</span>  
<span style="margin-left: 1em">日之一日逐漸加减因得九十日之晝夜長短隨可以</span>  
<span style="margin-left: 1em">推終歲之數也再論晨昏是分晝分夜之二界也太陽</span>  
<span style="margin-left: 1em">將出未出數刻之前其光東發星光漸爲所奪是名爲</span>  
<span style="margin-left: 1em">晨太陽已入迴光返照亦經數刻始逌然滅盡是名爲</span>  
<span style="margin-left: 1em">昏其久暫分數亦因冬夏而分短長新法以日在地平</span>  
<span style="margin-left: 1em">下十八度內爲晨昏之限但太陽行此十八度又各方</span>  
<span style="margin-left: 1em">各宫不等因有五刻七刻十刻之別若論極高七十二</span>  
<span style="margin-left: 1em">度以上之度則夏月晨昏相切雖至丙夜無甚黯黑也</span>  
<span style="margin-left: 3em">太陰</span>  
<span style="margin-left: 1em">太陰之行參錯不一推步籌算爲力倍艱苟或分秒乖</span>  
<span style="margin-left: 1em">違交食豈能密合故必細審其行度所以然而後可立</span>  
<span style="margin-left: 1em">法致用也蓋月較諸曜本旋之外行復多種第一曰平</span>  
<span style="margin-left: 1em">行一日十三度有奇但此行之界凡四一界是從某官</span>  
<span style="margin-left: 1em">次度分起算此界定而不動二界爲本天之最高此非</span>  
<span style="margin-left: 1em">定界每日自順天右行七分有奇是月距本天最高一</span>  
<span style="margin-left: 1em">日爲十三度三分有奇也故其平行二十七日三十刻</span>  
<span style="margin-left: 1em">有奇爲一周已復于宫次元度又必再行二十三刻有</span>  
<span style="margin-left: 1em">奇爲二十七日五十三刻始能及于本天之最高此行</span>  
<span style="margin-left: 1em">新法謂之月自行中曆于此周謂之轉周滿一周謂之</span>  
<span style="margin-left: 1em">轉終其最高則行八年有奇而周天謂之月孛三界爲</span>  
<span style="margin-left: 1em">黃白二道相交之所所謂正交中交此界亦自有行乃</span>  
<span style="margin-left: 1em">逆行也<sub class="note-yuan">自東而西</sub>每日三分有奇則月平行距正交一日爲</span>  
<span style="margin-left: 1em">十三度十三分有奇至二十七日二十七刻减交行之</span>  
<span style="margin-left: 1em">一度二十三分得二十七日十五刻有奇月乃回于元</span>  
<span style="margin-left: 1em">界曆謂之交終四界是與太陽去離太陽一日約行一</span>  
<span style="margin-left: 1em">度則太陰距太陽爲十二度十分有奇至二十九日五</span>  
<span style="margin-left: 1em">十三刻有奇逐及太陽復與之會曆謂朔策是也凡上</span>  
<span style="margin-left: 1em">四行總歸第一平行其第二行曰小輪每一朔內行滿</span>  
<span style="margin-left: 1em">輪周二次每日爲二十四度有奇<sub class="note-yuan">若以不同心圈論此即太陰中距圈也</sub></span>  
<span style="margin-left: 1em">因有此行復生第二損益加减分云第二者蓋于朔望</span>  
<span style="margin-left: 1em">所用加减分外再加再减故也此行中曆所無以上太</span>  
<span style="margin-left: 1em">陰諸行新法定其軌轍不外三者均圈一不同心圈一</span>  
<span style="margin-left: 1em">小輪一然不同心圈與小輪名異而理實同曆家資以</span>  
<span style="margin-left: 1em">推算兩用互推所得之數正等也</span>  
<span style="margin-left: 3em">一系月道惟一古謂月行九道者乃白道正交行</span>  
<span style="margin-left: 4em">及四正陰陽二曆各異命之因有八名加以公</span>  
<span style="margin-left: 4em">名共有九耳非真有九道也白道兩交黃道論</span>  
<span style="margin-left: 4em">最遠之距謂爲五度此係二曆未甚大差之數</span>  
<span style="margin-left: 4em">新法測得凡朔望外相距皆過五度上下二弦</span>  
<span style="margin-left: 4em">則爲五度一十七分三十秒推知二道相交之</span>  
<span style="margin-left: 4em">角非定而不動者要其廣狹之行恒以十五日</span>  
<span style="margin-left: 4em">爲限也</span>  
<span style="margin-left: 3em">二系合朔後月夕西見遲疾不一甚有差至三日</span>  
<span style="margin-left: 4em">者其故有三一因月視行度視行爲疾段則疾</span>  
<span style="margin-left: 4em">見遲段則遲見一因黃道升降或斜或正正必</span>  
<span style="margin-left: 4em">疾見斜必遲見一因白道在緯南緯北凡在陰</span>  
<span style="margin-left: 4em">曆疾見陽曆遲見也此外又有極出地之不同</span>  
<span style="margin-left: 4em">朦朧分與炁差諸異所以遲疾難齊也</span>  
<span style="margin-left: 3em">交食</span>  
<span style="margin-left: 1em">凡日月之行二十九日有奇而東西同度謂之會朔至</span>  
<span style="margin-left: 1em">若日行在黃道近交人視爲與日同經同緯是人目與</span>  
<span style="margin-left: 1em">月日相參直而月魄正隔日光于人目則爲日食日食</span>  
<span style="margin-left: 1em">者非日失其光光爲月掩耳凡太陰距太陽百八十度</span>  
<span style="margin-left: 1em">而正與之衝謂之望若當衝時月行近于兩交必入地</span>  
<span style="margin-left: 1em">景而爲闇虛此乃月日同在一線而地居其中間日光</span>  
<span style="margin-left: 1em">爲地所阻不能射照月體則月失其光而爲月食此日</span>  
<span style="margin-left: 1em">月二食者躔度有恒持籌推步分秒確然而曆家各法</span>  
<span style="margin-left: 1em">之疎密于此更難掩也試言其畧黃白二道相交之二</span>  
<span style="margin-left: 1em">所名正交中交凡日月行及二交爲同度同度則有食</span>  
<span style="margin-left: 1em">矣然而論交又須論限及交而在限內則食限外則不</span>  
<span style="margin-left: 1em">食此不可不審也顧限度諸方不一蓋太陽於諸方之</span>  
<span style="margin-left: 1em">地平高度不同而陰陽二曆之各限亦異論煖帶下之</span>  
<span style="margin-left: 1em">地二曆互相受變如白道向南極半周有時在天頂及</span>  
<span style="margin-left: 1em">黃道之中勢必反謂爲陰曆白道向北平周是時在黃</span>  
<span style="margin-left: 1em">道外勢必反謂爲陽曆故其下日食之限莫得而定之</span>  
<span style="margin-left: 1em">也他域更近于北必陰曆限多陽曆限少更近于南必</span>  
<span style="margin-left: 1em">陽曆限多陰曆限少比如京師近北約算陽曆八度陰</span>  
<span style="margin-left: 1em">曆二十一度則知日月相會凡在陽曆近二交八度在</span>  
<span style="margin-left: 1em">陰曆近二交二十一度其下必見日食而過此限以往</span>  
<span style="margin-left: 1em">則否即北可以推南莫不以遠近分多寡矣然而二曆</span>  
<span style="margin-left: 1em">食限之度有異者其故蓋在月輪月輪比日最近于地</span>  
<span style="margin-left: 1em">而月又小于地人目見月之所又在地面不在地心故</span>  
<span style="margin-left: 1em">以月天論地平雖天與地球皆爲平分直過其心而人</span>  
<span style="margin-left: 1em">在地面高所以視天地之兩界則似地球與月天非平</span>  
<span style="margin-left: 1em">分也少半在上多半在下而差約一度故以本法推算</span>  
<span style="margin-left: 1em">月已出正地平其于人目所視之地平尚少一度此其</span>  
<span style="margin-left: 1em">較謂之視差蓋惟月在天頂正地平與視地平之極皆</span>  
<span style="margin-left: 1em">以一直線合于天頂無有視差過此左右不免有差愈</span>  
<span style="margin-left: 1em">遠天頂愈近地平差必愈甚夫視差無他恒降下月體</span>  
<span style="margin-left: 1em">數十分耳設令日月同度同在近交之南又因同度並</span>  
<span style="margin-left: 1em">在正地平上高二十度則太陽于視地平爲十九度五</span>  
<span style="margin-left: 1em">十八分祗降二分太陰于視地平爲十九度直降一度</span>  
<span style="margin-left: 1em">矣而日月二差之較爲五十八分故以算論雖二曜同</span>  
<span style="margin-left: 1em">高同度而人目視之太陰恒下于太陽一度弱不掩日</span>  
<span style="margin-left: 1em">光則不食若二曜在地平上高七十度則太陽無視差</span>  
<span style="margin-left: 1em">太陰視差止二十分其降于太陽亦止二十分勢必相</span>  
<span style="margin-left: 1em">切或至掩數分而成食若二曜在交北又當以太陰算</span>  
<span style="margin-left: 1em">在太陽之上庶因視差所降而掩陽光以爲食也顧此</span>  
<span style="margin-left: 1em">二地平之差又分二類一加减交食分數謂之氣差一</span>  
<span style="margin-left: 1em">加减時刻謂之時差曆算之艱且劇莫過於此所最當</span>  
<span style="margin-left: 1em">究心者也</span>  
<span style="margin-left: 3em">系日食之全與不全其故有二一由天上之行一</span>  
<span style="margin-left: 4em">由食時地平上高弧之度故均一食也有見全</span>  
<span style="margin-left: 4em">食者有見食多寡不等者有全不見食者就南</span>  
<span style="margin-left: 4em">北論見食地界設如北京見全食其南北谷距</span>  
<span style="margin-left: 4em">四十五度之地爲萬一千有餘里皆見有食然</span>  
<span style="margin-left: 4em">而多寡不等就東西論各距六十度爲萬五千</span>  
<span style="margin-left: 4em">有餘里各見食而分數多寡亦不等焉即月食</span>  
<span style="margin-left: 4em">時刻南北亦有不同而東西爲甚也</span>  
<span style="margin-left: 3em">三餘</span>  
<span style="margin-left: 1em">三餘舊加紫氣名爲四餘亦謂之四隱曜然詳求天行</span>  
<span style="margin-left: 1em">實無紫氣且絕無當於推步之術故西法棄而不錄第</span>  
<span style="margin-left: 1em">取三餘一羅㬋一計都一月孛羅㬋即白道之正交計</span>  
<span style="margin-left: 1em">都即中交也月道自南遡北以交于黃道之一點此點</span>  
<span style="margin-left: 1em">有本行每日左旋三分有奇而羅㬋正對之點即爲計</span>  
<span style="margin-left: 1em">都蓋兩規斜絡其兩交之二點必正相對也月孛是月</span>  
<span style="margin-left: 1em">所行圈極高極遠之點謂月離于是其行極遲其體見</span>  
<span style="margin-left: 1em">極小蓋孛云者指其交轉兩行相悖之義故其平行右</span>  
<span style="margin-left: 1em">旋每日七分有奇是三點者土木火諸星本圈亦有之</span>  
<span style="margin-left: 1em">名義皆同第其各行不同耳古曆悉所未諳悉置不推</span>  
<span style="margin-left: 1em">不錄新法用算五星之緯故于本曆名詳其名數云獨</span>  
<span style="margin-left: 1em">惜日者之流以羅計月孛等名皆指爲星謂其所躔宿</span>  
<span style="margin-left: 1em">度各有吉凶用以推人祿命不知周天諸道諸點皆人</span>  
<span style="margin-left: 1em">所設以便揆算其行度耳並非實物何與吉凶至紫氣</span>  
<span style="margin-left: 1em">一曜或謂生于閏餘或謂土木相會或謂古人以是紀</span>  
<span style="margin-left: 1em">直年宿故二十八年而一周天都無義理可考故月離</span>  
<span style="margin-left: 1em">曆指詳論其必無是曜也</span>  
<span style="margin-left: 3em">五緯異行</span>  
<span style="margin-left: 1em">土木火金水五曜名爲緯星者謂其日有近南近北之</span>  
<span style="margin-left: 1em">行與恒星異也夫五緯之行各有二種其一爲本行如</span>  
<span style="margin-left: 1em">填星約三十年行天一周日二分歲星約十二年一周</span>  
<span style="margin-left: 1em">天日五分熒惑將滿二年一周天日三十五分太白辰</span>  
<span style="margin-left: 1em">星皆隨太陽每年旋天一周各有盈縮各有加减分各</span>  
<span style="margin-left: 1em">有本天之最高與最衝即其最高又各有本行論其行</span>  
<span style="margin-left: 1em">界亦分四種非若回回曆總一最高也其二在于本行</span>  
<span style="margin-left: 1em">之外西法稱爲歳行蓋各星會太陽一次成一周也因</span>  
<span style="margin-left: 1em">此歲行之規<sub class="note-yuan">亦名小輪</sub>推知各星順逆留疾諸情故依新法</span>  
<span style="margin-left: 1em">圖五緯各有一不同心圈一均圈一小輪凡星在小輪</span>  
<span style="margin-left: 1em">極遠之所必合太陽其行順而疾其體見小凡在小輪</span>  
<span style="margin-left: 1em">極近之所其行逆而疾其體見大土木火行逆則衝太</span>  
<span style="margin-left: 1em">陽金水行逆夕伏而合行順晨伏而合其各順行轉逆</span>  
<span style="margin-left: 1em">逆行轉順之兩中界爲留留非不行乃際於極遲行之</span>  
<span style="margin-left: 1em">所也留段前後或順或逆皆有遲行其土木火行逆即</span>  
<span style="margin-left: 1em">衝太陽而金水則否者緣土木火之本天大皆以太陽</span>  
<span style="margin-left: 1em">爲心而包地得與太陽衝而金水之本天雖亦以太陽</span>  
<span style="margin-left: 1em">爲心而不包地不能衝太陽也金水不能衝太陽而能</span>  
<span style="margin-left: 1em">與之離金離太陽四十八度水離二十四度</span>  
<span style="margin-left: 3em">五緯緯行</span>  
<span style="margin-left: 1em">太陽之行因黃道斜交于赤道故其距赤道之緯南緯</span>  
<span style="margin-left: 1em">北也各二十三度有半以成二至是黃道者太陽之軌</span>  
<span style="margin-left: 1em">蹟也太陰本道又斜交於黃道最遠之距爲五度以生</span>  
<span style="margin-left: 1em">陰陽二曆五星之道雖相距緯度各異而其斜絡黃道</span>  
<span style="margin-left: 1em">則與月道同理故皆借月道諸名名之其兩交之所亦</span>  
<span style="margin-left: 1em">謂正交中交其在南在北兩半周亦謂陰陽二曆審是</span>  
<span style="margin-left: 1em">而五星緯行庶可詳求矣蓋各本道外之歲行小輪恒</span>  
<span style="margin-left: 1em">與黃道爲平行而又斜交於本道其上半恒在黃本二</span>  
<span style="margin-left: 1em">道中凡道躔于此則减本道之緯其下半恒在本道外</span>  
<span style="margin-left: 1em">星躔于此則加其緯然此小輪之緯向則恒不變如土</span>  
<span style="margin-left: 1em">星三十年行天一周其在正中二交之下必無緯度分</span>  
<span style="margin-left: 1em">十五年恒北十五年恒南耳凡衝太陽因在小輪下半</span>  
<span style="margin-left: 1em">即加本道緯度凡會太陽因在小輪上半即减緯度他</span>  
<span style="margin-left: 1em">星亦猶是也其或行近于地小輪加緯益多太白至夕</span>  
<span style="margin-left: 1em">伏合之際因其近地其緯幾及八度矣中曆不諳緯行</span>  
<span style="margin-left: 1em">之原一見金星在緯南北七八九度即詑謂本星失行</span>  
<span style="margin-left: 1em">豈非誣乎又中曆亦有五星南北緯行圖亦界以黃道</span>  
<span style="margin-left: 1em">本道似矣但其逆行之蹟恒作一斜方形此甚非也五</span>  
<span style="margin-left: 1em">緯不行直線安得方形以此新法圖分二種一設人在</span>  
<span style="margin-left: 1em">地仰觀天上進退諸行故於上三星衝太陽下二星夕</span>  
<span style="margin-left: 1em">伏時第作一僅似之圓形凡衝太陽如在本道交上則</span>  
<span style="margin-left: 1em">不作圓形即彷彿一之字形而已一各星近遠於地之</span>  
<span style="margin-left: 1em">圖要皆舊曆所未諳也</span>  
<span style="margin-left: 3em">五星伏見</span>  
<span style="margin-left: 1em">五星之光與日相較譬猶螢火之于庭燎光本非滅第</span>  
<span style="margin-left: 1em">爲大光所奪人莫能睹耳舊曆亦曉此理故用黃道距</span>  
<span style="margin-left: 1em">度以定諸星伏見如謂太陽在降婁初度歲星在十五</span>  
<span style="margin-left: 1em">度即以爲見限似矣然而諸星各有緯南緯北之分黃</span>  
<span style="margin-left: 1em">道有正斜升降之勢各宫不同何得泥距度以定限乎</span>  
<span style="margin-left: 1em">新法定限惟以地平爲主緣地平障蔽日光能使星或</span>  
<span style="margin-left: 1em">伏或見耳夫日之下于地平其光漸殺所謂晨昏此晨</span>  
<span style="margin-left: 1em">昏光之久暫四時不等即冥漠等矣而星見時刻又自</span>  
<span style="margin-left: 1em">不等所以然者太陽由黃道而下地平或十度或十五</span>  
<span style="margin-left: 1em">度或至三十度有奇原自不等而星在黃道南相距必</span>  
<span style="margin-left: 1em">多數度在北相距必少數度其限豈可泥乎大畧土木</span>  
<span style="margin-left: 1em">火三星較太陽行遲行後太陽夕伏晨見金水二星順</span>  
<span style="margin-left: 1em">天東旋較太陽行疾行先太陽晨伏夕見逆行反是其</span>  
<span style="margin-left: 1em">與太陽遇也亦夕伏晨見太陰行較太陽更疾晨伏夕</span>  
<span style="margin-left: 1em">見至于金星之緯不及八度則凡逆行合太陽于壽星</span>  
<span style="margin-left: 1em">大火二宫而其緯又在北七度以上雖與日合其光不</span>  
<span style="margin-left: 1em">伏一日晨夕皆可見之水星之緯惟四度餘若其緯向</span>  
<span style="margin-left: 1em">南合太陽於壽星此後去離夕必不見合太陽于降婁</span>  
<span style="margin-left: 1em">此後去離晨必不見金合而不伏水離而不見此二故</span>  
<span style="margin-left: 1em">者渾儀解之他如恒星亦有夕伏晨見者一因黃道之</span>  
<span style="margin-left: 1em">經緯度一因其小大等第即爲見伏之限故亦可推也</span>  
<span style="margin-left: 3em">測太陽</span>  
<span style="margin-left: 1em">諸曜森羅太陽其宗主也或推或測必首太陽顧其應</span>  
<span style="margin-left: 1em">測之行不外三種一曰盈縮之限一曰盈縮細行一曰</span>  
<span style="margin-left: 1em">盈初縮末之所中曆之測太陽未嘗及此三行即所測</span>  
<span style="margin-left: 1em">止冬夏二至猶未盡善也其法立八尺表用景符器于</span>  
<span style="margin-left: 1em">冬至前後三四日測定三景因以三景之較數求太陽</span>  
<span style="margin-left: 1em">到冬至時刻其法未嘗不是所以爲未盡善者蓋表景</span>  
<span style="margin-left: 1em">短長乃太陽行南行北所生論其近二至之候南北之</span>  
<span style="margin-left: 1em">行極微計一日所行天度有分半者有一分者有半分</span>  
<span style="margin-left: 1em">者乃于冬至近期建表尋丈而其所得二景差爲一分</span>  
<span style="margin-left: 1em">二釐<sub class="note-yuan">量度則云分秒量景則云丈尺分釐</sub>釐爲八刻而此一二釐間相差</span>  
<span style="margin-left: 1em">甚微彼景符曷能定之况景符光線恒占數釐或更稍</span>  
<span style="margin-left: 1em">爲進退其失彌甚是恒差數十刻也若測夏至則倍難</span>  
<span style="margin-left: 1em">矣今新法用八線表法查古所遺之數以用于推步庶</span>  
<span style="margin-left: 1em">稱密近耳然又不但用表亦時用別法以相濟也比如</span>  
<span style="margin-left: 1em">春秋二分太陽之南北行較大日行天度二十四分乃</span>  
<span style="margin-left: 1em">於其前後數日先測極出地度得赤道高次用象限儀</span>  
<span style="margin-left: 1em">測日軌高不免相差一分而其于本算日軌入交點時</span>  
<span style="margin-left: 1em">刻則約差四刻耳較之以尋丈表測冬至差釐數而乖</span>  
<span style="margin-left: 1em">違數十刻者豈不大相遠哉且新法于太陽實躔宫度</span>  
<span style="margin-left: 1em">分秒逐日可測而舊法于二至外推步遂窮何也又新</span>  
<span style="margin-left: 1em">法本測曰太陽從春分底立夏行黃道四十五度歷四</span>  
<span style="margin-left: 1em">十六日十刻十分又從立秋底秋分亦四十五度而所</span>  
<span style="margin-left: 1em">歷則四十六日三十八刻十分是逐日刻數不等所謂</span>  
<span style="margin-left: 1em">春行盈秋行縮也故定此盈縮初末之界非在二至點</span>  
<span style="margin-left: 1em">也乃在二至之後六度<sub class="note-yuan">古今不同</sub>若如舊法謂恒在二至則</span>  
<span style="margin-left: 1em">是前後行度等也何爲所歷之期日刻數不等乎此率</span>  
<span style="margin-left: 1em">古稱盈末縮初新法稱爲最高因有此最高遂晰太陽</span>  
<span style="margin-left: 1em">之行爲一不同心規也其行遲者在最高行疾者在最</span>  
<span style="margin-left: 1em">高之衝此最高本行亦猶太陰之有月孛云</span>  
<span style="margin-left: 3em">測恒星</span>  
<span style="margin-left: 1em">測星之法不一大要以太陽爲主而以太陰或太白或</span>  
<span style="margin-left: 1em">歲星爲中次任取某星爲界互相測度即得其度法于</span>  
<span style="margin-left: 1em">太陽將入之時測月或太白或歲星其距太陽度分若</span>  
<span style="margin-left: 1em">干日既没再測月或太白或歲星其與某星相距度分</span>  
<span style="margin-left: 1em">若干合兩測即得太陽與此星之距然後查太陽本日</span>  
<span style="margin-left: 1em">躔某宫度則知此星所在宫度矣測一星之經度如此</span>  
<span style="margin-left: 1em">他星可以類推于是又測此星出地平之最高即其距</span>  
<span style="margin-left: 1em">極距赤道之緯度并可得也然而恒星之經緯度分有</span>  
<span style="margin-left: 1em">二其一以黃極爲樞每歲東行五十一秒有奇而其距</span>  
<span style="margin-left: 1em">本極之緯度則亘古無變其一則因赤道以算其經緯</span>  
<span style="margin-left: 1em">南北星位古今大異如堯時外屏星全座在赤道南今</span>  
<span style="margin-left: 1em">則在北角宿古在北者今亦在南星緯變易類多如此</span>  
<span style="margin-left: 1em">至以赤道論各宿距度亦有異者如觜宿距星上古爲</span>  
<span style="margin-left: 1em">三度歷代遞減今且侵入參宿二十四分他宿互有損</span>  
<span style="margin-left: 1em">益距度各各不同因知赤極非恒星之極而其經緯之</span>  
<span style="margin-left: 1em">度亦非赤道之經緯度分也由是觀之象數精微彌測</span>  
<span style="margin-left: 1em">彌明彼有畫者流輙謂循古已足豈其然哉</span>  
<span style="margin-left: 3em">測太陰</span>  
<span style="margin-left: 1em">太陰行度所當測定者五一遲疾之限一遲疾初末一</span>  
<span style="margin-left: 1em">月孛行一每日細行一交行五測有一不詳月離之違</span>  
<span style="margin-left: 1em">合難齊矣又月有氣差時差<sub class="note-yuan">即地半徑所生</sub>所測之經緯度分</span>  
<span style="margin-left: 1em">于正度分復有相較以此測月于七政中爲最難舊曆</span>  
<span style="margin-left: 1em">用表于午正測定三景以求之越四載而得一次測驗</span>  
<span style="margin-left: 1em">之時九載而復推定疑太拙矣新法用三會食推算其</span>  
<span style="margin-left: 1em">法以食甚正對太陽得月經度以食甚分秒得距交若</span>  
<span style="margin-left: 1em">干以各食中積時日刻數不等并得天上所行不等度</span>  
<span style="margin-left: 1em">分于是用本法以求月天之孛或最高<sub class="note-yuan">即極遲之行</sub>亦遂得</span>  
<span style="margin-left: 1em">平視二行相較之度以簡御繁法莫善於此矣其測上</span>  
<span style="margin-left: 1em">下二弦經度亦有本法蓋弦乃太陰實距太陽或東或</span>  
<span style="margin-left: 1em">西九十度即周天四分之一也先以本儀測定其限次</span>  
<span style="margin-left: 1em">用法算其平行因其加分恒與所測差二度餘賴有二</span>  
<span style="margin-left: 1em">三均數測算乃合又弦時去離南北所測與算亦較天</span>  
<span style="margin-left: 1em">度差四分之一緣白道斜交黃道相距度分各廣狹不</span>  
<span style="margin-left: 1em">同故也至太陰之掩恒星測其出入亦可以知月離度</span>  
<span style="margin-left: 1em">分但須先以地半徑差均之</span>  
<span style="margin-left: 3em">測五緯</span>  
<span style="margin-left: 1em">上三星爲土木火與太陽相衝會然于衝會之二時各</span>  
<span style="margin-left: 1em">無歲行加减分緣其會太陽即在歲行圈之最高而衝</span>  
<span style="margin-left: 1em">之即在其最卑于實行爲合故也須知實行與平行不</span>  
<span style="margin-left: 1em">同平行百千萬年維均各星本天各有遲疾<sub class="note-yuan">即最高最卑</sub>然</span>  
<span style="margin-left: 1em">而星合太陽無從可測每於其衝測之<sub class="note-yuan">測其對太陽用恒星各經度或</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">太陽躔度推算</sub>得此衝經度即有中積天度日數及本星隨日</span>  
<span style="margin-left: 1em">數之平行而後用此三率以求各星木天最高之所于</span>  
<span style="margin-left: 1em">是又得其盈縮大差因并得衝時各星以平行距冬至</span>  
<span style="margin-left: 1em">之界若干矣下二星爲金水以其不能衝太陽也測之</span>  
<span style="margin-left: 1em">較難法先于或晨或昏求其與太陽距度者數次然後</span>  
<span style="margin-left: 1em">依法測算即可得其本天諸情也凡歲行之測以二留</span>  
<span style="margin-left: 1em">爲本二留之限各星不同即所躔天度亦不同然而星</span>  
<span style="margin-left: 1em">在二留非衝太陽乃折中之度故本之以測歲行也下</span>  
<span style="margin-left: 1em">三星亦然又二留之際因無歲圈緯度故可得其本天</span>  
<span style="margin-left: 1em">之緯其或在日之衝距緯極遠又可得歲圈之本緯矣</span>  
<span style="margin-left: 1em">五星之天皆斜交黃道與白道同但其相距之緯各多</span>  
<span style="margin-left: 1em">寡不等又白道交行右旋而五星左旋此其異也</span>  
<span style="margin-left: 3em">測器</span>  
<span style="margin-left: 1em">夫測器之在曆家猶之工師之準繩規矩不可須臾離</span>  
<span style="margin-left: 1em">也蓋宿曜運行樊然不齊苟欲齊之非器不可矣然而</span>  
<span style="margin-left: 1em">簡便是求制作未能盡善雖欲齊烏得齊古曆所紀原</span>  
<span style="margin-left: 1em">有數種而今靈臺所存止有圭表景符簡儀渾象等器</span>
