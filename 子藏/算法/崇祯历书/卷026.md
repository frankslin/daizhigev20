## 崇祯历书卷之二十六　康熙奏疏

*康熙十七年七月十一日至康熙二十七年三月初四日*

<span style="margin-left: 2em">奏疏十二</span>  
<span style="margin-left: 4em">康熙十七年七月十一日礼部题本</span>  
<span style="margin-left: 3em">礼部　题为</span>  
<span style="margin-left: 1em">钦命预推康熙永年历法告成著有书表详载推法以</span>  
<span style="margin-left: 3em">传永久以光</span>  
<span style="margin-left: 2em">国典事　钦天监治理历法加太常寺卿南怀仁奏</span>  
<span style="margin-left: 3em">前事等因康熙十七年七月十一日奏本月十七</span>  
<span style="margin-left: 3em">日奉</span>  
<span style="margin-left: 1em">旨据奏预造康熙永年历永为后式尽心推算可嘉著</span>  
<span style="margin-left: 3em">议叙具奏于七月十八日到部</span>  
<span style="margin-left: 3em">议得治理历法南怀仁疏称奉</span>  
<span style="margin-left: 2em">命臣将先臣汤若望遗留诸历二百年恒表相继预</span>  
<span style="margin-left: 3em">推至数千年之后以垂永久今已告成预推将来</span>  
<span style="margin-left: 3em">二千年其历书三十二卷名为康熙永年历法</span>  
<span style="margin-left: 2em">进呈</span>  
<span style="margin-left: 1em">御览等因具题奉</span>  
<span style="margin-left: 1em">旨据奏预造康熙永年历永为后式尽心推算可嘉著</span>  
<span style="margin-left: 3em">议叙具奏该部知道历并发查得康熙十三年因</span>  
<span style="margin-left: 3em">仪象告成制造精密从优议叙之处交与吏部议</span>  
<span style="margin-left: 3em">叙在案今永年历法告成相应将治理历法加太</span>  
<span style="margin-left: 3em">常寺卿南怀仁由吏部议叙可也</span>  
<span style="margin-left: 3em">奉</span>  
<span style="margin-left: 1em">旨依议永年历本内并未议及著再议具奏</span>  
<span style="margin-left: 8em">康熙十七年八月二十日礼部题本</span>  
<span style="margin-left: 3em">礼部　题为</span>  
<span style="margin-left: 1em">钦命预推康熙永年历法告成著有书表详载推法以</span>  
<span style="margin-left: 3em">传永久以光</span>  
<span style="margin-left: 2em">国典事该臣等题前事奉</span>  
<span style="margin-left: 1em">旨依议永年历本内并未议及著再议具奏再议得先</span>  
<span style="margin-left: 3em">经臣部因永年历法告成缘由将治理历法加太</span>  
<span style="margin-left: 3em">常寺卿南怀仁由吏部议叙等因具题奉</span>  
<span style="margin-left: 1em">旨依议永年历本内并未议及著再议具奏钦此随行</span>  
<span style="margin-left: 3em">查钦天监去后今准呈称顺治贰年拾贰月掌管</span>  
<span style="margin-left: 3em">钦天监印务汤若望奏为新历告成恭呈</span>  
<span style="margin-left: 1em">御览以昭成宪以光史册事壹疏奉</span>  
<span style="margin-left: 1em">圣旨新历密合天行已经颁用这所进历书考据精详</span>  
<span style="margin-left: 3em">理明数著著该监局官生用心肄习永远遵守仍</span>  
<span style="margin-left: 3em">宣付史馆以彰大典汤若望勤慎可嘉宜加叙赉</span>  
<span style="margin-left: 3em">著吏礼二部议奏该衙门知道钦此今南怀仁</span>  
<span style="margin-left: 2em">进呈</span>  
<span style="margin-left: 1em">御览康熙永年历乃系按推汤若望所推二百年恒表</span>  
<span style="margin-left: 3em">之历亦应交与翰林院仍著该监官生用心肄习</span>  
<span style="margin-left: 3em">永远遵行可也</span>  
<span style="margin-left: 3em">八月二十日奉</span>  
<span style="margin-left: 1em">旨依议</span>  
<span style="margin-left: 7em">康熙十七年九月二十一日吏部题本</span>  
<span style="margin-left: 3em">吏部　题为</span>  
<span style="margin-left: 1em">钦命预推康熙永年历法告成著有书表详载推法以</span>  
<span style="margin-left: 3em">传永久以光</span>  
<span style="margin-left: 2em">国典事该臣等再议得先经臣部复礼部疏称治理</span>  
<span style="margin-left: 3em">历法加太常寺卿南怀仁预造康熙永年历永为</span>  
<span style="margin-left: 3em">后式应将南怀仁于见任内加一级等因具题奉</span>  
<span style="margin-left: 1em">旨这所议尚轻著再议具奏应将治理历法加太常寺</span>  
<span style="margin-left: 3em">卿南怀仁加为通政使司通政使职衔仍加一级</span>  
<span style="margin-left: 3em">九月二十一日奉</span>  
<span style="margin-left: 1em">旨南怀仁著加为通政使司通政使职衔仍加一级</span>  
<span style="margin-left: 7em">康熙十七年十月初八日南怀仁奏本</span>  
<span style="margin-left: 3em">钦天监治理历法加太常寺卿臣南怀仁谨</span>  
<span style="margin-left: 2em">奏为恳辞溢衔之</span>  
<span style="margin-left: 1em">宠命以安守愚分事窃臣以永年历表告成恭</span>  
<span style="margin-left: 2em">进全书深荷</span>  
<span style="margin-left: 1em">纶音褒嘉随奉</span>  
<span style="margin-left: 1em">旨南怀仁著加为通政使司通政使职衔仍加一级臣</span>  
<span style="margin-left: 3em">伏读</span>  
<span style="margin-left: 1em">恩纶感激之余不胜愧汗盖臣业身任治历厚蒙豢养</span>  
<span style="margin-left: 3em">循分自尽未罄涓埃何敢萌非分之念乎臣原不</span>  
<span style="margin-left: 3em">婚不宦自幼以修道为本业虽修道原治内心非</span>  
<span style="margin-left: 3em">关外貌而朝绅之中亦可存缮性之功布衣之下</span>  
<span style="margin-left: 3em">亦有藏荣适之想但职任所责皆措理外务而难</span>  
<span style="margin-left: 3em">暇治内故谢绝世务勤励于正心诚意乃修道之</span>  
<span style="margin-left: 3em">本志耳向荷</span>  
<span style="margin-left: 1em">皇上准臣专办历务免选择相度等监副监正之职是</span>  
<span style="margin-left: 3em">职官既已蒙宽免今又领受高衔此微臣之心不</span>  
<span style="margin-left: 3em">安者一年也夫</span>  
<span style="margin-left: 2em">国家增秩加衔之典原以酬赏才能故才能必须与</span>  
<span style="margin-left: 3em">职衔相当倘才能低下不符职衔之崇高则如身</span>  
<span style="margin-left: 3em">短衣长不相称也臣见蒙太常之衔已属逾分本</span>  
<span style="margin-left: 3em">愿再辞今复加大卿之衔尤为越分伏睹</span>  
<span style="margin-left: 1em">皇上弘恩如海洋溢大小高下无不充满但臣才下器</span>  
<span style="margin-left: 3em">小岂能容受此微臣之心不安者二也我</span>  
<span style="margin-left: 1em">皇上辉光并日自东至西万方普照臣本西陬鄙儒即</span>  
<span style="margin-left: 3em">在九万里远地举目遥瞻尚难当彩耀若阶荣上</span>  
<span style="margin-left: 3em">卿去天咫尺能不昏瞀哉此微臣之心不安者三</span>  
<span style="margin-left: 3em">也至于预推永年历表不过臣应尽之职分若缘</span>  
<span style="margin-left: 3em">此加衔则以后凡分内竭力之事如理推天象等</span>  
<span style="margin-left: 3em">书何敢具疏请</span>  
<span style="margin-left: 1em">旨恐人指谓图名求荣之为耳此微臣之心不安者四</span>  
<span style="margin-left: 3em">也伏乞</span>  
<span style="margin-left: 1em">皇上俯鉴愚衷收回</span>  
<span style="margin-left: 1em">成命俾臣照旧以闲散办事澹泊修身得以安心发明</span>  
<span style="margin-left: 3em">理推天象等历务以图报我</span>  
<span style="margin-left: 1em">皇上格外洪恩之万一也为此具本亲赍谨具奏</span>  
<span style="margin-left: 1em">闻</span>  
<span style="margin-left: 3em">十月初八日奉</span>  
<span style="margin-left: 1em">旨南怀仁预造永年历尽心推算勤劳可嘉加衔已有</span>  
<span style="margin-left: 3em">成命不必控辞该部知道</span>  
<span style="margin-left: 11em">康熙十七年十月礼部题本</span>  
<span style="margin-left: 3em">礼部谨</span>  
<span style="margin-left: 2em">题为历法既已精详序次应行改正宜首尊</span>  
<span style="margin-left: 2em">盛京以重时宪事礼科抄出吏科给事中李宗孔题</span>  
<span style="margin-left: 3em">前事内开<sub class="note-yuan">云云</sub>等因康熙十七年十月初九日题</span>  
<span style="margin-left: 3em">本月十七日奉</span>  
<span style="margin-left: 1em">旨该部议奏钦此钦遵于本月十八日到部随问钦天</span>  
<span style="margin-left: 3em">监监正加一级宜塔喇治理历法加通政使司通</span>  
<span style="margin-left: 3em">政使仍加一级南怀仁监副降一级留任查尔大</span>  
<span style="margin-left: 3em">左监副邵泰衢右监副鲍英齐五官正魏成格屯</span>  
<span style="margin-left: 3em">主祜主簿阿莫索峩刘应昌春官正孙有本夏官</span>  
<span style="margin-left: 3em">正何雒书中官正薛文炳秋官正张问明冬官正</span>  
<span style="margin-left: 3em">何君锡等科臣李宗孔疏称历本开载太阳出入</span>  
<span style="margin-left: 2em">盛京居首及各省之节气则以朝鲜列于</span>  
<span style="margin-left: 2em">盛京之先在监臣止论节气之先后悉依地之经度</span>  
<span style="margin-left: 3em">所列为之序次</span>  
<span style="margin-left: 2em">颁行既久习矣不察嗣后历本似宜朝鲜节气附直</span>  
<span style="margin-left: 3em">省之末等语此处怎么说应否将朝鲜附于直省</span>  
<span style="margin-left: 3em">之末宜塔喇南怀仁供称敬授民时以合天为春</span>  
<span style="margin-left: 3em">王正月之义也夫历者历也不但其度分时刻等</span>  
<span style="margin-left: 3em">项应合于天即其所列先后之序次亦应合于天</span>  
<span style="margin-left: 3em">先后之序方可为全合于天矣今历本内所列诸</span>  
<span style="margin-left: 3em">省之序即全合于天地经纬之序论太阳出人则</span>  
<span style="margin-left: 3em">历本内顺其从北而南行之定序故以北为先以</span>  
<span style="margin-left: 3em">南为后今</span>  
<span style="margin-left: 2em">盛京既在诸省之最北则历本内列在诸省之先依</span>  
<span style="margin-left: 3em">其合天之序非依各省尊贵之序论各省之节气</span>  
<span style="margin-left: 3em">即顺太阳先东后西之行序因而以东为先以西</span>  
<span style="margin-left: 3em">为后今朝鲜既在诸省最东则列在诸省之先正</span>  
<span style="margin-left: 3em">合天行亦合地经纬之序若依各省尊贵定序则</span>  
<span style="margin-left: 3em">朝鲜不但论节气应附在直省之末即论太阳出</span>  
<span style="margin-left: 3em">入不应同山东列在第三行内亦分开另附于诸</span>  
<span style="margin-left: 3em">省之末矣若历本内将朝鲜列在诸省之末即如</span>  
<span style="margin-left: 3em">舆图内将最东之朝鲜移在云南最西之后如一</span>  
<span style="margin-left: 3em">年之中将先月移在于后月一月之中将先日移</span>  
<span style="margin-left: 3em">在于后日可乎此不合天地经纬之序矣况历本</span>  
<span style="margin-left: 3em">内明开载止依东西南北之先后不依各省尊贵</span>  
<span style="margin-left: 3em">之先后万国之观瞻无不易晓</span>  
<span style="margin-left: 2em">国家以治历为首务本监惟依合天行为治历之首</span>  
<span style="margin-left: 3em">务竝无习而不察之故也该臣等议得据监正宜</span>  
<span style="margin-left: 3em">塔喇南怀仁供称论太阳出入则历本内顺其从</span>  
<span style="margin-left: 3em">北而南之定序故以北为先以南为后今</span>  
<span style="margin-left: 2em">盛京既在诸省之最北故列在诸省之先论各省之</span>  
<span style="margin-left: 3em">节气顺太阳先东后西之行序因而以东为先以</span>  
<span style="margin-left: 3em">西为后今朝鲜既在诸省最东则列在诸省之先</span>  
<span style="margin-left: 3em">正合天行若历本内将朝鲜列在诸省之末即如</span>  
<span style="margin-left: 3em">舆图内最东之朝鲜移在云南最西之后可乎况</span>  
<span style="margin-left: 3em">历本内明开载止依东西南北之先后不依各省</span>  
<span style="margin-left: 3em">尊贵之先后万国之观瞻无不易晓</span>  
<span style="margin-left: 2em">国家以治历为首务本监惟依合天行为治历之首</span>  
<span style="margin-left: 3em">务竝无习而不察之故等语查得康熙八年议政</span>  
<span style="margin-left: 3em">王等会议南怀仁所推之法既合天象一应历日</span>  
<span style="margin-left: 3em">皆交与南怀仁等因在案今宜塔喇南怀仁等将</span>  
<span style="margin-left: 3em">节气顺太阳先东因朝鲜既在最东故节气处列</span>  
<span style="margin-left: 3em">在于先若列在诸省之末不合天地经纬之序矣</span>  
<span style="margin-left: 3em">相应将科臣李宗孔疏称之处无庸议奉</span>  
<span style="margin-left: 1em">旨依议</span>  
<span style="margin-left: 7em">康熙十八年十二月初五日五人题本</span>  
<span style="margin-left: 3em">钦天监监正加一级臣安泰治理历法加通政使</span>  
<span style="margin-left: 3em">司通政使仍加一级臣南怀仁监副臣查尔大左</span>  
<span style="margin-left: 3em">监副臣邵泰衢右监副臣鲍英齐等</span>  
<span style="margin-left: 2em">题为请颁七政历日以使画一遵行事切惟颁历为</span>  
<span style="margin-left: 2em">国家首务上合于天下行于人</span>  
<span style="margin-left: 2em">国家大典士民之动作诸务卜其宜忌以使画一之</span>  
<span style="margin-left: 3em">所系也今时宪历日颁于天下而各省仍不免于</span>  
<span style="margin-left: 3em">伪造私历者其故无他盖缘时宪历日之中止有</span>  
<span style="margin-left: 3em">朔望节气太阳出入昼夜长短而已凡阴阳诸家</span>  
<span style="margin-left: 3em">相度选择必以七政为本而我</span>  
<span style="margin-left: 2em">朝七政历日原颁于直隶八府未及颁行各省今臣</span>  
<span style="margin-left: 3em">监若仍止颁直隶八府而不颁各省则射利之徒</span>  
<span style="margin-left: 3em">另为铺注伪列七政名为便览通书卖于街市者</span>  
<span style="margin-left: 3em">亦未可定选择之士既不得颁行七政则不得不</span>  
<span style="margin-left: 3em">用此伪历矣诸凡士民所用之日又不得不从其</span>  
<span style="margin-left: 3em">所选是国人所用之时日乃大不合于时宪矣况</span>  
<span style="margin-left: 3em">颁历之典缘以同风俗大一统治天下如一家者</span>  
<span style="margin-left: 3em">也是以刘基云历日颁行天下使国不异政家不</span>  
<span style="margin-left: 3em">殊俗大回太古之风以成熙皞之治今正</span>  
<span style="margin-left: 2em">国家戡乱致平之时岂容此异伪之历伏乞</span>  
<span style="margin-left: 1em">睿鉴勅将七政历日亦于四月内照民历颁行各省并</span>  
<span style="margin-left: 3em">勅下各省督抚将另为铺注伪列七政名为便览</span>  
<span style="margin-left: 3em">通书等书者严行禁止臣等未敢擅便谨</span>  
<span style="margin-left: 2em">题请</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 3em">康熙十八年十二月初五日奉</span>
