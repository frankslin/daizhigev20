## 崇禎曆書卷之二十六　康熙奏疏

*康熙十七年七月十一日至康熙二十七年三月初四日*

<span style="margin-left: 2em">奏疏十二</span>  
<span style="margin-left: 4em">康熙十七年七月十一日禮部題本</span>  
<span style="margin-left: 3em">禮部　題爲</span>  
<span style="margin-left: 1em">欽命預推康熙永年曆法告成著有書表詳載推法以</span>  
<span style="margin-left: 3em">傳永久以光</span>  
<span style="margin-left: 2em">國典事　欽天監治理曆法加太常寺卿南懷仁奏</span>  
<span style="margin-left: 3em">前事等因康熙十七年七月十一日奏本月十七</span>  
<span style="margin-left: 3em">日奉</span>  
<span style="margin-left: 1em">旨據奏預造康熙永年曆永爲後式盡心推算可嘉著</span>  
<span style="margin-left: 3em">議敘具奏於七月十八日到部</span>  
<span style="margin-left: 3em">議得治理曆法南懷仁疏稱奉</span>  
<span style="margin-left: 2em">命臣將先臣湯若望遺留諸曆二百年恆表相繼預</span>  
<span style="margin-left: 3em">推至數千年之後以垂永久今已告成預推將來</span>  
<span style="margin-left: 3em">二千年其曆書三十二卷名爲康熙永年曆法</span>  
<span style="margin-left: 2em">進呈</span>  
<span style="margin-left: 1em">御覽等因具題奉</span>  
<span style="margin-left: 1em">旨據奏預造康熙永年曆永爲後式盡心推算可嘉著</span>  
<span style="margin-left: 3em">議敘具奏該部知道曆併發查得康熙十三年因</span>  
<span style="margin-left: 3em">儀象告成製造精密從優議敘之處交與吏部議</span>  
<span style="margin-left: 3em">敘在案今永年曆法告成相應將治理曆法加太</span>  
<span style="margin-left: 3em">常寺卿南懷仁由吏部議敘可也</span>  
<span style="margin-left: 3em">奉</span>  
<span style="margin-left: 1em">旨依議永年曆本內並未議及著再議具奏</span>  
<span style="margin-left: 8em">康熙十七年八月二十日禮部題本</span>  
<span style="margin-left: 3em">禮部　題爲</span>  
<span style="margin-left: 1em">欽命預推康熙永年曆法告成著有書表詳載推法以</span>  
<span style="margin-left: 3em">傳永久以光</span>  
<span style="margin-left: 2em">國典事該臣等題前事奉</span>  
<span style="margin-left: 1em">旨依議永年曆本內並未議及著再議具奏再議得先</span>  
<span style="margin-left: 3em">經臣部因永年曆法告成緣由將治理曆法加太</span>  
<span style="margin-left: 3em">常寺卿南懷仁由吏部議敘等因具題奉</span>  
<span style="margin-left: 1em">旨依議永年曆本內並未議及著再議具奏欽此隨行</span>  
<span style="margin-left: 3em">查欽天監去後今准呈稱順治貳年拾貳月掌管</span>  
<span style="margin-left: 3em">欽天監印務湯若望奏爲新曆告成恭呈</span>  
<span style="margin-left: 1em">御覽以昭成憲以光史冊事壹疏奉</span>  
<span style="margin-left: 1em">聖旨新曆密合天行已經頒用這所進曆書考據精詳</span>  
<span style="margin-left: 3em">理明數著著該監局官生用心肄習永遠遵守仍</span>  
<span style="margin-left: 3em">宣付史館以彰大典湯若望勤慎可嘉宜加敘賚</span>  
<span style="margin-left: 3em">著吏禮二部議奏該衙門知道欽此今南懷仁</span>  
<span style="margin-left: 2em">進呈</span>  
<span style="margin-left: 1em">御覽康熙永年曆乃係按推湯若望所推二百年恆表</span>  
<span style="margin-left: 3em">之曆亦應交與翰林院仍著該監官生用心肄習</span>  
<span style="margin-left: 3em">永遠遵行可也</span>  
<span style="margin-left: 3em">八月二十日奉</span>  
<span style="margin-left: 1em">旨依議</span>  
<span style="margin-left: 7em">康熙十七年九月二十一日吏部題本</span>  
<span style="margin-left: 3em">吏部　題爲</span>  
<span style="margin-left: 1em">欽命預推康熙永年曆法告成著有書表詳載推法以</span>  
<span style="margin-left: 3em">傳永久以光</span>  
<span style="margin-left: 2em">國典事該臣等再議得先經臣部復禮部疏稱治理</span>  
<span style="margin-left: 3em">曆法加太常寺卿南懷仁預造康熙永年曆永爲</span>  
<span style="margin-left: 3em">後式應將南懷仁於見任內加一級等因具題奉</span>  
<span style="margin-left: 1em">旨這所議尚輕著再議具奏應將治理曆法加太常寺</span>  
<span style="margin-left: 3em">卿南懷仁加爲通政使司通政使職銜仍加一級</span>  
<span style="margin-left: 3em">九月二十一日奉</span>  
<span style="margin-left: 1em">旨南懷仁著加爲通政使司通政使職銜仍加一級</span>  
<span style="margin-left: 7em">康熙十七年十月初八日南懷仁奏本</span>  
<span style="margin-left: 3em">欽天監治理曆法加太常寺卿臣南懷仁謹</span>  
<span style="margin-left: 2em">奏爲懇辭溢銜之</span>  
<span style="margin-left: 1em">寵命以安守愚分事竊臣以永年曆表告成恭</span>  
<span style="margin-left: 2em">進全書深荷</span>  
<span style="margin-left: 1em">綸音褒嘉隨奉</span>  
<span style="margin-left: 1em">旨南懷仁著加爲通政使司通政使職銜仍加一級臣</span>  
<span style="margin-left: 3em">伏讀</span>  
<span style="margin-left: 1em">恩綸感激之餘不勝愧汗蓋臣業身任治曆厚蒙豢養</span>  
<span style="margin-left: 3em">循分自盡未罄涓埃何敢萌非分之念乎臣原不</span>  
<span style="margin-left: 3em">婚不宦自幼以修道爲本業雖修道原治內心非</span>  
<span style="margin-left: 3em">關外貌而朝紳之中亦可存繕性之功布衣之下</span>  
<span style="margin-left: 3em">亦有藏榮適之想但職任所責皆措理外務而難</span>  
<span style="margin-left: 3em">暇治內故謝絕世務勤勵於正心誠意乃修道之</span>  
<span style="margin-left: 3em">本志耳向荷</span>  
<span style="margin-left: 1em">皇上准臣專辦曆務免選擇相度等監副監正之職是</span>  
<span style="margin-left: 3em">職官既已蒙寬免今又領受高銜此微臣之心不</span>  
<span style="margin-left: 3em">安者一年也夫</span>  
<span style="margin-left: 2em">國家增秩加銜之典原以酬賞才能故才能必須與</span>  
<span style="margin-left: 3em">職銜相當倘才能低下不符職銜之崇高則如身</span>  
<span style="margin-left: 3em">短衣長不相稱也臣見蒙太常之銜已屬逾分本</span>  
<span style="margin-left: 3em">願再辭今復加大卿之銜尤爲越分伏睹</span>  
<span style="margin-left: 1em">皇上弘恩如海洋溢大小高下無不充滿但臣才下器</span>  
<span style="margin-left: 3em">小豈能容受此微臣之心不安者二也我</span>  
<span style="margin-left: 1em">皇上輝光並日自東至西萬方普照臣本西陬鄙儒即</span>  
<span style="margin-left: 3em">在九萬里遠地舉目遙瞻尚難當彩耀若階榮上</span>  
<span style="margin-left: 3em">卿去天咫尺能不昏瞀哉此微臣之心不安者三</span>  
<span style="margin-left: 3em">也至於預推永年曆表不過臣應盡之職分若緣</span>  
<span style="margin-left: 3em">此加銜則以後凡分內竭力之事如理推天象等</span>  
<span style="margin-left: 3em">書何敢具疏請</span>  
<span style="margin-left: 1em">旨恐人指謂圖名求榮之爲耳此微臣之心不安者四</span>  
<span style="margin-left: 3em">也伏乞</span>  
<span style="margin-left: 1em">皇上俯鑒愚衷收回</span>  
<span style="margin-left: 1em">成命俾臣照舊以閑散辦事澹泊修身得以安心發明</span>  
<span style="margin-left: 3em">理推天象等曆務以圖報我</span>  
<span style="margin-left: 1em">皇上格外洪恩之萬一也爲此具本親齎謹具奏</span>  
<span style="margin-left: 1em">聞</span>  
<span style="margin-left: 3em">十月初八日奉</span>  
<span style="margin-left: 1em">旨南懷仁預造永年曆盡心推算勤勞可嘉加銜已有</span>  
<span style="margin-left: 3em">成命不必控辭該部知道</span>  
<span style="margin-left: 11em">康熙十七年十月禮部題本</span>  
<span style="margin-left: 3em">禮部謹</span>  
<span style="margin-left: 2em">題爲曆法既已精詳序次應行改正宜首尊</span>  
<span style="margin-left: 2em">盛京以重時憲事禮科抄出吏科給事中李宗孔題</span>  
<span style="margin-left: 3em">前事內開<sub class="note-yuan">云云</sub>等因康熙十七年十月初九日題</span>  
<span style="margin-left: 3em">本月十七日奉</span>  
<span style="margin-left: 1em">旨該部議奏欽此欽遵於本月十八日到部隨問欽天</span>  
<span style="margin-left: 3em">監監正加一級宜塔喇治理曆法加通政使司通</span>  
<span style="margin-left: 3em">政使仍加一級南懷仁監副降一級留任查爾大</span>  
<span style="margin-left: 3em">左監副邵泰衢右監副鮑英齊五官正魏成格屯</span>  
<span style="margin-left: 3em">主祜主簿阿莫索峩劉應昌春官正孫有本夏官</span>  
<span style="margin-left: 3em">正何雒書中官正薛文炳秋官正張問明冬官正</span>  
<span style="margin-left: 3em">何君錫等科臣李宗孔疏稱曆本開載太陽出入</span>  
<span style="margin-left: 2em">盛京居首及各省之節氣則以朝鮮列於</span>  
<span style="margin-left: 2em">盛京之先在監臣止論節氣之先後悉依地之經度</span>  
<span style="margin-left: 3em">所列爲之序次</span>  
<span style="margin-left: 2em">頒行既久習矣不察嗣後曆本似宜朝鮮節氣附直</span>  
<span style="margin-left: 3em">省之末等語此處怎麼說應否將朝鮮附於直省</span>  
<span style="margin-left: 3em">之末宜塔喇南懷仁供稱敬授民時以合天爲春</span>  
<span style="margin-left: 3em">王正月之義也夫曆者歷也不但其度分時刻等</span>  
<span style="margin-left: 3em">項應合於天即其所列先後之序次亦應合於天</span>  
<span style="margin-left: 3em">先後之序方可爲全合於天矣今曆本內所列諸</span>  
<span style="margin-left: 3em">省之序即全合於天地經緯之序論太陽出人則</span>  
<span style="margin-left: 3em">曆本內順其從北而南行之定序故以北爲先以</span>  
<span style="margin-left: 3em">南爲後今</span>  
<span style="margin-left: 2em">盛京既在諸省之最北則曆本內列在諸省之先依</span>  
<span style="margin-left: 3em">其合天之序非依各省尊貴之序論各省之節氣</span>  
<span style="margin-left: 3em">即順太陽先東後西之行序因而以東爲先以西</span>  
<span style="margin-left: 3em">爲後今朝鮮既在諸省最東則列在諸省之先正</span>  
<span style="margin-left: 3em">合天行亦合地經緯之序若依各省尊貴定序則</span>  
<span style="margin-left: 3em">朝鮮不但論節氣應附在直省之末即論太陽出</span>  
<span style="margin-left: 3em">入不應同山東列在第三行內亦分開另附於諸</span>  
<span style="margin-left: 3em">省之末矣若曆本內將朝鮮列在諸省之末即如</span>  
<span style="margin-left: 3em">輿圖內將最東之朝鮮移在雲南最西之後如一</span>  
<span style="margin-left: 3em">年之中將先月移在於後月一月之中將先日移</span>  
<span style="margin-left: 3em">在於後日可乎此不合天地經緯之序矣況曆本</span>  
<span style="margin-left: 3em">內明開載止依東西南北之先後不依各省尊貴</span>  
<span style="margin-left: 3em">之先後萬國之觀瞻無不易曉</span>  
<span style="margin-left: 2em">國家以治曆爲首務本監惟依合天行爲治曆之首</span>  
<span style="margin-left: 3em">務竝無習而不察之故也該臣等議得據監正宜</span>  
<span style="margin-left: 3em">塔喇南懷仁供稱論太陽出入則曆本內順其從</span>  
<span style="margin-left: 3em">北而南之定序故以北爲先以南爲後今</span>  
<span style="margin-left: 2em">盛京既在諸省之最北故列在諸省之先論各省之</span>  
<span style="margin-left: 3em">節氣順太陽先東後西之行序因而以東爲先以</span>  
<span style="margin-left: 3em">西爲後今朝鮮既在諸省最東則列在諸省之先</span>  
<span style="margin-left: 3em">正合天行若曆本內將朝鮮列在諸省之末即如</span>  
<span style="margin-left: 3em">輿圖內最東之朝鮮移在雲南最西之後可乎況</span>  
<span style="margin-left: 3em">曆本內明開載止依東西南北之先後不依各省</span>  
<span style="margin-left: 3em">尊貴之先後萬國之觀瞻無不易曉</span>  
<span style="margin-left: 2em">國家以治曆爲首務本監惟依合天行爲治曆之首</span>  
<span style="margin-left: 3em">務竝無習而不察之故等語查得康熙八年議政</span>  
<span style="margin-left: 3em">王等會議南懷仁所推之法既合天象一應曆日</span>  
<span style="margin-left: 3em">皆交與南懷仁等因在案今宜塔喇南懷仁等將</span>  
<span style="margin-left: 3em">節氣順太陽先東因朝鮮既在最東故節氣處列</span>  
<span style="margin-left: 3em">在於先若列在諸省之末不合天地經緯之序矣</span>  
<span style="margin-left: 3em">相應將科臣李宗孔疏稱之處無庸議奉</span>  
<span style="margin-left: 1em">旨依議</span>  
<span style="margin-left: 7em">康熙十八年十二月初五日五人題本</span>  
<span style="margin-left: 3em">欽天監監正加一級臣安泰治理曆法加通政使</span>  
<span style="margin-left: 3em">司通政使仍加一級臣南懷仁監副臣查爾大左</span>  
<span style="margin-left: 3em">監副臣邵泰衢右監副臣鮑英齊等</span>  
<span style="margin-left: 2em">題爲請頒七政曆日以使畫一遵行事切惟頒曆爲</span>  
<span style="margin-left: 2em">國家首務上合於天下行於人</span>  
<span style="margin-left: 2em">國家大典士民之動作諸務卜其宜忌以使畫一之</span>  
<span style="margin-left: 3em">所係也今時憲曆日頒於天下而各省仍不免於</span>  
<span style="margin-left: 3em">僞造私曆者其故無他蓋緣時憲曆日之中止有</span>  
<span style="margin-left: 3em">朔望節氣太陽出入晝夜長短而已凡陰陽諸家</span>  
<span style="margin-left: 3em">相度選擇必以七政爲本而我</span>  
<span style="margin-left: 2em">朝七政曆日原頒於直隸八府未及頒行各省今臣</span>  
<span style="margin-left: 3em">監若仍止頒直隸八府而不頒各省則射利之徒</span>  
<span style="margin-left: 3em">另爲鋪注僞列七政名爲便覽通書賣於街市者</span>  
<span style="margin-left: 3em">亦未可定選擇之士既不得頒行七政則不得不</span>  
<span style="margin-left: 3em">用此僞曆矣諸凡士民所用之日又不得不從其</span>  
<span style="margin-left: 3em">所選是國人所用之時日乃大不合於時憲矣況</span>  
<span style="margin-left: 3em">頒曆之典緣以同風俗大一統治天下如一家者</span>  
<span style="margin-left: 3em">也是以劉基云曆日頒行天下使國不異政家不</span>  
<span style="margin-left: 3em">殊俗大回太古之風以成熙皞之治今正</span>  
<span style="margin-left: 2em">國家戡亂致平之時豈容此異僞之曆伏乞</span>  
<span style="margin-left: 1em">睿鑒勅將七政曆日亦於四月內照民曆頒行各省並</span>  
<span style="margin-left: 3em">勅下各省督撫將另爲鋪注僞列七政名爲便覽</span>  
<span style="margin-left: 3em">通書等書者嚴行禁止臣等未敢擅便謹</span>  
<span style="margin-left: 2em">題請</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 3em">康熙十八年十二月初五日奉</span>  
<span style="margin-left: 1em">旨該部議奏</span>  
<span style="margin-left: 5em">康熙二十一年七月二十九日南懷仁奏本</span>

<span style="margin-left: 3em">懷仁謹</span>  
<span style="margin-left: 2em">奏爲請推定盛京本地交食之法以密合天行以光</span>  
<span style="margin-left: 3em">曆典事竊見我</span>  
<span style="margin-left: 2em">朝欽定新法之曆所以超越諸代者爲其於天下各</span>  
<span style="margin-left: 3em">省密合天行而諸代不過一方之曆而已如明季</span>  
<span style="margin-left: 3em">雖用元法而元法較諸代號爲精微然其曆亦惟</span>  
<span style="margin-left: 3em">京師之曆匪但弗合於各省即京師亦不能全合</span>  
<span style="margin-left: 3em">也以京師之交食三四分者在他省雖有八九分</span>  
<span style="margin-left: 3em">之食至其頒行仍照本京所食三四分者之數緣</span>  
<span style="margin-left: 3em">舊曆無變通推各省之法也但食分時刻各省所</span>  
<span style="margin-left: 3em">以不同者由大地經緯度各省有不同之故蓋天</span>  
<span style="margin-left: 3em">下各省凡兩省之省城北極之高下彼此相隔二</span>  
<span style="margin-left: 3em">度者則新法照各省北極之高度另有推步交食</span>  
<span style="margin-left: 3em">表名爲九十度表以變通各方所食不同之時刻</span>  
<span style="margin-left: 3em">不等之食分惟盛京無本地之表其現用者與京</span>  
<span style="margin-left: 3em">都本地同一表耳幸於今年春月恭遇</span>

<span style="margin-left: 3em">治理曆法加工部右侍郎又加二級南懷仁謹</span>  
<span style="margin-left: 2em">奏爲恭</span>  
<span style="margin-left: 2em">進窮理學之書以明曆理以廣開百學之門永垂萬</span>  
<span style="margin-left: 3em">世事竊惟治曆明時爲帝王之首務今我</span>  
<span style="margin-left: 1em">皇上治曆明時超越百代如太陽之光超越諸星之光</span>  
<span style="margin-left: 3em">然蓋曆法有屬法之數有立法之理設惟有其法</span>  
<span style="margin-left: 3em">之數而無其法之理即如人惟有形體而無靈性</span>  
<span style="margin-left: 3em">亦如諸天惟有定所而無運動之照臨焉夫曆理</span>  
<span style="margin-left: 3em">爲諸星恆動定規之所由如泉源爲江河永流之</span>

<span style="margin-left: 3em">矣大都專求法數罕求名理修改之門戶雖歧實</span>  
<span style="margin-left: 3em">則互相依徬雖間有出一二新意亦未能洞曉本</span>  
<span style="margin-left: 3em">原惟元郭守敬之曆號稱精密顧其法亦未盡善</span>  
<span style="margin-left: 3em">在當日已有推食而不食食而失推之弊其立法</span>  
<span style="margin-left: 3em">之後不越十八年其差已如此況沿至於今日哉</span>  
<span style="margin-left: 3em">今我</span>  
<span style="margin-left: 1em">皇上之治曆已爲全備其書則有永年曆表有靈臺儀</span>  
<span style="margin-left: 3em">象志有諸曆之理指一百五十餘卷曆典光明可</span>  
<span style="margin-left: 3em">謂極矣然臣猶有請者非爲加曆理之內光惟加</span>  
<span style="margin-left: 3em">曆理之外光將所載諸書之曆理開窮理之學以</span>  
<span style="margin-left: 3em">發明之使習曆者知其數並知其理而後其光發</span>  
<span style="margin-left: 3em">見於外也今習曆者惟知其數而不知其理其所</span>  
<span style="margin-left: 3em">以不知曆理者緣不知理推之法故耳夫見在曆</span>  
<span style="margin-left: 3em">指等書所論天文曆法之理設不知其推法則如</span>  
<span style="margin-left: 3em">金寶藏於地脈而不知開礦之門路矣若展卷惟</span>  
<span style="margin-left: 3em">泥於法數而不究法理如手徒持燈篝而不用其</span>  
<span style="margin-left: 3em">內之光然故從來學曆者必先熟習窮理之總學</span>

<span style="margin-left: 3em">曆法壞亂失傳朦朧不明者皆不知理推之法故</span>

<span style="margin-left: 3em">前曾在</span>  
<span style="margin-left: 2em">內庭奏</span>  
<span style="margin-left: 2em">聞及越一載復蒙</span>
