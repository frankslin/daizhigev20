<span style="margin-left: 2em">界说章第一<sub class="note-yuan">凡十则</sub></span>  
<span style="margin-left: 3em">第一界</span>  
<span style="margin-left: 5em">角者两线纵横相遇所作线有曲直两直相</span>  
<span style="margin-left: 5em">遇为直线角两曲相遇为曲线角一直一曲</span>  
<span style="margin-left: 5em">相遇为杂线角曲杂两线角更有别论今先</span>  
<span style="margin-left: 1em">明直线角</span>  
<span style="margin-left: 3em">第二界</span>  
<span style="margin-left: 5em">凡直线正垂于横直线之上必成两直角相</span>  
<span style="margin-left: 5em">等如上图甲乙为垂线丙丁为横线而乙之</span>  
<span style="margin-left: 5em">左右两角相等为两直角若反以甲乙为横</span>  
<span style="margin-left: 1em">线则丙丁为甲乙垂线也<sub class="note-yuan">如今用短尺一纵一横互相为直线互相为垂线</sub></span>  
<span style="margin-left: 3em">第三界</span>  
<span style="margin-left: 5em">垂线斜交于横直线之上必成两不等角两</span>  
<span style="margin-left: 5em">不等角一大于直角一小于直角大为钝角</span>  
<span style="margin-left: 5em">小为锐角如上图戊己庚为钝角戊己辛为</span>  
<span style="margin-left: 1em">锐角故直角惟一而锐钝两角其大小不等乃至无数</span>  
<span style="margin-left: 3em">第四界</span>  
<span style="margin-left: 1em">凡二直线不能为有界之形故直线之形有界者至少</span>  
<span style="margin-left: 5em">有三角有三直线为边名曰三边形亦曰三</span>  
<span style="margin-left: 5em">角形如上图三边形止有三种</span>  
<span style="margin-left: 3em">第五界</span>  
<span style="margin-left: 4em">三边线相等为等边三角形亦为平边三角形</span>  
<span style="margin-left: 4em">如上甲乙丙图</span>

<span style="margin-left: 3em">第七界</span>

<span style="margin-left: 4em">图</span>

<span style="margin-left: 4em">短今用长度于甲乙不等作短界线交处为丙</span>

<span style="margin-left: 6em">丁等次或用元度或任取一度以丁为心</span>

<span style="margin-left: 6em">求若向乙丙无地可作短界线则宜仍以</span>

<span style="margin-left: 5em">从此边对角作垂线至乙即所求</span>  
<span style="margin-left: 2em">有角任分为若干分章第八</span>

<span style="margin-left: 5em">又各两分之得四又各两分之得八又各两</span>

<span style="margin-left: 1em">线即所求如上图</span>  
<span style="margin-left: 2em">有三直线求作三角形其三边如所设三直线等章</span>  
<span style="margin-left: 3em">第九</span>  
<span style="margin-left: 5em">如甲乙丙三线每两线并大于一线任以一</span>  
<span style="margin-left: 5em">线为底以底之甲为心第<sub class="note-yuan">二三</sub>线为度向上作</span>  
<span style="margin-left: 5em">短界线两界线交处为丙次向下作丙甲丙</span>  
<span style="margin-left: 1em">乙两腰即所求</span>  
<span style="margin-left: 6em">设一三角形求别作一形与之等章第十</span>  
<span style="margin-left: 5em">以所设三角形之三边当甲乙丙三线以前</span>  
<span style="margin-left: 5em">法作之即所求或又用前所备三髀规以规</span>  
<span style="margin-left: 1em">形所设三角形度移于别处即所求</span>  
<span style="margin-left: 2em">一直线任于一点上求作一角如所设角等章第十</span>  
<span style="margin-left: 3em">一</span>  
<span style="margin-left: 1em">如甲乙线上有丙点求作一角如所设丁戊己角等先</span>

<span style="margin-left: 5em">有甲乙丙角形从丁点求两平分之先自丁</span>  
<span style="margin-left: 5em">至相对甲角作甲丁直线次平分乙丙线于</span>

<span style="margin-left: 2em">有三边直角形以两边求第三边长短之数章第十</span>  
<span style="margin-left: 3em">四</span>  
<span style="margin-left: 1em">如甲乙丙三角形甲边直角先得甲乙甲丙两边长短</span>  
<span style="margin-left: 1em">之数如甲乙六甲丙八求乙丙边长短之数其甲乙甲</span>  
<span style="margin-left: 5em">丙上所作两直角方形并既与乙丙上所作</span>  
<span style="margin-left: 5em">直角方形等<sub class="note-yuan">原本卷四十七</sub>则甲乙之羃<sub class="note-yuan">自乘之数曰羃</sub>得</span>  
<span style="margin-left: 5em">三十六甲丙之羃得六十四并之得百而乙</span>
