<span style="margin-left: 2em">界說章第一<sub class="note-yuan">凡十則</sub></span>  
<span style="margin-left: 3em">第一界</span>  
<span style="margin-left: 5em">角者兩線縱橫相遇所作線有曲直兩直相</span>  
<span style="margin-left: 5em">遇爲直線角兩曲相遇爲曲線角一直一曲</span>  
<span style="margin-left: 5em">相遇爲雜線角曲雜兩線角更有別論今先</span>  
<span style="margin-left: 1em">明直線角</span>  
<span style="margin-left: 3em">第二界</span>  
<span style="margin-left: 5em">凡直線正垂於橫直線之上必成兩直角相</span>  
<span style="margin-left: 5em">等如上圖甲乙爲垂線丙丁爲橫線而乙之</span>  
<span style="margin-left: 5em">左右兩角相等爲兩直角若反以甲乙爲橫</span>  
<span style="margin-left: 1em">線則丙丁爲甲乙垂線也<sub class="note-yuan">如今用短尺一縱一橫互相爲直線互相爲垂線</sub></span>  
<span style="margin-left: 3em">第三界</span>  
<span style="margin-left: 5em">垂線斜交於橫直線之上必成兩不等角兩</span>  
<span style="margin-left: 5em">不等角一大于直角一小于直角大爲鈍角</span>  
<span style="margin-left: 5em">小爲銳角如上圖戊己庚爲鈍角戊己辛爲</span>  
<span style="margin-left: 1em">銳角故直角惟一而銳鈍兩角其大小不等乃至無數</span>  
<span style="margin-left: 3em">第四界</span>  
<span style="margin-left: 1em">凡二直線不能爲有界之形故直線之形有界者至少</span>  
<span style="margin-left: 5em">有三角有三直線爲邊名曰三邊形亦曰三</span>  
<span style="margin-left: 5em">角形如上圖三邊形止有三種</span>  
<span style="margin-left: 3em">第五界</span>  
<span style="margin-left: 4em">三邊線相等爲等邊三角形亦爲平邊三角形</span>  
<span style="margin-left: 4em">如上甲乙丙圖</span>  
<span style="margin-left: 3em">第六界</span>  
<span style="margin-left: 4em">兩邊線相等爲一不等三角形如上丁戊己圖</span>  
<span style="margin-left: 3em">第七界</span>  
<span style="margin-left: 4em">三邊線俱不等爲不等邊三角形如上庚辛壬</span>  
<span style="margin-left: 4em">圖</span>  
<span style="margin-left: 3em">第八界</span>  
<span style="margin-left: 5em">三邊形有一直角爲三邊直角形有一鈍角</span>  
<span style="margin-left: 5em">爲三邊鈍角形有三銳角爲三邊各銳角形</span>  
<span style="margin-left: 5em">如上三圖</span>  
<span style="margin-left: 3em">第九界</span>  
<span style="margin-left: 5em">凡三邊形恆以在下者爲底在上邊爲腰如</span>  
<span style="margin-left: 5em">上圖甲乙甲丙爲腰乙丙爲底</span>  
<span style="margin-left: 4em">第十界</span>  
<span style="margin-left: 4em">凡言角者俱用三字爲識其第二字即所指角</span>  
<span style="margin-left: 4em">也如甲乙丙角其乙字指角</span>  
<span style="margin-left: 2em">三髀規章第二</span>  
<span style="margin-left: 1em">規以二髀爲常法或倍之於兩端爲四髀前卷己詳之</span>  
<span style="margin-left: 1em">矣兹有三髀規新式造法兩髀如常如前二卷中所設</span>  
<span style="margin-left: 1em">是也旁一髀即附於二髀之樞稍引長之出頭其頭端</span>  
<span style="margin-left: 1em">上有眼銜旁一髀令其圓活可上下左右如下圖用法</span>  
<span style="margin-left: 1em">見後</span>  
<span style="margin-left: 2em">於有界直線上求立等邊三角形章第三</span>  
<span style="margin-left: 5em">如甲乙直線上求立等邊三角形先以甲爲</span>  
<span style="margin-left: 5em">心乙爲界或上或下作一短界線次以乙爲</span>  
<span style="margin-left: 5em">心甲爲界亦如之兩短界線交處爲丙末自</span>  
<span style="margin-left: 1em">甲至丙丙至乙各作直線即所求</span>  
<span style="margin-left: 2em">於有界直線上求立一不等三角形章第四</span>  
<span style="margin-left: 5em">如甲乙直線以甲爲心任取一度或長或短</span>  
<span style="margin-left: 5em">於甲乙線上用前法作一短界線次以乙爲</span>  
<span style="margin-left: 5em">心用前度亦如之兩短界線交處爲丙從丙</span>  
<span style="margin-left: 1em">至甲至乙各作直線即所求</span>  
<span style="margin-left: 2em">於有界直線上求立三不等角形章第五</span>  
<span style="margin-left: 4em">如甲乙直線以甲爲心或長或短用一度如前</span>  
<span style="margin-left: 4em">作短界線次以乙爲心甲度長今用短度甲度</span>  
<span style="margin-left: 4em">短今用長度于甲乙不等作短界線交處爲丙</span>  
<span style="margin-left: 1em">從丙至甲至乙作兩直線即所求</span>  
<span style="margin-left: 2em">有直線角求兩平分之章第六</span>  
<span style="margin-left: 6em">如乙甲丙角求兩平分之先於甲乙線任</span>  
<span style="margin-left: 6em">截一分爲甲丁次于甲丙線截甲戊與甲</span>  
<span style="margin-left: 6em">丁等次或用元度或任取一度以丁爲心</span>  
<span style="margin-left: 6em">向乙丙間作一短界線次以戊爲心亦如</span>  
<span style="margin-left: 6em">之兩線交處爲己從甲至己作直線即所</span>  
<span style="margin-left: 6em">求若向乙丙無地可作短界線則宜仍以</span>  
<span style="margin-left: 6em">丁以戊爲心向甲上作短界線爲己從己</span>  
<span style="margin-left: 1em">至甲作直線即所求<sub class="note-yuan">如上圖</sub></span>  
<span style="margin-left: 2em">有直角求三平分之章第七</span>  
<span style="margin-left: 1em">如甲乙丙直角求三平分之先任于一邊立平邊角形</span>  
<span style="margin-left: 5em">爲甲乙丁次分對直角一邊爲兩平分丁戊</span>  
<span style="margin-left: 5em">從此邊對角作垂線至乙即所求</span>  
<span style="margin-left: 2em">有角任分爲若干分章第八</span>  
<span style="margin-left: 1em">如乙甲丙角欲分爲四爲八爲十六等分則先分兩分</span>  
<span style="margin-left: 5em">又各兩分之得四又各兩分之得八又各兩</span>  
<span style="margin-left: 5em">分之得十六愈分愈倍如任欲分爲幾分如</span>  
<span style="margin-left: 5em">三五七九之類則先以甲爲心向乙作一圜</span>  
<span style="margin-left: 1em">分次以規分圜分任作幾何分末從所分度至甲作直</span>  
<span style="margin-left: 1em">線即所求如上圖</span>  
<span style="margin-left: 2em">有三直線求作三角形其三邊如所設三直線等章</span>  
<span style="margin-left: 3em">第九</span>  
<span style="margin-left: 5em">如甲乙丙三線每兩線并大于一線任以一</span>  
<span style="margin-left: 5em">線爲底以底之甲爲心第<sub class="note-yuan">二三</sub>線爲度向上作</span>  
<span style="margin-left: 5em">短界線兩界線交處爲丙次向下作丙甲丙</span>  
<span style="margin-left: 1em">乙兩腰即所求</span>  
<span style="margin-left: 6em">設一三角形求別作一形與之等章第十</span>  
<span style="margin-left: 5em">以所設三角形之三邊當甲乙丙三線以前</span>  
<span style="margin-left: 5em">法作之即所求或又用前所備三髀規以規</span>  
<span style="margin-left: 1em">形所設三角形度移于別處即所求</span>  
<span style="margin-left: 2em">一直線任于一點上求作一角如所設角等章第十</span>  
<span style="margin-left: 3em">一</span>  
<span style="margin-left: 1em">如甲乙線上有丙點求作一角如所設丁戊己角等先</span>  
<span style="margin-left: 5em">於戊丁線任取一點爲庚於戊己線任取一</span>  
<span style="margin-left: 5em">點爲辛自庚至辛作直線次以前法於甲乙</span>  
<span style="margin-left: 5em">線上作丙壬癸角形與戊庚辛角等即所求</span>  
<span style="margin-left: 6em">有三角形求兩平分之章第十二</span>  
<span style="margin-left: 5em">如有甲乙丙三角形求兩平分之任于一邊</span>  
<span style="margin-left: 5em">兩平分之于丁向角作直線即所求</span>  
<span style="margin-left: 2em">凡角形任于一邊任作一點求從點分兩形爲兩平</span>  
<span style="margin-left: 3em">分章第十三</span>  
<span style="margin-left: 5em">有甲乙丙角形從丁點求兩平分之先自丁</span>  
<span style="margin-left: 5em">至相對甲角作甲丁直線次平分乙丙線于</span>  
<span style="margin-left: 5em">戊作戊己線與甲丁平行末作己丁直線即</span>  
<span style="margin-left: 1em">分本形爲兩平分</span>  
<span style="margin-left: 2em">有三邊直角形以兩邊求第三邊長短之數章第十</span>  
<span style="margin-left: 3em">四</span>  
<span style="margin-left: 1em">如甲乙丙三角形甲邊直角先得甲乙甲丙兩邊長短</span>  
<span style="margin-left: 1em">之數如甲乙六甲丙八求乙丙邊長短之數其甲乙甲</span>  
<span style="margin-left: 5em">丙上所作兩直角方形并既與乙丙上所作</span>  
<span style="margin-left: 5em">直角方形等<sub class="note-yuan">原本卷四十七</sub>則甲乙之羃<sub class="note-yuan">自乘之數曰羃</sub>得</span>  
<span style="margin-left: 5em">三十六甲丙之羃得六十四并之得百而乙</span>  
<span style="margin-left: 5em">丙之羃亦百百開方得十即乙丙數十也又</span>  
<span style="margin-left: 5em">設先得甲乙乙丙如甲乙六乙丙十而求甲</span>  
<span style="margin-left: 1em">丙之數其甲乙甲丙上兩直角方形并既與乙丙上直</span>  
<span style="margin-left: 1em">角方形等則甲乙之羃得三十六乙丙之羃得百百減</span>  
<span style="margin-left: 1em">三十六得甲丙之羃六十四六十四開方得八即甲丙</span>  
<span style="margin-left: 1em">八也求甲乙倣此</span>
