<span style="margin-left: 2em">求视会实会第一</span>  
<span style="margin-left: 1em">前所得实会时刻虽则合天于人目所见仪器所测未</span>  
<span style="margin-left: 2em">尽合也所以然者太阳行度赤道交子午圈有升度</span>  
<span style="margin-left: 2em">差随时变易日日不均<sub class="note-yuan">详见日躔历指</sub>而今依历元推步或</span>  
<span style="margin-left: 2em">用表查算无能不均须用加减时表以求本地可见</span>  
<span style="margin-left: 2em">可测之实时又推步者但依本地所定子午线其在</span>  
<span style="margin-left: 2em">地方不同子午线者难可通用故又用里差加减以</span>  
<span style="margin-left: 2em">求诸方所见所测之实时也</span>  
<span style="margin-left: 3em">实时改视时</span>  
<span style="margin-left: 1em">如前求太阳实度得中实两会相距时刻查太阳平行</span>  
<span style="margin-left: 2em">时表得分数依前加减时刻亦加亦减于前得太阳</span>  
<span style="margin-left: 2em">经度乃得实度　假如前推壬申三月望会太阳平</span>  
<span style="margin-left: 2em">经度为四宫<sub class="note-yuan">冬至起算</sub>一十二度三十四分〇一秒中实</span>  
<span style="margin-left: 2em">两会之差得六时一十二分五十五秒其距间又得</span>  
<span style="margin-left: 2em">太阳平行一十五分一十八秒以加于中会时之太</span>  
<span style="margin-left: 2em">阳平经度得其实会时平经度四宫一十二度四十</span>  
<span style="margin-left: 2em">九分一十九秒更加其次均度一度三十六分三十</span>  
<span style="margin-left: 2em">六秒则太阳实度四宫一十四度二十五分五十五</span>  
<span style="margin-left: 2em">秒今查加减时表得〇九分五十五秒其号为加则</span>  
<span style="margin-left: 2em">以加于实会共得二十时〇五分四十四秒算外得</span>  
<span style="margin-left: 2em">癸丑日戌正五分为顺天府所见所测之食甚时</span>  
<span style="margin-left: 3em">见食随地异时</span>  
<span style="margin-left: 1em">月食分数天下皆同第见食时刻随地各异何也人各</span>  
<span style="margin-left: 2em">就所居之地目力所及者则见月食而各所居地皆</span>  
<span style="margin-left: 2em">以子午正线为主若其地同居一子午线者<sub class="note-yuan">南北地纬虽异</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">东西地经则同</sub>则所见月食之分数迟速皆同也若地易子</span>  
<span style="margin-left: 2em">午线易则时刻并易矣所以然者时刻早晚因太阳</span>  
<span style="margin-left: 2em">行度随人所居各以见日出入为东西为卯酉即以</span>  
<span style="margin-left: 2em">日中为南为子午而平分时刻故月食时必本地之</span>  
<span style="margin-left: 2em">日未东升或己西沉乃得见之若在其昼时刻不可</span>  
<span style="margin-left: 2em">得见也天启三年九月十五夜望月食顺天府及南</span>  
<span style="margin-left: 2em">北同经之地则初亏在酉初一刻一十二分食甚在</span>  
<span style="margin-left: 2em">戌初初刻复圆在戌正二刻一十三分各算外高丽</span>  
<span style="margin-left: 2em">及其同经之地即初亏在酉末戌初而西洋意大里</span>  
<span style="margin-left: 2em">亚诸国日尚在天顶为午正则不见月食以里差推</span>  
<span style="margin-left: 2em">之西洋之初亏在己正三刻四分食甚在午正一刻</span>  
<span style="margin-left: 2em">〇七分复圆在未初三刻一十分各算外虽月入景</span>  
<span style="margin-left: 2em">七分五十六秒所居宫度彼此远近皆同而以里差</span>  
<span style="margin-left: 2em">故彼地彼时太阳在午正二十二分太阴反在子正</span>  
<span style="margin-left: 2em">二十二分食甚正在日中何从见之今壬申年九月</span>  
<span style="margin-left: 2em">十五日夜望月食初亏在卯初三刻则陜西四川等</span>  
<span style="margin-left: 2em">处得见南京山东等近海东境不可得见也秦蜀之</span>  
<span style="margin-left: 2em">子午异于东方之子午故</span>  
<span style="margin-left: 2em">今以顺天府推算本食因定各省直之食时宜先定</span>  
<span style="margin-left: 2em">各省直视顺天子午线之里差几何后以其所差度</span>  
<span style="margin-left: 2em">数化为所差时刻每一度应得时四分向东以加于</span>  
<span style="margin-left: 2em">顺天推定时刻向西则减乃可得各省直见食时刻</span>  
<span style="margin-left: 2em">也若日食则其食分多寡加时早晚皆系视差东西</span>  
<span style="margin-left: 2em">南北悉无同者必须随地考北极高下差其距度随</span>  
<span style="margin-left: 2em">地测子午正线差其经度乃可定其目见器测之视</span>  
<span style="margin-left: 2em">时定子午术见西测食略中法于当身所居目见器</span>  
<span style="margin-left: 2em">测考定一月食之时刻与先所定他方之月食时刻</span>  
<span style="margin-left: 2em">较算或两地两人同测一月食彼此较算乃以所差</span>  
<span style="margin-left: 2em">时刻得所差度分也</span>  
<span style="margin-left: 2em">前顺天府所推月食时刻并具各省直先后差数因</span>  
<span style="margin-left: 2em">未得诸方见食确数无从遽定地之经度但依广舆</span>  
<span style="margin-left: 2em">图计里画方之法略率开载耳既而咨报多相合者</span>

<span style="margin-left: 2em">敢以耳闻臆断勒为成书也左方所记政所谓略率</span>
