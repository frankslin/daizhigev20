## 崇禎曆書卷之六十　交食歷指卷三

<span style="margin-left: 1em">曆指第十一卷　交食三</span>  
<span style="margin-left: 2em">求視會實會第一</span>  
<span style="margin-left: 1em">前所得實會時刻雖則合天于人目所見儀器所測未</span>  
<span style="margin-left: 2em">盡合也所以然者太陽行度赤道交子午圈有升度</span>  
<span style="margin-left: 2em">差隨時變易日日不均<sub class="note-yuan">詳見日躔曆指</sub>而今依曆元推步或</span>  
<span style="margin-left: 2em">用表查算無能不均須用加減時表以求本地可見</span>  
<span style="margin-left: 2em">可測之實時又推步者但依本地所定子午線其在</span>  
<span style="margin-left: 2em">地方不同子午線者難可通用故又用里差加減以</span>  
<span style="margin-left: 2em">求諸方所見所測之實時也</span>  
<span style="margin-left: 3em">實時改視時</span>  
<span style="margin-left: 1em">如前求太陽實度得中實兩會相距時刻查太陽平行</span>  
<span style="margin-left: 2em">時表得分數依前加減時刻亦加亦減于前得太陽</span>  
<span style="margin-left: 2em">經度乃得實度　假如前推壬申三月望會太陽平</span>  
<span style="margin-left: 2em">經度爲四宮<sub class="note-yuan">冬至起算</sub>一十二度三十四分〇一秒中實</span>  
<span style="margin-left: 2em">兩會之差得六時一十二分五十五秒其距間又得</span>  
<span style="margin-left: 2em">太陽平行一十五分一十八秒以加于中會時之太</span>  
<span style="margin-left: 2em">陽平經度得其實會時平經度四宮一十二度四十</span>  
<span style="margin-left: 2em">九分一十九秒更加其次均度一度三十六分三十</span>  
<span style="margin-left: 2em">六秒則太陽實度四宮一十四度二十五分五十五</span>  
<span style="margin-left: 2em">秒今查加減時表得〇九分五十五秒其號爲加則</span>  
<span style="margin-left: 2em">以加于實會共得二十時〇五分四十四秒算外得</span>  
<span style="margin-left: 2em">癸丑日戌正五分爲順天府所見所測之食甚時</span>  
<span style="margin-left: 3em">見食隨地異時</span>  
<span style="margin-left: 1em">月食分數天下皆同第見食時刻隨地各異何也人各</span>  
<span style="margin-left: 2em">就所居之地目力所及者則見月食而各所居地皆</span>  
<span style="margin-left: 2em">以子午正線爲主若其地同居一子午線者<sub class="note-yuan">南北地緯雖異</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">東西地經則同</sub>則所見月食之分數遲速皆同也若地易子</span>  
<span style="margin-left: 2em">午線易則時刻并易矣所以然者時刻早晚因太陽</span>  
<span style="margin-left: 2em">行度隨人所居各以見日出入爲東西爲卯酉即以</span>  
<span style="margin-left: 2em">日中爲南爲子午而平分時刻故月食時必本地之</span>  
<span style="margin-left: 2em">日未東升或己西沉乃得見之若在其晝時刻不可</span>  
<span style="margin-left: 2em">得見也天啓三年九月十五夜望月食順天府及南</span>  
<span style="margin-left: 2em">北同經之地則初虧在酉初一刻一十二分食甚在</span>  
<span style="margin-left: 2em">戌初初刻復圓在戌正二刻一十三分各算外高麗</span>  
<span style="margin-left: 2em">及其同經之地即初虧在酉末戌初而西洋意大里</span>  
<span style="margin-left: 2em">亞諸國日尚在天頂爲午正則不見月食以里差推</span>  
<span style="margin-left: 2em">之西洋之初虧在己正三刻四分食甚在午正一刻</span>  
<span style="margin-left: 2em">〇七分復圓在未初三刻一十分各算外雖月入景</span>  
<span style="margin-left: 2em">七分五十六秒所居宮度彼此遠近皆同而以里差</span>  
<span style="margin-left: 2em">故彼地彼時太陽在午正二十二分太陰反在子正</span>  
<span style="margin-left: 2em">二十二分食甚正在日中何從見之今壬申年九月</span>  
<span style="margin-left: 2em">十五日夜望月食初虧在卯初三刻則陜西四川等</span>  
<span style="margin-left: 2em">處得見南京山東等近海東境不可得見也秦蜀之</span>  
<span style="margin-left: 2em">子午異于東方之子午故</span>  
<span style="margin-left: 2em">今以順天府推算本食因定各省直之食時宜先定</span>  
<span style="margin-left: 2em">各省直視順天子午線之里差幾何後以其所差度</span>  
<span style="margin-left: 2em">數化爲所差時刻每一度應得時四分向東以加于</span>  
<span style="margin-left: 2em">順天推定時刻向西則減乃可得各省直見食時刻</span>  
<span style="margin-left: 2em">也若日食則其食分多寡加時早晚皆係視差東西</span>  
<span style="margin-left: 2em">南北悉無同者必須隨地考北極高下差其距度隨</span>  
<span style="margin-left: 2em">地測子午正線差其經度乃可定其目見器測之視</span>  
<span style="margin-left: 2em">時定子午術見西測食略中法于當身所居目見器</span>  
<span style="margin-left: 2em">測考定一月食之時刻與先所定他方之月食時刻</span>  
<span style="margin-left: 2em">較算或兩地兩人同測一月食彼此較算乃以所差</span>  
<span style="margin-left: 2em">時刻得所差度分也</span>  
<span style="margin-left: 2em">前順天府所推月食時刻并具各省直先後差數因</span>  
<span style="margin-left: 2em">未得諸方見食確數無從遽定地之經度但依廣輿</span>  
<span style="margin-left: 2em">圖計里畫方之法略率開載耳既而咨報多相合者</span>  
<span style="margin-left: 2em">然非甄明之輩躬至其地測極高下見食早晚終未</span>  
<span style="margin-left: 2em">敢以耳聞臆斷勒爲成書也左方所記政所謂略率</span>  
<span style="margin-left: 2em">開載者欲求决定當竢異日故稱約加約減焉</span>  
<span style="margin-left: 2em">南京應天府及福建福州府約加四分<sub class="note-yuan">凡一十五分爲一刻</sub></span>  
<span style="margin-left: 2em">山東濟南府約加五分<sub class="note-jiao">校：原作減五分據奎章閣本清刊本改</sub></span>  
<span style="margin-left: 2em">山西太原府約減一刻〇九分</span>  
<span style="margin-left: 2em">湖廣武昌府河南開封府約減一刻</span>  
<span style="margin-left: 2em">陜西西安府廣西桂林府約減二刻〇四分</span>  
<span style="margin-left: 2em">浙江杭州府約加十二分</span>  
<span style="margin-left: 2em">江西南昌府約減一十分</span>  
<span style="margin-left: 2em">廣東廣州府約減一刻〇五分</span>  
<span style="margin-left: 2em">四川成都府約減三刻〇七分</span>  
<span style="margin-left: 2em">貴州貴陽府約減二刻〇八分</span>  
<span style="margin-left: 2em">雲南雲南府約減四刻〇八分</span>  
<span style="margin-left: 3em">證子午差變易見時</span>  
<span style="margin-left: 1em">萬曆元年癸酉十一月望依大統曆推月食初虧丑正</span>  
<span style="margin-left: 2em">一刻食甚寅初三刻本夜第谷在西國測得食甚在</span>  
<span style="margin-left: 2em">戌正〇三分于時太陽近冬至所測時即定望時無</span>  
<span style="margin-left: 2em">加減大統所推稍疏大略東西差時三十餘刻爲順</span>  
<span style="margin-left: 2em">天府所見後于西國也</span>  
<span style="margin-left: 1em">萬曆五年丁丑三月十五日夜望依大統曆月食甚寅</span>  
<span style="margin-left: 2em">正一刻第谷測戌正三刻〇五分先後差七小時一</span>  
<span style="margin-left: 2em">刻一十分爲一彼一此子午異線變易加時也</span>  
<span style="margin-left: 1em">萬曆二十年壬辰十一月望大統曆記食甚寅初二刻</span>  
<span style="margin-left: 2em">第谷測在戌初二刻〇七分加時差二分總得差七</span>  
<span style="margin-left: 2em">小時三刻〇二分則西國之夜望爲順天府之曉望</span>  
<span style="margin-left: 2em">西國半夜後所測在順天爲次晝不可得見也</span>  
<span style="margin-left: 1em">萬曆四十年壬子四月十五日夜望曆官報月食初虧</span>  
<span style="margin-left: 2em">寅正一刻既實測得寅正四刻當時西國把沕辣有</span>  
<span style="margin-left: 2em">測戌正三刻〇八分者更西多勒都測得戌正〇三</span>  
<span style="margin-left: 2em">方同測不必加減時得順天府較極西差九小時正</span>  
<span style="margin-left: 2em">較中西差八小時〇七分</span>  
<span style="margin-left: 1em">萬曆四十四年丙辰正月十六日夜望雲陰不見初虧</span>  
<span style="margin-left: 2em">至戌正一刻見食一分約食九分有奇測復圓在亥</span>  
<span style="margin-left: 2em">正四刻于時小西洋之印度國測月正出地平上食</span>  
<span style="margin-left: 2em">九分有奇此地北極出地一十五度二十五分因本</span>  
<span style="margin-left: 2em">食時太陽在娵訾宮一十四度其半晝弧得五小時</span>  
<span style="margin-left: 2em">三刻〇八分則太陽入地時正太陰食甚時爲酉初</span>  
<span style="margin-left: 2em">三刻〇八分又復圓時測畢宿大星高五十五度次</span>  
<span style="margin-left: 2em">測軒轅大星高四十六度以先測之畢宿大星得復</span>  
<span style="margin-left: 2em">圓在戌初二刻一十一分以次測之軒轅大星得復</span>  
<span style="margin-left: 2em">圓在戌初三刻則順天府較後三小時一刻</span>  
<span style="margin-left: 1em">萬曆四十五年丁巳正月十五日夜望依大統曆推復</span>  
<span style="margin-left: 2em">圓亥正二刻庶幾密合廣州府測得復圓亥正一十</span>  
<span style="margin-left: 2em">三分南印度國測在戌初三刻則廣州府較順天府</span>  
<span style="margin-left: 2em">偏西差一十七分南印度更西較廣東差二小時一</span>  
<span style="margin-left: 2em">刻一十三分</span>  
<span style="margin-left: 1em">天啓三年癸亥九月十五日夜望初虧月未出順天府</span>  
<span style="margin-left: 2em">測得復圓戌正二刻一十分杭州府測戌正三刻〇</span>  
<span style="margin-left: 2em">七分上海縣測亥初一刻三方較得杭州視順天偏</span>  
<span style="margin-left: 2em">東差一十二分上海視杭州更東差一刻〇八分上</span>  
<span style="margin-left: 2em">海視順天偏東總差二刻〇五分</span>  
<span style="margin-left: 1em">天啓四年甲子八月十四日夜望曆官報月食一十三</span>  
<span style="margin-left: 2em">分六十五秒初虧丑正初刻既測得一十六分六十</span>  
<span style="margin-left: 2em">三秒初虧丑初二刻〇六分小西洋北國測得子初</span>  
<span style="margin-left: 2em">三刻〇八分泰西教主京都測得酉正三刻一十三</span>  
<span style="margin-left: 2em">分較得北印度視順天府偏西差七刻一十三分視</span>  
<span style="margin-left: 2em">泰西差六小時二刻〇八分</span>  
<span style="margin-left: 1em">天啓七年丁卯十二月望月食曆官報初虧寅正三刻</span>  
<span style="margin-left: 2em">復圓辰初三刻既實測得初虧寅初初刻〇一分復</span>  
<span style="margin-left: 2em">圓卯正三刻〇六分與西法合于時太陽在玄枵宮</span>  
<span style="margin-left: 2em">一度順天府出地平上爲辰初一十一分依大統曆</span>  
<span style="margin-left: 2em">推復圓在辰初三刻則在日出後二刻不可得見而</span>  
<span style="margin-left: 2em">同時陜西西安府則見復圓在天測得大角星高四</span>  
<span style="margin-left: 2em">十七度其北極出地三十四度一十九分得月食初</span>  
<span style="margin-left: 2em">虧丑正二刻〇三分將復圓測角南星高四十一度</span>  
<span style="margin-left: 2em">五十分得卯正一刻〇二分視京師偏西差二刻〇</span>  
<span style="margin-left: 2em">四分爲八度半也</span>  
<span style="margin-left: 1em">崇禎四年辛未四月十五日戊午夜望依大統曆月初</span>  
<span style="margin-left: 2em">虧丑初三刻依新曆初虧丑初〇六分三十八秒實</span>  
<span style="margin-left: 2em">測得丑初〇五分大角星高四十九度四十分距午</span>  
<span style="margin-left: 2em">正三十九度加其距太陽一百五十七度二十七分</span>  
<span style="margin-left: 2em">得太陽過正午一十三小時〇五分二十八秒去半</span>  
<span style="margin-left: 2em">日刻餘一時〇五分爲丑初〇五分新曆初報各省</span>  
<span style="margin-left: 2em">較順天差數在四川成都府初虧子正一十四分三</span>  
<span style="margin-left: 2em">十八秒彼中實測正合是成都府視京師偏西差三</span>  
<span style="margin-left: 2em">刻〇六分得一十二度四十五分爲兩子午線之度</span>  
<span style="margin-left: 2em">差較各處實測食之時如此凡有兩處東西相距則</span>  
<span style="margin-left: 2em">所得時刻必差若相距愈遠則所得食之時刻差必</span>  
<span style="margin-left: 2em">愈多蓋因子午不同證見食時故不同</span>  
<span style="margin-left: 2em">推步交食本論第二</span>  
<span style="margin-left: 1em">步交食之術有二一曰加時早晚一曰食分淺深加時</span>  
<span style="margin-left: 2em">者日食于朔月食于望當豫定其食甚在某時刻分</span>  
<span style="margin-left: 2em">秒也食分者月所借之日光食于地景地所受之日</span>  
<span style="margin-left: 2em">光食于月景當豫定其失光幾何分秒也加時早晚</span>  
<span style="margin-left: 2em">非在日月正相會相望之實時而在人目所見儀器</span>  
<span style="margin-left: 2em">所測之視時乃視時無均度可推故日月兩食皆先</span>  
<span style="margin-left: 2em">求其實時既得實時然後從視處密求日食之定時</span>  
<span style="margin-left: 2em"><sub class="note-yuan">詳見後篇</sub>惟月食則實時即近視時也然日與月實相會</span>  
<span style="margin-left: 2em">之度分未定即欲求其實時無從可得故須先推中</span>  
<span style="margin-left: 2em">會時計其平行及自行而得均數然後以均數加減</span>  
<span style="margin-left: 2em">求得其實會因得其實時矣古法所謂躔離朓朒即</span>  
<span style="margin-left: 2em">自行均數之謂兹特深求原委以故倍加詳密耳若</span>
