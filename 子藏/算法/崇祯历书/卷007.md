## 崇禎曆書卷之七　崇禎奏疏

*崇禎七年閏八月十八日至崇禎七年十一月二十四日*

<span style="margin-left: 2em">緣起七</span>  
<span style="margin-left: 7em">崇禎七年閏八月十八日李天經題本</span>  
<span style="margin-left: 3em">督修曆法山東布政使司右參政臣李天經謹</span>  
<span style="margin-left: 2em">題爲預報諸曜會合凌犯行度並陳節氣始末以資</span>  
<span style="margin-left: 3em">考核以正曆法事該臣于崇禎七年八月十八日</span>  
<span style="margin-left: 3em">回</span>  
<span style="margin-left: 2em">奏月食奉</span>  
<span style="margin-left: 1em">聖旨已有旨了七政諸行須晝夜考測李天經即協同</span>  
<span style="margin-left: 2em">各官生精心講求期底成績禮部知道欽此欽遵臣</span>  
<span style="margin-left: 2em">恭承</span>  
<span style="margin-left: 1em">明命夙夜乾惕毎毎督率監局官生逐時測算乃于考</span>  
<span style="margin-left: 3em">求七政之餘依新法算得土火金三星本年九月</span>  
<span style="margin-left: 3em">初旬會于尾宿之天江左右木星亦于是月前犯</span>  
<span style="margin-left: 3em">鬼宿之積尸氣一時五緯已有其四未必非以數</span>  
<span style="margin-left: 3em">合天即天驗法之一據也從來治曆名家大都于</span>  
<span style="margin-left: 3em">列宿諸星有經度無緯度雖回回曆近之猶然千</span>  
<span style="margin-left: 3em">百年前古法用之未必合天故臣等所推經緯度</span>  
<span style="margin-left: 3em">數時刻分秒若數一二與監推所得者各各不同</span>  
<span style="margin-left: 3em">又如本年八月秋分大統算在八月三十日未正</span>  
<span style="margin-left: 3em">一刻而新法算在閏八月初二日未初一刻一十</span>  
<span style="margin-left: 3em">分相距約差二日臣于閏八月初二日同監局官</span>  
<span style="margin-left: 3em">生用儀器測得太陽午正高五十度零六分尚差</span>  
<span style="margin-left: 3em">一分入交推變時刻應在未初一刻一十分與新</span>  
<span style="margin-left: 3em">法脗合隨取輔臣徐光啓從前測景簿查對數年</span>  
<span style="margin-left: 3em">俱如一日然此非臆說也臣謹按春秋傳曰分同</span>  
<span style="margin-left: 3em">道也至相過也是二語者可爲今日節氣差訛之</span>  
<span style="margin-left: 3em">一証蓋太陽行黃道中線迄二分而黃道與赤道</span>  
<span style="margin-left: 3em">相交此晝夜之所以平而分之名所繇起也迄二</span>  
<span style="margin-left: 3em">至則過赤道內外各二十三度有奇矣夫過赤道</span>  
<span style="margin-left: 3em">二十三度有奇者爲真至則兩道相交于一線者</span>  
<span style="margin-left: 3em">不爲真分乎即舊法亦知分前分後之有晝夜平</span>  
<span style="margin-left: 3em">但拘泥一定之法平分歲實計日立算其于盈縮</span>  
<span style="margin-left: 3em">加減之理多所未曉無怪其認平與分爲二也何</span>  
<span style="margin-left: 3em">也太陽有平行有實行平則每日約行若干而實</span>  
<span style="margin-left: 3em">則有多有寡日日不等從最高起算用法加減之</span>  
<span style="margin-left: 3em">始得真度分真節氣故新法之與舊法惟冬夏二</span>  
<span style="margin-left: 3em">至止差時刻餘則有差至一日二日者不獨秋分</span>  
<span style="margin-left: 3em">爲然秋分其一端也謹將諸曜會合凌犯行度開</span>  
<span style="margin-left: 3em">具圖象表說一冊進呈</span>  
<span style="margin-left: 1em">御覽伏乞</span>
