## 崇祯历书卷之七　崇祯奏疏

*崇祯七年闰八月十八日至崇祯七年十一月二十四日*

<span style="margin-left: 2em">缘起七</span>  
<span style="margin-left: 7em">崇祯七年闰八月十八日李天经题本</span>  
<span style="margin-left: 3em">督修历法山东布政使司右参政臣李天经谨</span>  
<span style="margin-left: 2em">题为预报诸曜会合凌犯行度并陈节气始末以资</span>  
<span style="margin-left: 3em">考核以正历法事该臣于崇祯七年八月十八日</span>  
<span style="margin-left: 3em">回</span>  
<span style="margin-left: 2em">奏月食奉</span>  
<span style="margin-left: 1em">圣旨已有旨了七政诸行须昼夜考测李天经即协同</span>  
<span style="margin-left: 2em">各官生精心讲求期底成绩礼部知道钦此钦遵臣</span>  
<span style="margin-left: 2em">恭承</span>  
<span style="margin-left: 1em">明命夙夜乾惕毎毎督率监局官生逐时测算乃于考</span>  
<span style="margin-left: 3em">求七政之余依新法算得土火金三星本年九月</span>  
<span style="margin-left: 3em">初旬会于尾宿之天江左右木星亦于是月前犯</span>  
<span style="margin-left: 3em">鬼宿之积尸气一时五纬已有其四未必非以数</span>  
<span style="margin-left: 3em">合天即天验法之一据也从来治历名家大都于</span>  
<span style="margin-left: 3em">列宿诸星有经度无纬度虽回回历近之犹然千</span>  
<span style="margin-left: 3em">百年前古法用之未必合天故臣等所推经纬度</span>  
<span style="margin-left: 3em">数时刻分秒若数一二与监推所得者各各不同</span>  
<span style="margin-left: 3em">又如本年八月秋分大统算在八月三十日未正</span>  
<span style="margin-left: 3em">一刻而新法算在闰八月初二日未初一刻一十</span>  
<span style="margin-left: 3em">分相距约差二日臣于闰八月初二日同监局官</span>  
<span style="margin-left: 3em">生用仪器测得太阳午正高五十度零六分尚差</span>  
<span style="margin-left: 3em">一分入交推变时刻应在未初一刻一十分与新</span>  
<span style="margin-left: 3em">法脗合随取辅臣徐光启从前测景簿查对数年</span>  
<span style="margin-left: 3em">俱如一日然此非臆说也臣谨按春秋传曰分同</span>  
<span style="margin-left: 3em">道也至相过也是二语者可为今日节气差讹之</span>  
<span style="margin-left: 3em">一证盖太阳行黄道中线迄二分而黄道与赤道</span>  
<span style="margin-left: 3em">相交此昼夜之所以平而分之名所繇起也迄二</span>  
<span style="margin-left: 3em">至则过赤道内外各二十三度有奇矣夫过赤道</span>  
<span style="margin-left: 3em">二十三度有奇者为真至则两道相交于一线者</span>  
<span style="margin-left: 3em">不为真分乎即旧法亦知分前分后之有昼夜平</span>  
<span style="margin-left: 3em">但拘泥一定之法平分岁实计日立算其于盈缩</span>  
<span style="margin-left: 3em">加减之理多所未晓无怪其认平与分为二也何</span>  
<span style="margin-left: 3em">也太阳有平行有实行平则每日约行若干而实</span>  
<span style="margin-left: 3em">则有多有寡日日不等从最高起算用法加减之</span>  
<span style="margin-left: 3em">始得真度分真节气故新法之与旧法惟冬夏二</span>  
<span style="margin-left: 3em">至止差时刻余则有差至一日二日者不独秋分</span>  
<span style="margin-left: 3em">为然秋分其一端也谨将诸曜会合凌犯行度开</span>
