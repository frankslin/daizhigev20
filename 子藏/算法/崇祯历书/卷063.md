<span style="margin-left: 1em">曆指第十四卷　交食六</span>  
<span style="margin-left: 2em">外三差</span>  
<span style="margin-left: 1em">前論交食法有東西南北高庳三差皆生於地徑蓋以</span>  
<span style="margin-left: 2em">地爲太圜之心爲此界以宗動天爲彼界日月在兩</span>  
<span style="margin-left: 2em">界之間因地徑之小於日大於月生彼界之視三差</span>  
<span style="margin-left: 2em">也今言外三差者於三差之外復有三差不生於日</span>  
<span style="margin-left: 2em">月地之三徑而生於氣氣有輕重有厚薄各因地因</span>  
<span style="margin-left: 2em">時而三光之視度爲之變易三者一曰清蒙高差是</span>  
<span style="margin-left: 2em">近於地平爲地面所出清蒙之氣變易高下也二曰</span>  
<span style="margin-left: 2em">清蒙徑差亦因地上清蒙之氣而人目所見太陽本</span>  
<span style="margin-left: 2em">徑之大小爲所變易也三曰本氣徑差本氣者四行</span>  
<span style="margin-left: 2em">之一即內經素問所謂大氣地面以上月天以下充</span>  
<span style="margin-left: 2em">塞太空者是也此比於地上清蒙更爲精微無形質</span>  
<span style="margin-left: 2em">而亦能變易太陽之光照使目所見之視度隨地隨</span>  
<span style="margin-left: 2em">時小大不一也外三差之義振古不聞西史第谷於</span>  
<span style="margin-left: 2em">萬曆年間殫精推測鈎深索隱曆家推重以爲冠絕</span>  
<span style="margin-left: 2em">古今而此秘未睹至其暮年方行萬里乃始洞徹原</span>  
<span style="margin-left: 2em">委尚未及著書其門人述遵遺指撰集論次然後交</span>  
<span style="margin-left: 2em">食之法於理爲盡則近今十餘年事耳蓋曆學之難</span>  
<span style="margin-left: 2em">言如此</span>  
<span style="margin-left: 3em">清蒙高差</span>  
<span style="margin-left: 1em">曆家測驗日月及經緯諸星積累所得其光入人目往</span>  
<span style="margin-left: 2em">往不依直線而至夫太陰太陽有地徑視差無怪其</span>  
<span style="margin-left: 2em">然也恆星無地徑差人測之在地面與在地心不異</span>  
<span style="margin-left: 2em">宜所見者必依直線若之何不然且兩星相距近於</span>  
<span style="margin-left: 2em">地平與其相距近於天頂絕不同其各體之大小亦</span>  
<span style="margin-left: 2em">不同又太陽太陰固有地徑差其視體偏下視高度</span>  
<span style="margin-left: 2em">宜少而所得者忽復多定望時二曜正居天地徑之</span>  
<span style="margin-left: 2em">兩端以理論見一不得見二或並見則半體而已今</span>  
<span style="margin-left: 2em">有時全見之何也古度數家見直物入水中折成曲</span>  
<span style="margin-left: 2em">象空水之交則有鈍角以此鈍角喻諸星射目之折</span>  
<span style="margin-left: 2em">線於理爲允則近地面之氣可比於水天體至清可</span>  
<span style="margin-left: 2em">比水晶光在有氣無氣之交必成折角而能令諸曜</span>  
<span style="margin-left: 2em">之象升卑爲高也若星距頂愈遠所射光之折線角</span>  
<span style="margin-left: 2em">愈減其鈍而視高之去實高也愈多蓋近地則濕氣</span>  
<span style="margin-left: 2em">愈厚故受蒙爲甚而又實非雲霧等有質之物且在</span>  
<span style="margin-left: 2em">地濁之上<sub class="note-yuan">曆言入濁言濁中近濁入則不見視此爲異也</sub>謂之清蒙也因此</span>  
<span style="margin-left: 2em">凡測候兩星若距度線與地平平行者其在高之距</span>  
<span style="margin-left: 2em">與在庳之距必小有異若不與地平平行而兩高弧</span>  
<span style="margin-left: 2em">各異者不論或正<sub class="note-yuan">與地平爲直角</sub>或斜<sub class="note-yuan">與地平爲斜角</sub>其在高之距</span>  
<span style="margin-left: 2em">與在庳之距亦小有異總之星愈近于地兩距之實</span>  
<span style="margin-left: 2em">度愈少遠則愈多矣第谷之本地北極高五十五度</span>  
<span style="margin-left: 2em">有奇測定太陽太陰之蒙氣差大約相等自地平以</span>  
<span style="margin-left: 2em">上至四十餘度高差漸少更高則無有而近地之最</span>  
<span style="margin-left: 2em">大差得三十四分故太陽極近地平以地徑視差之</span>  
<span style="margin-left: 2em">偏庳三分蒙氣差之視高三十四分相減得太陽高</span>  
<span style="margin-left: 2em">弧之視差三十一分則目視太陽將入以下周至地</span>  
<span style="margin-left: 2em">平見謂在上而其實體已全入于地太陰以最大之</span>  
<span style="margin-left: 2em">地徑視差六十三分蒙氣差之視高三十三分相減</span>  
<span style="margin-left: 2em">餘三十〇分目視之見謂全沒而其實體猶全在地</span>  
<span style="margin-left: 2em">平上也多祿某以渾天儀測太陽行春秋分積年所</span>  
<span style="margin-left: 2em">得皆以本日兩交于赤道遂爲千古不決之疑不知</span>  
<span style="margin-left: 2em">者意其差在儀器儀器果差安得百無一合又安得</span>  
<span style="margin-left: 2em">悉在地平之上竟無差而在下者乎至近世而後知</span>  
<span style="margin-left: 2em">爲清蒙之差也第谷用器甚多甚精諸器畢合不可</span>  
<span style="margin-left: 2em">謂有器差而其所得亦復如是所以然者太陽臨春</span>  
<span style="margin-left: 2em">分論實度尚在赤道南晨測之爲蒙氣所升視之巳</span>  
<span style="margin-left: 2em">在赤道上迨太陽近午出蒙氣之外復測之始以實</span>  
<span style="margin-left: 2em">行交於赤道爲真春分秋分反是先以近午之實行</span>  
<span style="margin-left: 2em">在赤道上爲真秋分迨昏測之日巳入過赤道而北</span>  
<span style="margin-left: 2em">矣視度乃復在赤道上自朝至中不能有兩春分自</span>  
<span style="margin-left: 2em">中至夕不能有兩秋分則朝夕所見皆視度非實度</span>  
<span style="margin-left: 2em">也則皆清蒙之高差也</span>  
<span style="margin-left: 1em">問清蒙之氣能變易太陽太陰之實度是已其言隨地</span>  
<span style="margin-left: 2em">隨時又各不同者何謂也曰第谷測定清蒙諸差太</span>  
<span style="margin-left: 2em">陽與太陰大約相等而與諸星則不等其五星所得</span>  
<span style="margin-left: 2em">之差又與恆星不等因此推知致差之因不在距地</span>  
<span style="margin-left: 2em">遠近其差大小皆氣之所爲也氣厚薄時之所爲也</span>  
<span style="margin-left: 2em">距地遠近地之所爲也凡考七曜之蒙差皆候其高</span>  
<span style="margin-left: 2em">弧至於無蒙之處得其實度而以較於有蒙之處得</span>  
<span style="margin-left: 2em">其視差幾何如第谷所居北極高五十五度冬至日</span>  
<span style="margin-left: 2em">夏至夜皆甚短其測候太陽之蒙差必於夏月太陽</span>  
<span style="margin-left: 2em">出蒙氣之上乃可得之測恆星之蒙差又於冬月若</span>  
<span style="margin-left: 2em">夏測星冬測日則盡日盡夜皆在蒙氣中無法可得</span>  
<span style="margin-left: 2em">而氣之厚薄冬與夏必有分矣故所定氣差隨之異</span>  
<span style="margin-left: 2em">也若論地則山阜之上蒙氣爲少平地乃多澤國尤</span>  
<span style="margin-left: 2em">多海濱更多蓋此氣周生於大地之面外規之界距</span>  
<span style="margin-left: 2em">地心悉等而地面有高庳其距氣界各各不等此爲</span>  
<span style="margin-left: 2em">淺深厚薄之緣正如海底有坳突之勢因有淺深若</span>  
<span style="margin-left: 2em">海水之面恆平而已然論其恆勢淺氣所生之視差</span>  
<span style="margin-left: 2em">少深氣爲多論其變淺氣或忽然增加少易而多深</span>  
<span style="margin-left: 2em">氣乃鮮有變時也萬曆十八年庚寅夏六月西曆記</span>  
<span style="margin-left: 2em">月食太陽以半體出地其太陰正相對尚高二度入</span>  
<span style="margin-left: 2em">景中已多分及太陰半没而太陽已高二度出地平</span>  
<span style="margin-left: 2em">之上若以恆理論之則太陽心方出地平景心宜同</span>  
<span style="margin-left: 2em">時而入太陰之西周實入於地又當在景心入地之</span>  
<span style="margin-left: 2em">前今太陽心出矣而景心尚高二度非蒙氣所爲安</span>  
<span style="margin-left: 2em">得此乎然此視高差可謂甚大則以本地近於大山</span>  
<span style="margin-left: 2em">之下大河之濱其蒙氣爲厚遇夜清氣上騰凌晨更</span>  
<span style="margin-left: 2em">甚故也若他地他時未必盡同此數故治曆者當先</span>  
<span style="margin-left: 2em">定本地之諸曜蒙差參以時令乃能立表推步其法</span>  
<span style="margin-left: 2em">須累測交食之多寡早晏斟酌定之勿謂精於本法</span>  
<span style="margin-left: 2em">便可隨地隨時必無舛戾也若立差既定而臨食時</span>  
<span style="margin-left: 2em">氣候忽更此則難可豫料然所失無幾矣此高差惟</span>  
<span style="margin-left: 2em">月食累遇之若日食則二曜之蒙氣差大畧相等高</span>  
<span style="margin-left: 2em">弧既同鮮有變易徑可勿論也</span>  
<span style="margin-left: 3em">清蒙徑差</span>  
<span style="margin-left: 1em">太陽全食晝晦星見恆事耳中史及西史皆數記之若</span>  
<span style="margin-left: 2em">太陰全在日與人目之間而不能盡掩日體四周皆</span>  
<span style="margin-left: 2em">有餘光曆家謂之金環或有闕如鈎或云依日月周</span>  
<span style="margin-left: 2em">徑本法則不應有此何者凡此一視徑或大或等于</span>  
<span style="margin-left: 2em">彼一視徑則以此體寘之人目與彼體之間無不全</span>  
<span style="margin-left: 2em">受掩蔽者今止論太陽在其最庳全視徑爲大得三</span>  
<span style="margin-left: 2em">十一分太陰在其最高全視徑爲小得三十〇分三</span>  
<span style="margin-left: 2em">十〇秒其較三十〇秒爲全徑六十分之一耳即定</span>  
<span style="margin-left: 2em">朔果在此時日月以兩心正會何因四周能見太陽</span>  
<span style="margin-left: 2em">之邊乎<sub class="note-yuan">或有時可見詳下文</sub>此說是也然而古今所記實見實</span>  
<span style="margin-left: 2em">測乃復多有之如隆慶元年丁卯三月朔日太陽近</span>  
<span style="margin-left: 2em">於最高得全徑三十分太陰在高庳之正中得全徑</span>  
<span style="margin-left: 2em">三十二分三十四秒則全掩太陽之外尚餘二分三</span>  
<span style="margin-left: 2em">十四秒乃西土實候<sub class="note-jiao">校：實候原作實侯今校正</sub>至食甚時二曜以</span>  
<span style="margin-left: 2em">心正會見有金環又萬曆二十六年戊戌二月朔日</span>  
<span style="margin-left: 2em">太陰在最庳掩太陽復如是論地則此測在西國之</span>  
<span style="margin-left: 2em">內地前測在海濱論北極則此測高五十度前測正</span>  
<span style="margin-left: 2em">高四十二度論臨食時此測有雲前測無雲也<sub class="note-yuan">雲氣雖不</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">掩日月亦能變易光曜損益分秒</sub>而第谷專精候驗多在北海之濱</span>  
<span style="margin-left: 2em">北極高五十六度累年密測終不見太陰盡掩太陽</span>  
<span style="margin-left: 2em">晝晦星見是則日光恆贏月魄恆縮又將疑掩之不</span>  
<span style="margin-left: 2em">盡爲恆事矣迨萬曆二十八年庚子六月朔於內地</span>  
<span style="margin-left: 2em">北極高五十度測得日食五分有半依本地原推正</span>  
<span style="margin-left: 2em">應四分較多一分有半則又日光縮月魄贏也又萬</span>  
<span style="margin-left: 2em">曆二十九年辛丑十一月朔日全食第谷門人於本</span>  
<span style="margin-left: 2em">地北極高六十餘度測得食甚時見金環四周皆廣</span>  
<span style="margin-left: 2em">一分有半<sub class="note-yuan">太陽徑十二分</sub>萬曆三十六年戊申七月朔日食</span>  
<span style="margin-left: 2em">西土內地北極高五十一度測食甚時得二分正同</span>  
<span style="margin-left: 2em">時向北更四度論高視差宜減一分猶宜見食一分</span>  
<span style="margin-left: 2em">而第谷門人密測乃不見食此兩測者皆日先居贏</span>

<span style="margin-left: 3em">求太陰視行</span>  
<span style="margin-left: 1em">定太陰東西差須得其與太陽相會之實度應先<sub class="note-yuan">如在九十</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">度東</sub>應後<sub class="note-yuan">在九十度西</sub>乃使太陰實行即從自行可得則或</span>  
<span style="margin-left: 2em">二十八分一小時或三十〇分或三十三分有奇<sub class="note-yuan">因最</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">高最庳中距不等故</sub>以三率法推其度差則相應幾何時刻因</span>  
<span style="margin-left: 2em">與定朔加減之其所得時亦可於真視會不遠但先</span>  
<span style="margin-left: 2em">後會之度差必以太陰實行爲主然因視差故每每</span>  
<span style="margin-left: 2em">移其本實行故以實行求時差多謬而以視行求之</span>  
<span style="margin-left: 2em">乃準矣法曰日食在九十度東則較定朔前一小時</span>  
<span style="margin-left: 2em">食在九十度西則較定朔後一小時復求東西差以</span>  
<span style="margin-left: 2em">兩差不等之分秒或加或減於太陰一小時因以實</span>  
<span style="margin-left: 2em">行得其視行若次得之東西差大於先得之東西差</span>  
<span style="margin-left: 2em">其兩差不等之數爲減若次得之差數小於先得數</span>  
<span style="margin-left: 2em">則兩差不等之數爲加乃得太陰一小時視行也或</span>  
<span style="margin-left: 2em">不用一小時先於定朔算東西差而以實行化爲時</span>  
<span style="margin-left: 2em">差或加或減於本時得視會又以視會與定朔相去</span>  
<span style="margin-left: 2em">不拘若干惟於此時再求東西差兩差不等之數依</span>  
<span style="margin-left: 2em">前法加減之必得太陰視行時差因以復算真時差</span>  
<span style="margin-left: 1em">假如崇禎四年辛未十月定朔在辛丑日未初八分四</span>  
<span style="margin-left: 2em">十〇秒此時順天府得東西差三分五十〇秒太陰</span>  
<span style="margin-left: 2em">一小時實行爲三十三分二十〇秒以此算得六分</span>  
<span style="margin-left: 2em">五十四秒爲時差因食在九十度東故減得未初〇</span>  
<span style="margin-left: 2em">一分四十六秒即相近視會時也次升度先在正午</span>  
<span style="margin-left: 2em">自春分起爲二百二十六度二十五分四十〇秒因</span>  
<span style="margin-left: 2em">時差宜減一度四十三分則以餘升度查本表得躔</span>  
<span style="margin-left: 2em">度在正午者爲大火宮一十七度一十二分算得九</span>  
<span style="margin-left: 2em">十度在午西離二十三度三十五分比日月距午更</span>  
<span style="margin-left: 2em">遠七度四十四分三十八秒又以太陽高三十六度</span>  
<span style="margin-left: 2em">一十四分算得高弧交黃道角八十四度一十七分</span>  
<span style="margin-left: 2em">則以餘角復得東西差四分五十〇秒兩差不等之</span>  
<span style="margin-left: 2em">數爲〇一分因後得之差大故先得差內減一分實</span>  
<span style="margin-left: 2em">得〇二分五十〇秒爲太陰過太陽之視行也前時</span>  
<span style="margin-left: 2em">差〇六分五十四秒今以三率法依本視行得前東</span>  
<span style="margin-left: 2em">西差〇三分五十〇秒應九分一十九秒爲真時差</span>  
<span style="margin-left: 2em">因減故算得視會在午正三刻一十四分二十一秒</span>  
<span style="margin-left: 2em"><sub class="note-yuan">一十五分爲一刻</sub></span>  
<span style="margin-left: 3em">考真時差</span>  
<span style="margin-left: 1em">真時差者爲太陰視行反覆推求再三加減脗與視會</span>  
<span style="margin-left: 2em">相合者也欲更考其實須算太陰實距太陽幾何若</span>  
<span style="margin-left: 2em">所得分數與太陰所當視會之東西差等則所得視</span>  
<span style="margin-left: 2em">會亦準若微有不等則以不等之分數化爲時依兩</span>  
<span style="margin-left: 2em">曜實相距之分數較之視差或大或小依法加減於</span>  
<span style="margin-left: 2em">前視會如距度大日食在九十度東則時差爲加食</span>  
<span style="margin-left: 2em">在九十度西則時差爲減如距度小則九十度東宜</span>  
<span style="margin-left: 2em">減九十度西宜加分秒內可得其準也因此再求東</span>  
<span style="margin-left: 2em">西差而以本視會時復求九十度限與其距天頂及</span>  
<span style="margin-left: 2em">距太陽度因以本高弧及高弧交黃道角復算視差</span>  
<span style="margin-left: 2em">如前假如得真時差九分一十九秒何以知其然也</span>  
<span style="margin-left: 2em">因減時九十度略在前即壽星宮二十三度〇六分</span>  
<span style="margin-left: 2em">距天頂五十三度四十〇分距午二十三度三十一</span>  
<span style="margin-left: 2em">分較太陽復西去〇八度二十一分算得高弧三十</span>  
<span style="margin-left: 2em">六度三十四分交角八十三度四十五分推東西差</span>  
<span style="margin-left: 2em">〇五分一十三秒故以三率法用太陰實行三十三</span>  
<span style="margin-left: 2em">分二十〇秒一小時以真時差得五分一十〇秒爲</span>  
<span style="margin-left: 2em">太陰實距太陽分數見其與纔得之東西差相等則</span>  
<span style="margin-left: 2em">前時之時差亦準若未等則求所差分數如前東西</span>  
<span style="margin-left: 2em">差三分五十〇秒得九分一十九秒爲時差此不等</span>  
<span style="margin-left: 2em">之三秒亦得七秒依前法視會內應減實得午正三</span>  
<span style="margin-left: 2em">刻一十四分一十四秒乃真視會也</span>  
<span style="margin-left: 3em">求初虧復圓俱依視差算</span>  
<span style="margin-left: 1em">凡算月食推初虧復圓先以開方求其自初虧至食甚</span>  
<span style="margin-left: 2em">所行之度分若干又自食甚至復圓所行之度分亦</span>  
<span style="margin-left: 2em">若干故所推食甚前後時刻大約相等算日食則不</span>  
<span style="margin-left: 2em">然雖太陰在食甚前後所行度數相等而所應之時</span>  
<span style="margin-left: 2em">刻鮮有不參差者蓋視差能變實行爲視行有前得</span>  
<span style="margin-left: 2em">之時較後得爲多亦有後得之時較前得爲多此中</span>  
<span style="margin-left: 7em">種種不一如圖甲爲太陽乙丙丁皆爲</span>  
<span style="margin-left: 7em">太陰甲乙或甲丙爲兩曜視半徑甲丁</span>  
<span style="margin-left: 7em">爲太陰食甚視距度則甲乙線之方數</span>  
<span style="margin-left: 7em">減甲丁線之方數其餘數開方得乙丁</span>  
<span style="margin-left: 7em">線爲太陰自初虧至食甚所行之度與</span>  
<span style="margin-left: 2em">丁丙至復圓數畧相等但太陰行過乙丙線時<sub class="note-yuan">除食甚正</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">在九十度</sub>前後未嘗相等故求之之法必於前時以東西</span>  
<span style="margin-left: 2em">差求其視行則得初虧距食甚之時又於後時復以</span>  
<span style="margin-left: 2em">東西差求其視行乃得復圓與食甚相距之時然初</span>  
<span style="margin-left: 2em">虧與食甚或皆在九十度東則因初時之東西差大</span>  
<span style="margin-left: 2em">于後時之東西差其兩差不等之數減於太陰實行</span>  
<span style="margin-left: 2em">則得視行若初時之東西差反小於後時之東西差</span>  
<span style="margin-left: 2em">其兩差不等之數則加于太陰實行而得其視行或</span>  
<span style="margin-left: 2em">初虧與食甚皆在九十度西而初時之東西差大後</span>  
<span style="margin-left: 2em">時之東西差小其兩差不等之數用加如初時之東</span>  
<span style="margin-left: 2em">西差小後時之東西差大其兩差不等之數用減與</span>  
<span style="margin-left: 2em">前法相反此較初虧與食甚若較食甚與復圓皆爲</span>  
<span style="margin-left: 2em">一理第其兩相比量俱以先東西差與次東西爲主</span>  
<span style="margin-left: 2em">故求初虧則食甚爲後時而求復圓則食甚又爲前</span>  
<span style="margin-left: 2em">時也或前後兩時不同在九十度之一邊如初虧在</span>  
<span style="margin-left: 2em">東食甚在西則求東西差必不止食甚前後之兩次</span>  
<span style="margin-left: 2em">因九十度而中分之則一視行求其時之多半又一</span>  
<span style="margin-left: 2em">視行求其時之餘乃合之爲初時至後時太陰視會</span>  
<span style="margin-left: 2em">所行度分矣</span>  
<span style="margin-left: 1em">假如視會在鶉首宮初度午後正二刻距九十度西得</span>  
<span style="margin-left: 2em">東西差〇五分設得視行二十二分則太陰自九十</span>  
<span style="margin-left: 2em">度至本視會之度兩刻間視東行一十一分如前圖</span>  
<span style="margin-left: 2em">乙丁線爲二十八分減一十一分所餘一十七分爲</span>  
<span style="margin-left: 2em">太陰在九十度東自初虧至食甚時所行即因九十</span>  
<span style="margin-left: 2em">度前一小時以東西差得太陰視行二十一分故其</span>  
<span style="margin-left: 2em">行一十七分必須時三刻〇四分乃自初食至正午</span>  
<span style="margin-left: 2em"><sub class="note-yuan">此正午與九十度同故</sub>爲太陰所行之時并午前後時總得五</span>  
<span style="margin-left: 2em">刻〇四分爲太陰自初虧至食甚過乙丁線所行時</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 3em">算日食復求太陰視距度之故第四</span>  
<span style="margin-left: 1em">前以實會而不得其視會則所求者在東西差乃今視</span>  
<span style="margin-left: 2em">會真矣然何以知其所食大小之分數及以月掩日</span>  
<span style="margin-left: 2em">所向之方位乎曰此皆由於太陰視距度也故推步</span>  
<span style="margin-left: 2em">者必先於食甚求視距度則得日應食幾何分又於</span>  
<span style="margin-left: 2em">初虧復圓求視距度則得月掩日之光在何方</span>  
<span style="margin-left: 3em">日食分數</span>  
<span style="margin-left: 1em">凡推月食以太陰實距度較其半徑及地景半徑即得</span>  
<span style="margin-left: 2em">月食之分今算日食法雖同然因視度爲主則必以</span>  
<span style="margin-left: 2em">太陰視距度與日月兩輪之半徑相較乃得日食分</span>  
<span style="margin-left: 2em">矣依法於視徑本表查日月半徑并之減視距度爲</span>  
<span style="margin-left: 2em">太陰掩日之分<sub class="note-yuan">天度數之分</sub>次以三率法求食之分<sub class="note-yuan">日徑分十</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">分之分</sub>因先於食甚求太陰實距度則太陰視會及實</span>  
<span style="margin-left: 2em">會間之本行或加或減于其交周度依時差加減得</span>  
<span style="margin-left: 2em">視會時太陰交周度用算或查表即得距度</span>  
<span style="margin-left: 1em">假如時差爲三十五分二十一秒宜加此間太陰過太</span>  
<span style="margin-left: 2em">陽行一十七分五十六秒太陽本行〇一分二十七</span>  
<span style="margin-left: 2em">秒相加共得一十九分二十三秒爲太陰本行今設</span>  
<span style="margin-left: 2em">交周實度爲五宮二十九度因時差應加則交周多</span>  
<span style="margin-left: 2em">得一十九分二十三秒終得太陰食甚時實距北〇</span>  
<span style="margin-left: 2em">一分四十一秒次以南北視差本實距度改爲視距</span>  
<span style="margin-left: 2em">度故凡於三差小三角形內考時差并求南北差乃</span>  
<span style="margin-left: 2em">所得爲正視會若太陰距黃道北人居夏至北則實</span>  
<span style="margin-left: 2em">距度恆減視差爲視距度若太陽距黃道南則視差</span>  
<span style="margin-left: 2em">反加於實距度爲視距度</span>  
<span style="margin-left: 1em">假如萬曆二十四年丙申歲八月朔日食曆官報應食</span>  
<span style="margin-left: 2em">九分八十六秒實測得八分强弱之間依新法算當</span>  
<span style="margin-left: 2em">食甚時太陽高五十〇度〇五分得太陰高差三十</span>  
<span style="margin-left: 2em">八分因九十度距太陽西一十六度〇八分算得高</span>  
<span style="margin-left: 2em">弧交黃道角六十八度四十八分爲南北差線其對</span>  
<span style="margin-left: 2em">角爲南北差得三十五分因當時太陰近交中在黃</span>  
<span style="margin-left: 2em">道北二十八分五十〇秒與南北差相減得〇六分</span>  
<span style="margin-left: 2em">一十〇秒乃太陰視距在黃道南矣又日月兩輪半</span>  
<span style="margin-left: 2em">徑并得三十二分〇五秒減視距度得二十五分五</span>  
<span style="margin-left: 2em">十五秒以此求食分數得〇八分二十九秒乃與所</span>  
<span style="margin-left: 2em">測適合也</span>  
<span style="margin-left: 3em">日食圖說</span>  
<span style="margin-left: 1em">新法以圖顯本食所向之方故上下書南北左右書東</span>  
<span style="margin-left: 2em">西其繪圖則以太陰距度爲主但食時先後太陰距</span>  
<span style="margin-left: 2em">度常有變易或初虧距度多而復圓距度少或初虧</span>  
<span style="margin-left: 2em">距度少而復圓距度多此其故蓋因食在交處前後</span>  
<span style="margin-left: 2em">之不一也若前後離交相等則雖距度同而所向南</span>  
<span style="margin-left: 2em">北未免有不同矣故日食前後求太陰視距度必以</span>  
<span style="margin-left: 2em">交周所應食甚視距度減其自初虧至食甚所行徑</span>  
<span style="margin-left: 2em">度則得太陰初虧視距度又以加於自食甚至復圓</span>  
<span style="margin-left: 2em">所行徑度則得其復圓視距度也復求交周所應太</span>  
<span style="margin-left: 2em">陰食甚視距度惟查距度表內上下左右則得交周</span>  
<span style="margin-left: 2em">度及其在交前後分數</span>  
<span style="margin-left: 1em">假如前萬曆二十四年食甚得視距度〇六分一十〇</span>  
<span style="margin-left: 2em">秒即交中後查本表右得〇一度一十二分其本表</span>  
<span style="margin-left: 2em">上則得六宮乃所應視距度交周也又當時自初虧</span>  
<span style="margin-left: 2em">至食甚太陰所行徑度三十一分〇七秒與交周相</span>  
<span style="margin-left: 2em">減得六宮〇度四十一分五十一秒相加得六宮〇</span>  
<span style="margin-left: 2em">一度四十三分〇五秒即初虧及復圓交周也依此</span>  
<span style="margin-left: 7em">交周復查表得初虧視距度〇三分三</span>  
<span style="margin-left: 7em">十三秒而復圓得八分五十三秒因此</span>  
<span style="margin-left: 7em">畫本食圖如乙丁及丙戊兩直線以直</span>  
<span style="margin-left: 7em">角在甲相交指南北東西方乙丁爲黃</span>  
<span style="margin-left: 7em">道甲心爲太陽居其中依前食論其太</span>  
<span style="margin-left: 7em">陽半徑得一十五分一十五秒較太陰</span>  
<span style="margin-left: 2em">半徑畧小甲戊線則并兩輪半徑爲三十二分〇五</span>  
<span style="margin-left: 2em">秒因太陰食甚在辛甲辛乃當時視距度〇六分一</span>  
<span style="margin-left: 2em">十〇秒初虧在壬即乙壬與甲己相等只三分三十</span>  
<span style="margin-left: 2em">三秒復圓在庚得丁庚與甲癸相等共八分五十三</span>  
<span style="margin-left: 2em">秒而壬辛庚皆視距南也</span>
