<span style="margin-left: 1em">历指第十四卷　交食六</span>  
<span style="margin-left: 2em">外三差</span>  
<span style="margin-left: 1em">前论交食法有东西南北高庳三差皆生于地径盖以</span>  
<span style="margin-left: 2em">地为太圜之心为此界以宗动天为彼界日月在两</span>  
<span style="margin-left: 2em">界之间因地径之小于日大于月生彼界之视三差</span>  
<span style="margin-left: 2em">也今言外三差者于三差之外复有三差不生于日</span>  
<span style="margin-left: 2em">月地之三径而生于气气有轻重有厚薄各因地因</span>  
<span style="margin-left: 2em">时而三光之视度为之变易三者一曰清蒙高差是</span>  
<span style="margin-left: 2em">近于地平为地面所出清蒙之气变易高下也二曰</span>  
<span style="margin-left: 2em">清蒙径差亦因地上清蒙之气而人目所见太阳本</span>  
<span style="margin-left: 2em">径之大小为所变易也三曰本气径差本气者四行</span>  
<span style="margin-left: 2em">之一即内经素问所谓大气地面以上月天以下充</span>  
<span style="margin-left: 2em">塞太空者是也此比于地上清蒙更为精微无形质</span>  
<span style="margin-left: 2em">而亦能变易太阳之光照使目所见之视度随地随</span>  
<span style="margin-left: 2em">时小大不一也外三差之义振古不闻西史第谷于</span>  
<span style="margin-left: 2em">万历年间殚精推测钩深索隐历家推重以为冠绝</span>  
<span style="margin-left: 2em">古今而此秘未睹至其暮年方行万里乃始洞彻原</span>  
<span style="margin-left: 2em">委尚未及著书其门人述遵遗指撰集论次然后交</span>  
<span style="margin-left: 2em">食之法于理为尽则近今十余年事耳盖历学之难</span>  
<span style="margin-left: 2em">言如此</span>  
<span style="margin-left: 3em">清蒙高差</span>  
<span style="margin-left: 1em">历家测验日月及经纬诸星积累所得其光入人目往</span>  
<span style="margin-left: 2em">往不依直线而至夫太阴太阳有地径视差无怪其</span>  
<span style="margin-left: 2em">然也恒星无地径差人测之在地面与在地心不异</span>  
<span style="margin-left: 2em">宜所见者必依直线若之何不然且两星相距近于</span>  
<span style="margin-left: 2em">地平与其相距近于天顶绝不同其各体之大小亦</span>  
<span style="margin-left: 2em">不同又太阳太阴固有地径差其视体偏下视高度</span>  
<span style="margin-left: 2em">宜少而所得者忽复多定望时二曜正居天地径之</span>  
<span style="margin-left: 2em">两端以理论见一不得见二或并见则半体而已今</span>  
<span style="margin-left: 2em">有时全见之何也古度数家见直物入水中折成曲</span>  
<span style="margin-left: 2em">象空水之交则有钝角以此钝角喻诸星射目之折</span>  
<span style="margin-left: 2em">线于理为允则近地面之气可比于水天体至清可</span>  
<span style="margin-left: 2em">比水晶光在有气无气之交必成折角而能令诸曜</span>  
<span style="margin-left: 2em">之象升卑为高也若星距顶愈远所射光之折线角</span>  
<span style="margin-left: 2em">愈减其钝而视高之去实高也愈多盖近地则湿气</span>  
<span style="margin-left: 2em">愈厚故受蒙为甚而又实非云雾等有质之物且在</span>  
<span style="margin-left: 2em">地浊之上<sub class="note-yuan">历言入浊言浊中近浊入则不见视此为异也</sub>谓之清蒙也因此</span>  
<span style="margin-left: 2em">凡测候两星若距度线与地平平行者其在高之距</span>  
<span style="margin-left: 2em">与在庳之距必小有异若不与地平平行而两高弧</span>  
<span style="margin-left: 2em">各异者不论或正<sub class="note-yuan">与地平为直角</sub>或斜<sub class="note-yuan">与地平为斜角</sub>其在高之距</span>  
<span style="margin-left: 2em">与在庳之距亦小有异总之星愈近于地两距之实</span>  
<span style="margin-left: 2em">度愈少远则愈多矣第谷之本地北极高五十五度</span>  
<span style="margin-left: 2em">有奇测定太阳太阴之蒙气差大约相等自地平以</span>  
<span style="margin-left: 2em">上至四十余度高差渐少更高则无有而近地之最</span>  
<span style="margin-left: 2em">大差得三十四分故太阳极近地平以地径视差之</span>  
<span style="margin-left: 2em">偏庳三分蒙气差之视高三十四分相减得太阳高</span>  
<span style="margin-left: 2em">弧之视差三十一分则目视太阳将入以下周至地</span>  
<span style="margin-left: 2em">平见谓在上而其实体已全入于地太阴以最大之</span>  
<span style="margin-left: 2em">地径视差六十三分蒙气差之视高三十三分相减</span>  
<span style="margin-left: 2em">余三十〇分目视之见谓全没而其实体犹全在地</span>  
<span style="margin-left: 2em">平上也多禄某以浑天仪测太阳行春秋分积年所</span>  
<span style="margin-left: 2em">得皆以本日两交于赤道遂为千古不决之疑不知</span>  
<span style="margin-left: 2em">者意其差在仪器仪器果差安得百无一合又安得</span>  
<span style="margin-left: 2em">悉在地平之上竟无差而在下者乎至近世而后知</span>  
<span style="margin-left: 2em">为清蒙之差也第谷用器甚多甚精诸器毕合不可</span>  
<span style="margin-left: 2em">谓有器差而其所得亦复如是所以然者太阳临春</span>  
<span style="margin-left: 2em">分论实度尚在赤道南晨测之为蒙气所升视之巳</span>  
<span style="margin-left: 2em">在赤道上迨太阳近午出蒙气之外复测之始以实</span>  
<span style="margin-left: 2em">行交于赤道为真春分秋分反是先以近午之实行</span>  
<span style="margin-left: 2em">在赤道上为真秋分迨昏测之日巳入过赤道而北</span>  
<span style="margin-left: 2em">矣视度乃复在赤道上自朝至中不能有两春分自</span>  
<span style="margin-left: 2em">中至夕不能有两秋分则朝夕所见皆视度非实度</span>  
<span style="margin-left: 2em">也则皆清蒙之高差也</span>  
<span style="margin-left: 1em">问清蒙之气能变易太阳太阴之实度是已其言随地</span>  
<span style="margin-left: 2em">随时又各不同者何谓也曰第谷测定清蒙诸差太</span>  
<span style="margin-left: 2em">阳与太阴大约相等而与诸星则不等其五星所得</span>  
<span style="margin-left: 2em">之差又与恒星不等因此推知致差之因不在距地</span>  
<span style="margin-left: 2em">远近其差大小皆气之所为也气厚薄时之所为也</span>  
<span style="margin-left: 2em">距地远近地之所为也凡考七曜之蒙差皆候其高</span>  
<span style="margin-left: 2em">弧至于无蒙之处得其实度而以较于有蒙之处得</span>  
<span style="margin-left: 2em">其视差几何如第谷所居北极高五十五度冬至日</span>  
<span style="margin-left: 2em">夏至夜皆甚短其测候太阳之蒙差必于夏月太阳</span>  
<span style="margin-left: 2em">出蒙气之上乃可得之测恒星之蒙差又于冬月若</span>  
<span style="margin-left: 2em">夏测星冬测日则尽日尽夜皆在蒙气中无法可得</span>  
<span style="margin-left: 2em">而气之厚薄冬与夏必有分矣故所定气差随之异</span>  
<span style="margin-left: 2em">也若论地则山阜之上蒙气为少平地乃多泽国尤</span>  
<span style="margin-left: 2em">多海滨更多盖此气周生于大地之面外规之界距</span>  
<span style="margin-left: 2em">地心悉等而地面有高庳其距气界各各不等此为</span>  
<span style="margin-left: 2em">浅深厚薄之缘正如海底有坳突之势因有浅深若</span>  
<span style="margin-left: 2em">海水之面恒平而已然论其恒势浅气所生之视差</span>  
<span style="margin-left: 2em">少深气为多论其变浅气或忽然增加少易而多深</span>  
<span style="margin-left: 2em">气乃鲜有变时也万历十八年庚寅夏六月西历记</span>  
<span style="margin-left: 2em">月食太阳以半体出地其太阴正相对尚高二度入</span>  
<span style="margin-left: 2em">景中已多分及太阴半没而太阳已高二度出地平</span>  
<span style="margin-left: 2em">之上若以恒理论之则太阳心方出地平景心宜同</span>  
<span style="margin-left: 2em">时而入太阴之西周实入于地又当在景心入地之</span>  
<span style="margin-left: 2em">前今太阳心出矣而景心尚高二度非蒙气所为安</span>  
<span style="margin-left: 2em">得此乎然此视高差可谓甚大则以本地近于大山</span>  
<span style="margin-left: 2em">之下大河之滨其蒙气为厚遇夜清气上腾凌晨更</span>  
<span style="margin-left: 2em">甚故也若他地他时未必尽同此数故治历者当先</span>  
<span style="margin-left: 2em">定本地之诸曜蒙差参以时令乃能立表推步其法</span>  
<span style="margin-left: 2em">须累测交食之多寡早晏斟酌定之勿谓精于本法</span>  
<span style="margin-left: 2em">便可随地随时必无舛戾也若立差既定而临食时</span>  
<span style="margin-left: 2em">气候忽更此则难可豫料然所失无几矣此高差惟</span>  
<span style="margin-left: 2em">月食累遇之若日食则二曜之蒙气差大畧相等高</span>  
<span style="margin-left: 2em">弧既同鲜有变易径可勿论也</span>  
<span style="margin-left: 3em">清蒙径差</span>  
<span style="margin-left: 1em">太阳全食昼晦星见恒事耳中史及西史皆数记之若</span>  
<span style="margin-left: 2em">太阴全在日与人目之间而不能尽掩日体四周皆</span>  
<span style="margin-left: 2em">有余光历家谓之金环或有阙如钩或云依日月周</span>  
<span style="margin-left: 2em">径本法则不应有此何者凡此一视径或大或等于</span>  
<span style="margin-left: 2em">彼一视径则以此体寘之人目与彼体之间无不全</span>  
<span style="margin-left: 2em">受掩蔽者今止论太阳在其最庳全视径为大得三</span>  
<span style="margin-left: 2em">十一分太阴在其最高全视径为小得三十〇分三</span>  
<span style="margin-left: 2em">十〇秒其较三十〇秒为全径六十分之一耳即定</span>  
<span style="margin-left: 2em">朔果在此时日月以两心正会何因四周能见太阳</span>  
<span style="margin-left: 2em">之边乎<sub class="note-yuan">或有时可见详下文</sub>此说是也然而古今所记实见实</span>  
<span style="margin-left: 2em">测乃复多有之如隆庆元年丁卯三月朔日太阳近</span>  
<span style="margin-left: 2em">于最高得全径三十分太阴在高庳之正中得全径</span>  
<span style="margin-left: 2em">三十二分三十四秒则全掩太阳之外尚余二分三</span>  
<span style="margin-left: 2em">十四秒乃西土实候<sub class="note-jiao">校：實候原作實侯今校正</sub>至食甚时二曜以</span>  
<span style="margin-left: 2em">心正会见有金环又万历二十六年戊戌二月朔日</span>  
<span style="margin-left: 2em">太阴在最庳掩太阳复如是论地则此测在西国之</span>  
<span style="margin-left: 2em">内地前测在海滨论北极则此测高五十度前测正</span>  
<span style="margin-left: 2em">高四十二度论临食时此测有云前测无云也<sub class="note-yuan">云气虽不</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">掩日月亦能变易光曜损益分秒</sub>而第谷专精候验多在北海之滨</span>  
<span style="margin-left: 2em">北极高五十六度累年密测终不见太阴尽掩太阳</span>  
<span style="margin-left: 2em">昼晦星见是则日光恒赢月魄恒缩又将疑掩之不</span>  
<span style="margin-left: 2em">尽为恒事矣迨万历二十八年庚子六月朔于内地</span>  
<span style="margin-left: 2em">北极高五十度测得日食五分有半依本地原推正</span>  
<span style="margin-left: 2em">应四分较多一分有半则又日光缩月魄赢也又万</span>  
<span style="margin-left: 2em">历二十九年辛丑十一月朔日全食第谷门人于本</span>  
<span style="margin-left: 2em">地北极高六十余度测得食甚时见金环四周皆广</span>  
<span style="margin-left: 2em">一分有半<sub class="note-yuan">太阳径十二分</sub>万历三十六年戊申七月朔日食</span>  
<span style="margin-left: 2em">西土内地北极高五十一度测食甚时得二分正同</span>  
<span style="margin-left: 2em">时向北更四度论高视差宜减一分犹宜见食一分</span>

<span style="margin-left: 2em">其两差不等之数为减若次得之差数小于先得数</span>  
<span style="margin-left: 2em">则两差不等之数为加乃得太阴一小时视行也或</span>  
<span style="margin-left: 2em">不用一小时先于定朔算东西差而以实行化为时</span>  
<span style="margin-left: 2em">差或加或减于本时得视会又以视会与定朔相去</span>  
<span style="margin-left: 2em">不拘若干惟于此时再求东西差两差不等之数依</span>
