<span style="margin-left: 1em"><sub class="note-yuan">򐈫罗雅谷򐈫譔򐈫򐈫修政历法极西耶稣会士门人杨之华򐈫周士昌򐈫受法򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫汤若望订</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫掌乘刘有泰</sub></span>  
<span style="margin-left: 2em">论体<sub class="note-jiao">校：清刊本此前有測量全義六卷標題</sub></span>  
<span style="margin-left: 2em">历家所重全在测量所当测者略有三事一曰线测</span>  
<span style="margin-left: 2em">其长短二曰面测其长短广狭三曰体测其长短广</span>  
<span style="margin-left: 2em">狭厚薄所以测体者何也即如交食一法日与月各</span>  
<span style="margin-left: 2em">有不同心本天各有最高度最高冲度其去人远近</span>  
<span style="margin-left: 2em">也恒不等其自相去之远近恒不等人目所见二曜</span>  
<span style="margin-left: 2em">之体大小恒不等若此者必于地体推之故有日与</span>  
<span style="margin-left: 2em">月与地三大之比例<sub class="note-yuan">别有本书</sub>不用此比例何繇知交食</span>  
<span style="margin-left: 2em">之歳月日时地影<sub class="note-yuan">即暗虚</sub>比于月体小大之数几何乎</span>  
<span style="margin-left: 2em">不因地月之比例何从推日轮之视体几何大去人</span>  
<span style="margin-left: 2em">几何远乎则何繇知日食既之有无金环乎何繇知</span>  
<span style="margin-left: 2em">月食过分之暗虚几何大乎何繇定食限之几何时</span>  
<span style="margin-left: 2em">刻乎不知地球之大何繇定东西相去几何里即交</span>  
<span style="margin-left: 2em">食前后相去几何时刻南北相去几何里即日食应</span>  
<span style="margin-left: 2em">有应无有则几何分秒乎则安得不讲于量体之法</span>  
<span style="margin-left: 2em">乎然则测线测面者何也曰体者诸面之积也未能</span>  
<span style="margin-left: 2em">测面安能测体面者又诸线之积也未能测线安能</span>  
<span style="margin-left: 2em">测面又测候七政行度皆以句股弧弦诸法诸法则</span>  
<span style="margin-left: 2em">皆线也诸线之积为面不知面理则亦不能晰线之</span>  
<span style="margin-left: 2em">体势故三测为并重也虽然测天皆曲线曲面也直</span>  
<span style="margin-left: 2em">线与平面何为乎曰曲线法从直线出也曲面法从</span>  
<span style="margin-left: 2em">平面出也犹圆体法从方体出也故繇线而面而体</span>  
<span style="margin-left: 2em">繇直线而曲线平面而曲面方体而圆体譬之跬步</span>  
<span style="margin-left: 2em">前步未行后步不可得进也是测量之全义也</span>  
<span style="margin-left: 1em">体者面之积或实如金木土石等或空如盘池陶穹等</span>  
<span style="margin-left: 2em">俱同理同法</span>  
<span style="margin-left: 2em">其界为面面居体之周<sub class="note-yuan">面截面生棱如线遇线生角也又棱为两面之共界</sub></span>  
<span style="margin-left: 3em">一面之体如球如卵</span>  
<span style="margin-left: 3em">二面之体如半球半卵圆角圆堆</span>  
<span style="margin-left: 3em">三面之体如剖球卵之一分</span>  
<span style="margin-left: 3em">四面之体如三面角体而四面等</span>  
<span style="margin-left: 5em">即三面角体第因各面俱等故属四面</span>  
<span style="margin-left: 3em">五面之体如四面角体<sub class="note-yuan">因角体之面无定数故左方不列其名</sub></span>  
<span style="margin-left: 3em">六面之体如立方正立方斜立方</span>  
<span style="margin-left: 3em">八面之体八面俱等</span>  
<span style="margin-left: 3em">十二面之体十二面俱等</span>  
<span style="margin-left: 3em">二十面之体二十面俱等<sub class="note-yuan">自四六八十二二十面之外不能为等面胥无</sub></span>  
<span style="margin-left: 3em"><sub class="note-yuan">法之体也</sub></span>  
<span style="margin-left: 3em">公量如斗如升皆足为体之量总之以立方为本</span>  
<span style="margin-left: 3em">如用尺寸分为度而一尺之体其长其广其袤各</span>  
<span style="margin-left: 3em">一尺八俱直棱八俱直角乘法一千实寸为一实</span>  
<span style="margin-left: 3em">尺一千实分为一实寸则以立方之体再自之耳</span>  
<span style="margin-left: 3em">此为物数均齐推算简易者也</span>  
<span style="margin-left: 2em">几何原本一十一卷详解其理今略引一二如左</span>  
<span style="margin-left: 2em">有法之体二其上者各面俱等盖设一边即知其面</span>  
<span style="margin-left: 2em">其容也其次则对面为平行面或同类之体有公法</span>  
<span style="margin-left: 2em">如角体者是也球亦有法之体盖其径其周其外面</span>  
<span style="margin-left: 2em">其容之比例恒相等第以比例无尽分之数亦属次</span>  
<span style="margin-left: 2em">焉</span>  
<span style="margin-left: 1em">第一体名立面体如正立方斜立方多边立体正立圆</span>  
<span style="margin-left: 2em">体扁圆体<sub class="note-yuan">因其上下为平行面亦属等面</sub>公法以高乘底之积得其</span>  
<span style="margin-left: 2em">容<sub class="note-yuan">高深两名互用</sub>其高之度则垂线也</span>  
<span style="margin-left: 2em">几何原本十二卷七增题曰两平行面内之体或同</span>  
<span style="margin-left: 2em">高两体其比例为体与体若底与底但取同类相求</span>  
<span style="margin-left: 2em">以正高为据不论体势直与不直</span>  
<span style="margin-left: 2em">又本卷三十二题曰同类之体与体<sub class="note-yuan">凡比体者皆以其容积相比</sub></span>  
<span style="margin-left: 2em">为其边与边三加之比例　解曰三加之比例者四</span>  
<span style="margin-left: 2em">几何为同理之连比例则一与二为一加与三为再</span>  
<span style="margin-left: 2em">加与四为三加也<sub class="note-yuan">五卷十界</sub>此云三加者谓体之一与二</span>  
<span style="margin-left: 2em">若其边之一与四也如二　四　八　十六为四几</span>  
<span style="margin-left: 2em">何同理之连比例其首二尾十六为三加之比例则</span>  
<span style="margin-left: 2em">小体之边二大体之边四其小体之容与大体之容</span>  
<span style="margin-left: 2em">若小边之二与大边之十六也</span>  
<span style="margin-left: 3em">系凡同类数体测定一体之容即其容与他体之</span>  
<span style="margin-left: 3em">容为其边与边三加之比例设有立方体其边八</span>  
<span style="margin-left: 3em">其容五一二又设次体其边十二即八与十二再</span>  
<span style="margin-left: 3em">加之得十八三加之得二七<sub class="note-yuan">其超法为一身有半</sub>则初体与</span>  
<span style="margin-left: 3em">次体若八与二十七或用三率法八与二十七若</span>  
<span style="margin-left: 3em">五一二与一七二六或以四率连比例之第二率</span>  
<span style="margin-left: 3em">再自之得数同</span>  
<span style="margin-left: 1em">第二体名角体底广上锐如堆垛锥亭峰之类其法同</span>  
<span style="margin-left: 2em">也几何十二卷七题之系曰同底同高之角体与平</span>  
<span style="margin-left: 2em">行面体<sub class="note-yuan">即同高体</sub>之比例若一与三法曰如方锥之底边</span>  
<span style="margin-left: 2em">设九则底积八十一设高十八以乘底积得一四五</span>  
<span style="margin-left: 2em">八以三为法而一得四八六方锥之容也又如圆堆</span>  
<span style="margin-left: 2em">之底周设十二尺设高五尺则先求周之径得三又</span>  
<span style="margin-left: 2em">十一之九相乘得四五又十一之九以四为法而一</span>  
<span style="margin-left: 2em">得十一又十一之五底积也以高乘之得五七实尺</span>  
<span style="margin-left: 2em">又十一之三以三为法而一得十九又十一之一为</span>  
<span style="margin-left: 2em">圆堆之容<sub class="note-yuan">系凡委粟及倚垣等角体皆求立体之容三除之为角体之容</sub></span>  
<span style="margin-left: 2em">若不知其正高但知其底及棱则先求其正高</span>  
<span style="margin-left: 2em">法曰若棱为偶数如上图得四甲乙丙丁为底之四</span>  
<span style="margin-left: 2em">边各八又半甲丙对角线十二弱戊为角顶戊甲戊</span>  
<span style="margin-left: 2em">乙戊丁戊丙为四棱各十而求次图之中长线戊己</span>  
<span style="margin-left: 2em"><sub class="note-yuan">次图何物如上图戊甲丁丙乙为全体若从戊顶向甲丙对角线平分之为二即所截之两面各成戊甲</sub></span>  
<span style="margin-left: 7em"><sub class="note-yuan">丙三角形甲丙底十二弱戊甲戊丙各十以此三边求中长线戊已即角体之</sub></span>  
<span style="margin-left: 7em"><sub class="note-yuan">高</sub></span>  
<span style="margin-left: 7em">法以半底甲已自之得三十六<sub class="note-yuan">句方</sub>以减</span>  
<span style="margin-left: 7em">腰方一百<sub class="note-yuan">弦方</sub>余六十四<sub class="note-yuan">股方</sub>开方得甲已</span>  
<span style="margin-left: 7em">八为角体之正高余如前</span>  
<span style="margin-left: 7em">若棱为奇数如五底之各边为十二棱</span>  
<span style="margin-left: 7em">之度为二十则先求一面之中长线<sub class="note-yuan">各体</sub></span>  
<span style="margin-left: 7em"><sub class="note-yuan">有底有面有棱底之边随体无定数面则恒各为三边形形之底线即底之一</sub></span>  
<span style="margin-left: 7em"><sub class="note-yuan">边两腰即棱也</sub>依句股法半底边得六<sub class="note-yuan">为句</sub>自之</span>  
<span style="margin-left: 7em">得三十六<sub class="note-yuan">句方</sub>棱度自之得四百<sub class="note-yuan">弦方</sub>相减</span>  
<span style="margin-left: 2em">得三百六十四<sub class="note-yuan">股方</sub>开方得一十九又一十三之一<sub class="note-yuan">即股</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">即面形之中长线</sub></span>  
<span style="margin-left: 2em">次求底形之中长线用正弦法以五<sub class="note-yuan">底之边数</sub>为法三百</span>  
<span style="margin-left: 2em">六十<sub class="note-yuan">全圈之周</sub>为实<sub class="note-yuan">几何论凡有法之形形外可作圈切形之各角形内可作圈切形之各边</sub></span>  
<span style="margin-left: 2em">而一得七十二度为一边之弧半弧之正弦<sub class="note-yuan">即底之半边</sub></span>  
<span style="margin-left: 2em">为五八七七九第一率也<sub class="note-yuan">内</sub>半边之数六为二率<sub class="note-yuan">外</sub></span>  
<span style="margin-left: 2em">半弧之余弦八〇九〇二为三率<sub class="note-yuan">内</sub>算得八又四之</span>  
<span style="margin-left: 2em">一不尽<sub class="note-yuan">外</sub>为五边底形从心所出之中垂线又正弦</span>  
<span style="margin-left: 2em"><sub class="note-yuan">内</sub>与半边<sub class="note-yuan">外</sub>若全数<sub class="note-yuan">内</sub>与半径<sub class="note-yuan">外</sub>得一十又五之一</span>  
<span style="margin-left: 2em">强<sub class="note-yuan">形外圈之半径</sub>两数并得一十八又二十之九强为五边</span>  
<span style="margin-left: 2em">形之中长线</span>  
<span style="margin-left: 2em">次以面形之中长线底形之中长线及一棱之度三</span>  
<span style="margin-left: 2em">线相遇成一三角形<sub class="note-yuan">平分全体所分之两面</sub>有三边之数求中</span>  
<span style="margin-left: 2em">长线得一十六又半不尽为所求元体之正高</span>  
<span style="margin-left: 2em">底之周六十半之得三十以中垂线乘之得五七二</span>  
<span style="margin-left: 2em">又十三之四为底积以正高乘之得九四三八三而</span>  
<span style="margin-left: 2em">一为元体之容得三一四六也</span>  
<span style="margin-left: 2em">若棱之度长短不等则用最长之棱及其对面之中</span>  
<span style="margin-left: 2em">长线求体之正高</span>  
<span style="margin-left: 2em">论曰角体为立面体三之一者何也如正立方体自</span>  
<span style="margin-left: 2em">上而下对角平分之为两堑堵每一堑堵得正立方</span>  
<span style="margin-left: 2em">二之一又于堑堵之两方面自上而下对角平分之</span>  
<span style="margin-left: 2em">成大小二分大者为阳马得堑堵三之二小者为鼈</span>  
<span style="margin-left: 2em">臑得堑堵三之一则一正立方分之为堑堵得二阳</span>  
<span style="margin-left: 2em">马则三鼈臑则六角体者阳马也故得立面体三之</span>  
<span style="margin-left: 2em">一也<sub class="note-yuan">说见九章算</sub></span>  
<span style="margin-left: 2em">又外切圈之半径为句棱数为弦用句股法求股即</span>  
<span style="margin-left: 2em">元体之正高<sub class="note-yuan">此法甚简易但须各棱俱等乃可非公法也</sub></span>  
<span style="margin-left: 2em">截圆角体法有五从其轴平分直截之所截两平面</span>  
<span style="margin-left: 2em">为三角形一也横截之与底平行截面为平圆形二</span>  
<span style="margin-left: 6em">也斜截之与边平行截面为圭窦形<sub class="note-yuan">顶不锐近</sub></span>  
<span style="margin-left: 6em"><sub class="note-yuan">底之两腰稍平行</sub>三也直截之与轴平行截面为</span>  
<span style="margin-left: 6em">陶丘形<sub class="note-yuan">顶曲渐下渐直底两旁为锐角</sub>四也无平行任斜</span>  
<span style="margin-left: 6em">截之截面为椭圆形五也内第一第二第</span>  
<span style="margin-left: 6em">五<sub class="note-yuan">有本</sub>论第三第四其面皆为一直线一曲</span>  
<span style="margin-left: 6em">线两界之面所截体之一分皆为两平面</span>  
<span style="margin-left: 6em">一曲面三界之体亚奇默德备论其量法</span>  
<span style="margin-left: 2em">然非测量所必须又各截面皆有底有轴<sub class="note-yuan">即中长线</sub>有曲</span>  
<span style="margin-left: 2em">线若转轴环行即径线为平底界曲线为曲面界生</span>  
<span style="margin-left: 2em">二界之体其边名曰平曲之边平曲者从曲顶而下</span>  
<span style="margin-left: 2em">渐趋平也若以此体为空体则皆造作燧鉴之法以</span>  
<span style="margin-left: 2em">其浅深为光心之远近亦非测天所用未及详焉</span>  
<span style="margin-left: 1em">第三名斗体古名方窖圆窖等其上下两面不等而相</span>  
<span style="margin-left: 2em">似盖角体之截分也引长其棱即相遇而成全角之</span>  
<span style="margin-left: 2em">体<sub class="note-yuan">凡置斗体大面居下本角体之截分角体欲自立底必在下也其置截分亦然</sub></span>

<span style="margin-left: 3em">轴环行是生扁圆之体椭圆之体或名为卵体非</span>  
<span style="margin-left: 3em">也凡乌卵一端大一端小是为无法之体椭圆体</span>  
<span style="margin-left: 3em">则两端等亚奇默德之第一卷备解此体及分角</span>  
<span style="margin-left: 3em">体之理今略述之</span>  
<span style="margin-left: 2em">凡截圆球生两圆面成两圈若平分之即过心过心</span>  
<span style="margin-left: 2em">之截分恒相等若椭圆体从小径横截之生两平圆</span>  
<span style="margin-left: 2em">面因小径过心故若从其长径直截之生两长圆面</span>  
<span style="margin-left: 2em">即元体之长圆也若横截与小径平行亦成平圆面</span>  
<span style="margin-left: 2em">若斜截之则其面皆不等皆成长圆形</span>  
<span style="margin-left: 1em">凡圆角体其底之径为椭圆体之小径其高半长径则</span>  
<span style="margin-left: 10em">其体之容为椭圆体四之一</span>  
<span style="margin-left: 10em">如甲乙为长径丙丁为小径即</span>  
<span style="margin-left: 10em">丙戊丁甲半椭圆体倍大于甲</span>  
<span style="margin-left: 2em">丙丁角体</span>  
<span style="margin-left: 2em">解曰小径以二十二乘之七而一小径之周也得数</span>  
<span style="margin-left: 2em">以乘小径四而一小径之平圆面积也得数以乘半</span>  
<span style="margin-left: 2em">长径圆柱之容也三而一角体之容也得数四之椭</span>  
<span style="margin-left: 9em">圆半体之容也</span>  
<span style="margin-left: 9em">若截面与小径平行如庚己壬求</span>  
<span style="margin-left: 9em">椭圆分体如庚甲壬之容默德法</span>  
<span style="margin-left: 2em">曰先求庚壬甲角体之容次用三率法己乙<sub class="note-yuan">大分之轴线</sub></span>  
<span style="margin-left: 2em">与戊乙<sub class="note-yuan">半长径线</sub>甲己<sub class="note-yuan">小分之轴线</sub>并若角体甲庚壬之容与</span>  
<span style="margin-left: 2em">椭圆小分庚己壬甲之容</span>  
<span style="margin-left: 9em">若求大分之容先求角体庚壬乙</span>  
<span style="margin-left: 9em">之容次用三率法甲己<sub class="note-yuan">小分之轴线</sub>与</span>  
<span style="margin-left: 9em">甲乙<sub class="note-yuan">长径</sub>戊乙<sub class="note-yuan">半长径</sub>并若角体庚壬</span>  
<span style="margin-left: 2em">乙之容与椭圆大分庚己壬乙之容</span>  
<span style="margin-left: 1em">量无法之体</span>  
<span style="margin-left: 8em">解曰以锡为正方椟各边一尺或五</span>  
<span style="margin-left: 8em">寸若用木则以三和灰涂其罅令不</span>  
<span style="margin-left: 8em">漏实之以水投所量物其中则水溢</span>  
<span style="margin-left: 8em">取出物量水减几何得物之容如减</span>  
<span style="margin-left: 8em">一寸而椟边设一尺则得一百寸为</span>  
<span style="margin-left: 2em">物之容盖各边一尺上面积为一百寸水减一寸则</span>  
<span style="margin-left: 2em">为一百寸若水减不及寸或过焉则量若干分以面</span>  
<span style="margin-left: 2em">积乘之得物之容</span>
