## 崇禎曆書卷之四十三　測量全義卷六

<span style="margin-left: 1em">法原部</span>  
<span style="margin-left: 2em">測量全義第六卷　測體</span>  
<span style="margin-left: 1em">欽差禮部尚書兼翰林院學士協理詹事府事加俸一</span>  
<span style="margin-left: 1em">級徐光啓奉勅督修</span>  
<span style="margin-left: 9em">遠西耶穌會士羅雅谷　　譔</span>  
<span style="margin-left: 9em">同　　會　　龍華民</span>  
<span style="margin-left: 15em">湯若望同　訂</span>  
<span style="margin-left: 9em">訪　　舉　　楊之華</span>  
<span style="margin-left: 15em">黃國楨等　算</span>  
<span style="margin-left: 9em">長　　洲　　孫嗣烈校　梓</span>  
<span style="margin-left: 1em">　<sub class="note-jiao">校：校諱作較今改清刊本署名不同錄之於左</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">西洋新法曆書法原部測量全義第六卷測體</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">明禮部尚書兼翰林院學士協理詹事府事加俸一級</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">徐光啓督修</sub></span>  
<span style="margin-left: 1em">　<sub class="note-yuan">　　　　　　　　　　　　　　　　　　　　孫嗣烈　陳正諫　　　</sub>　　</span>  
<span style="margin-left: 1em"><sub class="note-yuan">　羅雅谷　譔　　修政曆法極西耶穌會士門人楊之華　周士昌　受法　　　　　　　　　　　湯若望訂</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">　　　　　　　　　　　　　　　　　　　　掌乘劉有泰</sub></span>  
<span style="margin-left: 2em">論體<sub class="note-jiao">校：清刊本此前有測量全義六卷標題</sub></span>  
<span style="margin-left: 2em">曆家所重全在測量所當測者略有三事一曰線測</span>  
<span style="margin-left: 2em">其長短二曰面測其長短廣狹三曰體測其長短廣</span>  
<span style="margin-left: 2em">狹厚薄所以測體者何也即如交食一法日與月各</span>  
<span style="margin-left: 2em">有不同心本天各有最高度最高衝度其去人遠近</span>  
<span style="margin-left: 2em">也恆不等其自相去之遠近恆不等人目所見二曜</span>  
<span style="margin-left: 2em">之體大小恆不等若此者必于地體推之故有日與</span>  
<span style="margin-left: 2em">月與地三大之比例<sub class="note-yuan">別有本書</sub>不用此比例何繇知交食</span>  
<span style="margin-left: 2em">之歳月日時地影<sub class="note-yuan">即闇虛</sub>比于月體小大之數幾何乎</span>  
<span style="margin-left: 2em">不因地月之比例何從推日輪之視體幾何大去人</span>  
<span style="margin-left: 2em">幾何遠乎則何繇知日食既之有無金環乎何繇知</span>  
<span style="margin-left: 2em">月食過分之闇虛幾何大乎何繇定食限之幾何時</span>  
<span style="margin-left: 2em">刻乎不知地球之大何繇定東西相去幾何里即交</span>  
<span style="margin-left: 2em">食前後相去幾何時刻南北相去幾何里即日食應</span>  
<span style="margin-left: 2em">有應無有則幾何分秒乎則安得不講于量體之法</span>  
<span style="margin-left: 2em">乎然則測線測面者何也曰體者諸面之積也未能</span>  
<span style="margin-left: 2em">測面安能測體面者又諸線之積也未能測線安能</span>  
<span style="margin-left: 2em">測面又測候七政行度皆以句股弧弦諸法諸法則</span>  
<span style="margin-left: 2em">皆線也諸線之積爲面不知面理則亦不能晰線之</span>  
<span style="margin-left: 2em">體勢故三測爲並重也雖然測天皆曲線曲面也直</span>  
<span style="margin-left: 2em">線與平面何爲乎曰曲線法從直線出也曲面法從</span>  
<span style="margin-left: 2em">平面出也猶圓體法從方體出也故繇線而面而體</span>  
<span style="margin-left: 2em">繇直線而曲線平面而曲面方體而圓體譬之跬步</span>  
<span style="margin-left: 2em">前步未行後步不可得進也是測量之全義也</span>  
<span style="margin-left: 1em">體者面之積或實如金木土石等或空如盤池陶穹等</span>  
<span style="margin-left: 2em">俱同理同法</span>  
<span style="margin-left: 2em">其界爲面面居體之周<sub class="note-yuan">面截面生稜如線遇線生角也又稜爲兩面之共界</sub></span>  
<span style="margin-left: 3em">一面之體如球如卵</span>  
<span style="margin-left: 3em">二面之體如半球半卵圓角圓堆</span>  
<span style="margin-left: 3em">三面之體如剖球卵之一分</span>  
<span style="margin-left: 3em">四面之體如三面角體而四面等</span>  
<span style="margin-left: 5em">即三面角體第因各面俱等故屬四面</span>  
<span style="margin-left: 3em">五面之體如四面角體<sub class="note-yuan">因角體之面無定數故左方不列其名</sub></span>  
<span style="margin-left: 3em">六面之體如立方正立方斜立方</span>  
<span style="margin-left: 3em">八面之體八面俱等</span>  
<span style="margin-left: 3em">十二面之體十二面俱等</span>  
<span style="margin-left: 3em">二十面之體二十面俱等<sub class="note-yuan">自四六八十二二十面之外不能爲等面胥無</sub></span>  
<span style="margin-left: 3em"><sub class="note-yuan">法之體也</sub></span>  
<span style="margin-left: 3em">公量如斗如升皆足爲體之量總之以立方爲本</span>  
<span style="margin-left: 3em">如用尺寸分爲度而一尺之體其長其廣其袤各</span>  
<span style="margin-left: 3em">一尺八俱直稜八俱直角乘法一千實寸爲一實</span>  
<span style="margin-left: 3em">尺一千實分爲一實寸則以立方之體再自之耳</span>  
<span style="margin-left: 3em">此爲物數均齊推算簡易者也</span>  
<span style="margin-left: 2em">幾何原本一十一卷詳解其理今略引一二如左</span>  
<span style="margin-left: 2em">有法之體二其上者各面俱等蓋設一邊即知其面</span>  
<span style="margin-left: 2em">其容也其次則對面爲平行面或同類之體有公法</span>  
<span style="margin-left: 2em">如角體者是也球亦有法之體蓋其徑其周其外面</span>  
<span style="margin-left: 2em">其容之比例恆相等第以比例無盡分之數亦屬次</span>  
<span style="margin-left: 2em">焉</span>  
<span style="margin-left: 1em">第一體名立面體如正立方斜立方多邊立體正立圓</span>  
<span style="margin-left: 2em">體扁圓體<sub class="note-yuan">因其上下爲平行面亦屬等面</sub>公法以高乘底之積得其</span>  
<span style="margin-left: 2em">容<sub class="note-yuan">高深兩名互用</sub>其高之度則垂線也</span>  
<span style="margin-left: 2em">幾何原本十二卷七增題曰兩平行面內之體或同</span>  
<span style="margin-left: 2em">高兩體其比例爲體與體若底與底但取同類相求</span>  
<span style="margin-left: 2em">以正高爲據不論體勢直與不直</span>  
<span style="margin-left: 2em">又本卷三十二題曰同類之體與體<sub class="note-yuan">凡比體者皆以其容積相比</sub></span>  
<span style="margin-left: 2em">爲其邊與邊三加之比例　解曰三加之比例者四</span>  
<span style="margin-left: 2em">幾何爲同理之連比例則一與二爲一加與三爲再</span>  
<span style="margin-left: 2em">加與四爲三加也<sub class="note-yuan">五卷十界</sub>此云三加者謂體之一與二</span>  
<span style="margin-left: 2em">若其邊之一與四也如二　四　八　十六爲四幾</span>  
<span style="margin-left: 2em">何同理之連比例其首二尾十六爲三加之比例則</span>  
<span style="margin-left: 2em">小體之邊二大體之邊四其小體之容與大體之容</span>  
<span style="margin-left: 2em">若小邊之二與大邊之十六也</span>  
<span style="margin-left: 3em">系凡同類數體測定一體之容即其容與他體之</span>  
<span style="margin-left: 3em">容爲其邊與邊三加之比例設有立方體其邊八</span>  
<span style="margin-left: 3em">其容五一二又設次體其邊十二即八與十二再</span>  
<span style="margin-left: 3em">加之得十八三加之得二七<sub class="note-yuan">其超法爲一身有半</sub>則初體與</span>  
<span style="margin-left: 3em">次體若八與二十七或用三率法八與二十七若</span>  
<span style="margin-left: 3em">五一二與一七二六或以四率連比例之第二率</span>  
<span style="margin-left: 3em">再自之得數同</span>  
<span style="margin-left: 1em">第二體名角體底廣上銳如堆垛錐亭峰之類其法同</span>  
<span style="margin-left: 2em">也幾何十二卷七題之系曰同底同高之角體與平</span>  
<span style="margin-left: 2em">行面體<sub class="note-yuan">即同高體</sub>之比例若一與三法曰如方錐之底邊</span>  
<span style="margin-left: 2em">設九則底積八十一設高十八以乘底積得一四五</span>  
<span style="margin-left: 2em">八以三爲法而一得四八六方錐之容也又如圓堆</span>  
<span style="margin-left: 2em">之底周設十二尺設高五尺則先求周之徑得三又</span>  
<span style="margin-left: 2em">十一之九相乘得四五又十一之九以四爲法而一</span>  
<span style="margin-left: 2em">得十一又十一之五底積也以高乘之得五七實尺</span>  
<span style="margin-left: 2em">又十一之三以三爲法而一得十九又十一之一爲</span>  
<span style="margin-left: 2em">圓堆之容<sub class="note-yuan">系凡委粟及倚垣等角體皆求立體之容三除之爲角體之容</sub></span>  
<span style="margin-left: 2em">若不知其正高但知其底及稜則先求其正高</span>  
<span style="margin-left: 2em">法曰若稜爲偶數如上圖得四甲乙丙丁爲底之四</span>  
<span style="margin-left: 2em">邊各八又半甲丙對角線十二弱戊爲角頂戊甲戊</span>  
<span style="margin-left: 2em">乙戊丁戊丙爲四稜各十而求次圖之中長線戊己</span>  
<span style="margin-left: 2em"><sub class="note-yuan">次圖何物如上圖戊甲丁丙乙爲全體若從戊頂向甲丙對角線平分之爲二即所截之兩面各成戊甲</sub></span>  
<span style="margin-left: 7em"><sub class="note-yuan">丙三角形甲丙底十二弱戊甲戊丙各十以此三邊求中長線戊已即角體之</sub></span>  
<span style="margin-left: 7em"><sub class="note-yuan">高</sub></span>  
<span style="margin-left: 7em">法以半底甲已自之得三十六<sub class="note-yuan">句方</sub>以減</span>  
<span style="margin-left: 7em">腰方一百<sub class="note-yuan">弦方</sub>餘六十四<sub class="note-yuan">股方</sub>開方得甲已</span>  
<span style="margin-left: 7em">八爲角體之正高餘如前</span>  
<span style="margin-left: 7em">若稜爲奇數如五底之各邊爲十二稜</span>  
<span style="margin-left: 7em">之度爲二十則先求一面之中長線<sub class="note-yuan">各體</sub></span>  
<span style="margin-left: 7em"><sub class="note-yuan">有底有面有稜底之邊隨體無定數面則恆各爲三邊形形之底線即底之一</sub></span>  
<span style="margin-left: 7em"><sub class="note-yuan">邊兩腰即稜也</sub>依句股法半底邊得六<sub class="note-yuan">爲句</sub>自之</span>  
<span style="margin-left: 7em">得三十六<sub class="note-yuan">句方</sub>稜度自之得四百<sub class="note-yuan">弦方</sub>相減</span>  
<span style="margin-left: 2em">得三百六十四<sub class="note-yuan">股方</sub>開方得一十九又一十三之一<sub class="note-yuan">即股</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">即面形之中長線</sub></span>  
<span style="margin-left: 2em">次求底形之中長線用正弦法以五<sub class="note-yuan">底之邊數</sub>爲法三百</span>  
<span style="margin-left: 2em">六十<sub class="note-yuan">全圈之周</sub>爲實<sub class="note-yuan">幾何論凡有法之形形外可作圈切形之各角形內可作圈切形之各邊</sub></span>  
<span style="margin-left: 2em">而一得七十二度爲一邊之弧半弧之正弦<sub class="note-yuan">即底之半邊</sub></span>  
<span style="margin-left: 2em">爲五八七七九第一率也<sub class="note-yuan">內</sub>半邊之數六爲二率<sub class="note-yuan">外</sub></span>  
<span style="margin-left: 2em">半弧之餘弦八〇九〇二爲三率<sub class="note-yuan">內</sub>算得八又四之</span>  
<span style="margin-left: 2em">一不盡<sub class="note-yuan">外</sub>爲五邊底形從心所出之中垂線又正弦</span>  
<span style="margin-left: 2em"><sub class="note-yuan">內</sub>與半邊<sub class="note-yuan">外</sub>若全數<sub class="note-yuan">內</sub>與半徑<sub class="note-yuan">外</sub>得一十又五之一</span>  
<span style="margin-left: 2em">强<sub class="note-yuan">形外圈之半徑</sub>兩數并得一十八又二十之九强爲五邊</span>  
<span style="margin-left: 2em">形之中長線</span>  
<span style="margin-left: 2em">次以面形之中長線底形之中長線及一稜之度三</span>  
<span style="margin-left: 2em">線相遇成一三角形<sub class="note-yuan">平分全體所分之兩面</sub>有三邊之數求中</span>  
<span style="margin-left: 2em">長線得一十六又半不盡爲所求元體之正高</span>  
<span style="margin-left: 2em">底之周六十半之得三十以中垂線乘之得五七二</span>  
<span style="margin-left: 2em">又十三之四爲底積以正高乘之得九四三八三而</span>  
<span style="margin-left: 2em">一爲元體之容得三一四六也</span>  
<span style="margin-left: 2em">若稜之度長短不等則用最長之稜及其對面之中</span>  
<span style="margin-left: 2em">長線求體之正高</span>  
<span style="margin-left: 2em">論曰角體爲立面體三之一者何也如正立方體自</span>  
<span style="margin-left: 2em">上而下對角平分之爲兩塹堵每一塹堵得正立方</span>  
<span style="margin-left: 2em">二之一又于塹堵之兩方面自上而下對角平分之</span>  
<span style="margin-left: 2em">成大小二分大者爲陽馬得塹堵三之二小者爲鼈</span>  
<span style="margin-left: 2em">臑得塹堵三之一則一正立方分之爲塹堵得二陽</span>  
<span style="margin-left: 2em">馬則三鼈臑則六角體者陽馬也故得立面體三之</span>  
<span style="margin-left: 2em">一也<sub class="note-yuan">說見九章算</sub></span>  
<span style="margin-left: 2em">又外切圈之半徑爲句稜數爲弦用句股法求股即</span>  
<span style="margin-left: 2em">元體之正高<sub class="note-yuan">此法甚簡易但須各稜俱等乃可非公法也</sub></span>  
<span style="margin-left: 2em">截圓角體法有五從其軸平分直截之所截兩平面</span>  
<span style="margin-left: 2em">爲三角形一也横截之與底平行截面爲平圓形二</span>  
<span style="margin-left: 6em">也斜截之與邊平行截面爲圭竇形<sub class="note-yuan">頂不銳近</sub></span>  
<span style="margin-left: 6em"><sub class="note-yuan">底之兩腰稍平行</sub>三也直截之與軸平行截面爲</span>  
<span style="margin-left: 6em">陶丘形<sub class="note-yuan">頂曲漸下漸直底兩旁爲銳角</sub>四也無平行任斜</span>  
<span style="margin-left: 6em">截之截面爲橢圓形五也內第一第二第</span>  
<span style="margin-left: 6em">五<sub class="note-yuan">有本</sub>論第三第四其面皆爲一直線一曲</span>  
<span style="margin-left: 6em">線兩界之面所截體之一分皆爲兩平面</span>  
<span style="margin-left: 6em">一曲面三界之體亞奇默德備論其量法</span>  
<span style="margin-left: 2em">然非測量所必須又各截面皆有底有軸<sub class="note-yuan">即中長線</sub>有曲</span>  
<span style="margin-left: 2em">線若轉軸環行即徑線爲平底界曲線爲曲面界生</span>  
<span style="margin-left: 2em">二界之體其邊名曰平曲之邊平曲者從曲頂而下</span>  
<span style="margin-left: 2em">漸趨平也若以此體爲空體則皆造作燧鑒之法以</span>  
<span style="margin-left: 2em">其淺深爲光心之遠近亦非測天所用未及詳焉</span>

<span style="margin-left: 6em">乘之爲凸面之積次以甲庚半徑乘之三</span>  
<span style="margin-left: 2em">而一爲丁甲辛庚球分之容</span>  
<span style="margin-left: 2em">若截爲直面不過心如甲丁辛之一分而求其容則</span>  
<span style="margin-left: 2em">先求甲丁辛凸面之積以徑乘之六而一爲丁甲辛</span>  
<span style="margin-left: 2em">庚體之容次丁辛截面至心則想丁辛庚圓角體求</span>  
<span style="margin-left: 2em">其容以減丁甲辛庚體之容餘爲丁甲辛球分之容</span>  
<span style="margin-left: 1em">量橢圓體之容</span>  
<span style="margin-left: 3em">橢圓亦有法之體也又次於圓球其爲體則長圓</span>  
<span style="margin-left: 3em">形之長徑爲軸旋轉所生如一點直行生線一線</span>  
<span style="margin-left: 3em">横行生面一面上行生體平圓面以徑爲軸轉軸</span>  
<span style="margin-left: 3em">環行是生圓球長圓面則有二徑一長一短以長</span>  
<span style="margin-left: 3em">徑爲軸轉軸環行是生橢圓之體以短徑爲軸轉</span>  
<span style="margin-left: 3em">軸環行是生扁圓之體橢圓之體或名爲卵體非</span>  
<span style="margin-left: 3em">也凡烏卵一端大一端小是爲無法之體橢圓體</span>  
<span style="margin-left: 3em">則兩端等亞奇默德之第一卷備解此體及分角</span>  
<span style="margin-left: 3em">體之理今略述之</span>  
<span style="margin-left: 2em">凡截圓球生兩圓面成兩圈若平分之即過心過心</span>  
<span style="margin-left: 2em">之截分恆相等若橢圓體從小徑横截之生兩平圓</span>  
<span style="margin-left: 2em">面因小徑過心故若從其長徑直截之生兩長圓面</span>  
<span style="margin-left: 2em">即元體之長圓也若横截與小徑平行亦成平圓面</span>  
<span style="margin-left: 2em">若斜截之則其面皆不等皆成長圓形</span>  
<span style="margin-left: 1em">凡圓角體其底之徑爲橢圓體之小徑其高半長徑則</span>  
<span style="margin-left: 10em">其體之容爲橢圓體四之一</span>  
<span style="margin-left: 10em">如甲乙爲長徑丙丁爲小徑即</span>  
<span style="margin-left: 10em">丙戊丁甲半橢圓體倍大于甲</span>  
<span style="margin-left: 2em">丙丁角體</span>  
<span style="margin-left: 2em">解曰小徑以二十二乘之七而一小徑之周也得數</span>  
<span style="margin-left: 2em">以乘小徑四而一小徑之平圓面積也得數以乘半</span>  
<span style="margin-left: 2em">長徑圓柱之容也三而一角體之容也得數四之橢</span>  
<span style="margin-left: 9em">圓半體之容也</span>  
<span style="margin-left: 9em">若截面與小徑平行如庚己壬求</span>  
<span style="margin-left: 9em">橢圓分體如庚甲壬之容默德法</span>  
<span style="margin-left: 2em">曰先求庚壬甲角體之容次用三率法己乙<sub class="note-yuan">大分之軸線</sub></span>  
<span style="margin-left: 2em">與戊乙<sub class="note-yuan">半長徑線</sub>甲己<sub class="note-yuan">小分之軸線</sub>并若角體甲庚壬之容與</span>  
<span style="margin-left: 2em">橢圓小分庚己壬甲之容</span>  
<span style="margin-left: 9em">若求大分之容先求角體庚壬乙</span>  
<span style="margin-left: 9em">之容次用三率法甲己<sub class="note-yuan">小分之軸線</sub>與</span>  
<span style="margin-left: 9em">甲乙<sub class="note-yuan">長徑</sub>戊乙<sub class="note-yuan">半長徑</sub>并若角體庚壬</span>  
<span style="margin-left: 2em">乙之容與橢圓大分庚己壬乙之容</span>  
<span style="margin-left: 1em">量無法之體</span>  
<span style="margin-left: 8em">解曰以錫爲正方櫝各邊一尺或五</span>  
<span style="margin-left: 8em">寸若用木則以三和灰塗其罅令不</span>  
<span style="margin-left: 8em">漏實之以水投所量物其中則水溢</span>  
<span style="margin-left: 8em">取出物量水減幾何得物之容如減</span>  
<span style="margin-left: 8em">一寸而櫝邊設一尺則得一百寸爲</span>  
<span style="margin-left: 2em">物之容蓋各邊一尺上面積爲一百寸水減一寸則</span>  
<span style="margin-left: 2em">爲一百寸若水減不及寸或過焉則量若干分以面</span>  
<span style="margin-left: 2em">積乘之得物之容</span>
