<span style="margin-left: 1em">寰宇者括天地万物之总名也水附地以为一球凝奠</span>

<span style="margin-left: 2em">指其德也于是因处地球者视日景之不同有五所</span>

<span style="margin-left: 2em">为限<sub class="note-yuan">此限即二极出地之高</sub>其下名为煖带若于午正立表揆</span>

<span style="margin-left: 2em">表无景<sub class="note-yuan">其正居赤道下者春秋二分日中无景过春分则景在南过秋分则景在北</sub>乃太</span>

<span style="margin-left: 2em">现新生之星迨经数载复灭是有生有灭之物也生</span>  
<span style="margin-left: 2em">与灭相代是知必属受坏或曰否盖谓凡物受坏必</span>

<span style="margin-left: 1em">古分天作数层七曜恒星各居其一其诸星丽天如宝</span>  
<span style="margin-left: 2em">饰于钿如节嵌于板层各坚实不相通而相包然新</span>  
<span style="margin-left: 2em">历推测火日金水四曜所行之迹相割相遇交互在</span>  
<span style="margin-left: 2em">上在下是又必不能言星于诸天层各坚实矣</span>  
<span style="margin-left: 1em">或问天行之健恒久不已厥枢焉系斡运谁司有谓天</span>  
<span style="margin-left: 2em">非生物自不能行所行之原必在厥外故每层必有</span>  
<span style="margin-left: 2em">一灵者以运之有谓天下诸物自然之行不过三者</span>  
<span style="margin-left: 2em">其一恒向地心必下至地心而后止乃重物也其一</span>  
<span style="margin-left: 2em">恒欲向天必升至月天而后已乃轻物也其一恒为</span>  
<span style="margin-left: 2em">旋动即天之本行也此其本行自运不息三者之外</span>  
<span style="margin-left: 2em">复有杂乱诸行是名无法之动其详具寰有诠中</span>  
<span style="margin-left: 3em">天道<sub class="note-yuan">第三章</sub></span>  
<span style="margin-left: 1em">天为大寰之公称然非判界立限以为准的则第就此</span>  
<span style="margin-left: 2em">浑沦之体抑何从而推测攷验欤今夫人之蚁附地</span>  
<span style="margin-left: 2em">面仰视穹然者即此浑沦之半耳半恒绕于地下此</span>  
<span style="margin-left: 2em">其见与不见之界诸曜繇是而出入以分明分暗是</span>  
<span style="margin-left: 2em">之曰地平规其一极即天顶其一即底极也然而地</span>  
<span style="margin-left: 2em">平非一各随所居人目四望者即是矣此规剖为四</span>  
<span style="margin-left: 2em">象各限以九十度以纪四方以定地平经度以辨各</span>  
<span style="margin-left: 2em">曜出入方位自地平上至天顶多立距等圈即其纬</span>  
<span style="margin-left: 2em">度此则可算各曜渐升之度可稽北极出地若干可</span>  
<span style="margin-left: 2em">审各曜出地离赤道为几何纬度</span>  
<span style="margin-left: 1em">古曰天行健又曰天左旋知其旋之健则验南北必有</span>  
<span style="margin-left: 2em">其极矣极者非星乃天体永久无动二点所以周天</span>  
<span style="margin-left: 2em">倚为环动之枢也一极出地必一极入地其出入之</span>  
<span style="margin-left: 2em">度惟均所谓极星者盖指其最切近于极之某星以</span>  
<span style="margin-left: 2em">命耳二极相距正中之界判一规谓之赤道平分天</span>  
<span style="margin-left: 2em">体为南向北向二方南者为外为阳北者为内为阴</span>  
<span style="margin-left: 2em">此规则三百六十赋其度十有二以分其辰九十六</span>  
<span style="margin-left: 2em">以析其刻其亘于天中也终古不易推步者毕赖之</span>  
<span style="margin-left: 2em">为准则故天体一日一周之运于是焉纪昼夜刻分</span>  
<span style="margin-left: 2em">永短于是焉定黄道出入广狭于是齐春秋二分晷</span>  
<span style="margin-left: 2em">景于是限南北纬算起于是天下地员度于是此皆</span>  
<span style="margin-left: 2em">其为用也又谓赤道有二者一缘相交相割于黄道</span>  
<span style="margin-left: 2em">而恒动一缘恒不动而以定各方时刻盖即指其二</span>  
<span style="margin-left: 2em">用岂果实有二道欤至于赤道正居天顶之所则两</span>  
<span style="margin-left: 2em">极相合于地平若赤道斜交地平之所则极出地度</span>  
<span style="margin-left: 2em">数即为赤道距天顶之度矣其经度即过极圈纬度</span>  
<span style="margin-left: 2em">即距等侣圈也</span>  
<span style="margin-left: 1em">太阳一岁所周轨迹旋以成规是名黄道此规斜络于</span>  
<span style="margin-left: 2em">赤道其半在南最南界为冬至其半在北最北界为</span>  
<span style="margin-left: 2em">夏至二道两交两点为春秋分以故四平分为象限</span>  
<span style="margin-left: 2em">限各九十度者亦即两分两至四正之限也亦总计</span>  
<span style="margin-left: 2em">为三百六十度又十二剖之为宫宫各三十度<sub class="note-yuan">十二宫云</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">者中历曰星纪丑宫玄枵子宫娵訾亥宫降娄戌宫大梁酉宫实沈申宫鹑首未宫鹑火午宫鹑尾巳宫</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">寿星辰宫大火卯宫析木寅宫西历曰磨羯宝瓶双鱼白羊金牛双兄巨蟹狮子室女天秤天蝎人马</sub></span>  
<span style="margin-left: 2em">二十四剖之为节气气各十五度七十二剖之为候</span>  
<span style="margin-left: 2em">三候仍一气盖用以节七曜列宿之行用以审日月</span>  
<span style="margin-left: 2em">交食之限是规因与赤道斜交则必有本极谓之黄</span>  
<span style="margin-left: 2em">极乃恒星及太阳本行之枢然而二道最远之距<sub class="note-yuan">即南</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">至北至之距也</sub>今古不同上古较今多数十分今测定为天</span>  
<span style="margin-left: 2em">度二十三度三十一分三十秒</span>  
<span style="margin-left: 1em">太阳一日旋天一周见于东方渐升至高为正午此地</span>  
<span style="margin-left: 2em">平以上东半昼分也午正后西半昼分即谓之降他</span>  
<span style="margin-left: 2em">曜皆然此升降度之中界天官家立有一规名为子</span>  
<span style="margin-left: 2em">午规诸曜际此谓为在子在午是规必过赤道二极</span>  
<span style="margin-left: 2em">暨地平二极其偕赤道地平而交为直角也恒不动</span>  
<span style="margin-left: 2em">然人于地面南北迁此规惟一若东西迁则随在各</span>  
<span style="margin-left: 2em">异与地平等故二规亦谓之私规焉</span>  
<span style="margin-left: 1em">以上黄赤二道地平子午之四大规为用甚大测候者</span>  
<span style="margin-left: 2em">欲求七政行度会望等一切诸法咸必所需苟于此</span>  
<span style="margin-left: 2em">不详明终未可与言象数也</span>  
<span style="margin-left: 1em">历家欲晰诸道之相交及其行度故创置多规悉为赋</span>  
<span style="margin-left: 2em">度分宫以期不爽至最备者则莫浑仪若矣其上加</span>  
<span style="margin-left: 2em">日月二道以代本行之天或有更制为简平浑盖等</span>  
<span style="margin-left: 2em">平面诸仪虽厥规制各殊然其求合天行则一也</span>  
<span style="margin-left: 1em">周天诸道虽借立多规以验之然非第定住一线乃一</span>  
<span style="margin-left: 2em">平圆面也义同剖瓜而再合其两相分合之内必为</span>  
<span style="margin-left: 2em">平圆一面天道亦复如是故凡某曜在某面上即谓</span>  
<span style="margin-left: 2em">之在某道云</span>  
<span style="margin-left: 3em">日轨<sub class="note-yuan">第四章</sub></span>  
<span style="margin-left: 1em">太阳之行终岁不外黄道左右虽其或上或下皆在黄</span>  
<span style="margin-left: 2em">道一圆面内然其实行非均冬有嬴而夏有缩至算</span>  
<span style="margin-left: 2em">平行则中历为一度<sub class="note-yuan">日度也</sub>新历为五十九分八秒有</span>  
<span style="margin-left: 2em">奇<sub class="note-yuan">天度也</sub>嬴行云者乃较平行为多为疾也冬月一日</span>  
<span style="margin-left: 2em">旧法为百五分新为一度一分有奇<sub class="note-yuan">旧以百分为度新以六十分为</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">度</sub>二数相通则旧法较之天度余一分弱矣缩行云</span>  
<span style="margin-left: 2em">者迟而不及平行度也夏月一日旧法为九十五分</span>  
<span style="margin-left: 2em">新为五十七分有奇是则新旧之算不同若此至若</span>  
<span style="margin-left: 2em">春秋二分之近必有二日平视二行相均此外两行</span>  
<span style="margin-left: 2em">之较必且日日不等因而有加分减分是即所谓加</span>  
<span style="margin-left: 2em">减差也</span>  
<span style="margin-left: 1em">嬴缩疾迟二行旧历不明其所以然新历之本解曰黄</span>  
<span style="margin-left: 2em">道圈与日轮天不同心<sub class="note-yuan">黄道之心即地球心也</sub>其行必距地近</span>  
<span style="margin-left: 2em">远不等故在近而行见疾在远而行见迟理所固然</span>  
<span style="margin-left: 2em">者今太阳之体冬月见大其去地近故其行疾夏月</span>  
<span style="margin-left: 2em">见小其去地远故其行迟耳</span>  
<span style="margin-left: 1em">黄道规与太阳本行天不同心者此新法所绍明也其</span>  
<span style="margin-left: 2em">用最广诸曜纷杂异行非此莫得而齐之又匪特太</span>  
<span style="margin-left: 2em">阳也太阴五纬莫不各有本行此太阳本行天距地</span>  
<span style="margin-left: 2em">极远之点谓为最高极近之点谓为最高冲<sub class="note-yuan">亦谓最卑</sub>夫</span>  
<span style="margin-left: 2em">此二点者为嬴缩二行之界古法于冬夏二至恒谓</span>  
<span style="margin-left: 2em">在其一点然而非也按古今诸测皆自不齐古测在</span>  
<span style="margin-left: 2em">夏至前数度今则在后六度矣于此推之因知其一</span>  
<span style="margin-left: 2em">年之内有自行四十五秒焉</span>  
<span style="margin-left: 1em">步太阳高远之法以地半径为度约得地半径者一千</span>  
<span style="margin-left: 2em">一百八十变里为一千六百八十七万八千七百有</span>  
<span style="margin-left: 2em">奇此则古今屡测屡算所得即少有差不过千分之</span>  
<span style="margin-left: 2em">一二而已</span>  
<span style="margin-left: 1em">日体之大倍于地球一百五十一求其容积得一千九</span>  
<span style="margin-left: 2em">百五十万一千二百六十五亿三千三百四十六万</span>  
<span style="margin-left: 2em">九千五百三十里<sub class="note-yuan">测体里度乃实里也六面之体面各一里</sub>或疑人目所</span>  
<span style="margin-left: 2em">覩径不盈尺聆此觉异不知其距地如许之远苟非</span>  
<span style="margin-left: 2em">如许其大则视径奚至若是哉矧此乃西历屡代实</span>  
<span style="margin-left: 2em">测推算以理求得故能于一切交食等法密合否则</span>  
<span style="margin-left: 2em">何以能测算不紊乎</span>  
<span style="margin-left: 1em">历家期于推步无爽故太阳分有平视二行视行即人</span>  
<span style="margin-left: 2em">所测平行则立算之根也两行之较逐日不合而大</span>  
<span style="margin-left: 2em">差之数古曰二日零四十刻有奇今新历定为二日</span>  
<span style="margin-left: 2em">零八刻<sub class="note-yuan">或二度三分</sub>两历算法不同大统以三差法算西</span>  
<span style="margin-left: 2em">法用天弧以三角形算</span>  
<span style="margin-left: 1em">太阳入某宫次节气也以平行实行亦有二算若算平</span>  
<span style="margin-left: 2em">行则十五日二十一刻有奇为一节气乃一岁内二</span>  
<span style="margin-left: 2em">十四平分之一也用躔度之日以算<sub class="note-yuan">即实行</sub>则冬夏不</span>  
<span style="margin-left: 2em">齐冬之一节气为十四日八十四刻有奇夏之一节</span>  
<span style="margin-left: 2em">气为十五日七十二刻有奇是即繇于夏迟而冬疾</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 1em">太阳为万光之原太阴经纬诸星之光咸禀受焉然以</span>  
<span style="margin-left: 2em">远镜窥日轨之面上有黑子其多寡大小不等或时</span>  
<span style="margin-left: 2em">而行于太阳东西径上十四日而尽以其行在日体</span>  
<span style="margin-left: 2em">之外或疑以为小星然亦究竟不知何物也</span>  
<span style="margin-left: 3em">年月<sub class="note-yuan">第五章</sub></span>  
<span style="margin-left: 1em">纪年者何太阳随列宿东行旋天一周之期也太阳行</span>  
<span style="margin-left: 2em">界有二其一乃从某宫次度分行天周而复于元度</span>  
<span style="margin-left: 2em">其数为三百六十五日二十四刻二十五分然此数</span>  
<span style="margin-left: 2em">家各不等新法所定小余二十一分有奇今考授时</span>  
<span style="margin-left: 2em">历所用但云百年减一分似与新历相近而授时又</span>  
<span style="margin-left: 2em">莫详其故或有用小余二十八分古或用三十六分</span>  
<span style="margin-left: 2em">则皆于天不合矣其一乃太阳会于列宿天之某星</span>  
<span style="margin-left: 2em">行天周而复与元星会第其星每岁有本行是又当</span>  
<span style="margin-left: 2em">加其本行以定岁古法谓为一分半<sub class="note-yuan">百分一度</sub>新法定为</span>  
<span style="margin-left: 2em">五十一秒<sub class="note-yuan">六十分一度</sub>斯二界者即推步家所谓岁实周</span>  
<span style="margin-left: 2em">岁岁差也</span>  
<span style="margin-left: 1em">日历之纪年惟以全日准算不用小余或以太阳十二</span>  
<span style="margin-left: 2em">次会合太阴为岁即三百五十四日也此则每二年</span>  
<span style="margin-left: 2em">三年而闰一月或有以太阳周十二宫次为岁即三</span>  
<span style="margin-left: 2em">百六十五日也此则每四年而闰一日是盖各因各</span>  
<span style="margin-left: 2em">国之本风耳</span>  
<span style="margin-left: 1em">纪月有二或因太阴会朔一次以定所谓太阴之月或</span>  
<span style="margin-left: 2em">因太阳行一宫次以定所谓太阳之月然皆十二分</span>  
<span style="margin-left: 2em">年之一分也</span>  
<span style="margin-left: 1em">一月之终分有大尽小尽者试如初朔子正苟第二朔</span>  
<span style="margin-left: 2em">过二十九日外不能及于第三十日子正则谓之小</span>  
<span style="margin-left: 2em">其过于子正则谓之大大则二朔同一天干小则不</span>  
<span style="margin-left: 2em">同矣故有三十日弱时刻不及者历家不得名大或</span>  
<span style="margin-left: 2em">二十九日强而时刻已逾者历家仍不得名小也然</span>  
<span style="margin-left: 2em">宇内之地度不同而月之小大天下又莫能律以一</span>  
<span style="margin-left: 2em">法何者假设京师第二朔在子初二刻是未到子正</span>  
<span style="margin-left: 2em">其月为小若西安则此朔已在子正初刻是当为大</span>  
<span style="margin-left: 2em">尽矣地度愈远时刻愈差故曰天下不可律以一法</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 1em">上古至今三统各异然则岁首悉繇于人所定者也大</span>  
<span style="margin-left: 2em">统建寅以立春前后近朔为岁首又二十四节气其</span>  
<span style="margin-left: 2em">半命为各月之节其半命为各月之中言中者太阳</span>  
<span style="margin-left: 2em">躔某节气必定于是月而不移易者也如冬至必在</span>  
<span style="margin-left: 2em">十一月中若大雪则或在十月或在十一月不齐矣</span>  
<span style="margin-left: 2em">然近大雪之朔必为十一月朔</span>  
<span style="margin-left: 1em">余气归终积而为闰是闰月者缘太阳躔一宫之时与</span>  
<span style="margin-left: 2em">月会合二次以成者也其为月也因无中气故谓之</span>  
<span style="margin-left: 2em">闰如冬至是十一月中在其月三十日大寒是十二</span>  
<span style="margin-left: 2em">月中在其月初一日则此闰十一月必无中气矣</span>  
<span style="margin-left: 1em">古法置闰用平节气新法用太阳所躔天度节气故闰</span>  
<span style="margin-left: 2em">有合有异或前后一月不等</span>  
<span style="margin-left: 3em">昼夜晨昏<sub class="note-yuan">第六章</sub></span>  
<span style="margin-left: 1em">太阳随宗动天西行一周而复于元界谓之日此其繇</span>  
<span style="margin-left: 2em">东渐升过午西降至子而冲亦甚循环无端矣苟非</span>  
<span style="margin-left: 2em">定一界曷据以推算乎或谓起于东者世俗云然乃</span>  
<span style="margin-left: 2em">古历亦有用自地平起算以定月食之候所谓晓望</span>  
<span style="margin-left: 2em">是也若星家恒用则以太阳或在子或在午以起算</span>  
<span style="margin-left: 1em">论从子午起算之日则一岁内之实行度分日日不等</span>  
<span style="margin-left: 2em">其差较得一刻余厥有二故一缘黄道夏迟冬疾差</span>  
<span style="margin-left: 2em">四分余一缘黄赤二道广狭不同距则率度必不同</span>  
<span style="margin-left: 2em">分也</span>  
<span style="margin-left: 1em">昼云者太阳在地平上人目可得而覩也其渐隐于地</span>  
<span style="margin-left: 2em">平之下人目无见则谓之夜是全繇于人居各所以</span>  
<span style="margin-left: 2em">分故随方<sub class="note-yuan">极出地若干</sub>随时<sub class="note-yuan">太阳躔某宫</sub>依法皆可以算昼夜</span>  
<span style="margin-left: 2em">刻分然推算者恒较短而目所见者恒较长恒差数</span>  
<span style="margin-left: 2em">刻其故云何盖太阳体大算法皆以体心出地平为</span>  
<span style="margin-left: 2em">昼始而人目第以见日轮即谓为昼始矣其故一日</span>  
<span style="margin-left: 2em">之出没升降度有斜有正其故二近于地平各曜出</span>  
<span style="margin-left: 2em">没之界受清蒙气变其故三有此多故所以恒差若</span>

<span style="margin-left: 2em">皆以其平行在同度也中历谓为经朔曰实食乃用</span>

<span style="margin-left: 2em">类者一与二较或有差至五六十刻若二与三较则</span>  
<span style="margin-left: 2em">所差不过七八刻而已</span>  
<span style="margin-left: 1em">日月二体视各半度然因距地有远有近所以时或见</span>  
<span style="margin-left: 2em">大见小互有相胜之日南北二方食顷亦差北方日</span>

<span style="margin-left: 2em">小迨至月所则其径为天之一度半焉</span>

<span style="margin-left: 3em">三余<sub class="note-yuan">第十四章</sub></span>  
<span style="margin-left: 1em">三余者何罗睺计都月孛也古加紫炁名为四余亦谓</span>  
<span style="margin-left: 2em">之四隐曜然详求天行实无紫炁且绝无当于推步</span>  
<span style="margin-left: 2em">之术故新法弃而不录第取三余</span>  
<span style="margin-left: 1em">罗睺即白道之正交乃月道自南溯北以交于黄道之</span>  
<span style="margin-left: 2em">一点此点有本行每日左旋约三分有奇而罗睺正</span>  
<span style="margin-left: 2em">对之点即计都矣盖两规斜络其两交之二处必正</span>

<span style="margin-left: 3em">历学改革<sub class="note-yuan">第十五章</sub></span>  
<span style="margin-left: 1em">星官之学有法有用法者测各重天之运行体势以审</span>  
<span style="margin-left: 2em">诸曜出入隐现所在以求本行迹道以定准则也用</span>  
<span style="margin-left: 2em">者是取法所测定分数随方随时以推步夫日月五</span>  
<span style="margin-left: 2em">星次舍冲照交食凌犯顺逆等情也斯二家惟立法</span>  
<span style="margin-left: 2em">最难故谬以纤毫必差之千里则用之者何所藉为</span>

<span style="margin-left: 2em">一时讵得施行久远后惟授时历庶乎称善然亦本</span>  
<span style="margin-left: 2em">于大明今大统则悉以授时为本而移岁差及四应</span>

<span style="margin-left: 2em">归同会通成书务求明简或亦可以质诸来祀顾何</span>

<span style="margin-left: 3em">历元<sub class="note-yuan">第十六章</sub></span>  
<span style="margin-left: 1em">历元者乃以诸曜之平行同时而求各所历家因之用</span>  
<span style="margin-left: 2em">为起算之根也今夫邈矣寰究旋绕无际苟欲繇往</span>  
<span style="margin-left: 2em">詧来必须预定一点为界斯界分有三缘一为某宫</span>  
<span style="margin-left: 2em">次一为某方域一为某时刻如古法以京师太阳躔</span>  
<span style="margin-left: 2em">冬至时刻为界则日月之气闰转交四应列宿五星</span>  
<span style="margin-left: 2em">之合应历应等数以及一切撰造悉于此时定之以</span>  
<span style="margin-left: 2em">为筹䇲之限今大统历以至元辛巳己未日丑初二</span>  
<span style="margin-left: 2em">刻为历元嗣后每年加岁实闰余等平行之策或逆</span>  
<span style="margin-left: 2em">推前而减之以定日历</span>  
<span style="margin-left: 1em">新法以崇祯元年戊辰前太阳过天正冬至后第一子</span>  
<span style="margin-left: 2em">正为历元其日干则己卯也斯时太阳躔星纪宫初</span>  
<span style="margin-left: 2em">度五十三分太阴在六宫五十分他曜皆以此时定</span>  
<span style="margin-left: 2em">准不用冬至时刻缘冬至有正有平得其真率最难</span>  
<span style="margin-left: 2em">也夫历元既为诸算借资根本其或稍有舛忒则诸</span>  
<span style="margin-left: 2em">行讵能求合欤矧诸曜终岁细行莫不皆以子正起</span>  
<span style="margin-left: 2em">算又安用冬至时刻为哉</span>  
<span style="margin-left: 1em">上言欲定历元预须审某方域者盖各方一年冬至非</span>  
<span style="margin-left: 2em">皆在一时也如京师在卯正向东之地为辰愈东必</span>  
<span style="margin-left: 2em">且为巳为午向西之地为寅愈西必且为丑为子矣</span>  
<span style="margin-left: 2em">故此方所定历元或欲算彼方必先加减若干然后</span>  
<span style="margin-left: 2em">可用今回回历所用历元乃定于西域马可者亦以</span>  
<span style="margin-left: 2em">加减推之<sub class="note-yuan">其年号曰阿剌必考之则在中华隋开皇九年云</sub></span>  
<span style="margin-left: 3em">历算<sub class="note-yuan">第十七章</sub></span>  
<span style="margin-left: 1em">条地经天托基九九此所以数学而居于六艺之一也</span>  
<span style="margin-left: 2em">若夫历家之算无假淹贯九章第加减乘除开方五</span>  
<span style="margin-left: 2em">法而已故西古有言握算不深休蹈历学之门然数</span>  
<span style="margin-left: 2em">之为技亦綦琐矣兹不曰广而曰深者盖谓惟求五</span>  
<span style="margin-left: 2em">法精熟耳其为术也古用觚棱近便珠算西法第资</span>  
<span style="margin-left: 2em">毫颖今复有算筹之创其简捷则更倍于畴昔诸术</span>  
<span style="margin-left: 2em">矣</span>  
<span style="margin-left: 1em">古以周天判为三百六十五度四分度之一所谓日度</span>  
<span style="margin-left: 2em">而以太阳之行每日为一度度析百分分析百秒然</span>  
<span style="margin-left: 2em">又均之分为宫次气候第是法者因用奇零欲求齐</span>  
<span style="margin-left: 2em">一必棼绪难领且天度乃岁实之日分中历所用岁</span>  
<span style="margin-left: 2em">实家各多寡不等此其分天非为一定乃游移之法</span>  
<span style="margin-left: 2em">也何可定诸曜之行乎今新法分周天历度也则以</span>  
<span style="margin-left: 2em">三百六十平剖之所谓天度度析六十分分析六十</span>  
<span style="margin-left: 2em">秒盖六十者半之则为三十三之一则二十四之一</span>  
<span style="margin-left: 2em">则十五余任剖析皆为自然而然之分故往古历纪</span>  
<span style="margin-left: 2em">未始繁载第于其测得者曰某度几何分之一而已</span>  
<span style="margin-left: 2em">此其错综离合庶于筹䇲者无甚舛忒也</span>  
<span style="margin-left: 1em">加法者是以类相比并多分而成各类之全也<sub class="note-yuan">类者如度从度</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">分从分秒从秒以及时刻从时刻之等</sub>故须知定位及进位如算历法</span>  
<span style="margin-left: 2em">则以积六十秒为一分积六十分为一度秒进于分</span>  
<span style="margin-left: 2em">之位分进于度之位而与他度分秒并之若加时刻</span>  
<span style="margin-left: 2em">则以十五分进一刻四刻进一时二十四时进一日</span>  
<span style="margin-left: 2em">二十四者乃西法所谓小时也</span>  
<span style="margin-left: 1em">减与加反用稽所余其法先须较数多寡多中减寡理</span>  
<span style="margin-left: 2em">数易明若干少内减多必当立借法以通其变借法</span>  
<span style="margin-left: 2em">者如借度化分借分化秒为本类以用之</span>  
<span style="margin-left: 1em">乘法乃九九互积之义其术有实有法凡单数乘度分</span>  
<span style="margin-left: 2em">秒则不变其位若度乘度复生多度分乘分以生秒</span>

<span style="margin-left: 1em">除云者以少剖多分分除减意也为法有二或以单数</span>  
<span style="margin-left: 2em">商除亦不变位苟分度或不尽即以余度化为分以</span>  
<span style="margin-left: 2em">除之算秒算分莫不如是</span>  
<span style="margin-left: 1em">或有用三率法即先以化法化之得其微数如法握算</span>  
<span style="margin-left: 2em">然后再受为度若开方者亦以化法求其微数用筹</span>  
<span style="margin-left: 2em">乘除亦与常法无甚大异焉</span>  
<span style="margin-left: 1em">新历任欲算某星经纬及交食等项约有二法其一取</span>  
<span style="margin-left: 2em">所图各宿曜本行规之半径并其所设某日平行<sub class="note-yuan">即本</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">圈上之弧</sub>用诸三角形法推演始可得其经纬细行或交</span>  
<span style="margin-left: 2em">食之分数时刻此术最为缜密苟能精心详审则诸</span>

<span style="margin-left: 2em">纯熟者必觉厌倦乘之也其二以先所推定诸表握</span>

<span style="margin-left: 2em">简表二三次以求即能得其宫度非若中历之必须</span>

<span style="margin-left: 1em">割圆亦属古法盖人用圭表等测天天圜而圭表直直</span>  
<span style="margin-left: 2em">与圜为异类讵能合欤此所以立有割圆法也乃谓</span>

<span style="margin-left: 3em">测太阳<sub class="note-yuan">第二十一章</sub></span>

<span style="margin-left: 2em">差厘数而辄乖违数十刻者究竟孰疏远而孰详密</span>  
<span style="margin-left: 2em">哉且新法用仪逐日可测太阳实躔宫度分秒古法</span>  
<span style="margin-left: 2em">绝未之及岂其果于二至之外推步之术遂穷欤总</span>  
<span style="margin-left: 2em">缘其莫能甄发天路之本原耳</span>

<span style="margin-left: 2em">夏行黄道四十五度历四十六日十刻十分又从立</span>

<span style="margin-left: 3em">测恒星<sub class="note-yuan">第二十二章</sub></span>

<span style="margin-left: 2em">七政惟日度有常而恒星之经纬易定其他六曜皆</span>

<span style="margin-left: 2em"><sub class="note-yuan">百余年一周天</sub>然其距本极纬度则亘古无变其二因赤道</span>

<span style="margin-left: 2em">分复有相较此所以测月之法于七政中尤为不易</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 1em">新法测月用三会食推算其法以食甚正对太阳即可</span>  
<span style="margin-left: 2em">简知月之经度因食甚分秒又可知距交若干因各</span>  
<span style="margin-left: 2em">食之中积时日刻数不等乃知天上所行度分亦不</span>

<span style="margin-left: 2em">如欲免测验即再择三会食重算而又可得之</span>  
<span style="margin-left: 1em">测太阴二弦经度亦有本法盖弦者乃太阴实距太阳</span>  
<span style="margin-left: 2em">或东或西九十度即周天四分之一也以本仪测定</span>  
<span style="margin-left: 2em">次用法算其平行然其加分推算者与测候者殊不</span>

<span style="margin-left: 3em">测五纬<sub class="note-yuan">第二十四章</sub></span>

<span style="margin-left: 2em">岁行圈之最高而冲之即在其最低其于实行为合</span>

<span style="margin-left: 3em">测时晷<sub class="note-yuan">第二十五章</sub></span>
