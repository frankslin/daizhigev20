<span style="margin-left: 2em">歷引<sub class="note-jiao">校：據奎章閣藏明刊本校錄</sub></span>  
<span style="margin-left: 3em">歷引序</span>  
<span style="margin-left: 2em">乾象昭垂匪數術莫稽其隱賾陰陽通變惟理道可</span>

<span style="margin-left: 3em">寰宇序次<sub class="note-yuan">第一章</sub></span>  
<span style="margin-left: 1em">寰宇者括天地萬物之總名也水附地以爲一球凝奠</span>  
<span style="margin-left: 2em">於中天爲大圜包其外地之周則氣充溢之理學乃</span>  
<span style="margin-left: 2em">謂氣以上有元火切於月天內界厥質清純非人目</span>  
<span style="margin-left: 2em">所可見蓋理推之如是也地在寰宇之中常靜不動</span>  
<span style="margin-left: 2em">與天相較政若稊米之于喬岳耳其形渾圓即突者</span>  
<span style="margin-left: 2em">爲丘陵坳者爲谿谷仍無損其萬分之一試設大圓</span>  
<span style="margin-left: 2em">徑數十丈加以芥子損之毫末不害其圓古謂方者</span>  
<span style="margin-left: 2em">指其德也于是因處地球者視日景之不同有五所</span>  
<span style="margin-left: 2em">以分爲五帶其中則自赤道南北各以二十三度半</span>  
<span style="margin-left: 2em">爲限<sub class="note-yuan">此限即二極出地之高</sub>其下名爲煖帶若于午正立表揆</span>  
<span style="margin-left: 2em">日測景必自射南射北然於一歲之內必有二日其</span>  
<span style="margin-left: 2em">表無景<sub class="note-yuan">其正居赤道下者春秋二分日中無景過春分則景在南過秋分則景在北</sub>乃太</span>  
<span style="margin-left: 2em">陽正過其天頂之日也此帶惟一又於其南其北每</span>  
<span style="margin-left: 2em">自二十三度半外各截至六十六度半爲限其下名</span>  
<span style="margin-left: 2em">爲溫帶居南者表景恆射南居北者表景恆射北歲</span>  
<span style="margin-left: 2em">內惟有一日其景極短然太陽則不經其天頂矣此</span>  
<span style="margin-left: 2em">帶有二上三帶者是皆太陽每日有出有入者也又</span>  
<span style="margin-left: 2em">於南北二方自六十六度半外各至極止名爲冷帶</span>  
<span style="margin-left: 2em">其下或表景周圍旋轉乃有日太陽繞其地恆見又</span>  
<span style="margin-left: 2em">有日太陽恆隱其隱見之候久至半年數月不等此</span>  
<span style="margin-left: 2em">帶亦二是則大地共分五帶之異也</span>  
<span style="margin-left: 1em">距赤道之南北二方<sub class="note-jiao">校：和刻本作赤道距南距北二方</sub>必其氣候相反</span>  
<span style="margin-left: 2em">如太陽躔星紀宮向北之方爲冬至向南之方爲夏</span>  
<span style="margin-left: 2em">至其春其秋莫不皆然</span>  
<span style="margin-left: 1em">地球因人所止以天頂而分有東西南北然亦界爲三</span>  
<span style="margin-left: 2em">百六十度以期合于天行東西謂之經南北謂之緯</span>  
<span style="margin-left: 2em">求經度者於赤道上測之求緯度則測于子午線上</span>  
<span style="margin-left: 2em">故隨方用儀測極出地高即得其緯度因月食以此</span>  
<span style="margin-left: 2em">方食時與彼方食時相較其經度即可推得矣<sub class="note-yuan">以地驗天</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">每東西離三十度而差一時凡食時在前則定某地在西或食時在後則定某地在東如京師月食在卯</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">正二刻西安府則在寅初初刻兩相較而差二刻因知天度之差七度半也</sub>第欲測東西</span>  
<span style="margin-left: 2em">先該定一所以爲起界<sub class="note-yuan">不言南北者有極爲其定界也</sub>新曆悉以京</span>  
<span style="margin-left: 2em">師爲本至若別方因未親測第據輿圖以定其經緯</span>  
<span style="margin-left: 2em">耳</span>  
<span style="margin-left: 1em">曆家不明各方經緯度則無以知幅𢄙相距之數亦孰</span>  
<span style="margin-left: 2em">從而推步太陽節氣與五星經度凌犯及各方之交</span>  
<span style="margin-left: 2em">食時刻併日食分數乎<sub class="note-yuan">日食則南北東西各不同分月食分數皆同第東西不同</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">時耳</sub>又難以證古測今測之歲實至若日出日八晝夜</span>  
<span style="margin-left: 2em">永短咸以地球緯度爲本而定之</span>  
<span style="margin-left: 1em">欲明地球之廣先當明經緯一度爲幾何里今約定二</span>  
<span style="margin-left: 2em">百五十里而差一度乘以周地之數得九萬里求其</span>  
<span style="margin-left: 2em">徑爲二萬八千六百四十八里其環周之面爲二十</span>  
<span style="margin-left: 2em">五億七千四百七十二萬里云</span>  
<span style="margin-left: 1em">論氣及火高厚即自地面以至月天內界也因測太陰</span>  
<span style="margin-left: 2em">距地近遠以知之依法推得月最近於地<sub class="note-yuan">即月天內面</sub>爲</span>  
<span style="margin-left: 2em">七十二萬九千五百里若于此中求氣與火相分之</span>  
<span style="margin-left: 2em">際亦非擬議可及矣</span>  
<span style="margin-left: 1em">古者謂月天之上爲辰星爲太白爲太陽熒惑歲星填</span>  
<span style="margin-left: 2em">星列宿宗動諸天其外尚有三層共十二層如蔥白</span>  
<span style="margin-left: 2em">之層相包裹也然列星以上無復象緯可測曆家以</span>  
<span style="margin-left: 2em">測候爲本務于無測奚求哉故亦不論</span>  
<span style="margin-left: 3em">天體<sub class="note-yuan">第二章</sub></span>  
<span style="margin-left: 1em">天之高也雖屬有極然非人目能覩曷克詳其體質哉</span>  
<span style="margin-left: 2em">理學相傳謂天乃透光之體如玻璃如水晶極其淸</span>  
<span style="margin-left: 2em">瑩純粹無雜其光明美好非世物可比擬古有謂天</span>  
<span style="margin-left: 2em">爲第五元行然實非也乃天體不入雜物之質烏可</span>  
<span style="margin-left: 2em">謂爲元行乎有問天體能壞否或曰能壞蓋謂時乎</span>  
<span style="margin-left: 2em">現新生之星迨經數載復滅是有生有滅之物也生</span>  
<span style="margin-left: 2em">與滅相代是知必屬受壞或曰否蓋謂凡物受壞必</span>  
<span style="margin-left: 2em">屬外物相攻豈其一物而能自壞今夫宇內何物爲</span>  
<span style="margin-left: 2em">此大圜相攻者歟二說甚繁茲不備述</span>  
<span style="margin-left: 1em">古分天作數層七曜恆星各居其一其諸星麗天如寶</span>  
<span style="margin-left: 2em">飾於鈿如節嵌于板層各堅實不相通而相包然新</span>  
<span style="margin-left: 2em">曆推測火日金水四曜所行之蹟相割相遇交互在</span>  
<span style="margin-left: 2em">上在下是又必不能言星于諸天層各堅實矣</span>  
<span style="margin-left: 1em">或問天行之健恆久不已厥樞焉繫斡運誰司有謂天</span>  
<span style="margin-left: 2em">非生物自不能行所行之原必在厥外故每層必有</span>  
<span style="margin-left: 2em">一靈者以運之有謂天下諸物自然之行不過三者</span>  
<span style="margin-left: 2em">其一恆向地心必下至地心而後止乃重物也其一</span>  
<span style="margin-left: 2em">恆欲向天必升至月天而後已乃輕物也其一恆爲</span>  
<span style="margin-left: 2em">旋動即天之本行也此其本行自運不息三者之外</span>  
<span style="margin-left: 2em">復有雜亂諸行是名無法之動其詳具寰有詮中</span>  
<span style="margin-left: 3em">天道<sub class="note-yuan">第三章</sub></span>  
<span style="margin-left: 1em">天爲大寰之公稱然非判界立限以爲準的則第就此</span>  
<span style="margin-left: 2em">渾淪之體抑何從而推測攷驗歟今夫人之蟻附地</span>  
<span style="margin-left: 2em">面仰視穹然者即此渾淪之半耳半恆繞于地下此</span>  
<span style="margin-left: 2em">其見與不見之界諸曜繇是而出入以分明分暗是</span>  
<span style="margin-left: 2em">之曰地平規其一極即天頂其一即底極也然而地</span>  
<span style="margin-left: 2em">平非一各隨所居人目四望者即是矣此規剖爲四</span>  
<span style="margin-left: 2em">象各限以九十度以紀四方以定地平經度以辨各</span>  
<span style="margin-left: 2em">曜出入方位自地平上至天頂多立距等圈即其緯</span>

<span style="margin-left: 2em">審各曜出地離赤道爲幾何緯度</span>  
<span style="margin-left: 1em">古曰天行健又曰天左旋知其旋之健則驗南北必有</span>

<span style="margin-left: 2em">命耳二極相距正中之界判一規謂之赤道平分天</span>

<span style="margin-left: 2em">爲準則故天體一日一周之運于是焉紀晝夜刻分</span>  
<span style="margin-left: 2em">永短于是焉定黃道出入廣狹于是齊春秋二分晷</span>

<span style="margin-left: 2em">減差也</span>

<span style="margin-left: 2em">者較多然此皆一歲之中必有四日其晝與夜互相</span>  
<span style="margin-left: 2em">均停故握算者得九十日之晝夜長短即可以推終</span>  
<span style="margin-left: 2em">歲之數<sub class="note-yuan">晝夜相互均停者如立夏之晝與立冬之夜相停立秋之夜與立春之晝相停等類</sub></span>  
<span style="margin-left: 1em">一晝一夜平分爲十二時<sub class="note-yuan">或二十四小時</sub>時各八刻<sub class="note-yuan">或四刻</sub>刻共</span>  
<span style="margin-left: 2em">爲九十六此九十六刻爲新法所用大統之所以用</span>  
<span style="margin-left: 2em">百刻者舉成數以便籌策耳故每于推交食求時差</span>  
<span style="margin-left: 2em">分仍用九十六刻爲法而定之</span>  
<span style="margin-left: 1em">晨昏者何乃分晝分夜之二界也<sub class="note-yuan">亦謂爲朦朧影</sub>太陽未出數</span>  
<span style="margin-left: 2em">刻之前發其光星光漸爲所奪是名爲晨<sub class="note-yuan">亦曰昧爽</sub>太陽</span>  
<span style="margin-left: 2em">已入廻光返照亦數刻始逌然滅盡是名爲昏<sub class="note-yuan">亦曰黃昏</sub></span>  
<span style="margin-left: 2em">此其久暫分數則亦因冬夏有短長新曆謂凡日在</span>  
<span style="margin-left: 2em">地平下十八度以內者是爲晨昏之限第太陽行此</span>  
<span style="margin-left: 2em">十八度各方各宮不等緣是有五刻七刻十刻之別</span>  
<span style="margin-left: 2em">若論極高七十二度以上之處則夏月晨昏相切雖</span>  
<span style="margin-left: 2em">至于丙夜而亦未甚有黯黑也</span>  
<span style="margin-left: 1em">大統曆不分晨昏刻數多寡第一歲內恆以二刻半爲</span>  
<span style="margin-left: 2em">定率此其立法之疎固不必假儀測舉目即可瞭然</span>  
<span style="margin-left: 2em">矣</span>  
<span style="margin-left: 3em">恆星<sub class="note-yuan">第七章</sub></span>  
<span style="margin-left: 1em">恆星亦名列星亦名經星云恆者謂終古不易其象也</span>  
<span style="margin-left: 2em">云經者別于五緯無南北行之義爲數甚多莫能窮</span>  
<span style="margin-left: 2em">盡其間有光渺體微非目可及非儀可推者則略而</span>  
<span style="margin-left: 2em">不錄其在等第之內已經新法所測定者南北兩極</span>  
<span style="margin-left: 2em">大小共得一千七百二十五星</span>  
<span style="margin-left: 1em">星以大小分爲六等第一等大星如五帝座織女類者</span>  
<span style="margin-left: 2em">一十七次二等如帝星開陽類者五十七次三等如</span>  
<span style="margin-left: 2em">太子少衛類者八十五次四等如上將柱史類者三</span>  
<span style="margin-left: 2em">百八十九次五等如上相虎賁類者三百二十三次</span>  
<span style="margin-left: 2em">六等如天皇太帝后宮類者二百九十五是皆有名</span>  
<span style="margin-left: 2em">之星共爲一千二百六十六餘則皆爲無名之星矣</span>  
<span style="margin-left: 1em">古曆以周天諸星分爲三垣二十八宿各各定有名位</span>  
<span style="margin-left: 2em">座次每座每宿星數又各多寡不齊然其所謂宿者</span>  
<span style="margin-left: 2em">蓋取七曜經行止宿之義且用以便于測算經度又</span>  
<span style="margin-left: 2em">謂其各能主施德也而西古曆亦有二十八舍義與</span>  
<span style="margin-left: 2em">中古相侔其所定二十八距星<sub class="note-yuan">距星者此宿隔越彼宿之定度分也</sub>亦</span>  
<span style="margin-left: 2em">皆脗合第觜宿距星西用天關與中不合耳西又分</span>  
<span style="margin-left: 2em">爲六十二像亦名命之以名以期便于識別然今時</span>  
<span style="margin-left: 2em">亦不甚大相關于測天算曜也此二十八宿者各以</span>  
<span style="margin-left: 2em">一字命名分註每日之下內以房虛星昴四宿爲屬</span>  
<span style="margin-left: 2em">太陽之日心尾畢張爲屬太陰之日是外五緯各屬</span>  
<span style="margin-left: 2em">四宿每以七日爲期每日各屬一宿西曆亦然義理</span>  
<span style="margin-left: 2em">皆符西經相傳上古有一大師名諾厄者所通于天</span>  
<span style="margin-left: 2em">下萬國云</span>  
<span style="margin-left: 1em">星之命名或彷彿其形似或因其光色或因其德性或</span>  
<span style="margin-left: 2em">名以官以國以人以物以事種種借義咸以便司天</span>  
<span style="margin-left: 2em">氏之仰觀耳然西曆亦多有相同者若論其的于何</span>  
<span style="margin-left: 2em">有主管則未之敢或信至其情性不同所以旉施互</span>  
<span style="margin-left: 2em">異是殆理所固然故總圖于某星屬某緯者咸附註</span>  
<span style="margin-left: 2em">之</span>  
<span style="margin-left: 1em">恆星距地高遠亦有法以步之約得數爲一萬四千地</span>  
<span style="margin-left: 2em">半徑變里得二億萬里或謂恆星距地各各近遠不</span>  
<span style="margin-left: 2em">等所以人見之有小大是說無徵殊不足信</span>  
<span style="margin-left: 1em">論星體小大因測定其遠及視徑算得第一等大星大</span>  
<span style="margin-left: 2em">于地球者六十餘倍第六等小星比地球小爲三分</span>  
<span style="margin-left: 2em">之一他星皆各有數玆不備述</span>  
<span style="margin-left: 1em">天漢斜絡天體廣狹不等與天異色終古無變昔稱雲</span>  
<span style="margin-left: 2em">漢疑與白氣同類且有別爲謬解者今用遠鏡窺之</span>  
<span style="margin-left: 2em">實則無算小星也外如積尸氣等之類亦皆小星攢</span>  
<span style="margin-left: 2em">聚以成第人目力不能辨別遂作如是觀耳</span>  
<span style="margin-left: 1em">圖星不出二法或作渾球以圖之此爲正式或圖于平</span>  
<span style="margin-left: 2em">面此爲借式蓋球有南北二極有地平子午諸規界</span>  
<span style="margin-left: 2em">判黃赤二道試斡運之能肖天體旋轉以便審各星</span>  
<span style="margin-left: 2em">之經緯度分又可辨夫星中出沒且能于夜中測時</span>  
<span style="margin-left: 2em">若平面圖者雖乏諸用然星之位置宮度瞭若視掌</span>  
<span style="margin-left: 2em">而亦有多種之分曰見界圖以北極爲心其最南隱</span>  
<span style="margin-left: 2em">于地中星極非此方人目可見者截出之曰赤道圖</span>  
<span style="margin-left: 2em">黃道圖二者各以二極爲心二道爲界此皆以天之</span>  
<span style="margin-left: 2em">南北平剖爲二圖者也曰分星圖此蓋依黃道而分</span>  
<span style="margin-left: 2em">天爲二十圖亦復均賦經緯署以維辰是皆用便按</span>  
<span style="margin-left: 2em">圖指陳明哲天象者也外有渾蓋所用天盤以極爲</span>  
<span style="margin-left: 2em">心截冬至規爲界亦圖星于儀上最能肖天運動可</span>  
<span style="margin-left: 2em">覘諸星出沒升降等又有平儀從二極剖天爲南六</span>  
<span style="margin-left: 2em">宮北六宮之二面亦繪辰宿亦可以代渾儀旋轉至</span>  
<span style="margin-left: 2em">若古傳星經星圖及步天謌等雖亦分宿分座似于</span>  
<span style="margin-left: 2em">觀覽得矣至求厥經緯度分悉皆茫然掛漏于測候</span>  
<span style="margin-left: 2em">奚藉諸此新法所以繪有諸圖也</span>  
<span style="margin-left: 1em">彗孛蚩尤等類各有法以步厥高遠小大第因其非經</span>  
<span style="margin-left: 2em">曜以故馮相氏每置不論然依測星之法求得其更</span>  
<span style="margin-left: 2em">高于太陰矧其行又非繇于黃赤二道恆自斜行游</span>  
<span style="margin-left: 2em">移無定然其尾則恆指太陽占未嘗細測是以有謂</span>  
<span style="margin-left: 2em">此星在月天之下乃太陽照熱下域之氣騰以成形</span>  
<span style="margin-left: 2em">第較雲稍高耳斯蓋據古云然若于今測論之未必</span>  
<span style="margin-left: 2em">如是也</span>  
<span style="margin-left: 3em">太陰<sub class="note-yuan">第八章</sub></span>  
<span style="margin-left: 1em">太陰之行參錯不一推步籌算爲力倍囏苟或分秒乖</span>  
<span style="margin-left: 2em">違交食必難求合然則非細審其行度所以然抑何</span>  
<span style="margin-left: 2em">以立法致用哉是月離者政曆學之本根也故新法</span>  
<span style="margin-left: 2em">全書備爲闡明之</span>  
<span style="margin-left: 1em">月較諸曜本旋之外其行復有多種第一曰平行<sub class="note-yuan">亦曰本行</sub></span>  
<span style="margin-left: 2em">一日十三度十分有奇斯行之界凡四故又生四行</span>  
<span style="margin-left: 2em">之類其一界是以某宮次度分<sub class="note-yuan">或用宿度亦可</sub>從其初點起</span>  
<span style="margin-left: 2em">算則此界爲定而不動<sub class="note-yuan">宮次初點者如從星紀宮初度等類</sub></span>  
<span style="margin-left: 2em">其二界是本天之最高此界非定而自有其行每日</span>  
<span style="margin-left: 2em">順天右行七分有奇則月距本天最高一日爲十三</span>  
<span style="margin-left: 2em">度三分有奇<sub class="note-yuan">月從本天每日右行十三度十分最高亦右行七分故其距爲十三度三分也</sub></span>  
<span style="margin-left: 2em">故其平行則二十七日三十刻有奇爲一周而回于</span>  
<span style="margin-left: 2em">宮次元度然必再行二十三刻有奇爲二十七日五</span>  
<span style="margin-left: 2em">十三刻始能及于本天之最高此行新法謂之月自</span>  
<span style="margin-left: 2em">行<sub class="note-yuan">或引行</sub>中曆于此周謂之轉周滿一周謂之轉終其</span>  
<span style="margin-left: 2em">最高則行八年有奇而周天中曆謂爲月孛</span>  
<span style="margin-left: 2em">其三界是黃白二道相交之所所謂正交中交此界</span>  
<span style="margin-left: 2em">亦自有行乃逆行也<sub class="note-yuan">自東而西</sub>每日三分有奇則月平行</span>  
<span style="margin-left: 2em">距正交一日爲十三度十三分有奇<sub class="note-yuan">月順經度平行距宮次之界一</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">日十三度十分正交逆經度左旋每日行三分所以共爲十三度十三分也</sub>至二十七日</span>  
<span style="margin-left: 2em">二十七刻減交行之一度二十三分得二十七日十</span>  
<span style="margin-left: 2em">五刻有奇月回于元界曆謂之交終</span>  
<span style="margin-left: 2em">其四界是與太陽去離太陽一曰約行一度則太陰</span>  
<span style="margin-left: 2em">一日距太陽爲十二度十分有奇迨至二十九日五</span>  
<span style="margin-left: 2em">十三刻有奇逐及太陽復與之相會曆謂朔策<sub class="note-yuan">亦謂會望</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">策</sub></span>  
<span style="margin-left: 1em">第二行曰小輪一朔內行滿其輪周二次每日爲二十</span>  
<span style="margin-left: 2em">四度有奇<sub class="note-yuan">若以不同心圈論此即太陰中距圈也</sub>因有此行所以生第</span>  
<span style="margin-left: 2em">二損益加減分謂第二者蓋于朔望所用加減分之</span>  
<span style="margin-left: 2em">外或再加再減不等其二弦之大數則爲二度半中</span>  
<span style="margin-left: 2em">曆無此</span>  
<span style="margin-left: 1em">以上西曆所定太陰諸行軌轍總不外于三者一爲不</span>  
<span style="margin-left: 2em">同心圈一爲均圈一爲小輪然資以推算或用不同</span>  
<span style="margin-left: 2em">心圈或用小輪厥名雖異厥理則同故兩用互推所</span>  
<span style="margin-left: 2em">得之數正等</span>  
<span style="margin-left: 1em">月道惟一非九古謂月行九道者乃白道正交行及于</span>  
<span style="margin-left: 2em">春夏秋冬四正其陰陽二曆各異命之因有八名通</span>  
<span style="margin-left: 2em">其公名共九豈其果有九道歟白道兩交黃道其最</span>  
<span style="margin-left: 2em">遠之距謂爲五度此乃二曆未甚大差之數然新測</span>  
<span style="margin-left: 2em">得凡朔望外五度即不合天若至上下兩弦則爲五</span>  
<span style="margin-left: 2em">度一十七分三十秒因知二道相交之角又非定而</span>  
<span style="margin-left: 2em">不動其廣狹之行則恆以十五日爲限焉</span>  
<span style="margin-left: 1em">二道相交厥名不一白道自南順天而北交于黃道之</span>  
<span style="margin-left: 2em">點謂之正交亦名羅睺龍頭升交等其過正交而在</span>  
<span style="margin-left: 2em">黃道北半周是爲陰曆白道自北遡南而交黃道之</span>  
<span style="margin-left: 2em">點謂之中交亦名計都龍尾降交等其過中交而在</span>  
<span style="margin-left: 2em">黃道南半周是爲陽曆</span>  
<span style="margin-left: 1em">太陰距地高遠以法可求然古今諸測亦自大同小異</span>  
<span style="margin-left: 2em">今約略言之月中距地<sub class="note-yuan">云中距地以別于首章所言月最近于地也</sub>爲地</span>  
<span style="margin-left: 2em">球全徑二十八變里得八十萬有奇然有遠近之度</span>  
<span style="margin-left: 2em">近則距數少而遠則多因其行之遲疾及視徑小大</span>  
<span style="margin-left: 2em">即可以知之</span>  
<span style="margin-left: 1em">論月體之大依法測其遠及視徑算得小于地球爲三</span>  
<span style="margin-left: 2em">十六分之一</span>  
<span style="margin-left: 1em">月本無光恆借太陽之光故日光爲地景所隔則人見</span>  
<span style="margin-left: 2em">食若食甚有微光者乃經緯諸星之光所映照也</span>  
<span style="margin-left: 1em">日月相照不等人因見有晦朔弦望譬如置一球于燈</span>  
<span style="margin-left: 2em">光之前人目于球後參直視之則見全球皆暗球遷</span>  
<span style="margin-left: 2em">轉于人目必見球上側相映而有光迨人居于球與</span>  
<span style="margin-left: 2em">燈之中且見全球受光矣月借日光其理猶是</span>  
<span style="margin-left: 1em">月體班駁繇其質非淸純虛實相雜實則發光密虛則</span>  
<span style="margin-left: 2em">發光微也又謂其上有坳突以遠鏡可見之又謂實</span>  
<span style="margin-left: 2em">處如金類能照光其本然耳虛則照光必少是蓋皆</span>  
<span style="margin-left: 2em">因其質所以明昧雜成若謂大地影所印者則世俗</span>  
<span style="margin-left: 2em">之謬言也</span>  
<span style="margin-left: 1em">合朔以後月夕西見遲疾不一或有差至三日者何故</span>  
<span style="margin-left: 2em">曰其因有三一因月視行度若視行爲疾段則疾見</span>  
<span style="margin-left: 2em">遲段則遲見一因黃道升降有斜有正正必疾見斜</span>  
<span style="margin-left: 2em">必遲見一因白道在緯南緯北凡在陰曆疾見陽曆</span>  
<span style="margin-left: 2em">遲見也三因之外又有極出地之不同以及朦朧分</span>  
<span style="margin-left: 2em">與炁差諸異所以遲疾恆不能齊矣</span>  
<span style="margin-left: 3em">交食<sub class="note-yuan">第九章</sub></span>  
<span style="margin-left: 1em">七政運行遲疾互異每日距有近遠以成相合相衝然</span>  
<span style="margin-left: 2em">其最昭明者莫若二曜薄蝕此之規分期限推測精</span>  
<span style="margin-left: 2em">密則庶乎可稱治曆者已</span>  
<span style="margin-left: 1em">日月二十九日有奇而西東之行同度謂爲會朔若月</span>  
<span style="margin-left: 2em">視行在于黃道近交人適視爲同經同緯則人目與</span>  
<span style="margin-left: 2em">月日相參直月魄正隔日光於人目是爲日食非日</span>  
<span style="margin-left: 2em">失其光月魄掩之耳太陰距太陽一百八十度而正</span>  
<span style="margin-left: 2em">與之衝謂爲望若其衝時月行近于兩交必入地影</span>  
<span style="margin-left: 2em">則闇虛也此乃地體居于月與日之中日光不能射</span>  
<span style="margin-left: 2em">照于月人目視之似若月忽失光而爲月食此其日</span>  
<span style="margin-left: 2em">月二食躔度有恆千百世以還規程不爽曆家持籌</span>  
<span style="margin-left: 2em">可步其分秒且確然因知必非若俗所謂有異物以</span>  
<span style="margin-left: 2em">食之也</span>  
<span style="margin-left: 1em">白道交于黃道二所是爲正交中交凡日月及于正交</span>  
<span style="margin-left: 2em">或中交爲同度則必有食然而日食宇內各異者蓋</span>  
<span style="margin-left: 2em">月距地甚近而日甚遠此所以不能爲公食譬之一</span>  
<span style="margin-left: 2em">指當前則喬岳爲之掩然一指不能掩二目則一目</span>  
<span style="margin-left: 2em">必見岳矣是二目者猶夫二所之人也指喻月體而</span>  
<span style="margin-left: 2em">喬岳其日乎</span>  
<span style="margin-left: 1em">日食之全與不全厥有二故其一繇于天上之行其二</span>  
<span style="margin-left: 2em">繇于日食時地平上高弧之度故一食也有見全食</span>  
<span style="margin-left: 2em">有見食多寡有全不見食復有見食在南在北之異</span>  
<span style="margin-left: 2em">即其時刻咸各不同若問見食地界其廣幾何則設</span>  
<span style="margin-left: 2em">如北京見全食而其南北各距四十五度之地爲一</span>  
<span style="margin-left: 2em">萬一千餘里皆見有多寡不等之食抑論東西則距</span>  
<span style="margin-left: 2em">六十度爲一萬五千餘里之地各見食而其分數多</span>  
<span style="margin-left: 2em">寡亦各不等焉</span>  
<span style="margin-left: 1em">日月近於兩交有食固也然推法咸有限焉限內則食</span>  
<span style="margin-left: 2em">限外必無食矣夫限度各方莫能一之也蓋太陽于</span>  
<span style="margin-left: 2em">各方地平高度不同又陰陽二曆各限亦不同論煖</span>  
<span style="margin-left: 2em">帶下之域則二曆互相受變如白道向南極半周有</span>  
<span style="margin-left: 2em">時在于天頂及黃道之中不得不反謂爲陰曆白道</span>  
<span style="margin-left: 2em">向北半周有時在黃道外即以之代陽曆故其下難</span>  
<span style="margin-left: 2em">定日食之限而他域更近于北必陰曆限多陽曆限</span>  
<span style="margin-left: 2em">少如北京約算得陽曆爲八度陰曆爲二十一度則</span>  
<span style="margin-left: 2em">凡日月相會在陽曆近二交八度或陰曆近二交二</span>  
<span style="margin-left: 2em">十一度必天下見日有食之過是以往則否此限乃</span>  
<span style="margin-left: 2em">赤道向北之人所用者若居于赤道南則以陽爲陰</span>  
<span style="margin-left: 2em">以陰爲陽而其限度亦悉以遠近分有多寡矣</span>  
<span style="margin-left: 1em">二曆食限之度有異者其故在于月輪月輪比日最近</span>  
<span style="margin-left: 2em">于地人之見月在地面不在地心矧地球之于恆星</span>  
<span style="margin-left: 2em">天其小<sub class="note-jiao">校：和刻本小作少</sub>無分數可較較之太陽則有分數</span>  
<span style="margin-left: 2em">若較月輪則地反大矣故以月天論地平有二其一</span>  
<span style="margin-left: 2em">是以天與地球皆爲平分而過其心其一是人在高</span>  
<span style="margin-left: 2em">所而見天地之界今夫地球非與月天爲平分也少</span>  
<span style="margin-left: 2em">半在上多半在下其差約爲一度故以本法推算月</span>  
<span style="margin-left: 2em">已出正地平然于人目所視之地平尚少一度此二</span>  
<span style="margin-left: 2em">者之較謂之視差<sub class="note-yuan">亦曰地半徑差</sub>是視差者乃算與測二地</span>  
<span style="margin-left: 2em">平不能相同之數也設月在天頂必無視差矣蓋二</span>  
<span style="margin-left: 2em">地平之極皆以一直線合于天頂耳過此左右皆必</span>  
<span style="margin-left: 2em">有差愈遠或愈近地平其差必愈甚焉</span>  
<span style="margin-left: 1em">視差之異是恆降下月數十分也設今算得日月同度</span>  
<span style="margin-left: 2em">又設同在近交之南又因同度皆在正地平上高二</span>  
<span style="margin-left: 2em">十度則太陽于視地平爲十九度五十八分顧視與</span>  
<span style="margin-left: 2em">正所差第二分耳若太陰于視地平則爲十九度其</span>  
<span style="margin-left: 2em">差至一度矣總日月二差之較爲五十八分故以算</span>  
<span style="margin-left: 2em">論雖二曜同高同度而人目視之必太陰在于太陽</span>  
<span style="margin-left: 2em">下一度弱必不能掩日之光若二曜在地平上高七</span>  
<span style="margin-left: 2em">十度則太陽無視差太陰視正二地平之差止二十</span>  
<span style="margin-left: 2em">分其降于太陽者亦止二十分必且相切或至掩日</span>  
<span style="margin-left: 2em">數分而爲食若二曜在交北又當以太陰算在太陽</span>  
<span style="margin-left: 2em">之上庶因視差所降而得掩太陽之光以爲食焉</span>  
<span style="margin-left: 1em">此二地平之差又分二類其一是加減交食分數所謂</span>  
<span style="margin-left: 2em">炁差其一是加減時刻所謂時差此皆曆算之最囏</span>  
<span style="margin-left: 2em">且劇者然日月在天頂則無炁差更近地平更多若</span>  
<span style="margin-left: 2em">在黃道中限則無時差此中限非午正之點或即偏</span>  
<span style="margin-left: 2em">東偏西大較二十餘度皆是也</span>  
<span style="margin-left: 1em">以上可解所謂日食有三曰平食乃因日月及於交點</span>  
<span style="margin-left: 2em">皆以其平行在同度也中曆謂爲經朔曰實食乃用</span>  
<span style="margin-left: 2em">日月加減分推得地心月魄日輪參居一直線以爲</span>  
<span style="margin-left: 2em">同度也此則在于天頂人始見食中曆謂爲定朔曰</span>  
<span style="margin-left: 2em">視食乃用視差及炁時二數推定人目見食也之三</span>  
<span style="margin-left: 2em">類者一與二較或有差至五六十刻若二與三較則</span>  
<span style="margin-left: 2em">所差不過七八刻而已</span>  
<span style="margin-left: 1em">日月二體視各半度然因距地有遠有近所以時或見</span>  
<span style="margin-left: 2em">大見小互有相勝之日南北二方食頃亦差北方日</span>  
<span style="margin-left: 2em">食甚時見魄更小蓋緣地冷氣濁能使日光照廣故</span>  
<span style="margin-left: 2em">月魄自然見小矣兩地相較食或差至一分又日體</span>  
<span style="margin-left: 2em">之視徑必十分之所謂食幾何分者蓋視徑之分數</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 1em">月食之限無二陰曆陽曆皆爲十三度亦無地半徑差</span>  
<span style="margin-left: 2em">月愈近兩交其食分愈多凡食則天下大半可見必</span>  
<span style="margin-left: 2em">分數皆等第時刻各不同耳</span>  
<span style="margin-left: 1em">問闇虛者何曰地球之影也日輪雖大其照地之光不</span>  
<span style="margin-left: 2em">能透過則其後生影是影爲角形近地者大徐徐而</span>  
<span style="margin-left: 2em">小迨至月所則其徑爲天之一度半焉</span>  
<span style="margin-left: 1em">日體亦十分之然地影大于月三倍弱故影徑分爲三</span>  
<span style="margin-left: 2em">十分其半徑得分數十五月入于地影幾分是所謂</span>  
<span style="margin-left: 2em">食幾分也若據大統曆此月體十分之一及地影三</span>  
<span style="margin-left: 2em">十分之一時時爲等新曆非然謂或時有小大之較</span>  
<span style="margin-left: 2em">蓋因月行近遠于地不等故也</span>  
<span style="margin-left: 3em">五緯異行<sub class="note-yuan">第十章</sub></span>  
<span style="margin-left: 1em">土木火金水五曜名爲緯星者謂其較于恆星則無日</span>  
<span style="margin-left: 2em">不有近南近北之行也此其緯度古法所遺然則于</span>  
<span style="margin-left: 2em">緯之名義何居乎斯所以新法曆指更加詳譯焉</span>  
<span style="margin-left: 1em">五緯之行各有二種其一是本行如填星約三十年行</span>  
<span style="margin-left: 2em">天一周每日二分歲星約十二年一周天每日五分</span>  
<span style="margin-left: 2em">熒惑之周天爲二年弱每日三十五分太白辰星皆</span>  
<span style="margin-left: 2em">隨太陽約每年<sub class="note-jiao">校：和刻本年作日當誤也</sub>旋天一周各各有嬴有</span>  
<span style="margin-left: 2em">縮有加減分有本天之最高及其衝而其最高又各</span>  
<span style="margin-left: 2em">有本行若論其界亦分四種如月行等非若回回曆</span>  
<span style="margin-left: 2em">云總一最高也其二在于本行之外新法稱爲歲行</span>  
<span style="margin-left: 2em">蓋各星會太陽一次成一周也因此歲行之規<sub class="note-yuan">亦謂小輪</sub></span>  
<span style="margin-left: 2em">能解各星順逆留疾諸情故依新法之圖五緯各有</span>  
<span style="margin-left: 2em">一不同心圈一均圈一小輪凡星在小輪極遠之所</span>  
<span style="margin-left: 2em">必合于太陽其行爲順而疾厥體見小凡在小輪極</span>  
<span style="margin-left: 2em">近之所其行爲逆而疾厥體見大若土木火三星行</span>  
<span style="margin-left: 2em">逆則衝太陽金水二星行逆必夕伏而合行順必晨</span>  
<span style="margin-left: 2em">伏而合其各星之順行而轉逆逆行而轉順之兩中</span>  
<span style="margin-left: 2em">界爲留留者非星不行乃際于極遲行之所也留段</span>  
<span style="margin-left: 2em">前後或順或逆皆有遲行</span>  
<span style="margin-left: 1em">土木火三星之本天大皆以太陽爲心而包地故得與</span>  
<span style="margin-left: 2em">太陽相衝金水二星之本天雖亦以太陽爲心而不</span>  
<span style="margin-left: 2em">包地故不能衝太陽第能與之相離耳金星離太陽</span>  
<span style="margin-left: 2em">爲四十八度水星則二十四度<sub class="note-jiao">校：和刻本度字脫</sub>而已</span>  
<span style="margin-left: 3em">五緯緯行<sub class="note-yuan">第十一章</sub></span>  
<span style="margin-left: 1em">太陽之行天也因黃道斜交赤道故距赤道緯南緯北</span>  
<span style="margin-left: 2em">各二十三度半以成二至是黃道者太陽之軌蹟也</span>  
<span style="margin-left: 2em">而太陰本道又斜交于黃道其最遠之距爲五度以</span>  
<span style="margin-left: 2em">生陰陽二曆五星之道雖其相距緯度各異然其斜</span>  
<span style="margin-left: 2em">絡黃道與月道同理故皆借月道諸名以命之其兩</span>  
<span style="margin-left: 2em">交之所亦曰正交中交其在南在北兩半周亦曰陰</span>  
<span style="margin-left: 2em">陽兩曆繇是而五星緯行則庶乎可詳明矣</span>  
<span style="margin-left: 1em">本道外之歲行小輪恆與黃道爲平行又斜交于本道</span>  
<span style="margin-left: 2em">其上半恆在黃本二道中若星躔于此則減本道之</span>  
<span style="margin-left: 2em">緯其下半恆在本道外若星躔于此則加其緯然此</span>  
<span style="margin-left: 2em">小輪則恆不變緯之向如土星三十年行天一周其</span>  
<span style="margin-left: 2em">在于正中二交之下必無緯度分十五年恆在北十</span>  
<span style="margin-left: 2em">五年恆在南耳凡衝太陽因在小輪下半即加本道</span>  
<span style="margin-left: 2em">緯度凡會太陽因在小輪上半必減之他星咸猶是</span>  
<span style="margin-left: 2em">也其或行近于地則其小輪所加緯分更多故太白</span>  
<span style="margin-left: 2em">至夕伏合之際因近于地其緯且不逾八度矣中曆</span>  
<span style="margin-left: 2em">不諳緯行之原凡見金星在緯南北七八九度即詫</span>  
<span style="margin-left: 2em">曰星失行夫星也而終古未嘗失分秒之行人舛于</span>  
<span style="margin-left: 2em">推步而顧咎天誣矣哉</span>  
<span style="margin-left: 1em">古有五星南北緯行圖亦界以黃道本道但其逆行之</span>  
<span style="margin-left: 2em">蹟恆作一斜方形此甚非也夫五星之緯非行直線</span>  
<span style="margin-left: 2em">胡然而作四方之形歟今新曆五星行圖分有二種</span>  
<span style="margin-left: 2em">其一設人在地仰觀乎天上進退諸行故上三星每</span>  
<span style="margin-left: 2em">衝太陽下二星每夕伏時第作一僅似之圓形耳凡</span>  
<span style="margin-left: 2em">衝太陽如在本道交上不作圓形即彷彿之字形而</span>  
<span style="margin-left: 2em">已其二是各星近遠于地之圖此皆古所莫能詳明</span>  
<span style="margin-left: 2em">者也</span>  
<span style="margin-left: 3em">五星伏見<sub class="note-yuan">第十二章</sub></span>  
<span style="margin-left: 1em">五星之光與日相較政猶螢光之于庭燎也其光本不</span>  
<span style="margin-left: 2em">滅人第莫睹耳試觀太陽東出諸星漸隱先失其小</span>  
<span style="margin-left: 2em">者至日光漸盛則大星亦繼以熄今夫初暘冉冉其</span>  
<span style="margin-left: 2em">光猶殺故或啓明或歲星不伏而見暨升高而其光</span>  
<span style="margin-left: 2em">炳燿則匪特諸大星即此二星最燦之光必爲所奪</span>  
<span style="margin-left: 2em">矣肉目何自而見乎</span>  
<span style="margin-left: 1em">小大諸星各有距太陽若干度分以爲見伏之限此限</span>  
<span style="margin-left: 2em">度新舊二法各異舊曆但用黃道距度以定星之伏</span>  
<span style="margin-left: 2em">見如謂太陽在降婁宮初度或歲星在十五度即謂</span>  
<span style="margin-left: 2em">爲見限矣然實非也何者諸星有緯南緯北之分黃</span>  
<span style="margin-left: 2em">道有正斜升降之勢各宮不同何能泥此以定公法</span>  
<span style="margin-left: 2em">今新曆定各星見伏之限惟以地平爲主緣地平障</span>  
<span style="margin-left: 2em">蔽日光能使星爲見與不見耳今夫日之下于地平</span>  
<span style="margin-left: 2em">也其光漸淡所謂晨昏此晨昏光之久暫四時各各</span>  
<span style="margin-left: 2em">不等即冥漠矣而星見時刻又自不等所以太陽繇</span>  
<span style="margin-left: 2em">黃道而下于地平或有十度或十五度甚至有三十</span>  
<span style="margin-left: 2em">餘度爲限者總之星在黃道南必多數度若在北必</span>  
<span style="margin-left: 2em">少數度矣故統論其見伏之因凡四一以太陽下于</span>  
<span style="margin-left: 2em">地平一以星在緯之南北一以極出地高一以黃道</span>  
<span style="margin-left: 2em">升降斜正不明斯數者乃第謂太陽距某數即可以</span>  
<span style="margin-left: 2em">定母惑乎其恆差而莫能合也</span>  
<span style="margin-left: 1em">土木火三星因較太陽行遲故有夕伏晨見蓋太陽行</span>  
<span style="margin-left: 2em">逾其先也金水二星凡順天東旋則較太陽爲疾故</span>  
<span style="margin-left: 2em">有晨伏夕見蓋逾太陽而先行耳若逆行時必反之</span>  
<span style="margin-left: 2em">而與太陽相遇亦爲夕伏晨見矣太陰則恆爲晨伏</span>  
<span style="margin-left: 2em">夕見者緣其行視太陽更疾也</span>  
<span style="margin-left: 1em">恆星亦有夕伏晨見因于黃道之經緯度又因其小大</span>  
<span style="margin-left: 2em">等第亦可推其見伏之限</span>  
<span style="margin-left: 1em">金星緣其緯不至八度則凡逆行合太陽于壽星大火</span>  
<span style="margin-left: 2em">二宮之內而其緯復在北七度以上是雖與日合而</span>  
<span style="margin-left: 2em">其光不伏也故于一日晨夕皆可以見之</span>  
<span style="margin-left: 1em">水星之緯惟四度餘若其緯向南合太陽于壽星宮是</span>  
<span style="margin-left: 2em">後去離夕必不見或合太陽于降婁宮是後去離必</span>  
<span style="margin-left: 2em">晨不見矣此金星合太陽而不伏水星離太陽而不</span>  
<span style="margin-left: 2em">見用渾儀可解之</span>

<span style="margin-left: 2em">有某星與之相衝然曆家于其合者無從推測第測</span>  
<span style="margin-left: 2em">得其衝者謂爲歲差然恆星有出沒者亦有不出不</span>  
<span style="margin-left: 2em">沒者是全繇于本方極出地度也如京師北極出地</span>  
<span style="margin-left: 2em">四十度則星距極<sub class="note-jiao">校：和刻本脫極字</sub>四十度以下皆爲恆見</span>  
<span style="margin-left: 2em">而距南極四十度以內者則在京皆不能見矣</span>  
<span style="margin-left: 1em">恆星伏云者亦繇太陽右旋至某宿度其附近于某宿</span>  
<span style="margin-left: 2em">度之星光障于日故不能爲見也迨太陽去離漸遠</span>  
<span style="margin-left: 2em">則此星光能于東方漸升斯爲之見矣緣是而升至</span>  
<span style="margin-left: 2em">午點者即曰中星此其星中出沒立象學用之最鉅</span>  
<span style="margin-left: 2em">而曆家不過夜中資之以定時刻耳</span>  
<span style="margin-left: 3em">三餘<sub class="note-yuan">第十四章</sub></span>  
<span style="margin-left: 1em">三餘者何羅睺計都月孛也古加紫炁名爲四餘亦謂</span>  
<span style="margin-left: 2em">之四隱曜然詳求天行實無紫炁且絕無當于推步</span>  
<span style="margin-left: 2em">之術故新法棄而不錄第取三餘</span>  
<span style="margin-left: 1em">羅睺即白道之正交乃月道自南遡北以交于黃道之</span>

<span style="margin-left: 2em">周終古無其準率也</span>

<span style="margin-left: 2em">并而開方可得本規四平分之通弦用幾何諸法又</span>  
<span style="margin-left: 2em">可得各度分之通弦矣又各弧及其通弦折半得正</span>  
<span style="margin-left: 2em">弦正弧列表有正弦正弧即有其矢也故於矢獨不</span>  
<span style="margin-left: 2em">立表</span>  
<span style="margin-left: 1em">通弦之外有切線割線二種通弦全在規內切線全在</span>  
<span style="margin-left: 2em">規外其有線從規心而出于規周之外者則謂爲割</span>  
<span style="margin-left: 2em">線</span>  
<span style="margin-left: 1em">一象限爲本表之限或于限內取幾何度謂爲正弧其</span>  
<span style="margin-left: 2em">或逾九十度者即謂之餘矣正餘各有爲弦爲矢爲</span>  
<span style="margin-left: 2em">割爲切之四線正四餘四總名八線此八線表之爲</span>  
<span style="margin-left: 2em">用甚簡而大如籌筴七政測量輿地開平方算句股</span>  
<span style="margin-left: 2em">作簡儀日晷繪各項之圖悉皆用之</span>  
<span style="margin-left: 3em">測器<sub class="note-yuan">第二十章</sub></span>  
<span style="margin-left: 1em">欲齊七政首重璣衡驗合改差匪器胡籍是測器之于</span>  
<span style="margin-left: 2em">曆家猶之工師之準繩規矩也宿曜運行樊然紛賾</span>  
<span style="margin-left: 2em">必其精妙之器亦需多種始克盡用若第求簡便制</span>  
<span style="margin-left: 2em">作不良雖欲齊之必且棼之矣古曆所記尚有數類</span>  
<span style="margin-left: 2em">茲者靈臺所存惟有圭表景符簡儀渾象等器耳今</span>  
<span style="margin-left: 2em">新法增置者曰象限儀百游儀地平儀弩儀天環天</span>  
<span style="margin-left: 2em">球紀限儀渾蓋簡平儀黃赤全儀日星等晷諸器或</span>  
<span style="margin-left: 2em">用推諸曜或用審經緯或用測極或用求時此諸儀</span>  
<span style="margin-left: 2em">者皆爲曆學名家酌量增修精加研審多歷年所始</span>  
<span style="margin-left: 2em">趨巧便其外尚有多種不堪大用茲故不錄而其最</span>  
<span style="margin-left: 2em">巧最奇則近時所造遠鏡更爲窺天要具如用之能</span>  
<span style="margin-left: 2em">詳日食分秒能觀太白有上下弦能見歲星㫄四小</span>  
<span style="margin-left: 2em">星填星爲橢形㫄附有兩小星昴宿有三十餘鬼宿</span>  
<span style="margin-left: 2em">中之積尸氣他若月體之坳突日中之黑子以至體</span>  
<span style="margin-left: 2em">微光渺之星用此奚啻多數十倍抑且界限分明光</span>  
<span style="margin-left: 2em">耀璀燦此外爲用尚廣然非關仰觀故不殫述</span>  
<span style="margin-left: 3em">測太陽<sub class="note-yuan">第二十一章</sub></span>  
<span style="margin-left: 1em">諸曜森羅太陽爲其宗主故古今言曆者皆以測候盡</span>  
<span style="margin-left: 2em">善爲首務然其應測行類不出三者曰盈縮之限曰</span>  
<span style="margin-left: 2em">盈縮細行曰盈初縮末之所今按中曆雖有測太陽</span>  
<span style="margin-left: 2em">之法然止于冬夏二至至他時則未聞別有他法以</span>  
<span style="margin-left: 2em">測且未始有所謂測三種之行類也今以二法參駁</span>  
<span style="margin-left: 2em">之如左</span>  
<span style="margin-left: 1em">古法立八尺表用景符器每于冬至三四日前後測定</span>  
<span style="margin-left: 2em">三景因以三景相較之數求太陽到冬至時刻此其</span>  
<span style="margin-left: 2em">法固善矣然論法之爲用則未盡善也何者表景短</span>  
<span style="margin-left: 2em">長乃太陽行南行北所生論近于二至之候其南北</span>  
<span style="margin-left: 2em">行極微若計一日所行天度則有分半者有一分者</span>  
<span style="margin-left: 2em">而甚且有半分之日今于近冬至之期建尋丈之表</span>  
<span style="margin-left: 2em">其所得二景差爲一分二釐<sub class="note-yuan">量度則云分秒量景則云丈尺分釐</sub>每釐</span>  
<span style="margin-left: 2em">當算八刻是景符者何能定此一釐二釐之微乎況</span>  
<span style="margin-left: 2em">景符光線恆占數釐或再稍爲進退其失彌甚是其</span>  
<span style="margin-left: 2em">恆差數十刻也矧于測夏至倍難歟今新曆用八線</span>  
<span style="margin-left: 2em">表法查古所遺之數以推步焉則庶幾稍爲密近矣</span>  
<span style="margin-left: 1em">新曆正中測之訛復用別法以濟之曰春秋二分太陽</span>  
<span style="margin-left: 2em">之南北行較多每一日爲天度二十四分乃于其前</span>  
<span style="margin-left: 2em">後數日先測極出地度得赤道高次用象限儀測日</span>  
<span style="margin-left: 2em">軌高以法算日軌入于交點時刻此測或舛一分第</span>  
<span style="margin-left: 2em">于算者惟差四刻耳是較之于測冬至以尋丈之表</span>  
<span style="margin-left: 2em">差釐數而輒乖違數十刻者究竟孰疏遠而孰詳密</span>  
<span style="margin-left: 2em">哉且新法用儀逐日可測太陽實躔宮度分秒古法</span>  
<span style="margin-left: 2em">絕未之及豈其果于二至之外推步之術遂窮歟總</span>  
<span style="margin-left: 2em">緣其莫能甄發天路之本原耳</span>  
<span style="margin-left: 1em">又新法本測曰<sub class="note-jiao">校：日抄本和刻本日作曰是今改</sub>太陽從春分底于立</span>  
<span style="margin-left: 2em">夏行黃道四十五度歷四十六日十刻十分又從立</span>  
<span style="margin-left: 2em">秋底于秋分亦行四十五度而所歷則四十六日三</span>  
<span style="margin-left: 2em">十八刻十分此其逐日刻數不等是所謂春行嬴秋</span>  
<span style="margin-left: 2em">行縮也故定此嬴縮初末之界非二至點乃在二至</span>  
<span style="margin-left: 2em">之後推得爲六度<sub class="note-yuan">古今不同</sub>若如古法恆謂實在二至則</span>  
<span style="margin-left: 2em">其前後所行之度等胡爲所歷之期日刻數不等乎</span>  
<span style="margin-left: 2em">此率古稱盈末縮初新法稱爲最高因有此最高遂</span>  
<span style="margin-left: 2em">悉太陽之行必爲一不同心規也其行遲者在最高</span>  
<span style="margin-left: 2em">而行疾者在最高之衝此最高本行亦猶夫太陰之</span>  
<span style="margin-left: 2em">有月孛類云</span>  
<span style="margin-left: 1em">授時曆于終歲之閒冬夏兩測然後又測次冬于是自</span>  
<span style="margin-left: 2em">冬迄夏較之夏迄次冬必其所積日內時刻不同冬</span>  
<span style="margin-left: 2em">迄夏少夏迄冬多其較爲刻半其故何也最高不在</span>  
<span style="margin-left: 2em">夏至也然尊用厥術者覺其非而絕不求其故豈其</span>  
<span style="margin-left: 2em">尚得詡爲治曆之精密者歟</span>  
<span style="margin-left: 3em">測恆星<sub class="note-yuan">第二十二章</sub></span>  
<span style="margin-left: 1em">貞明遞更莫顯著乎日月茲首測日而次恆星者何蓋</span>  
<span style="margin-left: 2em">七政惟日度有常而恆星之經緯易定其他六曜皆</span>  
<span style="margin-left: 2em">有龐雜之行苟欲推厥不齊必先其齊者始所以次</span>  
<span style="margin-left: 2em">論測星是殆謂以有恆而御無恆也然則恆之爲義</span>  
<span style="margin-left: 2em">有以夫</span>  
<span style="margin-left: 1em">測星之法不一大要以太陽爲主而以太陰或太白或</span>  
<span style="margin-left: 2em">歲星爲中次任取某星爲界互測合推即得其度今</span>  
<span style="margin-left: 2em">概其法曰太陽將入測月或太白歲星距太陽若干</span>  
<span style="margin-left: 2em">度分迨日沒後再測月或太白歲星與某星相距度</span>  
<span style="margin-left: 2em">分若干兩測算之即得太陽與此星之距然後稽太</span>  
<span style="margin-left: 2em">陽本日躔某宮度則知此星所在宮度矣得一星之</span>  
<span style="margin-left: 2em">經度他可依法類推于是又測此星出地平最高則</span>  
<span style="margin-left: 2em">又得其距極距赤道之緯度焉</span>  
<span style="margin-left: 1em">恆星經緯度分凡二其一因其以黃道極爲本行之樞</span>  
<span style="margin-left: 2em">每歲東行五十一秒有奇約七十載行一度<sub class="note-yuan">凡二萬五千二</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">百餘年一周天</sub>然其距本極緯度則亙古無變其二因赤道</span>  
<span style="margin-left: 2em">以算其經緯則古今大異其南其北之星位甚有變</span>  
<span style="margin-left: 2em">遷如堯時外屏星全座在赤道南今則盡移于北又</span>  
<span style="margin-left: 2em">角宿古在北今在南多星易其緯如此至以赤道論</span>  
<span style="margin-left: 2em">各宿距度亦有異者如觜宿距星上古爲三度歷代</span>  
<span style="margin-left: 2em">遞減今且侵入參宿二十四分矣他宿互有損益其</span>  
<span style="margin-left: 2em">距度各各不同因知赤極非恆星之極而其經緯之</span>  
<span style="margin-left: 2em">度亦非赤道經緯度分也繇是推之象數理奧屢測</span>  
<span style="margin-left: 2em">彌精乃不學者畫限自封輒謂循古已足豈其然乎</span>  
<span style="margin-left: 1em">恆星循黃道東行近始紹明然古曆謂恆星不動冬至</span>  
<span style="margin-left: 2em">左行是生歲差或謂曆家用此數以爲算兩說咸用</span>  
<span style="margin-left: 2em">之即曰星無本行而冬至春秋二分及黃赤二道並</span>  
<span style="margin-left: 2em">左行亦可即曰冬至及天上諸道無左行惟恆星自</span>  
<span style="margin-left: 2em">行亦可二者皆一年爲五十一秒大要以定歲差爲</span>  
<span style="margin-left: 2em">務耳然以理晰之黃道乃太陽所行之迹赤道乃人</span>  
<span style="margin-left: 2em">所立以齊諸棼雜之行皆非實物何得有行是則治</span>  
<span style="margin-left: 2em">曆者所紀某年冬至在某宿度者非也而第可云某</span>  
<span style="margin-left: 2em">年箕宿初度距冬至幾何度分庶爲得之</span>  
<span style="margin-left: 4em">測太陰<sub class="note-yuan">第二十三章</sub></span>  
<span style="margin-left: 1em">太陰行度所當測定者有五一爲遲疾之限一爲遲疾</span>  
<span style="margin-left: 2em">初末一爲月孛行一爲每日細行一爲交行此數者</span>  
<span style="margin-left: 2em">苟于一測不善必不能齊月離之違合舊曆用表于</span>  
<span style="margin-left: 2em">午正測定三景以求之法與冬至測太陽同然方之</span>  
<span style="margin-left: 2em">太陽倍爲囏劇必四越歲而始得一次測驗之時至</span>  
<span style="margin-left: 2em">九載而後推定此其役心難事良亦拙矣又況月恆</span>  
<span style="margin-left: 2em">有炁差時差<sub class="note-yuan">即地半徑差所生</sub>故所測之經緯度分于正度</span>  
<span style="margin-left: 2em">分復有相較此所以測月之法于七政中尤爲不易</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 1em">新法測月用三會食推算其法以食甚正對太陽即可</span>  
<span style="margin-left: 2em">簡知月之經度因食甚分秒又可知距交若干因各</span>  
<span style="margin-left: 2em">食之中積時日刻數不等乃知天上所行度分亦不</span>  
<span style="margin-left: 2em">等于是用本法以求月天之孛或最高<sub class="note-yuan">亦即極遲之行</sub>亦遂</span>  
<span style="margin-left: 2em">得平視二行相較之度斯乃以極簡御極繁之法也</span>  
<span style="margin-left: 2em">如欲免測驗即再擇三會食重算而又可得之</span>  
<span style="margin-left: 1em">測太陰二弦經度亦有本法蓋弦者乃太陰實距太陽</span>  
<span style="margin-left: 2em">或東或西九十度即周天四分之一也以本儀測定</span>  
<span style="margin-left: 2em">次用法算其平行然其加分推算者與測候者殊不</span>  
<span style="margin-left: 2em">合其較爲二度餘諸表名爲二三均數若于近二至</span>  
<span style="margin-left: 2em">測月弦更便蓋緣彼時在午無時差也</span>  
<span style="margin-left: 1em">又弦時測其去離南北亦與推算不合亦較天度差四</span>  
<span style="margin-left: 2em">分之一蓋白道斜交黃道其相距度分各爲廣狹不</span>  
<span style="margin-left: 2em">同也</span>  
<span style="margin-left: 1em">月掩食恆星測其出入亦可以知月離度分然先當以</span>  
<span style="margin-left: 2em">地半徑差均之</span>  
<span style="margin-left: 3em">測五緯<sub class="note-yuan">第二十四章</sub></span>  
<span style="margin-left: 1em">上三星爲土爲木爲火皆能與太陽相衝相會然于衝</span>  
<span style="margin-left: 2em">會二時各星皆無歲行加減分矣蓋緣會太陽即在</span>  
<span style="margin-left: 2em">歲行圈之最高而衝之即在其最低其于實行爲合</span>  
<span style="margin-left: 2em">也夫實行與平行不同平行百千斯年爲均故各星</span>  
<span style="margin-left: 2em">本天各自有其遲其疾<sub class="note-yuan">即最高最低</sub>然而星合太陽則無</span>  
<span style="margin-left: 2em">從測每于其衝三測之<sub class="note-yuan">測其正對太陽用恆星各經度及太陽躔度以推算</sub>得</span>  
<span style="margin-left: 2em">此三衝經度即有中積天度日數及本星隨日數之</span>  
<span style="margin-left: 2em">平行而後用此三率以求各星本天最高之所于是</span>  
<span style="margin-left: 2em">又得其嬴縮大差亦遂因而得三衝時各星以平行</span>  
<span style="margin-left: 2em">距冬至之界若干矣此三星惟熒惑之行更異是以</span>  
<span style="margin-left: 2em">古謂其句己而行也</span>  
<span style="margin-left: 1em">下二星爲金爲水測之似乎較難因其不能衝太陽也</span>  
<span style="margin-left: 2em">其測法第于或晨或昏求其與太陽距度如是者數</span>  
<span style="margin-left: 2em">四然後依法測算即可得其本天之諸情</span>  
<span style="margin-left: 1em">歲行之測以二留爲本夫二留之限各星不同即其所</span>  
<span style="margin-left: 2em">躔天度亦不同然星在二留非衝太陽乃折中之度</span>  
<span style="margin-left: 2em">故本之以測歲行也下二星亦然</span>  
<span style="margin-left: 1em">新法測候諸星各有本儀然其外爲法甚多如繪圖如</span>  
<span style="margin-left: 2em">簡儀如句股三角形等類因備有此多法故隨時咸</span>  
<span style="margin-left: 2em">可測之</span>  
<span style="margin-left: 1em">五星之天五重皆斜交于黃道如白道然但其相距之</span>  
<span style="margin-left: 2em">緯各有多寡不等又彼之交行右旋而此則皆左旋</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 1em">凡五緯不論其行度第若星體在于黃道下而無緯度</span>  
<span style="margin-left: 2em">分則其實行經度必在本天交上也用黃赤全儀可</span>  
<span style="margin-left: 2em">得之又二留之際因無歲圈緯度故可得其本天之</span>  
<span style="margin-left: 2em">緯其或在日之衝距緯極遠又可以得歲圈本緯焉</span>  
<span style="margin-left: 1em">古不測五星緯度即其測經或用表或用望筩然星之</span>  
<span style="margin-left: 2em">光最微胡然而可得哉若夫用赤道儀以測則又大</span>  
<span style="margin-left: 2em">謬之甚者矣</span>  
<span style="margin-left: 3em">測時晷<sub class="note-yuan">第二十五章</sub></span>  
<span style="margin-left: 1em">日月薄食會合五星凌歷犯守此其期刻于何取準爰</span>  
<span style="margin-left: 2em">是作器厥名時晷乃古法不分方土第用時牌揆景</span>  
<span style="margin-left: 2em">以定然則大地之廣豈其時皆合一故新法之創斯</span>  
<span style="margin-left: 2em">器也必預定各方北極出地之度隨在隨處以至垣</span>  
<span style="margin-left: 2em">壁正側咸可制造或用羅鍼或可不用且又能于一</span>  
<span style="margin-left: 2em">晷之面視太陽所躔節氣宮次度分及定日之高度</span>  
<span style="margin-left: 2em">定黃道各時出沒其稱最者則地平晷立晷百游晷</span>  
<span style="margin-left: 2em">通光晷等數種他若柱晷瓦晷碗晷十字晷等或正</span>  
<span style="margin-left: 2em">或欹之類其異製誠不翅數十而外復有星晷及測</span>  
<span style="margin-left: 2em">月之器以爲夜中測時之需云</span>  
<span style="margin-left: 1em">風雨晦冥無日月諸星照臨於是有自鳴鐘沙水等漏</span>  
<span style="margin-left: 2em">之製然古亦有壺漏與新式異古式以水入壺而時</span>  
<span style="margin-left: 2em">箭浮新製以水出而時牌轉此則不開孔于壺體其</span>

<span style="margin-left: 2em">端偏西爲四度餘</span>

<span style="margin-left: 2em">即高起二三度暨及午時其高不過數分矣是曷爲</span>

<span style="margin-left: 4em">新舊二法疎密之徵<sub class="note-yuan">第二十六章</sub></span>  
<span style="margin-left: 1em">曆象授時古今要典茲值　　聖明特命革正緣其乖</span>  
<span style="margin-left: 2em">迕之徵已著也然其中有舉目可覿者亦有必需儀</span>  
<span style="margin-left: 2em">測者今列其最舛之條如左</span>  
<span style="margin-left: 1em">日食分秒九服各異在昔類能言之今兹不第不能推</span>  
<span style="margin-left: 2em">各方之異且併京都見食之分數多寡虧伏初終靡</span>  
<span style="margin-left: 2em">不咸忒矣月食亦然其方向亦皆恆舛祖述授時曆</span>  
<span style="margin-left: 2em">者亦曾言及也</span>  
<span style="margin-left: 1em">日躔節氣皆先後差錯數刻亦有差至一二日者用儀</span>  
<span style="margin-left: 2em">測可知之</span>

<span style="margin-left: 2em">莫能合天邢觀察律曆考亦辨其非第無術爲之更</span>  
<span style="margin-left: 2em">定耳</span>  
<span style="margin-left: 1em">月上下弦或有先後舛一日者晨昏宿度以器求之亦</span>  
<span style="margin-left: 2em">差二三度</span>  
<span style="margin-left: 1em">諸曜入某宮次皆有差至七八度若計日算因各曜行</span>  
<span style="margin-left: 2em">遲疾日數不等或有差至數十日者</span>  
<span style="margin-left: 1em">五星經度入宿亦恆乖違一二度若計日則或十日或</span>  
<span style="margin-left: 2em">半月餘不等</span>  
<span style="margin-left: 1em">五星伏見尤其舛甚今據所推或謂當見而實不見或</span>  
<span style="margin-left: 2em">謂當伏而實未嘗伏或先後錯至一句二旬甚且朞</span>

<span style="margin-left: 1em">五星相會之期于天有差數日</span>  
<span style="margin-left: 1em">二十八宿距度其中于天度有大有小故亦有紊亂一</span>  
<span style="margin-left: 2em">二三度者</span>  
<span style="margin-left: 1em">諸經星距極之度盡不合天舊星圖之宿座亦皆有增</span>  
<span style="margin-left: 2em">有減上皆事驗之最昭皙者而尚惟古是循也合乎</span>  
<span style="margin-left: 2em">哉</span>  
<span style="margin-left: 3em">訂正古法<sub class="note-yuan">第二十七章</sub></span>  
<span style="margin-left: 1em">曆家所定率策諸款極瑣極繁即如推一交食必資三</span>  
<span style="margin-left: 2em">四十條爲用其算五星爲數亦多或稍有差忒而欲</span>  
<span style="margin-left: 2em">求詳明必至困于無術矣豈其誠無術以窮歟良由</span>  
<span style="margin-left: 2em">其不能探本遡源不晰周天諸行度數所以然之理</span>  
<span style="margin-left: 2em">而第稟成法成表故耳茲亦聊舉其用法乖謬之槩</span>  
<span style="margin-left: 2em">其他所當釐正者雖多然皆散見于曆書全帙中故</span>  
<span style="margin-left: 2em">不復再爲贅云</span>  
<span style="margin-left: 1em">一測列宿五星之經緯度用赤道儀實與天行不類蓋</span>  
<span style="margin-left: 2em">恆星以黃極爲樞而太陰五星雖皆各有本道然亦</span>  
<span style="margin-left: 2em">出入于黃道表裏今用赤道儀測之是其度非本極</span>  
<span style="margin-left: 2em">所出矣于術母乃遠乎測其緯亦然否則必不能攷</span>  
<span style="margin-left: 2em">其真度兩儀相較其差約五六度不等今新法所以</span>  
<span style="margin-left: 2em">用黃道儀</span>  
<span style="margin-left: 1em">一推算七政之各嬴縮及其加減損益分等用平立定</span>  
<span style="margin-left: 2em">三差法是以訛謬緣厥法皆從勾股形平面撰造詎</span>  
<span style="margin-left: 2em">能諧合于天之圜體哉今新法用天弧三角形算</span>  
<span style="margin-left: 1em">一日月及地景之徑度不審高庳分其小大恆定爲一</span>  
<span style="margin-left: 2em">今按月徑度上下差四分半地景徑差二分日亦差</span>  
<span style="margin-left: 2em">一分餘此所以推步交食秒分恆必乖違也本曆悉</span>  
<span style="margin-left: 2em">爲改正</span>  
<span style="margin-left: 1em">一日月五星諸應失天益遠如太陽之氣應乃平行之</span>  
<span style="margin-left: 2em">應而非實行蓋測者得實行之應而算者必需平行</span>  
<span style="margin-left: 2em">也二者不分胡能無舛</span>  
<span style="margin-left: 1em">一十二宮之表乃古曆所定今星東行十餘度而此表</span>  
<span style="margin-left: 2em">應改</span>  
<span style="margin-left: 1em">一五星之合伏留退大統咸律爲一定之日段繇其不</span>  
<span style="margin-left: 2em">諳緯行及小輪之理以故不能得其凌犯見伏之準</span>  
<span style="margin-left: 2em">率而顧猶且沾沾乎信古疑今也謬矣</span>  
<span style="margin-left: 1em">一交食之時差炁差亦不當例以定率蓋月行遲疾二</span>  
<span style="margin-left: 2em">所不齊也又以午正爲時差之限亦謬不知午正豈</span>  
<span style="margin-left: 2em">黃道之中限乎</span>  
<span style="margin-left: 1em">一諸法皆爲定法第可用于京都他方之交食分秒時</span>  
<span style="margin-left: 2em">刻細行等類皆不能變通而推算新曆推算別方各</span>
