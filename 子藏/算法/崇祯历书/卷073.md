<span style="margin-left: 2em">界说<sub class="note-yuan">第一章</sub></span>  
<span style="margin-left: 1em">七政凌犯历家恒言顾有所以然之理未明其理未透</span>  
<span style="margin-left: 2em">其根则测与算难相符合惟明其所以然则先推后</span>  
<span style="margin-left: 2em">测无弗合者盖七政之行有迟疾不等是以后先参</span>  
<span style="margin-left: 2em">错其所呈象约有五种作界说</span>  
<span style="margin-left: 1em">一会聚界</span>  
<span style="margin-left: 2em">会聚者是彼此两曜在黄道上同经度若月于太阳</span>  
<span style="margin-left: 2em">曰朔星于太阳曰合伏星于星曰凌曰犯<sub class="note-yuan">古占法二星相距七</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">寸内曰犯二星光相切曰凌</sub>若经纬度俱同在日月曰食星于星</span>  
<span style="margin-left: 2em">或月于星曰掩<sub class="note-yuan">同经度有二或同黄道或同赤道在赤道同度谓之同升此谓同度第指</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">黄道言也</sub></span>  
<span style="margin-left: 1em">二对照界</span>  
<span style="margin-left: 2em">对照者乃相距天周之半为经度一百八十度月对</span>  
<span style="margin-left: 2em">日曰望经纬俱对曰月食星对日曰夕退统名曰冲</span>  
<span style="margin-left: 2em">照<sub class="note-yuan">月与土木火三星皆能于日对照亦能各相对照金水二星不然盖其不离日之左右故于日不对</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">照亦不相对照</sub></span>  
<span style="margin-left: 1em">三方照界</span>  
<span style="margin-left: 2em">方照者相距天周四之一即九十度也月距日曰上</span>  
<span style="margin-left: 2em">下弦<sub class="note-yuan">其象如弓中明晦之界如弦</sub>他曜相距统名曰方照</span>  
<span style="margin-left: 1em">四隅照界</span>  
<span style="margin-left: 2em">隅照者相距天周三之一乃一百二十度也亦名三</span>  
<span style="margin-left: 2em">角形照</span>  
<span style="margin-left: 1em">五六合照界</span>  
<span style="margin-left: 2em">六合照者乃相距天周六之一即六十度也</span>  
<span style="margin-left: 2em">以上诸照视诸曜之性情或相益或相损或相胜或</span>  
<span style="margin-left: 2em">相和象悬于天而宇下征验因之历家所算尤不可</span>  
<span style="margin-left: 2em">爽也</span>  
<span style="margin-left: 1em">五照图说</span>  
<span style="margin-left: 10em">周圈为黄道各分其照之界以</span>  
<span style="margin-left: 10em">相距之度著其名而照有先后</span>  
<span style="margin-left: 10em">先者顺天数后者逆天数</span>  
<span style="margin-left: 2em">诸曜伏见说<sub class="note-yuan">第二章</sub></span>  
<span style="margin-left: 1em">凡星会太阳时太阳光大胜于星光人目不能见星故</span>  
<span style="margin-left: 2em">曰伏</span>  
<span style="margin-left: 1em">夕伏者星比太阳行迟合后太阳故夕初伏不见亦名</span>  
<span style="margin-left: 2em">西伏如土木火三星及金水二星逆行之时</span>  
<span style="margin-left: 1em">晨伏者星比太阳行疾合先太阳故晨初伏不见亦名</span>

<span style="margin-left: 2em">迟行无限盖迟则不行而留今须求疾迟逆一日之</span>  
<span style="margin-left: 2em">行若干始可攷其凌犯之自也</span>

<span style="margin-left: 2em">有实节气平节气者为十五日有奇乃平分岁周二</span>  
<span style="margin-left: 2em">十四分之一分也实节气者乃天上太阳所行之节</span>  
<span style="margin-left: 2em">以天周三百六十度作二十四平分各得十五度<sub class="note-yuan">平节</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">气谓之地节气实节气谓之天节气</sub>然太阳行此十五度冬夏日数不</span>  
<span style="margin-left: 2em">同冬月约十四日十六时夏月十五日又十九时是</span>  
<span style="margin-left: 2em">岁周二十四分有盈有缩此测太阳在天之行实节</span>  
<span style="margin-left: 2em">气日不得平分也</span>  
<span style="margin-left: 1em">问闰月如何曰无宫次之月是闰月天上十二宫为一</span>  
<span style="margin-left: 2em">年十二月各月有定宫次如冬至在星纪宫为十一</span>  
<span style="margin-left: 2em">月之中节大寒在玄枵宫为十二月之中节若一月</span>  
<span style="margin-left: 2em">之中积内太阳无入宫次谓之闰</span>  
<span style="margin-left: 1em">系若用实节气以定闰月则夏时多冬时少盖冬至二</span>  
<span style="margin-left: 2em">十九日三十二刻太阳行一宫此数于二朔之小中</span>  
<span style="margin-left: 2em">积相近夏至太阳约三十一日行一宫比二朔之大</span>  
<span style="margin-left: 2em">中积更多其中有二朔盖合朔大数不过二十九日</span>  
<span style="margin-left: 2em">八十余刻也</span>
