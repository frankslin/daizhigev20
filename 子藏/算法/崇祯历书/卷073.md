<span style="margin-left: 2em">界說<sub class="note-yuan">第一章</sub></span>  
<span style="margin-left: 1em">七政凌犯曆家恆言顧有所以然之理未明其理未透</span>  
<span style="margin-left: 2em">其根則測與算難相符合惟明其所以然則先推後</span>  
<span style="margin-left: 2em">測無弗合者蓋七政之行有遲疾不等是以後先參</span>  
<span style="margin-left: 2em">錯其所呈象約有五種作界說</span>  
<span style="margin-left: 1em">一會聚界</span>  
<span style="margin-left: 2em">會聚者是彼此兩曜在黃道上同經度若月于太陽</span>  
<span style="margin-left: 2em">曰朔星于太陽曰合伏星于星曰凌曰犯<sub class="note-yuan">古占法二星相距七</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">寸內曰犯二星光相切曰凌</sub>若經緯度俱同在日月曰食星于星</span>  
<span style="margin-left: 2em">或月于星曰掩<sub class="note-yuan">同經度有二或同黃道或同赤道在赤道同度謂之同升此謂同度第指</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">黃道言也</sub></span>  
<span style="margin-left: 1em">二對照界</span>  
<span style="margin-left: 2em">對照者乃相距天周之半爲經度一百八十度月對</span>  
<span style="margin-left: 2em">日曰望經緯俱對曰月食星對日曰夕退統名曰衝</span>  
<span style="margin-left: 2em">照<sub class="note-yuan">月與土木火三星皆能于日對照亦能各相對照金水二星不然蓋其不離日之左右故于日不對</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">照亦不相對照</sub></span>  
<span style="margin-left: 1em">三方照界</span>  
<span style="margin-left: 2em">方照者相距天周四之一即九十度也月距日曰上</span>  
<span style="margin-left: 2em">下弦<sub class="note-yuan">其象如弓中明晦之界如弦</sub>他曜相距統名曰方照</span>  
<span style="margin-left: 1em">四隅照界</span>  
<span style="margin-left: 2em">隅照者相距天周三之一乃一百二十度也亦名三</span>  
<span style="margin-left: 2em">角形照</span>  
<span style="margin-left: 1em">五六合照界</span>  
<span style="margin-left: 2em">六合照者乃相距天周六之一即六十度也</span>  
<span style="margin-left: 2em">以上諸照視諸曜之性情或相益或相損或相勝或</span>  
<span style="margin-left: 2em">相和象懸于天而宇下徵驗因之曆家所算尤不可</span>  
<span style="margin-left: 2em">爽也</span>  
<span style="margin-left: 1em">五照圖說</span>  
<span style="margin-left: 10em">周圈爲黃道各分其照之界以</span>  
<span style="margin-left: 10em">相距之度著其名而照有先後</span>  
<span style="margin-left: 10em">先者順天數後者逆天數</span>  
<span style="margin-left: 2em">諸曜伏見說<sub class="note-yuan">第二章</sub></span>  
<span style="margin-left: 1em">凡星會太陽時太陽光大勝于星光人目不能見星故</span>  
<span style="margin-left: 2em">曰伏</span>  
<span style="margin-left: 1em">夕伏者星比太陽行遲合後太陽故夕初伏不見亦名</span>  
<span style="margin-left: 2em">西伏如土木火三星及金水二星逆行之時</span>  
<span style="margin-left: 1em">晨伏者星比太陽行疾合先太陽故晨初伏不見亦名</span>  
<span style="margin-left: 2em">東伏<sub class="note-yuan">惟金水二星及月名晨伏上三星非晨伏</sub></span>  
<span style="margin-left: 1em">夕見者星比太陽行疾過合而先行故夕見亦曰西見</span>  
<span style="margin-left: 2em"><sub class="note-yuan">惟金水二星及月名夕見上三星非夕見</sub></span>  
<span style="margin-left: 1em">晨見者星比太陽行遲合後太陽故晨見亦名東見如</span>  
<span style="margin-left: 2em">土木火三星及金水逆行合太陽之後或初見或初</span>  
<span style="margin-left: 2em">不見之限有本篇</span>

<span style="margin-left: 2em">七政遲疾二行論<sub class="note-yuan">第三章</sub></span>  
<span style="margin-left: 1em">日月有遲有疾五星有遲疾兼有順逆星之逆行有限</span>  
<span style="margin-left: 2em">遲行無限蓋遲則不行而留今須求疾遲逆一日之</span>  
<span style="margin-left: 2em">行若干始可攷其凌犯之自也</span>  
<span style="margin-left: 1em">疾者何視行勝平行謂之疾平行勝視行謂之遲逆行</span>  
<span style="margin-left: 2em">實不能言疾蓋退未進之行也或依舊法言謂之疾</span>  
<span style="margin-left: 2em">遲蓋名如意耳</span>  
<span style="margin-left: 1em">大統曆所記有疾初末遲初末等皆從疾遲二行之限</span>  
<span style="margin-left: 2em">而生無他解</span>  
<span style="margin-left: 1em">太陽及諸政之行在本天最高極遲在其衝極疾何者</span>  
<span style="margin-left: 2em">凡物遠見小近見大如太陽一日平行一度此一度</span>  
<span style="margin-left: 2em">近于人目則見大遠則小大小之分在人目之視角</span>  
<span style="margin-left: 2em">或天上所掩之分弧大則近小則遠太陽近則視行</span>  
<span style="margin-left: 2em">多遠則視行少遠者最高也近者最卑也各星加減</span>  
<span style="margin-left: 2em">表俱平與實一度之差置太陽一日平行度爲五十</span>  
<span style="margin-left: 2em">九分八秒廿微求最高卑五十九分得均數若干或</span>  
<span style="margin-left: 2em">加或減于平行在遲疾二行之度太陽無歲輪無次</span>  
<span style="margin-left: 2em">均則以本天均數若足</span>  
<span style="margin-left: 1em">太陰與五星遲疾之行其根有三本天最高卑一也小</span>

<span style="margin-left: 2em">日二十二刻<sub class="note-yuan">兩朔中積爲小</sub>得次朔在甲午日丑時而謂之</span>  
<span style="margin-left: 2em">月大蓋以次朔于同甲故也</span>  
<span style="margin-left: 1em">一所定月大小之法非公法因非從天測乃繇方所而</span>  
<span style="margin-left: 2em">定如順天府首朔在甲子日子正一刻到次朔西安</span>  
<span style="margin-left: 2em">府在癸巳日子初三刻順天府前月爲大西安府爲</span>  
<span style="margin-left: 2em">小<sub class="note-yuan">朔之時刻往西爲少往東爲多</sub></span>  
<span style="margin-left: 1em">一大統法月之大小皆從順天府定今新法亦然蓋以</span>  
<span style="margin-left: 2em">順天府爲推算曆元之地</span>  
<span style="margin-left: 3em">定每月節氣及閏法<sub class="note-yuan">第十七章</sub></span>  
<span style="margin-left: 1em">大統有各月中節具見民曆然節氣有二類有平節氣</span>  
<span style="margin-left: 2em">有實節氣平節氣者爲十五日有奇乃平分歲周二</span>  
<span style="margin-left: 2em">十四分之一分也實節氣者乃天上太陽所行之節</span>  
<span style="margin-left: 2em">以天周三百六十度作二十四平分各得十五度<sub class="note-yuan">平節</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">氣謂之地節氣實節氣謂之天節氣</sub>然太陽行此十五度冬夏日數不</span>  
<span style="margin-left: 2em">同冬月約十四日十六時夏月十五日又十九時是</span>  
<span style="margin-left: 2em">歲周二十四分有盈有縮此測太陽在天之行實節</span>  
<span style="margin-left: 2em">氣日不得平分也</span>  
<span style="margin-left: 1em">問閏月如何曰無宮次之月是閏月天上十二宮爲一</span>  
<span style="margin-left: 2em">年十二月各月有定宮次如冬至在星紀宮爲十一</span>  
<span style="margin-left: 2em">月之中節大寒在玄枵宮爲十二月之中節若一月</span>  
<span style="margin-left: 2em">之中積內太陽無入宮次謂之閏</span>  
<span style="margin-left: 1em">系若用實節氣以定閏月則夏時多冬時少蓋冬至二</span>  
<span style="margin-left: 2em">十九日三十二刻太陽行一宮此數于二朔之小中</span>  
<span style="margin-left: 2em">積相近夏至太陽約三十一日行一宮比二朔之大</span>  
<span style="margin-left: 2em">中積更多其中有二朔蓋合朔大數不過二十九日</span>
