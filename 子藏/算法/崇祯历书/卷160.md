<span style="margin-left: 1em"><sub class="note-yuan">　　　　　　　　　　　　　　　　　　　　孫嗣烈宋可成</sub></span>  
<span style="margin-left: 2em">天文曆法等學舍度與數則授受不能措其辭故量</span>  
<span style="margin-left: 2em">法算法恆相發焉其法種種不襲而器因之各國之</span>  
<span style="margin-left: 2em">法與器大同小異如算法之或以書或以盤珠吾西</span>  
<span style="margin-left: 2em">國猶以爲未盡其妙也近世設立籌法似更超越千</span>  
<span style="margin-left: 2em">古至幾何家用法則籌有所不盡者而量該之不能</span>  
<span style="margin-left: 2em">不藉以爲用今繇幾何六卷六題推顯比例規尺一</span>  
<span style="margin-left: 2em">器其用至廣其法至妙前諸法器不能及之因度用</span>  
<span style="margin-left: 2em">數開閤其尺以規搘度得算最捷或加減或乘除或</span>  
<span style="margin-left: 2em">三率或開方之面與體此尺悉能括之又函表度倒</span>  
<span style="margin-left: 2em">景直景日晷句股弦算五金輕重諸法及百種技藝</span>  
<span style="margin-left: 2em">無不賴之功倍用捷爲造瑪得瑪第嘉最近之津梁</span>  
<span style="margin-left: 2em">也昔在上海曾爲徐宗伯造其尺而未暇譯書今奉</span>  
旨修曆兼用敝庠之法思此小器爲用既廣曷敢祕而不  
<span style="margin-left: 2em">傳第中西文字絕不相同倘因艱澁而輟譯是坐令</span>  
<span style="margin-left: 2em">此器不得其用不甚可惜哉因草創成書請教宗伯</span>  
<span style="margin-left: 2em">此器之倘爲用於世也則潤色之增補之定有其時</span>  
<span style="margin-left: 2em">而谷之不文或見亮於天下後世也矣</span>  
<span style="margin-left: 1em">崇禎庚午仲秋　　　　　遠西羅雅谷識</span>  
<span style="margin-left: 1em">比例規解目錄</span>  
<span style="margin-left: 1em">論度數者其綱領有二一曰量法一曰算法所量所算</span>  
<span style="margin-left: 2em">其節目有四曰點曰線曰面曰體總命之曰幾何之</span>  
<span style="margin-left: 2em">學而其法不出于比例比例法又不出于句股第句</span>  
<span style="margin-left: 2em">股爲正方角而別有等角斜角句股不足盡其理故</span>  
<span style="margin-left: 2em">總名之曰三角形此規名比例者用比例法也器不</span>  
<span style="margin-left: 2em">越咫尺而量法算法若線若面若體若弧矢方圓諸</span>  
<span style="margin-left: 2em">法凡度數所須該括欲盡斯亦奇矣所分諸線篇中</span>  
<span style="margin-left: 2em">稱引之說特其指要各有本法本論未及詳焉若所</span>  
<span style="margin-left: 2em">從出與其致用則三角形之比例而已按幾何原本</span>  
<span style="margin-left: 2em">六卷四題云凡等角三角形其在等角旁之各兩腰</span>  
<span style="margin-left: 2em">線相與爲比例必等而對等角之邊爲相似之邊六</span>  
<span style="margin-left: 2em">題云兩三角形之一角等而對等角旁之各兩邊比</span>  
<span style="margin-left: 7em">例等即兩形爲等角形而對各相似邊</span>  
<span style="margin-left: 7em">之角各等作者因此二題創爲此器今</span>  
<span style="margin-left: 7em">依上圖解之如甲乙丙與丁乙戊大小</span>  
<span style="margin-left: 2em">兩三角形同用乙角即爲等角則甲乙與乙丙之比</span>  
<span style="margin-left: 2em">例若丁乙與乙戊而對等角之邊如甲丙與丁戊爲</span>  
<span style="margin-left: 2em">相似之邊也又顯兩形爲等角形而對各相似邊之</span>  
<span style="margin-left: 2em">角各等也今此規之樞心即乙角兩股即乙甲乙丙</span>  
<span style="margin-left: 2em">兩腰甲丙爲底即與乙丁戊爲等角形而各相當之</span>  
<span style="margin-left: 2em">各角各邊其比例悉等矣任張翕之但取大小兩腰</span>  
<span style="margin-left: 2em">其兩底必相似也或取兩底其兩腰必相似也或取</span>  
<span style="margin-left: 2em">此腰此底其與彼腰彼底必相似也以數明之如甲</span>  
<span style="margin-left: 2em">乙大腰一百乙丁小腰六十而設甲丙大底八十以</span>  
<span style="margin-left: 2em">求小底丁戊即定尺用規器量取丁戊爲度向平分</span>  
<span style="margin-left: 2em">線取數必四十八不煩乘除矣又如平方積一萬其</span>  
<span style="margin-left: 2em">根一百求作別方爲大方四之三即以一百爲腰分</span>  
<span style="margin-left: 2em">面線之四點爲大底次以三點爲小腰取小底爲度</span>  
<span style="margin-left: 2em">向平分線得八十六半強爲小方根自之約得七千</span>  
<span style="margin-left: 2em">五百爲小方積不煩開平方矣又如立方積八千其</span>  
<span style="margin-left: 2em">根二十求作大方倍元方即以二十爲小底分體線</span>  
<span style="margin-left: 2em">之一點爲小腰次以二點爲大腰取大底爲度于平</span>  
<span style="margin-left: 2em">分線得二十五半自之再自之約得一萬六千爲大</span>  
<span style="margin-left: 2em">方積不煩開立方矣篇中言某爲腰某爲底設某數</span>  
<span style="margin-left: 2em">得某數皆此類也規凡二面面五線共十線其目如</span>

<span style="margin-left: 2em">右比例十類之外依幾何原本其法甚多因一器難</span>  
<span style="margin-left: 2em">容多線故止設十線其不爲恆用者姑置之稍廣焉</span>  
<span style="margin-left: 2em">更具四法如左</span>  
<span style="margin-left: 2em">一平面形之邊與其積</span>  
<span style="margin-left: 2em">二有形五體之邊與其積與其面</span>  
<span style="margin-left: 2em">三有法五體與球或內或外兩相容</span>  
<span style="margin-left: 2em">四隨地造日晷求其節氣</span>  
<span style="margin-left: 1em">比例規造法<sub class="note-yuan">一名度數尺其式有二</sub></span>  
<span style="margin-left: 1em">一以薄銅板或厚紙作兩長股如圖任長一尺上下廣</span>  
<span style="margin-left: 2em">如長八之一兩股等長等廣股首上角爲樞以樞心</span>  
<span style="margin-left: 2em">爲心從心出各直線以尺大小定線數今折中作五</span>  
<span style="margin-left: 2em">線兩股之面共十線可用十種比例之法線行相距</span>  
<span style="margin-left: 2em">之地取足書字而止尺首半規餘地以固樞也用時</span>  
<span style="margin-left: 2em">張翕游移</span>  
<span style="margin-left: 1em">一以銅或堅木作兩股如圖厚一分以上長任意股上</span>  
<span style="margin-left: 2em">兩用之際以爲心規餘地以安樞其一規面與尺面</span>  
<span style="margin-left: 2em">平而空其中其一剡規而入于彼尺之空令密無罅</span>  
<span style="margin-left: 2em">也樞欲其無偏也兩尺並欲其無罅也樞心爲心與</span>  
<span style="margin-left: 2em">兩尺之合線欲其中繩也用則張翕游移之張盡令</span>  
<span style="margin-left: 2em">兩首相就成一直線可作長尺或以兩半直角相就</span>  
<span style="margin-left: 2em">成一直角可作矩尺</span>  
<span style="margin-left: 2em">比例規之類別有二種一爲四銳定心規一爲四銳</span>  
<span style="margin-left: 2em">百游規不解之其造法頗難爲用未廣姑置之<sub class="note-jiao">校：第四圖</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">奎章閣本闕底本漶漫據清本補</sub></span>  
<span style="margin-left: 1em">比例規解</span>  
<span style="margin-left: 1em">第一平分線</span>  
<span style="margin-left: 2em">分法　此線平分爲一百或二百乃至一千量尺之</span>  
<span style="margin-left: 2em">大小也分法如取一百先平分之爲二又平分爲四</span>  
<span style="margin-left: 2em">又各五分之爲二十自此以上不容分矣則用更分</span>  
<span style="margin-left: 2em">法以元分四復五分之或以元分六復五分之如上</span>  
<span style="margin-left: 2em">圖甲乙線分丙丁戊爲元分之四今更五分之得己</span>  
<span style="margin-left: 4em">庚辛壬元分與次分之較爲壬丙爲戊己皆甲</span>  
<span style="margin-left: 4em">乙二十分之一爲元分五之一<sub class="note-yuan">每數至十至百各書字識之</sub></span>  
<span style="margin-left: 4em">論曰甲乙<sub class="note-yuan">四</sub>與甲丙<sub class="note-yuan">一</sub>若甲己<sub class="note-yuan">四</sub>與甲壬<sub class="note-yuan">一</sub>更</span>  
<span style="margin-left: 2em">之甲乙<sub class="note-yuan">四</sub>與甲己<sub class="note-yuan">四</sub>若甲丙<sub class="note-yuan">一</sub>與甲壬<sub class="note-yuan">一</sub>甲己爲甲</span>  
<span style="margin-left: 2em">乙五之四即甲壬爲甲丙五之四壬丙爲甲丙五之</span>  
<span style="margin-left: 2em">一又甲丁爲十甲辛爲八辛丁爲甲丁十之二或丙</span>  
<span style="margin-left: 2em">丁五之二戊庚爲丁戊五之三又壬丙爲甲丙五之</span>  
<span style="margin-left: 2em">一必爲甲壬四之一<sub class="note-yuan">幾何五卷</sub></span>  
<span style="margin-left: 2em">用法一　凡設一直線任欲作幾分假如四分即以</span>  
<span style="margin-left: 2em">設線爲度數兩尺之各一百以爲腰張尺以就度令</span>  
<span style="margin-left: 2em">設線度爲兩腰之底置尺數兩尺之各二十五以爲</span>  
<span style="margin-left: 2em">腰斂規取二十五兩點間之度以爲底向線上簡得</span>  
<span style="margin-left: 2em">若干數即所求分數　凡言線者皆直線依幾何原</span>  
<span style="margin-left: 2em">本大小兩三角形之比例則二十五與得線若一百</span>  
<span style="margin-left: 2em">與設線也更之二十五與一百得線與設線皆若一</span>  
<span style="margin-left: 2em">與四也　若求極微分如一百之一如上以一百爲</span>  
<span style="margin-left: 2em">腰設線爲底置尺次以九十九爲腰取底比設線其</span>  
<span style="margin-left: 2em">較爲百之一　若欲設線內取零數如七之三即以</span>  
<span style="margin-left: 2em">七十爲腰設線爲底置尺次以三十爲腰斂規取底</span>  
<span style="margin-left: 2em">即設線七之三<sub class="note-yuan">置尺者置不復動下倣此</sub></span>  
<span style="margin-left: 2em">用法二　凡有線求幾倍之以十爲腰設線爲底置</span>  
<span style="margin-left: 2em">尺如求七倍以七十爲腰取底即元線之七倍若求</span>  
<span style="margin-left: 2em">十四倍則倍得線或先取十倍更取四倍并之</span>  
<span style="margin-left: 2em">用法三　有兩直線欲定其比例以大線爲尺末之</span>  
<span style="margin-left: 2em">數<sub class="note-yuan">尺百即百千即千</sub>置尺斂規取小線度於尺上進退就其</span>  
<span style="margin-left: 2em">等數如大線爲一百小線爲三十七即兩線之比例</span>  
<span style="margin-left: 2em">若一百與三十七可約者約之<sub class="note-yuan">約法以兩大數約爲兩小數其比例不異</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">如一百與三十約爲十與三</sub></span>  
<span style="margin-left: 2em">用法四　乘法與倍法相通<sub class="note-yuan">乘者求設數</sub>如以七乘</span>  
<span style="margin-left: 5em">　<sub class="note-yuan">之幾倍也</sub></span>  
<span style="margin-left: 2em">十三于腰線取十三爲度七倍之即所求數也</span>  
<span style="margin-left: 2em">用法五　設兩線或兩數<sub class="note-yuan">凡言數者腰上取其分或</sub></span>  
<span style="margin-left: 5em">　<sub class="note-yuan">以數變爲線或以線變爲</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">數</sub>欲求一直線而與元設兩線爲連比例　若設大</span>  
<span style="margin-left: 2em">求小則以大設爲兩腰中設爲底次以中設爲兩腰</span>  
<span style="margin-left: 14em">得小底即所求如甲</span>  
<span style="margin-left: 14em">乙甲丙尺之兩腰所</span>  
<span style="margin-left: 14em">設兩數爲三十爲十</span>  
<span style="margin-left: 9em">八欲求其小比例從心向兩腰取</span>  
<span style="margin-left: 9em">三十如甲辛甲己識之斂規取十</span>  
<span style="margin-left: 9em">八爲度以爲底如辛己次從心取</span>  
<span style="margin-left: 9em">十八如甲丁甲戊即丁戊爲連比</span>  
<span style="margin-left: 9em">例之小率得十一有奇　若設小</span>  
<span style="margin-left: 9em">求大則反之以中設爲兩腰小設</span>  
<span style="margin-left: 9em">爲底置尺以中設爲度進求其等</span>  
<span style="margin-left: 2em">數以爲底從底向心得數即所求如甲丁甲戊爲兩</span>  
<span style="margin-left: 2em">腰丁戊爲底次以甲丁爲度引之至辛至己而等從</span>  
<span style="margin-left: 2em">辛從己向心得三十即大率論見幾何六卷十一題</span>  
<span style="margin-left: 2em"><sub class="note-yuan">凡言等數者皆兩腰上縱心取兩數等下同</sub></span>  
<span style="margin-left: 2em">用法六　凡有四率連比例既有三率而求第四或</span>  
<span style="margin-left: 2em">以前求後則丁戊爲第一率辛己甲丁甲戊爲第二</span>  
<span style="margin-left: 2em">又爲第三而得辛甲爲第四　若以後求前則甲辛</span>  
<span style="margin-left: 2em">甲己爲第一辛己甲戊甲丁爲第二又爲第三而得</span>  
<span style="margin-left: 2em">丁戊爲第四<sub class="note-yuan">甲辛與辛己若甲丁與丁戊故也</sub></span>  
<span style="margin-left: 2em">用法七　有斷比例之三率求第四如一星行九日</span>  
<span style="margin-left: 2em">得一十一度今行二十五度日幾何即用三率法以</span>  
<span style="margin-left: 6em">元得一十一度爲兩腰元行九日爲底置</span>  
<span style="margin-left: 6em">尺以二十五度爲兩腰取大底腰上數之</span>  
<span style="margin-left: 6em">得二十日<sub class="note-yuan">十一之五</sub>爲所求日<sub class="note-yuan">此正三率法九章中名異乘同</sub></span>  
<span style="margin-left: 6em"><sub class="note-yuan">除也</sub></span>
