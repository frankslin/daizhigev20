## 崇祯历书卷之十六　顺治奏疏

*顺治元年八月初二日至顺治元年十一月初九日*

<span style="margin-left: 2em">奏疏二</span>  
<span style="margin-left: 9em">顺治元年八月初二日冯铨启本</span>  
<span style="margin-left: 3em">内院大学士臣冯铨谨</span>  
<span style="margin-left: 2em">启臣敬奉</span>  
<span style="margin-left: 1em">王上差遣于本月初一日早率制勅房中书李正茂诣</span>  
<span style="margin-left: 3em">观象台督监局官生测验日食深维</span>  
<span style="margin-left: 2em">国家新定宝历祈</span>  
天永命迓亿万年无疆之休非寻常比因与远臣汤若望  
<span style="margin-left: 3em">钦天监正戈承科等及回回历官吴明炫约矢公</span>  
<span style="margin-left: 3em">矢慎勿执成心勿泥已见一以</span>  
天行为准遂将台上璇玑玉衡及远臣新法仪器对正妥  
<span style="margin-left: 3em">当复调理刻漏如法依该监旧法候至巳正一刻</span>  
<span style="margin-left: 3em">全无形迹过正二正三正四巳时已完直至午初</span>  
<span style="margin-left: 3em">初刻半弱日果如时宪历新法从西南食起臣率</span>  
<span style="margin-left: 3em">众官即于台上行礼候至午正一刻强以筒影观</span>  
<span style="margin-left: 3em">之果食甚三分臣令中书李正茂从纸扇孔内仰</span>  
<span style="margin-left: 3em">观其食处在正南稍西臣因取家藏紫色眼镜再</span>  
<span style="margin-left: 3em">观已稍转东可见扇孔不如眼镜之真而食甚之</span>  
<span style="margin-left: 3em">在正南无可疑也未初二刻转东南复圆一如新</span>  
<span style="margin-left: 3em">法所算毫无差谬臣复率众官行礼毕若依回回</span>  
<span style="margin-left: 3em">历法推算则午正一刻食甚之时方应如亏讹舛</span>  
<span style="margin-left: 3em">殊甚详询回回历官吴明炫无以置对盖相传之</span>  
<span style="margin-left: 3em">法如此非本官疎误也总之时宪历法尽善尽美</span>  
<span style="margin-left: 3em">即局监诸臣无不众口一词服其精确依此法治</span>  
<span style="margin-left: 3em">历明时真可仰副</span>  
<span style="margin-left: 1em">朝廷敬</span>  
天勤民之盛心矣内院见有进到西洋仪器臣初登台时  
<span style="margin-left: 3em">即令局官朱光大赴院伺候安置谅同官诸臣定</span>  
<span style="margin-left: 3em">已详察而朝臣俱在礼部救护该部亦设有仪晷</span>  
<span style="margin-left: 3em">必皆灼见伏乞</span>  
<span style="margin-left: 1em">睿鉴下部再加考订如果臣言不爽见今造历宜定以</span>  
<span style="margin-left: 3em">新法为则此诚开</span>  
天立极第一要务也本日差回理应具  
<span style="margin-left: 2em">启报</span>  
<span style="margin-left: 1em">命今将新法旧法回回历法日食时刻分秒三图进呈</span>  
<span style="margin-left: 1em">上覧臣谨</span>  
<span style="margin-left: 2em">启八月初二日启初七日奉</span>  
<span style="margin-left: 1em">令旨覧卿本知远臣汤若望所用西洋新法测验日食</span>  
<span style="margin-left: 2em">时刻分秒方位一一精确密合</span>  
天行尽善尽美见今定造时宪新历颁行天下宜悉依此  
<span style="margin-left: 2em">法为准以钦崇</span>  
天道敬授人时该监旧法岁久自差非由各官推算之误  
<span style="margin-left: 2em">以后都着精习新法不得怠玩礼部知道</span>  
<span style="margin-left: 8em">顺治元年八月初八日汤若望奏本</span>  
<span style="margin-left: 3em">修政历法臣汤若望谨</span>  
<span style="margin-left: 2em">奏为恭</span>  
<span style="margin-left: 1em">报测验日食事该臣于六月二十二日报称本局依西</span>  
<span style="margin-left: 3em">洋新法椎算得本年八月初一日丙辰朔</span>  
<span style="margin-left: 2em">京师顺天府日食三分弱初亏午初初刻半弱西南</span>  
<span style="margin-left: 3em">食甚午正一刻强正南复圆未初二刻东南等因</span>  
<span style="margin-left: 3em">具</span>  
<span style="margin-left: 2em">奏奉有这本内日食分秒时刻起复方位并各省直</span>  
<span style="margin-left: 3em">见食有多寡先后不同具见推测详审俟先期二</span>  
<span style="margin-left: 3em">日来说以便遣官公同测验之</span>  
<span style="margin-left: 1em">旨复于先期奏</span>  
<span style="margin-left: 1em">报又奉有汤若望照例携带仪器前赴观象台如法测</span>  
<span style="margin-left: 3em">验之</span>  
<span style="margin-left: 1em">旨敬此敬遵是日大学士冯铨督同局监官生齐赴观</span>  
<span style="margin-left: 3em">象台臣若望亦携远镜并黄赤全仪及台上简仪</span>  
<span style="margin-left: 3em">等器悉心觇候其初亏食甚复圆时刻分秒及方</span>  
<span style="margin-left: 3em">位等项测之一一俱与臣法密合其该监所推大</span>  
<span style="margin-left: 3em">统回回两法俱各疎远此大学士逐刻登记众皆</span>  
<span style="margin-left: 3em">心悦诚服悉听大学士具</span>  
<span style="margin-left: 2em">题外至于</span>  
<span style="margin-left: 2em">内院觇测则有本局供事经历朱光大听大学士公</span>  
<span style="margin-left: 3em">同如法窥验随于日食分秒图后批称中堂公同</span>  
<span style="margin-left: 3em">用仪器测验大统历差有一半回回历差有一个</span>  
<span style="margin-left: 3em">时辰惟西洋新法分秒时刻纎忽不差以明朝二</span>  
<span style="margin-left: 3em">十年未及行之新法</span>  
<span style="margin-left: 1em">大清朝以数日间行之一试验而合若符节可谓奇矣</span>  
<span style="margin-left: 3em">着用心精造新历以为万年法传等语而历局觇</span>  
<span style="margin-left: 3em">测则有本局供事署正黄宏宪及生儒掌乘徐瑍</span>  
<span style="margin-left: 3em">等公同如法窥验各各俱与新法脗合此新旧各</span>  
<span style="margin-left: 3em">法疎密自见无庸微臣凟赘者也缘系测验日食</span>  
<span style="margin-left: 3em">事理理合据实回奏为此具本谨具</span>  
<span style="margin-left: 2em">奏</span>  
<span style="margin-left: 1em">闻</span>  
<span style="margin-left: 3em">顺治元年八月初二日上初八日奉</span>  
<span style="margin-left: 1em">令旨据报知内院诸臣依新法测验日食纎忽不差与</span>  
<span style="margin-left: 2em">观象台公同测验无异具见精密汤若望即督率监</span>  
<span style="margin-left: 2em">局官生用心精造新法以传永久礼部知道</span>  
<span style="margin-left: 8em">顺治元年八月十五日汤若望奏本</span>  
<span style="margin-left: 3em">修政历法臣汤若望谨</span>  
<span style="margin-left: 2em">奏为请给新历供费以便推算速竣兼陈本局要务</span>  
<span style="margin-left: 3em">事臣自六月间蒙</span>  
<span style="margin-left: 1em">特旨悉用西洋新法颁行时宪历即率本局官生先推</span>  
<span style="margin-left: 3em">民历每觉其散早聚迟总由各官生城外居住又</span>  
<span style="margin-left: 3em">皆穷苦每日饔飧或就食于市肆或待炊于本家</span>  
<span style="margin-left: 3em">往返奔驰费时失事最为未便因而臣即设处垫</span>  
<span style="margin-left: 3em">用供给并垫纸札绫绢装演等费乃今民历虽完</span>  
<span style="margin-left: 3em">尚有七政躔度纂推正亟功倍于前臣欲再行垫</span>  
<span style="margin-left: 3em">用力又不能虽已两次移行礼部连请补给未见</span>  
<span style="margin-left: 3em">应发守候半月有余推算无由起手至于官生住</span>  
<span style="margin-left: 3em">居臣愚以为历局房屋止有三层大小计十二间</span>  
<span style="margin-left: 3em">极为窄狭今幸局旁尚有空房两处半遭流寇烧</span>  
<span style="margin-left: 3em">毁又无兵丁居住亦且附近臣居可以通连俾官</span>  
<span style="margin-left: 3em">生得以聚处庶于推算缮写等功无误相应一并</span>  
<span style="margin-left: 3em">请给者也他若推算之官旧制列名历尾今铺注</span>  
<span style="margin-left: 3em">神煞者该监止须二人填写两日即毕而例得列</span>  
<span style="margin-left: 3em">名者十一员乃本局推算者勤劳两月列名仅有</span>  
<span style="margin-left: 3em">朱光大宋发二员如顺天生员宋可成副榜监生</span>  
<span style="margin-left: 3em">李祖白儒士掌乘焦应旭此四人者文理优通有</span>  
<span style="margin-left: 3em">志历学访举在局効力多年祗以未蒙授职不便</span>  
<span style="margin-left: 3em">附列其名兹因</span>  
<span style="margin-left: 1em">颁历重典推测缮写劳苦倍常似应</span>  
<span style="margin-left: 1em">勅下吏部查照办历事例对加职衔以便添名历尾其</span>  
<span style="margin-left: 3em">余在局学习供事诸生则有掌有篆徐瑍孙有本</span>  
<span style="margin-left: 3em">张中鹄鲍英齐殷铠武之彦李华宋可立刘蕴德</span>  
<span style="margin-left: 3em">计共十人亦应照天文生例食粮办事以鼓后効</span>  
<span style="margin-left: 3em">如此则前后相继自可传法永久而弗斁也又历</span>  
<span style="margin-left: 3em">局原有看门人役一名书役一名皂隶二名匠役</span>  
<span style="margin-left: 3em">四名因年久历未颁行渐皆散去今令各役复还</span>  
<span style="margin-left: 3em">必得月给米粮庶身无他营而公务自无迟误也</span>  
<span style="margin-left: 3em">以上三欵并前供费房屋二事系目前要务恳乞</span>  
<span style="margin-left: 1em">圣明俯赐</span>  
<span style="margin-left: 1em">俞允勅下该衙门一一遵奉施行则事无推诿而</span>  
<span style="margin-left: 1em">大典克襄矣为此具本谨具奏</span>  
<span style="margin-left: 1em">闻</span>  
<span style="margin-left: 3em">顺治元年八月十一日上十五日奉</span>  
<span style="margin-left: 1em">令旨治历大典官生供费各役月粮既有成例即察明</span>  
<span style="margin-left: 2em">支给局旁空房准作推算缮写之所宋可成等四人</span>  
<span style="margin-left: 2em">量授职衔同朱光大等列民历尾在局诸生照天文</span>  
<span style="margin-left: 2em">生例食粮办事该监各科并回回科官生通晓新法</span>  
<span style="margin-left: 2em">的照旧留用怠惰冒滥的应行裁汰著礼部同礼科</span>  
<span style="margin-left: 2em">官详加考试分别具启内灵台仪器并选历局官生</span>  
<span style="margin-left: 2em">二人典守该衙门知道</span>  
<span style="margin-left: 4em">顺治元年八月二十五日礼部启文</span>  
<span style="margin-left: 3em">礼部</span>  
<span style="margin-left: 2em">启为请给新历供费以便推算速竣兼陈本局要务</span>  
<span style="margin-left: 3em">事祠祭清吏司案呈奉本部送礼科抄出修政历</span>  
<span style="margin-left: 3em">法远臣汤若望启前事等因奉</span>  
<span style="margin-left: 1em">令旨治历大典官生供费各役月粮既有成例即察明</span>  
<span style="margin-left: 2em">支给局旁空房准作推算缮写之所宋可成等四人</span>  
<span style="margin-left: 2em">量授职衔同朱光大等列名历尾在局诸生照天文</span>  
<span style="margin-left: 2em">生例食粮办事该监各科并回回科官生通晓新法</span>  
<span style="margin-left: 2em">的照旧留用怠惰冒滥的应行裁汰礼部同礼科官</span>  
<span style="margin-left: 2em">详加考试分别具奏内灵台见在仪器并选历局官</span>  
<span style="margin-left: 2em">生二人典守该衙门知道敬此又该</span>  
<span style="margin-left: 2em">内院大学士冯铨启二十二日考试钦天监官生等</span>  
<span style="margin-left: 3em">因八月二十一日奉</span>  
<span style="margin-left: 1em">令旨知道了卿亲监历局考试以定去留具见敬慎该</span>  
<span style="margin-left: 2em">部知道敬此敬遵各抄到部送司又据历局手本开</span>  
<span style="margin-left: 3em">送书办吴胜皂隶周于德潘文晓匠役高长春李</span>  
<span style="margin-left: 3em">洪玉李贵芳王三聘门役俞信各花名前来相应</span>  
<span style="margin-left: 3em">具覆通查案呈到部照得修历远臣汤若望所请</span>  
<span style="margin-left: 3em">供费一项案查先经该局进呈历样垫过笔札绫</span>  
<span style="margin-left: 3em">绢装帙工价官生供给等费共银二十两有奇所</span>  
<span style="margin-left: 3em">费为数不多先行补给又称尚有七政躔度等历</span>  
<span style="margin-left: 3em">纂修正亟功倍于前一应公费俟有确数报部再</span>  
<span style="margin-left: 3em">行酌给各役月粮业经该局开送书皂匠役吴胜</span>  
<span style="margin-left: 3em">等八名前来应照各衙门例一体支给局旁空房</span>  
<span style="margin-left: 3em">已行远臣安插住坐为推算缮写之所其生儒宋</span>  
<span style="margin-left: 3em">可成等四人既以効劳有年勒敏可加相应照例</span>  
<span style="margin-left: 3em">量带钦天监博士职衔应同朱光大等附名历尾</span>  
<span style="margin-left: 3em">在局効劳儒士掌有篆等十人今依原启准照天</span>  
<span style="margin-left: 3em">文生例食粮办事内灵台仪器远臣遴委官生着</span>  
<span style="margin-left: 3em">令收掌匙钥管理外其考试一节于本月二十一</span>  
<span style="margin-left: 3em">日未时蒙</span>  
<span style="margin-left: 2em">内院传谕礼部同礼科官于二十二日早先赴历局</span>  
<span style="margin-left: 3em">将钦天监各科官生通行考试分别等次候</span>  
<span style="margin-left: 2em">内院到局议定去留以凭具启请</span>  
<span style="margin-left: 1em">旨定夺等因该本部左侍郎臣李明睿右侍郎臣何瑞</span>  
<span style="margin-left: 3em">征遵即会同礼科给事中臣孟　　署祠祭司事</span>  
<span style="margin-left: 3em">精膳司郎中今复授山东道御史臣寗承勲于二</span>  
<span style="margin-left: 3em">十二日黎明督率钦天监监正戈承科监副贾良</span>  
<span style="margin-left: 3em">栋周胤带领官生潘国祥等到局伺候即蒙</span>  
<span style="margin-left: 2em">内院大学士冯铨亲临考试臣等在局齐集历科等</span>  
<span style="margin-left: 3em">科官潘国祥等四十七员并回回科官吴明炫等</span>  
<span style="margin-left: 3em">五员历科等科天文生朱光荫等三十一名及回</span>  
<span style="margin-left: 3em">回科天文生吴明燿等三名命题考试随据各官</span>  
<span style="margin-left: 3em">生呈称今科各有专司株守一遵成例其于新法</span>  
<span style="margin-left: 3em">除贾良琦刘有庆朱光显三名而外求其熟习精</span>  
<span style="margin-left: 3em">通者盖甚难其人也臣等细诘其由则谓本年八</span>  
<span style="margin-left: 3em">月方奉有精习新法不得怠玩之</span>  
<span style="margin-left: 1em">令旨今学习伊始若非宽限讲求未敢揣摹应试也臣</span>  
<span style="margin-left: 3em">等以为治历明时虽法分新旧然而其人之勤惰</span>  
<span style="margin-left: 3em">与其人之明昧其年之衰壮固可观而知也于是</span>  
<span style="margin-left: 3em">逐名细询或考其推算之异同或察其占验之得</span>
