## 崇禎曆書卷之十六　順治奏疏

*順治元年八月初二日至順治元年十一月初九日*

<span style="margin-left: 2em">奏疏二</span>  
<span style="margin-left: 9em">順治元年八月初二日馮銓啓本</span>  
<span style="margin-left: 3em">內院大學士臣馮銓謹</span>  
<span style="margin-left: 2em">啓臣敬奉</span>  
<span style="margin-left: 1em">王上差遣於本月初一日早率制勅房中書李正茂詣</span>  
<span style="margin-left: 3em">觀象臺督監局官生測驗日食深維</span>  
<span style="margin-left: 2em">國家新定寶曆祈</span>  
天永命迓億萬年無疆之休非尋常比因與遠臣湯若望  
<span style="margin-left: 3em">欽天監正戈承科等及回回曆官吳明炫約矢公</span>  
<span style="margin-left: 3em">矢慎勿執成心勿泥已見一以</span>  
天行爲準遂將臺上璿璣玉衡及遠臣新法儀器對正妥  
<span style="margin-left: 3em">當復調理刻漏如法依該監舊法候至巳正一刻</span>  
<span style="margin-left: 3em">全無形迹過正二正三正四巳時已完直至午初</span>  
<span style="margin-left: 3em">初刻半弱日果如時憲曆新法從西南食起臣率</span>  
<span style="margin-left: 3em">衆官即于臺上行禮候至午正一刻強以筒影觀</span>  
<span style="margin-left: 3em">之果食甚三分臣令中書李正茂從紙扇孔內仰</span>  
<span style="margin-left: 3em">觀其食處在正南稍西臣因取家藏紫色眼鏡再</span>  
<span style="margin-left: 3em">觀已稍轉東可見扇孔不如眼鏡之真而食甚之</span>  
<span style="margin-left: 3em">在正南無可疑也未初二刻轉東南復圓一如新</span>  
<span style="margin-left: 3em">法所算毫無差謬臣復率衆官行禮畢若依回回</span>  
<span style="margin-left: 3em">曆法推算則午正一刻食甚之時方應如虧訛舛</span>  
<span style="margin-left: 3em">殊甚詳詢回回曆官吳明炫無以置對蓋相傳之</span>  
<span style="margin-left: 3em">法如此非本官疎誤也總之時憲曆法盡善盡美</span>  
<span style="margin-left: 3em">即局監諸臣無不衆口一詞服其精確依此法治</span>  
<span style="margin-left: 3em">曆明時真可仰副</span>  
<span style="margin-left: 1em">朝廷敬</span>  
天勤民之盛心矣內院見有進到西洋儀器臣初登臺時  
<span style="margin-left: 3em">即令局官朱光大赴院伺候安置諒同官諸臣定</span>  
<span style="margin-left: 3em">已詳察而朝臣俱在禮部救護該部亦設有儀晷</span>  
<span style="margin-left: 3em">必皆灼見伏乞</span>  
<span style="margin-left: 1em">睿鑒下部再加考訂如果臣言不爽見今造曆宜定以</span>  
<span style="margin-left: 3em">新法爲則此誠開</span>  
天立極第一要務也本日差回理應具  
<span style="margin-left: 2em">啓報</span>  
<span style="margin-left: 1em">命今將新法舊法回回曆法日食時刻分秒三圖進呈</span>  
<span style="margin-left: 1em">上覧臣謹</span>  
<span style="margin-left: 2em">啓八月初二日啓初七日奉</span>  
<span style="margin-left: 1em">令旨覧卿本知遠臣湯若望所用西洋新法測驗日食</span>  
<span style="margin-left: 2em">時刻分秒方位一一精確密合</span>  
天行盡善盡美見今定造時憲新曆頒行天下宜悉依此  
<span style="margin-left: 2em">法爲準以欽崇</span>  
天道敬授人時該監舊法歲久自差非由各官推算之誤  
<span style="margin-left: 2em">以後都着精習新法不得怠玩禮部知道</span>  
<span style="margin-left: 8em">順治元年八月初八日湯若望奏本</span>  
<span style="margin-left: 3em">修政曆法臣湯若望謹</span>  
<span style="margin-left: 2em">奏爲恭</span>  
<span style="margin-left: 1em">報測驗日食事該臣于六月二十二日報稱本局依西</span>  
<span style="margin-left: 3em">洋新法椎算得本年八月初一日丙辰朔</span>  
<span style="margin-left: 2em">京師順天府日食三分弱初虧午初初刻半弱西南</span>  
<span style="margin-left: 3em">食甚午正一刻強正南復圓未初二刻東南等因</span>  
<span style="margin-left: 3em">具</span>  
<span style="margin-left: 2em">奏奉有這本內日食分秒時刻起復方位并各省直</span>  
<span style="margin-left: 3em">見食有多寡先後不同具見推測詳審俟先期二</span>  
<span style="margin-left: 3em">日來說以便遣官公同測驗之</span>  
<span style="margin-left: 1em">旨復于先期奏</span>  
<span style="margin-left: 1em">報又奉有湯若望照例携帶儀器前赴觀象臺如法測</span>  
<span style="margin-left: 3em">驗之</span>  
<span style="margin-left: 1em">旨敬此敬遵是日大學士馮銓督同局監官生齊赴觀</span>  
<span style="margin-left: 3em">象臺臣若望亦携遠鏡并黃赤全儀及臺上簡儀</span>  
<span style="margin-left: 3em">等器悉心覘候其初虧食甚復圓時刻分秒及方</span>  
<span style="margin-left: 3em">位等項測之一一俱與臣法密合其該監所推大</span>  
<span style="margin-left: 3em">統回回兩法俱各疎遠此大學士逐刻登記衆皆</span>  
<span style="margin-left: 3em">心悅誠服悉聽大學士具</span>  
<span style="margin-left: 2em">題外至于</span>  
<span style="margin-left: 2em">內院覘測則有本局供事經歷朱光大聽大學士公</span>  
<span style="margin-left: 3em">同如法窺驗隨于日食分秒圖後批稱中堂公同</span>  
<span style="margin-left: 3em">用儀器測驗大統曆差有一半回回曆差有一個</span>  
<span style="margin-left: 3em">時辰惟西洋新法分秒時刻纎忽不差以明朝二</span>  
<span style="margin-left: 3em">十年未及行之新法</span>  
<span style="margin-left: 1em">大清朝以數日間行之一試驗而合若符節可謂奇矣</span>  
<span style="margin-left: 3em">着用心精造新曆以爲萬年法傳等語而曆局覘</span>  
<span style="margin-left: 3em">測則有本局供事署正黃宏憲及生儒掌乘徐瑍</span>  
<span style="margin-left: 3em">等公同如法窺驗各各俱與新法脗合此新舊各</span>  
<span style="margin-left: 3em">法疎密自見無庸微臣凟贅者也緣係測驗日食</span>  
<span style="margin-left: 3em">事理理合據實回奏爲此具本謹具</span>  
<span style="margin-left: 2em">奏</span>  
<span style="margin-left: 1em">聞</span>  
<span style="margin-left: 3em">順治元年八月初二日上初八日奉</span>  
<span style="margin-left: 1em">令旨據報知內院諸臣依新法測驗日食纎忽不差與</span>  
<span style="margin-left: 2em">觀象臺公同測驗無異具見精密湯若望即督率監</span>  
<span style="margin-left: 2em">局官生用心精造新法以傳永久禮部知道</span>  
<span style="margin-left: 8em">順治元年八月十五日湯若望奏本</span>  
<span style="margin-left: 3em">修政曆法臣湯若望謹</span>  
<span style="margin-left: 2em">奏爲請給新曆供費以便推算速竣兼陳本局要務</span>  
<span style="margin-left: 3em">事臣自六月間蒙</span>  
<span style="margin-left: 1em">特旨悉用西洋新法頒行時憲曆即率本局官生先推</span>  
<span style="margin-left: 3em">民曆每覺其散早聚遲總由各官生城外居住又</span>  
<span style="margin-left: 3em">皆窮苦每日饔飱或就食于市肆或待炊于本家</span>  
<span style="margin-left: 3em">往返奔馳費時失事最爲未便因而臣即設處墊</span>  
<span style="margin-left: 3em">用供給并墊紙劄綾絹裝演等費乃今民曆雖完</span>  
<span style="margin-left: 3em">尚有七政躔度纂推正亟功倍于前臣欲再行垫</span>  
<span style="margin-left: 3em">用力又不能雖已兩次移行禮部連請補給未見</span>  
<span style="margin-left: 3em">應發守候半月有餘推算無由起手至于官生住</span>  
<span style="margin-left: 3em">居臣愚以爲曆局房屋止有三層大小計十二間</span>  
<span style="margin-left: 3em">極爲窄狭今幸局旁尚有空房兩處半遭流寇燒</span>  
<span style="margin-left: 3em">燬又無兵丁居住亦且附近臣居可以通連俾官</span>  
<span style="margin-left: 3em">生得以聚處庶于推算繕寫等功無誤相應一并</span>  
<span style="margin-left: 3em">請給者也他若推算之官舊制列名曆尾今鋪註</span>  
<span style="margin-left: 3em">神煞者該監止須二人填寫兩日即畢而例得列</span>  
<span style="margin-left: 3em">名者十一員乃本局推算者勤勞兩月列名僅有</span>  
<span style="margin-left: 3em">朱光大宋發二員如順天生員宋可成副榜監生</span>  
<span style="margin-left: 3em">李祖白儒士掌乘焦應旭此四人者文理優通有</span>  
<span style="margin-left: 3em">志曆學訪舉在局効力多年祗以未蒙授職不便</span>  
<span style="margin-left: 3em">附列其名茲因</span>  
<span style="margin-left: 1em">頒曆重典推測繕寫勞苦倍常似應</span>  
<span style="margin-left: 1em">勅下吏部查照辦曆事例對加職銜以便添名曆尾其</span>  
<span style="margin-left: 3em">餘在局學習供事諸生則有掌有篆徐瑍孫有本</span>  
<span style="margin-left: 3em">張中鵠鮑英齊殷鎧武之彦李華宋可立劉藴德</span>  
<span style="margin-left: 3em">計共十人亦應照天文生例食糧辦事以鼓後効</span>  
<span style="margin-left: 3em">如此則前後相繼自可傳法永久而弗斁也又曆</span>  
<span style="margin-left: 3em">局原有看門人役一名書役一名皂隸二名匠役</span>  
<span style="margin-left: 3em">四名因年久曆未頒行漸皆散去今令各役復還</span>  
<span style="margin-left: 3em">必得月給米糧庶身無他營而公務自無遲誤也</span>  
<span style="margin-left: 3em">以上三欵并前供費房屋二事係目前要務懇乞</span>  
<span style="margin-left: 1em">聖明俯賜</span>  
<span style="margin-left: 1em">俞允勅下該衙門一一遵奉施行則事無推諉而</span>  
<span style="margin-left: 1em">大典克襄矣爲此具本謹具奏</span>  
<span style="margin-left: 1em">聞</span>  
<span style="margin-left: 3em">順治元年八月十一日上十五日奉</span>  
<span style="margin-left: 1em">令旨治曆大典官生供費各役月糧既有成例即察明</span>  
<span style="margin-left: 2em">支給局旁空房准作推算繕寫之所宋可成等四人</span>  
<span style="margin-left: 2em">量授職銜同朱光大等列民曆尾在局諸生照天文</span>  
<span style="margin-left: 2em">生例食糧辦事該監各科併回回科官生通曉新法</span>  
<span style="margin-left: 2em">的照舊留用怠惰冒濫的應行裁汰著禮部同禮科</span>  
<span style="margin-left: 2em">官詳加考試分別具啓內靈臺儀器併選曆局官生</span>  
<span style="margin-left: 2em">二人典守該衙門知道</span>  
<span style="margin-left: 4em">順治元年八月二十五日禮部啓文</span>  
<span style="margin-left: 3em">禮部</span>  
<span style="margin-left: 2em">啓爲請給新曆供費以便推算速竣兼陳本局要務</span>  
<span style="margin-left: 3em">事祠祭清吏司案呈奉本部送禮科抄出修政曆</span>  
<span style="margin-left: 3em">法遠臣湯若望啓前事等因奉</span>  
<span style="margin-left: 1em">令旨治曆大典官生供費各役月糧既有成例即察明</span>  
<span style="margin-left: 2em">支給局旁空房准作推算繕寫之所宋可成等四人</span>  
<span style="margin-left: 2em">量授職銜同朱光大等列名曆尾在局諸生照天文</span>  
<span style="margin-left: 2em">生例食糧辦事該監各科併回回科官生通曉新法</span>  
<span style="margin-left: 2em">的照舊留用怠惰冒濫的應行裁汰禮部同禮科官</span>  
<span style="margin-left: 2em">詳加考試分別具奏內靈臺見在儀器併選曆局官</span>  
<span style="margin-left: 2em">生二人典守該衙門知道敬此又該</span>  
<span style="margin-left: 2em">內院大學士馮銓啓二十二日考試欽天監官生等</span>  
<span style="margin-left: 3em">因八月二十一日奉</span>  
<span style="margin-left: 1em">令旨知道了卿親監曆局考試以定去留具見敬慎該</span>  
<span style="margin-left: 2em">部知道敬此敬遵各抄到部送司又據曆局手本開</span>  
<span style="margin-left: 3em">送書辦吳勝皂隸周于德潘文曉匠役高長春李</span>  
<span style="margin-left: 3em">洪玉李貴芳王三聘門役俞信各花名前來相應</span>  
<span style="margin-left: 3em">具覆通查案呈到部照得修曆遠臣湯若望所請</span>  
<span style="margin-left: 3em">供費一項案查先經該局進呈曆樣墊過筆札綾</span>  
<span style="margin-left: 3em">絹裝帙工價官生供給等費共銀二十兩有奇所</span>  
<span style="margin-left: 3em">費爲數不多先行補給又稱尚有七政躔度等曆</span>  
<span style="margin-left: 3em">纂修正亟功倍于前一應公費俟有確數報部再</span>  
<span style="margin-left: 3em">行酌給各役月糧業經該局開送書皂匠役吳勝</span>  
<span style="margin-left: 3em">等八名前來應照各衙門例一體支給局旁空房</span>  
<span style="margin-left: 3em">已行遠臣安插住坐爲推算繕寫之所其生儒宋</span>  
<span style="margin-left: 3em">可成等四人既以効勞有年勒敏可加相應照例</span>  
<span style="margin-left: 3em">量帶欽天監博士職銜應同朱光大等附名曆尾</span>  
<span style="margin-left: 3em">在局効勞儒士掌有篆等十人今依原啓准照天</span>  
<span style="margin-left: 3em">文生例食粮辦事內靈臺儀器遠臣遴委官生着</span>  
<span style="margin-left: 3em">令收掌匙鑰管理外其考試一節於本月二十一</span>  
<span style="margin-left: 3em">日未時蒙</span>  
<span style="margin-left: 2em">內院傳諭禮部同禮科官於二十二日早先赴曆局</span>  
<span style="margin-left: 3em">將欽天監各科官生通行考試分別等次候</span>  
<span style="margin-left: 2em">內院到局議定去留以憑具啓請</span>  
<span style="margin-left: 1em">旨定奪等因該本部左侍郎臣李明睿右侍郎臣何瑞</span>  
<span style="margin-left: 3em">徵遵即會同禮科給事中臣孟　　署祠祭司事</span>  
<span style="margin-left: 3em">精膳司郎中今復授山東道御史臣寗承勲於二</span>  
<span style="margin-left: 3em">十二日黎明督率欽天監監正戈承科監副賈良</span>  
<span style="margin-left: 3em">棟周胤帶領官生潘國祥等到局伺候即蒙</span>  
<span style="margin-left: 2em">內院大學士馮銓親臨考試臣等在局齊集曆科等</span>  
<span style="margin-left: 3em">科官潘國祥等四十七員并回回科官吳明炫等</span>  
<span style="margin-left: 3em">五員曆科等科天文生朱光蔭等三十一名及回</span>  
<span style="margin-left: 3em">回科天文生吳明燿等三名命題考試隨據各官</span>  
<span style="margin-left: 3em">生呈稱今科各有專司株守一遵成例其於新法</span>  
<span style="margin-left: 3em">除賈良琦劉有慶朱光顯三名而外求其熟習精</span>  
<span style="margin-left: 3em">通者蓋甚難其人也臣等細詰其由則謂本年八</span>  
<span style="margin-left: 3em">月方奉有精習新法不得怠玩之</span>  
<span style="margin-left: 1em">令旨今學習伊始若非寬限講求未敢揣摹應試也臣</span>  
<span style="margin-left: 3em">等以爲治曆明時雖法分新舊然而其人之勤惰</span>  
<span style="margin-left: 3em">與其人之明昧其年之衰壯固可觀而知也於是</span>  
<span style="margin-left: 3em">逐名細詢或考其推算之異同或察其占驗之得</span>  
<span style="margin-left: 3em">失且課其職掌觀其字義則見有法雖守舊而志</span>
