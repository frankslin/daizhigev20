<span style="margin-left: 2em">金水二星历指叙目</span>  
<span style="margin-left: 1em">上土木火三星各以自行能冲太阳亦各有本行不随</span>  
<span style="margin-left: 2em">太阳是以其平行或本天之行与太阳不同外亦有</span>  
<span style="margin-left: 2em">岁行凡冲太阳为年岁之界即于此起算然或会太</span>  
<span style="margin-left: 2em">阳必无均数即在太阳之冲亦无年岁之均数古以</span>  
<span style="margin-left: 2em">三测冲太阳时刻度分可得本天两心之差及极大</span>  
<span style="margin-left: 2em">之均数等金水二星不然其行不冲太阳而且恒随</span>  
<span style="margin-left: 2em">太阳虽亦有离太阳之时或左或右其距度东西不</span>  
<span style="margin-left: 2em">一在东距度时多时寡会日之时或顺或逆二次人</span>  
<span style="margin-left: 2em">目不见古人以为难测莫定其行之道今依多禄某</span>  
<span style="margin-left: 2em">所著为法</span>

<span style="margin-left: 2em">岁行之本若星或会或冲太阳平行者则为在岁行</span>  
<span style="margin-left: 2em">之界今则不然乃以太阳实行为岁行之本凡上三</span>  
<span style="margin-left: 2em">星或会或冲太阳实行者始为岁行之界而金水二</span>

<span style="margin-left: 2em">金星天以太阳为心<sub class="note-yuan">第一章</sub></span>  
<span style="margin-left: 1em">本历总论有七政新图以太阳为五纬之心然土木火</span>  
<span style="margin-left: 2em">三星在太阳上难征今以金星测定无可疑后详之</span>  
<span style="margin-left: 1em">试测金星于西将伏东初见时用远镜窥之必见其体</span>  
<span style="margin-left: 2em">其光皆如新月之象或西或东光恒向日又于西初</span>  
<span style="margin-left: 14em">见东将伏时如前法</span>  
<span style="margin-left: 14em">窥之则见其光体全</span>  
<span style="margin-left: 14em">圆<sub class="note-jiao">校：全圓原作全圖據文淵本改</sub>若</span>  
<span style="margin-left: 14em">于其留际观之见其</span>  
<span style="margin-left: 14em">体又非全圆而有光</span>  
<span style="margin-left: 2em">有魄盖因金星不旋地球如月体乃得齐见其光之</span>  
<span style="margin-left: 2em">盈缩故曰金星以太阳为心如图月在太阳人目之</span>  
<span style="margin-left: 2em">间为丙则无光金星在太阳人目之间为乙亦无光</span>  
<span style="margin-left: 2em">若地在戊日丁月之间则月光满若太阳戊在金星</span>  
<span style="margin-left: 2em">甲地球之间则金星光满若在左右则月及金星各</span>  
<span style="margin-left: 2em">有半光光之大小如按古图不析其理虽千百世不</span>  
<span style="margin-left: 2em">能透其根也</span>  
<span style="margin-left: 2em">古者言太白在本轮上体小光盛在本轮下体大光</span>  
<span style="margin-left: 2em">淡在左右体不甚大而光甚盛今如图解之在高于</span>  
<span style="margin-left: 2em">时为望其体远则见小全透其光故盛也在庳于时</span>  
<span style="margin-left: 2em">为晦不可得见晦朔左右去地为近则体见大哉生</span>  
<span style="margin-left: 2em">明故稍淡也在左右为上下弦所见半体故不甚大</span>  
<span style="margin-left: 2em">远近之间又见半光故甚盛也</span>  
<span style="margin-left: 1em">又金星因岁轮于地时近时远远时显其体小而光全</span>  
<span style="margin-left: 2em">若以远镜窥之难分别其或圆或缺之体在极远左</span>  
<span style="margin-left: 2em">右数十度亦然若在中距者其光稍淡则远镜可略</span>  
<span style="margin-left: 2em">测其体之形然光芒锐利亦难明别为真体或为虚</span>  
<span style="margin-left: 2em">暎之光惟在极近数十度则光更淡又于地近其体</span>  
<span style="margin-left: 2em">显大可明见之</span>  
<span style="margin-left: 1em">系凡金星为迟行或逆行用远镜窥之可测其形体若</span>  
<span style="margin-left: 2em">更近见其体缺更大</span>  
<span style="margin-left: 2em">测金星之最高<sub class="note-yuan">第二章</sub></span>  
<span style="margin-left: 1em">测金星距太阳两次其距度分为等者则太阳两平行</span>  
<span style="margin-left: 2em">中度分为金星本天之最高或高冲之处</span>  
<span style="margin-left: 2em">解曰用不同心一圈及小轮一圈作图如古丁为地</span>  
<span style="margin-left: 2em">心己本天心庚辛为两心线置庚为最高辛为其冲</span>  
<span style="margin-left: 8em">最高庚左右等度分取甲乙两点各</span>  
<span style="margin-left: 8em">为心作等径之两小轮从己从丁到</span>  
<span style="margin-left: 8em">甲到乙作线又从人目丁作丁丙丁</span>  
<span style="margin-left: 8em">壬切小轮两线置夕一测金星在丙</span>  
<span style="margin-left: 8em">晨一测在壬甲乙小轮两心为太阳</span>  
<span style="margin-left: 8em">及金星同用平行之经度庚己甲为</span>  
<span style="margin-left: 8em">距最高度之角<sub class="note-yuan">平行数又引数</sub>庚丁丙角为</span>  
<span style="margin-left: 8em">金星体距最高视角<sub class="note-yuan">视角视行正经一同</sub>从丁</span>  
<span style="margin-left: 8em">作丁未丁酉与己甲己乙平行两线</span>  
<span style="margin-left: 8em">而成未丁丙酉丁壬两角乃平行庚</span>  
<span style="margin-left: 2em">己甲视行庚丁丙两角之较</span>  
<span style="margin-left: 1em">题言凡星在丙在壬而丙丁未壬丁酉两角之度分为</span>  
<span style="margin-left: 2em">等者庚最高点必在甲乙两点之中</span>  
<span style="margin-left: 2em">欲试之更置其一测乙移在亥星亦在壬则亥丁壬</span>  
<span style="margin-left: 2em">为距太阳之视角比甲丁丙角更大<sub class="note-yuan">观图自明不须赘论盖亥点比</sub></span>
