## 崇禎曆書卷之七十　五緯歷指卷五

<span style="margin-left: 2em">金水二星曆指敘目</span>  
<span style="margin-left: 1em">上土木火三星各以自行能衝太陽亦各有本行不隨</span>  
<span style="margin-left: 2em">太陽是以其平行或本天之行與太陽不同外亦有</span>  
<span style="margin-left: 2em">歲行凡衝太陽爲年歲之界即于此起算然或會太</span>  
<span style="margin-left: 2em">陽必無均數即在太陽之衝亦無年歲之均數古以</span>  
<span style="margin-left: 2em">三測衝太陽時刻度分可得本天兩心之差及極大</span>  
<span style="margin-left: 2em">之均數等金水二星不然其行不衝太陽而且恆隨</span>  
<span style="margin-left: 2em">太陽雖亦有離太陽之時或左或右其距度東西不</span>  
<span style="margin-left: 2em">一在東距度時多時寡會日之時或順或逆二次人</span>  
<span style="margin-left: 2em">目不見古人以爲難測莫定其行之道今依多祿某</span>  
<span style="margin-left: 2em">所著爲法</span>  
<span style="margin-left: 1em">古者以太陽平行度<sub class="note-jiao">校：太陽原作大陽據文淵本改</sub>爲土木火上三星</span>  
<span style="margin-left: 2em">歲行之本若星或會或衝太陽平行者則爲在歲行</span>  
<span style="margin-left: 2em">之界今則不然乃以太陽實行爲歲行之本凡上三</span>  
<span style="margin-left: 2em">星或會或衝太陽實行者始爲歲行之界而金水二</span>  
<span style="margin-left: 2em">星又不然乃以太陽平行即爲本天之平行</span>  
<span style="margin-left: 2em">本天非太陽之天另有一圈載次輪上三星因能衝</span>  
<span style="margin-left: 2em">對太陽約一年再相會所用圈以齊其順逆等行名</span>  
<span style="margin-left: 2em">謂之歲圈金水二星雖行亦有順逆然此圈不能稱</span>

<span style="margin-left: 2em">金星天以太陽爲心<sub class="note-yuan">第一章</sub></span>  
<span style="margin-left: 1em">本曆總論有七政新圖以太陽爲五緯之心然土木火</span>  
<span style="margin-left: 2em">三星在太陽上難徵今以金星測定無可疑後詳之</span>  
<span style="margin-left: 1em">試測金星于西將伏東初見時用遠鏡窺之必見其體</span>  
<span style="margin-left: 2em">其光皆如新月之象或西或東光恆向日又於西初</span>  
<span style="margin-left: 14em">見東將伏時如前法</span>  
<span style="margin-left: 14em">窺之則見其光體全</span>  
<span style="margin-left: 14em">圓<sub class="note-jiao">校：全圓原作全圖據文淵本改</sub>若</span>  
<span style="margin-left: 14em">于其留際觀之見其</span>  
<span style="margin-left: 14em">體又非全圓而有光</span>  
<span style="margin-left: 2em">有魄蓋因金星不旋地球如月體乃得齊見其光之</span>  
<span style="margin-left: 2em">盈縮故曰金星以太陽爲心如圖月在太陽人目之</span>  
<span style="margin-left: 2em">間爲丙則無光金星在太陽人目之間爲乙亦無光</span>  
<span style="margin-left: 2em">若地在戊日丁月之間則月光滿若太陽戊在金星</span>  
<span style="margin-left: 2em">甲地球之間則金星光滿若在左右則月及金星各</span>  
<span style="margin-left: 2em">有半光光之大小如按古圖不析其理雖千百世不</span>  
<span style="margin-left: 2em">能透其根也</span>  
<span style="margin-left: 2em">古者言太白在本輪上體小光盛在本輪下體大光</span>  
<span style="margin-left: 2em">淡在左右體不甚大而光甚盛今如圖解之在高于</span>  
<span style="margin-left: 2em">時爲望其體遠則見小全透其光故盛也在庳于時</span>  
<span style="margin-left: 2em">爲晦不可得見晦朔左右去地爲近則體見大哉生</span>  
<span style="margin-left: 2em">明故稍淡也在左右爲上下弦所見半體故不甚大</span>  
<span style="margin-left: 2em">遠近之間又見半光故甚盛也</span>  
<span style="margin-left: 1em">又金星因歲輪于地時近時遠遠時顯其體小而光全</span>  
<span style="margin-left: 2em">若以遠鏡窺之難分別其或圓或缺之體在極遠左</span>  
<span style="margin-left: 2em">右數十度亦然若在中距者其光稍淡則遠鏡可略</span>  
<span style="margin-left: 2em">測其體之形然光芒銳利亦難明別爲真體或爲虛</span>  
<span style="margin-left: 2em">暎之光惟在極近數十度則光更淡又于地近其體</span>  
<span style="margin-left: 2em">顯大可明見之</span>  
<span style="margin-left: 1em">系凡金星爲遲行或逆行用遠鏡窺之可測其形體若</span>  
<span style="margin-left: 2em">更近見其體缺更大</span>  
<span style="margin-left: 2em">測金星之最高<sub class="note-yuan">第二章</sub></span>  
<span style="margin-left: 1em">測金星距太陽兩次其距度分爲等者則太陽兩平行</span>  
<span style="margin-left: 2em">中度分爲金星本天之最高或高衝之處</span>  
<span style="margin-left: 2em">解曰用不同心一圈及小輪一圈作圖如古丁爲地</span>  
<span style="margin-left: 2em">心己本天心庚辛爲兩心線置庚爲最高辛爲其衝</span>  
<span style="margin-left: 8em">最高庚左右等度分取甲乙兩點各</span>  
<span style="margin-left: 8em">爲心作等徑之兩小輪從己從丁到</span>  
<span style="margin-left: 8em">甲到乙作線又從人目丁作丁丙丁</span>  
<span style="margin-left: 8em">壬切小輪兩線置夕一測金星在丙</span>  
<span style="margin-left: 8em">晨一測在壬甲乙小輪兩心爲太陽</span>  
<span style="margin-left: 8em">及金星同用平行之經度庚己甲爲</span>  
<span style="margin-left: 8em">距最高度之角<sub class="note-yuan">平行數又引數</sub>庚丁丙角爲</span>  
<span style="margin-left: 8em">金星體距最高視角<sub class="note-yuan">視角視行正經一同</sub>從丁</span>  
<span style="margin-left: 8em">作丁未丁酉與己甲己乙平行兩線</span>  
<span style="margin-left: 8em">而成未丁丙酉丁壬兩角乃平行庚</span>  
<span style="margin-left: 2em">己甲視行庚丁丙兩角之較</span>  
<span style="margin-left: 1em">題言凡星在丙在壬而丙丁未壬丁酉兩角之度分爲</span>  
<span style="margin-left: 2em">等者庚最高點必在甲乙兩點之中</span>  
<span style="margin-left: 2em">欲試之更置其一測乙移在亥星亦在壬則亥丁壬</span>  
<span style="margin-left: 2em">爲距太陽之視角比甲丁丙角更大<sub class="note-yuan">觀圖自明不須贅論蓋亥點比</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">乙更近</sub>則反先所定而命取二測皆有距太陽平行之</span>  
<span style="margin-left: 2em">角而爲同度必丁乙于丁甲丁壬于丁丙各兩線相</span>  
<span style="margin-left: 2em">等因幾何<sub class="note-yuan">三卷七題</sub>若非等者其距庚辛兩心線必不能</span>  
<span style="margin-left: 2em">爲等其距視角必亦不等若所測之得爲等則兩測</span>  
<span style="margin-left: 2em">兩平行之中有最高距太陽極大數者爲等則其近</span>  
<span style="margin-left: 2em">遠<sub class="note-yuan">與地</sub>亦等本天均數亦等蓋皆相連之圖也</span>  
<span style="margin-left: 2em">古測金星最高及其衝<sub class="note-yuan">第三章</sub></span>  
<span style="margin-left: 1em">多祿某記古得剜總積四千八百四十五年爲陽嘉元</span>  
<span style="margin-left: 2em">年壬申<sub class="note-yuan">西曆</sub>三月初八日夕測金星得大梁宮一度半</span>  
<span style="margin-left: 2em"><sub class="note-yuan">用昴宿星比測</sub>當時太陽及金星之平行爲娵訾宮十四度</span>  
<span style="margin-left: 2em">十五分兩行之差爲四十七度十五分乃金星距平</span>  
<span style="margin-left: 2em">行大數也亦名均數又總積四千八百五十三年爲</span>  
<span style="margin-left: 2em">永和五年庚辰<sub class="note-yuan">西曆</sub>七月三十日金星見東方多祿某</span>  
<span style="margin-left: 2em">親測得在實沈宮十八度半<sub class="note-yuan">用井宿第七星比測定之</sub>當時太陽</span>  
<span style="margin-left: 2em">及金星之平行爲鶉火宮五度四十五分兩行之較</span>  
<span style="margin-left: 2em">爲四十七度十五分用兩測兩平行相減<sub class="note-yuan">從娵訾宮十四度十</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">五分順天數到鶉火宮五度四十五分</sub>得中積爲一百四十一度三十</span>  
<span style="margin-left: 2em">分折半得七十度四十五分并加于娵訾十四度十</span>  
<span style="margin-left: 2em">五分以減全周得大梁宮二十五度其衝大火同度</span>

<span style="margin-left: 1em">次測乃得剜總積四千八百四十年爲永建二年丁卯</span>

<span style="margin-left: 2em">太陽平行爲壽星宮十七度五十二分星距太陽爲</span>  
<span style="margin-left: 2em">四十七度三十二分乃兩行之較也<sub class="note-yuan">用右執法星比測金星得數</sub></span>  
<span style="margin-left: 2em">又多祿某于總積四千八百四十九年爲永和元年</span>

<span style="margin-left: 2em">第八星在東如月其小徑爲二十四分時金星光大</span>  
<span style="margin-left: 2em">因用恆星比測得在玄枵宮十九度三十六分時太</span>  
<span style="margin-left: 2em">陽平行爲星紀宮二度四分星距太陽爲四十七度</span>  
<span style="margin-left: 2em">三十二分用前後兩測太陽平行相減折半亦得大</span>  
<span style="margin-left: 2em">梁宮二十五度或大火等度乃兩心之線也<sub class="note-yuan">亦未定最高之</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">宮分</sub></span>  
<span style="margin-left: 1em">多祿某記前人二測并親測定金星兩心線如上然未</span>  
<span style="margin-left: 2em">知最高或在大梁或大火乃因前論互用取金星平</span>  
<span style="margin-left: 2em">行之近大梁或近大火而測其大距度曰依不同心</span>  
<span style="margin-left: 2em">圈均數極微則大距度全從小輪而生若距度小指</span>  
<span style="margin-left: 2em">平行小輪心于地極遠若距度大指小輪心于地極</span>  
<span style="margin-left: 2em">近遠近之分即最高及其衝也定論如此用得剜測</span>  
<span style="margin-left: 2em">一用親測一<sub class="note-yuan">見本曆首卷總說</sub></span>  
<span style="margin-left: 1em">總積四千八百四十二年爲永建四年己巳<sub class="note-yuan">西曆</sub>五月二</span>  
<span style="margin-left: 2em">十日晨比金星于婁宿第二星及天囷座第四星測</span>  
<span style="margin-left: 2em">算得金星在降婁宮十度三十六分其緯度在南一</span>  
<span style="margin-left: 2em">度半當時太陽平行得二十五度二十四分大距度</span>  
<span style="margin-left: 2em"><sub class="note-yuan">兩行之差</sub>爲四十四度四十八分多祿某自測總積四千</span>  
<span style="margin-left: 2em">八百四十九年爲永和元年丙子<sub class="note-yuan">西曆</sub>十一月十八日</span>  
<span style="margin-left: 2em">昏以牛宿第二星比測得金星在星紀宮十二度五</span>  
<span style="margin-left: 2em">十分當時太陽平行爲大火二十〇度半大距度爲</span>  
<span style="margin-left: 2em">四十七度二十分大距指最高衝則小距指最高也</span>  
<span style="margin-left: 1em">系金星天最高多祿某于總積四千八百五十三年庚</span>  
<span style="margin-left: 2em">辰爲永和五年測定在大梁宮二十五度其衝在大</span>  
<span style="margin-left: 2em">火宮同度又曰在大火時金星距日度極多日在大</span>  
<span style="margin-left: 2em">梁時星距日度極少他處大距度在兩限之中<sub class="note-yuan">近遠各有</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">比例見下文</sub></span>

<span style="margin-left: 1em">前章記古測定金星最高在大梁宮二十五度又依後</span>  
<span style="margin-left: 2em">所記第谷九測在總積六千二百九十八年爲萬曆</span>  
<span style="margin-left: 2em">十三年乙酉測得金星天最高在實沈宮二十九度</span>  
<span style="margin-left: 2em">十五分<sub class="note-yuan">其行極微先後數年不碍算</sub>兩測比算則以中積一千四</span>  
<span style="margin-left: 2em">百四十五年爲法以兩測最高行之較三十三度十</span>

<span style="margin-left: 2em">表</span>  
<span style="margin-left: 2em">求金星伏見輪半徑及兩心之差<sub class="note-yuan">第五章</sub></span>  
<span style="margin-left: 1em">如圖丁地心己金星本天心作庚丙辛圈及己丁兩心</span>
