<span style="margin-left: 1em"><sub class="note-yuan">򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫朱廷樞鮑英齊</sub></span>  
<span style="margin-left: 3em">依渾儀製日晷法</span>  
<span style="margin-left: 1em">太陽左旋以定晝夜十二時<sub class="note-yuan">二十四小時</sub>則常依赤道三度</span>  
<span style="margin-left: 2em">四十五分爲一刻每十五度爲一小時故諸圈以二</span>  
<span style="margin-left: 2em">十四平分之而每分又以四平分之乃得時盤必周</span>  
<span style="margin-left: 2em">分各與赤道皆等之度相應令之竪立與赤道高下</span>  
<span style="margin-left: 2em">等而中依直角安表則表景所射即能定時而赤道</span>  
<span style="margin-left: 2em">晷所繇起也今不必恆以竪立合赤道圈或正立面</span>  
<span style="margin-left: 2em">向南北爲立晷或正倒面向天頂爲地平晷或復正</span>  
<span style="margin-left: 2em">立面東西正向爲子午晷或又正立面偏正南左右</span>  
<span style="margin-left: 2em">或不正立面偏地平各以所向天上之圈得名而各</span>  
<span style="margin-left: 2em">以其面承接日光故立表或正或斜不一即表射景</span>  
<span style="margin-left: 2em">遠近與面分時刻廣狹亦不得一雖太陽左旋同諸</span>  
<span style="margin-left: 2em">時刻平行同而線則實繇景得射景既異相距之線</span>  
<span style="margin-left: 2em">安得不異此諸晷公有日平行之原而私則各有所</span>  
<span style="margin-left: 2em">異總于本儀可得而明矣</span>  
<span style="margin-left: 3em">求諸晷方位法</span>  
<span style="margin-left: 1em">日晷之製原以度數考求而度數必有相應之定處則</span>  
<span style="margin-left: 2em">又在取準方位焉故凡平面日晷所向方位多變大</span>  
<span style="margin-left: 2em">約相較有二原或較地平即與之爲平行有正立有</span>  
<span style="margin-left: 2em">曲立種種不同皆應度數不等或較子午圈亦與之</span>  
<span style="margin-left: 2em">爲平行乃有偏左偏右而多寡復以間度爲則者又</span>  
<span style="margin-left: 12em">或有偏于地平偏于子午</span>  
<span style="margin-left: 12em">兼地平子午而別爲一種</span>  
<span style="margin-left: 12em">總不外此二原乃復得一</span>  
<span style="margin-left: 12em">方位者必先置木或銅取</span>  
<span style="margin-left: 12em">四方直角平面形爲甲乙</span>  
<span style="margin-left: 2em">丙丁依其長邊面內作戊己線與甲乙爲平行線應</span>  
<span style="margin-left: 2em">平分于壬即以壬爲心以辛爲界作己辛戊半圈乃</span>  
<span style="margin-left: 2em">平分一百八十度也從中線壬辛左右各一象限而</span>  
<span style="margin-left: 2em">另設垂線于壬則定方位之器全矣臨用時如求地</span>  
<span style="margin-left: 2em">平方位即令此器以丙丁邊倚晷面正立得垂線合</span>  
<span style="margin-left: 2em">壬辛中線者即得其面正與地平同若垂線偏距中</span>  
<span style="margin-left: 2em">線左右則必查象限得晷面前後離地平若干度以</span>  
<span style="margin-left: 2em">垂線依象限辛點之前後度爲法或令甲丙邊依直</span>  
<span style="margin-left: 2em">角倚晷面得垂線正合壬辛線者即其面正立在地</span>  
<span style="margin-left: 2em">平若得垂線距辛點內外則依其距度于象限上亦</span>  
<span style="margin-left: 2em">可得晷面偏前後之廣欲求距子午圈方位即令甲</span>  
<span style="margin-left: 2em">乙邊以直角倚晷面從此器中心壬出尺能旋轉于</span>  
<span style="margin-left: 2em">半圈諸度尺末設指南針其上隨尺同轉乃先安器</span>  
<span style="margin-left: 2em">後轉尺而以羅針對下順尺線者爲準隨以尺距中</span>  
<span style="margin-left: 2em">線之度定晷面距子午圈之廣但羅針未免畧差故</span>  
<span style="margin-left: 2em">又一法晷面上界線自上一直下于線上立表表末</span>  
<span style="margin-left: 2em">另懸垂線候日光射垂線之景必合晷面上線乃準</span>  
<span style="margin-left: 2em">且將渾儀依法測得日輪高度而以太陽躔度對高</span>  
<span style="margin-left: 2em">弧則高弧所指地平度或正東西或偏左右因偏若</span>  
<span style="margin-left: 2em">干亦可定晷面離正南北之廣也其求重複方位各</span>  
<span style="margin-left: 2em">依所向可得乃向地平如前向子午別有法于晷面</span>  
<span style="margin-left: 2em">立二表任意相距表銳各設垂線距面皆等候日輪</span>  
<span style="margin-left: 2em">出視其二線準對即於儀上測其地平高以與高弧</span>  
<span style="margin-left: 2em">正合而地平經度可得子午圈方位亦定矣</span>  
<span style="margin-left: 3em">製正球日晷</span>  
<span style="margin-left: 1em">凡日晷之表等雖北極出地不等得各時線相距等者</span>  
<span style="margin-left: 2em">謂之正球晷此其製原易可不須球然舍球又無以</span>  
<span style="margin-left: 2em">明其理也如赤道晷因諸時圈與赤道交其相距皆</span>  
<span style="margin-left: 2em">于球心相切設以本儀之樞當表其射景必順時圈</span>  
<span style="margin-left: 2em">行赤道使各依極安儀而表之長短同則時圈在赤</span>  
<span style="margin-left: 2em">道上相距之度亦同或論赤極晷因其面正合卯酉</span>  
<span style="margin-left: 2em">時圈設本面距儀心任表長短等而諸時圈與中心</span>  
<span style="margin-left: 2em">相切從心過晷面相距不等則正午線合儀樞可當</span>  
<span style="margin-left: 2em">儀面中線而餘線左右相距漸遠皆平行如上圖以</span>  
<span style="margin-left: 2em">長方形爲晷面其丙丁橫線者即赤道與之相切線</span>  
<span style="margin-left: 9em">其甲午正南北線者即合儀樞從</span>  
<span style="margin-left: 9em">赤道頂過時圈所爲線也立圈者</span>  
<span style="margin-left: 9em">乃赤道周平分以指諸時圈相交</span>  
<span style="margin-left: 9em">之點者也蓋時圈必皆切表頂<sub class="note-yuan">當地</sub></span>  
<span style="margin-left: 9em"><sub class="note-yuan">心是</sub>而復開之使過至丙丁線上爲</span>  
<span style="margin-left: 9em">時線所居之界故本晷諸線交心</span>  
<span style="margin-left: 9em">在面外而以表頂爲心彼此相距</span>  
<span style="margin-left: 2em">皆平行今設表長短同雖極高多寡不同其線則二</span>  
<span style="margin-left: 2em">晷相距無異又設甲午線依天樞斜竪令晷面偏東</span>  
<span style="margin-left: 2em">或西則午時線不能定在面之中必依面所偏多寡</span>  
<span style="margin-left: 2em">而晷面亦移左右不等至其面向正東正西乃以中</span>  
<span style="margin-left: 2em">線爲卯正酉正餘線漸遠惟午時線不入晷面而丙</span>  
<span style="margin-left: 2em">丁線則尚爲赤道所切雖時線皆平行乃晷則應以</span>  
<span style="margin-left: 2em">一面斜起庶合赤道高度而得中所橫線其高低度</span>  
<span style="margin-left: 2em">與之等也</span>  
<span style="margin-left: 3em">製斜球正日晷</span>  
<span style="margin-left: 1em">凡日晷之表等因北極出地不等得各時線相距亦不</span>  
<span style="margin-left: 2em">等者謂之斜球晷其製法原不一今用渾儀列簡法</span>  
<span style="margin-left: 2em">如左如製地平晷先起儀依本北極高乃令過極圈</span>  
<span style="margin-left: 2em">正合子午圈而子午圈之左或右每於赤道上查十</span>  
<span style="margin-left: 2em">五度移居子午圈下即識過極圈交地平正南北度</span>  
<span style="margin-left: 2em">復於赤道上查十五度如前移居子午圈下又得過</span>  
<span style="margin-left: 2em">極圈交地平度以此遞查遞移必至盡過極圈交地</span>  
<span style="margin-left: 2em">平度之界而止則諸時線在晷面相距之廣全得焉</span>  
<span style="margin-left: 2em">蓋晷面上先作兩直線以直角相交其一爲子午線</span>  
<span style="margin-left: 2em">其一爲卯酉線而以交點爲心任意大小作虛圈或</span>  
<span style="margin-left: 2em">用比例尺或依本圈預分度取儀上地平所識度爲</span>  
<span style="margin-left: 2em">法<sub class="note-yuan">自卯酉線至子午線或反之以應儀上所識度爲準</sub>從心出線過此者皆平</span>  
<span style="margin-left: 2em">晷時線也如北極高四十度以過春分經圈居子午</span>  
<span style="margin-left: 2em">圈下必在地平之正南北初度爲午正移之去東十</span>  
<span style="margin-left: 2em">五度<sub class="note-yuan">依赤道度</sub>得經圈東交地平十度<sub class="note-yuan">距子午圈算</sub>爲午初移</span>  
<span style="margin-left: 2em">之去西十五度得經圈西交地平亦十度爲未初<sub class="note-yuan">距午</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">前後等時恆得距度等</sub>巳正及未正約得二十度半巳初及申</span>  
<span style="margin-left: 2em">初約得三十三度辰正申正得四十八度辰初酉初</span>  
<span style="margin-left: 2em">得六十七度半至卯正酉正則各滿九十度而卯酉</span>  
<span style="margin-left: 2em">外與前距時等必皆得度等若求刻線亦依赤道上</span>  
<span style="margin-left: 2em">三度四十五分爲一刻如前法遞查之安表使之出</span>  
<span style="margin-left: 2em">晷心向午正距晷面漸遠以北極出地度爲則必懸</span>  
<span style="margin-left: 2em">子午線上以正合本地天樞是也</span>  
<span style="margin-left: 2em">若正南北立晷亦用儀上赤道求距度漸移至子午</span>  
<span style="margin-left: 2em">圈法同前其所異惟在交度蓋高弧與過極圈相遇</span>  
<span style="margin-left: 2em">處爲交度而高弧則定居東西或卯正酉正苟不用</span>  
<span style="margin-left: 2em">高弧惟以極高所餘度求之如北極高四十度依其</span>  
<span style="margin-left: 2em">地製立晷必使儀北極出地平上五十度如前法定</span>  
<span style="margin-left: 2em">時線蓋五十度即極高四十度之餘度其安表漸距</span>  
<span style="margin-left: 2em">晷面正下以至本地赤道高爲止此晷自卯正至酉</span>  
<span style="margin-left: 2em">正獨十二小時向南而卯前酉後之時面皆向北其</span>  
<span style="margin-left: 2em">表漸距晷面與前同從上反求得正矣</span>  
<span style="margin-left: 3em">製斜球单偏日晷</span>  
<span style="margin-left: 1em">若不正立面向南北製法略與正立同但用高弧必依</span>  
<span style="margin-left: 2em">其偏容有異蓋向南面偏北者必查偏度于子午圈</span>  
<span style="margin-left: 2em">從儀頂去北即此安高弧面向南者則偏度宜求於</span>  
<span style="margin-left: 2em">頂之南以此界出高弧其向北晷面偏南者即依偏</span>  
<span style="margin-left: 2em">度於頂南求界或面反偏北尤宜于頂北求界總之</span>  
<span style="margin-left: 2em">偏度多寡及所向方位皆應查于子午圈距頂南或</span>  
<span style="margin-left: 2em">北之處以安高弧而高弧下至地平恆在正東正西</span>  
<span style="margin-left: 2em">之點表位必在正午時線從晷心漸距其面與高弧</span>  
<span style="margin-left: 2em">上距北極等</span>  
<span style="margin-left: 2em">若不正立面偏正東正西法用立象半圈先於高弧</span>  
<span style="margin-left: 2em">上取偏度如設面向東而偏西三十度令高弧自頂</span>  
<span style="margin-left: 2em">下至正西量三十度爲限即安半圈于其限以當地</span>  
<span style="margin-left: 2em">平必識其與極圈相交之點爲各時線之距如北極</span>  
<span style="margin-left: 2em">高四十度安高弧及半圈如前將時盤與夏至圈對</span>  
<span style="margin-left: 2em">試於太陽出時必得春分經圈北交半圈十六度卯</span>  
<span style="margin-left: 2em">初交十二度漸過以南交二十六度後七十等度至</span>  
<span style="margin-left: 2em">未正一刻餘太陽過半圈西晷面無景其本晷表位</span>  
<span style="margin-left: 2em">偏午正線左右距晷面較地平面高不等求其位法</span>  
<span style="margin-left: 2em">使經圈與立象半圈以直角相交即因經圈自交點</span>  
<span style="margin-left: 2em">至極中弧得表之高半圈自交點至交北地平得表</span>  
<span style="margin-left: 2em">位與午正線相距之遠如依前極高等數則表距三</span>  
<span style="margin-left: 2em">十八度高二十二度</span>  
<span style="margin-left: 2em">若正立面偏東或西製法亦與正向南北立晷同獨</span>  
<span style="margin-left: 2em">高弧下至地平不得定在正東正西之處必依晷面</span>  
<span style="margin-left: 2em">偏度因之距東西等如面向南偏西三十度即高弧</span>

<span style="margin-left: 2em">移高弧任取十度或多或少距限恆等而依之視正</span>  
<span style="margin-left: 2em">對地平度必爲直線故恆得儀心居間此本線所以</span>  
<span style="margin-left: 2em">合於表位也其地平緯線必安高弧于定處從下漸</span>  
<span style="margin-left: 2em">上以相等之距限視儀心則以目光線所射之面爲</span>  
<span style="margin-left: 2em">界初寬而後狹若移高弧他處亦依此爲法此以表</span>  
<span style="margin-left: 2em">位爲心而圖平行圈之所以然也其製法惟量表大</span>  
<span style="margin-left: 2em">小依之開比例尺于上取各距度之切線從表位帶</span>  
<span style="margin-left: 2em">入面上爲圈即地平緯度限則表景所至必指太陽</span>  
<span style="margin-left: 2em">出地平高度隨將地平緯度平分或五或十等距度</span>  
<span style="margin-left: 2em"><sub class="note-yuan">從午正線起</sub>則表位所出直線皆過其分弧界即地平經</span>  
<span style="margin-left: 2em">度已定而表景所至必指太陽所向方位</span>  
<span style="margin-left: 2em">論十二舍線即立象半圈所爲本圈儀上皆合子午</span>  
<span style="margin-left: 2em">圈交地平爲一點者但若左右倒耳故正東西從儀</span>  
<span style="margin-left: 2em">上視之至面必爲平行直線其製法亦不異正向東</span>  
<span style="margin-left: 2em">西之偏晷也論太陽出沒已距時線即過極圈依各</span>  
<span style="margin-left: 2em">赤緯度所爲起儀依本極高將時盤午正與過極圈</span>  
<span style="margin-left: 2em">合令之轉東或西以太陽本方春秋分出沒爲止則</span>  
<span style="margin-left: 2em">即地平分赤道及二至圈皆不等而赤道恆得六時</span>  
<span style="margin-left: 2em">至午正夏至若過冬至反不及今設去夷地平圈上</span>  
<span style="margin-left: 2em">一時或二時至滿半晝時皆并過橫線至第六時其</span>  
<span style="margin-left: 2em">線赤道上必交子午圈夏至上未及冬至上已過即</span>  
<span style="margin-left: 2em">因其橫線指太陽出沒相離時若干依之從渾儀心</span>  
<span style="margin-left: 2em">視晷面必皆斜交赤道而愈離愈斜法必先于晷面</span>  
<span style="margin-left: 2em">界赤道線就內或外加一節氣得晝時雙數者因以</span>  
<span style="margin-left: 2em">太陽至本節氣出沒之時定爲初時而餘時漸依之</span>  
<span style="margin-left: 2em">列也如北極高四十度太陽至立夏晝長約十四時</span>  
<span style="margin-left: 2em">而立冬止得十時皆雙數則因立冬日出辰初必得</span>  
<span style="margin-left: 2em">辰正爲距日出第一時而餘時次之立夏日沒戌初</span>  
<span style="margin-left: 2em">而戌正即日沒後第一時餘時亦隨次之今赤道上</span>  
<span style="margin-left: 2em">辰初恆爲日出後第一時戌初爲日没後之初時即</span>  
<span style="margin-left: 2em">前所識節氣線上諸時點與赤道上相應之時點以</span>  
<span style="margin-left: 2em">直線連引之得太陽出沒後諸時線也論七政時線</span>  
<span style="margin-left: 2em">其向中線繇赤道等圈則自午前及午後以至地平</span>  
<span style="margin-left: 2em">皆平分各六時蓋夏至午前後弧大于冬至午前後</span>  
<span style="margin-left: 2em">之各弧而赤道得居中必與諸時線斜相交是以其</span>  
<span style="margin-left: 2em">線自向中也法先依最長之晝平分時盤或六或十</span>  
<span style="margin-left: 2em">二分遂于地平求各時相距度<sub class="note-yuan">皆依前二卷</sub>帶入夏至節</span>  
<span style="margin-left: 2em">氣必得其平分午正左右各六時也然後將赤道與</span>  
<span style="margin-left: 2em">夏至相應之時以直線連之得左右皆同皆與斜球</span>  
<span style="margin-left: 2em">斜交赤道其晝長短線總繇赤道緯度任用疎或密</span>  
<span style="margin-left: 2em">故其理不異節氣線製法亦同若諸方相距東西線</span>  
<span style="margin-left: 2em">皆子午圈所爲與時圈同必以過兩極圈取準與製</span>  
<span style="margin-left: 2em">地平晷線同法以上晷面所得諸線依本容因之有</span>  
<span style="margin-left: 2em">異必從其儀上所得圈視儀心至面止俱依前法如</span>  
<span style="margin-left: 2em">試於立晷即地平與赤道爲平行故地平緯似節氣</span>  
<span style="margin-left: 2em">線形地平經皆上下平行遠疎而近午時則密全倣</span>  
<span style="margin-left: 2em">赤極晷線十二舍線皆出地平與子午線相交太陽</span>  
<span style="margin-left: 2em">出沒距時線如前地平面同七政線亦出地平交子</span>  
<span style="margin-left: 2em">午線之點晝夜長短亦如節氣線諸方相距東西線</span>  
<span style="margin-left: 2em">亦與正時線同製法各隨本類全載日晷本欵此不</span>

<span style="margin-left: 3em">地球用法</span>  
<span style="margin-left: 1em">地球以圓形倣地之本體又以旋動反其性情者總欲</span>  
<span style="margin-left: 2em">因各處向頂之自然也蓋地居萬物之中心隨處向</span>  
<span style="margin-left: 2em">天即如圓圈中心出直線無一線不正向其界者然</span>  
<span style="margin-left: 2em">乃製之爲球反若偏居<sub class="note-yuan">在地面故</sub>距天此近彼遠<sub class="note-yuan">俱以子午圈求</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">天頂故</sub>必宜活動以隨處能移至頂與天相近而從之</span>  
<span style="margin-left: 2em">向頂可也故安球必先取平以合于地平使子午圈</span>  
<span style="margin-left: 2em">南北得正而因以諸方向得本所焉後令球前後起</span>  
<span style="margin-left: 2em">或左右轉務以本處至中頂乃得向天之勢有以二</span>  
<span style="margin-left: 2em">處相提而論或經緯皆異者或經同而緯異者或求</span>  
<span style="margin-left: 2em">二處相距之里及所向之位緯同而經異者總于本</span>  
<span style="margin-left: 2em">球得明矣先論其經緯皆異者法任令一處居頂而</span>  
<span style="margin-left: 2em">從此下高弧至地平使之南北游移以正交其彼處</span>  
<span style="margin-left: 2em">爲度乃識交度與頂之中弧化爲里則得二處直相</span>  
<span style="margin-left: 2em">距之里數又復識本高弧交地平度因以得彼處較</span>  
<span style="margin-left: 2em">前處所居之方位假如順天府北極出地四十度令</span>  
<span style="margin-left: 2em">球極起四十度隨轉球使順天府至子午圈即以之</span>  
<span style="margin-left: 2em">居頂乃依之安高弧過雲南則自頂至交點約二十</span>  
<span style="margin-left: 2em">二度即算得六千里<sub class="note-yuan">依二百七十里一度算</sub>而高弧至地平則</span>  
<span style="margin-left: 2em">從正南去西五十二度即西南第四向位也<sub class="note-yuan">各向詳下文</sub></span>  
<span style="margin-left: 2em">又使高弧過星宿海得自頂至本海之中弧爲一十</span>  
<span style="margin-left: 2em">八度化得四千八百餘里而高弧至地平乃距正南</span>  
<span style="margin-left: 2em">六十二度則因本海較順天府在西南第三向位矣</span>  
<span style="margin-left: 2em">若經同而緯異即先移其處同居子午圈下以本圈</span>  
<span style="margin-left: 2em">上度識二處各距赤道若干度以之相減乃得其相</span>  
<span style="margin-left: 2em">距度因以化爲里如順天府與南昌府約在同經試</span>  
<span style="margin-left: 2em">於子午圈上得南昌北距赤道二十八度順天距四</span>  
<span style="margin-left: 2em">十度相差十二度化得三千六百餘里設一處在赤</span>  
<span style="margin-left: 2em">道內一處在赤道外各以所得數相加即其相距度</span>  
<span style="margin-left: 2em">乃因以化爲里若緯同而經異即先各以其處移至</span>  
<span style="margin-left: 2em">子午圈下從鶯島圈線起至子午圈下止赤道上算</span>  
<span style="margin-left: 2em">各經度以之相減即得二處經度差但距赤道內外</span>  
<span style="margin-left: 2em">遠近者依赤道平行小圈似不能如前法求里數蓋</span>  
<span style="margin-left: 2em">小圈所應一度之里較本赤道度相應者不等因而</span>  
<span style="margin-left: 2em">度小里數亦應少今惟于球上用高弧乃有一簡即</span>  
<span style="margin-left: 2em">得者何也以一處居頂安高弧使從地處過則止視</span>  
<span style="margin-left: 2em">高弧上交點與頂之間弧即其相距度因復算得里</span>  
<span style="margin-left: 2em">數如前假如大西之極西地得北極高四十度與順</span>  
<span style="margin-left: 2em">天府同緯因屬距赤道四十度之平行小圈論其本</span>  
<span style="margin-left: 2em">經度應差一百三十度依度求里亦應距三萬五千</span>  
<span style="margin-left: 2em">一百有奇今止以高弧爲主則二處直相距約九十</span>  
<span style="margin-left: 2em">度算得爲二萬四千三百里而相應之向位且亦不</span>  
<span style="margin-left: 2em">在正東西焉使以順天府居頂極西地必北去正西</span>  
<span style="margin-left: 2em">五十餘里入從西第五方位使以極西地居頂順天</span>  
<span style="margin-left: 2em">府亦必北去正東五十餘度以入東第五方位凡此</span>  
<span style="margin-left: 2em">皆地爲圓形而更得斜容故也</span>  
<span style="margin-left: 3em">任以一處依經緯度安於球</span>  
<span style="margin-left: 1em">地球以東西爲經南北爲緯與天球不異但求緯甚易</span>  
<span style="margin-left: 2em">惟一測其極出地高即得其頂距赤道度而緯定矣</span>  
<span style="margin-left: 2em">若經度必以其所先定處爲界依之東去加度至某</span>  
<span style="margin-left: 2em">處止乃較前所得距度是其本經度也如測緯依測</span>  
<span style="margin-left: 2em">北極諸法即以所得極高度于子午圈上從赤道往</span>  
<span style="margin-left: 2em">極數至本度隨識之球上乃得緯圈應過之界焉測</span>  
<span style="margin-left: 2em">經一法以月食爲準因先知某處月食初虧食甚等</span>  
<span style="margin-left: 2em">時分秒今復得他處所測分秒以之相較必得二處</span>  
<span style="margin-left: 2em">相距之時乃化爲度蓋前處居西所得差度加前經</span>  
<span style="margin-left: 2em">度前處居東所得差度減於前經度乃因得本處之</span>  
<span style="margin-left: 2em">經度次於本球赤道上從前處查得其度而於本度</span>  
<span style="margin-left: 2em">左或右即以距弧所至之處復移至子午圈則本圈</span>  
<span style="margin-left: 2em">交前緯圈之點即某處在地面方位也第月食不常</span>  
<span style="margin-left: 2em">遇更有一法止須測太陰在黃道度并識其臨測之</span>  
<span style="margin-left: 2em">時刻而復考他處所載太陰細行<sub class="note-yuan">務求極準者</sub>應于何時</span>  
<span style="margin-left: 2em">至所測度分則較二時所距化爲度如前加減乃復</span>  
<span style="margin-left: 2em">得二處距經度然太陰每多視差必候其在冬夏至</span>  
<span style="margin-left: 2em">之時于正過子午線上測之乃可免視差也又或以</span>

<span style="margin-left: 2em">日復以他器測日考時得之與鍾正合則較前處必</span>  
<span style="margin-left: 2em">南北相距東西猶同若不合即以所差時加減之乃</span>
