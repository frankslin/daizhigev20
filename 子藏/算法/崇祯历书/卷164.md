<span style="margin-left: 3em">依浑仪制日晷法</span>  
<span style="margin-left: 1em">太阳左旋以定昼夜十二时<sub class="note-yuan">二十四小时</sub>则常依赤道三度</span>  
<span style="margin-left: 2em">四十五分为一刻每十五度为一小时故诸圈以二</span>  
<span style="margin-left: 2em">十四平分之而每分又以四平分之乃得时盘必周</span>  
<span style="margin-left: 2em">分各与赤道皆等之度相应令之竖立与赤道高下</span>  
<span style="margin-left: 2em">等而中依直角安表则表景所射即能定时而赤道</span>  
<span style="margin-left: 2em">晷所繇起也今不必恒以竖立合赤道圈或正立面</span>  
<span style="margin-left: 2em">向南北为立晷或正倒面向天顶为地平晷或复正</span>  
<span style="margin-left: 2em">立面东西正向为子午晷或又正立面偏正南左右</span>  
<span style="margin-left: 2em">或不正立面偏地平各以所向天上之圈得名而各</span>  
<span style="margin-left: 2em">以其面承接日光故立表或正或斜不一即表射景</span>  
<span style="margin-left: 2em">远近与面分时刻广狭亦不得一虽太阳左旋同诸</span>  
<span style="margin-left: 2em">时刻平行同而线则实繇景得射景既异相距之线</span>  
<span style="margin-left: 2em">安得不异此诸晷公有日平行之原而私则各有所</span>  
<span style="margin-left: 2em">异总于本仪可得而明矣</span>  
<span style="margin-left: 3em">求诸晷方位法</span>  
<span style="margin-left: 1em">日晷之制原以度数考求而度数必有相应之定处则</span>  
<span style="margin-left: 2em">又在取准方位焉故凡平面日晷所向方位多变大</span>  
<span style="margin-left: 2em">约相较有二原或较地平即与之为平行有正立有</span>  
<span style="margin-left: 2em">曲立种种不同皆应度数不等或较子午圈亦与之</span>  
<span style="margin-left: 2em">为平行乃有偏左偏右而多寡复以间度为则者又</span>  
<span style="margin-left: 12em">或有偏于地平偏于子午</span>  
<span style="margin-left: 12em">兼地平子午而别为一种</span>  
<span style="margin-left: 12em">总不外此二原乃复得一</span>  
<span style="margin-left: 12em">方位者必先置木或铜取</span>  
<span style="margin-left: 12em">四方直角平面形为甲乙</span>  
<span style="margin-left: 2em">丙丁依其长边面内作戊己线与甲乙为平行线应</span>  
<span style="margin-left: 2em">平分于壬即以壬为心以辛为界作己辛戊半圈乃</span>  
<span style="margin-left: 2em">平分一百八十度也从中线壬辛左右各一象限而</span>  
<span style="margin-left: 2em">另设垂线于壬则定方位之器全矣临用时如求地</span>  
<span style="margin-left: 2em">平方位即令此器以丙丁边倚晷面正立得垂线合</span>  
<span style="margin-left: 2em">壬辛中线者即得其面正与地平同若垂线偏距中</span>  
<span style="margin-left: 2em">线左右则必查象限得晷面前后离地平若干度以</span>  
<span style="margin-left: 2em">垂线依象限辛点之前后度为法或令甲丙边依直</span>  
<span style="margin-left: 2em">角倚晷面得垂线正合壬辛线者即其面正立在地</span>  
<span style="margin-left: 2em">平若得垂线距辛点内外则依其距度于象限上亦</span>  
<span style="margin-left: 2em">可得晷面偏前后之广欲求距子午圈方位即令甲</span>  
<span style="margin-left: 2em">乙边以直角倚晷面从此器中心壬出尺能旋转于</span>  
<span style="margin-left: 2em">半圈诸度尺末设指南针其上随尺同转乃先安器</span>  
<span style="margin-left: 2em">后转尺而以罗针对下顺尺线者为准随以尺距中</span>  
<span style="margin-left: 2em">线之度定晷面距子午圈之广但罗针未免畧差故</span>  
<span style="margin-left: 2em">又一法晷面上界线自上一直下于线上立表表末</span>  
<span style="margin-left: 2em">另悬垂线候日光射垂线之景必合晷面上线乃准</span>  
<span style="margin-left: 2em">且将浑仪依法测得日轮高度而以太阳躔度对高</span>  
<span style="margin-left: 2em">弧则高弧所指地平度或正东西或偏左右因偏若</span>  
<span style="margin-left: 2em">干亦可定晷面离正南北之广也其求重复方位各</span>  
<span style="margin-left: 2em">依所向可得乃向地平如前向子午别有法于晷面</span>  
<span style="margin-left: 2em">立二表任意相距表锐各设垂线距面皆等候日轮</span>  
<span style="margin-left: 2em">出视其二线准对即于仪上测其地平高以与高弧</span>  
<span style="margin-left: 2em">正合而地平经度可得子午圈方位亦定矣</span>  
<span style="margin-left: 3em">制正球日晷</span>  
<span style="margin-left: 1em">凡日晷之表等虽北极出地不等得各时线相距等者</span>  
<span style="margin-left: 2em">谓之正球晷此其制原易可不须球然舍球又无以</span>  
<span style="margin-left: 2em">明其理也如赤道晷因诸时圈与赤道交其相距皆</span>  
<span style="margin-left: 2em">于球心相切设以本仪之枢当表其射景必顺时圈</span>  
<span style="margin-left: 2em">行赤道使各依极安仪而表之长短同则时圈在赤</span>  
<span style="margin-left: 2em">道上相距之度亦同或论赤极晷因其面正合卯酉</span>  
<span style="margin-left: 2em">时圈设本面距仪心任表长短等而诸时圈与中心</span>  
<span style="margin-left: 2em">相切从心过晷面相距不等则正午线合仪枢可当</span>  
<span style="margin-left: 2em">仪面中线而余线左右相距渐远皆平行如上图以</span>  
<span style="margin-left: 2em">长方形为晷面其丙丁横线者即赤道与之相切线</span>  
<span style="margin-left: 9em">其甲午正南北线者即合仪枢从</span>  
<span style="margin-left: 9em">赤道顶过时圈所为线也立圈者</span>  
<span style="margin-left: 9em">乃赤道周平分以指诸时圈相交</span>  
<span style="margin-left: 9em">之点者也盖时圈必皆切表顶<sub class="note-yuan">当地</sub></span>  
<span style="margin-left: 9em"><sub class="note-yuan">心是</sub>而复开之使过至丙丁线上为</span>  
<span style="margin-left: 9em">时线所居之界故本晷诸线交心</span>  
<span style="margin-left: 9em">在面外而以表顶为心彼此相距</span>  
<span style="margin-left: 2em">皆平行今设表长短同虽极高多寡不同其线则二</span>  
<span style="margin-left: 2em">晷相距无异又设甲午线依天枢斜竖令晷面偏东</span>  
<span style="margin-left: 2em">或西则午时线不能定在面之中必依面所偏多寡</span>  
<span style="margin-left: 2em">而晷面亦移左右不等至其面向正东正西乃以中</span>  
<span style="margin-left: 2em">线为卯正酉正余线渐远惟午时线不入晷面而丙</span>  
<span style="margin-left: 2em">丁线则尚为赤道所切虽时线皆平行乃晷则应以</span>  
<span style="margin-left: 2em">一面斜起庶合赤道高度而得中所横线其高低度</span>  
<span style="margin-left: 2em">与之等也</span>  
<span style="margin-left: 3em">制斜球正日晷</span>  
<span style="margin-left: 1em">凡日晷之表等因北极出地不等得各时线相距亦不</span>  
<span style="margin-left: 2em">等者谓之斜球晷其制法原不一今用浑仪列简法</span>  
<span style="margin-left: 2em">如左如制地平晷先起仪依本北极高乃令过极圈</span>  
<span style="margin-left: 2em">正合子午圈而子午圈之左或右每于赤道上查十</span>  
<span style="margin-left: 2em">五度移居子午圈下即识过极圈交地平正南北度</span>  
<span style="margin-left: 2em">复于赤道上查十五度如前移居子午圈下又得过</span>  
<span style="margin-left: 2em">极圈交地平度以此递查递移必至尽过极圈交地</span>  
<span style="margin-left: 2em">平度之界而止则诸时线在晷面相距之广全得焉</span>  
<span style="margin-left: 2em">盖晷面上先作两直线以直角相交其一为子午线</span>  
<span style="margin-left: 2em">其一为卯酉线而以交点为心任意大小作虚圈或</span>  
<span style="margin-left: 2em">用比例尺或依本圈预分度取仪上地平所识度为</span>  
<span style="margin-left: 2em">法<sub class="note-yuan">自卯酉线至子午线或反之以应仪上所识度为准</sub>从心出线过此者皆平</span>  
<span style="margin-left: 2em">晷时线也如北极高四十度以过春分经圈居子午</span>  
<span style="margin-left: 2em">圈下必在地平之正南北初度为午正移之去东十</span>  
<span style="margin-left: 2em">五度<sub class="note-yuan">依赤道度</sub>得经圈东交地平十度<sub class="note-yuan">距子午圈算</sub>为午初移</span>  
<span style="margin-left: 2em">之去西十五度得经圈西交地平亦十度为未初<sub class="note-yuan">距午</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">前后等时恒得距度等</sub>巳正及未正约得二十度半巳初及申</span>  
<span style="margin-left: 2em">初约得三十三度辰正申正得四十八度辰初酉初</span>  
<span style="margin-left: 2em">得六十七度半至卯正酉正则各满九十度而卯酉</span>  
<span style="margin-left: 2em">外与前距时等必皆得度等若求刻线亦依赤道上</span>  
<span style="margin-left: 2em">三度四十五分为一刻如前法递查之安表使之出</span>  
<span style="margin-left: 2em">晷心向午正距晷面渐远以北极出地度为则必悬</span>  
<span style="margin-left: 2em">子午线上以正合本地天枢是也</span>  
<span style="margin-left: 2em">若正南北立晷亦用仪上赤道求距度渐移至子午</span>  
<span style="margin-left: 2em">圈法同前其所异惟在交度盖高弧与过极圈相遇</span>  
<span style="margin-left: 2em">处为交度而高弧则定居东西或卯正酉正苟不用</span>  
<span style="margin-left: 2em">高弧惟以极高所余度求之如北极高四十度依其</span>  
<span style="margin-left: 2em">地制立晷必使仪北极出地平上五十度如前法定</span>  
<span style="margin-left: 2em">时线盖五十度即极高四十度之余度其安表渐距</span>  
<span style="margin-left: 2em">晷面正下以至本地赤道高为止此晷自卯正至酉</span>  
<span style="margin-left: 2em">正独十二小时向南而卯前酉后之时面皆向北其</span>  
<span style="margin-left: 2em">表渐距晷面与前同从上反求得正矣</span>  
<span style="margin-left: 3em">制斜球单偏日晷</span>  
<span style="margin-left: 1em">若不正立面向南北制法略与正立同但用高弧必依</span>  
<span style="margin-left: 2em">其偏容有异盖向南面偏北者必查偏度于子午圈</span>  
<span style="margin-left: 2em">从仪顶去北即此安高弧面向南者则偏度宜求于</span>  
<span style="margin-left: 2em">顶之南以此界出高弧其向北晷面偏南者即依偏</span>  
<span style="margin-left: 2em">度于顶南求界或面反偏北尤宜于顶北求界总之</span>  
<span style="margin-left: 2em">偏度多寡及所向方位皆应查于子午圈距顶南或</span>  
<span style="margin-left: 2em">北之处以安高弧而高弧下至地平恒在正东正西</span>  
<span style="margin-left: 2em">之点表位必在正午时线从晷心渐距其面与高弧</span>  
<span style="margin-left: 2em">上距北极等</span>  
<span style="margin-left: 2em">若不正立面偏正东正西法用立象半圈先于高弧</span>  
<span style="margin-left: 2em">上取偏度如设面向东而偏西三十度令高弧自顶</span>  
<span style="margin-left: 2em">下至正西量三十度为限即安半圈于其限以当地</span>  
<span style="margin-left: 2em">平必识其与极圈相交之点为各时线之距如北极</span>  
<span style="margin-left: 2em">高四十度安高弧及半圈如前将时盘与夏至圈对</span>  
<span style="margin-left: 2em">试于太阳出时必得春分经圈北交半圈十六度卯</span>  
<span style="margin-left: 2em">初交十二度渐过以南交二十六度后七十等度至</span>  
<span style="margin-left: 2em">未正一刻余太阳过半圈西晷面无景其本晷表位</span>  
<span style="margin-left: 2em">偏午正线左右距晷面较地平面高不等求其位法</span>  
<span style="margin-left: 2em">使经圈与立象半圈以直角相交即因经圈自交点</span>  
<span style="margin-left: 2em">至极中弧得表之高半圈自交点至交北地平得表</span>  
<span style="margin-left: 2em">位与午正线相距之远如依前极高等数则表距三</span>  
<span style="margin-left: 2em">十八度高二十二度</span>  
<span style="margin-left: 2em">若正立面偏东或西制法亦与正向南北立晷同独</span>  
<span style="margin-left: 2em">高弧下至地平不得定在正东正西之处必依晷面</span>  
<span style="margin-left: 2em">偏度因之距东西等如面向南偏西三十度即高弧</span>  
<span style="margin-left: 2em">距正西亦北去三十度面偏东必高弧距正西之南</span>  
<span style="margin-left: 2em">向北面偏东西皆倣此但偏晷所得高弧度午前后</span>  
<span style="margin-left: 2em">必异时刻多寡不等试令北极高四十度晷面向南</span>  
<span style="margin-left: 2em">偏西三十度先以高弧北距正西三十度转经圈西</span>  
<span style="margin-left: 2em">十五度<sub class="note-yuan">赤道上取或用时盘亦同</sub>得其交高弧点距顶十二度为</span>

<span style="margin-left: 2em">赤纬度所为起仪依本极高将时盘午正与过极圈</span>  
<span style="margin-left: 2em">合令之转东或西以太阳本方春秋分出没为止则</span>  
<span style="margin-left: 2em">即地平分赤道及二至圈皆不等而赤道恒得六时</span>  
<span style="margin-left: 2em">至午正夏至若过冬至反不及今设去夷地平圈上</span>  
<span style="margin-left: 2em">一时或二时至满半昼时皆并过横线至第六时其</span>  
<span style="margin-left: 2em">线赤道上必交子午圈夏至上未及冬至上已过即</span>  
<span style="margin-left: 2em">因其横线指太阳出没相离时若干依之从浑仪心</span>  
<span style="margin-left: 2em">视晷面必皆斜交赤道而愈离愈斜法必先于晷面</span>  
<span style="margin-left: 2em">界赤道线就内或外加一节气得昼时双数者因以</span>  
<span style="margin-left: 2em">太阳至本节气出没之时定为初时而余时渐依之</span>  
<span style="margin-left: 2em">列也如北极高四十度太阳至立夏昼长约十四时</span>  
<span style="margin-left: 2em">而立冬止得十时皆双数则因立冬日出辰初必得</span>  
<span style="margin-left: 2em">辰正为距日出第一时而余时次之立夏日没戌初</span>  
<span style="margin-left: 2em">而戌正即日没后第一时余时亦随次之今赤道上</span>  
<span style="margin-left: 2em">辰初恒为日出后第一时戌初为日没后之初时即</span>  
<span style="margin-left: 2em">前所识节气线上诸时点与赤道上相应之时点以</span>  
<span style="margin-left: 2em">直线连引之得太阳出没后诸时线也论七政时线</span>  
<span style="margin-left: 2em">其向中线繇赤道等圈则自午前及午后以至地平</span>  
<span style="margin-left: 2em">皆平分各六时盖夏至午前后弧大于冬至午前后</span>  
<span style="margin-left: 2em">之各弧而赤道得居中必与诸时线斜相交是以其</span>  
<span style="margin-left: 2em">线自向中也法先依最长之昼平分时盘或六或十</span>  
<span style="margin-left: 2em">二分遂于地平求各时相距度<sub class="note-yuan">皆依前二卷</sub>带入夏至节</span>  
<span style="margin-left: 2em">气必得其平分午正左右各六时也然后将赤道与</span>  
<span style="margin-left: 2em">夏至相应之时以直线连之得左右皆同皆与斜球</span>  
<span style="margin-left: 2em">斜交赤道其昼长短线总繇赤道纬度任用疎或密</span>  
<span style="margin-left: 2em">故其理不异节气线制法亦同若诸方相距东西线</span>  
<span style="margin-left: 2em">皆子午圈所为与时圈同必以过两极圈取准与制</span>  
<span style="margin-left: 2em">地平晷线同法以上晷面所得诸线依本容因之有</span>  
<span style="margin-left: 2em">异必从其仪上所得圈视仪心至面止俱依前法如</span>  
<span style="margin-left: 2em">试于立晷即地平与赤道为平行故地平纬似节气</span>  
<span style="margin-left: 2em">线形地平经皆上下平行远疎而近午时则密全倣</span>  
<span style="margin-left: 2em">赤极晷线十二舍线皆出地平与子午线相交太阳</span>  
<span style="margin-left: 2em">出没距时线如前地平面同七政线亦出地平交子</span>  
<span style="margin-left: 2em">午线之点昼夜长短亦如节气线诸方相距东西线</span>  
<span style="margin-left: 2em">亦与正时线同制法各随本类全载日晷本欵此不</span>

<span style="margin-left: 3em">地球用法</span>  
<span style="margin-left: 1em">地球以圆形倣地之本体又以旋动反其性情者总欲</span>  
<span style="margin-left: 2em">因各处向顶之自然也盖地居万物之中心随处向</span>  
<span style="margin-left: 2em">天即如圆圈中心出直线无一线不正向其界者然</span>  
<span style="margin-left: 2em">乃制之为球反若偏居<sub class="note-yuan">在地面故</sub>距天此近彼远<sub class="note-yuan">俱以子午圈求</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">天顶故</sub>必宜活动以随处能移至顶与天相近而从之</span>  
<span style="margin-left: 2em">向顶可也故安球必先取平以合于地平使子午圈</span>  
<span style="margin-left: 2em">南北得正而因以诸方向得本所焉后令球前后起</span>  
<span style="margin-left: 2em">或左右转务以本处至中顶乃得向天之势有以二</span>  
<span style="margin-left: 2em">处相提而论或经纬皆异者或经同而纬异者或求</span>  
<span style="margin-left: 2em">二处相距之里及所向之位纬同而经异者总于本</span>  
<span style="margin-left: 2em">球得明矣先论其经纬皆异者法任令一处居顶而</span>  
<span style="margin-left: 2em">从此下高弧至地平使之南北游移以正交其彼处</span>  
<span style="margin-left: 2em">为度乃识交度与顶之中弧化为里则得二处直相</span>  
<span style="margin-left: 2em">距之里数又复识本高弧交地平度因以得彼处较</span>  
<span style="margin-left: 2em">前处所居之方位假如顺天府北极出地四十度令</span>  
<span style="margin-left: 2em">球极起四十度随转球使顺天府至子午圈即以之</span>  
<span style="margin-left: 2em">居顶乃依之安高弧过云南则自顶至交点约二十</span>  
<span style="margin-left: 2em">二度即算得六千里<sub class="note-yuan">依二百七十里一度算</sub>而高弧至地平则</span>  
<span style="margin-left: 2em">从正南去西五十二度即西南第四向位也<sub class="note-yuan">各向详下文</sub></span>  
<span style="margin-left: 2em">又使高弧过星宿海得自顶至本海之中弧为一十</span>  
<span style="margin-left: 2em">八度化得四千八百余里而高弧至地平乃距正南</span>  
<span style="margin-left: 2em">六十二度则因本海较顺天府在西南第三向位矣</span>  
<span style="margin-left: 2em">若经同而纬异即先移其处同居子午圈下以本圈</span>  
<span style="margin-left: 2em">上度识二处各距赤道若干度以之相减乃得其相</span>  
<span style="margin-left: 2em">距度因以化为里如顺天府与南昌府约在同经试</span>  
<span style="margin-left: 2em">于子午圈上得南昌北距赤道二十八度顺天距四</span>  
<span style="margin-left: 2em">十度相差十二度化得三千六百余里设一处在赤</span>  
<span style="margin-left: 2em">道内一处在赤道外各以所得数相加即其相距度</span>  
<span style="margin-left: 2em">乃因以化为里若纬同而经异即先各以其处移至</span>  
<span style="margin-left: 2em">子午圈下从莺岛圈线起至子午圈下止赤道上算</span>  
<span style="margin-left: 2em">各经度以之相减即得二处经度差但距赤道内外</span>

<span style="margin-left: 2em">度小里数亦应少今惟于球上用高弧乃有一简即</span>

<span style="margin-left: 2em">经度应差一百三十度依度求里亦应距三万五千</span>

<span style="margin-left: 2em">度算得为二万四千三百里而相应之向位且亦不</span>
