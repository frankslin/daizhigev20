## 崇祯历书卷之二十二　康熙奏疏

*康熙元年九月十二日至康熙八年五月十二日*

<span style="margin-left: 2em">奏疏八</span>  
<span style="margin-left: 8em">康熙元年九月十二日汤若望题本</span>  
<span style="margin-left: 3em">通政使司通政使加二品又加一级掌钦天监印</span>  
<span style="margin-left: 3em">务臣汤若望谨</span>  
<span style="margin-left: 2em">题为监员考满事窃照臣监办历衙门原与别衙门</span>  
<span style="margin-left: 3em">事理有别当其授官之初部监当堂考试之术业</span>  
<span style="margin-left: 3em">即其后来居官之职业业本家传童而习之供职</span>  
<span style="margin-left: 3em">终身老益精熟非如科目诸司中式以文章奉职</span>  
<span style="margin-left: 3em">以钱谷刑名者比也以此监员无才力不及更无</span>  
<span style="margin-left: 3em">贪酷疲软等弊从来不经考察不许外转不强致</span>  
<span style="margin-left: 3em">仕三年一考满槩皆称职考满不分等第正缘无</span>  
<span style="margin-left: 3em">等第之可分也目今监员有考九年满者臣奉</span>  
<span style="margin-left: 1em">功令欲开等第势苦不能将欲不开有违</span>  
<span style="margin-left: 1em">功令此臣之所不敢决者也监员既不外转止于本衙</span>  
<span style="margin-left: 3em">门遇缺挨升河清难俟惟九年考满准照会典升</span>  
<span style="margin-left: 3em">俸二级以酬其劳不则终身无复上进之阶矣顺</span>  
<span style="margin-left: 3em">治十七年内监员刘有庆掌乗等三十余员考九</span>  
<span style="margin-left: 3em">年满皆得准升俸二级乃臣今奉</span>  
<span style="margin-left: 1em">功令三年考满一等称职者加一级而目今监官数员</span>  
<span style="margin-left: 3em">又皆系九年考满则其为三年者三矣或请加一</span>  
<span style="margin-left: 3em">级或请加二级此又臣之所不敢决者也以上统</span>  
<span style="margin-left: 3em">祈</span>  
<span style="margin-left: 1em">皇上勅部议定以便臣监移送施行缘系属员考满事</span>  
<span style="margin-left: 3em">理臣未敢擅便谨题请</span>  
<span style="margin-left: 1em">旨</span>

<span style="margin-left: 3em">吏部为监员考满事该本部覆考功清吏司案呈</span>  
<span style="margin-left: 3em">奉本部送吏科抄出通政使司通政使加二品又</span>  
<span style="margin-left: 3em">加一级掌钦天监印务汤若望题前事等因康熙</span>  
<span style="margin-left: 3em">元年九月十九日奉</span>

<span style="margin-left: 3em">汤若望疏称臣监办历业本家传童而习之供职</span>  
<span style="margin-left: 3em">终身从来考满槩皆称职无等第之可分也奉</span>  
<span style="margin-left: 1em">功令欲开等弟势苦不能将欲不开有违</span>  
<span style="margin-left: 1em">功令监员既不外转止于本衙门遇缺挨升河清难俟</span>  
<span style="margin-left: 3em">惟九年考满准照会典升俸二级以酬其劳等语</span>  
<span style="margin-left: 3em">查钦天监官职司天文办历止于本衙门遇缺升</span>  
<span style="margin-left: 3em">转原无别衙门及外升转之例查会典职掌开载</span>
