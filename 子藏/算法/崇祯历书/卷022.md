## 崇禎曆書卷之二十二　康熙奏疏

*康熙元年九月十二日至康熙八年五月十二日*

<span style="margin-left: 2em">奏疏八</span>  
<span style="margin-left: 8em">康熙元年九月十二日湯若望題本</span>  
<span style="margin-left: 3em">通政使司通政使加二品又加一級掌欽天監印</span>  
<span style="margin-left: 3em">務臣湯若望謹</span>  
<span style="margin-left: 2em">題爲監員考滿事竊照臣監辦曆衙門原與別衙門</span>  
<span style="margin-left: 3em">事理有別當其授官之初部監當堂考試之術業</span>  
<span style="margin-left: 3em">即其後來居官之職業業本家傳童而習之供職</span>  
<span style="margin-left: 3em">終身老益精熟非如科目諸司中式以文章奉職</span>  
<span style="margin-left: 3em">以錢穀刑名者比也以此監員無才力不及更無</span>  
<span style="margin-left: 3em">貪酷疲軟等弊從來不經考察不許外轉不强致</span>  
<span style="margin-left: 3em">仕三年一考滿槩皆稱職考滿不分等第正緣無</span>  
<span style="margin-left: 3em">等第之可分也目今監員有考九年滿者臣奉</span>  
<span style="margin-left: 1em">功令欲開等第勢苦不能將欲不開有違</span>  
<span style="margin-left: 1em">功令此臣之所不敢决者也監員既不外轉止於本衙</span>  
<span style="margin-left: 3em">門遇缺挨陞河清難俟惟九年考滿准照會典陞</span>  
<span style="margin-left: 3em">俸二級以酬其勞不則終身無復上進之階矣順</span>  
<span style="margin-left: 3em">治十七年內監員劉有慶掌乗等三十餘員考九</span>  
<span style="margin-left: 3em">年滿皆得准陞俸二級乃臣今奉</span>  
<span style="margin-left: 1em">功令三年考滿一等稱職者加一級而目今監官數員</span>  
<span style="margin-left: 3em">又皆係九年考滿則其爲三年者三矣或請加一</span>  
<span style="margin-left: 3em">級或請加二級此又臣之所不敢决者也以上統</span>  
<span style="margin-left: 3em">祈</span>  
<span style="margin-left: 1em">皇上勅部議定以便臣監移送施行緣係屬員考滿事</span>  
<span style="margin-left: 3em">理臣未敢擅便謹題請</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 3em">康熙元年九月十二日題十九日奉</span>  
<span style="margin-left: 1em">旨該部議奏</span>  
<span style="margin-left: 9em">康熙元年十月初十日吏部奏疏</span>  
<span style="margin-left: 3em">吏部爲監員考满事該本部覆考功清吏司案呈</span>  
<span style="margin-left: 3em">奉本部送吏科抄出通政使司通政使加二品又</span>  
<span style="margin-left: 3em">加一級掌欽天監印務湯若望題前事等因康熙</span>  
<span style="margin-left: 3em">元年九月十九日奉</span>  
<span style="margin-left: 1em">旨該部議奏欽此欽遵抄出到部議得掌欽天監印務</span>  
<span style="margin-left: 3em">湯若望疏稱臣監辦曆業本家傳童而習之供職</span>  
<span style="margin-left: 3em">終身從來考滿槩皆稱職無等第之可分也奉</span>  
<span style="margin-left: 1em">功令欲開等弟勢苦不能將欲不開有違</span>  
<span style="margin-left: 1em">功令監員既不外轉止於本衙門遇缺挨陞河清難俟</span>  
<span style="margin-left: 3em">惟九年考滿准照會典陞俸二級以酬其勞等語</span>  
<span style="margin-left: 3em">查欽天監官職司天文辦曆止於本衙門遇缺陞</span>  
<span style="margin-left: 3em">轉原無別衙門及外陞轉之例查會典職掌開載</span>  
<span style="margin-left: 3em">欽天監宫九年考滿有缺陞缺無缺陞俸二級以</span>  
<span style="margin-left: 3em">酬其勞等語應將欽天監官員原不與部院官一</span>  
<span style="margin-left: 3em">體應照會典例行可也等因康熙元年十月初五</span>  
<span style="margin-left: 3em">日奉</span>  
<span style="margin-left: 1em">旨依議欽此欽遵抄部送司相應劄付案呈到部擬合</span>  
<span style="margin-left: 3em">就行爲此合劄該監遵奉</span>  
<span style="margin-left: 1em">旨內事理欽遵施行須至劄付者</span>  
<span style="margin-left: 4em">康熙元年十月初十日</span>  
<span style="margin-left: 1em">康熙七年十一月二十三日上諭<sub class="note-jiao">校：日抄本據熙朝定案輯僅十條以下重輯</sub></span>  
<span style="margin-left: 3em">康熙七年十一月二十三日</span>  
<span style="margin-left: 1em">欽遣內院大學士李霨等捧</span>  
<span style="margin-left: 1em">上諭一道諭楊光先胡振龯李光顯吳明烜安文思利</span>  
<span style="margin-left: 3em">類思南懷仁</span>  
<span style="margin-left: 2em">天文最爲精微曆法關係國家要務爾等勿懷夙仇</span>  
<span style="margin-left: 3em">各執己見以己爲是以彼爲非互相爭兢孰者爲</span>  
<span style="margin-left: 3em">是即當遵行非者更改務須實心將天文曆法詳</span>  
<span style="margin-left: 3em">定以成至善之法本日又奉</span>  
<span style="margin-left: 1em">上諭爾等同禮部尚書布顏郝惟納去測驗日影</span>  
<span style="margin-left: 1em">欽此</span>  
<span style="margin-left: 1em">欽遵十一月二十四日內院大學士李霨學士多諾吳</span>  
<span style="margin-left: 3em">格塞卓令安范承謨禮部尚書布顏郝惟納等帶</span>  
<span style="margin-left: 3em">領欽天監監正楊光先監副吳明垣及南懷仁等</span>  
<span style="margin-left: 3em">到觀象臺預推正午日影所止之處測驗合與不</span>  
<span style="margin-left: 3em">合據楊光先吳明垣說我等日影所到之處以後</span>  
<span style="margin-left: 3em">方知推算等因具題奉</span>  
<span style="margin-left: 1em">旨楊光先吳明垣先問爾等既稱能推日影今又怎說</span>  
<span style="margin-left: 3em">不知着伊等一並帶去將日影遮掩測驗</span>  
<span style="margin-left: 1em">欽此本日隨到觀象臺叫楊光先吳明垣推正午日影</span>  
<span style="margin-left: 3em">所到之處據楊光先等說我等所到日影之處若</span>  
<span style="margin-left: 3em">離表影不能推算但日影所到之處以後方知推</span>  
<span style="margin-left: 3em">算等語南懷仁等將表影高做成八尺四寸九分</span>  
<span style="margin-left: 3em">正午日影到一太六尺六寸六分之處畫成界限</span>  
<span style="margin-left: 3em">日到正午我等公同看得日影正合着所畫之制</span>  
<span style="margin-left: 3em">楊光先說影已多九分等語吳明烜說已多六分</span>  
<span style="margin-left: 3em">等語等因本日具題</span>  
<span style="margin-left: 1em">奉旨二十五日二十六日再測吳明烜所造七政及民</span>  
<span style="margin-left: 3em">曆俱交與南懷仁若有差錯之處寫在傍邊</span>  
<span style="margin-left: 1em">欽此本日與南懷仁等定高二尺二寸的木表將二十</span>  
<span style="margin-left: 3em">五日正午日影所到之處交與推算據南懷仁等</span>  
<span style="margin-left: 3em">推算日影所到四尺三寸四分五厘之處止預先</span>  
<span style="margin-left: 3em">畫定界限於二十五日在午門前放在平地看得</span>  
<span style="margin-left: 3em">正午日影正合着所畫之界又在觀象臺表影上</span>  
<span style="margin-left: 3em">二十六日正午日影所到之處交與推算南懷仁</span>  
<span style="margin-left: 3em">等將測驗表影做成高八尺五分五厘所推日影</span>  
<span style="margin-left: 3em">所到之處一丈五尺八寸三分之處止畫制本日</span>  
<span style="margin-left: 3em">具題奉</span>  
<span style="margin-left: 1em">旨知道了將吳明垣所算七政及民曆着南懷仁驗看</span>  
<span style="margin-left: 3em">差錯之處寫出俟報部之日爾等議奏</span>  
<span style="margin-left: 10em">康熙七年十二月南懷仁奏本</span>  
<span style="margin-left: 3em">遠西臣南懷仁謹</span>  
<span style="margin-left: 2em">奏爲遵</span>  
<span style="margin-left: 1em">旨查對曆本謹據實列冊回奏事本年十一月二十六</span>  
<span style="margin-left: 3em">日蒙</span>  
<span style="margin-left: 1em">皇上發下欽天監監副吳明烜所造康熙八年七政民</span>  
<span style="margin-left: 3em">曆二本着臣查對差錯切念臣遠方孤旅荷蒙</span>  
<span style="margin-left: 1em">皇上特知之隆敢不竭力殫心以求無負我</span>  
<span style="margin-left: 1em">皇上憲天授時之至意今以臣所推曆法查對本曆所</span>  
<span style="margin-left: 3em">載相去甚遠如本曆載有康熙八年閏十二月應</span>  
<span style="margin-left: 3em">是九年正月者有一年節氣或先天或後天一二</span>  
<span style="margin-left: 3em">日有餘者有一年兩春分兩秋分者有每月晝夜</span>  
<span style="margin-left: 3em">長短槩不合於日出入時刻者有五星伏見日失</span>  
<span style="margin-left: 3em">天至三十日有餘者如此等錯俱已條詳冊内即</span>  
<span style="margin-left: 3em">使本曆所定無差亦只爲直隷一方之曆而不可</span>  
<span style="margin-left: 3em">通用之天下各省况爲一方且錯誤種種乎蓋一</span>  
<span style="margin-left: 3em">年晝夜長短日出入時刻與節氣時刻隨地不同</span>  
<span style="margin-left: 3em">并交食時刻食分多寡無不如之故據本曆有外</span>  
<span style="margin-left: 3em">省日日失天至十五度有餘者矣今我</span>  
<span style="margin-left: 1em">皇上德威遠播拜玉帛數十國奉正朔者幾萬里自</span>  
<span style="margin-left: 2em">京師以至四訖豈可使一年俱不得其真晝夜真時</span>  
<span style="margin-left: 3em">刻真節氣哉概天下之理惟不明其所以然則已</span>  
<span style="margin-left: 3em">然者茫茫不知何來其當然者昧昧不知何往今</span>  
<span style="margin-left: 3em">本曆差錯之所以然誠非疏内數言可盡其詳具</span>  
<span style="margin-left: 3em">在臣所較對曆法書百餘卷内且此法非一時一</span>  
<span style="margin-left: 3em">人之力所能全備遠方諸曆學專家互相考訂其</span>  
<span style="margin-left: 3em">來已久自八中邦部監公測密合者屢矣若閏月</span>  
<span style="margin-left: 3em">節氣等差即以本年十一月所驗表影可據凡欲</span>  
<span style="margin-left: 3em">定某日表影之長短必先定本日時刻太陽所躔</span>  
<span style="margin-left: 3em">某節氣度分正午之刻在地平高下日日不同表</span>  
<span style="margin-left: 3em">影之長短隨之前臣所預定表影長短合天既已</span>

<span style="margin-left: 3em">明矣抑臣九萬里外之孤旅無家無親且自幼學</span>  
<span style="margin-left: 3em">道口不言人之短長兹叨奉</span>

<span style="margin-left: 1em">明綸恩逾格外微臣顧分難安謹再疏瀝辭仰祈</span>  
<span style="margin-left: 1em">俯允事案炤該臣奏爲驚聞</span>  
<span style="margin-left: 1em">寵命等事一疏三月十七日奉</span>  
<span style="margin-left: 1em">旨南懷仁着遵前</span>  
<span style="margin-left: 1em">旨供職不必控辭該部知道欽此臣恭捧</span>  
<span style="margin-left: 1em">天言不勝悚惕</span>  
<span style="margin-left: 1em">浩蕩之恩頂踵靡報第臣草茅微悃切切有請者臣生</span>  
<span style="margin-left: 3em">長極西自幼矢志不婚不宦惟以學道修身爲務</span>  
<span style="margin-left: 3em">業經三十餘年荷蒙</span>  
<span style="margin-left: 1em">皇上不棄庸材特畀簡用犬馬尚知報主臣非木石敢</span>  
<span style="margin-left: 3em">不勉力以答</span>  
<span style="margin-left: 1em">高深臣一疏再疏控辭官職出於臣至情非敢勉强瀆</span>  
<span style="margin-left: 3em">陳至於曆法天文一切事務敢不竭蹶管理寧憚</span>  
<span style="margin-left: 3em">煩勞如唐一行亦任修曆法亦未嘗授職伏乞</span>  
<span style="margin-left: 1em">皇上憫臣之心察臣之悃允臣微志臣感激</span>  
<span style="margin-left: 1em">皇恩寧有涯埃項者恭遇我</span>  
<span style="margin-left: 1em">皇上面詢臣藝業如測量奇器等製臣少時涉獵係臣</span>  
<span style="margin-left: 3em">所長容臣按圖規製各樣測天儀器節次殫心料</span>  
<span style="margin-left: 3em">理以備</span>  
<span style="margin-left: 1em">皇上採擇省覧臣言出由衷非收蹈習巧餙謹冒昧悚</span>  
<span style="margin-left: 3em">慄伏乞</span>  
<span style="margin-left: 1em">睿鑒施行爲此具本奏</span>  
<span style="margin-left: 1em">聞</span>  
<span style="margin-left: 3em">康熙八年五月　　日具奏本月　　日奉</span>  
<span style="margin-left: 1em">旨禮部議奏六月初十日蒙</span>  
<span style="margin-left: 3em">禮部議覆十五日奉</span>  
<span style="margin-left: 1em">旨據奏南懷仁控辭官職其曆法天文一切事務俱殫</span>  
<span style="margin-left: 2em">心料理情詞懇切准其所請每年應炤何品給俸着</span>  
<span style="margin-left: 2em">議奏</span>  
<span style="margin-left: 9em">康熙八年五月十二日馬祜題本</span>  
<span style="margin-left: 3em">欽天監監正加一級臣馬祜等謹</span>  
<span style="margin-left: 2em">題爲請</span>  
<span style="margin-left: 1em">旨事准本監監副南懷仁移會內開蒙禮部札付二月</span>  
<span style="margin-left: 3em">二十九日奉</span>  
<span style="margin-left: 1em">上諭諭禮部曆法關係重大必考驗詳明始爲允當觀</span>  
<span style="margin-left: 3em">象臺所有渾儀簡儀測驗表影等器自古觀候不</span>  
<span style="margin-left: 3em">可廢棄今年久損壞衙捨傾頹著交與工部令該</span>  
<span style="margin-left: 3em">衙門南懷仁等修正詳驗期於符合又前會議本</span>  
<span style="margin-left: 3em">內欲將紫氣星停止開寫紫氣月孛羅睺計都此</span>  
<span style="margin-left: 3em">四星向來曆日既經開寫今不宜獨缺其一以後</span>  
<span style="margin-left: 3em">欽天監衙門官推算曆日著仍將紫氣星一並推</span>  
<span style="margin-left: 3em">算開寫爾部即遵行特</span>  
<span style="margin-left: 1em">諭欽此欽遵除紫氣遵諭開寫外懷仁恭繹明綸仰見</span>  
<span style="margin-left: 3em">我</span>  
<span style="margin-left: 1em">皇上留心欽若至詳至慎然懷仁於此敬有請焉竊惟</span>  
<span style="margin-left: 3em">從來製造儀器原依曆法而作用之考驗以證合</span>  
<span style="margin-left: 3em">天故其要有二一務合於天行如儀器中之黃赤</span>  
<span style="margin-left: 3em">諸道並南北兩極等必與天上之黃赤諸道南北</span>  
<span style="margin-left: 3em">兩極等相符一務合於曆法如儀器中所列度分</span>  
<span style="margin-left: 3em">刻數必與曆法所定分天之度分刻數相符兩者</span>  
<span style="margin-left: 3em">失一則所設儀器徒成虛具而無實用矣前蒙</span>  
<span style="margin-left: 1em">皇上命諸王貝勒大臣詳經會議奉</span>  
<span style="margin-left: 1em">旨簡用九十六刻之曆法夫此九十六刻之法原與天</span>  
<span style="margin-left: 3em">上諸道三百六十整度兩相符合計一時八刻每</span>  
<span style="margin-left: 3em">一刻爲三度四十五分而無奇零則一時八刻符</span>  
<span style="margin-left: 3em">合天上三十整度矣今一百刻之法既不合天則</span>  
<span style="margin-left: 3em">三百六十五度之法遂亦因之而不合而臺上一</span>  
<span style="margin-left: 3em">百刻與三百六十五度之儀器俱不適於用矣茲</span>  
<span style="margin-left: 3em">奉</span>  
<span style="margin-left: 1em">上諭著懷仁修正詳驗或將觀象臺百刻儀器修正爲</span>  
<span style="margin-left: 3em">九十六刻並三百六十五度儀器修正三百六十</span>  
<span style="margin-left: 3em">度每度六十分或請</span>  
<span style="margin-left: 1em">勅該部庀材鳩工容懷仁指授另行製造細緻輕巧儀</span>  
<span style="margin-left: 3em">器更便測驗之用於</span>  
<span style="margin-left: 1em">天行曆法俱相符合矣等因到臣緣係欽奉</span>  
<span style="margin-left: 1em">上諭修正儀器事理臣等未敢擅便謹</span>  
<span style="margin-left: 2em">題請</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 3em">康熙八年五月十二日題本月十五日奉</span>  
<span style="margin-left: 1em">旨該部議奏</span>
