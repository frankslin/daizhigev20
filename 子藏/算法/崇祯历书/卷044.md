<span style="margin-left: 1em">每弧每角有八種線曰正弦曰正切線曰正割線曰正</span>  
<span style="margin-left: 2em">矢曰餘弦曰餘切線曰餘割線曰餘矢并全數爲九</span>  
<span style="margin-left: 2em">種諸線內各有相當之理皆依三邊形等角比例法</span>  
<span style="margin-left: 8em"><sub class="note-yuan">幾何六卷四題</sub>如上圖丙丁爲正弧甲丁爲</span>  
<span style="margin-left: 8em">正弦丙辛爲正切線乙辛爲正割線</span>  
<span style="margin-left: 8em">甲丙爲正矢戊丁爲餘弦己壬爲餘</span>  
<span style="margin-left: 2em">切線乙壬爲餘割線戊己爲餘矢乙己乙丁乙丙皆</span>  
<span style="margin-left: 2em">全數也即辛丙乙壬己乙兩形相似何者己丙兩直</span>  
<span style="margin-left: 2em">角己乙辛丙爲平行線辛乙直線割兩平行即其相</span>  
<span style="margin-left: 2em">對兩內角必等既丙辛乙壬乙己兩角等即其對邊</span>  
<span style="margin-left: 2em">相似</span>  
<span style="margin-left: 1em">一全數爲正弦餘割線兩率之中率</span>  
<span style="margin-left: 2em">如丙丁弧之正弦爲甲丁全數爲丁乙餘割線爲乙</span>  
<span style="margin-left: 2em">壬則甲丁與丁乙若乙己與乙壬矣丁乙乙己皆全</span>  
<span style="margin-left: 2em">數必等則甲丁與丁乙若丁乙與乙壬也</span>  
<span style="margin-left: 2em">又全數爲餘弦正割線之中率如戊丁與丁乙若丁</span>  
<span style="margin-left: 2em">乙<sub class="note-yuan">與乙丙等故</sub>與乙辛</span>  
<span style="margin-left: 2em">一系凡四率全數爲中率<sub class="note-yuan">或二或三</sub>若第一率爲正弦即</span>  
<span style="margin-left: 5em">棄正弦而變餘割線爲中率全數爲第一省</span>  
<span style="margin-left: 5em">而一　若第一率爲餘弦則變正割線爲中</span>  
<span style="margin-left: 5em">率　若第一率爲正割線則變餘弦</span>  
<span style="margin-left: 2em">若第一率爲餘割線則變正弦　凡所變者皆以易</span>  
<span style="margin-left: 2em">全數而使爲第一率</span>  
<span style="margin-left: 2em">論曰凡有連比例之三率一率與二<sub class="note-yuan">如二與六</sub>若二率與</span>  
<span style="margin-left: 2em">三<sub class="note-yuan">如六與十八</sub>別有二數其比例若連理之一率與二<sub class="note-yuan">如八</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">與二十四</sub>即可代用或連理之一率與二<sub class="note-yuan">如二與六</sub>若他數與</span>  
<span style="margin-left: 2em">別數<sub class="note-yuan">八與二十四</sub>可也或連理之二率與三<sub class="note-yuan">六與十八</sub>若他數</span>  
<span style="margin-left: 2em">與別數<sub class="note-yuan">八與二十四</sub>亦可也爲其比例等故也<sub class="note-yuan">皆三之一</sub>今連</span>  
<span style="margin-left: 2em">理之一率爲甲<sub class="note-yuan">正弦</sub>二率爲乙<sub class="note-yuan">全數</sub>三率爲丙<sub class="note-yuan">餘割線</sub>次有</span>  
<span style="margin-left: 2em">斷理之第三率丁第四率戊即可代用謂一甲<sub class="note-yuan">正弦</sub>與</span>  
<span style="margin-left: 2em">二乙<sub class="note-yuan">全數</sub>若三丁與四戊可也謂二乙<sub class="note-yuan">全數</sub>與三丙<sub class="note-yuan">餘割線</sub></span>  
<span style="margin-left: 2em">若三丁與四戊亦可也是于連理之三率二比中棄</span>  
<span style="margin-left: 2em">前比而用後比初以全數爲第二餘割爲三今以全</span>  
<span style="margin-left: 2em">數爲一餘割爲二也</span>  
<span style="margin-left: 2em">如三十八度一十七分之正弦六一九五五與全數</span>  
<span style="margin-left: 2em">若三十度之正弦與某數常法二三率相乘以一率</span>  
<span style="margin-left: 2em">爲法而一得第四今法用三十八度一十七分之餘</span>  
<span style="margin-left: 2em">割線一六一四〇七爲二率以易全數而爲第一以</span>  
<span style="margin-left: 2em">二三率相乘即得第四何者正弦全數餘割線爲連</span>  
<span style="margin-left: 2em">比例故也</span>  
<span style="margin-left: 2em">二系凡四率中無全數若第一率爲正弦則變餘割</span>  
<span style="margin-left: 2em">線爲第一率若第一率爲餘弦則變正割線爲第一</span>  
<span style="margin-left: 2em">率法用一二率相乘得數以全爲法去後五位所存</span>  
<span style="margin-left: 2em">若干位與全數等而一又以乘第三率得數如前而</span>  
<span style="margin-left: 2em">一得四率<sub class="note-yuan">名爲而一者再皆以全數爲法止减末位不難也常法一乘一除此用兩乘猶是捷</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">法</sub></span>  
<span style="margin-left: 2em">假如一十八度四十〇分之正弦三二〇〇六與二</span>  
<span style="margin-left: 2em">十五度三十七分之正弦四三二三一若六十三度</span>  
<span style="margin-left: 2em">三十二分之切線二〇〇八六二與某數其常法二</span>  
<span style="margin-left: 2em">三率相乘第一率而一今用捷法取一十八度四十</span>  
<span style="margin-left: 2em">分之餘割線三一二四三九乘第二率四三二三一</span>  
<span style="margin-left: 2em">得一三五〇七〇〇〇〇〇〇爲實以全數爲法而</span>  
<span style="margin-left: 2em">一得一三五〇七〇又以第三率一二四三二二乘</span>  
<span style="margin-left: 2em">之得一六七九二二〇〇〇〇〇以全爲法而一得</span>  
<span style="margin-left: 2em">一六七九二二爲四率</span>  
<span style="margin-left: 8em">二三〇七三五六十四度十九分之正割線</span>  
<span style="margin-left: 2em">又假設三率如一二二三四一</span>  
<span style="margin-left: 8em">二三四三二</span>  
<span style="margin-left: 7em">第一率變取六十四度十九分之餘弦</span>  
<span style="margin-left: 7em">四三三四〇以乘第二率得數减後五</span>  
<span style="margin-left: 7em">位以所存乘第三率得數又减後五位</span>  
<span style="margin-left: 2em">所存即第四率</span>  
<span style="margin-left: 1em">二全數爲正餘兩切線之中率</span>  
<span style="margin-left: 2em">如上圖辛丙與丙乙若乙己與己壬何者丙乙乙己</span>  
<span style="margin-left: 2em">皆全數則辛丙丙乙<sub class="note-yuan">或乙己</sub>己壬爲三率連比例</span>  
<span style="margin-left: 2em">系凡四率斷比例全數爲中率若第一爲正切線變</span>  
<span style="margin-left: 2em">餘切線爲中率以易全爲第一若第一爲餘切線變</span>  
<span style="margin-left: 2em">正切線爲中率以易全爲第一</span>  
<span style="margin-left: 1em">三正弦與餘弦若全數與餘切線餘弦與正弦若全數</span>  
<span style="margin-left: 2em">與正切線</span>  
<span style="margin-left: 2em">如前圖甲丁與丁戊<sub class="note-yuan">即甲乙故</sub>若乙己與己壬戊丁<sub class="note-yuan">即甲乙故</sub></span>  
<span style="margin-left: 2em">與甲丁若乙丙與丙辛</span>  
<span style="margin-left: 2em">系四率斷比例若一二率爲正弦與餘弦變爲全數</span>  
<span style="margin-left: 2em">與餘切線若爲餘弦與正弦變爲全數與正切線</span>  
<span style="margin-left: 1em">四凡兩弧之正割線與其餘弦爲互相視之線兩弧之</span>  
<span style="margin-left: 2em">餘割線與其正弦爲互相視之線</span>  
<span style="margin-left: 7em">如上圖丙癸丙丁兩弧丙癸弧之正割</span>  
<span style="margin-left: 7em">線爲乙寅丙丁弧之正割線爲乙辛丙</span>  
<span style="margin-left: 7em">癸弧之餘弦爲庚癸丙丁弧之餘弦爲</span>  
<span style="margin-left: 7em">戊丁則乙寅與乙辛若戊丁與癸庚</span>  
<span style="margin-left: 2em">論曰全數在正弧<sub class="note-yuan">丙癸</sub>爲其正割線<sub class="note-yuan">乙寅</sub>及其餘弦<sub class="note-yuan">癸庚</sub>之</span>  
<span style="margin-left: 2em">中率在他弧<sub class="note-yuan">丙丁</sub>亦爲其正割線<sub class="note-yuan">乙辛</sub>及其餘弦<sub class="note-yuan">丁戊</sub>之中</span>  
<span style="margin-left: 2em">率兩理之各前後矩內形各與全數上方形等<sub class="note-yuan">各爲其中</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">率故</sub>即兩矩內形自相等其邊互相視<sub class="note-yuan">幾何六卷十四</sub></span>

<span style="margin-left: 1em">論卷中諸圈皆以曲線當圓球之大圈相交相截人目</span>  
<span style="margin-left: 1em">視球曲面或近或遠或上或下或左或右所見不同有</span>  
<span style="margin-left: 1em">時視曲線而爲直線即同是曲線而形象不一蓋平面</span>  
<span style="margin-left: 1em">圖球不能盡球之理宜從論說中領其意義乃得耳</span>

<span style="margin-left: 1em">五大圈與本極距一象限九十度</span>  
<span style="margin-left: 1em">六大圈交兩大圈若作直角則元圈之極在兩圈之交</span>  
<span style="margin-left: 2em">如赤道與極至交圈極分交圈爲直角則兩圈之交</span>  
<span style="margin-left: 2em">在赤道極</span>
