<span style="margin-left: 2em">相似</span>  
<span style="margin-left: 1em">一全数为正弦余割线两率之中率</span>  
<span style="margin-left: 2em">如丙丁弧之正弦为甲丁全数为丁乙余割线为乙</span>  
<span style="margin-left: 2em">壬则甲丁与丁乙若乙己与乙壬矣丁乙乙己皆全</span>  
<span style="margin-left: 2em">数必等则甲丁与丁乙若丁乙与乙壬也</span>  
<span style="margin-left: 2em">又全数为余弦正割线之中率如戊丁与丁乙若丁</span>  
<span style="margin-left: 2em">乙<sub class="note-yuan">与乙丙等故</sub>与乙辛</span>  
<span style="margin-left: 2em">一系凡四率全数为中率<sub class="note-yuan">或二或三</sub>若第一率为正弦即</span>

<span style="margin-left: 5em">而一　若第一率为余弦则变正割线为中</span>  
<span style="margin-left: 5em">率　若第一率为正割线则变余弦</span>  
<span style="margin-left: 2em">若第一率为余割线则变正弦　凡所变者皆以易</span>  
<span style="margin-left: 2em">全数而使为第一率</span>  
<span style="margin-left: 2em">论曰凡有连比例之三率一率与二<sub class="note-yuan">如二与六</sub>若二率与</span>  
<span style="margin-left: 2em">三<sub class="note-yuan">如六与十八</sub>别有二数其比例若连理之一率与二<sub class="note-yuan">如八</sub></span>

<span style="margin-left: 2em">别数<sub class="note-yuan">八与二十四</sub>可也或连理之二率与三<sub class="note-yuan">六与十八</sub>若他数</span>  
<span style="margin-left: 2em">与别数<sub class="note-yuan">八与二十四</sub>亦可也为其比例等故也<sub class="note-yuan">皆三之一</sub>今连</span>  
<span style="margin-left: 2em">理之一率为甲<sub class="note-yuan">正弦</sub>二率为乙<sub class="note-yuan">全数</sub>三率为丙<sub class="note-yuan">余割线</sub>次有</span>

<span style="margin-left: 2em">若三丁与四戊亦可也是于连理之三率二比中弃</span>  
<span style="margin-left: 2em">前比而用后比初以全数为第二余割为三今以全</span>  
<span style="margin-left: 2em">数为一余割为二也</span>
