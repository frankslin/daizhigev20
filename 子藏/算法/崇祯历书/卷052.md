<span style="margin-left: 1em">历指三卷　　恒星二</span>  
<span style="margin-left: 2em">恒星本行第一　五章</span>  
<span style="margin-left: 1em">前卷所借西史测星之法为恒星历之基本此卷应准</span>  
<span style="margin-left: 2em">前法仍借旧测诸星经纬度立表以待推算然旧测</span>  
<span style="margin-left: 2em">在万历十三四年今相去四十余载不复可用宜作</span>  
<span style="margin-left: 2em">新表又须先明新旧所以异同之故不得不论其本</span>  
<span style="margin-left: 2em">行次乃定时下各星之经纬度表</span>  
<span style="margin-left: 3em">恒星本行之征</span>  
<span style="margin-left: 1em">七政之运行也时相会时相对其与恒星也时相近时</span>  
<span style="margin-left: 2em">相远其本曜之光时消时长<sub class="note-yuan">月有晦朔弦望近论大白辰星荧惑皆有之</sub></span>  
<span style="margin-left: 2em">其东西出没于卯酉也时南时北其过子午圈也时</span>  
<span style="margin-left: 2em">高时下人目所见变动不居故从古迄今人人知其</span>  
<span style="margin-left: 2em">自有运动因生各曜推步之法无可疑者若恒星则</span>  
<span style="margin-left: 2em">无先相会后相望无先相近后相远其光不消不长</span>  
<span style="margin-left: 2em">其东西出没其过子午圈虽百数十年无从觉其有</span>  
<span style="margin-left: 2em">差安知其有本运动乎夫恒星移运非一世之事前</span>  
<span style="margin-left: 2em">古历家既已测其定度欲更得其转移之数必百年</span>  
<span style="margin-left: 2em">数十年谁能待之是故一人之身绝无能觉之缘也</span>  
<span style="margin-left: 2em">后来学者传受先贤所测度数复身试测之往往见</span>  
<span style="margin-left: 2em">其不合先人所见与四节相近者后人测之渐远又</span>  
<span style="margin-left: 2em">后之人测之又渐远从是推知恒星有本行之实度</span>  
<span style="margin-left: 2em">分及其移易之所以然也如角宿大星古地未恰于</span>  
<span style="margin-left: 2em">周赧王二十年丙寅测得其经度在秋分前鹑尾宫</span>  
<span style="margin-left: 2em">二十二度后多禄某于汉顺帝永和三年戊寅测在</span>  
<span style="margin-left: 2em">鹑尾宫二十七度后尼谷老于嘉靖四年乙酉测得</span>  
<span style="margin-left: 2em">过秋分在寿星宫一十七度后第谷于万历十三年</span>  
<span style="margin-left: 2em">乙酉测在寿星宫一十八度轩辕星亦如之周赧王</span>  
<span style="margin-left: 2em">丙寅在鹑首宫二十七度汉永和戊寅在鹑火宫三</span>  
<span style="margin-left: 2em">度三十分今测在鹑火宫二十四度四十分余星皆</span>  
<span style="margin-left: 2em">如之是以帝尧之世日中星鸟谓春分则初昏时鹑</span>  
<span style="margin-left: 2em">火中也而周末在井今在参矣尧时冬至日在虚汉</span>  
<span style="margin-left: 2em">唐在斗今在箕矣非其自有本行安得冬至离虚宿</span>  
<span style="margin-left: 2em">而西鸟离子午而东乎</span>  
<span style="margin-left: 3em">恒星本行之极</span>  
<span style="margin-left: 1em">十政本行以黄道为道以黄道极为极终古恒然何繇</span>  
<span style="margin-left: 2em">知之盖人目所见出没于地平之卯酉南北不一过</span>  
<span style="margin-left: 2em">午之高度多寡不一又有时离赤道而南有时复还</span>  
<span style="margin-left: 2em">于赤道之北以此知其行必非循赤道行以此知其</span>  
<span style="margin-left: 2em">极必非宗赤道极也然七政之循黄道或浃旬可得</span>  
<span style="margin-left: 2em">或周岁可得恒星之循黄道必上下古今然后可得</span>  
<span style="margin-left: 2em">何者上古有测中古有测今时有测乃恒星出没地</span>  
<span style="margin-left: 2em">平之处今非中古之处中古非上古之处其过午之</span>  
<span style="margin-left: 2em">轨高亦然而恒移不定者赤道之距度恒定不移者</span>  
<span style="margin-left: 2em">黄道之距度也以此推知其循黄道行宗黄道极与</span>  
<span style="margin-left: 2em">七政同理灼然无疑矣更征实论之凡恒星距赤道</span>  
<span style="margin-left: 2em">之度从星纪迄鹑首则在赤道之南者必古多而今</span>  
<span style="margin-left: 2em">渐少在赤道之北者必古少而今渐多不似七政之</span>  
<span style="margin-left: 2em">行从冬至逾春分而夏至自南趋北乎从鹑首迄星</span>  
<span style="margin-left: 2em">纪则在赤道之南者必古少而今渐多在赤道之北</span>  
<span style="margin-left: 2em">者必古多而今渐少不似七政之行从夏至逾秋分</span>  
<span style="margin-left: 2em">而冬至自北趋南乎如外屏第二星尧时在赤道南</span>  
<span style="margin-left: 2em">十二度强因此时入娵訾宫故距度渐减至多禄某</span>  
<span style="margin-left: 2em">尚在南二度四十九分后渐过赤道以北今北距五</span>  
<span style="margin-left: 2em">度矣井宿距星<sub class="note-jiao">校：法圖本井宿距星作井宿龯星</sub>尧时在赤道北一</span>  
<span style="margin-left: 2em">十四度弱因入实沈宫故距度渐加至多禄某得二</span>  
<span style="margin-left: 2em">十度正今北距二十三度与夏至圈相近也又轩辕</span>  
<span style="margin-left: 2em">大星尧时距赤道北二十四度因入鹑火宫故距度</span>  
<span style="margin-left: 2em">渐减至多禄某得一十九度三十分今止一十三度</span>  
<span style="margin-left: 2em">三十分角宿大星尧时距赤道北十度因入鹑尾宫</span>  
<span style="margin-left: 2em">故距度渐减以至于尽尽而复加至多禄某过赤道</span>  
<span style="margin-left: 2em">距南三十分而今渐远距南得九度一十分以此三</span>  
<span style="margin-left: 2em">四星为征余者尽然知其不随赤道而循黄道行宗</span>  
<span style="margin-left: 2em">黄道极也且七政皆右行而恒星亦右行以此推之</span>  
<span style="margin-left: 2em">尤著明矣</span>  
<span style="margin-left: 3em">恒星本行古测</span>  
<span style="margin-left: 1em">多禄某见恒星距赤游移不一先以上古所测星之赤</span>  
<span style="margin-left: 2em">道距度黄道距度及其两道相距度依三角形法测</span>  
<span style="margin-left: 2em">得其黄道经度后以自测之赤道距度如前求所当</span>  
<span style="margin-left: 2em">之黄道经度以两距时之经度差得中积之本行假</span>  
<span style="margin-left: 2em">如地末恰在其前四百三十二年所测角宿大星距</span>  
<span style="margin-left: 2em">赤道北一度二十四分距黄道南二度正此时之两</span>  
<span style="margin-left: 2em">道相距为二十三度五十一分因推其黄道经度在</span>  
<span style="margin-left: 2em">鹑尾宫二十二度二十分后自测其黄道距度已过</span>  
<span style="margin-left: 2em">赤道而南三十分其黄道距度及两道相距如前因</span>  
<span style="margin-left: 2em">得本星黄道经度在鹑尾宫二十六度三十八分以</span>  
<span style="margin-left: 2em">较地末恰所测差四度一十八分以四百三十二年</span>  
<span style="margin-left: 2em">分之约得一百余年而行一度此多禄某所定为恒</span>  
<span style="margin-left: 2em">星本行也</span>  
<span style="margin-left: 2em">泥谷老后多禄某一千三百八十六年又以时史所</span>  
<span style="margin-left: 2em">记恒星距赤道度及所自测以推其本行渐次戚速</span>  
<span style="margin-left: 2em">盖从多禄某至巴德倪七百四十一年共得本行一</span>  
<span style="margin-left: 2em">十一度二十六分为六十五年而一度又六百四十</span>  
<span style="margin-left: 2em">五年至见测时行九度一十一分是为六十一年而</span>  
<span style="margin-left: 2em">一度以是论恒星之本行有迟速初无恒度可为常</span>  
<span style="margin-left: 2em">定不易之法也因立为迟疾加减法今畧解之云凡</span>  
<span style="margin-left: 2em">恒星去离四节有两说或云恒星离四节<sub class="note-yuan">二分二至</sub>而右</span>  
<span style="margin-left: 2em">行每六七十年进一度或四节离恒星而左行每六</span>  
<span style="margin-left: 2em">七十年退一度其理则同此所用者左行而退度也</span>  
<span style="margin-left: 2em">如图甲戊子大圈为黄道甲为天元春分古时合于</span>  
<span style="margin-left: 2em">娄宿南星<sub class="note-jiao">校：法圖本婁宿南星作婁宿中星</sub>后来春分去离天元甲</span>  
<span style="margin-left: 7em">而积渐西移以至于戊乃其行迟疾不</span>  
<span style="margin-left: 7em">一故推步之法以从甲至戊之本行为</span>  
<span style="margin-left: 7em">春分去天元之平行以戊为心作午子</span>  
<span style="margin-left: 7em">己小平面圈帖合于圆球面上以子未</span>  
<span style="margin-left: 2em">全径指量平行与视行<sub class="note-yuan">视行即实行也</sub>之差度其癸己辛边</span>  
<span style="margin-left: 2em">上为自行度立加减法若在己未午半圈则减于甲</span>  
<span style="margin-left: 2em">戊之平行以得其实行若在午子己半圈即加于甲</span>  
<span style="margin-left: 2em">戊之平行以得实行也依此所求有三一求春分节</span>  
<span style="margin-left: 2em">戊随时去离天元甲若干为平行二求小圈之最远</span>  
<span style="margin-left: 2em">己随时向辛未行若干为自行三求子未小圈半径</span>  
<span style="margin-left: 2em">内加减度所当小圈边之自行度即显恒星实本行</span>  
<span style="margin-left: 2em">之度也</span>  
<span style="margin-left: 3em">恒星本行今测</span>  
<span style="margin-left: 1em">从古历家既知恒星自有本行后相去二千余年其所</span>  
<span style="margin-left: 2em">行度尚未及周天十二分之一三十〇度<sub class="note-jiao">校：法圖本作十五分之一〔二十</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">四度〕</sub>其迟如此乃欲借此推测全周欲定其运行体势</span>  
<span style="margin-left: 2em">历岁多寡譬如隙中窥豹所见一斑而遽欲槩其全</span>  
<span style="margin-left: 2em">体何从取证乎故古来诸家所定或六十年或七八</span>  
<span style="margin-left: 2em">十年或百年而行一度各不相合若于诸家所定长</span>  
<span style="margin-left: 2em">短不齐之中立为别法又甚繁而未必是也第谷精</span>  
<span style="margin-left: 2em">思累年用前贤之成法展转参订始信恒星运动常</span>  
<span style="margin-left: 2em">是平行虽从前诸测不无差殊究所从来各有因起</span>  
<span style="margin-left: 2em">穷极理势终归一致其说先以泥谷老所测角宿距</span>  
<span style="margin-left: 2em">星试之<sub class="note-jiao">校：法圖本角宿距星作角宿南星</sub>于正德九年甲戌测得赤</span>  
<span style="margin-left: 2em">道南距八度二十六分<sub class="note-jiao">校：法圖本作八度三十六分</sub>第谷疑前测</span>  
<span style="margin-left: 2em">地面其北极出地高度尚非真率使人用大器密测</span>  
<span style="margin-left: 2em">实得彼所用高度尚差二分四十五秒因辨角距星</span>  
<span style="margin-left: 2em">距度中<sub class="note-jiao">校：法圖本角距星作角南星</sub>宜减二分四十五秒为北极</span>  
<span style="margin-left: 2em">不及之度又以所自测本星之黄道南距一度五十</span>  
<span style="margin-left: 2em">九分及此时之两道相距二十三度三十一分三十</span>  
<span style="margin-left: 2em">秒依前卷三角形法改泥谷老时所测黄道经应得</span>  
<span style="margin-left: 2em">过秋分一十七度〇三分三十〇秒又自于万历甲</span>  
<span style="margin-left: 2em">申年测算得十八度〇三分两测时相距七十年而</span>  
<span style="margin-left: 2em">角南星行五九分三十秒<sub class="note-jiao">校：法圖本作一度〇三十秒</sub>即一年得</span>  
<span style="margin-left: 2em">五十一秒为恒星本行之恒数也</span>  
<span style="margin-left: 2em">又疑七十年时日太少不足以推验全周再引系巴</span>  
<span style="margin-left: 2em">科于汉武帝元朔六年戊午所测轩辕大星在鹑首</span>  
<span style="margin-left: 2em">宫二十九度五十分至自测时逾一千七百一十三</span>

<span style="margin-left: 2em">恒星变易度　第三</span>  
<span style="margin-left: 1em">向言恒星有本行足明其黄道经度日日变迁且有定</span>  
<span style="margin-left: 2em">率矣若用此以推赤道经纬度及黄道纬度可否移</span>  
<span style="margin-left: 2em">易及其经度差互相近互相远俱未及详也今论次</span>  
<span style="margin-left: 2em">如左</span>  
<span style="margin-left: 3em">恒星赤道经纬度变易</span>  
<span style="margin-left: 1em">定恒星向赤道之度必从赤道起算右行则为经度而</span>  
<span style="margin-left: 2em">去离南北则距度也若从赤道两极出大圈过春分</span>  
<span style="margin-left: 2em">名极分交圈乃为界首经度所始而星居其上者不</span>  
<span style="margin-left: 2em">论在赤道之或南或北皆无经度分因在初度初分</span>  
<span style="margin-left: 2em">故也一离此圈不论左右远近皆名正升度之圈<sub class="note-yuan">是从</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">黄道上行而与赤道同出地平同入地平者名升度圈其在正球处名正升在欹球处名斜升然止论赤</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">道度则皆用正升</sub>乃以限赤道之经度容赤道之纬度也又</span>  
<span style="margin-left: 2em">赤道大圈为南北距度所始星居其上则无纬度一</span>  
<span style="margin-left: 2em">离此圈不论南北远近乃至两极皆名距等圈<sub class="note-yuan">或云赤道</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">纬圈</sub>乃以限赤道之纬度容赤道之经度也但赤道既</span>  
<span style="margin-left: 2em">斜交于黄道而恒星依黄道有本行必与赤道纬圈</span>  
<span style="margin-left: 2em">皆以斜角相交相过即星虽在赤道纬圈上得限距</span>  
<span style="margin-left: 2em">度而以迤行故即黄赤两距圈每相违远矣故星之</span>  
<span style="margin-left: 2em">升度圈能得黄赤经度合一不离者独有二一为同</span>  
<span style="margin-left: 2em">在极至交圈一为同在两道交之两点自此而外更</span>  
<span style="margin-left: 2em">不可得虽行黄道经度均平如一其行赤道经度时</span>  
<span style="margin-left: 2em">时变动所以然者赤道之升度圈与黄道极所出圈</span>  
<span style="margin-left: 8em">相遇有疎有密随在不等故也如图</span>  
<span style="margin-left: 8em">赤道极乙所出升度圈乙午乙子乙</span>  
<span style="margin-left: 8em">癸等黄道极甲所出圈甲庚未甲丑</span>  
<span style="margin-left: 8em">未等若星在黄道纬之丙己圈行近</span>  
<span style="margin-left: 8em">于黄道即黄赤两极所出两圈相去</span>  
<span style="margin-left: 2em">畧等其经度或赤道或黄道东行亦畧等若星距黄</span>  
<span style="margin-left: 2em">道远在戊丁圈从戊至庚设一十五度即星历黄道</span>  
<span style="margin-left: 2em">经圈若干时得戊庚十五度而历赤道升度圈亦若</span>  
<span style="margin-left: 2em">干时所过乙壬乙癸<sub class="note-yuan">各十五度</sub>将及乙甲几四十度矣所</span>  
<span style="margin-left: 2em">以然者甲庚未弧限黄道经度至戊庚己稍宽而乙</span>  
<span style="margin-left: 2em">壬乙癸等弧限赤道经度至此尚密所以星行历黄</span>  
<span style="margin-left: 2em">道经度少历赤道经度多也又使有星在黄道纬之</span>  
<span style="margin-left: 2em">辛丁圈上行即乙午乙子等弧限赤道经度者反宽</span>  
<span style="margin-left: 2em">而甲辛未等弧限黄道者反密则星行时所历黄道</span>  
<span style="margin-left: 2em">经度反多历赤道经度反寡矣总言之为星行二道</span>  
<span style="margin-left: 2em">之经度恒自不等再论星历赤道纬度亦常不等如</span>  
<span style="margin-left: 2em">图甲为星在赤道南二十三度三十〇分若行一周</span>  
<span style="margin-left: 8em">必至分节乙即无距度然随黄道行</span>  
<span style="margin-left: 8em">必过赤道而北极远处又在北二十</span>  
<span style="margin-left: 8em">三度三十〇分矣又丙为星行一周</span>  
<span style="margin-left: 8em">即离赤道圈丙渐至己行愈远去赤</span>  
<span style="margin-left: 8em">道亦愈远至丁必离四十七度若更</span>  
<span style="margin-left: 2em">在戊距赤道丙己向北二十度过庚行愈远距亦愈</span>  
<span style="margin-left: 2em">远至壬为本圈距赤最远之界更加二十度总为六</span>  
<span style="margin-left: 2em">十七度矣余皆倣此盖左边距赤之度每多于右边</span>  
<span style="margin-left: 2em">距赤之度如庚之距乙多于戊之距丙也至北极癸</span>  
<span style="margin-left: 2em">即左满九十度若过极即周行皆在癸丙九十度间</span>  
<span style="margin-left: 2em">戊辛之间加一度即癸辛之间减一度<sub class="note-yuan">减者减癸丙九十度也</sub></span>  
<span style="margin-left: 2em">若至黄道极辛即其距度终古不易矣</span>  
<span style="margin-left: 3em">二十八宿各宿度变易</span>  
<span style="margin-left: 1em">或问二十八宿有次第盖日月五星各以本行先历角</span>  
<span style="margin-left: 2em">宿至亢至氐房心等古昔如此今世不然所见先入</span>  
<span style="margin-left: 2em">参度而后过觜度自余不觉者宿度宽也其实皆有</span>  
<span style="margin-left: 2em">之何故曰二十八宿不以赤道极为本行之极而以</span>  
<span style="margin-left: 2em">黄道极为极故其行度时近时远于赤道极行渐近</span>  
<span style="margin-left: 2em">极即北极所出赤道经圈渐密七政过之其行则疾</span>  
<span style="margin-left: 2em">渐远极即赤道经圈渐疎七政过之其行则迟七政</span>  
<span style="margin-left: 2em">行度疾于恒星远甚其逐及于近极之恒星在古觉</span>  
<span style="margin-left: 2em">速在今觉迟其逐及于远极之恒星在古觉迟在今</span>  
<span style="margin-left: 2em">觉速皆缘二道二极能使其然非七政有异行亦非</span>  
<span style="margin-left: 2em">恒星有易位也</span>  
<span style="margin-left: 8em">如图赤道南北极甲上所出各圈相</span>  
<span style="margin-left: 8em">去皆设一十度黄道两极乙上所出</span>  
<span style="margin-left: 8em">各圈亦如之有星为丁即限其赤道</span>  
<span style="margin-left: 8em">经度者为甲丁癸圈而星却不依赤</span>  
<span style="margin-left: 8em">道行乃依黄道自丁向戊行约每七</span>  
<span style="margin-left: 2em">百年行一十度也又一星为己原设在丁前一十度</span>  
<span style="margin-left: 2em">其限赤度者为甲己子圈而所行亦依黄道自己向</span>  
<span style="margin-left: 2em">庚七百年十度因是己星依黄道至壬时丁星亦依</span>  
<span style="margin-left: 2em">黄道至辛己壬以黄道算得十经度而丁辛亦正对</span>  
<span style="margin-left: 2em">寅卯为黄道之十经度也然以赤道算之则黄己壬</span>  
<span style="margin-left: 2em">所对赤子丑一十度之弧而黄丁辛所对不止赤癸</span>  
<span style="margin-left: 2em">子一十度之弧更过赤道子而近丑将及二十度即</span>  
<span style="margin-left: 2em">丁星先在己星之后十度而渐向前行至逐及于甲</span>  
<span style="margin-left: 2em">丑圈上即两星同经度矣过丑则丁反在前矣假令</span>  
<span style="margin-left: 2em">日循黄道亦于丁戊线上行何得不于七百载之先</span>  
<span style="margin-left: 2em">至卯入丁宿度前距己未及数度而七百载之后乃</span>  
<span style="margin-left: 2em">至壬并入丁己二宿同经之度乎此非行有疾迟皆</span>  
<span style="margin-left: 2em">因度有广狭故也度之所以广狭者分宿度以赤道</span>  
<span style="margin-left: 2em">所出经圈为限而步七政以黄道所出经圈为限也</span>  
<span style="margin-left: 2em">但此设丁己二星一近北极一近黄道相去稍远者</span>  
<span style="margin-left: 2em">欲令此理灼然易见若设两星距度不远即不必七</span>  
<span style="margin-left: 2em">百年能超逾十度或进一二度亦此理耳若古时七</span>  
<span style="margin-left: 2em">政所历先后不相越者正当黄赤二度广狭相等故</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 3em">考赤道宿度差</span>  
<span style="margin-left: 1em">中历古分宿度以相并或不成一周天今用之不合天</span>  
<span style="margin-left: 2em">度因自授时以来如上所说宿度变易故也法宜先</span>  
<span style="margin-left: 2em">求今之实宿度以究极古今异同之故仍立法以求</span>

<span style="margin-left: 2em">赤道经度不远亦在本宫二十三度三十八分所以</span>

<span style="margin-left: 3em">恒星黄道经度不变易</span>
