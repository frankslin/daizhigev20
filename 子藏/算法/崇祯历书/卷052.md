<span style="margin-left: 3em"><sub class="note-jiao">校：牛津本武大本東北刊本清刊本俱將恆星曆指目錄置於卷一故本卷原無目錄</sub></span>  
<span style="margin-left: 1em">曆指三卷　　恆星二</span>  
<span style="margin-left: 2em">恆星本行第一　五章</span>  
<span style="margin-left: 1em">前卷所借西史測星之法爲恆星曆之基本此卷應準</span>  
<span style="margin-left: 2em">前法仍借舊測諸星經緯度立表以待推算然舊測</span>  
<span style="margin-left: 2em">在萬曆十三四年今相去四十餘載不復可用宜作</span>  
<span style="margin-left: 2em">新表又須先明新舊所以異同之故不得不論其本</span>  
<span style="margin-left: 2em">行次乃定時下各星之經緯度表</span>  
<span style="margin-left: 3em">恆星本行之徵</span>  
<span style="margin-left: 1em">七政之運行也時相會時相對其與恆星也時相近時</span>  
<span style="margin-left: 2em">相遠其本曜之光時消時長<sub class="note-yuan">月有晦朔弦望近論大白辰星熒惑皆有之</sub></span>  
<span style="margin-left: 2em">其東西出没於卯酉也時南時北其過子午圈也時</span>  
<span style="margin-left: 2em">高時下人目所見變動不居故從古迄今人人知其</span>  
<span style="margin-left: 2em">自有運動因生各曜推步之法無可疑者若恆星則</span>  
<span style="margin-left: 2em">無先相會後相望無先相近後相遠其光不消不長</span>  
<span style="margin-left: 2em">其東西出没其過子午圈雖百數十年無從覺其有</span>  
<span style="margin-left: 2em">差安知其有本運動乎夫恆星移運非一世之事前</span>  
<span style="margin-left: 2em">古曆家既已測其定度欲更得其轉移之數必百年</span>  
<span style="margin-left: 2em">數十年誰能待之是故一人之身絕無能覺之緣也</span>  
<span style="margin-left: 2em">後來學者傳受先賢所測度數復身試測之往往見</span>  
<span style="margin-left: 2em">其不合先人所見與四節相近者後人測之漸遠又</span>  
<span style="margin-left: 2em">後之人測之又漸遠從是推知恆星有本行之實度</span>  
<span style="margin-left: 2em">分及其移易之所以然也如角宿大星古地未恰於</span>  
<span style="margin-left: 2em">周赧王二十年丙寅測得其經度在秋分前鶉尾宫</span>  
<span style="margin-left: 2em">二十二度後多祿某於漢順帝永和三年戊寅測在</span>  
<span style="margin-left: 2em">鶉尾宫二十七度後尼谷老於嘉靖四年乙酉測得</span>  
<span style="margin-left: 2em">過秋分在壽星宫一十七度後第谷于萬曆十三年</span>  
<span style="margin-left: 2em">乙酉測在壽星宫一十八度軒轅星亦如之周赧王</span>  
<span style="margin-left: 2em">丙寅在鶉首宫二十七度漢永和戊寅在鶉火宫三</span>  
<span style="margin-left: 2em">度三十分今測在鶉火宫二十四度四十分餘星皆</span>  
<span style="margin-left: 2em">如之是以帝堯之世日中星鳥謂春分則初昏時鶉</span>  
<span style="margin-left: 2em">火中也而周末在井今在參矣堯時冬至日在虛漢</span>  
<span style="margin-left: 2em">唐在斗今在箕矣非其自有本行安得冬至離虛宿</span>  
<span style="margin-left: 2em">而西鳥離子午而東乎</span>  
<span style="margin-left: 3em">恆星本行之極</span>  
<span style="margin-left: 1em">十政本行以黃道爲道以黃道極爲極終古恆然何繇</span>  
<span style="margin-left: 2em">知之蓋人目所見出没于地平之卯酉南北不一過</span>  
<span style="margin-left: 2em">午之高度多寡不一又有時離赤道而南有時復還</span>  
<span style="margin-left: 2em">於赤道之北以此知其行必非循赤道行以此知其</span>  
<span style="margin-left: 2em">極必非宗赤道極也然七政之循黃道或浹旬可得</span>  
<span style="margin-left: 2em">或周歲可得恆星之循黃道必上下古今然後可得</span>  
<span style="margin-left: 2em">何者上古有測中古有測今時有測乃恆星出没地</span>  
<span style="margin-left: 2em">平之處今非中古之處中古非上古之處其過午之</span>  
<span style="margin-left: 2em">軌高亦然而恆移不定者赤道之距度恆定不移者</span>  
<span style="margin-left: 2em">黃道之距度也以此推知其循黃道行宗黃道極與</span>  
<span style="margin-left: 2em">七政同理灼然無疑矣更徵實論之凡恆星距赤道</span>  
<span style="margin-left: 2em">之度從星紀迄鶉首則在赤道之南者必古多而今</span>  
<span style="margin-left: 2em">漸少在赤道之北者必古少而今漸多不似七政之</span>  
<span style="margin-left: 2em">行從冬至逾春分而夏至自南趨北乎從鶉首迄星</span>  
<span style="margin-left: 2em">紀則在赤道之南者必古少而今漸多在赤道之北</span>  
<span style="margin-left: 2em">者必古多而今漸少不似七政之行從夏至逾秋分</span>  
<span style="margin-left: 2em">而冬至自北趨南乎如外屏第二星堯時在赤道南</span>  
<span style="margin-left: 2em">十二度强因此時入娵訾宫故距度漸減至多祿某</span>  
<span style="margin-left: 2em">尚在南二度四十九分後漸過赤道以北今北距五</span>  
<span style="margin-left: 2em">度矣井宿距星<sub class="note-jiao">校：法圖本井宿距星作井宿龯星</sub>堯時在赤道北一</span>  
<span style="margin-left: 2em">十四度弱因入實沈宫故距度漸加至多祿某得二</span>  
<span style="margin-left: 2em">十度正今北距二十三度與夏至圈相近也又軒轅</span>  
<span style="margin-left: 2em">大星堯時距赤道北二十四度因入鶉火宫故距度</span>  
<span style="margin-left: 2em">漸減至多祿某得一十九度三十分今止一十三度</span>  
<span style="margin-left: 2em">三十分角宿大星堯時距赤道北十度因入鶉尾宫</span>  
<span style="margin-left: 2em">故距度漸減以至于盡盡而復加至多祿某過赤道</span>  
<span style="margin-left: 2em">距南三十分而今漸遠距南得九度一十分以此三</span>  
<span style="margin-left: 2em">四星爲徵餘者盡然知其不隨赤道而循黃道行宗</span>  
<span style="margin-left: 2em">黃道極也且七政皆右行而恆星亦右行以此推之</span>  
<span style="margin-left: 2em">尤著明矣</span>  
<span style="margin-left: 3em">恆星本行古測</span>  
<span style="margin-left: 1em">多祿某見恆星距赤游移不一先以上古所測星之赤</span>  
<span style="margin-left: 2em">道距度黃道距度及其兩道相距度依三角形法測</span>  
<span style="margin-left: 2em">得其黃道經度後以自測之赤道距度如前求所當</span>  
<span style="margin-left: 2em">之黃道經度以兩距時之經度差得中積之本行假</span>  
<span style="margin-left: 2em">如地末恰在其前四百三十二年所測角宿大星距</span>  
<span style="margin-left: 2em">赤道北一度二十四分距黃道南二度正此時之兩</span>  
<span style="margin-left: 2em">道相距爲二十三度五十一分因推其黃道經度在</span>  
<span style="margin-left: 2em">鶉尾宫二十二度二十分後自測其黃道距度已過</span>  
<span style="margin-left: 2em">赤道而南三十分其黃道距度及兩道相距如前因</span>  
<span style="margin-left: 2em">得本星黃道經度在鶉尾宫二十六度三十八分以</span>  
<span style="margin-left: 2em">較地末恰所測差四度一十八分以四百三十二年</span>  
<span style="margin-left: 2em">分之約得一百餘年而行一度此多祿某所定爲恆</span>  
<span style="margin-left: 2em">星本行也</span>  
<span style="margin-left: 2em">泥谷老後多祿某一千三百八十六年又以時史所</span>  
<span style="margin-left: 2em">記恆星距赤道度及所自測以推其本行漸次戚速</span>  
<span style="margin-left: 2em">蓋從多祿某至巴德倪七百四十一年共得本行一</span>  
<span style="margin-left: 2em">十一度二十六分爲六十五年而一度又六百四十</span>  
<span style="margin-left: 2em">五年至見測時行九度一十一分是爲六十一年而</span>  
<span style="margin-left: 2em">一度以是論恆星之本行有遲速初無恆度可爲常</span>  
<span style="margin-left: 2em">定不易之法也因立爲遲疾加減法今畧解之云凡</span>  
<span style="margin-left: 2em">恆星去離四節有兩說或云恆星離四節<sub class="note-yuan">二分二至</sub>而右</span>  
<span style="margin-left: 2em">行每六七十年進一度或四節離恆星而左行每六</span>  
<span style="margin-left: 2em">七十年退一度其理則同此所用者左行而退度也</span>  
<span style="margin-left: 2em">如圖甲戊子大圈爲黃道甲爲天元春分古時合于</span>  
<span style="margin-left: 2em">婁宿南星<sub class="note-jiao">校：法圖本婁宿南星作婁宿中星</sub>後來春分去離天元甲</span>  
<span style="margin-left: 7em">而積漸西移以至于戊乃其行遲疾不</span>  
<span style="margin-left: 7em">一故推步之法以從甲至戊之本行爲</span>  
<span style="margin-left: 7em">春分去天元之平行以戊爲心作午子</span>  
<span style="margin-left: 7em">己小平面圈帖合于圓球面上以子未</span>  
<span style="margin-left: 2em">全徑指量平行與視行<sub class="note-yuan">視行即實行也</sub>之差度其癸己辛邊</span>  
<span style="margin-left: 2em">上爲自行度立加減法若在己未午半圈則減于甲</span>  
<span style="margin-left: 2em">戊之平行以得其實行若在午子己半圈即加于甲</span>  
<span style="margin-left: 2em">戊之平行以得實行也依此所求有三一求春分節</span>  
<span style="margin-left: 2em">戊隨時去離天元甲若干爲平行二求小圈之最遠</span>  
<span style="margin-left: 2em">己隨時向辛未行若干爲自行三求子未小圈半徑</span>  
<span style="margin-left: 2em">內加減度所當小圈邊之自行度即顯恆星實本行</span>  
<span style="margin-left: 2em">之度也</span>  
<span style="margin-left: 3em">恆星本行今測</span>  
<span style="margin-left: 1em">從古曆家既知恆星自有本行後相去二千餘年其所</span>  
<span style="margin-left: 2em">行度尚未及周天十二分之一三十〇度<sub class="note-jiao">校：法圖本作十五分之一〔二十</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">四度〕</sub>其遲如此乃欲藉此推測全周欲定其運行體勢</span>  
<span style="margin-left: 2em">曆歲多寡譬如隙中窺豹所見一斑而遽欲槩其全</span>  
<span style="margin-left: 2em">體何從取證乎故古來諸家所定或六十年或七八</span>  
<span style="margin-left: 2em">十年或百年而行一度各不相合若于諸家所定長</span>  
<span style="margin-left: 2em">短不齊之中立爲別法又甚繁而未必是也第谷精</span>  
<span style="margin-left: 2em">思累年用前賢之成法展轉參訂始信恆星運動常</span>  
<span style="margin-left: 2em">是平行雖從前諸測不無差殊究所從來各有因起</span>  
<span style="margin-left: 2em">窮極理勢終歸一致其說先以泥谷老所測角宿距</span>  
<span style="margin-left: 2em">星試之<sub class="note-jiao">校：法圖本角宿距星作角宿南星</sub>於正德九年甲戌測得赤</span>  
<span style="margin-left: 2em">道南距八度二十六分<sub class="note-jiao">校：法圖本作八度三十六分</sub>第谷疑前測</span>  
<span style="margin-left: 2em">地面其北極出地高度尚非真率使人用大器密測</span>  
<span style="margin-left: 2em">實得彼所用高度尚差二分四十五秒因辨角距星</span>  
<span style="margin-left: 2em">距度中<sub class="note-jiao">校：法圖本角距星作角南星</sub>宜減二分四十五秒爲北極</span>  
<span style="margin-left: 2em">不及之度又以所自測本星之黃道南距一度五十</span>  
<span style="margin-left: 2em">九分及此時之兩道相距二十三度三十一分三十</span>  
<span style="margin-left: 2em">秒依前卷三角形法改泥谷老時所測黃道經應得</span>  
<span style="margin-left: 2em">過秋分一十七度〇三分三十〇秒又自于萬曆甲</span>  
<span style="margin-left: 2em">申年測算得十八度〇三分兩測時相距七十年而</span>  
<span style="margin-left: 2em">角南星行五九分三十秒<sub class="note-jiao">校：法圖本作一度〇三十秒</sub>即一年得</span>  
<span style="margin-left: 2em">五十一秒爲恆星本行之恆數也</span>  
<span style="margin-left: 2em">又疑七十年時日太少不足以推驗全周再引係巴</span>

<span style="margin-left: 2em">恆星變易度　第三</span>  
<span style="margin-left: 1em">向言恆星有本行足明其黃道經度日日變遷且有定</span>  
<span style="margin-left: 2em">率矣若用此以推赤道經緯度及黃道緯度可否移</span>  
<span style="margin-left: 2em">易及其經度差互相近互相遠俱未及詳也今論次</span>  
<span style="margin-left: 2em">如左</span>  
<span style="margin-left: 3em">恆星赤道經緯度變易</span>  
<span style="margin-left: 1em">定恆星向赤道之度必從赤道起算右行則爲經度而</span>  
<span style="margin-left: 2em">去離南北則距度也若從赤道兩極出大圈過春分</span>  
<span style="margin-left: 2em">名極分交圈乃爲界首經度所始而星居其上者不</span>  
<span style="margin-left: 2em">論在赤道之或南或北皆無經度分因在初度初分</span>  
<span style="margin-left: 2em">故也一離此圈不論左右遠近皆名正升度之圈<sub class="note-yuan">是從</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">黃道上行而與赤道同出地平同入地平者名升度圈其在正球處名正升在欹球處名斜升然止論赤</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">道度則皆用正升</sub>乃以限赤道之經度容赤道之緯度也又</span>  
<span style="margin-left: 2em">赤道大圈爲南北距度所始星居其上則無緯度一</span>  
<span style="margin-left: 2em">離此圈不論南北遠近乃至兩極皆名距等圈<sub class="note-yuan">或云赤道</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">緯圈</sub>乃以限赤道之緯度容赤道之經度也但赤道既</span>  
<span style="margin-left: 2em">斜交于黃道而恆星依黃道有本行必與赤道緯圈</span>  
<span style="margin-left: 2em">皆以斜角相交相過即星雖在赤道緯圈上得限距</span>  
<span style="margin-left: 2em">度而以迤行故即黃赤兩距圈每相違遠矣故星之</span>  
<span style="margin-left: 2em">升度圈能得黃赤經度合一不離者獨有二一爲同</span>  
<span style="margin-left: 2em">在極至交圈一爲同在兩道交之兩點自此而外更</span>  
<span style="margin-left: 2em">不可得雖行黃道經度均平如一其行赤道經度時</span>  
<span style="margin-left: 2em">時變動所以然者赤道之升度圈與黃道極所出圈</span>  
<span style="margin-left: 8em">相遇有疎有密隨在不等故也如圖</span>  
<span style="margin-left: 8em">赤道極乙所出升度圈乙午乙子乙</span>  
<span style="margin-left: 8em">癸等黃道極甲所出圈甲庚未甲丑</span>  
<span style="margin-left: 8em">未等若星在黃道緯之丙己圈行近</span>  
<span style="margin-left: 8em">于黃道即黃赤兩極所出兩圈相去</span>  
<span style="margin-left: 2em">畧等其經度或赤道或黃道東行亦畧等若星距黃</span>  
<span style="margin-left: 2em">道遠在戊丁圈從戊至庚設一十五度即星歷黃道</span>  
<span style="margin-left: 2em">經圈若干時得戊庚十五度而歷赤道升度圈亦若</span>  
<span style="margin-left: 2em">干時所過乙壬乙癸<sub class="note-yuan">各十五度</sub>將及乙甲幾四十度矣所</span>  
<span style="margin-left: 2em">以然者甲庚未弧限黃道經度至戊庚己稍寬而乙</span>  
<span style="margin-left: 2em">壬乙癸等弧限赤道經度至此尚密所以星行歷黃</span>  
<span style="margin-left: 2em">道經度少歷赤道經度多也又使有星在黃道緯之</span>  
<span style="margin-left: 2em">辛丁圈上行即乙午乙子等弧限赤道經度者反寬</span>  
<span style="margin-left: 2em">而甲辛未等弧限黃道者反密則星行時所歷黃道</span>  
<span style="margin-left: 2em">經度反多歷赤道經度反寡矣總言之爲星行二道</span>  
<span style="margin-left: 2em">之經度恆自不等再論星歷赤道緯度亦常不等如</span>  
<span style="margin-left: 2em">圖甲爲星在赤道南二十三度三十〇分若行一周</span>  
<span style="margin-left: 8em">必至分節乙即無距度然隨黃道行</span>  
<span style="margin-left: 8em">必過赤道而北極遠處又在北二十</span>  
<span style="margin-left: 8em">三度三十〇分矣又丙爲星行一周</span>  
<span style="margin-left: 8em">即離赤道圈丙漸至己行愈遠去赤</span>  
<span style="margin-left: 8em">道亦愈遠至丁必離四十七度若更</span>  
<span style="margin-left: 2em">在戊距赤道丙己向北二十度過庚行愈遠距亦愈</span>  
<span style="margin-left: 2em">遠至壬爲本圈距赤最遠之界更加二十度總爲六</span>  
<span style="margin-left: 2em">十七度矣餘皆倣此蓋左邊距赤之度每多于右邊</span>  
<span style="margin-left: 2em">距赤之度如庚之距乙多于戊之距丙也至北極癸</span>  
<span style="margin-left: 2em">即左滿九十度若過極即周行皆在癸丙九十度間</span>  
<span style="margin-left: 2em">戊辛之間加一度即癸辛之間減一度<sub class="note-yuan">減者減癸丙九十度也</sub></span>  
<span style="margin-left: 2em">若至黃道極辛即其距度終古不易矣</span>  
<span style="margin-left: 3em">二十八宿各宿度變易</span>  
<span style="margin-left: 1em">或問二十八宿有次第蓋日月五星各以本行先歷角</span>  
<span style="margin-left: 2em">宿至亢至氐房心等古昔如此今世不然所見先入</span>  
<span style="margin-left: 2em">參度而後過觜度自餘不覺者宿度寬也其實皆有</span>  
<span style="margin-left: 2em">之何故曰二十八宿不以赤道極爲本行之極而以</span>  
<span style="margin-left: 2em">黃道極爲極故其行度時近時遠于赤道極行漸近</span>  
<span style="margin-left: 2em">極即北極所出赤道經圈漸密七政過之其行則疾</span>  
<span style="margin-left: 2em">漸遠極即赤道經圈漸疎七政過之其行則遲七政</span>  
<span style="margin-left: 2em">行度疾于恆星遠甚其逐及于近極之恆星在古覺</span>  
<span style="margin-left: 2em">速在今覺遲其逐及于遠極之恆星在古覺遲在今</span>  
<span style="margin-left: 2em">覺速皆緣二道二極能使其然非七政有異行亦非</span>  
<span style="margin-left: 2em">恆星有易位也</span>  
<span style="margin-left: 8em">如圖赤道南北極甲上所出各圈相</span>  
<span style="margin-left: 8em">去皆設一十度黃道兩極乙上所出</span>  
<span style="margin-left: 8em">各圈亦如之有星爲丁即限其赤道</span>  
<span style="margin-left: 8em">經度者爲甲丁癸圈而星却不依赤</span>  
<span style="margin-left: 8em">道行乃依黃道自丁向戊行約每七</span>  
<span style="margin-left: 2em">百年行一十度也又一星爲己原設在丁前一十度</span>  
<span style="margin-left: 2em">其限赤度者爲甲己子圈而所行亦依黃道自己向</span>  
<span style="margin-left: 2em">庚七百年十度因是己星依黃道至壬時丁星亦依</span>  
<span style="margin-left: 2em">黃道至辛己壬以黃道算得十經度而丁辛亦正對</span>  
<span style="margin-left: 2em">寅卯爲黃道之十經度也然以赤道算之則黃己壬</span>  
<span style="margin-left: 2em">所對赤子丑一十度之弧而黃丁辛所對不止赤癸</span>  
<span style="margin-left: 2em">子一十度之弧更過赤道子而近丑將及二十度即</span>  
<span style="margin-left: 2em">丁星先在己星之後十度而漸向前行至逐及于甲</span>  
<span style="margin-left: 2em">丑圈上即兩星同經度矣過丑則丁反在前矣假令</span>  
<span style="margin-left: 2em">日循黃道亦于丁戊線上行何得不于七百載之先</span>  
<span style="margin-left: 2em">至卯入丁宿度前距己未及數度而七百載之後乃</span>  
<span style="margin-left: 2em">至壬并入丁己二宿同經之度乎此非行有疾遲皆</span>  
<span style="margin-left: 2em">因度有廣狹故也度之所以廣狹者分宿度以赤道</span>  
<span style="margin-left: 2em">所出經圈爲限而步七政以黃道所出經圈爲限也</span>

<span style="margin-left: 2em">欲令此理灼然易見若設兩星距度不遠即不必七</span>  
<span style="margin-left: 2em">百年能超踰十度或進一二度亦此理耳若古時七</span>  
<span style="margin-left: 2em">政所歷先後不相越者正當黃赤二度廣狹相等故</span>

<span style="margin-left: 2em">五十五分較古測强一十五分爲此處變易黃道之</span>  
<span style="margin-left: 2em">度也又房宿北星與昴宿爲對照地末恰所測在大</span>  
<span style="margin-left: 2em">火宫二度距北一度二十〇分後在本宫六度默聶</span>  
<span style="margin-left: 2em">老所測未移度而今測乃前至二十三度二十分距</span>  
<span style="margin-left: 2em">黃道止一度〇五分較古測差一十五分即此時黃</span>  
<span style="margin-left: 2em">道近就于赤道亦一十五分矣或疑黃赤二道之距</span>  
<span style="margin-left: 2em">既能自遠而近則邃古之時必更遠遠于何止乎曰</span>  
<span style="margin-left: 2em">邃古之距無從取證何可妄爲之說但近古三史皆</span>  
<span style="margin-left: 2em">以二十三度五十一分爲二至距赤之限且測非一</span>  
<span style="margin-left: 2em">人人非一測又皆以太陽二至之高下得之豈有誤</span>  
<span style="margin-left: 2em">乎今世之測驗更細更詳比昔就近實爲三分度之</span>  
<span style="margin-left: 2em">一尤無可疑者但自今以後當復更近近何時已近</span>  
<span style="margin-left: 2em">極或當復遠復在何時此則人靈微妙無能窮天載</span>  
<span style="margin-left: 2em">之無窮耳</span>  
<span style="margin-left: 1em">或問前所求虛宿等距星上古之經度也而用今之黃</span>  
<span style="margin-left: 2em">緯度能無謬乎曰用今世之緯度微不同千古之緯</span>  
<span style="margin-left: 2em">度但以之推南北度亦微差以求東西經度即無緣</span>  
<span style="margin-left: 2em">致誤矣</span>  
<span style="margin-left: 3em">恆星黃道經度不變易</span>  
<span style="margin-left: 1em">前以恆星之有本行徵其赤道經緯度隨時變易者爲</span>  
<span style="margin-left: 2em">諸星循黃道行斜交于赤道故也今論諸星循黃道</span>  
<span style="margin-left: 2em">行互相視有遲速乎曰否藉有遲有速者必有違有</span>  
<span style="margin-left: 2em">就位置有違就者形象必有改革乃自上古以來氐</span>  
<span style="margin-left: 2em">恆似斗尾恆如鈎天津如弓箕宿向冬至行四千年</span>  
<span style="margin-left: 2em">得五十四度<sub class="note-jiao">校：法圖本五十四度作十四度</sub>虛宿之過冬至也四千</span>  
<span style="margin-left: 2em">年亦五十四度餘皆若此歷數千年形像如故運行</span>  
<span style="margin-left: 2em">如故遲速如故知黃道經度決無變易矣係巴科于</span>  
<span style="margin-left: 2em">二千年前述古記以遺後世論黃道周繞數星或居</span>  
<span style="margin-left: 2em">一直線上或別成形象多祿某在後更測之仍如是</span>
