## 崇禎曆書卷之八十　諸方晝夜晨昏論及其分表

<span style="margin-left: 1em">諸方晝夜晨昏論及其分表<sub class="note-jiao">校：據日本島根大學抄本校錄</sub></span>  
<span style="margin-left: 3em">論經緯</span>  
<span style="margin-left: 1em">晝夜長短不一時刻亦異何也蓋晝夜長短由于太陽</span>  
<span style="margin-left: 1em">及南北極出入地平也北極出地即夏至晝長夜短冬</span>  
<span style="margin-left: 1em">至晝短夜長南極出地反是其時勢異也爲此夏至爲</span>  
<span style="margin-left: 1em">彼冬至故晝短夜長爲此冬至爲彼夏至故晝長夜短</span>  
<span style="margin-left: 1em">南北二極與地平則其地晝夜恒平故晝長夜短由于</span>  
<span style="margin-left: 1em">太陽及極出入地也南北爲緯度東西爲經度各一周</span>  
<span style="margin-left: 1em">三百六十度<sub class="note-jiao">校：周原作用據天理本東北本改</sub>人在地面凡居經度一</span>  
<span style="margin-left: 1em">帶之内者其晝夜長短恒同其日出入及晝夜時刻則</span>  
<span style="margin-left: 1em">異蓋經度之自東而西者人之所居或東或西雖各不</span>  
<span style="margin-left: 1em">同而緯度之三十度者皆爲三十度四十度者皆爲四</span>  
<span style="margin-left: 1em">十度也此同緯度者也若緯度之異者自赤道以至極</span>  
<span style="margin-left: 1em">下其晝夜長短各異矣</span>  
<span style="margin-left: 1em">如左圖地爲圓體懸于空際上下四旁皆有人居四方</span>  
<span style="margin-left: 1em">之人各以所居子午線爲午時太陽在東方甲居東方</span>  
<span style="margin-left: 1em">者爲午時日輪在其天頂故也乙居西方者即爲卯時</span>  
<span style="margin-left: 1em">日輪至天頂須三時故也丙亦居西方方即爲子時日</span>  
<span style="margin-left: 14em">輪以至天頂須六時</span>  
<span style="margin-left: 14em">故也諸地相去自東</span>  
<span style="margin-left: 14em">而西莫不皆然地球</span>  
<span style="margin-left: 14em">自南而北三百六十</span>  
<span style="margin-left: 14em">度一周每一度二百</span>  
<span style="margin-left: 14em">五十里日輪每刻平</span>  
<span style="margin-left: 14em">行天度三度四十五</span>  
<span style="margin-left: 14em">分如兩地相去九百</span>  
<span style="margin-left: 14em">三十七里半則相隔</span>  
<span style="margin-left: 14em">爲一刻相去七千五</span>  
<span style="margin-left: 1em">百里則相隔爲一時因知居東方者若得午時自此逐</span>  
<span style="margin-left: 1em">漸往西即爲己爲辰爲卯爲寅爲丑爲子天下自東而</span>  
<span style="margin-left: 1em">西時刻各異各以日輪到本處子午線爲午正初刻晝</span>  
<span style="margin-left: 1em">夜長短恒同者蓋以北極出地多寡定爲時刻多少所</span>  
<span style="margin-left: 1em">以自東而西一帶但經度相同地方其離北極皆同則</span>  
<span style="margin-left: 1em">晝夜長短亦同</span>  
<span style="margin-left: 1em">南北緯度自赤道至極下晝夜時刻隨地各有長短蓋</span>  
<span style="margin-left: 1em">居赤道下者以赤道爲天頂而其南北二極正與地面</span>  
<span style="margin-left: 1em">相平地平之交于諸節氣線皆其正中故其晝夜長短</span>  
<span style="margin-left: 1em">恒平也北極出地則地平之交節氣非其正中矣故所</span>  
<span style="margin-left: 1em">分上下亦非平分夏至則其線大分在上而晝長夜短</span>  
<span style="margin-left: 1em">冬至則其線小分在上而晝短夜長今欲知<sub class="note-jiao">校：今原作分據天理</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">本東北本改</sub>赤道之下晝夜常平</span>  
<span style="margin-left: 1em">如左圖即見人居此地以赤道爲天頂又南北極不出</span>  
<span style="margin-left: 1em">入地次見地平線相交于諸節氣之線正當中而六時</span>  
<span style="margin-left: 1em">在地平上六時在下故太陽或行夏至或冬至或春秋</span>  
<span style="margin-left: 1em">分線上必六時在地面上而爲晝六時在下而爲夜其</span>  
<span style="margin-left: 1em">諸節氣日出必卯正初刻日入必酉正初刻即晝夜當</span>  
<span style="margin-left: 1em">平可知也<sub class="note-jiao">校：當字天理本作常</sub>但其朦朧影稍異冬夏二至略長</span>  
<span style="margin-left: 1em">于春秋分之時此有别論今不其詳自北道北行二百</span>  
<span style="margin-left: 14em">五十里見北極出地</span>  
<span style="margin-left: 14em">一度赤道離天頂南</span>  
<span style="margin-left: 14em">亦一度若行二千五</span>  
<span style="margin-left: 14em">百里即北極出地南</span>  
<span style="margin-left: 14em">極入地赤道離天頂</span>  
<span style="margin-left: 14em">南俱差十度自赤道</span>  
<span style="margin-left: 14em">下至北極下每行二</span>  
<span style="margin-left: 14em">百五十里皆差一度</span>  
<span style="margin-left: 14em">其赤道線偏在天頂</span>  
<span style="margin-left: 14em">南即諸節氣線亦偏</span>  
<span style="margin-left: 1em">于南不與地平線相交于正中以爲平分故晝夜時刻</span>  
<span style="margin-left: 1em">各有長短焉晝夜長短皆從北極出地而生今以北極</span>  
<span style="margin-left: 1em">出地四十度作法餘可推焉</span>  
<span style="margin-left: 1em">如左圖北極出地南極入地四十度赤道在天頂南亦</span>  
<span style="margin-left: 1em">四十度地平線交于諸節氣線非其正中其交夏至線</span>  
<span style="margin-left: 1em">也于寅正二刻四分故晝長五十九刻七分每日九十</span>  
<span style="margin-left: 1em">六刻其餘三十六刻八分爲夜甚短因其線大半在地</span>  
<span style="margin-left: 1em">平上故自春分經夏至至秋分皆爲晝長而夜短地平</span>  
<span style="margin-left: 1em">線交冬至在辰初一刻十一分故夜長五十九刻七分</span>  
<span style="margin-left: 1em">其餘三十六刻八分爲晝甚短因其線大半在地平下</span>  
<span style="margin-left: 14em">故自秋分歷冬至至</span>  
<span style="margin-left: 14em">春分皆为夜長而晝</span>  
<span style="margin-left: 14em">短可知晝夜長短<sub class="note-jiao">校：長</sub></span>  
<span style="margin-left: 14em"><sub class="note-yuan">原作晨據天理本改</sub>由于南北</span>  
<span style="margin-left: 14em">二極出入地也</span>  
<span style="margin-left: 14em">如上圖欲知順天府</span>  
<span style="margin-left: 14em">每節氣晝夜刻各几</span>  
<span style="margin-left: 14em">何則視本日節氣在</span>  
<span style="margin-left: 14em">地平線上時刻即晝</span>  
<span style="margin-left: 14em">在下時刻即夜也假</span>  
<span style="margin-left: 1em">如于夏至線視地平線交于寅正二刻以上得二十九</span>  
<span style="margin-left: 1em">刻十一分是從日出至午正初刻數加一倍即從午正</span>  
<span style="margin-left: 1em">初至日入得五十九刻七分爲晝刻分所餘刻分即夜</span>  
<span style="margin-left: 1em">刻分也諸節氣亦然又欲知日出入時刻即視地平線</span>  
<span style="margin-left: 1em">于本節氣相交某時刻即得欲知隨節氣朦朧影刻各</span>  
<span style="margin-left: 1em">幾何亦視本節氣自朦朧線以上至地平線皆黄昏昧</span>  
<span style="margin-left: 1em">爽刻分也</span>  
<span style="margin-left: 1em">凡晝夜長短時刻由于南北極出入地與所居緯度之</span>  
<span style="margin-left: 1em">不同也天頂近于赤道則北極出地度數少即晝夜長</span>  
<span style="margin-left: 1em">短亦少天頂遠于赤道則北極出地度分多即晝夜長</span>  
<span style="margin-left: 15em">短亦多故應天府</span>  
<span style="margin-left: 15em">北極出地三十二</span>  
<span style="margin-left: 15em">度半順天府四十</span>  
<span style="margin-left: 15em">度强即多七度半</span>  
<span style="margin-left: 15em">其晝夜長短亦自</span>  
<span style="margin-left: 15em">不同欲知所差几</span>  
<span style="margin-left: 15em">何試觀北極出地</span>  
<span style="margin-left: 15em">四十度强圖地平</span>  
<span style="margin-left: 15em">線交夏至線于寅</span>  
<span style="margin-left: 15em">正二刻四分故順</span>  
<span style="margin-left: 1em">天府夏至晝長五十九刻十分<sub class="note-jiao">校：天理本十作七</sub>觀北極出地</span>  
<span style="margin-left: 1em">三十二度半圖地平線交夏至線于寅正三刻十二分</span>  
<span style="margin-left: 1em">故應天府夏至昼长五十六刻六分計差三刻其餘節</span>  
<span style="margin-left: 1em">氣以法對之亦然又欲知日出入及朦朧影時刻各異</span>  
<span style="margin-left: 1em">如上法可求</span>  
<span style="margin-left: 1em">因上三圖即知晝夜時刻隨北極出地各有長短北極</span>  
<span style="margin-left: 1em">不出地因赤道爲天頂左右節氣半在地上半在地下</span>  
<span style="margin-left: 1em">故晝夜必恒平也北極出地或二十度其赤道在天頂</span>  
<span style="margin-left: 1em">南二十度左右節氣皆偏于南二十度故晝夜必有長</span>  
<span style="margin-left: 1em">短也蓋人居赤道下者恒見半天若北極出地二十度</span>  
<span style="margin-left: 1em">南極必入地二十度人居赤道北二十度者其所見天</span>  
<span style="margin-left: 1em">北方必多二十度而能見赤道下者之所不見南方必</span>  
<span style="margin-left: 1em">少二十度而不見赤道下者之所得見人恒得見半天</span>  
<span style="margin-left: 1em">故也夏至節氣在赤道北其二十度之分現在地面上</span>  
<span style="margin-left: 1em">故得晝長冬至在赤道南其二十度之分隱在地面下</span>  
<span style="margin-left: 1em">故得晝短其北極出地三十四十五十度者其理并同</span>  
<span style="margin-left: 1em">獨至出地六十七度半則不同也試觀渾儀若北極出</span>  
<span style="margin-left: 1em">地十度夏至晝長二刻若出二十度長五刻出三十度</span>  
<span style="margin-left: 1em">長八刻出四十度長十二刻出五十度長十八刻出六</span>  
<span style="margin-left: 1em">十度長二十六刻出六十七度長四十八刻其長四十</span>  
<span style="margin-left: 1em">八刻者夏至線不交地平而全見在地平上冬至全在</span>  
<span style="margin-left: 1em">地平下故夏至日太陽行地面上不入地平晝長九十</span>  
<span style="margin-left: 1em">六刻無夜冬至日太陽行地面下不出地平夜長九十</span>  
<span style="margin-left: 1em">六刻無晝北極出地七十度立夏節氣線小滿芒種夏</span>  
<span style="margin-left: 1em">至小暑大暑皆在地平上立冬節氣線小雪大雪冬至</span>  
<span style="margin-left: 1em">小寒大寒皆在地平下其北極出地七十度者從小滿</span>  
<span style="margin-left: 1em">歷夏至夏至歷大暑凡六十日太陽斜行地上不入地</span>  
<span style="margin-left: 1em">下即六十日全爲晝無夜小雪以後歷冬至冬至歷大</span>  
<span style="margin-left: 1em">寒凡六十日太陽斜行地下不出地上即六十日全爲</span>  
<span style="margin-left: 1em">夜無晝若北極出地八十度則夏十節氣皆在地平上</span>  
<span style="margin-left: 15em">冬在下晝夜長短</span>  
<span style="margin-left: 15em">全爲百二十餘日</span>  
<span style="margin-left: 15em">若北極出地九十</span>  
<span style="margin-left: 15em">度則此地以北極</span>  
<span style="margin-left: 15em">爲天頂以赤道爲</span>  
<span style="margin-left: 15em">地平赤道北諸節</span>  
<span style="margin-left: 15em">氣全在地平上赤</span>  
<span style="margin-left: 15em">道南諸節氣全在</span>  
<span style="margin-left: 15em">地平下而半年爲</span>  
<span style="margin-left: 15em">晝半年爲夜矣</span>  
<span style="margin-left: 1em">試觀上圖北極在天頂赤道爲地平從春分歷夏至迄</span>  
<span style="margin-left: 1em">秋分諸節氣在地平上從秋分歷冬至迄春分諸節氣</span>  
<span style="margin-left: 1em">在地平下即見此地日躔赤道春分以後出地日輪漸</span>  
<span style="margin-left: 1em">高至夏至二十三度半以後漸下至秋分故半年恒周</span>  
<span style="margin-left: 1em">行于地平之上而全爲一晝秋分以後入地日輪漸下</span>  
<span style="margin-left: 1em">至冬至二十三度半以後漸高至春分故半年恒周行</span>  
<span style="margin-left: 1em">于地平之下而全爲一夜日出入地平十八度内皆爲</span>  
<span style="margin-left: 1em">朦朧影時刻故此地春分以前月半爲昧爽秋分以後</span>  
<span style="margin-left: 1em">月半爲黄昏也</span>  
<span style="margin-left: 1em">或曰一年半爲晝半爲夜何以證之曰吾西國人親所</span>  
<span style="margin-left: 1em">經歷其愈近北極者夏至日晝愈長夜愈短夏至日有</span>  
<span style="margin-left: 1em">全十二時爲晝有全三十日爲晝全六十日爲晝全六</span>  
<span style="margin-left: 1em">月爲晝歷歷身涉不可疑也依渾天儀論之其理不得</span>  
<span style="margin-left: 1em">不然也試于中國亦可見焉中國本境自南十八度起</span>  
<span style="margin-left: 1em">至北四十二度止人從最南北行每二百五十里必更</span>  
<span style="margin-left: 1em">一度漸北<sub class="note-jiao">校：漸原作所據天理本改</sub>漸移夏至日晝長夜短而京師</span>  
<span style="margin-left: 1em">北土之夏至日長于廣東南土之夏至廣州北極出地</span>  
<span style="margin-left: 1em">二十三度半夏至日五十三刻十一分爲晝餘四十二</span>  
<span style="margin-left: 1em">刻四分爲夜又以江西校之南昌府北極出地二十九</span>  
<span style="margin-left: 1em">度夏至日五十五刻七分爲晝餘四十刻八分爲夜視</span>  
<span style="margin-left: 1em">廣東晝夜長短差二刻南京北極出地三十二度半夏</span>  
<span style="margin-left: 1em">至日五十六刻六分爲晝餘三十九刻九分爲夜視廣</span>  
<span style="margin-left: 1em">東晝夜長短差三刻視江西差一刻山東濟南府北極</span>  
<span style="margin-left: 1em">出地三十七度晝長五十八刻四分餘爲夜即晝長于</span>  
<span style="margin-left: 1em">廣東五刻于江西三刻于南京二刻京師北極出地四</span>  
<span style="margin-left: 1em">十度其晝夜長短所差愈多從此可推自十八度以至</span>  
<span style="margin-left: 1em">四十一度各處不同又推知自四十二度至九十度晝</span>  
<span style="margin-left: 1em">夜漸長漸短以至半年爲晝半年爲夜足徵矣</span>  
<span style="margin-left: 1em">晝夜長短日出入時刻朦朧影刻分皆以北極出地多</span>  
<span style="margin-left: 1em">寡及所交節氣之日爲準宜随地随氣立算不可執一</span>  
<span style="margin-left: 1em">處以概地方也故爲立表如左表中最上横書一行首</span>  
<span style="margin-left: 1em">列北極出地自十八度至四十二度次爲諸節氣本日</span>  
<span style="margin-left: 1em">從冬至至夏至次得日出一行此行横書作二行一爲</span>  
<span style="margin-left: 1em">日出刻數一爲日出分數次日入一行次晝夜長短朦</span>  
<span style="margin-left: 1em">朧影其行各横書作二行一爲刻數一爲分數假如欲</span>  
<span style="margin-left: 1em">知順天府立冬或立春日日出入時刻晝夜長短朦朧</span>  
<span style="margin-left: 1em">影刻分别視左各表而檢得四十度爲其本表次檢取</span>  
<span style="margin-left: 1em">表中立冬本行及右日出行相對得卯正三刻十三分</span>
