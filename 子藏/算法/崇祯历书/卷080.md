## 崇祯历书卷之八十　诸方昼夜晨昏论及其分表

<span style="margin-left: 1em">诸方昼夜晨昏论及其分表<sub class="note-jiao">校：據日本島根大學抄本校錄</sub></span>  
<span style="margin-left: 3em">论经纬</span>  
<span style="margin-left: 1em">昼夜长短不一时刻亦异何也盖昼夜长短由于太阳</span>  
<span style="margin-left: 1em">及南北极出入地平也北极出地即夏至昼长夜短冬</span>  
<span style="margin-left: 1em">至昼短夜长南极出地反是其时势异也为此夏至为</span>  
<span style="margin-left: 1em">彼冬至故昼短夜长为此冬至为彼夏至故昼长夜短</span>  
<span style="margin-left: 1em">南北二极与地平则其地昼夜恒平故昼长夜短由于</span>  
<span style="margin-left: 1em">太阳及极出入地也南北为纬度东西为经度各一周</span>  
<span style="margin-left: 1em">三百六十度<sub class="note-jiao">校：周原作用據天理本東北本改</sub>人在地面凡居经度一</span>  
<span style="margin-left: 1em">带之内者其昼夜长短恒同其日出入及昼夜时刻则</span>  
<span style="margin-left: 1em">异盖经度之自东而西者人之所居或东或西虽各不</span>  
<span style="margin-left: 1em">同而纬度之三十度者皆为三十度四十度者皆为四</span>  
<span style="margin-left: 1em">十度也此同纬度者也若纬度之异者自赤道以至极</span>  
<span style="margin-left: 1em">下其昼夜长短各异矣</span>  
<span style="margin-left: 1em">如左图地为圆体悬于空际上下四旁皆有人居四方</span>  
<span style="margin-left: 1em">之人各以所居子午线为午时太阳在东方甲居东方</span>  
<span style="margin-left: 1em">者为午时日轮在其天顶故也乙居西方者即为卯时</span>  
<span style="margin-left: 1em">日轮至天顶须三时故也丙亦居西方方即为子时日</span>  
<span style="margin-left: 14em">轮以至天顶须六时</span>  
<span style="margin-left: 14em">故也诸地相去自东</span>  
<span style="margin-left: 14em">而西莫不皆然地球</span>  
<span style="margin-left: 14em">自南而北三百六十</span>  
<span style="margin-left: 14em">度一周每一度二百</span>  
<span style="margin-left: 14em">五十里日轮每刻平</span>  
<span style="margin-left: 14em">行天度三度四十五</span>  
<span style="margin-left: 14em">分如两地相去九百</span>  
<span style="margin-left: 14em">三十七里半则相隔</span>  
<span style="margin-left: 14em">为一刻相去七千五</span>  
<span style="margin-left: 1em">百里则相隔为一时因知居东方者若得午时自此逐</span>  
<span style="margin-left: 1em">渐往西即为己为辰为卯为寅为丑为子天下自东而</span>  
<span style="margin-left: 1em">西时刻各异各以日轮到本处子午线为午正初刻昼</span>  
<span style="margin-left: 1em">夜长短恒同者盖以北极出地多寡定为时刻多少所</span>  
<span style="margin-left: 1em">以自东而西一带但经度相同地方其离北极皆同则</span>  
<span style="margin-left: 1em">昼夜长短亦同</span>  
<span style="margin-left: 1em">南北纬度自赤道至极下昼夜时刻随地各有长短盖</span>  
<span style="margin-left: 1em">居赤道下者以赤道为天顶而其南北二极正与地面</span>  
<span style="margin-left: 1em">相平地平之交于诸节气线皆其正中故其昼夜长短</span>  
<span style="margin-left: 1em">恒平也北极出地则地平之交节气非其正中矣故所</span>  
<span style="margin-left: 1em">分上下亦非平分夏至则其线大分在上而昼长夜短</span>  
<span style="margin-left: 1em">冬至则其线小分在上而昼短夜长今欲知<sub class="note-jiao">校：今原作分據天理</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">本东北本改</sub>赤道之下昼夜常平</span>  
<span style="margin-left: 1em">如左图即见人居此地以赤道为天顶又南北极不出</span>  
<span style="margin-left: 1em">入地次见地平线相交于诸节气之线正当中而六时</span>  
<span style="margin-left: 1em">在地平上六时在下故太阳或行夏至或冬至或春秋</span>  
<span style="margin-left: 1em">分线上必六时在地面上而为昼六时在下而为夜其</span>  
<span style="margin-left: 1em">诸节气日出必卯正初刻日入必酉正初刻即昼夜当</span>  
<span style="margin-left: 1em">平可知也<sub class="note-jiao">校：當字天理本作常</sub>但其朦胧影稍异冬夏二至略长</span>  
<span style="margin-left: 1em">于春秋分之时此有别论今不其详自北道北行二百</span>  
<span style="margin-left: 14em">五十里见北极出地</span>  
<span style="margin-left: 14em">一度赤道离天顶南</span>  
<span style="margin-left: 14em">亦一度若行二千五</span>  
<span style="margin-left: 14em">百里即北极出地南</span>  
<span style="margin-left: 14em">极入地赤道离天顶</span>  
<span style="margin-left: 14em">南俱差十度自赤道</span>  
<span style="margin-left: 14em">下至北极下每行二</span>  
<span style="margin-left: 14em">百五十里皆差一度</span>  
<span style="margin-left: 14em">其赤道线偏在天顶</span>  
<span style="margin-left: 14em">南即诸节气线亦偏</span>  
<span style="margin-left: 1em">于南不与地平线相交于正中以为平分故昼夜时刻</span>  
<span style="margin-left: 1em">各有长短焉昼夜长短皆从北极出地而生今以北极</span>  
<span style="margin-left: 1em">出地四十度作法余可推焉</span>  
<span style="margin-left: 1em">如左图北极出地南极入地四十度赤道在天顶南亦</span>  
<span style="margin-left: 1em">四十度地平线交于诸节气线非其正中其交夏至线</span>  
<span style="margin-left: 1em">也于寅正二刻四分故昼长五十九刻七分每日九十</span>  
<span style="margin-left: 1em">六刻其余三十六刻八分为夜甚短因其线大半在地</span>  
<span style="margin-left: 1em">平上故自春分经夏至至秋分皆为昼长而夜短地平</span>  
<span style="margin-left: 1em">线交冬至在辰初一刻十一分故夜长五十九刻七分</span>  
<span style="margin-left: 1em">其余三十六刻八分为昼甚短因其线大半在地平下</span>  
<span style="margin-left: 14em">故自秋分历冬至至</span>  
<span style="margin-left: 14em">春分皆为夜长而昼</span>  
<span style="margin-left: 14em">短可知昼夜长短<sub class="note-jiao">校：長</sub></span>  
<span style="margin-left: 14em"><sub class="note-yuan">原作晨据天理本改</sub>由于南北</span>  
<span style="margin-left: 14em">二极出入地也</span>  
<span style="margin-left: 14em">如上图欲知顺天府</span>  
<span style="margin-left: 14em">每节气昼夜刻各几</span>  
<span style="margin-left: 14em">何则视本日节气在</span>  
<span style="margin-left: 14em">地平线上时刻即昼</span>  
<span style="margin-left: 14em">在下时刻即夜也假</span>  
<span style="margin-left: 1em">如于夏至线视地平线交于寅正二刻以上得二十九</span>  
<span style="margin-left: 1em">刻十一分是从日出至午正初刻数加一倍即从午正</span>  
<span style="margin-left: 1em">初至日入得五十九刻七分为昼刻分所余刻分即夜</span>  
<span style="margin-left: 1em">刻分也诸节气亦然又欲知日出入时刻即视地平线</span>  
<span style="margin-left: 1em">于本节气相交某时刻即得欲知随节气朦胧影刻各</span>  
<span style="margin-left: 1em">几何亦视本节气自朦胧线以上至地平线皆黄昏昧</span>  
<span style="margin-left: 1em">爽刻分也</span>  
<span style="margin-left: 1em">凡昼夜长短时刻由于南北极出入地与所居纬度之</span>  
<span style="margin-left: 1em">不同也天顶近于赤道则北极出地度数少即昼夜长</span>  
<span style="margin-left: 1em">短亦少天顶远于赤道则北极出地度分多即昼夜长</span>  
<span style="margin-left: 15em">短亦多故应天府</span>  
<span style="margin-left: 15em">北极出地三十二</span>  
<span style="margin-left: 15em">度半顺天府四十</span>  
<span style="margin-left: 15em">度强即多七度半</span>  
<span style="margin-left: 15em">其昼夜长短亦自</span>  
<span style="margin-left: 15em">不同欲知所差几</span>  
<span style="margin-left: 15em">何试观北极出地</span>  
<span style="margin-left: 15em">四十度强图地平</span>  
<span style="margin-left: 15em">线交夏至线于寅</span>  
<span style="margin-left: 15em">正二刻四分故顺</span>  
<span style="margin-left: 1em">天府夏至昼长五十九刻十分<sub class="note-jiao">校：天理本十作七</sub>观北极出地</span>  
<span style="margin-left: 1em">三十二度半图地平线交夏至线于寅正三刻十二分</span>  
<span style="margin-left: 1em">故应天府夏至昼长五十六刻六分计差三刻其余节</span>  
<span style="margin-left: 1em">气以法对之亦然又欲知日出入及朦胧影时刻各异</span>  
<span style="margin-left: 1em">如上法可求</span>  
<span style="margin-left: 1em">因上三图即知昼夜时刻随北极出地各有长短北极</span>  
<span style="margin-left: 1em">不出地因赤道为天顶左右节气半在地上半在地下</span>  
<span style="margin-left: 1em">故昼夜必恒平也北极出地或二十度其赤道在天顶</span>  
<span style="margin-left: 1em">南二十度左右节气皆偏于南二十度故昼夜必有长</span>  
<span style="margin-left: 1em">短也盖人居赤道下者恒见半天若北极出地二十度</span>  
<span style="margin-left: 1em">南极必入地二十度人居赤道北二十度者其所见天</span>  
<span style="margin-left: 1em">北方必多二十度而能见赤道下者之所不见南方必</span>  
<span style="margin-left: 1em">少二十度而不见赤道下者之所得见人恒得见半天</span>  
<span style="margin-left: 1em">故也夏至节气在赤道北其二十度之分现在地面上</span>  
<span style="margin-left: 1em">故得昼长冬至在赤道南其二十度之分隐在地面下</span>  
<span style="margin-left: 1em">故得昼短其北极出地三十四十五十度者其理并同</span>  
<span style="margin-left: 1em">独至出地六十七度半则不同也试观浑仪若北极出</span>  
<span style="margin-left: 1em">地十度夏至昼长二刻若出二十度长五刻出三十度</span>  
<span style="margin-left: 1em">长八刻出四十度长十二刻出五十度长十八刻出六</span>  
<span style="margin-left: 1em">十度长二十六刻出六十七度长四十八刻其长四十</span>  
<span style="margin-left: 1em">八刻者夏至线不交地平而全见在地平上冬至全在</span>  
<span style="margin-left: 1em">地平下故夏至日太阳行地面上不入地平昼长九十</span>  
<span style="margin-left: 1em">六刻无夜冬至日太阳行地面下不出地平夜长九十</span>  
<span style="margin-left: 1em">六刻无昼北极出地七十度立夏节气线小满芒种夏</span>  
<span style="margin-left: 1em">至小暑大暑皆在地平上立冬节气线小雪大雪冬至</span>  
<span style="margin-left: 1em">小寒大寒皆在地平下其北极出地七十度者从小满</span>  
<span style="margin-left: 1em">历夏至夏至历大暑凡六十日太阳斜行地上不入地</span>  
<span style="margin-left: 1em">下即六十日全为昼无夜小雪以后历冬至冬至历大</span>  
<span style="margin-left: 1em">寒凡六十日太阳斜行地下不出地上即六十日全为</span>  
<span style="margin-left: 1em">夜无昼若北极出地八十度则夏十节气皆在地平上</span>  
<span style="margin-left: 15em">冬在下昼夜长短</span>  
<span style="margin-left: 15em">全为百二十余日</span>  
<span style="margin-left: 15em">若北极出地九十</span>  
<span style="margin-left: 15em">度则此地以北极</span>  
<span style="margin-left: 15em">为天顶以赤道为</span>  
<span style="margin-left: 15em">地平赤道北诸节</span>  
<span style="margin-left: 15em">气全在地平上赤</span>  
<span style="margin-left: 15em">道南诸节气全在</span>  
<span style="margin-left: 15em">地平下而半年为</span>  
<span style="margin-left: 15em">昼半年为夜矣</span>  
<span style="margin-left: 1em">试观上图北极在天顶赤道为地平从春分历夏至迄</span>  
<span style="margin-left: 1em">秋分诸节气在地平上从秋分历冬至迄春分诸节气</span>  
<span style="margin-left: 1em">在地平下即见此地日躔赤道春分以后出地日轮渐</span>  
<span style="margin-left: 1em">高至夏至二十三度半以后渐下至秋分故半年恒周</span>  
<span style="margin-left: 1em">行于地平之上而全为一昼秋分以后入地日轮渐下</span>  
<span style="margin-left: 1em">至冬至二十三度半以后渐高至春分故半年恒周行</span>  
<span style="margin-left: 1em">于地平之下而全为一夜日出入地平十八度内皆为</span>  
<span style="margin-left: 1em">朦胧影时刻故此地春分以前月半为昧爽秋分以后</span>  
<span style="margin-left: 1em">月半为黄昏也</span>  
<span style="margin-left: 1em">或曰一年半为昼半为夜何以证之曰吾西国人亲所</span>  
<span style="margin-left: 1em">经历其愈近北极者夏至日昼愈长夜愈短夏至日有</span>  
<span style="margin-left: 1em">全十二时为昼有全三十日为昼全六十日为昼全六</span>  
<span style="margin-left: 1em">月为昼历历身涉不可疑也依浑天仪论之其理不得</span>  
<span style="margin-left: 1em">不然也试于中国亦可见焉中国本境自南十八度起</span>  
<span style="margin-left: 1em">至北四十二度止人从最南北行每二百五十里必更</span>  
<span style="margin-left: 1em">一度渐北<sub class="note-jiao">校：漸原作所據天理本改</sub>渐移夏至日昼长夜短而京师</span>  
<span style="margin-left: 1em">北土之夏至日长于广东南土之夏至广州北极出地</span>  
<span style="margin-left: 1em">二十三度半夏至日五十三刻十一分为昼余四十二</span>  
<span style="margin-left: 1em">刻四分为夜又以江西校之南昌府北极出地二十九</span>  
<span style="margin-left: 1em">度夏至日五十五刻七分为昼余四十刻八分为夜视</span>  
<span style="margin-left: 1em">广东昼夜长短差二刻南京北极出地三十二度半夏</span>  
<span style="margin-left: 1em">至日五十六刻六分为昼余三十九刻九分为夜视广</span>  
<span style="margin-left: 1em">东昼夜长短差三刻视江西差一刻山东济南府北极</span>  
<span style="margin-left: 1em">出地三十七度昼长五十八刻四分余为夜即昼长于</span>  
<span style="margin-left: 1em">广东五刻于江西三刻于南京二刻京师北极出地四</span>  
<span style="margin-left: 1em">十度其昼夜长短所差愈多从此可推自十八度以至</span>  
<span style="margin-left: 1em">四十一度各处不同又推知自四十二度至九十度昼</span>  
<span style="margin-left: 1em">夜渐长渐短以至半年为昼半年为夜足征矣</span>  
<span style="margin-left: 1em">昼夜长短日出入时刻朦胧影刻分皆以北极出地多</span>  
<span style="margin-left: 1em">寡及所交节气之日为准宜随地随气立算不可执一</span>  
<span style="margin-left: 1em">处以概地方也故为立表如左表中最上横书一行首</span>  
<span style="margin-left: 1em">列北极出地自十八度至四十二度次为诸节气本日</span>  
<span style="margin-left: 1em">从冬至至夏至次得日出一行此行横书作二行一为</span>  
<span style="margin-left: 1em">日出刻数一为日出分数次日入一行次昼夜长短朦</span>  
<span style="margin-left: 1em">胧影其行各横书作二行一为刻数一为分数假如欲</span>  
<span style="margin-left: 1em">知顺天府立冬或立春日日出入时刻昼夜长短朦胧</span>  
<span style="margin-left: 1em">影刻分别视左各表而检得四十度为其本表次检取</span>  
<span style="margin-left: 1em">表中立冬本行及右日出行相对得卯正三刻十三分</span>  
<span style="margin-left: 1em">其余相对如是而得日入申正四刻二分昼长短四十</span>
