## 崇禎曆書卷之九　崇禎奏疏

*崇禎八年四月初四日至崇禎九年二月二十六日*

<span style="margin-left: 2em">緣起九</span>  
<span style="margin-left: 8em">崇禎八年四月初四日李天經奏本</span>  
<span style="margin-left: 3em">督修曆法山東布政使司右參政臣李天經謹</span>  
<span style="margin-left: 2em">奏爲曆法業有成局微臣敬申前請伏乞轉委大臣</span>  
<span style="margin-left: 3em">以終鉅典事竊照臣之奉</span>  
<span style="margin-left: 1em">命入都門也緣</span>  
<span style="margin-left: 1em">皇上特允輔臣禮臣之</span>  
<span style="margin-left: 1em">請兩下速催到任之</span>  
<span style="margin-left: 1em">明旨臣是以袛遵</span>  
<span style="margin-left: 1em">明命竭蹷前來任事乃屢遭謗忌相駁相扼無肯秉虛</span>  
<span style="margin-left: 3em">公以從事者令臣法難明臣心兹苦矣乃尚隠忍</span>  
<span style="margin-left: 3em">逾時未即引退者以書器雖完僅畢治曆之成模</span>  
<span style="margin-left: 3em">而參訂未詳猶非修正之實着恐虛</span>  
<span style="margin-left: 1em">皇上責成之盛心且墮舊輔將完之前緒耳今於數月</span>  
<span style="margin-left: 3em">間公同欽天監監正張守登監副戈承科周胤等</span>  
<span style="margin-left: 3em">皆虛心察理不執成見遵</span>  
<span style="margin-left: 1em">旨參訂頗韙臣言且監官曆科之學習新法如劉有慶</span>  
<span style="margin-left: 3em">賈良棟等皆精心理解知新法合天而津津願學</span>  
<span style="margin-left: 3em">皆非有所强也故臣等得與結參訂一局而彙欵</span>  
<span style="margin-left: 3em">細推恭</span>  
<span style="margin-left: 2em">進以塵</span>  
<span style="margin-left: 1em">御覽或</span>  
<span style="margin-left: 2em">下閣部大臣會議之後如即</span>  
<span style="margin-left: 2em">賜改正頒行固成</span>  
<span style="margin-left: 2em">一代之大典臣敢必其無所差忒倘猶欲與異術較</span>  
<span style="margin-left: 3em">疏密待屢測屢驗人心大同以成信曆則</span>  
<span style="margin-left: 1em">聖主慎重欽若之弘謨亦臣所大願此則非歳月之可</span>  
<span style="margin-left: 3em">計也臣請以在局生儒盡收之欽天監以便隨時</span>  
<span style="margin-left: 3em">推測將臣等所成新法暫附于大統以便公同考</span>  
<span style="margin-left: 3em">驗使久之而屢測不爽以</span>  
<span style="margin-left: 1em">天縱聖明如</span>  
<span style="margin-left: 1em">皇上亦豈容承舛者尚沿乎陋習而合天者終以故紙</span>  
<span style="margin-left: 3em">置之耶此事正有待也然而本局之曆則已告成</span>  
<span style="margin-left: 3em">矣臣之一身可以言去矣蓋臣自去歳四月到京</span>  
<span style="margin-left: 3em">已及一年藩司薪俸久不沾濡仕籍姓名向已刊</span>  
<span style="margin-left: 3em">落論臣子敬事後食之義皆不敢言但奉</span>  
<span style="margin-left: 1em">命而來竣事而退微臣出處之宜明不當如是耶伏乞</span>  
<span style="margin-left: 1em">皇上放臣歸里以甦病骨以避衆忌則所全于臣之身</span>  
<span style="margin-left: 3em">名更大矣即尚有未完如監官之學習新法者纔</span>  
<span style="margin-left: 3em">得一半講解通徹尚須年餘新法之度數旁通尚</span>  
<span style="margin-left: 3em">有多欵經輔臣之已</span>  
<span style="margin-left: 2em">題者徐待製造然皆餘事也伏乞</span>  
<span style="margin-left: 2em">轉委閣部大臣一員兼攝之則不煩更置可以鎮羣</span>  
<span style="margin-left: 3em">囂而凝庶績賢于孤踪之臣萬萬矣伏祈</span>  
<span style="margin-left: 1em">聖鑒下部議</span>  
<span style="margin-left: 2em">覆施行臣無任惶悚之至</span>  
<span style="margin-left: 3em">崇禎八年四月初四日具</span>  
<span style="margin-left: 2em">題初六日奉</span>  
<span style="margin-left: 1em">聖旨新法書器雖完然推測疎密未經考驗且據稱度</span>  
<span style="margin-left: 2em">數旁通尚有多欵徐待製造豈得遽云局曆告成李</span>  
<span style="margin-left: 2em">天經還同該監官虛心詳究務期畫一以禆曆法俸</span>  
<span style="margin-left: 2em">薪久不支給是何緣故著即與查補該部知道</span>  
<span style="margin-left: 7em">崇禎八年四月二十七日李天經題本</span>  
<span style="margin-left: 3em">督修曆法山東布政使司右參政臣李天經謹</span>  
<span style="margin-left: 2em">題爲遵奉</span>  
<span style="margin-left: 1em">明旨敬申旁通事宜以便翻譯製造事先該前輔臣徐</span>  
<span style="margin-left: 3em">光啓條上旁通十事奉</span>  
<span style="margin-left: 1em">聖旨度數旁通有關庶績一併分曹料理欽此蓋因前</span>  
<span style="margin-left: 3em">此曆事未完工力有限是以至今未遑措辦也頃</span>  
<span style="margin-left: 3em">該臣奏爲曆法業有成局一疏奉</span>  
<span style="margin-left: 1em">聖旨新法書器雖完然推測疎密未經考驗且據稱度</span>  
<span style="margin-left: 2em">數旁通尚有多欵徐待製造豈得遽云局曆告成李</span>  
<span style="margin-left: 2em">天經還同該監官虛心詳究務期畫一以禆曆法俸</span>  
<span style="margin-left: 2em">薪久不支給是何緣故著即與查補該部知道欽此</span>  
<span style="margin-left: 2em">欽遵除臣一面遵</span>  
<span style="margin-left: 1em">旨任事會同該監諸臣將新舊七政行度朝夕考驗聽</span>  
<span style="margin-left: 3em">禮部類奏外所有旁通諸務臣一一與陪臣<sub class="note-jiao">校：清刊本</sub></span>  
<span style="margin-left: 3em"><sub class="note-yuan">陪臣作遠臣</sub>羅雅谷湯若望等逐欵商確然皆目前切</span>  
<span style="margin-left: 3em">要之事濟時適用有禆急需第非旦夕可竟之功</span>  
<span style="margin-left: 3em">講解著述尚須時日謹照輔臣原題稍加更正再</span>  
<span style="margin-left: 3em">行臚列于</span>  
<span style="margin-left: 1em">皇上之前亦見臣等于考測之暇非敢玩日愒月而所</span>  
<span style="margin-left: 3em">接續考求者乃歴法修正後推廣度數之妙用以</span>  
<span style="margin-left: 3em">仰佐</span>  
<span style="margin-left: 1em">明時急務而非止言曆已也然之數事者頭緒頗多形</span>  
<span style="margin-left: 3em">質甚廣釋義演文與夫較勘製造翳惟人是賴似</span>  
<span style="margin-left: 3em">非臣與一二陪臣<sub class="note-jiao">校：同前條</sub>所能卒業故不無望于衆</span>  
<span style="margin-left: 3em">思羣力之助也如在局知曆生儒等臣會</span>  
<span style="margin-left: 2em">請以量加職銜少酬前勞業蒙</span>  
<span style="margin-left: 1em">皇上下部酌議具奏但得速爲叙錄臣亦可藉手責成</span>  
<span style="margin-left: 3em">不獨日後交食並七政諸曆皆須爲之推算即旁</span>  
<span style="margin-left: 3em">通一役必先示以勉勵之意使諸臣薪水無慮得</span>  
<span style="margin-left: 3em">以一意隨分盡職如</span>  
<span style="margin-left: 1em">明旨所爲分曹料理可也統候</span>  
<span style="margin-left: 1em">聖裁</span>  
<span style="margin-left: 3em">計開</span>  
<span style="margin-left: 4em">度數旁通十事</span>  
<span style="margin-left: 5em">其一考求七政行度性情下合地宜一切水</span>  
<span style="margin-left: 6em">旱蟲蝗疾癘兵戎可以約略預知則凡先</span>  
<span style="margin-left: 6em">事修救如農家因之勤稼穡兵家因之備</span>  
<span style="margin-left: 6em">邊儲其于民生國計大有利益</span>  
<span style="margin-left: 5em">其二度數既明精通水法一切疏濬河渠灌</span>  
<span style="margin-left: 6em">溉田畆置閘河以利運艘造水銃以捄火</span>  
<span style="margin-left: 6em">灾與夫風水輪盤諸器治水用水各利實</span>  
<span style="margin-left: 6em">用</span>  
<span style="margin-left: 5em">其三度數與樂律相通明于度數即能考正</span>  
<span style="margin-left: 6em">音律制造器具于修定雅樂可以相資</span>  
<span style="margin-left: 5em">其四兵家營陣器械及築治城臺池隍等皆</span>  
<span style="margin-left: 6em">須度數爲用精于其法有禆邊計</span>  
<span style="margin-left: 5em">其五算學久廢官司計會多委任胥吏錢榖</span>  
<span style="margin-left: 6em">之司關係尤重度數既明凡九章諸術皆</span>  
<span style="margin-left: 6em">有簡當捷要之法習業甚易理財之臣尤</span>  
<span style="margin-left: 6em">所急需</span>  
<span style="margin-left: 5em">其六營建屋宇橋梁等明于度數者力省功</span>  
<span style="margin-left: 6em">倍且經度堅固千萬年不圮不壊</span>  
<span style="margin-left: 5em">其七明于度數能造作機器可以任重致遠</span>  
<span style="margin-left: 6em">一切舉重引重諸器皆有利便之法以前</span>  
<span style="margin-left: 6em">民用以省民力</span>  
<span style="margin-left: 5em">其八天下輿地其南北東西縱横相距紆直</span>  
<span style="margin-left: 6em">廣袤與夫山海原隰高深廣遠皆可用法</span>  
<span style="margin-left: 6em">測量洞其隠微</span>  
<span style="margin-left: 5em">其九醫藥之家宜審運氣曆數既明可以察</span>  
<span style="margin-left: 6em">知日月五星躔次與病體相視乖和順逆</span>  
<span style="margin-left: 6em">因而藥石針砭不致差誤大爲生民利益</span>  
<span style="margin-left: 5em">其十造作沙水等漏以知時刻分秒若日月</span>  
<span style="margin-left: 6em">星晷依視學製造不論公私處所南北東</span>  
<span style="margin-left: 6em">西欹斜㘭突皆可安置施用使人人能分</span>  
<span style="margin-left: 6em">更分漏以率作興事屢省考成</span>
