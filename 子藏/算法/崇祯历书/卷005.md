## 崇禎曆書卷之五　崇禎奏疏

*崇禎五年九月十二日至崇禎六年十月初七日*

<span style="margin-left: 2em">緣起五</span>  
<span style="margin-left: 8em">崇禎五年九月十二日徐光啓題本</span>  
<span style="margin-left: 3em">大學士徐</span>  
<span style="margin-left: 2em">題本月十四日夜望月食臣已于本年五月初二日</span>  
<span style="margin-left: 3em">題奉</span>  
<span style="margin-left: 1em">聖旨禮部知道欽此竊惟交食之法臣等所譯譔新法</span>  
<span style="margin-left: 3em">與舊法不無參差若在早晚其驗尤著蓋郭守敬</span>  
<span style="margin-left: 3em">之術視古爲密其差最多不過四五刻惟是四五</span>  
<span style="margin-left: 3em">刻之差在日出入之交未免以夜刻爲晝以晝刻</span>  
<span style="margin-left: 3em">爲夜故前世有推而不食有食而失推者以此之</span>  
<span style="margin-left: 3em">故非星官曆人敢有改易也如今次一食大統法</span>  
<span style="margin-left: 3em">日出卯正二刻新法日出卯正三刻所差約一刻</span>  
<span style="margin-left: 3em">其食時回回曆推初虧在辰初初刻則晝食矣大</span>  
<span style="margin-left: 3em">統推初虧卯初一刻依本法見食者五刻依新法</span>  
<span style="margin-left: 3em">見食者六刻新法初虧卯初三刻在舊法後二刻</span>  
<span style="margin-left: 3em">依本法見食者四刻依舊法見食者五刻此外若</span>  
<span style="margin-left: 3em">定時有先後升降有正斜地氣有厚薄亦皆參差</span>  
<span style="margin-left: 3em">之緣也故每交食時臣曾</span>  
<span style="margin-left: 2em">題請身往測候必得其真時刻真分數少有參錯又</span>  
<span style="margin-left: 3em">因而究其所以然然後目前辨難可據以剖晰異</span>  
<span style="margin-left: 3em">時推步可用以尋求矣今臣仰荷</span>  
<span style="margin-left: 1em">聖恩備員揆地例當於中府衙門隨班救護如此則本</span>  
<span style="margin-left: 3em">局督視無人雖有陪臣<sub class="note-jiao">校：清刊本陪臣改作遠臣</sub>臺官等依法</span>  
<span style="margin-left: 3em">測驗不至乖舛然非臣目所親見而即憑以</span>  
<span style="margin-left: 1em">上聞且勒以垂後實臣心所未安也且是日見食者僅</span>  
<span style="margin-left: 3em">四刻月又當斜入于地初虧時月在地上僅十餘</span>  
<span style="margin-left: 3em">度若在中府則墻屋隱蔽恐不可得見候驗乎以</span>  
<span style="margin-left: 3em">此</span>  
<span style="margin-left: 1em">請乞容臣於是日照前登臺實測次日具本奏</span>  
<span style="margin-left: 1em">聞庶於</span>  
<span style="margin-left: 1em">欽若大典不無禆益伏候</span>  
<span style="margin-left: 1em">勅旨謹</span>  
<span style="margin-left: 2em">題</span>  
<span style="margin-left: 3em">崇禎五年九月十二日　　　　十四日奉</span>  
<span style="margin-left: 1em">聖旨覽卿奏以月食詣局候驗具徴恪慎朕知道了</span>  
<span style="margin-left: 8em">崇禎五年九月十五日徐光啓題本</span>  
<span style="margin-left: 3em">大學士徐</span>  
<span style="margin-left: 2em">題臣于本月十四日欽奉</span>  
<span style="margin-left: 1em">明旨至今十五日丑時前往曆局督同陪臣<sub class="note-jiao">校：清刊本陪臣改作</sub></span>  
<span style="margin-left: 3em"><sub class="note-yuan">遠臣</sub>及該監官生在局知曆人等測候月食依法用</span>  
<span style="margin-left: 3em">儀器二具測量星度推算時候參以星晷壺漏務</span>  
<span style="margin-left: 3em">求四事脗合逐時逐刻測至卯初一刻忽有雲氣</span>  
<span style="margin-left: 3em">隱蔽月體至天明雲尚未開凡食分時刻皆無憑</span>  
<span style="margin-left: 3em">測驗理合</span>  
<span style="margin-left: 2em">奏</span>  
<span style="margin-left: 1em">聞謹</span>  
<span style="margin-left: 2em">題</span>  
<span style="margin-left: 3em">崇禎五年九月十五日具　十八日奉</span>  
<span style="margin-left: 1em">聖旨朕知道了</span>  
<span style="margin-left: 8em">崇禎五年十月十一日徐光啓奏本</span>  
<span style="margin-left: 3em">禮部尚書兼東閣大學士臣徐光啓謹</span>  
<span style="margin-left: 2em">奏爲月食事本年九月十五日臣奉</span>  
<span style="margin-left: 1em">旨前往曆局測候月食自卯初至日出時俱雲陰不見</span>  
<span style="margin-left: 3em">隨于本日具揭回</span>  
<span style="margin-left: 2em">奏十八日奉</span>  
<span style="margin-left: 1em">聖旨朕知道了欽此又本日該欽天監一本爲觀候事</span>  
<span style="margin-left: 3em">二十一日奉</span>  
<span style="margin-left: 1em">聖旨月食據靈臺官奏卯初一刻初虧忽遇薄雲漸布</span>  
<span style="margin-left: 3em">該監徑稱雲陰不見何故異同其食時先後各法</span>  
<span style="margin-left: 3em">不一也著奏明禮部知道欽此案照先時推步本</span>  
<span style="margin-left: 3em">食據欽天監靈臺官俱依郭守敬授時曆法初虧</span>  
<span style="margin-left: 3em">在卯初一刻臣等譯譔新法初虧在卯初三刻回</span>  
<span style="margin-left: 3em">回曆初虧在辰初初刻三法之不同如此至期測</span>  
<span style="margin-left: 3em">候正欲藉以辨其離合合則據爲準式離則尚費</span>  
<span style="margin-left: 3em">推求不意候至卯初一刻遂有陰雲迄于天明未</span>  
<span style="margin-left: 3em">見開朗諸法是非無從徴驗該靈臺官言先有薄</span>  
<span style="margin-left: 3em">雲後見濃雲該監言雲陰不見靈臺語意稍詳而</span>  
<span style="margin-left: 3em">雲陰不見亦曆書成語略有異同其實一也迨奉</span>  
<span style="margin-left: 1em">明旨該監已經呈部覆</span>  
<span style="margin-left: 2em">奏但三法不同之因則曆科官生專諳舊法其習學</span>  
<span style="margin-left: 3em">新法時日未久未能一一究明臣不得不代陳之</span>  
<span style="margin-left: 3em">蓋聞交食之法先求平朔望平朔望之算起于曆</span>  
<span style="margin-left: 3em">元今曆法本用元授時曆以至元辛巳爲曆元當</span>  
<span style="margin-left: 3em">時所立四應稍有未合臣等新法以崇禎元年戊</span>  
<span style="margin-left: 3em">辰爲曆元兩者相提已推得舊法後天六十五分</span>  
<span style="margin-left: 3em">爲半刻有奇矣既得平朔望以求定朔望定朔望</span>  
<span style="margin-left: 3em">即日月之食甚定分也法以日躔盈縮月轉遲疾</span>  
<span style="margin-left: 3em">推其各差又以兩差之較爲加減時差用以加減</span>  
<span style="margin-left: 3em">于平數得定數焉昨九月十四日夜望則太陽在</span>  
<span style="margin-left: 3em">縮曆而授時法縮曆起夏至不知日有最高有夏</span>  
<span style="margin-left: 3em">至兩行異法縮曆宜從最高起算也惟宋紹興年</span>  
<span style="margin-left: 3em">間兩行同度郭守敬後此百年去離僅一度有奇</span>  
<span style="margin-left: 3em">故未及覺今最高一行已在夏至後六日有奇以</span>  
<span style="margin-left: 3em">推縮差則舊法後天一十八分有奇也是日太陰</span>  
<span style="margin-left: 3em">在疾曆遲疾之法授時止論一轉周新法謂之自</span>  
<span style="margin-left: 3em">行輪月自行之外又有兩次輪以次密推則舊法</span>  
<span style="margin-left: 3em">疾曆先天二度有奇以推疾差又後天四十分也</span>  
<span style="margin-left: 3em">次以縮疾兩差相較變爲時而求定望宜用減法</span>  
<span style="margin-left: 3em">舊法則一推而得四十八刻九十分新法再推先</span>  
<span style="margin-left: 3em">得四十一刻一十三分有奇次得四十四刻八分</span>  
<span style="margin-left: 3em">兩得相較又差三刻弱故舊法之食甚定分得二</span>  
<span style="margin-left: 3em">十八刻弱新法得三十刻弱以推初虧則舊法得</span>  
<span style="margin-left: 3em">在子正後二十二刻二十二分爲卯初一刻新法</span>  
<span style="margin-left: 3em">得在子正後二十三刻五十九分爲卯初三刻此</span>  
<span style="margin-left: 3em">舊法與新法異同之因也若回回曆又異二法者</span>  
<span style="margin-left: 3em">臣等實未能盡曉其故僅知彼曆元爲阿剌必年</span>  
<span style="margin-left: 3em">與隋開皇相值去今一千三十餘載矣年遠數殊</span>  
<span style="margin-left: 3em">意其平朔望亦未合也即以減分論則是日太陽</span>  
<span style="margin-left: 3em">縮曆在四宫一度依彼法得縮差一度四十一分</span>  
<span style="margin-left: 3em">新法得一度四十三分其差二分太陰疾曆在十</span>  
<span style="margin-left: 3em">宫十七度依彼法得疾差二度一十九分半新法</span>  
<span style="margin-left: 3em">得三度六分其差一十三分半兩差相併得十五</span>  
<span style="margin-left: 3em">分半變爲時約彼法在新法後四刻今差五刻者</span>  
<span style="margin-left: 3em">意其緣正在曆元四應否則創法之處距西一萬</span>  
<span style="margin-left: 3em">餘里或里差又未合也總之三家所報各依其本</span>  
<span style="margin-left: 3em">法展轉推求乃始得之不能立異以相畸亦不能</span>  
<span style="margin-left: 3em">中變以相就必欲辨其疎密則在臨食之時實測</span>  
<span style="margin-left: 3em">實驗而已今已往之事無復可論將來準法似須</span>  
<span style="margin-left: 3em">商求所宜求者蓋有二端其一曰食分多寡按交</span>  
<span style="margin-left: 3em">食法中不惟推步爲難併較驗亦復未易臣前疏</span>  
<span style="margin-left: 3em">嘗言日食時陽晶晃耀每先食而後見月食時游</span>  
<span style="margin-left: 3em">氣紛侵每先見而後食蓋食者二體相交之謂也</span>  
<span style="margin-left: 3em">日食既交因其大光人目未見必至一分以上乃</span>  
<span style="margin-left: 3em">得見之月食未交闇虛之旁先有黑影侵入于月</span>  
<span style="margin-left: 3em">及其體交反無界限故推步縱無舛謬而較驗多</span>  
<span style="margin-left: 3em">任目任意揣摹影響不能灼見分數以證原推得</span>  
<span style="margin-left: 3em">失亦無繇知如宋臣周琮所定差天一分以下爲</span>  
<span style="margin-left: 3em">親二分以下爲近三分以下爲遠非苟自恕蓋其</span>  
<span style="margin-left: 3em">術止此而已今欲灼見實分有近造闚筩新法日</span>  
<span style="margin-left: 3em">食時用于密室中取其光影映照尺素之上自初</span>  
<span style="margin-left: 3em">虧至復圓所見分數界限真確畫然不爽月食不</span>  
<span style="margin-left: 3em">能定其分秒之限然二體離合之際鄞鄂著明中</span>  
<span style="margin-left: 3em">間色象亦與目測逈異此定分法也其一曰加時</span>  
<span style="margin-left: 3em">早晚定時之術相傳有壺漏爲古法近有輪鍾爲</span>  
<span style="margin-left: 3em">簡法然而調品皆繇人力遷就可憑人意故不如</span>  
<span style="margin-left: 3em">求端于日星晝則用日夜則任用一星皆以儀器</span>  
<span style="margin-left: 3em">測取經緯度數推算得之是爲本法其驗之則測</span>  
<span style="margin-left: 3em">日有平晷新法測星有立晷新法皆礱石範銅鑱</span>  
<span style="margin-left: 3em">畫數度節氣時刻一一分明以之較論交食皆于</span>  
<span style="margin-left: 3em">本晷之上某時某刻先期注定至時徴驗是合是</span>  
<span style="margin-left: 3em">離灼然易見此定時法也二法既立一遇交食凡</span>  
<span style="margin-left: 3em">古今諸術得失疎密如明鏡高懸妍𡟎莫遁矣然</span>  
<span style="margin-left: 3em">而臺官之情甚以此爲苦何者彼之本法有時先</span>  
<span style="margin-left: 3em">後天一二刻或四五刻自以爲差天至此不免于</span>  
<span style="margin-left: 3em">罪戾故耳以臣論之臺官之曆郭守敬之曆也守</span>  
<span style="margin-left: 3em">敬之法今日之所謂差當時之所謂密也臣嘗曆</span>  
<span style="margin-left: 3em">考古今疎密之致矣月食諸史不載所載日食自</span>  
<span style="margin-left: 3em">漢至隋凡二百九十三而食于晦日者七十七晦</span>  
<span style="margin-left: 3em">前一日者三初二日者三其疎如此唐至五代凡</span>  
<span style="margin-left: 3em">一百一十而食于晦日者一初二日者一初三日</span>  
<span style="margin-left: 3em">者一稍密矣宋凡一百四十八則無晦食更密矣</span>  
<span style="margin-left: 3em">猶有推食而不食者十三元凡四十五亦無晦食</span>  
<span style="margin-left: 3em">猶有推食而不食者一食而失推者一夜食而書</span>  
<span style="margin-left: 3em">晝者一至加時先後至四五刻者當其時已然至</span>  
<span style="margin-left: 3em">今遵用安能免此乃守敬之法三百年來世共歸</span>  
<span style="margin-left: 3em">推以爲度越前代何也高遠無窮之事必積時累</span>  
<span style="margin-left: 3em">世乃稍見其端倪故漢至今千五百歲立法者僅</span>  
<span style="margin-left: 3em">十有三家蓋于數十百年間一較工拙非一人之</span>  
<span style="margin-left: 3em">心思智力所能黽勉者也守敬集前古之大成加</span>  
<span style="margin-left: 3em">以精思廣測故所差僅四五刻比于前代洵爲密</span>  
<span style="margin-left: 3em">矣若使守敬復生今世欲更求精密計非苦心竭</span>  
<span style="margin-left: 3em">力假以數年恐未易得何可責于沿襲舊法如諸</span>  
<span style="margin-left: 3em">臺臣者乎今食分加時並如臣等新法較勘則差</span>  
<span style="margin-left: 3em">殊畢露儻遂以此爲諸臣罪能無惶怖能無畏葸</span>  
<span style="margin-left: 3em">然而實非彼罪即加之譴責亦付之無可奈何而</span>  
<span style="margin-left: 3em">已事有非力所及者亦古法所必寛也豈惟諸臣</span>  
<span style="margin-left: 3em">即臣等新法遂成似可悉無前代之誤乃食限或</span>  
<span style="margin-left: 3em">差半分上下加時或差半刻上下慮所不免惟是</span>  
<span style="margin-left: 3em">臣等不敢以差自安亦不敢以差自廢正須緣此</span>  
<span style="margin-left: 3em">微差遡厥因起別求新意據理改定臣所懼者諸</span>  
<span style="margin-left: 3em">臣以惶恐畏咎之心堅其安習溺聞之陋臣等書</span>  
<span style="margin-left: 3em">雖告成而願學者少有倡無和有傳無習恐他日</span>  
<span style="margin-left: 3em">終成廢閣耳伏望</span>  
<span style="margin-left: 1em">聖明察其從前之失實非繇已開其向往之路嘉與圖</span>  
<span style="margin-left: 3em">新即有疎遠且勿遽加罪譴但令陳說所以然之</span>  
<span style="margin-left: 3em">故有能精習透曉者量加優異久而不諳罰亦隨</span>  
<span style="margin-left: 3em">之將必有翹然傑出明羲和之大業應唐虞之</span>  
<span style="margin-left: 1em">景運者矣若日晷星晷闚筩三器者局中所用體製甚</span>  
<span style="margin-left: 3em">小工作尤粗儻須上塵</span>  
<span style="margin-left: 1em">聖覽則模式應加廣長賦列應加精贍其費亦不過數</span>
