## 崇祯历书卷之五　崇祯奏疏

*崇祯五年九月十二日至崇祯六年十月初七日*

<span style="margin-left: 2em">缘起五</span>  
<span style="margin-left: 8em">崇祯五年九月十二日徐光启题本</span>  
<span style="margin-left: 3em">大学士徐</span>  
<span style="margin-left: 2em">题本月十四日夜望月食臣已于本年五月初二日</span>  
<span style="margin-left: 3em">题奉</span>  
<span style="margin-left: 1em">圣旨礼部知道钦此窃惟交食之法臣等所译譔新法</span>  
<span style="margin-left: 3em">与旧法不无参差若在早晚其验尤著盖郭守敬</span>  
<span style="margin-left: 3em">之术视古为密其差最多不过四五刻惟是四五</span>  
<span style="margin-left: 3em">刻之差在日出入之交未免以夜刻为昼以昼刻</span>  
<span style="margin-left: 3em">为夜故前世有推而不食有食而失推者以此之</span>  
<span style="margin-left: 3em">故非星官历人敢有改易也如今次一食大统法</span>  
<span style="margin-left: 3em">日出卯正二刻新法日出卯正三刻所差约一刻</span>  
<span style="margin-left: 3em">其食时回回历推初亏在辰初初刻则昼食矣大</span>  
<span style="margin-left: 3em">统推初亏卯初一刻依本法见食者五刻依新法</span>  
<span style="margin-left: 3em">见食者六刻新法初亏卯初三刻在旧法后二刻</span>  
<span style="margin-left: 3em">依本法见食者四刻依旧法见食者五刻此外若</span>  
<span style="margin-left: 3em">定时有先后升降有正斜地气有厚薄亦皆参差</span>  
<span style="margin-left: 3em">之缘也故每交食时臣曾</span>  
<span style="margin-left: 2em">题请身往测候必得其真时刻真分数少有参错又</span>  
<span style="margin-left: 3em">因而究其所以然然后目前辨难可据以剖晰异</span>  
<span style="margin-left: 3em">时推步可用以寻求矣今臣仰荷</span>  
<span style="margin-left: 1em">圣恩备员揆地例当于中府衙门随班救护如此则本</span>  
<span style="margin-left: 3em">局督视无人虽有陪臣<sub class="note-jiao">校：清刊本陪臣改作遠臣</sub>台官等依法</span>  
<span style="margin-left: 3em">测验不至乖舛然非臣目所亲见而即凭以</span>  
<span style="margin-left: 1em">上闻且勒以垂后实臣心所未安也且是日见食者仅</span>  
<span style="margin-left: 3em">四刻月又当斜入于地初亏时月在地上仅十余</span>  
<span style="margin-left: 3em">度若在中府则墙屋隐蔽恐不可得见候验乎以</span>  
<span style="margin-left: 3em">此</span>  
<span style="margin-left: 1em">请乞容臣于是日照前登台实测次日具本奏</span>  
<span style="margin-left: 1em">闻庶于</span>  
<span style="margin-left: 1em">钦若大典不无禆益伏候</span>  
<span style="margin-left: 1em">勅旨谨</span>  
<span style="margin-left: 2em">题</span>  
<span style="margin-left: 3em">崇祯五年九月十二日　　　　十四日奉</span>  
<span style="margin-left: 1em">圣旨览卿奏以月食诣局候验具徴恪慎朕知道了</span>  
<span style="margin-left: 8em">崇祯五年九月十五日徐光启题本</span>  
<span style="margin-left: 3em">大学士徐</span>  
<span style="margin-left: 2em">题臣于本月十四日钦奉</span>  
<span style="margin-left: 1em">明旨至今十五日丑时前往历局督同陪臣<sub class="note-jiao">校：清刊本陪臣改作</sub></span>  
<span style="margin-left: 3em"><sub class="note-yuan">远臣</sub>及该监官生在局知历人等测候月食依法用</span>  
<span style="margin-left: 3em">仪器二具测量星度推算时候参以星晷壶漏务</span>  
<span style="margin-left: 3em">求四事脗合逐时逐刻测至卯初一刻忽有云气</span>  
<span style="margin-left: 3em">隐蔽月体至天明云尚未开凡食分时刻皆无凭</span>  
<span style="margin-left: 3em">测验理合</span>  
<span style="margin-left: 2em">奏</span>  
<span style="margin-left: 1em">闻谨</span>  
<span style="margin-left: 2em">题</span>  
<span style="margin-left: 3em">崇祯五年九月十五日具　十八日奉</span>  
<span style="margin-left: 1em">圣旨朕知道了</span>  
<span style="margin-left: 8em">崇祯五年十月十一日徐光启奏本</span>  
<span style="margin-left: 3em">礼部尚书兼东阁大学士臣徐光启谨</span>  
<span style="margin-left: 2em">奏为月食事本年九月十五日臣奉</span>  
<span style="margin-left: 1em">旨前往历局测候月食自卯初至日出时俱云阴不见</span>  
<span style="margin-left: 3em">随于本日具揭回</span>  
<span style="margin-left: 2em">奏十八日奉</span>  
<span style="margin-left: 1em">圣旨朕知道了钦此又本日该钦天监一本为观候事</span>  
<span style="margin-left: 3em">二十一日奉</span>  
<span style="margin-left: 1em">圣旨月食据灵台官奏卯初一刻初亏忽遇薄云渐布</span>  
<span style="margin-left: 3em">该监径称云阴不见何故异同其食时先后各法</span>  
<span style="margin-left: 3em">不一也著奏明礼部知道钦此案照先时推步本</span>  
<span style="margin-left: 3em">食据钦天监灵台官俱依郭守敬授时历法初亏</span>  
<span style="margin-left: 3em">在卯初一刻臣等译譔新法初亏在卯初三刻回</span>  
<span style="margin-left: 3em">回历初亏在辰初初刻三法之不同如此至期测</span>  
<span style="margin-left: 3em">候正欲借以辨其离合合则据为准式离则尚费</span>  
<span style="margin-left: 3em">推求不意候至卯初一刻遂有阴云迄于天明未</span>  
<span style="margin-left: 3em">见开朗诸法是非无从徴验该灵台官言先有薄</span>  
<span style="margin-left: 3em">云后见浓云该监言云阴不见灵台语意稍详而</span>  
<span style="margin-left: 3em">云阴不见亦历书成语略有异同其实一也迨奉</span>  
<span style="margin-left: 1em">明旨该监已经呈部覆</span>  
<span style="margin-left: 2em">奏但三法不同之因则历科官生专谙旧法其习学</span>  
<span style="margin-left: 3em">新法时日未久未能一一究明臣不得不代陈之</span>  
<span style="margin-left: 3em">盖闻交食之法先求平朔望平朔望之算起于历</span>  
<span style="margin-left: 3em">元今历法本用元授时历以至元辛巳为历元当</span>  
<span style="margin-left: 3em">时所立四应稍有未合臣等新法以崇祯元年戊</span>  
<span style="margin-left: 3em">辰为历元两者相提已推得旧法后天六十五分</span>  
<span style="margin-left: 3em">为半刻有奇矣既得平朔望以求定朔望定朔望</span>  
<span style="margin-left: 3em">即日月之食甚定分也法以日躔盈缩月转迟疾</span>  
<span style="margin-left: 3em">推其各差又以两差之较为加减时差用以加减</span>  
<span style="margin-left: 3em">于平数得定数焉昨九月十四日夜望则太阳在</span>  
<span style="margin-left: 3em">缩历而授时法缩历起夏至不知日有最高有夏</span>  
<span style="margin-left: 3em">至两行异法缩历宜从最高起算也惟宋绍兴年</span>  
<span style="margin-left: 3em">间两行同度郭守敬后此百年去离仅一度有奇</span>  
<span style="margin-left: 3em">故未及觉今最高一行已在夏至后六日有奇以</span>  
<span style="margin-left: 3em">推缩差则旧法后天一十八分有奇也是日太阴</span>  
<span style="margin-left: 3em">在疾历迟疾之法授时止论一转周新法谓之自</span>  
<span style="margin-left: 3em">行轮月自行之外又有两次轮以次密推则旧法</span>  
<span style="margin-left: 3em">疾历先天二度有奇以推疾差又后天四十分也</span>  
<span style="margin-left: 3em">次以缩疾两差相较变为时而求定望宜用减法</span>  
<span style="margin-left: 3em">旧法则一推而得四十八刻九十分新法再推先</span>  
<span style="margin-left: 3em">得四十一刻一十三分有奇次得四十四刻八分</span>  
<span style="margin-left: 3em">两得相较又差三刻弱故旧法之食甚定分得二</span>  
<span style="margin-left: 3em">十八刻弱新法得三十刻弱以推初亏则旧法得</span>  
<span style="margin-left: 3em">在子正后二十二刻二十二分为卯初一刻新法</span>  
<span style="margin-left: 3em">得在子正后二十三刻五十九分为卯初三刻此</span>  
<span style="margin-left: 3em">旧法与新法异同之因也若回回历又异二法者</span>  
<span style="margin-left: 3em">臣等实未能尽晓其故仅知彼历元为阿剌必年</span>  
<span style="margin-left: 3em">与隋开皇相值去今一千三十余载矣年远数殊</span>  
<span style="margin-left: 3em">意其平朔望亦未合也即以减分论则是日太阳</span>  
<span style="margin-left: 3em">缩历在四宫一度依彼法得缩差一度四十一分</span>  
<span style="margin-left: 3em">新法得一度四十三分其差二分太阴疾历在十</span>  
<span style="margin-left: 3em">宫十七度依彼法得疾差二度一十九分半新法</span>  
<span style="margin-left: 3em">得三度六分其差一十三分半两差相并得十五</span>  
<span style="margin-left: 3em">分半变为时约彼法在新法后四刻今差五刻者</span>  
<span style="margin-left: 3em">意其缘正在历元四应否则创法之处距西一万</span>  
<span style="margin-left: 3em">余里或里差又未合也总之三家所报各依其本</span>  
<span style="margin-left: 3em">法展转推求乃始得之不能立异以相畸亦不能</span>  
<span style="margin-left: 3em">中变以相就必欲辨其疎密则在临食之时实测</span>  
<span style="margin-left: 3em">实验而已今已往之事无复可论将来准法似须</span>  
<span style="margin-left: 3em">商求所宜求者盖有二端其一曰食分多寡按交</span>  
<span style="margin-left: 3em">食法中不惟推步为难并较验亦复未易臣前疏</span>  
<span style="margin-left: 3em">尝言日食时阳晶晃耀每先食而后见月食时游</span>  
<span style="margin-left: 3em">气纷侵每先见而后食盖食者二体相交之谓也</span>  
<span style="margin-left: 3em">日食既交因其大光人目未见必至一分以上乃</span>  
<span style="margin-left: 3em">得见之月食未交暗虚之旁先有黑影侵入于月</span>  
<span style="margin-left: 3em">及其体交反无界限故推步纵无舛谬而较验多</span>  
<span style="margin-left: 3em">任目任意揣摹影响不能灼见分数以证原推得</span>  
<span style="margin-left: 3em">失亦无繇知如宋臣周琮所定差天一分以下为</span>  
<span style="margin-left: 3em">亲二分以下为近三分以下为远非苟自恕盖其</span>  
<span style="margin-left: 3em">术止此而已今欲灼见实分有近造闚筩新法日</span>  
<span style="margin-left: 3em">食时用于密室中取其光影映照尺素之上自初</span>  
<span style="margin-left: 3em">亏至复圆所见分数界限真确画然不爽月食不</span>  
<span style="margin-left: 3em">能定其分秒之限然二体离合之际鄞鄂著明中</span>  
<span style="margin-left: 3em">间色象亦与目测逈异此定分法也其一曰加时</span>  
<span style="margin-left: 3em">早晚定时之术相传有壶漏为古法近有轮钟为</span>  
<span style="margin-left: 3em">简法然而调品皆繇人力迁就可凭人意故不如</span>  
<span style="margin-left: 3em">求端于日星昼则用日夜则任用一星皆以仪器</span>  
<span style="margin-left: 3em">测取经纬度数推算得之是为本法其验之则测</span>  
<span style="margin-left: 3em">日有平晷新法测星有立晷新法皆砻石范铜镵</span>  
<span style="margin-left: 3em">画数度节气时刻一一分明以之较论交食皆于</span>  
<span style="margin-left: 3em">本晷之上某时某刻先期注定至时徴验是合是</span>  
<span style="margin-left: 3em">离灼然易见此定时法也二法既立一遇交食凡</span>  
<span style="margin-left: 3em">古今诸术得失疎密如明镜高悬妍𡟎莫遁矣然</span>  
<span style="margin-left: 3em">而台官之情甚以此为苦何者彼之本法有时先</span>  
<span style="margin-left: 3em">后天一二刻或四五刻自以为差天至此不免于</span>  
<span style="margin-left: 3em">罪戾故耳以臣论之台官之历郭守敬之历也守</span>  
<span style="margin-left: 3em">敬之法今日之所谓差当时之所谓密也臣尝历</span>  
<span style="margin-left: 3em">考古今疎密之致矣月食诸史不载所载日食自</span>  
<span style="margin-left: 3em">汉至隋凡二百九十三而食于晦日者七十七晦</span>  
<span style="margin-left: 3em">前一日者三初二日者三其疎如此唐至五代凡</span>  
<span style="margin-left: 3em">一百一十而食于晦日者一初二日者一初三日</span>  
<span style="margin-left: 3em">者一稍密矣宋凡一百四十八则无晦食更密矣</span>  
<span style="margin-left: 3em">犹有推食而不食者十三元凡四十五亦无晦食</span>  
<span style="margin-left: 3em">犹有推食而不食者一食而失推者一夜食而书</span>  
<span style="margin-left: 3em">昼者一至加时先后至四五刻者当其时已然至</span>  
<span style="margin-left: 3em">今遵用安能免此乃守敬之法三百年来世共归</span>  
<span style="margin-left: 3em">推以为度越前代何也高远无穷之事必积时累</span>  
<span style="margin-left: 3em">世乃稍见其端倪故汉至今千五百岁立法者仅</span>  
<span style="margin-left: 3em">十有三家盖于数十百年间一较工拙非一人之</span>  
<span style="margin-left: 3em">心思智力所能黾勉者也守敬集前古之大成加</span>  
<span style="margin-left: 3em">以精思广测故所差仅四五刻比于前代洵为密</span>  
<span style="margin-left: 3em">矣若使守敬复生今世欲更求精密计非苦心竭</span>  
<span style="margin-left: 3em">力假以数年恐未易得何可责于沿袭旧法如诸</span>  
<span style="margin-left: 3em">台臣者乎今食分加时并如臣等新法较勘则差</span>  
<span style="margin-left: 3em">殊毕露傥遂以此为诸臣罪能无惶怖能无畏葸</span>  
<span style="margin-left: 3em">然而实非彼罪即加之谴责亦付之无可奈何而</span>  
<span style="margin-left: 3em">已事有非力所及者亦古法所必寛也岂惟诸臣</span>  
<span style="margin-left: 3em">即臣等新法遂成似可悉无前代之误乃食限或</span>  
<span style="margin-left: 3em">差半分上下加时或差半刻上下虑所不免惟是</span>  
<span style="margin-left: 3em">臣等不敢以差自安亦不敢以差自废正须缘此</span>  
<span style="margin-left: 3em">微差溯厥因起别求新意据理改定臣所惧者诸</span>  
<span style="margin-left: 3em">臣以惶恐畏咎之心坚其安习溺闻之陋臣等书</span>  
<span style="margin-left: 3em">虽告成而愿学者少有倡无和有传无习恐他日</span>  
<span style="margin-left: 3em">终成废阁耳伏望</span>  
<span style="margin-left: 1em">圣明察其从前之失实非繇已开其向往之路嘉与图</span>  
<span style="margin-left: 3em">新即有疎远且勿遽加罪谴但令陈说所以然之</span>  
<span style="margin-left: 3em">故有能精习透晓者量加优异久而不谙罚亦随</span>  
<span style="margin-left: 3em">之将必有翘然杰出明羲和之大业应唐虞之</span>  
<span style="margin-left: 1em">景运者矣若日晷星晷闚筩三器者局中所用体制甚</span>  
<span style="margin-left: 3em">小工作尤粗傥须上尘</span>  
<span style="margin-left: 1em">圣览则模式应加广长赋列应加精赡其费亦不过数</span>  
<span style="margin-left: 3em">十金耳如蒙</span>  
<span style="margin-left: 1em">赐俞容臣等仰遵前</span>  
<span style="margin-left: 1em">旨仍于户工二部事例银内咨取令在局诸臣募工备</span>  
<span style="margin-left: 3em">料造成恭</span>
