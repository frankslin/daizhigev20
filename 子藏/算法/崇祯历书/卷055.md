<span style="margin-left: 11em">古松庠生陸昌𧃆　校梓</span>  
<span style="margin-left: 1em">　<sub class="note-jiao">校：校諱作較今改清刊本署名不同錄之於左</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">西洋新法曆書法原部明禮部尚書兼翰林院學士協理詹事府事加俸一級</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">徐光啓督修</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">　　　　　　　　　　　　　　　　　　　　祝懋元　宋光顯　　　　羅雅谷　譔　　</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">修政曆法極西耶穌會士門人陸昌𧃆　劉有慶　受法　　　　　　　　　　　湯若望訂</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">　　　　　　　　　　　　　　　　　　　　朱國壽宋可成</sub></span>  
<span style="margin-left: 1em">曆指第六卷　　月離二</span>  
<span style="margin-left: 2em">解第二均數第十</span>  
<span style="margin-left: 1em">如上論因月有本輪自行度以致不平不順定朔定望</span>  
<span style="margin-left: 2em">多寡不一今用其自行度分加減其平行視行以定</span>  
<span style="margin-left: 2em">均數則于定朔定望及交食之法始無遺漏乃曆家</span>  
<span style="margin-left: 2em">詳測密推以爲未足盡月行之理故又立次輪一法</span>  
<span style="margin-left: 2em">以定均數與本輪第一均數並用之今解其義如左</span>  
<span style="margin-left: 1em">古今測月行審有自行度與平行不合立爲本輪法<sub class="note-yuan">或不</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">同心</sub>與自行加減以定朔望以正交食然其朔望之極</span>  
<span style="margin-left: 2em">大差不過五度此本輪之半徑也是知定朔定望時</span>  
<span style="margin-left: 2em">太陰恆在本輪之周矣其在上下弦之差則不然古</span>  
<span style="margin-left: 2em">曆於上下弦日推太陰自行本輪之二限四限<sub class="note-yuan">左右兩傍</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">之盡處所謂留際也如此則爲去最高之極大差</sub>又在黃道之九十度限<sub class="note-yuan">一名</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">黃平象限如此則無東西視差</sub>以定本日之經度若如本輪法則此</span>  
<span style="margin-left: 2em">差止應得爲五度及用圓渾儀測候或以距太陽求</span>  
<span style="margin-left: 2em">月之視行經度或以恆星求其黃道上之視經度得</span>  
<span style="margin-left: 2em">數乃與先推殊不合論推算宜得五度論測度則得</span>  
<span style="margin-left: 2em">七度四十分從古至今累測皆如之又測弦前後若</span>  
<span style="margin-left: 2em">干日亦與推算不合每日遠近所差不等知月行止</span>  
<span style="margin-left: 2em">定朔定望日在小輪周餘日去離遠近多寡各有本</span>  
<span style="margin-left: 2em">行度分因從其差數以立差法仍定本輪周上復有</span>  
<span style="margin-left: 2em">次小一輪循本輪右旋<sub class="note-yuan">與七政行同與自行異</sub>半月一周因其</span>  
<span style="margin-left: 2em">行度作加減差以定第二均數列表<sub class="note-yuan">如後卷</sub></span>  
<span style="margin-left: 2em">求次輪之比例第十一</span>  
<span style="margin-left: 1em">既論有次小輪今論其大小以定加減率</span>  
<span style="margin-left: 12em">如圖丁爲地心庚爲本輪</span>  
<span style="margin-left: 12em">心甲乙丙爲本輪周作庚</span>  
<span style="margin-left: 12em">丁過心線作本輪之丁甲</span>  
<span style="margin-left: 2em">切線即庚丁甲爲五度角<sub class="note-yuan">視行平行之極大差</sub>朔望時次作庚</span>  
<span style="margin-left: 2em">甲戊線作丁戊線成庚丁戊角爲七度四十〇分視</span>  
<span style="margin-left: 2em">平兩行上弦下弦之大差次庚爲心戊爲界作戊己</span>  
<span style="margin-left: 2em">圈太陰在定朔定望時必循甲乙丙本輪周左行在</span>  
<span style="margin-left: 2em">兩弦時必循戊己周左行兩弦<sub class="note-jiao">校：兩弦原作而弦據文淵本改</sub>前後</span>  
<span style="margin-left: 12em">半月間則自甲向戊戊向</span>  
<span style="margin-left: 12em">甲右旋爲次輪之自行若</span>  
<span style="margin-left: 12em">庚丁線爲一萬全數即庚</span>  
<span style="margin-left: 2em">甲爲八百七十二<sub class="note-yuan">五度之正弦</sub>庚戊爲一千三百三十四</span>  
<span style="margin-left: 2em"><sub class="note-yuan">七度四十分之正弦</sub>相減得甲戊四百六十三甲戊線平分于</span>  
<span style="margin-left: 2em">辛庚爲心辛爲界作辛壬爲負次輪圈<sub class="note-yuan">一曰帶次輪</sub>即甲</span>  
<span style="margin-left: 2em">辛爲二百三十一以并庚甲得庚辛一千一百〇三</span>  
<span style="margin-left: 2em">爲負次輪辛癸圈之半徑則本輪次輪兩半徑爲一</span>  
<span style="margin-left: 2em">一〇三與二三一也</span>  
<span style="margin-left: 2em">系有二小輪之比例可解前一推一測異同之極大</span>  
<span style="margin-left: 2em">差又可推朔望前後之視行疑於無法而實有法<sub class="note-yuan">朔望</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">前後三十八度其視行絕異故云疑於無法詳後論</sub></span>  
<span style="margin-left: 1em">如圖兩圈爲本次二輪丁爲地心甲爲本輪之最高丙</span>  
<span style="margin-left: 13em">爲其心乙爲次輪心作</span>  
<span style="margin-left: 13em">丙乙線爲一一〇三從</span>  
<span style="margin-left: 13em">乙心作次輪圈其半徑</span>  
<span style="margin-left: 2em">二三一<sub class="note-yuan">如上兩輪之比例</sub>次從丙作丙戊丙子線切次輪於</span>  
<span style="margin-left: 2em">戊於子成戊子兩直角設月體在戊今論之</span>  
<span style="margin-left: 1em">凡月行本輪周左旋<sub class="note-yuan">依宗動天自東而西</sub>如圖庚爲本輪心甲乙</span>  
<span style="margin-left: 2em">爲白道丁爲最高己爲最庳其平行則自甲向丙庚</span>  
<span style="margin-left: 5em">至乙其自行則自丁而丙而己而戊而復于</span>  
<span style="margin-left: 5em">丁從丁<sub class="note-yuan">即正半轉即最高</sub>入轉行極遲向丙<sub class="note-yuan">即中轉亦留際</sub></span>  
<span style="margin-left: 5em">其遲日損至丙而及平行度謂之遲初限從</span>  
<span style="margin-left: 2em">丙向己<sub class="note-yuan">即中半轉即最庳</sub>遲損疾益至己而極疾謂之遲末</span>  
<span style="margin-left: 2em">限從己向戊<sub class="note-yuan">即正轉亦留際</sub>其疾日損至戊而及平行度謂</span>  
<span style="margin-left: 2em">之疾初限從戊而復向丁疾損遲益至丁而極遲謂</span>  
<span style="margin-left: 2em">之疾末限最高左右二限謂之遲曆逆經度行<sub class="note-yuan">逆七政經</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">度也後省曰逆行</sub>最庳左右二限謂之疾曆順經度行<sub class="note-yuan">後省曰順</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">行</sub>二十七日有奇而周<sub class="note-yuan">即轉周</sub>若次輪則如圖乙爲其</span>  
<span style="margin-left: 2em">心甲己爲本輪周壬戊癸子爲次輪周壬爲最近癸</span>  
<span style="margin-left: 5em">爲其最遠<sub class="note-yuan">本輪可言高庳次輪不得言高庳故言遠近謂遠近于本輪心</sub>其</span>  
<span style="margin-left: 5em">順本輪左旋則自甲向己其自行右旋<sub class="note-yuan">如七政自</sub></span>  
<span style="margin-left: 5em"><sub class="note-yuan">西而東</sub>則自壬而戊而癸而子而復于壬從壬</span>  
<span style="margin-left: 2em">入轉至戊爲遲初限從戊至癸爲遲末限從癸至子</span>  
<span style="margin-left: 2em">爲疾初限從子至壬爲疾末限最近左右二限爲遲</span>  
<span style="margin-left: 2em">曆逆行最遠左右二限爲疾曆順行十五日弱而周</span>  
<span style="margin-left: 2em">謂之次轉周</span>  
<span style="margin-left: 1em">夫甲己弧者約太陰距太陽之半周也<sub class="note-yuan">朔與望相距之一百八十度</sub></span>  
<span style="margin-left: 2em">次輪心行甲己半周則月循次輪行滿一周是月體</span>  
<span style="margin-left: 2em">循本輪周行一度即循次輪周行二度次輪心從甲</span>  
<span style="margin-left: 6em">至乙月從壬至戊比本輪上之兩行皆在</span>  
<span style="margin-left: 6em">遲曆皆逆行一至戊切點則爲逆行之末</span>  
<span style="margin-left: 6em">順行之始順行則始疾故戊切點爲月行</span>  
<span style="margin-left: 2em">次輪順逆兩行之大差今以數明之</span>  
<span style="margin-left: 1em">作乙戊線爲切線之垂線成乙戊丙形戊爲直角此形</span>  
<span style="margin-left: 9em">有乙戊二三一有乙丙一一〇二</span>  
<span style="margin-left: 9em">求丙角得一十二度二十八分爲</span>  
<span style="margin-left: 9em">次輪上月行之最大差是本輪心</span>  
<span style="margin-left: 9em">行度<sub class="note-yuan">甲乙</sub>外應加應減之數乙丙戊</span>  
<span style="margin-left: 9em">角既一十二度二十八分戊乙丙</span>  
<span style="margin-left: 2em">角必七十七度三十二分壬戊弧也半之得二十八</span>  
<span style="margin-left: 2em">度四十六分爲甲乙弧<sub class="note-yuan">甲乙爲壬戊之半</sub></span>  
<span style="margin-left: 2em">系凡次輪心距本輪最高三十八度爲大差之限朔</span>  
<span style="margin-left: 2em">望前後各等</span>  
<span style="margin-left: 2em">論太陰次輪異名同理第十二</span>  
<span style="margin-left: 1em">前卷推月不平行之緣爲有本輪次輪因立兩均數以</span>  
<span style="margin-left: 2em">定其實行<sub class="note-yuan">此歌白泥術</sub>而首卷又有異名同理一章<sub class="note-yuan">第五</sub>言</span>  
<span style="margin-left: 2em">用不同心圈立法得數不異是則止論本輪未及次</span>  
<span style="margin-left: 2em">輪也今并論兩小輪與兩不同心圈亦復異名同理</span>  
<span style="margin-left: 2em">得數無二<sub class="note-yuan">比馬日諾術</sub>如左</span>  
<span style="margin-left: 2em">如圖是月本天之大圈平面也本天中函有諸球體</span>  
<span style="margin-left: 2em">有厚薄行有順逆遲速此圖平面亦函有諸圈譬猶</span>  
<span style="margin-left: 2em">剖球爲面其中所有一一具見矣內外凡六圈甲爲</span>  
<span style="margin-left: 2em">地心亦爲月本天之心外第一圈爲黃道平分十二</span>  
<span style="margin-left: 10em">宫次圈爲交道<sub class="note-yuan">黃白經度畧等</sub>己見前</span>  
<span style="margin-left: 10em">解第二第六總名爲負太陰中</span>  
<span style="margin-left: 10em">距之天其第二之外規面第六</span>  
<span style="margin-left: 10em">之內規面則與地同心<sub class="note-yuan">甲也</sub>其第</span>  
<span style="margin-left: 10em">二之內規面第六之外規面則</span>  
<span style="margin-left: 10em">與地不同心而以中距之心爲</span>  
<span style="margin-left: 2em">心兩天各有厚薄不等其厚薄處恆相反相對<sub class="note-yuan">此二天同</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">一色繪之</sub></span>  
<span style="margin-left: 2em">此天平面之外圈斜交于黃道內函月行諸圈爲一</span>  
<span style="margin-left: 2em">體順經度行<sub class="note-yuan">右旋</sub>每日六分四十〇秒五十五微〇六</span>  
<span style="margin-left: 2em">纖八平年三百一十二日有奇而行天一周周行無</span>  
<span style="margin-left: 2em">首尾其起算之界用外規之最薄即本天之最高</span>  
<span style="margin-left: 2em">第三第五總名爲太陰中距天又名爲正不同心天</span>  
<span style="margin-left: 2em"><sub class="note-yuan">上有二面同心此四面不同心</sub>其心爲乙距地心甲以最外規<sub class="note-yuan">丁也</sub>之</span>  
<span style="margin-left: 2em">半徑<sub class="note-yuan">丁甲也</sub>爲度十分之約得一有半爲乙甲求其厚</span>  
<span style="margin-left: 2em">得丁甲十五分之四爲丁戊此天內函月行之軌道</span>  
<span style="margin-left: 2em">爲一體順經度行<sub class="note-yuan">右旋</sub>其外雖爲負距天所挈一體順</span>  
<span style="margin-left: 2em">行又自有其行度每日二十四度二十二分五十三</span>  
<span style="margin-left: 2em">秒有奇凡一十四日七十三刻〇七分有奇而行天</span>  
<span style="margin-left: 2em">一周<sub class="note-yuan">在歌白泥法爲次輪上月行之周</sub>其起算之界爲最近地心之</span>  
<span style="margin-left: 10em">處<sub class="note-yuan">已也如上次輪法</sub>本表目其本行度</span>  
<span style="margin-left: 10em">爲日月相距之倍度是爲次引</span>  
<span style="margin-left: 10em">數凡月朔望間必行一周故朔</span>  
<span style="margin-left: 10em">望時月恆在于最近即無此圈</span>  
<span style="margin-left: 10em">行度亦不用次均數皆與前法</span>  
<span style="margin-left: 10em">所論次輪同理此圈又名爲引</span>  
<span style="margin-left: 2em">數之圈以其函負月軌圈爲定均數之根</span>  
<span style="margin-left: 2em">第四名爲月軌圈蓋太陰自行之軌道也與第三第</span>  
<span style="margin-left: 2em">五正不同心之天又不同心其心丙故又名次不同</span>  
<span style="margin-left: 2em">心之天乙丙兩心相距以中距天<sub class="note-yuan">即第三第五</sub>之全徑<sub class="note-yuan">外規</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">過心相距</sub>爲度六十平分之得其一分半弱</span>  
<span style="margin-left: 2em">次不同心之心丙旋遶正不同心之心乙作一小圈</span>  
<span style="margin-left: 2em">月體循第四天行雖最外爲負距天所挈一體順行</span>  
<span style="margin-left: 2em">又爲中距天所挈一體順行其自行則又逆經度左</span>  
<span style="margin-left: 2em">旋譬之負距天如流水中距天如舟月體如人水自</span>  
<span style="margin-left: 2em">順地勢東行有水之行度舟亦順水勢東行又自有</span>  
<span style="margin-left: 2em">舟之行度人却從船首向船尾西行又自有人之行</span>  
<span style="margin-left: 2em">度也其起算以自天之最高爲界日逆行一十一度</span>  
<span style="margin-left: 2em">一十八分五十九秒有奇三十一日七十八刻有奇</span>  
<span style="margin-left: 2em">而行天一周其在前解則自行本輪也</span>  
<span style="margin-left: 2em">前解定次輪上<sub class="note-yuan">或正不同心圈理同</sub>太陰一日順行二十四度</span>  
<span style="margin-left: 2em">有奇今減本輪上<sub class="note-yuan">或次不同心圈理同</sub>逆行一十一度一十八</span>  
<span style="margin-left: 2em">分有奇餘一十三度〇三分有奇因兩行相背故相</span>  
<span style="margin-left: 2em">減所得較數爲前引數</span>  
<span style="margin-left: 2em">兩不同心圈各有最高最庳<sub class="note-yuan">前解在次輪者爲最遠最近此解亦名最高最</sub></span>
