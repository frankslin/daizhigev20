## 崇禎曆書卷之一百六十二　渾天儀說卷二

<span style="margin-left: 3em">渾天儀卷二目錄</span>  
<span style="margin-left: 1em">前以天行之效顯儀之理此復依天行之法晰儀之用</span>  
<span style="margin-left: 2em">大端以求三曜<sub class="note-yuan">日月星</sub>爲要領矣至分論之或依本行</span>  
<span style="margin-left: 2em">與黃赤二道相較彼此得經緯度或依宗動之行與</span>  
<span style="margin-left: 2em">地平天頂及子午等圈相較求諸曜出沒之時又或</span>  
<span style="margin-left: 2em">依方位地平高度彼此相較求星距太陽遠近與出</span>  
<span style="margin-left: 2em">沒之先後伏見之期限總于本儀得全用焉但恆星</span>

<span style="margin-left: 3em">安儀</span>  
<span style="margin-left: 1em">凡測天諸儀有黃赤道等圈必以本圈正合天上所有</span>  
<span style="margin-left: 2em">之圈爲準如在天有過頂者儀中相當圈宜竪立以</span>  
<span style="margin-left: 2em">應之有距頂向南北東西者儀中相當之圈亦宜向</span>  
<span style="margin-left: 2em">南北或東西地平皆與天上之圈合則日月諸星行</span>  
<span style="margin-left: 2em">度爲儀圈所得者即天上諸曜實行之度分也今渾</span>  
<span style="margin-left: 2em">儀雖未盡乎測天然能以日景考查時刻並求各方</span>  
<span style="margin-left: 2em">北極出地之度及太陽高弧距地平等用則必一切</span>  
<span style="margin-left: 2em">方位與天脗合先以兩極依出地度安定徐以羅針</span>  
<span style="margin-left: 2em">所得正其南北又以垂線取準地平任置臺几之上</span>  
<span style="margin-left: 2em">以聽次第用焉</span>  
<span style="margin-left: 3em">求北極出地度</span>  
<span style="margin-left: 1em">北極高庳隨地東西同南北不一此乃晝夜長短寒暑</span>  
<span style="margin-left: 2em">異同日月諸曜距天頂遠近之所繇也法先將本儀</span>  
<span style="margin-left: 2em">取準地平考正南北隨以游表于黃道上定住太陽</span>  
<span style="margin-left: 2em">本日躔度轉儀切子午圈正面候太陽當正午之時</span>  
<span style="margin-left: 2em">視表周無景即本北極高度已定而極高之度必爲</span>  
<span style="margin-left: 2em">子午圈自地平至極中之弧也若表尚射景漸運子</span>  
<span style="margin-left: 2em">午圈于架內或上或下展轉那移至表無景乃止而</span>  
<span style="margin-left: 2em">因以得北極出地之度</span>  
<span style="margin-left: 2em">或先設象限等器于正午時測定太陽出地平高度</span>  
<span style="margin-left: 2em">次于本儀黃道上查取本日太陽躔度置子午圈正</span>  
<span style="margin-left: 2em">面下隨運儀令自地平至躔度間子午圈之弧與前</span>  
<span style="margin-left: 2em">所測之度等則自北極至地平度分即本北極出地</span>  
<span style="margin-left: 2em">度分或不候午正即將游表置太陽本躔度與時盤</span>  
<span style="margin-left: 2em">午正初刻正對子午圈後用日晷等器測定時刻以</span>  
<span style="margin-left: 2em">所得時轉儀令居子午圈下後視表無景<sub class="note-yuan">如射景將子午圈上</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">下那移無景乃止</sub>則子午圈自地平至極中之弧亦準可得</span>  
<span style="margin-left: 2em">本北極高度</span>  
<span style="margin-left: 2em">或以星求之即近極諸星中<sub class="note-yuan">因恆不沒</sub>任測一星先于最</span>  
<span style="margin-left: 2em">庳處識所測高度待旋至最高處復測之所得高度</span>  
<span style="margin-left: 2em">加前測之度總而半之爲本北極高度此常法也今</span>  
<span style="margin-left: 2em">不拘出沒或距極遠近之星一測其至天中之高<sub class="note-yuan">另用</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">一器</sub>即轉球<sub class="note-yuan">天球</sub>令本星居子午圈下較儀上地平與前</span>  
<span style="margin-left: 2em">所測等則本儀北極亦自距地平爲弧因得本方北</span>  
<span style="margin-left: 2em">極高度或依所測天中星高度即球上查其本星之</span>  
<span style="margin-left: 2em">赤道緯以加<sub class="note-yuan">距南用加</sub>減<sub class="note-yuan">距北用減</sub>于至中之高度得本赤道</span>  
<span style="margin-left: 2em">高因得本北極高度如測大角高七十一度球上查</span>  
<span style="margin-left: 2em">緯得距北二十一度宜高度內減之<sub class="note-yuan">因距北故</sub>存五十度</span>  
<span style="margin-left: 2em">爲赤道高應四十度爲順天府北極出地高度</span>  
<span style="margin-left: 3em">求太陽躔度</span>  
<span style="margin-left: 1em">太陽依黃道右旋每日約行一度謂之躔度法先依本</span>  
<span style="margin-left: 2em">北極出地高令地平與子午圈如法安置候午正初</span>  
<span style="margin-left: 2em">刻將遊表以直角切子午圈上下試之遇表無射景</span>  
<span style="margin-left: 2em">乃止轉儀視黃道正居表下之度即太陽本日所躔</span>  
<span style="margin-left: 2em">度</span>  
<span style="margin-left: 2em">又一法用象限等儀測太陽距赤道度因得其距南</span>  
<span style="margin-left: 2em">或北隨于本儀子午圈上點定作識乃令全儀運轉</span>  
<span style="margin-left: 2em">視黃道度正交其點即本日太陽躔度但距赤道等</span>  
<span style="margin-left: 2em">度與子午圈相交之點黃道可有二處必依晝漸長</span>  
<span style="margin-left: 2em">或短求之即得其度在冬夏至之前或後也假如崇</span>  
<span style="margin-left: 2em">禎七年七月初八日壬申曆局午正測得太陽高六</span>  
<span style="margin-left: 2em">十八度一十五分因得距赤道北一十八度一十分</span>  
<span style="margin-left: 2em"><sub class="note-yuan">北極高三十九度五十五分即赤道高五十度〇五分</sub>依之作識得大梁宮二</span>  
<span style="margin-left: 2em">十一度或鶉火宮九度俱與所識點相交第此時夏</span>  
<span style="margin-left: 2em">至已過晝漸短即知所得必爲鶉火宮度</span>  
<span style="margin-left: 3em">求恆星黃道經緯度</span>  
<span style="margin-left: 1em">恆星較黃道有經有緯而共以黃極爲主必依黃道右</span>  
<span style="margin-left: 2em">行任從冬至或春分起算爲之經本道南北爲緯法</span>  
<span style="margin-left: 2em">以高弧切球上使從黃極過星所至經度即本星之</span>  
<span style="margin-left: 2em">黃經度所居黃道上及星間之弧即黃緯度但星距</span>  
<span style="margin-left: 2em">北必高弧安之黃北極星距南高弧亦安黃南極如</span>  
<span style="margin-left: 2em">貫索大星距黃道北以高弧從黃北極過本星視至</span>  
<span style="margin-left: 2em">大火宮六度有奇即貫索大星之黃經度又自黃道</span>  
<span style="margin-left: 2em">北至本星處約得四十四度三十分即其黃緯度也</span>  
<span style="margin-left: 2em">若先得星黃經緯度欲查球上星所當在之處亦用</span>  
<span style="margin-left: 2em">高弧依球上本星黃經度因之安高弧初度令末度</span>  
<span style="margin-left: 2em">至黃極中<sub class="note-yuan">黃極南北依星距南或北</sub>任黃道內外順高弧數星緯</span>  
<span style="margin-left: 2em">度所止之點即星居球上之處假如崇禎元年測定</span>  
<span style="margin-left: 2em">心宿中星在黃道析木宮四度三十六分距南四度</span>  
<span style="margin-left: 2em">二十七分依此度分安高弧至南黃極從球上黃道</span>  
<span style="margin-left: 2em">數起得本距度之限即心宿中星所居之處</span>  
<span style="margin-left: 3em">求太陽赤經緯</span>  
<span style="margin-left: 1em">太陽依黃道行近考定冬夏二至距赤道南北最遠之</span>  
<span style="margin-left: 2em">處爲二十三度三十一分三十秒迨二至前後每日</span>  
<span style="margin-left: 2em">相距不等而二道又以斜交惟分至之點彼此得同</span>  
<span style="margin-left: 2em">經餘俱不得合一也今求緯度法令本儀轉任取黃</span>  
<span style="margin-left: 2em">道若干度正合子午圈下即于本子午圈視兩道間</span>  
<span style="margin-left: 2em">所容之弧得數即黃赤相距之緯也求經度亦任取</span>  
<span style="margin-left: 2em">春分或冬至起算視黃道度在子午圈爲限順數其</span>  
<span style="margin-left: 2em">赤道圈之度即黃道上之赤經度若依地平求之必</span>  
<span style="margin-left: 2em">先安儀使兩極與本地平齊即用地平當子午圈則</span>  
<span style="margin-left: 2em">赤經弧必過赤極與赤道以直角相交而東西所限</span>  
<span style="margin-left: 2em">赤緯弧亦爲本圈南北所量雖子午圈本當過極諸</span>  
<span style="margin-left: 2em">圈與赤道正球相交而地平與正球亦不異是故所</span>  
<span style="margin-left: 2em">指度分即得赤道經緯度分</span>  
<span style="margin-left: 3em">求恆星赤經緯</span>  
<span style="margin-left: 1em">法以赤極爲準必順十二宮爲經赤道南北爲緯先轉</span>  
<span style="margin-left: 2em">其球以所求星切子午圈下後視赤道是何度分此</span>  
<span style="margin-left: 2em">即本星赤經度又視赤道與星在子午圈上所開之</span>  
<span style="margin-left: 2em">弧容何度分乃其星之赤緯度如設狼星居子午圈</span>  
<span style="margin-left: 2em">得本圈下赤道度自夏至起算約七度三十分即狼</span>  
<span style="margin-left: 2em">星赤經度分又赤道南距狼星一十六度乃即本星</span>  
<span style="margin-left: 2em">之赤緯度求五星赤經緯法與同但先以黃經緯點</span>  
<span style="margin-left: 2em">星于球上如法使高弧自黃極中至黃道本經度過</span>  
<span style="margin-left: 2em">星處即依高弧之黃緯點球作識後轉球令其點合</span>  
<span style="margin-left: 2em">子午圈亦可得赤經緯也若先算定恆星赤經緯于</span>  
<span style="margin-left: 2em">球上考其處即從春分依赤道順查星經度移至子</span>  
<span style="margin-left: 2em">午圈下乃本圈上南或北<sub class="note-yuan">依星距</sub>查其緯度用點作識</span>  
<span style="margin-left: 2em">即其星所居之處也如崇禎元年心宿中星得赤經</span>  
<span style="margin-left: 2em">二百四十一度四十三分以本度分轉球至子午圈</span>  
<span style="margin-left: 2em">因星緯度距南二十五度三十分隨以此度正對子</span>  
<span style="margin-left: 2em">午圈下作點必指其本星之實處</span>  
<span style="margin-left: 3em">求黃道每度赤道緯</span>  
<span style="margin-left: 1em">法任取黃道何度移置子午圈正面即從黃道中線至</span>  
<span style="margin-left: 2em">赤道上視本圈所得若干度爲黃道度之赤道緯<sub class="note-yuan">南或</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">北依所求點得所距</sub>若從北極起算亦於子午圈從極數至所</span>  
<span style="margin-left: 2em">求之點亦是如求清明初度緯得其距赤道北約五</span>  
<span style="margin-left: 2em">度距北極八十五度寒露初度距赤道南約五度距</span>  
<span style="margin-left: 2em">北極九十五度餘俱倣此</span>  
<span style="margin-left: 3em">求黃道各弧出没之時</span>  
<span style="margin-left: 1em">黃道上出沒較赤道圈之出沒恆異蓋赤道等弧或正</span>  
<span style="margin-left: 2em">球斜球<sub class="note-yuan">南北兩極并在地平爲正球一極出地平上一極入地平下爲斜球</sub>所應出入</span>  
<span style="margin-left: 2em">之時恆如一黃道不然遇正出或遲斜出反速每日</span>  
<span style="margin-left: 2em">早晚先後不等隨地有變試以最長之晝其見出止</span>  
<span style="margin-left: 2em">六宮最短之晝亦爲六宮如太陽在鶉首初度<sub class="note-yuan">晝長時</sub></span>  
<span style="margin-left: 2em">任北極高若干使本度切儀東地平漸轉至正午必</span>  
<span style="margin-left: 2em">見壽星初度東出矣復轉至西地平即星紀初度東</span>  
<span style="margin-left: 2em">出縂得黃道半圈爲其所出沒也又如太陽躔星紀</span>  
<span style="margin-left: 2em">初度<sub class="note-yuan">晝短時</sub>在本儀東地平轉至正午爲降婁初度東</span>  
<span style="margin-left: 2em">出至本躔度西入則東出者必鶉首初度本等自早</span>  
<span style="margin-left: 2em">至晚亦得半圈是黃道與地平皆大圈相交必各平</span>
