<span style="margin-left: 3em">安仪</span>  
<span style="margin-left: 1em">凡测天诸仪有黄赤道等圈必以本圈正合天上所有</span>  
<span style="margin-left: 2em">之圈为准如在天有过顶者仪中相当圈宜竖立以</span>  
<span style="margin-left: 2em">应之有距顶向南北东西者仪中相当之圈亦宜向</span>  
<span style="margin-left: 2em">南北或东西地平皆与天上之圈合则日月诸星行</span>  
<span style="margin-left: 2em">度为仪圈所得者即天上诸曜实行之度分也今浑</span>  
<span style="margin-left: 2em">仪虽未尽乎测天然能以日景考查时刻并求各方</span>  
<span style="margin-left: 2em">北极出地之度及太阳高弧距地平等用则必一切</span>  
<span style="margin-left: 2em">方位与天脗合先以两极依出地度安定徐以罗针</span>  
<span style="margin-left: 2em">所得正其南北又以垂线取准地平任置台几之上</span>  
<span style="margin-left: 2em">以听次第用焉</span>  
<span style="margin-left: 3em">求北极出地度</span>  
<span style="margin-left: 1em">北极高庳随地东西同南北不一此乃昼夜长短寒暑</span>  
<span style="margin-left: 2em">异同日月诸曜距天顶远近之所繇也法先将本仪</span>  
<span style="margin-left: 2em">取准地平考正南北随以游表于黄道上定住太阳</span>  
<span style="margin-left: 2em">本日躔度转仪切子午圈正面候太阳当正午之时</span>  
<span style="margin-left: 2em">视表周无景即本北极高度已定而极高之度必为</span>  
<span style="margin-left: 2em">子午圈自地平至极中之弧也若表尚射景渐运子</span>  
<span style="margin-left: 2em">午圈于架内或上或下展转那移至表无景乃止而</span>  
<span style="margin-left: 2em">因以得北极出地之度</span>  
<span style="margin-left: 2em">或先设象限等器于正午时测定太阳出地平高度</span>  
<span style="margin-left: 2em">次于本仪黄道上查取本日太阳躔度置子午圈正</span>  
<span style="margin-left: 2em">面下随运仪令自地平至躔度间子午圈之弧与前</span>  
<span style="margin-left: 2em">所测之度等则自北极至地平度分即本北极出地</span>  
<span style="margin-left: 2em">度分或不候午正即将游表置太阳本躔度与时盘</span>  
<span style="margin-left: 2em">午正初刻正对子午圈后用日晷等器测定时刻以</span>  
<span style="margin-left: 2em">所得时转仪令居子午圈下后视表无景<sub class="note-yuan">如射景将子午圈上</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">下那移无景乃止</sub>则子午圈自地平至极中之弧亦准可得</span>  
<span style="margin-left: 2em">本北极高度</span>  
<span style="margin-left: 2em">或以星求之即近极诸星中<sub class="note-yuan">因恒不没</sub>任测一星先于最</span>  
<span style="margin-left: 2em">庳处识所测高度待旋至最高处复测之所得高度</span>  
<span style="margin-left: 2em">加前测之度总而半之为本北极高度此常法也今</span>  
<span style="margin-left: 2em">不拘出没或距极远近之星一测其至天中之高<sub class="note-yuan">另用</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">一器</sub>即转球<sub class="note-yuan">天球</sub>令本星居子午圈下较仪上地平与前</span>  
<span style="margin-left: 2em">所测等则本仪北极亦自距地平为弧因得本方北</span>  
<span style="margin-left: 2em">极高度或依所测天中星高度即球上查其本星之</span>  
<span style="margin-left: 2em">赤道纬以加<sub class="note-yuan">距南用加</sub>减<sub class="note-yuan">距北用减</sub>于至中之高度得本赤道</span>  
<span style="margin-left: 2em">高因得本北极高度如测大角高七十一度球上查</span>  
<span style="margin-left: 2em">纬得距北二十一度宜高度内减之<sub class="note-yuan">因距北故</sub>存五十度</span>  
<span style="margin-left: 2em">为赤道高应四十度为顺天府北极出地高度</span>  
<span style="margin-left: 3em">求太阳躔度</span>  
<span style="margin-left: 1em">太阳依黄道右旋每日约行一度谓之躔度法先依本</span>  
<span style="margin-left: 2em">北极出地高令地平与子午圈如法安置候午正初</span>  
<span style="margin-left: 2em">刻将游表以直角切子午圈上下试之遇表无射景</span>  
<span style="margin-left: 2em">乃止转仪视黄道正居表下之度即太阳本日所躔</span>  
<span style="margin-left: 2em">度</span>  
<span style="margin-left: 2em">又一法用象限等仪测太阳距赤道度因得其距南</span>  
<span style="margin-left: 2em">或北随于本仪子午圈上点定作识乃令全仪运转</span>  
<span style="margin-left: 2em">视黄道度正交其点即本日太阳躔度但距赤道等</span>  
<span style="margin-left: 2em">度与子午圈相交之点黄道可有二处必依昼渐长</span>  
<span style="margin-left: 2em">或短求之即得其度在冬夏至之前或后也假如崇</span>  
<span style="margin-left: 2em">祯七年七月初八日壬申历局午正测得太阳高六</span>  
<span style="margin-left: 2em">十八度一十五分因得距赤道北一十八度一十分</span>  
<span style="margin-left: 2em"><sub class="note-yuan">北极高三十九度五十五分即赤道高五十度〇五分</sub>依之作识得大梁宫二</span>  
<span style="margin-left: 2em">十一度或鹑火宫九度俱与所识点相交第此时夏</span>  
<span style="margin-left: 2em">至已过昼渐短即知所得必为鹑火宫度</span>  
<span style="margin-left: 3em">求恒星黄道经纬度</span>  
<span style="margin-left: 1em">恒星较黄道有经有纬而共以黄极为主必依黄道右</span>  
<span style="margin-left: 2em">行任从冬至或春分起算为之经本道南北为纬法</span>  
<span style="margin-left: 2em">以高弧切球上使从黄极过星所至经度即本星之</span>  
<span style="margin-left: 2em">黄经度所居黄道上及星间之弧即黄纬度但星距</span>  
<span style="margin-left: 2em">北必高弧安之黄北极星距南高弧亦安黄南极如</span>  
<span style="margin-left: 2em">贯索大星距黄道北以高弧从黄北极过本星视至</span>  
<span style="margin-left: 2em">大火宫六度有奇即贯索大星之黄经度又自黄道</span>  
<span style="margin-left: 2em">北至本星处约得四十四度三十分即其黄纬度也</span>  
<span style="margin-left: 2em">若先得星黄经纬度欲查球上星所当在之处亦用</span>  
<span style="margin-left: 2em">高弧依球上本星黄经度因之安高弧初度令末度</span>  
<span style="margin-left: 2em">至黄极中<sub class="note-yuan">黄极南北依星距南或北</sub>任黄道内外顺高弧数星纬</span>  
<span style="margin-left: 2em">度所止之点即星居球上之处假如崇祯元年测定</span>  
<span style="margin-left: 2em">心宿中星在黄道析木宫四度三十六分距南四度</span>  
<span style="margin-left: 2em">二十七分依此度分安高弧至南黄极从球上黄道</span>  
<span style="margin-left: 2em">数起得本距度之限即心宿中星所居之处</span>  
<span style="margin-left: 3em">求太阳赤经纬</span>  
<span style="margin-left: 1em">太阳依黄道行近考定冬夏二至距赤道南北最远之</span>  
<span style="margin-left: 2em">处为二十三度三十一分三十秒迨二至前后每日</span>  
<span style="margin-left: 2em">相距不等而二道又以斜交惟分至之点彼此得同</span>  
<span style="margin-left: 2em">经余俱不得合一也今求纬度法令本仪转任取黄</span>  
<span style="margin-left: 2em">道若干度正合子午圈下即于本子午圈视两道间</span>  
<span style="margin-left: 2em">所容之弧得数即黄赤相距之纬也求经度亦任取</span>  
<span style="margin-left: 2em">春分或冬至起算视黄道度在子午圈为限顺数其</span>  
<span style="margin-left: 2em">赤道圈之度即黄道上之赤经度若依地平求之必</span>  
<span style="margin-left: 2em">先安仪使两极与本地平齐即用地平当子午圈则</span>  
<span style="margin-left: 2em">赤经弧必过赤极与赤道以直角相交而东西所限</span>  
<span style="margin-left: 2em">赤纬弧亦为本圈南北所量虽子午圈本当过极诸</span>  
<span style="margin-left: 2em">圈与赤道正球相交而地平与正球亦不异是故所</span>  
<span style="margin-left: 2em">指度分即得赤道经纬度分</span>  
<span style="margin-left: 3em">求恒星赤经纬</span>  
<span style="margin-left: 1em">法以赤极为准必顺十二宫为经赤道南北为纬先转</span>  
<span style="margin-left: 2em">其球以所求星切子午圈下后视赤道是何度分此</span>  
<span style="margin-left: 2em">即本星赤经度又视赤道与星在子午圈上所开之</span>  
<span style="margin-left: 2em">弧容何度分乃其星之赤纬度如设狼星居子午圈</span>  
<span style="margin-left: 2em">得本圈下赤道度自夏至起算约七度三十分即狼</span>  
<span style="margin-left: 2em">星赤经度分又赤道南距狼星一十六度乃即本星</span>  
<span style="margin-left: 2em">之赤纬度求五星赤经纬法与同但先以黄经纬点</span>  
<span style="margin-left: 2em">星于球上如法使高弧自黄极中至黄道本经度过</span>  
<span style="margin-left: 2em">星处即依高弧之黄纬点球作识后转球令其点合</span>  
<span style="margin-left: 2em">子午圈亦可得赤经纬也若先算定恒星赤经纬于</span>  
<span style="margin-left: 2em">球上考其处即从春分依赤道顺查星经度移至子</span>  
<span style="margin-left: 2em">午圈下乃本圈上南或北<sub class="note-yuan">依星距</sub>查其纬度用点作识</span>  
<span style="margin-left: 2em">即其星所居之处也如崇祯元年心宿中星得赤经</span>  
<span style="margin-left: 2em">二百四十一度四十三分以本度分转球至子午圈</span>  
<span style="margin-left: 2em">因星纬度距南二十五度三十分随以此度正对子</span>  
<span style="margin-left: 2em">午圈下作点必指其本星之实处</span>  
<span style="margin-left: 3em">求黄道每度赤道纬</span>  
<span style="margin-left: 1em">法任取黄道何度移置子午圈正面即从黄道中线至</span>  
<span style="margin-left: 2em">赤道上视本圈所得若干度为黄道度之赤道纬<sub class="note-yuan">南或</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">北依所求点得所距</sub>若从北极起算亦于子午圈从极数至所</span>  
<span style="margin-left: 2em">求之点亦是如求清明初度纬得其距赤道北约五</span>  
<span style="margin-left: 2em">度距北极八十五度寒露初度距赤道南约五度距</span>  
<span style="margin-left: 2em">北极九十五度余俱倣此</span>  
<span style="margin-left: 3em">求黄道各弧出没之时</span>  
<span style="margin-left: 1em">黄道上出没较赤道圈之出没恒异盖赤道等弧或正</span>  
<span style="margin-left: 2em">球斜球<sub class="note-yuan">南北两极并在地平为正球一极出地平上一极入地平下为斜球</sub>所应出入</span>
