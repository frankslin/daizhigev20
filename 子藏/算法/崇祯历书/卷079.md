<span style="margin-left: 3em">求太白经度法</span>  
<span style="margin-left: 1em">法之纲有四</span>  
<span style="margin-left: 2em">一将恒年表简距冬至根及日躔历考太阳日时平</span>  
<span style="margin-left: 3em">行得星平行<sub class="note-jiao">校：至當作星據天理本東北本改</sub></span>  
<span style="margin-left: 2em">二将平行距最高为引数得初均加减数以加减平</span>  
<span style="margin-left: 3em">行为星实经数得较分别记</span>  
<span style="margin-left: 2em">三将伏见轮表年日时行为二均平引数又将初均</span>  
<span style="margin-left: 3em">数加之为二均实引数入二均加减表求加减数</span>  
<span style="margin-left: 3em">得中分别记</span>  
<span style="margin-left: 2em">四以中分较分相乘除得三均同二均加减实经得</span>  
<span style="margin-left: 3em">真视经</span>  
<span style="margin-left: 1em">法之目有十六</span>  
<span style="margin-left: 2em">一于二百恒年表简距冬至年根</span>  
<span style="margin-left: 2em">二于日躔平行表简日平行数</span>  
<span style="margin-left: 2em">三于日躔周日时表例简时数<sub class="note-jiao">校：例當作例據天理本改</sub></span>  
<span style="margin-left: 2em">四将前三数并之得平行数</span>  
<span style="margin-left: 2em">五于恒年表简最高行数</span>  
<span style="margin-left: 2em">六求平行距最高为初均引数</span>  
<span style="margin-left: 2em">七以初均数入加减表得初均数其下中分别记</span>  
<span style="margin-left: 2em">八以初均加减数加减平行得星实经数</span>  
<span style="margin-left: 2em">九于伏见轮年表简年根数</span>  
<span style="margin-left: 2em">十于伏见日表简日数</span>  
<span style="margin-left: 2em">十一于伏见时表简时数</span>  
<span style="margin-left: 2em">十二将伏见轮三数并之得二均平引数</span>  
<span style="margin-left: 2em">十三将前初均数加于平引为二均实引数</span>  
<span style="margin-left: 2em">十四以次均实引数入次均加减表得二均数其下</span>  
<span style="margin-left: 3em">较分别记</span>

<span style="margin-left: 3em">求太白纬度法</span>

<span style="margin-left: 2em">二以伏见实引数入前伏见轮宫度表往北顺行往</span>  
<span style="margin-left: 3em">南逆行求纬限度</span>  
<span style="margin-left: 2em">三以前中分与前纬限相乘得实六十为法除之得</span>

<span style="margin-left: 2em">五以伏见实引入伏见轮后宫度或南表北表求纬</span>  
<span style="margin-left: 3em">限度</span>
