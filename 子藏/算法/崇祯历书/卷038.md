<span style="margin-left: 1em"><sub class="note-yuan">徐光启督修򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫陈于阶򐈫朱廷枢򐈫򐈫򐈫</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">򐈫罗雅谷򐈫譔򐈫򐈫修政历法极西耶稣会士门人孙嗣烈򐈫朱光大򐈫受法򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫汤若望订</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫򐈫卫斗枢掌乘</sub></span>  
<span style="margin-left: 3em">测量全义十卷<sub class="note-jiao">校：清刊本段前有測量全義敘目標題</sub>前九卷属法</span>  
<span style="margin-left: 3em">原后一卷属法器法原者法之所以然也凡事不</span>  
<span style="margin-left: 3em">明于所以然则其已然者茫茫不知所来其当然</span>  
<span style="margin-left: 3em">者昧昧不知所往即使沿其流齐其末穷智极虑</span>  
<span style="margin-left: 3em">求法之确然不易弗可得已况天之高星辰之远</span>  
<span style="margin-left: 3em">历数之赜且隐也而不究其原可乎旋观往代如</span>  
<span style="margin-left: 3em">二十一史所载汉以后诸家之历详矣大都专求</span>  
<span style="margin-left: 3em">法数罕言名理即才士间出亦各窥一二莫覩大</span>  
<span style="margin-left: 3em">全杂以易卦乐律益增迷瞀何怪乎千八百年而</span>  
<span style="margin-left: 3em">未有定法也夫历法之原有二其一则象纬之原</span>  
<span style="margin-left: 3em">也天事也其一则推测之原也人事也象纬之原</span>  
<span style="margin-left: 3em">如测天约说所论百中之一二耳其他散见于七</span>  
<span style="margin-left: 3em">政本论会而通之聊足著明矣此书所论则推测</span>  
<span style="margin-left: 3em">之原也古今言推测者又有二其可以形察可以</span>  
<span style="margin-left: 3em">度审者谓之叀术不可以形察不可以度审者谓</span>  
<span style="margin-left: 3em">之缀术此所论者又缀术也缀术之用又有二其</span>  
<span style="margin-left: 3em">一总物以为度论其几何大曰量法也其一截物</span>  
<span style="margin-left: 3em">以为数论其几何众曰算法也历象之家兼用二</span>  
<span style="margin-left: 3em">法如鸟之傅两翼也则无所不可之矣凡几何之</span>  
<span style="margin-left: 3em">属有四曰点曰线曰面曰体点引为线线展为面</span>  
<span style="margin-left: 3em">面积为体究此四者诸有形有质之物细若纤芥</span>  
<span style="margin-left: 3em">巨若大圜悉可极其数而尽其变所以能范围不</span>  
<span style="margin-left: 3em">过曲成不遗也点不可为度线不可为形必三线</span>  
<span style="margin-left: 3em">交始成三角形焉凡度与数不用此形即巧历无</span>  
<span style="margin-left: 3em">从布算故三角者虽形体之始基实测量之纲要</span>  
<span style="margin-left: 3em">诸卷中当首论者此也凡言度数必通大小通近</span>  
<span style="margin-left: 3em">远者也三角形繇两视线一径线径线者所测物</span>  
<span style="margin-left: 3em">之广也径之两端出两直线入交于目睛之最中</span>  
<span style="margin-left: 3em">而成形如分寸咫尺为近小之形乃至大圜七政</span>  
<span style="margin-left: 3em">为远大之形形绝不等然其为三角等则比例必</span>  
<span style="margin-left: 3em">等因而用小推大用近推远亡不合者故曰通大</span>  
<span style="margin-left: 3em">小通远近也夫学难者必自近也学微者必自显</span>  
<span style="margin-left: 3em">也最难且微莫如天之三光最易且显莫如地之</span>  
<span style="margin-left: 3em">百物次卷所测测地与物以此故也然而测一物</span>  
<span style="margin-left: 3em">之高一山之高与测日月星辰去地之高也无以</span>  
<span style="margin-left: 3em">异则亦通大小通远近者也其次进而测面面者</span>  
<span style="margin-left: 3em">平方平圆之类其变不可胜穷也然而测物之面</span>  
<span style="margin-left: 3em">与测地景之面测日月星之面其理一也又进而</span>  
<span style="margin-left: 3em">测体体者立方立圆之类其变不可胜穷也然而</span>  
<span style="margin-left: 3em">测物之容与测地之容日月星之容其理一也是</span>  
<span style="margin-left: 3em">皆远近大小通焉者也既曰通焉而不言远大先</span>  
<span style="margin-left: 3em">言近小者则所以习之也习之奈何习手与目以</span>  
<span style="margin-left: 3em">求其贯也习心与意以求其信也不习不贯未有</span>  
<span style="margin-left: 3em">能信者也习且贯未有不信者也故习小习近言</span>  
<span style="margin-left: 3em">远大者之所求也夫论度数至于测体深矣微矣</span>  
<span style="margin-left: 3em">然而皆平面直线也天则圆体其面圆面其线曲</span>  
<span style="margin-left: 3em">线也测圆面之难十倍平面测曲线之难十倍直</span>  
<span style="margin-left: 3em">线盖圆与曲谓之弧而测弧无法于无法中求有</span>  
<span style="margin-left: 3em">法其势不得不难世有传弧矢算术测圆术者皆</span>  
<span style="margin-left: 3em">非术也其本术稍见于大测其为数则割圆八线</span>  
<span style="margin-left: 3em">表而此书第七至第九则言其理与法也盖以弧</span>  
<span style="margin-left: 3em">背求弦矢用测曲线三角形展转推求展转变易</span>  
<span style="margin-left: 3em">凡周天众规相交相距所以经纬七政运行四时</span>  
<span style="margin-left: 3em">推迁运会者上下百千万年可知也诸天诸曜种</span>  
<span style="margin-left: 3em">种运行悉无一定之法其为纷赜莫可胜原此弧</span>  
<span style="margin-left: 3em">弦诸法则何以能追求至尽乎盖所论者非诸曜</span>  
<span style="margin-left: 3em">自行之度数而宗动天之度数也宗动者不依七</span>  
<span style="margin-left: 3em">政而能为七政之准则历家谓之天元道天元极</span>  
<span style="margin-left: 3em">天元分至终古无变易也因此推步是以有恒御</span>  
<span style="margin-left: 3em">无恒历家之立法最难在此其用法最易亦在此</span>  
<span style="margin-left: 3em">矣终之以法器何也曰器之用大矣智者非器不</span>  
<span style="margin-left: 3em">作明者非器不述差者非器不改合者非器不验</span>  
<span style="margin-left: 3em">教者非器无以措其辞学者非器莫能领其意巧</span>  
<span style="margin-left: 3em">者非器未繇见其长拙者非器有所匿其短是以</span>  
<span style="margin-left: 3em">唐虞钦若首在玑衡历代以还屡更其制据今所</span>  
<span style="margin-left: 3em">有则浑天仪简仪立运仪浑天象四器也而年逾</span>  
<span style="margin-left: 3em">数百久阙缮治地址倾垫枢轴锈蚀浑天一仪不</span>  
<span style="margin-left: 3em">复运动简仪立运犹似堪用复少黄道规环且测</span>  
<span style="margin-left: 3em">候多端止凭一器架柱森列多成映蔽均赋辰度</span>  
<span style="margin-left: 3em">尚未精密刻定宿度则又元时所测非今测也此</span>  
<span style="margin-left: 3em">卷中分列诸器择其最急畧有五种曰测高仪曰</span>  
<span style="margin-left: 3em">距度仪曰地平经纬仪曰赤道经纬仪曰黄道经</span>  
<span style="margin-left: 3em">纬仪有此诸仪相袭并用彼碍则此通可以无求</span>  
<span style="margin-left: 3em">不得矣更求密测责以分秒无差则一式又须三</span>  
<span style="margin-left: 3em">器三器俱列用相参较三测并合则制器精工安</span>  
<span style="margin-left: 3em">置如式测验得法灼然具见矣有不合者可以推</span>  
<span style="margin-left: 3em">究病源更求厘正厘正之后测复参差则择其同</span>  
<span style="margin-left: 3em">者用之若止据一器有得即真乌从知其然不然</span>  
<span style="margin-left: 3em">可不可乎且旧仪大环径止五尺二寸度止十分</span>  
<span style="margin-left: 3em">今拟新式用半径者六尺则三倍大也度得百分</span>  
<span style="margin-left: 3em">则十倍细也用全径亦六尺度可六十分亦六倍</span>  
<span style="margin-left: 3em">细也夫今之改宪欲求倍胜于古非倍胜之器谅</span>  
<span style="margin-left: 3em">无从得之矣或疑法器重大取数复多即用物必</span>  
<span style="margin-left: 3em">奢是又不然今之旧仪不能揣知轻重大都唐宋</span>  
<span style="margin-left: 3em">以来考诸史志约畧相等宋史言东都浑仪四座</span>  
<span style="margin-left: 3em">每座约铜二万余斤今拟诸式槩从轻省若得宋</span>  
<span style="margin-left: 3em">元一仪之费足以尽造诸器有余矣且每式三器</span>  
<span style="margin-left: 3em">诚不可少若宛转相就则经纬仪可以得距地平</span>  
<span style="margin-left: 3em">仪可以得高一倍本数亦能通用或五大既全稍</span>  
<span style="margin-left: 3em">从狭小以为副贰兼用精铁以省铜材固无不可</span>  
<span style="margin-left: 3em">则所计一仪之费尚可损其半也惟是旧仪欲将</span>  
<span style="margin-left: 3em">修改则一器止堪一用其修改之费恐过于造作</span>  
<span style="margin-left: 3em">计不当为之耳惟浑天象止以测到度分量度经</span>  
<span style="margin-left: 3em">纬在于施用未为关切今体制完美无烦再造矣</span>

<span style="margin-left: 2em">界说二十三则</span>  
<span style="margin-left: 2em">第一界</span>  
<span style="margin-left: 1em">正弧全圈四分之一或大焉或小焉</span>  
<span style="margin-left: 5em">如图甲乙丁为全圈之半乙丙丁为四分之</span>  
<span style="margin-left: 5em">一是名一象限九十度正弧之大无过于此</span>  
<span style="margin-left: 5em">若甲乙丙则大于象限丙丁则小于象限但</span>  
<span style="margin-left: 2em">小者皆名正弧而大者则名过弧</span>  
<span style="margin-left: 2em">第二界</span>  
<span style="margin-left: 1em">余弧正弧之剩分</span>  
<span style="margin-left: 6em">如庚己正弧庚乙为余弧是正小于己乙</span>  
<span style="margin-left: 6em">也如庚丁过弧则大于丁乙而庚乙为过</span>  
<span style="margin-left: 6em">弧之余弧也</span>  
<span style="margin-left: 2em">第三界</span>  
<span style="margin-left: 1em">通弦者通弧之相当线分圈为两分<sub class="note-yuan">相当线亦名对线</sub></span>  
<span style="margin-left: 2em">如庚丙线与庚乙丙弧相当又与庚己子丙弧相当</span>  
<span style="margin-left: 2em">第四界</span>  
<span style="margin-left: 1em">圈内线极大过心者为圈径</span>  
<span style="margin-left: 2em">如己戊丁是</span>  
<span style="margin-left: 2em">第五界</span>  
<span style="margin-left: 1em">正弦弦之半</span>  
<span style="margin-left: 2em">如丙甲庚弦半之为丙甲正弦当丙乙弧又丙辛子</span>  
<span style="margin-left: 2em">弦半之为丙辛正弦当丙丁弧或曰正弦者从圈上</span>  
<span style="margin-left: 2em">一点作垂线至己丁径上则丙辛为丙丁弧相当之</span>  
<span style="margin-left: 2em">正弦</span>  
<span style="margin-left: 2em">第六界</span>  
<span style="margin-left: 1em">余弦余弧之正弦</span>  
<span style="margin-left: 2em">如丁丙正弧则丙乙其余弧丙甲为丙乙之正弦丙</span>  
<span style="margin-left: 2em">丁之余弦</span>  
<span style="margin-left: 2em">第七界</span>  
<span style="margin-left: 1em">倒弦者余弦与半径之较亦名矢</span>  
<span style="margin-left: 6em">如丙甲余弦与辛戊线等以辛戊减丁戊</span>  
<span style="margin-left: 6em">半径存辛丁为丙丁弧之倒弦亦为丙丁</span>  
<span style="margin-left: 6em">弧之矢</span>  
<span style="margin-left: 2em">第八界</span>  
<span style="margin-left: 1em">全弦径之半象限弧之正弦</span>  
<span style="margin-left: 2em">第九界</span>  
<span style="margin-left: 4em">直线角在圈心或大或小皆居对弧两腰间<sub class="note-yuan">相当</sub></span>  
<span style="margin-left: 4em"><sub class="note-yuan">弧亦曰对弧</sub></span>  
<span style="margin-left: 4em">如丙戊丁角在戊心向丙丁正弧则角生于丙</span>  
<span style="margin-left: 2em">戊丁戊两腰间</span>  
<span style="margin-left: 2em">第十界</span>  
<span style="margin-left: 1em">余角者余弧之正角<sub class="note-yuan">对角亦名正角亦名相当角</sub></span>  
<span style="margin-left: 2em">如丙戊乙角为丙丁正弧之余角即丙乙余弧之正</span>  
<span style="margin-left: 2em">角</span>  
<span style="margin-left: 2em">第十一界</span>  
<span style="margin-left: 1em">切线者圈径界之垂线亦名切圈线在圈外<sub class="note-yuan">如下界之丙甲线</sub></span>  
<span style="margin-left: 2em">第十二界</span>  
<span style="margin-left: 1em">割线者直角之对线亦名交线亦名截线在圈之内外</span>  
<span style="margin-left: 2em">如甲戊丙形甲直角<sub class="note-yuan">凡言甲角当九十度弧之直角</sub>戊为心丙戊交</span>  
<span style="margin-left: 5em">圈于乙割线也此线限心上角限甲乙弧则</span>  
<span style="margin-left: 5em">角与弧胥生于甲戊戊丙两腰间又曰正割</span>  
<span style="margin-left: 2em">线者正弧之割线如甲乙正弧则戊丙正割线也</span>  
<span style="margin-left: 2em">第十三界</span>  
<span style="margin-left: 1em">余切线者余弧之切线</span>  
<span style="margin-left: 2em">第十四界</span>  
<span style="margin-left: 1em">余割线者余弧之割线</span>  
<span style="margin-left: 5em">如戊丁余弧乙己为割线是甲戊弧之余割</span>  
<span style="margin-left: 5em">线</span>
