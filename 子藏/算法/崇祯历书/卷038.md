## 崇禎曆書卷之三十八　測量全義卷一

<span style="margin-left: 2em">法原部<sub class="note-jiao">校：據奎章</sub></span>  
<span style="margin-left: 1em">　<sub class="note-yuan">閣本校錄</sub></span>  
<span style="margin-left: 2em">測量全義第一卷　敘目　測直線三角形</span>  
<span style="margin-left: 1em">欽差禮部尚書兼翰林院學士協理詹事府事加俸一</span>  
<span style="margin-left: 1em">級徐光啓奉勅督修</span>  
<span style="margin-left: 9em">遠西耶穌會士羅雅谷　　譔</span>  
<span style="margin-left: 9em">同　　會　　龍華民</span>  
<span style="margin-left: 15em">湯若望同　訂</span>  
<span style="margin-left: 9em">庠　　生　　衛斗樞脩　潤</span>  
<span style="margin-left: 9em">訪　　舉　　陳于階等　算</span>  
<span style="margin-left: 9em">長　　洲　　孫嗣烈校　梓</span>  
<span style="margin-left: 1em">　<sub class="note-jiao">校：校諱作較今改清刊本署名不同錄之於左</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">西洋新法曆書法原部明禮部尚書兼翰林院學士協理詹事府事加俸一級</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">徐光啓督修　　　　　　　　　　　　　　　　　　　　陳于階　朱廷樞　　　</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">　羅雅谷　譔　　修政曆法極西耶穌會士門人孫嗣烈　朱光大　受法　　　　　　　　　　　湯若望訂</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">　　　　　　　　　　　　　　　　　　　　衛斗樞掌乘</sub></span>  
<span style="margin-left: 3em">測量全義十卷<sub class="note-jiao">校：清刊本段前有測量全義敘目標題</sub>前九卷屬法</span>  
<span style="margin-left: 3em">原後一卷屬法器法原者法之所以然也凡事不</span>  
<span style="margin-left: 3em">明於所以然則其已然者茫茫不知所来其當然</span>  
<span style="margin-left: 3em">者昧昧不知所往即使沿其流齊其末窮智極慮</span>  
<span style="margin-left: 3em">求法之確然不易弗可得已况天之高星辰之遠</span>  
<span style="margin-left: 3em">曆數之賾且隱也而不究其原可乎旋觀往代如</span>  
<span style="margin-left: 3em">二十一史所載漢以後諸家之曆詳矣大都專求</span>  
<span style="margin-left: 3em">法數罕言名理即才士間出亦各窺一二莫覩大</span>  
<span style="margin-left: 3em">全雜以易卦樂律益增迷瞀何怪乎千八百年而</span>  
<span style="margin-left: 3em">未有定法也夫曆法之原有二其一則象緯之原</span>  
<span style="margin-left: 3em">也天事也其一則推測之原也人事也象緯之原</span>  
<span style="margin-left: 3em">如測天約說所論百中之一二耳其他散見於七</span>  
<span style="margin-left: 3em">政本論會而通之聊足著明矣此書所論則推測</span>  
<span style="margin-left: 3em">之原也古今言推測者又有二其可以形察可以</span>  
<span style="margin-left: 3em">度審者謂之叀術不可以形察不可以度審者謂</span>  
<span style="margin-left: 3em">之綴術此所論者又綴術也綴術之用又有二其</span>  
<span style="margin-left: 3em">一總物以爲度論其幾何大曰量法也其一截物</span>  
<span style="margin-left: 3em">以爲數論其幾何衆曰算法也曆象之家兼用二</span>  
<span style="margin-left: 3em">法如鳥之傅兩翼也則無所不可之矣凡幾何之</span>  
<span style="margin-left: 3em">屬有四曰點曰線曰面曰體點引爲線線展爲面</span>  
<span style="margin-left: 3em">面積爲體究此四者諸有形有質之物細若纖芥</span>  
<span style="margin-left: 3em">鉅若大圜悉可極其數而盡其變所以能範圍不</span>  
<span style="margin-left: 3em">過曲成不遺也點不可爲度線不可爲形必三線</span>  
<span style="margin-left: 3em">交始成三角形焉凡度與數不用此形即巧曆無</span>  
<span style="margin-left: 3em">從布算故三角者雖形體之始基實測量之綱要</span>  
<span style="margin-left: 3em">諸卷中當首論者此也凡言度數必通大小通近</span>  
<span style="margin-left: 3em">遠者也三角形繇兩視線一徑線徑線者所測物</span>  
<span style="margin-left: 3em">之廣也徑之兩端出兩直線入交於目睛之最中</span>  
<span style="margin-left: 3em">而成形如分寸咫尺爲近小之形乃至大圜七政</span>  
<span style="margin-left: 3em">爲遠大之形形絕不等然其爲三角等則比例必</span>  
<span style="margin-left: 3em">等因而用小推大用近推遠亡不合者故曰通大</span>  
<span style="margin-left: 3em">小通遠近也夫學難者必自近也學微者必自顯</span>  
<span style="margin-left: 3em">也最難且微莫如天之三光最易且顯莫如地之</span>  
<span style="margin-left: 3em">百物次卷所測測地與物以此故也然而測一物</span>  
<span style="margin-left: 3em">之高一山之高與測日月星辰去地之高也無以</span>  
<span style="margin-left: 3em">異則亦通大小通遠近者也其次進而測面面者</span>  
<span style="margin-left: 3em">平方平圓之類其變不可勝窮也然而測物之面</span>  
<span style="margin-left: 3em">與測地景之面測日月星之面其理一也又進而</span>  
<span style="margin-left: 3em">測體體者立方立圓之類其變不可勝窮也然而</span>  
<span style="margin-left: 3em">測物之容與測地之容日月星之容其理一也是</span>  
<span style="margin-left: 3em">皆遠近大小通焉者也既曰通焉而不言遠大先</span>  
<span style="margin-left: 3em">言近小者則所以習之也習之奈何習手與目以</span>  
<span style="margin-left: 3em">求其貫也習心與意以求其信也不習不貫未有</span>  
<span style="margin-left: 3em">能信者也習且貫未有不信者也故習小習近言</span>  
<span style="margin-left: 3em">遠大者之所求也夫論度數至於測體深矣微矣</span>  
<span style="margin-left: 3em">然而皆平面直線也天則圓體其面圓面其線曲</span>  
<span style="margin-left: 3em">線也測圓面之難十倍平面測曲線之難十倍直</span>  
<span style="margin-left: 3em">線蓋圓與曲謂之弧而測弧無法於無法中求有</span>  
<span style="margin-left: 3em">法其勢不得不難世有傳弧矢算術測圓術者皆</span>  
<span style="margin-left: 3em">非術也其本術稍見於大測其爲數則割圓八線</span>  
<span style="margin-left: 3em">表而此書第七至第九則言其理與法也蓋以弧</span>  
<span style="margin-left: 3em">背求弦矢用測曲線三角形展轉推求展轉變易</span>  
<span style="margin-left: 3em">凡周天衆規相交相距所以經緯七政運行四時</span>  
<span style="margin-left: 3em">推遷運會者上下百千萬年可知也諸天諸曜種</span>  
<span style="margin-left: 3em">種運行悉無一定之法其爲紛賾莫可勝原此弧</span>  
<span style="margin-left: 3em">弦諸法則何以能追求至盡乎蓋所論者非諸曜</span>  
<span style="margin-left: 3em">自行之度數而宗動天之度數也宗動者不依七</span>  
<span style="margin-left: 3em">政而能爲七政之準則曆家謂之天元道天元極</span>  
<span style="margin-left: 3em">天元分至終古無變易也因此推步是以有恆御</span>  
<span style="margin-left: 3em">無恆曆家之立法最難在此其用法最易亦在此</span>  
<span style="margin-left: 3em">矣終之以法器何也曰器之用大矣智者非器不</span>  
<span style="margin-left: 3em">作明者非器不述差者非器不改合者非器不驗</span>  
<span style="margin-left: 3em">教者非器無以措其辭學者非器莫能領其意巧</span>  
<span style="margin-left: 3em">者非器未繇見其長拙者非器有所匿其短是以</span>  
<span style="margin-left: 3em">唐虞欽若首在璣衡歷代以還屢更其制據今所</span>  
<span style="margin-left: 3em">有則渾天儀簡儀立運儀渾天象四器也而年逾</span>  
<span style="margin-left: 3em">數百久闕繕治地址傾墊樞軸鏽蝕渾天一儀不</span>  
<span style="margin-left: 3em">復運動簡儀立運猶似堪用復少黃道規環且測</span>  
<span style="margin-left: 3em">候多端止憑一器架柱森列多成映蔽均賦辰度</span>  
<span style="margin-left: 3em">尚未精密刻定宿度則又元時所測非今測也此</span>  
<span style="margin-left: 3em">卷中分列諸器擇其最急畧有五種曰測高儀曰</span>  
<span style="margin-left: 3em">距度儀曰地平經緯儀曰赤道經緯儀曰黃道經</span>  
<span style="margin-left: 3em">緯儀有此諸儀相襲並用彼礙則此通可以無求</span>  
<span style="margin-left: 3em">不得矣更求密測責以分秒無差則一式又須三</span>  
<span style="margin-left: 3em">器三器俱列用相參較三測並合則製器精工安</span>  
<span style="margin-left: 3em">置如式測驗得法灼然具見矣有不合者可以推</span>  
<span style="margin-left: 3em">究病源更求釐正釐正之後測復參差則擇其同</span>  
<span style="margin-left: 3em">者用之若止據一器有得即真烏從知其然不然</span>  
<span style="margin-left: 3em">可不可乎且舊儀大環徑止五尺二寸度止十分</span>  
<span style="margin-left: 3em">今擬新式用半徑者六尺則三倍大也度得百分</span>  
<span style="margin-left: 3em">則十倍細也用全徑亦六尺度可六十分亦六倍</span>  
<span style="margin-left: 3em">細也夫今之改憲欲求倍勝於古非倍勝之器諒</span>  
<span style="margin-left: 3em">無從得之矣或疑法器重大取數復多即用物必</span>  
<span style="margin-left: 3em">奢是又不然今之舊儀不能揣知輕重大都唐宋</span>  
<span style="margin-left: 3em">以来考諸史志約畧相等宋史言東都渾儀四座</span>  
<span style="margin-left: 3em">每座約銅二萬餘斤今擬諸式槩從輕省若得宋</span>  
<span style="margin-left: 3em">元一儀之費足以盡造諸器有餘矣且每式三器</span>  
<span style="margin-left: 3em">誠不可少若宛轉相就則經緯儀可以得距地平</span>  
<span style="margin-left: 3em">儀可以得高一倍本數亦能通用或五大既全稍</span>  
<span style="margin-left: 3em">從狹小以爲副貳兼用精鐵以省銅材固無不可</span>  
<span style="margin-left: 3em">則所計一儀之費尚可損其半也惟是舊儀欲將</span>  
<span style="margin-left: 3em">脩改則一器止堪一用其脩改之費恐過於造作</span>  
<span style="margin-left: 3em">計不當爲之耳惟渾天象止以測到度分量度經</span>  
<span style="margin-left: 3em">緯在於施用未爲關切今體製完美無煩再造矣</span>

<span style="margin-left: 4em">第十卷　儀器圖說</span>  
<span style="margin-left: 1em">測量全義第一卷之首</span>  
<span style="margin-left: 2em">界說二十三則</span>  
<span style="margin-left: 2em">第一界</span>  
<span style="margin-left: 1em">正弧全圈四分之一或大焉或小焉</span>  
<span style="margin-left: 5em">如圖甲乙丁爲全圈之半乙丙丁爲四分之</span>  
<span style="margin-left: 5em">一是名一象限九十度正弧之大無過於此</span>  
<span style="margin-left: 5em">若甲乙丙則大於象限丙丁則小於象限但</span>  
<span style="margin-left: 2em">小者皆名正弧而大者則名過弧</span>  
<span style="margin-left: 2em">第二界</span>  
<span style="margin-left: 1em">餘弧正弧之剩分</span>  
<span style="margin-left: 6em">如庚己正弧庚乙爲餘弧是正小於己乙</span>  
<span style="margin-left: 6em">也如庚丁過弧則大於丁乙而庚乙爲過</span>  
<span style="margin-left: 6em">弧之餘弧也</span>  
<span style="margin-left: 2em">第三界</span>  
<span style="margin-left: 1em">通弦者通弧之相當線分圈爲兩分<sub class="note-yuan">相當線亦名對線</sub></span>  
<span style="margin-left: 2em">如庚丙線與庚乙丙弧相當又與庚己子丙弧相當</span>  
<span style="margin-left: 2em">第四界</span>  
<span style="margin-left: 1em">圈內線極大過心者爲圈徑</span>  
<span style="margin-left: 2em">如己戊丁是</span>  
<span style="margin-left: 2em">第五界</span>  
<span style="margin-left: 1em">正弦弦之半</span>  
<span style="margin-left: 2em">如丙甲庚弦半之爲丙甲正弦當丙乙弧又丙辛子</span>  
<span style="margin-left: 2em">弦半之爲丙辛正弦當丙丁弧或曰正弦者從圈上</span>  
<span style="margin-left: 2em">一點作垂線至己丁徑上則丙辛爲丙丁弧相當之</span>  
<span style="margin-left: 2em">正弦</span>  
<span style="margin-left: 2em">第六界</span>  
<span style="margin-left: 1em">餘弦餘弧之正弦</span>  
<span style="margin-left: 2em">如丁丙正弧則丙乙其餘弧丙甲爲丙乙之正弦丙</span>  
<span style="margin-left: 2em">丁之餘弦</span>  
<span style="margin-left: 2em">第七界</span>  
<span style="margin-left: 1em">倒弦者餘弦與半徑之較亦名矢</span>  
<span style="margin-left: 6em">如丙甲餘弦與辛戊線等以辛戊减丁戊</span>  
<span style="margin-left: 6em">半徑存辛丁爲丙丁弧之倒弦亦爲丙丁</span>  
<span style="margin-left: 6em">弧之矢</span>  
<span style="margin-left: 2em">第八界</span>  
<span style="margin-left: 1em">全弦徑之半象限弧之正弦</span>  
<span style="margin-left: 2em">第九界</span>  
<span style="margin-left: 4em">直線角在圈心或大或小皆居對弧兩腰間<sub class="note-yuan">相當</sub></span>  
<span style="margin-left: 4em"><sub class="note-yuan">弧亦曰對弧</sub></span>  
<span style="margin-left: 4em">如丙戊丁角在戊心向丙丁正弧則角生於丙</span>  
<span style="margin-left: 2em">戊丁戊兩腰間</span>  
<span style="margin-left: 2em">第十界</span>  
<span style="margin-left: 1em">餘角者餘弧之正角<sub class="note-yuan">對角亦名正角亦名相當角</sub></span>  
<span style="margin-left: 2em">如丙戊乙角爲丙丁正弧之餘角即丙乙餘弧之正</span>  
<span style="margin-left: 2em">角</span>  
<span style="margin-left: 2em">第十一界</span>  
<span style="margin-left: 1em">切線者圈徑界之垂線亦名切圈線在圈外<sub class="note-yuan">如下界之丙甲線</sub></span>  
<span style="margin-left: 2em">第十二界</span>  
<span style="margin-left: 1em">割線者直角之對線亦名交線亦名截線在圈之內外</span>  
<span style="margin-left: 2em">如甲戊丙形甲直角<sub class="note-yuan">凡言甲角當九十度弧之直角</sub>戊爲心丙戊交</span>  
<span style="margin-left: 5em">圈於乙割線也此線限心上角限甲乙弧則</span>  
<span style="margin-left: 5em">角與弧胥生於甲戊戊丙兩腰間又曰正割</span>  
<span style="margin-left: 2em">線者正弧之割線如甲乙正弧則戊丙正割線也</span>  
<span style="margin-left: 2em">第十三界</span>  
<span style="margin-left: 1em">餘切線者餘弧之切線</span>  
<span style="margin-left: 2em">第十四界</span>  
<span style="margin-left: 1em">餘割線者餘弧之割線</span>  
<span style="margin-left: 5em">如戊丁餘弧乙己爲割線是甲戊弧之餘割</span>  
<span style="margin-left: 5em">線</span>  
<span style="margin-left: 2em">第十五界</span>  
<span style="margin-left: 1em">全圈三百六十度半徑之全數十萬平分<sub class="note-yuan">或用一萬或用百萬千萬</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">皆可</sub></span>  
<span style="margin-left: 2em">第十六界</span>  
<span style="margin-left: 1em">設弧者任取全圈之一分<sub class="note-yuan">凡言設者先有定數也或稱有或稱得</sub></span>  
<span style="margin-left: 5em">如甲戊丙角形戊爲心甲乙丁其象限弧也</span>  
<span style="margin-left: 5em">取甲乙一分四十度則甲乙爲設弧也</span>  
<span style="margin-left: 2em">第十七界</span>  
<span style="margin-left: 1em">設角者設弧之角</span>

<span style="margin-left: 1em">設邊線</span>

<span style="margin-left: 1em">平形有方有矩<sub class="note-yuan">方者直角方形矩者矩內直角形</sub></span>

<span style="margin-left: 2em">第一題</span>  
<span style="margin-left: 1em">通弦與通弧正弦與正弧比例等<sub class="note-yuan">比例等後省曰若</sub></span>  
<span style="margin-left: 5em">解曰有己庚乙丙丁圈其通徑己戊丁戊上</span>  
<span style="margin-left: 5em">作乙戊垂線別作庚甲丙線與己丁平行則</span>  
<span style="margin-left: 5em">庚甲丙爲庚乙丙通弧之對弦題言庚甲丙</span>  
<span style="margin-left: 2em">通弦與庚乙丙通弧之比例若丙甲正弦與乙丙正</span>  
<span style="margin-left: 2em">弧</span>  
<span style="margin-left: 2em">論曰戊心上垂線作直角平分庚乙丙弧則庚甲戊</span>  
<span style="margin-left: 2em">丙甲戊兩角形等何者庚戊丙戊從心至界等甲兩</span>  
<span style="margin-left: 2em">旁直角等甲戊同邊則兩形必等兩角之對弧亦等</span>  
<span style="margin-left: 2em"><sub class="note-yuan">幾何三卷二十六</sub>故庚甲丙偕庚乙丙兩全與丙甲偕丙乙</span>  
<span style="margin-left: 2em">兩半比例等</span>  
<span style="margin-left: 2em">第二題</span>  
<span style="margin-left: 1em">圈內正弧等正弦亦等反之正弦等正弧亦等</span>  
<span style="margin-left: 5em">解曰有全圈丁丙乙寅己丁寅爲徑設丁丙</span>  
<span style="margin-left: 5em">乙寅兩正弧等從丙從乙作丙戊乙己兩垂</span>  
<span style="margin-left: 5em">線截徑於辛於壬作直角平分兩弦<sub class="note-yuan">三卷第三</sub>亦</span>  
<span style="margin-left: 2em">平分丙丁戊乙寅己兩弧<sub class="note-yuan">三卷三十</sub>是丙丁丁戊偕乙寅</span>  
<span style="margin-left: 2em">寅己之各兩半與丙丁戊偕乙寅己之兩全比例等</span>

<span style="margin-left: 2em">等則丙辛乙壬兩正弦必等</span>

<span style="margin-left: 2em">角形必等故丙辛乙壬兩正弦必等反之丙辛與乙</span>  
<span style="margin-left: 2em">壬丙庚與乙庚各等丙辛庚乙壬庚兩直角等則丙</span>  
<span style="margin-left: 2em">庚辛乙庚壬兩角亦等<sub class="note-yuan">一卷第八</sub>而丙丁乙寅兩對弧必</span>  
<span style="margin-left: 2em">等<sub class="note-yuan">三卷第二十六</sub></span>  
<span style="margin-left: 2em">第三題</span>  
<span style="margin-left: 1em">圈之內大弧大弦小弧小弦反之大弦大弧小弦小弧</span>  
<span style="margin-left: 2em">各相對</span>  
<span style="margin-left: 5em">解曰甲乙丙丁圈甲己大弧丙庚小弧題言</span>  
<span style="margin-left: 5em">己卯弦大於庚寅弦</span>  
<span style="margin-left: 5em">論曰試取甲辛弧與丙庚弧等從庚乙己辛</span>  
<span style="margin-left: 2em">各作垂線過甲丙徑至於丑於丁於癸於子其庚寅</span>  
<span style="margin-left: 2em">辛壬兩半等<sub class="note-yuan">本卷二</sub>即庚丑辛子兩全亦等<sub class="note-yuan">三卷第三</sub>己癸</span>

<span style="margin-left: 2em">次論曰試截卯己於午與庚寅等午上作垂線至辛</span>  
<span style="margin-left: 2em">與丙甲徑平行午卯庚寅既等自與辛壬等<sub class="note-yuan">皆在兩平行線</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">內</sub>甲辛丙庚兩弧亦等己甲全弧大於辛甲分弧己</span>  
<span style="margin-left: 2em">卯大弦必大於辛壬小弦是大弦對大弧小弦對小</span>  
<span style="margin-left: 2em">弧也</span>  
<span style="margin-left: 2em">第四題</span>  
<span style="margin-left: 1em">圈徑截弦亦截弧任分弦之兩分與兩弧之正弦各相</span>  
<span style="margin-left: 6em">似</span>  
<span style="margin-left: 6em">解曰有圈徑乙辛截丙丁通弦於己截丙</span>  
<span style="margin-left: 6em">乙丁通弧於乙其丙乙乙丁兩分弧之各</span>  
<span style="margin-left: 2em">正弦爲丙甲戊丁題言丙己己丁兩分弦與甲丙戊</span>  
<span style="margin-left: 2em">丁兩正弦比例等</span>  
<span style="margin-left: 2em">論曰丙甲己丁戊己兩角形相似何者兩形有相等</span>  
<span style="margin-left: 2em">之己交角有相等之兩直角即丁角與丙角必等<sub class="note-yuan">一卷</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">三十二</sub>是形與形邊與邊俱相似而丙己己丁兩分弦</span>  
<span style="margin-left: 2em">之比例與丙甲丁戊兩正弦自相似</span>  
<span style="margin-left: 2em">第五題<sub class="note-yuan">三支</sub></span>  
<span style="margin-left: 1em">三不等角形作垂線任分底爲二其大分依大邊大邊</span>  
<span style="margin-left: 2em">上方大於小邊上方其較爲底全線偕分餘線矩內</span>  
<span style="margin-left: 2em">形</span>  
<span style="margin-left: 6em">先解曰丁乙丙角形三邊不等丁乙小丁</span>  
<span style="margin-left: 6em">丙次之乙丙大爲底<sub class="note-yuan">凡邊大者爲底</sub>從丁角作垂</span>  
<span style="margin-left: 6em">線至底題言分底爲二者謂垂線之甲點</span>  
<span style="margin-left: 6em">在形內蓋乙丙邊大即對角之乙丁丙角</span>  
<span style="margin-left: 2em">亦大乙丙兩角必小如謂點在形外即以乙丙邊引</span>  
<span style="margin-left: 2em">長於己而令己作直角將丁己乙三角形內有丁乙</span>  
<span style="margin-left: 2em">己鈍角<sub class="note-yuan">甲乙丁爲銳角故也</sub>又有己直角是兩角大於兩直角</span>  
<span style="margin-left: 2em">也可乎次解曰丁甲垂線任分乙丙底題言甲丙大</span>  
<span style="margin-left: 2em">分依丁丙大邊</span>  
<span style="margin-left: 2em">論曰丁丙邊既大於丁乙邊即其上方形亦大而丁</span>  
<span style="margin-left: 5em">丙上方與甲丁甲丙上兩方并等<sub class="note-yuan">一卷四十七</sub>則</span>  
<span style="margin-left: 5em">甲丁甲丙兩邊并亦大於甲丁甲乙兩邊并</span>  
<span style="margin-left: 5em">試减同用之甲丁則所存甲丙亦大於甲乙</span>  
<span style="margin-left: 5em">是甲丙大分依丁丙大邊也</span>  
<span style="margin-left: 2em">三解曰丁丙方大於丁乙方其較乙丙偕戊丙矩內</span>  
<span style="margin-left: 2em">形</span>  
<span style="margin-left: 2em">論曰試截甲戊與甲乙等其乙戊線平分於甲有引</span>  
<span style="margin-left: 2em">增戊丙線則乙丙偕戊丙矩內形及甲戊上方形并</span>  
<span style="margin-left: 2em">與甲丙上方形等<sub class="note-yuan">二卷第六</sub>次各加一甲丁上方形則乙</span>  
<span style="margin-left: 2em">丙偕戊丙矩內形及乙甲<sub class="note-yuan">即甲戊也</sub>甲丁上兩方形或丁</span>  
<span style="margin-left: 2em">乙上方形<sub class="note-yuan">乙甲甲丁兩方并與丁乙方等一卷四七</sub>與甲丙甲丁上兩方</span>  
<span style="margin-left: 2em">并或丁丙上方形俱等夫丁乙上方形內有甲乙甲</span>  
<span style="margin-left: 2em">丁上兩方形獨少乙丙偕戊丙矩內形則丁丙上方</span>  
<span style="margin-left: 2em">大於丁乙上方形之較爲乙丙偕戊丙矩內形</span>  
<span style="margin-left: 2em">第六題<sub class="note-yuan">四支</sub></span>  
<span style="margin-left: 1em">三不等角形從角作垂線任分底爲二知其邊數即知</span>  
<span style="margin-left: 2em">各分數</span>  
<span style="margin-left: 5em">解曰同前圖乙甲甲戊等戊丙爲任分之較</span>  
<span style="margin-left: 5em">法曰丁乙丁丙上兩方之實相减餘者以底</span>  
<span style="margin-left: 5em">數而一得戊丙以减底數餘者半之得乙甲</span>  
<span style="margin-left: 2em">小分如丁丙十五丁乙十乙丙底十八丁丙自之得</span>  
<span style="margin-left: 2em">二百二十五丁乙自之得一百相减存一百二十五</span>  
<span style="margin-left: 2em">以底十八爲法而一得六又十八之十七戊丙也以</span>  
<span style="margin-left: 2em">减十八存十一又十八之一乙戊也半之得五又三</span>  
<span style="margin-left: 2em">十六之十九乙甲也</span>  
<span style="margin-left: 2em">次解曰依二卷十三題乙丙爲兩銳角則丁丙上方</span>  
<span style="margin-left: 2em">小於丁乙乙丙上兩方其較爲乙丙偕乙甲矩內形</span>  
<span style="margin-left: 2em">二</span>

<span style="margin-left: 2em">爲四百二十四减去丁丙方形之數二百二十五存</span>  
<span style="margin-left: 2em">一百九十九爲實底數一十八爲法而一得乙甲之</span>  
<span style="margin-left: 2em">數約之爲五又三十六之十九者二</span>  
<span style="margin-left: 2em">三解曰以丁大角爲心丁乙小邊爲界作全圈截丁</span>  
<span style="margin-left: 2em">丙於己乙丙於戊丁丙引長於辛丁乙丁辛兩半徑</span>  
<span style="margin-left: 2em">等則辛丙偕己丙與乙丙偕戊丙兩矩內形等<sub class="note-yuan">三卷三十</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">六</sub>乙甲甲戊又等<sub class="note-yuan">三卷三</sub>丙乙大邊有戊丙分在圈外</span>  
<span style="margin-left: 5em">法曰用前數丁丙十五加丁乙十或丁辛得</span>  
<span style="margin-left: 5em">辛丙二十五丁己與丁乙等則辛己徑爲二</span>  
<span style="margin-left: 5em">十以己丙五乘辛丙得一百二十五爲實乙</span>  
<span style="margin-left: 5em">丙十八爲法而一得六又十八之十七爲戊</span>  
<span style="margin-left: 2em">丙有戊丙得乙戊平分乙戊得乙甲</span>  
<span style="margin-left: 2em">四解曰以丁大角爲心丁丙大邊爲界作全圈乙丙</span>  
<span style="margin-left: 2em">底引長於戊丁乙邊引長於庚於己即庚乙乙己矩</span>  
<span style="margin-left: 5em">內形與丙乙乙戊矩內形等<sub class="note-yuan">三卷三十五</sub>丙甲甲</span>  
<span style="margin-left: 5em">戊既等庚丁丁丙亦等庚乙邊二十五丁丙</span>  
<span style="margin-left: 5em">丁乙兩邊并亦二十五丁己丁丙各十五减</span>  
<span style="margin-left: 2em">丁乙十存乙己五與庚乙相乘得一百二十五爲實</span>  
<span style="margin-left: 2em">乙丙十八爲法而一得六有奇爲戊乙以加乙丙十</span>  
<span style="margin-left: 2em">八得戊丙平分得丙甲</span>  
<span style="margin-left: 2em">第七題</span>  
<span style="margin-left: 1em">斷比例之四率以三推一名三率法</span>  
<span style="margin-left: 2em">解曰四幾何爲兩比例等先有三推得第四或同類</span>  
<span style="margin-left: 2em">或異類其前其後不得更易用反理亦用轉理列第</span>  
<span style="margin-left: 2em">一第二第三率即可推第四率依七卷十九題中率</span>  
<span style="margin-left: 2em">相乘與首尾兩率相乘得數等故二三相乘爲實第</span>  
<span style="margin-left: 2em">一爲法而一得四率也昔人因其用大算家必需稱</span>  
<span style="margin-left: 2em">爲全法焉<sub class="note-yuan">同類異類反理轉理俱見幾何四卷</sub></span>  
<span style="margin-left: 2em">第八題</span>  
<span style="margin-left: 1em">三邊直角形銳角爲心底爲界作象限圈半徑爲全數</span>  
<span style="margin-left: 2em">在心角對邊爲其弧之正弦其旁爲正弧之餘餘弧</span>  
<span style="margin-left: 2em">之正</span>  
<span style="margin-left: 5em">解曰如前圖甲乙丙直角形乙銳角爲心乙</span>  
<span style="margin-left: 5em">丙底爲界作丁己象限圈引乙甲邊於丁從</span>  
<span style="margin-left: 5em">心作乙己垂線題言甲直角乙丙爲對邊作</span>  
<span style="margin-left: 2em">全數<sub class="note-yuan">本界說八</sub>丙甲邊爲在心角之對邊即丁丙弧之正</span>  
<span style="margin-left: 2em">弦<sub class="note-yuan">本界說五</sub>而甲乙邊爲丁丙正弧之餘弦爲丙己餘弧</span>  
<span style="margin-left: 2em">之正弦所以然者試從丙作丙戊與甲乙平行甲直</span>  
<span style="margin-left: 5em">角丙戊乙亦直角則丙戊甲乙兩線等<sub class="note-yuan">一卷三十</sub></span>  
<span style="margin-left: 5em"><sub class="note-yuan">四</sub>丙己弧爲丁丙正弧之餘弧丙戊爲丙己</span>  
<span style="margin-left: 5em">餘弧之正弦爲丁丙正弧之餘弦<sub class="note-yuan">甲乙同</sub></span>  
<span style="margin-left: 2em">又如後圖用銳角丙爲心乙爲界則乙甲爲丙角之</span>  
<span style="margin-left: 2em">對邊爲乙丁正弧之正弦甲丙其餘弦<sub class="note-yuan">乙戊同</sub></span>  
<span style="margin-left: 2em">第九題</span>  
<span style="margin-left: 1em">三角形邊與邊之比例若各對角之正弦</span>  
<span style="margin-left: 6em">解曰題一言直角形依前論各邊爲對角</span>  
<span style="margin-left: 6em">之正弦在心角與正弧與正弦俱同理則</span>  
<span style="margin-left: 6em">弧與弧弦與弦角與角其比例俱等二言</span>  
<span style="margin-left: 6em">三邊等即三角俱等<sub class="note-yuan">一卷五</sub>角之正弦亦等</span>  
<span style="margin-left: 6em">則邊與邊皆若角與角三言己乙丙雜角</span>  
<span style="margin-left: 2em">形三邊形不等則以己乙小邊引長於丁爲乙丁與</span>  
<span style="margin-left: 2em">己丙等丙爲心己爲界作己庚弧又乙爲心丁爲界</span>  
<span style="margin-left: 2em">作丁戊弧末作丁辛甲己兩垂線至乙丙底</span>
