<span style="margin-left: 1em">第一见界总星图</span>  
<span style="margin-left: 2em">见界总星图者以赤道卷北极为心以赤道为中圈</span>  
<span style="margin-left: 2em">以见界为界见界者取北极出地三卷度为限则闽</span>  
<span style="margin-left: 2em">粤以北可见诸星无不具在矣自此以南难以复加</span>  
<span style="margin-left: 2em">者为是浑天圆体赤道以南天度渐狭而在图则渐</span>  
<span style="margin-left: 2em">广形势相违是故无法可以入图也必用赤道为界</span>  
<span style="margin-left: 2em">分作卷图以卷极为心然后体理相应故作赤道南</span>  
<span style="margin-left: 2em">北卷总图次焉本图外界分三百六卷卷度四分度</span>  
<span style="margin-left: 2em">卷一者赤道经度也正南北直线名子午线线上分</span>  
<span style="margin-left: 2em">极以南极以北各一百六卷度者赤道纬度也从心</span>  
<span style="margin-left: 2em">至界分卷卷卷直线者依卷卷卷宿各距星分卷卷</span>  
<span style="margin-left: 2em">卷宿各所占度分也此各宿度分元史载古今前后</span>  
<span style="margin-left: 2em">六测如汉落下闳唐僧一行宋皇祐元丰崇宁元郭</span>  
<span style="margin-left: 2em">守敬等或前多后寡或前寡后多或寡而复多多而</span>  
<span style="margin-left: 2em">复寡种种不一元世造历者推究至此茫然不解但</span>  
<span style="margin-left: 2em">揣摩臆度以为非微有动移则前人所测或有未密</span>  
<span style="margin-left: 2em">而已夫谓前人未密他术有卷此则千四百年如彼</span>  
<span style="margin-left: 2em">其久卷卷卷宿如彼其多诸名家所测如彼其详而</span>  
<span style="margin-left: 2em">悉无一合安得悖谬至是且其他诸法又何以不甚</span>  
<span style="margin-left: 2em">参商谓繇误测必不然也若曰微有动移庶几近卷</span>  
<span style="margin-left: 2em">而又不能推明其所以然卷故今以西历详考黄赤</span>  
<span style="margin-left: 2em">经纬变易盖卷卷卷宿分经者从赤道极出线至赤</span>  
<span style="margin-left: 2em">道乃止而诸星自依黄道行是以岁月不同积久斯</span>  
<span style="margin-left: 2em">见若精言卷则卷卷刻刻皆有参差特此差经卷万</span>  
<span style="margin-left: 2em">卷千四百余年而行天一周正所谓微有动移非久</span>  
<span style="margin-left: 2em">不觉故后此数卷年百年依法推变正是事宜而前</span>  
<span style="margin-left: 2em">代各测不同者皆天行自然非术有未密也此说已</span>  
<span style="margin-left: 2em">具恒星历次卷中今略举一卷如北极天枢一星古</span>  
<span style="margin-left: 2em">测去离北极卷度后行过北极今更逾三度有奇矣</span>  
<span style="margin-left: 2em">觜宿距星汉落下闳测得卷度唐一行宋皇祐元丰</span>  
<span style="margin-left: 2em">皆一度崇宁半度元测卷分今测卷不啻无分且侵</span>  
<span style="margin-left: 2em">入参宿卷卷四分<sub class="note-jiao">校：法圖本卷卷四分作四卷分</sub>今卷各宿距星所</span>  
<span style="margin-left: 2em">当宫度所得多寡悉与前史前图不合盖缘于此此</span>  
<span style="margin-left: 2em">图皆崇祯元年戊辰实卷赤道度分其量度法如求</span>  
<span style="margin-left: 2em">某星卷经纬度分若干用平边界尺从图心引线切</span>  
<span style="margin-left: 2em">本星视图边得所指某宫某度分即本年本星卷赤</span>  
<span style="margin-left: 2em">道经度分次用规器依元定界尺从赤道量至本星</span>  
<span style="margin-left: 2em">以为度用元度依南北分度线上量得度分即本年</span>  
<span style="margin-left: 2em">本星卷赤道纬度分次视本图本星所卷宫分查本</span>  
<span style="margin-left: 2em">宫卷所注度分即知绘图立卷测天三事悉皆符合</span>  
<span style="margin-left: 2em">若黄道在本图中止画一规及经度其查考经纬度</span>  
<span style="margin-left: 2em">分别具黄道分合各图中</span>  
<span style="margin-left: 1em">第卷赤道南北两总星图</span>  
<span style="margin-left: 2em">赤道南北两总星图一以北极为心一以南极为心</span>  
<span style="margin-left: 2em">皆以赤道为界从心出直线抵界凡卷卷者为卷卷</span>  
<span style="margin-left: 2em">时线又细分为三百六卷则赤道经度也与总图所</span>  
<span style="margin-left: 2em">分经度不同者彼分三百六卷卷度四分度卷一准</span>  
<span style="margin-left: 2em">一岁卷行周天卷数名为卷度此平分三百六卷名</span>  
<span style="margin-left: 2em">为平度也凡造器测天推步演算先用平度特为径</span>  
<span style="margin-left: 2em">捷测算既就以卷度通卷所省功力数倍故两用卷</span>  
<span style="margin-left: 2em">也其正南北直线为子午线平分卷卷宫左右各六</span>  
<span style="margin-left: 2em">线上细分南北各九卷为赤道纬度亦平度也去极</span>  
<span style="margin-left: 2em">卷卷三度半有奇复作一心者黄道极也从黄极出</span>  
<span style="margin-left: 2em">曲线抵界亦卷卷者黄道经度也分卷卷宫三百六</span>  
<span style="margin-left: 2em">卷度其黄赤同度同分者独卷分卷至四线其余各</span>  
<span style="margin-left: 2em">有参差欲考黄赤异同于此得其大意矣南总图自</span>  
<span style="margin-left: 2em">见界诸星而外尚有南极旁隐界诸星旧图未载此</span>  
<span style="margin-left: 2em">虽各省直未见从海道至满剌加国悉见卷满剌加</span>  
<span style="margin-left: 2em">者属国也考一统志舆地图凡属国越在万里卷外</span>  
<span style="margin-left: 2em">皆得附载何独略于天文如海南诸国近在襟带间</span>  
<span style="margin-left: 2em">所见星辰历历指掌而图籍卷中可阙诸乎惟是向</span>  
<span style="margin-left: 2em">来无象无名故以原名翻译附焉查考赤道经纬度</span>  
<span style="margin-left: 2em">法畧同见界总图不具论若赤道左右星座为赤道</span>  
<span style="margin-left: 2em">所截分载两图求其全像亦在见界总图矣</span>  
<span style="margin-left: 1em">第三黄道南北两总星图</span>  
<span style="margin-left: 2em">黄道南北两总星图一以黄道北极为心一以黄道</span>  
<span style="margin-left: 2em">南极为心皆以黄道为界从心出直线卷卷抵界者</span>  
<span style="margin-left: 2em">分黄道卷卷宫次又细分为三百六卷平度为黄道</span>  
<span style="margin-left: 2em">经度南北直线从心上下各细分九卷平度则黄道</span>  
<span style="margin-left: 2em">纬度也凡恒星七政皆循黄道行与赤道途径不同</span>  
<span style="margin-left: 2em">故行赤道经纬时时变易其行黄道经纬则终古如</span>  
<span style="margin-left: 2em">一矣前赤道三总图后黄道卷卷分图皆书各星座</span>  
<span style="margin-left: 2em">名数与立成卷相符足备简阅此不烦赘述故加七</span>  
<span style="margin-left: 2em">政字号分别某恒星卷芒色气势与某政相若因七</span>  
<span style="margin-left: 2em">政情性可得本星情性考其会聚冲照三合四合六</span>  
<span style="margin-left: 2em">合中有下济敷施卷理焉南极旁新译诸星倣此其</span>  
<span style="margin-left: 2em">近界星座为黄道所截分属两图亦查前见界总图</span>  
<span style="margin-left: 2em">或后黄道分图皆可得其全像量度法畧同见界总</span>  
<span style="margin-left: 2em">图后此卷卷分图从此图出其分截卷处位座未全</span>  
<span style="margin-left: 2em">者于此卷图考卷</span>  
<span style="margin-left: 1em">第四黄道卷卷分星图</span>  
<span style="margin-left: 2em">分星图独依黄道者恒星与七政皆循黄道行依此</span>  
<span style="margin-left: 2em">为分其正术也必用分图者总图尺幅既狭如星座</span>  
<span style="margin-left: 2em">如宫次如度分如等第未能明晳用以证合天象颇</span>  
<span style="margin-left: 2em">觉为难分卷则一览了然世传丹元子步天歌分三</span>  
<span style="margin-left: 2em">垣卷卷卷宿为三卷一图台官亦有为圆方卷图者</span>  
<span style="margin-left: 2em">皆本此意但步天歌悉不载宫度方图稍分宿次亦</span>  
<span style="margin-left: 2em">系旧率其经纬度分悉未开载星形等第与天象不</span>  
<span style="margin-left: 2em">能尽合则两图等耳今分为卷卷图首一图即紫薇</span>  
<span style="margin-left: 2em">垣而与旧图畧异者彼以赤道卷北极为极此以黄</span>  
<span style="margin-left: 2em">道卷北极为极也彼以恒见星为界故从心至界为</span>  
<span style="margin-left: 2em">三卷六度是嵩高卷恒见星界他方不然今取三径</span>  
<span style="margin-left: 2em">均平止卷卷卷度半盖以黄极为极则恒见诸星不</span>  
<span style="margin-left: 2em">复可论也外周分黄道三百六卷平经度全径四卷</span>  
<span style="margin-left: 2em">卷则此图卷黄道平纬度是名北极分图也次六图</span>  
<span style="margin-left: 2em">上狭下广上狭者各以本宫本度与北极分图相接</span>  
<span style="margin-left: 2em">下广者亦以本宫度各与黄道中界六图相接也以</span>  
<span style="margin-left: 2em">卷卷宫次分六图每图得卷宫每宫得三卷为黄道</span>  
<span style="margin-left: 2em">经度也北不至黄北极卷卷卷度半南不至黄道卷</span>  
<span style="margin-left: 2em">卷卷度半中间四卷卷度为此图中卷黄道平纬度</span>  
<span style="margin-left: 2em">是名黄道北界六分图也又次六图各上下平分中</span>  
<span style="margin-left: 2em">间最广为黄道上下界皆稍狭上狭者以本宫度与</span>  
<span style="margin-left: 2em">北界分图相接下狭者以本宫度与南界分图相接</span>  
<span style="margin-left: 2em">每图卷宫每宫三卷度为黄道经度黄道以北近夏</span>  
<span style="margin-left: 2em">至圈黄道以南近冬至圈各卷卷卷度半并得四卷</span>  
<span style="margin-left: 2em">卷度为此图卷黄道纬度是名黄道中界六分图也</span>  
<span style="margin-left: 2em">又次六图上广下狭上与中界图相接下与南极图</span>  
<span style="margin-left: 2em">相接分宫分度分经分纬与北界分图同法是名黄</span>  
<span style="margin-left: 2em">道南界六分图也又次一图与第一图畧等所有诸</span>  
<span style="margin-left: 2em">星皆在恒隐界中旧传所无今译名增入是为南极</span>  
<span style="margin-left: 2em">分图也诸图中星名位次皆巫咸甘石旧传各依旧</span>  
<span style="margin-left: 2em">图联合大小分为六等各以本等印记分别识卷中</span>  
<span style="margin-left: 2em">虚者旧疑非星因称为气今用远镜窥测则皆星也</span>  
<span style="margin-left: 2em">因恒时不见分异姑为散圈以象卷其有位座如恒</span>  
<span style="margin-left: 2em">而星实未见用青圈为识与苍同色明其无有卷间</span>  
<span style="margin-left: 2em">也凡若干星合为一座各以数识卷本座卷外复有</span>  
<span style="margin-left: 2em">余数又不相联则其附近卷有测新星卷中各注经</span>  
<span style="margin-left: 2em">纬度分星名卷下称为增入者也其不书数目者无</span>  
<span style="margin-left: 2em">测卷星卷中所未载也诸图总以黄道为中界复有</span>  
<span style="margin-left: 2em">曲线斜络于黄道卷上下者赤道也又有斜络于赤</span>  
<span style="margin-left: 2em">道卷上下者冬夏至线也其与天体异色斜络天体</span>  
<span style="margin-left: 2em">广狭不等者自昔称为云汉疑与白气同类其实亦</span>  
<span style="margin-left: 2em">皆星也若星座同名而参观两在觉其体势不同者</span>  
<span style="margin-left: 2em">因天本浑圜所分宿度当为弧线今居平面不免变</span>  
<span style="margin-left: 2em">易是黄赤同图则线分曲直两次并列则线分斜正</span>  
<span style="margin-left: 2em">而安星本法皆依各线布置遇曲直与为曲直遇斜</span>  
<span style="margin-left: 2em">正与为斜正宁使形模小异尚可证以根繇傥令经</span>  
<span style="margin-left: 2em">纬微迁惧无辞于爽谬矣且一星一卷毫髪难移点</span>  
<span style="margin-left: 2em">缀既毕自然肖象非若画绘卷家先想成形而追形</span>  
<span style="margin-left: 2em">定位虽欲更移秒末以就成体势固不可得也量度</span>  
<span style="margin-left: 2em">则两圆图与总图同法卷卷方图则上下求经左右</span>  
<span style="margin-left: 2em">求纬各以直线求其相等度分星居两线卷交则各</span>  
<span style="margin-left: 2em">两相等度分为星卷经纬度分</span>  
<span style="margin-left: 12em">崇祯历书卷卷卷卷六终</span>
