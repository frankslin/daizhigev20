<span style="margin-left: 1em"><sub class="note-yuan">　　　　　　　　　　　　　　　　　　　　陳于階鄭洪猷</sub></span>  
<span style="margin-left: 1em">第一見界總星圖</span>  
<span style="margin-left: 2em">見界總星圖者以赤道之北極爲心以赤道爲中圈</span>  
<span style="margin-left: 2em">以見界爲界見界者取北極出地三十度爲限則閩</span>  
<span style="margin-left: 2em">粤以北可見諸星無不具在矣自此以南難以復加</span>  
<span style="margin-left: 2em">者爲是渾天圓體赤道以南天度漸狹而在圖則漸</span>  
<span style="margin-left: 2em">廣形勢相違是故無法可以入圖也必用赤道爲界</span>  
<span style="margin-left: 2em">分作二圖以二極爲心然後體理相應故作赤道南</span>  
<span style="margin-left: 2em">北二總圖次焉本圖外界分三百六十五度四分度</span>  
<span style="margin-left: 2em">之一者赤道經度也正南北直線名子午線線上分</span>  
<span style="margin-left: 2em">極以南極以北各一百六十度者赤道緯度也從心</span>  
<span style="margin-left: 2em">至界分二十八直線者依二十八宿各距星分二十</span>  
<span style="margin-left: 2em">八宿各所占度分也此各宿度分元史載古今前後</span>  
<span style="margin-left: 2em">六測如漢落下閎唐僧一行宋皇祐元豐崇寧元郭</span>  
<span style="margin-left: 2em">守敬等或前多後寡或前寡後多或寡而復多多而</span>  
<span style="margin-left: 2em">復寡種種不一元世造曆者推究至此茫然不解但</span>  
<span style="margin-left: 2em">揣摩臆度以爲非微有動移則前人所測或有未密</span>  
<span style="margin-left: 2em">而已夫謂前人未密他術有之此則千四百年如彼</span>  
<span style="margin-left: 2em">其久二十八宿如彼其多諸名家所測如彼其詳而</span>  
<span style="margin-left: 2em">悉無一合安得悖謬至是且其他諸法又何以不甚</span>  
<span style="margin-left: 2em">參商謂繇誤測必不然也若曰微有動移庶幾近之</span>  
<span style="margin-left: 2em">而又不能推明其所以然之故今以西曆詳考黃赤</span>  
<span style="margin-left: 2em">經緯變易蓋二十八宿分經者從赤道極出線至赤</span>  
<span style="margin-left: 2em">道乃止而諸星自依黃道行是以歲月不同積久斯</span>  
<span style="margin-left: 2em">見若精言之則日日刻刻皆有參差特此差經二萬</span>  
<span style="margin-left: 2em">五千四百餘年而行天一周正所謂微有動移非久</span>  
<span style="margin-left: 2em">不覺故後此數十年百年依法推變正是事宜而前</span>  
<span style="margin-left: 2em">代各測不同者皆天行自然非術有未密也此說已</span>  
<span style="margin-left: 2em">具恆星曆次卷中今略舉一二如北極天樞一星古</span>  
<span style="margin-left: 2em">測去離北極二度後行過北極今更踰三度有奇矣</span>  
<span style="margin-left: 2em">觜宿距星漢落下閎測得二度唐一行宋皇祐元豐</span>  
<span style="margin-left: 2em">皆一度崇寧半度元測五分今測之不啻無分且侵</span>  
<span style="margin-left: 2em">入參宿二十四分<sub class="note-jiao">校：法圖本二十四分作四十分</sub>今之各宿距星所</span>  
<span style="margin-left: 2em">當宫度所得多寡悉與前史前圖不合蓋緣于此此</span>  
<span style="margin-left: 2em">圖皆崇禎元年戊辰實躔赤道度分其量度法如求</span>  
<span style="margin-left: 2em">某星之經緯度分若干用平邊界尺從圖心引線切</span>  
<span style="margin-left: 2em">本星視圖邊得所指某宫某度分即本年本星之赤</span>  
<span style="margin-left: 2em">道經度分次用規器依元定界尺從赤道量至本星</span>  
<span style="margin-left: 2em">以爲度用元度依南北分度線上量得度分即本年</span>  
<span style="margin-left: 2em">本星之赤道緯度分次視本圖本星所躔宫分查本</span>  
<span style="margin-left: 2em">宫表所註度分即知繪圖立表測天三事悉皆符合</span>  
<span style="margin-left: 2em">若黃道在本圖中止畫一規及經度其查考經緯度</span>  
<span style="margin-left: 2em">分別具黃道分合各圖中</span>  
<span style="margin-left: 1em">第二赤道南北兩總星圖</span>  
<span style="margin-left: 2em">赤道南北兩總星圖一以北極爲心一以南極爲心</span>  
<span style="margin-left: 2em">皆以赤道爲界從心出直線抵界凡十二者爲十二</span>  
<span style="margin-left: 2em">時線又細分爲三百六十則赤道經度也與總圖所</span>  
<span style="margin-left: 2em">分經度不同者彼分三百六十五度四分度之一準</span>  
<span style="margin-left: 2em">一歲日行周天之數名爲日度此平分三百六十名</span>  
<span style="margin-left: 2em">爲平度也凡造器測天推步演算先用平度特爲徑</span>  
<span style="margin-left: 2em">捷測算既就以日度通之所省功力數倍故兩用之</span>  
<span style="margin-left: 2em">也其正南北直線爲子午線平分十二宫左右各六</span>  
<span style="margin-left: 2em">線上細分南北各九十爲赤道緯度亦平度也去極</span>  
<span style="margin-left: 2em">二十三度半有奇復作一心者黃道極也從黃極出</span>  
<span style="margin-left: 2em">曲線抵界亦十二者黃道經度也分十二宫三百六</span>  
<span style="margin-left: 2em">十度其黃赤同度同分者獨二分二至四線其餘各</span>  
<span style="margin-left: 2em">有參差欲考黃赤異同于此得其大意矣南總圖自</span>  
<span style="margin-left: 2em">見界諸星而外尚有南極旁隱界諸星舊圖未載此</span>  
<span style="margin-left: 2em">雖各省直未見從海道至滿剌加國悉見之滿剌加</span>  
<span style="margin-left: 2em">者屬國也考一統志輿地圖凡屬國越在萬里之外</span>  
<span style="margin-left: 2em">皆得附載何獨略于天文如海南諸國近在襟帶間</span>  
<span style="margin-left: 2em">所見星辰曆曆指掌而圖籍之中可闕諸乎惟是向</span>  
<span style="margin-left: 2em">来無象無名故以原名翻譯附焉查考赤道經緯度</span>  
<span style="margin-left: 2em">法畧同見界總圖不具論若赤道左右星座爲赤道</span>  
<span style="margin-left: 2em">所截分載兩圖求其全像亦在見界總圖矣</span>  
<span style="margin-left: 1em">第三黃道南北兩總星圖</span>  
<span style="margin-left: 2em">黃道南北兩總星圖一以黃道北極爲心一以黃道</span>  
<span style="margin-left: 2em">南極爲心皆以黃道爲界從心出直線十二抵界者</span>  
<span style="margin-left: 2em">分黃道十二宫次又細分爲三百六十平度爲黃道</span>  
<span style="margin-left: 2em">經度南北直線從心上下各細分九十平度則黃道</span>  
<span style="margin-left: 2em">緯度也凡恆星七政皆循黃道行與赤道途徑不同</span>  
<span style="margin-left: 2em">故行赤道經緯時時變易其行黃道經緯則終古如</span>  
<span style="margin-left: 2em">一矣前赤道三總圖後黃道二十分圖皆書各星座</span>  
<span style="margin-left: 2em">名數與立成表相符足備簡閲此不煩贅述故加七</span>  
<span style="margin-left: 2em">政字號分別某恆星之芒色氣勢與某政相若因七</span>  
<span style="margin-left: 2em">政情性可得本星情性考其會聚衝照三合四合六</span>  
<span style="margin-left: 2em">合中有下濟敷施之理焉南極旁新譯諸星倣此其</span>  
<span style="margin-left: 2em">近界星座爲黃道所截分屬兩圖亦查前見界總圖</span>  
<span style="margin-left: 2em">或後黃道分圖皆可得其全像量度法畧同見界總</span>  
<span style="margin-left: 2em">圖後此二十分圖從此圖出其分截之處位座未全</span>  
<span style="margin-left: 2em">者於此二圖考之</span>  
<span style="margin-left: 1em">第四黃道二十分星圖</span>  
<span style="margin-left: 2em">分星圖獨依黃道者恆星與七政皆循黃道行依此</span>  
<span style="margin-left: 2em">爲分其正術也必用分圖者總圖尺幅既狹如星座</span>  
<span style="margin-left: 2em">如宫次如度分如等第未能明晳用以證合天象頗</span>  
<span style="margin-left: 2em">覺爲難分之則一覽瞭然世傳丹元子步天歌分三</span>  
<span style="margin-left: 2em">垣二十八宿爲三十一圖臺官亦有爲圓方二圖者</span>  
<span style="margin-left: 2em">皆本此意但步天歌悉不載宫度方圖稍分宿次亦</span>  
<span style="margin-left: 2em">係舊率其經緯度分悉未開載星形等第與天象不</span>  
<span style="margin-left: 2em">能盡合則兩圖等耳今分爲二十圖首一圖即紫薇</span>  
<span style="margin-left: 2em">垣而與舊圖畧異者彼以赤道之北極爲極此以黃</span>  
<span style="margin-left: 2em">道之北極爲極也彼以恆見星爲界故從心至界爲</span>  
<span style="margin-left: 2em">三十六度是嵩高之恆見星界他方不然今取三徑</span>  
<span style="margin-left: 2em">均平止二十二度半蓋以黃極爲極則恆見諸星不</span>  
<span style="margin-left: 2em">復可論也外周分黃道三百六十平經度全徑四十</span>  
<span style="margin-left: 2em">五則此圖之黃道平緯度是名北極分圖也次六圖</span>  
<span style="margin-left: 2em">上狹下廣上狹者各以本宫本度與北極分圖相接</span>  
<span style="margin-left: 2em">下廣者亦以本宫度各與黃道中界六圖相接也以</span>  
<span style="margin-left: 2em">十二宫次分六圖每圖得二宫每宫得三十爲黃道</span>  
<span style="margin-left: 2em">經度也北不至黃北極二十二度半南不至黃道二</span>  
<span style="margin-left: 2em">十二度半中間四十五度爲此圖中之黃道平緯度</span>  
<span style="margin-left: 2em">是名黃道北界六分圖也又次六圖各上下平分中</span>  
<span style="margin-left: 2em">間最廣爲黃道上下界皆稍狹上狹者以本宫度與</span>  
<span style="margin-left: 2em">北界分圖相接下狹者以本宫度與南界分圖相接</span>  
<span style="margin-left: 2em">每圖二宫每宫三十度爲黃道經度黃道以北近夏</span>  
<span style="margin-left: 2em">至圈黃道以南近冬至圈各二十二度半并得四十</span>  
<span style="margin-left: 2em">五度爲此圖之黃道緯度是名黃道中界六分圖也</span>  
<span style="margin-left: 2em">又次六圖上廣下狹上與中界圖相接下與南極圖</span>  
<span style="margin-left: 2em">相接分宫分度分經分緯與北界分圖同法是名黃</span>  
<span style="margin-left: 2em">道南界六分圖也又次一圖與第一圖畧等所有諸</span>  
<span style="margin-left: 2em">星皆在恆隱界中舊傳所無今譯名增入是爲南極</span>  
<span style="margin-left: 2em">分圖也諸圖中星名位次皆巫咸甘石舊傳各依舊</span>  
<span style="margin-left: 2em">圖聯合大小分爲六等各以本等印記分別識之中</span>  
<span style="margin-left: 2em">虛者舊疑非星因稱爲氣今用遠鏡窺測則皆星也</span>  
<span style="margin-left: 2em">因恆時不見分異姑爲散圈以象之其有位座如恆</span>  
<span style="margin-left: 2em">而星實未見用青圈爲識與蒼同色明其無有之間</span>  
<span style="margin-left: 2em">也凡若干星合爲一座各以數識之本座之外復有</span>  
<span style="margin-left: 2em">餘數又不相聯則其附近之有測新星表中各註經</span>  
<span style="margin-left: 2em">緯度分星名之下稱爲增入者也其不書數目者無</span>  
<span style="margin-left: 2em">測之星表中所未載也諸圖總以黃道爲中界復有</span>  
<span style="margin-left: 2em">曲線斜絡于黃道之上下者赤道也又有斜絡于赤</span>  
<span style="margin-left: 2em">道之上下者冬夏至線也其與天體異色斜絡天體</span>  
<span style="margin-left: 2em">廣狹不等者自昔稱爲雲漢疑與白氣同類其實亦</span>  
<span style="margin-left: 2em">皆星也若星座同名而參觀兩在覺其體勢不同者</span>  
<span style="margin-left: 2em">因天本渾圜所分宿度當爲弧線今居平面不免變</span>  
<span style="margin-left: 2em">易是黃赤同圖則線分曲直兩次並列則線分斜正</span>  
<span style="margin-left: 2em">而安星本法皆依各線布置遇曲直與爲曲直遇斜</span>  
<span style="margin-left: 2em">正與爲斜正寧使形模小異尚可證以根繇儻令經</span>  
<span style="margin-left: 2em">緯微遷懼無辭於爽謬矣且一星一表毫髪難移點</span>  
<span style="margin-left: 2em">綴既畢自然肖象非若畫繪之家先想成形而追形</span>  
<span style="margin-left: 2em">定位雖欲更移秒末以就成體勢固不可得也量度</span>  
<span style="margin-left: 2em">則兩圓圖與總圖同法十八方圖則上下求經左右</span>  
<span style="margin-left: 2em">求緯各以直線求其相等度分星居兩線之交則各</span>  
<span style="margin-left: 2em">兩相等度分爲星之經緯度分</span>  
<span style="margin-left: 12em">崇禎曆書卷之八十六終</span>
