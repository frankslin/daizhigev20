## 崇禎曆書卷之一百六十九　日晷圖法卷二

<span style="margin-left: 1em">日晷圖法卷二</span>  
<span style="margin-left: 1em">第一題作平晷第一法</span>  
<span style="margin-left: 1em">此晷畫于地平或與地平平行之面故名曰平晷畫晷</span>  
<span style="margin-left: 1em">之體若定不移則先須以　卷第一測其面與地平平</span>  
<span style="margin-left: 1em">否少偏則時刻不能準也若體不定則用時亦須置極</span>  
<span style="margin-left: 1em">平無偏然後表景指節氣及時刻俱無爽也其圖式及</span>  
<span style="margin-left: 1em">後諸晷之圖式皆以京師極出地四十度爲主</span>  
<span style="margin-left: 1em">先作甲乙垂線爲子午線次作丙丁橫線兩線交于戊</span>  
<span style="margin-left: 1em">爲表位次量晷小大取一度爲表長晷小表長則日出</span>  
<span style="margin-left: 17em">後入前數刻</span>  
<span style="margin-left: 17em">表端景俱在</span>  
<span style="margin-left: 17em">晷外不能指</span>  
<span style="margin-left: 17em">節氣時刻也</span>  
<span style="margin-left: 17em">次以表長爲</span>  
<span style="margin-left: 17em">度從戊石行</span>  
<span style="margin-left: 17em">得己即以己</span>  
<span style="margin-left: 17em">爲心向子午</span>  
<span style="margin-left: 17em">線任作艮土</span>  
<span style="margin-left: 17em">半圈交丙丁</span>  
<span style="margin-left: 1em">線于革次從革丙上量本地極出度如京師四十度爲</span>  
<span style="margin-left: 1em">土即作土己線與子午線交于辛次從辛與丙丁線平</span>  
<span style="margin-left: 1em">行作竹云線爲赤道線次從革向艮量極出地之餘度</span>  
<span style="margin-left: 1em">如京師四十度之餘五十度爲艮即作艮己線與子午</span>  
<span style="margin-left: 1em">線交于甘甘點即晷心衆時刻所聚也次從甘與丙丁</span>  
<span style="margin-left: 1em">線平行作庚石線爲卯酉線次以己辛爲度從辛依子</span>  
<span style="margin-left: 1em">午線下行得元即以元爲心任作弓牙坎仁圈平分爲</span>  
<span style="margin-left: 1em">九十六分或其半爲四十八分亦可次以元與圈分俱</span>  
<span style="margin-left: 1em">相望<sub class="note-yuan">凡言相望皆言界尺切圈心與圈分或切此線識及彼線識不必作他線</sub>每至赤道交</span>  
<span style="margin-left: 1em">處即作識次以甘與赤道上各識相望俱作斜線即時</span>  
<span style="margin-left: 1em">刻線矣其午右線皆午前時午左線皆午後時<sub class="note-yuan">本宜每時八刻</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">每刻一線兹圖四刻作一線者恐圖小線多易混以後凡圖式皆仿此</sub>第赤道上近子午</span>  
<span style="margin-left: 1em">十二刻之識其交赤道尚直易于取準十二刻以外之</span>  
<span style="margin-left: 1em">識<sub class="note-jiao">校：十二刻原作十二則據天理本改</sub>其交太斜難以取準故宜用別法</span>  
<span style="margin-left: 1em">法曰以辛至甘爲度從元向甘得尺從尺與赤道平行</span>  
<span style="margin-left: 1em">作勺夕線次依前法赤道上作識之時亦并作識予勺</span>  
<span style="margin-left: 1em">夕線以十二爲止不次多作次以辛己爲度于卯酉線</span>  
<span style="margin-left: 1em">上從甘左行右行行斤從斤與子午線平行作斤缶線</span>  
<span style="margin-left: 1em">次從尺至勺夕線上諸識逐一爲度從斤于斤缶線上</span>  
<span style="margin-left: 1em">行下行逐一作識即赤道上第十二識與斤下第十二</span>  
<span style="margin-left: 1em">識相遇于一方驗其無爽也次從甘于斤缶線諸識相</span>  
<span style="margin-left: 1em">望各作斜線即卯酉前後諸時刻線俱定矣</span>  
<span style="margin-left: 1em">尺法亦以己辛爲度從甘于卯酉線或左或右行得斤</span>  
<span style="margin-left: 1em">亦如前法作斤缶線與子午線平行次以辛甘爲度從</span>  
<span style="margin-left: 1em">斤于卯酉線或左或右行得方以方爲心向子午線任</span>  
<span style="margin-left: 1em">作屯止水半圈平分爲四十八分止用卯酉線上下各</span>  
<span style="margin-left: 1em">十二分一刻一分或任三分四刻一分即以方與止上</span>  
<span style="margin-left: 1em">下十二分或三分俱相望每至斤缶線交處即作識次</span>  
<span style="margin-left: 1em">以甘與斤缶線各識相望俱作斜線則卯酉前後各十</span>  
<span style="margin-left: 1em">二刻亦得焉若不用節氣線則以戊己爲表長立表于</span>  
<span style="margin-left: 1em">戊而晷成焉此式既畢乃視各線宜留者深之宜去者</span>  
<span style="margin-left: 1em">礲之此圖式亦可爲作平晷之母也</span>  
<span style="margin-left: 3em">平晷第二法</span>  
<span style="margin-left: 1em">凡欲依前圖式作平晷先備甲乙丙丁平面板次己戊</span>  
<span style="margin-left: 1em">辛橫線爲卯酉線次任作時刻界線或圓或方以待記</span>  
<span style="margin-left: 1em">時刻<sub class="note-yuan">蓋量晷方圓近邊作平行二線爲界使時刻線至此而止</sub>次以規量卯酉線正</span>  
<span style="margin-left: 1em">中于庚從庚立艮土線爲卯酉之垂線即子午線次任</span>  
<span style="margin-left: 1em">用一度從第一式甘爲心作一虛圈即用元度以此式</span>  
<span style="margin-left: 1em">庚爲心亦作虛圈交子午線于云次于第一式虛圈從</span>  
<span style="margin-left: 1em">午線向左右量諸時線交處逐一爲度移于此式虛圈</span>  
<span style="margin-left: 1em">上從云向左右逐一作皿尹諸識次從庚與各式相望</span>  
<span style="margin-left: 1em">俱作線而本晷時刻線皆定矣次以第一式辛戊爲度</span>  
<span style="margin-left: 1em">從庚下行于午線上得坎爲立表之位以第一式戊己</span>  
<span style="margin-left: 1em">爲表長即得坎升爲本晷直表而晷體完矣第立表不</span>  
<span style="margin-left: 1em">正則時刻不準欲得正表法則依第一卷二十一法以</span>  
<span style="margin-left: 1em">坎升表長爲度自坎上行作識爲仁從仁作卯酉平行</span>  
<span style="margin-left: 1em">短線次以表長爲度從仁向兩旁各作識右爲尺左爲</span>  
<span style="margin-left: 1em">勺次作坎尺坎勺兩斜線次以表長爲度從坎向尺得</span>  
<span style="margin-left: 1em">石向勺得元而正表三角形畢矣凡立表之時用規以</span>  
<span style="margin-left: 1em">尺元或勺石爲度從尺勺各向表端量之令表端兩俱</span>  
<span style="margin-left: 1em">相遇則表正矣否則須再正之</span>  
<span style="margin-left: 1em">第直表景長其本<sub class="note-jiao">校：其本天理本作其末</sub>不顯則指時亦難準切</span>  
<span style="margin-left: 1em">須用線代之線一端繫于庚即子午卯酉相交之處次</span>  
<span style="margin-left: 1em">引線令與平面作銳角隨本地極出度以爲高下假如</span>  
<span style="margin-left: 1em">京師極出地四十度即以庚爲心任作弓牙圈分從牙</span>  
<span style="margin-left: 1em">上行量四十度于弓線必經此四十度之識也若立得</span>  
<span style="margin-left: 1em">直表于坎線亦必切過表端也次于平晷板之北時刻</span>  
<span style="margin-left: 1em">線之外立一板或一柱聯于晷板而與晷板作直角或</span>  
<span style="margin-left: 1em">可闔闢或不可闔闢其上端鑽一細孔以繫線如右圖</span>  
<span style="margin-left: 1em">庚世爲線世缶爲柱線之一端繫于庚一繫于世篇世</span>  
<span style="margin-left: 1em">孔<sub class="note-jiao">校：天理本篇作第</sub>須正對平面上午線方得不謬而從晷面</span>  
<span style="margin-left: 1em">以量柱上未必確準則于他紙橫作司古線以當午線</span>  
<span style="margin-left: 1em">以司爲心任作古介圈分從古向上量四十度于介即</span>  
<span style="margin-left: 1em">作介司線次以晷心庚向兩板交處爲度從司向古得</span>  
<span style="margin-left: 1em">丘次從丘作司古線之垂線以當竪柱或竪板交介司</span>  
<span style="margin-left: 1em">線于卉即卉爲繫線之孔處也次以卉至丘爲度從午</span>  
<span style="margin-left: 1em">竪兩板交角向竪板或柱上與午線正相對處作識即</span>  
<span style="margin-left: 1em">鑽孔繫線之所也若不用節氣即于平面南端開孔如</span>  
<span style="margin-left: 1em">艮庚圈以設羅經次以羅經定向方則表端表線景即</span>  
<span style="margin-left: 1em">指時刻焉</span>  
<span style="margin-left: 3em">平晷第三法</span>  
<span style="margin-left: 1em">若欲加節氣先作甲乙橫線爲極線次作丙丁垂線爲</span>  
<span style="margin-left: 1em">赤道線兩線相遇于丙次于赤道左右依一卷十八分</span>  
<span style="margin-left: 1em">節氣氣線次以<sub class="note-jiao">校：天理本以作戊</sub>第一式己至甘爲度從丙左</span>  
<span style="margin-left: 1em">行得以復以第一式己至辛爲度從丙下行得己即以</span>  
<span style="margin-left: 1em">戊己相望作斜線即子午線也更以戊爲心向丙外任</span>  
<span style="margin-left: 1em">作庚辛圈分自子午線至極線定爲極出地度稍差即</span>  
<span style="margin-left: 1em">不準也次以第一式元向赤道各識逐一爲度從丙向</span>  
<span style="margin-left: 1em">下于赤道線<sub class="note-jiao">校：天理本亦道作赤道據此改</sub>上逐一作識即以戊與各</span>  
<span style="margin-left: 1em">識相望作線即得衆時刻線也其從戊與赤道平行者</span>  
<span style="margin-left: 17em">即卯酉線若</span>  
<span style="margin-left: 17em">欲作卯酉左</span>  
<span style="margin-left: 17em">時刻則從戊</span>  
<span style="margin-left: 17em">向下作半圈</span>  
<span style="margin-left: 17em">以卯酉線右</span>  
<span style="margin-left: 17em">交于圈者移</span>  
<span style="margin-left: 17em">之左圈作識</span>  
<span style="margin-left: 17em">從戊與各識</span>  
<span style="margin-left: 17em">作線即得但</span>  
<span style="margin-left: 17em">時刻線有與</span>  
<span style="margin-left: 1em">赤道交遠者則太斜難準更有一法于卯酉線上從戊</span>  
<span style="margin-left: 1em">下行任指一點爲云從云作云竹線與甲乙平行交午</span>  
<span style="margin-left: 1em">線于竹即以云爲心竹爲界作竹壬艮圈從竹或壬艮</span>  
<span style="margin-left: 1em">起平分爲九十六分即以圈分竹云線上下直望每至</span>  
<span style="margin-left: 1em">云竹線交處即作識次以戊與各識相望作線即得衆</span>  
<span style="margin-left: 1em">時刻線也</span>  
<span style="margin-left: 3em">平晷第四法</span>  
<span style="margin-left: 1em">此式乃有節氣平晷成式也其法橫作甲乙線爲卯酉</span>  
<span style="margin-left: 1em">線即于其上直作丙丁垂線爲午線兩線相遇于丙次</span>  
<span style="margin-left: 1em">以第一式甘至辛爲度從丙向丁得庚即從庚作線與</span>  
<span style="margin-left: 9em">甲乙平行爲赤道線次以第一式</span>  
<span style="margin-left: 9em">自辛至左右線記逐一爲度從庚</span>  
<span style="margin-left: 9em">左右逐一作識即以丙與各識相</span>  
<span style="margin-left: 9em">望俱作虛線或以丙爲心任作虛</span>  
<span style="margin-left: 9em">圈即用元度于第一式上以甘爲</span>  
<span style="margin-left: 9em">心亦作虛圈次以第一式虛圈上</span>  
<span style="margin-left: 9em">午旁線分逐一爲度移至本式虛</span>  
<span style="margin-left: 9em">圈上子午線左右逐一作識亦以</span>  
<span style="margin-left: 9em">丙與各識相望作線則卯酉子午</span>  
<span style="margin-left: 9em">前後刻線俱定矣次以第三式自</span>  
<span style="margin-left: 1em">戊循午線斜行至與夏至交處爲度從丙下行午線上</span>  
<span style="margin-left: 1em">作識即夏至午正表景所至也次如前以第三式量午</span>  
<span style="margin-left: 1em">未初線至與夏至線交處爲度亦如前從丙于午線左</span>  
<span style="margin-left: 1em">右各第二線斜行作識即夏至午未初初刻表景所至</span>  
<span style="margin-left: 1em">也次己辰申卯酉皆如之而各時線上夏至線界定矣</span>  
<span style="margin-left: 1em">次又以第二式從戊至小暑及芒種交處爲度從丙下</span>  
<span style="margin-left: 1em">行午線上作識即小暑芒種初日午正表景所至也大</span>  
<span style="margin-left: 1em">暑小滿立秋立夏等節氣皆以是法逐一量之則各氣</span>  
<span style="margin-left: 1em">各時無不定矣次以一卷第二十依時刻上之識作曲</span>  
<span style="margin-left: 1em">線即太陽行諸節氣初日之表景所至線也今以圖紙</span>  
<span style="margin-left: 1em">隘恐線混持缶節作一曲線初日以後十四日至次節</span>  
<span style="margin-left: 1em">氣線表景必射兩節線之間夏至以後景日長冬至以</span>  
<span style="margin-left: 1em">後景日短也次爲定表法量第一式甘至戊爲度從丙</span>  
<span style="margin-left: 1em">下行得辛即立表位也次量第一式戊至己爲度從辛</span>  
<span style="margin-left: 1em">右行得艮即表長也此立表法也次依第一卷二十一</span>  
<span style="margin-left: 1em">正表捷法以求其正而晷成矣</span>  
<span style="margin-left: 1em">第二定節線界識捷法</span>  
<span style="margin-left: 1em">但右法太煩故又有捷法凡各晷之子午線及偏晷之</span>  
<span style="margin-left: 1em">表線全與節線相遇者其冬夏至之節線及冬至內之</span>  
<span style="margin-left: 1em">第一線與夏至內之第一線若冬至內之第二三四五</span>  
<span style="margin-left: 1em">線與夏至內之第二三四五線其疎密雖不等而其曲</span>  
<span style="margin-left: 1em">直必各自相等也捷法曰從丙于子午線上先定節氣</span>  
<span style="margin-left: 1em">疎密之位如元爲夏至土爲冬至次以丙元爲度從上</span>  
<span style="margin-left: 1em">下行得竹次依丙心下行所作時刻線亦從竹上行俱</span>  
<span style="margin-left: 1em">作虛線作法則以丙與竹各爲心各作半虛圈而二圈</span>  
<span style="margin-left: 1em">等乃以上圈諸時線從午線左右逐一爲度悉移之下</span>  
<span style="margin-left: 1em">圈亦午線左右逐一作識次從竹與各識相望俱作虛</span>  
<span style="margin-left: 1em">線即得矣或平分丙竹線間于云從云作甘云石線與</span>  
<span style="margin-left: 1em">赤道平行交于丙心所出時刻線即以交處各與竹相</span>  
<span style="margin-left: 1em">望俱作虛線亦得也次凡從丙向下行各時線上所定</span>  
<span style="margin-left: 1em">夏至之位逐一爲度亦從竹向上行各時線上作識次</span>  
<span style="margin-left: 1em">依上下識作兩曲線而冬夏兩相等節氣線并定焉<sub class="note-jiao">校：焉</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">原作爲據天理本改</sub>餘曲直相等節氣線皆如之但竹心及上行</span>  
<span style="margin-left: 11em">時線各節氣不同則各須更</span>  
<span style="margin-left: 11em">畫爲法亦煩<sub class="note-jiao">校：煩原作須據天理本改</sub>故</span>  
<span style="margin-left: 11em">又有後法更捷</span>  
<span style="margin-left: 11em">法曰先作甲乙爲午線次于</span>  
<span style="margin-left: 11em">其上依第一法定各節疎密</span>  
<span style="margin-left: 11em">之位假如丁爲夏至己爲冬</span>  
<span style="margin-left: 11em">至之位次于午線或左或右</span>
