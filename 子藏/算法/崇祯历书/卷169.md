## 崇祯历书卷之一百六十九　日晷图法卷二

<span style="margin-left: 1em">日晷图法卷二</span>  
<span style="margin-left: 1em">第一题作平晷第一法</span>  
<span style="margin-left: 1em">此晷画于地平或与地平平行之面故名曰平晷画晷</span>  
<span style="margin-left: 1em">之体若定不移则先须以　卷第一测其面与地平平</span>  
<span style="margin-left: 1em">否少偏则时刻不能准也若体不定则用时亦须置极</span>  
<span style="margin-left: 1em">平无偏然后表景指节气及时刻俱无爽也其图式及</span>  
<span style="margin-left: 1em">后诸晷之图式皆以京师极出地四十度为主</span>  
<span style="margin-left: 1em">先作甲乙垂线为子午线次作丙丁横线两线交于戊</span>  
<span style="margin-left: 1em">为表位次量晷小大取一度为表长晷小表长则日出</span>  
<span style="margin-left: 17em">后入前数刻</span>  
<span style="margin-left: 17em">表端景俱在</span>  
<span style="margin-left: 17em">晷外不能指</span>  
<span style="margin-left: 17em">节气时刻也</span>  
<span style="margin-left: 17em">次以表长为</span>  
<span style="margin-left: 17em">度从戊石行</span>  
<span style="margin-left: 17em">得己即以己</span>  
<span style="margin-left: 17em">为心向子午</span>  
<span style="margin-left: 17em">线任作艮土</span>  
<span style="margin-left: 17em">半圈交丙丁</span>  
<span style="margin-left: 1em">线于革次从革丙上量本地极出度如京师四十度为</span>  
<span style="margin-left: 1em">土即作土己线与子午线交于辛次从辛与丙丁线平</span>  
<span style="margin-left: 1em">行作竹云线为赤道线次从革向艮量极出地之余度</span>  
<span style="margin-left: 1em">如京师四十度之余五十度为艮即作艮己线与子午</span>  
<span style="margin-left: 1em">线交于甘甘点即晷心众时刻所聚也次从甘与丙丁</span>  
<span style="margin-left: 1em">线平行作庚石线为卯酉线次以己辛为度从辛依子</span>  
<span style="margin-left: 1em">午线下行得元即以元为心任作弓牙坎仁圈平分为</span>  
<span style="margin-left: 1em">九十六分或其半为四十八分亦可次以元与圈分俱</span>  
<span style="margin-left: 1em">相望<sub class="note-yuan">凡言相望皆言界尺切圈心与圈分或切此线识及彼线识不必作他线</sub>每至赤道交</span>  
<span style="margin-left: 1em">处即作识次以甘与赤道上各识相望俱作斜线即时</span>  
<span style="margin-left: 1em">刻线矣其午右线皆午前时午左线皆午后时<sub class="note-yuan">本宜每时八刻</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">每刻一线兹图四刻作一线者恐图小线多易混以后凡图式皆仿此</sub>第赤道上近子午</span>  
<span style="margin-left: 1em">十二刻之识其交赤道尚直易于取准十二刻以外之</span>  
<span style="margin-left: 1em">识<sub class="note-jiao">校：十二刻原作十二則據天理本改</sub>其交太斜难以取准故宜用别法</span>  
<span style="margin-left: 1em">法曰以辛至甘为度从元向甘得尺从尺与赤道平行</span>  
<span style="margin-left: 1em">作勺夕线次依前法赤道上作识之时亦并作识予勺</span>  
<span style="margin-left: 1em">夕线以十二为止不次多作次以辛己为度于卯酉线</span>  
<span style="margin-left: 1em">上从甘左行右行行斤从斤与子午线平行作斤缶线</span>  
<span style="margin-left: 1em">次从尺至勺夕线上诸识逐一为度从斤于斤缶线上</span>  
<span style="margin-left: 1em">行下行逐一作识即赤道上第十二识与斤下第十二</span>  
<span style="margin-left: 1em">识相遇于一方验其无爽也次从甘于斤缶线诸识相</span>  
<span style="margin-left: 1em">望各作斜线即卯酉前后诸时刻线俱定矣</span>  
<span style="margin-left: 1em">尺法亦以己辛为度从甘于卯酉线或左或右行得斤</span>  
<span style="margin-left: 1em">亦如前法作斤缶线与子午线平行次以辛甘为度从</span>  
<span style="margin-left: 1em">斤于卯酉线或左或右行得方以方为心向子午线任</span>  
<span style="margin-left: 1em">作屯止水半圈平分为四十八分止用卯酉线上下各</span>  
<span style="margin-left: 1em">十二分一刻一分或任三分四刻一分即以方与止上</span>  
<span style="margin-left: 1em">下十二分或三分俱相望每至斤缶线交处即作识次</span>  
<span style="margin-left: 1em">以甘与斤缶线各识相望俱作斜线则卯酉前后各十</span>  
<span style="margin-left: 1em">二刻亦得焉若不用节气线则以戊己为表长立表于</span>  
<span style="margin-left: 1em">戊而晷成焉此式既毕乃视各线宜留者深之宜去者</span>  
<span style="margin-left: 1em">礲之此图式亦可为作平晷之母也</span>  
<span style="margin-left: 3em">平晷第二法</span>  
<span style="margin-left: 1em">凡欲依前图式作平晷先备甲乙丙丁平面板次己戊</span>  
<span style="margin-left: 1em">辛横线为卯酉线次任作时刻界线或圆或方以待记</span>  
<span style="margin-left: 1em">时刻<sub class="note-yuan">盖量晷方圆近边作平行二线为界使时刻线至此而止</sub>次以规量卯酉线正</span>  
<span style="margin-left: 1em">中于庚从庚立艮土线为卯酉之垂线即子午线次任</span>  
<span style="margin-left: 1em">用一度从第一式甘为心作一虚圈即用元度以此式</span>  
<span style="margin-left: 1em">庚为心亦作虚圈交子午线于云次于第一式虚圈从</span>  
<span style="margin-left: 1em">午线向左右量诸时线交处逐一为度移于此式虚圈</span>  
<span style="margin-left: 1em">上从云向左右逐一作皿尹诸识次从庚与各式相望</span>  
<span style="margin-left: 1em">俱作线而本晷时刻线皆定矣次以第一式辛戊为度</span>  
<span style="margin-left: 1em">从庚下行于午线上得坎为立表之位以第一式戊己</span>  
<span style="margin-left: 1em">为表长即得坎升为本晷直表而晷体完矣第立表不</span>  
<span style="margin-left: 1em">正则时刻不准欲得正表法则依第一卷二十一法以</span>  
<span style="margin-left: 1em">坎升表长为度自坎上行作识为仁从仁作卯酉平行</span>  
<span style="margin-left: 1em">短线次以表长为度从仁向两旁各作识右为尺左为</span>  
<span style="margin-left: 1em">勺次作坎尺坎勺两斜线次以表长为度从坎向尺得</span>  
<span style="margin-left: 1em">石向勺得元而正表三角形毕矣凡立表之时用规以</span>  
<span style="margin-left: 1em">尺元或勺石为度从尺勺各向表端量之令表端两俱</span>  
<span style="margin-left: 1em">相遇则表正矣否则须再正之</span>  
<span style="margin-left: 1em">第直表景长其本<sub class="note-jiao">校：其本天理本作其末</sub>不显则指时亦难准切</span>  
<span style="margin-left: 1em">须用线代之线一端系于庚即子午卯酉相交之处次</span>  
<span style="margin-left: 1em">引线令与平面作锐角随本地极出度以为高下假如</span>  
<span style="margin-left: 1em">京师极出地四十度即以庚为心任作弓牙圈分从牙</span>  
<span style="margin-left: 1em">上行量四十度于弓线必经此四十度之识也若立得</span>  
<span style="margin-left: 1em">直表于坎线亦必切过表端也次于平晷板之北时刻</span>  
<span style="margin-left: 1em">线之外立一板或一柱联于晷板而与晷板作直角或</span>  
<span style="margin-left: 1em">可阖辟或不可阖辟其上端钻一细孔以系线如右图</span>  
<span style="margin-left: 1em">庚世为线世缶为柱线之一端系于庚一系于世篇世</span>  
<span style="margin-left: 1em">孔<sub class="note-jiao">校：天理本篇作第</sub>须正对平面上午线方得不谬而从晷面</span>  
<span style="margin-left: 1em">以量柱上未必确准则于他纸横作司古线以当午线</span>  
<span style="margin-left: 1em">以司为心任作古介圈分从古向上量四十度于介即</span>  
<span style="margin-left: 1em">作介司线次以晷心庚向两板交处为度从司向古得</span>  
<span style="margin-left: 1em">丘次从丘作司古线之垂线以当竖柱或竖板交介司</span>  
<span style="margin-left: 1em">线于卉即卉为系线之孔处也次以卉至丘为度从午</span>  
<span style="margin-left: 1em">竖两板交角向竖板或柱上与午线正相对处作识即</span>  
<span style="margin-left: 1em">钻孔系线之所也若不用节气即于平面南端开孔如</span>  
<span style="margin-left: 1em">艮庚圈以设罗经次以罗经定向方则表端表线景即</span>  
<span style="margin-left: 1em">指时刻焉</span>  
<span style="margin-left: 3em">平晷第三法</span>  
<span style="margin-left: 1em">若欲加节气先作甲乙横线为极线次作丙丁垂线为</span>  
<span style="margin-left: 1em">赤道线两线相遇于丙次于赤道左右依一卷十八分</span>  
<span style="margin-left: 1em">节气气线次以<sub class="note-jiao">校：天理本以作戊</sub>第一式己至甘为度从丙左</span>  
<span style="margin-left: 1em">行得以复以第一式己至辛为度从丙下行得己即以</span>  
<span style="margin-left: 1em">戊己相望作斜线即子午线也更以戊为心向丙外任</span>  
<span style="margin-left: 1em">作庚辛圈分自子午线至极线定为极出地度稍差即</span>  
<span style="margin-left: 1em">不准也次以第一式元向赤道各识逐一为度从丙向</span>  
<span style="margin-left: 1em">下于赤道线<sub class="note-jiao">校：天理本亦道作赤道據此改</sub>上逐一作识即以戊与各</span>  
<span style="margin-left: 1em">识相望作线即得众时刻线也其从戊与赤道平行者</span>  
<span style="margin-left: 17em">即卯酉线若</span>  
<span style="margin-left: 17em">欲作卯酉左</span>  
<span style="margin-left: 17em">时刻则从戊</span>  
<span style="margin-left: 17em">向下作半圈</span>  
<span style="margin-left: 17em">以卯酉线右</span>  
<span style="margin-left: 17em">交于圈者移</span>  
<span style="margin-left: 17em">之左圈作识</span>  
<span style="margin-left: 17em">从戊与各识</span>  
<span style="margin-left: 17em">作线即得但</span>  
<span style="margin-left: 17em">时刻线有与</span>  
<span style="margin-left: 1em">赤道交远者则太斜难准更有一法于卯酉线上从戊</span>  
<span style="margin-left: 1em">下行任指一点为云从云作云竹线与甲乙平行交午</span>  
<span style="margin-left: 1em">线于竹即以云为心竹为界作竹壬艮圈从竹或壬艮</span>  
<span style="margin-left: 1em">起平分为九十六分即以圈分竹云线上下直望每至</span>  
<span style="margin-left: 1em">云竹线交处即作识次以戊与各识相望作线即得众</span>  
<span style="margin-left: 1em">时刻线也</span>  
<span style="margin-left: 3em">平晷第四法</span>  
<span style="margin-left: 1em">此式乃有节气平晷成式也其法横作甲乙线为卯酉</span>  
<span style="margin-left: 1em">线即于其上直作丙丁垂线为午线两线相遇于丙次</span>  
<span style="margin-left: 1em">以第一式甘至辛为度从丙向丁得庚即从庚作线与</span>  
<span style="margin-left: 9em">甲乙平行为赤道线次以第一式</span>  
<span style="margin-left: 9em">自辛至左右线记逐一为度从庚</span>  
<span style="margin-left: 9em">左右逐一作识即以丙与各识相</span>  
<span style="margin-left: 9em">望俱作虚线或以丙为心任作虚</span>  
<span style="margin-left: 9em">圈即用元度于第一式上以甘为</span>  
<span style="margin-left: 9em">心亦作虚圈次以第一式虚圈上</span>  
<span style="margin-left: 9em">午旁线分逐一为度移至本式虚</span>  
<span style="margin-left: 9em">圈上子午线左右逐一作识亦以</span>  
<span style="margin-left: 9em">丙与各识相望作线则卯酉子午</span>  
<span style="margin-left: 9em">前后刻线俱定矣次以第三式自</span>  
<span style="margin-left: 1em">戊循午线斜行至与夏至交处为度从丙下行午线上</span>  
<span style="margin-left: 1em">作识即夏至午正表景所至也次如前以第三式量午</span>  
<span style="margin-left: 1em">未初线至与夏至线交处为度亦如前从丙于午线左</span>  
<span style="margin-left: 1em">右各第二线斜行作识即夏至午未初初刻表景所至</span>  
<span style="margin-left: 1em">也次己辰申卯酉皆如之而各时线上夏至线界定矣</span>  
<span style="margin-left: 1em">次又以第二式从戊至小暑及芒种交处为度从丙下</span>  
<span style="margin-left: 1em">行午线上作识即小暑芒种初日午正表景所至也大</span>  
<span style="margin-left: 1em">暑小满立秋立夏等节气皆以是法逐一量之则各气</span>  
<span style="margin-left: 1em">各时无不定矣次以一卷第二十依时刻上之识作曲</span>  
<span style="margin-left: 1em">线即太阳行诸节气初日之表景所至线也今以图纸</span>  
<span style="margin-left: 1em">隘恐线混持缶节作一曲线初日以后十四日至次节</span>  
<span style="margin-left: 1em">气线表景必射两节线之间夏至以后景日长冬至以</span>  
<span style="margin-left: 1em">后景日短也次为定表法量第一式甘至戊为度从丙</span>  
<span style="margin-left: 1em">下行得辛即立表位也次量第一式戊至己为度从辛</span>  
<span style="margin-left: 1em">右行得艮即表长也此立表法也次依第一卷二十一</span>  
<span style="margin-left: 1em">正表捷法以求其正而晷成矣</span>  
<span style="margin-left: 1em">第二定节线界识捷法</span>  
<span style="margin-left: 1em">但右法太烦故又有捷法凡各晷之子午线及偏晷之</span>  
<span style="margin-left: 1em">表线全与节线相遇者其冬夏至之节线及冬至内之</span>  
<span style="margin-left: 1em">第一线与夏至内之第一线若冬至内之第二三四五</span>  
<span style="margin-left: 1em">线与夏至内之第二三四五线其疎密虽不等而其曲</span>  
<span style="margin-left: 1em">直必各自相等也捷法曰从丙于子午线上先定节气</span>  
<span style="margin-left: 1em">疎密之位如元为夏至土为冬至次以丙元为度从上</span>  
<span style="margin-left: 1em">下行得竹次依丙心下行所作时刻线亦从竹上行俱</span>  
<span style="margin-left: 1em">作虚线作法则以丙与竹各为心各作半虚圈而二圈</span>  
<span style="margin-left: 1em">等乃以上圈诸时线从午线左右逐一为度悉移之下</span>  
<span style="margin-left: 1em">圈亦午线左右逐一作识次从竹与各识相望俱作虚</span>  
<span style="margin-left: 1em">线即得矣或平分丙竹线间于云从云作甘云石线与</span>  
<span style="margin-left: 1em">赤道平行交于丙心所出时刻线即以交处各与竹相</span>  
<span style="margin-left: 1em">望俱作虚线亦得也次凡从丙向下行各时线上所定</span>  
<span style="margin-left: 1em">夏至之位逐一为度亦从竹向上行各时线上作识次</span>  
<span style="margin-left: 1em">依上下识作两曲线而冬夏两相等节气线并定焉<sub class="note-jiao">校：焉</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">原作为据天理本改</sub>余曲直相等节气线皆如之但竹心及上行</span>  
<span style="margin-left: 11em">时线各节气不同则各须更</span>  
<span style="margin-left: 11em">画为法亦烦<sub class="note-jiao">校：煩原作須據天理本改</sub>故</span>  
<span style="margin-left: 11em">又有后法更捷</span>  
<span style="margin-left: 11em">法曰先作甲乙为午线次于</span>  
<span style="margin-left: 11em">其上依第一法定各节疎密</span>  
<span style="margin-left: 11em">之位假如丁为夏至己为冬</span>  
<span style="margin-left: 11em">至之位次于午线或左或右</span>
