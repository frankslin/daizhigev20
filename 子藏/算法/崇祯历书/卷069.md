<span style="margin-left: 3em">火星曆指敘目</span>  
<span style="margin-left: 1em">按古天圖火星屬第四重天在太陽之上土木之下今</span>  
<span style="margin-left: 2em">因新測及新圖又博考前賢遺論凡會合伏太陽則</span>  
<span style="margin-left: 2em">在其上凡夕退衝太陽則在其下而于地更近也</span>  
<span style="margin-left: 1em">火星視行絜他星之行更奇或行逾二百餘日不及天</span>  
<span style="margin-left: 2em">周一宮或越四旬日而行過一宮不達其道者曰無</span>  
<span style="margin-left: 2em">法之行也古比利尼阿<sub class="note-yuan">西大士</sub>曰火星之行不能測度</span>

<span style="margin-left: 2em">爲世法歷年久而無成功自懟虛費功力悶而幾斃</span>  
<span style="margin-left: 2em">後世之士益敏學如第谷二十年中心恆不倦每夜</span>
