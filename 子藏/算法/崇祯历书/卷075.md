<span style="margin-left: 1em">几何要法序</span>  
<span style="margin-left: 1em">世之执牛耳盟者幽言理至度数之学则以为迂而无</span>  
<span style="margin-left: 1em">当于道而刍狗置之夫度数而斤斤术艺也者则刍狗</span>  
<span style="margin-left: 1em">实也可度数之中大而授时定历正律审音算量分秒</span>  
<span style="margin-left: 1em">不爽水泉灌溉有资与夫力小任重营建机巧毕具而</span>  
<span style="margin-left: 1em">兵家制胜列营阵揣形势策攻守所须乎此者尤亟用</span>  
<span style="margin-left: 1em">之如斯其广且切也此而可刍狗视之将羲画虞璇亦</span>  
<span style="margin-left: 1em">枯而不灵之器而禹奏平成可舍句股勿用而姬公测</span>  
<span style="margin-left: 1em">验必周髀是问何为也始信理脱数而藏易借以覆短</span>  
<span style="margin-left: 1em">数传理而见则有物有事假作不得假说亦不得也善</span>  
<span style="margin-left: 1em">哉几何原本之帙译自西国裁自徐太史先生之手其</span>  
<span style="margin-left: 1em">中比分栉解义数详明可以佐隶首商高所不逮可以</span>  
<span style="margin-left: 1em">补十经九执之遗亡而梓甘翟襄不擅长焉者神而明</span>  
<span style="margin-left: 1em">之引类而伸之先王制器前用之法备见矣特初学望</span>  
<span style="margin-left: 1em">洋而叹不无惊其繁余因晤西先生得受几何要法其</span>  
<span style="margin-left: 1em">义约而达简而易从如攻坚木先其易者后其节目久</span>  
<span style="margin-left: 1em">也相说以解先河而后海昔有言之矣不操缦而能安</span>  
<span style="margin-left: 1em">弦有是学乎爰是订而别诸梓人僣数语弁其端有笑</span>  
<span style="margin-left: 1em">而诧猷以俗吏而迂谭度数之理也猷乌知</span>

<span style="margin-left: 3em">几何总论</span>  
<span style="margin-left: 1em">几何家者脱物体而空穷度数数其截者度其完者度</span>  
<span style="margin-left: 1em">有三曰线曰面曰体线以度长短面以度广狭体以度</span>  
<span style="margin-left: 1em">厚薄线自点始点引为线线展为面面运为体点者无</span>  
<span style="margin-left: 1em">长线者无广面者无厚点为线之界线为面之界面为</span>  
<span style="margin-left: 1em">体之界体不可为界点线面体几何之论起焉</span>  
<span style="margin-left: 2em">界说章第一<sub class="note-yuan">十六则</sub></span>  
<span style="margin-left: 1em">界者一物之始终解篇中所用名目作界说</span>  
<span style="margin-left: 3em">第一界</span>  
<span style="margin-left: 1em">几何者度与数之府也</span>  
<span style="margin-left: 3em">第二界</span>  
<span style="margin-left: 3em">点者无分无长短广狭厚薄故无分如上图甲点</span>  
<span style="margin-left: 1em">真圆真平相遇处止一点毕世积点不能结线<sub class="note-yuan">凡图十干为识</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">干尽用十二支等字</sub></span>  
<span style="margin-left: 3em">第三界</span>  
<span style="margin-left: 3em">线止有长无广厚如一平面光照之有光无光之</span>  
<span style="margin-left: 3em">间不容一物是线也如上甲乙图毕世积线不能</span>  
<span style="margin-left: 1em">结面</span>  
<span style="margin-left: 3em">第四界</span>  
<span style="margin-left: 1em">面者有长有广无厚一体所见为面凡体之影极似于</span>  
<span style="margin-left: 5em">面无厚之极也如上甲乙丙丁图毕世积面</span>  
<span style="margin-left: 5em">不能结体</span>  
<span style="margin-left: 3em">第五界</span>  
<span style="margin-left: 4em">体有长有广有厚如上甲乙丙丁戊己庚图</span>  
<span style="margin-left: 3em">第六界</span>  
<span style="margin-left: 1em">分者几何之几何也小能度大而尽之无赢不足者以</span>  
<span style="margin-left: 4em">小为大之分若小不能尽度大当称几分几何</span>  
<span style="margin-left: 4em">之几如上甲乙四与丙丁八戊己十二等数皆</span>  
<span style="margin-left: 4em">能尽分者则甲乙四为丙丁八戊己十二之分</span>  
<span style="margin-left: 2em">若庚辛四与壬癸六一即赢二即不足不能尽度者</span>  
<span style="margin-left: 2em">不得正名为分则称之为三分六之二<sub class="note-yuan">他数倣此</sub></span>  
<span style="margin-left: 3em">第七界</span>  
<span style="margin-left: 1em">点者非几何故不能为线及诸几何之分</span>  
<span style="margin-left: 3em">第八界</span>  
<span style="margin-left: 1em">线非广狭之几何故不能为面之分</span>  
<span style="margin-left: 3em">第九界</span>  
<span style="margin-left: 1em">面非厚薄之几何故不能为体之分</span>  
<span style="margin-left: 3em">第十界</span>  
<span style="margin-left: 4em">线有曲直线之一点能遮两界是直线如上图</span>  
<span style="margin-left: 4em">甲乙不遮则不直如下图丙丁</span>  
<span style="margin-left: 3em">第十一界</span>  
<span style="margin-left: 4em">面之中间线能遮两界不碍不空是平面如上</span>  
<span style="margin-left: 4em">图甲乙丙丁不遮则不平如下图戊己庚</span>  
<span style="margin-left: 3em">第十二界</span>  
<span style="margin-left: 1em">直线垂于横线之上为横线之垂线如上图丁乙为甲</span>  
<span style="margin-left: 4em">丙之垂线</span>  
<span style="margin-left: 3em">第十三界</span>  
<span style="margin-left: 4em">两直线于同面行至无穷不相离亦不相远终</span>  
<span style="margin-left: 1em">不得相遇者为平行线如上甲乙丙丁两线</span>  
<span style="margin-left: 3em">第十四界</span>  
<span style="margin-left: 1em">两几何以几何相比之理为比例两几何者或两数或</span>  
<span style="margin-left: 1em">两线或两面或两体各以同类大小相比谓之比例若</span>  
<span style="margin-left: 1em">线与面或数与线此异类不为比例若同类相比而不</span>  
<span style="margin-left: 1em">以几何亦不为比例也如白线与黑线或有穷之线与</span>  
<span style="margin-left: 1em">无穷之线虽则同类实无比例有穷之线毕世倍之不</span>  
<span style="margin-left: 1em">能及无穷之线故也</span>  
<span style="margin-left: 1em">凡比例有三种有数之比例有量法之比例有乐律之</span>  
<span style="margin-left: 1em">比例本卷论量法之比例</span>  
<span style="margin-left: 3em">第十五界</span>  
<span style="margin-left: 3em">比例相续不断为连比例其中率与前后两率递</span>  
<span style="margin-left: 3em">相为比例而中率既为前率之后又为后率之前</span>  
<span style="margin-left: 3em">如上图甲二与乙四比乙四又与丙八比是也</span>  
<span style="margin-left: 3em">第十六界</span>  
<span style="margin-left: 5em">中率一取不再用为断比例如上图甲四自</span>  
<span style="margin-left: 5em">与乙八比丙六自与丁十二比是也</span>  
<span style="margin-left: 2em">备器章第二</span>  
<span style="margin-left: 1em">几何在历家则多用图画图必先备器器有三曰尺曰</span>  
<span style="margin-left: 1em">规曰矩尺以画线而贵直规以画圜而贵调矩以画方</span>  
<span style="margin-left: 1em">而贵准器准矣不识用法则茫无措手今以用法著于</span>  
<span style="margin-left: 1em">篇</span>  
<span style="margin-left: 2em">审尺章第三</span>  
<span style="margin-left: 1em">画图首画线线贵直线界于尺故先求尺直如甲乙为</span>  
<span style="margin-left: 4em">尺面丙丁为尺侧一棱先以丙丁画一戊己线</span>  
<span style="margin-left: 4em">丙合戊丁合己次转丙丁棱画一己戊线丙合</span>  
<span style="margin-left: 4em">己丁合戊不出不入则尺直矣不直再当琢削</span>  
<span style="margin-left: 2em">画线章第四</span>  
<span style="margin-left: 1em">尺既直矣线可无曲然画时又有法须以铁或铜铸笔</span>  
<span style="margin-left: 1em">上长其柄令可把手下截濶出复渐窄而下其正面削</span>  
<span style="margin-left: 10em">极平背令稍圆去末寸许作一</span>  
<span style="margin-left: 10em">小窝窝下渐细至末用时以墨</span>  
<span style="margin-left: 1em">汁入小窝以平面紧倚尺作线则墨汁自就下或恐墨</span>  
<span style="margin-left: 1em">污其地将尺削去丙丁侧一棱则墨线莹细如丝即作</span>  
<span style="margin-left: 1em">于规末亦得</span>  
<span style="margin-left: 2em">审平面章第五</span>  
<span style="margin-left: 1em">平面者诸方皆作直线</span>  
<span style="margin-left: 5em">法曰如甲乙丙丁为面欲审其平即用直尺</span>  
<span style="margin-left: 5em">施于甲角绕面运转不碍不空全合直尺是</span>  
<span style="margin-left: 5em">平面也</span>  
<span style="margin-left: 2em">引线章第六</span>  
<span style="margin-left: 1em">有一短直线求平引长之</span>  
<span style="margin-left: 1em">法曰如有甲乙线欲平引长之先以甲为心以乙为界</span>  
<span style="margin-left: 1em">画小半圜以乙为心任取一度于小半圜上下各作规</span>  
<span style="margin-left: 5em">界线为丙为丁次以丙丁为心任取一度向</span>  
<span style="margin-left: 5em">前作短界线相交为戊末引甲乙线至戊则</span>  
<span style="margin-left: 5em">得所求若欲更引长仍依此法</span>  
<span style="margin-left: 2em">平分直线章第七<sub class="note-yuan">法有二</sub></span>  
<span style="margin-left: 1em">有有界之线求两平分之</span>  
<span style="margin-left: 3em">第一法</span>  
<span style="margin-left: 5em">如有甲乙线求两平分先以甲为心任用一</span>  
<span style="margin-left: 5em">度但须长于甲乙线之半愈长愈准向上向</span>  
<span style="margin-left: 5em">下各作一短界线次用元度以乙为心亦如</span>  
<span style="margin-left: 1em">之两界线交处即丙丁末用尺作丙丁直线即甲乙有</span>  
<span style="margin-left: 1em">界之线两平分于戊矣</span>  
<span style="margin-left: 3em">第二法</span>  
<span style="margin-left: 5em">若所分之线下面无地可作短界线即于甲</span>  
<span style="margin-left: 5em">乙线上先画两短界线于丙次或开或收规</span>  
<span style="margin-left: 5em">度仍前从甲从乙向上又作两短界线于丁</span>  
<span style="margin-left: 5em">规度愈相远画线愈准末以丙丁二交用尺</span>  
<span style="margin-left: 1em">如前画线则得所求</span>  
<span style="margin-left: 2em">作垂线章第八<sub class="note-yuan">法有四</sub></span>  
<span style="margin-left: 1em">有一直线任于一点上求作垂线</span>  
<span style="margin-left: 3em">第一法</span>  
<span style="margin-left: 5em">甲乙直线任指一点于丙求丙上作垂线先</span>  
<span style="margin-left: 5em">于丙点左右任用一度愈远愈准各截一界</span>  
<span style="margin-left: 5em">为丁为戊次以丁为心任用一度但须长于</span>  
<span style="margin-left: 1em">丙丁线向丙上方作短界线次用元度以戊为心亦如</span>  
<span style="margin-left: 1em">之两界线交处为己从己至丙以尺画线则得所求</span>  
<span style="margin-left: 3em">第二法</span>  
<span style="margin-left: 5em">于丙左右如上法截取丁与戊即任用一度</span>  
<span style="margin-left: 5em">以丁为心于丙上下方各作短界线次用元</span>  
<span style="margin-left: 5em">度以戊为心亦如之则上交为己下交为庚</span>  
<span style="margin-left: 1em">末作己庚直线视直线交于丙点即得所求若丙点在</span>  
<span style="margin-left: 1em">甲乙端上则当暗引长甲乙线后如前作亦得</span>  
<span style="margin-left: 3em">第三法</span>  
<span style="margin-left: 5em">若直线甲端上求立垂线又甲点外无地可</span>  
<span style="margin-left: 5em">暗引线则先以甲乙原线上方任取一点为</span>  
<span style="margin-left: 5em">丙以丙为心甲为界作大半圜圜界与甲乙</span>  
<span style="margin-left: 1em">线相遇为丁次自丁至丙依前法作直线引长之至戊</span>  
<span style="margin-left: 1em">为戊丁线戊丁与圜界相遇为己末自己至甲作直线</span>  
<span style="margin-left: 1em">即所求</span>  
<span style="margin-left: 3em">第四法</span>  
<span style="margin-left: 5em">若甲乙线所欲立垂线之点乃在线末甲界</span>  
<span style="margin-left: 5em">上甲外无余线可截则于甲乙线上任取一</span>  
<span style="margin-left: 5em">点为丙如前一二法于丙上立丁丙垂线次</span>  
<span style="margin-left: 1em">以甲丙丁角两平分之<sub class="note-yuan">分法在后三卷第四章</sub>为己丙线次以甲</span>  
<span style="margin-left: 1em">丙为度于丁丙垂线上截戊丙线又用元度以戊为心</span>  
<span style="margin-left: 1em">向己作短界线为庚末自庚至甲作直线得所求</span>  
<span style="margin-left: 2em">立垂线章第九<sub class="note-yuan">法有四</sub></span>  
<span style="margin-left: 1em">有无界直线线外有一点求自彼点作垂线至直线上</span>  
<span style="margin-left: 3em">第一法</span>  
<span style="margin-left: 1em">如有甲乙无界直线直线外有丙点求自丙点作垂线</span>  
<span style="margin-left: 5em">至甲乙线先以丙为心向直线两处各作小</span>  
<span style="margin-left: 5em">半圜或两短界线为甲为乙次仍用一度以</span>  
<span style="margin-left: 5em">甲为心向丙点相望处作短界线又以乙为</span>  
<span style="margin-left: 1em">心亦如之两线相交处为丁末自丙至丁作直线截甲</span>
