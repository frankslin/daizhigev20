## 崇禎曆書卷之七十五　幾何要法卷一

<span style="margin-left: 1em">幾何要法卷一<sub class="note-jiao">校：據明刊牛津本校錄</sub></span>  
<span style="margin-left: 11em">泰西耶蘇會士艾儒略　述</span>  
<span style="margin-left: 17em">高一志</span>  
<span style="margin-left: 17em">鄧玉函</span>  
<span style="margin-left: 13em">同會　　　　　仝訂</span>  
<span style="margin-left: 17em">龍華民</span>  
<span style="margin-left: 17em">羅雅谷</span>  
<span style="margin-left: 13em">值會　　陽瑪諾　准</span>  
<span style="margin-left: 1em"><sub class="note-jiao">校：清刊本無此署名</sub></span>  
<span style="margin-left: 1em">幾何要法序</span>  
<span style="margin-left: 1em">世之執牛耳盟者幽言理至度數之學則以爲迂而無</span>  
<span style="margin-left: 1em">當於道而芻狗置之夫度數而斤斤術藝也者則芻狗</span>  
<span style="margin-left: 1em">實也可度數之中大而授時定曆正律審音算量分秒</span>  
<span style="margin-left: 1em">不爽水泉灌溉有資與夫力小任重營建機巧畢具而</span>  
<span style="margin-left: 1em">兵家制勝列營陣揣形勢策攻守所須乎此者尤亟用</span>  
<span style="margin-left: 1em">之如斯其廣且切也此而可芻狗視之將羲畫虞璿亦</span>  
<span style="margin-left: 1em">枯而不靈之器而禹奏平成可舍句股勿用而姬公測</span>  
<span style="margin-left: 1em">驗必周髀是問何爲也始信理脫數而藏易借以覆短</span>  
<span style="margin-left: 1em">數傳理而見則有物有事假作不得假說亦不得也善</span>  
<span style="margin-left: 1em">哉幾何原本之帙譯自西國裁自徐太史先生之手其</span>  
<span style="margin-left: 1em">中比分櫛解義數詳明可以佐隸首商高所不逮可以</span>  
<span style="margin-left: 1em">補十經九執之遺亡而梓甘翟襄不擅長焉者神而明</span>  
<span style="margin-left: 1em">之引類而伸之先王制器前用之法備見矣特初學望</span>  
<span style="margin-left: 1em">洋而嘆不無驚其繁余因晤西先生得受幾何要法其</span>  
<span style="margin-left: 1em">義約而達簡而易從如攻堅木先其易者後其節目久</span>  
<span style="margin-left: 1em">也相說以解先河而後海昔有言之矣不操縵而能安</span>  
<span style="margin-left: 1em">絃有是學乎爰是訂而別諸梓人僣數語弁其端有笑</span>  
<span style="margin-left: 1em">而詫猷以俗吏而迂譚度數之理也猷烏知</span>

<span style="margin-left: 3em">幾何總論</span>  
<span style="margin-left: 1em">幾何家者脫物體而空窮度數數其截者度其完者度</span>  
<span style="margin-left: 1em">有三曰線曰面曰體線以度長短面以度廣狹體以度</span>  
<span style="margin-left: 1em">厚薄線自點始點引爲線線展爲面面運爲體點者無</span>  
<span style="margin-left: 1em">長線者無廣面者無厚點爲線之界線爲面之界面爲</span>  
<span style="margin-left: 1em">體之界體不可爲界點線面體幾何之論起焉</span>  
<span style="margin-left: 2em">界說章第一<sub class="note-yuan">十六則</sub></span>  
<span style="margin-left: 1em">界者一物之始終解篇中所用名目作界說</span>  
<span style="margin-left: 3em">第一界</span>  
<span style="margin-left: 1em">幾何者度與數之府也</span>  
<span style="margin-left: 3em">第二界</span>  
<span style="margin-left: 3em">點者無分無長短廣狹厚薄故無分如上圖甲點</span>  
<span style="margin-left: 1em">真圓真平相遇處止一點畢世積點不能結線<sub class="note-yuan">凡圖十干爲識</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">干盡用十二支等字</sub></span>  
<span style="margin-left: 3em">第三界</span>  
<span style="margin-left: 3em">線止有長無廣厚如一平面光照之有光無光之</span>  
<span style="margin-left: 3em">間不容一物是線也如上甲乙圖畢世積線不能</span>  
<span style="margin-left: 1em">結面</span>  
<span style="margin-left: 3em">第四界</span>  
<span style="margin-left: 1em">面者有長有廣無厚一體所見爲面凡體之影極似於</span>  
<span style="margin-left: 5em">面無厚之極也如上甲乙丙丁圖畢世積面</span>  
<span style="margin-left: 5em">不能結體</span>  
<span style="margin-left: 3em">第五界</span>  
<span style="margin-left: 4em">體有長有廣有厚如上甲乙丙丁戊己庚圖</span>  
<span style="margin-left: 3em">第六界</span>  
<span style="margin-left: 1em">分者幾何之幾何也小能度大而盡之無贏不足者以</span>  
<span style="margin-left: 4em">小爲大之分若小不能盡度大當稱幾分幾何</span>  
<span style="margin-left: 4em">之幾如上甲乙四與丙丁八戊己十二等數皆</span>  
<span style="margin-left: 4em">能盡分者則甲乙四爲丙丁八戊己十二之分</span>  
<span style="margin-left: 2em">若庚辛四與壬癸六一即贏二即不足不能盡度者</span>  
<span style="margin-left: 2em">不得正名爲分則稱之爲三分六之二<sub class="note-yuan">他數倣此</sub></span>  
<span style="margin-left: 3em">第七界</span>  
<span style="margin-left: 1em">點者非幾何故不能爲線及諸幾何之分</span>  
<span style="margin-left: 3em">第八界</span>  
<span style="margin-left: 1em">線非廣狹之幾何故不能爲面之分</span>  
<span style="margin-left: 3em">第九界</span>  
<span style="margin-left: 1em">面非厚薄之幾何故不能爲體之分</span>  
<span style="margin-left: 3em">第十界</span>  
<span style="margin-left: 4em">線有曲直線之一點能遮兩界是直線如上圖</span>  
<span style="margin-left: 4em">甲乙不遮則不直如下圖丙丁</span>  
<span style="margin-left: 3em">第十一界</span>  
<span style="margin-left: 4em">面之中間線能遮兩界不礙不空是平面如上</span>  
<span style="margin-left: 4em">圖甲乙丙丁不遮則不平如下圖戊己庚</span>  
<span style="margin-left: 3em">第十二界</span>  
<span style="margin-left: 1em">直線垂於橫線之上爲橫線之垂線如上圖丁乙爲甲</span>  
<span style="margin-left: 4em">丙之垂線</span>  
<span style="margin-left: 3em">第十三界</span>  
<span style="margin-left: 4em">兩直線於同面行至無窮不相離亦不相遠終</span>  
<span style="margin-left: 1em">不得相遇者爲平行線如上甲乙丙丁兩線</span>  
<span style="margin-left: 3em">第十四界</span>  
<span style="margin-left: 1em">兩幾何以幾何相比之理爲比例兩幾何者或兩數或</span>  
<span style="margin-left: 1em">兩線或兩面或兩體各以同類大小相比謂之比例若</span>  
<span style="margin-left: 1em">線與面或數與線此異類不爲比例若同類相比而不</span>  
<span style="margin-left: 1em">以幾何亦不爲比例也如白線與黑線或有窮之線與</span>  
<span style="margin-left: 1em">無窮之線雖則同類實無比例有窮之線畢世倍之不</span>  
<span style="margin-left: 1em">能及無窮之線故也</span>  
<span style="margin-left: 1em">凡比例有三種有數之比例有量法之比例有樂律之</span>  
<span style="margin-left: 1em">比例本卷論量法之比例</span>  
<span style="margin-left: 3em">第十五界</span>  
<span style="margin-left: 3em">比例相續不斷爲連比例其中率與前後兩率遞</span>  
<span style="margin-left: 3em">相爲比例而中率既爲前率之後又爲後率之前</span>  
<span style="margin-left: 3em">如上圖甲二與乙四比乙四又與丙八比是也</span>  
<span style="margin-left: 3em">第十六界</span>  
<span style="margin-left: 5em">中率一取不再用爲斷比例如上圖甲四自</span>  
<span style="margin-left: 5em">與乙八比丙六自與丁十二比是也</span>  
<span style="margin-left: 2em">備器章第二</span>  
<span style="margin-left: 1em">幾何在曆家則多用圖畫圖必先備器器有三曰尺曰</span>  
<span style="margin-left: 1em">規曰矩尺以畫線而貴直規以畫圜而貴調矩以畫方</span>  
<span style="margin-left: 1em">而貴準器準矣不識用法則茫無措手今以用法著於</span>  
<span style="margin-left: 1em">篇</span>  
<span style="margin-left: 2em">審尺章第三</span>  
<span style="margin-left: 1em">畫圖首畫線線貴直線界於尺故先求尺直如甲乙爲</span>  
<span style="margin-left: 4em">尺面丙丁爲尺側一稜先以丙丁畫一戊己線</span>  
<span style="margin-left: 4em">丙合戊丁合己次轉丙丁稜畫一己戊線丙合</span>  
<span style="margin-left: 4em">己丁合戊不出不入則尺直矣不直再當琢削</span>  
<span style="margin-left: 2em">畫線章第四</span>  
<span style="margin-left: 1em">尺既直矣線可無曲然畫時又有法須以鐵或銅鑄筆</span>  
<span style="margin-left: 1em">上長其柄令可把手下截濶出復漸窄而下其正面削</span>  
<span style="margin-left: 10em">極平背令稍圓去末寸許作一</span>  
<span style="margin-left: 10em">小窩窩下漸細至末用時以墨</span>  
<span style="margin-left: 1em">汁入小窩以平面緊倚尺作線則墨汁自就下或恐墨</span>  
<span style="margin-left: 1em">汙其地將尺削去丙丁側一稜則墨線瑩細如絲即作</span>  
<span style="margin-left: 1em">於規末亦得</span>  
<span style="margin-left: 2em">審平面章第五</span>  
<span style="margin-left: 1em">平面者諸方皆作直線</span>  
<span style="margin-left: 5em">法曰如甲乙丙丁爲面欲審其平即用直尺</span>  
<span style="margin-left: 5em">施於甲角繞面運轉不礙不空全合直尺是</span>  
<span style="margin-left: 5em">平面也</span>  
<span style="margin-left: 2em">引線章第六</span>  
<span style="margin-left: 1em">有一短直線求平引長之</span>  
<span style="margin-left: 1em">法曰如有甲乙線欲平引長之先以甲爲心以乙爲界</span>  
<span style="margin-left: 1em">畫小半圜以乙爲心任取一度於小半圜上下各作規</span>  
<span style="margin-left: 5em">界線爲丙爲丁次以丙丁爲心任取一度向</span>  
<span style="margin-left: 5em">前作短界線相交爲戊末引甲乙線至戊則</span>  
<span style="margin-left: 5em">得所求若欲更引長仍依此法</span>  
<span style="margin-left: 2em">平分直線章第七<sub class="note-yuan">法有二</sub></span>  
<span style="margin-left: 1em">有有界之線求兩平分之</span>  
<span style="margin-left: 3em">第一法</span>  
<span style="margin-left: 5em">如有甲乙線求兩平分先以甲爲心任用一</span>  
<span style="margin-left: 5em">度但須長於甲乙線之半愈長愈準向上向</span>  
<span style="margin-left: 5em">下各作一短界線次用元度以乙爲心亦如</span>  
<span style="margin-left: 1em">之兩界線交處即丙丁末用尺作丙丁直線即甲乙有</span>  
<span style="margin-left: 1em">界之線兩平分於戊矣</span>  
<span style="margin-left: 3em">第二法</span>  
<span style="margin-left: 5em">若所分之線下面無地可作短界線即於甲</span>  
<span style="margin-left: 5em">乙線上先畫兩短界線於丙次或開或收規</span>  
<span style="margin-left: 5em">度仍前從甲從乙向上又作兩短界線於丁</span>  
<span style="margin-left: 5em">規度愈相遠畫線愈準末以丙丁二交用尺</span>  
<span style="margin-left: 1em">如前畫線則得所求</span>  
<span style="margin-left: 2em">作垂線章第八<sub class="note-yuan">法有四</sub></span>  
<span style="margin-left: 1em">有一直線任於一點上求作垂線</span>  
<span style="margin-left: 3em">第一法</span>  
<span style="margin-left: 5em">甲乙直線任指一點於丙求丙上作垂線先</span>  
<span style="margin-left: 5em">於丙點左右任用一度愈遠愈準各截一界</span>  
<span style="margin-left: 5em">爲丁爲戊次以丁爲心任用一度但須長於</span>  
<span style="margin-left: 1em">丙丁線向丙上方作短界線次用元度以戊爲心亦如</span>  
<span style="margin-left: 1em">之兩界線交處爲己從己至丙以尺畫線則得所求</span>  
<span style="margin-left: 3em">第二法</span>  
<span style="margin-left: 5em">於丙左右如上法截取丁與戊即任用一度</span>  
<span style="margin-left: 5em">以丁爲心於丙上下方各作短界線次用元</span>  
<span style="margin-left: 5em">度以戊爲心亦如之則上交爲己下交爲庚</span>  
<span style="margin-left: 1em">末作己庚直線視直線交於丙點即得所求若丙點在</span>  
<span style="margin-left: 1em">甲乙端上則當暗引長甲乙線後如前作亦得</span>  
<span style="margin-left: 3em">第三法</span>  
<span style="margin-left: 5em">若直線甲端上求立垂線又甲點外無地可</span>  
<span style="margin-left: 5em">暗引線則先以甲乙原線上方任取一點爲</span>  
<span style="margin-left: 5em">丙以丙爲心甲爲界作大半圜圜界與甲乙</span>  
<span style="margin-left: 1em">線相遇爲丁次自丁至丙依前法作直線引長之至戊</span>  
<span style="margin-left: 1em">爲戊丁線戊丁與圜界相遇爲己末自己至甲作直線</span>  
<span style="margin-left: 1em">即所求</span>  
<span style="margin-left: 3em">第四法</span>  
<span style="margin-left: 5em">若甲乙線所欲立垂線之點乃在線末甲界</span>  
<span style="margin-left: 5em">上甲外無餘線可截則於甲乙線上任取一</span>  
<span style="margin-left: 5em">點爲丙如前一二法於丙上立丁丙垂線次</span>  
<span style="margin-left: 1em">以甲丙丁角兩平分之<sub class="note-yuan">分法在後三卷第四章</sub>爲己丙線次以甲</span>  
<span style="margin-left: 1em">丙爲度於丁丙垂線上截戊丙線又用元度以戊爲心</span>  
<span style="margin-left: 1em">向己作短界線爲庚末自庚至甲作直線得所求</span>  
<span style="margin-left: 2em">立垂線章第九<sub class="note-yuan">法有四</sub></span>  
<span style="margin-left: 1em">有無界直線線外有一點求自彼點作垂線至直線上</span>  
<span style="margin-left: 3em">第一法</span>  
<span style="margin-left: 1em">如有甲乙無界直線直線外有丙點求自丙點作垂線</span>  
<span style="margin-left: 5em">至甲乙線先以丙爲心向直線兩處各作小</span>  
<span style="margin-left: 5em">半圜或兩短界線爲甲爲乙次仍用一度以</span>  
<span style="margin-left: 5em">甲爲心向丙點相望處作短界線又以乙爲</span>  
<span style="margin-left: 1em">心亦如之兩線相交處爲丁末自丙至丁作直線截甲</span>  
<span style="margin-left: 1em">乙線於戊則丙戊爲垂線</span>

<span style="margin-left: 5em">爲心向丙上作短界線次用元度以戊爲心</span>  
<span style="margin-left: 5em">仍向丙上作短界線交於己末自己至丙作</span>  
<span style="margin-left: 1em">直線引長之至庚得所求又有便法在後平行線中</span>  
<span style="margin-left: 2em">作平行線章第十<sub class="note-yuan">法有三</sub></span>  
<span style="margin-left: 1em">一點求作直線與原設直線平行</span>  
<span style="margin-left: 3em">第一法</span>  
<span style="margin-left: 1em">於甲點求作直線與乙丙線平行先任作甲丁線與乙</span>

<span style="margin-left: 3em">第二法</span>  
<span style="margin-left: 5em">先以甲點爲心於乙丙線近乙處任指一點</span>

<span style="margin-left: 1em">元度以戊爲心對甲平行作短界線於己末自甲至己</span>

<span style="margin-left: 3em">一規而數易其度則元度永不復矣此丁先生秘</span>  
<span style="margin-left: 3em">法</span>  
<span style="margin-left: 3em">註曰以上二法以甲點定遠近若無甲點任指所</span>  
<span style="margin-left: 3em">欲遠近爲界可當甲點</span>  
<span style="margin-left: 6em">第三法</span>  
<span style="margin-left: 5em">此法比前法更簡易即西本幾何亦未載乃</span>  
<span style="margin-left: 5em">敝師伯先生所授如有甲乙線任遠近求作</span>  
<span style="margin-left: 5em">平行線近甲取心向上以所求遠近爲度作</span>  
<span style="margin-left: 1em">小半圜次用元度近乙取心向上復作小半圜末以尺</span>  
<span style="margin-left: 1em">依半圜爲界作直線即所求</span>  
<span style="margin-left: 5em">註曰以上平行數法可推用作沿邊直線之</span>  
<span style="margin-left: 5em">垂線如有甲乙線求乙線界上作一垂線先</span>  
<span style="margin-left: 5em">以乙爲心向甲任取一點爲丙又用元度以</span>  
<span style="margin-left: 5em">丙爲心向甲指一點爲丁又以乙爲心任取</span>  
<span style="margin-left: 3em">一度向上方作一短界線愈遠愈準又以丁爲心</span>  
<span style="margin-left: 3em">用元度仍向上方作一短界線與前界線相交於</span>  
<span style="margin-left: 3em">戊次自戊至丙作垂線末以前作平行線法隨用</span>  
<span style="margin-left: 3em">一法以丙乙爲度作平行線正垂在乙點上即得</span>  
<span style="margin-left: 3em">所求</span>  
<span style="margin-left: 2em">求分一直線任爲若干平分章第十一<sub class="note-yuan">法有四</sub></span>  
<span style="margin-left: 1em">凡造曆象數欲分直線爲不等分不諳其法大費手力</span>  
<span style="margin-left: 1em">抑且不準宜熟後法以便用</span>  
<span style="margin-left: 3em">第一法</span>  
<span style="margin-left: 5em">如甲乙線求五平分先從甲任作甲丙線爲</span>  
<span style="margin-left: 5em">丙甲乙角次從甲向丙任作五平度爲甲丁</span>  
<span style="margin-left: 5em">丁戊戊己己庚庚辛次作辛乙直線末用平</span>  
<span style="margin-left: 5em">行線法作丁壬戊癸己子庚丑四線皆與辛</span>  
<span style="margin-left: 1em">乙平行即壬癸子丑與甲乙爲五平分</span>  
<span style="margin-left: 3em">第二法</span>  
<span style="margin-left: 5em">如甲乙線求五平分即從乙任作乙丙線爲</span>  
<span style="margin-left: 5em">丙乙甲角次於乙丙任取一點爲丁作丁戊</span>  
<span style="margin-left: 5em">線與甲乙平行次從丁向戊任作五平分爲</span>  
<span style="margin-left: 5em">丁己己庚庚辛辛壬壬癸而丁癸線令小於</span>  
<span style="margin-left: 5em">甲乙次從甲過癸作甲子線遇乙丙於子末</span>  
<span style="margin-left: 5em">從子作子壬子辛子庚子己四線各引長之</span>  
<span style="margin-left: 1em">而分甲乙於丑於寅於卯於辰爲五平分</span>  
<span style="margin-left: 3em">第三法</span>  
<span style="margin-left: 1em">如甲乙線求五平分即從甲從乙作甲丁乙丙兩平行</span>  
<span style="margin-left: 5em">線次從乙任作戊己庚辛四平分次用元度</span>  
<span style="margin-left: 5em">從甲作壬癸子丑四平分末作戊丑己子庚</span>  
<span style="margin-left: 5em">癸辛壬四線相聯即分甲乙於己於辰於卯</span>  
<span style="margin-left: 5em">於寅爲五平分</span>  
<span style="margin-left: 3em">第四法</span>  
<span style="margin-left: 10em">此法極簡極神可分百千不等</span>

<span style="margin-left: 1em">用愈廣格每分作平行線相聯今欲分甲乙爲五平分</span>  
<span style="margin-left: 1em">即規取甲乙之度以一規髀任抵戊丙線上一規髀抵</span>  
<span style="margin-left: 1em">第五庚辛線上如不在庚辛者即漸移之至線界而止</span>

<span style="margin-left: 1em">又如有甲乙線求十七平分先以規取甲乙之度以一</span>

<span style="margin-left: 15em">處以一規髀抵此</span>  
<span style="margin-left: 15em">器庚辛第十七格</span>  
<span style="margin-left: 15em">爲壬次從戊至壬</span>  
<span style="margin-left: 15em">畫一直線次取所</span>

<span style="margin-left: 1em">十分矣每十分作識如所求餘以此推之</span>

<span style="margin-left: 5em">第一法</span>  
<span style="margin-left: 5em">如有甲乙直線求截取三分之一先從甲任</span>

<span style="margin-left: 5em">如甲乙直線求截取七分之三先以前章法</span>  
<span style="margin-left: 5em">分甲乙線爲七分後取其三於庚則得所求</span>

<span style="margin-left: 5em">數亦如之</span>  
<span style="margin-left: 2em">有一直線求截各分如所設之分章第十三<sub class="note-yuan">一法</sub></span>  
<span style="margin-left: 1em">法曰甲乙線求截各分如所設甲丙任分之丁戊者謂</span>
