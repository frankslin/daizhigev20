<span style="margin-left: 1em">恆星曆叙目</span>  
<span style="margin-left: 1em">曆以齊七政乃自日躔而後首論恆星者何也曰日躔</span>  
<span style="margin-left: 1em">終古行黃道其經其緯易定耳若月五星各有道各有</span>  
<span style="margin-left: 1em">極各有交各有轉紛糅不齊非先定恆星之經緯即六</span>  
<span style="margin-left: 1em">曜之經緯無從可論故六曜如乘傳恆星其地誌也六</span>  
<span style="margin-left: 1em">曜如行棊恆星其楸局也以是先恆星也恆星之黃道</span>  
<span style="margin-left: 1em">赤道須並論者何也曰赤道在天中終古不變推步者</span>  
<span style="margin-left: 1em">賴爲準則焉乃諸曜皆循黃道行一切躔度因之布算</span>  
<span style="margin-left: 1em">故用赤道經緯以求合于天元用黃道經緯以求合于</span>  
<span style="margin-left: 1em">本行則七政如海舟黃道其行程赤道其望山也故黃</span>  
<span style="margin-left: 1em">赤二道須並論也二道之兼求經緯何也曰凡測量躔</span>  
<span style="margin-left: 1em">度及交食會合必將定其所至之處左右前後纖微乖</span>  
<span style="margin-left: 1em">舛非定處矣故二道之各經各緯如棋局之有縱有橫</span>  
<span style="margin-left: 1em">地圖之有袤有廣闕其一固不可也然則自古曆家何</span>  
<span style="margin-left: 1em">以皆有經度無緯度乎曰創始難工增脩易善前人所</span>  
<span style="margin-left: 1em">作爲後人之師前人所缺待後人而補凡事盡然曆爲</span>  
<span style="margin-left: 1em">尤甚者天事難明故也有經無緯正前人所未及回回</span>  
<span style="margin-left: 1em">曆有經有緯而成法爲千年前所立至今無測候改定</span>  
<span style="margin-left: 1em">者亦彼法所未及也曰繇前取喻既以爲郵之誌棊之</span>  
<span style="margin-left: 1em">局宜恆定不易矣今又須測候改定則是恆星之經緯</span>  
<span style="margin-left: 1em">亦非恆定也已自不定曷爲他行待彼而定曰天載無</span>  
<span style="margin-left: 1em">窮天能無盡大圜在上既爲動體凡在體中無有不動</span>  
<span style="margin-left: 1em">若云不動則有窮之屬也顧其爲動動必有法若云無</span>  
<span style="margin-left: 1em">法又無能之屬也天豈然哉非止動而已也凡能動者</span>  
<span style="margin-left: 1em">皆有四端一曰隨動一曰自動一曰疾動一曰遲動宗</span>  
<span style="margin-left: 1em">動西行諸曜從之此隨動也七曜恆星各自東行而各</span>  
<span style="margin-left: 1em">有法此自動也西行一日一周其爲亟速非思議所及</span>  
<span style="margin-left: 1em">此疾動也諸曜東行經時不等比于宗動皆可名遲最</span>  
<span style="margin-left: 1em">遲者二萬五千餘年而東行一周此遲動也今論恆星</span>  
<span style="margin-left: 1em">則屬自動又屬遲動自動既有法即依法推步可爲他</span>  
<span style="margin-left: 1em">行之法遲動即數十年而徵露端倪數百年而灼見違</span>  
<span style="margin-left: 1em">離違離之後因可隨時革正端倪初見不妨豫爲更易</span>  
<span style="margin-left: 1em">其或甄明此學人不絕世即數年之間一爲推變有何</span>  
<span style="margin-left: 1em">不可向所云測候改定職此之繇易稱治曆明時取象</span>  
<span style="margin-left: 1em">于革至哉乎一言蔽之矣曰向言每一動者各有四動</span>  
<span style="margin-left: 1em">今恆星之黃赤經緯又屬四種此四動者異乎同乎曰</span>  
<span style="margin-left: 1em">安得同乎黃赤二道位置不等其各兩極不等二經二</span>  
<span style="margin-left: 1em">緯縱橫不等交互不等故令星行不等其差亦不等有</span>  
<span style="margin-left: 1em">名爲有差而絕不可謂差者黃道之經度是也恆星依</span>  
<span style="margin-left: 1em">黃道東行如載籍相傳堯時冬至日躔約在虛七度今</span>  
<span style="margin-left: 1em">躔箕四度四千年間而日退行若干度者即星之進行</span>  
<span style="margin-left: 1em">若干度也古曆謂之歲差各立年率郭守敬以爲六十</span>  
<span style="margin-left: 1em">六年有奇而差一度今者斟酌異同辨析微妙定爲每</span>  
<span style="margin-left: 1em">歳東行一分四十三秒七十三微二十六纖六十九年</span>  
<span style="margin-left: 1em">一百九十一日七十三刻而行一度凡二萬五千二百</span>  
<span style="margin-left: 1em">〇二年九十一日二十五刻而行天一周終古恆然也</span>  
<span style="margin-left: 1em">此立名爲差而實有定法不可謂差者也有行度不爽</span>  
<span style="margin-left: 1em">而兩道參差致生違異者赤道之經度是也星依黃道</span>  
<span style="margin-left: 1em">行與赤道諸緯皆以斜角相遇兩經相較是生廣狹因</span>  
<span style="margin-left: 1em">其廣狹是生疾遲又因其斜迤而從赤極分經古今各</span>  
<span style="margin-left: 1em">測復生參錯其南北東西亟舒寬迮互有乘除一再廻</span>  
<span style="margin-left: 1em">易即還故處此則星經不異而以交道爲異者也有星</span>  
<span style="margin-left: 1em">本平行而兩距變易致成升降者赤道之緯度是也黃</span>  
<span style="margin-left: 1em">亦兩至之距爲二十三度八十六分有奇星從南至行</span>  
<span style="margin-left: 1em">北距如是既迄象限與赤同行迨于半周則其距南亦</span>  
<span style="margin-left: 1em">復乃爾計行半周而南北距差四十七度七十二分有</span>  
<span style="margin-left: 1em">奇盡一周而復是其星行不異而以距度爲異者也至</span>  
<span style="margin-left: 1em">若黃赤二道兩至之距古來皆稱二十四度今測定爲</span>  
<span style="margin-left: 1em">二十三度八十六分七十六秒考之西史所載周顯王</span>  
<span style="margin-left: 1em">時一測西漢景帝時一測東漢順帝時一測三史折衷</span>  
<span style="margin-left: 1em">爲二十四度一十八分三十秒以較今測差三十一分</span>  
<span style="margin-left: 1em">五十四秒此爲二道之兩至距度二千年間昔遠今近</span>  
<span style="margin-left: 1em">漸次移易之數也故有不係星行不關經度而躔道自</span>  
<span style="margin-left: 1em">爲近京者黃道之緯度是也合四者論之有易見易知</span>  
<span style="margin-left: 1em">者一有難見而可知者二有易見而不可知者一黃道</span>  
<span style="margin-left: 1em">經行與日躔同類理明數順易見易知矣赤經赤緯糾</span>  
<span style="margin-left: 1em">紛轉易致爲繁曲然其理可推其數可循總皆二萬五</span>  
<span style="margin-left: 1em">千二百〇二年有奇而一周則難見而可知也惟是黃</span>  
<span style="margin-left: 1em">緯一差分數曉然然古時既遠上古時當更遠不知遠</span>  
<span style="margin-left: 1em">于何始今時既近後來者當更近不知近于何終遠極</span>  
<span style="margin-left: 1em">或當先近不知改于何年近極或當返遠不知轉于何</span>  
<span style="margin-left: 1em">日此則非理數所能窮非思路所能及故曰易見也不</span>  
<span style="margin-left: 1em">可知也而近世曆家以支離之詞文鹵莽之術揣摩者</span>  
<span style="margin-left: 1em">尚云微有移動誕妄者直曰天度失行自非博稽遠覽</span>  
<span style="margin-left: 1em">探賾索隱何繇知天運之必無僣差天事之終難究竟</span>  
<span style="margin-left: 1em">耶然則法當何如曰無他道焉深論理明著數精擇人</span>  
<span style="margin-left: 1em">審造器隨時測驗追合于天而已西曆所載恆星經緯</span>  
<span style="margin-left: 1em">定自萬曆年間迄今已三十餘載不敢因仍妄用今擬</span>  
<span style="margin-left: 1em">新曆以崇禎元年戊辰歲爲曆元一切撰造斷以是年</span>  
<span style="margin-left: 1em">爲始故恆星黃赤道經緯皆用是年實躔度分展轉推</span>  
<span style="margin-left: 1em">算三四較勘無有差忒然後繪圖立表以待施用别爲</span>  
<span style="margin-left: 1em">恆星曆指三卷首言測驗諸法次言本行及經緯度變</span>  
<span style="margin-left: 1em">易又次言經緯相求繪圖法義于所謂深論理明著數</span>  
<span style="margin-left: 1em">者未及詳備已得其十二三矣用之百年當無舛戾後</span>  
<span style="margin-left: 1em">此依法推變畧如前説凡爲圖二十有五立成表四卷</span>  
<span style="margin-left: 1em">其與舊傳天文圖稍異者舊圖無緯度并分宫分宿亦</span>  
<span style="margin-left: 1em">千二百年前所定今則皆係見測又圖中止有形象而</span>  
<span style="margin-left: 1em">無本星躔度回回曆立成所載有黃道經緯度者上二</span>  
<span style="margin-left: 1em">百七十八星其繪圖者止十七座九十四星亦無赤道</span>  
<span style="margin-left: 1em">經緯今皆崇禎元年所測黃赤二道經緯度分各各備</span>  
<span style="margin-left: 1em">具各各正對一加量度即圖中各星所在度分與立成</span>  
<span style="margin-left: 1em">表所載本星度分各各符同並無差失凡有測而入表</span>  
<span style="margin-left: 1em">者一千三百五十六星所分大小等次遠近位置紆直</span>  
<span style="margin-left: 1em">形模悉與天象相合其所繇符合者非從舊圖改易非</span>  
<span style="margin-left: 1em">從懸象倣摹若改易倣摹不惟不合去之彌遠今此諸</span>  
<span style="margin-left: 1em">圖黃赤經緯每座每星測算既確次于圖中依表點定</span>  
<span style="margin-left: 1em">乃加印記後方聯綴所謂閉門造車出而合轍因此知</span>  
<span style="margin-left: 1em">前之測候曾無乖爽後來致用可無謬誤也其舊圖未</span>  
<span style="margin-left: 1em">載而體勢明晳測量已定經緯悉具者一一增入舊圖</span>  
<span style="margin-left: 1em">所有而微細隱約者雖仍其位座目所未見星猶闕焉</span>  
<span style="margin-left: 1em">此外微星雖分明可見而不在測數者悉無增加免致</span>  
<span style="margin-left: 1em">煩亂至若舊圖中南天田六甲天柱天床等皆茫昧依</span>  
<span style="margin-left: 1em">希不成位座又如器府天理八魁天廟等按圖索之了</span>  
<span style="margin-left: 1em">不可得其近處多有微星或云昔之作者牽合此星綴</span>  
<span style="margin-left: 1em">緝成形以補苴空缺今欲依經緯度分聯之即非本像</span>  
<span style="margin-left: 1em">因仍舊貫則飾無爲有迹涉矯誣儻令依圖指陳依法</span>  
<span style="margin-left: 1em">測驗將無辭以對不得不并廢其名也恆星曆三卷共</span>

<span style="margin-left: 2em">測恆星法第一　一章</span>  
<span style="margin-left: 1em">凡治曆以七政經緯度分爲本欲知七政經緯度分以</span>  
<span style="margin-left: 2em">恆星度分爲本欲察恆星得其所居定處必用測星</span>  
<span style="margin-left: 2em">之法測星之法有三其一用太陰用太陰者令太陰</span>  
<span style="margin-left: 2em">居太陽恆星之間早測則太陽未出先測星與太陰</span>  
<span style="margin-left: 2em">之距度既出即測太陰與太陽之距度晚測則太陽</span>

<span style="margin-left: 3em">測恆星相距之器</span>  
<span style="margin-left: 1em">如前圖甲乙丙爲全圈六分之一名紀限儀者曆家以</span>  
<span style="margin-left: 2em">六十爲紀法以別於四分一之象限也甲爲全圈之</span>  
<span style="margin-left: 2em">心乙丙爲紀限之弧分六十度度分六分十二或三</span>  
<span style="margin-left: 2em">十任儀大小作之儀愈大分愈細即愈善耳甲丁尺</span>  
<span style="margin-left: 2em">爲度尺樹圓表於甲以爲尺樞其末丁游移弧上以</span>  
<span style="margin-left: 2em">定度分切度分之處剡其半爲中線以直當甲心之</span>  
<span style="margin-left: 2em">一點丁上立一通光耳耳上於中線兩旁各作一罅</span>  
<span style="margin-left: 2em">各與中線平行兩罅之間與甲表之徑等是耳随尺</span>  
<span style="margin-left: 2em">游移故名通光游耳又於乙上立一耳常定不移是</span>  
<span style="margin-left: 2em">名通光定耳又別作一耳用則加之否則去之是名</span>  
<span style="margin-left: 2em">通光設耳三耳之用不同其制一也又於己上立一</span>  
<span style="margin-left: 2em">小表弧之上去乙二十度爲戊去乙丙各三十度爲</span>  
<span style="margin-left: 2em">庚己戊線與甲庚平行使從戊闚己從庚闚甲其度</span>  
<span style="margin-left: 2em">分等而通光設耳之本所則戊也全器以架承之或</span>  
<span style="margin-left: 2em">爲圓球架或爲三樞架令上下左右偏正無所不可</span>  
<span style="margin-left: 2em">以便展轉測諸曜之距度分測法先定所測之二星</span>  
<span style="margin-left: 2em">順其正斜之勢以儀面承之以搘杖支之次令一人</span>  
<span style="margin-left: 2em">從定耳之一罅窺甲表同方之一邊令目與表與第</span>  
<span style="margin-left: 2em">一星相參直又一人從游耳窺第二星亦如之次視</span>  
<span style="margin-left: 2em">兩耳下兩中線之間弧上距度分即兩星之距度分</span>  
<span style="margin-left: 2em">也若兩距度分絕少難容兩人並測即加設耳於戊</span>  
<span style="margin-left: 2em">以戊己當乙甲向己表窺第一星而丁甲度尺對第</span>  
<span style="margin-left: 2em">二星如前從庚右數之即所測之距度因戊己與庚</span>  
<span style="margin-left: 2em">甲爲平行線故也凡測日與月月與星星與日皆倣</span>  
<span style="margin-left: 2em">此但日光照耀表景多虛淡不明宜用展縮木筩一</span>  
<span style="margin-left: 2em">具加度尺之上以束光聚影則灼然易見矣</span>

<span style="margin-left: 3em">測恆星赤道經緯度之器</span>  
<span style="margin-left: 1em">如前圖乙爲子午圈周分三百六十度游移架上以就</span>  
<span style="margin-left: 2em">本方北極出地之高平分其周而設之軸平分其軸</span>  
<span style="margin-left: 2em">而設之表當天頂而設之垂線下置垂權至於壬而</span>  
<span style="margin-left: 2em">止以取平也架之下設螺轉之臬四<sub class="note-jiao">校：梵蒂岡本臬四作臬三</sub>以</span>  
<span style="margin-left: 2em">爲足展轉視垂權而高下之以取平也軸之兩端入</span>  
<span style="margin-left: 2em">於乙圈之鑿欲其利轉也其交於己圈也己圈之交</span>  
<span style="margin-left: 2em">於丙丁圈也持之欲其固也丙丁圈者赤道也平分</span>  
<span style="margin-left: 2em">兩極而居於己圈之中界故又名中圈也己與丙丁</span>  
<span style="margin-left: 2em">兩圈爲一體旋轉相從而兩圈之內又設爲戊辛之</span>  
<span style="margin-left: 2em">圈戊辛與外圈同軸自爲旋運不交於外圈而丙丁</span>  
<span style="margin-left: 2em">戊辛兩圈之上各設兩游耳游耳者可離可合百游</span>  
<span style="margin-left: 2em">無定之通光耳也兩圈之各兩面皆平分爲三百六</span>  
<span style="margin-left: 2em">十以定度分其測星也用赤道圈求經度法以兩通</span>  
<span style="margin-left: 2em">光耳一定焉一游焉一人從定耳窺軸心之甲表與</span>  
<span style="margin-left: 2em">第一星參直一人移游耳展轉遷就窺甲表與第二</span>  
<span style="margin-left: 2em">星參直兩耳間之度分即兩星之真經度差也用戊</span>  
<span style="margin-left: 2em">辛圈求緯度亦以通光耳遷就焉若測向北緯度即</span>  
<span style="margin-left: 2em">設耳於赤道南測向南緯度即設耳於赤道北皆準</span>  
<span style="margin-left: 2em">諸軸心之甲表令目與表與所測星參直乃止次簡</span>  
<span style="margin-left: 2em">游耳下本圈之度分在赤道圈或南或北凡若干即</span>
