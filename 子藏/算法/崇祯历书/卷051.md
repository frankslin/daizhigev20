<span style="margin-left: 1em">恒星历叙目</span>  
<span style="margin-left: 1em">历以齐七政乃自日躔而后首论恒星者何也曰日躔</span>  
<span style="margin-left: 1em">终古行黄道其经其纬易定耳若月五星各有道各有</span>  
<span style="margin-left: 1em">极各有交各有转纷糅不齐非先定恒星之经纬即六</span>  
<span style="margin-left: 1em">曜之经纬无从可论故六曜如乘传恒星其地志也六</span>  
<span style="margin-left: 1em">曜如行棋恒星其楸局也以是先恒星也恒星之黄道</span>  
<span style="margin-left: 1em">赤道须并论者何也曰赤道在天中终古不变推步者</span>  
<span style="margin-left: 1em">赖为准则焉乃诸曜皆循黄道行一切躔度因之布算</span>  
<span style="margin-left: 1em">故用赤道经纬以求合于天元用黄道经纬以求合于</span>  
<span style="margin-left: 1em">本行则七政如海舟黄道其行程赤道其望山也故黄</span>  
<span style="margin-left: 1em">赤二道须并论也二道之兼求经纬何也曰凡测量躔</span>  
<span style="margin-left: 1em">度及交食会合必将定其所至之处左右前后纤微乖</span>  
<span style="margin-left: 1em">舛非定处矣故二道之各经各纬如棋局之有纵有横</span>  
<span style="margin-left: 1em">地图之有袤有广阙其一固不可也然则自古历家何</span>  
<span style="margin-left: 1em">以皆有经度无纬度乎曰创始难工增修易善前人所</span>  
<span style="margin-left: 1em">作为后人之师前人所缺待后人而补凡事尽然历为</span>  
<span style="margin-left: 1em">尤甚者天事难明故也有经无纬正前人所未及回回</span>  
<span style="margin-left: 1em">历有经有纬而成法为千年前所立至今无测候改定</span>  
<span style="margin-left: 1em">者亦彼法所未及也曰繇前取喻既以为邮之志棋之</span>  
<span style="margin-left: 1em">局宜恒定不易矣今又须测候改定则是恒星之经纬</span>  
<span style="margin-left: 1em">亦非恒定也已自不定曷为他行待彼而定曰天载无</span>  
<span style="margin-left: 1em">穷天能无尽大圜在上既为动体凡在体中无有不动</span>  
<span style="margin-left: 1em">若云不动则有穷之属也顾其为动动必有法若云无</span>  
<span style="margin-left: 1em">法又无能之属也天岂然哉非止动而已也凡能动者</span>  
<span style="margin-left: 1em">皆有四端一曰随动一曰自动一曰疾动一曰迟动宗</span>  
<span style="margin-left: 1em">动西行诸曜从之此随动也七曜恒星各自东行而各</span>  
<span style="margin-left: 1em">有法此自动也西行一日一周其为亟速非思议所及</span>  
<span style="margin-left: 1em">此疾动也诸曜东行经时不等比于宗动皆可名迟最</span>  
<span style="margin-left: 1em">迟者二万五千余年而东行一周此迟动也今论恒星</span>  
<span style="margin-left: 1em">则属自动又属迟动自动既有法即依法推步可为他</span>  
<span style="margin-left: 1em">行之法迟动即数十年而征露端倪数百年而灼见违</span>  
<span style="margin-left: 1em">离违离之后因可随时革正端倪初见不妨豫为更易</span>  
<span style="margin-left: 1em">其或甄明此学人不绝世即数年之间一为推变有何</span>  
<span style="margin-left: 1em">不可向所云测候改定职此之繇易称治历明时取象</span>  
<span style="margin-left: 1em">于革至哉乎一言蔽之矣曰向言每一动者各有四动</span>  
<span style="margin-left: 1em">今恒星之黄赤经纬又属四种此四动者异乎同乎曰</span>  
<span style="margin-left: 1em">安得同乎黄赤二道位置不等其各两极不等二经二</span>  
<span style="margin-left: 1em">纬纵横不等交互不等故令星行不等其差亦不等有</span>  
<span style="margin-left: 1em">名为有差而绝不可谓差者黄道之经度是也恒星依</span>  
<span style="margin-left: 1em">黄道东行如载籍相传尧时冬至日躔约在虚七度今</span>  
<span style="margin-left: 1em">躔箕四度四千年间而日退行若干度者即星之进行</span>  
<span style="margin-left: 1em">若干度也古历谓之岁差各立年率郭守敬以为六十</span>  
<span style="margin-left: 1em">六年有奇而差一度今者斟酌异同辨析微妙定为每</span>  
<span style="margin-left: 1em">歳东行一分四十三秒七十三微二十六纤六十九年</span>  
<span style="margin-left: 1em">一百九十一日七十三刻而行一度凡二万五千二百</span>  
<span style="margin-left: 1em">〇二年九十一日二十五刻而行天一周终古恒然也</span>  
<span style="margin-left: 1em">此立名为差而实有定法不可谓差者也有行度不爽</span>  
<span style="margin-left: 1em">而两道参差致生违异者赤道之经度是也星依黄道</span>  
<span style="margin-left: 1em">行与赤道诸纬皆以斜角相遇两经相较是生广狭因</span>  
<span style="margin-left: 1em">其广狭是生疾迟又因其斜迤而从赤极分经古今各</span>  
<span style="margin-left: 1em">测复生参错其南北东西亟舒宽迮互有乘除一再廻</span>  
<span style="margin-left: 1em">易即还故处此则星经不异而以交道为异者也有星</span>  
<span style="margin-left: 1em">本平行而两距变易致成升降者赤道之纬度是也黄</span>  
<span style="margin-left: 1em">亦两至之距为二十三度八十六分有奇星从南至行</span>  
<span style="margin-left: 1em">北距如是既迄象限与赤同行迨于半周则其距南亦</span>  
<span style="margin-left: 1em">复乃尔计行半周而南北距差四十七度七十二分有</span>  
<span style="margin-left: 1em">奇尽一周而复是其星行不异而以距度为异者也至</span>  
<span style="margin-left: 1em">若黄赤二道两至之距古来皆称二十四度今测定为</span>  
<span style="margin-left: 1em">二十三度八十六分七十六秒考之西史所载周显王</span>  
<span style="margin-left: 1em">时一测西汉景帝时一测东汉顺帝时一测三史折衷</span>  
<span style="margin-left: 1em">为二十四度一十八分三十秒以较今测差三十一分</span>  
<span style="margin-left: 1em">五十四秒此为二道之两至距度二千年间昔远今近</span>  
<span style="margin-left: 1em">渐次移易之数也故有不系星行不关经度而躔道自</span>  
<span style="margin-left: 1em">为近京者黄道之纬度是也合四者论之有易见易知</span>  
<span style="margin-left: 1em">者一有难见而可知者二有易见而不可知者一黄道</span>  
<span style="margin-left: 1em">经行与日躔同类理明数顺易见易知矣赤经赤纬纠</span>  
<span style="margin-left: 1em">纷转易致为繁曲然其理可推其数可循总皆二万五</span>  
<span style="margin-left: 1em">千二百〇二年有奇而一周则难见而可知也惟是黄</span>  
<span style="margin-left: 1em">纬一差分数晓然然古时既远上古时当更远不知远</span>  
<span style="margin-left: 1em">于何始今时既近后来者当更近不知近于何终远极</span>  
<span style="margin-left: 1em">或当先近不知改于何年近极或当返远不知转于何</span>  
<span style="margin-left: 1em">日此则非理数所能穷非思路所能及故曰易见也不</span>  
<span style="margin-left: 1em">可知也而近世历家以支离之词文卤莽之术揣摩者</span>  
<span style="margin-left: 1em">尚云微有移动诞妄者直曰天度失行自非博稽远览</span>  
<span style="margin-left: 1em">探赜索隐何繇知天运之必无僣差天事之终难究竟</span>  
<span style="margin-left: 1em">耶然则法当何如曰无他道焉深论理明著数精择人</span>  
<span style="margin-left: 1em">审造器随时测验追合于天而已西历所载恒星经纬</span>  
<span style="margin-left: 1em">定自万历年间迄今已三十余载不敢因仍妄用今拟</span>  
<span style="margin-left: 1em">新历以崇祯元年戊辰岁为历元一切撰造断以是年</span>  
<span style="margin-left: 1em">为始故恒星黄赤道经纬皆用是年实躔度分展转推</span>  
<span style="margin-left: 1em">算三四较勘无有差忒然后绘图立表以待施用别为</span>  
<span style="margin-left: 1em">恒星历指三卷首言测验诸法次言本行及经纬度变</span>  
<span style="margin-left: 1em">易又次言经纬相求绘图法义于所谓深论理明著数</span>  
<span style="margin-left: 1em">者未及详备已得其十二三矣用之百年当无舛戾后</span>  
<span style="margin-left: 1em">此依法推变畧如前说凡为图二十有五立成表四卷</span>  
<span style="margin-left: 1em">其与旧传天文图稍异者旧图无纬度并分宫分宿亦</span>  
<span style="margin-left: 1em">千二百年前所定今则皆系见测又图中止有形象而</span>  
<span style="margin-left: 1em">无本星躔度回回历立成所载有黄道经纬度者上二</span>  
<span style="margin-left: 1em">百七十八星其绘图者止十七座九十四星亦无赤道</span>  
<span style="margin-left: 1em">经纬今皆崇祯元年所测黄赤二道经纬度分各各备</span>  
<span style="margin-left: 1em">具各各正对一加量度即图中各星所在度分与立成</span>  
<span style="margin-left: 1em">表所载本星度分各各符同并无差失凡有测而入表</span>  
<span style="margin-left: 1em">者一千三百五十六星所分大小等次远近位置纡直</span>  
<span style="margin-left: 1em">形模悉与天象相合其所繇符合者非从旧图改易非</span>  
<span style="margin-left: 1em">从悬象倣摹若改易倣摹不惟不合去之弥远今此诸</span>  
<span style="margin-left: 1em">图黄赤经纬每座每星测算既确次于图中依表点定</span>  
<span style="margin-left: 1em">乃加印记后方联缀所谓闭门造车出而合辙因此知</span>  
<span style="margin-left: 1em">前之测候曾无乖爽后来致用可无谬误也其旧图未</span>  
<span style="margin-left: 1em">载而体势明晳测量已定经纬悉具者一一增入旧图</span>  
<span style="margin-left: 1em">所有而微细隐约者虽仍其位座目所未见星犹阙焉</span>  
<span style="margin-left: 1em">此外微星虽分明可见而不在测数者悉无增加免致</span>  
<span style="margin-left: 1em">烦乱至若旧图中南天田六甲天柱天床等皆茫昧依</span>  
<span style="margin-left: 1em">希不成位座又如器府天理八魁天庙等按图索之了</span>  
<span style="margin-left: 1em">不可得其近处多有微星或云昔之作者牵合此星缀</span>  
<span style="margin-left: 1em">缉成形以补苴空缺今欲依经纬度分联之即非本像</span>  
<span style="margin-left: 1em">因仍旧贯则饰无为有迹涉矫诬傥令依图指陈依法</span>  
<span style="margin-left: 1em">测验将无辞以对不得不并废其名也恒星历三卷共</span>

<span style="margin-left: 2em">测恒星法第一　一章</span>  
<span style="margin-left: 1em">凡治历以七政经纬度分为本欲知七政经纬度分以</span>  
<span style="margin-left: 2em">恒星度分为本欲察恒星得其所居定处必用测星</span>  
<span style="margin-left: 2em">之法测星之法有三其一用太阴用太阴者令太阴</span>

<span style="margin-left: 2em">六十为纪法以别于四分一之象限也甲为全圈之</span>  
<span style="margin-left: 2em">心乙丙为纪限之弧分六十度度分六分十二或三</span>  
<span style="margin-left: 2em">十任仪大小作之仪愈大分愈细即愈善耳甲丁尺</span>  
<span style="margin-left: 2em">为度尺树圆表于甲以为尺枢其末丁游移弧上以</span>  
<span style="margin-left: 2em">定度分切度分之处剡其半为中线以直当甲心之</span>  
<span style="margin-left: 2em">一点丁上立一通光耳耳上于中线两旁各作一罅</span>  
<span style="margin-left: 2em">各与中线平行两罅之间与甲表之径等是耳随尺</span>  
<span style="margin-left: 2em">游移故名通光游耳又于乙上立一耳常定不移是</span>  
<span style="margin-left: 2em">名通光定耳又别作一耳用则加之否则去之是名</span>  
<span style="margin-left: 2em">通光设耳三耳之用不同其制一也又于己上立一</span>  
<span style="margin-left: 2em">小表弧之上去乙二十度为戊去乙丙各三十度为</span>  
<span style="margin-left: 2em">庚己戊线与甲庚平行使从戊闚己从庚闚甲其度</span>  
<span style="margin-left: 2em">分等而通光设耳之本所则戊也全器以架承之或</span>  
<span style="margin-left: 2em">为圆球架或为三枢架令上下左右偏正无所不可</span>  
<span style="margin-left: 2em">以便展转测诸曜之距度分测法先定所测之二星</span>  
<span style="margin-left: 2em">顺其正斜之势以仪面承之以搘杖支之次令一人</span>  
<span style="margin-left: 2em">从定耳之一罅窥甲表同方之一边令目与表与第</span>  
<span style="margin-left: 2em">一星相参直又一人从游耳窥第二星亦如之次视</span>  
<span style="margin-left: 2em">两耳下两中线之间弧上距度分即两星之距度分</span>  
<span style="margin-left: 2em">也若两距度分绝少难容两人并测即加设耳于戊</span>  
<span style="margin-left: 2em">以戊己当乙甲向己表窥第一星而丁甲度尺对第</span>  
<span style="margin-left: 2em">二星如前从庚右数之即所测之距度因戊己与庚</span>

<span style="margin-left: 3em">测恒星赤道经纬度之器</span>  
<span style="margin-left: 1em">如前图乙为子午圈周分三百六十度游移架上以就</span>  
<span style="margin-left: 2em">本方北极出地之高平分其周而设之轴平分其轴</span>  
<span style="margin-left: 2em">而设之表当天顶而设之垂线下置垂权至于壬而</span>  
<span style="margin-left: 2em">止以取平也架之下设螺转之臬四<sub class="note-jiao">校：梵蒂岡本臬四作臬三</sub>以</span>  
<span style="margin-left: 2em">为足展转视垂权而高下之以取平也轴之两端入</span>  
<span style="margin-left: 2em">于乙圈之凿欲其利转也其交于己圈也己圈之交</span>  
<span style="margin-left: 2em">于丙丁圈也持之欲其固也丙丁圈者赤道也平分</span>  
<span style="margin-left: 2em">两极而居于己圈之中界故又名中圈也己与丙丁</span>  
<span style="margin-left: 2em">两圈为一体旋转相从而两圈之内又设为戊辛之</span>  
<span style="margin-left: 2em">圈戊辛与外圈同轴自为旋运不交于外圈而丙丁</span>  
<span style="margin-left: 2em">戊辛两圈之上各设两游耳游耳者可离可合百游</span>  
<span style="margin-left: 2em">无定之通光耳也两圈之各两面皆平分为三百六</span>  
<span style="margin-left: 2em">十以定度分其测星也用赤道圈求经度法以两通</span>  
<span style="margin-left: 2em">光耳一定焉一游焉一人从定耳窥轴心之甲表与</span>  
<span style="margin-left: 2em">第一星参直一人移游耳展转迁就窥甲表与第二</span>  
<span style="margin-left: 2em">星参直两耳间之度分即两星之真经度差也用戊</span>
