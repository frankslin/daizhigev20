## 崇禎曆書卷之七十八　幾何要法卷四

<span style="margin-left: 1em">幾何要法卷之四目錄</span>  
<span style="margin-left: 3em">界說章第一<sub class="note-yuan">八則</sub></span>  
<span style="margin-left: 3em">一直線上求立直角方形章第三</span>  
<span style="margin-left: 3em">有直線形求作直角方形與之等章第四</span>  
<span style="margin-left: 3em">有三角形求作平行方形與之等而方形角又與</span>  
<span style="margin-left: 4em">所設角等章第五</span>  
<span style="margin-left: 3em">有多邊直線形求作一平行方形與之等而方形</span>  
<span style="margin-left: 4em">角又與所設角等章第六</span>  
<span style="margin-left: 3em">有多直角方形求并作一直角方形與之等章第</span>  
<span style="margin-left: 4em">七</span>  
<span style="margin-left: 3em">有平行方形求作三角形與之等而三角形一角</span>  
<span style="margin-left: 4em">如所設角等章第八</span>  
<span style="margin-left: 3em">一直線上求作平行方形與所設三角形等而方</span>  
<span style="margin-left: 4em">形角又與所設角等章第九</span>  
<span style="margin-left: 3em">設不等兩直角方形如一以甲爲邊一以乙爲邊</span>  
<span style="margin-left: 4em">求別作兩直角方形自相等而并之又與元設</span>  
<span style="margin-left: 4em">兩形并等章第十</span>  
<span style="margin-left: 3em">兩直線形不等求相減之較幾何章第十一</span>  
<span style="margin-left: 3em">有圜求作一直角方形與之等章第十二</span>  
<span style="margin-left: 3em">有直角方形求作一圜與之等章第十三</span>  
<span style="margin-left: 3em">推用一法任有直線形求作一圜與之等又任設</span>  
<span style="margin-left: 3em">一圜求作直線形與之等</span>  
<span style="margin-left: 1em">幾何要法卷之四<sub class="note-yuan">本篇論方形計界說八章數十三要法十四</sub></span>  
<span style="margin-left: 2em">泰　西　艾儒略口述　吳淞陳于階</span>  
<span style="margin-left: 2em">海　虞　瞿式穀筆受　陸安鄭洪猷仝校梓</span>  
<span style="margin-left: 2em">古　閩　葉益蕃參校　山陰陳應登</span>  
<span style="margin-left: 1em"><sub class="note-jiao">校：法圖本以下三人</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">闕較諱字改作校</sub></span>  
<span style="margin-left: 2em">界說章第一<sub class="note-yuan">凡八則</sub></span>  
<span style="margin-left: 3em">第一界</span>  
<span style="margin-left: 4em">方形者四直線兩縱兩橫相遇所成亦謂之四</span>  
<span style="margin-left: 4em">邊形如上甲圖</span>  
<span style="margin-left: 3em">第二界</span>  
<span style="margin-left: 4em">四邊形之四線等而四直角者爲直角方形如</span>  
<span style="margin-left: 4em">上甲圖</span>  
<span style="margin-left: 3em">第三界</span>  
<span style="margin-left: 4em">四邊兩兩相等而俱直角者爲長直方形如上</span>  
<span style="margin-left: 4em">乙圖</span>  
<span style="margin-left: 3em">第四界</span>  
<span style="margin-left: 4em">四邊等但非直角者爲斜方形如上丙圖</span>  
<span style="margin-left: 6em">第五界</span>  
<span style="margin-left: 4em">四邊兩兩相等但非直角者爲長斜方形如上</span>  
<span style="margin-left: 1em">丁圖</span>  
<span style="margin-left: 3em">第六界</span>  
<span style="margin-left: 4em">已上方形四種謂之有法四邊形四種之外他</span>  
<span style="margin-left: 4em">方形皆謂之無法四邊形如上戊圖等本卷多</span>  
<span style="margin-left: 1em">以直方形爲論爲其多有用也</span>  
<span style="margin-left: 3em">第七界</span>  
<span style="margin-left: 5em">凡形每兩邊有平行線爲平行線方形如上</span>  
<span style="margin-left: 5em">已圖</span>  
<span style="margin-left: 3em">第八界</span>  
<span style="margin-left: 1em">凡平行線方形若于兩對角作一直線其直線爲對角</span>  
<span style="margin-left: 1em">線又于兩邊縱橫各作一平行線其兩平行線與對角</span>  
<span style="margin-left: 1em">線交羅相遇即此形分爲四平行線方形其兩形有對</span>  
<span style="margin-left: 1em">角線者爲角線方形其兩形無對角線者爲餘方形如</span>  
<span style="margin-left: 5em">甲乙丙丁方形于丙乙兩角作一線爲對角</span>  
<span style="margin-left: 5em">線又依乙丁平行作戊己線依甲乙平行作</span>  
<span style="margin-left: 5em">庚辛線其對角線與戊己庚辛兩線交羅相</span>  
<span style="margin-left: 5em">遇于壬即作大小四平行線方形矣則庚壬</span>  
<span style="margin-left: 5em">己丙及戊壬辛乙謂之角線方形而甲庚壬</span>  
<span style="margin-left: 1em">戊及壬己丁辛謂之餘方形</span>  
<span style="margin-left: 2em">審矩章第二</span>  
<span style="margin-left: 1em">凡作方形必欲用矩故先論審矩法後論棄矩求方之</span>  
<span style="margin-left: 5em">法矩以兩尺縱橫而成然必成直角方準若</span>  
<span style="margin-left: 5em">稍出入必爲銳鈍兩角而不成矩今欲審直</span>  
<span style="margin-left: 5em">角先審兩尺之稜如首卷第一法後于他堅</span>  
<span style="margin-left: 1em">體上作半圜中畫徑線次以矩角倚半圜之界視二尺</span>  
<span style="margin-left: 1em">稜正切徑線與圜相交處則矩準而可用矣若有出入</span>  
<span style="margin-left: 1em">則當更改或于堅體上作一直線更作一垂線四邊作</span>  
<span style="margin-left: 1em">直角以一矩準四直角不爽則至準矣</span>  
<span style="margin-left: 2em">一直線上求立直角方形章第三</span>  
<span style="margin-left: 1em">如甲乙線上求立直角方形先于甲乙兩界各立垂線</span>  
<span style="margin-left: 5em">爲丁甲爲丙乙皆與甲乙線等次作丁丙線</span>  
<span style="margin-left: 5em">相聯即得所求</span>  
<span style="margin-left: 2em">有直線形求作直角方形與之等章第四</span>  
<span style="margin-left: 1em">甲直線無法四邊形求作直角方形與之等先作乙丁</span>  
<span style="margin-left: 5em">形與甲等<sub class="note-yuan">本卷第五第六章</sub>而直角次任用一邊引</span>  
<span style="margin-left: 5em">長之如丁丙引之至己而丙己與乙丙等次</span>  
<span style="margin-left: 5em">以丁己兩平分于庚其庚點或在丙點或在</span>  
<span style="margin-left: 5em">丙點之外若在丙即乙丁是直角方形與甲</span>  
<span style="margin-left: 1em">等矣若庚在丙外即以庚爲心丁己爲界作丁辛己半</span>  
<span style="margin-left: 1em">圜末從乙丙線引長之遇圜界于辛即丙辛上直角方</span>  
<span style="margin-left: 1em">形與甲等如上圖丙辛壬癸</span>  
<span style="margin-left: 2em">有三角形求作平行方形與之等而方形角又與所</span>  
<span style="margin-left: 3em">設角等章第五</span>  
<span style="margin-left: 1em">設甲乙丙角形丁角求作平行方形與甲乙丙角形等</span>  
<span style="margin-left: 5em">而有丁角先分一邊爲兩平分如乙丙邊平</span>  
<span style="margin-left: 5em">分于戊次作丙戊己角與丁角等次自甲作</span>  
<span style="margin-left: 5em">直線與乙丙平行而與戊己線遇于己末自</span>  
<span style="margin-left: 5em">丙作直線與戊己平行爲丙庚而與甲己線</span>  
<span style="margin-left: 1em">遇于庚則得己戊丙庚平行方形與甲乙丙角形等而</span>  
<span style="margin-left: 1em">有丁角</span>  
<span style="margin-left: 2em">有多邊直線形求作一平行方形與之等而方形角</span>  
<span style="margin-left: 3em">又與所設角等章第六</span>  
<span style="margin-left: 5em">設甲乙丙五邊形丁角求作平行方形與五</span>  
<span style="margin-left: 5em">邊形等而有丁角先分五邊形爲甲乙丙三</span>  
<span style="margin-left: 5em"><sub class="note-yuan">三角</sub>形次依前章法作戊己庚辛平行方形與</span>  
<span style="margin-left: 5em">甲等而有丁角次于戊辛己庚兩平行線引</span>  
<span style="margin-left: 1em">長之作庚辛壬癸平行方形與乙等而有丁角末復引</span>  
<span style="margin-left: 1em">前線作壬癸子丑平行方形與丙等而有丁角即此三</span>  
<span style="margin-left: 1em">形并爲一平行方形與甲乙丙併形等而有丁角自五</span>  
<span style="margin-left: 1em">邊以上可至無窮俱倣此法</span>  
<span style="margin-left: 2em">有多直角方形求并作一直角方形與之等章第七</span>  
<span style="margin-left: 6em">如五直角方形以甲乙丙丁戊爲邊任等</span>  
<span style="margin-left: 6em">不等求作一直角方形與五形等先作己</span>  
<span style="margin-left: 6em">庚辛直角而己庚線與甲等庚辛線與乙</span>  
<span style="margin-left: 6em">等次作己辛線旋作己辛壬直角而辛壬</span>  
<span style="margin-left: 6em">與丙等次作己壬線旋作己壬癸直角而</span>  
<span style="margin-left: 6em">壬癸與丁等次作己癸線旋作己癸子直</span>  
<span style="margin-left: 6em">角而癸子與戊等末作己子線而己子線</span>  
<span style="margin-left: 6em">上所作直角方形即所求</span>  
<span style="margin-left: 2em">有平行方形求作三角形與之等而三角形</span>  
<span style="margin-left: 3em">角如所設角等章第八</span>  
<span style="margin-left: 5em">如有甲乙丙丁平行方形戊角先作丁乙己</span>  
<span style="margin-left: 5em">角與戊等遇甲丙線于己次以乙丁線引長</span>  
<span style="margin-left: 5em">之爲庚取丁庚度與乙丁等末作己庚直線</span>  
<span style="margin-left: 1em">乙丙庚三角形與甲乙丙丁平行方形等而有戊角即</span>  
<span style="margin-left: 1em">所求</span>  
<span style="margin-left: 2em">一直線上求作平行方形與所設三角形等而方形</span>  
<span style="margin-left: 3em">角又與所設角等章第九</span>  
<span style="margin-left: 1em">設甲線乙角形丙角求于甲線上作平行方形與乙角</span>  
<span style="margin-left: 1em">形等而有丙角先依本卷第五章法作丁戊己庚平行</span>  
<span style="margin-left: 5em">方形與乙角形等而戊己庚角與丙角等次</span>  
<span style="margin-left: 5em">于庚己線引長之作己辛線次作辛壬線與</span>  
<span style="margin-left: 5em">戊己平行次于丁戊引長之與辛壬線遇于</span>  
<span style="margin-left: 5em">壬次自壬至己作對角線引出之又自丁庚</span>  
<span style="margin-left: 5em">引長之與對角線遇于癸次自癸作直線與</span>  
<span style="margin-left: 1em">庚辛平行又于壬辛引長之與癸線遇于子末于戊己</span>  
<span style="margin-left: 1em">引長之至癸子線得丑即己丑子辛平行方形如所求</span>  
<span style="margin-left: 1em">如欲即于甲線立形則先依本章法作己辛子丑方形</span>  
<span style="margin-left: 1em">次于甲線一界作寅角如辛己丑角等次取寅卯如己</span>  
<span style="margin-left: 1em">丑等末成平行方形即得所求</span>  
<span style="margin-left: 2em">設不等兩直角方形如一以甲爲邊一以乙爲邊求</span>  
<span style="margin-left: 3em">別作兩直角方形自相等而并之又與元設兩形</span>  
<span style="margin-left: 3em">并等章第十</span>  
<span style="margin-left: 5em">先作丙戊線與甲等次作戊丙丁直角而丙</span>  
<span style="margin-left: 5em">丁線與乙等次作戊丁線相聯末于丙丁戊</span>  
<span style="margin-left: 5em">角丙戊丁角各作一角皆半于直角己戊己</span>  
<span style="margin-left: 5em">丁兩腰相遇于己而等即己戊己丁兩線上</span>  
<span style="margin-left: 1em">所作兩直角方形自相等而并之又與丙戊丙丁上所</span>  
<span style="margin-left: 1em">作兩直角方形等</span>  
<span style="margin-left: 2em">兩直線形不等求相等之較幾何章第十一</span>  
<span style="margin-left: 1em">甲與乙兩直線形甲大于乙以乙減甲求較幾何先任</span>  
<span style="margin-left: 4em">作丁丙己戊平行方形與甲等次于丙丁線上</span>  
<span style="margin-left: 4em">依丁角作丁丙辛庚平行方形與乙等即得辛</span>  
<span style="margin-left: 4em">庚戊己爲相減之較矣</span>  
<span style="margin-left: 6em">有圜求作一直角方形與之等章第十二</span>  
<span style="margin-left: 5em">方圓圓方之法自古名賢究折而未準吾師</span>  
<span style="margin-left: 5em">丁先生幾何六卷之末設此神法其法之用</span>  
<span style="margin-left: 5em">甚廣今撮其要以推作方圓圓方之法先設</span>  
<span style="margin-left: 5em">甲乙丙丁直角方形次以乙爲心以甲爲界</span>  
<span style="margin-left: 1em">作甲丁限象任分爲若干度今姑分爲九十度又分甲</span>  
<span style="margin-left: 1em">乙丙丁兩線如前數爲九十次自乙心至象限逐度皆</span>  
<span style="margin-left: 1em">作虛線次從甲乙丙丁兩線對望作平行線其與限象</span>  
<span style="margin-left: 1em">線交處俱作點次從甲作曲線貫諸點貫諸點之線則</span>  
<span style="margin-left: 1em">甲戊線爲方圓圓方之根線而乙甲爲邊乙丁爲底次</span>  
<span style="margin-left: 1em">自甲至戊作一直線若乙戊直線與所設欲方之圜半</span>  
<span style="margin-left: 1em">徑等則甲乙線爲所設圜限象之界線若圜半徑長則</span>  
<span style="margin-left: 1em">于乙丁線上截乙己與半徑等引長甲乙線作己庚與</span>  
<span style="margin-left: 1em">戊甲線平行庚至乙即長徑圜限象之界線若圜半徑</span>  
<span style="margin-left: 1em">短則于乙丁線上截乙辛與半徑等作辛壬線與戊甲</span>  
<span style="margin-left: 5em">平行則壬至乙即短徑圜限象之界線今有</span>  
<span style="margin-left: 5em">子丑圜或大或小其半徑與乙辛等先作一</span>  
<span style="margin-left: 5em">寅卯直線立一辰己垂線次從己起取己午</span>  
<span style="margin-left: 5em">午未各與乙壬等次取己申與乙辛等次兩</span>  
<span style="margin-left: 5em">平分申未于酉以酉爲心以申或未爲界作</span>  
<span style="margin-left: 5em">半圜切垂線于辰末取己辰作直角方形之</span>  
<span style="margin-left: 1em">一邊則此方形與所設圜等以此可推不特一方與一</span>  
<span style="margin-left: 1em">圜即方之一邊線與圜一限象等方之半邊線與圜半</span>  
<span style="margin-left: 1em">限象等</span>  
<span style="margin-left: 2em">有直角方形求作一圜與之等章第十三</span>  
<span style="margin-left: 6em">如有甲線爲方之邊先取一圜依前法求</span>  
<span style="margin-left: 6em">其作方之線如前度得申己次作辰申直</span>  
<span style="margin-left: 6em">線次截戊己如所設甲線等次自戊作戊</span>  
<span style="margin-left: 6em">卯線與辰申平行末以己卯爲半徑之度</span>  
<span style="margin-left: 6em">作一圜即得所求</span>  
<span style="margin-left: 3em">推用一法</span>  
<span style="margin-left: 1em">依兩章方圓圓方之法可推任有直線形可作一圜與</span>  
<span style="margin-left: 1em">之等又任設一圜可作直線形與之等須先依前章法</span>  
<span style="margin-left: 1em">求多邊直線形作一方形與之等次依本章法作一圜</span>  
<span style="margin-left: 1em">形與直角方形等則得一圜與所設直線形等若又有</span>  
<span style="margin-left: 1em">圜求作一三角形先依本章法作一方與所設圜等次</span>  
<span style="margin-left: 1em">依前法作三角形如所設方形等則所作三角形如原</span>  
<span style="margin-left: 1em">設圜等</span>
