<span style="margin-left: 2em">有直角方形求作一圜与之等章第十三</span>  
<span style="margin-left: 6em">如有甲线为方之边先取一圜依前法求</span>  
<span style="margin-left: 6em">其作方之线如前度得申己次作辰申直</span>

<span style="margin-left: 6em">作一圜即得所求</span>  
<span style="margin-left: 3em">推用一法</span>

<span style="margin-left: 1em">形与直角方形等则得一圜与所设直线形等若又有</span>  
<span style="margin-left: 1em">圜求作一三角形先依本章法作一方与所设圜等次</span>

<span style="margin-left: 1em">设圜等</span>
