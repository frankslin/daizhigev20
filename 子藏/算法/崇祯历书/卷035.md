## 崇祯历书卷之三十五　测食下卷

<span style="margin-left: 1em">测食下卷</span>  
<span style="margin-left: 14em">大西汤若望述</span>  
<span style="margin-left: 14em">慈水周子愚</span>  
<span style="margin-left: 1em">　　　　　　　　　　　　　　　　　　订</span>  
<span style="margin-left: 14em">武林卓尔康</span>  
<span style="margin-left: 3em">月食为地影所隔<sub class="note-yuan">第一</sub></span>  
<span style="margin-left: 1em">问月食必在于望因日月相对之故其说明矣至谓地</span>  
<span style="margin-left: 1em">影隔之而食窃有疑焉曰月对日而受其光苟日月之</span>  
<span style="margin-left: 1em">间非有不通光之实体为之障蔽则必不能阻日光之</span>  
<span style="margin-left: 1em">照月体无论空中之火空中之气与夫天体不能掩月</span>  
<span style="margin-left: 1em">即金水二星虽居日月之间其影俱不及地况能过地</span>  
<span style="margin-left: 1em">而及月乎则知能掩日者惟有地体一面受光一面射</span>  
<span style="margin-left: 1em">影而月体为借光之物入此影中安得不食而半进则</span>  
<span style="margin-left: 1em">半食全进则全食矣</span>  
<span style="margin-left: 3em">月体当食尚有光色<sub class="note-yuan">第二</sub></span>  
<span style="margin-left: 1em">问无光之月一入地影遂全失其借光也然食时尚有</span>  
<span style="margin-left: 1em">依稀可见之光天文家每视食月之色预言食之徴验</span>  
<span style="margin-left: 1em">若人以目切墙屋掩其未食之光体而独视其既食之</span>  
<span style="margin-left: 1em">乌体其光尚明于星也盖物之可见必借外光不独能</span>  
<span style="margin-left: 1em">见物体且更能发越物色也月既在地影即失借光安</span>  
<span style="margin-left: 1em">得尚有色乎曰月体虽食尚有微光今直以影为明者</span>  
<span style="margin-left: 1em">误也以影为暗者亦误也称影为明暗之中者庶为近</span>  
<span style="margin-left: 1em">之盖日所正照为最光明有物隔之而四傍之气映射</span>  
<span style="margin-left: 1em">或对面之光反照虽无最光明亦有次光明也如一室</span>  
<span style="margin-left: 1em">之外为最光明一室之内为次光明也云之上为最光</span>  
<span style="margin-left: 1em">明云之下为次光明也直至所隔愈深去光愈远并次</span>  
<span style="margin-left: 1em">光明亦渐微微而又微以至丝毫无光乃为暗耳夫人</span>  
<span style="margin-left: 1em">与地近日与地远人居地此面日在地彼面至夜子初</span>  
<span style="margin-left: 1em">人在地影至浓之中近物尚能别识何况月在地影至</span>  
<span style="margin-left: 1em">锐之处次光明正盛其有光色又何疑乎且人在极暗</span>  
<span style="margin-left: 1em">则月光虽微视之反觉明也</span>  
<span style="margin-left: 3em">日食在朔月体掩之<sub class="note-yuan">第三</sub></span>  
<span style="margin-left: 1em">问前言月在日前能掩日光是已金水二星亦皆在日</span>  
<span style="margin-left: 1em">前又皆实体且水星虽小而金星则大于月也何独以</span>  
<span style="margin-left: 1em">食属月乎曰二星于人甚远不能掩日百分之一二而</span>  
<span style="margin-left: 1em">日光甚盛即亏百分之一二人亦不觉且二星去日甚</span>  
<span style="margin-left: 1em">近去地甚远所出锐角之影亦甚短决不能及地面也</span>  
<span style="margin-left: 1em">若夫月体虽不及太白之大然去地近去日远一指足</span>  
<span style="margin-left: 1em">蔽泰山又何疑乎由此言之求一实体之能全掩日又</span>  
<span style="margin-left: 1em">从西而东过之甚疾唯月为能盖月之右旋比诸天更</span>  
<span style="margin-left: 1em">速且必至合朔方有食则日食于月决然之理也</span>  
<span style="margin-left: 3em">因食知月体不通光<sub class="note-yuan">第四</sub></span>  
<span style="margin-left: 1em">问月体受光而返照之必不通光如铜鉄镜盖通光则</span>  
<span style="margin-left: 1em">不能受日光而反照他物亦不能掩日而生影也曰镜</span>  
<span style="margin-left: 1em">之设譬似矣而尚未尽夫镜之照物而反生之象其大</span>  
<span style="margin-left: 1em">小远近必与物体相当然后可以镜喻月今观镜之面</span>  
<span style="margin-left: 1em">有突如球有平如案有򐉄如釜惟平者所生之象乃与</span>  
<span style="margin-left: 1em">物体相当若如釜者所生物象必倍于物体如球者所</span>  
<span style="margin-left: 1em">生物象必小于物体矣试以球镜照远物而人又从远</span>  
<span style="margin-left: 1em">视之则物象必倍小尝持球镜照太阳之体其小如星</span>  
<span style="margin-left: 1em">倘月体如球镜欲其反生太阳之象乌可得乎又问合</span>  
<span style="margin-left: 1em">朔后月之下半未受日光而月体微光比诸星更显若</span>  
<span style="margin-left: 1em">不通明则此光又从何生且观其掩日而日全食时月</span>  
<span style="margin-left: 1em">之边际觉稍明于月之中心似中间厚处难通而薄处</span>  
<span style="margin-left: 1em">稍可通透乎曰前既言月在地影最中处乃天光映照</span>  
<span style="margin-left: 1em">之明若合朔时则有光之天与月体最为切近而日光</span>  
<span style="margin-left: 1em">上照月体约有大半四边岂得无光或言月既非极通</span>  
<span style="margin-left: 1em">光如玻瓈或半通光如玉石特因在后之物其体质不</span>  
<span style="margin-left: 1em">明故不能映见在后之物乎曰试观日食甚之时天光</span>  
<span style="margin-left: 1em">尽黑星体亦现尔时太阳在后体质最为明显何以不</span>  
<span style="margin-left: 1em">能映见丝毫可知月体绝不通光也或言在月后之物</span>  
<span style="margin-left: 1em">必更坚密于月者然后能照见若较月更通彻即不能</span>  
<span style="margin-left: 1em">见乎曰若然日体在月后坚密不亚于月而亦不能见</span>  
<span style="margin-left: 1em">可言日体为通彻乎又凡目所注必须有色及所照之</span>  
<span style="margin-left: 1em">光此二者必不通彻之体乃能受之则月体从可推矣</span>  
<span style="margin-left: 3em">月食时人目不及见月受光之面<sub class="note-yuan">第五</sub></span>  
<span style="margin-left: 1em">上言日光照月体大半则知日比月体至大然日食甚</span>  
<span style="margin-left: 1em">之时人目所见之面何故绝无丝毫之光曰凡人视圆</span>  
<span style="margin-left: 1em">球止见小半盖球有大圜有小圜若以两线切大圜其</span>  
<span style="margin-left: 1em">线必为平行今目所注视之线既不能平行则不切至</span>  
<span style="margin-left: 8em">大圜可知而目亦仅能及小圜矣<sub class="note-yuan">详见</sub></span>  
<span style="margin-left: 8em"><sub class="note-yuan">几何一卷二十八题</sub>又望后三日虽月每日行</span>  
<span style="margin-left: 8em">十三度有奇而月边尚似圆圜可见</span>  
<span style="margin-left: 8em">人目正及其小圜也或曰望日所见</span>  
<span style="margin-left: 8em">月体之面即月所受光之面其光为</span>  
<span style="margin-left: 8em">大半则二三日其光尚在大半之内</span>  
<span style="margin-left: 8em">则晦后月轮稍移便宜见光而光今</span>  
<span style="margin-left: 8em">竟不即见何也曰月掩日之时一则</span>  
<span style="margin-left: 8em">人所注之圜与日光照月之圜为平</span>  
<span style="margin-left: 8em">行一则日食时不过一两刻则两线</span>  
<span style="margin-left: 8em">亦不能相切至望则不同矣又望时</span>  
<span style="margin-left: 8em">日光照月少于他时盖晦日日与月</span>  
<span style="margin-left: 8em">止隔金水二星天而甚近故所照亦</span>  
<span style="margin-left: 8em">多于望日望日与月隔金水二天及</span>  
<span style="margin-left: 8em">月本天之体而甚远故所照亦少于</span>  
<span style="margin-left: 8em">他日然晦日所照虽多于望日而人</span>  
<span style="margin-left: 8em">目所及止见小圜而月光不即见职</span>  
<span style="margin-left: 8em">由此矣</span>  
<span style="margin-left: 10em">日月每月不食<sub class="note-yuan">第六</sub></span>  
<span style="margin-left: 8em">夫月不恒食之故有二一则日体常</span>  
<span style="margin-left: 1em">丽躔道则地影亦常对躔道一则月行常出入躔道故</span>  
<span style="margin-left: 1em">他影不及盖凡光照物必直射而作直线今日在躔道</span>  
<span style="margin-left: 1em">其光自平面而直通至地则反影亦反射至天如日光</span>  
<span style="margin-left: 1em">之射地其日光绕地一周则影亦绕天一周其地影至</span>  
<span style="margin-left: 1em">月天濶不过一度半躔道平分地影每边有四分之三</span>  
<span style="margin-left: 1em">又望日月轮不在龙头龙尾近处故月体与地影不得</span>  
<span style="margin-left: 1em">相遇故不食此前篇言每月食三体必在一直线也或</span>  
<span style="margin-left: 1em">曰日食应有多次为其不论月之实所但论月之似所</span>  
<span style="margin-left: 1em">若论似所则南北所差甚多如此则人住两极近处者</span>  
<span style="margin-left: 1em">视月远于躔道亦能食日矣曰人居在北极下而似所</span>  
<span style="margin-left: 1em">与实所相距不过一度譬如月在地平东西差亦不过</span>  
<span style="margin-left: 1em">一度可见日欲食时月不能离躔道一度强故日食亦</span>  
<span style="margin-left: 1em">少也但论一处则日月之食不等槩论天下日食应多</span>  
<span style="margin-left: 1em">于月食也</span>  
<span style="margin-left: 3em">因月食徴地圆如球<sub class="note-yuan">第七</sub></span>  
<span style="margin-left: 1em">格物家悉言地圆如球验之洵不得不然也盖凡物之</span>  
<span style="margin-left: 1em">性重者势必就下若一无所阻必径就天心天心者最</span>  
<span style="margin-left: 1em">下处也故大地四旁皆欲就下其势不得不结为圆然</span>  
<span style="margin-left: 1em">则虽山岳之高湖海之深亦无损于地体之圆也今以</span>  
<span style="margin-left: 1em">地面论之日月星之出入东西异则时刻亦异试观同</span>  
<span style="margin-left: 1em">此月食欧逻巴见于丑正亚细亚见于寅正是可见日</span>  
<span style="margin-left: 1em">之没也先没于亚细亚之东后没于欧逻巴之西也非</span>  
<span style="margin-left: 1em">圆于球者必不然矣大率从西而东七千五百里则应</span>  
<span style="margin-left: 1em">天三十度而先八刻见食设地体如案则天下见食共</span>  
<span style="margin-left: 1em">在一时无有彼此后先矣若地势如盌则远于月之处</span>  
<span style="margin-left: 1em">先得见食近于月之处反后得见食矣至若地体如觚</span>  
<span style="margin-left: 1em">而四方或八棱则凡在一面者见食皆同矣何故有时</span>  
<span style="margin-left: 1em">刻先后之异乎非圆而何也又问地固圆矣但日月初</span>  
<span style="margin-left: 1em">出半露地上圜体切之宜若弧状今但如弦何也曰地</span>  
<span style="margin-left: 1em">球掩日月之半实自如弧今见如弦者因地形掩日月</span>  
<span style="margin-left: 8em">处较全圜甚短人目视之如直而实</span>  
<span style="margin-left: 8em">圆也今设一圜线其长寻丈若截取</span>  
<span style="margin-left: 8em">分寸之长则不见其曲矣问地既为</span>  
<span style="margin-left: 8em">圆球吾措足之地在球面则所见四</span>  
<span style="margin-left: 8em">旁之地宜皆低也今见近处觉低远</span>  
<span style="margin-left: 8em">处反觉高何也曰凡人视物之远近</span>  
<span style="margin-left: 8em">皆从一直线来入吾目而人之内司</span>  
<span style="margin-left: 8em">从外司忆之故视远物出线似过高</span>  
<span style="margin-left: 8em">于近物出线如上图甲为人目乙为</span>  
<span style="margin-left: 8em">远处丙丁为近处俱属一平线乙远</span>  
<span style="margin-left: 1em">出线来甲目似高于丙丁近出者也如人立长廊中或</span>  
<span style="margin-left: 1em">长瓮道廊道两头平正如一而自此视彼只见其高矣</span>  
<span style="margin-left: 1em">夫视近尚尔况地面之远乎惟据实理察得之则知外</span>  
<span style="margin-left: 1em">司之似误矣</span>  
<span style="margin-left: 3em">因食徴地海并为圆球<sub class="note-yuan">第八</sub></span>  
<span style="margin-left: 1em">航海者远望他舟之来未见其舟先见桅端须臾渐两</span>  
<span style="margin-left: 1em">相近则帆樯头尾全舟毕见矣设海面为平则此舟全</span>  
<span style="margin-left: 1em">体可见何乃有先后见不见之殊乎</span>  
<span style="margin-left: 1em">几何家正之云从一点出线至一界若其线长短若一</span>  
<span style="margin-left: 1em">则所至界必为圜界之形今从地心出线至海面如此</span>  
<span style="margin-left: 13em">则海面果成肖圜界明</span>  
<span style="margin-left: 13em">矣若弗允其说而谓线</span>  
<span style="margin-left: 13em">有长短长者其界更远</span>  
<span style="margin-left: 13em">而远于心点短者其界</span>  
<span style="margin-left: 13em">更近而近于心点如此</span>  
<span style="margin-left: 13em">则地心出线有长有短</span>  
<span style="margin-left: 13em">长处之水独能居高而</span>  
<span style="margin-left: 13em">不下也岂不逆水之性</span>  
<span style="margin-left: 13em">乎如图甲为地心乙丙</span>  
<span style="margin-left: 13em">丁为水平面丙近地心</span>  
<span style="margin-left: 1em">而为水低面丁乙远地心而为水高面则乙丁之水逆</span>  
<span style="margin-left: 1em">其性而居高若居己庚处则更高乎乙丁水边也观此</span>  
<span style="margin-left: 1em">可知地与海为圆之证而其明白显现者无过于月食</span>  
<span style="margin-left: 1em">敝国有人自依西巴尼亚国至墨是谷国验月食之时</span>  
<span style="margin-left: 1em">刻则先于依西巴尼亚国然两地时刻俱一一较准故</span>  
<span style="margin-left: 1em">知食有后先而地与海为圆球又食时月内乌影不拘</span>  
<span style="margin-left: 1em">何地其影必作圆形而光体未受食处若半规然以接</span>  
<span style="margin-left: 1em">其乌影若影为方为扁则月之乌影安能如圆形哉若</span>  
<span style="margin-left: 1em">言影圆而其生影之体为四方八角种种异形此犹不</span>  
<span style="margin-left: 1em">通之甚矣说更详于视法诸书其言乌影悉随其生影</span>  
<span style="margin-left: 1em">之体而肖之也</span>  
<span style="margin-left: 1em">问谓影之圆应地体之圆是已若夫水乃通明之物不</span>  
<span style="margin-left: 1em">能并地而生影亦不能并地而为圆形如何曰水离地</span>  
<span style="margin-left: 1em">之重浊能有几何即不同体寕非连体乎既水与地为</span>  
<span style="margin-left: 1em">连体则重浊搅混岂得通明而况加以深厚孰谓水之</span>  
<span style="margin-left: 1em">通明全体而不能生影乎盖月之食影惟系地影则海</span>  
<span style="margin-left: 1em">中有岛如爪哇老冷苏门之等星罗碁布在在有之有</span>  
<span style="margin-left: 1em">则皆能生种种之影则射于月体何处分别是水乎是</span>  
<span style="margin-left: 1em">地乎</span>  
<span style="margin-left: 3em">因食知大山不损地圆<sub class="note-yuan">第九</sub></span>  
<span style="margin-left: 1em">问客从欧逻巴航海来于西海首见分子午之福岛其</span>  
<span style="margin-left: 1em">隣地有山说者云从千五十里之远以见其山脊或言</span>  
<span style="margin-left: 1em">天下高山此其首矣又利未亚中一山名亚兰得其高</span>  
<span style="margin-left: 1em">视之若际天故名天柱又额勒济亚中一山名百峦说</span>  
<span style="margin-left: 1em">者云其高出于云表此数处有山之高如此则天下各</span>  
<span style="margin-left: 1em">国岂无有类是者然大地有此种种高山则未免有凹</span>  
<span style="margin-left: 1em">凸之状今言其形若球不易信也曰地海并为圆体其</span>  
<span style="margin-left: 1em">形如球者非实圆如天球通光滑泽不򐉄不突者也特</span>  
<span style="margin-left: 1em">谓其类天之球而少异焉尔额罗斯德逆尝云地形如</span>  
<span style="margin-left: 1em">球者大都肖球之圆非如工匠车旋器物之浑圆而毫</span>  
<span style="margin-left: 1em">无凹凸处也否则山之高谷之深将安所置顿哉然山</span>  
<span style="margin-left: 1em">谷在地面圆球之上不过为球面之一点尘埃耳今视</span>  
<span style="margin-left: 1em">山谷在地面虽不齐而视月食乌影未尝不圆若谓山</span>  
<span style="margin-left: 1em">谷与月相望之一面不能生影则地球与月相切之一</span>  
<span style="margin-left: 1em">边岂不能生山谷之影而灭地球圆尖之影哉今俱不</span>  
<span style="margin-left: 1em">见其圆可知矣</span>  
<span style="margin-left: 1em">几何家用通光测量等器测亚兰得百峦二山垂线之</span>  
<span style="margin-left: 1em">高只得千二百五十步况雨雪时天下诸高山顶处处</span>  
<span style="margin-left: 1em">皆有积雪则较之彼所称天柱者所差又多矣曾何足</span>  
<span style="margin-left: 1em">损地之圆乎</span>  
<span style="margin-left: 1em">今测大地之围九万里矣则其径应三万里也以二山</span>  
<span style="margin-left: 1em">之高步化为里数而以较地之全径仅为五千七百二</span>  
<span style="margin-left: 1em">十七之一耳今三倍其高亦仅为一千七百零八之一</span>  
<span style="margin-left: 1em">是山谷之高深较地全体之大直九牛一毛耳球上些</span>  
<span style="margin-left: 1em">须之点乌能损大地之圆乎</span>  
<span style="margin-left: 3em">因食徴地球在天心<sub class="note-yuan">第十</sub></span>  
<span style="margin-left: 1em">前论地球居天中心者理势不得不然也盖四行之重</span>  
<span style="margin-left: 1em">浊下坠者惟地重浊之反而轻清上凝者惟天性之两</span>  
<span style="margin-left: 1em">相反而两相去去之至远者其惟天心乎故地之上下</span>  
<span style="margin-left: 1em">四傍面面皆生民所居首俱戴天足俱履地其首上足</span>  
<span style="margin-left: 14em">下攅聚皆不离斯是</span>  
<span style="margin-left: 14em">知地面上之屋宇楼</span>  
<span style="margin-left: 14em">台地面中之江河湖</span>  
<span style="margin-left: 14em">海千古安于就下之</span>  
<span style="margin-left: 14em">性初未尝见其起离</span>  
<span style="margin-left: 14em">地面而超越于天也</span>  
<span style="margin-left: 14em">问天之四傍恐未必</span>  
<span style="margin-left: 14em">皆是九十度之高人</span>  
<span style="margin-left: 14em">视四傍之天似下垂</span>  
<span style="margin-left: 14em">而近乎地又似相接</span>  
<span style="margin-left: 1em">而比乎地矣且朝暮日月之出没若出没于地平之近</span>  
<span style="margin-left: 1em">处则近地平之天未必九十度如天顶也曰欲释此疑</span>  
<span style="margin-left: 1em">盍验诸月食夫日月不相望于一直长线之末则终古</span>  
<span style="margin-left: 1em">不能食也设地不居天中而偏近于黄道之上下东西</span>  
<span style="margin-left: 1em">则食不居半圜黄道之一百八十度矣如上图甲乙丙</span>  
<span style="margin-left: 1em">丁为黄道若地不居中心戊而居己则日居甲而月至</span>  
<span style="margin-left: 1em">庚即食然此日月非正居直长线之末相对相望处其</span>  
<span style="margin-left: 1em">甲丁庚之长未足半圜与古来测验之准的不易之常</span>  
<span style="margin-left: 1em">法大相背戾矣若言地居黄道极但去极不必相等是</span>  
<span style="margin-left: 1em">又迂濶之甚盖地影近黄道极则地影不能与月相对</span>  
<span style="margin-left: 1em">而掩其光而月体亦终古不能离黄道而受地影其能</span>  
<span style="margin-left: 1em">服天下高明之耳目乎</span>  
<span style="margin-left: 1em">夫人视地之四边若与天近与天相接者尚自有说盖</span>  
<span style="margin-left: 1em">人从此处以目视彼远物之界悉凭乎中间有实体与</span>  
<span style="margin-left: 1em">否如于地面视天所见只有天有地以中间浑无实体</span>  
<span style="margin-left: 1em">以间之也则地面之四边与天若近若比此其故矣今</span>  
<span style="margin-left: 1em">试观林中竹木或城上旗竿鱼贯而列若侧而视之在</span>  
<span style="margin-left: 1em">远者若相近在近者反似相远而远近恍惚之不定也</span>  
<span style="margin-left: 1em">又河之两岸各有人立倘在远处视此二人似觉并立</span>  
<span style="margin-left: 1em">而无远近亦不能料二人中间尚有河隔足徴从远视</span>  
<span style="margin-left: 1em">物易于淆乱而视天何独不然</span>  
<span style="margin-left: 3em">因食而知黄道六宫恒在上六宫恒在下<sub class="note-yuan">第十一</sub></span>  
<span style="margin-left: 1em">凡习浑仪之说者即当知黄道之居仪上随宗动天以</span>  
<span style="margin-left: 1em">运旋第就黄道之随动而言固有正斜迟速之不等所</span>  
<span style="margin-left: 1em">以然者因其随宗动天之极而极与黄道之十二宫远</span>  
<span style="margin-left: 1em">近不同故也又当知黄道之在仪不拘何度次何节气</span>  
<span style="margin-left: 1em">其黄道宫从地面而升则其所相对之宫由地面而没</span>  
<span style="margin-left: 1em">焉夫地平与黄道两圜在仪为大圜凡圜交错分为十</span>  
<span style="margin-left: 1em">字者实为半圜而举黄道全圜则半在地面上半在地</span>  
<span style="margin-left: 1em">面下也右所言不必胶执一定即据浑仪审验亦可窥</span>  
<span style="margin-left: 1em">见月食之大凡而其故了如指掌矣但食居东西两面</span>  
<span style="margin-left: 1em">方为相当又见地海全球半居地平上半居地平下盖</span>  
<span style="margin-left: 1em">食在东则日居西食在西则日居东而日月实相对望</span>  
<span style="margin-left: 1em">于至长至平线之末则见日月出线正当穿过地心又</span>  
<span style="margin-left: 1em">见日月至地平上则地球之面居地平之上矣又见日</span>  
<span style="margin-left: 1em">居东月居西正当半乌影设当此时以通光耳测器平</span>  
<span style="margin-left: 1em">对日月则日光正射月体如此岂不昭然见日月实居</span>  
<span style="margin-left: 1em">地平线之末而贯地球于平线之中乎又见日月及地</span>  
<span style="margin-left: 1em">心并贯于一平直线如此则自通光耳窍测影处以去</span>  
<span style="margin-left: 1em">地心非如一小点乎且凡有月食无拘冬夏天文家正</span>  
<span style="margin-left: 1em">测以日月相去黄道六宫则明见六宫居上六宫居下</span>  
<span style="margin-left: 1em">是又不待食而然四时恒若此也第其宫当从地平游</span>  
<span style="margin-left: 1em">移上下而至于原处地平也</span>  
<span style="margin-left: 3em">据月食即知其实本位所<sub class="note-yuan">第十二</sub></span>  
<span style="margin-left: 1em">据子午高处欲求星宿之偏居原不属地心距度者即</span>  
<span style="margin-left: 1em">因其偏居处求之而知其居于黄道之处所甚易易也</span>  
<span style="margin-left: 1em">故天文家欲求其准的详制若干仪象以测验焉然仪</span>  
<span style="margin-left: 1em">象之巧妙全在通光之窍使其射光处有准的不移动</span>  
<span style="margin-left: 1em">不更改则是器之用不惟能测地面足迹所不能至之</span>  
<span style="margin-left: 1em">处即山岳楼台之高江湖之阔地里之远井谷之深凡</span>  
<span style="margin-left: 1em">诸种种悉能测之极而能测量天之星宿与天之彗孛</span>  
<span style="margin-left: 1em">也第今用是器以求月之高度因而知其在黄道之实</span>  
<span style="margin-left: 1em">本位所惟除地方二十三度内如广东广西等处不特</span>  
<span style="margin-left: 1em">难之难且无准的可据更难于推算也盖月之始出其</span>  
<span style="margin-left: 1em">高度少则差度多高度多则差度少由是则时刻之所</span>  
<span style="margin-left: 1em">在其差度恒不一盖凡<sub class="note-jiao">校：以上二字據文淵本補</sub>以仪象测月要当</span>  
<span style="margin-left: 1em">取地心之所方为不谬今势不能得不为虚器乎但器</span>  
<span style="margin-left: 1em">虽有短心灵无尽故多罗某及诸天文各家言细测月</span>  
<span style="margin-left: 1em">食在于月行本道进影时不居似处而居实处则在食</span>  
<span style="margin-left: 1em">甚时不得不准对乎日既知其的确处所则知其本动</span>  
<span style="margin-left: 1em">之行本行之异知其顺往则知其逆来而食之时刻食</span>  
<span style="margin-left: 1em">之大小食之方所毕知之矣</span>  
<span style="margin-left: 3em">因食而知月有小轮<sub class="note-yuan">第十三</sub></span>  
<span style="margin-left: 1em">问月有小轮何所据乎抑因其食而证其有乎曰天文</span>  
<span style="margin-left: 1em">家究心殚思屡经测验月食悉见夫食屡居本圜之极</span>  
<span style="margin-left: 1em">远其日屡居本圜一处则生影不得不尽一也然食时</span>  
<span style="margin-left: 1em">之分数有多有寡多则月居影厚处寡则月居影薄处</span>  
<span style="margin-left: 1em">必有小轮焉月体居之因其极而动时居轮上则去地</span>  
<span style="margin-left: 1em">面远时居轮下则去地面近如后图所载云问月既有</span>  
<span style="margin-left: 1em">小轮如五星者则其停居顺行退行亦宜若五星然今</span>  
<span style="margin-left: 14em">独未见何也曰夫月</span>  
<span style="margin-left: 14em">行随其本圜之疾故</span>  
<span style="margin-left: 14em">不言其停居退行只</span>  
<span style="margin-left: 14em">言其行速行迟也速</span>  
<span style="margin-left: 14em">者因其居小轮下随</span>  
<span style="margin-left: 14em">本圜之动自西而东</span>  
<span style="margin-left: 14em">迟者因其居小轮上</span>  
<span style="margin-left: 14em">随其自动自东而西</span>  
<span style="margin-left: 14em">逆本圜之自西而东</span>  
<span style="margin-left: 14em">故也</span>  
<span style="margin-left: 1em">问月体既居小轮随轮而动则无本动若论其体之圆</span>  
<span style="margin-left: 1em">则宜自能动何如曰有谓月中影象是地体厚处所映</span>  
<span style="margin-left: 1em">者谓月体通光处日光射而达之不得返照者又谓月</span>  
<span style="margin-left: 1em">体中自有高卑如山谷者种种异说然此影象恒俯对</span>  
<span style="margin-left: 1em">地面而人恒仰见之不侧不移则月体有本动明矣其</span>  
<span style="margin-left: 1em">动因乎本极而逆乎小轮行之迅速与小轮并速也影</span>  
<span style="margin-left: 1em">象之明恒下垂之安得谓月轮无本动乎</span>  
<span style="margin-left: 3em">因食而知日有不同心圜<sub class="note-yuan">第十四</sub></span>  
<span style="margin-left: 1em">问日食有或全食经候多而见食多处者或全食而经</span>  
<span style="margin-left: 1em">候不多而食不在多方者其故何也日天文家正据此</span>  
<span style="margin-left: 9em">以验日有不同心圜不然何其食</span>  
<span style="margin-left: 9em">同而经候不同掩地面之广狭不</span>  
<span style="margin-left: 9em">同也可见日月俱有不同心圜而</span>  
<span style="margin-left: 9em">居不同心圜之上下则为去地之</span>  
<span style="margin-left: 9em">远近生影之大小也今有一光明</span>  
<span style="margin-left: 9em">之体照一不通光之小物两体相</span>  
<span style="margin-left: 9em">近则明体照物体之大分而生影</span>  
<span style="margin-left: 9em">小两体相远则明体照实体之小</span>  
<span style="margin-left: 9em">分而生影大此见日食全而大者</span>  
<span style="margin-left: 9em">则日体必远乎月体日食全而小</span>  
<span style="margin-left: 1em">者日体必近乎月体明矣倘日月无不同心圜之极而</span>  
<span style="margin-left: 1em">以地心为心则其东西行动必规随夫地心何有远近</span>  
<span style="margin-left: 1em">之殊耶丁先生者太西高明之士尤长于天学亲见两</span>  
<span style="margin-left: 1em">日食之异其一于耶稣降生一千五百六十年在哥应</span>  
<span style="margin-left: 1em">巴府见月掩日白昼如夜星宿昭然其一于一千五百</span>  
<span style="margin-left: 1em">六十七年居罗玛都时见月居日前当中掩之而未全</span>  
<span style="margin-left: 1em">蔽月边四围皆有日光即此二食知日月去地面有远</span>  
<span style="margin-left: 1em">近而日必有不同心圜也</span>  
<span style="margin-left: 3em">因食而知日月地大小之别<sub class="note-yuan">第十五</sub></span>  
<span style="margin-left: 1em">问日体甚大于月与地何徴曰昔有人叹世人止凭肉</span>  
<span style="margin-left: 1em">目不求物理尝设喻曰日出地时设有骏马疾驰从日</span>  
<span style="margin-left: 1em">始露至全现亦可驰四里纵令日行与马等速则四里</span>  
<span style="margin-left: 1em">而仅见其全则全体之径亦必四里矣今骏马一昼夜</span>  
<span style="margin-left: 1em">所驰于地几何最速不过全围百分之一也而太阳日</span>  
<span style="margin-left: 1em">一周焉则其行之疾莫拟也是则马之四里日之行几</span>  
<span style="margin-left: 1em">千万里矣日体之大即此微可知也且日月体之大小</span>  
<span style="margin-left: 1em">即食可辩盖凡物之有形象者若空中无所障碍则其</span>  
<span style="margin-left: 1em">体之全体之分无不出其本象于一直线而至乎界之</span>  
<span style="margin-left: 1em">一点此凡物皆然不拘方圆棱角等形如有物体于此</span>  
<span style="margin-left: 1em">其基址即物体也其界点则线之锐角所至而入人目</span>  
<span style="margin-left: 1em">者也凡实体出锐角影者照体必大乎实体否则其光</span>  
<span style="margin-left: 1em">不能照实体之全面而使对面锐影之尽处仍聚合而</span>  
<span style="margin-left: 1em">有光也今欲验日大乎月可视日食月居日前而掩其</span>  
<span style="margin-left: 1em">光是时月边尚有光是日体在外而其象之入人目非</span>  
<span style="margin-left: 1em">近来自月体乃远来自日体也其线既为角形则从月</span>  
<span style="margin-left: 1em">体至日体更为广大是其角形之锐从日来目为一点</span>  
<span style="margin-left: 1em">而中间能包月体有余则日体之大于月体复奚疑哉</span>  
<span style="margin-left: 1em">今欲知日体大乎地者观诸月食可知月之食地居日</span>  
<span style="margin-left: 1em">前而生角影掩月体也当月食时月体近乎地则入濶</span>  
<span style="margin-left: 1em">影远乎地则入锐影愈远愈锐以聚于一点若此者孰</span>  
<span style="margin-left: 1em">不信日体之大于地体也设谓日体与地体均则地影</span>  
<span style="margin-left: 1em">大小均为无穷尽之等影若言地体大乎日体则地影</span>  
<span style="margin-left: 1em">必益远益大为无穷尽之大影其影既远不独食诸天</span>  
<span style="margin-left: 1em">之星必且食诸星之天矣则每遇望时月体讵能逸于</span>  
<span style="margin-left: 1em">大影之外乎由此益信月体之小乎地球也盖地影益</span>  
<span style="margin-left: 1em">远益锐而月食居此影或有全而久者则月径更小于</span>  
<span style="margin-left: 1em">影而影小于地故月体地球之大小从可知矣</span>  
<span style="margin-left: 3em">因食而知各地之子午<sub class="note-yuan">第十六</sub></span>  
<span style="margin-left: 1em">多罗某者天文家之宗匠也其所定子午法诸子皆宗</span>  
<span style="margin-left: 1em">之当时欲定各国各府之子午以便测验乃先定福岛</span>  
<span style="margin-left: 1em">以为西极而此外因海弗论也职方氏谓心忆不如足</span>  
<span style="margin-left: 1em">至多罗某生平足履虽未徧地而垂法之妙足逾百家</span>  
<span style="margin-left: 1em">矣厥后诸天文家身渉多方目测多食益精其遗法之</span>  
<span style="margin-left: 1em">妙而职方图志益广其传焉今欲求经度之准的东西</span>  
<span style="margin-left: 1em">之远近法莫善乎考两地之月食以此方之时刻与彼</span>  
<span style="margin-left: 1em">方之时刻相较视所差几何即知两地相去几何度矣</span>  
<span style="margin-left: 1em">假如癸亥年九月望应月食</span>  
<span style="margin-left: 1em">京师及隣近地初食在酉初二十七分食甚在戌初五</span>  
<span style="margin-left: 1em">分复圆在戌正四十三分此中国之食候也若在西洋</span>  
<span style="margin-left: 1em">则初食在巳正四十二分食甚在午正十五分复圆在</span>
