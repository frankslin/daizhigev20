## 崇禎曆書卷之三十五　測食下卷

<span style="margin-left: 1em">測食下卷</span>  
<span style="margin-left: 14em">大西湯若望述</span>  
<span style="margin-left: 14em">慈水周子愚</span>  
<span style="margin-left: 1em">　　　　　　　　　　　　　　　　　　訂</span>  
<span style="margin-left: 14em">武林卓爾康</span>  
<span style="margin-left: 3em">月食爲地影所隔<sub class="note-yuan">第一</sub></span>  
<span style="margin-left: 1em">問月食必在於望因日月相對之故其說明矣至謂地</span>  
<span style="margin-left: 1em">影隔之而食竊有疑焉曰月對日而受其光苟日月之</span>  
<span style="margin-left: 1em">間非有不通光之實體爲之障蔽則必不能阻日光之</span>  
<span style="margin-left: 1em">照月體無論空中之火空中之氣與夫天體不能掩月</span>  
<span style="margin-left: 1em">即金水二星雖居日月之間其影俱不及地況能過地</span>  
<span style="margin-left: 1em">而及月乎則知能掩日者惟有地體一面受光一面射</span>  
<span style="margin-left: 1em">影而月體爲借光之物入此影中安得不食而半進則</span>  
<span style="margin-left: 1em">半食全進則全食矣</span>  
<span style="margin-left: 3em">月體當食尚有光色<sub class="note-yuan">第二</sub></span>  
<span style="margin-left: 1em">問無光之月一入地影遂全失其借光也然食時尚有</span>  
<span style="margin-left: 1em">依稀可見之光天文家每視食月之色預言食之徴驗</span>  
<span style="margin-left: 1em">若人以目切墻屋掩其未食之光體而獨視其既食之</span>  
<span style="margin-left: 1em">烏體其光尚明於星也蓋物之可見必借外光不獨能</span>  
<span style="margin-left: 1em">見物體且更能發越物色也月既在地影即失借光安</span>  
<span style="margin-left: 1em">得尚有色乎曰月體雖食尚有微光今直以影爲明者</span>  
<span style="margin-left: 1em">誤也以影爲暗者亦誤也稱影爲明暗之中者庶爲近</span>  
<span style="margin-left: 1em">之蓋日所正照爲最光明有物隔之而四傍之氣映射</span>  
<span style="margin-left: 1em">或對面之光反照雖無最光明亦有次光明也如一室</span>  
<span style="margin-left: 1em">之外爲最光明一室之內爲次光明也雲之上爲最光</span>  
<span style="margin-left: 1em">明雲之下爲次光明也直至所隔愈深去光愈遠并次</span>  
<span style="margin-left: 1em">光明亦漸微微而又微以至絲毫無光乃爲暗耳夫人</span>  
<span style="margin-left: 1em">與地近日與地遠人居地此面日在地彼面至夜子初</span>  
<span style="margin-left: 1em">人在地影至濃之中近物尚能別識何況月在地影至</span>  
<span style="margin-left: 1em">銳之處次光明正盛其有光色又何疑乎且人在極暗</span>  
<span style="margin-left: 1em">則月光雖微視之反覺明也</span>  
<span style="margin-left: 3em">日食在朔月體掩之<sub class="note-yuan">第三</sub></span>  
<span style="margin-left: 1em">問前言月在日前能掩日光是已金水二星亦皆在日</span>  
<span style="margin-left: 1em">前又皆實體且水星雖小而金星則大於月也何獨以</span>  
<span style="margin-left: 1em">食屬月乎曰二星于人甚遠不能掩日百分之一二而</span>  
<span style="margin-left: 1em">日光甚盛即虧百分之一二人亦不覺且二星去日甚</span>  
<span style="margin-left: 1em">近去地甚遠所出銳角之影亦甚短决不能及地面也</span>  
<span style="margin-left: 1em">若夫月體雖不及太白之大然去地近去日遠一指足</span>  
<span style="margin-left: 1em">蔽泰山又何疑乎由此言之求一實體之能全掩日又</span>  
<span style="margin-left: 1em">從西而東過之甚疾唯月爲能蓋月之右旋比諸天更</span>  
<span style="margin-left: 1em">速且必至合朔方有食則日食於月决然之理也</span>  
<span style="margin-left: 3em">因食知月體不通光<sub class="note-yuan">第四</sub></span>  
<span style="margin-left: 1em">問月體受光而返照之必不通光如銅鉄鏡蓋通光則</span>  
<span style="margin-left: 1em">不能受日光而反照他物亦不能掩日而生影也曰鏡</span>  
<span style="margin-left: 1em">之設譬似矣而尚未盡夫鏡之照物而反生之象其大</span>  
<span style="margin-left: 1em">小遠近必與物體相當然後可以鏡喻月今觀鏡之面</span>  
<span style="margin-left: 1em">有突如球有平如案有򐉄如釜惟平者所生之象乃與</span>  
<span style="margin-left: 1em">物體相當若如釜者所生物象必倍於物體如球者所</span>  
<span style="margin-left: 1em">生物象必小於物體矣試以球鏡照遠物而人又從遠</span>  
<span style="margin-left: 1em">視之則物象必倍小嘗持球鏡照太陽之體其小如星</span>  
<span style="margin-left: 1em">倘月體如球鏡欲其反生太陽之象烏可得乎又問合</span>  
<span style="margin-left: 1em">朔後月之下半未受日光而月體微光比諸星更顯若</span>  
<span style="margin-left: 1em">不通明則此光又從何生且觀其掩日而日全食時月</span>  
<span style="margin-left: 1em">之邊際覺稍明于月之中心似中間厚處難通而薄處</span>  
<span style="margin-left: 1em">稍可通透乎曰前既言月在地影最中處乃天光映照</span>  
<span style="margin-left: 1em">之明若合朔時則有光之天與月體最爲切近而日光</span>  
<span style="margin-left: 1em">上照月體約有大半四邊豈得無光或言月既非極通</span>  
<span style="margin-left: 1em">光如玻瓈或半通光如玉石特因在後之物其體質不</span>  
<span style="margin-left: 1em">明故不能映見在後之物乎曰試觀日食甚之時天光</span>  
<span style="margin-left: 1em">盡黑星體亦現爾時太陽在後體質最爲明顯何以不</span>  
<span style="margin-left: 1em">能映見絲毫可知月體絶不通光也或言在月後之物</span>  
<span style="margin-left: 1em">必更堅密於月者然後能照見若較月更通徹即不能</span>  
<span style="margin-left: 1em">見乎曰若然日體在月後堅密不亞於月而亦不能見</span>  
<span style="margin-left: 1em">可言日體爲通徹乎又凡目所注必須有色及所照之</span>  
<span style="margin-left: 1em">光此二者必不通徹之體乃能受之則月體從可推矣</span>  
<span style="margin-left: 3em">月食時人目不及見月受光之面<sub class="note-yuan">第五</sub></span>  
<span style="margin-left: 1em">上言日光照月體大半則知日比月體至大然日食甚</span>  
<span style="margin-left: 1em">之時人目所見之面何故絶無絲毫之光曰凡人視圓</span>  
<span style="margin-left: 1em">球止見小半蓋球有大圜有小圜若以兩線切大圜其</span>  
<span style="margin-left: 1em">線必爲平行今目所注視之線既不能平行則不切至</span>  
<span style="margin-left: 8em">大圜可知而目亦僅能及小圜矣<sub class="note-yuan">詳見</sub></span>  
<span style="margin-left: 8em"><sub class="note-yuan">幾何一卷二十八題</sub>又望後三日雖月每日行</span>  
<span style="margin-left: 8em">十三度有奇而月邊尚似圓圜可見</span>  
<span style="margin-left: 8em">人目正及其小圜也或曰望日所見</span>  
<span style="margin-left: 8em">月體之面即月所受光之面其光爲</span>  
<span style="margin-left: 8em">大半則二三日其光尚在大半之內</span>  
<span style="margin-left: 8em">則晦後月輪稍移便宜見光而光今</span>  
<span style="margin-left: 8em">竟不即見何也曰月掩日之時一則</span>  
<span style="margin-left: 8em">人所注之圜與日光照月之圜爲平</span>  
<span style="margin-left: 8em">行一則日食時不過一兩刻則兩線</span>  
<span style="margin-left: 8em">亦不能相切至望則不同矣又望時</span>  
<span style="margin-left: 8em">日光照月少於他時蓋晦日日與月</span>  
<span style="margin-left: 8em">止隔金水二星天而甚近故所照亦</span>  
<span style="margin-left: 8em">多於望日望日與月隔金水二天及</span>  
<span style="margin-left: 8em">月本天之體而甚遠故所照亦少於</span>  
<span style="margin-left: 8em">他日然晦日所照雖多於望日而人</span>  
<span style="margin-left: 8em">目所及止見小圜而月光不即見職</span>  
<span style="margin-left: 8em">由此矣</span>  
<span style="margin-left: 10em">日月每月不食<sub class="note-yuan">第六</sub></span>  
<span style="margin-left: 8em">夫月不恒食之故有二一則日體常</span>  
<span style="margin-left: 1em">麗躔道則地影亦常對躔道一則月行常出入躔道故</span>  
<span style="margin-left: 1em">他影不及蓋凡光照物必直射而作直線今日在躔道</span>  
<span style="margin-left: 1em">其光自平面而直通至地則反影亦反射至天如日光</span>  
<span style="margin-left: 1em">之射地其日光繞地一周則影亦繞天一周其地影至</span>  
<span style="margin-left: 1em">月天濶不過一度半躔道平分地影每邊有四分之三</span>  
<span style="margin-left: 1em">又望日月輪不在龍頭龍尾近處故月體與地影不得</span>  
<span style="margin-left: 1em">相遇故不食此前篇言每月食三體必在一直線也或</span>  
<span style="margin-left: 1em">曰日食應有多次爲其不論月之實所但論月之似所</span>  
<span style="margin-left: 1em">若論似所則南北所差甚多如此則人住兩極近處者</span>  
<span style="margin-left: 1em">視月遠於躔道亦能食日矣曰人居在北極下而似所</span>  
<span style="margin-left: 1em">與實所相距不過一度譬如月在地平東西差亦不過</span>  
<span style="margin-left: 1em">一度可見日欲食時月不能離躔道一度强故日食亦</span>  
<span style="margin-left: 1em">少也但論一處則日月之食不等槩論天下日食應多</span>  
<span style="margin-left: 1em">於月食也</span>  
<span style="margin-left: 3em">因月食徴地圓如球<sub class="note-yuan">第七</sub></span>  
<span style="margin-left: 1em">格物家悉言地圓如球驗之洵不得不然也蓋凡物之</span>  
<span style="margin-left: 1em">性重者勢必就下若一無所阻必徑就天心天心者最</span>  
<span style="margin-left: 1em">下處也故大地四旁皆欲就下其勢不得不結爲圓然</span>  
<span style="margin-left: 1em">則雖山岳之高湖海之深亦無損於地體之圓也今以</span>  
<span style="margin-left: 1em">地面論之日月星之出入東西異則時刻亦異試觀同</span>  
<span style="margin-left: 1em">此月食歐邏巴見於丑正亞細亞見於寅正是可見日</span>  
<span style="margin-left: 1em">之没也先没於亞細亞之東後没於歐邏巴之西也非</span>  
<span style="margin-left: 1em">圓於球者必不然矣大率從西而東七千五百里則應</span>  
<span style="margin-left: 1em">天三十度而先八刻見食設地體如案則天下見食共</span>  
<span style="margin-left: 1em">在一時無有彼此後先矣若地勢如盌則遠於月之處</span>  
<span style="margin-left: 1em">先得見食近於月之處反後得見食矣至若地體如觚</span>  
<span style="margin-left: 1em">而四方或八稜則凡在一面者見食皆同矣何故有時</span>  
<span style="margin-left: 1em">刻先後之異乎非圓而何也又問地固圓矣但日月初</span>  
<span style="margin-left: 1em">出半露地上圜體切之宜若弧狀今但如弦何也曰地</span>  
<span style="margin-left: 1em">球掩日月之半實自如弧今見如弦者因地形掩日月</span>  
<span style="margin-left: 8em">處較全圜甚短人目視之如直而實</span>  
<span style="margin-left: 8em">圓也今設一圜線其長尋丈若截取</span>  
<span style="margin-left: 8em">分寸之長則不見其曲矣問地既爲</span>  
<span style="margin-left: 8em">圓球吾措足之地在球面則所見四</span>  
<span style="margin-left: 8em">旁之地宜皆低也今見近處覺低遠</span>  
<span style="margin-left: 8em">處反覺高何也曰凡人視物之遠近</span>  
<span style="margin-left: 8em">皆從一直線來入吾目而人之內司</span>  
<span style="margin-left: 8em">從外司憶之故視遠物出線似過高</span>  
<span style="margin-left: 8em">於近物出線如上圖甲爲人目乙爲</span>  
<span style="margin-left: 8em">遠處丙丁爲近處俱屬一平線乙遠</span>  
<span style="margin-left: 1em">出線來甲目似高於丙丁近出者也如人立長廊中或</span>  
<span style="margin-left: 1em">長甕道廊道兩頭平正如一而自此視彼只見其高矣</span>  
<span style="margin-left: 1em">夫視近尚爾況地面之遠乎惟據實理察得之則知外</span>  
<span style="margin-left: 1em">司之似誤矣</span>  
<span style="margin-left: 3em">因食徴地海併爲圓球<sub class="note-yuan">第八</sub></span>  
<span style="margin-left: 1em">航海者遠望他舟之來未見其舟先見桅端須臾漸兩</span>  
<span style="margin-left: 1em">相近則帆檣頭尾全舟畢見矣設海面爲平則此舟全</span>  
<span style="margin-left: 1em">體可見何乃有先後見不見之殊乎</span>  
<span style="margin-left: 1em">幾何家正之云從一點出線至一界若其線長短若一</span>  
<span style="margin-left: 1em">則所至界必爲圜界之形今從地心出線至海面如此</span>  
<span style="margin-left: 13em">則海面果成肖圜界明</span>  
<span style="margin-left: 13em">矣若弗允其說而謂線</span>  
<span style="margin-left: 13em">有長短長者其界更遠</span>  
<span style="margin-left: 13em">而遠於心點短者其界</span>  
<span style="margin-left: 13em">更近而近於心點如此</span>  
<span style="margin-left: 13em">則地心出線有長有短</span>  
<span style="margin-left: 13em">長處之水獨能居高而</span>  
<span style="margin-left: 13em">不下也豈不逆水之性</span>  
<span style="margin-left: 13em">乎如圖甲爲地心乙丙</span>  
<span style="margin-left: 13em">丁爲水平面丙近地心</span>  
<span style="margin-left: 1em">而爲水低面丁乙遠地心而爲水高面則乙丁之水逆</span>  
<span style="margin-left: 1em">其性而居高若居己庚處則更高乎乙丁水邊也觀此</span>  
<span style="margin-left: 1em">可知地與海爲圓之證而其明白顯現者無過於月食</span>  
<span style="margin-left: 1em">敝國有人自依西巴尼亞國至墨是谷國驗月食之時</span>  
<span style="margin-left: 1em">刻則先於依西巴尼亞國然兩地時刻俱一一較準故</span>  
<span style="margin-left: 1em">知食有後先而地與海爲圓球又食時月內烏影不拘</span>  
<span style="margin-left: 1em">何地其影必作圓形而光體未受食處若半規然以接</span>  
<span style="margin-left: 1em">其烏影若影爲方爲扁則月之烏影安能如圓形哉若</span>  
<span style="margin-left: 1em">言影圓而其生影之體爲四方八角種種異形此猶不</span>  
<span style="margin-left: 1em">通之甚矣說更詳於視法諸書其言烏影悉隨其生影</span>  
<span style="margin-left: 1em">之體而肖之也</span>  
<span style="margin-left: 1em">問謂影之圓應地體之圓是已若夫水乃通明之物不</span>  
<span style="margin-left: 1em">能併地而生影亦不能併地而爲圓形如何曰水離地</span>  
<span style="margin-left: 1em">之重濁能有幾何即不同體寕非連體乎既水與地爲</span>  
<span style="margin-left: 1em">連體則重濁攪混豈得通明而況加以深厚孰謂水之</span>  
<span style="margin-left: 1em">通明全體而不能生影乎蓋月之食影惟係地影則海</span>  
<span style="margin-left: 1em">中有島如爪哇老冷蘇門之等星羅碁布在在有之有</span>  
<span style="margin-left: 1em">則皆能生種種之影則射於月體何處分別是水乎是</span>  
<span style="margin-left: 1em">地乎</span>  
<span style="margin-left: 3em">因食知大山不損地圓<sub class="note-yuan">第九</sub></span>  
<span style="margin-left: 1em">問客從歐邏巴航海來于西海首見分子午之福島其</span>  
<span style="margin-left: 1em">隣地有山說者云從千五十里之遠以見其山脊或言</span>  
<span style="margin-left: 1em">天下高山此其首矣又利未亞中一山名亞蘭得其高</span>  
<span style="margin-left: 1em">視之若際天故名天柱又額勒濟亞中一山名百巒說</span>  
<span style="margin-left: 1em">者云其高出於雲表此數處有山之高如此則天下各</span>  
<span style="margin-left: 1em">國豈無有類是者然大地有此種種高山則未免有凹</span>  
<span style="margin-left: 1em">凸之狀今言其形若球不易信也曰地海併爲圓體其</span>  
<span style="margin-left: 1em">形如球者非實圓如天球通光滑澤不򐉄不突者也特</span>  
<span style="margin-left: 1em">謂其類天之球而少異焉爾額羅斯德逆嘗云地形如</span>  
<span style="margin-left: 1em">球者大都肖球之圓非如工匠車鏇器物之渾圓而毫</span>  
<span style="margin-left: 1em">無凹凸處也否則山之高谷之深將安所置頓哉然山</span>  
<span style="margin-left: 1em">谷在地面圓球之上不過爲球面之一點塵埃耳今視</span>  
<span style="margin-left: 1em">山谷在地面雖不齊而視月食烏影未嘗不圓若謂山</span>  
<span style="margin-left: 1em">谷與月相望之一面不能生影則地球與月相切之一</span>  
<span style="margin-left: 1em">邊豈不能生山谷之影而滅地球圓尖之影哉今俱不</span>  
<span style="margin-left: 1em">見其圓可知矣</span>  
<span style="margin-left: 1em">幾何家用通光測量等器測亞蘭得百巒二山垂線之</span>  
<span style="margin-left: 1em">高只得千二百五十步況雨雪時天下諸高山頂處處</span>  
<span style="margin-left: 1em">皆有積雪則較之彼所稱天柱者所差又多矣曾何足</span>  
<span style="margin-left: 1em">損地之圓乎</span>  
<span style="margin-left: 1em">今測大地之圍九萬里矣則其徑應三萬里也以二山</span>  
<span style="margin-left: 1em">之高步化爲里數而以較地之全徑僅爲五千七百二</span>  
<span style="margin-left: 1em">十七之一耳今三倍其高亦僅爲一千七百零八之一</span>  
<span style="margin-left: 1em">是山谷之高深較地全體之大直九牛一毛耳球上些</span>  
<span style="margin-left: 1em">須之點烏能損大地之圓乎</span>  
<span style="margin-left: 3em">因食徴地球在天心<sub class="note-yuan">第十</sub></span>  
<span style="margin-left: 1em">前論地球居天中心者理勢不得不然也蓋四行之重</span>  
<span style="margin-left: 1em">濁下墜者惟地重濁之反而輕清上凝者惟天性之兩</span>  
<span style="margin-left: 1em">相反而兩相去去之至遠者其惟天心乎故地之上下</span>  
<span style="margin-left: 1em">四傍面面皆生民所居首俱戴天足俱履地其首上足</span>  
<span style="margin-left: 14em">下攅聚皆不離斯是</span>  
<span style="margin-left: 14em">知地面上之屋宇樓</span>  
<span style="margin-left: 14em">臺地面中之江河湖</span>  
<span style="margin-left: 14em">海千古安於就下之</span>  
<span style="margin-left: 14em">性初未嘗見其起離</span>  
<span style="margin-left: 14em">地面而超越於天也</span>  
<span style="margin-left: 14em">問天之四傍恐未必</span>  
<span style="margin-left: 14em">皆是九十度之高人</span>  
<span style="margin-left: 14em">視四傍之天似下垂</span>  
<span style="margin-left: 14em">而近乎地又似相接</span>  
<span style="margin-left: 1em">而比乎地矣且朝暮日月之出没若出没於地平之近</span>  
<span style="margin-left: 1em">處則近地平之天未必九十度如天頂也曰欲釋此疑</span>  
<span style="margin-left: 1em">盍驗諸月食夫日月不相望于一直長線之末則終古</span>  
<span style="margin-left: 1em">不能食也設地不居天中而偏近於黃道之上下東西</span>  
<span style="margin-left: 1em">則食不居半圜黃道之一百八十度矣如上圖甲乙丙</span>  
<span style="margin-left: 1em">丁爲黃道若地不居中心戊而居己則日居甲而月至</span>  
<span style="margin-left: 1em">庚即食然此日月非正居直長線之末相對相望處其</span>  
<span style="margin-left: 1em">甲丁庚之長未足半圜與古來測驗之準的不易之常</span>  
<span style="margin-left: 1em">法大相背戾矣若言地居黃道極但去極不必相等是</span>  
<span style="margin-left: 1em">又迂濶之甚蓋地影近黃道極則地影不能與月相對</span>  
<span style="margin-left: 1em">而掩其光而月體亦終古不能離黃道而受地影其能</span>  
<span style="margin-left: 1em">服天下高明之耳目乎</span>  
<span style="margin-left: 1em">夫人視地之四邊若與天近與天相接者尚自有說蓋</span>  
<span style="margin-left: 1em">人從此處以目視彼遠物之界悉憑乎中間有實體與</span>  
<span style="margin-left: 1em">否如於地面視天所見只有天有地以中間渾無實體</span>  
<span style="margin-left: 1em">以間之也則地面之四邊與天若近若比此其故矣今</span>  
<span style="margin-left: 1em">試觀林中竹木或城上旗竿魚貫而列若側而視之在</span>  
<span style="margin-left: 1em">遠者若相近在近者反似相遠而遠近恍惚之不定也</span>  
<span style="margin-left: 1em">又河之兩岸各有人立倘在遠處視此二人似覺並立</span>  
<span style="margin-left: 1em">而無遠近亦不能料二人中間尚有河隔足徴從遠視</span>  
<span style="margin-left: 1em">物易於淆亂而視天何獨不然</span>  
<span style="margin-left: 3em">因食而知黃道六宫恒在上六宫恒在下<sub class="note-yuan">第十一</sub></span>  
<span style="margin-left: 1em">凡習渾儀之說者即當知黃道之居儀上隨宗動天以</span>  
<span style="margin-left: 1em">運旋第就黃道之隨動而言固有正斜遲速之不等所</span>  
<span style="margin-left: 1em">以然者因其隨宗動天之極而極與黃道之十二宫遠</span>  
<span style="margin-left: 1em">近不同故也又當知黃道之在儀不拘何度次何節氣</span>  
<span style="margin-left: 1em">其黃道宫從地面而升則其所相對之宫由地面而没</span>  
<span style="margin-left: 1em">焉夫地平與黃道兩圜在儀爲大圜凡圜交錯分爲十</span>  
<span style="margin-left: 1em">字者實爲半圜而舉黃道全圜則半在地面上半在地</span>  
<span style="margin-left: 1em">面下也右所言不必膠執一定即據渾儀審驗亦可窺</span>  
<span style="margin-left: 1em">見月食之大凡而其故瞭如指掌矣但食居東西兩面</span>  
<span style="margin-left: 1em">方爲相當又見地海全球半居地平上半居地平下蓋</span>  
<span style="margin-left: 1em">食在東則日居西食在西則日居東而日月實相對望</span>  
<span style="margin-left: 1em">於至長至平線之末則見日月出線正當穿過地心又</span>  
<span style="margin-left: 1em">見日月至地平上則地球之面居地平之上矣又見日</span>  
<span style="margin-left: 1em">居東月居西正當半烏影設當此時以通光耳測器平</span>  
<span style="margin-left: 1em">對日月則日光正射月體如此豈不昭然見日月實居</span>  
<span style="margin-left: 1em">地平線之末而貫地球於平線之中乎又見日月及地</span>  
<span style="margin-left: 1em">心並貫於一平直線如此則自通光耳竅測影處以去</span>  
<span style="margin-left: 1em">地心非如一小點乎且凡有月食無拘冬夏天文家正</span>  
<span style="margin-left: 1em">測以日月相去黃道六宫則明見六宫居上六宫居下</span>  
<span style="margin-left: 1em">是又不待食而然四時恒若此也第其宫當從地平游</span>  
<span style="margin-left: 1em">移上下而至於原處地平也</span>  
<span style="margin-left: 3em">據月食即知其實本位所<sub class="note-yuan">第十二</sub></span>  
<span style="margin-left: 1em">據子午高處欲求星宿之偏居原不屬地心距度者即</span>  
<span style="margin-left: 1em">因其偏居處求之而知其居於黃道之處所甚易易也</span>  
<span style="margin-left: 1em">故天文家欲求其準的詳製若干儀象以測驗焉然儀</span>  
<span style="margin-left: 1em">象之巧妙全在通光之竅使其射光處有準的不移動</span>  
<span style="margin-left: 1em">不更改則是器之用不惟能測地面足跡所不能至之</span>  
<span style="margin-left: 1em">處即山岳樓臺之高江湖之闊地里之遠井谷之深凡</span>  
<span style="margin-left: 1em">諸種種悉能測之極而能測量天之星宿與天之彗孛</span>  
<span style="margin-left: 1em">也第今用是器以求月之高度因而知其在黃道之實</span>  
<span style="margin-left: 1em">本位所惟除地方二十三度內如廣東廣西等處不特</span>  
<span style="margin-left: 1em">難之難且無準的可據更難於推算也蓋月之始出其</span>  
<span style="margin-left: 1em">高度少則差度多高度多則差度少由是則時刻之所</span>  
<span style="margin-left: 1em">在其差度恒不一蓋凡<sub class="note-jiao">校：以上二字據文淵本補</sub>以儀象測月要當</span>  
<span style="margin-left: 1em">取地心之所方爲不謬今勢不能得不爲虛器乎但器</span>  
<span style="margin-left: 1em">雖有短心靈無盡故多羅某及諸天文各家言細測月</span>  
<span style="margin-left: 1em">食在于月行本道進影時不居似處而居實處則在食</span>  
<span style="margin-left: 1em">甚時不得不準對乎日既知其的確處所則知其本動</span>  
<span style="margin-left: 1em">之行本行之異知其順往則知其逆來而食之時刻食</span>  
<span style="margin-left: 1em">之大小食之方所畢知之矣</span>  
<span style="margin-left: 3em">因食而知月有小輪<sub class="note-yuan">第十三</sub></span>  
<span style="margin-left: 1em">問月有小輪何所據乎抑因其食而證其有乎曰天文</span>  
<span style="margin-left: 1em">家究心殫思屢經測驗月食悉見夫食屢居本圜之極</span>  
<span style="margin-left: 1em">遠其日屢居本圜一處則生影不得不盡一也然食時</span>  
<span style="margin-left: 1em">之分數有多有寡多則月居影厚處寡則月居影薄處</span>  
<span style="margin-left: 1em">必有小輪焉月體居之因其極而動時居輪上則去地</span>  
<span style="margin-left: 1em">面遠時居輪下則去地面近如後圖所載云問月既有</span>  
<span style="margin-left: 1em">小輪如五星者則其停居順行退行亦宜若五星然今</span>  
<span style="margin-left: 14em">獨未見何也曰夫月</span>  
<span style="margin-left: 14em">行隨其本圜之疾故</span>  
<span style="margin-left: 14em">不言其停居退行只</span>  
<span style="margin-left: 14em">言其行速行遲也速</span>  
<span style="margin-left: 14em">者因其居小輪下隨</span>  
<span style="margin-left: 14em">本圜之動自西而東</span>  
<span style="margin-left: 14em">遲者因其居小輪上</span>  
<span style="margin-left: 14em">隨其自動自東而西</span>  
<span style="margin-left: 14em">逆本圜之自西而東</span>  
<span style="margin-left: 14em">故也</span>  
<span style="margin-left: 1em">問月體既居小輪隨輪而動則無本動若論其體之圓</span>  
<span style="margin-left: 1em">則宜自能動何如曰有謂月中影象是地體厚處所映</span>  
<span style="margin-left: 1em">者謂月體通光處日光射而達之不得返照者又謂月</span>  
<span style="margin-left: 1em">體中自有高卑如山谷者種種異說然此影象恒俯對</span>  
<span style="margin-left: 1em">地面而人恒仰見之不側不移則月體有本動明矣其</span>  
<span style="margin-left: 1em">動因乎本極而逆乎小輪行之迅速與小輪並速也影</span>  
<span style="margin-left: 1em">象之明恒下垂之安得謂月輪無本動乎</span>  
<span style="margin-left: 3em">因食而知日有不同心圜<sub class="note-yuan">第十四</sub></span>  
<span style="margin-left: 1em">問日食有或全食經候多而見食多處者或全食而經</span>  
<span style="margin-left: 1em">候不多而食不在多方者其故何也日天文家正據此</span>  
<span style="margin-left: 9em">以驗日有不同心圜不然何其食</span>  
<span style="margin-left: 9em">同而經候不同掩地面之廣狹不</span>  
<span style="margin-left: 9em">同也可見日月俱有不同心圜而</span>  
<span style="margin-left: 9em">居不同心圜之上下則爲去地之</span>  
<span style="margin-left: 9em">遠近生影之大小也今有一光明</span>  
<span style="margin-left: 9em">之體照一不通光之小物兩體相</span>  
<span style="margin-left: 9em">近則明體照物體之大分而生影</span>  
<span style="margin-left: 9em">小兩體相遠則明體照實體之小</span>  
<span style="margin-left: 9em">分而生影大此見日食全而大者</span>  
<span style="margin-left: 9em">則日體必遠乎月體日食全而小</span>  
<span style="margin-left: 1em">者日體必近乎月體明矣倘日月無不同心圜之極而</span>  
<span style="margin-left: 1em">以地心爲心則其東西行動必規隨夫地心何有遠近</span>  
<span style="margin-left: 1em">之殊耶丁先生者太西高明之士尤長於天學親見兩</span>  
<span style="margin-left: 1em">日食之異其一于耶穌降生一千五百六十年在哥應</span>  
<span style="margin-left: 1em">巴府見月掩日白晝如夜星宿昭然其一于一千五百</span>  
<span style="margin-left: 1em">六十七年居羅瑪都時見月居日前當中掩之而未全</span>  
<span style="margin-left: 1em">蔽月邊四圍皆有日光即此二食知日月去地面有遠</span>  
<span style="margin-left: 1em">近而日必有不同心圜也</span>  
<span style="margin-left: 3em">因食而知日月地大小之別<sub class="note-yuan">第十五</sub></span>  
<span style="margin-left: 1em">問日體甚大於月與地何徴曰昔有人嘆世人止憑肉</span>  
<span style="margin-left: 1em">目不求物理嘗設喻曰日出地時設有駿馬疾馳從日</span>  
<span style="margin-left: 1em">始露至全現亦可馳四里縱令日行與馬等速則四里</span>  
<span style="margin-left: 1em">而僅見其全則全體之徑亦必四里矣今駿馬一晝夜</span>  
<span style="margin-left: 1em">所馳於地幾何最速不過全圍百分之一也而太陽日</span>  
<span style="margin-left: 1em">一周焉則其行之疾莫擬也是則馬之四里日之行幾</span>  
<span style="margin-left: 1em">千萬里矣日體之大即此微可知也且日月體之大小</span>  
<span style="margin-left: 1em">即食可辯蓋凡物之有形象者若空中無所障礙則其</span>  
<span style="margin-left: 1em">體之全體之分無不出其本象於一直線而至乎界之</span>  
<span style="margin-left: 1em">一點此凡物皆然不拘方圓稜角等形如有物體于此</span>  
<span style="margin-left: 1em">其基址即物體也其界點則線之銳角所至而入人目</span>  
<span style="margin-left: 1em">者也凡實體出銳角影者照體必大乎實體否則其光</span>  
<span style="margin-left: 1em">不能照實體之全面而使對面銳影之盡處仍聚合而</span>  
<span style="margin-left: 1em">有光也今欲驗日大乎月可視日食月居日前而掩其</span>  
<span style="margin-left: 1em">光是時月邊尚有光是日體在外而其象之入人目非</span>  
<span style="margin-left: 1em">近來自月體乃遠來自日體也其線既爲角形則從月</span>  
<span style="margin-left: 1em">體至日體更爲廣大是其角形之銳從日來目爲一點</span>  
<span style="margin-left: 1em">而中間能包月體有餘則日體之大於月體復奚疑哉</span>  
<span style="margin-left: 1em">今欲知日體大乎地者觀諸月食可知月之食地居日</span>  
<span style="margin-left: 1em">前而生角影掩月體也當月食時月體近乎地則入濶</span>  
<span style="margin-left: 1em">影遠乎地則入銳影愈遠愈銳以聚于一點若此者孰</span>  
<span style="margin-left: 1em">不信日體之大於地體也設謂日體與地體均則地影</span>  
<span style="margin-left: 1em">大小均爲無窮盡之等影若言地體大乎日體則地影</span>  
<span style="margin-left: 1em">必益遠益大爲無窮盡之大影其影既遠不獨食諸天</span>  
<span style="margin-left: 1em">之星必且食諸星之天矣則每遇望時月體詎能逸於</span>  
<span style="margin-left: 1em">大影之外乎由此益信月體之小乎地球也蓋地影益</span>  
<span style="margin-left: 1em">遠益銳而月食居此影或有全而久者則月徑更小于</span>  
<span style="margin-left: 1em">影而影小於地故月體地球之大小從可知矣</span>  
<span style="margin-left: 3em">因食而知各地之子午<sub class="note-yuan">第十六</sub></span>  
<span style="margin-left: 1em">多羅某者天文家之宗匠也其所定子午法諸子皆宗</span>  
<span style="margin-left: 1em">之當時欲定各國各府之子午以便測驗乃先定福島</span>  
<span style="margin-left: 1em">以爲西極而此外因海弗論也職方氏謂心憶不如足</span>
