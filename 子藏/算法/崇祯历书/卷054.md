<span style="margin-left: 2em">月離曆指敘目</span>  
<span style="margin-left: 2em">步七政次月離者何也曰其故有六月與日視體相</span>  
<span style="margin-left: 2em">若雖偕恆星五緯同借日光而獨能繼照古今以之</span>  
<span style="margin-left: 2em">配日稱爲二曜則尊於諸星一也太陽以定春夏秋</span>  
<span style="margin-left: 2em">冬而成歲太陰以定晦朔弦望而成月歲與月錯綜</span>  
<span style="margin-left: 2em">損益曆法興焉以知天時以授民事二也日食于定</span>  
<span style="margin-left: 2em">朔月食于定望恆用日躔月離諸行以求食分加時</span>  
<span style="margin-left: 2em">日食之繁倍于月食其三視差皆從月生三也太陽</span>  
<span style="margin-left: 2em">五緯恆星漸次高遠差數漸微大小高下難可遽得</span>  
<span style="margin-left: 2em">惟月去人最近差數爲大易見易測故測候諸曜皆</span>  
<span style="margin-left: 2em">用月差較量繇顯入微悉能推見四也日與星不並</span>

<span style="margin-left: 1em">曆指五卷　　月離一</span>  
<span style="margin-left: 3em">月離各種行度第一</span>  
<span style="margin-left: 1em">月離行度與日躔異日躔恆依黃道其行度三而已隨</span>  
<span style="margin-left: 2em">宗動天西行一也自行二也最高行三也若月離則</span>  
<span style="margin-left: 2em">有七種行度如左</span>  
<span style="margin-left: 1em">一曰隨行隨行者自東而西依宗動天一日一周七政</span>  
<span style="margin-left: 2em">恆星共繇之其起算之界爲子正初點或午正初點</span>  
<span style="margin-left: 2em">與太陽同</span>  
<span style="margin-left: 1em">二曰平行<sub class="note-yuan">一名本行</sub>平行者月之本天自西而東日平行一</span>  
<span style="margin-left: 2em">十三度有奇二十七日有奇而行天一周其界有二</span>  
<span style="margin-left: 2em">一以太陽爲界從合朔起算每日去離太陽若干度</span>  
<span style="margin-left: 2em">分以命太陰之本行度分累積之一以宫次節氣爲</span>  
<span style="margin-left: 2em">界<sub class="note-yuan">宫次如降婁大梁等節氣如春分秋分等</sub>從各初點起算每日去離若</span>  
<span style="margin-left: 2em">干以命太陰之本行度分累積之此行謂之交周滿</span>  
<span style="margin-left: 2em">一周爲交終其初交曰正交其次交曰中交其行各</span>  
<span style="margin-left: 2em">及半曰正半交曰中半交　其兩界命兩種行度分</span>  
<span style="margin-left: 2em">異名同理詳下方</span>  
<span style="margin-left: 1em">三曰自行<sub class="note-jiao">校：清刊本三誤爲二〕一名本輪舊名小輪也因小輪非一故改名之</sub>自行者太</span>  
<span style="margin-left: 2em">陰之行不平不順有時疾有時遲既爾紛紜無憑布</span>  
<span style="margin-left: 2em">度古曆因想近月四周有一本輪太陰既隨本天循</span>  
<span style="margin-left: 2em">交道<sub class="note-yuan">即白道</sub>東行<sub class="note-yuan">右旋</sub>又依此輪自東而西<sub class="note-yuan">左旋</sub>一日行十</span>  
<span style="margin-left: 2em">三度有奇二十七日有奇而行輪一周此亦平行也</span>  
<span style="margin-left: 2em">而與交道平行參錯不一所以下土視之時疾時遲</span>  
<span style="margin-left: 2em">矣因其疾遲以別于交道之行故彼名平行此名自</span>  
<span style="margin-left: 2em">行也既曰周行本輪則疾時與交行相合遲時與交</span>  
<span style="margin-left: 2em">行相背亦宜如五緯之法有逆行度分此獨言遲不</span>  
<span style="margin-left: 2em">言逆者月行甚疾但見其遲不見其逆也此周謂之</span>  
<span style="margin-left: 2em">轉周滿一周爲轉終分四象限首限曰正轉二限曰</span>  
<span style="margin-left: 2em">正半轉亦曰本輪之最高三限曰中轉四限曰中半</span>  
<span style="margin-left: 2em">轉亦曰本輪之最庳曰最高衝<sub class="note-yuan">或省日高衝</sub>行最高極遲</span>  
<span style="margin-left: 2em">行最庳極疾也<sub class="note-yuan">最高最庳之一周又名不同心圈其與本輪異名同理詳見下方</sub></span>  
<span style="margin-left: 1em">四曰次輪次輪者太陰之最高既依白道行則月離最</span>  
<span style="margin-left: 2em">高時其距地心之遠近宜等迨測之則時時不等古</span>  
<span style="margin-left: 2em">曆又想本輪之周復有一次輪循本輪左旋月在次</span>  
<span style="margin-left: 2em">輪之上循周右旋也此法古曆所未有以意命之其</span>  
<span style="margin-left: 2em">行次輪一周名爲次轉終也四分之則爲小四象第</span>  
<span style="margin-left: 2em">一名正初象第二名正半象第三名中初象第四名</span>  
<span style="margin-left: 2em">中半象也</span>  
<span style="margin-left: 1em">五曰交行交行者從測候見太陰行白道<sub class="note-yuan">古法月有九行殊謬元授</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">時曆廢不用獨言白道交周是也一名月道</sub>出入黃道約五度有奇不行</span>  
<span style="margin-left: 2em">黃道中線<sub class="note-yuan">何名黃道中線七政恆星皆循黃道行而六曜皆有出入如太白最遠出入約六度</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">故黃道左右廣十二度名爲黃道帶而太陽獨行其最中故名中線也黃道一名躔道</sub>而兩交</span>  
<span style="margin-left: 2em">於中線兩交之點一名正交<sub class="note-yuan">亦曰羅㬋</sub>一名中交<sub class="note-yuan">亦曰計都</sub>兩</span>  
<span style="margin-left: 2em">交之行自東而西與他行異亦名羅計行度也</span>  
<span style="margin-left: 1em">六曰又次輪古來無有也萬曆間西史第谷測候極密</span>  
<span style="margin-left: 2em">得太陰行兩小輪<sub class="note-yuan">其一本輪其一次輪</sub>其各兩半時<sub class="note-yuan">兩小輪各有正半中</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">半</sub>之兩均數與實測之度分往往未合故知次輪而</span>  
<span style="margin-left: 2em">外當有又次一輪此之爲數微妙難分其於曆法未</span>  
<span style="margin-left: 2em">關損益故無暇及也</span>  
<span style="margin-left: 1em">七曰面輪面輪者太陰既依本輪又依次輪各周行即</span>  
<span style="margin-left: 2em">月面宜恆向次輪心下土所見時時旋轉須當不一</span>  
<span style="margin-left: 2em">若之何終古恆如是故當復有本行使面恆下向也</span>  
<span style="margin-left: 2em">此亦未關疎密不復備著</span>  
<span style="margin-left: 2em">測月平行度第二</span>  
<span style="margin-left: 1em">測月之法於七政爲最難其故有六</span>  
<span style="margin-left: 1em">其一月天最小距地甚近即地球與其本天有小大之</span>  
<span style="margin-left: 2em">比例乃測器之心不居地心而居地面則所得月軌</span>  
<span style="margin-left: 2em">高乃地面之視高非地心之實高也<sub class="note-yuan">此在日躔曆指謂之地半徑差</sub></span>  
<span style="margin-left: 1em">其二有地球與月天之比例乃可推地半徑差既得地</span>  
<span style="margin-left: 2em">半徑差乃以加所測之高定其實高不先得此無緣</span>  
<span style="margin-left: 2em">得彼</span>  
<span style="margin-left: 1em">其三凡得各曜之高必減清蒙之高以定實高各曜之</span>  
<span style="margin-left: 2em">蒙差高下不等測月者未知距地若干即無差數可</span>  
<span style="margin-left: 2em">減所測高則非實高</span>  
<span style="margin-left: 1em">其四月體恆虧缺不全若用太陽法令其光過窺表即</span>  
<span style="margin-left: 2em">虛淡難見光體不圓亦無從得其中心之光若目察</span>  
<span style="margin-left: 2em">窺表見月體不全無從測其心</span>  
<span style="margin-left: 1em">其五若測以地平經緯儀或黃赤道經緯儀縱得其經</span>  
<span style="margin-left: 2em">緯度分又以三視差故測得之數無一合者<sub class="note-yuan">三視差見交食</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">曆指</sub></span>  
<span style="margin-left: 1em">其六依測日星法以恆星測驗推算而得其經緯度似</span>  
<span style="margin-left: 2em">可用亦因三視差故無一合者</span>  
<span style="margin-left: 1em">然則何如按西曆古今法則月離度分必於月食時簡</span>  
<span style="margin-left: 2em">知之晉史姜岌亦以月食衝簡知太陽所在不知考</span>  
<span style="margin-left: 2em">太陽之躔度易考太陰之離度難而姜倒用之兩率</span>  
<span style="margin-left: 2em">皆疎矣今法於月食時推太陽之經度其對衝即太</span>  
<span style="margin-left: 2em">陰之經度<sub class="note-yuan">考大陽經度法見日躔表一卷</sub>若日食則不可用何故日</span>  
<span style="margin-left: 2em">食時因于視差是生中食實食視食<sub class="note-yuan">中食者兩平行所得平朔也實</sub></span>

<span style="margin-left: 2em"><sub class="note-yuan">也</sub>隨地隨時都無定率故</span>
