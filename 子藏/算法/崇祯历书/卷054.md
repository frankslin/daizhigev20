<span style="margin-left: 1em">历指五卷　　月离一</span>  
<span style="margin-left: 3em">月离各种行度第一</span>  
<span style="margin-left: 1em">月离行度与日躔异日躔恒依黄道其行度三而已随</span>  
<span style="margin-left: 2em">宗动天西行一也自行二也最高行三也若月离则</span>  
<span style="margin-left: 2em">有七种行度如左</span>  
<span style="margin-left: 1em">一曰随行随行者自东而西依宗动天一日一周七政</span>  
<span style="margin-left: 2em">恒星共繇之其起算之界为子正初点或午正初点</span>  
<span style="margin-left: 2em">与太阳同</span>  
<span style="margin-left: 1em">二曰平行<sub class="note-yuan">一名本行</sub>平行者月之本天自西而东日平行一</span>  
<span style="margin-left: 2em">十三度有奇二十七日有奇而行天一周其界有二</span>  
<span style="margin-left: 2em">一以太阳为界从合朔起算每日去离太阳若干度</span>  
<span style="margin-left: 2em">分以命太阴之本行度分累积之一以宫次节气为</span>  
<span style="margin-left: 2em">界<sub class="note-yuan">宫次如降娄大梁等节气如春分秋分等</sub>从各初点起算每日去离若</span>  
<span style="margin-left: 2em">干以命太阴之本行度分累积之此行谓之交周满</span>  
<span style="margin-left: 2em">一周为交终其初交曰正交其次交曰中交其行各</span>  
<span style="margin-left: 2em">及半曰正半交曰中半交　其两界命两种行度分</span>  
<span style="margin-left: 2em">异名同理详下方</span>  
<span style="margin-left: 1em">三曰自行<sub class="note-jiao">校：清刊本三誤爲二〕一名本輪舊名小輪也因小輪非一故改名之</sub>自行者太</span>  
<span style="margin-left: 2em">阴之行不平不顺有时疾有时迟既尔纷纭无凭布</span>  
<span style="margin-left: 2em">度古历因想近月四周有一本轮太阴既随本天循</span>  
<span style="margin-left: 2em">交道<sub class="note-yuan">即白道</sub>东行<sub class="note-yuan">右旋</sub>又依此轮自东而西<sub class="note-yuan">左旋</sub>一日行十</span>  
<span style="margin-left: 2em">三度有奇二十七日有奇而行轮一周此亦平行也</span>  
<span style="margin-left: 2em">而与交道平行参错不一所以下土视之时疾时迟</span>  
<span style="margin-left: 2em">矣因其疾迟以别于交道之行故彼名平行此名自</span>  
<span style="margin-left: 2em">行也既曰周行本轮则疾时与交行相合迟时与交</span>  
<span style="margin-left: 2em">行相背亦宜如五纬之法有逆行度分此独言迟不</span>  
<span style="margin-left: 2em">言逆者月行甚疾但见其迟不见其逆也此周谓之</span>  
<span style="margin-left: 2em">转周满一周为转终分四象限首限曰正转二限曰</span>  
<span style="margin-left: 2em">正半转亦曰本轮之最高三限曰中转四限曰中半</span>  
<span style="margin-left: 2em">转亦曰本轮之最庳曰最高冲<sub class="note-yuan">或省日高冲</sub>行最高极迟</span>  
<span style="margin-left: 2em">行最庳极疾也<sub class="note-yuan">最高最庳之一周又名不同心圈其与本轮异名同理详见下方</sub></span>  
<span style="margin-left: 1em">四曰次轮次轮者太阴之最高既依白道行则月离最</span>  
<span style="margin-left: 2em">高时其距地心之远近宜等迨测之则时时不等古</span>  
<span style="margin-left: 2em">历又想本轮之周复有一次轮循本轮左旋月在次</span>  
<span style="margin-left: 2em">轮之上循周右旋也此法古历所未有以意命之其</span>  
<span style="margin-left: 2em">行次轮一周名为次转终也四分之则为小四象第</span>  
<span style="margin-left: 2em">一名正初象第二名正半象第三名中初象第四名</span>  
<span style="margin-left: 2em">中半象也</span>  
<span style="margin-left: 1em">五曰交行交行者从测候见太阴行白道<sub class="note-yuan">古法月有九行殊谬元授</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">时历废不用独言白道交周是也一名月道</sub>出入黄道约五度有奇不行</span>  
<span style="margin-left: 2em">黄道中线<sub class="note-yuan">何名黄道中线七政恒星皆循黄道行而六曜皆有出入如太白最远出入约六度</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">故黄道左右广十二度名为黄道带而太阳独行其最中故名中线也黄道一名躔道</sub>而两交</span>  
<span style="margin-left: 2em">于中线两交之点一名正交<sub class="note-yuan">亦曰罗㬋</sub>一名中交<sub class="note-yuan">亦曰计都</sub>两</span>  
<span style="margin-left: 2em">交之行自东而西与他行异亦名罗计行度也</span>  
<span style="margin-left: 1em">六曰又次轮古来无有也万历间西史第谷测候极密</span>  
<span style="margin-left: 2em">得太阴行两小轮<sub class="note-yuan">其一本轮其一次轮</sub>其各两半时<sub class="note-yuan">两小轮各有正半中</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">半</sub>之两均数与实测之度分往往未合故知次轮而</span>  
<span style="margin-left: 2em">外当有又次一轮此之为数微妙难分其于历法未</span>  
<span style="margin-left: 2em">关损益故无暇及也</span>  
<span style="margin-left: 1em">七曰面轮面轮者太阴既依本轮又依次轮各周行即</span>  
<span style="margin-left: 2em">月面宜恒向次轮心下土所见时时旋转须当不一</span>  
<span style="margin-left: 2em">若之何终古恒如是故当复有本行使面恒下向也</span>  
<span style="margin-left: 2em">此亦未关疎密不复备著</span>  
<span style="margin-left: 2em">测月平行度第二</span>  
<span style="margin-left: 1em">测月之法于七政为最难其故有六</span>  
<span style="margin-left: 1em">其一月天最小距地甚近即地球与其本天有小大之</span>  
<span style="margin-left: 2em">比例乃测器之心不居地心而居地面则所得月轨</span>  
<span style="margin-left: 2em">高乃地面之视高非地心之实高也<sub class="note-yuan">此在日躔历指谓之地半径差</sub></span>  
<span style="margin-left: 1em">其二有地球与月天之比例乃可推地半径差既得地</span>  
<span style="margin-left: 2em">半径差乃以加所测之高定其实高不先得此无缘</span>  
<span style="margin-left: 2em">得彼</span>  
<span style="margin-left: 1em">其三凡得各曜之高必减清蒙之高以定实高各曜之</span>  
<span style="margin-left: 2em">蒙差高下不等测月者未知距地若干即无差数可</span>  
<span style="margin-left: 2em">减所测高则非实高</span>  
<span style="margin-left: 1em">其四月体恒亏缺不全若用太阳法令其光过窥表即</span>  
<span style="margin-left: 2em">虚淡难见光体不圆亦无从得其中心之光若目察</span>  
<span style="margin-left: 2em">窥表见月体不全无从测其心</span>  
<span style="margin-left: 1em">其五若测以地平经纬仪或黄赤道经纬仪纵得其经</span>  
<span style="margin-left: 2em">纬度分又以三视差故测得之数无一合者<sub class="note-yuan">三视差见交食</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">历指</sub></span>  
<span style="margin-left: 1em">其六依测日星法以恒星测验推算而得其经纬度似</span>  
<span style="margin-left: 2em">可用亦因三视差故无一合者</span>  
<span style="margin-left: 1em">然则何如按西历古今法则月离度分必于月食时简</span>  
<span style="margin-left: 2em">知之晋史姜岌亦以月食冲简知太阳所在不知考</span>  
<span style="margin-left: 2em">太阳之躔度易考太阴之离度难而姜倒用之两率</span>  
<span style="margin-left: 2em">皆疎矣今法于月食时推太阳之经度其对冲即太</span>  
<span style="margin-left: 2em">阴之经度<sub class="note-yuan">考大阳经度法见日躔表一卷</sub>若日食则不可用何故日</span>  
<span style="margin-left: 2em">食时因于视差是生中食实食视食<sub class="note-yuan">中食者两平行所得平朔也实</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">食者加减平朔而得地月日三心参直定朔也视食者加减定朔而得其加时先后此地此时人目所见</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">也</sub>随地随时都无定率故</span>  
<span style="margin-left: 1em">右法任用一月食皆足简知行度若求月平行率则用</span>  
<span style="margin-left: 2em">前后两会食取中积平分之其法与日平行相似而</span>  
<span style="margin-left: 2em">难易迥别何者月或全食或不全食或食于南或食</span>  
<span style="margin-left: 2em">于北或于迟限食或于疾限食各各不等顾须求其</span>
