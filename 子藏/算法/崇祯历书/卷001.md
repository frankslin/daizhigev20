## 崇禎曆書卷之一　崇禎奏疏

*崇禎二年四月二十九日至崇禎二年七月二十一日*

<sub class="note-jiao">校：據明刊國圖藏本爲底本</sub>

<span style="margin-left: 2em">緣起一</span>  
<span style="margin-left: 3em">崇禎二年九月十三日敕諭<sub class="note-jiao">校：標題原無今爲整理時加下同</sub></span>

<span style="margin-left: 9em">崇禎二年五月初十日禮部題本</span>  
<span style="margin-left: 3em">禮部</span>  
<span style="margin-left: 2em">題爲日食事祠祭司案呈奉本部送本月初三日奉</span>  
<span style="margin-left: 1em">上傳諭內閣欽天監推算日食前後刻數俱不對天文</span>  
<span style="margin-left: 2em">重事這等錯誤卿等傳與他姑恕一次以後還要細</span>  
<span style="margin-left: 2em">心推算如再錯誤重治不饒欽此欽遵傳出</span>  
<span style="margin-left: 3em">到部送司隨行該監查取推算官員職名據該監</span>  
<span style="margin-left: 3em">五官夏官正等官戈豐年等回稱備陳日食時刻</span>  
<span style="margin-left: 3em">少差切照本監所用</span>  
<span style="margin-left: 1em">大統曆乃</span>  
<span style="margin-left: 2em">國初監正元統所定其實即元太史郭守敬等所造</span>  
<span style="margin-left: 3em">授時曆也二百六十年來曆官按法推步一毫未</span>  
<span style="margin-left: 3em">嘗增損非惟不敢亦不能若妄有竄易則失之益</span>  
<span style="margin-left: 3em">遠矣切詳曆始于唐堯至今四千年其法從粗入</span>  
<span style="margin-left: 3em">細從疏入密漢唐以來有差至二日一日者後有</span>  
<span style="margin-left: 3em">差一二時者至于守敬授時之法古今稱爲極密</span>  
<span style="margin-left: 3em">然中間刻數依其本法尚不能無差故向來遵用</span>  
<span style="margin-left: 3em">推算每有一二刻不合若在早晚又不止一二刻</span>  
<span style="margin-left: 3em">矣此其立法固然非職自能更改亦非敢鹵莽失</span>  
<span style="margin-left: 3em">誤也豈惟職等即守敬以至元十八年成曆越十</span>  
<span style="margin-left: 3em">八年爲大德三年八月已推當食而不食大德六</span>  
<span style="margin-left: 3em">年六月又食而失推載在律曆志可查也是時守</span>  
<span style="margin-left: 3em">敬方以昭文殿大學士知太史院事亦付之無可</span>  
<span style="margin-left: 3em">奈何蓋一時心思技術已盡於此不能復有進步</span>  
<span style="margin-left: 3em">矣夫彼立法者尚然況職等斤斤守法者哉切聞</span>  
<span style="margin-left: 3em">創始難工增修易善自古以來每覺差訛即令專</span>  
<span style="margin-left: 3em">門宿學之臣爲之修改故漢曆改五次魏至隋改</span>  
<span style="margin-left: 3em">十三次唐至五代改十六次宋改十八次金元改</span>  
<span style="margin-left: 3em">三次獨我</span>  
<span style="margin-left: 1em">朝二百六十年未經修改中間又有年遠數盈及歲差</span>  
<span style="margin-left: 3em">增損諸事致差之因非一端也今欲循守舊法向</span>  
<span style="margin-left: 3em">後不能無差欲行修改更非淺陋所及遵奉</span>  
<span style="margin-left: 1em">聖諭嚴切措躬無地爲此備陳情愫等因到部送司案</span>  
<span style="margin-left: 3em">呈先該欽天監題稱推算到崇禎二年五月初一</span>  
<span style="margin-left: 3em">日乙酉朔日食三分二十四秒初虧巳正三刻西</span>  
<span style="margin-left: 3em">南食甚午初三刻正南復圓午正三刻東南至期</span>  
<span style="margin-left: 3em">劄委本司主事黃鳴俊公同測驗回呈據該監五</span>  
<span style="margin-left: 3em">官靈臺郎孔文進等手本回稱先該曆科夏官正</span>  
<span style="margin-left: 3em">戈豐年等推算到崇禎二年五月初一日乙酉朔</span>  
<span style="margin-left: 3em">日食候至午初一刻觀見日食初虧西南午正一</span>  
<span style="margin-left: 3em">刻食甚正南約食三分餘測參宿度分午正三刻</span>  
<span style="margin-left: 3em">復圓東南等因到司與先題互異例應罰治案呈</span>  
<span style="margin-left: 3em">到部臣等看得本月初一日日食原題初虧巳正</span>  
<span style="margin-left: 3em">三刻而今在午初一刻則已差二刻矣乃原推復</span>  
<span style="margin-left: 3em">圓在午正三刻而實在午正一刻又差二刻矣據</span>

<span style="margin-left: 1em">大統曆乃</span>  
<span style="margin-left: 2em">國初監正元統所定實元郭守敬授時曆之成法也</span>  
<span style="margin-left: 3em">曆官按書推步一毫不敢擅自增減今驗日食時</span>  
<span style="margin-left: 3em">刻俱不合以爲原法固然臣等查考近來交食果</span>

<span style="margin-left: 3em">能出郭守敬之上因循至今後來專官修正則有</span>

<span style="margin-left: 1em">請未奉</span>

<span style="margin-left: 1em">聖思寛宥又復具呈前來意亦謂元初至今相沿三百</span>  
<span style="margin-left: 3em">五十年無能改正而一旦於彼責成非其識力所</span>

<span style="margin-left: 3em">奉</span>  
<span style="margin-left: 1em">聖旨曆法</span>  
皇祖朝曾議重修今日食刻數復差允宜更正依卿等所  
<span style="margin-left: 2em">請修改一應事宜再著另行具奏欽此欽遵抄出到</span>  
<span style="margin-left: 3em">部送司案呈到部臣等查得萬曆四十年十一月</span>  
<span style="margin-left: 3em">朔日食欽天監推算得未正一刻初虧而兵部員</span>  
<span style="margin-left: 3em">外郎范守已候得申初一刻則是先天四刻以此</span>  
<span style="margin-left: 3em">累疏駁正該監亦稱候得初虧在未正三刻則是</span>  
<span style="margin-left: 3em">先天二刻以此具疏爭辯臣部看得四刻二刻總</span>  
<span style="margin-left: 3em">非密合所以然者授時曆本元初郭守敬諸人所</span>  
<span style="margin-left: 3em">造而大統曆因之比于漢唐宋諸家誠爲密近尚</span>  
<span style="margin-left: 3em">未能確與天合加以年遠數盈至今三百五十年</span>  
<span style="margin-left: 3em">未經修改故也以此具疏覆請乞博選知曆之人</span>  
<span style="margin-left: 3em">講求考驗務期悉合天度超越前古以垂永久未</span>  
<span style="margin-left: 3em">果施行今兩奉</span>  
<span style="margin-left: 1em">聖旨仰見我</span>
