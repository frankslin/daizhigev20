## 崇禎曆書卷之一百七十　日晷圖法卷三

<span style="margin-left: 1em">日晷圖法卷三</span>  
<span style="margin-left: 3em">百遊方晷</span>  
<span style="margin-left: 1em">用銅板或堅木板作甲乙丙丁直角形其長倍于其廣</span>  
<span style="margin-left: 1em">次五分其長令三在上二在下<sub class="note-jiao">校：在原作石據天理本校正</sub>橫作一</span>  
<span style="margin-left: 1em">辛庚直線次丙<sub class="note-jiao">校：天理本丙作兩</sub>平分辛庚于竹從竹作辛庚</span>  
<span style="margin-left: 1em">之垂線上爲竹艮即赤道線下爲竹土即卯酉線也次</span>  
<span style="margin-left: 1em">從辛從庚各作直線與艮土平行從辛者爲甲丁線從</span>  
<span style="margin-left: 1em">庚者爲乙丙線而辛之上下當書節氣則宜視板之厚</span>  
<span style="margin-left: 1em">薄薄者稍留三四分餘板以書節氣厚者不必留其邊</span>  
<span style="margin-left: 1em">亦可書之而板之分限定矣次以竹爲心向上作升凡</span>  
<span style="margin-left: 1em">半圈交赤道線于云次平分半圈爲百八十分則一度</span>  
<span style="margin-left: 1em">一分或九十分則兩度一分或三十六分則五度一分</span>  
<span style="margin-left: 1em">次于云左右各截二十三度半右爲甘左爲石次作甘</span>  
<span style="margin-left: 1em">竹線即冬至節線作石竹線即夏至節線也次作甘石</span>  
<span style="margin-left: 1em">線交赤道線于元即以元爲心甘石爲界作圈平分爲</span>  
<span style="margin-left: 1em">二十四分次以圈分上下直望每至甘云石圈上即作</span>  
<span style="margin-left: 1em">識即以竹心與甘云石圈上諸識相望作斜線而諸節</span>  
<span style="margin-left: 1em">氣線得矣次以竹與升云凡半圈上諸分相望每至甲</span>  
<span style="margin-left: 1em">丁乙丙兩界直線上交處即作識次以兩界線諸識平</span>  
<span style="margin-left: 1em">望各作平行線于冬夏二至線內漸移而上隨板書之</span>  
<span style="margin-left: 1em">若遇十數則稍上二至線外以便紀數而極出地度分</span>  
<span style="margin-left: 1em">線定矣但度數多則晷體益高大中國之地極出地度</span>  
<span style="margin-left: 1em">分不過四十五度或稍推廣亦以五六十度爲止更便</span>  
<span style="margin-left: 1em">携持也次以竹爲心辛庚爲界作仁庚土辛圈交赤道</span>  
<span style="margin-left: 1em">線于仁交處必與四十五度之線切合方爲的準不然</span>  
<span style="margin-left: 1em">必差矣次復以仁爲心竹爲界作半圈爲時線上界近</span>  
<span style="margin-left: 1em">板下邊亦以仁爲心任作圈分爲時線下界令線下留</span>  
<span style="margin-left: 1em">空以便記時次于仁庚土辛圈<sub class="note-jiao">校：土原作上據天理本校正</sub>從仁土</span>  
<span style="margin-left: 1em">線左右每半圈平分爲四十八分即十一時<sub class="note-jiao">校：天理本十一作十</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">二</sub>九十六刻也次以圈分上下直望俱作線與竹土線</span>  
<span style="margin-left: 1em">平行而十二時刻定矣次以右界線從辛土下<sub class="note-jiao">校：天理本土作</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">上</sub>各取圈分二十三度半依前法分節氣從辛上下俱</span>  
<span style="margin-left: 1em">作識即得旁節氣或于四十五度線上從仁向左右諸</span>  
<span style="margin-left: 1em">節氣線交處逐一爲度移至甲丁線上從辛向上下逐</span>  
<span style="margin-left: 1em">一作識亦得其上節氣線從竹度<sub class="note-jiao">校：天理本度作艮</sub>赤道線左</span>  
<span style="margin-left: 1em">行第一空爲春分及白露右行第一空爲秋分及驚蟄</span>  
<span style="margin-left: 1em">左行末線爲夏至界右行末線爲冬至界也其旁節氣</span>  
<span style="margin-left: 1em">線從辛向上第一空爲春分及白露向下第一空爲秋</span>  
<span style="margin-left: 1em">分及驚蟄上行末界爲夏至界下行末線爲冬至界也</span>  
<span style="margin-left: 1em">餘節氣依此推之諸式既畢乃視各線宜留者深之宜</span>  
<span style="margin-left: 1em">去者礲之次于節線上兩角勺行<sub class="note-jiao">校：天理本勺作內</sub>或于面上</span>  
<span style="margin-left: 1em">節線兩旁置左弓右坎<sub class="note-jiao">校：坎原作次據圖示改</sub>通光兩耳各作細</span>  
<span style="margin-left: 1em">孔以通日光其孔須相望相平從赤道上以規驗之次</span>  
<span style="margin-left: 1em">用銅作世勺尺牙三節臂可直可曲其世端任釘于空</span>  
<span style="margin-left: 1em">處如夕或于赤道上如艮令可轉動其牙端作一細孔</span>  
<span style="margin-left: 1em">孔貫一線可上可下其線末懸一銅銳如斤巨或線貫</span>  
<span style="margin-left: 1em">一細珠如丸線末懸一墜如卉用時移牙端切于極出</span>  
<span style="margin-left: 1em">地度及本日節氣線交處若用銅銳則以銳挈至界線</span>  
<span style="margin-left: 1em">節氣上餘線悉從牙孔上收之勿令有餘或以珠亦僅</span>  
<span style="margin-left: 1em">令至界線節氣上次以坎耳對日光令光從坎耳之孔</span>  
<span style="margin-left: 1em">直射弓耳之孔乃視銳或珠所值即得時刻也或于晷</span>  
<span style="margin-left: 1em">板繫一線線貫一針以代銅臂仍貫細珠及墜用時令</span>  
<span style="margin-left: 1em">針孔切于極出度及節線交處以等按之<sub class="note-jiao">校：天理本等作予</sub>次</span>  
<span style="margin-left: 1em">以珠當旁節氣如前用之亦得假如京師極出地四十</span>  
<span style="margin-left: 1em">度清明初　日測時則令銅臂牙端切于四十度當清</span>  
<span style="margin-left: 1em">明第　日交處如方點而以銅銳或珠移至界線上清</span>  
<span style="margin-left: 1em">明第八日如屯點次合日光<sub class="note-jiao">校：天理本合作令</sub>通耳孔而銳或</span>  
<span style="margin-left: 1em">珠乃若水點若午前即辰正二刻午後即申初三刻也</span>  
<span style="margin-left: 1em">依此晷即太陽出入時刻及晝夜長短俱可測之試以</span>  
<span style="margin-left: 1em">銅臂牙端加于本地極度及本日節氣線交處乃正立</span>  
<span style="margin-left: 1em">晷體令赤道線上端直指天頂次視銳或珠所指即得</span>  
<span style="margin-left: 1em">如欲知京師夏至日太陽出入及晝夜時刻即以铜臂</span>  
<span style="margin-left: 1em">仁端加于極出地四十度及夏至線上如寸點乃正立</span>  
<span style="margin-left: 1em">晷體令銳自垂所指互點若午前即寅正三刻爲日出</span>  
<span style="margin-left: 1em">時午後即戌初二刻爲日入時也從互以右諸時刻即</span>  
<span style="margin-left: 1em">晝時刻以左即夜時刻遂可知其長短焉</span>  
<span style="margin-left: 3em">百遊空晷</span>  
<span style="margin-left: 1em">用銅或牙或堅木約厚七八分爲甲乙丙丁圓板心在</span>  
<span style="margin-left: 1em">戊先作甲戊丙垂線次量晷大小從戊稍上任取辛點</span>  
<span style="margin-left: 1em">從辛作己庚辛橫線爲甲丙之垂線名表度線次于表</span>  
<span style="margin-left: 1em">線上從辛向近邊不逼邊處右截壬左截艮而辛壬與</span>  
<span style="margin-left: 1em">辛艮等次從壬從艮俱作線與甲丙平行即從壬從艮</span>  
<span style="margin-left: 1em">下行亦于近邊不逼邊處右截云左截甘而壬云與艮</span>  
<span style="margin-left: 1em">甘亦等次以壬云或艮甘爲度從壬從艮俱作半圈名</span>  
<span style="margin-left: 1em">時圈右圈交表線于土左圈交表線于竹但始求云甘</span>  
<span style="margin-left: 1em">時須先量土竹不與表線逼而始求壬艮線時亦須先</span>  
<span style="margin-left: 1em">量云甘不與圈邊逼爲度次取己庚壬艮云甘以外及</span>  
<span style="margin-left: 1em">半圈以內板悉刳去之圈內面須極平極圓壬艮角須</span>  
<span style="margin-left: 16em">極稜極整次于</span>  
<span style="margin-left: 16em">圈內面求左右</span>  
<span style="margin-left: 16em">之中作弓坎線</span>  
<span style="margin-left: 16em"><sub class="note-jiao">校：坎原作次據圖示改</sub>爲</span>  
<span style="margin-left: 16em">赤道線即以時</span>  
<span style="margin-left: 16em">圈爲度別于他</span>  
<span style="margin-left: 16em">平板依一卷第</span>  
<span style="margin-left: 17em">法分節氣俱</span>  
<span style="margin-left: 16em">作平行直線即</span>  
<span style="margin-left: 16em">以此線移之晷</span>  
<span style="margin-left: 1em">內從赤道左右作節氣線自赤道以下者即春分至白</span>  
<span style="margin-left: 1em">露十二節赤道以上者即秋分至驚蟄十二節也次于</span>  
<span style="margin-left: 1em">壬艮角表之中與圖內<sub class="note-jiao">校：天理本圖作圈</sub>赤道線相對處置微</span>  
<span style="margin-left: 1em">銳如仁爲定節氣之表若于角表面上分節氣線而作</span>  
<span style="margin-left: 1em">一微銳活表以隨日就之則圈上止作赤道線不必分</span>  
<span style="margin-left: 1em">他節矣次從上至云竹至甘勺分爲二十四分土即酉</span>  
<span style="margin-left: 1em">正竹即卯正云甘即午也卯酉以上依下分之即得寅</span>  
<span style="margin-left: 1em">戌等時矣其极以內兩圈次外所存者上少下多輕重</span>  
<span style="margin-left: 1em">不等難以懸時即于下方復鑿缶世皿一空以稱之次</span>  
<span style="margin-left: 1em">于晷下或作平板用度板以倚之<sub class="note-yuan">法見前赤道晷</sub>或于晷邊外</span>  
<span style="margin-left: 1em">別作度圈以懸之如前圖作尺勺夕斤圈其上半圈平</span>  
<span style="margin-left: 1em">分一百八十度若晷小則每二度或五度或十度作一</span>  
<span style="margin-left: 1em">分亦可用時開度圈與晷作十字形令度圈正對晷上</span>  
<span style="margin-left: 1em">甲丙線以鈎二度圈上本地極出之度而令晷之甲向</span>  
<span style="margin-left: 1em">南若午前則視左半圈之景午後則視右半圈之景如</span>  
<span style="margin-left: 1em">節氣分于圈內則令表上微銳之景指本日節氣線次</span>  
<span style="margin-left: 1em">視表景所值即得目下時刻也若節氣不分于圈而分</span>  
<span style="margin-left: 1em">于表面上則移活銳置于本日節氣線令銳射圈內赤</span>  
<span style="margin-left: 1em">道線次視表景所值亦如前得時刻其自己至庚下半</span>  
<span style="margin-left: 1em">圈相連處亦可以依中線分時刻自己至丙爲卯至午</span>  
<span style="margin-left: 1em">自丙至庚爲午至酉即赤道晷也用時立表于戊心其</span>  
<span style="margin-left: 1em">角表至內時刻即心表至外時刻必相合也</span>  
<span style="margin-left: 3em">盤晷<sub class="note-yuan">附百遊法</sub></span>  
<span style="margin-left: 1em">此晷之形如仰盂其法用堅木或銅或牙爲甲乙丙丁</span>  
<span style="margin-left: 1em">圓盤刳其內深半規以當周天之半盤口須厚分許以</span>  
<span style="margin-left: 1em">備書字又須極平口線須極準規深欲極圓宜光作<sub class="note-jiao">校：天</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">理本光作先</sub>一器以驗之用銅板或半規如巨凡古又用銅</span>  
<span style="margin-left: 1em">板爲半規之半如工卉乍其卉乍邊合于巨凡古之中</span>  
<span style="margin-left: 1em">線<sub class="note-jiao">校：中線原作甲線據天理本改</sub>而丹乍邊之匹聿二柄入于巨凡古</span>  
<span style="margin-left: 1em">線之今厄二孔又于工丹與巨凡之上稍留餘板以便</span>  
<span style="margin-left: 16em">執持而工巨凡</span>  
<span style="margin-left: 16em">之三角亦稍留</span>  
<span style="margin-left: 16em">餘銳以爲界限</span>  
<span style="margin-left: 16em">次樹此器于盤</span>  
<span style="margin-left: 16em">中旋轉范之令</span>  
<span style="margin-left: 16em">工巨凡之三角</span>  
<span style="margin-left: 16em">切于盤口而巨</span>  
<span style="margin-left: 16em">古與古凡及工</span>  
<span style="margin-left: 16em">乍三邊俱與盤</span>  
<span style="margin-left: 16em">底相合即極圓</span>  
<span style="margin-left: 1em">矣次以盤口內邊作艮土竹云四平分次以四分之一</span>  
<span style="margin-left: 1em">爲度以云及土各爲心向盤底作圜線兩線必爲一線</span>  
<span style="margin-left: 1em">必與盤口之艮竹相遇是即午線也若以艮竹各爲心</span>  
<span style="margin-left: 1em">亦向盤底作圜線兩線亦必爲一線亦必與盤口之土</span>  
<span style="margin-left: 1em">云相遇而土云及艮竹兩線必交于戊爲盤之正心稍</span>  
<span style="margin-left: 1em">差必不準矣次平分戊艮爲九十度若盤中分法不便</span>  
<span style="margin-left: 1em">則以盤口半徑如艮竹爲度別于平板上作全圜四分</span>  
<span style="margin-left: 1em">之一平分爲九十度逐一移之戊艮線上即得或以半</span>  
<span style="margin-left: 1em">徑爲度于首卷第　　度板上取本地極出度分如京</span>  
<span style="margin-left: 1em">師四十度從戊向竹得己又于度板上量本地極出餘</span>  
<span style="margin-left: 1em">分如京師五十度如戊向艮得庚自己至庚即周天四</span>  
<span style="margin-left: 1em">分之一也次用向外曲脚規以庚爲心己爲界作辛己</span>  
<span style="margin-left: 1em">壬圜爲赤道線次以盤口半徑爲度于一卷分節氣法</span>  
<span style="margin-left: 1em">求得各節氣疎密之度次從赤道各各節氣逐一爲度</span>  
<span style="margin-left: 1em">移至盤中從己向庚向竹逐一作識次以庚爲心各識</span>  
<span style="margin-left: 1em">爲界逐一作線皆與赤道平行而節氣定矣次于赤道</span>  
<span style="margin-left: 1em">線上從己向土向云各爲二十四平分即三時之二十</span>  
<span style="margin-left: 1em">四刻也次以曲規于各分逐一爲心每隔三時二十四</span>  
<span style="margin-left: 1em">刻爲界逐一作線如以午正爲心即作卯酉正線以未</span>  
<span style="margin-left: 1em">正爲心即作辰正線而時刻定矣次立表于戊或于庚</span>  
<span style="margin-left: 1em">無定位但須表端與盤口正平用直尺橫盤口驗之又</span>  
<span style="margin-left: 1em">須表端居盤空正中用規指盤口四面度之若不欲用</span>  
<span style="margin-left: 1em">表即于盤口繫艮竹及土云兩線相聯必交于盤口之</span>  
<span style="margin-left: 1em">正中而又與盤口相平以交處當表端更準也用時仰</span>  
<span style="margin-left: 1em">晷于平處以甲邊面南<sub class="note-jiao">校：天理本面作向</sub>而令表端景射本日</span>  
<span style="margin-left: 1em">節氣線即甲丙正直子午向矣次視表端景所指時刻</span>  
<span style="margin-left: 1em">即得若于盤底設小羅經以正方則不必作節線而表</span>  
<span style="margin-left: 1em">端景亦必指時刻也</span>  
<span style="margin-left: 1em">前法乃依本地極出度分而作故獨同度之地可用若</span>  
<span style="margin-left: 1em">欲百遊則節氣時刻分法悉與前同但午正線反在盤</span>  
<span style="margin-left: 1em">口卯酉正線反在盤中而赤道線亦在盤中與卯酉線</span>  
<span style="margin-left: 1em">交于戌則稍異耳則左圖甲乙丙丁圜爲盤體升方線</span>
