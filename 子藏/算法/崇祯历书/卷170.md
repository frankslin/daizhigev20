## 崇祯历书卷之一百七十　日晷图法卷三

<span style="margin-left: 1em">日晷图法卷三</span>  
<span style="margin-left: 3em">百游方晷</span>  
<span style="margin-left: 1em">用铜板或坚木板作甲乙丙丁直角形其长倍于其广</span>  
<span style="margin-left: 1em">次五分其长令三在上二在下<sub class="note-jiao">校：在原作石據天理本校正</sub>横作一</span>  
<span style="margin-left: 1em">辛庚直线次丙<sub class="note-jiao">校：天理本丙作兩</sub>平分辛庚于竹从竹作辛庚</span>  
<span style="margin-left: 1em">之垂线上为竹艮即赤道线下为竹土即卯酉线也次</span>  
<span style="margin-left: 1em">从辛从庚各作直线与艮土平行从辛者为甲丁线从</span>  
<span style="margin-left: 1em">庚者为乙丙线而辛之上下当书节气则宜视板之厚</span>  
<span style="margin-left: 1em">薄薄者稍留三四分余板以书节气厚者不必留其边</span>  
<span style="margin-left: 1em">亦可书之而板之分限定矣次以竹为心向上作升凡</span>  
<span style="margin-left: 1em">半圈交赤道线于云次平分半圈为百八十分则一度</span>  
<span style="margin-left: 1em">一分或九十分则两度一分或三十六分则五度一分</span>  
<span style="margin-left: 1em">次于云左右各截二十三度半右为甘左为石次作甘</span>  
<span style="margin-left: 1em">竹线即冬至节线作石竹线即夏至节线也次作甘石</span>  
<span style="margin-left: 1em">线交赤道线于元即以元为心甘石为界作圈平分为</span>  
<span style="margin-left: 1em">二十四分次以圈分上下直望每至甘云石圈上即作</span>  
<span style="margin-left: 1em">识即以竹心与甘云石圈上诸识相望作斜线而诸节</span>  
<span style="margin-left: 1em">气线得矣次以竹与升云凡半圈上诸分相望每至甲</span>  
<span style="margin-left: 1em">丁乙丙两界直线上交处即作识次以两界线诸识平</span>  
<span style="margin-left: 1em">望各作平行线于冬夏二至线内渐移而上随板书之</span>  
<span style="margin-left: 1em">若遇十数则稍上二至线外以便纪数而极出地度分</span>  
<span style="margin-left: 1em">线定矣但度数多则晷体益高大中国之地极出地度</span>  
<span style="margin-left: 1em">分不过四十五度或稍推广亦以五六十度为止更便</span>  
<span style="margin-left: 1em">携持也次以竹为心辛庚为界作仁庚土辛圈交赤道</span>  
<span style="margin-left: 1em">线于仁交处必与四十五度之线切合方为的准不然</span>  
<span style="margin-left: 1em">必差矣次复以仁为心竹为界作半圈为时线上界近</span>  
<span style="margin-left: 1em">板下边亦以仁为心任作圈分为时线下界令线下留</span>  
<span style="margin-left: 1em">空以便记时次于仁庚土辛圈<sub class="note-jiao">校：土原作上據天理本校正</sub>从仁土</span>  
<span style="margin-left: 1em">线左右每半圈平分为四十八分即十一时<sub class="note-jiao">校：天理本十一作十</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">二</sub>九十六刻也次以圈分上下直望俱作线与竹土线</span>  
<span style="margin-left: 1em">平行而十二时刻定矣次以右界线从辛土下<sub class="note-jiao">校：天理本土作</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">上</sub>各取圈分二十三度半依前法分节气从辛上下俱</span>  
<span style="margin-left: 1em">作识即得旁节气或于四十五度线上从仁向左右诸</span>  
<span style="margin-left: 1em">节气线交处逐一为度移至甲丁线上从辛向上下逐</span>  
<span style="margin-left: 1em">一作识亦得其上节气线从竹度<sub class="note-jiao">校：天理本度作艮</sub>赤道线左</span>  
<span style="margin-left: 1em">行第一空为春分及白露右行第一空为秋分及惊蛰</span>  
<span style="margin-left: 1em">左行末线为夏至界右行末线为冬至界也其旁节气</span>  
<span style="margin-left: 1em">线从辛向上第一空为春分及白露向下第一空为秋</span>  
<span style="margin-left: 1em">分及惊蛰上行末界为夏至界下行末线为冬至界也</span>  
<span style="margin-left: 1em">余节气依此推之诸式既毕乃视各线宜留者深之宜</span>  
<span style="margin-left: 1em">去者礲之次于节线上两角勺行<sub class="note-jiao">校：天理本勺作內</sub>或于面上</span>  
<span style="margin-left: 1em">节线两旁置左弓右坎<sub class="note-jiao">校：坎原作次據圖示改</sub>通光两耳各作细</span>  
<span style="margin-left: 1em">孔以通日光其孔须相望相平从赤道上以规验之次</span>  
<span style="margin-left: 1em">用铜作世勺尺牙三节臂可直可曲其世端任钉于空</span>  
<span style="margin-left: 1em">处如夕或于赤道上如艮令可转动其牙端作一细孔</span>  
<span style="margin-left: 1em">孔贯一线可上可下其线末悬一铜锐如斤巨或线贯</span>  
<span style="margin-left: 1em">一细珠如丸线末悬一坠如卉用时移牙端切于极出</span>  
<span style="margin-left: 1em">地度及本日节气线交处若用铜锐则以锐挈至界线</span>  
<span style="margin-left: 1em">节气上余线悉从牙孔上收之勿令有余或以珠亦仅</span>  
<span style="margin-left: 1em">令至界线节气上次以坎耳对日光令光从坎耳之孔</span>  
<span style="margin-left: 1em">直射弓耳之孔乃视锐或珠所值即得时刻也或于晷</span>  
<span style="margin-left: 1em">板系一线线贯一针以代铜臂仍贯细珠及坠用时令</span>  
<span style="margin-left: 1em">针孔切于极出度及节线交处以等按之<sub class="note-jiao">校：天理本等作予</sub>次</span>  
<span style="margin-left: 1em">以珠当旁节气如前用之亦得假如京师极出地四十</span>  
<span style="margin-left: 1em">度清明初　日测时则令铜臂牙端切于四十度当清</span>  
<span style="margin-left: 1em">明第　日交处如方点而以铜锐或珠移至界线上清</span>  
<span style="margin-left: 1em">明第八日如屯点次合日光<sub class="note-jiao">校：天理本合作令</sub>通耳孔而锐或</span>  
<span style="margin-left: 1em">珠乃若水点若午前即辰正二刻午后即申初三刻也</span>  
<span style="margin-left: 1em">依此晷即太阳出入时刻及昼夜长短俱可测之试以</span>  
<span style="margin-left: 1em">铜臂牙端加于本地极度及本日节气线交处乃正立</span>  
<span style="margin-left: 1em">晷体令赤道线上端直指天顶次视锐或珠所指即得</span>  
<span style="margin-left: 1em">如欲知京师夏至日太阳出入及昼夜时刻即以铜臂</span>  
<span style="margin-left: 1em">仁端加于极出地四十度及夏至线上如寸点乃正立</span>  
<span style="margin-left: 1em">晷体令锐自垂所指互点若午前即寅正三刻为日出</span>  
<span style="margin-left: 1em">时午后即戌初二刻为日入时也从互以右诸时刻即</span>  
<span style="margin-left: 1em">昼时刻以左即夜时刻遂可知其长短焉</span>  
<span style="margin-left: 3em">百游空晷</span>  
<span style="margin-left: 1em">用铜或牙或坚木约厚七八分为甲乙丙丁圆板心在</span>  
<span style="margin-left: 1em">戊先作甲戊丙垂线次量晷大小从戊稍上任取辛点</span>  
<span style="margin-left: 1em">从辛作己庚辛横线为甲丙之垂线名表度线次于表</span>  
<span style="margin-left: 1em">线上从辛向近边不逼边处右截壬左截艮而辛壬与</span>  
<span style="margin-left: 1em">辛艮等次从壬从艮俱作线与甲丙平行即从壬从艮</span>  
<span style="margin-left: 1em">下行亦于近边不逼边处右截云左截甘而壬云与艮</span>  
<span style="margin-left: 1em">甘亦等次以壬云或艮甘为度从壬从艮俱作半圈名</span>  
<span style="margin-left: 1em">时圈右圈交表线于土左圈交表线于竹但始求云甘</span>  
<span style="margin-left: 1em">时须先量土竹不与表线逼而始求壬艮线时亦须先</span>  
<span style="margin-left: 1em">量云甘不与圈边逼为度次取己庚壬艮云甘以外及</span>  
<span style="margin-left: 1em">半圈以内板悉刳去之圈内面须极平极圆壬艮角须</span>  
<span style="margin-left: 16em">极棱极整次于</span>  
<span style="margin-left: 16em">圈内面求左右</span>  
<span style="margin-left: 16em">之中作弓坎线</span>  
<span style="margin-left: 16em"><sub class="note-jiao">校：坎原作次據圖示改</sub>为</span>  
<span style="margin-left: 16em">赤道线即以时</span>  
<span style="margin-left: 16em">圈为度别于他</span>  
<span style="margin-left: 16em">平板依一卷第</span>  
<span style="margin-left: 17em">法分节气俱</span>  
<span style="margin-left: 16em">作平行直线即</span>  
<span style="margin-left: 16em">以此线移之晷</span>  
<span style="margin-left: 1em">内从赤道左右作节气线自赤道以下者即春分至白</span>  
<span style="margin-left: 1em">露十二节赤道以上者即秋分至惊蛰十二节也次于</span>  
<span style="margin-left: 1em">壬艮角表之中与图内<sub class="note-jiao">校：天理本圖作圈</sub>赤道线相对处置微</span>  
<span style="margin-left: 1em">锐如仁为定节气之表若于角表面上分节气线而作</span>  
<span style="margin-left: 1em">一微锐活表以随日就之则圈上止作赤道线不必分</span>  
<span style="margin-left: 1em">他节矣次从上至云竹至甘勺分为二十四分土即酉</span>  
<span style="margin-left: 1em">正竹即卯正云甘即午也卯酉以上依下分之即得寅</span>  
<span style="margin-left: 1em">戌等时矣其极以内两圈次外所存者上少下多轻重</span>  
<span style="margin-left: 1em">不等难以悬时即于下方复凿缶世皿一空以称之次</span>  
<span style="margin-left: 1em">于晷下或作平板用度板以倚之<sub class="note-yuan">法见前赤道晷</sub>或于晷边外</span>  
<span style="margin-left: 1em">别作度圈以悬之如前图作尺勺夕斤圈其上半圈平</span>  
<span style="margin-left: 1em">分一百八十度若晷小则每二度或五度或十度作一</span>  
<span style="margin-left: 1em">分亦可用时开度圈与晷作十字形令度圈正对晷上</span>  
<span style="margin-left: 1em">甲丙线以钩二度圈上本地极出之度而令晷之甲向</span>  
<span style="margin-left: 1em">南若午前则视左半圈之景午后则视右半圈之景如</span>  
<span style="margin-left: 1em">节气分于圈内则令表上微锐之景指本日节气线次</span>  
<span style="margin-left: 1em">视表景所值即得目下时刻也若节气不分于圈而分</span>  
<span style="margin-left: 1em">于表面上则移活锐置于本日节气线令锐射圈内赤</span>

<span style="margin-left: 1em">角表至内时刻即心表至外时刻必相合也</span>  
<span style="margin-left: 3em">盘晷<sub class="note-yuan">附百游法</sub></span>  
<span style="margin-left: 1em">此晷之形如仰盂其法用坚木或铜或牙为甲乙丙丁</span>

<span style="margin-left: 16em">工巨凡之三角</span>  
<span style="margin-left: 16em">切于盘口而巨</span>  
<span style="margin-left: 16em">古与古凡及工</span>  
<span style="margin-left: 16em">乍三边俱与盘</span>  
<span style="margin-left: 16em">底相合即极圆</span>  
<span style="margin-left: 1em">矣次以盘口内边作艮土竹云四平分次以四分之一</span>  
<span style="margin-left: 1em">为度以云及土各为心向盘底作圜线两线必为一线</span>

<span style="margin-left: 1em">之一平分为九十度逐一移之戊艮线上即得或以半</span>  
<span style="margin-left: 1em">径为度于首卷第　　度板上取本地极出度分如京</span>  
<span style="margin-left: 1em">师四十度从戊向竹得己又于度板上量本地极出余</span>  
<span style="margin-left: 1em">分如京师五十度如戊向艮得庚自己至庚即周天四</span>  
<span style="margin-left: 1em">分之一也次用向外曲脚规以庚为心己为界作辛己</span>

<span style="margin-left: 1em">节气线即甲丙正直子午向矣次视表端景所指时刻</span>  
<span style="margin-left: 1em">即得若于盘底设小罗经以正方则不必作节线而表</span>
