<span style="margin-left: 1em">首二三位爲數幾何以意商除商得之餘尚有不盡以</span>  
<span style="margin-left: 1em">法命分可耳愚按曆書總目載有開方簡法卷帙殘闕</span>  
<span style="margin-left: 1em">原書不復可得因爲竊取遺意推衍補入由繁得簡法</span>  
<span style="margin-left: 1em">法具備即以印證西士知可百世不惑矣歲在玄黓閹</span>  
<span style="margin-left: 1em">茂日躔井十六度古吳苼菴道人朱㿥識于葑溪西里</span>  
<span style="margin-left: 1em">詒遠堂</span>  
<span style="margin-left: 3em">開方立成表用法</span>  
<span style="margin-left: 1em">此立成表即自乘再乘之積實也上格橫列爲方根及</span>  
<span style="margin-left: 1em">次商百十成數漸下則自一至九末商零數始于一終</span>  
<span style="margin-left: 1em">于九百九十九不及四開者數踰十億萬大畧已備遇</span>  
<span style="margin-left: 1em">此則漸及兆萬浩賾難窮不便作表矣其每格各分二</span>  
<span style="margin-left: 1em">行上行爲平方積下行爲立方積列實自右而左凡遇</span>  
<span style="margin-left: 1em">開方不煩列籌布算但一檢表舉積實之全數即得方</span>  
<span style="margin-left: 1em">根之若干舉方根之若干即得積實之全數至簡至易</span>  
<span style="margin-left: 1em">無過于此然學者從事推算貴有心得必須熟知廉隅</span>  
<span style="margin-left: 1em">加倍之故運用無差若未經探討漫趋捷徑則是日用</span>  
<span style="margin-left: 1em">不知反失置表之意矣</span>
