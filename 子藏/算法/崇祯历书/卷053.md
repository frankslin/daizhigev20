<span style="margin-left: 2em">以恒星之黄道经纬度求其赤道经纬度第一　三</span>  
<span style="margin-left: 3em">章</span>  
<span style="margin-left: 1em">前论恒星以本行依黄道渐移而东既有平行经度而</span>  
<span style="margin-left: 2em">纬度南北移就为数甚少非历岁久远不可得见以</span>  
<span style="margin-left: 2em">此互相推较其经度差无时不同纬度相距远近又</span>  
<span style="margin-left: 2em">无从可改必至数百年后测验差数乃得依法推变</span>  
<span style="margin-left: 2em">也若论赤道经纬度则否星行既依黄道其向赤道</span>  
<span style="margin-left: 2em">时时迁改欲从赤道求之无法可得故求赤道经纬</span>  
<span style="margin-left: 2em">必用黄道经纬盖星之去离赤道无恒而去离黄道</span>  
<span style="margin-left: 2em">有恒黄道赤道之相去离也又有恒以两有恒求一</span>  
<span style="margin-left: 2em">无恒无患不得矣其推步则有多法或用曲线三角</span>  
<span style="margin-left: 2em">形依乘除三率推算为第一此初法也或用曲线三</span>  
<span style="margin-left: 2em">角形加减推算为第二此约法也或用简平仪量度</span>  
<span style="margin-left: 2em">加减推算为第三此简法也或造立成表简阅得数</span>  
<span style="margin-left: 2em">并免临时推算之烦为第四此因法也第一法前第</span>  
<span style="margin-left: 2em">一卷已备论之今所论者每具二则为第二第三法</span>  
<span style="margin-left: 2em">如左方若立成表作者甚难用者甚佚但恐狥末忘</span>  
<span style="margin-left: 2em">本则繇而不知者多矣今附载之</span>  
<span style="margin-left: 3em">求恒星赤道纬度前法<sub class="note-yuan">即第二法</sub></span>  
<span style="margin-left: 1em">前法用曲线三角形加减推算如图有星在甲甲辛为</span>  
<span style="margin-left: 7em">黄道纬度其余弧甲乙为甲乙丙三角</span>  
<span style="margin-left: 7em">形之一边辛戊为黄道经度以加戊己</span>  
<span style="margin-left: 7em">象限得甲乙丙角又乙丙为两极距度</span>  
<span style="margin-left: 7em">则是甲乙丙角形有甲乙乙丙两边有</span>  
<span style="margin-left: 2em">乙角可求甲丙边甲丙之余弧甲丁则本星距赤道</span>  
<span style="margin-left: 2em">之纬度也其法以三角形内之小弧加于大弧之余</span>  
<span style="margin-left: 2em">弧得总弧求其正弦<sub class="note-yuan">求纬恒用正弦求经恒用切线</sub>为先得数其总</span>  
<span style="margin-left: 2em">弧或正得九十度或较多或较寡若正得九十度即</span>  
<span style="margin-left: 2em">半先得之弦为次得之弦又以大小两弧所包之见</span>  
<span style="margin-left: 2em">角求其倒弦<sub class="note-yuan">为角之弧过象限故用倒弦倒弦者对本角过弧之正弦</sub>则后得之</span>  
<span style="margin-left: 2em">弦也今用三率法为全数与次得之弦若后得之倒</span>  
<span style="margin-left: 2em">弦与他弦既得他弦以减先得之弦所存为三角形</span>

<span style="margin-left: 2em">弦次求甲乙丙角之倒弦<sub class="note-yuan">即己辛弧之弦</sub>一九六三〇一<sub class="note-yuan">首一</sub></span>
