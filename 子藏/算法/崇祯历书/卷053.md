<span style="margin-left: 2em">以恆星之黃道經緯度求其赤道經緯度第一　三</span>  
<span style="margin-left: 3em">章</span>  
<span style="margin-left: 1em">前論恆星以本行依黃道漸移而東既有平行經度而</span>  
<span style="margin-left: 2em">緯度南北移就爲數甚少非歷歲久遠不可得見以</span>  
<span style="margin-left: 2em">此互相推較其經度差無時不同緯度相距遠近又</span>  
<span style="margin-left: 2em">無從可改必至數百年後測驗差數乃得依法推變</span>  
<span style="margin-left: 2em">也若論赤道經緯度則否星行既依黃道其向赤道</span>  
<span style="margin-left: 2em">時時遷改欲從赤道求之無法可得故求赤道經緯</span>  
<span style="margin-left: 2em">必用黃道經緯蓋星之去離赤道無恆而去離黃道</span>  
<span style="margin-left: 2em">有恆黃道赤道之相去離也又有恆以兩有恆求一</span>  
<span style="margin-left: 2em">無恆無患不得矣其推步則有多法或用曲線三角</span>  
<span style="margin-left: 2em">形依乘除三率推算爲第一此初法也或用曲線三</span>  
<span style="margin-left: 2em">角形加減推算爲第二此約法也或用簡平儀量度</span>  
<span style="margin-left: 2em">加減推算爲第三此簡法也或造立成表簡閲得數</span>  
<span style="margin-left: 2em">并免臨時推算之煩爲第四此因法也第一法前第</span>  
<span style="margin-left: 2em">一卷已備論之今所論者每具二則爲第二第三法</span>  
<span style="margin-left: 2em">如左方若立成表作者甚難用者甚佚但恐狥末忘</span>  
<span style="margin-left: 2em">本則繇而不知者多矣今附載之</span>  
<span style="margin-left: 3em">求恆星赤道緯度前法<sub class="note-yuan">即第二法</sub></span>  
<span style="margin-left: 1em">前法用曲線三角形加減推算如圖有星在甲甲辛爲</span>  
<span style="margin-left: 7em">黃道緯度其餘弧甲乙爲甲乙丙三角</span>  
<span style="margin-left: 7em">形之一邊辛戊爲黃道經度以加戊己</span>  
<span style="margin-left: 7em">象限得甲乙丙角又乙丙爲兩極距度</span>  
<span style="margin-left: 7em">則是甲乙丙角形有甲乙乙丙兩邊有</span>  
<span style="margin-left: 2em">乙角可求甲丙邊甲丙之餘弧甲丁則本星距赤道</span>  
<span style="margin-left: 2em">之緯度也其法以三角形內之小弧加于大弧之餘</span>  
<span style="margin-left: 2em">弧得總弧求其正弦<sub class="note-yuan">求緯恆用正弦求經恆用切線</sub>爲先得數其總</span>  
<span style="margin-left: 2em">弧或正得九十度或較多或較寡若正得九十度即</span>  
<span style="margin-left: 2em">半先得之弦爲次得之弦又以大小兩弧所包之見</span>  
<span style="margin-left: 2em">角求其倒弦<sub class="note-yuan">爲角之弧過象限故用倒弦倒弦者對本角過弧之正弦</sub>則後得之</span>  
<span style="margin-left: 2em">弦也今用三率法爲全數與次得之弦若後得之倒</span>  
<span style="margin-left: 2em">弦與他弦既得他弦以減先得之弦所存爲三角形</span>  
<span style="margin-left: 2em">內第三弧之餘弦即所求赤道緯之正弦也</span>  
<span style="margin-left: 2em">假如參宿腰星之西有五等小星<sub class="note-jiao">校：法圖本無之字</sub>其黃道</span>  
<span style="margin-left: 2em">經度于崇禎元年<sub class="note-jiao">校：法圖本無于字</sub>推得七十四度二十二</span>  
<span style="margin-left: 2em">分其<sub class="note-jiao">校：法圖本無其字</sub>緯度距黃道南二十三度三十二分</span>  
<span style="margin-left: 2em">使黃道在南距赤道二十三度三十二分<sub class="note-yuan">云使者假設之數不</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">用實分秒</sub>則三角形內甲乙大弧得六十六度二十八分</span>  
<span style="margin-left: 2em">乙丙小弧二十三度三十二分甲乙丙角對辛戊經</span>  
<span style="margin-left: 7em">度弧及戊己象限弧共得一百六十四</span>  
<span style="margin-left: 7em">度二十二分<sub class="note-jiao">校：法圖本無得字</sub>甲辛爲甲乙大</span>  
<span style="margin-left: 7em">弧之餘弧得二十三度三十二分依法</span>  
<span style="margin-left: 7em">加于乙丙小弧二十三度三十二分<sub class="note-jiao">校：法</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">圖本無于字</sub>得四十七度〇四分其正弦七三二一五爲</span>  
<span style="margin-left: 2em">先得之弦即半之<sub class="note-yuan">適足一象限故</sub>得三六六〇七爲次得之</span>  
<span style="margin-left: 2em">弦次求甲乙丙角之倒弦<sub class="note-yuan">即己辛弧之弦</sub>一九六三〇一<sub class="note-yuan">首一</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">者己戊全弦也</sub>爲後得之弦依三率法以乘次得之三六六</span>  
<span style="margin-left: 2em">〇七得七一八五九爲他弦以減先得之七三二一</span>  
<span style="margin-left: 2em">五餘一三五六爲甲丙弧之餘弦即甲丁弧之正弦</span>  
<span style="margin-left: 2em">爲本星距赤道圈緯度<sub class="note-jiao">校：法圖本無圈字</sub>四十六分三十五</span>  
<span style="margin-left: 2em">秒</span>  
<span style="margin-left: 2em">若三角形內之總弧過一象限<sub class="note-jiao">校：法圖本無之字</sub>即次得之</span>  
<span style="margin-left: 2em">弦非折半可得法以大弧之餘弧減小弧所存求其</span>  
<span style="margin-left: 2em">弦以加于先得之總弦半之爲次得之弦其後得者</span>  
<span style="margin-left: 2em">甲乙丙角之倒弦依前用三率法但所求得之他弦</span>  
<span style="margin-left: 2em">若小于先得之弦其法同前若等則所求三角形內</span>  
<span style="margin-left: 2em">第三弧之弦正爲九十度之弦而星必在赤道上無</span>  
<span style="margin-left: 2em">距度若他弦大于先得之弦則以小弦減大弦<sub class="note-yuan">不論何弦</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">但以小減大</sub>餘爲本星距赤道之弦假如畢宿大星于崇</span>  
<span style="margin-left: 7em">禎元年距黃道南五度三十一分在甲</span>  
<span style="margin-left: 7em">其黃道經度爲辛戊六十四度三十五</span>  
<span style="margin-left: 7em">分三十秒即甲乙爲大弧八十四度二</span>  
<span style="margin-left: 7em">十九分乙丙爲小弧二十三度三十一</span>  
<span style="margin-left: 2em">分三十秒<sub class="note-yuan">兩極之距度</sub>兩弧所包甲乙丙角一百五十四</span>  
<span style="margin-left: 2em">度三十五分三十秒依法以大弧甲乙之餘弧甲戊</span>  
<span style="margin-left: 2em">五度三十一分加于小弧乙丙二十三度三十一分</span>  
<span style="margin-left: 2em">三十秒共得二十九度〇二分三十秒求其弦四八</span>  
<span style="margin-left: 2em">五四四爲先得之總弦又以餘弧甲戊減小弧乙丙</span>  
<span style="margin-left: 2em">存一十八度〇分三十秒<sub class="note-jiao">校：法圖本作一十八度〇〇三十秒</sub>其弦三</span>  
<span style="margin-left: 2em">〇九一五以加先得之總弦四八五四四得七九四</span>  
<span style="margin-left: 2em">五九然後半之得三九七二九爲次得之弦其後得</span>  
<span style="margin-left: 2em">者甲乙丙角之倒弦一九〇三二八依三率法以乘</span>  
<span style="margin-left: 2em">次得之三九七二九得他弦七五六一四因他弦大</span>  
<span style="margin-left: 2em">于先得之弦故于他弦內減先得之四八五四四存</span>  
<span style="margin-left: 2em">二七〇七〇<sub class="note-jiao">校：法圖本作二七一七〇</sub>查得十五度四十二分<sub class="note-jiao">校：法</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">圖本作十五度四十六分</sub>爲甲庚弧是本星距赤道之度</span>  
<span style="margin-left: 2em">若總弧不及一象限則如前求先得之總弦次以小</span>  
<span style="margin-left: 2em">弧減大弧之餘弧所存查其正弦又以減先得之弦</span>  
<span style="margin-left: 2em">所存半之爲次得之弦其餘同前第一法</span>  
<span style="margin-left: 1em">假如崇禎元年大角星距黃道北三十一度〇二分三</span>  
<span style="margin-left: 6em">十〇秒其經度過秋分一十九度〇二分</span>  
<span style="margin-left: 6em">三十〇秒其兩弧間之角甲乙丙得一百</span>

<span style="margin-left: 2em">小弧二十三度三十一分三十秒今大弧之餘弧甲</span>

<span style="margin-left: 2em">五十四秒</span>  
<span style="margin-left: 3em">求赤道緯度後法<sub class="note-yuan">即第三法</sub></span>  
<span style="margin-left: 1em">後法用簡平儀或量度或加減推算<sub class="note-yuan">簡平儀者以圓平面當渾儀也圓平</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">面者以極至交圈爲界作過心平面也以面當球與平渾儀同意論球則半在面前可見今以直線當弧</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">半在面後不可見其直線當弧與前半同理下文言某線爲某弧或言前弧後弧等俱本此</sub>量度</span>  
<span style="margin-left: 2em">者用規器量度所有之見度分即於分度等圈上量</span>  
<span style="margin-left: 2em">取所求之隱度分也加減者亦於本儀取數其算法</span>

<span style="margin-left: 2em">冬至星距黃道南則寅爲夏至辛爲冬至今所測星</span>  
<span style="margin-left: 7em">爲乙癸甲線爲星之黃道緯度對丙辛</span>

<span style="margin-left: 2em">則先定黃道緯度之丙辛弧經度之辰卯弧從經緯</span>
