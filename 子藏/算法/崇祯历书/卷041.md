<span style="margin-left: 2em">界说<sub class="note-jiao">校：清刊本此前有測量全義四卷標題</sub></span>  
<span style="margin-left: 2em">第一界</span>  
<span style="margin-left: 1em">面者有长有广</span>  
<span style="margin-left: 2em">第二界</span>  
<span style="margin-left: 1em">平面者一面平</span>  
<span style="margin-left: 2em">第三界</span>  
<span style="margin-left: 1em">曲面者一面曲</span>  
<span style="margin-left: 2em">无界者如球卵之面有界者如窑桥之面</span>  
<span style="margin-left: 2em">第四界</span>  
<span style="margin-left: 1em">一界之面</span>  
<span style="margin-left: 11em">一曲线内之形如圆形在圈</span>  
<span style="margin-left: 11em">界之内凡有三一平圆从心</span>  
<span style="margin-left: 11em">至界各线俱等一椭圆如圆</span>  
<span style="margin-left: 2em">柱而斜剡之得两面焉一无法曲线如桃梨之面</span>  
<span style="margin-left: 2em">第五界</span>  
<span style="margin-left: 1em">二界之面</span>  
<span style="margin-left: 9em">如两弧或无法之曲线或一直线</span>  
<span style="margin-left: 9em">一曲线而形之有法与否则视曲</span>  
<span style="margin-left: 9em">线</span>  
<span style="margin-left: 2em">第六界</span>  
<span style="margin-left: 1em">三界之面</span>  
<span style="margin-left: 2em">三边或直或曲以曲线为边者先定曲线之有法与</span>  
<span style="margin-left: 2em">否面因之量与二界同法以直线为本</span>  
<span style="margin-left: 6em">如丙丁戊曲边形从丙角至丁作丙丁直</span>  
<span style="margin-left: 6em">线成丙乙丁两角襍形从丙至戊从戊至</span>  
<span style="margin-left: 6em">丁亦如之细分元形各依法量之用所得</span>  
<span style="margin-left: 6em">或加或减以得其容凡三边形或俱等或</span>  
<span style="margin-left: 6em">俱不等或两边等或有直角或无直角皆</span>  
<span style="margin-left: 6em">有法之形也</span>  
<span style="margin-left: 2em">第七界</span>  
<span style="margin-left: 1em">四界之面</span>  
<span style="margin-left: 2em">方面有五边角俱等者正方也角等边不等者长方</span>  
<span style="margin-left: 2em">也边等角不等者斜方也各对角对边等者长斜方</span>  
<span style="margin-left: 12em">也边角俱不等者无法之</span>  
<span style="margin-left: 12em">方也首两种之外皆属无</span>  
<span style="margin-left: 12em">法盖有设边无设角或大</span>  
<span style="margin-left: 2em">或小容积因之异焉欲求其容须定角之度或中长</span>  
<span style="margin-left: 2em">线也</span>  
<span style="margin-left: 2em">第八界</span>  
<span style="margin-left: 8em">五以上多界之面</span>  
<span style="margin-left: 8em">边角俱等者有法之形也或边或角</span>  
<span style="margin-left: 8em">不等者皆无法之形也</span>  
<span style="margin-left: 2em">第九界</span>  
<span style="margin-left: 1em">定度者求两物之比例</span>  
<span style="margin-left: 2em">凡量度万形先定一有几何之度如三丈之物以一</span>  
<span style="margin-left: 2em">丈之度量之谓之某物与定度为三倍大则一丈之</span>  
<span style="margin-left: 2em">度名曰公度因其能量之势定各所量之物也凡量</span>  
<span style="margin-left: 2em">高长广远皆属线类则以线为公度盖比例之两率</span>  
<span style="margin-left: 2em">为同类也故量线者先具一定线或一丈或一尺以</span>  
<span style="margin-left: 2em">为公度量面者先具一定面或方步或方丈边等角</span>  
<span style="margin-left: 2em">直以为公度量线用直线以直线在万线中为最短</span>  
<span style="margin-left: 2em">故量面用平面用正方以平面在万面中为最短正</span>  
<span style="margin-left: 2em">方之理视万形之理为最准故<sub class="note-yuan">量体亦定一度如一石斗为六面体各面</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">等各角及边等</sub></span>  
<span style="margin-left: 2em">第十界</span>  
<span style="margin-left: 1em">量算</span>  
<span style="margin-left: 2em">丈尺寸分满十进位亩法步法则否二百四十方步</span>  
<span style="margin-left: 2em">为亩二十五方尺为步一百方寸复为尺也凡若干</span>  
<span style="margin-left: 2em">步之积步约为亩以二百四十方步而一若干尺之</span>  
<span style="margin-left: 2em">积约为步以二十五方尺而一若干寸之积约为尺</span>  
<span style="margin-left: 2em">以一百方寸而一约步约亩则递以步法亩法除之</span>  
<span style="margin-left: 2em">第十一界</span>  
<span style="margin-left: 1em">中垂线</span>  
<span style="margin-left: 2em">从形心至边作直角者为中垂线有法形之各中垂</span>  
<span style="margin-left: 2em">线必等无法形各边不等中垂线亦不等</span>  
<span style="margin-left: 2em">第十二界</span>  
<span style="margin-left: 1em">中长线</span>  
<span style="margin-left: 2em">从形之一边或一角至对边作垂线是各边上极远</span>  
<span style="margin-left: 2em">之线以得本形中之直角三边形</span>  
<span style="margin-left: 2em">第十三界</span>  
<span style="margin-left: 1em">直线为有法形之径</span>  
<span style="margin-left: 2em">直线形本无径聊借圆形之径名之然有法之形周</span>  
<span style="margin-left: 2em">内周外可作全圈在外者形之各边切圈周在内者</span>  
<span style="margin-left: 2em">各用切圈周故圈之径亦可谓容形之径</span>  
<span style="margin-left: 1em">测量全义第四卷　测面上</span>  
<span style="margin-left: 2em">第一题</span>  
<span style="margin-left: 1em">量四边形<sub class="note-yuan">其法有三</sub></span>  
<span style="margin-left: 2em">形之类有二有直线有曲线兹先解直线形若曲线</span>  
<span style="margin-left: 6em">形后方详之</span>  
<span style="margin-left: 6em">公量为方有法之方形二有正方四边四</span>  
<span style="margin-left: 6em">角俱等<sub class="note-yuan">直角也</sub>以所设一边自之得面之容</span>  
<span style="margin-left: 2em">如正方田一段各边四步自之其容为十六方步有</span>  
<span style="margin-left: 2em">长方以所设两边相乘得面之容如长方田一段纵</span>  
<span style="margin-left: 2em">五横六相乘其容为三十方步</span>  
<span style="margin-left: 6em">若斜方具边无角亦无法之类也有中长</span>  
<span style="margin-left: 6em">线之数则以底数乘之得斜方之容若无</span>  
<span style="margin-left: 6em">中长线之数而知一角之数则先以角求</span>  
<span style="margin-left: 6em">中长线如乙丁斜方形有长濶若干有丁</span>  
<span style="margin-left: 6em">角之数即从丙钝角作丙甲垂线<sub class="note-yuan">即中长线</sub>则</span>  
<span style="margin-left: 6em">丙丁甲直角形有丙丁边丁角依法求丙</span>  
<span style="margin-left: 6em">甲得数以乘乙丙得元形之容</span>  
<span style="margin-left: 9em">若等边斜方形作两对角线分元</span>  
<span style="margin-left: 9em">形为四句股形两对角线之交为</span>  
<span style="margin-left: 9em">直法法以两对角线相乘二而一</span>  
<span style="margin-left: 2em">四边形有上下不等而在平行线内者名梯田旧法</span>  
<span style="margin-left: 6em">并两广半之以中长线乘之　论曰戊己</span>  
<span style="margin-left: 6em">丁丙形从上广之两界己戊作己甲戊乙</span>  
<span style="margin-left: 6em">两垂线<sub class="note-yuan">即中长线</sub>中成长方形旁有两句股形</span>  
<span style="margin-left: 6em">次引戊己广至庚得庚己与乙丙等成己</span>  
<span style="margin-left: 2em">庚丁句股形与丙乙戊形等则庚乙方形与梯田形</span>  
<span style="margin-left: 2em">等丙乙甲丁为两广之较半之者损下广以益上广</span>  
<span style="margin-left: 2em">也兹旧法所自出也</span>  
<span style="margin-left: 2em">凡斜田箕田诸法俱同前两腰之等与不等角之等</span>  
<span style="margin-left: 6em">与不等俱以平行线为本若不知中长线</span>  
<span style="margin-left: 6em">而知斜边或一角者如下文</span>  
<span style="margin-left: 6em">知斜边如丁己先分形成甲丁己直角形</span>  
<span style="margin-left: 6em">有甲丁为两广之半较有己丁弦法以两</span>  
<span style="margin-left: 2em">数自之相减开方得己甲中长线</span>  
<span style="margin-left: 2em">知角者如己甲丁形有甲丁边有丁角或己角求己</span>  
<span style="margin-left: 2em">甲即全数与丁角之切线若丁甲边与己甲边</span>  
<span style="margin-left: 2em">旧法曰一面长乘中濶得形之容驳曰中广必垂线</span>  
<span style="margin-left: 10em">乃准垂线而外皆斜线必长于</span>  
<span style="margin-left: 10em">中长线况斜边乎今设两形之</span>  
<span style="margin-left: 10em">同边异积如上图其理易见</span>  
<span style="margin-left: 2em">二不等田东长三十六西长三十北广二十五无南</span>  
<span style="margin-left: 6em">广问田旧法并两长折半乘北广</span>  
<span style="margin-left: 6em">驳曰若北两皆直角者即梯田之类也否</span>  
<span style="margin-left: 6em">则从何定南广之度乎</span>  
<span style="margin-left: 2em">旧法四不等田北四十二南五十六东六十四西五</span>  
<span style="margin-left: 6em">十八并东西两边半之并南北两边亦半</span>  
<span style="margin-left: 6em">之两半相乘得二九八九步为其容</span>  
<span style="margin-left: 6em">驳曰若甲为直角试作乙丁对直角线成</span>  
<span style="margin-left: 6em">甲乙丁句股形有句股以求弦为七十六</span>  
<span style="margin-left: 2em">又一五三之九四其积为一三四四又以乙丙丁形</span>  
<span style="margin-left: 2em">之三边求其容得一五三七<sub class="note-yuan">此法见后第三题</sub>并两形积得</span>  
<span style="margin-left: 2em">二八七一知法为未合也</span>  
<span style="margin-left: 2em">论曰两广或两长在平行线内者并而折半损有余</span>  
<span style="margin-left: 2em">补不足改为方形也以中长线乘之则得其容若四</span>  
<span style="margin-left: 2em">不等无法形也损此益彼一不能为方一不能为中</span>  
<span style="margin-left: 2em">长线何缘得合乎</span>  
<span style="margin-left: 2em">第二题</span>  
<span style="margin-left: 1em">量三边形</span>  
<span style="margin-left: 5em">乙丙丁三边形有边数无角数求实其法并</span>  
<span style="margin-left: 5em">三边数半之为实以每边之数为法各减之</span>  
<span style="margin-left: 5em">三较连乘得数以半总数乘之为实平方开</span>  
<span style="margin-left: 2em">之得实</span>  
<span style="margin-left: 2em">如三边为七为十二为九并得二十八半之为一十</span>  
<span style="margin-left: 2em">四减七较七减十二较二减九较五三较连乘得七</span>  
<span style="margin-left: 2em">十以半总十四乘之得九百八十〇开方得三十一</span>  
<span style="margin-left: 2em">又六十二之一十九不尽</span>  
<span style="margin-left: 2em">又如三边为十三十八二十一并得五十二半之为</span>  
<span style="margin-left: 5em">二十六减十三较十三减十八较八减二十</span>  
<span style="margin-left: 5em">一较五三较连乘得五百二十〇以半总数</span>  
<span style="margin-left: 5em">二十六乘之得一万三千六百二十〇开方</span>  
<span style="margin-left: 2em">得一百一十六又二三二七之一六四不尽</span>  
<span style="margin-left: 2em">解曰如图乙丙丁斜角形先平分丙丁二角作丙戊</span>  
<span style="margin-left: 2em">丁戊二线遇于戊从戊向各边作垂线为戊壬戊己</span>  
<span style="margin-left: 2em">戊庚三线皆等<sub class="note-yuan">戊壬丙戊己丙两直角形同用戊丙边两丙角亦等形必等则戊己戊壬</sub></span>  
<span style="margin-left: 10em"><sub class="note-yuan">亦等又壬戊丁丁戊庚两直角形同用戊丁边两丁角亦等形</sub></span>  
<span style="margin-left: 10em"><sub class="note-yuan">必等则壬戊戊庚亦等</sub></span>  
<span style="margin-left: 10em">次从乙作乙戊平分乙角乙戊</span>  
<span style="margin-left: 10em">己乙戊庚两直角形有己戊戊</span>  
<span style="margin-left: 10em">庚两边等同用乙戊边形必等</span>  
<span style="margin-left: 10em">则两乙角亦等依三角形推壬</span>  
<span style="margin-left: 2em">丙与丙己己乙与乙庚庚丁与丁壬各等共六线三</span>  
<span style="margin-left: 2em">等次于三相等边各取一边如乙己己丙壬丁合之</span>  
<span style="margin-left: 2em">为元形三边并之半<sub class="note-yuan">或丁庚庚乙壬丙或每相等两形边减一边得三较亦元形三</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">边并之半</sub>次乙丙边引长之取丙辛与丁壬等乙丁边引</span>  
<span style="margin-left: 2em">长之取丁癸与己丙等则乙辛乙癸皆元形三边并</span>  
<span style="margin-left: 2em">之半亦三较之总数也次从辛从癸作两垂线遇于</span>  
<span style="margin-left: 2em">子乙戊引长之亦与辛子癸子遇于子<sub class="note-yuan">乙癸子乙辛子两直角形</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">之乙癸乙辛两边等两乙角亦等即乙子弦必等而辛子子癸亦等</sub>次截丙午与壬丁</span>

<span style="margin-left: 8em">若形之边为断几何如圆果平积之</span>  
<span style="margin-left: 8em">边其法以边数自之又加边数半之</span>  
<span style="margin-left: 8em">为形之积假如各边有三自之得九</span>  
<span style="margin-left: 3em">加边得十二半之得六形积也又如设边五自之</span>  
<span style="margin-left: 3em">得二十五加边三十半之得十五积也见算</span>  
<span style="margin-left: 3em">章递加法</span>  
<span style="margin-left: 2em">第三题</span>  
<span style="margin-left: 1em">量多边形</span>  
<span style="margin-left: 2em">一解曰有法多边形求其容必先分元形皆为两边</span>  
<span style="margin-left: 2em">等三角形故不论几何边俱同法</span>  
<span style="margin-left: 2em">法曰多边形从心至各角作线悉分为两边等三角</span>  
<span style="margin-left: 2em">形各形有边数有角数求其中长线得各三角形之</span>  
<span style="margin-left: 2em">容并之得元形之容</span>  
<span style="margin-left: 7em">如八边边设十步从心至角作线辏心</span>  
<span style="margin-left: 7em">成八角皆等凡辏心必四直角分三百</span>  
<span style="margin-left: 7em">六十度八而一每角得四十五度乙丙</span>  
<span style="margin-left: 7em">丁角形二边等有丁丙底有丁乙丙角</span>  
<span style="margin-left: 2em">则丁丙两角并得一百三十五度半之得六十七度</span>  
<span style="margin-left: 2em">又二之一为乙丁丙角又甲乙丁角形有丁甲<sub class="note-yuan">半元边为</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">五</sub>求甲乙垂线即全数<sub class="note-yuan">内</sub>与丁甲<sub class="note-yuan">五外</sub>若丁角之切线</span>  
<span style="margin-left: 2em"><sub class="note-yuan">二四一四二一内</sub>与甲乙边<sub class="note-yuan">一二〇七一〇五外</sub>约之得十二步有奇</span>  
<span style="margin-left: 2em">以乘甲丁五步得六二三五五二五约六十步有奇</span>  
<span style="margin-left: 2em">八之得四八八四二四〇〇约得四百八十八步有</span>  
<span style="margin-left: 2em">奇为元形之容</span>  
<span style="margin-left: 2em">若有中长线如甲戊以其半乘半周所得与前等</span>  
<span style="margin-left: 2em">又如十二边有法形边设十步以十二除三百六十</span>  
<span style="margin-left: 2em">度得三十度为丙乙丁角即乙丁丙角必七十五度</span>  
<span style="margin-left: 2em">从心作乙甲线至丁丙边又甲乙丁角形有甲丁五</span>  
<span style="margin-left: 2em">步有丁角七十五度求甲乙线即全数<sub class="note-yuan">内</sub>与甲乙<sub class="note-yuan">五外</sub></span>  
<span style="margin-left: 2em">若丁角之切线<sub class="note-yuan">三七三二〇五内</sub>与甲乙<sub class="note-yuan">八一八六六〇二五外</sub>约得</span>  
<span style="margin-left: 2em">十八步有奇甲乙中垂线也次如前</span>  
<span style="margin-left: 6em">或用正弦数法曰各边为本弧之弦即半</span>  
<span style="margin-left: 6em">边为半弧之正弦而中垂线为半弧之余</span>  
<span style="margin-left: 6em">弦以边数除三百六十得设边之弧边数</span>  
<span style="margin-left: 6em">及弧度各半之次用半弧度求其正弦及</span>  
<span style="margin-left: 2em">余弦末用三率法以半弧之正弦为第一半边数为</span>  
<span style="margin-left: 2em">第二余弦数为第三得第四为正垂线即乙甲</span>  
<span style="margin-left: 2em">如五边等形边设十二以五除三百六十得七十二</span>  
<span style="margin-left: 2em">半之得三十六其正弦五八七七九为一率<sub class="note-yuan">内</sub>其余</span>  
<span style="margin-left: 2em">弦八〇九〇二为三率<sub class="note-yuan">内</sub>半边六为二率<sub class="note-yuan">外</sub>得九又</span>  
<span style="margin-left: 2em">九之一为四率<sub class="note-yuan">外</sub>即一边上之垂线次以形周乘四</span>  
<span style="margin-left: 2em">率得数半之为形之积五边形之周为六十乘得五</span>  
<span style="margin-left: 2em">四六又九之四为五边形之并积</span>  
<span style="margin-left: 2em">多边有法形之比例　多边有法形之具三曰边曰</span>  
<span style="margin-left: 2em">周曰积形大小不等其比例等故有一形某具之比</span>  
<span style="margin-left: 2em">例可得他形某具之比例</span>  
<span style="margin-left: 2em">每形之边为一<sub class="note-yuan">一虚数也丈尺寸分唯所设之</sub></span>  
<span style="margin-left: 3em">三边形之周三积为三十之十三</span>  
<span style="margin-left: 3em">四边形之周四积为一</span>  
<span style="margin-left: 3em">五边之周五积为一又一一七七五七〇六之八</span>  
<span style="margin-left: 3em">四六九七一九约为十一之八不尽</span>  
<span style="margin-left: 3em">六边形之周六积为二又五百万之二九九〇三</span>  
<span style="margin-left: 3em">八一约为五之三不足</span>  
<span style="margin-left: 3em">七边形之周七积为三又八六七七六七四之五</span>  
<span style="margin-left: 3em">五〇七二二一约为八之一而盈</span>  
<span style="margin-left: 3em">八边形之周八积为四又一九一三四一七之一</span>  
<span style="margin-left: 3em">五八五一二七约为十九之十六不足</span>  
<span style="margin-left: 3em">九边形之周九积为六又六八四〇四〇二之一</span>  
<span style="margin-left: 3em">二四三七五五约为十七之三不尽</span>  
<span style="margin-left: 3em">十边形之周十积为七又一二三六〇六八之八</span>  
<span style="margin-left: 3em">五八〇八九约为三之二不足</span>  
<span style="margin-left: 2em">用法设他形之边求积以其边数自之以上所列同</span>  
<span style="margin-left: 2em">类形之积数乘之若设他形之积求边则上所列同</span>  
<span style="margin-left: 2em">类形之积数除之所得之根设形之边也</span>  
<span style="margin-left: 6em">旧法三角形每面十四以六乘面得八十</span>  
<span style="margin-left: 6em">四以七而一得十二为实半面七为法乘</span>  
<span style="margin-left: 6em">之得八四积也试用前法分元形作两句</span>  
<span style="margin-left: 2em">股形各形有弦有句以求股而求积得八四又三十</span>  
<span style="margin-left: 2em">之二十八几为八五非八四</span>  
<span style="margin-left: 2em">论曰所以然者古法正六面七谓丙乙十四则丙甲</span>  
<span style="margin-left: 2em">十二故七六相乘得四十二为丙乙丁之实八十四</span>  
<span style="margin-left: 2em">矣不知丙乙十四乙甲七各自之相减开方乃十二</span>  
<span style="margin-left: 2em">有奇非十二也且七除又七乘安用之</span>  
<span style="margin-left: 2em">旧法六角形每面十五以面数自之得二二五以三</span>  
<span style="margin-left: 6em">乘之得六七五今用几何四卷十五之系</span>  
<span style="margin-left: 6em">六边等形内有三角等边形六用古法得</span>  
<span style="margin-left: 6em">各形之积为九十六又七之六六因之得</span>  
<span style="margin-left: 2em">五九一又七之一非六七五</span>  
<span style="margin-left: 2em">论曰所以然者十五自之为二二五彼以为此乙丙</span>  
<span style="margin-left: 2em">边乘得乙丙丁戊形之实也不知二二五者乙丙上</span>  
<span style="margin-left: 2em">正方形之实此乙丙丁戊则斜方斜方与正方同边</span>  
<span style="margin-left: 2em">而异积也斜方之积必少于正方之积故实少而误</span>  
<span style="margin-left: 2em">以为多</span>  
<span style="margin-left: 2em">古法八角田每面十四以面五乘得七十七而一得</span>  
<span style="margin-left: 2em">十倍之得二十求一面得三十四自之得一一五六</span>  
<span style="margin-left: 2em">为实面数自之得一九六为法减之余九六〇八角</span>  
<span style="margin-left: 2em">形积也正法作图每两边引长之遇于甲成正方形</span>  
<span style="margin-left: 6em">其内有元八边形又有甲乙丙四句股形</span>  
<span style="margin-left: 6em">以丙乙元形边十四为弦求丙甲而句股</span>  
<span style="margin-left: 6em">等法以弦十四自之得一九六半</span>  
<span style="margin-left: 2em">之得九八开方为九又十九之十七甲乙也甲乙甲</span>  
<span style="margin-left: 2em">丁等合之加于乙丁元形之边得三十二又十九之</span>  
<span style="margin-left: 2em">十七为甲甲正方之边自之得一一四又三六一之</span>  
<span style="margin-left: 2em">二二五正方之积也次求句股四形之积得一九六</span>  
<span style="margin-left: 2em">弱以减正方积余九四四有奇元八角形之积也古</span>  
<span style="margin-left: 2em">法曰九六〇谬矣</span>  
<span style="margin-left: 2em">论曰所以然者古法方五斜七不知方五则斜七有</span>  
<span style="margin-left: 2em">奇不发之根也彼以甲乙等各句各股俱为十则乙</span>  
<span style="margin-left: 2em">丙边与乙丙弦俱十四不知各率皆是而独乙丙弦</span>  
<span style="margin-left: 2em">非十四也故八角形之积实少而误以为多</span>
