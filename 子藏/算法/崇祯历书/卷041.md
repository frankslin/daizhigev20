## 崇禎曆書卷之四十一　測量全義卷四

<span style="margin-left: 1em">法原部<sub class="note-jiao">校：法圖本存雙署名葉版式與比皇圖本奎章閣本均異又誤作湯若望爲湯如望顯然錯版</sub></span>

<span style="margin-left: 1em"><sub class="note-yuan">　羅雅谷　譔　　修政曆法極西耶穌會士門人祝懋元　劉有慶　受法　　　　　　　　　　　湯若望訂</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">　　　　　　　　　　　　　　　　　　　　孫嗣烈左允和</sub></span>  
<span style="margin-left: 2em">界說<sub class="note-jiao">校：清刊本此前有測量全義四卷標題</sub></span>  
<span style="margin-left: 2em">第一界</span>  
<span style="margin-left: 1em">面者有長有廣</span>  
<span style="margin-left: 2em">第二界</span>  
<span style="margin-left: 1em">平面者一面平</span>  
<span style="margin-left: 2em">第三界</span>  
<span style="margin-left: 1em">曲面者一面曲</span>  
<span style="margin-left: 2em">無界者如球卵之面有界者如窑橋之面</span>  
<span style="margin-left: 2em">第四界</span>  
<span style="margin-left: 1em">一界之面</span>  
<span style="margin-left: 11em">一曲線內之形如圓形在圈</span>  
<span style="margin-left: 11em">界之內凡有三一平圓從心</span>  
<span style="margin-left: 11em">至界各線俱等一橢圓如圓</span>  
<span style="margin-left: 2em">柱而斜剡之得兩面焉一無法曲線如桃梨之面</span>  
<span style="margin-left: 2em">第五界</span>  
<span style="margin-left: 1em">二界之面</span>  
<span style="margin-left: 9em">如兩弧或無法之曲線或一直線</span>  
<span style="margin-left: 9em">一曲線而形之有法與否則視曲</span>  
<span style="margin-left: 9em">線</span>  
<span style="margin-left: 2em">第六界</span>  
<span style="margin-left: 1em">三界之面</span>  
<span style="margin-left: 2em">三邊或直或曲以曲線爲邊者先定曲線之有法與</span>  
<span style="margin-left: 2em">否面因之量與二界同法以直線爲本</span>  
<span style="margin-left: 6em">如丙丁戊曲邊形從丙角至丁作丙丁直</span>  
<span style="margin-left: 6em">線成丙乙丁兩角襍形從丙至戊從戊至</span>  
<span style="margin-left: 6em">丁亦如之細分元形各依法量之用所得</span>  
<span style="margin-left: 6em">或加或減以得其容凡三邊形或俱等或</span>  
<span style="margin-left: 6em">俱不等或兩邊等或有直角或無直角皆</span>  
<span style="margin-left: 6em">有法之形也</span>  
<span style="margin-left: 2em">第七界</span>  
<span style="margin-left: 1em">四界之面</span>  
<span style="margin-left: 2em">方面有五邊角俱等者正方也角等邊不等者長方</span>  
<span style="margin-left: 2em">也邊等角不等者斜方也各對角對邊等者長斜方</span>  
<span style="margin-left: 12em">也邊角俱不等者無法之</span>  
<span style="margin-left: 12em">方也首兩種之外皆屬無</span>  
<span style="margin-left: 12em">法蓋有設邊無設角或大</span>  
<span style="margin-left: 2em">或小容積因之異焉欲求其容須定角之度或中長</span>  
<span style="margin-left: 2em">線也</span>  
<span style="margin-left: 2em">第八界</span>  
<span style="margin-left: 8em">五以上多界之面</span>  
<span style="margin-left: 8em">邊角俱等者有法之形也或邊或角</span>  
<span style="margin-left: 8em">不等者皆無法之形也</span>  
<span style="margin-left: 2em">第九界</span>  
<span style="margin-left: 1em">定度者求兩物之比例</span>  
<span style="margin-left: 2em">凡量度萬形先定一有幾何之度如三丈之物以一</span>  
<span style="margin-left: 2em">丈之度量之謂之某物與定度爲三倍大則一丈之</span>  
<span style="margin-left: 2em">度名曰公度因其能量之勢定各所量之物也凡量</span>  
<span style="margin-left: 2em">高長廣遠皆屬線類則以線爲公度蓋比例之兩率</span>  
<span style="margin-left: 2em">爲同類也故量線者先具一定線或一丈或一尺以</span>  
<span style="margin-left: 2em">爲公度量面者先具一定面或方步或方丈邊等角</span>  
<span style="margin-left: 2em">直以爲公度量線用直線以直線在萬線中爲最短</span>  
<span style="margin-left: 2em">故量面用平面用正方以平面在萬面中爲最短正</span>  
<span style="margin-left: 2em">方之理視萬形之理爲最準故<sub class="note-yuan">量體亦定一度如一石斗爲六面體各面</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">等各角及邊等</sub></span>  
<span style="margin-left: 2em">第十界</span>  
<span style="margin-left: 1em">量算</span>  
<span style="margin-left: 2em">丈尺寸分滿十進位畝法步法則否二百四十方步</span>  
<span style="margin-left: 2em">爲畝二十五方尺爲步一百方寸復爲尺也凡若干</span>  
<span style="margin-left: 2em">步之積步約爲畝以二百四十方步而一若干尺之</span>  
<span style="margin-left: 2em">積約爲步以二十五方尺而一若干寸之積約爲尺</span>  
<span style="margin-left: 2em">以一百方寸而一約步約畝則遞以步法畝法除之</span>  
<span style="margin-left: 2em">第十一界</span>  
<span style="margin-left: 1em">中垂線</span>  
<span style="margin-left: 2em">從形心至邊作直角者爲中垂線有法形之各中垂</span>  
<span style="margin-left: 2em">線必等無法形各邊不等中垂線亦不等</span>  
<span style="margin-left: 2em">第十二界</span>  
<span style="margin-left: 1em">中長線</span>  
<span style="margin-left: 2em">從形之一邊或一角至對邊作垂線是各邊上極遠</span>  
<span style="margin-left: 2em">之線以得本形中之直角三邊形</span>  
<span style="margin-left: 2em">第十三界</span>  
<span style="margin-left: 1em">直線爲有法形之徑</span>  
<span style="margin-left: 2em">直線形本無徑聊借圓形之徑名之然有法之形周</span>  
<span style="margin-left: 2em">內周外可作全圈在外者形之各邊切圈周在內者</span>  
<span style="margin-left: 2em">各用切圈周故圈之徑亦可謂容形之徑</span>  
<span style="margin-left: 1em">測量全義第四卷　測面上</span>  
<span style="margin-left: 2em">第一題</span>  
<span style="margin-left: 1em">量四邊形<sub class="note-yuan">其法有三</sub></span>  
<span style="margin-left: 2em">形之類有二有直線有曲線兹先解直線形若曲線</span>  
<span style="margin-left: 6em">形後方詳之</span>  
<span style="margin-left: 6em">公量爲方有法之方形二有正方四邊四</span>  
<span style="margin-left: 6em">角俱等<sub class="note-yuan">直角也</sub>以所設一邊自之得面之容</span>  
<span style="margin-left: 2em">如正方田一段各邊四步自之其容爲十六方步有</span>  
<span style="margin-left: 2em">長方以所設兩邊相乘得面之容如長方田一段縱</span>  
<span style="margin-left: 2em">五横六相乘其容爲三十方步</span>  
<span style="margin-left: 6em">若斜方具邊無角亦無法之類也有中長</span>  
<span style="margin-left: 6em">線之數則以底數乘之得斜方之容若無</span>  
<span style="margin-left: 6em">中長線之數而知一角之數則先以角求</span>  
<span style="margin-left: 6em">中長線如乙丁斜方形有長濶若干有丁</span>  
<span style="margin-left: 6em">角之數即從丙鈍角作丙甲垂線<sub class="note-yuan">即中長線</sub>則</span>  
<span style="margin-left: 6em">丙丁甲直角形有丙丁邊丁角依法求丙</span>  
<span style="margin-left: 6em">甲得數以乘乙丙得元形之容</span>  
<span style="margin-left: 9em">若等邊斜方形作兩對角線分元</span>  
<span style="margin-left: 9em">形爲四句股形兩對角線之交爲</span>  
<span style="margin-left: 9em">直法法以兩對角線相乘二而一</span>  
<span style="margin-left: 2em">四邊形有上下不等而在平行線內者名梯田舊法</span>  
<span style="margin-left: 6em">并兩廣半之以中長線乘之　論曰戊己</span>  
<span style="margin-left: 6em">丁丙形從上廣之兩界己戊作己甲戊乙</span>  
<span style="margin-left: 6em">兩垂線<sub class="note-yuan">即中長線</sub>中成長方形旁有兩句股形</span>  
<span style="margin-left: 6em">次引戊己廣至庚得庚己與乙丙等成己</span>  
<span style="margin-left: 2em">庚丁句股形與丙乙戊形等則庚乙方形與梯田形</span>  
<span style="margin-left: 2em">等丙乙甲丁爲兩廣之較半之者損下廣以益上廣</span>  
<span style="margin-left: 2em">也兹舊法所自出也</span>  
<span style="margin-left: 2em">凡斜田箕田諸法俱同前兩腰之等與不等角之等</span>  
<span style="margin-left: 6em">與不等俱以平行線爲本若不知中長線</span>  
<span style="margin-left: 6em">而知斜邊或一角者如下文</span>  
<span style="margin-left: 6em">知斜邊如丁己先分形成甲丁己直角形</span>  
<span style="margin-left: 6em">有甲丁爲兩廣之半較有己丁弦法以兩</span>  
<span style="margin-left: 2em">數自之相減開方得己甲中長線</span>  
<span style="margin-left: 2em">知角者如己甲丁形有甲丁邊有丁角或己角求己</span>  
<span style="margin-left: 2em">甲即全數與丁角之切線若丁甲邊與己甲邊</span>  
<span style="margin-left: 2em">舊法曰一面長乘中濶得形之容駁曰中廣必垂線</span>  
<span style="margin-left: 10em">乃准垂線而外皆斜線必長于</span>  
<span style="margin-left: 10em">中長線况斜邊乎今設兩形之</span>  
<span style="margin-left: 10em">同邊異積如上圖其理易見</span>  
<span style="margin-left: 2em">二不等田東長三十六西長三十北廣二十五無南</span>  
<span style="margin-left: 6em">廣問田舊法并兩長折半乘北廣</span>  
<span style="margin-left: 6em">駁曰若北兩皆直角者即梯田之類也否</span>  
<span style="margin-left: 6em">則從何定南廣之度乎</span>  
<span style="margin-left: 2em">舊法四不等田北四十二南五十六東六十四西五</span>  
<span style="margin-left: 6em">十八并東西兩邊半之并南北兩邊亦半</span>  
<span style="margin-left: 6em">之兩半相乘得二九八九步爲其容</span>  
<span style="margin-left: 6em">駁曰若甲爲直角試作乙丁對直角線成</span>  
<span style="margin-left: 6em">甲乙丁句股形有句股以求弦爲七十六</span>  
<span style="margin-left: 2em">又一五三之九四其積爲一三四四又以乙丙丁形</span>  
<span style="margin-left: 2em">之三邊求其容得一五三七<sub class="note-yuan">此法見後第三題</sub>并兩形積得</span>  
<span style="margin-left: 2em">二八七一知法爲未合也</span>  
<span style="margin-left: 2em">論曰兩廣或兩長在平行線內者并而折半損有餘</span>  
<span style="margin-left: 2em">補不足改爲方形也以中長線乘之則得其容若四</span>  
<span style="margin-left: 2em">不等無法形也損此益彼一不能爲方一不能爲中</span>  
<span style="margin-left: 2em">長線何緣得合乎</span>  
<span style="margin-left: 2em">第二題</span>  
<span style="margin-left: 1em">量三邊形</span>  
<span style="margin-left: 5em">乙丙丁三邊形有邊數無角數求實其法并</span>  
<span style="margin-left: 5em">三邊數半之爲實以每邊之數爲法各減之</span>  
<span style="margin-left: 5em">三較連乘得數以半總數乘之爲實平方開</span>  
<span style="margin-left: 2em">之得實</span>  
<span style="margin-left: 2em">如三邊爲七爲十二爲九并得二十八半之爲一十</span>  
<span style="margin-left: 2em">四減七較七減十二較二減九較五三較連乘得七</span>  
<span style="margin-left: 2em">十以半總十四乘之得九百八十〇開方得三十一</span>  
<span style="margin-left: 2em">又六十二之一十九不盡</span>  
<span style="margin-left: 2em">又如三邊爲十三十八二十一并得五十二半之爲</span>  
<span style="margin-left: 5em">二十六減十三較十三減十八較八減二十</span>  
<span style="margin-left: 5em">一較五三較連乘得五百二十〇以半總數</span>  
<span style="margin-left: 5em">二十六乘之得一萬三千六百二十〇開方</span>  
<span style="margin-left: 2em">得一百一十六又二三二七之一六四不盡</span>  
<span style="margin-left: 2em">解曰如圖乙丙丁斜角形先平分丙丁二角作丙戊</span>  
<span style="margin-left: 2em">丁戊二線遇于戊從戊向各邊作垂線爲戊壬戊己</span>  
<span style="margin-left: 2em">戊庚三線皆等<sub class="note-yuan">戊壬丙戊己丙兩直角形同用戊丙邊兩丙角亦等形必等則戊己戊壬</sub></span>  
<span style="margin-left: 10em"><sub class="note-yuan">亦等又壬戊丁丁戊庚兩直角形同用戊丁邊兩丁角亦等形</sub></span>  
<span style="margin-left: 10em"><sub class="note-yuan">必等則壬戊戊庚亦等</sub></span>  
<span style="margin-left: 10em">次從乙作乙戊平分乙角乙戊</span>  
<span style="margin-left: 10em">己乙戊庚兩直角形有己戊戊</span>  
<span style="margin-left: 10em">庚兩邊等同用乙戊邊形必等</span>  
<span style="margin-left: 10em">則兩乙角亦等依三角形推壬</span>  
<span style="margin-left: 2em">丙與丙己己乙與乙庚庚丁與丁壬各等共六線三</span>  
<span style="margin-left: 2em">等次于三相等邊各取一邊如乙己己丙壬丁合之</span>  
<span style="margin-left: 2em">爲元形三邊并之半<sub class="note-yuan">或丁庚庚乙壬丙或每相等兩形邊減一邊得三較亦元形三</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">邊并之半</sub>次乙丙邊引長之取丙辛與丁壬等乙丁邊引</span>  
<span style="margin-left: 2em">長之取丁癸與己丙等則乙辛乙癸皆元形三邊并</span>  
<span style="margin-left: 2em">之半亦三較之總數也次從辛從癸作兩垂線遇于</span>  
<span style="margin-left: 2em">子乙戊引長之亦與辛子癸子遇于子<sub class="note-yuan">乙癸子乙辛子兩直角形</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">之乙癸乙辛兩邊等兩乙角亦等即乙子弦必等而辛子子癸亦等</sub>次截丙午與壬丁</span>  
<span style="margin-left: 2em">等作午子線又截辛丑與壬丙等作丑子線即丑子</span>  
<span style="margin-left: 2em">與丁子必等<sub class="note-yuan">癸丁子辛丑子兩直角形之丁癸與辛丑等癸子與辛子等則其弦丁子丑子</sub></span>

<span style="margin-left: 3em">一六開方得一二六有奇不盡若有角求一邊或</span>  
<span style="margin-left: 3em">有二角求二邊亦先求邊<sub class="note-yuan">本書一卷十</sub></span>  
<span style="margin-left: 13em"><sub class="note-yuan">五十六題</sub>　	</span>  
<span style="margin-left: 8em">若形之邊爲斷幾何如圓果平積之</span>  
<span style="margin-left: 8em">邊其法以邊數自之又加邊數半之</span>  
<span style="margin-left: 8em">爲形之積假如各邊有三自之得九</span>  
<span style="margin-left: 3em">加邊得十二半之得六形積也又如設邊五自之</span>  
<span style="margin-left: 3em">得二十五加邊三十半之得十五積也見算</span>  
<span style="margin-left: 3em">章遞加法</span>  
<span style="margin-left: 2em">第三題</span>  
<span style="margin-left: 1em">量多邊形</span>  
<span style="margin-left: 2em">一解曰有法多邊形求其容必先分元形皆爲兩邊</span>  
<span style="margin-left: 2em">等三角形故不論幾何邊俱同法</span>  
<span style="margin-left: 2em">法曰多邊形從心至各角作線悉分爲兩邊等三角</span>  
<span style="margin-left: 2em">形各形有邊數有角數求其中長線得各三角形之</span>  
<span style="margin-left: 2em">容并之得元形之容</span>  
<span style="margin-left: 7em">如八邊邊設十步從心至角作線輳心</span>  
<span style="margin-left: 7em">成八角皆等凡輳心必四直角分三百</span>  
<span style="margin-left: 7em">六十度八而一每角得四十五度乙丙</span>  
<span style="margin-left: 7em">丁角形二邊等有丁丙底有丁乙丙角</span>  
<span style="margin-left: 2em">則丁丙兩角并得一百三十五度半之得六十七度</span>  
<span style="margin-left: 2em">又二之一爲乙丁丙角又甲乙丁角形有丁甲<sub class="note-yuan">半元邊爲</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">五</sub>求甲乙垂線即全數<sub class="note-yuan">內</sub>與丁甲<sub class="note-yuan">五外</sub>若丁角之切線</span>  
<span style="margin-left: 2em"><sub class="note-yuan">二四一四二一內</sub>與甲乙邊<sub class="note-yuan">一二〇七一〇五外</sub>約之得十二步有奇</span>  
<span style="margin-left: 2em">以乘甲丁五步得六二三五五二五約六十步有奇</span>  
<span style="margin-left: 2em">八之得四八八四二四〇〇約得四百八十八步有</span>  
<span style="margin-left: 2em">奇爲元形之容</span>  
<span style="margin-left: 2em">若有中長線如甲戊以其半乘半周所得與前等</span>  
<span style="margin-left: 2em">又如十二邊有法形邊設十步以十二除三百六十</span>  
<span style="margin-left: 2em">度得三十度爲丙乙丁角即乙丁丙角必七十五度</span>  
<span style="margin-left: 2em">從心作乙甲線至丁丙邊又甲乙丁角形有甲丁五</span>  
<span style="margin-left: 2em">步有丁角七十五度求甲乙線即全數<sub class="note-yuan">內</sub>與甲乙<sub class="note-yuan">五外</sub></span>  
<span style="margin-left: 2em">若丁角之切線<sub class="note-yuan">三七三二〇五內</sub>與甲乙<sub class="note-yuan">八一八六六〇二五外</sub>約得</span>  
<span style="margin-left: 2em">十八步有奇甲乙中垂線也次如前</span>  
<span style="margin-left: 6em">或用正弦數法曰各邊爲本弧之弦即半</span>  
<span style="margin-left: 6em">邊爲半弧之正弦而中垂線爲半弧之餘</span>  
<span style="margin-left: 6em">弦以邊數除三百六十得設邊之弧邊數</span>  
<span style="margin-left: 6em">及弧度各半之次用半弧度求其正弦及</span>  
<span style="margin-left: 2em">餘弦末用三率法以半弧之正弦爲第一半邊數爲</span>  
<span style="margin-left: 2em">第二餘弦數爲第三得第四爲正垂線即乙甲</span>  
<span style="margin-left: 2em">如五邊等形邊設十二以五除三百六十得七十二</span>  
<span style="margin-left: 2em">半之得三十六其正弦五八七七九爲一率<sub class="note-yuan">內</sub>其餘</span>  
<span style="margin-left: 2em">弦八〇九〇二爲三率<sub class="note-yuan">內</sub>半邊六爲二率<sub class="note-yuan">外</sub>得九又</span>  
<span style="margin-left: 2em">九之一爲四率<sub class="note-yuan">外</sub>即一邊上之垂線次以形周乘四</span>  
<span style="margin-left: 2em">率得數半之爲形之積五邊形之周爲六十乘得五</span>  
<span style="margin-left: 2em">四六又九之四爲五邊形之并積</span>  
<span style="margin-left: 2em">多邊有法形之比例　多邊有法形之具三曰邊曰</span>  
<span style="margin-left: 2em">周曰積形大小不等其比例等故有一形某具之比</span>  
<span style="margin-left: 2em">例可得他形某具之比例</span>  
<span style="margin-left: 2em">每形之邊爲一<sub class="note-yuan">一虛數也丈尺寸分唯所設之</sub></span>  
<span style="margin-left: 3em">三邊形之周三積爲三十之十三</span>  
<span style="margin-left: 3em">四邊形之周四積爲一</span>  
<span style="margin-left: 3em">五邊之周五積爲一又一一七七五七〇六之八</span>  
<span style="margin-left: 3em">四六九七一九約爲十一之八不盡</span>  
<span style="margin-left: 3em">六邊形之周六積爲二又五百萬之二九九〇三</span>  
<span style="margin-left: 3em">八一約爲五之三不足</span>  
<span style="margin-left: 3em">七邊形之周七積爲三又八六七七六七四之五</span>  
<span style="margin-left: 3em">五〇七二二一約爲八之一而盈</span>  
<span style="margin-left: 3em">八邊形之周八積爲四又一九一三四一七之一</span>  
<span style="margin-left: 3em">五八五一二七約爲十九之十六不足</span>  
<span style="margin-left: 3em">九邊形之周九積爲六又六八四〇四〇二之一</span>  
<span style="margin-left: 3em">二四三七五五約爲十七之三不盡</span>  
<span style="margin-left: 3em">十邊形之周十積爲七又一二三六〇六八之八</span>  
<span style="margin-left: 3em">五八〇八九約爲三之二不足</span>  
<span style="margin-left: 2em">用法設他形之邊求積以其邊數自之以上所列同</span>  
<span style="margin-left: 2em">類形之積數乘之若設他形之積求邊則上所列同</span>  
<span style="margin-left: 2em">類形之積數除之所得之根設形之邊也</span>  
<span style="margin-left: 6em">舊法三角形每面十四以六乘面得八十</span>  
<span style="margin-left: 6em">四以七而一得十二爲實半面七爲法乘</span>  
<span style="margin-left: 6em">之得八四積也試用前法分元形作兩句</span>  
<span style="margin-left: 2em">股形各形有弦有句以求股而求積得八四又三十</span>  
<span style="margin-left: 2em">之二十八幾爲八五非八四</span>  
<span style="margin-left: 2em">論曰所以然者古法正六面七謂丙乙十四則丙甲</span>  
<span style="margin-left: 2em">十二故七六相乘得四十二爲丙乙丁之實八十四</span>  
<span style="margin-left: 2em">矣不知丙乙十四乙甲七各自之相減開方乃十二</span>  
<span style="margin-left: 2em">有奇非十二也且七除又七乘安用之</span>  
<span style="margin-left: 2em">舊法六角形每面十五以面數自之得二二五以三</span>  
<span style="margin-left: 6em">乘之得六七五今用幾何四卷十五之系</span>  
<span style="margin-left: 6em">六邊等形內有三角等邊形六用古法得</span>  
<span style="margin-left: 6em">各形之積爲九十六又七之六六因之得</span>  
<span style="margin-left: 2em">五九一又七之一非六七五</span>  
<span style="margin-left: 2em">論曰所以然者十五自之爲二二五彼以爲此乙丙</span>  
<span style="margin-left: 2em">邊乘得乙丙丁戊形之實也不知二二五者乙丙上</span>  
<span style="margin-left: 2em">正方形之實此乙丙丁戊則斜方斜方與正方同邊</span>  
<span style="margin-left: 2em">而異積也斜方之積必少于正方之積故實少而誤</span>  
<span style="margin-left: 2em">以爲多</span>  
<span style="margin-left: 2em">古法八角田每面十四以面五乘得七十七而一得</span>  
<span style="margin-left: 2em">十倍之得二十求一面得三十四自之得一一五六</span>  
<span style="margin-left: 2em">爲實面數自之得一九六爲法減之餘九六〇八角</span>  
<span style="margin-left: 2em">形積也正法作圖每兩邊引長之遇于甲成正方形</span>  
<span style="margin-left: 6em">其內有元八邊形又有甲乙丙四句股形</span>  
<span style="margin-left: 6em">以丙乙元形邊十四爲弦求丙甲而句股</span>  
<span style="margin-left: 6em">等法以弦十四自之得一九六半</span>  
<span style="margin-left: 2em">之得九八開方爲九又十九之十七甲乙也甲乙甲</span>  
<span style="margin-left: 2em">丁等合之加于乙丁元形之邊得三十二又十九之</span>  
<span style="margin-left: 2em">十七爲甲甲正方之邊自之得一一四又三六一之</span>  
<span style="margin-left: 2em">二二五正方之積也次求句股四形之積得一九六</span>  
<span style="margin-left: 2em">弱以減正方積餘九四四有奇元八角形之積也古</span>  
<span style="margin-left: 2em">法曰九六〇謬矣</span>  
<span style="margin-left: 2em">論曰所以然者古法方五斜七不知方五則斜七有</span>  
<span style="margin-left: 2em">奇不發之根也彼以甲乙等各句各股俱爲十則乙</span>  
<span style="margin-left: 2em">丙邊與乙丙弦俱十四不知各率皆是而獨乙丙弦</span>  
<span style="margin-left: 2em">非十四也故八角形之積實少而誤以爲多</span>
