## 崇祯历书卷之二十八　新历晓或

<span style="margin-left: 1em">新历晓或<sub class="note-jiao">校：清刊本內容</sub></span>  
<span style="margin-left: 3em">历颁时宪正朔维新爰钦爰若万世用遵义关肇</span>  
<span style="margin-left: 3em">造匪旧是因聊设答问与世共论作晓或<sub class="note-yuan">凡六条</sub></span>  
<span style="margin-left: 1em">或问二十八宿旧有定序今新法先参后觜近于立异</span>  
<span style="margin-left: 2em">未解也晓之曰尝测诸天实然何敢立异也且此亦</span>  
<span style="margin-left: 2em">非自今日始也古测从来不同矣间览前史觜宿距</span>  
<span style="margin-left: 2em">星汉测二度唐测一度宋测一度迄半度元测五分</span>  
<span style="margin-left: 2em">夫由汉而唐而宋而元或越数百年或越百十年而</span>  
<span style="margin-left: 2em">差以度计以数十分计既已如是历元而明以至今</span>  
<span style="margin-left: 2em">日又越三百余年矣乃自相距五分积渐而侵入参</span>  
<span style="margin-left: 2em">宿二十四分此理势之必然又何足讶乎不测诸天</span>  
<span style="margin-left: 2em">不考诸古而拘泥习说以滋疑议岂其可哉<sub class="note-yuan">二宿先后之所</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">以然详见历指</sub>即如旧法列黄黑道于直宿之上颇亦未安</span>  
<span style="margin-left: 2em">盖黄黑道与直宿义不相属而各宿各挨直本日与</span>  
<span style="margin-left: 2em">支千同用黄黑道则属以下铺注之事矣今故更置</span>  
<span style="margin-left: 2em">之以便观览恐或者不察并晓之</span>  
<span style="margin-left: 1em">或问新法节气与旧法有差至二日者太远若此未解</span>  
<span style="margin-left: 2em">也晓之曰旧法乎节气非天上真节气也盖太阳之</span>  
<span style="margin-left: 2em">行有盈有缩而盈缩又各不等旧法平分气策一十</span>  
<span style="margin-left: 2em">五万二一八四三七五以为岁周二十四分之一是</span>  
<span style="margin-left: 2em">以平数定节气不免违天矣子是节气之差或以时</span>  
<span style="margin-left: 2em">计或以日计至若春分则后天二日秋分则先天二</span>  
<span style="margin-left: 2em">日夫二分孰不知为昼夜乎之节气乃旧历昼夜平</span>  
<span style="margin-left: 2em">已二日而后春分秋分已二日而后昼夜平此何以</span>  
<span style="margin-left: 2em">说也又旧法平节气限定十五日一见每月准有二</span>  
<span style="margin-left: 2em">节今新法节气既依日度盈缩以定则不但十五日</span>  
<span style="margin-left: 2em">一见亦有十六日一见者如夏至前后诸节是也亦</span>  
<span style="margin-left: 2em">有十四日一见者如冬至前后诸节是也而惟十四</span>  
<span style="margin-left: 2em">日一节气者或至一月三见者有之凡此皆于旧历</span>  
<span style="margin-left: 2em">则远于天行则合岂得舍天弗从而从旧乎</span>  
<span style="margin-left: 1em">或问旧法节气时刻惟一新法诸方不同篇首赘附数</span>  
<span style="margin-left: 2em">页未解也晓之曰国家治历敬授民时岂可蒙混苟</span>  
<span style="margin-left: 2em">图塞责而已夫大地浑圜居天之中昔人所为譬之</span>  
<span style="margin-left: 2em">卵黄也地既浑圜则是太阳每日环绕一周出没早</span>  
<span style="margin-left: 2em">晏处处不同因而节气时刻互异此系天度地里远</span>  
<span style="margin-left: 2em">近各有相当岂可槩而同之乎旧历不知此理强执</span>  
<span style="margin-left: 2em">一方以槩诸方遂令诸方节气皆不得真正时刻为</span>  
<span style="margin-left: 2em">误匪小其去敬授之旨远矣新历用是详列首篇随</span>  
<span style="margin-left: 2em">地晓示以著天行而前民用奈何以为赘也</span>  
<span style="margin-left: 1em">或问每昼夜百刻所从未矣今称九十六刻无端少却</span>  
<span style="margin-left: 2em">四刻未解也晓之曰是旧多四刻非新少四刻也盖</span>  
<span style="margin-left: 2em">一昼一夜平分为十有二时时各八刻积十二时计</span>  
<span style="margin-left: 2em">之其为刻也九十有六日巳何云少也旧历增设四</span>  
<span style="margin-left: 2em">刻间尝举以相质有谓子午卯酉各增一刻均之时</span>  
<span style="margin-left: 2em">也而四时独增此其于理甚谬且太阳出没随地异</span>  
<span style="margin-left: 2em">时在此为子在彼或为丑为寅在此为午在彼或为</span>  
<span style="margin-left: 2em">未为申设此方子午各增一刻则彼一方丑未各增</span>  
<span style="margin-left: 2em">一刻彼又一方寅申各增一刻矣其说又岂可通乎</span>  
<span style="margin-left: 2em">窃意强增四刻者辏成百数以便筹策耳然据授时</span>  
<span style="margin-left: 2em">历分派百刻谓每时八刻又三分刻之一则是每时</span>  
<span style="margin-left: 2em">各有一奇零愈益繁琐何便之有迩来畴人子弟亦</span>  
<span style="margin-left: 2em">自知百刻之不适于用也其于推交食求时差分仍</span>  
<span style="margin-left: 2em">用九十六刻为法定之是岂非旧多四刻之明验乎</span>  
<span style="margin-left: 1em">或问旧载四余今则遗却紫气未解也晓之曰历法家</span>  
<span style="margin-left: 2em">凡有理可据则有论述有数可定则有推算有象可</span>  
<span style="margin-left: 2em">明则有测候而凡理与数又必缘象而生苟无其象</span>  
<span style="margin-left: 2em">虽有巧历不能违天创一理造一数也旧法所载紫</span>  
<span style="margin-left: 2em">气盖谓生于闰余夫闰余者朔周不及气盈之数也</span>  
<span style="margin-left: 2em">则为太阴历中之行度率无疑矣然尝密考太阴历</span>  
<span style="margin-left: 2em">之行度展转相生尽于十种并不见有余闰一行糅</span>  
<span style="margin-left: 2em">襍其间则是无其象矣无象则理数并归于无又何</span>  
<span style="margin-left: 2em">论述推算之可施哉惟其强无为有未免牵合传会</span>  
<span style="margin-left: 2em">以成其说<sub class="note-yuan">详见历指</sub>从古名家皆知其无当无论唐以前</span>  
<span style="margin-left: 2em">未闻其说即唐以后传其说而中历西历凡为正术</span>  
<span style="margin-left: 2em">者皆弃弗录也昔曹士荐尝业其术而及其为书止</span>  
<span style="margin-left: 2em">罗计立成历而已先是李淳风亦止作月孛法五代</span>  
<span style="margin-left: 2em">王朴作钦天历止以罗计为蚀神首尾行之民间小</span>  
<span style="margin-left: 2em">历可见紫气一术即用彼法者亦弃弗录也然则鄙</span>  
<span style="margin-left: 2em">俚不经莫此为甚其为耶律楚材王恂郭守敬诸人</span>  
<span style="margin-left: 2em">所讳明矣说者乃讥元失其传岂不谬哉新法不敢</span>  
<span style="margin-left: 2em">悬空立说以恣诬民之术非与星家故相左也亦曰</span>  
<span style="margin-left: 2em">传信阙疑庶无欺于天下后世云尔</span>  
<span style="margin-left: 1em">或问天行与人事相应以此历有推算铺注二事今云</span>  
<span style="margin-left: 2em">依西法造历则是铺注亦西法矣晓之曰自前朝奉</span>  
<span style="margin-left: 2em">旨修历秪因该监所推交食不合皆由旧法七政差</span>  
<span style="margin-left: 2em">讹乃始决议改修所谓改修者皆関推算非铺注也</span>  
<span style="margin-left: 2em">二十年来著成新法历书百十余卷皆天行理数之</span>  
<span style="margin-left: 2em">学创法者之所指授受法者之所讲求皆推算非铺</span>  
<span style="margin-left: 2em">注也历成恭逄</span>  
<span style="margin-left: 1em">圣明御宇特鉴新法与天行密合分毫不爽遂用造历</span>  
<span style="margin-left: 2em">颁行则是所用之西法皆关推算之事而该监铺注</span>  
<span style="margin-left: 2em">尚仍旧例非西洋天文实用之铺注也</span>  
<span style="margin-left: 12em">修政历法汤若望识</span>  
<span style="margin-left: 1em">新历晓或跋<sub class="note-jiao">校：昭代叢書本內容</sub></span>  
<span style="margin-left: 1em">测量推步新法实密于旧法明末格于门户不能立入</span>  
<span style="margin-left: 1em">国朝乃用以布授时之典其有改革剏造者汤氏设为</span>  
<span style="margin-left: 1em">问荅以发明之致详且悉向附载于新法表异后表异</span>  
<span style="margin-left: 1em">卷帙颇繁故仅录此以见一斑乙丑仲夏震泽杨复吉</span>  
<span style="margin-left: 1em">跋</span>  
<span style="margin-left: 13em">孙揆嘉肇初校字</span>
