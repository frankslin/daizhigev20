## 崇禎曆書卷之二十八　新曆曉或

<span style="margin-left: 1em">新曆曉或<sub class="note-jiao">校：清刊本內容</sub></span>  
<span style="margin-left: 3em">歷頒時憲正朔維新爰欽爰若萬世用遵義關肇</span>  
<span style="margin-left: 3em">造匪舊是因聊設答問與世共論作曉或<sub class="note-yuan">凡六條</sub></span>  
<span style="margin-left: 1em">或問二十八宿舊有定序今新法先參後觜近于立異</span>  
<span style="margin-left: 2em">未解也曉之曰嘗測諸天實然何敢立異也且此亦</span>  
<span style="margin-left: 2em">非自今日始也古測從來不同矣間覽前史觜宿距</span>  
<span style="margin-left: 2em">星漢測二度唐測一度宋測一度迄半度元測五分</span>  
<span style="margin-left: 2em">夫由漢而唐而宋而元或越數百年或越百十年而</span>  
<span style="margin-left: 2em">差以度計以數十分計既已如是歷元而明以至今</span>  
<span style="margin-left: 2em">日又越三百餘年矣乃自相距五分積漸而侵入參</span>  
<span style="margin-left: 2em">宿二十四分此理勢之必然又何足訝乎不測諸天</span>  
<span style="margin-left: 2em">不考諸古而拘泥習說以滋疑議豈其可哉<sub class="note-yuan">二宿先後之所</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">以然詳見曆指</sub>即如舊法列黃黑道于直宿之上頗亦未安</span>  
<span style="margin-left: 2em">蓋黃黑道與直宿義不相屬而各宿各挨直本日與</span>  
<span style="margin-left: 2em">支千同用黃黑道則屬以下鋪註之事矣今故更置</span>  
<span style="margin-left: 2em">之以便觀覽恐或者不察并曉之</span>  
<span style="margin-left: 1em">或問新法節氣與舊法有差至二日者太遠若此未解</span>  
<span style="margin-left: 2em">也曉之曰舊法乎節氣非天上真節氣也蓋太陽之</span>  
<span style="margin-left: 2em">行有盈有縮而盈縮又各不等舊法平分氣策一十</span>  
<span style="margin-left: 2em">五萬二一八四三七五以爲歲周二十四分之一是</span>  
<span style="margin-left: 2em">以平數定節氣不免違天矣子是節氣之差或以時</span>  
<span style="margin-left: 2em">計或以日計至若春分則後天二日秋分則先天二</span>  
<span style="margin-left: 2em">日夫二分孰不知爲晝夜乎之節氣乃舊歷晝夜平</span>  
<span style="margin-left: 2em">已二日而後春分秋分已二日而後晝夜平此何以</span>  
<span style="margin-left: 2em">說也又舊法平節氣限定十五日一見每月準有二</span>  
<span style="margin-left: 2em">節今新法節氣既依日度盈縮以定則不但十五日</span>  
<span style="margin-left: 2em">一見亦有十六日一見者如夏至前後諸節是也亦</span>  
<span style="margin-left: 2em">有十四日一見者如冬至前後諸節是也而惟十四</span>  
<span style="margin-left: 2em">日一節氣者或至一月三見者有之凡此皆于舊曆</span>  
<span style="margin-left: 2em">則遠于天行則合豈得舍天弗從而從舊乎</span>  
<span style="margin-left: 1em">或問舊法節氣時刻惟一新法諸方不同篇首贅附數</span>  
<span style="margin-left: 2em">頁未解也曉之曰國家治曆敬授民時豈可蒙混苟</span>  
<span style="margin-left: 2em">圖塞責而已夫大地渾圜居天之中昔人所爲譬之</span>  
<span style="margin-left: 2em">卵黃也地既渾圜則是太陽每日環繞一周出没早</span>  
<span style="margin-left: 2em">晏處處不同因而節氣時刻互異此係天度地里遠</span>  
<span style="margin-left: 2em">近各有相當豈可槩而同之乎舊曆不知此理强執</span>  
<span style="margin-left: 2em">一方以槩諸方遂令諸方節氣皆不得真正時刻爲</span>  
<span style="margin-left: 2em">誤匪小其去敬授之旨遠矣新曆用是詳列首篇隨</span>  
<span style="margin-left: 2em">地曉示以著天行而前民用奈何以爲贅也</span>  
<span style="margin-left: 1em">或問每晝夜百刻所從未矣今稱九十六刻無端少却</span>  
<span style="margin-left: 2em">四刻未解也曉之曰是舊多四刻非新少四刻也蓋</span>  
<span style="margin-left: 2em">一晝一夜平分爲十有二時時各八刻積十二時計</span>  
<span style="margin-left: 2em">之其爲刻也九十有六日巳何云少也舊曆增設四</span>  
<span style="margin-left: 2em">刻間嘗舉以相質有謂子午卯酉各增一刻均之時</span>  
<span style="margin-left: 2em">也而四時獨增此其于理甚謬且太陽出没隨地異</span>  
<span style="margin-left: 2em">時在此爲子在彼或爲丑爲寅在此爲午在彼或爲</span>  
<span style="margin-left: 2em">未爲申設此方子午各增一刻則彼一方丑未各增</span>  
<span style="margin-left: 2em">一刻彼又一方寅申各增一刻矣其說又豈可通乎</span>  
<span style="margin-left: 2em">竊意强增四刻者輳成百數以便籌策耳然據授時</span>  
<span style="margin-left: 2em">曆分派百刻謂每時八刻又三分刻之一則是每時</span>  
<span style="margin-left: 2em">各有一奇零愈益繁瑣何便之有邇來疇人子弟亦</span>  
<span style="margin-left: 2em">自知百刻之不適于用也其于推交食求時差分仍</span>  
<span style="margin-left: 2em">用九十六刻爲法定之是豈非舊多四刻之明驗乎</span>  
<span style="margin-left: 1em">或問舊載四餘今則遺却紫氣未解也曉之曰曆法家</span>  
<span style="margin-left: 2em">凡有理可據則有論述有數可定則有推算有象可</span>  
<span style="margin-left: 2em">明則有測候而凡理與數又必緣象而生苟無其象</span>  
<span style="margin-left: 2em">雖有巧曆不能違天創一理造一數也舊法所載紫</span>  
<span style="margin-left: 2em">氣蓋謂生于閏餘夫閏餘者朔周不及氣盈之數也</span>  
<span style="margin-left: 2em">則爲太陰曆中之行度率無疑矣然嘗密考太陰曆</span>  
<span style="margin-left: 2em">之行度展轉相生盡于十種並不見有餘閏一行糅</span>  
<span style="margin-left: 2em">襍其間則是無其象矣無象則理數并歸于無又何</span>  
<span style="margin-left: 2em">論述推算之可施哉惟其强無爲有未免牽合傳會</span>  
<span style="margin-left: 2em">以成其說<sub class="note-yuan">詳見曆指</sub>從古名家皆知其無當無論唐以前</span>  
<span style="margin-left: 2em">未聞其說即唐以後傳其說而中曆西曆凡爲正術</span>  
<span style="margin-left: 2em">者皆棄弗錄也昔曹士薦嘗業其術而及其爲書止</span>  
<span style="margin-left: 2em">羅計立成曆而已先是李淳風亦止作月孛法五代</span>  
<span style="margin-left: 2em">王朴作欽天曆止以羅計爲蝕神首尾行之民間小</span>  
<span style="margin-left: 2em">曆可見紫氣一術即用彼法者亦棄弗錄也然則鄙</span>  
<span style="margin-left: 2em">俚不經莫此爲甚其爲耶律楚材王恂郭守敬諸人</span>  
<span style="margin-left: 2em">所諱明矣說者乃譏元失其傳豈不謬哉新法不敢</span>  
<span style="margin-left: 2em">懸空立說以恣誣民之術非與星家故相左也亦曰</span>  
<span style="margin-left: 2em">傳信闕疑庶無欺于天下後世云爾</span>  
<span style="margin-left: 1em">或問天行與人事相應以此曆有推算鋪註二事今云</span>  
<span style="margin-left: 2em">依西法造曆則是鋪註亦西法矣曉之曰自前朝奉</span>  
<span style="margin-left: 2em">旨修曆秪因該監所推交食不合皆由舊法七政差</span>  
<span style="margin-left: 2em">訛乃始决議改修所謂改修者皆関推算非鋪註也</span>  
<span style="margin-left: 2em">二十年來著成新法曆書百十餘卷皆天行理數之</span>  
<span style="margin-left: 2em">學創法者之所指授受法者之所講求皆推算非鋪</span>  
<span style="margin-left: 2em">註也曆成恭逄</span>  
<span style="margin-left: 1em">聖明御宇特鑒新法與天行密合分毫不爽遂用造曆</span>  
<span style="margin-left: 2em">頒行則是所用之西法皆關推算之事而該監鋪註</span>  
<span style="margin-left: 2em">尚仍舊例非西洋天文實用之鋪註也</span>  
<span style="margin-left: 12em">修政曆法湯若望識</span>  
<span style="margin-left: 1em">新曆曉或跋<sub class="note-jiao">校：昭代叢書本內容</sub></span>  
<span style="margin-left: 1em">測量推步新法實密於舊法明末格於門戶不能立入</span>  
<span style="margin-left: 1em">國朝乃用以布授時之典其有改革剏造者湯氏設爲</span>  
<span style="margin-left: 1em">問荅以發明之致詳且悉向附載於新法表異後表異</span>  
<span style="margin-left: 1em">卷帙頗繁故僅錄此以見一斑乙丑仲夏震澤楊復吉</span>  
<span style="margin-left: 1em">跋</span>  
<span style="margin-left: 13em">孫揆嘉肇初校字</span>
