## 崇禎曆書卷之一百七十一　日晷圖法卷四

<span style="margin-left: 1em">日晷圖法卷四</span>  
<span style="margin-left: 3em">面東面西面南晷</span>  
<span style="margin-left: 3em">第一式</span>  
<span style="margin-left: 1em">面東面西晷置正向卯酉兩壁者先于壁上以　卷第</span>  
<span style="margin-left: 2em">題所作器式以懸空之線作甲乙垂線爲天頂線次</span>  
<span style="margin-left: 1em">作丙丁橫線爲地平線兩線交于戊爲表位即以戊爲</span>  
<span style="margin-left: 1em">心從地平線向上任作全圜四分之一如辛壬但面東</span>  
<span style="margin-left: 1em">者作于天頂線左面西者作于天頂線右即平分辛壬</span>  
<span style="margin-left: 1em">爲九十度次視本地極出度如京師四十度從辛向壬</span>  
<span style="margin-left: 1em">量四十度或從壬向辛量極出餘度五十度于己次作</span>  
<span style="margin-left: 1em">戊己線即赤道線也次從戊作赤道之垂線仁尺即卯</span>  
<span style="margin-left: 1em">酉線次量晷大小任取戊作爲表長以表長爲度從戊</span>  
<span style="margin-left: 1em">于卯酉線上右得甘左得云即從甘云俱作虛線與赤</span>  
<span style="margin-left: 1em">道平行者如甘石如云元次以戊爲心任作甲乙丙丁</span>  
<span style="margin-left: 1em">全圜平分爲九十六刻次以戊與圜分相望每至甘石</span>  
<span style="margin-left: 1em">云元兩線交處即作識次以兩線與諸識平望俱作直</span>  
<span style="margin-left: 1em">線與卯酉線平行即時刻線也其卯酉以上下十二刻</span>  
<span style="margin-left: 1em">必與表長之戊竹相等稍差必不準也次立表于戊以</span>  
<span style="margin-left: 1em">視日晷即得但此二晷之壁面與午線平行日至午正</span>  
<span style="margin-left: 1em">初刻表景即無窮不能射壁面故皆無午正時也</span>  
<span style="margin-left: 3em">第二式</span>  
<span style="margin-left: 1em">若欲并得午正諸刻宜別作面南赤道晷但前二晷面</span>  
<span style="margin-left: 1em">東西者正對天頂而此晷者正對北極故如赤道晷因</span>  
<span style="margin-left: 1em">其向南之邊正對赤道故曰赤道晷此晷向北之邊正</span>  
<span style="margin-left: 1em">對北極故名曰極晷若所用畫晷之體定不移則先須</span>  
<span style="margin-left: 1em">量其面上邊正與北極對否試如甲乙丙丁爲畫晷體</span>  
<span style="margin-left: 1em">乙戊線爲地平以乙爲心任作戊己圜分從地平向上</span>  
<span style="margin-left: 1em">量本地極出度分如京師四十度爲己即作乙己線若</span>  
<span style="margin-left: 1em">平面依此斜線即此晷高于地平四十度矣若體不定</span>  
<span style="margin-left: 10em">則依十字晷法求得時刻及節</span>  
<span style="margin-left: 10em">氣線而或依度板法以四十度</span>  
<span style="margin-left: 10em">之度板倚之或以度圜懸之令</span>  
<span style="margin-left: 10em">其面向赤道<sub class="note-jiao">校：赤道原作北道據文意改</sub>而</span>  
<span style="margin-left: 10em">其向北邊正對北極即得次量</span>  
<span style="margin-left: 10em">甲乙之中于庚丙丁之中于辛</span>  
<span style="margin-left: 10em">作庚辛線爲赤道線次兩平分</span>  
<span style="margin-left: 10em">庚辛線于土爲表位從土作壬</span>  
<span style="margin-left: 10em">艮爲庚辛之垂線即午線也次</span>  
<span style="margin-left: 10em">以第一式赤道上從卯酉線向</span>  
<span style="margin-left: 1em">諸時線逐一爲度移至此式赤道上從上向左右逐一</span>  
<span style="margin-left: 1em">作識次以諸識俱作直線皆與壬艮平行爲時刻線也</span>  
<span style="margin-left: 1em">第此晷面亦與卯酉線平行故日出入表景不能指其</span>  
<span style="margin-left: 1em">向也次以申初初刻及巳初初刻兩線交赤道處各爲</span>  
<span style="margin-left: 1em">心各向午任作等圜分交赤道線于元即以元循圜各</span>  
<span style="margin-left: 1em">量極出地餘度如京師五十度于牙次作元牙線相交</span>  
<span style="margin-left: 1em">于坎<sub class="note-jiao">校：坎原作以據圖示改</sub>即從坎<sub class="note-jiao">校：坎原作次據圖示改</sub>作弓坎仁赤道</span>  
<span style="margin-left: 1em">平行線即地平線也日出入之際表景必射此線此線</span>  
<span style="margin-left: 1em">以下即晝晷以上即夜時也截地平線以上置于向地</span>  
<span style="margin-left: 1em">背面則春分以後日出入之際表景亦指時刻也第向</span>  
<span style="margin-left: 1em">上晷表<sub class="note-jiao">校：第原作節今據天理本校正</sub>與地平線皆在時刻及節氣線</span>  
<span style="margin-left: 1em">之上向下背面倒置故皆在上向上晷爲午者向下晷</span>  
<span style="margin-left: 1em">爲子午線前後時刻線亦皆易爲子前後時刻線也</span>  
<span style="margin-left: 3em">第三式</span>  
<span style="margin-left: 1em">若三晷俱欲加節氣線則如十字晷法先作甲乙橫線</span>  
<span style="margin-left: 1em">任指丙點從丙作甲乙之垂線爲赤道線次于赤道線</span>  
<span style="margin-left: 1em">左右依一卷分節氣法求得節氣疎密之度次從甲從</span>  
<span style="margin-left: 1em">乙各作線與赤道平行爲甲戊爲乙己次以第一式戊</span>  
<span style="margin-left: 1em">竹表長爲度移至此式從甲向戊乙向己丙向丁各作</span>  
<span style="margin-left: 1em">識復以第一式從戊向各時線與甘石或云元線交處</span>  
<span style="margin-left: 8em">逐一爲度移至此式亦從甲從乙從</span>  
<span style="margin-left: 8em">丙向下逐一作識即以諸識俱作平</span>  
<span style="margin-left: 8em">行線或一刻一線或二刻四刻一線</span>  
<span style="margin-left: 8em">可也但兩旁須即記時刻以免混亂</span>  
<span style="margin-left: 8em">此本晷成式也先于壁上如第一式</span>  
<span style="margin-left: 8em">作甲乙垂線爲天頂線作丙丁橫線</span>  
<span style="margin-left: 1em">爲地平線作戊己線爲赤道線作庚辛線爲卯酉線并</span>  
<span style="margin-left: 1em">作卯酉平行諸時刻線次以第三式諸時橫線自赤道</span>  
<span style="margin-left: 1em">向左向右行至諸節氣交處逐一爲度移至此式各于</span>  
<span style="margin-left: 1em">本時線上亦自赤道向左向右行逐一作識第二三以</span>  
<span style="margin-left: 14em">後皆如之爲諸節線</span>  
<span style="margin-left: 14em">界第二式面南者依</span>  
<span style="margin-left: 14em">此類推之次以諸界</span>  
<span style="margin-left: 14em">識依一卷曲線作法</span>  
<span style="margin-left: 14em">作節氣線而晷成矣</span>
