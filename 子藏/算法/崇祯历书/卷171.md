## 崇祯历书卷之一百七十一　日晷图法卷四

<span style="margin-left: 1em">日晷图法卷四</span>  
<span style="margin-left: 3em">面东面西面南晷</span>  
<span style="margin-left: 3em">第一式</span>  
<span style="margin-left: 1em">面东面西晷置正向卯酉两壁者先于壁上以　卷第</span>  
<span style="margin-left: 2em">题所作器式以悬空之线作甲乙垂线为天顶线次</span>  
<span style="margin-left: 1em">作丙丁横线为地平线两线交于戊为表位即以戊为</span>  
<span style="margin-left: 1em">心从地平线向上任作全圜四分之一如辛壬但面东</span>  
<span style="margin-left: 1em">者作于天顶线左面西者作于天顶线右即平分辛壬</span>  
<span style="margin-left: 1em">为九十度次视本地极出度如京师四十度从辛向壬</span>  
<span style="margin-left: 1em">量四十度或从壬向辛量极出余度五十度于己次作</span>  
<span style="margin-left: 1em">戊己线即赤道线也次从戊作赤道之垂线仁尺即卯</span>  
<span style="margin-left: 1em">酉线次量晷大小任取戊作为表长以表长为度从戊</span>  
<span style="margin-left: 1em">于卯酉线上右得甘左得云即从甘云俱作虚线与赤</span>  
<span style="margin-left: 1em">道平行者如甘石如云元次以戊为心任作甲乙丙丁</span>  
<span style="margin-left: 1em">全圜平分为九十六刻次以戊与圜分相望每至甘石</span>  
<span style="margin-left: 1em">云元两线交处即作识次以两线与诸识平望俱作直</span>  
<span style="margin-left: 1em">线与卯酉线平行即时刻线也其卯酉以上下十二刻</span>  
<span style="margin-left: 1em">必与表长之戊竹相等稍差必不准也次立表于戊以</span>  
<span style="margin-left: 1em">视日晷即得但此二晷之壁面与午线平行日至午正</span>  
<span style="margin-left: 1em">初刻表景即无穷不能射壁面故皆无午正时也</span>  
<span style="margin-left: 3em">第二式</span>  
<span style="margin-left: 1em">若欲并得午正诸刻宜别作面南赤道晷但前二晷面</span>  
<span style="margin-left: 1em">东西者正对天顶而此晷者正对北极故如赤道晷因</span>  
<span style="margin-left: 1em">其向南之边正对赤道故曰赤道晷此晷向北之边正</span>  
<span style="margin-left: 1em">对北极故名曰极晷若所用画晷之体定不移则先须</span>  
<span style="margin-left: 1em">量其面上边正与北极对否试如甲乙丙丁为画晷体</span>  
<span style="margin-left: 1em">乙戊线为地平以乙为心任作戊己圜分从地平向上</span>  
<span style="margin-left: 1em">量本地极出度分如京师四十度为己即作乙己线若</span>  
<span style="margin-left: 1em">平面依此斜线即此晷高于地平四十度矣若体不定</span>  
<span style="margin-left: 10em">则依十字晷法求得时刻及节</span>  
<span style="margin-left: 10em">气线而或依度板法以四十度</span>  
<span style="margin-left: 10em">之度板倚之或以度圜悬之令</span>  
<span style="margin-left: 10em">其面向赤道<sub class="note-jiao">校：赤道原作北道據文意改</sub>而</span>  
<span style="margin-left: 10em">其向北边正对北极即得次量</span>  
<span style="margin-left: 10em">甲乙之中于庚丙丁之中于辛</span>  
<span style="margin-left: 10em">作庚辛线为赤道线次两平分</span>  
<span style="margin-left: 10em">庚辛线于土为表位从土作壬</span>  
<span style="margin-left: 10em">艮为庚辛之垂线即午线也次</span>  
<span style="margin-left: 10em">以第一式赤道上从卯酉线向</span>  
<span style="margin-left: 1em">诸时线逐一为度移至此式赤道上从上向左右逐一</span>  
<span style="margin-left: 1em">作识次以诸识俱作直线皆与壬艮平行为时刻线也</span>  
<span style="margin-left: 1em">第此晷面亦与卯酉线平行故日出入表景不能指其</span>  
<span style="margin-left: 1em">向也次以申初初刻及巳初初刻两线交赤道处各为</span>  
<span style="margin-left: 1em">心各向午任作等圜分交赤道线于元即以元循圜各</span>  
<span style="margin-left: 1em">量极出地余度如京师五十度于牙次作元牙线相交</span>  
<span style="margin-left: 1em">于坎<sub class="note-jiao">校：坎原作以據圖示改</sub>即从坎<sub class="note-jiao">校：坎原作次據圖示改</sub>作弓坎仁赤道</span>  
<span style="margin-left: 1em">平行线即地平线也日出入之际表景必射此线此线</span>  
<span style="margin-left: 1em">以下即昼晷以上即夜时也截地平线以上置于向地</span>  
<span style="margin-left: 1em">背面则春分以后日出入之际表景亦指时刻也第向</span>  
<span style="margin-left: 1em">上晷表<sub class="note-jiao">校：第原作節今據天理本校正</sub>与地平线皆在时刻及节气线</span>  
<span style="margin-left: 1em">之上向下背面倒置故皆在上向上晷为午者向下晷</span>  
<span style="margin-left: 1em">为子午线前后时刻线亦皆易为子前后时刻线也</span>  
<span style="margin-left: 3em">第三式</span>  
<span style="margin-left: 1em">若三晷俱欲加节气线则如十字晷法先作甲乙横线</span>  
<span style="margin-left: 1em">任指丙点从丙作甲乙之垂线为赤道线次于赤道线</span>  
<span style="margin-left: 1em">左右依一卷分节气法求得节气疎密之度次从甲从</span>  
<span style="margin-left: 1em">乙各作线与赤道平行为甲戊为乙己次以第一式戊</span>  
<span style="margin-left: 1em">竹表长为度移至此式从甲向戊乙向己丙向丁各作</span>  
<span style="margin-left: 1em">识复以第一式从戊向各时线与甘石或云元线交处</span>  
<span style="margin-left: 8em">逐一为度移至此式亦从甲从乙从</span>  
<span style="margin-left: 8em">丙向下逐一作识即以诸识俱作平</span>  
<span style="margin-left: 8em">行线或一刻一线或二刻四刻一线</span>  
<span style="margin-left: 8em">可也但两旁须即记时刻以免混乱</span>  
<span style="margin-left: 8em">此本晷成式也先于壁上如第一式</span>  
<span style="margin-left: 8em">作甲乙垂线为天顶线作丙丁横线</span>  
<span style="margin-left: 1em">为地平线作戊己线为赤道线作庚辛线为卯酉线并</span>  
<span style="margin-left: 1em">作卯酉平行诸时刻线次以第三式诸时横线自赤道</span>  
<span style="margin-left: 1em">向左向右行至诸节气交处逐一为度移至此式各于</span>  
<span style="margin-left: 1em">本时线上亦自赤道向左向右行逐一作识第二三以</span>  
<span style="margin-left: 14em">后皆如之为诸节线</span>  
<span style="margin-left: 14em">界第二式面南者依</span>  
<span style="margin-left: 14em">此类推之次以诸界</span>  
<span style="margin-left: 14em">识依一卷曲线作法</span>  
<span style="margin-left: 14em">作节气线而晷成矣</span>  
<span style="margin-left: 14em">次俱立直表于土可</span>  
<span style="margin-left: 14em">得日景焉又有立表</span>  
<span style="margin-left: 14em">一法尤为明准其法</span>  
<span style="margin-left: 14em">面东西者于卯酉两</span>  
<span style="margin-left: 14em">端卯酉线外面南者</span>

<span style="margin-left: 1em">次以联线于两表之端如云石面东西者此线正与卯</span>
