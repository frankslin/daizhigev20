<span style="margin-left: 2em">水星本天象<sub class="note-yuan">第一章</sub></span>  
<span style="margin-left: 1em">水星以太陽平行處爲本行之心即以太陽之平行爲</span>  
<span style="margin-left: 2em">自行之平行如金星無二然其兩行之差非太陽兩</span>  
<span style="margin-left: 2em">行之差則必有自行本圈而載其次輪又此圈或圈</span>  
<span style="margin-left: 2em">上之行非平有高有低與他星等何以知其然耶曰</span>  
<span style="margin-left: 2em">見其距太陽之大距度時有大小因知其次輪必有</span>  
<span style="margin-left: 2em">遠近也今以圖略解其所測於左後詳釋之<sub class="note-yuan">次輪亦名伏見</sub></span>

<span style="margin-left: 15em">圈周上取丙點爲</span>  
<span style="margin-left: 15em">心作己丁庚戊大</span>  
<span style="margin-left: 15em">圈又作甲乙丁線</span>  
<span style="margin-left: 15em">爲兩心線取丁點</span>  
<span style="margin-left: 15em">作己癸庚圈是名</span>  
<span style="margin-left: 15em">水星次輪<sub class="note-yuan">木火土三星名</sub></span>  
<span style="margin-left: 15em"><sub class="note-yuan">曰歲輪金水不然蓋以其率非滿一</sub></span>

<span style="margin-left: 2em">輪上而行此本天之心有行之理獨水星如是而他</span>

<span style="margin-left: 2em">擇測水星以定其最高<sub class="note-yuan">第三章</sub></span>  
<span style="margin-left: 1em">金星曆曰凡朝夕測得金星距太陽平行兩大距度爲</span>  
<span style="margin-left: 2em">等者則於兩測之兩平行中度抄半得爲金星兩心</span>  
<span style="margin-left: 2em">線之處然其最高低之分尚未定也今水星或有兩</span>  
<span style="margin-left: 2em">大距度等者乃若折半不得爲兩心線之處覺測此</span>  
<span style="margin-left: 2em">星爲難古今曆家測得本天一周內伏見輪有多度</span>  
<span style="margin-left: 2em">不見前後多測大距度之差如距地無遠近等故法</span>  
<span style="margin-left: 2em">曰取用朝夕兩大距等及前後多日各測之行相反</span>  
<span style="margin-left: 2em">并平視兩行有差可知兩測兩平行中折半爲兩心</span>  
<span style="margin-left: 2em">之線所在曰相反者何一測之行爲盈一測爲縮必</span>  
<span style="margin-left: 2em">知在兩心線左右曰兩行有差言一測星在此無近</span>  
<span style="margin-left: 2em">遠處或測十日前後之行爲等因可知其引數爲等</span>
