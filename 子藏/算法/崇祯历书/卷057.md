<span style="margin-left: 1em"><sub class="note-yuan">　　　　　　　　　　　　　　　　　　　　黃宏憲劉蘊德</sub></span>  
<span style="margin-left: 1em">曆指第八卷　　月離四</span>  
<span style="margin-left: 2em">太陰小論第二十八</span>  
<span style="margin-left: 1em">第一論太陰晦朔伏見　太陰晦朔伏見古今立論疏</span>  
<span style="margin-left: 2em">密逈殊漢儒洪範傳曰晦而月見西方謂之朏<sub class="note-yuan">亦曰朓</sub></span>  
<span style="margin-left: 2em">朏者政緩所致朔而月見東方謂之側匿側匿者政</span>  
<span style="margin-left: 2em">急所致夫晦在朔後晦失也朔在晦前朔失也曆則</span>  
<span style="margin-left: 2em">失之而歸咎于政誣甚矣唐曆家以晦日之晨月見</span>  
<span style="margin-left: 2em">東方因立進朔之法使月隱晦晨明藏朔夕此則鉤</span>  
<span style="margin-left: 2em">索未能而妄生遷變使月有兩朔食乃在晦將誰欺</span>  
<span style="margin-left: 2em">乎宋元史皆非之頗爲辨晰然未能縷形其所以然</span>  
<span style="margin-left: 2em">也夫月距晦朔見有疾遲因乎天度因乎地度即此</span>  
<span style="margin-left: 2em">方近處合朔于亥子之交而甲日之晨乙日之夕兩</span>  
<span style="margin-left: 2em">見微明亦時有之此之進退將安往焉況海以南數</span>  
<span style="margin-left: 2em">千里則有甲晨乙夕終歲恆見者漠以北數千里則</span>  
<span style="margin-left: 2em">有朔在午中朝暮皆見者亦將使晨隱夕藏其可得</span>  
<span style="margin-left: 2em">乎今法若時若地應速應遲皆從籌算可密推用儀</span>  
<span style="margin-left: 2em">器可指數先事可豫言臨時可確按又何庸轉移避</span>  
<span style="margin-left: 2em">就爲也以此備述所繇徵之度數如下論</span>  
<span style="margin-left: 2em">問太陰合朔以後恆以三日見于西方亦有二日者</span>  
<span style="margin-left: 2em">其在晦以前亦如之何故曰是其因有三　一因赤</span>  
<span style="margin-left: 2em">道上之黃道升降度有正有斜正升則斜降斜升則</span>  
<span style="margin-left: 2em">正降正升斜降者秋半周六宫<sub class="note-yuan">秋分左右各三宫</sub>是也斜升</span>  
<span style="margin-left: 2em">正降者春半周六宫<sub class="note-yuan">春分左右各三宫</sub>是也<sub class="note-yuan">皆論斜球非正平球</sub>正升</span>  
<span style="margin-left: 2em">者赤道之升度多黃道之升度少正降者赤道之降</span>  
<span style="margin-left: 2em">數多黃道之降數少斜升斜降則反是<sub class="note-yuan">凡南極出地者與上論悉</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">相反</sub>若太陰離正降六宫則朔後疾見若離斜降六宫</span>  
<span style="margin-left: 2em">則朔後遲見其在晦前亦如之離正升六宫則遲隱</span>  
<span style="margin-left: 2em">離斜升六宫則疾隱也如二圖各有子午圈有地平</span>  
<span style="margin-left: 2em">有極出地等有黃道宫次二圖上圖月離大梁爲正</span>  
<span style="margin-left: 2em">降宫次距太陽十五度日入月在地平上爲十三度</span>  
<span style="margin-left: 2em">半即能見下圖月離大火爲斜降宫次距太陽十五</span>  
<span style="margin-left: 2em">度日入月在地平上爲十度即不能見一也　一因</span>  
<span style="margin-left: 2em">白道南北如圖設月距黃道五度距太陽皆十五度</span>  
<span style="margin-left: 2em">而緯分南北<sub class="note-yuan">日月各有一日所行之軌道即赤道距等圈也今如圖設黃道左右五度各一</sub></span>  
<span style="margin-left: 8em"><sub class="note-yuan">圜交于距等月在焉兩月各至地平其弧有大小則入地有先後人見有</sub></span>  
<span style="margin-left: 8em"><sub class="note-yuan">遲速</sub>若在北即入地後黃道疾見若在</span>  
<span style="margin-left: 8em">南即入地先黃道遲見二也　一因</span>  
<span style="margin-left: 8em">月視行度若視行爲遲段則朔後見</span>  
<span style="margin-left: 8em">月遲爲疾段則朔後見月疾三也</span>  
<span style="margin-left: 2em">右第一因月之見界以十五度爲限其疾者朔後一</span>  
<span style="margin-left: 2em">日又四分日之一而見也若三因并合又不待此如</span>  
<span style="margin-left: 2em">合朔在亥子間則甲日太陽未出亦見東方乙日太</span>  
<span style="margin-left: 2em">陽已入亦見西方何以徵之設月在黃道北五度太</span>  
<span style="margin-left: 2em">陽躔實沈一十五度本地北極高四十度即晝長<sub class="note-yuan">甲之</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">日也</sub>五十九刻<sub class="note-yuan">日九十六刻</sub>加一日刻<sub class="note-yuan">甲之夜乙之日</sub>共一百五十</span>  
<span style="margin-left: 2em">五刻<sub class="note-yuan">甲晨至乙夕</sub>于時月行約得二十三度平分之<sub class="note-yuan">合朔前後</sub></span>  
<span style="margin-left: 2em">得一十一度半以加實沈十五度<sub class="note-yuan">日躔也</sub>得實沈二十</span>  
<span style="margin-left: 2em">六度半是乙日日入時月之距日經度也以減十五</span>  
<span style="margin-left: 2em">度得實沈三度半是甲日日未出月之距日經度也</span>  
<span style="margin-left: 2em">日躔實沈十五度其斜升五十三度一十三分月離</span>  
<span style="margin-left: 2em">實沈三度半又北距五度其斜升三十六度半日月</span>  
<span style="margin-left: 2em">兩升度相減得一十六度四十三分爲甲日之晨日</span>  
<span style="margin-left: 2em">月赤道上出地平之差<sub class="note-yuan">月先日後</sub>變時爲月出四刻半而</span>  
<span style="margin-left: 2em">日出得見月東方也乙日太陽正降爲九十五度月</span>  
<span style="margin-left: 2em">離實沈二十六度半其正降爲一百一十三度兩降</span>  
<span style="margin-left: 2em">度相減得一十八度爲乙日之夕日月赤道上入地</span>  
<span style="margin-left: 2em">平之差<sub class="note-yuan">日先月後</sub>變時爲日入五刻而月入得見月西方</span>  
<span style="margin-left: 2em">也　若日躔冬至月離黃道南推日月出入之差不</span>  
<span style="margin-left: 2em">過八度變時爲二刻則不見</span>  
<span style="margin-left: 2em">一系凡極出地愈高愈疾見因斜升度之差爲多否</span>  
<span style="margin-left: 2em">則遲見</span>  
<span style="margin-left: 2em">二系極甚高朔後數日不見</span>  
<span style="margin-left: 2em">三系月距黃道南五度若極出地六十二度月盡夜</span>  
<span style="margin-left: 2em">不見</span>  
<span style="margin-left: 2em">四系極甚高合朔在午正則一日之間晨見東方夕</span>  
<span style="margin-left: 2em">見西方如極高五十二度躔離度同上推得日月升</span>  
<span style="margin-left: 2em">降差一十二度時爲三刻皆在月見界之內</span>  
<span style="margin-left: 2em">五系既定月之見界爲距日十二升度亦可推遲見</span>  
<span style="margin-left: 2em">之日數如極出地四十度日躔降婁月南距五度推</span>  
<span style="margin-left: 2em">得兩斜升差爲一十二度即得月距日之經度爲四</span>  
<span style="margin-left: 2em">十度月行當三日有奇則朔後三日有奇而見月西</span>  
<span style="margin-left: 2em">方晦前亦如之</span>  
<span style="margin-left: 2em">三因之外又有兩因一曰朦朧分<sub class="note-yuan">即晨昏度一名昧爽黃昏</sub>日入</span>  
<span style="margin-left: 2em">地平下一十八度爲朦朧之未分因升降有正斜斜</span>  
<span style="margin-left: 2em">又有大小則月距日十二度有時得見有時不得見</span>  
<span style="margin-left: 2em">一曰氣清濁差如同是子正時有時見極微之星有</span>  
<span style="margin-left: 2em">時不得見四五等之星氣則使之其在月也亦然</span>  
<span style="margin-left: 1em">第二論月體　月體爲圓球何以知之凡圓體于諸體</span>  
<span style="margin-left: 2em">中爲最尊如天如日月星如地亦於萬象中爲最尊</span>  
<span style="margin-left: 2em">故應圓凡物之初體皆圓<sub class="note-yuan">如核如卵如胎</sub>諸大象皆始造時</span>  
<span style="margin-left: 2em">之初體故應圓又月之體半爲明半爲魄其明魄之</span>  
<span style="margin-left: 2em">界時爲弦直線時爲弧曲線若果平體何從得生弧</span>  
<span style="margin-left: 2em">線且既爲平面日照之宜全體發光如平面之鏡一</span>  
<span style="margin-left: 2em">向日即全面發光也月爲不然則非平面　試以人</span>  
<span style="margin-left: 2em">目居中置一燭東方稍遠置一球西方稍近相參直</span>  
<span style="margin-left: 2em">即見球全受光次不動目燭獨移球西南隅即見球</span>  
<span style="margin-left: 2em">大半爲明小半爲魄更移球正南必明魄各半其界</span>  
<span style="margin-left: 2em">爲直線更移得魄大明小更移正東必見全魄燭爲</span>  
<span style="margin-left: 2em">太陽目爲地爲人球爲太陰以近遠日爲光大小其</span>  
<span style="margin-left: 2em">明魄界半周之間爲直線者一而已餘皆弧線也</span>  
<span style="margin-left: 2em">論其體質非清非純虛實雜也故能映光不能透光</span>  
<span style="margin-left: 2em">能發光不能廻光何謂透光如水如玻璃水晶金剛</span>  
<span style="margin-left: 2em">石皆純清故能透光不止映光非惟不能廻光亦且</span>  
<span style="margin-left: 2em">不能發光何謂廻光如明鏡爲全實故能廻光不止</span>  
<span style="margin-left: 2em">發光非惟不能透光亦且不能映光月皆不然而虛</span>  
<span style="margin-left: 2em">實疎密介在其間故能映能發也　然則何似稍似</span>  
<span style="margin-left: 2em">於雲雲掩日月皆能映光質薄則光顯質厚則光微</span>  
<span style="margin-left: 2em">早日未出夕日已入照雲成霞霞照下土虹霓之屬</span>  
<span style="margin-left: 2em">本因雲氣而成光采是爲發光體實則光大體虛則</span>  
<span style="margin-left: 2em">光小月實似之獨雲之映光多發光少月之映光少</span>  
<span style="margin-left: 2em">發光多此爲異耳</span>  
<span style="margin-left: 1em">第三論月駁　月面不純一色如斑駁然昔人以爲山</span>  
<span style="margin-left: 2em">河大地之景不然也山河大地之體東西不等云何</span>  
<span style="margin-left: 2em">月中之景時時不變乎然則如何此有二說一曰月</span>  
<span style="margin-left: 2em">本圓體特其體中疎密虛實不得純一不能如鏡光</span>  
<span style="margin-left: 2em">合體廻返所受之光第因其本質所至自爲發光密</span>  
<span style="margin-left: 2em">實處發光大虛疎處發光微<sub class="note-yuan">如金剛石勝玻瓈玻瓈勝水其質疎密虛實不</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">等故</sub>凡大光明中間有弱光可指則曰大光中之駁點</span>  
<span style="margin-left: 2em">也如大赤霞中間有淡紅可指則曰大赤中之駁點</span>  
<span style="margin-left: 2em">也是故名爲月駁也一曰月體如地球實處如山谷</span>  
<span style="margin-left: 2em">土田虛處如江海日出先照高山光甚顯次及田谷</span>  
<span style="margin-left: 2em">江海漸微如人登大高山視下土崇卑其明昧互相</span>  
<span style="margin-left: 2em">容也試用遠鏡窺月生明以後初日見光界外別有</span>  
<span style="margin-left: 2em">光明微點若海中島嶼然次日光長魄消<sub class="note-yuan">日漸遠明漸生如人</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">上山漸遠漸見所未見</sub>則見初日之點或合于大光或較昨加</span>  
<span style="margin-left: 2em">大或魄中更生他點<sub class="note-yuan">如日出地先照山顛次照平疇等</sub>以光先後知</span>  
<span style="margin-left: 2em">月面高庳此其徵已</span>  
<span style="margin-left: 1em">第四論月光　太陽爲萬光之原本其體至實<sub class="note-yuan">光大小</sub></span>  
<span style="margin-left: 6em">　<sub class="note-yuan">如體虛</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">實如煉鐵之光大于煉炭之光鐵體實于炭也</sub>其質極地<sub class="note-yuan">質不純者光亦不純則不能大</sub>其</span>  
<span style="margin-left: 2em">體爲全球曲面<sub class="note-yuan">凡發光者不論曲面直面必須順平若凹凸之面不能發大光稍有偏欹</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">光則相奪亦不能大</sub>故在大圜中爲大光之獨體月及經緯諸</span>  
<span style="margin-left: 2em">星之光皆從禀受焉<sub class="note-yuan">月借日光古語則然</sub>何以明之如月食甚</span>  
<span style="margin-left: 2em">時地球隔太陽之光露光極微目所難見一也日食</span>  
<span style="margin-left: 2em">甚時月在日與人目之間月之下魄不受日光人目</span>  
<span style="margin-left: 2em">見之則爲黑色二也</span>  
<span style="margin-left: 2em">問月既無光乃兩食甚時亦有淡光此爲何故曰體</span>  
<span style="margin-left: 2em">實無光而能受光而能發光兩食之時不受日光而</span>  
<span style="margin-left: 2em">經緯諸星亦能映照相受相發因生微光矣</span>  
<span style="margin-left: 2em">月光有二一爲對日而發光名曰正光一爲日光不</span>  
<span style="margin-left: 2em">至而從所受之處相映發爲微光名曰次光</span>  
<span style="margin-left: 2em">問月近日人見光小遠日人見光大何故曰月合朔</span>  
<span style="margin-left: 2em">時外大半受光<sub class="note-yuan">日體大月體小則日必照月之大半</sub>人自下土止視其</span>  
<span style="margin-left: 2em">內小半則無光既而生明所見漸大至一象限則己</span>  
<span style="margin-left: 9em">見其受光之大半故漸遠漸大也</span>  
<span style="margin-left: 9em">何謂日照月之大半如圖甲爲日</span>  
<span style="margin-left: 9em">乙爲月戊丁己丙兩光線切月體</span>  
<span style="margin-left: 2em">從丙從丁向乙作兩垂線成戊丁乙己丙乙兩直角</span>

<span style="margin-left: 2em">行兩線其內兩角并與兩直角等反之若兩直線不</span>
