<span style="margin-left: 2em">太阴小论第二十八</span>  
<span style="margin-left: 1em">第一论太阴晦朔伏见　太阴晦朔伏见古今立论疏</span>  
<span style="margin-left: 2em">密逈殊汉儒洪范传曰晦而月见西方谓之朏<sub class="note-yuan">亦曰朓</sub></span>  
<span style="margin-left: 2em">朏者政缓所致朔而月见东方谓之侧匿侧匿者政</span>  
<span style="margin-left: 2em">急所致夫晦在朔后晦失也朔在晦前朔失也历则</span>  
<span style="margin-left: 2em">失之而归咎于政诬甚矣唐历家以晦日之晨月见</span>  
<span style="margin-left: 2em">东方因立进朔之法使月隐晦晨明藏朔夕此则钩</span>  
<span style="margin-left: 2em">索未能而妄生迁变使月有两朔食乃在晦将谁欺</span>  
<span style="margin-left: 2em">乎宋元史皆非之颇为辨晰然未能缕形其所以然</span>  
<span style="margin-left: 2em">也夫月距晦朔见有疾迟因乎天度因乎地度即此</span>  
<span style="margin-left: 2em">方近处合朔于亥子之交而甲日之晨乙日之夕两</span>  
<span style="margin-left: 2em">见微明亦时有之此之进退将安往焉况海以南数</span>  
<span style="margin-left: 2em">千里则有甲晨乙夕终岁恒见者漠以北数千里则</span>  
<span style="margin-left: 2em">有朔在午中朝暮皆见者亦将使晨隐夕藏其可得</span>  
<span style="margin-left: 2em">乎今法若时若地应速应迟皆从筹算可密推用仪</span>  
<span style="margin-left: 2em">器可指数先事可豫言临时可确按又何庸转移避</span>  
<span style="margin-left: 2em">就为也以此备述所繇征之度数如下论</span>  
<span style="margin-left: 2em">问太阴合朔以后恒以三日见于西方亦有二日者</span>  
<span style="margin-left: 2em">其在晦以前亦如之何故曰是其因有三　一因赤</span>  
<span style="margin-left: 2em">道上之黄道升降度有正有斜正升则斜降斜升则</span>  
<span style="margin-left: 2em">正降正升斜降者秋半周六宫<sub class="note-yuan">秋分左右各三宫</sub>是也斜升</span>  
<span style="margin-left: 2em">正降者春半周六宫<sub class="note-yuan">春分左右各三宫</sub>是也<sub class="note-yuan">皆论斜球非正平球</sub>正升</span>  
<span style="margin-left: 2em">者赤道之升度多黄道之升度少正降者赤道之降</span>  
<span style="margin-left: 2em">数多黄道之降数少斜升斜降则反是<sub class="note-yuan">凡南极出地者与上论悉</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">相反</sub>若太阴离正降六宫则朔后疾见若离斜降六宫</span>  
<span style="margin-left: 2em">则朔后迟见其在晦前亦如之离正升六宫则迟隐</span>  
<span style="margin-left: 2em">离斜升六宫则疾隐也如二图各有子午圈有地平</span>  
<span style="margin-left: 2em">有极出地等有黄道宫次二图上图月离大梁为正</span>  
<span style="margin-left: 2em">降宫次距太阳十五度日入月在地平上为十三度</span>  
<span style="margin-left: 2em">半即能见下图月离大火为斜降宫次距太阳十五</span>  
<span style="margin-left: 2em">度日入月在地平上为十度即不能见一也　一因</span>  
<span style="margin-left: 2em">白道南北如图设月距黄道五度距太阳皆十五度</span>  
<span style="margin-left: 2em">而纬分南北<sub class="note-yuan">日月各有一日所行之轨道即赤道距等圈也今如图设黄道左右五度各一</sub></span>  
<span style="margin-left: 8em"><sub class="note-yuan">圜交于距等月在焉两月各至地平其弧有大小则入地有先后人见有</sub></span>  
<span style="margin-left: 8em"><sub class="note-yuan">迟速</sub>若在北即入地后黄道疾见若在</span>  
<span style="margin-left: 8em">南即入地先黄道迟见二也　一因</span>  
<span style="margin-left: 8em">月视行度若视行为迟段则朔后见</span>  
<span style="margin-left: 8em">月迟为疾段则朔后见月疾三也</span>  
<span style="margin-left: 2em">右第一因月之见界以十五度为限其疾者朔后一</span>  
<span style="margin-left: 2em">日又四分日之一而见也若三因并合又不待此如</span>  
<span style="margin-left: 2em">合朔在亥子间则甲日太阳未出亦见东方乙日太</span>  
<span style="margin-left: 2em">阳已入亦见西方何以征之设月在黄道北五度太</span>  
<span style="margin-left: 2em">阳躔实沈一十五度本地北极高四十度即昼长<sub class="note-yuan">甲之</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">日也</sub>五十九刻<sub class="note-yuan">日九十六刻</sub>加一日刻<sub class="note-yuan">甲之夜乙之日</sub>共一百五十</span>  
<span style="margin-left: 2em">五刻<sub class="note-yuan">甲晨至乙夕</sub>于时月行约得二十三度平分之<sub class="note-yuan">合朔前后</sub></span>  
<span style="margin-left: 2em">得一十一度半以加实沈十五度<sub class="note-yuan">日躔也</sub>得实沈二十</span>  
<span style="margin-left: 2em">六度半是乙日日入时月之距日经度也以减十五</span>  
<span style="margin-left: 2em">度得实沈三度半是甲日日未出月之距日经度也</span>  
<span style="margin-left: 2em">日躔实沈十五度其斜升五十三度一十三分月离</span>  
<span style="margin-left: 2em">实沈三度半又北距五度其斜升三十六度半日月</span>  
<span style="margin-left: 2em">两升度相减得一十六度四十三分为甲日之晨日</span>  
<span style="margin-left: 2em">月赤道上出地平之差<sub class="note-yuan">月先日后</sub>变时为月出四刻半而</span>  
<span style="margin-left: 2em">日出得见月东方也乙日太阳正降为九十五度月</span>  
<span style="margin-left: 2em">离实沈二十六度半其正降为一百一十三度两降</span>  
<span style="margin-left: 2em">度相减得一十八度为乙日之夕日月赤道上入地</span>  
<span style="margin-left: 2em">平之差<sub class="note-yuan">日先月后</sub>变时为日入五刻而月入得见月西方</span>  
<span style="margin-left: 2em">也　若日躔冬至月离黄道南推日月出入之差不</span>  
<span style="margin-left: 2em">过八度变时为二刻则不见</span>  
<span style="margin-left: 2em">一系凡极出地愈高愈疾见因斜升度之差为多否</span>  
<span style="margin-left: 2em">则迟见</span>  
<span style="margin-left: 2em">二系极甚高朔后数日不见</span>  
<span style="margin-left: 2em">三系月距黄道南五度若极出地六十二度月尽夜</span>  
<span style="margin-left: 2em">不见</span>  
<span style="margin-left: 2em">四系极甚高合朔在午正则一日之间晨见东方夕</span>  
<span style="margin-left: 2em">见西方如极高五十二度躔离度同上推得日月升</span>  
<span style="margin-left: 2em">降差一十二度时为三刻皆在月见界之内</span>  
<span style="margin-left: 2em">五系既定月之见界为距日十二升度亦可推迟见</span>  
<span style="margin-left: 2em">之日数如极出地四十度日躔降娄月南距五度推</span>  
<span style="margin-left: 2em">得两斜升差为一十二度即得月距日之经度为四</span>  
<span style="margin-left: 2em">十度月行当三日有奇则朔后三日有奇而见月西</span>  
<span style="margin-left: 2em">方晦前亦如之</span>  
<span style="margin-left: 2em">三因之外又有两因一曰朦胧分<sub class="note-yuan">即晨昏度一名昧爽黄昏</sub>日入</span>  
<span style="margin-left: 2em">地平下一十八度为朦胧之未分因升降有正斜斜</span>  
<span style="margin-left: 2em">又有大小则月距日十二度有时得见有时不得见</span>  
<span style="margin-left: 2em">一曰气清浊差如同是子正时有时见极微之星有</span>  
<span style="margin-left: 2em">时不得见四五等之星气则使之其在月也亦然</span>  
<span style="margin-left: 1em">第二论月体　月体为圆球何以知之凡圆体于诸体</span>  
<span style="margin-left: 2em">中为最尊如天如日月星如地亦于万象中为最尊</span>  
<span style="margin-left: 2em">故应圆凡物之初体皆圆<sub class="note-yuan">如核如卵如胎</sub>诸大象皆始造时</span>  
<span style="margin-left: 2em">之初体故应圆又月之体半为明半为魄其明魄之</span>  
<span style="margin-left: 2em">界时为弦直线时为弧曲线若果平体何从得生弧</span>  
<span style="margin-left: 2em">线且既为平面日照之宜全体发光如平面之镜一</span>  
<span style="margin-left: 2em">向日即全面发光也月为不然则非平面　试以人</span>  
<span style="margin-left: 2em">目居中置一烛东方稍远置一球西方稍近相参直</span>  
<span style="margin-left: 2em">即见球全受光次不动目烛独移球西南隅即见球</span>  
<span style="margin-left: 2em">大半为明小半为魄更移球正南必明魄各半其界</span>  
<span style="margin-left: 2em">为直线更移得魄大明小更移正东必见全魄烛为</span>  
<span style="margin-left: 2em">太阳目为地为人球为太阴以近远日为光大小其</span>  
<span style="margin-left: 2em">明魄界半周之间为直线者一而已余皆弧线也</span>  
<span style="margin-left: 2em">论其体质非清非纯虚实杂也故能映光不能透光</span>  
<span style="margin-left: 2em">能发光不能廻光何谓透光如水如玻璃水晶金刚</span>  
<span style="margin-left: 2em">石皆纯清故能透光不止映光非惟不能廻光亦且</span>  
<span style="margin-left: 2em">不能发光何谓廻光如明镜为全实故能廻光不止</span>  
<span style="margin-left: 2em">发光非惟不能透光亦且不能映光月皆不然而虚</span>  
<span style="margin-left: 2em">实疎密介在其间故能映能发也　然则何似稍似</span>  
<span style="margin-left: 2em">于云云掩日月皆能映光质薄则光显质厚则光微</span>  
<span style="margin-left: 2em">早日未出夕日已入照云成霞霞照下土虹霓之属</span>  
<span style="margin-left: 2em">本因云气而成光采是为发光体实则光大体虚则</span>  
<span style="margin-left: 2em">光小月实似之独云之映光多发光少月之映光少</span>  
<span style="margin-left: 2em">发光多此为异耳</span>  
<span style="margin-left: 1em">第三论月驳　月面不纯一色如斑驳然昔人以为山</span>  
<span style="margin-left: 2em">河大地之景不然也山河大地之体东西不等云何</span>  
<span style="margin-left: 2em">月中之景时时不变乎然则如何此有二说一曰月</span>  
<span style="margin-left: 2em">本圆体特其体中疎密虚实不得纯一不能如镜光</span>  
<span style="margin-left: 2em">合体廻返所受之光第因其本质所至自为发光密</span>  
<span style="margin-left: 2em">实处发光大虚疎处发光微<sub class="note-yuan">如金刚石胜玻瓈玻瓈胜水其质疎密虚实不</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">等故</sub>凡大光明中间有弱光可指则曰大光中之驳点</span>  
<span style="margin-left: 2em">也如大赤霞中间有淡红可指则曰大赤中之驳点</span>  
<span style="margin-left: 2em">也是故名为月驳也一曰月体如地球实处如山谷</span>  
<span style="margin-left: 2em">土田虚处如江海日出先照高山光甚显次及田谷</span>  
<span style="margin-left: 2em">江海渐微如人登大高山视下土崇卑其明昧互相</span>  
<span style="margin-left: 2em">容也试用远镜窥月生明以后初日见光界外别有</span>  
<span style="margin-left: 2em">光明微点若海中岛屿然次日光长魄消<sub class="note-yuan">日渐远明渐生如人</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">上山渐远渐见所未见</sub>则见初日之点或合于大光或较昨加</span>  
<span style="margin-left: 2em">大或魄中更生他点<sub class="note-yuan">如日出地先照山颠次照平畴等</sub>以光先后知</span>  
<span style="margin-left: 2em">月面高庳此其征已</span>  
<span style="margin-left: 1em">第四论月光　太阳为万光之原本其体至实<sub class="note-yuan">光大小</sub></span>  
<span style="margin-left: 6em">　<sub class="note-yuan">如体虚</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">实如炼铁之光大于炼炭之光铁体实于炭也</sub>其质极地<sub class="note-yuan">质不纯者光亦不纯则不能大</sub>其</span>  
<span style="margin-left: 2em">体为全球曲面<sub class="note-yuan">凡发光者不论曲面直面必须顺平若凹凸之面不能发大光稍有偏欹</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">光则相夺亦不能大</sub>故在大圜中为大光之独体月及经纬诸</span>  
<span style="margin-left: 2em">星之光皆从禀受焉<sub class="note-yuan">月借日光古语则然</sub>何以明之如月食甚</span>  
<span style="margin-left: 2em">时地球隔太阳之光露光极微目所难见一也日食</span>  
<span style="margin-left: 2em">甚时月在日与人目之间月之下魄不受日光人目</span>  
<span style="margin-left: 2em">见之则为黑色二也</span>  
<span style="margin-left: 2em">问月既无光乃两食甚时亦有淡光此为何故曰体</span>  
<span style="margin-left: 2em">实无光而能受光而能发光两食之时不受日光而</span>  
<span style="margin-left: 2em">经纬诸星亦能映照相受相发因生微光矣</span>  
<span style="margin-left: 2em">月光有二一为对日而发光名曰正光一为日光不</span>  
<span style="margin-left: 2em">至而从所受之处相映发为微光名曰次光</span>  
<span style="margin-left: 2em">问月近日人见光小远日人见光大何故曰月合朔</span>  
<span style="margin-left: 2em">时外大半受光<sub class="note-yuan">日体大月体小则日必照月之大半</sub>人自下土止视其</span>  
<span style="margin-left: 2em">内小半则无光既而生明所见渐大至一象限则己</span>  
<span style="margin-left: 9em">见其受光之大半故渐远渐大也</span>  
<span style="margin-left: 9em">何谓日照月之大半如图甲为日</span>
