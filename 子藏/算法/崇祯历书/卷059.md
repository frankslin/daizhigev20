<span style="margin-left: 2em">日月本行图第一</span>

<span style="margin-left: 2em">朔望者交食时必在其本轮内圈之周也</span>  
<span style="margin-left: 3em">太阳本行图</span>  
<span style="margin-left: 1em">甲为地球在天心其大小之比例难可计算略言之则</span>  
<span style="margin-left: 2em">地之与天若尺土之与大地也如图外大圈为黄道</span>  
<span style="margin-left: 2em">与地同心内圈为太阳本天其心在乙乙之离地心</span>  
<span style="margin-left: 2em">依第谷算为全数十万分之三千五百八十四约之</span>  
<span style="margin-left: 7em">为百分之三有半也其最高今时在鹑</span>  
<span style="margin-left: 7em">首宫六度为丙太阳右行从辛过丙一</span>  
<span style="margin-left: 7em">周天而复于辛为三百六十五日二十</span>  
<span style="margin-left: 7em">三刻三分四十八秒是谓岁实任躔某</span>  
<span style="margin-left: 7em">宫某度分皆以地心甲为主而地心所</span>  
<span style="margin-left: 2em">出直线至戊黄道指为太阳之实行其平行则又以</span>  
<span style="margin-left: 2em">本圜之乙心为主故人在地所测之实行时速时迟</span>  
<span style="margin-left: 2em">而太阳因最高在北平分本圈<sub class="note-jiao">校：清刊本平分作任分</sub>则北为</span>  
<span style="margin-left: 2em">大半故北六宫之日数多于南六宫几八日有奇也</span>  
<span style="margin-left: 2em">依此见求太阳之躔度必用两法一者定其平行如</span>  
<span style="margin-left: 2em">随乙丁己直线窥之从乙心见黄道上之己点二者</span>  
<span style="margin-left: 2em">定其实行如随甲丁戊窥之乃从地心见黄道上之</span>  
<span style="margin-left: 2em">戊点先得其平行又以加减求实行而平实之差为</span>  
<span style="margin-left: 2em">戊己弧以甲丁乙三角形求之即得也其自丙过秋</span>  
<span style="margin-left: 2em">分至庚两行之差必减平行而得实行自庚过辛春</span>  
<span style="margin-left: 2em">分至丙则加于平行而得实行若用表则从丙最高</span>  
<span style="margin-left: 2em">起算或从庚最庳起算至日体之本度为引数以求</span>  
<span style="margin-left: 2em">加减之度</span>  
<span style="margin-left: 3em">太阴朔望本行图</span>  
<span style="margin-left: 1em">月离之术依歌白泥论有本圜有本轮有次轮本轮之</span>  
<span style="margin-left: 2em">心依本圈之边满一转即次轮之心依本轮之边得</span>  
<span style="margin-left: 2em">两转故朔望时月体皆在次轮之最近最近者近于</span>  
<span style="margin-left: 2em">本轮之心也因是不用次轮但以最近处为界得圆</span>  
<span style="margin-left: 2em">圈月离历指谓为本轮之内圈此可名朔望之小轮</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 2em">假如丙丁戊为太阴朔望时之本圈则与地同心<sub class="note-yuan">因无</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">差故设为同心</sub>本轮为乙丙丁其心在本圜之边甲右距日</span>  
<span style="margin-left: 2em">得每日十二度一十一分其最高在乙最庳在己月</span>  
<span style="margin-left: 2em">体则又居次之边左行自乙至丙而己而丁谓之引</span>  
<span style="margin-left: 1em">数最外有黄道为辛庚若从地心出直线上至黄道而</span>  
<span style="margin-left: 9em">次轮心正居此线之上则所指者</span>  
<span style="margin-left: 9em">为太阴之平行度分也又从地心</span>  
<span style="margin-left: 9em">出直线上至黄道而月体正居此</span>  
<span style="margin-left: 9em">线之上则所</span>  
<span style="margin-left: 9em">指者为太阴实行度分也凡月转</span>  
<span style="margin-left: 2em">或在高或在庳正当一宫初度<sub class="note-yuan">乙也</sub>或七宫初度<sub class="note-yuan">己也</sub>则</span>  
<span style="margin-left: 2em">平行即是实行过此必有两行之差则以差数加减</span>  
<span style="margin-left: 2em">于平行度分得其实行度分又月在乙丙己半转则</span>  
<span style="margin-left: 2em">以减得之若在己丁乙半转则以加得之以在朔望</span>  
<span style="margin-left: 2em">故平实行相距之极大差不过四度五十八分二十</span>  
<span style="margin-left: 2em">七秒<sub class="note-yuan">甲丙甲丁是也</sub>过此为两弦之差则更少与交食无与</span>  
<span style="margin-left: 2em">月离历详之若用不同心圈论则并不用此本轮其</span>  
<span style="margin-left: 2em">加减平行度分而得实行度分理则一也　因日月</span>  
<span style="margin-left: 2em">以平实分本行故平朔平望时两体未必正相合正</span>  
<span style="margin-left: 2em">相对凡实会之或先或后日月各以其平行直线相</span>  
<span style="margin-left: 2em">遇而合为一直线则是中会</span>  
<span style="margin-left: 2em">实会中会视会第二</span>  
<span style="margin-left: 1em">测天约说言日月之行有隅照<sub class="note-yuan">相距三之一</sub>有方照<sub class="note-yuan">相距四之一</sub></span>  
<span style="margin-left: 2em">有六合照<sub class="note-yuan">相距六之一</sub>然悉无交食而独相会<sub class="note-yuan">朔也亦名合会</sub>相</span>  
<span style="margin-left: 2em">对<sub class="note-yuan">望也亦名照会</sub>则能有食故本篇所论者止于相会相对</span>  
<span style="margin-left: 2em">也抑会者总名也细言之有实会有中会有视会三</span>  
<span style="margin-left: 2em">者皆为推步之原故言交食之术必先言相会相对</span>  
<span style="margin-left: 2em">言相会相对之理必从实会中会始</span>  
<span style="margin-left: 3em">实会中会以地心为主</span>  
<span style="margin-left: 1em">实会者以地心所出直线上至黄道者为主而日月五</span>  
<span style="margin-left: 2em">星两居此线之上则实会也即南北相距非同一点</span>  
<span style="margin-left: 2em">而总在此线正对之过黄极圈亦为实会盖过黄极</span>  
<span style="margin-left: 2em">圈者过黄道之两极而交会于黄道分黄道为四直</span>  
<span style="margin-left: 2em">角者也则从旁视之虽地心各出一线南北异纬从</span>  
<span style="margin-left: 2em">黄极视之即见地心所出二线东西同经是南北正</span>  
<span style="margin-left: 2em">对如一线也是故谓之实会若月与五星各居其本</span>  
<span style="margin-left: 2em">轮之周地心所出线上至黄道而两本轮之心俱当</span>  
<span style="margin-left: 2em">此线之上则为月与五星之中会日无本轮本行圈</span>  
<span style="margin-left: 2em">与地为不同心两心所出则有两线此两线者若为</span>  
<span style="margin-left: 2em">平行线而月本轮之心正居地心线上则是日与月</span>  
<span style="margin-left: 2em">之中会也盖实会既以地心线射太阴之体为主则</span>  
<span style="margin-left: 2em">此地心线过小轮之心谓之中会矣若以不同心圈</span>  
<span style="margin-left: 2em">之平行线论之因日月各有本圈即本圈心皆与地</span>  
<span style="margin-left: 2em">心<sub class="note-yuan">即黄道心</sub>有相距之度分即日月循各本圈之周右行</span>  
<span style="margin-left: 2em">所过黄道经度必时时有差<sub class="note-yuan">与地不同心故也</sub>其从地心出</span>  
<span style="margin-left: 2em">直线过日月之体上至黄道此所指者为日月之实</span>

<span style="margin-left: 2em">出直线偕平行而上至黄道此所指者为日月之平</span>

<span style="margin-left: 2em">直线与太阴实行之直线合为一线则是日月之实</span>  
<span style="margin-left: 2em">相会合会望会皆有中有实其理不异</span>  
<span style="margin-left: 2em">先依小轮法作图甲为地心亦为黄道心亦为太阴</span>  
<span style="margin-left: 2em">本圈心<sub class="note-yuan">太阴与地同心者为用本轮故盖本轮周即太阴圈心绕地心之周其理一也</sub>乙为</span>  
<span style="margin-left: 2em">太阳本圈心<sub class="note-yuan">与地不同心</sub>太阳在丁太阴在戊甲戊丁线</span>  
<span style="margin-left: 2em">直至黄道圈得辛指日月实相会之度如太阳在丁</span>  
<span style="margin-left: 2em">太阴亦在甲辛直线上为庚而此线至黄道圈得丙</span>

<span style="margin-left: 2em">线之上乃过月本轮之心己而至黄道壬此直线所</span>  
<span style="margin-left: 2em">指则日月中相会之度也如月在庚从地心出平行</span>
