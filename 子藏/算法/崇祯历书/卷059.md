<span style="margin-left: 2em">日月本行圖第一</span>  
<span style="margin-left: 1em">日居本圈月居本輪行度參差因而有交食因而每食</span>  
<span style="margin-left: 2em">不同此略圖二曜本行以明交食之原月離圖獨言</span>  
<span style="margin-left: 2em">朔望者交食時必在其本輪內圈之周也</span>  
<span style="margin-left: 3em">太陽本行圖</span>  
<span style="margin-left: 1em">甲爲地球在天心其大小之比例難可計算略言之則</span>  
<span style="margin-left: 2em">地之與天若尺土之與大地也如圖外大圈爲黃道</span>  
<span style="margin-left: 2em">與地同心內圈爲太陽本天其心在乙乙之離地心</span>  
<span style="margin-left: 2em">依第谷算爲全數十萬分之三千五百八十四約之</span>  
<span style="margin-left: 7em">爲百分之三有半也其最高今時在鶉</span>  
<span style="margin-left: 7em">首宮六度爲丙太陽右行從辛過丙一</span>  
<span style="margin-left: 7em">周天而復于辛爲三百六十五日二十</span>  
<span style="margin-left: 7em">三刻三分四十八秒是謂歲實任躔某</span>  
<span style="margin-left: 7em">宮某度分皆以地心甲爲主而地心所</span>  
<span style="margin-left: 2em">出直線至戊黃道指爲太陽之實行其平行則又以</span>  
<span style="margin-left: 2em">本圜之乙心爲主故人在地所測之實行時速時遲</span>  
<span style="margin-left: 2em">而太陽因最高在北平分本圈<sub class="note-jiao">校：清刊本平分作任分</sub>則北爲</span>  
<span style="margin-left: 2em">大半故北六宮之日數多於南六宮幾八日有奇也</span>  
<span style="margin-left: 2em">依此見求太陽之躔度必用兩法一者定其平行如</span>  
<span style="margin-left: 2em">隨乙丁己直線窺之從乙心見黃道上之己點二者</span>  
<span style="margin-left: 2em">定其實行如隨甲丁戊窺之乃從地心見黃道上之</span>  
<span style="margin-left: 2em">戊點先得其平行又以加減求實行而平實之差爲</span>  
<span style="margin-left: 2em">戊己弧以甲丁乙三角形求之即得也其自丙過秋</span>  
<span style="margin-left: 2em">分至庚兩行之差必減平行而得實行自庚過辛春</span>  
<span style="margin-left: 2em">分至丙則加于平行而得實行若用表則從丙最高</span>  
<span style="margin-left: 2em">起算或從庚最庳起算至日體之本度爲引數以求</span>  
<span style="margin-left: 2em">加減之度</span>  
<span style="margin-left: 3em">太陰朔望本行圖</span>  
<span style="margin-left: 1em">月離之術依歌白泥論有本圜有本輪有次輪本輪之</span>  
<span style="margin-left: 2em">心依本圈之邊滿一轉即次輪之心依本輪之邊得</span>  
<span style="margin-left: 2em">兩轉故朔望時月體皆在次輪之最近最近者近於</span>  
<span style="margin-left: 2em">本輪之心也因是不用次輪但以最近處爲界得圓</span>  
<span style="margin-left: 2em">圈月離曆指謂爲本輪之內圈此可名朔望之小輪</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 2em">假如丙丁戊爲太陰朔望時之本圈則與地同心<sub class="note-yuan">因無</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">差故設爲同心</sub>本輪爲乙丙丁其心在本圜之邊甲右距日</span>  
<span style="margin-left: 2em">得每日十二度一十一分其最高在乙最庳在己月</span>  
<span style="margin-left: 2em">體則又居次之邊左行自乙至丙而己而丁謂之引</span>  
<span style="margin-left: 1em">數最外有黃道爲辛庚若從地心出直線上至黃道而</span>  
<span style="margin-left: 9em">次輪心正居此線之上則所指者</span>  
<span style="margin-left: 9em">爲太陰之平行度分也又從地心</span>  
<span style="margin-left: 9em">出直線上至黃道而月體正居此</span>  
<span style="margin-left: 9em">線之上則所</span>  
<span style="margin-left: 9em">指者爲太陰實行度分也凡月轉</span>  
<span style="margin-left: 2em">或在高或在庳正當一宮初度<sub class="note-yuan">乙也</sub>或七宮初度<sub class="note-yuan">己也</sub>則</span>  
<span style="margin-left: 2em">平行即是實行過此必有兩行之差則以差數加減</span>  
<span style="margin-left: 2em">于平行度分得其實行度分又月在乙丙己半轉則</span>  
<span style="margin-left: 2em">以減得之若在己丁乙半轉則以加得之以在朔望</span>  
<span style="margin-left: 2em">故平實行相距之極大差不過四度五十八分二十</span>  
<span style="margin-left: 2em">七秒<sub class="note-yuan">甲丙甲丁是也</sub>過此爲兩弦之差則更少與交食無與</span>  
<span style="margin-left: 2em">月離曆詳之若用不同心圈論則并不用此本輪其</span>  
<span style="margin-left: 2em">加減平行度分而得實行度分理則一也　因日月</span>  
<span style="margin-left: 2em">以平實分本行故平朔平望時兩體未必正相合正</span>  
<span style="margin-left: 2em">相對凡實會之或先或後日月各以其平行直線相</span>  
<span style="margin-left: 2em">遇而合爲一直線則是中會</span>  
<span style="margin-left: 2em">實會中會視會第二</span>  
<span style="margin-left: 1em">測天約說言日月之行有隅照<sub class="note-yuan">相距三之一</sub>有方照<sub class="note-yuan">相距四之一</sub></span>  
<span style="margin-left: 2em">有六合照<sub class="note-yuan">相距六之一</sub>然悉無交食而獨相會<sub class="note-yuan">朔也亦名合會</sub>相</span>  
<span style="margin-left: 2em">對<sub class="note-yuan">望也亦名照會</sub>則能有食故本篇所論者止于相會相對</span>  
<span style="margin-left: 2em">也抑會者總名也細言之有實會有中會有視會三</span>  
<span style="margin-left: 2em">者皆爲推步之原故言交食之術必先言相會相對</span>  
<span style="margin-left: 2em">言相會相對之理必從實會中會始</span>  
<span style="margin-left: 3em">實會中會以地心爲主</span>  
<span style="margin-left: 1em">實會者以地心所出直線上至黃道者爲主而日月五</span>  
<span style="margin-left: 2em">星兩居此線之上則實會也即南北相距非同一點</span>  
<span style="margin-left: 2em">而總在此線正對之過黃極圈亦爲實會蓋過黃極</span>  
<span style="margin-left: 2em">圈者過黃道之兩極而交會于黃道分黃道爲四直</span>  
<span style="margin-left: 2em">角者也則從旁視之雖地心各出一線南北異緯從</span>  
<span style="margin-left: 2em">黃極視之即見地心所出二線東西同經是南北正</span>  
<span style="margin-left: 2em">對如一線也是故謂之實會若月與五星各居其本</span>  
<span style="margin-left: 2em">輪之周地心所出線上至黃道而兩本輪之心俱當</span>  
<span style="margin-left: 2em">此線之上則爲月與五星之中會日無本輪本行圈</span>  
<span style="margin-left: 2em">與地爲不同心兩心所出則有兩線此兩線者若爲</span>  
<span style="margin-left: 2em">平行線而月本輪之心正居地心線上則是日與月</span>  
<span style="margin-left: 2em">之中會也蓋實會既以地心線射太陰之體爲主則</span>  
<span style="margin-left: 2em">此地心線過小輪之心謂之中會矣若以不同心圈</span>  
<span style="margin-left: 2em">之平行線論之因日月各有本圈即本圈心皆與地</span>  
<span style="margin-left: 2em">心<sub class="note-yuan">即黃道心</sub>有相距之度分即日月循各本圈之周右行</span>  
<span style="margin-left: 2em">所過黃道經度必時時有差<sub class="note-yuan">與地不同心故也</sub>其從地心出</span>  
<span style="margin-left: 2em">直線過日月之體上至黃道此所指者爲日月之實</span>  
<span style="margin-left: 2em">行度分也設從地心更出一平行直線與本圈心所</span>  
<span style="margin-left: 2em">出直線偕平行而上至黃道此所指者爲日月之平</span>  
<span style="margin-left: 2em">行度分也蓋太陽心線與地心一線平行太陰心線</span>  
<span style="margin-left: 2em">亦與地心一線平行恆時多不相遇至相遇時兩地</span>  
<span style="margin-left: 2em">心線合爲一線則是日月之中相會若太陽實行之</span>  
<span style="margin-left: 2em">直線與太陰實行之直線合爲一線則是日月之實</span>  
<span style="margin-left: 2em">相會合會望會皆有中有實其理不異</span>  
<span style="margin-left: 2em">先依小輪法作圖甲爲地心亦爲黃道心亦爲太陰</span>  
<span style="margin-left: 2em">本圈心<sub class="note-yuan">太陰與地同心者爲用本輪故蓋本輪周即太陰圈心繞地心之周其理一也</sub>乙爲</span>  
<span style="margin-left: 2em">太陽本圈心<sub class="note-yuan">與地不同心</sub>太陽在丁太陰在戊甲戊丁線</span>  
<span style="margin-left: 2em">直至黃道圈得辛指日月實相會之度如太陽在丁</span>  
<span style="margin-left: 2em">太陰亦在甲辛直線上爲庚而此線至黃道圈得丙</span>  
<span style="margin-left: 2em">即指日月實相望之度若太陰在癸與太陽不同一</span>  
<span style="margin-left: 2em">線之上乃過月本輪之心己而至黃道壬此直線所</span>  
<span style="margin-left: 2em">指則日月中相會之度也如月在庚從地心出平行</span>  
<span style="margin-left: 13em">線甲子與甲壬太陽平</span>  
<span style="margin-left: 13em">行爲一線而至黃道子</span>  
<span style="margin-left: 13em">亦指日月中相望之度</span>  
<span style="margin-left: 13em">矣</span>  
<span style="margin-left: 13em">次依不同心圈法如後</span>  
<span style="margin-left: 13em">圖黃道與太陽之本圈</span>  
<span style="margin-left: 13em">皆同前獨太陰無本輪</span>  
<span style="margin-left: 13em">而易爲本圈其心與地</span>  
<span style="margin-left: 13em">心不同在甲乃在丙此</span>  
<span style="margin-left: 13em">亦以日月並居一直線</span>  
<span style="margin-left: 13em">爲實會如太陽在丁太</span>  
<span style="margin-left: 13em">陰在本圈之邊戊地心</span>  
<span style="margin-left: 13em">所出甲戊丁線至辛則</span>  
<span style="margin-left: 13em">所指爲實會而正對月</span>  
<span style="margin-left: 13em">體至黃道寅則所指爲</span>  
<span style="margin-left: 13em">實望若中會中望則以</span>  
<span style="margin-left: 13em">平行線爲主蓋甲壬爲</span>  
<span style="margin-left: 13em">地心所出直線既偕太</span>  
<span style="margin-left: 13em">陽本圈心所出過日體</span>  
<span style="margin-left: 13em">之直線乙丁爲平行線</span>  
<span style="margin-left: 2em">又偕太陰本圈心所出過月體之直線丙庚爲平行</span>  
<span style="margin-left: 2em">線則是兩偕行之直線合爲一甲壬而至黃道故所</span>  
<span style="margin-left: 2em">指者爲日月中相會之度也其至相對之黃道上爲</span>  
<span style="margin-left: 2em">癸則所指者爲日月中相望之度設過此交會之時</span>  
<span style="margin-left: 2em">太陰在丑則月圈心出者爲丙丑線地心出者爲甲</span>  
<span style="margin-left: 2em">己線兩線自偕爲平行而甲壬與乙丁自偕爲平行</span>  
<span style="margin-left: 2em">甲壬甲己不得合爲一線矣故地心所出之兩偕行</span>  
<span style="margin-left: 2em">線能合爲一甲壬者必指中交之度爲日月相會之</span>  
<span style="margin-left: 2em">共界也</span>  
<span style="margin-left: 3em">實會中會相距無定度</span>  
<span style="margin-left: 1em">日月本圈各與地不同心故兩圈心所出直線各與地</span>  
<span style="margin-left: 2em">心所出直線雖恆爲平行線而又與地心所出直線</span>  
<span style="margin-left: 2em">其相距廣狹恆無定數設日在本圈之最高月在本</span>  
<span style="margin-left: 2em">圈之最庳其實行所至即平行所至則中會即實會</span>  
<span style="margin-left: 2em">矣或太陽在最庳太陰在最高或兩最高兩最庳在</span>  
<span style="margin-left: 2em">黃道上同度則中會實會亦皆無距度也惟日月去</span>  
<span style="margin-left: 2em">本圈之最高及最庳右行漸遠則地心所出平行直</span>  
<span style="margin-left: 2em">線漸相去至半圈周則甚相遠而爲實中兩會之相</span>  
<span style="margin-left: 2em">距最大差</span>  
<span style="margin-left: 2em">假如甲爲太陽之最高乙爲太陰之最庳若太陽在</span>  
<span style="margin-left: 2em">甲太陰在乙即兩本圈心及地心所出直線上至黃</span>  
<span style="margin-left: 9em">道皆合于甲乙線則實會無分于</span>  
<span style="margin-left: 9em">中會也若太陽至丙太陰至丁去</span>  
<span style="margin-left: 9em">最高各不甚遠則地心所出辛平</span>  
<span style="margin-left: 9em">行線距本圈心所出直線亦左右</span>  
<span style="margin-left: 9em">稍遠即中會亦稍遠于實會矣又</span>  
<span style="margin-left: 9em">使太陽在戊太陰在己則三直線</span>  
<span style="margin-left: 2em">相距更遠而實會中會相距亦更遠此則以太陽之</span>  
<span style="margin-left: 2em">引數九宮二度得戊辛弧二度三分一十五秒應減</span>  
<span style="margin-left: 2em">以太陰之引數八宮二十八度得辛庚弧四度五十</span>  
<span style="margin-left: 2em">八分二十七秒應加依法合之得戊庚弧七度〇一</span>  
<span style="margin-left: 2em">分四十二秒爲太陽太陰實會相距數</span>  
<span style="margin-left: 3em">實會中會互相隨因有變易</span>  
<span style="margin-left: 1em">實會與中會多不同時或中會在先實會在後或實會</span>
