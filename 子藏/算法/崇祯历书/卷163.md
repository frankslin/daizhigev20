<span style="margin-left: 3em">立象</span>  
<span style="margin-left: 1em">立象者何任所得时刻应何宫度依之以推定十二舍</span>  
<span style="margin-left: 2em">也而各舍所当居之度分并经纬诸曜皆从本度起</span>  
<span style="margin-left: 2em">算则此因时之变得天之容乃占验所繇以生第此</span>  
<span style="margin-left: 2em">中紧要在定每舍之初界<sub class="note-yuan">即初度</sub>举所应得分数绘以</span>  
<span style="margin-left: 2em">方图或圆形随点入星曜即浑天之象成矣法依本</span>  
<span style="margin-left: 2em">北极高安球以本日躔度与时盘午正较对始转球</span>  
<span style="margin-left: 2em">与盘将先所得时刻居子午圈下而本球宛然一当</span>  
<span style="margin-left: 2em">时之天象次于西地平识同居之赤道度并得相应</span>  
<span style="margin-left: 2em">之黄道度即第七舍初界次起半圈至赤道上距三</span>  
<span style="margin-left: 2em">十度之限所得黄道度乃第八舍初界递起递加尽</span>  
<span style="margin-left: 2em">得地平上各舍初界而地平下诸舍则以黄道相对</span>  
<span style="margin-left: 2em">处可定如一与七二与八三与九四与十五与十一</span>  
<span style="margin-left: 2em">六与十二之类是也假如崇祯九年正月十五日辛</span>  
<span style="margin-left: 2em">酉晓望月食顺天府食甚在卯正一刻〇二分日躔</span>  
<span style="margin-left: 2em">在娵訾宫一度五十三分因此时求各舍躔度先以</span>  
<span style="margin-left: 2em">日躔对时盘午正依法转仪得西地平交赤道一百</span>  
<span style="margin-left: 2em">五十〇度交黄道鹑火宫一十三度此即七舍初界</span>  
<span style="margin-left: 2em">正对东地平得玄枵宫一十三度为第一舍初界<sub class="note-yuan">即命</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">宫是</sub>上居天中得析木宫〇二度为第十舍初界正下</span>  
<span style="margin-left: 2em">得实沈宫〇二度为第四舍初界半圈交赤道一百</span>  
<span style="margin-left: 2em">八十度<sub class="note-yuan">距前数三十度</sub>得黄道寿星宫初度为第八舍初界</span>  
<span style="margin-left: 2em">正对之降娄初度起第二舍又以半圈交赤道二百</span>  
<span style="margin-left: 2em">一十度得大火宫九度为第九舍正对之大梁九度</span>  
<span style="margin-left: 2em">即第三舍后移半圈至子午圈之东得析木宫二十</span>  
<span style="margin-left: 2em">度为第十一舍星纪一十度为第十二舍而正对处</span>  
<span style="margin-left: 2em">即实沈鹑首相等之处为第五及第六舍因而上下</span>  
<span style="margin-left: 2em">左右四角<sub class="note-yuan">四角占验最得力处</sub>定矣复求纬星所居之舍或依</span>  
<span style="margin-left: 2em">表预算或径用推定七政细行则以本北极高及本</span>  
<span style="margin-left: 2em">时刻取各曜相应度分入其舍若星近舍初界有距</span>  
<span style="margin-left: 2em">度或可入前舍中必先以黄经纬安球上随以本曜</span>  
<span style="margin-left: 2em">所居之处求于本舍而以前所立象定球渐移半圈</span>  
<span style="margin-left: 2em">如法起舍乃星入前后界内者即得本舍是也若地</span>  
<span style="margin-left: 2em">平下各舍之星法起南极于架上与北极等高移前</span>  
<span style="margin-left: 2em">第一舍之初界至西地平而天容在地平下者反居</span>  
<span style="margin-left: 2em">地平上即得诸曜本舍之界如以鹑火十三度交西</span>  
<span style="margin-left: 2em">地平至寿星初度总弧内得前月食惟木星与太阴</span>  
<span style="margin-left: 2em">畧近查丙子年七政细行食甚时木星躔鹑火二十</span>  
<span style="margin-left: 2em">九度五十七分而火星则躔大火三度三十分应入</span>  
<span style="margin-left: 2em">八舍土星躔星纪一十一度三十分纬北三十四分</span>  
<span style="margin-left: 2em">必在十二舍之初界太阳金水二星皆在娵訾宫因</span>  
<span style="margin-left: 2em">同入命舍其土星依本经度惟纬北三十四分故得</span>  
<span style="margin-left: 2em">在十二舍之初界若距黄道北或一度半或二度试</span>  
<span style="margin-left: 2em">以舍圈限之必其已入十一舍因近顶纬多故也求</span>  
<span style="margin-left: 2em">恒星法同此盖此象一立则凡各曜性情势力强弱</span>  
<span style="margin-left: 2em">可考而知穷理之家借以观变于未然鲜有不验者</span>  
<span style="margin-left: 2em"><sub class="note-yuan">其法详天文卷中</sub></span>  
<span style="margin-left: 3em">求两星于立象圈上相合之时</span>  
<span style="margin-left: 1em">凡两星本各无力一合即增力此实足为所立象损益</span>  
<span style="margin-left: 2em">之原也故以初得某星某宫度主人生命等事者安</span>  
<span style="margin-left: 2em">东地平<sub class="note-yuan">依本地北极高</sub>即应查其与某星相合否盖转立象</span>  
<span style="margin-left: 2em">圈于球面上下得二星在通径上即命星在地平时</span>  
<span style="margin-left: 2em">其星必合否则令球与立象圈各自那转后求其当</span>  
<span style="margin-left: 2em">合时法必得二星能如此合遂识赤道交子午圈度</span>  
<span style="margin-left: 2em">次移本日躔度合子午圈并识其同居赤道度乃以</span>  
<span style="margin-left: 2em">前赤道交度减后赤道交度余度化为时刻即得二</span>  
<span style="margin-left: 2em">星应合之时如极高四十度一星在鹑尾宫二度距</span>  
<span style="margin-left: 2em">纬南三度又一星在本宫四度距纬北一度本日躔</span>  
<span style="margin-left: 2em">鹑首宫七度试转仪并半圈见子午圈西未合必过</span>  
<span style="margin-left: 2em">东近地平方可得合而合时赤道则以七十五度交</span>  
<span style="margin-left: 2em">子午圈便移日躔至子午圈下得同居赤道九十七</span>  
<span style="margin-left: 2em">度为前度所减<sub class="note-yuan">先借全周后减</sub>余三百三十八度化为时得</span>  
<span style="margin-left: 2em">二十二时二刻〇四分即二星去午时后合圈下之</span>  
<span style="margin-left: 2em">限</span>  
<span style="margin-left: 3em">求经纬星相照度</span>  
<span style="margin-left: 1em">凡两星相照增力或阻力多以向黄道为准大约有五</span>  
<span style="margin-left: 2em">等如会合即同度同分为密而同度不同分者则谓</span>  
<span style="margin-left: 2em">之疎六照以六十度为界四照止于一象限三照以</span>  
<span style="margin-left: 2em">四宫相距而云然望照则以正相对而得半圈之距</span>  
<span style="margin-left: 2em">乃此数照又各有亲或远者盖星体居正照之界即</span>  
<span style="margin-left: 2em">亲而力强若体未正居其界而第以光居之即远而</span>  
<span style="margin-left: 2em">力弱至若光之前后虽同而各星所定之限有异如</span>  
<span style="margin-left: 2em">土得十度<sub class="note-yuan">前十后十</sub>木十二度火八度太阳十七度金水</span>  
<span style="margin-left: 2em">皆七度太阴复十二度经星凡第一等有七度三十</span>  
<span style="margin-left: 2em">分二等五度三十分三等三度三十分四等一度三</span>  
<span style="margin-left: 2em">十分五六等最微力弱不入其数总之除会望二照</span>  
<span style="margin-left: 2em">余皆以顺十二宫为左照逆十二宫为右照试于仪</span>  
<span style="margin-left: 2em">上考之法用规器量黄道上任取一照之界<sub class="note-yuan">六十九十等度</sub></span>  
<span style="margin-left: 2em">以星为心于黄道左右分顺与逆照之限假如求大</span>  
<span style="margin-left: 2em">角四照以九十度为限将规一锐居本星体一锐指</span>  
<span style="margin-left: 2em">左界九十度必至星纪十七度为顺照指右界九十</span>  
<span style="margin-left: 2em">度必至鹑首十七度为逆照若七政必先依各经纬</span>  
<span style="margin-left: 2em">度安其本位余法同前又一法用立象半圈先依北</span>  
<span style="margin-left: 2em">极出地安球任取本时升度居地平乃移半圈径过</span>  
<span style="margin-left: 2em">其星依之于赤道上作识后转球从前所识赤道度</span>  
<span style="margin-left: 2em">相距三四等照界仍移半圈其上所指黄道度即星</span>  
<span style="margin-left: 2em">照所至界也假如升度在寿星十六度求轩辕大星</span>  
<span style="margin-left: 2em">六照限必移升度于东地平立象圈过星指赤道一</span>  
<span style="margin-left: 2em">百三十八度复加六十度应一百九十八度居立象</span>  
<span style="margin-left: 2em">圈即并得寿星宫十六度居本圈为轩辕大星六照</span>  
<span style="margin-left: 2em">之左限其右限则以反减六十度为法</span>  
<span style="margin-left: 3em">求岁旋</span>  
<span style="margin-left: 1em">凡从前所取时刻至太阳复躔元度分其中相去总数</span>  
<span style="margin-left: 2em">谓之岁旋盖依后时所立象较前象所得七政等星</span>  
<span style="margin-left: 2em">居舍内应增或阻前星之力即效验所繇变也法令</span>  
<span style="margin-left: 2em">球依前立象之时定住视赤道交子午圈若干度为</span>  
<span style="margin-left: 2em">前象天中升度今越若干年复求后象天中之升度</span>  
<span style="margin-left: 2em">必每去一岁加八十八度四十九分满全周则去之</span>  
<span style="margin-left: 2em">余数即后象赤道交子午圈度使之于本圈正合可</span>  
<span style="margin-left: 2em">得天容依岁旋之时因以定各舍宫度而各星安舍</span>  
<span style="margin-left: 2em">法亦同前假如崇祯元年正月酉正时立前象因太</span>

<span style="margin-left: 3em">引照元与增力元相合</span>  
<span style="margin-left: 1em">凡初得某星某宫居某舍因之以占所效是谓照元设</span>  
<span style="margin-left: 2em">更有一星或一宫所居舍能增力或阻前效即谓为</span>  
<span style="margin-left: 2em">增力元二元必各依定时著力乃就中求以前者至</span>  
<span style="margin-left: 2em">后之位或反以后者至前之位俱依赤道弧相应二</span>  
<span style="margin-left: 2em">元之距为限转球查其弧之大小为引则一度应一</span>  
<span style="margin-left: 2em">年度数既定应在何时亦可限矣故引后至前以顺</span>  
<span style="margin-left: 2em">宗动为正而引前至后则因五纬逆行时用之遂名</span>  
<span style="margin-left: 2em">曰反引皆于球上可得正引者何转球先依天象安</span>  
<span style="margin-left: 2em">定令黄道应第一舍初界之度正居东地平次查照</span>  
<span style="margin-left: 2em">元移象圈径过其上并识赤道合子午圈度又转球</span>  
<span style="margin-left: 2em">右行以增力元至半圈复识赤道交子午圈度则先</span>  
<span style="margin-left: 2em">后所识之间弧乃指正引限而总数可推年时也欲</span>
