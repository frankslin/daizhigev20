<span style="margin-left: 3em">立象</span>  
<span style="margin-left: 1em">立象者何任所得時刻應何宮度依之以推定十二舍</span>  
<span style="margin-left: 2em">也而各舍所當居之度分並經緯諸曜皆從本度起</span>  
<span style="margin-left: 2em">算則此因時之變得天之容乃占驗所繇以生第此</span>  
<span style="margin-left: 2em">中緊要在定每舍之初界<sub class="note-yuan">即初度</sub>舉所應得分數繪以</span>  
<span style="margin-left: 2em">方圖或圓形隨點入星曜即渾天之象成矣法依本</span>  
<span style="margin-left: 2em">北極高安球以本日躔度與時盤午正較對始轉球</span>  
<span style="margin-left: 2em">與盤將先所得時刻居子午圈下而本球宛然一當</span>  
<span style="margin-left: 2em">時之天象次于西地平識同居之赤道度並得相應</span>  
<span style="margin-left: 2em">之黃道度即第七舍初界次起半圈至赤道上距三</span>  
<span style="margin-left: 2em">十度之限所得黃道度乃第八舍初界遞起遞加盡</span>  
<span style="margin-left: 2em">得地平上各舍初界而地平下諸舍則以黃道相對</span>  
<span style="margin-left: 2em">處可定如一與七二與八三與九四與十五與十一</span>  
<span style="margin-left: 2em">六與十二之類是也假如崇禎九年正月十五日辛</span>  
<span style="margin-left: 2em">酉曉望月食順天府食甚在卯正一刻〇二分日躔</span>  
<span style="margin-left: 2em">在娵訾宮一度五十三分因此時求各舍躔度先以</span>  
<span style="margin-left: 2em">日躔對時盤午正依法轉儀得西地平交赤道一百</span>  
<span style="margin-left: 2em">五十〇度交黃道鶉火宮一十三度此即七舍初界</span>  
<span style="margin-left: 2em">正對東地平得玄枵宮一十三度爲第一舍初界<sub class="note-yuan">即命</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">宮是</sub>上居天中得析木宮〇二度爲第十舍初界正下</span>  
<span style="margin-left: 2em">得實沈宮〇二度爲第四舍初界半圈交赤道一百</span>  
<span style="margin-left: 2em">八十度<sub class="note-yuan">距前數三十度</sub>得黃道壽星宮初度爲第八舍初界</span>  
<span style="margin-left: 2em">正對之降婁初度起第二舍又以半圈交赤道二百</span>  
<span style="margin-left: 2em">一十度得大火宮九度爲第九舍正對之大梁九度</span>  
<span style="margin-left: 2em">即第三舍後移半圈至子午圈之東得析木宮二十</span>  
<span style="margin-left: 2em">度爲第十一舍星紀一十度爲第十二舍而正對處</span>  
<span style="margin-left: 2em">即實沈鶉首相等之處爲第五及第六舍因而上下</span>  
<span style="margin-left: 2em">左右四角<sub class="note-yuan">四角占驗最得力處</sub>定矣復求緯星所居之舍或依</span>  
<span style="margin-left: 2em">表預算或徑用推定七政細行則以本北極高及本</span>  
<span style="margin-left: 2em">時刻取各曜相應度分入其舍若星近舍初界有距</span>  
<span style="margin-left: 2em">度或可入前舍中必先以黃經緯安球上隨以本曜</span>  
<span style="margin-left: 2em">所居之處求于本舍而以前所立象定球漸移半圈</span>  
<span style="margin-left: 2em">如法起舍乃星入前後界內者即得本舍是也若地</span>  
<span style="margin-left: 2em">平下各舍之星法起南極于架上與北極等高移前</span>  
<span style="margin-left: 2em">第一舍之初界至西地平而天容在地平下者反居</span>  
<span style="margin-left: 2em">地平上即得諸曜本舍之界如以鶉火十三度交西</span>  
<span style="margin-left: 2em">地平至壽星初度總弧內得前月食惟木星與太陰</span>  
<span style="margin-left: 2em">畧近查丙子年七政細行食甚時木星躔鶉火二十</span>  
<span style="margin-left: 2em">九度五十七分而火星則躔大火三度三十分應入</span>  
<span style="margin-left: 2em">八舍土星躔星紀一十一度三十分緯北三十四分</span>  
<span style="margin-left: 2em">必在十二舍之初界太陽金水二星皆在娵訾宮因</span>  
<span style="margin-left: 2em">同入命舍其土星依本經度惟緯北三十四分故得</span>  
<span style="margin-left: 2em">在十二舍之初界若距黃道北或一度半或二度試</span>  
<span style="margin-left: 2em">以舍圈限之必其已入十一舍因近頂緯多故也求</span>  
<span style="margin-left: 2em">恆星法同此蓋此象一立則凡各曜性情勢力强弱</span>  
<span style="margin-left: 2em">可考而知窮理之家借以觀變于未然鮮有不驗者</span>  
<span style="margin-left: 2em"><sub class="note-yuan">其法詳天文卷中</sub></span>  
<span style="margin-left: 3em">求兩星于立象圈上相合之時</span>  
<span style="margin-left: 1em">凡兩星本各無力一合即增力此實足爲所立象損益</span>  
<span style="margin-left: 2em">之原也故以初得某星某宮度主人生命等事者安</span>  
<span style="margin-left: 2em">東地平<sub class="note-yuan">依本地北極高</sub>即應查其與某星相合否蓋轉立象</span>  
<span style="margin-left: 2em">圈于球面上下得二星在通徑上即命星在地平時</span>  
<span style="margin-left: 2em">其星必合否則令球與立象圈各自那轉後求其當</span>  
<span style="margin-left: 2em">合時法必得二星能如此合遂識赤道交子午圈度</span>  
<span style="margin-left: 2em">次移本日躔度合子午圈併識其同居赤道度乃以</span>  
<span style="margin-left: 2em">前赤道交度減後赤道交度餘度化爲時刻即得二</span>  
<span style="margin-left: 2em">星應合之時如極高四十度一星在鶉尾宮二度距</span>  
<span style="margin-left: 2em">緯南三度又一星在本宮四度距緯北一度本日躔</span>  
<span style="margin-left: 2em">鶉首宮七度試轉儀併半圈見子午圈西未合必過</span>  
<span style="margin-left: 2em">東近地平方可得合而合時赤道則以七十五度交</span>  
<span style="margin-left: 2em">子午圈便移日躔至子午圈下得同居赤道九十七</span>  
<span style="margin-left: 2em">度爲前度所減<sub class="note-yuan">先借全周後減</sub>餘三百三十八度化爲時得</span>  
<span style="margin-left: 2em">二十二時二刻〇四分即二星去午時後合圈下之</span>  
<span style="margin-left: 2em">限</span>  
<span style="margin-left: 3em">求經緯星相照度</span>  
<span style="margin-left: 1em">凡兩星相照增力或阻力多以向黃道爲準大約有五</span>  
<span style="margin-left: 2em">等如會合即同度同分爲密而同度不同分者則謂</span>  
<span style="margin-left: 2em">之疎六照以六十度爲界四照止于一象限三照以</span>  
<span style="margin-left: 2em">四宮相距而云然望照則以正相對而得半圈之距</span>  
<span style="margin-left: 2em">乃此數照又各有親或遠者蓋星體居正照之界即</span>  
<span style="margin-left: 2em">親而力强若體未正居其界而第以光居之即遠而</span>  
<span style="margin-left: 2em">力弱至若光之前後雖同而各星所定之限有異如</span>  
<span style="margin-left: 2em">土得十度<sub class="note-yuan">前十後十</sub>木十二度火八度太陽十七度金水</span>  
<span style="margin-left: 2em">皆七度太陰復十二度經星凡第一等有七度三十</span>  
<span style="margin-left: 2em">分二等五度三十分三等三度三十分四等一度三</span>  
<span style="margin-left: 2em">十分五六等最微力弱不入其數總之除會望二照</span>  
<span style="margin-left: 2em">餘皆以順十二宮爲左照逆十二宮爲右照試于儀</span>  
<span style="margin-left: 2em">上考之法用規器量黃道上任取一照之界<sub class="note-yuan">六十九十等度</sub></span>  
<span style="margin-left: 2em">以星爲心于黃道左右分順與逆照之限假如求大</span>  
<span style="margin-left: 2em">角四照以九十度爲限將規一銳居本星體一銳指</span>  
<span style="margin-left: 2em">左界九十度必至星紀十七度爲順照指右界九十</span>  
<span style="margin-left: 2em">度必至鶉首十七度爲逆照若七政必先依各經緯</span>  
<span style="margin-left: 2em">度安其本位餘法同前又一法用立象半圈先依北</span>  
<span style="margin-left: 2em">極出地安球任取本時升度居地平乃移半圈徑過</span>  
<span style="margin-left: 2em">其星依之于赤道上作識後轉球從前所識赤道度</span>  
<span style="margin-left: 2em">相距三四等照界仍移半圈其上所指黃道度即星</span>  
<span style="margin-left: 2em">照所至界也假如升度在壽星十六度求軒轅大星</span>  
<span style="margin-left: 2em">六照限必移升度于東地平立象圈過星指赤道一</span>  
<span style="margin-left: 2em">百三十八度復加六十度應一百九十八度居立象</span>  
<span style="margin-left: 2em">圈即併得壽星宮十六度居本圈爲軒轅大星六照</span>  
<span style="margin-left: 2em">之左限其右限則以反減六十度爲法</span>  
<span style="margin-left: 3em">求歲旋</span>  
<span style="margin-left: 1em">凡從前所取時刻至太陽復躔元度分其中相去總數</span>  
<span style="margin-left: 2em">謂之歲旋蓋依後時所立象較前象所得七政等星</span>  
<span style="margin-left: 2em">居舍內應增或阻前星之力即效驗所繇變也法令</span>  
<span style="margin-left: 2em">球依前立象之時定住視赤道交子午圈若干度爲</span>  
<span style="margin-left: 2em">前象天中升度今越若干年復求後象天中之升度</span>  
<span style="margin-left: 2em">必每去一歲加八十八度四十九分滿全周則去之</span>  
<span style="margin-left: 2em">餘數即後象赤道交子午圈度使之于本圈正合可</span>  
<span style="margin-left: 2em">得天容依歲旋之時因以定各舍宮度而各星安舍</span>  
<span style="margin-left: 2em">法亦同前假如崇禎元年正月酉正時立前象因太</span>  
<span style="margin-left: 2em">陽躔玄枵一十六度一十九分依法轉球令時盤酉</span>  
<span style="margin-left: 2em">正交子午圈得赤道交本圈之升度爲五十度設相</span>  
<span style="margin-left: 2em">去八年復立象爲崇禎八年十二月二十九日<sub class="note-yuan">太陽躔元</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">度是</sub>則以八乘八十八度四十九分去全周餘四十度</span>  
<span style="margin-left: 2em">三十三分爲後象之升度移居子午圈得本圈指酉</span>  
<span style="margin-left: 2em">初二刻爲歲旋之時如用立成表細求即後歲中先</span>  
<span style="margin-left: 2em">查太陽躔元度分之日爲歲旋終之日次以後象升</span>  
<span style="margin-left: 2em">度減太陽是日之升度<sub class="note-yuan">不足減借全周減之</sub>餘數化爲時刻分</span>  
<span style="margin-left: 2em">即得當日立象之時刻焉假如因十二月二十九日</span>  
<span style="margin-left: 2em">太陽躔元度爲歲旋終之日其升度三百一十八度</span>  
<span style="margin-left: 2em">四十八分後象升度四十度三十三分不足減借全</span>  
<span style="margin-left: 2em">周共得四百〇度三十三分減去前數餘八十一度</span>  
<span style="margin-left: 2em">四十五分化爲五小時一刻一十二分<sub class="note-yuan">從午正起算</sub></span>  
<span style="margin-left: 3em">加升度表</span>  
<span style="margin-left: 1em"><sub class="note-yuan">歲一一一一一一一一一一二三四五數一二三四五六七八九〇一二三四五六七八九〇〇〇〇</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">一二三一二三一二三一二三一二三一三一度八七六五八七六五七八五四七六五四六五四三四一二</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">八七六五四二一〇九六七五四三二一九八七六四二〇</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">四三二一〇五四三二一〇四三二一〇五四三二三四五分九八七六五四三三二一〇九八七六五四三二〇〇二三</sub></span>  
<span style="margin-left: 3em">引照元與增力元相合</span>  
<span style="margin-left: 1em">凡初得某星某宮居某舍因之以占所效是謂照元設</span>  
<span style="margin-left: 2em">更有一星或一宮所居舍能增力或阻前效即謂爲</span>  
<span style="margin-left: 2em">增力元二元必各依定時著力乃就中求以前者至</span>  
<span style="margin-left: 2em">後之位或反以後者至前之位俱依赤道弧相應二</span>  
<span style="margin-left: 2em">元之距爲限轉球查其弧之大小爲引則一度應一</span>  
<span style="margin-left: 2em">年度數既定應在何時亦可限矣故引後至前以順</span>  
<span style="margin-left: 2em">宗動爲正而引前至後則因五緯逆行時用之遂名</span>  
<span style="margin-left: 2em">曰反引皆于球上可得正引者何轉球先依天象安</span>  
<span style="margin-left: 2em">定令黃道應第一舍初界之度正居東地平次查照</span>  
<span style="margin-left: 2em">元移象圈徑過其上併識赤道合子午圈度又轉球</span>  
<span style="margin-left: 2em">右行以增力元至半圈復識赤道交子午圈度則先</span>  
<span style="margin-left: 2em">後所識之間弧乃指正引限而總數可推年時也欲</span>  
<span style="margin-left: 2em">反引安球令之轉同前惟立象圈宜先徑過增力元</span>  
<span style="margin-left: 2em">復識轉球時赤道過子午圈弧因以定其中相去之</span>  
<span style="margin-left: 2em">年假如北極高四十度設大梁十度在第一舍初界</span>  
<span style="margin-left: 2em">太陰離黃道娵訾二十度距北二度爲照元火星近</span>  
<span style="margin-left: 2em">東地平躔大梁六度距南三度爲增力元必先依各</span>  
<span style="margin-left: 2em">經緯度帶二曜于球上然後令象圈過太陰處所交</span>  
<span style="margin-left: 2em">赤道點約爲三百五十二度<sub class="note-yuan">用本圈與用子午圈同</sub>次定住象</span>  
<span style="margin-left: 2em">圈移火星與本圈正對約得赤道交圈點爲二十八</span>  
<span style="margin-left: 2em">度以所得前後度相減餘中弧爲三十六度即正引</span>  
<span style="margin-left: 2em">之限求反引法亦同但引限在地平下必先起南極</span>  
<span style="margin-left: 2em">依北極出地度令黃道第一舍初界之度正居西地</span>  
<span style="margin-left: 2em">平餘法同前<sub class="note-yuan">見前第二卷</sub></span>  
<span style="margin-left: 3em">求引二元應止黃道何度</span>  
<span style="margin-left: 1em">因照元漸離初得之象圈乃更有黃道相應故任至某</span>  
<span style="margin-left: 2em">年亦可求其相應度法先安球依本象令象圈與照</span>  
<span style="margin-left: 2em">元合隨查赤道交子午圈度因之順或逆取本度與</span>  
<span style="margin-left: 2em">年數所止限移至子午圈必此時交象圈黃道度即</span>  
<span style="margin-left: 2em">其年所引照元止限也如北極高四十度設壽星十</span>  
<span style="margin-left: 2em">六度東出太陽躔玄枵六度爲照元依去四十二年</span>  
<span style="margin-left: 2em">之數復求躔度因安壽星十六度于本地平安象圈</span>  
<span style="margin-left: 2em">于鶉火六度<sub class="note-yuan">與玄枵對度因後在地平下故</sub>得子午圈交赤道一百</span>  
<span style="margin-left: 2em">一十度以加四十二度依之應一百五十二度交子</span>  
<span style="margin-left: 2em">午圈得象圈交鶉尾一十六度即娵訾一十六度<sub class="note-yuan">正對</sub></span>

<span style="margin-left: 2em">照元所止度設壽星十六度爲照元而出地平者亦</span>  
<span style="margin-left: 2em">即此度則得地平交赤道二百零一度令球右轉以</span>  
<span style="margin-left: 2em">赤道四十三度至地平則所并居之大火十九度即</span>  
<span style="margin-left: 2em">爲照元任取之年後止限又設增力元亦居地平等</span>  
<span style="margin-left: 2em">角即以同居赤道度減年數之度所止限復移至地</span>  
<span style="margin-left: 2em">平等角亦即得黃道交地平等角爲其當年所至之</span>  
<span style="margin-left: 2em">限或增力元不正居角仍用象圈與之交并識其所</span>  
<span style="margin-left: 2em">過赤道度減總年數餘度限移至本象圈復得并交</span>  
<span style="margin-left: 2em">黃道度爲增力元當年之限也</span>  
<span style="margin-left: 3em">依渾儀解圓線三角形</span>  
<span style="margin-left: 1em">圓線三角形者何乃過球心大圈相交三弧之形而各</span>  
<span style="margin-left: 2em">弧不及圈之半周所成也蓋形內每兩弧共抱一角</span>  
<span style="margin-left: 2em">在間者謂之腰弧而與角相對之弧即底弧或又謂</span>  
<span style="margin-left: 2em">直角三角形內以所抱直角弧爲底弧及垂弧即與</span>  
<span style="margin-left: 2em">勾股不異而以所正對直角者爲弦弧論角其大小</span>  
<span style="margin-left: 2em">以對弧之大小爲則蓋用規器以本角爲心以九十</span>  
<span style="margin-left: 2em">度爲界則兩腰間之弧<sub class="note-yuan">腰先引長</sub>必量其角得本弧爲一</span>  
<span style="margin-left: 2em">象限即對角爲直角過象限爲鈍角不及象限乃爲</span>  
<span style="margin-left: 2em">銳角凡弧或角不及滿象限之度名之爲餘又凡兩</span>  
<span style="margin-left: 2em">腰引長至合一點則得抱角之對三角形以底弧爲</span>  
<span style="margin-left: 2em">公底以對角爲等角而餘弧餘角皆前三角形所不</span>  
<span style="margin-left: 2em">及滿一百八十度之餘弧餘角者也因止一直角三</span>  
<span style="margin-left: 2em">角形得餘皆鈍角者則與直角正對之形內腰間角</span>  
<span style="margin-left: 2em">必直餘反皆銳也如止一直角三角形得餘一鈍一</span>  
<span style="margin-left: 5em">銳者則與銳角正對之形內惟前形直角相</span>  
<span style="margin-left: 5em">連之角爲直角餘皆銳角也如圖乙戊丙形</span>  
<span style="margin-left: 5em">內設戊爲直角乙丙皆鈍角即其對形乙甲</span>  
<span style="margin-left: 5em">丙內得甲爲直角乙丙皆銳角也又丁丙戊</span>  
<span style="margin-left: 5em">形內設丙爲銳角戊直角丁鈍角即其對形</span>  
<span style="margin-left: 2em">爲丁己戊而戊角獨直丁己皆銳角論斜角形如三</span>  
<span style="margin-left: 2em">角總爲銳角必對形獨存一銳角餘皆鈍角也設乙</span>  
<span style="margin-left: 2em">甲丙形內甲爲銳角即得對形乙戊丙內戊亦爲銳</span>  
<span style="margin-left: 2em">角乙丙皆鈍角如三角總爲鈍角乃對形反存一鈍</span>  
<span style="margin-left: 2em">角餘皆銳角也設乙戊丙形內戊爲鈍角即乙甲丙</span>  
<span style="margin-left: 2em">內甲亦鈍角今解三角形法多論不及一象限之弧</span>  
<span style="margin-left: 2em">即銳角之底是也因以斜鈍角形先變爲銳角形以</span>  
<span style="margin-left: 2em">直角形有一或二鈍角者亦先改爲對形則就中推</span>  
<span style="margin-left: 2em">求之法與解原形不異即餘弧餘角之理所繇出也</span>  
<span style="margin-left: 2em">今用渾天儀解之亦倣此但先解直角形盡之于三</span>  
<span style="margin-left: 2em">比法有以先得一銳角并與各弧者又餘銳角復并</span>  
<span style="margin-left: 2em">與各弧者又以其底同各腰或并得二腰者各列法</span>  
<span style="margin-left: 2em">如左</span>  
<span style="margin-left: 3em">任取一弧一銳角求餘弧及餘角</span>  
<span style="margin-left: 1em">設甲乙丙三角形內甲爲直角其底乙丙餘弧即腰則</span>  
<span style="margin-left: 5em">乙與丙皆銳角也先設得乙丙直角之底弧</span>  
<span style="margin-left: 5em">及乙角欲求餘盡解本三角形法架內北起</span>  
<span style="margin-left: 5em">子午圈令赤道前高依本角之度然後或東</span>  
<span style="margin-left: 2em">或西自赤道交地平處與本地平查底多寡之度以</span>  
<span style="margin-left: 2em">爲限移過極圈至此限上即三角形儀上定矣如乙</span>  
<span style="margin-left: 2em">角爲二十三度半以前子午圈弧爲則使赤道依之</span>  
<span style="margin-left: 2em">其左右交地平角即得對弧以定大小今甲爲直角</span>  
<span style="margin-left: 2em">必于赤道交過極圈處求之則地平上得底若設乙</span>  
<span style="margin-left: 2em">丙底弧爲六十度而移過極圈至本度<sub class="note-yuan">從乙角算起</sub>因大</span>  
<span style="margin-left: 2em">腰在赤道弧約爲五十八度小腰在過極圈弧爲二</span>  
<span style="margin-left: 2em">十度有半自過極圈交地平查各圈滿一象限即以</span>  
<span style="margin-left: 2em">其限安高弧得二圈間之弧爲丙銳角之對弧約七</span>  
<span style="margin-left: 2em">十八度又設以小腰及本角求餘弧及餘角即先定</span>

<span style="margin-left: 2em">上爲點移之至交地平必自得腰與底弧合前度即</span>  
<span style="margin-left: 2em">丙角亦在高弧同矣或以大腰查求其餘亦先定乙</span>  
<span style="margin-left: 2em">角而轉儀以漸進赤道弧入地平令自其二圈相交</span>  
<span style="margin-left: 2em">之處獨餘五十八度至過極圈交赤道之角必餘法</span>  
<span style="margin-left: 2em">餘度亦合前也</span>  
<span style="margin-left: 2em">今試以三弧各與丙角爲先得如底爲六十度求餘</span>  
<span style="margin-left: 2em">弧餘角法移過極圈至地平距子午東或西三十度</span>  
<span style="margin-left: 2em"><sub class="note-yuan">六十度餘是</sub>定住球使高弧距二圈相交之處各滿一象</span>  
<span style="margin-left: 2em">限得間弧爲七十八度即所設之形準否則宜前或</span>  
<span style="margin-left: 2em">後起子午圈必令高弧對丙角如其度爲止即子午</span>  
<span style="margin-left: 2em">圈自地平以上得對乙角之弧而直角兩腰皆明矣</span>  
<span style="margin-left: 2em">或設先得大腰與丙角必進或退赤道圈定其腰之</span>  
<span style="margin-left: 2em">大小<sub class="note-yuan">如五十八度</sub>即安高弧而起子午圈依前法求餘弧</span>  
<span style="margin-left: 2em">及餘角也或以小腰及丙角求餘即先于過極圈查</span>  
<span style="margin-left: 2em">腰弧大小之度使之交地平以試高弧得全形蓋對</span>  
<span style="margin-left: 2em">角弧不及其度即球宜北起過極圈宜南下若對弧</span>  
<span style="margin-left: 2em">已過其度則球反宜南起隨移過極圈東西得正然</span>  
<span style="margin-left: 2em">後餘角餘弧皆依前法準得矣任取一腰一底或二</span>

<span style="margin-left: 2em">下或起即得餘腰與底而求角亦不異前也</span>  
<span style="margin-left: 3em">解斜角三角形總爲六題</span>  
<span style="margin-left: 1em">其一曰以二腰及間角求底弧及餘角如甲乙丙三角</span>

<span style="margin-left: 2em">爲小腰高弧爲底因而如前圖得乙丙底爲二十六</span>  
<span style="margin-left: 2em">度有半乙角以地平爲對弧在子午圈及高弧之間</span>

<span style="margin-left: 1em">凡黃道以冬夏二至交子午圈成角者必爲四直角因</span>  
<span style="margin-left: 2em">子午圈當過黃極並二至圈此間必正相交故也使</span>  
<span style="margin-left: 2em">以春秋二分交即爲斜角得對弧正與兩道最相距</span>  
<span style="margin-left: 2em">之餘弧等從此距分漸遠交角亦漸易必自冬至至</span>  
<span style="margin-left: 2em">夏至交得銳角向東北或西南自夏至至冬至亦交</span>  
<span style="margin-left: 2em">得銳角向西北或東南法以黃道度正合子午圈定</span>  
<span style="margin-left: 2em">住移交點至天頂從此至地平兩圈各成象限則其</span>  
<span style="margin-left: 2em">間地平弧能量交角之度如大梁宮初度交合子午</span>  
<span style="margin-left: 2em">圈七十九度<sub class="note-yuan">從北極算</sub>必移其七十九度在頂與本宮初</span>  
<span style="margin-left: 2em">度相交其二弧至地平間必抱七十度東北與西南</span>  
<span style="margin-left: 2em">皆等又設鶉火宮以十五度相交因在子午圈七十</span>  
<span style="margin-left: 2em">四度移本度居頂得二圈至地平中弧必爲七十二</span>  
<span style="margin-left: 2em">度西北與東南皆等</span>  
<span style="margin-left: 3em">求高弧與黃道各度之交角</span>  
<span style="margin-left: 1em">先依黃道距午正前後度以赤經圈交黃道角或加或</span>  
<span style="margin-left: 2em">減于高弧交經圈之角乃得高弧與黃道或正或餘</span>  
<span style="margin-left: 2em"><sub class="note-yuan">形內外是</sub>之交角此原法也今用渾儀可免加減徑安高</span>  
<span style="margin-left: 2em">弧交黃道于其距正午度即依前法界線隨移本度</span>  
<span style="margin-left: 2em">至頂復依線安高弧必得角于對地平弧矣如北極</span>  
<span style="margin-left: 2em">高四十度設大梁宮初度距午正六十四度<sub class="note-yuan">東西無異</sub>使</span>  
<span style="margin-left: 2em">高弧交其躔度因得界線後起大梁初度居頂依線</span>  
<span style="margin-left: 2em">復安高弧即得所指地平五十八度爲高弧交黃道</span>  
<span style="margin-left: 2em">角也或不必轉儀而獨移高弧于地平對度用規器</span>  
<span style="margin-left: 2em">于高弧及黃道弧距前交點九十度之界量其二弧</span>  
<span style="margin-left: 2em">相距則地平上亦得五十八度如後圖甲爲天頂丙</span>  
<span style="margin-left: 2em">戊黃道弧甲丁爲子午圈平象限距其東設在乙日</span>  
<span style="margin-left: 2em">食在戊或丙依前第三及第四題公論以二曜躔度</span>  
<span style="margin-left: 2em">丙及定朔時先得丙丁黃道弧必使丁居正午以高</span>  
<span style="margin-left: 8em">弧過丙爲甲丙丁斜角三角形內求</span>
