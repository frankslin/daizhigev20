<span style="margin-left: 2em">第八题<sub class="note-yuan">球内</sub></span>  
<span style="margin-left: 1em">球不离于本所而能旋转则其一径之不动者名为轴</span>  
<span style="margin-left: 2em">轴之两端名为两极也凡一球止有一心凡球之转</span>  
<span style="margin-left: 6em">止有一轴其径甚多无数可尽</span>  
<span style="margin-left: 6em">如上图甲乙丙丁球戊为心乙丁过心此</span>  
<span style="margin-left: 6em">球从甲向丙丙又向甲旋转而不离其处</span>  
<span style="margin-left: 2em">则乙戊丁直线为不动之处是名轴也乙与丁则为</span>  
<span style="margin-left: 2em">两极球心若离于戊点如己则从心所出两半径线</span>

<span style="margin-left: 2em">第九题<sub class="note-yuan">球外</sub></span>  
<span style="margin-left: 1em">球之面可作多圈圈有大有小大圈者其心即球心若</span>

<span style="margin-left: 6em">即其两极故大圈在两极间离两极俱等</span>  
<span style="margin-left: 2em">第十题<sub class="note-yuan">球外</sub></span>  
<span style="margin-left: 1em">小圈者不分球为两平分不与球同心其去两极一近</span>  
<span style="margin-left: 2em">一远愈近所向极愈小愈近心愈大</span>

<span style="margin-left: 6em">也故一大圈之上之下可作无数小圈众</span>  
<span style="margin-left: 6em">小圈之间止可作一大圈</span>  
<span style="margin-left: 2em">第十一题<sub class="note-yuan">球外</sub></span>  
<span style="margin-left: 1em">圈不论大小其分之有三等</span>  
<span style="margin-left: 2em">三等者一曰大分一曰小分一曰细分如两平分之</span>  
<span style="margin-left: 2em">为半圈四平分之为象限此大分也每象限分为九</span>  
<span style="margin-left: 2em">十度此小分也每度又析为百分每分为百秒递析</span>  
<span style="margin-left: 2em">为百至纤而止西历则每度析为六十分每分为六</span>  
<span style="margin-left: 2em">十秒递析为六十至十位而止此细分也</span>  
<span style="margin-left: 2em">第十二题<sub class="note-yuan">球外</sub></span>  
<span style="margin-left: 1em">两大圈交而相分为角欲测其角之大从交数两弧各</span>  
<span style="margin-left: 2em">九十度而遇过极之圈两弧所容过极圈之弧度分</span>  
<span style="margin-left: 2em">即命为本角之度分</span>  
<span style="margin-left: 6em">如上图戊丁乙为过极圈有甲乙丙甲丁</span>  
<span style="margin-left: 6em">丙两大圈交而相分于甲于丙问丁甲乙</span>  
<span style="margin-left: 6em">角为几何度分之角法从甲交数各九十</span>  
<span style="margin-left: 2em">度而遇过极之戊丁乙圈为甲丁甲乙此两弧间所</span>  
<span style="margin-left: 2em">容过极圈之分为丁乙弧如丁乙六十度即命丁甲</span>  
<span style="margin-left: 2em">乙角为六十度角</span>  
<span style="margin-left: 2em">第十三题<sub class="note-yuan">球外</sub></span>  
<span style="margin-left: 1em">凡大圈俱相等两大圈交而相分其所分之圈分两俱</span>  
<span style="margin-left: 2em">相等</span>  
<span style="margin-left: 2em">凡大圈必于本球之腰腰者最大之线也凡最大之</span>  
<span style="margin-left: 2em">线止有一不得有二故辰转作无数大圈俱相等圈</span>  
<span style="margin-left: 2em">既相等则以大圈分大圈其两交线必在球之腰此</span>  
<span style="margin-left: 2em">交至彼交必居球之半故无数大圈各相分所分之</span>  
<span style="margin-left: 2em">两圈分各相等有不等者即小圈也</span>  
<span style="margin-left: 2em">第十四题<sub class="note-yuan">球外</sub></span>  
<span style="margin-left: 1em">大圈俱相等故所分之度分秒各所容皆相等小圈各</span>  
<span style="margin-left: 2em">不相等故度分秒之名数等其所容各不等</span>  
<span style="margin-left: 6em">如上图甲乙己为大圈丙丁戊为小圈大</span>  
<span style="margin-left: 6em">圈既相等即多作大圈皆与甲乙己圈等</span>  
<span style="margin-left: 6em">而各圈之甲至乙其度皆等若丙丁戊小</span>  
<span style="margin-left: 1em">圈既与甲乙己大圈不等则甲至乙与丙至丁同名为</span>  
<span style="margin-left: 1em">若干度而所容之广狭不等</span>

<span style="margin-left: 1em">长方面其中任设一点欲定其所在为何度分作经纬</span>

<span style="margin-left: 2em">俱等次视经纬之线其过点各若干度分即命为点</span>

<span style="margin-left: 1em"><sub class="note-yuan">不得命为第一而命为初历家言算外者俱准此</sub></span>  
<span style="margin-left: 2em">第十六题</span>  
<span style="margin-left: 1em">其在球也亦如之球之中任设一点欲定其所在为何</span>  
<span style="margin-left: 2em">度分亦先作球之经度</span>

<span style="margin-left: 2em">为一百八十度是为腰圈上之经度</span>

<span style="margin-left: 1em">次作球之纬度即定所设点在何度分</span>  
<span style="margin-left: 2em">腰圈之两旁有两极从腰圈向极分为九十度每度</span>  
<span style="margin-left: 2em">各作一距等小圈渐远腰渐小至极而为一点即第</span>

<span style="margin-left: 2em">如图甲乙丙丁球上依前题既作甲庚丙甲辛丙各</span>  
<span style="margin-left: 6em">经线次于乙戊丁腰圈上向甲极分为九</span>

<span style="margin-left: 2em">是其容也其一自此度至彼度各以一点为界是其</span>

<span style="margin-left: 2em">第十八题</span>  
<span style="margin-left: 1em">论纬圈以大圈为宗</span>

<span style="margin-left: 1em">地为圆体与海合为一球</span>
