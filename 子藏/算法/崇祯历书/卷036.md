<span style="margin-left: 2em">理</span>  
<span style="margin-left: 1em">球之內有心心者從此引出線至球面俱相等</span>  
<span style="margin-left: 5em">如上圖甲乙丙球丁爲心從丁引出線至甲</span>  
<span style="margin-left: 5em">至乙至丙各等即作百千萬線皆等</span>  
<span style="margin-left: 2em">第七題<sub class="note-yuan">球內</sub></span>  
<span style="margin-left: 1em">徑者一直線過球心兩端各至面半徑者從心至面</span>  
<span style="margin-left: 6em">如上圖甲乙球丙爲心一直線過丙兩端</span>  
<span style="margin-left: 6em">至甲至乙即甲乙爲徑線其丙乙丙甲皆</span>  
<span style="margin-left: 6em">爲半徑線</span>  
<span style="margin-left: 2em">第八題<sub class="note-yuan">球內</sub></span>  
<span style="margin-left: 1em">球不離於本所而能旋轉則其一徑之不動者名爲軸</span>  
<span style="margin-left: 2em">軸之兩端名爲兩極也凡一球止有一心凡球之轉</span>  
<span style="margin-left: 6em">止有一軸其徑甚多無數可盡</span>  
<span style="margin-left: 6em">如上圖甲乙丙丁球戊爲心乙丁過心此</span>  
<span style="margin-left: 6em">球從甲向丙丙又向甲旋轉而不離其處</span>  
<span style="margin-left: 2em">則乙戊丁直線爲不動之處是名軸也乙與丁則爲</span>  
<span style="margin-left: 2em">兩極球心若離于戊點如己則從心所出兩半徑線</span>  
<span style="margin-left: 2em">如庚己己辛必不等故曰止有此心凡軸皆利轉若</span>  
<span style="margin-left: 2em">有二軸二俱轉即相礙一不轉即非軸故曰止有一</span>  
<span style="margin-left: 2em">軸從心出直線苟至面皆徑也故曰無數</span>  
<span style="margin-left: 2em">第九題<sub class="note-yuan">球外</sub></span>  
<span style="margin-left: 1em">球之面可作多圈圈有大有小大圈者其心即球心若</span>  
<span style="margin-left: 2em">從圈剖球爲二則其圈之徑過球心也各大圈從圈</span>  
<span style="margin-left: 2em">面作垂線各有其本圈之軸與其兩極</span>  
<span style="margin-left: 6em">如圖甲乙丙丁球上作甲戊丙己大圈其</span>  
<span style="margin-left: 6em">垂線乙丁即乙丁爲本圈之軸乙丁兩點</span>  
<span style="margin-left: 6em">即其兩極故大圈在兩極間離兩極俱等</span>  
<span style="margin-left: 2em">第十題<sub class="note-yuan">球外</sub></span>  
<span style="margin-left: 1em">小圈者不分球爲兩平分不與球同心其去兩極一近</span>  
<span style="margin-left: 2em">一遠愈近所向極愈小愈近心愈大</span>  
<span style="margin-left: 6em">如上圖甲乙爲大圈丙丁戊己庚皆小圈</span>  
<span style="margin-left: 6em">也故一大圈之上之下可作無數小圈衆</span>  
<span style="margin-left: 6em">小圈之間止可作一大圈</span>  
<span style="margin-left: 2em">第十一題<sub class="note-yuan">球外</sub></span>  
<span style="margin-left: 1em">圈不論大小其分之有三等</span>  
<span style="margin-left: 2em">三等者一曰大分一曰小分一曰細分如兩平分之</span>  
<span style="margin-left: 2em">爲半圈四平分之爲象限此大分也每象限分爲九</span>  
<span style="margin-left: 2em">十度此小分也每度又析爲百分每分爲百秒遞析</span>  
<span style="margin-left: 2em">爲百至纖而止西曆則每度析爲六十分每分爲六</span>  
<span style="margin-left: 2em">十秒遞析爲六十至十位而止此細分也</span>  
<span style="margin-left: 2em">第十二題<sub class="note-yuan">球外</sub></span>  
<span style="margin-left: 1em">兩大圈交而相分爲角欲測其角之大從交數兩弧各</span>  
<span style="margin-left: 2em">九十度而遇過極之圈兩弧所容過極圈之弧度分</span>  
<span style="margin-left: 2em">即命爲本角之度分</span>  
<span style="margin-left: 6em">如上圖戊丁乙爲過極圈有甲乙丙甲丁</span>  
<span style="margin-left: 6em">丙兩大圈交而相分于甲於丙問丁甲乙</span>  
<span style="margin-left: 6em">角爲幾何度分之角法從甲交數各九十</span>  
<span style="margin-left: 2em">度而遇過極之戊丁乙圈爲甲丁甲乙此兩弧間所</span>  
<span style="margin-left: 2em">容過極圈之分爲丁乙弧如丁乙六十度即命丁甲</span>  
<span style="margin-left: 2em">乙角爲六十度角</span>  
<span style="margin-left: 2em">第十三題<sub class="note-yuan">球外</sub></span>  
<span style="margin-left: 1em">凡大圈俱相等兩大圈交而相分其所分之圈分兩俱</span>  
<span style="margin-left: 2em">相等</span>  
<span style="margin-left: 2em">凡大圈必于本球之腰腰者最大之線也凡最大之</span>  
<span style="margin-left: 2em">線止有一不得有二故辰轉作無數大圈俱相等圈</span>  
<span style="margin-left: 2em">既相等則以大圈分大圈其兩交線必在球之腰此</span>  
<span style="margin-left: 2em">交至彼交必居球之半故無數大圈各相分所分之</span>  
<span style="margin-left: 2em">兩圈分各相等有不等者即小圈也</span>  
<span style="margin-left: 2em">第十四題<sub class="note-yuan">球外</sub></span>  
<span style="margin-left: 1em">大圈俱相等故所分之度分秒各所容皆相等小圈各</span>  
<span style="margin-left: 2em">不相等故度分秒之名數等其所容各不等</span>  
<span style="margin-left: 6em">如上圖甲乙己爲大圈丙丁戊爲小圈大</span>  
<span style="margin-left: 6em">圈既相等即多作大圈皆與甲乙己圈等</span>  
<span style="margin-left: 6em">而各圈之甲至乙其度皆等若丙丁戊小</span>  
<span style="margin-left: 1em">圈既與甲乙己大圈不等則甲至乙與丙至丁同名爲</span>  
<span style="margin-left: 1em">若干度而所容之廣狹不等</span>  
<span style="margin-left: 2em">第十五題<sub class="note-yuan">以下四題言測量之法</sub></span>  
<span style="margin-left: 1em">長方面其中任設一點欲定其所在爲何度分作經緯</span>  
<span style="margin-left: 2em">度求之法曰先平分其長爲若干度分名經線次平</span>  
<span style="margin-left: 2em">分其廣爲若干度分名緯線經與緯每度分之小大</span>  
<span style="margin-left: 2em">俱等次視經緯之線其過點各若干度分即命爲點</span>  
<span style="margin-left: 2em">所在之度分</span>  
<span style="margin-left: 6em">如上圖甲乙丙丁長方形欲知戊點所在</span>  
<span style="margin-left: 6em">先從乙向丙作距等經線次從乙向甲作</span>  
<span style="margin-left: 6em">距等緯線次視戊點在經緯線之交爲是</span>  
<span style="margin-left: 1em">何度即命曰在經度之四緯度之八也<sub class="note-yuan">乙至丙丙點得命爲第六乙點</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">不得命爲第一而命爲初曆家言算外者俱准此</sub></span>  
<span style="margin-left: 2em">第十六題</span>  
<span style="margin-left: 1em">其在球也亦如之球之中任設一點欲定其所在爲何</span>  
<span style="margin-left: 2em">度分亦先作球之經度</span>  
<span style="margin-left: 2em">法曰先於兩極之間作一大圈爲腰圈平分腰圈爲</span>  
<span style="margin-left: 2em">三百六十度從各度各作一過極大圈即半圈平分</span>  
<span style="margin-left: 2em">爲一百八十度是爲腰圈上之經度</span>  
<span style="margin-left: 6em">如上圖甲乙丙丁球乙丁爲兩極於其間</span>  
<span style="margin-left: 6em">作甲戊丙己腰圈從戊向丙丙向己各作</span>  
<span style="margin-left: 6em">過極大圈即乙庚丁乙辛丁等線皆腰圈</span>  
<span style="margin-left: 1em">上之經度</span>  
<span style="margin-left: 2em">第十七題</span>  
<span style="margin-left: 1em">次作球之緯度即定所設點在何度分</span>  
<span style="margin-left: 2em">腰圈之兩旁有兩極從腰圈向極分爲九十度每度</span>  
<span style="margin-left: 2em">各作一距等小圈漸遠腰漸小至極而爲一點即第</span>  
<span style="margin-left: 2em">九十小圈也次視經緯兩線之交命所<sub class="note-jiao">校：所明刊本作在據清刊</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">本校正</sub>設點在何度分</span>  
<span style="margin-left: 2em">如圖甲乙丙丁球上依前題既作甲庚丙甲辛丙各</span>  
<span style="margin-left: 6em">經線次於乙戊丁腰圈上向甲極分爲九</span>  
<span style="margin-left: 6em">十度每度各作一距等小圈如壬子癸丑</span>  
<span style="margin-left: 6em">之類皆緯圈也次視經緯各遇點之交從</span>  
<span style="margin-left: 2em">腰圈線考其經度從過極線考其緯度即命所設己</span>  
<span style="margin-left: 2em">點在從戊向丁之第四經圈從戊向甲之第三緯圈</span>  
<span style="margin-left: 2em">凡言度者各有二義其一一度之廣能包一度之地</span>  
<span style="margin-left: 2em">是其容也其一自此度至彼度各以一點爲界是其</span>  
<span style="margin-left: 2em">限也腰圈度之容以各過極度之線限之過極度之</span>  
<span style="margin-left: 2em">容以各距等線限之</span>  
<span style="margin-left: 2em">凡圈互相爲經亦互相爲緯如以過極爲經則距等</span>  
<span style="margin-left: 2em">爲緯若以距等爲經則過極爲緯如幾何原本之論</span>  
<span style="margin-left: 2em">線互相爲直線互相爲垂線也</span>  
<span style="margin-left: 2em">第十八題</span>  
<span style="margin-left: 1em">論緯圈以大圈爲宗</span>  
<span style="margin-left: 2em">過極經圈皆大圈也皆等距等線限之諸度分之容</span>  
<span style="margin-left: 2em">亦等距等緯圈皆小圈也各不等過極圈限之諸度</span>  
<span style="margin-left: 2em">分之容愈近極愈狹至極而盡矣故緯度之容等于</span>  
<span style="margin-left: 2em">經度者獨有腰圈一線獨有初度初分初秒之一率</span>  
<span style="margin-left: 2em">過此以上無不狹也故當以大圈爲宗大圈左右諸</span>  
<span style="margin-left: 2em">緯圈之上凡言經度之容者皆從此推減之圈愈小</span>  
<span style="margin-left: 2em">度愈狹即差愈多也</span>  
<span style="margin-left: 2em">視學一題</span>  
<span style="margin-left: 1em">凡物必有影影有等大小有盡不盡</span>  
<span style="margin-left: 2em">不透光之物體前對光體後必有影焉若光體大於</span>  
<span style="margin-left: 2em">物體其影漸遠漸殺銳極而盡若光體小於物體其</span>  
<span style="margin-left: 2em">影漸遠漸大以至無窮若光物相等其影亦相等亦</span>  
<span style="margin-left: 2em">無窮</span>  
<span style="margin-left: 1em">測地學四題</span>  
<span style="margin-left: 2em">第一題</span>  
<span style="margin-left: 1em">地爲圓體與海合爲一球</span>  
<span style="margin-left: 2em">何以徵之凡人任於一處向北行二日半則北方之</span>  
<span style="margin-left: 2em">星在子午線上者必高一度次後二日半復高一度</span>  
<span style="margin-left: 12em">恆如是爲相等之差向南</span>  
<span style="margin-left: 12em">行亦如之知從南至北爲</span>  
<span style="margin-left: 12em">圓體也如上圖甲爲北星</span>  
<span style="margin-left: 12em">丁爲南星乙辛丙圈爲地</span>  
<span style="margin-left: 1em">球人在乙則見甲正在其頂至戊則少一度矣從戊至</span>  
<span style="margin-left: 1em">己與乙至戊道里等又少一度矣迨至辛則不見甲至</span>  
<span style="margin-left: 1em">壬則反見丁安得非圓體乎若云地爲平體則見星當</span>  
<span style="margin-left: 1em">如癸從丑向寅至辰宜常見不隱又丑至寅寅至卯若</span>  
<span style="margin-left: 1em">見子之高下所差等則道里宜不等<sub class="note-yuan">別有算數</sub>安得有時不</span>  
<span style="margin-left: 1em">見又恆爲相等之差也</span>  
<span style="margin-left: 2em">若人東行漸遠則諸星出地者漸先見西行漸遠漸</span>  
<span style="margin-left: 2em">後見故東西人見日月食遲速先後各異是知東西</span>  
<span style="margin-left: 2em">必圓體也</span>  
<span style="margin-left: 2em">第二題</span>  
<span style="margin-left: 1em">地在大圜天之最中</span>  
<span style="margin-left: 2em">何以徵之人任於所在見天星半恆在上半恆在下</span>  
<span style="margin-left: 2em">故知地在最中也</span>  
<span style="margin-left: 5em">如上圖丙爲地東見甲西見乙甲乙以上恆</span>  
<span style="margin-left: 5em">爲天星之半知丙在中也若云非中當在丁</span>  
<span style="margin-left: 5em">則東望戊西望己當見天之小半而不見者</span>  
<span style="margin-left: 2em">大半</span>  
<span style="margin-left: 2em">第三題</span>  
<span style="margin-left: 1em">地之體恆不動</span>  
<span style="margin-left: 2em">一不去本所二亦不旋轉云不去本所者去即不在</span>  
<span style="margin-left: 2em">天之最中也云在本所又不旋轉者若旋轉人當覺</span>  
<span style="margin-left: 2em">之且不轉則已轉須一日一周其行至速一切雲行</span>  
<span style="margin-left: 2em">鳥飛順行則遲逆行則速人或從地擲物空中復歸</span>  
<span style="margin-left: 2em">於地不宜在其初所今皆不然足明地之不轉</span>  
<span style="margin-left: 2em">第四題</span>  
<span style="margin-left: 1em">地球在天中止于一點</span>  
<span style="margin-left: 2em">何以徴之人在地面不論所在仰視填星歳星熒惑</span>  
<span style="margin-left: 2em">彼此所見恆是同度故知地體較于天體則爲極小</span>  
<span style="margin-left: 2em">若地大者兩人相去絕遠其視三星彼此所見不宜</span>  
<span style="margin-left: 5em">同躔</span>  
<span style="margin-left: 5em">如上圖丙己戊乙爲天甲爲地丁爲星地體</span>  
<span style="margin-left: 5em">若大能爲天分數者則人在庚宜見丁在己</span>  
<span style="margin-left: 1em">度人在辛宜見丁在戊度今不然者是地與天其小大</span>  
<span style="margin-left: 1em">無分數可論也</span>

<span style="margin-left: 1em">問測天者何事所論者何義也曰此度數之學度數學</span>  
<span style="margin-left: 2em">有七支此爲第六也所論者一言三曜<sub class="note-yuan">日月星</sub>形像大</span>  
<span style="margin-left: 2em">小之比例一言其各去離地心地面各幾何一言其</span>

<span style="margin-left: 2em">言其五相視五相視者一曰會聚<sub class="note-yuan">會聚或同一宿或同一宮或相掩或</sub></span>

<span style="margin-left: 1em">大圜者上天下地之總名也<sub class="note-yuan">亦稱宇宙亦稱天下亦稱六合之內下文通用</sub>天</span>  
<span style="margin-left: 2em">實渾圓其中毫無空隙譬如葱本重重包裹其分數</span>  
<span style="margin-left: 2em">幾何則自下數之<sub class="note-yuan">地居天中爲最下亦曰最內</sub>第一爲地水補其</span>  
<span style="margin-left: 2em">闕<sub class="note-yuan">地有卑窪水則就之若據地面則水土相半蹠實論之水之視地僅當千分之一</sub>共爲一</span>  
<span style="margin-left: 2em">球地外爲氣氣之外爲七政之天七政之外爲恆星</span>
