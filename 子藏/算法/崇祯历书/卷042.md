<span style="margin-left: 2em">第一题</span>  
<span style="margin-left: 1em">圆形之半径偕其周作句股形其容与圆形之积等</span>  
<span style="margin-left: 2em">解曰丙丁戊己圆形其心乙其半径乙丙即以为股</span>  
<span style="margin-left: 2em">形之周为句成午申酉句股形题言两形之容等</span>  
<span style="margin-left: 2em">论曰设有言不等必云或大或小云圆形为大句股</span>  
<span style="margin-left: 2em">形小者索其较为亥形即于圈内作丙丁己戊正方</span>  
<span style="margin-left: 2em">形又作丙庚丁辛戊壬己癸八角直线形从心至八</span>  
<span style="margin-left: 9em">角形之各边作甲乙等中垂线试</span>  
<span style="margin-left: 9em">于圆形内减其大半所余又减其</span>  
<span style="margin-left: 9em">大半末所余以比较形亥必能为</span>  
<span style="margin-left: 9em">小矣<sub class="note-yuan">十卷首题</sub>如先减丁丙己戊方形</span>  
<span style="margin-left: 9em">次减丙癸己等三角形八末余丙</span>  
<span style="margin-left: 9em">庚丙癸等二角杂形八必小于亥</span>  
<span style="margin-left: 9em">形也次作午未戌三边形与丙庚</span>  
<span style="margin-left: 9em">丁八角形等必小于午申酉三边</span>  
<span style="margin-left: 9em">形何者未午乙甲也小于圈半径</span>  
<span style="margin-left: 9em">乙庚先设午申酉三边形及亥较</span>  
<span style="margin-left: 9em">形始与圈等今午未戌三边形及</span>  
<span style="margin-left: 9em">八两角杂形适与圈等夫午申酉</span>  
<span style="margin-left: 9em">三角形大于午未戌三角形亥形</span>  
<span style="margin-left: 9em">又大于八两角杂形是合两大形</span>  
<span style="margin-left: 9em"><sub class="note-yuan">即午申酉及亥较形</sub>与圈等者复谓合两小</span>  
<span style="margin-left: 9em">形<sub class="note-yuan">即午未戌及八两角杂形</sub>与圈等有是理乎</span>  
<span style="margin-left: 9em">次论曰若言圈形为小句股形大</span>  
<span style="margin-left: 9em">者索其较为亥形即于圈外作子</span>  
<span style="margin-left: 9em">寅丑己正方形又作卯辰八角形</span>  
<span style="margin-left: 9em">夫寅己方形大于午申酉三角形</span>  
<span style="margin-left: 2em">者方形之周线大于圆形之周线也内减其大半<sub class="note-yuan">即元</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">圈</sub>又减其大半<sub class="note-yuan">即卯辰子等四三角形也</sub>末余丙卯庚庚辰丁等</span>  
<span style="margin-left: 2em">三角杂形八必小于较形亥又作午申亢三角形与</span>  
<span style="margin-left: 2em">丙卯辰八角形等兹形为圈之外切必大于元圈而</span>  
<span style="margin-left: 2em">午亢为外形之周必大于午酉内圈之周先设圈及</span>  
<span style="margin-left: 2em">亥形与午申酉三角形等今并圈及三角襍形八<sub class="note-yuan">即丙</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">卯庚等八杂形也</sub>反大于午申酉三角形是圜偕八杂小形</span>  
<span style="margin-left: 2em">而为大者又偕亥大形而为小可乎</span>  
<span style="margin-left: 2em">第二题</span>  
<span style="margin-left: 1em">凡圈周三倍圈径有奇<sub class="note-yuan">二支</sub></span>  
<span style="margin-left: 2em">此有二法其一云三倍又七十之十则朒其二云三</span>  
<span style="margin-left: 2em">倍又七十一之十则盈先解其一曰甲乙戊丁圈戊</span>  
<span style="margin-left: 2em">为心甲戊乙戊为两径辏心作直角从甲作午子切</span>  
<span style="margin-left: 2em">线从乙从丁作乙己丁壬线与乙戊等乙戊己角六</span>  
<span style="margin-left: 2em">十度己戊甲角必三十度为六边形之半角也末从</span>  
<span style="margin-left: 2em">心过己过壬作戊午戊子线成戊午子等角形己戊</span>  
<span style="margin-left: 9em">壬既六十度则午子为等形之边</span>  
<span style="margin-left: 9em">设甲午股一百五十三<sub class="note-yuan">任设此数以便推算</sub></span>  
<span style="margin-left: 9em">午子或午戊弦必三百〇六各自</span>  
<span style="margin-left: 9em">之股方得二万三千四百〇九弦</span>  
<span style="margin-left: 9em">方得九万三千六百三十六相减</span>  
<span style="margin-left: 9em">余七万〇二百二十七为句方开</span>  
<span style="margin-left: 9em">得二百六十五有奇为戊甲句半</span>  
<span style="margin-left: 9em">径也则戊甲与甲午之比例为二</span>  
<span style="margin-left: 2em">六五有奇与一五三次平分午戊甲角作戊庚线任</span>  
<span style="margin-left: 2em">分午甲于庚则午戊与戊甲若午庚与甲庚<sub class="note-yuan">六卷三题</sub>合</span>  
<span style="margin-left: 2em">之戊午偕戊甲而与戊甲若午庚偕甲庚而与甲庚</span>  
<span style="margin-left: 2em">更之戊午并戊甲而与午甲<sub class="note-yuan">即午庚偕甲庚</sub>若戊甲与甲庚</span>  
<span style="margin-left: 2em">先定戊午戊甲并得五七一有奇午甲为一五三则</span>  
<span style="margin-left: 2em">戊午并戊甲与甲午之比例若五七一与一五三若</span>  
<span style="margin-left: 2em">设甲庚一五三则戊甲与甲庚之比例为五七一与</span>  
<span style="margin-left: 2em">一五三矣即以两数自之并而开方得五九一又八</span>  
<span style="margin-left: 2em">之一不尽为庚戊线<sub class="note-yuan">戊甲甲庚之弦</sub>则庚戊与甲庚之比例</span>  
<span style="margin-left: 2em">若五九一又八之一不尽与一五三次平分庚戊甲</span>  
<span style="margin-left: 2em">角作戊辛线则戊庚并戊甲一一六二又八之一与</span>  
<span style="margin-left: 2em">庚甲一五三若戊甲与甲辛若设甲辛一五三则戊</span>  
<span style="margin-left: 2em">甲为一一六二又八之一有奇两数各自之并而开</span>  
<span style="margin-left: 2em">方得二七二又八之一为辛戊线<sub class="note-yuan">甲戊甲辛之弦</sub>则辛戊与</span>  
<span style="margin-left: 2em">辛甲之比例若二七二又八之一与一五三次平分</span>  
<span style="margin-left: 2em">辛戊甲角作戊寅线则辛戊并戊甲二三三四又四</span>  
<span style="margin-left: 9em">之一与辛甲一五三若戊甲与甲</span>  
<span style="margin-left: 9em">寅若设甲寅为一五三则戊甲为</span>  
<span style="margin-left: 9em">二三三四又四之一有奇两数各</span>  
<span style="margin-left: 9em">自之并而开方得二三三九又四</span>  
<span style="margin-left: 2em">之一有奇为寅戊线<sub class="note-yuan">戊甲甲寅之弦</sub>则寅戊与寅甲之比例</span>  
<span style="margin-left: 2em">若二三三九又四之一有奇与一五三次平分寅戊</span>  
<span style="margin-left: 2em">甲角作未戊线则寅戊并戊甲四六七三半有奇与</span>  
<span style="margin-left: 2em">寅甲一五三若戊甲与甲未若设甲未为一五三则</span>  
<span style="margin-left: 2em">戊甲为四六七三半有奇</span>  
<span style="margin-left: 2em">论曰午戊子元角为三等角形之一即一直角三之</span>  
<span style="margin-left: 2em">二午戊甲其半则三之一庚戊甲其半则六之一辛</span>  
<span style="margin-left: 2em">戊甲其半则十二之一寅戊甲其半则二十四之一</span>  
<span style="margin-left: 2em">未戊甲其半则四十八之一复作甲戊申角与甲戊</span>  
<span style="margin-left: 2em">未角等成未戊申角形其戊角为直角二十四之一</span>  
<span style="margin-left: 2em">而未申弧为象限弧二十四之一于全周为九十六</span>  
<span style="margin-left: 2em">之一未甲申其切线也为九十六边形之一边此边</span>  
<span style="margin-left: 2em">与圈全径之比例若戊甲四六七三半与甲未一五</span>  
<span style="margin-left: 2em">三末置九十六边形之一边为一五三因周为一四</span>  
<span style="margin-left: 2em">六八八径为四六七三半有奇则九十六边圈外形</span>  
<span style="margin-left: 2em">之周与圈径之比例为一四六八八与四六七三半</span>  
<span style="margin-left: 9em">约之为三又七之一不足则径为</span>  
<span style="margin-left: 9em">一九十六边圈外周为三又七之</span>  
<span style="margin-left: 9em">一不足夫形在周之外尚不及三</span>  
<span style="margin-left: 9em">又七之一况圈周乎</span>  
<span style="margin-left: 9em">二解三倍又七十一之十而盈者</span>  
<span style="margin-left: 9em">曰圈内作乙丙径从丙作六边形</span>  
<span style="margin-left: 9em">之一边丙甲与半径戊丙等<sub class="note-yuan">四卷十五</sub></span>  
<span style="margin-left: 9em">从乙作乙甲成乙甲丙形在半圈</span>  
<span style="margin-left: 9em">之内则甲为直角<sub class="note-yuan">三卷三十一题</sub>设甲丙</span>  
<span style="margin-left: 9em">句七百八十〇乙丙弦一千五百</span>  
<span style="margin-left: 2em">六十〇两数自之相减开方得一千三百五十一不</span>  
<span style="margin-left: 2em">足为乙甲股则乙甲与甲丙之比例为一三五一与</span>  
<span style="margin-left: 2em">七八〇次平分甲乙丙角作乙丁线又作丁丙线成</span>  
<span style="margin-left: 2em">乙丁丙丙丁己两直角形相似盖同用丁直角在半</span>  
<span style="margin-left: 2em">圈内甲丁丁丙两所乘之弧等则丁丙己丁乙丙两</span>  
<span style="margin-left: 2em">弧之角必等<sub class="note-yuan">三卷二十一</sub>夫两形有两角等者各腰俱相</span>  
<span style="margin-left: 2em">似则乙丁<sub class="note-yuan">大形之股</sub>与丁丙<sub class="note-yuan">大形之句</sub>若丁丙<sub class="note-yuan">小形之股</sub>与丁己<sub class="note-yuan">小形</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">之句</sub>又乙丙<sub class="note-yuan">大形之弦</sub>与丁丙<sub class="note-yuan">大形之句</sub>若己丙<sub class="note-yuan">小形之弦</sub>与丁己<sub class="note-yuan">小形</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">之句</sub>更之乙丙与己丙<sub class="note-yuan">两弦</sub>若丁丙与丁己<sub class="note-yuan">两句</sub>是乙丁与</span>  
<span style="margin-left: 2em">丁丙<sub class="note-yuan">两股</sub>丁丙与丁己<sub class="note-yuan">两句</sub>乙丙与己丙<sub class="note-yuan">两弦</sub>三比例皆等</span>  
<span style="margin-left: 2em">又乙丙与己丙<sub class="note-yuan">两弦</sub>若乙丙并乙甲<sub class="note-yuan">两腰</sub>与甲丙底之两</span>  
<span style="margin-left: 2em">分<sub class="note-yuan">见前解</sub>则乙丁与丁丙亦若乙丙并乙甲与甲丙先</span>  
<span style="margin-left: 2em">定乙甲一三五一弱乙丙一五六〇是乙甲乙丙并</span>  
<span style="margin-left: 2em">为二九一一弱甲丙先设七八〇则乙丁与丁丙亦</span>  
<span style="margin-left: 2em">为二九一一弱与七八〇各自之并而开方得三〇</span>  
<span style="margin-left: 2em">一二又四之一弱为乙丙<sub class="note-yuan">乙丁丁丙之弦</sub>则乙丙与丁丙之</span>  
<span style="margin-left: 2em">比例为三〇一三又四之一弱与七八〇次平分丁</span>  
<span style="margin-left: 2em">乙丙角作辛乙线因前比例论得乙辛与辛丙比例</span>  
<span style="margin-left: 2em">之数盖丁乙并乙丙与丙丁若乙辛与辛丙先定乙</span>  
<span style="margin-left: 2em">丙三〇一三又四之一乙丁二九一一弱并为五九</span>  
<span style="margin-left: 2em">二四又四之一弱今丙丁为七八〇则乙辛与辛丙</span>  
<span style="margin-left: 2em">为五九二四又四之一弱与七八〇欲省数改设辛</span>  
<span style="margin-left: 2em">丙二四〇依三率法辛丙七八〇乙辛为五九二四</span>  
<span style="margin-left: 2em">有奇今辛丙二四〇即乙辛为一八二三弱两数自</span>  
<span style="margin-left: 2em">之并而开方得一八三八又十一之九弱为乙丙线</span>  
<span style="margin-left: 2em"><sub class="note-yuan">乙辛辛丙之弦</sub>则二四〇与一八三八又十一之九为丙辛</span>  
<span style="margin-left: 2em">乙辛之比例次平分辛乙丙角作乙壬壬丙两线辛</span>  
<span style="margin-left: 2em">乙乙丙两数并为三六六一又十一之九弱与辛丙</span>  
<span style="margin-left: 2em">二四〇为乙壬与壬丙之比例又改设壬丙六六依</span>  
<span style="margin-left: 2em">三率法乙壬为一〇〇七弱两数自之并而开方得</span>

<span style="margin-left: 2em">假如大底为十上边为六斜边得四上下边之较四</span>  
<span style="margin-left: 2em">半之得二为第一率大底半数五为二率斜边四为</span>  
<span style="margin-left: 2em">三率算得全形之腰为十此全形有两腰有底求其</span>  
<span style="margin-left: 2em">积得四十三又三之一其小形有两腰各六有底六</span>  
<span style="margin-left: 2em">求其积得十五又五之三以减全积得二十七又三</span>  
<span style="margin-left: 2em">之二弱为元梯形之积今欲截取四之一以四而一</span>  
<span style="margin-left: 2em">得六又五之四弱以除全积得六有五之二弱为元</span>  
<span style="margin-left: 2em">形四之一亦为全形六分五之二分用平行截三角</span>  
<span style="margin-left: 2em">形之法六有奇为母五有奇<sub class="note-yuan">减一得子</sub>为子相乘开方得</span>  
<span style="margin-left: 2em">五〇〇即从全形上角分全腰为六分有五之二弱</span>  
<span style="margin-left: 2em">内取五又五之四强作平行线分元形如所求<sub class="note-yuan">或取三十</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">二而取二十九</sub></span>  
<span style="margin-left: 2em">若近小底命作截线其理同上但母子数不同上得</span>  
<span style="margin-left: 2em">元形四之一分为六又六十之四十六畧约五之四</span>  
<span style="margin-left: 2em">今所求者四之三则三倍之得二十又三十之九以</span>  
<span style="margin-left: 2em">倍数与全数相乘得数开方得二十九半即从上角</span>  
<span style="margin-left: 2em">如法取作平行线分元形如所求<sub class="note-yuan">或分全腰为四十三又三之一从上</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">角取二十九半作线</sub></span>  
<span style="margin-left: 7em">凡梯田在平行线内但底等即其积等</span>  
<span style="margin-left: 7em">不论角大小</span>

<span style="margin-left: 7em">形所截之分为彼形之几分其用法如</span>
