<span style="margin-left: 1em"><sub class="note-yuan">　羅雅谷　譔　　修政曆法極西耶穌會士門人魏邦綸　賈良琦　受法　　　　　　　　　　　湯若望訂</sub></span>

<span style="margin-left: 1em">圓面求積<sub class="note-jiao">校：清刊本此前有測量全義五卷標題</sub></span>  
<span style="margin-left: 2em">凡圓面積與其半經線偕半周線作矩內直角形之</span>  
<span style="margin-left: 2em">積等依此法則量圓形者以半徑乘半周而已古高</span>  
<span style="margin-left: 2em">士亞奇默德作圜書內三題洞燭圓形之理今表而</span>  
<span style="margin-left: 2em">出之爲元本焉</span>  
<span style="margin-left: 2em">第一題</span>  
<span style="margin-left: 1em">圓形之半徑偕其周作句股形其容與圓形之積等</span>  
<span style="margin-left: 2em">解曰丙丁戊己圓形其心乙其半徑乙丙即以爲股</span>  
<span style="margin-left: 2em">形之周爲句成午申酉句股形題言两形之容等</span>  
<span style="margin-left: 2em">論曰設有言不等必云或大或小云圓形爲大句股</span>  
<span style="margin-left: 2em">形小者索其較爲亥形即于圈內作丙丁己戊正方</span>  
<span style="margin-left: 2em">形又作丙庚丁辛戊壬己癸八角直線形從心至八</span>  
<span style="margin-left: 9em">角形之各邊作甲乙等中垂線試</span>  
<span style="margin-left: 9em">於圓形內減其大半所餘又減其</span>  
<span style="margin-left: 9em">大半末所餘以比較形亥必能爲</span>  
<span style="margin-left: 9em">小矣<sub class="note-yuan">十卷首題</sub>如先減丁丙己戊方形</span>  
<span style="margin-left: 9em">次減丙癸己等三角形八末餘丙</span>  
<span style="margin-left: 9em">庚丙癸等二角雜形八必小于亥</span>  
<span style="margin-left: 9em">形也次作午未戌三邊形與丙庚</span>  
<span style="margin-left: 9em">丁八角形等必小于午申酉三邊</span>  
<span style="margin-left: 9em">形何者未午乙甲也小于圈半徑</span>  
<span style="margin-left: 9em">乙庚先設午申酉三邊形及亥較</span>  
<span style="margin-left: 9em">形始與圈等今午未戌三邊形及</span>  
<span style="margin-left: 9em">八兩角雜形適與圈等夫午申酉</span>  
<span style="margin-left: 9em">三角形大于午未戌三角形亥形</span>  
<span style="margin-left: 9em">又大于八兩角雜形是合兩大形</span>  
<span style="margin-left: 9em"><sub class="note-yuan">即午申酉及亥較形</sub>與圈等者復謂合兩小</span>  
<span style="margin-left: 9em">形<sub class="note-yuan">即午未戌及八兩角雜形</sub>與圈等有是理乎</span>  
<span style="margin-left: 9em">次論曰若言圈形爲小句股形大</span>  
<span style="margin-left: 9em">者索其較爲亥形即于圈外作子</span>  
<span style="margin-left: 9em">寅丑己正方形又作卯辰八角形</span>  
<span style="margin-left: 9em">夫寅己方形大于午申酉三角形</span>  
<span style="margin-left: 2em">者方形之周線大于圓形之周線也內减其大半<sub class="note-yuan">即元</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">圈</sub>又减其大半<sub class="note-yuan">即卯辰子等四三角形也</sub>末餘丙卯庚庚辰丁等</span>  
<span style="margin-left: 2em">三角雜形八必小于較形亥又作午申亢三角形與</span>  
<span style="margin-left: 2em">丙卯辰八角形等兹形爲圈之外切必大于元圈而</span>  
<span style="margin-left: 2em">午亢爲外形之周必大于午酉內圈之周先設圈及</span>  
<span style="margin-left: 2em">亥形與午申酉三角形等今并圈及三角襍形八<sub class="note-yuan">即丙</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">卯庚等八雜形也</sub>反大于午申酉三角形是圜偕八雜小形</span>  
<span style="margin-left: 2em">而爲大者又偕亥大形而爲小可乎</span>  
<span style="margin-left: 2em">第二題</span>  
<span style="margin-left: 1em">凡圈周三倍圈徑有奇<sub class="note-yuan">二支</sub></span>  
<span style="margin-left: 2em">此有二法其一云三倍又七十之十則朒其二云三</span>  
<span style="margin-left: 2em">倍又七十一之十則盈先解其一曰甲乙戊丁圈戊</span>  
<span style="margin-left: 2em">爲心甲戊乙戊爲两徑輳心作直角從甲作午子切</span>  
<span style="margin-left: 2em">線從乙從丁作乙己丁壬線與乙戊等乙戊己角六</span>  
<span style="margin-left: 2em">十度己戊甲角必三十度爲六邊形之半角也末從</span>  
<span style="margin-left: 2em">心過己過壬作戊午戊子線成戊午子等角形己戊</span>  
<span style="margin-left: 9em">壬既六十度則午子爲等形之邊</span>  
<span style="margin-left: 9em">設甲午股一百五十三<sub class="note-yuan">任設此數以便推算</sub></span>  
<span style="margin-left: 9em">午子或午戊弦必三百〇六各自</span>  
<span style="margin-left: 9em">之股方得二萬三千四百〇九弦</span>  
<span style="margin-left: 9em">方得九萬三千六百三十六相减</span>  
<span style="margin-left: 9em">餘七萬〇二百二十七爲句方開</span>  
<span style="margin-left: 9em">得二百六十五有奇爲戊甲句半</span>  
<span style="margin-left: 9em">徑也則戊甲與甲午之比例爲二</span>  
<span style="margin-left: 2em">六五有奇與一五三次平分午戊甲角作戊庚線任</span>  
<span style="margin-left: 2em">分午甲于庚則午戊與戊甲若午庚與甲庚<sub class="note-yuan">六卷三題</sub>合</span>  
<span style="margin-left: 2em">之戊午偕戊甲而與戊甲若午庚偕甲庚而與甲庚</span>  
<span style="margin-left: 2em">更之戊午并戊甲而與午甲<sub class="note-yuan">即午庚偕甲庚</sub>若戊甲與甲庚</span>  
<span style="margin-left: 2em">先定戊午戊甲并得五七一有奇午甲爲一五三則</span>  
<span style="margin-left: 2em">戊午并戊甲與甲午之比例若五七一與一五三若</span>  
<span style="margin-left: 2em">設甲庚一五三則戊甲與甲庚之比例爲五七一與</span>  
<span style="margin-left: 2em">一五三矣即以兩數自之并而開方得五九一又八</span>  
<span style="margin-left: 2em">之一不盡爲庚戊線<sub class="note-yuan">戊甲甲庚之弦</sub>則庚戊與甲庚之比例</span>  
<span style="margin-left: 2em">若五九一又八之一不盡與一五三次平分庚戊甲</span>  
<span style="margin-left: 2em">角作戊辛線則戊庚并戊甲一一六二又八之一與</span>  
<span style="margin-left: 2em">庚甲一五三若戊甲與甲辛若設甲辛一五三則戊</span>  
<span style="margin-left: 2em">甲爲一一六二又八之一有奇兩數各自之并而開</span>  
<span style="margin-left: 2em">方得二七二又八之一爲辛戊線<sub class="note-yuan">甲戊甲辛之弦</sub>則辛戊與</span>  
<span style="margin-left: 2em">辛甲之比例若二七二又八之一與一五三次平分</span>  
<span style="margin-left: 2em">辛戊甲角作戊寅線則辛戊并戊甲二三三四又四</span>  
<span style="margin-left: 9em">之一與辛甲一五三若戊甲與甲</span>  
<span style="margin-left: 9em">寅若設甲寅爲一五三則戊甲爲</span>  
<span style="margin-left: 9em">二三三四又四之一有奇兩數各</span>  
<span style="margin-left: 9em">自之并而開方得二三三九又四</span>  
<span style="margin-left: 2em">之一有奇爲寅戊線<sub class="note-yuan">戊甲甲寅之弦</sub>則寅戊與寅甲之比例</span>  
<span style="margin-left: 2em">若二三三九又四之一有奇與一五三次平分寅戊</span>  
<span style="margin-left: 2em">甲角作未戊線則寅戊并戊甲四六七三半有奇與</span>  
<span style="margin-left: 2em">寅甲一五三若戊甲與甲未若設甲未爲一五三則</span>  
<span style="margin-left: 2em">戊甲爲四六七三半有奇</span>  
<span style="margin-left: 2em">論曰午戊子元角爲三等角形之一即一直角三之</span>  
<span style="margin-left: 2em">二午戊甲其半則三之一庚戊甲其半則六之一辛</span>  
<span style="margin-left: 2em">戊甲其半則十二之一寅戊甲其半則二十四之一</span>  
<span style="margin-left: 2em">未戊甲其半則四十八之一復作甲戊申角與甲戊</span>  
<span style="margin-left: 2em">未角等成未戊申角形其戊角爲直角二十四之一</span>  
<span style="margin-left: 2em">而未申弧爲象限弧二十四之一于全周爲九十六</span>  
<span style="margin-left: 2em">之一未甲申其切線也爲九十六邊形之一邊此邊</span>  
<span style="margin-left: 2em">與圈全徑之比例若戊甲四六七三半與甲未一五</span>  
<span style="margin-left: 2em">三末置九十六邊形之一邊爲一五三因周爲一四</span>  
<span style="margin-left: 2em">六八八徑爲四六七三半有奇則九十六邊圈外形</span>  
<span style="margin-left: 2em">之周與圈徑之比例爲一四六八八與四六七三半</span>  
<span style="margin-left: 9em">約之爲三又七之一不足則徑爲</span>  
<span style="margin-left: 9em">一九十六邊圈外周爲三又七之</span>  
<span style="margin-left: 9em">一不足夫形在周之外尚不及三</span>  
<span style="margin-left: 9em">又七之一况圈周乎</span>  
<span style="margin-left: 9em">二解三倍又七十一之十而盈者</span>  
<span style="margin-left: 9em">曰圈內作乙丙徑從丙作六邊形</span>  
<span style="margin-left: 9em">之一邊丙甲與半徑戊丙等<sub class="note-yuan">四卷十五</sub></span>  
<span style="margin-left: 9em">從乙作乙甲成乙甲丙形在半圈</span>  
<span style="margin-left: 9em">之內則甲爲直角<sub class="note-yuan">三卷三十一題</sub>設甲丙</span>  
<span style="margin-left: 9em">句七百八十〇乙丙弦一千五百</span>  
<span style="margin-left: 2em">六十〇兩數自之相减開方得一千三百五十一不</span>  
<span style="margin-left: 2em">足爲乙甲股則乙甲與甲丙之比例爲一三五一與</span>  
<span style="margin-left: 2em">七八〇次平分甲乙丙角作乙丁線又作丁丙線成</span>  
<span style="margin-left: 2em">乙丁丙丙丁己兩直角形相似蓋同用丁直角在半</span>  
<span style="margin-left: 2em">圈內甲丁丁丙兩所乘之弧等則丁丙己丁乙丙兩</span>  
<span style="margin-left: 2em">弧之角必等<sub class="note-yuan">三卷二十一</sub>夫兩形有兩角等者各腰俱相</span>  
<span style="margin-left: 2em">似則乙丁<sub class="note-yuan">大形之股</sub>與丁丙<sub class="note-yuan">大形之句</sub>若丁丙<sub class="note-yuan">小形之股</sub>與丁己<sub class="note-yuan">小形</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">之句</sub>又乙丙<sub class="note-yuan">大形之弦</sub>與丁丙<sub class="note-yuan">大形之句</sub>若己丙<sub class="note-yuan">小形之弦</sub>與丁己<sub class="note-yuan">小形</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">之句</sub>更之乙丙與己丙<sub class="note-yuan">兩弦</sub>若丁丙與丁己<sub class="note-yuan">兩句</sub>是乙丁與</span>  
<span style="margin-left: 2em">丁丙<sub class="note-yuan">兩股</sub>丁丙與丁己<sub class="note-yuan">兩句</sub>乙丙與己丙<sub class="note-yuan">兩弦</sub>三比例皆等</span>  
<span style="margin-left: 2em">又乙丙與己丙<sub class="note-yuan">兩弦</sub>若乙丙并乙甲<sub class="note-yuan">兩腰</sub>與甲丙底之兩</span>  
<span style="margin-left: 2em">分<sub class="note-yuan">見前解</sub>則乙丁與丁丙亦若乙丙并乙甲與甲丙先</span>  
<span style="margin-left: 2em">定乙甲一三五一弱乙丙一五六〇是乙甲乙丙并</span>  
<span style="margin-left: 2em">爲二九一一弱甲丙先設七八〇則乙丁與丁丙亦</span>  
<span style="margin-left: 2em">爲二九一一弱與七八〇各自之并而開方得三〇</span>  
<span style="margin-left: 2em">一二又四之一弱爲乙丙<sub class="note-yuan">乙丁丁丙之弦</sub>則乙丙與丁丙之</span>  
<span style="margin-left: 2em">比例爲三〇一三又四之一弱與七八〇次平分丁</span>  
<span style="margin-left: 2em">乙丙角作辛乙線因前比例論得乙辛與辛丙比例</span>  
<span style="margin-left: 2em">之數蓋丁乙并乙丙與丙丁若乙辛與辛丙先定乙</span>  
<span style="margin-left: 2em">丙三〇一三又四之一乙丁二九一一弱并爲五九</span>  
<span style="margin-left: 2em">二四又四之一弱今丙丁爲七八〇則乙辛與辛丙</span>  
<span style="margin-left: 2em">爲五九二四又四之一弱與七八〇欲省數改設辛</span>  
<span style="margin-left: 2em">丙二四〇依三率法辛丙七八〇乙辛爲五九二四</span>  
<span style="margin-left: 2em">有奇今辛丙二四〇即乙辛爲一八二三弱兩數自</span>  
<span style="margin-left: 2em">之并而開方得一八三八又十一之九弱爲乙丙線</span>  
<span style="margin-left: 2em"><sub class="note-yuan">乙辛辛丙之弦</sub>則二四〇與一八三八又十一之九爲丙辛</span>  
<span style="margin-left: 2em">乙辛之比例次平分辛乙丙角作乙壬壬丙兩線辛</span>  
<span style="margin-left: 2em">乙乙丙兩數并爲三六六一又十一之九弱與辛丙</span>  
<span style="margin-left: 2em">二四〇爲乙壬與壬丙之比例又改設壬丙六六依</span>  
<span style="margin-left: 2em">三率法乙壬爲一〇〇七弱兩數自之并而開方得</span>  
<span style="margin-left: 9em">一〇〇九弱則六六與一〇〇九</span>  
<span style="margin-left: 9em">爲壬丙與乙丙兩線之比例末平</span>  
<span style="margin-left: 9em">分壬乙丙角作乙庚庚丙兩線乙</span>

<span style="margin-left: 1em">截形法</span>  
<span style="margin-left: 2em">借題云設多邊形截爲多三角形求作多線以<sub class="note-yuan">當各形之</sub></span>  
<span style="margin-left: 7em"><sub class="note-yuan">比例</sub>如圖甲乙丙丁戊多邊形從甲角作</span>  
<span style="margin-left: 7em">甲戊甲丁甲丙各對角線分元形爲四</span>  
<span style="margin-left: 7em">三角形求其比例法曰從各角向各對</span>  
<span style="margin-left: 7em">線爲垂線如己向庚戊向辛丁向壬又</span>  
<span style="margin-left: 2em">向子丙向癸乙向丑<sub class="note-yuan">丁壬丙癸因對角線短故垂線在形之外蓋三角形論底論高</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">不論垂線內外</sub>因幾何六卷第一題增同底之形其比例若</span>  
<span style="margin-left: 8em">其高之比例今甲戊己甲戊丁兩形</span>  
<span style="margin-left: 8em">同用甲戊爲底即己庚壬丁兩垂線</span>  
<span style="margin-left: 8em">爲兩形之比例又甲戊丁甲丁丙兩</span>  
<span style="margin-left: 8em">形同用甲丁爲底即戊辛丙癸兩垂</span>

<span style="margin-left: 2em">丑<sub class="note-yuan">元數</sub>與某線而某線之數爲乙丑之次數</span>

<span style="margin-left: 2em">若命截線與底平行則用三率法依設形成三角形</span>  
<span style="margin-left: 2em">得其腰求兩形之比例得全三角之積若干小三角</span>  
<span style="margin-left: 5em">形之積若干以小减大得梯形積若干因算</span>  
<span style="margin-left: 5em">梯形之幾分得全形之幾分隨用前第一設</span>  
<span style="margin-left: 5em">截三角形之法得所求</span>  
<span style="margin-left: 2em">假如大底爲十上邊爲六斜邊得四上下邊之較四</span>  
<span style="margin-left: 2em">半之得二爲第一率大底半數五爲二率斜邊四爲</span>  
<span style="margin-left: 2em">三率算得全形之腰爲十此全形有兩腰有底求其</span>  
<span style="margin-left: 2em">積得四十三又三之一其小形有兩腰各六有底六</span>  
<span style="margin-left: 2em">求其積得十五又五之三以減全積得二十七又三</span>  
<span style="margin-left: 2em">之二弱爲元梯形之積今欲截取四之一以四而一</span>  
<span style="margin-left: 2em">得六又五之四弱以除全積得六有五之二弱爲元</span>  
<span style="margin-left: 2em">形四之一亦爲全形六分五之二分用平行截三角</span>  
<span style="margin-left: 2em">形之法六有奇爲母五有奇<sub class="note-yuan">减一得子</sub>爲子相乘開方得</span>  
<span style="margin-left: 2em">五〇〇即從全形上角分全腰爲六分有五之二弱</span>  
<span style="margin-left: 2em">內取五又五之四強作平行線分元形如所求<sub class="note-yuan">或取三十</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">二而取二十九</sub></span>

<span style="margin-left: 2em">元形四之一分爲六又六十之四十六畧約五之四</span>
