## 续修四库全书提要

<sub class="note-jiao">校：爾時大多館藏清點未明與今大異姑錄之</sub>

<span style="margin-left: 1em">崇祯历书</span>  

### 崇祯历书七十三卷

<span style="margin-left: 2em">明徐光启等撰光启字子先号</span>  
<span style="margin-left: 2em">玄扈江苏上海人崇祯初为礼部尚书寻擢入阁参</span>  
<span style="margin-left: 2em">机务颇为上所重光启禀赋聪颖器识过人时耶稣</span>  
<span style="margin-left: 2em">教士意大利人利玛窦来中土传教擅天文算法火</span>  
<span style="margin-left: 2em">器诸术尤精于历光启从之游尽得其术复与意人</span>  
<span style="margin-left: 2em">龙华民罗雅谷瑞士人邓玉函等同修正中国历法</span>  
<span style="margin-left: 2em">尤为时人所重晚年以接近传教士多遂入教受洗</span>  
<span style="margin-left: 2em">礼加名保禄崇祯癸酉卒赠太保谥文定其译著诸</span>  
<span style="margin-left: 2em">书甚多有几何原本新法算书测量法义等大都已</span>  
<span style="margin-left: 2em">为四库著录所收此书为其卒后十年所刻凡七十</span>  
<span style="margin-left: 2em">三卷均历数计算之作计二十有三种首卷为奏疏</span>  
<span style="margin-left: 2em">均出光启手其余为割圆勾股八线表日躔表月离</span>  
<span style="margin-left: 2em">表交食表学历小辨测量全义日躔历指月离历指</span>  
<span style="margin-left: 2em">五纬历指交食历指恒星出没表古今交食考测食</span>  
<span style="margin-left: 2em">浑天仪说测天约说大测几何要法新法历引历法</span>  
<span style="margin-left: 2em">西传新法表异黄赤道距度表比例规解等二十二</span>  
<span style="margin-left: 2em">种多署为西儒汤若望罗雅谷汤儒略邓玉函等名</span>  
<span style="margin-left: 2em">间有光启译注者亦非多见惟学历小辨一卷则署</span>  
<span style="margin-left: 2em">光启所撰推理演论详尽明确其有文字不能尽者</span>  
<span style="margin-left: 2em">率以图解之明清之交西学东渐士大夫从学者多</span>  
<span style="margin-left: 2em">光启实导先河此盖其鸠集西人修正历法之余驳</span>  
<span style="margin-left: 2em">诘推敲各纾所见日积月累蔚成巨帙法式规程亦</span>  
<span style="margin-left: 2em">成大观推之后世俾有遵循固亦不可泯灭之著也</span>  

### 测食二卷

<span style="margin-left: 2em">德意志国人汤若望撰是编论推算日食月食之理</span>  
<span style="margin-left: 2em">其说约曰天学家究日月诸星之理设为圜界以论</span>  
<span style="margin-left: 2em">其运动分为五支其一论从月星之本圜小轮而应</span>  
<span style="margin-left: 2em">其居所不一其二论月星之随应太阳如臣庶之应</span>  
<span style="margin-left: 2em">其启其三论月星与太阳相近相远相会相对其四</span>  
<span style="margin-left: 2em">论月星应日躔赤道之远近其五论月星显示人目</span>  
<span style="margin-left: 2em">之别垂象向地之异本编于前四支不具论仅论其</span>  
<span style="margin-left: 2em">第五支厘为上下二篇上篇分子目八述食之梗概</span>  
<span style="margin-left: 2em">下篇分子自十七穷食之义理综观其说在今视之</span>  
<span style="margin-left: 2em">则极浅近然而当时已为细密录而存之庶可考测</span>  
<span style="margin-left: 2em">食之法由疏入密之渐也</span>  

### 古今交食考一卷

<span style="margin-left: 2em">德意志国人汤若望撰意大利国人罗雅谷订明史</span>  
<span style="margin-left: 2em">意大里亚传称崇祯时历法益疏舛礼部尚书徐光</span>  
<span style="margin-left: 2em">启请令其徒罗雅谷汤若望等以其国新法相参较</span>  
<span style="margin-left: 2em">开局纂修报可久之书成考光启奏请开局事在崇</span>  
<span style="margin-left: 2em">祯二年次年召雅谷至京同若望会同纂修崇祯七</span>  
<span style="margin-left: 2em">年二人会纂天文算法之书共为一百三十七卷多</span>  
<span style="margin-left: 2em">已收入新法算书中是编历引经史中之日食月食</span>  
<span style="margin-left: 2em">逐条用新法推算其误计日食二十一条月食十二</span>  
<span style="margin-left: 2em">条止于天启元年盖以当时新法旧法之争特撰是</span>  
<span style="margin-left: 2em">编以证旧法之谬而新法之密者也雅谷一作雅各</span>  
<span style="margin-left: 2em">字味韶以崇祯十一年卒于北京云</span>  

### 恒星历指三卷

<span style="margin-left: 2em">明徐光启督修汤若望撰光启字子先上海人明神</span>  
<span style="margin-left: 2em">宗二十五年举乡试第一由庶吉士官至礼部尚书</span>  
<span style="margin-left: 2em">卒谥文定精于天文历法算术译著甚富中国历法</span>  
<span style="margin-left: 2em">之近于精密自光启始汤若望字道未西洋人明崇</span>  
<span style="margin-left: 2em">祯二年因传天主教入中国精明历算明代历法之</span>  
<span style="margin-left: 2em">改革多氏之力在中国与徐氏致力天算输入科学</span>  
<span style="margin-left: 2em">是书为崇祯历书之一种首页署钦差礼部尚书兼</span>  
<span style="margin-left: 2em">翰林院学士协理詹事府事加俸一级徐光启奉勅</span>  
<span style="margin-left: 2em">督修极西耶稣会士汤若望撰同会龙华民罗雅谷</span>  
<span style="margin-left: 2em">同订访举李遇春推算陈子阶绘图祝懋元魏邦纶</span>  
<span style="margin-left: 2em">同测以专家各司其事足见修纂是书时规模之大</span>  
<span style="margin-left: 2em">按明季以旧历未善复因新法输入乃别撰历书由</span>  
<span style="margin-left: 2em">徐汤等总其事成崇祯历书一百二十六卷凡日躔</span>  
<span style="margin-left: 2em">交食割圆八线无不最备洵集天文历法算术之大</span>  
<span style="margin-left: 2em">成也四库提要虽撰有新法算书一百卷仅概论总</span>  
<span style="margin-left: 2em">名殊嫌简略此书考证精华详自谓当无舛戾实非</span>  
<span style="margin-left: 2em">夸妄所拟新历以崇祯元年戊辰岁为历元一切撰</span>  
<span style="margin-left: 2em">造以是年为始故恒星黄赤道经纬皆用是年实躔</span>  
<span style="margin-left: 2em">度分展转推算别为恒星历指三卷卷一恒星测法</span>  
<span style="margin-left: 2em">共八题二十二章为测恒星法第一独测星法第二</span>  
<span style="margin-left: 2em">重测恒星法第三以赤道之周度察恒星之经度第</span>  
<span style="margin-left: 2em">四以恒星赤道经纬度求其黄道经纬度第五以恒</span>  
<span style="margin-left: 2em">星测恒星第六测恒星之资第七测恒星之器第八</span>  
<span style="margin-left: 2em">卷二恒星经纬度共四题十二章为恒星本恒第一</span>  
<span style="margin-left: 2em">岁差第二恒星变易度第三恒星黄道经纬度变易</span>  
<span style="margin-left: 2em">第四卷三经纬相求为以恒星之黄道经纬度求其</span>  
<span style="margin-left: 2em">赤道经纬度第一以度数图星象第二绘总星图第</span>  
<span style="margin-left: 2em">三恒星有等无数第四盖首言测验诸法次言本行</span>  
<span style="margin-left: 2em">及经纬度变易又次言经纬相求绘图法义于所谓</span>  
<span style="margin-left: 2em">深论理明著数者未及详备已得其十二三矣书中</span>  
<span style="margin-left: 2em">各条皆绘图立算以资证明较之旧历精密远矣其</span>  
<span style="margin-left: 2em">分宫分宿与本星躔度皆系见测即较之回回历立</span>  
<span style="margin-left: 2em">成所载亦加详而正确焉凡测而入表者一千三百</span>  
<span style="margin-left: 2em">五十六星所分大小等次远近位置纡直形模悉与</span>  
<span style="margin-left: 2em">天象相合按此书之优长在其乃创造而繁难非改</span>  
<span style="margin-left: 2em">易旧图或倣摩悬象皆于黄赤经纬每座每星测算</span>  
<span style="margin-left: 2em">既确次于图中依表点定先加印记后方联缀宜其</span>  
<span style="margin-left: 2em">详细而正确也惜当时因门户之见虽由徐汤诸人</span>  
<span style="margin-left: 2em">推算新历未克全行至清初复修历象全书中国历</span>  
<span style="margin-left: 2em">算始大进步也</span>  

### 康熙永年历法不分卷

<span style="margin-left: 2em">清南仁怀闵明我俱宜嗒喇修南怀仁比利时国人</span>  
<span style="margin-left: 2em">康熙间入中国传教以推算历法为圣祖所信任累</span>  
<span style="margin-left: 2em">官钦天监正卒谥勤悫著有坤舆图说西方要纪等</span>  
<span style="margin-left: 2em">是书凡分六表各表之后皆附立永年表法首月离</span>  
<span style="margin-left: 2em">表次火星表次水星表次金星表次交食表次木星</span>  
<span style="margin-left: 2em">表凡各表之距冬至日行正交行月孛引数最高行</span>  
<span style="margin-left: 2em">伏见行首朔太阳引数太阴引数交周度太阳经度</span>  
<span style="margin-left: 2em">宿记日等均于表内详载其度分秒等又各表均自</span>  
<span style="margin-left: 2em">历元戊辰二百年后戊子年起己酉年止惟金星表</span>  
<span style="margin-left: 2em">则自戊午年起庚戌年止各表之前均有列监副及</span>  
<span style="margin-left: 2em">左右监副校正衔名及传士天文生布算衔名书前</span>  
<span style="margin-left: 2em">无序跋各表记自为起迄又无刻书年月但各行星</span>  
<span style="margin-left: 2em">内尚缺土星表则非完帙可知矣</span>  

### 交食历书

<span style="margin-left: 2em">泰西南怀仁撰怀仁比利时国人耶稣教会之宣教</span>  
<span style="margin-left: 2em">师康熙初入中国传教以推算历法为清圣祖所信</span>  
<span style="margin-left: 2em">任累官钦天监正卒谥勤悫著有坤舆图说西方要</span>  
<span style="margin-left: 2em">记等是编悉为黄道九十度表于康熙二十二年孟</span>  
<span style="margin-left: 2em">春依盛京北极高四十二度所推者其表示九十度</span>  
<span style="margin-left: 2em">限距天顶若干度分九十度限距正午若干度分九</span>  
<span style="margin-left: 2em">十度限在黄道何宫度分由白羊宫起依次金牛双</span>  
<span style="margin-left: 2em">兄巨蟹狮子室女天秤天蝎人马磨羯宝瓶双鱼各</span>  
<span style="margin-left: 2em">宫顺推怀仁于书首附有图说谓黄道九十度限者</span>  
<span style="margin-left: 2em">即黄道出地平东西各九十度之中限也凡推日食</span>  
<span style="margin-left: 2em">以此为最要其理论详在交食历指等书然多理之</span>  
<span style="margin-left: 2em">论亦或可简略于目前一面之图如所见浑天之广</span>  
<span style="margin-left: 2em">大简略于一目之小然庶可因图而推立法之原由</span>  
<span style="margin-left: 2em">矣书末附太阳高度表及因三角形之理而立九十</span>  
<span style="margin-left: 2em">度表法云</span>  

## 四库全书提要


### 新法算书一百卷

<span style="margin-left: 5em">明大学士徐光启太仆寺</span>  
<span style="margin-left: 5em">少卿李之藻光禄寺卿李天经及西洋人龙</span>  
<span style="margin-left: 5em">华民邓玉函罗雅谷汤若望等所修西洋新</span>  
<span style="margin-left: 5em">历也明自成化以后历法愈谬而台官墨守</span>  
<span style="margin-left: 5em">旧闻朝廷亦惮于<sub class="note-jiao">校：以下於字文津本皆作于</sub>改作建议</span>  
<span style="margin-left: 5em">者俱格不行万历中大西洋人龙华民邓玉</span>  
<span style="margin-left: 5em">函等先后至京俱精究律法<sub class="note-jiao">校：律文津本作曆</sub>五官</span>  
<span style="margin-left: 5em">正周子愚请令参订修改礼部因举光启之</span>  
<span style="margin-left: 5em">藻任其事而庶务因循未暇开局至崇祯二</span>  
<span style="margin-left: 5em">年推日食不验礼部乃始奏请开局修改以</span>  
<span style="margin-left: 5em">光启领之时满城布衣魏文魁著历元历测</span>  
<span style="margin-left: 5em">二书令其子献诸朝光启作学历小辨以斥</span>  
<span style="margin-left: 5em">其谬文魁之说遂绌于是光启督成历书数</span>  
<span style="margin-left: 5em">十卷次第奏进而光启病卒李天经代董其</span>  
<span style="margin-left: 5em">事又续以所作历书及仪器上进其书凡十</span>  
<span style="margin-left: 5em">一部曰法原曰法数曰法算曰法器曰会通</span>  
<span style="margin-left: 5em">谓之基本五目曰日躔曰恒星曰月离曰日</span>  
<span style="margin-left: 5em">月交会曰五纬星曰五星交会谓之节次六</span>  
<span style="margin-left: 5em">目<sub class="note-jiao">校：以上五十字文津本刪</sub>书首为修历缘起皆当时奏</span>  
<span style="margin-left: 5em">疏及考测辨论之事书末历法西传新法表</span>  
<span style="margin-left: 5em">异二种则汤若望入</span>  
<span style="margin-left: 4em">本朝后所作而附刻以行者其中有解有术有</span>  
<span style="margin-left: 5em">图有考有表有论皆钩深索隐密合天行足</span>  
<span style="margin-left: 5em">以尽欧罗巴历学之蕴然其时牵制于廷臣</span>  
<span style="margin-left: 5em">之门户虽诏立两局累年测验明知新法之</span>  
<span style="margin-left: 5em">密竟不能行迨</span>  
<span style="margin-left: 3em">圣代龙兴乃因其成帙用备畴人之掌岂非</span>  
<span style="margin-left: 2em">天之所祐有开必先莫知其然而然者耶越我</span>  
<span style="margin-left: 2em">圣祖仁皇帝天亶聪明乾坤合契</span>  
<span style="margin-left: 2em">御制数理精蕴历象考成诸编益复推阐微茫穷究</span>  
<span style="margin-left: 5em">正变如月离二三均数分为二表交食改黄</span>  
<span style="margin-left: 5em">平象限用白平象限方位以髙弧定上下左</span>  
<span style="margin-left: 5em">右又增借根方法解对数法解于点线面体</span>  
<span style="margin-left: 5em">部之末皆是书所未能及者八线表旧以半</span>  
<span style="margin-left: 5em">径数为十万各线数逐分列之今改半径数</span>  
<span style="margin-left: 5em">为千万各线数逐十秒列之用以步算尤为</span>  
<span style="margin-left: 5em">径捷<sub class="note-jiao">校：以上一百二字文津本刪</sub>至</span>  
<span style="margin-left: 3em">钦定历象考成后编日月以本天为椭圆交食以</span>  
<span style="margin-left: 5em">日月两经斜距为白道以视行取视距推步</span>  
<span style="margin-left: 5em">之密垂范万年<sub class="note-jiao">校：以上三十四字文津本刪</sub>又非光启等</span>  
<span style="margin-left: 5em">所能企及然授时改宪之所自其源流实本</span>  
<span style="margin-left: 5em">于是编故具录存之庶论西法之权舆者有</span>  
<span style="margin-left: 5em">考于斯焉</span>
