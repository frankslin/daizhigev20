## 續修四庫全書提要

<sub class="note-jiao">校：爾時大多館藏清點未明與今大異姑錄之</sub>

<span style="margin-left: 1em">崇禎曆書</span>  

### 崇禎曆書七十三卷

<span style="margin-left: 2em">明徐光啓等撰光啓字子先號</span>  
<span style="margin-left: 2em">玄扈江蘇上海人崇禎初爲禮部尚書尋擢入閣參</span>  
<span style="margin-left: 2em">機務頗爲上所重光啓稟賦聰穎器識過人時耶穌</span>  
<span style="margin-left: 2em">教士意大利人利瑪竇來中土傳教擅天文算法火</span>  
<span style="margin-left: 2em">器諸術尤精於曆光啓從之遊盡得其術復與意人</span>  
<span style="margin-left: 2em">龍華民羅雅谷瑞士人鄧玉函等同修正中國曆法</span>  
<span style="margin-left: 2em">尤爲時人所重晚年以接近傳教士多遂入教受洗</span>  
<span style="margin-left: 2em">禮加名保祿崇禎癸酉卒贈太保謚文定其譯著諸</span>  
<span style="margin-left: 2em">書甚多有幾何原本新法算書測量法義等大都已</span>  
<span style="margin-left: 2em">爲四庫著錄所收此書爲其卒後十年所刻凡七十</span>  
<span style="margin-left: 2em">三卷均曆數計算之作計二十有三種首卷爲奏疏</span>  
<span style="margin-left: 2em">均出光啓手其餘爲割圓勾股八線表日躔表月離</span>  
<span style="margin-left: 2em">表交食表學曆小辨測量全義日躔曆指月離曆指</span>  
<span style="margin-left: 2em">五緯曆指交食曆指恆星出沒表古今交食考測食</span>  
<span style="margin-left: 2em">渾天儀說測天約說大測幾何要法新法曆引曆法</span>  
<span style="margin-left: 2em">西傳新法表異黃赤道距度表比例規解等二十二</span>  
<span style="margin-left: 2em">種多署爲西儒湯若望羅雅谷湯儒略鄧玉函等名</span>  
<span style="margin-left: 2em">間有光啓譯註者亦非多見惟學曆小辨一卷則署</span>  
<span style="margin-left: 2em">光啓所撰推理演論詳盡明確其有文字不能盡者</span>  
<span style="margin-left: 2em">率以圖解之明清之交西學東漸士大夫從學者多</span>  
<span style="margin-left: 2em">光啓實導先河此蓋其鳩集西人修正曆法之餘駁</span>  
<span style="margin-left: 2em">詰推敲各紓所見日積月累蔚成巨帙法式規程亦</span>  
<span style="margin-left: 2em">成大觀推之後世俾有遵循固亦不可泯滅之著也</span>  

### 測食二卷

<span style="margin-left: 2em">德意志國人湯若望撰是編論推算日食月食之理</span>  
<span style="margin-left: 2em">其說約曰天學家究日月諸星之理設爲圜界以論</span>  
<span style="margin-left: 2em">其運動分爲五支其一論從月星之本圜小輪而應</span>  
<span style="margin-left: 2em">其居所不一其二論月星之隨應太陽如臣庶之應</span>  
<span style="margin-left: 2em">其啓其三論月星與太陽相近相遠相會相對其四</span>  
<span style="margin-left: 2em">論月星應日躔赤道之遠近其五論月星顯示人目</span>  
<span style="margin-left: 2em">之別垂象向地之異本編于前四支不具論僅論其</span>  
<span style="margin-left: 2em">第五支釐爲上下二篇上篇分子目八述食之梗概</span>  
<span style="margin-left: 2em">下篇分子自十七窮食之義理綜觀其說在今視之</span>  
<span style="margin-left: 2em">則極淺近然而當時已爲細密錄而存之庶可考測</span>  
<span style="margin-left: 2em">食之法由疏入密之漸也</span>  

### 古今交食考一卷

<span style="margin-left: 2em">德意志國人湯若望撰意大利國人羅雅谷訂明史</span>  
<span style="margin-left: 2em">意大里亞傳稱崇禎時曆法益疏舛禮部尚書徐光</span>  
<span style="margin-left: 2em">啓請令其徒羅雅谷湯若望等以其國新法相參較</span>  
<span style="margin-left: 2em">開局纂修報可久之書成考光啓奏請開局事在崇</span>  
<span style="margin-left: 2em">禎二年次年召雅谷至京同若望會同纂修崇禎七</span>  
<span style="margin-left: 2em">年二人會纂天文算法之書共爲一百三十七卷多</span>  
<span style="margin-left: 2em">已收入新法算書中是編曆引經史中之日食月食</span>  
<span style="margin-left: 2em">逐條用新法推算其誤計日食二十一條月食十二</span>  
<span style="margin-left: 2em">條止於天啓元年蓋以當時新法舊法之爭特撰是</span>  
<span style="margin-left: 2em">編以證舊法之謬而新法之密者也雅谷一作雅各</span>  
<span style="margin-left: 2em">字味韶以崇禎十一年卒於北京云</span>  

### 恆星曆指三卷

<span style="margin-left: 2em">明徐光啓督修湯若望撰光啓字子先上海人明神</span>  
<span style="margin-left: 2em">宗二十五年舉鄉試第一由庶吉士官至禮部尚書</span>  
<span style="margin-left: 2em">卒諡文定精於天文曆法算術譯著甚富中國曆法</span>  
<span style="margin-left: 2em">之近於精密自光啓始湯若望字道未西洋人明崇</span>  
<span style="margin-left: 2em">禎二年因傳天主教入中國精明曆算明代曆法之</span>  
<span style="margin-left: 2em">改革多氏之力在中國與徐氏致力天算輸入科學</span>  
<span style="margin-left: 2em">是書爲崇禎曆書之一種首頁署欽差禮部尚書兼</span>  
<span style="margin-left: 2em">翰林院學士協理詹事府事加俸一級徐光啓奉勅</span>  
<span style="margin-left: 2em">督修極西耶穌會士湯若望撰同會龍華民羅雅谷</span>  
<span style="margin-left: 2em">同訂訪舉李遇春推算陳子階繪圖祝懋元魏邦綸</span>  
<span style="margin-left: 2em">同測以專家各司其事足見修纂是書時規模之大</span>  
<span style="margin-left: 2em">按明季以舊曆未善復因新法輸入乃別撰曆書由</span>  
<span style="margin-left: 2em">徐湯等總其事成崇禎曆書一百二十六卷凡日躔</span>  
<span style="margin-left: 2em">交食割圓八線無不最備洵集天文曆法算術之大</span>  
<span style="margin-left: 2em">成也四庫提要雖撰有新法算書一百卷僅概論總</span>  
<span style="margin-left: 2em">名殊嫌簡略此書考證精華詳自謂當無舛戾實非</span>  
<span style="margin-left: 2em">夸妄所擬新曆以崇禎元年戊辰歲爲曆元一切撰</span>  
<span style="margin-left: 2em">造以是年爲始故恆星黃赤道經緯皆用是年實躔</span>  
<span style="margin-left: 2em">度分展轉推算別爲恆星曆指三卷卷一恆星測法</span>  
<span style="margin-left: 2em">共八題二十二章爲測恆星法第一獨測星法第二</span>  
<span style="margin-left: 2em">重測恆星法第三以赤道之周度察恆星之經度第</span>  
<span style="margin-left: 2em">四以恆星赤道經緯度求其黃道經緯度第五以恆</span>  
<span style="margin-left: 2em">星測恆星第六測恆星之資第七測恆星之器第八</span>  
<span style="margin-left: 2em">卷二恆星經緯度共四題十二章爲恆星本恆第一</span>  
<span style="margin-left: 2em">歲差第二恆星變易度第三恆星黃道經緯度變易</span>  
<span style="margin-left: 2em">第四卷三經緯相求爲以恆星之黃道經緯度求其</span>  
<span style="margin-left: 2em">赤道經緯度第一以度數圖星象第二繪總星圖第</span>  
<span style="margin-left: 2em">三恆星有等無數第四蓋首言測驗諸法次言本行</span>  
<span style="margin-left: 2em">及經緯度變易又次言經緯相求繪圖法義于所謂</span>  
<span style="margin-left: 2em">深論理明著數者未及詳備已得其十二三矣書中</span>  
<span style="margin-left: 2em">各條皆繪圖立算以資證明較之舊曆精密遠矣其</span>  
<span style="margin-left: 2em">分宮分宿與本星躔度皆係見測即較之回回曆立</span>  
<span style="margin-left: 2em">成所載亦加詳而正確焉凡測而入表者一千三百</span>  
<span style="margin-left: 2em">五十六星所分大小等次遠近位置紆直形模悉與</span>  
<span style="margin-left: 2em">天象相合按此書之優長在其乃創造而繁難非改</span>  
<span style="margin-left: 2em">易舊圖或倣摩懸象皆於黃赤經緯每座每星測算</span>  
<span style="margin-left: 2em">既確次於圖中依表點定先加印記後方聯綴宜其</span>  
<span style="margin-left: 2em">詳細而正確也惜當時因門戶之見雖由徐湯諸人</span>  
<span style="margin-left: 2em">推算新曆未克全行至清初復修曆象全書中國曆</span>  
<span style="margin-left: 2em">算始大進步也</span>  

### 康熙永年曆法不分卷

<span style="margin-left: 2em">清南仁懷閔明我俱宜嗒喇修南懷仁比利時國人</span>  
<span style="margin-left: 2em">康熙間入中國傳教以推算曆法爲聖祖所信任累</span>  
<span style="margin-left: 2em">官欽天監正卒謚勤慤著有坤輿圖說西方要紀等</span>  
<span style="margin-left: 2em">是書凡分六表各表之後皆附立永年表法首月離</span>  
<span style="margin-left: 2em">表次火星表次水星表次金星表次交食表次木星</span>  
<span style="margin-left: 2em">表凡各表之距冬至日行正交行月孛引數最高行</span>  
<span style="margin-left: 2em">伏見行首朔太陽引數太陰引數交周度太陽經度</span>  
<span style="margin-left: 2em">宿記日等均於表內詳載其度分秒等又各表均自</span>  
<span style="margin-left: 2em">曆元戊辰二百年後戊子年起己酉年止惟金星表</span>  
<span style="margin-left: 2em">則自戊午年起庚戌年止各表之前均有列監副及</span>  
<span style="margin-left: 2em">左右監副校正銜名及傳士天文生佈算銜名書前</span>  
<span style="margin-left: 2em">無序跋各表記自爲起迄又無刻書年月但各行星</span>  
<span style="margin-left: 2em">內尚缺土星表則非完帙可知矣</span>  

### 交食曆書

<span style="margin-left: 2em">泰西南懷仁撰懷仁比利時國人耶穌教會之宣教</span>  
<span style="margin-left: 2em">師康熙初入中國傳教以推算曆法爲清聖祖所信</span>  
<span style="margin-left: 2em">任累官欽天監正卒謚勤慤著有坤輿圖說西方要</span>  
<span style="margin-left: 2em">記等是編悉爲黄道九十度表於康熙二十二年孟</span>  
<span style="margin-left: 2em">春依盛京北極高四十二度所推者其表示九十度</span>  
<span style="margin-left: 2em">限距天頂若干度分九十度限距正午若干度分九</span>  
<span style="margin-left: 2em">十度限在黄道何宫度分由白羊宫起依次金牛雙</span>  
<span style="margin-left: 2em">兄巨蟹獅子室女天秤天蝎人馬磨羯寶瓶雙魚各</span>  
<span style="margin-left: 2em">宮順推懷仁於書首附有圖說謂黃道九十度限者</span>  
<span style="margin-left: 2em">即黄道出地平東西各九十度之中限也凡推日食</span>  
<span style="margin-left: 2em">以此爲最要其理論詳在交食曆指等書然多理之</span>  
<span style="margin-left: 2em">論亦或可簡略于目前一面之圖如所見渾天之廣</span>  
<span style="margin-left: 2em">大簡略于一目之小然庶可因圖而推立法之原由</span>  
<span style="margin-left: 2em">矣書末附太陽高度表及因三角形之理而立九十</span>  
<span style="margin-left: 2em">度表法云</span>  

## 四庫全書提要


### 新法算書一百卷

<span style="margin-left: 5em">明大學士徐光啟太僕寺</span>  
<span style="margin-left: 5em">少卿李之藻光祿寺卿李天經及西洋人龍</span>  
<span style="margin-left: 5em">華民鄧玉函羅雅谷湯若望等所修西洋新</span>  
<span style="margin-left: 5em">曆也明自成化以後曆法愈謬而臺官墨守</span>  
<span style="margin-left: 5em">舊聞朝廷亦憚於<sub class="note-jiao">校：以下於字文津本皆作于</sub>改作建議</span>  
<span style="margin-left: 5em">者俱格不行萬曆中大西洋人龍華民鄧玉</span>  
<span style="margin-left: 5em">函等先後至京俱精究律法<sub class="note-jiao">校：律文津本作曆</sub>五官</span>  
<span style="margin-left: 5em">正周子愚請令參訂修改禮部因舉光啟之</span>  
<span style="margin-left: 5em">藻任其事而庶務因循未暇開局至崇禎二</span>  
<span style="margin-left: 5em">年推日食不驗禮部乃始奏請開局修改以</span>  
<span style="margin-left: 5em">光啟領之時滿城布衣魏文魁著曆元曆測</span>  
<span style="margin-left: 5em">二書令其子獻諸朝光啟作學曆小辨以斥</span>  
<span style="margin-left: 5em">其謬文魁之説遂絀於是光啟督成曆書數</span>  
<span style="margin-left: 5em">十卷次第奏進而光啟病卒李天經代董其</span>  
<span style="margin-left: 5em">事又續以所作曆書及儀器上進其書凡十</span>  
<span style="margin-left: 5em">一部曰法原曰法數曰法算曰法器曰會通</span>  
<span style="margin-left: 5em">謂之基本五目曰日躔曰恆星曰月離曰日</span>  
<span style="margin-left: 5em">月交會曰五緯星曰五星交會謂之節次六</span>  
<span style="margin-left: 5em">目<sub class="note-jiao">校：以上五十字文津本刪</sub>書首爲修曆緣起皆當時奏</span>  
<span style="margin-left: 5em">疏及考測辨論之事書末曆法西傳新法表</span>  
<span style="margin-left: 5em">異二種則湯若望入</span>  
<span style="margin-left: 4em">本朝後所作而附刻以行者其中有解有術有</span>  
<span style="margin-left: 5em">圖有考有表有論皆鈎深索隱密合天行足</span>  
<span style="margin-left: 5em">以盡歐羅巴曆學之藴然其時牽制於廷臣</span>  
<span style="margin-left: 5em">之門户雖詔立兩局累年測驗明知新法之</span>  
<span style="margin-left: 5em">密竟不能行迨</span>  
<span style="margin-left: 3em">聖代龍興乃因其成帙用備疇人之掌豈非</span>  
<span style="margin-left: 2em">天之所祐有開必先莫知其然而然者耶越我</span>  
<span style="margin-left: 2em">聖祖仁皇帝天亶聰明乾坤合契</span>  
<span style="margin-left: 2em">御製數理精藴曆象考成諸編益復推闡微茫窮究</span>  
<span style="margin-left: 5em">正變如月離二三均數分爲二表交食改黃</span>  
<span style="margin-left: 5em">平象限用白平象限方位以髙弧定上下左</span>  
<span style="margin-left: 5em">右又增借根方法解對數法解於點線面體</span>  
<span style="margin-left: 5em">部之末皆是書所未能及者八線表舊以半</span>  
<span style="margin-left: 5em">徑數爲十萬各線數逐分列之今改半徑數</span>  
<span style="margin-left: 5em">爲千萬各線數逐十秒列之用以步算尤爲</span>  
<span style="margin-left: 5em">徑捷<sub class="note-jiao">校：以上一百二字文津本刪</sub>至</span>
