## 崇禎曆書卷之十　崇禎奏疏

*崇禎九年三月十七日至崇禎九年十二月十九日*

<span style="margin-left: 2em">緣起十</span>  
<span style="margin-left: 8em">崇禎九年三月十七日李天經題本</span>  
<span style="margin-left: 3em">督修曆法山東布政使司右參政臣李天經謹</span>  
<span style="margin-left: 2em">題爲遵</span>  
<span style="margin-left: 1em">旨回奏仰乞</span>  
<span style="margin-left: 1em">聖鑒事崇禎九年三月初五日准禮部照會內開該本</span>  
<span style="margin-left: 3em">部奏前事等因奉</span>  
<span style="margin-left: 1em">聖旨據稱各管俱有分屬地方豈無占驗又冬至葭管</span>  
<span style="margin-left: 2em">飛灰載在冊籍何云專取立春還着同李天經魏文</span>  
<span style="margin-left: 2em">魁再加詳考講求明白具奏欽此欽遵照會到臣該</span>  
<span style="margin-left: 3em">臣看得臣所職掌乃推步日月交食測算五星凌</span>  
<span style="margin-left: 3em">犯是皆有理可據有數可憑者耳即旁通首欵曾</span>  
<span style="margin-left: 3em">言事應亦第謂其考求七政性情約略預知初未</span>  
<span style="margin-left: 3em">嘗敢以瑣屑不經之事牽合傅會今該監候氣一</span>  
<span style="margin-left: 3em">法其散見于經典者悉後儒引以註疏律呂者也</span>  
<span style="margin-left: 3em">故史記以前言律曆者未之或及至後漢志則云</span>  
<span style="margin-left: 3em">律可相傳惟有候氣始紀其法而謂氣所動者其</span>  
<span style="margin-left: 3em">灰散人及風所動者其灰聚蓋按辰以候每月之</span>  
<span style="margin-left: 3em">中氣以定十二律之應與否也漢臣馬防云聖人</span>  
<span style="margin-left: 3em">作樂所以宣氣致和故于歲首發太簇之律然古</span>  
<span style="margin-left: 3em">謂律首黃鍾其位在子而宋儒朱子一主其說云</span>  
<span style="margin-left: 3em">冬至氣至黃鍾之管灰飛大寒以下隨月應焉是</span>  
<span style="margin-left: 3em">知候非止于一月</span>  
<span style="margin-left: 1em">明旨所謂何云專取立春蓋已洞其底裏矣臣歷考前</span>  
<span style="margin-left: 3em">代魏時杜䕫製律候氣灰悉不飛隋開皇間毛爽</span>  
<span style="margin-left: 3em">等依古法候氣有節至即應有終月不應之異而</span>  
<span style="margin-left: 3em">牛弘創爲衰氣和氣猛氣之說一經隋帝所駁遂</span>  
<span style="margin-left: 3em">無復置對宋景祐間李照請下河內取葭莩製玉</span>  
<span style="margin-left: 3em">律候氣以定樂率不能合惟北齊信都芳能以管</span>  
<span style="margin-left: 3em">灰候氣每月應律不爽時刻而先臣邢雲路謂其</span>  
<span style="margin-left: 3em">用機鼓動致然且自古相傳有謂當以紗縠蒙管</span>  
<span style="margin-left: 3em">端者有謂葭灰升降有毫忽者有謂灰用懐州河</span>  
<span style="margin-left: 3em">內縣竹用宜陽金門山者鄭康成有玉管銅管之</span>  
<span style="margin-left: 3em">別熊安有大動小動之徴其說互有異同法亦不</span>  
<span style="margin-left: 3em">能盡驗然皆止于候氣已耳至若主何占驗作何</span>  
<span style="margin-left: 3em">徴應臣于史冊未覩惟按</span>  
<span style="margin-left: 1em">大明會典一欵內云凡每歲立春前期五日本監</span>  
<span style="margin-left: 1em">面奏差官二員往順天府候氣至日回監具呈依書占</span>  
<span style="margin-left: 3em">奏則是明有一書存貯本監以待占奏乃該監主</span>  
<span style="margin-left: 3em">占官徐源直日官章必選俱稱玩占一書未經登</span>  
<span style="margin-left: 3em">載何敢臆說若然則</span>  
<span style="margin-left: 1em">會典所載依書占奏者豈無所據而云然該監所藏又</span>  
<span style="margin-left: 3em">豈止玩占一書而已耶蓋書爲該監所收掌占則</span>  
<span style="margin-left: 3em">靈臺之本業而乃茫無以對其于職掌何居耶臣</span>  
<span style="margin-left: 3em">謹詳史冊所載之大略若此如詡詡然謬爲不經</span>  
<span style="margin-left: 3em">之說以炫視聽則斷斷非臣所敢出也統祈</span>  
<span style="margin-left: 1em">聖明裁奪施行</span>  
<span style="margin-left: 3em">崇禎九年三月十七日具</span>  
<span style="margin-left: 2em">題二十日奉</span>  
<span style="margin-left: 1em">聖旨奏內依書占奏載在會典該監所貯是否止玩占</span>  
<span style="margin-left: 2em">一書還着詳查具奏禮部知道</span>  
<span style="margin-left: 8em">崇禎九年三月二十二日禮部題本</span>  
<span style="margin-left: 3em">禮部</span>  
<span style="margin-left: 2em">題爲測驗月食事祠祭清吏司案呈案查崇禎九年</span>  
<span style="margin-left: 3em">正月十五日曉望月食先該本部差委主客司員</span>  
<span style="margin-left: 3em">外郭之奇祠祭司主事李焻公同督修曆法參政</span>  
<span style="margin-left: 3em">李天經布衣魏文魁欽天監監正張守登隨委監</span>  
<span style="margin-left: 3em">官黃子賢劉有慶賈良琦及兩局生儒鄔明著林</span>  
<span style="margin-left: 3em">蔭世等是日在觀象臺公同測驗回奏月食緣因</span>  
<span style="margin-left: 3em">正月二十一日奉</span>  
<span style="margin-left: 1em">聖旨據奏測驗月食分秒初虧食甚及月未入見復光</span>  
<span style="margin-left: 2em">新法爲近但以十三日爲雨水是何說還著奏明其</span>  
<span style="margin-left: 2em">魏文魁所推食甚時刻與靈台測驗相符還俟河南</span>  
<span style="margin-left: 2em">山西二處奏報至日再加考究以正曆法欽此欽遵</span>  
<span style="margin-left: 3em">除十三日爲雨水緣繇李天經自行奏明外案查</span>  
<span style="margin-left: 3em">先該督修曆法山東布政使司右參政李天經手</span>  
<span style="margin-left: 3em">本開送曆局供事官陳應登差往山西知曆儒士</span>  
<span style="margin-left: 3em">黃宏憲差往河南仍同欽天監春官正潘國祥天</span>  
<span style="margin-left: 3em">文生朱光大攜帶測器以往隨該本部具題將陳</span>  
<span style="margin-left: 3em">應登朱光大差往山西潘國祥黃宏憲差往河南</span>  
<span style="margin-left: 3em">公同測驗緣因崇禎八年十二月十二日奉</span>  
<span style="margin-left: 1em">聖旨是欽此欽遵隨給咨文即令官生陳應登等四員</span>  
<span style="margin-left: 3em">名<sub class="note-jiao">校：名疑爲各字之誤</sub>齎文分投山西河南測驗去後今三</span>  
<span style="margin-left: 3em">月初八日接准提督鴈門等關兼巡撫山西地方</span>  
<span style="margin-left: 3em">都察院右僉都御史今降五級戴罪管事吳甡咨</span>  
<span style="margin-left: 3em">稱據山西布政使司呈准</span>  
<span style="margin-left: 1em">欽差曆局供事官陳應登等手本開稱職等奉</span>  
<span style="margin-left: 1em">旨前來山西測驗自正月初六日抵省奉有公同撫按</span>  
<span style="margin-left: 3em">測驗然撫院在平陸堵勦流冦地之相去千有餘</span>  
<span style="margin-left: 3em">里測驗地方題定太原欲會撫院往回必須半月</span>  
<span style="margin-left: 3em">有誤在府測驗于是蒙本司遣役齎咨投院而職</span>  
<span style="margin-left: 3em">等在省連日測得北極高三十七度四十四分至</span>  
<span style="margin-left: 3em">本月十五日辛酉曉望蒙本司會率司道府廳縣</span>  
<span style="margin-left: 3em">衛文武多官于十四日夜先詣本府鼓樓高闊處</span>  
<span style="margin-left: 3em">所安頓測量儀器三更時星月尚明候至寅正二</span>  
<span style="margin-left: 3em">刻內山烟層叠雲霧彌漫星月被遮觀測不見自</span>  
<span style="margin-left: 3em">初虧以至復圓分秒時刻無從考驗此皆蒙本司</span>  
<span style="margin-left: 3em">同司道府廳縣衛共目同見者也伏乞據實轉文</span>  
<span style="margin-left: 3em">撫按兩院請給咨文以憑回</span>  
<span style="margin-left: 2em">奏緣繇到司准此擬合呈報緣繇到院據此案查先</span>  
<span style="margin-left: 3em">據該司呈送禮部咨前事正值本院駐鎮河津于</span>  
<span style="margin-left: 3em">正月十五日曉望行救護禮時際天陰黑雲密布</span>  
<span style="margin-left: 3em">無繇測驗該本院遵照部咨會同巡按余御史備</span>  
<span style="margin-left: 3em">行布按二司公同道府衛縣文武各官會同該監</span>  
<span style="margin-left: 3em">官生陳應登等細加測驗從實呈報去後今據藩</span>  
<span style="margin-left: 3em">司呈詳前來擬合咨覆同日又准巡撫河南等處</span>  
<span style="margin-left: 3em">地方提督軍務都察院右副都御史陳必謙咨稱</span>  
<span style="margin-left: 3em">據河南布政使司呈蒙本院憲牌准禮部咨前事</span>  
<span style="margin-left: 3em">等因蒙此本司于正月十五日辛酉曉蒙巡按河</span>  
<span style="margin-left: 3em">南監察金御史率屬親詣西南城角樓高闊處所</span>  
<span style="margin-left: 3em">安頓測星儀器先以星晷測至句陳帝星視垂針</span>  
<span style="margin-left: 3em">所指寅正四刻內果見初虧又用象限儀測得角</span>  
<span style="margin-left: 3em">宿南星西高三十七度二十七分依法推算得在</span>  
<span style="margin-left: 3em">寅正四刻內五十六分候至卯正一刻內瞻見食</span>  
<span style="margin-left: 3em">甚仍測得河鼓中星東高四十度弱算得在卯正</span>  
<span style="margin-left: 3em">一刻內一十三分見食三分有奇其復圓時刻因</span>  
<span style="margin-left: 3em">復光未幾旋入地平而太陽東出無從考驗則自</span>  
<span style="margin-left: 3em">初虧以至食甚分秒時刻起復方位一一皆與新</span>  
<span style="margin-left: 3em">法脗合此城頭萬目所共覩者准此擬合轉報等</span>  
<span style="margin-left: 3em">因到院會同巡按金御史擬合回覆各等因到部</span>  
<span style="margin-left: 3em">送司通查案呈到部看得本年正月十五日月食</span>  
<span style="margin-left: 3em">除</span>  
<span style="margin-left: 2em">京師交食分數已經奏</span>  
<span style="margin-left: 1em">報今據山西既稱時值陰雲無從測驗又據河南所報</span>  
<span style="margin-left: 3em">自初虧以至食甚分秒時刻起復方位一一皆與</span>  
<span style="margin-left: 3em">新法脗合從此再加虛心考究而曆法漸次可有</span>  
<span style="margin-left: 3em">成績矣既經二處撫臣咨覆前來相應據實回</span>  
<span style="margin-left: 2em">奏爲此具本謹具題</span>  
<span style="margin-left: 1em">知　崇禎九年三月二十二日具題奉</span>  
<span style="margin-left: 1em">聖旨知道了</span>  
<span style="margin-left: 8em">崇禎九年四月初六日李天經題本</span>  
<span style="margin-left: 3em">督修曆法山東布政使司右參政臣李天經謹</span>  
<span style="margin-left: 2em">題爲星度方位昭然推算疏密立辨恭懇</span>  
<span style="margin-left: 1em">聖明親垂</span>  
<span style="margin-left: 1em">睿覽以破游移以襄</span>  
<span style="margin-left: 2em">大典事先該禮部回奏臣局測驗一疏奉</span>  
<span style="margin-left: 1em">聖旨新法成法雖有不同星度伏見仰觀可據徐源等</span>  
<span style="margin-left: 2em">既稱指示多合又云不敢扶同殊屬游移該部還遵</span>  
<span style="margin-left: 2em">旨遴委司官同監局各官生隨時測驗仍取準交食</span>  
<span style="margin-left: 2em">以期脗合欽此臣恭繹</span>  
<span style="margin-left: 1em">綸音不勝感戴以爲我</span>  
<span style="margin-left: 1em">皇上如此其慎密斯典而源等猶敢如此其淆亂含糊</span>  
<span style="margin-left: 3em">而不以實覆也總之若輩牢不可破之成心惟欲</span>  
<span style="margin-left: 3em">承舛襲訛嫉修改爲多事止知護短固位忌測驗</span>  
<span style="margin-left: 3em">爲摘發遂不難支離巧飾其辭如此耳獨不思測</span>  
<span style="margin-left: 3em">驗一事屢奉</span>  
<span style="margin-left: 1em">明旨命臣率領監局官儒詳加考驗則相與會同之際</span>  
<span style="margin-left: 3em">孰疎孰密臣自不能以一手掩其目一人箝其口</span>  
<span style="margin-left: 3em">然于入</span>  
<span style="margin-left: 1em">告之時合與不合監官自當據共見之確情絕浮游之</span>  
<span style="margin-left: 3em">囈語豈非虛公參訂而忠于</span>  
<span style="margin-left: 1em">皇上之職分哉今該監與臣屢測皆合即此曹豈無虛</span>  
<span style="margin-left: 3em">心嘆服者乃源等敢于回奏之日故爲游移是臣</span>  
<span style="margin-left: 3em">雖與之時時測而事事合則彼輩仍不難于面是</span>  
<span style="margin-left: 3em">背非欲其出一真實之語不可得也則亦何取于</span>  
<span style="margin-left: 3em">若而人之追隨仰觀哉兹該監之情形既若此而</span>  
<span style="margin-left: 3em">曉曆之訪求又未驟得臣於此時復何望哉惟有</span>  
<span style="margin-left: 3em">仰望之我</span>  
<span style="margin-left: 1em">皇上而已目今火星躔度據大統算從三月二十七日</span>  
<span style="margin-left: 3em">起至五月初八日止夕退遲留嘗在軫宿十六十</span>  
<span style="margin-left: 3em">七等度內而臣等用新法推步此等日時火星嘗</span>  
<span style="margin-left: 3em">在角宿二三等度內逆行不入軫宿見有本局</span>  
<span style="margin-left: 2em">進呈七政可查是則二法所推三十九日之中恒差</span>  
<span style="margin-left: 3em">二三度不等且舊法謂在軫宿則當恒在角宿大</span>  
<span style="margin-left: 3em">星西新法推在角宿則當恒在角宿大星東彰明</span>  
<span style="margin-left: 3em">較著莫此爲甚誠如</span>  
<span style="margin-left: 1em">皇上明旨所謂星度伏見仰觀可據者也敢懇</span>  
<span style="margin-left: 1em">皇上于萬幾之暇每于戌時不需儀器窺筩一仰觀間</span>  
<span style="margin-left: 3em">自可瞭若指掌臣非敢冒昧以此瑣事上凟</span>  
<span style="margin-left: 1em">聖聰竊念與其屢測屢覆而屢費</span>  
<span style="margin-left: 1em">聖心不若以乾象之昭著者一質于</span>  
<span style="margin-left: 1em">君父之前則新舊二法疎密了然從前所測皆可類推</span>  
<span style="margin-left: 3em">匪惟可以折該監沿習之故智而亦可以杜旁撓</span>  
<span style="margin-left: 3em">憎兹之多口則繇此漸底于成績而曆法亦可藉</span>  
<span style="margin-left: 3em">手告襄矣</span>  
<span style="margin-left: 3em">崇禎九年四月初六日具</span>  
<span style="margin-left: 2em">題初十日奉</span>  
<span style="margin-left: 1em">聖旨這推算火星躔度知道了還著禮部遴委司官同</span>  
<span style="margin-left: 2em">監局各官生公同驗明具奏</span>  
<span style="margin-left: 9em">崇禎九年四月初八日吏部題本</span>  
<span style="margin-left: 3em">吏部</span>  
<span style="margin-left: 2em">題爲書器告成錄叙宜加謹照原題查叙在事諸臣</span>  
<span style="margin-left: 3em">以示激勸事文選清吏司案呈崇禎九年三月初</span>
