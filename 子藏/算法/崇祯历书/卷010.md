## 崇祯历书卷之十　崇祯奏疏

*崇祯九年三月十七日至崇祯九年十二月十九日*

<span style="margin-left: 2em">缘起十</span>  
<span style="margin-left: 8em">崇祯九年三月十七日李天经题本</span>  
<span style="margin-left: 3em">督修历法山东布政使司右参政臣李天经谨</span>  
<span style="margin-left: 2em">题为遵</span>  
<span style="margin-left: 1em">旨回奏仰乞</span>  
<span style="margin-left: 1em">圣鉴事崇祯九年三月初五日准礼部照会内开该本</span>  
<span style="margin-left: 3em">部奏前事等因奉</span>  
<span style="margin-left: 1em">圣旨据称各管俱有分属地方岂无占验又冬至葭管</span>  
<span style="margin-left: 2em">飞灰载在册籍何云专取立春还着同李天经魏文</span>  
<span style="margin-left: 2em">魁再加详考讲求明白具奏钦此钦遵照会到臣该</span>  
<span style="margin-left: 3em">臣看得臣所职掌乃推步日月交食测算五星凌</span>  
<span style="margin-left: 3em">犯是皆有理可据有数可凭者耳即旁通首欵曾</span>  
<span style="margin-left: 3em">言事应亦第谓其考求七政性情约略预知初未</span>  
<span style="margin-left: 3em">尝敢以琐屑不经之事牵合傅会今该监候气一</span>  
<span style="margin-left: 3em">法其散见于经典者悉后儒引以注疏律吕者也</span>  
<span style="margin-left: 3em">故史记以前言律历者未之或及至后汉志则云</span>  
<span style="margin-left: 3em">律可相传惟有候气始纪其法而谓气所动者其</span>  
<span style="margin-left: 3em">灰散人及风所动者其灰聚盖按辰以候每月之</span>  
<span style="margin-left: 3em">中气以定十二律之应与否也汉臣马防云圣人</span>  
<span style="margin-left: 3em">作乐所以宣气致和故于岁首发太簇之律然古</span>  
<span style="margin-left: 3em">谓律首黄钟其位在子而宋儒朱子一主其说云</span>  
<span style="margin-left: 3em">冬至气至黄钟之管灰飞大寒以下随月应焉是</span>  
<span style="margin-left: 3em">知候非止于一月</span>  
<span style="margin-left: 1em">明旨所谓何云专取立春盖已洞其底里矣臣历考前</span>  
<span style="margin-left: 3em">代魏时杜䕫制律候气灰悉不飞隋开皇间毛爽</span>  
<span style="margin-left: 3em">等依古法候气有节至即应有终月不应之异而</span>  
<span style="margin-left: 3em">牛弘创为衰气和气猛气之说一经隋帝所驳遂</span>  
<span style="margin-left: 3em">无复置对宋景祐间李照请下河内取葭莩制玉</span>  
<span style="margin-left: 3em">律候气以定乐率不能合惟北齐信都芳能以管</span>  
<span style="margin-left: 3em">灰候气每月应律不爽时刻而先臣邢云路谓其</span>  
<span style="margin-left: 3em">用机鼓动致然且自古相传有谓当以纱縠蒙管</span>  
<span style="margin-left: 3em">端者有谓葭灰升降有毫忽者有谓灰用懐州河</span>  
<span style="margin-left: 3em">内县竹用宜阳金门山者郑康成有玉管铜管之</span>  
<span style="margin-left: 3em">别熊安有大动小动之徴其说互有异同法亦不</span>  
<span style="margin-left: 3em">能尽验然皆止于候气已耳至若主何占验作何</span>  
<span style="margin-left: 3em">徴应臣于史册未覩惟按</span>  
<span style="margin-left: 1em">大明会典一欵内云凡每岁立春前期五日本监</span>  
<span style="margin-left: 1em">面奏差官二员往顺天府候气至日回监具呈依书占</span>  
<span style="margin-left: 3em">奏则是明有一书存贮本监以待占奏乃该监主</span>  
<span style="margin-left: 3em">占官徐源直日官章必选俱称玩占一书未经登</span>  
<span style="margin-left: 3em">载何敢臆说若然则</span>  
<span style="margin-left: 1em">会典所载依书占奏者岂无所据而云然该监所藏又</span>  
<span style="margin-left: 3em">岂止玩占一书而已耶盖书为该监所收掌占则</span>  
<span style="margin-left: 3em">灵台之本业而乃茫无以对其于职掌何居耶臣</span>  
<span style="margin-left: 3em">谨详史册所载之大略若此如诩诩然谬为不经</span>  
<span style="margin-left: 3em">之说以炫视听则断断非臣所敢出也统祈</span>  
<span style="margin-left: 1em">圣明裁夺施行</span>
