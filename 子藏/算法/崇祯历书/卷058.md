<span style="margin-left: 2em">交食历指叙</span>  
<span style="margin-left: 2em">或问日月薄蚀是灾变乎非灾变乎若言是者则躔</span>  
<span style="margin-left: 2em">度有常上下百千万年如视掌耳岂人世之吉凶亦</span>  
<span style="margin-left: 2em">可以筹算穷也若言否者则古圣贤戒惧修省又复</span>  
<span style="margin-left: 2em">何说曰灾与变不同灾与灾变与变又各不同如水</span>  
<span style="margin-left: 2em">旱虫蝗之属伤害民物者灾也日月薄蚀无患害可</span>  
<span style="margin-left: 2em">指然以理揆之日为万光之原是生暄燠月为夜光</span>  
<span style="margin-left: 2em">之首是生湿润大圜之中惟是二曜相资相济以生</span>  
<span style="margin-left: 2em">万有若能施之体受其蔽亏即所施之物成其阙陷</span>  
<span style="margin-left: 2em">矣况一朔一望两光盛长受损之势将愈甚焉是谓</span>  
<span style="margin-left: 2em">无形之灾不可谓非灾也夫晕珥彗孛之属非凡所</span>  
<span style="margin-left: 2em">有者异也交食虽躔度有常推步可致然光明下济</span>  
<span style="margin-left: 2em">忽焉掩抑如月食入景深者乃至倍于月体日食既</span>  
<span style="margin-left: 2em">者乃至昼晦星见嘻其甚矣是则常中之变不可谓</span>  
<span style="margin-left: 2em">非变也既属灾变即宜视为谴告侧身修省是以有</span>  
<span style="margin-left: 2em">修德正事之训有无敢驰驱之戒兢业日慎犹惧不</span>  
<span style="margin-left: 2em">塈矣曰既称灾变凡厥事应可豫占乎可豫备乎曰</span>  
<span style="margin-left: 2em">从古历家不言事应言事应者天文也天文之学牵</span>  
<span style="margin-left: 2em">合傅会傥过信其说非惟无益害乃滋大欲辨真伪</span>  
<span style="margin-left: 2em">总之能言其所以然者近是如日月薄蚀宜论其时</span>  
<span style="margin-left: 2em">论其地论时则正照者灾深论地则食少者灾减然</span>  
<span style="margin-left: 2em">月食天下皆同宜专计时日食九服各异宜并记地</span>  
<span style="margin-left: 2em">矣迨于五纬恒星其与二曜各有顺逆乖违之性亢</span>  
<span style="margin-left: 2em">害承制之理方隅冲合之势为其术者一一持之有</span>  
<span style="margin-left: 2em">故然以为必然不爽终不可得也惟豫备一法则所</span>  
<span style="margin-left: 2em">谓灾害者不过水旱虫蝗疾疠兵戎数事而已诚以</span>  
<span style="margin-left: 2em">钦若昭事之衷修勤恤顾畏之实过求夙戒时至而</span>  
<span style="margin-left: 2em">救之者裕如则所谓天不能使之灾又何必征休咎</span>  
<span style="margin-left: 2em">于梓禆问祲祥于京翼乎然则星历之家概求精密</span>  
<span style="margin-left: 2em">尤勤于交食者何也曰太阴去人最近饶有视差凡</span>  
<span style="margin-left: 2em">人目所见人器所测则视度而已其实行度分非人</span>  
<span style="margin-left: 2em">可见非器可测必以食甚时知为定望与日正相对</span>  
<span style="margin-left: 2em">从是知其实度从是知其本行自余行度渐可推算</span>  
<span style="margin-left: 2em">也又因月食知地景为角体之形月体过之其距地</span>  
<span style="margin-left: 2em">同而入景之浅深不同可推日在其本天行与地为</span>  
<span style="margin-left: 2em">不同心也又因日食推月距地时时不等知其有本</span>  
<span style="margin-left: 2em">轮有次轮也又兼以日月食推日月体之小大及日</span>  
<span style="margin-left: 2em">月距地之远近也别有度地之学因月食可推地在</span>  
<span style="margin-left: 2em">天之最中其四周皆以天为上人则环居地面也又</span>  
<span style="margin-left: 2em">因月食知地景为圆体而居东者渐远渐后见食即</span>  
<span style="margin-left: 2em">非月食以地为先后特因各所见之时刻为先后也</span>  
<span style="margin-left: 2em">因以推地为圆体而水附于地合为一球也又以月</span>

<span style="margin-left: 1em">凡物体能隔他物之象使不至目则为暗体若以体之</span>  
<span style="margin-left: 2em">一面受光而光复透射出于彼面则为彻体<sub class="note-yuan">如玻瓈水精是</sub></span>

<span style="margin-left: 1em">一曰有两球于此一为暗体一为明体而小大等即明</span>  
<span style="margin-left: 2em">者以半面施光暗者以半面受光　如图甲为明球</span>  
<span style="margin-left: 2em">乙为暗球小大等即其径丙丁及戊己各与甲乙线</span>  
<span style="margin-left: 8em">为直角而丙丁与戊己等即甲丙甲</span>  
<span style="margin-left: 8em">丁乙戊乙己与甲庚乙辛皆以半径</span>  
<span style="margin-left: 8em">相等而丙庚丁半球与戊辛己半球</span>  
<span style="margin-left: 2em">亦相等今于明球之旁从丙从丁出两切线至暗球</span>  
<span style="margin-left: 2em">之旁戊己戊己与丙丁为平行线即丙戊与丁己亦</span>  
<span style="margin-left: 2em">平行线也<sub class="note-yuan">见几何一卷</sub>　又因丙戊乙及丁己乙俱</span>  
<span style="margin-left: 6em"><sub class="note-yuan">三十三题</sub></span>  
<span style="margin-left: 2em">为直角即戊丙甲及己丁甲亦俱直角<sub class="note-yuan">见几何一卷二十九题</sub></span>  
<span style="margin-left: 2em">即丙戊丁己线不能割两球而止切两周于丙于戊</span>  
<span style="margin-left: 2em">于丁于己其所抱为丙庚丁为戊辛己是甲乙两球</span>  
<span style="margin-left: 2em">之各半也若日月地三球相等而月与地皆以半面</span>  
<span style="margin-left: 2em">受太阳之光如上所说则定朔日食半地面宜皆见</span>  
<span style="margin-left: 2em">之安得复有南北不等食分望日太阴全食时才食</span>  
<span style="margin-left: 2em">既即生光安得复有食甚时刻及既内分今皆不然</span>  
<span style="margin-left: 2em">可见三球无相等之球</span>  
<span style="margin-left: 1em">二曰明体大暗体小则施光以小半受光以大半　如</span>  
<span style="margin-left: 9em">图甲为明球乙为暗球作两切线</span>  
<span style="margin-left: 9em">为丙己为戊庚从四切点作横线</span>  
<span style="margin-left: 9em">为丙戊为己庚甲既大球即己丙</span>  
<span style="margin-left: 2em">戊为锐角丙己庚角为钝角如曰不然或皆为直角</span>  
<span style="margin-left: 2em">即庚戊丙戊庚己亦皆直角两切线必平行而乙球</span>  
<span style="margin-left: 9em">与甲球等<sub class="note-yuan">见几何一卷二十八题</sub>必不然也</span>  
<span style="margin-left: 9em">或己丙戊反为钝角而丙己庚反</span>  
<span style="margin-left: 9em">为锐角即两切线不能相交于癸</span>  
<span style="margin-left: 2em">又不然也今以两切线相交于癸明己丙戊为锐角</span>  
<span style="margin-left: 2em">丙己庚为钝角即于丙丁戊弧内作负圈角必钝角</span>  
<span style="margin-left: 2em">矣于己壬庚内作负圈角必锐角矣<sub class="note-yuan">见几何三卷三十一三十二题</sub></span>  
<span style="margin-left: 2em">故丙丁戊施光者不及半圈己壬庚受光者又不止</span>  
<span style="margin-left: 2em">半圈也因此推知太阳照地及太阴必各照其大半</span>  
<span style="margin-left: 2em">而暗体所隔之日光渐远又渐歛渐进以趋于一处</span>  
<span style="margin-left: 2em">即景居暗球之背不得不为角体之形矣又因此推</span>  
<span style="margin-left: 2em">求望日先后人目所见太阴受日之光不长不消者</span>  
<span style="margin-left: 2em">久之而后生魄此为何故盖亦因月体以大半受光</span>  
<span style="margin-left: 2em">以小半入于人目光不辄转而魄未遽见故未望时</span>  
<span style="margin-left: 2em">已见全光已望后犹未失全光矣</span>  
<span style="margin-left: 1em">三曰明体小暗体大则施光以大半受光以小半　如</span>  
<span style="margin-left: 2em">前图反论之可明太阴何以照地而地何反隔日之</span>  
<span style="margin-left: 2em">光也</span>  
<span style="margin-left: 1em">四曰大施小受愈相近则施者之小半愈小受者之大</span>  
<span style="margin-left: 2em">半愈大　如图丙为小暗球甲与乙皆大明球作庚</span>  
<span style="margin-left: 2em">未直线过三球心以交于左右切线其乙球之两切</span>  
<span style="margin-left: 11em">线交于午甲球之两切线交</span>  
<span style="margin-left: 11em">于未即庚未长于乙午而庚</span>  
<span style="margin-left: 11em">丁未与乙辛午两角庚丁与</span>  
<span style="margin-left: 2em">乙辛两线皆相等则庚未线与庚丁线之比例大于</span>  
<span style="margin-left: 2em">乙午与乙辛而丁庚未角大于辛乙午角也<sub class="note-yuan">见几何五卷八</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">题</sub>又庚未线过三球之心必截丁己辛癸两线为两</span>  
<span style="margin-left: 2em">平分而庚甲丁乙子辛两形内之甲与子皆为直角</span>  
<span style="margin-left: 2em">则其余庚丁两角并乙辛两角并皆等一直角即两</span>  
<span style="margin-left: 2em">并率等<sub class="note-yuan">几何一卷三十二题</sub>两并率之甲庚丁角大于子乙辛</span>  
<span style="margin-left: 2em">角各减之所存庚丁甲角必小于乙辛子角矣次以</span>  
<span style="margin-left: 2em">庚丁甲及乙辛子不等之两角各减庚丁未及乙辛</span>  
<span style="margin-left: 2em">午相等之两直角所存甲丁未角更大于子辛午角</span>  
<span style="margin-left: 2em">又丁戊己弧内作负圈角必等于甲丁未角辛壬癸</span>  
<span style="margin-left: 2em">弧内作负圈角必等于子辛午角辛壬癸弧之负圈</span>  
<span style="margin-left: 2em">角既小于丁戊己弧之负圈角则辛壬癸弧必大于</span>  
<span style="margin-left: 2em">丁戊己弧<sub class="note-yuan">几何三卷三十一三十二题</sub>夫辰寅巳与辛壬癸相似</span>  
<span style="margin-left: 2em">之弧也丑寅卯与丁戊己亦相似之弧也<sub class="note-yuan">大小圈左右各有切</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">线其切点过分圈之线其所分大小圈分各相似其大小两弧亦相似</sub>即辰寅巳弧亦</span>  
<span style="margin-left: 2em">大于丑寅卯弧可见明球在近比在远者尤能照小</span>  
<span style="margin-left: 2em">暗球之多分也　因此推知日全食而视为大者日</span>  
<span style="margin-left: 2em">体去月体远故也日全食而视为小者日体去月体</span>  
<span style="margin-left: 2em">近故也何以分远近日与月俱有自行圈与地不同</span>  
<span style="margin-left: 2em">心其行于自行圈之上下为最高最庳则为距地之</span>  
<span style="margin-left: 2em">远近因生景之大小也日既全食矣又何以分大小</span>  
<span style="margin-left: 2em">月掩日至既有时昼晦恒星皆见虫飞鸟栖此为全</span>  
<span style="margin-left: 2em">食而大月在日内从中掩蔽虽至食既而其四周日</span>  
<span style="margin-left: 2em">光皆见历家谓之金环此为全食而小矣若然者日</span>  
<span style="margin-left: 2em">与月与地相去或远或近之所繇生也</span>  
<span style="margin-left: 1em">五曰小施大受愈相远则施者之大半加小受者之小</span>  
<span style="margin-left: 2em">半渐大　如图甲乙皆为小明球丙为大暗球乙去</span>  
<span style="margin-left: 11em">丙远于甲作各切线过三球</span>  
<span style="margin-left: 11em">心之直线皆如前次从暗球</span>  
<span style="margin-left: 11em">心丙至各切点作丙丁丙己</span>  
<span style="margin-left: 2em">丙庚丙辛各半径得丙丁为丁壬之垂线丙庚为庚</span>  
<span style="margin-left: 2em">癸之垂线而丁与庚皆为直角丙丁与丙庚两线又</span>  
<span style="margin-left: 2em">等则丙癸线与丙庚半径之比例大于丙壬与丙丁</span>  
<span style="margin-left: 2em">而丙庚癸角又大于丙丁壬角也<sub class="note-yuan">几何五卷八题</sub>依显丙辛</span>  
<span style="margin-left: 2em">癸角亦大于丙己壬角以并前率为庚丙辛合角亦</span>  
<span style="margin-left: 2em">大于丁丙己合角而其弧庚戊辛必大于丁戊己可</span>  
<span style="margin-left: 2em">见小明球照大暗球愈远愈照其多分也今依本图</span>  
<span style="margin-left: 11em">设丙为地外切线<sub class="note-yuan">癸辛也</sub>以内</span>  
<span style="margin-left: 11em">为地景<sub class="note-yuan">日光过丙大球所出景</sub>甲乙两</span>  
<span style="margin-left: 11em">小球为月体其两小球之小</span>  
<span style="margin-left: 2em">大既等则同以外切线为外光之界或为内景之界</span>  
<span style="margin-left: 2em">惟因月体循本轮行时居上周如乙则去地远时居</span>  
<span style="margin-left: 2em">下周如甲则去地近以是月食之分数有多有寡月</span>  
<span style="margin-left: 2em">居影厚处如甲左右则食多月居影薄处如乙左右</span>  
<span style="margin-left: 2em">则食寡故曰月食有多寡者亦相距或远或近之所</span>  
<span style="margin-left: 2em">繇生也</span>  
<span style="margin-left: 2em">景之处所第二</span>  
<span style="margin-left: 1em">凡光以直线照物体其无光之处则有景之处也欲于</span>  
<span style="margin-left: 2em">交食时求影所在理不异此盖月与地能出景者不</span>  
<span style="margin-left: 2em">在其受光之面或其左右必于受光反对之面日光</span>  
<span style="margin-left: 2em">不照之地在日食则为月景之处在月食则为地景</span>  
<span style="margin-left: 2em">之处矣说二章</span>  
<span style="margin-left: 1em">一曰景与光所居正相反　暗体得光于此面射影于</span>  
<span style="margin-left: 2em">彼面是景之中心与原光之心暗体之心参相对如</span>  
<span style="margin-left: 2em">一直线则暗体隔光于景使原光之心恒居一线之</span>  
<span style="margin-left: 2em">末界其正相反之彼界其景之心在焉如曰不然设</span>  
<span style="margin-left: 7em">原光在甲其照及乙乙为暗体隔光生</span>  
<span style="margin-left: 7em">景据云景不射丙<sub class="note-yuan">丙者与甲正相对之处</sub>为甲乙</span>  
<span style="margin-left: 2em">丙直线而斜射丁则乙甲丁者角也有角则有几何</span>  
<span style="margin-left: 2em">凡几何皆分之无穷能出直线至于无数而皆至乙</span>  
<span style="margin-left: 2em">丁边夫甲既为原光之体其所照必以直线出之<sub class="note-yuan">试诸</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">仪器足以为证</sub>即乙丁皆在受光之地何自能为乙暗体之</span>  
<span style="margin-left: 2em">景乎因此明景与光正在相反之两界论暗体者其</span>  
<span style="margin-left: 2em">受光之面必向光所出之原界其生景之面必向景</span>  
<span style="margin-left: 2em">所射之彼界亦正相反也论日与月独至两交之处</span>  
<span style="margin-left: 2em">而有食亦依此理</span>  
<span style="margin-left: 1em">二曰明暗两体任一运动景随之移　试以暗体移动</span>  
<span style="margin-left: 2em">其所借之光随处不一即所生之景亦随处不一盖</span>  
<span style="margin-left: 2em">景与光既如一直线即暗体所居定为景之末界如</span>  
<span style="margin-left: 2em">直线之首首移而线尚不移则是曲线非直线也又</span>  
<span style="margin-left: 2em">试以明体移动设甲为明体乙为暗体乙丙为影则</span>  
<span style="margin-left: 2em">甲乙丙如一直线如曰明体甲移至丁丁仍照乙而</span>  
<span style="margin-left: 6em">乙尚射景至丙则丁乙丙犹直线也有是</span>  
<span style="margin-left: 6em">理乎</span>  
<span style="margin-left: 2em">问太阳照室仅通隙光光照墙壁奕奕颤动太阳既</span>  
<span style="margin-left: 2em">自顺行墙隙仍无迁变则此颤动为从何来或者光</span>  
<span style="margin-left: 2em">与景未必定为直线而能微作曲势乎曰西古博物</span>  
<span style="margin-left: 2em">者亚利斯多言空中尝有浮埃轻而不坠微而不显</span>  
<span style="margin-left: 2em">庄周氏谓之野马或亦称为白驹幽室之内原光既</span>  
<span style="margin-left: 2em">微次光反厚即显此物在于光中纷入沓出能乱光</span>  
<span style="margin-left: 2em">景之界使目视景𬘡缊浮动而实非景动乃景之界</span>  
<span style="margin-left: 2em">线为浮埃所乱致使其然也更以气为证今观太阳</span>  
<span style="margin-left: 2em">出地地面以上多生蒙气气在日体与人目之间即</span>  
<span style="margin-left: 2em">见日之光界亦如颤动非独日也日中晴朗切视地</span>  
<span style="margin-left: 2em">面光耀闪烁如波浪然炽炭在罏炭之四周火光烨</span>  
<span style="margin-left: 2em">烨亦如颤动凡若此者一皆繇气而生在日在地在</span>  
<span style="margin-left: 2em">炭固无颤动之理是以景必系于暗体如轮必系于</span>  
<span style="margin-left: 2em">枢轴光上景即下光东景即西必相对也无相就也</span>  
<span style="margin-left: 2em">故太阳照地其光绕地一周则景在其相冲之界亦</span>  
<span style="margin-left: 2em">绕天一周盖日光从其本天直射至于地面而景在</span>  
<span style="margin-left: 2em">地之彼面亦直射至于月天第日体常依黄道中线</span>  
<span style="margin-left: 2em">则地景亦常依黄道中线而月行常出入黄道中线</span>  
<span style="margin-left: 2em">之内外是以月体与地景不得恒相遇合大都不合</span>  
<span style="margin-left: 2em">时多合时少故日月不食时多食时少以此</span>  
<span style="margin-left: 2em">景之形势第三</span>  
<span style="margin-left: 1em">求食分之几何必先求景之几何景几何者以日月地</span>  
<span style="margin-left: 2em">之大得景之形势以日月地相距之远近分数得景</span>  
<span style="margin-left: 2em">之变易大小分数也此所论则景之形势后考其变</span>  
<span style="margin-left: 2em">易之势得景分以定食分焉凡二章</span>  
<span style="margin-left: 1em">一曰二体相等其影平行而无穷明小暗大其景渐展</span>  
<span style="margin-left: 2em">而无穷　论相等者证以平行之切线也如图甲乙</span>  
<span style="margin-left: 2em">两球等丙己丁戊为两球之切线与两球之径丙丁</span>  
<span style="margin-left: 9em">己戊遇于切点皆为直角则互为</span>  
<span style="margin-left: 9em">平行线又球等即径之长短亦等</span>  
<span style="margin-left: 9em">以遇丙己及丁戊无不为平行线</span>  
<span style="margin-left: 9em">也<sub class="note-yuan">几何一卷三十三题</sub>若两球之周遭切线</span>  
<span style="margin-left: 2em">无数皆同此论则引之至庚辛以迨无穷终平行终</span>  
<span style="margin-left: 2em">不能相遇而其形为长圆柱之无穷体</span>  
<span style="margin-left: 2em">论明球小于暗球则推以三角形相似之比例也如</span>  
<span style="margin-left: 2em">图乙丙为小明球丁戊为大暗球两球之切线丁乙</span>  
<span style="margin-left: 2em">及戊丙引长之过小球必相遇于甲成甲丁戊三角</span>  
<span style="margin-left: 2em">形又从丁戊底作己庚平行线在大球之外成庚甲</span>  
<span style="margin-left: 2em">己三角形与甲丁戊相似则甲己庚角与甲丁戊角</span>  
<span style="margin-left: 2em">相等其各边各角皆相似而甲丁与丁戊若甲己与</span>  
<span style="margin-left: 10em">己庚也反而更之己庚与丁戊</span>  
<span style="margin-left: 10em">若甲己与甲丁也甲己长与甲</span>  
<span style="margin-left: 10em">丁则己庚亦长与丁戊愈远愈</span>  
<span style="margin-left: 2em">长可见大球之影渐远渐拓矣<sub class="note-yuan">几何六卷四题</sub>更论丁戊线</span>  
<span style="margin-left: 2em">之内外角则在内者为锐角在外者为钝角故引切</span>  
<span style="margin-left: 2em">线向内过小球必相遇引之向外愈远愈拓终不相</span>  
<span style="margin-left: 2em">遇而其形为无限长无限广之角体又因两球所居</span>  
<span style="margin-left: 2em">远近不同景之张翕随而变易故两球相近即乙丙</span>  
<span style="margin-left: 2em">底线为小其景愈狭而乙甲丙角形愈短两球相远</span>  
<span style="margin-left: 2em">即底线为大其景愈拓而角形愈长也</span>  
<span style="margin-left: 2em">今验诸日食有食分同而所历时刻不同者月景之</span>  
<span style="margin-left: 2em">在地面广狭不同也月与日会月在日与地之间或</span>  
<span style="margin-left: 2em">月近地而日在远则目之见界过月周至日体其界</span>  
<span style="margin-left: 2em">广日过迟其见食时刻多或月远地而日反近则目</span>  
<span style="margin-left: 2em">之见界过月周至日体其界狭日过速其见食时刻</span>  
<span style="margin-left: 2em">少也姑以前图明之目在甲乙丙为月体丁戊为日</span>  
<span style="margin-left: 2em">体切线甲丁及甲戊为目所见之界若日在近为丁</span>  
<span style="margin-left: 2em">戊即从丁过戊道近行速其食时寡若在远为己庚</span>  
<span style="margin-left: 2em">从己过庚道远行迟其食时多皆太阳有不同心圈</span>  
<span style="margin-left: 2em">而太阴又有小轮所繇生也</span>  
<span style="margin-left: 1em">二曰日月地三体大小不同　凡暗体出角景者施光</span>  
<span style="margin-left: 2em">之体必大于暗体否者其光不能照暗体之大半而</span>  
<span style="margin-left: 2em">使其景渐小以趋于尽也试观月食时月体近地则</span>  
<span style="margin-left: 2em">入大景远地则入小景愈远愈小必至于尽安得不</span>  
<span style="margin-left: 2em">信日体大于地体乎设谓日体与地体或等则景宜</span>  
<span style="margin-left: 2em">亦等或小则宜渐大又当皆为无穷之景遇望时月</span>  
<span style="margin-left: 2em">体必不能出大影之外不应有不食之望矣有不食</span>  
<span style="margin-left: 2em">者是地景之益远益锐也月食于地景之中又有全</span>  
<span style="margin-left: 2em">而且久者是月径更小于景而景小于地也地景之</span>  
<span style="margin-left: 2em">远而益锐者是日大于地也此以景理推论三体之</span>  
<span style="margin-left: 2em">小大畧可明矣若又以日体之大推月地之景则更</span>  
<span style="margin-left: 2em">有法可考其大小之比例也昔人因太阳照地所生</span>  
<span style="margin-left: 2em">之景及其远近其视径时时不同又以较于他体得</span>  
<span style="margin-left: 2em">其实体之大说见月离历指中此独用视径定食时</span>  
<span style="margin-left: 2em">刻分之数其论实体为景与食之原畧举一二如左</span>  
<span style="margin-left: 2em">几何原本论三角形于一边之两界出两线复作一</span>  
<span style="margin-left: 2em">三角形在其内则内形两腰并之必小于相对两腰</span>  
<span style="margin-left: 2em">而后两线所作角必大于相对角如图甲乙为太阳</span>  
<span style="margin-left: 2em">之径丙为目从远视之丁亦为目从近视之此所谓</span>  
<span style="margin-left: 2em">内外两三角形也今先以线论因内形之甲丁乙丁</span>  
<span style="margin-left: 2em">两腰小于相对之甲丙乙丙两腰则所作丁角比相</span>  
<span style="margin-left: 10em">对之两角亦近于共用之甲乙</span>  
<span style="margin-left: 10em">底近则见大故丁目视甲乙日</span>  
<span style="margin-left: 2em">径必见大于丙目所视之甲乙径也次以角论因内</span>  
<span style="margin-left: 2em">两线所作丁角大于相对丙角则此内角所对线亦</span>  
<span style="margin-left: 2em">似大于外角所对线而丁目所见之甲乙大于丙目</span>  
<span style="margin-left: 2em">所见之甲乙也此太阳视径不同之缘也</span>  
<span style="margin-left: 2em">求太阳实体之大第谷设最高最庳之中处得其距</span>  
<span style="margin-left: 2em">地一千一百五十地半径全数十万其半径一十五</span>  
<span style="margin-left: 2em">分三十秒得正弦四百五十一以三率算法推其全</span>  
<span style="margin-left: 2em">径得地之全径五又七十五之一十四如三百八十</span>  
<span style="margin-left: 2em">九与七十五也又以其径与其周之比例得太阳体</span>  
<span style="margin-left: 2em">之立方五千八百八十六万三千八百六十九地球</span>  
<span style="margin-left: 2em">之立方四十二万一千八百七十五其终数得一百</span>  
<span style="margin-left: 2em">四十弱为太阳大于地之倍数也此其照月照地生</span>  
<span style="margin-left: 2em">角体锐景之原也</span>  
<span style="margin-left: 2em">景之作用第四</span>  
<span style="margin-left: 2em">月与地若各以其景相酧报然如月望则地景隔日</span>  
<span style="margin-left: 2em">光令月不受照有时失满光有时全失光也至月朔</span>  
<span style="margin-left: 2em">则月体隔日光令地不受照有处射满影有处留少</span>  
<span style="margin-left: 2em">光而已说三章</span>  
<span style="margin-left: 1em">一曰月食于地景　月食在望缘日月相对其理明矣</span>  
<span style="margin-left: 2em">独谓暗虚为地景者或致疑焉今解之月对日受光</span>  
<span style="margin-left: 2em">藉非日月之间有不通光之实体为其映蔽则何繇</span>  
<span style="margin-left: 2em">阻日光之直照若天体及空中之火空中之气皆通</span>  
<span style="margin-left: 2em">明透彻不能作障使月失光也即金水二星亦是实</span>  
<span style="margin-left: 2em">体有时居日月之间然其景俱不及地况能过地及</span>  
<span style="margin-left: 2em">月乎则知能掩月者惟有地体一面受光一面射景</span>  
<span style="margin-left: 2em">而月体为借光之物入此景中无能不食半进而半</span>  
<span style="margin-left: 2em">食矣全进而全食矣</span>  
<span style="margin-left: 1em">二曰日食者月掩之　恒言月在内去人近日在外去</span>  
<span style="margin-left: 2em">人远故定朔时月体能掩日光是已第金水二星亦</span>  
<span style="margin-left: 2em">皆时在日内又皆不通光之实体水星虽小金星则</span>  
<span style="margin-left: 2em">大于月也何独月能食日乎曰二星虽有时在日内</span>  
<span style="margin-left: 2em">则去人甚远远则视径见小不能掩日百分之一二</span>  
<span style="margin-left: 2em">而日光甚盛所亏百之一二非目力所及且二星比</span>  
<span style="margin-left: 2em">月去日更近所出锐角之景更短不能及地面也若</span>  
<span style="margin-left: 2em">月体之大虽不及太白而去地甚近去日甚远一指</span>  
<span style="margin-left: 2em">足蔽泰山又何疑乎由此言之求一实不通光之体</span>  
<span style="margin-left: 2em">全掩日体者惟月为能又自西而东不及三十日而</span>  
<span style="margin-left: 2em">周其行度较于诸天最为疾速故每望定朔皆同经</span>  
<span style="margin-left: 2em">度皆能有食其不食者繇距度不及交耳</span>  
<span style="margin-left: 1em">三曰因景之径生多变易　月以距度广狭为食分多</span>  
<span style="margin-left: 2em">寡一因去交有远有近去黄道中线有正有偏一因</span>  
<span style="margin-left: 2em">入地景有浅有深故也今论其全食者而大小迟疾</span>  
<span style="margin-left: 2em">犹多变易曾非一定盖日在自行本天月在小轮相</span>  
<span style="margin-left: 2em">距远近往往不等日距月近较距远时更照月体之</span>  
<span style="margin-left: 2em">多分从月体出景更短其景至地更小则日虽全食</span>  
<span style="margin-left: 2em">月体见小历时亦速也日与地亦然以两体相距之</span>  
<span style="margin-left: 2em">远近为地景之大小使月食时入于地景在其近末</span>  
<span style="margin-left: 2em">之锐分则暗虚之体见小食分少历时速皆因三体</span>  
<span style="margin-left: 2em">之相距远近以生大小迟疾地景月景皆无一定之</span>  
<span style="margin-left: 2em">径致令随时变易如此</span>  
<span style="margin-left: 2em">若月景地景二径之小大又自不等故日食尽于食</span>  
<span style="margin-left: 2em">既而月则食既以后尚有既内余分盖地景大于月</span>  
<span style="margin-left: 2em">景故两食皆全其亏复迟疾无能不异矣又月食天</span>  
<span style="margin-left: 2em">下皆同日食则否日食则此地速彼地迟此地见多</span>  
<span style="margin-left: 2em">彼地见少此地见偏南彼地见偏北无不异也月食</span>  
<span style="margin-left: 2em">则凡居地面者目所共见其食分大小同亏复迟疾</span>  
<span style="margin-left: 2em">同经历时刻同唯所居不同子午线者则见食之时</span>  
<span style="margin-left: 2em">刻先后不同耳盖月一入景失去借光更无处可见</span>  
<span style="margin-left: 2em">其光也又槩论天下日食应多于月食为二径折半</span>  
<span style="margin-left: 2em">其近交时加以南北视差易相逮及故论一方则日</span>  
<span style="margin-left: 2em">食应少于月食为月食共见日食因地故<sub class="note-yuan">见后卷详之</sub></span>  
<span style="margin-left: 2em">月在景之光色第五</span>  
<span style="margin-left: 1em">月既暗体当全食时一入地景遂应失其借光非复人</span>  
<span style="margin-left: 2em">目可见也盖可见之物悉无原光必借外光以显其</span>  
<span style="margin-left: 2em">象无外光即无从见有此物安从更显物色乎今月</span>  
<span style="margin-left: 2em">居厚影尚有微光可见更发色象或赤色或青黑色</span>  
<span style="margin-left: 2em">或襍色此何从生今畧解之凡三章</span>  
<span style="margin-left: 1em">一曰月不独食于地影　论通光者有二体一谓物象</span>  
<span style="margin-left: 2em">遇甚彻之体易于通射比于发象元处更加透明则</span>  
<span style="margin-left: 2em">形若开而散焉一谓物象遇次澈之体难于通射比</span>  
<span style="margin-left: 2em">于发象元处少襍昏暗则形若歛而聚焉其遇甚彻</span>  
<span style="margin-left: 2em">者如舟用篙艣半在水中发象上出出于水面所遇</span>  
<span style="margin-left: 2em">空明气之光甚澈之体也则其象散而斜射视之若</span>  
<span style="margin-left: 2em">曲焉其遇次澈者如太阳入地平下其光照地旁本</span>  
<span style="margin-left: 2em">宜直上乃所遇清蒙之气次澈之体也则其象合聚</span>  
<span style="margin-left: 2em">而射于地面凡地平以上皆得其次光为朦胧焉<sub class="note-yuan">即昧</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">爽黄昏亦曰晨昏</sub>此两者皆以一物经繇两体其势曲折皆</span>  
<span style="margin-left: 2em">谓之折照<sub class="note-yuan">若一物在一体之中以一直线入目谓之直照</sub>夫同是日光也在</span>  
<span style="margin-left: 2em">地面之上能折入于地景之根际则自地面而上何</span>  
<span style="margin-left: 2em">独不能折入于景之中际至月体经行之处乎如图</span>  
<span style="margin-left: 2em">甲为太阳乙为地球藉非清蒙气能迎太阳之光而</span>  
<span style="margin-left: 2em">成折照则宜从子出光至丙从丑出光至丁切地面</span>  
<span style="margin-left: 2em">径过而复合于庚为地景锐角也今不其然因清蒙</span>  
<span style="margin-left: 2em">气周绕地球日光至丙至丁遇其次澈之体难于透</span>  
<span style="margin-left: 17em">射则曲而内</span>  
<span style="margin-left: 17em">聚止于戊己</span>  
<span style="margin-left: 17em">地面矣而大</span>  
<span style="margin-left: 2em">圜中大气无不受日之照光光在壬癸者遇于蒙气</span>  
<span style="margin-left: 2em">即内歛至于卯辰此为初折从卯辰切地而过若遂</span>  
<span style="margin-left: 2em">以直线引之即复合于辛成卯辰辛襍线三角形为</span>  
<span style="margin-left: 2em">地之满影自此以外全景之中皆得太阳折照之光</span>  
<span style="margin-left: 2em">与朦胧次光相类而实为初景能食望月之满光也</span>  
<span style="margin-left: 2em">欲求满景之长姑先依初折之光引直线复出于蒙</span>

<span style="margin-left: 2em"><sub class="note-yuan">线之交尚在辛点之内今云然者姑先明初折之理约定乙辛之数如太阴之言交泛言平朔言本轮也</sub></span>

<span style="margin-left: 17em">秒乙辰辛为</span>  
<span style="margin-left: 17em">切线与垂线</span>  
<span style="margin-left: 17em">所作角必直</span>

<span style="margin-left: 2em">乙庚线尚长三四倍也夫月食于地景必依其景之</span>  
<span style="margin-left: 2em">体势显其食之貌象今全景之中既以地景兼蒙气</span>  
<span style="margin-left: 2em">之景则并有初景有满景月入于中随其所至变易</span>  
<span style="margin-left: 2em">光色无足异矣或曰从古论食月者全属地景今云</span>

<span style="margin-left: 2em">愈长愈广乎则从上古以来以地径度月体过景之</span>  
<span style="margin-left: 2em">数以地径定日月之视径以地径较日月之两高以</span>  
<span style="margin-left: 2em">地径求日月之去地远近悉皆乖舛而当更定新率</span>  
<span style="margin-left: 2em">然乎抑否乎曰不然所论蒙气之景谓太阳之光因</span>

<span style="margin-left: 2em">徒以变易物象显其用耳且气景之于地景亦何能</span>  
<span style="margin-left: 2em">加长加大乎计清蒙出地之高不能过极高之山极</span>  
<span style="margin-left: 2em">高之山测其垂线不能过千四百步大地之径则三</span>  
<span style="margin-left: 2em">万里以高山之步数化为里数而较地径则五千分</span>  
<span style="margin-left: 2em">之一耳此气之厚何能加于地径而云设此论者有</span>  
<span style="margin-left: 2em">妨于地径测量之法乎</span>
