<span style="margin-left: 2em">交食曆指敘</span>  
<span style="margin-left: 2em">或問日月薄蝕是災變乎非災變乎若言是者則躔</span>  
<span style="margin-left: 2em">度有常上下百千萬年如視掌耳豈人世之吉凶亦</span>  
<span style="margin-left: 2em">可以籌算窮也若言否者則古聖賢戒懼脩省又復</span>  
<span style="margin-left: 2em">何說曰災與變不同災與災變與變又各不同如水</span>  
<span style="margin-left: 2em">旱蟲蝗之屬傷害民物者災也日月薄蝕無患害可</span>  
<span style="margin-left: 2em">指然以理揆之日爲萬光之原是生暄燠月爲夜光</span>  
<span style="margin-left: 2em">之首是生濕潤大圜之中惟是二曜相資相濟以生</span>  
<span style="margin-left: 2em">萬有若能施之體受其蔽虧即所施之物成其闕陷</span>  
<span style="margin-left: 2em">矣况一朔一望兩光盛長受損之勢將愈甚焉是謂</span>  
<span style="margin-left: 2em">無形之災不可謂非災也夫暈珥彗孛之屬非凡所</span>  
<span style="margin-left: 2em">有者異也交食雖躔度有常推步可致然光明下濟</span>  
<span style="margin-left: 2em">忽焉掩抑如月食入景深者乃至倍于月體日食既</span>  
<span style="margin-left: 2em">者乃至晝晦星見嘻其甚矣是則常中之變不可謂</span>  
<span style="margin-left: 2em">非變也既屬災變即宜視爲譴告側身脩省是以有</span>  
<span style="margin-left: 2em">脩德正事之訓有無敢馳驅之戒兢業日慎猶懼不</span>  
<span style="margin-left: 2em">塈矣曰既稱災變凡厥事應可豫占乎可豫備乎曰</span>  
<span style="margin-left: 2em">從古曆家不言事應言事應者天文也天文之學牽</span>  
<span style="margin-left: 2em">合傅會儻過信其說非惟無益害乃滋大欲辨真偽</span>  
<span style="margin-left: 2em">總之能言其所以然者近是如日月薄蝕宜論其時</span>  
<span style="margin-left: 2em">論其地論時則正照者災深論地則食少者災減然</span>  
<span style="margin-left: 2em">月食天下皆同宜專計時日食九服各異宜并記地</span>  
<span style="margin-left: 2em">矣迨于五緯恆星其與二曜各有順逆乖違之性亢</span>  
<span style="margin-left: 2em">害承制之理方隅衝合之勢爲其術者一一持之有</span>  
<span style="margin-left: 2em">故然以爲必然不爽終不可得也惟豫備一法則所</span>  
<span style="margin-left: 2em">謂災害者不過水旱蟲蝗疾癘兵戎數事而已誠以</span>  
<span style="margin-left: 2em">欽若昭事之衷脩勤恤顧畏之實過求夙戒時至而</span>  
<span style="margin-left: 2em">救之者裕如則所謂天不能使之災又何必徵休咎</span>  
<span style="margin-left: 2em">于梓禆問祲祥于京翼乎然則星曆之家概求精密</span>  
<span style="margin-left: 2em">尤勤于交食者何也曰太陰去人最近饒有視差凡</span>  
<span style="margin-left: 2em">人目所見人器所測則視度而已其實行度分非人</span>  
<span style="margin-left: 2em">可見非器可測必以食甚時知爲定望與日正相對</span>  
<span style="margin-left: 2em">從是知其實度從是知其本行自餘行度漸可推算</span>  
<span style="margin-left: 2em">也又因月食知地景爲角體之形月體過之其距地</span>  
<span style="margin-left: 2em">同而入景之淺深不同可推日在其本天行與地爲</span>  
<span style="margin-left: 2em">不同心也又因日食推月距地時時不等知其有本</span>  
<span style="margin-left: 2em">輪有次輪也又兼以日月食推日月體之小大及日</span>  
<span style="margin-left: 2em">月距地之遠近也別有度地之學因月食可推地在</span>  
<span style="margin-left: 2em">天之最中其四周皆以天爲上人則環居地面也又</span>  
<span style="margin-left: 2em">因月食知地景爲圓體而居東者漸遠漸後見食即</span>  
<span style="margin-left: 2em">非月食以地爲先後特因各所見之時刻爲先後也</span>  
<span style="margin-left: 2em">因以推地爲圓體而水附于地合爲一球也又以月</span>  
<span style="margin-left: 2em">食與子午線相距遠近知諸方之地經度也若泯薄</span>  
<span style="margin-left: 2em">蝕於二曜即造曆者雖神明默成無所措其意矣是</span>  
<span style="margin-left: 2em">則交食者密術之所繇生故作者述者咸于此盡心</span>  
<span style="margin-left: 2em">焉今譔曆指有合論有分論月食術稍簡以附合論</span>

<span style="margin-left: 2em">界說　七章</span>  
<span style="margin-left: 1em">凡物體能隔他物之象使不至目則爲暗體若以體之</span>  
<span style="margin-left: 2em">一面受光而光復透射出於彼面則爲徹體<sub class="note-yuan">如玻瓈水精是</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">也</sub></span>  
<span style="margin-left: 2em">目所司存惟光惟色而色又隨光發見故解徹體必</span>  
<span style="margin-left: 2em">以通光解暗體必以其能隔他象如月掩日而日全</span>  
<span style="margin-left: 2em">食晝爲之晦恆星皆見爾時太陽在外體質明顯又</span>  
<span style="margin-left: 2em">堅密無比光力甚厚乃爲月體所隔不能映見微光</span>  
<span style="margin-left: 2em">可證月乃全非徹體而全爲暗體　徹體有二通明</span>  
<span style="margin-left: 2em">之極全無隔礙者爲甚徹雖則透光而微雜昏蒙者</span>  
<span style="margin-left: 2em">爲次徹</span>  
<span style="margin-left: 1em">光在本體爲原光其出而顯他物之象爲照光　日有</span>  
<span style="margin-left: 2em">原光地與月皆借之爲光者照光也謂顯他物之象</span>  
<span style="margin-left: 2em">者因他物之勢隨施隨受有原先後無時先後也非</span>  
<span style="margin-left: 2em">如寒熱燥濕之類漸及于物力盡而止</span>  
<span style="margin-left: 1em">原光以直徑發照爲最光因而旁及者爲次光　日光</span>  
<span style="margin-left: 2em">正照以直線至於物體則爲最光有物隔之旁周映</span>  
<span style="margin-left: 2em">射則生次光如雲之上日體所照最光也雲之下不</span>  
<span style="margin-left: 2em">復見日而猶有光是次光也</span>  
<span style="margin-left: 1em">滿光者原光之全體所發少光者原光之半體所發</span>  
<span style="margin-left: 2em">日未全出地平上所生光爲少光全昇在上則生滿</span>  
<span style="margin-left: 2em">光日食時未全食則存少光既以復圓即得滿光</span>  
<span style="margin-left: 1em">景之四周有最光遶之即景爲次光　以景爲明者誤</span>  
<span style="margin-left: 2em">也以影爲暗者亦誤也稱景爲明暗之中庶幾近之</span>  
<span style="margin-left: 2em">蓋全無光乃爲暗今至夜子初人在地景至深之中</span>  
<span style="margin-left: 2em">去最光極遠而近目之物尚能別識即見景中猶存</span>  
<span style="margin-left: 2em">微光不失爲次光也</span>  
<span style="margin-left: 1em">最光所不及爲初景次光所不及則爲次景　景與光</span>  
<span style="margin-left: 2em">并行光漸微景漸厚故次景與最光相反若初景即</span>  
<span style="margin-left: 2em">次光也</span>  
<span style="margin-left: 1em">最光全不及之處則爲滿景若受正照之微光即爲缺</span>  
<span style="margin-left: 2em">景滿景與光正相反無景之極則爲滿光無光之極</span>  
<span style="margin-left: 2em">則爲滿景假如甲乙爲施光之物丙爲暗球從甲出</span>  
<span style="margin-left: 6em">正照之光過丙球左右其切丙之界者得</span>  
<span style="margin-left: 6em">甲戊及甲己從乙出光又得乙戊及乙丁</span>  
<span style="margin-left: 6em">其庚戊辛爲最光全不及之處則滿景也</span>  
<span style="margin-left: 2em">若庚戊辛戊以外則甲乙光體之多分漸照之至乙</span>  
<span style="margin-left: 2em">丁甲己乃全光之界即自戊至丁至己丙球之景漸</span>  
<span style="margin-left: 2em">薄以趨于盡矣</span>  
<span style="margin-left: 2em">太陽光照月及地第一</span>  
<span style="margin-left: 1em">日月地三球體大小不等地爲靜體日月則有諸種行</span>  
<span style="margin-left: 2em">度則有高庳內外其去地去人遠近不等法當以大</span>  
<span style="margin-left: 2em">小之比例及其相遠相近之比例推其施光受光之</span>  
<span style="margin-left: 2em">體勢乃得景之體勢因而得交食之體勢蓋交食者</span>  
<span style="margin-left: 2em">生於景景生于光不尋其本而求其末無法可得其</span>  
<span style="margin-left: 2em">說五章</span>  
<span style="margin-left: 1em">一曰有兩球于此一爲暗體一爲明體而小大等即明</span>  
<span style="margin-left: 2em">者以半面施光暗者以半面受光　如圖甲爲明球</span>  
<span style="margin-left: 2em">乙爲暗球小大等即其徑丙丁及戊己各與甲乙線</span>  
<span style="margin-left: 8em">爲直角而丙丁與戊己等即甲丙甲</span>  
<span style="margin-left: 8em">丁乙戊乙己與甲庚乙辛皆以半徑</span>  
<span style="margin-left: 8em">相等而丙庚丁半球與戊辛己半球</span>  
<span style="margin-left: 2em">亦相等今于明球之旁從丙從丁出兩切線至暗球</span>  
<span style="margin-left: 2em">之旁戊己戊己與丙丁爲平行線即丙戊與丁己亦</span>  
<span style="margin-left: 2em">平行線也<sub class="note-yuan">見幾何一卷</sub>　又因丙戊乙及丁己乙俱</span>  
<span style="margin-left: 6em"><sub class="note-yuan">三十三題</sub></span>  
<span style="margin-left: 2em">爲直角即戊丙甲及己丁甲亦俱直角<sub class="note-yuan">見幾何一卷二十九題</sub></span>  
<span style="margin-left: 2em">即丙戊丁己線不能割兩球而止切兩周于丙于戊</span>  
<span style="margin-left: 2em">于丁于己其所抱爲丙庚丁爲戊辛己是甲乙兩球</span>  
<span style="margin-left: 2em">之各半也若日月地三球相等而月與地皆以半面</span>  
<span style="margin-left: 2em">受太陽之光如上所說則定朔日食半地面宜皆見</span>  
<span style="margin-left: 2em">之安得復有南北不等食分望日太陰全食時纔食</span>  
<span style="margin-left: 2em">既即生光安得復有食甚時刻及既內分今皆不然</span>  
<span style="margin-left: 2em">可見三球無相等之球</span>  
<span style="margin-left: 1em">二曰明體大暗體小則施光以小半受光以大半　如</span>  
<span style="margin-left: 9em">圖甲爲明球乙爲暗球作兩切線</span>  
<span style="margin-left: 9em">爲丙己爲戊庚從四切點作橫線</span>  
<span style="margin-left: 9em">爲丙戊爲己庚甲既大球即己丙</span>  
<span style="margin-left: 2em">戊爲銳角丙己庚角爲鈍角如曰不然或皆爲直角</span>  
<span style="margin-left: 2em">即庚戊丙戊庚己亦皆直角兩切線必平行而乙球</span>  
<span style="margin-left: 9em">與甲球等<sub class="note-yuan">見幾何一卷二十八題</sub>必不然也</span>  
<span style="margin-left: 9em">或己丙戊反爲鈍角而丙己庚反</span>  
<span style="margin-left: 9em">爲銳角即兩切線不能相交于癸</span>  
<span style="margin-left: 2em">又不然也今以兩切線相交于癸明己丙戊爲銳角</span>  
<span style="margin-left: 2em">丙己庚爲鈍角即于丙丁戊弧內作負圈角必鈍角</span>  
<span style="margin-left: 2em">矣于己壬庚內作負圈角必銳角矣<sub class="note-yuan">見幾何三卷三十一三十二題</sub></span>  
<span style="margin-left: 2em">故丙丁戊施光者不及半圈己壬庚受光者又不止</span>  
<span style="margin-left: 2em">半圈也因此推知太陽照地及太陰必各照其大半</span>  
<span style="margin-left: 2em">而暗體所隔之日光漸遠又漸歛漸進以趨于一處</span>  
<span style="margin-left: 2em">即景居暗球之背不得不爲角體之形矣又因此推</span>  
<span style="margin-left: 2em">求望日先後人目所見太陰受日之光不長不消者</span>  
<span style="margin-left: 2em">久之而後生魄此爲何故蓋亦因月體以大半受光</span>  
<span style="margin-left: 2em">以小半入于人目光不輒轉而魄未遽見故未望時</span>  
<span style="margin-left: 2em">已見全光已望後猶未失全光矣</span>  
<span style="margin-left: 1em">三曰明體小暗體大則施光以大半受光以小半　如</span>  
<span style="margin-left: 2em">前圖反論之可明太陰何以照地而地何反隔日之</span>  
<span style="margin-left: 2em">光也</span>  
<span style="margin-left: 1em">四曰大施小受愈相近則施者之小半愈小受者之大</span>  
<span style="margin-left: 2em">半愈大　如圖丙爲小暗球甲與乙皆大明球作庚</span>  
<span style="margin-left: 2em">未直線過三球心以交于左右切線其乙球之兩切</span>  
<span style="margin-left: 11em">線交于午甲球之兩切線交</span>  
<span style="margin-left: 11em">于未即庚未長于乙午而庚</span>  
<span style="margin-left: 11em">丁未與乙辛午兩角庚丁與</span>  
<span style="margin-left: 2em">乙辛兩線皆相等則庚未線與庚丁線之比例大于</span>  
<span style="margin-left: 2em">乙午與乙辛而丁庚未角大于辛乙午角也<sub class="note-yuan">見幾何五卷八</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">題</sub>又庚未線過三球之心必截丁己辛癸兩線爲兩</span>  
<span style="margin-left: 2em">平分而庚甲丁乙子辛兩形內之甲與子皆爲直角</span>  
<span style="margin-left: 2em">則其餘庚丁兩角并乙辛兩角并皆等一直角即兩</span>  
<span style="margin-left: 2em">并率等<sub class="note-yuan">幾何一卷三十二題</sub>兩并率之甲庚丁角大于子乙辛</span>  
<span style="margin-left: 2em">角各減之所存庚丁甲角必小于乙辛子角矣次以</span>  
<span style="margin-left: 2em">庚丁甲及乙辛子不等之兩角各減庚丁未及乙辛</span>  
<span style="margin-left: 2em">午相等之兩直角所存甲丁未角更大于子辛午角</span>  
<span style="margin-left: 2em">又丁戊己弧內作負圈角必等于甲丁未角辛壬癸</span>  
<span style="margin-left: 2em">弧內作負圈角必等于子辛午角辛壬癸弧之負圈</span>  
<span style="margin-left: 2em">角既小于丁戊己弧之負圈角則辛壬癸弧必大于</span>  
<span style="margin-left: 2em">丁戊己弧<sub class="note-yuan">幾何三卷三十一三十二題</sub>夫辰寅巳與辛壬癸相似</span>  
<span style="margin-left: 2em">之弧也丑寅卯與丁戊己亦相似之弧也<sub class="note-yuan">大小圈左右各有切</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">線其切點過分圈之線其所分大小圈分各相似其大小兩弧亦相似</sub>即辰寅巳弧亦</span>  
<span style="margin-left: 2em">大于丑寅卯弧可見明球在近比在遠者尤能照小</span>  
<span style="margin-left: 2em">暗球之多分也　因此推知日全食而視爲大者日</span>  
<span style="margin-left: 2em">體去月體遠故也日全食而視爲小者日體去月體</span>  
<span style="margin-left: 2em">近故也何以分遠近日與月俱有自行圈與地不同</span>  
<span style="margin-left: 2em">心其行于自行圈之上下爲最高最庳則爲距地之</span>  
<span style="margin-left: 2em">遠近因生景之大小也日既全食矣又何以分大小</span>  
<span style="margin-left: 2em">月掩日至既有時晝晦恆星皆見蟲飛鳥棲此爲全</span>  
<span style="margin-left: 2em">食而大月在日內從中掩蔽雖至食既而其四周日</span>  
<span style="margin-left: 2em">光皆見曆家謂之金環此爲全食而小矣若然者日</span>  
<span style="margin-left: 2em">與月與地相去或遠或近之所繇生也</span>  
<span style="margin-left: 1em">五曰小施大受愈相遠則施者之大半加小受者之小</span>  
<span style="margin-left: 2em">半漸大　如圖甲乙皆爲小明球丙爲大暗球乙去</span>  
<span style="margin-left: 11em">丙遠于甲作各切線過三球</span>  
<span style="margin-left: 11em">心之直線皆如前次從暗球</span>  
<span style="margin-left: 11em">心丙至各切點作丙丁丙己</span>  
<span style="margin-left: 2em">丙庚丙辛各半徑得丙丁爲丁壬之垂線丙庚爲庚</span>  
<span style="margin-left: 2em">癸之垂線而丁與庚皆爲直角丙丁與丙庚兩線又</span>  
<span style="margin-left: 2em">等則丙癸線與丙庚半徑之比例大於丙壬與丙丁</span>  
<span style="margin-left: 2em">而丙庚癸角又大于丙丁壬角也<sub class="note-yuan">幾何五卷八題</sub>依顯丙辛</span>  
<span style="margin-left: 2em">癸角亦大于丙己壬角以并前率爲庚丙辛合角亦</span>  
<span style="margin-left: 2em">大于丁丙己合角而其弧庚戊辛必大于丁戊己可</span>  
<span style="margin-left: 2em">見小明球照大暗球愈遠愈照其多分也今依本圖</span>  
<span style="margin-left: 11em">設丙爲地外切線<sub class="note-yuan">癸辛也</sub>以內</span>  
<span style="margin-left: 11em">爲地景<sub class="note-yuan">日光過丙大球所出景</sub>甲乙兩</span>  
<span style="margin-left: 11em">小球爲月體其兩小球之小</span>  
<span style="margin-left: 2em">大既等則同以外切線爲外光之界或爲內景之界</span>  
<span style="margin-left: 2em">惟因月體循本輪行時居上周如乙則去地遠時居</span>  
<span style="margin-left: 2em">下周如甲則去地近以是月食之分數有多有寡月</span>  
<span style="margin-left: 2em">居影厚處如甲左右則食多月居影薄處如乙左右</span>  
<span style="margin-left: 2em">則食寡故曰月食有多寡者亦相距或遠或近之所</span>  
<span style="margin-left: 2em">繇生也</span>  
<span style="margin-left: 2em">景之處所第二</span>  
<span style="margin-left: 1em">凡光以直線照物體其無光之處則有景之處也欲于</span>  
<span style="margin-left: 2em">交食時求影所在理不異此蓋月與地能出景者不</span>  
<span style="margin-left: 2em">在其受光之面或其左右必于受光反對之面日光</span>  
<span style="margin-left: 2em">不照之地在日食則爲月景之處在月食則爲地景</span>  
<span style="margin-left: 2em">之處矣說二章</span>  
<span style="margin-left: 1em">一曰景與光所居正相反　暗體得光于此面射影于</span>  
<span style="margin-left: 2em">彼面是景之中心與原光之心暗體之心參相對如</span>  
<span style="margin-left: 2em">一直線則暗體隔光于景使原光之心恆居一線之</span>  
<span style="margin-left: 2em">末界其正相反之彼界其景之心在焉如曰不然設</span>  
<span style="margin-left: 7em">原光在甲其照及乙乙爲暗體隔光生</span>  
<span style="margin-left: 7em">景據云景不射丙<sub class="note-yuan">丙者與甲正相對之處</sub>爲甲乙</span>  
<span style="margin-left: 2em">丙直線而斜射丁則乙甲丁者角也有角則有幾何</span>  
<span style="margin-left: 2em">凡幾何皆分之無窮能出直線至于無數而皆至乙</span>  
<span style="margin-left: 2em">丁邊夫甲既爲原光之體其所照必以直線出之<sub class="note-yuan">試諸</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">儀器足以爲證</sub>即乙丁皆在受光之地何自能爲乙暗體之</span>  
<span style="margin-left: 2em">景乎因此明景與光正在相反之兩界論暗體者其</span>  
<span style="margin-left: 2em">受光之面必向光所出之原界其生景之面必向景</span>  
<span style="margin-left: 2em">所射之彼界亦正相反也論日與月獨至兩交之處</span>  
<span style="margin-left: 2em">而有食亦依此理</span>  
<span style="margin-left: 1em">二曰明暗兩體任一運動景隨之移　試以暗體移動</span>  
<span style="margin-left: 2em">其所借之光隨處不一即所生之景亦隨處不一蓋</span>  
<span style="margin-left: 2em">景與光既如一直線即暗體所居定爲景之末界如</span>  
<span style="margin-left: 2em">直線之首首移而線尚不移則是曲線非直線也又</span>  
<span style="margin-left: 2em">試以明體移動設甲爲明體乙爲暗體乙丙爲影則</span>  
<span style="margin-left: 2em">甲乙丙如一直線如曰明體甲移至丁丁仍照乙而</span>  
<span style="margin-left: 6em">乙尚射景至丙則丁乙丙猶直線也有是</span>  
<span style="margin-left: 6em">理乎</span>  
<span style="margin-left: 2em">問太陽照室僅通隙光光照墻壁奕奕顫動太陽既</span>  
<span style="margin-left: 2em">自順行墻隙仍無遷變則此顫動爲從何來或者光</span>  
<span style="margin-left: 2em">與景未必定爲直線而能微作曲勢乎曰西古博物</span>  
<span style="margin-left: 2em">者亞利斯多言空中嘗有浮埃輕而不墜微而不顯</span>  
<span style="margin-left: 2em">莊周氏謂之野馬或亦稱爲白駒幽室之內原光既</span>  
<span style="margin-left: 2em">微次光反厚即顯此物在于光中紛入沓出能亂光</span>  
<span style="margin-left: 2em">景之界使目視景絪緼浮動而實非景動乃景之界</span>  
<span style="margin-left: 2em">線爲浮埃所亂致使其然也更以氣爲證今觀太陽</span>  
<span style="margin-left: 2em">出地地面以上多生蒙氣氣在日體與人目之間即</span>  
<span style="margin-left: 2em">見日之光界亦如顫動非獨日也日中晴朗切視地</span>  
<span style="margin-left: 2em">面光耀閃爍如波浪然熾炭在罏炭之四周火光燁</span>  
<span style="margin-left: 2em">燁亦如顫動凡若此者一皆繇氣而生在日在地在</span>  
<span style="margin-left: 2em">炭固無顫動之理是以景必繫于暗體如輪必繫于</span>  
<span style="margin-left: 2em">樞軸光上景即下光東景即西必相對也無相就也</span>  
<span style="margin-left: 2em">故太陽照地其光繞地一周則景在其相衝之界亦</span>  
<span style="margin-left: 2em">繞天一周蓋日光從其本天直射至於地面而景在</span>  
<span style="margin-left: 2em">地之彼面亦直射至于月天第日體常依黃道中線</span>  
<span style="margin-left: 2em">則地景亦常依黃道中線而月行常出入黃道中線</span>  
<span style="margin-left: 2em">之內外是以月體與地景不得恆相遇合大都不合</span>  
<span style="margin-left: 2em">時多合時少故日月不食時多食時少以此</span>  
<span style="margin-left: 2em">景之形勢第三</span>  
<span style="margin-left: 1em">求食分之幾何必先求景之幾何景幾何者以日月地</span>  
<span style="margin-left: 2em">之大得景之形勢以日月地相距之遠近分數得景</span>  
<span style="margin-left: 2em">之變易大小分數也此所論則景之形勢後考其變</span>  
<span style="margin-left: 2em">易之勢得景分以定食分焉凡二章</span>  
<span style="margin-left: 1em">一曰二體相等其影平行而無窮明小暗大其景漸展</span>  
<span style="margin-left: 2em">而無窮　論相等者證以平行之切線也如圖甲乙</span>  
<span style="margin-left: 2em">兩球等丙己丁戊爲兩球之切線與兩球之徑丙丁</span>  
<span style="margin-left: 9em">己戊遇于切點皆爲直角則互爲</span>  
<span style="margin-left: 9em">平行線又球等即徑之長短亦等</span>  
<span style="margin-left: 9em">以遇丙己及丁戊無不爲平行線</span>  
<span style="margin-left: 9em">也<sub class="note-yuan">幾何一卷三十三題</sub>若兩球之周遭切線</span>  
<span style="margin-left: 2em">無數皆同此論則引之至庚辛以迨無窮終平行終</span>  
<span style="margin-left: 2em">不能相遇而其形爲長圓柱之無窮體</span>  
<span style="margin-left: 2em">論明球小于暗球則推以三角形相似之比例也如</span>  
<span style="margin-left: 2em">圖乙丙爲小明球丁戊爲大暗球兩球之切線丁乙</span>  
<span style="margin-left: 2em">及戊丙引長之過小球必相遇于甲成甲丁戊三角</span>  
<span style="margin-left: 2em">形又從丁戊底作己庚平行線在大球之外成庚甲</span>  
<span style="margin-left: 2em">己三角形與甲丁戊相似則甲己庚角與甲丁戊角</span>  
<span style="margin-left: 2em">相等其各邊各角皆相似而甲丁與丁戊若甲己與</span>  
<span style="margin-left: 10em">己庚也反而更之己庚與丁戊</span>  
<span style="margin-left: 10em">若甲己與甲丁也甲己長與甲</span>  
<span style="margin-left: 10em">丁則己庚亦長與丁戊愈遠愈</span>  
<span style="margin-left: 2em">長可見大球之影漸遠漸拓矣<sub class="note-yuan">幾何六卷四題</sub>更論丁戊線</span>  
<span style="margin-left: 2em">之內外角則在內者爲銳角在外者爲鈍角故引切</span>  
<span style="margin-left: 2em">線向內過小球必相遇引之向外愈遠愈拓終不相</span>  
<span style="margin-left: 2em">遇而其形爲無限長無限廣之角體又因兩球所居</span>  
<span style="margin-left: 2em">遠近不同景之張翕隨而變易故兩球相近即乙丙</span>  
<span style="margin-left: 2em">底線爲小其景愈狹而乙甲丙角形愈短兩球相遠</span>  
<span style="margin-left: 2em">即底線爲大其景愈拓而角形愈長也</span>  
<span style="margin-left: 2em">今驗諸日食有食分同而所歷時刻不同者月景之</span>  
<span style="margin-left: 2em">在地面廣狹不同也月與日會月在日與地之間或</span>  
<span style="margin-left: 2em">月近地而日在遠則目之見界過月周至日體其界</span>  
<span style="margin-left: 2em">廣日過遲其見食時刻多或月遠地而日反近則目</span>  
<span style="margin-left: 2em">之見界過月周至日體其界狹日過速其見食時刻</span>  
<span style="margin-left: 2em">少也姑以前圖明之目在甲乙丙爲月體丁戊爲日</span>  
<span style="margin-left: 2em">體切線甲丁及甲戊爲目所見之界若日在近爲丁</span>  
<span style="margin-left: 2em">戊即從丁過戊道近行速其食時寡若在遠爲己庚</span>  
<span style="margin-left: 2em">從己過庚道遠行遲其食時多皆太陽有不同心圈</span>  
<span style="margin-left: 2em">而太陰又有小輪所繇生也</span>  
<span style="margin-left: 1em">二曰日月地三體大小不同　凡暗體出角景者施光</span>  
<span style="margin-left: 2em">之體必大于暗體否者其光不能照暗體之大半而</span>  
<span style="margin-left: 2em">使其景漸小以趨于盡也試觀月食時月體近地則</span>  
<span style="margin-left: 2em">入大景遠地則入小景愈遠愈小必至于盡安得不</span>  
<span style="margin-left: 2em">信日體大于地體乎設謂日體與地體或等則景宜</span>  
<span style="margin-left: 2em">亦等或小則宜漸大又當皆爲無窮之景遇望時月</span>  
<span style="margin-left: 2em">體必不能出大影之外不應有不食之望矣有不食</span>  
<span style="margin-left: 2em">者是地景之益遠益銳也月食於地景之中又有全</span>  
<span style="margin-left: 2em">而且久者是月徑更小于景而景小于地也地景之</span>  
<span style="margin-left: 2em">遠而益銳者是日大于地也此以景理推論三體之</span>  
<span style="margin-left: 2em">小大畧可明矣若又以日體之大推月地之景則更</span>  
<span style="margin-left: 2em">有法可考其大小之比例也昔人因太陽照地所生</span>  
<span style="margin-left: 2em">之景及其遠近其視徑時時不同又以較于他體得</span>  
<span style="margin-left: 2em">其實體之大說見月離曆指中此獨用視徑定食時</span>  
<span style="margin-left: 2em">刻分之數其論實體爲景與食之原畧舉一二如左</span>  
<span style="margin-left: 2em">幾何原本論三角形于一邊之兩界出兩線復作一</span>  
<span style="margin-left: 2em">三角形在其內則內形兩腰并之必小于相對兩腰</span>  
<span style="margin-left: 2em">而後兩線所作角必大于相對角如圖甲乙爲太陽</span>  
<span style="margin-left: 2em">之徑丙爲目從遠視之丁亦爲目從近視之此所謂</span>  
<span style="margin-left: 2em">內外兩三角形也今先以線論因內形之甲丁乙丁</span>  
<span style="margin-left: 2em">兩腰小于相對之甲丙乙丙兩腰則所作丁角比相</span>  
<span style="margin-left: 10em">對之兩角亦近于共用之甲乙</span>  
<span style="margin-left: 10em">底近則見大故丁目視甲乙日</span>  
<span style="margin-left: 2em">徑必見大于丙目所視之甲乙徑也次以角論因內</span>  
<span style="margin-left: 2em">兩線所作丁角大于相對丙角則此內角所對線亦</span>  
<span style="margin-left: 2em">似大于外角所對線而丁目所見之甲乙大于丙目</span>  
<span style="margin-left: 2em">所見之甲乙也此太陽視徑不同之緣也</span>  
<span style="margin-left: 2em">求太陽實體之大第谷設最高最庳之中處得其距</span>  
<span style="margin-left: 2em">地一千一百五十地半徑全數十萬其半徑一十五</span>  
<span style="margin-left: 2em">分三十秒得正弦四百五十一以三率算法推其全</span>  
<span style="margin-left: 2em">徑得地之全徑五又七十五之一十四如三百八十</span>  
<span style="margin-left: 2em">九與七十五也又以其徑與其周之比例得太陽體</span>  
<span style="margin-left: 2em">之立方五千八百八十六萬三千八百六十九地球</span>  
<span style="margin-left: 2em">之立方四十二萬一千八百七十五其終數得一百</span>  
<span style="margin-left: 2em">四十弱爲太陽大于地之倍數也此其照月照地生</span>  
<span style="margin-left: 2em">角體銳景之原也</span>  
<span style="margin-left: 2em">景之作用第四</span>  
<span style="margin-left: 2em">月與地若各以其景相酧報然如月望則地景隔日</span>  
<span style="margin-left: 2em">光令月不受照有時失滿光有時全失光也至月朔</span>  
<span style="margin-left: 2em">則月體隔日光令地不受照有處射滿影有處留少</span>  
<span style="margin-left: 2em">光而已說三章</span>  
<span style="margin-left: 1em">一曰月食于地景　月食在望緣日月相對其理明矣</span>  
<span style="margin-left: 2em">獨謂闇虛爲地景者或致疑焉今解之月對日受光</span>  
<span style="margin-left: 2em">藉非日月之間有不通光之實體爲其映蔽則何繇</span>  
<span style="margin-left: 2em">阻日光之直照若天體及空中之火空中之氣皆通</span>  
<span style="margin-left: 2em">明透徹不能作障使月失光也即金水二星亦是實</span>  
<span style="margin-left: 2em">體有時居日月之間然其景俱不及地况能過地及</span>  
<span style="margin-left: 2em">月乎則知能掩月者惟有地體一面受光一面射景</span>  
<span style="margin-left: 2em">而月體爲借光之物入此景中無能不食半進而半</span>  
<span style="margin-left: 2em">食矣全進而全食矣</span>  
<span style="margin-left: 1em">二曰日食者月掩之　恆言月在內去人近日在外去</span>  
<span style="margin-left: 2em">人遠故定朔時月體能掩日光是已第金水二星亦</span>  
<span style="margin-left: 2em">皆時在日內又皆不通光之實體水星雖小金星則</span>  
<span style="margin-left: 2em">大于月也何獨月能食日乎曰二星雖有時在日內</span>  
<span style="margin-left: 2em">則去人甚遠遠則視徑見小不能掩日百分之一二</span>  
<span style="margin-left: 2em">而日光甚盛所虧百之一二非目力所及且二星比</span>  
<span style="margin-left: 2em">月去日更近所出銳角之景更短不能及地面也若</span>  
<span style="margin-left: 2em">月體之大雖不及太白而去地甚近去日甚遠一指</span>  
<span style="margin-left: 2em">足蔽泰山又何疑乎由此言之求一實不通光之體</span>  
<span style="margin-left: 2em">全掩日體者惟月爲能又自西而東不及三十日而</span>  
<span style="margin-left: 2em">周其行度較于諸天最爲疾速故每望定朔皆同經</span>  
<span style="margin-left: 2em">度皆能有食其不食者繇距度不及交耳</span>  
<span style="margin-left: 1em">三曰因景之徑生多變易　月以距度廣狹爲食分多</span>  
<span style="margin-left: 2em">寡一因去交有遠有近去黃道中線有正有偏一因</span>  
<span style="margin-left: 2em">入地景有淺有深故也今論其全食者而大小遲疾</span>  
<span style="margin-left: 2em">猶多變易曾非一定蓋日在自行本天月在小輪相</span>  
<span style="margin-left: 2em">距遠近往往不等日距月近較距遠時更照月體之</span>  
<span style="margin-left: 2em">多分從月體出景更短其景至地更小則日雖全食</span>  
<span style="margin-left: 2em">月體見小歷時亦速也日與地亦然以兩體相距之</span>  
<span style="margin-left: 2em">遠近爲地景之大小使月食時入于地景在其近末</span>  
<span style="margin-left: 2em">之銳分則闇虛之體見小食分少歷時速皆因三體</span>  
<span style="margin-left: 2em">之相距遠近以生大小遲疾地景月景皆無一定之</span>  
<span style="margin-left: 2em">徑致令隨時變易如此</span>  
<span style="margin-left: 2em">若月景地景二徑之小大又自不等故日食盡于食</span>  
<span style="margin-left: 2em">既而月則食既以後尚有既內餘分蓋地景大于月</span>  
<span style="margin-left: 2em">景故兩食皆全其虧復遲疾無能不異矣又月食天</span>  
<span style="margin-left: 2em">下皆同日食則否日食則此地速彼地遲此地見多</span>  
<span style="margin-left: 2em">彼地見少此地見偏南彼地見偏北無不異也月食</span>  
<span style="margin-left: 2em">則凡居地面者目所共見其食分大小同虧復遲疾</span>  
<span style="margin-left: 2em">同經歷時刻同唯所居不同子午線者則見食之時</span>  
<span style="margin-left: 2em">刻先後不同耳蓋月一入景失去借光更無處可見</span>  
<span style="margin-left: 2em">其光也又槩論天下日食應多于月食爲二徑折半</span>  
<span style="margin-left: 2em">其近交時加以南北視差易相逮及故論一方則日</span>  
<span style="margin-left: 2em">食應少於月食爲月食共見日食因地故<sub class="note-yuan">見後卷詳之</sub></span>  
<span style="margin-left: 2em">月在景之光色第五</span>  
<span style="margin-left: 1em">月既暗體當全食時一入地景遂應失其借光非復人</span>  
<span style="margin-left: 2em">目可見也蓋可見之物悉無原光必借外光以顯其</span>  
<span style="margin-left: 2em">象無外光即無從見有此物安從更顯物色乎今月</span>  
<span style="margin-left: 2em">居厚影尚有微光可見更發色象或赤色或青黑色</span>  
<span style="margin-left: 2em">或襍色此何從生今畧解之凡三章</span>  
<span style="margin-left: 1em">一曰月不獨食于地影　論通光者有二體一謂物象</span>  
<span style="margin-left: 2em">遇甚徹之體易于通射比于發象元處更加透明則</span>  
<span style="margin-left: 2em">形若開而散焉一謂物象遇次澈之體難于通射比</span>  
<span style="margin-left: 2em">于發象元處少襍昏暗則形若歛而聚焉其遇甚徹</span>  
<span style="margin-left: 2em">者如舟用篙艣半在水中發象上出出於水面所遇</span>  
<span style="margin-left: 2em">空明氣之光甚澈之體也則其象散而斜射視之若</span>  
<span style="margin-left: 2em">曲焉其遇次澈者如太陽入地平下其光照地旁本</span>  
<span style="margin-left: 2em">宜直上乃所遇清蒙之氣次澈之體也則其象合聚</span>  
<span style="margin-left: 2em">而射于地面凡地平以上皆得其次光爲朦朧焉<sub class="note-yuan">即昧</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">爽黃昏亦曰晨昏</sub>此兩者皆以一物經繇兩體其勢曲折皆</span>  
<span style="margin-left: 2em">謂之折照<sub class="note-yuan">若一物在一體之中以一直線入目謂之直照</sub>夫同是日光也在</span>  
<span style="margin-left: 2em">地面之上能折入于地景之根際則自地面而上何</span>  
<span style="margin-left: 2em">獨不能折入於景之中際至月體經行之處乎如圖</span>  
<span style="margin-left: 2em">甲爲太陽乙爲地球藉非清蒙氣能迎太陽之光而</span>  
<span style="margin-left: 2em">成折照則宜從子出光至丙從丑出光至丁切地面</span>  
<span style="margin-left: 2em">徑過而復合于庚爲地景銳角也今不其然因清蒙</span>  
<span style="margin-left: 2em">氣周遶地球日光至丙至丁遇其次澈之體難于透</span>

<span style="margin-left: 17em">聚止于戊己</span>  
<span style="margin-left: 17em">地面矣而大</span>

<span style="margin-left: 2em">即內歛至于卯辰此爲初折從卯辰切地而過若遂</span>

<span style="margin-left: 2em">地之滿影自此以外全景之中皆得太陽折照之光</span>  
<span style="margin-left: 2em">與朦朧次光相類而實爲初景能食望月之滿光也</span>  
<span style="margin-left: 2em">欲求滿景之長姑先依初折之光引直線復出于蒙</span>

<span style="margin-left: 2em">體勢顯其食之貌象今全景之中既以地景兼蒙氣</span>  
<span style="margin-left: 2em">之景則并有初景有滿景月入于中隨其所至變易</span>

<span style="margin-left: 2em">愈長愈廣乎則從上古以來以地徑度月體過景之</span>  
<span style="margin-left: 2em">數以地徑定日月之視徑以地徑較日月之兩高以</span>

<span style="margin-left: 2em">之一耳此氣之厚何能加于地徑而云設此論者有</span>  
<span style="margin-left: 2em">妨於地徑測量之法乎</span>
