<span style="margin-left: 2em">辛丙癸子爲繩子爲懸錘壬辛庚爲吸水管壬頭在</span>

<span style="margin-left: 1em">第一造規法</span>  
<span style="margin-left: 1em">此運規之器形以銅鐵爲之圓頭二髀可閤可開一居</span>  
<span style="margin-left: 1em">心一旋轉銳施精鋼若用以量其兩髀須極銳若用墨</span>  
<span style="margin-left: 1em">其一髀須極銳其一作一小溝以便用墨可以爲圖可</span>  
<span style="margin-left: 1em">以作直線也</span>  
<span style="margin-left: 1em">第二造界尺</span>  
<span style="margin-left: 1em">若界尺欲驗其直否則任依其一邊畫線試如界尺在</span>  
<span style="margin-left: 1em">北畫線在南勿令線移第轉尺令其原邊在線南線在</span>  
<span style="margin-left: 1em">尺北視其切合原線否如合則直否則曲矣視不合處</span>  
<span style="margin-left: 1em">而得尺之曲處也</span>  
<span style="margin-left: 1em">或如前尺在線北線在尺南線不動但反覆界尺反其</span>  
<span style="margin-left: 1em">下面向下東端向西亦視界尺原邊與線切合否即得</span>  
<span style="margin-left: 1em">其曲直處也</span>  
<span style="margin-left: 1em">第三作引長線法</span>  
<span style="margin-left: 1em">有甲乙兩點相近或甲乙短線求依甲乙引增作一長</span>  
<span style="margin-left: 7em">線甲乙太短必差也先以甲爲心乙爲</span>  
<span style="margin-left: 7em">界作半圈從乙向圈任截乙丙乙丁兩</span>  
<span style="margin-left: 7em">度等即從丙丁向乙平處各作短界線</span>  
<span style="margin-left: 7em">交于己次以甲爲心己爲界作圈分從</span>  
<span style="margin-left: 7em">己向圈任截己戊己庚兩度等即從戊</span>  
<span style="margin-left: 7em">庚向己平處各作短界線交于壬次以</span>  
<span style="margin-left: 7em">甲爲心壬爲界又作圈分從壬任截壬</span>  
<span style="margin-left: 7em">辛壬艮兩度等即從辛艮向壬平處各</span>  
<span style="margin-left: 1em">作短界線交于土末作甲乙己壬土線其線即所求若</span>  
<span style="margin-left: 1em">欲更長依此推作</span>  
<span style="margin-left: 3em">又作引長線三法</span>  
<span style="margin-left: 1em">第一法以甲乙各爲心左右各作兩短界線交于丙于</span>  
<span style="margin-left: 7em">丁即以丙丁各爲心向乙平處各作短</span>  
<span style="margin-left: 7em">界線交于戊<sub class="note-jiao">校：交于戊原作交于以據天理本改</sub>次以乙</span>  
<span style="margin-left: 7em">戊各爲心各作兩短界線交于己于庚</span>  
<span style="margin-left: 7em">即以己庚各爲心向戊平處各作短界</span>  
<span style="margin-left: 7em">線交于辛次以戊辛各爲心各作兩短</span>  
<span style="margin-left: 7em">界線交于壬于艮即以壬艮各爲心向</span>  
<span style="margin-left: 7em">辛平處各作短界線交于土即將甲乙</span>  
<span style="margin-left: 7em">戊辛土共作一直線即得也</span>  
<span style="margin-left: 8em">第二法從甲壬作一長線爲甲庚竹</span>  
<span style="margin-left: 8em">成甲角此角固不至直亦勿太銳又</span>  
<span style="margin-left: 8em">從乙任作乙丁一線交長線于丙次</span>  
<span style="margin-left: 8em">以甲丙爲度從丙依長線截取丙戊</span>  
<span style="margin-left: 8em">戊己己庚庚辛四分則甲辛爲五平</span>  
<span style="margin-left: 8em">分也次任用一度以丙爲心作圈分</span>  
<span style="margin-left: 8em">石丁交甲庚線于石交丙乙線于丁</span>  
<span style="margin-left: 8em">即用元度以庚爲心亦作圈分交甲</span>  
<span style="margin-left: 8em">庚線于壬從壬向圈截取壬艮與石</span>  
<span style="margin-left: 1em">丁等次作庚艮線必與丙丁平行次庚爲甲庚線第四</span>  
<span style="margin-left: 1em">分即以丙乙爲度從庚向艮截取四分至土末作甲乙</span>  
<span style="margin-left: 1em">土直線即所求若欲更長則以庚壬爲度以辛爲心作</span>  
<span style="margin-left: 1em">圈分交甲庚線于竹次從竹截竹云與石丁等次作辛</span>  
<span style="margin-left: 1em">云線必與丙丁庚土平行次辛爲甲庚線第五分<sub class="note-jiao">校：五原作</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">九據天理本改</sub>即亦以丙乙爲度于辛云線上從辛向云截取</span>  
<span style="margin-left: 1em">五分至甘末<sub class="note-jiao">校：五分原作土分據天理本改</sub>作甲土甘直線即所求若</span>  
<span style="margin-left: 1em">欲更引長之依此推作第視甲庚線幾分如是六分七</span>  
<span style="margin-left: 1em">分則丙乙平行線亦截丙乙六分七分也或命甲元爲</span>  
<span style="margin-left: 1em">引長短線先作甲庚竹長線即任用一度從甲向長線</span>  
<span style="margin-left: 1em">截取第一分爲丙第四分爲庚次從丙任作一線交甲</span>  
<span style="margin-left: 1em">元線于乙不必交元點次如前法得庚艮線即以丙乙</span>  
<span style="margin-left: 1em">爲度作四分于庚艮線亦得土也</span>  
<span style="margin-left: 1em">第三法以乙爲心甲爲界作圈分次用元度從甲向圈</span>  
<span style="margin-left: 1em">截取丙丁戊三分即半圈也又以戊爲心乙爲界作圈</span>  
<span style="margin-left: 1em">分如前截得丁己庚三分又以庚爲心戊爲界作圈分</span>  
<span style="margin-left: 1em">如前截得己辛壬三分又以壬爲心庚爲界作圈分如</span>  
<span style="margin-left: 1em">前截得辛艮土三分次以戊爲心甲爲界作圈分如前</span>  
<span style="margin-left: 1em">截得石元壬三分又以壬爲心戊爲界作圈分如前截</span>  
<span style="margin-left: 1em">得元牙竹三分又以竹爲心壬爲界作圈分如前截得</span>  
<span style="margin-left: 1em">牙弓云三分次以壬爲心甲爲界作圈分如前截得坎</span>  
<span style="margin-left: 1em">仁云三分必與壬云圈遇于云也次又以竹爲心甲爲</span>  
<span style="margin-left: 1em">界作圈分如前截得尺勺甘三分末作甲乙戊庚壬土</span>  
<span style="margin-left: 1em">竹云甘線即所求若欲更長則又以云或甘爲心壬爲</span>  
<span style="margin-left: 7em">界依法推作</span>  
<span style="margin-left: 7em">第四作平行線法</span>  
<span style="margin-left: 7em">有甲乙線線外有丙點求從丙作線與</span>  
<span style="margin-left: 7em">甲乙平行先從丙點或左或右任取一</span>  
<span style="margin-left: 7em">點或在甲乙線上如丁或在甲乙線及</span>  
<span style="margin-left: 7em">丙點聞處如戊或與丙點平處如己次</span>  
<span style="margin-left: 7em">以丁爲心過丙作圈分交甲乙線于庚</span>  
<span style="margin-left: 5em">次用元度復以丁爲心與丙庚圈分對處復</span>  
<span style="margin-left: 5em">作辛壬圈分交甲乙線于壬次以丙庚爲度</span>  
<span style="margin-left: 5em">移之從壬至辛丙辛二點作直線即甲乙平</span>  
<span style="margin-left: 5em">行線也或以戊爲心右作丙元左作弓牙圈</span>  
<span style="margin-left: 5em">分或以己爲心右作丙以左作尺仁圈分皆</span>  
<span style="margin-left: 5em">得但所取點在甲乙線及丙點之間如丁則</span>  
<span style="margin-left: 5em">圈分交甲乙線更直更易準也</span>  
<span style="margin-left: 5em">第五作垂線法</span>  
<span style="margin-left: 5em">先得甲乙橫線欲從丙點作一垂線即以丙</span>  
<span style="margin-left: 1em">爲心左右任取二點甲乙去丙等次任用一度但須長</span>  
<span style="margin-left: 8em">于丙甲甲乙各爲心以上向丙點平</span>  
<span style="margin-left: 8em">處各作一短界線兩線上交于丁下</span>  
<span style="margin-left: 8em">交于戊次作丁戊直線必過于丙且</span>  
<span style="margin-left: 8em">必爲甲乙垂線與甲乙成直角形也</span>  
<span style="margin-left: 8em">若不便作上下短界線止作或上或</span>  
<span style="margin-left: 8em">下亦足矣若所命作垂線點在線界</span>  
<span style="margin-left: 8em">如己外無餘線可截即于甲乙線上</span>  
<span style="margin-left: 8em">任取一點爲庚如前法從庚立庚辛</span>  
<span style="margin-left: 8em">垂線次任取一度以己爲心向上或</span>  
<span style="margin-left: 8em">下作短界線次用元度從庚于庚辛</span>

<span style="margin-left: 1em">第二十二作節氣曲線捷法</span>  
<span style="margin-left: 1em">夫直線用尺圓線用規獨曲線無法故最難作蓋分時</span>  
<span style="margin-left: 1em">帶節則長短廣狹之間有不可以相合者故必以本晷</span>  
<span style="margin-left: 1em">作法晷小別作于薄銅板上晷大或薄木紙板上作曲</span>  
<span style="margin-left: 1em">線次依各曲線裁磋令極順以待作曲線之用若十字</span>  
<span style="margin-left: 1em">晷及面東面西面南與大凡<sub class="note-jiao">校：大凡天理本作夫凡</sub>時線爲平行</span>

<span style="margin-left: 12em">線近赤道兩旁作節線界</span>
