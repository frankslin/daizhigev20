<span style="margin-left: 1em">若平晷天顶晷与夫凡时线聚于一心不能为平行线</span>  
<span style="margin-left: 1em">之晷者板上依本晷之法画时线次各线上从心定节</span>  
<span style="margin-left: 1em">线界识循识截板而得也试如甲为晷心从心画诸时</span>  
<span style="margin-left: 1em">次依本晷作法从甲定第一节气线界识为乙丙丁戊</span>  
<span style="margin-left: 1em">己庚依识截板而得也其第二三四五六皆依此法截</span>  
<span style="margin-left: 1em">之而二十四节气线板备矣相对节线如芒种小暑大</span>  
<span style="margin-left: 1em">雪小寒其线曲直等故两线共一板板六片而二十四</span>  
<span style="margin-left: 1em">节线俱可尽矣不啻相对节线等即一节线午前午后</span>  
<span style="margin-left: 1em">两半亦等用板半片既画午前半节气线反板则作午</span>  
<span style="margin-left: 1em">后半节气线是以六半片而二十四节气俱可画画矣</span>  
<span style="margin-left: 1em">第用板时本晷上既尽时线则于午后上及前后各任</span>  
<span style="margin-left: 1em">二三时线上各定节气线界识令本节线板曲边切合</span>  
<span style="margin-left: 1em">晷上节气界识曲板上时线切加晷上时线上下正对</span>  
<span style="margin-left: 1em">午对午辰对辰未对未依曲边作深线而节气界定矣</span>

<span style="margin-left: 1em">第二十三正表法</span>  
<span style="margin-left: 1em">晷表立不正则指节气及时刻俱不准故须得法以正</span>  
<span style="margin-left: 8em">之法曰凡用直表即以表位为心任</span>  
<span style="margin-left: 8em">作一圈次用规其一髀任指圈上其</span>  
<span style="margin-left: 8em">一指表端自圈上三处量表端如三</span>  
<span style="margin-left: 8em">相遇于一则表正矣否则偏试如甲</span>  
<span style="margin-left: 8em">为表位乙为表端即以甲为心作丙</span>  
<span style="margin-left: 8em">丁戊圈任从丙从丁从戊量乙若俱</span>  
<span style="margin-left: 8em">相遇于乙即甲乙表正立矣否则移</span>  
<span style="margin-left: 8em">而正之如欲切知自丙至乙开规二</span>  
<span style="margin-left: 8em">髀之度即以甲丙本圈半径为度别</span>  
<span style="margin-left: 8em">作己庚线次从乙立己辛为己庚垂</span>  
<span style="margin-left: 1em">线而与甲乙表长等次以庚辛相望作线庚辛即开规</span>  
<span style="margin-left: 1em">髀自圈量乙之度也</span>  
<span style="margin-left: 1em">若恐立表移动而再正之则从甲表位任作壬土线或</span>  
<span style="margin-left: 1em">与表长等如竹或任更长如元次任作壬土垂线即以</span>  
<span style="margin-left: 1em">壬土为度从壬左右行截壬甘壬艮与壬土等次作土</span>  
<span style="margin-left: 1em">甘土艮两斜线即从土斜行截土牙土坎与所定表长</span>  
<span style="margin-left: 1em">等次以甘坎或艮牙为度于甘艮线上从甘截仁从艮</span>  
<span style="margin-left: 1em">截尺次用规以甘仁或艮尺为度自甘自艮各量表端</span>
