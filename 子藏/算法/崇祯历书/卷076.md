<span style="margin-left: 3em">總說</span>  
<span style="margin-left: 1em">圜成於線線有二種爲曲爲直直線或單或衆前卷已</span>  
<span style="margin-left: 1em">詳之衆線或三而成三角形或四而成方形或多而成</span>  
<span style="margin-left: 1em">諸不等形曲線或半或全半線有不等之用全線或成</span>  
<span style="margin-left: 1em">圜形或成卯形等角形及方形卯形詳見後卷今先論</span>  
<span style="margin-left: 1em">圜形</span>  
<span style="margin-left: 2em">界說章第一<sub class="note-yuan">十二則</sub></span>  
<span style="margin-left: 3em">第一界</span>  
<span style="margin-left: 1em">圓形於平地居一界之間爲圜</span>  
<span style="margin-left: 3em">第二界</span>  
<span style="margin-left: 1em">外圓線爲圜之界</span>  
<span style="margin-left: 3em">第三界</span>  
<span style="margin-left: 1em">圜之中處爲圜心</span>  
<span style="margin-left: 3em">第四界</span>  
<span style="margin-left: 1em">自圜之界作一直線過中心至他界爲圜徑如上圖甲</span>  
<span style="margin-left: 5em">丁乙戊爲圜界丙爲心甲乙爲徑</span>  
<span style="margin-left: 3em">第五界</span>  
<span style="margin-left: 5em">凡直線切圜界過之而不與界交者爲切線</span>  
<span style="margin-left: 5em">如上圖甲乙丙線是也若先切圜界而引之</span>  
<span style="margin-left: 5em">入圜內則謂之交線如丁戊是也</span>  
<span style="margin-left: 7em">第六界</span>  
<span style="margin-left: 5em">凡兩圜相切而不相交者爲切圜相切而相</span>  
<span style="margin-left: 5em">入者爲交圜加上圖</span>  
<span style="margin-left: 7em">第七界</span>  
<span style="margin-left: 5em">凡直線形居他直線形內而此形之各角切</span>  
<span style="margin-left: 5em">他形之各邊爲形內切形如上圖丁戊己爲</span>  
<span style="margin-left: 1em">甲乙丙形內切形</span>  
<span style="margin-left: 3em">第八界</span>  
<span style="margin-left: 1em">凡直線形居他直線形外而此形之各邊切他形之各</span>  
<span style="margin-left: 1em">角爲形外切形如前圖甲乙丙爲丁戊己形外切形其</span>  
<span style="margin-left: 1em">餘各形倣此二例</span>  
<span style="margin-left: 3em">第九界</span>  
<span style="margin-left: 1em">直線形之各角切圜之界爲圜內切形如上圖甲乙丙</span>  
<span style="margin-left: 5em">形之三角各切圜界於甲於乙於丙是也圜</span>  
<span style="margin-left: 5em">之界切直線形之各角爲形外切圜同上圖</span>  
<span style="margin-left: 7em">第十界</span>  
<span style="margin-left: 1em">直線形之各邊切圜之界爲圜外切形如上甲乙丙形</span>  
<span style="margin-left: 5em">之三邊切圜於丁於己於戊是也</span>  
<span style="margin-left: 7em">第十一界</span>  
<span style="margin-left: 1em">一圜之界切直線形之各邊爲形內切圜如前圖</span>  
<span style="margin-left: 3em">第十二界</span>  
<span style="margin-left: 1em">一直線之兩界各抵圜界爲合圜線如上圖之甲乙線</span>  
<span style="margin-left: 2em">造規章第二<sub class="note-yuan">法有四</sub></span>  
<span style="margin-left: 5em">圜形以至圓爲準至圓必出於規規必欲極</span>  
<span style="margin-left: 5em">準極順其用甚活乃堪造曆凡造規之法有</span>  
<span style="margin-left: 1em">四詳列於後</span>  
<span style="margin-left: 3em">第一法</span>  
<span style="margin-left: 1em">先以銅或鐵範成二股上濶下窄至末而銳近頭小半</span>  
<span style="margin-left: 1em">截作凹凸狀令可相合次以釘釘其圓頭貴寬緊得宜</span>  
<span style="margin-left: 1em">任意可開收規下半截爲規髀一規髀作墨池如首卷</span>  
<span style="margin-left: 1em">第三章法以適用凡欲造曆象必須備規其造式見後</span>  
<span style="margin-left: 2em">規圖</span>  
<span style="margin-left: 3em">第二法</span>  
<span style="margin-left: 1em">凡規有三用一畫虛線則須鉛條當先以銅葉爲管虛</span>  
<span style="margin-left: 1em">其中橫開小路上套小銅圜可上下鬆緊以出入鉛條</span>  
<span style="margin-left: 1em">末畧奓出以留小圜如下甲圖一畫墨線則當作墨路</span>  
<span style="margin-left: 1em">如前章法如下乙圖一畫銅板線須以純鋼爲末如下</span>  
<span style="margin-left: 1em">丙圖右三髀俱另作不相連本規其本規如前法造但</span>  
<span style="margin-left: 1em">截去一髀臨截處長半寸許作一小箱狀虛其中亦令</span>  
<span style="margin-left: 1em">方可受規髀柄如下圖丁處箱面作旋螺用時任入一</span>  
<span style="margin-left: 1em">規髀以銅消息如旋螺者貫定之如下戊圖則任意可</span>  
<span style="margin-left: 1em">畫線而一規可具三用矣此爲第二法如下圖</span>  
<span style="margin-left: 3em">第三法</span>  
<span style="margin-left: 1em">造曆恆用規依比例法分線分圜或以大形移變小形</span>  
<span style="margin-left: 1em">或以小度移變大度其分法稍難今作一四髀規或銅</span>  
<span style="margin-left: 1em">或鐵畧如剪形上下作四規髀上短下長令上準下度</span>  
<span style="margin-left: 1em">或半或三之一或十之一及種種不等則作線圜時或</span>  
<span style="margin-left: 1em">欲以大變小先以下髀取度次以上髀移度或欲以小</span>  
<span style="margin-left: 1em">變大先以上髀取度次以下髀移度則得所求其或半</span>  
<span style="margin-left: 1em">或三之一或十之一俱從髀之長短而分下愈長則度</span>  
<span style="margin-left: 1em">愈大上愈短則度愈促</span>  
<span style="margin-left: 3em">第四法</span>  
<span style="margin-left: 1em">前三種規長不踰尺止堪小用如欲造璣衡大器則當</span>  
<span style="margin-left: 1em">更變其式如下圖其規以銅範爲極方條上下如一任</span>  
<span style="margin-left: 1em">作幾尺於條左末作錐垂下二三寸以純鋼爲之更造</span>  
<span style="margin-left: 1em">一錐與前錐等上方寸許仍鑿方孔令透可受方條任</span>  
<span style="margin-left: 1em">遠近可推移方孔旁更鑿圓孔仍前法作旋螺貫定方</span>  
<span style="margin-left: 1em">條使兩錐堅定不爽分毫可畫大圜如下圖</span>  
<span style="margin-left: 6em">有圜求兩平分之章第三<sub class="note-yuan">一法</sub></span>  
<span style="margin-left: 5em">如有甲乙丙圜求兩平分用尺任以圜一處</span>  
<span style="margin-left: 5em">爲界正過心畫一直線則圜體兩平分矣</span>  
<span style="margin-left: 2em">有圜之分求兩平分之章第四<sub class="note-yuan">一法</sub></span>  
<span style="margin-left: 5em">如有甲乙丙圜分求兩平分之先於圜分兩</span>  
<span style="margin-left: 5em">界作甲乙線次兩平分之於丁從丁作丙丁</span>  
<span style="margin-left: 5em">爲甲乙之垂線<sub class="note-yuan">一卷第八章</sub>即丙丁分甲乙圜分</span>  
<span style="margin-left: 1em">爲兩平分若有圜不露其心又求兩平分之亦如此法</span>  
<span style="margin-left: 2em">有圜求四平分之章第五<sub class="note-yuan">一法</sub></span>  
<span style="margin-left: 1em">凡立天象多用四分圜爲周天四象限故造法不可不</span>  
<span style="margin-left: 5em">準如有甲乙丙圜求四平分先以前法作甲</span>  
<span style="margin-left: 5em">乙線過戊心兩平分之次依作垂線法於戊</span>  
<span style="margin-left: 5em">心上自丙至丁作垂線得所求</span>  
<span style="margin-left: 2em">有圜求六平分之章第六<sub class="note-yuan">一法</sub></span>  
<span style="margin-left: 5em">凡曆家分周天度多用六數或十二或二十</span>  
<span style="margin-left: 5em">四今詳其法如有一圜求作六分不用他法</span>  
<span style="margin-left: 5em">惟以畫圜之元規周圜界六步則自然分爲</span>  
<span style="margin-left: 1em">甲乙丙丁戊己六平分矣</span>  
<span style="margin-left: 2em">有圜求十二平分之章第七<sub class="note-yuan">一法</sub></span>  
<span style="margin-left: 1em">先以本卷五章法四平分於甲乙丙丁次以畫圜元規</span>  
<span style="margin-left: 5em">從甲從乙上下各指一點又從丙從丁左右</span>  
<span style="margin-left: 5em">各指一點則得所求若欲二十四分每分爲</span>  
<span style="margin-left: 5em">兩則得所求矣</span>  
<span style="margin-left: 2em">有圜求三百六十平分之章第八<sub class="note-yuan">一法</sub></span>  
<span style="margin-left: 9em">凡曆家所用細分周天度以三百</span>  
<span style="margin-left: 9em">六十爲率今詳其法</span>  
<span style="margin-left: 9em">如有甲乙丙圜先依前法四平分</span>  
<span style="margin-left: 9em">之爲四象限次以規元度依前法</span>  
<span style="margin-left: 9em">十二平分爲十二宮就以所分十</span>  
<span style="margin-left: 9em">二宮各三分之各包十度次每十</span>  
<span style="margin-left: 1em">兩平分之各包五次每宮又五平分之各包六今用六</span>  
<span style="margin-left: 1em">度之規至終不改從子宮初一度步起完一周又次從</span>  
<span style="margin-left: 1em">初五度初十度十五度二十度二十五度各步完一周</span>  
<span style="margin-left: 1em">則平分三百六十分矣</span>  
<span style="margin-left: 2em">有圜之分任截幾度章第九<sub class="note-yuan">一法</sub></span>  
<span style="margin-left: 7em">如有甲乙圜之一分欲取三十五度如</span>  
<span style="margin-left: 7em">用常法必須先求圜分之心依後十一</span>  
<span style="margin-left: 7em">章法成圜後均分三百六十乃取三百</span>  
<span style="margin-left: 7em">六十之三十五分其法頗繁今有簡妙</span>  
<span style="margin-left: 1em">法先備一銅板分一子丑寅象限爲九十分合極準設</span>  
<span style="margin-left: 7em">有甲乙圜之界自甲起欲取三十五度</span>  
<span style="margin-left: 7em">之分先從甲至圜心作甲丙半徑線如</span>  
<span style="margin-left: 7em">與子丑寅象限半徑合則移彼度子卯</span>  
<span style="margin-left: 7em">至甲乙線上至庚即得所求如大小不</span>  
<span style="margin-left: 1em">合則以規取子丑寅半徑以丙爲心或甲乙內或外作</span>  
<span style="margin-left: 1em">一圜分若丁戊圜在外則當引長甲丙線至丁取子丑</span>  
<span style="margin-left: 1em">寅限三十五度以丁爲始移於丁戊圜上至己從丙心</span>  
<span style="margin-left: 1em">過己作一直線截甲乙於庚則甲庚爲甲乙圜上三百</span>  
<span style="margin-left: 1em">六十分之三十五也若所範銅板欲其用廣當從寅心</span>  
<span style="margin-left: 1em">重重作圜與子丑平行又自子丑外圜逐度引直線至</span>  
<span style="margin-left: 1em">寅心後所欲取圜分之度若其半徑與子寅不等或同</span>  
<span style="margin-left: 1em">於他子丑內圜之半徑則可徑移其度於所分圜上不</span>  
<span style="margin-left: 1em">爾仍用前法</span>  
<span style="margin-left: 2em">有圜求尋其心章第十<sub class="note-yuan">一法</sub></span>  
<span style="margin-left: 5em">如有甲乙丙丁圜欲求其心先於圜之兩界</span>  
<span style="margin-left: 5em">任作一戊己直線次以平分線法作丙丁垂</span>  
<span style="margin-left: 5em">線兩平分之於庚則庚爲圜心</span>  
<span style="margin-left: 2em">有圜之分求成圜章第十一<sub class="note-yuan">一法</sub></span>  
<span style="margin-left: 1em">如有甲乙丙圜分求成圜先於圜分任取三點於甲於</span>  
<span style="margin-left: 1em">乙於丙從甲至丙丙至乙各作一直線各兩平分於丁</span>  
<span style="margin-left: 5em">於戊次於丁戊上各作垂線相交處爲己末</span>  
<span style="margin-left: 5em">以己爲心以圜爲界旋轉即得所求</span>  
<span style="margin-left: 2em">任設三點不在一直線求作一過三點之圜章第十</span>  
<span style="margin-left: 3em">二<sub class="note-yuan">法有二</sub></span>  
<span style="margin-left: 3em">第一法</span>  
<span style="margin-left: 1em">如有甲乙丙三點求作一圜貫之先以甲爲心任取一</span>  
<span style="margin-left: 5em">度向乙上下各作小圜分又以乙爲心向甲</span>  
<span style="margin-left: 5em">仍用元度上下各作小圜分相交處爲丁爲</span>  
<span style="margin-left: 5em">戊次又以甲爲心向丙上下作小圜分如前</span>  
<span style="margin-left: 1em">次以丙爲心亦如之相交處爲己爲庚次從丁至戊從</span>  
<span style="margin-left: 1em">己至庚各作直線相交處爲辛末以辛爲心任取一點</span>  
<span style="margin-left: 1em">爲界旋規成圜即得所求</span>  
<span style="margin-left: 3em">第二法</span>
