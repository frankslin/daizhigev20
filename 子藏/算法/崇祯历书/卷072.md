## 崇祯历书卷之七十二　五纬历指卷七

<span style="margin-left: 1em">五纬纬行历指叙目</span>  
<span style="margin-left: 1em">太阳乃万曜之君其所行之道为直道凡天上诸星悉</span>  
<span style="margin-left: 2em">繇以定其行左右距太阳之道谓之纬而土木火金</span>  
<span style="margin-left: 2em">水五星常在太阳之左右<sub class="note-jiao">校：常原作嘗泰昌之諱也今校正</sub>不能直</span>  
<span style="margin-left: 2em">行故名曰五纬</span>  
<span style="margin-left: 2em">太阴之行亦斜交太阳之道竝可名纬古测未觉月</span>  
<span style="margin-left: 2em">亦有纬南北二行直谓之离然其南北之离比五星</span>  
<span style="margin-left: 2em">更纯无多纬之杂其差甚微故仍其名也</span>  
<span style="margin-left: 1em">历家非以定日月之行为足又须兼齐五纬而七政始</span>  
<span style="margin-left: 2em">全其五星经行业详著各历指然以明理适用则某</span>  
<span style="margin-left: 2em">星随时所在躔次及某时应会某星并同某星出入</span>  
<span style="margin-left: 2em">与凌犯近远见伏诸类必明晰详尽始全其学若不</span>  
<span style="margin-left: 2em">知纬行南北多寡无从得其准故第谷名士深心攷</span>  
<span style="margin-left: 2em">究制为多仪密测密算定其进退之两限南北之距</span>  
<span style="margin-left: 2em">度立为成表皆务得各星之真路本道之行限详解</span>  
<span style="margin-left: 2em">纬图盖以止晰经行不能全定其处也</span>  
<span style="margin-left: 1em">新历按古今历家两测之论以明五星纬行之理各有</span>  
<span style="margin-left: 2em">数端其一为本天轮其一为岁圈轮此二根五星皆</span>  
<span style="margin-left: 2em">同若夫金水别有纬行之根异于土木共著论八条</span>

<span style="margin-left: 2em">古测纬行<sub class="note-yuan">第一章</sub></span>  
<span style="margin-left: 1em">王宝翰<sub class="note-yuan">距今百五十年</sub>曰五星纬行前古未有识者迄多禄某</span>  
<span style="margin-left: 2em">始觉其理而明其法测验功深乃得立成而布算<sub class="note-yuan">前人</sub></span>  
<span style="margin-left: 2em">但以经度为本未觉纬行之所以然多禄某密测精求因几何原本等书<sub class="note-jiao">校：幾何原本原作幾何元本今</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">校正〕以定星行之率始得纬道立成诸法</sub></span>  
<span style="margin-left: 1em">一觉五星之纬各有天半周恒纬黄道南有半周恒纬</span>  
<span style="margin-left: 2em">黄道北</span>  
<span style="margin-left: 1em">一觉此南北之交处非一时六宫在南六宫在北或时</span>  
<span style="margin-left: 2em">七宫南五宫北盖此南北之行非繇视行以所测视</span>  
<span style="margin-left: 2em">行求实行末得各星黄道某宫度以实行到此或南</span>  
<span style="margin-left: 2em">变北或北变南</span>  
<span style="margin-left: 1em">三测各星极大纬而得其距交度约三宫曰星所行非</span>  
<span style="margin-left: 2em">黄道乃各星有本道而斜交于黄道再测得土木二</span>  
<span style="margin-left: 2em">星凡近寿星宫火星近鹑火宫者皆距黄道北极大</span>  
<span style="margin-left: 2em">纬度若三星在其冲之处<sub class="note-yuan">土木为降娄宫火星为玄枵宫</sub>则距黄道</span>  
<span style="margin-left: 2em">更南</span>  
<span style="margin-left: 1em">四用本图不同心圈及小轮择各星在南北大纬或在</span>  
<span style="margin-left: 2em">极近合伏太阳之处<sub class="note-yuan">凡星在岁轮极远者其心会合太阳不能窥测惟越前后多日</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">方得其准</sub>或在极近冲日之处或在中距迟留之近处各</span>  
<span style="margin-left: 2em">有异相比测未得星在极近加本纬之度数<sub class="note-yuan">本纬乃从本道</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">加加纬度繇于岁轮下平加纬上半减纬</sub>在极远减本纬之度数若在中</span>  
<span style="margin-left: 2em">距者无大差所云加纬度者如在近处星道向南则</span>  
<span style="margin-left: 2em">加南纬向北则加北纬详见下文</span>  
<span style="margin-left: 1em">细究纬形之故古者借图形解之曰日月五星之本行</span>  
<span style="margin-left: 2em">更顺更平各有全圈各圈置一平面盖圈者乃圆形</span>  
<span style="margin-left: 2em">之外周而面者乃圆形外周内所容之积也不曰积</span>  
<span style="margin-left: 2em">而曰面者以积有厚之形面乃无厚之形也<sub class="note-yuan">见几何界说</sub></span>  
<span style="margin-left: 2em">凡曰黄道白道相交宜想两圆形相容相割如东西</span>  
<span style="margin-left: 2em">两堵墙相遇不止而过此两面相割之处为一直线</span>  
<span style="margin-left: 2em">如黄赤两道以春秋两分之一线上割之两分谓之</span>  
<span style="margin-left: 2em">两道之交即两面相割之限五星本道及小轮相交</span>  
<span style="margin-left: 2em">各圈之面相割若以楮为圈之像可明其理</span>  
<span style="margin-left: 1em">一系置多禄某所言各星有本道之面及小轮之面曰</span>  
<span style="margin-left: 2em">凡年岁小轮之径线<sub class="note-yuan">从人目过小轮之心则近远两处之线</sub>全在黄道</span>  
<span style="margin-left: 2em">之外而不相割相交凡负小轮圈在黄道或南或北</span>  
<span style="margin-left: 2em">则小轮全体亦在或南或北</span>  
<span style="margin-left: 1em">二系见星纬黄道或南或北则知星之本道交于黄道</span>  
<span style="margin-left: 2em">今见小轮或加或减本道之纬必小轮交于本轮两</span>  
<span style="margin-left: 2em">面相割不则在一平面何能置其加减乎</span>  
<span style="margin-left: 2em">又五星之纬古来未有名界即借太阴用之凡各星</span>  
<span style="margin-left: 2em">本道纬向北者谓之阴历向南者谓之阳历从南往</span>  
<span style="margin-left: 2em">北之交谓正交从北往南谓中交凡小轮在其近半</span>  
<span style="margin-left: 2em">周者谓之外盖恒向黄道本道之外而加凡在其远</span>  
<span style="margin-left: 2em">半周者谓之内盖恒在黄道本道之中而减</span>  
<span style="margin-left: 2em">又择小轮心<sub class="note-yuan">即算时所得实行</sub>在黄道本道两交之上及星</span>  
<span style="margin-left: 2em">距日天周四之一<sub class="note-yuan">如其时星在小轮近远之中</sub>测得星在黄道下</span>  
<span style="margin-left: 2em">则无纬度分又凡小轮心在黄道下各星在小轮上</span>  
<span style="margin-left: 2em">不拘度分<sub class="note-yuan">于太阳或近或远</sub>星恒不见纬度</span>  
<span style="margin-left: 1em">三系小轮心在交上无纬度者其平面与黄道平面相</span>  
<span style="margin-left: 2em">合为一</span>  
<span style="margin-left: 2em">多禄某曰土木火三星本天<sub class="note-yuan">即不同心圈</sub>之面斜割黄道</span>  
<span style="margin-left: 2em">面可定其斜交之角<sub class="note-yuan">如赤黄二道斜相割其交角为二十三度半</sub>又曰割</span>  
<span style="margin-left: 2em">小轮面而交本天为不定之角其小轮近远两限中</span>  
<span style="margin-left: 2em">有一直线于近远线在两交之中为直角与在交上</span>  
<span style="margin-left: 2em">相合为一乃于两交线恒为平行分小轮上下两平</span>  
<span style="margin-left: 2em">分此线当小轮之枢因之转动其上半极远之点若</span>  
<span style="margin-left: 2em">在黄道北则在本道南若在黄道南则在本道北盖</span>  
<span style="margin-left: 2em">小轮恒于黄道为平行面故也</span>  
<span style="margin-left: 2em">黄道本道交角<sub class="note-yuan">第二章</sub></span>  
<span style="margin-left: 1em">黄道星道两平面相割一直线上<sub class="note-yuan">面割交面生一线如线交线生一点名曰</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">交点点之两端生四角相对相等而两面亦生相交割一直线亦生四角等</sub>曰同交线此</span>  
<span style="margin-left: 2em">线通黄道之心即地心也</span>  
<span style="margin-left: 1em">系交线割星道面不平分盖星道不过黄道之心不同</span>  
<span style="margin-left: 2em">心圈故也其大半<sub class="note-yuan">六宫以上</sub>向北其小半<sub class="note-yuan">六宫以下</sub>向南大半</span>  
<span style="margin-left: 2em">在北则北纬比南纬更大</span>  
<span style="margin-left: 1em">如图丁地心作丙乙戊甲黄道圈<sub class="note-yuan">圈或面互用</sub>又任取己为</span>  
<span style="margin-left: 2em">某星天之心作庚甲壬乙圈又作甲丁乙同交线分</span>  
<span style="margin-left: 2em">黄道为平分分星道则任分</span>  
<span style="margin-left: 2em">多禄某曰此交线以异角交各天两心之线今如法</span>  
<span style="margin-left: 2em">土星两心线<sub class="note-yuan">即最高</sub>在析木宫二十七度六分<sub class="note-yuan">甲子年所算为</sub></span>

<span style="margin-left: 2em">甚锐者两任分之较更小如木星本天交线上之弧</span>
