## 崇禎曆書卷之七十二　五緯歷指卷七

<span style="margin-left: 1em">五緯緯行曆指敘目</span>  
<span style="margin-left: 1em">太陽乃萬曜之君其所行之道爲直道凡天上諸星悉</span>  
<span style="margin-left: 2em">繇以定其行左右距太陽之道謂之緯而土木火金</span>  
<span style="margin-left: 2em">水五星常在太陽之左右<sub class="note-jiao">校：常原作嘗泰昌之諱也今校正</sub>不能直</span>  
<span style="margin-left: 2em">行故名曰五緯</span>  
<span style="margin-left: 2em">太陰之行亦斜交太陽之道竝可名緯古測未覺月</span>  
<span style="margin-left: 2em">亦有緯南北二行直謂之離然其南北之離比五星</span>  
<span style="margin-left: 2em">更純無多緯之雜其差甚微故仍其名也</span>  
<span style="margin-left: 1em">曆家非以定日月之行爲足又須兼齊五緯而七政始</span>  
<span style="margin-left: 2em">全其五星經行業詳著各曆指然以明理適用則某</span>  
<span style="margin-left: 2em">星随時所在躔次及某時應會某星并同某星出入</span>  
<span style="margin-left: 2em">與凌犯近遠見伏諸類必明晰詳盡始全其學若不</span>  
<span style="margin-left: 2em">知緯行南北多寡無從得其準故第谷名士深心攷</span>  
<span style="margin-left: 2em">究制爲多儀密測密算定其進退之兩限南北之距</span>  
<span style="margin-left: 2em">度立爲成表皆務得各星之真路本道之行限詳解</span>  
<span style="margin-left: 2em">緯圖蓋以止晰經行不能全定其處也</span>  
<span style="margin-left: 1em">新曆按古今曆家兩測之論以明五星緯行之理各有</span>  
<span style="margin-left: 2em">數端其一爲本天輪其一爲歲圈輪此二根五星皆</span>  
<span style="margin-left: 2em">同若夫金水別有緯行之根異于土木共著論八條</span>

<span style="margin-left: 2em">古測緯行<sub class="note-yuan">第一章</sub></span>  
<span style="margin-left: 1em">王寶翰<sub class="note-yuan">距今百五十年</sub>曰五星緯行前古未有識者迄多祿某</span>  
<span style="margin-left: 2em">始覺其理而明其法測驗功深乃得立成而布算<sub class="note-yuan">前人</sub></span>  
<span style="margin-left: 2em">但以經度爲本未覺緯行之所以然多祿某密測精求因幾何原本等書<sub class="note-jiao">校：幾何原本原作幾何元本今</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">校正〕以定星行之率始得緯道立成諸法</sub></span>  
<span style="margin-left: 1em">一覺五星之緯各有天半周恆緯黃道南有半周恆緯</span>  
<span style="margin-left: 2em">黃道北</span>  
<span style="margin-left: 1em">一覺此南北之交處非一時六宮在南六宮在北或時</span>  
<span style="margin-left: 2em">七宮南五宮北蓋此南北之行非繇視行以所測視</span>  
<span style="margin-left: 2em">行求實行末得各星黃道某宮度以實行到此或南</span>  
<span style="margin-left: 2em">變北或北變南</span>  
<span style="margin-left: 1em">三測各星極大緯而得其距交度約三宮曰星所行非</span>  
<span style="margin-left: 2em">黃道乃各星有本道而斜交于黃道再測得土木二</span>  
<span style="margin-left: 2em">星凡近壽星宮火星近鶉火宮者皆距黃道北極大</span>  
<span style="margin-left: 2em">緯度若三星在其衝之處<sub class="note-yuan">土木爲降婁宮火星爲玄枵宮</sub>則距黃道</span>  
<span style="margin-left: 2em">更南</span>  
<span style="margin-left: 1em">四用本圖不同心圈及小輪擇各星在南北大緯或在</span>  
<span style="margin-left: 2em">極近合伏太陽之處<sub class="note-yuan">凡星在歲輪極遠者其心會合太陽不能窺測惟越前後多日</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">方得其準</sub>或在極近衝日之處或在中距遲留之近處各</span>  
<span style="margin-left: 2em">有異相比測未得星在極近加本緯之度數<sub class="note-yuan">本緯乃從本道</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">加加緯度繇于歲輪下平加緯上半減緯</sub>在極遠減本緯之度數若在中</span>  
<span style="margin-left: 2em">距者無大差所云加緯度者如在近處星道向南則</span>  
<span style="margin-left: 2em">加南緯向北則加北緯詳見下文</span>  
<span style="margin-left: 1em">細究緯形之故古者借圖形解之曰日月五星之本行</span>  
<span style="margin-left: 2em">更順更平各有全圈各圈置一平面蓋圈者乃圓形</span>  
<span style="margin-left: 2em">之外周而面者乃圓形外周內所容之積也不曰積</span>  
<span style="margin-left: 2em">而曰面者以積有厚之形面乃無厚之形也<sub class="note-yuan">見幾何界說</sub></span>  
<span style="margin-left: 2em">凡曰黃道白道相交宜想兩圓形相容相割如東西</span>  
<span style="margin-left: 2em">兩堵牆相遇不止而過此兩面相割之處爲一直線</span>  
<span style="margin-left: 2em">如黃赤兩道以春秋兩分之一線上割之兩分謂之</span>  
<span style="margin-left: 2em">兩道之交即兩面相割之限五星本道及小輪相交</span>  
<span style="margin-left: 2em">各圈之面相割若以楮爲圈之像可明其理</span>  
<span style="margin-left: 1em">一系置多祿某所言各星有本道之面及小輪之面曰</span>  
<span style="margin-left: 2em">凡年歲小輪之徑線<sub class="note-yuan">從人目過小輪之心則近遠兩處之線</sub>全在黃道</span>  
<span style="margin-left: 2em">之外而不相割相交凡負小輪圈在黃道或南或北</span>  
<span style="margin-left: 2em">則小輪全體亦在或南或北</span>  
<span style="margin-left: 1em">二系見星緯黃道或南或北則知星之本道交于黃道</span>  
<span style="margin-left: 2em">今見小輪或加或減本道之緯必小輪交于本輪兩</span>  
<span style="margin-left: 2em">面相割不則在一平面何能置其加減乎</span>  
<span style="margin-left: 2em">又五星之緯古來未有名界即借太陰用之凡各星</span>  
<span style="margin-left: 2em">本道緯向北者謂之陰曆向南者謂之陽曆從南往</span>  
<span style="margin-left: 2em">北之交謂正交從北往南謂中交凡小輪在其近半</span>  
<span style="margin-left: 2em">周者謂之外蓋恆向黃道本道之外而加凡在其遠</span>  
<span style="margin-left: 2em">半周者謂之內蓋恆在黃道本道之中而減</span>  
<span style="margin-left: 2em">又擇小輪心<sub class="note-yuan">即算時所得實行</sub>在黃道本道兩交之上及星</span>  
<span style="margin-left: 2em">距日天周四之一<sub class="note-yuan">如其時星在小輪近遠之中</sub>測得星在黃道下</span>  
<span style="margin-left: 2em">則無緯度分又凡小輪心在黃道下各星在小輪上</span>  
<span style="margin-left: 2em">不拘度分<sub class="note-yuan">于太陽或近或遠</sub>星恆不見緯度</span>  
<span style="margin-left: 1em">三系小輪心在交上無緯度者其平面與黃道平面相</span>  
<span style="margin-left: 2em">合爲一</span>  
<span style="margin-left: 2em">多祿某曰土木火三星本天<sub class="note-yuan">即不同心圈</sub>之面斜割黃道</span>  
<span style="margin-left: 2em">面可定其斜交之角<sub class="note-yuan">如赤黃二道斜相割其交角爲二十三度半</sub>又曰割</span>  
<span style="margin-left: 2em">小輪面而交本天爲不定之角其小輪近遠兩限中</span>  
<span style="margin-left: 2em">有一直線于近遠線在兩交之中爲直角與在交上</span>  
<span style="margin-left: 2em">相合爲一乃于兩交線恆爲平行分小輪上下兩平</span>  
<span style="margin-left: 2em">分此線當小輪之樞因之轉動其上半極遠之點若</span>  
<span style="margin-left: 2em">在黃道北則在本道南若在黃道南則在本道北蓋</span>  
<span style="margin-left: 2em">小輪恆于黃道爲平行面故也</span>  
<span style="margin-left: 2em">黃道本道交角<sub class="note-yuan">第二章</sub></span>  
<span style="margin-left: 1em">黃道星道兩平面相割一直線上<sub class="note-yuan">面割交面生一線如線交線生一點名曰</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">交點點之兩端生四角相對相等而兩面亦生相交割一直線亦生四角等</sub>曰同交線此</span>  
<span style="margin-left: 2em">線通黃道之心即地心也</span>  
<span style="margin-left: 1em">系交線割星道面不平分蓋星道不過黃道之心不同</span>  
<span style="margin-left: 2em">心圈故也其大半<sub class="note-yuan">六宮以上</sub>向北其小半<sub class="note-yuan">六宮以下</sub>向南大半</span>  
<span style="margin-left: 2em">在北則北緯比南緯更大</span>  
<span style="margin-left: 1em">如圖丁地心作丙乙戊甲黃道圈<sub class="note-yuan">圈或面互用</sub>又任取己爲</span>  
<span style="margin-left: 2em">某星天之心作庚甲壬乙圈又作甲丁乙同交線分</span>  
<span style="margin-left: 2em">黃道爲平分分星道則任分</span>  
<span style="margin-left: 2em">多祿某曰此交線以異角交各天兩心之線今如法</span>  
<span style="margin-left: 2em">土星兩心線<sub class="note-yuan">即最高</sub>在析木宮二十七度六分<sub class="note-yuan">甲子年所算爲</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">曆元之本見本表</sub>其正交在鶉首宮二十度三十九分相距</span>  
<span style="margin-left: 2em">一百六十五度二十七分中交在其衝</span>  
<span style="margin-left: 2em">木星最高在壽星宮八度五十四分其正交在鶉首</span>  
<span style="margin-left: 2em">七度八分相距爲八十九度十四分中交在其衝</span>  
<span style="margin-left: 2em">火星最高在鶉火宮二十九度二十六分其正交在</span>  
<span style="margin-left: 2em">大梁宮一十七度相距一百〇二度二十六分中交</span>  
<span style="margin-left: 2em">在其衝</span>  
<span style="margin-left: 2em">金星正交在本天最高前十六度此時在實沈宮十</span>  
<span style="margin-left: 2em">四度<sub class="note-yuan">金水二星差數微免繪圖</sub></span>  
<span style="margin-left: 2em">水星正交于最高爲一此時在析木宮一度</span>  
<span style="margin-left: 1em">系因圖可見各星交線之異任分本天凡兩心線及交</span>  
<span style="margin-left: 2em">線之交角近于直角者其兩任分之較更大若交角</span>  
<span style="margin-left: 2em">甚銳者兩任分之較更小如木星本天交線上之弧</span>  
<span style="margin-left: 2em">比土星交線上之弧更大觀圖可見</span>  
<span style="margin-left: 1em">二系各星本行<sub class="note-yuan">即平行</sub>時行周天向北之弧比行南弧更</span>  
<span style="margin-left: 2em">多弧之多寡與行時多寡相應故也</span>  
<span style="margin-left: 1em">問南北兩弧若干曰用上各星之圖從己至正交中交</span>  
<span style="margin-left: 2em">兩處作線成己丁正己丁中兩形夫形爲加減均數</span>  
<span style="margin-left: 7em">之形以視行角己丁中求平行角丁己</span>  
<span style="margin-left: 7em">中之餘即高中弧之度用加減表求之</span>  
<span style="margin-left: 7em">相并得土星北弧勝南弧爲五度二十</span>  
<span style="margin-left: 7em">分木星北弧勝南弧爲五度五十四分</span>  
<span style="margin-left: 2em">火星北弧勝南弧爲二十一度五十六分</span>  
<span style="margin-left: 1em">依上多祿某所定黃道本道正交中交之角上見星在</span>  
<span style="margin-left: 2em">此恆無緯度又緯類從此變或以南往北或自北往</span>  
<span style="margin-left: 2em">南取星在兩交之中測其緯得上三星凡在小輪極</span>  
<span style="margin-left: 2em">遠者緯度少在小輪近者緯度多以多寡之較求小</span>  
<span style="margin-left: 2em">輪之心或本道距黃道若干得數如左</span>  
<span style="margin-left: 1em">土星本道交黃道角<sub class="note-yuan">或一圓球上兩大圈相交之角或兩道之平面相割各用之</sub>爲</span>  
<span style="margin-left: 2em">二度一十六分<sub class="note-jiao">校：文淵本此作二度二十六分</sub>小輪平面割本天面</span>  
<span style="margin-left: 2em">交角小輪在兩交之中爲四度半凡在正交或中交</span>  
<span style="margin-left: 2em">之上者交角爲二度一十六分<sub class="note-jiao">校：同前條</sub>乃兩道之角也</span>  
<span style="margin-left: 1em">星木道交黃道角爲一度二十四分小輪交本道爲二</span>  
<span style="margin-left: 2em">度三十分</span>  
<span style="margin-left: 1em">火星本天交黃道角爲一度二十四分小輪交本天爲</span>  
<span style="margin-left: 2em">二度十一分</span>  
<span style="margin-left: 1em">依上論小輪高庳則視緯有多寡如加減表凡引數在</span>  
<span style="margin-left: 2em">高者均數少在低者均數多如圖<sub class="note-yuan">依視法凡對周看一平面或圜形者</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">所見之形爲一直線如簡平儀諸線爲直線即當圜形曲線今兩道及小輪各對周看成直線兩線交角</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">當兩面之交角</sub>丁地心戊丁亥線當黃道己爲某星天之心</span>  
<span style="margin-left: 10em">作庚己壬線當某星本道置庚</span>  
<span style="margin-left: 10em">丁戊角爲兩道交角<sub class="note-yuan">數見上</sub>又從</span>  
<span style="margin-left: 10em">己心取己庚己壬等線壬庚爲</span>  
<span style="margin-left: 2em">小輪心作午庚未乙壬甲兩線于黃道平行亦兩線</span>  
<span style="margin-left: 2em">相等未庚己爲小輪及本天之交角上下無二從丁</span>  
<span style="margin-left: 2em"><sub class="note-yuan">人目所在</sub>作丁甲丁未視線定高庳兩處未丁戊甲丁亥</span>  
<span style="margin-left: 2em">兩緯角題言在最高未丁戊角爲小在高衝甲丁亥</span>  
<span style="margin-left: 2em">角爲大甲壬丁庚丁未兩形各有等底甲壬庚未又</span>  
<span style="margin-left: 2em">有壬庚兩角等庚丁邊比壬丁邊更大則其對角未</span>
