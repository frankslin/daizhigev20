<span style="margin-left: 1em">远镜说自序</span>  
<span style="margin-left: 2em">人身五司耳目为贵无疑也耳与目又孰为贵乎昔</span>  
<span style="margin-left: 2em">亚利斯多称耳司为百学之母谓凡授受以耳学问</span>  
<span style="margin-left: 2em">所以弥精弥广也若目司则巴拉多称为理学之师</span>  
<span style="margin-left: 2em">何者盖当其陡与物遇见其然即索其所以然由粗</span>  
<span style="margin-left: 2em">入细由有形入无形理学始终总目为牖矣而不宁</span>  
<span style="margin-left: 2em">惟是明光色光较形声臭味独居上分不既属于目</span>  
<span style="margin-left: 2em">乎观夫亚尼玛以目为居止孟子谓存乎人者莫良</span>  
<span style="margin-left: 2em">于眸子则凡情开意动之微必达于目善恶莫掩有</span>  
<span style="margin-left: 2em">如执左契然者且耳之于声也有待目之于形也无</span>  
<span style="margin-left: 2em">待闻每后见每先闻每似见每真闻仅有轻重清浊</span>  
<span style="margin-left: 2em">见岂特玄黄采素而已哉物体有大小方圆邪正动</span>  
<span style="margin-left: 2em">静数有多寡位有远近畴非于目辨者乎诚若是则</span>  
<span style="margin-left: 2em">目之贵于耳也明矣虽然耳目皆不可废者也则佐</span>  
<span style="margin-left: 2em">耳佐目之法亦皆不可废者也第佐耳者用力省以</span>  
<span style="margin-left: 2em">管则远以螺则清利物出于天成其巧妙自无可得</span>  
<span style="margin-left: 2em">而言佐目者用力烦管以为眶镜以为睛利物出于</span>  
<span style="margin-left: 2em">人力其巧妙诚有可得而言者无可得而言者言之</span>  
<span style="margin-left: 2em">则诞有可得而言者秘之则欺此远镜说之所由述</span>  
<span style="margin-left: 2em">也</span>

<span style="margin-left: 14em">后学李祖白订</span>  
<span style="margin-left: 1em"><sub class="note-jiao">校：清刊本改爲西洋湯若望著且刪後學李祖白訂六字</sub></span>  
<span style="margin-left: 3em">利用<sub class="note-yuan">计二端</sub></span>  
<span style="margin-left: 1em">夫远镜何昉乎昉于大西洋天文士也其用之利可胜</span>  
<span style="margin-left: 1em">言哉盖凡人视近与大易视远与小难远镜则无远近</span>  
<span style="margin-left: 1em">无大小者也约畧言之天象地形不出其照而至若山</span>  
<span style="margin-left: 1em">海之间尤为备盗之先资补益人世亦大矣奈何忽为</span>  
<span style="margin-left: 1em">悦目快心之具也今试姑举一二以概其用</span>  
<span style="margin-left: 2em">一利用于仰观<sub class="note-yuan">计六条</sub></span>  
<span style="margin-left: 9em">用以观太阴则见本体有凸而明</span>  
<span style="margin-left: 9em">者有凹而暗者盖如山之高处先</span>  
<span style="margin-left: 9em">得日光而明也又观月时试一目</span>  
<span style="margin-left: 9em">用镜一目不用镜则大小迥别焉</span>  
<span style="margin-left: 10em">用以观金星则见有消长有上</span>  
<span style="margin-left: 10em">弦下弦如月焉其消长上下弦</span>  
<span style="margin-left: 10em">变易于一年之间亦如月之消</span>  
<span style="margin-left: 10em">长上下弦变易于一月之内又</span>  
<span style="margin-left: 10em">见本体间或大小不一则验其</span>  
<span style="margin-left: 10em">行动周围随太阳者居太阳之</span>  
<span style="margin-left: 10em">上其光则满居太阳之下其光</span>  
<span style="margin-left: 10em">则虚本体之大小以其居太阳</span>  
<span style="margin-left: 10em">左右之上下而别焉</span>  
<span style="margin-left: 10em">用以观太阳之出没则见本体</span>  
<span style="margin-left: 10em">非至圆乃似鸡鸟卵盖因尘气</span>  
<span style="margin-left: 10em">腾空遮蒙恍惚使之然也<sub class="note-yuan">即此可知</sub></span>  
<span style="margin-left: 10em"><sub class="note-yuan">尘气腾空高远几许</sub>若卯酉二时并见太</span>  
<span style="margin-left: 10em">阳边体龃龉如锯齿日面有浮</span>  
<span style="margin-left: 10em">游黑点点大小多寡不一相为</span>  
<span style="margin-left: 10em">隐显随从必十四日方周径日</span>  
<span style="margin-left: 10em">面而出前点出后点入迄无定</span>  
<span style="margin-left: 10em">期竟不解其何故也</span>  
<span style="margin-left: 10em">用以观木星则见有四小星左</span>  
<span style="margin-left: 10em">右随从护卫木君者四星随木</span>  
<span style="margin-left: 10em">有规则有定期又有蚀时则非</span>  
<span style="margin-left: 10em">宿天之星明矣欲知其与木近</span>  
<span style="margin-left: 10em">远几何宜先究其经道圈处合</span>  
<span style="margin-left: 10em">下即验矣</span>  
<span style="margin-left: 10em">用以观土星则见两傍有两小</span>  
<span style="margin-left: 10em">星经久渐益近土竟合而为一</span>  
<span style="margin-left: 10em">如卵两头有二耳焉</span>  
<span style="margin-left: 10em">用以观宿天诸星较之平时不</span>  
<span style="margin-left: 10em">啻多数十倍而且界限甚明也</span>  
<span style="margin-left: 10em">即如昴宿数不止于七而有三</span>  
<span style="margin-left: 10em">十多鬼宿中积尸气觜宿中北</span>  
<span style="margin-left: 10em">星天河中诸小星皆难见者用</span>  
<span style="margin-left: 10em">镜则了然矣又如尾宿中距星</span>  
<span style="margin-left: 10em">及神宫北斗中开阳及辅星皆</span>  
<span style="margin-left: 10em">难分者用镜则见相去甚远焉</span>  
<span style="margin-left: 10em">是宿天诸星借镜验之算之相</span>  
<span style="margin-left: 10em">去几何丝毫不爽因之而观察</span>  
<span style="margin-left: 1em">星宿本相星宿所好星宿正度偏度于修历法尤为切</span>  
<span style="margin-left: 1em">要以上六条是聊述观天之槩也</span>  
<span style="margin-left: 2em">一利用于直视<sub class="note-yuan">计三条</sub></span>  
<span style="margin-left: 1em">楼台高处用之则远见山川江河树林村落虽人物行</span>  
<span style="margin-left: 1em">动如在目前若陡遇兵革之变无论白日即深夜借彼</span>  
<span style="margin-left: 1em">火光用之则远见敌处营帐人马器械辎重便知其备</span>  
<span style="margin-left: 1em">不备而我得预为防宜战宜守或宜安放铳砲功莫大</span>  
<span style="margin-left: 1em">焉</span>  
<span style="margin-left: 1em">海上用之则数十里外之行舟人但见为块然如山石</span>  
<span style="margin-left: 1em">者我能别其船舟何等帆旗何色或为友伴或为强徒</span>  
<span style="margin-left: 1em">与夫人数之多寡悉无谬焉</span>  
<span style="margin-left: 1em">居室中用之则照见诸远物其体其色活泼泼地各现</span>  
<span style="margin-left: 1em">本相大西洋有一画士秘用此法画种种物像俨然如</span>  
<span style="margin-left: 1em">生举国奇之以上三条是聊述地海人间之槩也</span>  
<span style="margin-left: 3em">附分用之利<sub class="note-yuan">计三端</sub></span>  
<span style="margin-left: 1em">夫远镜者二镜合之以成器者也其利用既如斯矣乃</span>  
<span style="margin-left: 1em">分之而制造如法则又各利于用焉即中国所谓眼镜</span>  
<span style="margin-left: 1em">也试言之</span>  
<span style="margin-left: 9em">一利于苦近视者用之<sub class="note-yuan">一条</sub></span>  
<span style="margin-left: 8em">世有自少好远游喜远望者年老目</span>  
<span style="margin-left: 8em">衰则不苦视远物而苦视近物不耐</span>  
<span style="margin-left: 8em">三角形射线而耐平行射线习性使</span>  
<span style="margin-left: 8em">然耳若用远镜之中高镜则物象一</span>  
<span style="margin-left: 8em">点之小散射镜面从镜平行入目巧</span>  
<span style="margin-left: 8em">合其习性视近不劳而自明也然又</span>  
<span style="margin-left: 8em">有未尝好远游远望而平日专务平</span>  
<span style="margin-left: 8em">直是视者亦必老至力衰则视物不</span>  
<span style="margin-left: 8em">能敛聚其象象形直射恍惚不真若</span>  
<span style="margin-left: 8em">用中高镜则物形虽小而暗视之自</span>  
<span style="margin-left: 8em">大而显矣</span>  
<span style="margin-left: 9em">一利于苦远视者用之<sub class="note-yuan">一条</sub></span>  
<span style="margin-left: 8em">有书生目不去书史视不逾几席习</span>  
<span style="margin-left: 8em">惯成性喜三角形视近不耐平行视</span>  
<span style="margin-left: 8em">远者亦有非繇习惯但眸子精力不</span>  
<span style="margin-left: 8em">开广视物象不得员而满者是二人</span>  
<span style="margin-left: 8em">者用远镜之中洼镜则物象从镜角</span>  
<span style="margin-left: 8em">形入目乃合其习性视物自明矣</span>  
<span style="margin-left: 9em">一分用不如合用之无不利<sub class="note-yuan">一条</sub></span>  
<span style="margin-left: 8em">人有目精全衰视物全暗者则与无</span>  
<span style="margin-left: 8em">目同天日不能照固非镜之所能与</span>  
<span style="margin-left: 8em">力也乃有目精至强视物至明者用</span>  
<span style="margin-left: 8em">镜亦反加翳焉何也吾人睛中有眸</span>  
<span style="margin-left: 8em">张闭自宜睛底有屈伸如性高洼二</span>  
<span style="margin-left: 8em">镜自备目中何以镜为若二镜合用</span>  
<span style="margin-left: 8em">之于远镜则不然远镜者目明益明</span>  
<span style="margin-left: 8em">象显益显实备非常之用者也</span>  
<span style="margin-left: 3em">原繇<sub class="note-yuan">计三端</sub></span>  
<span style="margin-left: 2em">一易象不同而远镜独妙于斜透以为利用之原<sub class="note-yuan">计</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">三条</sub></span>  
<span style="margin-left: 1em">是镜之妙妙乎能易物象也何谓易象盖凡物之有形</span>  
<span style="margin-left: 1em">者必发越本象于空明中以射人目若象目交接之间</span>  
<span style="margin-left: 1em">无所阻碍则象从径线直射入目矣苟如为他物形所</span>  
<span style="margin-left: 1em">间则本象或斜透其照而易者有之或反映其照而易</span>  
<span style="margin-left: 1em">者有之乃是镜易象之妙则妙乎有斜透而无反映此</span>  
<span style="margin-left: 1em">其所以利用也</span>  
<span style="margin-left: 1em">何谓斜透而易反映而易盖象与目交而为物所间槩</span>  
<span style="margin-left: 8em">有二焉一曰不通光之体一曰通光</span>  
<span style="margin-left: 8em">之体不通光之体可借喻镜面夫镜</span>  
<span style="margin-left: 8em">有突如球平如案洼如釜之类其面</span>  
<span style="margin-left: 8em">皆能受物象而其体之不通彻皆不</span>  
<span style="margin-left: 8em">能不反映物象反映之象自不能如</span>  
<span style="margin-left: 8em">本象之光明也所谓反映者此也通</span>  
<span style="margin-left: 8em">光之体又分二体一谓物象遇大光</span>  
<span style="margin-left: 8em">明易通彻者比发象元处更光明而</span>  
<span style="margin-left: 8em">形似广而散焉一谓物象遇次光明</span>  
<span style="margin-left: 8em">难通彻者比发象元处少昏暗而形</span>  
<span style="margin-left: 8em">似敛而聚焉今试以象遇大光明易</span>  
<span style="margin-left: 8em">通彻者言之即如前图甲象居盂底</span>  
<span style="margin-left: 8em">直射乙目乙目可视乙目偏东则象</span>  
<span style="margin-left: 8em">不现而目不见碍于盂边也若充水</span>  
<span style="margin-left: 8em">齐边则象上映于水遇空明气之大</span>  
<span style="margin-left: 8em">光明即邪射而象更显焉甲象更广</span>  
<span style="margin-left: 8em">散于丙丁边东目视丙边即视丙象</span>  
<span style="margin-left: 8em">而象体似居戊处矣即东目更移东</span>  
<span style="margin-left: 8em">尚可见象而象体若更浮戊上矣是</span>  
<span style="margin-left: 8em">又因象映而然也又如舟用篙橹其</span>  
<span style="margin-left: 1em">半在水视之若曲焉张断取鱼多半在水视之若短焉</span>  
<span style="margin-left: 1em">又鱼者见鱼象浮游水面而投又刺之必欲稍下于鱼</span>  
<span style="margin-left: 1em">乃能得鱼盖水气两隔恍惚使然渔夫习之熟知其必</span>  
<span style="margin-left: 1em">然而不知其所以然耳试以象遇次光明难通彻者言</span>  
<span style="margin-left: 1em">之即如上图甲象在空明气盂底无水直射盂底乙处</span>  
<span style="margin-left: 1em">乙处可视甲象若戊处则象不射戊不见碍于盂边也</span>  
<span style="margin-left: 1em">盂内充水至于丙丁则空明甲象入水稍暗敛聚于丙</span>  
<span style="margin-left: 1em">丁边戊视丁边则明见甲象而象体似居己处矣凡此</span>  
<span style="margin-left: 1em">皆所谓斜透者也</span>  
<span style="margin-left: 1em">夫所云间隔物体大光明能广散物象次光明能敛聚</span>  
<span style="margin-left: 1em">物象盖必大与次不同体者也若前后二镜亦既同体</span>  
<span style="margin-left: 1em">矣而亦有广散敛聚之别则以同体而不同形耳前镜</span>  
<span style="margin-left: 1em">形中高类球镜而通彻焉是即次光明意也所以照日</span>  
<span style="margin-left: 1em">光能渐聚大光于一点而且照日生火照第一等星光</span>  
<span style="margin-left: 1em">能透明于纸上夜借灯光亦能远照后镜形中洼类釜</span>  
<span style="margin-left: 1em">镜而通彻焉是即大光明意也所以照日光则渐散大</span>
