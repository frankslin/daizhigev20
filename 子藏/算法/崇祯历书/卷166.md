## 崇禎曆書卷之一百六十六　遠鏡說

<span style="margin-left: 2em">立表惟以目隨內線至極爲安表之地必斜出于晷</span>

<span style="margin-left: 1em">崇禎曆書卷之一百六十六　遠鏡說</span>  
<span style="margin-left: 1em"><sub class="note-jiao">校：據奎章閣本校錄</sub></span>  
<span style="margin-left: 1em">遠鏡說自序</span>  
<span style="margin-left: 2em">人身五司耳目爲貴無疑也耳與目又孰爲貴乎昔</span>  
<span style="margin-left: 2em">亞利斯多稱耳司爲百學之母謂凡授受以耳學問</span>  
<span style="margin-left: 2em">所以彌精彌廣也若目司則巴拉多稱爲理學之師</span>  
<span style="margin-left: 2em">何者蓋當其陡與物遇見其然即索其所以然由粗</span>  
<span style="margin-left: 2em">入細由有形入無形理學始終總目爲牖矣而不寧</span>  
<span style="margin-left: 2em">惟是明光色光較形聲臭味獨居上分不既屬於目</span>  
<span style="margin-left: 2em">乎觀夫亞尼瑪以目爲居止孟子謂存乎人者莫良</span>  
<span style="margin-left: 2em">於眸子則凡情開意動之微必達於目善惡莫掩有</span>  
<span style="margin-left: 2em">如執左契然者且耳之於聲也有待目之於形也無</span>  
<span style="margin-left: 2em">待聞每後見每先聞每似見每真聞僅有輕重清濁</span>  
<span style="margin-left: 2em">見豈特玄黃采素而已哉物體有大小方圓邪正動</span>  
<span style="margin-left: 2em">靜數有多寡位有遠近疇非於目辨者乎誠若是則</span>  
<span style="margin-left: 2em">目之貴於耳也明矣雖然耳目皆不可廢者也則佐</span>  
<span style="margin-left: 2em">耳佐目之法亦皆不可廢者也第佐耳者用力省以</span>  
<span style="margin-left: 2em">管則遠以螺則清利物出於天成其巧妙自無可得</span>  
<span style="margin-left: 2em">而言佐目者用力煩管以爲眶鏡以爲睛利物出於</span>  
<span style="margin-left: 2em">人力其巧妙誠有可得而言者無可得而言者言之</span>  
<span style="margin-left: 2em">則誕有可得而言者秘之則欺此遠鏡說之所由述</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 1em">天啓六年歲次丙寅仲秋月大西洋湯若望題</span>  
<span style="margin-left: 1em">遠鏡說目</span>  
<span style="margin-left: 1em">首利用</span>  
<span style="margin-left: 2em">一利用於仰觀</span>  
<span style="margin-left: 2em">一利用於直視</span>  
<span style="margin-left: 1em">次附分用之利</span>  
<span style="margin-left: 2em">一利於苦近視者用之</span>  
<span style="margin-left: 2em">一利於苦遠視者用之</span>  
<span style="margin-left: 2em">一分用不如合用之無不利</span>  
<span style="margin-left: 1em">次原繇</span>  
<span style="margin-left: 2em">一易象不同而遠鏡獨妙於斜透以爲利用之原</span>  
<span style="margin-left: 2em">一射線不一而遠鏡兼攝乎屈曲以爲斜透之繇</span>  
<span style="margin-left: 2em">一視象明而大者繇乎二鏡之合用</span>  
<span style="margin-left: 1em">次造法用法</span>  
<span style="margin-left: 2em">一鏡</span>  
<span style="margin-left: 2em">一筒</span>  
<span style="margin-left: 2em">一遠近各得其宜</span>  
<span style="margin-left: 2em">一避眩便觀</span>  
<span style="margin-left: 2em">一安放調停</span>  
<span style="margin-left: 2em">一衰目近視用訣</span>  
<span style="margin-left: 2em">一借照作畫</span>  
<span style="margin-left: 2em">一習用訣</span>

<span style="margin-left: 2em">遠鏡說　　　　　　　　　西洋湯如望述</span>  
<span style="margin-left: 14em">後學李祖白訂</span>  
<span style="margin-left: 1em"><sub class="note-jiao">校：清刊本改爲西洋湯若望著且刪後學李祖白訂六字</sub></span>  
<span style="margin-left: 3em">利用<sub class="note-yuan">計二端</sub></span>  
<span style="margin-left: 1em">夫遠鏡何昉乎昉於大西洋天文士也其用之利可勝</span>  
<span style="margin-left: 1em">言哉蓋凡人視近與大易視遠與小難遠鏡則無遠近</span>  
<span style="margin-left: 1em">無大小者也約畧言之天象地形不出其照而至若山</span>  
<span style="margin-left: 1em">海之間尤爲備盜之先資補益人世亦大矣奈何忽爲</span>  
<span style="margin-left: 1em">悅目快心之具也今試姑舉一二以概其用</span>  
<span style="margin-left: 2em">一利用於仰觀<sub class="note-yuan">計六條</sub></span>  
<span style="margin-left: 9em">用以觀太陰則見本體有凸而明</span>  
<span style="margin-left: 9em">者有凹而暗者蓋如山之高處先</span>  
<span style="margin-left: 9em">得日光而明也又觀月時試一目</span>  
<span style="margin-left: 9em">用鏡一目不用鏡則大小迥別焉</span>  
<span style="margin-left: 10em">用以觀金星則見有消長有上</span>  
<span style="margin-left: 10em">弦下弦如月焉其消長上下弦</span>  
<span style="margin-left: 10em">變易於一年之間亦如月之消</span>  
<span style="margin-left: 10em">長上下弦變易於一月之內又</span>  
<span style="margin-left: 10em">見本體間或大小不一則驗其</span>  
<span style="margin-left: 10em">行動周圍隨太陽者居太陽之</span>  
<span style="margin-left: 10em">上其光則滿居太陽之下其光</span>  
<span style="margin-left: 10em">則虛本體之大小以其居太陽</span>  
<span style="margin-left: 10em">左右之上下而別焉</span>  
<span style="margin-left: 10em">用以觀太陽之出没則見本體</span>  
<span style="margin-left: 10em">非至圓乃似鷄鳥卵蓋因塵氣</span>  
<span style="margin-left: 10em">騰空遮蒙恍惚使之然也<sub class="note-yuan">即此可知</sub></span>  
<span style="margin-left: 10em"><sub class="note-yuan">塵氣騰空高遠幾許</sub>若卯酉二時併見太</span>  
<span style="margin-left: 10em">陽邊體齟齬如鋸齒日面有浮</span>  
<span style="margin-left: 10em">游黑點點大小多寡不一相爲</span>  
<span style="margin-left: 10em">隱顯隨從必十四日方周徑日</span>  
<span style="margin-left: 10em">面而出前點出後點入迄無定</span>  
<span style="margin-left: 10em">期竟不解其何故也</span>  
<span style="margin-left: 10em">用以觀木星則見有四小星左</span>  
<span style="margin-left: 10em">右隨從護衛木君者四星隨木</span>  
<span style="margin-left: 10em">有規則有定期又有蝕時則非</span>  
<span style="margin-left: 10em">宿天之星明矣欲知其與木近</span>  
<span style="margin-left: 10em">遠幾何宜先究其經道圈處合</span>  
<span style="margin-left: 10em">下即驗矣</span>  
<span style="margin-left: 10em">用以觀土星則見兩傍有兩小</span>  
<span style="margin-left: 10em">星經久漸益近土竟合而爲一</span>  
<span style="margin-left: 10em">如卵兩頭有二耳焉</span>  
<span style="margin-left: 10em">用以觀宿天諸星較之平時不</span>  
<span style="margin-left: 10em">啻多數十倍而且界限甚明也</span>  
<span style="margin-left: 10em">即如昴宿數不止於七而有三</span>  
<span style="margin-left: 10em">十多鬼宿中積尸氣觜宿中北</span>  
<span style="margin-left: 10em">星天河中諸小星皆難見者用</span>  
<span style="margin-left: 10em">鏡則瞭然矣又如尾宿中距星</span>  
<span style="margin-left: 10em">及神宮北斗中開陽及輔星皆</span>  
<span style="margin-left: 10em">難分者用鏡則見相去甚遠焉</span>  
<span style="margin-left: 10em">是宿天諸星借鏡驗之算之相</span>  
<span style="margin-left: 10em">去幾何絲毫不爽因之而觀察</span>  
<span style="margin-left: 1em">星宿本相星宿所好星宿正度偏度於修曆法尤爲切</span>  
<span style="margin-left: 1em">要以上六條是聊述觀天之槩也</span>  
<span style="margin-left: 2em">一利用於直視<sub class="note-yuan">計三條</sub></span>  
<span style="margin-left: 1em">樓臺高處用之則遠見山川江河樹林村落雖人物行</span>  
<span style="margin-left: 1em">動如在目前若陡遇兵革之變無論白日即深夜借彼</span>  
<span style="margin-left: 1em">火光用之則遠見敵處營帳人馬器械輜重便知其備</span>  
<span style="margin-left: 1em">不備而我得預爲防宜戰宜守或宜安放銃砲功莫大</span>  
<span style="margin-left: 1em">焉</span>  
<span style="margin-left: 1em">海上用之則數十里外之行舟人但見爲塊然如山石</span>  
<span style="margin-left: 1em">者我能別其船舟何等帆旂何色或爲友伴或爲强徒</span>  
<span style="margin-left: 1em">與夫人數之多寡悉無謬焉</span>  
<span style="margin-left: 1em">居室中用之則照見諸遠物其體其色活潑潑地各現</span>  
<span style="margin-left: 1em">本相大西洋有一畫士秘用此法畫種種物像儼然如</span>  
<span style="margin-left: 1em">生舉國奇之以上三條是聊述地海人間之槩也</span>  
<span style="margin-left: 3em">附分用之利<sub class="note-yuan">計三端</sub></span>  
<span style="margin-left: 1em">夫遠鏡者二鏡合之以成器者也其利用既如斯矣乃</span>  
<span style="margin-left: 1em">分之而製造如法則又各利於用焉即中國所謂眼鏡</span>  
<span style="margin-left: 1em">也試言之</span>  
<span style="margin-left: 9em">一利於苦近視者用之<sub class="note-yuan">一條</sub></span>  
<span style="margin-left: 8em">世有自少好遠游喜遠望者年老目</span>  
<span style="margin-left: 8em">衰則不苦視遠物而苦視近物不耐</span>  
<span style="margin-left: 8em">三角形射線而耐平行射線習性使</span>  
<span style="margin-left: 8em">然耳若用遠鏡之中高鏡則物象一</span>  
<span style="margin-left: 8em">點之小散射鏡面從鏡平行入目巧</span>  
<span style="margin-left: 8em">合其習性視近不勞而自明也然又</span>  
<span style="margin-left: 8em">有未嘗好遠遊遠望而平日專務平</span>  
<span style="margin-left: 8em">直是視者亦必老至力衰則視物不</span>  
<span style="margin-left: 8em">能斂聚其象象形直射恍惚不真若</span>  
<span style="margin-left: 8em">用中高鏡則物形雖小而暗視之自</span>  
<span style="margin-left: 8em">大而顯矣</span>  
<span style="margin-left: 9em">一利於苦遠視者用之<sub class="note-yuan">一條</sub></span>  
<span style="margin-left: 8em">有書生目不去書史視不踰几席習</span>  
<span style="margin-left: 8em">慣成性喜三角形視近不耐平行視</span>  
<span style="margin-left: 8em">遠者亦有非繇習慣但眸子精力不</span>  
<span style="margin-left: 8em">開廣視物象不得員而滿者是二人</span>  
<span style="margin-left: 8em">者用遠鏡之中窪鏡則物象從鏡角</span>  
<span style="margin-left: 8em">形入目乃合其習性視物自明矣</span>  
<span style="margin-left: 9em">一分用不如合用之無不利<sub class="note-yuan">一條</sub></span>  
<span style="margin-left: 8em">人有目精全衰視物全暗者則與無</span>  
<span style="margin-left: 8em">目同天日不能照固非鏡之所能與</span>  
<span style="margin-left: 8em">力也乃有目精至强視物至明者用</span>  
<span style="margin-left: 8em">鏡亦反加翳焉何也吾人睛中有眸</span>  
<span style="margin-left: 8em">張閉自宜睛底有屈伸如性高窪二</span>  
<span style="margin-left: 8em">鏡自備目中何以鏡爲若二鏡合用</span>  
<span style="margin-left: 8em">之于遠鏡則不然遠鏡者目明益明</span>  
<span style="margin-left: 8em">象顯益顯實備非常之用者也</span>  
<span style="margin-left: 3em">原繇<sub class="note-yuan">計三端</sub></span>  
<span style="margin-left: 2em">一易象不同而遠鏡獨妙於斜透以爲利用之原<sub class="note-yuan">計</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">三條</sub></span>  
<span style="margin-left: 1em">是鏡之妙妙乎能易物象也何謂易象蓋凡物之有形</span>  
<span style="margin-left: 1em">者必發越本象於空明中以射人目若象目交接之間</span>  
<span style="margin-left: 1em">無所阻礙則象從徑線直射入目矣苟如爲他物形所</span>  
<span style="margin-left: 1em">間則本象或斜透其照而易者有之或反映其照而易</span>  
<span style="margin-left: 1em">者有之乃是鏡易象之妙則妙乎有斜透而無反映此</span>  
<span style="margin-left: 1em">其所以利用也</span>  
<span style="margin-left: 1em">何謂斜透而易反映而易蓋象與目交而爲物所間槩</span>  
<span style="margin-left: 8em">有二焉一曰不通光之體一曰通光</span>  
<span style="margin-left: 8em">之體不通光之體可借喻鏡面夫鏡</span>  
<span style="margin-left: 8em">有突如球平如案窪如釜之類其面</span>  
<span style="margin-left: 8em">皆能受物象而其體之不通徹皆不</span>  
<span style="margin-left: 8em">能不反映物象反映之象自不能如</span>  
<span style="margin-left: 8em">本象之光明也所謂反映者此也通</span>  
<span style="margin-left: 8em">光之體又分二體一謂物象遇大光</span>  
<span style="margin-left: 8em">明易通徹者比發象元處更光明而</span>  
<span style="margin-left: 8em">形似廣而散焉一謂物象遇次光明</span>  
<span style="margin-left: 8em">難通徹者比發象元處少昏暗而形</span>  
<span style="margin-left: 8em">似斂而聚焉今試以象遇大光明易</span>  
<span style="margin-left: 8em">通徹者言之即如前圖甲象居盂底</span>  
<span style="margin-left: 8em">直射乙目乙目可視乙目偏東則象</span>  
<span style="margin-left: 8em">不現而目不見礙于盂邊也若充水</span>  
<span style="margin-left: 8em">齊邊則象上映於水遇空明氣之大</span>  
<span style="margin-left: 8em">光明即邪射而象更顯焉甲象更廣</span>  
<span style="margin-left: 8em">散於丙丁邊東目視丙邊即視丙象</span>  
<span style="margin-left: 8em">而象體似居戊處矣即東目更移東</span>  
<span style="margin-left: 8em">尚可見象而象體若更浮戊上矣是</span>  
<span style="margin-left: 8em">又因象映而然也又如舟用篙櫓其</span>  
<span style="margin-left: 1em">半在水視之若曲焉張斷取魚多半在水視之若短焉</span>  
<span style="margin-left: 1em">又魚者見魚象浮游水面而投又刺之必欲稍下於魚</span>  
<span style="margin-left: 1em">乃能得魚蓋水氣兩隔恍惚使然漁夫習之熟知其必</span>  
<span style="margin-left: 1em">然而不知其所以然耳試以象遇次光明難通徹者言</span>  
<span style="margin-left: 1em">之即如上圖甲象在空明氣盂底無水直射盂底乙處</span>  
<span style="margin-left: 1em">乙處可視甲象若戊處則象不射戊不見礙于盂邊也</span>  
<span style="margin-left: 1em">盂內充水至於丙丁則空明甲象入水稍暗斂聚於丙</span>  
<span style="margin-left: 1em">丁邊戊視丁邊則明見甲象而象體似居己處矣凡此</span>  
<span style="margin-left: 1em">皆所謂斜透者也</span>  
<span style="margin-left: 1em">夫所云間隔物體大光明能廣散物象次光明能斂聚</span>  
<span style="margin-left: 1em">物象蓋必大與次不同體者也若前後二鏡亦既同體</span>  
<span style="margin-left: 1em">矣而亦有廣散斂聚之別則以同體而不同形耳前鏡</span>  
<span style="margin-left: 1em">形中高類球鏡而通徹焉是即次光明意也所以照日</span>  
<span style="margin-left: 1em">光能漸聚大光於一點而且照日生火照第一等星光</span>  
<span style="margin-left: 1em">能透明於紙上夜借燈光亦能遠照後鏡形中窪類釜</span>  
<span style="margin-left: 1em">鏡而通徹焉是即大光明意也所以照日光則漸散大</span>  
<span style="margin-left: 1em">光至於無光而且照日不能生火不能照星不能遠照</span>  
<span style="margin-left: 1em">正與前鏡相反然照象則甚鮮明也</span>  
<span style="margin-left: 2em">一射線不一而遠鏡兼攝乎屈曲以爲斜透之繇<sub class="note-yuan">一</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">條</sub></span>  
<span style="margin-left: 1em">光明之體間隔物象者有正有邪而物象之來有直有</span>  
<span style="margin-left: 1em">偏以故象直矣而體有未正則象來之線尚多屈曲况</span>  
<span style="margin-left: 1em">象偏乎體正矣而象有未直則象來之線亦多屈曲况</span>  
<span style="margin-left: 1em">體邪乎若二鏡照物之時則必皆正者也但物象射線</span>  
<span style="margin-left: 1em">不能皆直蓋必射線直入鏡之中央方無斜透不然射</span>  
<span style="margin-left: 1em">線去中或近或遠皆不免屈曲所以皆不能無斜透也</span>  
<span style="margin-left: 2em">一視象明而大者繇乎二鏡之合用<sub class="note-yuan">計二條</sub></span>  
<span style="margin-left: 1em">二鏡之性乃相反以相制者也獨用則偏並用則得中</span>  
<span style="margin-left: 1em">而成器焉夫遠物發象從平行線入目則目視遠物亦</span>  
<span style="margin-left: 1em">必須從平行線視象假若二鏡獨用其一則前鏡中高</span>  
<span style="margin-left: 8em">而聚象聚象之至則偏偏則不能平</span>  
<span style="margin-left: 8em">行後鏡中窪而散象散象之至則亦</span>  
<span style="margin-left: 8em">偏偏亦不能平行故二鏡合用則前</span>  
<span style="margin-left: 8em">鏡賴有後鏡自能分而散之得乎平</span>  
<span style="margin-left: 8em">行線之中而視物自明後鏡賴有前</span>  
<span style="margin-left: 8em">鏡自能合而聚之得乎平行線之中</span>  
<span style="margin-left: 8em">而視物明且大也</span>  
<span style="margin-left: 8em">前鏡視遠去目如法物象每見其大</span>  
<span style="margin-left: 8em">焉蓋以全鏡之體照物體之分分則</span>  
<span style="margin-left: 8em">見其大矣若鏡目相近則雖鏡體得</span>  
<span style="margin-left: 8em">照全象分分不遺而象則小矣後鏡</span>  
<span style="margin-left: 8em">視遠近目如法視物每見其大焉蓋</span>  
<span style="margin-left: 8em">以全象視物之體若鏡目相遠則以</span>  
<span style="margin-left: 8em">象之一分視物之體而已總之分二</span>  
<span style="margin-left: 8em">鏡而用之則不免昏暗套筒而合用</span>  
<span style="margin-left: 8em">之則彼此相濟視物至大而且明也</span>  
<span style="margin-left: 9em">造法用法<sub class="note-yuan">計九端</sub></span>  
<span style="margin-left: 8em">造鏡至巧也用鏡至變也取不定之</span>  
<span style="margin-left: 8em">法於一定之中必須面授方得了然</span>  
<span style="margin-left: 8em">若但憑書不無差謬今亦撮其大畧</span>  
<span style="margin-left: 1em">而已</span>  
<span style="margin-left: 2em">一鏡<sub class="note-yuan">一條</sub></span>  
<span style="margin-left: 1em">造法曰用玻璃製一似平非平之圓鏡曰筒口鏡即前</span>  
<span style="margin-left: 1em">所謂中高鏡所謂前鏡也製一小窪鏡曰靠眼鏡即前</span>  
<span style="margin-left: 1em">所謂中窪鏡所謂後鏡也須察二鏡之力若何相合若</span>  
<span style="margin-left: 1em">何長短若何比例若何苟既知其力矣知其合矣長短</span>  
<span style="margin-left: 1em">宜而比例審矣方能聚一物像雖遠而小者形形色色</span>  
<span style="margin-left: 1em">不失本來也</span>  
<span style="margin-left: 2em">一筒<sub class="note-yuan">一條</sub></span>  
<span style="margin-left: 1em">鏡止於兩筒不止於兩筒筒相套欲長欲短可伸可縮</span>  
<span style="margin-left: 2em">一遠近各得其宜<sub class="note-yuan">一條</sub></span>  
<span style="margin-left: 1em">用法曰鏡筒相宜以視二百步爲定則因之而視數十</span>  
<span style="margin-left: 1em">里視天象視地形無不同之若視二百步以內物形彌</span>  
<span style="margin-left: 1em">近筒鏡彌長逐分伸長物相明亮即爲限止大要伸縮</span>  
<span style="margin-left: 1em">宜緩而不宜急</span>  
<span style="margin-left: 2em">一避眩便觀<sub class="note-yuan">計三條</sub></span>  
<span style="margin-left: 1em">用以視太陽金星則二者光射明烈故須於近鏡上再</span>  
<span style="margin-left: 1em">加一青綠鏡少禦其烈鏡筒再伸分寸許則光相不眩</span>  
<span style="margin-left: 1em">目力乃精視乃不幻也</span>  
<span style="margin-left: 1em">視太陽又有兩法一加青綠鏡如上所云一不必加青</span>  
<span style="margin-left: 1em">綠鏡只以筒鏡兩相合宜以前鏡直對太陽以白淨紙</span>  
<span style="margin-left: 1em">一張置眼鏡下遠近如法撮其光射則太陽本體在天</span>  
<span style="margin-left: 1em">在紙絲毫不異若用硬紙尺許中翦空圓形冒靠後鏡</span>  
<span style="margin-left: 1em">上則日光團聚下射紙面四暗中光黑白更顯體相更</span>  
<span style="margin-left: 1em">真矣若遇依稀雲霧天太陽本體居明暗中不用綠鏡</span>  
<span style="margin-left: 1em">不用硬紙只以平常格式用目視更快也</span>  
<span style="margin-left: 1em">用以視地形物色前鏡勿對日光以日光照鏡則鏡光</span>  
<span style="margin-left: 1em">與相反昏也</span>  
<span style="margin-left: 2em">一安放調停<sub class="note-yuan">計二條</sub></span>  
<span style="margin-left: 1em">將鏡置諸本架或倚著實落處使不搖動視鏡止用一</span>  
<span style="margin-left: 1em">目目力乃專光益聚而象益顯也</span>  
<span style="margin-left: 1em">視欲開廣將鏡牀少少那動欲左而左欲右而右欲上</span>  
<span style="margin-left: 1em">而上欲下而下架無不隨者只用螺絲釘寧住宜堅定</span>  
<span style="margin-left: 1em">不移</span>  
<span style="margin-left: 2em">一衰目短視用訣<sub class="note-yuan">一條</sub></span>

<span style="margin-left: 1em">短視人亦可用蓋筒內後鏡伸長能使易象於前鏡者</span>  
<span style="margin-left: 1em">仍平行線入目縮短能使易象於前鏡者反以廣行線</span>  
<span style="margin-left: 1em">入目一伸一縮能稱衰目短視人則巧妙又在伸縮得</span>

<span style="margin-left: 1em">照之亦可</span>  
<span style="margin-left: 2em">一借照作畫<sub class="note-yuan">一條</sub></span>

<span style="margin-left: 1em">土所謂物像像物者此也</span>

<span style="margin-left: 1em">欲知鏡之能照遠及小與夫晝夜無異則必於平常試</span>

<span style="margin-left: 2em">一去垢訣<sub class="note-yuan">一條</sub></span>  
<span style="margin-left: 1em">兩鏡或受塵垢勿用手揩摸只以新淨絹帛輕輕拂拭</span>  
<span style="margin-left: 1em">即復光明</span>  
<span style="margin-left: 2em">用鏡測星法</span>  
<span style="margin-left: 1em">前後二鏡各加一積楮圈圈心開圓孔露鏡而以其周</span>  
<span style="margin-left: 1em">掩鏡邊蓋惟邊掩而心孔攝聚星象益加顯著故也孔</span>  
<span style="margin-left: 1em">之大小視鏡光力前圈孔之大以盡見月徑爲率月徑</span>  
<span style="margin-left: 1em">約三十分依此爲孔以求兩星相距或相凌犯遠近分</span>
