## 崇祯历书卷之二十三　康熙奏疏

*康熙八年六月初五日至康熙八年八月二十七日*

<span style="margin-left: 2em">奏疏九</span>  
<span style="margin-left: 12em">康熙八年六月礼部移疏</span>  
<span style="margin-left: 3em">礼部一本恭进考注事复钦天监奉</span>  
<span style="margin-left: 1em">旨杨光先任意将吉凶之神更换均分戈继文以为不</span>  
<span style="margin-left: 3em">便三次具呈即系对答但以其于马祜等面问时</span>  
<span style="margin-left: 3em">不答尔部欲交吏部议处殊为不合戈继文等著</span>  
<span style="margin-left: 3em">免交吏部杨光先任意改易旧书更换均分吉凶</span>  
<span style="margin-left: 3em">之神马祜等不加详核反同杨光先将戈继文等</span>  
<span style="margin-left: 3em">参奏亦殊不合应一并从重治罪姑从宽饶这一</span>  
<span style="margin-left: 3em">遭选择之书关系紧要应作何定正颁行尔部会</span>  
<span style="margin-left: 3em">同吏部再确议具</span>  
<span style="margin-left: 2em">奏</span>  
<span style="margin-left: 9em">康熙八年六月初五日礼部题本</span>  
<span style="margin-left: 3em">礼部</span>  
<span style="margin-left: 2em">题为请</span>  
<span style="margin-left: 1em">旨事该臣等议得据钦天监监副南怀仁称观象台旧</span>  
<span style="margin-left: 3em">仪器俱系百刻并三百六十五度与九十六刻之</span>  
<span style="margin-left: 3em">历法刻分度数不同若改作古器废矣其旧器仍</span>  
<span style="margin-left: 3em">旧存留旧处另依九十六刻之法制造细致轻巧</span>  
<span style="margin-left: 3em">仪器以便测验之用旧表影与九十六刻之法相</span>  
<span style="margin-left: 3em">符不必另造台基窄小难以添设应接旧基往南</span>  
<span style="margin-left: 3em">开展阔大以便安设新仪器等语既称旧仪器并</span>  
<span style="margin-left: 3em">接造台基俱应照南怀仁所指听工部修造其旧</span>  
<span style="margin-left: 3em">仪器仍遵前</span>  
<span style="margin-left: 1em">旨交与南怀仁等修整存留旧处可也</span>  
<span style="margin-left: 3em">康熙八年六月初五日具题本月初七日奉</span>  
<span style="margin-left: 1em">旨依议</span>  
<span style="margin-left: 8em">康熙八年六月二十六日礼部题本</span>  
<span style="margin-left: 3em">礼部</span>  
<span style="margin-left: 2em">题为</span>  
<span style="margin-left: 1em">明纶恩逾格外等事礼科抄出该本部题复治理历法</span>  
<span style="margin-left: 3em">南怀仁奏前事内开该臣等议得臣部先将南怀</span>  
<span style="margin-left: 3em">仁仍留以监副之职办事等因具奏奉</span>  
<span style="margin-left: 1em">旨据奏南怀仁控辞官职其历法天文一切事务俱殚</span>  
<span style="margin-left: 2em">心料理情辞恳切准其所请每年应照何品给俸著</span>  
<span style="margin-left: 2em">议奏钦此今南怀仁应照监副俸银俸米户部支给</span>  
<span style="margin-left: 3em">可也等因康熙八年六月二十六日题二十九日</span>  
<span style="margin-left: 3em">奉</span>  
<span style="margin-left: 1em">旨南怀仁著每年给银一百两米二十五石</span>  
<span style="margin-left: 7em">康熙八年六月二十九日礼部代题本</span>  
<span style="margin-left: 3em">礼部为代</span>  
<span style="margin-left: 2em">题事礼科抄出该本部题复钦天监呈前事内开该</span>  
<span style="margin-left: 3em">臣等议得据钦天监呈称杨光先已经奉</span>  
<span style="margin-left: 1em">旨革职其候气修仪器二事应请部台裁夺外至于上</span>  
<span style="margin-left: 3em">吉壬遁二历铺注事宜业已开载</span>  
<span style="margin-left: 1em">御览总历相应照旧无庸添造等语今杨光先已经革</span>  
<span style="margin-left: 3em">职其会候气之人访求未得且本年议政王贝勒</span>  
<span style="margin-left: 3em">大臣九卿科道会议定历之时据南怀仁供称候</span>  
<span style="margin-left: 3em">气因系自古以来之例故此候气推算历日并不</span>  
<span style="margin-left: 3em">相涉等语故将顺天府候气停止杨光先另行候</span>  
<span style="margin-left: 3em">气之处与推算历日既不相涉应将候气并访求</span>  
<span style="margin-left: 3em">候气之人停止其仪器已经交与南怀仁依九十</span>  
<span style="margin-left: 3em">六刻之法制造将江南解来之仪器不必修造其</span>  
<span style="margin-left: 3em">旧器仍应存留交与钦天监收监正马祜等既称</span>  
<span style="margin-left: 3em">上吉壬遁二历铺注事宜业已开载</span>  
<span style="margin-left: 1em">御览总历相应照旧无庸添造等语其修造上吉壬遁</span>  
<span style="margin-left: 3em">二历并访求修历之人应行停止可也臣等未敢</span>  
<span style="margin-left: 3em">擅便谨</span>  
<span style="margin-left: 2em">题请</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 3em">康熙八年六月二十九日题七月初一日奉</span>  
<span style="margin-left: 1em">旨依议</span>  
<span style="margin-left: 12em">康熙八年六月马祜题本</span>  
<span style="margin-left: 3em">钦天监监正马祜谨题为特参欺诳监副</span>  
<span style="margin-left: 2em">伏乞</span>  
<span style="margin-left: 1em">勅部处分事窃惟历官治历欲合天象法器自当相合</span>  
<span style="margin-left: 3em">人臣供职欲取实效言行自应相符监副吴明烜</span>  
<span style="margin-left: 3em">向因妄奏水星出现已经拟绞适遇恩赦获免又</span>  
<span style="margin-left: 3em">于去年十一月内在</span>  
<span style="margin-left: 1em">皇上御前面奏会算勾股表影及同诸大臣临期测验</span>  
<span style="margin-left: 3em">又称其实不会此言不顾行者也今年正月内</span>  
<span style="margin-left: 1em">皇上特遣大臣公同测验彼以回回三百六十度之法</span>  
<span style="margin-left: 3em">妄测于三百六十五度之仪此器不合法者也又</span>  
<span style="margin-left: 3em">黄道宿度与赤道宿度各有长短不同明烜乃以</span>  
<span style="margin-left: 3em">黄道所推七政用赤道之仪测之此又器不合法</span>  
<span style="margin-left: 3em">者也明烜始而毁古法差讹称回回法善及用回</span>  
<span style="margin-left: 3em">回法测验全不合天复称古法尧舜相传岂可废</span>  
<span style="margin-left: 3em">置似此恣意妄言扰乱历典得蒙</span>  
<span style="margin-left: 1em">皇上宽宥奉有严旨在案明烜自应洗心改过以图报</span>  
<span style="margin-left: 3em">效乃欺诳性成怙终不改本月二十四日同臣等</span>  
<span style="margin-left: 3em">启</span>  
<span style="margin-left: 2em">奏</span>  
<span style="margin-left: 1em">皇上面问南怀仁所推天象尔会算否明烜不会算又</span>  
<span style="margin-left: 3em">复妄奏会算于君父之前毫无忌惮妄肆欺诳臣</span>  
<span style="margin-left: 3em">等实不能为彼掩也谨据实题参</span>  
<span style="margin-left: 2em">伏乞</span>  
<span style="margin-left: 1em">皇上勅部处分以儆欺诳为此谨具</span>  
<span style="margin-left: 2em">题请</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 3em">康熙八年六月　　日奉</span>  
<span style="margin-left: 1em">旨吴明烜著革了职刑部严加议罪具奏</span>  
<span style="margin-left: 8em">康熙八年七月初二日马祜等题本</span>  
<span style="margin-left: 3em">钦天监监正加一级臣马祜等谨</span>  
<span style="margin-left: 2em">题为历法必欲合天成宪无庸变更谨遵</span>  
<span style="margin-left: 1em">旨题明以定一代历典事准本监治理历法南怀仁移</span>  
<span style="margin-left: 3em">会内开切照九十六刻合天之历业蒙</span>  
世祖章皇帝屡经测准命名时宪历颁行二十余年天下  
<span style="margin-left: 3em">信服已久且不次奉有旧法岁久差讹新法屡屡</span>  
<span style="margin-left: 3em">密合著永远遵行之旨嗣因杨光先不知历法欲</span>  
<span style="margin-left: 3em">诬汤若望历差无由谬指旧法紫气坐为遗漏夫</span>  
<span style="margin-left: 3em">紫气乃不合天之旧法实非</span>  
世祖章皇帝钦定之宝历也且本年正月内诸王贝勒大  
<span style="margin-left: 3em">臣会议紫气有云今南怀仁吴明烜既称推算历</span>  
<span style="margin-left: 3em">日并无用处应自康熙九年起将紫气不必造入</span>  
<span style="margin-left: 3em">七政历日内又南怀仁推算九十六刻之法既合</span>  
<span style="margin-left: 3em">天象自康熙九年起应将九十六刻之法准行一</span>  
<span style="margin-left: 3em">应历日俱交南怀仁俱奉有依议之</span>  
<span style="margin-left: 1em">旨钦遵在案于二月内奉有</span>  
<span style="margin-left: 1em">上谕前会议本内欲将紫气星停止开写紫气月孛罗</span>  
<span style="margin-left: 3em">睺计都此四星向来历日既经开写今不宜独缺</span>  
<span style="margin-left: 3em">其一以后钦天监衙门官推算历日著仍将紫气</span>  
<span style="margin-left: 3em">星一并推算开写怀仁谨按历法查得月孛罗睺</span>  
<span style="margin-left: 3em">计都皆指太阴行度系历法所必用故当载入七</span>  
<span style="margin-left: 3em">政至于紫气一项实无理可考无数可推于天象</span>  
<span style="margin-left: 3em">则毫无凭据于历法则毫无干涉若仍开写历内</span>  
<span style="margin-left: 3em">是怀仁以无为有捏假为真反以钦定合天之法</span>  
<span style="margin-left: 3em">变为不合天矣今不题明倘有知者辨驳其非则</span>  
<span style="margin-left: 3em">怀仁隐默之罪将谁诿乎且我</span>  
<span style="margin-left: 2em">朝历典已被光先坏乱数载若非</span>  
<span style="margin-left: 1em">皇上明断克复则一代之良法几为佞口所泯没矣兹</span>  
<span style="margin-left: 3em">所推七政将成理应恭照</span>  
世祖章皇帝钦定旧式颁行则巨典克继前徽历法可永  
<span style="margin-left: 3em">传于后世矣等因到监事关历典臣等未敢擅便</span>  
<span style="margin-left: 3em">谨</span>  
<span style="margin-left: 2em">题请</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 3em">康熙八年七月初二日题本月初四日奉</span>  
<span style="margin-left: 1em">旨该部议奏</span>  
<span style="margin-left: 8em">康熙八年七月二十日杰淑等题本</span>  
<span style="margin-left: 3em">和硕康亲王臣杰淑等谨</span>  
<span style="margin-left: 2em">题为请</span>  
<span style="margin-left: 1em">旨事礼科抄出礼部等衙门</span>  
<span style="margin-left: 2em">题前事该臣等会议得汤若望等建造天主堂供献</span>  
<span style="margin-left: 3em">天主系伊国之例并无诱人作恶结党乱行之处</span>  
<span style="margin-left: 3em">只因供献伊国原供献之天主缘由将汤若望官</span>  
<span style="margin-left: 3em">职并所赐嘉名革去又因入教捐银作序情由将</span>  
<span style="margin-left: 3em">许缵曾等革职俱属冤枉且所赐汤若望通微教</span>  
<span style="margin-left: 3em">师之名因通晓天文历法赐给应将汤若望通微</span>  
<span style="margin-left: 3em">教师之名复行给还该部照依原品级</span>  
<span style="margin-left: 1em">赐恤其许缵曾许之渐等应令该部查明给还原职至</span>  
<span style="margin-left: 3em">于阜城门外堂及房屋工部具题变卖无容议所</span>  
<span style="margin-left: 3em">卖原价并将空地工部取还给南怀仁等因天主</span>  
<span style="margin-left: 3em">教缘由解送广东西洋人栗安当二十五人应行</span>  
<span style="margin-left: 3em">该督抚差官驿送来京候到日该部请</span>  
<span style="margin-left: 1em">旨关系西洋人书籍铜像及天学传概书板前已焚毁</span>  
<span style="margin-left: 3em">无容议杨光先告称荣亲王系丁酉年生纳音属</span>  
<span style="margin-left: 3em">火以水为杀宜选一木生旺之日以生火令水不</span>  
<span style="margin-left: 3em">克火而生木以化杀忌水生旺之月以克火以水</span>  
<span style="margin-left: 3em">能灭火也一说亥子丑为火绝胎养之乡火至北</span>  
<span style="margin-left: 3em">方而无元气等语李祖白等供称葬荣亲王系壬</span>  
<span style="margin-left: 3em">山丙向非子山午向也洪范五行壬山属火火墓</span>  
<span style="margin-left: 3em">在戌遁得壬戌水运纳音属水惟忌土年月日时</span>  
<span style="margin-left: 3em">等语随据杨光先称洪范五行乃唐朝丘延翰造</span>  
<span style="margin-left: 3em">此颠倒生死之五行以哄蛮彝原是中国撰记俾</span>  
<span style="margin-left: 3em">流外国使其用之剿绝根源荡除种类谓之灭蛮</span>  
<span style="margin-left: 3em">经等语事关重大故议将李祖白等正法今据钦</span>  
<span style="margin-left: 3em">天监漏刻科五官挈壶正吴周斌五官司晨王柱</span>  
<span style="margin-left: 3em">蔡九旌等呈称按学士传洪范五行以配八卦取</span>  
<span style="margin-left: 3em">义郭璞诸君子屡皆用之吴景鸾进五行表于宋</span>  
<span style="margin-left: 3em">英宗英宗允之于是颁行天下罗青霄阴阳辨疑</span>  
<span style="margin-left: 3em">云洪范五行作于唐僧一行传流外国以灭蛮何</span>  
<span style="margin-left: 3em">辽金元反盛而不可灭也此立灭蛮之说以斥洪</span>  
<span style="margin-left: 3em">范五行者益见其不经矣说洪范五行者起于唐</span>  
<span style="margin-left: 3em">而唐之袁李杨曾为阴阳之家未闻斥其非也皇</span>  
<span style="margin-left: 3em">极范图衍于宋邵康节邵乃理数之宗亦未以纳</span>  
<span style="margin-left: 3em">甲为非也宋辉山通书明朝刊入司礼监通行天</span>  
<span style="margin-left: 3em">下刘诚意姚恭靖诸公皆精于阴阳之术亦未斥</span>  
<span style="margin-left: 3em">其非也宋中散大夫田吾公同司天监杨维德奏</span>  
<span style="margin-left: 3em">编茔原总录首篇论五行云洪范者此名大五行</span>  
<span style="margin-left: 3em">古今之极有征验阴阳之妙有不可诘徐世彦地</span>  
<span style="margin-left: 3em">理元关云洪范五行之起例从先天卦爻互变而</span>  
<span style="margin-left: 3em">来者也源其始始自洪范九畴继而管郭但申明</span>  
<span style="margin-left: 3em">之而已流而至于今日以讹传讹诿以灭蛮荒唐</span>  
<span style="margin-left: 3em">之语考之并代并无此说况蛮类万千汉二师之</span>  
<span style="margin-left: 3em">旅孔明七纵之雄亦不能尽其类况洪范一书可</span>  
<span style="margin-left: 3em">灭也且蛮与中华书不同文洪范将何所用耶</span>  
<span style="margin-left: 4em">荣亲王戊戌年八月二十七日壬辰日辰时安</span>  
<span style="margin-left: 3em">葬系壬山丙向据洪范五行壬山属火火墓在戌</span>  
<span style="margin-left: 3em">此戊戌年遁得壬戌运属水忌土年月日时尅山</span>  
<span style="margin-left: 3em">运查戊戌年属木八月辛酉亦属木二十七壬辰</span>
