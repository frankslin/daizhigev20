## 崇禎曆書卷之二十三　康熙奏疏

*康熙八年六月初五日至康熙八年八月二十七日*

<span style="margin-left: 2em">奏疏九</span>  
<span style="margin-left: 12em">康熙八年六月禮部移疏</span>  
<span style="margin-left: 3em">禮部一本恭進考注事復欽天監奉</span>  
<span style="margin-left: 1em">旨楊光先任意將吉凶之神更換均分戈繼文以爲不</span>  
<span style="margin-left: 3em">便三次具呈即係對答但以其於馬祜等面問時</span>  
<span style="margin-left: 3em">不答爾部欲交吏部議處殊爲不合戈繼文等著</span>  
<span style="margin-left: 3em">免交吏部楊光先任意改易舊書更換均分吉凶</span>  
<span style="margin-left: 3em">之神馬祜等不加詳核反同楊光先將戈繼文等</span>  
<span style="margin-left: 3em">參奏亦殊不合應一並從重治罪姑從寬饒這一</span>  
<span style="margin-left: 3em">遭選擇之書關係緊要應作何定正頒行爾部會</span>  
<span style="margin-left: 3em">同吏部再確議具</span>  
<span style="margin-left: 2em">奏</span>  
<span style="margin-left: 9em">康熙八年六月初五日禮部題本</span>  
<span style="margin-left: 3em">禮部</span>  
<span style="margin-left: 2em">題爲請</span>  
<span style="margin-left: 1em">旨事該臣等議得據欽天監監副南懷仁稱觀象臺舊</span>  
<span style="margin-left: 3em">儀器俱係百刻並三百六十五度與九十六刻之</span>  
<span style="margin-left: 3em">曆法刻分度數不同若改作古器廢矣其舊器仍</span>  
<span style="margin-left: 3em">舊存留舊處另依九十六刻之法製造細緻輕巧</span>  
<span style="margin-left: 3em">儀器以便測驗之用舊表影與九十六刻之法相</span>  
<span style="margin-left: 3em">符不必另造臺基窄小難以添設應接舊基往南</span>  
<span style="margin-left: 3em">開展闊大以便安設新儀器等語既稱舊儀器並</span>  
<span style="margin-left: 3em">接造臺基俱應照南懷仁所指聽工部修造其舊</span>  
<span style="margin-left: 3em">儀器仍遵前</span>  
<span style="margin-left: 1em">旨交與南懷仁等修整存留舊處可也</span>  
<span style="margin-left: 3em">康熙八年六月初五日具題本月初七日奉</span>  
<span style="margin-left: 1em">旨依議</span>  
<span style="margin-left: 8em">康熙八年六月二十六日禮部題本</span>  
<span style="margin-left: 3em">禮部</span>  
<span style="margin-left: 2em">題爲</span>  
<span style="margin-left: 1em">明綸恩逾格外等事禮科抄出該本部題復治理曆法</span>  
<span style="margin-left: 3em">南懷仁奏前事內開該臣等議得臣部先將南懷</span>  
<span style="margin-left: 3em">仁仍留以監副之職辦事等因具奏奉</span>  
<span style="margin-left: 1em">旨據奏南懷仁控辭官職其曆法天文一切事務俱殫</span>  
<span style="margin-left: 2em">心料理情辭懇切准其所請每年應照何品給俸著</span>  
<span style="margin-left: 2em">議奏欽此今南懷仁應照監副俸銀俸米戶部支給</span>  
<span style="margin-left: 3em">可也等因康熙八年六月二十六日題二十九日</span>  
<span style="margin-left: 3em">奉</span>  
<span style="margin-left: 1em">旨南懷仁著每年給銀一百兩米二十五石</span>  
<span style="margin-left: 7em">康熙八年六月二十九日禮部代題本</span>  
<span style="margin-left: 3em">禮部爲代</span>  
<span style="margin-left: 2em">題事禮科抄出該本部題復欽天監呈前事內開該</span>  
<span style="margin-left: 3em">臣等議得據欽天監呈稱楊光先已經奉</span>  
<span style="margin-left: 1em">旨革職其候氣修儀器二事應請部臺裁奪外至於上</span>  
<span style="margin-left: 3em">吉壬遁二曆鋪注事宜業已開載</span>  
<span style="margin-left: 1em">御覽總曆相應照舊無庸添造等語今楊光先已經革</span>  
<span style="margin-left: 3em">職其會候氣之人訪求未得且本年議政王貝勒</span>  
<span style="margin-left: 3em">大臣九卿科道會議定曆之時據南懷仁供稱候</span>  
<span style="margin-left: 3em">氣因係自古以來之例故此候氣推算曆日並不</span>  
<span style="margin-left: 3em">相涉等語故將順天府候氣停止楊光先另行候</span>  
<span style="margin-left: 3em">氣之處與推算曆日既不相涉應將候氣並訪求</span>  
<span style="margin-left: 3em">候氣之人停止其儀器已經交與南懷仁依九十</span>  
<span style="margin-left: 3em">六刻之法製造將江南解來之儀器不必修造其</span>  
<span style="margin-left: 3em">舊器仍應存留交與欽天監收監正馬祜等既稱</span>  
<span style="margin-left: 3em">上吉壬遁二曆鋪注事宜業已開載</span>  
<span style="margin-left: 1em">御覽總曆相應照舊無庸添造等語其修造上吉壬遁</span>  
<span style="margin-left: 3em">二曆並訪求修曆之人應行停止可也臣等未敢</span>  
<span style="margin-left: 3em">擅便謹</span>  
<span style="margin-left: 2em">題請</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 3em">康熙八年六月二十九日題七月初一日奉</span>  
<span style="margin-left: 1em">旨依議</span>  
<span style="margin-left: 12em">康熙八年六月馬祜題本</span>  
<span style="margin-left: 3em">欽天監監正馬祜謹題爲特參欺誑監副</span>  
<span style="margin-left: 2em">伏乞</span>  
<span style="margin-left: 1em">勅部處分事竊惟曆官治曆欲合天象法器自當相合</span>  
<span style="margin-left: 3em">人臣供職欲取實效言行自應相符監副吳明烜</span>  
<span style="margin-left: 3em">向因妄奏水星出現已經擬絞適遇恩赦獲免又</span>  
<span style="margin-left: 3em">於去年十一月內在</span>  
<span style="margin-left: 1em">皇上御前面奏會算勾股表影及同諸大臣臨期測驗</span>  
<span style="margin-left: 3em">又稱其實不會此言不顧行者也今年正月內</span>  
<span style="margin-left: 1em">皇上特遣大臣公同測驗彼以回回三百六十度之法</span>  
<span style="margin-left: 3em">妄測於三百六十五度之儀此器不合法者也又</span>  
<span style="margin-left: 3em">黃道宿度與赤道宿度各有長短不同明烜乃以</span>  
<span style="margin-left: 3em">黃道所推七政用赤道之儀測之此又器不合法</span>  
<span style="margin-left: 3em">者也明烜始而毀古法差訛稱回回法善及用回</span>  
<span style="margin-left: 3em">回法測驗全不合天復稱古法堯舜相傳豈可廢</span>  
<span style="margin-left: 3em">置似此恣意妄言擾亂曆典得蒙</span>  
<span style="margin-left: 1em">皇上寬宥奉有嚴旨在案明烜自應洗心改過以圖報</span>  
<span style="margin-left: 3em">效乃欺誑性成怙終不改本月二十四日同臣等</span>  
<span style="margin-left: 3em">啓</span>  
<span style="margin-left: 2em">奏</span>  
<span style="margin-left: 1em">皇上面問南懷仁所推天象爾會算否明烜不會算又</span>  
<span style="margin-left: 3em">復妄奏會算於君父之前毫無忌憚妄肆欺誑臣</span>  
<span style="margin-left: 3em">等實不能爲彼掩也謹據實題參</span>  
<span style="margin-left: 2em">伏乞</span>  
<span style="margin-left: 1em">皇上勅部處分以儆欺誑爲此謹具</span>  
<span style="margin-left: 2em">題請</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 3em">康熙八年六月　　日奉</span>  
<span style="margin-left: 1em">旨吳明烜著革了職刑部嚴加議罪具奏</span>  
<span style="margin-left: 8em">康熙八年七月初二日馬祜等題本</span>  
<span style="margin-left: 3em">欽天監監正加一級臣馬祜等謹</span>  
<span style="margin-left: 2em">題爲曆法必欲合天成憲無庸變更謹遵</span>  
<span style="margin-left: 1em">旨題明以定一代曆典事准本監治理曆法南懷仁移</span>  
<span style="margin-left: 3em">會內開切照九十六刻合天之曆業蒙</span>  
世祖章皇帝屢經測准命名時憲曆頒行二十餘年天下  
<span style="margin-left: 3em">信服已久且不次奉有舊法歲久差訛新法屢屢</span>  
<span style="margin-left: 3em">密合著永遠遵行之旨嗣因楊光先不知曆法欲</span>  
<span style="margin-left: 3em">誣湯若望曆差無由謬指舊法紫氣坐爲遺漏夫</span>  
<span style="margin-left: 3em">紫氣乃不合天之舊法實非</span>  
世祖章皇帝欽定之寶曆也且本年正月內諸王貝勒大  
<span style="margin-left: 3em">臣會議紫氣有雲今南懷仁吳明烜既稱推算曆</span>  
<span style="margin-left: 3em">日並無用處應自康熙九年起將紫氣不必造入</span>  
<span style="margin-left: 3em">七政曆日內又南懷仁推算九十六刻之法既合</span>  
<span style="margin-left: 3em">天象自康熙九年起應將九十六刻之法准行一</span>  
<span style="margin-left: 3em">應曆日俱交南懷仁俱奉有依議之</span>  
<span style="margin-left: 1em">旨欽遵在案於二月內奉有</span>  
<span style="margin-left: 1em">上諭前會議本內欲將紫氣星停止開寫紫氣月孛羅</span>  
<span style="margin-left: 3em">睺計都此四星向來曆日既經開寫今不宜獨缺</span>  
<span style="margin-left: 3em">其一以後欽天監衙門官推算曆日著仍將紫氣</span>  
<span style="margin-left: 3em">星一並推算開寫懷仁謹按曆法查得月孛羅睺</span>  
<span style="margin-left: 3em">計都皆指太陰行度係曆法所必用故當載入七</span>  
<span style="margin-left: 3em">政至於紫氣一項實無理可考無數可推於天象</span>  
<span style="margin-left: 3em">則毫無憑據於曆法則毫無干涉若仍開寫曆內</span>  
<span style="margin-left: 3em">是懷仁以無爲有捏假爲真反以欽定合天之法</span>  
<span style="margin-left: 3em">變爲不合天矣今不題明倘有知者辨駁其非則</span>  
<span style="margin-left: 3em">懷仁隱默之罪將誰諉乎且我</span>  
<span style="margin-left: 2em">朝曆典已被光先壞亂數載若非</span>  
<span style="margin-left: 1em">皇上明斷克復則一代之良法幾爲佞口所泯沒矣茲</span>  
<span style="margin-left: 3em">所推七政將成理應恭照</span>  
世祖章皇帝欽定舊式頒行則鉅典克繼前徽曆法可永  
<span style="margin-left: 3em">傳於後世矣等因到監事關曆典臣等未敢擅便</span>  
<span style="margin-left: 3em">謹</span>  
<span style="margin-left: 2em">題請</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 3em">康熙八年七月初二日題本月初四日奉</span>  
<span style="margin-left: 1em">旨該部議奏</span>  
<span style="margin-left: 8em">康熙八年七月二十日傑淑等題本</span>  
<span style="margin-left: 3em">和碩康親王臣傑淑等謹</span>  
<span style="margin-left: 2em">題爲請</span>  
<span style="margin-left: 1em">旨事禮科抄出禮部等衙門</span>  
<span style="margin-left: 2em">題前事該臣等會議得湯若望等建造天主堂供獻</span>  
<span style="margin-left: 3em">天主係伊國之例並無誘人作惡結黨亂行之處</span>  
<span style="margin-left: 3em">只因供獻伊國原供獻之天主緣由將湯若望官</span>  
<span style="margin-left: 3em">職並所賜嘉名革去又因入教捐銀作序情由將</span>  
<span style="margin-left: 3em">許纘曾等革職俱屬冤枉且所賜湯若望通微教</span>  
<span style="margin-left: 3em">師之名因通曉天文曆法賜給應將湯若望通微</span>  
<span style="margin-left: 3em">教師之名復行給還該部照依原品級</span>  
<span style="margin-left: 1em">賜卹其許纘曾許之漸等應令該部查明給還原職至</span>  
<span style="margin-left: 3em">於阜城門外堂及房屋工部具題變賣無容議所</span>  
<span style="margin-left: 3em">賣原價並將空地工部取還給南懷仁等因天主</span>  
<span style="margin-left: 3em">教緣由解送廣東西洋人栗安當二十五人應行</span>  
<span style="margin-left: 3em">該督撫差官驛送來京候到日該部請</span>  
<span style="margin-left: 1em">旨關係西洋人書籍銅像及天學傳概書板前已焚毀</span>  
<span style="margin-left: 3em">無容議楊光先告稱榮親王係丁酉年生納音屬</span>  
<span style="margin-left: 3em">火以水爲殺宜選一木生旺之日以生火令水不</span>  
<span style="margin-left: 3em">克火而生木以化殺忌水生旺之月以克火以水</span>  
<span style="margin-left: 3em">能滅火也一說亥子醜爲火絕胎養之鄉火至北</span>  
<span style="margin-left: 3em">方而無元氣等語李祖白等供稱葬榮親王係壬</span>  
<span style="margin-left: 3em">山丙向非子山午向也洪範五行壬山屬火火墓</span>  
<span style="margin-left: 3em">在戌遁得壬戌水運納音屬水惟忌土年月日時</span>  
<span style="margin-left: 3em">等語隨據楊光先稱洪範五行乃唐朝丘延翰造</span>  
<span style="margin-left: 3em">此顛倒生死之五行以哄蠻彝原是中國撰記俾</span>  
<span style="margin-left: 3em">流外國使其用之剿絕根源蕩除種類謂之滅蠻</span>  
<span style="margin-left: 3em">經等語事關重大故議將李祖白等正法今據欽</span>  
<span style="margin-left: 3em">天監漏刻科五官挈壺正吳周斌五官司晨王柱</span>  
<span style="margin-left: 3em">蔡九旌等呈稱按學士傳洪範五行以配八卦取</span>  
<span style="margin-left: 3em">義郭璞諸君子屢皆用之吳景鸞進五行表於宋</span>  
<span style="margin-left: 3em">英宗英宗允之於是頒行天下羅青霄陰陽辨疑</span>  
<span style="margin-left: 3em">云洪範五行作於唐僧一行傳流外國以滅蠻何</span>  
<span style="margin-left: 3em">遼金元反盛而不可滅也此立滅蠻之說以斥洪</span>  
<span style="margin-left: 3em">範五行者益見其不經矣說洪範五行者起於唐</span>  
<span style="margin-left: 3em">而唐之袁李楊曾爲陰陽之家未聞斥其非也皇</span>  
<span style="margin-left: 3em">極範圖衍於宋邵康節邵乃理數之宗亦未以納</span>  
<span style="margin-left: 3em">甲爲非也宋輝山通書明朝刊入司禮監通行天</span>  
<span style="margin-left: 3em">下劉誠意姚恭靖諸公皆精於陰陽之術亦未斥</span>  
<span style="margin-left: 3em">其非也宋中散大夫田吾公同司天監楊維德奏</span>  
<span style="margin-left: 3em">編塋原總錄首篇論五行云洪範者此名大五行</span>  
<span style="margin-left: 3em">古今之極有徵驗陰陽之妙有不可詰徐世彥地</span>  
<span style="margin-left: 3em">理元關云洪範五行之起例從先天卦爻互變而</span>  
<span style="margin-left: 3em">來者也源其始始自洪範九疇繼而管郭但申明</span>

<span style="margin-left: 3em">天自有曆法至今未聞有先天之說也又曰二十</span>  
<span style="margin-left: 3em">八宿東行夫二十八宿西行舉頭即能見之而謂</span>  
<span style="margin-left: 3em">十八宿東行不但知曆日不肯作此言即三歲孩</span>  
<span style="margin-left: 3em">童亦不肯作此言矣不經之駁種種類此而又欲</span>  
<span style="margin-left: 3em">毀堯舜相傳之儀器以改西洋之儀器夫西洋至</span>  
<span style="margin-left: 3em">我</span>  
<span style="margin-left: 2em">大清國相去八萬里星宿宮度自然各別豈可以八</span>  
<span style="margin-left: 3em">萬里之外國而毀我堯舜之儀器哉使堯舜之儀</span>  
<span style="margin-left: 3em">器可毀則堯舜以來之詩書禮樂文章制度皆可</span>  
<span style="margin-left: 3em">毀矣此其人只可稱制器精巧之工匠而不貫穿</span>  
<span style="margin-left: 3em">於聖賢之道理只知說無根之天話而不知合禮</span>  
<span style="margin-left: 3em">數之精微若用其人臣未見其可也臣病日深一</span>  
<span style="margin-left: 3em">日以將就木之人而娓娓不休者爲堯舜法計爲</span>  
<span style="margin-left: 1em">皇上國統計爲</span>  
<span style="margin-left: 1em">皇上國體計耳非自爲也</span>  
<span style="margin-left: 2em">伏乞</span>  
<span style="margin-left: 1em">皇上垂察焉臣謹席稿以待斧鉞之至奉</span>  
<span style="margin-left: 1em">旨曆法見令諸王貝勒大臣等會議楊光先若實有所</span>  
<span style="margin-left: 3em">見應於衆議之處說出且前有天文最爲精微曆</span>  
<span style="margin-left: 3em">法關係</span>  
<span style="margin-left: 2em">國家要務爾等勿懷夙仇各執己見以己爲是以彼</span>  
<span style="margin-left: 3em">爲非互相爭兢孰是者即遵行非者即更改之旨</span>  
<span style="margin-left: 3em">甚明楊光先不候定議據稱爲不可用阻撓具奏</span>  
<span style="margin-left: 3em">殊爲可惡理應從重處治姑從寬免著飭行該部</span>
