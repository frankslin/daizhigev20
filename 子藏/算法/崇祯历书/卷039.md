<span style="margin-left: 7em">甲角上平安象限仪之心<sub class="note-yuan">后言象限或言仪平安言</sub></span>  
<span style="margin-left: 7em"><sub class="note-yuan">安省文</sub>两边向乙向丙作直角次从甲向</span>  
<span style="margin-left: 7em">丙行任取一十二步为丙点丙上再安</span>

<span style="margin-left: 2em">于丁定丙角为四十八度成甲乙丙直角形此形有</span>  
<span style="margin-left: 2em">甲丙边丙角而求甲乙边法为全数与甲丙边外数</span>  
<span style="margin-left: 2em">若丙角之切线与甲乙边外数也算得一十三步又</span>

<span style="margin-left: 2em">二法曰丁乙为两所不能作直角或不欲或地非平</span>  
<span style="margin-left: 6em">面<sub class="note-yuan">山水林木屋舍所隔</sub>则丁安象限边向乙窥衡向</span>  
<span style="margin-left: 6em">丙定丁角为六十二度向丙行任取一十</span>

<span style="margin-left: 6em">丙角为八十度成丁乙丙角形此形有丁</span>  
<span style="margin-left: 6em">丙边丁丙两角自有乙角而求乙丁边法</span>  
<span style="margin-left: 2em">乙角之正弦与丁丙边外数若丙角之正弦与丁乙</span>  
<span style="margin-left: 2em">边外数算得一十九步又五之一为乙与丁相距之</span>  
<span style="margin-left: 2em">远丁为钝角亦如之</span>  
<span style="margin-left: 2em">三法曰或从丁向丙线持象限前却取得甲直角是</span>  
<span style="margin-left: 2em">乙丁为直角之对边也法全数与外甲丁若丁角之</span>

<span style="margin-left: 9em">四法曰若丁为钝角上安象限面</span>

<span style="margin-left: 2em">之正弦与外丁丙若丙角之正弦与外乙丁得一丈</span>  
<span style="margin-left: 2em">七尺七寸</span>  
<span style="margin-left: 2em">五法曰丁安象限边向乙衡向任取之丙表得二丈</span>  
<span style="margin-left: 6em">从丁直视过丙至己任定丙己为一丈以</span>  
<span style="margin-left: 6em">上安象限边向戊衡向丙令己角与丁角</span>  
<span style="margin-left: 6em">等末前却令戊过丙至乙作直线则丙己</span>  
<span style="margin-left: 6em">与己戊若丙丁与丁乙论曰丁乙丙丙己</span>  
<span style="margin-left: 6em">戊两角形相似何者己丁两角等丙上两</span>  
<span style="margin-left: 6em">交角又等是形与形相似<sub class="note-yuan">六卷四题</sub>即相当边</span>  
<span style="margin-left: 6em">之比例必等用三率法丙己一丈为一率</span>  
<span style="margin-left: 6em">己戊三丈为次率丁丙二丈为三率算得</span>  
<span style="margin-left: 6em">六丈为乙丁</span>  
<span style="margin-left: 6em">六法曰甲乙为两所从乙引长任取二十</span>  
<span style="margin-left: 2em">步为丙又任作丙丁戊直线任取丙丁二十五步丁</span>  
<span style="margin-left: 2em">安象限边向乙衡向丙定乙丁丙角次持象限前却</span>  
<span style="margin-left: 2em">取戊令戊角与丁角等量丁戊得一十六步<sub class="note-jiao">校：一十六步原</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">作六十一步据上下文改</sub>法丙丁与丁戊若丙乙与乙甲<sub class="note-yuan">六卷二</sub></span>  
<span style="margin-left: 6em">算得十二步又一十五之四不用布算法</span>  
<span style="margin-left: 6em">七法曰乙丁为两所乙安象限边向任取</span>  
<span style="margin-left: 6em">之丙衡向丁得丁乙丙外角七十度次从</span>

<span style="margin-left: 6em">则戊乙与乙丁等</span>

<span style="margin-left: 2em"><sub class="note-yuan">三十二</sub>戊角半丁角亦半两角等两腰亦等</span>  
<span style="margin-left: 2em">八法曰乙上安象限作六十度角次于乙丙直线上</span>  
<span style="margin-left: 2em">求丙亦作六十度角则乙丙与乙丁等</span>

<span style="margin-left: 2em">丙为三边等形</span>  
<span style="margin-left: 8em">九法曰若乙丙短则向乙向丁求甲</span>

<span style="margin-left: 6em">十法曰任设乙角为四十度次以半周上</span>  
<span style="margin-left: 6em">余度平分为七十度于乙丙线上前却令</span>  
<span style="margin-left: 6em">丙角亦七十度则乙丙与乙丁等论曰丙</span>  
<span style="margin-left: 6em">角为外角之半丁角亦半乙丙与乙丁两</span>  
<span style="margin-left: 2em">线必等</span>  
<span style="margin-left: 2em">用矩度法　用矩度者以器上小形当所测大形也</span>  
<span style="margin-left: 2em">如所测为甲乙则矩度之边壬丙或己辛与甲乙平</span>  
<span style="margin-left: 2em">行其相当数为比例必等所设两在边为甲丙则矩</span>  
<span style="margin-left: 2em">度之边壬辛或丙己与甲丙平行其相当数为比例</span>  
<span style="margin-left: 8em">必等<sub class="note-yuan">一卷二十九三十二题</sub>置法同前甲恒为</span>  
<span style="margin-left: 8em">直角</span>  
<span style="margin-left: 8em">十一法曰一解窥衡交线<sub class="note-yuan">后省曰交或曰视交</sub></span>  
<span style="margin-left: 8em">在对角则丙甲与甲乙等</span>  
<span style="margin-left: 8em">论曰丙己辛丙甲乙两角形相似何</span>  
<span style="margin-left: 8em">者两形有己甲各直角同用丙角则</span>  
<span style="margin-left: 8em">两相似<sub class="note-yuan">六卷四题</sub>而矩形丙己与己辛等</span>  
<span style="margin-left: 2em">则丙甲与甲乙亦等二解视交在两所平行边如戊</span>  
<span style="margin-left: 2em">则丙己与己戊若丙甲与甲乙</span>  
<span style="margin-left: 2em">论曰丙己戊丙甲乙两角形相似何者两形有己甲</span>  
<span style="margin-left: 7em">各直角同用丙角则两形相似<sub class="note-yuan">六卷四题</sub>而</span>  
<span style="margin-left: 7em">矩形之丙己与己戊若甲丙与甲乙</span>  
<span style="margin-left: 7em">三率法丙己一百分为首率己戊七十</span>  
<span style="margin-left: 7em">分为二率丙甲一十五步为三率算得</span>  
<span style="margin-left: 7em">甲乙十一步半<sub class="note-yuan">两所平行边后省曰平边</sub></span>  
<span style="margin-left: 7em">三解视交在两测平行边如丁则丁壬</span>  
<span style="margin-left: 2em">与壬丙若丙甲与甲乙<sub class="note-yuan">两测平行边后省曰立边</sub></span>

<span style="margin-left: 2em">有相等之壬丁丙乙丙甲两角在平行线内则相当</span>  
<span style="margin-left: 2em">线之比例必等　三率法丁壬六十分为一率壬丙</span>  
<span style="margin-left: 2em">百分为次率丙甲一十二步为三率算得二十步为</span>  
<span style="margin-left: 2em">甲乙</span>  
<span style="margin-left: 7em">省算法　十二法曰交戊甲丙六十步</span>  
<span style="margin-left: 7em">即于丙己边自己至未取六十分与甲</span>  
<span style="margin-left: 7em">丙比例等自未至视线作未子为丙己</span>  
<span style="margin-left: 7em">之垂线从子作子午为辛己之垂线得</span>  
<span style="margin-left: 7em">子午戊形戊午之若干分为甲乙之若</span>  
<span style="margin-left: 2em">干步</span>  
<span style="margin-left: 2em">论曰子午戊丙甲乙两角形相似何者两形各有直</span>  
<span style="margin-left: 2em">角有相等之戊角与乙角则各边之比例等先作未</span>  
<span style="margin-left: 8em">己或子午与甲丙比例等则戊午甲</span>  
<span style="margin-left: 8em">乙比例亦等　若交在丁从壬至午</span>  
<span style="margin-left: 8em">取六十分作午子垂线二支测两所</span>  
<span style="margin-left: 8em">之不能到者</span>  
<span style="margin-left: 8em">一法曰乙丙为两所俱不能到独甲</span>  
<span style="margin-left: 8em">可到即于甲上立表令甲乙丙为直</span>  
<span style="margin-left: 8em">线安象限边向乙向丁行至丁得若</span>  
<span style="margin-left: 2em">干步安象限于丁边向甲衡以次向乙向丙成甲丁</span>  
<span style="margin-left: 2em">丙甲乙丁两直角形甲乙丁角形有甲丁边丁角可</span>  
<span style="margin-left: 2em">求甲乙边<sub class="note-yuan">本书首卷十二题二解</sub>甲丁丙角形有甲丁边丁角</span>  
<span style="margin-left: 2em">可求甲丙边末以甲乙减甲丙所余乙丙用切线可</span>  
<span style="margin-left: 2em">求乙丙边如甲丁二十四步乙丁甲角三十四度丙</span>  
<span style="margin-left: 2em">丁甲角四十八度则甲丁为全数而甲乙为甲丁乙</span>  
<span style="margin-left: 2em">角之切线甲丙为甲丁丙角之切线两切线之较为</span>  
<span style="margin-left: 2em">乙丙用三率法全数一甲丁二十四步二切线较三</span>  
<span style="margin-left: 2em">算得一十步一十五之七为乙丙</span>  
<span style="margin-left: 9em">二法曰乙丙为两所直线上更任</span>  
<span style="margin-left: 9em">取两所如丁如庚次作庚壬线任</span>  
<span style="margin-left: 9em">取壬点安象限边向丙窥庚定壬</span>  
<span style="margin-left: 2em">角之度次辛点上安象限向乙向庚游移令辛角与</span>

<span style="margin-left: 2em">与壬角亦等未量壬辛戊庚及庚丁各几何用三率</span>  
<span style="margin-left: 2em">法与戊庚与辛壬若庚丁与乙丙</span>  
<span style="margin-left: 7em">三法曰乙丙直线上任至一处如庚庚</span>  
<span style="margin-left: 7em">上安象限边向乙丙窥丁定丁庚乙角</span>  
<span style="margin-left: 7em">之度又从庚丁直线上至戊戊上安象</span>  
<span style="margin-left: 7em">限作庚戊己角与丁庚<sub class="note-yuan">乙角</sub>等即戊己线</span>  
<span style="margin-left: 7em">与丙庚平行次于己上窥过丁到丙戊</span>  
<span style="margin-left: 7em">己之间游移窥过丁到乙得辛则戊丁</span>  
<span style="margin-left: 2em">与辛己若丁庚与乙丙</span>  
<span style="margin-left: 2em">论曰丙乙丁辛己丁两角形相似戊辛丁乙庚丁两</span>  
<span style="margin-left: 2em">角形亦相似则各边之比例自等</span>  
<span style="margin-left: 1em">省算　四法曰乙庚为两所直线上取甲安象限作乙</span>  
<span style="margin-left: 2em">甲丁直角行至丁安象限边向甲窥乙窥庚作甲丁</span>  
<span style="margin-left: 8em">乙甲丁庚两角次甲乙直线上寻戊</span>  
<span style="margin-left: 8em">作甲戊丁为乙丁甲之余角寻己作</span>  
<span style="margin-left: 8em">甲己丁为甲丁庚之余角则得戊己</span>  
<span style="margin-left: 8em">与乙庚等</span>  
<span style="margin-left: 8em">论曰甲乙丁甲戊丁两形等何者戊</span>  
<span style="margin-left: 8em">为甲丁乙之余角则与乙角等同用</span>  
<span style="margin-left: 2em">甲丁边故两形等依显甲庚丁甲丁己两直角形亦</span>  
<span style="margin-left: 2em">等夫庚甲甲己既等减相等之甲乙甲戊所存戊己</span>  
<span style="margin-left: 2em">乙庚亦等</span>  
<span style="margin-left: 6em">五法曰甲丁直线上取戊安象限窥乙作</span>  
<span style="margin-left: 6em">戊角为四十五度丁上窥庚亦令丁角为</span>  
<span style="margin-left: 6em">四十五则戊丁与乙庚等<sub class="note-yuan">戊甲乙为直角</sub>论曰丁</span>  
<span style="margin-left: 2em">戊各半直角则庚与乙亦如之甲丁甲庚必等又甲</span>  
<span style="margin-left: 2em">戊甲乙亦然减相等之甲乙甲戊则所存亦等</span>  
<span style="margin-left: 2em">六法曰若庚乙丁戊两线上所得角未真则于乙庚</span>

<span style="margin-left: 2em">底为量高在物顶为量深</span>  
<span style="margin-left: 2em">一法曰测井从口一边垂线至底或视口广狭从口</span>  
<span style="margin-left: 7em">边投之以石至底作旋涡定其处如甲</span>  
<span style="margin-left: 7em">戊丙丁井甲戊口丁丙底投石作旋涡</span>  
<span style="margin-left: 7em">得乙为视线之界戊立象限向乙成甲</span>  
<span style="margin-left: 7em">戊乙直角形有甲戊边戊角得甲乙之</span>  
<span style="margin-left: 7em">深</span>  
<span style="margin-left: 7em">二法曰不知井口于口边立表表端加</span>  
<span style="margin-left: 7em">象限作甲丁乙形测之</span>
