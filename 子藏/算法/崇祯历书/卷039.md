## 崇禎曆書卷之三十九　測量全義卷二

<span style="margin-left: 1em">法原部</span>  
<span style="margin-left: 2em">測量全義第二卷　測線上</span>  
<span style="margin-left: 1em">欽差禮部尚書兼翰林院學士協理詹事府事加俸一</span>  
<span style="margin-left: 1em">級徐光啓奉勅督修</span>

<span style="margin-left: 15em">湯若望同　訂</span>  
<span style="margin-left: 9em">庠　　生　　衛斗樞脩　潤</span>  
<span style="margin-left: 9em">訪　　舉　　張寀臣等　算</span>  
<span style="margin-left: 9em">南　　州　　張宋臣校　梓</span>  
<span style="margin-left: 1em"><sub class="note-jiao">校：校諱作較今改清刊本署名不同錄之於左西洋新法曆書法原部測量全義第二卷測線上</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">明禮部尚書兼翰林院學士協理詹事府事加俸一級</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">徐光啓督修　　　　　　　　　　　　　　　　　　　　衛斗樞　朱光顯　　　</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">　羅雅谷　譔　　修政曆法極西耶穌會士門人張寀臣　黃宏憲　受法　　　　　　　　　　　湯若望訂</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">　　　　　　　　　　　　　　　　　　　　孫嗣烈宋發</sub></span>  
<span style="margin-left: 3em">第一題<sub class="note-jiao">校：清刊本此前有測量全義二卷標題</sub></span>  
<span style="margin-left: 1em">平面測遠<sub class="note-yuan">三支</sub></span>  
<span style="margin-left: 2em">一支測兩物之能到者　一法曰甲乙爲地平面上</span>  
<span style="margin-left: 2em">江河之廣或土田道里之遠欲從甲測去乙幾何於</span>  
<span style="margin-left: 7em">甲角上平安象限儀之心<sub class="note-yuan">後言象限或言儀平安言</sub></span>  
<span style="margin-left: 7em"><sub class="note-yuan">安省文</sub>兩邊向乙向丙作直角次從甲向</span>  
<span style="margin-left: 7em">丙行任取一十二步爲丙點丙上再安</span>  
<span style="margin-left: 7em">象限邊向甲窺衡望乙交象限之周線</span>  
<span style="margin-left: 2em">于丁定丙角爲四十八度成甲乙丙直角形此形有</span>  
<span style="margin-left: 2em">甲丙邊丙角而求甲乙邊法爲全數與甲丙邊外數</span>  
<span style="margin-left: 2em">若丙角之切線與甲乙邊外數也算得一十三步又</span>  
<span style="margin-left: 2em">三之一爲甲與乙平面相距之遠<sub class="note-yuan">象限儀法見本篇第三卷窺衡或作</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">指尺義同</sub></span>  
<span style="margin-left: 2em">二法曰丁乙爲兩所不能作直角或不欲或地非平</span>  
<span style="margin-left: 6em">面<sub class="note-yuan">山水林木屋舍所隔</sub>則丁安象限邊向乙窺衡向</span>  
<span style="margin-left: 6em">丙定丁角爲六十二度向丙行任取一十</span>  
<span style="margin-left: 6em">二步丙上再加象限邊向丁窺衡望乙定</span>  
<span style="margin-left: 6em">丙角爲八十度成丁乙丙角形此形有丁</span>  
<span style="margin-left: 6em">丙邊丁丙兩角自有乙角而求乙丁邊法</span>  
<span style="margin-left: 2em">乙角之正弦與丁丙邊外數若丙角之正弦與丁乙</span>  
<span style="margin-left: 2em">邊外數算得一十九步又五之一爲乙與丁相距之</span>  
<span style="margin-left: 2em">遠丁爲鈍角亦如之</span>  
<span style="margin-left: 2em">三法曰或從丁向丙線持象限前却取得甲直角是</span>  
<span style="margin-left: 2em">乙丁爲直角之對邊也法全數與外甲丁若丁角之</span>  
<span style="margin-left: 9em">交線與外乙丁</span>  
<span style="margin-left: 9em">四法曰若丁爲鈍角上安象限面</span>  
<span style="margin-left: 9em">移丁丙線外邊向乙衡向任取之</span>  
<span style="margin-left: 9em">丙表定戊丁丙角爲五十度以并</span>  
<span style="margin-left: 9em">戊丁乙直角得鈍角一百四十度</span>  
<span style="margin-left: 9em">末定丙角二十四度成丁乙丙角</span>  
<span style="margin-left: 2em">形此形有丙丁邊一丈二尺丙角二十四度法乙角</span>  
<span style="margin-left: 2em">之正弦與外丁丙若丙角之正弦與外乙丁得一丈</span>  
<span style="margin-left: 2em">七尺七寸</span>  
<span style="margin-left: 2em">五法曰丁安象限邊向乙衡向任取之丙表得二丈</span>  
<span style="margin-left: 6em">從丁直視過丙至己任定丙己爲一丈以</span>  
<span style="margin-left: 6em">上安象限邊向戊衡向丙令己角與丁角</span>  
<span style="margin-left: 6em">等末前却令戊過丙至乙作直線則丙己</span>  
<span style="margin-left: 6em">與己戊若丙丁與丁乙論曰丁乙丙丙己</span>  
<span style="margin-left: 6em">戊兩角形相似何者己丁兩角等丙上兩</span>  
<span style="margin-left: 6em">交角又等是形與形相似<sub class="note-yuan">六卷四題</sub>即相當邊</span>  
<span style="margin-left: 6em">之比例必等用三率法丙己一丈爲一率</span>  
<span style="margin-left: 6em">己戊三丈爲次率丁丙二丈爲三率算得</span>  
<span style="margin-left: 6em">六丈爲乙丁</span>  
<span style="margin-left: 6em">六法曰甲乙爲兩所從乙引長任取二十</span>  
<span style="margin-left: 2em">步爲丙又任作丙丁戊直線任取丙丁二十五步丁</span>  
<span style="margin-left: 2em">安象限邊向乙衡向丙定乙丁丙角次持象限前却</span>  
<span style="margin-left: 2em">取戊令戊角與丁角等量丁戊得一十六步<sub class="note-jiao">校：一十六步原</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">作六十一步據上下文改</sub>法丙丁與丁戊若丙乙與乙甲<sub class="note-yuan">六卷二</sub></span>  
<span style="margin-left: 6em">算得十二步又一十五之四不用布算法</span>  
<span style="margin-left: 6em">七法曰乙丁爲兩所乙安象限邊向任取</span>  
<span style="margin-left: 6em">之丙衡向丁得丁乙丙外角七十度次從</span>  
<span style="margin-left: 6em">丙乙直線上求戊令戊角半於丁乙丙角</span>  
<span style="margin-left: 6em">則戊乙與乙丁等</span>  
<span style="margin-left: 6em">論曰丁乙丙外角與相對之兩內角等<sub class="note-yuan">一卷</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">三十二</sub>戊角半丁角亦半兩角等兩腰亦等</span>  
<span style="margin-left: 2em">八法曰乙上安象限作六十度角次于乙丙直線上</span>  
<span style="margin-left: 2em">求丙亦作六十度角則乙丙與乙丁等</span>  
<span style="margin-left: 2em">論曰乙丙兩角各六十度則丁角亦六十度而乙丁</span>  
<span style="margin-left: 2em">丙爲三邊等形</span>  
<span style="margin-left: 8em">九法曰若乙丙短則向乙向丁求甲</span>  
<span style="margin-left: 8em">直角得甲乙爲乙丁之半</span>  
<span style="margin-left: 8em">論曰丁乙甲直角形乙角既六十度</span>  
<span style="margin-left: 8em">則丁角三十度因角與角之正弦若</span>  
<span style="margin-left: 8em">邊與邊是三十度之正弦全數之半</span>  
<span style="margin-left: 6em">也故乙甲爲乙丁之半也</span>  
<span style="margin-left: 6em">十法曰任設乙角爲四十度次以半周上</span>  
<span style="margin-left: 6em">餘度平分爲七十度于乙丙線上前却令</span>  
<span style="margin-left: 6em">丙角亦七十度則乙丙與乙丁等論曰丙</span>  
<span style="margin-left: 6em">角爲外角之半丁角亦半乙丙與乙丁兩</span>  
<span style="margin-left: 2em">線必等</span>  
<span style="margin-left: 2em">用矩度法　用矩度者以器上小形當所測大形也</span>  
<span style="margin-left: 2em">如所測爲甲乙則矩度之邊壬丙或己辛與甲乙平</span>  
<span style="margin-left: 2em">行其相當數爲比例必等所設兩在邊爲甲丙則矩</span>  
<span style="margin-left: 2em">度之邊壬辛或丙己與甲丙平行其相當數爲比例</span>  
<span style="margin-left: 8em">必等<sub class="note-yuan">一卷二十九三十二題</sub>置法同前甲恆爲</span>  
<span style="margin-left: 8em">直角</span>  
<span style="margin-left: 8em">十一法曰一解窺衡交線<sub class="note-yuan">後省曰交或曰視交</sub></span>  
<span style="margin-left: 8em">在對角則丙甲與甲乙等</span>  
<span style="margin-left: 8em">論曰丙己辛丙甲乙兩角形相似何</span>  
<span style="margin-left: 8em">者兩形有己甲各直角同用丙角則</span>  
<span style="margin-left: 8em">兩相似<sub class="note-yuan">六卷四題</sub>而矩形丙己與己辛等</span>  
<span style="margin-left: 2em">則丙甲與甲乙亦等二解視交在兩所平行邊如戊</span>  
<span style="margin-left: 2em">則丙己與己戊若丙甲與甲乙</span>  
<span style="margin-left: 2em">論曰丙己戊丙甲乙兩角形相似何者兩形有己甲</span>  
<span style="margin-left: 7em">各直角同用丙角則兩形相似<sub class="note-yuan">六卷四題</sub>而</span>  
<span style="margin-left: 7em">矩形之丙己與己戊若甲丙與甲乙</span>  
<span style="margin-left: 7em">三率法丙己一百分爲首率己戊七十</span>  
<span style="margin-left: 7em">分爲二率丙甲一十五步爲三率算得</span>  
<span style="margin-left: 7em">甲乙十一步半<sub class="note-yuan">兩所平行邊後省曰平邊</sub></span>  
<span style="margin-left: 7em">三解視交在兩測平行邊如丁則丁壬</span>  
<span style="margin-left: 2em">與壬丙若丙甲與甲乙<sub class="note-yuan">兩測平行邊後省曰立邊</sub></span>  
<span style="margin-left: 2em">論曰丁壬丙丙甲乙兩角形相似何者兩形有直角</span>  
<span style="margin-left: 2em">有相等之壬丁丙乙丙甲兩角在平行線內則相當</span>  
<span style="margin-left: 2em">線之比例必等　三率法丁壬六十分爲一率壬丙</span>  
<span style="margin-left: 2em">百分爲次率丙甲一十二步爲三率算得二十步爲</span>  
<span style="margin-left: 2em">甲乙</span>  
<span style="margin-left: 7em">省算法　十二法曰交戊甲丙六十步</span>  
<span style="margin-left: 7em">即于丙己邊自己至未取六十分與甲</span>  
<span style="margin-left: 7em">丙比例等自未至視線作未子爲丙己</span>  
<span style="margin-left: 7em">之垂線從子作子午爲辛己之垂線得</span>  
<span style="margin-left: 7em">子午戊形戊午之若干分爲甲乙之若</span>  
<span style="margin-left: 2em">干步</span>  
<span style="margin-left: 2em">論曰子午戊丙甲乙兩角形相似何者兩形各有直</span>  
<span style="margin-left: 2em">角有相等之戊角與乙角則各邊之比例等先作未</span>  
<span style="margin-left: 8em">己或子午與甲丙比例等則戊午甲</span>  
<span style="margin-left: 8em">乙比例亦等　若交在丁從壬至午</span>  
<span style="margin-left: 8em">取六十分作午子垂線二支測兩所</span>  
<span style="margin-left: 8em">之不能到者</span>  
<span style="margin-left: 8em">一法曰乙丙爲兩所俱不能到獨甲</span>  
<span style="margin-left: 8em">可到即於甲上立表令甲乙丙爲直</span>  
<span style="margin-left: 8em">線安象限邊向乙向丁行至丁得若</span>  
<span style="margin-left: 2em">干步安象限于丁邊向甲衡以次向乙向丙成甲丁</span>  
<span style="margin-left: 2em">丙甲乙丁兩直角形甲乙丁角形有甲丁邊丁角可</span>  
<span style="margin-left: 2em">求甲乙邊<sub class="note-yuan">本書首卷十二題二解</sub>甲丁丙角形有甲丁邊丁角</span>  
<span style="margin-left: 2em">可求甲丙邊末以甲乙減甲丙所餘乙丙用切線可</span>  
<span style="margin-left: 2em">求乙丙邊如甲丁二十四步乙丁甲角三十四度丙</span>  
<span style="margin-left: 2em">丁甲角四十八度則甲丁爲全數而甲乙爲甲丁乙</span>  
<span style="margin-left: 2em">角之切線甲丙爲甲丁丙角之切線兩切線之較爲</span>  
<span style="margin-left: 2em">乙丙用三率法全數一甲丁二十四步二切線較三</span>  
<span style="margin-left: 2em">算得一十步一十五之七爲乙丙</span>  
<span style="margin-left: 9em">二法曰乙丙爲兩所直線上更任</span>  
<span style="margin-left: 9em">取兩所如丁如庚次作庚壬線任</span>  
<span style="margin-left: 9em">取壬點安象限邊向丙窺庚定壬</span>  
<span style="margin-left: 2em">角之度次辛點上安象限向乙向庚游移令辛角與</span>  
<span style="margin-left: 2em">壬角等次戊安象限向丁<sub class="note-yuan">乙丙直線上</sub>向庚游移令戊角</span>  
<span style="margin-left: 2em">與壬角亦等未量壬辛戊庚及庚丁各幾何用三率</span>  
<span style="margin-left: 2em">法與戊庚與辛壬若庚丁與乙丙</span>  
<span style="margin-left: 7em">三法曰乙丙直線上任至一處如庚庚</span>  
<span style="margin-left: 7em">上安象限邊向乙丙窺丁定丁庚乙角</span>  
<span style="margin-left: 7em">之度又從庚丁直線上至戊戊上安象</span>  
<span style="margin-left: 7em">限作庚戊己角與丁庚<sub class="note-yuan">乙角</sub>等即戊己線</span>  
<span style="margin-left: 7em">與丙庚平行次于己上窺過丁到丙戊</span>  
<span style="margin-left: 7em">己之間游移窺過丁到乙得辛則戊丁</span>  
<span style="margin-left: 2em">與辛己若丁庚與乙丙</span>  
<span style="margin-left: 2em">論曰丙乙丁辛己丁兩角形相似戊辛丁乙庚丁兩</span>  
<span style="margin-left: 2em">角形亦相似則各邊之比例自等</span>  
<span style="margin-left: 1em">省算　四法曰乙庚爲兩所直線上取甲安象限作乙</span>  
<span style="margin-left: 2em">甲丁直角行至丁安象限邊向甲窺乙窺庚作甲丁</span>  
<span style="margin-left: 8em">乙甲丁庚兩角次甲乙直線上尋戊</span>  
<span style="margin-left: 8em">作甲戊丁爲乙丁甲之餘角尋己作</span>  
<span style="margin-left: 8em">甲己丁爲甲丁庚之餘角則得戊己</span>  
<span style="margin-left: 8em">與乙庚等</span>  
<span style="margin-left: 8em">論曰甲乙丁甲戊丁兩形等何者戊</span>  
<span style="margin-left: 8em">爲甲丁乙之餘角則與乙角等同用</span>  
<span style="margin-left: 2em">甲丁邊故兩形等依顯甲庚丁甲丁己兩直角形亦</span>  
<span style="margin-left: 2em">等夫庚甲甲己既等減相等之甲乙甲戊所存戊己</span>  
<span style="margin-left: 2em">乙庚亦等</span>  
<span style="margin-left: 6em">五法曰甲丁直線上取戊安象限窺乙作</span>  
<span style="margin-left: 6em">戊角爲四十五度丁上窺庚亦令丁角爲</span>  
<span style="margin-left: 6em">四十五則戊丁與乙庚等<sub class="note-yuan">戊甲乙爲直角</sub>論曰丁</span>  
<span style="margin-left: 2em">戊各半直角則庚與乙亦如之甲丁甲庚必等又甲</span>  
<span style="margin-left: 2em">戊甲乙亦然減相等之甲乙甲戊則所存亦等</span>  
<span style="margin-left: 2em">六法曰若庚乙丁戊兩線上所得角未真則于乙庚</span>  
<span style="margin-left: 2em">線上取丙安象限作六十度角丙丁線上尋戊尋丁</span>  
<span style="margin-left: 7em">望乙望庚作戊丁二角各六十度則戊</span>  
<span style="margin-left: 7em">丁與乙庚等</span>  
<span style="margin-left: 7em">論曰丁丙庚角形之三角同爲六十度</span>  
<span style="margin-left: 7em">乙戊丙亦如之減相等之戊丙乙丙所</span>  
<span style="margin-left: 2em">存丁戊乙庚自等</span>  
<span style="margin-left: 8em">七法曰置丙角六十度令戊丁爲兩</span>  
<span style="margin-left: 8em">直角則戊丁爲庚乙之半</span>  
<span style="margin-left: 8em">論曰庚丙丁乙丙戊兩直角形有丙</span>

<span style="margin-left: 3em">第二題</span>  
<span style="margin-left: 1em">斜面測遠<sub class="note-yuan">三支</sub></span>  
<span style="margin-left: 2em">一支不論根之能到與否</span>  
<span style="margin-left: 1em">一法曰乙甲爲山之高其坡乙丙欲測坡若于于丙或</span>  
<span style="margin-left: 6em">左或右置象限作直角一邊向丁至丁上</span>  
<span style="margin-left: 6em">置象限邊向丙窺乙令丁爲四十五度角</span>  
<span style="margin-left: 6em">則得丙丁與乙丙等</span>  
<span style="margin-left: 6em">論曰乙丁丙直角形丁角四十五度則乙</span>  
<span style="margin-left: 2em">角亦四十五度丁丙乙丙各等角之對邊也必等</span>  
<span style="margin-left: 9em">二支根之能到者　二法曰置丙</span>  
<span style="margin-left: 9em">象限邊向甲根窺乙定丙角之度</span>  
<span style="margin-left: 9em">此形有甲丙邊丙角而求乙丙邊</span>  
<span style="margin-left: 9em">法爲全數與外甲丙若丙角之割</span>  
<span style="margin-left: 2em">線與外乙丙　三法曰丙甲直線上求丁置象限令</span>  
<span style="margin-left: 9em">其角爲乙丙甲角之半則丙丁與</span>  
<span style="margin-left: 9em">乙丙等</span>  
<span style="margin-left: 9em">四法用矩度</span>  
<span style="margin-left: 9em">一解曰表在丁窺交平邊于辛爲</span>  
<span style="margin-left: 9em">辛庚與辛丁若甲丁與乙丁</span>  
<span style="margin-left: 9em">二解曰表在丙窺交爲對角線依</span>  
<span style="margin-left: 9em">句股法丙甲自之倍之開方得弦</span>  
<span style="margin-left: 9em">三解曰表在戊窺交立邊于己爲</span>  
<span style="margin-left: 2em">戊寅與戊己若甲戊與戊乙</span>  
<span style="margin-left: 2em">五法省算矩邊從丁到午取分數如丁甲之步數立</span>  
<span style="margin-left: 8em">午子垂線成午丁子角形與甲丁乙</span>  
<span style="margin-left: 8em">形相似則丁子之分數爲乙丁之步</span>  
<span style="margin-left: 8em">數從戊亦如之</span>  
<span style="margin-left: 8em">三支根之不能到者　六法曰丙丁</span>  
<span style="margin-left: 8em">直線上用象限兩次于丙于丁成乙</span>  
<span style="margin-left: 8em">丙丁形此形有丁丙邊丁丙兩角用</span>  
<span style="margin-left: 8em">正弦法得乙丙邊</span>  
<span style="margin-left: 8em">七法曰以意置乙甲垂線用丁乙甲</span>  
<span style="margin-left: 2em">丙乙甲兩角之切線較爲一率外丁丙爲次率丙乙</span>  
<span style="margin-left: 2em">甲之割線爲三率所得爲外率乙丙<sub class="note-yuan">或丁乙甲交線爲三率所得四</sub></span>  
<span style="margin-left: 2em"><sub class="note-yuan">率乙丁</sub></span>

<span style="margin-left: 2em">論曰壬辛丙角形與甲丙乙角形相似丁己壬角形</span>  
<span style="margin-left: 2em">與乙丁甲角形相似于壬己減壬辛甲丁減甲丙則</span>  
<span style="margin-left: 2em">丁丙與己辛相似</span>

<span style="margin-left: 2em">作子午線與丁戊平行截辛丁線<sub class="note-yuan">即辛丙</sub>于子遇己丁</span>  
<span style="margin-left: 2em">線于午成子午丁角形與丁丙乙角形相似則子午</span>  
<span style="margin-left: 8em">與子丁若丁丙與丙乙或矩面外作</span>  
<span style="margin-left: 8em">辛庚線與丁戊平行則庚辛丁形與</span>  
<span style="margin-left: 8em">乙丁丙形相似是庚辛與辛丁若丁</span>  
<span style="margin-left: 8em">丙與丙乙次求辛丁線法以辛戊戊</span>  
<span style="margin-left: 8em">丁各自之并而開方得所求次求辛</span>  
<span style="margin-left: 8em">庚線法己戊與戊丁若辛己與辛庚</span>  
<span style="margin-left: 8em">爲丁己戊辛己庚兩直角形有庚丁</span>

<span style="margin-left: 2em">平行線內相對之兩角等辛子午辛丙壬兩角等<sub class="note-yuan">在平</sub></span>

<span style="margin-left: 1em">望高測遠</span>  
<span style="margin-left: 6em">一支平面上有餘地　一法曰甲乙爲山</span>  
<span style="margin-left: 6em">或樓臺而直線不能至甲欲借乙頂測丙</span>  
<span style="margin-left: 6em">與甲相距之遠則於丙上置象限定角度</span>  
<span style="margin-left: 6em">却從丙到丁得若干步置象限定角度乙</span>  
<span style="margin-left: 2em">丙丁角形有丁丙邊丁丙兩角可求乙丙邊有乙丙</span>  
<span style="margin-left: 2em">邊而求甲丙邊法爲全數與乙丙邊若乙角之正弦</span>  
<span style="margin-left: 2em">與甲丙邊</span>

<span style="margin-left: 6em">三法曰丙外不能作直線則或左或右作</span>  
<span style="margin-left: 6em">丁丙乙直角行至丁置象限求作四十五</span>  
<span style="margin-left: 6em">度角即丙丁得三十一步又三十之二十</span>  
<span style="margin-left: 2em">三以乙丙爲全數丙丁爲丁乙丙角之切線丙甲爲</span>  
<span style="margin-left: 2em">甲乙丙角之正弦是丁丙切線與外丁丙之步數若</span>  
<span style="margin-left: 2em">丙甲正弦與外甲丙之步數</span>  
<span style="margin-left: 2em">四法省算丙上置象限定乙丙甲角六十四度退至</span>  
<span style="margin-left: 2em">丁定其角三十二度爲丙角之半却于地平面之丙</span>  
<span style="margin-left: 6em">丁線上作丙丁戊角與甲乙丙角等爲二</span>  
<span style="margin-left: 6em">十六度丁戊線上求戊作直角則丙戊之</span>

<span style="margin-left: 2em">若丁丙與丙甲</span>  
<span style="margin-left: 2em">論曰試從己作己戊線與午丁平行即午壬丁形<sub class="note-yuan">即午</sub></span>

<span style="margin-left: 7em">兩形亦相似己壬丁甲乙丁兩形亦相</span>  
<span style="margin-left: 7em">似夫戊己壬形之壬戊爲小甲丙己丁</span>  
<span style="margin-left: 7em">壬形之丁壬爲小丁甲丁壬之內減戊</span>

<span style="margin-left: 7em">午己與己壬既若丁戊與戊壬必若丁</span>
