## 崇祯历书卷之二十七　学历小辩

<span style="margin-left: 2em">学历小辩<sub class="note-jiao">校：據明刊梵蒂岡藏本爲底本</sub></span>  
<span style="margin-left: 1em">咨礼部文</span>  
<span style="margin-left: 2em">为恭</span>  
进历元以正历数等事准  
<span style="margin-left: 2em">礼部咨准通政司咨据保定府满城县玉山布衣魏</span>  
<span style="margin-left: 2em">文魁为前事具疏令伊男魏象乾赍捧历元一部到</span>  
<span style="margin-left: 2em">司看得魏文魁虽云考正历法然未经试验不敢轻</span>  
<span style="margin-left: 2em">进</span>  
御览合咨考验等因到部相应转咨查照考验等因准此  
<span style="margin-left: 2em">看得满城县耆儒魏文魁知其名二十余年矣颇闻</span>  
<span style="margin-left: 2em">邢观察律历考多出其手近刻历测历元二书则功</span>  
<span style="margin-left: 2em">力识见加胜于前盖苦心力学之士无论一时草泽</span>  
<span style="margin-left: 2em">即百年来治历名家翘然自负借甚有声者所不逮</span>  
<span style="margin-left: 2em">也但事干</span>  
进奏银台谓未经考验不敢轻进良为有见而本儒身在  
<span style="margin-left: 2em">原籍无凭咨核姑就近刻二书及送到交食一单略</span>  
<span style="margin-left: 2em">举一二令再为商求务期画一徴前验后确与天合</span>  
<span style="margin-left: 2em">因而推歩成历不惟生平绩学可以自见本部亦得</span>  
<span style="margin-left: 2em">取资藉力以襄</span>  
大典矣百年绝绪非不欲速其成潜隐硕儒非不乐与其  
<span style="margin-left: 2em">善但与其奉</span>  
旨之后考究异同致稽  
<span style="margin-left: 2em">题覆不若计定于前应时报</span>  
命之为愈也辞句颇繁粘连别幅为此合咨  
<span style="margin-left: 1em">贵部希为查照转达施行须至咨者</span>  
<span style="margin-left: 2em">崇祯四年六月初一日</span>  
<span style="margin-left: 3em">计开</span>  
<span style="margin-left: 4em">一议交食据单开崇祯四年四月十五日夜望</span>  
<span style="margin-left: 5em">月食今考验食分则为密合加时后天一刻</span>  
<span style="margin-left: 5em">亦为亲近独二年五月朔日食监推三分二</span>  
<span style="margin-left: 5em">十四秒初亏已正三刻回回科推五分五十</span>  
<span style="margin-left: 5em">二秒初亏午初三刻临期实候得食止二分</span>  
<span style="margin-left: 5em">初亏巳正四刻与本部所据新法密合此改</span>  
<span style="margin-left: 5em">修之议所从起也今历测称三分九秒初亏</span>  
<span style="margin-left: 5em">巳初三刻则食多一分时先五刻历元称日</span>  
<span style="margin-left: 5em">食一分二十一秒初亏午初初刻则食少一</span>  
<span style="margin-left: 5em">分加时密合而两书自相违异食差将及二</span>  
<span style="margin-left: 5em">分加时不啻五刻此宜再加研察并将两术</span>  
<span style="margin-left: 5em">算草备细开报以凭查核务须追合天行方</span>  
<span style="margin-left: 5em">可议定成法以垂永久至今年十月朔监推</span>  
<span style="margin-left: 5em">日食二分六十四秒初亏未初一刻本局新</span>  
<span style="margin-left: 5em">法推食二分有奇初亏午正一刻而单开食</span>  
<span style="margin-left: 5em">止九十七秒初亏未初二刻则食少一分有</span>  
<span style="margin-left: 5em">奇加时后天五刻此法异同不须争论宜待</span>  
<span style="margin-left: 5em">临时候验疎密自见耳</span>  
<span style="margin-left: 4em">一议冬至据历测不用授时历加减岁实亦不</span>  
<span style="margin-left: 5em">用大统定用岁实而用金重修大明历小余</span>  
<span style="margin-left: 5em">二十四刻三十六分则各年冬至宜递加二</span>  
<span style="margin-left: 5em">十四刻三十六分方合古来成法今查历元</span>  
<span style="margin-left: 5em">称崇祯元年戊辰测己巳岁天正冬至得癸</span>  
<span style="margin-left: 5em">未日午正二刻崇祯三年庚午测辛未岁天</span>  
<span style="margin-left: 5em">正冬至得甲午日子正初刻两年之间实差</span>  
<span style="margin-left: 5em">四十九刻平分之得二十四刻五十分亦为</span>  
<span style="margin-left: 5em">密近但天启七年丁卯测戊辰岁天正冬至</span>  
<span style="margin-left: 5em">得戊寅日卯初二刻而前推己巳岁天正冬</span>  
<span style="margin-left: 5em">至得午正二刻则差二十九刻与小余不合</span>  
<span style="margin-left: 5em">者四刻六十四分两测两推必居一误矣所</span>  
<span style="margin-left: 5em">宜再加研究以求必合者也</span>  
<span style="margin-left: 5em">右二则略举目前易见之事欲须审定画一</span>  
<span style="margin-left: 5em">但山居既无仪器推测得此已属苦心今欲</span>  
<span style="margin-left: 5em">必求确合当于候台测验本部新局亦粗备</span>  
<span style="margin-left: 5em">一二可以审详或本儒年至未得辄便前来</span>  
<span style="margin-left: 5em">亦可令嗣子门生测量分数细加较算纵未</span>  
<span style="margin-left: 5em">能即合天行于自立之法自譔之书不宜参</span>  
<span style="margin-left: 5em">商矛盾以启驳正之端若临期果有疑义不</span>  
<span style="margin-left: 5em">妨实告本部共图剖析事关</span>  
<span style="margin-left: 1em">国典不至如往代历师珍其敝帚也再查二书中复有</span>  
<span style="margin-left: 5em">当极论者今略举数事如左计好学深思者</span>  
<span style="margin-left: 5em">必能豁然领悟不至厌其繁细也此事岂不</span>  
<span style="margin-left: 5em">繁不细可卤莽而得者哉</span>  
<span style="margin-left: 4em">其一岁实自汉以来代有减差至授时减为二</span>  
<span style="margin-left: 5em">十四分二十五秒依郭分百年消一今当为</span>  
<span style="margin-left: 5em">二十一分有奇而历元用杨级赵知微之三</span>  
<span style="margin-left: 5em">十六秒翻复骤加与郭法悬殊矣今详郭法</span>  
<span style="margin-left: 5em">寝次减率考古验今实非妄作决宜遵用而</span>  
<span style="margin-left: 5em">历元所用又似实测得之是以确然自信仍</span>  
<span style="margin-left: 5em">非臆说二义参差将何决定根寻究竟则皆</span>  
<span style="margin-left: 5em">是也又皆非也其中义据巧历茫然所宜极</span>  
<span style="margin-left: 5em">论者一</span>  
<span style="margin-left: 4em">其一句股弧矢历学之斧斤绳尺也每测皆寻</span>  
<span style="margin-left: 5em">弧背每算皆求弦矢而今历测中犹用围三</span>  
<span style="margin-left: 5em">径一开方求矢之法此之半径则六十度八</span>  
<span style="margin-left: 5em">十七分五十秒之通弦耳此而可用则六十</span>  
<span style="margin-left: 5em">度八十七分五十秒之弧与其通弦等乎半</span>  
<span style="margin-left: 5em">之则三十度四十三分七十五秒之弧又与</span>  
<span style="margin-left: 5em">其正弦等乎是术一误何所不误所宜极论</span>  
<span style="margin-left: 5em">者二</span>  
<span style="margin-left: 4em">其一冬夏二至不为盈缩之定限今考日躔春</span>  
<span style="margin-left: 5em">分迄夏至夏至迄秋分此两限中日时刻不</span>  
<span style="margin-left: 5em">等又立春迄立夏立秋迄立冬此两限中日</span>  
<span style="margin-left: 5em">时刻亦不等此皆测量易见推算易明之事</span>  
<span style="margin-left: 5em">则太阳盈缩之实限宜在夏冬二至之后而</span>  
<span style="margin-left: 5em">各有时日刻分代有长消加减所宜极论者</span>  
<span style="margin-left: 5em">三</span>  
<span style="margin-left: 4em">其一旧历言太阴最高得疾最低得迟且以圭</span>  
<span style="margin-left: 5em">表测而得之非也太阴迟疾是入转内事表</span>  
<span style="margin-left: 5em">测高下是入交内事若云交即是转缘何交</span>  
<span style="margin-left: 5em">终转终两率互异既是二法岂容混推以交</span>  
<span style="margin-left: 5em">道之高下为转率之迟疾也交转既是二行</span>  
<span style="margin-left: 5em">而月行转周之上又复左旋所以最高向西</span>  
<span style="margin-left: 5em">行则极迟最低向东行乃极疾正与旧法相</span>  
<span style="margin-left: 5em">反五星高下迟疾亦皆准此所宜极论者四</span>  
<span style="margin-left: 4em">其一日食法谓在正午则无时差非也时差言</span>  
<span style="margin-left: 5em">距非距赤道之午中乃距黄道限东西各九</span>  
<span style="margin-left: 5em">十度之正中也而黄道限之正中在午中前</span>  
<span style="margin-left: 5em">后有差至二十余度者若依正午加减乌能</span>  
<span style="margin-left: 5em">必合所宜极论者五</span>  
<span style="margin-left: 4em">其一交食限定为阴历距交八度阳历距交六</span>  
<span style="margin-left: 5em">度亦非也本局考定阴历当十七度阳历当</span>  
<span style="margin-left: 5em">八度月食则定限南北各十二度所宜极论</span>  
<span style="margin-left: 5em">者六</span>  
<span style="margin-left: 4em">其一历测云宋文帝元嘉六年十一月己丑朔</span>  
<span style="margin-left: 5em">日食不尽如钩昼星见今以郭氏授时历推</span>  
<span style="margin-left: 5em">之止食六分九十六秒郭历舛矣不知所谓</span>  
<span style="margin-left: 5em">舛者何也若郭历果推得不尽如钩昼星见</span>  
<span style="margin-left: 5em">则真舛耳今云六分九十六秒乃是密合非</span>  
<span style="margin-left: 5em">舛也夫月食天下皆同日食九服皆异前史</span>  
<span style="margin-left: 5em">类能言之南宋都于金陵郭历造于燕中相</span>  
<span style="margin-left: 5em">去三千里北极出地差八度日食分数宜有</span>  
<span style="margin-left: 5em">异同矣其云不尽如钩当在九分左右而极</span>  
<span style="margin-left: 5em">差八度时在十一月则食差当得二分弱郭</span>  
<span style="margin-left: 5em">历当得七分弱非密合而何本局今定日食</span>  
<span style="margin-left: 5em">分数首言交次言地次言时一不可阙所宜</span>  
<span style="margin-left: 5em">极论者七</span>  
<span style="margin-left: 5em">右七则因本书所有略引其端事颇赜隐更</span>  
<span style="margin-left: 5em">仆未罄此外有当论定者不止百数必欲集</span>  
<span style="margin-left: 5em">成大业固当一一讲究勒为全书令传习者</span>  
<span style="margin-left: 5em">洞晓其法可以随试辄效后来者通知其意</span>  
<span style="margin-left: 5em">可以因时改革或复墨守其说则各就本法</span>  
<span style="margin-left: 5em">自成一家之言以待天验以质公评斯亦前</span>  
<span style="margin-left: 5em">朝之恒事无足为嫌者也</span>  
<span style="margin-left: 2em">贵局二议七论其中有是非二字谨领教略答一二</span>  
<span style="margin-left: 11em">满城玉山布衣魏文魁</span>  
<span style="margin-left: 2em">一议交食据崇祯四年四月十五日月食<sub class="note-yuan">魁</sub>以第二</span>  
<span style="margin-left: 2em">男魏星乾第二孙魏理漕候漏测验　本县县尹葛</span>  
<span style="margin-left: 2em">允升县学生员张尔翥同测验　蠡县人甲午举人</span>  
<span style="margin-left: 2em">贾讷己未进士王行健测验三处测得食既生光刻</span>  
<span style="margin-left: 2em">分<sub class="note-yuan">魁</sub>以法推得分秒以著历元乞</span>  
<span style="margin-left: 2em">贵局大方家更正咨云独崇祯二年五月乙酉朔日</span>  
<span style="margin-left: 2em">食历测称三分九秒初亏巳初三刻是刊书者误也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">魁</sub>之原稿所存日食一分三十九秒复圆午初三刻</span>  
<span style="margin-left: 2em">将日食分秒作成定用倍而减之初亏自见临时测</span>  
<span style="margin-left: 2em">验数处报来及礼部有闻各著历元乞</span>  
<span style="margin-left: 2em">贵局更正</span>  
<span style="margin-left: 2em">一议冬至据历测不用加减岁实亦不用大统岁实</span>  
<span style="margin-left: 2em">而用金重修大明历岁实非余用也原是授时历大</span>  
<span style="margin-left: 2em">统历四余用也</span>  
<span style="margin-left: 2em">贵局不查疑余用之余之所用岁实者不假思索皆</span>  
<span style="margin-left: 2em">从天得历元著明千载合天不谬真而不伪谅之谅</span>  
<span style="margin-left: 2em">之咨单中又云或本儒未得辄便前来斯言过也<sub class="note-yuan">魁</sub></span>  
<span style="margin-left: 2em">疏潜隐未上历元未进</span>  
皇上不知下落何处未奉  
旨议并无召命私自来  
<span style="margin-left: 1em">京惹人哂耻而来何为耶</span>  
<span style="margin-left: 2em">其一岁实自汉以来代有减差至授时历减为二十</span>  
<span style="margin-left: 2em">四刻二十五分是郭守敬自言自大明壬寅岁距至</span>  
<span style="margin-left: 2em">元辛巳岁八百一十九年以积年而一积日得岁实</span>  
<span style="margin-left: 2em">非减而得之也守敬只有这一长处其月策转终交</span>  
<span style="margin-left: 2em">终交泛等并皆仍旧矣百年消长各一决不可用历</span>  
<span style="margin-left: 2em">元不从用杨级赵知微之三十六分历元妙而神术</span>  
<span style="margin-left: 2em">人何得知耶郭守敬法考古验今真是妄作决不可</span>  
<span style="margin-left: 2em">遵用如是遵用</span>  
<span style="margin-left: 2em">贵局遵用在<sub class="note-yuan">魁</sub>不然何谓也守敬云自大明壬寅岁</span>  
<span style="margin-left: 2em">来壬寅岁天正冬至乙酉日夜半后三十二刻祖冲</span>  
<span style="margin-left: 2em">之立表所测守敬用百年消长推之得甲午日八十</span>  
<span style="margin-left: 2em">刻失一日二十四刻守敬云天道有失行是天失行</span>  
<span style="margin-left: 2em">邪是人之法失行邪而百年消长遵是乎非乎<sub class="note-yuan">魁</sub>用</span>  
<span style="margin-left: 2em">众君子所测今年崇祯四年辛未岁天正冬至甲午</span>  
<span style="margin-left: 2em">日夜半后五十分为应上距大明壬寅岁一千一百</span>  
<span style="margin-left: 2em">六十九年乘岁实三百六十五日二十四刻二十七</span>  
<span style="margin-left: 2em">分得中积减气应以甲子去之余以减甲子得乙酉</span>  
<span style="margin-left: 2em">日二十九刻天正冬至与天合又以授时至元辛巳</span>  
<span style="margin-left: 2em">三百五十年乘岁实得中积减气应以甲子去之余</span>  
<span style="margin-left: 2em">以减甲子得己未日夜半后六刻冬至与天合</span>  
<span style="margin-left: 2em">其一句股弧矢历学之斧斤绳尺也犹用围三径一</span>  
<span style="margin-left: 2em">是术一误何所不误</span>  
<span style="margin-left: 2em">贵局责误者不责其源清而责流浊余历测历元所</span>  
<span style="margin-left: 2em">著句股弧矢三乘之术以误三百五十余年误起于</span>  
<span style="margin-left: 2em">元翰林学士知制诰同修国史栾城李冶其后太史</span>  
<span style="margin-left: 2em">令郭守敬遵而用之既然围三径一之误必也用太</span>  
<span style="margin-left: 2em">一之文三而一二一三之数也弧矢割圆三乘之误</span>  
<span style="margin-left: 2em">贵局定有良见著为书何如使<sub class="note-yuan">魏</sub>收入历元以传后</span>

<span style="margin-left: 1em">一治历者先立历元定四应分各策皆平行数耳欲求</span>

<span style="margin-left: 2em">合于天行焉有不合者更测更算必合乃已此非一</span>

<span style="margin-left: 2em">根极理要推寻事验孰戴就祖尚未知所定抑何言</span>  
<span style="margin-left: 2em">之易耶法兴所说持之有故不遇正术固自斐然恐</span>

<span style="margin-left: 2em">者惟处士所测遂无一合殆是任意揣摩非繇实测</span>

<span style="margin-left: 2em">先推九十七秒后来直云不食何也是日百司奏鼓</span>
