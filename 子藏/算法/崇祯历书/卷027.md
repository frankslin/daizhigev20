## 崇禎曆書卷之二十七　學歷小辯

<span style="margin-left: 2em">學歷小辯<sub class="note-jiao">校：據明刊梵蒂岡藏本爲底本</sub></span>  
<span style="margin-left: 1em">諮禮部文</span>  
<span style="margin-left: 2em">爲恭</span>  
進曆元以正曆數等事准  
<span style="margin-left: 2em">禮部咨准通政司咨據保定府滿城縣玉山布衣魏</span>  
<span style="margin-left: 2em">文魁爲前事具疏令伊男魏象乾賫捧曆元一部到</span>  
<span style="margin-left: 2em">司看得魏文魁雖云考正曆法然未經試驗不敢輕</span>  
<span style="margin-left: 2em">進</span>  
御覽合咨考驗等因到部相應轉咨查照考驗等因准此  
<span style="margin-left: 2em">看得滿城縣耆儒魏文魁知其名二十餘年矣頗聞</span>  
<span style="margin-left: 2em">邢觀察律曆考多出其手近刻曆測曆元二書則功</span>  
<span style="margin-left: 2em">力識見加勝於前蓋苦心力學之士無論一時草澤</span>  
<span style="margin-left: 2em">即百年来治曆名家翹然自負藉甚有聲者所不逮</span>  
<span style="margin-left: 2em">也但事干</span>  
進奏銀臺謂未經考驗不敢輕進良爲有見而本儒身在  
<span style="margin-left: 2em">原籍無憑咨核姑就近刻二書及送到交食一單略</span>  
<span style="margin-left: 2em">舉一二令再爲商求務期畫一徴前驗後確與天合</span>  
<span style="margin-left: 2em">因而推歩成曆不惟生平績學可以自見本部亦得</span>  
<span style="margin-left: 2em">取資藉力以襄</span>  
大典矣百年絕緒非不欲速其成潛隱碩儒非不樂與其  
<span style="margin-left: 2em">善但與其奉</span>  
旨之後考究異同致稽  
<span style="margin-left: 2em">題覆不若計定于前應時報</span>  
命之爲愈也辭句頗繁粘連別幅爲此合咨  
<span style="margin-left: 1em">貴部希爲查照轉達施行須至咨者</span>  
<span style="margin-left: 2em">崇禎四年六月初一日</span>  
<span style="margin-left: 3em">計開</span>  
<span style="margin-left: 4em">一議交食據單開崇禎四年四月十五日夜望</span>  
<span style="margin-left: 5em">月食今考驗食分則爲密合加時後天一刻</span>  
<span style="margin-left: 5em">亦爲親近獨二年五月朔日食監推三分二</span>  
<span style="margin-left: 5em">十四秒初虧已正三刻回回科推五分五十</span>  
<span style="margin-left: 5em">二秒初虧午初三刻臨期實候得食止二分</span>  
<span style="margin-left: 5em">初虧巳正四刻與本部所據新法密合此改</span>  
<span style="margin-left: 5em">修之議所從起也今曆測稱三分九秒初虧</span>  
<span style="margin-left: 5em">巳初三刻則食多一分時先五刻曆元稱日</span>  
<span style="margin-left: 5em">食一分二十一秒初虧午初初刻則食少一</span>  
<span style="margin-left: 5em">分加時密合而兩書自相違異食差將及二</span>  
<span style="margin-left: 5em">分加時不啻五刻此宜再加研察并將兩術</span>  
<span style="margin-left: 5em">算草備細開報以憑查核務須追合天行方</span>  
<span style="margin-left: 5em">可議定成法以垂永久至今年十月朔監推</span>  
<span style="margin-left: 5em">日食二分六十四秒初虧未初一刻本局新</span>  
<span style="margin-left: 5em">法推食二分有奇初虧午正一刻而單開食</span>  
<span style="margin-left: 5em">止九十七秒初虧未初二刻則食少一分有</span>  
<span style="margin-left: 5em">奇加時後天五刻此法異同不須爭論宜待</span>  
<span style="margin-left: 5em">臨時候驗疎密自見耳</span>  
<span style="margin-left: 4em">一議冬至據曆測不用授時曆加減歲實亦不</span>  
<span style="margin-left: 5em">用大統定用歲實而用金重修大明曆小餘</span>  
<span style="margin-left: 5em">二十四刻三十六分則各年冬至宜遞加二</span>  
<span style="margin-left: 5em">十四刻三十六分方合古来成法今查曆元</span>  
<span style="margin-left: 5em">稱崇禎元年戊辰測己巳歲天正冬至得癸</span>  
<span style="margin-left: 5em">未日午正二刻崇禎三年庚午測辛未歲天</span>  
<span style="margin-left: 5em">正冬至得甲午日子正初刻兩年之間實差</span>  
<span style="margin-left: 5em">四十九刻平分之得二十四刻五十分亦爲</span>  
<span style="margin-left: 5em">密近但天啓七年丁卯測戊辰歲天正冬至</span>  
<span style="margin-left: 5em">得戊寅日卯初二刻而前推己巳歲天正冬</span>  
<span style="margin-left: 5em">至得午正二刻則差二十九刻與小餘不合</span>  
<span style="margin-left: 5em">者四刻六十四分兩測兩推必居一誤矣所</span>  
<span style="margin-left: 5em">宜再加研究以求必合者也</span>  
<span style="margin-left: 5em">右二則略舉目前易見之事欲須審定畫一</span>  
<span style="margin-left: 5em">但山居既無儀器推測得此已屬苦心今欲</span>  
<span style="margin-left: 5em">必求確合當于候臺測驗本部新局亦粗備</span>  
<span style="margin-left: 5em">一二可以審詳或本儒年至未得輒便前来</span>  
<span style="margin-left: 5em">亦可令嗣子門生測量分數細加較算縱未</span>  
<span style="margin-left: 5em">能即合天行于自立之法自譔之書不宜參</span>  
<span style="margin-left: 5em">商矛盾以啓駁正之端若臨期果有疑義不</span>  
<span style="margin-left: 5em">妨實告本部共圖剖析事關</span>  
<span style="margin-left: 1em">國典不至如往代曆師珍其敝帚也再查二書中復有</span>  
<span style="margin-left: 5em">當極論者今略舉數事如左計好學深思者</span>  
<span style="margin-left: 5em">必能豁然領悟不至厭其繁細也此事豈不</span>  
<span style="margin-left: 5em">繁不細可鹵莽而得者哉</span>  
<span style="margin-left: 4em">其一歲實自漢以来代有減差至授時減爲二</span>  
<span style="margin-left: 5em">十四分二十五秒依郭分百年消一今當爲</span>  
<span style="margin-left: 5em">二十一分有奇而曆元用楊級趙知微之三</span>  
<span style="margin-left: 5em">十六秒翻復驟加與郭法懸殊矣今詳郭法</span>  
<span style="margin-left: 5em">寢次減率考古驗今實非妄作決宜遵用而</span>  
<span style="margin-left: 5em">曆元所用又似實測得之是以確然自信仍</span>  
<span style="margin-left: 5em">非臆說二義參差將何決定根尋究竟則皆</span>  
<span style="margin-left: 5em">是也又皆非也其中義據巧曆茫然所宜極</span>  
<span style="margin-left: 5em">論者一</span>  
<span style="margin-left: 4em">其一句股弧矢曆學之斧斤繩尺也每測皆尋</span>  
<span style="margin-left: 5em">弧背每算皆求弦矢而今曆測中猶用圍三</span>  
<span style="margin-left: 5em">徑一開方求矢之法此之半徑則六十度八</span>  
<span style="margin-left: 5em">十七分五十秒之通弦耳此而可用則六十</span>  
<span style="margin-left: 5em">度八十七分五十秒之弧與其通弦等乎半</span>  
<span style="margin-left: 5em">之則三十度四十三分七十五秒之弧又與</span>  
<span style="margin-left: 5em">其正弦等乎是術一誤何所不誤所宜極論</span>  
<span style="margin-left: 5em">者二</span>  
<span style="margin-left: 4em">其一冬夏二至不爲盈縮之定限今考日躔春</span>  
<span style="margin-left: 5em">分迄夏至夏至迄秋分此兩限中日時刻不</span>  
<span style="margin-left: 5em">等又立春迄立夏立秋迄立冬此兩限中日</span>  
<span style="margin-left: 5em">時刻亦不等此皆測量易見推算易明之事</span>  
<span style="margin-left: 5em">則太陽盈縮之實限宜在夏冬二至之後而</span>  
<span style="margin-left: 5em">各有時日刻分代有長消加減所宜極論者</span>  
<span style="margin-left: 5em">三</span>  
<span style="margin-left: 4em">其一舊曆言太陰最高得疾最低得遲且以圭</span>  
<span style="margin-left: 5em">表測而得之非也太陰遲疾是入轉內事表</span>  
<span style="margin-left: 5em">測高下是入交內事若云交即是轉緣何交</span>  
<span style="margin-left: 5em">終轉終兩率互異既是二法豈容混推以交</span>  
<span style="margin-left: 5em">道之高下爲轉率之遲疾也交轉既是二行</span>  
<span style="margin-left: 5em">而月行轉周之上又復左旋所以最高向西</span>  
<span style="margin-left: 5em">行則極遲最低向東行乃極疾正與舊法相</span>  
<span style="margin-left: 5em">反五星高下遲疾亦皆准此所宜極論者四</span>  
<span style="margin-left: 4em">其一日食法謂在正午則無時差非也時差言</span>  
<span style="margin-left: 5em">距非距赤道之午中乃距黃道限東西各九</span>  
<span style="margin-left: 5em">十度之正中也而黃道限之正中在午中前</span>  
<span style="margin-left: 5em">後有差至二十餘度者若依正午加減烏能</span>  
<span style="margin-left: 5em">必合所宜極論者五</span>  
<span style="margin-left: 4em">其一交食限定爲陰曆距交八度陽曆距交六</span>  
<span style="margin-left: 5em">度亦非也本局考定陰曆當十七度陽曆當</span>  
<span style="margin-left: 5em">八度月食則定限南北各十二度所宜極論</span>  
<span style="margin-left: 5em">者六</span>  
<span style="margin-left: 4em">其一曆測云宋文帝元嘉六年十一月己丑朔</span>  
<span style="margin-left: 5em">日食不盡如鈎晝星見今以郭氏授時曆推</span>  
<span style="margin-left: 5em">之止食六分九十六秒郭曆舛矣不知所謂</span>  
<span style="margin-left: 5em">舛者何也若郭曆果推得不盡如鉤晝星見</span>  
<span style="margin-left: 5em">則真舛耳今云六分九十六秒乃是密合非</span>  
<span style="margin-left: 5em">舛也夫月食天下皆同日食九服皆異前史</span>  
<span style="margin-left: 5em">類能言之南宋都于金陵郭曆造于燕中相</span>  
<span style="margin-left: 5em">去三千里北極出地差八度日食分數宜有</span>  
<span style="margin-left: 5em">異同矣其云不盡如鉤當在九分左右而極</span>  
<span style="margin-left: 5em">差八度時在十一月則食差當得二分弱郭</span>  
<span style="margin-left: 5em">曆當得七分弱非密合而何本局今定日食</span>  
<span style="margin-left: 5em">分數首言交次言地次言時一不可闕所宜</span>  
<span style="margin-left: 5em">極論者七</span>  
<span style="margin-left: 5em">右七則因本書所有略引其端事頗賾隱更</span>  
<span style="margin-left: 5em">僕未罄此外有當論定者不止百數必欲集</span>  
<span style="margin-left: 5em">成大業固當一一講究勒爲全書令傳習者</span>  
<span style="margin-left: 5em">洞曉其法可以隨試輒效後来者通知其意</span>  
<span style="margin-left: 5em">可以因時改革或復墨守其說則各就本法</span>  
<span style="margin-left: 5em">自成一家之言以待天驗以質公評斯亦前</span>  
<span style="margin-left: 5em">朝之恒事無足爲嫌者也</span>  
<span style="margin-left: 2em">貴局二議七論其中有是非二字謹領教略答一二</span>  
<span style="margin-left: 11em">滿城玉山布衣魏文魁</span>  
<span style="margin-left: 2em">一議交食據崇禎四年四月十五日月食<sub class="note-yuan">魁</sub>以第二</span>  
<span style="margin-left: 2em">男魏星乾第二孫魏理漕候漏測驗　本縣縣尹葛</span>  
<span style="margin-left: 2em">允升縣學生員張爾翥同測驗　蠡縣人甲午舉人</span>  
<span style="margin-left: 2em">賈訥己未進士王行健測驗三處測得食既生光刻</span>  
<span style="margin-left: 2em">分<sub class="note-yuan">魁</sub>以法推得分秒以著曆元乞</span>  
<span style="margin-left: 2em">貴局大方家更正咨云獨崇禎二年五月乙酉朔日</span>  
<span style="margin-left: 2em">食曆測稱三分九秒初虧巳初三刻是刊書者誤也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">魁</sub>之原稿所存日食一分三十九秒復圓午初三刻</span>  
<span style="margin-left: 2em">將日食分秒作成定用倍而減之初虧自見臨時測</span>  
<span style="margin-left: 2em">驗數處報来及禮部有聞各著曆元乞</span>  
<span style="margin-left: 2em">貴局更正</span>  
<span style="margin-left: 2em">一議冬至據曆測不用加減歲實亦不用大統歲實</span>  
<span style="margin-left: 2em">而用金重修大明曆歲實非余用也原是授時曆大</span>  
<span style="margin-left: 2em">統曆四餘用也</span>  
<span style="margin-left: 2em">貴局不查疑余用之余之所用歲實者不假思索皆</span>  
<span style="margin-left: 2em">從天得曆元著明千載合天不謬真而不偽諒之諒</span>  
<span style="margin-left: 2em">之咨單中又云或本儒未得輒便前来斯言過也<sub class="note-yuan">魁</sub></span>  
<span style="margin-left: 2em">疏潜隱未上曆元未進</span>  
皇上不知下落何處未奉  
旨議並無召命私自来  
<span style="margin-left: 1em">京惹人哂耻而来何爲耶</span>  
<span style="margin-left: 2em">其一歲實自漢以来代有減差至授時曆減爲二十</span>  
<span style="margin-left: 2em">四刻二十五分是郭守敬自言自大明壬寅歲距至</span>  
<span style="margin-left: 2em">元辛巳歲八百一十九年以積年而一積日得歲實</span>  
<span style="margin-left: 2em">非減而得之也守敬只有這一長處其月策轉終交</span>  
<span style="margin-left: 2em">終交泛等並皆仍舊矣百年消長各一決不可用曆</span>  
<span style="margin-left: 2em">元不從用楊級趙知微之三十六分曆元妙而神術</span>  
<span style="margin-left: 2em">人何得知耶郭守敬法考古驗今真是妄作決不可</span>  
<span style="margin-left: 2em">遵用如是遵用</span>  
<span style="margin-left: 2em">貴局遵用在<sub class="note-yuan">魁</sub>不然何謂也守敬云自大明壬寅歲</span>  
<span style="margin-left: 2em">来壬寅歲天正冬至乙酉日夜半後三十二刻祖冲</span>  
<span style="margin-left: 2em">之立表所測守敬用百年消長推之得甲午日八十</span>  
<span style="margin-left: 2em">刻失一日二十四刻守敬云天道有失行是天失行</span>  
<span style="margin-left: 2em">邪是人之法失行邪而百年消長遵是乎非乎<sub class="note-yuan">魁</sub>用</span>  
<span style="margin-left: 2em">衆君子所測今年崇禎四年辛未歲天正冬至甲午</span>  
<span style="margin-left: 2em">日夜半後五十分爲應上距大明壬寅歲一千一百</span>  
<span style="margin-left: 2em">六十九年乘歲實三百六十五日二十四刻二十七</span>  
<span style="margin-left: 2em">分得中積減氣應以甲子去之餘以減甲子得乙酉</span>  
<span style="margin-left: 2em">日二十九刻天正冬至與天合又以授時至元辛巳</span>  
<span style="margin-left: 2em">三百五十年乘歲實得中積減氣應以甲子去之餘</span>  
<span style="margin-left: 2em">以減甲子得己未日夜半後六刻冬至與天合</span>  
<span style="margin-left: 2em">其一句股弧矢歷學之斧斤繩尺也猶用圍三徑一</span>  
<span style="margin-left: 2em">是術一誤何所不誤</span>  
<span style="margin-left: 2em">貴局責誤者不責其源清而責流濁余曆測曆元所</span>  
<span style="margin-left: 2em">著句股弧矢三乘之術以誤三百五十餘年誤起於</span>  
<span style="margin-left: 2em">元翰林學士知制誥同修國史欒城李冶其後太史</span>  
<span style="margin-left: 2em">令郭守敬遵而用之既然圍三徑一之誤必也用太</span>  
<span style="margin-left: 2em">一之文三而一二一三之數也弧矢割圓三乘之誤</span>  
<span style="margin-left: 2em">貴局定有良見著爲書何如使<sub class="note-yuan">魏</sub>收入曆元以傳後</span>  
<span style="margin-left: 2em">世</span>  
<span style="margin-left: 2em">其一冬夏二至不爲盈縮之定限殊不知冬至盈初</span>  
<span style="margin-left: 2em">夏至縮初春分前二日四十刻秋分後二日四十刻</span>  
<span style="margin-left: 2em">盈縮遞換即爲末限二日四十刻者自平立定三差</span>  
<span style="margin-left: 2em">而来曰極差</span>  
<span style="margin-left: 2em">其一太陰而用圭表所測是真遲疾者何云非非也</span>  
<span style="margin-left: 2em">夫測太陽二至前後晷景年年有之矣若測太陰高</span>  
<span style="margin-left: 2em">低晷刻有年有月非測太陽之比也非是年是月不</span>  
<span style="margin-left: 2em">得測驗四年半測高四年半測低九年一率遲疾一</span>  
<span style="margin-left: 2em">更自劉洪粗知而不知平立有差今以尖圓法得平</span>  
<span style="margin-left: 2em">立定三差盈縮遲疾咸備在曆元卷之三天啓癸亥</span>  
<span style="margin-left: 2em">歲日低月高之會測法細錄報</span>  
<span style="margin-left: 2em">貴局查之</span>  
<span style="margin-left: 2em">其一日食法謂在正午則無時差是也非非也所謂</span>  
<span style="margin-left: 2em">時差者言旦夕也不言距度也食在夕者酉初一刻</span>  
<span style="margin-left: 2em">時差多定朔小餘必是七十二刻時差六刻有奇日</span>  
<span style="margin-left: 2em">食在晨刻者卯正三刻定朔小餘必是二十八刻時</span>  
<span style="margin-left: 2em">差六刻有奇日食在午正初刻者定朔小餘必是五</span>  
<span style="margin-left: 2em">十刻不知時差自何而来在曆元卷之二交食元中</span>  
<span style="margin-left: 2em">講之甚明</span>  
<span style="margin-left: 2em">貴局非也是孰非邪以定朔小餘五十刻問司曆氏</span>  
<span style="margin-left: 2em">時差幾何渠止會推數不明曆理待報自知也</span>  
<span style="margin-left: 2em">其一日食限定爲陰曆距交八度陽曆距交六度亦</span>  
<span style="margin-left: 2em">是也非非也陰陽過此限不食且如宋仁宗天聖二</span>  
<span style="margin-left: 2em">年甲子歲五月丁亥朔曆官報當午日食五分有奇</span>  
<span style="margin-left: 2em">候之不食以諸曆推算皆食五分有奇授時曆推之</span>  
<span style="margin-left: 2em">亦然郭守敬云天道失行以<sub class="note-yuan">魁</sub>之術推之是日得陰</span>  
<span style="margin-left: 2em">曆八度三分果然不食嗟嗟歷代無一人知曆數湮</span>  
<span style="margin-left: 2em">沒至今不亦傷乎今</span>  
<span style="margin-left: 2em">貴局定陰曆當十七度陽曆當八度月食則定限南</span>  
<span style="margin-left: 2em">北各十二度此夷外之曆學非中國之有也<sub class="note-yuan">魁</sub>不可</span>  
<span style="margin-left: 2em">得而知之也何謂也言陰曆定限八度陽曆定限六</span>  
<span style="margin-left: 2em">度者是距交前後二度相並也自陰陽八度六度之</span>  
<span style="margin-left: 2em">前後漸漸而寛寛至六度弱漸漸而窄窄至距交陰</span>  
<span style="margin-left: 2em">八陽六二度相並乃會食之所也弧矢三乘尖圓之</span>  
<span style="margin-left: 2em">法正謂此云</span>  
<span style="margin-left: 2em">其一曆測云劉宋文帝元嘉六年己巳歲十一月己</span>  
<span style="margin-left: 2em">丑朔日食不盡如鉤晝星見河北地盡暗黑如夜秦</span>  
<span style="margin-left: 2em">中地震</span>  
<span style="margin-left: 2em">貴局言南宋都金陵三千里郭曆造於燕去河北止</span>  
<span style="margin-left: 2em">千里非三千里不可辯論何謂也</span>  
<span style="margin-left: 2em">貴局報今年四月十五日夜望月食朝鮮虧時與山</span>  
<span style="margin-left: 2em">西太原府同則可知矣夫北極出地南北異東西同</span>  
<span style="margin-left: 2em">求日出日入則可而南北日出入異異者北極出地</span>  
<span style="margin-left: 2em">高下之故也東西雖同者謂日出卯日入酉也若交</span>  
<span style="margin-left: 2em">食時刻相同則不然夫交食者或當交或交之前後</span>  
<span style="margin-left: 2em">移刻則交過之而日躔月離去交遠矣如陕西臨洮</span>  
<span style="margin-left: 2em">蘭州河州等處西去上谷纔五千餘里日在酉時帶</span>  
<span style="margin-left: 2em">食此處在天復圓朝鮮王京東去上谷五千餘里上</span>  
<span style="margin-left: 2em">谷西距太原又四百餘里北極出地雖同是言日之</span>  
<span style="margin-left: 2em">出入與交不干假如西域巳時即中國未時也如是</span>  
<span style="margin-left: 2em">日月有食定巳時邪定未時邪欲修曆數必也數理</span>  
<span style="margin-left: 2em">明達方任其事余觀</span>  
<span style="margin-left: 2em">貴局多曆理明達者乎諺云水深丈探人深語激是</span>  
<span style="margin-left: 2em">也是也</span>  
<span style="margin-left: 3em">與王廷評答客難</span>  
<span style="margin-left: 2em">昨傳来魏處士答問語已悉當須更一辨正否古云</span>  
<span style="margin-left: 2em">有爭氣者勿與言也又曰不直則道不見酌於言不</span>  
<span style="margin-left: 2em">言之間採該局所論次者略節數語開其未悟望致</span>  
<span style="margin-left: 2em">之若更有辨論能依名理雖十往返可也</span>  
<span style="margin-left: 1em">一崇禎二年五月朔日食據云刻書者誤也然原稿未</span>  
<span style="margin-left: 2em">誤者云食一分三十九秒亦恐未確蓋日食之難苦</span>  
<span style="margin-left: 2em">于陽精晃耀每先食而後見月食之難苦于游景紛</span>  
<span style="margin-left: 2em">侵每先見而後食故日食一分以下非人目所能見</span>  
<span style="margin-left: 2em">臺官類能言之是日果食一分三十九秒則所見者</span>  
<span style="margin-left: 2em">極微矣而通都共覩實不止一分三十九秒也今年</span>  
<span style="margin-left: 2em">十月朔密室所候將及二分而外間所見止一分以</span>  
<span style="margin-left: 2em">上此足下所目覩非其明效也</span>  
<span style="margin-left: 1em">一歲實小餘三十六分據云此趙知微重修大明曆四</span>  
<span style="margin-left: 2em">餘所用授時大統皆仍之處士亦仍之則三十六分</span>  
<span style="margin-left: 2em">特用之四餘不用之氣朔邪豈四餘氣朔當有兩歲</span>  
<span style="margin-left: 2em">實耶不知五星之歲實又與氣朔四餘同耶異耶處</span>  
<span style="margin-left: 2em">士自云所用歲實不假思索皆從天得此疑實測所</span>  
<span style="margin-left: 2em">定果亦近之然何不少費思索并定一五星四餘畫</span>  
<span style="margin-left: 2em">一不爽之歲實乃猶仍金元諸人之舊也咨單中言</span>  
<span style="margin-left: 2em">或本儒年至未得輒便前来者謂其高年儻未得来</span>  
<span style="margin-left: 2em">當遣子弟代之此正欲其来不得已命其子弟耳若</span>  
<span style="margin-left: 2em">曰拒之使不来曷不并拒其子弟耶文理自明再繹</span>  
<span style="margin-left: 2em">之</span>  
<span style="margin-left: 1em">一歲實加減小餘自漢四分曆定爲二十五分乾象曆</span>  
<span style="margin-left: 2em">減爲二四六一八〇南宋大明曆又減爲二四二八</span>  
<span style="margin-left: 2em">一四宋統天曆元授時曆又減爲二四二五其間七</span>  
<span style="margin-left: 2em">十餘家互有加損總計之則自漢至今皆以漸減也</span>  
<span style="margin-left: 2em">彼皆實測實算以爲當然烏得謂元以後遂不應復</span>  
<span style="margin-left: 2em">減耶郭云百年減一分三百五十年来應減三分五</span>  
<span style="margin-left: 2em">十秒當爲二十一分五十秒而該局所考正今之定</span>  
<span style="margin-left: 2em">用歲實乃是二十〇分四十八秒六十〇微即又不</span>  
<span style="margin-left: 2em">及百年而減一分明理著數亦猶行古之道也此則</span>  
<span style="margin-left: 2em">不知者聞之將大笑且駭以爲該局所推冬至時刻</span>  
<span style="margin-left: 2em">必且先天若干亦先大統若干而又不然如今歲推</span>  
<span style="margin-left: 2em">壬申年天正冬至大統得在十一月三十日己亥寅</span>  
<span style="margin-left: 2em">正一刻而局推在本年月日辰初一刻一十八分乃</span>  
<span style="margin-left: 2em">後于大統一十二刻用儀器數具前後測驗確與天</span>  
<span style="margin-left: 2em">合並無乖爽此爲何故平歲實非本年冬至可定真</span>  
<span style="margin-left: 2em">冬至時刻非歲實可推也此說甚長更僕未罄姑就</span>  
<span style="margin-left: 2em">所明通之處士亦知冬至時刻終古無定率乎果有</span>  
<span style="margin-left: 2em">定率則處士所定二十七分歲歲加增足矣何爲每</span>  
<span style="margin-left: 2em">測必差即曆元所測定二三年間便成參錯此其間</span>  
<span style="margin-left: 2em">得無諉之儀表未精測候未確不知果精果確乃真</span>  
<span style="margin-left: 2em">見其無定率矣蓋正歲年與步月離相似冬至無定</span>  
<span style="margin-left: 2em">率與定朔定望無定率一也朔望無定率宜以平朔</span>  
<span style="margin-left: 2em">望加減之冬至無定率宜以平年加減之若郭太史</span>  
<span style="margin-left: 2em">所增減之歲實者平年也故新法之平冬至或在大</span>  
<span style="margin-left: 2em">統前或在後其定冬至恒在大統後也此法一經道</span>  
<span style="margin-left: 2em">破達者自能豁然但欲窮究其理非虛心定意經歷</span>  
<span style="margin-left: 2em">歲時難可遽通耳</span>  
<span style="margin-left: 1em">一句股三乘術非誤也特徑一圍三不合耳既稱作者</span>  
<span style="margin-left: 2em">宜自爲清源以傳後世柰何沿前人之濁流耶弧與</span>  
<span style="margin-left: 2em">弦終古無相等之率無論古率徽率密率太一率即</span>  
<span style="margin-left: 2em">多分之至萬萬億猶是弦也否則周外之切線也且</span>  
<span style="margin-left: 2em">弧弦之術舉手即須每推一法當數四用之即依古</span>  
<span style="margin-left: 2em">率推演已覺大繁况徽密以上乎必若此者曆將卒</span>  
<span style="margin-left: 2em">世而不就矣該局既已言之安得無見又安得無書</span>  
<span style="margin-left: 2em">第所傳之書有論說有立成有通率都爲一十六卷</span>  
<span style="margin-left: 2em">八十餘萬言以入曆元得無本末不相稱耶此書爲</span>  
<span style="margin-left: 2em">用甚大故名大測自當孤行于世待知者用之譬如</span>  
<span style="margin-left: 2em">崇臺九成延袤百丈而不混者或未可寄人廡下也</span>  
<span style="margin-left: 2em">老而好學誠往昔之美談然求人之術乃當以排抵</span>  
<span style="margin-left: 2em">爲羔鴈耶</span>  
<span style="margin-left: 1em">一舊法冬夏二至爲盈縮之定限今云否者古名曆家</span>  
<span style="margin-left: 2em">精詳測候見春分至立夏行四十五度有奇立秋至</span>  
<span style="margin-left: 2em">秋分亦行四十五度有奇其度分等而中間所曆時</span>  
<span style="margin-left: 2em">日不等又時日多寡世世不等因知日行最高度上</span>  
<span style="margin-left: 2em">古在夏至前今世在夏至後六度則夏至後六日乃</span>  
<span style="margin-left: 2em">真盈縮之限此即真冬至所自出矣第其說頗奥且</span>  
<span style="margin-left: 2em">賾非好學深思未易與之言也</span>  
<span style="margin-left: 1em">一論太陰遲疾用圭表得之夫太陽用二至前後表景</span>  
<span style="margin-left: 2em">推算在一二日內或亦近之若遠則所得者定非真</span>  
<span style="margin-left: 2em">率何况太陰但太陰之遲疾不在去地高庳去地高</span>  
<span style="margin-left: 2em">庳者交道也九年再測者亦非測太陰測月孛也月</span>  
<span style="margin-left: 2em">交東騖月轉西馳兩道違行是生月孛孛者悖也月</span>  
<span style="margin-left: 2em">轉至是則違天行故最遲也九年以內孛實行天一</span>  
<span style="margin-left: 2em">周四年半在高四年半在庳其測高測庳之月日太</span>  
<span style="margin-left: 2em">陰必與孛同度既得同度必是最遲豈因圭表所測</span>  
<span style="margin-left: 2em">去地高下爲其遲疾耶且孛則九年而一周月則二</span>  
<span style="margin-left: 2em">十七日有奇而一轉若洞悉交轉之義精探違順之</span>  
<span style="margin-left: 2em">理深明平自之率確審經緯之度即月月自有其遲</span>  
<span style="margin-left: 2em">疾日日可得其高下何必九年哉必九年乃得者則</span>  
<span style="margin-left: 2em">歲星須十二年填星須二十九年歲差須二萬五千</span>  
<span style="margin-left: 2em">餘年誰能待之</span>  
<span style="margin-left: 1em">一日食距午時差舊法以爲論時則定朔小餘五十刻</span>  
<span style="margin-left: 2em">是也本局以爲論度則黃道九十度限是也時與度</span>  
<span style="margin-left: 2em">有時而合有時而離有食在午中或近午左右而推</span>  
<span style="margin-left: 2em">算時刻乃不合天者其度限去午左右稍遠故也如</span>  
<span style="margin-left: 2em">今年十月朔日食午正而監推乃在未初回回曆在</span>  
<span style="margin-left: 2em">未正亦一證已</span>  
<span style="margin-left: 1em">一日食距交限定爲陰曆八度陽曆六度舊法也該局</span>  
<span style="margin-left: 2em">定爲陰曆十七度陽曆八度而云不然何不考今年</span>  
<span style="margin-left: 2em">十月朔日食甚距交幾度耶按是日食甚在未初一</span>  
<span style="margin-left: 2em">刻內五十一分本月十五日夜望月食甚在辰初一</span>  
<span style="margin-left: 2em">刻內一十三分兩食中積爲十四日七十三刻月食</span>  
<span style="margin-left: 2em">甚時過正交入陰曆一度依法推得日食甚時月未</span>  
<span style="margin-left: 2em">至中交十四度强而食及一分則初入食限豈非十</span>  
<span style="margin-left: 2em">七度乎何得定爲陰曆八度耶至宋仁宗天聖二年</span>  
<span style="margin-left: 2em">甲子歲五月丁亥朔曆官推當食不食司天奏日食</span>  
<span style="margin-left: 2em">不應中書奉表稱賀乃諸曆推算皆云當食以授時</span>  
<span style="margin-left: 2em">推之亦然夫于法則實當食而於時則實不食苟如</span>  
<span style="margin-left: 2em">宋臣之稱賀是罔上也如元人言日度失行是誣天</span>  
<span style="margin-left: 2em">也此事遂爲千古不決之疑今當何以解之按西曆</span>  
<span style="margin-left: 2em">日食有變差一法是日在陰曆距交十度强于法當</span>  
<span style="margin-left: 2em">食而獨此日此地之南北差變爲東西差故論天行</span>  
<span style="margin-left: 2em">則地心與日月兩心俱參直實不失食而從人目所</span>  
<span style="margin-left: 2em">見則日月相距近變爲遠實不得食顧獨汴京爲然</span>  
<span style="margin-left: 2em">若從汴以東數千里漸見食至東北一萬數千里則</span>  
<span style="margin-left: 2em">全見食也此術於日食法中最爲深賾推曆之難全</span>  
<span style="margin-left: 2em">在此等其說甚長已著該局所譔交食曆中未經</span>  
進呈不敢輕出然論曆至此果所謂得未曾有也古来當  
<span style="margin-left: 2em">食而不食者或推入限不真或夜食而誤爲晨夕皆</span>  
<span style="margin-left: 2em">不足論獨是年于法不誤而實不見食乃是百中一</span>  
<span style="margin-left: 2em">二變差法亦曆中玄指藉此一駁得爲闡明正如洪</span>  
<span style="margin-left: 2em">鐘在懸非因扣擊何從發其音聲哉處士一言謂之</span>  
<span style="margin-left: 2em">有功曆學可矣若陰曆八度三分已入限大半無緣</span>  
<span style="margin-left: 2em">得不食也</span>  
<span style="margin-left: 1em">一據答未後一條語意難明如云河北千里朝鮮虧時</span>  
<span style="margin-left: 2em">等不知何物若本部原咨則有二說一謂南北里差</span>  
<span style="margin-left: 2em">元史稱四海測驗二十七所大都北極出地四十度</span>  
<span style="margin-left: 2em">太强揚州三十三度今測得金陵三十二度半較差</span>  
<span style="margin-left: 2em">八度少加唐書每度三百五十里則二千九百餘里</span>  
<span style="margin-left: 2em">謬也如近法每度二百五十里則二千餘里爲其南</span>  
<span style="margin-left: 2em">北徑線加行路紆曲豈非三千里乎有里差則有食</span>

<span style="margin-left: 2em">去昭昭入冥冥誰能聽之哉</span>  
<span style="margin-left: 1em">一日食距交限學曆小辯中用崇禎四年十月兩食之</span>  
<span style="margin-left: 2em">數剖晰極明處士何惜一覽耶尚執陽六陰八之舊</span>  
<span style="margin-left: 2em">法以爲必然不易也夫陰曆十七度陽曆八度不自</span>  
<span style="margin-left: 2em">西法始大統曆亦然處士所抄纂者皆大統法也而</span>  
<span style="margin-left: 2em">于日食第三推亦未之見尤異矣今採錄如左</span>  
<span style="margin-left: 2em">大統曆推日食在正交中交限度法曰視其推得交</span>  
<span style="margin-left: 2em">定度全分如在七度以下或三百四十二度以上者</span>  
<span style="margin-left: 2em">皆爲食在正交</span>  
<span style="margin-left: 2em">依此則正交前七度正交後二十二度爲食限何者</span>  
<span style="margin-left: 2em">置三百四十二度以減全周三百六十四度餘二十</span>  
<span style="margin-left: 2em">二度則將滿全周二十二度入食限也</span>  
<span style="margin-left: 2em">又曰如在一百七十五度以上或二百零二度以下</span>  
<span style="margin-left: 2em">皆爲食在中交</span>  
<span style="margin-left: 2em">以上兩數相減得二十七度即中交前後兩食限并</span>  
<span style="margin-left: 2em">也又置一百七十五度以減半周一百八十二度餘</span>  
<span style="margin-left: 2em">七度與正交等又置半周一百八十二度以減二百</span>  
<span style="margin-left: 2em">〇二度餘二十〇度則中交前後兩食限爲七爲二</span>  
<span style="margin-left: 2em">十也</span>  
<span style="margin-left: 1em">一古稱義禮之家有如聚訟惟曆亦然顧惟曆家是非</span>  
<span style="margin-left: 2em">特爲易辨何者訟必決于證佐他證佐未足可信也</span>  
<span style="margin-left: 2em">曆以七政爲證佐無不可信者矣今欲追天以求決</span>  
<span style="margin-left: 2em">定乎小辨固云日日可推夜夜可驗但恐處士於恒</span>  
<span style="margin-left: 2em">星五星之學未能深入不應傲之以其所不知獨交</span>  
<span style="margin-left: 2em">食法其所侈言而来年甲戌歲適有三食處士亦推</span>  
<span style="margin-left: 2em">得復圓時刻特未詳耳儻必以已法爲是請與本局</span>
