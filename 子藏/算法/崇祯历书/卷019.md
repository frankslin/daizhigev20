<span style="margin-left: 2em">一辩遗漏紫气</span>  
<span style="margin-left: 3em">历家为司天天有形乃有象有象乃有理论述生</span>  
<span style="margin-left: 3em">马有象乃有数推算生焉苟无其象虽巧历不能</span>  
<span style="margin-left: 3em">违天创一理设一数也今称紫气有名而无星象</span>  
<span style="margin-left: 3em">夫既无其象矣理必并无数从何起明系后人无</span>  
<span style="margin-left: 3em">端妄增唐以前不闻其说即唐以后凡为正术者</span>  
<span style="margin-left: 3em">皆弃之弗录时宪历何得承讹存之其所载孛罗</span>  
<span style="margin-left: 3em">计皆指太阴行度非余气之说安得因载有理有</span>  
<span style="margin-left: 3em">数之孛罗计而并欲载无理无数之紫气乎且</span>  
<span style="margin-left: 2em">国家将兴必有祯祥天人相应之理诚然但因此而</span>  
<span style="margin-left: 3em">强援东方之白气以为紫气则又诬天甚矣至于</span>  
<span style="margin-left: 1em">人主之不尚杀自系修德行仁之验炫乃指为木德之</span>  
<span style="margin-left: 3em">验以征紫气之必有苟如其说则天下臣民安享</span>  
<span style="margin-left: 3em">恬熙皆不必感</span>  
<span style="margin-left: 1em">朝廷而感紫气而自古暴虐如桀纣皆得卸咎于紫气</span>  
<span style="margin-left: 3em">之无灵矣其说之舛谬岂得智者而辩哉</span>  
<span style="margin-left: 2em">一辩颠倒参觜</span>  
<span style="margin-left: 3em">天体如瓜两极如蒂近极度狭远极度宽此理人</span>  
<span style="margin-left: 3em">多知之又经星每岁浸渐东行岁差所由生也行</span>  
<span style="margin-left: 3em">当狭处则速行当宽处则迟迟之既久则原先者</span>

<span style="margin-left: 3em">测觜宿已侵入参宿二十四分此天行之必然毫</span>  
<span style="margin-left: 3em">无足讶者炫不考诸古不求诸天而妄以为颠倒</span>  
<span style="margin-left: 3em">果颠倒乎至若鬼宿今仍在柳宿之西二度有余</span>  
<span style="margin-left: 3em">安得与参觜同论夫历者历也按天行所历之数</span>

<span style="margin-left: 3em">星图刊行已久炫独未之见乎何不详考之图而</span>  
<span style="margin-left: 3em">信口放言也</span>  
<span style="margin-left: 2em">一辩颠倒罗计</span>  
<span style="margin-left: 3em">罗计新法皆指太阴行度而炫沿旧说谓罗为火</span>  
<span style="margin-left: 3em">之余气计为土之余气请得而辩之夫所谓余气</span>

<span style="margin-left: 3em">一星之气而占天九十度或百五十度有是理乎</span>
