## 崇禎曆書卷之十九　順治奏疏

*順治十四年三月二十八日至順治十四年十月二十九日*

<span style="margin-left: 2em">奏疏五</span>  
<span style="margin-left: 6em">順治十四年三月二十八日湯若望題本</span>  
<span style="margin-left: 1em">勅錫通微教師加二品頂帶通政使司通政使掌欽天</span>  
<span style="margin-left: 3em">監印務臣湯若望謹</span>  
<span style="margin-left: 2em">題爲遵</span>  
<span style="margin-left: 1em">旨復進時憲曆書事竊照時憲曆書於順治貳年拾貳</span>  
<span style="margin-left: 3em">月貳拾日進呈荷蒙</span>  
<span style="margin-left: 1em">皇上宣付史舘矣臣復纂簡要曆書壹套於拾叁年捌</span>  
<span style="margin-left: 3em">月拾肆日恭進奉</span>  
<span style="margin-left: 1em">旨知道了該部知道欽此本年貳月拾壹日蒙</span>  
<span style="margin-left: 1em">皇上面諭將先進曆書再進壹部留</span>  
<span style="margin-left: 1em">覧臣謹遵</span>  
<span style="margin-left: 1em">旨復將先後所進曆書裝演共成拾肆套恭呈</span>  
<span style="margin-left: 1em">御覧其簡要曆書伏祈</span>  
<span style="margin-left: 1em">皇上照前宣付史舘庶曆典彌光矣臣未敢擅便謹題</span>  
<span style="margin-left: 3em">請</span>  
<span style="margin-left: 1em">旨　順治拾肆年叄月貳拾捌日題肆月初捌日奉</span>  
<span style="margin-left: 1em">旨這復進前後曆書精詳可嘉着留覧其簡要曆書仍</span>  
<span style="margin-left: 2em">宣付史館該衙門知道</span>  
<span style="margin-left: 6em">順治十四年四月二十九日湯若望題本</span>  
<span style="margin-left: 1em">勅錫通微教師加二品頂帶通政使司通政使掌欽天</span>  
<span style="margin-left: 3em">監印務臣湯若望謹</span>  
<span style="margin-left: 2em">題爲曆與大定無容紊亂以滋紛囂事切照臣修政</span>  
<span style="margin-left: 3em">曆法在明季與大統交食回回交食登臺公同測</span>  
<span style="margin-left: 3em">驗已經十有七載而回回之疎遠尤甚舉國通知</span>  
<span style="margin-left: 3em">於順治元年八月初一日日食</span>  
<span style="margin-left: 2em">內院公同測驗大統曆差有一半回回曆差有一箇</span>  
<span style="margin-left: 3em">時辰新法密合定爲時憲頒行天下隨于本年十</span>  
<span style="margin-left: 3em">月內奉有回回科不許再報交食以亂新法之</span>  
<span style="margin-left: 1em">旨又于三年五月內奉有回回凌犯曆不必用之</span>  
<span style="margin-left: 1em">旨于九年五月內又奉</span>  
<span style="margin-left: 1em">上傳回回科不必再報夏季天象自此姑容在監虛糜</span>  
<span style="margin-left: 3em">廪祿毫無職司而吳明炫遂于十一年三月內私</span>  
<span style="margin-left: 3em">自回籍禮部題參奉</span>  
<span style="margin-left: 1em">旨革職于去歲來京希圖復進擅報交食天象妄揣水</span>  
<span style="margin-left: 3em">星見伏冒凟</span>  
<span style="margin-left: 1em">天聽如使其法之果密何不爭于臣修曆之始與我朝</span>  
<span style="margin-left: 2em">定曆之初既已疎遠于前豈能符合于後理勢之所</span>  
<span style="margin-left: 3em">必無也明係紊亂新法有干律紀且臣之新法屢</span>  
<span style="margin-left: 3em">測脗合幸蒙我</span>  
<span style="margin-left: 2em">朝洞鑒特用今經十有四載並無異議突有吳明炫</span>  
<span style="margin-left: 3em">以革職之人報疎遠之法欲圖倖進恣意溷淆曆</span>  
<span style="margin-left: 3em">典攸關恐非</span>  
<span style="margin-left: 1em">盛朝之所宜有也仰祈</span>  
<span style="margin-left: 1em">乾斷以杜囂爭臣未敢擅便謹題請</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 3em">順治十四年四月二十九日具題五月初一日奉</span>  
<span style="margin-left: 1em">旨禮部一併議奏</span>  
<span style="margin-left: 7em">順治十四年五月初二日湯若望題本</span>  
<span style="margin-left: 1em">勅錫通微教師加二品頂帶通政使司通政使掌欽天</span>  
<span style="margin-left: 3em">監印務臣湯若望謹</span>  
<span style="margin-left: 2em">題爲日食事該臣於本年五月初一日五鼓督率監</span>  
<span style="margin-left: 3em">員公同禮部祠祭司副理事官臣索尼他赤哈哈</span>  
<span style="margin-left: 3em">番臣額勒木員外郎臣宋徵璧等齊在觀象臺用</span>  
<span style="margin-left: 3em">儀器觀候至寅正二刻半窺見日體已食二分餘</span>  
<span style="margin-left: 3em">隨有陰雲稍蔽候至卯初初刻雲氣開朗觀見食</span>  
<span style="margin-left: 3em">甚候至卯正初刻復圓自初虧至復圓時刻分秒</span>  
<span style="margin-left: 3em">一一與臣所奏悉相脗合衆目共見緣係日食觀</span>  
<span style="margin-left: 3em">候事理理合具題謹題請</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 3em">順治十四年五月初二日具題初四日奉</span>  
<span style="margin-left: 1em">旨知道了禮部知道</span>  
<span style="margin-left: 7em">順治十四年五月初十日湯若望題本</span>  
<span style="margin-left: 1em">勅錫通微教師加二品頂帶通政使司通政使掌欽天</span>  
<span style="margin-left: 3em">監印務臣湯若望謹</span>  
<span style="margin-left: 2em">題爲請</span>  
<span style="margin-left: 1em">旨公同測驗以光曆典事竊照臣於本年五月初一日</span>  
<span style="margin-left: 3em">日食臣同禮部祠祭司副理官索尼員外郎宋徵</span>  
<span style="margin-left: 3em">璧等登臺測驗自初虧至復圓分秒時刻倶與臣</span>  
<span style="margin-left: 3em">之新法符合在臺諸臣衆目共見已經具題奉</span>  
<span style="margin-left: 1em">旨知道了禮部知道欽此是日吳明炫亦自登臺窺看</span>  
<span style="margin-left: 3em">今仍復在部紛言溷亂肆行欺誑臣思五月十五</span>  
<span style="margin-left: 3em">日丑時月食在邇測驗八月水星伏見亦自不遠</span>  
<span style="margin-left: 3em">伏乞</span>  
<span style="margin-left: 1em">皇上遣內大臣同部堂滿漢官於本月十四日夜登臺</span>  
<span style="margin-left: 3em">公同測驗月食分秒時刻庶曆法自明而大典有</span>  
<span style="margin-left: 3em">光矣臣未敢擅便謹題請</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 3em">順治十四年五月初十日具題十三日奉</span>  
<span style="margin-left: 1em">旨禮部知道</span>  
<span style="margin-left: 9em">順治十四年六月通政使司奏疏</span>  
<span style="margin-left: 3em">通政使司通政使用二品頂帶又加一級掌欽天</span>  
<span style="margin-left: 3em">監印務湯若望爲就疏剖明以便回奏事項閱邸</span>  
<span style="margin-left: 3em">報有吳明炫爲詳述設科等事一疏內列交食合</span>  
<span style="margin-left: 3em">朔之是非除已經本監具摺辯明送部外至所奏</span>  
<span style="margin-left: 3em">三欵盡皆以無爲有以是爲非言大而誇不知而</span>  
<span style="margin-left: 3em">作因</span>  
<span style="margin-left: 3em">貴部奉</span>  
<span style="margin-left: 1em">旨察明具奏謹就三欸逐一辯明於後又舊刻進</span>  
<span style="margin-left: 3em">呈曆書中所載有關三欵及水星伏見者一並簡</span>  
<span style="margin-left: 3em">彙成帙呈</span>  
<span style="margin-left: 3em">部以憑詳察具奏施行</span>  
<span style="margin-left: 2em">一辯遺漏紫氣</span>  
<span style="margin-left: 3em">曆家爲司天天有形乃有象有象乃有理論述生</span>  
<span style="margin-left: 3em">馬有象乃有數推算生焉苟無其象雖巧曆不能</span>  
<span style="margin-left: 3em">違天創一理設一數也今稱紫氣有名而無星象</span>  
<span style="margin-left: 3em">夫既無其象矣理必並無數從何起明係後人無</span>  
<span style="margin-left: 3em">端妄增唐以前不聞其說即唐以後凡爲正術者</span>  
<span style="margin-left: 3em">皆棄之弗錄時憲曆何得承訛存之其所載孛羅</span>  
<span style="margin-left: 3em">計皆指太陰行度非餘氣之說安得因載有理有</span>  
<span style="margin-left: 3em">數之孛羅計而并欲載無理無數之紫氣乎且</span>  
<span style="margin-left: 2em">國家將興必有禎祥天人相應之理誠然但因此而</span>  
<span style="margin-left: 3em">强援東方之白氣以爲紫氣則又誣天甚矣至於</span>  
<span style="margin-left: 1em">人主之不尚殺自係修德行仁之驗炫乃指爲木德之</span>  
<span style="margin-left: 3em">驗以徵紫氣之必有苟如其說則天下臣民安享</span>  
<span style="margin-left: 3em">恬熙皆不必感</span>  
<span style="margin-left: 1em">朝廷而感紫氣而自古暴虐如桀紂皆得卸咎於紫氣</span>  
<span style="margin-left: 3em">之無靈矣其說之舛謬豈得智者而辯哉</span>  
<span style="margin-left: 2em">一辯顛倒參觜</span>  
<span style="margin-left: 3em">天體如瓜兩極如蒂近極度狹遠極度寬此理人</span>  
<span style="margin-left: 3em">多知之又經星每歲浸漸東行歲差所由生也行</span>  
<span style="margin-left: 3em">當狹處則速行當寬處則遲遲之既久則原先者</span>  
<span style="margin-left: 3em">轉後速之既久則原後者轉先不但西法即中華</span>  
<span style="margin-left: 3em">從古皆以爲然觜之距參漢測二度唐測一度宋</span>  
<span style="margin-left: 3em">測一度迄半度元測五分諸史可考迨至前朝崇</span>  
<span style="margin-left: 3em">禎戊辰又越三百餘年是時適當望修曆之始細</span>  
<span style="margin-left: 3em">測觜宿已侵入參宿二十四分此天行之必然毫</span>  
<span style="margin-left: 3em">無足訝者炫不考諸古不求諸天而妄以爲顛倒</span>  
<span style="margin-left: 3em">果顛倒乎至若鬼宿今仍在柳宿之西二度有餘</span>  
<span style="margin-left: 3em">安得與參觜同論夫曆者歷也按天行所歷之數</span>  
<span style="margin-left: 3em">以成曆也荷欲附合一切緣餙之文甘心悖天行</span>  
<span style="margin-left: 3em">而不顧斯豈義之所敢出乎况某先某後皆指各</span>  
<span style="margin-left: 3em">宿距星而言炫不曉此而妄舉星座以恣彈駁且</span>  
<span style="margin-left: 3em">又謂新法錯定參占度半觜占十一度望有見界</span>  
<span style="margin-left: 3em">星圖刊行已久炫獨未之見乎何不詳考之圖而</span>  
<span style="margin-left: 3em">信口放言也</span>  
<span style="margin-left: 2em">一辯顛倒羅計</span>  
<span style="margin-left: 3em">羅計新法皆指太陰行度而炫沿舊說謂羅爲火</span>  
<span style="margin-left: 3em">之餘氣計爲土之餘氣請得而辯之夫所謂餘氣</span>  
<span style="margin-left: 3em">必其與本星相連者也譬謂雷發聲訖猶有餘響</span>  
<span style="margin-left: 3em">響必與雷相連日有地頃猶有餘光光必與日相</span>  
<span style="margin-left: 3em">連今曰火土餘氣豈得不與火土相連乎如其果</span>  
<span style="margin-left: 3em">連則今年正月朔土在辰宫五度炫所指土之餘</span>  
<span style="margin-left: 3em">氣乃在丑宫是相連有三宫也火在寅宫二十六</span>  
<span style="margin-left: 3em">度炫所指火之餘氣乃在未官是相連有五宫也</span>  
<span style="margin-left: 3em">一星之氣而占天九十度或百五十度有是理乎</span>  
<span style="margin-left: 3em">如謂餘氣不與本星相連則何所見而以在辰之</span>  
<span style="margin-left: 3em">土妄指其餘氣在丑在寅之火妄指其餘氣在未</span>  
<span style="margin-left: 3em">又有是理乎或曰舊算餘氣皆有度分之數非屬</span>  
<span style="margin-left: 3em">妄指夫羅計既稱無星無象則數本無從生而謂</span>  
<span style="margin-left: 3em">有度分是無數而有數也豈非妄指乎新法改正</span>  
<span style="margin-left: 3em">爲太陰行度已十有四載乃炫猶執此以爲争端</span>  
<span style="margin-left: 3em">可謂大惑不解已羅計既非餘氣則顛倒不辯自</span>  
<span style="margin-left: 3em">明蓋羅睺計都從原稱也實爲月之交行曰正交</span>  
<span style="margin-left: 3em">中交耳西謂之龍頭龍尾亦有謂天首天尾者蓋</span>  
<span style="margin-left: 3em">初宫爲首月行交此爲正交六宫爲尾月行交此</span>  
<span style="margin-left: 3em">爲中交羅從初官起算計從六宫起算首尾分明</span>  
<span style="margin-left: 3em">正中順序炫妄稱顛倒何也至于月食所見之色</span>  
<span style="margin-left: 3em">本由蒙氣濕氣二景與地景相參而生詳交食曆</span>  
<span style="margin-left: 3em">指中炫不曉此而歸之羅計又豈非妄乎</span>  
<span style="margin-left: 7em">順治十四年八月二十五日禮部題本</span>  
<span style="margin-left: 3em">禮部</span>  
<span style="margin-left: 2em">題爲請</span>  
<span style="margin-left: 1em">旨事案照吳明炫疏稱八月二十四日夜水星出見至</span>  
<span style="margin-left: 3em">九月二十二日伏於卯宫等語據湯若望疏稱八</span>  
<span style="margin-left: 3em">月水星不見今八月二十四日少保兼太子太保</span>  
<span style="margin-left: 3em">內大臣公愛星噶精奇尼哈番加一級劉良佐太</span>  
<span style="margin-left: 3em">子太保內翰林國史院大學士管吏部尚書事王</span>  
<span style="margin-left: 3em">永吉户部尚書加一級孫廷銓刑部尚書白胤謙</span>  
<span style="margin-left: 3em">兵部尚書加一級梁清標太子太保工部尚書加</span>  
<span style="margin-left: 3em">一級衛周祚臣部左侍郎加一級烏赫左侍郎加</span>  
<span style="margin-left: 3em">二級薛所藴右侍郎加一級潘朝選右侍郎加二</span>  
<span style="margin-left: 3em">級李奭棠祠祭司正理事官石琳副理官加一級</span>  
<span style="margin-left: 3em">索尼馬喇郎中加一級田萃禎俱登觀象臺照吳</span>  
<span style="margin-left: 3em">明炫所稱時刻方向詳細測驗未見水星是吳明</span>  
<span style="margin-left: 3em">炫所稱水星出見一節事屬虛妄應將吳明炫拿</span>  
<span style="margin-left: 3em">送刑部羈候臣等另議具奏謹題請</span>  
<span style="margin-left: 1em">旨</span>  
<span style="margin-left: 3em">順治十四年八月二十五日具題本日奉</span>  
<span style="margin-left: 1em">旨是</span>  
<span style="margin-left: 7em">順治十四年八月二十七日禮部題本</span>  
<span style="margin-left: 3em">禮部</span>  
<span style="margin-left: 2em">題爲天象原自著明推法各有得失冒死驗象以存</span>  
<span style="margin-left: 3em">絕學事祠祭清吏司案呈奉本部送禮科抄出該</span>  
<span style="margin-left: 3em">本部題覆原任欽天監回回科秋官正革職臣吳</span>  
<span style="margin-left: 3em">明炫測驗天象緣由等因該臣等議得吳明炫所</span>  
<span style="margin-left: 3em">稱水星出見一節已于八月二十四日</span>  
<span style="margin-left: 1em">欽遣少保兼太子太保內大臣公愛星噶等公同太子</span>
