<span style="margin-left: 1em">圣旨画一历法已屡有旨了所进书册留览该部知道</span>  
<span style="margin-left: 3em">崇祯十年十二月十九日巩焴奏本<sub class="note-jiao">校：據清刊本補錄</sub></span>  
<span style="margin-left: 3em">礼部祠祭清吏司主事臣巩焴谨</span>  
<span style="margin-left: 2em">奏为遵</span>  
<span style="margin-left: 1em">旨据实奏明事本月初九日奉本部送礼科抄出另局</span>  
<span style="margin-left: 3em">纂修历法魏文魁男生员魏象乾奏为感激</span>  
<span style="margin-left: 1em">天恩剖陈秘法愿揭愚衷仰佐</span>  
<span style="margin-left: 1em">圣明敬授之大典事等因崇祯十年十二月初八日奉</span>  
<span style="margin-left: 1em">圣旨魏象乾曾否进揭着巩焴及钦天监官据实奏明</span>  
<span style="margin-left: 2em">廪薪不准辞该部知道钦此钦遵臣焴蒙堂札委于</span>  
<span style="margin-left: 3em">本年十二月初一日同两局及钦天监官前赴观</span>  
<span style="margin-left: 3em">象台测验日食四家之印图较若列眉各局之开</span>  
<span style="margin-left: 3em">单灿若指掌尔时魏象乾亦厕身班行中闻其家</span>  
<span style="margin-left: 3em">传历学讲求有素似当先期拟定分秒时刻缮进</span>  
<span style="margin-left: 1em">御览次投揭臣部堂官次投揭臣等于上台之初待其</span>  
<span style="margin-left: 3em">测验有准时方可持为左劵以箝盈庭聚讼之口</span>  
<span style="margin-left: 3em">也乃迟至日亏已完始袖出一揭臣同钦天监官</span>  
<span style="margin-left: 3em">公看大抵揭内开载与新法稍觉符合其为素定</span>  
<span style="margin-left: 3em">猝办俱不可悬揣况臣未奉</span>  
<span style="margin-left: 1em">明旨未蒙堂批又日食事已告竣不敢擅收事后私揭</span>  
<span style="margin-left: 3em">以附会于新法此本日实情实事也至于象乾果</span>  
<span style="margin-left: 3em">识精象纬淹贯历法与否钦天监官知之必稔臣</span>  
<span style="margin-left: 3em">不敢悬揣蒙奏也今奉有着巩焴及钦天监官据</span>  
<span style="margin-left: 3em">实奏明之</span>  
<span style="margin-left: 1em">旨臣即据实奏明仰祈</span>  
<span style="margin-left: 1em">圣明裁夺施行</span>  
<span style="margin-left: 3em">崇祯十年十二月十九日奉</span>  
<span style="margin-left: 1em">圣旨该部一并看议具奏</span>  
<span style="margin-left: 2em">崇祯十一年正月十二日李天经题本<sub class="note-jiao">校：據清刊本補錄</sub></span>  
<span style="margin-left: 3em">督修历法山东按察使司按察使照京官例正三</span>  
<span style="margin-left: 3em">品支俸臣李天经谨</span>  
<span style="margin-left: 2em">题为各法疎密已蒙</span>  
<span style="margin-left: 1em">睿判画一屡</span>  
<span style="margin-left: 1em">旨未见钦遵再恳</span>  
<span style="margin-left: 1em">圣明独断早定历法事窃照治历明时乃</span>  
<span style="margin-left: 2em">国家之首务而法取合</span>  
天亦千古之定论今臣局历法自奉  
<span style="margin-left: 1em">勅修改以来逐年推测交食五星无不合</span>  
天且书器久已告成惟候昼一遵行耳去冬日月两食荷  
<span style="margin-left: 3em">蒙</span>  
<span style="margin-left: 1em">圣明内廷亲验两奉有新法为近余俱疎远之</span>  
<span style="margin-left: 1em">旨屡经</span>  
<span style="margin-left: 1em">勅部画一而该部诸臣明知新法合</span>  
天尚欲曲全另局欲臣局与之参合会通移会到臣业经  
<span style="margin-left: 3em">逐欵驳明所云历法原自浑成迁就割裂不得傥</span>  
<span style="margin-left: 3em">一那移一差尽差而部臣犹以甲可乙否终归纷</span>  
<span style="margin-left: 3em">纭等语模棱具覆以卸怨尤随奉有历法务求画</span>  
<span style="margin-left: 3em">一前已有</span>  
<span style="margin-left: 1em">旨该部作速看议具奏之</span>  
<span style="margin-left: 1em">旨是</span>  
<span style="margin-left: 1em">圣明已洞烛其疎远者无容与合</span>  
天者相会通明矣又于部臣覆疏内续奉有历议纷纭尔  
<span style="margin-left: 3em">部须折衷画一还着遵旨确议速奏毋再游移之</span>  
<span style="margin-left: 1em">旨是</span>  
<span style="margin-left: 1em">圣明亦洞鉴其另局三法自不能一且又悉皆疎远曾</span>  
<span style="margin-left: 3em">无寸长而于备考奚补似又不待姑俟再验而决</span>  
<span style="margin-left: 3em">者更明矣</span>  
<span style="margin-left: 1em">煌煌明纶炳若星日想部臣自宜仰体若欲再踵会通</span>  
<span style="margin-left: 3em">之故套不惟真伪不分是非倒置有误</span>  
<span style="margin-left: 1em">大典抑且仰遵</span>  
<span style="margin-left: 1em">圣旨之谓何闻部臣已于去冬十二月内具覆矣但未</span>  
<span style="margin-left: 3em">审所奏云何诚恐一时之情面难破画一之</span>  
<span style="margin-left: 1em">明旨未能钦遵且闻伪法者乘机凟奏图逭疎远之愆</span>  
<span style="margin-left: 3em">百计挠成罔顾</span>  
<span style="margin-left: 1em">圣明画一之切所幸我</span>  
<span style="margin-left: 1em">皇上离照当空谅宵小终难荧</span>  
<span style="margin-left: 1em">听惟是十二月朔之日食臣局所报食甚在未初二刻</span>  
<span style="margin-left: 3em">半者图疏昭然郭正中见臣法合</span>  
天疏内捏改臣报未初三刻半而诳陈之又巩主事于分  
<span style="margin-left: 3em">秒亲测六分余书纪见存部疏又改为四分而诳</span>  
<span style="margin-left: 3em">覆之种种欺罔难以殚述若非我</span>  
<span style="margin-left: 1em">皇上亲验则臣局新法又几为若辈所朦蔽矣但新法</span>  
<span style="margin-left: 3em">既经屡测皆符画一屡厪</span>  
<span style="margin-left: 1em">睿判其阻挠而欺罔者尚若是游移而不决者又若是</span>  
<span style="margin-left: 3em">后即再测不过总此机局臣于此时傥不请乞</span>  
<span style="margin-left: 1em">圣明大奋乾断钦定画一则历法终鲜结局之日不几</span>  
<span style="margin-left: 3em">有负我</span>  
<span style="margin-left: 1em">皇上屡颁画一之</span>  
<span style="margin-left: 1em">严旨乎伏查钦天监旧例如十二年民历应于十一年</span>  
<span style="margin-left: 3em">二月初一日进様四月初一日颁布刊刻且今稍</span>  
<span style="margin-left: 3em">一蹉跎其期遂误将必以我</span>  
<span style="margin-left: 1em">皇上亲测有不足凭而画一终无底止臣所以亟亟叩</span>  
<span style="margin-left: 1em">阍者此也总之画一之法惟取合</span>  
天者而遵用之今新法既已合  
天惟乞  
<span style="margin-left: 1em">圣明勅令该监诸臣以后照依新法推算通行庶嫉忌</span>  
<span style="margin-left: 3em">消而玄黄息则敬授</span>  
<span style="margin-left: 1em">大典不致久承讹舛而万年</span>  
<span style="margin-left: 1em">宝历亦为之焕然一新矣</span>
