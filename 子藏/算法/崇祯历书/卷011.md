## 崇禎曆書卷之十一　崇禎奏疏

*崇禎十年二月初二日至崇禎十一年正月十二日*

<span style="margin-left: 2em">緣起十一</span>  
<span style="margin-left: 9em">崇禎十年二月初二姜逄元題本</span>  
<span style="margin-left: 3em">太子少保禮部尚書兼翰林院學士臣姜逄元</span>  
<span style="margin-left: 2em">題爲遵</span>  
<span style="margin-left: 1em">旨酌議恭請</span>  
<span style="margin-left: 1em">聖裁事祠祭清吏司案查先該本部題覆兵部左侍郎</span>  
<span style="margin-left: 3em">加從二品服俸暫署部事王業浩題覆虜氛<sub class="note-jiao">校：清刊本</sub></span>

<span style="margin-left: 3em">望等自應</span>  
<span style="margin-left: 1em">召修曆以來著述獨探理窟製造咸晰天行功次犁然</span>  
<span style="margin-left: 3em">況登陴指授遠折狂氛其一段忠義之氣尤屬可</span>  
<span style="margin-left: 3em">風誠有如</span>

<span style="margin-left: 3em">非彼所欲則量給田房以資朝夕是亦爵賞之外</span>  
<span style="margin-left: 3em">別示優異臣部再四斟酌似爲妥便合無仍將羅</span>

<span style="margin-left: 3em">匱用以酬前勞而勉後效端在是矣伏乞</span>  
<span style="margin-left: 1em">勅下臣部劄行順天府或查給入官田房或另設法措</span>  
<span style="margin-left: 3em">給施行緣係<sub class="note-yuan">云云</sub>事理未敢擅便謹題請</span>

<span style="margin-left: 3em">夜鳩工如法製造隨一面將故輔原進兩陪臣<sub class="note-jiao">校：同</sub></span>  
<span style="margin-left: 3em"><sub class="note-yuan">前條</sub>譯譔恒星經緯表二卷與臣所進</span>

<span style="margin-left: 3em">鏤刻動經歲月有非一人一手所能猝辦者今幸</span>

<span style="margin-left: 2em">進臣于此尤有</span>  
<span style="margin-left: 1em">請焉我</span>  
<span style="margin-left: 1em">皇上事事求真處處務實則此勒之金石登之</span>  
<span style="margin-left: 2em">大內者其欲傳信不欲傳疑也必矣乃臣等所列星</span>  
<span style="margin-left: 3em">座俱皆有器可測有象可憑一一依經緯點定與</span>  
<span style="margin-left: 3em">舊圖原自不同如舊所載天廟稱其在張宿下十</span>  
<span style="margin-left: 3em">有四星所載器府亦稱其在軫宿下三十二星等</span>  
<span style="margin-left: 3em">類今按之實測渺難窺匪器可測臣何敢以漫無</span>  
<span style="margin-left: 3em">可測之星而輕圖之也又如團圓十三之天壘城</span>  
<span style="margin-left: 3em">今測之僅見其三團圓十三之軍市今測之亦僅</span>  
<span style="margin-left: 3em">見其五甚且人星本三也而舊繪以五天廐本三</span>

<span style="margin-left: 3em">様葫蘆而狥此耳食之見乎且有昭然顯著之星</span>  
<span style="margin-left: 3em">舊圖原未盡載者兹且悉爲測定增入但緣舊未</span>  
<span style="margin-left: 3em">有名今亦第以增等別之然而恭繹</span>  
<span style="margin-left: 1em">明綸一切星象不可遺漏臣等再四思維星球之製但</span>  
<span style="margin-left: 3em">取合天何嫌同異且從古及今天文各家代有更</span>  
<span style="margin-left: 3em">易何獨拘泥成說而疑于今日乎益以見我</span>  
<span style="margin-left: 1em">皇上大聖人之作用超出前代萬萬矣所有用過錢糧</span>
