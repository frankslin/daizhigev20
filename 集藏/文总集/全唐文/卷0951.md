# 张耀

## 井赋（以「清汲遇时美」为韵）

原夫井之为德，以不变而居贞，毁成形于方载，亦列象于圆清。润下之功，爰修之于六府；习坎之义，则配之于五行。惟斯井之肇作，实伯益之所营。

尔乃玉甃爰起，银床斯立，窥寻丈以惟深，觇清泉之始及。青梧下映，泛桂叶以摇扬；素绠高悬，弄银瓶之出入。光洞彻而缘止，影飞翻而为汲。且其盥之取新，渫之去故，体清通之惟审，知应物而无忤。居上善而且平，挹清规而可遇，庶乎鸾镜荧煌而可比，凤池皎洁而为喻。别有前临紫殿，俯映丹墀，上栋下宇，绣栭文楣。意者岂非至尊尚恬澹而取诸动善时而已哉！懿夫粉署清华，飞禽载止，对仙郎之章奏，近尚书之剑履。窃自羞嫫母之陋姿，鉴清澜之眩美。

# 张文

## 气赋

余尝志于元言，每寻庄老，莫不虚心竦神，锐精厉志。究夫道源，孰不因气而生者。其功也大，其应也细，述之无已，遂成赋曰：

二仪混合兮成天地，四气汗漫兮育万类。离云腾陵而千峰崔嵬，震风飋飓而百卉葱翠。宵中星虚，则大火西流；律应黄钟，而凝阴东萃。惟兹气之浩然，胡应物之无匮？若乃假名为声，托体而成，凭乎动息，美恶必呈。挫锐解纷，庶同归乎老氏；虚心弱志，或契合乎庄生。逆之为怒，顺之为贞，纵之则逸，舍之则盈。若也勇冠三军，神雄思锐。善战善胜，徒激愤于项王；嘉谋嘉猷，望旗靡于曹刿。尔其瞻白虹之贯日，眺紫气之冲牛，应精诚之所感，显神异之潜周，随时变易，物莫能俦。则知气之为用，其道飞浮，或聚或散，处刚处柔，能从达人之性，偏攻思妇之愁。其兴也勃，其去也休，伊万古之造化，胡六合之因由。阴阳以之准则，天地以之通流，匪斯文之可测，终铭简于千秋。

# 张畴

## 对袭代封逃判〈丁长当袭代封，逃。主司以有兄不录其弟。〉

先王有作，班氏叙其家风；远代无违，韦孟陈其祖德。是知本枝可重，宗叶难轻。丁胄望素高，勋庸夙著。金柯玉叶，冠盖之望攸崇；青社白茅，诸侯之业斯大。上林春至，花萼均芳；下泽秋归，鸿雁齐列。既而风枝不静，星琯屡移。何劭承家，泫然流涕；桓元袭爵，悲不自胜。苟怀揖让之风，遂有逋逃之迹。昔延陵去国，令范犹存；太伯辞周，遗芳未泯。必若情深让弟，义等脱身，请封韦氏之次男，无亏太伯之高节。

# 张凭

## 对贡人帖经判

〈漳浦郡贡人景，帖策不通，所由将坐。郡守云：「未成分，仰处分。」〉

唯贤是举，慎择为先，明试以言，得失斯在。惟景策名岁贡，待扣礼闱，将登甲乙之科，翻速主君之戾。何则帖兹学圃？既谢专经；策以词林，仍非善中。遂使仙台清镜，徒讶于才难；幽谷迁莺，空悲于岁晚。顾惟州将，岂曰能官？据条虽未成分，于是恐非公荐。景当冒贡，请用迁郊之礼；守举非才，宜从削地之罚。

## 对屯田不开渠判

〈甲当屯于戊已校尉故地。乙告其常行厌胜之术。御史按云：「唯使丁开渠播种，不伏科罪。」〉

富国强兵，允资重种；辟土殖谷，必俟良农。虽云因地之利，无爽用天之道。惟甲克勤稼穑，受任军屯。候正岁之布和，乃宣乃理；及王瓜之生夏，或钱或镈。遂使其茨如梁，必周戊己之地；其比如栉，不忝京坻之诗，眷此屯功，宜蒙上赏。谁闻兴利之举，翻招厌胜之讼？然而六甲纪则，刚柔异体；五行统岁，禳厌分区。苟获赖于柔嘉，固无嫌于法术。况丁也为役，职此开渠，虽决泄之诚劳，岂仓黄而妄告？仰稽古训，甲则无辜；旁酌人情，乙宜致诘。必若事非政要，术异农祥，请遵持斧之绳，勿恕薄言之诉。

# 张渊（疑）

## 对驱傩判 (张渊)

〈月晦所司阙堂赠之礼。〉

景家非绵上，室异\<广毁\>焚，初闻问马之辞，旋至歌龙之毙。将救余烬，昧元瑜之旧林；言访遗煨，异僖父之前室。望人矜兹逝者，歌彼荡乎，亦既聚财，更其所伤。吊生以礼，因不违于赗赠；哀死及尸，亦何仪于赃物？诚以鲁策，求之宋妻。邱既吾无闲然，预今得为义矣！

# 张德升

## 声赋

夫礼乐相成，人之有生，物归乎理，感在乎声。声之所起，其应多矣。既闻郑以戒荒，亦称《韶》于尽美。至若诗陈钟鼓，礼奏笙簧，音怀律吕，韵合宫商。或婵娟而如绝，或窈窕而复扬，将曲尽而逾妙，遇风吹而更长。潜鳞竞跃，仪凤来翔，嘉此声之可贵，乐吾君之奉常。则有思妇伤离，芳年屡换，织素寒早，调砧夜半。垤鸣鹳而初合，砌吟蛩而正乱。何此声之可悲，使空闺之浩叹？况复金徽远奏（一作金微远戍），玉律穷秋，阴风烈烈，边树修修。听胡笳之互动，看陇水之分流，何此声之可怨，使征客之含愁？亦有遁世无闷，闲居栖找，坐啸竹林？忘形菌（一作苔）阁。怜宿鸟之喧薮，爱飞泉而喷壑。何此声之独殊，使幽人之为乐？夫意存则言发，言发则声来，顺之则喜，逆之则哀。是以文君听琴而悦矣，子期闻笛而悲哉！何悲欢之易感，使众人之难裁。

客有吟者，潸然下泪。吾将不言，安知所谓？退失路而流落，进无媒而自致，思巫峡之猿啼，闻洞庭之叶坠。《易》曰：「同声相应，同气相求。」傥知音之见许，期厚德而相酬。

# 张时敏

## 登凤凰台赋

客有凭崇高，吹玉箫，挟飞仙兮游遨。尝访于丹邱之阿，附凤翼而飘飖。一日过升州，蹑层楼，望三山，豁双眸。乃见其钟山龙蟠，石城虎踞，爰有崇台，中焉而处。其高也莫窥几仞，其广也不如几许。上有琳琅之竿，林林兮参穹窿；下有坚贞之璞，粲粲兮镇后土，左雨华兮为之翼，右乌台兮为之辅。铜雀虽高兮焉可与之侔，龙虎何壮兮莫能与之伍，百灵见之而辟易，六丁守之而嗬护。此其为金陵帝王之地，凤凰来集之所也！维时烟销雾敛，晴旭初升，万象森列，众露毕呈。长江静其如练，天籁寂其不鸣。方将振尘躅，陟崔嵬，舒玉管，据崇台，访谪仙之遗咏，拂龟龙之莓苔，叹凤凰之已去，徒抚掌而徘徊。

呜呼噫嘻！想灵物之雝雝兮，羌太和而出世，苟或遇之非时兮，又奚足以称瑞？昔虞姬之继作兮，胡来仪而鸣岐，表雍熙于一代兮，斯为瑞也固宜。伟兹台之致祥兮，盎太和而辟翕，下必有其丹泉兮，上必具夫玉食。地博厚而钟灵兮，水甘馨而泌汨，顾葳蕤而来翔兮，缤五彩而翼翼。览德辉而一鸣兮，应元嘉之宝历。宜兹台之擅美兮，历千祀而不易。今也不往，终焉悒悒。于是攀凤栖，涉丹池，追故迹，访前知。盼遗踪其忽恍，眩寒璞而烟霏，景不可乎复得，益感叹而忘归。

客乃脱帽解襟，独倚台楹，纵舒玉吹，声凌太清。声未既，碧穹如洗，俄而有仙子，驾彩凤于云衢，下斯台而暂止。客视而惊，悚然惧，矍然兴。屏气敛容，稽首称臣，踧踖前诣，请问其因。仙曰：「方今天命以仁，文运一新，制礼作乐，多士彬彬。立庙堂者，乃瑞时之丹凤；居翰苑者，乃表祥之白麟。虽高蹈而远举，亦征用而超伸，际云龙于风虎，总附翼而攀鳞。故其进也，优游乎岩廊之上；其退也，笑傲于山泽之滨。惟声和而气和，俾嘉瑞之毕臻。吾天帝之孙，文昌之宾。观子之登崇高，吹玉箫，振袅袅之清声，协嗈嗈之和音，律高而调婉，克享于天心。吾其驾凤以征，达聪以听，进汝为席上之珍，登汝为天府之琛。」客闻其语，领然而悟，敬再拜而称谢。仙子携客跨凤而去。

# 张处信

## 对折狱之理

对：五材递用，前圣因而设刑；四象代兴，往贤则而为治。所以明弼五教，敬成三德，为安上之鞭策，作御下之堤防。粉黛帝猷，脂泽王化。故轩皇六禁，设言而不违；妫帝三居，画象而无犯。既而末代多僻，乱政滋章，网密凝脂，文深刺骨，威逾夏日，苦烈秋荼。或酷甚弃灰，或刑深盗土。遂使棘林之下，鬼哭呈祅；函谷之前，冤魂表沴。虽汉文易肌肤之痛，孝景减鞭扑之科，竟未革弊除烦，焉能救焚拯溺？

方今膺期千载，保业重光，表至德以泣辜，布深仁于解网，敬刑若祭，重狱如伤。诚宜削季叶之惨科，袭至安之有美，自可驾三皇而𬴂五帝，超千古而笼万方。欲废彼黄沙，赦兹丹笔，眷言斯理，蒙窃惑焉。何者？德刑递施，宽猛相济。是知明君至乂，不独任于诗书；哲后钦明，岂专行于礼乐？此乃杀以止杀，刑期无刑，绵绝代而不渝，迈终古而无替！愚谓摈苍鹰之酷吏，弃乳虎之屠伯，然后举皋陶而作士，命随会以守官。则内盗自奔，不仁斯远，自然防萌之术无阙，削觚之化有余。岂止封府之赦不施，遗冠之宥无设？用舍之义，夫何足疑！

且律之兴，其来尚矣。盖三光列景，法星丽于天文；五位成形，习坎彰于《易·象》。爰洎贰负，初洽维絷之科；降及四凶，始受殛流之罚。及庭坚翼舜，狱律遂此陶情；萧相主刘，甲令于焉刻意。至如锯钻之绝，班固书而可知；肉刑之兴，孙卿论而已备。谨对。

# 张怀道

## 对坐大夫箦丧姊不除服判〈谏议大夫廖贞，坐黜疾用大夫箦。又俞仲丧姊不除服。〉

位列千官，藻火陈轻重之制；礼明五服，麻绖分丧纪之仪。苟失其中，章程是紊。廖贞门承累叶，坐登朝散之荣：俞仲痛切连枝，行招墨绶之问。潘仁之遭谴累，将复位而无阶；子路之寡兄弟，欲除丧而未忍。与其易而宁戚，稍越周公之经；当其疾而未遑，犹卧大夫之箦。下乌台而遽纠，如申避马之威；举丹笔以缓刑，似得求羊之术。与夺合理，法有固于堤防；刑罚失中，人无措其手足。纵其床箦不易，见讥非帛之书；服刑将逾，岂累弦歌之化？言规小过，欲寘深文。令长临人，未庶几于蚕蟹；鹰鹯逐雀，亦何问于狐狸。听子舆之言，（阙）罪不假于科绳，事终期于改正。仲之无罪，小鲜之责太深；贞亦何辜？大理之折斯当。

# 张存则

## 舞中成八卦赋（以「中和所制，盛德斯陈」为韵）

乐之容，舞为则，导于情，崇于德。制其衣而五方咸备，颂其序而八卦不忒。然后体利贞而疾徐有度，法行健而循环不穷，数盈而刚柔匪杂，缀短而明德将融。初配六以回旋，状马行于此；及变三而成列，如龙化其中。信乾坤之简易，应金石之变通。于是步日而前，因风而举，乘飘飏而婆娑杂遝，映照烛而长短合序。既顺之而不却，亦明之而有所。则离巽之不差，岂进退之无旅？则有应水之理，象木之规，叠若奔溜，散如繁丝。五色相宣，谓神龟初负；八音咸奏，知灵凤来仪。震也坎也，何斯违斯？既以悦随，企其遵令。象山而乍结乍凝，依泽而若游若泳。状巍巍之德，仰之弥高；节荡荡之音，于斯为盛。是知艮、兑之为美，故必随而不竞。

是故圣人穷乐之变，制舞惟新，效知来而藏往，故有要而有伦。非干戚之前设，若钧天之所陈。至若卿云共临，瑞日同霁，乍离乍合，若翔若滞。随方辨色，非前代之旧章；应节成文，实我唐之新制。是知舞以适道无颇，乐以审政同和。观象取则，异乎侧弁峨峨。则斯舞也，实百代之不讹。

# 张彦震

## 驾幸宣辉门观试举人赋（以「君圣臣肃，精择多士」为韵）

望之如云，圣人为君，克敷厥德，以嶷鸿勋。大庇黎元，始躬耕而载籍；旁求俊彦，终访道而崇文。於穆我皇，乃神乃圣，开四目以达聪，掩八荒而布政。群龙顺启沃之旨，多士奉畴谘之命，大哉邈乎！于斯为盛。尔其庶士冢宰，百寮近臣，大夫师长之旅，版筑岩穴之人。举尔所知，乃寸长无舍；褎然而至，虽片善必申。于是朝无遗逸，野绝沉沦，激昂于凤阙之下，鼓舞于鸿渐之辰。

且圣泽昭宣，惟闻有典有则；天威咫尺，孰谓不躬不亲？伊何（阙四字）百寮增肃，仰清问而矫首，拜昌言而俯伏。烝哉髦士，绿骥方呈于长衢；贲于邱园，白驹自来于空谷。亦既赞休命，亦既陈厥成，将献可而替否，必覃思而研精。意彼逸足，侔乎先鸣。错翘薪以割楚，聊擢桂而敷荣。懿乎文物明明，威仪赫赫。摇彩仗于云路，辟禁闱于广陌。虽知人不易，实在乎区分；而天鉴孔明，自彰乎慎择。夫然才为世出，才应时多。以才从政兮国有恒典，以才为辅兮人知匪他。于以代天工，则百寮矜式；于以掌邦宪，则庶事协和。亦自此立功，亦自此致理。迈前王之躅，垂可大之纪。维翼翼之圣朝，务济济之多士。岂止夫尧吁舜谘，可畴德而已哉？

# 张真祥

## 嘉禾合颖赋

南山之下兮无人之境，力穑此中兮均夫躁静。劳则不惮，既寒耕而热耘；庆有所归，忽异亩而同颖。茎骈惜芃芃之色，秀合垂䔿䔿之影。此焉观瑞，亦祗以异。比于木乃连理之祥，在于人葢同心之义。粰已闻于二米，茎乃殊于九穗。岂非德之能及，实圣朝之所致。

爰考休征，丰年是凭，麦两歧而能匹，茅三脊而徒称，固神仓之可贮，期郊庙之以升。欲荐尧阶，且闻挃挃之𮒗；将登禹膳，遂入烰烰之烝。天道元默，瑞以表德。岂无沃土？而光于我家；岂无异方？而祚此王国。不有嘉生，孰谓宾荣？友朋之心，因取兴于连茹；兄弟之乐，遂作戒于分荆。伫闻唐叔之献颂，我后之升平。

# 张元览

## 欹器赋

夫阳鸟中而则谢，阴兔望而斯蚀，谅天道之常理，岂人情之能测！何此器之知机，体变通之消息。其形也菲陋，任其淳素之姿；其质也嵚欹，无假丹青之饰。平而则正，满而斯侧，不平不满，无穷无极。夫盛衰共贯，倚伏多途，或始吉而终否，或前荣而后枯。才闻栖越，遽见亡吴，不知戒其盈溢，空有叹于姑苏。

是知高而不危则治，操而有求则竞，见握发以存诚，虏宵衣而致命。老氏贵其善建，大易崇其积庆，殷汤镂几以为虞，孔甲镌盘而自镜。尔其冥豫不止，怀足无厌，衅成山岳，祸起微纤。愚者已然而不见，智者未兆而斯瞻，圣人损之而又损，君子谦之而更谦。大禹惟圣，每殷勤于菲食；惟尧则哲，终眷恋于茅簷。然而默默如存，隆隆自绝，天且不能固西北之坏，地且不能补东南之缺。天地尚不能久，矧人道之不灭。勒兹器以为箴，庶作鉴于来哲。

# 张彦振

## 指南车赋

缅窥皇始，倾听巢风，时仪朴略，化迹冥蒙。结绳云谢，徽章渐通，乃服牛而乘马，爰斫木而观蓬。故圣人因象以制器，随物而兴功。北斗在天，察四时而行度；司南在地，表万乘之光融。尔其法制奇诡，神妙无穷。见其指而皆知其向，睹其外而莫测其中，轮须藉乎奚子，妙乃发于周公。观其作也，扃关脉凑，衡枢星设，烟萦电转，鬼聚神灭。离朱目乱，计然思绝，公输服其心工，王尔惭其手拙。虽词给而口敏，终难得而缕说。至如帝容顺动，王涂允泰。二月东巡，万国南会，羽卫出而天动，笳鼓鸣而雷磕。司南于是备属车，引行旆。候薰风而进指，仰卿云而承盖，超摇光景之中，缥缈烟霞之外。同夫越鸟，常有意于南枝；异彼鲁人，竟无情于殿最。惟皇明之远瞩，驱八骏以遐举，既访道于襄城，亦寻仙于海渚。岂须老马之智，宁藉小童之语，赖我司南，不迷其所。伊司南之用溥，逢国道之昌平，就日月于天路，闻《箫韶》于玉京。常使朝朝承北阙，何辞岁岁指南行。

## 大章车赋（以「上方所造，问次羽仪」为韵）

舜为君兮禹为相，七政齐兮八风畅。备礼容兮和乐章，同车书兮一度量。龙楼恭己，则无为以垂衣；鸾跸豫游，或有时而端望。伊大章之攸作，冠轮舆而为上。其始也，委材质于资斧，授规模于梓匠。其终也，援桴鼓于天街，动𫐐𫐄于霜仗。乃画界疏疆，正位辨方，候之以节步，先之以启行。象雷而鸣，曾不闻其霆击；如蓬之转，终不见其飘扬。遵彼坦途，违兹险阻，勿忘情而习静，殊不知其处所。类智者之行藏，同至人之默语。历代传宝，鼓车逾好，有异人谋，宛同灵造，行不由径，动能合道。

向使贵贱混并，高卑不问，应无迷远之疾，讵有穷途之患。则是大章为器，国容之利，指方位于遥空，数田里于厚地。节六鼓以鼍骇，首五辂而鳞次。望尘不及，初非千里之遥；听响争先，终欣一日而至。夫然则可以式序秩宗，发挥乐府，扶持辇毂，隐翳干羽。以家刑国，何一二之能谈；自迩陟遐，虽万亿而可数。墨客何为？来攀桂枝。悬鼓待鸣，仰淳淳之风俗；克车就驾，识穆穆之威仪。伊可大而可久，谅斯焉而取斯。

## 响赋（以「庭下云晚响轻」为韵）

伊二仪之陶甄，览万物之生长，为随方而可见，独不测乎兹响。同夫道之无质，每凭虚而起象。既不睹其洪纤，亦罕知其尺丈。尔乃依声于发，有待而生，触万窍而皆异，会五音而共成。随人心之哀乐，因感召而重轻。至于惊激万变，高卑千转，临牝谷而悲多，因归风而去远。感华钟于霜曙，思孤雁于秋晚，触物类以成态，托空虚以运形。尔其细也，草虫鸣於潜穴；至其大也，震雷作于天庭。离朱拭目而不见，师旷清而可听。尔其响发乎器，必声有假。故器有盈虚，而响为高下，随之则不可究，及之如或可写。信造化之自然，亦焉知其为者。乃有厌处鸡群，穷栖海滨，垂六翮而未举，鸣九皋而不闻。愿托响于星骥，希可彻于高云。

# 张鸣鹤

## 空赋

造化不测，长空浩然，生于未有，物莫能先。故其走目遐甸，幽不可见；流听高冥，渐不可听。既从天而共色，又鉴水而同形，若乃变化随时，凭乎动止。韶容春遍，火云夏起，流电夺目，殷雷激耳，立绕树之千岩，广长风之万里。惊飙既临，彩虹破阴，雨尽天远，云空涧深。百尺楼头，见朝阳之赫奕；九重宫里，闻众鸟之喧林。何高秋之辽迥，至穷冬而不极，感在物之捐华，益穷人之叹息。惟长空之爱此，终生灵兮动植，歌和光以同尘，每因空以悟色。至人恬澹，既将元之又元。小智多非，岂斯文之果测。

# 张余庆

## 竹宫望拜神光赋（以「亲飨虔洁，灵报光烛」为韵）

祀之严者飨帝，德之盛者降神。不励精孰谓福之自己，非表异曷知天实无亲。武皇卜郊以元吉，祈灵于上辛。密命始传，光则𬘡缊未感；斋宫爰拜，神其蚃有因。盖以穆尔精勤，凝然存想，属属乎苍璧既奠，煌煌乎太坛攸仰。委佩尽饰，庶无哗以端庄；秉圭展仪，（阙二十字）彼电破乎祥烟逮暗之时，熉烛而明烂矣！遥望之处，拜起而容肃然。岂不以配合崇高，昭陈宿设。圜丘之上，将候其耿光；竹宫之中，以备其斋洁。既恍惚而有见，竟超遥而未绝。或左或右，通幽洞冥，照灼兮疑分辉于画烛，焜煌兮乍联影于低星。所以彰有德，赫炳灵，实见祠祈，周流福庭。望神之休，惟一人有庆；主日之际，必上帝是听。故天降德祥，人窥其奥。至德而感，岂元邈之不臻；至诚而祈，岂昭彰之不报？首兹祀事，实在阳方，望拜虽同乎手拜，神光且异乎萧光。人皆见之，孰不仰而祇栗？夜则艾矣！谅惟远之馨香。殷雉雊而称异，鲁郊牛而用伤，皆祈报之琐细，非昊穹之降康。岂比夫神祠太乙之灵，乐饮歌童之曲，虽望之而如在，惧敬之而不足。汉后之虔恭也如此，故景光而下烛。

## 祀后土赋

:祀后土赋

## 青玉案赋（以「报之贞亮，因物莹心」为韵）

当群物之具陈，唯玉案而是珍，青莹自乎天产，追琢资于匠人。呈形而色有温润，成器而道无缁磷，由是功倍几杖，质殊琳瑉。当施设之不倦，幸发挥而有因。顾瞻之时，爱苔色之增丽；拂拭之后，觉花文之转新。振彼高价，膺兹美名，洁其内而冰彻，虚其中而砥平。嘉韫椟之资，忽雕镌而有立；以出蓝之色，作治莹而斯成。美乎充玩好，守坚贞，小大合度，高卑有程。谅当人而可托，信在物之惟精。厕彼华筵，云母之屏边色丽；置乎虚室，琉璃之窗下寒生。玉貌宜临，丹心可莹，成其高而有足，历其远而有胫。将以表青骨，传素心，既捧执以来此，亦保持而在今。甘寝之时，虚色而空怜角枕；闲居之处，凝光而但对瑶琴。是宜君子之好，用资端操，质美而微瑕莫容，色净而纤埃不到。况能坦荡而为物，以俟依凭而寄傲。伊锦绣之段，诚可见投；此琼玖之珍，是宜相报。平居之时，中心甚夷，当卓尔而空承简牍，忽藏诸而遂映帘帷。见贤之眼，惟永日而观矣；比德之心，可终朝而用之。则知瑰丽之状，物无以尚，欲随时而共美，因体物而先唱。空附识真之人，将一鉴其浏亮，（不见「物」字官韵）。
