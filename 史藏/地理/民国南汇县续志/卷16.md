## 南匯縣續志卷十六　人物志四

<span style="margin-left: 1em">人物志四</span>  
<span style="margin-left: 2em">游寓</span>  
<span style="margin-left: 2em">蕭雲經<sub class="note-yuan">父承萼</sub>毛祥麟</span>  
<span style="margin-left: 2em">陶　模汪人驥</span>  
<span style="margin-left: 2em">鄭　烺胡鎔熙</span>  
<span style="margin-left: 2em">金　玉俞廷颺</span>  
<span style="margin-left: 2em">改　簣吳修之</span>  
<span style="margin-left: 2em">張元復謝允培</span>  
<span style="margin-left: 2em">吳山喬李東沅</span>  
<span style="margin-left: 2em">彭以藩沈景修</span>  
蕭雲經字卿臺上海人父承萼字棣香避紅巾亂至新場後遷周浦風雅好客座滿屨綦詩學温飛卿温黁旖旎之作尤工長短句雲經年十二即能詩以知縣分發江西墨絰從戎歷十五年積功累保花翎三品銜即補知府歷任萍鄉廬陵龍南縣事皆有政聲  
毛祥麟字瑞文號對山上海人兩浙候補鹽大使避紅巾亂僑寄周浦好讀書工詩善畫山水尤精醫術性好客與里人朱作霖交莫逆拈韻分題酬唱無虛日情意肫摯撫教孤姪賙䘏戚族必竭其心力  
陶模字子方一字芷芳浙江秀水人洪楊之亂避地至新場貧而介時值喪偶因以訓蒙餬口沈静寡言授課外唯手一編亂定回籍成進士官至陝甘總督諡勤肅於時浙西名士如仁和樊恭煦稼軒錢德培琴齋洪昌燾子安洪衍慶宜孫秀水孫瀜次公陳春熙雪厂王坤瘦石金廷椿少愚陶　錐庵陶鎔鏡庵德清戚士廉砥齊戚士元曼亭戚人鑑麈仙或長經濟或善詩文或工書畫皆以新場爲樂土先後來游極一時之盛焉  
汪人驥字逸如安徽巢縣諸生本居上海避紅巾亂僑寄周浦爲文以理法勝巡道涂宗瀛重其品學聘主廣方言館講席晚益嗜學病中猶手錄困學紀聞諸家箋注蠅頭細楷一筆不苟卒年七十有四  
鄭烺字星聯晚號梧陽道人浙江歸安人貢生避亂僑居新場性恬淡不問户外事工書行草學坡公得其神似尤精醫理爲人治疾人酬以金輒儲充善舉  
胡鎔熙字眉泉安徽績溪人以賈至新場性慷慨好施予里有善舉必首先輸貲倡建新安思義堂尤爲同鄉所推重  
金玉字縵虹青浦貢生避亂至川沙又遷周浦著鶴沙集二卷皆僑居浦左時作也曾上書大府觸犯忌諱幾蹈不測上海令劉郇膏力救得免  
俞廷颺字彤侯青浦人廩生幼有穎異與婁縣李繼膺同邑熊其光莊世驥結吟花詩社有四才子之目學使李聯琇深賞其詩文與奉賢李花卿邑人丁宜福目爲雲間三子亂後遷居墓舍賊聞讀書聲欲夜獲之踰牖逃流徙至浦東宜福延諸家旋以喘疾卒宜福歸其喪<sub class="note-yuan">青浦縣志</sub>  
改簣字再薌華亭人祖琦字七薌以畫得重名簣僦居城北作畫能守家法富收藏善鑒別<sub class="note-yuan">參黃氏南沙雜志</sub>  
吳修之原名學鴻字次雲後改梅史上海諸生父機工詩與張紘顧成順相唱和嘗輯故舊投贈之詩爲懷雨集一卷修之天姿穎異筆下飄飄有凌雲氣友人以詩文質者竄易一二字即覺新穎奪目工畫花鳥隨筆揮灑神致生動題畫詩尤超妙然名終爲畫所掩  
張元復原名文錦字鳳巢號鎔深上海諸生其父經商至杜家行遂僑居焉元復少佐合肥李文忠公幕保舉訓導既而論事不合舍之走贛鄂皆無所遇遂拂衣歸得張文虎之賞拔主講上海廣方言館造就甚衆善交際人無論貧富貴賤遇之輒煦煦道寒温若甚親暱者  
謝允培字蘭階號叔愚上海貢生避紅巾亂僦居新場性恬静嫺吟詠家貧親老藉館穀以供甘旨循循善誘門下多知名士中表潘承湛遺囑教其三子凡豐脯敦聘者悉卻之三子卒皆成名  
吳山喬字山樵浙江黃巖人以文才著善摹鐘鼎古篆又能畫墨梅詩則淡遠蕭疏雅近韋孟以行伍立功保至提督承平後解甲歸田隱新場以筆墨博饔飱巡撫湘中聶緝槼檄令帶撫標衛隊旋殁於蘇  
李東沅字芷汀自號酒坐琴言室主浙江慈谿人幼孤貧鄉人挈之至周浦爲酒家傭暇即讀書遂能作詩上海王慶勳新年至周浦訪其戚薄游燈市見文虎語甚敏妙問之市人以東沅告召與語奇賞之攜之赴温處道任所令悉心求學越年即游庠領鄉薦旋入彭剛直公幕飛書草檄贊畫良多迨剛直薨落拓滬江爲賈人子司筆札侘傺以終  
彭以藩崇明人家一團泥城貧而勤讀初以訓蒙餬口脩脯所入置蕩田三十畝自耕自食家日以豐海濱民風強悍以藩思化以詩書之氣捐田二十畝假純陽道院設義塾又捐田十畝充興仁義塾經費酷恨煙賭有犯必懲故終彭之世煙寮賭窟泥城中無一存者  
沈景修字蒙叔晚號寒柯浙江秀水人拔貢生僑居新場工行楷書秀媚似右軍中年以後漸臻蒼老歸安沈秉成爲之延譽名乃大噪  
<span style="margin-left: 2em">游寓補遺</span>  
<span style="margin-left: 2em">張慕騫朱樹錕</span>  
<span style="margin-left: 2em">黃良弼黃益源<sub class="note-yuan">本銓</sub></span>  
<span style="margin-left: 2em">韓柳文俞萬同</span>  
張慕騫字雲槎熙純<sub class="note-yuan">光緒志有傳</sub>孫上海諸生寄居張江栅耽吟詠與馮金伯友善唱和甚多兼工度曲嘗秋試過常州訪其友有片刻木犀花下坐莫嫌草草過蘭陵句其風趣可想矣  
朱樹錕上海人寓周浦幼孝且慧家貧習賈悉所得以奉親咸豐辛酉粤匪擾浦東父先他出樹錕負母避鄉間匪追及之樹錕跽請曰如捨母願以身從匪信之俟母去遠遽投水死年祇一十有五同治七年旌如例  
黃良弼字夢卿上海人居新場精青烏術勇於任事粤匪至督鄉團禦之戰敗遇害事定旌如例  
黃益源字竹樓籍上海居黃家樓下善畫墨竹性剛俠道光時里有王金氏者與無賴夏三官通死其夫已瘞埋矣有賣餹人發其覆益源赴省白其冤大吏飭縣發墓出屍蒸檢氏伏誅夏不預謀遣戍陝西旋脫身投粤匪率其黨擾浦東獲益源將殺之其子長跽請代夏曰我殺而父報舊讐也何預爾事遂刳益源腹碎其體而投諸河䘏贈雲騎尉從子本銓字沐三上海諸生穎慧過人詩古文詞竝臻妙境  
韓柳文號申甫浙江蕭山諸生避粤匪亂僑居三墩歷受一團邵氏王氏之聘課徒之外枕經葄史尤精宋學後肄業上海龍門書院爲孫渠田鮑花潭兩山長所賞拔嘗著周易彙解蒐諸家易說而加以按語書未成而卒有文集行世<sub class="note-yuan">參南沙雜志</sub>  
俞萬同滁州人道光丁酉拔貢工詩文避難至馬路港夫婦相繼死里中沈氏爲之淺葬<sub class="note-yuan">府續志</sub>
