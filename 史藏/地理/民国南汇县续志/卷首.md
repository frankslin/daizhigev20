## 提要

南滙縣續志二十二卷首一卷江蘇儀征嚴偉廣東梅縣劉芷芬同修上海秦錫田等纂偉字覺之官南滙縣知事芷芬官南滙縣長錫田字硯畦號適盦清光緒間舉人官至內閣中書是志始事於民國十二年中遭齊盧之役兵燹骤起其議遂輟至十七年始克成書卷首列圖十有四其書分門十有六曰疆域曰水利曰建置曰田賦曰戶口曰學校曰祠祀曰兵防曰官司曰選舉曰藝文曰人物曰名迹曰風俗曰方外曰雜志凡子目百有七記事起清光緒四年迄宣統三年其書體例頗能隨時變置具見近世之遷革如兵防門增入南滙營外海水師新章學校門則載初等小學校高等小學堂中等及教會學堂皆足徵膠庠戎政之改制至若境內天主堂之設鄰邑奉賢光復軋花場之製紀述咸稱詳備復著其典當之業徧於全境冠乎江蘇皆極具方志之特徵卷尾附以遺事考證考勘精審亦足資考鏡焉  
　　　　　　　　　　　　　谷水道人撰  

## 序

共和紀元之第二年歲在癸丑孟冬之月余承符知南匯縣事習聞邑父老顧君旬侯<sub class="note-yuan">忠宣</sub>秦君亮臣<sub class="note-yuan">始基</sub>朱君子灝<sub class="note-yuan">祥紱</sub>之賢過從甚驩時顧君門人黃君祉安<sub class="note-yuan">報廷</sub>長縣議會徐君耐冰<sub class="note-yuan">守清</sub>任縣視學而唐君松盦<sub class="note-yuan">其寅</sub>則助秦君於地方財政處習普濟堂事并有賢名余官南匯纔一年報罷顧秦朱三君則始終參預地方政務爲士民所信仰初縣參議兩會議決續修縣志余甚韙之以黃君月波<sub class="note-yuan">炳奎</sub>及顧君年最高凡諸興革靡不通曉延主修志局事黃顧兩君卒繼之者爲祉安耐冰其後松盦主普濟堂以堂產糾紛時來告余因知志局諸君之賢志之成有日爲嘉慰者久之抑縣之有志疆域户口城防學校必詳必盡固已官斯土者有治績紀以名宦生斯土者有令譽紀以鄉賢余守官日淺教不行而令不立食祿者期年幾無一善可紀志之成祉安耐冰松盦三君不以余爲庸俗之吏徵序於余庸詎知余下筆序此書時當汗流浹背耶志仿松江府續志起前清光緒四年斷至宣統三年爲二十二卷圖志視舊書頗有增損則政治變遷爲之也志創於顧君而成於祉安之手有其師必有其弟故樂爲序其緣起如此紀元十八年五月前知南匯縣事儀徵嚴偉序  
南匯縣續志序  
民國四年三月余分修上海縣續志南匯朱君子灝以修志事來商且徵求纂輯之人才余曰修志之難不在於纂輯而在於采訪采訪不得人則捨精華而拾糟粕冗雜猥璅無所取裁間有一事可錄而原委混淆先後倒置問之訪員訪員置之不答或答非所問或答而不詳終至刪其成稿不能記載譬之飲食采訪者選置物品也纂輯者調和鼎鼐也山珍海錯精美鮮潔膳夫和以五味自堪適口若其肉腐魚敗雖有易牙無所措手故體例之不完密文辭之不雅馴纂者之咎也至於事實之乖舛典章之疏漏毀譽之顛倒咎不盡在纂者焉南邑采訪伊始必求其諳悉志例兼擅史才勤於諮詢熟於掌故如鄉先輩于充甫顧秋巖兩明經者庶幾去取悉當垂信將來朱君深以爲然於時南邑籌備修志聘黃丈月波顧丈旬侯爲主任黃丈旋歸道山顧丈獨任其事十二年八月修志局成立顧丈延余莅局與分纂諸君議定分類編輯乃披閲訪稿則搜羅未備采擇未精不能倉卒下筆復議推舉訪查員重加裒集未一年而齊盧搆釁風鶴驚心不遑鉛槧又年餘而顧丈作古人亡政息業將中輟十六年七月邑人士公推黃君祉安繼任志事黃君知訪稿之不詳不備猶乎四年前之狀態也爰周歷鄉曲以廣見聞徧搜案牘以備稽考分纂諸君亦知采訪之不足恃也不憚繁璅四出調查若馬君荻生之疆域顧君鐵生之建置盛君希伯之田賦徐君耐冰之學校葉君貞柏之物產王君季昆之列女傳皆淬精厲神周諮博訪隨得隨錄以底於成明年六月屬稿已具復集闔邑耆碩公同審核八月開始鏤板又一年而剞劂工竣蓋自開局至今已歷六載而此六載之中人事之變遷政體之改革紛紜擾攘杌隉不安以視同光間之運際中興修文偃武從容暇豫安心著述者其情狀固不相同而吾人之學問文章又未能抗希先哲則續貂之誚其奚能免余與志事相終始而有感乎諸君子之熱心毅力慎始圖終又致恫乎黃顧二丈之不及見也爰掇其顛末而爲之序中華民國十有八年九月上海秦錫田  

## 凡例

<span style="margin-left: 1em">會稽章學誠氏答甄秀才書曰修志當續前人之記載不當毀前人之成書又與戴東原書曰前志無憾則但當續其所有前志有闕則但當補其所無本志依此宗旨專爲光緒志之續</span>  
<span style="margin-left: 1em">本志限斷起光緒四年訖宣統三年九月</span>  
<span style="margin-left: 1em">光緒志爲類十六爲子目八十六本志沿用前例唯子目則因時勢之變遷畧有增減爲一百有七</span>  
<span style="margin-left: 1em">濱海漲灘半成沃產邑境形勢迥異曩時轄海之權關係尤重故本志冠以邑境總圖次以海境圖</span>  
<span style="margin-left: 1em">清季創辦自治城區之外又劃全境爲二鎮十七鄉本志各製一圖以著自治之區域</span>  
<span style="margin-left: 1em">光緒志采輯藝文但憑目見不據空名第通人著述有名滿衆口而書已散佚者有繕寫之孤本書存而未經送局者概令湮没心殊不安本志著錄之書雖不皆目覩必有依據一以備將來之徵訪一以慰作者之苦心</span>  
<span style="margin-left: 1em">光緒志以川沙自有志書皆可從畧但川境之典章法令固不宜攔入若其人名列本邑之黌籍而平生行義屏不載錄於理似不可通本志依上海縣志例間爲立傳</span>  
<span style="margin-left: 1em">松江府續志卷後皆有補遺考證一以補舊志之闕畧一以正舊志之疏舛本志循用此例惟續府志分隸子目之後本志畧爲變通</span>  
<span style="margin-left: 1em">舊志紀事詳於啚而畧於團蓋當時團區地褊而事寡也今則斥鹵漸爲膏腴生齒日繁人文蔚起故本志記載亦較昔加詳而於河渠道路尤致意焉</span>  
<span style="margin-left: 1em">本志采掇訪稿佐以官廳之案牘參以私家之著述其無可依據者皆從簡畧拾遺補闕跂俟明哲</span>
