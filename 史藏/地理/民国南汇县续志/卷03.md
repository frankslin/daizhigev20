## 南匯縣續志卷三　建置志

<span style="margin-left: 1em">建置志</span>  
<span style="margin-left: 2em">城池</span>  
光緒二十一年六月十九夜大雷電南門城樓東城牆觸電毀雉堞三垛旋即修理如舊宣統二年知縣畢培先以四門城樓損壞已多籌款重修  
<span style="margin-left: 2em">萬壽宮</span>  
萬壽宮光緒二十年慈禧皇太后萬壽將行朝賀盛典宮牆有坍毀者朝門戲臺覲光樓闕樓拜廳朝房等有欹側滲漏者門窗亦多剝落者知縣汪以誠諭城董陳錦柏等重修費錢二百六十三千三百文  
<span style="margin-left: 2em">衙署</span>  
縣署大堂二堂及大堂左右庫房等年久失修幾坍毀光緒初知縣顧思賢詳准撥給租課款項大修五年知縣吳觀樂稟准借廉俸重修三堂等處宣統二年知縣賴豐熙撥盛姓捐款翻造大堂外東西兩廊科房  
縣丞署舊址同治十一年併入東常平倉地創建積穀倉  
訓導署<sub class="note-yuan">詳光緒志</sub>  
典史署<sub class="note-yuan">詳光緒志</sub>  
都司署基地<sub class="note-yuan">詳光緒志</sub>  
守備署基地<sub class="note-yuan">詳光緒志</sub>  
周浦三林莊巡檢署基地<sub class="note-yuan">詳光緒志</sub>  
金山屯署<sub class="note-yuan">詳光緒志</sub>俗呼金山衛署清季衛官<sub class="note-yuan">守備</sub>裁署發賣邑紳王震購之改建民屋設義務小學於其中  
大團鎮下沙場署基<sub class="note-yuan">詳光緒志</sub>  
新建縣丞署在泥城自縣丞移駐後向未建署光緒十六年由本地紳士稟准捐建大堂三間東西廂屋六間頭門五間宣統元年知縣王念祖撥款八百元諭董添建後進正屋五間廂房兩間  
<span style="margin-left: 2em">倉廒</span>  
積穀倉光緒志頭門以外有照牆一座牆東平廒房五間今查頭門外竝無照牆面北平廒房則增爲十一間用何款改建及改建於何時待考<sub class="note-yuan">查徵信錄第一冊所載倉房與光緒志同以後各冊竝無改建報銷訪諸故老咸謂數十年來向見如是夫既數十年來如是度其改建必在光緒初年又自團啚管理權劃分後以頭門面北廒間作爲團有餘屬啚有以此推之改建增廒費或出自團也</sub>  
宣統元年將外頭門南首毘連之二間舊歸縣署科房用者改建歸倉用先時外頭門間已裝修佔用至此南北相連共用三間  
西常平倉光緒三十四年改建習藝所  
周浦西市糧倉基清季由縣自治機關稟准立碣作爲全縣公共體育場  
<span style="margin-left: 2em">禁獄</span>  
監獄<sub class="note-yuan">詳光緒志</sub>  
自新所舊時自新所省悟所左右分列同在典史署之西又有東待質所俗呼東飯歇亦設於此今皆併作看守所<sub class="note-yuan">另有西待質所俗呼西飯歇現爲班房茶館之一部分</sub>  
習藝所光緒三十四年知縣李超瓊就縣署西首常平倉基諭董秦始基胡世英督造樓平房四十五間內工廠五間宿舍十間工師室二間收藏工器室一間病房一間暗室一間思過室一間看役室一間更房一間浴室一間會客廳三間會計室一間卧室三間原料儲積室二間成物陳列室三間厨房三間門房一間過道一間柴薪室一間米倉一間雜作室一間探晤室一間計共費銀一萬二千六百餘元  
<span style="margin-left: 1em">建築費之由來　由五十市鄉紳富捐資官廳撥給罰款相輔而成其中捐款最大者邵錫瓚爲母請旌捐銀一千五百兩罰款最大者馬姓銅圓案三千元其餘均由紳富集成</span>  
<span style="margin-left: 1em">開辦經費及年月　宣統元年四月知縣王念祖准縣自治機關公推奚光耀爲總理胡世英胡咸章爲坐辦開辦費及常年經費均賴紳富捐及官廳撥給罰款充用初時定名爲罪犯習藝所兼收各市鄉無業莠民額定八十名由官廳發押者口糧由官廳發給由市鄉送所者每名收膳費洋六元敗家子弟由家長送所代爲管教者酌捐若干擾害地方無家可靠之人由各鄉經董送所者免貼膳費宣統三年九月十八日海匪樊培生糾黨進城擾亂秩序劫放監所押犯習藝所亦暫解散</span>  
<span style="margin-left: 2em"><sub class="note-yuan">附宣統元年詳定章程</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第一章總綱</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第一節　本所遵飭開辦先收在禁及押所罪犯兼收城鄉呈送莠民名曰南匯縣習藝所每月將人犯造冊報縣</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第二節　本所設總理一員坐辦兩員由縣紳會議遴選公正紳董承充縣給照會設書記兼庶務一人會計一人監工兼稽察一人買辦一人巡警八名看役兩名伺應夫兩名門房一名更夫一名均由總理坐辦擇勤慎耐勞之人充當各項工藝教師隨時酌雇</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第三節　總理月支公費銀二十元坐辦每人月支公費銀十二元司事每人月支薪水銀八元工師巡警及各夫役由總理坐辦分別等差酌定數目按月給發一概不准預支</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第四節　本所設在縣署大堂西首內計工廠五大間罪犯宿舍十間議事廳一間會計室一間書記室一間監工室一間買辦室一間客廳兼飯廳一間巡警坐卧室兩間犯親探晤室一間工師坐卧室三間收藏工作器具室一間粗料儲積所兩間細料儲積所一間成物陳列所兩間賣物所一間看役伺應膳夫卧房各一間厨房三間大門一間廳門過道樓下過道各一間</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第五節　本所設名譽贊助董十四人查帳董四人每月初十到所研究一切詳查帳目設遇重大事件由總理隨時定期傳知開特別會以到者過半取決多數議決案由書記員登簿記考</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第六節　凡有發配南邑軍流徒及擬定監禁習藝年限各犯如遇脫逃典史例有處分今遵章收所習藝由縣札飭典史一體就近照料如法管束如有脫逃典史及看守兵役率照舊例參辦如扣足一年竝無疏脫專管官照章請奬</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第七節　本所開辦經費已向各紳富勸捐常年經費另由官紳籌議詳請立案</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第二章　職員</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第一節　總理坐辦爲所中領袖要和衷共濟執行章程監察一切所有司事夫役人犯無使怠惰工料日用無使縻費坐辦二人不得同時回家如有夫役人等不守規則輕則徹换重則送縣懲處</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第二節　本所由縣刊發木質南匯縣習藝所圖記一顆以昭信守歸總理收掌與縣公牘照商會例用牒呈</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第三節　書記兼庶務專司所中往來公牘冊籍印收及登記罪犯莠民姓名年歲面貌箕斗籍貫住址罪狀刑期家屬保證收放時日兼糾正所內各司事夫役不合規則之處</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第四節　會計專司所中一切銀錢收支稽查買賣貨物帳目倘有差誤惟會計是問本所帳款分爲收支二項凡薪工伙食備辦物料及一切修理雜用皆屬之付項歲入專常捐撥各款及成貨售款皆屬之收項每月一小結每季一大結年終總結按季報縣查考每年總結造徵信錄冊印送各區</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第五節　監工及稽察專司廠中工藝物件監督工師訓教犯人勤工守法兼稽察巡役勤惰查看犯人飲食起居衛生事宜察驗宿舍及各處牆垣門栅如有損壞立刻雇匠修補其厨房及堆積柴薪處所更宜督率夫役格外小心防檢</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第六節　買辦專司所中購買原料發給犯人收回成物定價出售無論原料成物均要妥慎收儲詳細登簿隨時將價目銀開列清冊交會計核明收付</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第七節　本所總理坐辦三年一任任滿及有臨時別故者由縣傳集各區紳董公議接充如被選連任者准之名譽贊助董及查帳董一年任滿公議選舉如有被選連任者亦准</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第三章　巡役</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第一節　巡警八名以四名站工廠四名駐守大門均不許片刻擅離每兩小時調班如有犯人口角爭毆立即喝散或拘送總理坐辦議處若聚衆兇毆毀物圖脫立鳴警笛集衆拘拏倘敢拒捕傷人格殺勿論</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第二節　看役二名專管罪犯宿舍啓閉稽查人數及違禁物件禁止口角爭吵督率輪值人犯灑埽潔浄夜間時常巡察如有不守規則及圖脫形跡報警拘拏送請總理坐辦懲處</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第三節　門房一名專司早晚大門啓閉凡遇賓客往來官紳來拜均須問名登入門簿如有犯人家屬來所探望應詳詢姓名年歲住址欲探何犯與犯何親有無函件帶交一一登簿有則先呈坐辦或監工驗明竝無禁物方許將來人帶進交巡警入廠門俟其出時仍由門房帶出倘有閒雜人等窺探滋擾立報巡警驅逐</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第四節　伺應夫二名專備所員送信購物伺應來賓各項差遣膳夫二名專司全所伙食另撥輕罪人犯輪值汲水燒火洗物各項雜務更夫一名按時擊柝周巡更衖各處</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第四章　罪犯莠民</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第一節　本所現定額一百二十名除由縣撥發已定罪名人犯外如有小竊流氓惡丐棍徒遊蕩無賴有礙地方治安應由公正紳董函開事實拘送到所經總理核明加片解縣即日過堂量其情節輕重酌定期限發所習藝藝成限滿即准保釋如限內藝成毫無過犯真能悔過自新者亦准報縣察核保釋倘有兇橫不法之徒擾害地方紳董等不能拘解可先將犯事實跡開送本所由所送縣請派巡警差役協保指拏一經獲案訊實或擬罪詳辦或發所習藝由縣酌核辦理所有縣中差堂各費一律除免</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第二節　紳董公送莠民由縣查訊確實判定期限發所習藝應由原送之紳董貼所中三個月膳費洋六元衣被均由紳董備送如由其父母族長呈送則三個月膳費及衣被歸其父母族長貼備均由書記檢驗登冊</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第三節　入所各犯編定宿舍工廠號舍登明各簿即給號衣不准私自移易無論何項煙草不准各犯吸食宿舍內禁用燈火如有煙癮人犯給服林文忠戒煙丸逐日遞減戒浄</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第四節　罪犯釘鐐習藝如私自開放及脫逃被獲送縣嚴懲加釘雙鐐收所拘禁減膳莠民免其釘鐐如脫逃被獲亦送縣懲處釘鐐收所罰作苦工如脫逃人犯不論何人拏獲以及報信因而拏獲者均由所酌給奬賞</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第五節　凡人犯家屬探望由門房報明經坐辦及監工允准派巡警帶至探晤室監視立談不准低聲小語及私遞信函物件接談不得過五分鐘語畢人犯即由巡警帶交監工來人即由門房帶出不准逗留窺視</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第六節　習藝人犯照各處定章每日早晚兩餐每月給葷膳兩次自清明至白露每日加給一餐</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第七節　習藝人犯如不守規則屢教不悛輕則罰作苦工或減其食料重則送縣嚴懲或禁錮暗室</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第八節　罪犯每年冬季各給棉衣袴一身夏季各給單衣兩身蓆一條扇一柄衣用藍色背釘白布書明該犯姓名號數</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第九節　凡所內各處灑埽及清除廁所竝一切雜役均不雇用人夫由總理懸牌派令輕罪人犯輪值不准推諉</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第十節　習藝人犯患病由監工看役報告坐辦驗明遷入病房延醫調治如輕罪人犯及莠民病危立即報縣傳屬領回醫治痊愈送所設有病故報縣詣驗由善堂棺殮發壇浮厝飭屬領葬</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第五章　工作</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第一節　本所工藝先設織草蓆作麻袋編蒲包結魚網裁縫衣服製造鞋襪編造竹籐器具各雇工師教授餘藝陸續擴充如有罪犯勤於工作出貨優美習藝成就由總理驗明給賞或拔作工師教授各人犯</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第二節　本所上工散工會食及早起晚睡均以敲鐘爲號各人犯聞鐘即須齊起聚集早晚由監工查點人數挨次進出不得雜亂喧譁</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第三節　習藝人犯工作時刻按冬夏日之長短隨時牌示冬日以八小時夏日以十小時爲率毋任曠誤</sub></span>  
<span style="margin-left: 1em"><sub class="note-yuan">第四節　每逢萬壽節端午中秋除夕元旦至初三竝元宵各停工休息一日給葷食一餐每逢星期下午停工由坐辦邀請學堂教員演講修身勤業因果各事實以冀改悔感悟由工師比較各該犯工作勤惰良窳分別存記立表榜示</sub></span>
