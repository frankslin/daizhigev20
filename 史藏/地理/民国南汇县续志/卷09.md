## 南匯縣續志卷九　兵防志

<span style="margin-left: 1em">兵防志</span>  
<span style="margin-left: 2em">兵制</span>

<span style="margin-left: 2em">弓兵</span>

<span style="margin-left: 2em">海防</span>

<span style="margin-left: 2em">防兵</span>

五團普濟蕩事連年糾紛不解輒滋事端光緒三十一年邑令王念祖詳請江蘇提督　派兵八棚以二棚駐蕩二棚駐竹橋三棚駐大團一棚駐新場三十二年復請提督劉派兵二棚駐蕩一棚駐竹橋由趙宗保管帶以增防護<sub class="note-yuan">改革時諸營盡撤惟趙哨官營改爲衛隊移駐縣公署</sub>  
<span style="margin-left: 2em">徵兵</span>  
光緒三十一年江蘇督練公所督辦陸鍾琦通飭蘇松太三屬遵照頒布徵兵定章先行開辦竝派委徵兵官到境會辦按格選募知縣李超瓊照會各董就地勸諭復親詣各鎮鄉演說徵兵大旨鼓勵人民三十二年本邑申送四十一人迨到省後間有逃歸者此令旋廢  
<span style="margin-left: 1em"><sub class="note-yuan">松屬徵兵正官阮慕咸勸應徵兵啓古無所謂兵也三代之世兵民合一聚則爲兵散則爲民不待徵發而師徒之數按冊可稽故其時無游民無冗卒也方今泰西各國兵制猶爲近古又其風氣右武雖以王公子弟之貴亦必身入行間而閭左齊民一隸兵籍即克與貴族子弟編伍同列故人人以當兵爲榮而兵亦皆人人自重現值朝廷發奮爲雄追蹤隆古抗衡泰西略師其意參用其法以力挽近來軍營之積弊自去年北洋大臣舉行徵兵之令一下公卿子弟與夫舉貢生監入伍者時有所聞一見於直隸深州之某孝廉率同親族門生計廪生二人文生五人具禀請發往陸軍充當正兵一見於安徽之新徵兵士內有江蘇候補道程襲爵建勳之長公子晉藩投入該營右隊補充兵籍一時從戎之士皆稱道之前蘇撫憲陸仿北洋之制舉行就地徵兵不徒爲強兵計抑實爲地方自治之基礎夫吳人本習戰陣前志稱其爲天下精兵郡國志亦言吳俗多鬬將戰士可見吳人素非文弱人人有軍人資格人人有國家思想宜其徵無不應者也況徵兵之制與從前召募迥殊有事呈地方官則如生監遣抱退伍回籍則有董保鼓吹歡迎今長元吳三邑紳士撰有徵兵公啓定章優待其例有四一三邑壯士有應徵者各學會各學堂敬援入泮例公具彩旗鼓樂迎送入伍宗族交游一律道賀一應徵以後其家有要事相識者皆往相助毋使有內顧憂一入伍學成後有由學堂延爲教習者其子弟入學一概不取學費一兵士得有善行證書者凡遇公集禮延上座足見應徵之兵爲學界所歡迎爲鄉里所崇拜爲國家所旌異凡我壯士亟宜起而應之同心協力相率偕來地方之幸抑亦三吳父老三薰三沐馨香禱祝以樂觀其慷慨請纓者也</sub></span>
