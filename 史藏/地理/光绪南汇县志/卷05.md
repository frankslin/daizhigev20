## 光绪南汇县志卷五　田赋志下

<span style="margin-left: 2em">田赋志下</span>  
<span style="margin-left: 3em">盐场</span>  
<span style="margin-left: 1em">明洪武元年立都转运盐使司于杭州设松江分司于</span>  
<span style="margin-left: 1em">下沙下沙场统领九团正统五年分场为三每场辖三</span>  
<span style="margin-left: 1em">团各置大副使是时计丁授荡<sub class="note-yuan">煎盐者为灶丁去场三十里者为水乡不及三十里者为滨海水乡丁不能煎盐例出柴卤价米石贴滨海丁代煎</sub>每丁受草荡十八亩</span>  
<span style="margin-left: 1em">零岁支工本钞二贯六百余文办盐二引二百余斤成</span>  
<span style="margin-left: 1em">化二十年以盐仓走卤消折每三分之二存场给客其</span>  
<span style="margin-left: 1em">一分改折银两纳官解京嘉靖中遂全征折色然灶丁</span>  
<span style="margin-left: 1em">与荡尚未分也隆万闲有霸占灶荡者有贫灶出佃与</span>  
<span style="margin-left: 1em">人者有私相典卖者有并归总催者<sub class="note-yuan">丁多而富者佥报总催</sub>于是</span>  
<span style="margin-left: 1em">或有丁而无地或占地而非丁万历四十二年裁定派</span>  
<span style="margin-left: 1em">征水乡草荡白涂仓基解京银数自是丁银征荡而灶</span>  
<span style="margin-left: 1em">与荡分矣<sub class="note-yuan">府志云明嘉靖闲倭乱灶户逃亡丁课已归地亩征输钦志云盐课归荡实在万历闲</sub></span>  
<span style="margin-left: 1em">其课银以各团总催充解户<sub class="note-yuan">小户皆由总催催办</sub>每年三限经松</span>  
<span style="margin-left: 1em">江分司验封自赴两浙运司兑收耗倍正供</span>  
<span style="margin-left: 1em">国朝顺治初年盐课官制悉仍明旧<sub class="note-yuan">府志云顺治元年设两浙巡盐御史二年设松江分司领盐课司六</sub>康熙二十六年浙江巡抚金𬭎奏准各</span>  
<span style="margin-left: 1em">场盐课归县征收解两浙运司小户得自输将大户得</span>  
<span style="margin-left: 1em">免解费民甚便之三十六年复归场征三十八年两江</span>  
<span style="margin-left: 1em">总督张鹏翮定议复归县征四十三年裁松江分司归</span>  
<span style="margin-left: 1em">并嘉兴分司管辖后又裁二三场大使归并一场<sub class="note-yuan">康熙四十一年裁三场雍正二年裁二场</sub>雍正七年浙督李卫请复设二场大使</span>  
<span style="margin-left: 1em">将下沙三场原地酌量中分其一二三四团额课属一</span>  
<span style="margin-left: 1em">场五六七八九团额课属二场更定场征县解之例乾</span>  
<span style="margin-left: 1em">隆五年复设三场并为下沙二三场其各团分属如故</span>  
<span style="margin-left: 1em">五十八年户部议定场员征收径解运库至今因之<sub class="note-yuan">雍正四年分县下沙场地全隶南邑嘉庆十五年八九两团分隶川沙厅</sub></span>  
<span style="margin-left: 1em">下沙场盐荡共四千三百十四顷六十二亩有奇<sub class="note-yuan">一场一千六百三十二顷十一亩有奇二场一千一百八十八顷三十九亩有奇三场一千四百九十四顷十亩有奇</sub></span>
