## 光緒南匯縣誌卷一　疆域志

<span style="margin-left: 2em">疆域志</span>  
<span style="margin-left: 3em">形勢</span>  
<span style="margin-left: 1em">南滙縣地在黃浦東南明洪武初於華亭南境置金山</span>  
<span style="margin-left: 1em">衞領千戶所六南滙其一也十九年建築城池於三團</span>  
<span style="margin-left: 1em">地即今邑城以大海環其東南潮汐折旋南派入浙江</span>  
<span style="margin-left: 1em">北派入大江故名　國朝雍正三年分上海浦東地長</span>  
<span style="margin-left: 1em">人鄉爲南滙縣治南滙城編戶凡一百六十六里東西</span>  
<span style="margin-left: 1em">廣九十里南北袤八十四里<sub class="note-yuan">欽志</sub></span>  
<span style="margin-left: 1em">自嘉慶十六年畫分南滙十七保二十保之一十啚及</span>  
<span style="margin-left: 1em">二三場之八團九團爲川沙廳界自奉南界河至川沙</span>  
<span style="margin-left: 1em">南門外之竹行橋南北袤七十里自西南千步涇曲折</span>  
<span style="margin-left: 1em">至西北龍王廟又折而至馬家浜仍袤八十餘里此與</span>  
<span style="margin-left: 1em">前不同之形勢也</span>  
<span style="margin-left: 1em">南滙地勢如犂狀突出洋中勢向東南三面皆海故謂</span>  
<span style="margin-left: 1em">之南滙嘴前明倭寇每察風色分䑸於洋山馬磧如東</span>  
<span style="margin-left: 1em">南風則此嘴大𣼷口當洋山之衝如東北風則此嘴四</span>  
<span style="margin-left: 1em">五六團洪當馬磧之衝<sub class="note-yuan">欽志</sub></span>  
<span style="margin-left: 1em">南滙嘴亦名老鸛嘴東南爲翁家港向係南滙營與青</span>  
<span style="margin-left: 1em">村營會哨處水勢極險<sub class="note-yuan">胡志</sub></span>  
<span style="margin-left: 1em">邑東沿海一帶皆鐵板沙船最難泊且縣治歷內外捍</span>  
<span style="margin-left: 1em">海塘及蘆蕩鹽場沙嶺約三十里較之上邑海舟得由</span>  
<span style="margin-left: 1em">吳淞口直達城下者異前明倭犯上海薄黃浦逼城下</span>  
<span style="margin-left: 1em">吾地反在其外若統練精兵自外衝擊虜勢立絀矣<sub class="note-yuan">欽志</sub></span>  
<span style="margin-left: 1em">欽志云大海東環黃浦西亙非特東南一郡之屏障實</span>  
<span style="margin-left: 1em">亦江浙海防之要衝今按護海塘如長虹環亙自江浙</span>  
<span style="margin-left: 1em">交界之金山衞城以及柘林青村而下不半日走馬可</span>  
<span style="margin-left: 1em">達咸豐十一年冬粤寇由浙省闖入金山直抵奉賢南</span>  
<span style="margin-left: 1em">滙川沙盤踞各城市窺伺上海寶山旋於同治元年五</span>  
<span style="margin-left: 1em">月朔南滙城首先招降又連復川奉兩城駐滬者無東</span>  
<span style="margin-left: 1em">顧之憂得以併力攻拔金山而蘇州嘉興以次進勦則</span>  
<span style="margin-left: 1em">南滙豈特江浙海防之衝陸路亦其扼要也明信國公</span>  
<span style="margin-left: 1em">不築城於川沙而築於南滙蓋有見焉</span>  
<span style="margin-left: 1em">自七團出海迤東至崇明洋中流將近銅沙之淡水內</span>  
<span style="margin-left: 1em">洋向爲南滙營川沙營巡哨交界處<sub class="note-yuan">按銅沙在崇明東南洋自銅沙以外爲外洋鹹水自銅沙以內爲內洋淡水</sub></span>
