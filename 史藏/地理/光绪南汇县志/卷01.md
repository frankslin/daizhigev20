## 光绪南汇县志卷一　疆域志

<span style="margin-left: 2em">疆域志</span>  
<span style="margin-left: 3em">形势</span>  
<span style="margin-left: 1em">南汇县地在黄浦东南明洪武初于华亭南境置金山</span>  
<span style="margin-left: 1em">衞领千户所六南汇其一也十九年建筑城池于三团</span>  
<span style="margin-left: 1em">地即今邑城以大海环其东南潮汐折旋南派入浙江</span>  
<span style="margin-left: 1em">北派入大江故名　国朝雍正三年分上海浦东地长</span>  
<span style="margin-left: 1em">人乡为南汇县治南汇城编户凡一百六十六里东西</span>  
<span style="margin-left: 1em">广九十里南北袤八十四里<sub class="note-yuan">钦志</sub></span>  
<span style="margin-left: 1em">自嘉庆十六年画分南汇十七保二十保之一十啚及</span>  
<span style="margin-left: 1em">二三场之八团九团为川沙厅界自奉南界河至川沙</span>  
<span style="margin-left: 1em">南门外之竹行桥南北袤七十里自西南千步泾曲折</span>  
<span style="margin-left: 1em">至西北龙王庙又折而至马家浜仍袤八十余里此与</span>  
<span style="margin-left: 1em">前不同之形势也</span>  
<span style="margin-left: 1em">南汇地势如犂状突出洋中势向东南三面皆海故谓</span>  
<span style="margin-left: 1em">之南汇嘴前明倭寇每察风色分䑸于洋山马碛如东</span>  
<span style="margin-left: 1em">南风则此嘴大𣼷口当洋山之冲如东北风则此嘴四</span>  
<span style="margin-left: 1em">五六团洪当马碛之冲<sub class="note-yuan">钦志</sub></span>  
<span style="margin-left: 1em">南汇嘴亦名老鹳嘴东南为翁家港向系南汇营与青</span>  
<span style="margin-left: 1em">村营会哨处水势极险<sub class="note-yuan">胡志</sub></span>  
<span style="margin-left: 1em">邑东沿海一带皆铁板沙船最难泊且县治历内外捍</span>  
<span style="margin-left: 1em">海塘及芦荡盐场沙岭约三十里较之上邑海舟得由</span>  
<span style="margin-left: 1em">吴淞口直达城下者异前明倭犯上海薄黄浦逼城下</span>  
<span style="margin-left: 1em">吾地反在其外若统练精兵自外冲击虏势立绌矣<sub class="note-yuan">钦志</sub></span>  
<span style="margin-left: 1em">钦志云大海东环黄浦西亘非特东南一郡之屏障实</span>  
<span style="margin-left: 1em">亦江浙海防之要冲今按护海塘如长虹环亘自江浙</span>  
<span style="margin-left: 1em">交界之金山衞城以及柘林青村而下不半日走马可</span>  
<span style="margin-left: 1em">达咸丰十一年冬粤寇由浙省闯入金山直抵奉贤南</span>  
<span style="margin-left: 1em">汇川沙盘踞各城市窥伺上海宝山旋于同治元年五</span>  
<span style="margin-left: 1em">月朔南汇城首先招降又连复川奉两城驻沪者无东</span>  
<span style="margin-left: 1em">顾之忧得以并力攻拔金山而苏州嘉兴以次进勦则</span>  
<span style="margin-left: 1em">南汇岂特江浙海防之冲陆路亦其扼要也明信国公</span>  
<span style="margin-left: 1em">不筑城于川沙而筑于南汇盖有见焉</span>  
<span style="margin-left: 1em">自七团出海迤东至崇明洋中流将近铜沙之淡水内</span>  
<span style="margin-left: 1em">洋向为南汇营川沙营巡哨交界处<sub class="note-yuan">按铜沙在崇明东南洋自铜沙以外为外洋咸水自铜沙以内为内洋淡水</sub></span>
