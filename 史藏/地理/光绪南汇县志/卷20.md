## 光绪南汇县志卷二十　风俗志

<span style="margin-left: 2em">风俗志</span>  
<span style="margin-left: 3em">风俗</span>  
<span style="margin-left: 1em">南邑濒海阻浦冠盖商贾罕至故俗尚耕织风多俭勤</span>  
<span style="margin-left: 1em">犹为近古然西连奉邑近于乔野北接上海习于浮华</span>  
<span style="margin-left: 1em">士大夫好读书尚气节而呰窳之徒好訾议结党聚讼</span>  
<span style="margin-left: 1em">持官府短长者闲亦有之<sub class="note-yuan">参钦志</sub></span>  
<span style="margin-left: 1em">吉凶多沿俗礼丧事尚佛老祭多以俗节清明七月半</span>  
<span style="margin-left: 1em">十月朝之类婚丧费尤侈</span>  
<span style="margin-left: 1em">邑素崇俭朴虽士大夫家居衹布素有事暂服绸绫今</span>  
<span style="margin-left: 1em">差役之流居然天青缎套其妇女亦天青缎披红绉裙</span>  
<span style="margin-left: 1em">满头金珠矣咸丰初年宴会犹衹八簋今则多用燕窝</span>  
<span style="margin-left: 1em">鱼翅炙煿诸品良由近沪相沿成习渐趋华靡云</span>  
<span style="margin-left: 1em">造墓惑于风水为选地过苛迁延岁月其后或以家道</span>  
<span style="margin-left: 1em">中落或以兄弟消长不齐积棺累累有数十年不克葬</span>  
<span style="margin-left: 1em">者甚至厝之荒野年久坍毁虽经地方官催趱掩埋而</span>  
<span style="margin-left: 1em">置若罔闻咸丰辛酉发逆窜扰凡空屋停棺多被发掘</span>  
<span style="margin-left: 1em">甚或纵火焚烧暴骨尤为可惨然事定后仍蹈故习<sub class="note-yuan">参钦志乔钟吴海上乐府浮茔椁田野闲云谁无父母骨朽不相关云谁非人子亲丧若等闲有钱择佳地有地择佳辰富家不易葬贫家葬尤难岁月易迁流门户忽衰残荒郊多悲风吹此白骨寒昔为华屋人今为无主棺</sub></span>  
<span style="margin-left: 1em">俗信神鬼病则多事祈祷男巫曰火居<sub class="note-yuan">华娄金青闲曰太保</sub>女巫</span>  
<span style="margin-left: 1em">曰师娘俗又谓看仙言能与鬼神通语不独乡愚为其</span>  
<span style="margin-left: 1em">所惑士族亦有信之者<sub class="note-yuan">参钦志</sub></span>  
<span style="margin-left: 1em">四月十二日为城隍白夫人诞商贾云集庙中演戏小</span>  
<span style="margin-left: 1em">家妇女排坐东西楼观剧浮荡子弟评头量足腆不为</span>  
<span style="margin-left: 1em">怪县署旧有赏花例妇女至者插花饮酒虽意取劝农</span>  
<span style="margin-left: 1em">实乖政体前令王其淦详请革除而以其费为恤嫠用</span>  
<span style="margin-left: 1em">浦东地瘠而农民颇耐作苦种稻者曰水田种棉花黄</span>  
<span style="margin-left: 1em">豆者曰旱田今岁稻来岁花豆者曰翻田翻田必以牛</span>  
<span style="margin-left: 1em">犁余则或以牛或以人人日耕一亩率十人当一牛水</span>  
<span style="margin-left: 1em">田用车戽水近浦通潮易为力其潮汐所不及者岸峻</span>  
<span style="margin-left: 1em">水车陡立非五六人不能运夏日男女赤汗交流邪许</span>  
<span style="margin-left: 1em">之声相闻有不用人而以牛运者其形如轮横辗以转</span>  
<span style="margin-left: 1em">水车之轴俗名牛车<sub class="note-yuan">钦志参胡志</sub></span>  
<span style="margin-left: 1em">浦东宜棉不宜稻稻田遇大熟年可收二石中年祇一</span>  
<span style="margin-left: 1em">石五六斗歉则一石左右土民不敷所食必俟苏常贩</span>  
<span style="margin-left: 1em">来乾隆五十九年岁祲米每石腾贵至六千文道光三</span>  
<span style="margin-left: 1em">年十三年二十九年水灾米每石至六千余文出米之</span>  
<span style="margin-left: 1em">乡奸民结党阻籴各镇米铺俱以二百文为限同治元</span>  
<span style="margin-left: 1em">年发逆退后外来米每石十二千文后以次递减至六</span>  
<span style="margin-left: 1em">七年始平至三四千文<sub class="note-yuan">按米自江北来者曰下河籼自关东来者曰牛庄籼牛庄最佳江北次之然终不及苏松常之稌米</sub></span>  
<span style="margin-left: 1em">浦东种稻较迟于浦南而获则反先七月中新谷已登</span>  
<span style="margin-left: 1em">八九月闲几无遗秉矣盖地气使然</span>  
<span style="margin-left: 1em">农家秋成曰大熟麦秋曰小熟人皆藉小熟以种大熟</span>  
<span style="margin-left: 1em">麦有小麦大麦圆麦小麦为面大麦圆麦贫家糁米作</span>  
<span style="margin-left: 1em">饭俗曰麦粞故他邑有东乡麦子之称<sub class="note-yuan">钦志</sub></span>  
<span style="margin-left: 1em">傍浦种秔稻者十之三种木棉者十之七妇女馌饷外</span>  
<span style="margin-left: 1em">耘获车灌与男子共作苦盛夏赤日中耘草棉田俗谓</span>  
<span style="margin-left: 1em">脱花<sub class="note-yuan">脱宜为捝解捝也谓为草所缠而解捝之俗通作脱浦南人呼如挞声之转</sub>汗雨交流</span>  
<span style="margin-left: 1em">热极就塘掬水饮之甚或和衣入水浸片时不特贫家</span>  
<span style="margin-left: 1em">妇女为然即温饱家亦必躬亲操作俗谓领脱花</span>  
<span style="margin-left: 1em">海滨八九月闲大风雨曰风潮风潮所过花稻之早者</span>  
<span style="margin-left: 1em">减收其晚者祇存空茎农家占验云白露看花秋看稻</span>  
<span style="margin-left: 1em">屡试屡验</span>  
<span style="margin-left: 1em">妇女纺织佐衣食不第乡落虽城市亦然纺纱他邑止</span>  
<span style="margin-left: 1em">用两指撚一纱者名手车邑多一手三纱以足运输名</span>  
<span style="margin-left: 1em">脚车织布率日成一疋甚有一日两疋通宵不寐者故</span>  
<span style="margin-left: 1em">男子耕获所入输官偿息外未卒岁室已罄<sub class="note-yuan">俗有六十日财主之称</sub>其衣食全赖红女<sub class="note-yuan">参钦志胡志</sub></span>  
<span style="margin-left: 1em">土俗向不解蚕桑粤寇之乱浙西及江甯避难者多至</span>  
<span style="margin-left: 1em">浦东遂开其端前令罗嘉杰金福曾先后官斯土始课</span>  
<span style="margin-left: 1em">民艺桑并导以育蚕之利近日周浦新场六灶各镇已</span>  
<span style="margin-left: 1em">树桑徧地而蚕利犹未溥焉</span>  
<span style="margin-left: 1em">灶丁摊晒盐场朝往暮归沍寒时海飚迅烈头面䝍裂</span>  
<span style="margin-left: 1em">酷暑聚棚煎炼火气熏烁立赤日中反觉清凉掘沙得</span>  
<span style="margin-left: 1em">水掬饮辄尽<sub class="note-yuan">钦志</sub></span>  
<span style="margin-left: 1em">一二团皆妇女摊晒耐饥寒健者能负盐行百里余无</span>  
<span style="margin-left: 1em">业者赖以给衣食此肩挑糊口与船载私贩不同而盐</span>  
<span style="margin-left: 1em">捕每覻其孤单指为私贩而截留焉<sub class="note-yuan">参钦志</sub></span>  
<span style="margin-left: 1em">海边草荡明初给与灶户为煎盐之资万历后豪强告</span>  
<span style="margin-left: 1em">帖起税管业遂变为荡租盐丁以是消乏<sub class="note-yuan">钦志按此盐户逃亡之所由来</sub></span>  
<span style="margin-left: 1em">沿海闲有私贩率多从浙境之南山船载来近虽此风</span>  
<span style="margin-left: 1em">少息而犹不能绝</span>  
<span style="margin-left: 1em">傍海编氓多从事捕鱼有𥱼网蒲网列竹于海澨曰沪</span>  
<span style="margin-left: 1em"><sub class="note-yuan">钦志</sub>春夏之交于海滨张网鱼随潮上得鱼装鲜满载贩</span>  
<span style="margin-left: 1em">往上海俗谓之鲜船所畏飓风骤起海潮陡长网随飃</span>  
<span style="margin-left: 1em">没不知所之又雷雨后蟛蜞满滩于黑夜篝灯或用铁</span>  
<span style="margin-left: 1em">钩钩取或用手取俗谓之抢蟛蜞余如土蛈海狮儿童</span>  
<span style="margin-left: 1em">携筐拾取入市易钱</span>  
<span style="margin-left: 1em">海滩新涨地辽濶无际俗统名之曰荡虽经历届官吏</span>  
<span style="margin-left: 1em">勘丈升科召佃然利薮所在众所必争其已承佃者谓</span>  
<span style="margin-left: 1em">之老荡户其未承佃者谓之新荡户省控京控靡有已</span>  
<span style="margin-left: 1em">时</span>  
<span style="margin-left: 1em">乡民谨愿者多每以鼠牙雀角涉讼公堂讼师暗唆胥</span>  
<span style="margin-left: 1em">吏又从中煽惑株连不已其始一时逞忿其后欲罢不</span>  
<span style="margin-left: 1em">能经年累月破家亡身前志谓动以人命相倾至今犹</span>  
<span style="margin-left: 1em">然<sub class="note-yuan">参钦志</sub></span>  
<span style="margin-left: 1em">地方公事如开濬赈饥之类不能全资差保自当以绅</span>  
<span style="margin-left: 1em">士督率而好事之徒往往各挟私见互相告讦甲与则</span>  
<span style="margin-left: 1em">乙讼乙与则甲讼其实易地则皆然于是爱惜声名者</span>  
<span style="margin-left: 1em">深藏不出实事求是赏罚必信鼓之舞之惩之创之诚</span>  
<span style="margin-left: 1em">未易言矣</span>  
<span style="margin-left: 1em">木棉有早晚不同十月候寒游手之徒连群攫取名曰</span>  
<span style="margin-left: 1em">捉落花于是田户雇人防守曰赶捉落花有相鬭至伤</span>  
<span style="margin-left: 1em">人命者<sub class="note-yuan">参胡志</sub></span>  
<span style="margin-left: 1em">脚行或谓之马头或谓之箩担脚夫所聚也分立段界</span>  
<span style="margin-left: 1em">不相通借婚丧之家彩舆丧輴故昂其直市肆货物迁</span>  
<span style="margin-left: 1em">运出人以及客舟起载不容他雇必餍其欲否则攘臂</span>  
<span style="margin-left: 1em">骂詈随之士民商旅吞声而已<sub class="note-yuan">约钦志文</sub></span>  
<span style="margin-left: 1em">民闲吉凶之事不论贫富丏头率诸行乞索酒食钱物</span>  
<span style="margin-left: 1em">少拂其求即围门肆扰<sub class="note-yuan">钦志</sub></span>  
<span style="margin-left: 1em">乡镇游手每以秋末冬初开场鬭蟋蟀名曰秋兴既罢</span>  
<span style="margin-left: 1em">则鬭鹌鹑曰冬兴又曰鹌鹑圈少年子弟多由此废时</span>  
<span style="margin-left: 1em">失业虽屡经严惩往往贿差保蔽纵亦敝俗也</span>  
<span style="margin-left: 1em">夏天小旱游手辈舁庙中神像求雨所过庙神有尊于</span>  
<span style="margin-left: 1em">所舁者疾趋而过谓之抢轿率尔倾跌虽神像堕臂碎</span>  
<span style="margin-left: 1em">首弗顾焉始出惟以日中一锣一繖而已继且卜夕糊</span>  
<span style="margin-left: 1em">纸作灯渐加繁盛务以奇巧相炫每至深夜举国若狂</span>  
<span style="margin-left: 1em">既雨之后复盛设仪卫百戏日夜游街或清唱演剧谓</span>  
<span style="margin-left: 1em">之谢将有出假民居为行馆者至是各归本庙谓之回</span>  
<span style="margin-left: 1em">銮凡此之类骚扰闾阎科派列肆虽小本营生亦不得</span>  
<span style="margin-left: 1em">免而人亦愿之谓四方聚集可多赚钱也此风周浦尤</span>  
<span style="margin-left: 1em">甚</span>  
<span style="margin-left: 1em">乡鄙有演唱淫词者或杂以妇人曰花鼓戏或在茶肆</span>  
<span style="margin-left: 1em">或在野闲开场聚众最足伤风败俗近因官司严禁暂</span>  
<span style="margin-left: 1em">息又有所谓影戏者盖兴于浙之海盐乡闲颇复沿及</span>  
<span style="margin-left: 1em">浦东亦其类也</span>  
<span style="margin-left: 1em">妇女茹素佞佛原无大害然近有所谓吃长素者奉大</span>  
<span style="margin-left: 1em">被教教主名阿太<sub class="note-yuan">浙省无赖男子也所至男女跪拜争供献有被大如一室夜则男女共被谓之传教</sub>最伤风化及官司访究又逸往他处</span>  
<span style="margin-left: 1em">鸦片流毒无穷三四十年来吸食者不特城市殆徧即</span>  
<span style="margin-left: 1em">乡僻亦然计邑城每日所进烟土其费倍于米粮又有</span>  
<span style="margin-left: 1em">花烟馆名为夫妻店勾引良家子弟尤为藏奸之所虽</span>  
<span style="margin-left: 1em">经官吏访究亦不能绝</span>  
<span style="margin-left: 1em">无藉之徒三五为群醵酒肆横强取市物或习拳勇聚</span>  
<span style="margin-left: 1em">党结盟谓之小弟兄迎神赛会敛钱演戏勒派良善伙</span>  
<span style="margin-left: 1em">赌窝娼留蔽盗贼借力打降此类不一各以其地名曰</span>  
<span style="margin-left: 1em">某帮某帮此乱民也近方有警首造谣言者必此辈矣</span>  
<span style="margin-left: 1em"><sub class="note-yuan">参钦志</sub></span>  
<span style="margin-left: 1em">孀妇再醮皆其自愿乃有强娶孀妇者诱其远族私立</span>  
<span style="margin-left: 1em">婚书夜率鼓乐破门而入挟妇升舆谓之扛孀<sub class="note-yuan">钦志</sub>近且</span>  
<span style="margin-left: 1em">有鸠众抢醮或畧卖者此视扛孀为尤恶虽司牧严惩</span>  
<span style="margin-left: 1em">未能革也</span>  
<span style="margin-left: 1em">海中去岸数十里有铁板沙阑亘海舶误阁率多胶碎</span>  
<span style="margin-left: 1em">沿海不轨之徒以救生为名搬抢货物名捞洋货亦随</span>  
<span style="margin-left: 1em">惩随犯终难杜绝</span>

<span style="margin-left: 1em">松郡七邑物产大同府志概之宜著其异者惟木棉所</span>  
<span style="margin-left: 1em">产尤多民业赖焉不可以不识　木棉<sub class="note-yuan">王逢云交广木棉一名斑枝花吴地所种乃草棉也胡志云陶南村呼为吉贝钦志云元时有道婆黄姓上海乌泥泾人沦落崖州贞元中附海舶归因以是艺传里中吴伟业云乌泥泾偶传此种黄婆教之以杆弹纺织之法死而为庙祀之褚华云邑人止谓之华而不言棉有数种一曰黄蒂穰蒂有黄色如粟大一曰青核核细于他种一曰黑核核亦细纯黑一曰宽大衣核白而穰浮四者棉重皆二十而得九黄蒂稍强紧余皆柔细又一种紫花浮细而核大棉轻二十而得四早收者曰早花晚收者曰晚花经霜而采色微糙者曰霜黄花其莳植采摘轧弹揉卷之法详褚所著木棉谱中不具载元熊禾木棉歌秋阳收尽枝头露烘绽青囊翻白絮田妇携筐采得归浑家拮作机中布大儿来觅襦小儿来觅袴半拟偿私债半拟输官赋竹笼旋着活火熏蠹虫母子走纷纷尺铁碾出瑶宫雪一弓弹破秋江云中虚外泛搓成索昼夜踏车声落落车声才冷催上机知作谁人身上衣小女背面临风泣忆曾随母田中拾</sub>布<sub class="note-yuan">出周浦者名标布俗称大布十六尺为平稍二十尺为套段出新场下沙及各乡镇者总名扣布俗称小布又名中机又稀布较大布濶三四寸有单扣双扣之分又有斜文方丈尤精而贵以上参钦志胡志节录徐献忠布赋序云邑人以布缕为业农氓之困借以稍济然其为生甚疲非若他郡邑蚕缫枲苎之业力少利倍者可同日语也括其事告观风者若乃铁木相轧手挽足压且餧且扐出絮吐核张弓柱弦弦急声噎牵条络车咿哑错杂借光于膏继夜于日衾簟空夜漏水寂溢含愁入机凝寒弄杼流苏绾综一伏一起踏蹑相次上下不已缕断苦接梭涩恐腻长夜凄然得尺望咫寒鸡喔喔解轴趋市方是时也织妇抱冻龟手不顾匹夫怀饥奔走长路摩肩臂以授人腾口说而售我坐守风簷平明反顾妇辞机而远望子牵裳而诉饥先洁釜而待米旋汲水而候炊语少待以相慰既久竚而始归夫婴婴以捐涕云攘攘者在途索子钱而不释并布母以如蚨狼攫虎噉肉寒骨解无一语之相抗犹三𡅗而称怪握两手以授之拂空拳而吞欬夫广储丰积出自农夫之耕一丝寸缕皆从匹妇之手然而茧丝告成置蚕不问耕犂召丰与牛何有是固天下之同风惟江南为丛薮是以手不停机而终岁无衣穷年仡仡而不赡其口全文见胡志不具录</sub></span>
