<span style="margin-left: 1em">光绪南汇县志二十二卷首一卷末一卷清金福曾顾</span>  
<span style="margin-left: 1em">思贤修张文虎等纂福曾字苕人浙江秀水人廪贡生</span>  
<span style="margin-left: 1em">同治十二年知南汇县事思贤广东新兴人同治十三</span>  
<span style="margin-left: 1em">年继任是志之设因编纂江南通志奉檄而起始事于</span>  
<span style="margin-left: 1em">同治十二年讫功于光绪五年卷首为图序及凡例正</span>  
<span style="margin-left: 1em">文分门十有六曰疆域曰水利曰建置曰田赋曰户口</span>  
<span style="margin-left: 1em">曰学校曰祠祀曰兵防曰官司曰选举曰艺文曰人物</span>  
<span style="margin-left: 1em">曰名迹曰风俗曰方外曰杂志十六门之中子目九十</span>  
<span style="margin-left: 1em">有二凡五十二万余言其书编次详审凡记风俗物产</span>  
<span style="margin-left: 1em">咸以邑中所特有者为限不事旁骛又特引物价以资</span>  
<span style="margin-left: 1em">佐证后之治史者得以考见泉货市易民生赢缩之实</span>  
<span style="margin-left: 1em">于经济史料尤称珍贵至若人物一门除列女游寓外</span>  
<span style="margin-left: 1em">古今人传不复繁分类别惟以时代先后为序体例最</span>  
<span style="margin-left: 1em">得简括之体尤难得者凡例特重志德其言曰凡载笔</span>  
<span style="margin-left: 1em">之事必先不私于己而后能不私于人深斥入局纂修</span>  
<span style="margin-left: 1em">之徒必欲使其祖考族党一一厕名卷帙之弊持论严</span>  
<span style="margin-left: 1em">正直笔无隐足为志乘之法式也</span>

<span style="margin-left: 1em">南汇县新志序</span>  
<span style="margin-left: 1em">圣门论政既庶之后曰富曰教固循序渐进之全功实</span>  
<span style="margin-left: 1em">防弊未然之微旨也何以言之庶而不富转徙流离无</span>  
<span style="margin-left: 1em">以保庶矣富而不教饱食煖衣骄奢淫佚无以保富矣</span>  
<span style="margin-left: 1em">南汇析自上海蕞尔邑市廛栉比乱后旋定安集户口</span>  
<span style="margin-left: 1em">日滋较旧志有过无不及庶矣然而积储有经沟洫有</span>  
<span style="margin-left: 1em">利为民闲有无缓急之通旱乾水溢之剂者虽粗具规</span>  
<span style="margin-left: 1em">模非再求美且备焉吾惧无以应于猝也若夫讲孝弟</span>  
<span style="margin-left: 1em">敦节俭次第设施于既富后者则视良有司之自致民</span>  
<span style="margin-left: 1em">何容心焉海宇幸而无事其绸缪牖户时乎</span>  
<span style="margin-left: 1em">九重旰食宵衣孜孜求治有土有民者咸如父兄之谋</span>  
<span style="margin-left: 1em">其子弟庶无戾圣门论政之旨而</span>  
<span style="margin-left: 1em">朝廷以身作则为不虚矣续修县志成邑令顾君思贤</span>  
<span style="margin-left: 1em">以序请为书数语进顾君且以自励也</span>  
<span style="margin-left: 1em">光绪戊寅夏五督江使者侯官沈葆桢谨叙</span>  
<span style="margin-left: 1em">南汇县新志序</span>  
<span style="margin-left: 1em">南汇县于雍正四年析自上海大海环其东南潮汐所</span>  
<span style="margin-left: 1em">至于此回澜南派入浙江北派入大江故名非特东南</span>  
<span style="margin-left: 1em">一郡之屏障实亦江浙海防之要冲地势如犂状突出</span>  
<span style="margin-left: 1em">洋面长兴钦公首宰是邑以分邑应有专志得朱之屏</span>  
<span style="margin-left: 1em">鹤沙志及蒋思永分县志而纂辑之是南邑有志之始</span>  
<span style="margin-left: 1em">旋有陆学渊副志乾隆五十九年孝感胡志熊继之迄</span>  
<span style="margin-left: 1em">今八十余年典章日轶大惧文献之无征爰命牧令顾</span>  
<span style="margin-left: 1em">思贤延邑人士之诚悫多识者重加修辑次第成编其</span>  
<span style="margin-left: 1em">闲田赋之乘除营制之改革禺䇲之短长建置兴复之</span>  
<span style="margin-left: 1em">纷繁犂然咸备至其条例颇为精审如田亩场园芦洲</span>  
<span style="margin-left: 1em">屯田自宜列于田赋而不隶于疆域学校以示尊崇不</span>  
<span style="margin-left: 1em">可隶于建设人物不专科第自应别为选举其他图志</span>  
<span style="margin-left: 1em">或增或并亦属秩有条理庶几钦胡二志不得专美于</span>  
<span style="margin-left: 1em">前亦余实事求是之心也夫</span>  
<span style="margin-left: 1em">光绪四年岁次戊寅春二月抚吴使者吴元炳谨序</span>  
<span style="margin-left: 1em">南汇县新志序</span>  
<span style="margin-left: 1em">南汇以雍正二年割上海分建时长兴钦公连首宰是</span>  
<span style="margin-left: 1em">邑因据上海志鹤沙志成县志十六卷旋有陆公学渊</span>  
<span style="margin-left: 1em">著副志以补苴罅漏攷证讹谬厥后乾隆五十有九年</span>  
<span style="margin-left: 1em">孝感胡公志熊继宰是邑因钦志之旧而续修之成新</span>  
<span style="margin-left: 1em">志十五卷事增文减颇为完善迄今又八十年矣中经</span>  
<span style="margin-left: 1em">兵燹书缺有闲时事迁流因革不一若田赋若营制若</span>  
<span style="margin-left: 1em">盐法若水利若农桑学校市廛仓廪以及备荒恤孤诸</span>  
<span style="margin-left: 1em">举皆王政之所发施而良有司所宜时时留意非可以</span>  
<span style="margin-left: 1em">苟焉忽焉已也邑境右临浦江左濒大海海底尽铁板</span>  
<span style="margin-left: 1em">沙巨舰不得深入有濠塘可资拒守非如上海宝山之</span>  
<span style="margin-left: 1em">瞬息扬帆直薄城下也境内新场镇左右最为沃壤余</span>  
<span style="margin-left: 1em">地半多斥卤旧时下沙大团颇饶盐䇲今土脉渐淡煮</span>  
<span style="margin-left: 1em">海之利盖稍微矣今幸大难削平百废渐举而民困甫</span>  
<span style="margin-left: 1em">苏元气未复更宜何如励精淬神究心利病耶同治十</span>  
<span style="margin-left: 1em">有三年知县事者为秀水金公福曾实始有事于修志</span>  
<span style="margin-left: 1em">聘邑人士分类集修延张训导文虎总之未几而中丞</span>  
<span style="margin-left: 1em">固始吴公有续修江南通志之举檄下郡县各事采辑</span>  
<span style="margin-left: 1em">于时新兴顾公思贤复继金公为南汇令因详加审订</span>  
<span style="margin-left: 1em">次第成编蒇事于光绪三年某月夫志者识也识大识</span>  
<span style="margin-left: 1em">小俾后世有可稽考也二君子者固皆能励精淬神究</span>  
<span style="margin-left: 1em">心利病者耶抑亦深可嘉也是为序</span>  
<span style="margin-left: 1em">光绪戊寅六月江苏布政使勒方锜谨序</span>  
<span style="margin-left: 1em">南汇县新志序</span>  
<span style="margin-left: 1em">南汇民风朴素未分县以前风土之纪人物之志阙如</span>  
<span style="margin-left: 1em">也自雍正四年析上海东南境为县长兴钦君首宰是</span>  
<span style="margin-left: 1em">邑因朱氏鹤沙志备蒋氏分县志稿成分建南汇县志</span>  
<span style="margin-left: 1em">十六卷厥后孝感胡君志熊重加采辑为新志十五卷</span>  
<span style="margin-left: 1em">距钦志之作已六十年私家著述视昔尤稀文献之征</span>  
<span style="margin-left: 1em">君子嗛焉同治十三年春秀水金君福曾权知是邑则</span>  
<span style="margin-left: 1em">距胡氏修志已八十年上溯钦志且百四十年历时弥</span>  
<span style="margin-left: 1em">久又洊遭兵乱旧闻坠典放轶滋甚惧纪述之无征思</span>  
<span style="margin-left: 1em">典型之尚在乃请于大府有事修辑延张啸山先生总</span>  
<span style="margin-left: 1em">司其事张先生名文虎本邑人耆德宿学于乡里闻见</span>  
<span style="margin-left: 1em">尤极该洽金君亦好古不怠纲罗搜辑端绪渐兴未几</span>  
<span style="margin-left: 1em">金君谢事去而新兴顾君思贤实来君久官江苏咸丰</span>  
<span style="margin-left: 1em">闲尝宰奉贤县与南汇接壤张先生昔年亦通雅故相</span>  
<span style="margin-left: 1em">与踵事增订赏析异同会大中丞吴公有续修通志之</span>  
<span style="margin-left: 1em">举既饬各属先成县志复以松江一府命太守龚君寿</span>  
<span style="margin-left: 1em">图董其成龚君奄有三长大雅宏达君子也于是官师</span>  
<span style="margin-left: 1em">皆一时之选阅岁未久书用告成将付剞劂顾君属序</span>  
<span style="margin-left: 1em">于余自维谫陋曷足以赞一辞顾受其书而读之见赋</span>  
<span style="margin-left: 1em">役之乘除营制之因革学校坛庙建置之宜水利盐课</span>

<span style="margin-left: 1em">甲于天下一浦东西之隔风尚截然其初固一县也询</span>

<span style="margin-left: 1em">以华嚣相耀考其民俗实与南邑相类及今而究迁流</span>  
<span style="margin-left: 1em">之故思挽救之方所谓一命以上与有责焉者也然则</span>

<span style="margin-left: 1em">南汇县志序</span>  
<span style="margin-left: 1em">按籍以为治可乎不可也去籍以为治可乎愈不可也</span>  
<span style="margin-left: 1em">余于咸丰初筮仕江苏惟时洪逆陷金陵而隶于苏州</span>  
<span style="margin-left: 1em">布政司者惟上海为别贼窃据二年其他固无恙也余</span>

<span style="margin-left: 1em">相接闻父老言南汇风土朴直尚气好胜在昔分县之</span>

<span style="margin-left: 1em">而勤业务本乐善崇义则尚气好胜适以成其志余于</span>

<span style="margin-left: 1em">南汇县新志序</span>  
<span style="margin-left: 1em">松郡七邑惟南汇为东鄙俗朴而民俭号偁富庶同治</span>  
<span style="margin-left: 1em">十有二年福曾承乏此邦抚治之余察其人情风土与</span>  
<span style="margin-left: 1em">其衣食根本殊异于所闻接其士绅讲求利敝所在佥</span>  
<span style="margin-left: 1em">谓固由匪扰之后元气未复而今昔情形亦有不知其</span>  
<span style="margin-left: 1em">何为而迁变者乃索观其志乘钦志作于分县之始胡</span>  
<span style="margin-left: 1em">志作于乾隆之末相去几六十年而两志所纪已有不</span>  
<span style="margin-left: 1em">同自胡志至此又八十年矣宜其不能尽合也时　宪</span>  
<span style="margin-left: 1em">行有饬属修志之举以言于诸君则以为宜商诸张学</span>  
<span style="margin-left: 1em">博啸山乃驰书金陵介钱京卿子密致之学博以年老</span>  
<span style="margin-left: 1em">且书局事不得解为辞是冬暂假归福曾亟访之仍固</span>  
<span style="margin-left: 1em">辞往复再三福曾责以桑梓之谊且众议皆同成否一</span>  
<span style="margin-left: 1em">言耳学博不得已乃诺福曾请先为条例学博因历数</span>  
<span style="margin-left: 1em">修志之难与其敝画一其所以为志者福曾上之　抚</span>  
<span style="margin-left: 1em">军张公　公韪之谕如所陈乃设局署之积谷仓福曾</span>  
<span style="margin-left: 1em">闲问学博曰志事二年可竣乎学博笑曰三四年虑犹</span>  
<span style="margin-left: 1em">未也夫采辑故录则文献散佚搜访新闻则舟舆跋涉</span>  
<span style="margin-left: 1em">盛暑雨雪人情所畏水利通塞岁有变更且彼任事者</span>  
<span style="margin-left: 1em">孰无室家妻子之累或且授徒糊口焉得孑身无事之</span>  
<span style="margin-left: 1em">人而任之且一人之耳目有限不得不求助于人而助</span>  
<span style="margin-left: 1em">之者岂必皆谛审其实道听涂说言人人殊是在分纂</span>  
<span style="margin-left: 1em">者之折衷一是而今所定条例或不能无变通增减盖</span>  
<span style="margin-left: 1em">有已登梨枣而犹需刓改者岂渠能急就乎福曾观钦</span>  
<span style="margin-left: 1em">志条例为顾小厓侍讲所定经修七八年始刊行而议</span>  
<span style="margin-left: 1em">者纷然学博言殆非谬是时同治十三年之春也及秋</span>  
<span style="margin-left: 1em">福曾调署吴江新兴顾君竹城来补斯缺岁轨五周矣</span>  
<span style="margin-left: 1em">顾君知此事之不可以促迫也宽以待之福曾频年奉</span>  
<span style="margin-left: 1em">檄振饥豫晋日在车尘马迹闲蒿目惊心惨惨靡乐忽</span>  
<span style="margin-left: 1em">接诸君书言志事已蒇不可无序则为之一喜虽然福</span>  
<span style="margin-left: 1em">曾何以序此志哉邑之情形与修之条例具于志无事</span>  
<span style="margin-left: 1em">赘述姑述当日议修之缘起于此抑有所急欲为邑之</span>  
<span style="margin-left: 1em">人告者豫晋皆雄省其俗视江浙尤为俭朴乃弃其稼</span>  
<span style="margin-left: 1em">穑而骛罂粟之利溺于蛊毒而不返天降之罚以至道</span>  
<span style="margin-left: 1em">殣相望饿莩枕藉而烦东南之助振夫南邑之富庶非</span>  
<span style="margin-left: 1em">一日而今且日衰盇亦熟计其所以变迁之故鉴于覆</span>  
<span style="margin-left: 1em">辙为七邑倡而洊复当日之盛此福曾于数千里外所</span>  
<span style="margin-left: 1em">惓惓不能忘于是邑者也光绪五年岁次己卯冬月嘉</span>  
<span style="margin-left: 1em">兴金福曾识</span>  
<span style="margin-left: 1em">光绪南汇县志凡例</span>  
<span style="margin-left: 1em">一南邑析自上海雍正三年长兴钦公首任是邑即创</span>  
<span style="margin-left: 2em">修邑志六阅岁而始成盖本朱之屏黄仲若所辑鹤</span>  
<span style="margin-left: 2em">沙志及蒋思永新分县志而增修之迨乾隆八年邑</span>  
<span style="margin-left: 2em">人陆学渊作副志视钦志加详矣又后五十年而孝</span>  
<span style="margin-left: 2em">感胡公重纂新志尤为详悉迄今又八十余年天道</span>  
<span style="margin-left: 2em">十年小变至于人事何独不然况自咸丰以来中更</span>  
<span style="margin-left: 2em">兵燹文献凋落采访綦难诚非朝夕所可集事宽其</span>  
<span style="margin-left: 2em">岁月广其搜罗择以精心持以固志实事求是勿徇</span>  
<span style="margin-left: 2em">私勿随俗盖余五年而始溃于成非缓也不得已也</span>  
<span style="margin-left: 1em">一鹤沙志新分县志据胡志其时似尚存今已失传陆</span>  
<span style="margin-left: 2em">志虽存而已残缺又遭蠹蚀不可检阅皆未见椠本</span>  
<span style="margin-left: 2em">钦志祗分六类胡志广为十三其子目分合互有同</span>  
<span style="margin-left: 2em">异今参酌于两志之闲约为十六类为子目八十有</span>  
<span style="margin-left: 2em">六附见者二凡二十二卷合首末为二十四卷事主</span>  
<span style="margin-left: 2em">于详而不欲滥文主于简而不敢漏所与同人共勉</span>  
<span style="margin-left: 2em">者如此而已非敢必其果副也</span>  
<span style="margin-left: 1em">一全境水利二图钦胡两志互有详略今合两志参以</span>  
<span style="margin-left: 2em">访册或并或删俾一目了然得其要领川沙厅已别</span>  
<span style="margin-left: 2em">有志故不复列图</span>  
<span style="margin-left: 1em">一粮仓向在周浦镇以便漕运故胡志有图仓毁于咸</span>  
<span style="margin-left: 2em">丰三年自是以来全漕改折久未议复故今祇存其</span>  
<span style="margin-left: 2em">梗概于建置志惟积谷仓为同治十一年创建条理</span>  
<span style="margin-left: 2em">井井图之以期垂久</span>  
<span style="margin-left: 1em">一惠南书院胡志附见学校图今别为图以为人文劝</span>  
<span style="margin-left: 1em">一钦志坛庙亦隶建设胡别分祀典志然所列不尽应</span>  
<span style="margin-left: 2em">祀典也今改题祠祀志凡城乡诸杂祀皆附此</span>  
<span style="margin-left: 1em">一钦志武衞亦隶建设胡别分武备志称名不当今改</span>  
<span style="margin-left: 2em">题兵防屯田已见田赋营官列于官司至兵燹所以</span>  
<span style="margin-left: 2em">纪事不宜附兵防之后今别入杂志</span>  
<span style="margin-left: 1em">一有国者设官分职以为一朝制度故史有职官志今</span>  
<span style="margin-left: 2em">一隅之地守土而已钦志题为官司是也而统于建</span>  
<span style="margin-left: 2em">设则非今从胡别立志而名从钦钦志名宦冠于人</span>  
<span style="margin-left: 2em">物志胡题为宦绩列于此今亦从之</span>  
<span style="margin-left: 1em">一钦志科第错出于人物志今从胡别为选举志旧附</span>  
<span style="margin-left: 2em">封赠例仕习非成是姑从俗登其实缺者</span>  
<span style="margin-left: 1em">一钦志无艺文今从胡志但搜采续增必须目见不敢</span>  
<span style="margin-left: 2em">但据空名考志者宜本此为实其非灼见或已佚者</span>  
<span style="margin-left: 2em">仅载传内两不相蒙闲有小集以分目欠晰及传简</span>  
<span style="margin-left: 2em">难再删者始互见一二</span>  
<span style="margin-left: 1em">一人物志钦胡两志各分传目中有疑似可互见者盖</span>  
<span style="margin-left: 2em">子孙述德才华必兼经济学问必擅辞章文饰铺张</span>  
<span style="margin-left: 2em">几于人人具美虽其中闲有一二而安能尽攷其虚</span>  
<span style="margin-left: 2em">实嘉定钱少詹修鄞志总题人物不分名目引宝庆</span>  
<span style="margin-left: 2em">延祐两志上海志亦依陆庆循修例而独分艺术则</span>  
<span style="margin-left: 2em">自乱其例今拟依古人合传之例其无他长可见者</span>  
<span style="margin-left: 2em">立一人为首而牵连书之惟列女游寓自当别题方</span>  
<span style="margin-left: 2em">外则自为一志以寺观僧道教堂隶焉勿使其溷乎</span>  
<span style="margin-left: 2em">我教也耆硕亦不标名如艺术例</span>  
<span style="margin-left: 1em">一钦志坊表附于建设胡志入之杂志上海新志附之</span>  
<span style="margin-left: 2em">街巷于意不安今别为名迹志与古迹第宅围林冢</span>  
<span style="margin-left: 2em">墓为类碑刻绝少各附于当处</span>  
<span style="margin-left: 1em">一风俗为郡邑志之急务旧多附之杂志非是今别立</span>  
<span style="margin-left: 2em">志而详著其利敝以为官斯土者因势利导矫枉正</span>  
<span style="margin-left: 2em">俗之本其物产则取独异于他处者著之</span>  
<span style="margin-left: 1em">一祥异遗事皆纪事也无类可归各志隶之杂志兵燹</span>  
<span style="margin-left: 2em">亦然今从其类凡遭寇死者随其地其时皆系于此</span>  
<span style="margin-left: 2em">其确有拒贼不屈事迹昭然者仍著录于人物志</span>  
<span style="margin-left: 1em">一自嘉庆十年始析南邑十啚以与川沙则未析以前</span>  
<span style="margin-left: 2em">例宜详载既析以后川沙自有志宜可从略惟学校</span>  
<span style="margin-left: 2em">统于南邑科第故仍载入云</span>  
<span style="margin-left: 1em">一志中例采前人诗文然必有裨于当地掌故古迹可</span>  
<span style="margin-left: 2em">攷见盛衰者始附之或有补于采风问俗可推知民</span>  
<span style="margin-left: 2em">隐者附之至于流连光景一时兴到之作弁有全不</span>  
<span style="margin-left: 2em">关本地者概不采入</span>  
<span style="margin-left: 1em">一凡载笔之事必先不私于己而后能不私于人一有</span>  
<span style="margin-left: 2em">偏徇反唇立至钱少詹言近代士大夫一入志局必</span>  
<span style="margin-left: 2em">欲使其祖父族党一一厕名卷中于是儒林文苑车</span>  
<span style="margin-left: 2em">载斗量徒为后人覆瓿之用此论甚笃窃尝以此自</span>  
<span style="margin-left: 2em">律并以告诸君子倘有遗漏请待续修</span>  
<span style="margin-left: 1em">凡例终</span>
