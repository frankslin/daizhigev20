<span style="margin-left: 1em">提要</span>  
<span style="margin-left: 1em">光緒南滙縣志二十二卷首一卷末一卷清金福曾顧</span>  
<span style="margin-left: 1em">思賢修張文虎等纂福曾字苕人浙江秀水人廩貢生</span>  
<span style="margin-left: 1em">同治十二年知南滙縣事思賢廣東新興人同治十三</span>  
<span style="margin-left: 1em">年繼任是志之設因編纂江南通志奉檄而起始事於</span>  
<span style="margin-left: 1em">同治十二年訖功於光緒五年卷首爲圖序及凡例正</span>  
<span style="margin-left: 1em">文分門十有六曰疆域曰水利曰建置曰田賦曰戶口</span>  
<span style="margin-left: 1em">曰學校曰祠祀曰兵防曰官司曰選舉曰藝文曰人物</span>  
<span style="margin-left: 1em">曰名迹曰風俗曰方外曰雜志十六門之中子目九十</span>  
<span style="margin-left: 1em">有二凡五十二萬餘言其書編次詳審凡記風俗物產</span>  
<span style="margin-left: 1em">咸以邑中所特有者爲限不事旁騖又特引物價以資</span>  
<span style="margin-left: 1em">佐證後之治史者得以考見泉貨市易民生贏縮之實</span>  
<span style="margin-left: 1em">於經濟史料尤稱珍貴至若人物一門除列女遊寓外</span>  
<span style="margin-left: 1em">古今人傳不復繁分類別惟以時代先後爲序體例最</span>  
<span style="margin-left: 1em">得簡括之體尤難得者凡例特重志德其言曰凡載筆</span>  
<span style="margin-left: 1em">之事必先不私於己而後能不私於人深斥入局纂修</span>  
<span style="margin-left: 1em">之徒必欲使其祖考族黨一一廁名卷帙之弊持論嚴</span>  
<span style="margin-left: 1em">正直筆無隱足爲志乘之法式也</span>  
<span style="margin-left: 15em">谷水道人撰</span>  
<span style="margin-left: 1em">南滙縣新志序</span>  
<span style="margin-left: 1em">聖門論政既庶之後曰富曰教固循序漸進之全功實</span>  
<span style="margin-left: 1em">防弊未然之微旨也何以言之庶而不富轉徙流離無</span>  
<span style="margin-left: 1em">以保庶矣富而不教飽食煖衣驕奢淫佚無以保富矣</span>  
<span style="margin-left: 1em">南滙析自上海蕞爾邑市廛櫛比亂後旋定安集户口</span>  
<span style="margin-left: 1em">日滋較舊志有過無不及庶矣然而積儲有經溝洫有</span>  
<span style="margin-left: 1em">利爲民閒有無緩急之通旱乾水溢之劑者雖粗具規</span>  
<span style="margin-left: 1em">模非再求美且備焉吾懼無以應於猝也若夫講孝弟</span>  
<span style="margin-left: 1em">敦節儉次第設施於既富後者則視良有司之自致民</span>  
<span style="margin-left: 1em">何容心焉海宇幸而無事其綢繆牖户時乎</span>  
<span style="margin-left: 1em">九重旰食宵衣孜孜求治有土有民者咸如父兄之謀</span>  
<span style="margin-left: 1em">其子弟庶無戾聖門論政之旨而</span>  
<span style="margin-left: 1em">朝廷以身作則爲不虛矣續修縣志成邑令顧君思賢</span>  
<span style="margin-left: 1em">以序請爲書數語進顧君且以自勵也</span>  
<span style="margin-left: 1em">光緒戊寅夏五督江使者侯官沈葆楨謹敘</span>  
<span style="margin-left: 1em">南滙縣新志序</span>  
<span style="margin-left: 1em">南滙縣於雍正四年析自上海大海環其東南潮汐所</span>  
<span style="margin-left: 1em">至於此迴瀾南派入浙江北派入大江故名非特東南</span>  
<span style="margin-left: 1em">一郡之屏障實亦江浙海防之要衝地勢如犂狀突出</span>  
<span style="margin-left: 1em">洋面長興欽公首宰是邑以分邑應有專志得朱之屏</span>  
<span style="margin-left: 1em">鶴沙志及蔣思永分縣志而纂輯之是南邑有志之始</span>  
<span style="margin-left: 1em">旋有陸學淵副志乾隆五十九年孝感胡志熊繼之迄</span>  
<span style="margin-left: 1em">今八十餘年典章日軼大懼文獻之無徵爰命牧令顧</span>  
<span style="margin-left: 1em">思賢延邑人士之誠慤多識者重加修輯次第成編其</span>  
<span style="margin-left: 1em">閒田賦之乘除營制之改革禺筴之短長建置興復之</span>  
<span style="margin-left: 1em">紛繁犂然咸備至其條例頗爲精審如田畝場園蘆洲</span>  
<span style="margin-left: 1em">屯田自宜列於田賦而不隸於疆域學校以示尊崇不</span>  
<span style="margin-left: 1em">可隸於建設人物不專科第自應別爲選舉其他圖志</span>  
<span style="margin-left: 1em">或增或併亦屬秩有條理庶幾欽胡二志不得專美於</span>  
<span style="margin-left: 1em">前亦余實事求是之心也夫</span>  
<span style="margin-left: 1em">光緒四年歲次戊寅春二月撫吳使者吳元炳謹序</span>  
<span style="margin-left: 1em">南滙縣新志序</span>  
<span style="margin-left: 1em">南滙以雍正二年割上海分建時長興欽公連首宰是</span>  
<span style="margin-left: 1em">邑因据上海志鶴沙志成縣志十六卷旋有陸公學淵</span>  
<span style="margin-left: 1em">著副志以補苴罅漏攷證訛謬厥後乾隆五十有九年</span>  
<span style="margin-left: 1em">孝感胡公志熊繼宰是邑因欽志之舊而續修之成新</span>  
<span style="margin-left: 1em">志十五卷事增文減頗爲完善迄今又八十年矣中經</span>  
<span style="margin-left: 1em">兵燹書缺有閒時事遷流因革不一若田賦若營制若</span>  
<span style="margin-left: 1em">鹽法若水利若農桑學校市廛倉廩以及備荒恤孤諸</span>  
<span style="margin-left: 1em">舉皆王政之所發施而良有司所宜時時留意非可以</span>  
<span style="margin-left: 1em">苟焉忽焉已也邑境右臨浦江左瀕大海海底盡鐵板</span>  
<span style="margin-left: 1em">沙巨艦不得深入有濠塘可資拒守非如上海寶山之</span>  
<span style="margin-left: 1em">瞬息揚帆直薄城下也境內新場鎮左右最爲沃壤餘</span>  
<span style="margin-left: 1em">地半多斥鹵舊時下沙大團頗饒鹽筴今土脈漸淡煮</span>  
<span style="margin-left: 1em">海之利蓋稍微矣今幸大難削平百廢漸舉而民困甫</span>  
<span style="margin-left: 1em">蘇元氣未復更宜何如勵精淬神究心利病耶同治十</span>  
<span style="margin-left: 1em">有三年知縣事者爲秀水金公福曾實始有事於修志</span>  
<span style="margin-left: 1em">聘邑人士分類集修延張訓導文虎總之未幾而中丞</span>  
<span style="margin-left: 1em">固始吳公有續修江南通志之舉檄下郡縣各事采輯</span>  
<span style="margin-left: 1em">於時新興顧公思賢復繼金公爲南滙令因詳加審訂</span>  
<span style="margin-left: 1em">次第成編蕆事於光緒三年某月夫志者識也識大識</span>  
<span style="margin-left: 1em">小俾後世有可稽考也二君子者固皆能勵精淬神究</span>  
<span style="margin-left: 1em">心利病者耶抑亦深可嘉也是爲序</span>  
<span style="margin-left: 1em">光緒戊寅六月江蘇布政使勒方錡謹序</span>  
<span style="margin-left: 1em">南滙縣新志序</span>  
<span style="margin-left: 1em">南滙民風樸素未分縣以前風土之紀人物之志闕如</span>  
<span style="margin-left: 1em">也自雍正四年析上海東南境爲縣長興欽君首宰是</span>  
<span style="margin-left: 1em">邑因朱氏鶴沙志備蔣氏分縣志稿成分建南滙縣志</span>  
<span style="margin-left: 1em">十六卷厥後孝感胡君志熊重加采輯爲新志十五卷</span>  
<span style="margin-left: 1em">距欽志之作已六十年私家著述視昔尤稀文獻之徵</span>  
<span style="margin-left: 1em">君子嗛焉同治十三年春秀水金君福曾權知是邑則</span>  
<span style="margin-left: 1em">距胡氏修志已八十年上溯欽志且百四十年歷時彌</span>  
<span style="margin-left: 1em">久又洊遭兵亂舊聞墜典放軼滋甚懼紀述之無徵思</span>  
<span style="margin-left: 1em">典型之尚在乃請於大府有事修輯延張嘯山先生總</span>  
<span style="margin-left: 1em">司其事張先生名文虎本邑人耆德宿學於鄉里聞見</span>  
<span style="margin-left: 1em">尤極該洽金君亦好古不怠綱羅蒐輯端緒漸興未幾</span>  
<span style="margin-left: 1em">金君謝事去而新興顧君思賢實來君久官江蘇咸豐</span>  
<span style="margin-left: 1em">閒嘗宰奉賢縣與南滙接壤張先生昔年亦通雅故相</span>  
<span style="margin-left: 1em">與踵事增訂賞析異同會大中丞吳公有續修通志之</span>  
<span style="margin-left: 1em">舉既飭各屬先成縣志復以松江一府命太守龔君壽</span>  
<span style="margin-left: 1em">圖董其成龔君奄有三長大雅宏達君子也於是官師</span>  
<span style="margin-left: 1em">皆一時之選閱歲未久書用告成將付剞劂顧君屬序</span>  
<span style="margin-left: 1em">於余自維譾陋曷足以贊一辭顧受其書而讀之見賦</span>  
<span style="margin-left: 1em">役之乘除營制之因革學校壇廟建置之宜水利鹽課</span>  
<span style="margin-left: 1em">旺衰之迹以至藝文之著錄人物之表彰犂然秩然既</span>  
<span style="margin-left: 1em">美既備而義例之善史裁之卓尤有足爲志乘法者洵</span>  
<span style="margin-left: 1em">乎江淹有言非老於典故者不能爲善作善成諸賢適</span>  
<span style="margin-left: 1em">會非偶然矣抑余重有慨焉南滙析自上海俗尚未變</span>  
<span style="margin-left: 1em">城市民居亦知重農務本而上海自通市舶侈蕩奇麗</span>  
<span style="margin-left: 1em">甲於天下一浦東西之隔風尚截然其初固一縣也詢</span>  
<span style="margin-left: 1em">之故老三四十年之前雖商賈輻輳市廛之閒猶未至</span>  
<span style="margin-left: 1em">以華囂相耀考其民俗實與南邑相類及今而究遷流</span>  
<span style="margin-left: 1em">之故思挽救之方所謂一命以上與有責焉者也然則</span>  
<span style="margin-left: 1em">讀是編也豈惟是考獻徵文爲掌故之資而已哉</span>  
<span style="margin-left: 1em">光緒四年戊寅正月布政使銜署理蘇松太兵備道海</span>  
<span style="margin-left: 1em">關監督貴池劉瑞芬序</span>  
<span style="margin-left: 1em">南滙縣志序</span>  
<span style="margin-left: 1em">按籍以爲治可乎不可也去籍以爲治可乎愈不可也</span>  
<span style="margin-left: 1em">余於咸豐初筮仕江蘇惟時洪逆陷金陵而隸於蘇州</span>  
<span style="margin-left: 1em">布政司者惟上海爲別賊竊據二年其他固無恙也余</span>  
<span style="margin-left: 1em">每至一宮取縣志讀之溯其成書或百餘年或數十年</span>  
<span style="margin-left: 1em">閲時不爲不久然惟人物選舉藝文或有增益有待采</span>  
<span style="margin-left: 1em">輯而已及寇氛蔓延迄今戡亂兵農學校諸大政大府</span>  
<span style="margin-left: 1em">數鉅公乘時通變經營酌劑復數載而後定而民居土</span>  
<span style="margin-left: 1em">俗消息盈虛即十餘年中余所及見亦多有改易證之</span>  
<span style="margin-left: 1em">前志乃邈焉如古初之不可復接蓋時與勢之不同如</span>  
<span style="margin-left: 1em">此南滙分自上海長興欽君連首膺是選始纂邑志閲</span>  
<span style="margin-left: 1em">六十年而孝感胡君志熊繼之暨今又八十年矣同治</span>  
<span style="margin-left: 1em">閒前署令秀水金君福曾有志修輯邑之紳士詢謀僉</span>  
<span style="margin-left: 1em">同遂延邑張學博文虎爲總纂條例既舉而金君遷任</span>  
<span style="margin-left: 1em">去予適補官會大中丞吳公以通志之役命太守龔公</span>  
<span style="margin-left: 1em">監督松郡乃討論文獻商畧一是首尾五載薈萃畧定</span>  
<span style="margin-left: 1em">因復檢舊志而校證之則減漕而後歲賦殊矣水師新</span>  
<span style="margin-left: 1em">設營制異矣學官弟子之額屢加斥鹵沙塗之地日徙</span>  
<span style="margin-left: 1em">犖犖大者損益已多而河渠之通塞鄉鎮之盛衰穀倉</span>  
<span style="margin-left: 1em">桑園善堂義塾之建置昔所以因今所以革條分綱舉</span>  
<span style="margin-left: 1em">粲然畢陳後之覽者庶幾考信而不惑矣顧嘗以爲典</span>  
<span style="margin-left: 1em">章制度因時而變者也風俗人心不必因時而變者也</span>  
<span style="margin-left: 1em">南滙在蘇松閒號爲易治兵亂以前余兩權奉賢壤地</span>  
<span style="margin-left: 1em">相接聞父老言南滙風土樸直尚氣好勝在昔分縣之</span>  
<span style="margin-left: 1em">際武勇著於州郡然士知正誼農不惰安工不爲奇麗</span>  
<span style="margin-left: 1em">商罕遠賈類能勤業而知務本近數十年亦稍稍變矣</span>  
<span style="margin-left: 1em">今余來兹五年幸相安無事閒接士紳肫然相親惟鄉</span>  
<span style="margin-left: 1em">愚細故輕赴訟庭徒爲吏役之利余每速聽而立結之</span>  
<span style="margin-left: 1em">俾免此曹之劫持雀鼠之爭其少息乎夫有樸直之風</span>  
<span style="margin-left: 1em">而勤業務本樂善崇義則尚氣好勝適以成其志余於</span>  
<span style="margin-left: 1em">此邦有厚望焉而豈徒屑屑焉鉤稽簿書參考掌故爲</span>  
<span style="margin-left: 1em">哉是爲序</span>  
<span style="margin-left: 1em">光緒五年己卯三月知府用知南滙縣事新興顧思賢</span>  
<span style="margin-left: 1em">撰</span>  
<span style="margin-left: 1em">南滙縣新志序</span>  
<span style="margin-left: 1em">松郡七邑惟南滙爲東鄙俗樸而民儉號偁富庶同治</span>  
<span style="margin-left: 1em">十有二年福曾承乏此邦撫治之餘察其人情風土與</span>  
<span style="margin-left: 1em">其衣食根本殊異於所聞接其士紳講求利敝所在僉</span>  
<span style="margin-left: 1em">謂固由匪擾之後元氣未復而今昔情形亦有不知其</span>  
<span style="margin-left: 1em">何爲而遷變者乃索觀其志乘欽志作於分縣之始胡</span>  
<span style="margin-left: 1em">志作於乾隆之末相去幾六十年而兩志所紀已有不</span>  
<span style="margin-left: 1em">同自胡志至此又八十年矣宜其不能盡合也時　憲</span>  
<span style="margin-left: 1em">行有飭屬修志之舉以言於諸君則以爲宜商諸張學</span>  
<span style="margin-left: 1em">博嘯山乃馳書金陵介錢京卿子密致之學博以年老</span>  
<span style="margin-left: 1em">且書局事不得解爲辭是冬暫假歸福曾亟訪之仍固</span>  
<span style="margin-left: 1em">辭往復再三福曾責以桑梓之誼且衆議皆同成否一</span>  
<span style="margin-left: 1em">言耳學博不得已乃諾福曾請先爲條例學博因歷數</span>  
<span style="margin-left: 1em">修志之難與其敝畫一其所以爲志者福曾上之　撫</span>  
<span style="margin-left: 1em">軍張公　公韙之諭如所陳乃設局署之積穀倉福曾</span>  
<span style="margin-left: 1em">閒問學博曰志事二年可竣乎學博笑曰三四年慮猶</span>  
<span style="margin-left: 1em">未也夫采輯故錄則文獻散佚搜訪新聞則舟輿跋涉</span>  
<span style="margin-left: 1em">盛暑雨雪人情所畏水利通塞歲有變更且彼任事者</span>  
<span style="margin-left: 1em">孰無室家妻子之累或且授徒餬口焉得孑身無事之</span>  
<span style="margin-left: 1em">人而任之且一人之耳目有限不得不求助於人而助</span>  
<span style="margin-left: 1em">之者豈必皆諦審其實道聽塗說言人人殊是在分纂</span>  
<span style="margin-left: 1em">者之折衷一是而今所定條例或不能無變通增減蓋</span>  
<span style="margin-left: 1em">有已登梨棗而猶需刓改者豈渠能急就乎福曾觀欽</span>  
<span style="margin-left: 1em">志條例爲顧小厓侍講所定經修七八年始刊行而議</span>  
<span style="margin-left: 1em">者紛然學博言殆非謬是時同治十三年之春也及秋</span>  
<span style="margin-left: 1em">福曾調署吳江新興顧君竹城來補斯缺歲軌五周矣</span>  
<span style="margin-left: 1em">顧君知此事之不可以促迫也寬以待之福曾頻年奉</span>  
<span style="margin-left: 1em">檄振飢豫晉日在車塵馬迹閒蒿目驚心慘慘靡樂忽</span>  
<span style="margin-left: 1em">接諸君書言志事已蕆不可無序則爲之一喜雖然福</span>  
<span style="margin-left: 1em">曾何以序此志哉邑之情形與修之條例具於志無事</span>  
<span style="margin-left: 1em">贅述姑述當日議修之緣起於此抑有所急欲爲邑之</span>  
<span style="margin-left: 1em">人告者豫晉皆雄省其俗視江浙尤爲儉樸乃棄其稼</span>  
<span style="margin-left: 1em">穡而騖罌粟之利溺於蠱毒而不返天降之罰以至道</span>  
<span style="margin-left: 1em">殣相望餓莩枕藉而煩東南之助振夫南邑之富庶非</span>  
<span style="margin-left: 1em">一日而今且日衰盇亦熟計其所以變遷之故鑒於覆</span>  
<span style="margin-left: 1em">轍爲七邑倡而洊復當日之盛此福曾於數千里外所</span>  
<span style="margin-left: 1em">惓惓不能忘於是邑者也光緒五年歲次己卯冬月嘉</span>  
<span style="margin-left: 1em">興金福曾識</span>  
<span style="margin-left: 1em">光緒南滙縣志凡例</span>  
<span style="margin-left: 1em">一南邑析自上海雍正三年長興欽公首任是邑即創</span>  
<span style="margin-left: 2em">修邑志六閱歲而始成蓋本朱之屏黃仲若所輯鶴</span>  
<span style="margin-left: 2em">沙志及蔣思永新分縣志而增修之迨乾隆八年邑</span>  
<span style="margin-left: 2em">人陸學淵作副志視欽志加詳矣又後五十年而孝</span>  
<span style="margin-left: 2em">感胡公重纂新志尤爲詳悉迄今又八十餘年天道</span>  
<span style="margin-left: 2em">十年小變至於人事何獨不然况自咸豐以來中更</span>  
<span style="margin-left: 2em">兵燹文獻凋落采訪綦難誠非朝夕所可集事寬其</span>  
<span style="margin-left: 2em">歲月廣其蒐羅擇以精心持以固志實事求是勿徇</span>  
<span style="margin-left: 2em">私勿隨俗蓋餘五年而始潰於成非緩也不得已也</span>  
<span style="margin-left: 1em">一鶴沙志新分縣志據胡志其時似尚存今已失傳陸</span>  
<span style="margin-left: 2em">志雖存而已殘缺又遭蠹蝕不可檢閱皆未見槧本</span>  
<span style="margin-left: 2em">欽志祗分六類胡志廣爲十三其子目分合互有同</span>  
<span style="margin-left: 2em">異今參酌於兩志之閒約爲十六類爲子目八十有</span>  
<span style="margin-left: 2em">六附見者二凡二十二卷合首末爲二十四卷事主</span>  
<span style="margin-left: 2em">於詳而不欲濫文主於簡而不敢漏所與同人共勉</span>  
<span style="margin-left: 2em">者如此而已非敢必其果副也</span>  
<span style="margin-left: 1em">一全境水利二圖欽胡兩志互有詳略今合兩志參以</span>  
<span style="margin-left: 2em">訪冊或并或刪俾一目了然得其要領川沙廳已別</span>  
<span style="margin-left: 2em">有志故不復列圖</span>  
<span style="margin-left: 1em">一糧倉向在周浦鎮以便漕運故胡志有圖倉燬於咸</span>  
<span style="margin-left: 2em">豐三年自是以來全漕改折久未議復故今祇存其</span>  
<span style="margin-left: 2em">梗概於建置志惟積穀倉爲同治十一年創建條理</span>  
<span style="margin-left: 2em">井井圖之以期垂久</span>  
<span style="margin-left: 1em">一惠南書院胡志附見學校圖今別爲圖以爲人文勸</span>  
<span style="margin-left: 1em">一欽志壇廟亦隸建設胡別分祀典志然所列不盡應</span>  
<span style="margin-left: 2em">祀典也今改題祠祀志凡城鄉諸雜祀皆附此</span>  
<span style="margin-left: 1em">一欽志武衞亦隸建設胡別分武備志稱名不當今改</span>  
<span style="margin-left: 2em">題兵防屯田已見田賦營官列於官司至兵燹所以</span>  
<span style="margin-left: 2em">紀事不宜附兵防之後今別入雜志</span>  
<span style="margin-left: 1em">一有國者設官分職以爲一朝制度故史有職官志今</span>  
<span style="margin-left: 2em">一隅之地守土而已欽志題爲官司是也而統於建</span>  
<span style="margin-left: 2em">設則非今從胡別立志而名從欽欽志名宦冠於人</span>  
<span style="margin-left: 2em">物志胡題爲宦績列於此今亦從之</span>  
<span style="margin-left: 1em">一欽志科第錯出於人物志今從胡別爲選舉志舊附</span>  
<span style="margin-left: 2em">封贈例仕習非成是姑從俗登其實缺者</span>  
<span style="margin-left: 1em">一欽志無藝文今從胡志但搜采續增必須目見不敢</span>  
<span style="margin-left: 2em">但據空名考志者宜本此爲實其非灼見或已佚者</span>  
<span style="margin-left: 2em">僅載傳內兩不相蒙閒有小集以分目欠晰及傳簡</span>  
<span style="margin-left: 2em">難再刪者始互見一二</span>  
<span style="margin-left: 1em">一人物志欽胡兩志各分傳目中有疑似可互見者蓋</span>  
<span style="margin-left: 2em">子孫述德才華必兼經濟學問必擅辭章文飾鋪張</span>  
<span style="margin-left: 2em">幾於人人具美雖其中閒有一二而安能盡攷其虛</span>  
<span style="margin-left: 2em">實嘉定錢少詹修鄞志總題人物不分名目引寶慶</span>  
<span style="margin-left: 2em">延祐兩志上海志亦依陸慶循修例而獨分藝術則</span>  
<span style="margin-left: 2em">自亂其例今擬依古人合傳之例其無他長可見者</span>  
<span style="margin-left: 2em">立一人爲首而牽連書之惟列女游寓自當別題方</span>  
<span style="margin-left: 2em">外則自爲一志以寺觀僧道教堂隸焉勿使其溷乎</span>  
<span style="margin-left: 2em">我教也耆碩亦不標名如藝術例</span>  
<span style="margin-left: 1em">一欽志坊表附於建設胡志入之雜志上海新志附之</span>  
<span style="margin-left: 2em">街巷於意不安今別爲名跡志與古跡第宅圍林冢</span>  
<span style="margin-left: 2em">墓爲類碑刻絕少各附於當處</span>  
<span style="margin-left: 1em">一風俗爲郡邑志之急務舊多附之雜志非是今別立</span>  
<span style="margin-left: 2em">志而詳著其利敝以爲官斯土者因勢利導矯枉正</span>  
<span style="margin-left: 2em">俗之本其物產則取獨異於他處者著之</span>  
<span style="margin-left: 1em">一祥異遺事皆紀事也無類可歸各志隸之雜志兵燹</span>  
<span style="margin-left: 2em">亦然今從其類凡遭寇死者隨其地其時皆系於此</span>  
<span style="margin-left: 2em">其確有拒賊不屈事跡昭然者仍著錄於人物志</span>  
<span style="margin-left: 1em">一自嘉慶十年始析南邑十啚以與川沙則未析以前</span>  
<span style="margin-left: 2em">例宜詳載既析以後川沙自有志宜可從略惟學校</span>  
<span style="margin-left: 2em">統於南邑科第故仍載入云</span>  
<span style="margin-left: 1em">一志中例采前人詩文然必有裨於當地掌故古跡可</span>  
<span style="margin-left: 2em">攷見盛衰者始附之或有補於采風問俗可推知民</span>  
<span style="margin-left: 2em">隱者附之至於流連光景一時興到之作弁有全不</span>  
<span style="margin-left: 2em">關本地者概不采入</span>  
<span style="margin-left: 1em">一凡載筆之事必先不私於己而後能不私於人一有</span>  
<span style="margin-left: 2em">偏徇反脣立至錢少詹言近代士大夫一入志局必</span>  
<span style="margin-left: 2em">欲使其祖父族黨一一廁名卷中於是儒林文苑車</span>  
<span style="margin-left: 2em">載斗量徒爲後人覆瓿之用此論甚篤竊嘗以此自</span>  
<span style="margin-left: 2em">律并以告諸君子倘有遺漏請待續修</span>  
<span style="margin-left: 1em">凡例終</span>
