## 卷末

<span style="margin-left: 1em">旧序</span>  
<span style="margin-left: 1em">南汇向隶上海之东境隔浦依海询方问俗者所罕至</span>  
<span style="margin-left: 1em">而其闲风气湻朴士女敦实行务本业弗自炫耀以故</span>  
<span style="margin-left: 1em">向之志上海者一切水道兵赋风土人物之属浦以东</span>  
<span style="margin-left: 1em">率多缺略</span>  
<span style="margin-left: 1em">今上御极之三载诏分南汇为县而余以</span>  
<span style="margin-left: 1em">召对特简宰是邑至之日疆里建置咸未有定索考旧</span>  
<span style="margin-left: 1em">志既茫然无可据爰博访稗乘得鹤沙志十卷载十九</span>  
<span style="margin-left: 1em">保故实甚详他保阙如也又得蒋生思永辑新分县志</span>  
<span style="margin-left: 1em">稿摭拾略备惜未精核不足传信丁未冬修举缔造渐</span>  
<span style="margin-left: 1em">次就理公余稍暇延邑之乡先辈顾君成天暨其及门</span>  
<span style="margin-left: 1em">叶进士承其小阮孝廉昌设馆修辑经一寒暑始脱稿</span>  
<span style="margin-left: 1em">值余罢官不果就越明年委护郡符计将校正竣厥事</span>  
<span style="margin-left: 1em">适顾君奉</span>  
<span style="margin-left: 1em">天子召叶进士论次就选顾孝廉以计偕各先后北上</span>  
<span style="margin-left: 1em">无可与商榷者余旋亦纳印绶去又不果就既而余旅</span>  
<span style="margin-left: 1em">寓平江需次待</span>  
<span style="margin-left: 1em">命于箧中得未成志稿重加讐校不禁喟然叹曰是志</span>  
<span style="margin-left: 1em">之成固时有幸不幸耶夫志为一邑之记载凡政事之</span>  
<span style="margin-left: 1em">所出皆于是乎征且在剙始前无所因后将何考此长</span>  
<span style="margin-left: 1em">民者之责也余首宰于此虽去矣乌始事而中辍哉乃</span>  
<span style="margin-left: 1em">约一二老友裹粮载笔泛舟申浦重过治所遍询父老</span>  
<span style="margin-left: 1em">印证槀本芜者删阙者补正舛讹核事实虽不敢谓纲</span>  
<span style="margin-left: 1em">举目张亦庶几稍补缺略差异于芜陋不足传信者耳</span>  
<span style="margin-left: 1em">是志也自己酉初冬至庚戌秋杪又期月而告成为图</span>  
<span style="margin-left: 1em">十为卷十有六因备书起讫之年月与纂修之姓氏捐</span>  
<span style="margin-left: 1em">赀付诸梓藏其板于南汇之学舍俾后之人藉有考焉</span>  
<span style="margin-left: 1em">长兴钦连序</span>  
<span style="margin-left: 1em">皇上御极以来政教覃敷德化翔洽表忠孝节烈以厚</span>  
<span style="margin-left: 1em">民俗兴营田水利以遂民生蠲逋赋以苏民力惩贪残</span>  
<span style="margin-left: 1em">以去民害薄海内外物阜民安固已无利不兴无害不</span>  
<span style="margin-left: 1em">除犹</span>  
<span style="margin-left: 1em">轸念江南地方财赋重大讼狱繁多三年秋</span>  
<span style="margin-left: 1em">特允　督抚两宪之请于苏松常太四府州之大县设</span>  
<span style="margin-left: 1em">官分治共分县一十有三南汇其一也复</span>  
<span style="margin-left: 1em">命廷臣各保贤能一人分任其地而钦公连以新进士</span>  
<span style="margin-left: 1em">引见特授南汇南汇为上海分县处黄浦之东滨大海</span>  
<span style="margin-left: 1em">之西去县治百余里居民僻处海滨道路辽远斥卤之</span>  
<span style="margin-left: 1em">区土疥民贫有生平不至城中不见官长者以故钱粮</span>  
<span style="margin-left: 1em">听胥役之包收争讼任奸棍之起灭善良束手百獘丛</span>  
<span style="margin-left: 1em">生即此一邑而推仰见</span>  
<span style="margin-left: 1em">圣天子怀保奠安之心覆载无遗矣公深体其意捧檄</span>  
<span style="margin-left: 1em">星驰下车南汇旧城城故营卫地也城郭倾圮阛阓萧</span>  
<span style="margin-left: 1em">条居民寥落井里荒榛公则道妙张弛恩威交济殷殷</span>  
<span style="margin-left: 1em">化导宣布</span>  
<span style="margin-left: 1em">皇恩南汇之人民无不乐尧天而歌舜日但公廨全无</span>  
<span style="margin-left: 1em">僦寓民舍</span>  
<span style="margin-left: 1em">学宫未建弦诵声稀公乃相度形势领</span>  
<span style="margin-left: 1em">帑鸠工邑之人鼓舞欢欣荷畚锸而任力役者远近云</span>  
<span style="margin-left: 1em">集计工授值不以一丝累及百姓数月而</span>  
<span style="margin-left: 1em">学宫官署次第落成<sub class="note-yuan">珂</sub>于五年春奉</span>  
<span style="margin-left: 1em">命拣发江南兴修水利因督修吴淞江坝工适公摄上</span>  
<span style="margin-left: 1em">海篆晤于工所欢若生平得闻经营创造之概七年秋</span>  
<span style="margin-left: 1em"><sub class="note-yuan">珂</sub>承乏南汇适公委护松江府篆进见之时公顾<sub class="note-yuan">珂</sub>曰</span>  
<span style="margin-left: 1em">职守无分难易视力行何如耳治南之略余已纲举试</span>  
<span style="margin-left: 1em">为君言之南之财赋江海坍涨不一宜清理之南之户</span>  
<span style="margin-left: 1em">口鱼盐生活居多宜矜恤之南之堤塘道路宜补其倾</span>  
<span style="margin-left: 1em">圮而禁其科派南之园廛芦荡宜清其兼并而释其偏</span>  
<span style="margin-left: 1em">累至培士气如师保抚民生如父母此在新硎游刃者</span>  
<span style="margin-left: 1em">批郤导窾余于此有厚望焉邑既新分应有专志但凡</span>  
<span style="margin-left: 1em">例多而考证不易纂辑繁而仓卒难成且校讐需人剞</span>  
<span style="margin-left: 1em">劂需费余于退食之暇将手辑以成书<sub class="note-yuan">珂</sub>谨书绅受教</span>  
<span style="margin-left: 1em">期勉力捐赀以共勷盛举及<sub class="note-yuan">珂</sub>莅任南汇谒</span>  
<span style="margin-left: 1em">圣庙则数仞宫墙巍然美富而应祀之祠宇坛壝无一</span>  
<span style="margin-left: 1em">不备也入衙署则堂庑翼翼燕处如如而经设之仓库</span>  
<span style="margin-left: 1em">禁狱无处不坚也城垣其旧也而雉堞嵯峨池河如故</span>  
<span style="margin-left: 1em">也而疏濬通畅闲有一二未尽善美者仍留督修其深</span>  
<span style="margin-left: 1em">思远虑舍己爱民尤在建漕仓于周浦镇南汇处上海</span>  
<span style="margin-left: 1em">之东虽有支河河流浅隘止可容舠漕艘难进若建仓</span>  
<span style="margin-left: 1em">于城中交兑则有盘剥之劳沍寒则有冰冻之虑周浦</span>  
<span style="margin-left: 1em">镇为南邑适中之地去黄浦不远漕艘直达镇西四乡</span>  
<span style="margin-left: 1em">居民远近均平惟官吏收漕冬则移居仓所夏则复回</span>  
<span style="margin-left: 1em">县署胥役惮于往来以命盗重案提审虑有疎虞为请</span>  
<span style="margin-left: 1em">公曰慎差役勤听断朝发夕至夫何虑焉吾岂以身心</span>  
<span style="margin-left: 1em">目下之安闲贻百姓将来之派累耶仓建而民悉便是</span>  
<span style="margin-left: 1em">以去南之日南之绅衿黎庶无不卧辙攀辕或公以按</span>  
<span style="margin-left: 1em">部来南杖鸠父老骑竹儿童以及民闲妇女悉皆观望</span>  
<span style="margin-left: 1em">欢欣如婴儿之恋慈母则公之德泽入人深而感人切</span>  
<span style="margin-left: 1em">也<sub class="note-yuan">珂</sub>以迂拙奉职无状负公知遇然继公之后佩公之</span>  
<span style="margin-left: 1em">言行公之政南之士民以爱公之心爱<sub class="note-yuan">珂</sub>缠绵笃挚先</span>  
<span style="margin-left: 1em">后同揆实本公留去后之思而珂得为召伯之甘棠亦</span>  
<span style="margin-left: 1em">何幸欤此书之成远据前猷近参舆论分疆画界图稽</span>  
<span style="margin-left: 1em">甲考既无摭拾亦无遗漏遂成一邑之典制经济文章</span>  
<span style="margin-left: 1em">各臻其极以无负</span>  
<span style="margin-left: 1em">圣天子分县设官爱养元元之至意为南汇创始之一</span>  
<span style="margin-left: 1em">人茂绩循声载诸信史将见书以人传南邑之版舆南</span>  
<span style="margin-left: 1em">邑之风土人物亦与之俱传<sub class="note-yuan">珂</sub>得窃附以不朽焉因不</span>  
<span style="margin-left: 1em">揣固陋而为之序雍正庚戌岁十月朔楚黄姚之珂撰</span>  
<span style="margin-left: 1em">曩年<sub class="note-yuan">连</sub>承乏南邑既与搢绅肇修新乘敬志</span>  
<span style="margin-left: 1em">皇上分土厚民之至意十一年癸丑复莅是邦恭遇</span>  
<span style="margin-left: 1em">皇上轸念灾荒沛</span>  
<span style="margin-left: 1em">大恩兴大役百方补救因之大吏承流下里任恤播</span>  
<span style="margin-left: 1em">九重之德音回万井于阳春<sub class="note-yuan">连</sub>于是时肃恭将事惴惴</span>  
<span style="margin-left: 1em">然惟惧弗胜事麤集穆然深思曰尧汤水旱圣人无召</span>  
<span style="margin-left: 1em">灾之过而有弭灾之功盖天之阴阳刚柔犹人之喜怒</span>  
<span style="margin-left: 1em">哀乐喜怒哀乐过其节则事失其宜阴阳刚柔反其常</span>  
<span style="margin-left: 1em">则物戕其生天地一积气之区气不能无过不及也圣</span>  
<span style="margin-left: 1em">人在上为天地宗子继其志述其事人之所憾圣人补</span>  
<span style="margin-left: 1em">之故曰致中和天地位万物育又曰人能宏道今</span>  
<span style="margin-left: 1em">天子之衽席残黎此物此志也事莫大焉可弗纪乎爰</span>  
<span style="margin-left: 1em">与孝廉顾君昺述灾荒颂</span>  
<span style="margin-left: 1em">仁恩闾阎好义并书以劝原本中之误者正之遗者补</span>  
<span style="margin-left: 1em">之夫孝廉遇灾极人世未有之惨其言固宜深切著明</span>  
<span style="margin-left: 1em">也至于百凡沿革值连去位姑俟后之君子雍正十二</span>  
<span style="margin-left: 1em">年甲寅夏长兴钦连叙</span>  
<span style="margin-left: 1em">皇帝闳开仁域大邑分厘雍正三年乙巳定建南汇县</span>  
<span style="margin-left: 1em">议其明年邑侯钦公迪简于</span>  
<span style="margin-left: 1em">廷首莅兹土德孚才驭民和事集廼延众论而修邑志</span>  
<span style="margin-left: 1em">成天与及门士叶子承从子昺获珥笔焉朝夕参考数</span>  
<span style="margin-left: 1em">月将脱稿而侯去成天亦随奉</span>  
<span style="margin-left: 1em">恩诏入都觐</span>  
<span style="margin-left: 1em">天颜伴</span>  
<span style="margin-left: 1em">皇子讲读从子试南宫留余直庐叶子令常山而侯独</span>  
<span style="margin-left: 1em">于驰驱鞅掌闲摅所见而荟萃焉又阅期月书成成天</span>  
<span style="margin-left: 1em">受而序之盖尝论南邑之建其治较他邑颇易亦颇难</span>  
<span style="margin-left: 1em">邑东薄大海申浦带其西鲜往来舟车行旅异物气以</span>  
<span style="margin-left: 1em">蓄而不过人心无所荡故风不甚漓治之所以易也地</span>  
<span style="margin-left: 1em">多斥卤水泉不厚旱乾可患海若冲突可虞兵防盐䇲</span>  
<span style="margin-left: 1em">杂揉其闲小民生齿繁生计鲜姑息则弛武健则蹙治</span>  
<span style="margin-left: 1em">之所以难也以其易者而顺导之以其难者而补救之</span>  
<span style="margin-left: 1em">侯之绩皆有明效矣是志之作又以其顺导补救之策</span>  
<span style="margin-left: 1em">遵</span>  
<span style="margin-left: 1em">昭代章程参前人法戒验人情之所欲恶胪而列之俾</span>  
<span style="margin-left: 1em">行人可采外史可掌守土者可攷镜侯盖有无已之心</span>  
<span style="margin-left: 1em">焉夫分土以亲民</span>  
<span style="margin-left: 1em">天子之仁也克勤乃事新猷永赖有司之良也谨编摩</span>  
<span style="margin-left: 1em">而备一得乡人士之职也侯能上报</span>  
<span style="margin-left: 1em">圣天子而余三人得借手以黼黻升平厥功懋哉雍正</span>  
<span style="margin-left: 1em">八年嘉平月邑人顾成天撰<sub class="note-yuan">以上钦志序文</sub></span>  
<span style="margin-left: 2em">附纂辑姓氏<sub class="note-yuan">籍贯官阶前见卷中概不叙</sub></span>  
<span style="margin-left: 2em">钦　连<sub class="note-yuan">主修</sub>　　顾成天　　叶　承</span>  
<span style="margin-left: 2em">顾　昺<sub class="note-yuan">上俱纂辑</sub>　　姚之珂<sub class="note-yuan">参订</sub></span>  
<span style="margin-left: 1em">志之为言识也语多见而识识其大识其小古本作志</span>  
<span style="margin-left: 1em">是也周外史掌四方之志郑氏谓翁鲁春秋晋乘楚梼</span>  
<span style="margin-left: 1em">杌之比近省志府县志因之然志之名分系之天文地</span>  
<span style="margin-left: 1em">理职官选举艺文诸类而省志府县志统及乎诸类以</span>  
<span style="margin-left: 1em">观其通然失之冗者摭引不根失之漏者阙轶有闲故</span>  
<span style="margin-left: 1em">志之修与作也其难等吾邑以雍正二年割上海分建</span>  
<span style="margin-left: 1em">时邑侯长兴钦公连据上海志鹤沙志撰县志十六卷</span>  
<span style="margin-left: 1em">不载分野不专立艺文义例最为明简阅今六十余年</span>  
<span style="margin-left: 1em">生聚日蕃风会日盛民物之丰悴政令之张弛今之视</span>  
<span style="margin-left: 1em">昔犹后之视今不有传焉意司牧者以未具史才抑亦</span>  
<span style="margin-left: 1em">邑士夫之耻也岁癸丑发春予在假持妇服闻欵门者</span>  
<span style="margin-left: 1em">至则擕胡侯志稿属定伏读累日叹其事增文减所应</span>  
<span style="margin-left: 1em">有者尽有所应无者尽无史事如此即吏事可知焉矣</span>  
<span style="margin-left: 1em">三十年前县号难治民有摸金校尉之智士有邓思贤</span>  
<span style="margin-left: 1em">之书击断鸷猛俗尚斯变虽变之者非必其道而其底</span>  
<span style="margin-left: 1em">于变也则同侯究心利病举所以治之道一再致意为</span>  
<span style="margin-left: 1em">农桑学校计至深且远而余以衰迟孱病之身亲见之</span>  
<span style="margin-left: 1em">而执简序之为何如厚幸也汇之名始自禹贡禹贡言</span>  
<span style="margin-left: 1em">水以小注大曰入水力大小相配曰会惟彭蠡受豫章</span>  
<span style="margin-left: 1em">九水越大江之南地势北高南下故其入江处反为江</span>  
<span style="margin-left: 1em">水所遏而不得遂遂却而自潴曰东汇泽为彭蠡言汉</span>  
<span style="margin-left: 1em">水入江以东迥为大泽也曰东迤北会为汇言江水与</span>  
<span style="margin-left: 1em">汉所汇之彭蠡会也汇者迥也大海抱县东南地势旋</span>  
<span style="margin-left: 1em">折南派受浙水北派受大江水波澜迥复潮汐激宕海</span>  
<span style="margin-left: 1em">底铁板沙寇舶至即败城踞要害贻乐利于无穷官是</span>  
<span style="margin-left: 1em">邦者手是编以周知夫疆宇夷险民物丰悴政令张弛</span>  
<span style="margin-left: 1em">之数而于治思过半焉是又侯勤施所在而邑士夫不</span>  
<span style="margin-left: 1em">能諠者夫乾隆五十八年二月十六日工部右侍郎邑</span>  
<span style="margin-left: 1em">人吴省钦撰</span>  
<span style="margin-left: 1em">癸丑春余游云闲适南邑胡明府下车之三载物阜民</span>  
<span style="margin-left: 1em">安清和咸理续辑志乘业有缮本属之检校重以太守</span>  
<span style="margin-left: 1em">李甯圃先生之命固辞不获因再加厘订删繁举要田</span>  
<span style="margin-left: 1em">赋则数核区圩水利则流分脉络至于政事文章孝友</span>  
<span style="margin-left: 1em">节义务期事事足征阅四月而诠次成帙用以答贤侯</span>  
<span style="margin-left: 1em">垂示久远之意夫志之为书非徒矜博骋华供文人之</span>  
<span style="margin-left: 1em">流览将举一邑之土田城郭典章文物与夫士习民风</span>  
<span style="margin-left: 1em">罗而列之俾莅是土者周知其因革损益废兴隆替之</span>  
<span style="margin-left: 1em">由以为敷治之具顾创之固难而修之亦复不易自非</span>  
<span style="margin-left: 1em">守土者主持纲要集悫诚多识之士搜辑旧闻相与信</span>  
<span style="margin-left: 1em">今而传后势必承讹袭谬后之人即欲考镜得失其道</span>  
<span style="margin-left: 1em">何由邑志创自钦侯幼畹当分邑之始规模粗立政治</span>  
<span style="margin-left: 1em">毕具今又得贤侯重为修辑事在旧志以后者续之在</span>  
<span style="margin-left: 1em">前者补之广搜旁采确而有据甯非此邦之厚幸与余</span>  
<span style="margin-left: 1em">久荒学殖言之弗文或借以稽故实广闻见未必非为</span>  
<span style="margin-left: 1em">学一助也因缀数语于简末云乾隆五十八年仲秋月</span>  
<span style="margin-left: 1em">虞山姚左垣撰</span>  
<span style="margin-left: 1em">南汇分于雍正四年知县事者自钦公连始县志即始</span>  
<span style="margin-left: 1em">于公邑人顾侍讲成天叶进士承分任搜辑阅岁而稾</span>  
<span style="margin-left: 1em">具侯之复来重加删补而书始成乾隆辛亥熊承乏兹</span>  
<span style="margin-left: 1em">土阅其书政术赅备纲举目张窃谓钦公之志即公之</span>  
<span style="margin-left: 1em">治也至今六十余年</span>  
<span style="margin-left: 1em">国家重熙累洽闿泽滂洋我</span>  
<span style="margin-left: 1em">皇上久道化成</span>  
<span style="margin-left: 1em">恩膏叠沛海隅黎庶共沐泰和长吏播扬</span>  
<span style="margin-left: 1em">上德化导斯民风俗蒸蒸日上举凡兴利除弊之制美</span>  
<span style="margin-left: 1em">不胜数邑三面濒海西抱申浦地势高于诸港无潴水</span>  
<span style="margin-left: 1em">之区以备暵乾沟浍既隘潮汐易淤沙团月洞疏濬节</span>  
<span style="margin-left: 1em">蓄之方关于民生者甚钜圩田平衍群习勤苦又非孔</span>  
<span style="margin-left: 1em">道不见浮靡之事故人知礼节而户有秀民学校既兴</span>  
<span style="margin-left: 1em">艺文蔚起独行懿修遗风可挹凡前志所未及详者网</span>  
<span style="margin-left: 1em">罗而补缀之亦莅斯邑者之责也爰集绅士采摭以顾</span>  
<span style="margin-left: 1em">侍讲原稿目录为诠次旁及碑碣谱乘就正于吴白华</span>  
<span style="margin-left: 1em">稷堂两先生订其譌阙复延虞山姚星岩铨部为之厘</span>  
<span style="margin-left: 1em">定名曰新志凡十五卷<sub class="note-yuan">熊</sub>受任以来钦</span>  
<span style="margin-left: 1em">圣德之渐被遵</span>
