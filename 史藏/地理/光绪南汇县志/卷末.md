## 卷末

<span style="margin-left: 1em">舊序</span>  
<span style="margin-left: 1em">南滙向隸上海之東境隔浦依海詢方問俗者所罕至</span>  
<span style="margin-left: 1em">而其閒風氣湻樸士女敦實行務本業弗自炫耀以故</span>  
<span style="margin-left: 1em">向之志上海者一切水道兵賦風土人物之屬浦以東</span>  
<span style="margin-left: 1em">率多缺略</span>  
<span style="margin-left: 1em">今上御極之三載詔分南滙爲縣而余以</span>  
<span style="margin-left: 1em">召對特簡宰是邑至之日疆里建置咸未有定索考舊</span>  
<span style="margin-left: 1em">志既茫然無可據爰博訪稗乘得鶴沙志十卷載十九</span>  
<span style="margin-left: 1em">保故實甚詳他保闕如也又得蔣生思永輯新分縣志</span>  
<span style="margin-left: 1em">稿摭拾略備惜未精覈不足傳信丁未冬修舉締造漸</span>  
<span style="margin-left: 1em">次就理公餘稍暇延邑之鄉先輩顧君成天暨其及門</span>  
<span style="margin-left: 1em">葉進士承其小阮孝廉昌設館修輯經一寒暑始脫稿</span>  
<span style="margin-left: 1em">值余罷官不果就越明年委護郡符計將校正竣厥事</span>  
<span style="margin-left: 1em">適顧君奉</span>  
<span style="margin-left: 1em">天子召葉進士論次就選顧孝廉以計偕各先後北上</span>  
<span style="margin-left: 1em">無可與商榷者余旋亦納印綬去又不果就既而余旅</span>  
<span style="margin-left: 1em">寓平江需次待</span>  
<span style="margin-left: 1em">命於篋中得未成志稿重加讐校不禁喟然嘆曰是志</span>  
<span style="margin-left: 1em">之成固時有幸不幸耶夫志爲一邑之記載凡政事之</span>  
<span style="margin-left: 1em">所出皆於是乎徵且在剙始前無所因後將何考此長</span>  
<span style="margin-left: 1em">民者之責也余首宰於此雖去矣烏始事而中輟哉乃</span>  
<span style="margin-left: 1em">約一二老友裹糧載筆泛舟申浦重過治所遍詢父老</span>  
<span style="margin-left: 1em">印證槀本蕪者刪闕者補正舛訛核事實雖不敢謂綱</span>  
<span style="margin-left: 1em">舉目張亦庶幾稍補缺略差異於蕪陋不足傳信者耳</span>  
<span style="margin-left: 1em">是志也自己酉初冬至庚戌秋杪又期月而告成爲圖</span>  
<span style="margin-left: 1em">十爲卷十有六因備書起訖之年月與纂修之姓氏捐</span>  
<span style="margin-left: 1em">貲付諸梓藏其板於南滙之學舍俾後之人藉有考焉</span>  
<span style="margin-left: 1em">長興欽連序</span>  
<span style="margin-left: 1em">皇上御極以來政教覃敷德化翔洽表忠孝節烈以厚</span>  
<span style="margin-left: 1em">民俗興營田水利以遂民生蠲逋賦以蘇民力懲貪殘</span>  
<span style="margin-left: 1em">以去民害薄海內外物阜民安固已無利不興無害不</span>  
<span style="margin-left: 1em">除猶</span>  
<span style="margin-left: 1em">軫念江南地方財賦重大訟獄繁多三年秋</span>  
<span style="margin-left: 1em">特允　督撫兩憲之請於蘇松常太四府州之大縣設</span>  
<span style="margin-left: 1em">官分治共分縣一十有三南滙其一也復</span>  
<span style="margin-left: 1em">命廷臣各保賢能一人分任其地而欽公連以新進士</span>  
<span style="margin-left: 1em">引見特授南滙南滙爲上海分縣處黃浦之東濱大海</span>  
<span style="margin-left: 1em">之西去縣治百餘里居民僻處海濱道路遼遠斥鹵之</span>  
<span style="margin-left: 1em">區土疥民貧有生平不至城中不見官長者以故錢糧</span>  
<span style="margin-left: 1em">聽胥役之包收爭訟任奸棍之起滅善良束手百獘叢</span>  
<span style="margin-left: 1em">生即此一邑而推仰見</span>  
<span style="margin-left: 1em">聖天子懷保奠安之心覆載無遺矣公深體其意捧檄</span>  
<span style="margin-left: 1em">星馳下車南滙舊城城故營衛地也城郭傾圮闤闠蕭</span>  
<span style="margin-left: 1em">條居民寥落井里荒榛公則道妙張弛恩威交濟殷殷</span>  
<span style="margin-left: 1em">化導宣布</span>  
<span style="margin-left: 1em">皇恩南滙之人民無不樂堯天而歌舜日但公廨全無</span>  
<span style="margin-left: 1em">僦寓民舍</span>  
<span style="margin-left: 1em">學宮未建絃誦聲稀公乃相度形勢領</span>  
<span style="margin-left: 1em">帑鳩工邑之人鼓舞歡欣荷畚鍤而任力役者遠近雲</span>  
<span style="margin-left: 1em">集計工授值不以一絲累及百姓數月而</span>  
<span style="margin-left: 1em">學宮官署次第落成<sub class="note-yuan">珂</sub>於五年春奉</span>  
<span style="margin-left: 1em">命揀發江南興修水利因督修吳淞江壩工適公攝上</span>  
<span style="margin-left: 1em">海篆晤於工所歡若生平得聞經營創造之概七年秋</span>  
<span style="margin-left: 1em"><sub class="note-yuan">珂</sub>承乏南滙適公委護松江府篆進見之時公顧<sub class="note-yuan">珂</sub>曰</span>  
<span style="margin-left: 1em">職守無分難易視力行何如耳治南之略余已綱舉試</span>  
<span style="margin-left: 1em">爲君言之南之財賦江海坍漲不一宜清理之南之户</span>  
<span style="margin-left: 1em">口魚鹽生活居多宜矜恤之南之堤塘道路宜補其傾</span>  
<span style="margin-left: 1em">圮而禁其科派南之園廛蘆蕩宜清其兼并而釋其偏</span>  
<span style="margin-left: 1em">累至培士氣如師保撫民生如父母此在新硎游刃者</span>  
<span style="margin-left: 1em">批郤導窾余於此有厚望焉邑既新分應有專志但凡</span>  
<span style="margin-left: 1em">例多而考証不易纂輯繁而倉卒難成且校讐需人剞</span>  
<span style="margin-left: 1em">劂需費余於退食之暇將手輯以成書<sub class="note-yuan">珂</sub>謹書紳受教</span>  
<span style="margin-left: 1em">期勉力捐貲以共勷盛舉及<sub class="note-yuan">珂</sub>蒞任南滙謁</span>  
<span style="margin-left: 1em">聖廟則數仞宮牆巍然美富而應祀之祠宇壇壝無一</span>  
<span style="margin-left: 1em">不備也入衙署則堂廡翼翼燕處如如而經設之倉庫</span>  
<span style="margin-left: 1em">禁獄無處不堅也城垣其舊也而雉堞嵯峨池河如故</span>  
<span style="margin-left: 1em">也而疏濬通暢閒有一二未盡善美者仍留督修其深</span>  
<span style="margin-left: 1em">思遠慮舍己愛民尤在建漕倉於周浦鎮南滙處上海</span>  
<span style="margin-left: 1em">之東雖有支河河流淺隘止可容舠漕艘難進若建倉</span>  
<span style="margin-left: 1em">於城中交兌則有盤剝之勞沍寒則有冰凍之慮周浦</span>  
<span style="margin-left: 1em">鎮爲南邑適中之地去黃浦不遠漕艘直達鎮西四鄉</span>  
<span style="margin-left: 1em">居民遠近均平惟官吏收漕冬則移居倉所夏則復回</span>  
<span style="margin-left: 1em">縣署胥役憚於往來以命盜重案提審慮有疎虞爲請</span>  
<span style="margin-left: 1em">公曰慎差役勤聽斷朝發夕至夫何慮焉吾豈以身心</span>  
<span style="margin-left: 1em">目下之安閒貽百姓將來之派累耶倉建而民悉便是</span>  
<span style="margin-left: 1em">以去南之日南之紳衿黎庶無不臥轍攀轅或公以按</span>  
<span style="margin-left: 1em">部來南杖鳩父老騎竹兒童以及民閒婦女悉皆觀望</span>  
<span style="margin-left: 1em">歡欣如嬰兒之戀慈母則公之德澤入人深而感人切</span>  
<span style="margin-left: 1em">也<sub class="note-yuan">珂</sub>以迂拙奉職無狀負公知遇然繼公之後佩公之</span>  
<span style="margin-left: 1em">言行公之政南之士民以愛公之心愛<sub class="note-yuan">珂</sub>纏綿篤摯先</span>  
<span style="margin-left: 1em">後同揆實本公留去後之思而珂得爲召伯之甘棠亦</span>  
<span style="margin-left: 1em">何幸歟此書之成遠據前猷近參輿論分疆畫界圖稽</span>  
<span style="margin-left: 1em">甲考既無摭拾亦無遺漏遂成一邑之典制經濟文章</span>  
<span style="margin-left: 1em">各臻其極以無負</span>  
<span style="margin-left: 1em">聖天子分縣設官愛養元元之至意爲南滙創始之一</span>  
<span style="margin-left: 1em">人茂績循聲載諸信史將見書以人傳南邑之版輿南</span>  
<span style="margin-left: 1em">邑之風土人物亦與之俱傳<sub class="note-yuan">珂</sub>得竊附以不朽焉因不</span>  
<span style="margin-left: 1em">揣固陋而爲之序雍正庚戌歲十月朔楚黃姚之珂撰</span>  
<span style="margin-left: 1em">曩年<sub class="note-yuan">連</sub>承乏南邑既與搢紳肇修新乘敬誌</span>  
<span style="margin-left: 1em">皇上分土厚民之至意十一年癸丑復蒞是邦恭遇</span>  
<span style="margin-left: 1em">皇上軫念災荒沛</span>  
<span style="margin-left: 1em">大恩興大役百方補救因之大吏承流下里任恤播</span>  
<span style="margin-left: 1em">九重之德音回萬井於陽春<sub class="note-yuan">連</sub>於是時肅恭將事惴惴</span>  
<span style="margin-left: 1em">然惟懼弗勝事麤集穆然深思曰堯湯水旱聖人無召</span>  
<span style="margin-left: 1em">災之過而有弭災之功蓋天之陰陽剛柔猶人之喜怒</span>  
<span style="margin-left: 1em">哀樂喜怒哀樂過其節則事失其宜陰陽剛柔反其常</span>  
<span style="margin-left: 1em">則物戕其生天地一積氣之區氣不能無過不及也聖</span>  
<span style="margin-left: 1em">人在上爲天地宗子繼其志述其事人之所憾聖人補</span>  
<span style="margin-left: 1em">之故曰致中和天地位萬物育又曰人能宏道今</span>  
<span style="margin-left: 1em">天子之衽席殘黎此物此志也事莫大焉可弗紀乎爰</span>  
<span style="margin-left: 1em">與孝廉顧君昺述災荒頌</span>  
<span style="margin-left: 1em">仁恩閭閻好義并書以勸原本中之誤者正之遺者補</span>  
<span style="margin-left: 1em">之夫孝廉遇災極人世未有之慘其言固宜深切著明</span>  
<span style="margin-left: 1em">也至於百凡沿革值連去位姑俟後之君子雍正十二</span>  
<span style="margin-left: 1em">年甲寅夏長興欽連敘</span>  
<span style="margin-left: 1em">皇帝閎開仁域大邑分釐雍正三年乙巳定建南滙縣</span>  
<span style="margin-left: 1em">議其明年邑侯欽公迪簡於</span>  
<span style="margin-left: 1em">廷首蒞兹土德孚才馭民和事集廼延衆論而修邑志</span>  
<span style="margin-left: 1em">成天與及門士葉子承從子昺獲珥筆焉朝夕參考數</span>  
<span style="margin-left: 1em">月將脫稿而侯去成天亦隨奉</span>  
<span style="margin-left: 1em">恩詔入都覲</span>  
<span style="margin-left: 1em">天顏伴</span>  
<span style="margin-left: 1em">皇子講讀從子試南宮留余直廬葉子令常山而侯獨</span>  
<span style="margin-left: 1em">於馳驅鞅掌閒攄所見而薈萃焉又閲期月書成成天</span>  
<span style="margin-left: 1em">受而序之蓋嘗論南邑之建其治較他邑頗易亦頗難</span>  
<span style="margin-left: 1em">邑東薄大海申浦帶其西鮮往來舟車行旅異物氣以</span>  
<span style="margin-left: 1em">蓄而不過人心無所蕩故風不甚漓治之所以易也地</span>  
<span style="margin-left: 1em">多斥鹵水泉不厚旱乾可患海若衝突可虞兵防鹽筴</span>  
<span style="margin-left: 1em">雜揉其閒小民生齒繁生計鮮姑息則弛武健則蹙治</span>  
<span style="margin-left: 1em">之所以難也以其易者而順導之以其難者而補救之</span>  
<span style="margin-left: 1em">侯之績皆有明效矣是志之作又以其順導補救之策</span>  
<span style="margin-left: 1em">遵</span>  
<span style="margin-left: 1em">昭代章程參前人法戒驗人情之所欲惡臚而列之俾</span>  
<span style="margin-left: 1em">行人可采外史可掌守土者可攷鏡侯蓋有無已之心</span>  
<span style="margin-left: 1em">焉夫分土以親民</span>  
<span style="margin-left: 1em">天子之仁也克勤乃事新猷永賴有司之良也謹編摩</span>  
<span style="margin-left: 1em">而備一得鄉人士之職也侯能上報</span>  
<span style="margin-left: 1em">聖天子而余三人得藉手以黼黻昇平厥功懋哉雍正</span>  
<span style="margin-left: 1em">八年嘉平月邑人顧成天撰<sub class="note-yuan">以上欽志序文</sub></span>  
<span style="margin-left: 2em">附纂輯姓氏<sub class="note-yuan">籍貫官階前見卷中概不敘</sub></span>  
<span style="margin-left: 2em">欽　連<sub class="note-yuan">主修</sub>　　顧成天　　葉　承</span>  
<span style="margin-left: 2em">顧　昺<sub class="note-yuan">上俱纂輯</sub>　　姚之珂<sub class="note-yuan">參訂</sub></span>  
<span style="margin-left: 1em">志之爲言識也語多見而識識其大識其小古本作志</span>  
<span style="margin-left: 1em">是也周外史掌四方之志鄭氏謂翁魯春秋晉乘楚檮</span>  
<span style="margin-left: 1em">杌之比近省志府縣志因之然志之名分繫之天文地</span>  
<span style="margin-left: 1em">理職官選舉藝文諸類而省志府縣志統及乎諸類以</span>  
<span style="margin-left: 1em">觀其通然失之冗者摭引不根失之漏者闕軼有閒故</span>  
<span style="margin-left: 1em">志之修與作也其難等吾邑以雍正二年割上海分建</span>  
<span style="margin-left: 1em">時邑侯長興欽公連據上海志鶴沙志撰縣志十六卷</span>  
<span style="margin-left: 1em">不載分野不專立藝文義例最爲明簡閲今六十餘年</span>  
<span style="margin-left: 1em">生聚日蕃風會日盛民物之豐悴政令之張弛今之視</span>  
<span style="margin-left: 1em">昔猶後之視今不有傳焉意司牧者以未具史才抑亦</span>  
<span style="margin-left: 1em">邑士夫之恥也歲癸丑發春予在假持婦服聞欵門者</span>  
<span style="margin-left: 1em">至則擕胡侯志稿屬定伏讀累日嘆其事增文減所應</span>  
<span style="margin-left: 1em">有者盡有所應無者盡無史事如此即吏事可知焉矣</span>  
<span style="margin-left: 1em">三十年前縣號難治民有摸金校尉之智士有鄧思賢</span>  
<span style="margin-left: 1em">之書擊斷鷙猛俗尚斯變雖變之者非必其道而其底</span>  
<span style="margin-left: 1em">於變也則同侯究心利病舉所以治之道一再致意爲</span>  
<span style="margin-left: 1em">農桑學校計至深且遠而余以衰遲孱病之身親見之</span>  
<span style="margin-left: 1em">而執簡序之爲何如厚幸也滙之名始自禹貢禹貢言</span>  
<span style="margin-left: 1em">水以小注大曰入水力大小相配曰會惟彭蠡受豫章</span>  
<span style="margin-left: 1em">九水越大江之南地勢北高南下故其入江處反爲江</span>  
<span style="margin-left: 1em">水所遏而不得遂遂卻而自瀦曰東滙澤爲彭蠡言漢</span>  
<span style="margin-left: 1em">水入江以東迥爲大澤也曰東迤北會爲滙言江水與</span>  
<span style="margin-left: 1em">漢所滙之彭蠡會也滙者迥也大海抱縣東南地勢旋</span>  
<span style="margin-left: 1em">折南派受浙水北派受大江水波瀾迥復潮汐激宕海</span>  
<span style="margin-left: 1em">底鐵板沙寇舶至即敗城踞要害貽樂利於無窮官是</span>  
<span style="margin-left: 1em">邦者手是編以周知夫疆宇夷險民物豐悴政令張弛</span>  
<span style="margin-left: 1em">之數而於治思過半焉是又侯勤施所在而邑士夫不</span>  
<span style="margin-left: 1em">能諠者夫乾隆五十八年二月十六日工部右侍郎邑</span>  
<span style="margin-left: 1em">人吳省欽撰</span>  
<span style="margin-left: 1em">癸丑春余遊雲閒適南邑胡明府下車之三載物阜民</span>  
<span style="margin-left: 1em">安清和咸理續輯志乘業有繕本屬之檢校重以太守</span>  
<span style="margin-left: 1em">李甯圃先生之命固辭不獲因再加釐訂刪繁舉要田</span>  
<span style="margin-left: 1em">賦則數核區圩水利則流分脉絡至于政事文章孝友</span>  
<span style="margin-left: 1em">節義務期事事足徵閲四月而詮次成帙用以答賢侯</span>  
<span style="margin-left: 1em">垂示久遠之意夫志之爲書非徒矜博騁華供文人之</span>  
<span style="margin-left: 1em">流覽將舉一邑之土田城郭典章文物與夫士習民風</span>  
<span style="margin-left: 1em">羅而列之俾蒞是土者周知其因革損益廢興隆替之</span>  
<span style="margin-left: 1em">由以爲敷治之具顧創之固難而修之亦復不易自非</span>  
<span style="margin-left: 1em">守土者主持綱要集慤誠多識之士搜輯舊聞相與信</span>  
<span style="margin-left: 1em">今而傳後勢必承訛襲謬後之人即欲考鏡得失其道</span>  
<span style="margin-left: 1em">何由邑志創自欽侯幼畹當分邑之始規模粗立政治</span>  
<span style="margin-left: 1em">畢具今又得賢侯重爲修輯事在舊志以後者續之在</span>  
<span style="margin-left: 1em">前者補之廣搜旁采確而有據甯非此邦之厚幸與余</span>  
<span style="margin-left: 1em">久荒學殖言之弗文或藉以稽故實廣聞見未必非爲</span>  
<span style="margin-left: 1em">學一助也因綴數語于簡末云乾隆五十八年仲秋月</span>  
<span style="margin-left: 1em">虞山姚左垣撰</span>  
<span style="margin-left: 1em">南滙分於雍正四年知縣事者自欽公連始縣志即始</span>  
<span style="margin-left: 1em">於公邑人顧侍講成天葉進士承分任蒐輯閲歲而稾</span>  
<span style="margin-left: 1em">具侯之復來重加刪補而書始成乾隆辛亥熊承乏兹</span>  
<span style="margin-left: 1em">土閲其書政術賅備綱舉目張竊謂欽公之志即公之</span>  
<span style="margin-left: 1em">治也至今六十餘年</span>  
<span style="margin-left: 1em">國家重熙累洽闓澤滂洋我</span>  
<span style="margin-left: 1em">皇上久道化成</span>  
<span style="margin-left: 1em">恩膏疊沛海隅黎庶共沐泰和長吏播揚</span>  
<span style="margin-left: 1em">上德化導斯民風俗蒸蒸日上舉凡興利除弊之制美</span>  
<span style="margin-left: 1em">不勝數邑三面瀕海西抱申浦地勢高於諸港無瀦水</span>  
<span style="margin-left: 1em">之區以備暵乾溝澮既隘潮汐易淤沙團月洞疏濬節</span>  
<span style="margin-left: 1em">蓄之方關於民生者甚鉅圩田平衍羣習勤苦又非孔</span>  
<span style="margin-left: 1em">道不見浮靡之事故人知禮節而户有秀民學校既興</span>  
<span style="margin-left: 1em">藝文蔚起獨行懿修遺風可挹凡前志所未及詳者網</span>  
<span style="margin-left: 1em">羅而補綴之亦蒞斯邑者之責也爰集紳士采摭以顧</span>  
<span style="margin-left: 1em">侍講原稿目錄爲詮次旁及碑碣譜乘就正於吳白華</span>  
<span style="margin-left: 1em">稷堂兩先生訂其譌闕復延虞山姚星巖銓部爲之釐</span>  
<span style="margin-left: 1em">定名曰新志凡十五卷<sub class="note-yuan">熊</sub>受任以來欽</span>  
<span style="margin-left: 1em">聖德之漸被遵</span>  
<span style="margin-left: 1em">大憲之指授而喜邑人之朴淳自愧未能於物有濟日</span>  
<span style="margin-left: 1em">懼隕越惟兹編纂仍虞疎漏繼前令而俟來哲俾是邦</span>  
<span style="margin-left: 1em">掌故庶資考鏡之助云爾乾隆五十八年仲秋月知南</span>  
<span style="margin-left: 1em">滙縣事胡志熊撰</span>
