## 崇禎松江府志卷之十二　役法下（役議附）

<span style="margin-left: 3em">役法<sub class="note-yuan">二</sub></span>  
<span style="margin-left: 2em">收兑糧長<sub class="note-yuan">上等役</sub></span>  
<span style="margin-left: 1em">每歲闔府兑軍正耗米淮米衛倉米遼米行糧共該若</span>  
<span style="margin-left: 1em">干石除官甲書册民甲囤户本名田糧常年例應自囤</span>  
<span style="margin-left: 1em">自兑外其各保區啚民户田畝推收不等大約收兑糧</span>  
<span style="margin-left: 1em">長一名約兑漕糧一千二三百石或千石是役也自本</span>  
<span style="margin-left: 1em">年十月至十二月有守候交納之苦每名約僱書算斛</span>  
<span style="margin-left: 1em">手搬運看守人夫數名并借賃倉厫置買蘆蓆木板食</span>  
<span style="margin-left: 1em">用諸費之苦自明年正月至三四月有守候交兑之苦</span>  
<span style="margin-left: 1em">又有旗軍勒掯贈耗横索使用之苦又有頑户插和粞</span>  
<span style="margin-left: 1em">穀水漿米多濕熱在倉蒸黑之苦又有船錢擔錢之苦</span>  
<span style="margin-left: 1em">又有旗軍踢斛淋尖之苦但收支不出本鄉比之北運</span>  
<span style="margin-left: 1em">不同今議官甲田九百畝編充一名囤户慣役有千畝</span>  
<span style="margin-left: 1em">者亦類編充五年之內華亭應編收兑糧長三百名上</span>  
<span style="margin-left: 1em">海應編一百九十名青浦應編二百十五名</span>  
<span style="margin-left: 1em">宣德六年辛亥十一月行在户部定官軍兑運民糧加</span>  
<span style="margin-left: 1em">耗則例先是平江伯陳瑄言江南民運糧赴臨清等倉</span>  
<span style="margin-left: 1em">若與官軍兑運加耗與之民免勞苦得以務農軍亦少</span>  
<span style="margin-left: 1em">有嬴利命侍郎王佐往淮安與瑄等再議以爲可行</span>  
<span style="margin-left: 1em">上復命群臣議至是吏部尚書蹇義等議奏其法寔便</span>  
<span style="margin-left: 1em">軍民加耗之例請每石湖廣八斗江西浙江七斗南直</span>  
<span style="margin-left: 1em">隸六斗北直隸五斗民有運至淮安兑與軍運者止加</span>  
<span style="margin-left: 1em">四斗如有兑運不盡令民運赴原定官倉交納不納兑</span>  
<span style="margin-left: 1em">者聽自運官軍補數不及仍於揚州衛所備倭官軍內</span>  
<span style="margin-left: 1em">摘撥其宣德六年以前軍告漂流運納不足者不爲常</span>  
<span style="margin-left: 1em">例許將粟米黃豆小麥抵斗於通州上倉軍兑民糧請</span>  
<span style="margin-left: 1em">限本年終及次年正月完就出通關不許遷延妨誤農</span>  
<span style="margin-left: 1em">業其路遠衛所就與本都司填給勘合從之</span>  
<span style="margin-left: 2em">嘉靖乙丑御史婁江張公振之救止民運疏</span>  
<span style="margin-left: 2em">據揭報爲黃河水汎淤塞運道妨阻糧船等事議要</span>  
<span style="margin-left: 2em">查照往年河變事例將糧米寄囤就撥各軍看守空</span>  
<span style="margin-left: 2em">船回南修艌仍照舊管運到京但來歲之糧不無顧</span>  
<span style="margin-left: 2em">此失彼權議改折則見今京通二倉畜積無多勢必</span>  
<span style="margin-left: 2em">難行其勢不能不取之民運等因臣歷查接管舊卷</span>  
<span style="margin-left: 2em">往年河變事例如嘉靖十八年三十一年三十二年</span>  
<span style="margin-left: 2em">三十六年不得已而寄囤往往有之惟是民運之說</span>  
<span style="margin-left: 2em">自有運軍以來未聞也漕司何見而一旦倡議及此</span>  
<span style="margin-left: 2em">臣請先陳民運之害而後及其議處之方可乎夫人</span>  
<span style="margin-left: 2em">之情安於其所常爲無故而驟加之以所不能則駭</span>  
<span style="margin-left: 2em">刑驅勢迫而强之從則怨先年民運止於徐淮臨德</span>  
<span style="margin-left: 2em">四倉官軍轉運尚交納稱難弊害百出而議爲官軍</span>  
<span style="margin-left: 2em">水次交兑自成化以後百年相守田野郊邑之民不</span>  
<span style="margin-left: 2em">知運糧爲何事矣一旦責之舍耕鉏操舟楫而涉歷</span>  
<span style="margin-left: 2em">江河險阻風濤洶湧之衝其誰堪之彼有號苦而已</span>  
<span style="margin-left: 2em">耳駭走而已耳有力者則囑托告免轉相攀陷而已</span>  
<span style="margin-left: 2em">耳此其不可行一也萬一迫于官司不得已認役則</span>  
<span style="margin-left: 2em">不得不轉包積年走京光棍私僱横惡長船召募無</span>  
<span style="margin-left: 2em">籍水手欲無侵累賠盜不可得也此其不可行二也</span>  
<span style="margin-left: 2em">有民運則必有官部運裁革冗員之後官既不多數</span>  
<span style="margin-left: 2em">千里遠行欲無常例科索不可得也此其不可行三</span>  
<span style="margin-left: 2em">也旗官交兑下有千百户上有指揮把總然且船抵</span>  
<span style="margin-left: 2em">水次而有頑户不納倉厫無糧較斛議耗交相鬪怒</span>  
<span style="margin-left: 2em">又或勢豪私兑每至米不乾圓潔浄抵京掛欠追賠</span>  
<span style="margin-left: 2em">一田野小民欲與有司較美惡争多寡論遲速得乎</span>  
<span style="margin-left: 2em">其勢不至于數月守待濕爛支吾傾資代應不止也</span>  
<span style="margin-left: 2em">此其不可行四也往時十年一編均徭今則提編加</span>  
<span style="margin-left: 2em">徵不知幾倍矣往時五年一審糧長今則三年一當</span>  
<span style="margin-left: 2em">甚至有年年者矣往時十年一名里役今則一家二</span>  
<span style="margin-left: 2em">三名矣當此困窮雖賑荒蠲賦尚不能救而加此百</span>  
<span style="margin-left: 2em">年未有之役乎此其不可行五也一年開端將來遂</span>  
<span style="margin-left: 2em">爲定制寄囤守凍無歲無之今年凍阻明年兑運孰</span>  
<span style="margin-left: 2em">不以後到之爲利此其不可行六也此臣所謂民運</span>  
<span style="margin-left: 2em">之害斷斷不可行也</span>  
<span style="margin-left: 2em">萬曆庚戌華亭聶公紹昌收兑議　收兑之役不苦</span>  
<span style="margin-left: 2em">於收之難苦于兑之難而其實兑之多費繇于收之</span>  
<span style="margin-left: 2em">不精蓋漕軍見米之不精也多勒贈耗以爲利糧役</span>  
<span style="margin-left: 2em">因兑之多費也益插穢雜以售欺所以一當交兑煩</span>  
<span style="margin-left: 2em">費蝟起有綱司話會有踢斛淋尖有網圈後手使用</span>  
<span style="margin-left: 2em">不可勝記風力官員欲爲民少减贈耗即環擁囂呼</span>  
<span style="margin-left: 2em">張拳犯上而莫誰何其在旗軍則利歸旗甲不過恣</span>  
<span style="margin-left: 2em">一時之浪費及至兑米入船中途浥爛反累運官揭</span>  
<span style="margin-left: 2em">債賠補回衛之日累小軍扣除月糧以抵京債此不</span>  
<span style="margin-left: 2em">平之在軍者也其在糧長諸用不貲常至賣産鬻業</span>  
<span style="margin-left: 2em">盡蕩其家其在國用則軍糧之所交于京通諸倉者</span>  
<span style="margin-left: 2em">皆濫惡不堪積久盡腐而其病又在于國矣然軍之</span>  
<span style="margin-left: 2em">所以得爲民害者又皆繇傍倉奸棍糾引漕軍大開</span>  
<span style="margin-left: 2em">詐局漕軍利奸棍以爲腹心奸棍利漕軍以爲囊槖</span>  
<span style="margin-left: 2em">互相勾引花街鬧市浪擲金錢未及交兑漕軍地頭</span>  
<span style="margin-left: 2em">之費已百孔千瘡專待多勒贈耗以償所用于是倉</span>  
<span style="margin-left: 2em">棍輪情指點曰某某是糧役渠魁一賂此人即爲多</span>  
<span style="margin-left: 2em">耗多用之倡而兑軍之費始騷然煩重而不可以禁</span>  
<span style="margin-left: 2em">止今幸撫按漕臺刻列告示嚴行禁戢若納户米既</span>  
<span style="margin-left: 2em">乾潔不得耗贈之外多勒升合違者一體責治悉遵</span>  
<span style="margin-left: 2em">漕運議單每百止加濕潤米三石五斗或外再加三</span>  
<span style="margin-left: 2em">石五斗而止又嚴申漕規止許一旗一軍到倉交兑</span>  
<span style="margin-left: 2em">其綱司話會踢斛淋尖網圈後手之類一切禁約通</span>  
<span style="margin-left: 2em">完之日即催趲開幫前去如此則漕粟乾潔軍無腐</span>  
<span style="margin-left: 2em">壞累賠之苦漕令嚴肅倉無講兑喧擾之虞　又查</span>  
<span style="margin-left: 2em">得華亭糧米在萬曆十八年間因收成久雨倉米黑</span>  
<span style="margin-left: 2em">爛是年交兑旗軍大鬨辱及官府一切使用從此開</span>  
<span style="margin-left: 2em">端自後逐年增加因以爲例以故四郡之中惟松爲</span>  
<span style="margin-left: 2em">甚即一郡三縣之中而華亭尤甚如南京豹韜龍虎</span>  
<span style="margin-left: 2em">廣洋水軍等衛旗甲食利已非一日且與奸棍素相</span>  
<span style="margin-left: 2em">糾結沿習諸弊頓革甚難今將豹韜等衛凡積年專</span>  
<span style="margin-left: 2em">兑華亭者派兑別府另撥衛所領兑華亭庶可使彼</span>  
<span style="margin-left: 2em">此各遵憲禁自得一槩輕省斯真甦劇役裕軍儲之</span>  
<span style="margin-left: 2em">一大計也</span>  
<span style="margin-left: 2em">萬曆己未華亭章公允儒榜諭　收兑所收之米聽</span>  
<span style="margin-left: 2em">兑漕糧既總代小民之勞復首犯強軍之難蓋自布</span>  
<span style="margin-left: 2em">解而下此役稱苦訪得舊日糧房吏書稱派區保每</span>  
<span style="margin-left: 2em">名索銀五兩隨而到倉收米即有差役紛紛騙詐倉</span>  
<span style="margin-left: 2em">棍蓋斛每石要米一升總甲討報每名索銀一兩糧</span>  
<span style="margin-left: 2em">房書手稱做比簿每名要銀二兩頂區保家每名索</span>  
<span style="margin-left: 2em">銀五錢糧衙書手指稱本官有徵比漕糧之責每名</span>  
<span style="margin-left: 2em">索銀四兩書手一兩外有隨娘大叔之費又得五錢</span>  
<span style="margin-left: 2em">稍若遲延多方尋事非曰多勒贈耗即曰私用大斛</span>  
<span style="margin-left: 2em">至于皂快小甲門子之類尤不可計誅求百出民脂</span>  
<span style="margin-left: 2em">幾何各區荒熟品搭俱本縣親派其收米之後只于</span>  
<span style="margin-left: 2em">初二十六赴縣親遞完欠數並無一差之擾設有朦</span>  
<span style="margin-left: 2em">朧混僉者許收兑即執票赴禀以欺詐坐罪至于比</span>  
<span style="margin-left: 2em">簿一節俱本縣親自吊查總撒相同用印鈐蓋絕無</span>  
<span style="margin-left: 2em">那移毋聽積書愚弄也若收兑既省雜費止許加二</span>  
<span style="margin-left: 2em">受贈敢有指稱使費大斛多勒及折乾者與前項人</span>  
<span style="margin-left: 2em">等或經告發或經訪出一體坐罪</span>  
<span style="margin-left: 2em">天啟丁卯撫臺毛公一鷺與總漕止淮運書　伏讀</span>  
<span style="margin-left: 2em">蘇石水公祖條議因漕兑日遲將凍阻各船令各郡</span>  
<span style="margin-left: 2em">邑運米赴淮就近交兑既經部覆功令方新何敢置</span>  
<span style="margin-left: 2em">喙惟是此中士民一聞斯舉皆相顧徬徨争言其極</span>  
<span style="margin-left: 2em">不便者且極言其大可慮者蓋三吳賦額半於天下</span>  
<span style="margin-left: 2em">即以蘇松四郡言之爲漕糧計正耗百五十三萬石</span>  
<span style="margin-left: 2em">爲運船計三千艘爲經收糧長計萬餘人今欲民自</span>  
<span style="margin-left: 2em">僱船運淮交兑無論此中輕舠小艇既不堪重載且</span>  
<span style="margin-left: 2em">不便出江即吳地經商者亦皆從浙河外江僱船非</span>  
<span style="margin-left: 2em">若江廣淮揚諸處商舶雲集可呼之立至也無論民</span>  
<span style="margin-left: 2em">力已殫無貲覓船即有貲而無船將安用之此不便</span>  
<span style="margin-left: 2em">在僱船也此中糧多則糧長更多年來十役九廢除</span>  
<span style="margin-left: 2em">官大户外率多零星小户在途盤剥未免疎失寄頓</span>  
<span style="margin-left: 2em">漫藏更虞火盗一官之耳目有限各船之照料難周</span>  
<span style="margin-left: 2em">此不便在押運也軍彊民弱從來皆然向在水次交</span>  
<span style="margin-left: 2em">兑有道府彈壓守令講戢尚時有凌譟之端若迫之</span>  
<span style="margin-left: 2em">遠涉何異赴湯蹈火且令與悍軍講兑不啻如羊見</span>  
<span style="margin-left: 2em">虎逃亡勢所必至此不便在交兑也糧長不獨辦漕</span>  
<span style="margin-left: 2em">糧一項折色亦屬催辦有如以本色遠涉將折色白</span>  
<span style="margin-left: 2em">銀屬之何人是本色未必速而折色愈加緩况兑糧</span>  
<span style="margin-left: 2em">正農事匆忙之時奪其農時必至抛荒田地春不耕</span>  
<span style="margin-left: 2em">秋何望且將爲來歲之漕慮矣此不便在催徵也每</span>  
<span style="margin-left: 2em">石减耗一斗在運軍似亦費米若干石然此一斗之</span>  
<span style="margin-left: 2em">耗軍豈甘心短少稍加抑勒便足取償且各糧長盤</span>  
<span style="margin-left: 2em">剥虧折費必數倍勢必復派里甲當此皮骨空存之</span>  
<span style="margin-left: 2em">日誰堪叠役誰甘重徵互相規避輾轉遲延此不便</span>  
<span style="margin-left: 2em">在科派也各省修船彙集淮上或船到而匠役缺乏</span>  
<span style="margin-left: 2em">或船多而材料未充或米到而船未修或船修而米</span>  
<span style="margin-left: 2em">不至凍阻之餘益增其守候之苦况以一衣帶之水</span>  
<span style="margin-left: 2em">屯數千百之船争先競後擾攘擠軋欲速而反得遲</span>  
<span style="margin-left: 2em">此不便在修船也至遠近船隻見漕事需船急於星</span>  
<span style="margin-left: 2em">火誰肯操舟就索勢必裹足遠匿將鈔關之額課必</span>  
<span style="margin-left: 2em">虧又常鎮去歲困於旱蝗有如客船不到米價必至</span>  
<span style="margin-left: 2em">騰貴恐搶攘衝決事出意外而况目今　三王之國</span>  
<span style="margin-left: 2em">凡公私衡隻皆取資於裝運萬一凍阻之船既以封</span>  
<span style="margin-left: 2em">阻而不至商販之船又以懼禍而不前則數十萬漕</span>

<span style="margin-left: 2em">猶且不率聞有代之勞而分其過者裹足匿影益以</span>

<span style="margin-left: 2em">米色谿壑是盈如奉驕子若更予之以自便累民以</span>  
<span style="margin-left: 2em">難堪濟變一時階厲後世恐漕法繇此壞矣蘇常鎮</span>  
<span style="margin-left: 2em">州邑臨大河通商舶者有限其餘迂回僻遠港水淺</span>  
<span style="margin-left: 2em">窄與雲間三縣逼近海隅又有泖浦之險運艦而外</span>

<span style="margin-left: 2em">相倚賠費不貲使僱船一人運糧更一人痛癢不關</span>  
<span style="margin-left: 2em">情態錯出毋論薄版輕舟負重致遠洪波懸溜意外</span>  
<span style="margin-left: 2em">生虞甚有不肖奸旗折乾盜賣利其漂沉推諉首事</span>  
<span style="margin-left: 2em">雖竭頂踵不足以殉作事謀始寧得不鰓鰓過計以</span>

<span style="margin-left: 2em">須畢力仔肩法不容寬務兼程必濟救急之方無善</span>

<span style="margin-left: 2em">民皮骨僅存血杖淋漓淚與俱下然不敢愛姑息而</span>  
<span style="margin-left: 2em">後催科定當竭心力以稱上指第僱船代運之事斷</span>  
<span style="margin-left: 2em">難加積羸極困之氓責之無米之炊望其不脛而走</span>  
<span style="margin-left: 2em">一朝反側恐有不可言者職方被催督之檄爲此迂</span>  
<span style="margin-left: 2em">緩之言跡疑自寬念則轉切爲地方乃以利國家惟</span>  
<span style="margin-left: 2em">台臺詳計而審行之</span>  
<span style="margin-left: 2em">崇禎己巳華亭鄭公友玄收兑議　本縣漕兑一十</span>  
<span style="margin-left: 2em">七萬有奇不爲少矣舊例八十區點糧長八十名收</span>  
<span style="margin-left: 2em">納户米與官軍交兑役稱最苦二十年內懲區運私</span>  
<span style="margin-left: 2em">侵逃累之弊始改收兑六十名責令坐倉受納不許</span>  
<span style="margin-left: 2em">在家收費且將闔縣各區糧米從横派收照派押兑</span>

<span style="margin-left: 2em">而派收有費凡衛所幫大軍悍糧長委曲規避凡出</span>  
<span style="margin-left: 2em">兑之先後亦以賄囑而派兑又有費然在門內者一</span>

<span style="margin-left: 2em">得成效大抵蠲除荒區改派軍儲恤孤等則小民不</span>

<span style="margin-left: 2em">官甲餘田起役議　官甲書册詭寄田畝已清十之</span>  
<span style="margin-left: 2em">七八而餘田有倍于囤户惟編役之中須斟酌相宜</span>  
<span style="margin-left: 2em">乃可與久故餘田及五千畝者除二千畝起布解一</span>  
<span style="margin-left: 2em">名餘田至萬畝者除四千畝起布解二名至于南北</span>  
<span style="margin-left: 2em">二運各項差解非民甲諳練慣熟者不能承受請以</span>  
<span style="margin-left: 2em">收銀總催之半糙糧兑軍之大半役官甲餘田可乎</span>  
<span style="margin-left: 2em">何也往時里排催鄉官白銀不惟主人難見如帝管</span>  
<span style="margin-left: 2em">數人亦難見如鬼徙倚侯門吞飢忍凍徒手而返限</span>

<span style="margin-left: 2em">里排之役獨自傾銷交納猶累收銀總催耳今議官</span>
