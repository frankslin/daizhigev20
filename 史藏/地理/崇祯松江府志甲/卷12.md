## 崇祯松江府志卷之十二　役法下（役议附）

<span style="margin-left: 3em">役法<sub class="note-yuan">二</sub></span>  
<span style="margin-left: 2em">收兑粮长<sub class="note-yuan">上等役</sub></span>  
<span style="margin-left: 1em">每岁阖府兑军正耗米淮米卫仓米辽米行粮共该若</span>  
<span style="margin-left: 1em">干石除官甲书册民甲囤户本名田粮常年例应自囤</span>  
<span style="margin-left: 1em">自兑外其各保区啚民户田亩推收不等大约收兑粮</span>  
<span style="margin-left: 1em">长一名约兑漕粮一千二三百石或千石是役也自本</span>  
<span style="margin-left: 1em">年十月至十二月有守候交纳之苦每名约雇书算斛</span>  
<span style="margin-left: 1em">手搬运看守人夫数名并借赁仓厫置买芦席木板食</span>  
<span style="margin-left: 1em">用诸费之苦自明年正月至三四月有守候交兑之苦</span>  
<span style="margin-left: 1em">又有旗军勒掯赠耗横索使用之苦又有顽户插和粞</span>  
<span style="margin-left: 1em">谷水浆米多湿热在仓蒸黑之苦又有船钱担钱之苦</span>  
<span style="margin-left: 1em">又有旗军踢斛淋尖之苦但收支不出本乡比之北运</span>  
<span style="margin-left: 1em">不同今议官甲田九百亩编充一名囤户惯役有千亩</span>  
<span style="margin-left: 1em">者亦类编充五年之内华亭应编收兑粮长三百名上</span>  
<span style="margin-left: 1em">海应编一百九十名青浦应编二百十五名</span>  
<span style="margin-left: 1em">宣德六年辛亥十一月行在户部定官军兑运民粮加</span>  
<span style="margin-left: 1em">耗则例先是平江伯陈瑄言江南民运粮赴临清等仓</span>  
<span style="margin-left: 1em">若与官军兑运加耗与之民免劳苦得以务农军亦少</span>  
<span style="margin-left: 1em">有嬴利命侍郎王佐往淮安与瑄等再议以为可行</span>  
<span style="margin-left: 1em">上复命群臣议至是吏部尚书蹇义等议奏其法寔便</span>  
<span style="margin-left: 1em">军民加耗之例请每石湖广八斗江西浙江七斗南直</span>  
<span style="margin-left: 1em">隶六斗北直隶五斗民有运至淮安兑与军运者止加</span>  
<span style="margin-left: 1em">四斗如有兑运不尽令民运赴原定官仓交纳不纳兑</span>  
<span style="margin-left: 1em">者听自运官军补数不及仍于扬州卫所备倭官军内</span>  
<span style="margin-left: 1em">摘拨其宣德六年以前军告漂流运纳不足者不为常</span>  
<span style="margin-left: 1em">例许将粟米黄豆小麦抵斗于通州上仓军兑民粮请</span>  
<span style="margin-left: 1em">限本年终及次年正月完就出通关不许迁延妨误农</span>  
<span style="margin-left: 1em">业其路远卫所就与本都司填给勘合从之</span>  
<span style="margin-left: 2em">嘉靖乙丑御史娄江张公振之救止民运疏</span>  
<span style="margin-left: 2em">据揭报为黄河水泛淤塞运道妨阻粮船等事议要</span>  
<span style="margin-left: 2em">查照往年河变事例将粮米寄囤就拨各军看守空</span>  
<span style="margin-left: 2em">船回南修艌仍照旧管运到京但来岁之粮不无顾</span>  
<span style="margin-left: 2em">此失彼权议改折则见今京通二仓畜积无多势必</span>  
<span style="margin-left: 2em">难行其势不能不取之民运等因臣历查接管旧卷</span>  
<span style="margin-left: 2em">往年河变事例如嘉靖十八年三十一年三十二年</span>  
<span style="margin-left: 2em">三十六年不得已而寄囤往往有之惟是民运之说</span>  
<span style="margin-left: 2em">自有运军以来未闻也漕司何见而一旦倡议及此</span>  
<span style="margin-left: 2em">臣请先陈民运之害而后及其议处之方可乎夫人</span>  
<span style="margin-left: 2em">之情安于其所常为无故而骤加之以所不能则骇</span>  
<span style="margin-left: 2em">刑驱势迫而强之从则怨先年民运止于徐淮临德</span>  
<span style="margin-left: 2em">四仓官军转运尚交纳称难弊害百出而议为官军</span>  
<span style="margin-left: 2em">水次交兑自成化以后百年相守田野郊邑之民不</span>  
<span style="margin-left: 2em">知运粮为何事矣一旦责之舍耕鉏操舟楫而涉历</span>  
<span style="margin-left: 2em">江河险阻风涛汹涌之冲其谁堪之彼有号苦而已</span>  
<span style="margin-left: 2em">耳骇走而已耳有力者则嘱托告免转相攀陷而已</span>  
<span style="margin-left: 2em">耳此其不可行一也万一迫于官司不得已认役则</span>  
<span style="margin-left: 2em">不得不转包积年走京光棍私雇横恶长船召募无</span>  
<span style="margin-left: 2em">籍水手欲无侵累赔盗不可得也此其不可行二也</span>  
<span style="margin-left: 2em">有民运则必有官部运裁革冗员之后官既不多数</span>  
<span style="margin-left: 2em">千里远行欲无常例科索不可得也此其不可行三</span>  
<span style="margin-left: 2em">也旗官交兑下有千百户上有指挥把总然且船抵</span>  
<span style="margin-left: 2em">水次而有顽户不纳仓厫无粮较斛议耗交相鬪怒</span>  
<span style="margin-left: 2em">又或势豪私兑每至米不乾圆洁浄抵京挂欠追赔</span>  
<span style="margin-left: 2em">一田野小民欲与有司较美恶争多寡论迟速得乎</span>  
<span style="margin-left: 2em">其势不至于数月守待湿烂支吾倾资代应不止也</span>  
<span style="margin-left: 2em">此其不可行四也往时十年一编均徭今则提编加</span>  
<span style="margin-left: 2em">征不知几倍矣往时五年一审粮长今则三年一当</span>  
<span style="margin-left: 2em">甚至有年年者矣往时十年一名里役今则一家二</span>  
<span style="margin-left: 2em">三名矣当此困穷虽赈荒蠲赋尚不能救而加此百</span>  
<span style="margin-left: 2em">年未有之役乎此其不可行五也一年开端将来遂</span>  
<span style="margin-left: 2em">为定制寄囤守冻无岁无之今年冻阻明年兑运孰</span>  
<span style="margin-left: 2em">不以后到之为利此其不可行六也此臣所谓民运</span>  
<span style="margin-left: 2em">之害断断不可行也</span>  
<span style="margin-left: 2em">万历庚戌华亭聂公绍昌收兑议　收兑之役不苦</span>  
<span style="margin-left: 2em">于收之难苦于兑之难而其实兑之多费繇于收之</span>  
<span style="margin-left: 2em">不精盖漕军见米之不精也多勒赠耗以为利粮役</span>  
<span style="margin-left: 2em">因兑之多费也益插秽杂以售欺所以一当交兑烦</span>  
<span style="margin-left: 2em">费猬起有纲司话会有踢斛淋尖有网圈后手使用</span>  
<span style="margin-left: 2em">不可胜记风力官员欲为民少减赠耗即环拥嚣呼</span>  
<span style="margin-left: 2em">张拳犯上而莫谁何其在旗军则利归旗甲不过恣</span>  
<span style="margin-left: 2em">一时之浪费及至兑米入船中途浥烂反累运官揭</span>  
<span style="margin-left: 2em">债赔补回卫之日累小军扣除月粮以抵京债此不</span>  
<span style="margin-left: 2em">平之在军者也其在粮长诸用不赀常至卖产鬻业</span>  
<span style="margin-left: 2em">尽荡其家其在国用则军粮之所交于京通诸仓者</span>  
<span style="margin-left: 2em">皆滥恶不堪积久尽腐而其病又在于国矣然军之</span>  
<span style="margin-left: 2em">所以得为民害者又皆繇傍仓奸棍纠引漕军大开</span>  
<span style="margin-left: 2em">诈局漕军利奸棍以为腹心奸棍利漕军以为囊槖</span>  
<span style="margin-left: 2em">互相勾引花街闹市浪掷金钱未及交兑漕军地头</span>  
<span style="margin-left: 2em">之费已百孔千疮专待多勒赠耗以偿所用于是仓</span>  
<span style="margin-left: 2em">棍轮情指点曰某某是粮役渠魁一赂此人即为多</span>  
<span style="margin-left: 2em">耗多用之倡而兑军之费始骚然烦重而不可以禁</span>  
<span style="margin-left: 2em">止今幸抚按漕台刻列告示严行禁戢若纳户米既</span>  
<span style="margin-left: 2em">乾洁不得耗赠之外多勒升合违者一体责治悉遵</span>  
<span style="margin-left: 2em">漕运议单每百止加湿润米三石五斗或外再加三</span>  
<span style="margin-left: 2em">石五斗而止又严申漕规止许一旗一军到仓交兑</span>  
<span style="margin-left: 2em">其纲司话会踢斛淋尖网圈后手之类一切禁约通</span>  
<span style="margin-left: 2em">完之日即催趱开帮前去如此则漕粟乾洁军无腐</span>  
<span style="margin-left: 2em">坏累赔之苦漕令严肃仓无讲兑喧扰之虞　又查</span>  
<span style="margin-left: 2em">得华亭粮米在万历十八年间因收成久雨仓米黑</span>  
<span style="margin-left: 2em">烂是年交兑旗军大哄辱及官府一切使用从此开</span>  
<span style="margin-left: 2em">端自后逐年增加因以为例以故四郡之中惟松为</span>  
<span style="margin-left: 2em">甚即一郡三县之中而华亭尤甚如南京豹韬龙虎</span>  
<span style="margin-left: 2em">广洋水军等卫旗甲食利已非一日且与奸棍素相</span>  
<span style="margin-left: 2em">纠结沿习诸弊顿革甚难今将豹韬等卫凡积年专</span>  
<span style="margin-left: 2em">兑华亭者派兑别府另拨卫所领兑华亭庶可使彼</span>  
<span style="margin-left: 2em">此各遵宪禁自得一槩轻省斯真甦剧役裕军储之</span>  
<span style="margin-left: 2em">一大计也</span>  
<span style="margin-left: 2em">万历己未华亭章公允儒榜谕　收兑所收之米听</span>  
<span style="margin-left: 2em">兑漕粮既总代小民之劳复首犯强军之难盖自布</span>  
<span style="margin-left: 2em">解而下此役称苦访得旧日粮房吏书称派区保每</span>  
<span style="margin-left: 2em">名索银五两随而到仓收米即有差役纷纷骗诈仓</span>  
<span style="margin-left: 2em">棍盖斛每石要米一升总甲讨报每名索银一两粮</span>  
<span style="margin-left: 2em">房书手称做比簿每名要银二两顶区保家每名索</span>  
<span style="margin-left: 2em">银五钱粮衙书手指称本官有征比漕粮之责每名</span>  
<span style="margin-left: 2em">索银四两书手一两外有随娘大叔之费又得五钱</span>  
<span style="margin-left: 2em">稍若迟延多方寻事非曰多勒赠耗即曰私用大斛</span>  
<span style="margin-left: 2em">至于皂快小甲门子之类尤不可计诛求百出民脂</span>  
<span style="margin-left: 2em">几何各区荒熟品搭俱本县亲派其收米之后只于</span>  
<span style="margin-left: 2em">初二十六赴县亲递完欠数并无一差之扰设有朦</span>  
<span style="margin-left: 2em">胧混佥者许收兑即执票赴禀以欺诈坐罪至于比</span>  
<span style="margin-left: 2em">簿一节俱本县亲自吊查总撒相同用印钤盖绝无</span>  
<span style="margin-left: 2em">那移毋听积书愚弄也若收兑既省杂费止许加二</span>  
<span style="margin-left: 2em">受赠敢有指称使费大斛多勒及折乾者与前项人</span>  
<span style="margin-left: 2em">等或经告发或经访出一体坐罪</span>  
<span style="margin-left: 2em">天启丁卯抚台毛公一鹭与总漕止淮运书　伏读</span>  
<span style="margin-left: 2em">苏石水公祖条议因漕兑日迟将冻阻各船令各郡</span>  
<span style="margin-left: 2em">邑运米赴淮就近交兑既经部覆功令方新何敢置</span>  
<span style="margin-left: 2em">喙惟是此中士民一闻斯举皆相顾徬徨争言其极</span>  
<span style="margin-left: 2em">不便者且极言其大可虑者盖三吴赋额半于天下</span>  
<span style="margin-left: 2em">即以苏松四郡言之为漕粮计正耗百五十三万石</span>  
<span style="margin-left: 2em">为运船计三千艘为经收粮长计万余人今欲民自</span>  
<span style="margin-left: 2em">雇船运淮交兑无论此中轻舠小艇既不堪重载且</span>  
<span style="margin-left: 2em">不便出江即吴地经商者亦皆从浙河外江雇船非</span>  
<span style="margin-left: 2em">若江广淮扬诸处商舶云集可呼之立至也无论民</span>  
<span style="margin-left: 2em">力已殚无赀觅船即有赀而无船将安用之此不便</span>  
<span style="margin-left: 2em">在雇船也此中粮多则粮长更多年来十役九废除</span>  
<span style="margin-left: 2em">官大户外率多零星小户在途盘剥未免疎失寄顿</span>  
<span style="margin-left: 2em">漫藏更虞火盗一官之耳目有限各船之照料难周</span>  
<span style="margin-left: 2em">此不便在押运也军彊民弱从来皆然向在水次交</span>  
<span style="margin-left: 2em">兑有道府弹压守令讲戢尚时有凌噪之端若迫之</span>  
<span style="margin-left: 2em">远涉何异赴汤蹈火且令与悍军讲兑不啻如羊见</span>  
<span style="margin-left: 2em">虎逃亡势所必至此不便在交兑也粮长不独办漕</span>  
<span style="margin-left: 2em">粮一项折色亦属催办有如以本色远涉将折色白</span>  
<span style="margin-left: 2em">银属之何人是本色未必速而折色愈加缓况兑粮</span>  
<span style="margin-left: 2em">正农事匆忙之时夺其农时必至抛荒田地春不耕</span>  
<span style="margin-left: 2em">秋何望且将为来岁之漕虑矣此不便在催征也每</span>  
<span style="margin-left: 2em">石减耗一斗在运军似亦费米若干石然此一斗之</span>  
<span style="margin-left: 2em">耗军岂甘心短少稍加抑勒便足取偿且各粮长盘</span>  
<span style="margin-left: 2em">剥亏折费必数倍势必复派里甲当此皮骨空存之</span>  
<span style="margin-left: 2em">日谁堪叠役谁甘重征互相规避辗转迟延此不便</span>  
<span style="margin-left: 2em">在科派也各省修船汇集淮上或船到而匠役缺乏</span>  
<span style="margin-left: 2em">或船多而材料未充或米到而船未修或船修而米</span>  
<span style="margin-left: 2em">不至冻阻之余益增其守候之苦况以一衣带之水</span>  
<span style="margin-left: 2em">屯数千百之船争先竞后扰攘挤轧欲速而反得迟</span>  
<span style="margin-left: 2em">此不便在修船也至远近船只见漕事需船急于星</span>  
<span style="margin-left: 2em">火谁肯操舟就索势必裹足远匿将钞关之额课必</span>  
<span style="margin-left: 2em">亏又常镇去岁困于旱蝗有如客船不到米价必至</span>  
<span style="margin-left: 2em">腾贵恐抢攘冲决事出意外而况目今　三王之国</span>  
<span style="margin-left: 2em">凡公私衡只皆取资于装运万一冻阻之船既以封</span>  
<span style="margin-left: 2em">阻而不至商贩之船又以惧祸而不前则数十万漕</span>  
<span style="margin-left: 2em">粮岂能无胫而走凡此不便窽系似在漕粮之外病</span>  
<span style="margin-left: 2em">痛俱在漕粮之内政今日漕事切肤隐忧也鹭愚无</span>  
<span style="margin-left: 2em">似细详部覆与苏公祖原议虽不过以尾帮冻阻为</span>  
<span style="margin-left: 2em">言似非关全漕干系然闻去岁冻阻颇多关系甚大</span>  
<span style="margin-left: 2em">而三吴事体又与各省事体不同缘此中赋繁役重</span>

<span style="margin-left: 2em">官甲余田起役议　官甲书册诡寄田亩已清十之</span>

<span style="margin-left: 2em">名余田至万亩者除四千亩起布解二名至于南北</span>
