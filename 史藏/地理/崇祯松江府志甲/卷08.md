## 崇祯松江府志卷之八　赋额上

<span style="margin-left: 3em">田赋一</span>  
<span style="margin-left: 1em">国朝赋额</span>  
<span style="margin-left: 1em">松江财赋之乡田下下而赋上上近者军兴不息而国</span>  
<span style="margin-left: 1em">计单虚非特小民枵腹攒眉即上官催征之时亦且含</span>  
<span style="margin-left: 1em">涕敲朴而不欲正视之矣此岂得已而不已哉余为是</span>  
<span style="margin-left: 1em">独详赋额而先之以八故终之两大害此赋之大纲骨</span>  
<span style="margin-left: 1em">也后之吏兹土者幸赐详览焉</span>  
<span style="margin-left: 3em">查官田民田粮重之故</span>  
<span style="margin-left: 1em">太祖高皇帝受命之初收天下田税每亩起科止三升</span>  
<span style="margin-left: 1em">五升有三合五合反轻于古昔井田之税此之谓民田</span>  
<span style="margin-left: 1em">国初有因兵燹后遗下土田无主者有籍没张士诚者</span>  
<span style="margin-left: 1em">有籍没土豪虐民得罪者此之谓官田查得弘治十五</span>  
<span style="margin-left: 1em">年松江府民田止七十三万二十八亩官田有三百九</span>  
<span style="margin-left: 1em">十八万五千六百亩则官田不更多于民田乎召民耕</span>  
<span style="margin-left: 1em">种输租于官此租额非赋额也小民送纳各仓远涉江</span>  
<span style="margin-left: 1em">湖极其烦苦以致累年拖欠逃徙抛荒乃复转卖官田</span>  
<span style="margin-left: 1em">于民间又将官田租额摊作民田粮额虽有上中下三</span>  
<span style="margin-left: 1em">乡之别而总之赋极重不可反矣松郡粮重始于此</span>  
<span style="margin-left: 3em">查力差银差听差之故</span>  
<span style="margin-left: 1em">太祖洪武元年定法每田一顷出丁夫一人三年置直</span>  
<span style="margin-left: 1em">隶应天均工夫图册每岁农隙其夫赴京供役每岁率</span>  
<span style="margin-left: 1em">用三十日遣归田多丁少者以佃人充夫其佃户出米</span>  
<span style="margin-left: 1em">一石资其费用非佃人而计亩出夫者其资费每田一</span>  
<span style="margin-left: 1em">亩出米二升五合他如府州县杂差亦如之其后分力</span>  
<span style="margin-left: 1em">差银差听差三项系力差者计其代当工食之费量为</span>  
<span style="margin-left: 1em">增减系银差者计其扛解交纳之费加以赠耗又其后</span>  
<span style="margin-left: 1em">派银雇役力差变为银差而听差并罢之矣初弘治元</span>  
<span style="margin-left: 1em">年令各处编审均徭但于均徭人户丁粮有力之家止</span>  
<span style="margin-left: 1em">编本等差役不许分外加增若贫难下户逃亡绝户听</span>  
<span style="margin-left: 1em">其空闲不许征银及额外滥设听差等项违者听抚按</span>  
<span style="margin-left: 1em">等官纠察问罪此力差听差银差之所自始</span>  
<span style="margin-left: 3em">查丝绵折绢之故</span>  
<span style="margin-left: 1em">吾松徧栽花稻不种桑不养蚕而岁赋农桑丝绵折绢</span>  
<span style="margin-left: 1em">若干载在夏税额中松民既有细布粗布之解京又有</span>  
<span style="margin-left: 1em">内号外号之织造则丝绵折绢一项似乎可以奏蠲也</span>  
<span style="margin-left: 1em">查得金时之田制凡民户以多植桑枣为勤少者必种</span>  
<span style="margin-left: 1em">其地十之三又少者必种其地十之一除枯补新使之</span>  
<span style="margin-left: 1em">不缺元太宗丙申年始行丝科之法每二户出丝一斤</span>  
<span style="margin-left: 1em">并随路丝线颜色输于官五户出丝一斤并随路丝线</span>  
<span style="margin-left: 1em">颜色输于本位此金元之遗制而相沿犹未改也其有</span>  
<span style="margin-left: 1em">农桑丝绵折绢自此始</span>  
<span style="margin-left: 3em">查马草豆料之故</span>  
<span style="margin-left: 1em">国初光禄寺牺牲所御马监并象马牛羊房等草料俱</span>  
<span style="margin-left: 1em">于民间照田粮科征解纳官军草料亦如之洪武二十</span>  
<span style="margin-left: 1em">五年以百姓供给艰难令北平等处卫所官军不知草</span>  
<span style="margin-left: 1em">束自采野草备用自后遂有秋青草事例宣德以来遂</span>  
<span style="margin-left: 1em">命在京在外军卫有司量派军夫采打置场收纳与民</span>  
<span style="margin-left: 1em">纳草相兼支用而其因时制宜措备支给法亦不一其</span>  
<span style="margin-left: 1em">黄黑豆等料即于税粮内折征不更载此马草之征所</span>  
<span style="margin-left: 1em">自始</span>  
<span style="margin-left: 3em">查一条鞭之故</span>  
<span style="margin-left: 1em">往时夏税秋粮及丁银兵银役银贴役银种种名色不</span>  
<span style="margin-left: 1em">一或分时而征或分额而征上不胜其头绪之碎烦下</span>  
<span style="margin-left: 1em">不胜其追呼之杂沓自嘉靖四十年侍御庞公尚鹏按</span>  
<span style="margin-left: 1em">浙改作一条鞭法最称简便直捷但于平米上分本色</span>  
<span style="margin-left: 1em">米折色银两项里排征之于纳户而县官派之于各色</span>  
<span style="margin-left: 1em">孰是起运孰是存留孰是额设孰是加编孰是宜后宜</span>  
<span style="margin-left: 1em">先孰是宜增宜减孰是朝廷曾赦而犹存如故孰是户</span>  
<span style="margin-left: 1em">漕抚按曾减而犹增如故其算数在县总那移亦在县</span>  
<span style="margin-left: 1em">总而摘发则在精明之县大夫是法行之七八十年矣</span>  
<span style="margin-left: 1em">此一条鞭之所自始</span>  
<span style="margin-left: 3em">查加派从粮不从亩之故</span>  
<span style="margin-left: 1em">隆庆二年巡抚林润奏言江南诸郡久已均粮民颇称</span>  
<span style="margin-left: 1em">便惟松郡未均请乞暂设专官丈之吏部题原任本府</span>  
<span style="margin-left: 1em">同知郑元韶升湖广按察司佥事领勅专管丈田均牵</span>  
<span style="margin-left: 1em">斗则丈得松江三县上乡算平米一石准共田二亩七</span>  
<span style="margin-left: 1em">分三厘九毫中乡平米一石准共田三亩一分二厘五</span>  
<span style="margin-left: 1em">毫下乡平米一石准共田三亩六分三厘凡有不时钱</span>  
<span style="margin-left: 1em">粮加派俱照前周文襄所行则例无分上中下三乡一</span>  
<span style="margin-left: 1em">槩论粮加耗贫富适均官民两便此一定不易之法也</span>  
<span style="margin-left: 1em">若从平米上每石加派则所派轻从田上每亩加派则</span>  
<span style="margin-left: 1em">所派重今辽饷亦宜准此俟辽事平后并原派除之盖</span>  
<span style="margin-left: 1em">粮额之轻重易见而田数之多寡难明耳此加派从粮</span>  
<span style="margin-left: 1em">不从亩之始</span>  
<span style="margin-left: 3em">查钱谷琐碎易眩之故</span>  
<span style="margin-left: 1em">赋额如海见者望洋况米之数则曰升曰合曰勺曰抄</span>  
<span style="margin-left: 1em">曰撮曰圭曰粟曰颗曰粒银之数则曰厘曰毫曰丝曰</span>  
<span style="margin-left: 1em">忽曰微曰纤曰沙曰尘曰埃此项积之无补于丘山而</span>  
<span style="margin-left: 1em">算之甚眯于心目惛惛闷闷得无为骊龙之睡乎龙睡</span>  
<span style="margin-left: 1em">而盗者攫其珠去矣前辈云银至厘而止米至合而止</span>  
<span style="margin-left: 1em">其下悉宜抹除之不然堕入奸人云雾中可恨也此钱</span>  
<span style="margin-left: 1em">谷混淆之所自始</span>  
<span style="margin-left: 3em">查青由之故</span>  
<span style="margin-left: 1em">嘉靖三十七年奏准天下正赋户给青由先开田亩粮</span>  
<span style="margin-left: 1em">石仍分本色金花折银使民周知输纳其一时加派不</span>  
<span style="margin-left: 1em">得混入亦不分官员举监生员吏户人等一例均派令</span>  
<span style="margin-left: 1em">给印信小票与民执照事毕停止此青由之所自始</span>  
<span style="margin-left: 14em">以上陈继儒查</span>  
<span style="margin-left: 3em">田赋加减额数</span>  
<span style="margin-left: 1em">洪武三年庚戌九月户部奏赏军用布其数甚多请令</span>  
<span style="margin-left: 2em">浙西四府秋粮内收布三十万疋　上曰松江乃产</span>  
<span style="margin-left: 2em">布之地止令一府输纳以便其民余征米如故</span>  
<span style="margin-left: 1em">七年甲寅五月　上以苏松嘉湖四府租税太重特令</span>  
<span style="margin-left: 2em">户部计其数如亩税七斗五升者除其半以甦民力</span>  
<span style="margin-left: 1em">十三年庚申三月　上曰民犹树也树利土以生民利</span>  
<span style="margin-left: 2em">食以养民而尽其利犹种树而去土也比年苏松各</span>  
<span style="margin-left: 2em">郡之民困于重租而官不知恤其赋之重者宜悉减</span>  
<span style="margin-left: 2em">之于是旧额田亩科七斗五升至四斗四升者减十</span>  
<span style="margin-left: 2em">之二四斗三升至三斗六升者俱止征三斗五以下</span>  
<span style="margin-left: 2em">仍旧自今年为始升通行改科</span>  
<span style="margin-left: 1em">十七年甲子七月命苏松嘉湖四府以黄金代输今年</span>  
<span style="margin-left: 2em">田租</span>  
<span style="margin-left: 1em">二十二年己巳夏四月朔命杭湖温台苏松诸郡民无</span>  
<span style="margin-left: 2em">田者许令往淮河迤南滁和等处就耕官给钞户三</span>  
<span style="margin-left: 2em">十锭使备农具免其赋役三年</span>  
<span style="margin-left: 1em">二十四年辛未合府定垦官民田地山池涂荡四万七</span>  
<span style="margin-left: 2em">千六百五顷一亩五毫</span>  
<span style="margin-left: 2em">夏税<sub class="note-yuan">大麦九千九百四十五石一斗七升二合小麦一十万一千五百三十四石三斗四升九合丝九千七百八十三两九分九厘绵二千二百二十六两九钱二分八厘钞一万五千五百七十四贯九百一十文九分</sub></span>  
<span style="margin-left: 2em">秋粮<sub class="note-yuan">秔米八十七万八千三百九十七石一升七合糯米一千六百七十六石七斗四升三合赤米三十二万五千五百八石一斗一升七合黄豆九万三千九百一十三石九升六合斑豆九千九百六十六石七斗七升菉豆四十六石五斗四合赤谷九百四十三石三斗八升七合</sub></span>  
<span style="margin-left: 4em">已上洪武时华上二县总数</span>  
<span style="margin-left: 1em">又查户部会计洪武年间原额田土官民共五万一千</span>  
<span style="margin-left: 2em">三百二十顷九十亩</span>  
<span style="margin-left: 2em">夏税<sub class="note-yuan">麦一十万七千四百九十六石绢六百六十六疋</sub></span>  
<span style="margin-left: 2em">秋粮<sub class="note-yuan">米一百一十一万二千四百石钱钞三千七十二锭</sub></span>  
<span style="margin-left: 1em">永乐十年辛卯定垦官民田地山池涂荡四万六千六</span>  
<span style="margin-left: 2em">百一十二顷八十亩八分五厘七丝</span>  
<span style="margin-left: 2em">夏税<sub class="note-yuan">大麦九千八石七十二升九合小麦九万五千九百一石三斗丝九千七百二十四两九钱二分八厘四毫六丝三忽绵二千五百二十两八钱八分钞一万五千五百三十七贯八百文</sub></span>  
<span style="margin-left: 2em">秋粮<sub class="note-yuan">秔米八十二万六千二百三十一石九斗五升七合糯米一千二百六十五石七斗五合赤米二十八万二百七十九石五斗七升六合黄豆八万六千六百九十石五斗三升六合斑豆九千五百三十七石二斗五升六合菉豆三十二石七斗八升五合四勺赤谷八百七十九石六斗七升</sub></span>  
<span style="margin-left: 4em">以上永乐时华上二县总数</span>  
<span style="margin-left: 1em">宣德五年庚戌二月二十一日　勅减本府税粮米麦</span>  
<span style="margin-left: 2em">豆菉共计三十万二千八百八十五石一斗四升二</span>  
<span style="margin-left: 2em">合</span>  
<span style="margin-left: 2em">夏税<sub class="note-yuan">大麦正耗一千四百九十石四斗一升二合小麦正耗一万一千九百七十六石八斗二升六合</sub></span>  
<span style="margin-left: 2em">秋粮<sub class="note-yuan">秔米正耗一十万五千九百九十六石一升六合糯米正耗三百三十一石二斗一升一合赤米正耗六万七千八百三石二斗五升一合黄豆正耗一万三千四百九十二石一斗八升二合斑豆正耗一千六百二十五石二斗二升四合菉豆正耗五石四斗六升四合赤谷正耗一百六十四石五斗四升</sub></span>  
<span style="margin-left: 4em">以上宣德五年华上二县总数</span>  
<span style="margin-left: 1em">勅谕各处旧额官田起科不一租粮既重农民弗胜自</span>  
<span style="margin-left: 2em">今年为始每田一亩旧额纳粮自一斗至四斗者各</span>  
<span style="margin-left: 2em">减十分之二自四斗一升至一石以上者各减十分</span>  
<span style="margin-left: 2em">之三永为定制钦此</span>  
<span style="margin-left: 1em">七年壬子定垦官民田地山池涂荡四万六千八百八</span>  
<span style="margin-left: 2em">十八顷一十九亩六分一厘</span>  
<span style="margin-left: 2em">夏税<sub class="note-yuan">大麦七千六百六石九斗八升八合小麦八万四千四百三十八石四斗四升九合丝九千九百五十四两四钱九分四厘五毫绵二千五百三十两三钱五分四厘钞一万六千九百二十贯六百七十文三分</sub></span>

<span style="margin-left: 4em">以上宣德二年华上二县总数</span>  
<span style="margin-left: 1em">八年癸丑巡抚侍郎周忱　奏定加耗折征例洪武永</span>
