## 崇禎松江府志卷之八　賦額上

<span style="margin-left: 3em">田賦一</span>  
<span style="margin-left: 1em">國朝賦額</span>  
<span style="margin-left: 1em">松江財賦之鄉田下下而賦上上近者軍興不息而國</span>  
<span style="margin-left: 1em">計單虛非特小民枵腹攢眉即上官催征之時亦且含</span>  
<span style="margin-left: 1em">涕敲朴而不欲正視之矣此豈得已而不已哉余爲是</span>  
<span style="margin-left: 1em">獨詳賦額而先之以八故終之兩大害此賦之大綱骨</span>  
<span style="margin-left: 1em">也後之吏兹土者幸賜詳覽焉</span>  
<span style="margin-left: 3em">查官田民田糧重之故</span>  
<span style="margin-left: 1em">太祖高皇帝受命之初收天下田稅每畝起科止三升</span>  
<span style="margin-left: 1em">五升有三合五合反輕於古昔井田之稅此之謂民田</span>  
<span style="margin-left: 1em">國初有因兵燹後遺下土田無主者有籍没張士誠者</span>  
<span style="margin-left: 1em">有籍没土豪虐民得罪者此之謂官田查得弘治十五</span>  
<span style="margin-left: 1em">年松江府民田止七十三萬二十八畝官田有三百九</span>  
<span style="margin-left: 1em">十八萬五千六百畝則官田不更多于民田乎召民耕</span>  
<span style="margin-left: 1em">種輸租于官此租額非賦額也小民送納各倉遠涉江</span>  
<span style="margin-left: 1em">湖極其煩苦以致累年拖欠逃徙抛荒乃復轉賣官田</span>  
<span style="margin-left: 1em">於民間又將官田租額攤作民田糧額雖有上中下三</span>  
<span style="margin-left: 1em">鄉之別而總之賦極重不可反矣松郡糧重始于此</span>  
<span style="margin-left: 3em">查力差銀差聽差之故</span>  
<span style="margin-left: 1em">太祖洪武元年定法每田一頃出丁夫一人三年置直</span>  
<span style="margin-left: 1em">隸應天均工夫圖册每歲農隙其夫赴京供役每歲率</span>  
<span style="margin-left: 1em">用三十日遣歸田多丁少者以佃人充夫其佃户出米</span>  
<span style="margin-left: 1em">一石資其費用非佃人而計畝出夫者其資費每田一</span>  
<span style="margin-left: 1em">畝出米二升五合他如府州縣雜差亦如之其後分力</span>  
<span style="margin-left: 1em">差銀差聽差三項係力差者計其代當工食之費量爲</span>  
<span style="margin-left: 1em">增減係銀差者計其扛解交納之費加以贈耗又其後</span>  
<span style="margin-left: 1em">派銀僱役力差變爲銀差而聽差并罷之矣初弘治元</span>  
<span style="margin-left: 1em">年令各處編審均徭但于均徭人户丁糧有力之家止</span>  
<span style="margin-left: 1em">編本等差役不許分外加增若貧難下户逃亡絕户聽</span>  
<span style="margin-left: 1em">其空閒不許徵銀及額外濫設聽差等項違者聽撫按</span>  
<span style="margin-left: 1em">等官糾察問罪此力差聽差銀差之所自始</span>  
<span style="margin-left: 3em">查絲綿折絹之故</span>  
<span style="margin-left: 1em">吾松徧栽花稻不種桑不養蠶而歲賦農桑絲綿折絹</span>  
<span style="margin-left: 1em">若干載在夏稅額中松民既有細布粗布之解京又有</span>  
<span style="margin-left: 1em">內號外號之織造則絲綿折絹一項似乎可以奏蠲也</span>  
<span style="margin-left: 1em">查得金時之田制凡民户以多植桑棗爲勤少者必種</span>  
<span style="margin-left: 1em">其地十之三又少者必種其地十之一除枯補新使之</span>  
<span style="margin-left: 1em">不缺元太宗丙申年始行絲科之法每二户出絲一斤</span>  
<span style="margin-left: 1em">并隨路絲線顔色輸於官五户出絲一斤并隨路絲線</span>  
<span style="margin-left: 1em">顔色輸於本位此金元之遺制而相沿猶未改也其有</span>  
<span style="margin-left: 1em">農桑絲綿折絹自此始</span>  
<span style="margin-left: 3em">查馬草豆料之故</span>  
<span style="margin-left: 1em">國初光禄寺犧牲所御馬監并象馬牛羊房等草料俱</span>  
<span style="margin-left: 1em">於民間照田糧科徵解納官軍草料亦如之洪武二十</span>  
<span style="margin-left: 1em">五年以百姓供給艱難令北平等處衛所官軍不知草</span>  
<span style="margin-left: 1em">束自采野草備用自後遂有秋青草事例宣德以來遂</span>  
<span style="margin-left: 1em">命在京在外軍衛有司量派軍夫采打置場收納與民</span>  
<span style="margin-left: 1em">納草相兼支用而其因時制宜措備支給法亦不一其</span>  
<span style="margin-left: 1em">黃黑豆等料即于稅糧內折徵不更載此馬草之徵所</span>  
<span style="margin-left: 1em">自始</span>  
<span style="margin-left: 3em">查一條鞭之故</span>  
<span style="margin-left: 1em">往時夏稅秋糧及丁銀兵銀役銀貼役銀種種名色不</span>  
<span style="margin-left: 1em">一或分時而徵或分額而徵上不勝其頭緒之碎煩下</span>  
<span style="margin-left: 1em">不勝其追呼之雜沓自嘉靖四十年侍御龐公尚鵬按</span>  
<span style="margin-left: 1em">浙改作一條鞭法最稱簡便直捷但于平米上分本色</span>  
<span style="margin-left: 1em">米折色銀兩項里排徵之于納户而縣官派之于各色</span>  
<span style="margin-left: 1em">孰是起運孰是存留孰是額設孰是加編孰是宜後宜</span>  
<span style="margin-left: 1em">先孰是宜增宜減孰是朝廷曾赦而猶存如故孰是户</span>  
<span style="margin-left: 1em">漕撫按曾減而猶增如故其算數在縣總那移亦在縣</span>  
<span style="margin-left: 1em">總而摘發則在精明之縣大夫是法行之七八十年矣</span>  
<span style="margin-left: 1em">此一條鞭之所自始</span>  
<span style="margin-left: 3em">查加派從糧不從畝之故</span>  
<span style="margin-left: 1em">隆慶二年巡撫林潤奏言江南諸郡久已均糧民頗稱</span>  
<span style="margin-left: 1em">便惟松郡未均請乞暫設專官丈之吏部題原任本府</span>  
<span style="margin-left: 1em">同知鄭元韶陞湖廣按察司僉事領勅專管丈田均牽</span>  
<span style="margin-left: 1em">斗則丈得松江三縣上鄉算平米一石准共田二畝七</span>  
<span style="margin-left: 1em">分三厘九毫中鄉平米一石准共田三畝一分二厘五</span>  
<span style="margin-left: 1em">毫下鄉平米一石准共田三畝六分三厘凡有不時錢</span>  
<span style="margin-left: 1em">糧加派俱照前周文襄所行則例無分上中下三鄉一</span>  
<span style="margin-left: 1em">槩論糧加耗貧富適均官民兩便此一定不易之法也</span>  
<span style="margin-left: 1em">若從平米上每石加派則所派輕從田上每畝加派則</span>  
<span style="margin-left: 1em">所派重今遼餉亦宜準此俟遼事平後并原派除之蓋</span>  
<span style="margin-left: 1em">糧額之輕重易見而田數之多寡難明耳此加派從糧</span>  
<span style="margin-left: 1em">不從畝之始</span>  
<span style="margin-left: 3em">查錢穀瑣碎易眩之故</span>  
<span style="margin-left: 1em">賦額如海見者望洋况米之數則曰升曰合曰勺曰抄</span>  
<span style="margin-left: 1em">曰撮曰圭曰粟曰顆曰粒銀之數則曰厘曰毫曰絲曰</span>  
<span style="margin-left: 1em">忽曰微曰纖曰沙曰塵曰埃此項積之無補于丘山而</span>  
<span style="margin-left: 1em">算之甚眯于心目惛惛悶悶得無爲驪龍之睡乎龍睡</span>  
<span style="margin-left: 1em">而盗者攫其珠去矣前輩云銀至厘而止米至合而止</span>  
<span style="margin-left: 1em">其下悉宜抹除之不然墮入奸人雲霧中可恨也此錢</span>  
<span style="margin-left: 1em">穀混淆之所自始</span>  
<span style="margin-left: 3em">查青由之故</span>  
<span style="margin-left: 1em">嘉靖三十七年奏准天下正賦户給青由先開田畝糧</span>  
<span style="margin-left: 1em">石仍分本色金花折銀使民周知輸納其一時加派不</span>  
<span style="margin-left: 1em">得混入亦不分官員舉監生員吏户人等一例均派令</span>  
<span style="margin-left: 1em">給印信小票與民執照事畢停止此青由之所自始</span>  
<span style="margin-left: 14em">以上陳繼儒查</span>  
<span style="margin-left: 3em">田賦加減額數</span>  
<span style="margin-left: 1em">洪武三年庚戌九月户部奏賞軍用布其數甚多請令</span>  
<span style="margin-left: 2em">浙西四府秋糧內收布三十萬疋　上曰松江乃産</span>  
<span style="margin-left: 2em">布之地止令一府輸納以便其民餘徵米如故</span>  
<span style="margin-left: 1em">七年甲寅五月　上以蘇松嘉湖四府租稅太重特令</span>  
<span style="margin-left: 2em">户部計其數如畝稅七斗五升者除其半以甦民力</span>  
<span style="margin-left: 1em">十三年庚申三月　上曰民猶樹也樹利土以生民利</span>  
<span style="margin-left: 2em">食以養民而盡其利猶種樹而去土也比年蘇松各</span>  
<span style="margin-left: 2em">郡之民困于重租而官不知恤其賦之重者宜悉減</span>  
<span style="margin-left: 2em">之於是舊額田畝科七斗五升至四斗四升者減十</span>  
<span style="margin-left: 2em">之二四斗三升至三斗六升者俱止徵三斗五以下</span>  
<span style="margin-left: 2em">仍舊自今年爲始升通行改科</span>  
<span style="margin-left: 1em">十七年甲子七月命蘇松嘉湖四府以黃金代輸今年</span>  
<span style="margin-left: 2em">田租</span>  
<span style="margin-left: 1em">二十二年己巳夏四月朔命杭湖温台蘇松諸郡民無</span>  
<span style="margin-left: 2em">田者許令往淮河迤南滁和等處就耕官給鈔户三</span>  
<span style="margin-left: 2em">十錠使備農具免其賦役三年</span>  
<span style="margin-left: 1em">二十四年辛未合府定墾官民田地山池塗蕩四萬七</span>  
<span style="margin-left: 2em">千六百五頃一畝五毫</span>  
<span style="margin-left: 2em">夏稅<sub class="note-yuan">大麥九千九百四十五石一斗七升二合小麥一十萬一千五百三十四石三斗四升九合絲九千七百八十三兩九分九厘綿二千二百二十六兩九錢二分八厘鈔一萬五千五百七十四貫九百一十文九分</sub></span>  
<span style="margin-left: 2em">秋糧<sub class="note-yuan">秔米八十七萬八千三百九十七石一升七合糯米一千六百七十六石七斗四升三合赤米三十二萬五千五百八石一斗一升七合黃豆九萬三千九百一十三石九升六合斑豆九千九百六十六石七斗七升菉豆四十六石五斗四合赤穀九百四十三石三斗八升七合</sub></span>  
<span style="margin-left: 4em">已上洪武時華上二縣總數</span>  
<span style="margin-left: 1em">又查户部會計洪武年間原額田土官民共五萬一千</span>  
<span style="margin-left: 2em">三百二十頃九十畝</span>  
<span style="margin-left: 2em">夏稅<sub class="note-yuan">麥一十萬七千四百九十六石絹六百六十六疋</sub></span>  
<span style="margin-left: 2em">秋糧<sub class="note-yuan">米一百一十一萬二千四百石錢鈔三千七十二錠</sub></span>  
<span style="margin-left: 1em">永樂十年辛卯定墾官民田地山池塗蕩四萬六千六</span>  
<span style="margin-left: 2em">百一十二頃八十畝八分五厘七絲</span>  
<span style="margin-left: 2em">夏稅<sub class="note-yuan">大麥九千八石七十二升九合小麥九萬五千九百一石三斗絲九千七百二十四兩九錢二分八厘四毫六絲三忽綿二千五百二十兩八錢八分鈔一萬五千五百三十七貫八百文</sub></span>  
<span style="margin-left: 2em">秋糧<sub class="note-yuan">秔米八十二萬六千二百三十一石九斗五升七合糯米一千二百六十五石七斗五合赤米二十八萬二百七十九石五斗七升六合黃豆八萬六千六百九十石五斗三升六合斑豆九千五百三十七石二斗五升六合菉豆三十二石七斗八升五合四勺赤穀八百七十九石六斗七升</sub></span>  
<span style="margin-left: 4em">以上永樂時華上二縣總數</span>  
<span style="margin-left: 1em">宣德五年庚戌二月二十一日　勅減本府稅糧米麥</span>  
<span style="margin-left: 2em">豆菉共計三十萬二千八百八十五石一斗四升二</span>  
<span style="margin-left: 2em">合</span>  
<span style="margin-left: 2em">夏稅<sub class="note-yuan">大麥正耗一千四百九十石四斗一升二合小麥正耗一萬一千九百七十六石八斗二升六合</sub></span>  
<span style="margin-left: 2em">秋糧<sub class="note-yuan">秔米正耗一十萬五千九百九十六石一升六合糯米正耗三百三十一石二斗一升一合赤米正耗六萬七千八百三石二斗五升一合黃豆正耗一萬三千四百九十二石一斗八升二合斑豆正耗一千六百二十五石二斗二升四合菉豆正耗五石四斗六升四合赤穀正耗一百六十四石五斗四升</sub></span>  
<span style="margin-left: 4em">以上宣德五年華上二縣總數</span>  
<span style="margin-left: 1em">勅諭各處舊額官田起科不一租糧既重農民弗勝自</span>  
<span style="margin-left: 2em">今年爲始每田一畝舊額納糧自一斗至四斗者各</span>  
<span style="margin-left: 2em">减十分之二自四斗一升至一石以上者各减十分</span>  
<span style="margin-left: 2em">之三永爲定制欽此</span>  
<span style="margin-left: 1em">七年壬子定墾官民田地山池塗蕩四萬六千八百八</span>  
<span style="margin-left: 2em">十八頃一十九畝六分一厘</span>  
<span style="margin-left: 2em">夏稅<sub class="note-yuan">大麥七千六百六石九斗八升八合小麥八萬四千四百三十八石四斗四升九合絲九千九百五十四兩四錢九分四厘五毫綿二千五百三十兩三錢五分四厘鈔一萬六千九百二十貫六百七十文三分</sub></span>  
<span style="margin-left: 2em">秋糧<sub class="note-yuan">秔米六十三萬六千七百一石一斗七升九合糯米九百三十四石四斗九升四合赤米二十二萬七千五百八十八石九斗五升三合黃豆七萬三千一百二石三升四合斑豆七千九百四十一石五斗六升九合菉豆二十七石三斗二升一合赤穀七百一十五石一斗二升一合</sub></span>  
<span style="margin-left: 4em">以上宣德二年華上二縣總數</span>  
<span style="margin-left: 1em">八年癸丑巡撫侍郎周忱　奏定加耗折徵例洪武永</span>  
<span style="margin-left: 2em">樂中稅糧額重積欠數多<sub class="note-yuan">五年定撥起運米四十三萬九千實納止六萬六千有奇</sub>每正糧一石徵平米至二石而猶不足忱至盡祛</span>
