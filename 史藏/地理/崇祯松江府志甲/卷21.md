## 崇祯松江府志卷之二十一　官署上

<span style="margin-left: 3em">官署上<sub class="note-jiao">校：上字當脫據目錄補</sub></span>  
<span style="margin-left: 1em">叔孙虽一日必葺馆而后行第五伦虽一宿必扫地而</span>  
<span style="margin-left: 1em">后去诸葛井灶谢玄履屐自古大豪杰之作用正妙在</span>  
<span style="margin-left: 1em">微细处不渗漏耳而况官署乎一人向隅当有闭阁之</span>  
<span style="margin-left: 1em">思四郊多垒不无垂堂之惧彻户牖以桑土严屋漏于</span>  
<span style="margin-left: 1em">鬼神皆官署中大人事也不敢传舍官署者还从不传</span>  
<span style="margin-left: 1em">舍其官始</span>  
<span style="margin-left: 1em">郡有署郡伯听政之所也前临官衢后枕流水宅中而</span>  
<span style="margin-left: 1em">居之以明尊也堂之左个为李厅东北为经司右为永</span>  
<span style="margin-left: 1em">丰库西北为照磨所翼以两庑居群吏而莅事焉堂下</span>  
<span style="margin-left: 1em">有甬甬有亭以覆戒石其前六枨者仪门也又前有楼</span>  
<span style="margin-left: 1em">巍然者丽谯也序其堂之东西者为丞为别驾为李官</span>  
<span style="margin-left: 1em">分治之署又其下为架阁库为銮驾库为幕僚之居门</span>  
<span style="margin-left: 1em">左右为土神祠为寅宾馆列于丽谯之东西偏者为申</span>  
<span style="margin-left: 1em">明旌善二亭即赵宋以来华亭县故治也元初立府以</span>  
<span style="margin-left: 1em">为府治越十七年郡守张公之翰始撤新之自为记大</span>  
<span style="margin-left: 1em">德癸丑嗣政周公维惠迁丽谯于外作仪门及后寝重</span>  
<span style="margin-left: 1em">纪至元庚辰守杨伯野台展堂庑而大之至正间达鲁</span>  
<span style="margin-left: 1em">花赤哈只作中寝嗣政哈散沙揭一联于座右曰食淡</span>  
<span style="margin-left: 1em">精神爽官清梦寐安盖历阳张即之书九华程熹字华</span>  
<span style="margin-left: 1em">亭时刻也己丑谯楼毁王公至和纠工复建焉国初自</span>  
<span style="margin-left: 1em">王立中归附署制一因元旧建佐贰以下宅陈公宁也</span>  
<span style="margin-left: 1em">建中堂展两庑及新佐僚廨宇黄公子威也重修后堂</span>  
<span style="margin-left: 1em">及两庑赵公豫也改建厅事李公惠也始置刻漏及画</span>  
<span style="margin-left: 1em">角于谯楼凡门以内之制悉备王公衡也丽谯前压民</span>  
<span style="margin-left: 1em">居出官镪易隙地新之增榫榜廊路而南迁旌善申明</span>  
<span style="margin-left: 1em">二亭于左右迁旧福民坊于亭间易以今名刘公琬也</span>  
<span style="margin-left: 1em">规模弘敞始为浙西雄郡矣树门坊建吏舍令供事使</span>  
<span style="margin-left: 1em">无离次喻公时也重建府治堂史公直臣建宾馆及经</span>  
<span style="margin-left: 1em">司臧公继芳也署通修之颜其堂曰勤政曰和衷宾馆</span>  
<span style="margin-left: 1em">曰亲贤凡门楼及佐贰已下诸廨次第俱新方公廉也</span>  
<span style="margin-left: 1em">修谯楼改建三坊东曰旬宣西曰师帅南曰东南保障</span>  
<span style="margin-left: 1em">再迁二亭于桥南之左右贾公待问也重修府治改建</span>  
<span style="margin-left: 1em">督粮厅许公维新也重修而更颜其堂曰琴鹤门房廨</span>  
<span style="margin-left: 1em">宇皆增丹垩勒题名碑于厅壁建宾月楼于寝室之左</span>  
<span style="margin-left: 1em">张公九德重修谯楼张公光缙先后皆郡守也若夫理</span>  
<span style="margin-left: 1em">刑厅之重建始于黄公洪毘之莅任时徐文贞阶记题</span>  
<span style="margin-left: 1em">名于厅壁筹海堂建于燕公祖召而杨公元裕复修之</span>  
<span style="margin-left: 1em">又建观海楼于仪门内府署之兴革大端如此</span>  
<span style="margin-left: 2em">张之翰公廨记　松江古华亭民物繁伙为天下壮</span>  
<span style="margin-left: 2em">哉县天兵渡江升华亭府寻改松江至元辛卯直隶</span>  
<span style="margin-left: 2em">省郡号虽新县治仍旧越明年之翰由翰林牧是郡</span>  
<span style="margin-left: 2em">与达鲁花赤麻合马广威同知玉渠失不花奉训府</span>  
<span style="margin-left: 2em">判赵德衍承务一意催科奚暇他及又二年偕广威</span>  
<span style="margin-left: 2em">赴省力陈弊病之尤者除荒租等额十余万府中渐</span>  
<span style="margin-left: 2em">廓廓然瓜期将近廨之不修复何待廼就木瓦竹石</span>  
<span style="margin-left: 2em">之所有补短以长代朽以坚易缺以完阙则平买出</span>  
<span style="margin-left: 2em">俸金以酬直远近闻者无不喜至有一二贵室愿为</span>  
<span style="margin-left: 2em">之助或以梁或以米或以工役之费上不侵于官下</span>  
<span style="margin-left: 2em">不及于民始甲午冬仲迄乙未春季四晦朔而厥功</span>  
<span style="margin-left: 2em">成崇数尺之基敞五间而耳以左右屋者厅事也拓</span>  
<span style="margin-left: 2em">数丈之地合两庑而翼以东西楼者吏舍也而又署</span>  
<span style="margin-left: 2em">参佐于乾设架合于巽严狴犴于坤远庖厨于震其</span>  
<span style="margin-left: 2em">规模才十七八翚飞翔舞已与雄藩巨镇相颉颃以</span>  
<span style="margin-left: 2em">今视昔如隔仙凡每庭空吏散倚危栏送落日顾瞻</span>  
<span style="margin-left: 2em">徘徊觉三泖之增明九峰之益峻水吾砚池山吾笔</span>  
<span style="margin-left: 2em">锋发清思祛簿书之昬挥新句解鞭笞之劳呼皮陆</span>  
<span style="margin-left: 2em">于苍烟翠霭中问当时倡酬处亦可为公余之一乐</span>  
<span style="margin-left: 2em">阖郡大贺后广威举酒属之翰记昔叔孙所馆一日</span>  
<span style="margin-left: 2em">必葺陆抗临去缮完城围我辈固不敢望其于视公</span>  
<span style="margin-left: 2em">府如传舍略不加省而去庶无媿元贞元年四月</span>  
<span style="margin-left: 2em">杨维祯重建谯楼记　松江府古华亭县也本嘉兴</span>  
<span style="margin-left: 2em">地宋属嘉兴为壮县入国朝以五万户之上者为州</span>  
<span style="margin-left: 2em">华亭户登七十余万至元十四年遂升华亭为华亭</span>  
<span style="margin-left: 2em">府明年改曰松江府二十九年又割华亭县东北地</span>  
<span style="margin-left: 2em">为上海属邑凡二焉繇是辟府廨崇建谯门与名藩</span>  
<span style="margin-left: 2em">巨镇同一雄大至正六年冬市庐灾延谯楼明年夏</span>  
<span style="margin-left: 2em">淫雨秋大水未遑营造又明年秋达鲁花赤答理麻</span>  
<span style="margin-left: 2em">公来年大有与知府王公至和同知拜住闾泊府判</span>  
<span style="margin-left: 2em">剌马丹推官曹思义佥谓谯楼鼓角以令民废而不</span>  
<span style="margin-left: 2em">治非所以司天时谨民事也盍亟成之遂各捐俸金</span>  
<span style="margin-left: 2em">鸠工聚材以九年四月九日经始阅四月而竣事工</span>  
<span style="margin-left: 2em">以日佣材以时直而僦梓镘争趋商贾售鬻惟恐后</span>  
<span style="margin-left: 2em">若民之营其私室然楼凡四楹其高七十尺视旧有</span>  
<span style="margin-left: 2em">加其下垒甓固密广道轩豁重檐上飞耸出云表风</span>  
<span style="margin-left: 2em">雨旋薄安然若泰山之崇铙鼓讙震如雷出天上落</span>  
<span style="margin-left: 2em">成之日守臣监军宾佐吏士咸集登府榜其颜民父</span>  
<span style="margin-left: 2em">老举欣欣然有喜色而相告曰丽谯之灾非天警也</span>  
<span style="margin-left: 2em">历七十余年而遭逢贤守贰政化更新吾侪小人犹</span>  
<span style="margin-left: 2em">及戴白扶藜以仰瞻壮丽一何幸欤夫重门击柝以</span>  
<span style="margin-left: 2em">待暴客此古者防民之道未闻鼓角之令后世晨暮</span>  
<span style="margin-left: 2em">传相警呼至唐马周始制鼓以代参以挈壶氏之职</span>  
<span style="margin-left: 2em">出人作息皆有恒度奸民敛手以避游徼良民得安</span>  
<span style="margin-left: 2em">厥居而不惊所谓不肃而成不严而治矣昔之观善</span>  
<span style="margin-left: 2em">政者或以更鼓分明而得之谯楼之建固系于政治</span>  
<span style="margin-left: 2em">者如此是宜书以劝来者</span>  
<span style="margin-left: 2em">李年壶漏记略　郡有丽谯以司昼夜设壶漏以验</span>  
<span style="margin-left: 2em">时刻久矣而昼夜百刻之图今所传者为唐司天少</span>  
<span style="margin-left: 2em">监吕才所著其制以百刻分十二时时有八刻二分</span>  
<span style="margin-left: 2em">刻有六十秒其二十四气每一气差一分之半冬至</span>  
<span style="margin-left: 2em">日极短春分而日昼夜半平冬至后行盈夏至后行</span>  
<span style="margin-left: 2em">缩阴阳升降日晷短长之期昭然明著范金为壶注</span>  
<span style="margin-left: 2em">水浮箭以区区之人巧测茫茫之天道时昏时旦脗</span>  
<span style="margin-left: 2em">合无爽盖先民竭心思而有作理以事寓器以治设</span>  
<span style="margin-left: 2em">皆有切于官民之所需而不可忽焉者也松江府谯</span>  
<span style="margin-left: 2em">楼旧有铜壶滴漏设官掌其事矣久而废弛因仍以</span>  
<span style="margin-left: 2em">焚香为验而香有燥湿风有疾徐往往不能悉准以</span>  
<span style="margin-left: 2em">便为安莫知改作成化戊戌稷山王侯以北台各侍</span>  
<span style="margin-left: 2em">御来牧吾郡始至兴利革弊修废举坠以安人神暮</span>  
<span style="margin-left: 2em">夜闻钟鼓知漏过差曰唏时以作事政之所系不小</span>  
<span style="margin-left: 2em">铜壶可后复也乃选耆民之能者授以成规俾即古</span>  
<span style="margin-left: 2em">杭而冶焉不越月以是器献凡为具夜天池二日天</span>  
<span style="margin-left: 2em">池一平壶水壶各一铜人持尺者一定南星影表一</span>  
<span style="margin-left: 2em">水海一添水桶一更筹十二筹架一既严勅所司随</span>  
<span style="margin-left: 2em">时注视复纵民就观三日俾知古作之妙于是缙绅</span>  
<span style="margin-left: 2em">士子老稚黎庶缁黄艺技行旅商贾踊跃扶携莫不</span>  
<span style="margin-left: 2em">交口叹所未覩夫舆杠时成君子谓之知政更漏分</span>  
<span style="margin-left: 2em">明识者审其能官侯能易简易知习为经久之具以</span>  
<span style="margin-left: 2em">利官民之兴作非知政之大体欤是为记</span>  
<span style="margin-left: 1em">华亭县治在府西望云桥北县初升府寓治于旧东尉</span>  
<span style="margin-left: 1em">司至元壬午迁于此日河抱于南月河环于北相传建</span>  
<span style="margin-left: 1em">治时形家言日月夹照官多廉明遂定址焉志称元时</span>  
<span style="margin-left: 1em">簿厅也或由即来翰林修撰李䕫为县尉时生李忠定</span>  
<span style="margin-left: 1em">公纲故处宋政和中华亭今姚公舜明颜中堂为兰芳</span>  
<span style="margin-left: 1em">舜明为令抚民尽敬以元丰元符断狱制书揭之狱乾</span>  
<span style="margin-left: 1em">道八年嗣令陈公岄移置中堂榜曰尽心自为记即治</span>  
<span style="margin-left: 1em">西旧琴堂也后令叶仲英复改名琴堂元祐中令刘公</span>  
<span style="margin-left: 1em">雕于县斋之东建堂曰弦歌亭曰三山阁曰艮阁集致</span>  
<span style="margin-left: 1em">贤士讲论歌咏其间绍兴中陈公祖安为令辟亭为东</span>  
<span style="margin-left: 1em">堂温大著改曰贻牟有鸣琴拂榻此游衍作诗何止夸</span>  
<span style="margin-left: 1em">厘牟句又制锦堂旧令之正寝也绍定间令黄公崖建</span>  
<span style="margin-left: 1em">为退食之所有岁寒雪香宜尔倚骑栽春棹月烟翠露</span>  
<span style="margin-left: 1em">红八亭俾邑人皆得嬉游焉熙宁十年沈辽摄华亭令</span>  
<span style="margin-left: 1em">悬箴于县门曰政之善出于是不善亦出于是斯民何</span>  
<span style="margin-left: 1em">知惟令所置勿谓可欺固亦易制师言不私是乃可畏</span>  
<span style="margin-left: 1em">朝而开焉小大必治逮昏而阖以休吾吏治得其平谓</span>  
<span style="margin-left: 1em">我恺悌有或不然为门之愧自改县为府而宋时名宰</span>  
<span style="margin-left: 1em">所建亭馆尽属于郡署矣至元甲午县尹柴公琳达鲁</span>  
<span style="margin-left: 1em">花赤兀都蛮鼎建榜其厅曰牧爱至元六年门之两庑</span>  
<span style="margin-left: 1em">火张公德昭缮治之虞文靖集曰元时县大门皆画耕</span>  
<span style="margin-left: 1em">织图于两壁盖重农至意也后复毁于兵　国朝以来</span>  
<span style="margin-left: 1em">渐次兴复永乐中复火宣德庚戌吴公大用重建正统</span>  
<span style="margin-left: 1em">戊辰郭公文直又增修之弘治乙丑张公岐建中堂榜</span>  
<span style="margin-left: 1em">曰氷雪嘉靖间聂公豹朱公执中相继修葺颓者整圮</span>  
<span style="margin-left: 1em">者安而熊公剑化以万历甲辰至莅政岁余病其諠杂</span>  
<span style="margin-left: 1em">不肃置木栅于前开左右两门以便出人榜曰敬天威</span>  
<span style="margin-left: 1em">畏民志癸亥春郭公如暗复以讼系诸舍偪处公扅捐</span>  
<span style="margin-left: 1em">俸买地廓大而新之规模宏敞不愧江南壮县矣其县</span>  
<span style="margin-left: 1em">治之制前有门有戒石亭有堂有内库堂之东为典史</span>  
<span style="margin-left: 1em">厅西架阁库两庑为吏书六房堂庑之外为官吏私舍</span>  
<span style="margin-left: 1em">中门之外东为土地祠西为寅宾馆馆前为内监房门</span>  
<span style="margin-left: 1em">外为牓廊东西相向规模大约如府而门内列十柜以</span>  
<span style="margin-left: 1em">司钱谷出纳焉</span>  
<span style="margin-left: 2em">松江府教授马允中新廨记畧　华亭汉故亭留宿</span>  
<span style="margin-left: 2em">会之所唐天寳十年始置县属苏州石晋天福五年</span>  
<span style="margin-left: 2em">分隶秀州为天下壮邑至元丁丑春因升华亭府改</span>  
<span style="margin-left: 2em">名松江即县之公宇为府治寓县治于东尉旧司壬</span>  
<span style="margin-left: 2em">午秋始以昔时主簿廨舍为新县屋才二十余间颓</span>  
<span style="margin-left: 2em">圮狭隘门与厅参差且未有狱禁甲午春达鲁花赤</span>
