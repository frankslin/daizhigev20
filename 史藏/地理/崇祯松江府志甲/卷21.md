## 崇禎松江府志卷之二十一　官署上

<span style="margin-left: 3em">官署上<sub class="note-jiao">校：上字當脫據目錄補</sub></span>  
<span style="margin-left: 1em">叔孫雖一日必葺館而後行第五倫雖一宿必掃地而</span>  
<span style="margin-left: 1em">後去諸葛井竈謝玄履屐自古大豪傑之作用正妙在</span>  
<span style="margin-left: 1em">微細處不滲漏耳而况官署乎一人向隅當有閉閣之</span>  
<span style="margin-left: 1em">思四郊多壘不無垂堂之懼徹户牖以桑土嚴屋漏于</span>  
<span style="margin-left: 1em">鬼神皆官署中大人事也不敢傳舍官署者還從不傳</span>  
<span style="margin-left: 1em">舍其官始</span>  
<span style="margin-left: 1em">郡有署郡伯聽政之所也前臨官衢後枕流水宅中而</span>  
<span style="margin-left: 1em">居之以明尊也堂之左个爲李廳東北爲經司右爲永</span>  
<span style="margin-left: 1em">豐庫西北爲照磨所翼以兩廡居羣吏而蒞事焉堂下</span>  
<span style="margin-left: 1em">有甬甬有亭以覆戒石其前六棖者儀門也又前有樓</span>  
<span style="margin-left: 1em">巍然者麗譙也序其堂之東西者爲丞爲別駕爲李官</span>  
<span style="margin-left: 1em">分治之署又其下爲架閣庫爲鑾駕庫爲幕僚之居門</span>  
<span style="margin-left: 1em">左右爲土神祠爲寅賓館列於麗譙之東西偏者爲申</span>  
<span style="margin-left: 1em">明旌善二亭即趙宋以來華亭縣故治也元初立府以</span>  
<span style="margin-left: 1em">爲府治越十七年郡守張公之翰始撤新之自爲記大</span>  
<span style="margin-left: 1em">德癸丑嗣政周公維惠遷麗譙於外作儀門及後寢重</span>  
<span style="margin-left: 1em">紀至元庚辰守楊伯野台展堂廡而大之至正間達魯</span>  
<span style="margin-left: 1em">花赤哈只作中寢嗣政哈散沙揭一聯于座右曰食淡</span>  
<span style="margin-left: 1em">精神爽官清夢寐安蓋歷陽張即之書九華程熹字華</span>  
<span style="margin-left: 1em">亭時刻也己丑譙樓燬王公至和糾工復建焉國初自</span>  
<span style="margin-left: 1em">王立中歸附署制一因元舊建佐貳以下宅陳公寧也</span>  
<span style="margin-left: 1em">建中堂展兩廡及新佐僚廨宇黃公子威也重修後堂</span>  
<span style="margin-left: 1em">及兩廡趙公豫也改建廳事李公惠也始置刻漏及畫</span>  
<span style="margin-left: 1em">角於譙樓凡門以內之制悉備王公衡也麗譙前壓民</span>  
<span style="margin-left: 1em">居出官鏹易隙地新之增榫榜廊路而南遷旌善申明</span>  
<span style="margin-left: 1em">二亭於左右遷舊福民坊於亭間易以今名劉公琬也</span>  
<span style="margin-left: 1em">規模弘敞始爲浙西雄郡矣樹門坊建吏舍令供事使</span>  
<span style="margin-left: 1em">無離次喻公時也重建府治堂史公直臣建賓館及經</span>  
<span style="margin-left: 1em">司臧公繼芳也署通修之顔其堂曰勤政曰和衷賓館</span>  
<span style="margin-left: 1em">曰親賢凡門樓及佐貳已下諸廨次第俱新方公廉也</span>  
<span style="margin-left: 1em">修譙樓改建三坊東曰旬宣西曰師帥南曰東南保障</span>  
<span style="margin-left: 1em">再遷二亭於橋南之左右賈公待問也重修府治改建</span>  
<span style="margin-left: 1em">督糧廳許公維新也重修而更顔其堂曰琴鶴門房廨</span>  
<span style="margin-left: 1em">宇皆增丹堊勒題名碑於廳壁建賓月樓於寢室之左</span>  
<span style="margin-left: 1em">張公九德重修譙樓張公光縉先後皆郡守也若夫理</span>  
<span style="margin-left: 1em">刑廳之重建始於黃公洪毘之蒞任時徐文貞階記題</span>  
<span style="margin-left: 1em">名於廳壁籌海堂建於燕公祖召而楊公元裕復修之</span>  
<span style="margin-left: 1em">又建觀海樓於儀門內府署之興革大端如此</span>  
<span style="margin-left: 2em">張之翰公廨記　松江古華亭民物繁夥爲天下壯</span>  
<span style="margin-left: 2em">哉縣天兵渡江升華亭府尋改松江至元辛卯直隸</span>  
<span style="margin-left: 2em">省郡號雖新縣治仍舊越明年之翰由翰林牧是郡</span>  
<span style="margin-left: 2em">與達魯花赤麻合馬廣威同知玉渠失不花奉訓府</span>  
<span style="margin-left: 2em">判趙德衍承務一意催科奚暇他及又二年偕廣威</span>  
<span style="margin-left: 2em">赴省力陳弊病之尤者除荒租等額十餘萬府中漸</span>  
<span style="margin-left: 2em">廓廓然瓜期將近廨之不修復何待廼就木瓦竹石</span>  
<span style="margin-left: 2em">之所有補短以長代朽以堅易缺以完闕則平買出</span>  
<span style="margin-left: 2em">俸金以酬直遠近聞者無不喜至有一二貴室願爲</span>  
<span style="margin-left: 2em">之助或以梁或以米或以工役之費上不侵於官下</span>  
<span style="margin-left: 2em">不及於民始甲午冬仲迄乙未春季四晦朔而厥功</span>  
<span style="margin-left: 2em">成崇數尺之基敞五間而耳以左右屋者廳事也拓</span>  
<span style="margin-left: 2em">數丈之地合兩廡而翼以東西樓者吏舍也而又署</span>  
<span style="margin-left: 2em">參佐於乾設架閤於巽嚴狴犴於坤遠庖厨於震其</span>  
<span style="margin-left: 2em">規模纔十七八翬飛翔舞已與雄藩巨鎮相頡頏以</span>  
<span style="margin-left: 2em">今視昔如隔仙凡每庭空吏散倚危欄送落日顧瞻</span>  
<span style="margin-left: 2em">徘徊覺三泖之增明九峯之益峻水吾硯池山吾筆</span>  
<span style="margin-left: 2em">鋒發清思祛簿書之昬揮新句解鞭笞之勞呼皮陸</span>  
<span style="margin-left: 2em">於蒼烟翠靄中問當時倡酬處亦可爲公餘之一樂</span>  
<span style="margin-left: 2em">闔郡大賀後廣威舉酒屬之翰記昔叔孫所館一日</span>  
<span style="margin-left: 2em">必葺陸抗臨去繕完城圍我輩固不敢望其於視公</span>  
<span style="margin-left: 2em">府如傳舍略不加省而去庶無媿元貞元年四月</span>  
<span style="margin-left: 2em">楊維禎重建譙樓記　松江府古華亭縣也本嘉興</span>  
<span style="margin-left: 2em">地宋屬嘉興爲壯縣入國朝以五萬户之上者爲州</span>  
<span style="margin-left: 2em">華亭户登七十餘萬至元十四年遂陞華亭爲華亭</span>  
<span style="margin-left: 2em">府明年改曰松江府二十九年又割華亭縣東北地</span>  
<span style="margin-left: 2em">爲上海屬邑凡二焉繇是闢府廨崇建譙門與名藩</span>  
<span style="margin-left: 2em">巨鎮同一雄大至正六年冬市廬災延譙樓明年夏</span>  
<span style="margin-left: 2em">淫雨秋大水未遑營造又明年秋達魯花赤答理麻</span>  
<span style="margin-left: 2em">公來年大有與知府王公至和同知拜住閭泊府判</span>  
<span style="margin-left: 2em">剌馬丹推官曹思義僉謂譙樓鼓角以令民廢而不</span>  
<span style="margin-left: 2em">治非所以司天時謹民事也盍亟成之遂各捐俸金</span>  
<span style="margin-left: 2em">鳩工聚材以九年四月九日經始閲四月而竣事工</span>  
<span style="margin-left: 2em">以日傭材以時直而僦梓鏝争趨商賈售鬻惟恐後</span>  
<span style="margin-left: 2em">若民之營其私室然樓凡四楹其高七十尺視舊有</span>  
<span style="margin-left: 2em">加其下壘甓固密廣道軒豁重檐上飛聳出雲表風</span>  
<span style="margin-left: 2em">雨旋薄安然若泰山之崇鐃鼓讙震如雷出天上落</span>  
<span style="margin-left: 2em">成之日守臣監軍賓佐吏士咸集登府榜其顔民父</span>  
<span style="margin-left: 2em">老舉欣欣然有喜色而相告曰麗譙之災非天警也</span>  
<span style="margin-left: 2em">歷七十餘年而遭逢賢守貳政化更新吾儕小人猶</span>  
<span style="margin-left: 2em">及戴白扶藜以仰瞻壯麗一何幸歟夫重門擊柝以</span>  
<span style="margin-left: 2em">待暴客此古者防民之道未聞鼓角之令後世晨暮</span>  
<span style="margin-left: 2em">傳相警呼至唐馬周始制鼓以代參以挈壺氏之職</span>  
<span style="margin-left: 2em">出人作息皆有恒度奸民斂手以避遊徼良民得安</span>  
<span style="margin-left: 2em">厥居而不驚所謂不肅而成不嚴而治矣昔之觀善</span>  
<span style="margin-left: 2em">政者或以更鼓分明而得之譙樓之建固係於政治</span>  
<span style="margin-left: 2em">者如此是宜書以勸來者</span>  
<span style="margin-left: 2em">李年壺漏記略　郡有麗譙以司晝夜設壺漏以驗</span>  
<span style="margin-left: 2em">時刻久矣而晝夜百刻之圖今所傳者爲唐司天少</span>  
<span style="margin-left: 2em">監呂才所著其制以百刻分十二時時有八刻二分</span>  
<span style="margin-left: 2em">刻有六十秒其二十四氣每一氣差一分之半冬至</span>  
<span style="margin-left: 2em">日極短春分而日晝夜半平冬至後行盈夏至後行</span>  
<span style="margin-left: 2em">縮陰陽升降日晷短長之期昭然明著範金爲壺注</span>  
<span style="margin-left: 2em">水浮箭以區區之人巧測茫茫之天道時昏時旦脗</span>  
<span style="margin-left: 2em">合無爽蓋先民竭心思而有作理以事寓器以治設</span>  
<span style="margin-left: 2em">皆有切於官民之所需而不可忽焉者也松江府譙</span>  
<span style="margin-left: 2em">樓舊有銅壺滴漏設官掌其事矣久而廢弛因仍以</span>  
<span style="margin-left: 2em">焚香爲驗而香有燥濕風有疾徐往往不能悉準以</span>  
<span style="margin-left: 2em">便爲安莫知改作成化戊戌稷山王侯以北臺各侍</span>  
<span style="margin-left: 2em">御來牧吾郡始至興利革弊修廢舉墜以安人神暮</span>  
<span style="margin-left: 2em">夜聞鐘鼓知漏過差曰唏時以作事政之所係不小</span>  
<span style="margin-left: 2em">銅壺可後復也乃選耆民之能者授以成規俾即古</span>  
<span style="margin-left: 2em">杭而冶焉不越月以是器獻凡爲具夜天池二日天</span>  
<span style="margin-left: 2em">池一平壺水壺各一銅人持尺者一定南星影表一</span>  
<span style="margin-left: 2em">水海一添水桶一更籌十二籌架一既嚴勅所司隨</span>  
<span style="margin-left: 2em">時注視復縱民就觀三日俾知古作之妙於是縉紳</span>  
<span style="margin-left: 2em">士子老稚黎庶緇黃藝技行旅商賈踊躍扶攜莫不</span>  
<span style="margin-left: 2em">交口嘆所未覩夫輿杠時成君子謂之知政更漏分</span>  
<span style="margin-left: 2em">明識者審其能官侯能易簡易知習爲經久之具以</span>  
<span style="margin-left: 2em">利官民之興作非知政之大體歟是爲記</span>  
<span style="margin-left: 1em">華亭縣治在府西望雲橋北縣初陞府寓治於舊東尉</span>  
<span style="margin-left: 1em">司至元壬午遷於此日河抱於南月河環於北相傳建</span>  
<span style="margin-left: 1em">治時形家言日月夾照官多廉明遂定址焉志稱元時</span>  
<span style="margin-left: 1em">簿廳也或由即來翰林修撰李䕫爲縣尉時生李忠定</span>  
<span style="margin-left: 1em">公綱故處宋政和中華亭今姚公舜明顔中堂爲蘭芳</span>  
<span style="margin-left: 1em">舜明爲令撫民盡敬以元豐元符斷獄制書揭之獄乾</span>  
<span style="margin-left: 1em">道八年嗣令陳公岄移置中堂榜曰盡心自爲記即治</span>  
<span style="margin-left: 1em">西舊琴堂也後令葉仲英復改名琴堂元祐中令劉公</span>  
<span style="margin-left: 1em">鵰於縣齋之東建堂曰弦歌亭曰三山閣曰艮閣集致</span>  
<span style="margin-left: 1em">賢士講論歌詠其間紹興中陳公祖安爲令闢亭爲東</span>  
<span style="margin-left: 1em">堂温大著改曰貽牟有鳴琴拂榻此遊衍作詩何止誇</span>  
<span style="margin-left: 1em">釐牟句又製錦堂舊令之正寢也紹定間令黃公崖建</span>  
<span style="margin-left: 1em">爲退食之所有歲寒雪香宜爾倚騎栽春棹月烟翠露</span>  
<span style="margin-left: 1em">紅八亭俾邑人皆得嬉遊焉熙寧十年沈遼攝華亭令</span>  
<span style="margin-left: 1em">懸箴於縣門曰政之善出於是不善亦出於是斯民何</span>  
<span style="margin-left: 1em">知惟令所置勿謂可欺固亦易制師言不私是乃可畏</span>  
<span style="margin-left: 1em">朝而開焉小大必治逮昏而闔以休吾吏治得其平謂</span>  
<span style="margin-left: 1em">我愷悌有或不然爲門之愧自改縣爲府而宋時名宰</span>  
<span style="margin-left: 1em">所建亭館盡屬於郡署矣至元甲午縣尹柴公琳達魯</span>  
<span style="margin-left: 1em">花赤兀都蠻鼎建榜其廳曰牧愛至元六年門之兩廡</span>  
<span style="margin-left: 1em">火張公德昭繕治之虞文靖集曰元時縣大門皆畫耕</span>  
<span style="margin-left: 1em">織圖於兩壁蓋重農至意也後復燬於兵　國朝以來</span>  
<span style="margin-left: 1em">漸次興復永樂中復火宣德庚戌吳公大用重建正統</span>  
<span style="margin-left: 1em">戊辰郭公文直又增修之弘治乙丑張公岐建中堂榜</span>  
<span style="margin-left: 1em">曰氷雪嘉靖間聶公豹朱公執中相繼修葺頽者整圮</span>  
<span style="margin-left: 1em">者安而熊公劍化以萬曆甲辰至蒞政歲餘病其諠雜</span>  
<span style="margin-left: 1em">不肅置木栅於前開左右兩門以便出人榜曰敬天威</span>  
<span style="margin-left: 1em">畏民志癸亥春郭公如闇復以訟係諸舍偪處公扅捐</span>  
<span style="margin-left: 1em">俸買地廓大而新之規模宏敞不愧江南壯縣矣其縣</span>  
<span style="margin-left: 1em">治之制前有門有戒石亭有堂有內庫堂之東爲典史</span>  
<span style="margin-left: 1em">廳西架閣庫兩廡爲吏書六房堂廡之外爲官吏私舍</span>  
<span style="margin-left: 1em">中門之外東爲土地祠西爲寅賓館館前爲內監房門</span>  
<span style="margin-left: 1em">外爲牓廊東西相向規模大約如府而門內列十櫃以</span>  
<span style="margin-left: 1em">司錢穀出納焉</span>  
<span style="margin-left: 2em">松江府教授馬允中新廨記畧　華亭漢故亭留宿</span>  
<span style="margin-left: 2em">會之所唐天寳十年始置縣屬蘇州石晉天福五年</span>  
<span style="margin-left: 2em">分隸秀州爲天下壯邑至元丁丑春因陞華亭府改</span>  
<span style="margin-left: 2em">名松江即縣之公宇爲府治寓縣治于東尉舊司壬</span>  
<span style="margin-left: 2em">午秋始以昔時主簿廨舍爲新縣屋纔二十餘間頽</span>  
<span style="margin-left: 2em">圮狹隘門與廳參差且未有獄禁甲午春達魯花赤</span>  
<span style="margin-left: 2em">兀都蠻承務來監慨然有增修之志爰及縣尹柴琳</span>  
<span style="margin-left: 2em">承務暨同僚佐吏協議悉捐已俸積千一百緡買民</span>  
<span style="margin-left: 2em">地二畝一角三十步創建推廳門軒之間七狴犴之</span>
