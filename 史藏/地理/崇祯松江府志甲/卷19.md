## 崇祯松江府志卷之十九　城池　仓廪　驿逓

<span style="margin-left: 3em">城池</span>  
<span style="margin-left: 1em">易曰王公设险以守其国春秋书城二十五城者盛也</span>  
<span style="margin-left: 1em">所以宅民而御暴也墙止及肩水不没髁金汤云乎哉</span>  
<span style="margin-left: 1em">凡郡城邑城以及沿海要害诸城版筑之畚锸之邻震</span>  
<span style="margin-left: 1em">肤剥庶几有捍乎议者谓城如斗大创议式扩似矣然</span>  
<span style="margin-left: 1em">府库告单闾阎称匮莫若寻前人之遗绪而岁加缮治</span>  
<span style="margin-left: 1em">之堞如飞雉濠类贯虹而后徐及于扩城之役未晚也</span>  
<span style="margin-left: 1em">是标是本以俟老成者采而择焉</span>  
<span style="margin-left: 1em">府城广袤凡九里一百七十三步高二丈四尺濠广十</span>  
<span style="margin-left: 1em">丈深七尺门凡四东曰披云西曰谷阳南曰集僊北曰</span>  
<span style="margin-left: 1em">通波披云集僊以桥通波以塘并知府陈威所题谷阳</span>  
<span style="margin-left: 1em">旧名也水门各附其旁门有楼楼外为月城元末张士</span>  
<span style="margin-left: 1em">诚据吴时筑　国朝因而葺之其地后殿九峰前襟黄</span>  
<span style="margin-left: 1em">浦大海环其东南三江绕乎西北平畴沃野四望极目</span>  
<span style="margin-left: 1em">东南之重地也城之南为吴王猎场场有五茸俗因呼</span>  
<span style="margin-left: 1em">为五茸城云</span>  
<span style="margin-left: 2em"><sub class="note-yuan">国朝章简诗云城郭何年号五茸盘回十里控吴松旌旗晓障芙蓉日鼓角寒生苜蓿风云起北山连雉堞波澄南海息狼烽登高一望民风厚楼阁重重烟雨中</sub></span>  
<span style="margin-left: 2em">海防志云洪武三十年十一月始分金山卫中千户</span>  
<span style="margin-left: 2em">所官军立为松江守御千户所专管守护城池城上</span>  
<span style="margin-left: 2em">敌台二十座窝铺二十六座雉堞三千三百八十九</span>  
<span style="margin-left: 2em">垜</span>  
<span style="margin-left: 2em">嘉靖间岛夷入寇知府方廉捐俸增葺万历二十三</span>  
<span style="margin-left: 2em">年兵部以倭警奉　旨移檄各抚按整理一时工费</span>  
<span style="margin-left: 2em">无措缙绅各照田乐助银六千有奇华亭令王公廷</span>  
<span style="margin-left: 2em">锡设处备用银三千有奇共九千余两给佥点殷实</span>  
<span style="margin-left: 2em">富民分派四门丈尺葺治分工趱役筑未坚牢春雨</span>  
<span style="margin-left: 2em">乘之工方讫而西月城崩陷压死男妇巡抚赵公可</span>  
<span style="margin-left: 2em">怀檄行重加增缮高阔并加五尺外濠深广濬治如</span>  
<span style="margin-left: 2em">制万历三十六年倾于积雨凡塌毁数百丈华亭令</span>  
<span style="margin-left: 2em">聂公绍昌修筑之迩年旋圮不时盖因城中巨室或</span>  
<span style="margin-left: 2em">有兴作从外搬运木石以辘轳升之又或钩致束薪</span>  
<span style="margin-left: 2em">垜砖狼籍守城官军玩为故常又避不敢上闻崇祯</span>  
<span style="margin-left: 2em">三年郡守方公岳贡躬行相视委官修废补坏增高</span>  
<span style="margin-left: 2em">城堞修建窝铺敌台肃毖军兵防宿编号分明递筹</span>  
<span style="margin-left: 2em">击柝内外始知有严城之守矣城楼四座整顿一新</span>  
<span style="margin-left: 2em">东曰迎生西曰宝成南曰阜民北曰拱宸皆董宗伯</span>  
<span style="margin-left: 2em">其昌手笔榜之楼中</span>  
<span style="margin-left: 2em"><sub class="note-yuan">城外傍濠因承平日久小民甃筑成居视若世业难于动徒尚仍其旧万一有事之日宜善为区画者也</sub></span>  
<span style="margin-left: 1em">上海县城周围凡九里高二丈四尺门大小凡六东曰</span>  
<span style="margin-left: 1em">朝宗南曰跨龙西曰仪凤北曰晏海小东门曰宝带小</span>  
<span style="margin-left: 1em">南门曰朝阳水门三其东西者跨肇嘉浜其在小东门</span>  
<span style="margin-left: 1em">者跨方浜城为敌楼一为平台二为堞三千六百有奇</span>  
<span style="margin-left: 1em">为穿廊七十有八濠广六丈深一丈七尺周回潆绕外</span>  
<span style="margin-left: 1em">通潮汐嘉靖癸丑九月知府方公廉因倭乱从邑人顾</span>  
<span style="margin-left: 1em">从礼建议筑濬命通判李公国纪同从礼旦暮督工兴</span>  
<span style="margin-left: 1em">筑数月克就三十六年丁巳本府同知罗公拱宸海防</span>  
<span style="margin-left: 1em">于此四大门益以敌楼三楹沿城益以箭台二十环濠</span>  
<span style="margin-left: 1em">益以土墙要害处益以高台层楼凡三曰万军曰制胜</span>  
<span style="margin-left: 1em">曰镇武万历二十六年知县许公汝魁奉赵巡抚檄城</span>  
<span style="margin-left: 1em">加五尺开小南门水关引薛家浜水以通市河南城居</span>  
<span style="margin-left: 1em">民至今赖焉知县徐公可求刘公一爌相继甃内城加</span>  
<span style="margin-left: 1em">阔自大南门迄北门俱甃以巨石工费数千金十余年</span>  
<span style="margin-left: 1em">而告成三十六年久雨内城倾数十处知县李公继周</span>  
<span style="margin-left: 1em">次第修筑四十六年增置穿廊八十余间</span>  
<span style="margin-left: 2em">邑人顾光禄从礼奏请筑城疏略　切照松江府上</span>  
<span style="margin-left: 2em">海县黄浦环其东吴淞绕其北二水会合东流入海</span>  
<span style="margin-left: 2em">不过四五十里实据东海上游故曰上海宋时特为</span>  
<span style="margin-left: 2em">海舶所驻之地故置市舶提举司元朝禁网踈阔江</span>  
<span style="margin-left: 2em">南数郡顽民率皆私造大船出海交通琉球日本满</span>  
<span style="margin-left: 2em">剌交趾诸番往来贸易悉繇上海出人地方赖以富</span>  
<span style="margin-left: 2em">饶遂于至元二十九年开设县治至今二百余年原</span>  
<span style="margin-left: 2em">无城垣可守盖因立县之际一则事出草创库藏钱</span>  
<span style="margin-left: 2em">粮未多一则彼时地方之人半是海洋贩易之辈武</span>  
<span style="margin-left: 2em">艺素所通习海寇不敢轻犯所以虽未设有城池自</span>  
<span style="margin-left: 2em">然亦无他患　国朝以来法令严明沿海通番之家</span>  
<span style="margin-left: 2em">悉皆诛窜从此良民无敢私自出海兼之太平日久</span>  
<span style="margin-left: 2em">人不知兵一闻盗起满县张皇如往年海寇刘通施</span>  
<span style="margin-left: 2em">天泰近年沙贼王棣董淇之乱县官以仓库为忧百</span>  
<span style="margin-left: 2em">姓以身家为虑惊惶错愕手足无错幸赖　圣明旋</span>  
<span style="margin-left: 2em">即扑灭一县生灵得以无咎万一狂贼无知乘潮入</span>  
<span style="margin-left: 2em">寇其往返不过半日间耳为祸可胜道哉见今一县</span>  
<span style="margin-left: 2em">编户六百余里殷实之家率多在市钱粮四十余万</span>  
<span style="margin-left: 2em">银布之类数船可载兼之富商大贾四方辐辏居积</span>  
<span style="margin-left: 2em">货物尤多而县门之外不过一里即是黄浦潮势极</span>  
<span style="margin-left: 2em">其迅急寇贼最难防御所以近来嘉靖戊子等年屡</span>  
<span style="margin-left: 2em">屡被贼劫烧杀伤地方乡官商人居民不下百有余</span>  
<span style="margin-left: 2em">家盖因贼自海入江乘潮而来乘潮而去劫掠城市</span>  
<span style="margin-left: 2em">如取囊中皆繇无城可依之故也伏望　皇上轸念</span>  
<span style="margin-left: 2em">府库钱粮之难聚地方百姓之可哀乞　勅工部都</span>  
<span style="margin-left: 2em">察院会议如果臣言有可采转行南直隶抚按官亲</span>  
<span style="margin-left: 2em">履地方相度基址选委贤能官员趂今秋收岁晚务</span>  
<span style="margin-left: 2em">闲之际开筑内外峻壁城垣以为经久可守之计实</span>  
<span style="margin-left: 2em">一县公私无疆之休也地方幸甚民生幸甚</span>  
<span style="margin-left: 2em"><sub class="note-yuan">抚台周公如斗登上海城寄云襟江滨海驻孤城逝者如斯昼夜行地僻境冲无险设戎生寇至有谁平升虚望景波心彻入境观风海甸清遥忆任人兴地利少卿千载著芳名</sub></span>  
<span style="margin-left: 1em">青浦县城周围一千三十丈以里计者六高二丈三尺</span>  
<span style="margin-left: 1em">箭垜一千七百一十五敌台七窝铺四十八门楼六旱</span>  
<span style="margin-left: 1em">门五东曰望海南曰观宁小西曰来苏大西曰永保北</span>  
<span style="margin-left: 1em">曰拱宸水关三南曰跃龙北曰充赋大西曰通漕月城</span>  
<span style="margin-left: 1em">三在南北大西三门余未建濠广三丈深一丈周围共</span>  
<span style="margin-left: 1em">八里万历二年知县石继芳申请创建</span>  
<span style="margin-left: 2em">青浦县嘉靖庚子以粮税无征议建于郡之西北离</span>  
<span style="margin-left: 2em">城七十余里地名青龙历知县杨垚吕调阴几十年</span>  
<span style="margin-left: 2em">值徐文贞公入相有称不便者壬子议废又二十年</span>  
<span style="margin-left: 2em">而少司马蔡公汝贤时为给谏疏议复之万历癸酉</span>  
<span style="margin-left: 2em">移建于唐行镇邑令石公继芳明敏练达凡城池县</span>  
<span style="margin-left: 2em">宇及学宫察院仓储之属皆其鼎建而运筹有方公</span>  
<span style="margin-left: 2em">私不扰</span>
