## 崇禎松江府志卷之十九　城池　倉廩　驛逓

<span style="margin-left: 3em">城池</span>  
<span style="margin-left: 1em">易曰王公設險以守其國春秋書城二十五城者盛也</span>  
<span style="margin-left: 1em">所以宅民而禦暴也牆止及肩水不没髁金湯云乎哉</span>  
<span style="margin-left: 1em">凡郡城邑城以及沿海要害諸城版築之畚鍤之鄰震</span>  
<span style="margin-left: 1em">膚剥庶幾有扞乎議者謂城如斗大創議式擴似矣然</span>  
<span style="margin-left: 1em">府庫告單閭閻稱匱莫若尋前人之遺緒而歲加繕治</span>  
<span style="margin-left: 1em">之堞如飛雉濠類貫虹而後徐及於擴城之役未晚也</span>  
<span style="margin-left: 1em">是標是本以俟老成者采而擇焉</span>  
<span style="margin-left: 1em">府城廣袤凡九里一百七十三步高二丈四尺濠廣十</span>  
<span style="margin-left: 1em">丈深七尺門凡四東曰披雲西曰谷陽南曰集僊北曰</span>  
<span style="margin-left: 1em">通波披雲集僊以橋通波以塘並知府陳威所題谷陽</span>  
<span style="margin-left: 1em">舊名也水門各附其旁門有樓樓外爲月城元末張士</span>  
<span style="margin-left: 1em">誠據吳時築　國朝因而葺之其地後殿九峯前襟黃</span>  
<span style="margin-left: 1em">浦大海環其東南三江繞乎西北平疇沃野四望極目</span>  
<span style="margin-left: 1em">東南之重地也城之南爲吳王獵場場有五茸俗因呼</span>  
<span style="margin-left: 1em">爲五茸城云</span>  
<span style="margin-left: 2em"><sub class="note-yuan">國朝章簡詩云城郭何年號五茸盤回十里控吳松旌旗曉障芙蓉日鼓角寒生苜蓿風雲起北山連雉堞波澄南海息狼烽登高一望民風厚樓閣重重烟雨中</sub></span>  
<span style="margin-left: 2em">海防志云洪武三十年十一月始分金山衛中千户</span>  
<span style="margin-left: 2em">所官軍立爲松江守禦千户所專管守護城池城上</span>  
<span style="margin-left: 2em">敵臺二十座窩舖二十六座雉堞三千三百八十九</span>  
<span style="margin-left: 2em">垜</span>  
<span style="margin-left: 2em">嘉靖間島夷入寇知府方廉捐俸增葺萬曆二十三</span>  
<span style="margin-left: 2em">年兵部以倭警奉　旨移檄各撫按整理一時工費</span>  
<span style="margin-left: 2em">無措縉紳各照田樂助銀六千有奇華亭令王公廷</span>  
<span style="margin-left: 2em">錫設處備用銀三千有奇共九千餘兩給僉點殷實</span>  
<span style="margin-left: 2em">富民分派四門丈尺葺治分工趲役築未堅牢春雨</span>  
<span style="margin-left: 2em">乘之工方訖而西月城崩陷壓死男婦巡撫趙公可</span>  
<span style="margin-left: 2em">懷檄行重加增繕高闊並加五尺外濠深廣濬治如</span>  
<span style="margin-left: 2em">制萬曆三十六年傾於積雨凡塌毁數百丈華亭令</span>  
<span style="margin-left: 2em">聶公紹昌修築之邇年旋圮不時蓋因城中巨室或</span>  
<span style="margin-left: 2em">有興作從外搬運木石以轆轤升之又或鉤致束薪</span>  
<span style="margin-left: 2em">垜磚狼籍守城官軍玩爲故常又避不敢上聞崇禎</span>  
<span style="margin-left: 2em">三年郡守方公岳貢躬行相視委官修廢補壞增高</span>  
<span style="margin-left: 2em">城堞修建窩舖敵臺肅毖軍兵防宿編號分明遞籌</span>  
<span style="margin-left: 2em">擊柝內外始知有嚴城之守矣城樓四座整頓一新</span>  
<span style="margin-left: 2em">東曰迎生西曰寶成南曰阜民北曰拱宸皆董宗伯</span>  
<span style="margin-left: 2em">其昌手筆榜之樓中</span>  
<span style="margin-left: 2em"><sub class="note-yuan">城外傍濠因承平日久小民甃築成居視若世業難於動徒尚仍其舊萬一有事之日宜善爲區畫者也</sub></span>  
<span style="margin-left: 1em">上海縣城周圍凡九里高二丈四尺門大小凡六東曰</span>  
<span style="margin-left: 1em">朝宗南曰跨龍西曰儀鳳北曰晏海小東門曰寶帶小</span>  
<span style="margin-left: 1em">南門曰朝陽水門三其東西者跨肇嘉浜其在小東門</span>  
<span style="margin-left: 1em">者跨方浜城爲敵樓一爲平臺二爲堞三千六百有奇</span>  
<span style="margin-left: 1em">爲穿廊七十有八濠廣六丈深一丈七尺周迴瀠繞外</span>  
<span style="margin-left: 1em">通潮汐嘉靖癸丑九月知府方公廉因倭亂從邑人顧</span>  
<span style="margin-left: 1em">從禮建議築濬命通判李公國紀同從禮旦暮督工興</span>  
<span style="margin-left: 1em">築數月克就三十六年丁巳本府同知羅公拱宸海防</span>  
<span style="margin-left: 1em">於此四大門益以敵樓三楹沿城益以箭臺二十環濠</span>  
<span style="margin-left: 1em">益以土牆要害處益以高臺層樓凡三曰萬軍曰制勝</span>  
<span style="margin-left: 1em">曰鎮武萬曆二十六年知縣許公汝魁奉趙巡撫檄城</span>  
<span style="margin-left: 1em">加五尺開小南門水關引薛家浜水以通市河南城居</span>  
<span style="margin-left: 1em">民至今賴焉知縣徐公可求劉公一爌相繼甃內城加</span>  
<span style="margin-left: 1em">闊自大南門迄北門俱甃以巨石工費數千金十餘年</span>  
<span style="margin-left: 1em">而告成三十六年久雨內城傾數十處知縣李公繼周</span>  
<span style="margin-left: 1em">次第修築四十六年增置穿廊八十餘間</span>  
<span style="margin-left: 2em">邑人顧光禄從禮奏請築城疏略　切照松江府上</span>  
<span style="margin-left: 2em">海縣黃浦環其東吳淞繞其北二水會合東流入海</span>  
<span style="margin-left: 2em">不過四五十里實據東海上游故曰上海宋時特爲</span>  
<span style="margin-left: 2em">海舶所駐之地故置市舶提舉司元朝禁網踈闊江</span>  
<span style="margin-left: 2em">南數郡頑民率皆私造大船出海交通琉球日本滿</span>  
<span style="margin-left: 2em">剌交趾諸番往來貿易悉繇上海出人地方賴以富</span>  
<span style="margin-left: 2em">饒遂於至元二十九年開設縣治至今二百餘年原</span>  
<span style="margin-left: 2em">無城垣可守蓋因立縣之際一則事出草創庫藏錢</span>  
<span style="margin-left: 2em">糧未多一則彼時地方之人半是海洋販易之輩武</span>  
<span style="margin-left: 2em">藝素所通習海寇不敢輕犯所以雖未設有城池自</span>  
<span style="margin-left: 2em">然亦無他患　國朝以來法令嚴明沿海通番之家</span>  
<span style="margin-left: 2em">悉皆誅竄從此良民無敢私自出海兼之太平日久</span>  
<span style="margin-left: 2em">人不知兵一聞盗起滿縣張皇如往年海寇劉通施</span>  
<span style="margin-left: 2em">天泰近年沙賊王棣董淇之亂縣官以倉庫爲憂百</span>  
<span style="margin-left: 2em">姓以身家爲慮驚惶錯愕手足無錯幸賴　聖明旋</span>  
<span style="margin-left: 2em">即撲滅一縣生靈得以無咎萬一狂賊無知乘潮入</span>  
<span style="margin-left: 2em">寇其往返不過半日間耳爲禍可勝道哉見今一縣</span>  
<span style="margin-left: 2em">編户六百餘里殷實之家率多在市錢糧四十餘萬</span>  
<span style="margin-left: 2em">銀布之類數船可載兼之富商大賈四方輻輳居積</span>  
<span style="margin-left: 2em">貨物尤多而縣門之外不過一里即是黃浦潮勢極</span>  
<span style="margin-left: 2em">其迅急寇賊最難防禦所以近來嘉靖戊子等年屢</span>  
<span style="margin-left: 2em">屢被賊劫燒殺傷地方鄉官商人居民不下百有餘</span>  
<span style="margin-left: 2em">家蓋因賊自海入江乘潮而來乘潮而去劫掠城市</span>  
<span style="margin-left: 2em">如取囊中皆繇無城可依之故也伏望　皇上軫念</span>  
<span style="margin-left: 2em">府庫錢糧之難聚地方百姓之可哀乞　勅工部都</span>  
<span style="margin-left: 2em">察院會議如果臣言有可採轉行南直隸撫按官親</span>  
<span style="margin-left: 2em">履地方相度基址選委賢能官員趂今秋收歲晚務</span>  
<span style="margin-left: 2em">閒之際開築內外峻壁城垣以爲經久可守之計實</span>  
<span style="margin-left: 2em">一縣公私無疆之休也地方幸甚民生幸甚</span>  
<span style="margin-left: 2em"><sub class="note-yuan">撫臺周公如斗登上海城寄云襟江濱海駐孤城逝者如斯晝夜行地僻境衝無險設戎生寇至有誰平升虛望景波心徹入境觀風海甸清遥憶任人興地利少卿千載著芳名</sub></span>  
<span style="margin-left: 1em">青浦縣城周圍一千三十丈以里計者六高二丈三尺</span>  
<span style="margin-left: 1em">箭垜一千七百一十五敵臺七窩舖四十八門樓六旱</span>  
<span style="margin-left: 1em">門五東曰望海南曰觀寧小西曰來蘇大西曰永保北</span>  
<span style="margin-left: 1em">曰拱宸水關三南曰躍龍北曰充賦大西曰通漕月城</span>  
<span style="margin-left: 1em">三在南北大西三門餘未建濠廣三丈深一丈周圍共</span>  
<span style="margin-left: 1em">八里萬曆二年知縣石繼芳申請創建</span>  
<span style="margin-left: 2em">青浦縣嘉靖庚子以糧稅無徵議建於郡之西北離</span>  
<span style="margin-left: 2em">城七十餘里地名青龍歷知縣楊垚呂調陰幾十年</span>  
<span style="margin-left: 2em">值徐文貞公入相有稱不便者壬子議廢又二十年</span>  
<span style="margin-left: 2em">而少司馬蔡公汝賢時爲給諫疏議復之萬曆癸酉</span>  
<span style="margin-left: 2em">移建於唐行鎮邑令石公繼芳明敏練達凡城池縣</span>  
<span style="margin-left: 2em">宇及學宫察院倉儲之屬皆其鼎建而運籌有方公</span>  
<span style="margin-left: 2em">私不擾</span>  
<span style="margin-left: 1em">金山衛城在府南七十二里西連乍浦東接青村周一</span>  
<span style="margin-left: 1em">十二里三百步有奇高二丈八尺濠周於城深丈有八</span>  
<span style="margin-left: 1em">尺面廣十二丈陸門八水門一門樓四南曰鎮海北曰</span>  
<span style="margin-left: 1em">拱北角樓四腰樓八敵臺八間以箭樓凡四十八雉堞</span>  
<span style="margin-left: 1em">三千六百七十八其外營堡烽堠氣勢聯絡隱若金湯</span>  
<span style="margin-left: 1em">洪武十九年　欽差安遠侯等官起嘉湖蘇松等府衛</span>  
<span style="margin-left: 1em">軍民築城周一十二里零三百步五尺六寸五分高二</span>  
<span style="margin-left: 1em">丈八寸永樂十五年九月欽差都指揮使谷祥增高五</span>  
<span style="margin-left: 1em">尺今高二丈八尺池周一十三里零三百步潮沙淤塞</span>  
<span style="margin-left: 1em">指揮侯端等奉部符督修挑深一丈四尺闊一十丈旱</span>  
<span style="margin-left: 1em">門四座水門一座城樓五座角樓四處窩舖七十二座</span>  
<span style="margin-left: 1em">弔橋四座烽堠墩臺四十四處營堡七處弘治初指揮</span>  
<span style="margin-left: 1em">使翁熊重修萬曆二十六年城池日漸頽淤巡撫趙公</span>  
<span style="margin-left: 1em">可懷委本府督令衛官幫砌城牆務令高厚濠闊一十</span>  
<span style="margin-left: 1em">二丈深一丈五尺崇禎三年郡侯方公岳貢以城久傾</span>  
<span style="margin-left: 1em">隳特捐俸鍰移會指揮范必忠刻期舉工合措軍三料</span>  
<span style="margin-left: 1em">銀修築坍城二百二十六丈葺建窩舖五十四座并四</span>  
<span style="margin-left: 1em">門營房務俾堅久以嚴防禦</span>  
<span style="margin-left: 2em"><sub class="note-yuan">知府樊瑩登樓詩孤城周匝倚江干大海微茫入望寬蜃氣半收初霽日潮聲漸細已迴瀾魚鹽有利民空羡穀粟無功我愧飱獨喜四夷時貢獻將軍不用事征鞍洪武丙寅沿海築城王逢有詩牀頭鴟卧久空金壁上蝸行尚有琴孺子成名狂阮籍覇才無主老陳琳虹霓氣冠登萊市蝙蝠群飛顧陸林環海烟河翻萬臿連書霜月抱孤衾</sub></span>  
<span style="margin-left: 1em">柘林城本堡原係古鎮以其臨海嘉靖甲寅倭至取便</span>  
<span style="margin-left: 1em">結老巢於此巡按御史尚公維持因建議築城周圍四</span>  
<span style="margin-left: 1em">里高丈八尺旱門三座水關二座雉堞一千八百七十</span>  
<span style="margin-left: 1em">垜城濠原欠深闊後奉巡撫趙公可懷明文重浚面闊</span>  
<span style="margin-left: 1em">十丈底闊六丈深一丈五尺</span>  
<span style="margin-left: 2em"><sub class="note-yuan">柘林城成周學憲思兼贈尚侍御詩扶桑新築受降城海上烽烟萬里清天作重關魚鑰靜戍臨三島雉樓鳴旌旗曉映霜臺月鼓角宵傳漢將營聞道廟廊今有議籌邊還欲仗威名</sub></span>  
<span style="margin-left: 1em">青村城在金山城東一百里周圍六里高二丈五尺濠</span>  
<span style="margin-left: 1em">廣二十有四丈深七尺餘城門四上各有樓外各有月</span>  
<span style="margin-left: 1em">城角樓四敵臺十有一箭樓二十八</span>  
<span style="margin-left: 2em">海防志云青村城在府東南一百十里金山城東一</span>  
<span style="margin-left: 2em">百里洪武十九年安遠侯議築城周六里八十九步</span>  
<span style="margin-left: 2em">高一丈八尺永樂十五年都指揮使谷祥增修指揮</span>  
<span style="margin-left: 2em">侯端濬治池周五里八十步月城四座城樓四座早</span>  
<span style="margin-left: 2em">門四座箭樓二十八座弔橋四座窩舖一百三十座</span>  
<span style="margin-left: 2em">雉堞一千七百六十垜弘治初指揮使翁熊重修年</span>  
<span style="margin-left: 2em">來日漸坍頽濠亦壅淤奉趙公可懷檄委署海防李</span>  
<span style="margin-left: 2em">同知暹重修城加高厚如敵臺面浚闊十丈底闊六</span>  
<span style="margin-left: 2em">丈深一丈六尺</span>  
<span style="margin-left: 1em">南滙嘴城在青村北五十里周圍九里百三十步高二</span>  
<span style="margin-left: 1em">丈二尺濠周於城深七尺餘廣二十有四丈陸門四水</span>  
<span style="margin-left: 1em">門四門樓角樓各四敵臺四箭樓四十</span>  
<span style="margin-left: 2em">海防志云南滙城即金山衛中後千户所分署在上</span>  
<span style="margin-left: 2em">海縣十九保地方去府西南一百五十里去青村五</span>  
<span style="margin-left: 2em">十里洪武十九年安遠侯所築城周五里一百四十</span>

<span style="margin-left: 2em"><sub class="note-yuan">至元十三年有調寄賀新郎無名氏題西湖官驛水閣倩綵鸞傳語問陸家兄弟翩翩今歸何處留下文章藏萬壑時作雲烟吞吐謾徙倚朱蘭凝竚闌外瑁河誰管領歎先生舊宅僧分住天下事盡如許英雄總被虛名誤覽遺編浩歎寂寞一丘寒土惟有春風長來往催却幾多人去但歲歲垂楊自舞今日我來懷古後算後人又以今爲古留此曲伴鷗鷺</sub></span>  
<span style="margin-left: 1em">聽鶴亭在今西林寺舊名谷陽俗呼接官亭古送迎憇</span>  
<span style="margin-left: 2em">息之所元元貞三年修造易今名至正中府監哈只</span>  
<span style="margin-left: 2em">哈散沙繼修益壯左有堂扁曰集英門榜曰駐驛華</span>  
<span style="margin-left: 2em">亭尹劉必世温書志稱其地面瞰大河背負九峯光</span>  
<span style="margin-left: 2em">明敞豁爲郡之絕致而又當闤闠輻輳中以是頗爲</span>  
<span style="margin-left: 2em">傍近所侵數十年前嘗有以勢規爲己業者存古愛</span>  
<span style="margin-left: 2em">禮之君子尚於此而致意云</span>  
<span style="margin-left: 2em">儒學教授劉蒙聽鶴亭記略　松江古華亭邑天朝</span>  
<span style="margin-left: 2em">以其冠浙右而陞之府千里牧寄視昔之邑事有加</span>  
<span style="margin-left: 2em">於是上之人循行撫治常絡繹郵遞走役告至告去</span>  
<span style="margin-left: 2em">有司駿奔出郊素無傳館往往班荆道周寄跡梵宇</span>  
<span style="margin-left: 2em">至則雜前迎趨去則交向遽別視古進退之節幾失</span>  
<span style="margin-left: 2em">之矣余爲郡文學椽侍迎送者亦屢一日郡長官顧</span>  
<span style="margin-left: 2em">聯事僚屬而謂曰府若縣幸各就治所迎送之地則</span>  
<span style="margin-left: 2em">未暇舊聞有谷陽亭獨不能捐俸以作此室耶詢謀</span>  
<span style="margin-left: 2em">僉同元貞三年春命工度材計直傭作築亭於谷陽</span>  
<span style="margin-left: 2em">門之西土木具興不動衆不妨農逮至卒事不兩月</span>  
<span style="margin-left: 2em">觀者偉其制之新而喜其成之速也亭東水連於湖</span>  
<span style="margin-left: 2em">湖有磧曰唳鶴灘或請以聽鶴名焉中書右丞馬公</span>  
<span style="margin-left: 2em">可而書之遂揭于扁俾余爰記諸石以明作者之所</span>  
<span style="margin-left: 2em">始</span>  
<span style="margin-left: 2em">達魯花赤完澤普化重修記略　雲間直郭西孔道</span>  
<span style="margin-left: 2em">有亭翼然臨其陽顏曰聽鶴者郡昔置以爲送御憇</span>  
<span style="margin-left: 2em">恩之所也上自天子銜命之使暨省若憲若有司凡</span>  
<span style="margin-left: 2em">檄號郡縣以至者必郊御之郡之群有司歲時進賀</span>  
<span style="margin-left: 2em">章奏及使者之布命而返與凡僚屬之被命或代而</span>  
<span style="margin-left: 2em">去必郊送之舊規褊陿自大德丁酉歷四十有五年</span>  
<span style="margin-left: 2em">未有圖展而新者至正改元亞中大夫哈只公來監</span>  
<span style="margin-left: 2em">是邦蒞政慈祥民俗胥變遠近洽和爰相是亭宜更</span>  
<span style="margin-left: 2em">舊於是資者給財力者效庸未數月告完廓焉軒墀</span>  
<span style="margin-left: 2em">窈焉室堂司閽有廬庖厠畢具視舊觀加克拓矣官</span>  
<span style="margin-left: 2em">不知費民不知擾監牧喜之偕予來登予曰世之仕</span>  
<span style="margin-left: 2em">者視己廨猶傳舍且不恤况勞送之暫至者又孰加</span>  
<span style="margin-left: 2em">之意乎今侯視官廨如己廨則能視官事如家事能</span>  
<span style="margin-left: 2em">推是而往自官舍而民舍使各有寧宇則善政之實</span>  
<span style="margin-left: 2em">又何言耶方侯葺兹亭而時和及成而歲用登是尤</span>
