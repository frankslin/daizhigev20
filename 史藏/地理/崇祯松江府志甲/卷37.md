## 崇禎松江府志卷之三十七　人物二（國朝賢達）

<span style="margin-left: 3em">宋元賢達二</span>  
<span style="margin-left: 1em">宋</span>  
<span style="margin-left: 1em">陳舜俞字令舉華亭人嘉祐四年擢制科第一時舜俞</span>  
<span style="margin-left: 1em">已登進士復中是選聲名赫然始授光禄丞簽書壽州</span>  
<span style="margin-left: 1em">判官熙寧初以屯田員外郎知山陰縣未幾召試館職</span>  
<span style="margin-left: 1em">不就會青苗法行不奉令上疏自劾曰方今小民匱乏</span>  
<span style="margin-left: 1em">願貸之人往往有之譬如孺子見飴蜜孰不染指争食</span>  
<span style="margin-left: 1em">然父母疾止之恐其積甘生病故耆老戒其鄉黨父兄</span>  
<span style="margin-left: 1em">誨其子弟未嘗不以貸貰爲不善治生今乃官自出錢</span>  
<span style="margin-left: 1em">誘以便利督以威行非王道之舉况正月放夏料五月</span>  
<span style="margin-left: 1em">放秋料而所斂亦在當月百姓得錢便出息輸納實無</span>  
<span style="margin-left: 1em">所利是使民輸青苗錢乃別爲一賦以獘之也疏上謫</span>  
<span style="margin-left: 1em">監南康軍鹽酒稅𨓆居華亭嘗騎白牛往來風涇自號</span>  
<span style="margin-left: 1em">白牛居士舜俞直道自信無所回撓所著有都官集行</span>  
<span style="margin-left: 1em">於世</span>  
<span style="margin-left: 1em">李撰字子約熙寧中以進士歷彭澤令時括民田轉運</span>  
<span style="margin-left: 1em">使苛擾欲多得匿户美田爲功撰持不可抱牘抗論且</span>  
<span style="margin-left: 1em">請就劾并解印綬去使者度不可屈從之時王安禮爲</span>  
<span style="margin-left: 1em">部刺史使者還金陵欲搆撰罪安禮曰縣令敢與部使</span>  
<span style="margin-left: 1em">者争衡必介特有守士也亟艸奏薦之元祐三年議遣</span>  
<span style="margin-left: 1em">使修復小吳河撰上復吳賦二篇言河不可復通判莫</span>  
<span style="margin-left: 1em">保二州官至朝奉大夫大觀三年卒撰廣孟子說著養</span>  
<span style="margin-left: 1em">氣論三篇毛詩訓解二十卷孟子講義十四卷文集五</span>  
<span style="margin-left: 1em">十卷贊論五卷子彌遜</span>  
<span style="margin-left: 2em">唐曹王明子偲居陳留至餘慶以國子博士知常州</span>  
<span style="margin-left: 2em">卒葬横山遂家於吳子撰又以松江有李塔明王廟</span>  
<span style="margin-left: 2em">分一子祀香火遂家西竹鄉見李氏譜</span>  
<span style="margin-left: 1em">朱諤華亭人初名紱進士第二御筆改今名賜字聖與</span>  
<span style="margin-left: 1em">徽宗時累官御史中丞嘗奏請開內閣延群臣從容論</span>  
<span style="margin-left: 1em">道如神宗故事又請分命使者剌舉諸道有受令不行</span>  
<span style="margin-left: 1em">行而不盡者謫其罪帝嘗諭諤曰今朝廷無事宜審重</span>  
<span style="margin-left: 1em">以稱朕意對曰前此中執法類不知職守言事多妄至</span>  
<span style="margin-left: 1em">過天津橋見汴堤一角墊陷乞修葺如許細故何足論</span>  
<span style="margin-left: 1em">哉歷兵禮吏三部尚書大觀初拜右丞相卒謚忠靖累</span>  
<span style="margin-left: 1em">贈秦國公初諤在位所得恩澤皆分蔭族人及卒二子</span>  
<span style="margin-left: 1em">猶未禄人以是多之</span>  
<span style="margin-left: 1em">柳約字元禮華亭人性至孝深爲經學大觀三年上舍</span>  
<span style="margin-left: 1em">進士爲霸州教授歷辟雍博士靖康初陞殿中侍御史</span>  
<span style="margin-left: 1em">論三鎮不可棄後以直龍圖閣知嚴州兼浙西兵馬都</span>  
<span style="margin-left: 1em">監時金人大入杜充擁衆北去列郡震恐約於横潰中</span>  
<span style="margin-left: 1em">屹保孤城悉心捍禦上書請糾合諸郡克復吳會上嘉</span>  
<span style="margin-left: 1em">其忠進右文殿修撰再詔褒奬其備禦功充集英殿修</span>  
<span style="margin-left: 1em">撰召對嘉勞再三擢權户部侍郎凡例外宣索皆執奏</span>  
<span style="margin-left: 1em">不進論吳开等罪未正非所以厲臣節諸大將提兵入</span>  
<span style="margin-left: 1em">覲將有尾大不掉之患皆人不敢言者遣使高麗當路</span>  
<span style="margin-left: 1em">諷言者誣以事罷之金人歸侵疆起知蔡州被命而往</span>  
<span style="margin-left: 1em">一無所顧既而金人渝盟傳檄河南守臣皆舉城降約</span>  
<span style="margin-left: 1em">獨遣使數輩於武昌得報而後返未幾以敷文閣待制</span>  
<span style="margin-left: 1em">食祠禄十有五年卒約母病泣禱於天願損壽以益母</span>  
<span style="margin-left: 1em">尋愈約先兩月卒</span>  
<span style="margin-left: 1em">朱彦美字師實華亭人贈少師伯虎之子任授郴州司</span>  
<span style="margin-left: 1em">理參軍知仁和縣籍記姦頑斂迹凡徵租不遣一吏大</span>  
<span style="margin-left: 1em">署其門予之期趨令無一人後者除通判杭州守將悉</span>  
<span style="margin-left: 1em">以事委彦美每夜漏欲盡起秉兩炬據案閲訟訴數十</span>  
<span style="margin-left: 1em">百人立盡一郡翕然稱治會宰相王鄭公當國彦美陳</span>  
<span style="margin-left: 1em">便宜十餘條以名聞徽宗召見賜五品服除江淮荆湖</span>  
<span style="margin-left: 1em">兩浙等路制置發運判官祖宗時據淮海走集之地置</span>  
<span style="margin-left: 1em">轉般倉受東南八十四州之粟發運使具千艘歲漕六</span>  
<span style="margin-left: 1em">百萬斛輸之京師蔡京用事罷轉般倉爲直達倉盡掊</span>  
<span style="margin-left: 1em">藏錢廪粟爲羡餘以獻而六路漕船浮江絕淮泝汴累</span>  
<span style="margin-left: 1em">數月後至吏卒冗食其中度不能償則穴而沉之以險</span>  
<span style="margin-left: 1em">爲解或委空舟逃去歲亡十二三中都藏粟且盡彦美</span>  
<span style="margin-left: 1em">受命曰此直達之誤也今轉般倉法具載有司第付推</span>  
<span style="margin-left: 1em">行乃攷故事著科條蒐獮脱遺鉏治乾没得緡錢累百</span>  
<span style="margin-left: 1em">萬會王鄭公憂去京黨復進罷彦美提點江州太平觀</span>  
<span style="margin-left: 1em">而直達如故識者恨惜之宣和二年除京西路計度轉</span>  
<span style="margin-left: 1em">運副使五年進直秘閣遂請老彦美仕四朝在事五十</span>  
<span style="margin-left: 1em">年五持使者節皆有能名而漕京西尤稱於天下京西</span>  
<span style="margin-left: 1em">治河南總十八州介居國右守將類多顯人怙貴不法</span>  
<span style="margin-left: 1em">至輦金幣署別籍儲之部使者無誰何而河防陵寢視</span>  
<span style="margin-left: 1em">他路爲劇往往丐請於朝或移用他司錢佐其乏而以</span>  
<span style="margin-left: 1em">負殿免者相屬也彦美曰轉運使操一路之羸而倒持</span>  
<span style="margin-left: 1em">之吾不能喑噫以爲生即日乘傳詣所屬州按簿書窮</span>  
<span style="margin-left: 1em">株穴得匹貨百餘萬釋逋負之在繫者量緩急輕重所</span>  
<span style="margin-left: 1em">宜爲施舍費出之節於是上下贍足奏課爲天下第一</span>  
<span style="margin-left: 1em">擢陞三路名動朝廷享年八十葬於修竹鄉之福泉山</span>  
<span style="margin-left: 1em">衛膚敏字商彦以上舍生登進士第歷秘書省較書郎</span>  
<span style="margin-left: 1em">命假給事中賀金主生辰膚敏奏曰彼生辰後天寧節</span>  
<span style="margin-left: 1em">五日萬一金使不來爲朝廷羞請至燕山候進止徽宗</span>  
<span style="margin-left: 1em">可其奏既至燕金使果不至遂以幣置境上而還後復</span>  
<span style="margin-left: 1em">使金道聞金且大入至燕報愈急衆懼不敢進膚敏叱</span>  
<span style="margin-left: 1em">曰吾將君命以行其可止乎既至金知其兵已舉殊不</span>  
<span style="margin-left: 1em">爲屈金人不說及還中道羈留且半年至涿州新城與</span>  
<span style="margin-left: 1em">斡離不遇遣人約相見膚敏長揖而入金人出誓書示</span>  
<span style="margin-left: 1em">之却不視曰遠使久不聞朝廷事此書真僞不可知因</span>  
<span style="margin-left: 1em">論用兵事又以語折之幾爲所留靖康初始還進三官</span>  
<span style="margin-left: 1em">遷吏部員外郎進衛尉少卿建議兩河諸郡宜降㼃書</span>  
<span style="margin-left: 1em">許以世襲使各堅守陝西山東淮南諸路並令增陴浚</span>  
<span style="margin-left: 1em">隍徙民入城爲清野計命大臣留守汴京車駕早幸江</span>  
<span style="margin-left: 1em">寧帝頗納之遷起居舍人言陛下򐂜祚之初苟無典刑</span>  
<span style="margin-left: 1em">何以立國凡前日屈節敵人委質僞命者宜差第其罪</span>  
<span style="margin-left: 1em">大則族次則誅又其次竄殛下則斥之遠方終身不齒</span>  
<span style="margin-left: 1em">豈可猶𢌿祠禄使塵班列哉拜右諫議大夫兼侍讀時</span>  
<span style="margin-left: 1em">高宗欲起用欽宗內侍膚敏言自古帝王未有求閹寺</span>  
<span style="margin-left: 1em">於閑𨓆而用者遂寢后父邢焕除徽猷閣待制太后兄</span>  
<span style="margin-left: 1em">子孟忠厚顯謨閣直學士膚敏言非祖宗法焕雖换武</span>  
<span style="margin-left: 1em">職忠厚如故遷膚敏中書舍人膚敏奏曰事母后莫若</span>  
<span style="margin-left: 1em">孝待親屬莫若恩勸臣下莫若賞今陛下順太母以非</span>  
<span style="margin-left: 1em">法非所謂孝處忠厚以非分非所謂恩不用臣言而遷</span>  
<span style="margin-left: 1em">其官非所謂賞一舉而三失矣帝命宰相諭曰朝廷以</span>  
<span style="margin-left: 1em">次遷官非因論事也膚敏猶不拜居家逾月及忠厚改</span>  
<span style="margin-left: 1em">承宣使詔后族勿除從官膚敏始拜命在後省論事爲</span>  
<span style="margin-left: 1em">黃潛善汪伯彦所惡因事斥之三年春召赴行在力疾</span>  
<span style="margin-left: 1em">扈蹕至臨安俄除刑部侍郎未拜謁告歸華亭就醫許</span>  
<span style="margin-left: 1em">之遷禮部侍郎卒</span>  
<span style="margin-left: 1em">李綱字伯紀梁谿人父夔爲華亭尉生綱於官舍政和</span>  
<span style="margin-left: 1em">二年進士官階政績俱詳宋史紹興十年卒年五十八</span>  
<span style="margin-left: 1em">贈少師孝宗初謚忠定</span>  
<span style="margin-left: 2em">雲間志及谿山餘話云華亭縣尉廳有相公閣以右</span>  
<span style="margin-left: 2em">文殿修撰李公夔元豐初爲尉生大丞相忠定公於</span>  
<span style="margin-left: 2em">此因呼相公閣　國朝用知縣趙驥議立祠祀之又</span>  
<span style="margin-left: 2em">讀李忠定集有謝知秀州表則忠定又職於此矣</span>  
<span style="margin-left: 2em">葉適李丞相謚忠定議　公自起居郎極論都城水</span>  
<span style="margin-left: 2em">災斥爲監當而抗直之聲震於天下矣及斡離不來</span>  
<span style="margin-left: 2em">寇在廷茫然將從乘輿以出獨公請與執政辨詰遂</span>  
<span style="margin-left: 2em">奪其議力守京師虜以退卻然其留割三鎮詔書擊</span>  
<span style="margin-left: 2em">女真之歸而募兵以防其再至皆爲同列所排不果</span>  
<span style="margin-left: 2em">用也高宗中興首命公自輔於是張邦昌以僭逆誅</span>  
<span style="margin-left: 2em">矣先是河北河東錄堅守者建議遣張所傅亮往援</span>  
<span style="margin-left: 2em">接之乞幸襄鄧以係人心而無走東南使周望傅雱</span>  
<span style="margin-left: 2em">通問二聖而無踵和約時中原尚未潰也公方除京</span>  
<span style="margin-left: 2em">黼亂政漸復祖宗舊法奏請施行數十事事多機要</span>  
<span style="margin-left: 2em">使稍得歲年之須則兩河不遂陷而虜不敢復鼓行</span>  
<span style="margin-left: 2em">入內地矣而讐耻固可報也不幸七十五日而罷去</span>  
<span style="margin-left: 2em">迄其後常疏外坎壈雖僅免顛沛而曾不少得其意</span>  
<span style="margin-left: 2em">焉自是禍難百出而南北竟以分裂此爲國家惜者</span>  
<span style="margin-left: 2em">所以哀公之志而深悲其相之不終士至有未嘗識</span>  
<span style="margin-left: 2em">公面而坐論救公以死彼豈有所顧望用託而然哉</span>  
<span style="margin-left: 2em">蓋公之賢自當時市井負販莫不喜爲之道說然而</span>  
<span style="margin-left: 2em">謗公者亦衆矣其尤甚者罪公特以計取顯位而已</span>  
<span style="margin-left: 2em">京師之禍公實使之嗚呼當是之時所謂謀國者豈</span>  
<span style="margin-left: 2em">有他道哉避走而乞和譽賊虜而卑中國爾以避走</span>  
<span style="margin-left: 2em">乞和譽賊虜卑中國之人而議公之得失故其自許</span>  
<span style="margin-left: 2em">爲謀詳慮密而謂公爲畧而疎自以爲鎮重能消弭</span>  
<span style="margin-left: 2em">而謂公爲輕鋭而喜事其恬視君父之仇畏死持禄</span>  
<span style="margin-left: 2em">甘爲世所賤侮而以公之能尊君以身殉國爲人望</span>  
<span style="margin-left: 2em">所屬者謂爲朋黨要結以自榮故主和者非致寇而</span>  
<span style="margin-left: 2em">守京師者爲失策矣則公之負謗於時亦其理之所</span>  
<span style="margin-left: 2em">宜得也何足辭哉獨有可恨者是非毁譽之相蒙布</span>  
<span style="margin-left: 2em">必至於久而後論定是從古以然者也公之殁五十</span>  
<span style="margin-left: 2em">載矣世之論公者卒未有以大異於前日也何歟孔</span>  
<span style="margin-left: 2em">子曰微管仲吾其被髮左衽矣考公之行事而深察</span>  
<span style="margin-left: 2em">其志使要其功烈之所成就則豈有媿於孔子之所</span>  
<span style="margin-left: 2em">稱者哉悲夫謹按謚法慮國忘家曰忠安民大慮曰</span>  
<span style="margin-left: 2em">定請以忠定爲公謚謹議<sub class="note-yuan">葉水心適集</sub></span>  
<span style="margin-left: 1em">任盡言字元受登紹興五年進士第生平忠義自負慷</span>  
<span style="margin-left: 1em">慨喜談時事雖在下位而意氣足壓萬夫秦檜擅權久</span>  
<span style="margin-left: 1em">言路壅塞上召湯鵬舉爲御史盡言投啟賀之數列檜</span>  
<span style="margin-left: 1em">罪狀凛凛髮上指鵬舉袖以白上檜之姻黨始盡罷斥</span>  
<span style="margin-left: 1em">去并釋趙鼎子汾及李孟堅王之奇聽自便人推盡言</span>
