## 崇祯松江府志卷之三十七　人物二（国朝贤达）

<span style="margin-left: 3em">宋元贤达二</span>  
<span style="margin-left: 1em">宋</span>  
<span style="margin-left: 1em">陈舜俞字令举华亭人嘉祐四年擢制科第一时舜俞</span>  
<span style="margin-left: 1em">已登进士复中是选声名赫然始授光禄丞签书寿州</span>  
<span style="margin-left: 1em">判官熙宁初以屯田员外郎知山阴县未几召试馆职</span>  
<span style="margin-left: 1em">不就会青苗法行不奉令上疏自劾曰方今小民匮乏</span>  
<span style="margin-left: 1em">愿贷之人往往有之譬如孺子见饴蜜孰不染指争食</span>  
<span style="margin-left: 1em">然父母疾止之恐其积甘生病故耆老戒其乡党父兄</span>  
<span style="margin-left: 1em">诲其子弟未尝不以贷贳为不善治生今乃官自出钱</span>  
<span style="margin-left: 1em">诱以便利督以威行非王道之举况正月放夏料五月</span>  
<span style="margin-left: 1em">放秋料而所敛亦在当月百姓得钱便出息输纳实无</span>  
<span style="margin-left: 1em">所利是使民输青苗钱乃别为一赋以獘之也疏上谪</span>  
<span style="margin-left: 1em">监南康军盐酒税𨓆居华亭尝骑白牛往来风泾自号</span>  
<span style="margin-left: 1em">白牛居士舜俞直道自信无所回挠所著有都官集行</span>  
<span style="margin-left: 1em">于世</span>  
<span style="margin-left: 1em">李撰字子约熙宁中以进士历彭泽令时括民田转运</span>  
<span style="margin-left: 1em">使苛扰欲多得匿户美田为功撰持不可抱牍抗论且</span>  
<span style="margin-left: 1em">请就劾并解印绶去使者度不可屈从之时王安礼为</span>  
<span style="margin-left: 1em">部刺史使者还金陵欲搆撰罪安礼曰县令敢与部使</span>  
<span style="margin-left: 1em">者争衡必介特有守士也亟艸奏荐之元祐三年议遣</span>  
<span style="margin-left: 1em">使修复小吴河撰上复吴赋二篇言河不可复通判莫</span>  
<span style="margin-left: 1em">保二州官至朝奉大夫大观三年卒撰广孟子说著养</span>  
<span style="margin-left: 1em">气论三篇毛诗训解二十卷孟子讲义十四卷文集五</span>  
<span style="margin-left: 1em">十卷赞论五卷子弥逊</span>  
<span style="margin-left: 2em">唐曹王明子偲居陈留至余庆以国子博士知常州</span>  
<span style="margin-left: 2em">卒葬横山遂家于吴子撰又以松江有李塔明王庙</span>  
<span style="margin-left: 2em">分一子祀香火遂家西竹乡见李氏谱</span>  
<span style="margin-left: 1em">朱谔华亭人初名绂进士第二御笔改今名赐字圣与</span>  
<span style="margin-left: 1em">徽宗时累官御史中丞尝奏请开内阁延群臣从容论</span>  
<span style="margin-left: 1em">道如神宗故事又请分命使者剌举诸道有受令不行</span>  
<span style="margin-left: 1em">行而不尽者谪其罪帝尝谕谔曰今朝廷无事宜审重</span>  
<span style="margin-left: 1em">以称朕意对曰前此中执法类不知职守言事多妄至</span>  
<span style="margin-left: 1em">过天津桥见汴堤一角垫陷乞修葺如许细故何足论</span>  
<span style="margin-left: 1em">哉历兵礼吏三部尚书大观初拜右丞相卒谥忠靖累</span>  
<span style="margin-left: 1em">赠秦国公初谔在位所得恩泽皆分荫族人及卒二子</span>  
<span style="margin-left: 1em">犹未禄人以是多之</span>  
<span style="margin-left: 1em">柳约字元礼华亭人性至孝深为经学大观三年上舍</span>  
<span style="margin-left: 1em">进士为霸州教授历辟雍博士靖康初升殿中侍御史</span>  
<span style="margin-left: 1em">论三镇不可弃后以直龙图阁知严州兼浙西兵马都</span>  
<span style="margin-left: 1em">监时金人大入杜充拥众北去列郡震恐约于横溃中</span>  
<span style="margin-left: 1em">屹保孤城悉心捍御上书请纠合诸郡克复吴会上嘉</span>  
<span style="margin-left: 1em">其忠进右文殿修撰再诏褒奖其备御功充集英殿修</span>  
<span style="margin-left: 1em">撰召对嘉劳再三擢权户部侍郎凡例外宣索皆执奏</span>  
<span style="margin-left: 1em">不进论吴开等罪未正非所以厉臣节诸大将提兵入</span>  
<span style="margin-left: 1em">觐将有尾大不掉之患皆人不敢言者遣使高丽当路</span>  
<span style="margin-left: 1em">讽言者诬以事罢之金人归侵疆起知蔡州被命而往</span>  
<span style="margin-left: 1em">一无所顾既而金人渝盟传檄河南守臣皆举城降约</span>  
<span style="margin-left: 1em">独遣使数辈于武昌得报而后返未几以敷文阁待制</span>  
<span style="margin-left: 1em">食祠禄十有五年卒约母病泣祷于天愿损寿以益母</span>  
<span style="margin-left: 1em">寻愈约先两月卒</span>  
<span style="margin-left: 1em">朱彦美字师实华亭人赠少师伯虎之子任授郴州司</span>  
<span style="margin-left: 1em">理参军知仁和县籍记奸顽敛迹凡征租不遣一吏大</span>  
<span style="margin-left: 1em">署其门予之期趋令无一人后者除通判杭州守将悉</span>  
<span style="margin-left: 1em">以事委彦美每夜漏欲尽起秉两炬据案阅讼诉数十</span>  
<span style="margin-left: 1em">百人立尽一郡翕然称治会宰相王郑公当国彦美陈</span>  
<span style="margin-left: 1em">便宜十余条以名闻徽宗召见赐五品服除江淮荆湖</span>  
<span style="margin-left: 1em">两浙等路制置发运判官祖宗时据淮海走集之地置</span>  
<span style="margin-left: 1em">转般仓受东南八十四州之粟发运使具千艘岁漕六</span>  
<span style="margin-left: 1em">百万斛输之京师蔡京用事罢转般仓为直达仓尽掊</span>  
<span style="margin-left: 1em">藏钱廪粟为羡余以献而六路漕船浮江绝淮溯汴累</span>  
<span style="margin-left: 1em">数月后至吏卒冗食其中度不能偿则穴而沉之以险</span>  
<span style="margin-left: 1em">为解或委空舟逃去岁亡十二三中都藏粟且尽彦美</span>  
<span style="margin-left: 1em">受命曰此直达之误也今转般仓法具载有司第付推</span>  
<span style="margin-left: 1em">行乃攷故事著科条蒐狝脱遗鉏治乾没得缗钱累百</span>  
<span style="margin-left: 1em">万会王郑公忧去京党复进罢彦美提点江州太平观</span>  
<span style="margin-left: 1em">而直达如故识者恨惜之宣和二年除京西路计度转</span>  
<span style="margin-left: 1em">运副使五年进直秘阁遂请老彦美仕四朝在事五十</span>  
<span style="margin-left: 1em">年五持使者节皆有能名而漕京西尤称于天下京西</span>  
<span style="margin-left: 1em">治河南总十八州介居国右守将类多显人怙贵不法</span>  
<span style="margin-left: 1em">至辇金币署别籍储之部使者无谁何而河防陵寝视</span>  
<span style="margin-left: 1em">他路为剧往往丐请于朝或移用他司钱佐其乏而以</span>  
<span style="margin-left: 1em">负殿免者相属也彦美曰转运使操一路之羸而倒持</span>  
<span style="margin-left: 1em">之吾不能喑噫以为生即日乘传诣所属州按簿书穷</span>  
<span style="margin-left: 1em">株穴得匹货百余万释逋负之在系者量缓急轻重所</span>  
<span style="margin-left: 1em">宜为施舍费出之节于是上下赡足奏课为天下第一</span>  
<span style="margin-left: 1em">擢升三路名动朝廷享年八十葬于修竹乡之福泉山</span>  
<span style="margin-left: 1em">卫肤敏字商彦以上舍生登进士第历秘书省较书郎</span>  
<span style="margin-left: 1em">命假给事中贺金主生辰肤敏奏曰彼生辰后天宁节</span>  
<span style="margin-left: 1em">五日万一金使不来为朝廷羞请至燕山候进止徽宗</span>  
<span style="margin-left: 1em">可其奏既至燕金使果不至遂以币置境上而还后复</span>  
<span style="margin-left: 1em">使金道闻金且大入至燕报愈急众惧不敢进肤敏叱</span>  
<span style="margin-left: 1em">曰吾将君命以行其可止乎既至金知其兵已举殊不</span>  
<span style="margin-left: 1em">为屈金人不说及还中道羁留且半年至涿州新城与</span>  
<span style="margin-left: 1em">斡离不遇遣人约相见肤敏长揖而入金人出誓书示</span>  
<span style="margin-left: 1em">之却不视曰远使久不闻朝廷事此书真伪不可知因</span>  
<span style="margin-left: 1em">论用兵事又以语折之几为所留靖康初始还进三官</span>  
<span style="margin-left: 1em">迁吏部员外郎进卫尉少卿建议两河诸郡宜降㼃书</span>  
<span style="margin-left: 1em">许以世袭使各坚守陕西山东淮南诸路并令增陴浚</span>  
<span style="margin-left: 1em">隍徙民入城为清野计命大臣留守汴京车驾早幸江</span>  
<span style="margin-left: 1em">宁帝颇纳之迁起居舍人言陛下򐂜祚之初苟无典刑</span>  
<span style="margin-left: 1em">何以立国凡前日屈节敌人委质伪命者宜差第其罪</span>  
<span style="margin-left: 1em">大则族次则诛又其次窜殛下则斥之远方终身不齿</span>  
<span style="margin-left: 1em">岂可犹𢌿祠禄使尘班列哉拜右谏议大夫兼侍读时</span>  
<span style="margin-left: 1em">高宗欲起用钦宗内侍肤敏言自古帝王未有求阉寺</span>  
<span style="margin-left: 1em">于闲𨓆而用者遂寝后父邢焕除徽猷阁待制太后兄</span>  
<span style="margin-left: 1em">子孟忠厚显谟阁直学士肤敏言非祖宗法焕虽换武</span>  
<span style="margin-left: 1em">职忠厚如故迁肤敏中书舍人肤敏奏曰事母后莫若</span>  
<span style="margin-left: 1em">孝待亲属莫若恩劝臣下莫若赏今陛下顺太母以非</span>  
<span style="margin-left: 1em">法非所谓孝处忠厚以非分非所谓恩不用臣言而迁</span>  
<span style="margin-left: 1em">其官非所谓赏一举而三失矣帝命宰相谕曰朝廷以</span>  
<span style="margin-left: 1em">次迁官非因论事也肤敏犹不拜居家逾月及忠厚改</span>  
<span style="margin-left: 1em">承宣使诏后族勿除从官肤敏始拜命在后省论事为</span>  
<span style="margin-left: 1em">黄潜善汪伯彦所恶因事斥之三年春召赴行在力疾</span>  
<span style="margin-left: 1em">扈跸至临安俄除刑部侍郎未拜谒告归华亭就医许</span>  
<span style="margin-left: 1em">之迁礼部侍郎卒</span>  
<span style="margin-left: 1em">李纲字伯纪梁溪人父夔为华亭尉生纲于官舍政和</span>  
<span style="margin-left: 1em">二年进士官阶政绩俱详宋史绍兴十年卒年五十八</span>  
<span style="margin-left: 1em">赠少师孝宗初谥忠定</span>  
<span style="margin-left: 2em">云间志及溪山余话云华亭县尉厅有相公阁以右</span>  
<span style="margin-left: 2em">文殿修撰李公夔元丰初为尉生大丞相忠定公于</span>  
<span style="margin-left: 2em">此因呼相公阁　国朝用知县赵骥议立祠祀之又</span>  
<span style="margin-left: 2em">读李忠定集有谢知秀州表则忠定又职于此矣</span>  
<span style="margin-left: 2em">叶适李丞相谥忠定议　公自起居郎极论都城水</span>  
<span style="margin-left: 2em">灾斥为监当而抗直之声震于天下矣及斡离不来</span>  
<span style="margin-left: 2em">寇在廷茫然将从乘舆以出独公请与执政辨诘遂</span>  
<span style="margin-left: 2em">夺其议力守京师虏以退却然其留割三镇诏书击</span>  
<span style="margin-left: 2em">女真之归而募兵以防其再至皆为同列所排不果</span>  
<span style="margin-left: 2em">用也高宗中兴首命公自辅于是张邦昌以僭逆诛</span>  
<span style="margin-left: 2em">矣先是河北河东录坚守者建议遣张所傅亮往援</span>  
<span style="margin-left: 2em">接之乞幸襄邓以系人心而无走东南使周望傅雱</span>  
<span style="margin-left: 2em">通问二圣而无踵和约时中原尚未溃也公方除京</span>  
<span style="margin-left: 2em">黼乱政渐复祖宗旧法奏请施行数十事事多机要</span>  
<span style="margin-left: 2em">使稍得岁年之须则两河不遂陷而虏不敢复鼓行</span>  
<span style="margin-left: 2em">入内地矣而讐耻固可报也不幸七十五日而罢去</span>  
<span style="margin-left: 2em">迄其后常疏外坎壈虽仅免颠沛而曾不少得其意</span>  
<span style="margin-left: 2em">焉自是祸难百出而南北竟以分裂此为国家惜者</span>  
<span style="margin-left: 2em">所以哀公之志而深悲其相之不终士至有未尝识</span>  
<span style="margin-left: 2em">公面而坐论救公以死彼岂有所顾望用托而然哉</span>  
<span style="margin-left: 2em">盖公之贤自当时市井负贩莫不喜为之道说然而</span>  
<span style="margin-left: 2em">谤公者亦众矣其尤甚者罪公特以计取显位而已</span>  
<span style="margin-left: 2em">京师之祸公实使之呜呼当是之时所谓谋国者岂</span>  
<span style="margin-left: 2em">有他道哉避走而乞和誉贼虏而卑中国尔以避走</span>  
<span style="margin-left: 2em">乞和誉贼虏卑中国之人而议公之得失故其自许</span>  
<span style="margin-left: 2em">为谋详虑密而谓公为畧而疎自以为镇重能消弭</span>  
<span style="margin-left: 2em">而谓公为轻锐而喜事其恬视君父之仇畏死持禄</span>  
<span style="margin-left: 2em">甘为世所贱侮而以公之能尊君以身殉国为人望</span>  
<span style="margin-left: 2em">所属者谓为朋党要结以自荣故主和者非致寇而</span>  
<span style="margin-left: 2em">守京师者为失策矣则公之负谤于时亦其理之所</span>  
<span style="margin-left: 2em">宜得也何足辞哉独有可恨者是非毁誉之相蒙布</span>  
<span style="margin-left: 2em">必至于久而后论定是从古以然者也公之殁五十</span>  
<span style="margin-left: 2em">载矣世之论公者卒未有以大异于前日也何欤孔</span>  
<span style="margin-left: 2em">子曰微管仲吾其被发左衽矣考公之行事而深察</span>  
<span style="margin-left: 2em">其志使要其功烈之所成就则岂有媿于孔子之所</span>  
<span style="margin-left: 2em">称者哉悲夫谨按谥法虑国忘家曰忠安民大虑曰</span>  
<span style="margin-left: 2em">定请以忠定为公谥谨议<sub class="note-yuan">叶水心适集</sub></span>  
<span style="margin-left: 1em">任尽言字元受登绍兴五年进士第生平忠义自负慷</span>  
<span style="margin-left: 1em">慨喜谈时事虽在下位而意气足压万夫秦桧擅权久</span>  
<span style="margin-left: 1em">言路壅塞上召汤鹏举为御史尽言投启贺之数列桧</span>  
<span style="margin-left: 1em">罪状凛凛发上指鹏举袖以白上桧之姻党始尽罢斥</span>  
<span style="margin-left: 1em">去并释赵鼎子汾及李孟坚王之奇听自便人推尽言</span>  
<span style="margin-left: 1em">之功尝通判平江除京西运判改淮东提举钦庙崩尽</span>  
<span style="margin-left: 1em">言率缙绅为位佛宫致哀疏文二通读者感泣谓其义</span>
