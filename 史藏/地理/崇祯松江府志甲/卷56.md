## 崇禎松江府志卷之五十六　畫苑　書評　金石

<span style="margin-left: 3em">畫苑</span>  
<span style="margin-left: 1em">王僧虔論書或以其人可想或以其法可傳夫畫亦然</span>  
<span style="margin-left: 1em">自來善書者必善畫畫法即書法也古之蕭散韻士以</span>  
<span style="margin-left: 1em">此寫其性靈非積數十年精神不行世後人朝吮毫而</span>  
<span style="margin-left: 1em">暮索薦牘適以涴蠒疥壁而已東坡曰退筆如山何足</span>  
<span style="margin-left: 1em">珍讀書萬卷始通神敢以爲畫苑書譜法</span>  
<span style="margin-left: 1em">宣和畫譜云顧野王字希馮七歲讀五經九歲善屬文</span>  
<span style="margin-left: 2em">識天文地理無所不通尤長於畫在梁爲中領軍後</span>  
<span style="margin-left: 2em">宣城王爲揚州刺史野王與瑯琊王褒並爲賓客乃</span>  
<span style="margin-left: 2em">令野王畫古賢命王褒書贊時人稱爲二絶畫草蟲</span>  
<span style="margin-left: 2em">尤工多識草木蟲魚之性詩人之事畫亦野王無聲</span>  
<span style="margin-left: 2em">詩也入陳至皇門侍郎今御府所藏一草蟲圖</span>  
<span style="margin-left: 1em">春明錄云唐顧況攻小筆嘗求知新亭監人詰之曰余</span>  
<span style="margin-left: 2em">要貌海中山耳仍辟畫省王默爲副落筆有可趣山</span>  
<span style="margin-left: 2em">中作云野人愛向山中宿況在葛洪丹井西庭前有</span>  
<span style="margin-left: 2em">箇長松樹半夜子規來上啼<sub class="note-yuan">又</sub>巫峽朝雲暮不歸洞</span>  
<span style="margin-left: 2em">庭春水晴空滿<sub class="note-yuan">又</sub>頽垣化爲陂陸地堪乘舟<sub class="note-yuan">又</sub>大孤</span>  
<span style="margin-left: 2em">山盡小孤出月照洞庭行客船皆點筆爲之圖</span>  
<span style="margin-left: 1em">張志和號烟波子常漁釣於洞庭湖顔魯公典吳興知</span>  
<span style="margin-left: 2em">其高節以漁歌五首贈之張迺隨句傳像人物舟舩</span>  
<span style="margin-left: 2em">烟波風月鳥獸皆依其文寫之曲盡其妙</span>  
<span style="margin-left: 2em">董玄宰題云宋時名手如巨然李范諸公皆有漁樂</span>  
<span style="margin-left: 2em">圖此起於烟波釣徒張志和蓋顔魯公贈志和詩而</span>  
<span style="margin-left: 2em">志和自爲畫此唐勝事後人蒙之多寓意漁隱耳元</span>  
<span style="margin-left: 2em">季尤多蓋四大家皆在江南葭菼間習知漁釣之趣</span>  
<span style="margin-left: 2em">故也<sub class="note-yuan">張志和畫漁翁夜傍西巖宿詩</sub></span>  
<span style="margin-left: 1em">春渚紀聞云朱象先少時畫筆常恨無前人深遠潤澤</span>  
<span style="margin-left: 2em">之趣一日於鵝溪絹上作小山覺不如意急湔去之</span>  
<span style="margin-left: 2em">故墨再三揮染即有悟見自後作畫多再滌去或以</span>  
<span style="margin-left: 2em">細石磨絹要令墨色着入絹縷者沈珪道人作墨亦</span>  
<span style="margin-left: 2em">嘗因搗和墨蒸去故膠再入新膠及出灰池而墨堅</span>  
<span style="margin-left: 2em">如石遂悟李氏對膠法可謂精藝同理</span>  
<span style="margin-left: 1em">華亭李甲寫花鳥靈氣生動蘇東坡嘗題其畫雁晁補</span>  
<span style="margin-left: 2em">之和曰畫寫物外形要物外不改詩傳畫外意貴有</span>  
<span style="margin-left: 2em">畫中態我今豈見畫觀詩雁真在尚想高郵間湖寒</span>  
<span style="margin-left: 2em">沙璀璀冰霜已凌厲藻荇良瑣碎衡陽渺何處中沚</span>  
<span style="margin-left: 2em">若烟海又云蕭條新河秋霜落洲渚潔蓮垂蘭杜死</span>  
<span style="margin-left: 2em">菖蒲見深節慘澹沙礫姿清波侣群鴨往時吳興守</span>  
<span style="margin-left: 2em">看畫境苕霅爲儀尚不污孤高比雲月聞在雪堂時</span>  
<span style="margin-left: 2em">滿堂唯畫雪</span>  
<span style="margin-left: 2em">蘇東坡題李甲畫云聞說神仙郭恕先醉中狂筆勢</span>  
<span style="margin-left: 2em">瀾翻百年寥落何人在只有華亭李景元</span>  
<span style="margin-left: 1em">雲間陶叔彬解丹青精理自有畫帙題曰無聲詩意楊</span>  
<span style="margin-left: 2em">鐵崖題曰東坡以詩爲有聲畫畫爲無聲詩蓋詩者</span>  
<span style="margin-left: 2em">心聲畫者心畫二者同體也故能詩者必知畫而能</span>  
<span style="margin-left: 2em">畫者多知詩叔彬名畫以詩意不惟知畫其知詩矣</span>  
<span style="margin-left: 2em">詩之弊至宋末而極我朝詩人往往造盛唐之選不</span>  
<span style="margin-left: 2em">極乎晉魏漢楚不止也畫亦然</span>  
<span style="margin-left: 1em">張觀字可觀華亭風涇人少游江湖志尚古雅工畫山</span>  
<span style="margin-left: 2em">水師夏圭馬遠及見盛懋丁野夫而與吳仲圭游故</span>  
<span style="margin-left: 2em">其筆力古勁無俗弱之氣尤善鑒別古器書畫物元</span>  
<span style="margin-left: 2em">末徒嘉興洪武中寓長洲之周莊</span>  
<span style="margin-left: 2em">可觀有釣雪亭圖其筆意清遠展玩間覺清寒逼人</span>  
<span style="margin-left: 2em">萬玉清秋圖華亭張可觀作此魯昌言別墅也中有</span>  
<span style="margin-left: 2em">菊坡梧桐修竹諸景濃淡疎密絶有韵致世共寶之</span>  
<span style="margin-left: 2em">張可觀學馬遠張子政學黃大癡筆墨皆是但不化</span>  
<span style="margin-left: 2em">耳朱孟辨張以文畫山水亦好然只是游戲未必精</span>  
<span style="margin-left: 2em">到</span>  
<span style="margin-left: 1em">張遠號梅巖華亭人善畫山水人物學夏圭馬遠潛補</span>  
<span style="margin-left: 2em">古畫無出其右臨模亦能亂真</span>  
<span style="margin-left: 1em">元任仁發字子明號山月道人世居松之青龍鎮年十</span>  
<span style="margin-left: 2em">八中鄉試二都水監開江置閘凡水議皆仁發主之</span>  
<span style="margin-left: 2em">善繪事嘗奉旨入內畫渥洼天馬圖今人稱任水監</span>  
<span style="margin-left: 2em">畫馬蓋以藝掩云</span>  
<span style="margin-left: 2em">王逢題任山月少監職貢圖云好風東來快雨俱天</span>  
<span style="margin-left: 2em">須亭觀職貢圖厥首高鼻深目胡冠插翟尾服繡襦</span>  
<span style="margin-left: 2em">革帶鞮鞻貂襜褕左女執盞右執壺手容恭如下大</span>  
<span style="margin-left: 2em">夫酋妻髻椎將湛盧五采雜珮相縈紆轉顧飛虎飛</span>  
<span style="margin-left: 2em">龍旟鎪耳者殿帕首驅瓔珞袒跣兩侏儒一擎木難</span>  
<span style="margin-left: 2em">珊瑚株一戴五堟狻猊鑪神獒髬髵狀乳貙復誰牽</span>  
<span style="margin-left: 2em">之鬈𩬊須最後峩弁飾寶珠若將入朝謹進趨秃奚</span>  
<span style="margin-left: 2em">踉蹡亦在途錦膊驄帶汗血駒尊貴卑賤各爾殊經</span>  
<span style="margin-left: 2em">營意匠窮錙銖唐稱二閻道元吳今也少監稱京都</span>  
<span style="margin-left: 2em">少監材抱豈畫史禹跡曾爲帝親理河伯川后備任</span>  
<span style="margin-left: 2em">使無支祈氏甘胥靡大德延後貞觀比輦陸航海填</span>  
<span style="margin-left: 2em">筐篚鳥言夷面遠能邇少監臨古不無已趙公商公</span>  
<span style="margin-left: 2em">暨高李頡頏霄漢嗟已矣霱雲曙開儼斧扆包茅不</span>  
<span style="margin-left: 2em">入顙誰泚周官大書王會禮安得臣臣奉天紀陋儒</span>  
<span style="margin-left: 2em">作歌歌正始</span>  
<span style="margin-left: 1em">馬文璧太守寓居泖濱從鐵崖楊公授春秋工詩與書</span>  
<span style="margin-left: 2em">畫每遇佳山水必託之毫素有董北苑米南宫之法</span>  
<span style="margin-left: 2em">輒自題其左時號三絶</span>  
<span style="margin-left: 2em">貝瓊題馬文璧畫云龍江今喜對雁蕩昔曾聞樹黑</span>  
<span style="margin-left: 2em">深藏雨山晴半出雲行人知虎跡仙客問羊群老我</span>  
<span style="margin-left: 2em">成何日林泉定許分<sub class="note-yuan">又</sub>小橋危跨壑破壁幸依山避</span>  
<span style="margin-left: 2em">地人相過朝天客未還麝眠春草外猿掛古松間寂</span>  
<span style="margin-left: 2em">寞南窗月殘書亦久閑</span>  
<span style="margin-left: 2em">仲琚題畫贈馬文璧云長憶秦溪馬文璧能詩能畫</span>  
<span style="margin-left: 2em">最風流酒酣落筆皆天趣剪斷巴江萬里秋<sub class="note-yuan">又</sub>田家</span>  
<span style="margin-left: 2em">一簇江南路草閣柴扉近水開人背夕陽巫峽去雁</span>  
<span style="margin-left: 2em">將秋色洞庭來</span>  
<span style="margin-left: 1em">曹知白字貞素號雲西華亭人畫山水師馮覲筆墨差</span>  
<span style="margin-left: 2em">弱而清氣可愛有僕夏汲清亦能畫</span>  
<span style="margin-left: 2em">筆叢云松江曹雲西善詩畫家貲富盛而文采有餘</span>  
<span style="margin-left: 2em">嘗築臺以錫塗之月夜擕客痛飲稱瑶臺云或醉後</span>  
<span style="margin-left: 2em">灑翰或秉燭揮毫有旁若無人之意時惟常州倪雲</span>  
<span style="margin-left: 2em">林崑山顧仲瑛可相伯仲</span>  
<span style="margin-left: 2em">王逢題曹雲西山水云世治多福人時危多貴人貴</span>  
<span style="margin-left: 2em">人乃鬼朴福人真天民緬憶曹雲西生死太平辰高</span>  
<span style="margin-left: 2em">秋下孤鶴想見美風神菀菀露櫸間幽幽水石濱槳</span>  
<span style="margin-left: 2em">打甫里船角墊林宗巾往訪趙松雪滿載九峯春斯</span>  
<span style="margin-left: 2em">圖作何年援筆爲慨呻池廢餘野鴇井渫摇青蘋</span>  
<span style="margin-left: 2em">倪元鎮題曹雲西畫云吳淞江水碧於藍怪石喬柯</span>  
<span style="margin-left: 2em">在渚南鼓柁長吟採蘋去新晴風日更清酣</span>  
<span style="margin-left: 2em">太平清話云曹雲西有霽雪圖傍題云老雲爲敬之</span>  
<span style="margin-left: 2em">作</span>  
<span style="margin-left: 2em">倪元鎮題曹雲西畫松石詩云雲西老人子曹子畫</span>  
<span style="margin-left: 2em">手遠師韋與李衡門晝卷春長閑彩毫動處雄風起</span>  
<span style="margin-left: 2em">葉藏戈法枝如籀蒼石庚庚横玉理庭前落月滿長</span>  
<span style="margin-left: 2em">松影落吳淞半江水</span>  
<span style="margin-left: 2em">松事叢說云吾松善畫者在勝國時莫過曹雲西其</span>  
<span style="margin-left: 2em">平遠法李成山水師郭熙蓋郭亦本之李成也筆墨</span>  
<span style="margin-left: 2em">清潤全無俗氣張梅巖畫尊者得吳道子筆法任水</span>  
<span style="margin-left: 2em">監畫馬有龍眠遺意此三人傳派最正可稱</span>  
<span style="margin-left: 1em">沈月溪華亭青村人以綾作爲業畫山水人物學馬遠</span>  
<span style="margin-left: 2em">往往亂真人莫能辨</span>  
<span style="margin-left: 1em">瞿睿夫名智松江人博學善詩以書法鈎勒蘭花妙絶</span>  
<span style="margin-left: 2em">爲太史黃溍提學段天祐編修李孝光外史張伯雨</span>  
<span style="margin-left: 2em">所友重累遷文學官攝紹興錄判尋棄官去昔人稱</span>  
<span style="margin-left: 2em">其畫蘭云我夢陪群仙凥輪神爲馬咀秀蒼梧吟集</span>  
<span style="margin-left: 2em">芳洞庭野水雲秋澹泞月露夜清灑畫者何如人沖</span>  
<span style="margin-left: 2em">心良獨寫</span>  
<span style="margin-left: 1em">僧時溥字君澤號兩岩華亭人居奉賢鄉接待寺通經</span>  
<span style="margin-left: 2em">律作詩亦畫墨竹三稍五葉而已</span>  
<span style="margin-left: 1em">黃子久公望自號大癡畫宗董巨自成一家寓居松江</span>  
<span style="margin-left: 2em">從遊者無虛日嘗寫山水訣示沈生瑞</span>  
<span style="margin-left: 2em">王逢題黃大癡山水云十年不見黃大癡筆鋒墨瀋</span>  
<span style="margin-left: 2em">元氣垂絶壁雙巑萬古鐵長松離立五丈旗蜀江巫</span>  
<span style="margin-left: 2em">峽動溟涬陰嵐夜束魚龍吟峨眉更插空青間差似</span>  
<span style="margin-left: 2em">胸中之耿耿大癡與我忘年交高視河嶽同兒曹天</span>  
<span style="margin-left: 2em">寒歲晚鴻鵠遠風雨草樹餘蕭騷風雨草樹餘蕭騷</span>  
<span style="margin-left: 2em">大癡真是人中豪</span>  
<span style="margin-left: 2em">又簡大癡十年松上築仙關猿鶴如童守大還故舊</span>  
<span style="margin-left: 2em">盡騎箕尾去漁樵長共水雲閑吹笙夜半桃花碧倚</span>  
<span style="margin-left: 2em">杖春深竹筍斑顧我丹臺名有在幾時再隱陸機山</span>  
<span style="margin-left: 1em">華亭沈瑞得畫法於大癡道人爲楊鐵崖作君山吹笛</span>  
<span style="margin-left: 2em">圖木石幽潤山水清遠人物器具點綴於毫末者纖</span>  
<span style="margin-left: 2em">妍可喜鐵崖跋其尾云予往年與大癡扁舟東西泖</span>  
<span style="margin-left: 2em">間或乘興涉海抵小金山道人出所製小鐵笛令余</span>  
<span style="margin-left: 2em">吹洞庭曲道人自歌小海和之不知風作水横舟楫</span>  
<span style="margin-left: 2em">揮舞魚龍悲嘯也道人已仙去余猶隨風塵澒洞中</span>  
<span style="margin-left: 2em">便若此境與世相隔今將盡棄人間事追遊洞庭儻</span>  
<span style="margin-left: 2em">老人歌紫藟如道人者出笛懷袖間吾取其與明相</span>  
<span style="margin-left: 2em">和引滿數杯據床三弄遂與紫藟者終隱十二峯瑞</span>  
<span style="margin-left: 2em">能從之否</span>  
<span style="margin-left: 1em">管夫人小貞人畫與文敏争重其畫蘭幽絶題云趙管</span>  
<span style="margin-left: 2em">才高柳絮風水晶宫裏畫幽叢秋來紉作夫君佩笑</span>  
<span style="margin-left: 2em">殺迴文漫自工</span>  
<span style="margin-left: 2em">董玄宰題云管夫人墨竹世多有之余見山廬繡佛</span>  
<span style="margin-left: 2em">圖亦工山水今復見此佛像及小楷皆有法度雖文</span>  
<span style="margin-left: 2em">敏續書數十行無能遠過也白石翁跋筆法不减涪</span>  
<span style="margin-left: 2em">翁垂始當作無始或偶然筆誤耳</span>  
<span style="margin-left: 1em">柯博士九思字敬仲辟華亭尉不就嘗隱華亭善畫墨</span>  
<span style="margin-left: 2em">竹人以重價購之王逢題云奎章博士寫蒼筤葉葉</span>
