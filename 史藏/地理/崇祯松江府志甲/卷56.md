## 崇祯松江府志卷之五十六　画苑　书评　金石

<span style="margin-left: 3em">画苑</span>  
<span style="margin-left: 1em">王僧虔论书或以其人可想或以其法可传夫画亦然</span>  
<span style="margin-left: 1em">自来善书者必善画画法即书法也古之萧散韵士以</span>  
<span style="margin-left: 1em">此写其性灵非积数十年精神不行世后人朝吮毫而</span>  
<span style="margin-left: 1em">暮索荐牍适以涴蠒疥壁而已东坡曰退笔如山何足</span>  
<span style="margin-left: 1em">珍读书万卷始通神敢以为画苑书谱法</span>  
<span style="margin-left: 1em">宣和画谱云顾野王字希冯七岁读五经九岁善属文</span>  
<span style="margin-left: 2em">识天文地理无所不通尤长于画在梁为中领军后</span>  
<span style="margin-left: 2em">宣城王为扬州刺史野王与瑯琊王褒并为宾客乃</span>  
<span style="margin-left: 2em">令野王画古贤命王褒书赞时人称为二绝画草虫</span>  
<span style="margin-left: 2em">尤工多识草木虫鱼之性诗人之事画亦野王无声</span>  
<span style="margin-left: 2em">诗也入陈至皇门侍郎今御府所藏一草虫图</span>  
<span style="margin-left: 1em">春明录云唐顾况攻小笔尝求知新亭监人诘之曰余</span>  
<span style="margin-left: 2em">要貌海中山耳仍辟画省王默为副落笔有可趣山</span>  
<span style="margin-left: 2em">中作云野人爱向山中宿况在葛洪丹井西庭前有</span>  
<span style="margin-left: 2em">个长松树半夜子规来上啼<sub class="note-yuan">又</sub>巫峡朝云暮不归洞</span>  
<span style="margin-left: 2em">庭春水晴空满<sub class="note-yuan">又</sub>颓垣化为陂陆地堪乘舟<sub class="note-yuan">又</sub>大孤</span>  
<span style="margin-left: 2em">山尽小孤出月照洞庭行客船皆点笔为之图</span>  
<span style="margin-left: 1em">张志和号烟波子常渔钓于洞庭湖颜鲁公典吴兴知</span>  
<span style="margin-left: 2em">其高节以渔歌五首赠之张迺随句传像人物舟舩</span>  
<span style="margin-left: 2em">烟波风月鸟兽皆依其文写之曲尽其妙</span>  
<span style="margin-left: 2em">董玄宰题云宋时名手如巨然李范诸公皆有渔乐</span>  
<span style="margin-left: 2em">图此起于烟波钓徒张志和盖颜鲁公赠志和诗而</span>  
<span style="margin-left: 2em">志和自为画此唐胜事后人蒙之多寓意渔隐耳元</span>  
<span style="margin-left: 2em">季尤多盖四大家皆在江南葭菼间习知渔钓之趣</span>  
<span style="margin-left: 2em">故也<sub class="note-yuan">张志和画渔翁夜傍西岩宿诗</sub></span>  
<span style="margin-left: 1em">春渚纪闻云朱象先少时画笔常恨无前人深远润泽</span>  
<span style="margin-left: 2em">之趣一日于鹅溪绢上作小山觉不如意急湔去之</span>  
<span style="margin-left: 2em">故墨再三挥染即有悟见自后作画多再涤去或以</span>  
<span style="margin-left: 2em">细石磨绢要令墨色着入绢缕者沈珪道人作墨亦</span>  
<span style="margin-left: 2em">尝因捣和墨蒸去故胶再入新胶及出灰池而墨坚</span>  
<span style="margin-left: 2em">如石遂悟李氏对胶法可谓精艺同理</span>  
<span style="margin-left: 1em">华亭李甲写花鸟灵气生动苏东坡尝题其画雁晁补</span>  
<span style="margin-left: 2em">之和曰画写物外形要物外不改诗传画外意贵有</span>  
<span style="margin-left: 2em">画中态我今岂见画观诗雁真在尚想高邮间湖寒</span>  
<span style="margin-left: 2em">沙璀璀冰霜已凌厉藻荇良琐碎衡阳渺何处中沚</span>  
<span style="margin-left: 2em">若烟海又云萧条新河秋霜落洲渚洁莲垂兰杜死</span>  
<span style="margin-left: 2em">菖蒲见深节惨澹沙砾姿清波侣群鸭往时吴兴守</span>  
<span style="margin-left: 2em">看画境苕霅为仪尚不污孤高比云月闻在雪堂时</span>  
<span style="margin-left: 2em">满堂唯画雪</span>  
<span style="margin-left: 2em">苏东坡题李甲画云闻说神仙郭恕先醉中狂笔势</span>  
<span style="margin-left: 2em">澜翻百年寥落何人在只有华亭李景元</span>  
<span style="margin-left: 1em">云间陶叔彬解丹青精理自有画帙题曰无声诗意杨</span>  
<span style="margin-left: 2em">铁崖题曰东坡以诗为有声画画为无声诗盖诗者</span>  
<span style="margin-left: 2em">心声画者心画二者同体也故能诗者必知画而能</span>  
<span style="margin-left: 2em">画者多知诗叔彬名画以诗意不惟知画其知诗矣</span>  
<span style="margin-left: 2em">诗之弊至宋末而极我朝诗人往往造盛唐之选不</span>  
<span style="margin-left: 2em">极乎晋魏汉楚不止也画亦然</span>  
<span style="margin-left: 1em">张观字可观华亭风泾人少游江湖志尚古雅工画山</span>  
<span style="margin-left: 2em">水师夏圭马远及见盛懋丁野夫而与吴仲圭游故</span>  
<span style="margin-left: 2em">其笔力古劲无俗弱之气尤善鉴别古器书画物元</span>  
<span style="margin-left: 2em">末徒嘉兴洪武中寓长洲之周庄</span>  
<span style="margin-left: 2em">可观有钓雪亭图其笔意清远展玩间觉清寒逼人</span>  
<span style="margin-left: 2em">万玉清秋图华亭张可观作此鲁昌言别墅也中有</span>  
<span style="margin-left: 2em">菊坡梧桐修竹诸景浓淡疎密绝有韵致世共宝之</span>  
<span style="margin-left: 2em">张可观学马远张子政学黄大痴笔墨皆是但不化</span>  
<span style="margin-left: 2em">耳朱孟辨张以文画山水亦好然只是游戏未必精</span>  
<span style="margin-left: 2em">到</span>  
<span style="margin-left: 1em">张远号梅岩华亭人善画山水人物学夏圭马远潜补</span>  
<span style="margin-left: 2em">古画无出其右临模亦能乱真</span>  
<span style="margin-left: 1em">元任仁发字子明号山月道人世居松之青龙镇年十</span>  
<span style="margin-left: 2em">八中乡试二都水监开江置闸凡水议皆仁发主之</span>  
<span style="margin-left: 2em">善绘事尝奉旨入内画渥洼天马图今人称任水监</span>  
<span style="margin-left: 2em">画马盖以艺掩云</span>  
<span style="margin-left: 2em">王逢题任山月少监职贡图云好风东来快雨俱天</span>  
<span style="margin-left: 2em">须亭观职贡图厥首高鼻深目胡冠插翟尾服绣襦</span>  
<span style="margin-left: 2em">革带鞮鞻貂襜褕左女执盏右执壶手容恭如下大</span>  
<span style="margin-left: 2em">夫酋妻髻椎将湛卢五采杂珮相萦纡转顾飞虎飞</span>  
<span style="margin-left: 2em">龙旟锼耳者殿帕首驱璎珞袒跣两侏儒一擎木难</span>  
<span style="margin-left: 2em">珊瑚株一戴五堟狻猊𬬻神獒髬髵状乳䝙复谁牵</span>  
<span style="margin-left: 2em">之鬈𩬊须最后峩弁饰宝珠若将入朝谨进趋秃奚</span>  
<span style="margin-left: 2em">踉蹡亦在途锦膊骢带汗血驹尊贵卑贱各尔殊经</span>  
<span style="margin-left: 2em">营意匠穷锱铢唐称二阎道元吴今也少监称京都</span>  
<span style="margin-left: 2em">少监材抱岂画史禹迹曾为帝亲理河伯川后备任</span>  
<span style="margin-left: 2em">使无支祈氏甘胥靡大德延后贞观比辇陆航海填</span>  
<span style="margin-left: 2em">筐篚鸟言夷面远能迩少监临古不无已赵公商公</span>  
<span style="margin-left: 2em">暨高李颉颃霄汉嗟已矣霱云曙开俨斧扆包茅不</span>  
<span style="margin-left: 2em">入颡谁泚周官大书王会礼安得臣臣奉天纪陋儒</span>  
<span style="margin-left: 2em">作歌歌正始</span>  
<span style="margin-left: 1em">马文璧太守寓居泖滨从铁崖杨公授春秋工诗与书</span>  
<span style="margin-left: 2em">画每遇佳山水必托之毫素有董北苑米南宫之法</span>  
<span style="margin-left: 2em">辄自题其左时号三绝</span>  
<span style="margin-left: 2em">贝琼题马文璧画云龙江今喜对雁荡昔曾闻树黑</span>  
<span style="margin-left: 2em">深藏雨山晴半出云行人知虎迹仙客问羊群老我</span>  
<span style="margin-left: 2em">成何日林泉定许分<sub class="note-yuan">又</sub>小桥危跨壑破壁幸依山避</span>  
<span style="margin-left: 2em">地人相过朝天客未还麝眠春草外猿挂古松间寂</span>  
<span style="margin-left: 2em">寞南窗月残书亦久闲</span>  
<span style="margin-left: 2em">仲琚题画赠马文璧云长忆秦溪马文璧能诗能画</span>  
<span style="margin-left: 2em">最风流酒酣落笔皆天趣剪断巴江万里秋<sub class="note-yuan">又</sub>田家</span>  
<span style="margin-left: 2em">一簇江南路草阁柴扉近水开人背夕阳巫峡去雁</span>  
<span style="margin-left: 2em">将秋色洞庭来</span>  
<span style="margin-left: 1em">曹知白字贞素号云西华亭人画山水师冯觐笔墨差</span>  
<span style="margin-left: 2em">弱而清气可爱有仆夏汲清亦能画</span>  
<span style="margin-left: 2em">笔丛云松江曹云西善诗画家赀富盛而文采有余</span>  
<span style="margin-left: 2em">尝筑台以锡涂之月夜擕客痛饮称瑶台云或醉后</span>  
<span style="margin-left: 2em">洒翰或秉烛挥毫有旁若无人之意时惟常州倪云</span>  
<span style="margin-left: 2em">林昆山顾仲瑛可相伯仲</span>  
<span style="margin-left: 2em">王逢题曹云西山水云世治多福人时危多贵人贵</span>  
<span style="margin-left: 2em">人乃鬼朴福人真天民缅忆曹云西生死太平辰高</span>  
<span style="margin-left: 2em">秋下孤鹤想见美风神菀菀露榉间幽幽水石滨桨</span>  
<span style="margin-left: 2em">打甫里船角垫林宗巾往访赵松雪满载九峰春斯</span>  
<span style="margin-left: 2em">图作何年援笔为慨呻池废余野鸨井渫摇青苹</span>  
<span style="margin-left: 2em">倪元镇题曹云西画云吴淞江水碧于蓝怪石乔柯</span>  
<span style="margin-left: 2em">在渚南鼓柁长吟采苹去新晴风日更清酣</span>  
<span style="margin-left: 2em">太平清话云曹云西有霁雪图傍题云老云为敬之</span>  
<span style="margin-left: 2em">作</span>  
<span style="margin-left: 2em">倪元镇题曹云西画松石诗云云西老人子曹子画</span>  
<span style="margin-left: 2em">手远师韦与李衡门昼卷春长闲彩毫动处雄风起</span>  
<span style="margin-left: 2em">叶藏戈法枝如籀苍石庚庚横玉理庭前落月满长</span>  
<span style="margin-left: 2em">松影落吴淞半江水</span>  
<span style="margin-left: 2em">松事丛说云吾松善画者在胜国时莫过曹云西其</span>  
<span style="margin-left: 2em">平远法李成山水师郭熙盖郭亦本之李成也笔墨</span>  
<span style="margin-left: 2em">清润全无俗气张梅岩画尊者得吴道子笔法任水</span>  
<span style="margin-left: 2em">监画马有龙眠遗意此三人传派最正可称</span>  
<span style="margin-left: 1em">沈月溪华亭青村人以绫作为业画山水人物学马远</span>  
<span style="margin-left: 2em">往往乱真人莫能辨</span>  
<span style="margin-left: 1em">瞿睿夫名智松江人博学善诗以书法钩勒兰花妙绝</span>  
<span style="margin-left: 2em">为太史黄溍提学段天祐编修李孝光外史张伯雨</span>  
<span style="margin-left: 2em">所友重累迁文学官摄绍兴录判寻弃官去昔人称</span>  
<span style="margin-left: 2em">其画兰云我梦陪群仙凥轮神为马咀秀苍梧吟集</span>  
<span style="margin-left: 2em">芳洞庭野水云秋澹泞月露夜清洒画者何如人冲</span>  
<span style="margin-left: 2em">心良独写</span>  
<span style="margin-left: 1em">僧时溥字君泽号两岩华亭人居奉贤乡接待寺通经</span>  
<span style="margin-left: 2em">律作诗亦画墨竹三稍五叶而已</span>  
<span style="margin-left: 1em">黄子久公望自号大痴画宗董巨自成一家寓居松江</span>  
<span style="margin-left: 2em">从游者无虚日尝写山水诀示沈生瑞</span>  
<span style="margin-left: 2em">王逢题黄大痴山水云十年不见黄大痴笔锋墨沈</span>  
<span style="margin-left: 2em">元气垂绝壁双巑万古铁长松离立五丈旗蜀江巫</span>  
<span style="margin-left: 2em">峡动溟涬阴岚夜束鱼龙吟峨眉更插空青间差似</span>  
<span style="margin-left: 2em">胸中之耿耿大痴与我忘年交高视河岳同儿曹天</span>  
<span style="margin-left: 2em">寒岁晚鸿鹄远风雨草树余萧骚风雨草树余萧骚</span>  
<span style="margin-left: 2em">大痴真是人中豪</span>  
<span style="margin-left: 2em">又简大痴十年松上筑仙关猿鹤如童守大还故旧</span>  
<span style="margin-left: 2em">尽骑箕尾去渔樵长共水云闲吹笙夜半桃花碧倚</span>  
<span style="margin-left: 2em">杖春深竹笋斑顾我丹台名有在几时再隐陆机山</span>  
<span style="margin-left: 1em">华亭沈瑞得画法于大痴道人为杨铁崖作君山吹笛</span>  
<span style="margin-left: 2em">图木石幽润山水清远人物器具点缀于毫末者纤</span>  
<span style="margin-left: 2em">妍可喜铁崖跋其尾云予往年与大痴扁舟东西泖</span>  
<span style="margin-left: 2em">间或乘兴涉海抵小金山道人出所制小铁笛令余</span>  
<span style="margin-left: 2em">吹洞庭曲道人自歌小海和之不知风作水横舟楫</span>  
<span style="margin-left: 2em">挥舞鱼龙悲啸也道人已仙去余犹随风尘澒洞中</span>  
<span style="margin-left: 2em">便若此境与世相隔今将尽弃人间事追游洞庭傥</span>  
<span style="margin-left: 2em">老人歌紫藟如道人者出笛怀袖间吾取其与明相</span>  
<span style="margin-left: 2em">和引满数杯据床三弄遂与紫藟者终隐十二峰瑞</span>  
<span style="margin-left: 2em">能从之否</span>  
<span style="margin-left: 1em">管夫人小贞人画与文敏争重其画兰幽绝题云赵管</span>  
<span style="margin-left: 2em">才高柳絮风水晶宫里画幽丛秋来纫作夫君佩笑</span>  
<span style="margin-left: 2em">杀回文漫自工</span>  
<span style="margin-left: 2em">董玄宰题云管夫人墨竹世多有之余见山庐绣佛</span>  
<span style="margin-left: 2em">图亦工山水今复见此佛像及小楷皆有法度虽文</span>  
<span style="margin-left: 2em">敏续书数十行无能远过也白石翁跋笔法不减涪</span>  
<span style="margin-left: 2em">翁垂始当作无始或偶然笔误耳</span>
