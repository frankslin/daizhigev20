## 崇禎松江府志卷之二十四　學政下

<span style="margin-left: 3em">學政<sub class="note-yuan">二</sub></span>  
<span style="margin-left: 2em">華亭縣學</span>  
<span style="margin-left: 1em">縣學在府西南徐家橋之東邑人徐進義塾也學始建</span>  
<span style="margin-left: 1em">於宋元祐中在今府學後玉帶河之陽尊賢坊內即今</span>  
<span style="margin-left: 1em">射圃魁星樓地端平間遷於河南以其址爲閲武亭及</span>  
<span style="margin-left: 1em">學陞府學復建縣學於舊址<sub class="note-yuan">按楊維禎至正九年記縣學本燕居之所則閲武嘗爲燕居周伯琦府學記十九年作燕居堂於學北不言舊爲閲武</sub>元至大初劉尹慶建</span>  
<span style="margin-left: 1em">夫子廟延祐間張尹國英搆講堂至正中楚尹恭張尹</span>  
<span style="margin-left: 1em">德昭繼爲繕理而學乃粗備丙申燬於兵以其地爲學</span>  
<span style="margin-left: 1em">射圃</span>  
<span style="margin-left: 2em">至正九年重修學記　華亭縣學在府治東南二百</span>  
<span style="margin-left: 2em">步按前志繇宋端平縣令楊公瑾之所開拓堂殿齋</span>  
<span style="margin-left: 2em">舍廊廡庖廥始具焉至　國朝縣陞松江府學亦陞</span>  
<span style="margin-left: 2em">府學土田儒籍皆隸之縣復立頖宫於府庠北舊燕</span>  
<span style="margin-left: 2em">居之所也至大初劉某來典邑始搆大成殿并儀門</span>  
<span style="margin-left: 2em">兩廡延祐己未令張國英復搆講堂及設祭噐至正</span>  
<span style="margin-left: 2em">癸未縣令楚恭修櫺星門繚以崇墉而學之規稍完</span>  
<span style="margin-left: 2em">歷年未久而棟宇有弗支者其址尚湫隘周旋升降</span>  
<span style="margin-left: 2em">有弗堪者至正九年春縣長養安海涯縣令張德昭</span>  
<span style="margin-left: 2em">釋菜之際惕然相謂曰學較教之出守令教之行學</span>  
<span style="margin-left: 2em">較廢何以資守令之理乎命教諭王倫謀更作之而</span>  
<span style="margin-left: 2em">費未知所出乃告丞簿帖木兒不花兀都馬沙俾諭</span>  
<span style="margin-left: 2em">邑士願新學較者聽於是澱山謝庭蘭與其姪晉併</span>  
<span style="margin-left: 2em">力從事經始於是年之二月閲三月而告成大成殿</span>  
<span style="margin-left: 2em">增闢後室殿之側剙學官廨又前後築石塘以捍水</span>  
<span style="margin-left: 2em">蝕齧於是凡柱石之欹傾者正之椽櫚之朽蠧者易</span>  
<span style="margin-left: 2em">之丹青之漫漶者飾之下及庾庫庖湢什伯之具無</span>  
<span style="margin-left: 2em">不完整既竣事乃伐石以二侯之命徵記於余余嘗</span>  
<span style="margin-left: 2em">悼井牧閭師之廢而先王之教廢後之爲治者亦難</span>  
<span style="margin-left: 2em">矣貧富相縣雖使臯陶持刑不能禁彊不侮弱倫理</span>  
<span style="margin-left: 2em">弗明雖使姬旦制禮不能革賤不僣貴此非教何賴</span>  
<span style="margin-left: 2em">哉故朝廷以六事命守令而教爲之首然而不知治</span>  
<span style="margin-left: 2em">本者視學較如眡傳舍其教民者無實政已職教者</span>  
<span style="margin-left: 2em">又素非冠帶之望其佐令者無實教已士之在上者</span>  
<span style="margin-left: 2em">既無躬行實履在下者又可責其有實學乎令無實</span>  
<span style="margin-left: 2em">政師無實教士無實學而望風俗之美人才之興不</span>  
<span style="margin-left: 2em">亦難乎華亭古號文物之邦而其地卑下沮洳民性</span>  
<span style="margin-left: 2em">輕戾而媮靡易叛於教今邑侯以興學較爲先務師</span>  
<span style="margin-left: 2em">儒以作成士類爲急功邑之人士又能不負循令長</span>  
<span style="margin-left: 2em">賢師儒教養爲實學吾見華亭復舊時文物之盛而</span>  
<span style="margin-left: 2em">無其輕戾媮靡之風且使他邑於是乎勸禮令之得</span>  
<span style="margin-left: 2em">治名者不在是乎不在是乎遂以復二侯俾刻爲記</span>  
<span style="margin-left: 2em">是年五月楊維禎記</span>  
<span style="margin-left: 1em">國朝洪武庚戌知縣馮榮奉　詔立學始即義塾爲之</span>  
<span style="margin-left: 1em">甲寅知縣周朗新作大成殿嗣令視子憲以學舍卑陋</span>  
<span style="margin-left: 1em">廓而新之邑人徐進子彦裕力任其事於是明倫觀頤</span>  
<span style="margin-left: 1em">二堂博文約禮二齋繚垣翼室習射之圃凡學之制悉</span>  
<span style="margin-left: 1em">備丙辰知縣朱直新教官廨名其堂曰知本丁卯大成</span>  
<span style="margin-left: 1em">殿壞御史黃克庸新之仍建文昌祠於戟門之右永樂</span>  
<span style="margin-left: 1em">丙申學舍壞於風雨丁酉知縣高宫重修宣德丙午大</span>  
<span style="margin-left: 1em">理卿胡槩改作明倫堂復爲堂於其後榜曰進修正統</span>  
<span style="margin-left: 1em">己未推官楊政重建大成殿新戟門及兩廡庚申提學</span>  
<span style="margin-left: 1em">御史彭朂闢射圃於學東隙地<sub class="note-yuan">先是改舊圃以爲董漕</sub>癸亥知縣</span>  
<span style="margin-left: 1em">李希容建觀德亭教諭程完義訓導胡穗趙建相其役</span>  
<span style="margin-left: 1em">成化壬辰知縣戴冕修殿廊飾聖賢像重作明倫堂及</span>  
<span style="margin-left: 1em">齋門廡撤觀頤堂而徙觀德亭於其後新教官宅增修</span>  
<span style="margin-left: 1em">號舍二十有五間學三面緣河皆甃以石爲石闌於其</span>  
<span style="margin-left: 1em">南東西跨河爲亭曰希顔曰志尹立科舉題名於儀門</span>  
<span style="margin-left: 1em">且爲之記弘治庚戌知縣汪宣因戴舊規而增葺之撤</span>  
<span style="margin-left: 1em">興賢育才二坊而建以石於中爲石梁跨河而南爲泮</span>  
<span style="margin-left: 1em">宫坊坊之南爲亭重簷八觚顔之曰聚奎科貢題名其</span>  
<span style="margin-left: 1em">上其南爲泮池池外有積水五泓左右爲外號繚以周</span>  
<span style="margin-left: 1em">垣環植檜栢自遷學以來增拓凡六至戴而規制始宏</span>  
<span style="margin-left: 1em">至是而大備甲寅知府陳讓建崇文閣於講堂後<sub class="note-yuan">其址故進修堂也</sub>嗣政劉琬復射圃於學之東中開廣術徹於横街</span>  
<span style="margin-left: 1em">曰鴻逵於是弘敞壯麗甲於他邑矣</span>  
<span style="margin-left: 2em">曹睿新學記　華亭舊學在今府治之南自元至元</span>  
<span style="margin-left: 2em">間縣陞爲府學亦隸焉繇是改燕居堂爲縣學後厄</span>  
<span style="margin-left: 2em">於兵燹今之學則徐氏義塾也初縣人徐進始創於</span>  
<span style="margin-left: 2em">縣南割私田一萬畝有奇招延明師以淑里子弟西</span>  
<span style="margin-left: 2em">建大成殿堂廡戟門春秋祀先聖先師至我　朝始</span>  
<span style="margin-left: 2em">更爲縣學及教諭束宗癸訓導胡鉉金聲朱武李象</span>  
<span style="margin-left: 2em">賢相繼至修廢舉墜思作新未就洪武七年春郡守</span>  
<span style="margin-left: 2em">王公文貞祗謁廟庭退而延儒師講經義諸生升揖</span>  
<span style="margin-left: 2em">拜肩摩踵躡不容周旋乃與知縣祝子憲議廓而新</span>  
<span style="margin-left: 2em">之進子彦裕聞而請曰此吾先子志也敢不身任其</span>  
<span style="margin-left: 2em">責郡守嘉而義之於是拓學東地重建明倫堂三間</span>  
<span style="margin-left: 2em">夾以翼室創東西齋重門兩廡繚以周垣高爽明塏</span>  
<span style="margin-left: 2em">輪奂翬飛論講有堂肄業有齋藏修有室與夫習射</span>  
<span style="margin-left: 2em">之宫庖湢之廬靡不畢具未幾知縣朱直來視事學</span>  
<span style="margin-left: 2em">較之事知無不爲作育後進增光前人繇是華亭之</span>  
<span style="margin-left: 2em">學遂甲於他縣矣時教諭曹宗儒訓導錢震謝南萬</span>  
<span style="margin-left: 2em">權實主之董是役者沈文進也予謂學較之興廢關</span>  
<span style="margin-left: 2em">世運之盛衰曩年學廪充溢悉爲游食所蠧職教者</span>  
<span style="margin-left: 2em">鮮有易一椽加一甓者今以枵然之宫而氣象一新</span>  
<span style="margin-left: 2em">如此是雖賢守令之所舉倡徐氏父子之所經營其</span>  
<span style="margin-left: 2em">亦斯文氣運之所關與洪武十年春二月初吉</span>  
<span style="margin-left: 2em">袁凱修殿記　洪武改元我國家平浙西二年詔興</span>  
<span style="margin-left: 2em">天下學較三年知縣馮榮始遷於此而大成殿庳隘</span>  
<span style="margin-left: 2em">弗稱七年知縣周朗始命邑民鄒德方徐均德更新</span>  
<span style="margin-left: 2em">之不數年而圯今年春風雨大作自中棟廡廊一夕</span>  
<span style="margin-left: 2em">傾圯適監察御史臨川黃公克庸至郡展禮廟下顧</span>  
<span style="margin-left: 2em">而歎曰兹非吾之責邪時邑長貳以下咸缺未幾池</span>  
<span style="margin-left: 2em">陽李啓先來主簿即命董其事知府雲南何賜知縣</span>  
<span style="margin-left: 2em">劉均俊相繼至各捐俸以倡而鄉之好義者張示周</span>  
<span style="margin-left: 2em">思誠等亦以貲來助於是鳩工聚材傾昃者正之腐</span>  
<span style="margin-left: 2em">撓者易之覆之甓之塗塈丹雘之至於葺兩廡新文</span>  
<span style="margin-left: 2em">昌祠凡昔未備者今皆完美凡四月訖工諸生俾凱</span>  
<span style="margin-left: 2em">記之凱時以訓導攝學事其敢以荒陋辭竊惟有天</span>  
<span style="margin-left: 2em">下者必設學較崇廟庭然後人心有所係屬如百工</span>  
<span style="margin-left: 2em">之居肆則志不遷而事可成今風紀之司臨蒞於上</span>  
<span style="margin-left: 2em">賢有司倡率於下以致輪焉奂焉睹兹清廟肅瞻聖</span>  
<span style="margin-left: 2em">容有得於觀感之間而興起焉賢才輩出使江海之</span>  
<span style="margin-left: 2em">上藹然有洙泗之風無負國家從來教養之意則自</span>  
<span style="margin-left: 2em">今日始也洪武二十九年九月吉日</span>  
<span style="margin-left: 2em">胡儼重修殿記　洪武戊辰予初典教華亭釋菜之</span>  
<span style="margin-left: 2em">日周覽學宫自殿宇堂齋以至門廡庖廪之所規制</span>  
<span style="margin-left: 2em">整肅締搆完固仰瞻聖殿文彩焕然蓋予未至前訓</span>  
<span style="margin-left: 2em">導李處仁所作袁凱爲之記居六年以內艱去固巋</span>  
<span style="margin-left: 2em">然也自初建立距今五十餘年海濱多颶風雷雨震</span>  
<span style="margin-left: 2em">蕩拔木飄瓦繇是昔之巋然者至敝棟撓梁腐桷墜</span>  
<span style="margin-left: 2em">檐典教事錢塘楊益舜江陳賓廬陵胡穗深以爲憂</span>  
<span style="margin-left: 2em">廬陵楊君惟斆繇監察御史來典松江府刑獄慨然</span>  
<span style="margin-left: 2em">有志更作謀諸郡守趙君於聽訟之際簡閲平民情</span>  
<span style="margin-left: 2em">有可矜法有所疑悉從寬貸俾就於贖積二年凡得</span>  
<span style="margin-left: 2em">材木磚甓若干及工人之費百需之具充乎有餘遂</span>  
<span style="margin-left: 2em">度材庀工經始於正統二年冬十一月落成於四年</span>  
<span style="margin-left: 2em">十月殿之崇高加故十尺深廣各加八尺規模改觀</span>  
<span style="margin-left: 2em">輪奂一新惟斆與學之師徒謂予昔嘗處此求爲之</span>  
<span style="margin-left: 2em">記予惟諸君之從游於斯者肅瞻聖容有所觀感退</span>  
<span style="margin-left: 2em">而致力端其趨向將見道德明秀之士彬彬然胥此</span>  
<span style="margin-left: 2em">焉出庶幾不負朝廷教育之恩守令作興之意惟斆</span>  
<span style="margin-left: 2em">奉揚之美予雖衰老與有光榮引領雲間寸心千里</span>  
<span style="margin-left: 2em">諸君幸朂之</span>  
<span style="margin-left: 2em">錢溥修改廟學記　吾華亭至元陞府以學爲府學</span>  
<span style="margin-left: 2em">其縣學遷於舊址而燬於兵爲府學射圃洪武二年</span>  
<span style="margin-left: 2em">始遷今學蓋奉　聖祖開國之詔也正統間推官吉</span>  
<span style="margin-left: 2em">水楊侯政增葺正殿兩廡允稱而堂齋門道日就朽</span>  
<span style="margin-left: 2em">腐不可復支師生不升立者有年矣成化五年春戴</span>  
<span style="margin-left: 2em">侯來知縣事遂日節廪稍公用之餘重修殿廡及聖</span>  
<span style="margin-left: 2em">賢像講堂褊小廓而增高廣與深倍之兩齋翼然門</span>  
<span style="margin-left: 2em">廊跂然觀德堂舊在堂東今改於殿側公廨二在學</span>  
<span style="margin-left: 2em">外之橋南今鼎立於中門之左增修號房與庖湢庫</span>  
<span style="margin-left: 2em">庾若干間芟其蒙翳甃以磚甓爲岸爲欄爲兩橋咸</span>  
<span style="margin-left: 2em">以石而亭於橋上左曰希顔右曰志尹規模閎壯金</span>  
<span style="margin-left: 2em">碧輝飛於是學諭陳章司訓陸顯袁充請爲記夫華</span>  
<span style="margin-left: 2em">亭遷學已踰百禩而久安於庳陋一旦成於戴侯不</span>  
<span style="margin-left: 2em">謀於上不煩於民焕然宏構傑出於羣望之表異時</span>  
<span style="margin-left: 2em">戴侯稱循於史傳殆於是有徵焉侯名冕字廷章巴</span>  
<span style="margin-left: 2em">縣人舉四川癸酉解試第一成化九年歲在癸巳夏</span>  
<span style="margin-left: 2em">六月朔旦立石</span>  
<span style="margin-left: 2em">徐階修學記　雙江先生永豐聶公知華亭之二年</span>  
<span style="margin-left: 2em">百廢具興上下胥悦乃修學宫葺故創新具有成績</span>  
<span style="margin-left: 2em">天子徵公爲御史又晉公作伯於蘇而於時尚未有</span>  
<span style="margin-left: 2em">刻石己丑春姚江陳君徠以鄉進士乞典學事君之</span>  
<span style="margin-left: 2em">始拜命也階爲言公作學勤導士懇有古循吏之風</span>  
<span style="margin-left: 2em">君嘆且慕久之比至肅瞻廟宇周視黌舍旁稽載籍</span>  
<span style="margin-left: 2em">博詢黃耈謂雙江公之功前此未有也乃相與礱石</span>

<span style="margin-left: 2em">學田</span>  
<span style="margin-left: 2em"><sub class="note-yuan">萬曆三十七年蔭君徐肇惠捐助本縣四十二三保田二百五十畝每年除完糧外浄租一百二十五石請詳學院給散貧生萬曆四十一年巡撫徐發銀二百五十六兩伍錢置買本縣四十六保田一百零五畝三分每年除完糧外浄租七十八石一斗二升四合請詳兩院分給貧生萬曆四十二年商人方良捐助田地一百零六畝每年除完糧外折租銀一十一兩二錢貯學月考支銷</sub></span>  
<span style="margin-left: 2em">金山衛學</span>  
<span style="margin-left: 1em">衛學在衛東北隅篠館街之北正統己未巡撫周忱奏</span>  
<span style="margin-left: 1em">立御史劉福嚴洤劉魁相繼增修弘治戊午指揮翁熊</span>  
<span style="margin-left: 1em">重建大成殿兩廡戟門飾聖賢像壬戌指揮西寧新學</span>  
<span style="margin-left: 1em">門甲子備倭都指揮王憲製文廟祭噐自弘治迄萬曆</span>  
<span style="margin-left: 1em">八十餘年士不登科榜癸巳閩中翁興賢來典學事謀</span>  
<span style="margin-left: 1em">之參將李震請於郡太守柳公希點濬河改闢重建</span>  
<span style="margin-left: 1em">先師廟修學宫掘地得聖像倒埋土中翕然以爲大聖</span>  
<span style="margin-left: 1em">人出現文運其一昌矣甲午旋發科以後科第元魁不</span>  
<span style="margin-left: 1em">絕</span>  
<span style="margin-left: 2em">錢溥廟學記　衛有廟學非古也而古教行焉孔子</span>  
<span style="margin-left: 2em">當諸侯尚武則救之以文曰瑚簋之事則嘗學之當</span>  
<span style="margin-left: 2em">萊兵劫魯則濟之以武曰有文事者必有武備請設</span>  
<span style="margin-left: 2em">左右司馬顧當用者則先之未嘗舉一而廢百此孔</span>  
<span style="margin-left: 2em">子所以備文武之全材體天衷立民極者與後以文</span>  
<span style="margin-left: 2em">廟祀孔子有十哲配武廟祀大公望亦有十哲配文</span>  
<span style="margin-left: 2em">有學學講誦武有學學騎射判爲二塗竟莫能一其</span>  
<span style="margin-left: 2em">能損武祀罷武學而武置文廟學亦未聞焉我　國</span>  
<span style="margin-left: 2em">家君師宇內作養文武士幾八十年自京師暨郡縣</span>  
<span style="margin-left: 2em">學有習射爲武備而尤慮武臣子弟安於熙洽之久</span>  
<span style="margin-left: 2em">動作進退鮮克繇禮英偉間生或局其材於是命天</span>  
<span style="margin-left: 2em">下軍衛立文廟學如郡制典教者亦如郡曰教授而</span>  
<span style="margin-left: 2em">訓導則半之麗郡縣者則從郡縣學教其官之適庶</span>  
<span style="margin-left: 2em">與凡軍士之俊秀登第者隨其材而庸之定爲著令</span>  
<span style="margin-left: 2em">班之天下後世金山距松城七十二里許遵海而居</span>  
<span style="margin-left: 2em">地僻費繁未易營度幸而巡撫廬陵周公提調學較</span>  
<span style="margin-left: 2em">御史吉豐彭公同心輔化而太守保定趙公克相斯</span>  
<span style="margin-left: 2em">舉工善材良不勞而集廟自大成殿兩廡戟門櫺星</span>  
<span style="margin-left: 2em">門學自明倫堂東西序以及賓客之所肄業之室靡</span>  
<span style="margin-left: 2em">不完美采繪焕然一旦斥鹵之境兜鍪之士得被冕</span>  
<span style="margin-left: 2em">服俎豆之化升降揖遜之容而作其親親尊上之心</span>  
<span style="margin-left: 2em">者皆繇三君子起家學較有志文武之業故能祗奉</span>  
<span style="margin-left: 2em">德意於有成毓人才之効於無窮是役也經始於正</span>  
<span style="margin-left: 2em">統五年夏成於次年之冬始終董其事者管衛指揮</span>  
<span style="margin-left: 2em">使劉公請予記其成者衛學訓導陳輿傳鴻介吾郡</span>  
<span style="margin-left: 2em">博孫先生而謂予史職可當紀事者則又出於今提</span>  
<span style="margin-left: 2em">調侍御公云</span>  
<span style="margin-left: 2em">陳鑑修學記　予於金山儒學之記喜其有復古之</span>  
<span style="margin-left: 2em">道也金山之爲衛越在海隅皆以瀕海之人介胄之</span>  
<span style="margin-left: 2em">士武事且未習何以文爲故自有衛以來未嘗建學</span>  
<span style="margin-left: 2em">正統己未巡撫周公忱奏請建學朝廷允之乃相地</span>  
<span style="margin-left: 2em">於衛之東北隅篠館街之北高亢靚深宜教宜習庀</span>  
<span style="margin-left: 2em">材鳩工首建明倫堂仍立居仁由義兩齋與夫師儒</span>  
<span style="margin-left: 2em">居止之地生徒游息之處庖湢庫庾咸有品則維時</span>  
<span style="margin-left: 2em">董督厥事則提學吉豐彭侍御朂經畫修理則松江</span>  
<span style="margin-left: 2em">趙太守豫兹衛揮使劉君惠西君賢貳揮侯君端而</span>  
<span style="margin-left: 2em">興化陳師興實以分教職來與焉於是乎武臣子弟</span>  
<span style="margin-left: 2em">與凡伍符尺籍之秀朗英偉者偕來就學蓋學以始</span>  
<span style="margin-left: 2em">創廟祀闕然正統戊辰建寧劉侍御福以憲節至以</span>  
<span style="margin-left: 2em">爲學而弗廟師何以崇費雖夥弗宜中止凡繫於三</span>  
<span style="margin-left: 2em">尺之下法可疑而情可矜悉聽其贖或金或帛皆輸</span>  
<span style="margin-left: 2em">之學以爲百需之費再踰月而就厥緒迨天順辛巳</span>  
<span style="margin-left: 2em">提學莆田嚴侍御洤宗源至又進民生以增廣之大</span>  
<span style="margin-left: 2em">都督安慶董侯宸尤以興學爲心俾殿堂門廡焕然</span>  
<span style="margin-left: 2em">一新故士之游於其間者靡不争自磨濯文風繇之</span>  
<span style="margin-left: 2em">而丕變士氣繇之而掀騰矣司訓鐔城梁君元礱石</span>  
<span style="margin-left: 2em">請記於戲少司空不以武士爲不可學而始創之大</span>  
<span style="margin-left: 2em">都督不以文學爲可緩而振舉之侍御公尤能防範</span>  
<span style="margin-left: 2em">激勸於其間惡得而弗書</span>  
<span style="margin-left: 2em">錢溥重修廟學記　金山之有廟學自己未抵今成</span>  
<span style="margin-left: 2em">化辛丑歷歲滋久將入於毁監察御史高唐劉公魁</span>  
<span style="margin-left: 2em">巡按至衛與鎮守都帥合肥郭公鋐周覽庠舍亟命</span>  
<span style="margin-left: 2em">掌衛事指揮使西寧暨僉事魏文修葺之教授張濂</span>  
<span style="margin-left: 2em">訓導歐陽法贊助之槩發官帑專命文董治之劉公</span>  
<span style="margin-left: 2em">既滿去而陝右孟公俊繼之復量措使趣爲之廟自</span>  
<span style="margin-left: 2em">大成殿兩廡櫺星門學則重建明倫堂徙舊爲後堂</span>  
<span style="margin-left: 2em">東西兩齋儀門射圃鍾秀育材二坊與夫供祀之所</span>  
<span style="margin-left: 2em">棲士之屋科舉題名之坊昔未備而今始壞者悉與</span>  
<span style="margin-left: 2em">維新金山越在海濱今則有武以捍患有學以興教</span>  
<span style="margin-left: 2em">百餘年來士際此文明之盛當益修文武之業而不</span>  
<span style="margin-left: 2em">失爲全材之用豈惟無負　朝廷作養之厚恩而於</span>  
<span style="margin-left: 2em">諸君子上下協請之盛心則亦有賴矣</span>  
<span style="margin-left: 2em">徐階衛學初置廩膳記　金山衛故有學有師以教</span>  
<span style="margin-left: 2em">吏士之子弟及其民之秀者率再歲而貢士一人於</span>  
<span style="margin-left: 2em">庭比於邑學蓋自正統己未迄於今百餘年矣而其</span>  
<span style="margin-left: 2em">士猶未得養於有司於是其當貢者亦相持不能決</span>  
<span style="margin-left: 2em">嘉靖庚子教授王新請於督學御史楊公宜得以文</span>  
<span style="margin-left: 2em">之優者二十人當廪膳之數而次第貢之其明年新</span>  
<span style="margin-left: 2em">率訓導蔣詵及諸生孫寅陸中美等言於巡按御史</span>  
<span style="margin-left: 2em">舒公汀曰國家彊城萬里以養士二十人不爲費然</span>  
<span style="margin-left: 2em">而可以見一視之仁焉可以見右文之盛焉如其請</span>  
<span style="margin-left: 2em">當無不可公以語郡守何侯繼之別駕李侯蓁郡憲</span>  
<span style="margin-left: 2em">黃侯洪毗前華亭縣令尹執中僉曰教授言是黃侯</span>  
<span style="margin-left: 2em">則又進曰洪毗閩人閩有平海衛者實得廪其學生</span>  
<span style="margin-left: 2em">金山一衛也援以請其可於是舒公會同都御史夏</span>  
<span style="margin-left: 2em">公邦謨疏於　朝如黃侯言大宗伯上議曰御史言</span>  
<span style="margin-left: 2em">是得　詔置廪膳二十人教授新既拜舞以謝退語</span>  
<span style="margin-left: 2em">於衆曰我　國家以文爲治自洪武至正統其化大</span>  
<span style="margin-left: 2em">行則衛於是有學又自正統迄今化日益淪浹則士</span>  
<span style="margin-left: 2em">始得養於有司蓋繫乎時者如此不可無述也乃幣</span>  
<span style="margin-left: 2em">而徵文於階階嘗讀易切有感矣爲卦六十四而有</span>  
<span style="margin-left: 2em">取於養士者二其一鼎之象曰大烹以養聖賢言上</span>  
<span style="margin-left: 2em">之養士也其一頤之象曰君子以慎言語節飲食言</span>  
<span style="margin-left: 2em">士之自養也夫上必養士而後可以成治士必自養</span>  
<span style="margin-left: 2em">而後可以佐時二者固恒相須也三代以降聖人之</span>  
<span style="margin-left: 2em">道不明已久故士或從事於學而狥外以𢦤內則是</span>  
<span style="margin-left: 2em">不能養其入而於節飲食之義乖牽己以從物則是</span>  
<span style="margin-left: 2em">不能養其出而於慎言語之旨悖如是而徒養於上</span>  
<span style="margin-left: 2em">之人其又何能佐時以無負於國家也哉階不敏欲</span>  
<span style="margin-left: 2em">僣規於多士遂不辭而記之雖然亦諸君子建請之</span>  
<span style="margin-left: 2em">初心也</span>  
<span style="margin-left: 2em">張鼐重修儒學碑記　金山本周康王築城地也淪</span>  
<span style="margin-left: 2em">於海幾千年　本朝沿其名設衛於海之壖修軍實</span>  
<span style="margin-left: 2em">謹風潮也　國制天下衛所皆立學而金山儒學創</span>  
<span style="margin-left: 2em">自正統中形家言大海浩淼從東南來轟雷奔趨而</span>  
<span style="margin-left: 2em">金山寒穴當海國一柱蜃氣縹緲實接其巽位又危</span>  
<span style="margin-left: 2em">樓孤聳踈鐘遠聞南望甬東諸境在海外隱隱若列</span>  
<span style="margin-left: 2em">案學址環河週抱璧水當懷其西北艮隅則秦皇望</span>  
<span style="margin-left: 2em">海之丘查玉成僊人鍊丹之崖層巒叠護取勢於海</span>  
<span style="margin-left: 2em">取氣於山廣大高厚宫牆屹然於海上夫武衛借文</span>  
<span style="margin-left: 2em">教乃重故瑚簋飭而金革之氣銷學官厲而雄武之</span>  
<span style="margin-left: 2em">圖固聖人所以綢繆其制而剛柔劑焉者也自學較</span>  
<span style="margin-left: 2em">既設武臣猛將凡受事兹土者皆得歲時瞻拜廟下</span>  
<span style="margin-left: 2em">拱手立堂皇聽博士諸生講與聞先王之教暨諸世</span>  
<span style="margin-left: 2em">弁子弟亦以時習禮於庭故事博士師以文物尊重</span>  
<span style="margin-left: 2em">例得與總參諸大帥備賓主禮博士師軒車繡服直</span>  
<span style="margin-left: 2em">入大帥戟門大帥趨迎於門乃下揖而入據上坐凡</span>  
<span style="margin-left: 2em">歲時公會讌享皆相抗而坐其弟子員非舊隸戎籍</span>  
<span style="margin-left: 2em">亦得交大帥以下如學師儀凡學有賓興喜慶典禮</span>  
<span style="margin-left: 2em">張旂幟鳴鐘鼓傳砲作樂帥府從便宜弗敢問學故</span>  
<span style="margin-left: 2em">武地顧乃以教澤休明冠紱整肅爲一方重其將帥</span>  
<span style="margin-left: 2em">皆以得奉教師儒依光絃誦爲賢先是創學以來繇</span>  
<span style="margin-left: 2em">景泰迄正德如羅御史義而下崛起科目上第者凡</span>  
<span style="margin-left: 2em">十餘人而後寖衰微八十年於兹矣地靈遷於斷石</span>  
<span style="margin-left: 2em">廟像錮於沉沙氣散而學容敝教薄而人材放此非</span>  
<span style="margin-left: 2em">獨運會使然其亦有待而興者也史官張鼐曰余爲</span>  
<span style="margin-left: 2em">諸生猶能記憶當日廢興事云癸甲之間拓基濬河</span>  
<span style="margin-left: 2em">出聖靈於坑塹標識石於泥塗拮据艸萊天荒以破</span>  
<span style="margin-left: 2em">則八閩翁先生之教也降而庚辛運頗中厄磨厲士</span>  
<span style="margin-left: 2em">氣作新賓興躋桃李於棟梁升鹽梅於鼎實遂徼華</span>  
<span style="margin-left: 2em">貫生光朽株則淮南凌先生之教也至於今日前茅</span>  
<span style="margin-left: 2em">蔚起穎脱代興人負驪龍家合靈霧而經營木石疏</span>  
<span style="margin-left: 2em">滌河渠核實程功不皇櫛沐還鍾虡於舊地飭廟貌</span>  
<span style="margin-left: 2em">於鼎新則黔南婁先生暨今新任田先生之教也夫</span>  
<span style="margin-left: 2em">澤宫興替繫乎官師營度以才服衆以守集事以誠</span>  
<span style="margin-left: 2em">三資者備而功成反掌婁先生矢志神明皭然不染</span>  
<span style="margin-left: 2em">勞來和會底於落成以方前軌彌有光焉若乃宗工</span>  
<span style="margin-left: 2em">教主潤澤斯文權衡所歸德心用播督撫中丞荆南</span>  
<span style="margin-left: 2em">胡公督學臺使武康駱公遂安毛公馳檄鳩工量籌</span>  
<span style="margin-left: 2em">經費勢成建瓴功在主盟署府事節推南楚劉公勞</span>  
<span style="margin-left: 2em">心調度劑絀用贏帑額不豐繼以廪俸署青浦縣事</span>  
<span style="margin-left: 2em">水利兼海防同知南安孫公恪遵舊經樂成盛舉役</span>  
<span style="margin-left: 2em">不罷衆費不礙官並以潔己奉公之誠助禮樂絃歌</span>  
<span style="margin-left: 2em">之美使宫牆巍焕聖澤增日月之光俎豆修明海國</span>  
<span style="margin-left: 2em">賁風雲之氣介弁之胄習威儀而敦禮讓豪武之俗</span>  
<span style="margin-left: 2em">修孝弟而重章縫夫爲臣死忠爲子死孝學較之教</span>  
<span style="margin-left: 2em">也文不愛錢武不惜死臣子之分也數公拮据良苦</span>  
<span style="margin-left: 2em">寧第尊崇一廟貌倘亦念國家設衛立學之意而令</span>
