## 崇祯松江府志卷之二十四　学政下

<span style="margin-left: 3em">学政<sub class="note-yuan">二</sub></span>  
<span style="margin-left: 2em">华亭县学</span>  
<span style="margin-left: 1em">县学在府西南徐家桥之东邑人徐进义塾也学始建</span>  
<span style="margin-left: 1em">于宋元祐中在今府学后玉带河之阳尊贤坊内即今</span>  
<span style="margin-left: 1em">射圃魁星楼地端平间迁于河南以其址为阅武亭及</span>  
<span style="margin-left: 1em">学升府学复建县学于旧址<sub class="note-yuan">按杨维祯至正九年记县学本燕居之所则阅武尝为燕居周伯琦府学记十九年作燕居堂于学北不言旧为阅武</sub>元至大初刘尹庆建</span>  
<span style="margin-left: 1em">夫子庙延祐间张尹国英搆讲堂至正中楚尹恭张尹</span>  
<span style="margin-left: 1em">德昭继为缮理而学乃粗备丙申毁于兵以其地为学</span>  
<span style="margin-left: 1em">射圃</span>  
<span style="margin-left: 2em">至正九年重修学记　华亭县学在府治东南二百</span>  
<span style="margin-left: 2em">步按前志繇宋端平县令杨公瑾之所开拓堂殿斋</span>  
<span style="margin-left: 2em">舍廊庑庖廥始具焉至　国朝县升松江府学亦升</span>  
<span style="margin-left: 2em">府学土田儒籍皆隶之县复立頖宫于府庠北旧燕</span>  
<span style="margin-left: 2em">居之所也至大初刘某来典邑始搆大成殿并仪门</span>  
<span style="margin-left: 2em">两庑延祐己未令张国英复搆讲堂及设祭噐至正</span>  
<span style="margin-left: 2em">癸未县令楚恭修櫺星门缭以崇墉而学之规稍完</span>  
<span style="margin-left: 2em">历年未久而栋宇有弗支者其址尚湫隘周旋升降</span>  
<span style="margin-left: 2em">有弗堪者至正九年春县长养安海涯县令张德昭</span>  
<span style="margin-left: 2em">释菜之际惕然相谓曰学较教之出守令教之行学</span>  
<span style="margin-left: 2em">较废何以资守令之理乎命教谕王伦谋更作之而</span>  
<span style="margin-left: 2em">费未知所出乃告丞簿帖木儿不花兀都马沙俾谕</span>  
<span style="margin-left: 2em">邑士愿新学较者听于是淀山谢庭兰与其姪晋并</span>  
<span style="margin-left: 2em">力从事经始于是年之二月阅三月而告成大成殿</span>  
<span style="margin-left: 2em">增辟后室殿之侧剙学官廨又前后筑石塘以捍水</span>  
<span style="margin-left: 2em">蚀啮于是凡柱石之欹倾者正之椽榈之朽蠧者易</span>  
<span style="margin-left: 2em">之丹青之漫漶者饰之下及庾库庖湢什伯之具无</span>  
<span style="margin-left: 2em">不完整既竣事乃伐石以二侯之命征记于余余尝</span>  
<span style="margin-left: 2em">悼井牧闾师之废而先王之教废后之为治者亦难</span>  
<span style="margin-left: 2em">矣贫富相县虽使臯陶持刑不能禁彊不侮弱伦理</span>  
<span style="margin-left: 2em">弗明虽使姬旦制礼不能革贱不僣贵此非教何赖</span>  
<span style="margin-left: 2em">哉故朝廷以六事命守令而教为之首然而不知治</span>  
<span style="margin-left: 2em">本者视学较如眡传舍其教民者无实政已职教者</span>  
<span style="margin-left: 2em">又素非冠带之望其佐令者无实教已士之在上者</span>  
<span style="margin-left: 2em">既无躬行实履在下者又可责其有实学乎令无实</span>  
<span style="margin-left: 2em">政师无实教士无实学而望风俗之美人才之兴不</span>  
<span style="margin-left: 2em">亦难乎华亭古号文物之邦而其地卑下沮洳民性</span>  
<span style="margin-left: 2em">轻戾而媮靡易叛于教今邑侯以兴学较为先务师</span>  
<span style="margin-left: 2em">儒以作成士类为急功邑之人士又能不负循令长</span>  
<span style="margin-left: 2em">贤师儒教养为实学吾见华亭复旧时文物之盛而</span>  
<span style="margin-left: 2em">无其轻戾媮靡之风且使他邑于是乎劝礼令之得</span>  
<span style="margin-left: 2em">治名者不在是乎不在是乎遂以复二侯俾刻为记</span>  
<span style="margin-left: 2em">是年五月杨维祯记</span>  
<span style="margin-left: 1em">国朝洪武庚戌知县冯荣奉　诏立学始即义塾为之</span>  
<span style="margin-left: 1em">甲寅知县周朗新作大成殿嗣令视子宪以学舍卑陋</span>  
<span style="margin-left: 1em">廓而新之邑人徐进子彦裕力任其事于是明伦观颐</span>  
<span style="margin-left: 1em">二堂博文约礼二斋缭垣翼室习射之圃凡学之制悉</span>  
<span style="margin-left: 1em">备丙辰知县朱直新教官廨名其堂曰知本丁卯大成</span>  
<span style="margin-left: 1em">殿坏御史黄克庸新之仍建文昌祠于戟门之右永乐</span>  
<span style="margin-left: 1em">丙申学舍坏于风雨丁酉知县高宫重修宣德丙午大</span>  
<span style="margin-left: 1em">理卿胡槩改作明伦堂复为堂于其后榜曰进修正统</span>  
<span style="margin-left: 1em">己未推官杨政重建大成殿新戟门及两庑庚申提学</span>  
<span style="margin-left: 1em">御史彭朂辟射圃于学东隙地<sub class="note-yuan">先是改旧圃以为董漕</sub>癸亥知县</span>  
<span style="margin-left: 1em">李希容建观德亭教谕程完义训导胡穗赵建相其役</span>  
<span style="margin-left: 1em">成化壬辰知县戴冕修殿廊饰圣贤像重作明伦堂及</span>  
<span style="margin-left: 1em">斋门庑撤观颐堂而徙观德亭于其后新教官宅增修</span>  
<span style="margin-left: 1em">号舍二十有五间学三面缘河皆甃以石为石阑于其</span>  
<span style="margin-left: 1em">南东西跨河为亭曰希颜曰志尹立科举题名于仪门</span>  
<span style="margin-left: 1em">且为之记弘治庚戌知县汪宣因戴旧规而增葺之撤</span>  
<span style="margin-left: 1em">兴贤育才二坊而建以石于中为石梁跨河而南为泮</span>  
<span style="margin-left: 1em">宫坊坊之南为亭重簷八觚颜之曰聚奎科贡题名其</span>  
<span style="margin-left: 1em">上其南为泮池池外有积水五泓左右为外号缭以周</span>  
<span style="margin-left: 1em">垣环植桧栢自迁学以来增拓凡六至戴而规制始宏</span>  
<span style="margin-left: 1em">至是而大备甲寅知府陈让建崇文阁于讲堂后<sub class="note-yuan">其址故进修堂也</sub>嗣政刘琬复射圃于学之东中开广术彻于横街</span>  
<span style="margin-left: 1em">曰鸿逵于是弘敞壮丽甲于他邑矣</span>  
<span style="margin-left: 2em">曹睿新学记　华亭旧学在今府治之南自元至元</span>  
<span style="margin-left: 2em">间县升为府学亦隶焉繇是改燕居堂为县学后厄</span>  
<span style="margin-left: 2em">于兵燹今之学则徐氏义塾也初县人徐进始创于</span>  
<span style="margin-left: 2em">县南割私田一万亩有奇招延明师以淑里子弟西</span>  
<span style="margin-left: 2em">建大成殿堂庑戟门春秋祀先圣先师至我　朝始</span>  
<span style="margin-left: 2em">更为县学及教谕束宗癸训导胡铉金声朱武李象</span>  
<span style="margin-left: 2em">贤相继至修废举坠思作新未就洪武七年春郡守</span>  
<span style="margin-left: 2em">王公文贞祗谒庙庭退而延儒师讲经义诸生升揖</span>  
<span style="margin-left: 2em">拜肩摩踵蹑不容周旋乃与知县祝子宪议廓而新</span>  
<span style="margin-left: 2em">之进子彦裕闻而请曰此吾先子志也敢不身任其</span>  
<span style="margin-left: 2em">责郡守嘉而义之于是拓学东地重建明伦堂三间</span>  
<span style="margin-left: 2em">夹以翼室创东西斋重门两庑缭以周垣高爽明垲</span>  
<span style="margin-left: 2em">轮奂翚飞论讲有堂肄业有斋藏修有室与夫习射</span>  
<span style="margin-left: 2em">之宫庖湢之庐靡不毕具未几知县朱直来视事学</span>  
<span style="margin-left: 2em">较之事知无不为作育后进增光前人繇是华亭之</span>  
<span style="margin-left: 2em">学遂甲于他县矣时教谕曹宗儒训导钱震谢南万</span>  
<span style="margin-left: 2em">权实主之董是役者沈文进也予谓学较之兴废关</span>  
<span style="margin-left: 2em">世运之盛衰曩年学廪充溢悉为游食所蠧职教者</span>  
<span style="margin-left: 2em">鲜有易一椽加一甓者今以枵然之宫而气象一新</span>  
<span style="margin-left: 2em">如此是虽贤守令之所举倡徐氏父子之所经营其</span>  
<span style="margin-left: 2em">亦斯文气运之所关与洪武十年春二月初吉</span>  
<span style="margin-left: 2em">袁凯修殿记　洪武改元我国家平浙西二年诏兴</span>  
<span style="margin-left: 2em">天下学较三年知县冯荣始迁于此而大成殿庳隘</span>  
<span style="margin-left: 2em">弗称七年知县周朗始命邑民邹德方徐均德更新</span>  
<span style="margin-left: 2em">之不数年而圯今年春风雨大作自中栋庑廊一夕</span>  
<span style="margin-left: 2em">倾圯适监察御史临川黄公克庸至郡展礼庙下顾</span>  
<span style="margin-left: 2em">而叹曰兹非吾之责邪时邑长贰以下咸缺未几池</span>  
<span style="margin-left: 2em">阳李启先来主簿即命董其事知府云南何赐知县</span>  
<span style="margin-left: 2em">刘均俊相继至各捐俸以倡而乡之好义者张示周</span>  
<span style="margin-left: 2em">思诚等亦以赀来助于是鸠工聚材倾昃者正之腐</span>  
<span style="margin-left: 2em">挠者易之覆之甓之涂塈丹雘之至于葺两庑新文</span>  
<span style="margin-left: 2em">昌祠凡昔未备者今皆完美凡四月讫工诸生俾凯</span>  
<span style="margin-left: 2em">记之凯时以训导摄学事其敢以荒陋辞窃惟有天</span>  
<span style="margin-left: 2em">下者必设学较崇庙庭然后人心有所系属如百工</span>  
<span style="margin-left: 2em">之居肆则志不迁而事可成今风纪之司临莅于上</span>  
<span style="margin-left: 2em">贤有司倡率于下以致轮焉奂焉睹兹清庙肃瞻圣</span>  
<span style="margin-left: 2em">容有得于观感之间而兴起焉贤才辈出使江海之</span>  
<span style="margin-left: 2em">上蔼然有洙泗之风无负国家从来教养之意则自</span>  
<span style="margin-left: 2em">今日始也洪武二十九年九月吉日</span>  
<span style="margin-left: 2em">胡俨重修殿记　洪武戊辰予初典教华亭释菜之</span>  
<span style="margin-left: 2em">日周览学宫自殿宇堂斋以至门庑庖廪之所规制</span>  
<span style="margin-left: 2em">整肃缔搆完固仰瞻圣殿文彩焕然盖予未至前训</span>  
<span style="margin-left: 2em">导李处仁所作袁凯为之记居六年以内艰去固岿</span>  
<span style="margin-left: 2em">然也自初建立距今五十余年海滨多飓风雷雨震</span>  
<span style="margin-left: 2em">荡拔木飘瓦繇是昔之岿然者至敝栋挠梁腐桷坠</span>  
<span style="margin-left: 2em">檐典教事钱塘杨益舜江陈宾庐陵胡穗深以为忧</span>  
<span style="margin-left: 2em">庐陵杨君惟敩繇监察御史来典松江府刑狱慨然</span>  
<span style="margin-left: 2em">有志更作谋诸郡守赵君于听讼之际简阅平民情</span>  
<span style="margin-left: 2em">有可矜法有所疑悉从宽贷俾就于赎积二年凡得</span>  
<span style="margin-left: 2em">材木砖甓若干及工人之费百需之具充乎有余遂</span>  
<span style="margin-left: 2em">度材庀工经始于正统二年冬十一月落成于四年</span>  
<span style="margin-left: 2em">十月殿之崇高加故十尺深广各加八尺规模改观</span>  
<span style="margin-left: 2em">轮奂一新惟敩与学之师徒谓予昔尝处此求为之</span>  
<span style="margin-left: 2em">记予惟诸君之从游于斯者肃瞻圣容有所观感退</span>  
<span style="margin-left: 2em">而致力端其趋向将见道德明秀之士彬彬然胥此</span>  
<span style="margin-left: 2em">焉出庶几不负朝廷教育之恩守令作兴之意惟敩</span>  
<span style="margin-left: 2em">奉扬之美予虽衰老与有光荣引领云间寸心千里</span>  
<span style="margin-left: 2em">诸君幸朂之</span>  
<span style="margin-left: 2em">钱溥修改庙学记　吾华亭至元升府以学为府学</span>  
<span style="margin-left: 2em">其县学迁于旧址而毁于兵为府学射圃洪武二年</span>  
<span style="margin-left: 2em">始迁今学盖奉　圣祖开国之诏也正统间推官吉</span>  
<span style="margin-left: 2em">水杨侯政增葺正殿两庑允称而堂斋门道日就朽</span>  
<span style="margin-left: 2em">腐不可复支师生不升立者有年矣成化五年春戴</span>  
<span style="margin-left: 2em">侯来知县事遂日节廪稍公用之余重修殿庑及圣</span>  
<span style="margin-left: 2em">贤像讲堂褊小廓而增高广与深倍之两斋翼然门</span>  
<span style="margin-left: 2em">廊跂然观德堂旧在堂东今改于殿侧公廨二在学</span>  
<span style="margin-left: 2em">外之桥南今鼎立于中门之左增修号房与庖湢库</span>  
<span style="margin-left: 2em">庾若干间芟其蒙翳甃以砖甓为岸为栏为两桥咸</span>  
<span style="margin-left: 2em">以石而亭于桥上左曰希颜右曰志尹规模闳壮金</span>  
<span style="margin-left: 2em">碧辉飞于是学谕陈章司训陆显袁充请为记夫华</span>  
<span style="margin-left: 2em">亭迁学已逾百禩而久安于庳陋一旦成于戴侯不</span>  
<span style="margin-left: 2em">谋于上不烦于民焕然宏构杰出于群望之表异时</span>  
<span style="margin-left: 2em">戴侯称循于史传殆于是有征焉侯名冕字廷章巴</span>  
<span style="margin-left: 2em">县人举四川癸酉解试第一成化九年岁在癸巳夏</span>  
<span style="margin-left: 2em">六月朔旦立石</span>  
<span style="margin-left: 2em">徐阶修学记　双江先生永丰聂公知华亭之二年</span>  
<span style="margin-left: 2em">百废具兴上下胥悦乃修学宫葺故创新具有成绩</span>  
<span style="margin-left: 2em">天子征公为御史又晋公作伯于苏而于时尚未有</span>  
<span style="margin-left: 2em">刻石己丑春姚江陈君徕以乡进士乞典学事君之</span>  
<span style="margin-left: 2em">始拜命也阶为言公作学勤导士恳有古循吏之风</span>  
<span style="margin-left: 2em">君叹且慕久之比至肃瞻庙宇周视黉舍旁稽载籍</span>  
<span style="margin-left: 2em">博询黄耈谓双江公之功前此未有也乃相与砻石</span>  
<span style="margin-left: 2em">搆亭谋征文史氏今年春阶以谪归请曰子昔言双</span>  
<span style="margin-left: 2em">江公作学之勤而导士之恳也徕今得覩而考焉修</span>  
<span style="margin-left: 2em">大成殿以崇本修明伦堂以崇教作名宦乡贤祠以</span>  
<span style="margin-left: 2em">端轨作讲堂作号楼以居业信哉恳矣乎知双江公</span>  
<span style="margin-left: 2em">者莫如子阶昔为诸生受业公之门又亲见公之修</span>  
<span style="margin-left: 2em">学及官翰林尝欲为公作记而公以书止曰是有司</span>
