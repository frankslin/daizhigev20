## 崇禎松江府志卷之三十　宦績三（元朝名宦）

<span style="margin-left: 3em">名臣宦績三</span>  
<span style="margin-left: 1em">元</span>  
<span style="margin-left: 1em">呂謙字和之亳人元初從丞相伯顔南征所至不殺謙</span>  
<span style="margin-left: 1em">實贊之宋平求糧二千石以惠黎元詣省白狀發粟賑</span>  
<span style="margin-left: 1em">之活民數萬即拜謙懷遠大將軍鎮守上海當春勸農</span>  
<span style="margin-left: 1em">召父老謂曰善牧羊者先去敗群善治民者先除民病</span>  
<span style="margin-left: 1em">由是里胥畏憚境內大治</span>  
<span style="margin-left: 1em">王肖翁字傳朋金華人宋丞相魯國文定公淮之玄孫</span>  
<span style="margin-left: 1em">與虞集俱以前代名臣相家子學業不群不拘常制授</span>  
<span style="margin-left: 1em">靜江教授積年勞除將仕郎海道漕運萬户府知事上</span>  
<span style="margin-left: 1em">下克協漕事迄辦僉以爲能至元二年轉從仕郎嘉興</span>  
<span style="margin-left: 1em">府錄事適歲祲部使者檄公行視田公爲具實以聞得</span>  
<span style="margin-left: 1em">免荒租數萬石他州郡有姦利事部使者悉委公決公</span>  
<span style="margin-left: 1em">決之無不當者未幾屬疾請致遂加承務郎松江府判</span>  
<span style="margin-left: 1em">官年六十有四<sub class="note-yuan">載黃溍集</sub></span>  
<span style="margin-left: 1em">燕珪以父公楠蔭仕松江府知府有政聲趙孟頫程鉅</span>  
<span style="margin-left: 1em">夫輩皆推轂之除大司農領八道勸農營田司事按行</span>  
<span style="margin-left: 1em">郡縣興利除弊遷湖廣行省右丞終於京邸勑命朝臣</span>  
<span style="margin-left: 1em">護喪南歸所過官司癸奠天下榮之<sub class="note-yuan">見江西通志</sub></span>  
<span style="margin-left: 1em">石從愿大德間自翰林來知府事明敏果斷郡無寃民</span>  
<span style="margin-left: 1em">代去兒童連袂歌好知府</span>  
<span style="margin-left: 1em">季禄兒至大間爲知府交篆日叱散城中捕蝗吏民胥</span>  
<span style="margin-left: 1em">鼓舞稱快性廉貞豪民有懷金贄見者竟送爲官物人</span>  
<span style="margin-left: 1em">稱曰真清太守尋丁內艱哀號擗踊一夕頭爲白喪除</span>  
<span style="margin-left: 1em">乞終身廬墓已而朝廷奪情起爲嘉興路治中時重惜</span>  
<span style="margin-left: 1em">名爵聽之而御史抗章以率舊職</span>  
<span style="margin-left: 1em">哈散沙字允中阿兒温氏至正十一年爲達魯花赤時</span>  
<span style="margin-left: 1em">兵興民苦徭役抑强植弱以均之文事武備厥政克修</span>  
<span style="margin-left: 1em">鈔法不行民無糴告僚吏曰吾爲民師帥忍坐視老弱</span>  
<span style="margin-left: 1em">餒死溝壑乎吾將糶倉粟以賑民秋穫糴以補之吾責</span>  
<span style="margin-left: 1em">塞矣衆驩然曰惟相公命遂發粟及勸富民月糶官置</span>  
<span style="margin-left: 1em">半印簿帖書其口與糴數簿給糶家帖給糴者逐月對</span>  
<span style="margin-left: 1em">帖糴之卒無閉糶憂所活甚衆民有孫明重建城隍廟</span>  
<span style="margin-left: 1em">成式肖像祠之</span>  
<span style="margin-left: 1em">燕只吉臺徹理才畧兼人恒以匡君經國自期軀幹異</span>  
<span style="margin-left: 1em">常襲其祖衣長不能勝則知其先亦魁傑也帝嘗賜問</span>  
<span style="margin-left: 1em">奇其對進侍帷幄積官至榮禄大夫平章政事成宗入</span>  
<span style="margin-left: 1em">踐大位拜江南諸道行御史大夫一日召其都事賈鈞</span>  
<span style="margin-left: 1em">今參議中書者謂曰明詔責使肅清宣明風俗教化而</span>  
<span style="margin-left: 1em">刀筆流爲御史者肆爲苛虐性急徵贜以多爲功至迫</span>  
<span style="margin-left: 1em">子證父妻證夫弟證兄奴告其主敗風教者我實行之</span>  
<span style="margin-left: 1em">汝宜以是出訓其屬帝聞之以爲得風紀大體改浙省</span>  
<span style="margin-left: 1em">平章政事其治如臺門無私謁以轉粟京師多資東南</span>  
<span style="margin-left: 1em">居天下什六七而松江填淤歲久富民利之當水出塗</span>  
<span style="margin-left: 1em">築爲圍田以故瀰漫浸灌沮洳廣遠民不可稻公發卒</span>  
<span style="margin-left: 1em">數萬浚決揵石隄之導水入海使復其故凡身董役經</span>  
<span style="margin-left: 1em">時而成民得良田若干萬頃至今賴之召入平章中書</span>  
<span style="margin-left: 1em">贊右丞相薨年四十有七蓋棺之日楮緡不滿二百債</span>  
<span style="margin-left: 1em">券積多至十萬大臣清貧無與比贈徐國公謚忠肅</span>  
<span style="margin-left: 2em">姚燧撰神道碑銘曰俾行南臺不專繩愆體仁德音</span>  
<span style="margin-left: 2em">風教是宣移平章杭先民所急浚通松江壞防巨室</span>  
<span style="margin-left: 1em">王淮字玉淵處州人博學美容儀嘗受業於石塘胡先</span>  
<span style="margin-left: 1em">生大德間授瀏陽州教授歷松江路判官</span>  
<span style="margin-left: 1em">汪從善字國良婺之著姓父徽國公斌以醫進累遷太</span>  
<span style="margin-left: 1em">醫院使昭文館大學士出人宫闕從善年十三歲入見</span>  
<span style="margin-left: 1em">便殿世祖使免冠相之點首許可以手撫其額顧徽國</span>  
<span style="margin-left: 1em">曰卿有子矣使學文術後當遠大成宗皇帝命入速古</span>  
<span style="margin-left: 1em">兒赤班尚冠服日在上左右聰敏絕人凡有臺卿監奏</span>  
<span style="margin-left: 1em">事無不默記奏對無所遺誤又膂力善騎射每田獵及</span>  
<span style="margin-left: 1em">巡幸上都必命侍從涉歷險阻能力捍衞進秩奉訓大</span>  
<span style="margin-left: 1em">夫典瑞監丞大德十一年上不懌詔徵御寶入內時儲</span>  
<span style="margin-left: 1em">貳未定武宗皇帝總戎朔方仁宗皇帝以太弟先入居</span>  
<span style="margin-left: 1em">東宫太后垂簾宗室未附從善語同寅曰神器不宜久</span>  
<span style="margin-left: 1em">留中宫莫若先奉璽東宫是夜舁寶至東宫門仁宗曰</span>  
<span style="margin-left: 1em">卿等忠孝使吾有此神器爲是謀者誰衆曰汪從善仁</span>  
<span style="margin-left: 1em">宗拱手曰天實福我邦國卿等社稷臣也武宗入正大</span>  
<span style="margin-left: 1em">統即位之日下詔天下從善抱璽立上側太監乞里古</span>  
<span style="margin-left: 1em">怯用璽弗稱仁宗顧使用璽如法上大悦賜四品服陞</span>  
<span style="margin-left: 1em">中順大夫宣德府知府丁徽國艱服闋特旨除松江府</span>  
<span style="margin-left: 1em">知府兼勸農事仍命提調普慶寺錢糧松郡濱海統華</span>  
<span style="margin-left: 1em">亭上海二縣厥田下下而厥賦上上春夏間水至則不</span>  
<span style="margin-left: 1em">受種藝秋潦則穀且不實從善始以爲憂即戒縣官築</span>  
<span style="margin-left: 1em">堤防水親授以法既又親往率役其年秋大熟城西南</span>  
<span style="margin-left: 1em">有晋陸瑁魚池舊爲屋其上以爲鄉師授書之地歲久</span>  
<span style="margin-left: 1em">不修且壞即命富室弘其前規命曰西湖書塾設掌祠</span>  
<span style="margin-left: 1em">置祭田招師訓弟子而廪膳之七年夏大旱從善親用</span>  
<span style="margin-left: 1em">幣於群望詰朝大雨境內皆足歲又大熟秩滿母夫人</span>  
<span style="margin-left: 1em">樂蒪鱸因卜居城南以稱母意焉泰定元年宰相奏爲</span>  
<span style="margin-left: 1em">南康守多異績會徽國夫人薨終喪還居松江以著書</span>  
<span style="margin-left: 1em">自晦貌狀魁梧氣宇落落性剛介不務細行常面折人</span>  
<span style="margin-left: 1em">過退無後言有爲不善者必相戒曰毋使汪使君知也</span>  
<span style="margin-left: 1em">所著書有通鑑地理志二十卷考異六卷生意齋筆錄</span>  
<span style="margin-left: 1em">三十五卷書記十卷中朝紀聞若干卷博愛堂家藏方</span>  
<span style="margin-left: 1em">論若干卷又長書法凡鍾王以下靡不究晚年書益有</span>  
<span style="margin-left: 1em">名力學不懈至正二年卒於松江里第家無長物琴書</span>  
<span style="margin-left: 1em">祭器而已<sub class="note-yuan">蛾術集</sub></span>  
<span style="margin-left: 1em">俞師魯字唯道婺源人大德十年江浙行省薦其行能</span>  
<span style="margin-left: 1em">應茂材異等江東使者涿郡盧摯薦之辟署史館編修</span>  
<span style="margin-left: 1em">以親老求外遂授隆興路學教授家居十年至治中除</span>  
<span style="margin-left: 1em">廣德路學教授授松江府知事多有政績民爲之歌曰</span>  
<span style="margin-left: 1em">俞公未來案牘紛披吏饒而欺俞公既來官僚怡怡吏</span>  
<span style="margin-left: 1em">飽而嬉惟其黑幘使我心惻府中事無大小須其一言</span>  
<span style="margin-left: 1em">而決疾卒於官</span>  
<span style="margin-left: 1em">王珪至大間丞上海縣建學校抑豪右伸孱弱政績藹</span>  
<span style="margin-left: 1em">然至今故老頌之</span>  
<span style="margin-left: 1em">申杲字良輔真定人皇慶壬子知松江府以忠信仁厚</span>  
<span style="margin-left: 1em">爲治隨事悉心百廢具舉未滿考召同僉崇祥院民思</span>  
<span style="margin-left: 1em">之不忘濟南張養浩撰去思碑具載其事從子秉禮字</span>  
<span style="margin-left: 1em">彦魯元統癸酉亦知本府有善政士民刻石頌德謂之</span>  
<span style="margin-left: 1em">棠陰碑</span>  
<span style="margin-left: 2em">予至松江之明年夏黌宇佩衿閭閻之班白者相率</span>  
<span style="margin-left: 2em">而請曰真定申侯前守兹土始至民安之歲久而民</span>  
<span style="margin-left: 2em">懷之秩滿代去而民咸思之侯何以得此於民哉順</span>  
<span style="margin-left: 2em">而弗擾之則自安逆而弗威之則自勸久而弗易其</span>  
<span style="margin-left: 2em">所守則益自思慕侯之爲政如是而已豈巧於徵科</span>  
<span style="margin-left: 2em">信於期會而足以得匹夫匹婦之心哉是故學興西</span>  
<span style="margin-left: 2em">湖崇教化也壇奉社稷重農事也局新惠民仁黎庶</span>  
<span style="margin-left: 2em">也壝祠風師若天道也惠及孤寡閔無告也至於崇</span>  
<span style="margin-left: 2em">餙神祠者三亦皆所以爲民祈福也斯政也人謂可</span>  
<span style="margin-left: 2em">緩侯丞爲之人視若迂侯力行之其與汲汲於催科</span>  
<span style="margin-left: 2em">期會者相去遠矣請述其事爲記將壽諸石而昭厥</span>  
<span style="margin-left: 2em">後焉</span>  
<span style="margin-left: 1em">張國英字世傑延祐間尹華亭有威名而敏於政時郡</span>  
<span style="margin-left: 1em">將恃世家陵轢有司欺細民其蒼頭廬兒日游街曲謔</span>  
<span style="margin-left: 1em">浪譏訶民婦弗敢避國英以法制之民藉以安與儕貴</span>  
<span style="margin-left: 1em">李廷傑西漢傑鱗差人稱三傑</span>  
<span style="margin-left: 1em">張如砥字周道濟南人始爲舞陽洛陽尹及來治上海</span>  
<span style="margin-left: 1em">潔己愛民有民負人租以嬰兒病死訟之縣曰某菴僧</span>  
<span style="margin-left: 1em">索租毆斃如砥察其僞曰不毆爾而毆嬰此詐也叱使</span>  
<span style="margin-left: 1em">去民不肯行又呼謂之曰某以人命染人某以故殺子</span>  
<span style="margin-left: 1em">孫汝勿改亦猶是也民遂戚然去延祐丙辰秋浙西大</span>  
<span style="margin-left: 1em">水壞禾稼冬行省委官分詣覈實凡粟有根幹者詰縣</span>  
<span style="margin-left: 1em">徵其賦如常如砥力與争不從涕泣謂民曰彼欲殺汝</span>  
<span style="margin-left: 1em">我不能救汝獲戾柰何明年春大饑民以糠覈和草葉</span>  
<span style="margin-left: 1em">煮食流離餓死相繼道上遂訴於省得發粟賑濟大行</span>  
<span style="margin-left: 1em">勸分之令民得穀以全活者衆以清惠聞擢陝西行臺</span>  
<span style="margin-left: 1em">監察御史</span>  
<span style="margin-left: 1em">火失哈兒欽察氏繇宿衞入官至治二年知離熟州達</span>  
<span style="margin-left: 1em">魯花赤朝廷聞浙右田有賦存而無徵者里正歲代償</span>  
<span style="margin-left: 1em">至破産議勸富民助田以紓之擇火失哈兒視事乃得</span>  
<span style="margin-left: 1em">民一百五十餘户田一千一百三頃歲入米六萬四千</span>  
<span style="margin-left: 1em">石慎屬人出納民受廣利又奉省檄勸富民移米平糶</span>  
<span style="margin-left: 1em">廉知田已鬻而抑派者居四之三凡爲米四萬九千石</span>  
<span style="margin-left: 1em">有奇茫然無儗乃奮身廷辨以去就争之卒得蠲釋轉</span>  
<span style="margin-left: 1em">徙就食者日來歸募民墾荒田八十餘頃歲增賦三千</span>  
<span style="margin-left: 1em">餘石開淞江浚練湖修大成樂令學官課講焉泰定丙</span>  
<span style="margin-left: 1em">寅滿去民請湯彌昌記其遺愛</span>  
<span style="margin-left: 1em">鄧巨川字百川真定人至治初丞上海建言縣之苗糧</span>  
<span style="margin-left: 1em">改科爲豆麥民被其利莫不額手顧自語人曰改科皆</span>  
<span style="margin-left: 1em">鄔人都剌公平章江浙深知民病適進中書故從斯請</span>  
<span style="margin-left: 1em">予何力焉仕至禮部尚書致仕既壽且康時謂利民之</span>  
<span style="margin-left: 1em">報</span>  
<span style="margin-left: 1em">密蘭色目人廉敏讜正泰定二年自山西江北道肅政</span>  
<span style="margin-left: 1em">廉訪使爲都水庸田使置司華亭每赴司騶從甚簡一</span>  
<span style="margin-left: 1em">日導市中有抒厠者荷擔突簾而出乘馬驚蹷地騶皂</span>  
<span style="margin-left: 1em">掖憇民家保伍方譟縻抒厠者待罪蘭起坐召民長者</span>  
<span style="margin-left: 1em">謂曰吾馬生非其故也毋責之遂上馬去時服其量僚</span>  
<span style="margin-left: 1em">寀間爵均者蒙古人以漢人先之官漢人以蒙古人國</span>  
<span style="margin-left: 1em">族交推右坐久未決公命主書取除目宣之曰玉音有</span>  
<span style="margin-left: 1em">序二公奚遜爲位遂定後同列張友諒入參中書上問</span>  
<span style="margin-left: 1em">庸田時誰與共政對曰密蘭上曰回回耳友諒曰密蘭</span>  
<span style="margin-left: 1em">回回中寶也遂召爲刑部尚書其爲世推重如此</span>  
<span style="margin-left: 1em">何蒙字叔正泰定間尹上海貧而廉家奴十餘口屑麥</span>  
<span style="margin-left: 1em">作粥舉無愠歎歲歉邑民阻饑請發粟賑貸民賴以全</span>  
<span style="margin-left: 1em">余貞字復卿寧州人中泰定丁卯科授上海丞調棗陽</span>
