## 崇祯松江府志卷之三十　宦绩三（元朝名宦）

<span style="margin-left: 3em">名臣宦绩三</span>  
<span style="margin-left: 1em">元</span>  
<span style="margin-left: 1em">吕谦字和之亳人元初从丞相伯颜南征所至不杀谦</span>  
<span style="margin-left: 1em">实赞之宋平求粮二千石以惠黎元诣省白状发粟赈</span>  
<span style="margin-left: 1em">之活民数万即拜谦怀远大将军镇守上海当春劝农</span>  
<span style="margin-left: 1em">召父老谓曰善牧羊者先去败群善治民者先除民病</span>  
<span style="margin-left: 1em">由是里胥畏惮境内大治</span>  
<span style="margin-left: 1em">王肖翁字传朋金华人宋丞相鲁国文定公淮之玄孙</span>  
<span style="margin-left: 1em">与虞集俱以前代名臣相家子学业不群不拘常制授</span>  
<span style="margin-left: 1em">静江教授积年劳除将仕郎海道漕运万户府知事上</span>  
<span style="margin-left: 1em">下克协漕事迄办佥以为能至元二年转从仕郎嘉兴</span>  
<span style="margin-left: 1em">府录事适岁祲部使者檄公行视田公为具实以闻得</span>  
<span style="margin-left: 1em">免荒租数万石他州郡有奸利事部使者悉委公决公</span>  
<span style="margin-left: 1em">决之无不当者未几属疾请致遂加承务郎松江府判</span>  
<span style="margin-left: 1em">官年六十有四<sub class="note-yuan">载黄溍集</sub></span>  
<span style="margin-left: 1em">燕珪以父公楠荫仕松江府知府有政声赵孟𫖯程巨</span>  
<span style="margin-left: 1em">夫辈皆推毂之除大司农领八道劝农营田司事按行</span>  
<span style="margin-left: 1em">郡县兴利除弊迁湖广行省右丞终于京邸勑命朝臣</span>  
<span style="margin-left: 1em">护丧南归所过官司癸奠天下荣之<sub class="note-yuan">见江西通志</sub></span>  
<span style="margin-left: 1em">石从愿大德间自翰林来知府事明敏果断郡无寃民</span>  
<span style="margin-left: 1em">代去儿童连袂歌好知府</span>  
<span style="margin-left: 1em">季禄儿至大间为知府交篆日叱散城中捕蝗吏民胥</span>  
<span style="margin-left: 1em">鼓舞称快性廉贞豪民有怀金贽见者竟送为官物人</span>  
<span style="margin-left: 1em">称曰真清太守寻丁内艰哀号擗踊一夕头为白丧除</span>  
<span style="margin-left: 1em">乞终身庐墓已而朝廷夺情起为嘉兴路治中时重惜</span>  
<span style="margin-left: 1em">名爵听之而御史抗章以率旧职</span>  
<span style="margin-left: 1em">哈散沙字允中阿儿温氏至正十一年为达鲁花赤时</span>  
<span style="margin-left: 1em">兵兴民苦徭役抑强植弱以均之文事武备厥政克修</span>  
<span style="margin-left: 1em">钞法不行民无籴告僚吏曰吾为民师帅忍坐视老弱</span>  
<span style="margin-left: 1em">馁死沟壑乎吾将粜仓粟以赈民秋获籴以补之吾责</span>  
<span style="margin-left: 1em">塞矣众驩然曰惟相公命遂发粟及劝富民月粜官置</span>  
<span style="margin-left: 1em">半印簿帖书其口与籴数簿给粜家帖给籴者逐月对</span>  
<span style="margin-left: 1em">帖籴之卒无闭粜忧所活甚众民有孙明重建城隍庙</span>  
<span style="margin-left: 1em">成式肖像祠之</span>  
<span style="margin-left: 1em">燕只吉台彻理才畧兼人恒以匡君经国自期躯干异</span>  
<span style="margin-left: 1em">常袭其祖衣长不能胜则知其先亦魁杰也帝尝赐问</span>  
<span style="margin-left: 1em">奇其对进侍帷幄积官至荣禄大夫平章政事成宗入</span>  
<span style="margin-left: 1em">践大位拜江南诸道行御史大夫一日召其都事贾钧</span>  
<span style="margin-left: 1em">今参议中书者谓曰明诏责使肃清宣明风俗教化而</span>  
<span style="margin-left: 1em">刀笔流为御史者肆为苛虐性急征赃以多为功至迫</span>  
<span style="margin-left: 1em">子证父妻证夫弟证兄奴告其主败风教者我实行之</span>  
<span style="margin-left: 1em">汝宜以是出训其属帝闻之以为得风纪大体改浙省</span>  
<span style="margin-left: 1em">平章政事其治如台门无私谒以转粟京师多资东南</span>  
<span style="margin-left: 1em">居天下什六七而松江填淤岁久富民利之当水出涂</span>  
<span style="margin-left: 1em">筑为围田以故弥漫浸灌沮洳广远民不可稻公发卒</span>  
<span style="margin-left: 1em">数万浚决揵石隄之导水入海使复其故凡身董役经</span>  
<span style="margin-left: 1em">时而成民得良田若干万顷至今赖之召入平章中书</span>  
<span style="margin-left: 1em">赞右丞相薨年四十有七盖棺之日楮缗不满二百债</span>  
<span style="margin-left: 1em">券积多至十万大臣清贫无与比赠徐国公谥忠肃</span>  
<span style="margin-left: 2em">姚燧撰神道碑铭曰俾行南台不专绳愆体仁德音</span>  
<span style="margin-left: 2em">风教是宣移平章杭先民所急浚通松江坏防巨室</span>  
<span style="margin-left: 1em">王淮字玉渊处州人博学美容仪尝受业于石塘胡先</span>  
<span style="margin-left: 1em">生大德间授浏阳州教授历松江路判官</span>  
<span style="margin-left: 1em">汪从善字国良婺之著姓父徽国公斌以医进累迁太</span>  
<span style="margin-left: 1em">医院使昭文馆大学士出人宫阙从善年十三岁入见</span>  
<span style="margin-left: 1em">便殿世祖使免冠相之点首许可以手抚其额顾徽国</span>  
<span style="margin-left: 1em">曰卿有子矣使学文术后当远大成宗皇帝命入速古</span>  
<span style="margin-left: 1em">儿赤班尚冠服日在上左右聪敏绝人凡有台卿监奏</span>  
<span style="margin-left: 1em">事无不默记奏对无所遗误又膂力善骑射每田猎及</span>  
<span style="margin-left: 1em">巡幸上都必命侍从涉历险阻能力捍衞进秩奉训大</span>  
<span style="margin-left: 1em">夫典瑞监丞大德十一年上不怿诏征御宝入内时储</span>  
<span style="margin-left: 1em">贰未定武宗皇帝总戎朔方仁宗皇帝以太弟先入居</span>  
<span style="margin-left: 1em">东宫太后垂帘宗室未附从善语同寅曰神器不宜久</span>  
<span style="margin-left: 1em">留中宫莫若先奉玺东宫是夜舁宝至东宫门仁宗曰</span>  
<span style="margin-left: 1em">卿等忠孝使吾有此神器为是谋者谁众曰汪从善仁</span>  
<span style="margin-left: 1em">宗拱手曰天实福我邦国卿等社稷臣也武宗入正大</span>  
<span style="margin-left: 1em">统即位之日下诏天下从善抱玺立上侧太监乞里古</span>  
<span style="margin-left: 1em">怯用玺弗称仁宗顾使用玺如法上大悦赐四品服升</span>  
<span style="margin-left: 1em">中顺大夫宣德府知府丁徽国艰服阕特旨除松江府</span>  
<span style="margin-left: 1em">知府兼劝农事仍命提调普庆寺钱粮松郡滨海统华</span>  
<span style="margin-left: 1em">亭上海二县厥田下下而厥赋上上春夏间水至则不</span>  
<span style="margin-left: 1em">受种艺秋潦则谷且不实从善始以为忧即戒县官筑</span>  
<span style="margin-left: 1em">堤防水亲授以法既又亲往率役其年秋大熟城西南</span>  
<span style="margin-left: 1em">有晋陆瑁鱼池旧为屋其上以为乡师授书之地岁久</span>  
<span style="margin-left: 1em">不修且坏即命富室弘其前规命曰西湖书塾设掌祠</span>  
<span style="margin-left: 1em">置祭田招师训弟子而廪膳之七年夏大旱从善亲用</span>  
<span style="margin-left: 1em">币于群望诘朝大雨境内皆足岁又大熟秩满母夫人</span>  
<span style="margin-left: 1em">乐蒪鲈因卜居城南以称母意焉泰定元年宰相奏为</span>  
<span style="margin-left: 1em">南康守多异绩会徽国夫人薨终丧还居松江以著书</span>  
<span style="margin-left: 1em">自晦貌状魁梧气宇落落性刚介不务细行常面折人</span>  
<span style="margin-left: 1em">过退无后言有为不善者必相戒曰毋使汪使君知也</span>  
<span style="margin-left: 1em">所著书有通鉴地理志二十卷考异六卷生意斋笔录</span>  
<span style="margin-left: 1em">三十五卷书记十卷中朝纪闻若干卷博爱堂家藏方</span>  
<span style="margin-left: 1em">论若干卷又长书法凡钟王以下靡不究晚年书益有</span>  
<span style="margin-left: 1em">名力学不懈至正二年卒于松江里第家无长物琴书</span>  
<span style="margin-left: 1em">祭器而已<sub class="note-yuan">蛾术集</sub></span>  
<span style="margin-left: 1em">俞师鲁字唯道婺源人大德十年江浙行省荐其行能</span>  
<span style="margin-left: 1em">应茂材异等江东使者涿郡卢挚荐之辟署史馆编修</span>  
<span style="margin-left: 1em">以亲老求外遂授隆兴路学教授家居十年至治中除</span>  
<span style="margin-left: 1em">广德路学教授授松江府知事多有政绩民为之歌曰</span>  
<span style="margin-left: 1em">俞公未来案牍纷披吏饶而欺俞公既来官僚怡怡吏</span>  
<span style="margin-left: 1em">饱而嬉惟其黑帻使我心恻府中事无大小须其一言</span>  
<span style="margin-left: 1em">而决疾卒于官</span>  
<span style="margin-left: 1em">王珪至大间丞上海县建学校抑豪右伸孱弱政绩蔼</span>  
<span style="margin-left: 1em">然至今故老颂之</span>  
<span style="margin-left: 1em">申杲字良辅真定人皇庆壬子知松江府以忠信仁厚</span>  
<span style="margin-left: 1em">为治随事悉心百废具举未满考召同佥崇祥院民思</span>  
<span style="margin-left: 1em">之不忘济南张养浩撰去思碑具载其事从子秉礼字</span>  
<span style="margin-left: 1em">彦鲁元统癸酉亦知本府有善政士民刻石颂德谓之</span>  
<span style="margin-left: 1em">棠阴碑</span>  
<span style="margin-left: 2em">予至松江之明年夏黉宇佩衿闾阎之班白者相率</span>  
<span style="margin-left: 2em">而请曰真定申侯前守兹土始至民安之岁久而民</span>  
<span style="margin-left: 2em">怀之秩满代去而民咸思之侯何以得此于民哉顺</span>  
<span style="margin-left: 2em">而弗扰之则自安逆而弗威之则自劝久而弗易其</span>  
<span style="margin-left: 2em">所守则益自思慕侯之为政如是而已岂巧于征科</span>  
<span style="margin-left: 2em">信于期会而足以得匹夫匹妇之心哉是故学兴西</span>  
<span style="margin-left: 2em">湖崇教化也坛奉社稷重农事也局新惠民仁黎庶</span>  
<span style="margin-left: 2em">也壝祠风师若天道也惠及孤寡闵无告也至于崇</span>  
<span style="margin-left: 2em">餙神祠者三亦皆所以为民祈福也斯政也人谓可</span>  
<span style="margin-left: 2em">缓侯丞为之人视若迂侯力行之其与汲汲于催科</span>  
<span style="margin-left: 2em">期会者相去远矣请述其事为记将寿诸石而昭厥</span>  
<span style="margin-left: 2em">后焉</span>  
<span style="margin-left: 1em">张国英字世杰延祐间尹华亭有威名而敏于政时郡</span>  
<span style="margin-left: 1em">将恃世家陵轹有司欺细民其苍头庐儿日游街曲谑</span>  
<span style="margin-left: 1em">浪讥诃民妇弗敢避国英以法制之民借以安与侪贵</span>  
<span style="margin-left: 1em">李廷杰西汉杰鳞差人称三杰</span>  
<span style="margin-left: 1em">张如砥字周道济南人始为舞阳洛阳尹及来治上海</span>  
<span style="margin-left: 1em">洁己爱民有民负人租以婴儿病死讼之县曰某庵僧</span>  
<span style="margin-left: 1em">索租殴毙如砥察其伪曰不殴尔而殴婴此诈也叱使</span>  
<span style="margin-left: 1em">去民不肯行又呼谓之曰某以人命染人某以故杀子</span>  
<span style="margin-left: 1em">孙汝勿改亦犹是也民遂戚然去延祐丙辰秋浙西大</span>  
<span style="margin-left: 1em">水坏禾稼冬行省委官分诣核实凡粟有根干者诘县</span>  
<span style="margin-left: 1em">征其赋如常如砥力与争不从涕泣谓民曰彼欲杀汝</span>  
<span style="margin-left: 1em">我不能救汝获戾柰何明年春大饥民以糠核和草叶</span>  
<span style="margin-left: 1em">煮食流离饿死相继道上遂诉于省得发粟赈济大行</span>  
<span style="margin-left: 1em">劝分之令民得谷以全活者众以清惠闻擢陕西行台</span>  
<span style="margin-left: 1em">监察御史</span>  
<span style="margin-left: 1em">火失哈儿钦察氏繇宿衞入官至治二年知离熟州达</span>  
<span style="margin-left: 1em">鲁花赤朝廷闻浙右田有赋存而无征者里正岁代偿</span>  
<span style="margin-left: 1em">至破产议劝富民助田以纾之择火失哈儿视事乃得</span>  
<span style="margin-left: 1em">民一百五十余户田一千一百三顷岁入米六万四千</span>  
<span style="margin-left: 1em">石慎属人出纳民受广利又奉省檄劝富民移米平粜</span>  
<span style="margin-left: 1em">廉知田已鬻而抑派者居四之三凡为米四万九千石</span>  
<span style="margin-left: 1em">有奇茫然无儗乃奋身廷辨以去就争之卒得蠲释转</span>  
<span style="margin-left: 1em">徙就食者日来归募民垦荒田八十余顷岁增赋三千</span>  
<span style="margin-left: 1em">余石开淞江浚练湖修大成乐令学官课讲焉泰定丙</span>  
<span style="margin-left: 1em">寅满去民请汤弥昌记其遗爱</span>  
<span style="margin-left: 1em">邓巨川字百川真定人至治初丞上海建言县之苗粮</span>  
<span style="margin-left: 1em">改科为豆麦民被其利莫不额手顾自语人曰改科皆</span>  
<span style="margin-left: 1em">邬人都剌公平章江浙深知民病适进中书故从斯请</span>  
<span style="margin-left: 1em">予何力焉仕至礼部尚书致仕既寿且康时谓利民之</span>  
<span style="margin-left: 1em">报</span>  
<span style="margin-left: 1em">密兰色目人廉敏谠正泰定二年自山西江北道肃政</span>  
<span style="margin-left: 1em">廉访使为都水庸田使置司华亭每赴司驺从甚简一</span>  
<span style="margin-left: 1em">日导市中有抒厕者荷担突帘而出乘马惊蹷地驺皂</span>  
<span style="margin-left: 1em">掖憇民家保伍方噪縻抒厕者待罪兰起坐召民长者</span>  
<span style="margin-left: 1em">谓曰吾马生非其故也毋责之遂上马去时服其量僚</span>  
<span style="margin-left: 1em">采间爵均者蒙古人以汉人先之官汉人以蒙古人国</span>  
<span style="margin-left: 1em">族交推右坐久未决公命主书取除目宣之曰玉音有</span>  
<span style="margin-left: 1em">序二公奚逊为位遂定后同列张友谅入参中书上问</span>  
<span style="margin-left: 1em">庸田时谁与共政对曰密兰上曰回回耳友谅曰密兰</span>  
<span style="margin-left: 1em">回回中宝也遂召为刑部尚书其为世推重如此</span>
