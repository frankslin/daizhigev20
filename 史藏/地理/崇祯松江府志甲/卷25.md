## 崇祯松江府志卷之二十五　兵防

<span style="margin-left: 3em">兵防</span>  
<span style="margin-left: 1em">汉边郡太守绾铜虎符得自兴发讨击名为守实郡将</span>  
<span style="margin-left: 1em">也第当事者治钱谷簿书不暇而暇理兵事乎惟名守</span>  
<span style="margin-left: 1em">与郡司马共持筹而经畧之训练世胄材官良家子而</span>  
<span style="margin-left: 1em">松有爪牙矣马似游龙船如使马而松有足矣多储粻</span>  
<span style="margin-left: 1em">糗而松有腹矣瞭望明侦探信兵无虚伍饷无虚额陆</span>  
<span style="margin-left: 1em">路水路之门户无所不谙火战水战之器械无所不具</span>  
<span style="margin-left: 1em">而松有手眼矣如是其能乗衅蹈瑕以撼我张虚驾伪</span>  
<span style="margin-left: 1em">以嫚我乎况带江襟泖滨海外寇少内盗多松非百年</span>  
<span style="margin-left: 1em">无事之国也未雨而桑未病而艾岂鳃鳃过计哉</span>  
<span style="margin-left: 2em">府城军兵之制</span>  
<span style="margin-left: 1em">郡地在秦汉之际未为山海要阨历晋魏以后立亭设</span>  
<span style="margin-left: 2em">长以司讥察而已唐有县始有兵宋制则设厢军供</span>  
<span style="margin-left: 2em">县之杂役禁军供县之守御又有弓手为县之巡徼</span>  
<span style="margin-left: 2em">皆以募充元升为府至正十五年设总管军兵万户</span>  
<span style="margin-left: 2em">府建两翼有千百户镇抚等官后改镇守万户府以</span>  
<span style="margin-left: 2em">总军政又置兵马司治城内兼巡徼之事入　国朝</span>  
<span style="margin-left: 2em">洪武初设民兵万户府简民间武勇之人编成队伍</span>  
<span style="margin-left: 2em">以时操练有事从征事平还复为民有功者一体升</span>  
<span style="margin-left: 2em">赏后革万户府而设守御松江千户所然其时尚每</span>  
<span style="margin-left: 2em">岁调苏州卫官军更番戍守至洪武三十年始定今</span>  
<span style="margin-left: 2em">制以金山卫中千户所一署分驻之开建公署于府</span>  
<span style="margin-left: 2em">治东南旧设千百户镇抚二十三员旗军一千一百</span>  
<span style="margin-left: 2em">二十名以守护城池设屯田一百六十一顷有奇岁</span>  
<span style="margin-left: 2em">收子粒三千四百六十余石以充其月粮有不敷于</span>  
<span style="margin-left: 2em">三县民粮支补军兵之外又佥选民壮操练以备御</span>  
<span style="margin-left: 2em">非常正统景泰以后历有更制经嘉靖之倭警而兵</span>  
<span style="margin-left: 2em">额顿增隆万承平稍为裁减今见在者陆兵额设三</span>  
<span style="margin-left: 2em">百名旧以所官一员统练水兵额设二百名哨船二</span>  
<span style="margin-left: 2em">十只亦以官一员统练每岁粮饷额征银三千三百</span>  
<span style="margin-left: 2em">六十九两有奇</span>  
<span style="margin-left: 1em">守御松江千户所<sub class="note-yuan">在府东南望仙桥东</sub></span>  
<span style="margin-left: 2em">兵职</span>  
<span style="margin-left: 2em"><sub class="note-yuan">本所正千户四员副千户七员掌印兼清军屯局一管巡盐巡江一管巡捕一管城操一管运粮一管练兵一管水哨一百户十员除故绝外见在四员听差镇抚二员镇抚司在所之西原初制千户九人百户七人镇抚二人</sub></span>  
<span style="margin-left: 2em">兵额</span>  
<span style="margin-left: 2em"><sub class="note-yuan">本所原额旗军一千一百二十名内运粮四百七十名操备一百八十名共老幼二十六名食粮三斗余皆事故缺伍又三巡每军十名共三十名练陆哨兵所官一员管民兵三百名练水哨兵所官一员管民兵一百六十名哨船二十只管运粮所官一员统运船四十七只军四百七十名内在城船五只该军五十名在屯船四十二只该军四百二十名</sub></span>  
<span style="margin-left: 2em">军屯</span>  
<span style="margin-left: 2em"><sub class="note-yuan">本所屯田一百六十一顷四亩坐落上海县二十保共屯田军七百八十四名内运军四百十四名每名该征粮三石共一千二百四十二石城操三百七十名每名征粮六石共二千二百二十石二项共征屯田子粒三千四百六十二石抵作军人月粮如有不敷于华上青三县民粮派支本所城内外堑地连营地等项每岁该租银一百三十三两听本所征收抵军需支用本所派守四门千户各一员军余各十名</sub></span>  
<span style="margin-left: 2em">府境巡徼司兵之署</span>  
<span style="margin-left: 1em">凡内郡要冲地各设巡简司主讥往来奸慝及私贩禁</span>  
<span style="margin-left: 2em">盐逃亡军民罪囚并无引私越之人仍皆责以捕逮</span>  
<span style="margin-left: 2em">警逻之事府境巡简司皆设于洪武初后历有更置</span>  
<span style="margin-left: 2em">盖因其要阨之所有时变迁故司署亦随时异宜耳</span>  
<span style="margin-left: 1em">华亭金山司<sub class="note-yuan">洪武初建于张泾堰至十九年徙建胡家港口在华亭东南六十里</sub></span>  
<span style="margin-left: 1em">南桥司<sub class="note-yuan">洪武初原建于南桥镇称戚木司十九年徙建于戚木泾万历九年复徙于南桥改今名在华亭东南七十里</sub></span>  
<span style="margin-left: 1em">泖桥司<sub class="note-yuan">洪武三年建于泖桥之东数里洙泾镇在华亭西南三十六里</sub></span>  
<span style="margin-left: 1em">小贞司<sub class="note-yuan">洪武七年建于小蒸镇今镇地分属青浦而官属华亭在县西三十六里</sub></span>  
<span style="margin-left: 1em">上海黄浦司<sub class="note-yuan">洪武六年建于黄浦之上闵行镇在上海南二十一保</sub></span>  
<span style="margin-left: 2em">三林庄司<sub class="note-yuan">洪武六年建于三林塘镇在上海东南十七保</sub></span>  
<span style="margin-left: 2em">吴淞江司<sub class="note-yuan">洪武五年建于吴淞江北岸在上海西北二十七保</sub></span>  
<span style="margin-left: 1em">青浦新泾司<sub class="note-yuan">洪武六年建于二十九保新泾今在青浦四十五保青龙镇</sub></span>  
<span style="margin-left: 2em">淀山司<sub class="note-yuan">洪武初年建府西北六十里今在青浦四十二保安庄镇</sub></span>  
<span style="margin-left: 2em">南跄司即周浦司　　陶宅司<sub class="note-yuan">今俱</sub></span>  
<span style="margin-left: 9em">　　<sub class="note-yuan">废革</sub></span>  
<span style="margin-left: 2em">每司设巡简一员弓兵在腹里者例三十名沿海沿</span>  
<span style="margin-left: 2em">江者加额或至七十名松境惟淀山司弓兵四十名</span>  
<span style="margin-left: 2em">新泾等皆三十名各分信地每司以数镇属其官领</span>  
<span style="margin-left: 2em">之此皆昔之经畧地方者视村镇要害而设专为巡</span>  
<span style="margin-left: 2em">缉盗贼卫护村氓迩来废弛其司官或因公廨敝毁</span>  
<span style="margin-left: 2em">仍便僦住或因注选踵蹑任若传舍其司兵则或散</span>  
<span style="margin-left: 2em">处村落远迩不一或积棍宿蠧顶冒霸踞于地方有</span>  
<span style="margin-left: 2em">名无实即失事加罚噬脐无及殊失设官为民之意</span>  
<span style="margin-left: 2em">此当亟为区处修复廨宇着令官吏住札常川巡守</span>  
<span style="margin-left: 2em">弓兵务选附近精壮土著之人应役庶乎振作玩愒</span>  
<span style="margin-left: 2em">安民有赖矣</span>  
<span style="margin-left: 2em">一郡乡镇险要之防</span>  
<span style="margin-left: 1em">松郡东南濒海西襟湖泖盗贼出没尤警于海寇以一</span>  
<span style="margin-left: 2em">郡论之上海当贼之来华亭当贼之去青浦当苏松</span>  
<span style="margin-left: 2em">二郡往来之冲贼繇大海而来登泊海岸者必零贼</span>  
<span style="margin-left: 2em">也从江口而来径入者必大䑸也零贼登陆以渐而</span>  
<span style="margin-left: 2em">积易于勦除大䑸入江其势必甚扬帆直入城下然</span>  
<span style="margin-left: 2em">后分䑸掠华亭诸镇此必然之势也故上海当贼之</span>  
<span style="margin-left: 2em">来华亭附郭不当要冲然其西北淀山三泖可以遍</span>  
<span style="margin-left: 2em">苏州西南吕港独树可以通嘉兴贼如转寇二府必</span>  
<span style="margin-left: 2em">繇此进故华亭当贼之去青浦北通昆山东通吴淞</span>  
<span style="margin-left: 2em">西通湖泖若繇二郡出人此乃必繇之路故青浦当</span>  
<span style="margin-left: 2em">二郡往来之冲是一说也然嘉靖间贼连岁犯上海</span>  
<span style="margin-left: 2em">及松城未尝竟往他郡者惟水备吴淞所李家洪黄</span>  
<span style="margin-left: 2em">浦口而归重于宝山陆备青南川柘蔡庙独树营而</span>  
<span style="margin-left: 2em">归重于金山此一郡险要之完策也</span>  
<span style="margin-left: 1em">华亭依于府治犹腹心之居荣卫也似可少安然处营</span>  
<span style="margin-left: 2em">卫者以御侮为事居腹心者以偷安为常守御无方</span>  
<span style="margin-left: 2em">单弱莫甚且与浦泖相接盗贼啸聚靡常海寇少而</span>  
<span style="margin-left: 2em">内盗多则华亭非无事之国也议者谓宜慎选将才</span>  
<span style="margin-left: 2em">团练骁勇合于四郊津要处建置敌台少广之可瞭</span>  
<span style="margin-left: 2em">望亦可屯聚外有捍御则中夜巡警无前后牵制之</span>  
<span style="margin-left: 2em">虞向有扩西城议未暇举行兹尤便法也城中又严</span>  
<span style="margin-left: 2em">行保甲保甲之法人能言之第以虚文塞责耳今议</span>  
<span style="margin-left: 2em">一巷之中十人互结而以一二有力大家核其虚伪</span>  
<span style="margin-left: 2em">则奸究无所藏身绝内外勾引一旦有事人自为守</span>  
<span style="margin-left: 2em">古人巷战退贼当亦此意村落皆可行宜以郡人为</span>  
<span style="margin-left: 2em">倡录之以备采焉</span>  
<span style="margin-left: 2em">洙泾为华亭巨镇古于此置大盈务东通黄浦西通</span>  
<span style="margin-left: 2em">湖泖水寇睥睨之地也设泖桥巡司在镇巡缉以其</span>  
<span style="margin-left: 2em">南道水达海盐平湖北从泖达苏州嘉兴盐艘出没</span>  
<span style="margin-left: 2em">最便利故驵魁大猾号召暴横摇驾辄数十艘驰波</span>  
<span style="margin-left: 2em">飞水倏往倏来挟大众为捍蔽白日恣行亡命作奸</span>  
<span style="margin-left: 2em">之徒趋之为窟前华亭东鳌项公沾白俞公鲁斋章</span>  
<span style="margin-left: 2em">公相继擒灭诸猾立置之死得免挜盐威劫之苦云</span>  
<span style="margin-left: 2em">张泾隶华亭七保去县南五十里宋人堰海十八所</span>  
<span style="margin-left: 2em">之一也浦东场盐课司旧设于此后以牢盆相远别</span>  
<span style="margin-left: 2em">建官衙于堰南镇有陆路北通府治南通金山可以</span>  
<span style="margin-left: 2em">直达间有支河断港乡绅吴郡伯贞石造石梁数十</span>  
<span style="margin-left: 2em">以联之无事为乡民之便道有事为策应之冲衢昔</span>  
<span style="margin-left: 2em">年倭难时咸议金山离府太远兵势太孤欲特遣重</span>  
<span style="margin-left: 2em">兵一枝屯练于此为金山声援为郡南外护诚计之</span>  
<span style="margin-left: 2em">得也</span>  
<span style="margin-left: 2em">曹泾镇在华亭县东南七十里介于柘林金山之间</span>  
<span style="margin-left: 2em">逼处护塘之内居民皆煮海为生家率饶裕但为盐</span>  
<span style="margin-left: 2em">徒渊薮其操艘出人波涛闲习如御马海贼颇畏之</span>  
<span style="margin-left: 2em">往年倭夷内犯尝被此地盐艘驱迫一小岛中围之</span>  
<span style="margin-left: 2em">数匝焚其舟绝其粮贼大窘适大䑸至遁去故其时</span>  
<span style="margin-left: 2em">练乡兵之议有司请择本镇著姓异其礼貌使得部</span>  
<span style="margin-left: 2em">署灶丁结立团营以自为守一时亦暂行之</span>  
<span style="margin-left: 2em">叶谢在华亭东南地隶八保与萧塘邻其外为柘林</span>  
<span style="margin-left: 2em">处腹而势冲有事之日北与闵行须相策应西与漕</span>  
<span style="margin-left: 2em">泾须为犄角往年倭寇入巢柘林尝自此渡浦至瓜</span>  
<span style="margin-left: 2em">泾而西以犯府城此时议屯乡兵于镇以遏之</span>  
<span style="margin-left: 1em">上海与华亭形胜逈异贼多从海子口入不五十里为</span>  
<span style="margin-left: 2em">吴淞江为黄浦黄浦逼县东门贼至即抵城下然后</span>  
<span style="margin-left: 2em">分䑸或循浦而南或繇江而西皆可达郡城是一郡</span>  
<span style="margin-left: 2em">之要害在上海上海之要害在黄浦黄浦之要害在</span>  
<span style="margin-left: 2em">吴淞所吴淞所之要害在李家口守李家口以拒贼</span>  
<span style="margin-left: 2em">上游守黄浦口以遏贼横渡守御不出此</span>  
<span style="margin-left: 2em">嘉靖甲寅设海防道以佥事董邦政领之募战兵三</span>  
<span style="margin-left: 2em">千名备倭丁巳改海防道为海防同知存兵一千二</span>  
<span style="margin-left: 2em">百名己未因海上无警汰存兵六百名海防厅仍驻</span>  
<span style="margin-left: 2em">本府增派兵银支应隆庆己巳至壬申渐次减革止</span>  
<span style="margin-left: 2em">存兵二百七十名改于本县均徭内支应分为水陆</span>  
<span style="margin-left: 2em">二哨水兵七十名随海防驻本府陆兵额少不足防</span>  
<span style="margin-left: 2em">守邑治襟江带海盐盗出没无常城中时有寇警练</span>  
<span style="margin-left: 2em">兵者皆以失事被谴万历癸酉兵道调百户瞿彦威</span>  
<span style="margin-left: 2em">防守请归松江水兵复原额兵六百名六门设正兵</span>  
<span style="margin-left: 2em">六屯周城要害处设伏兵七队水兵分两翼上巡龙</span>  
<span style="margin-left: 2em">华港下巡东沟口以防外警兵粮向系练兵官散给</span>  
<span style="margin-left: 2em">兵苦侵渔后县官唱名面给万历乙亥因海上兵银</span>  
<span style="margin-left: 2em">不足议以徭银凑补遂复割本县兵额以一百六十</span>  
<span style="margin-left: 2em">名补川沙堡五十名补寳镇堡存兵三百九十名议</span>  
<span style="margin-left: 2em">者尚嫌寡弱思复旧额然此辈多豪家厮养市井无</span>  
<span style="margin-left: 2em">赖技艺殊不精专目前实为冗食但既有城池不容</span>  
<span style="margin-left: 2em">无兵守御惟在当事者汰冒滥核尺伍以时训练庶</span>

<span style="margin-left: 1em">宝山堡</span>  
<span style="margin-left: 2em">官兵<sub class="note-yuan">官无定员系吴淞所官军驻守造给营房听苏州府委官统摄又设民兵及兵船捕舵兵夫听松江府委官统练皆属里沙把总本堡设民兵五百名委总练官一员领兵宫一员新议增唬船四只每只捕舵兵夫一十四名</sub></span>
