## 崇禎松江府志卷之二十五　兵防

<span style="margin-left: 3em">兵防</span>  
<span style="margin-left: 1em">漢邊郡太守綰銅虎符得自興發討擊名爲守實郡將</span>  
<span style="margin-left: 1em">也第當事者治錢穀簿書不暇而暇理兵事乎惟名守</span>  
<span style="margin-left: 1em">與郡司馬共持籌而經畧之訓練世胄材官良家子而</span>  
<span style="margin-left: 1em">松有爪牙矣馬似游龍船如使馬而松有足矣多儲粻</span>  
<span style="margin-left: 1em">糗而松有腹矣瞭望明偵探信兵無虛伍餉無虛額陸</span>  
<span style="margin-left: 1em">路水路之門户無所不諳火戰水戰之器械無所不具</span>  
<span style="margin-left: 1em">而松有手眼矣如是其能乗釁蹈瑕以撼我張虛駕僞</span>  
<span style="margin-left: 1em">以嫚我乎况帶江襟泖濱海外寇少內盗多松非百年</span>  
<span style="margin-left: 1em">無事之國也未雨而桑未病而艾豈鰓鰓過計哉</span>  
<span style="margin-left: 2em">府城軍兵之制</span>  
<span style="margin-left: 1em">郡地在秦漢之際未爲山海要阨歷晉魏以後立亭設</span>  
<span style="margin-left: 2em">長以司譏察而已唐有縣始有兵宋制則設廂軍供</span>  
<span style="margin-left: 2em">縣之雜役禁軍供縣之守禦又有弓手爲縣之巡徼</span>  
<span style="margin-left: 2em">皆以募充元陞爲府至正十五年設總管軍兵萬户</span>  
<span style="margin-left: 2em">府建兩翼有千百户鎮撫等官後改鎮守萬户府以</span>  
<span style="margin-left: 2em">總軍政又置兵馬司治城內兼巡徼之事入　國朝</span>  
<span style="margin-left: 2em">洪武初設民兵萬户府簡民間武勇之人編成隊伍</span>  
<span style="margin-left: 2em">以時操練有事從征事平還復爲民有功者一體陞</span>  
<span style="margin-left: 2em">賞後革萬户府而設守禦松江千户所然其時尚每</span>  
<span style="margin-left: 2em">歲調蘇州衛官軍更番戍守至洪武三十年始定今</span>  
<span style="margin-left: 2em">制以金山衛中千户所一署分駐之開建公署於府</span>  
<span style="margin-left: 2em">治東南舊設千百户鎮撫二十三員旗軍一千一百</span>  
<span style="margin-left: 2em">二十名以守護城池設屯田一百六十一頃有奇歲</span>  
<span style="margin-left: 2em">收子粒三千四百六十餘石以充其月糧有不敷於</span>  
<span style="margin-left: 2em">三縣民糧支補軍兵之外又僉選民壯操練以備禦</span>  
<span style="margin-left: 2em">非常正統景泰以後歷有更制經嘉靖之倭警而兵</span>  
<span style="margin-left: 2em">額頓增隆萬承平稍爲裁减今見在者陸兵額設三</span>  
<span style="margin-left: 2em">百名舊以所官一員統練水兵額設二百名哨船二</span>  
<span style="margin-left: 2em">十隻亦以官一員統練每歲糧餉額徵銀三千三百</span>  
<span style="margin-left: 2em">六十九兩有奇</span>  
<span style="margin-left: 1em">守禦松江千户所<sub class="note-yuan">在府東南望仙橋東</sub></span>  
<span style="margin-left: 2em">兵職</span>  
<span style="margin-left: 2em"><sub class="note-yuan">本所正千户四員副千户七員掌印兼清軍屯局一管巡鹽巡江一管巡捕一管城操一管運糧一管練兵一管水哨一百户十員除故絕外見在四員聽差鎮撫二員鎮撫司在所之西原初制千户九人百户七人鎮撫二人</sub></span>  
<span style="margin-left: 2em">兵額</span>  
<span style="margin-left: 2em"><sub class="note-yuan">本所原額旗軍一千一百二十名內運糧四百七十名操備一百八十名共老幼二十六名食糧三斗餘皆事故缺伍又三巡每軍十名共三十名練陸哨兵所官一員管民兵三百名練水哨兵所官一員管民兵一百六十名哨船二十隻管運糧所官一員統運船四十七隻軍四百七十名內在城船五隻該軍五十名在屯船四十二隻該軍四百二十名</sub></span>  
<span style="margin-left: 2em">軍屯</span>  
<span style="margin-left: 2em"><sub class="note-yuan">本所屯田一百六十一頃四畝坐落上海縣二十保共屯田軍七百八十四名內運軍四百十四名每名該徵糧三石共一千二百四十二石城操三百七十名每名徵糧六石共二千二百二十石二項共徵屯田子粒三千四百六十二石抵作軍人月糧如有不敷於華上青三縣民糧派支本所城內外塹地連營地等項每歲該租銀一百三十三兩聽本所徵收抵軍需支用本所派守四門千户各一員軍餘各十名</sub></span>  
<span style="margin-left: 2em">府境巡徼司兵之署</span>  
<span style="margin-left: 1em">凡內郡要衝地各設巡簡司主譏往來姦慝及私販禁</span>  
<span style="margin-left: 2em">鹽逃亡軍民罪囚并無引私越之人仍皆責以捕逮</span>  
<span style="margin-left: 2em">警邏之事府境巡簡司皆設於洪武初後歷有更置</span>  
<span style="margin-left: 2em">蓋因其要阨之所有時變遷故司署亦隨時異宜耳</span>  
<span style="margin-left: 1em">華亭金山司<sub class="note-yuan">洪武初建於張涇堰至十九年徙建胡家港口在華亭東南六十里</sub></span>  
<span style="margin-left: 1em">南橋司<sub class="note-yuan">洪武初原建於南橋鎮稱戚木司十九年徙建於戚木涇萬曆九年復徙於南橋改今名在華亭東南七十里</sub></span>  
<span style="margin-left: 1em">泖橋司<sub class="note-yuan">洪武三年建於泖橋之東數里洙涇鎮在華亭西南三十六里</sub></span>  
<span style="margin-left: 1em">小貞司<sub class="note-yuan">洪武七年建於小蒸鎮今鎮地分屬青浦而官屬華亭在縣西三十六里</sub></span>  
<span style="margin-left: 1em">上海黃浦司<sub class="note-yuan">洪武六年建於黃浦之上閔行鎮在上海南二十一保</sub></span>  
<span style="margin-left: 2em">三林莊司<sub class="note-yuan">洪武六年建於三林塘鎮在上海東南十七保</sub></span>  
<span style="margin-left: 2em">吳淞江司<sub class="note-yuan">洪武五年建於吳淞江北岸在上海西北二十七保</sub></span>  
<span style="margin-left: 1em">青浦新涇司<sub class="note-yuan">洪武六年建於二十九保新涇今在青浦四十五保青龍鎮</sub></span>  
<span style="margin-left: 2em">澱山司<sub class="note-yuan">洪武初年建府西北六十里今在青浦四十二保安莊鎮</sub></span>  
<span style="margin-left: 2em">南蹌司即周浦司　　陶宅司<sub class="note-yuan">今俱</sub></span>  
<span style="margin-left: 9em">　　<sub class="note-yuan">廢革</sub></span>  
<span style="margin-left: 2em">每司設巡簡一員弓兵在腹裏者例三十名沿海沿</span>  
<span style="margin-left: 2em">江者加額或至七十名松境惟澱山司弓兵四十名</span>  
<span style="margin-left: 2em">新涇等皆三十名各分信地每司以數鎮屬其官領</span>  
<span style="margin-left: 2em">之此皆昔之經畧地方者視村鎮要害而設專爲巡</span>  
<span style="margin-left: 2em">緝盗賊衛護村氓邇來廢弛其司官或因公廨敝毁</span>  
<span style="margin-left: 2em">仍便僦住或因註選踵躡任若傳舍其司兵則或散</span>  
<span style="margin-left: 2em">處村落遠邇不一或積棍宿蠧頂冒霸踞於地方有</span>  
<span style="margin-left: 2em">名無實即失事加罰噬臍無及殊失設官爲民之意</span>  
<span style="margin-left: 2em">此當亟爲區處修復廨宇着令官吏住劄常川巡守</span>  
<span style="margin-left: 2em">弓兵務選附近精壯土著之人應役庶乎振作玩愒</span>  
<span style="margin-left: 2em">安民有賴矣</span>  
<span style="margin-left: 2em">一郡鄉鎮險要之防</span>  
<span style="margin-left: 1em">松郡東南瀕海西襟湖泖盗賊出没尤警於海寇以一</span>  
<span style="margin-left: 2em">郡論之上海當賊之來華亭當賊之去青浦當蘇松</span>  
<span style="margin-left: 2em">二郡往來之衝賊繇大海而來登泊海岸者必零賊</span>  
<span style="margin-left: 2em">也從江口而來逕入者必大䑸也零賊登陸以漸而</span>  
<span style="margin-left: 2em">積易於勦除大䑸入江其勢必甚揚帆直入城下然</span>  
<span style="margin-left: 2em">後分䑸掠華亭諸鎮此必然之勢也故上海當賊之</span>  
<span style="margin-left: 2em">來華亭附郭不當要衝然其西北澱山三泖可以遍</span>  
<span style="margin-left: 2em">蘇州西南呂港獨樹可以通嘉興賊如轉寇二府必</span>  
<span style="margin-left: 2em">繇此進故華亭當賊之去青浦北通崑山東通吳淞</span>  
<span style="margin-left: 2em">西通湖泖若繇二郡出人此乃必繇之路故青浦當</span>  
<span style="margin-left: 2em">二郡往來之衝是一說也然嘉靖間賊連歲犯上海</span>  
<span style="margin-left: 2em">及松城未嘗竟往他郡者惟水備吳淞所李家洪黃</span>  
<span style="margin-left: 2em">浦口而歸重於寶山陸備青南川柘蔡廟獨樹營而</span>  
<span style="margin-left: 2em">歸重於金山此一郡險要之完策也</span>  
<span style="margin-left: 1em">華亭依於府治猶腹心之居榮衛也似可少安然處營</span>  
<span style="margin-left: 2em">衛者以禦侮爲事居腹心者以偷安爲常守禦無方</span>  
<span style="margin-left: 2em">單弱莫甚且與浦泖相接盜賊嘯聚靡常海寇少而</span>  
<span style="margin-left: 2em">內盜多則華亭非無事之國也議者謂宜慎選將才</span>  
<span style="margin-left: 2em">團練驍勇合於四郊津要處建置敵臺少廣之可瞭</span>  
<span style="margin-left: 2em">望亦可屯聚外有捍禦則中夜巡警無前後牽制之</span>  
<span style="margin-left: 2em">虞向有擴西城議未暇舉行兹尤便法也城中又嚴</span>  
<span style="margin-left: 2em">行保甲保甲之法人能言之第以虛文塞責耳今議</span>  
<span style="margin-left: 2em">一巷之中十人互結而以一二有力大家覈其虛僞</span>  
<span style="margin-left: 2em">則奸究無所藏身絕內外勾引一旦有事人自爲守</span>  
<span style="margin-left: 2em">古人巷戰退賊當亦此意村落皆可行宜以郡人爲</span>  
<span style="margin-left: 2em">倡錄之以備採焉</span>  
<span style="margin-left: 2em">洙涇爲華亭巨鎮古於此置大盈務東通黃浦西通</span>  
<span style="margin-left: 2em">湖泖水寇睥睨之地也設泖橋巡司在鎮巡緝以其</span>  
<span style="margin-left: 2em">南道水達海鹽平湖北從泖達蘇州嘉興鹽艘出没</span>  
<span style="margin-left: 2em">最便利故駔魁大猾號召暴横摇駕輒數十艘馳波</span>  
<span style="margin-left: 2em">飛水倏往倏來挾大衆爲扞蔽白日恣行亡命作奸</span>  
<span style="margin-left: 2em">之徒趨之爲窟前華亭東鰲項公沾白俞公魯齋章</span>  
<span style="margin-left: 2em">公相繼擒滅諸猾立置之死得免掗鹽威劫之苦云</span>  
<span style="margin-left: 2em">張涇隸華亭七保去縣南五十里宋人堰海十八所</span>  
<span style="margin-left: 2em">之一也浦東場鹽課司舊設於此後以牢盆相遠別</span>  
<span style="margin-left: 2em">建官衙於堰南鎮有陸路北通府治南通金山可以</span>  
<span style="margin-left: 2em">直達間有支河斷港鄉紳吳郡伯貞石造石梁數十</span>  
<span style="margin-left: 2em">以聯之無事爲鄉民之便道有事爲策應之衝衢昔</span>  
<span style="margin-left: 2em">年倭難時咸議金山離府太遠兵勢太孤欲特遣重</span>  
<span style="margin-left: 2em">兵一枝屯練於此爲金山聲援爲郡南外護誠計之</span>  
<span style="margin-left: 2em">得也</span>  
<span style="margin-left: 2em">曹涇鎮在華亭縣東南七十里介於柘林金山之間</span>  
<span style="margin-left: 2em">逼處護塘之內居民皆煮海爲生家率饒裕但爲鹽</span>  
<span style="margin-left: 2em">徒淵藪其操艘出人波濤閑習如御馬海賊頗畏之</span>  
<span style="margin-left: 2em">往年倭夷內犯嘗被此地鹽艘驅迫一小島中圍之</span>  
<span style="margin-left: 2em">數匝焚其舟絕其糧賊大窘適大䑸至遁去故其時</span>  
<span style="margin-left: 2em">練鄉兵之議有司請擇本鎮著姓異其禮貌使得部</span>  
<span style="margin-left: 2em">署竈丁結立團營以自爲守一時亦暫行之</span>  
<span style="margin-left: 2em">葉謝在華亭東南地隸八保與蕭塘鄰其外爲柘林</span>  
<span style="margin-left: 2em">處腹而勢衝有事之日北與閔行須相策應西與漕</span>  
<span style="margin-left: 2em">涇須爲犄角往年倭寇入巢柘林嘗自此渡浦至瓜</span>  
<span style="margin-left: 2em">涇而西以犯府城此時議屯鄉兵於鎮以遏之</span>  
<span style="margin-left: 1em">上海與華亭形勝逈異賊多從海子口入不五十里爲</span>  
<span style="margin-left: 2em">吳淞江爲黃浦黃浦逼縣東門賊至即抵城下然後</span>  
<span style="margin-left: 2em">分䑸或循浦而南或繇江而西皆可達郡城是一郡</span>  
<span style="margin-left: 2em">之要害在上海上海之要害在黃浦黃浦之要害在</span>  
<span style="margin-left: 2em">吳淞所吳淞所之要害在李家口守李家口以拒賊</span>  
<span style="margin-left: 2em">上游守黃浦口以遏賊横渡守禦不出此</span>  
<span style="margin-left: 2em">嘉靖甲寅設海防道以僉事董邦政領之募戰兵三</span>  
<span style="margin-left: 2em">千名備倭丁巳改海防道爲海防同知存兵一千二</span>  
<span style="margin-left: 2em">百名己未因海上無警汰存兵六百名海防廳仍駐</span>  
<span style="margin-left: 2em">本府增派兵銀支應隆慶己巳至壬申漸次减革止</span>  
<span style="margin-left: 2em">存兵二百七十名改於本縣均徭內支應分爲水陸</span>  
<span style="margin-left: 2em">二哨水兵七十名隨海防駐本府陸兵額少不足防</span>  
<span style="margin-left: 2em">守邑治襟江帶海鹽盜出没無常城中時有寇警練</span>  
<span style="margin-left: 2em">兵者皆以失事被譴萬曆癸酉兵道調百户瞿彦威</span>  
<span style="margin-left: 2em">防守請歸松江水兵復原額兵六百名六門設正兵</span>  
<span style="margin-left: 2em">六屯周城要害處設伏兵七隊水兵分兩翼上巡龍</span>  
<span style="margin-left: 2em">華港下巡東溝口以防外警兵糧向係練兵官散給</span>  
<span style="margin-left: 2em">兵苦侵漁後縣官唱名面給萬曆乙亥因海上兵銀</span>  
<span style="margin-left: 2em">不足議以徭銀凑補遂復割本縣兵額以一百六十</span>

<span style="margin-left: 2em">人之中必有一人得之以爲大將此一人之智勇乃</span>  
<span style="margin-left: 2em">萬人之選也</span>  
<span style="margin-left: 2em">今之禦寇者平時不思訓練有事則調客兵不知客</span>  
<span style="margin-left: 2em">兵之驕悍甚于虜寇且其志不在于戰而在于擄不</span>  
<span style="margin-left: 2em">易約束而易于逃元末松郡被楊完者禍甚慘以苗</span>  
<span style="margin-left: 2em">兵也嘉靖間以倭亂調廣兵調土番兵俱無功而制</span>  
<span style="margin-left: 2em">勝者皆募之近地及鄉兵乃知遠募不如近募用多</span>  
<span style="margin-left: 2em">不如用精</span>  
<span style="margin-left: 2em">海中以風潮爲主水操之法欲進則進欲退則退欲</span>  
<span style="margin-left: 2em">轉折則轉折回翔如飛横風鬬風皆能調戧者惟沙</span>  
<span style="margin-left: 2em">船也其次則蒼艟之類帆櫓兼用亦可操演若廣船</span>  
<span style="margin-left: 2em">福船皆不設櫓所恃者帆耳其船重大順風而往逆</span>  
<span style="margin-left: 2em">風即不可回棄潮而往逆潮即不可回進退轉折皆</span>  
<span style="margin-left: 2em">非所便也將欲操之于內港歟則又港形甚狹潮勢</span>  
<span style="margin-left: 2em">甚迅兵船操者甚多大船順風其迅如矢向前衝擊</span>  
<span style="margin-left: 2em">舟遇即碎故斷斷乎不可行惟募舵工得人奪上風</span>  
<span style="margin-left: 2em">施火器或迎而犂或尾而追或合而圍或横而衝總</span>  
<span style="margin-left: 2em">副參遊注意遴選賞罰則可耳</span>  
<span style="margin-left: 2em">松郡稱水鄉邊則大海腸則泖浦尤不可不習水操</span>  
<span style="margin-left: 2em">法然古今論操法戰法皆詳于陸地而畧于江海以</span>  
<span style="margin-left: 2em">風潮爲主分合進退難也勝之之法惟有鬬船力不</span>  
<span style="margin-left: 2em">鬬人力如遇賊舟之小者則以吾大舟犂而沉之遇</span>  
<span style="margin-left: 2em">賊舟之大者則使調戧奪上風用火器以攻之當前</span>  
<span style="margin-left: 2em">衝敵者一舟之人皆賞觀望不應援者一舟之人皆</span>  
<span style="margin-left: 2em">戮其賞其戮尤以督哨之人與舵工爲重每船必設</span>  
<span style="margin-left: 2em">舵二副以備不虞每舵工必設二三人以防損失此</span>  
<span style="margin-left: 2em">戰之之法也其在平日置船于陸地上集水兵演而</span>  
<span style="margin-left: 2em">教之兵械火器如何而設施金鼓旗幟如何而照會</span>  
<span style="margin-left: 2em">前後左右如何而列哨飢飽勞逸如何而更代晝夜</span>  
<span style="margin-left: 2em">風雨如何而防守山島沙磧如何而收泊號令約束</span>  
<span style="margin-left: 2em">如何而轉報習之于平陸用之于江海此操之之法</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 2em">奚秋蟾云海中有風時多無風時少舟易散而難聚</span>  
<span style="margin-left: 2em">且逐潮勢而行若風猛潮平則以風爲主潮湧風微</span>  
<span style="margin-left: 2em">則以潮爲主風潮皆逆則回船向後而行風潮皆順</span>  
<span style="margin-left: 2em">則一瀉千里每日所行程途之數與東西朔南方向</span>  
<span style="margin-left: 2em">皆不可料敵船亦然故吾行若干里敵亦行若干里</span>  
<span style="margin-left: 2em">愈追愈遠愈求戰而愈不得况兵船分行大海渺茫</span>  
<span style="margin-left: 2em">有與我相望而見者有不可望見者昏黑之夜起火</span>  
<span style="margin-left: 2em">爲號則隱隱見之然亦不能辨其爲賊船與我兵船</span>  
<span style="margin-left: 2em">也有時遇賊欲戰而吾同哨離遠則勢孤而罷有時</span>  
<span style="margin-left: 2em">鄰哨相近敵舟又遠難於攻擊有時我兵偶合敵舟</span>  
<span style="margin-left: 2em">亦近可以戰矣而風或大作舟在浪漕中低昂起伏</span>  
<span style="margin-left: 2em">方欲仰而攻敵瞬眼之間吾舟忽擡高一二丈敵舟</span>  
<span style="margin-left: 2em">反在下矣船出浪漕之時船首向天落漕時船尾向</span>  
<span style="margin-left: 2em">天兵士竚立且難况戰乎亦有風不甚猛可以戰時</span>  
<span style="margin-left: 2em">而怒濤爲虐兩舟相擊即碎亦不敢戰惟是舵工巧</span>  
<span style="margin-left: 2em">妙能占上風撞碎賊舟或乗風火攻或揚灰沙以迷</span>  
<span style="margin-left: 2em">賊目方得勝勢所患者一舟衝前而餘舟不至或一</span>  
<span style="margin-left: 2em">哨接戰而餘哨不援方其戰時我兵四散遠望麾旗</span>  
<span style="margin-left: 2em">而招之弗顧也張號以唤之弗聽也戰敗則終不集</span>  
<span style="margin-left: 2em">戰勝則聚而分功及責之則托諸風帆不便今又皆</span>  
<span style="margin-left: 2em">傳海戰利用火箭與銃砲弓弩殆非也火箭惟微風</span>  
<span style="margin-left: 2em">可用若無風則帆不可焚風急則火亦反熄皆無益</span>  
<span style="margin-left: 2em">也銃砲弓矢因舟蕩漾發去無准皆虛送于浪中鎗</span>  
<span style="margin-left: 2em">鈀之類亦無所用惟鏢鎗鈎鎗鐃鈎三件舟在上風</span>  
<span style="margin-left: 2em">者以鐃鈎鈎住下風之舟以鈎鎗鈎扯賊人之足以</span>  
<span style="margin-left: 2em">鏢鎗鏢射賊人之身胥爲有用之器</span>  
<span style="margin-left: 1em">船艦附載</span>  
<span style="margin-left: 2em">武經總要曰凡水戰以船艦大小爲等勝人多少皆</span>  
<span style="margin-left: 2em">以米爲准一人不過重米二石帆櫓輕便爲上以金</span>  
<span style="margin-left: 2em">鼓旗幡爲進退之節其戰則有樓船鬬艦走舸海鶻</span>  
<span style="margin-left: 2em">其潛襲則有艨衝遊舸其器則有拍竿爲其用順流</span>  
<span style="margin-left: 2em">以擊之諸軍視大將之旗旗前亞聞鼓進則旗立聞</span>  
<span style="margin-left: 2em">金則止旗偃則還若先鋒遊奕等船爲賊所圍以須</span>  
<span style="margin-left: 2em">外援則視大將赤旗向賊點則進每點一船進旗亞</span>  
<span style="margin-left: 2em">不舉則戰船徐退旗向內點每點一船退若張疑兵</span>  
<span style="margin-left: 2em">則于浦海廣設旌旗檣帆以惑之此其大畧也</span>
