## 崇禎松江府志卷之七　風俗

<span style="margin-left: 3em">風俗</span>  
<span style="margin-left: 1em">千里不同風百里不同俗史無臚載者載之自應劭風</span>  
<span style="margin-left: 1em">俗通始其後荆楚歲時記東京夢華錄皆昉於劭而郡</span>  
<span style="margin-left: 1em">國志亦不廢焉吾松正德辛巳以來日新月異自儉入</span>  
<span style="margin-left: 1em">奢即自盛入衰之兆也吾友青蓮子有風俗二十四變</span>  
<span style="margin-left: 1em">而未敢暢言之者何曰太上因之也昔子貢觀蜡以爲</span>  
<span style="margin-left: 1em">狂夫子曉之曰百日之勞一日之澤蓋因民俗而不嚴</span>  
<span style="margin-left: 1em">爲之禁如此第去其太甚而已</span>  
<span style="margin-left: 1em">總論</span>  
<span style="margin-left: 2em">陸機吳趨行云山澤多藏育土風清且嘉又云文德</span>  
<span style="margin-left: 2em">熙淳懿武功侔山河禮讓何濟濟流化自滂沱又懷</span>  
<span style="margin-left: 2em">土賦云余去家漸久懷土彌篤方思之殷何物不感</span>  
<span style="margin-left: 2em">曲街委巷罔不興詠水泉草木咸足悲焉故述斯賦</span>  
<span style="margin-left: 2em">背故都之衍沃適新邑之丘墟</span>  
<span style="margin-left: 2em">潘尼贈陸機詩云祁祁大邦惟桑惟梓穆穆伊入南</span>  
<span style="margin-left: 2em">國之紀</span>  
<span style="margin-left: 2em">左思吳都賦云高門鼎貴魁岸豪傑虞魏之昆顧陸</span>  
<span style="margin-left: 2em">之裔岐凝繼體老成奕世躍馬疊跡朱輪累轍冠蓋</span>  
<span style="margin-left: 2em">雲蔭閭閻闐噎又水浮陸行方舟結駟唱棹轉轂昧</span>  
<span style="margin-left: 2em">旦永日富中之甿貨殖之選乘時射利財豐盈萬競</span>  
<span style="margin-left: 2em">其區宇則并彊兼巷娱其宴居則珠服玉饌</span>  
<span style="margin-left: 2em">白居易詩云吳中好風景八月如三月水荇葉仍香</span>  
<span style="margin-left: 2em">木蓮花未歇海天微雨散江郭纖埃滅暑退衣服乾</span>  
<span style="margin-left: 2em">潮生船舫活兩衙漸多暇亭午初無熱騎吏語使君</span>  
<span style="margin-left: 2em">正是游時節</span>  
<span style="margin-left: 2em">許克昌云地東南負海北通江有魚鹽稻蟹之饒多</span>  
<span style="margin-left: 2em">富商大賈俗以浮侈相高不能力本業然衣冠之盛</span>  
<span style="margin-left: 2em">亦爲江浙諸縣之最雖佃家中人衣食纔足喜教子</span>  
<span style="margin-left: 2em">弟以讀書秀民才士往往起家爲達官繇是競勸于</span>  
<span style="margin-left: 2em">學弦歌之聲相聞居官不必以擊斷鷙猛爲治亦可</span>  
<span style="margin-left: 2em">以禮義馴服也</span>  
<span style="margin-left: 2em">魏了翁云吳中族姓人物之盛自東漢以來有聞于</span>  
<span style="margin-left: 2em">世逮魏晉而後彬彬輩出左太冲所謂高門鼎貴魁</span>  
<span style="margin-left: 2em">岸豪傑虞魏之昆顧陸之裔雖通言吳郡而居華亭</span>  
<span style="margin-left: 2em">者爲尤著蓋其地負海枕江平疇沃野生民之資用</span>  
<span style="margin-left: 2em">饒衍得以畢力于當事故士奮於學民興於仁</span>  
<span style="margin-left: 2em">趙孟頫云松江古句吳之地吳小且遠至季札知樂</span>  
<span style="margin-left: 2em">其文始通上國今天下一家地大物衆鄉聚成郡邑</span>  
<span style="margin-left: 2em">昔之海隅商賈百貨禮殿儒宫巖巖翼翼粲然不異</span>  
<span style="margin-left: 2em">鄒魯</span>  
<span style="margin-left: 2em">薩天錫詩云三山雲海幾千里十幅蒲帆掛秋水吳</span>  
<span style="margin-left: 2em">中過客莫思家江南畫船如屋裏蘆芽短短穿碧紗</span>  
<span style="margin-left: 2em">船頭鯉魚吹浪花吳姬蕩槳入城去細雨小寒生綠</span>  
<span style="margin-left: 2em">紗我歌水調無人續江上月凉吹紫竹春風一曲鷓</span>  
<span style="margin-left: 2em">鴣詞花落鶯啼滿城綠</span>  
<span style="margin-left: 2em">董良史曰王教雍和秀茂挺逸英偉既多風謡亦作</span>  
<span style="margin-left: 3em">土膏氣秀人食稻魚俗不愁苦然地沃人驕奢侈</span>  
<span style="margin-left: 2em">頗異</span>  
<span style="margin-left: 2em">邵亨貞記云華亭爲濱海壯邑因九峯三泖之勝而</span>  
<span style="margin-left: 2em">置司官焉晉陸士衡陳顧野王而下人才輩出民俗</span>  
<span style="margin-left: 2em">殷富逮唐宋間幾與列郡抗以五代南渡之亂民有</span>  
<span style="margin-left: 2em">不知兵者生聚五百年至宋末而盛劇矣宋社既遷</span>  
<span style="margin-left: 2em">名家鉅室罔不與國同休戚者貴游子弟華顛野服</span>  
<span style="margin-left: 2em">欷歔喬木之下彷彿黍離之間相望于寬閒寂寞者</span>  
<span style="margin-left: 2em">百年于兹矣</span>  
<span style="margin-left: 2em">嘉秀軒記云禹貢揚州之域曰三江既入震澤底定</span>  
<span style="margin-left: 2em">厥草惟夭厥木惟<sub class="note-jiao">校：惟字當惟字之音訛據嘉秀軒記改</sub>喬蓋三江導</span>  
<span style="margin-left: 2em">震澤之水東入於海江之南北壤地數百里土肥而</span>  
<span style="margin-left: 2em">木茂民生敦龐而富庶地志所載讀書宦達者歷代</span>  
<span style="margin-left: 2em">皆有人焉</span>  
<span style="margin-left: 2em">貝瓊云初余游九峯三泖間嘗愛其俗務本而好學</span>  
<span style="margin-left: 2em">故無不耕之民無不食之地而諸謝雄蓋一邑比古</span>  
<span style="margin-left: 2em">之秦陽</span>  
<span style="margin-left: 2em">陶安曰華亭古名邑倚郭于松江曩余識其文物類</span>  
<span style="margin-left: 2em">修整醖藉有機雲遺思唯是啓義理之秘藥浮奢之</span>  
<span style="margin-left: 2em">疴新耳目之習謹身心之修相與考德業美風化者</span>  
<span style="margin-left: 2em">則司教之責也</span>  
<span style="margin-left: 2em">何良俊曰我松文物之盛莫甚於元浙西諸郡皆爲</span>  
<span style="margin-left: 2em">戰場而我松僻峯泖之間以及海上皆可避兵故四</span>  
<span style="margin-left: 2em">方名流彙萃於此薰陶漸染之功爲多</span>  
<span style="margin-left: 1em">習尚</span>  
<span style="margin-left: 1em">松故吳之裔壤負海枕江土膏沃饒風俗淳秀其習尚</span>  
<span style="margin-left: 2em">亦各有所宗自東都以後陸氏居之康績以行誼聞</span>  
<span style="margin-left: 2em">遜抗以功名顯機雲以詞學著國人化之梁有顧希</span>  
<span style="margin-left: 2em">馮唐有陸敬輿至宋而科名盛故其俗文原澤沃衍</span>  
<span style="margin-left: 2em">有魚稻海鹽之富商賈輻輳故其俗侈有康僧會船</span>  
<span style="margin-left: 2em">子夾山之遺蹤故尚佛有金山柘湖之靈跡故信鬼</span>  
<span style="margin-left: 2em">神好淫祀有三甲五甲之風故或號難理文物衣冠</span>  
<span style="margin-left: 2em">蔚爲東南之望經學詞章下至書翰咸有師法各稱</span>  
<span style="margin-left: 2em">名家田野小民生理裁足皆知以教子孫讀書爲事</span>  
<span style="margin-left: 2em">故士奮于學民興于仁租稅百萬歲期而集雖役重</span>  
<span style="margin-left: 2em">賦煩身重敲榜中未嘗有一言犯上罹淫放不孝之</span>  
<span style="margin-left: 2em">刑故嚚訟者少淳良者多舊志云諸州外縣多樸質</span>  
<span style="margin-left: 2em">附郭多繁華吾松則反是蓋東北五鄉故爲海商馳</span>  
<span style="margin-left: 2em">騖之地而其南純事耕織故所習不同如此大率府</span>  
<span style="margin-left: 2em">城之俗謹繩墨畏清議而其流失之隘上海之俗喜</span>  
<span style="margin-left: 2em">事功尚意氣而其流失之夸尚清雅飾玩好境內皆</span>  
<span style="margin-left: 2em">然而西南爲盛然畏首事喜隨衆而府城以之諺所</span>  
<span style="margin-left: 2em">謂松江齊也</span>  
<span style="margin-left: 2em">吉凶多沿俗禮冠不備三加婚事親迎喪事亦尚佛</span>  
<span style="margin-left: 2em">老舊志載天順景泰以前男子窄袖短躬衫裾幅甚</span>  
<span style="margin-left: 2em">狹雖士人亦然婦女平髻寬衫制極樸古婚會以大</span>  
<span style="margin-left: 2em">衣俗謂之襖子領袖緣以圈金或挑綫爲上飾其綵</span>  
<span style="margin-left: 2em">繡織金之類非仕宦家絕不敢用燕會果肴以四色</span>  
<span style="margin-left: 2em">至五色而止尤重師範時教授以下至府以賓禮見</span>  
<span style="margin-left: 2em">不庭參燕科貢士時皆上坐景泰中猶然見部使者</span>  
<span style="margin-left: 2em">長揖不跪使者蒞學進講坐堂之西序成化中猶然</span>  
<span style="margin-left: 2em">今自顧文僖公以來凡百十餘年俗日多靡民日凋</span>  
<span style="margin-left: 2em">攰無復昔日風規矣江淹曰經邦緯治去華爲急體</span>  
<span style="margin-left: 2em">國制變循素爲先是在坊民者有以風之其君子之</span>  
<span style="margin-left: 2em">德乎若四時節序閭井所尚與舊志小有同異亦略</span>  
<span style="margin-left: 2em">得而紀焉</span>  
<span style="margin-left: 1em">歲時</span>  
<span style="margin-left: 1em">正月一日春秋謂之端月雞鳴起悉正衣冠拜天地家</span>  
<span style="margin-left: 2em">廟尊長後以次拜鄰里親戚盛輿服往來馳遝各投</span>  
<span style="margin-left: 2em">刺于門爲賀歲文衡山太史詩云新春車馬賀年初</span>  
<span style="margin-left: 2em">名刺紛紛滿舊廬我亦隨人投一紙世情嫌簡不嫌</span>  
<span style="margin-left: 2em">虛此風蘇松皆同一日至三日禁不掃除室中小兒</span>  
<span style="margin-left: 2em">競擊鑼鼓爲罷市立春前一日以綵仗迎春于東郊</span>  
<span style="margin-left: 2em">又先一日鼓樂雜伎先呈府縣爲呈宴至日士女觀</span>  
<span style="margin-left: 2em">者垂簾闐市茹春餅進春酒爲看春立春之候祭芒</span>  
<span style="margin-left: 2em">神鞭土牛舊志于七日八日九日會佛寺名龍華今</span>  
<span style="margin-left: 2em">廢上旬之暮女子邀卜厠姑又向竈爲嚮卜以秫穀</span>  
<span style="margin-left: 2em">投釜爆之名卜流花又名米花女子曳綵戴珍珥以</span>  
<span style="margin-left: 2em">金珠翡翠相誇尚上元前後爲元宵節家製粉餌爲</span>  
<span style="margin-left: 2em">看燈圓即舊志呼珍珠圓也及油䭔亦以粉爲之采</span>  
<span style="margin-left: 2em">竹結棚於通衢燈皆刻飾紙帛穿綴綵珠剪簇絢繪</span>  
<span style="margin-left: 2em">工競百巧市人各掛綵懸流蘇以障幕覆之金鼓管</span>  
<span style="margin-left: 2em">絃火樹最勝游人往往達曙爲常是夕農家争束芻</span>  
<span style="margin-left: 2em">徧燒田間謂照田蠶家祀竈爲接竈按禮樂器竈者</span>  
<span style="margin-left: 2em">老婦之祭尊于餅盛于盆言瓶爲尊盆盛饌也舊志</span>  
<span style="margin-left: 2em">十七日會普照寺燃巨燭士女七日方散月內誦連</span>  
<span style="margin-left: 2em">華經又醮章爲禳火已不復見</span>  
<span style="margin-left: 2em"><sub class="note-yuan">郡守許公維新元宵詩元宵氣候和微雲淡河漢然燈起東風聊作豐登辦糕繭兆繭良遂爲先蠶奠太守分爲民取作耳目玩迅雷忽砰砯花燭紅燦爛冲空萬虹流矯如射天箭鼓吹衆壘鳴有如鉅鹿戰海潮沸疑愛方昏又忽旦北方瘠土生驟然經未慣彷皇步庭階呼僮防火患開關告海防或然有外變轉笑告者迂無聊坐夜半棲烏禁不鳴樓角寂宿鸛豈亦訝非常焚巢愁禍亂良久月沉西燈宵火亦倦熱鬧逐霜零鼓角隨風散燈花有幾錢量貴應無算消者灰與塵散者衣若飯即此耳目前可卜餘鄉縣富貴猶堪惜如此貧與賤夏畦苦作勞當午滴禾汗膏血一粒艱用作泥沙盼急來不勝情枉競田廬畔争鬪亦無術不情告加嘆重求却失輕作此顛倒見雖去鄙吝心此理無難判荆楚風土謡往古先賢傳本以教耕桑末流成惑眩害財最苦奢足民莫如儉歲穀餘三年中仍慮水旱此宵已如斯八節費巨萬往歲魃爲妖揚塵江流斷茹草腹不充道殭嗟逋竄安得燈與花煮作飢寒膳奈何揮金穀泖底九峯澗年祲再禱神神恫民亦怨禁屠與止沽赴南如北面守臣罪可誅何不爲民勸燎原足易焚射天是恭慢無禮召祝融恣錢買禍難馬舞青樓街熊嘯錦廛徧此其在眼前皆可爲殷鑒齊傖不能詞存爲不職案省費反樸風何勝愜大顯</sub></span>  
<span style="margin-left: 1em">二月十二日百花生日以紅綵繫群卉十九日觀音大</span>  
<span style="margin-left: 2em">士誕晨群詣佛寺進香始放風鳶亦曰風筝又曰放</span>  
<span style="margin-left: 2em">鷂子即仁寶云春之風自下而升紙鳶因之以起夜</span>  
<span style="margin-left: 2em">以燈爇燭懸線而升之亦有烟火飛如繁星</span>  
<span style="margin-left: 1em">三月清明祀先家設野祭拜掃先塋掛紙錢謂之紙幢</span>  
<span style="margin-left: 2em">家長率子孫咸往名標墓俗折柳枝及薺花戴于首</span>  
<span style="margin-left: 2em">清明先三日郡牒　城隍神至期請詣厲壇郡民執</span>  
<span style="margin-left: 2em">香花騎從擁導前後者數萬餘人至晚復以華燈千</span>  
<span style="margin-left: 2em">炬迎歸入廟七月十五日十月一日亦如之元時于</span>  
<span style="margin-left: 2em">是日有鞦韆之戲</span>  
<span style="margin-left: 2em">舊志載歌咢游山迎會先時巫者舁神偶沿門互唱</span>  
<span style="margin-left: 2em">索錢結綵成幡勝以奉嶽神爲錢幡會至今有之自</span>  
<span style="margin-left: 2em">茶笋之候九峯惟佘山神山干山畫舫鱗次徵歌載</span>  
<span style="margin-left: 2em">酒游者無虛日二十八日東岳帝誕辰里人聚鼓樂</span>  
<span style="margin-left: 2em">旗旛騎蓋迎神于東岳廟</span>  
<span style="margin-left: 1em">四月八日俗稱浴佛之辰浮屠設供以水浴釋迦像謂</span>  
<span style="margin-left: 2em">九龍吐水之日也舊志于是日迎華光會</span>  
<span style="margin-left: 1em">五月朔日貼門符端午收桃艾競采雜藥夏小正此月</span>  
<span style="margin-left: 2em">蓄藥以蠲毒氣切菖蒲屑雄黃酒中合老幼飲之云</span>  
<span style="margin-left: 2em">辟邪有織組雜物相贈遺囊雄黃以佩小兒噉角黍</span>
