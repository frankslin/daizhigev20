## 崇祯松江府志卷之七　风俗

<span style="margin-left: 3em">风俗</span>  
<span style="margin-left: 1em">千里不同风百里不同俗史无胪载者载之自应劭风</span>  
<span style="margin-left: 1em">俗通始其后荆楚岁时记东京梦华录皆昉于劭而郡</span>  
<span style="margin-left: 1em">国志亦不废焉吾松正德辛巳以来日新月异自俭入</span>  
<span style="margin-left: 1em">奢即自盛入衰之兆也吾友青莲子有风俗二十四变</span>  
<span style="margin-left: 1em">而未敢畅言之者何曰太上因之也昔子贡观蜡以为</span>  
<span style="margin-left: 1em">狂夫子晓之曰百日之劳一日之泽盖因民俗而不严</span>  
<span style="margin-left: 1em">为之禁如此第去其太甚而已</span>  
<span style="margin-left: 1em">总论</span>  
<span style="margin-left: 2em">陆机吴趋行云山泽多藏育土风清且嘉又云文德</span>  
<span style="margin-left: 2em">熙淳懿武功侔山河礼让何济济流化自滂沱又怀</span>  
<span style="margin-left: 2em">土赋云余去家渐久怀土弥笃方思之殷何物不感</span>  
<span style="margin-left: 2em">曲街委巷罔不兴咏水泉草木咸足悲焉故述斯赋</span>  
<span style="margin-left: 2em">背故都之衍沃适新邑之丘墟</span>  
<span style="margin-left: 2em">潘尼赠陆机诗云祁祁大邦惟桑惟梓穆穆伊入南</span>  
<span style="margin-left: 2em">国之纪</span>  
<span style="margin-left: 2em">左思吴都赋云高门鼎贵魁岸豪杰虞魏之昆顾陆</span>  
<span style="margin-left: 2em">之裔岐凝继体老成奕世跃马叠迹朱轮累辙冠盖</span>  
<span style="margin-left: 2em">云荫闾阎阗噎又水浮陆行方舟结驷唱棹转毂昧</span>  
<span style="margin-left: 2em">旦永日富中之甿货殖之选乘时射利财丰盈万竞</span>  
<span style="margin-left: 2em">其区宇则并彊兼巷娱其宴居则珠服玉馔</span>  
<span style="margin-left: 2em">白居易诗云吴中好风景八月如三月水荇叶仍香</span>  
<span style="margin-left: 2em">木莲花未歇海天微雨散江郭纤埃灭暑退衣服乾</span>  
<span style="margin-left: 2em">潮生船舫活两衙渐多暇亭午初无热骑吏语使君</span>  
<span style="margin-left: 2em">正是游时节</span>  
<span style="margin-left: 2em">许克昌云地东南负海北通江有鱼盐稻蟹之饶多</span>  
<span style="margin-left: 2em">富商大贾俗以浮侈相高不能力本业然衣冠之盛</span>  
<span style="margin-left: 2em">亦为江浙诸县之最虽佃家中人衣食才足喜教子</span>  
<span style="margin-left: 2em">弟以读书秀民才士往往起家为达官繇是竞劝于</span>  
<span style="margin-left: 2em">学弦歌之声相闻居官不必以击断鸷猛为治亦可</span>  
<span style="margin-left: 2em">以礼义驯服也</span>  
<span style="margin-left: 2em">魏了翁云吴中族姓人物之盛自东汉以来有闻于</span>  
<span style="margin-left: 2em">世逮魏晋而后彬彬辈出左太冲所谓高门鼎贵魁</span>  
<span style="margin-left: 2em">岸豪杰虞魏之昆顾陆之裔虽通言吴郡而居华亭</span>  
<span style="margin-left: 2em">者为尤著盖其地负海枕江平畴沃野生民之资用</span>  
<span style="margin-left: 2em">饶衍得以毕力于当事故士奋于学民兴于仁</span>  
<span style="margin-left: 2em">赵孟𫖯云松江古句吴之地吴小且远至季札知乐</span>  
<span style="margin-left: 2em">其文始通上国今天下一家地大物众乡聚成郡邑</span>  
<span style="margin-left: 2em">昔之海隅商贾百货礼殿儒宫岩岩翼翼粲然不异</span>  
<span style="margin-left: 2em">邹鲁</span>  
<span style="margin-left: 2em">萨天锡诗云三山云海几千里十幅蒲帆挂秋水吴</span>  
<span style="margin-left: 2em">中过客莫思家江南画船如屋里芦芽短短穿碧纱</span>  
<span style="margin-left: 2em">船头鲤鱼吹浪花吴姬荡桨入城去细雨小寒生绿</span>  
<span style="margin-left: 2em">纱我歌水调无人续江上月凉吹紫竹春风一曲鹧</span>  
<span style="margin-left: 2em">鸪词花落莺啼满城绿</span>  
<span style="margin-left: 2em">董良史曰王教雍和秀茂挺逸英伟既多风谣亦作</span>  
<span style="margin-left: 3em">土膏气秀人食稻鱼俗不愁苦然地沃人骄奢侈</span>  
<span style="margin-left: 2em">颇异</span>  
<span style="margin-left: 2em">邵亨贞记云华亭为滨海壮邑因九峰三泖之胜而</span>  
<span style="margin-left: 2em">置司官焉晋陆士衡陈顾野王而下人才辈出民俗</span>  
<span style="margin-left: 2em">殷富逮唐宋间几与列郡抗以五代南渡之乱民有</span>  
<span style="margin-left: 2em">不知兵者生聚五百年至宋末而盛剧矣宋社既迁</span>  
<span style="margin-left: 2em">名家巨室罔不与国同休戚者贵游子弟华颠野服</span>  
<span style="margin-left: 2em">欷歔乔木之下仿佛黍离之间相望于宽闲寂寞者</span>  
<span style="margin-left: 2em">百年于兹矣</span>  
<span style="margin-left: 2em">嘉秀轩记云禹贡扬州之域曰三江既入震泽底定</span>  
<span style="margin-left: 2em">厥草惟夭厥木惟<sub class="note-jiao">校：惟字當惟字之音訛據嘉秀軒記改</sub>乔盖三江导</span>  
<span style="margin-left: 2em">震泽之水东入于海江之南北壤地数百里土肥而</span>  
<span style="margin-left: 2em">木茂民生敦庞而富庶地志所载读书宦达者历代</span>  
<span style="margin-left: 2em">皆有人焉</span>  
<span style="margin-left: 2em">贝琼云初余游九峰三泖间尝爱其俗务本而好学</span>  
<span style="margin-left: 2em">故无不耕之民无不食之地而诸谢雄盖一邑比古</span>  
<span style="margin-left: 2em">之秦阳</span>  
<span style="margin-left: 2em">陶安曰华亭古名邑倚郭于松江曩余识其文物类</span>  
<span style="margin-left: 2em">修整酝藉有机云遗思唯是启义理之秘药浮奢之</span>  
<span style="margin-left: 2em">疴新耳目之习谨身心之修相与考德业美风化者</span>  
<span style="margin-left: 2em">则司教之责也</span>  
<span style="margin-left: 2em">何良俊曰我松文物之盛莫甚于元浙西诸郡皆为</span>  
<span style="margin-left: 2em">战场而我松僻峰泖之间以及海上皆可避兵故四</span>  
<span style="margin-left: 2em">方名流汇萃于此薰陶渐染之功为多</span>  
<span style="margin-left: 1em">习尚</span>  
<span style="margin-left: 1em">松故吴之裔壤负海枕江土膏沃饶风俗淳秀其习尚</span>  
<span style="margin-left: 2em">亦各有所宗自东都以后陆氏居之康绩以行谊闻</span>  
<span style="margin-left: 2em">逊抗以功名显机云以词学著国人化之梁有顾希</span>  
<span style="margin-left: 2em">冯唐有陆敬舆至宋而科名盛故其俗文原泽沃衍</span>  
<span style="margin-left: 2em">有鱼稻海盐之富商贾辐辏故其俗侈有康僧会船</span>  
<span style="margin-left: 2em">子夹山之遗踪故尚佛有金山柘湖之灵迹故信鬼</span>  
<span style="margin-left: 2em">神好淫祀有三甲五甲之风故或号难理文物衣冠</span>  
<span style="margin-left: 2em">蔚为东南之望经学词章下至书翰咸有师法各称</span>  
<span style="margin-left: 2em">名家田野小民生理裁足皆知以教子孙读书为事</span>  
<span style="margin-left: 2em">故士奋于学民兴于仁租税百万岁期而集虽役重</span>  
<span style="margin-left: 2em">赋烦身重敲榜中未尝有一言犯上罹淫放不孝之</span>  
<span style="margin-left: 2em">刑故嚚讼者少淳良者多旧志云诸州外县多朴质</span>  
<span style="margin-left: 2em">附郭多繁华吾松则反是盖东北五乡故为海商驰</span>  
<span style="margin-left: 2em">骛之地而其南纯事耕织故所习不同如此大率府</span>  
<span style="margin-left: 2em">城之俗谨绳墨畏清议而其流失之隘上海之俗喜</span>  
<span style="margin-left: 2em">事功尚意气而其流失之夸尚清雅饰玩好境内皆</span>  
<span style="margin-left: 2em">然而西南为盛然畏首事喜随众而府城以之谚所</span>  
<span style="margin-left: 2em">谓松江齐也</span>  
<span style="margin-left: 2em">吉凶多沿俗礼冠不备三加婚事亲迎丧事亦尚佛</span>  
<span style="margin-left: 2em">老旧志载天顺景泰以前男子窄袖短躬衫裾幅甚</span>  
<span style="margin-left: 2em">狭虽士人亦然妇女平髻宽衫制极朴古婚会以大</span>  
<span style="margin-left: 2em">衣俗谓之袄子领袖缘以圈金或挑线为上饰其彩</span>  
<span style="margin-left: 2em">绣织金之类非仕宦家绝不敢用燕会果肴以四色</span>  
<span style="margin-left: 2em">至五色而止尤重师范时教授以下至府以宾礼见</span>  
<span style="margin-left: 2em">不庭参燕科贡士时皆上坐景泰中犹然见部使者</span>  
<span style="margin-left: 2em">长揖不跪使者莅学进讲坐堂之西序成化中犹然</span>  
<span style="margin-left: 2em">今自顾文僖公以来凡百十余年俗日多靡民日凋</span>  
<span style="margin-left: 2em">攰无复昔日风规矣江淹曰经邦纬治去华为急体</span>  
<span style="margin-left: 2em">国制变循素为先是在坊民者有以风之其君子之</span>  
<span style="margin-left: 2em">德乎若四时节序闾井所尚与旧志小有同异亦略</span>  
<span style="margin-left: 2em">得而纪焉</span>  
<span style="margin-left: 1em">岁时</span>  
<span style="margin-left: 1em">正月一日春秋谓之端月鸡鸣起悉正衣冠拜天地家</span>  
<span style="margin-left: 2em">庙尊长后以次拜邻里亲戚盛舆服往来驰遝各投</span>  
<span style="margin-left: 2em">刺于门为贺岁文衡山太史诗云新春车马贺年初</span>  
<span style="margin-left: 2em">名刺纷纷满旧庐我亦随人投一纸世情嫌简不嫌</span>  
<span style="margin-left: 2em">虚此风苏松皆同一日至三日禁不扫除室中小儿</span>  
<span style="margin-left: 2em">竞击锣鼓为罢市立春前一日以彩仗迎春于东郊</span>  
<span style="margin-left: 2em">又先一日鼓乐杂伎先呈府县为呈宴至日士女观</span>  
<span style="margin-left: 2em">者垂帘阗市茹春饼进春酒为看春立春之候祭芒</span>  
<span style="margin-left: 2em">神鞭土牛旧志于七日八日九日会佛寺名龙华今</span>  
<span style="margin-left: 2em">废上旬之暮女子邀卜厕姑又向灶为向卜以秫谷</span>  
<span style="margin-left: 2em">投釜爆之名卜流花又名米花女子曳彩戴珍珥以</span>  
<span style="margin-left: 2em">金珠翡翠相夸尚上元前后为元宵节家制粉饵为</span>  
<span style="margin-left: 2em">看灯圆即旧志呼珍珠圆也及油䭔亦以粉为之采</span>  
<span style="margin-left: 2em">竹结棚于通衢灯皆刻饰纸帛穿缀彩珠剪簇绚绘</span>  
<span style="margin-left: 2em">工竞百巧市人各挂彩悬流苏以障幕覆之金鼓管</span>  
<span style="margin-left: 2em">弦火树最胜游人往往达曙为常是夕农家争束刍</span>  
<span style="margin-left: 2em">徧烧田间谓照田蚕家祀灶为接灶按礼乐器灶者</span>  
<span style="margin-left: 2em">老妇之祭尊于饼盛于盆言瓶为尊盆盛馔也旧志</span>  
<span style="margin-left: 2em">十七日会普照寺燃巨烛士女七日方散月内诵连</span>  
<span style="margin-left: 2em">华经又醮章为禳火已不复见</span>  
<span style="margin-left: 2em"><sub class="note-yuan">郡守许公维新元宵诗元宵气候和微云淡河汉然灯起东风聊作丰登办糕茧兆茧良遂为先蚕奠太守分为民取作耳目玩迅雷忽砰砯花烛红灿烂冲空万虹流矫如射天箭鼓吹众垒鸣有如巨鹿战海潮沸疑爱方昏又忽旦北方瘠土生骤然经未惯彷皇步庭阶呼僮防火患开关告海防或然有外变转笑告者迂无聊坐夜半栖乌禁不鸣楼角寂宿鹳岂亦讶非常焚巢愁祸乱良久月沉西灯宵火亦倦热闹逐霜零鼓角随风散灯花有几钱量贵应无算消者灰与尘散者衣若饭即此耳目前可卜余乡县富贵犹堪惜如此贫与贱夏畦苦作劳当午滴禾汗膏血一粒艰用作泥沙盼急来不胜情枉竞田庐畔争鬪亦无术不情告加叹重求却失轻作此颠倒见虽去鄙吝心此理无难判荆楚风土谣往古先贤传本以教耕桑末流成惑眩害财最苦奢足民莫如俭岁谷余三年中仍虑水旱此宵已如斯八节费巨万往岁魃为妖扬尘江流断茹草腹不充道僵嗟逋窜安得灯与花煮作饥寒膳奈何挥金谷泖底九峰涧年祲再祷神神恫民亦怨禁屠与止沽赴南如北面守臣罪可诛何不为民劝燎原足易焚射天是恭慢无礼召祝融恣钱买祸难马舞青楼街熊啸锦廛徧此其在眼前皆可为殷鉴齐伧不能词存为不职案省费反朴风何胜惬大显</sub></span>  
<span style="margin-left: 1em">二月十二日百花生日以红彩系群卉十九日观音大</span>  
<span style="margin-left: 2em">士诞晨群诣佛寺进香始放风鸢亦曰风筝又曰放</span>  
<span style="margin-left: 2em">鹞子即仁宝云春之风自下而升纸鸢因之以起夜</span>  
<span style="margin-left: 2em">以灯爇烛悬线而升之亦有烟火飞如繁星</span>  
<span style="margin-left: 1em">三月清明祀先家设野祭拜扫先茔挂纸钱谓之纸幢</span>  
<span style="margin-left: 2em">家长率子孙咸往名标墓俗折柳枝及荠花戴于首</span>  
<span style="margin-left: 2em">清明先三日郡牒　城隍神至期请诣厉坛郡民执</span>  
<span style="margin-left: 2em">香花骑从拥导前后者数万余人至晚复以华灯千</span>  
<span style="margin-left: 2em">炬迎归入庙七月十五日十月一日亦如之元时于</span>  
<span style="margin-left: 2em">是日有秋千之戏</span>  
<span style="margin-left: 2em">旧志载歌咢游山迎会先时巫者舁神偶沿门互唱</span>  
<span style="margin-left: 2em">索钱结彩成幡胜以奉岳神为钱幡会至今有之自</span>  
<span style="margin-left: 2em">茶笋之候九峰惟佘山神山干山画舫鳞次征歌载</span>  
<span style="margin-left: 2em">酒游者无虚日二十八日东岳帝诞辰里人聚鼓乐</span>  
<span style="margin-left: 2em">旗旛骑盖迎神于东岳庙</span>  
<span style="margin-left: 1em">四月八日俗称浴佛之辰浮屠设供以水浴释迦像谓</span>  
<span style="margin-left: 2em">九龙吐水之日也旧志于是日迎华光会</span>

<span style="margin-left: 2em"><sub class="note-yuan">钱惟善田家五行序五行之说见于经传其来尚矣岂特为田家设哉然舍田家而言五行不知本者也此古二至之书氛祲三时之纪风雨皆为田家设也田家以耕桑为重民生以衣食为本有天下国家者必先讲乎此而后可得而理成周以农事开国王业之艰难风俗之醇厚见于诗之七月书之无逸其迎寒逆暑之侯惓惓以耕织为言忧君爱民之道谆谆以稼穑为意至洪范之论五行首曰土爰稼穑孟子之论王道在乎不违农时是则农事之于五行岂不有所系哉华亭之上有隐于农者陆伯翔氏尽心于农事而妙契乎天时尝徧考历代诸氏之说以为一家之书其占风雨视氛祲地利有高下之宜天道有旱潦之分罔不备具而所以朝占暮观者用心亦良苦矣是书固若为吴下设也然而谨修筑以御旱潦勤树艺以致丰歉训之以尊卑长幼之节定之以冠婚丧祭之仪戒之以疾病患难相救相扶之计贫穷盗贼相周相䘏之举古人忠厚之意蔼然见于言表讵可忽哉呜呼使有位者皆知农事为王政之本天下国家其有不治乎古之为民者四农居其一然士出于农而兵寓于农工商之暇亦未必不务于农也虽仕者亦分田制禄又乌得有无田之家乎亦乌有不耕而食之民不蚕而衣之俗乎后世天下国家之难理由田者寡而食者众耳此书所以未必无关于治道无补于风化也今将贡诸有司以献芹曝之惓惟上之命刻之梓散之四方则民生幸甚故为之叙其槩云至正二十五年乙巳夏五月既望序</sub></span>
