## 崇禎松江府志卷之四十九　兵燹

<span style="margin-left: 3em">兵燹</span>  
<span style="margin-left: 1em">新安胡司馬曰昔之防海重防其入今之防海重防其</span>  
<span style="margin-left: 1em">出蓋島夷與不逞之徒皆能窺我圉決我藩也往自諸</span>  
<span style="margin-left: 1em">寇蹂躪吾松後中倭難迄今八十餘年無警絶不聞兵</span>  
<span style="margin-left: 1em">燹二字然老人談及寇變猶惴惴有戒心焉緩而養之</span>  
<span style="margin-left: 1em">迫而陷之幾幾乎爲寇之所乘若夫料理未來綢繆善</span>  
<span style="margin-left: 1em">後而兵燹之始末戰守之機宜皆在目中矣</span>  
<span style="margin-left: 1em">吳闔閭十三年越伐吳戰于笠澤笠澤松江也按越之</span>  
<span style="margin-left: 2em">入寇渡師檇李則從繇拳辟塞辟塞者吳備越之塞</span>  
<span style="margin-left: 2em">若以舟師濟則入三江口婁有南武城闔閭起以備</span>  
<span style="margin-left: 2em">越今滬瀆壘有闔閭城是也太子友云越王將選死</span>  
<span style="margin-left: 2em">士出三江之口入五湖之中屠吾吳國指此</span>  
<span style="margin-left: 1em">晉隆安三年會稽世子元顯縱暴吳會百姓不安孫恩</span>  
<span style="margin-left: 2em">因其騷動遂襲會稽於是吳郡陸懷吳興丘羗等凡</span>  
<span style="margin-left: 2em">八郡一時皆起殺長令以應之旬日間衆數十萬詔</span>  
<span style="margin-left: 2em">徐州刺史謝琰及加劉牢之都督吳郡諸軍事牢之</span>  
<span style="margin-left: 2em">引劉裕爲參軍共討之恩驅男女二十餘萬俱入海</span>  
<span style="margin-left: 2em">牢之東屯會稽吳國內史袁山松築滬瀆壘緣海備</span>  
<span style="margin-left: 2em">恩明年恩復入唊口高雅之敗績牢之督五郡兵東</span>  
<span style="margin-left: 2em">征恩復還于海轉寇滬瀆害袁山松仍浮海向京口</span>  
<span style="margin-left: 2em">牢之使劉裕自海鹽赴難累戰恩衆大敗繇是漸弱</span>  
<span style="margin-left: 2em">南還裕亦尋海要截大破恩于滬瀆</span>  
<span style="margin-left: 1em">晉肅宗太寧二年蘇峻既從庾亮追破沈充封邵陵公</span>  
<span style="margin-left: 2em">食邑一千八百户威望漸著頗懷驕溢潛有異志乃</span>  
<span style="margin-left: 2em">結祖約爲亂陷没宫城分軍東下遣張健管高等進</span>  
<span style="margin-left: 2em">攻吳郡燒府舍掠諸縣所在塗地海鹽嘉興婁縣尤</span>  
<span style="margin-left: 2em">亟前義興太守顧衆還吳潛圖舉義時吳國內史庾</span>  
<span style="margin-left: 2em">冰棄郡奔揚州刺史王舒于會稽峻以蔡謨代之衆</span>  
<span style="margin-left: 2em">乃遣人密說謨謨檄衆爲本國都護揚威將軍衆弟</span>  
<span style="margin-left: 2em">颺威遠將軍前鋒都護吳中人士同時響應破峻將</span>  
<span style="margin-left: 2em">弘徵收其軍實舒更以晉陵軍屯兵章埭吳興太守</span>  
<span style="margin-left: 2em">虞潭率所領討健屯不敢進適暴雨大水賊管商乘</span>  
<span style="margin-left: 2em">船旁出襲潭及衆潭等奔敗乃增戍海浦築壘防之</span>  
<span style="margin-left: 2em">張健據有吳城顧衆繇婁縣東倉與賊別帥交戰破</span>  
<span style="margin-left: 2em">之義軍又集舒潭並檄衆爲五郡大督護統義軍討</span>  
<span style="margin-left: 2em">健健退曲河復破走之斬首二千餘級</span>  
<span style="margin-left: 1em">晉成帝咸和六年劉徵復寇婁縣</span>  
<span style="margin-left: 1em">梁大清四年九月侯景使侯子鑒率兵入吳太守袁君</span>  
<span style="margin-left: 2em">正迎降之吳郡以西南陵以北俱爲景據承聖元年</span>  
<span style="margin-left: 2em">三月王僧辨陳覇先敗景于石顯景至晉陵得餘兵</span>  
<span style="margin-left: 2em">因驅掠居民東趨吳郡僧辨使侯填追之戰於松江</span>  
<span style="margin-left: 2em">大敗景盡獲其軍實景乃與心腹數十人潛遁惟餘</span>  
<span style="margin-left: 2em">三舸乃推墮二子於水自滬瀆入海欲向蒙山會景</span>  
<span style="margin-left: 2em">倦晝寢羊鵾語海師此中何處有蒙山海但向我處</span>  
<span style="margin-left: 2em">分遂直至京口至胡豆洲景覺大驚鵾抽刀斫之鵾</span>  
<span style="margin-left: 2em">侃之子也</span>  
<span style="margin-left: 1em">隋大業九年劉元進舉兵應楊玄感將渡江而玄感敗</span>  
<span style="margin-left: 2em">吳郡朱燮晉陵管崇亦舉兵共迎元進據吳郡稱天</span>  
<span style="margin-left: 2em">子署置百官衆至十萬燮本還俗道人涉獵經史微</span>  
<span style="margin-left: 2em">知兵略時爲崑山博士知天下將亂謀於學而起兵</span>  
<span style="margin-left: 2em">民苦役者赴之如歸自東陽至京口千餘里並受燮</span>  
<span style="margin-left: 2em">節度崇隱居常熟身長七尺三寸美姿容少無賴衆</span>  
<span style="margin-left: 2em">推奉之隋將吐萬緒進軍逼之相持百餘日元進潰</span>  
<span style="margin-left: 2em">遁與崇燮連營自保緒復被之斬崇然從亂者益衆</span>  
<span style="margin-left: 2em">帝令江都丞王世充發淮南兵擊之元進崇敗死餘</span>  
<span style="margin-left: 2em">衆降散</span>  
<span style="margin-left: 1em">隋大業九年杜伏威起兵掠江淮唐武德二年伏威降</span>  
<span style="margin-left: 2em">唐唐以爲和州總管三年李子通渡江攻沈法興法</span>  
<span style="margin-left: 2em">興棄毗陵奔吳郡於是丹陽毗陵等郡皆降于子通</span>  
<span style="margin-left: 2em">伏威遣輔公祏攻子通子通大敗伏威徙居丹陽子</span>  
<span style="margin-left: 2em">通復東走太湖收合亡散得二萬人襲法興於吳郡</span>  
<span style="margin-left: 2em">大破之法興棄城走吳郡賊帥聞人遂安遣其將葉</span>  
<span style="margin-left: 2em">孝辯迎之法興中途而悔欲殺孝辯更向會稽孝辯</span>  
<span style="margin-left: 2em">覺之法興窘迫赴江死子通軍勢復振徙都餘杭盡</span>  
<span style="margin-left: 2em">收法興之地自太湖以南皆有之是歲唐封伏威爲</span>  
<span style="margin-left: 2em">吳王四年十一月伏威將王雄誕擊子通子通降聞</span>  
<span style="margin-left: 2em">人遂安據崑山無所屬伏威使雄誕擊之以崑山險</span>  
<span style="margin-left: 2em">隘難以力勝乃單騎造其城下陳國威靈示以禍福</span>  
<span style="margin-left: 2em">遂安感悦出降於是伏威盡有江東之地秋七月子</span>  
<span style="margin-left: 2em">通復叛欲至江東收舊兵被獲伏誅<sub class="note-yuan">姑蘇志</sub></span>  
<span style="margin-left: 1em">隋開皇末吳郡沈玄懀沈傑等以兵圍蘇州刺史皇甫</span>  
<span style="margin-left: 2em">績頻戰不利楊素率衆援之玄懀勢迫走投南沙賊</span>  
<span style="margin-left: 2em">帥陸孟孫楊素擊孟孫于松江大破之生擒玄懀</span>  
<span style="margin-left: 1em">唐僖宗乾符六年黃巢據宣歙出采石略揚州明年僖</span>  
<span style="margin-left: 2em">宗幸蜀群盜所在磐結海寇王騰竊據華亭與常熟</span>  
<span style="margin-left: 2em">之柳起無錫之宋可復互爲聲援鎮海軍節度招討</span>  
<span style="margin-left: 2em">使周寶練卒自守發杭州兵戍縣鎮先是華亭之南</span>  
<span style="margin-left: 2em">境金山北境上海青龍皆有鎮將勢孤不敵故加兵</span>  
<span style="margin-left: 2em">戍之又據剽崑山寶遣張郁領兵三百戍海上郁醉</span>  
<span style="margin-left: 2em">而叛反肆大掠寶遣拓拔從討定之郁係鎮海將初</span>  
<span style="margin-left: 2em">以擊毬事寶者也昭宗大順四年吳越王錢鏐遣顧</span>  
<span style="margin-left: 2em">全武平嘉興拔華亭遂取蘇州淮南吳王楊行密屢</span>  
<span style="margin-left: 2em">争不已兵圍嘉興守臣曹珪擊走之華亭終歸錢氏</span>  
<span style="margin-left: 2em">錢氏奄有兩浙更於諸縣鎮置鎮遏使以土之豪傑</span>  
<span style="margin-left: 2em">世領焉</span>  
<span style="margin-left: 1em">宋建炎四年二月兀朮自廣德繇吉安渡錢塘破明越</span>  
<span style="margin-left: 2em">北還時以同知樞密院周望爲淮浙宣撫使望老繆</span>  
<span style="margin-left: 2em">不知兵初無守禦十八日犯崇德乃徵鄉兵發太湖</span>  
<span style="margin-left: 2em">洞庭東西兩山千艘命甪頭巡簡湯舉摠之陳于簡</span>  
<span style="margin-left: 2em">村二十一日犯平望聲言犯松江轉掠崑山待制胡</span>  
<span style="margin-left: 2em">舜陟語望云欲守平江莫若移軍吳江據太湖天險</span>  
<span style="margin-left: 2em">吾軍以中軍振其前使諸將以小舟自太湖旁擊之</span>  
<span style="margin-left: 2em">可必勝統制陳思恭深然其策望不從及虜至吳江</span>  
<span style="margin-left: 2em">思恭自以兵出太湖横擊其尾中原係虜之民聞兵</span>  
<span style="margin-left: 2em">至皆爲內應縱火焚舟幾虜四太子者以援少得去</span>  
<span style="margin-left: 2em">然松江之免蹂踐思恭一戰力也二十五日犯平江</span>  
<span style="margin-left: 2em">周望遁走青龍虜從盤門入劫掠廪庫子女金帛延</span>  
<span style="margin-left: 2em">燒官府民居烟焰見二百里凡五晝夜極兵火未有</span>  
<span style="margin-left: 2em">之慘韓世忠屯鎮江聞望遁遣將追之至許浦不得</span>  
<span style="margin-left: 2em">趨水而下直往青龍江及至青龍江口聞望已還軍</span>  
<span style="margin-left: 2em">而西乃逆江而上之鎮江世忠以江船鑿沉閘口虜</span>  
<span style="margin-left: 2em">不得出別開一河口遁去</span>  
<span style="margin-left: 1em">張士誠泰州白駒場人與弟士義士德士信並駕鹽綱</span>  
<span style="margin-left: 2em">船兼業私販至正十一年役民十五萬軍二萬治黃</span>  
<span style="margin-left: 2em">河民不聊生四方兵起有王克柔亦泰州人家富多</span>  
<span style="margin-left: 2em">結游俠高郵知府李齊收捕于獄李華甫與士誠素</span>  
<span style="margin-left: 2em">感克柔恩謀劫獄齊置克柔于揚州招華甫爲泰州</span>  
<span style="margin-left: 2em">判士誠爲千夫長十三年丑月士誠與李華甫同謀</span>  
<span style="margin-left: 2em">起事未幾殺華甫併其衆焚掠村落驅民爲盜陷通</span>  
<span style="margin-left: 2em">泰高郵自號誠王改元天祐設官分截要衝南北梗</span>  
<span style="margin-left: 2em">塞元立淮南行省於揚州以扼其勢既而亦招安之</span>  
<span style="margin-left: 2em">立義兵元帥府以官其黨然士誠狙詐百出卒不就</span>  
<span style="margin-left: 2em">降江陰寇江宗三朱英分黨戕殺互相吞啖英求救</span>  
<span style="margin-left: 2em">於士誠仍質妻子借兵復讐又盛陳江南土地之廣</span>  
<span style="margin-left: 2em">錢穀子女玉帛之富以動之十六年正月朔攻破常</span>  
<span style="margin-left: 2em">熟行省丞相達識帖木兒以漕運萬户脱因陞爲參</span>  
<span style="margin-left: 2em">政統官軍義民捍禦境上陞松江府達魯花赤哈散</span>  
<span style="margin-left: 2em">沙補平江領兵出戰除都水庸田使貢師泰爲平江</span>  
<span style="margin-left: 2em">總管巡守城池吳江止元帥王與敬官軍一戰而敗</span>  
<span style="margin-left: 2em">死者過半殘兵千餘退屯松江士誠遂據有平江路</span>  
<span style="margin-left: 2em">二月壬子朔也與敬據松江叛以城降之士誠以史</span>  
<span style="margin-left: 2em">文炳爲樞密院同知鎮松江郡欲南取嘉興參政楊</span>  
<span style="margin-left: 2em">完者統苗僚瑶僮名曰荅剌罕守禦甚堅屢攻不克</span>  
<span style="margin-left: 2em">秋八月文炳大舉兵臨其東門悉爲所殲文炳僅以</span>  
<span style="margin-left: 2em">身免先是與敬至松時名曰守禦實戀娼董賽兒也</span>  
<span style="margin-left: 2em">後與帖木古思不合乃令萬户戴列思等引軍出西</span>  
<span style="margin-left: 2em">門燬民房寺觀簡括金銀財物以行而完者率苗兵</span>  
<span style="margin-left: 2em">突至與敬遂北走通波塘子女玉帛悉爲苗兵所有</span>  
<span style="margin-left: 2em">矣是年十一月　太祖皇帝天兵取常州十七年攻</span>  
<span style="margin-left: 2em">長興又取江陰分兵絶太湖遂取宜興士誠窮迫願</span>  
<span style="margin-left: 2em">就省相招安元赦其罪令參政周伯琦等撫諭之授</span>  
<span style="margin-left: 2em">爲太尉開府平江立江淮分省江浙分樞密院以處</span>  
<span style="margin-left: 2em">之十九年元遣使以御酒龍衣賜士誠徵海運糧自</span>  
<span style="margin-left: 2em">是士誠每歲運粟十餘萬至燕京秋七月大城武林</span>  
<span style="margin-left: 2em">起松江及平江嘉湖四路官民以供畚築松江府工</span>  
<span style="margin-left: 2em">徒屬繆思恭主之稍得衆心二十三年九月士誠自</span>  
<span style="margin-left: 2em">稱吳王請命于元不報自是徵糧不與二十六年是</span>  
<span style="margin-left: 2em">爲　太祖皇帝龍鳳十二年命以榜諭浙西八月大</span>  
<span style="margin-left: 2em">將軍徐達副將軍常遇春帥師二十萬南伐師至太</span>  
<span style="margin-left: 2em">湖擒士誠將尹義陳旺遂次洞庭山士誠在湖中不</span>  
<span style="margin-left: 2em">敢戰進次湖州連敗士誠軍湖州既下兵轉至南潯</span>  
<span style="margin-left: 2em">王勝降至吳江至尹山橋焚士誠戰舸千餘艘及積</span>  
<span style="margin-left: 2em">聚甚衆於是兵集城下吳元年九月達兵破葑門遇</span>  
<span style="margin-left: 2em">春破閶門左右皆散達令李伯升諭意士誠士誠閉</span>  
<span style="margin-left: 2em">目不語舁入舟俘于南京自經死</span>  
<span style="margin-left: 1em">至正十六年淮人陷平江時江浙行省丞相塔失帖木</span>  
<span style="margin-left: 2em">兒得便宜從事以楊完者守嘉興未行隨以兵劫丞</span>  
<span style="margin-left: 2em">相陞本省參知政事即拜添設左丞楊完者字伯英</span>  
<span style="margin-left: 2em">家世播州湖湘亂以苗僚義軍征行自備糧餉衣裝</span>  
<span style="margin-left: 2em">故所至多殺掠轉戰至江東駐軍廣德至是招用之</span>

<span style="margin-left: 2em">者千人〇二月徐海復巢柘林與陳東合參將尚允</span>  
<span style="margin-left: 2em">紹札營青村率兵偵哨遇賊百人輒追捕賊乃伏四</span>  
<span style="margin-left: 2em">橋左右螺貝聲起環攻叢射殺允紹及二指揮三千</span>  
<span style="margin-left: 2em">户一武舉兵卒死者數百餘人時楊公宜劾爲民曹</span>

<span style="margin-left: 2em">闕胡公宗憲令任公環會參將喬基共擊之賊逃至</span>  
<span style="margin-left: 2em">蔡廟廢堡環乃以把總陳習攻東門車梁攻西門張</span>  
<span style="margin-left: 2em">維孝攻西北顧鳴鵬攻西南賊死拒官兵逼之戰方</span>  
<span style="margin-left: 2em">酣王賓等兵潛從東北入大破賊斬之賊遂分支流</span>  
<span style="margin-left: 2em">突一犯南匯任公環敗之婁宇又敗之總督會兵搗</span>  
<span style="margin-left: 2em">陶宅賊敗遁出漴闕外洋婁宇與把總王應麟復敗</span>  
<span style="margin-left: 2em">之于九團一犯青村王應麟敗之一自金山流至西</span>  
<span style="margin-left: 2em">菴董公邦政盡殲其衆又追擊新賊于沈莊再犯吳</span>  
<span style="margin-left: 2em">淞俞大猷與把總楊尚英劉堂等設伏海口賊至伏</span>  
<span style="margin-left: 2em">發沉其舟十三艘〇四月十一日新場舊賊往合新</span>  
<span style="margin-left: 2em">賊水陸並進從金山過乍浦入浙舊賊得船而歸新</span>  
<span style="margin-left: 2em">賊遍劫嘉湖〇五月一日倭船一百五十餘艘自吳</span>  
<span style="margin-left: 2em">淞入上海北宫前登岸焚劫造雲梯進攻通判劉本</span>  
<span style="margin-left: 2em">學署縣篆邑縉紳諸生請貸帑金二千募死士分守</span>  
<span style="margin-left: 2em">凡十有八日先二日佯退至十七日夜窺西南隅地</span>  
<span style="margin-left: 2em">曠梯而登守城豎兒楊鈿覺之大呼衆驚起賊刺鈿</span>  
<span style="margin-left: 2em">墮城下衆亦并堞墮磚石雨下賊受傷奔溺死者六</span>  
<span style="margin-left: 2em">十七人遂退入浦始解圍十九日直抵閔行官兵守</span>  
<span style="margin-left: 2em">浦者獸散居民奔入城者蹂踐于途二十日賊繇斜</span>  
<span style="margin-left: 2em">塘往蘇州爲吳江水兵衝擊轉掠郡西關火七日不</span>  
<span style="margin-left: 2em">絶焚劫視癸丑尤甚至二十七日始解去把總劉堂</span>  
<span style="margin-left: 2em">追擊之于泖湖敗之任公環同知縣熊桴復擊于澱</span>  
<span style="margin-left: 2em">山東又敗之〇六月七日賊破桐鄉駕千艘東下經</span>  
<span style="margin-left: 2em">朱涇泊呂巷分掠如四保五保七保八保張堰干巷</span>  
<span style="margin-left: 2em">松隱横涇等處焚劫一空十一日賊首徐明山即前</span>  
<span style="margin-left: 2em">巢柘林者遣千户陸鳳并承差健步二名倭十人詣</span>  
<span style="margin-left: 2em">南關城下餘賊稍遠持總督檄稱會同效順海商徐</span>  
<span style="margin-left: 2em">明山勦賊求見時賊奸叵測內外洶洶周公如斗即</span>  
<span style="margin-left: 2em">諭鳳令宣示朝廷威德賊即移舟徙去〇六月新安</span>  
<span style="margin-left: 2em">衛百户帥印統廣兵與賊遇于青村戰敗死之海上</span>  
<span style="margin-left: 2em">官兵時獲賊艘生擒斬首者皆桐鄉之寇間有出海</span>  
<span style="margin-left: 2em">多爲飛艦所擊無生還故島者至三十八年己未賊</span>  
<span style="margin-left: 2em">據崇明山沙爲官兵所截七月奔遁揚州而寇始絶</span>  
<span style="margin-left: 3em">附倭亂調劑事宜</span>  
<span style="margin-left: 1em">歸有光上禦倭書　今日之計宜於速戰然兵有分有</span>  
<span style="margin-left: 2em">合徒厚集其衆於一而不爲之列屯要害廣布形勢</span>  
<span style="margin-left: 2em">則賊之所出必視吾無備之處而爲之走集是宜觀</span>  
<span style="margin-left: 2em">地之要以擬其潰吳越之地瀕於大海海口之可通</span>  
<span style="margin-left: 2em">者數處而已既不能把扼而使之突入三江五湖之</span>  
<span style="margin-left: 2em">間要害之可守者數處而已又不能按據而使之横</span>  
<span style="margin-left: 2em">潰則將何爲而可也某以爲賊在川沙兵之所向能</span>  
<span style="margin-left: 2em">保其敗於東不潰於西耶攻其外不潰於內耶故太</span>  
<span style="margin-left: 2em">湖之口可屯也三泖之口可屯也吳淞江之中道可</span>  
<span style="margin-left: 2em">屯也某常循行江上問所謂滬瀆壘者知昔人禦寇</span>  
<span style="margin-left: 2em">之遺跡即如此壘正在蘇松二府之中賊得至此則</span>  
<span style="margin-left: 2em">蘇州松江諸縣無日不危也故爲屯壘不獨可以拒</span>  
<span style="margin-left: 2em">賊之入路又可以爲州縣之聲援也昨者黃岡涇之</span>  
<span style="margin-left: 2em">捷斬首之多以前所未有然賊復東出則賊鋒雖挫</span>  
<span style="margin-left: 2em">於五湖之上而蠻煙復接於九峯之間矣繇此言之</span>  
<span style="margin-left: 2em">分屯其可後乎往賊攻州而府不救攻縣而州不救</span>  
<span style="margin-left: 2em">劫掠村落而縣不救府如無州州如無縣縣如無村</span>  
<span style="margin-left: 2em">落僅僅自保於一城之中如與人鬪而束其手足絶</span>  
<span style="margin-left: 2em">其黨而孤立如之何能自存也幸而此賊在於抄掠</span>  
<span style="margin-left: 2em">而已設有長驅之志孰能禦之是唇齒俱亡首尾衡</span>  
<span style="margin-left: 2em">決矣即使徒以保城爲功而置百里生民於度外爲</span>  
<span style="margin-left: 2em">人父母何以爲心況京畿千里之地蕩然無藩籬之</span>  
<span style="margin-left: 2em">限兵之失勢莫甚於此此其不可一也凡王者之師</span>  
<span style="margin-left: 2em">未有不分別其逆順離散其黨與者今閩浙亡命與</span>  
<span style="margin-left: 2em">諸島之夷固所必誅若吾民所在被其係虜而髡之</span>  
<span style="margin-left: 2em">以爲前行以餌吾師嘗聞我軍斬首虜二百餘其間</span>  
<span style="margin-left: 2em">止有一二爲真賊者則臨陣之際豈可不辨其真僞</span>  
<span style="margin-left: 2em">明購賞格開示丹青生活之信古之用兵能使賊爲</span>  
<span style="margin-left: 2em">吾用而今驅之使爲賊此其不可二也聚天下之兵</span>  
<span style="margin-left: 2em">而軍政不立斷斬不行鹵掠不禁前者方陷陣後者</span>  
<span style="margin-left: 2em">已奔佚是民有百走退死之心而無一前進生之計</span>  
<span style="margin-left: 2em">且所謂營壘行陣間諜兵械與夫分數形名虛實奇</span>  
<span style="margin-left: 2em">正之說兵家之所常言悉置而不講此其不可三也</span>  
<span style="margin-left: 2em">故今日之兵在於決機而分屯以佐其勢又當戒飭</span>  
<span style="margin-left: 2em">州縣之吏不宜以閉塞城闉爲上策百姓之逃歸者</span>  
<span style="margin-left: 2em">不可逆以奸細而禁錮誅戮之至於刑賞軍令之大</span>  
<span style="margin-left: 2em">今之所調雜以夷僚宜示中國之紀律不可爲蠻夷</span>  
<span style="margin-left: 2em">所笑如是而戰不勝賊不滅者未之有也然今雖以</span>  
<span style="margin-left: 2em">殄滅爲期而經略措置非數十年不能安寧且夷性</span>  
<span style="margin-left: 2em">貪狼狃於虜獲之利雖有懲艾不能保其不來夫自</span>  
<span style="margin-left: 2em">正統以來殆將百年及今而發如人之疾病一旦發</span>  
<span style="margin-left: 2em">作豈得遽止故宜考求宣德正統之間前之所以侵</span>  
<span style="margin-left: 2em">盜而無已後之所以頓息而不來則有以知其故矣</span>  
<span style="margin-left: 2em">永樂中廣寧伯鎮守遼東築城金線島之西北夜見</span>  
<span style="margin-left: 2em">東南海島中火光即知寇至邀擊之擒斬無遺以是</span>  
<span style="margin-left: 2em">寇不敢入境蓋彼懸度大海經以旬月非風候不行</span>  
<span style="margin-left: 2em">又不能多齎糧餉賊未到岸往往饑罷兵法無負於</span>  
<span style="margin-left: 2em">水而迎客無迎水流獨於禦倭宜反而用之必迎水</span>  
<span style="margin-left: 2em">逆擊不使上岸此必盡之術也舍是則由外海而入</span>  
<span style="margin-left: 2em">內海由海入港由港入城郭如今日必至之害矣謂</span>  
<span style="margin-left: 2em">宜振飭　祖宗之法自廣閩浙淮以至遼東修沿海</span>  
<span style="margin-left: 2em">列衛之政則兵不必別調也舉都司備倭之職則將</span>  
<span style="margin-left: 2em">不必別選也不然而恃客兵客兵不可久居設使散</span>  
<span style="margin-left: 2em">還賊將復至周旋不已是兵無時而息也而民亦殫</span>  
<span style="margin-left: 2em">矣</span>  
<span style="margin-left: 1em">又備倭事略　今賊徒出没羅店劉家行江灣月浦等</span>  
<span style="margin-left: 2em">地方其路皆可逆知欲乞密切差兵設伏相機截殺</span>  
<span style="margin-left: 2em">彼狃於數勝謂我不能軍往來如入無人之地出其</span>  
<span style="margin-left: 2em">不意可以得志古之用兵惟恐敵之不驕不貪法曰</span>  
<span style="margin-left: 2em">卑而驕之又曰利而誘之今賊正犯兵家之忌可襲</span>  
<span style="margin-left: 2em">而取也訪得吳淞所一軍素號精悍倭賊憚之呼爲</span>  
<span style="margin-left: 2em">白頭蟲去歲宗百户馮百户見倭船近城倉卒與敵</span>  
<span style="margin-left: 2em">爲其所殺有司不加矜恤反歸罪於二人自後人以</span>  
<span style="margin-left: 2em">爲戒又城壁崩圮半落海中且累年不給軍糧士皆</span>  
<span style="margin-left: 2em">饑疲往往乞食道路遂致新城失陷翻爲賊巢嘉定</span>  
<span style="margin-left: 2em">上海之勢日以孤危今乞召新城失事指揮令收還</span>  
<span style="margin-left: 2em">散卒許以贖罪要以厚賞俾於賊所入嘉定及往南</span>  
<span style="margin-left: 2em">翔等要路阻陿之處長鎗勁弩設伏以待之又新城</span>  
<span style="margin-left: 2em">敗散之餘所存約二百餘人人數寡少乞募沿海大</span>  
<span style="margin-left: 2em">姓沈濮蔡嚴黃陸等家素能禦賊及被其毒害者并</span>  
<span style="margin-left: 2em">合爲一專爲伏兵及往來遊擊賊自不敢近太倉嘉</span>  
<span style="margin-left: 2em">定松江矣且因新城之軍俟便襲擊城可復襲而有</span>  
<span style="margin-left: 2em">也法曰善守者守其所不攻又曰使敵人不得至者</span>  
<span style="margin-left: 2em">害之也今所謂守城者徒守於城之內而不知守於</span>  
<span style="margin-left: 2em">城之外惴惴然如在圍城之中賊未至而已先自困</span>  
<span style="margin-left: 2em">矣畏首畏尾身其餘幾故唇亡而齒寒魯酒薄而邯</span>  
<span style="margin-left: 2em">鄲圍夫蘇州之守不在於婁門而在於崑山太倉太</span>  
<span style="margin-left: 2em">倉之守不在於太倉而在於劉家港此易知也今賊</span>  
<span style="margin-left: 2em">掠羅店等處已盡必及南翔賊據南翔奪民船以入</span>  
<span style="margin-left: 2em">吳淞江一日可至葑門即蘇州危矣南過唐行則松</span>  
<span style="margin-left: 2em">江危矣今聞又至太倉崑山等處即常熟危矣故欲</span>  
<span style="margin-left: 2em">害之使不得至所以爲守也然所謂設伏爲奇兵又</span>  
<span style="margin-left: 2em">時出正兵相爲表裏而後可也又嘉定近海爲內地</span>  
<span style="margin-left: 2em">保障其縣令恇怯不知兵乞委任百姓所信向如任</span>  
<span style="margin-left: 2em">同知董知縣武指揮等協力主決兵事知縣備辦糧</span>  
<span style="margin-left: 2em">食不得從中阻撓儻有疎虞即蘇松二郡不可保矣</span>  
<span style="margin-left: 2em">又考得白茆舊有白茆寨劉家港舊有劉家港寨青</span>  
<span style="margin-left: 2em">浦舊有青浦寨此皆前朝撥置軍士備倭之所蓋以</span>  
<span style="margin-left: 2em">春夏巡哨秋冬還衛又白茆吳塘茜涇劉家港甘市</span>  
<span style="margin-left: 2em">等處各有煙墩烽火相接以此見往時被倭之跡今</span>  
<span style="margin-left: 2em">疎濶如此欲以一城自固不可得也又訪得賊中海</span>  
<span style="margin-left: 2em">島夷洲真正倭種不過百數其內地亡命之徒固多</span>  
<span style="margin-left: 2em">而亦往往有被劫掠不能自拔者近日賊搶婁塘羅</span>  
<span style="margin-left: 2em">店等處驅率居民挑包其守包之人與吾民私語言</span>  
<span style="margin-left: 2em">是某府州縣人被賊脅從未嘗不思鄉里但已剃髮</span>  
<span style="margin-left: 2em">從其衣號與賊無異欲自逃去反爲州縣所殺以此</span>  
<span style="margin-left: 2em">只得依違苟延性命愚望官府設法招徠明示以丹</span>  
<span style="margin-left: 2em">青生活之信務在孤弱其黨賊勢不久自當解散此</span>  
<span style="margin-left: 2em">古人制夷遏盜之長策也又聞民間不見官府出軍</span>  
<span style="margin-left: 2em">以爲當俟請旨須大軍之至竊見　祖宗於山東淮</span>  
<span style="margin-left: 2em">浙閩廣沿海設立衛所鎮戍連絡每年風候進發舟</span>  
<span style="margin-left: 2em">師出海後又設都指揮一員統領諸衛專以備倭爲</span>  
<span style="margin-left: 2em">名今倭賊馮陵所在莫之誰何但見官司紛紛抽點</span>  
<span style="margin-left: 2em">壯丁及原役民快皆素不教練之民驅之殺賊以致</span>  
<span style="margin-left: 2em">一人見殺千人自潰徒長賊氣使海外蠻夷聞之皆</span>  
<span style="margin-left: 2em">有輕中國之心非　祖宗設立沿海軍衛之意也當</span>  
<span style="margin-left: 2em">事者拘礙文法動以擅調官軍爲解竊伏讀大明律</span>  
<span style="margin-left: 2em">擅調官軍一欵其暴兵卒至欲來攻襲事有警急及</span>  
<span style="margin-left: 2em">程途遥遠者並聽從便火速調撥軍馬乘機勦捕若</span>  
<span style="margin-left: 2em">寇賊滋蔓應合會捕者鄰近衛所雖非所屬亦得調</span>  
<span style="margin-left: 2em">發策應若不即調遣會合或不即申報上司及鄰近</span>  
<span style="margin-left: 2em">衛所不即發兵策應者與擅調官軍罪同此各衛得</span>  
<span style="margin-left: 2em">自調撥策應之明文也今賊殺害人民摇動畿輔蘇</span>  
<span style="margin-left: 2em">松內地城門經月不開百姓喁喁各衛擁兵深居賊</span>  
<span style="margin-left: 2em">在近郊不發一矢忍以百萬生靈餌賊幸其自退豈</span>  
<span style="margin-left: 2em">可得哉夫以沿海之衛自足備禦今獨民兵支吾玩</span>  
<span style="margin-left: 2em">愒養寇及其必不可已然後請　旨動調大軍夫以</span>  
<span style="margin-left: 2em">民兵則氣力孱弱以大軍則事體隆重是虛設沿海</span>  
<span style="margin-left: 2em">數百萬之兵也況大軍之至吾民饜飽豺狼之腹已</span>
