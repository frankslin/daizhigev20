## 崇祯松江府志卷之四十九　兵燹

<span style="margin-left: 3em">兵燹</span>  
<span style="margin-left: 1em">新安胡司马曰昔之防海重防其入今之防海重防其</span>  
<span style="margin-left: 1em">出盖岛夷与不逞之徒皆能窥我圉决我藩也往自诸</span>  
<span style="margin-left: 1em">寇蹂躏吾松后中倭难迄今八十余年无警绝不闻兵</span>  
<span style="margin-left: 1em">燹二字然老人谈及寇变犹惴惴有戒心焉缓而养之</span>  
<span style="margin-left: 1em">迫而陷之几几乎为寇之所乘若夫料理未来绸缪善</span>  
<span style="margin-left: 1em">后而兵燹之始末战守之机宜皆在目中矣</span>  
<span style="margin-left: 1em">吴阖闾十三年越伐吴战于笠泽笠泽松江也按越之</span>  
<span style="margin-left: 2em">入寇渡师檇李则从繇拳辟塞辟塞者吴备越之塞</span>  
<span style="margin-left: 2em">若以舟师济则入三江口娄有南武城阖闾起以备</span>  
<span style="margin-left: 2em">越今沪渎垒有阖闾城是也太子友云越王将选死</span>  
<span style="margin-left: 2em">士出三江之口入五湖之中屠吾吴国指此</span>  
<span style="margin-left: 1em">晋隆安三年会稽世子元显纵暴吴会百姓不安孙恩</span>  
<span style="margin-left: 2em">因其骚动遂袭会稽于是吴郡陆怀吴兴丘羗等凡</span>  
<span style="margin-left: 2em">八郡一时皆起杀长令以应之旬日间众数十万诏</span>  
<span style="margin-left: 2em">徐州刺史谢琰及加刘牢之都督吴郡诸军事牢之</span>  
<span style="margin-left: 2em">引刘裕为参军共讨之恩驱男女二十余万俱入海</span>  
<span style="margin-left: 2em">牢之东屯会稽吴国内史袁山松筑沪渎垒缘海备</span>  
<span style="margin-left: 2em">恩明年恩复入唊口高雅之败绩牢之督五郡兵东</span>  
<span style="margin-left: 2em">征恩复还于海转寇沪渎害袁山松仍浮海向京口</span>  
<span style="margin-left: 2em">牢之使刘裕自海盐赴难累战恩众大败繇是渐弱</span>  
<span style="margin-left: 2em">南还裕亦寻海要截大破恩于沪渎</span>  
<span style="margin-left: 1em">晋肃宗太宁二年苏峻既从庾亮追破沈充封邵陵公</span>  
<span style="margin-left: 2em">食邑一千八百户威望渐著颇怀骄溢潜有异志乃</span>  
<span style="margin-left: 2em">结祖约为乱陷没宫城分军东下遣张健管高等进</span>  
<span style="margin-left: 2em">攻吴郡烧府舍掠诸县所在涂地海盐嘉兴娄县尤</span>  
<span style="margin-left: 2em">亟前义兴太守顾众还吴潜图举义时吴国内史庾</span>  
<span style="margin-left: 2em">冰弃郡奔扬州刺史王舒于会稽峻以蔡谟代之众</span>  
<span style="margin-left: 2em">乃遣人密说谟谟檄众为本国都护扬威将军众弟</span>  
<span style="margin-left: 2em">飏威远将军前锋都护吴中人士同时响应破峻将</span>  
<span style="margin-left: 2em">弘征收其军实舒更以晋陵军屯兵章埭吴兴太守</span>  
<span style="margin-left: 2em">虞潭率所领讨健屯不敢进适暴雨大水贼管商乘</span>  
<span style="margin-left: 2em">船旁出袭潭及众潭等奔败乃增戍海浦筑垒防之</span>  
<span style="margin-left: 2em">张健据有吴城顾众繇娄县东仓与贼别帅交战破</span>  
<span style="margin-left: 2em">之义军又集舒潭并檄众为五郡大督护统义军讨</span>  
<span style="margin-left: 2em">健健退曲河复破走之斩首二千余级</span>  
<span style="margin-left: 1em">晋成帝咸和六年刘征复寇娄县</span>  
<span style="margin-left: 1em">梁大清四年九月侯景使侯子鉴率兵入吴太守袁君</span>  
<span style="margin-left: 2em">正迎降之吴郡以西南陵以北俱为景据承圣元年</span>  
<span style="margin-left: 2em">三月王僧辨陈覇先败景于石显景至晋陵得余兵</span>  
<span style="margin-left: 2em">因驱掠居民东趋吴郡僧辨使侯填追之战于松江</span>  
<span style="margin-left: 2em">大败景尽获其军实景乃与心腹数十人潜遁惟余</span>  
<span style="margin-left: 2em">三舸乃推堕二子于水自沪渎入海欲向蒙山会景</span>  
<span style="margin-left: 2em">倦昼寝羊鹍语海师此中何处有蒙山海但向我处</span>  
<span style="margin-left: 2em">分遂直至京口至胡豆洲景觉大惊鹍抽刀斫之鹍</span>  
<span style="margin-left: 2em">侃之子也</span>  
<span style="margin-left: 1em">隋大业九年刘元进举兵应杨玄感将渡江而玄感败</span>  
<span style="margin-left: 2em">吴郡朱燮晋陵管崇亦举兵共迎元进据吴郡称天</span>  
<span style="margin-left: 2em">子署置百官众至十万燮本还俗道人涉猎经史微</span>  
<span style="margin-left: 2em">知兵略时为昆山博士知天下将乱谋于学而起兵</span>  
<span style="margin-left: 2em">民苦役者赴之如归自东阳至京口千余里并受燮</span>  
<span style="margin-left: 2em">节度崇隐居常熟身长七尺三寸美姿容少无赖众</span>  
<span style="margin-left: 2em">推奉之隋将吐万绪进军逼之相持百余日元进溃</span>  
<span style="margin-left: 2em">遁与崇燮连营自保绪复被之斩崇然从乱者益众</span>  
<span style="margin-left: 2em">帝令江都丞王世充发淮南兵击之元进崇败死余</span>  
<span style="margin-left: 2em">众降散</span>  
<span style="margin-left: 1em">隋大业九年杜伏威起兵掠江淮唐武德二年伏威降</span>  
<span style="margin-left: 2em">唐唐以为和州总管三年李子通渡江攻沈法兴法</span>  
<span style="margin-left: 2em">兴弃毗陵奔吴郡于是丹阳毗陵等郡皆降于子通</span>  
<span style="margin-left: 2em">伏威遣辅公祏攻子通子通大败伏威徙居丹阳子</span>  
<span style="margin-left: 2em">通复东走太湖收合亡散得二万人袭法兴于吴郡</span>  
<span style="margin-left: 2em">大破之法兴弃城走吴郡贼帅闻人遂安遣其将叶</span>  
<span style="margin-left: 2em">孝辩迎之法兴中途而悔欲杀孝辩更向会稽孝辩</span>  
<span style="margin-left: 2em">觉之法兴窘迫赴江死子通军势复振徙都余杭尽</span>  
<span style="margin-left: 2em">收法兴之地自太湖以南皆有之是岁唐封伏威为</span>  
<span style="margin-left: 2em">吴王四年十一月伏威将王雄诞击子通子通降闻</span>  
<span style="margin-left: 2em">人遂安据昆山无所属伏威使雄诞击之以昆山险</span>  
<span style="margin-left: 2em">隘难以力胜乃单骑造其城下陈国威灵示以祸福</span>  
<span style="margin-left: 2em">遂安感悦出降于是伏威尽有江东之地秋七月子</span>  
<span style="margin-left: 2em">通复叛欲至江东收旧兵被获伏诛<sub class="note-yuan">姑苏志</sub></span>  
<span style="margin-left: 1em">隋开皇末吴郡沈玄懀沈杰等以兵围苏州刺史皇甫</span>  
<span style="margin-left: 2em">绩频战不利杨素率众援之玄懀势迫走投南沙贼</span>  
<span style="margin-left: 2em">帅陆孟孙杨素击孟孙于松江大破之生擒玄懀</span>  
<span style="margin-left: 1em">唐僖宗乾符六年黄巢据宣歙出采石略扬州明年僖</span>  
<span style="margin-left: 2em">宗幸蜀群盗所在磐结海寇王腾窃据华亭与常熟</span>  
<span style="margin-left: 2em">之柳起无锡之宋可复互为声援镇海军节度招讨</span>  
<span style="margin-left: 2em">使周宝练卒自守发杭州兵戍县镇先是华亭之南</span>  
<span style="margin-left: 2em">境金山北境上海青龙皆有镇将势孤不敌故加兵</span>  
<span style="margin-left: 2em">戍之又据剽昆山宝遣张郁领兵三百戍海上郁醉</span>  
<span style="margin-left: 2em">而叛反肆大掠宝遣拓拔从讨定之郁系镇海将初</span>  
<span style="margin-left: 2em">以击毬事宝者也昭宗大顺四年吴越王钱镠遣顾</span>  
<span style="margin-left: 2em">全武平嘉兴拔华亭遂取苏州淮南吴王杨行密屡</span>  
<span style="margin-left: 2em">争不已兵围嘉兴守臣曹珪击走之华亭终归钱氏</span>  
<span style="margin-left: 2em">钱氏奄有两浙更于诸县镇置镇遏使以土之豪杰</span>  
<span style="margin-left: 2em">世领焉</span>  
<span style="margin-left: 1em">宋建炎四年二月兀术自广德繇吉安渡钱塘破明越</span>  
<span style="margin-left: 2em">北还时以同知枢密院周望为淮浙宣抚使望老缪</span>  
<span style="margin-left: 2em">不知兵初无守御十八日犯崇德乃征乡兵发太湖</span>  
<span style="margin-left: 2em">洞庭东西两山千艘命甪头巡简汤举摠之陈于简</span>  
<span style="margin-left: 2em">村二十一日犯平望声言犯松江转掠昆山待制胡</span>  
<span style="margin-left: 2em">舜陟语望云欲守平江莫若移军吴江据太湖天险</span>  
<span style="margin-left: 2em">吾军以中军振其前使诸将以小舟自太湖旁击之</span>  
<span style="margin-left: 2em">可必胜统制陈思恭深然其策望不从及虏至吴江</span>  
<span style="margin-left: 2em">思恭自以兵出太湖横击其尾中原系虏之民闻兵</span>  
<span style="margin-left: 2em">至皆为内应纵火焚舟几虏四太子者以援少得去</span>  
<span style="margin-left: 2em">然松江之免蹂践思恭一战力也二十五日犯平江</span>  
<span style="margin-left: 2em">周望遁走青龙虏从盘门入劫掠廪库子女金帛延</span>  
<span style="margin-left: 2em">烧官府民居烟焰见二百里凡五昼夜极兵火未有</span>  
<span style="margin-left: 2em">之惨韩世忠屯镇江闻望遁遣将追之至许浦不得</span>  
<span style="margin-left: 2em">趋水而下直往青龙江及至青龙江口闻望已还军</span>  
<span style="margin-left: 2em">而西乃逆江而上之镇江世忠以江船凿沉闸口虏</span>  
<span style="margin-left: 2em">不得出别开一河口遁去</span>  
<span style="margin-left: 1em">张士诚泰州白驹场人与弟士义士德士信并驾盐纲</span>  
<span style="margin-left: 2em">船兼业私贩至正十一年役民十五万军二万治黄</span>  
<span style="margin-left: 2em">河民不聊生四方兵起有王克柔亦泰州人家富多</span>  
<span style="margin-left: 2em">结游侠高邮知府李齐收捕于狱李华甫与士诚素</span>  
<span style="margin-left: 2em">感克柔恩谋劫狱齐置克柔于扬州招华甫为泰州</span>  
<span style="margin-left: 2em">判士诚为千夫长十三年丑月士诚与李华甫同谋</span>  
<span style="margin-left: 2em">起事未几杀华甫并其众焚掠村落驱民为盗陷通</span>  
<span style="margin-left: 2em">泰高邮自号诚王改元天祐设官分截要冲南北梗</span>  
<span style="margin-left: 2em">塞元立淮南行省于扬州以扼其势既而亦招安之</span>  
<span style="margin-left: 2em">立义兵元帅府以官其党然士诚狙诈百出卒不就</span>  
<span style="margin-left: 2em">降江阴寇江宗三朱英分党戕杀互相吞啖英求救</span>  
<span style="margin-left: 2em">于士诚仍质妻子借兵复讐又盛陈江南土地之广</span>  
<span style="margin-left: 2em">钱谷子女玉帛之富以动之十六年正月朔攻破常</span>  
<span style="margin-left: 2em">熟行省丞相达识帖木儿以漕运万户脱因升为参</span>  
<span style="margin-left: 2em">政统官军义民捍御境上升松江府达鲁花赤哈散</span>  
<span style="margin-left: 2em">沙补平江领兵出战除都水庸田使贡师泰为平江</span>  
<span style="margin-left: 2em">总管巡守城池吴江止元帅王与敬官军一战而败</span>  
<span style="margin-left: 2em">死者过半残兵千余退屯松江士诚遂据有平江路</span>  
<span style="margin-left: 2em">二月壬子朔也与敬据松江叛以城降之士诚以史</span>  
<span style="margin-left: 2em">文炳为枢密院同知镇松江郡欲南取嘉兴参政杨</span>  
<span style="margin-left: 2em">完者统苗僚瑶僮名曰荅剌罕守御甚坚屡攻不克</span>  
<span style="margin-left: 2em">秋八月文炳大举兵临其东门悉为所歼文炳仅以</span>  
<span style="margin-left: 2em">身免先是与敬至松时名曰守御实恋娼董赛儿也</span>  
<span style="margin-left: 2em">后与帖木古思不合乃令万户戴列思等引军出西</span>  
<span style="margin-left: 2em">门毁民房寺观简括金银财物以行而完者率苗兵</span>  
<span style="margin-left: 2em">突至与敬遂北走通波塘子女玉帛悉为苗兵所有</span>  
<span style="margin-left: 2em">矣是年十一月　太祖皇帝天兵取常州十七年攻</span>  
<span style="margin-left: 2em">长兴又取江阴分兵绝太湖遂取宜兴士诚穷迫愿</span>  
<span style="margin-left: 2em">就省相招安元赦其罪令参政周伯琦等抚谕之授</span>  
<span style="margin-left: 2em">为太尉开府平江立江淮分省江浙分枢密院以处</span>  
<span style="margin-left: 2em">之十九年元遣使以御酒龙衣赐士诚征海运粮自</span>  
<span style="margin-left: 2em">是士诚每岁运粟十余万至燕京秋七月大城武林</span>  
<span style="margin-left: 2em">起松江及平江嘉湖四路官民以供畚筑松江府工</span>  
<span style="margin-left: 2em">徒属缪思恭主之稍得众心二十三年九月士诚自</span>  
<span style="margin-left: 2em">称吴王请命于元不报自是征粮不与二十六年是</span>  
<span style="margin-left: 2em">为　太祖皇帝龙凤十二年命以榜谕浙西八月大</span>  
<span style="margin-left: 2em">将军徐达副将军常遇春帅师二十万南伐师至太</span>  
<span style="margin-left: 2em">湖擒士诚将尹义陈旺遂次洞庭山士诚在湖中不</span>  
<span style="margin-left: 2em">敢战进次湖州连败士诚军湖州既下兵转至南浔</span>  
<span style="margin-left: 2em">王胜降至吴江至尹山桥焚士诚战舸千余艘及积</span>  
<span style="margin-left: 2em">聚甚众于是兵集城下吴元年九月达兵破葑门遇</span>  
<span style="margin-left: 2em">春破阊门左右皆散达令李伯升谕意士诚士诚闭</span>  
<span style="margin-left: 2em">目不语舁入舟俘于南京自经死</span>  
<span style="margin-left: 1em">至正十六年淮人陷平江时江浙行省丞相塔失帖木</span>  
<span style="margin-left: 2em">儿得便宜从事以杨完者守嘉兴未行随以兵劫丞</span>  
<span style="margin-left: 2em">相升本省参知政事即拜添设左丞杨完者字伯英</span>

<span style="margin-left: 2em">莫之支矣未几寇果至而直抵于上海县治之前此</span>  
<span style="margin-left: 2em">则机会之一失也寇至上海蔓延以至松城关厢烧</span>  
<span style="margin-left: 2em">劫而四野无所不至遂盘据川沙洼柘林镇以为巢</span>  
<span style="margin-left: 2em">穴四出抄掠西至嘉湖苏常北至嘉定太仓昆山常</span>  
<span style="margin-left: 2em">熟南至金山乍浦平湖海盐各路为害初寇之至自</span>  
<span style="margin-left: 2em">柘林也未知所据屯扰于上横泾冯氏家汤总兵任</span>  
<span style="margin-left: 2em">兵备董知县三战而三失利汤公复鼓败奋勇再与</span>  
<span style="margin-left: 2em">之战寇则剉衂以退奔柘林将为出海汤公谓有司</span>  
<span style="margin-left: 2em">曰乘寇此败再得粮饷以供士卒我可自柘林驱之</span>  
<span style="margin-left: 2em">出海有司吝财省事曰无钱粮可供总兵欲为当自</span>  
<span style="margin-left: 2em">为之不必问有司也汤公笑曰我为主将用兵兵无</span>  
<span style="margin-left: 2em">自饷之理若然我亦无能为也繇是寇退柘林后无</span>  
<span style="margin-left: 2em">有一人驱逐出海遂窥见城中虚实盘据柘林徒类</span>  
<span style="margin-left: 2em">日繁势大猖獗此则机会之再失也其机会之初失</span>  
<span style="margin-left: 2em">也繇有司不知倭祸之烈玩寇忽民后成滔天之祸</span>  
<span style="margin-left: 2em">其机会之再失也盖繇有司自求保全增高城垣严</span>  
<span style="margin-left: 2em">民固守视城外之民殆犹胡越任其杀戮不一介怀</span>  
<span style="margin-left: 2em">是以吾民枕籍就死莫有一援救者此有司济变之</span>  
<span style="margin-left: 2em">失策也自后寇势未已　朝廷选择总制大臣授钺</span>  
<span style="margin-left: 2em">开府调兵提督田州麻阳之兵四面而至总制亦求</span>  
<span style="margin-left: 2em">自全田州之兵曰瓦氏者战志甚锐乃使屯聚金山</span>  
<span style="margin-left: 2em">者三月不肯出师繇是众头目间出嬉戏尽为寇设</span>  
<span style="margin-left: 2em">伏陷没一时师老志懈迄无成功总制亦坐逗留之</span>  
<span style="margin-left: 2em">辜继此为提督者皆前后雷同坐糜廪给听其扰扰</span>  
<span style="margin-left: 2em">者六年人销物尽地无余资寇无所掠遂出海而去</span>  
<span style="margin-left: 2em">呜呼痛哉中间亦不无可言者若兵备任公之忠义</span>  
<span style="margin-left: 2em">巡抚曹公之忠实巡按周公之慈恳佥事董公之勇</span>  
<span style="margin-left: 2em">敢虽皆可言然大权不居不过就职事表见而已大</span>  
<span style="margin-left: 2em">抵天下祸乱之兴本于旧法废弛旧法废弛祸乱未</span>  
<span style="margin-left: 2em">有不兴者祸乱之弭在于当事有人当事无人祸乱</span>  
<span style="margin-left: 2em">未有能弭者善乎岳武穆有言曰文臣不爱钱武臣</span>  
<span style="margin-left: 2em">不畏死天下斯可太平信斯言也今日倭乱虽烈亦</span>  
<span style="margin-left: 2em">无其人耳苟有其人吾民岂足患哉</span>  
<span style="margin-left: 1em">徐御史宗鲁论倭变始末　寇起四年初以十计渐至</span>  
<span style="margin-left: 2em">数百数千之众今则聚而为几万矣始寇一方次沿</span>  
<span style="margin-left: 2em">邻邑傍郡之间犹怀顾忌今岁则满于浙之东西江</span>  
<span style="margin-left: 2em">之南北矣名虽倭寇实繇漳泉宁绍之民勾引为乱</span>  
<span style="margin-left: 2em">今岁则多客兵之附党乡民之投入矣昔但剽掠每</span>  
<span style="margin-left: 2em">窃窥于郊野海滨之区饱欲即去今岁则攻郡邑之</span>  
<span style="margin-left: 2em">城池据腹里之内地矣年复一年日甚一日曾不少</span>  
<span style="margin-left: 2em">挫其锋安得使之惩创他日之祸殆有不可测者此</span>  
<span style="margin-left: 2em">寇患之可虑者一也造海船莺船兵船之大户动费</span>  
<span style="margin-left: 2em">亿万而多弃于烈焰起盖营填港钉桩之工作动经</span>  
<span style="margin-left: 2em">岁月而多毁于贼手征海防丁田乡兵之杂税动及</span>  
<span style="margin-left: 2em">疲民而多冒于巨奸定籴米夫马支应之诸差动累</span>  
<span style="margin-left: 2em">赔偿而多困于妄报遭贼残破之余又苦繁役之扰</span>  
<span style="margin-left: 2em">弱者思逃强者思乱此民病之可虑者二也召募乡</span>  
<span style="margin-left: 2em">兵曾不操练安能驱其赴鬪调到客兵曾不禁制安</span>  
<span style="margin-left: 2em">能戢其强暴水兵守浦曾不预备安能止其奔溃陆</span>  
<span style="margin-left: 2em">兵临阵曾不示法安能遏其逃归横劫于乡曾不处</span>  
<span style="margin-left: 2em">斩安能使其敛戢私窃于市曾不刺发安能令其悔</span>  
<span style="margin-left: 2em">改管领之官利其虚报之饷而不敢讦其玩法之奸</span>  
<span style="margin-left: 2em">故上下因循戎政日坏此兵弊之可虑者三也各乡</span>  
<span style="margin-left: 2em">团结势可互援乃阻之于妄议四郊立堡急可奔守</span>  
<span style="margin-left: 2em">乃失之于先图岁造军器动支万金乃弃之于无用</span>  
<span style="margin-left: 2em">各省协济几至百万乃废之于冒赏畏难避祸专务</span>  
<span style="margin-left: 2em">逢迎乃藉之以求去布功罔利争先干进乃因之以</span>  
<span style="margin-left: 2em">偾事况更代不常人无固志故地方多变谁与责成</span>  
<span style="margin-left: 2em">此政蠧之可虑者四也防海则失堵截岂顾藩篱之</span>  
<span style="margin-left: 2em">撤守浦则先奔溃安念门庭之败屯札则忘结垒动</span>  
<span style="margin-left: 2em">遭冲突之变退缩则专姑息罔彰纪律之严军饷则</span>  
<span style="margin-left: 2em">多侵尅明籍钻求之费客兵则昧调度妄生激变之</span>  
<span style="margin-left: 2em">疑盖忠勇智谋均无可录故数年群盗未见勦平此</span>  
<span style="margin-left: 2em">将懦之可虑者五也或杀其老幼或掳其妻女而举</span>  
<span style="margin-left: 2em">家灭亡或火其庐舍或焚其米粟而罄产荡废或窜</span>  
<span style="margin-left: 2em">于野宿或栖于城隅而哭声载道或驱之投水或斩</span>  
<span style="margin-left: 2em">之郊市而尸骨成丘或尽毁农具或搬掳房室而稻</span>  
<span style="margin-left: 2em">因枯槁或只锅皆失或斗粟全无而民多饥馁况时</span>  
<span style="margin-left: 2em">更亢旱万姓嗷嗷坐待死亡祸不旋踵此时变之可</span>  
<span style="margin-left: 2em">虑者六也夫当此多难之秋须赖忠贞之佐开诚布</span>  
<span style="margin-left: 2em">公智愚方获其用明赏饬罚战守斯献其功总帅必</span>  
<span style="margin-left: 2em">经畧于中军督抚必协谋于制阃屏去积习之弊一</span>  
<span style="margin-left: 2em">新鼓舞之机分布诸将各守要害申戒有司各保城</span>  
<span style="margin-left: 2em">池相度事宜方议进止况闻　圣上悯念江南分命</span>  
<span style="margin-left: 2em">诸将提兵南下势若雷霆人心震奋兵威自张繇是</span>  
<span style="margin-left: 2em">合三军之众图万全之功庶中国可尊寇患自平此</span>

<span style="margin-left: 2em">薄贼寨赖保靖先入永顺继之乘风纵火斩贼千余</span>
