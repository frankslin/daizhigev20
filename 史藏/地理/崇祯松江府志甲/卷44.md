## 崇禎松江府志卷之四十四　人物九（遊寓）

<span style="margin-left: 3em">游寓</span>  
<span style="margin-left: 1em">彈丸峯泖游者不鄙而辱臨焉寓公客卿饘於是粥於</span>  
<span style="margin-left: 1em">是聚國族於是長子孫於是其否否者往來漸熟兒童</span>  
<span style="margin-left: 1em">牽衣而迎之曰吾家先生至矣清風古道高咏微言尚</span>  
<span style="margin-left: 1em">在詩筒酒瓢間寧忍以飄風視之乎志游寓</span>  
<span style="margin-left: 1em">漢</span>  
<span style="margin-left: 1em">笮融丹陽人初徐州牧陶謙使督廣陵漕運曹操攻謙</span>  
<span style="margin-left: 1em">徐土不靜融護謙男女百口馬三十匹走北亭鄉避難</span>  
<span style="margin-left: 1em">卒遂葬於此至今稱爲笮墓</span>  
<span style="margin-left: 1em">鄒湛南陽新野人嘗寓居孔宅故名鄒孔宅湛嘗見一</span>  
<span style="margin-left: 1em">人自稱甄仲舒乃悟曰吾宅西有積土敗瓦其中必有</span>  
<span style="margin-left: 1em">死人撿之果然厚加斂葬後捨宅爲慧日寺</span>  
<span style="margin-left: 1em">唐</span>  
<span style="margin-left: 1em">朱放字長通襄州人隱於越之剡溪嗣曹王臯鎮江西</span>  
<span style="margin-left: 1em">辟爲節度參謀尋歸越遭寇亂避地雲間先有寄張山</span>  
<span style="margin-left: 1em">詩云知君住處足風烟古樹荒村在眼前便欲移家逐</span>  
<span style="margin-left: 1em">君去惟愁未有買山錢至是留寓焉貞元初召爲拾遺</span>  
<span style="margin-left: 1em">劉長卿贈以詩云詔書徵拜脱荷裳身在東山閉草堂</span>  
<span style="margin-left: 1em">閶闔九門通禁籍華亭一鶴在朝行滄洲離別風烟遠</span>  
<span style="margin-left: 1em">青瑣幽深漏刻長今日郤迴垂釣處海鷗相見已高翔</span>  
<span style="margin-left: 1em">然放終不就也後山陰賊退仍歸剡溪劉又送之詩云</span>  
<span style="margin-left: 1em">越中初戰罷江上送歸橈後終於廣陵有詩集顧況序</span>  
<span style="margin-left: 2em"><sub class="note-yuan">序云因都國出麟角鳳喙爲續斷之膠與本無異朱君能以烟霞風景補綴藻繡符於自然山深月清中有猿嘯復如新安江水文魚彩石歷歷可數其杳瓊翛颯若有人衣薜荔而隱女蘿立意皆新奇創離聲樂友之什情思最切雖有諫職心遊江湖謝病而來慕出塵之侣精好涅般維摩經愛人爲善有志未就終於廣陵舟中識與不識聆風嚮義相與興嘆我主人延陵包君兵部李侍郎禮部劉侍郎皆有託孤之舊子郁襲其先行敬事父友泣捧遺文祈余冠序</sub></span>  
<span style="margin-left: 1em">張志和字子同婺州人唐肅宗慕其高命待詔翰林後</span>  
<span style="margin-left: 1em">出爲南海尉遂放浪江湖與陸羽往還因托迹吳興舴</span>  
<span style="margin-left: 1em">艋既敝請於顔魯公得漁舟更之以爲浮家泛宅垂綸</span>  
<span style="margin-left: 1em">於松江震澤間自謂烟波釣徒所著玄真子及大易十</span>  
<span style="margin-left: 1em">五篇其卦三百六十五後憲宗圖其像求之不可得李</span>  
<span style="margin-left: 1em">德裕稱志和隱而有名顯而無事不窮不達嚴光之比</span>  
<span style="margin-left: 2em"><sub class="note-yuan">志和漁父詞西塞山邊白鷺飛桃花流水鱖魚肥青箬笠綠蓑衣斜風細雨不須歸雲溪灣裏釣漁翁舴艋爲家西復東江上雪浦邊風反著荷衣不嘆窮松江蟹舍主人歡菰飯蓴羹亦共飡楓葉落荻花乾醉泊漁舟不覺寒青草湖中月正圓巴陵漁父櫂歌連釣車子橛頭船樂在風波不用仙顔魯公碑士有牢籠大虛橶掖玄造擺元氣而詞鋒首出軋無間而理窟肌分者其惟玄真子乎玄真子姓張氏本名龜齡東陽金華人父游朝清真好道著南華象罔說十卷又著冲虛白馬非馬證八卷代莫知之母留氏夢楓生腹上因而誕焉年十六游太學以明經擢第獻策肅宗深蒙賞重令翰林待詔授左金吾衛錄事參軍仍改名志和字子同尋復貶南浦尉經量移不願之任得還本貫既而親喪無復宦情遂扁舟垂綸浮三江泛五湖自謂烟波釣徒著十二卷凡三萬言號玄真子遂以稱焉客或以其文論道縱横謂之造化鼓吹京兆常請爲作內解玄真文述太易十五卷凡三百六十五卦以有無爲宗觀者以爲碧虛金骨兄浦陽尉鶴齡亦有文學恐玄真浪跡不還乃於會稽東郭鋤地結茅齋以居之閉竹門十年不出吏人嘗呼爲掏河夫執畚就役曾無忤色又欲以大布爲褐裘後徐氏聞之手爲織纊一製十年方暑不解所居草堂椽柱皮節皆存而無斧斤之跡文士效柏梁體作歌者十餘人浙東觀察使御史大夫陳公少游聞而謁之坐必終日因表其所居曰玄真坊又以門巷湫隘出錢買地以立閈閭曰迴軒巷命評事劉太真爲叙因賦柏梁之什文士詩以美之者十五人既門隔流水十年無橋陳公遂爲創造行者謂之大夫橋遂作告大夫橋文以謝之嘗以豹皮爲茵駿皮爲屩隱素木几酌班螺杯鳴柳杖拏隨意取適垂釣去餌不在得魚肅宗嘗錫奴婢各一玄真配爲夫妻名奴曰漁僮婢曰樵青人問其故漁僮使捧釣收綸蘆中鼓枻樵青使蘇蘭炊桂竹裏煎茶竟陵子陸羽校書郎裴修嘗詣問有何人往來答曰太虛作室而共居夜月爲燈以同照與四海諸公未嘗離別有何往來性好畫山水皆因酒酣乘興擊鼓吹笛或閉目或背面舞筆飛墨應節而成大曆九年秋八月訊真卿於湖州前御史李萼以縑帳請焉俄揮灑横抪而纖纊霏拂亂搶而攢毫電馳須臾之間千變萬化蓬壺彷彿而隱見天水微茫而招合觀者如堵轟然愕眙在坐六十餘人玄真命各言爵里紀年名字第行於下作兩句題目命酒以蕉葉書之授翰立成潛皆屬對舉席駭嘆竟陵子因命畫工圖而次焉真卿以舴艋既敝請命更之答曰倘惠漁舟願以爲浮家泛宅沿泝江湖之上往來苕霅之間野夫之幸矣其詼諧辯捷皆此類然立性孤峻不可得而親踈率誠澹然人莫窺其喜愠視軒裳如草芥屏嗜欲若泥沙希跡乎道丈夫同符乎古作者莫可測乎忽焉去我思德滋深曷以寘懷寄諸他山之石銘曰邈玄真超隱淪齊得喪甘賤貧泛湖海同光塵字漁舟垂釣綸輔明主斯若人豈烟波終此身</sub></span>  
<span style="margin-left: 1em">宋</span>  
<span style="margin-left: 1em">邵桂子字德芳淳安人號玄同咸淳間以博學宏詞登</span>  
<span style="margin-left: 1em">進士第教授處州棄歸慕天隨子之風家於松江之修</span>  
<span style="margin-left: 1em">竹鄉殁乃還葬生平喜爲詩而意象冲融足淹高聽裁</span>  
<span style="margin-left: 1em">謝風塵之表脱超凡徑之外所謂卧深巖壑思遶滄洲</span>  
<span style="margin-left: 1em">瀟灑風流固宜爾也其寓松江有詩云家住千峯落照</span>  
<span style="margin-left: 1em">邊移居三泖白鷗前東鄰舊日秦侯隱西洛新巢衛叟</span>  
<span style="margin-left: 1em">還當日釣遊頻入夢何時婚嫁送歸田會須共跨青溪</span>  
<span style="margin-left: 1em">鶴點易寒窗伴老仙具見雅致高尚寓首丘之思焉</span>  
<span style="margin-left: 2em"><sub class="note-yuan">邵桂子娶華亭曹澤之女因家小蒸爲斯文領袖者四十年八十二卒所著有脞談稿又作忍默恕退四卦以自警子祖義池州學錄能詩工篆隸</sub></span>  
<span style="margin-left: 1em">俞韋齊汴梁人侍孝宗讀有詩名而好方外之學遍游</span>  
<span style="margin-left: 1em">名山至雲間擇紫岡家焉父伯雍以愈高宗左頤瘍賜</span>  
<span style="margin-left: 1em">保宜大夫資政殿學士其七世孫曰仲明號湛然子游</span>  
<span style="margin-left: 1em">心好道老釋之書遍覽無遺得至人三五飛步之術能</span>  
<span style="margin-left: 1em">致風雨不苟慕名利父殁奉喪葬東海上結廬其傍事</span>  
<span style="margin-left: 1em">其母尤謹</span>  
<span style="margin-left: 1em">吳惟信字仲孚湖州人寓居白鶴村以詩鳴郡人糜先</span>  
<span style="margin-left: 1em">生見惟信文亟稱之一日相遇扣所作惟信誦一絶云</span>  
<span style="margin-left: 1em">白髮傷春又一年閑將心事卜金錢梨花瘦盡東風軟</span>  
<span style="margin-left: 1em">商略平生到杜鵑糜不覺下拜曰天才也</span>  
<span style="margin-left: 1em">高晞遠字照菴通州人咸淳德祐間通判平江府自城</span>  
<span style="margin-left: 1em">潰家亦散亡煢然一身浮游江湖嘗館於衛參政涇家</span>  
<span style="margin-left: 1em">以所學私淑諸人晞遠資禀秀朗學問該博尤精邵堯</span>  
<span style="margin-left: 1em">夫之學謂堯夫觀物以聲色氣味聲色氣味有一萬七</span>  
<span style="margin-left: 1em">千二十四人之目若鼻口不能盡其觀與嗅嘗惟一萬</span>  
<span style="margin-left: 1em">七千二十四聲可以字別舉聲之一例而色氣味可類</span>  
<span style="margin-left: 1em">推也嘗手截竹爲管以定五音六律進退疏數細微弗</span>  
<span style="margin-left: 1em">差晚嗜參同契修究甚力嘗謂其書大抵以納甲之說</span>  
<span style="margin-left: 1em">寓其行持進退之度然納甲法即先天圖也第未知伯</span>  
<span style="margin-left: 1em">陽用虞翻之圖抑虞翻反用伯陽之圖耳他凡術數太</span>  
<span style="margin-left: 1em">乙六壬諸家咸究其妙因動聞聲可以驗吉凶定禍福</span>  
<span style="margin-left: 1em">其學後皆無傳者</span>  
<span style="margin-left: 1em">林景曦字德陽別號霽山温之平陽人咸淳辛未自太</span>  
<span style="margin-left: 1em">學釋褐授泉州教官歷禮部架閣轉從政郎適元兵熾</span>  
<span style="margin-left: 1em">遂不復仕恒與同舍生鄭樸翁輩私相嗟悼丙子元兵</span>  
<span style="margin-left: 1em">破杭有楊總統盡發宋諸陵棄其遺骸於草莽人莫敢</span>  
<span style="margin-left: 1em">收先生在越痛憤不已乃與樸翁陽爲采藥偕行陵上</span>  
<span style="margin-left: 1em">以草囊拾之盛以二函託言佛經埋瘞越山植冬青樹</span>  
<span style="margin-left: 1em">志之聞者莫不敬仰識與不識咸稱霽山先生會稽王</span>  
<span style="margin-left: 1em">監簿素相契善與尋歲寒之盟於是往來吳越殆廿餘</span>  
<span style="margin-left: 1em">年居雲間甚久有雲間懷古神山訪僧二陸故居澱湖</span>  
<span style="margin-left: 1em">黃耳塜諸作戊申卧疾歸卒於家年六十九所著詩文</span>  
<span style="margin-left: 1em">集十卷皆感發於忠義士林傳誦之</span>  
<span style="margin-left: 1em">吳潛字毅夫宣城人侍其父寓居下沙鹽塲讀書後魁</span>  
<span style="margin-left: 1em">多士爲宋開慶名相</span>  
<span style="margin-left: 1em">殷群號古溪娶曹學諭女因居小蒸至今呼其地爲殷</span>  
<span style="margin-left: 1em">莊仕宋至轉運司幹辦公事</span>  
<span style="margin-left: 1em">任士林字叔寔家奉化松林鄉人稱松鄉先生其先蜀</span>  
<span style="margin-left: 1em">緜竹人宋少師希夷之後八世祖始來居奉化再徙崎</span>  
<span style="margin-left: 1em">山士林六歲能屬文書經耳不忘諸子百家之言靡不</span>  
<span style="margin-left: 1em">周覽文章沉厚正大一以理爲主不作廋語棘人喉舌</span>  
<span style="margin-left: 1em">而含蓄頓挫使人讀之有餘味趙子昂袁伯長輩咸推</span>  
<span style="margin-left: 1em">其文謂今之柳河東云大德間擕家華亭與衛山齋善</span>  
<span style="margin-left: 1em">有訪山齋詩及興聖塔華藏院諸記至大初舉爲安定</span>  
<span style="margin-left: 1em">書院山長明年卒葬松林鄉子耜繇松江府史至兩浙</span>  
<span style="margin-left: 1em">鹽運照磨致仕會天下亂子孫遂家華亭</span>  
<span style="margin-left: 1em">元</span>  
<span style="margin-left: 1em">章齊字叔敬江陰人少喪母趙侍父孝謹長善詩尤好</span>  
<span style="margin-left: 1em">琴有田膏腴有宅靜邃暄辰涼夕藥闌竹嶼俎膎豆胰</span>  
<span style="margin-left: 1em">時捧一巵晏如也至正十五年八月守臣搆亂遂謝吏</span>  
<span style="margin-left: 1em">禄奉父隱於淞亂定歸踰年城復陷時父外往齊草舍</span>  
<span style="margin-left: 1em">露行問道訪候兵後躡奔吳門且物色諸昆弟侄之流</span>  
<span style="margin-left: 1em">散者而父終不見乃哀毁致疾七日呼子庠具紙筆書</span>  
<span style="margin-left: 1em">蓼莪詩首四句卒年三十七庠以鄉里梗隔葬上海之</span>  
<span style="margin-left: 1em">奥原王逢志其墓銘曰始焉同歸終分擕孝乖慈暌祇</span>  
<span style="margin-left: 1em">繫亂離死可以無悲</span>  
<span style="margin-left: 1em">張昱字元弼廬陵人仕元累陞行樞密院判嘗贊謀戎</span>  
<span style="margin-left: 1em">幕元末政壞遂棄官不仕張士誠據有浙西禮致之不</span>  
<span style="margin-left: 1em">屈與楊廉夫相得遂寓松江號一笑居士洪武初訪求</span>  
<span style="margin-left: 1em">前元故臣之賢者嘗被徵至京深見温接已而憫其老</span>  
<span style="margin-left: 1em">曰可閑矣厚賜遣歸更號可閑老人徜徉浙西湖山之</span>  
<span style="margin-left: 1em">間詩酒自適年八十有三</span>  
<span style="margin-left: 1em">楊維禎字廉夫會稽人封會稽男宏之子母李氏夢月</span>  
<span style="margin-left: 1em">中金錢墮懷而生稍長穎悟日記數千言弱冠父不爲</span>  
<span style="margin-left: 1em">授室築萬卷樓鐵崖山中使讀書去其梯轆轤傳食久</span>
