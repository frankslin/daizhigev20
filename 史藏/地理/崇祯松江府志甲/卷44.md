## 崇祯松江府志卷之四十四　人物九（游寓）

<span style="margin-left: 3em">游寓</span>  
<span style="margin-left: 1em">弹丸峰泖游者不鄙而辱临焉寓公客卿𫗴于是粥于</span>  
<span style="margin-left: 1em">是聚国族于是长子孙于是其否否者往来渐熟儿童</span>  
<span style="margin-left: 1em">牵衣而迎之曰吾家先生至矣清风古道高咏微言尚</span>  
<span style="margin-left: 1em">在诗筒酒瓢间宁忍以飘风视之乎志游寓</span>  
<span style="margin-left: 1em">汉</span>  
<span style="margin-left: 1em">笮融丹阳人初徐州牧陶谦使督广陵漕运曹操攻谦</span>  
<span style="margin-left: 1em">徐土不静融护谦男女百口马三十匹走北亭乡避难</span>  
<span style="margin-left: 1em">卒遂葬于此至今称为笮墓</span>  
<span style="margin-left: 1em">邹湛南阳新野人尝寓居孔宅故名邹孔宅湛尝见一</span>  
<span style="margin-left: 1em">人自称甄仲舒乃悟曰吾宅西有积土败瓦其中必有</span>  
<span style="margin-left: 1em">死人捡之果然厚加敛葬后舍宅为慧日寺</span>  
<span style="margin-left: 1em">唐</span>  
<span style="margin-left: 1em">朱放字长通襄州人隐于越之剡溪嗣曹王臯镇江西</span>  
<span style="margin-left: 1em">辟为节度参谋寻归越遭寇乱避地云间先有寄张山</span>  
<span style="margin-left: 1em">诗云知君住处足风烟古树荒村在眼前便欲移家逐</span>  
<span style="margin-left: 1em">君去惟愁未有买山钱至是留寓焉贞元初召为拾遗</span>  
<span style="margin-left: 1em">刘长卿赠以诗云诏书征拜脱荷裳身在东山闭草堂</span>  
<span style="margin-left: 1em">阊阖九门通禁籍华亭一鹤在朝行沧洲离别风烟远</span>  
<span style="margin-left: 1em">青琐幽深漏刻长今日郤回垂钓处海鸥相见已高翔</span>  
<span style="margin-left: 1em">然放终不就也后山阴贼退仍归剡溪刘又送之诗云</span>  
<span style="margin-left: 1em">越中初战罢江上送归桡后终于广陵有诗集顾况序</span>  
<span style="margin-left: 2em"><sub class="note-yuan">序云因都国出麟角凤喙为续断之胶与本无异朱君能以烟霞风景补缀藻绣符于自然山深月清中有猿啸复如新安江水文鱼彩石历历可数其杳琼翛飒若有人衣薜荔而隐女萝立意皆新奇创离声乐友之什情思最切虽有谏职心游江湖谢病而来慕出尘之侣精好涅般维摩经爱人为善有志未就终于广陵舟中识与不识聆风向义相与兴叹我主人延陵包君兵部李侍郎礼部刘侍郎皆有托孤之旧子郁袭其先行敬事父友泣捧遗文祈余冠序</sub></span>  
<span style="margin-left: 1em">张志和字子同婺州人唐肃宗慕其高命待诏翰林后</span>  
<span style="margin-left: 1em">出为南海尉遂放浪江湖与陆羽往还因托迹吴兴舴</span>  
<span style="margin-left: 1em">艋既敝请于颜鲁公得渔舟更之以为浮家泛宅垂纶</span>  
<span style="margin-left: 1em">于松江震泽间自谓烟波钓徒所著玄真子及大易十</span>  
<span style="margin-left: 1em">五篇其卦三百六十五后宪宗图其像求之不可得李</span>  
<span style="margin-left: 1em">德裕称志和隐而有名显而无事不穷不达严光之比</span>  
<span style="margin-left: 2em"><sub class="note-yuan">志和渔父词西塞山边白鹭飞桃花流水鳜鱼肥青箬笠绿蓑衣斜风细雨不须归云溪湾里钓渔翁舴艋为家西复东江上雪浦边风反著荷衣不叹穷松江蟹舍主人欢菰饭莼羹亦共飡枫叶落荻花乾醉泊渔舟不觉寒青草湖中月正圆巴陵渔父櫂歌连钓车子橛头船乐在风波不用仙颜鲁公碑士有牢笼大虚橶掖玄造摆元气而词锋首出轧无间而理窟肌分者其惟玄真子乎玄真子姓张氏本名龟龄东阳金华人父游朝清真好道著南华象罔说十卷又著冲虚白马非马证八卷代莫知之母留氏梦枫生腹上因而诞焉年十六游太学以明经擢第献策肃宗深蒙赏重令翰林待诏授左金吾卫录事参军仍改名志和字子同寻复贬南浦尉经量移不愿之任得还本贯既而亲丧无复宦情遂扁舟垂纶浮三江泛五湖自谓烟波钓徒著十二卷凡三万言号玄真子遂以称焉客或以其文论道纵横谓之造化鼓吹京兆常请为作内解玄真文述太易十五卷凡三百六十五卦以有无为宗观者以为碧虚金骨兄浦阳尉鹤龄亦有文学恐玄真浪迹不还乃于会稽东郭锄地结茅斋以居之闭竹门十年不出吏人尝呼为掏河夫执畚就役曾无忤色又欲以大布为褐裘后徐氏闻之手为织纩一制十年方暑不解所居草堂椽柱皮节皆存而无斧斤之迹文士效柏梁体作歌者十余人浙东观察使御史大夫陈公少游闻而谒之坐必终日因表其所居曰玄真坊又以门巷湫隘出钱买地以立闬闾曰回轩巷命评事刘太真为叙因赋柏梁之什文士诗以美之者十五人既门隔流水十年无桥陈公遂为创造行者谓之大夫桥遂作告大夫桥文以谢之尝以豹皮为茵骏皮为屩隐素木几酌班螺杯鸣柳杖拏随意取适垂钓去饵不在得鱼肃宗尝锡奴婢各一玄真配为夫妻名奴曰渔僮婢曰樵青人问其故渔僮使捧钓收纶芦中鼓枻樵青使苏兰炊桂竹里煎茶竟陵子陆羽校书郎裴修尝诣问有何人往来答曰太虚作室而共居夜月为灯以同照与四海诸公未尝离别有何往来性好画山水皆因酒酣乘兴击鼓吹笛或闭目或背面舞笔飞墨应节而成大历九年秋八月讯真卿于湖州前御史李萼以缣帐请焉俄挥洒横抪而纤纩霏拂乱抢而攒毫电驰须臾之间千变万化蓬壶仿佛而隐见天水微茫而招合观者如堵轰然愕眙在坐六十余人玄真命各言爵里纪年名字第行于下作两句题目命酒以蕉叶书之授翰立成潜皆属对举席骇叹竟陵子因命画工图而次焉真卿以舴艋既敝请命更之答曰倘惠渔舟愿以为浮家泛宅沿溯江湖之上往来苕霅之间野夫之幸矣其诙谐辩捷皆此类然立性孤峻不可得而亲踈率诚澹然人莫窥其喜愠视轩裳如草芥屏嗜欲若泥沙希迹乎道丈夫同符乎古作者莫可测乎忽焉去我思德滋深曷以寘怀寄诸他山之石铭曰邈玄真超隐沦齐得丧甘贱贫泛湖海同光尘字渔舟垂钓纶辅明主斯若人岂烟波终此身</sub></span>  
<span style="margin-left: 1em">宋</span>  
<span style="margin-left: 1em">邵桂子字德芳淳安人号玄同咸淳间以博学宏词登</span>  
<span style="margin-left: 1em">进士第教授处州弃归慕天随子之风家于松江之修</span>  
<span style="margin-left: 1em">竹乡殁乃还葬生平喜为诗而意象冲融足淹高听裁</span>  
<span style="margin-left: 1em">谢风尘之表脱超凡径之外所谓卧深岩壑思绕沧洲</span>  
<span style="margin-left: 1em">潇洒风流固宜尔也其寓松江有诗云家住千峰落照</span>  
<span style="margin-left: 1em">边移居三泖白鸥前东邻旧日秦侯隐西洛新巢卫叟</span>  
<span style="margin-left: 1em">还当日钓游频入梦何时婚嫁送归田会须共跨青溪</span>  
<span style="margin-left: 1em">鹤点易寒窗伴老仙具见雅致高尚寓首丘之思焉</span>  
<span style="margin-left: 2em"><sub class="note-yuan">邵桂子娶华亭曹泽之女因家小蒸为斯文领袖者四十年八十二卒所著有脞谈稿又作忍默恕退四卦以自警子祖义池州学录能诗工篆隶</sub></span>  
<span style="margin-left: 1em">俞韦齐汴梁人侍孝宗读有诗名而好方外之学遍游</span>  
<span style="margin-left: 1em">名山至云间择紫冈家焉父伯雍以愈高宗左颐疡赐</span>  
<span style="margin-left: 1em">保宜大夫资政殿学士其七世孙曰仲明号湛然子游</span>  
<span style="margin-left: 1em">心好道老释之书遍览无遗得至人三五飞步之术能</span>  
<span style="margin-left: 1em">致风雨不苟慕名利父殁奉丧葬东海上结庐其傍事</span>  
<span style="margin-left: 1em">其母尤谨</span>  
<span style="margin-left: 1em">吴惟信字仲孚湖州人寓居白鹤村以诗鸣郡人糜先</span>  
<span style="margin-left: 1em">生见惟信文亟称之一日相遇扣所作惟信诵一绝云</span>  
<span style="margin-left: 1em">白发伤春又一年闲将心事卜金钱梨花瘦尽东风软</span>  
<span style="margin-left: 1em">商略平生到杜鹃糜不觉下拜曰天才也</span>  
<span style="margin-left: 1em">高晞远字照庵通州人咸淳德祐间通判平江府自城</span>  
<span style="margin-left: 1em">溃家亦散亡茕然一身浮游江湖尝馆于卫参政泾家</span>  
<span style="margin-left: 1em">以所学私淑诸人晞远资禀秀朗学问该博尤精邵尧</span>  
<span style="margin-left: 1em">夫之学谓尧夫观物以声色气味声色气味有一万七</span>  
<span style="margin-left: 1em">千二十四人之目若鼻口不能尽其观与嗅尝惟一万</span>  
<span style="margin-left: 1em">七千二十四声可以字别举声之一例而色气味可类</span>  
<span style="margin-left: 1em">推也尝手截竹为管以定五音六律进退疏数细微弗</span>  
<span style="margin-left: 1em">差晚嗜参同契修究甚力尝谓其书大抵以纳甲之说</span>  
<span style="margin-left: 1em">寓其行持进退之度然纳甲法即先天图也第未知伯</span>  
<span style="margin-left: 1em">阳用虞翻之图抑虞翻反用伯阳之图耳他凡术数太</span>  
<span style="margin-left: 1em">乙六壬诸家咸究其妙因动闻声可以验吉凶定祸福</span>  
<span style="margin-left: 1em">其学后皆无传者</span>  
<span style="margin-left: 1em">林景曦字德阳别号霁山温之平阳人咸淳辛未自太</span>  
<span style="margin-left: 1em">学释褐授泉州教官历礼部架阁转从政郎适元兵炽</span>  
<span style="margin-left: 1em">遂不复仕恒与同舍生郑朴翁辈私相嗟悼丙子元兵</span>  
<span style="margin-left: 1em">破杭有杨总统尽发宋诸陵弃其遗骸于草莽人莫敢</span>  
<span style="margin-left: 1em">收先生在越痛愤不已乃与朴翁阳为采药偕行陵上</span>  
<span style="margin-left: 1em">以草囊拾之盛以二函托言佛经埋瘗越山植冬青树</span>  
<span style="margin-left: 1em">志之闻者莫不敬仰识与不识咸称霁山先生会稽王</span>  
<span style="margin-left: 1em">监簿素相契善与寻岁寒之盟于是往来吴越殆廿余</span>  
<span style="margin-left: 1em">年居云间甚久有云间怀古神山访僧二陆故居淀湖</span>  
<span style="margin-left: 1em">黄耳塜诸作戊申卧疾归卒于家年六十九所著诗文</span>  
<span style="margin-left: 1em">集十卷皆感发于忠义士林传诵之</span>  
<span style="margin-left: 1em">吴潜字毅夫宣城人侍其父寓居下沙盐塲读书后魁</span>  
<span style="margin-left: 1em">多士为宋开庆名相</span>  
<span style="margin-left: 1em">殷群号古溪娶曹学谕女因居小蒸至今呼其地为殷</span>  
<span style="margin-left: 1em">庄仕宋至转运司干办公事</span>  
<span style="margin-left: 1em">任士林字叔寔家奉化松林乡人称松乡先生其先蜀</span>  
<span style="margin-left: 1em">緜竹人宋少师希夷之后八世祖始来居奉化再徙崎</span>  
<span style="margin-left: 1em">山士林六岁能属文书经耳不忘诸子百家之言靡不</span>  
<span style="margin-left: 1em">周览文章沉厚正大一以理为主不作廋语棘人喉舌</span>  
<span style="margin-left: 1em">而含蓄顿挫使人读之有余味赵子昂袁伯长辈咸推</span>  
<span style="margin-left: 1em">其文谓今之柳河东云大德间擕家华亭与卫山斋善</span>  
<span style="margin-left: 1em">有访山斋诗及兴圣塔华藏院诸记至大初举为安定</span>  
<span style="margin-left: 1em">书院山长明年卒葬松林乡子耜繇松江府史至两浙</span>  
<span style="margin-left: 1em">盐运照磨致仕会天下乱子孙遂家华亭</span>  
<span style="margin-left: 1em">元</span>  
<span style="margin-left: 1em">章齐字叔敬江阴人少丧母赵侍父孝谨长善诗尤好</span>  
<span style="margin-left: 1em">琴有田膏腴有宅静邃暄辰凉夕药阑竹屿俎膎豆胰</span>  
<span style="margin-left: 1em">时捧一巵晏如也至正十五年八月守臣搆乱遂谢吏</span>  
<span style="margin-left: 1em">禄奉父隐于淞乱定归逾年城复陷时父外往齐草舍</span>  
<span style="margin-left: 1em">露行问道访候兵后蹑奔吴门且物色诸昆弟侄之流</span>  
<span style="margin-left: 1em">散者而父终不见乃哀毁致疾七日呼子庠具纸笔书</span>  
<span style="margin-left: 1em">蓼莪诗首四句卒年三十七庠以乡里梗隔葬上海之</span>  
<span style="margin-left: 1em">奥原王逢志其墓铭曰始焉同归终分擕孝乖慈暌祇</span>  
<span style="margin-left: 1em">系乱离死可以无悲</span>  
<span style="margin-left: 1em">张昱字元弼庐陵人仕元累升行枢密院判尝赞谋戎</span>  
<span style="margin-left: 1em">幕元末政坏遂弃官不仕张士诚据有浙西礼致之不</span>  
<span style="margin-left: 1em">屈与杨廉夫相得遂寓松江号一笑居士洪武初访求</span>  
<span style="margin-left: 1em">前元故臣之贤者尝被征至京深见温接已而悯其老</span>  
<span style="margin-left: 1em">曰可闲矣厚赐遣归更号可闲老人徜徉浙西湖山之</span>  
<span style="margin-left: 1em">间诗酒自适年八十有三</span>  
<span style="margin-left: 1em">杨维祯字廉夫会稽人封会稽男宏之子母李氏梦月</span>  
<span style="margin-left: 1em">中金钱堕怀而生稍长颖悟日记数千言弱冠父不为</span>  
<span style="margin-left: 1em">授室筑万卷楼铁崖山中使读书去其梯辘轳传食久</span>  
<span style="margin-left: 1em">之俾游学莆东鬻良马益装乃节缩诸费购黄氏群书</span>  
<span style="margin-left: 1em">以归父欢曰此顾不多于良马耶泰定丁卯擢进士第</span>  
<span style="margin-left: 1em">署天台尹天台多黠吏执官短长世号八雕悉按以法</span>
