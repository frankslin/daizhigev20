## 崇禎松江府志卷之二十八　宦績一（王霸治績）

<span style="margin-left: 3em">王霸治績</span>  
<span style="margin-left: 1em">吾松江見禹貢自神禹疏鑿三江而震澤洩矣太伯端</span>  
<span style="margin-left: 1em">委治吳而被髮文身之俗變矣康王設衛以鎮海壽夢</span>  
<span style="margin-left: 1em">築城以畜衆仲謀造艦以破曹鏐平王騰俶置營田其</span>  
<span style="margin-left: 1em">功德大有造於吾松歷歷載在掌故胡可罔也故首書</span>  
<span style="margin-left: 1em">王霸治績以志弗諼</span>  
<span style="margin-left: 1em">夏禹王　路史云舜拜禹治水土爵司空乃握括命暨</span>  
<span style="margin-left: 1em">虞余度人徒以傅王禹貢云三江既入震澤底定</span>  
<span style="margin-left: 2em">按三江謂松江婁江東江也史記正義曰西南上七</span>  
<span style="margin-left: 2em">十里至太湖曰松江古笠澤江吳地記云松江東北</span>  
<span style="margin-left: 2em">行七十里得三江口東北入海爲婁江東南入海爲</span>  
<span style="margin-left: 2em">東江并松江爲三江</span>  
<span style="margin-left: 1em">吳泰伯　吳世家云泰伯奔荆蠻自號勾吳往而歸之</span>  
<span style="margin-left: 1em">千餘家按左傳曰泰伯端委以治周禮杜元凱注曰端</span>  
<span style="margin-left: 1em">委禮服也穎達曰端玄也委者長委于地也賦言太伯</span>  
<span style="margin-left: 1em">造成國邑服玄端之衣以行周禮彰顯先王之風化於</span>  
<span style="margin-left: 1em">吳國也</span>  
<span style="margin-left: 2em">吳之先襍於蠻夷斷髮文身以避蛟龍之患而邊海</span>  
<span style="margin-left: 2em">尤甚太伯實千萬世教化之祖尸而祝之寧獨毘陵</span>  
<span style="margin-left: 2em">閶闔也<sub class="note-yuan">泰伯廟祀議</sub></span>  
<span style="margin-left: 1em">周康王　樞要云康王東遊築城鎮海以南接金山後</span>  
<span style="margin-left: 1em">代因以設衛金山有城始此其地東南際大海西抵浙</span>  
<span style="margin-left: 1em">之海寧而襟帶淮揚諸郡</span>  
<span style="margin-left: 2em">金山志云按南接金山則應麗金山北麓其故址莫</span>  
<span style="margin-left: 2em">攷又吳越春秋云宋武帝築城於故海鹽以禦孫恩</span>  
<span style="margin-left: 2em">故海鹽即今柘湖里人所謂金山嘴是也</span>  
<span style="margin-left: 1em">吳子壽夢　泰伯至壽夢十九世益昌大稱王通於中</span>  
<span style="margin-left: 1em">國始築華亭郡有吳王獵場在華亭谷東</span>  
<span style="margin-left: 2em">嘗見小說家言吳陸遜居第園有華麗亭故名華亭</span>  
<span style="margin-left: 2em">妄也漢法十里一亭十亭一鄉此亭留會宿之所凡</span>  
<span style="margin-left: 2em">封侯初封亭侯如某亭侯之類遜初封華亭侯<sub class="note-yuan">農田餘話</sub></span>  
<span style="margin-left: 1em">秦始皇　括地志云三十七年冬始皇東巡浮江下過</span>  
<span style="margin-left: 1em">丹陽臨浙江還過吳並海上又雲間志云邑有始皇馳</span>  
<span style="margin-left: 1em">道相傳有大岡路西通吳城有始皇走馬塘有秦山謂</span>  
<span style="margin-left: 1em">始皇駐蹕於此以望海</span>  
<span style="margin-left: 2em">史記秦二世東行郡縣到碣石並海南至會稽丞相</span>  
<span style="margin-left: 2em">斯等請具刻詔書刻石其詞曰皇帝立國維初在昔</span>  
<span style="margin-left: 2em">嗣世稱王討伐亂逆威動四極武義直方戎臣奉詔</span>  
<span style="margin-left: 2em">經時不久滅六暴强廿有六年上薦高號孝道顯明</span>  
<span style="margin-left: 2em">既獻泰成乃降專惠親巡遠方登於嶧山群臣從者</span>  
<span style="margin-left: 2em">咸思攸長追念亂世分土建邦以開事理攻戰日作</span>  
<span style="margin-left: 2em">流血於野自太古始世無萬數阤及五帝莫能禁止</span>  
<span style="margin-left: 2em">乃今皇帝一家天下兵不復起災害滅除黔首康定</span>  
<span style="margin-left: 2em">利澤長久羣臣誦畧刻此樂石以著經紀<sub class="note-yuan">史記失載今載之焦氏筆乘</sub></span>  
<span style="margin-left: 1em">吳主孫權代兄領兵割據江東欲攻曹操大造青龍戰</span>  
<span style="margin-left: 1em">艦命周瑜程普各領萬人與劉備俱進遇於赤壁大破</span>  
<span style="margin-left: 1em">曹軍遂識武功因名其地爲青龍江後爲青龍鎮</span>  
<span style="margin-left: 2em">青龍鎮今爲青浦縣</span>  
<span style="margin-left: 1em">吳越王錢鏐拒黃巢斬劉漢宏擒薛明破徐福執董昌</span>  
<span style="margin-left: 1em">梁受唐禪進封吳越王改臨安縣爲安國縣廣義鄉爲</span>  
<span style="margin-left: 1em">衣錦鄉升杭越爲大都督府時華亭爲海冠王騰所據</span>  
<span style="margin-left: 1em">鏐遣顧全斌平之</span>  
<span style="margin-left: 1em">錢俶字文德襲吳越王宋改元江南平俶與妻子朝宋</span>  
<span style="margin-left: 1em">太祖待以優禮特賜劍履上殿詔書不名太平興國三</span>  
<span style="margin-left: 1em">年復朝宋遂以國歸有司錢氏傳五王共八十四年俶</span>  
<span style="margin-left: 1em">薨册封秦國王謚忠懿吳越雖重稅歛然俶多寬民之</span>  
<span style="margin-left: 1em">政下令租賦多所逋滯歲杪必命蠲蕩又募民能墾荒</span>  
<span style="margin-left: 1em">田者勿收其稅於是境無棄田又置營田數千人於松</span>  
<span style="margin-left: 1em">江闢土而耕其奇器精縑皆製於官以充朝貢民老死</span>  
<span style="margin-left: 1em">無他纏累且完國歸朝不殺一人太宗嘗謂俶曰卿能</span>  
<span style="margin-left: 1em">保全一方以歸於我不致血刃深可嘉也</span>  
<span style="margin-left: 3em">名臣宦績</span>  
<span style="margin-left: 1em">長吏一報殊尤之擢相與攀行轍碑去思士風近於厚</span>  
<span style="margin-left: 1em">矣及問先朝循吏捍大患卹大災砥大節鑿鑿著人耳</span>  
<span style="margin-left: 1em">目者至不能舉其姓氏甚有經百餘年而不登之名宦</span>  
<span style="margin-left: 1em">俎豆之祠烏在其三代直道也余故於臺察郡縣以至</span>  
<span style="margin-left: 1em">一命而上無微不錄無隱不搜大抵後諸公而不亡者</span>  
<span style="margin-left: 1em">石也後石而不亡者文也石不言志言之矣</span>  
<span style="margin-left: 1em">吳</span>  
<span style="margin-left: 1em">伍員字子胥楚平王以讒殺其父伍奢逃於吳仕爲行</span>  
<span style="margin-left: 1em">人卒報楚仇强吳以破越子胥以忠諫死夫差裹之鴟</span>  
<span style="margin-left: 1em">夷投於江華亭胥浦塘子胥所鑿故名自長泖接界涇</span>  
<span style="margin-left: 1em">而東盡納惠高彭巷處士瀝瀆諸水此一郡北流入浦</span>  
<span style="margin-left: 1em">之要津也漢唐有子胥廟</span>  
<span style="margin-left: 2em">脚氣集云吳越分界在檇李錢塘江乃是越地吳投</span>  
<span style="margin-left: 2em">子胥於江松江耳</span>  
<span style="margin-left: 1em">楚</span>  
<span style="margin-left: 1em">黃歇楚人也烈王即位以爲相封春申君賜淮北地十</span>  
<span style="margin-left: 1em">二縣後十五歲歇請獻淮北地而封於江東王許之歇</span>  
<span style="margin-left: 1em">因城故吳墟以自爲都邑治水松江導流入海今黃浦</span>  
<span style="margin-left: 1em">是也因其姓曰黃亦曰春申浦</span>  
<span style="margin-left: 1em">漢</span>  
<span style="margin-left: 1em">朱買臣字翁子吳人也邑子嚴助貴幸薦買臣召見說</span>  
<span style="margin-left: 1em">春秋言楚辭帝甚說之時東粤數反覆買臣因言故東</span>  
<span style="margin-left: 1em">越王居保泉山一人守險千人不得上今聞東越王更</span>  
<span style="margin-left: 1em">徙處南行去泉山五百里居大澤中令發兵浮海直指</span>  
<span style="margin-left: 1em">泉山陳舟列兵席捲南行可破滅也拜會稽太守上謂</span>  
<span style="margin-left: 1em">買臣曰富貴不歸故鄉如衣繡夜行今子何如買臣頓</span>  
<span style="margin-left: 1em">首謝詔買臣到郡治樓船備糧食水戰具居歲餘受詔</span>  
<span style="margin-left: 1em">將兵與横海將軍韓說等共擊東越破之以功徵入爲</span>  
<span style="margin-left: 1em">主爵都尉</span>  
<span style="margin-left: 2em">郡守秦置掌理郡政秩二千石漢景帝中和二年更</span>  
<span style="margin-left: 2em">名太守董仲舒曰民之師帥兼領武事者也漢會稽</span>  
<span style="margin-left: 2em">太守治吳吳郡東至於海北至於江青龍福山皆海</span>  
<span style="margin-left: 2em">道遺蹟武帝遣嚴助發兵會稽浮海救東甌即此地</span>  
<span style="margin-left: 2em">也助與買臣俱會稽吳人相繼爲會稽太守助未至</span>  
<span style="margin-left: 2em">閩越旋罷兵而買臣成破越之功爵都尉<sub class="note-yuan">見閲古編</sub></span>  
<span style="margin-left: 2em">韓說亦吳人與朱買臣同受詔在吳中治樓船破東</span>  
<span style="margin-left: 2em">越有功祀於吳</span>  
<span style="margin-left: 1em">任延字長孫宛人更始元年拜會稽都尉時年十九迎</span>  
<span style="margin-left: 1em">官驚其壯及到靜泊無爲唯先遣饋禮祠延陵季子時</span>  
<span style="margin-left: 1em">道路未通避亂江南者未還中土會稽頗稱多士延聘</span>  
<span style="margin-left: 1em">請高行如董子儀嚴子陵等待以師友掾吏貧者輒分</span>  
<span style="margin-left: 1em">俸賑給之省諸卒令耕公田以周窮急每時行屬縣輒</span>  
<span style="margin-left: 1em">使慰勉孝子就餐飯之吳有龍丘萇隱居太末志不降</span>  
<span style="margin-left: 1em">辱王莽連辟不到掾吏白請召之延曰龍丘先生躬德</span>  
<span style="margin-left: 1em">履義有原憲伯夷之節都尉灑掃其門猶懼辱焉召之</span>  
<span style="margin-left: 1em">不可遣功曹奉謁修書記致醫藥吏使相望於道積一</span>  
<span style="margin-left: 1em">歲萇乃詣府願得備錄延辭讓再三遂署議曹祭酒萇</span>  
<span style="margin-left: 1em">尋卒延自臨殯不朝三日是以郡中賢士大夫争往宦</span>  
<span style="margin-left: 1em">焉建武初徵爲九真太守</span>  
<span style="margin-left: 1em">李君更始五年爲守治東倉爲婁縣屋<sub class="note-yuan">見越絕書</sub></span>  
<span style="margin-left: 2em">姑蘇志云東倉古婁縣之惠安鄉</span>  
<span style="margin-left: 1em">鍾離意字子阿山陰人少爲郡督郵時部縣亭長有受</span>  
<span style="margin-left: 1em">人酒禮者府下記案考之意封還記入言於太守曰政</span>  
<span style="margin-left: 1em">化之本繇近及遠今宜先清府內直闊畧遠縣亭細微</span>  
<span style="margin-left: 1em">之愆太守甚賢之遂任以縣事建武十四年會稽大疫</span>  
<span style="margin-left: 1em">死者萬數意獨身自巡視經給醫藥所部多蒙全濟舉</span>  
<span style="margin-left: 1em">孝廉光武目爲良吏</span>  
<span style="margin-left: 2em">意別傳云建武十四年太守汝南黃讜召意署北部</span>  
<span style="margin-left: 2em">督郵吳中大疫黃君轉署意爲中部督郵意乃露車</span>  
<span style="margin-left: 2em">不冠身不修整行病者門入其家至與醫藥詣神廟</span>  
<span style="margin-left: 2em">爲民禱祭召醫數百人令和草藥恐醫或以毒藥過</span>  
<span style="margin-left: 2em">劑賊害民命先自吞嘗然後行之其所臨護四千餘</span>  
<span style="margin-left: 2em">人後日府君出省災百姓攀車言曰明府不須出但</span>  
<span style="margin-left: 2em">得鍾離督郵民皆活也</span>  
<span style="margin-left: 1em">第五倫字伯魚長陵人少有義行建武二十九年拜會</span>  
<span style="margin-left: 1em">稽太守躬自斬芻養馬妻執炊爨受俸裁留一月糧餘</span>  
<span style="margin-left: 1em">皆賤貿與貧羸之民俗多淫祀常以牛祭神財産困匱</span>  
<span style="margin-left: 1em">其自食牛而不以薦祠者發病且死爲牛鳴前後郡將</span>  
<span style="margin-left: 1em">莫敢禁倫移書屬縣曉告百姓其巫祝託鬼神詐怖愚</span>  
<span style="margin-left: 1em">民皆案論之有妄屠牛者吏輒行罰百姓以安署督郵</span>  
<span style="margin-left: 1em">謝夷吾爲主簿鄉嗇夫鄭弘爲督郵舉武孝廉永平五</span>  
<span style="margin-left: 1em">年坐法徵老小攀車馬號呼相隨日纔行數里倫乃僞</span>  
<span style="margin-left: 1em">止亭舍陰乘船去及詣廷尉吏民上書守闕者千餘人</span>  
<span style="margin-left: 1em">詔公車諸爲會稽太守上書者勿復受會帝幸廷尉錄</span>  
<span style="margin-left: 1em">囚得免歸田里後官至司空</span>  
<span style="margin-left: 1em">張霸字伯饒成都人永元中爲會稽太守表用郡人處</span>  
<span style="margin-left: 1em">士顧奉公孫松等奉後爲穎川太守松爲司隸校尉並</span>  
<span style="margin-left: 1em">有名稱其餘有業行者皆見擢用凡在屬邑争厲志節</span>  
<span style="margin-left: 1em">習經者以千數道路但聞誦讀聲野無遺冠民語曰城</span>  
<span style="margin-left: 1em">上烏鳴哺父母府中諸吏皆孝子霸視事三年遂上病</span>  
<span style="margin-left: 1em">後徵四遷爲侍中卒翟酺與諸儒門人追錄本行謚曰</span>  
<span style="margin-left: 1em">憲文</span>  
<span style="margin-left: 2em">續漢書曰霸爲郡越賊歸附童謡曰棄我㦸捐我矛</span>  
<span style="margin-left: 2em">盗賊盡吏皆休</span>  
<span style="margin-left: 1em">李肅穎川人桓帝時太守舉陸康孝廉肅後坐事誅康</span>  
<span style="margin-left: 1em">爲斂尸送喪還鄉行服</span>  
<span style="margin-left: 2em">康字季寧少篤孝弟勤修操行載郡名賢志又漢太</span>  
<span style="margin-left: 2em">守臧旻亦舉陸康茂才</span>  
<span style="margin-left: 1em">鄧攸平陽襄陽人元帝時爲吳郡守攸載米之郡俸禄</span>  
<span style="margin-left: 1em">無所受唯飲吳水而已時郡中大饑攸表賑貸未報乃</span>  
<span style="margin-left: 1em">輒開倉救之攸在郡刑政清明百姓歡悦爲中興良守</span>  
<span style="margin-left: 1em">後稱疾去職郡常有送迎錢數百萬攸去郡不受一錢</span>  
<span style="margin-left: 1em">百姓數千人留牽攸船不得進攸乃小停夜中發去吳</span>  
<span style="margin-left: 1em">人歌之曰紞如打五鼓鷄鳴天欲曙鄧侯挽不留謝令</span>  
<span style="margin-left: 1em">推不去百姓仍詣臺乞留焉</span>
