## 崇祯松江府志卷之二十八　宦绩一（王霸治绩）

<span style="margin-left: 3em">王霸治绩</span>  
<span style="margin-left: 1em">吾松江见禹贡自神禹疏凿三江而震泽泄矣太伯端</span>  
<span style="margin-left: 1em">委治吴而被发文身之俗变矣康王设卫以镇海寿梦</span>  
<span style="margin-left: 1em">筑城以畜众仲谋造舰以破曹镠平王腾俶置营田其</span>  
<span style="margin-left: 1em">功德大有造于吾松历历载在掌故胡可罔也故首书</span>  
<span style="margin-left: 1em">王霸治绩以志弗谖</span>  
<span style="margin-left: 1em">夏禹王　路史云舜拜禹治水土爵司空乃握括命暨</span>  
<span style="margin-left: 1em">虞余度人徒以傅王禹贡云三江既入震泽底定</span>  
<span style="margin-left: 2em">按三江谓松江娄江东江也史记正义曰西南上七</span>  
<span style="margin-left: 2em">十里至太湖曰松江古笠泽江吴地记云松江东北</span>  
<span style="margin-left: 2em">行七十里得三江口东北入海为娄江东南入海为</span>  
<span style="margin-left: 2em">东江并松江为三江</span>  
<span style="margin-left: 1em">吴泰伯　吴世家云泰伯奔荆蛮自号勾吴往而归之</span>  
<span style="margin-left: 1em">千余家按左传曰泰伯端委以治周礼杜元凯注曰端</span>  
<span style="margin-left: 1em">委礼服也颖达曰端玄也委者长委于地也赋言太伯</span>  
<span style="margin-left: 1em">造成国邑服玄端之衣以行周礼彰显先王之风化于</span>  
<span style="margin-left: 1em">吴国也</span>  
<span style="margin-left: 2em">吴之先襍于蛮夷断发文身以避蛟龙之患而边海</span>  
<span style="margin-left: 2em">尤甚太伯实千万世教化之祖尸而祝之宁独毘陵</span>  
<span style="margin-left: 2em">阊阖也<sub class="note-yuan">泰伯庙祀议</sub></span>  
<span style="margin-left: 1em">周康王　枢要云康王东游筑城镇海以南接金山后</span>  
<span style="margin-left: 1em">代因以设卫金山有城始此其地东南际大海西抵浙</span>  
<span style="margin-left: 1em">之海宁而襟带淮扬诸郡</span>  
<span style="margin-left: 2em">金山志云按南接金山则应丽金山北麓其故址莫</span>  
<span style="margin-left: 2em">攷又吴越春秋云宋武帝筑城于故海盐以御孙恩</span>  
<span style="margin-left: 2em">故海盐即今柘湖里人所谓金山嘴是也</span>  
<span style="margin-left: 1em">吴子寿梦　泰伯至寿梦十九世益昌大称王通于中</span>  
<span style="margin-left: 1em">国始筑华亭郡有吴王猎场在华亭谷东</span>  
<span style="margin-left: 2em">尝见小说家言吴陆逊居第园有华丽亭故名华亭</span>  
<span style="margin-left: 2em">妄也汉法十里一亭十亭一乡此亭留会宿之所凡</span>  
<span style="margin-left: 2em">封侯初封亭侯如某亭侯之类逊初封华亭侯<sub class="note-yuan">农田余话</sub></span>  
<span style="margin-left: 1em">秦始皇　括地志云三十七年冬始皇东巡浮江下过</span>  
<span style="margin-left: 1em">丹阳临浙江还过吴并海上又云间志云邑有始皇驰</span>  
<span style="margin-left: 1em">道相传有大冈路西通吴城有始皇走马塘有秦山谓</span>  
<span style="margin-left: 1em">始皇驻跸于此以望海</span>  
<span style="margin-left: 2em">史记秦二世东行郡县到碣石并海南至会稽丞相</span>  
<span style="margin-left: 2em">斯等请具刻诏书刻石其词曰皇帝立国维初在昔</span>  
<span style="margin-left: 2em">嗣世称王讨伐乱逆威动四极武义直方戎臣奉诏</span>  
<span style="margin-left: 2em">经时不久灭六暴强廿有六年上荐高号孝道显明</span>  
<span style="margin-left: 2em">既献泰成乃降专惠亲巡远方登于峄山群臣从者</span>  
<span style="margin-left: 2em">咸思攸长追念乱世分土建邦以开事理攻战日作</span>  
<span style="margin-left: 2em">流血于野自太古始世无万数阤及五帝莫能禁止</span>  
<span style="margin-left: 2em">乃今皇帝一家天下兵不复起灾害灭除黔首康定</span>  
<span style="margin-left: 2em">利泽长久群臣诵畧刻此乐石以著经纪<sub class="note-yuan">史记失载今载之焦氏笔乘</sub></span>  
<span style="margin-left: 1em">吴主孙权代兄领兵割据江东欲攻曹操大造青龙战</span>  
<span style="margin-left: 1em">舰命周瑜程普各领万人与刘备俱进遇于赤壁大破</span>  
<span style="margin-left: 1em">曹军遂识武功因名其地为青龙江后为青龙镇</span>  
<span style="margin-left: 2em">青龙镇今为青浦县</span>  
<span style="margin-left: 1em">吴越王钱镠拒黄巢斩刘汉宏擒薛明破徐福执董昌</span>  
<span style="margin-left: 1em">梁受唐禅进封吴越王改临安县为安国县广义乡为</span>  
<span style="margin-left: 1em">衣锦乡升杭越为大都督府时华亭为海冠王腾所据</span>  
<span style="margin-left: 1em">镠遣顾全斌平之</span>  
<span style="margin-left: 1em">钱俶字文德袭吴越王宋改元江南平俶与妻子朝宋</span>  
<span style="margin-left: 1em">太祖待以优礼特赐剑履上殿诏书不名太平兴国三</span>  
<span style="margin-left: 1em">年复朝宋遂以国归有司钱氏传五王共八十四年俶</span>  
<span style="margin-left: 1em">薨册封秦国王谥忠懿吴越虽重税歛然俶多宽民之</span>  
<span style="margin-left: 1em">政下令租赋多所逋滞岁杪必命蠲荡又募民能垦荒</span>  
<span style="margin-left: 1em">田者勿收其税于是境无弃田又置营田数千人于松</span>  
<span style="margin-left: 1em">江辟土而耕其奇器精缣皆制于官以充朝贡民老死</span>  
<span style="margin-left: 1em">无他缠累且完国归朝不杀一人太宗尝谓俶曰卿能</span>  
<span style="margin-left: 1em">保全一方以归于我不致血刃深可嘉也</span>  
<span style="margin-left: 3em">名臣宦绩</span>  
<span style="margin-left: 1em">长吏一报殊尤之擢相与攀行辙碑去思士风近于厚</span>  
<span style="margin-left: 1em">矣及问先朝循吏捍大患恤大灾砥大节凿凿著人耳</span>  
<span style="margin-left: 1em">目者至不能举其姓氏甚有经百余年而不登之名宦</span>  
<span style="margin-left: 1em">俎豆之祠乌在其三代直道也余故于台察郡县以至</span>  
<span style="margin-left: 1em">一命而上无微不录无隐不搜大抵后诸公而不亡者</span>  
<span style="margin-left: 1em">石也后石而不亡者文也石不言志言之矣</span>  
<span style="margin-left: 1em">吴</span>  
<span style="margin-left: 1em">伍员字子胥楚平王以谗杀其父伍奢逃于吴仕为行</span>  
<span style="margin-left: 1em">人卒报楚仇强吴以破越子胥以忠谏死夫差裹之鸱</span>  
<span style="margin-left: 1em">夷投于江华亭胥浦塘子胥所凿故名自长泖接界泾</span>  
<span style="margin-left: 1em">而东尽纳惠高彭巷处士沥渎诸水此一郡北流入浦</span>  
<span style="margin-left: 1em">之要津也汉唐有子胥庙</span>  
<span style="margin-left: 2em">脚气集云吴越分界在檇李钱塘江乃是越地吴投</span>  
<span style="margin-left: 2em">子胥于江松江耳</span>  
<span style="margin-left: 1em">楚</span>  
<span style="margin-left: 1em">黄歇楚人也烈王即位以为相封春申君赐淮北地十</span>  
<span style="margin-left: 1em">二县后十五岁歇请献淮北地而封于江东王许之歇</span>  
<span style="margin-left: 1em">因城故吴墟以自为都邑治水松江导流入海今黄浦</span>  
<span style="margin-left: 1em">是也因其姓曰黄亦曰春申浦</span>  
<span style="margin-left: 1em">汉</span>  
<span style="margin-left: 1em">朱买臣字翁子吴人也邑子严助贵幸荐买臣召见说</span>  
<span style="margin-left: 1em">春秋言楚辞帝甚说之时东粤数反复买臣因言故东</span>  
<span style="margin-left: 1em">越王居保泉山一人守险千人不得上今闻东越王更</span>  
<span style="margin-left: 1em">徙处南行去泉山五百里居大泽中令发兵浮海直指</span>  
<span style="margin-left: 1em">泉山陈舟列兵席卷南行可破灭也拜会稽太守上谓</span>  
<span style="margin-left: 1em">买臣曰富贵不归故乡如衣绣夜行今子何如买臣顿</span>  
<span style="margin-left: 1em">首谢诏买臣到郡治楼船备粮食水战具居岁余受诏</span>  
<span style="margin-left: 1em">将兵与横海将军韩说等共击东越破之以功征入为</span>  
<span style="margin-left: 1em">主爵都尉</span>  
<span style="margin-left: 2em">郡守秦置掌理郡政秩二千石汉景帝中和二年更</span>  
<span style="margin-left: 2em">名太守董仲舒曰民之师帅兼领武事者也汉会稽</span>  
<span style="margin-left: 2em">太守治吴吴郡东至于海北至于江青龙福山皆海</span>  
<span style="margin-left: 2em">道遗迹武帝遣严助发兵会稽浮海救东瓯即此地</span>  
<span style="margin-left: 2em">也助与买臣俱会稽吴人相继为会稽太守助未至</span>  
<span style="margin-left: 2em">闽越旋罢兵而买臣成破越之功爵都尉<sub class="note-yuan">见阅古编</sub></span>  
<span style="margin-left: 2em">韩说亦吴人与朱买臣同受诏在吴中治楼船破东</span>  
<span style="margin-left: 2em">越有功祀于吴</span>  
<span style="margin-left: 1em">任延字长孙宛人更始元年拜会稽都尉时年十九迎</span>  
<span style="margin-left: 1em">官惊其壮及到静泊无为唯先遣馈礼祠延陵季子时</span>  
<span style="margin-left: 1em">道路未通避乱江南者未还中土会稽颇称多士延聘</span>  
<span style="margin-left: 1em">请高行如董子仪严子陵等待以师友掾吏贫者辄分</span>  
<span style="margin-left: 1em">俸赈给之省诸卒令耕公田以周穷急每时行属县辄</span>  
<span style="margin-left: 1em">使慰勉孝子就餐饭之吴有龙丘苌隐居太末志不降</span>  
<span style="margin-left: 1em">辱王莽连辟不到掾吏白请召之延曰龙丘先生躬德</span>  
<span style="margin-left: 1em">履义有原宪伯夷之节都尉洒扫其门犹惧辱焉召之</span>  
<span style="margin-left: 1em">不可遣功曹奉谒修书记致医药吏使相望于道积一</span>  
<span style="margin-left: 1em">岁苌乃诣府愿得备录延辞让再三遂署议曹祭酒苌</span>  
<span style="margin-left: 1em">寻卒延自临殡不朝三日是以郡中贤士大夫争往宦</span>  
<span style="margin-left: 1em">焉建武初征为九真太守</span>  
<span style="margin-left: 1em">李君更始五年为守治东仓为娄县屋<sub class="note-yuan">见越绝书</sub></span>  
<span style="margin-left: 2em">姑苏志云东仓古娄县之惠安乡</span>  
<span style="margin-left: 1em">钟离意字子阿山阴人少为郡督邮时部县亭长有受</span>  
<span style="margin-left: 1em">人酒礼者府下记案考之意封还记入言于太守曰政</span>  
<span style="margin-left: 1em">化之本繇近及远今宜先清府内直阔畧远县亭细微</span>  
<span style="margin-left: 1em">之愆太守甚贤之遂任以县事建武十四年会稽大疫</span>  
<span style="margin-left: 1em">死者万数意独身自巡视经给医药所部多蒙全济举</span>  
<span style="margin-left: 1em">孝廉光武目为良吏</span>  
<span style="margin-left: 2em">意别传云建武十四年太守汝南黄谠召意署北部</span>  
<span style="margin-left: 2em">督邮吴中大疫黄君转署意为中部督邮意乃露车</span>  
<span style="margin-left: 2em">不冠身不修整行病者门入其家至与医药诣神庙</span>  
<span style="margin-left: 2em">为民祷祭召医数百人令和草药恐医或以毒药过</span>  
<span style="margin-left: 2em">剂贼害民命先自吞尝然后行之其所临护四千余</span>  
<span style="margin-left: 2em">人后日府君出省灾百姓攀车言曰明府不须出但</span>  
<span style="margin-left: 2em">得钟离督邮民皆活也</span>  
<span style="margin-left: 1em">第五伦字伯鱼长陵人少有义行建武二十九年拜会</span>  
<span style="margin-left: 1em">稽太守躬自斩刍养马妻执炊爨受俸裁留一月粮余</span>  
<span style="margin-left: 1em">皆贱贸与贫羸之民俗多淫祀常以牛祭神财产困匮</span>  
<span style="margin-left: 1em">其自食牛而不以荐祠者发病且死为牛鸣前后郡将</span>  
<span style="margin-left: 1em">莫敢禁伦移书属县晓告百姓其巫祝托鬼神诈怖愚</span>  
<span style="margin-left: 1em">民皆案论之有妄屠牛者吏辄行罚百姓以安署督邮</span>  
<span style="margin-left: 1em">谢夷吾为主簿乡啬夫郑弘为督邮举武孝廉永平五</span>  
<span style="margin-left: 1em">年坐法征老小攀车马号呼相随日才行数里伦乃伪</span>  
<span style="margin-left: 1em">止亭舍阴乘船去及诣廷尉吏民上书守阙者千余人</span>  
<span style="margin-left: 1em">诏公车诸为会稽太守上书者勿复受会帝幸廷尉录</span>  
<span style="margin-left: 1em">囚得免归田里后官至司空</span>  
<span style="margin-left: 1em">张霸字伯饶成都人永元中为会稽太守表用郡人处</span>  
<span style="margin-left: 1em">士顾奉公孙松等奉后为颖川太守松为司隶校尉并</span>  
<span style="margin-left: 1em">有名称其余有业行者皆见擢用凡在属邑争厉志节</span>  
<span style="margin-left: 1em">习经者以千数道路但闻诵读声野无遗冠民语曰城</span>  
<span style="margin-left: 1em">上乌鸣哺父母府中诸吏皆孝子霸视事三年遂上病</span>  
<span style="margin-left: 1em">后征四迁为侍中卒翟酺与诸儒门人追录本行谥曰</span>  
<span style="margin-left: 1em">宪文</span>  
<span style="margin-left: 2em">续汉书曰霸为郡越贼归附童谣曰弃我㦸捐我矛</span>  
<span style="margin-left: 2em">盗贼尽吏皆休</span>  
<span style="margin-left: 1em">李肃颖川人桓帝时太守举陆康孝廉肃后坐事诛康</span>  
<span style="margin-left: 1em">为敛尸送丧还乡行服</span>  
<span style="margin-left: 2em">康字季宁少笃孝弟勤修操行载郡名贤志又汉太</span>  
<span style="margin-left: 2em">守臧旻亦举陆康茂才</span>  
<span style="margin-left: 1em">邓攸平阳襄阳人元帝时为吴郡守攸载米之郡俸禄</span>  
<span style="margin-left: 1em">无所受唯饮吴水而已时郡中大饥攸表赈贷未报乃</span>  
<span style="margin-left: 1em">辄开仓救之攸在郡刑政清明百姓欢悦为中兴良守</span>  
<span style="margin-left: 1em">后称疾去职郡常有送迎钱数百万攸去郡不受一钱</span>
