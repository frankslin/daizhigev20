## 崇禎松江府志卷之四　山

<span style="margin-left: 3em">山</span>  
<span style="margin-left: 1em">東南龍脉遇海而止元氣蟠演發爲柔中之剛山不能</span>  
<span style="margin-left: 1em">勝水而拔地卓起未肯相牽相連强爲詭隨附麗其骨</span>  
<span style="margin-left: 1em">力與龍門砥柱同人才間生率多品勝厥惟肖哉若禪</span>  
<span style="margin-left: 1em">宫玄館今昔品題東坡所謂使後來入山者信足而行</span>  
<span style="margin-left: 1em">自然得路其惟志乎故并綴其名於山之下</span>  
<span style="margin-left: 2em"><sub class="note-yuan">顧志云九峯中惟天馬佘山最高玉屏斯下矣崑山又下於玉屏舊志稱干山七十丈薛山九十丈崑山乃二百五十丈又機山最西北云去府二十里細林近東南乃二十五里况竹嶼浮蘇在滄波浩渺中誰能測之故不詳其高下遠近然其概亦畧可見矣</sub></span>  
<span style="margin-left: 1em">九峯董良史曰松之山三十有二而九峯特著在唐宋</span>  
<span style="margin-left: 2em">未之名也始見清氣集品第於凌嵓諸君蓋元多高</span>  
<span style="margin-left: 2em">賢避地搜尋佳山水相與詠歌楊鐵崖云淞之邑帶</span>  
<span style="margin-left: 2em">江枕海聚爲山者皆平疇大陸呀淵疏川突而高鬱</span>  
<span style="margin-left: 2em">而秀青螺九點出没於烟霏空翠中雨晴朝暮一葦</span>  
<span style="margin-left: 2em">可航陶南邨云長谷以東通波以西九山離立如幽</span>  
<span style="margin-left: 2em">人冠帶拱揖狀此九峯所以稱也至牟陵陽云九峯</span>  
<span style="margin-left: 2em">在郡之北層巒叠嶂攢青擁翠相爲蔽虧又一郡風</span>  
<span style="margin-left: 2em">氣攸聚矣</span>  
<span style="margin-left: 2em">董其昌云吾松之山機雲以古賢名爲名鍾賈羅佘</span>  
<span style="margin-left: 2em">以居人姓爲名干山以干將名北簳以竹箭名鳳凰</span>  
<span style="margin-left: 2em">天馬以鳥獸爲名神山原名辰山在諸山之東南次</span>  
<span style="margin-left: 2em">於辰位今作神者訛也大都江山自開闢以來何有</span>  
<span style="margin-left: 2em">名字皆世諦流布相承踵耳詞人挾江山以爲境江</span>  
<span style="margin-left: 2em">山亦以詞人爲境齊魯青不了澄江浄如練是爲山</span>  
<span style="margin-left: 2em">水傳神寫照語也山水亦樂得之</span>  
<span style="margin-left: 2em"><sub class="note-yuan">元晏鐸九峯行三徑重開書屋九峯舊隱人家欲辨武陵春色溪流泛出桃花曲徑沿流上下蒼苔白石磷磷落日惟聞啼鳥空山更少人行國朝楊基九峯山頭白雲飛飛來化爲遊子衣遊子思鄉去不返青天漫漫白日晚悵悵天河水夜夜東南流欲知何處去流向九峯頭</sub></span>  
<span style="margin-left: 1em">鳳凰山在郡城之北圖經云山之鎮曰鳳凰以其據九</span>  
<span style="margin-left: 2em">峯之首延頸舒翼宛若鳳翥故名東枕通波西連玉</span>  
<span style="margin-left: 2em">屏山形修峻循覽其下孤起無附陟半嶺則外山拱</span>  
<span style="margin-left: 2em">揖如奥區焉左有青壁高數十仞如削成其上有虬</span>  
<span style="margin-left: 2em">松壽藤蒼森可愛古來名流多寓隱焉有二泉曰鳳</span>  
<span style="margin-left: 2em">凰曰陸寶故陶九成有丹泉陸寶秘精靈之句山南</span>  
<span style="margin-left: 2em">村民依水而居曰鳳凰山鎮橋<sub class="note-jiao">校：橋字疑衍</sub>曰錦溪鎮有</span>  
<span style="margin-left: 2em">三星廟嘉靖中奉世廟賜徐文貞公福禄壽三星像</span>  
<span style="margin-left: 2em">又慶陽院在山下山之陽有張東海墓東海又作梅</span>  
<span style="margin-left: 2em">居于山麓其陰有俞嘉言山月軒徐文貞梅莊朱應</span>  
<span style="margin-left: 2em">祥點易臺何司理士抑洗石得巉壁建一堂曰拜石</span>  
<span style="margin-left: 2em">陳眉公來儀堂俱稱勝境</span>  
<span style="margin-left: 2em">衛宗武秋聲集云吾郡諸山以杭天目爲祖鳳皇東</span>  
<span style="margin-left: 2em">飛來自虎林虎林有鳳皇山故以雲間爲小鳳先文</span>  
<span style="margin-left: 2em">節詩云小鳳梳翎倚碧天此也或以厙公山當之未</span>  
<span style="margin-left: 2em">足稱矣</span>  
<span style="margin-left: 2em"><sub class="note-yuan">元凌嵓一峯雲氣接蓬萊白石磷磷護碧苔幾向鳳凰池上望不知何日鳳凰來錢惟善岩頭石是桂槎星烟市人家集地靈夜半月明仙仗過天風吹落鳳凰翎</sub></span>  
<span style="margin-left: 2em">錦溪橋<sub class="note-yuan">在鳳山下陶九成詩錦溪橋下水平溪楊柳條長拂岸齊參政寶坊歸幻劫右丞先壟可悲凄漁船桂楫雙雙短酒店茅簷處處低市井荒凉風景異老鴉啼過亂雲西先壟右</sub>○<sub class="note-yuan">公自註寶坊參政張瑄丞徐義</sub></span>  
<span style="margin-left: 2em">竹堂<sub class="note-yuan">宋張文潛耒寄題華亭竹室在鳳凰山下誰道清貧守冷間遶山十萬翠琅玕直應流水深相與不待清風已自寒長伴鳳鳴真自許忽成龍去不終蟠知君何世無知己豈是王郎獨與歡</sub></span>  
<span style="margin-left: 2em">山月軒<sub class="note-yuan">華亭俞嘉言允讀書處陶九成書額貝翔記略云華亭之山有九其最秀者曰鳳凰嘉言之居在鳳凰之麓有屋若干楹蓄書數千卷日諷誦其間夜至四鼓弗能休其勤篤若此或天高氣清海月東出廻視九峯若青芙渠然歷歷可數欣然有得不待假神仙而始覩夫所謂清暉廣寒之府也因名其軒曰山月久之遊京師中進士第擢爲行人將命四方西經太華周流終南太白東抵岱衆謂馳傳千里踰越險阻蒙犯霜露非其所堪而嘉言畧無覉旅無聊之色後爲吉安幕長改辰州泝大江觀匡廬轉浮洞庭窺蒼梧衆謂幕職位下簿書事煩非其所任而嘉言裁決無滯嘯傲自若如在山月軒時也或以爲嘉言遠祖清老嘗有猛虎一聲山月高之句見賞于蘇文忠公軒之得名其以是歟嘉言屬余以言故書以爲記王燧九山有月明如鏡月色山光互輝映君家故業隱山中幾度獨吟秋夜靜夜靜山空月倍明看山對月有餘情一輪艷彩河邊轉數點螺鬟天際青自從來作京華客何處却看山月色鳳凰臺下晚春時石頭城畔凉秋夕新月還同舊月華故鄉回首是天涯但喜人生逢賞事那知明月落誰家知君名紀神仙關桂子含香待攀折行看直舍待花陰未許還山重對月</sub></span>  
<span style="margin-left: 2em">點易臺<sub class="note-yuan">朱應祥讀書處應祥自題云老夫點易臺前坐笑看人間歲月忙落盡薔薇紅玉片筍梢容易過人長</sub></span>  
<span style="margin-left: 2em">鳳凰山莊<sub class="note-yuan">徐文貞公別業有梅花數百株九門自題云九日尊罍何處開鳳岩南下古層臺天甦病骨秋風至客有好懷今雨來把菊謾憑推節序看花猶恨隔蓬萊全生近解莊樗說深爲衰齡幸不才</sub></span>  
<span style="margin-left: 1em">厙公山在鳳山之南周一里高七丈實鳳山之附庸也</span>  
<span style="margin-left: 2em">昔有厙公隱此因名土宜盆盎可栽蘭竹<sub class="note-yuan">陸深詩序云晨登厙公山山形如軸正當鳳喙地理家云丹鳳銜書丹鳳銜書下九霄分明形勝見山椒先秋古樹蒼黃出映日高峯紫翠摇稅地澆花人未老買船載酒路非遥經行更愛清溪曲若個淮南若見招</sub></span>  
<span style="margin-left: 1em">陸寶山本陸氏家山界鳳凰玉屏之間山多土少石而</span>  
<span style="margin-left: 2em">土又美人争取之今夷爲平陸</span>  
<span style="margin-left: 2em"><sub class="note-yuan">凌嵓二峯藏寶樹精神金碧樓臺處處春溪上落花流水遠老翁疑是避秦人錢惟善誰家獲寶此中藏二陸文章耿夜光白石磷磷非高處一溪春霧落紅香</sub></span>  
<span style="margin-left: 1em">佘山舊傳有佘姓者養道於此故名按吳興志亦有佘</span>  
<span style="margin-left: 2em">山上有東漢佘將軍廟或遂指此爲東佘云諸峯中</span>  
<span style="margin-left: 2em">惟佘與天馬稱高而廣倍之兩山連亘招提蘭若隱</span>  
<span style="margin-left: 2em">見其中望之穠郁深秀遠近皆宜其東山勢一轉自</span>  
<span style="margin-left: 2em">爲挹抱遠峯障之尤稱邃密土宜茶有泉名洗心更</span>  
<span style="margin-left: 2em">清洌東山尤多奇石陳眉公頑仙廬在焉其上爲高</span>  
<span style="margin-left: 2em">齋傍種梅花數百株又折而北爲清微亭亭之下麓</span>  
<span style="margin-left: 2em">爲水邊林下苕菷菴水石俱勝可憇也</span>  
<span style="margin-left: 2em">雲間通志云佘山高八十丈周一十八里上有三菴</span>  
<span style="margin-left: 2em">中爲靈峯菴今昭慶慧日兩寺西菴今宣妙寺東菴</span>  
<span style="margin-left: 2em">今普照寺有秀道者塔有月軒有金沙地芥子菴虎</span>  
<span style="margin-left: 2em">樹亭顧志云佘山在盧山東北繇神山塘折而東或</span>  
<span style="margin-left: 2em">自富林八曲以入盡得其勝</span>  
<span style="margin-left: 2em"><sub class="note-yuan">凌嵓三峯高遠翠光濃右列仙宫左梵宫月落軒空人不見野花山鳥自春風錢惟善麟洲鹿苑帶烟霞上有先春日鑄茶愛月不逢聰道者青山無語疆名佘陶宗儀桃源只在人間世三老相逢莫問年一櫂歸來潮正落溪頭好似米家船寶暘於佘山北逾</sub>○<sub class="note-yuan">同邵青溪俞山月張嶺而南訪陳孟剛</sub></span>  
<span style="margin-left: 2em">西菴<sub class="note-yuan">陳律師所居許尚詩早爲儒冠誤齋心學竺乾而今林下塔夜夜戒光圓</sub></span>  
<span style="margin-left: 2em">靈峯地<sub class="note-yuan">皆金沙許尚詩路湧金沙地高人此築菴爲詢林下客妙語與誰參</sub></span>  
<span style="margin-left: 2em">芥子菴<sub class="note-yuan">許尚詩林外三椽建常思憇息時莫教嫌逼窄中有五須彌</sub></span>  
<span style="margin-left: 2em">洗心泉<sub class="note-yuan">孫作銘華亭佘山慧日院之東鳳皇山之西南友人夏士良築別業其地墾辟除治得泉穴舍後汪洋甘潔不竭不溢因即其次爲池名洗心泉曰吾將以是著易徵予銘銘曰鳳之脇蛇之蚹浚靈源發玄腴相有德噫何居沐陶泓濡褐徒招羲昌啓榮圖淬鐵擿續韋觚滌遐覽泣墨朱滋吾德神吾書匪斯泉乎</sub></span>  
<span style="margin-left: 2em">白石山房<sub class="note-yuan">章比部憲文別業嘗自題云旋種松蘿護石闌漫攜棋局傍檀欒春深燕子尋巢壘</sub></span>  
<span style="margin-left: 2em">月落漁郎捲釣竿懶性恰宜東佘隱移文休作北山看卧遊莫笑希宗炳蚤識風麈<sub class="note-jiao">校：麈字當塵字之訛今改]行路難</sub></span>  
<span style="margin-left: 2em">苕菷菴<sub class="note-yuan">在頑仙廬西董其昌詩云仲舉無心除一室盧鴻有句寫千峯欲參苕帚閑中意九點秋山雨後容</sub></span>  
<span style="margin-left: 1em">細林山在盧山南舊名神山梁簡文帝有銘序曰神山</span>  
<span style="margin-left: 2em">本名秀林山或稱辰山在華亭西北二十餘里僻居</span>  
<span style="margin-left: 2em">一方雖非巨麗未經標品而自古神仙往往托跡寔</span>  
<span style="margin-left: 2em">震旦之靈阜也余以機暇結駕游衍覽兹佳勝睠焉</span>  
<span style="margin-left: 2em">有懷乃作銘曰閣號天井山稱地維碧雞金馬越瀆</span>  
<span style="margin-left: 2em">梁池懷靈藴德孕寶含奇此亦仙岫英名遠攡昔有</span>  
<span style="margin-left: 2em">鶯窟不燒浄土邁彼高蹤搆兹法宇引葉成帷即樹</span>  
<span style="margin-left: 2em">爲柱石砌危横崕堦斜竪白巘途遠丹源路深長林</span>  
<span style="margin-left: 2em">萬頃偉木千尋竹牕看博松間聽琴捐芬蕩累散賞</span>  
<span style="margin-left: 2em">娱襟大通元年歲次庚午春三月十五日題寫則兹</span>  
<span style="margin-left: 2em">山之爲秀林舊矣按志唐天寶間易稱細林山元時</span>  
<span style="margin-left: 2em">仙人彭素雲遍遊名山至武當遇張真人集雲水三</span>  
<span style="margin-left: 2em">千人於紫霄宫素雲執厨汲水苦行三年得授接神</span>  
<span style="margin-left: 2em">鍊氣之旨洪武十四年至此居焉二十七年八月旦</span>  
<span style="margin-left: 2em">起沐浴更衣趺坐而逝七日顔色如生又舊有神鼉</span>  
<span style="margin-left: 2em">仙館四字是純陽呂仙書筆法奇異嘉靖間爲太守</span>  
<span style="margin-left: 2em">吳黃州取去今榜蓋臨本山有元旌義士夏椿墓上</span>  
<span style="margin-left: 2em">有石碑有素翁仙塚有石洞雲出其中有溪潭澄澈</span>  
<span style="margin-left: 2em">如鑑有石井有石灘漾沙日光照之點點如金有崇</span>
