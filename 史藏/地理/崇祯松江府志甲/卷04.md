## 崇祯松江府志卷之四　山

<span style="margin-left: 3em">山</span>  
<span style="margin-left: 1em">东南龙脉遇海而止元气蟠演发为柔中之刚山不能</span>  
<span style="margin-left: 1em">胜水而拔地卓起未肯相牵相连强为诡随附丽其骨</span>  
<span style="margin-left: 1em">力与龙门砥柱同人才间生率多品胜厥惟肖哉若禅</span>  
<span style="margin-left: 1em">宫玄馆今昔品题东坡所谓使后来入山者信足而行</span>  
<span style="margin-left: 1em">自然得路其惟志乎故并缀其名于山之下</span>  
<span style="margin-left: 2em"><sub class="note-yuan">顾志云九峰中惟天马佘山最高玉屏斯下矣昆山又下于玉屏旧志称干山七十丈薛山九十丈昆山乃二百五十丈又机山最西北云去府二十里细林近东南乃二十五里况竹屿浮苏在沧波浩渺中谁能测之故不详其高下远近然其概亦畧可见矣</sub></span>  
<span style="margin-left: 1em">九峰董良史曰松之山三十有二而九峰特著在唐宋</span>  
<span style="margin-left: 2em">未之名也始见清气集品第于凌嵓诸君盖元多高</span>  
<span style="margin-left: 2em">贤避地搜寻佳山水相与咏歌杨铁崖云淞之邑带</span>  
<span style="margin-left: 2em">江枕海聚为山者皆平畴大陆呀渊疏川突而高郁</span>  
<span style="margin-left: 2em">而秀青螺九点出没于烟霏空翠中雨晴朝暮一苇</span>  
<span style="margin-left: 2em">可航陶南邨云长谷以东通波以西九山离立如幽</span>  
<span style="margin-left: 2em">人冠带拱揖状此九峰所以称也至牟陵阳云九峰</span>  
<span style="margin-left: 2em">在郡之北层峦叠嶂攒青拥翠相为蔽亏又一郡风</span>  
<span style="margin-left: 2em">气攸聚矣</span>  
<span style="margin-left: 2em">董其昌云吾松之山机云以古贤名为名钟贾罗佘</span>  
<span style="margin-left: 2em">以居人姓为名干山以干将名北簳以竹箭名凤凰</span>  
<span style="margin-left: 2em">天马以鸟兽为名神山原名辰山在诸山之东南次</span>  
<span style="margin-left: 2em">于辰位今作神者讹也大都江山自开辟以来何有</span>  
<span style="margin-left: 2em">名字皆世谛流布相承踵耳词人挟江山以为境江</span>  
<span style="margin-left: 2em">山亦以词人为境齐鲁青不了澄江浄如练是为山</span>  
<span style="margin-left: 2em">水传神写照语也山水亦乐得之</span>  
<span style="margin-left: 2em"><sub class="note-yuan">元晏铎九峰行三径重开书屋九峰旧隐人家欲辨武陵春色溪流泛出桃花曲径沿流上下苍苔白石磷磷落日惟闻啼鸟空山更少人行国朝杨基九峰山头白云飞飞来化为游子衣游子思乡去不返青天漫漫白日晚怅怅天河水夜夜东南流欲知何处去流向九峰头</sub></span>  
<span style="margin-left: 1em">凤凰山在郡城之北图经云山之镇曰凤凰以其据九</span>  
<span style="margin-left: 2em">峰之首延颈舒翼宛若凤翥故名东枕通波西连玉</span>  
<span style="margin-left: 2em">屏山形修峻循览其下孤起无附陟半岭则外山拱</span>  
<span style="margin-left: 2em">揖如奥区焉左有青壁高数十仞如削成其上有虬</span>  
<span style="margin-left: 2em">松寿藤苍森可爱古来名流多寓隐焉有二泉曰凤</span>  
<span style="margin-left: 2em">凰曰陆宝故陶九成有丹泉陆宝秘精灵之句山南</span>  
<span style="margin-left: 2em">村民依水而居曰凤凰山镇桥<sub class="note-jiao">校：橋字疑衍</sub>曰锦溪镇有</span>  
<span style="margin-left: 2em">三星庙嘉靖中奉世庙赐徐文贞公福禄寿三星像</span>  
<span style="margin-left: 2em">又庆阳院在山下山之阳有张东海墓东海又作梅</span>  
<span style="margin-left: 2em">居于山麓其阴有俞嘉言山月轩徐文贞梅庄朱应</span>  
<span style="margin-left: 2em">祥点易台何司理士抑洗石得巉壁建一堂曰拜石</span>  
<span style="margin-left: 2em">陈眉公来仪堂俱称胜境</span>  
<span style="margin-left: 2em">卫宗武秋声集云吾郡诸山以杭天目为祖凤皇东</span>  
<span style="margin-left: 2em">飞来自虎林虎林有凤皇山故以云间为小凤先文</span>  
<span style="margin-left: 2em">节诗云小凤梳翎倚碧天此也或以厍公山当之未</span>  
<span style="margin-left: 2em">足称矣</span>  
<span style="margin-left: 2em"><sub class="note-yuan">元凌嵓一峰云气接蓬莱白石磷磷护碧苔几向凤凰池上望不知何日凤凰来钱惟善岩头石是桂槎星烟市人家集地灵夜半月明仙仗过天风吹落凤凰翎</sub></span>  
<span style="margin-left: 2em">锦溪桥<sub class="note-yuan">在凤山下陶九成诗锦溪桥下水平溪杨柳条长拂岸齐参政宝坊归幻劫右丞先垄可悲凄渔船桂楫双双短酒店茅簷处处低市井荒凉风景异老鸦啼过乱云西先垄右</sub>○<sub class="note-yuan">公自注宝坊参政张瑄丞徐义</sub></span>  
<span style="margin-left: 2em">竹堂<sub class="note-yuan">宋张文潜耒寄题华亭竹室在凤凰山下谁道清贫守冷间绕山十万翠琅玕直应流水深相与不待清风已自寒长伴凤鸣真自许忽成龙去不终蟠知君何世无知己岂是王郎独与欢</sub></span>  
<span style="margin-left: 2em">山月轩<sub class="note-yuan">华亭俞嘉言允读书处陶九成书额贝翔记略云华亭之山有九其最秀者曰凤凰嘉言之居在凤凰之麓有屋若干楹蓄书数千卷日讽诵其间夜至四鼓弗能休其勤笃若此或天高气清海月东出廻视九峰若青芙渠然历历可数欣然有得不待假神仙而始覩夫所谓清晖广寒之府也因名其轩曰山月久之游京师中进士第擢为行人将命四方西经太华周流终南太白东抵岱众谓驰传千里逾越险阻蒙犯霜露非其所堪而嘉言畧无覉旅无聊之色后为吉安幕长改辰州溯大江观匡庐转浮洞庭窥苍梧众谓幕职位下簿书事烦非其所任而嘉言裁决无滞啸傲自若如在山月轩时也或以为嘉言远祖清老尝有猛虎一声山月高之句见赏于苏文忠公轩之得名其以是欤嘉言属余以言故书以为记王燧九山有月明如镜月色山光互辉映君家故业隐山中几度独吟秋夜静夜静山空月倍明看山对月有余情一轮艳彩河边转数点螺鬟天际青自从来作京华客何处却看山月色凤凰台下晚春时石头城畔凉秋夕新月还同旧月华故乡回首是天涯但喜人生逢赏事那知明月落谁家知君名纪神仙关桂子含香待攀折行看直舍待花阴未许还山重对月</sub></span>  
<span style="margin-left: 2em">点易台<sub class="note-yuan">朱应祥读书处应祥自题云老夫点易台前坐笑看人间岁月忙落尽蔷薇红玉片笋梢容易过人长</sub></span>  
<span style="margin-left: 2em">凤凰山庄<sub class="note-yuan">徐文贞公别业有梅花数百株九门自题云九日尊罍何处开凤岩南下古层台天甦病骨秋风至客有好怀今雨来把菊谩凭推节序看花犹恨隔蓬莱全生近解庄樗说深为衰龄幸不才</sub></span>  
<span style="margin-left: 1em">厍公山在凤山之南周一里高七丈实凤山之附庸也</span>  
<span style="margin-left: 2em">昔有厍公隐此因名土宜盆盎可栽兰竹<sub class="note-yuan">陆深诗序云晨登厍公山山形如轴正当凤喙地理家云丹凤衔书丹凤衔书下九霄分明形胜见山椒先秋古树苍黄出映日高峰紫翠摇税地浇花人未老买船载酒路非遥经行更爱清溪曲若个淮南若见招</sub></span>  
<span style="margin-left: 1em">陆宝山本陆氏家山界凤凰玉屏之间山多土少石而</span>  
<span style="margin-left: 2em">土又美人争取之今夷为平陆</span>  
<span style="margin-left: 2em"><sub class="note-yuan">凌嵓二峰藏宝树精神金碧楼台处处春溪上落花流水远老翁疑是避秦人钱惟善谁家获宝此中藏二陆文章耿夜光白石磷磷非高处一溪春雾落红香</sub></span>  
<span style="margin-left: 1em">佘山旧传有佘姓者养道于此故名按吴兴志亦有佘</span>  
<span style="margin-left: 2em">山上有东汉佘将军庙或遂指此为东佘云诸峰中</span>  
<span style="margin-left: 2em">惟佘与天马称高而广倍之两山连亘招提兰若隐</span>  
<span style="margin-left: 2em">见其中望之秾郁深秀远近皆宜其东山势一转自</span>  
<span style="margin-left: 2em">为挹抱远峰障之尤称邃密土宜茶有泉名洗心更</span>  
<span style="margin-left: 2em">清洌东山尤多奇石陈眉公顽仙庐在焉其上为高</span>  
<span style="margin-left: 2em">斋傍种梅花数百株又折而北为清微亭亭之下麓</span>  
<span style="margin-left: 2em">为水边林下苕菷庵水石俱胜可憇也</span>  
<span style="margin-left: 2em">云间通志云佘山高八十丈周一十八里上有三庵</span>  
<span style="margin-left: 2em">中为灵峰庵今昭庆慧日两寺西庵今宣妙寺东庵</span>  
<span style="margin-left: 2em">今普照寺有秀道者塔有月轩有金沙地芥子庵虎</span>  
<span style="margin-left: 2em">树亭顾志云佘山在卢山东北繇神山塘折而东或</span>  
<span style="margin-left: 2em">自富林八曲以入尽得其胜</span>  
<span style="margin-left: 2em"><sub class="note-yuan">凌嵓三峰高远翠光浓右列仙宫左梵宫月落轩空人不见野花山鸟自春风钱惟善麟洲鹿苑带烟霞上有先春日铸茶爱月不逢聪道者青山无语疆名佘陶宗仪桃源只在人间世三老相逢莫问年一櫂归来潮正落溪头好似米家船宝旸于佘山北逾</sub>○<sub class="note-yuan">同邵青溪俞山月张岭而南访陈孟刚</sub></span>  
<span style="margin-left: 2em">西庵<sub class="note-yuan">陈律师所居许尚诗早为儒冠误斋心学竺乾而今林下塔夜夜戒光圆</sub></span>  
<span style="margin-left: 2em">灵峰地<sub class="note-yuan">皆金沙许尚诗路涌金沙地高人此筑庵为询林下客妙语与谁参</sub></span>  
<span style="margin-left: 2em">芥子庵<sub class="note-yuan">许尚诗林外三椽建常思憇息时莫教嫌逼窄中有五须弥</sub></span>  
<span style="margin-left: 2em">洗心泉<sub class="note-yuan">孙作铭华亭佘山慧日院之东凤皇山之西南友人夏士良筑别业其地垦辟除治得泉穴舍后汪洋甘洁不竭不溢因即其次为池名洗心泉曰吾将以是著易征予铭铭曰凤之脇蛇之蚹浚灵源发玄腴相有德噫何居沐陶泓濡褐徒招羲昌启荣图淬铁擿续韦觚涤遐览泣墨朱滋吾德神吾书匪斯泉乎</sub></span>  
<span style="margin-left: 2em">白石山房<sub class="note-yuan">章比部宪文别业尝自题云旋种松萝护石阑漫携棋局傍檀栾春深燕子寻巢垒</sub></span>  
<span style="margin-left: 2em">月落渔郎卷钓竿懒性恰宜东佘隐移文休作北山看卧游莫笑希宗炳蚤识风麈<sub class="note-jiao">校：麈字當塵字之訛今改]行路難</sub></span>  
<span style="margin-left: 2em">苕菷庵<sub class="note-yuan">在顽仙庐西董其昌诗云仲举无心除一室卢鸿有句写千峰欲参苕帚闲中意九点秋山雨后容</sub></span>  
<span style="margin-left: 1em">细林山在卢山南旧名神山梁简文帝有铭序曰神山</span>  
<span style="margin-left: 2em">本名秀林山或称辰山在华亭西北二十余里僻居</span>  
<span style="margin-left: 2em">一方虽非巨丽未经标品而自古神仙往往托迹寔</span>  
<span style="margin-left: 2em">震旦之灵阜也余以机暇结驾游衍览兹佳胜睠焉</span>  
<span style="margin-left: 2em">有怀乃作铭曰阁号天井山称地维碧鸡金马越渎</span>  
<span style="margin-left: 2em">梁池怀灵蕴德孕宝含奇此亦仙岫英名远攡昔有</span>  
<span style="margin-left: 2em">莺窟不烧浄土迈彼高踪搆兹法宇引叶成帷即树</span>  
<span style="margin-left: 2em">为柱石砌危横崕堦斜竖白𪩘途远丹源路深长林</span>  
<span style="margin-left: 2em">万顷伟木千寻竹牕看博松间听琴捐芬荡累散赏</span>

<span style="margin-left: 2em">炼气之旨洪武十四年至此居焉二十七年八月旦</span>
