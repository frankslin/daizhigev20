## 崇禎松江府志卷之四十　人物五（國朝賢達）

<span style="margin-left: 3em">國朝賢達五</span>  
<span style="margin-left: 1em">陸樹聲字與吉華亭人家世業農弱冠始從里師嘉靖</span>  
<span style="margin-left: 1em">庚子舉于鄉辛丑舉會試第一選庶吉士授編修庚戌</span>  
<span style="margin-left: 1em">廷試分宜謀寘私人上第樹聲掌卷故混之分宜猝無</span>  
<span style="margin-left: 1em">所得聲色俱厲不爲動事竣請告還里丁外艱服久除</span>  
<span style="margin-left: 1em">不出即家拜南京國子監司業未幾請告歸辛酉起諭</span>  
<span style="margin-left: 1em">德掌院篆乙丑進太常卿管南京國子監祭酒著汲古</span>  
<span style="margin-left: 1em">叢語及訓條十二篇以式士進吏部右侍郎引疾不就</span>  
<span style="margin-left: 1em">疏辭者再竟不出尋復起原官兼學士教習庶吉士抵</span>  
<span style="margin-left: 1em">淮復告歸壬申廷推內閣即家拜禮部尚書疏辭不允</span>  
<span style="margin-left: 1em">始勉赴陛見畢江陵首謁樹聲接對殊簡還報謁引席</span>  
<span style="margin-left: 1em">正南不少假尺寸時已有歸志疏上江陵以微言妮之</span>  
<span style="margin-left: 1em">樹聲笑曰一史官二十年始出山豈爲樹桃李希揆席</span>  
<span style="margin-left: 1em">耶弟中丞樹德曰兄即倦遊宜爲孺子恩澤地答曰吾</span>  
<span style="margin-left: 1em">得首丘有兒行歌負薪亦任之矣凡五疏得賜告乘傳</span>  
<span style="margin-left: 1em">歸瀕行疏陳十事尤觸時忌江陵詣別踞床見之抗手</span>  
<span style="margin-left: 1em">謝曰病甚負公推轂奈何江陵敗臺省交疏推薦無虛</span>  
<span style="margin-left: 1em">歲高卧彌堅戊子以八十　上詔有司存問九十再遣</span>  
<span style="margin-left: 1em">中書壬寅　皇太子立遣儀部郎凡存問者三時九十</span>  
<span style="margin-left: 1em">五歲矣遣孫景元陳謝特賜入監讀書乙巳九十七無</span>  
<span style="margin-left: 1em">疾薨兩臺以訃聞詔所司治葬賜祭三壇贈太子太保</span>  
<span style="margin-left: 1em">謚文定有司建坊曰百歲名臣特祠龍潭寺之左生平</span>  
<span style="margin-left: 1em">宦業鄉行始終以敦大體重清議堅晚節爲第一義豐</span>  
<span style="margin-left: 1em">頷竦肩長七尺有咫目靜深含光內藏對日不眩每入</span>  
<span style="margin-left: 1em">闕昂立班中姿表特異　穆廟登極久趣不赴趙文肅</span>  
<span style="margin-left: 1em">寄聲云我輩豈敢以機務煩公第欲　主上一見丰采</span>  
<span style="margin-left: 1em">知先朝培養得如此偉人耳垂老家居惟惓惓吏治士</span>  
<span style="margin-left: 1em">風民俗吏弊語不及私遇水旱必移書議捐議賑民藉</span>  
<span style="margin-left: 1em">稍甦文章本理學尤邃于易稱說古成敗得失及本朝</span>  
<span style="margin-left: 1em">掌故毫髮不爽所雜著詩文若干卷藏于家父兄子弟</span>  
<span style="margin-left: 1em">皆以遠聲利樂恬退爲法子彦章己丑進士官行人乞</span>  
<span style="margin-left: 1em">終養特予半俸親殁後爲文誓墓不出屢薦起光禄終</span>  
<span style="margin-left: 1em">南京刑部侍郎卒年六十五介石之節爲時所重云</span>  
<span style="margin-left: 1em">陸樹德字與成文定公弟嘉靖乙丑進士司理嚴州精</span>  
<span style="margin-left: 1em">明綜覈不喜爲煩劇奉檄按武義令夜行有所居間叱</span>  
<span style="margin-left: 1em">使去盡法無貸龎御史尚鵬于屬吏鮮當意至樹德則</span>  
<span style="margin-left: 1em">曰廉士廉士陞刑部主事改禮科給事中　莊皇帝每</span>  
<span style="margin-left: 1em">朝及經筵默不發一語疏言上下交爲泰非與公卿輔</span>  
<span style="margin-left: 1em">弼相論難何以劘君德酬萬幾又條議諸邊計甚析時</span>  
<span style="margin-left: 2em">上不豫中璫有請開戒壇爲　上造福利者復抗疏</span>  
<span style="margin-left: 1em">諫爲停止無何　上晏駕時中貴馮保横甚新鄭入相</span>  
<span style="margin-left: 1em">決策去之言路各有疏發其奸保遂逐新鄭併齮諸言</span>  
<span style="margin-left: 1em">者久之僅移尚寶卿擢應天府丞尋改太常少卿已進</span>  
<span style="margin-left: 1em">太僕卿擢右僉都御史出撫山東時保已逐竄至則請</span>  
<span style="margin-left: 1em">裁募兵諸費蘇里甲戒苛罰俱報可德藩奪民佃白雲</span>  
<span style="margin-left: 1em">湖力與中貴人争執不聽遂移病歸歸與文定嘗婆娑</span>  
<span style="margin-left: 1em">蕭寺偕名僧韻士談說娓娓啜茗小飲以爲常先文定</span>  
<span style="margin-left: 1em">數年卒子彦禎萬曆乙未進士官南京吏部考功主事</span>  
<span style="margin-left: 1em">廓落有才識惜未究其用孫景朋舉萬曆癸卯鄉薦</span>  
<span style="margin-left: 1em">蔡懋昭字允德上海人舉嘉靖庚子鄉試署教嘉善前</span>  
<span style="margin-left: 1em">令以墨敗剋扣戍伍金致譁而去乃諉罪庠士昭立爲</span>  
<span style="margin-left: 1em">辨雪李太史自華袁職方黃等是也擢知新河縣流賊</span>  
<span style="margin-left: 1em">出没乃從容畫方畧賊黨解散遷守趙州大橋稅歲千</span>  
<span style="margin-left: 1em">金例充州署公用昭申請撫院分償積逋載入會計册</span>  
<span style="margin-left: 1em">冢宰胡松稱其賢已擬內召而太守陳燁齮齕之竟拂</span>  
<span style="margin-left: 1em">衣歸適有西粤顔御史思賢過趙父老攀轅泣訴前州</span>  
<span style="margin-left: 1em">守治狀及去官之故顔抗章首舉之主爵楊襄毅即家</span>  
<span style="margin-left: 1em">起桂陽州旋同知懷慶平役均田加意振刷丁外艱補</span>  
<span style="margin-left: 1em">肇慶海酋何平餘黨許恩者築城陽江沙島東連惠州</span>  
<span style="margin-left: 1em">林道乾遥相犄角昭用間使恩自剪其翼示以恩信恩</span>  
<span style="margin-left: 1em">降一日忽檄楊參戎勒兵馳疾列陣恩之外營恩皇遽</span>  
<span style="margin-left: 1em">出迎入坐恩幄楊股栗不能語昭好言呼恩令解散諸</span>  
<span style="margin-left: 1em">黨凡六千餘人遂命將校急唤其城率恩入謁制府婉</span>  
<span style="margin-left: 1em">爲請命赦不誅授與名色處之陽江內地積寇既平乃</span>  
<span style="margin-left: 1em">率衆深入搜捕徭賊林道乾失援亦詣軍門降沈公思</span>  
<span style="margin-left: 1em">孝以忠諫戍神電衛昭迎至陽江勅傳授餐絕不以江</span>  
<span style="margin-left: 1em">陵介意拜思州知府建議廣其城郡苦無井渫民間輒</span>  
<span style="margin-left: 1em">從二三十里外取水一日肅衣冠禱天四門各穿一井</span>  
<span style="margin-left: 1em">水旋湧民稱爲蔡公井鄒公元標時戍都匀昭遣使慰</span>  
<span style="margin-left: 1em">勞一如沈公丙戌致仕歸思民肖像祀之疾病禱之即</span>  
<span style="margin-left: 1em">愈歷官凡三十年環堵蕭然至老衣粗食糲或不能舉</span>  
<span style="margin-left: 1em">火年届九十而殁二子長逢辰以貢爲州別駕清介不</span>  
<span style="margin-left: 1em">愧家聲</span>  
<span style="margin-left: 1em">范惟一字於中文正公十六世孫世家吳閶父北溪始</span>  
<span style="margin-left: 1em">遷松之泗涇食貧授經朱太史大韶出其門下成嘉靖</span>  
<span style="margin-left: 1em">辛丑進士知鈞州擢丞濟南轉虞部僉憲湖廣分部荆</span>  
<span style="margin-left: 1em">西捕治上豪一方懾息潛沔堤潰漂溺廬舍下令弛徵</span>  
<span style="margin-left: 1em">發粟賑貧者再擢山東參議已督兩浙學政旋陞按察</span>  
<span style="margin-left: 1em">晉江西布政遷南太僕乞歸留意著述季子允觀當唐</span>  
<span style="margin-left: 1em">文恪困諸生時慨爲助貲入成均隨舉丙戌狀元人高</span>  
<span style="margin-left: 1em">其誼惟一孫必試舉萬曆戊午弟惟丞嘉靖己未進士</span>  
<span style="margin-left: 1em">終光禄少卿丕長子允謙舉隆慶庚午次允臨乙未進</span>  
<span style="margin-left: 1em">士雲南學憲</span>  
<span style="margin-left: 1em">唐志大字子迪華亭人嘉靖辛丑進士將就選念其母</span>  
<span style="margin-left: 1em">垂老又獨子求南曹以便養親授南行人司副旋疏乞</span>  
<span style="margin-left: 1em">終養會倭寇起聞吳興地僻奉母居焉母卒護喪冒兵</span>  
<span style="margin-left: 1em">刃歸葬里中復趣還吳興遂病不起其殁也無以爲殮</span>  
<span style="margin-left: 1em">家人無以爲食欲歸郡城無以爲家聞者悲之所著有</span>  
<span style="margin-left: 1em">僑居賦及　高廟聖政記</span>  
<span style="margin-left: 1em">張鶚翼字習之中嘉靖戊子辛丑科進士授兵部職方</span>  
<span style="margin-left: 1em">司主事守山海關丙午改吏部稽勳司主事簡別進退</span>  
<span style="margin-left: 1em">一依公議歷驗封考功爲文選郎中歲終擢太常少卿</span>  
<span style="margin-left: 1em">提督四夷館時宰臣用事久諸附麗者率引伺津要乃</span>  
<span style="margin-left: 1em">鶚翼力請南得通政司右通政賊師尚詔起淮蔡留都</span>  
<span style="margin-left: 1em">戒嚴於是分督通濟門有議以城外竹木宜徙且焚者</span>  
<span style="margin-left: 1em">言根本重地不宜以小寇先自擾示之弱尋遷都察院</span>  
<span style="margin-left: 1em">右僉都御史巡撫貴州便道過海上時寇薄城下故留</span>  
<span style="margin-left: 1em">以係人心日夕圖扞寇計寇合長圍數重乘毁堞幾入</span>  
<span style="margin-left: 1em">撤民扉爲栅且戰且修復出粟以廪登陴者踰月寇退</span>  
<span style="margin-left: 1em">丙辰以星變免歸歸葺故廬日邀故人觴詠嘗愍民瘵</span>  
<span style="margin-left: 1em">于兵賦枯魚歎黃丞行以諷切當道疾亟猶口占授子</span>  
<span style="margin-left: 1em">弟答郡守論民瘼書引己疾爲喻蓋憂時之心無壯老</span>  
<span style="margin-left: 1em">一也所著有須野集易說辯訛孫泰階中萬曆己未進</span>  
<span style="margin-left: 1em">士歷官温處道</span>  
<span style="margin-left: 1em">張承憲字監先華亭人嘉靖甲辰進士爲行人賜一品</span>  
<span style="margin-left: 1em">服使朝鮮又兩使親藩却其贈遺遷南京吏科給事中</span>  
<span style="margin-left: 1em">時邊吏請聽北虜以牛羊易米豆上疏曰是益驕虜而</span>  
<span style="margin-left: 1em">示我弱且虜何厭之有今姑欲緩寇捐民所食使食我</span>  
<span style="margin-left: 1em">逋逃後復有請一不副寇猶故也條五不可狀得不果</span>  
<span style="margin-left: 1em">易又疏言外計宜止科斂禁賄賂嚴舉主之罰重部院</span>  
<span style="margin-left: 1em">之臣又疏久任以責成功撫臣不宜數易詔皆納焉倭</span>  
<span style="margin-left: 1em">寇東南請勅兵部發兵往援度寇之衝設海防參將定</span>  
<span style="margin-left: 1em">軍令計兵食爲戰守備又請勅浙直撫臣招還其民之</span>  
<span style="margin-left: 1em">從寇及嚴禁其導寇者又請薄賦稅練鄉兵䘏被寇之</span>  
<span style="margin-left: 1em">民丁艱服除改北乞歸遷葬卒年六十七所著有端諒</span>  
<span style="margin-left: 1em">堂集</span>  
<span style="margin-left: 1em">楊允繩字翼少華亭人嘉靖甲辰進士以行人擢兵科</span>  
<span style="margin-left: 1em">給事中疏論閣部大臣受餽遺不貲蓋指嵩相言也已</span>  
<span style="margin-left: 1em">巡視光禄有寺丞胡膏爲嚴相客允繩劾其虛冒物料</span>  
<span style="margin-left: 1em">貪鄙不法膏乃反誣允繩譏訕嵩陰中之　上震怒</span>  
<span style="margin-left: 1em">廷杖下錦衣獄比駡父律擬絞在繫五年會星隕如雨</span>  
<span style="margin-left: 1em">占者以爲咎在臣下不忠遂列名上請行刑以應天變</span>  
<span style="margin-left: 1em">庚申十月朔遂付西市死刑時黑霧四塞朝野皆以爲</span>  
<span style="margin-left: 1em">冤自遇害後三年而嚴氏誅先是允繩居里有郡佐峻</span>  
<span style="margin-left: 1em">行敲朴遺書貸其榎檚曰家有悍奴請治之與民分痛</span>  
<span style="margin-left: 1em">郡邑畏之　穆廟登極贈奉政大夫光禄寺少卿論祭</span>  
<span style="margin-left: 1em">天啟中賜謚忠恪廕一子</span>  
<span style="margin-left: 1em">彭應麟字泰符華亭人嘉靖甲辰進士知樂清縣會中</span>  
<span style="margin-left: 1em">丞檄之勞師心計手籌咄嗟立辦吏士數百千人竟日</span>  
<span style="margin-left: 1em">夕無譁者擢南刑曹出守邵武內制山賊外禦倭奴規</span>  
<span style="margin-left: 1em">條理舉以病致政歸應麟未第時友人蒼頭持蓋立倉</span>  
<span style="margin-left: 1em">卒自外至觸兩齒落友人方駭懼應麟絕不介意徐曰</span>  
<span style="margin-left: 1em">此吾不慎所致赴試南都館人有少婦挑之遂移館舍</span>  
<span style="margin-left: 1em">以避子汝讓見文學傳中</span>  
<span style="margin-left: 1em">宋賢字及甫嘉靖甲辰進士令新昌民有稅浮于田或</span>  
<span style="margin-left: 1em">有田無稅者賢身履畝手握算宿弊盡袪又爲汰侈費</span>  
<span style="margin-left: 1em">去冗役塞東溪以禦潦濬西溪以備旱歲連大稔士民</span>  
<span style="margin-left: 1em">相與祠諸學宫徵拜御史按甘肅前後上十七疏虜嘗</span>  
<span style="margin-left: 1em">窺莊浪不克入而去兼督學政得張問仁胡執禮於諸</span>  
<span style="margin-left: 1em">生中繼按四川蜀世子請名以金饋却之丁父憂歸哭</span>  
<span style="margin-left: 1em">過哀喪明家居嘗濬錢家壩以便民買田三百畝贍族</span>  
<span style="margin-left: 1em">胡公撫吳首謁賢賢陳民隱數事語不及私年七十五</span>  
<span style="margin-left: 1em">卒載浙江名宦</span>  
<span style="margin-left: 1em">王會字子嘉七寶里人嘉靖甲辰成進士授屯田主事</span>
