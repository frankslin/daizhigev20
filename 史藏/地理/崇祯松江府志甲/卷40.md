## 崇祯松江府志卷之四十　人物五（国朝贤达）

<span style="margin-left: 3em">国朝贤达五</span>  
<span style="margin-left: 1em">陆树声字与吉华亭人家世业农弱冠始从里师嘉靖</span>  
<span style="margin-left: 1em">庚子举于乡辛丑举会试第一选庶吉士授编修庚戌</span>  
<span style="margin-left: 1em">廷试分宜谋寘私人上第树声掌卷故混之分宜猝无</span>  
<span style="margin-left: 1em">所得声色俱厉不为动事竣请告还里丁外艰服久除</span>  
<span style="margin-left: 1em">不出即家拜南京国子监司业未几请告归辛酉起谕</span>  
<span style="margin-left: 1em">德掌院篆乙丑进太常卿管南京国子监祭酒著汲古</span>  
<span style="margin-left: 1em">丛语及训条十二篇以式士进吏部右侍郎引疾不就</span>  
<span style="margin-left: 1em">疏辞者再竟不出寻复起原官兼学士教习庶吉士抵</span>  
<span style="margin-left: 1em">淮复告归壬申廷推内阁即家拜礼部尚书疏辞不允</span>  
<span style="margin-left: 1em">始勉赴陛见毕江陵首谒树声接对殊简还报谒引席</span>  
<span style="margin-left: 1em">正南不少假尺寸时已有归志疏上江陵以微言妮之</span>  
<span style="margin-left: 1em">树声笑曰一史官二十年始出山岂为树桃李希揆席</span>  
<span style="margin-left: 1em">耶弟中丞树德曰兄即倦游宜为孺子恩泽地答曰吾</span>  
<span style="margin-left: 1em">得首丘有儿行歌负薪亦任之矣凡五疏得赐告乘传</span>  
<span style="margin-left: 1em">归濒行疏陈十事尤触时忌江陵诣别踞床见之抗手</span>  
<span style="margin-left: 1em">谢曰病甚负公推毂奈何江陵败台省交疏推荐无虚</span>  
<span style="margin-left: 1em">岁高卧弥坚戊子以八十　上诏有司存问九十再遣</span>  
<span style="margin-left: 1em">中书壬寅　皇太子立遣仪部郎凡存问者三时九十</span>  
<span style="margin-left: 1em">五岁矣遣孙景元陈谢特赐入监读书乙巳九十七无</span>  
<span style="margin-left: 1em">疾薨两台以讣闻诏所司治葬赐祭三坛赠太子太保</span>  
<span style="margin-left: 1em">谥文定有司建坊曰百岁名臣特祠龙潭寺之左生平</span>  
<span style="margin-left: 1em">宦业乡行始终以敦大体重清议坚晚节为第一义丰</span>  
<span style="margin-left: 1em">颔竦肩长七尺有咫目静深含光内藏对日不眩每入</span>  
<span style="margin-left: 1em">阙昂立班中姿表特异　穆庙登极久趣不赴赵文肃</span>  
<span style="margin-left: 1em">寄声云我辈岂敢以机务烦公第欲　主上一见丰采</span>  
<span style="margin-left: 1em">知先朝培养得如此伟人耳垂老家居惟惓惓吏治士</span>  
<span style="margin-left: 1em">风民俗吏弊语不及私遇水旱必移书议捐议赈民藉</span>  
<span style="margin-left: 1em">稍甦文章本理学尤邃于易称说古成败得失及本朝</span>  
<span style="margin-left: 1em">掌故毫发不爽所杂著诗文若干卷藏于家父兄子弟</span>  
<span style="margin-left: 1em">皆以远声利乐恬退为法子彦章己丑进士官行人乞</span>  
<span style="margin-left: 1em">终养特予半俸亲殁后为文誓墓不出屡荐起光禄终</span>  
<span style="margin-left: 1em">南京刑部侍郎卒年六十五介石之节为时所重云</span>  
<span style="margin-left: 1em">陆树德字与成文定公弟嘉靖乙丑进士司理严州精</span>  
<span style="margin-left: 1em">明综核不喜为烦剧奉檄按武义令夜行有所居间叱</span>  
<span style="margin-left: 1em">使去尽法无贷厐御史尚鹏于属吏鲜当意至树德则</span>  
<span style="margin-left: 1em">曰廉士廉士升刑部主事改礼科给事中　庄皇帝每</span>  
<span style="margin-left: 1em">朝及经筵默不发一语疏言上下交为泰非与公卿辅</span>  
<span style="margin-left: 1em">弼相论难何以劘君德酬万几又条议诸边计甚析时</span>  
<span style="margin-left: 2em">上不豫中珰有请开戒坛为　上造福利者复抗疏</span>  
<span style="margin-left: 1em">谏为停止无何　上晏驾时中贵冯保横甚新郑入相</span>  
<span style="margin-left: 1em">决策去之言路各有疏发其奸保遂逐新郑并𬺈诸言</span>  
<span style="margin-left: 1em">者久之仅移尚宝卿擢应天府丞寻改太常少卿已进</span>  
<span style="margin-left: 1em">太仆卿擢右佥都御史出抚山东时保已逐窜至则请</span>  
<span style="margin-left: 1em">裁募兵诸费苏里甲戒苛罚俱报可德藩夺民佃白云</span>  
<span style="margin-left: 1em">湖力与中贵人争执不听遂移病归归与文定尝婆娑</span>  
<span style="margin-left: 1em">萧寺偕名僧韵士谈说娓娓啜茗小饮以为常先文定</span>  
<span style="margin-left: 1em">数年卒子彦祯万历乙未进士官南京吏部考功主事</span>  
<span style="margin-left: 1em">廓落有才识惜未究其用孙景朋举万历癸卯乡荐</span>  
<span style="margin-left: 1em">蔡懋昭字允德上海人举嘉靖庚子乡试署教嘉善前</span>  
<span style="margin-left: 1em">令以墨败克扣戍伍金致哗而去乃诿罪庠士昭立为</span>  
<span style="margin-left: 1em">辨雪李太史自华袁职方黄等是也擢知新河县流贼</span>  
<span style="margin-left: 1em">出没乃从容画方畧贼党解散迁守赵州大桥税岁千</span>  
<span style="margin-left: 1em">金例充州署公用昭申请抚院分偿积逋载入会计册</span>  
<span style="margin-left: 1em">冢宰胡松称其贤已拟内召而太守陈烨𬺈龁之竟拂</span>  
<span style="margin-left: 1em">衣归适有西粤颜御史思贤过赵父老攀辕泣诉前州</span>  
<span style="margin-left: 1em">守治状及去官之故颜抗章首举之主爵杨襄毅即家</span>  
<span style="margin-left: 1em">起桂阳州旋同知怀庆平役均田加意振刷丁外艰补</span>  
<span style="margin-left: 1em">肇庆海酋何平余党许恩者筑城阳江沙岛东连惠州</span>  
<span style="margin-left: 1em">林道乾遥相犄角昭用间使恩自剪其翼示以恩信恩</span>  
<span style="margin-left: 1em">降一日忽檄杨参戎勒兵驰疾列阵恩之外营恩皇遽</span>  
<span style="margin-left: 1em">出迎入坐恩幄杨股栗不能语昭好言呼恩令解散诸</span>  
<span style="margin-left: 1em">党凡六千余人遂命将校急唤其城率恩入谒制府婉</span>  
<span style="margin-left: 1em">为请命赦不诛授与名色处之阳江内地积寇既平乃</span>  
<span style="margin-left: 1em">率众深入搜捕徭贼林道乾失援亦诣军门降沈公思</span>  
<span style="margin-left: 1em">孝以忠谏戍神电卫昭迎至阳江勅传授餐绝不以江</span>  
<span style="margin-left: 1em">陵介意拜思州知府建议广其城郡苦无井渫民间辄</span>  
<span style="margin-left: 1em">从二三十里外取水一日肃衣冠祷天四门各穿一井</span>  
<span style="margin-left: 1em">水旋涌民称为蔡公井邹公元标时戍都匀昭遣使慰</span>  
<span style="margin-left: 1em">劳一如沈公丙戌致仕归思民肖像祀之疾病祷之即</span>  
<span style="margin-left: 1em">愈历官凡三十年环堵萧然至老衣粗食粝或不能举</span>  
<span style="margin-left: 1em">火年届九十而殁二子长逢辰以贡为州别驾清介不</span>  
<span style="margin-left: 1em">愧家声</span>  
<span style="margin-left: 1em">范惟一字于中文正公十六世孙世家吴阊父北溪始</span>  
<span style="margin-left: 1em">迁松之泗泾食贫授经朱太史大韶出其门下成嘉靖</span>  
<span style="margin-left: 1em">辛丑进士知钧州擢丞济南转虞部佥宪湖广分部荆</span>  
<span style="margin-left: 1em">西捕治上豪一方慑息潜沔堤溃漂溺庐舍下令弛征</span>  
<span style="margin-left: 1em">发粟赈贫者再擢山东参议已督两浙学政旋升按察</span>  
<span style="margin-left: 1em">晋江西布政迁南太仆乞归留意著述季子允观当唐</span>  
<span style="margin-left: 1em">文恪困诸生时慨为助赀入成均随举丙戌状元人高</span>  
<span style="margin-left: 1em">其谊惟一孙必试举万历戊午弟惟丞嘉靖己未进士</span>  
<span style="margin-left: 1em">终光禄少卿丕长子允谦举隆庆庚午次允临乙未进</span>  
<span style="margin-left: 1em">士云南学宪</span>  
<span style="margin-left: 1em">唐志大字子迪华亭人嘉靖辛丑进士将就选念其母</span>  
<span style="margin-left: 1em">垂老又独子求南曹以便养亲授南行人司副旋疏乞</span>  
<span style="margin-left: 1em">终养会倭寇起闻吴兴地僻奉母居焉母卒护丧冒兵</span>  
<span style="margin-left: 1em">刃归葬里中复趣还吴兴遂病不起其殁也无以为殓</span>  
<span style="margin-left: 1em">家人无以为食欲归郡城无以为家闻者悲之所著有</span>  
<span style="margin-left: 1em">侨居赋及　高庙圣政记</span>  
<span style="margin-left: 1em">张鹗翼字习之中嘉靖戊子辛丑科进士授兵部职方</span>  
<span style="margin-left: 1em">司主事守山海关丙午改吏部稽勋司主事简别进退</span>  
<span style="margin-left: 1em">一依公议历验封考功为文选郎中岁终擢太常少卿</span>  
<span style="margin-left: 1em">提督四夷馆时宰臣用事久诸附丽者率引伺津要乃</span>  
<span style="margin-left: 1em">鹗翼力请南得通政司右通政贼师尚诏起淮蔡留都</span>  
<span style="margin-left: 1em">戒严于是分督通济门有议以城外竹木宜徙且焚者</span>  
<span style="margin-left: 1em">言根本重地不宜以小寇先自扰示之弱寻迁都察院</span>  
<span style="margin-left: 1em">右佥都御史巡抚贵州便道过海上时寇薄城下故留</span>  
<span style="margin-left: 1em">以系人心日夕图捍寇计寇合长围数重乘毁堞几入</span>  
<span style="margin-left: 1em">撤民扉为栅且战且修复出粟以廪登陴者逾月寇退</span>  
<span style="margin-left: 1em">丙辰以星变免归归葺故庐日邀故人觞咏尝愍民瘵</span>  
<span style="margin-left: 1em">于兵赋枯鱼叹黄丞行以讽切当道疾亟犹口占授子</span>  
<span style="margin-left: 1em">弟答郡守论民瘼书引己疾为喻盖忧时之心无壮老</span>  
<span style="margin-left: 1em">一也所著有须野集易说辩讹孙泰阶中万历己未进</span>  
<span style="margin-left: 1em">士历官温处道</span>  
<span style="margin-left: 1em">张承宪字监先华亭人嘉靖甲辰进士为行人赐一品</span>  
<span style="margin-left: 1em">服使朝鲜又两使亲藩却其赠遗迁南京吏科给事中</span>  
<span style="margin-left: 1em">时边吏请听北虏以牛羊易米豆上疏曰是益骄虏而</span>  
<span style="margin-left: 1em">示我弱且虏何厌之有今姑欲缓寇捐民所食使食我</span>  
<span style="margin-left: 1em">逋逃后复有请一不副寇犹故也条五不可状得不果</span>  
<span style="margin-left: 1em">易又疏言外计宜止科敛禁贿赂严举主之罚重部院</span>  
<span style="margin-left: 1em">之臣又疏久任以责成功抚臣不宜数易诏皆纳焉倭</span>  
<span style="margin-left: 1em">寇东南请勅兵部发兵往援度寇之冲设海防参将定</span>  
<span style="margin-left: 1em">军令计兵食为战守备又请勅浙直抚臣招还其民之</span>  
<span style="margin-left: 1em">从寇及严禁其导寇者又请薄赋税练乡兵䘏被寇之</span>  
<span style="margin-left: 1em">民丁艰服除改北乞归迁葬卒年六十七所著有端谅</span>  
<span style="margin-left: 1em">堂集</span>  
<span style="margin-left: 1em">杨允绳字翼少华亭人嘉靖甲辰进士以行人擢兵科</span>  
<span style="margin-left: 1em">给事中疏论阁部大臣受餽遗不赀盖指嵩相言也已</span>  
<span style="margin-left: 1em">巡视光禄有寺丞胡膏为严相客允绳劾其虚冒物料</span>  
<span style="margin-left: 1em">贪鄙不法膏乃反诬允绳讥讪嵩阴中之　上震怒</span>  
<span style="margin-left: 1em">廷杖下锦衣狱比骂父律拟绞在系五年会星陨如雨</span>  
<span style="margin-left: 1em">占者以为咎在臣下不忠遂列名上请行刑以应天变</span>  
<span style="margin-left: 1em">庚申十月朔遂付西市死刑时黑雾四塞朝野皆以为</span>  
<span style="margin-left: 1em">冤自遇害后三年而严氏诛先是允绳居里有郡佐峻</span>  
<span style="margin-left: 1em">行敲朴遗书贷其榎檚曰家有悍奴请治之与民分痛</span>  
<span style="margin-left: 1em">郡邑畏之　穆庙登极赠奉政大夫光禄寺少卿论祭</span>  
<span style="margin-left: 1em">天启中赐谥忠恪荫一子</span>  
<span style="margin-left: 1em">彭应麟字泰符华亭人嘉靖甲辰进士知乐清县会中</span>  
<span style="margin-left: 1em">丞檄之劳师心计手筹咄嗟立办吏士数百千人竟日</span>  
<span style="margin-left: 1em">夕无哗者擢南刑曹出守邵武内制山贼外御倭奴规</span>  
<span style="margin-left: 1em">条理举以病致政归应麟未第时友人苍头持盖立仓</span>  
<span style="margin-left: 1em">卒自外至触两齿落友人方骇惧应麟绝不介意徐曰</span>  
<span style="margin-left: 1em">此吾不慎所致赴试南都馆人有少妇挑之遂移馆舍</span>  
<span style="margin-left: 1em">以避子汝让见文学传中</span>  
<span style="margin-left: 1em">宋贤字及甫嘉靖甲辰进士令新昌民有税浮于田或</span>  
<span style="margin-left: 1em">有田无税者贤身履亩手握算宿弊尽袪又为汰侈费</span>  
<span style="margin-left: 1em">去冗役塞东溪以御潦濬西溪以备旱岁连大稔士民</span>  
<span style="margin-left: 1em">相与祠诸学宫征拜御史按甘肃前后上十七疏虏尝</span>  
<span style="margin-left: 1em">窥庄浪不克入而去兼督学政得张问仁胡执礼于诸</span>  
<span style="margin-left: 1em">生中继按四川蜀世子请名以金馈却之丁父忧归哭</span>  
<span style="margin-left: 1em">过哀丧明家居尝濬钱家坝以便民买田三百亩赡族</span>  
<span style="margin-left: 1em">胡公抚吴首谒贤贤陈民隐数事语不及私年七十五</span>  
<span style="margin-left: 1em">卒载浙江名宦</span>  
<span style="margin-left: 1em">王会字子嘉七宝里人嘉靖甲辰成进士授屯田主事</span>  
<span style="margin-left: 1em">榷南关税不以脂膏自润擢营缮郎治临清砖厂一式</span>  
<span style="margin-left: 1em">于杭入为虞衡郎中时北虏犯塞大将军仇鸾怙宠故</span>
