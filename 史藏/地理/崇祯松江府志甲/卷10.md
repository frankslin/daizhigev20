## 崇祯松江府志卷之十　赋额下

<span style="margin-left: 3em">田赋三</span>  
<span style="margin-left: 1em">前代赋额</span>  
<span style="margin-left: 1em">宋绍熙四年　定垦官民田土阙<sub class="note-jiao">校：原書</sub>夏税一十五</span>  
<span style="margin-left: 6em">　<sub class="note-yuan">即阙</sub></span>  
<span style="margin-left: 2em">万三千三百五十三贵一百一十五文　秋苗秔米</span>  
<span style="margin-left: 2em">一十一万二千三百一十六石九斗一升四合六勺</span>  
<span style="margin-left: 2em">一抄<sub class="note-yuan">实数六万七千余石县官岁督才三万八千石止</sub></span>  
<span style="margin-left: 1em">开禧三年以南四乡折补酒钱二税径解所司遇灾依</span>  
<span style="margin-left: 2em">例蠲放</span>  
<span style="margin-left: 2em">龙图阁直学士楼钥南四乡记畧　开禧三年孟秋</span>  
<span style="margin-left: 2em">月郡以邸报来有台评论嘉兴府华亭之四乡利病</span>  
<span style="margin-left: 2em">深切著明为之矍然而起仰叹曰皇上勤恤民隐宵</span>  
<span style="margin-left: 2em">旰不遑而耳目之官洞察田里之细微径以彻闻不</span>  
<span style="margin-left: 2em">旋踵而报可古所谓谏行言听膏泽下于民非此之</span>  
<span style="margin-left: 2em">谓耶于是时仲舅汪文昌之子立中为宰恐其累亟</span>  
<span style="margin-left: 2em">以书问之得报曰此出于殿中侍御史叶公之奏非</span>  
<span style="margin-left: 2em">特为一邑无穷之利立中与同僚亦有与大幸于斯</span>  
<span style="margin-left: 2em">焉士民方相与为叶公告立祠于县庠因请为记且</span>  
<span style="margin-left: 2em">序其事始及积弊之实大畧邑中岁造煮酝额止四</span>  
<span style="margin-left: 2em">万缗绍兴十八年有庠宰酝过倍增至十三万有奇</span>  
<span style="margin-left: 2em">科抑之害自里正市井道释医卜下至倡优无有免</span>  
<span style="margin-left: 2em">者吏胥以次差等其长岁或至二百万钱赇赂肆行</span>  
<span style="margin-left: 2em">公私多病吏逃民困官曹无以塞责动辄科罚重征</span>  
<span style="margin-left: 2em">倍税日甚一日参政钱良臣邑人也既登政路尽以</span>  
<span style="margin-left: 2em">告于孝宗宣谕漕臣韩彦质俾有以宽之先自张泾</span>  
<span style="margin-left: 2em">堰壤海潮大入云间胥浦仙山白沙四乡荡为巨壑</span>  
<span style="margin-left: 2em">漫及苏湖秀邑不复可耕乾道七年朝廷不惮重费</span>  
<span style="margin-left: 2em">大兴修筑海患虽除民力愈竭斥卤未清租税全失</span>  
<span style="margin-left: 2em">至是岁久农民渐归故业可以起赋犹未忍尽复旧</span>  
<span style="margin-left: 2em">贯量估米值使之乐输会计四乡夏税折帛为缗钱</span>  
<span style="margin-left: 2em">二万苗米近三万斛斛三缗合为九万于内以六万</span>  
<span style="margin-left: 2em">五千三十九贯充一岁月解之数以补酒额分隶发</span>  
<span style="margin-left: 2em">纳尚有增额三万贯有奇皆不可催促之数又尽蠲</span>  
<span style="margin-left: 2em">之自淳熙六年为始四乡之赋既轻而易输三十余</span>  
<span style="margin-left: 2em">年敷抑之害一旦洗去感被宽恩阖境为之鼓舞今</span>  
<span style="margin-left: 2em">又将三十年而四乡复成大弊春催夏税夏催秋苗</span>  
<span style="margin-left: 2em">是蚕桑未动而责以折绢铚艾未施而责以折苗殆</span>  
<span style="margin-left: 2em">无此理其尤害者遇有灾伤如今岁既旱而蝗他处</span>  
<span style="margin-left: 2em">皆有蠲减此独不与而征催益急别置牌引名色至</span>  
<span style="margin-left: 2em">不可缕数欲下漕司及本府措置每岁别委官专催</span>  
<span style="margin-left: 2em">四乡二税径解所隶不许邑官干预仍除去版帐中</span>  
<span style="margin-left: 2em">酒钱之数起催输纳并依条限给钞无得稽迟灾伤</span>  
<span style="margin-left: 2em">均与蠲放民赖以宽钱又无欠邑亦易办一举而三</span>  
<span style="margin-left: 2em">利具焉上意开纳旋即施行汪立中到官固已历究</span>  
<span style="margin-left: 2em">本末无路自达又以四乡所输每岁多不及额邑为</span>  
<span style="margin-left: 2em">补足尤难支吾天假之幸有此际会且蒙俯察官僚</span>  
<span style="margin-left: 2em">吏民交口相贺郡太守程公卓喜斯邑之少宽戒饬</span>  
<span style="margin-left: 2em">上下奉行惟谨立中深恐后人不知其详愿书而登</span>  
<span style="margin-left: 2em">之石叶公名时字秀发尝繇甲科入四明幕府其孜</span>  
<span style="margin-left: 2em">孜民事有年矣</span>  
<span style="margin-left: 1em">端平元年　秋苗米实征五万七千八百一十石是时</span>  
<span style="margin-left: 2em">华亭令杨瑾行经界法</span>  
<span style="margin-left: 2em">知县事杨瑾经界始末序畧　邑有绍兴经畧迨今</span>  
<span style="margin-left: 2em">且百年簿书漫漶赋役烦扰豪民猾吏相与为奸产</span>  
<span style="margin-left: 2em">去者赋不除力竭者役不止民讼纷拏吏胥黠徙而</span>  
<span style="margin-left: 2em">邑几不可为有志之士非不欲力起而图之阻于时</span>  
<span style="margin-left: 2em">阨于势则悠悠岁月徒汗颜落笔于敲朴间民生之</span>  
<span style="margin-left: 2em">害可胜难哉宋端平改元圣天子更新大化勤恤民</span>  
<span style="margin-left: 2em">隐以惠利为急瑾不肖获承流下邑修经界清版籍</span>  
<span style="margin-left: 2em">行之二年户无杂征之赋里无诐产之役信哉仁政</span>  
<span style="margin-left: 2em">自经界始修而复之顾岂不系诸时耶或曰难逢者</span>  
<span style="margin-left: 2em">时易弊者法向也经界未修赋犹有在民者今乃尽</span>  
<span style="margin-left: 2em">输于官矣前有一州县间复于额外求嬴则民力不</span>  
<span style="margin-left: 2em">堪咎必归子瑾悚然曰信如所虑虽然有田则有租</span>  
<span style="margin-left: 2em">有租则有赋此天下至公之法不取于所有而强有</span>  
<span style="margin-left: 2em">所无此昔日法弊之繇也今幸版籍粗明田赋就实</span>  
<span style="margin-left: 2em">民且乐输有仁心者必能维持而经久之何忍变易</span>  
<span style="margin-left: 2em">成规取嬴额外复重为民生害哉是用摭其颠末萃</span>  
<span style="margin-left: 2em">于一编庶览者亦亮瑾本心是举也始于元年二月</span>  
<span style="margin-left: 2em">成于二年四月乡官凡一百三十有七甲首凡八千</span>  
<span style="margin-left: 2em">八百八十有一乡书吏贴日计九十名县给纸札口</span>  
<span style="margin-left: 2em">券总一万五千缗其籍自亩之围则有归围簿自围</span>  
<span style="margin-left: 2em">之保则有归保簿自保之乡则有归乡簿自乡之县</span>  
<span style="margin-left: 2em">则有都头簿田不出围税不过乡此事制曲防之大</span>  
<span style="margin-left: 2em">畧也其纤悉条目别列于田围文籍库云端平丙申</span>  
<span style="margin-left: 2em">国史院编修简讨官权吏部侍郎袁甫修复经界记</span>  
<span style="margin-left: 2em">畧　华亭浙右壮邑岁入苗号逾十万石实六万七</span>  
<span style="margin-left: 2em">千有奇而县官岁督才三万八千止盖自绍兴经界</span>  
<span style="margin-left: 2em">迄今百年官无版籍吏缘为奸隐匿诡寄弊幸非一</span>  
<span style="margin-left: 2em">重以此邑西连湖北枕江东南并海田啮于水无岁</span>  
<span style="margin-left: 2em">无之繇是赋役俱病贫富交困而争讼四起绍定五</span>  
<span style="margin-left: 2em">年杨君来为司征越明年监簿赵君与򐂃出守嘉禾</span>  
<span style="margin-left: 2em">整图籍宽赋敛欲自近邑始招君幕下置田围局募</span>  
<span style="margin-left: 2em">甲首给青册命之曰抄撩匿者露虚者实乃檄君摄</span>  
<span style="margin-left: 2em">事华亭君日受讼牒力究弊源蠲胥吏白纳之钱代</span>  
<span style="margin-left: 2em">民户积欠之赋弛酒税无艺之征德意渐孚矣则以</span>  
<span style="margin-left: 2em">礼属乡官分任其责不履亩不立限不任吏每都甲</span>  
<span style="margin-left: 2em">首乡官择之每围青册甲首笔之田之顷亩昭哉可</span>  
<span style="margin-left: 2em">观邑士民相与举令于州州上之朝俾遂为真夙夜</span>  
<span style="margin-left: 2em">黾勉以竟前功赋籍一定诡挟有归既又白郡以北</span>  
<span style="margin-left: 2em">三乡上田赋重则降而为中以北三乡折糯价重则</span>  
<span style="margin-left: 2em">复减而从轻以青龙镇地积计税重则尽降而从亩</span>  
<span style="margin-left: 2em">以邑郛及诸乡浮财物力颇为民扰则止以实产定</span>  
<span style="margin-left: 2em">和买役钱之数令可谓尽心也已又谂于众曰吾当</span>  
<span style="margin-left: 2em">与尔增减槩量之赢以示优恤未几明天子新更大</span>  
<span style="margin-left: 2em">化诞布宽政痛减斛面尽蠲积逋令得奉行上意不</span>  
<span style="margin-left: 2em">负初约于是端平元年秋苗以五万七千八百一十</span>  
<span style="margin-left: 2em">石为额较递年之数逾二万而民不以为厉</span>  
<span style="margin-left: 2em">显谟阁待制王遂修复经界本末记畧　端平元二</span>  
<span style="margin-left: 2em">之年圣天子思所以揽权纲剔弊蠧而于两税输送</span>  
<span style="margin-left: 2em">尤致其谨遂待罪殿中获掌斯事诏下方国平江嘉</span>  
<span style="margin-left: 2em">兴奉行惟谨浙右在绍兴间尝举行经界法岁久弊</span>  
<span style="margin-left: 2em">坏二州为甚平江行于常熟暨嘉定嘉兴行于华亭</span>  
<span style="margin-left: 2em">而规模区画未有若华亭之详且密者则以太守赵</span>  
<span style="margin-left: 2em">公与򐂃主盟于上再令杨侯瑾维持于下而寓公通</span>  
<span style="margin-left: 2em">州教授孙君一飞等协赞其旁也上嘉乃劳赵公与</span>  
<span style="margin-left: 2em">平江张公嗣古各进一帙杨侯帙满升故府其修复</span>  
<span style="margin-left: 2em">本末则尚书袁公甫为之记孙君谓遂曰于华亭之</span>  
<span style="margin-left: 2em">不易满去者十不八九今守令俱贤公私被惠吾惧</span>  
<span style="margin-left: 2em">暴君污吏以墨自肥而利于坏也为我记之遂以心</span>  
<span style="margin-left: 2em">许而未有以酬其言今六载矣孙君一日移书曰嘉</span>  
<span style="margin-left: 2em">熙间郡置将不善复义役减等赋数千石民不便之</span>  
<span style="margin-left: 2em">赖县有碑具载省札援以请于朝幸而获免然则子</span>  
<span style="margin-left: 2em">之文讵可已乎遂谢无可辞抑田必有租租必有税</span>  
<span style="margin-left: 2em">自昔皆然未有富家大室广连阡陌而勺合不以供</span>  
<span style="margin-left: 2em">官贫民下户无甑石之入而受倍输之害者也向非</span>  
<span style="margin-left: 2em">当宁恻然垂念畿邑之民赵公杨侯相与考订一切</span>  
<span style="margin-left: 2em">请轻而孙君又以乡曲之利垂之永久则重敛于民</span>  
<span style="margin-left: 2em">岂有穷哉是宜砻石大书以识本末抑闻之经始者</span>  
<span style="margin-left: 2em">难为功继治者易于坏方其民瘼之深赖有贤守明</span>  
<span style="margin-left: 2em">令大开其端以去百年之害后之来者其能皆如前</span>  
<span style="margin-left: 2em">者之用心乎寓公士民亦有协心弗坏如孙君者乎</span>  
<span style="margin-left: 2em">遂畴昔之岁尝闻其畧矣及守平江继张公后自吴</span>  
<span style="margin-left: 2em">长洲昆山吴江皆得考论其故与两邑并行计石输</span>  
<span style="margin-left: 2em">租无重催白纳之患岁输三十四万无斛面多取之</span>  
<span style="margin-left: 2em">扰以春二月从事六月而毕前若嘉定而来尽后若</span>  
<span style="margin-left: 2em">吴江而或疑其多往往未及论定而解去矣兹闻赵</span>  
<span style="margin-left: 2em">公守吴行发运事其政宽大不苛而间取诸遂之旧</span>  
<span style="margin-left: 2em">又得杨侯为别驾以奉行其政其民小大安之嘉兴</span>  
<span style="margin-left: 2em">邻壤继至者能不动心乎此遂之所为平江喜而又</span>
