## 崇禎松江府志卷之十　賦額下

<span style="margin-left: 3em">田賦三</span>  
<span style="margin-left: 1em">前代賦額</span>  
<span style="margin-left: 1em">宋紹熙四年　定墾官民田土闕<sub class="note-jiao">校：原書</sub>夏稅一十五</span>  
<span style="margin-left: 6em">　<sub class="note-yuan">即闕</sub></span>  
<span style="margin-left: 2em">萬三千三百五十三貴一百一十五文　秋苗秔米</span>  
<span style="margin-left: 2em">一十一萬二千三百一十六石九斗一升四合六勺</span>  
<span style="margin-left: 2em">一抄<sub class="note-yuan">實數六萬七千餘石縣官歲督纔三萬八千石止</sub></span>  
<span style="margin-left: 1em">開禧三年以南四鄉折補酒錢二稅徑解所司遇災依</span>  
<span style="margin-left: 2em">例蠲放</span>  
<span style="margin-left: 2em">龍圖閣直學士樓鑰南四鄉記畧　開禧三年孟秋</span>  
<span style="margin-left: 2em">月郡以邸報來有臺評論嘉興府華亭之四鄉利病</span>  
<span style="margin-left: 2em">深切著明爲之矍然而起仰歎曰皇上勤恤民隱宵</span>  
<span style="margin-left: 2em">旰不遑而耳目之官洞察田里之細微徑以徹聞不</span>  
<span style="margin-left: 2em">旋踵而報可古所謂諫行言聽膏澤下于民非此之</span>  
<span style="margin-left: 2em">謂耶于是時仲舅汪文昌之子立中爲宰恐其累亟</span>  
<span style="margin-left: 2em">以書問之得報曰此出于殿中侍御史葉公之奏非</span>  
<span style="margin-left: 2em">特爲一邑無窮之利立中與同僚亦有與大幸于斯</span>  
<span style="margin-left: 2em">焉士民方相與爲葉公告立祠于縣庠因請爲記且</span>  
<span style="margin-left: 2em">序其事始及積弊之實大畧邑中歲造煮醖額止四</span>  
<span style="margin-left: 2em">萬緡紹興十八年有庠宰醖過倍增至十三萬有奇</span>  
<span style="margin-left: 2em">科抑之害自里正市井道釋醫卜下至倡優無有免</span>  
<span style="margin-left: 2em">者吏胥以次差等其長歲或至二百萬錢賕賂肆行</span>  
<span style="margin-left: 2em">公私多病吏逃民困官曹無以塞責動輒科罰重征</span>  
<span style="margin-left: 2em">倍稅日甚一日參政錢良臣邑人也既登政路盡以</span>  
<span style="margin-left: 2em">告于孝宗宣諭漕臣韓彦質俾有以寬之先自張涇</span>  
<span style="margin-left: 2em">堰壤海潮大入雲間胥浦仙山白沙四鄉蕩爲巨壑</span>  
<span style="margin-left: 2em">漫及蘇湖秀邑不復可耕乾道七年朝廷不憚重費</span>  
<span style="margin-left: 2em">大興修築海患雖除民力愈竭斥鹵未清租稅全失</span>  
<span style="margin-left: 2em">至是歲久農民漸歸故業可以起賦猶未忍盡復舊</span>  
<span style="margin-left: 2em">貫量估米值使之樂輸會計四鄉夏稅折帛爲緡錢</span>  
<span style="margin-left: 2em">二萬苗米近三萬斛斛三緡合爲九萬於內以六萬</span>  
<span style="margin-left: 2em">五千三十九貫充一歲月解之數以補酒額分隸發</span>  
<span style="margin-left: 2em">納尚有增額三萬貫有奇皆不可催促之數又盡蠲</span>  
<span style="margin-left: 2em">之自淳熙六年爲始四鄉之賦既輕而易輸三十餘</span>  
<span style="margin-left: 2em">年敷抑之害一旦洗去感被寬恩闔境爲之鼓舞今</span>  
<span style="margin-left: 2em">又將三十年而四鄉復成大弊春催夏稅夏催秋苗</span>  
<span style="margin-left: 2em">是蠶桑未動而責以折絹銍艾未施而責以折苗殆</span>  
<span style="margin-left: 2em">無此理其尤害者遇有災傷如今歲既旱而蝗他處</span>  
<span style="margin-left: 2em">皆有蠲减此獨不與而征催益急別置牌引名色至</span>  
<span style="margin-left: 2em">不可縷數欲下漕司及本府措置每歲別委官專催</span>  
<span style="margin-left: 2em">四鄉二稅徑解所隸不許邑官干預仍除去版帳中</span>  
<span style="margin-left: 2em">酒錢之數起催輸納並依條限給鈔無得稽遲災傷</span>  
<span style="margin-left: 2em">均與蠲放民賴以寬錢又無欠邑亦易辦一舉而三</span>  
<span style="margin-left: 2em">利具焉上意開納旋即施行汪立中到官固已歷究</span>  
<span style="margin-left: 2em">本末無路自達又以四鄉所輸每歲多不及額邑爲</span>  
<span style="margin-left: 2em">補足尤難支吾天假之幸有此際會且蒙俯察官僚</span>  
<span style="margin-left: 2em">吏民交口相賀郡太守程公卓喜斯邑之少寬戒飭</span>  
<span style="margin-left: 2em">上下奉行惟謹立中深恐後人不知其詳願書而登</span>  
<span style="margin-left: 2em">之石葉公名時字秀發嘗繇甲科入四明幕府其孜</span>  
<span style="margin-left: 2em">孜民事有年矣</span>  
<span style="margin-left: 1em">端平元年　秋苗米實徵五萬七千八百一十石是時</span>  
<span style="margin-left: 2em">華亭令楊瑾行經界法</span>  
<span style="margin-left: 2em">知縣事楊瑾經界始末序畧　邑有紹興經畧迨今</span>  
<span style="margin-left: 2em">且百年簿書漫漶賦役煩擾豪民猾吏相與爲姦産</span>  
<span style="margin-left: 2em">去者賦不除力竭者役不止民訟紛拏吏胥黠徙而</span>  
<span style="margin-left: 2em">邑幾不可爲有志之士非不欲力起而圖之阻于時</span>  
<span style="margin-left: 2em">阨于勢則悠悠歲月徒汗顔落筆于敲朴間民生之</span>  
<span style="margin-left: 2em">害可勝難哉宋端平改元聖天子更新大化勤恤民</span>  
<span style="margin-left: 2em">隱以惠利爲急瑾不肖獲承流下邑修經界清版籍</span>  
<span style="margin-left: 2em">行之二年户無雜征之賦里無詖産之役信哉仁政</span>  
<span style="margin-left: 2em">自經界始修而復之顧豈不係諸時耶或曰難逢者</span>  
<span style="margin-left: 2em">時易弊者法向也經界未修賦猶有在民者今乃盡</span>  
<span style="margin-left: 2em">輸于官矣前有一州縣間復于額外求嬴則民力不</span>  
<span style="margin-left: 2em">堪咎必歸子瑾悚然曰信如所慮雖然有田則有租</span>  
<span style="margin-left: 2em">有租則有賦此天下至公之法不取于所有而强有</span>  
<span style="margin-left: 2em">所無此昔日法弊之繇也今幸版籍粗明田賦就實</span>  
<span style="margin-left: 2em">民且樂輸有仁心者必能維持而經久之何忍變易</span>  
<span style="margin-left: 2em">成規取嬴額外復重爲民生害哉是用摭其顛末萃</span>  
<span style="margin-left: 2em">于一編庶覽者亦亮瑾本心是舉也始于元年二月</span>  
<span style="margin-left: 2em">成于二年四月鄉官凡一百三十有七甲首凡八千</span>  
<span style="margin-left: 2em">八百八十有一鄉書吏貼日計九十名縣給紙札口</span>  
<span style="margin-left: 2em">券總一萬五千緡其籍自畝之圍則有歸圍簿自圍</span>  
<span style="margin-left: 2em">之保則有歸保簿自保之鄉則有歸鄉簿自鄉之縣</span>  
<span style="margin-left: 2em">則有都頭簿田不出圍稅不過鄉此事制曲防之大</span>  
<span style="margin-left: 2em">畧也其纖悉條目別列于田圍文籍庫云端平丙申</span>  
<span style="margin-left: 2em">國史院編修簡討官權吏部侍郎袁甫修復經界記</span>  
<span style="margin-left: 2em">畧　華亭浙右壯邑歲入苗號踰十萬石實六萬七</span>  
<span style="margin-left: 2em">千有奇而縣官歲督纔三萬八千止蓋自紹興經界</span>  
<span style="margin-left: 2em">迄今百年官無版籍吏緣爲奸隱匿詭寄弊倖非一</span>  
<span style="margin-left: 2em">重以此邑西連湖北枕江東南並海田齧於水無歲</span>  
<span style="margin-left: 2em">無之繇是賦役俱病貧富交困而争訟四起紹定五</span>  
<span style="margin-left: 2em">年楊君來爲司征越明年監簿趙君與򐂃出守嘉禾</span>  
<span style="margin-left: 2em">整圖籍寬賦斂欲自近邑始招君幕下置田圍局募</span>  
<span style="margin-left: 2em">甲首給青册命之曰抄撩匿者露虛者實乃檄君攝</span>  
<span style="margin-left: 2em">事華亭君日受訟牒力究弊源蠲胥吏白納之錢代</span>  
<span style="margin-left: 2em">民户積欠之賦弛酒稅無藝之征德意漸孚矣則以</span>  
<span style="margin-left: 2em">禮屬鄉官分任其責不履畝不立限不任吏每都甲</span>  
<span style="margin-left: 2em">首鄉官擇之每圍青册甲首筆之田之頃畝昭哉可</span>  
<span style="margin-left: 2em">觀邑士民相與舉令於州州上之朝俾遂爲真夙夜</span>  
<span style="margin-left: 2em">黽勉以竟前功賦籍一定詭挾有歸既又白郡以北</span>  
<span style="margin-left: 2em">三鄉上田賦重則降而爲中以北三鄉折糯價重則</span>  
<span style="margin-left: 2em">復减而從輕以青龍鎮地積計稅重則盡降而從畝</span>  
<span style="margin-left: 2em">以邑郛及諸鄉浮財物力頗爲民擾則止以實産定</span>  
<span style="margin-left: 2em">和買役錢之數令可謂盡心也已又諗于衆曰吾當</span>  
<span style="margin-left: 2em">與爾增减槩量之贏以示優恤未幾明天子新更大</span>  
<span style="margin-left: 2em">化誕布寬政痛减斛面盡蠲積逋令得奉行上意不</span>  
<span style="margin-left: 2em">負初約於是端平元年秋苗以五萬七千八百一十</span>  
<span style="margin-left: 2em">石爲額較遞年之數逾二萬而民不以爲厲</span>  
<span style="margin-left: 2em">顯謨閣待制王遂修復經界本末記畧　端平元二</span>  
<span style="margin-left: 2em">之年聖天子思所以攬權綱剔弊蠧而于兩稅輸送</span>  
<span style="margin-left: 2em">尤致其謹遂待罪殿中獲掌斯事詔下方國平江嘉</span>  
<span style="margin-left: 2em">興奉行惟謹浙右在紹興間嘗舉行經界法歲久弊</span>  
<span style="margin-left: 2em">壞二州爲甚平江行于常熟暨嘉定嘉興行于華亭</span>  
<span style="margin-left: 2em">而規模區畫未有若華亭之詳且密者則以太守趙</span>  
<span style="margin-left: 2em">公與򐂃主盟于上再令楊侯瑾維持于下而寓公通</span>  
<span style="margin-left: 2em">州教授孫君一飛等協贊其旁也上嘉乃勞趙公與</span>  
<span style="margin-left: 2em">平江張公嗣古各進一帙楊侯帙滿陞故府其修復</span>  
<span style="margin-left: 2em">本末則尚書袁公甫爲之記孫君謂遂曰于華亭之</span>  
<span style="margin-left: 2em">不易滿去者十不八九今守令俱賢公私被惠吾懼</span>  
<span style="margin-left: 2em">暴君汙吏以墨自肥而利于壞也爲我記之遂以心</span>  
<span style="margin-left: 2em">許而未有以酬其言今六載矣孫君一日移書曰嘉</span>  
<span style="margin-left: 2em">熙間郡置將不善復義役减等賦數千石民不便之</span>  
<span style="margin-left: 2em">賴縣有碑具載省劄援以請于朝幸而獲免然則子</span>  
<span style="margin-left: 2em">之文詎可已乎遂謝無可辭抑田必有租租必有稅</span>  
<span style="margin-left: 2em">自昔皆然未有富家大室廣連阡陌而勺合不以供</span>  
<span style="margin-left: 2em">官貧民下户無甑石之入而受倍輸之害者也向非</span>  
<span style="margin-left: 2em">當宁惻然垂念畿邑之民趙公楊侯相與考訂一切</span>  
<span style="margin-left: 2em">請輕而孫君又以鄉曲之利垂之永久則重斂于民</span>  
<span style="margin-left: 2em">豈有窮哉是宜礱石大書以識本末抑聞之經始者</span>  
<span style="margin-left: 2em">難爲功繼治者易于壞方其民瘼之深賴有賢守明</span>  
<span style="margin-left: 2em">令大開其端以去百年之害後之來者其能皆如前</span>  
<span style="margin-left: 2em">者之用心乎寓公士民亦有協心弗壞如孫君者乎</span>  
<span style="margin-left: 2em">遂疇昔之歲嘗聞其畧矣及守平江繼張公後自吳</span>  
<span style="margin-left: 2em">長洲崑山吳江皆得考論其故與兩邑並行計石輸</span>  
<span style="margin-left: 2em">租無重催白納之患歲輸三十四萬無斛面多取之</span>  
<span style="margin-left: 2em">擾以春二月從事六月而畢前若嘉定而來盡後若</span>  
<span style="margin-left: 2em">吳江而或疑其多往往未及論定而解去矣兹聞趙</span>  
<span style="margin-left: 2em">公守吳行發運事其政寬大不苛而間取諸遂之舊</span>  
<span style="margin-left: 2em">又得楊侯爲別駕以奉行其政其民小大安之嘉興</span>  
<span style="margin-left: 2em">鄰壤繼至者能不動心乎此遂之所爲平江喜而又</span>

<span style="margin-left: 2em">宋晁景迂謂今賦役幾十倍于漢林勳謂宋租七倍</span>  
<span style="margin-left: 2em">于唐加以夏稅幾十倍按唐一夫百畝歲入租二石</span>  
<span style="margin-left: 2em">畝計租二升七倍則斗四升也然紹熙間華亭田四</span>  
<span style="margin-left: 2em">萬七千頃省額租十一萬二千三百有奇實數六萬</span>  
<span style="margin-left: 2em">七千餘石歲督纔三萬八千石極多至五萬七千而</span>  
<span style="margin-left: 2em">已以田計租比唐纔加十之一二七倍之說或他有</span>  
<span style="margin-left: 2em">所據吾鄉有木然也今總計二稅折納運耗等爲平</span>  
<span style="margin-left: 2em">米百三十八萬有奇比宋爲十二倍以上比寔徵常</span>  
<span style="margin-left: 2em">數三十倍而有餘矣而岸草商稅魚鹽等類又不計</span>  
<span style="margin-left: 2em">焉漢唐不敢望也求爲宋民何可得哉有官君子又</span>  
<span style="margin-left: 2em">往往以加賦爲言吾不知其何心也</span>  
<span style="margin-left: 2em">吾鄉征稅之重天下無之而岸草一節尤無謂舊例</span>  
<span style="margin-left: 2em">度田至水際皆併岸外沙塗一步有半通計爲田前</span>  
<span style="margin-left: 2em">人之意蓋以沙塗有水草茭蘆之利故也沙塗且稅</span>  
<span style="margin-left: 2em">則岸可知矣成化壬辰以東南水利廢弛設僉事一</span>  
<span style="margin-left: 2em">員董之始創爲岸草之稅而吾松一府計爲銀七千</span>

<span style="margin-left: 2em">糧畝加五合以足其數松田四萬七千餘頃率二畝</span>  
<span style="margin-left: 2em">一升爲米二萬三千五百餘石假曰姑以應一時之</span>  
<span style="margin-left: 2em">急猶或可爾而此後遂爲常稅岸草之征價又自如</span>

<span style="margin-left: 2em">吾鄉之田東南岸海西北臨江濱湖歲有崩陷而沿</span>

<span style="margin-left: 2em">輸二石有奇而猶不止也</span>

<span style="margin-left: 2em">倉米嘗數十萬一遇水旱便奏免糧奏准免數即以</span>  
<span style="margin-left: 2em">濟農倉米補完所以民不知凶荒　朝廷不知有缺</span>

<span style="margin-left: 2em">遵　朝命勸借得米六萬石催糧里甲運入濟農倉</span>  
<span style="margin-left: 2em">賑濟補災之外歲有寬餘此米之所以多也又曰每</span>

<span style="margin-left: 2em">萬石又遵　朝廷勸分之令于秋糧帶徵得米六萬</span>  
<span style="margin-left: 2em">石歲積米共二十一萬石賑濟補災及糧運虧損悉</span>

<span style="margin-left: 2em">而實猶存也又况得業蕩米歲有增加由六十文鈔</span>  
<span style="margin-left: 2em">而爲米三升由三升而爲五升二合至六升召佃官</span>  
<span style="margin-left: 2em">租二斗者爲二斗九升三斗者爲三斗九升矣則歲</span>  
<span style="margin-left: 2em">入所增又不知當幾何也而問之典守率皆茫然不</span>

<span style="margin-left: 2em">子所以勞心焦思朝慮夕畫使人承奉不暇而實無</span>

<span style="margin-left: 1em">陸文裕公論耗米</span>  
<span style="margin-left: 2em">加耗二字起於後唐明宗入倉見受納主吏折閲乃</span>  
<span style="margin-left: 2em">令石取二升爲鼠雀耗我　太祖則每斗起耗七合</span>  
<span style="margin-left: 2em">石爲七升蓋中制也江南糧稅每石平米上加耗已</span>  
<span style="margin-left: 2em">至七八斗蓋併入雜辦通謂之耗意不止於鼠雀爲</span>

<span style="margin-left: 2em">漢隱帝時王章爲三司使始令更輸二斗謂之雀耗</span>  
<span style="margin-left: 2em">當時人怨之史亦謂章聚斂刻急胡致堂推本其殺</span>  
<span style="margin-left: 2em">身以爲興利之戒</span>  
<span style="margin-left: 1em">徐文貞公與撫按論均糧書</span>  
<span style="margin-left: 2em">今之爲均糧之說者大率有三民之求均糧者曰田</span>  
<span style="margin-left: 2em">一也而其爲糧或畝三斗遞增之以至五斗或畝一</span>  
<span style="margin-left: 2em">斗遞减之以至五升其多寡若是懸絕也是不可以</span>  
<span style="margin-left: 2em">不均也有司之有志利民者曰松之民其日困乏而</span>  
<span style="margin-left: 2em">不能支由糧重也均之庶少輕乎是不可以不均也</span>  
<span style="margin-left: 2em">其有志釐弊者曰松之田糧斗則繁多易於增减存</span>  
<span style="margin-left: 2em">糧之弊由之作焉是不可以不均也而實不然蓋松</span>  
<span style="margin-left: 2em">之田糧其在西鄉畝自三斗至五斗而其收租亦自</span>  
<span style="margin-left: 2em">一石三斗至一石五斗間有一石七八斗如金澤鎮</span>  
<span style="margin-left: 2em">者焉放糧五斗而租一石三斗者西鄉之下田也其</span>  
<span style="margin-left: 2em">在東鄉畝自一斗至五升而其收租亦自七斗至五</span>  
<span style="margin-left: 2em">斗間有以花荳代租如十四五保者焉故糧五升而</span>  
<span style="margin-left: 2em">租七斗者東鄉之上田也今姑以西鄉之下田言之</span>  
<span style="margin-left: 2em">租一石三斗除納正糧五斗加耗一斗其贏尚七斗</span>  
<span style="margin-left: 2em">以東鄉之上田言之租七斗除納正糧五升加耗一</span>  
<span style="margin-left: 2em">斗其贏不過五斗五升是五升之贏租比五斗之贏</span>  
<span style="margin-left: 2em">反不足一斗五升也而况均徭之編五升田畝出銀</span>  
<span style="margin-left: 2em">五錢五斗田畝僅出銀三分乎又况近例五斗田不</span>  
<span style="margin-left: 2em">加耗乎以東鄉之上田比西鄉之下田若此則以西</span>  
<span style="margin-left: 2em">鄉之上田比東鄉之下田可知矣如是而欲均之可</span>  
<span style="margin-left: 2em">不可也且夫謂均糧而糧可輕也今五斗减而五升</span>  
<span style="margin-left: 2em">增是朝三暮四徂公之計耳而得謂之輕乎又况今</span>  
<span style="margin-left: 2em">之均糧也上鄉畝三斗六升中鄉畝三斗二升下鄉</span>  
<span style="margin-left: 2em">畝二斗八升併昔之所謂五升者不復見矣即其所</span>  
<span style="margin-left: 2em">謂五升者三倍而取之乎夫所謂上中下三鄉者其</span>  
<span style="margin-left: 2em">以田之肥瘠租之多寡爲等乎則如前所均可矣如</span>  
<span style="margin-left: 2em">其不然無乃求以利之而反以病之將使東鄉之下</span>  
<span style="margin-left: 2em">田棄而不敢耕而逋賦無所取乎若是者僕未見其</span>  
<span style="margin-left: 2em">可也或曰子之言均糧之不可則既然矣然而存糧</span>  
<span style="margin-left: 2em">之害亦子之所親覩也其將何以救之曰是其說亦</span>  
<span style="margin-left: 2em">有三在有司者加之意耳夫松之存糧有其人已往</span>  
<span style="margin-left: 2em">莫可究詰里甲代之輸者矣有其人尚存欲自訴理</span>  
<span style="margin-left: 2em">而無其階者矣有將爲增减之弊故舉往時所謂魚</span>  
<span style="margin-left: 2em">鱗圖册而亂之者矣今欲救尚存之弊請於民之赴</span>  
<span style="margin-left: 2em">訴者無撓權勢無狥請託無通貨賄一切斷之以法</span>

<span style="margin-left: 2em">其爲不均也小既均之後其爲不均也大是欲去小</span>

<span style="margin-left: 2em">周文襄公巡撫一十八年常操一小舟沿村逐港隨</span>  
<span style="margin-left: 2em">處詢訪遇一村朴老農則攜之與俱卧於榻下待其</span>  
<span style="margin-left: 2em">相狎則咨以地方之事民情土俗無不周知故定爲</span>  
<span style="margin-left: 2em">論糧加耗之制而以金花銀粗細布輕賫等項稗補</span>  
<span style="margin-left: 2em">重額之田斟酌損益盡善盡美顧文僖作文襄年譜</span>  
<span style="margin-left: 2em">所謂循之則治紊之則亂蓋不虛也</span>  
<span style="margin-left: 2em">嘗見東鄉之田岸下畧有茭蘆即飛弓一步夫些少</span>  
<span style="margin-left: 2em">茭蘆但可以供數日燒柴而已有何利息便作實田</span>  
<span style="margin-left: 2em">起糧如此寃苦當何所控訴耶况業户用錢者則有</span>  
<span style="margin-left: 2em">茭蘆者算作無茭蘆便不飛弓不用錢者雖無茭蘆</span>  
<span style="margin-left: 2em">算作有茭蘆便有飛弓小民無知何從辨別是自立</span>  
<span style="margin-left: 2em">名色自開孔隙以與弓正良民作騙局矣東鄉有立</span>  
<span style="margin-left: 2em">積水河與魚池二樣名色積水河則四畝作一畝魚</span>  
<span style="margin-left: 2em">池則二畝算一畝夫積水河本爲旱歲救田高鄉若</span>  
<span style="margin-left: 2em">一月無雨苗必槁死故積水救之又不出米又不出</span>  
<span style="margin-left: 2em">柴如何算作實田今四畝亦包一畝之稅矣魚池則</span>  
<span style="margin-left: 2em">積水河之稍大者以其稍寬可以養魚遂用工本銀</span>  
<span style="margin-left: 2em">買魚苗蓄之若數年多雨魚或生息亦有徵利或一</span>  
<span style="margin-left: 2em">年無水則數畝之池車戽立盡而魚即槁死且五六</span>  
<span style="margin-left: 2em">月中無處可賣皆臭腐棄去雖本錢亦無覓處今二</span>  
<span style="margin-left: 2em">畝作一畝實田徵糧則人心其何能堪况今試以積</span>  
<span style="margin-left: 2em">水河爲魚池魚池爲積水河即使公廉清正之官親</span>  
<span style="margin-left: 2em">至其地踏勘亦何從辨之今但憑公正與良民開報</span>  
<span style="margin-left: 2em">使良民公正皆伯夷史魚則可又何望一區之中伯</span>  
<span style="margin-left: 2em">夷史魚之多耶近有責任水利不思泥沙淤塞誰之</span>  
<span style="margin-left: 2em">咎也反沿鄉丈量以開墾報功此等用心即免王法</span>  
<span style="margin-left: 2em">能逃天刑乎</span>  
<span style="margin-left: 1em">巡撫都御史林公潤移文</span>  
<span style="margin-left: 2em">照得松郡素稱沃壤民樂供輸邇來催徵日煩逋負</span>  
<span style="margin-left: 2em">日衆是豈民之盡不如古哉良由田糧不均荒田之</span>  
<span style="margin-left: 2em">貽累也夫賦起於田而役困於賦今有力而狡者田</span>  
<span style="margin-left: 2em">腴而納輕稅無力而愚者田磽而反重科以致富者</span>  
<span style="margin-left: 2em">愈富貧者益貧逃亡相繼田地抛荒單弱窮區反累</span>  
<span style="margin-left: 2em">里役賠貱而奸滑富户多又以熟移荒如華亭之三</span>  
<span style="margin-left: 2em">十七八等保上海之西鄉等處雖稱極疲虛實一混</span>  
<span style="margin-left: 2em">相沿積弊民何聊生本院奉　命撫綏心切民隱亟</span>  
<span style="margin-left: 2em">亟厘正以濟時艱自非廣集衆思何以善後宜民所</span>  
<span style="margin-left: 2em">願諸司共圖良畫仰本府官吏只便轉行該府掌印</span>  
<span style="margin-left: 2em">官會同同知鄭李并華亭知縣聶上海知縣姜等請</span>  
<span style="margin-left: 2em">質賢達士夫并拘集年高有德耆老糧塘里排多方</span>  
<span style="margin-left: 2em">審訪田賦等則何以均平荒田何由覈實荒糧如何</span>  
<span style="margin-left: 2em">處豁開墾作何施工或應該丈量或先審處其太甚</span>  
<span style="margin-left: 2em">苟可永逸毋惜一勞苟有百益不惜一費酌量利害</span>  
<span style="margin-left: 2em">之分數如利多而害少則從其利遍詢民情之好惡</span>  
<span style="margin-left: 2em">如好衆而惡寡則從其好務要博採廣諮熟思審處</span>  
<span style="margin-left: 2em">會議停妥以憑裁奪各該官員職司守領尤須任事</span>  
<span style="margin-left: 2em">任怨着實舉行毋得畏避嫌疑坐視民殃致虧國計</span>  
<span style="margin-left: 2em">責有攸歸</span>  
<span style="margin-left: 1em">侍御南湖徐公宗魯均糧異議辨</span>  
<span style="margin-left: 2em">夫今丈量均糧之舉乃足國安民之策但大家不樂</span>  
<span style="margin-left: 2em">多立異議欲阻良圖敢按其說辨之蓋西鄉之田利</span>  
<span style="margin-left: 2em">于槩均東鄉之田利于各均大户之田利于不丈不</span>  
<span style="margin-left: 2em">均此大率人情之私也故聞議者有曰東鄉田畝取</span>  
<span style="margin-left: 2em">租七八斗西鄉金澤鎮田畝取租一石五六斗若一</span>  
<span style="margin-left: 2em">槩均糧則東鄉不堪是故不可均也然不知東鄉高</span>  
<span style="margin-left: 2em">亢下田果有此租若十二三等保畝取租一石二斗</span>  
<span style="margin-left: 2em">者數亦不少豈盡皆下田也西鄉金澤鎮田果間有</span>  
<span style="margin-left: 2em">此租若沿河窪下等田畝取租七八斗者亦未嘗無</span>  
<span style="margin-left: 2em">豈盡皆上田也若專指東之下田以較西之上田則</span>  
<span style="margin-left: 2em">太偏而非通論矣况二十年來雖金澤鎮田賤賣無</span>  
<span style="margin-left: 2em">主租雖大减民不肯佃此其故何也蓋因重糧追併</span>  
<span style="margin-left: 2em">民多逃亡在他區更可知矣東鄉上區田增價趨買</span>  
<span style="margin-left: 2em">租雖踰石民且樂耕此其故又何也蓋輕糧易辦動</span>  
<span style="margin-left: 2em">稱下區凡徵派更稍减矣今議者不念民困已極當</span>  
<span style="margin-left: 2em">變通以宜時而乃執租之多寡論田之難均獨不思</span>  
<span style="margin-left: 2em">蘇郡先嘗槩均民减利賴豈其租皆一等而無多寡</span>  
<span style="margin-left: 2em">乎豈其田皆一等而無高下乎合彼此觀之則其說</span>  
<span style="margin-left: 2em">不攻自破矣議者又曰松之糧誠重然册籍定于</span>  
<span style="margin-left: 2em">國初而科則實由稱土以起糧是故不可均也然不</span>  
<span style="margin-left: 2em">知洪武二十年　太祖憂天下田賦之不明遣監生</span>  
<span style="margin-left: 2em">往丈量畫圖編號悉書主名造魚鱗圖册曾無稱土</span>  
<span style="margin-left: 2em">起糧之說考之　大明會典亦所不載竊意　國初</span>  
<span style="margin-left: 2em">則壤成賦必通論天下以第其等如禹貢之成則三</span>  
<span style="margin-left: 2em">壤故稱土起糧之說所由起也若以同丘共畝之田</span>  
<span style="margin-left: 2em">而一一稱量曰某丘輕某丘重斷乎無是理也其同</span>  
<span style="margin-left: 2em">丘共畝輕重頓殊者原非稱量而有是科則也蓋</span>  
<span style="margin-left: 2em">國初版册悉因張士誠抄没租籍故有是科額觀霍</span>  
<span style="margin-left: 2em">渭厓疏張東海議自可考見且自正德以後里書那</span>  
<span style="margin-left: 2em">移等則以重作輕盡變舊册故利歸大户害歸小民</span>  
<span style="margin-left: 2em">今平其輕重均其苦樂盡洗册籍之宿弊保安困窮</span>  
<span style="margin-left: 2em">之殘民豈得爲紊舊册乎况昔蘇嘉湖三府今杭州</span>  
<span style="margin-left: 2em">等郡皆已均糧豈數郡册籍皆非　國初者乎豈其</span>  
<span style="margin-left: 2em">科則皆無輕重者乎蓋舊册多存虛弊而今均定實</span>  
<span style="margin-left: 2em">賦乃遠體　聖祖憂田賦之盛心仰贊　聖明立保</span>  
<span style="margin-left: 2em">邦之大計豈得爲紊舊册乎識者當必有定論矣議</span>  
<span style="margin-left: 2em">者又謂均糧而糧可輕若五斗雖减五升不增均之</span>  
<span style="margin-left: 2em">可也今五斗减而五升增可得爲輕乎是故不可均</span>  
<span style="margin-left: 2em">也然不知重糧多在小民輕糧多在大户其故何也</span>  
<span style="margin-left: 2em">蓋大户或减額以買田或與田以加糧或飛灑以欺</span>  
<span style="margin-left: 2em">隱或揑熟以作荒或捐價以賣糧或墾熟以漏報故</span>  
<span style="margin-left: 2em">輕糧皆歸之法當加重小民坐是數者之弊累賠虛</span>  
<span style="margin-left: 2em">糧流徙載途其重糧當輕法當輕也然于大户不樂</span>  
<span style="margin-left: 2em">而小民可安况此法一立百世永賴且查出數者之</span>  
<span style="margin-left: 2em">糧足以充槩縣之額補荒糧之數而均糧又可輕矣</span>  
<span style="margin-left: 2em">夫今蘇州各縣均糧每畝重者不過三斗幾升輕者</span>  
<span style="margin-left: 2em">不過二斗幾升吾松田糧若照得此數則國課易充</span>  
<span style="margin-left: 2em">民力易辦比舊每畝自五斗至八斗及至滿石或石</span>  
<span style="margin-left: 2em">以上者即此較量可不謂輕乎當不待辨而明矣議</span>  
<span style="margin-left: 2em">者又謂存糧之害須責里甲開報或令被害陳訴或</span>  
<span style="margin-left: 2em">查魚鱗舊册但舊册多亡責報准數徒增紛擾畢竟</span>  
<span style="margin-left: 2em">無益魯嘗見先年有司多有行者反開騙局終成畫</span>  
<span style="margin-left: 2em">餅試問父老當必有與知者若槩縣通丈按田派糧</span>  
<span style="margin-left: 2em">不勞餘力豈須此紛紛乎嗟夫均糧一議蘇守王公</span>  
<span style="margin-left: 2em">啓其端嘉湖諸公踵其後况霍渭厓責有司之良圖</span>  
<span style="margin-left: 2em">唐荆川論均則之方畧近浙省李南渠倡均糧之大</span>  
<span style="margin-left: 2em">議諸公皆我　朝名臣豈無高見而必欲爲此乎蓋</span>  
<span style="margin-left: 2em">念生民重困實由田賦不均舍此別無可救者耳魯</span>  
<span style="margin-left: 2em">病廢杜門久不問時事特以此舉興廢關松民休戚</span>  
<span style="margin-left: 2em">有不忍坐視者故不自覺其僭妄也</span>  
<span style="margin-left: 2em">附南安守東海張公弼積荒糧議　松江民瘼積荒</span>  
<span style="margin-left: 2em">爲甚民日就貧救䘏不甦者積荒滯之也田糧隱蔽</span>  
<span style="margin-left: 2em">弊日益深考覈無措者積荒汨之也此積荒一事公</span>  
<span style="margin-left: 2em">私共弊者有日矣非有司不知非　朝廷不察不得</span>  
<span style="margin-left: 2em">已而苟安之爾蓋積荒由于賦重而非制賦之本意</span>  
<span style="margin-left: 2em">稱土起糧本非輕重特籍没富家因其租籍著爲定</span>  
<span style="margin-left: 2em">額故同圩共里或止隔田塍地土無異輕重頓殊種</span>  
<span style="margin-left: 2em">重糧田者率多賠納不數年間家業蕩盡遂謀逃移</span>  
<span style="margin-left: 2em">尋至死絕田主既絕孰肯承佃所在原糧遞年里甲</span>  
<span style="margin-left: 2em">賠納賠納既久亦致逃移逃移愈多而田愈荒田愈</span>  
<span style="margin-left: 2em">荒而賠納愈多雖有良法徵科亦不免逋欠周尚書</span>  
<span style="margin-left: 2em">深痛其弊遂多增糧耗槩縣包荒故連年加耗常倍</span>  
<span style="margin-left: 2em">于正糧則雖槩受其累乃輕而可當庶得官無逋欠</span>  
<span style="margin-left: 2em">然納糧既多民能無貧乎此民日就貧救䘏不甦者</span>  
<span style="margin-left: 2em">積荒滯之也况既包荒則奸民作弊雖非積荒推入</span>  
<span style="margin-left: 2em">積荒之數鄰近熟田則侵入積荒之地積荒雖日减</span>  
<span style="margin-left: 2em">而數則日增熟田雖日增而數則日减歲適小歉又</span>  
<span style="margin-left: 2em">以熟作荒有司踏勘指積荒之地爲被災之所有司</span>  
<span style="margin-left: 2em">暫至何繇能知此田糧隱蔽弊日益深考覈無措者</span>  
<span style="margin-left: 2em">積荒汨之也私竊計之今之賦入米布銀而已米爲</span>  
<span style="margin-left: 2em">本色銀布爲折色折色輕齎民所願欲今以積荒糧</span>  
<span style="margin-left: 2em">額折木綿紗斤兩起科每升每合定例綿紗若干輳</span>  
<span style="margin-left: 2em">成布疋畸零不成疋段者各户輳織還官奏　聞定</span>  
<span style="margin-left: 2em">奪民樂輕齎又無後患争欲開墾以爲世業則原額</span>  
<span style="margin-left: 2em">不失加耗頓减隱蔽可防公私共享其利矣或謂賦</span>  
<span style="margin-left: 2em">稅舊額米荳穀麥之外惟有絲綿以綿紗起科難入</span>  
<span style="margin-left: 2em">黃册此不然絲綿雖非松江所産松江舊屬秀州即</span>  
<span style="margin-left: 2em">今嘉興府故有絲綿之額綿布雖松江所産舊亦不</span>  
<span style="margin-left: 2em">多故無其額自二三十年來松江之民多倚織布爲</span>  
<span style="margin-left: 2em">生見今正糧多折綿布以之起科入册何不可耶况</span>  
<span style="margin-left: 2em">非入册民恐後患誰肯從耶或又謂有田可墾固樂</span>  
<span style="margin-left: 2em">趨之矣其有水所蕩没等色從何而起科也此亦不</span>  
<span style="margin-left: 2em">然姑以三十萬積荒論之豈有四五萬蕩没者耶借</span>  
<span style="margin-left: 2em">使包納四五萬豈不愈于包三十萬耶但先開自首</span>  
<span style="margin-left: 2em">之條嚴示隱匿之罰選委公廉有心計者履歷覈究</span>  
<span style="margin-left: 2em">地里書手人等則無可開墾者殆亦不多矣或又謂</span>  
<span style="margin-left: 2em">加耗之多不特包荒亦兼夏稅使積荒既除夏稅亦</span>  
<span style="margin-left: 2em">另徵耶此又未然蓋夏稅所出止在瀕海高鄉地瘠</span>  
<span style="margin-left: 2em">糧輕故又加以稅以法論之固當另徵然未包納已</span>  
<span style="margin-left: 2em">前夏稅未嘗完足包納以來亦嘗另徵一年而逃者</span>  
<span style="margin-left: 2em">十六七蓋由高鄉獨被鹽司所困民窮爲甚糧稅難</span>  
<span style="margin-left: 2em">徵周尚書深憫高鄉之困欲大拯鹽司之弊亦畧施</span>  
<span style="margin-left: 2em">行掣肘莫遂因循至今夏稅包納若使鹽司之困如</span>  
<span style="margin-left: 2em">故夏稅又復另徵重困其民稅亦難足未見其利也</span>  
<span style="margin-left: 2em">魯近奉撫臺冤案專訪荒田荒糧之議前亦嘗條對</span>  
<span style="margin-left: 2em">矣近讀東海張公積荒一議深切時弊故敢先錄其</span>  
<span style="margin-left: 2em">成說復酌其時宜以備當道之採擇庶使先達救民</span>  
<span style="margin-left: 2em">之盛心可復見于今日矣公曰松江民瘼積荒爲甚</span>  
<span style="margin-left: 2em">民日就貧故救䘏不甦田糧隱蔽弊日益深故考覈</span>  
<span style="margin-left: 2em">無措斯二者誠積荒之大患而今昔所共憂者也考</span>  
<span style="margin-left: 2em">公救䘏之計則曰文襄公常加耗包賠僅足國賦而</span>  
<span style="margin-left: 2em">民益困常設法開墾量减田稅而民亦不從故公私</span>  
<span style="margin-left: 2em">所以救之乃議綿布折稅之法夫綿布今以正糧折</span>  
<span style="margin-left: 2em">之若如公議准稅入册則糧輕而無後患荒田争欲</span>  
<span style="margin-left: 2em">墾矣如是則耗糧可省包賠可免而墾荒可補原額</span>  
<span style="margin-left: 2em">謂非救民之良策乎然充公之所未及召統民歸業</span>  
<span style="margin-left: 2em">免追積逋徵開墾田稅姑限三年給免差下帖使專</span>  
<span style="margin-left: 2em">耕耨庶幾救䘏可甦而積荒豈足患哉復考公救弊</span>  
<span style="margin-left: 2em">之法則曰原非積荒而推入積荒之數鄰近熟田而</span>  
<span style="margin-left: 2em">侵入積荒地之故公思所以覈之乃議自首嚴罰之</span>  
<span style="margin-left: 2em">策夫自首固所以開之更如公議選官躬勘則弊革</span>  
<span style="margin-left: 2em">而田無隱蔽積荒不能混矣如此則國有常賦民有</span>  
<span style="margin-left: 2em">常稅而奸謀自無所容謂非救時之要法乎然推公</span>  
<span style="margin-left: 2em">之所未至舉丈量之政則荒熟自判嚴親覆之令則</span>  
<span style="margin-left: 2em">功罪自見公賞罰之典則勸戒自昭庶幾宿弊盡消</span>  
<span style="margin-left: 2em">而積荒豈足汨哉再觀公議夏稅不可另徵鹽司所</span>  
<span style="margin-left: 2em">當大拯皆憂患愛民至意但不知今時尚然否也</span>
