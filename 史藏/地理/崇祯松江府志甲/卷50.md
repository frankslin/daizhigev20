## 崇祯松江府志卷之五十　寺院上

<span style="margin-left: 3em">寺院</span>  
<span style="margin-left: 1em">浮屠老子之宫金碧照天钟鼓动地独吾</span>  
<span style="margin-left: 1em">先师严则不然正以淡胜之耳顾老有犹龙之称僧有</span>  
<span style="margin-left: 1em">三代威仪之叹即孔程且许之人其人而庐其居昌黎</span>  
<span style="margin-left: 1em">子得无过激乎神道设教存而不论可也志寺观</span>  
<span style="margin-left: 2em">旧志称丛林皆洪武二十四年归并诸小庵院而名</span>  
<span style="margin-left: 2em">三十五年俱令复旧有反盛于丛林者今仍附丛林</span>  
<span style="margin-left: 2em">以存旧制道观亦如之</span>  
<span style="margin-left: 1em">华亭丛林　新隶青浦附</span>  
<span style="margin-left: 1em">南禅寺在府学东宋崇宁中张头陀卜筑于此凿地得</span>  
<span style="margin-left: 2em">住世罗汉像邑人异之遂为施水庵僧名普愿请额</span>  
<span style="margin-left: 2em">于朝绍兴二十九年赐名演教禅院后改今额元大</span>  
<span style="margin-left: 2em">德间中书马左丞榜其门曰南山胜地中有绿筠楼</span>  
<span style="margin-left: 2em">雷音堂　国朝为在城诸禅之冠僧纲司治焉归并</span>  
<span style="margin-left: 2em">寺一庵二</span>  
<span style="margin-left: 2em">翰林学士阎复南山胜地记畧　松江府南禅寺为</span>  
<span style="margin-left: 2em">在城诸禅冠唐元和间船子和尚过而合爪曰此地</span>  
<span style="margin-left: 2em">形势最胜愿来兴福时未省其语至宋崇宁有头陀</span>  
<span style="margin-left: 2em">张氏即其地而庐焉掘井得罗汉像十有六颇异之</span>  
<span style="margin-left: 2em">后以掩骼赏不受换牒为僧实名普愿而船子愿来</span>  
<span style="margin-left: 2em">兴福之言始验愿虽草创数椽久废岁在绍兴得俊</span>  
<span style="margin-left: 2em">公而复兴请于朝为寺南渡百余年寺门终未光显</span>  
<span style="margin-left: 2em">入元逾三十年住山如寄驿宝公来住此山樽浮苴</span>  
<span style="margin-left: 2em">漏仅仅完备每出人是门徘徊四顾西则儒老二宫</span>  
<span style="margin-left: 2em">颉颃争先寺敛然退后若有物压其首东则墙垣塞</span>  
<span style="margin-left: 2em">路斗绝筑底若有物障其目南则断流如线过桥民</span>  
<span style="margin-left: 2em">居栉比隙不通轨若有物横其臆思欲挈山门而东</span>  
<span style="margin-left: 2em">之规模定在胸中凡三四年始克就绪旧有大石龟</span>  
<span style="margin-left: 2em">蹒跚水涘辇致其左背负崇墉若鼇戴山而前抃也</span>  
<span style="margin-left: 2em">入门不数步东南筑小土山植松其上若虎伏林而</span>  
<span style="margin-left: 2em">旁卫也兑水来其西巽风避其南缭以矮墙夹以佳</span>  
<span style="margin-left: 2em">植委蛇曲折渐入禅境见者生欢喜心咸谓布置之</span>  
<span style="margin-left: 2em">巧独未有颜其门者大德中宝公辄以南山福地四</span>  
<span style="margin-left: 2em">字乞书于中书右丞马公而船子此地最胜之言又</span>  
<span style="margin-left: 2em">验夫地不自胜因人而胜向也行即面墙入即窥室</span>  
<span style="margin-left: 2em">门外曾不容数骑一转移间繇南而东举目即见山</span>  
<span style="margin-left: 2em">门繇门而入林影阴翳若行诘曲山径间才见有寺</span>  
<span style="margin-left: 2em">地虽胜因人而益胜固无怪也独怪船子和尚距今</span>  
<span style="margin-left: 2em">四百余年前后如此其验安知昔之愿今之宝非船</span>  
<span style="margin-left: 2em">子身后身耶</span>  
<span style="margin-left: 2em">罗汉井<sub class="note-yuan">宋崇宁中张头陀所凿也泉甘而冽越四百四十年嘉靖丙申竹庵上人浚而甃之都刚一峰德滨为之铭曰井之升唯水泠泠止不波兮使我心平养之不穷兮勿赢其瓶终古不改兮同其清</sub></span>  
<span style="margin-left: 2em">定僧塔<sub class="note-yuan">定僧不知何代人将示寂时觅巨缸二端坐入定合两口而植树表之树今大十围盖几百年矣达观师指寺前树曰此下有定僧众不知解已而居人何姓者穿圊深五尺许忽得石板发之见满缸皆乱发其下果坐一僧见者骇异亟闭之寺僧如玘字良玉禅理精微尝作纸扇偈呈仪部山月俞公允见重于名公尤为周文襄礼重时钱文通十八岁偶过玘公文襄适至钱迫避榻后文襄顾见曰何人玘以钱对文襄奇其才荐之应举自是遂联第而去</sub></span>  
<span style="margin-left: 2em">积庆禅寺本名坐化庵在府东南龙门寺相望元至</span>  
<span style="margin-left: 2em">正辛巳邑人陈源为庆禅师舍宅建庆坐化肉身在</span>  
<span style="margin-left: 2em">焉庵因以名正统丁卯僧惠明请今额其后福昭等</span>  
<span style="margin-left: 2em">皆相继营建焉</span>  
<span style="margin-left: 2em"><sub class="note-yuan">董其昌建禅堂疏积庆寺后有宅一区是先伯之故庐本给孤之初地厥考肯堂厥子搆人都非矣南方入定北方起僧其病诸虽污泥不染莲花而秽土难参香积每梵钟之到枕似得皈依或勃溪之度垣殊妨晏坐非维摩抟取三千界乃歌利割截无边身云水裹足而不来居士攒眉而便去必有布金之缘如水投水庶成舍宅之事以空还空庶子首作金汤素庵因而荷担愿我同志咸广檀门捐彼杖头阿堵余展此袈裟一角地丛林废丛林兴衣钵宛尔招提游招提宿莲社开乎又疏江以南列刹相望未有称坐化庵者惟吾郡积庆寺元寿堂祖师之肉身在焉是以得名自元至今三百余年矣夫以地水火风之幻躯灵老岿若而晏坐经行之浄域风雨漂摇岂寿师护法弘誓之愿乎宿桑非至人所恋而苃树亦后代遐思瞻祖容者既作希有想皈敬想则此寺之栴檀瑞像即师之七宝台此寺之苔藓间房即祖之方丈室忍视其日就倾圮而使诗人有禅宫亦销歇之篇与世尊亦尘埃之叹耶且其求易供其出易核无王珣舍武丘之千间厐蕴掷湘流之百万证明功德有寿堂祖师良足起信非若他方兴作始则建鼓而招后乃空华不实敢以谕于檀施者</sub></span>  
<span style="margin-left: 2em">四十八愿庵元僧宝灯山建府南六十里</span>  
<span style="margin-left: 2em">仁寿庵元僧修建府南六十里</span>  
<span style="margin-left: 1em">北禅寺在府东北城内宋绍兴间僧法宁建元毁洪武</span>  
<span style="margin-left: 2em">中僧慧海重建万历丁巳年重修郡人钱龙锡有疏</span>  
<span style="margin-left: 2em">旧志领归并院三</span>  
<span style="margin-left: 2em">沈恺重修寺记畧　马𡺐寺居郡城东北故名北禅</span>  
<span style="margin-left: 2em">宋绍兴间僧法宁自沂州马𡺐山浄居寺航海至青</span>  
<span style="margin-left: 2em">龙有章氏往迎至此发地得古碑云大唐禅寺又得</span>  
<span style="margin-left: 2em">金刚天王像因建寺焉县令柳君约请今名元毁于</span>  
<span style="margin-left: 2em">兵至洪武中僧慧海重建有大雄殿天王殿金刚殿</span>  
<span style="margin-left: 2em">又有法堂有方丈有放生池有施食台至廊庑斋室</span>  
<span style="margin-left: 2em">靡不毕具其地宽衍悠邃岁时有司祝釐往往于此</span>  
<span style="margin-left: 2em">遂为吾松一大丛林岁久雨凌风震诸梵宇以次倾</span>  
<span style="margin-left: 2em">圮祝圣者亦旋徙普照寺所存者仅一大殿与二三</span>  
<span style="margin-left: 2em">古树非复昔之马𡺐矣继之嘉靖甲寅东夷不靖有</span>  
<span style="margin-left: 2em">司辄于此驻兵戎马蹂践鞠为蓁莽几半无寺赖僧</span>  
<span style="margin-left: 2em">是荣薙荒埋秽刜奥萃良饰而修之稍稍重葺会僧</span>  
<span style="margin-left: 2em">雪庵梵行修洁来自西蜀慨然有兴坠举废之志坠</span>  
<span style="margin-left: 2em">绪中兴皆自今日始余草堂去寺不百步禅居密迩</span>  
<span style="margin-left: 2em">随缘听梵可朝夕往当亦不作生客不待雪庵之请</span>  
<span style="margin-left: 2em">而乐为之书</span>  
<span style="margin-left: 2em"><sub class="note-yuan">莫是龙募建斋堂廊庑疏金仙建化启第一之真乗玉偈演音普大千之妙利佛性徧问于沙界示现无方法轮旋转于毫端感通如在诸祖传正法眼藏众生祈大甘露四吾松马𡺐禅寺迹纪唐年名延宋代表异绍兴之季具足之相俨然饰新洪武之初庄严之观蔚备庋兹僧腊屡有废兴慨此神区渐成颓圮会蜀僧昌昺卓锡本寺功创锄荒而守僧是荣矢心诸天愿弘肯称窃念垣墉甫就仅驰狐兔之踪金碧未施谁识象龙之迹将使梵天已倾而再补庶令慧日既昃而重悬缘隙地以为堂皈依三宝傍香台而结宇延供十方庑列东西拥化城于初地堦分南北开觉路于昏衢堪游白足之禅悉作黄金之布用资广募方办鸠工是以仰叩上贤敷同喜舍贵者护法首开方便之门富者输财共发菩提之愿则阴来双树尽是慈云而香散千花溥沾法雨时隆庆戊辰孟夏朔日</sub></span>  
<span style="margin-left: 2em">北禅双树<sub class="note-yuan">陆树声叙云马𡺐古刹岁久渐圮地为居民侵蚀者半独殿前双树䇄立度僧腊无算兵后官司取材议及焉余护存之他日过寺寺僧是荣引余读旧碑出双树下顾余曰是木向微公几已化去今清阴宛在实仗公再来缘愿一言贻山门因题识庑壁以戒刍牧岁远香台半劫灰断碑遗迹掩蒿莱回看双树闻僧语此日清阴是再来清源号雪泉系华亭陆氏子母王氏七岁学经誓愿出家投北禅寺坎峰荣公为师祝发蜀僧雪庵倡举禅堂遇牛山高峰禅师挂搭源晨夕请益蒙师开示陆宗伯复留天育禅师于寺源游南海见大士现身发心参学投留都无极金台东岩等席又参辨融沧溟二师诸老宿指示不二随至牛山入炼磨场大惫钳锤煅炼死生归结观音阁晏坐其中六十余而化天育禅师付雪泉语云先佛世尊五时设化大事因缘将毕末后拈花示众以正法眼藏涅槃妙心付嘱摩诃迦叶号最上乘迦叶廿六世而传之菩提达摩达摩五嗣而传之能师能之所传则两岳青原至黄蘗断际而法分五派唯临济一宗最为殷盛其传灯之续不能笔尽繇是而至国朝东传无际无际传繁昌宝月宝月传之吾师万松老人今来以此事付惠才才今六十有余俄四大不我摄而向上大事诸佛慧命将付嘱有在既而得可与者四人时在华亭之马𡺐相侍历岁以久中间唯清源禅人为与老僧有啐啄分源本华亭陆氏子母王氏生而瓌敏随父授持金刚般若至若见诸相非相即见如来处一时空荡觉习气稍断然未获大休歇去复于伏牛高峰常公前请益念佛话头久久提撕止得豁然初源自龆年出家于马𡺐投礼坎峰荣公为师其禀戒有严持经无相历讲有宗见性有眼禅流中磊磊落落者其所呈解颂及行脚事吾耄矣且行期在速兼不能以文字语言叨叨络索他后以吾师万松之道勿使坠滞务在灯灯相续手手相付与三世诸佛一鼻孔作嘘吸可也末后一段剩语作偈曰一偈如雷透祖机总非穿凿涉离微当人直下承师肯秋晚丛林赖有枝</sub></span>  
<span style="margin-left: 2em">本一禅院妙明桥西北旧北道堂也元至元末赵道</span>  
<span style="margin-left: 2em">渊为僧易今名</span>  
<span style="margin-left: 2em">杨维祯记畧　本一庵者宋乾道中邑人沈氏所建</span>  
<span style="margin-left: 2em">也岁久业废至元间昌公月麓复侵田撤去旧屋而</span>  
<span style="margin-left: 2em">一新之又虑后之嗣者或相逾越也定为甲乙使主</span>  
<span style="margin-left: 2em">庵事延祐昌寂其徒存礼惧己弗克肩事求其才且</span>  
<span style="margin-left: 2em">贤者主焉时善应庵空林果公行业峻茂有声丛林</span>  
<span style="margin-left: 2em">间礼延置之推居己上事无巨细悉归焉果公度弟</span>  
<span style="margin-left: 2em">子曰浄开浄誉善实等凡十人乃命开以师事己者</span>  
<span style="margin-left: 2em">视礼四方参扣之士闻果公之贤縢履而至者踵相</span>  
<span style="margin-left: 2em">接也顾旧屋褊隘无以馆学者繇是拓易旧制中为</span>  
<span style="margin-left: 2em">殿立大雄氏像其旁若僧堂筹室山门玄武之殿燕</span>  
<span style="margin-left: 2em">居庖湢之屋靡不完具乃题曰本一院果寂开以次</span>  
<span style="margin-left: 2em">主席开之后誉实继之夫松值兵燹之后求梵刹于</span>  
<span style="margin-left: 2em">城内外不啻百余区匪夷为焦土则穿漏为四虚之</span>  
<span style="margin-left: 2em">亭独本一者岿然于瓦砾场中椽瓦不动人以为祖</span>  
<span style="margin-left: 2em">师愿力所致而亦誉实之材干山门柱石也予复喻</span>  
<span style="margin-left: 2em">其徒曰农之为田也其始也垦治之播种之继以耨</span>  
<span style="margin-left: 2em">耘之灌溉之则宜其田愈腴而愈大有成利之获焉</span>  
<span style="margin-left: 2em">今昌之垦治播种亦劳矣果之耨耘灌溉又勤矣腴</span>  
<span style="margin-left: 2em">之大之而收秋获之功后之人享有成利者宜思其</span>  
<span style="margin-left: 2em">所繇来哉果字空林云间人尝参天目中峰本禅师</span>  
<span style="margin-left: 2em">机锋相直遂超玄窟实字性空亦云间人通内外典</span>  
<span style="margin-left: 2em">及世谛人称兰奢云</span>  
<span style="margin-left: 2em">幻住山房<sub class="note-yuan">大雄殿后禅堂之左室也中峰卓锡本一院与月麓昌公公弟孟𫖯讲道小憇之所中峰在处结茅皆名幻住遂以题之禅堂湮没应教已久万历壬辰癸巳间陆文定唐文恪与今董宗伯重复斯堂分别禅应有僧广澄号湛源者主堂事</sub></span>  
<span style="margin-left: 2em">双松堂<sub class="note-yuan">在院之西林木深沉即月公休憩地</sub></span>
