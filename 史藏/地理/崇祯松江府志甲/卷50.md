## 崇禎松江府志卷之五十　寺院上

<span style="margin-left: 3em">寺院</span>  
<span style="margin-left: 1em">浮屠老子之宫金碧照天鐘鼓動地獨吾</span>  
<span style="margin-left: 1em">先師嚴則不然正以淡勝之耳顧老有猶龍之稱僧有</span>  
<span style="margin-left: 1em">三代威儀之嘆即孔程且許之人其人而廬其居昌黎</span>  
<span style="margin-left: 1em">子得無過激乎神道設教存而不論可也志寺觀</span>  
<span style="margin-left: 2em">舊志稱叢林皆洪武二十四年歸併諸小菴院而名</span>  
<span style="margin-left: 2em">三十五年俱令復舊有反盛于叢林者今仍附叢林</span>  
<span style="margin-left: 2em">以存舊制道觀亦如之</span>  
<span style="margin-left: 1em">華亭叢林　新隸青浦附</span>  
<span style="margin-left: 1em">南禪寺在府學東宋崇寧中張頭陀卜築於此鑿地得</span>  
<span style="margin-left: 2em">住世羅漢像邑人異之遂爲施水菴僧名普願請額</span>  
<span style="margin-left: 2em">于朝紹興二十九年賜名演教禪院後改今額元大</span>  
<span style="margin-left: 2em">德間中書馬左丞榜其門曰南山勝地中有綠筠樓</span>  
<span style="margin-left: 2em">雷音堂　國朝爲在城諸禪之冠僧綱司治焉歸併</span>  
<span style="margin-left: 2em">寺一菴二</span>  
<span style="margin-left: 2em">翰林學士閻復南山勝地記畧　松江府南禪寺爲</span>  
<span style="margin-left: 2em">在城諸禪冠唐元和間船子和尚過而合爪曰此地</span>  
<span style="margin-left: 2em">形勢最勝願來興福時未省其語至宋崇寧有頭陀</span>  
<span style="margin-left: 2em">張氏即其地而廬焉掘井得羅漢像十有六頗異之</span>  
<span style="margin-left: 2em">後以掩骼賞不受换牒爲僧實名普願而船子願來</span>  
<span style="margin-left: 2em">興福之言始驗願雖草創數椽久廢歲在紹興得俊</span>  
<span style="margin-left: 2em">公而復興請于朝爲寺南渡百餘年寺門終未光顯</span>  
<span style="margin-left: 2em">入元踰三十年住山如寄驛寶公來住此山樽浮苴</span>  
<span style="margin-left: 2em">漏僅僅完備每出人是門徘徊四顧西則儒老二宫</span>  
<span style="margin-left: 2em">頡頏争先寺斂然退後若有物壓其首東則牆垣塞</span>  
<span style="margin-left: 2em">路斗絶築底若有物障其目南則斷流如綫過橋民</span>  
<span style="margin-left: 2em">居櫛比隙不通軌若有物横其臆思欲挈山門而東</span>  
<span style="margin-left: 2em">之規模定在胸中凡三四年始克就緒舊有大石龜</span>  
<span style="margin-left: 2em">蹣跚水涘輦致其左背負崇墉若鼇戴山而前抃也</span>  
<span style="margin-left: 2em">入門不數步東南築小土山植松其上若虎伏林而</span>  
<span style="margin-left: 2em">旁衛也兑水來其西巽風避其南繚以矮牆夾以佳</span>  
<span style="margin-left: 2em">植委蛇曲折漸入禪境見者生歡喜心咸謂布置之</span>  
<span style="margin-left: 2em">巧獨未有顔其門者大德中寶公輒以南山福地四</span>  
<span style="margin-left: 2em">字乞書于中書右丞馬公而船子此地最勝之言又</span>  
<span style="margin-left: 2em">驗夫地不自勝因人而勝向也行即面牆入即窺室</span>  
<span style="margin-left: 2em">門外曾不容數騎一轉移間繇南而東舉目即見山</span>  
<span style="margin-left: 2em">門繇門而入林影陰翳若行詰曲山徑間才見有寺</span>  
<span style="margin-left: 2em">地雖勝因人而益勝固無怪也獨怪船子和尚距今</span>  
<span style="margin-left: 2em">四百餘年前後如此其驗安知昔之願今之寶非船</span>  
<span style="margin-left: 2em">子身後身耶</span>  
<span style="margin-left: 2em">羅漢井<sub class="note-yuan">宋崇寧中張頭陀所鑿也泉甘而冽越四百四十年嘉靖丙申竹菴上人浚而甃之都剛一峯德濱爲之銘曰井之陞唯水泠泠止不波兮使我心平養之不窮兮勿贏其瓶終古不改兮同其清</sub></span>  
<span style="margin-left: 2em">定僧塔<sub class="note-yuan">定僧不知何代人將示寂時覓巨缸二端坐入定合兩口而植樹表之樹今大十圍蓋幾百年矣達觀師指寺前樹曰此下有定僧衆不知解已而居人何姓者穿圊深五尺許忽得石板發之見滿缸皆亂髮其下果坐一僧見者駭異亟閉之寺僧如玘字良玉禪理精微嘗作紙扇偈呈儀部山月俞公允見重於名公尤爲周文襄禮重時錢文通十八歲偶過玘公文襄適至錢迫避榻後文襄顧見曰何人玘以錢對文襄奇其才薦之應舉自是遂聯第而去</sub></span>  
<span style="margin-left: 2em">積慶禪寺本名坐化菴在府東南龍門寺相望元至</span>  
<span style="margin-left: 2em">正辛巳邑人陳源爲慶禪師捨宅建慶坐化肉身在</span>  
<span style="margin-left: 2em">焉菴因以名正統丁卯僧惠明請今額其後福昭等</span>  
<span style="margin-left: 2em">皆相繼營建焉</span>  
<span style="margin-left: 2em"><sub class="note-yuan">董其昌建禪堂疏積慶寺後有宅一區是先伯之故廬本給孤之初地厥考肯堂厥子搆人都非矣南方入定北方起僧其病諸雖污泥不染蓮花而穢土難參香積每梵鐘之到枕似得皈依或勃谿之度垣殊妨晏坐非維摩摶取三千界乃歌利割截無邊身雲水裹足而不來居士攢眉而便去必有布金之緣如水投水庶成捨宅之事以空還空庶子首作金湯素菴因而荷擔願我同志咸廣檀門捐彼杖頭阿堵餘展此袈裟一角地叢林廢叢林興衣鉢宛爾招提游招提宿蓮社開乎又疏江以南列刹相望未有稱坐化菴者惟吾郡積慶寺元壽堂祖師之肉身在焉是以得名自元至今三百餘年矣夫以地水火風之幻軀靈老巋若而晏坐經行之浄域風雨漂摇豈壽師護法弘誓之願乎宿桑非至人所戀而苃樹亦後代遐思瞻祖容者既作希有想皈敬想則此寺之栴檀瑞像即師之七寶臺此寺之苔蘚間房即祖之方丈室忍視其日就傾圮而使詩人有禪宫亦銷歇之篇與世尊亦塵埃之嘆耶且其求易供其出易核無王珣捨武丘之千間龎藴擲湘流之百萬證明功德有壽堂祖師良足起信非若他方興作始則建鼓而招後乃空華不實敢以諭於檀施者</sub></span>  
<span style="margin-left: 2em">四十八願菴元僧寶燈山建府南六十里</span>  
<span style="margin-left: 2em">仁壽菴元僧修建府南六十里</span>  
<span style="margin-left: 1em">北禪寺在府東北城內宋紹興間僧法寧建元燬洪武</span>  
<span style="margin-left: 2em">中僧慧海重建萬曆丁巳年重修郡人錢龍錫有疏</span>  
<span style="margin-left: 2em">舊志領歸併院三</span>  
<span style="margin-left: 2em">沈愷重修寺記畧　馬𡺐寺居郡城東北故名北禪</span>  
<span style="margin-left: 2em">宋紹興間僧法寧自沂州馬𡺐山浄居寺航海至青</span>  
<span style="margin-left: 2em">龍有章氏往迎至此發地得古碑云大唐禪寺又得</span>  
<span style="margin-left: 2em">金剛天王像因建寺焉縣令柳君約請今名元燬于</span>  
<span style="margin-left: 2em">兵至洪武中僧慧海重建有大雄殿天王殿金剛殿</span>  
<span style="margin-left: 2em">又有法堂有方丈有放生池有施食臺至廊廡齋室</span>  
<span style="margin-left: 2em">靡不畢具其地寬衍悠邃歲時有司祝釐往往於此</span>  
<span style="margin-left: 2em">遂爲吾松一大叢林歲久雨凌風震諸梵宇以次傾</span>  
<span style="margin-left: 2em">圮祝聖者亦旋徙普照寺所存者僅一大殿與二三</span>  
<span style="margin-left: 2em">古樹非復昔之馬𡺐矣繼之嘉靖甲寅東夷不靖有</span>  
<span style="margin-left: 2em">司輒於此駐兵戎馬蹂踐鞠爲蓁莽幾半無寺賴僧</span>  
<span style="margin-left: 2em">是榮薙荒埋穢刜奥萃良飾而修之稍稍重葺會僧</span>  
<span style="margin-left: 2em">雪菴梵行修潔來自西蜀慨然有興墜舉廢之志墜</span>  
<span style="margin-left: 2em">緒中興皆自今日始余草堂去寺不百步禪居密邇</span>  
<span style="margin-left: 2em">隨緣聽梵可朝夕往當亦不作生客不待雪菴之請</span>  
<span style="margin-left: 2em">而樂爲之書</span>  
<span style="margin-left: 2em"><sub class="note-yuan">莫是龍募建齋堂廊廡疏金仙建化啓第一之真乗玉偈演音普大千之妙利佛性徧問於沙界示現無方法輪旋轉于毫端感通如在諸祖傳正法眼藏衆生祈大甘露四吾松馬𡺐禪寺蹟紀唐年名延宋代表異紹興之季具足之相儼然飾新洪武之初莊嚴之觀蔚備庋兹僧臘屢有廢興慨此神區漸成頽圮會蜀僧昌昺卓錫本寺功創鋤荒而守僧是榮矢心諸天願弘肯稱竊念垣墉甫就僅馳狐兔之踪金碧未施誰識象龍之跡將使梵天已傾而再補庶令慧日既昃而重懸緣隙地以爲堂皈依三寶傍香臺而結宇延供十方廡列東西擁化城于初地堦分南北開覺路于昏衢堪游白足之禪悉作黃金之布用資廣募方辦鳩工是以仰叩上賢敷同喜捨貴者護法首開方便之門富者輸財共發菩提之願則陰來雙樹盡是慈雲而香散千花溥沾法雨時隆慶戊辰孟夏朔日</sub></span>  
<span style="margin-left: 2em">北禪雙樹<sub class="note-yuan">陸樹聲敘云馬𡺐古刹歲久漸圮地爲居民侵蝕者半獨殿前雙樹䇄立度僧臘無算兵後官司取材議及焉余護存之他日過寺寺僧是榮引余讀舊碑出雙樹下顧余曰是木向微公幾已化去今清陰宛在實仗公再來緣願一言貽山門因題識廡壁以戒芻牧歲遠香臺半劫灰斷碑遺蹟掩蒿萊回看雙樹聞僧語此日清陰是再來清源號雪泉係華亭陸氏子母王氏七歲學經誓願出家投北禪寺坎峯榮公爲師祝髮蜀僧雪菴倡舉禪堂遇牛山高峯禪師掛搭源晨夕請益蒙師開示陸宗伯復留天育禪師於寺源游南海見大士現身發心參學投留都無極金臺東巖等席又參辨融滄溟二師諸老宿指示不二隨至牛山入鍊磨場大憊鉗鎚煅煉死生歸結觀音閣晏坐其中六十餘而化天育禪師付雪泉語云先佛世尊五時設化大事因緣將畢末後拈花示衆以正法眼藏涅槃妙心付囑摩訶迦葉號最上乘迦葉廿六世而傳之菩提達摩達摩五嗣而傳之能師能之所傳則兩嶽青原至黃蘗斷際而法分五派唯臨濟一宗最爲殷盛其傳燈之續不能筆盡繇是而至國朝東傳無際無際傳繁昌寶月寶月傳之吾師萬松老人今來以此事付惠才才今六十有餘俄四大不我攝而向上大事諸佛慧命將付囑有在既而得可與者四人時在華亭之馬𡺐相侍歷歲以久中間唯清源禪人爲與老僧有啐啄分源本華亭陸氏子母王氏生而瓌敏隨父授持金剛般若至若見諸相非相即見如來處一時空蕩覺習氣稍斷然未獲大休歇去復於伏牛高峯常公前請益念佛話頭久久提撕止得豁然初源自齠年出家於馬𡺐投禮坎峯榮公爲師其稟戒有嚴持經無相歷講有宗見性有眼禪流中磊磊落落者其所呈解頌及行脚事吾耄矣且行期在速兼不能以文字語言叨叨絡索他後以吾師萬松之道勿使墜滯務在燈燈相續手手相付與三世諸佛一鼻孔作嘘吸可也末後一段剩語作偈曰一偈如雷透祖機總非穿鑿涉離微當人直下承師肯秋晚叢林賴有枝</sub></span>  
<span style="margin-left: 2em">本一禪院妙明橋西北舊北道堂也元至元末趙道</span>  
<span style="margin-left: 2em">淵爲僧易今名</span>  
<span style="margin-left: 2em">楊維禎記畧　本一菴者宋乾道中邑人沈氏所建</span>  
<span style="margin-left: 2em">也歲久業廢至元間昌公月麓復侵田撤去舊屋而</span>  
<span style="margin-left: 2em">一新之又慮後之嗣者或相踰越也定爲甲乙使主</span>  
<span style="margin-left: 2em">菴事延祐昌寂其徒存禮懼己弗克肩事求其才且</span>  
<span style="margin-left: 2em">賢者主焉時善應菴空林果公行業峻茂有聲叢林</span>  
<span style="margin-left: 2em">間禮延置之推居己上事無鉅細悉歸焉果公度弟</span>  
<span style="margin-left: 2em">子曰浄開浄譽善實等凡十人乃命開以師事己者</span>  
<span style="margin-left: 2em">視禮四方參扣之士聞果公之賢縢履而至者踵相</span>  
<span style="margin-left: 2em">接也顧舊屋褊隘無以館學者繇是拓易舊制中爲</span>  
<span style="margin-left: 2em">殿立大雄氏像其旁若僧堂籌室山門玄武之殿燕</span>  
<span style="margin-left: 2em">居庖湢之屋靡不完具乃題曰本一院果寂開以次</span>  
<span style="margin-left: 2em">主席開之後譽實繼之夫松值兵燹之後求梵刹于</span>  
<span style="margin-left: 2em">城內外不啻百餘區匪夷爲焦土則穿漏爲四虛之</span>  
<span style="margin-left: 2em">亭獨本一者巋然於瓦礫場中椽瓦不動人以爲祖</span>  
<span style="margin-left: 2em">師願力所致而亦譽實之材幹山門柱石也予復喻</span>  
<span style="margin-left: 2em">其徒曰農之爲田也其始也墾治之播種之繼以耨</span>  
<span style="margin-left: 2em">耘之灌溉之則宜其田愈腴而愈大有成利之獲焉</span>  
<span style="margin-left: 2em">今昌之墾治播種亦勞矣果之耨耘灌溉又勤矣腴</span>  
<span style="margin-left: 2em">之大之而收秋穫之功後之人享有成利者宜思其</span>  
<span style="margin-left: 2em">所繇來哉果字空林雲間人嘗參天目中峯本禪師</span>  
<span style="margin-left: 2em">機鋒相直遂超玄窟實字性空亦雲間人通內外典</span>  
<span style="margin-left: 2em">及世諦人稱蘭奢云</span>
