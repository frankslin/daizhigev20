## 崇祯松江府志卷之三十九　人物四（国朝贤达）

<span style="margin-left: 3em">国朝贤达<sub class="note-yuan">四</sub></span>  
<span style="margin-left: 1em">张弼字汝弼华亭人成化丙戌进士拜兵部主事转员</span>  
<span style="margin-left: 1em">外郎时罗伦以言事忤大臣去国弼慷慨作诗送之出</span>  
<span style="margin-left: 1em">知南安南安当两广要冲亡命啸聚数为民害弼设方</span>  
<span style="margin-left: 1em">畧平之大庾岭旅客赍装民素借雇直之利后为南雄</span>  
<span style="margin-left: 1em">桀黠所侵遂失业贫瘠弼请江右粤东二藩与中分著</span>  
<span style="margin-left: 1em">为令岭路故狭峻行者病之取商税甃石路三十里又</span>  
<span style="margin-left: 1em">夷小茆岭之砾崖难行者凿过路滩之舟航难济者筑</span>  
<span style="margin-left: 1em">龙潭水之歘蒙横溢者障谢行头何公塘通济街之春</span>  
<span style="margin-left: 1em">涨为梗者万民利之又立射圃躬亲教阅毁淫祠六百</span>  
<span style="margin-left: 1em">余所新道源书院祠周程三先生辟岭寺祀张九龄起</span>  
<span style="margin-left: 1em">江东神阁祀苏子瞻刘元城辈立蒙川馆于东山造铁</span>  
<span style="margin-left: 1em">汉楼墨君阁于宝界寺立吟风弄月台于郡城皆景仰</span>  
<span style="margin-left: 1em">先哲之意归之日老稚攀辕鼓棹送者载途建祠肖像</span>  
<span style="margin-left: 1em">于金莲山归三年卒年六十三弼襟度夷旷而敦尚行</span>  
<span style="margin-left: 1em">履动以风节自持虽谈论间杂诙谐往往以理胜诗文</span>  
<span style="margin-left: 1em">成一家言及草书狂翰醉墨流落人间虽海外之国购</span>  
<span style="margin-left: 1em">为异宝所刻有鹤城东海诸集传子若孙历代科名不</span>  
<span style="margin-left: 1em">绝</span>  
<span style="margin-left: 2em">公初为兵部郎数以直言忤当路遂出守南安入觐</span>  
<span style="margin-left: 2em">至京谒李东阳阁老阍人辞焉东海题其几云始知</span>  
<span style="margin-left: 2em">东阁先生贵不放南安太守参拂袖竟出李公追悔</span>  
<span style="margin-left: 2em">弗及公休致既早子皆成名无一事累心周德中称</span>  
<span style="margin-left: 2em">为神仙太守</span>  
<span style="margin-left: 1em">张骏字天骏华亭人十岁能诗长工书法与东海齐名</span>  
<span style="margin-left: 1em">时号二张景泰癸酉乡荐成化初选中书舍人直文华</span>  
<span style="margin-left: 1em">殿应制多称旨赏赉极优　孝庙命写风入松词拜羊</span>  
<span style="margin-left: 1em">酒之赐升太常少卿再晋光禄卿凡修诗海珠玑成</span>  
<span style="margin-left: 1em">诏进官一级考最荫一孙后以足疾上章乞休命乘传</span>  
<span style="margin-left: 1em">归逾年即家以原官起特免朝参仍令于文华供事会</span>  
<span style="margin-left: 1em">进呈通鉴纂要命骏等再誊晋礼部尚书时公年已八</span>  
<span style="margin-left: 1em">十复乞致仕命乘传岁给舆廪卒赐祭骏性笃孝奉节</span>  
<span style="margin-left: 1em">母胡夫人惟谨其叔玑珩相继殀亡妻瞿氏杨氏少年</span>  
<span style="margin-left: 1em">孀居公皆养事慰藉之竟全其节三母皆膺旌典称三</span>  
<span style="margin-left: 1em">节之门裔孙翼轸登万历戊戌进士官广东宪副</span>  
<span style="margin-left: 1em">柳淳字文粹华亭人少从舅氏袁公恺受壁经登成化</span>  
<span style="margin-left: 1em">丙戌进士授行人选监察御史巡畿内擒渠贼刘钊畿</span>  
<span style="margin-left: 1em">内就宁按西蜀成都多火灾民悉置囊箧户外罔顾厥</span>  
<span style="margin-left: 1em">居淳察而禁之民始安堵擢贵州宪副适乌撒等卫岁</span>  
<span style="margin-left: 1em">饥诸司议救荒淳以发粟为急躬诣其境验口赈给赖</span>  
<span style="margin-left: 1em">以全活者数万人转山东按察使时黄河为兖境患淳</span>  
<span style="margin-left: 1em">协谋赞襄患平论功升右布政使以内艰归哀毁逾礼</span>  
<span style="margin-left: 1em">而卒年六十有五淳公亮廉谨饬孝友睦族尤工真草</span>  
<span style="margin-left: 1em">书</span>  
<span style="margin-left: 1em">张诰字汝钦华亭人成化丙戌进士改庶吉士授御史</span>  
<span style="margin-left: 1em">按湖广升广东副使改四川寻升按察使弘治初岁饥</span>  
<span style="margin-left: 1em">诰请截荆襄卫兑运又发库银易米得数十余万石随</span>  
<span style="margin-left: 1em">在赈贷所全活颇多升贵州左布政未几升右副都御</span>  
<span style="margin-left: 1em">史抚云南平疑狱谕乱夷得抚绥体木邦孟密二部连</span>  
<span style="margin-left: 1em">兵不解诰檄诸道练兵为必讨计皆惧而自戢朝廷嘉</span>  
<span style="margin-left: 1em">其功厚赏焉乞归家居十三年教训子弟拯恤贫乏年</span>  
<span style="margin-left: 1em">七十有九荫一子太学生</span>  
<span style="margin-left: 1em">计琼字廷玉天顺壬午乡举任封丘邑洁己惠民籓臬</span>  
<span style="margin-left: 1em">考最亟称廉爱以不能事权势乞归当道不许谓其友</span>  
<span style="margin-left: 1em">张弼曰古之仕以行志今之仕以事势抑志偷安吾不</span>  
<span style="margin-left: 1em">能吾且归浦上读古人书以养吾素足矣曾孙安邦天</span>  
<span style="margin-left: 1em">启甲子顺天中式</span>  
<span style="margin-left: 1em">顾祥字廷吉华亭人景泰丙子乡举为都察院司务仕</span>  
<span style="margin-left: 1em">终保宁太守以廉吏称三原王端毅抚南畿重其清节</span>  
<span style="margin-left: 1em">题赞宪坊以表之在县治东数十武岁久倾圮几废嘉</span>  
<span style="margin-left: 1em">靖辛亥韦轩黄公来令首询其家有孙中道为弟子员</span>  
<span style="margin-left: 1em">黄公曰顾公廉吏不可使其里门卑敝不振王端毅先</span>  
<span style="margin-left: 1em">朝名卿不可使其兴建之迹湮毁不传捐廪助经费不</span>  
<span style="margin-left: 1em">逾月工告成</span>  
<span style="margin-left: 2em">何良俊存旧歌曰吴淞江水南之纪荡潏奔崩疾于</span>  
<span style="margin-left: 2em">矢往来倐忽几千回人事推移亦如此君不见东家</span>  
<span style="margin-left: 2em">官高新起宅近选名材远延石文杏为梁桂作楣美</span>  
<span style="margin-left: 2em">碝绿砌芸涂壁簷楹奕奕造青云丹垩辉辉映初日</span>  
<span style="margin-left: 2em">卷娄聚蚁何沸腾窟穴藏狐还拍塞谁知运改人代</span>  
<span style="margin-left: 2em">非门巷荒凉异畴昔栋宇高危风日欺瓦堕榱崩藓</span>  
<span style="margin-left: 2em">花碧深谋谓作百年期一朝宛是他人室眼见如此</span>  
<span style="margin-left: 2em">凡几家覆辙相追行复即顾公廉吏篚箧空数椽古</span>  
<span style="margin-left: 2em">屋愁秋风子孙相承已四世诗书清名传无穷亦有</span>  
<span style="margin-left: 2em">坊题名赞宪伊谁作之端毅公年深倾圯临官道车</span>  
<span style="margin-left: 2em">马日夕相追从不逢优孟能抵掌无一问者如盲聋</span>  
<span style="margin-left: 2em">黄侯忽捧天书至脱手牛刀才一试风猷髣髴盛汉</span>  
<span style="margin-left: 2em">余科条弃置常人事文举新开通德门任公远绍延</span>  
<span style="margin-left: 2em">陵祀侯言此坊劝鉴存崇修亦是怀贤义饬材捐俸</span>  
<span style="margin-left: 2em">甿趋功不日巍峩耸瞻视邑中冠盖纷成列应念豪</span>  
<span style="margin-left: 2em">奢易消歇勿穷壮丽侈华观但传卑隘贻来叶岂无</span>  
<span style="margin-left: 2em">贤令存旧似我侯伫看云仍保先业</span>  
<span style="margin-left: 1em">奚昊字时亨华亭人九岁就外傅囊白金为学资有妇</span>  
<span style="margin-left: 1em">人道哭问之曰家贫鬻丝得百钱而遗之舅姑老无以</span>  
<span style="margin-left: 1em">为𫗴粥昊即以金予妇归告其父父曰儿能如是吾无</span>  
<span style="margin-left: 1em">忧矣弱冠父疾刺血吁天求以身代又重伤母心匿不</span>  
<span style="margin-left: 1em">闻举成化戊子乡荐明年成进士拜刑部主事迁员外</span>  
<span style="margin-left: 1em">郎勘贵州狱归奏称旨进郎中庚子复乞归省遂就养</span>  
<span style="margin-left: 1em">焉居数月会瑞狱作事尤剧昊受命往日奔走劳瘁疾</span>  
<span style="margin-left: 1em">卒年三十六昊幼学时毋析资悉以让兄冕俸所得金</span>  
<span style="margin-left: 1em">帛必分族属为比部时同年董令去官道遇寇为馆谷</span>  
<span style="margin-left: 1em">给绨纩厚赆之还使经景州故寮刘判官死五年不能</span>  
<span style="margin-left: 1em">举昊葬之且恤其家平居恭逊见里中先辈无穷达皆</span>  
<span style="margin-left: 1em">不敢慢处寮采终日不色忤人多爱乐之尤嗜学喜临</span>  
<span style="margin-left: 1em">晋唐书诗文有奇思与客赋咏夜分不寝多著述李文</span>  
<span style="margin-left: 1em">正东阳志其墓</span>  
<span style="margin-left: 1em">李楷华亭人成化初知剡城县岁饥开仓尽给继以官</span>  
<span style="margin-left: 1em">廪全活甚众捐俸市地十亩为义冢以葬贫骨开垦荒</span>  
<span style="margin-left: 1em">田千七百顷招抚流移复业者七千余人去后民为立</span>  
<span style="margin-left: 1em">碑颂德<sub class="note-yuan">山东名宦传</sub></span>  
<span style="margin-left: 1em">许璘字文玉华亭人成化戊戌进士繇行人为御史忠</span>  
<span style="margin-left: 1em">诚愿悫遇事敢言为忌者所中出为湖广佥事以疆力</span>  
<span style="margin-left: 1em">著闻劾去县令之贪冒不法者数辈人以此衔之璘乃</span>  
<span style="margin-left: 1em">叹曰我行直道不合时宜固山野中人也遂致政归家</span>  
<span style="margin-left: 1em">居杜门澹泊如寒素虽灶突不烟不轻受人一缣一粟</span>  
<span style="margin-left: 1em">里中有被人诬讼者囊金托蒙古赛氏子丐璘居间璘</span>  
<span style="margin-left: 1em">知其诬直于官得释罪赛竟负其金璘知不复问所居</span>  
<span style="margin-left: 1em">前有空地赁人积竹木日征鸡子数枚以自给每夕阳</span>  
<span style="margin-left: 1em">在户乌帽布袍扶杖行游村郭间萧然古朴老叟也年</span>  
<span style="margin-left: 1em">八十终</span>  
<span style="margin-left: 1em">顾纶字惟诚华亭人成化甲午乡荐授大理司务寻改</span>  
<span style="margin-left: 1em">礼部升南京刑部郎方逆瑾用事狱以贿成周千户尅</span>  
<span style="margin-left: 1em">取军粮纶论如律周愬瑾审覆卒不能脱有熊丙者当</span>  
<span style="margin-left: 1em">弃市临刑呼曰吾死不恨矣顾郎中为我求生至再其</span>  
<span style="margin-left: 1em">处法宽平信于上下如此出知马湖府土官不识资序</span>  
<span style="margin-left: 1em">以袭职岁月为先后有舅甥争长十年不决召其人谕</span>  
<span style="margin-left: 1em">以国法事遂定夷俗杀人及盗皆不死偿以牛马纶著</span>  
<span style="margin-left: 1em">令有犯皆以法从事境内肃然有御史按蜀遣人求桫</span>  
<span style="margin-left: 1em">板拒之以私劾奏虽寝格不行纶亦请老卜筑白龙潭</span>  
<span style="margin-left: 1em">之南涯年七十九所著有寅清稿纪行稿碧潭稿</span>  
<span style="margin-left: 1em">孙衍字世延华亭人弱冠领乡荐登成化戊戌进士知</span>  
<span style="margin-left: 1em">深州丁艰归服除补信阳州沔阳鱼稻之乡商贾军卫</span>  
<span style="margin-left: 1em">强贪巧取衍明左券定市价民始得享其利于劝农兴</span>  
<span style="margin-left: 1em">学扶弱抑强尤加意焉升南京兵部郎中中官假进贡</span>

<span style="margin-left: 1em">治之中官势少杀奉部檄稽核马政厘革宿弊居多弘</span>

<span style="margin-left: 1em">解京料价多为势家包揽负累重征令编户自输岁办</span>  
<span style="margin-left: 1em">民亦无扰岁徭役皆手笔亲定推见纎悉人服其均民</span>  
<span style="margin-left: 1em">婚嫁往往以论财后时尤喜焚尸皆严加禁止复设义</span>  
<span style="margin-left: 1em">塜以处贫乏修郡志以纪往迹辛酉夏旱祷雨雨辄霁</span>  
<span style="margin-left: 1em">注衍喜却盖冒雨步行数里许疾卒年五十有九闽人</span>  
<span style="margin-left: 1em">哀之为立永慕祠于七月诞日岁祀焉</span>  
<span style="margin-left: 1em">顾纯字以正华亭人性介直不随俗俯仰成化丙辰登</span>
