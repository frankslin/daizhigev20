## 崇禎松江府志卷之三十九　人物四（國朝賢達）

<span style="margin-left: 3em">國朝賢達<sub class="note-yuan">四</sub></span>  
<span style="margin-left: 1em">張弼字汝弼華亭人成化丙戌進士拜兵部主事轉員</span>  
<span style="margin-left: 1em">外郎時羅倫以言事忤大臣去國弼慷慨作詩送之出</span>  
<span style="margin-left: 1em">知南安南安當兩廣要衝亡命嘯聚數爲民害弼設方</span>  
<span style="margin-left: 1em">畧平之大庾嶺旅客齎裝民素藉僱直之利後爲南雄</span>  
<span style="margin-left: 1em">桀黠所侵遂失業貧瘠弼請江右粤東二藩與中分著</span>  
<span style="margin-left: 1em">爲令嶺路故狹峻行者病之取商稅甃石路三十里又</span>  
<span style="margin-left: 1em">夷小茆嶺之礫崖難行者鑿過路灘之舟航難濟者築</span>  
<span style="margin-left: 1em">龍潭水之歘濛横溢者障謝行頭何公塘通濟街之春</span>  
<span style="margin-left: 1em">漲爲梗者萬民利之又立射圃躬親教閲毁淫祠六百</span>  
<span style="margin-left: 1em">餘所新道源書院祠周程三先生闢嶺寺祀張九齡起</span>  
<span style="margin-left: 1em">江東神閣祀蘇子瞻劉元城輩立蒙川館于東山造鐵</span>  
<span style="margin-left: 1em">漢樓墨君閣于寶界寺立吟風弄月臺于郡城皆景仰</span>  
<span style="margin-left: 1em">先哲之意歸之日老稚攀轅鼓棹送者載途建祠肖像</span>  
<span style="margin-left: 1em">于金蓮山歸三年卒年六十三弼襟度夷曠而敦尚行</span>  
<span style="margin-left: 1em">履動以風節自持雖談論間雜詼諧往往以理勝詩文</span>  
<span style="margin-left: 1em">成一家言及草書狂翰醉墨流落人間雖海外之國購</span>  
<span style="margin-left: 1em">爲異寶所刻有鶴城東海諸集傳子若孫歷代科名不</span>  
<span style="margin-left: 1em">絕</span>  
<span style="margin-left: 2em">公初爲兵部郎數以直言忤當路遂出守南安入覲</span>  
<span style="margin-left: 2em">至京謁李東陽閣老閽人辭焉東海題其几云始知</span>  
<span style="margin-left: 2em">東閣先生貴不放南安太守參拂袖竟出李公追悔</span>  
<span style="margin-left: 2em">弗及公休致既早子皆成名無一事累心周德中稱</span>  
<span style="margin-left: 2em">爲神仙太守</span>  
<span style="margin-left: 1em">張駿字天駿華亭人十歲能詩長工書法與東海齊名</span>  
<span style="margin-left: 1em">時號二張景泰癸酉鄉薦成化初選中書舍人直文華</span>  
<span style="margin-left: 1em">殿應制多稱旨賞賚極優　孝廟命寫風入松詞拜羊</span>  
<span style="margin-left: 1em">酒之賜陞太常少卿再晋光禄卿凡修詩海珠璣成</span>  
<span style="margin-left: 1em">詔進官一級考最廕一孫後以足疾上章乞休命乘傳</span>  
<span style="margin-left: 1em">歸踰年即家以原官起特免朝參仍令于文華供事會</span>  
<span style="margin-left: 1em">進呈通鑑纂要命駿等再謄晋禮部尚書時公年已八</span>  
<span style="margin-left: 1em">十復乞致仕命乘傳歲給輿廪卒賜祭駿性篤孝奉節</span>  
<span style="margin-left: 1em">母胡夫人惟謹其叔璣珩相繼殀亡妻瞿氏楊氏少年</span>  
<span style="margin-left: 1em">孀居公皆養事慰藉之竟全其節三母皆膺旌典稱三</span>  
<span style="margin-left: 1em">節之門裔孫翼軫登萬曆戊戌進士官廣東憲副</span>  
<span style="margin-left: 1em">柳淳字文粹華亭人少從舅氏袁公愷受壁經登成化</span>  
<span style="margin-left: 1em">丙戌進士授行人選監察御史巡畿內擒渠賊劉釗畿</span>  
<span style="margin-left: 1em">內就寧按西蜀成都多火災民悉置囊篋户外罔顧厥</span>  
<span style="margin-left: 1em">居淳察而禁之民始安堵擢貴州憲副適烏撒等衛歲</span>  
<span style="margin-left: 1em">飢諸司議救荒淳以發粟爲急躬詣其境驗口賑給賴</span>  
<span style="margin-left: 1em">以全活者數萬人轉山東按察使時黃河爲兗境患淳</span>  
<span style="margin-left: 1em">協謀贊襄患平論功陞右布政使以內艱歸哀毁踰禮</span>  
<span style="margin-left: 1em">而卒年六十有五淳公亮廉謹飭孝友睦族尤工真草</span>  
<span style="margin-left: 1em">書</span>  
<span style="margin-left: 1em">張誥字汝欽華亭人成化丙戌進士改庶吉士授御史</span>  
<span style="margin-left: 1em">按湖廣陞廣東副使改四川尋陞按察使弘治初歲飢</span>  
<span style="margin-left: 1em">誥請截荆襄衛兑運又發庫銀易米得數十餘萬石隨</span>  
<span style="margin-left: 1em">在賑貸所全活頗多陞貴州左布政未幾陞右副都御</span>  
<span style="margin-left: 1em">史撫雲南平疑獄諭亂夷得撫綏體木邦孟密二部連</span>  
<span style="margin-left: 1em">兵不解誥檄諸道練兵爲必討計皆懼而自戢朝廷嘉</span>  
<span style="margin-left: 1em">其功厚賞焉乞歸家居十三年教訓子弟拯恤貧乏年</span>  
<span style="margin-left: 1em">七十有九蔭一子太學生</span>  
<span style="margin-left: 1em">計瓊字廷玉天順壬午鄉舉任封丘邑潔己惠民籓臬</span>  
<span style="margin-left: 1em">考最亟稱廉愛以不能事權勢乞歸當道不許謂其友</span>  
<span style="margin-left: 1em">張弼曰古之仕以行志今之仕以事勢抑志偷安吾不</span>  
<span style="margin-left: 1em">能吾且歸浦上讀古人書以養吾素足矣曾孫安邦天</span>  
<span style="margin-left: 1em">啟甲子順天中式</span>  
<span style="margin-left: 1em">顧祥字廷吉華亭人景泰丙子鄉舉爲都察院司務仕</span>  
<span style="margin-left: 1em">終保寧太守以廉吏稱三原王端毅撫南畿重其清節</span>  
<span style="margin-left: 1em">題贊憲坊以表之在縣治東數十武歲久傾圮幾廢嘉</span>  
<span style="margin-left: 1em">靖辛亥韋軒黃公來令首詢其家有孫中道爲弟子員</span>  
<span style="margin-left: 1em">黃公曰顧公廉吏不可使其里門卑敝不振王端毅先</span>  
<span style="margin-left: 1em">朝名卿不可使其興建之跡湮毁不傳捐廪助經費不</span>  
<span style="margin-left: 1em">踰月工告成</span>  
<span style="margin-left: 2em">何良俊存舊歌曰吳淞江水南之紀蕩潏奔崩疾于</span>  
<span style="margin-left: 2em">矢往來倐忽幾千回人事推移亦如此君不見東家</span>  
<span style="margin-left: 2em">官高新起宅近選名材遠延石文杏爲梁桂作楣美</span>  
<span style="margin-left: 2em">碝綠砌芸塗壁簷楹奕奕造青雲丹堊輝輝映初日</span>  
<span style="margin-left: 2em">卷婁聚蟻何沸騰窟穴藏狐還拍塞誰知運改人代</span>  
<span style="margin-left: 2em">非門巷荒凉異疇昔棟宇高危風日欺瓦墮榱崩蘚</span>  
<span style="margin-left: 2em">花碧深謀謂作百年期一朝宛是他人室眼見如此</span>  
<span style="margin-left: 2em">凡幾家覆轍相追行復即顧公廉吏篚篋空數椽古</span>  
<span style="margin-left: 2em">屋愁秋風子孫相承已四世詩書清名傳無窮亦有</span>  
<span style="margin-left: 2em">坊題名贊憲伊誰作之端毅公年深傾圯臨官道車</span>  
<span style="margin-left: 2em">馬日夕相追從不逢優孟能抵掌無一問者如盲聾</span>  
<span style="margin-left: 2em">黃侯忽捧天書至脱手牛刀纔一試風猷髣髴盛漢</span>  
<span style="margin-left: 2em">餘科條棄置常人事文舉新開通德門任公遠紹延</span>  
<span style="margin-left: 2em">陵祀侯言此坊勸鑒存崇修亦是懷賢義飭材捐俸</span>  
<span style="margin-left: 2em">甿趨功不日巍峩聳瞻視邑中冠蓋紛成列應念豪</span>  
<span style="margin-left: 2em">奢易消歇勿窮壯麗侈華觀但傳卑隘貽來葉豈無</span>  
<span style="margin-left: 2em">賢令存舊似我侯佇看雲仍保先業</span>  
<span style="margin-left: 1em">奚昊字時亨華亭人九歲就外傅囊白金爲學資有婦</span>  
<span style="margin-left: 1em">人道哭問之曰家貧鬻絲得百錢而遺之舅姑老無以</span>  
<span style="margin-left: 1em">爲饘粥昊即以金予婦歸告其父父曰兒能如是吾無</span>  
<span style="margin-left: 1em">憂矣弱冠父疾刺血籲天求以身代又重傷母心匿不</span>  
<span style="margin-left: 1em">聞舉成化戊子鄉薦明年成進士拜刑部主事遷員外</span>  
<span style="margin-left: 1em">郎勘貴州獄歸奏稱旨進郎中庚子復乞歸省遂就養</span>  
<span style="margin-left: 1em">焉居數月會瑞獄作事尤劇昊受命往日奔走勞瘁疾</span>  
<span style="margin-left: 1em">卒年三十六昊幼學時毋析資悉以讓兄冕俸所得金</span>  
<span style="margin-left: 1em">帛必分族屬爲比部時同年董令去官道遇寇爲館穀</span>  
<span style="margin-left: 1em">給綈纊厚贐之還使經景州故寮劉判官死五年不能</span>  
<span style="margin-left: 1em">舉昊葬之且卹其家平居恭遜見里中先輩無窮達皆</span>  
<span style="margin-left: 1em">不敢慢處寮寀終日不色忤人多愛樂之尤嗜學喜臨</span>  
<span style="margin-left: 1em">晋唐書詩文有奇思與客賦詠夜分不寢多著述李文</span>  
<span style="margin-left: 1em">正東陽志其墓</span>  
<span style="margin-left: 1em">李楷華亭人成化初知剡城縣歲飢開倉盡給繼以官</span>  
<span style="margin-left: 1em">廪全活甚衆捐俸市地十畝爲義塚以葬貧骨開墾荒</span>  
<span style="margin-left: 1em">田千七百頃招撫流移復業者七千餘人去後民爲立</span>  
<span style="margin-left: 1em">碑頌德<sub class="note-yuan">山東名宦傳</sub></span>  
<span style="margin-left: 1em">許璘字文玉華亭人成化戊戌進士繇行人爲御史忠</span>  
<span style="margin-left: 1em">誠願慤遇事敢言爲忌者所中出爲湖廣僉事以疆力</span>  
<span style="margin-left: 1em">著聞劾去縣令之貪冒不法者數輩人以此銜之璘乃</span>  
<span style="margin-left: 1em">歎曰我行直道不合時宜固山野中人也遂致政歸家</span>  
<span style="margin-left: 1em">居杜門澹泊如寒素雖竈突不烟不輕受人一縑一粟</span>  
<span style="margin-left: 1em">里中有被人誣訟者囊金托蒙古賽氏子丐璘居間璘</span>  
<span style="margin-left: 1em">知其誣直于官得釋罪賽竟負其金璘知不復問所居</span>  
<span style="margin-left: 1em">前有空地賃人積竹木日徵雞子數枚以自給每夕陽</span>  
<span style="margin-left: 1em">在户烏帽布袍扶杖行游村郭間蕭然古樸老叟也年</span>  
<span style="margin-left: 1em">八十終</span>  
<span style="margin-left: 1em">顧綸字惟誠華亭人成化甲午鄉薦授大理司務尋改</span>  
<span style="margin-left: 1em">禮部陞南京刑部郎方逆瑾用事獄以賄成周千户尅</span>  
<span style="margin-left: 1em">取軍糧綸論如律周愬瑾審覆卒不能脱有熊丙者當</span>  
<span style="margin-left: 1em">棄市臨刑呼曰吾死不恨矣顧郎中爲我求生至再其</span>  
<span style="margin-left: 1em">處法寬平信於上下如此出知馬湖府土官不識資序</span>  
<span style="margin-left: 1em">以襲職歲月爲先後有舅甥争長十年不決召其人諭</span>  
<span style="margin-left: 1em">以國法事遂定夷俗殺人及盗皆不死償以牛馬綸著</span>  
<span style="margin-left: 1em">令有犯皆以法從事境內肅然有御史按蜀遣人求桫</span>  
<span style="margin-left: 1em">板拒之以私劾奏雖寢格不行綸亦請老卜築白龍潭</span>  
<span style="margin-left: 1em">之南涯年七十九所著有寅清稿紀行稿碧潭稿</span>  
<span style="margin-left: 1em">孫衍字世延華亭人弱冠領鄉薦登成化戊戌進士知</span>  
<span style="margin-left: 1em">深州丁艱歸服除補信陽州沔陽魚稻之鄉商賈軍衛</span>  
<span style="margin-left: 1em">强貪巧取衍明左券定市價民始得享其利于勸農興</span>  
<span style="margin-left: 1em">學扶弱抑强尤加意焉陞南京兵部郎中中官假進貢</span>  
<span style="margin-left: 1em">索馬快船無虛日每裁抑之因搆大獄　上命法司按</span>  
<span style="margin-left: 1em">治之中官勢少殺奉部檄稽覈馬政釐革宿弊居多弘</span>  
<span style="margin-left: 1em">治丙辰陞延平知府屬邑有盗殺人劫財匿山谷間其</span>  
<span style="margin-left: 1em">家誣以良民余新抵罪訊知其冤果得真盗而立出余</span>  
<span style="margin-left: 1em">新于獄邑有羅太學恃武斷箠人至死衍收捕無貸往</span>  
<span style="margin-left: 1em">解京料價多爲勢家包攬負累重徵令編户自輸歲辦</span>  
<span style="margin-left: 1em">民亦無擾歲徭役皆手筆親定推見纎悉人服其均民</span>  
<span style="margin-left: 1em">婚嫁往往以論財後時尤喜焚屍皆嚴加禁止復設義</span>  
<span style="margin-left: 1em">塜以處貧乏修郡志以紀往蹟辛酉夏旱禱雨雨輒霽</span>  
<span style="margin-left: 1em">注衍喜却蓋冒雨步行數里許疾卒年五十有九閩人</span>  
<span style="margin-left: 1em">哀之爲立永慕祠于七月誕日歲祀焉</span>  
<span style="margin-left: 1em">顧純字以正華亭人性介直不隨俗俯仰成化丙辰登</span>  
<span style="margin-left: 1em">進士出知高安縣中門內有神樹能爲禍福吏民賽禱</span>  
<span style="margin-left: 1em">雜庭下純至曰吾在安得爾命伐之諫者旁午不聽已</span>  
<span style="margin-left: 1em">伐果有變曰其本在爾盡劚之乃止自是縣中畏服獄</span>  
<span style="margin-left: 1em">訟屏息入爲刑部主事進員外郎時大官有以文章自</span>  
<span style="margin-left: 1em">命者衆咸歸之純持正獨無所附麗會大計罷歸純時</span>  
<span style="margin-left: 1em">年五十餘爾閒居郤掃日端坐一室游涉諸經子史尤</span>  
<span style="margin-left: 1em">注意鄉里後進有好學者引接訓誘無異子弟必以行</span>  
<span style="margin-left: 1em">誼爲本自以伉直少容更號頤弘子</span>  
<span style="margin-left: 1em">張穀字濟民上海人祖衡字允平永樂乙未進士宣德</span>  
<span style="margin-left: 1em">間拜監察御史上澄清風紀疏立朝不阿竟卒貶所穀</span>
