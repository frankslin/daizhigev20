## 崇禎松江府志卷之四十一　人物六（篤行）

<span style="margin-left: 3em">篤行</span>  
<span style="margin-left: 1em">蘧瑗不變節於昏行顔淵不改容於夜浴世尚夸毗如</span>  
<span style="margin-left: 1em">枯株槁籜無有心幹善乎柳玭之言曰忠信篤行乃食</span>  
<span style="margin-left: 1em">之醢醬獨孝友乎哉不言躬行中多嚴慎如莊叟所云</span>  
<span style="margin-left: 1em">爲善無近名者斯亦慥慥之君子也</span>  
<span style="margin-left: 1em">漢</span>  
<span style="margin-left: 1em">卞崇婁縣人漢桓帝時太守薛固爲法吏所枉下廷尉</span>  
<span style="margin-left: 1em">崇與烏程錢讓詣闕稱寃廷尉囚崇等以兵圍守苦毒</span>  
<span style="margin-left: 1em">持之崇讓恬然自若枉聲彌厲天子聞而奇之乃赦固</span>  
<span style="margin-left: 1em">罪</span>  
<span style="margin-left: 1em">宋</span>  
<span style="margin-left: 1em">衛公佐字輔之其先衛州汲縣人徙居華亭祖至有文</span>  
<span style="margin-left: 1em">行舉進士公佐被恩命授將仕郎守楊州助教母郁蚤</span>  
<span style="margin-left: 1em">卒事繼母陳盡孝族有貧不能嫁女者雖疎遠必擇壻</span>  
<span style="margin-left: 1em">歸之聚書數千卷禮四方賢士教訓子弟時縣未有學</span>  
<span style="margin-left: 1em">捐地爲址又獨任禮殿之役熙寧末飢疫乃施粥給藥</span>  
<span style="margin-left: 1em">請邑僧靈敏輩分拯之瘞殍給棺無慮萬數元豐中復</span>  
<span style="margin-left: 1em">飢租稅無所出令秩滿代者已至轉運使苛留之使督</span>  
<span style="margin-left: 1em">逋負纍繫盈庭又爲出粟代輸釋繫者而舊令始得解</span>  
<span style="margin-left: 1em">去民相與踵門謝曰微君吾屬將死于縲絏矣年五十</span>  
<span style="margin-left: 1em">八無疾而卒先卒一日展先塋且遍謁親舊若與之訣</span>  
<span style="margin-left: 1em">者歸語家人曰吾生樂善好施不爲不義今也云亡可</span>  
<span style="margin-left: 1em">無憾矣弟公亮公望並敦行義其後子孫蕃盛終宋世</span>  
<span style="margin-left: 1em">膚敏仲達文節皆其後</span>  
<span style="margin-left: 1em">元</span>  
<span style="margin-left: 1em">姚玉用華亭人循理樂善至治間割田立義莊歲收租</span>  
<span style="margin-left: 1em">千餘石以周宗族鄉黨建義塾于家以教鄉之子弟知</span>  
<span style="margin-left: 1em">府申秉禮聞其義委葺西湖書院遷義塾其中以便學</span>  
<span style="margin-left: 1em">者四方士子聞風而至者千二百人府嘗修儒學玉用</span>  
<span style="margin-left: 1em">功居多從父俊讀書好禮有孝行從弟實夫克協兄志</span>  
<span style="margin-left: 1em">若營廨宇復譙樓率先助費父子孝義聚于一門鄉人</span>  
<span style="margin-left: 1em">稱之</span>  
<span style="margin-left: 1em">任仲孚上海人好義樂善大德間飢發米二千斛穀八</span>  
<span style="margin-left: 1em">百斛以濟貧乏部使者上其事詔旌其門加其子良佐</span>  
<span style="margin-left: 1em">溧陽縣儒學教諭良輔信州叠山書院山長</span>  
<span style="margin-left: 1em">何長者名敬德上海浦東民家子樸謹不妄語善會計</span>  
<span style="margin-left: 1em">事吳郡張瑄行舶筦庫不數年贏羡莫可勝數一髮不</span>  
<span style="margin-left: 1em">以自私瑄父子方倚任之敬德亟辭云瑄既貴盛故敬</span>  
<span style="margin-left: 1em">德等夷皆佩於蒐金符爲萬户千户累爵積貲意氣自</span>  
<span style="margin-left: 1em">得敬德方布衣蔬食以施貧賑乏爲事勸瑄父子母嗜</span>  
<span style="margin-left: 1em">進厚藏以速禍及瑄敗夷戮藉没黨與家破禁錮而敬</span>  
<span style="margin-left: 1em">德無毫髮累大德十一年杭大飢官設粥仙林寺中飢</span>  
<span style="margin-left: 1em">民殍死敬德乃請杭好善而有材智者五七人即菩提</span>  
<span style="margin-left: 1em">寺作粥夜煮寘大甕中明旦飢民以至先後列堂廡下</span>  
<span style="margin-left: 1em">或溢出門外道上相向坐虛其前以行粥兩人舁一人</span>  
<span style="margin-left: 1em">執杓挹以注器中食已以次去日煮米七八石至十石</span>  
<span style="margin-left: 1em">始六月至八月凡七十日飢民無死者明年春敬德求</span>  
<span style="margin-left: 1em">破衣集諸好善者收聚遺骼枯胔數十萬具瘞之語在</span>  
<span style="margin-left: 1em">破衣傳夏爲粥如昨歲始五月朔踰三十六日而敬德</span>  
<span style="margin-left: 1em">殁年五十七</span>  
<span style="margin-left: 2em">胡長孺曰故老言宋嘉熙四年庚子大飢趙悦道尹</span>  
<span style="margin-left: 2em">臨安府發廪勸分恐弗暨奪民死中而生之初悦道</span>  
<span style="margin-left: 2em">無子養南外宗室子孟傳一夕夢之帝所嚴衛如大</span>  
<span style="margin-left: 2em">朝會儀既謁贊導之陞由祚階端笏屏息抑首僂躬</span>  
<span style="margin-left: 2em">不敢仰視帝告曰與歡汝無子救荒功多賜汝子九</span>  
<span style="margin-left: 2em">人趨下再拜稽首庭中寤以告家已而生八子與孟</span>  
<span style="margin-left: 2em">傳而九臧應星父記于書當時潮州作糜食飢人糜</span>  
<span style="margin-left: 2em">脱釜猶沸湧器中人急得糜食已輒仆死百步間飢</span>  
<span style="margin-left: 2em">未至死食糜者百無一生婺州顧籜未作𭫉熱而寒</span>  
<span style="margin-left: 2em">之約飢民旦由東門入與之履使之北門赴徙西門</span>  
<span style="margin-left: 2em">飲以藥復至東門給錢米出宿逆旅舍與爲買薪蘇</span>  
<span style="margin-left: 2em">旦洗沐廣舍不過棲十人明日復然竟去無一人死</span>  
<span style="margin-left: 2em">長者夜作粥貯大甕中蓋懲潮州事也有意哉</span>  
<span style="margin-left: 1em">何滄汴人建炎初爲制置京西北路上都尉賜紫金色</span>  
<span style="margin-left: 1em">袋隨高宗南渡見秀州青龍鎮士風淳厚遂卜居焉滄</span>  
<span style="margin-left: 1em">爲人勁直有才氣不媕阿纖趨歷仕雖久清約不滓家</span>  
<span style="margin-left: 1em">同寒素當時稱爲廉吏</span>  
<span style="margin-left: 1em">俞道善其先吳興人汝尚退翁之後宋季兵起移家避</span>  
<span style="margin-left: 1em">亂至華亭愛其土俗淳厚尤喜九峯娟秀卜居鳳凰山</span>  
<span style="margin-left: 1em">之南嘆曰宋鼎將傾中原成腥土我輩但能力耕耳因</span>  
<span style="margin-left: 1em">戒子孫勿干仕進胡元既有江南以豪氣粗戾變禮之</span>  
<span style="margin-left: 1em">俗不數年薰漬狃狎胥化成風宋之遺俗銷滅盡矣爲</span>  
<span style="margin-left: 1em">士者辮髮短衣效其語言容飾以自附于上道善獨率</span>  
<span style="margin-left: 1em">其宗以禮深衣峨冠談說古道嘗銘漢瓦硯曰人本漢</span>  
<span style="margin-left: 1em">人土亦漢土人與土皆古殆有宋室之思焉</span>  
<span style="margin-left: 1em">夏椿字壽之其先長興人兄杞宋景定間爲華亭典押</span>  
<span style="margin-left: 1em">因占籍華亭椿早孤事兄如父兄葬後語輒泣下至元</span>  
<span style="margin-left: 1em">丁亥歲祲椿出粟賤價以糶庚寅復祲則設粥于僧寺</span>  
<span style="margin-left: 1em">以待餓者大德丁未旱災鄰境民擕持老幼歸夏氏椿</span>  
<span style="margin-left: 1em">闢廬舍具饘藥視其羸壯而食飲之欲去則贐之歸死</span>  
<span style="margin-left: 1em">者給棺以瘞而書其姓名邑里以俟後來收骨者事聞</span>  
<span style="margin-left: 1em">於朝旌其門爲義士自郡城距海百里凡橋梁徑巷孤</span>  
<span style="margin-left: 1em">老所廬椿悉爲繕治每朔望飯囚徒與之棺即其居創</span>  
<span style="margin-left: 1em">義塾以訓鄉之子弟割土田五百畝以資之江浙僉事</span>  
<span style="margin-left: 1em">吳彦升剛直士也以劾時相去爲行臺都事椿素與吳</span>  
<span style="margin-left: 1em">善躬訪于金陵且致餽焉既見傾肝鬲語驩甚而辭其</span>  
<span style="margin-left: 1em">餽未幾彦升卒椿以遺其子曰吾誓終不忘彦升也御</span>  
<span style="margin-left: 1em">史周景遠爲作義士碑卒葬細林山鄧文原誌其墓子</span>  
<span style="margin-left: 1em">世澤</span>  
<span style="margin-left: 1em">章夢賢字思齊宋莊敏公楶九世孫孝友通練儀觀偉</span>  
<span style="margin-left: 1em">然至順初浙西大水朝廷募民能賑五百石以上者爵</span>  
<span style="margin-left: 1em">有差夢賢出粟二千餘石而不受爵詔旌爲義士之門</span>  
<span style="margin-left: 1em">至元中以孝友薦授襄陽建寧等處營田財賦提舉以</span>  
<span style="margin-left: 1em">父母俱喪不就官置義莊建義塾以教養鄉人兄殁撫</span>  
<span style="margin-left: 1em">其孤如子闔門二百口未嘗有間言子元澤字吉父性</span>  
<span style="margin-left: 1em">孝而好義父夢賢營義塾未竟而卒元澤感慨流涕乃</span>  
<span style="margin-left: 1em">崇齋宇飾廟貌爲清忠書院以仁宗賜故太師郇國文</span>  
<span style="margin-left: 1em">簡公得象清忠二字名也出贍田一千一百畝資師弟</span>  
<span style="margin-left: 1em">子及祠祭之費初爲丞相府舍人累遷奉政大夫海漕</span>  
<span style="margin-left: 1em">鎮撫以母老幡然棄官歸躬上甘旨鐵史爲求忠臣於</span>  
<span style="margin-left: 1em">孝子之門清忠書院有貢師泰記今郡之章氏皆莊敏</span>  
<span style="margin-left: 1em">青龍系也</span>  
<span style="margin-left: 1em">戴光遠字君實居白牛鎮其父暘谷規創義塾以私淑</span>  
<span style="margin-left: 1em">里人未竟而殁光遠經畫成之作堂室四十五間中祀</span>  
<span style="margin-left: 1em">先聖先師像講堂踞其後齋廬翼其旁環以幽篁佳木</span>  
<span style="margin-left: 1em">花徑菓蹊而瀦其流泉爲芰荷菰蒲之區又十畝藏貯</span>  
<span style="margin-left: 1em">圖史延師儒招來學四齋職教各一人生員恒百五十</span>  
<span style="margin-left: 1em">人割上腴之田五百畝以贍之黃學士爲之記稱其利</span>  
<span style="margin-left: 1em">澤加人爲惠豐爲養大戴氏父子之功不止獨善一鄉</span>  
<span style="margin-left: 1em">也</span>  
<span style="margin-left: 1em">葉以清字子徵其先京口人祖懋宋末避地家華亭以</span>  
<span style="margin-left: 1em">清尚氣節有古義俠風德清尉劉㫤告以三喪不舉即</span>  
<span style="margin-left: 1em">貸五十緡監黟縣伯顔調兵昱嶺屬妻子曰我死母老</span>  
<span style="margin-left: 1em">當往依華亭子徵顔果死以清夢顔來曰以八口累君</span>  
<span style="margin-left: 1em">越二日其妻子果奉母至苗兵守松江淮兵至而遁後</span>  
<span style="margin-left: 1em">尹鄭焕淮人也欲火巨室黨苗者以清控鄭獲免争持</span>  
<span style="margin-left: 1em">金帛走謝辭不受時避地者建德尹楊瑀平江尹貢師</span>  
<span style="margin-left: 1em">泰建德通守毛景賢咸來依清諸男女未婚嫁者皆爲</span>  
<span style="margin-left: 1em">擇配瑀卒無能斂以清葬以禮同門友胡方死無子躬</span>  
<span style="margin-left: 1em">爲斂藏籍遺物歸其弟妹浙省員外王國賢以囊槖留</span>  
<span style="margin-left: 1em">清所國賢死完封歸其家淮南江浙聞其風辟命交至</span>  
<span style="margin-left: 1em">皆不起晚築室蕭塘之上遠跡城府躬耕以自食一時</span>  
<span style="margin-left: 1em">士大夫皆慕之如古人云</span>  
<span style="margin-left: 1em">徐進華亭人輕財好義嘗割田萬餘畝建義塾以收鄉</span>  
<span style="margin-left: 1em">之子弟有貧乏者過其門必周贐之無倦容子彦裕挺</span>  
<span style="margin-left: 1em">特峭拔工草書尤善騎射洪武二年改義塾爲縣學彦</span>  
<span style="margin-left: 1em">裕復捐貲充拓以成之</span>  
<span style="margin-left: 2em">王逢曰今華亭縣學故徐德卿氏義塾也會學燬于</span>  
<span style="margin-left: 2em">兵官遂即塾爲學子彦裕上陳願廣葺之期年告成</span>  
<span style="margin-left: 2em">並誌諸石而士之才者咸爲歌頌</span>  
<span style="margin-left: 2em">袁凱詩徐徐新學徐卿始作伊誰克完季子仲寬惟</span>  
<span style="margin-left: 2em">此新學始亦甚隘爰斥爰搆以就于大其大惟何有</span>  
<span style="margin-left: 2em">門言言有堂軒軒有廡騫騫有階平平高墉連連鑿</span>  
<span style="margin-left: 2em">池濺濺樹木芊芊凡民之俊其來如雲小心鞠躬不</span>  
<span style="margin-left: 2em">惰以勤惟昔玄聖訓言斯明百工居肆匪肆不成嗟</span>  
<span style="margin-left: 2em">嗟爾俊亦既知止豈徒誦言厥有微旨其旨惟何曰</span>  
<span style="margin-left: 2em">仁與義明仁與義不遠甚邇爾求其方先我孝弟惟</span>  
<span style="margin-left: 2em">此孝弟爲仁之始始于家邦終于四海昔爲棫樸今</span>  
<span style="margin-left: 2em">則楩楠昔爲碔砆今則璵璠是蓄是儲邦家之需嗟</span>  
<span style="margin-left: 2em">嗟爾俊克就兹美誰其始之徐氏父子徐氏父子可</span>  
<span style="margin-left: 2em">謂曰賢我歌我詩刻于學宫以告後人以永其傳</span>  
<span style="margin-left: 1em">錢臯吳越王之裔孫也居華亭縣北六十里其聚爲小</span>  
<span style="margin-left: 1em">萊學通經史習騎射以義俠聞名貴人争欲致門下盗</span>  
<span style="margin-left: 1em">壓境臯呼鄉卒捍于松之陰鄉人賴以安又以白衣參</span>  
<span style="margin-left: 1em">諮贊帥越者却寇活遺黎數萬後乃結小團頂號純白</span>  
<span style="margin-left: 1em">窩以居收斂神氣識反本之義焉東維子楊維禎爲之</span>  
<span style="margin-left: 1em">記</span>  
<span style="margin-left: 1em">周顯字光遠世居華亭之干山少負奇氣美風度涉獵</span>  
<span style="margin-left: 1em">經史間喜神仙道士之學游龍虎山禮天師因給事其</span>  
<span style="margin-left: 1em">府久之慨然曰吾以孤身遠去父母將誰養乎遂謝歸</span>  
<span style="margin-left: 1em">踰年而丁父憂哀毁骨立葬祭有禮三年不與燕樂養</span>  
<span style="margin-left: 1em">母孫氏尤謹所居里歲輸官租四萬石民困于重斂多</span>  
<span style="margin-left: 1em">負逋慢期顯具爲約遂無敢後者吳淞江故道塞水溢</span>  
<span style="margin-left: 1em">諸郡詔所司開浚御史臺分官督視僉事范君素知其</span>  
<span style="margin-left: 1em">才請問方畧顯取方尺紙爲圖指畫形勢甚悉畢事御</span>  
<span style="margin-left: 1em">史舉酒勞曰是役也君之力也先是監守性緩急不同</span>

<span style="margin-left: 1em">給狀訴二侯受賄不法事下嘉興守杜侯覆治顯曰父</span>  
<span style="margin-left: 1em">母有過子當力諫今侯以論政不合使奸民迎合詆誣</span>  
<span style="margin-left: 1em">而吾徒坐視不顧設不幸中計奈何遂趨二侯備論所</span>  
<span style="margin-left: 1em">以皆感悟痛自責相好如初杜侯聞之亦抵奸民罪貢</span>  
<span style="margin-left: 1em">尚書師泰稱之曰聞義而勇不謀于人好仁而公不私</span>  
<span style="margin-left: 1em">其身卒年四十八</span>

<span style="margin-left: 1em">發帑財煮糜濟飢困至老彌篤壽九十乃逝生四子九</span>

<span style="margin-left: 1em">於親黨故舊遠近皆賢之</span>

<span style="margin-left: 1em">家遭焚掠恭克厲以復先業篤于信義能緩急人性至</span>

<span style="margin-left: 2em">痛堪弔不堪捫</span>
