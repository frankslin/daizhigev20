## 崇祯松江府志卷之四十一　人物六（笃行）

<span style="margin-left: 3em">笃行</span>  
<span style="margin-left: 1em">蘧瑗不变节于昏行颜渊不改容于夜浴世尚夸毗如</span>  
<span style="margin-left: 1em">枯株槁箨无有心干善乎柳玭之言曰忠信笃行乃食</span>  
<span style="margin-left: 1em">之醢酱独孝友乎哉不言躬行中多严慎如庄叟所云</span>  
<span style="margin-left: 1em">为善无近名者斯亦慥慥之君子也</span>  
<span style="margin-left: 1em">汉</span>  
<span style="margin-left: 1em">卞崇娄县人汉桓帝时太守薛固为法吏所枉下廷尉</span>  
<span style="margin-left: 1em">崇与乌程钱让诣阙称寃廷尉囚崇等以兵围守苦毒</span>  
<span style="margin-left: 1em">持之崇让恬然自若枉声弥厉天子闻而奇之乃赦固</span>  
<span style="margin-left: 1em">罪</span>  
<span style="margin-left: 1em">宋</span>  
<span style="margin-left: 1em">卫公佐字辅之其先卫州汲县人徙居华亭祖至有文</span>  
<span style="margin-left: 1em">行举进士公佐被恩命授将仕郎守杨州助教母郁蚤</span>  
<span style="margin-left: 1em">卒事继母陈尽孝族有贫不能嫁女者虽疎远必择壻</span>  
<span style="margin-left: 1em">归之聚书数千卷礼四方贤士教训子弟时县未有学</span>  
<span style="margin-left: 1em">捐地为址又独任礼殿之役熙宁末饥疫乃施粥给药</span>  
<span style="margin-left: 1em">请邑僧灵敏辈分拯之瘗殍给棺无虑万数元丰中复</span>  
<span style="margin-left: 1em">饥租税无所出令秩满代者已至转运使苛留之使督</span>  
<span style="margin-left: 1em">逋负累系盈庭又为出粟代输释系者而旧令始得解</span>  
<span style="margin-left: 1em">去民相与踵门谢曰微君吾属将死于缧絏矣年五十</span>  
<span style="margin-left: 1em">八无疾而卒先卒一日展先茔且遍谒亲旧若与之诀</span>  
<span style="margin-left: 1em">者归语家人曰吾生乐善好施不为不义今也云亡可</span>  
<span style="margin-left: 1em">无憾矣弟公亮公望并敦行义其后子孙蕃盛终宋世</span>  
<span style="margin-left: 1em">肤敏仲达文节皆其后</span>  
<span style="margin-left: 1em">元</span>  
<span style="margin-left: 1em">姚玉用华亭人循理乐善至治间割田立义庄岁收租</span>  
<span style="margin-left: 1em">千余石以周宗族乡党建义塾于家以教乡之子弟知</span>  
<span style="margin-left: 1em">府申秉礼闻其义委葺西湖书院迁义塾其中以便学</span>  
<span style="margin-left: 1em">者四方士子闻风而至者千二百人府尝修儒学玉用</span>  
<span style="margin-left: 1em">功居多从父俊读书好礼有孝行从弟实夫克协兄志</span>  
<span style="margin-left: 1em">若营廨宇复谯楼率先助费父子孝义聚于一门乡人</span>  
<span style="margin-left: 1em">称之</span>  
<span style="margin-left: 1em">任仲孚上海人好义乐善大德间饥发米二千斛谷八</span>  
<span style="margin-left: 1em">百斛以济贫乏部使者上其事诏旌其门加其子良佐</span>  
<span style="margin-left: 1em">溧阳县儒学教谕良辅信州叠山书院山长</span>  
<span style="margin-left: 1em">何长者名敬德上海浦东民家子朴谨不妄语善会计</span>  
<span style="margin-left: 1em">事吴郡张瑄行舶筦库不数年赢羡莫可胜数一发不</span>  
<span style="margin-left: 1em">以自私瑄父子方倚任之敬德亟辞云瑄既贵盛故敬</span>  
<span style="margin-left: 1em">德等夷皆佩于搜金符为万户千户累爵积赀意气自</span>  
<span style="margin-left: 1em">得敬德方布衣蔬食以施贫赈乏为事劝瑄父子母嗜</span>  
<span style="margin-left: 1em">进厚藏以速祸及瑄败夷戮藉没党与家破禁锢而敬</span>  
<span style="margin-left: 1em">德无毫发累大德十一年杭大饥官设粥仙林寺中饥</span>  
<span style="margin-left: 1em">民殍死敬德乃请杭好善而有材智者五七人即菩提</span>  
<span style="margin-left: 1em">寺作粥夜煮寘大瓮中明旦饥民以至先后列堂庑下</span>  
<span style="margin-left: 1em">或溢出门外道上相向坐虚其前以行粥两人舁一人</span>  
<span style="margin-left: 1em">执杓挹以注器中食已以次去日煮米七八石至十石</span>  
<span style="margin-left: 1em">始六月至八月凡七十日饥民无死者明年春敬德求</span>  
<span style="margin-left: 1em">破衣集诸好善者收聚遗骼枯胔数十万具瘗之语在</span>  
<span style="margin-left: 1em">破衣传夏为粥如昨岁始五月朔逾三十六日而敬德</span>  
<span style="margin-left: 1em">殁年五十七</span>  
<span style="margin-left: 2em">胡长孺曰故老言宋嘉熙四年庚子大饥赵悦道尹</span>  
<span style="margin-left: 2em">临安府发廪劝分恐弗暨夺民死中而生之初悦道</span>  
<span style="margin-left: 2em">无子养南外宗室子孟传一夕梦之帝所严卫如大</span>  
<span style="margin-left: 2em">朝会仪既谒赞导之升由祚阶端笏屏息抑首偻躬</span>  
<span style="margin-left: 2em">不敢仰视帝告曰与欢汝无子救荒功多赐汝子九</span>  
<span style="margin-left: 2em">人趋下再拜稽首庭中寤以告家已而生八子与孟</span>  
<span style="margin-left: 2em">传而九臧应星父记于书当时潮州作糜食饥人糜</span>  
<span style="margin-left: 2em">脱釜犹沸涌器中人急得糜食已辄仆死百步间饥</span>  
<span style="margin-left: 2em">未至死食糜者百无一生婺州顾箨未作𭫉热而寒</span>  
<span style="margin-left: 2em">之约饥民旦由东门入与之履使之北门赴徙西门</span>  
<span style="margin-left: 2em">饮以药复至东门给钱米出宿逆旅舍与为买薪苏</span>  
<span style="margin-left: 2em">旦洗沐广舍不过栖十人明日复然竟去无一人死</span>  
<span style="margin-left: 2em">长者夜作粥贮大瓮中盖惩潮州事也有意哉</span>  
<span style="margin-left: 1em">何沧汴人建炎初为制置京西北路上都尉赐紫金色</span>  
<span style="margin-left: 1em">袋随高宗南渡见秀州青龙镇士风淳厚遂卜居焉沧</span>  
<span style="margin-left: 1em">为人劲直有才气不媕阿纤趋历仕虽久清约不滓家</span>  
<span style="margin-left: 1em">同寒素当时称为廉吏</span>  
<span style="margin-left: 1em">俞道善其先吴兴人汝尚退翁之后宋季兵起移家避</span>  
<span style="margin-left: 1em">乱至华亭爱其土俗淳厚尤喜九峰娟秀卜居凤凰山</span>  
<span style="margin-left: 1em">之南叹曰宋鼎将倾中原成腥土我辈但能力耕耳因</span>  
<span style="margin-left: 1em">戒子孙勿干仕进胡元既有江南以豪气粗戾变礼之</span>  
<span style="margin-left: 1em">俗不数年薰渍狃狎胥化成风宋之遗俗销灭尽矣为</span>  
<span style="margin-left: 1em">士者辫发短衣效其语言容饰以自附于上道善独率</span>  
<span style="margin-left: 1em">其宗以礼深衣峨冠谈说古道尝铭汉瓦砚曰人本汉</span>  
<span style="margin-left: 1em">人土亦汉土人与土皆古殆有宋室之思焉</span>  
<span style="margin-left: 1em">夏椿字寿之其先长兴人兄杞宋景定间为华亭典押</span>  
<span style="margin-left: 1em">因占籍华亭椿早孤事兄如父兄葬后语辄泣下至元</span>  
<span style="margin-left: 1em">丁亥岁祲椿出粟贱价以粜庚寅复祲则设粥于僧寺</span>  
<span style="margin-left: 1em">以待饿者大德丁未旱灾邻境民擕持老幼归夏氏椿</span>  
<span style="margin-left: 1em">辟庐舍具𫗴药视其羸壮而食饮之欲去则赆之归死</span>  
<span style="margin-left: 1em">者给棺以瘗而书其姓名邑里以俟后来收骨者事闻</span>  
<span style="margin-left: 1em">于朝旌其门为义士自郡城距海百里凡桥梁径巷孤</span>  
<span style="margin-left: 1em">老所庐椿悉为缮治每朔望饭囚徒与之棺即其居创</span>  
<span style="margin-left: 1em">义塾以训乡之子弟割土田五百亩以资之江浙佥事</span>  
<span style="margin-left: 1em">吴彦升刚直士也以劾时相去为行台都事椿素与吴</span>  
<span style="margin-left: 1em">善躬访于金陵且致餽焉既见倾肝鬲语驩甚而辞其</span>  
<span style="margin-left: 1em">餽未几彦升卒椿以遗其子曰吾誓终不忘彦升也御</span>  
<span style="margin-left: 1em">史周景远为作义士碑卒葬细林山邓文原志其墓子</span>  
<span style="margin-left: 1em">世泽</span>  
<span style="margin-left: 1em">章梦贤字思齐宋庄敏公楶九世孙孝友通练仪观伟</span>  
<span style="margin-left: 1em">然至顺初浙西大水朝廷募民能赈五百石以上者爵</span>  
<span style="margin-left: 1em">有差梦贤出粟二千余石而不受爵诏旌为义士之门</span>  
<span style="margin-left: 1em">至元中以孝友荐授襄阳建宁等处营田财赋提举以</span>  
<span style="margin-left: 1em">父母俱丧不就官置义庄建义塾以教养乡人兄殁抚</span>  
<span style="margin-left: 1em">其孤如子阖门二百口未尝有间言子元泽字吉父性</span>  
<span style="margin-left: 1em">孝而好义父梦贤营义塾未竟而卒元泽感慨流涕乃</span>  
<span style="margin-left: 1em">崇斋宇饰庙貌为清忠书院以仁宗赐故太师郇国文</span>  
<span style="margin-left: 1em">简公得象清忠二字名也出赡田一千一百亩资师弟</span>  
<span style="margin-left: 1em">子及祠祭之费初为丞相府舍人累迁奉政大夫海漕</span>  
<span style="margin-left: 1em">镇抚以母老幡然弃官归躬上甘旨铁史为求忠臣于</span>  
<span style="margin-left: 1em">孝子之门清忠书院有贡师泰记今郡之章氏皆庄敏</span>  
<span style="margin-left: 1em">青龙系也</span>  
<span style="margin-left: 1em">戴光远字君实居白牛镇其父旸谷规创义塾以私淑</span>  
<span style="margin-left: 1em">里人未竟而殁光远经画成之作堂室四十五间中祀</span>  
<span style="margin-left: 1em">先圣先师像讲堂踞其后斋庐翼其旁环以幽篁佳木</span>  
<span style="margin-left: 1em">花径菓蹊而潴其流泉为芰荷菰蒲之区又十亩藏贮</span>  
<span style="margin-left: 1em">图史延师儒招来学四斋职教各一人生员恒百五十</span>  
<span style="margin-left: 1em">人割上腴之田五百亩以赡之黄学士为之记称其利</span>  
<span style="margin-left: 1em">泽加人为惠丰为养大戴氏父子之功不止独善一乡</span>  
<span style="margin-left: 1em">也</span>  
<span style="margin-left: 1em">叶以清字子征其先京口人祖懋宋末避地家华亭以</span>  
<span style="margin-left: 1em">清尚气节有古义侠风德清尉刘㫤告以三丧不举即</span>  
<span style="margin-left: 1em">贷五十缗监黟县伯颜调兵昱岭属妻子曰我死母老</span>  
<span style="margin-left: 1em">当往依华亭子征颜果死以清梦颜来曰以八口累君</span>  
<span style="margin-left: 1em">越二日其妻子果奉母至苗兵守松江淮兵至而遁后</span>  
<span style="margin-left: 1em">尹郑焕淮人也欲火巨室党苗者以清控郑获免争持</span>  
<span style="margin-left: 1em">金帛走谢辞不受时避地者建德尹杨瑀平江尹贡师</span>  
<span style="margin-left: 1em">泰建德通守毛景贤咸来依清诸男女未婚嫁者皆为</span>  
<span style="margin-left: 1em">择配瑀卒无能敛以清葬以礼同门友胡方死无子躬</span>  
<span style="margin-left: 1em">为敛藏籍遗物归其弟妹浙省员外王国贤以囊槖留</span>  
<span style="margin-left: 1em">清所国贤死完封归其家淮南江浙闻其风辟命交至</span>  
<span style="margin-left: 1em">皆不起晚筑室萧塘之上远迹城府躬耕以自食一时</span>  
<span style="margin-left: 1em">士大夫皆慕之如古人云</span>  
<span style="margin-left: 1em">徐进华亭人轻财好义尝割田万余亩建义塾以收乡</span>  
<span style="margin-left: 1em">之子弟有贫乏者过其门必周赆之无倦容子彦裕挺</span>  
<span style="margin-left: 1em">特峭拔工草书尤善骑射洪武二年改义塾为县学彦</span>  
<span style="margin-left: 1em">裕复捐赀充拓以成之</span>  
<span style="margin-left: 2em">王逢曰今华亭县学故徐德卿氏义塾也会学毁于</span>  
<span style="margin-left: 2em">兵官遂即塾为学子彦裕上陈愿广葺之期年告成</span>  
<span style="margin-left: 2em">并志诸石而士之才者咸为歌颂</span>  
<span style="margin-left: 2em">袁凯诗徐徐新学徐卿始作伊谁克完季子仲宽惟</span>  
<span style="margin-left: 2em">此新学始亦甚隘爰斥爰搆以就于大其大惟何有</span>  
<span style="margin-left: 2em">门言言有堂轩轩有庑骞骞有阶平平高墉连连凿</span>  
<span style="margin-left: 2em">池溅溅树木芊芊凡民之俊其来如云小心鞠躬不</span>  
<span style="margin-left: 2em">惰以勤惟昔玄圣训言斯明百工居肆匪肆不成嗟</span>  
<span style="margin-left: 2em">嗟尔俊亦既知止岂徒诵言厥有微旨其旨惟何曰</span>  
<span style="margin-left: 2em">仁与义明仁与义不远甚迩尔求其方先我孝弟惟</span>  
<span style="margin-left: 2em">此孝弟为仁之始始于家邦终于四海昔为棫朴今</span>  
<span style="margin-left: 2em">则楩楠昔为碔砆今则玙璠是蓄是储邦家之需嗟</span>  
<span style="margin-left: 2em">嗟尔俊克就兹美谁其始之徐氏父子徐氏父子可</span>  
<span style="margin-left: 2em">谓曰贤我歌我诗刻于学宫以告后人以永其传</span>  
<span style="margin-left: 1em">钱臯吴越王之裔孙也居华亭县北六十里其聚为小</span>  
<span style="margin-left: 1em">莱学通经史习骑射以义侠闻名贵人争欲致门下盗</span>  
<span style="margin-left: 1em">压境臯呼乡卒捍于松之阴乡人赖以安又以白衣参</span>  
<span style="margin-left: 1em">咨赞帅越者却寇活遗黎数万后乃结小团顶号纯白</span>  
<span style="margin-left: 1em">窝以居收敛神气识反本之义焉东维子杨维祯为之</span>  
<span style="margin-left: 1em">记</span>  
<span style="margin-left: 1em">周显字光远世居华亭之干山少负奇气美风度涉猎</span>  
<span style="margin-left: 1em">经史间喜神仙道士之学游龙虎山礼天师因给事其</span>  
<span style="margin-left: 1em">府久之慨然曰吾以孤身远去父母将谁养乎遂谢归</span>  
<span style="margin-left: 1em">逾年而丁父忧哀毁骨立葬祭有礼三年不与燕乐养</span>
