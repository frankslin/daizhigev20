## 崇祯松江府志卷之二十六　守令题名上

<span style="margin-left: 3em">守令题名</span>  
<span style="margin-left: 1em">昔杨文贞既为三公恨未曾据郡典邑何朂愿为剧县</span>  
<span style="margin-left: 1em">不愿为台阁盖守令若斯之重也吾朝令著最绩者下</span>  
<span style="margin-left: 1em">尺一召入台省而守若以常调待之独不闻永乐间黄</span>  
<span style="margin-left: 1em">公辂守松二十余年乎宣德间赵公豫守松十五年乎</span>  
<span style="margin-left: 2em">赐勅驰驿诣任　赐铜瓜得专击杀　赐宴午门尚</span>  
<span style="margin-left: 1em">书陪席赉衣钞皆有差近　皇上出台省为郡守盖规</span>  
<span style="margin-left: 1em">模　祖宗时成宪而更得兼行久任之法何忧百姓之</span>  
<span style="margin-left: 1em">不洪永若哉志守令题名</span>  
<span style="margin-left: 3em">郡守</span>  
<span style="margin-left: 1em">郡守秦官也汉更名太守娄属会稽郡郡守多不避本</span>  
<span style="margin-left: 1em">贯故严助朱买臣相继为太守治战艘出青龙海道以</span>  
<span style="margin-left: 1em">伐南越王莽改太守曰大尹东汉末分置钱塘江以南</span>  
<span style="margin-left: 1em">为吴郡仍太守之号晋为封国以内史行太守事加将</span>  
<span style="margin-left: 1em">军号给鼓盖为荣无者为耻虞潭加镇东将军王荟加</span>  
<span style="margin-left: 1em">建威将军筑沪渎垒施𫗴粥有功于娄唐改郡为州改</span>  
<span style="margin-left: 1em">守为刺史加号持节颁铜鱼符于时初置华亭称苏州</span>  
<span style="margin-left: 1em">华亭而德政则齐抗李德裕文章则韦应物白居易皆</span>  
<span style="margin-left: 1em">于华属邑有惠泽法得传之循吏宋革五代之弊命朝</span>  
<span style="margin-left: 1em">臣出守列郡号权知军州事又以地望高下或兼兵马</span>  
<span style="margin-left: 1em">钤辖巡检都监或带沿边安抚提辖而华亭又属秀州</span>  
<span style="margin-left: 1em">至胡元升华亭为松江府别设监府曰达鲁花赤守曰</span>  
<span style="margin-left: 1em">知府皆称兼管内劝农事　皇祖开基仍称知府征天</span>  
<span style="margin-left: 1em">下贤才为守令谓中书省曰昔在民间见官吏多不恤</span>  
<span style="margin-left: 1em">民贪财好色饮酒废事心实恶之故令严法禁但有蠧</span>  
<span style="margin-left: 1em">害吾民者罪不恕又曰新授郡县官多出布衣到任之</span>  
<span style="margin-left: 1em">时或假贷于人须养其廉予道里费又每新除赐银十</span>  
<span style="margin-left: 1em">两布六疋加意长吏务从民情黄子威以人才擢及忧</span>  
<span style="margin-left: 1em">去郡民数千人乞留凡再任松江赵豫以生员擢因吏</span>  
<span style="margin-left: 1em">民之情增秩三品先后在任十五年成弘间间以监察</span>  
<span style="margin-left: 1em">御史出守后乃以京曹官积俸得之秩正四品月支禄</span>  
<span style="margin-left: 1em">米二十四石</span>  
<span style="margin-left: 3em">郡丞</span>  
<span style="margin-left: 1em">郡丞亦秦官也秦为郡置守丞尉各一人守治民丞佐</span>  
<span style="margin-left: 1em">之尉以典兵尉至唐而废武德元年改郡丞为别驾十</span>  
<span style="margin-left: 1em">年又改别驾为长史又改诸州治中并为司马皆古丞</span>  
<span style="margin-left: 1em">职宋艺祖始设通判盖惩五代藩镇之擅而以儒臣临</span>  
<span style="margin-left: 1em">制之又设司寇参军用新进士及选人旋改司理亦称</span>  
<span style="margin-left: 1em">推官耑掌讼狱勘鞫之事而官号始于唐盖观察使僚</span>  
<span style="margin-left: 1em">属也元立松江府文武不相统设同知通判推官各一</span>  
<span style="margin-left: 1em">人分掌钱谷户口刑狱听断之事而已　国初因其官</span>  
<span style="margin-left: 1em">寻以松江赋繁多盗添设同知二人一主海防一主督</span>  
<span style="margin-left: 1em">漕通判二人一主水利一主粮务而推官无旁设如元</span>  
<span style="margin-left: 1em">制同知秩正五品月支禄米十二石通判秩正六品月</span>  
<span style="margin-left: 1em">支禄米十石推官秩正七品月支禄米七石五斗</span>  
<span style="margin-left: 1em">宋府设官</span>  
<span style="margin-left: 2em">知军事通判军事各一员并兼管内劝农营田事军</span>  
<span style="margin-left: 2em">判官一员录事司理司户司法参军各一员军学教</span>  
<span style="margin-left: 2em">授一员兵马都监本军驻札一员监押四员添差者</span>  
<span style="margin-left: 2em">不与巡检一员巡辖马递铺一员监在城酒税一员</span>  
<span style="margin-left: 2em">监户部赡军酒库一员</span>  
<span style="margin-left: 1em">元府设官</span>  
<span style="margin-left: 2em">总管府达鲁花赤总管各一员皆兼管内劝农事同</span>  
<span style="margin-left: 2em">知治中府判各一员推官二员经历知事照磨兼架</span>  
<span style="margin-left: 2em">阁各一员司狱一员中万户达鲁花赤正万户副万</span>  
<span style="margin-left: 2em">户各一员镇抚经历知事照磨各一员千户所一十</span>  
<span style="margin-left: 2em">一奕每奕千户三员百户三十员弹压三十员每奕</span>  
<span style="margin-left: 2em">又各有首领官一员</span>  
<span style="margin-left: 1em">元守令题名记　松江为府旧华亭县也县何以为府</span>  
<span style="margin-left: 2em">皇元有国重民食华亭粟伙他县府是用升也府何</span>  
<span style="margin-left: 2em">官官几何其监府曰达鲁花赤守曰知府佐贰曰同</span>  
<span style="margin-left: 2em">知曰判官专刑名者曰推官官凡五员也守颛一郡</span>  
<span style="margin-left: 2em">政无不统府何复有监世皇一海内声教自北而南</span>  
<span style="margin-left: 2em">百官有司必长吾类风乃同一也府升始何年国朝</span>  
<span style="margin-left: 2em">混一江南在至元丙子明年丁丑升华亭府其易今</span>  
<span style="margin-left: 2em">名又明年戊寅也府历官几何复府后总五官凡四</span>  
<span style="margin-left: 2em">十三员也前是官何弗及升府初官皆出常铨至大</span>  
<span style="margin-left: 2em">间武皇奉府为太后汤沐邑监郡出东朝命余官铨</span>
