## 崇禎松江府志卷之二十六　守令題名上

<span style="margin-left: 3em">守令題名</span>  
<span style="margin-left: 1em">昔楊文貞既爲三公恨未曾據郡典邑何朂願爲劇縣</span>  
<span style="margin-left: 1em">不願爲臺閣蓋守令若斯之重也吾朝令著最績者下</span>  
<span style="margin-left: 1em">尺一召入臺省而守若以常調待之獨不聞永樂間黃</span>  
<span style="margin-left: 1em">公輅守松二十餘年乎宣德間趙公豫守松十五年乎</span>  
<span style="margin-left: 2em">賜勅馳驛詣任　賜銅瓜得專擊殺　賜宴午門尚</span>  
<span style="margin-left: 1em">書陪席賚衣鈔皆有差近　皇上出臺省爲郡守蓋規</span>  
<span style="margin-left: 1em">模　祖宗時成憲而更得兼行久任之法何憂百姓之</span>  
<span style="margin-left: 1em">不洪永若哉志守令題名</span>  
<span style="margin-left: 3em">郡守</span>  
<span style="margin-left: 1em">郡守秦官也漢更名太守婁屬會稽郡郡守多不避本</span>  
<span style="margin-left: 1em">貫故嚴助朱買臣相繼爲太守治戰艘出青龍海道以</span>  
<span style="margin-left: 1em">伐南越王莽改太守曰大尹東漢末分置錢塘江以南</span>  
<span style="margin-left: 1em">爲吳郡仍太守之號晉爲封國以內史行太守事加將</span>  
<span style="margin-left: 1em">軍號給鼓蓋爲榮無者爲耻虞潭加鎮東將軍王薈加</span>  
<span style="margin-left: 1em">建威將軍築滬瀆壘施饘粥有功於婁唐改郡爲州改</span>  
<span style="margin-left: 1em">守爲刺史加號持節頒銅魚符於時初置華亭稱蘇州</span>  
<span style="margin-left: 1em">華亭而德政則齊抗李德裕文章則韋應物白居易皆</span>  
<span style="margin-left: 1em">於華屬邑有惠澤法得傳之循吏宋革五代之弊命朝</span>  
<span style="margin-left: 1em">臣出守列郡號權知軍州事又以地望高下或兼兵馬</span>  
<span style="margin-left: 1em">鈐轄巡檢都監或帶沿邊安撫提轄而華亭又屬秀州</span>  
<span style="margin-left: 1em">至胡元陞華亭爲松江府別設監府曰達魯花赤守曰</span>  
<span style="margin-left: 1em">知府皆稱兼管內勸農事　皇祖開基仍稱知府徵天</span>  
<span style="margin-left: 1em">下賢才爲守令謂中書省曰昔在民間見官吏多不恤</span>  
<span style="margin-left: 1em">民貪財好色飲酒廢事心實惡之故令嚴法禁但有蠧</span>  
<span style="margin-left: 1em">害吾民者罪不恕又曰新授郡縣官多出布衣到任之</span>  
<span style="margin-left: 1em">時或假貸於人須養其廉予道里費又每新除賜銀十</span>  
<span style="margin-left: 1em">兩布六疋加意長吏務從民情黃子威以人才擢及憂</span>  
<span style="margin-left: 1em">去郡民數千人乞留凡再任松江趙豫以生員擢因吏</span>  
<span style="margin-left: 1em">民之情增秩三品先後在任十五年成弘間間以監察</span>  
<span style="margin-left: 1em">御史出守後乃以京曹官積俸得之秩正四品月支禄</span>  
<span style="margin-left: 1em">米二十四石</span>  
<span style="margin-left: 3em">郡丞</span>  
<span style="margin-left: 1em">郡丞亦秦官也秦爲郡置守丞尉各一人守治民丞佐</span>  
<span style="margin-left: 1em">之尉以典兵尉至唐而廢武德元年改郡丞爲別駕十</span>  
<span style="margin-left: 1em">年又改別駕爲長史又改諸州治中並爲司馬皆古丞</span>  
<span style="margin-left: 1em">職宋藝祖始設通判蓋懲五代藩鎮之擅而以儒臣臨</span>  
<span style="margin-left: 1em">制之又設司寇參軍用新進士及選人旋改司理亦稱</span>  
<span style="margin-left: 1em">推官耑掌訟獄勘鞫之事而官號始於唐蓋觀察使僚</span>  
<span style="margin-left: 1em">屬也元立松江府文武不相統設同知通判推官各一</span>  
<span style="margin-left: 1em">人分掌錢穀户口刑獄聽斷之事而已　國初因其官</span>  
<span style="margin-left: 1em">尋以松江賦繁多盗添設同知二人一主海防一主督</span>  
<span style="margin-left: 1em">漕通判二人一主水利一主糧務而推官無旁設如元</span>  
<span style="margin-left: 1em">制同知秩正五品月支禄米十二石通判秩正六品月</span>  
<span style="margin-left: 1em">支禄米十石推官秩正七品月支禄米七石五斗</span>  
<span style="margin-left: 1em">宋府設官</span>  
<span style="margin-left: 2em">知軍事通判軍事各一員並兼管內勸農營田事軍</span>  
<span style="margin-left: 2em">判官一員錄事司理司户司法參軍各一員軍學教</span>  
<span style="margin-left: 2em">授一員兵馬都監本軍駐劄一員監押四員添差者</span>  
<span style="margin-left: 2em">不與巡檢一員巡轄馬遞舖一員監在城酒稅一員</span>  
<span style="margin-left: 2em">監户部贍軍酒庫一員</span>  
<span style="margin-left: 1em">元府設官</span>  
<span style="margin-left: 2em">總管府達魯花赤總管各一員皆兼管內勸農事同</span>  
<span style="margin-left: 2em">知治中府判各一員推官二員經歷知事照磨兼架</span>  
<span style="margin-left: 2em">閣各一員司獄一員中萬户達魯花赤正萬户副萬</span>  
<span style="margin-left: 2em">户各一員鎮撫經歷知事照磨各一員千户所一十</span>  
<span style="margin-left: 2em">一奕每奕千户三員百户三十員彈壓三十員每奕</span>  
<span style="margin-left: 2em">又各有首領官一員</span>  
<span style="margin-left: 1em">元守令題名記　松江爲府舊華亭縣也縣何以爲府</span>  
<span style="margin-left: 2em">皇元有國重民食華亭粟夥他縣府是用陞也府何</span>  
<span style="margin-left: 2em">官官幾何其監府曰達魯花赤守曰知府佐貳曰同</span>  
<span style="margin-left: 2em">知曰判官專刑名者曰推官官凡五員也守顓一郡</span>  
<span style="margin-left: 2em">政無不統府何復有監世皇一海內聲教自北而南</span>  
<span style="margin-left: 2em">百官有司必長吾類風乃同一也府陞始何年國朝</span>  
<span style="margin-left: 2em">混一江南在至元丙子明年丁丑陞華亭府其易今</span>  
<span style="margin-left: 2em">名又明年戊寅也府歷官幾何復府後總五官凡四</span>  
<span style="margin-left: 2em">十三員也前是官何弗及陞府初官皆出常銓至大</span>  
<span style="margin-left: 2em">間武皇奉府爲太后湯沐邑監郡出東朝命餘官銓</span>  
<span style="margin-left: 2em">如舊天曆改元革府名復舊縣明年己巳復府復府</span>  
<span style="margin-left: 2em">前官遠弗可悉考其可考者後府員也官曷臧曷否</span>  
<span style="margin-left: 2em">數官而臧否是訐爲直著其名實固不揜也府陞有</span>  
<span style="margin-left: 2em">年題名未前記今何以記昔之官吾府者有廉有貪</span>  
<span style="margin-left: 2em">有廉而迂有貪而能有德優於才有才勝於德有公</span>  
<span style="margin-left: 2em">正有邪辟有暴而猛有苛而察有優柔不斷有疲愞</span>  
<span style="margin-left: 2em">不勝任罔求全才畧而弗記猶可也若今郡長侯廉</span>  
<span style="margin-left: 2em">而明公而惠敏而能果誼不可諼也不諼將何以勒</span>  
<span style="margin-left: 2em">諸堅珉使臧否無隱後來者有勸懲也勒銘者誰何</span>  
<span style="margin-left: 2em">郡人之公言也述言者誰何雲間陸居仁也至正十</span>
