## 崇祯松江府志卷之五十五　诗品

<span style="margin-left: 3em">诗品</span>  
<span style="margin-left: 1em">志立艺文多有玉石鱼龙之混俞彦直从前代以及</span>  
<span style="margin-left: 1em">国朝其琅琅有声者著为诗品而余则散见于山水咏</span>  
<span style="margin-left: 1em">歌中为先贤张帜在此为先贤不敢滥觞亦在此即题</span>  
<span style="margin-left: 1em">曰云间诗话可也</span>  
<span style="margin-left: 1em">晋平原内史陆机郎中令陆云　诗至于晋稍入轻绮</span>  
<span style="margin-left: 2em">虽高言妙句波属云委而汉魏之风一变元康之际</span>  
<span style="margin-left: 2em">二陆特秀开六代之词源为云间之正始才名并出</span>  
<span style="margin-left: 2em">夐只千古后世仰之如绛云丽星之在霄汉非一郡</span>  
<span style="margin-left: 2em">之明珠白璧也京山李维祯云机之赋曰诗缘情而</span>  
<span style="margin-left: 2em">绮靡其言吴人诗乎马班史言吴东有海盐章山之</span>  
<span style="margin-left: 2em">铜三江五湖之利而延陵季子最后严助朱买臣之</span>  
<span style="margin-left: 2em">属并以文词显汉时其人往往韶令妍秀有巧思饮</span>  
<span style="margin-left: 2em">食衣服宫室器具刻画藻缋为天下最东晋以还声</span>  
<span style="margin-left: 2em">名文物日盛矣盖在士衡前所传始为南音者出涂</span>  
<span style="margin-left: 2em">山之女若夏统之暮歌河女章与木容紫玉尔女之</span>  
<span style="margin-left: 2em">类大端幻眇婉弱而其后为江南子夜前后团扇懊</span>  
<span style="margin-left: 2em">侬诸乐府则绮靡极矣士衡吴人将其时业已开绮</span>  
<span style="margin-left: 2em">靡之渐而预见之耶司空张华见机作篇篇称善犹</span>  
<span style="margin-left: 2em">讥其太冶钟嵘品其举体华美少于公干文劣于仲</span>  
<span style="margin-left: 2em">宣刘勰谓榛楛勿剪庸音足曲识非不鉴情若吝繁</span>  
<span style="margin-left: 2em">则绮靡实士衡自道耳橘柚北渡而化若榴东移而</span>  
<span style="margin-left: 2em">茂鹧鸪之飞先南子规之啼必北物性风土固有不</span>  
<span style="margin-left: 2em">可强者其评士衡瑜不揜瑕可称诗史</span>  
<span style="margin-left: 2em">唐太宗传论曰陆机陆云实荆衡之杞梓挺珪璋于</span>  
<span style="margin-left: 2em">秀实驰英华于早年风鉴澄爽神情俊迈文藻宏丽</span>  
<span style="margin-left: 2em">独步当时言论慷慨冠乎终古高词迥映如朗月之</span>  
<span style="margin-left: 2em">悬光叠意回舒若重岩之积秀千条析理则电圻霜</span>  
<span style="margin-left: 2em">开一绪连文则珠流璧合其词深而雅其义博而显</span>  
<span style="margin-left: 2em">故远超枚马高蹑王刘百代文宗一人而已</span>  
<span style="margin-left: 2em">文心雕龙云机云标二俊之采又云张潘左陆比肩</span>  
<span style="margin-left: 2em">诗衢采缛于正始力柔于建安或㭊文以为妙或流</span>  
<span style="margin-left: 2em">靡以自妍此其大畧也</span>  
<span style="margin-left: 2em">钟嵘诗品云陆机为太康之英</span>  
<span style="margin-left: 2em">北史文苑传云潘陆张左擅侈丽之才饰羽仪于风</span>  
<span style="margin-left: 2em">穴</span>  
<span style="margin-left: 2em">邢子才云潘陆齐轨不袭建安之风</span>  
<span style="margin-left: 2em">葛洪评陆机云玄圃之积玉无非夜光五湖之吐流</span>  
<span style="margin-left: 2em">泉源如一</span>  
<span style="margin-left: 2em">何大复云陆诗体俳语不俳谢则体语俱俳可谓千</span>  
<span style="margin-left: 2em">古卓识</span>  
<span style="margin-left: 2em">王世贞云谢陆之增而华也唐律之先兆也又云士</span>  
<span style="margin-left: 2em">龙文章差亚乃昆诗远不如又云士衡翩翩藻秀饶</span>  
<span style="margin-left: 2em">有才致</span>  
<span style="margin-left: 2em">冯时可论曰晋史称机文喻海韫蓬山而育芜兴公</span>  
<span style="margin-left: 2em">之论亦如此然才大者多有英有芜其势然也王元</span>  
<span style="margin-left: 2em">美谓陆不在多而在模拟寡自然之致然其集中模</span>  
<span style="margin-left: 2em">拟不免亦多独运又云颇见才致无奈俳弱余谓俳</span>  
<span style="margin-left: 2em">弱处固有伉健处尤堪读不可举一废百元美又谓</span>  
<span style="margin-left: 2em">人以俳偶之罪归之三谢识者谓起自陆平原然秦</span>  
<span style="margin-left: 2em">声发西气齐瑟扬东讴则魏诗亦然矣招摇西北指</span>  
<span style="margin-left: 2em">天汉东南倾则汉诗亦然矣遘闵既多受侮不少则</span>  
<span style="margin-left: 2em">毛诗亦然矣</span>  
<span style="margin-left: 2em">士衡拟古明月何皎皎诗云安寝北堂上明月入我</span>  
<span style="margin-left: 2em">牖照之有余晖揽之不盈手凉风绕曲房寒蝉鸣高</span>  
<span style="margin-left: 2em">柳踟蹰感节物我行永已久游宦会无成离思难独</span>  
<span style="margin-left: 2em">守此少年仕宦不得志而思其室家也照之有余晖</span>  
<span style="margin-left: 2em">揽之不盈手以兴佳人容光在想而渺不可即言外</span>  
<span style="margin-left: 2em">之旨甚有余情</span>  
<span style="margin-left: 2em">董逃行历九秋篇云荠与麦兮夏零兰桂践霜逾馨</span>  
<span style="margin-left: 2em">禄命悬天难明妾心结意丹青何忧君心中倾又序</span>  
<span style="margin-left: 2em">金罍兮玉觞宾主递起雁行杯若飞电绝光交觞接</span>  
<span style="margin-left: 2em">巵结裳慷慨欢笑万方又奏新诗兮夫君烂然虎变</span>  
<span style="margin-left: 2em">龙文浑如天地未分又君恩爱兮不竭譬若朝日夕</span>  
<span style="margin-left: 2em">月此景万里不绝长保初醮发结何忧坐成胡越昔</span>  
<span style="margin-left: 2em">人云此篇髣髴欢戚如在目前经纬情感若探衷曲</span>  
<span style="margin-left: 2em">宫商层叠绮绣斐亹其言有文其声有永走僵李杜</span>  
<span style="margin-left: 2em">不能及矣当为百世六言之祖</span>  
<span style="margin-left: 2em">士龙赠张士然诗通波激枉渚悲风薄丘榛修路无</span>  
<span style="margin-left: 2em">穷迹井邑自相循语殊有致真与平原齐轨方步</span>  
<span style="margin-left: 2em">石林诗话云晋魏间诗尚未知声律对偶然陆云相</span>  
<span style="margin-left: 2em">谑之辞所谓日下荀鸣鹤云间陆士龙者乃指为的</span>  
<span style="margin-left: 2em">对至四海习凿齿弥天释道安之类不一乃知此体</span>  
<span style="margin-left: 2em">出于自然不待沈约后能也</span>  
<span style="margin-left: 2em">胡应麟云士衡来日苦短去日苦长今我不乐蟋蟀</span>  
<span style="margin-left: 2em">在房绝类古诗雅颂虽远寔四言变体之工者典午</span>  
<span style="margin-left: 2em">以后殊不易传</span>  
<span style="margin-left: 1em">东曹掾张翰字季鹰晋史称其词义新丽造次立成而</span>  
<span style="margin-left: 2em">纵任不拘</span>  
<span style="margin-left: 2em">文心雕龙曰季鹰办切于短韵</span>  
<span style="margin-left: 2em">钟嵘诗品曰季鹰黄华之唱正叔缘繁之章虽不具</span>  
<span style="margin-left: 2em">美而文旨高丽并得虬龙片甲凤凰一毛张季鹰杂</span>  
<span style="margin-left: 2em">诗一首入昭明选脍炙篇籍间人知荣与壮俱去贱</span>  
<span style="margin-left: 2em">与老相寻二语写情极真却不知欢乐不照颜一句</span>  
<span style="margin-left: 2em">更幻妙可思</span>  
<span style="margin-left: 2em">钟惺曰季鹰咏周小史诗云翩翩周生婉变幼童年</span>  
<span style="margin-left: 2em">十有五如日在东香肤柔泽素质参红团辅圆颐菡</span>  
<span style="margin-left: 2em">萏芙蓉尔形既淑尔服亦鲜轻车随风飞雾流烟转</span>  
<span style="margin-left: 2em">侧猗靡顾盼便妍和颜喜笑美口善言有怜恤语无</span>  
<span style="margin-left: 2em">狎昵语咏美男宜如此一入狎昵便浅又繇容止看</span>  
<span style="margin-left: 2em">出性情是卫风手如柔荑章法</span>  
<span style="margin-left: 1em">齐左长史陆倕吟谱云陆佐公少勤学善属文任昉为</span>  
<span style="margin-left: 2em">中丞后进车轨日至号为兰台聚倕有诗赞昉曰壮</span>  
<span style="margin-left: 2em">哉荀文若贤哉陈太丘</span>  
<span style="margin-left: 2em">陆倕寄赠诸友以诗代书云余本水乡士闭门江海</span>  
<span style="margin-left: 2em">隅时逢世道泰蹇足步高衢名成官虽立效微功日</span>  
<span style="margin-left: 2em">疎入仕乘肥马出守拥高车关门游昔吏迁亭有故</span>  
<span style="margin-left: 2em">书江派资贤牧宗英出建旟不劳王布鼓无赖露田</span>  
<span style="margin-left: 2em">车弼政非责实求名已课虚长卿病犹在修龄疾未</span>  
<span style="margin-left: 2em">祛讵知亭长肉宁挂府丞鱼不能未能止内讼惭诸</span>  
<span style="margin-left: 2em">己僶俛从王事纚舟出淮涘朋故远追寻暄宿清江</span>  
<span style="margin-left: 2em">阴明旦一分手翻飞各异林归舟随岸曲犹闻歌棹</span>  
<span style="margin-left: 2em">音行者日迢远谁见别离心夕次冽洲岸明登慈姥</span>  
<span style="margin-left: 2em">岑水流多回复余归良未寻江关寒事早夜露伤秋</span>  
<span style="margin-left: 2em">草心缕姑苏台日送邯郸道葭苇日苍苍亲知慎早</span>  
<span style="margin-left: 2em">凉刘兄消渴病体摄戒无良殷弟癫昡疾行止避风</span>  
<span style="margin-left: 2em">霜刘侯有余冷宜饵陟厘方伏子多风咳门冬幸易</span>  
<span style="margin-left: 2em">将率更爱雅体体弱思自强吏曹勉玉润讽议勗金</span>  
<span style="margin-left: 2em">相比部多暇日奚用肆龙章建德何为者无隋<sub class="note-yuan">疑</sub>无</span>  
<span style="margin-left: 2em">人乡记室朋从暇露蝎附行商议曹坐朝罢尺板嗣</span>  
<span style="margin-left: 2em">微<sub class="note-yuan">疑</sub>芳双栖成独宿俱飞忽异翔眷言思亲友沉思</span>  
<span style="margin-left: 2em">结中肠追惟畴昔时朝府多欢暇薄暮尘埃静飞盖</span>  
<span style="margin-left: 2em">遥相迓李郭或同舟潘夏时方驾娱谈终美景敷文</span>  
<span style="margin-left: 2em">永清夜促膝岂异人戚戚皆朋娅今日一乖离漼然</span>  
<span style="margin-left: 2em">心事差山川望犹近便以隔天涯玉躬子加护昭质</span>  
<span style="margin-left: 2em">余未亏八行思息勉一礼望来仪</span>  
<span style="margin-left: 1em">陈黄门侍郎顾野王吟谱云野王九岁作日赋朱异见</span>  
<span style="margin-left: 2em">而奇之长更励精力学无所不晓</span>  
<span style="margin-left: 2em">虚楼续本事诗云虞伯施少受学顾野王野王当夏</span>  
<span style="margin-left: 2em">日闻蝉声使咏之伯施操笔便成诗曰垂緌饮清露</span>  
<span style="margin-left: 2em">流响出疎桐居高声自远非是藉秋风野王喜曰此</span>  
<span style="margin-left: 2em">子沉静寡欲要当享大名于天下</span>  
<span style="margin-left: 1em">唐著作郎顾况诗品云况诗天才不足而问辩有余虽</span>  
<span style="margin-left: 2em">有骨气殊乏风采其补亡诸诗颇有流调可讽然词</span>  
<span style="margin-left: 2em">旨不圆终违机悟既居茅山自号华阳真逸今观其</span>  
<span style="margin-left: 2em">诗类裁谢风尘超脱凡径岂感贶于山灵者耶</span>  
<span style="margin-left: 2em">顾况家吴淞江上作渔父词曰新妇矶边月明女儿</span>  
<span style="margin-left: 2em">浦口潮平<sub class="note-yuan">女儿浦在华亭</sub>又张志和浮家泛宅垂钓三江其</span>  
<span style="margin-left: 2em">渔父词曰青篛笠绿蓑衣斜风细雨不须归诚江上</span>  
<span style="margin-left: 2em">风景也二词俱松江事宋黄鲁直合为浣溪沙词曰</span>  
<span style="margin-left: 2em">新妇矶头眉黛秋女儿浦口眼波愁惊鱼错认月沉</span>  
<span style="margin-left: 2em">钩青篛笠前无限事绿蓑衣底一时休斜阳细雨转</span>  
<span style="margin-left: 2em">船头东坡曰此词清新婉丽其最得意处以山光水</span>  
<span style="margin-left: 2em">色赞玉肌花貌真得渔父家风然才出新妇矶便入</span>  
<span style="margin-left: 2em">女儿浦此渔父无乃大濶浪乎权德舆诗亦有新妇</span>  
<span style="margin-left: 2em">矶头云半敛女儿滩畔月初明句亦祖况词也<sub class="note-yuan">野客丛书</sub></span>  
<span style="margin-left: 2em">诗薮云顾况乐府整齐闳亮稍协前规又六气铜浑</span>  
<span style="margin-left: 2em">转三光玉律调颇整赡近老杜句格</span>  
<span style="margin-left: 2em">唐诗纪事云况尚疎远近于方外发为诗篇俱遐慕</span>  
<span style="margin-left: 2em">神仙悲感尘世其悲歌三首并序云情思发动圣所</span>  
<span style="margin-left: 2em">不免也故师乙陈其宜延陵审其音理乱之所经王</span>  
<span style="margin-left: 2em">化之所兴信无逃声岂徒文彩之丽遂作歌以悲之</span>  
<span style="margin-left: 2em">唐本事诗载顾况在洛乘间与一二诗友游苑中流</span>  
<span style="margin-left: 2em">水上得大梧叶题诗云一入深宫里年年不见春聊</span>  
<span style="margin-left: 2em">题一片叶寄与有情人况明日于上流亦题云愁见</span>  
<span style="margin-left: 2em">莺啼柳絮飞上阳宫女断肠时君恩不禁东流水叶</span>  
<span style="margin-left: 2em">上题诗寄与谁后十余日有客来苑中又于叶上得</span>  
<span style="margin-left: 2em">诗以示况曰一叶题诗出禁城谁人酬和独含情自</span>  
<span style="margin-left: 2em">嗟不及波中叶荡漾乘春取次行又明皇代以杨妃</span>  
<span style="margin-left: 2em">虢国宠盛宫娥皆衰悴不愿备掖庭尝书落叶随御</span>  
<span style="margin-left: 2em">沟水流出云旧宠悲秋扇新恩寄早春聊题一片叶</span>  
<span style="margin-left: 2em">将寄接流人顾况闻而和之既达圣听遣出禁内人</span>  
<span style="margin-left: 2em">不少或有五使之号况所和即前四句也其后云溪</span>
