## 崇禎松江府志卷之五十五　詩品

<span style="margin-left: 3em">詩品</span>  
<span style="margin-left: 1em">志立藝文多有玉石魚龍之混俞彦直從前代以及</span>  
<span style="margin-left: 1em">國朝其琅琅有聲者著爲詩品而餘則散見於山水詠</span>  
<span style="margin-left: 1em">歌中爲先賢張幟在此爲先賢不敢濫觴亦在此即題</span>  
<span style="margin-left: 1em">曰雲間詩話可也</span>  
<span style="margin-left: 1em">晉平原內史陸機郎中令陸雲　詩至於晉稍入輕綺</span>  
<span style="margin-left: 2em">雖高言妙句波屬雲委而漢魏之風一變元康之際</span>  
<span style="margin-left: 2em">二陸特秀開六代之詞源爲雲間之正始才名並出</span>  
<span style="margin-left: 2em">夐隻千古後世仰之如絳雲麗星之在霄漢非一郡</span>  
<span style="margin-left: 2em">之明珠白璧也京山李維禎云機之賦曰詩緣情而</span>  
<span style="margin-left: 2em">綺靡其言吳人詩乎馬班史言吳東有海鹽章山之</span>  
<span style="margin-left: 2em">銅三江五湖之利而延陵季子最後嚴助朱買臣之</span>  
<span style="margin-left: 2em">屬並以文詞顯漢時其人往往韶令妍秀有巧思飲</span>  
<span style="margin-left: 2em">食衣服宫室器具刻畫藻繢爲天下最東晉以還聲</span>  
<span style="margin-left: 2em">名文物日盛矣蓋在士衡前所傳始爲南音者出塗</span>  
<span style="margin-left: 2em">山之女若夏統之暮歌河女章與木容紫玉爾女之</span>  
<span style="margin-left: 2em">類大端幻眇婉弱而其後爲江南子夜前後團扇懊</span>  
<span style="margin-left: 2em">儂諸樂府則綺靡極矣士衡吳人將其時業已開綺</span>  
<span style="margin-left: 2em">靡之漸而預見之耶司空張華見機作篇篇稱善猶</span>  
<span style="margin-left: 2em">譏其太冶鍾嶸品其舉體華美少於公幹文劣於仲</span>  
<span style="margin-left: 2em">宣劉勰謂榛楛勿剪庸音足曲識非不鑒情若吝繁</span>  
<span style="margin-left: 2em">則綺靡實士衡自道耳橘柚北渡而化若榴東移而</span>  
<span style="margin-left: 2em">茂鷓鴣之飛先南子規之啼必北物性風土固有不</span>  
<span style="margin-left: 2em">可强者其評士衡瑜不揜瑕可稱詩史</span>  
<span style="margin-left: 2em">唐太宗傳論曰陸機陸雲實荆衡之杞梓挺珪璋於</span>  
<span style="margin-left: 2em">秀實馳英華於早年風鑒澄爽神情俊邁文藻宏麗</span>  
<span style="margin-left: 2em">獨步當時言論慷慨冠乎終古高詞迥映如朗月之</span>  
<span style="margin-left: 2em">懸光疊意迴舒若重岩之積秀千條析理則電圻霜</span>  
<span style="margin-left: 2em">開一緒連文則珠流璧合其詞深而雅其義博而顯</span>  
<span style="margin-left: 2em">故遠超枚馬高躡王劉百代文宗一人而已</span>  
<span style="margin-left: 2em">文心雕龍云機雲標二俊之采又云張潘左陸比肩</span>  
<span style="margin-left: 2em">詩衢采縟於正始力柔於建安或㭊文以爲妙或流</span>  
<span style="margin-left: 2em">靡以自妍此其大畧也</span>  
<span style="margin-left: 2em">鍾嶸詩品云陸機爲太康之英</span>  
<span style="margin-left: 2em">北史文苑傳云潘陸張左擅侈麗之才飾羽儀於風</span>  
<span style="margin-left: 2em">穴</span>  
<span style="margin-left: 2em">邢子才云潘陸齊軌不襲建安之風</span>  
<span style="margin-left: 2em">葛洪評陸機云玄圃之積玉無非夜光五湖之吐流</span>  
<span style="margin-left: 2em">泉源如一</span>  
<span style="margin-left: 2em">何大復云陸詩體俳語不俳謝則體語俱俳可謂千</span>  
<span style="margin-left: 2em">古卓識</span>  
<span style="margin-left: 2em">王世貞云謝陸之增而華也唐律之先兆也又云士</span>  
<span style="margin-left: 2em">龍文章差亞乃昆詩遠不如又云士衡翩翩藻秀饒</span>  
<span style="margin-left: 2em">有才致</span>  
<span style="margin-left: 2em">馮時可論曰晉史稱機文喻海韞蓬山而育蕪興公</span>  
<span style="margin-left: 2em">之論亦如此然才大者多有英有蕪其勢然也王元</span>  
<span style="margin-left: 2em">美謂陸不在多而在模擬寡自然之致然其集中模</span>  
<span style="margin-left: 2em">擬不免亦多獨運又云頗見才致無奈俳弱余謂俳</span>  
<span style="margin-left: 2em">弱處固有伉健處尤堪讀不可舉一廢百元美又謂</span>  
<span style="margin-left: 2em">人以俳偶之罪歸之三謝識者謂起自陸平原然秦</span>  
<span style="margin-left: 2em">聲發西氣齊瑟揚東謳則魏詩亦然矣招摇西北指</span>  
<span style="margin-left: 2em">天漢東南傾則漢詩亦然矣遘閔既多受侮不少則</span>  
<span style="margin-left: 2em">毛詩亦然矣</span>  
<span style="margin-left: 2em">士衡擬古明月何皎皎詩云安寢北堂上明月入我</span>  
<span style="margin-left: 2em">牖照之有餘暉攬之不盈手涼風繞曲房寒蟬鳴高</span>  
<span style="margin-left: 2em">柳踟蹰感節物我行永已久游宦會無成離思難獨</span>  
<span style="margin-left: 2em">守此少年仕宦不得志而思其室家也照之有餘暉</span>  
<span style="margin-left: 2em">攬之不盈手以興佳人容光在想而渺不可即言外</span>  
<span style="margin-left: 2em">之旨甚有餘情</span>  
<span style="margin-left: 2em">董逃行歷九秋篇云薺與麥兮夏零蘭桂踐霜逾馨</span>  
<span style="margin-left: 2em">禄命懸天難明妾心結意丹青何憂君心中傾又序</span>  
<span style="margin-left: 2em">金罍兮玉觴賓主遞起雁行杯若飛電絶光交觴接</span>  
<span style="margin-left: 2em">巵結裳慷慨歡笑萬方又奏新詩兮夫君爛然虎變</span>  
<span style="margin-left: 2em">龍文渾如天地未分又君恩愛兮不竭譬若朝日夕</span>  
<span style="margin-left: 2em">月此景萬里不絶長保初醮髮結何憂坐成胡越昔</span>  
<span style="margin-left: 2em">人云此篇髣髴歡戚如在目前經緯情感若探衷曲</span>  
<span style="margin-left: 2em">宫商層疊綺繡斐亹其言有文其聲有永走僵李杜</span>  
<span style="margin-left: 2em">不能及矣當爲百世六言之祖</span>  
<span style="margin-left: 2em">士龍贈張士然詩通波激枉渚悲風薄丘榛修路無</span>  
<span style="margin-left: 2em">窮跡井邑自相循語殊有致真與平原齊軌方步</span>  
<span style="margin-left: 2em">石林詩話云晉魏間詩尚未知聲律對偶然陸雲相</span>  
<span style="margin-left: 2em">謔之辭所謂日下荀鳴鶴雲間陸士龍者乃指爲的</span>  
<span style="margin-left: 2em">對至四海習鑿齒彌天釋道安之類不一乃知此體</span>  
<span style="margin-left: 2em">出於自然不待沈約後能也</span>  
<span style="margin-left: 2em">胡應麟云士衡來日苦短去日苦長今我不樂蟋蟀</span>  
<span style="margin-left: 2em">在房絶類古詩雅頌雖遠寔四言變體之工者典午</span>  
<span style="margin-left: 2em">以後殊不易傳</span>  
<span style="margin-left: 1em">東曹掾張翰字季鷹晉史稱其詞義新麗造次立成而</span>  
<span style="margin-left: 2em">縱任不拘</span>  
<span style="margin-left: 2em">文心雕龍曰季鷹辦切於短韵</span>  
<span style="margin-left: 2em">鍾嶸詩品曰季鷹黃華之唱正叔緣繁之章雖不具</span>  
<span style="margin-left: 2em">美而文旨高麗並得虬龍片甲鳳凰一毛張季鷹雜</span>  
<span style="margin-left: 2em">詩一首入昭明選膾炙篇籍間人知榮與壯俱去賤</span>  
<span style="margin-left: 2em">與老相尋二語寫情極真却不知歡樂不照顔一句</span>  
<span style="margin-left: 2em">更幻妙可思</span>  
<span style="margin-left: 2em">鍾惺曰季鷹詠周小史詩云翩翩周生婉變幼童年</span>  
<span style="margin-left: 2em">十有五如日在東香膚柔澤素質參紅團輔圓頤菡</span>  
<span style="margin-left: 2em">萏芙蓉爾形既淑爾服亦鮮輕車隨風飛霧流烟轉</span>  
<span style="margin-left: 2em">側猗靡顧盼便妍和顔喜笑美口善言有憐恤語無</span>  
<span style="margin-left: 2em">狎昵語詠美男宜如此一入狎昵便淺又繇容止看</span>  
<span style="margin-left: 2em">出性情是衛風手如柔荑章法</span>  
<span style="margin-left: 1em">齊左長史陸倕吟譜云陸佐公少勤學善屬文任昉爲</span>  
<span style="margin-left: 2em">中丞後進車軌日至號爲蘭臺聚倕有詩贊昉曰壯</span>  
<span style="margin-left: 2em">哉荀文若賢哉陳太丘</span>  
<span style="margin-left: 2em">陸倕寄贈諸友以詩代書云余本水鄉士閉門江海</span>  
<span style="margin-left: 2em">隅時逢世道泰蹇足步高衢名成官雖立效微功日</span>  
<span style="margin-left: 2em">疎入仕乘肥馬出守擁高車關門游昔吏遷亭有故</span>  
<span style="margin-left: 2em">書江派資賢牧宗英出建旟不勞王布鼓無賴露田</span>  
<span style="margin-left: 2em">車弼政非責實求名已課虛長卿病猶在修齡疾未</span>  
<span style="margin-left: 2em">祛詎知亭長肉寧掛府丞魚不能未能止內訟慚諸</span>  
<span style="margin-left: 2em">己僶俛從王事纚舟出淮涘朋故遠追尋暄宿清江</span>  
<span style="margin-left: 2em">陰明旦一分手翻飛各異林歸舟隨岸曲猶聞歌棹</span>  
<span style="margin-left: 2em">音行者日迢遠誰見別離心夕次冽洲岸明登慈姥</span>  
<span style="margin-left: 2em">岑水流多迴復余歸良未尋江關寒事早夜露傷秋</span>  
<span style="margin-left: 2em">草心縷姑蘇臺日送邯鄲道葭葦日蒼蒼親知慎早</span>  
<span style="margin-left: 2em">涼劉兄消渴病體攝戒無良殷弟癲昡疾行止避風</span>  
<span style="margin-left: 2em">霜劉侯有餘冷宜餌陟釐方伏子多風咳門冬幸易</span>  
<span style="margin-left: 2em">將率更愛雅體體弱思自强吏曹勉玉潤諷議勗金</span>  
<span style="margin-left: 2em">相比部多暇日奚用肆龍章建德何爲者無隋<sub class="note-yuan">疑</sub>無</span>  
<span style="margin-left: 2em">人鄉記室朋從暇露蝎附行商議曹坐朝罷尺板嗣</span>  
<span style="margin-left: 2em">微<sub class="note-yuan">疑</sub>芳雙棲成獨宿俱飛忽異翔眷言思親友沉思</span>  
<span style="margin-left: 2em">結中腸追惟疇昔時朝府多歡暇薄暮塵埃靜飛蓋</span>  
<span style="margin-left: 2em">遥相迓李郭或同舟潘夏時方駕娱談終美景敷文</span>  
<span style="margin-left: 2em">永清夜促膝豈異人戚戚皆朋婭今日一乖離漼然</span>  
<span style="margin-left: 2em">心事差山川望猶近便以隔天涯玉躬子加護昭質</span>  
<span style="margin-left: 2em">余未虧八行思息勉一禮望來儀</span>  
<span style="margin-left: 1em">陳黃門侍郎顧野王吟譜云野王九歲作日賦朱异見</span>  
<span style="margin-left: 2em">而奇之長更勵精力學無所不曉</span>  
<span style="margin-left: 2em">虛樓續本事詩云虞伯施少受學顧野王野王當夏</span>  
<span style="margin-left: 2em">日聞蟬聲使詠之伯施操筆便成詩曰垂緌飲清露</span>  
<span style="margin-left: 2em">流響出疎桐居高聲自遠非是藉秋風野王喜曰此</span>  
<span style="margin-left: 2em">子沉靜寡欲要當享大名於天下</span>  
<span style="margin-left: 1em">唐著作郎顧況詩品云況詩天才不足而問辯有餘雖</span>  
<span style="margin-left: 2em">有骨氣殊乏風采其補亡諸詩頗有流調可諷然詞</span>  
<span style="margin-left: 2em">旨不圓終違機悟既居茅山自號華陽真逸今觀其</span>  
<span style="margin-left: 2em">詩類裁謝風塵超脱凡徑豈感貺於山靈者耶</span>  
<span style="margin-left: 2em">顧況家吳淞江上作漁父詞曰新婦磯邊月明女兒</span>  
<span style="margin-left: 2em">浦口潮平<sub class="note-yuan">女兒浦在華亭</sub>又張志和浮家泛宅垂釣三江其</span>  
<span style="margin-left: 2em">漁父詞曰青篛笠綠蓑衣斜風細雨不須歸誠江上</span>  
<span style="margin-left: 2em">風景也二詞俱松江事宋黃魯直合爲浣溪沙詞曰</span>  
<span style="margin-left: 2em">新婦磯頭眉黛秋女兒浦口眼波愁驚魚錯認月沉</span>  
<span style="margin-left: 2em">鈎青篛笠前無限事綠簑衣底一時休斜陽細雨轉</span>  
<span style="margin-left: 2em">船頭東坡曰此詞清新婉麗其最得意處以山光水</span>  
<span style="margin-left: 2em">色贊玉肌花貌真得漁父家風然才出新婦磯便入</span>  
<span style="margin-left: 2em">女兒浦此漁父無乃大濶浪乎權德輿詩亦有新婦</span>  
<span style="margin-left: 2em">磯頭雲半斂女兒灘畔月初明句亦祖況詞也<sub class="note-yuan">野客叢書</sub></span>  
<span style="margin-left: 2em">詩藪云顧況樂府整齊閎亮稍協前規又六氣銅渾</span>  
<span style="margin-left: 2em">轉三光玉律調頗整贍近老杜句格</span>  
<span style="margin-left: 2em">唐詩紀事云況尚疎遠近於方外發爲詩篇俱遐慕</span>  
<span style="margin-left: 2em">神仙悲感塵世其悲歌三首并序云情思發動聖所</span>  
<span style="margin-left: 2em">不免也故師乙陳其宜延陵審其音理亂之所經王</span>  
<span style="margin-left: 2em">化之所興信無逃聲豈徒文彩之麗遂作歌以悲之</span>  
<span style="margin-left: 2em">唐本事詩載顧況在洛乘間與一二詩友游苑中流</span>  
<span style="margin-left: 2em">水上得大梧葉題詩云一入深宫裏年年不見春聊</span>  
<span style="margin-left: 2em">題一片葉寄與有情人況明日於上流亦題云愁見</span>  
<span style="margin-left: 2em">鶯啼柳絮飛上陽宫女斷腸時君恩不禁東流水葉</span>  
<span style="margin-left: 2em">上題詩寄與誰後十餘日有客來苑中又於葉上得</span>  
<span style="margin-left: 2em">詩以示況曰一葉題詩出禁城誰人酬和獨含情自</span>

<span style="margin-left: 2em">徐獻忠曰吾松濱於漲海猶稱名都非有寶玉珠璣</span>

<span style="margin-left: 2em">長有委道在廊廟而擅民宗顧其爲志實欲匡贊當</span>

<span style="margin-left: 1em">禮部侍郎顧清字士廉少與錢與謙齊名敏不逮錢而</span>

<span style="margin-left: 2em">情世用彪炳烜赫於天壤也決矣</span>  
<span style="margin-left: 1em">司訓王一鵬字九萬號西園詩宗元白淡雅成一家言</span>  
<span style="margin-left: 2em">人復瀟灑出塵有晉永和風致工書工畫每爲人題</span>  
<span style="margin-left: 2em">署尾必曰西園故西園之名特著</span>

<span style="margin-left: 2em">自繇故其詩多自得之意不蹈陳迹寫撰情景多驚</span>  
<span style="margin-left: 2em">人語</span>  
<span style="margin-left: 1em">禮部尚書孫承恩字貞甫歷承明著作之庭藻繪帝謨</span>  
<span style="margin-left: 2em">鴻裁特出嘗應制賦瑞雪詩　上特賜和書以龍箋</span>  
<span style="margin-left: 2em">鈐以御寶題爲和承恩瑞雪吟誠隆遇也</span>  
<span style="margin-left: 2em">文簡公喜與人談詩更憐惜才士嘗刻鶴坡龍淵一</span>  
<span style="margin-left: 2em">桂三詩人稿序云詩本性情而發於才才賦於天非</span>  
<span style="margin-left: 2em">窮之所能限也李杜窮同於郊島而其才之宏濶郊</span>  
<span style="margin-left: 2em">島所不能同也故李之作爲豪逸杜之作爲渾雄郊</span>  
<span style="margin-left: 2em">島所無也故郊寒島瘦噢吚慽蹙專於窮也三翁者</span>  
<span style="margin-left: 2em">窮以没齒而窮不限其才氣昌偉龍得李之放鶴得</span>  
<span style="margin-left: 2em">杜之蒼桂雖少劣而歌行諸篇亦頗得白傅之贍非</span>  
<span style="margin-left: 2em">郊島之一於窮也觀公論詩可以知公之詩矣</span>  
<span style="margin-left: 1em">大學士徐階蜀趙文肅貞吉云徐存翁相業似陸敬輿</span>  
<span style="margin-left: 2em">然敬輿詩不傳而存翁古近體直逼盛唐達者之言</span>  
<span style="margin-left: 2em">不難於無寒乞語難於有臺閣氣慮近俗也徐詩偏</span>  
<span style="margin-left: 2em">有遠致公有詩云雨時便住晴時出難道人謀不勝</span>  
<span style="margin-left: 2em">天此可覘公之相業矣</span>  
<span style="margin-left: 1em">禮部尚書陸樹聲字與吉養高林下有瀟灑物外之致</span>  
<span style="margin-left: 2em">詩曰陸瑁湖邊水漫流谷陽城外問漁舟鱸魚正美</span>  
<span style="margin-left: 2em">蓴系熟不到秋風已倦遊此詩何減老坡</span>  
<span style="margin-left: 1em">邑令徐獻忠王弇州曰獻忠詩法初唐又多六朝語雜</span>

<span style="margin-left: 2em">袁汝是曰徐子與合論詩五言重晉魏七言止取高</span>

<span style="margin-left: 2em">相出人其賦才尤爲人所重若布賦一篇憫念松人</span>  
<span style="margin-left: 2em">愁苦其情周委詳盡不蹈襲昔人體裁徒縱肆宏博</span>  
<span style="margin-left: 2em">至曲終而後奏雅者倫也</span>
