## 崇祯松江府志卷之四十七　古迹　灾异

<span style="margin-left: 3em">古迹</span>  
<span style="margin-left: 1em">志以志古也沧桑虽变往志可寻画家揣摹图为粉本</span>  
<span style="margin-left: 1em">骚人览眺采作诗题或若亡若存若承讹若摭实吾不</span>  
<span style="margin-left: 1em">得而定之则付之渔樵闲话质之弘览博物之君子而</span>  
<span style="margin-left: 1em">已志古迹</span>  
<span style="margin-left: 1em">周公墩华亭东南七十二里捍海塘外俗传府有周公</span>  
<span style="margin-left: 2em">孔子遗迹者缘北有孔宅南有是墩也旧经引枢要</span>  
<span style="margin-left: 2em">云周康王东游镇大海筑此城南接金山因名城距</span>  
<span style="margin-left: 2em">墩不十里当潮势奔猛处云间志云华亭襟带江海</span>  
<span style="margin-left: 2em">上而吴晋近而吴越皆筑城垒置防戍所以控守海</span>  
<span style="margin-left: 2em">道者至矣宋元仍旧城墩皆戍以兵然则墩盖古人</span>  
<span style="margin-left: 2em">所筑以防海处或者因康王金山城而传是名耳今</span>  
<span style="margin-left: 2em">金山营堡犹以是墩名者青龙南亦有白茅墩其东</span>  
<span style="margin-left: 2em">又有逢阵墩大抵皆烽堠也元大德中海港亦尝筑</span>  
<span style="margin-left: 2em">以捍湖云</span>  
<span style="margin-left: 1em">长谷亭唐陆广微吴地记在二十五里</span>  
<span style="margin-left: 1em">陆鹤墩在海上金山卫东二十余里陆平原内史尝于</span>  
<span style="margin-left: 2em">此处得鹤故名</span>  
<span style="margin-left: 1em">葛蓬墩在海上金山卫西其地生艾俗呼为蓬里人取</span>  
<span style="margin-left: 2em">灸病多神効相传为葛玄遗种从金山志</span>  
<span style="margin-left: 1em">吴王猎场旧图经云吴王猎所有五茸茸各有名在华</span>  
<span style="margin-left: 2em">亭谷东又旧经文云吴陆逊生此子孙常所游猎后</span>  
<span style="margin-left: 2em">人呼陆机茸今其地为桑陆陆龟蒙即事诗三泖凉</span>  
<span style="margin-left: 2em">波鱼蕝动五茸春草雉媒娇盖谓此也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">宋景祐初秀州华亭令唐询诗昔在全吴日从禽耀甲戈百车尝载羽一目旧张罗地变柔桑在原荒蔓草多思人无复见落日下山坡王安石和吴王好射虎但射不操戈匹马掠广场万兵助遮罗时平事非昔此地桑麻多猛兽亦已尽牛羊在田坡梅尧臣和孙氏有吴国四海未息戈猎以耀威武平野万骑罗英雄魏与蜀貔虎亦何多世事异莫究但见桑麻坡王艮和孙氏保泽国上马操金戈获禽非其志岂必施虞罗霸气凌秋旻精采一何多俯仰迹已陈禾麻被平坡段天祐和鼎足成功日蒐畋此注戈绣旗春浪卷铁骑夜星罗割据英雄尽登临感慨多年年二三月芳草睹阳坡徐献忠诗昔日吴王猎骑归五茸久已烧𤹉微沙头雁鹜犹成埒天外桑麻似合围十里孤城连落日几家秋思动征衣江南不愧称名郡祗觉风烟浄可依张世美诗猎场古吴壤君王恣游䠱异代蔓草缠寒烟空满目屠隆诗霸业在宣威高原试合围后宫开骑吹前队卷戎衣霜落胡鹰俊山空秋兎肥雄图收野火樵牧晚凉归</sub></span>  
<span style="margin-left: 1em">陆机茸</span>  
<span style="margin-left: 2em"><sub class="note-yuan">许尚诗二陆为童日驱驰晏忘归至今桑柘响禽鸟尚惊飞</sub></span>  
<span style="margin-left: 1em">三女冈旧图经县东南八十里吴王葬三女于此吴越</span>  
<span style="margin-left: 2em">春秋录异传有吴王葬女阊门外事吴郡图经阊门</span>  
<span style="margin-left: 2em">外有女坟湖枢要云吴王葬妃于此未知孰是明行</span>  
<span style="margin-left: 2em">寺记云寺近三女冈则冈在今南桥镇也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">唐询诗淑女云亡久哀丘尚著名九原谁可作千载或如生青骨何时化荒榛此地平空余图牒在不复启佳城王安石和自古世上雄慷慨擅功名当时岂有力能使死者生三女共一丘此憾亦难平音容若有作无乃倾人城梅尧臣和吴王葬三女因留此冈名已化彼粲质合有兰蕙生婵娟夜月照晻蔼朝雾平古魂如未泯不返阖闾城王艮和传闻三女祠不志三女名萧萧白杨尽靡靡芳草生西施殆其国此恨尚未平碧血化游燐犹当照吴城段天祐和三女共葬此无姓亦无名至今高冈上祗见明月生阿曲云霾合陂陀草露平芳魂如可返犹解惑阳城许尚诗玉殓知无有香魂计已消频来吟楚些岁久若为招屠隆诗三女临妆镜千花娇映人金钗没黄土玉骨化青燐昔有宫娥侍今为野鸟邻繁华总如此所以贵清真</sub></span>  
<span style="margin-left: 1em">秦始皇驰道郡西北昆山南四里相传有大堈路西通</span>  
<span style="margin-left: 2em">吴城即驰道也舆地志秦始皇东游至会稽句章渡</span>  
<span style="margin-left: 2em">海经此按汉贾山至言秦始皇驰道遍于天下东穷</span>  
<span style="margin-left: 2em">燕齐南极吴楚此盖其一也按昆山南四里即古浦</span>  
<span style="margin-left: 2em">塘然则驰道即塘之岸也山之北又有秦始皇走马</span>  
<span style="margin-left: 2em">塘</span>  
<span style="margin-left: 2em"><sub class="note-yuan">唐询诗秦德衰千祀江滨道不修相传大隄在曾是翠华游玉趾如将见金椎岂复留怅然寻旧迹蔓草蔽郊丘王安石和穆王乘八骏万事得其修茫茫千载间复此好远游车轮与马迹此地亦尝留想当治道时劳者尸如丘梅尧臣和秦帝观沧海劳人何得修石桥虹霓断驰道鹿麋游车辙久已没马迹亦无留骊山宝衣尽万古空冢丘王艮和秦皇混六合荒诞殄厥修求僊望蓬莱驱车乃东游道毙杂鲍鱼腥风久弥留徐福竟不还何处营丹丘段天祐和嬴政大狂惑轮蹄无阻修驰道弥六合此身能几游何曾悔心起祗有恶名留长城一千里不解障沙丘许尚诗叹息秦皇帝何年此逸游迢迢大堈路千古为嗟羞屠隆诗风烟包九州八骏想同游飒飒神鞭下萧萧鬼语愁松高清跸响云白海风秋自是无灵气三山实可求</sub></span>  
<span style="margin-left: 1em">白苎城县南四十里高一丈周一万步旧经云地生野</span>  
<span style="margin-left: 2em">苎因名今俗云白苎汇</span>  
<span style="margin-left: 1em">由拳塞秦始皇造通陵道到由拳塞因起马塘湛以为</span>  
<span style="margin-left: 2em">陂治陵水道到钱塘越地通浙江</span>  
<span style="margin-left: 1em">东庵在亭林中有忠烈公像庵地尝裂数尺中有风涛</span>  
<span style="margin-left: 2em">声以物探之则应手火起</span>  
<span style="margin-left: 1em">烽楼在亭林南按法云寺记载唐隰州司仓支令问妻</span>  
<span style="margin-left: 2em">曹氏墓志云葬顾亭林南烽楼之侧其南冈阜相属</span>  
<span style="margin-left: 2em">世传为野王墓非也寰宇记南带海上有烽火楼基</span>  
<span style="margin-left: 2em">吴时望海处今遗迹犹存</span>  
<span style="margin-left: 2em"><sub class="note-yuan">钱良臣诗伊昔边烽备不虞太平移作梵王居而今江表全无事借我三椽更读书</sub></span>  
<span style="margin-left: 1em">黄耳冢述异记陆机少时颇好猎在吴有家客献快犬</span>  
<span style="margin-left: 2em">曰黄耳后机仕洛将以自随犬黠慧解人语机尝戏</span>  
<span style="margin-left: 2em">语曰家久无书汝能驰往否犬摇尾作声似应之机</span>  
<span style="margin-left: 2em">为书盛以竹筒系犬颈走向吴经水辄依渡者掉尾</span>  
<span style="margin-left: 2em">向之得渡则腾上速去到家得书还向驰洛后死还</span>  
<span style="margin-left: 2em">葬其家村南二百步聚土为坟呼为黄耳冢商芸小</span>  
<span style="margin-left: 2em">说后分华亭村南为黄耳村以犬冢为号独刘贡父</span>  
<span style="margin-left: 2em">诗话以黄耳为仆未知何据今冢在城南二里余傍</span>  
<span style="margin-left: 2em">有普宁尼寺守之俗讹为黄泥寺然不闻所谓黄耳</span>  
<span style="margin-left: 2em">村也</span>  
<span style="margin-left: 2em">华亭黄耳寺以犬得名相兽经犬白身而黄耳者能</span>  
<span style="margin-left: 2em">知人家吉凶事是犬为陆机传信三千里亦异犬也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">冯元城集袁海叟诗黄犬墓前春日迟柳条花蕚正参差豪华已逐浮云去异物犹令后代思顾养有恩终不背交游何事独相欺春风绿酒人皆醉落日孤舟自咏诗屠隆诗生来多慧性死去即名村亦有猕猴果何论鹦鹉言水深迷草径月冷吠花源索莫平原里应怜旧主恩</sub></span>  
<span style="margin-left: 1em">南庵堂壁有六祖画像</span>  
<span style="margin-left: 1em">毘卢庵句氏香火院中有御书阁</span>  
<span style="margin-left: 2em"><sub class="note-yuan">许尚诗扪萝通一径修竹蔽中篱只有奎章在龙神暗护持</sub></span>  
<span style="margin-left: 1em">异木尝见梦商人自称土地神云祭我令汝宜商自是</span>  
<span style="margin-left: 2em">商人岁祠之祠必以夜半</span>  
<span style="margin-left: 2em"><sub class="note-yuan">许尚诗蟠根知永远曲干耸蛟虬闽贾蒙私庇年年此荐羞</sub></span>  
<span style="margin-left: 1em">赵店在府治西昔未邑之日市东名赵店今像夫妇谓</span>  
<span style="margin-left: 2em">之赵店土地祠之</span>

<span style="margin-left: 2em">年立幢镇之或传嘉兴楞严寺祖僧塔</span>  
<span style="margin-left: 2em">欹枕手镜云松最近海故平地类多有海眼城之西</span>  
<span style="margin-left: 2em">南隅八角井相传此井是地窍祷雨时以铁牌系鱼</span>  
<span style="margin-left: 2em">下井中不三日渔者得之白龙潭此海眼也华亭县</span>

<span style="margin-left: 2em">地似空洞久或有崩陷之患山中泉脉自是水源与</span>  
<span style="margin-left: 2em">此不同也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">许尚诗屹立应千载传因海眼成蓬莱水三浅曾不见欹倾</sub></span>

<span style="margin-left: 2em"><sub class="note-yuan">诈尚诗刻凿知何谓弥年亦有神宵行无足怪一吼亦惊人</sub></span>

<span style="margin-left: 2em">潮啮山北岸下瞰桥井犹凿凿有得一碑曰鹦鹉洲</span>  
<span style="margin-left: 2em">界</span>  
<span style="margin-left: 1em">文翚洲黄浦中洲生仅寻丈许今已延广三十余亩有</span>  
<span style="margin-left: 2em">群雉翚映鸥左右因名文翚洲</span>

<span style="margin-left: 2em">余尾光耀地复从东流至翼轸而没庚子午刻两日</span>  
<span style="margin-left: 2em">相荡是夜子刻月食甲辰日色变白无光烈风雨沙</span>  
<span style="margin-left: 2em">凡三日壬戌卯刻日色变白黑日数颗掩日相荡三</span>  
<span style="margin-left: 2em">月戊午卯刻两日相荡者久之庚申夜一鼓黑虹见</span>  
<span style="margin-left: 2em">于南方其长亘天五月中旬后淫雨彻昼夜不止遂</span>  
<span style="margin-left: 2em">成巨浸秧苗菜麦几尽岁饥</span>  
<span style="margin-left: 1em">乙丑三月大雨雹伤麦七月日下有晕如黑日欲蚀状</span>  
<span style="margin-left: 2em">又有大星现东方红芒四射是岁启明不见者半载</span>  
<span style="margin-left: 1em">丙寅七月初一日飓风霖雨两日夜拔木震屋郡谯楼</span>  
<span style="margin-left: 2em">尽倾水势顿添数尺二月八日大北风雨雹杀麦七</span>  
<span style="margin-left: 2em">月二十一日大风雨摇荡庐舍城内外有执盖过桥</span>
