## 崇禎松江府志卷之四十七　古蹟　災異

<span style="margin-left: 3em">古蹟</span>  
<span style="margin-left: 1em">志以志古也滄桑雖變往志可尋畫家揣摹圖爲粉本</span>  
<span style="margin-left: 1em">騷人覽眺採作詩題或若亡若存若承訛若摭實吾不</span>  
<span style="margin-left: 1em">得而定之則付之漁樵閑話質之弘覽博物之君子而</span>  
<span style="margin-left: 1em">已志古蹟</span>  
<span style="margin-left: 1em">周公墩華亭東南七十二里捍海塘外俗傳府有周公</span>  
<span style="margin-left: 2em">孔子遺蹟者緣北有孔宅南有是墩也舊經引樞要</span>  
<span style="margin-left: 2em">云周康王東遊鎮大海築此城南接金山因名城距</span>  
<span style="margin-left: 2em">墩不十里當潮勢奔猛處雲間志云華亭襟帶江海</span>  
<span style="margin-left: 2em">上而吳晉近而吳越皆築城壘置防戍所以控守海</span>  
<span style="margin-left: 2em">道者至矣宋元仍舊城墩皆戍以兵然則墩蓋古人</span>  
<span style="margin-left: 2em">所築以防海處或者因康王金山城而傳是名耳今</span>  
<span style="margin-left: 2em">金山營堡猶以是墩名者青龍南亦有白茅墩其東</span>  
<span style="margin-left: 2em">又有逢陣墩大抵皆烽堠也元大德中海港亦嘗築</span>  
<span style="margin-left: 2em">以捍湖云</span>  
<span style="margin-left: 1em">長谷亭唐陸廣微吳地記在二十五里</span>  
<span style="margin-left: 1em">陸鶴墩在海上金山衛東二十餘里陸平原內史嘗於</span>  
<span style="margin-left: 2em">此處得鶴故名</span>  
<span style="margin-left: 1em">葛蓬墩在海上金山衛西其地生艾俗呼爲蓬里人取</span>  
<span style="margin-left: 2em">灸病多神効相傳爲葛玄遺種從金山志</span>  
<span style="margin-left: 1em">吳王獵場舊圖經云吳王獵所有五茸茸各有名在華</span>  
<span style="margin-left: 2em">亭谷東又舊經文云吳陸遜生此子孫常所遊獵後</span>  
<span style="margin-left: 2em">人呼陸機茸今其地爲桑陸陸龜蒙即事詩三泖涼</span>  
<span style="margin-left: 2em">波魚蕝動五茸春草雉媒嬌蓋謂此也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">宋景祐初秀州華亭令唐詢詩昔在全吳日從禽耀甲戈百車嘗載羽一目舊張羅地變柔桑在原荒蔓草多思人無復見落日下山坡王安石和吳王好射虎但射不操戈匹馬掠廣場萬兵助遮羅時平事非昔此地桑麻多猛獸亦已盡牛羊在田坡梅堯臣和孫氏有吳國四海未息戈獵以耀威武平野萬騎羅英雄魏與蜀貔虎亦何多世事異莫究但見桑麻坡王艮和孫氏保澤國上馬操金戈獲禽非其志豈必施虞羅霸氣凌秋旻精采一何多俯仰迹已陳禾麻被平坡段天祐和鼎足成功日蒐畋此注戈繡旗春浪捲鐵騎夜星羅割據英雄盡登臨感慨多年年二三月芳草睹陽坡徐獻忠詩昔日吳王獵騎歸五茸久已燒𤹉微沙頭雁鶩猶成埒天外桑麻似合圍十里孤城連落日幾家秋思動征衣江南不愧稱名郡祗覺風烟浄可依張世美詩獵場古吳壤君王恣遊䠱異代蔓草纏寒烟空滿目屠隆詩霸業在宣威高原試合圍後宫開騎吹前隊捲戎衣霜落胡鷹俊山空秋兎肥雄圖收野火樵牧晚涼歸</sub></span>  
<span style="margin-left: 1em">陸機茸</span>  
<span style="margin-left: 2em"><sub class="note-yuan">許尚詩二陸爲童日驅馳晏忘歸至今桑柘響禽鳥尚驚飛</sub></span>  
<span style="margin-left: 1em">三女岡舊圖經縣東南八十里吳王葬三女于此吳越</span>  
<span style="margin-left: 2em">春秋錄異傳有吳王葬女閶門外事吳郡圖經閶門</span>  
<span style="margin-left: 2em">外有女墳湖樞要云吳王葬妃于此未知孰是明行</span>  
<span style="margin-left: 2em">寺記云寺近三女岡則岡在今南橋鎮也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">唐詢詩淑女云亡久哀丘尚著名九原誰可作千載或如生青骨何時化荒榛此地平空餘圖牒在不復啓佳城王安石和自古世上雄慷慨擅功名當時豈有力能使死者生三女共一丘此憾亦難平音容若有作無乃傾人城梅堯臣和吳王葬三女因留此岡名已化彼粲質合有蘭蕙生嬋娟夜月照晻藹朝霧平古魂如未泯不返闔閭城王艮和傳聞三女祠不誌三女名蕭蕭白楊盡靡靡芳草生西施殆其國此恨尚未平碧血化游燐猶當照吳城段天祐和三女共葬此無姓亦無名至今高岡上祗見明月生阿曲雲霾合陂陀草露平芳魂如可返猶解惑陽城許尚詩玉殮知無有香魂計已消頻來吟楚些歲久若爲招屠隆詩三女臨妝鏡千花嬌映人金釵没黃土玉骨化青燐昔有宫娥侍今爲野鳥鄰繁華總如此所以貴清真</sub></span>  
<span style="margin-left: 1em">秦始皇馳道郡西北崑山南四里相傳有大堈路西通</span>  
<span style="margin-left: 2em">吳城即馳道也輿地志秦始皇東遊至會稽句章渡</span>  
<span style="margin-left: 2em">海經此按漢賈山至言秦始皇馳道遍于天下東窮</span>  
<span style="margin-left: 2em">燕齊南極吳楚此蓋其一也按崑山南四里即古浦</span>  
<span style="margin-left: 2em">塘然則馳道即塘之岸也山之北又有秦始皇走馬</span>  
<span style="margin-left: 2em">塘</span>  
<span style="margin-left: 2em"><sub class="note-yuan">唐詢詩秦德衰千祀江濱道不修相傳大隄在曾是翠華遊玉趾如將見金椎豈復留悵然尋舊迹蔓草蔽郊丘王安石和穆王乘八駿萬事得其修茫茫千載間復此好遠遊車輪與馬跡此地亦嘗留想當治道時勞者屍如丘梅堯臣和秦帝觀滄海勞人何得修石橋虹霓斷馳道鹿麋遊車轍久已没馬迹亦無留驪山寶衣盡萬古空冢丘王艮和秦皇混六合荒誕殄厥修求僊望蓬萊驅車乃東遊道斃雜鮑魚腥風久彌留徐福竟不還何處營丹丘段天祐和嬴政大狂惑輪蹄無阻修馳道彌六合此身能幾遊何曾悔心起祗有惡名留長城一千里不解障沙丘許尚詩歎息秦皇帝何年此逸遊迢迢大堈路千古爲嗟羞屠隆詩風烟包九州八駿想同遊颯颯神鞭下蕭蕭鬼語愁松高清蹕響雲白海風秋自是無靈氣三山實可求</sub></span>  
<span style="margin-left: 1em">白苧城縣南四十里高一丈周一萬步舊經云地生野</span>  
<span style="margin-left: 2em">苧因名今俗云白苧匯</span>  
<span style="margin-left: 1em">由拳塞秦始皇造通陵道到由拳塞因起馬塘湛以爲</span>  
<span style="margin-left: 2em">陂治陵水道到錢塘越地通浙江</span>  
<span style="margin-left: 1em">東菴在亭林中有忠烈公像菴地嘗裂數尺中有風濤</span>  
<span style="margin-left: 2em">聲以物探之則應手火起</span>  
<span style="margin-left: 1em">烽樓在亭林南按法雲寺記載唐隰州司倉支令問妻</span>  
<span style="margin-left: 2em">曹氏墓誌云葬顧亭林南烽樓之側其南岡阜相屬</span>  
<span style="margin-left: 2em">世傳爲野王墓非也寰宇記南帶海上有烽火樓基</span>  
<span style="margin-left: 2em">吳時望海處今遺跡猶存</span>  
<span style="margin-left: 2em"><sub class="note-yuan">錢良臣詩伊昔邊烽備不虞太平移作梵王居而今江表全無事借我三椽更讀書</sub></span>  
<span style="margin-left: 1em">黃耳塚述異記陸機少時頗好獵在吳有家客獻快犬</span>  
<span style="margin-left: 2em">曰黃耳後機仕洛將以自隨犬黠慧解人語機嘗戲</span>  
<span style="margin-left: 2em">語曰家久無書汝能馳往否犬摇尾作聲似應之機</span>  
<span style="margin-left: 2em">爲書盛以竹筒繫犬頸走向吳經水輒依渡者掉尾</span>  
<span style="margin-left: 2em">向之得渡則騰上速去到家得書還向馳洛後死還</span>  
<span style="margin-left: 2em">葬其家村南二百步聚土爲墳呼爲黃耳塚商芸小</span>  
<span style="margin-left: 2em">說後分華亭村南爲黃耳村以犬塚爲號獨劉貢父</span>  
<span style="margin-left: 2em">詩話以黃耳爲僕未知何據今塚在城南二里餘傍</span>  
<span style="margin-left: 2em">有普寧尼寺守之俗訛爲黃泥寺然不聞所謂黃耳</span>  
<span style="margin-left: 2em">村也</span>  
<span style="margin-left: 2em">華亭黃耳寺以犬得名相獸經犬白身而黃耳者能</span>  
<span style="margin-left: 2em">知人家吉凶事是犬爲陸機傳信三千里亦異犬也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">馮元城集袁海叟詩黃犬墓前春日遲柳條花蕚正參差豪華已逐浮雲去異物猶令後代思顧養有恩終不背交游何事獨相欺春風綠酒人皆醉落日孤舟自詠詩屠隆詩生來多慧性死去即名村亦有獼猴果何論鸚鵡言水深迷草徑月冷吠花源索莫平原里應憐舊主恩</sub></span>  
<span style="margin-left: 1em">南菴堂壁有六祖畫像</span>  
<span style="margin-left: 1em">毘盧菴句氏香火院中有御書閣</span>  
<span style="margin-left: 2em"><sub class="note-yuan">許尚詩捫蘿通一徑修竹蔽中籬只有奎章在龍神暗護持</sub></span>  
<span style="margin-left: 1em">異木嘗見夢商人自稱土地神云祭我令汝宜商自是</span>  
<span style="margin-left: 2em">商人歲祠之祠必以夜半</span>  
<span style="margin-left: 2em"><sub class="note-yuan">許尚詩蟠根知永遠曲幹聳蛟虬閩賈蒙私庇年年此薦羞</sub></span>  
<span style="margin-left: 1em">趙店在府治西昔未邑之日市東名趙店今像夫婦謂</span>  
<span style="margin-left: 2em">之趙店土地祠之</span>  
<span style="margin-left: 1em">石幢在華亭縣前相傳地有湧泉云是海眼大中十三</span>  
<span style="margin-left: 2em">年立幢鎮之或傳嘉興楞嚴寺祖僧塔</span>  
<span style="margin-left: 2em">欹枕手鏡云松最近海故平地類多有海眼城之西</span>  
<span style="margin-left: 2em">南隅八角井相傳此井是地竅禱雨時以鐵牌繫魚</span>  
<span style="margin-left: 2em">下井中不三日漁者得之白龍潭此海眼也華亭縣</span>  
<span style="margin-left: 2em">前石幢相傳其下是海眼故以此鎮塞之上海縣浦</span>  
<span style="margin-left: 2em">東陸儼山祖居前亦有海眼晝夜泡起不息是山中</span>  
<span style="margin-left: 2em">泉脈儼山少時甃石爲方池至今猶存凡海眼處必</span>  
<span style="margin-left: 2em">地似空洞久或有崩陷之患山中泉脈自是水源與</span>  
<span style="margin-left: 2em">此不同也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">許尚詩屹立應千載傳因海眼成蓬萊水三淺曾不見欹傾</sub></span>  
<span style="margin-left: 1em">石獸在府東嘗爲變怪夜則環市而走遂斷其一足</span>  
<span style="margin-left: 2em"><sub class="note-yuan">詐尚詩刻鑿知何謂彌年亦有神宵行無足怪一吼亦驚人</sub></span>  
<span style="margin-left: 1em">鸚鵡洲在海中金山下山北古海鹽列後淪於海元末</span>  
<span style="margin-left: 2em">潮齧山北岸下瞰橋井猶鑿鑿有得一碑曰鸚鵡洲</span>  
<span style="margin-left: 2em">界</span>  
<span style="margin-left: 1em">文翬洲黃浦中洲生僅尋丈許今已延廣三十餘畝有</span>  
<span style="margin-left: 2em">群雉翬映鷗左右因名文翬洲</span>  
<span style="margin-left: 2em"><sub class="note-yuan">王逢詩我來初避地黃浦漸生洲里諺歸材傑天工障濁流望疑堅壁守醉覺小山浮仙躡金鼇背神迴白馬頭根盤連厚軸形勢壯遐陬漁倚盲風釣商藏疾雨舟篠鞭伸玉節荻筍屈紅鈎烟火鮫爲市雲霞蜃作樓沙津魚鼓急水栅蟹燈幽艮震方先曙吳淞木始秋老懷龎德隴隱覓謝鯤丘僮御争先導吾儕試一遊賡歌清氣合樂志古人侔可信文翬雉能盟懶性鷗</sub></span>  
<span style="margin-left: 1em">綾錦墩在盤龍塘上錢全袞種桑之所</span>  
<span style="margin-left: 2em"><sub class="note-yuan">楊維禎詩先生綾錦墩邊住日日柴門踏錦沙千古清風高士傳一溪流水野人家將軍樹老秋風裏使者槎迴碧海涯不鬪金園紫絲障鳳笙吹月醉桃花王逢詩華亭東有蟠龍塘塘上姓錢人種桑就陽避濕淺布子畦分疃列如針秧封培愛厚長尺許畚鍤争移春社雨惰農報德也自奇一本約輸雙簣土土高過客相指語千綾萬錦登城府懷材莫救時斂徵存心尚念農辛苦侍御題名綾錦墩錢郎笑歌墩樹根但願一絲不到體老著布袍青苧村</sub></span>  
<span style="margin-left: 1em">駱駝墩又呼落彈墩在簳山北任仁發墓在焉新志又</span>  
<span style="margin-left: 2em">云宋理宗妃林氏葬此</span>  
<span style="margin-left: 1em">鶴坡在下沙鎮此地出鶴俗又謂鶴窠</span>  
<span style="margin-left: 2em"><sub class="note-yuan">孫怡詩歸舟傍南坡坡樹雜嵐氣上有胎禽巢不知育雛未</sub></span>  
<span style="margin-left: 1em">石筍灘在下沙捍海塘外抵海三十餘里每二三丈沙</span>  
<span style="margin-left: 2em">汭中有石如筍者彌望潮汐至此其流遂分本名分</span>  
<span style="margin-left: 2em">水港喜事者易以今名莫原何代所建相傳此處潮</span>  
<span style="margin-left: 2em">勢悍激輒壞隄防自建石筍厥勢分矣</span>  
<span style="margin-left: 2em"><sub class="note-yuan">朱仲雲感古詩不見沙頭洗玉瓶閑移小艇弔江濱豪華銷歇今非古依舊春風岸草青</sub></span>  
<span style="margin-left: 1em">古岡身有三曰沙岡竹岡紫岡在府東七十里南屬于</span>  
<span style="margin-left: 2em">海北抵松江長百里入土數尺皆螺蚌殻世傳海中</span>  
<span style="margin-left: 2em">湧三浪而成其地高阜宜菽麥吳郡圖經謂瀕海之</span>

<span style="margin-left: 2em">爲月所食十二月丁未申刻地大震聲如風雨自西</span>  
<span style="margin-left: 2em">北往東南屋宇動摇久之鄉鎮皆然</span>  
<span style="margin-left: 1em">甲子正月癸未日赤如赭慘淡無光申刻有黑氣如日</span>  
<span style="margin-left: 2em">與太陽相盪翌日色赤如血復變青藍色人久視不</span>  
<span style="margin-left: 2em">眩二月乙酉朔日出没有黑氣如日與太陽相盪飛</span>  
<span style="margin-left: 2em">流不定是日日赤如赭癸巳日没後有星大如碗色</span>  
<span style="margin-left: 2em">赤從西至東化爲二星一大一小一赤一白相去尺</span>  
<span style="margin-left: 2em">餘尾光耀地復從東流至翼軫而没庚子午刻兩日</span>  
<span style="margin-left: 2em">相盪是夜子刻月食甲辰日色變白無光烈風雨沙</span>  
<span style="margin-left: 2em">凡三日壬戌卯刻日色變白黑日數顆掩日相盪三</span>  
<span style="margin-left: 2em">月戊午卯刻兩日相盪者久之庚申夜一鼓黑虹見</span>  
<span style="margin-left: 2em">于南方其長亘天五月中旬後淫雨徹晝夜不止遂</span>  
<span style="margin-left: 2em">成巨浸秧苗菜麥幾盡歲饑</span>  
<span style="margin-left: 1em">乙丑三月大雨雹傷麥七月日下有暈如黑日欲蝕狀</span>  
<span style="margin-left: 2em">又有大星現東方紅芒四射是歲啓明不見者半載</span>  
<span style="margin-left: 1em">丙寅七月初一日颶風霖雨兩日夜拔木震屋郡譙樓</span>  
<span style="margin-left: 2em">盡傾水勢頓添數尺二月八日大北風雨雹殺麥七</span>  
<span style="margin-left: 2em">月二十一日大風雨摇蕩廬舍城內外有執蓋過橋</span>  
<span style="margin-left: 2em">者漂溺多死</span>
