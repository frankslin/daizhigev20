## 崇禎松江府志卷之十三　荒政

<span style="margin-left: 3em">荒政</span>  
<span style="margin-left: 1em">古云救荒無奇策此言似是而實非也長吏盡心設處</span>  
<span style="margin-left: 1em">而士大夫以實心策應之何事不辨若議論顔多文移</span>  
<span style="margin-left: 1em">展轉其不索於枯魚之肆者幾希此口上救荒紙上救</span>  
<span style="margin-left: 1em">荒耳活數百萬生靈勝二十四考中書令如富鄭公之</span>  
<span style="margin-left: 1em">於青州何嘗不奇乎又聞陽明先生云饑民必救亂民</span>  
<span style="margin-left: 1em">必斬荒政之奇更盡括于此矣救荒如救焚何可不載</span>  
<span style="margin-left: 1em">故特補前志之闕</span>  
<span style="margin-left: 1em">勅諭</span>  
<span style="margin-left: 1em">洪武元年八月詔今歲水旱去處所在官司不拘時限</span>  
<span style="margin-left: 1em">從實踏勘實災租稅即與蠲免</span>  
<span style="margin-left: 1em">二年十二月賑應天蘇松杭湖諸郡貧民人給米一石</span>  
<span style="margin-left: 1em">棉布一疋</span>  
<span style="margin-left: 1em">十一年五月　上以蘇松嘉湖之民嘗被水災已嘗遣</span>  
<span style="margin-left: 1em">使賑濟至是復慮其困乏再遣使存問仍濟飢民六萬</span>  
<span style="margin-left: 1em">二千八百四十四户命户賜米一石免其逋租六十五</span>  
<span style="margin-left: 1em">萬二千八百二十八石</span>  
<span style="margin-left: 1em">七月蘇州松江揚州台州四府海溢漂民居人多溺死</span>  
<span style="margin-left: 1em">者詔遣官存恤之</span>  
<span style="margin-left: 1em">十一月　上以蘇松嘉湖杭五府屢被水災艱於衣食</span>  
<span style="margin-left: 1em">命悉罷五府河泊所免其稅課以其利與民今歲魚課</span>  
<span style="margin-left: 1em">未入徵者亦免之</span>  
<span style="margin-left: 1em">永樂二年八月户部臣言松江府華上二縣今歲水災</span>  
<span style="margin-left: 1em">低田稅糧宜令以帛代輸從之</span>  
<span style="margin-left: 1em">十一月以蘇松嘉湖杭等府水災蠲其今年糧六十萬</span>  
<span style="margin-left: 1em">九千九百餘石</span>  
<span style="margin-left: 1em">四年九月賑蘇松嘉湖杭常六府流徙復業民户十二</span>  
<span style="margin-left: 1em">萬二千九百有奇給粟十五萬七千一百石有奇</span>  
<span style="margin-left: 1em">十二年十一月蠲蘇松嘉湖杭五府水災田租四十七</span>  
<span style="margin-left: 1em">萬九千七百餘石初有司請減半徵之上謂户部尚書</span>  
<span style="margin-left: 1em">夏原吉等曰民田被水無收未有以賑之又可徵稅耶</span>  
<span style="margin-left: 1em">悉蠲之</span>  
<span style="margin-left: 1em">二十二年十月命户部蘇松嘉等被水災處今歲秋糧</span>  
<span style="margin-left: 1em">悉令折輸布鈔如永樂五年例每石輸布一疋或鈔六</span>  
<span style="margin-left: 1em">錠</span>  
<span style="margin-left: 1em">洪熙元年正月勑布政使周幹等巡行應天八府察民</span>  
<span style="margin-left: 1em">利病諭曰朕祗奉鴻圖君臨兆庶惓惓夙夜康濟爲心</span>  
<span style="margin-left: 1em">而南方諸郡尤厪念慮誠以民衆地遠情難上通今特</span>  
<span style="margin-left: 1em">命爾等巡視應天鎮江常州蘇州松江湖州杭州嘉興</span>  
<span style="margin-left: 1em">八府其軍民安否何似何弊當去何利當建審求其故</span>  
<span style="margin-left: 1em">具以實聞爾等必公必勤毋徒苟應故事庶副朕憂憫</span>  
<span style="margin-left: 1em">元元之意欽哉</span>  
<span style="margin-left: 1em">宣德元年九月左通政岳福奏蘇松嘉湖諸郡春夏久</span>  
<span style="margin-left: 1em">雨禾稼損傷　上命行在户部遣官覆視被災者蠲其</span>  
<span style="margin-left: 1em">稅</span>  
<span style="margin-left: 1em">三年八月巡按直隸監察御史林文秩言蘇州府吳江</span>  
<span style="margin-left: 1em">常熟等縣松江府華亭縣久雨山水衝決圩岸渰没田</span>  
<span style="margin-left: 1em">苗命行在户部驗數蠲租</span>  
<span style="margin-left: 1em">十月巡撫蘇松等處大理寺卿胡槩奏各部累差郎中</span>  
<span style="margin-left: 1em">主事等官催督蘇松及浙江諸郡造紙買銅鐵等物今</span>  
<span style="margin-left: 1em">年蘇松及紹興等府水澇民飢乞停買諸物所差官員</span>  
<span style="margin-left: 1em">悉取回京　上命六部除軍需所用外餘悉停止所差</span>  
<span style="margin-left: 1em">官員各令還京</span>  
<span style="margin-left: 1em">七年九月巡按蘇松監察御史王來言今年四月至六</span>  
<span style="margin-left: 1em">月苦雨海潮泛溢漫没堤圩所屬長洲吳江崑山常熟</span>  
<span style="margin-left: 1em">華亭上海宜興金壇八縣低田皆没苗稼無收　上命</span>  
<span style="margin-left: 1em">行在户部遣人覆視蠲其租稅</span>  
<span style="margin-left: 1em">九年八月勑諭應天蘇松等府州縣今水旱蝗蝻災傷</span>  
<span style="margin-left: 1em">之處民人缺食好生艱辛但是工部派辦物料即皆停</span>  
<span style="margin-left: 1em">止待豐熟之時辦納其不係災傷之處所派辦物料亦</span>  
<span style="margin-left: 1em">皆陸續辦納不許逼迫差去催辦官員人等除修造海</span>  
<span style="margin-left: 1em">船物料外其餘悉令回　京不許遷延在外擾民違者</span>  
<span style="margin-left: 1em">論罪不恕爾等其體朕恤民之心欽哉故諭</span>  
<span style="margin-left: 1em">十月勑諭巡撫侍郎周忱比聞直隸亢旱兵民飢窘良</span>  
<span style="margin-left: 1em">用惻然今將寬恤事件特勑頒示爾等其欽承朕命毋</span>  
<span style="margin-left: 1em">怠故諭被災之處人民乏食爾等即委官前去於所在</span>  
<span style="margin-left: 1em">官倉量給米糧賑濟毋得坐視民患</span>  
<span style="margin-left: 1em">正統五年五月以水災命直隸松江府華亭上海二縣</span>  
<span style="margin-left: 1em">今年折糧大三梭布五萬九千七百三十二疋免徵第</span>  
<span style="margin-left: 1em">徵中等三梭布二萬疋每疋折糧二石其餘折徵闊白</span>  
<span style="margin-left: 1em">綿布</span>  
<span style="margin-left: 1em">七月勑行在工部右侍郎周忱得奏蘇松等府潦水爲</span>  
<span style="margin-left: 1em">患農不及耕心爲惻焉今遣員外郎王瑛往視就齎勑</span>  
<span style="margin-left: 1em">諭爾即躬自踏勘凡各部所渰没不得耕種之處具實</span>  
<span style="margin-left: 1em">奏來處置其被水之民有艱難乏食者悉於官倉儲糧</span>  
<span style="margin-left: 1em">給濟仍戒飭郡邑官善加存卹毋令失所</span>  
<span style="margin-left: 1em">十年八月巡撫直隸工部左侍郎周忱奏南直隸并浙</span>  
<span style="margin-left: 1em">江蘇松嘉湖等十四府州正統九年水災無徵糧米共</span>  
<span style="margin-left: 1em">四十九萬三千五百六十三石有奇　上命户部驗寔</span>  
<span style="margin-left: 1em">蠲之</span>  
<span style="margin-left: 1em">十二年四月免直隸常州蘇州松江鎮江四府蘇州鎮</span>  
<span style="margin-left: 1em">海二衛被災秋糧子粒八十八萬四千七百七十餘石</span>  
<span style="margin-left: 1em">草二十一萬六百三十餘包</span>  
<span style="margin-left: 1em">景泰五年九月户部尚書張鳳等奏浙江嘉湖直隸蘇</span>  
<span style="margin-left: 1em">松常揚等府被災等處今年兑軍糧一百三十四萬餘</span>  
<span style="margin-left: 1em">石民運糧八十三萬二千餘石宜停免令軍就淮安常</span>  
<span style="margin-left: 1em">盈大軍等倉支運五十萬石邳州倉支運四萬石每石</span>  
<span style="margin-left: 1em">加耗一斗五升臨清倉支運十萬石每石加耗六升德</span>  
<span style="margin-left: 1em">州倉支米二十四萬石每石加耗五升以補盤剥之費</span>  
<span style="margin-left: 1em">俱赴通州倉交納其民運糧數并各項起運存留馬草</span>  
<span style="margin-left: 1em">折銀等項候差官踏勘災傷至日奏請定奪</span>  
<span style="margin-left: 1em">成化二年閏三月發松江府糧十萬石賑濟淮徐等處</span>  
<span style="margin-left: 1em">飢民<sub class="note-yuan">從巡撫都御史林聰請</sub></span>  
<span style="margin-left: 1em">十五年七月南畿巡撫王恕極論東南困苦乞培養元</span>  
<span style="margin-left: 1em">氣竝以災異上聞臣自去年奉命巡撫之後節據撫屬</span>  
<span style="margin-left: 1em">申奏各部勘合派買各項物件未免助辦于民里甲多</span>  
<span style="margin-left: 1em">致逃移臣惟凡此之類朝廷之上固有不可缺者亦有</span>  
<span style="margin-left: 1em">可減省者亦有可缺者如糧餉軍需此不可缺者也花</span>  
<span style="margin-left: 1em">樣段疋可減省者也珍奇玩好可缺者也今當軍民災</span>  
<span style="margin-left: 1em">荒凋弊之後凡百冗費宜樽節一應不急之務俱宜停</span>  
<span style="margin-left: 1em">止俾軍民息肩實爲社稷之福又兩京一應收受錢糧</span>  
<span style="margin-left: 1em">內外官員請勅戒諭各公乃心憫念民艱毋刁蹬留難</span>  
<span style="margin-left: 1em">毋巧取財物毋多收斛面愛惜民財培養元氣如或不</span>  
<span style="margin-left: 1em">悛令科道官指實參奏拿問則東南困苦其少甦矣</span>  
<span style="margin-left: 1em">上命查理禁約<sub class="note-yuan">大政記</sub></span>  
<span style="margin-left: 1em">十七年七月以水旱免松江府秋糧米八萬五千三百</span>  
<span style="margin-left: 1em">餘石草一萬三千餘包</span>  
<span style="margin-left: 1em">弘治四年八月工部尚書賈俊言蘇松浙江近被水患</span>  
<span style="margin-left: 1em">民不聊生而頃者織造段疋之令至于再三其數不下</span>  
<span style="margin-left: 1em">數萬以瘡夷未起之民加煩重不堪之役誠可憫惜乞</span>  
<span style="margin-left: 1em">暫令停免之　上曰諸府既有水災今次所派段疋羅</span>  
<span style="margin-left: 1em">紗姑令停織俟明年秋熟後陸續織造供用</span>  
<span style="margin-left: 1em">五年二月以水災免蘇松嘉湖等府衛糧草子粒有差</span>  
<span style="margin-left: 1em">其非全災者暫停徵納以三分爲率自弘治五年爲始</span>  
<span style="margin-left: 1em">每年帶徵一分</span>  
<span style="margin-left: 1em">五年七月以水災免蘇松常嘉湖五府正官朝覲<sub class="note-yuan">從巡撫都御史似鍾奏</sub></span>  
<span style="margin-left: 1em">八月以水災停南京兩浙蘇松等處之額外織造者并</span>  
<span style="margin-left: 1em">取回督造官員<sub class="note-yuan">從南京給事中楊廉等奏</sub></span>  
<span style="margin-left: 1em">十一月以水災免蘇松常鎮太平寧國應天七府所屬</span>  
<span style="margin-left: 1em">弘治四年夏秋稅糧有差</span>  
<span style="margin-left: 1em">八年五月以水災免應天及蘇松常鎮太寧池安八府</span>  
<span style="margin-left: 1em">弘治七年分糧草子粒有差</span>  
<span style="margin-left: 1em">十一月以蘇州府滸墅關今年秋冬二季并明年春夏</span>  
<span style="margin-left: 1em">二季解京課銀留賑蘇松常鎮四府飢民</span>  
<span style="margin-left: 1em">十五年議准蘇松災傷起運不前暫將一年在京各衛</span>  
<span style="margin-left: 1em">門官員月糧米每石折銀八錢該在南京本色禄俸每</span>  
<span style="margin-left: 1em">石照舊折銀七錢其南京各衙門官員俸糧每月米一</span>  
<span style="margin-left: 1em">石折銀八錢其餘并南京各衛倉糧俱每石折銀七錢</span>  
<span style="margin-left: 1em">漕運糧米折銀二十萬石每石兑運七錢改兑六錢各</span>  
<span style="margin-left: 1em">解交納</span>  
<span style="margin-left: 1em">正德元年十一月以鎮江蘇州常州松江等府災傷免</span>  
<span style="margin-left: 1em">其存留糧草子粒有差</span>  
<span style="margin-left: 1em">三年十二月總督蘇松等處糧儲都御史羅鑒奏蘇松</span>  
<span style="margin-left: 1em">杭州等府旱災該徵兑軍米并兩京官吏俸糧俱不能</span>  
<span style="margin-left: 1em">足數請盡折銀以省脚耗以備本處俸糧及賑濟之用</span>  
<span style="margin-left: 1em">下户部議覆宜于無災該徵兑軍米內量准折銀四十</span>  
<span style="margin-left: 1em">萬石石五錢兩京俸糧內准折糧十萬石石七錢省其</span>  
<span style="margin-left: 1em">脚耗以補有災不能起運之數數猶不足則於臨德等</span>  
<span style="margin-left: 1em">倉支運本處俸糧及賑濟所需聽從便宜處置從之</span>  
<span style="margin-left: 1em">五年十一月詔以蘇松常三府水災凡起運京庫及南</span>  
<span style="margin-left: 1em">京各倉稅糧絲絹綿布俱量改折色存留者本色折色</span>  
<span style="margin-left: 1em">中半徵收仍存省脚價以補應兑之數各衛所屯田子</span>  
<span style="margin-left: 1em">粒俱視災之輕重除免</span>  
<span style="margin-left: 1em">七年十二月以旱災免蘇松常鎮四府并鎮江等衛秋</span>  
<span style="margin-left: 1em">糧有差</span>  
<span style="margin-left: 1em">八月以水災免蘇松常鎮等府夏稅有差</span>  
<span style="margin-left: 1em">嘉靖四年正月以巡按朱實昌言詔蠲免蘇松常帶徵</span>  
<span style="margin-left: 1em">錢穀三十八萬有奇</span>  
<span style="margin-left: 1em">七年　上憫蘇松被災蠲免全稅發太倉庫銀一百萬</span>  
<span style="margin-left: 1em">兩抵補起存錢糧餘行賑濟</span>  
<span style="margin-left: 1em">隆慶二年十一月以蘇松常三府水災詔改折額解禄</span>  
<span style="margin-left: 1em">米倉糧一年</span>  
<span style="margin-left: 1em">萬曆七年蘇松水災巡江御史林應訓先後疏請蠲賑</span>  
<span style="margin-left: 1em">將北京馬草銀六千六百兩宗人府米折銀一萬七千</span>  
<span style="margin-left: 1em">八百三十二兩二錢零俱經全免鹽鈔銀七百七十四</span>  
<span style="margin-left: 1em">兩零北京公侯俸禄米麥銀七千二百九十五兩七錢</span>  
<span style="margin-left: 1em">八分零俱半免　馬價銀七千八百八十四兩一錢一</span>  
<span style="margin-left: 1em">分免四徵六餘帶徵　折布銀一萬二千六百六十七</span>  
<span style="margin-left: 1em">兩八錢俱全免</span>  
<span style="margin-left: 1em">十五年南京御史陳邦科奏爲救荒裕民乞將蘇松等</span>

<span style="margin-left: 2em">噪以借米糴米爲名者此皆亂法之民若有此等倡</span>

<span style="margin-left: 2em">攝亂民之膽者也蓋救災恤患之中專寓防微杜漸</span>  
<span style="margin-left: 2em">之意飢民必救亂民必斬舍此八字別無荒政矣</span>  
<span style="margin-left: 2em">禁張皇　夫上人要有救荒之心而不當有救荒之</span>  
<span style="margin-left: 2em">狀如銀賑米賑粥賑此爲無田者而設也而目前庫</span>  
<span style="margin-left: 2em">中之銀幾何倉中之穀米幾何此不可遽言賑也如</span>  
<span style="margin-left: 2em">蠲免如改折如停徵帶徵此爲有田者而設也而目</span>  
<span style="margin-left: 2em">前之荒疏未上朝廷之恩例未下此不可以遽言蠲</span>  
<span style="margin-left: 2em">也大抵飢民如小兒不忍用威又不敢遽用恩挨得</span>  
<span style="margin-left: 2em">一刻不啼哭則一刻之餅餌且止挨得一日不啼哭</span>  
<span style="margin-left: 2em">則一日之餅餌且止留前貯後相時而行屈指七月</span>  
<span style="margin-left: 2em">至十月終有一百二十日之期幸而高鄉成熟則新</span>  
<span style="margin-left: 2em">米可接濟矣又屈指十一月至明春四月終有一百</span>  
<span style="margin-left: 2em">八十日之期幸而春熟有望則豆麥又可接濟矣獨</span>  
<span style="margin-left: 2em">二熟未至接濟何人萬姓嗷嗷命在呼吸前則以設</span>  
<span style="margin-left: 2em">法預備爲主後則以分頭急救爲主中間則在閒時</span>  
<span style="margin-left: 2em">忙做忙時閒做勿促之告急勿挑之使動如遏糴抑</span>  
<span style="margin-left: 2em">價之類是也</span>  
<span style="margin-left: 2em">請改漕折　改折一事近雖奉有明旨但時事多艱</span>  
<span style="margin-left: 2em">拘孿當破議賑則倉庫空虛議蠲則金花難免獨有</span>  
<span style="margin-left: 2em">漕糧一項漕糧每石輕齎蓆板過江水脚折耗等項</span>  
<span style="margin-left: 2em">計費銀二兩若得幾分請折每石止徵銀五錢則餘</span>  
<span style="margin-left: 2em">米存留地方有田者明沾實惠無田者暗受恩波計</span>  
<span style="margin-left: 2em">無便於此矣查得改折事例被災十分九分以上者</span>  
<span style="margin-left: 2em">改折七分又查得被災八分以上者不分正改兑每</span>  
<span style="margin-left: 2em">石折銀五錢此定制也今三縣災傷正當十分九分</span>  
<span style="margin-left: 2em">之數則改折漕糧正當每石折銀五錢之時前有萬</span>  
<span style="margin-left: 2em">曆十六年及三十七年水災奏准文卷歷歷可查申</span>  
<span style="margin-left: 2em">請道院援例乞恩亦寬中之寬恩外之恩而未知可</span>  
<span style="margin-left: 2em">得否也若復請今歲停徵太過則來歲帶徵益多姑</span>  
<span style="margin-left: 2em">息於目前而箠楚於日後不惟難爲百姓抑且難爲</span>  
<span style="margin-left: 2em">縣官且看部覆何如耳</span>  
<span style="margin-left: 2em">禁遏糴　以官救民不若以民濟民以民濟民不若</span>  
<span style="margin-left: 2em">以商濟民我既遏糴鄰亦效尤寸寸節節皆是死路</span>  
<span style="margin-left: 2em">當聽其自相灌輸較是兩便蓋本方之米有限日用</span>  
<span style="margin-left: 2em">則米日消四方之米無窮日來則價日減此不待智</span>  
<span style="margin-left: 2em">者而後知也若云米在外者則欲招來米出境者則</span>  
<span style="margin-left: 2em">欲嚴禁非惟用情之不恕抑亦立法之難行此猶士</span>  
<span style="margin-left: 2em">大夫半明半暗之說也</span>  
<span style="margin-left: 2em">糴米　救荒之法無如設處糧食爲第一義揀選大</span>  
<span style="margin-left: 2em">户領銀轉販給付印批勒限回縣似矣目今庫藏空</span>  
<span style="margin-left: 2em">虛官銀何處撮借愚謂使大户糴米不如使大户積</span>  
<span style="margin-left: 2em">米如不願遠糴而願積米者即將本家之米自貯本</span>  
<span style="margin-left: 2em">家之倉積米若干時價若干但取結狀印信登册訖</span>  
<span style="margin-left: 2em">後日價踴原照前價平糶幸而價不甚昂米還大户</span>  
<span style="margin-left: 2em">而官無與焉在官府許境內之米留之境內不必處</span>  
<span style="margin-left: 2em">糴米之銀在大户以留之在家者聽之在官不必增</span>  
<span style="margin-left: 2em">遠販之費此不遏之遏不糴之糴也揀選積米大家</span>  
<span style="margin-left: 2em">只將屯户查明量田之多寡酌米之重輕如千畝五</span>  
<span style="margin-left: 2em">百畝之家或有餘蓄下此則不能矣若開報殷實徒</span>  
<span style="margin-left: 2em">生詐端請託營求易生煩擾其不便者一領銀糴米</span>  
<span style="margin-left: 2em">銀一到手豈無花費之子弟侵尅之家人其不便者</span>  
<span style="margin-left: 2em">二我遏我糴彼遏彼糴口語鬪争關津阻隔其不便</span>  
<span style="margin-left: 2em">者三遠涉江湖擔延歲月其不便者四遠方價高回</span>  
<span style="margin-left: 2em">鄉價減查驗推委多所支離其不便者五華亭八十</span>  
<span style="margin-left: 2em">餘區試選區中大户召而問之願積米乎願糴米乎</span>  
<span style="margin-left: 2em">其情實可以立見矣</span>  
<span style="margin-left: 2em">禁抑價　抑價之說行於官糶則可行於民糶則不</span>  
<span style="margin-left: 2em">可蓋官府設法銀兩遣官遠方販得糧食畧有頭緒</span>  
<span style="margin-left: 2em">矣然後發與良善大户平價糶與飢民但姦徒或以</span>  
<span style="margin-left: 2em">低銀至者以低錢至者以短價至者受之則大户虧</span>  
<span style="margin-left: 2em">本拒之則喧嚷相加甚則詐告小升小斗詐告插穀</span>  
<span style="margin-left: 2em">插粞而添出詞訟無已時矣况插勒減價則積米之</span>  
<span style="margin-left: 2em">家閉廪不出販米之商聞風不來本欲抑價而價愈</span>  
<span style="margin-left: 2em">增此立斃之道也</span>  
<span style="margin-left: 2em">平糴　官糶官糴其名甚美而往年奉行臺諭幾至</span>  
<span style="margin-left: 2em">大亂蓋强梁者得之軟弱者不得也附近者得之遠</span>  
<span style="margin-left: 2em">僻者不得也衙門之狡猾臧獲之親厚者得之而鰥</span>  
<span style="margin-left: 2em">寡孤獨疾病無告者不得也詭名詭姓假爲藍縷之</span>  
<span style="margin-left: 2em">服者得之而真正飢貧者不得也或擁軋或叫號或</span>  
<span style="margin-left: 2em">困踣或鬪争或聲言以減竊告以拌和告以小斗斛</span>  
<span style="margin-left: 2em">告本家不勝其煩但求糊塗苟且了事而止有平糶</span>  
<span style="margin-left: 2em">之名無平糶之實若不體帖設行則區處錢糧之艱</span>  
<span style="margin-left: 2em">難遠販糧食之辛苦俱付之兒戲一擲耳可惜可惜</span>  
<span style="margin-left: 2em">慎之慎之直待舖行十分踴貴之候始付好義大户</span>  
<span style="margin-left: 2em">平糶飢民但許升計不許斗計自城及鄉然亦可暫</span>  
<span style="margin-left: 2em">而不可久也</span>  
<span style="margin-left: 2em">散賑　夫用衆宜在狹處不宜在廣闊處如在廣闊</span>  
<span style="margin-left: 2em">處唱名叫一人而千萬人俱擁案前本人不到而他</span>  
<span style="margin-left: 2em">人冒應冒領者有之應去復來領去復應其誰能一</span>  
<span style="margin-left: 2em">一而稽察哉大抵散賑不散米而散票此常法也散</span>  
<span style="margin-left: 2em">票之法莫如晴明上城安排布置每啚分作十甲第</span>  
<span style="margin-left: 2em">一甲以至十甲每甲將六牌開寫飢民姓名挨甲編</span>  
<span style="margin-left: 2em">定有一城垜靠立飢民一名縣公乘轎門子執票有</span>  
<span style="margin-left: 2em">一名即將一票付之得票者從轎後陸續過去未領</span>  
<span style="margin-left: 2em">票者從轎前挨次前來散過一啚又是一啚散過十</span>  
<span style="margin-left: 2em">甲又是十甲飢民執票就倉倉吏認票發米先後亦</span>  
<span style="margin-left: 2em">以此爲次第兵法云用衆如用寡分數明也此即散</span>  
<span style="margin-left: 2em">賑之法也</span>  
<span style="margin-left: 2em">田主賑佃户　查得華亭田一百九十五萬畝若田</span>  
<span style="margin-left: 2em">主各自接救佃户種田一畝者付米二升種田十畝</span>  
<span style="margin-left: 2em">者付米二斗共計米三萬九千即省出官米三萬九</span>  
<span style="margin-left: 2em">千石矣即使官販有如此之直捷乎即使官糶有如</span>  
<span style="margin-left: 2em">此之均匀乎人自爲給無强梁擠軋之弊家自爲賑</span>  
<span style="margin-left: 2em">無遊手冒名之弊平時借作工本米凶年借作性命</span>  
<span style="margin-left: 2em">米工本米至冬月補償性命米至豐月補償各立券</span>  
<span style="margin-left: 2em">爲準不還者告官究追此官府不賑之中而民間暗</span>  
<span style="margin-left: 2em">寓賑濟之法比之報名分賑執票平糴者有淹速有</span>  
<span style="margin-left: 2em">均否有真僞有會集之擾有辨察之煩其孰便孰不</span>  
<span style="margin-left: 2em">便也乎且賑飢之事官府既不能遍及鄉村又不能</span>  
<span style="margin-left: 2em">確定災傷之重輕與飢户之真僞惟田主與租户痛</span>  
<span style="margin-left: 2em">癢相關情形又實凡田之果荒與否家之果貧與否</span>  
<span style="margin-left: 2em">不待踏勘而彼此灼然莫可掩飾者今能照依前議</span>  
<span style="margin-left: 2em">既報其平日胼手胝足之勞又救其目前逃亡餓殍</span>  
<span style="margin-left: 2em">之苦此安插佃户第一義而當事者又且賑之以濟</span>  
<span style="margin-left: 2em">其窮庶不立槁矣况士農工商惟農最苦比之游手</span>  
<span style="margin-left: 2em">閑民及素不識姓名者休戚萬萬也田主置之度外</span>  
<span style="margin-left: 2em">彼且相率而去其故居抛棄屋廬誰人看守明年菜</span>  
<span style="margin-left: 2em">麥誰人下種田主勞費豈不多於今日哉是說也無</span>  
<span style="margin-left: 2em">田者田少者皆欣然以爲可行而轉展阻撓倡言不</span>  
<span style="margin-left: 2em">便者必出於多田富户之僕輩獨不思田多則易於</span>  
<span style="margin-left: 2em">轉移人飢又易於爲德決不分外多求亦決不因求</span>  
<span style="margin-left: 2em">生事仁人首倡轉相勸諭繇城而鎮繇鎮而鄉繇吳</span>  
<span style="margin-left: 2em">而越繇吳越而推之他方被荒之處豈非根本簡便</span>  
<span style="margin-left: 2em">之良法哉</span>  
<span style="margin-left: 1em">萬曆三十七年天馬山煮粥事宜</span>  
<span style="margin-left: 2em">城郭不如鄉村　設粥於城郭則游手之人多設粥</span>  
<span style="margin-left: 2em">於鄉村則力耕之農衆聚則疫痢易染分則道里適</span>  
<span style="margin-left: 2em">中設粥城郭十之一鄉村十之九則較得其平矣</span>  
<span style="margin-left: 2em">委官不如委好義　大户一心以奉委官又一心以</span>  
<span style="margin-left: 2em">救飢民精神既分事事苟且惟敦請賢士大夫爲地</span>  
<span style="margin-left: 2em">方素所信服者監督煮粥朝夕無供應之煩左右無</span>  
<span style="margin-left: 2em">需索之苦柴米不能凑手可以猝請猝應於當事者</span>  
<span style="margin-left: 2em">又無扞格不通之虞</span>  
<span style="margin-left: 2em">搭廠不如寺院　搭廠費竹木費柴薪費工食既防</span>  
<span style="margin-left: 2em">火燭又防風雨又少遮攔惟在地方大寺院一便水</span>  
<span style="margin-left: 2em">漿一便造竈一便寓房一便貯柴積米一便容民畜</span>  
<span style="margin-left: 2em">衆</span>  
<span style="margin-left: 2em">早煮不如遲煮　煮粥最宜慎始慮終須計量倉穀</span>  
<span style="margin-left: 2em">多寡可食若干人可支若干月然後起手若驟然輕</span>  
<span style="margin-left: 2em">舉一時穀盡又驟而已之令老弱者轉死强梁者且</span>  
<span style="margin-left: 2em">生他心不可不慎</span>  
<span style="margin-left: 2em">土竈不如磚竈　土竈齷齪易敗磚竈潔浄可久其</span>  
<span style="margin-left: 2em">大鍋鍋蓋水缸等項即從地方鎮上店家借之編號</span>  
<span style="margin-left: 2em">登記訖若火鈐檐桶淘蘿簸扁諸小物類大户領價</span>  
<span style="margin-left: 2em">置之</span>  
<span style="margin-left: 2em">執事不如選用飢民　選用飢民須衣服洗浄精力</span>  
<span style="margin-left: 2em">健旺者每人給米二升計令給事煮粥如有不好潔</span>  
<span style="margin-left: 2em">不聽命因而偷盗米糧物件者逐出更换</span>  
<span style="margin-left: 2em">粞粥不如米粥　往時粞粥多有半生半熟者間有</span>  
<span style="margin-left: 2em">拌和石膏者往往食後致病而死若米粥則無此弊</span>  
<span style="margin-left: 2em">故煮粥決以白米爲主</span>  
<span style="margin-left: 2em">草柴不如木柴　官既發米隨將買柴銀兩同時給</span>  
<span style="margin-left: 2em">發每日用柴百束先買二三千束備用坐柴可以代</span>  
<span style="margin-left: 2em">凳餘炭可以煮茶日逐劈柴最爲煩苦飢民待粥空</span>  
<span style="margin-left: 2em">閒者即以劈柴委之劈完加粥一碗</span>  
<span style="margin-left: 2em">喫粥不如帶粥　凡煮粥上午一次下午一次奔走</span>  
<span style="margin-left: 2em">道途倘遇風雨尤覺艱難若願喫粥者許令自帶碗</span>  
<span style="margin-left: 2em">箸以便就食若願帶粥者許令自家帶缽并給二次</span>  
<span style="margin-left: 2em">以便攜歸昔嘗行此法願喫者少願帶者多蓋喫則</span>  
<span style="margin-left: 2em">止於一人帶則歸分老幼不妨生理不失碗筯不成</span>  
<span style="margin-left: 2em">群混擾不竟日奔馳飢民既得安閒而執事者亦少</span>  
<span style="margin-left: 2em">得半日之休息矣</span>  
<span style="margin-left: 2em">給粥老人先於童壯　前鍋粥熟即貯缸中遇老即</span>  
<span style="margin-left: 2em">發蓋老者尪嬴不能久待童壯者尚可待也</span>  
<span style="margin-left: 2em">給粥婦人先於男子　婦人領粥出自萬不得已來</span>  
<span style="margin-left: 2em">即發之蓋婦人廉耻最重不能久待男子猶可待也</span>  
<span style="margin-left: 2em">童子壯男各分一處　凡童子最難馴伏須擇人管</span>  
<span style="margin-left: 2em">攝使之自屯一隊或喫或帶擊鑼引旗五童一隊挨</span>  
<span style="margin-left: 2em">次散之凡壯男須俟煮粥有餘末後給散擊鑼引旗</span>  
<span style="margin-left: 2em">亦如之大約以己午爲期馴良生理者不必先來久</span>  
<span style="margin-left: 2em">候强暴頑梗者不致屯聚後留亦分別調馭之一法</span>  
<span style="margin-left: 2em">也</span>  
<span style="margin-left: 2em">丐流毋得混擾飢民　丐流溷入飢民非特不潔亦</span>  
<span style="margin-left: 2em">且不甘另遣乞丐頭領置之粥場遠處別設粥賑之</span>  
<span style="margin-left: 2em">飢民日登記籍　錢糧出自官府苦心區處得來一</span>  
<span style="margin-left: 2em">粒一毫俱要着落抛撒者上干天刑侵漁者難逃憲</span>  
<span style="margin-left: 2em">網凡每日男女領粥若干每日煮過米若干執事工</span>  
<span style="margin-left: 2em">食米若干一一登記簿籍以呈查考</span>
