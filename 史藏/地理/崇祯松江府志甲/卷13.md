## 崇祯松江府志卷之十三　荒政

<span style="margin-left: 3em">荒政</span>  
<span style="margin-left: 1em">古云救荒无奇策此言似是而实非也长吏尽心设处</span>  
<span style="margin-left: 1em">而士大夫以实心策应之何事不辨若议论颜多文移</span>  
<span style="margin-left: 1em">展转其不索于枯鱼之肆者几希此口上救荒纸上救</span>  
<span style="margin-left: 1em">荒耳活数百万生灵胜二十四考中书令如富郑公之</span>  
<span style="margin-left: 1em">于青州何尝不奇乎又闻阳明先生云饥民必救乱民</span>  
<span style="margin-left: 1em">必斩荒政之奇更尽括于此矣救荒如救焚何可不载</span>  
<span style="margin-left: 1em">故特补前志之阙</span>  
<span style="margin-left: 1em">勅谕</span>  
<span style="margin-left: 1em">洪武元年八月诏今岁水旱去处所在官司不拘时限</span>  
<span style="margin-left: 1em">从实踏勘实灾租税即与蠲免</span>  
<span style="margin-left: 1em">二年十二月赈应天苏松杭湖诸郡贫民人给米一石</span>  
<span style="margin-left: 1em">棉布一疋</span>  
<span style="margin-left: 1em">十一年五月　上以苏松嘉湖之民尝被水灾已尝遣</span>  
<span style="margin-left: 1em">使赈济至是复虑其困乏再遣使存问仍济饥民六万</span>  
<span style="margin-left: 1em">二千八百四十四户命户赐米一石免其逋租六十五</span>  
<span style="margin-left: 1em">万二千八百二十八石</span>  
<span style="margin-left: 1em">七月苏州松江扬州台州四府海溢漂民居人多溺死</span>  
<span style="margin-left: 1em">者诏遣官存恤之</span>  
<span style="margin-left: 1em">十一月　上以苏松嘉湖杭五府屡被水灾艰于衣食</span>  
<span style="margin-left: 1em">命悉罢五府河泊所免其税课以其利与民今岁鱼课</span>  
<span style="margin-left: 1em">未入征者亦免之</span>  
<span style="margin-left: 1em">永乐二年八月户部臣言松江府华上二县今岁水灾</span>  
<span style="margin-left: 1em">低田税粮宜令以帛代输从之</span>  
<span style="margin-left: 1em">十一月以苏松嘉湖杭等府水灾蠲其今年粮六十万</span>  
<span style="margin-left: 1em">九千九百余石</span>  
<span style="margin-left: 1em">四年九月赈苏松嘉湖杭常六府流徙复业民户十二</span>  
<span style="margin-left: 1em">万二千九百有奇给粟十五万七千一百石有奇</span>  
<span style="margin-left: 1em">十二年十一月蠲苏松嘉湖杭五府水灾田租四十七</span>  
<span style="margin-left: 1em">万九千七百余石初有司请减半征之上谓户部尚书</span>  
<span style="margin-left: 1em">夏原吉等曰民田被水无收未有以赈之又可征税耶</span>  
<span style="margin-left: 1em">悉蠲之</span>  
<span style="margin-left: 1em">二十二年十月命户部苏松嘉等被水灾处今岁秋粮</span>  
<span style="margin-left: 1em">悉令折输布钞如永乐五年例每石输布一疋或钞六</span>  
<span style="margin-left: 1em">锭</span>  
<span style="margin-left: 1em">洪熙元年正月勑布政使周干等巡行应天八府察民</span>  
<span style="margin-left: 1em">利病谕曰朕祗奉鸿图君临兆庶惓惓夙夜康济为心</span>  
<span style="margin-left: 1em">而南方诸郡尤厪念虑诚以民众地远情难上通今特</span>  
<span style="margin-left: 1em">命尔等巡视应天镇江常州苏州松江湖州杭州嘉兴</span>  
<span style="margin-left: 1em">八府其军民安否何似何弊当去何利当建审求其故</span>  
<span style="margin-left: 1em">具以实闻尔等必公必勤毋徒苟应故事庶副朕忧悯</span>  
<span style="margin-left: 1em">元元之意钦哉</span>  
<span style="margin-left: 1em">宣德元年九月左通政岳福奏苏松嘉湖诸郡春夏久</span>  
<span style="margin-left: 1em">雨禾稼损伤　上命行在户部遣官覆视被灾者蠲其</span>  
<span style="margin-left: 1em">税</span>  
<span style="margin-left: 1em">三年八月巡按直隶监察御史林文秩言苏州府吴江</span>  
<span style="margin-left: 1em">常熟等县松江府华亭县久雨山水冲决圩岸渰没田</span>  
<span style="margin-left: 1em">苗命行在户部验数蠲租</span>  
<span style="margin-left: 1em">十月巡抚苏松等处大理寺卿胡槩奏各部累差郎中</span>  
<span style="margin-left: 1em">主事等官催督苏松及浙江诸郡造纸买铜铁等物今</span>  
<span style="margin-left: 1em">年苏松及绍兴等府水涝民饥乞停买诸物所差官员</span>  
<span style="margin-left: 1em">悉取回京　上命六部除军需所用外余悉停止所差</span>  
<span style="margin-left: 1em">官员各令还京</span>  
<span style="margin-left: 1em">七年九月巡按苏松监察御史王来言今年四月至六</span>  
<span style="margin-left: 1em">月苦雨海潮泛溢漫没堤圩所属长洲吴江昆山常熟</span>  
<span style="margin-left: 1em">华亭上海宜兴金坛八县低田皆没苗稼无收　上命</span>  
<span style="margin-left: 1em">行在户部遣人覆视蠲其租税</span>  
<span style="margin-left: 1em">九年八月勑谕应天苏松等府州县今水旱蝗蝻灾伤</span>  
<span style="margin-left: 1em">之处民人缺食好生艰辛但是工部派办物料即皆停</span>  
<span style="margin-left: 1em">止待丰熟之时办纳其不系灾伤之处所派办物料亦</span>  
<span style="margin-left: 1em">皆陆续办纳不许逼迫差去催办官员人等除修造海</span>  
<span style="margin-left: 1em">船物料外其余悉令回　京不许迁延在外扰民违者</span>  
<span style="margin-left: 1em">论罪不恕尔等其体朕恤民之心钦哉故谕</span>  
<span style="margin-left: 1em">十月勑谕巡抚侍郎周忱比闻直隶亢旱兵民饥窘良</span>  
<span style="margin-left: 1em">用恻然今将宽恤事件特勑颁示尔等其钦承朕命毋</span>  
<span style="margin-left: 1em">怠故谕被灾之处人民乏食尔等即委官前去于所在</span>  
<span style="margin-left: 1em">官仓量给米粮赈济毋得坐视民患</span>  
<span style="margin-left: 1em">正统五年五月以水灾命直隶松江府华亭上海二县</span>  
<span style="margin-left: 1em">今年折粮大三梭布五万九千七百三十二疋免征第</span>  
<span style="margin-left: 1em">征中等三梭布二万疋每疋折粮二石其余折征阔白</span>  
<span style="margin-left: 1em">绵布</span>  
<span style="margin-left: 1em">七月勑行在工部右侍郎周忱得奏苏松等府潦水为</span>  
<span style="margin-left: 1em">患农不及耕心为恻焉今遣员外郎王瑛往视就赍勑</span>  
<span style="margin-left: 1em">谕尔即躬自踏勘凡各部所渰没不得耕种之处具实</span>  
<span style="margin-left: 1em">奏来处置其被水之民有艰难乏食者悉于官仓储粮</span>  
<span style="margin-left: 1em">给济仍戒饬郡邑官善加存恤毋令失所</span>  
<span style="margin-left: 1em">十年八月巡抚直隶工部左侍郎周忱奏南直隶并浙</span>  
<span style="margin-left: 1em">江苏松嘉湖等十四府州正统九年水灾无征粮米共</span>  
<span style="margin-left: 1em">四十九万三千五百六十三石有奇　上命户部验寔</span>  
<span style="margin-left: 1em">蠲之</span>  
<span style="margin-left: 1em">十二年四月免直隶常州苏州松江镇江四府苏州镇</span>  
<span style="margin-left: 1em">海二卫被灾秋粮子粒八十八万四千七百七十余石</span>  
<span style="margin-left: 1em">草二十一万六百三十余包</span>  
<span style="margin-left: 1em">景泰五年九月户部尚书张凤等奏浙江嘉湖直隶苏</span>  
<span style="margin-left: 1em">松常扬等府被灾等处今年兑军粮一百三十四万余</span>  
<span style="margin-left: 1em">石民运粮八十三万二千余石宜停免令军就淮安常</span>  
<span style="margin-left: 1em">盈大军等仓支运五十万石邳州仓支运四万石每石</span>  
<span style="margin-left: 1em">加耗一斗五升临清仓支运十万石每石加耗六升德</span>  
<span style="margin-left: 1em">州仓支米二十四万石每石加耗五升以补盘剥之费</span>  
<span style="margin-left: 1em">俱赴通州仓交纳其民运粮数并各项起运存留马草</span>  
<span style="margin-left: 1em">折银等项候差官踏勘灾伤至日奏请定夺</span>  
<span style="margin-left: 1em">成化二年闰三月发松江府粮十万石赈济淮徐等处</span>  
<span style="margin-left: 1em">饥民<sub class="note-yuan">从巡抚都御史林聪请</sub></span>  
<span style="margin-left: 1em">十五年七月南畿巡抚王恕极论东南困苦乞培养元</span>  
<span style="margin-left: 1em">气竝以灾异上闻臣自去年奉命巡抚之后节据抚属</span>  
<span style="margin-left: 1em">申奏各部勘合派买各项物件未免助办于民里甲多</span>  
<span style="margin-left: 1em">致逃移臣惟凡此之类朝廷之上固有不可缺者亦有</span>  
<span style="margin-left: 1em">可减省者亦有可缺者如粮饷军需此不可缺者也花</span>  
<span style="margin-left: 1em">样段疋可减省者也珍奇玩好可缺者也今当军民灾</span>  
<span style="margin-left: 1em">荒凋弊之后凡百冗费宜樽节一应不急之务俱宜停</span>  
<span style="margin-left: 1em">止俾军民息肩实为社稷之福又两京一应收受钱粮</span>  
<span style="margin-left: 1em">内外官员请勅戒谕各公乃心悯念民艰毋刁蹬留难</span>  
<span style="margin-left: 1em">毋巧取财物毋多收斛面爱惜民财培养元气如或不</span>  
<span style="margin-left: 1em">悛令科道官指实参奏拿问则东南困苦其少甦矣</span>  
<span style="margin-left: 1em">上命查理禁约<sub class="note-yuan">大政记</sub></span>  
<span style="margin-left: 1em">十七年七月以水旱免松江府秋粮米八万五千三百</span>  
<span style="margin-left: 1em">余石草一万三千余包</span>  
<span style="margin-left: 1em">弘治四年八月工部尚书贾俊言苏松浙江近被水患</span>  
<span style="margin-left: 1em">民不聊生而顷者织造段疋之令至于再三其数不下</span>  
<span style="margin-left: 1em">数万以疮夷未起之民加烦重不堪之役诚可悯惜乞</span>  
<span style="margin-left: 1em">暂令停免之　上曰诸府既有水灾今次所派段疋罗</span>  
<span style="margin-left: 1em">纱姑令停织俟明年秋熟后陆续织造供用</span>  
<span style="margin-left: 1em">五年二月以水灾免苏松嘉湖等府卫粮草子粒有差</span>  
<span style="margin-left: 1em">其非全灾者暂停征纳以三分为率自弘治五年为始</span>  
<span style="margin-left: 1em">每年带征一分</span>  
<span style="margin-left: 1em">五年七月以水灾免苏松常嘉湖五府正官朝觐<sub class="note-yuan">从巡抚都御史似钟奏</sub></span>  
<span style="margin-left: 1em">八月以水灾停南京两浙苏松等处之额外织造者并</span>  
<span style="margin-left: 1em">取回督造官员<sub class="note-yuan">从南京给事中杨廉等奏</sub></span>  
<span style="margin-left: 1em">十一月以水灾免苏松常镇太平宁国应天七府所属</span>  
<span style="margin-left: 1em">弘治四年夏秋税粮有差</span>  
<span style="margin-left: 1em">八年五月以水灾免应天及苏松常镇太宁池安八府</span>  
<span style="margin-left: 1em">弘治七年分粮草子粒有差</span>  
<span style="margin-left: 1em">十一月以苏州府浒墅关今年秋冬二季并明年春夏</span>  
<span style="margin-left: 1em">二季解京课银留赈苏松常镇四府饥民</span>  
<span style="margin-left: 1em">十五年议准苏松灾伤起运不前暂将一年在京各卫</span>  
<span style="margin-left: 1em">门官员月粮米每石折银八钱该在南京本色禄俸每</span>  
<span style="margin-left: 1em">石照旧折银七钱其南京各衙门官员俸粮每月米一</span>  
<span style="margin-left: 1em">石折银八钱其余并南京各卫仓粮俱每石折银七钱</span>  
<span style="margin-left: 1em">漕运粮米折银二十万石每石兑运七钱改兑六钱各</span>  
<span style="margin-left: 1em">解交纳</span>  
<span style="margin-left: 1em">正德元年十一月以镇江苏州常州松江等府灾伤免</span>  
<span style="margin-left: 1em">其存留粮草子粒有差</span>  
<span style="margin-left: 1em">三年十二月总督苏松等处粮储都御史罗鉴奏苏松</span>  
<span style="margin-left: 1em">杭州等府旱灾该征兑军米并两京官吏俸粮俱不能</span>  
<span style="margin-left: 1em">足数请尽折银以省脚耗以备本处俸粮及赈济之用</span>  
<span style="margin-left: 1em">下户部议覆宜于无灾该征兑军米内量准折银四十</span>  
<span style="margin-left: 1em">万石石五钱两京俸粮内准折粮十万石石七钱省其</span>  
<span style="margin-left: 1em">脚耗以补有灾不能起运之数数犹不足则于临德等</span>  
<span style="margin-left: 1em">仓支运本处俸粮及赈济所需听从便宜处置从之</span>  
<span style="margin-left: 1em">五年十一月诏以苏松常三府水灾凡起运京库及南</span>  
<span style="margin-left: 1em">京各仓税粮丝绢绵布俱量改折色存留者本色折色</span>  
<span style="margin-left: 1em">中半征收仍存省脚价以补应兑之数各卫所屯田子</span>  
<span style="margin-left: 1em">粒俱视灾之轻重除免</span>  
<span style="margin-left: 1em">七年十二月以旱灾免苏松常镇四府并镇江等卫秋</span>  
<span style="margin-left: 1em">粮有差</span>  
<span style="margin-left: 1em">八月以水灾免苏松常镇等府夏税有差</span>  
<span style="margin-left: 1em">嘉靖四年正月以巡按朱实昌言诏蠲免苏松常带征</span>  
<span style="margin-left: 1em">钱谷三十八万有奇</span>  
<span style="margin-left: 1em">七年　上悯苏松被灾蠲免全税发太仓库银一百万</span>  
<span style="margin-left: 1em">两抵补起存钱粮余行赈济</span>  
<span style="margin-left: 1em">隆庆二年十一月以苏松常三府水灾诏改折额解禄</span>  
<span style="margin-left: 1em">米仓粮一年</span>  
<span style="margin-left: 1em">万历七年苏松水灾巡江御史林应训先后疏请蠲赈</span>  
<span style="margin-left: 1em">将北京马草银六千六百两宗人府米折银一万七千</span>  
<span style="margin-left: 1em">八百三十二两二钱零俱经全免盐钞银七百七十四</span>  
<span style="margin-left: 1em">两零北京公侯俸禄米麦银七千二百九十五两七钱</span>  
<span style="margin-left: 1em">八分零俱半免　马价银七千八百八十四两一钱一</span>  
<span style="margin-left: 1em">分免四征六余带征　折布银一万二千六百六十七</span>

<span style="margin-left: 2em">覆辙</span>  
<span style="margin-left: 2em">檄行六　漕折不蒙部覆业已无可奈何然就中转</span>

<span style="margin-left: 2em">输将以完国课其果系全荒人户勘实被灾十分者</span>

<span style="margin-left: 2em">檄行七　赈籴之举期于饥民得沾实惠随门审察</span>

<span style="margin-left: 2em">檄行八　查得往时遇灾曾有谕令坐罪系狱之徒</span>
