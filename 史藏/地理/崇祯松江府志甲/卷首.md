## 卷首

<span style="margin-left: 1em">崇祯松江府志甲　　方志类<sub class="note-yuan">江苏松</sub></span>  
<span style="margin-left: 8em">　　<sub class="note-yuan">江府部</sub></span>  
<span style="margin-left: 2em">参本</span>  
<span style="margin-left: 3em">明崇祯五年刻本</span>  
<span style="margin-left: 4em">日本公文书馆内阁文库藏足本<sub class="note-yuan">底本</sub></span>  
<span style="margin-left: 4em">上海图书馆藏残本<sub class="note-yuan">校对补阙</sub></span>  
<span style="margin-left: 2em">谷水道人曰</span>  
<span style="margin-left: 1em">是书乃崇祯四年据九十四卷本删削而成九十四卷</span>  
<span style="margin-left: 1em">本近岁始现残帙于上海图书馆考康熙松江府志卷</span>  
<span style="margin-left: 1em">四十三知五十八卷本当锓于崇祯五年而九十四卷</span>  
<span style="margin-left: 1em">本实刊于其前当在崇祯四年今定五十八卷本为甲</span>  
<span style="margin-left: 1em">本九十四卷本为乙本二者卷次虽殊内容悉同然以</span>  
<span style="margin-left: 1em">卷数相异故判作两书盖卷帙不同未可以版本之式</span>  
<span style="margin-left: 1em">作文字校勘故此番修订并录二本焉是本凡五十八</span>  
<span style="margin-left: 1em">卷题方岳贡修陈继儒纂昔者上海府县旧志丛书尝</span>  
<span style="margin-left: 1em">取日本藏本校订之迩年复于上海图书馆又见藏本</span>  
<span style="margin-left: 1em">前度修订时见讹字脱文倒乙之舛今次校雠余以二</span>  
<span style="margin-left: 1em">本互雠补苴若有阙佚则标注其处遇可疑字则撰校</span>  
<span style="margin-left: 1em">勘记附后</span>  
<span style="margin-left: 2em">旹</span>  
<span style="margin-left: 1em"><sub class="note-yuan">道历四千七百二十二年明崇祯三百九十八年</sub>岁次乙巳闰六月丙辰日</span>  
<span style="margin-left: 1em">谷水道人于涌月书斋沐手谨序</span>  
<span style="margin-left: 1em">明崇祯五年刻本　　　　　　　　　　　　明刻本</span>  
<span style="margin-left: 1em">提要</span>  
<span style="margin-left: 1em">明方岳贡修陈继儒等纂岳贡字禹修一字四长湖广</span>  
<span style="margin-left: 1em">谷城人天启二年进士崇祯间授松江知府累官至右</span>  
<span style="margin-left: 1em">都御史兼东阁大学士继儒字仲醇号眉公华亭人郡</span>  
<span style="margin-left: 1em">中诸生不仕工诗文书画著有太平清话眉公书画史</span>  
<span style="margin-left: 1em">等书事迹具明史隐逸传考松江府旧志修于明正德</span>  
<span style="margin-left: 1em">壬申至崇祯时已历百二十余年文献散佚难以稽考</span>  
<span style="margin-left: 1em">守臣方岳贡莅任慨然以续修为己任因延同郡诸生</span>  
<span style="margin-left: 1em">陈继儒主其笔而同里诸人佐之成书于崇祯三年是</span>  
<span style="margin-left: 1em">志卷首列序图经年表其下分沿革分野形胜区界乡</span>  
<span style="margin-left: 1em">村户口镇市弄巷坊表桥梁堰闸山水物产风俗赋额</span>  
<span style="margin-left: 1em">役法荒政盐政织造税课水利城池仓廪驿道坛庙祠</span>  
<span style="margin-left: 1em">祀官署学政兵防守令题名宦绩选举人物第宅园林</span>  
<span style="margin-left: 1em">古迹灾异冢墓兵燹寺院道观著述诗品画苑书评金</span>  
<span style="margin-left: 1em">石志余凡四十八门洋洋百十万言其书考核详核而</span>  
<span style="margin-left: 1em">尤以深切民瘼反映疾苦为归地方有志例当粉饰而</span>  
<span style="margin-left: 1em">岳贡于序中自称志以述吾过也引咎自责在官修志</span>  
<span style="margin-left: 1em">书中实属罕见卷首图经所辑舆图二十幅绘摹极精</span>  
<span style="margin-left: 1em">考订疆界殊为珍遗其田赋一门最切时弊详记晚明</span>  
<span style="margin-left: 1em">军兴不息国计殚虚之状而上官催科无度侵扰百姓</span>  
<span style="margin-left: 1em">民不堪命更指出吾松一郡之赋凡当大省六七古未</span>  
<span style="margin-left: 1em">有也力陈重赋之害言极痛切于役法则遍列徭役之</span>  
<span style="margin-left: 1em">繁致令民困俗偷盗贼四起于兵防则备载嘉靖间抗</span>  
<span style="margin-left: 1em">倭始末最足征信松江地控江海人文荟萃继儒长于</span>  
<span style="margin-left: 1em">风雅故特详于本郡著述书画另辟著述诗品画苑书</span>  
<span style="margin-left: 1em">评金石诸目备载先贤碑帖与历代艺文虽于体例稍</span>  
<span style="margin-left: 1em">嫌繁碎然足见云间文献之盛亦为考证江南学艺发</span>  
<span style="margin-left: 1em">展之资总之是编非徒备考沿革实具经济实用之远</span>  
<span style="margin-left: 1em">识于晚明江南社会之生计赋税及文化风尚记载最</span>  
<span style="margin-left: 1em">为真切足资考证</span>  
<span style="margin-left: 15em">谷水道人撰</span>  
<span style="margin-left: 1em">松江府志序</span>  
<span style="margin-left: 1em">东南雄郡四而松居一焉在春秋时犹居楚越之后逮</span>  
<span style="margin-left: 1em">赤乌而文物盛起遂甲江表孙吴以之卫建康而瞰许</span>  
<span style="margin-left: 1em">洛则星土亦有运会尔余叨钺吴中于所谓四雄郡者</span>  
<span style="margin-left: 1em">海陬江分军民利弊根菀所系每夙夜覃维以无负</span>  
简书然毘陵京口俗嚣寖悍苏虽外腴痱瘠已甚而松于  
<span style="margin-left: 1em">属郡中斗僻一隅桑麻鱼盐沃野绣塍得三泖潴其流</span>  
<span style="margin-left: 1em">盖既非子午道离去轺车厨传绝远属世承平岛夷解</span>  
<span style="margin-left: 1em">辫海上鲜兜零之警其人民礼让葆大髫耆嬉游犹有</span>  
<span style="margin-left: 1em">昔时庞秀之气葱然一淳国也郡故有志久漶漫不理</span>  
<span style="margin-left: 1em">其事迹概多兴革檄二千石谋之博士掌故给笔刀燎</span>  
<span style="margin-left: 1em">煴厘总条贯鳞次而损益之焕然昭整使𬨎轩使者得</span>  
<span style="margin-left: 1em">以攷究徽图知善败所繇文治之功于是为巨夫治贵</span>  
<span style="margin-left: 1em">循本善化者不易民而理君子之于国也非徒身立之</span>  
<span style="margin-left: 1em">轨而又将以为后法以今日之松计之其人材如机云</span>  
<span style="margin-left: 1em">逊抗功业荫暎南国者犹昔也其徭赋瑶琨筿簜贡金</span>  
<span style="margin-left: 1em">三品厥赋下上上错者犹昔也凤山龙江环白苎城而</span>  
<span style="margin-left: 1em">萦带陵薮精荧亦犹昔也而观风问俗者不无江河日</span>  
<span style="margin-left: 1em">下之感则夫起衰剔蠧嘘凋攰而予之膏沐匡衺泆而</span>  
<span style="margin-left: 1em">惠之斌雅长吏之拊循与师儒之倡率其必有方矣志</span>  
<span style="margin-left: 1em">者志也汉称职志当使采风谣者望如旄帜焉而是编</span>  
<span style="margin-left: 1em">考班就部抑何顜晳列眉也志甫葺会余膺</span>  
纶召祝軷首涂古者土训氏得以山川阨塞土俗媺郁诏  
<span style="margin-left: 1em">王况今</span>  
旃厦右文东南股肱郡尤宵旰厪虑有如  
清问三江水利何状底定而予得借手诵说则是书固保  
<span style="margin-left: 1em">乂之元龟鞠谋之丹青縢之籍府可训可传者哉</span>  
赐进士第通奉大夫  
钦差总理粮储提督军务兼巡抚应天等府地方都察院  
<span style="margin-left: 1em">右副都御史奉</span>  
特旨钦召升兵部右侍郎中原曹文衡书  
<span style="margin-left: 2em">志序</span>  
<span style="margin-left: 1em">志者识也修志者多侈言山川人物风土之藻丽以为</span>  
<span style="margin-left: 1em">岩郡观而予不然志以志吾过而已松江郡志前正德</span>  
<span style="margin-left: 1em">辛未修者文僖东江顾公后崇祯辛未修者为不佞贡</span>  
<span style="margin-left: 1em">屈指甲子盖两周也一百二十年掌故幸借手诸君子</span>  
<span style="margin-left: 1em">以文我陋编纂明备岁日奇符览志而喜可知也而予</span>  
<span style="margin-left: 1em">愧乃滋甚松赋烦役重征者编者不能去其太甚且或</span>  
<span style="margin-left: 1em">甚之中人之产一经践更身非我有遑问田庐予孳孳</span>  
<span style="margin-left: 1em">讲求而艰苦乖错犹昔则览志而愧粟米布缕鱼盐之</span>  
<span style="margin-left: 1em">利貌称东南陆海然糊口则盈终事则诎力作游惰参</span>  
<span style="margin-left: 1em">半而处焉稍获余羡侈汰耗其三健讼耗其三博徒恶</span>  
<span style="margin-left: 1em">少年耗其三外腴中枯甘心逋赋者累累矣予拨挽隄</span>  
<span style="margin-left: 1em">防而雕瘵顽靡犹昔则览志而愧小津大川田错如绣</span>  
<span style="margin-left: 1em">十日不雨高者龟坼一雨十日下者凫没予躬行相视</span>  
<span style="margin-left: 1em">且濬且筑而崩啮堙淤犹昔则览志而愧凌暴成习莫</span>  
<span style="margin-left: 1em">以为非寡势而拥百亩赀辄有造患投之者矣虑患则</span>  
<span style="margin-left: 1em">身请为奴主人朝炎夕冷即朝趋而夕叛之而转以凌</span>  
<span style="margin-left: 1em">暴他氏者比比也余禁戢法无贷而格面不格心犹昔</span>  
<span style="margin-left: 1em">则览志而愧积贮大命天灾时有待蠲待赈沟瘠已盈</span>  
<span style="margin-left: 1em">区区朽粟二千济事能几近虽薄有存积而遽语修备</span>  
<span style="margin-left: 1em">犹未也则览志而愧松故腹地第百里之外仅与倭争</span>  
<span style="margin-left: 1em">一帆耳而内盗不时零发皆彻桑畜艾事也三年来雉</span>  
<span style="margin-left: 1em">堞修补几何戎器除缮几何伍苻屯籍整搠几何则览</span>  
<span style="margin-left: 1em">志而愧之数者皆予三年内悚慑而未敢懈者犹举少</span>  
<span style="margin-left: 1em">而废多或似修而实坠其为吾精神所未及周者隳弛</span>  
<span style="margin-left: 1em">又何如而予愧固无终极矣犹是物力而辽饷津粮则</span>  
<span style="margin-left: 1em">前之辛未所未有犹是征输而索逋及于八年考成及</span>  
<span style="margin-left: 1em">于零杂则前之辛未所未有赋日重日急民益困民益</span>  
<span style="margin-left: 1em">困俗日偷以一百二十年积重之弊救之急若援溺而</span>  
<span style="margin-left: 1em">贡且屑屑焉簿书期会是问不遑攷掌故而师前贤旧</span>  
<span style="margin-left: 1em">有志犹弗志耳故余以修</span>  
<span style="margin-left: 1em">圣宫之余董修郡志志郡事也并以志我过属有采薪</span>  
<span style="margin-left: 1em">之忧旦晚解组后我而守者亟为我忏之</span>  
<span style="margin-left: 3em">襄西方岳贡书于退思轩时清和月之廿二日</span>  
<span style="margin-left: 1em">重修松江府志序</span>  
<span style="margin-left: 1em">其昌忆当蚤岁西蜀王公谋续郡志陈太史伯求曰郡</span>  
<span style="margin-left: 1em">当甲寅乙卯用兵之后劳臣战将烈妇贞女尚在故老</span>  
<span style="margin-left: 1em">之口失今不纪遗恨千秋嗟嗟此二千石守长教训正</span>  
<span style="margin-left: 1em">俗之事后时犹病况久废不讲乎又三十年而阁学陈</span>  
<span style="margin-left: 1em">文宪公疏修本朝正史有</span>  
<span style="margin-left: 1em">诏天下郡国皆修志乘亟进史局于是文渊阁书目骤</span>  
<span style="margin-left: 1em">增其半吾郡但以旧志应当是时主盟者有陆文定羽</span>  
<span style="margin-left: 1em">翼者有同馆三四夫子文献非不足也而东郡许公道</span>  
<span style="margin-left: 1em">谋竟成寡和修志之不可冀如此今郡大夫禹修方公</span>  
<span style="margin-left: 1em">政成廉善才擅史长礼乐当百年之兴是非扶三代之</span>  
<span style="margin-left: 1em">直慨然以续修为己任驱车山中授简陈子就方正学</span>  
<span style="margin-left: 1em">先生之祠而扬扢焉公曰当吾世而笔讨此昌黎之所</span>  
<span style="margin-left: 1em">惧也敢为贤者累抑孔子作春秋于隐桓则章于定哀</span>  
<span style="margin-left: 1em">则微请以人物志断自</span>  
<span style="margin-left: 1em">肃庙之丙寅庶几定论己成大书无忌岂惟先贤耆旧</span>  
<span style="margin-left: 1em">月旦森然而揭车湘芷区别于士林梼杌驺虞并登于</span>  
<span style="margin-left: 1em">民监公之义例如此若乃千腋萃而成裘众材备而作</span>  
<span style="margin-left: 1em">室则通郡之事目日繁旧志之网罗犹略士大夫欣逢</span>  
<span style="margin-left: 1em">旷典仰赞芳规莫不发其缥缃购彼散失说铃腹笥四</span>  
<span style="margin-left: 1em">面毕陈蠹简残编一朝大出岂有乘轩之采拜爵之酬</span>  
<span style="margin-left: 1em">哉则公之德意所风动远矣公尝盟于正学之祠以秽</span>  
<span style="margin-left: 1em">史谤书为诫惟兹兵农钱谷赋役民隐攸关神丛是托</span>  
<span style="margin-left: 1em">新法与掌故离合靡常诏令与教条东西易向舞文不</span>  
<span style="margin-left: 1em">已玄籍乘之仕者之耳目密移民生之脂膏暗吸此其</span>  
<span style="margin-left: 1em">凶于而国不在秽史谤书之下乃惣其条贯周爰咨询</span>  
<span style="margin-left: 1em">参考异同归之画一使周车炳于指路禹鼎凛乎伏奸</span>  
<span style="margin-left: 1em">此又公之深心造福吾松于无既者也是役也一事而</span>  
<span style="margin-left: 1em">三善备焉鉴裁精也荷担勇也翕受虚也杀青既竟而</span>  
<span style="margin-left: 1em">犹以施设未尽为愧孔子曰我欲载之空言不如见诸</span>  
<span style="margin-left: 1em">行事宛然春秋法也哉不佞昌多暇人也田光之魂已</span>  
<span style="margin-left: 1em">消赵孟之偷无改不能具研削以从独以及见河清为</span>  
<span style="margin-left: 1em">幸而附名末简云尔</span>  
<span style="margin-left: 1em">赐进士第资善大夫南京礼部尚书前礼部左侍郎兼</span>  
<span style="margin-left: 1em">翰林院侍读学士詹事府詹事掌南京翰林院事</span>  
<span style="margin-left: 1em">实录副总裁</span>  
<span style="margin-left: 1em">经筵讲官郡人董其昌撰并书</span>  
<span style="margin-left: 1em">修志始末记</span>  
<span style="margin-left: 1em">郡伯禹修方公祖下车以来一尘不染百废具兴岁穰</span>  
<span style="margin-left: 1em">人和惟焚香披阅图史而已展及顾文僖公旧志屈指</span>  
<span style="margin-left: 1em">百二十年人文渐觉凋落有感于大方伯七泽张公之</span>  
<span style="margin-left: 1em">勤请也申之台察谋之寮属诹吉告文于方正学先生</span>

<span style="margin-left: 2em">遗坠岂免愆忘况乎蘅簷孤节易从艸木俱凋丘园</span>  
<span style="margin-left: 2em">帛戋不与翘车同载甘渊之曜肯留爝于腐萤峚阳</span>  
<span style="margin-left: 2em">之膏不辱馨于浊涌倘犹旁萃逊括曲收谢劬乐蟪</span>  
<span style="margin-left: 2em">蛄之寸拘躭榆枋之尺适吾恐灵峰湛泖将掬茂艸</span>  
<span style="margin-left: 2em">于杞宋矣先大夫往好管氏之言以土定人及其宜</span>  
<span style="margin-left: 2em">植复如史迁所历风俗物产画地而称余小子束发</span>  
<span style="margin-left: 2em">从游簪毫待吮将采金而铸鼎爰猎腋以资裘是以</span>  
<span style="margin-left: 2em">排纂不厌其繁复芟夷不厌其苛严托慕既珍则古</span>  
<span style="margin-left: 2em">芳先撷贯穿认体则时诫备陈窃以游夏之赞词用</span>  
<span style="margin-left: 2em">窥马班之作用若曰征文攷献补百余年未了之公</span>  
<span style="margin-left: 2em">案于以作起旷绪咨诹信史机缘时节皆秉笔秉衡</span>  
<span style="margin-left: 2em">者际之余小子受成而已又何力之有焉华亭后学</span>
