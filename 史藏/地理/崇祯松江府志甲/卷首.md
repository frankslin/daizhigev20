## 卷首

<span style="margin-left: 1em">崇禎松江府志甲　　方誌類<sub class="note-yuan">江蘇松</sub></span>  
<span style="margin-left: 8em">　　<sub class="note-yuan">江府部</sub></span>  
<span style="margin-left: 2em">參本</span>  
<span style="margin-left: 3em">明崇禎五年刻本</span>  
<span style="margin-left: 4em">日本公文書館內閣文庫藏足本<sub class="note-yuan">底本</sub></span>  
<span style="margin-left: 4em">上海圖書館藏殘本<sub class="note-yuan">校對補闕</sub></span>  
<span style="margin-left: 2em">谷水道人曰</span>  
<span style="margin-left: 1em">是書乃崇禎四年據九十四卷本刪削而成九十四卷</span>  
<span style="margin-left: 1em">本近歲始現殘帙於上海圖書館考康熙松江府志卷</span>  
<span style="margin-left: 1em">四十三知五十八卷本當鋟於崇禎五年而九十四卷</span>  
<span style="margin-left: 1em">本實刊於其前當在崇禎四年今定五十八卷本爲甲</span>  
<span style="margin-left: 1em">本九十四卷本爲乙本二者卷次雖殊內容悉同然以</span>  
<span style="margin-left: 1em">卷數相異故判作兩書蓋卷帙不同未可以版本之式</span>  
<span style="margin-left: 1em">作文字校勘故此番修訂並錄二本焉是本凡五十八</span>  
<span style="margin-left: 1em">卷題方岳貢修陳繼儒纂昔者上海府縣舊志叢書嘗</span>  
<span style="margin-left: 1em">取日本藏本校訂之邇年復於上海圖書館又見藏本</span>  
<span style="margin-left: 1em">前度修訂時見訛字脫文倒乙之舛今次校讎余以二</span>  
<span style="margin-left: 1em">本互讎補苴若有闕佚則標註其處遇可疑字則撰校</span>  
<span style="margin-left: 1em">勘記附後</span>  
<span style="margin-left: 2em">旹</span>  
<span style="margin-left: 1em"><sub class="note-yuan">道曆四千七百二十二年明崇禎三百九十八年</sub>歲次乙巳閏六月丙辰日</span>  
<span style="margin-left: 1em">谷水道人於湧月書齋沐手謹序</span>  
<span style="margin-left: 1em">明崇禎五年刻本　　　　　　　　　　　　明刻本</span>  
<span style="margin-left: 1em">提要</span>  
<span style="margin-left: 1em">明方岳貢修陳繼儒等纂岳貢字禹修一字四長湖廣</span>  
<span style="margin-left: 1em">穀城人天啓二年進士崇禎間授松江知府累官至右</span>  
<span style="margin-left: 1em">都御史兼東閣大學士繼儒字仲醇號眉公華亭人郡</span>  
<span style="margin-left: 1em">中諸生不仕工詩文書畫著有太平清話眉公書畫史</span>  
<span style="margin-left: 1em">等書事蹟具明史隱逸傳考松江府舊志修於明正德</span>  
<span style="margin-left: 1em">壬申至崇禎時已歷百二十餘年文獻散佚難以稽考</span>  
<span style="margin-left: 1em">守臣方岳貢蒞任慨然以續修爲己任因延同郡諸生</span>  
<span style="margin-left: 1em">陳繼儒主其筆而同里諸人佐之成書於崇禎三年是</span>  
<span style="margin-left: 1em">志卷首列序圖經年表其下分沿革分野形勝區界鄉</span>  
<span style="margin-left: 1em">村戶口鎮市弄巷坊表橋梁堰閘山水物產風俗賦額</span>  
<span style="margin-left: 1em">役法荒政鹽政織造稅課水利城池倉廩驛道壇廟祠</span>  
<span style="margin-left: 1em">祀官署學政兵防守令題名宦績選舉人物第宅園林</span>  
<span style="margin-left: 1em">古蹟災異塚墓兵燹寺院道觀著述詩品畫苑書評金</span>  
<span style="margin-left: 1em">石志餘凡四十八門洋洋百十萬言其書考核詳覈而</span>  
<span style="margin-left: 1em">尤以深切民瘼反映疾苦爲歸地方有志例當粉飾而</span>  
<span style="margin-left: 1em">岳貢於序中自稱志以述吾過也引咎自責在官修志</span>  
<span style="margin-left: 1em">書中實屬罕見卷首圖經所輯輿圖二十幅繪摹極精</span>  
<span style="margin-left: 1em">考訂疆界殊爲珍遺其田賦一門最切時弊詳記晚明</span>  
<span style="margin-left: 1em">軍興不息國計殫虛之狀而上官催科無度侵擾百姓</span>  
<span style="margin-left: 1em">民不堪命更指出吾松一郡之賦凡當大省六七古未</span>  
<span style="margin-left: 1em">有也力陳重賦之害言極痛切於役法則遍列徭役之</span>  
<span style="margin-left: 1em">繁致令民困俗偷盜賊四起於兵防則備載嘉靖間抗</span>  
<span style="margin-left: 1em">倭始末最足徵信松江地控江海人文薈萃繼儒長於</span>  
<span style="margin-left: 1em">風雅故特詳於本郡著述書畫另闢著述詩品畫苑書</span>  
<span style="margin-left: 1em">評金石諸目備載先賢碑帖與歷代藝文雖於體例稍</span>  
<span style="margin-left: 1em">嫌繁碎然足見雲間文獻之盛亦爲考證江南學藝發</span>  
<span style="margin-left: 1em">展之資總之是編非徒備考沿革實具經濟實用之遠</span>  
<span style="margin-left: 1em">識於晚明江南社會之生計賦税及文化風尚記載最</span>  
<span style="margin-left: 1em">爲真切足資考證</span>  
<span style="margin-left: 15em">谷水道人撰</span>  
<span style="margin-left: 1em">松江府誌序</span>  
<span style="margin-left: 1em">東南雄郡四而松居一焉在春秋時猶居楚越之後逮</span>  
<span style="margin-left: 1em">赤烏而文物盛起遂甲江表孫吳以之衛建康而瞰許</span>  
<span style="margin-left: 1em">洛則星土亦有運會爾余叨鉞吳中於所謂四雄郡者</span>  
<span style="margin-left: 1em">海陬江分軍民利弊根菀所係每夙夜覃維以無負</span>  
簡書然毘陵京口俗囂寖悍蘇雖外腴痱瘠已甚而松於  
<span style="margin-left: 1em">屬郡中斗僻一隅桑麻魚鹽沃野繡塍得三泖瀦其流</span>  
<span style="margin-left: 1em">蓋既非子午道離去軺車厨傳絶遠屬世承平島夷解</span>  
<span style="margin-left: 1em">辮海上鮮兜零之警其人民禮讓葆大髫耆嬉遊猶有</span>  
<span style="margin-left: 1em">昔時龐秀之氣蔥然一淳國也郡故有誌久漶漫不理</span>  
<span style="margin-left: 1em">其事蹟概多興革檄二千石謀之博士掌故給筆刀燎</span>  
<span style="margin-left: 1em">煴釐總條貫鱗次而損益之焕然昭整使輶軒使者得</span>  
<span style="margin-left: 1em">以攷究徽圖知善敗所繇文治之功於是爲鉅夫治貴</span>  
<span style="margin-left: 1em">循本善化者不易民而理君子之於國也非徒身立之</span>  
<span style="margin-left: 1em">軌而又將以爲後法以今日之松計之其人材如機雲</span>  
<span style="margin-left: 1em">遜抗功業蔭暎南國者猶昔也其徭賦瑶琨篠簜貢金</span>  
<span style="margin-left: 1em">三品厥賦下上上錯者猶昔也鳳山龍江環白苧城而</span>  
<span style="margin-left: 1em">縈帶陵藪精熒亦猶昔也而觀風問俗者不無江河日</span>  
<span style="margin-left: 1em">下之感則夫起衰剔蠧嘘凋攰而予之膏沐匡衺泆而</span>  
<span style="margin-left: 1em">惠之斌雅長吏之拊循與師儒之倡率其必有方矣誌</span>  
<span style="margin-left: 1em">者志也漢稱職志當使採風謡者望如旄幟焉而是編</span>  
<span style="margin-left: 1em">考班就部抑何顜晳列眉也志甫葺會余膺</span>  
綸召祝軷首塗古者土訓氏得以山川阨塞土俗媺郁詔  
<span style="margin-left: 1em">王况今</span>  
旃厦右文東南股肱郡尤宵旰厪慮有如  
清問三江水利何狀底定而予得藉手誦說則是書固保  
<span style="margin-left: 1em">乂之元龜鞠謀之丹青縢之籍府可訓可傳者哉</span>  
賜進士第通奉大夫  
欽差總理糧儲提督軍務兼巡撫應天等府地方都察院  
<span style="margin-left: 1em">右副都御史奉</span>  
特旨欽召陞兵部右侍郎中原曹文衡書  
<span style="margin-left: 2em">志序</span>  
<span style="margin-left: 1em">志者識也修志者多侈言山川人物風土之藻麗以爲</span>  
<span style="margin-left: 1em">巖郡觀而予不然志以志吾過而已松江郡志前正德</span>  
<span style="margin-left: 1em">辛未修者文僖東江顧公後崇禎辛未修者爲不佞貢</span>  
<span style="margin-left: 1em">屈指甲子蓋兩週也一百二十年掌故幸借手諸君子</span>  
<span style="margin-left: 1em">以文我陋編纂明備歲日奇符覽志而喜可知也而予</span>  
<span style="margin-left: 1em">愧乃滋甚松賦煩役重徵者編者不能去其太甚且或</span>  
<span style="margin-left: 1em">甚之中人之産一經踐更身非我有遑問田廬予孳孳</span>  
<span style="margin-left: 1em">講求而艱苦乖錯猶昔則覽志而愧粟米布縷魚鹽之</span>  
<span style="margin-left: 1em">利貌稱東南陸海然糊口則盈終事則詘力作游惰參</span>  
<span style="margin-left: 1em">半而處焉稍獲餘羡侈汰耗其三健訟耗其三博徒惡</span>  
<span style="margin-left: 1em">少年耗其三外腴中枯甘心逋賦者累累矣予撥挽隄</span>  
<span style="margin-left: 1em">防而彫瘵頑靡猶昔則覽志而愧小津大川田錯如繡</span>  
<span style="margin-left: 1em">十日不雨高者龜坼一雨十日下者鳧没予躬行相視</span>  
<span style="margin-left: 1em">且濬且築而崩嚙堙淤猶昔則覽志而愧凌暴成習莫</span>  
<span style="margin-left: 1em">以爲非寡勢而擁百畝貲輒有造患投之者矣慮患則</span>  
<span style="margin-left: 1em">身請爲奴主人朝炎夕冷即朝趨而夕叛之而轉以凌</span>  
<span style="margin-left: 1em">暴他氏者比比也余禁戢法無貸而格面不格心猶昔</span>  
<span style="margin-left: 1em">則覽志而愧積貯大命天災時有待蠲待賑溝瘠已盈</span>  
<span style="margin-left: 1em">區區朽粟二千濟事能幾近雖薄有存積而遽語脩備</span>  
<span style="margin-left: 1em">猶未也則覽志而愧松故腹地第百里之外僅與倭争</span>  
<span style="margin-left: 1em">一帆耳而內盗不時零發皆徹桑畜艾事也三年來雉</span>  
<span style="margin-left: 1em">堞脩補幾何戎器除繕幾何伍苻屯籍整搠幾何則覽</span>  
<span style="margin-left: 1em">志而愧之數者皆予三年內悚懾而未敢懈者猶舉少</span>  
<span style="margin-left: 1em">而廢多或似脩而實墜其爲吾精神所未及周者隳弛</span>  
<span style="margin-left: 1em">又何如而予愧固無終極矣猶是物力而遼餉津糧則</span>  
<span style="margin-left: 1em">前之辛未所未有猶是征輸而索逋及於八年考成及</span>  
<span style="margin-left: 1em">於零雜則前之辛未所未有賦日重日急民益困民益</span>  
<span style="margin-left: 1em">困俗日偷以一百二十年積重之弊救之急若援溺而</span>  
<span style="margin-left: 1em">貢且屑屑焉簿書期會是問不遑攷掌故而師前賢舊</span>  
<span style="margin-left: 1em">有志猶弗志耳故余以脩</span>  
<span style="margin-left: 1em">聖宫之餘董脩郡志志郡事也併以志我過屬有采薪</span>  
<span style="margin-left: 1em">之憂旦晚解組後我而守者亟爲我懺之</span>  
<span style="margin-left: 3em">襄西方岳貢書於退思軒時清和月之廿二日</span>  
<span style="margin-left: 1em">重修松江府志序</span>  
<span style="margin-left: 1em">其昌憶當蚤歲西蜀王公謀續郡志陳太史伯求曰郡</span>  
<span style="margin-left: 1em">當甲寅乙卯用兵之後勞臣戰將烈婦貞女尚在故老</span>  
<span style="margin-left: 1em">之口失今不紀遺恨千秋嗟嗟此二千石守長教訓正</span>  
<span style="margin-left: 1em">俗之事後時猶病况久廢不講乎又三十年而閣學陳</span>  
<span style="margin-left: 1em">文憲公疏脩本朝正史有</span>  
<span style="margin-left: 1em">詔天下郡國皆脩誌乘亟進史局於是文淵閣書目驟</span>  
<span style="margin-left: 1em">增其半吾郡但以舊志應當是時主盟者有陸文定羽</span>  
<span style="margin-left: 1em">翼者有同館三四夫子文獻非不足也而東郡許公道</span>  
<span style="margin-left: 1em">謀竟成寡和脩志之不可冀如此今郡大夫禹脩方公</span>  
<span style="margin-left: 1em">政成廉善才擅史長禮樂當百年之興是非扶三代之</span>  
<span style="margin-left: 1em">直慨然以續脩爲己任驅車山中授簡陳子就方正學</span>  
<span style="margin-left: 1em">先生之祠而揚扢焉公曰當吾世而筆討此昌黎之所</span>  
<span style="margin-left: 1em">懼也敢爲賢者累抑孔子作春秋於隱桓則章於定哀</span>  
<span style="margin-left: 1em">則微請以人物志斷自</span>  
<span style="margin-left: 1em">肅廟之丙寅庶幾定論己成大書無忌豈惟先賢耆舊</span>  
<span style="margin-left: 1em">月旦森然而揭車湘芷區別於士林檮杌騶虞並登於</span>  
<span style="margin-left: 1em">民監公之義例如此若乃千腋萃而成裘衆材備而作</span>  
<span style="margin-left: 1em">室則通郡之事目日繁舊志之網羅猶略士大夫欣逢</span>  
<span style="margin-left: 1em">曠典仰贊芳規莫不發其縹緗購彼散失說鈴腹笥四</span>  
<span style="margin-left: 1em">面畢陳蠹簡殘編一朝大出豈有乘軒之採拜爵之酬</span>  
<span style="margin-left: 1em">哉則公之德意所風動遠矣公嘗盟於正學之祠以穢</span>  
<span style="margin-left: 1em">史謗書爲誡惟兹兵農錢穀賦役民隱攸關神叢是託</span>  
<span style="margin-left: 1em">新法與掌故離合靡常詔令與教條東西易嚮舞文不</span>  
<span style="margin-left: 1em">已玄籍乘之仕者之耳目密移民生之脂膏暗吸此其</span>  
<span style="margin-left: 1em">凶于而國不在穢史謗書之下乃惣其條貫周爰諮詢</span>  
<span style="margin-left: 1em">參考異同歸之畫一使周車炳於指路禹鼎凛乎伏姦</span>  
<span style="margin-left: 1em">此又公之深心造福吾松於無既者也是役也一事而</span>  
<span style="margin-left: 1em">三善備焉鑒裁精也荷擔勇也翕受虛也殺青既竟而</span>  
<span style="margin-left: 1em">猶以施設未盡爲愧孔子曰我欲載之空言不如見諸</span>  
<span style="margin-left: 1em">行事宛然春秋法也哉不佞昌多暇人也田光之魂已</span>  
<span style="margin-left: 1em">消趙孟之偷無改不能具研削以從獨以及見河清爲</span>  
<span style="margin-left: 1em">幸而附名末簡云爾</span>  
<span style="margin-left: 1em">賜進士第資善大夫南京禮部尚書前禮部左侍郎兼</span>  
<span style="margin-left: 1em">翰林院侍讀學士詹事府詹事掌南京翰林院事</span>  
<span style="margin-left: 1em">實錄副總裁</span>  
<span style="margin-left: 1em">經筵講官郡人董其昌撰并書</span>  
<span style="margin-left: 1em">修志始末記</span>  
<span style="margin-left: 1em">郡伯禹脩方公祖下車以來一塵不染百廢具興歲穰</span>  
<span style="margin-left: 1em">人和惟焚香披閲圖史而已展及顧文僖公舊志屈指</span>  
<span style="margin-left: 1em">百二十年人文漸覺凋落有感於大方伯七澤張公之</span>  
<span style="margin-left: 1em">勤請也申之臺察謀之寮屬諏吉告文於方正學先生</span>  
<span style="margin-left: 1em">而薦紳孝秀咸集焉約十日一赴求忠書院分曹議之</span>  
<span style="margin-left: 1em">久則或至或否又久之凡郡中零星故實亦無復有投</span>  
<span style="margin-left: 1em">牒掌記者矣於是郡伯敦趨不佞儒更亟儒逡巡避如</span>  
<span style="margin-left: 1em">前俞彦直曰我將助子先大夫私錄志事秘笥中竊嘗</span>  
<span style="margin-left: 1em">欲禀承先志以成一郡之書鳩異聞蒐佚籍移舟不憚</span>  
<span style="margin-left: 1em">千里挑燈每及五更今且傾笥授子矣儒大喜乃繇山</span>  
<span style="margin-left: 1em">入郡不佞住東頭彦直住西頭繪圖雕棗始肇厥工而</span>  
<span style="margin-left: 1em">郡伯又聘章吉甫以匡儒之不逮儒謂吉甫曰自來脩</span>  
<span style="margin-left: 1em">志者比擬於脩史吾獨謂史易而志難史有起居註有</span>  
<span style="margin-left: 1em">編管章奏事繫歲歲繫月月繫日先後班班可考鏡而</span>  
<span style="margin-left: 1em">志有是乎一難也史不得求之譜今故家子姓如郯子</span>  
<span style="margin-left: 1em">之能言其祖王弘日對千客而不犯一人之諱者誰乎</span>  
<span style="margin-left: 1em">堂搆雖仍譜系不熟一難也先輩陸澄有地里書顧野</span>  
<span style="margin-left: 1em">王有輿地志非郡史材乎目前了無可尋即楊潛徐碩</span>  
<span style="margin-left: 1em">張之翰孫鼎諸舊本亦類龜毛兔角矣一難也倭奴躪</span>  
<span style="margin-left: 1em">內地轉餉徵師闕未書城上海邑青浦闕未書鄭僉憲</span>  
<span style="margin-left: 1em">均田林侍御均糧徐中丞均役闕未書張江陵下履畝</span>  
<span style="margin-left: 1em">之令縮弓溢額闕未書海忠介濬吳淞闕未書嘉靖辛</span>  
<span style="margin-left: 1em">酉萬曆戊子戊申大災大賑闕未書十年編里甲五年</span>  
<span style="margin-left: 1em">編收解闕未書諸如此類書之則其詞不雅馴雅馴矣</span>  
<span style="margin-left: 1em">而情形不必其精核洞達一難也史臣祕在禁廷監以</span>  
<span style="margin-left: 1em">勲戚總以公孤雖外僚不敢妄窺著作尺寸之地今圖</span>  
<span style="margin-left: 1em">史縱横於蓬牖賓朋剥啄於衡門一難也儒以七十四</span>  
<span style="margin-left: 1em">老人荷擔一百二十年曠典狹書細字複界重行瞶瞶</span>  
<span style="margin-left: 1em">行霧露中耳且才者遜之而拙者任之上衮遜之而布</span>  
<span style="margin-left: 1em">衣任之又一難也志之難如此可柰何吉甫曰是不難</span>  
<span style="margin-left: 1em">頃奉郡檄人物如史例生不立傳矣郡伯留</span>  
<span style="margin-left: 1em">覲得從容設處以觀厥成干旄不時至矣廪餼不時餽</span>  
<span style="margin-left: 1em">矣舊志徵引書籍寥寥無幾今采輯至三四千卷餘如</span>  
<span style="margin-left: 1em">累朝之實錄及省直郡縣之通志拈出無遺儲畜多則</span>  
<span style="margin-left: 1em">排纘便矣同事者或工於考古或敏於濡削或嚴於訂</span>  
<span style="margin-left: 1em">訛或密於收納部署少者助若老健者助若鈍同事踰</span>  
<span style="margin-left: 1em">年俱銷歸於太和罏冶中矣志何甚難之有陳子曰善</span>  
<span style="margin-left: 1em">乃與諸君子剋期竣事稿甫脱而剞劂隨之視顧志卷</span>  
<span style="margin-left: 1em">帙頗多歲月頗速而整齊精簡以補隆萬之遺則俟彦</span>  
<span style="margin-left: 1em">直歸而謀之而余志始無憾僕力已止此汲深窘於短</span>  
<span style="margin-left: 1em">綆道遠躓於疾行志雖不工不愈於今人而姑待後人</span>  
<span style="margin-left: 1em">今歲而復待他歲者乎若其中役法荒政郡伯謂東南</span>  
<span style="margin-left: 1em">民力民命所關不惜饒舌盡言之而小叙之似諷似諫</span>  
<span style="margin-left: 1em">則區區微寓芻蕘倘亦司牧者問織問耕師蟻師馬之</span>  
<span style="margin-left: 1em">少助哉此崇禎庚午辛未脩志之始末也是爲記</span>

<span style="margin-left: 2em">利蹟之宜補者也至於徐夷肆螫横海張戈白羽朱</span>  
<span style="margin-left: 2em">旂曾振武安之瓦高城大塹亦奉魯連之書百祀猶</span>  
<span style="margin-left: 2em">有戒心一隅豈曰無警爰從息樹之日宜繹綢桑之</span>  
<span style="margin-left: 2em">詩此烽燧之宜補者也又若民勞未復歲饉屢徵黑</span>  
<span style="margin-left: 2em">蜧白𧔥偏作哀鴻之祟苦葶惡藻時爲甘草之殃救</span>  
<span style="margin-left: 2em">荒何至於無奇發粟安名爲矯擅繭絲急而布病杼</span>  
<span style="margin-left: 2em">柚空而珮長中飽則上下俱饑尾大則臂指難使此</span>  
<span style="margin-left: 2em">痱癖之宜補者也若此者略舉概凡已窮標本倘搜</span>  
<span style="margin-left: 2em">遺墜豈免愆忘况乎蘅簷孤節易從艸木俱凋丘園</span>  
<span style="margin-left: 2em">帛戔不與翹車同載甘淵之曜肯留爝於腐螢峚陽</span>  
<span style="margin-left: 2em">之膏不辱馨於濁涌倘猶旁萃遜括曲收謝劬樂蟪</span>  
<span style="margin-left: 2em">蛄之寸拘躭榆枋之尺適吾恐靈峯湛泖將掬茂艸</span>  
<span style="margin-left: 2em">於杞宋矣先大夫往好管氏之言以土定人及其宜</span>  
<span style="margin-left: 2em">植復如史遷所歷風俗物産畫地而稱余小子束髮</span>  
<span style="margin-left: 2em">從游簪毫待吮將採金而鑄鼎爰獵腋以資裘是以</span>  
<span style="margin-left: 2em">排纂不厭其繁複芟夷不厭其苛嚴託慕既珍則古</span>  
<span style="margin-left: 2em">芳先擷貫穿認體則時誡備陳竊以游夏之贊詞用</span>  
<span style="margin-left: 2em">窺馬班之作用若曰徵文攷獻補百餘年未了之公</span>  
<span style="margin-left: 2em">案於以作起曠緒咨諏信史機緣時節皆秉筆秉衡</span>  
<span style="margin-left: 2em">者際之余小子受成而已又何力之有焉華亭後學</span>  
<span style="margin-left: 2em">俞廷諤彦直父識</span>
