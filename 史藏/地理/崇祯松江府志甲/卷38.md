## 崇禎松江府志卷之三十八　人物三（國朝賢達）

<span style="margin-left: 3em">國朝賢達<sub class="note-yuan">三</sub></span>  
<span style="margin-left: 1em">國朝</span>  
<span style="margin-left: 1em">全思誠字希賢上海人博學能詩文洪武十六年以耆</span>  
<span style="margin-left: 1em">儒繇本郡學正徵授文華殿大學士　上曰朕觀古人</span>  
<span style="margin-left: 1em">有志之士雖髮白氣衰心猶不怠故能善其始終卿懷</span>  
<span style="margin-left: 1em">才抱德志肩古人朕甚嘉焉惜乎年迫衰暮志雖存而</span>  
<span style="margin-left: 1em">力不能任朕不忍復勞特授此職以輔導太子免卿早</span>  
<span style="margin-left: 1em">朝日晏而入不久當從其志庶不負卿平生所學而鄉</span>  
<span style="margin-left: 1em">里亦有光焉思誠固辭翼日賜勑放還</span>  
<span style="margin-left: 2em">王逢有寄希賢學正兼諷陸宅之錢思復詩花開花</span>  
<span style="margin-left: 2em">落雪盈顱三地相望一信無梁震不慚前進士杜陵</span>  
<span style="margin-left: 2em">寧是老狂夫長淮浪接江逾濶南極星聯斗不孤想</span>  
<span style="margin-left: 2em">與窮經全學正酒香鄰杜杖同扶又郡人顧禄云余</span>  
<span style="margin-left: 2em">年十五即游郡庠當時爲師者全公希賢丘公克莊</span>  
<span style="margin-left: 2em">楊公孟載貝公仲琚魯公道源包公叔藴皆一時名</span>  
<span style="margin-left: 2em">士由是慕學之士自遠而來十餘年無慮千數松江</span>  
<span style="margin-left: 2em">一時文風之盛不下鄒魯<sub class="note-yuan">大雅集稱華亭人</sub></span>  
<span style="margin-left: 1em">王應隆字嘉會華亭人深明易理尤長於詩文應聘明</span>  
<span style="margin-left: 1em">經至京　高皇帝命賦詩應制稱旨復試其文賞異之</span>  
<span style="margin-left: 1em">除授簡討陞右司業時宋訥爲祭酒嘉會與訥及左司</span>  
<span style="margin-left: 1em">業龔敩嚴立楷範士類多所造就上眷待殊厚十六年</span>  
<span style="margin-left: 1em">冬以老疾乞歸優詔調治予致仕未啓行卒於官舍年</span>  
<span style="margin-left: 1em">八十餘　上嗟悼命禮部移文應天府給舟車還其喪</span>  
<span style="margin-left: 1em">發引日詔所在官司備禮祭之</span>  
<span style="margin-left: 1em">李寬字處仁原名可禮其先東平人父鎮撫松江萬户</span>  
<span style="margin-left: 1em">因占籍華亭少偕弟可才輩從魯道源受春秋年十六</span>  
<span style="margin-left: 1em">魁江浙省榜世亂隱居不出洪武初袁凱俞允等以人</span>  
<span style="margin-left: 1em">才薦臺使黃克庸聘署華亭訓導與掌教胡儼朝夕飭</span>  
<span style="margin-left: 1em">學宫端士習郡稱得師滿九載陞安遠令至則築望昕</span>  
<span style="margin-left: 1em">亭申諭鄉三老無干三尺訓諸士有法監司署其考曰</span>  
<span style="margin-left: 1em">處嵐瘴之地不易其心撫刁詐之民咸服其化以述職</span>  
<span style="margin-left: 1em">赴京病殁子萱繼登永樂庚子鄉舉有司表其堂曰世</span>  
<span style="margin-left: 1em">桂一時治春秋者若尚書錢溥按察司錢博侍御薛驥</span>  
<span style="margin-left: 1em">儀部俞永輩皆出其門若新昌訓導寅雲南按使希顔</span>  
<span style="margin-left: 1em">郡守人龍孝廉獻章耆卿鵬程皆其名裔</span>  
<span style="margin-left: 1em">朱芾字孟辨華亭人自號滄洲生少從楊鐵崖游才思</span>  
<span style="margin-left: 1em">飄逸工詞章兼善翰墨真草篆隸清潤遒勁風度不凡</span>  
<span style="margin-left: 1em">繪事亦擅聲於時洪武初以徵聘至官編修改中書舍</span>  
<span style="margin-left: 1em">人　太祖御製集有和朱孟辨落花詩</span>  
<span style="margin-left: 1em">管訥字時敏華亭人九歲能文比壯儀觀偉然受洪武</span>  
<span style="margin-left: 1em">中以秀才徵拜楚王府紀善恭謹强力事不避難楚王</span>  
<span style="margin-left: 1em">深加器重奏晉長史在職十年事無苟從必由於義年</span>  
<span style="margin-left: 1em">七十乞歸王不忍其去親製詩道意命世子書忠勤良</span>  
<span style="margin-left: 1em">佐四大字以褒之仍奏留本國先是訥五十艱子及從</span>  
<span style="margin-left: 1em">討蠻寇於銅鼓用訥之畫悉破斬之諸將以鄰於寇壤</span>  
<span style="margin-left: 1em">欲殄其衆訥進言曰是雖荒裔亦人類也奈何草雉而</span>  
<span style="margin-left: 1em">禽獮之王從其言揮使蔡春退而嘆曰管公一言活數</span>  
<span style="margin-left: 1em">萬之命必有後矣越數年生子錫名延枝教育於宫中</span>  
<span style="margin-left: 1em">既長奏爲伴讀今遂爲楚人所著有蚓竅集</span>  
<span style="margin-left: 2em">訥之子延枝天順乙卯年踰七十省墓還松親故有</span>  
<span style="margin-left: 2em">贈行詩文卷</span>  
<span style="margin-left: 1em">李至剛華亭人初名銅以字行父象賢洪武初爲縣學</span>  
<span style="margin-left: 1em">訓導擢任陝西鄜州同知大有施設卒於宦至剛嘗從</span>  
<span style="margin-left: 1em">學楊廉夫爲詩文有清思洪武戊辰舉明經奉命侍懿</span>  
<span style="margin-left: 1em">文太子授祠部試郎中坐累戌邊尋召還爲虞部郎中</span>  
<span style="margin-left: 1em">陞河南右參議會河決汴隄居民危懼建議假王府積</span>  
<span style="margin-left: 1em">木作筏濟之人賴全活甚衆調湖廣參議　太宗入正</span>  
<span style="margin-left: 1em">大統大臣薦其才遂以爲右通政旦暮在左右道說洪</span>  
<span style="margin-left: 1em">武中事甚親密是冬陞禮部尚書長於剸繁益見寵遇</span>  
<span style="margin-left: 1em">永樂一年春册立　皇太子命兼左春坊大學士爲侍</span>  
<span style="margin-left: 1em">郎宋禮所間降祠祭郎中與解縉素厚縉既遭讒人有</span>  
<span style="margin-left: 1em">言其怨望者詔下獄并逮至剛　仁廟嗣位復舊官念</span>  
<span style="margin-left: 1em">其老擇近郡優之改知興化有惠政再歲殁於官享年</span>  
<span style="margin-left: 1em">七十次子源永樂甲辰進士楊士奇表其墓</span>  
<span style="margin-left: 2em">永樂元年癸未二月癸丑禮部尚書李至剛上言論</span>  
<span style="margin-left: 2em">道經邦必求賢才興利除害必開言路昔太祖高皇</span>  
<span style="margin-left: 2em">帝勵精圖治聽納無遺三十年間化行俗美　皇上</span>  
<span style="margin-left: 2em">即位以來悉遵成憲博采群謀然無知小人往往假</span>  
<span style="margin-left: 2em">此爲名或搜求細事箝制諸司或懷挾私仇陷害良</span>  
<span style="margin-left: 2em">善或妄稱奏疏躲避差徭或馳騁小才希求進用甚</span>  
<span style="margin-left: 2em">者無稽泛言煩凟　聖聽雖稱興利除害其實假公</span>  
<span style="margin-left: 2em">營私誠宜榜示天下果有益國便民之事雖百工技</span>  
<span style="margin-left: 2em">藝之人皆許具實陳奏若官吏人等貪污顛倒曲直</span>  
<span style="margin-left: 2em">酷虐良善及婚姻田土軍役等事必令自下而上陳</span>  
<span style="margin-left: 2em">告若有假以實封建言驀越上司徑赴朝廷干冒者</span>  
<span style="margin-left: 2em">治以重罪永樂元年正月李至剛言宜徙北京從之</span>  
<span style="margin-left: 1em">王公亮華亭人洪武初以能書舉任吏科給事中陞應</span>  
<span style="margin-left: 1em">天府治中念草昧之初民心未定乃刲剔煩苛一意綏</span>  
<span style="margin-left: 1em">輯以卓異聞遷府丞益自淬礪舉所諳民情吏治斟酌</span>  
<span style="margin-left: 1em">施行之人大悦服永樂改元調四川右布政久之復調</span>  
<span style="margin-left: 1em">廣東卒于官公亮體貌豐偉儀度閒雅居官簡靜治政</span>  
<span style="margin-left: 1em">知大體所至廉重愷悌人皆悦服<sub class="note-yuan">載實錄又載廣東名宦</sub></span>  
<span style="margin-left: 1em">袁凱字景文華亭人父介字可潛以詩名吳中凱古貌</span>  
<span style="margin-left: 1em">長身議論英發尤工於詩專學杜工部又嘗以白燕詩</span>  
<span style="margin-left: 1em">得名於時號袁白燕洪武中拜侍御史上一日錄囚事</span>  
<span style="margin-left: 1em">竣送　東宫覆審遞减之凱還復命　上問凱朕與東</span>  
<span style="margin-left: 1em">宫孰是凱對曰　陛下法之正　東宫心之慈　上大</span>  
<span style="margin-left: 1em">喜從之後以疾放歸　上復思凱即其家拜本學教授</span>  
<span style="margin-left: 1em">凱對使者瞠目熟視唱月兒高一曲使者還報以凱爲</span>  
<span style="margin-left: 1em">真風遂不果召所著有在野集朱應祥序之陸文裕又</span>  
<span style="margin-left: 1em">購其殘缺刻既晦集</span>  
<span style="margin-left: 2em">洪武三年袁凱言國家盪平四方固資將帥之力然</span>  
<span style="margin-left: 2em">今天下已定將帥多在京師其精悍雄傑之士智雖</span>  
<span style="margin-left: 2em">有餘而於君臣之禮恐未悉究臣願於都督府延致</span>  
<span style="margin-left: 2em">通經學古之士或五人或三人每於諸將朔望早朝</span>  
<span style="margin-left: 2em">後俱赴都堂聽講經史庶幾忠君愛國之心全身保</span>  
<span style="margin-left: 2em">家之道油然自生而不自知也天生人材無非爲天</span>  
<span style="margin-left: 2em">下國家計其群小無廉耻之人有犯固在不赦至於</span>  
<span style="margin-left: 2em">老成長者或有過誤宜加矜恕養其廉耻以收他日</span>  
<span style="margin-left: 2em">之功則人材輩出矣　上嘉納之遂勑省臺延聘儒</span>  
<span style="margin-left: 2em">士於午門番直與諸將說書</span>  
<span style="margin-left: 1em">曹宗儒字元博慶孫之子洪武初任華亭教諭嘗爲府</span>  
<span style="margin-left: 1em">委至京師　上諭禮部曰教官所以作養生徒爲國儲</span>  
<span style="margin-left: 1em">才有司委以公務使不得盡心教訓甚非崇儒重道之</span>  
<span style="margin-left: 1em">意其禁止之所著有春秋左傳叙事本末三十卷子衡</span>  
<span style="margin-left: 1em">字士望精敏好學尤善真行草書仕至工科給事中</span>  
<span style="margin-left: 1em">任勉字近思華亭人登洪武甲戌進士授鄱陽令滿九</span>  
<span style="margin-left: 1em">載陞知瀘州會鄱民詣闕請留改同知薦爲福建右參</span>  
<span style="margin-left: 1em">政尋改都督府經歷考察南直隸官吏出知徽州府以</span>  
<span style="margin-left: 1em">事謫滄州者八年復起知蔚州內艱服除改睢州致仕</span>  
<span style="margin-left: 1em">壽八十有九初勉宰鄱陽訪擇德學鄉長者爲四門老</span>  
<span style="margin-left: 1em">每事相與酌輕重而處之或粘匿名文於縣門勉曰是</span>  
<span style="margin-left: 1em">教我也俾勿壞婦有新寡者訴夫兄不我養勉曰汝欲</span>  
<span style="margin-left: 1em">他適乎乃判其衫背曰餓死事極小失節事極大婦感</span>  
<span style="margin-left: 1em">其言卒不嫁邑中風勵稱爲賢令後所至皆載名宦勉</span>  
<span style="margin-left: 1em">豪邁英偉長身玉立音如洪鐘雖造次語言皆可錄永</span>  
<span style="margin-left: 1em">樂正統間論文章政事必以勉爲稱首所著有薇菴集</span>  
<span style="margin-left: 1em">子肅蚤夭以弟子弘爲後孫順仕終涇府長史</span>  
<span style="margin-left: 2em">太祖御宇數遣使者廉察諸士宦家當公令鄱陽時</span>  
<span style="margin-left: 2em">使者至其第止茅舍三間門臨池水父灌園母紡績</span>  
<span style="margin-left: 2em">使者問子何在門庭何蕭索如是父養素先生曰吾</span>  
<span style="margin-left: 2em">令兒子作清官不欲以脂膏自潤耳使者紿以客遊</span>  
<span style="margin-left: 2em">至鄱有札寄否因貽書戒之畧曰天道福善禍淫甚</span>  
<span style="margin-left: 2em">可畏也勿謂已安已治而懈怠勿謂己能己足而驕</span>  
<span style="margin-left: 2em">矜廉察使以書直達　宸覽并陳所居狀　上嘉歎</span>  
<span style="margin-left: 2em">旌異之</span>  
<span style="margin-left: 1em">俞允字嘉言華亭人入仕更名永力耕事父父性樂施</span>  
<span style="margin-left: 1em">予一日有道者羽衣策杖過之因止宿焉父命侍食謂</span>  
<span style="margin-left: 1em">允曰子有奇氣異時當爲　天子命吏遂別去允從李</span>  
<span style="margin-left: 1em">處仁授春秋卜築鳳山之麓三年學成洪武癸酉魁應</span>  
<span style="margin-left: 1em">天明年成進士授行人補楚府紀善輔導有體尋宰魯</span>  
<span style="margin-left: 1em">山創明理學士風翕然僚佐蔡滂曰俞公學通今古每</span>  
<span style="margin-left: 1em">有調畫必處置如法細大合宜民不驚擾若不知因革</span>  
<span style="margin-left: 1em">而翕然化成遠邇畏懷永樂初勑修大典妙選儒臣允</span>  
<span style="margin-left: 1em">被內召授禮部主事與胡儼劉季箎楊溥同在史局尋</span>  
<span style="margin-left: 1em">外艱服闋復官儀曹時有婚典奉旨往督供張部大臣</span>  
<span style="margin-left: 1em">授繻誤三日期謫判長沙未至貶所會道病暴卒已七</span>  
<span style="margin-left: 1em">日矣忽有道者貿藥至取青囊一粒納口中竟不死於</span>  
<span style="margin-left: 1em">是家人大喜競以金帛酬不受詢其姓名第云有長沙</span>  
<span style="margin-left: 1em">白鶴大仙廟盍往修之俄失所在始悟道者爲白鶴仙</span>  
<span style="margin-left: 1em">亦即向之杖策羽衣人也允悟宿因即致政歸研究性</span>  
<span style="margin-left: 1em">命之學又七年無疾而終<sub class="note-yuan">載河南名宦</sub></span>  
<span style="margin-left: 2em">允方正學門人當正學被難有幼子德宗航海投允</span>  
<span style="margin-left: 2em">允收匿舍中冒俞姓以養女妻之宗人懼禍更姓余</span>  
<span style="margin-left: 2em">至萬曆己酉學使楊廷筠廉其事得復原姓建正學</span>  
<span style="margin-left: 2em">祠祀方公而以允配食華亭知縣章允儒參語云俞</span>  
<span style="margin-left: 2em">公爲方正學先生門下士忠孝至味相投交情臨難</span>  
<span style="margin-left: 2em">乃見蓋方公之報國以不絕忠臣之嗣俞公之報師</span>  
<span style="margin-left: 2em">以力存如線之胤庶幾君臣師友之間可謂天理人</span>  
<span style="margin-left: 2em">情之至亟祀宫牆以光俎豆萬曆四十八年舉未行</span>  
<span style="margin-left: 1em">陳禎字景祺華亭人宋康肅公十四世孫洪武中以稅</span>  
<span style="margin-left: 1em">户子弟舉爲禮部主事有能聲嘗大廷議事衆不能決</span>
