## 崇祯松江府志卷之三十八　人物三（国朝贤达）

<span style="margin-left: 3em">国朝贤达<sub class="note-yuan">三</sub></span>  
<span style="margin-left: 1em">国朝</span>  
<span style="margin-left: 1em">全思诚字希贤上海人博学能诗文洪武十六年以耆</span>  
<span style="margin-left: 1em">儒繇本郡学正征授文华殿大学士　上曰朕观古人</span>  
<span style="margin-left: 1em">有志之士虽发白气衰心犹不怠故能善其始终卿怀</span>  
<span style="margin-left: 1em">才抱德志肩古人朕甚嘉焉惜乎年迫衰暮志虽存而</span>  
<span style="margin-left: 1em">力不能任朕不忍复劳特授此职以辅导太子免卿早</span>  
<span style="margin-left: 1em">朝日晏而入不久当从其志庶不负卿平生所学而乡</span>  
<span style="margin-left: 1em">里亦有光焉思诚固辞翼日赐勑放还</span>  
<span style="margin-left: 2em">王逢有寄希贤学正兼讽陆宅之钱思复诗花开花</span>  
<span style="margin-left: 2em">落雪盈颅三地相望一信无梁震不惭前进士杜陵</span>  
<span style="margin-left: 2em">宁是老狂夫长淮浪接江逾濶南极星联斗不孤想</span>  
<span style="margin-left: 2em">与穷经全学正酒香邻杜杖同扶又郡人顾禄云余</span>  
<span style="margin-left: 2em">年十五即游郡庠当时为师者全公希贤丘公克庄</span>  
<span style="margin-left: 2em">杨公孟载贝公仲琚鲁公道源包公叔蕴皆一时名</span>  
<span style="margin-left: 2em">士由是慕学之士自远而来十余年无虑千数松江</span>  
<span style="margin-left: 2em">一时文风之盛不下邹鲁<sub class="note-yuan">大雅集称华亭人</sub></span>  
<span style="margin-left: 1em">王应隆字嘉会华亭人深明易理尤长于诗文应聘明</span>  
<span style="margin-left: 1em">经至京　高皇帝命赋诗应制称旨复试其文赏异之</span>  
<span style="margin-left: 1em">除授简讨升右司业时宋讷为祭酒嘉会与讷及左司</span>  
<span style="margin-left: 1em">业龚敩严立楷范士类多所造就上眷待殊厚十六年</span>  
<span style="margin-left: 1em">冬以老疾乞归优诏调治予致仕未启行卒于官舍年</span>  
<span style="margin-left: 1em">八十余　上嗟悼命礼部移文应天府给舟车还其丧</span>  
<span style="margin-left: 1em">发引日诏所在官司备礼祭之</span>  
<span style="margin-left: 1em">李宽字处仁原名可礼其先东平人父镇抚松江万户</span>  
<span style="margin-left: 1em">因占籍华亭少偕弟可才辈从鲁道源受春秋年十六</span>  
<span style="margin-left: 1em">魁江浙省榜世乱隐居不出洪武初袁凯俞允等以人</span>  
<span style="margin-left: 1em">才荐台使黄克庸聘署华亭训导与掌教胡俨朝夕饬</span>  
<span style="margin-left: 1em">学宫端士习郡称得师满九载升安远令至则筑望昕</span>  
<span style="margin-left: 1em">亭申谕乡三老无干三尺训诸士有法监司署其考曰</span>  
<span style="margin-left: 1em">处岚瘴之地不易其心抚刁诈之民咸服其化以述职</span>  
<span style="margin-left: 1em">赴京病殁子萱继登永乐庚子乡举有司表其堂曰世</span>  
<span style="margin-left: 1em">桂一时治春秋者若尚书钱溥按察司钱博侍御薛骥</span>  
<span style="margin-left: 1em">仪部俞永辈皆出其门若新昌训导寅云南按使希颜</span>  
<span style="margin-left: 1em">郡守人龙孝廉献章耆卿鹏程皆其名裔</span>  
<span style="margin-left: 1em">朱芾字孟辨华亭人自号沧洲生少从杨铁崖游才思</span>  
<span style="margin-left: 1em">飘逸工词章兼善翰墨真草篆隶清润遒劲风度不凡</span>  
<span style="margin-left: 1em">绘事亦擅声于时洪武初以征聘至官编修改中书舍</span>  
<span style="margin-left: 1em">人　太祖御制集有和朱孟辨落花诗</span>  
<span style="margin-left: 1em">管讷字时敏华亭人九岁能文比壮仪观伟然受洪武</span>  
<span style="margin-left: 1em">中以秀才征拜楚王府纪善恭谨强力事不避难楚王</span>  
<span style="margin-left: 1em">深加器重奏晋长史在职十年事无苟从必由于义年</span>  
<span style="margin-left: 1em">七十乞归王不忍其去亲制诗道意命世子书忠勤良</span>  
<span style="margin-left: 1em">佐四大字以褒之仍奏留本国先是讷五十艰子及从</span>  
<span style="margin-left: 1em">讨蛮寇于铜鼓用讷之画悉破斩之诸将以邻于寇壤</span>  
<span style="margin-left: 1em">欲殄其众讷进言曰是虽荒裔亦人类也奈何草雉而</span>  
<span style="margin-left: 1em">禽狝之王从其言挥使蔡春退而叹曰管公一言活数</span>  
<span style="margin-left: 1em">万之命必有后矣越数年生子锡名延枝教育于宫中</span>  
<span style="margin-left: 1em">既长奏为伴读今遂为楚人所著有蚓窍集</span>  
<span style="margin-left: 2em">讷之子延枝天顺乙卯年逾七十省墓还松亲故有</span>  
<span style="margin-left: 2em">赠行诗文卷</span>  
<span style="margin-left: 1em">李至刚华亭人初名铜以字行父象贤洪武初为县学</span>  
<span style="margin-left: 1em">训导擢任陕西鄜州同知大有施设卒于宦至刚尝从</span>  
<span style="margin-left: 1em">学杨廉夫为诗文有清思洪武戊辰举明经奉命侍懿</span>  
<span style="margin-left: 1em">文太子授祠部试郎中坐累戌边寻召还为虞部郎中</span>  
<span style="margin-left: 1em">升河南右参议会河决汴隄居民危惧建议假王府积</span>  
<span style="margin-left: 1em">木作筏济之人赖全活甚众调湖广参议　太宗入正</span>  
<span style="margin-left: 1em">大统大臣荐其才遂以为右通政旦暮在左右道说洪</span>  
<span style="margin-left: 1em">武中事甚亲密是冬升礼部尚书长于剸繁益见宠遇</span>  
<span style="margin-left: 1em">永乐一年春册立　皇太子命兼左春坊大学士为侍</span>  
<span style="margin-left: 1em">郎宋礼所间降祠祭郎中与解缙素厚缙既遭谗人有</span>  
<span style="margin-left: 1em">言其怨望者诏下狱并逮至刚　仁庙嗣位复旧官念</span>  
<span style="margin-left: 1em">其老择近郡优之改知兴化有惠政再岁殁于官享年</span>  
<span style="margin-left: 1em">七十次子源永乐甲辰进士杨士奇表其墓</span>  
<span style="margin-left: 2em">永乐元年癸未二月癸丑礼部尚书李至刚上言论</span>  
<span style="margin-left: 2em">道经邦必求贤才兴利除害必开言路昔太祖高皇</span>  
<span style="margin-left: 2em">帝励精图治听纳无遗三十年间化行俗美　皇上</span>  
<span style="margin-left: 2em">即位以来悉遵成宪博采群谋然无知小人往往假</span>  
<span style="margin-left: 2em">此为名或搜求细事箝制诸司或怀挟私仇陷害良</span>  
<span style="margin-left: 2em">善或妄称奏疏躲避差徭或驰骋小才希求进用甚</span>  
<span style="margin-left: 2em">者无稽泛言烦凟　圣听虽称兴利除害其实假公</span>  
<span style="margin-left: 2em">营私诚宜榜示天下果有益国便民之事虽百工技</span>  
<span style="margin-left: 2em">艺之人皆许具实陈奏若官吏人等贪污颠倒曲直</span>  
<span style="margin-left: 2em">酷虐良善及婚姻田土军役等事必令自下而上陈</span>  
<span style="margin-left: 2em">告若有假以实封建言蓦越上司径赴朝廷干冒者</span>  
<span style="margin-left: 2em">治以重罪永乐元年正月李至刚言宜徙北京从之</span>  
<span style="margin-left: 1em">王公亮华亭人洪武初以能书举任吏科给事中升应</span>  
<span style="margin-left: 1em">天府治中念草昧之初民心未定乃刲剔烦苛一意绥</span>  
<span style="margin-left: 1em">辑以卓异闻迁府丞益自淬砺举所谙民情吏治斟酌</span>  
<span style="margin-left: 1em">施行之人大悦服永乐改元调四川右布政久之复调</span>  
<span style="margin-left: 1em">广东卒于官公亮体貌丰伟仪度闲雅居官简静治政</span>  
<span style="margin-left: 1em">知大体所至廉重恺悌人皆悦服<sub class="note-yuan">载实录又载广东名宦</sub></span>  
<span style="margin-left: 1em">袁凯字景文华亭人父介字可潜以诗名吴中凯古貌</span>  
<span style="margin-left: 1em">长身议论英发尤工于诗专学杜工部又尝以白燕诗</span>  
<span style="margin-left: 1em">得名于时号袁白燕洪武中拜侍御史上一日录囚事</span>  
<span style="margin-left: 1em">竣送　东宫覆审递减之凯还复命　上问凯朕与东</span>  
<span style="margin-left: 1em">宫孰是凯对曰　陛下法之正　东宫心之慈　上大</span>  
<span style="margin-left: 1em">喜从之后以疾放归　上复思凯即其家拜本学教授</span>  
<span style="margin-left: 1em">凯对使者瞠目熟视唱月儿高一曲使者还报以凯为</span>  
<span style="margin-left: 1em">真风遂不果召所著有在野集朱应祥序之陆文裕又</span>  
<span style="margin-left: 1em">购其残缺刻既晦集</span>  
<span style="margin-left: 2em">洪武三年袁凯言国家荡平四方固资将帅之力然</span>  
<span style="margin-left: 2em">今天下已定将帅多在京师其精悍雄杰之士智虽</span>  
<span style="margin-left: 2em">有余而于君臣之礼恐未悉究臣愿于都督府延致</span>  
<span style="margin-left: 2em">通经学古之士或五人或三人每于诸将朔望早朝</span>  
<span style="margin-left: 2em">后俱赴都堂听讲经史庶几忠君爱国之心全身保</span>  
<span style="margin-left: 2em">家之道油然自生而不自知也天生人材无非为天</span>  
<span style="margin-left: 2em">下国家计其群小无廉耻之人有犯固在不赦至于</span>  
<span style="margin-left: 2em">老成长者或有过误宜加矜恕养其廉耻以收他日</span>  
<span style="margin-left: 2em">之功则人材辈出矣　上嘉纳之遂勑省台延聘儒</span>  
<span style="margin-left: 2em">士于午门番直与诸将说书</span>  
<span style="margin-left: 1em">曹宗儒字元博庆孙之子洪武初任华亭教谕尝为府</span>  
<span style="margin-left: 1em">委至京师　上谕礼部曰教官所以作养生徒为国储</span>  
<span style="margin-left: 1em">才有司委以公务使不得尽心教训甚非崇儒重道之</span>  
<span style="margin-left: 1em">意其禁止之所著有春秋左传叙事本末三十卷子衡</span>  
<span style="margin-left: 1em">字士望精敏好学尤善真行草书仕至工科给事中</span>  
<span style="margin-left: 1em">任勉字近思华亭人登洪武甲戌进士授鄱阳令满九</span>  
<span style="margin-left: 1em">载升知泸州会鄱民诣阙请留改同知荐为福建右参</span>  
<span style="margin-left: 1em">政寻改都督府经历考察南直隶官吏出知徽州府以</span>  
<span style="margin-left: 1em">事谪沧州者八年复起知蔚州内艰服除改睢州致仕</span>  
<span style="margin-left: 1em">寿八十有九初勉宰鄱阳访择德学乡长者为四门老</span>  
<span style="margin-left: 1em">每事相与酌轻重而处之或粘匿名文于县门勉曰是</span>  
<span style="margin-left: 1em">教我也俾勿坏妇有新寡者诉夫兄不我养勉曰汝欲</span>  
<span style="margin-left: 1em">他适乎乃判其衫背曰饿死事极小失节事极大妇感</span>  
<span style="margin-left: 1em">其言卒不嫁邑中风励称为贤令后所至皆载名宦勉</span>  
<span style="margin-left: 1em">豪迈英伟长身玉立音如洪钟虽造次语言皆可录永</span>  
<span style="margin-left: 1em">乐正统间论文章政事必以勉为称首所著有薇庵集</span>  
<span style="margin-left: 1em">子肃蚤夭以弟子弘为后孙顺仕终泾府长史</span>  
<span style="margin-left: 2em">太祖御宇数遣使者廉察诸士宦家当公令鄱阳时</span>  
<span style="margin-left: 2em">使者至其第止茅舍三间门临池水父灌园母纺绩</span>  
<span style="margin-left: 2em">使者问子何在门庭何萧索如是父养素先生曰吾</span>  
<span style="margin-left: 2em">令儿子作清官不欲以脂膏自润耳使者绐以客游</span>  
<span style="margin-left: 2em">至鄱有札寄否因贻书戒之畧曰天道福善祸淫甚</span>  
<span style="margin-left: 2em">可畏也勿谓已安已治而懈怠勿谓己能己足而骄</span>  
<span style="margin-left: 2em">矜廉察使以书直达　宸览并陈所居状　上嘉叹</span>  
<span style="margin-left: 2em">旌异之</span>  
<span style="margin-left: 1em">俞允字嘉言华亭人入仕更名永力耕事父父性乐施</span>  
<span style="margin-left: 1em">予一日有道者羽衣策杖过之因止宿焉父命侍食谓</span>  
<span style="margin-left: 1em">允曰子有奇气异时当为　天子命吏遂别去允从李</span>  
<span style="margin-left: 1em">处仁授春秋卜筑凤山之麓三年学成洪武癸酉魁应</span>  
<span style="margin-left: 1em">天明年成进士授行人补楚府纪善辅导有体寻宰鲁</span>  
<span style="margin-left: 1em">山创明理学士风翕然僚佐蔡滂曰俞公学通今古每</span>  
<span style="margin-left: 1em">有调画必处置如法细大合宜民不惊扰若不知因革</span>  
<span style="margin-left: 1em">而翕然化成远迩畏怀永乐初勑修大典妙选儒臣允</span>  
<span style="margin-left: 1em">被内召授礼部主事与胡俨刘季箎杨溥同在史局寻</span>  
<span style="margin-left: 1em">外艰服阕复官仪曹时有婚典奉旨往督供张部大臣</span>  
<span style="margin-left: 1em">授𦈡误三日期谪判长沙未至贬所会道病暴卒已七</span>  
<span style="margin-left: 1em">日矣忽有道者贸药至取青囊一粒纳口中竟不死于</span>  
<span style="margin-left: 1em">是家人大喜竞以金帛酬不受询其姓名第云有长沙</span>  
<span style="margin-left: 1em">白鹤大仙庙盍往修之俄失所在始悟道者为白鹤仙</span>  
<span style="margin-left: 1em">亦即向之杖策羽衣人也允悟宿因即致政归研究性</span>  
<span style="margin-left: 1em">命之学又七年无疾而终<sub class="note-yuan">载河南名宦</sub></span>  
<span style="margin-left: 2em">允方正学门人当正学被难有幼子德宗航海投允</span>  
<span style="margin-left: 2em">允收匿舍中冒俞姓以养女妻之宗人惧祸更姓余</span>  
<span style="margin-left: 2em">至万历己酉学使杨廷筠廉其事得复原姓建正学</span>  
<span style="margin-left: 2em">祠祀方公而以允配食华亭知县章允儒参语云俞</span>  
<span style="margin-left: 2em">公为方正学先生门下士忠孝至味相投交情临难</span>  
<span style="margin-left: 2em">乃见盖方公之报国以不绝忠臣之嗣俞公之报师</span>  
<span style="margin-left: 2em">以力存如线之胤庶几君臣师友之间可谓天理人</span>  
<span style="margin-left: 2em">情之至亟祀宫墙以光俎豆万历四十八年举未行</span>
