## 崇祯松江府志卷之六　物产

<span style="margin-left: 3em">物产</span>  
<span style="margin-left: 1em">吴都赋云国税再熟之稻乡贡八蚕之绵珠服玉馔自</span>  
<span style="margin-left: 1em">昔称之然平畴与高山奥区羽毛夭乔率皆凡材也亦</span>  
<span style="margin-left: 1em">何足载名山经镂形夏鼎且而鸣吠相闻刍牧相守邻</span>  
<span style="margin-left: 1em">封所共岂一郡掌故得而私焉唯是品题独著见于古</span>  
<span style="margin-left: 1em">今人之载记者即私以为异可也</span>  
<span style="margin-left: 1em">物莫贵于五谷谷之品曰稻曰麦曰豆曰黍曰稷理生</span>  
<span style="margin-left: 1em">玉镜曰稻之粒其白如霜其性宜水说文谓之稌沛国</span>  
<span style="margin-left: 1em">谓之穤以黏者谓之糯亦谓之秫以不黏者谓之秔亦</span>  
<span style="margin-left: 1em">谓之稉故氾胜之云三月而种秔四月而种秫然皆谓</span>  
<span style="margin-left: 1em">之稻稉之小者谓之籼尝询之老农其粒小而色白四</span>  
<span style="margin-left: 1em">月种六月熟曰六十日稻又迟者曰八十日稻又迟者</span>  
<span style="margin-left: 1em">曰百日赤而小稻之种亦有六十日籼百日籼曰拖犂</span>  
<span style="margin-left: 1em">归白稃无芒或七月八月而熟俱谓之古城稻其性硬</span>  
<span style="margin-left: 1em">而皮茎俱白曰䆉䅉<sub class="note-yuan">俗呼早野</sub>稻其粒大色白秆软而有芒</span>  
<span style="margin-left: 1em">曰雪里拣其粒白无芒而秆矮九月熟曰师姑秔亦曰</span>  
<span style="margin-left: 1em">矮白五月种九月熟而皮赤者早曰早乌晚曰晚乌又</span>  
<span style="margin-left: 1em">有蝉鸣稻半夏稻黄陆稻青秆稻白漠稻鹊不知下马</span>  
<span style="margin-left: 1em">看<sub class="note-yuan">即三朝齐</sub>言其秀之易也其色白而性软五月种十月熟</span>  
<span style="margin-left: 1em">曰羊脂糯其色班五月种十月熟曰虎皮糯其粒最长</span>  
<span style="margin-left: 1em">白浮而有芒四月种七月熟曰赶陈糯其粒大而色白</span>  
<span style="margin-left: 1em">四月种九月熟曰矮儿糯其桴黄而芒赤已熟而秆微</span>  
<span style="margin-left: 1em">青四月种九月熟曰青秆糯又有小娘糯芦黄糯羊须</span>  
<span style="margin-left: 1em">糯鵞脂糯榧子糯白壳糯种类至繁吴之农不尽识也</span>  
<span style="margin-left: 1em">今姑存其略而吾松特著者曰箭子稻香稻红莲稻紫</span>  
<span style="margin-left: 1em">芒稻白花珠大小白麦争塲一丈红早中秋再熟稻松</span>  
<span style="margin-left: 1em">江赤金钗糯冷粒糯</span>  
<span style="margin-left: 1em">箭子稻其粒细长而白味香而甘以九月熟稻品之最</span>  
<span style="margin-left: 2em">高者即晚白稻而更胜今海内共推江南晚米此种</span>  
<span style="margin-left: 2em">尤第一</span>  
<span style="margin-left: 2em"><sub class="note-yuan">魏文靖骥尝新稻诗自序云忆昔在云间时承唐桥张氏父子兄弟若竹泉林岫东轩辈遇熟必先寄以尝触物感怀赋此云间咫尺若三秦别去于今六十春且喜又尝新谷饭堪嗟不见昔年人功名富贵情怀淡棋局琴台笑语新今日尽为蓬岛客停云可不泪沾巾何良俊秋获诗江南秔稻说吴淞生计吾应傍老农谩煑青精廻日驭细餐玉粒长秋容</sub></span>  
<span style="margin-left: 1em">香稻农圃四书云香秔其在松江者粒小而性柔有红</span>  
<span style="margin-left: 2em">芒赤芒之等七月而熟以三五十粒入它米数升炊</span>  
<span style="margin-left: 2em">之芬芳馨美谓之香子又谓之香櫑魏文帝与朝臣</span>  
<span style="margin-left: 2em">书曰江表闻长沙有好米何得比吴中香稻耶上风</span>  
<span style="margin-left: 2em">炊之五里闻香</span>  
<span style="margin-left: 1em">红莲稻粒大芒赤五月种九月熟吴郡志云粒肥而香</span>  
<span style="margin-left: 2em">陆龟蒙怀归诗有遥为晚花吟白菊<sub class="note-jiao">校：菊白當倒乙文今正之</sub>近</span>  
<span style="margin-left: 2em">炊香稻识红莲盖唐时已称之农圃四书云其粒长</span>  
<span style="margin-left: 2em">而色班五月而种九月而熟松江谓之胜红莲</span>  
<span style="margin-left: 1em">大小白农圃四书云其粒赤而稃芒白五月初种八月</span>  
<span style="margin-left: 2em">而熟谓之早白稻松江谓之小白九月而熟谓之晚</span>  
<span style="margin-left: 2em">白又谓芦花白松江谓之大白</span>  
<span style="margin-left: 1em">紫芒稻五月种九月熟紫谷白粒张方平诗云鲈脍饭</span>  
<span style="margin-left: 2em">紫芒古时人尊之常与鲈脍同荐</span>  
<span style="margin-left: 1em">白花珠性柔而不黏最宜作糜和润香滑异于常种吾</span>  
<span style="margin-left: 2em">郡东土人植之四月种九月收以品高而收薄故农</span>  
<span style="margin-left: 2em">人不能广种</span>  
<span style="margin-left: 1em">麦争塲以三月种六月熟谓与麦争塲也松江耕农稍</span>  
<span style="margin-left: 2em">有本力者必种少许以先疗饥农遗杂疏曰此种早</span>  
<span style="margin-left: 2em">熟农人甚赖其利食新者争市之价贵也若荒年新</span>  
<span style="margin-left: 2em">稔则倍尔矣</span>  
<span style="margin-left: 1em">一丈红徐玄扈云吾乡垦荒者近得籼稻曰一丈红五</span>  
<span style="margin-left: 2em">月种八月收绝能<sub class="note-yuan">古耐字</sub>水水深三四尺漫散种其中</span>  
<span style="margin-left: 2em">能从水底抽芽出水与常稻同熟但须厚壅耳松郡</span>  
<span style="margin-left: 2em">水乡此种不患潦最宜植之又农圃四书云其再莳</span>  
<span style="margin-left: 2em">而晚熟者谓之乌口稻在松江色黑而能<sub class="note-yuan">古耐字</sub>水与</span>  
<span style="margin-left: 2em">寒谓之冷水结是为稻之下品</span>  
<span style="margin-left: 1em">蚤中秋农圃四书云其粒白而大四月种八月熟谓之</span>  
<span style="margin-left: 2em">中秋稻在松江八月望而熟者谓之蚤中秋又谓之</span>  
<span style="margin-left: 2em">闪西风</span>  
<span style="margin-left: 1em">再熟稻见吴都赋后无称焉蒋堂登松江亭诗云向日</span>  
<span style="margin-left: 2em">早青牛引犊经秋田熟稻生孙注云是年有再熟之</span>  
<span style="margin-left: 2em">稻攷之当在皇祐间今田间丰岁已刈而稻根复蒸</span>  
<span style="margin-left: 2em">苗极易长旋复成实可掠取谓之再撩稻恐古所称</span>  
<span style="margin-left: 2em">即此</span>  
<span style="margin-left: 2em">理生玉镜曰其已刈而根复发苗再实者谓之再熟</span>  
<span style="margin-left: 2em">稻亦谓之再撩农遗杂疏云其陈根复生所谓稆也</span>  
<span style="margin-left: 2em">俗亦谓之二僚绝不秀实农人急恳之迟则损田力</span>  
<span style="margin-left: 1em">松江赤其粒尖色红而性硬四月种七月熟即金城稻</span>  
<span style="margin-left: 2em">也是惟高仰之所种农圃四书云松江谓之赤米乃</span>  
<span style="margin-left: 2em">谷之下品今郡中亦少所用赤米皆籴之楚中杂疏</span>  
<span style="margin-left: 2em">云其性不畏卤可当咸潮近海口之田不得不种之</span>  
<span style="margin-left: 1em">金钗糯米粒长三月种七月熟最宜酿酒刘梦得诗云</span>  
<span style="margin-left: 2em">酒法得传吴米好此也</span>  
<span style="margin-left: 2em">西溪丛语云宋王琪饮酒诗云蜀江雪浪来天际一</span>  
<span style="margin-left: 2em">派泉舂宝钗碎盖谓水碓舂金钗糯也金钗乃糯米</span>  
<span style="margin-left: 2em">之名</span>  
<span style="margin-left: 1em">冷粒糯种宜长田其粒圆白而稃黄大暑可刈其色难</span>  
<span style="margin-left: 2em">变不宜于酿酒谓之秋风糯可以代粳而输租又谓</span>  
<span style="margin-left: 2em">之瞒官糯农圃四书云松江谓之冷粒糯</span>  
<span style="margin-left: 2em">农遗杂疏曰有不道糯易种多收农人喜种之饭则</span>  
<span style="margin-left: 2em">糯酿则粳粜之则减价多以之代粳输租自是佳种</span>  
<span style="margin-left: 2em">〇俗呼为雌哥头古谓之奸米</span>  
<span style="margin-left: 1em">麦种以北地为良松郡所产大概有数种赤麦白麦又</span>  
<span style="margin-left: 1em">赤𥣬白𥣬麦紫秆麦火烧麦舜歌麦荞麦雀麦即燕麦</span>  
<span style="margin-left: 1em">躲梅麦以躲梅先熟青须麦至熟犹青也而吾郡所尚</span>  
<span style="margin-left: 1em">惟大麦小麦又悬壳麦即大麦别种而胜之以作饭佳</span>  
<span style="margin-left: 1em">大麦曰麰小麦曰𪎌陶隐居曰大麦为五谷长即今倮</span>  
<span style="margin-left: 2em">麦也似穬麦惟无皮耳吴农皆于秋成后播种三四</span>  
<span style="margin-left: 2em">月收刈土人呼为春熟接绝续乏农人最重先辈董</span>  
<span style="margin-left: 2em">良史击壤歌歌贤令也曰大麦䔿䔿秀小麦菶菶长</span>  
<span style="margin-left: 2em">菜花半稀青间黄今年县官好民害不下乡田家得</span>  
<span style="margin-left: 2em">安业出人无惊惶可知农尚矣</span>  
<span style="margin-left: 2em">南方麦花夜开昼掩受阴气多北方麦花昼开夜掩</span>  
<span style="margin-left: 2em">受阳气多故北麦宜人不特以种良也</span>  
<span style="margin-left: 1em">尔雅曰戎菽谓之荏菽孙炎注云戎菽大菽也广雅曰</span>  
<span style="margin-left: 1em">大豆菽也小豆荅也张骞使外国得胡豆以归传布中</span>  
<span style="margin-left: 1em">国今世大豆有黄黑白及紫罗四种小豆有赤菉白三</span>  
<span style="margin-left: 1em">种鷰豆豍豆蚕豆稨豆俗名延篱大豆类也豌豆俗名</span>  
<span style="margin-left: 1em">小寒豇豆俗名裙带小豆类也又刀豆龙爪豆皆以形</span>  
<span style="margin-left: 1em">名刀豆其叶可食龙爪花叶似裙带荚似蚕豆茅紫赤</span>  
<span style="margin-left: 1em">以徧地丛生故名亦大豆类也</span>  
<span style="margin-left: 1em">蚕豆九月种以蚕时熟故名一曰寒豆陆龟蒙嗜之移</span>  
<span style="margin-left: 2em">植松江甫里令农人每于田塍夹种之收其实贸钱</span>  
<span style="margin-left: 2em">亦以为饭</span>  
<span style="margin-left: 2em"><sub class="note-yuan">杨万里诗云翠荚中排浅碧珠甘欺崖蜜软欺酥沙瓶新熟西湖水漆櫑分尝晓露腴味与樱梅三益友名因蠢茧一丝絇老夫稼圃方双学谱入诗中当稼书</sub></span>  
<span style="margin-left: 1em">豌豆一名小寒九月种三月熟宋已前松故未有相传</span>  
<span style="margin-left: 2em">乡先辈宦游于蜀得其种植之今遍吴越间而其种</span>  
<span style="margin-left: 2em">则始吾郡蜀中以此豆之不实者为巢菜杂彘作笼</span>  
<span style="margin-left: 2em">饼啖之</span>  
<span style="margin-left: 2em">陆放翁过吴中得小巢作羹赋诗云春行露雨眩衡</span>  
<span style="margin-left: 2em">茅儿女随空治酒殽便觉此身如在蜀一盘笼饼是</span>  
<span style="margin-left: 2em">豌巢</span>  
<span style="margin-left: 1em">黄豆水白豆二种俱堪作腐孙大雅避地华亭命邻人</span>  
<span style="margin-left: 2em">作腐易其名曰菽乳<sub class="note-yuan">赋诗曰淮南信佳士思仙筑高台八老变童颜鸿宝枕中开异方营齐味数度真琦瑰传羹传世人令我忆蓬莱茹荤厌葱韭此物乃呈才戎菽来南山清漪浣浮埃转身一旋磨流膏入盆罍大釜气浮浮小眼汤洄洄顷待晴浪翻坐见雪花皑青盐化液卤绛蜡窜烟煤霍霍磨昆吾白玉大片裁烹煎适吾口不畏老齿摧蒸豚亦何为人乳圣所哀万钱同一饱斯言匪俳诙</sub></span>  
<span style="margin-left: 1em">黍穄凡有五色种类吾乡止有黄穄植于高原其色如</span>  
<span style="margin-left: 1em">蜡梁秫粟也尔雅曰虋门赤苗芑白苗郭璞注云虋今</span>  
<span style="margin-left: 1em">之赤梁粟芑今之白梁粟茎叶如薏苡而高亦东南乡</span>  
<span style="margin-left: 1em">高原种之秔者穗直而疏糯者穗疏而密然非所尚亦</span>  
<span style="margin-left: 1em">不广</span>  
<span style="margin-left: 2em">徐宗伯玄扈告乡里文<sub class="note-yuan">时年庚戌</sub>　近日水灾低田</span>  
<span style="margin-left: 11em"><sub class="note-yuan">水灾</sub></span>  
<span style="margin-left: 2em">渰没今水势退去禾已坏烂凡我农人切勿任其抛</span>  
<span style="margin-left: 2em">荒若寻种下秧时又无及六十日乌可种收成亦少</span>  
<span style="margin-left: 2em">今有一法虽立秋后数日尚可种稻与常时一般成</span>  
<span style="margin-left: 2em">熟要从邻近高田买其种成晚稻虽耘耨已毕但出</span>  
<span style="margin-left: 2em">重价自然肯卖每田二亩买他一亩间一科拔一科</span>  
<span style="margin-left: 2em">将此一亩稻分莳低田五亩多下粪饼便与常时同</span>  
<span style="margin-left: 2em">熟其高田虽卖去一半用粪接力稻科长大亦一般</span>  
<span style="margin-left: 2em">收成若禾长难莳须捩去稍叶存根一尺上下莳之</span>  
<span style="margin-left: 2em">晚稻处暑后方做肚未做肚前尽好分种不妨成实</span>  
<span style="margin-left: 2em">也若已经插莳今被渰没又无力买稻苗者亦要车</span>  
<span style="margin-left: 2em">去积水略令湿润稻苗虽烂稻根在土尚能发生培</span>  
<span style="margin-left: 2em">养起来反多了稻苗一番肥壅尽能成熟前一法是</span>  
<span style="margin-left: 2em">江浙农人常用他们不惜几石米买一亩禾至有一</span>  
<span style="margin-left: 2em">亩分作十亩莳者后一法余常亲验之近年水利不</span>  
<span style="margin-left: 2em">修太湖无从泄泻戊申之水到今未退所以一遇霖</span>  
<span style="margin-left: 2em">雨便能渰没不然已前何曾不做黄梅惟独今年数</span>  
<span style="margin-left: 2em">日之雨便长得许多水来今后若水利未修不免岁</span>  
<span style="margin-left: 2em">岁如此此法宜共传布之若时大旱到秋得雨亦用</span>  
<span style="margin-left: 2em">此法不信问诸江浙客游者凶年饥岁随意抛荒一</span>

<span style="margin-left: 2em">糕片而鬻时为珍庖脆梅甘豆市以青梅制脆镂虚</span>  
<span style="margin-left: 2em">其中黑豆巨者麋鬺之用糖瀹豆汁充炎月美供梅</span>  
<span style="margin-left: 2em">能已渴豆能消暑云银丝豆生旧出小蒸本以豆末</span>  
<span style="margin-left: 2em">糅面为之细如丝发顾志载茶食有蓼花地黄盒一</span>  
<span style="margin-left: 2em">捻酥等名线版糖石榴糖中虚外圆一名毬子二种</span>  
<span style="margin-left: 2em">并出洙泾又有雪糕梅生蹄出上海此皆随时感意</span>
