## 崇禎松江府志卷之六　物產

<span style="margin-left: 3em">物産</span>  
<span style="margin-left: 1em">吳都賦云國稅再熟之稻鄉貢八蠶之綿珠服玉饌自</span>  
<span style="margin-left: 1em">昔稱之然平疇與高山奥區羽毛夭喬率皆凡材也亦</span>  
<span style="margin-left: 1em">何足載名山經鏤形夏鼎且而鳴吠相聞芻牧相守鄰</span>  
<span style="margin-left: 1em">封所共豈一郡掌故得而私焉唯是品題獨著見於古</span>  
<span style="margin-left: 1em">今人之載記者即私以爲異可也</span>  
<span style="margin-left: 1em">物莫貴於五穀穀之品曰稻曰麥曰豆曰黍曰稷理生</span>  
<span style="margin-left: 1em">玉鏡曰稻之粒其白如霜其性宜水說文謂之稌沛國</span>  
<span style="margin-left: 1em">謂之穤以黏者謂之糯亦謂之秫以不黏者謂之秔亦</span>  
<span style="margin-left: 1em">謂之稉故氾勝之云三月而種秔四月而種秫然皆謂</span>  
<span style="margin-left: 1em">之稻稉之小者謂之秈嘗詢之老農其粒小而色白四</span>  
<span style="margin-left: 1em">月種六月熟曰六十日稻又遲者曰八十日稻又遲者</span>  
<span style="margin-left: 1em">曰百日赤而小稻之種亦有六十日秈百日秈曰拖犂</span>  
<span style="margin-left: 1em">歸白稃無芒或七月八月而熟俱謂之古城稻其性硬</span>  
<span style="margin-left: 1em">而皮莖俱白曰䆉稏<sub class="note-yuan">俗呼早野</sub>稻其粒大色白稈軟而有芒</span>  
<span style="margin-left: 1em">曰雪裏揀其粒白無芒而稈矮九月熟曰師姑秔亦曰</span>  
<span style="margin-left: 1em">矮白五月種九月熟而皮赤者早曰早烏晚曰晚烏又</span>  
<span style="margin-left: 1em">有蟬鳴稻半夏稻黃陸稻青稈稻白漠稻鵲不知下馬</span>  
<span style="margin-left: 1em">看<sub class="note-yuan">即三朝齊</sub>言其秀之易也其色白而性軟五月種十月熟</span>  
<span style="margin-left: 1em">曰羊脂糯其色班五月種十月熟曰虎皮糯其粒最長</span>  
<span style="margin-left: 1em">白浮而有芒四月種七月熟曰趕陳糯其粒大而色白</span>  
<span style="margin-left: 1em">四月種九月熟曰矮兒糯其桴黃而芒赤已熟而稈微</span>  
<span style="margin-left: 1em">青四月種九月熟曰青稈糯又有小娘糯蘆黃糯羊鬚</span>  
<span style="margin-left: 1em">糯鵞脂糯榧子糯白殻糯種類至繁吳之農不盡識也</span>  
<span style="margin-left: 1em">今姑存其略而吾松特著者曰箭子稻香稻紅蓮稻紫</span>  
<span style="margin-left: 1em">芒稻白花珠大小白麥争塲一丈紅早中秋再熟稻松</span>  
<span style="margin-left: 1em">江赤金釵糯冷粒糯</span>  
<span style="margin-left: 1em">箭子稻其粒細長而白味香而甘以九月熟稻品之最</span>  
<span style="margin-left: 2em">高者即晚白稻而更勝今海內共推江南晚米此種</span>  
<span style="margin-left: 2em">尤第一</span>  
<span style="margin-left: 2em"><sub class="note-yuan">魏文靖驥嘗新稻詩自序云憶昔在雲間時承唐橋張氏父子兄弟若竹泉林岫東軒輩遇熟必先寄以嘗觸物感懷賦此雲間咫尺若三秦別去于今六十春且喜又嘗新穀飯堪嗟不見昔年人功名富貴情懷淡棋局琴臺笑語新今日盡爲蓬島客停雲可不淚沾巾何良俊秋穫詩江南秔稻說吳淞生計吾應傍老農謾煑青精廻日馭細餐玉粒長秋容</sub></span>  
<span style="margin-left: 1em">香稻農圃四書云香秔其在松江者粒小而性柔有紅</span>  
<span style="margin-left: 2em">芒赤芒之等七月而熟以三五十粒入它米數升炊</span>  
<span style="margin-left: 2em">之芬芳馨美謂之香子又謂之香櫑魏文帝與朝臣</span>  
<span style="margin-left: 2em">書曰江表聞長沙有好米何得比吳中香稻耶上風</span>  
<span style="margin-left: 2em">炊之五里聞香</span>  
<span style="margin-left: 1em">紅蓮稻粒大芒赤五月種九月熟吳郡志云粒肥而香</span>  
<span style="margin-left: 2em">陸龜蒙懷歸詩有遥爲晚花吟白菊<sub class="note-jiao">校：菊白當倒乙文今正之</sub>近</span>  
<span style="margin-left: 2em">炊香稻識紅蓮蓋唐時已稱之農圃四書云其粒長</span>  
<span style="margin-left: 2em">而色班五月而種九月而熟松江謂之勝紅蓮</span>  
<span style="margin-left: 1em">大小白農圃四書云其粒赤而稃芒白五月初種八月</span>  
<span style="margin-left: 2em">而熟謂之早白稻松江謂之小白九月而熟謂之晚</span>  
<span style="margin-left: 2em">白又謂蘆花白松江謂之大白</span>  
<span style="margin-left: 1em">紫芒稻五月種九月熟紫穀白粒張方平詩云鱸膾飯</span>  
<span style="margin-left: 2em">紫芒古時人尊之常與鱸膾同薦</span>  
<span style="margin-left: 1em">白花珠性柔而不黏最宜作糜和潤香滑異於常種吾</span>  
<span style="margin-left: 2em">郡東土人植之四月種九月收以品高而收薄故農</span>  
<span style="margin-left: 2em">人不能廣種</span>  
<span style="margin-left: 1em">麥争塲以三月種六月熟謂與麥争塲也松江耕農稍</span>  
<span style="margin-left: 2em">有本力者必種少許以先療饑農遺雜疏曰此種早</span>  
<span style="margin-left: 2em">熟農人甚賴其利食新者争市之價貴也若荒年新</span>  
<span style="margin-left: 2em">稔則倍爾矣</span>  
<span style="margin-left: 1em">一丈紅徐玄扈云吾鄉墾荒者近得秈稻曰一丈紅五</span>  
<span style="margin-left: 2em">月種八月收絕能<sub class="note-yuan">古耐字</sub>水水深三四尺漫散種其中</span>  
<span style="margin-left: 2em">能從水底抽芽出水與常稻同熟但須厚壅耳松郡</span>  
<span style="margin-left: 2em">水鄉此種不患潦最宜植之又農圃四書云其再蒔</span>  
<span style="margin-left: 2em">而晚熟者謂之烏口稻在松江色黑而能<sub class="note-yuan">古耐字</sub>水與</span>  
<span style="margin-left: 2em">寒謂之冷水結是爲稻之下品</span>  
<span style="margin-left: 1em">蚤中秋農圃四書云其粒白而大四月種八月熟謂之</span>  
<span style="margin-left: 2em">中秋稻在松江八月望而熟者謂之蚤中秋又謂之</span>  
<span style="margin-left: 2em">閃西風</span>  
<span style="margin-left: 1em">再熟稻見吳都賦後無稱焉蔣堂登松江亭詩云嚮日</span>  
<span style="margin-left: 2em">早青牛引犢經秋田熟稻生孫注云是年有再熟之</span>  
<span style="margin-left: 2em">稻攷之當在皇祐間今田間豐歲已刈而稻根復蒸</span>  
<span style="margin-left: 2em">苗極易長旋復成實可掠取謂之再撩稻恐古所稱</span>  
<span style="margin-left: 2em">即此</span>  
<span style="margin-left: 2em">理生玉鏡曰其已刈而根復發苗再實者謂之再熟</span>  
<span style="margin-left: 2em">稻亦謂之再撩農遺雜疏云其陳根復生所謂稆也</span>  
<span style="margin-left: 2em">俗亦謂之二僚絕不秀實農人急懇之遲則損田力</span>  
<span style="margin-left: 1em">松江赤其粒尖色紅而性硬四月種七月熟即金城稻</span>  
<span style="margin-left: 2em">也是惟高仰之所種農圃四書云松江謂之赤米乃</span>  
<span style="margin-left: 2em">穀之下品今郡中亦少所用赤米皆糴之楚中雜疏</span>  
<span style="margin-left: 2em">云其性不畏鹵可當鹹潮近海口之田不得不種之</span>  
<span style="margin-left: 1em">金釵糯米粒長三月種七月熟最宜釀酒劉夢得詩云</span>  
<span style="margin-left: 2em">酒法得傳吳米好此也</span>  
<span style="margin-left: 2em">西溪叢語云宋王琪飲酒詩云蜀江雪浪來天際一</span>  
<span style="margin-left: 2em">派泉舂寶釵碎蓋謂水碓舂金釵糯也金釵乃糯米</span>  
<span style="margin-left: 2em">之名</span>  
<span style="margin-left: 1em">冷粒糯種宜長田其粒圓白而稃黃大暑可刈其色難</span>  
<span style="margin-left: 2em">變不宜於釀酒謂之秋風糯可以代粳而輸租又謂</span>  
<span style="margin-left: 2em">之瞞官糯農圃四書云松江謂之冷粒糯</span>  
<span style="margin-left: 2em">農遺雜疏曰有不道糯易種多收農人喜種之飯則</span>  
<span style="margin-left: 2em">糯釀則粳糶之則减價多以之代粳輸租自是佳種</span>  
<span style="margin-left: 2em">〇俗呼爲雌哥頭古謂之奸米</span>  
<span style="margin-left: 1em">麥種以北地爲良松郡所産大概有數種赤麥白麥又</span>  
<span style="margin-left: 1em">赤𥣬白𥣬麥紫稈麥火燒麥舜歌麥蕎麥雀麥即燕麥</span>  
<span style="margin-left: 1em">躲梅麥以躲梅先熟青鬚麥至熟猶青也而吾郡所尚</span>  
<span style="margin-left: 1em">惟大麥小麥又懸殻麥即大麥別種而勝之以作飯佳</span>  
<span style="margin-left: 1em">大麥曰麰小麥曰麳陶隱居曰大麥爲五穀長即今倮</span>  
<span style="margin-left: 2em">麥也似穬麥惟無皮耳吳農皆於秋成後播種三四</span>  
<span style="margin-left: 2em">月收刈土人呼爲春熟接絕續乏農人最重先輩董</span>  
<span style="margin-left: 2em">良史擊壤歌歌賢令也曰大麥䔿䔿秀小麥菶菶長</span>  
<span style="margin-left: 2em">菜花半稀青間黃今年縣官好民害不下鄉田家得</span>  
<span style="margin-left: 2em">安業出人無驚惶可知農尚矣</span>  
<span style="margin-left: 2em">南方麥花夜開晝掩受陰氣多北方麥花晝開夜掩</span>  
<span style="margin-left: 2em">受陽氣多故北麥宜人不特以種良也</span>  
<span style="margin-left: 1em">爾雅曰戎菽謂之荏菽孫炎注云戎菽大菽也廣雅曰</span>  
<span style="margin-left: 1em">大豆菽也小豆荅也張騫使外國得胡豆以歸傳布中</span>  
<span style="margin-left: 1em">國今世大豆有黃黑白及紫羅四種小豆有赤菉白三</span>  
<span style="margin-left: 1em">種鷰豆豍豆蠶豆稨豆俗名延籬大豆類也豌豆俗名</span>  
<span style="margin-left: 1em">小寒豇豆俗名裙帶小豆類也又刀豆龍爪豆皆以形</span>  
<span style="margin-left: 1em">名刀豆其葉可食龍爪花葉似裙帶莢似蠶豆茅紫赤</span>  
<span style="margin-left: 1em">以徧地叢生故名亦大豆類也</span>  
<span style="margin-left: 1em">蠶豆九月種以蠶時熟故名一曰寒豆陸龜蒙嗜之移</span>  
<span style="margin-left: 2em">植松江甫里令農人每於田塍夾種之收其實貿錢</span>  
<span style="margin-left: 2em">亦以爲飯</span>  
<span style="margin-left: 2em"><sub class="note-yuan">楊萬里詩云翠莢中排淺碧珠甘欺崖蜜軟欺酥沙瓶新熟西湖水漆櫑分嘗曉露腴味與櫻梅三益友名因蠢繭一絲絇老夫稼圃方雙學譜入詩中當稼書</sub></span>  
<span style="margin-left: 1em">豌豆一名小寒九月種三月熟宋已前松故未有相傳</span>  
<span style="margin-left: 2em">鄉先輩宦游于蜀得其種植之今遍吳越間而其種</span>  
<span style="margin-left: 2em">則始吾郡蜀中以此豆之不實者爲巢菜雜彘作籠</span>  
<span style="margin-left: 2em">餅啖之</span>  
<span style="margin-left: 2em">陸放翁過吳中得小巢作羹賦詩云春行露雨眩衡</span>  
<span style="margin-left: 2em">茅兒女隨空治酒殽便覺此身如在蜀一盤籠餅是</span>  
<span style="margin-left: 2em">豌巢</span>  
<span style="margin-left: 1em">黃豆水白豆二種俱堪作腐孫大雅避地華亭命鄰人</span>  
<span style="margin-left: 2em">作腐易其名曰菽乳<sub class="note-yuan">賦詩曰淮南信佳士思仙築高臺八老變童顔鴻寶枕中開異方營齊味數度真琦瑰傳羹傳世人令我憶蓬萊茹葷厭葱韭此物乃呈才戎菽來南山清漪浣浮埃轉身一旋磨流膏入盆罍大釜氣浮浮小眼湯洄洄頃待晴浪翻坐見雪花皚青鹽化液鹵絳蠟竄烟煤霍霍磨昆吾白玉大片裁烹煎適吾口不畏老齒摧蒸豚亦何爲人乳聖所哀萬錢同一飽斯言匪俳詼</sub></span>  
<span style="margin-left: 1em">黍穄凡有五色種類吾鄉止有黃穄植於高原其色如</span>  
<span style="margin-left: 1em">蠟梁秫粟也爾雅曰虋門赤苗芑白苗郭璞注云虋今</span>  
<span style="margin-left: 1em">之赤梁粟芑今之白梁粟莖葉如薏苡而高亦東南鄉</span>  
<span style="margin-left: 1em">高原種之秔者穗直而疏糯者穗疏而密然非所尚亦</span>  
<span style="margin-left: 1em">不廣</span>  
<span style="margin-left: 2em">徐宗伯玄扈告鄉里文<sub class="note-yuan">時年庚戌</sub>　近日水災低田</span>  
<span style="margin-left: 11em"><sub class="note-yuan">水災</sub></span>  
<span style="margin-left: 2em">渰没今水勢退去禾已壞爛凡我農人切勿任其抛</span>  
<span style="margin-left: 2em">荒若尋種下秧時又無及六十日烏可種收成亦少</span>  
<span style="margin-left: 2em">今有一法雖立秋後數日尚可種稻與常時一般成</span>  
<span style="margin-left: 2em">熟要從鄰近高田買其種成晚稻雖耘耨已畢但出</span>  
<span style="margin-left: 2em">重價自然肯賣每田二畝買他一畝間一科拔一科</span>  
<span style="margin-left: 2em">將此一畝稻分蒔低田五畝多下糞餅便與常時同</span>  
<span style="margin-left: 2em">熟其高田雖賣去一半用糞接力稻科長大亦一般</span>  
<span style="margin-left: 2em">收成若禾長難蒔須捩去稍葉存根一尺上下蒔之</span>  
<span style="margin-left: 2em">晚稻處暑後方做肚未做肚前儘好分種不妨成實</span>  
<span style="margin-left: 2em">也若已經插蒔今被渰没又無力買稻苗者亦要車</span>  
<span style="margin-left: 2em">去積水略令濕潤稻苗雖爛稻根在土尚能發生培</span>  
<span style="margin-left: 2em">養起來反多了稻苗一番肥壅儘能成熟前一法是</span>  
<span style="margin-left: 2em">江浙農人常用他們不惜幾石米買一畝禾至有一</span>  
<span style="margin-left: 2em">畝分作十畝蒔者後一法余常親驗之近年水利不</span>  
<span style="margin-left: 2em">修太湖無從洩瀉戊申之水到今未退所以一遇霖</span>
