## 崇祯松江府志卷之三十三　宦绩六（国朝名宦）

<span style="margin-left: 3em">国朝名臣宦绩<sub class="note-yuan">三</sub></span>  
<span style="margin-left: 1em">林润号念堂福建莆田人嘉靖丙辰进士除江西临川</span>  
<span style="margin-left: 1em">令擢南御史严嵩子世蕃置酒为别诸御史见之不敢</span>  
<span style="margin-left: 1em">吐一语润独高谈座上世蕃语其客曰顷见林御史谔</span>  
<span style="margin-left: 1em">谔吾以目慑之心且猜我复遣人语之曰严侍郎谢汝</span>  
<span style="margin-left: 1em">愿无刺论当世事润入南首弹祭酒沈坤次论鄢懋卿</span>  
<span style="margin-left: 1em">世蕃客罗龙文大逆状历官都御史开府江南江南大</span>  
<span style="margin-left: 1em">吏皆重足不寒而栗其所条上封事如请宽恤疲苦计</span>  
<span style="margin-left: 1em">民运清丈田袪积弊表节义恤耆哲裕虚征召贤辅诸</span>  
<span style="margin-left: 1em">论奏皆苏松切务朝廷方倚任之未几卒于官</span>  
<span style="margin-left: 1em">耿定向号楚侗更号天台湖广麻城人嘉靖丙辰进士</span>  
<span style="margin-left: 1em">少从阳明先生学以御史督学南畿课文之暇相与阐</span>  
<span style="margin-left: 1em">明洙泗伊洛之旨文章皆本原六经不取吊诡浮华前</span>  
<span style="margin-left: 1em">后六年所陶铸甚多士风丕振识者谓学使之任不以</span>  
<span style="margin-left: 1em">圣学陶士而第尚艺文非　祖宗设立师儒之义惟定</span>  
<span style="margin-left: 1em">向不愧云官至都御史谥庄简</span>  
<span style="margin-left: 1em">郜光先号文川山西长治人嘉靖己未进士宰上海听</span>  
<span style="margin-left: 1em">讼明简催科有法深沉不露而又有挥霍之才兑运武</span>  
<span style="margin-left: 1em">弁勒索最横一日率军卒数十人持挺露刃入县门光</span>  
<span style="margin-left: 1em">先待其至手执一弁叱之曰汝等将劫库耶遂命闭门</span>  
<span style="margin-left: 1em">勅舆隶尽缚其军卒牒申总漕武弁请罪数四始释之</span>  
<span style="margin-left: 1em">乃下令逐运船出浦外鱼贯而泊俟一船兑完方容一</span>  
<span style="margin-left: 1em">船进兑官军唯唯无敢哗不三日事竣辛酉大水光先</span>  
<span style="margin-left: 1em">劝邑缙绅顾从礼辈各捐米千斛计里设厂作粥赈济</span>  
<span style="margin-left: 1em">躬率居民王僖等以赈城市所全活甚众居官饭蔬未</span>  
<span style="margin-left: 1em">尝取之民间去之日行李萧然历官总督三边兵部尚</span>  
<span style="margin-left: 1em">书</span>  
<span style="margin-left: 1em">张伟字士美太原定襄人由顺天府判同知松江未一</span>  
<span style="margin-left: 1em">岁董饷都下卒徐文贞公表其墓曰松赋财所出而人</span>  
<span style="margin-left: 1em">又甚畏具上有司岁董饷将行长税者辄以羡余归之</span>  
<span style="margin-left: 1em">其辞曰赆比至都下将赂遗所知识长税者又辄以币</span>  
<span style="margin-left: 1em">帛资之其辞曰贽仍之既久遂名曰例虽费千百亲见</span>  
<span style="margin-left: 1em">其民鬻子女田宅以供弗恤也嘉靖乙酉郡倅湖南郑</span>  
<span style="margin-left: 1em">君始却去之丙戌张君继行君素贫却益坚日蔬食布</span>  
<span style="margin-left: 1em">衣怡然自适曰使我无饥寒足矣余非所愿也入见都</span>  
<span style="margin-left: 1em">下士大夫不持一物费用大省人亦贤伟既卒几无以</span>  
<span style="margin-left: 1em">为殓云</span>  
<span style="margin-left: 1em">陈邦颜号春台福建晋江人嘉靖壬戌进士知华亭适</span>  
<span style="margin-left: 1em">大水野无完土邦颜莅事过丙夜犹未寝或劝之少逸</span>  
<span style="margin-left: 1em">曰吾身逸矣其如吾民何细访健讼者扛幇者包揽者</span>  
<span style="margin-left: 1em">兑运棍徒之傍仓者廉其主名置之法吏民惊为神明</span>  
<span style="margin-left: 1em">父老以事至邑必降颜下色家咨户询凡闾阎之消长</span>  
<span style="margin-left: 1em">贤不肖虽事在肘腋间悉记之册故编审时上上下下</span>  
<span style="margin-left: 1em">役法称平清诡寄查积荒亦毫发不能遁也催科不遣</span>  
<span style="margin-left: 1em">吏第出片纸手署数字俾相传告赋长缓急如期至每</span>  
<span style="margin-left: 1em">旦按事六曹抱牍鱼贯而上剖析顷刻庭为一空性俭</span>  
<span style="margin-left: 1em">朴非礼之燕无益之费一切谢绝之及忧去赙吊餽遗</span>  
<span style="margin-left: 1em">无所受当邦颜诸生时吾乡次梁唐先生教授泉州识</span>  
<span style="margin-left: 1em">之俦伍中比至执弟子礼惟谨捐俸买先生葬地亦盛</span>  
<span style="margin-left: 1em">德事也</span>  
<span style="margin-left: 1em">黄文炜号景云江西南城人年甫二十举乡荐第一明</span>  
<span style="margin-left: 1em">年登嘉靖壬戌进士知上海县大意主于抚弱锄强有</span>  
<span style="margin-left: 1em">施铸睚眦杀人毒其弟里中畏之莫敢发文炜立捕置</span>  
<span style="margin-left: 1em">之辟沈友谅纳兄女为妾文炜怒重责锢狱中每月进</span>  
<span style="margin-left: 1em">诸生课试商搉古今即蔬食与之同饭是秋入彀额倍</span>  
<span style="margin-left: 1em">于往时置学田百余亩建忠良祠修济农仓饬废举坠</span>  
<span style="margin-left: 1em">县治肃然时与华亭陈公春台并有贤良之望文炜素</span>  
<span style="margin-left: 1em">孱弱未满三旬竟成疾不起死之日囊无余钱学使者</span>  
<span style="margin-left: 1em">采公议祀之名宦祠</span>  
<span style="margin-left: 1em">王叔杲字阳德号旸谷温州永嘉人徐文贞为学使者</span>  
<span style="margin-left: 1em">拔置诸生癸卯登乡书举嘉靖壬戌进士癸酉饬苏松</span>  
<span style="margin-left: 1em">四郡兵政叔杲故习倭情条列中窾乃简壮士部伍之</span>  
<span style="margin-left: 1em">教以阵法及骑射一军遂精又沿江自圌山至白茅福</span>  
<span style="margin-left: 1em">山相其险隘城障兵戍首尾相应造沙船佐以三翼轻</span>  
<span style="margin-left: 1em">舸制诸火器皆省费便用一日寇以百艘至叔杲发所</span>  
<span style="margin-left: 1em">练士分道搏战大破敌夺其舟悉遣闽越人之被胁者</span>  
<span style="margin-left: 1em">晋右参政仍留镇吴吴多逋赋时议带征逮系死者相</span>  
<span style="margin-left: 1em">藉会大司徒殷公正茂道吴叔杲驰白之曰江南岁输</span>  
<span style="margin-left: 1em">什取五六业不支而益之带征如沟壑我民何殷入言</span>  
<span style="margin-left: 1em">之当事蠲积逋数十万矣叔杲又采漕政著水利考值</span>  
<span style="margin-left: 1em">久旱粮艘胶京口叔杲令集田间水车𣂏湖水灌之三</span>  
<span style="margin-left: 1em">日漕遂通又开孟湖濬练河百余里无何论折征事起</span>  
<span style="margin-left: 1em">叔杲条六利四害语甚辩科臣石应岳谓叔杲不任漕</span>  
<span style="margin-left: 1em">借以自委劾叔杲得调当江陵柄国贤重叔杲叔杲不</span>  
<span style="margin-left: 1em">为纤趋申王两相公相继为政皆与叔杲同年莫逆而</span>  
<span style="margin-left: 1em">书问绝不一通也</span>  
<span style="margin-left: 1em">周采号三泉江西安福人嘉靖壬戌进士授嘉善县调</span>  
<span style="margin-left: 1em">华亭始到之日闷闷蚩蚩若无所知识告一状则准一</span>  
<span style="margin-left: 1em">状送一牌则佥一牌禀一事则行一事人人相顾窃笑</span>  
<span style="margin-left: 1em">直以为木彊人耳迟之三月后一日坐堂会天雨有老</span>  
<span style="margin-left: 1em">役人持伞穿油靴委蛇而过者采召问其姓名则诘以</span>  
<span style="margin-left: 1em">某日某日奉差拘某人何故一不结又从庭中唤某某</span>  
<span style="margin-left: 1em">某问其某事如何不完某差如何不缴一一杖而枷示</span>  
<span style="margin-left: 1em">之举三月内凡众所匿情骫法者拈出如照胆镜奸豪</span>  
<span style="margin-left: 1em">错愕以为神苞苴不入请托不行事权不下移利孔不</span>  
<span style="margin-left: 1em">旁出胥隶不下乡凡有讼即批原告勾摄不至则差里</span>  
<span style="margin-left: 1em">长又不至则将木皂隶投入其家判云此番如不来头</span>  
<span style="margin-left: 1em">上有乌鸦须臾决判而去暇则进逢掖与之谈经讲学</span>  
<span style="margin-left: 1em">词旨凛然不可干以私也莅任三载擢御史为佥事万</span>  
<span style="margin-left: 1em">历中历官淮抚少宰居家徒步惟葛巾布袍应门止一</span>  
<span style="margin-left: 1em">老苍头不识其为大僚也</span>  
<span style="margin-left: 1em">许拱字弘庄泉州南安人以贡授校华亭端轨正仪以</span>  
<span style="margin-left: 1em">临诸生不严而肃县大夫以才自雄欲𬺈龁之终不屈</span>  
<span style="margin-left: 1em">松守黄公润同泉产同幼学拱从诸寮旅见公庭外未</span>  
<span style="margin-left: 1em">尝一私谒衙斋即黄公召之弗往也仕宦虽不达而清</span>  
<span style="margin-left: 1em">望重于乡国有廉顽立懦之风所著易说学庸口义诸</span>  
<span style="margin-left: 1em">编藏于家</span>  
<span style="margin-left: 1em">衷贞吉号洪溪江西南昌人嘉靖己未进士本姓哀</span>  
<span style="margin-left: 1em">世宗御笔改哀为衷眉宇清森举动卓然有绳轨是非</span>  
<span style="margin-left: 1em">臧否井井于中而恒处之以悃诚隆庆改元来知府事</span>  
<span style="margin-left: 1em">时徐文贞罢政归里新郑修怨海蔡继之郡邑承风者</span>  
<span style="margin-left: 1em">所在骚然贞吉独挽颓波挺挺中立即上官有所指授</span>  
<span style="margin-left: 1em">不为动兴起斯文季试月课悉为之品题怜才爱士一</span>  
<span style="margin-left: 1em">时无两后为南大司马款留门下士不啻家人父子然</span>  
<span style="margin-left: 1em">官至御史大夫享寿八十而卒谥简肃</span>  
<span style="margin-left: 1em">聂廷璧号崇野金溪人嘉靖乙丑进士宰华亭凡兵役</span>  
<span style="margin-left: 1em">钱谷农桑水利之事辐辏旁午取办盼睐以敏干称时</span>  
<span style="margin-left: 1em">徐文贞方柄国出京与语曰毋纵吾家宗人毋纵吾家</span>  
<span style="margin-left: 1em">奴隶即儿子辈亦不达一言廷璧唯唯故有犯法者动</span>  
<span style="margin-left: 1em">以三尺惩之不假词色曰荣进有数吾岂能为绕指柔</span>  
<span style="margin-left: 1em">耶杨中丞朋石张夫人被杀家人执灯告变立命导往</span>  
<span style="margin-left: 1em">中丞家前后熟视访验毕令并孙辈晨具词以闻翌日</span>  
<span style="margin-left: 1em">再讯至第三日入见忽大呼拍案云眼前巳得罪人何</span>  
<span style="margin-left: 1em">须他捕并孙战栗不能已遂具讯牒下狱拟大辟咸以</span>  
<span style="margin-left: 1em">为神卒中忌者降开州倅已擢南吏部郎会新郑修隙</span>  
<span style="margin-left: 1em">于徐文贞廷璧诣海忠介侃侃为文贞表白人以是服</span>  
<span style="margin-left: 1em">其长者后官颖上备兵使引疾归优游林下三十年享</span>  
<span style="margin-left: 1em">寿八十有六董玄宰杨彦履主考江西先后访谒欢然</span>  
<span style="margin-left: 1em">道故无数味之设益叹服云</span>  
<span style="margin-left: 1em">张友舜号虞峰衡州人嘉靖丙寅岁以贡选训导华亭</span>  
<span style="margin-left: 1em">待诸生有恩礼凡执贽见者皆例辞或再三强之乃受</span>  
<span style="margin-left: 1em">退而廉知其家不甚饶立还之有乞其郡邑居间者辄</span>  
<span style="margin-left: 1em">不应当时郡邑长如衷公洪溪聂公崇野咸加敬礼屡</span>  
<span style="margin-left: 1em">经荐剡三年擢全州学正随升广西武宣知县象州旧</span>  
<span style="margin-left: 1em">有洞蛮出没道路劫杀人友舜疋马驰入蛮洞中谕以</span>  
<span style="margin-left: 1em">祸福声如洪钟意气又复慷慨诸蛮闻之惧相率倒戈</span>  
<span style="margin-left: 1em">出降吾松陆万锺奇其功具疏荐友舜征为南道御史</span>  
<span style="margin-left: 1em">受白金文绮之赐荫一子世袭百户华亭门下士至留</span>  
<span style="margin-left: 1em">都谒见欢然如故抵掌述单骑见虏状辄欷歔共浮大</span>  
<span style="margin-left: 1em">白亡何转佥宪亦三楚一人豪也</span>  
<span style="margin-left: 1em">胡执礼号雅斋陕西永昌人九岁以文字为当路所赏</span>  
<span style="margin-left: 1em">号奇童嘉靖己未成进士授保宁府推官历文选郎至</span>  
<span style="margin-left: 1em">右副都御史巡抚应天时年三十有六至则采访吴中</span>  
<span style="margin-left: 1em">乡缙绅之贤不肖咸籍而贮之胸中不轻发发即风驱</span>  
<span style="margin-left: 1em">电迅有所必行吴多逋税公曰此某某皆贫户耶出巡</span>  
<span style="margin-left: 1em">松郡责其田连阡陌家主名悬之榜以此任怨得严声</span>  
<span style="margin-left: 1em">然公之内行治布衾蔬食隐约如书生其接人不以位</span>  
<span style="margin-left: 1em">势低昂谦谦有礼事无巨细皆手经目阅抚吴三载忌</span>  
<span style="margin-left: 1em">者不得其毫芒过称一时名抚云</span>  
<span style="margin-left: 1em">李颐号及泉江西余干人隆庆戊辰进士由中书选御</span>  
<span style="margin-left: 1em">史万历庚辰备兵吴中前知湖州用赵广汉张子高法</span>  
<span style="margin-left: 1em">法豪公子无贷既至苏松一切以宽大镇静居之然吏</span>  
<span style="margin-left: 1em">民慑其先声皆惴惴不寒而栗江陵好操切峻下捕盗</span>  
<span style="margin-left: 1em">格于所部颐曰吾必不假他盗以自解得真盗乃已松</span>  
<span style="margin-left: 1em">数潦不登力言之台使者以蠲恤请其辞甚苦得报闻</span>  
<span style="margin-left: 1em">减赋发赈栗且至又谓民窘矣岂能待涸辙之水檄有</span>  
<span style="margin-left: 1em">司煮糜饲之岁以不害解道时行李三肩苍头二人送</span>  
<span style="margin-left: 1em">者服其清介</span>  
<span style="margin-left: 1em">郑岳号谦山长乐人隆庆戊辰进士为华亭令咲嚬必</span>
