## 崇禎松江府志卷之三十三　宦績六（國朝名宦）

<span style="margin-left: 3em">國朝名臣宦績<sub class="note-yuan">三</sub></span>  
<span style="margin-left: 1em">林潤號念堂福建莆田人嘉靖丙辰進士除江西臨川</span>  
<span style="margin-left: 1em">令擢南御史嚴嵩子世蕃置酒爲別諸御史見之不敢</span>  
<span style="margin-left: 1em">吐一語潤獨高談座上世蕃語其客曰頃見林御史諤</span>  
<span style="margin-left: 1em">諤吾以目懾之心且猜我復遣人語之曰嚴侍郎謝汝</span>  
<span style="margin-left: 1em">願無刺論當世事潤入南首彈祭酒沈坤次論鄢懋卿</span>  
<span style="margin-left: 1em">世蕃客羅龍文大逆狀歷官都御史開府江南江南大</span>  
<span style="margin-left: 1em">吏皆重足不寒而栗其所條上封事如請寬卹疲苦計</span>  
<span style="margin-left: 1em">民運清丈田袪積弊表節義卹耆哲裕虛徵召賢輔諸</span>  
<span style="margin-left: 1em">論奏皆蘇松切務朝廷方倚任之未幾卒于官</span>  
<span style="margin-left: 1em">耿定向號楚侗更號天臺湖廣麻城人嘉靖丙辰進士</span>  
<span style="margin-left: 1em">少從陽明先生學以御史督學南畿課文之暇相與闡</span>  
<span style="margin-left: 1em">明洙泗伊洛之旨文章皆本原六經不取吊詭浮華前</span>  
<span style="margin-left: 1em">後六年所陶鑄甚多士風丕振識者謂學使之任不以</span>  
<span style="margin-left: 1em">聖學陶士而第尚藝文非　祖宗設立師儒之義惟定</span>  
<span style="margin-left: 1em">向不愧云官至都御史謚莊簡</span>  
<span style="margin-left: 1em">郜光先號文川山西長治人嘉靖己未進士宰上海聽</span>  
<span style="margin-left: 1em">訟明簡催科有法深沉不露而又有揮霍之才兑運武</span>  
<span style="margin-left: 1em">弁勒索最横一日率軍卒數十人持挺露刃入縣門光</span>  
<span style="margin-left: 1em">先待其至手執一弁叱之曰汝等將劫庫耶遂命閉門</span>  
<span style="margin-left: 1em">勅輿隸盡縛其軍卒牒申總漕武弁請罪數四始釋之</span>  
<span style="margin-left: 1em">乃下令逐運船出浦外魚貫而泊俟一船兑完方容一</span>  
<span style="margin-left: 1em">船進兑官軍唯唯無敢譁不三日事竣辛酉大水光先</span>  
<span style="margin-left: 1em">勸邑縉紳顧從禮輩各捐米千斛計里設廠作粥賑濟</span>  
<span style="margin-left: 1em">躬率居民王僖等以賑城市所全活甚衆居官飯蔬未</span>  
<span style="margin-left: 1em">嘗取之民間去之日行李蕭然歷官總督三邊兵部尚</span>  
<span style="margin-left: 1em">書</span>  
<span style="margin-left: 1em">張偉字士美太原定襄人由順天府判同知松江未一</span>  
<span style="margin-left: 1em">歲董餉都下卒徐文貞公表其墓曰松賦財所出而人</span>  
<span style="margin-left: 1em">又甚畏具上有司歲董餉將行長稅者輒以羡餘歸之</span>  
<span style="margin-left: 1em">其辭曰贐比至都下將賂遺所知識長稅者又輒以幣</span>  
<span style="margin-left: 1em">帛資之其辭曰贄仍之既久遂名曰例雖費千百親見</span>  
<span style="margin-left: 1em">其民鬻子女田宅以供弗恤也嘉靖乙酉郡倅湖南鄭</span>  
<span style="margin-left: 1em">君始却去之丙戌張君繼行君素貧却益堅日蔬食布</span>  
<span style="margin-left: 1em">衣怡然自適曰使我無饑寒足矣餘非所願也入見都</span>  
<span style="margin-left: 1em">下士大夫不持一物費用大省人亦賢偉既卒幾無以</span>  
<span style="margin-left: 1em">爲殮云</span>  
<span style="margin-left: 1em">陳邦顔號春臺福建晋江人嘉靖壬戌進士知華亭適</span>  
<span style="margin-left: 1em">大水野無完土邦顔蒞事過丙夜猶未寢或勸之少逸</span>  
<span style="margin-left: 1em">曰吾身逸矣其如吾民何細訪健訟者扛幇者包攬者</span>  
<span style="margin-left: 1em">兑運棍徒之傍倉者廉其主名置之法吏民驚爲神明</span>  
<span style="margin-left: 1em">父老以事至邑必降顔下色家咨户詢凡閭閻之消長</span>  
<span style="margin-left: 1em">賢不肖雖事在肘腋間悉記之册故編審時上上下下</span>  
<span style="margin-left: 1em">役法稱平清詭寄查積荒亦毫髮不能遁也催科不遣</span>  
<span style="margin-left: 1em">吏第出片紙手署數字俾相傳告賦長緩急如期至每</span>  
<span style="margin-left: 1em">旦按事六曹抱牘魚貫而上剖析頃刻庭爲一空性儉</span>  
<span style="margin-left: 1em">朴非禮之燕無益之費一切謝絕之及憂去賻弔餽遺</span>  
<span style="margin-left: 1em">無所受當邦顔諸生時吾鄉次梁唐先生教授泉州識</span>  
<span style="margin-left: 1em">之儔伍中比至執弟子禮惟謹捐俸買先生葬地亦盛</span>  
<span style="margin-left: 1em">德事也</span>  
<span style="margin-left: 1em">黃文煒號景雲江西南城人年甫二十舉鄉薦第一明</span>  
<span style="margin-left: 1em">年登嘉靖壬戌進士知上海縣大意主于撫弱鋤强有</span>  
<span style="margin-left: 1em">施鑄睚眦殺人毒其弟里中畏之莫敢發文煒立捕置</span>  
<span style="margin-left: 1em">之辟沈友諒納兄女爲妾文煒怒重責錮獄中每月進</span>  
<span style="margin-left: 1em">諸生課試商搉古今即蔬食與之同飯是秋入彀額倍</span>  
<span style="margin-left: 1em">于往時置學田百餘畝建忠良祠修濟農倉飭廢舉墜</span>  
<span style="margin-left: 1em">縣治肅然時與華亭陳公春臺並有賢良之望文煒素</span>  
<span style="margin-left: 1em">孱弱未滿三旬竟成疾不起死之日囊無餘錢學使者</span>  
<span style="margin-left: 1em">採公議祀之名宦祠</span>  
<span style="margin-left: 1em">王叔杲字陽德號暘谷温州永嘉人徐文貞爲學使者</span>  
<span style="margin-left: 1em">拔置諸生癸卯登鄉書舉嘉靖壬戌進士癸酉飭蘇松</span>  
<span style="margin-left: 1em">四郡兵政叔杲故習倭情條列中窾乃簡壯士部伍之</span>  
<span style="margin-left: 1em">教以陣法及騎射一軍遂精又沿江自圌山至白茅福</span>  
<span style="margin-left: 1em">山相其險隘城障兵戍首尾相應造沙船佐以三翼輕</span>  
<span style="margin-left: 1em">舸制諸火器皆省費便用一日寇以百艘至叔杲發所</span>  
<span style="margin-left: 1em">練士分道搏戰大破敵奪其舟悉遣閩越人之被脅者</span>  
<span style="margin-left: 1em">晋右參政仍留鎮吳吳多逋賦時議帶徵逮繫死者相</span>  
<span style="margin-left: 1em">藉會大司徒殷公正茂道吳叔杲馳白之曰江南歲輸</span>  
<span style="margin-left: 1em">什取五六業不支而益之帶徵如溝壑我民何殷入言</span>  
<span style="margin-left: 1em">之當事蠲積逋數十萬矣叔杲又采漕政著水利考值</span>  
<span style="margin-left: 1em">久旱糧艘膠京口叔杲令集田間水車𣂏湖水灌之三</span>  
<span style="margin-left: 1em">日漕遂通又開孟湖濬練河百餘里無何論折徵事起</span>  
<span style="margin-left: 1em">叔杲條六利四害語甚辯科臣石應嶽謂叔杲不任漕</span>  
<span style="margin-left: 1em">借以自委劾叔杲得調當江陵柄國賢重叔杲叔杲不</span>  
<span style="margin-left: 1em">爲纖趨申王兩相公相繼爲政皆與叔杲同年莫逆而</span>  
<span style="margin-left: 1em">書問絕不一通也</span>  
<span style="margin-left: 1em">周寀號三泉江西安福人嘉靖壬戌進士授嘉善縣調</span>  
<span style="margin-left: 1em">華亭始到之日悶悶蚩蚩若無所知識告一狀則准一</span>  
<span style="margin-left: 1em">狀送一牌則僉一牌禀一事則行一事人人相顧竊笑</span>  
<span style="margin-left: 1em">直以爲木彊人耳遲之三月後一日坐堂會天雨有老</span>  
<span style="margin-left: 1em">役人持傘穿油靴委蛇而過者寀召問其姓名則詰以</span>  
<span style="margin-left: 1em">某日某日奉差拘某人何故一不結又從庭中唤某某</span>  
<span style="margin-left: 1em">某問其某事如何不完某差如何不繳一一杖而枷示</span>  
<span style="margin-left: 1em">之舉三月內凡衆所匿情骫法者拈出如照膽鏡奸豪</span>  
<span style="margin-left: 1em">錯愕以爲神苞苴不入請託不行事權不下移利孔不</span>  
<span style="margin-left: 1em">旁出胥隸不下鄉凡有訟即批原告勾攝不至則差里</span>  
<span style="margin-left: 1em">長又不至則將木皂隸投入其家判云此番如不來頭</span>  
<span style="margin-left: 1em">上有烏鴉須臾決判而去暇則進逢掖與之談經講學</span>  
<span style="margin-left: 1em">詞旨凛然不可干以私也蒞任三載擢御史爲僉事萬</span>  
<span style="margin-left: 1em">曆中歷官淮撫少宰居家徒步惟葛巾布袍應門止一</span>  
<span style="margin-left: 1em">老蒼頭不識其爲大僚也</span>  
<span style="margin-left: 1em">許拱字弘莊泉州南安人以貢授校華亭端軌正儀以</span>  
<span style="margin-left: 1em">臨諸生不嚴而肅縣大夫以才自雄欲齮齕之終不屈</span>  
<span style="margin-left: 1em">松守黃公潤同泉産同幼學拱從諸寮旅見公庭外未</span>  
<span style="margin-left: 1em">嘗一私謁衙齋即黃公召之弗往也仕宦雖不達而清</span>  
<span style="margin-left: 1em">望重於鄉國有廉頑立懦之風所著易說學庸口義諸</span>  
<span style="margin-left: 1em">編藏於家</span>  
<span style="margin-left: 1em">衷貞吉號洪溪江西南昌人嘉靖己未進士本姓哀</span>  
<span style="margin-left: 1em">世宗御筆改哀爲衷眉宇清森舉動卓然有繩軌是非</span>  
<span style="margin-left: 1em">臧否井井于中而恒處之以悃誠隆慶改元來知府事</span>  
<span style="margin-left: 1em">時徐文貞罷政歸里新鄭修怨海蔡繼之郡邑承風者</span>  
<span style="margin-left: 1em">所在騷然貞吉獨挽頽波挺挺中立即上官有所指授</span>  
<span style="margin-left: 1em">不爲動興起斯文季試月課悉爲之品題憐才愛士一</span>  
<span style="margin-left: 1em">時無兩後爲南大司馬款留門下士不啻家人父子然</span>  
<span style="margin-left: 1em">官至御史大夫享壽八十而卒謚簡肅</span>  
<span style="margin-left: 1em">聶廷璧號崇野金谿人嘉靖乙丑進士宰華亭凡兵役</span>  
<span style="margin-left: 1em">錢穀農桑水利之事輻輳旁午取辦盼睞以敏幹稱時</span>  
<span style="margin-left: 1em">徐文貞方柄國出京與語曰毋縱吾家宗人毋縱吾家</span>  
<span style="margin-left: 1em">奴隸即兒子輩亦不達一言廷璧唯唯故有犯法者動</span>  
<span style="margin-left: 1em">以三尺懲之不假詞色曰榮進有數吾豈能爲繞指柔</span>  
<span style="margin-left: 1em">耶楊中丞朋石張夫人被殺家人執燈告變立命導往</span>  
<span style="margin-left: 1em">中丞家前後熟視訪驗畢令并孫輩晨具詞以聞翌日</span>  
<span style="margin-left: 1em">再訊至第三日入見忽大呼拍案云眼前巳得罪人何</span>  
<span style="margin-left: 1em">須他捕并孫戰慄不能已遂具訊牒下獄擬大辟咸以</span>  
<span style="margin-left: 1em">爲神卒中忌者降開州倅已擢南吏部郎會新鄭修隙</span>  
<span style="margin-left: 1em">於徐文貞廷璧詣海忠介侃侃爲文貞表白人以是服</span>  
<span style="margin-left: 1em">其長者後官穎上備兵使引疾歸優游林下三十年享</span>  
<span style="margin-left: 1em">壽八十有六董玄宰楊彦履主考江西先後訪謁歡然</span>  
<span style="margin-left: 1em">道故無數味之設益歎服云</span>  
<span style="margin-left: 1em">張友舜號虞峯衡州人嘉靖丙寅歲以貢選訓導華亭</span>  
<span style="margin-left: 1em">待諸生有恩禮凡執贄見者皆例辭或再三强之乃受</span>  
<span style="margin-left: 1em">退而廉知其家不甚饒立還之有乞其郡邑居間者輒</span>  
<span style="margin-left: 1em">不應當時郡邑長如衷公洪溪聶公崇野咸加敬禮屢</span>  
<span style="margin-left: 1em">經薦剡三年擢全州學正隨陞廣西武宣知縣象州舊</span>  
<span style="margin-left: 1em">有洞蠻出没道路劫殺人友舜疋馬馳入蠻洞中諭以</span>  
<span style="margin-left: 1em">禍福聲如洪鐘意氣又復慷慨諸蠻聞之懼相率倒戈</span>  
<span style="margin-left: 1em">出降吾松陸萬鍾奇其功具疏薦友舜徵爲南道御史</span>  
<span style="margin-left: 1em">受白金文綺之賜蔭一子世襲百户華亭門下士至留</span>  
<span style="margin-left: 1em">都謁見歡然如故抵掌述單騎見虜狀輒欷歔共浮大</span>  
<span style="margin-left: 1em">白亡何轉僉憲亦三楚一人豪也</span>  
<span style="margin-left: 1em">胡執禮號雅齋陝西永昌人九歲以文字爲當路所賞</span>  
<span style="margin-left: 1em">號奇童嘉靖己未成進士授保寧府推官歷文選郎至</span>  
<span style="margin-left: 1em">右副都御史巡撫應天時年三十有六至則採訪吳中</span>  
<span style="margin-left: 1em">鄉縉紳之賢不肖咸籍而貯之胸中不輕發發即風驅</span>  
<span style="margin-left: 1em">電迅有所必行吳多逋稅公曰此某某皆貧户耶出巡</span>  
<span style="margin-left: 1em">松郡責其田連阡陌家主名懸之榜以此任怨得嚴聲</span>  
<span style="margin-left: 1em">然公之內行治布衾蔬食隱約如書生其接人不以位</span>  
<span style="margin-left: 1em">勢低昂謙謙有禮事無鉅細皆手經目閲撫吳三載忌</span>  
<span style="margin-left: 1em">者不得其毫芒過稱一時名撫云</span>  
<span style="margin-left: 1em">李頤號及泉江西餘干人隆慶戊辰進士由中書選御</span>  
<span style="margin-left: 1em">史萬曆庚辰備兵吳中前知湖州用趙廣漢張子高法</span>  
<span style="margin-left: 1em">法豪公子無貸既至蘇松一切以寬大鎮靜居之然吏</span>  
<span style="margin-left: 1em">民懾其先聲皆惴惴不寒而慄江陵好操切峻下捕盗</span>  
<span style="margin-left: 1em">格于所部頤曰吾必不假他盗以自解得真盗乃已松</span>
