## 崇祯松江府志卷之二十七　宋令题名下

<span style="margin-left: 3em">守令题名</span>  
<span style="margin-left: 1em">上海县令题名记　上海县令题名者题令上海县者</span>  
<span style="margin-left: 2em">之名也石之者示不朽也创之者嗣令上海浮梁曹</span>  
<span style="margin-left: 2em">侯孟辉也由曹侯而上令凡四十有一人其在元者</span>  
<span style="margin-left: 2em">十有二县元始也元令始于周侯汝楫也由周侯而</span>  
<span style="margin-left: 2em">下列其姓氏以官历次第之使可考见复虚其左以</span>  
<span style="margin-left: 2em">俟后之令兹县者题焉是役也循名以求其实弗替</span>  
<span style="margin-left: 2em">乎旧而引之今侯可谓知体矣县人陆深记之曰令</span>  
<span style="margin-left: 2em">于县无所不统令犹令也所以使令一县之人以知</span>  
<span style="margin-left: 2em">公上尊亲之义而和以富寿安逸之福悬以刑赏礼</span>  
<span style="margin-left: 2em">律之文发而出之故曰令盖言令之而必行也令于</span>  
<span style="margin-left: 2em">民亲诲谕训诫不越乎堂皇之间里阈向方可以徧</span>  
<span style="margin-left: 2em">于时日之内故令之民也便亲则有感便则有功此</span>  
<span style="margin-left: 2em">治之基也基于县而天下运矣基于令而六官举矣</span>  
<span style="margin-left: 2em">是故令于民也身教之手泽之民之视令也公则官</span>  
<span style="margin-left: 2em">之私则父母之遇则戴之去则思之殁则神明之尸</span>  
<span style="margin-left: 2em">祝之此县令题名之所以不容已也或曰凡是四十</span>  
<span style="margin-left: 2em">一令者有善乎曰有之亦有不善者乎曰亦有之曰</span>  
<span style="margin-left: 2em">善不善亦奚取于兹石哉曰民思其善以忘其不善</span>  
<span style="margin-left: 2em">令监其不善以底于善此关雎麟趾之意而周官之</span>  
<span style="margin-left: 2em">法度也又曰我皇明之治体也侯名煜丙戌进士有</span>  
<span style="margin-left: 2em">惠政为县之三年当嘉靖之十年是月某日立石陆</span>
