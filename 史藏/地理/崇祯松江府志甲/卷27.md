## 崇禎松江府志卷之二十七　宋令題名下

<span style="margin-left: 3em">守令題名</span>  
<span style="margin-left: 1em">上海縣令題名記　上海縣令題名者題令上海縣者</span>  
<span style="margin-left: 2em">之名也石之者示不朽也創之者嗣令上海浮梁曹</span>  
<span style="margin-left: 2em">侯孟輝也由曹侯而上令凡四十有一人其在元者</span>  
<span style="margin-left: 2em">十有二縣元始也元令始于周侯汝楫也由周侯而</span>  
<span style="margin-left: 2em">下列其姓氏以官曆次第之使可考見復虛其左以</span>  
<span style="margin-left: 2em">俟後之令兹縣者題焉是役也循名以求其實弗替</span>  
<span style="margin-left: 2em">乎舊而引之今侯可謂知体矣縣人陸深記之曰令</span>  
<span style="margin-left: 2em">于縣無所不統令猶令也所以使令一縣之人以知</span>  
<span style="margin-left: 2em">公上尊親之義而和以富壽安逸之福懸以刑賞禮</span>  
<span style="margin-left: 2em">律之文發而出之故曰令蓋言令之而必行也令于</span>  
<span style="margin-left: 2em">民親誨諭訓誡不越乎堂皇之間里閾向方可以徧</span>  
<span style="margin-left: 2em">于時日之內故令之民也便親則有感便則有功此</span>  
<span style="margin-left: 2em">治之基也基于縣而天下運矣基于令而六官舉矣</span>  
<span style="margin-left: 2em">是故令于民也身教之手澤之民之視令也公則官</span>  
<span style="margin-left: 2em">之私則父母之遇則戴之去則思之殁則神明之尸</span>  
<span style="margin-left: 2em">祝之此縣令題名之所以不容已也或曰凡是四十</span>  
<span style="margin-left: 2em">一令者有善乎曰有之亦有不善者乎曰亦有之曰</span>  
<span style="margin-left: 2em">善不善亦奚取于兹石哉曰民思其善以忘其不善</span>  
<span style="margin-left: 2em">令監其不善以底于善此關雎麟趾之意而周官之</span>  
<span style="margin-left: 2em">法度也又曰我皇明之治体也侯名煜丙戌進士有</span>  
<span style="margin-left: 2em">惠政爲縣之三年當嘉靖之十年是月某日立石陸</span>

<span style="margin-left: 2em">松教見學官姓名冺冺猶蘇且感胡師善以身翼學</span>  
<span style="margin-left: 2em">魏仲房以德鼓人孫宜鉉以正化俗乃嘆曰三君子</span>  
<span style="margin-left: 2em">可不與安定公並馳驅乎哉安定之名卓犖今古蘇</span>  
<span style="margin-left: 2em">學借重三君子獨松人知之稱之郡乘所傳有限量</span>  
<span style="margin-left: 2em">者居三君子之後寧無惻然赩然而曰責在我乎矧</span>  
<span style="margin-left: 2em">蘇松爲東南名郡勢相雄長士奮于學者樹德立功</span>  
<span style="margin-left: 2em">與奮于蘇學者可並馳驅端準正標有師之名可冺</span>  
<span style="margin-left: 2em">冺無傳而獨于一石之惜乎哉謀諸同寅輩礱石以</span>  
<span style="margin-left: 2em">紀庶乎覩師善以勵節覩仲房以勵志覩宜鉉以勵</span>  
<span style="margin-left: 2em">風作起人文報昭代之萬一使夫人不敢以嘆老嗟</span>  
<span style="margin-left: 2em">卑爲吾人之羞嗚乎三君子與安定公可並馳驅其</span>  
<span style="margin-left: 2em">在兹石矣乎吾人不愧乎三子之後其在兹石矣乎</span>
