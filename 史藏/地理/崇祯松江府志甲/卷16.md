## 崇禎松江府志卷之十六　水利上

<span style="margin-left: 3em">水利上<sub class="note-jiao">校：此處似脫上字今補</sub></span>  
<span style="margin-left: 1em">萬曆戊子大水</span>  
<span style="margin-left: 1em">上特命憲副許公來江南陸文定公語之曰治水者大</span>  
<span style="margin-left: 1em">約以神禹爲法以孔孟爲衡濬江導海孟子之水利也</span>  
<span style="margin-left: 1em">盡力溝洫孔子之水利也許公用違其言幾耗數萬金</span>  
<span style="margin-left: 1em">錢而訖無底績夏周諸公惓惓以修圩爲第一義其溝</span>  
<span style="margin-left: 1em">洫之遺意乎故先列　勅諭次列治策治績而乃以治</span>  
<span style="margin-left: 1em">田終焉</span>  
<span style="margin-left: 1em">國朝勅諭</span>  
<span style="margin-left: 1em">永樂三年　勅諭户部尚書夏原吉都察院僉都御史</span>  
<span style="margin-left: 1em">俞士吉通政司左通政趙居任大理寺少卿袁復四郡</span>  
<span style="margin-left: 1em">之民頻年厄於水患今舊穀已罄新苗未成老稚嗷嗷</span>  
<span style="margin-left: 1em">饑餒無告朕與卿等能獨飽乎其往督郡縣丞發倉廪</span>  
<span style="margin-left: 1em">賑之所至善加撫綏一切民間利害有當建革者速具</span>  
<span style="margin-left: 1em">以聞卿等宜體朕憂民之心欽哉無忽</span>  
<span style="margin-left: 1em">宣德五年　勅諭工部右侍郎周忱今命爾往南京應</span>  
<span style="margin-left: 1em">天蘇州松江常州鎮江太平寧國池州徽州安慶廣德</span>  
<span style="margin-left: 1em">州巡撫遞年一應稅糧務在從長設法區畫得宜使人</span>  
<span style="margin-left: 1em">不勞困輸不後期尤在敷宣德意撫恤人民扶植良善</span>  
<span style="margin-left: 1em">其水田圩岸爾亦相度時宜整理俾無旱潦之患庶副</span>  
<span style="margin-left: 1em">朕委任之重欽哉故諭</span>  
<span style="margin-left: 1em">正統九年　勅諭工部右侍郎周忱近聞浙江嘉湖等</span>  
<span style="margin-left: 1em">府直隸蘇松等府地方今秋多雨潦水暴溢渰没田稼</span>  
<span style="margin-left: 1em">漂蕩民居溺死人畜蓋因各處遞年將舊通江海河港</span>  
<span style="margin-left: 1em">乘乾旱之時築塞爲田耕種及因遞年沙漲以致水不</span>  
<span style="margin-left: 1em">流通人受其患今特命爾會同巡按御史嚴督各該府</span>  
<span style="margin-left: 1em">縣拘集耆民里老人等詢訪踏勘各處原通江海河港</span>  
<span style="margin-left: 1em">故道果被豪强之人築塞爲田即令退還并年深淤塞</span>  
<span style="margin-left: 1em">之處爾等公同計議督令府縣官起倩人夫開挑務要</span>  
<span style="margin-left: 1em">水道通行不至爲患其餘湖池陂塘圩岸可以蓄洩水</span>  
<span style="margin-left: 1em">利防備旱潦者悉從其修築開通其間果有豪强之徒</span>  
<span style="margin-left: 1em">占據把持以爲己利者爾即拿問輕則量情懲治情重</span>  
<span style="margin-left: 1em">者具奏區處用工之際尤須相度地勢酌量民力其殷</span>  
<span style="margin-left: 1em">富田多之家務令儘力用工貧難下户及田少糧重者</span>  
<span style="margin-left: 1em">酌量差遣不可誤其生理如工程浩大人力艱難非旬</span>  
<span style="margin-left: 1em">月可成者爾宜審度用工宜令受利近便去處同心同</span>  
<span style="margin-left: 1em">力切不可妨廢農時朕惟豪强專利小民受害論法難</span>  
<span style="margin-left: 1em">容今姑宥其罪使之自新保其身家爾爲朝廷重臣宜</span>  
<span style="margin-left: 1em">表率同事公以存心廉以律身勤以從事必誠必信用</span>  
<span style="margin-left: 1em">圖久遠毋虛勞民力毋苟具文移以塞責毋狃於小利</span>  
<span style="margin-left: 1em">以爲功爾克盡職民受實惠朕惟爾嘉朝廷以安養斯</span>  
<span style="margin-left: 1em">民爲念宜深體朕心爲民造福以副任使或有窒礙難</span>  
<span style="margin-left: 1em">行之事亦須體諒人情從長計議奏來不許違誤故諭</span>  
<span style="margin-left: 1em">弘治七年　勅諭工部侍郎徐貫兼都御史往同巡撫</span>  
<span style="margin-left: 1em">都御史何鑑朕惟直隸蘇松常杭嘉湖六府數年以來</span>  
<span style="margin-left: 1em">屢被水災園田渰没廬舍漂溺民既無聊生財賦又何</span>  
<span style="margin-left: 1em">自而出今特命爾會同彼處巡撫御史親詣其地逐一</span>  
<span style="margin-left: 1em">踏勘如果前日之水道形跡具存今日之水患實由於</span>  
<span style="margin-left: 1em">此即於所在司府州縣量取丁夫錢糧督同委官人等</span>  
<span style="margin-left: 1em">以次興工修築疏濬凡勅內該載不盡事宜聽爾便宜</span>  
<span style="margin-left: 1em">處置文武職官軍民人等有負才識諳曉水利者悉聽</span>  
<span style="margin-left: 1em">委用職官敢有違慢乖方狥私廢事者五品以下徑自</span>  
<span style="margin-left: 1em">提問應奏請者參奏施行其興工之際務審水道利害</span>  
<span style="margin-left: 1em">人情從違固不可畏難退避失經國之良圖亦不得鑿</span>  
<span style="margin-left: 1em">空妄爲致小民之嗟怨殫心畢慮利國便民斯不負朝</span>  
<span style="margin-left: 1em">廷委任之意</span>  
<span style="margin-left: 1em">弘治八年　勅諭工部都水司主事姚文灝直隸蘇松</span>  
<span style="margin-left: 1em">常鎮及浙江杭嘉湖七府并蘇州鎮江等衛所地方廣</span>  
<span style="margin-left: 1em">闊銀糧浩大每歲收成全資水利積年以來河港溝渠</span>  
<span style="margin-left: 1em">湖塘等項盡皆壅塞或被豪强之人占爲己業旱無所</span>  
<span style="margin-left: 1em">溉雨無所洩以致田穀不登軍民缺食近差工部侍郎</span>  
<span style="margin-left: 1em">徐貫往會巡撫等官通行疏濬已奏工完但恐歲月寖</span>  
<span style="margin-left: 1em">久港瀆漸致堙塞水利不能興舉圩岸愈見坍塌財賦</span>  
<span style="margin-left: 1em">無從出辦兹特陞爾前職命爾專一往來前項府衛地</span>  
<span style="margin-left: 1em">方提督各該管官員修理湖塘疏通河港開濬溝渠及</span>  
<span style="margin-left: 1em">一應圩岸未經修築者及時修築各處閘壩未盡修理</span>  
<span style="margin-left: 1em">者隨宜修理合用木石等料於各該田有力之家從公</span>  
<span style="margin-left: 1em">勸諭或別爲措置人夫於所在附近軍衛有司相度起</span>  
<span style="margin-left: 1em">工仍須督役以時調度有法使蓄洩有備旱澇無虞毋</span>  
<span style="margin-left: 1em">事虛文務臻實效以爲地方經久之計爾其勉之慎之</span>  
<span style="margin-left: 1em">故勅</span>  
<span style="margin-left: 1em">嘉靖□年<sub class="note-jiao">校：該字原書作墨丁當撰時已闕以下倣此不再重複</sub>勅諭巡撫都御</span>  
<span style="margin-left: 1em">史歐陽必進朕惟國家財賦取給東南近該前巡撫都</span>  
<span style="margin-left: 1em">御史丁汝夔及巡按呂光洵各題稱蘇松常鎮四府地</span>  
<span style="margin-left: 1em">方連年水旱頻仍皆由水利湮廢以致民困賦逋貽患</span>  
<span style="margin-left: 1em">非細乞要查舊例通行修濬事下該部轉行彼處查勘</span>  
<span style="margin-left: 1em">得太倉州常熟崑山等縣七浦白茆新涇等河港鹽鐵</span>  
<span style="margin-left: 1em">許浦等塘堰修濬有官民併力合修者其所費財用有</span>  
<span style="margin-left: 1em">原派導河夫及存留各項銀米并撫按司府州縣贓罰</span>  
<span style="margin-left: 1em">與夫應解錢糧堪以那借者俱令支用已經該部議奏</span>  
<span style="margin-left: 1em">前來相應依擬爾見有地方巡撫之責特命專理其事</span>  
<span style="margin-left: 1em">爾宜查照節題事理及巡按委官勘處緣由將四府支</span>  
<span style="margin-left: 1em">河動支前項銀米查議原奏官民合修分修地方坐委</span>  
<span style="margin-left: 1em">能幹官員責令及時修理庶幾事克有濟爾仍照先年</span>  
<span style="margin-left: 1em">撫臣李充嗣事例不時躬往督視務使緩急有備旱澇</span>  
<span style="margin-left: 1em">無虞期於一勞而永逸各該承委官員除巡按御史每</span>  
<span style="margin-left: 1em">年閲視工程分別勤惰舉劾外如有違慢悮事者五品</span>  
<span style="margin-left: 1em">以下爾即徑自拿問應奏請者奏聞施行事完之日通</span>  
<span style="margin-left: 1em">將修濬過緣由畫圖貼說并用過錢糧數目造册奏繳</span>  
<span style="margin-left: 1em">及將勤幹賢能官員通行論奏以憑旌擢</span>  
<span style="margin-left: 1em">隆慶陸年七月二十八日　詔書內一款大江南北財</span>  
<span style="margin-left: 1em">賦所出全資水利各處設有水利僉事各府州縣設有</span>  
<span style="margin-left: 1em">水利通判縣丞等官近來往往視爲末務上下因循一</span>  
<span style="margin-left: 1em">遇水荒即奏乞蠲免撫按督令專管水利司判官往來</span>  
<span style="margin-left: 1em">巡歷着落有司官將該管地方水利着實講求議處何</span>  
<span style="margin-left: 1em">處當疏通其源何處當挑濬其流壩堰圩岸在在增修</span>  
<span style="margin-left: 1em">使蓄洩有備旱潦無傷合用夫役取諸得利之家毋令</span>  
<span style="margin-left: 1em">騷擾若功程浩大撫按官查其先年導河夫役用剩貯</span>  
<span style="margin-left: 1em">庫及該府州縣近地魚課奏留修理隄壩等銀兩酌量</span>  
<span style="margin-left: 1em">動支有司官有仍前曠職誤事及地方土豪之家阻撓</span>  
<span style="margin-left: 1em">壅塞專利病民者撫按官參拿處治</span>  
<span style="margin-left: 1em">萬曆四年　勅諭監察御史林應訓近因言官建議蘇</span>  
<span style="margin-left: 1em">松常鎮等處水利久湮要差御史一員專管該部議覆</span>  
<span style="margin-left: 1em">相應今特命爾督理前項地方水利務要時常往來巡</span>  
<span style="margin-left: 1em">察督率各該司道及府州縣掌印官責令水利官帶同</span>  
<span style="margin-left: 1em">塘長人等躬親相度考究源委要見某處係上游水滙</span>  
<span style="margin-left: 1em">某處係下流支港應分某水以殺其勢應闊某岸以緩</span>  
<span style="margin-left: 1em">其衝應濬某湖以會其流某處壩閘應修某處塘堰應</span>  
<span style="margin-left: 1em">築合用人工隨宜區處其劉家河黃浦七浦白茆范家</span>  
<span style="margin-left: 1em">港大黃浦及各鄉支河尤當分疏其餘緊要河港湖滙</span>  
<span style="margin-left: 1em">并浙直交界所如有未經開通及已開仍欠深闊與夫</span>  
<span style="margin-left: 1em">塘堰涇瀆陡門閘壩等項應修應濬應復舊應新置者</span>  
<span style="margin-left: 1em">通勘估議處如一圩之中塘岸溝池等項不煩多費者</span>  
<span style="margin-left: 1em">即令得業之家量田多寡出力修濬果係土工浩大動</span>  
<span style="margin-left: 1em">支淘河等銀應用如再不敷會同撫按官從長計議務</span>  
<span style="margin-left: 1em">求共濟各不得推諉其該道并府州縣掌印等官敢有</span>  
<span style="margin-left: 1em">怠玩誤事及水利官營求別差隳廢職業或需索常例</span>  
<span style="margin-left: 1em">利己病民應拿應參並聽舉行如例若勢豪之家侵塞</span>  
<span style="margin-left: 1em">水利姑令首正免罪敢有隱瞞及違拒阻撓者即行拿</span>  
<span style="margin-left: 1em">問干礙職官指名參奏每年終將修濬過緣由造册奏</span>  
<span style="margin-left: 1em">繳復命之日仍將所屬大小官曾否有益水利照例舉</span>  
<span style="margin-left: 1em">劾以昭勸懲爾爲憲臣受兹重委須夙夜殫心務俾水</span>  
<span style="margin-left: 1em">利興舉旱澇有備以爲益國便民之計如或因循苟且</span>  
<span style="margin-left: 1em">虛應故事責有所歸爾其欽承之故勅</span>  
<span style="margin-left: 1em">萬曆十六年　勅諭湖廣按察司副使許應逵近該撫</span>  
<span style="margin-left: 1em">按官題稱江南水患不常亟宜復設專官管理該部議</span>  
<span style="margin-left: 1em">覆相應命爾前去專管蘇松等四府水利駐劄松江府</span>  
<span style="margin-left: 1em">地方兼理農務爾宜查照該部題准事理踏看所屬地</span>  
<span style="margin-left: 1em">方估計工程議處錢糧起調人夫涇港湮塞者設法開</span>  
<span style="margin-left: 1em">濬圩岸低薄者着實修築務使夫河疏通達於江海隄</span>  
<span style="margin-left: 1em">防堅固可禦水澇如官民勢豪之家占種淤地侵奪水</span>  
<span style="margin-left: 1em">利者爾即清查改正敢有抗拒阻撓應拿問者徑自拿</span>  
<span style="margin-left: 1em">問應參奏者參奏處治四府及所屬州縣官員悉聽委</span>  
<span style="margin-left: 1em">用如有重大程工應合奏請者申呈撫按官奏請施行</span>  
<span style="margin-left: 1em">其不急工程聽爾便宜斟酌不必虛費財力致拂人情</span>  
<span style="margin-left: 1em">錢糧等項除聽撫按官總理節制外別衙門不得干預</span>  
<span style="margin-left: 1em">爾亦不得關白參謁致妨公務每年終仍將做過工程</span>  
<span style="margin-left: 1em">用過錢糧轉呈撫按官造册奏繳青册送部查覈爾爲</span>  
<span style="margin-left: 1em">憲臣受兹委任須躬親相度竭力經理不避勞怨使水</span>  
<span style="margin-left: 1em">利興舉益國便民斯爲稱職如或因循苟且虛應故事</span>  
<span style="margin-left: 1em">責有所歸爾其勉之慎之故勅</span>  
<span style="margin-left: 1em">崇禎元年六月丙辰平臺召對　上取户科右給事中</span>  
<span style="margin-left: 2em">黃承昊所奏疏令讀承昊奏曰東南時患水災因水</span>  
<span style="margin-left: 2em">利不修之故臣因疏詞不敢冗長故未暢所欲言前</span>

<span style="margin-left: 2em">行之　上問水利何謂不修是何地方承昊對云是</span>
