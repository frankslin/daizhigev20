## 崇祯松江府志卷之十六　水利上

<span style="margin-left: 3em">水利上<sub class="note-jiao">校：此處似脫上字今補</sub></span>  
<span style="margin-left: 1em">万历戊子大水</span>  
<span style="margin-left: 1em">上特命宪副许公来江南陆文定公语之曰治水者大</span>  
<span style="margin-left: 1em">约以神禹为法以孔孟为衡濬江导海孟子之水利也</span>  
<span style="margin-left: 1em">尽力沟洫孔子之水利也许公用违其言几耗数万金</span>  
<span style="margin-left: 1em">钱而讫无底绩夏周诸公惓惓以修圩为第一义其沟</span>  
<span style="margin-left: 1em">洫之遗意乎故先列　勅谕次列治策治绩而乃以治</span>  
<span style="margin-left: 1em">田终焉</span>  
<span style="margin-left: 1em">国朝勅谕</span>  
<span style="margin-left: 1em">永乐三年　勅谕户部尚书夏原吉都察院佥都御史</span>  
<span style="margin-left: 1em">俞士吉通政司左通政赵居任大理寺少卿袁复四郡</span>  
<span style="margin-left: 1em">之民频年厄于水患今旧谷已罄新苗未成老稚嗷嗷</span>  
<span style="margin-left: 1em">饥馁无告朕与卿等能独饱乎其往督郡县丞发仓廪</span>  
<span style="margin-left: 1em">赈之所至善加抚绥一切民间利害有当建革者速具</span>  
<span style="margin-left: 1em">以闻卿等宜体朕忧民之心钦哉无忽</span>  
<span style="margin-left: 1em">宣德五年　勅谕工部右侍郎周忱今命尔往南京应</span>  
<span style="margin-left: 1em">天苏州松江常州镇江太平宁国池州徽州安庆广德</span>  
<span style="margin-left: 1em">州巡抚递年一应税粮务在从长设法区画得宜使人</span>  
<span style="margin-left: 1em">不劳困输不后期尤在敷宣德意抚恤人民扶植良善</span>  
<span style="margin-left: 1em">其水田圩岸尔亦相度时宜整理俾无旱潦之患庶副</span>  
<span style="margin-left: 1em">朕委任之重钦哉故谕</span>  
<span style="margin-left: 1em">正统九年　勅谕工部右侍郎周忱近闻浙江嘉湖等</span>  
<span style="margin-left: 1em">府直隶苏松等府地方今秋多雨潦水暴溢渰没田稼</span>  
<span style="margin-left: 1em">漂荡民居溺死人畜盖因各处递年将旧通江海河港</span>  
<span style="margin-left: 1em">乘乾旱之时筑塞为田耕种及因递年沙涨以致水不</span>  
<span style="margin-left: 1em">流通人受其患今特命尔会同巡按御史严督各该府</span>  
<span style="margin-left: 1em">县拘集耆民里老人等询访踏勘各处原通江海河港</span>  
<span style="margin-left: 1em">故道果被豪强之人筑塞为田即令退还并年深淤塞</span>  
<span style="margin-left: 1em">之处尔等公同计议督令府县官起倩人夫开挑务要</span>  
<span style="margin-left: 1em">水道通行不至为患其余湖池陂塘圩岸可以蓄泄水</span>  
<span style="margin-left: 1em">利防备旱潦者悉从其修筑开通其间果有豪强之徒</span>  
<span style="margin-left: 1em">占据把持以为己利者尔即拿问轻则量情惩治情重</span>  
<span style="margin-left: 1em">者具奏区处用工之际尤须相度地势酌量民力其殷</span>  
<span style="margin-left: 1em">富田多之家务令尽力用工贫难下户及田少粮重者</span>  
<span style="margin-left: 1em">酌量差遣不可误其生理如工程浩大人力艰难非旬</span>  
<span style="margin-left: 1em">月可成者尔宜审度用工宜令受利近便去处同心同</span>  
<span style="margin-left: 1em">力切不可妨废农时朕惟豪强专利小民受害论法难</span>  
<span style="margin-left: 1em">容今姑宥其罪使之自新保其身家尔为朝廷重臣宜</span>  
<span style="margin-left: 1em">表率同事公以存心廉以律身勤以从事必诚必信用</span>  
<span style="margin-left: 1em">图久远毋虚劳民力毋苟具文移以塞责毋狃于小利</span>  
<span style="margin-left: 1em">以为功尔克尽职民受实惠朕惟尔嘉朝廷以安养斯</span>  
<span style="margin-left: 1em">民为念宜深体朕心为民造福以副任使或有窒碍难</span>  
<span style="margin-left: 1em">行之事亦须体谅人情从长计议奏来不许违误故谕</span>  
<span style="margin-left: 1em">弘治七年　勅谕工部侍郎徐贯兼都御史往同巡抚</span>  
<span style="margin-left: 1em">都御史何鉴朕惟直隶苏松常杭嘉湖六府数年以来</span>  
<span style="margin-left: 1em">屡被水灾园田渰没庐舍漂溺民既无聊生财赋又何</span>  
<span style="margin-left: 1em">自而出今特命尔会同彼处巡抚御史亲诣其地逐一</span>  
<span style="margin-left: 1em">踏勘如果前日之水道形迹具存今日之水患实由于</span>  
<span style="margin-left: 1em">此即于所在司府州县量取丁夫钱粮督同委官人等</span>  
<span style="margin-left: 1em">以次兴工修筑疏濬凡勅内该载不尽事宜听尔便宜</span>  
<span style="margin-left: 1em">处置文武职官军民人等有负才识谙晓水利者悉听</span>  
<span style="margin-left: 1em">委用职官敢有违慢乖方狥私废事者五品以下径自</span>  
<span style="margin-left: 1em">提问应奏请者参奏施行其兴工之际务审水道利害</span>  
<span style="margin-left: 1em">人情从违固不可畏难退避失经国之良图亦不得凿</span>  
<span style="margin-left: 1em">空妄为致小民之嗟怨殚心毕虑利国便民斯不负朝</span>  
<span style="margin-left: 1em">廷委任之意</span>  
<span style="margin-left: 1em">弘治八年　勅谕工部都水司主事姚文灏直隶苏松</span>  
<span style="margin-left: 1em">常镇及浙江杭嘉湖七府并苏州镇江等卫所地方广</span>  
<span style="margin-left: 1em">阔银粮浩大每岁收成全资水利积年以来河港沟渠</span>  
<span style="margin-left: 1em">湖塘等项尽皆壅塞或被豪强之人占为己业旱无所</span>  
<span style="margin-left: 1em">溉雨无所泄以致田谷不登军民缺食近差工部侍郎</span>  
<span style="margin-left: 1em">徐贯往会巡抚等官通行疏濬已奏工完但恐岁月寖</span>  
<span style="margin-left: 1em">久港渎渐致堙塞水利不能兴举圩岸愈见坍塌财赋</span>  
<span style="margin-left: 1em">无从出办兹特升尔前职命尔专一往来前项府卫地</span>  
<span style="margin-left: 1em">方提督各该管官员修理湖塘疏通河港开濬沟渠及</span>  
<span style="margin-left: 1em">一应圩岸未经修筑者及时修筑各处闸坝未尽修理</span>  
<span style="margin-left: 1em">者随宜修理合用木石等料于各该田有力之家从公</span>  
<span style="margin-left: 1em">劝谕或别为措置人夫于所在附近军卫有司相度起</span>  
<span style="margin-left: 1em">工仍须督役以时调度有法使蓄泄有备旱涝无虞毋</span>  
<span style="margin-left: 1em">事虚文务臻实效以为地方经久之计尔其勉之慎之</span>  
<span style="margin-left: 1em">故勅</span>  
<span style="margin-left: 1em">嘉靖□年<sub class="note-jiao">校：該字原書作墨丁當撰時已闕以下倣此不再重複</sub>勅谕巡抚都御</span>  
<span style="margin-left: 1em">史欧阳必进朕惟国家财赋取给东南近该前巡抚都</span>  
<span style="margin-left: 1em">御史丁汝夔及巡按吕光洵各题称苏松常镇四府地</span>  
<span style="margin-left: 1em">方连年水旱频仍皆由水利湮废以致民困赋逋贻患</span>  
<span style="margin-left: 1em">非细乞要查旧例通行修濬事下该部转行彼处查勘</span>  
<span style="margin-left: 1em">得太仓州常熟昆山等县七浦白茆新泾等河港盐铁</span>  
<span style="margin-left: 1em">许浦等塘堰修濬有官民并力合修者其所费财用有</span>  
<span style="margin-left: 1em">原派导河夫及存留各项银米并抚按司府州县赃罚</span>  
<span style="margin-left: 1em">与夫应解钱粮堪以那借者俱令支用已经该部议奏</span>  
<span style="margin-left: 1em">前来相应依拟尔见有地方巡抚之责特命专理其事</span>  
<span style="margin-left: 1em">尔宜查照节题事理及巡按委官勘处缘由将四府支</span>  
<span style="margin-left: 1em">河动支前项银米查议原奏官民合修分修地方坐委</span>  
<span style="margin-left: 1em">能干官员责令及时修理庶几事克有济尔仍照先年</span>  
<span style="margin-left: 1em">抚臣李充嗣事例不时躬往督视务使缓急有备旱涝</span>  
<span style="margin-left: 1em">无虞期于一劳而永逸各该承委官员除巡按御史每</span>  
<span style="margin-left: 1em">年阅视工程分别勤惰举劾外如有违慢悮事者五品</span>  
<span style="margin-left: 1em">以下尔即径自拿问应奏请者奏闻施行事完之日通</span>  
<span style="margin-left: 1em">将修濬过缘由画图贴说并用过钱粮数目造册奏缴</span>  
<span style="margin-left: 1em">及将勤干贤能官员通行论奏以凭旌擢</span>  
<span style="margin-left: 1em">隆庆陆年七月二十八日　诏书内一款大江南北财</span>  
<span style="margin-left: 1em">赋所出全资水利各处设有水利佥事各府州县设有</span>  
<span style="margin-left: 1em">水利通判县丞等官近来往往视为末务上下因循一</span>  
<span style="margin-left: 1em">遇水荒即奏乞蠲免抚按督令专管水利司判官往来</span>  
<span style="margin-left: 1em">巡历着落有司官将该管地方水利着实讲求议处何</span>  
<span style="margin-left: 1em">处当疏通其源何处当挑濬其流坝堰圩岸在在增修</span>  
<span style="margin-left: 1em">使蓄泄有备旱潦无伤合用夫役取诸得利之家毋令</span>  
<span style="margin-left: 1em">骚扰若功程浩大抚按官查其先年导河夫役用剩贮</span>  
<span style="margin-left: 1em">库及该府州县近地鱼课奏留修理隄坝等银两酌量</span>  
<span style="margin-left: 1em">动支有司官有仍前旷职误事及地方土豪之家阻挠</span>  
<span style="margin-left: 1em">壅塞专利病民者抚按官参拿处治</span>  
<span style="margin-left: 1em">万历四年　勅谕监察御史林应训近因言官建议苏</span>  
<span style="margin-left: 1em">松常镇等处水利久湮要差御史一员专管该部议覆</span>  
<span style="margin-left: 1em">相应今特命尔督理前项地方水利务要时常往来巡</span>  
<span style="margin-left: 1em">察督率各该司道及府州县掌印官责令水利官带同</span>  
<span style="margin-left: 1em">塘长人等躬亲相度考究源委要见某处系上游水汇</span>  
<span style="margin-left: 1em">某处系下流支港应分某水以杀其势应阔某岸以缓</span>  
<span style="margin-left: 1em">其冲应濬某湖以会其流某处坝闸应修某处塘堰应</span>  
<span style="margin-left: 1em">筑合用人工随宜区处其刘家河黄浦七浦白茆范家</span>  
<span style="margin-left: 1em">港大黄浦及各乡支河尤当分疏其余紧要河港湖汇</span>  
<span style="margin-left: 1em">并浙直交界所如有未经开通及已开仍欠深阔与夫</span>  
<span style="margin-left: 1em">塘堰泾渎陡门闸坝等项应修应濬应复旧应新置者</span>  
<span style="margin-left: 1em">通勘估议处如一圩之中塘岸沟池等项不烦多费者</span>  
<span style="margin-left: 1em">即令得业之家量田多寡出力修濬果系土工浩大动</span>  
<span style="margin-left: 1em">支淘河等银应用如再不敷会同抚按官从长计议务</span>  
<span style="margin-left: 1em">求共济各不得推诿其该道并府州县掌印等官敢有</span>  
<span style="margin-left: 1em">怠玩误事及水利官营求别差隳废职业或需索常例</span>  
<span style="margin-left: 1em">利己病民应拿应参并听举行如例若势豪之家侵塞</span>  
<span style="margin-left: 1em">水利姑令首正免罪敢有隐瞒及违拒阻挠者即行拿</span>  
<span style="margin-left: 1em">问干碍职官指名参奏每年终将修濬过缘由造册奏</span>  
<span style="margin-left: 1em">缴复命之日仍将所属大小官曾否有益水利照例举</span>  
<span style="margin-left: 1em">劾以昭劝惩尔为宪臣受兹重委须夙夜殚心务俾水</span>  
<span style="margin-left: 1em">利兴举旱涝有备以为益国便民之计如或因循苟且</span>  
<span style="margin-left: 1em">虚应故事责有所归尔其钦承之故勅</span>  
<span style="margin-left: 1em">万历十六年　勅谕湖广按察司副使许应逵近该抚</span>  
<span style="margin-left: 1em">按官题称江南水患不常亟宜复设专官管理该部议</span>  
<span style="margin-left: 1em">覆相应命尔前去专管苏松等四府水利驻札松江府</span>  
<span style="margin-left: 1em">地方兼理农务尔宜查照该部题准事理踏看所属地</span>  
<span style="margin-left: 1em">方估计工程议处钱粮起调人夫泾港湮塞者设法开</span>  
<span style="margin-left: 1em">濬圩岸低薄者着实修筑务使夫河疏通达于江海隄</span>  
<span style="margin-left: 1em">防坚固可御水涝如官民势豪之家占种淤地侵夺水</span>  
<span style="margin-left: 1em">利者尔即清查改正敢有抗拒阻挠应拿问者径自拿</span>  
<span style="margin-left: 1em">问应参奏者参奏处治四府及所属州县官员悉听委</span>  
<span style="margin-left: 1em">用如有重大程工应合奏请者申呈抚按官奏请施行</span>  
<span style="margin-left: 1em">其不急工程听尔便宜斟酌不必虚费财力致拂人情</span>  
<span style="margin-left: 1em">钱粮等项除听抚按官总理节制外别衙门不得干预</span>  
<span style="margin-left: 1em">尔亦不得关白参谒致妨公务每年终仍将做过工程</span>  
<span style="margin-left: 1em">用过钱粮转呈抚按官造册奏缴青册送部查核尔为</span>  
<span style="margin-left: 1em">宪臣受兹委任须躬亲相度竭力经理不避劳怨使水</span>  
<span style="margin-left: 1em">利兴举益国便民斯为称职如或因循苟且虚应故事</span>  
<span style="margin-left: 1em">责有所归尔其勉之慎之故勅</span>  
<span style="margin-left: 1em">崇祯元年六月丙辰平台召对　上取户科右给事中</span>  
<span style="margin-left: 2em">黄承昊所奏疏令读承昊奏曰东南时患水灾因水</span>  
<span style="margin-left: 2em">利不修之故臣因疏词不敢冗长故未畅所欲言前</span>  
<span style="margin-left: 2em">礼部郎中陈懋德有疏言之极详乞并臣疏下工部</span>  
<span style="margin-left: 2em">行之　上问水利何谓不修是何地方承昊对云是</span>  
<span style="margin-left: 2em">苏松地方阁臣道登龙锡同竝奏云臣道登即苏州</span>  
<span style="margin-left: 2em">人臣龙锡即松江人水利是东南一件大事但修理</span>  
<span style="margin-left: 2em">须要钱粮懋德本内说原设有开河银两　上问几</span>  
<span style="margin-left: 2em">何对曰亦不多臣等前已拟　旨抚按酌议具奏</span>  
<span style="margin-left: 2em">上沉思久之云要修水利可扰民否臣龙锡奏正惟</span>  
<span style="margin-left: 2em">恐扰民故颁行本处抚按酌量　上曰水利事着公</span>  
<span style="margin-left: 2em">议来奏</span>
