## 崇祯松江府志卷之五十八　志余下（稗谈）

<span style="margin-left: 3em">志余<sub class="note-yuan">稗谈</sub></span>  
<span style="margin-left: 1em">陆机初入洛次河南入偃师时阴晦望道左若有民居</span>  
<span style="margin-left: 2em">因投宿见一少年神姿端远置易投壶与机言论妙</span>  
<span style="margin-left: 2em">得玄微机心服其能无以酬抗既晓便去税骖逆旅</span>  
<span style="margin-left: 2em">逆旅妪曰此东十数里无村落有山阳王家冢机往</span>  
<span style="margin-left: 2em">视之空野霾云拱木蔽日方知昨所遇者信王弼也</span>  
<span style="margin-left: 1em">刘斌在吴郡时娄县有一女忽夜乘风雨恍恍至郡城</span>  
<span style="margin-left: 2em">内自觉去家正一炊顷衣不沾濡晓在门上求通言</span>  
<span style="margin-left: 2em">我天地也府君宜起延我当大富贵不尔必有凶祸</span>  
<span style="margin-left: 2em">刘问所来不自知后二十许日刘被诛<sub class="note-yuan">幽冥录</sub></span>  
<span style="margin-left: 1em">吴黄龙年中海盐柘湖有陆东美与妻朱氏相重笃伉</span>  
<span style="margin-left: 2em">俪之恩时人号为比肩人夫妇云后妻卒东美不食</span>  
<span style="margin-left: 2em">死家人哀之乃合葬未一岁冢上生双梓树同根二</span>  
<span style="margin-left: 2em">身相抱而合成一树每有双鸿常宿于上孙权闻之</span>  
<span style="margin-left: 2em">嗟叹封其里曰比肩墓又曰双梓　后子弘与妻张</span>  
<span style="margin-left: 2em">亦相爱慕吴人又呼为小比肩<sub class="note-yuan">述异记</sub></span>  
<span style="margin-left: 1em">进士曹朗唐文宗时任华亭令秩将满于吴郡置一宅</span>  
<span style="margin-left: 2em">又买小青衣名曰花红除前一日朗姊妹乃亲皆办</span>  
<span style="margin-left: 2em">奠祝之用家人并在左右独花红不至意其惰寝遂</span>  
<span style="margin-left: 2em">召至将笞之便云头痛忽有大抟击几中朗亲于是</span>  
<span style="margin-left: 2em">惊散俄又空中有声火随上下忽见东窗下床上有</span>  
<span style="margin-left: 2em">一女子可年十四五作两髻衣短黄襦袴跪于床以</span>  
<span style="margin-left: 2em">效人碾茶朗走起擒之遂失所在朗召玉芝观顾道</span>  
<span style="margin-left: 2em">士作法数日有人长吁曰吾是梁苑客枚臯前因节</span>  
<span style="margin-left: 2em">日求食于此不知云何见捕足下之祟非吾所为其</span>  
<span style="margin-left: 2em">人不远但问他人当自知朗乃复召女巫朱二娘令</span>  
<span style="margin-left: 2em">占巫悉令家人出惟花红头痛未起巫强呼之出遂</span>  
<span style="margin-left: 2em">拽其臂近肘有青脉寸余隆起曰贤圣宅于此后有</span>  
<span style="margin-left: 2em">包山道士申屠千龄过花红本是洞庭山人户共买</span>  
<span style="margin-left: 2em">人家一女令守洞庭山庙后为洞庭观拓北境二百</span>  
<span style="margin-left: 2em">余步其庙遂除人户卖与曹时庙中山魅无所依遂</span>  
<span style="margin-left: 2em">与其类巢于其臂东吴人尽知其事<sub class="note-yuan">乾𦠆子</sub></span>  
<span style="margin-left: 1em">唐淞江渔人张胡子尝于太湖中钓得一巨鱼腹上有</span>  
<span style="margin-left: 2em">丹书字曰九登龙门山三饮太湖水毕竟不成龙命</span>  
<span style="margin-left: 2em">负张胡子<sub class="note-yuan">出灵怪录</sub></span>  
<span style="margin-left: 1em">太湖入松江口唐贞元中有渔人载小网数船共十余</span>  
<span style="margin-left: 2em">人下网取鱼一无所获网中得镜才七八寸渔人异</span>  
<span style="margin-left: 2em">之遂取镜照悉见其臓腑其人闷绝而倒众大惊取</span>  
<span style="margin-left: 2em">镜鉴形者皆然即以镜投水中明日方理网所得鱼</span>  
<span style="margin-left: 2em">倍多其人先有疾者自此皆愈故老云此镜在江湖</span>  
<span style="margin-left: 2em">每数百年一出人亦常见之<sub class="note-yuan">出原化记</sub></span>  
<span style="margin-left: 1em">普照寺有北方天王祠宋时雷震祠柱倒书曰高洞杨</span>  
<span style="margin-left: 2em">雅一十六人火令章凡十一字内令章两字特奇劲</span>  
<span style="margin-left: 2em">似唐人书<sub class="note-yuan">出笔谈</sub></span>  
<span style="margin-left: 1em">松江出海东五六日程小岛之前濶百余里四面海水</span>  
<span style="margin-left: 2em">粘浊此水独清无风而浪高数丈船不敢近每一潮</span>  
<span style="margin-left: 2em">水漫没其上不见此浪船始得过夜望见水上红光</span>  
<span style="margin-left: 2em">如日上与天连相传龙王宅其下<sub class="note-yuan">出录异记</sub></span>  
<span style="margin-left: 1em">淀山初自三藏道法师以佛牙舍利授开山灯禅师建</span>  
<span style="margin-left: 2em">寺为云间禅林冠后毁有长者提举忠翊唐公倾赀</span>  
<span style="margin-left: 2em">重建中奉灵山一会佛菩萨像及护法力士二十位</span>  
<span style="margin-left: 2em">殿阴涌塑瀛海幻宝普陀大士宴坐花岩十六应真</span>  
<span style="margin-left: 2em">往来波涛间计费二十万缗不余人增一茎草<sub class="note-yuan">僧正印记</sub></span>  
<span style="margin-left: 1em">宋嘉祐中海上有一船桅折风漂泊岸船中三十余人</span>  
<span style="margin-left: 2em">衣冠如唐人系红鞓角带短皂衫行则相缀如雁行</span>  
<span style="margin-left: 2em">自出一书示人乃唐天祐中告授新罗岛皆用汉字</span>  
<span style="margin-left: 2em">盖东夷之臣属高丽者时赞善大夫韩正彦为县令</span>  
<span style="margin-left: 2em">治舟遣归其舟中有诸谷惟麻子大如莲菂<sub class="note-yuan">见姑苏志</sub></span>  
<span style="margin-left: 1em">小蒸镇民颜甘泉浚井中有石一方旁有甲六二字石</span>  
<span style="margin-left: 2em">刻畧云先臣胡执中伏遇徽宗皇帝陛下以藩邸旧</span>  
<span style="margin-left: 2em">臣特加宠渥所赐御札甚多龙翔凤舞铁画银钩恐</span>  
<span style="margin-left: 2em">岁久湮没勒之坚珉以垂不朽今其石尚存</span>  
<span style="margin-left: 1em">青龙真一道院有孟张二羽士以方术齐名孟一日曝</span>  
<span style="margin-left: 2em">麦张语曰子其食我不尔当令子麦逐浪去也孟不</span>  
<span style="margin-left: 2em">与食张书符役将大雨立至孟亦书符顶于首长跪</span>  
<span style="margin-left: 2em">麦中塲独无雨麦亦无恙</span>  
<span style="margin-left: 1em">宋绍兴乙卯十月丁未大雨雹激射如箭覆舟坏屋海</span>  
<span style="margin-left: 2em">水大溢拥巨鳅卧沙上扬鬐拨剌高齐县谯其长百</span>  
<span style="margin-left: 2em">丈民脔其肉转鬛压死数十人颔骨长二丈五尺脊</span>  
<span style="margin-left: 2em">骨如臼己未大饥斗米千钱道殣相望</span>  
<span style="margin-left: 1em">中和中有士人苏昌远居小庄去官道十里自吴达娄</span>  
<span style="margin-left: 2em">率多荷芰而庄居其胜忽一日有一女郎容质艳丽</span>  
<span style="margin-left: 2em">若神仙中人自是与之相狎以庄为幽会之所苏生</span>  
<span style="margin-left: 2em">惑之既甚尝以玉环赠之结系殷勤偶一日见槛前</span>  
<span style="margin-left: 2em">白莲花开敷殊异俯而玩之见花房中有物细视之</span>  
<span style="margin-left: 2em">乃所赠玉环也因折之其妖遂绝</span>  
<span style="margin-left: 1em">宋顺帝升明中荆州刺史沈攸之得玉马于华亭谷中</span>  
<span style="margin-left: 2em">忽一夕群马踯蹋惊嘶令人伏枥候见一白驹以绿</span>  
<span style="margin-left: 2em">绳系腹从外来复去厩门犹闭也攸之乃悟爱妾冯</span>  
<span style="margin-left: 2em">月华臂上一玉马以绿丝绳穿之至夜辄脱置枕边</span>  
<span style="margin-left: 2em">有时失去晓时则还试取看之见蹄下有泥后攸之</span>  
<span style="margin-left: 2em">败不知所在<sub class="note-yuan">宣室志及珍异考</sub></span>  
<span style="margin-left: 1em">苏州华亭县有陆四官庙元和初有盐船数十只泊庙</span>  
<span style="margin-left: 2em">前守船者夜中雨过忽见庙前光明如火窥之见一</span>  
<span style="margin-left: 2em">物长数丈大如屋梁口弄一团火或吞或吐船者以</span>  
<span style="margin-left: 2em">竹篙遥掷之惊入草光遗在地视之乃一珠径寸光</span>  
<span style="margin-left: 2em">耀射目即以衣裹之光明透出乃脱亵衣裹之光遂</span>  
<span style="margin-left: 2em">不现至扬州胡店卖之获数千缗问胡曰此何珠也</span>  
<span style="margin-left: 2em">胡人不告而去<sub class="note-yuan">原化录</sub></span>  
<span style="margin-left: 1em">宋咸平初四月苏州赵屯渔妇李氏张罾河上得一白</span>  
<span style="margin-left: 2em">龟如钱其色玉莹电眸朱尾宫画灿然放于河中夜</span>  
<span style="margin-left: 2em">岸有火荧荧往视之龟在焉近村王道荣迺献于县</span>  
<span style="margin-left: 2em">令李维维上之郡时陈省华守松郡异之即具表以</span>  
<span style="margin-left: 2em">闻张君房曰按瑞应图千岁龟巢莲叶上其出也其</span>  
<span style="margin-left: 2em">将以应千岁之运乎且白西方色也龟归也岂西裔</span>  
<span style="margin-left: 2em">丑虏之怀归乎明年朔方叛帅李继迁来贡马其秋</span>  
<span style="margin-left: 2em">试进士以白龟诗为题</span>  
<span style="margin-left: 1em">宋杨备郎中天圣中为长溪令忽梦作诗云月俸蚨钱</span>  
<span style="margin-left: 2em">数甚微不知从宦几时归东吴一片轻波在欲问何</span>  
<span style="margin-left: 2em">人买钓矶意甚异之明道初为华亭令丁内艰遂家</span>  
<span style="margin-left: 2em">吴中乐其土风安之因悟梦中语尝效白乐天作我</span>  
<span style="margin-left: 2em">爱姑苏好十章又作姑苏百题诗行于世<sub class="note-yuan">旧志</sub></span>  
<span style="margin-left: 1em">黄土桥甲姓周保号中正宋敷文阁学士兼潼川等处</span>  
<span style="margin-left: 2em">安抚制置使尹之后也年三十余未有子保性虔恭</span>  
<span style="margin-left: 2em">乐施夜梦神人授十八味药方既寤知即五积散曰</span>  
<span style="margin-left: 2em">是诿予施济人也遂造酒三十石渍药以施人虽异</span>  
<span style="margin-left: 2em">疾无弗愈者酒尽因继以药俾如方湛酒服或施尽</span>  
<span style="margin-left: 2em">无以继乃为约朔望日来如约而至者亡虑千万人</span>  
<span style="margin-left: 2em">十五年保育五男七女<sub class="note-yuan">移愚斋笔记</sub></span>  
<span style="margin-left: 1em">华亭人黄翁世以卖香为业徙居东湖杨柳巷每往临</span>  
<span style="margin-left: 2em">安江下收买甜头归家修事为香货卖甜头者香行</span>  
<span style="margin-left: 2em">俚语也乃海南贩到柏木及藤头是也黄遂将此木</span>  
<span style="margin-left: 2em">截断如笺香片子与蕃香相和假造货卖淳熙年间</span>  
<span style="margin-left: 2em">一日欲归华亭留东湖口有金山大王庙是夜三鼓</span>  
<span style="margin-left: 2em">时忽一人撦起黄翁殴之谓曰汝何作业货卖假香</span>  
<span style="margin-left: 2em">更余许方抵舍卒<sub class="note-yuan">闲窗括异</sub></span>  
<span style="margin-left: 1em">泰定改元府治春帖云官清莹彻三江水民乐和熏两</span>  
<span style="margin-left: 2em">县春或云如何不见府明年诏罢府立庸田司</span>  
<span style="margin-left: 1em">亭塲斥卤之地海潮渐渍水泉咸苦至正中两浙盐运</span>  
<span style="margin-left: 2em">知事张允分务青村择地穿井水特甘一时亭民博</span>  
<span style="margin-left: 2em">被其利呼为张公井云允廉政具见袁浦塲石刻进</span>  
<span style="margin-left: 2em">士昂吉所为文</span>  
<span style="margin-left: 1em">大德间知府捏只回回人也秩垂满治第府之永安桥</span>  
<span style="margin-left: 2em">将定居焉凿地得古石刻云此地二百年后胡人居</span>  
<span style="margin-left: 2em">宋末长兴人夏杞养金氏子名世昌擕家华亭为典</span>  
<span style="margin-left: 2em">押元初一再迁为华亭尹税第与世昌居寝梁缠锦</span>  
<span style="margin-left: 2em">被上有金填三大字曰金世昌人生万事信前定也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">见旧志</sub></span>  
<span style="margin-left: 1em">吾松胜国时最称繁富青龙有任水监家小贞有曹云</span>  
<span style="margin-left: 2em">西家下沙有瞿廷发家张堰有杨竹西家陶宅有陶</span>  
<span style="margin-left: 2em">与权家吕巷有吕璜溪家祥泽有张家于巷有侯家</span>  
<span style="margin-left: 2em">吕璜溪即开应奎文会者也瞿即志中所称浙西苑</span>  
<span style="margin-left: 2em">囿之盛惟下沙瞿氏为最者也曹云西即所谓东吴</span>  
<span style="margin-left: 2em">富家惟松江曹云西无锡倪云林昆山顾玉山声华</span>  
<span style="margin-left: 2em">文物可以并称者也侯家亦好古所藏甚富有盈尺</span>  
<span style="margin-left: 2em">玉观音白如凝脂遭回禄侯至楼上取观音为烟所</span>  
<span style="margin-left: 2em">蔽不得下抱观音焚死者是也张氏即有三昧轩者</span>  
<span style="margin-left: 2em">是也昔日名家之盛如此</span>  
<span style="margin-left: 1em">松江元时有四塔西曰普照又西曰延恩西南曰超果</span>  
<span style="margin-left: 2em">东南曰兴圣夏监运家在四塔之东而小室内有一</span>  
<span style="margin-left: 2em">塔影长五寸许倒悬于西壁之上不知从何而来然</span>  
<span style="margin-left: 2em">不常有或时见之是不可晓也今四塔惟兴圣独存</span>  
<span style="margin-left: 2em">近或见于城西南黄泥溇中其地去寺既远城郭蔽</span>  
<span style="margin-left: 2em">亏了不相及是又不可晓也<sub class="note-yuan">旧志</sub></span>  
<span style="margin-left: 1em">兴圣寺铜钟元至正十年铸相传铸时有老妪以双股</span>  
<span style="margin-left: 2em">银钗投液中今见于钟腹扪之隐手或云有金指镮</span>  
<span style="margin-left: 2em">在蒲牢之侧至今宛然<sub class="note-yuan">旧志</sub></span>  
<span style="margin-left: 1em">嘉兴沈雷伯以道术名至正丙子松江旱府官遣香币</span>  
<span style="margin-left: 2em">迎请以来雷伯矜甚谓雨可立致结坛仙鹤观下铁</span>
