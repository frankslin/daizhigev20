## 崇禎松江府志卷之五十八　志餘下（稗談）

<span style="margin-left: 3em">志餘<sub class="note-yuan">稗談</sub></span>  
<span style="margin-left: 1em">陸機初入洛次河南入偃師時陰晦望道左若有民居</span>  
<span style="margin-left: 2em">因投宿見一少年神姿端遠置易投壺與機言論妙</span>  
<span style="margin-left: 2em">得玄微機心服其能無以酬抗既曉便去稅驂逆旅</span>  
<span style="margin-left: 2em">逆旅嫗曰此東十數里無村落有山陽王家冢機往</span>  
<span style="margin-left: 2em">視之空野霾雲拱木蔽日方知昨所遇者信王弼也</span>  
<span style="margin-left: 1em">劉斌在吳郡時婁縣有一女忽夜乘風雨恍恍至郡城</span>  
<span style="margin-left: 2em">內自覺去家正一炊頃衣不霑濡曉在門上求通言</span>  
<span style="margin-left: 2em">我天地也府君宜起延我當大富貴不爾必有凶禍</span>  
<span style="margin-left: 2em">劉問所來不自知後二十許日劉被誅<sub class="note-yuan">幽冥錄</sub></span>  
<span style="margin-left: 1em">吳黃龍年中海鹽柘湖有陸東美與妻朱氏相重篤伉</span>  
<span style="margin-left: 2em">儷之恩時人號爲比肩人夫婦云後妻卒東美不食</span>  
<span style="margin-left: 2em">死家人哀之乃合葬未一歲冢上生雙梓樹同根二</span>  
<span style="margin-left: 2em">身相抱而合成一樹每有雙鴻常宿于上孫權聞之</span>  
<span style="margin-left: 2em">嗟嘆封其里曰比肩墓又曰雙梓　後子弘與妻張</span>  
<span style="margin-left: 2em">亦相愛慕吳人又呼爲小比肩<sub class="note-yuan">述異記</sub></span>  
<span style="margin-left: 1em">進士曹朗唐文宗時任華亭令秩將滿于吳郡置一宅</span>  
<span style="margin-left: 2em">又買小青衣名曰花紅除前一日朗姊妹乃親皆辦</span>  
<span style="margin-left: 2em">奠祝之用家人並在左右獨花紅不至意其惰寢遂</span>  
<span style="margin-left: 2em">召至將笞之便云頭痛忽有大摶擊幾中朗親於是</span>  
<span style="margin-left: 2em">驚散俄又空中有聲火隨上下忽見東窗下床上有</span>  
<span style="margin-left: 2em">一女子可年十四五作兩髻衣短黃襦袴跪于床以</span>  
<span style="margin-left: 2em">效人碾茶朗走起擒之遂失所在朗召玉芝觀顧道</span>  
<span style="margin-left: 2em">士作法數日有人長吁曰吾是梁苑客枚臯前因節</span>  
<span style="margin-left: 2em">日求食于此不知云何見捕足下之祟非吾所爲其</span>  
<span style="margin-left: 2em">人不遠但問他人當自知朗乃復召女巫朱二娘令</span>  
<span style="margin-left: 2em">占巫悉令家人出惟花紅頭痛未起巫强呼之出遂</span>  
<span style="margin-left: 2em">拽其臂近肘有青脈寸餘隆起曰賢聖宅於此後有</span>  
<span style="margin-left: 2em">包山道士申屠千齡過花紅本是洞庭山人户共買</span>  
<span style="margin-left: 2em">人家一女令守洞庭山廟後爲洞庭觀拓北境二百</span>  
<span style="margin-left: 2em">餘步其廟遂除人户賣與曹時廟中山魅無所依遂</span>  
<span style="margin-left: 2em">與其類巢於其臂東吳人盡知其事<sub class="note-yuan">乾𦠆子</sub></span>  
<span style="margin-left: 1em">唐淞江漁人張胡子嘗于太湖中釣得一巨魚腹上有</span>  
<span style="margin-left: 2em">丹書字曰九登龍門山三飲太湖水畢竟不成龍命</span>  
<span style="margin-left: 2em">負張胡子<sub class="note-yuan">出靈怪錄</sub></span>  
<span style="margin-left: 1em">太湖入松江口唐貞元中有漁人載小網數船共十餘</span>  
<span style="margin-left: 2em">人下網取魚一無所獲網中得鏡纔七八寸漁人異</span>  
<span style="margin-left: 2em">之遂取鏡照悉見其臓腑其人悶絶而倒衆大驚取</span>  
<span style="margin-left: 2em">鏡鑑形者皆然即以鏡投水中明日方理網所得魚</span>  
<span style="margin-left: 2em">倍多其人先有疾者自此皆愈故老云此鏡在江湖</span>  
<span style="margin-left: 2em">每數百年一出人亦常見之<sub class="note-yuan">出原化記</sub></span>  
<span style="margin-left: 1em">普照寺有北方天王祠宋時雷震祠柱倒書曰高洞楊</span>  
<span style="margin-left: 2em">雅一十六人火令章凡十一字內令章兩字特奇勁</span>  
<span style="margin-left: 2em">似唐人書<sub class="note-yuan">出筆談</sub></span>  
<span style="margin-left: 1em">松江出海東五六日程小島之前濶百餘里四面海水</span>  
<span style="margin-left: 2em">粘濁此水獨清無風而浪高數丈船不敢近每一潮</span>  
<span style="margin-left: 2em">水漫没其上不見此浪船始得過夜望見水上紅光</span>  
<span style="margin-left: 2em">如日上與天連相傳龍王宅其下<sub class="note-yuan">出錄異記</sub></span>  
<span style="margin-left: 1em">澱山初自三藏道法師以佛牙舍利授開山燈禪師建</span>  
<span style="margin-left: 2em">寺爲雲間禪林冠後燬有長者提舉忠翊唐公傾貲</span>  
<span style="margin-left: 2em">重建中奉靈山一會佛菩薩像及護法力士二十位</span>  
<span style="margin-left: 2em">殿陰湧塑瀛海幻寶普陀大士宴坐花岩十六應真</span>  
<span style="margin-left: 2em">往來波濤間計費二十萬緡不餘人增一莖草<sub class="note-yuan">僧正印記</sub></span>  
<span style="margin-left: 1em">宋嘉祐中海上有一船桅折風漂泊岸船中三十餘人</span>  
<span style="margin-left: 2em">衣冠如唐人繫紅鞓角帶短皂衫行則相綴如雁行</span>  
<span style="margin-left: 2em">自出一書示人乃唐天祐中告授新羅島皆用漢字</span>  
<span style="margin-left: 2em">蓋東夷之臣屬高麗者時贊善大夫韓正彦爲縣令</span>  
<span style="margin-left: 2em">治舟遣歸其舟中有諸穀惟麻子大如蓮菂<sub class="note-yuan">見姑蘇志</sub></span>  
<span style="margin-left: 1em">小蒸鎮民顔甘泉浚井中有石一方旁有甲六二字石</span>  
<span style="margin-left: 2em">刻畧云先臣胡執中伏遇徽宗皇帝陛下以藩邸舊</span>  
<span style="margin-left: 2em">臣特加寵渥所賜御札甚多龍翔鳳舞鐵畫銀鈎恐</span>  
<span style="margin-left: 2em">歲久湮没勒之堅珉以垂不朽今其石尚存</span>  
<span style="margin-left: 1em">青龍真一道院有孟張二羽士以方術齊名孟一日曝</span>  
<span style="margin-left: 2em">麥張語曰子其食我不爾當令子麥逐浪去也孟不</span>  
<span style="margin-left: 2em">與食張書符役將大雨立至孟亦書符頂于首長跪</span>  
<span style="margin-left: 2em">麥中塲獨無雨麥亦無恙</span>  
<span style="margin-left: 1em">宋紹興乙卯十月丁未大雨雹激射如箭覆舟壞屋海</span>  
<span style="margin-left: 2em">水大溢擁巨鰍臥沙上揚鬐撥剌高齊縣譙其長百</span>  
<span style="margin-left: 2em">丈民臠其肉轉鬛壓死數十人頷骨長二丈五尺脊</span>  
<span style="margin-left: 2em">骨如臼己未大饑斗米千錢道殣相望</span>  
<span style="margin-left: 1em">中和中有士人蘇昌遠居小莊去官道十里自吳達婁</span>  
<span style="margin-left: 2em">率多荷芰而莊居其勝忽一日有一女郎容質豔麗</span>  
<span style="margin-left: 2em">若神仙中人自是與之相狎以莊爲幽會之所蘇生</span>  
<span style="margin-left: 2em">惑之既甚嘗以玉環贈之結繫殷勤偶一日見檻前</span>  
<span style="margin-left: 2em">白蓮花開敷殊異俯而玩之見花房中有物細視之</span>  
<span style="margin-left: 2em">乃所贈玉環也因折之其妖遂絶</span>  
<span style="margin-left: 1em">宋順帝昇明中荆州刺史沈攸之得玉馬於華亭谷中</span>  
<span style="margin-left: 2em">忽一夕群馬躑蹋驚嘶令人伏櫪候見一白駒以綠</span>  
<span style="margin-left: 2em">繩繫腹從外來復去厩門猶閉也攸之乃悟愛妾馮</span>  
<span style="margin-left: 2em">月華臂上一玉馬以綠絲繩穿之至夜輒脱置枕邊</span>  
<span style="margin-left: 2em">有時失去曉時則還試取看之見蹄下有泥後攸之</span>  
<span style="margin-left: 2em">敗不知所在<sub class="note-yuan">宣室志及珍異考</sub></span>  
<span style="margin-left: 1em">蘇州華亭縣有陸四官廟元和初有鹽船數十隻泊廟</span>  
<span style="margin-left: 2em">前守船者夜中雨過忽見廟前光明如火窺之見一</span>  
<span style="margin-left: 2em">物長數丈大如屋梁口弄一團火或吞或吐船者以</span>  
<span style="margin-left: 2em">竹篙遥擲之驚入草光遺在地視之乃一珠徑寸光</span>  
<span style="margin-left: 2em">耀射目即以衣裹之光明透出乃脱褻衣裹之光遂</span>  
<span style="margin-left: 2em">不現至揚州胡店賣之獲數千緡問胡曰此何珠也</span>  
<span style="margin-left: 2em">胡人不告而去<sub class="note-yuan">原化錄</sub></span>  
<span style="margin-left: 1em">宋咸平初四月蘇州趙屯漁婦李氏張罾河上得一白</span>  
<span style="margin-left: 2em">龜如錢其色玉瑩電眸朱尾宫畫燦然放於河中夜</span>  
<span style="margin-left: 2em">岸有火熒熒往視之龜在焉近村王道榮迺獻于縣</span>  
<span style="margin-left: 2em">令李維維上之郡時陳省華守松郡異之即具表以</span>  
<span style="margin-left: 2em">聞張君房曰按瑞應圖千歲龜巢蓮葉上其出也其</span>  
<span style="margin-left: 2em">將以應千歲之運乎且白西方色也龜歸也豈西裔</span>  
<span style="margin-left: 2em">醜虜之懷歸乎明年朔方叛帥李繼遷來貢馬其秋</span>  
<span style="margin-left: 2em">試進士以白龜詩爲題</span>  
<span style="margin-left: 1em">宋楊備郎中天聖中爲長溪令忽夢作詩云月俸蚨錢</span>  
<span style="margin-left: 2em">數甚微不知從宦幾時歸東吳一片輕波在欲問何</span>  
<span style="margin-left: 2em">人買釣磯意甚異之明道初爲華亭令丁內艱遂家</span>  
<span style="margin-left: 2em">吳中樂其土風安之因悟夢中語嘗效白樂天作我</span>  
<span style="margin-left: 2em">愛姑蘇好十章又作姑蘇百題詩行於世<sub class="note-yuan">舊志</sub></span>  
<span style="margin-left: 1em">黃土橋甲姓周保號中正宋敷文閣學士兼潼川等處</span>  
<span style="margin-left: 2em">安撫制置使尹之後也年三十餘未有子保性虔恭</span>  
<span style="margin-left: 2em">樂施夜夢神人授十八味藥方既寤知即五積散曰</span>  
<span style="margin-left: 2em">是諉予施濟人也遂造酒三十石漬藥以施人雖異</span>  
<span style="margin-left: 2em">疾無弗愈者酒盡因繼以藥俾如方湛酒服或施盡</span>  
<span style="margin-left: 2em">無以繼乃爲約朔望日來如約而至者亡慮千萬人</span>  
<span style="margin-left: 2em">十五年保育五男七女<sub class="note-yuan">移愚齋筆記</sub></span>  
<span style="margin-left: 1em">華亭人黃翁世以賣香爲業徙居東湖楊柳巷每往臨</span>  
<span style="margin-left: 2em">安江下收買甜頭歸家修事爲香貨賣甜頭者香行</span>  
<span style="margin-left: 2em">俚語也乃海南販到柏木及藤頭是也黃遂將此木</span>  
<span style="margin-left: 2em">截斷如箋香片子與蕃香相和假造貨賣淳熙年間</span>  
<span style="margin-left: 2em">一日欲歸華亭留東湖口有金山大王廟是夜三鼓</span>  
<span style="margin-left: 2em">時忽一人撦起黃翁毆之謂曰汝何作業貨賣假香</span>  
<span style="margin-left: 2em">更餘許方抵舍卒<sub class="note-yuan">閑窗括異</sub></span>  
<span style="margin-left: 1em">泰定改元府治春帖云官清瑩徹三江水民樂和熏兩</span>  
<span style="margin-left: 2em">縣春或云如何不見府明年詔罷府立庸田司</span>  
<span style="margin-left: 1em">亭塲斥鹵之地海潮漸漬水泉鹹苦至正中兩浙鹽運</span>  
<span style="margin-left: 2em">知事張允分務青村擇地穿井水特甘一時亭民博</span>  
<span style="margin-left: 2em">被其利呼爲張公井云允廉政具見袁浦塲石刻進</span>  
<span style="margin-left: 2em">士昂吉所爲文</span>  
<span style="margin-left: 1em">大德間知府捏只回回人也秩垂滿治第府之永安橋</span>  
<span style="margin-left: 2em">將定居焉鑿地得古石刻云此地二百年後胡人居</span>  
<span style="margin-left: 2em">宋末長興人夏杞養金氏子名世昌擕家華亭爲典</span>  
<span style="margin-left: 2em">押元初一再遷爲華亭尹稅第與世昌居寢梁纏錦</span>  
<span style="margin-left: 2em">被上有金填三大字曰金世昌人生萬事信前定也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">見舊志</sub></span>  
<span style="margin-left: 1em">吾松勝國時最稱繁富青龍有任水監家小貞有曹雲</span>  
<span style="margin-left: 2em">西家下沙有瞿廷發家張堰有楊竹西家陶宅有陶</span>  
<span style="margin-left: 2em">與權家呂巷有呂璜溪家祥澤有張家于巷有侯家</span>  
<span style="margin-left: 2em">呂璜溪即開應奎文會者也瞿即誌中所稱浙西苑</span>  
<span style="margin-left: 2em">囿之盛惟下沙瞿氏爲最者也曹雲西即所謂東吳</span>  
<span style="margin-left: 2em">富家惟松江曹雲西無錫倪雲林崑山顧玉山聲華</span>  
<span style="margin-left: 2em">文物可以並稱者也侯家亦好古所藏甚富有盈尺</span>  
<span style="margin-left: 2em">玉觀音白如凝脂遭回禄侯至樓上取觀音爲烟所</span>  
<span style="margin-left: 2em">蔽不得下抱觀音焚死者是也張氏即有三昧軒者</span>  
<span style="margin-left: 2em">是也昔日名家之盛如此</span>  
<span style="margin-left: 1em">松江元時有四塔西曰普照又西曰延恩西南曰超果</span>  
<span style="margin-left: 2em">東南曰興聖夏監運家在四塔之東而小室內有一</span>  
<span style="margin-left: 2em">塔影長五寸許倒懸于西壁之上不知從何而來然</span>  
<span style="margin-left: 2em">不常有或時見之是不可曉也今四塔惟興聖獨存</span>  
<span style="margin-left: 2em">近或見于城西南黃泥漊中其地去寺既遠城郭蔽</span>  
<span style="margin-left: 2em">虧了不相及是又不可曉也<sub class="note-yuan">舊志</sub></span>  
<span style="margin-left: 1em">興聖寺銅鐘元至正十年鑄相傳鑄時有老嫗以雙股</span>  
<span style="margin-left: 2em">銀釵投液中今見于鐘腹捫之隱手或云有金指鐶</span>  
<span style="margin-left: 2em">在蒲牢之側至今宛然<sub class="note-yuan">舊志</sub></span>  
<span style="margin-left: 1em">嘉興沈雷伯以道術名至正丙子松江旱府官遣香幣</span>
