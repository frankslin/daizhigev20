## 崇禎松江府志卷之十一　役法上

<span style="margin-left: 3em">役法一</span>  
<span style="margin-left: 1em">三縣役重已極非獨當役難即審役更難下則身家俱</span>  
<span style="margin-left: 1em">斃上則心口兩窮此豈細事哉昔温公蜀公與蘇文忠</span>  
<span style="margin-left: 1em">兄弟反覆專論役法蓋處置得宜非獨安小户以安大</span>  
<span style="margin-left: 1em">户且欲便前官而并便後官也故十年編審催徵五年</span>  
<span style="margin-left: 1em">編審收解凡抱桑梓之憂獻芻蕘之議者詳哉乎其言</span>  
<span style="margin-left: 1em">之矣幸賜覽而講求焉無聰明射覆無鹵莽完局蓋生</span>  
<span style="margin-left: 1em">靈以合縣計歲月以五年十年計一不妥而倒懸可知</span>  
<span style="margin-left: 1em">也役額細列于後</span>  
<span style="margin-left: 3em">十年編審里役之名</span>  
<span style="margin-left: 2em">經催<sub class="note-yuan">一啚之役</sub>該年　　　總甲</span>  
<span style="margin-left: 2em">總催<sub class="note-yuan">一區之役</sub>塘長</span>  
<span style="margin-left: 3em">五年編審糧役之數</span>  
<span style="margin-left: 2em">布解<sub class="note-yuan">每年八名華亭縣四名上海縣三名青浦縣一名</sub></span>  
<span style="margin-left: 2em">北運<sub class="note-yuan">每年五十六名華亭縣一十八名上海縣一十八名青浦縣十名</sub></span>  
<span style="margin-left: 2em">收兑<sub class="note-yuan">每年一百四十一名華亭縣六十名上海縣三十八名青浦縣四十三名</sub></span>  
<span style="margin-left: 2em">收銀<sub class="note-yuan">總催每年一百七十六名華亭縣九十名上海縣四十八名青浦縣三十八名</sub></span>  
<span style="margin-left: 2em">南運<sub class="note-yuan">每年七名華亭縣四名上海縣二名青浦縣一名</sub></span>  
<span style="margin-left: 2em">風汛<sub class="note-yuan">每年七名華亭縣二名上海縣四名青浦縣一名</sub></span>  
<span style="margin-left: 2em">鳳陽麥折<sub class="note-yuan">解户每年三名華亭縣一名上海縣一名青浦縣一名</sub></span>  
<span style="margin-left: 2em">南京蜜糖解户<sub class="note-yuan">每年一名係華亭縣</sub></span>  
<span style="margin-left: 2em">南京惜薪司運柴脚解户<sub class="note-yuan">每年二名華亭縣一名上海縣一名</sub></span>  
<span style="margin-left: 2em">南京各部柴薪解户<sub class="note-yuan">每年一名係華亭縣</sub></span>  
<span style="margin-left: 2em">南京五城弓兵解户<sub class="note-yuan">每年一名係華亭縣</sub></span>  
<span style="margin-left: 2em">南京直堂解户<sub class="note-yuan">每年一名係華亭縣</sub></span>  
<span style="margin-left: 2em">南京國子監膳夫解户<sub class="note-yuan">每年一名係華亭縣</sub></span>  
<span style="margin-left: 2em">兩浙運司船鹽解户<sub class="note-yuan">每年一名係華亭縣</sub></span>  
<span style="margin-left: 2em">織造府解户<sub class="note-yuan">每年一名係華亭縣</sub></span>  
<span style="margin-left: 2em">軍器庫子<sub class="note-yuan">每年二名華亭縣一名上海縣一名</sub></span>  
<span style="margin-left: 2em">斗給<sub class="note-yuan">每年一名係上海縣</sub></span>  
<span style="margin-left: 2em">水鄉蕩價解户<sub class="note-yuan">每年一名係青浦縣</sub></span>  
<span style="margin-left: 2em">南解<sub class="note-yuan">每年二名俱係上海縣</sub></span>  
<span style="margin-left: 2em">二六輕賫解頭</span>  
<span style="margin-left: 2em">鹽糧解頭</span>  
<span style="margin-left: 2em">南京公侯解頭</span>  
<span style="margin-left: 2em">徐州<sub class="note-yuan">米折解頭每年二名上海縣一名青浦縣一名</sub></span>  
<span style="margin-left: 2em">揚州<sub class="note-yuan">米折解頭每年二名上海縣一名青浦縣一名</sub></span>  
<span style="margin-left: 2em">山東<sub class="note-yuan">昌平等驛解頭每年一名係上海縣</sub></span>  
<span style="margin-left: 2em">鳳陽<sub class="note-yuan">大店驛解頭每年一名係上海縣</sub></span>  
<span style="margin-left: 2em">河間府灜海驛解頭</span>  
<span style="margin-left: 2em">南京農桑絲絹解頭<sub class="note-yuan">係青浦縣</sub></span>  
<span style="margin-left: 3em">自二六輕賫以下十役華亭免編繇議將顧署丞</span>  
<span style="margin-left: 3em">貼役義米內量扣一千二百石收貯以給解官轉</span>  
<span style="margin-left: 3em">解從萬曆三十八年至今民間省此諸役矣</span>  
<span style="margin-left: 2em">經催<sub class="note-yuan">分催一啚之人户闔府里役每年該一千三百八名</sub></span>  
<span style="margin-left: 3em">華亭縣共六百八十啚該經催六百八十名</span>  
<span style="margin-left: 3em">上海縣共三百九十八啚該經催六百九十八名</span>  
<span style="margin-left: 3em">青浦縣共二百三十啚該經催二百三十名</span>  
<span style="margin-left: 2em">總催<sub class="note-yuan">總領各啚之分催闔府每年該一百八十九名</sub></span>  
<span style="margin-left: 3em">華亭縣共八十區該總催八十名</span>  
<span style="margin-left: 3em">上海縣共五十六區該總催五十六名</span>  
<span style="margin-left: 3em">青浦縣共五十三區該總催五十三名</span>  
<span style="margin-left: 2em">每縣轄保若干保領區若干區領啚若干多寡不等</span>  
<span style="margin-left: 2em">每啚分十年爲十甲每甲編審經催一名或獨充或</span>  
<span style="margin-left: 2em">二户三户朋充謂之里長亦謂排年輪甲年分專責</span>  
<span style="margin-left: 2em">催辦本啚人户本折銀米假如於第一甲甲年分承</span>  
<span style="margin-left: 2em">充經催先一年第十甲癸年分即爲該年又先一年</span>  
<span style="margin-left: 2em">第九甲壬年分爲總甲該年承應起夫濬河運泥棘</span>  
<span style="margin-left: 2em">刺等差使總甲主管里中一應雜事當孔道去處承</span>  
<span style="margin-left: 2em">直官長水陸往來其城內外坊厢啚分地方干係祗</span>  
<span style="margin-left: 2em">應煩難尤爲喫緊經催輪年於八月中承役不拘啚</span>  
<span style="margin-left: 2em">分多少內點丁力尤勝者一人總一區催辦之事謂</span>  
<span style="margin-left: 2em">之領限總催如于第一甲甲年分點充總催後四年</span>  
<span style="margin-left: 2em">第四甲丁年分即爲塘長每年遇有開河水利等役</span>  
<span style="margin-left: 2em">督率各啚該年勾當公務尤倍煩難</span>  
<span style="margin-left: 1em">舊制每區設催辦糧長一名專管催徵本區銀米每年</span>  
<span style="margin-left: 1em">秋赴南京關領勘合然後承役亦重典也舊謂之公務</span>  
<span style="margin-left: 1em">糧長其在本區啚催辦人户則有零星窵遠之煩苦官</span>  
<span style="margin-left: 1em">豪勢宦則有上門守候刁蹬之煩苦民力既已告困編</span>  
<span style="margin-left: 1em">審又或不均鄉宦田多貽累日甚隆慶初年始立官甲</span>  
<span style="margin-left: 1em">書册每册用知數人一名應完本折錢糧自赴比較與</span>  
<span style="margin-left: 1em">總經催人役無涉該區啚所存田畝各啚應納銀米責</span>  
<span style="margin-left: 1em">在經催一人其苦樂繇本啚人户之完欠而人户之完</span>  
<span style="margin-left: 1em">欠又係該啚田地之高下本年收成之豐歉更有經催</span>  
<span style="margin-left: 1em">善良而人户奸頑者則任意拖賴而累歸經催又有人</span>  
<span style="margin-left: 1em">户善良而經催奸巧者則私侵入已托名民欠錢糧不</span>  
<span style="margin-left: 1em">起皆由二弊是役也自今年十月開徵至明年十月完</span>  
<span style="margin-left: 1em">限如數盡足尚有匝歲奔走之勞而民欠難完往往墮</span>  
<span style="margin-left: 1em">悮甚有四五年尚未清楚者沿鄉催辦則有跋涉之苦</span>  
<span style="margin-left: 1em">入城比限則有盤纏之苦完不如數又有血杖之苦田</span>  
<span style="margin-left: 1em">地抛荒又有拖欠之苦人户逃亡有代賠之苦若遇水</span>  
<span style="margin-left: 1em">旱凶年錢糧無出舉一啚之困苦獨萃于一人破身亡</span>  
<span style="margin-left: 1em">家賣妻鬻子累月窮年未能脱累故百畝以下人户充</span>  
<span style="margin-left: 1em">此一役猶慮不堪若以零星數畝之户朋充未有不立</span>  
<span style="margin-left: 1em">斃者也</span>  
<span style="margin-left: 2em">萬曆己酉華亭聶公紹昌經催議　松郡之役莫苦</span>  
<span style="margin-left: 2em">于經催經催不過於一啚十排年之中挨次輪辦而</span>  
<span style="margin-left: 2em">一啚之錢糧起總盡責其身十日一限一身在鄉催</span>  
<span style="margin-left: 2em">辦一身到縣應比所以近之有分身催比之難有上</span>  
<span style="margin-left: 2em">城下郭衙門押保之難有代人賠貱之難遠之有幾</span>  
<span style="margin-left: 2em">年徵欠之難有十年查盤納罪之難是以承此役者</span>  
<span style="margin-left: 2em">身家多喪總之大患有二一在拖欠一在侵欺染于</span>  
<span style="margin-left: 2em">經催爲侵欺逋于民間爲拖欠不問細民之完多完</span>  
<span style="margin-left: 2em">少而惟經催之是責則良者空自爲良頑者落得爲</span>  
<span style="margin-left: 2em">頑所以敲朴愈多而負課愈甚殊不知經催特輸役</span>  
<span style="margin-left: 2em">之人有何罪而代奸頑受此箠楚哉欲除拖欠惟在</span>  
<span style="margin-left: 2em">于明悉細户而欲除頑户侵欺其要在明摘欠户今</span>  
<span style="margin-left: 2em">細户之納與不納茫無查考而徒寄出納完欠之分</span>  
<span style="margin-left: 2em">數於總書櫃書之手任其糢糊出人種種奸弊即有</span>  
<span style="margin-left: 2em">神明莫能搜剔原頭總繇實徵細册上下茫然納者</span>  
<span style="margin-left: 2em">不知其納侵者難究其侵縣官之神日疲而侵賴之</span>  
<span style="margin-left: 2em">害日熾今本職議欲於各區各啚立一實徵細户田</span>  
<span style="margin-left: 2em">糧册每區總催開列啚總一册一樣二本一本發總</span>  
<span style="margin-left: 2em">催收執一本存縣發櫃上收執此册先開一區錢糧</span>  
<span style="margin-left: 2em">總數次開各啚錢糧總數即就一啚分爲十限每限</span>  
<span style="margin-left: 2em">總催于各啚名下開其完欠完者開其實數若干寫</span>  
<span style="margin-left: 2em">如數二字欠者開其實欠若干寫不如數三字又將</span>  
<span style="margin-left: 2em">入户田數照依虎頭鼠尾列其多者於前少者於後</span>  
<span style="margin-left: 2em">以憑比較其點拘頑户先拘其田糧最多者次及其</span>  
<span style="margin-left: 2em">田糧少者雖有先後決無倖免官甲囤户亦准此</span>  
<span style="margin-left: 2em">撫臺周公孔教徵糧緩急議　錢糧之中有起存起</span>  
<span style="margin-left: 2em">存之中有緩急率憑吏書那移作弊先其所緩後其</span>  
<span style="margin-left: 2em">所急以致上供緊要反多不完今後各州縣額徵糧</span>  
<span style="margin-left: 2em">除本色務要當年完足外其折色銀造簡明手册二</span>  
<span style="margin-left: 2em">本要見某州縣某項折銀若干係緊急某項折銀若</span>  
<span style="margin-left: 2em">干係稍緩不拘夏稅秋糧料價徭里起運存留逐項</span>  
<span style="margin-left: 2em">細開通共該銀若干分爲二十限使民一目瞭然便</span>  
<span style="margin-left: 2em">於輸納至於存留內若各役對支工食即米麥布艸</span>  
<span style="margin-left: 2em">之類許其作價收完不得刁難小民作拖欠累違者</span>  
<span style="margin-left: 2em">定行拏究吳中小民困苦譬之一碗飯以漸而食人</span>  
<span style="margin-left: 2em">不致噎若并食恐不能堪宜體此意</span>  
<span style="margin-left: 2em">崇禎己巳華亭鄭公友玄酌議賦役以甦民困八欵</span>  
<span style="margin-left: 2em">總申照得五茸一邑人不盡饒地不加腴而布縷粟</span>  
<span style="margin-left: 2em">米力役兼征焉重以逋賦則民苦益甚此時即不敢</span>  
<span style="margin-left: 2em">輕言减賦息役亦猶有長吏所得行者在也縣司自</span>  
<span style="margin-left: 2em">青浦移此迄踰數載仰見上臺憂民之誠發於聲顔</span>  
<span style="margin-left: 2em">筆舌則愧無寸長撫綏以康厥庶民者今酌陳一二</span>  
<span style="margin-left: 2em">特據其己見已行下狥民請以爲地方久計非有異</span>  
<span style="margin-left: 2em">政也實亦不敢喜事振矯上飾明德伏乞俯賜批示</span>  
<span style="margin-left: 2em">勒石施行一輕糧定派荒區議賦也布解北運區運</span>  
<span style="margin-left: 2em">收銀四者議役也里甲塘長義米三項則賦役兼之</span>  
<span style="margin-left: 2em">次列本役之後</span>  
<span style="margin-left: 3em">一經催十甲均辦議　本縣本折額賦幾及五十</span>  
<span style="margin-left: 3em">萬其里甲計共八十區六百三十啚每啚排年十</span>  
<span style="margin-left: 3em">名分辦十年一勞九逸其比較亦云簡便法似可</span>  
<span style="margin-left: 3em">久然逋賦因之愈甚經催之累遂至鬻産破家而</span>  
<span style="margin-left: 3em">莫支蓋因十甲輪役彼此互欠則承役之年一人</span>  
<span style="margin-left: 3em">代十甲以償逋而中人之産立盡且充役如此其</span>  
<span style="margin-left: 3em">苦則大家啚卸目前利人包辦而無田赤棍恣意</span>  
<span style="margin-left: 3em">索貼貼一入手恣意收侵幸而催科稍寬則募人</span>  
<span style="margin-left: 3em">代杖了事萬一差追緊逼攜家以逃而官仍問之</span>  
<span style="margin-left: 3em">正身必更鬻産賠納雖大家亦破矣且一啚并額</span>  
<span style="margin-left: 3em">多至數百金萬不得已而差一衙役押追見其重</span>  
<span style="margin-left: 3em">逋不能即完亦谿壑其欲勒騙酒食遂至取給正</span>  
<span style="margin-left: 3em">賦以供之而所逋益不能完困累終年官民愁嘆</span>  
<span style="margin-left: 3em">其流弊殆不可勝言然豈民盡無良哉蓋一人拖</span>  
<span style="margin-left: 3em">賴則九甲必至互欠九甲欠而一人償則役斷難</span>  
<span style="margin-left: 3em">充而包攬無賴侵逃相尋雖有淳民亦末如之何</span>  
<span style="margin-left: 3em">也今本縣新編里甲搜查詭寄一按田籍授之以</span>  
<span style="margin-left: 3em">役則包攬無繇呈身且一人分辦一甲額輕户少</span>  
<span style="margin-left: 3em">不待厲禁而朋賴包侵之弊俱絕第往年一人應</span>  
<span style="margin-left: 3em">比今驟增十人比較似屬紛沓然往年一月兩限</span>  
<span style="margin-left: 3em">者改省一月一限則淳良安枕樂於上納又每限</span>  
<span style="margin-left: 3em">止摘其極欠者榜示赴比甚者押令全完則淳役</span>  
<span style="margin-left: 3em">趨早完之便頑役畏不完之害人情鼓舞易於終</span>  
<span style="margin-left: 3em">事即或鞭朴不廢總爲頑民設法較之溷比溷追</span>  
<span style="margin-left: 3em">愚姓貱賠奸人欺侵其法之煩簡又豈啻十百而</span>  
<span style="margin-left: 3em">已哉今縣司行之兩年上下相習但棍徒覬覦包</span>

<span style="margin-left: 2em">嫌糧料不肯驗收俱令小民運送內府而害不可勝</span>  
<span style="margin-left: 2em">言矣　糧長之害李康惠疏之最詳曰家有千金之</span>  
<span style="margin-left: 2em">産當一年即有乞丐者矣家有壯丁十餘當一年即</span>  
<span style="margin-left: 2em">有絕户者矣民避糧役過於謫戍官府無如之何有</span>  
<span style="margin-left: 2em">每歲一换之例有數十家朋當之條始也破一家數</span>  
<span style="margin-left: 2em">歲則沿鄉無不破家者矣讀其言真堪流涕</span>  
<span style="margin-left: 2em">給事中陸公樹德民運疏　東南財賦之來有軍運</span>  
<span style="margin-left: 2em">有民運軍運以充六軍之儲民運以供百官之禄人</span>  
<span style="margin-left: 2em">皆知軍運之重而不知民運之苦夫軍運以十軍而</span>  
<span style="margin-left: 2em">運米四百石或五百石民運以一民而亦運米四百</span>  
<span style="margin-left: 2em">石或五百石軍運之船皆官所造而軍不知民運之</span>  
<span style="margin-left: 2em">船則民自僱而官不知軍運以軍法結爲漕法一呼</span>  
<span style="margin-left: 2em">百應人莫敢犯民運以田里小民供役遠道語言鄙</span>  
<span style="margin-left: 2em">俚衣服村賤人人得而侮之軍運經各該分司衙門</span>  
<span style="margin-left: 2em">無抑勒需求之苦民運經各該衙門動以遲違情繇</span>  
<span style="margin-left: 2em">問擬工價併諸雜色使用軍運過洪閘一錢不煩而</span>  
<span style="margin-left: 2em">洪夫閘夫共與挽拽民運每過一洪用銀十餘兩過</span>  
<span style="margin-left: 2em">一閘用銀五六錢所過共三洪五十餘閘而費可知</span>  
<span style="margin-left: 2em">矣其最苦者船户皆江淮奸民慣造此船裝載白糧</span>  
<span style="margin-left: 2em">每催船價及撑駕夫價計不下二百餘兩糧一入船</span>  
<span style="margin-left: 2em">其驅使糧長不啻奴婢每日供奉船長及撑駕夫不</span>  
<span style="margin-left: 2em">啻奉其父母蓋糧在船中即糧長身家所係吞聲忍</span>  
<span style="margin-left: 2em">氣曲爲順從勢不得不然也其最所畏者軍運每凌</span>  
<span style="margin-left: 2em">虐民運有等豪惡之軍故將己船撞擦民運之船民</span>  
<span style="margin-left: 2em">船板厚而軍船板薄微有損傷即便蜂攅鴉擁盡入</span>  
<span style="margin-left: 2em">民船百般挾詐不厭其欲不已其他入京攬頭之需</span>  
<span style="margin-left: 2em">索入倉交納之艱難又不可勝言凡充是役未有不</span>  
<span style="margin-left: 2em">破家者臣産東南親見此苦詢諸父老咸謂宜將白</span>  
<span style="margin-left: 2em">糧并入運軍順帶使民出所有以益軍軍出餘力以</span>  
<span style="margin-left: 2em">代民似無不可者但今年限期已迫尚未敢輕議上</span>  
<span style="margin-left: 2em">請今所當議者合無將民運并入議單兼責之漕臣</span>  
<span style="margin-left: 2em">令各該參政一體督促進閘總運參政督催至京則</span>  
<span style="margin-left: 2em">軍運不敢肆其凌虐船户不得恣其奸貪而洪閘亦</span>  
<span style="margin-left: 2em">可無需索之患如有此等許不時呈告以憑警治伏</span>  
<span style="margin-left: 2em">乞勑下該部會議施行</span>  
<span style="margin-left: 2em">御史婁江錢公桓民運疏　竊惟南直蘇松常三府</span>  
<span style="margin-left: 2em">浙江嘉湖二府歲輸白糧二十一萬四千八百餘石</span>  
<span style="margin-left: 2em">以充內庭供應及各官廪禄軍民兩運總屬公需矣</span>  
<span style="margin-left: 2em">及見南來部運官投遞解批問以今歲白糧何遲滯</span>  
<span style="margin-left: 2em">若此乃對曰行至泇河爲漕軍阻遏守候四十餘日</span>  
<span style="margin-left: 2em">及行至臨清又爲漕軍阻遏守候三十餘日稍欲移</span>  
<span style="margin-left: 2em">舟而前則數千漕艘數萬旗軍一呼蜂擁孰敢攖其</span>  
<span style="margin-left: 2em">鋒哉不得不忍氣吞聲挽舟遠避直俟漕艘過盡方</span>  
<span style="margin-left: 2em">敢尾其後而行耳職聞此言不覺髮竪眦裂白糧非</span>  
<span style="margin-left: 2em">私貨胡爲受制至此乎即今內供白糧缺乏已極倉</span>  
<span style="margin-left: 2em">臣耿鳴雷督責部運各官量行車運入京以濟急需</span>  
<span style="margin-left: 2em">固權宜變通之策也乃詢其脚價之費每米一石運</span>  
<span style="margin-left: 2em">一百里脚價銀一錢二分尚有凍阻天津德州者遠</span>  
<span style="margin-left: 2em">至五六百里脚價之倍費又可知也糧長隻身數千</span>  
<span style="margin-left: 2em">里外舉目無親誰爲應援殊可憐憫職查漕運議單</span>  
<span style="margin-left: 2em">一則曰白糧聽儧幫一則曰白糧起運軍七民三未</span>  
<span style="margin-left: 2em">聞有軍先民後之例夫以餉軍漕糧而較之內供白</span>  
<span style="margin-left: 2em">糧其輕重固有分矣聞漕糧之積尚支二年而較之</span>  
<span style="margin-left: 2em">旦暮待用之白糧其緩急又有分矣顧以軍而凌其</span>  
<span style="margin-left: 2em">民是謂不法以軍餉之故而壓上供之需是謂不義</span>  
<span style="margin-left: 2em">若今不爲嚴禁重懲則日甚一日歲遲一歲將重爲</span>  
<span style="margin-left: 2em">民害而上供其何賴焉宜行總漕巡漕衙門嚴爲申</span>  
<span style="margin-left: 2em">飭凡通津處所大張告示如白糧過淮過洪過閘先</span>  
<span style="margin-left: 2em">到先行若有漕軍仍前欺凌阻遏者許部運官指名</span>  
<span style="margin-left: 2em">申詳總漕巡漕衙門盡法拏究必罪不貸然而非常</span>  
<span style="margin-left: 2em">法也明歲以後還宜查照舊例行各該巡撫十一月</span>  
<span style="margin-left: 2em">以裏即責成州縣官督令糧長舂辦包完十二月以</span>  
<span style="margin-left: 2em">裏即責成部運官督糧長裝載開行有不遵者即繩</span>  
<span style="margin-left: 2em">以法夫民船自備原與軍船不同若民運先行與軍</span>  
<span style="margin-left: 2em">運不礙况白糧數少不過二十分中之一分耳船少</span>  
<span style="margin-left: 2em">則啟行自速行早則守凍無虞如是而白糧猶不早</span>  
<span style="margin-left: 2em">完職請伏妄言之誅矣</span>  
<span style="margin-left: 2em">給事中練川歸公子顧民運疏　國家之賦役莫重</span>  
<span style="margin-left: 2em">於東南而賦役之艱難莫重於民運職生三吳自爲</span>  
<span style="margin-left: 2em">諸生時即知北運之苦試舉其受累之大有三一曰</span>  
<span style="margin-left: 2em">水脚之侵没二曰沿途之需詐三曰交納之留難夫</span>  
<span style="margin-left: 2em">運糧之有水脚每船不下百金似亦可濟舂辦之耗</span>  
<span style="margin-left: 2em">折長途之勞費交納之賠償獨奈何侵漁者衆也米</span>  
<span style="margin-left: 2em">未下船而先盤詰牌票百出索取千方船尚未募而</span>  
<span style="margin-left: 2em">妄爲好歹胥吏哆口而談縣令拱手而聽各官原有</span>  
<span style="margin-left: 2em">費額另納公堂使費銀兩各項原有編銀復索轎夫</span>  
<span style="margin-left: 2em">修船工食既有總部協部之官已而添官押役原有</span>  
<span style="margin-left: 2em">儧運催運之役已而添役押幫且扛頭把持而水手</span>  
<span style="margin-left: 2em">任其僱募兜攬紛紜而撑駕聽其遲速蓋糧未行而</span>  
<span style="margin-left: 2em">水脚已耗其過半矣是水脚之侵費不可不重加裁</span>  
<span style="margin-left: 2em">革也至如糧船之行往返六千餘里涉險數十餘處</span>  
<span style="margin-left: 2em">民已不勝匍匐而皇店皇木之暴戾抑勒關津閘壩</span>  
<span style="margin-left: 2em">之阻滯留難快船官座船之欺凌需索重至叠出不</span>  
<span style="margin-left: 2em">惟詐財且阻去路而旱則起車遲則守凍耗費不貲</span>  
<span style="margin-left: 2em">且州縣查驗矣又有淮安理刑之驗通州糧衙之驗</span>  
<span style="margin-left: 2em">何爲者也况淮安之驗驗其少少則罪之通州之驗</span>  
<span style="margin-left: 2em">驗其多多又罪之少不可多不可爲之民者安所逃</span>  
<span style="margin-left: 2em">罪乎是沿途之需詐不可不重爲議處也若夫交納</span>  
<span style="margin-left: 2em">之累尤有不可勝言者五經科道七經內官掛號三</span>  
<span style="margin-left: 2em">十二衙門亦云瑣矣煩矣而糧未入城先講使用初</span>  
<span style="margin-left: 2em">入倉庾各役先索常例管門者有錢把解者有錢有</span>  
<span style="margin-left: 2em">數銖粒於掌上選銖粒於盤中者選畢則每石而收</span>  
<span style="margin-left: 2em">之收重有罰收輕有罰有每石費五錢者甚至有一</span>  
<span style="margin-left: 2em">二兩者况近時之新斛比國初之斛多有異同賠補</span>  
<span style="margin-left: 2em">甚難且遲留有罪違限有罪京中之罪未償而府州</span>  
<span style="margin-left: 2em">縣銷批之罪又至則交納之弊又不可不重爲裁革</span>  
<span style="margin-left: 2em">也先年有題准民運規則稽弊票册責令府州縣凡</span>  
<span style="margin-left: 2em">解户人給一本收照如官吏故違明　旨抑勒索騙</span>  
<span style="margin-left: 2em">許即據實填註前件之下候完日繳查參究以故尚</span>  
<span style="margin-left: 2em">有顧忌而今寢閣不復給矣小民安能訴耶若遲延</span>  
<span style="margin-left: 2em">守凍之苦更有不堪者則漕船虐阻之故也漕運之</span>  
<span style="margin-left: 2em">與民運均爲國儲漕卒之艘萬其實糲六師食之民</span>  
<span style="margin-left: 2em">之艘千其實精六宫百執事食之乃漕卒怙其衆而</span>  
<span style="margin-left: 2em">驕其民凡道路險阻之處抑之不得過曰吾爲官運</span>  
<span style="margin-left: 2em">也宜先而爲私運也宜後故將漕船擦民船民船損</span>  
<span style="margin-left: 2em">則忍氣吞聲莫敢誰何軍船傷則鴉擁蜂攅百般挾</span>  
<span style="margin-left: 2em">詐惟意所欲故民之畏軍如猛虎而莫敢以身當也</span>  
<span style="margin-left: 2em">夫軍與民皆王臣也一銖一粒皆王土所出也何不</span>  
<span style="margin-left: 2em">嚴爲申令雖五府之中俾得隨到隨行令一州一縣</span>  
<span style="margin-left: 2em">自爲群而不必候各府可乎或一州一縣之中得先</span>  
<span style="margin-left: 2em">則先行令十家五家自爲幇而不必候各邑可乎漕</span>  
<span style="margin-left: 2em">卒未行何妨解户之先行也漕船未過閘何妨民船</span>  
<span style="margin-left: 2em">之先過也先後聽民自便要以不違限爲主如此既</span>  
<span style="margin-left: 2em">無風波之險又免守凍之苦矣凡如此弊皆臣所目</span>  
<span style="margin-left: 2em">擊而親嘗者故備陳苦情以瀆　天聽</span>  
<span style="margin-left: 2em">董漕同知方公應明北運議　或問曰役莫苦於北</span>  
<span style="margin-left: 2em">運身既親之矣可得歷歷而言歟對曰北運之不先</span>  
<span style="margin-left: 2em">也始有所羈而不能先也中有所阻抑而不敢先也</span>  
<span style="margin-left: 2em">前有所畏避而不欲先也何謂始有所羈而不能先</span>  
<span style="margin-left: 2em">夫運必資舟楫無水脚價則失其資矣乃今不請托</span>  
<span style="margin-left: 2em">則不得也不對支民間則不得也不營求比限則不</span>  
<span style="margin-left: 2em">得也不鑚求放單則不得也不扣除公堂則不得也</span>  
<span style="margin-left: 2em">未涉江淮已爲魚肉安得冬理舟米春濟東風之便</span>  
<span style="margin-left: 2em">乎是水脚價爲北運之命脉最宜當官而現給量時</span>  
<span style="margin-left: 2em">而蚤給破陋規而全給者也何謂中有所阻抑而不</span>  
<span style="margin-left: 2em">敢先白糧　上供漕糧軍餉輕重自殊乃先漕後白</span>  
<span style="margin-left: 2em">强軍既逞横江湖之上而上人更助漕阻白不買幇</span>  
<span style="margin-left: 2em">則不得行也其最苦者漕白相值遇險破舟而令白</span>  
<span style="margin-left: 2em">賠漕私詐未遂鑚求公斷私詐十餘金而不得公斷</span>  
<span style="margin-left: 2em">百餘金而莫誰何是倒授強軍以恐喝之柄也不寧</span>  
<span style="margin-left: 2em">惟是河上游徒賄得緝盜未消之批遍搜糧艘沿河</span>  
<span style="margin-left: 2em">刁棍怙恃村里烏合之衆强禦糧長部官目擊之非</span>  
<span style="margin-left: 2em">不執有三尺彼借口差委將解諸院道實繁有徒將</span>  
<span style="margin-left: 2em">發問該管有司又非所屬之吏也則惟聽飽其欲去</span>  
<span style="margin-left: 2em">矣即去已羈程數十里矣甚至關閘之間止司啟閉</span>  
<span style="margin-left: 2em">商賈攸往一見糧艘必得重賄以導之行是處處皆</span>  
<span style="margin-left: 2em">北運之强禦何如重部官之權俾得直陳軍丁强横</span>  
<span style="margin-left: 2em">詐害之狀以爲軍官殿最備兩臺考察之一端則軍</span>  
<span style="margin-left: 2em">官自爲制以民糧分入軍幫可以一府之民糧合入</span>  
<span style="margin-left: 2em">軍幫亦可也至關閘爲擾彼自以官品償之若棍徒</span>  
<span style="margin-left: 2em">爲梗在兩臺一傳示而有司禁之自止繇是運官更</span>  
<span style="margin-left: 2em">時其起居審其風波無怠無急則衆役無險危之苦</span>  
<span style="margin-left: 2em">自無死亡之患也何謂前有所畏避而不欲先也苦</span>  
<span style="margin-left: 2em">莫苦於守凍彼何敢後意必較守凍而苦又甚焉者</span>  
<span style="margin-left: 2em">矣蓋守凍臨濟每名打點不過五十金而一至河西</span>  
<span style="margin-left: 2em">天津之間則內監以起車爲例所費不貲每名非二</span>  
<span style="margin-left: 2em">百金則百五十金也照顧不及攙和水土竊取米數</span>  
<span style="margin-left: 2em">且有連車推入私室者矣且有搶奪近地而無人問</span>  
<span style="margin-left: 2em">之者矣即部院布以寬政或車十之一或始議終免</span>  
<span style="margin-left: 2em">而一聞起車之議則一番催促一番打點一處催促</span>  
<span style="margin-left: 2em">處處打點况內府無厭打點未幾而催促隨之是以</span>  
<span style="margin-left: 2em">起車爲虛名而吏書受實利先至者首被害也何如</span>  
<span style="margin-left: 2em">守凍遠者用五十人而不驚其心也且勿論往歲即</span>  
<span style="margin-left: 2em">今之役議起車者數矣民之私用不知其幾而所運</span>  
<span style="margin-left: 2em">車不過二千石不識內府何以支其虛以待冰泮之</span>  
<span style="margin-left: 2em">際哉似不如永裁起車之例以塞吏書口實則各役</span>  
<span style="margin-left: 2em">無陸運之費争脱守凍之苦又何樂栖栖河上踰歲</span>  
<span style="margin-left: 2em">而不得至也所以然者何也彼皆視條陳爲虛文徒</span>  
<span style="margin-left: 2em">指弊立法而事竣之日無人據往議而按其實信其</span>  
<span style="margin-left: 2em">賞必其罰是以小人無忌指弊而弊在立法而法亡</span>  
<span style="margin-left: 2em">矣使誠能悉糧解始末之苦則人人踴躍而前未離</span>  
<span style="margin-left: 2em">本地所省已多然後照往歲有司扣除水脚之數改</span>
