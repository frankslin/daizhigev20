## 崇祯松江府志卷之十一　役法上

<span style="margin-left: 3em">役法一</span>  
<span style="margin-left: 1em">三县役重已极非独当役难即审役更难下则身家俱</span>  
<span style="margin-left: 1em">毙上则心口两穷此岂细事哉昔温公蜀公与苏文忠</span>  
<span style="margin-left: 1em">兄弟反复专论役法盖处置得宜非独安小户以安大</span>  
<span style="margin-left: 1em">户且欲便前官而并便后官也故十年编审催征五年</span>  
<span style="margin-left: 1em">编审收解凡抱桑梓之忧献刍荛之议者详哉乎其言</span>  
<span style="margin-left: 1em">之矣幸赐览而讲求焉无聪明射覆无卤莽完局盖生</span>  
<span style="margin-left: 1em">灵以合县计岁月以五年十年计一不妥而倒悬可知</span>  
<span style="margin-left: 1em">也役额细列于后</span>  
<span style="margin-left: 3em">十年编审里役之名</span>

<span style="margin-left: 2em">徐州<sub class="note-yuan">米折解头每年二名上海县一名青浦县一名</sub></span>  
<span style="margin-left: 2em">扬州<sub class="note-yuan">米折解头每年二名上海县一名青浦县一名</sub></span>  
<span style="margin-left: 2em">山东<sub class="note-yuan">昌平等驿解头每年一名系上海县</sub></span>  
<span style="margin-left: 2em">凤阳<sub class="note-yuan">大店驿解头每年一名系上海县</sub></span>  
<span style="margin-left: 2em">河间府灜海驿解头</span>  
<span style="margin-left: 2em">南京农桑丝绢解头<sub class="note-yuan">系青浦县</sub></span>  
<span style="margin-left: 3em">自二六轻赍以下十役华亭免编繇议将顾署丞</span>  
<span style="margin-left: 3em">贴役义米内量扣一千二百石收贮以给解官转</span>  
<span style="margin-left: 3em">解从万历三十八年至今民间省此诸役矣</span>  
<span style="margin-left: 2em">经催<sub class="note-yuan">分催一啚之人户阖府里役每年该一千三百八名</sub></span>  
<span style="margin-left: 3em">华亭县共六百八十啚该经催六百八十名</span>  
<span style="margin-left: 3em">上海县共三百九十八啚该经催六百九十八名</span>  
<span style="margin-left: 3em">青浦县共二百三十啚该经催二百三十名</span>  
<span style="margin-left: 2em">总催<sub class="note-yuan">总领各啚之分催阖府每年该一百八十九名</sub></span>  
<span style="margin-left: 3em">华亭县共八十区该总催八十名</span>  
<span style="margin-left: 3em">上海县共五十六区该总催五十六名</span>  
<span style="margin-left: 3em">青浦县共五十三区该总催五十三名</span>  
<span style="margin-left: 2em">每县辖保若干保领区若干区领啚若干多寡不等</span>  
<span style="margin-left: 2em">每啚分十年为十甲每甲编审经催一名或独充或</span>  
<span style="margin-left: 2em">二户三户朋充谓之里长亦谓排年轮甲年分专责</span>  
<span style="margin-left: 2em">催办本啚人户本折银米假如于第一甲甲年分承</span>  
<span style="margin-left: 2em">充经催先一年第十甲癸年分即为该年又先一年</span>  
<span style="margin-left: 2em">第九甲壬年分为总甲该年承应起夫濬河运泥棘</span>  
<span style="margin-left: 2em">刺等差使总甲主管里中一应杂事当孔道去处承</span>  
<span style="margin-left: 2em">直官长水陆往来其城内外坊厢啚分地方干系祗</span>  
<span style="margin-left: 2em">应烦难尤为吃紧经催轮年于八月中承役不拘啚</span>  
<span style="margin-left: 2em">分多少内点丁力尤胜者一人总一区催办之事谓</span>  
<span style="margin-left: 2em">之领限总催如于第一甲甲年分点充总催后四年</span>  
<span style="margin-left: 2em">第四甲丁年分即为塘长每年遇有开河水利等役</span>  
<span style="margin-left: 2em">督率各啚该年勾当公务尤倍烦难</span>  
<span style="margin-left: 1em">旧制每区设催办粮长一名专管催征本区银米每年</span>  
<span style="margin-left: 1em">秋赴南京关领勘合然后承役亦重典也旧谓之公务</span>  
<span style="margin-left: 1em">粮长其在本区啚催办人户则有零星窎远之烦苦官</span>  
<span style="margin-left: 1em">豪势宦则有上门守候刁蹬之烦苦民力既已告困编</span>  
<span style="margin-left: 1em">审又或不均乡宦田多贻累日甚隆庆初年始立官甲</span>  
<span style="margin-left: 1em">书册每册用知数人一名应完本折钱粮自赴比较与</span>  
<span style="margin-left: 1em">总经催人役无涉该区啚所存田亩各啚应纳银米责</span>  
<span style="margin-left: 1em">在经催一人其苦乐繇本啚人户之完欠而人户之完</span>  
<span style="margin-left: 1em">欠又系该啚田地之高下本年收成之丰歉更有经催</span>  
<span style="margin-left: 1em">善良而人户奸顽者则任意拖赖而累归经催又有人</span>  
<span style="margin-left: 1em">户善良而经催奸巧者则私侵入已托名民欠钱粮不</span>  
<span style="margin-left: 1em">起皆由二弊是役也自今年十月开征至明年十月完</span>  
<span style="margin-left: 1em">限如数尽足尚有匝岁奔走之劳而民欠难完往往堕</span>  
<span style="margin-left: 1em">悮甚有四五年尚未清楚者沿乡催办则有跋涉之苦</span>  
<span style="margin-left: 1em">入城比限则有盘缠之苦完不如数又有血杖之苦田</span>  
<span style="margin-left: 1em">地抛荒又有拖欠之苦人户逃亡有代赔之苦若遇水</span>  
<span style="margin-left: 1em">旱凶年钱粮无出举一啚之困苦独萃于一人破身亡</span>  
<span style="margin-left: 1em">家卖妻鬻子累月穷年未能脱累故百亩以下人户充</span>  
<span style="margin-left: 1em">此一役犹虑不堪若以零星数亩之户朋充未有不立</span>  
<span style="margin-left: 1em">毙者也</span>  
<span style="margin-left: 2em">万历己酉华亭聂公绍昌经催议　松郡之役莫苦</span>  
<span style="margin-left: 2em">于经催经催不过于一啚十排年之中挨次轮办而</span>  
<span style="margin-left: 2em">一啚之钱粮起总尽责其身十日一限一身在乡催</span>  
<span style="margin-left: 2em">办一身到县应比所以近之有分身催比之难有上</span>  
<span style="margin-left: 2em">城下郭衙门押保之难有代人赔貱之难远之有几</span>  
<span style="margin-left: 2em">年征欠之难有十年查盘纳罪之难是以承此役者</span>  
<span style="margin-left: 2em">身家多丧总之大患有二一在拖欠一在侵欺染于</span>  
<span style="margin-left: 2em">经催为侵欺逋于民间为拖欠不问细民之完多完</span>  
<span style="margin-left: 2em">少而惟经催之是责则良者空自为良顽者落得为</span>  
<span style="margin-left: 2em">顽所以敲朴愈多而负课愈甚殊不知经催特输役</span>  
<span style="margin-left: 2em">之人有何罪而代奸顽受此箠楚哉欲除拖欠惟在</span>  
<span style="margin-left: 2em">于明悉细户而欲除顽户侵欺其要在明摘欠户今</span>  
<span style="margin-left: 2em">细户之纳与不纳茫无查考而徒寄出纳完欠之分</span>  
<span style="margin-left: 2em">数于总书柜书之手任其糢糊出人种种奸弊即有</span>  
<span style="margin-left: 2em">神明莫能搜剔原头总繇实征细册上下茫然纳者</span>  
<span style="margin-left: 2em">不知其纳侵者难究其侵县官之神日疲而侵赖之</span>  
<span style="margin-left: 2em">害日炽今本职议欲于各区各啚立一实征细户田</span>  
<span style="margin-left: 2em">粮册每区总催开列啚总一册一样二本一本发总</span>  
<span style="margin-left: 2em">催收执一本存县发柜上收执此册先开一区钱粮</span>  
<span style="margin-left: 2em">总数次开各啚钱粮总数即就一啚分为十限每限</span>  
<span style="margin-left: 2em">总催于各啚名下开其完欠完者开其实数若干写</span>  
<span style="margin-left: 2em">如数二字欠者开其实欠若干写不如数三字又将</span>  
<span style="margin-left: 2em">入户田数照依虎头鼠尾列其多者于前少者于后</span>  
<span style="margin-left: 2em">以凭比较其点拘顽户先拘其田粮最多者次及其</span>  
<span style="margin-left: 2em">田粮少者虽有先后决无幸免官甲囤户亦准此</span>  
<span style="margin-left: 2em">抚台周公孔教征粮缓急议　钱粮之中有起存起</span>  
<span style="margin-left: 2em">存之中有缓急率凭吏书那移作弊先其所缓后其</span>  
<span style="margin-left: 2em">所急以致上供紧要反多不完今后各州县额征粮</span>  
<span style="margin-left: 2em">除本色务要当年完足外其折色银造简明手册二</span>  
<span style="margin-left: 2em">本要见某州县某项折银若干系紧急某项折银若</span>  
<span style="margin-left: 2em">干系稍缓不拘夏税秋粮料价徭里起运存留逐项</span>  
<span style="margin-left: 2em">细开通共该银若干分为二十限使民一目了然便</span>  
<span style="margin-left: 2em">于输纳至于存留内若各役对支工食即米麦布艸</span>  
<span style="margin-left: 2em">之类许其作价收完不得刁难小民作拖欠累违者</span>  
<span style="margin-left: 2em">定行拏究吴中小民困苦譬之一碗饭以渐而食人</span>  
<span style="margin-left: 2em">不致噎若并食恐不能堪宜体此意</span>  
<span style="margin-left: 2em">崇祯己巳华亭郑公友玄酌议赋役以甦民困八欵</span>  
<span style="margin-left: 2em">总申照得五茸一邑人不尽饶地不加腴而布缕粟</span>  
<span style="margin-left: 2em">米力役兼征焉重以逋赋则民苦益甚此时即不敢</span>  
<span style="margin-left: 2em">轻言减赋息役亦犹有长吏所得行者在也县司自</span>  
<span style="margin-left: 2em">青浦移此迄逾数载仰见上台忧民之诚发于声颜</span>  
<span style="margin-left: 2em">笔舌则愧无寸长抚绥以康厥庶民者今酌陈一二</span>  
<span style="margin-left: 2em">特据其己见已行下狥民请以为地方久计非有异</span>  
<span style="margin-left: 2em">政也实亦不敢喜事振矫上饰明德伏乞俯赐批示</span>  
<span style="margin-left: 2em">勒石施行一轻粮定派荒区议赋也布解北运区运</span>  
<span style="margin-left: 2em">收银四者议役也里甲塘长义米三项则赋役兼之</span>  
<span style="margin-left: 2em">次列本役之后</span>  
<span style="margin-left: 3em">一经催十甲均办议　本县本折额赋几及五十</span>  
<span style="margin-left: 3em">万其里甲计共八十区六百三十啚每啚排年十</span>  
<span style="margin-left: 3em">名分办十年一劳九逸其比较亦云简便法似可</span>  
<span style="margin-left: 3em">久然逋赋因之愈甚经催之累遂至鬻产破家而</span>  
<span style="margin-left: 3em">莫支盖因十甲轮役彼此互欠则承役之年一人</span>  
<span style="margin-left: 3em">代十甲以偿逋而中人之产立尽且充役如此其</span>  
<span style="margin-left: 3em">苦则大家啚卸目前利人包办而无田赤棍恣意</span>  
<span style="margin-left: 3em">索贴贴一入手恣意收侵幸而催科稍宽则募人</span>  
<span style="margin-left: 3em">代杖了事万一差追紧逼携家以逃而官仍问之</span>  
<span style="margin-left: 3em">正身必更鬻产赔纳虽大家亦破矣且一啚并额</span>  
<span style="margin-left: 3em">多至数百金万不得已而差一衙役押追见其重</span>  
<span style="margin-left: 3em">逋不能即完亦溪壑其欲勒骗酒食遂至取给正</span>  
<span style="margin-left: 3em">赋以供之而所逋益不能完困累终年官民愁叹</span>  
<span style="margin-left: 3em">其流弊殆不可胜言然岂民尽无良哉盖一人拖</span>  
<span style="margin-left: 3em">赖则九甲必至互欠九甲欠而一人偿则役断难</span>  
<span style="margin-left: 3em">充而包揽无赖侵逃相寻虽有淳民亦末如之何</span>  
<span style="margin-left: 3em">也今本县新编里甲搜查诡寄一按田籍授之以</span>  
<span style="margin-left: 3em">役则包揽无繇呈身且一人分办一甲额轻户少</span>  
<span style="margin-left: 3em">不待厉禁而朋赖包侵之弊俱绝第往年一人应</span>  
<span style="margin-left: 3em">比今骤增十人比较似属纷沓然往年一月两限</span>  
<span style="margin-left: 3em">者改省一月一限则淳良安枕乐于上纳又每限</span>  
<span style="margin-left: 3em">止摘其极欠者榜示赴比甚者押令全完则淳役</span>  
<span style="margin-left: 3em">趋早完之便顽役畏不完之害人情鼓舞易于终</span>  
<span style="margin-left: 3em">事即或鞭朴不废总为顽民设法较之溷比溷追</span>

<span style="margin-left: 2em">御史娄江钱公桓民运疏　窃惟南直苏松常三府</span>  
<span style="margin-left: 2em">浙江嘉湖二府岁输白粮二十一万四千八百余石</span>

<span style="margin-left: 2em">以里即责成州县官督令粮长舂办包完十二月以</span>  
<span style="margin-left: 2em">里即责成部运官督粮长装载开行有不遵者即绳</span>  
<span style="margin-left: 2em">以法夫民船自备原与军船不同若民运先行与军</span>  
<span style="margin-left: 2em">运不碍况白粮数少不过二十分中之一分耳船少</span>  
<span style="margin-left: 2em">则启行自速行早则守冻无虞如是而白粮犹不早</span>  
<span style="margin-left: 2em">完职请伏妄言之诛矣</span>  
<span style="margin-left: 2em">给事中练川归公子顾民运疏　国家之赋役莫重</span>  
<span style="margin-left: 2em">于东南而赋役之艰难莫重于民运职生三吴自为</span>  
<span style="margin-left: 2em">诸生时即知北运之苦试举其受累之大有三一曰</span>  
<span style="margin-left: 2em">水脚之侵没二曰沿途之需诈三曰交纳之留难夫</span>  
<span style="margin-left: 2em">运粮之有水脚每船不下百金似亦可济舂办之耗</span>  
<span style="margin-left: 2em">折长途之劳费交纳之赔偿独奈何侵渔者众也米</span>  
<span style="margin-left: 2em">未下船而先盘诘牌票百出索取千方船尚未募而</span>  
<span style="margin-left: 2em">妄为好歹胥吏哆口而谈县令拱手而听各官原有</span>  
<span style="margin-left: 2em">费额另纳公堂使费银两各项原有编银复索轿夫</span>  
<span style="margin-left: 2em">修船工食既有总部协部之官已而添官押役原有</span>  
<span style="margin-left: 2em">儧运催运之役已而添役押帮且扛头把持而水手</span>

<span style="margin-left: 2em">水脚已耗其过半矣是水脚之侵费不可不重加裁</span>  
<span style="margin-left: 2em">革也至如粮船之行往返六千余里涉险数十余处</span>  
<span style="margin-left: 2em">民已不胜匍匐而皇店皇木之暴戾抑勒关津闸坝</span>  
<span style="margin-left: 2em">之阻滞留难快船官座船之欺凌需索重至叠出不</span>

<span style="margin-left: 2em">何为者也况淮安之验验其少少则罪之通州之验</span>
