## 崇禎松江府志卷之五十四　著述

<span style="margin-left: 3em">著述</span>  
<span style="margin-left: 1em">班孟堅創藝文志列名氏不錄其文蓋文不可勝載也</span>  
<span style="margin-left: 1em">吾郡自漢魏以來作者代興豈不家金鑄而户絲繡哉</span>  
<span style="margin-left: 1em">惜秘藏于笥櫝而漏落于誰何手者未能一一訪求耳</span>  
<span style="margin-left: 1em">嗟乎著述如野燒草灰而根存亦復如夜書燭滅而字</span>  
<span style="margin-left: 1em">在故藝文不勝錄而錄著述之名氏焉讀其書知其人</span>  
<span style="margin-left: 1em">矣</span>  
<span style="margin-left: 1em">渾天圖註易釋玄漢鬱林太守陸績著</span>  
<span style="margin-left: 1em">言道審幾娱賓九思近百篇西州清論吳散騎常侍陸</span>  
<span style="margin-left: 1em">喜著</span>  
<span style="margin-left: 2em">陳氏曰喜吳人也生平慕諸葛孔明故西州清論借</span>  
<span style="margin-left: 2em">其名以行</span>  
<span style="margin-left: 1em">陸士衡集十卷晉陸機著</span>  
<span style="margin-left: 2em">晁公武讀書志曰機少有異才文章冠世所著文章</span>  
<span style="margin-left: 2em">凡三百餘篇今存詩賦論議箋表碑誄一百七十餘</span>  
<span style="margin-left: 2em">首以晉書文選校正外餘多舛誤</span>  
<span style="margin-left: 1em">陸士龍集十卷陸雲著</span>  
<span style="margin-left: 2em">晁氏曰雲六歲能屬文與機齊名雖文章不及而持</span>  
<span style="margin-left: 2em">論過之所著文章三百四十九篇新書十篇宋華亭</span>  
<span style="margin-left: 2em">令徐民瞻重刻二陸集于華亭有序</span>  
<span style="margin-left: 1em">文筆數十卷季鷹張翰著</span>  
<span style="margin-left: 1em">玉篇三十卷輿地志三十卷符瑞圖十卷顧氏譜傳十</span>  
<span style="margin-left: 1em">卷分野樞要一卷續洞冥記一卷玄象表一卷通史要</span>  
<span style="margin-left: 1em">略一百卷國史記傳二百卷顧野王著</span>  
<span style="margin-left: 2em">上玉篇啓昔者庖犧始成八卦暨乎蒼頡肇創六爻</span>  
<span style="margin-left: 2em">政罷結繩教興書契天粟晝零市妖夜哭繇來尚矣</span>  
<span style="margin-left: 2em">爰至玄龜龍馬負河洛之圖赤雀素鱗標受終之命</span>  
<span style="margin-left: 2em">鳳羽爲字掌理成書豈得人功亦猶夫授故能傳流</span>  
<span style="margin-left: 2em">奥典鉤深至賾揚顯聖謨耀光洪範文遺百代則禮</span>  
<span style="margin-left: 2em">樂可知驛宣萬里則心言可述授民軌物則縣方象</span>  
<span style="margin-left: 2em">魏興功命衆則誓威師旅律存三尺政仰八成聽稱</span>  
<span style="margin-left: 2em">責於附別執士師於兩造勒功名於鐘鼎頌美德於</span>  
<span style="margin-left: 2em">神祇故百官以治萬民以察雕金鏤玉升崧岱而告</span>  
<span style="margin-left: 2em">平汗竹裁縑寫憲章而授政莫不以版牘施於經緯</span>  
<span style="margin-left: 2em">文字表於無窮者矣所以垂帷閉户而覿遐年之世</span>  
<span style="margin-left: 2em">藏形晦迹而識遠方之風遵覽篆素以測九垓則靡</span>  
<span style="margin-left: 2em">差膚寸詳觀純錄以遊八裔則不謬毫釐鑒水鏡於</span>  
<span style="margin-left: 2em">往謨遺元龜於今體仰瞻景行式備音文戒慎荒邪</span>  
<span style="margin-left: 2em">用存古典故說教施法無以尚兹經世治俗豈先乎</span>  
<span style="margin-left: 2em">此但微言既絶大旨亦乖故五典三墳競開異義六</span>  
<span style="margin-left: 2em">書八體今古殊形或字各而訓同或文均而釋異百</span>  
<span style="margin-left: 2em">家所談差誤不少字書卷軸舛錯尤多難用尋求易</span>  
<span style="margin-left: 2em">生疑惑猥承明命預纘過庭總會衆篇校讐群籍以</span>  
<span style="margin-left: 2em">成一家之制文字之訓備矣而學慚精博聞見尤寡</span>  
<span style="margin-left: 2em">才非通敏理辭彌躓既謬先蹤且乖聖旨謹當端笏</span>  
<span style="margin-left: 2em">擁篲以俟嘉猷</span>  
<span style="margin-left: 2em">竊聞兩儀俶啟九皇始君情性初動有巢肇制三聖</span>  
<span style="margin-left: 2em">代立十絶遞興龍牒浮河龜書起洛八卦既陳六爻</span>  
<span style="margin-left: 2em">攸叙篆素之流是焉而出至於精課源妙求其本始</span>  
<span style="margin-left: 2em">末學膚淺誠所未詳雖復研考六經校讐百氏殊非</span>  
<span style="margin-left: 2em">庸菲所能與奪謹依條例同異具以上呈伏惟聖皇</span>  
<span style="margin-left: 2em">馭㝢膺籙受圖德尚昊軒功造嬀姒通妙廣運乃聖</span>  
<span style="margin-left: 2em">乃神經天曰文止戈爲武百工維理庶績咸熙勸以</span>  
<span style="margin-left: 2em">九歌撝之八柄修文德以來要服舞干戚以格有苗</span>  
<span style="margin-left: 2em">是故仁風所扇九服蒙靈正朔可班四荒懷德取衣</span>  
<span style="margin-left: 2em">雒樹則肅慎識受命之興夷波海水則越裳知聖人</span>  
<span style="margin-left: 2em">之德豈但中和樂職近播岷峨德廣所覃旁流江漢</span>  
<span style="margin-left: 2em">殿下天縱岳峙叡哲淵凝三善自然匪須勤學六行</span>  
<span style="margin-left: 2em">前哲寧以勞喻是以聲覃八表譽決九垓規範百司</span>  
<span style="margin-left: 2em">陶鈞萬品猶復留心圖籍俛情篆素糾先民之積繆</span>  
<span style="margin-left: 2em">振往古之重疑簡册所傳莫今比盛野王沾濡聖道</span>  
<span style="margin-left: 2em">沐浴康衢不揆愚淺妄陳狂狷徒夢收腸終當覆瓿</span>  
<span style="margin-left: 2em">空思朱墨懼必無傳悚悸交心罔知攸錯</span>  
<span style="margin-left: 1em">禮疏一百卷禇輝著</span>  
<span style="margin-left: 1em">五經微旨十四卷孟子義音三卷張鎰著</span>  
<span style="margin-left: 1em">逋翁集二十卷顧況著</span>  
<span style="margin-left: 2em">皇甫湜序云吳中山泉氣狀英淑怪麗太湖異石洞</span>  
<span style="margin-left: 2em">庭朱實華亭清唳與虎丘天竺諸佛寺鈞錦秀絶君</span>  
<span style="margin-left: 2em">出其中間翕輕清以爲性結泠汰以爲質喣鮮榮以</span>  
<span style="margin-left: 2em">爲詞偏於逸歌長句駿發踔厲往往若穿天心出月</span>  
<span style="margin-left: 2em">脇意外驚人語非尋常所能及最爲快也李白杜甫</span>  
<span style="margin-left: 2em">已死非君將誰與哉湜以童子見君揚州孝感寺君</span>  
<span style="margin-left: 2em">披黃衫白絹鞳頭眸子瞭然烱烱清立望之真白珪</span>  
<span style="margin-left: 2em">振鷺也既接歡然以我爲揚雄孟軻顧恨不及見三</span>  
<span style="margin-left: 2em">十年于兹矣知音之厚曷嘗忘諸</span>  
<span style="margin-left: 2em">陳氏曰湜嘗言吾自爲顧況作序未常許他人況在</span>  
<span style="margin-left: 2em">唐爲人推重如此集本一十五卷今止五卷</span>  
<span style="margin-left: 1em">禮志十卷丁公著著</span>  
<span style="margin-left: 1em">陸宣公奏議十三卷唐陸贄著<sub class="note-yuan">別有集古驗方</sub></span>  
<span style="margin-left: 2em">晁氏曰舊翰苑集外有牓子集五卷議論集三卷元</span>  
<span style="margin-left: 2em">祐中蘇子瞻乞校正進呈改從今名疑是時裒諸集</span>  
<span style="margin-left: 2em">以成云</span>  
<span style="margin-left: 2em">東坡蘇氏乞校正陸贄奏議劄子曰臣等猥以空疎</span>  
<span style="margin-left: 2em">備員講讀聖明天縱學問日新臣等才有限而道無</span>  
<span style="margin-left: 2em">窮心欲言而口不逮以此自媿莫知所爲竊謂人臣</span>  
<span style="margin-left: 2em">之納忠譬如醫者之用藥藥雖進於醫手方多傳於</span>  
<span style="margin-left: 2em">古人若以經效於世間不必皆從於己出伏見唐宰</span>  
<span style="margin-left: 2em">相陸贄才本王佐學爲帝師論深切於事情言不離</span>  
<span style="margin-left: 2em">於道德智如子房而文則過辯如賈誼而術不疎上</span>  
<span style="margin-left: 2em">以格君心之非下以通天下之志但其不幸仕不遇</span>  
<span style="margin-left: 2em">時德宗以苛刻爲能而贄諫之以忠厚德宗以猜疑</span>  
<span style="margin-left: 2em">爲術而贄勸之以推誠德宗好用兵而贄以消兵爲</span>  
<span style="margin-left: 2em">先德宗好聚斂而贄以散財爲急至於用人聽言之</span>  
<span style="margin-left: 2em">法治邊馭將之方罪己以收入心改過以應天道去</span>  
<span style="margin-left: 2em">小人以除民患惜名器以待有功如斯之流未易悉</span>  
<span style="margin-left: 2em">數可謂進苦口之藥石鍼害身之膏肓使德宗盡用</span>  
<span style="margin-left: 2em">其言則貞觀可得而復臣等每退自西閣即相與告</span>  
<span style="margin-left: 2em">言以陛下聖明必喜贄議論但使聖賢之相契即如</span>  
<span style="margin-left: 2em">臣主之同時昔馮唐論頗牧之賢則漢文爲之太息</span>  
<span style="margin-left: 2em">魏相條晁董之對則孝宣以致中興若陛下能自得</span>  
<span style="margin-left: 2em">師莫若近取諸贄夫六經三史諸子百家非無可觀</span>  
<span style="margin-left: 2em">皆足爲治但聖言幽遠末學支離譬如山海之崇深</span>  
<span style="margin-left: 2em">難以一二而推擇如贄之論開卷了然聚古今之精</span>  
<span style="margin-left: 2em">英實治亂之龜鑑臣等欲取其奏議稍加校正繕寫</span>  
<span style="margin-left: 2em">進呈願陛下置之坐隅如見贄面反覆熟讀如與贄</span>  
<span style="margin-left: 2em">言必能發聖性之高明成治功於歲月</span>  
<span style="margin-left: 2em">陳氏曰權德輿爲之序稱制誥集十三卷奏章七卷</span>  
<span style="margin-left: 2em">中書奏議七卷今所存者翰苑集十卷牓子集十二</span>  
<span style="margin-left: 2em">卷序又稱別集文賦表狀十五卷今不傳</span>  
<span style="margin-left: 2em">朱子語錄曰陸宣公奏議極好看這人極會議論事</span>  
<span style="margin-left: 2em">理委曲說盡更無滲漏雖至小底事被他處置得亦</span>  
<span style="margin-left: 2em">無不盡如後面所論二稅之弊極佳人言陸宣公口</span>  
<span style="margin-left: 2em">說不出只是寫得出今觀奏議中多云今日早面奏</span>  
<span style="margin-left: 2em">聖旨云云臣退而思之云云疑或然也</span>  
<span style="margin-left: 2em">楊誠齋跋云陸宣公之貶也杜門集古方書而已或</span>  
<span style="margin-left: 2em">曰避謗者歟或曰窮而不怨也楊子曰宣公之心利</span>  
<span style="margin-left: 2em">天下而已矣其用也則醫之以奏議其不用也則醫</span>  
<span style="margin-left: 2em">之以方書有用有不用者宣公之身也宣公之心亦</span>  
<span style="margin-left: 2em">有用有不用乎哉</span>  
<span style="margin-left: 1em">笠澤叢書陸龜蒙著<sub class="note-yuan">別有小名錄三卷松林集十卷</sub></span>  
<span style="margin-left: 2em">自序云叢書者叢脞之書也叢脞猶細碎也細而不</span>  
<span style="margin-left: 2em">遺大可知其所容也乾符六年春臥于笠澤之藪敗</span>  
<span style="margin-left: 2em">屋數間蓋蠧書十餘篋帕<sub class="note-yuan">集作伯</sub>男兒裁三尺許長䃣</span>  
<span style="margin-left: 2em">齒猶未遍教以藥劑象梧子大小外研墨泚筆供紙</span>  
<span style="margin-left: 2em">札而已體中不甚<sub class="note-yuan">集作堪</sub>羸耄時亦隱几强坐內壹鬱</span>  
<span style="margin-left: 2em">則外揚爲聲音歌詩賦額銘記傳叙往往雜發不類</span>  
<span style="margin-left: 2em">不次渾而載之得稱爲叢書自當<sub class="note-yuan">去聲</sub>諼<sub class="note-yuan">集作緩</sub>憂之一</span>  
<span style="margin-left: 2em">物非敢露世家耳目凡所諱其中畧無避焉</span>  
<span style="margin-left: 2em">晁氏曰龜蒙以末世有官名小名之別自秦至隋編</span>  
<span style="margin-left: 2em">而記之至於神仙玉女之名婦人臧獲之字亦無棄</span>  
<span style="margin-left: 2em">焉龜蒙世稱其博然此書特雜取於史傳間爾無異</span>  
<span style="margin-left: 2em">聞也</span>  
<span style="margin-left: 2em">晁氏曰唐陸龜蒙與皮日休酬唱詩凡六百五十八</span>  
<span style="margin-left: 2em">首</span>  
<span style="margin-left: 1em">朱倣詩一卷唐朱倣著</span>  
<span style="margin-left: 2em">朱倣字長通襄陽人隱居剡溪後流寓雲間嗣曹王</span>  
<span style="margin-left: 2em">臯鎮江西辟節度參謀貞元初召爲拾遺不就顧況</span>  
<span style="margin-left: 2em">有序</span>  
<span style="margin-left: 1em">漁歌碑傳集錄玄真子著</span>  
<span style="margin-left: 2em">陳氏曰玄真子漁歌世上傳誦其西塞山前一章而</span>  
<span style="margin-left: 2em">已嘗得其一時唱和諸賢之辭各五章及南卓柳宗</span>  
<span style="margin-left: 2em">元所賦通爲若干章因以顔魯公碑述唐書本傳以</span>  
<span style="margin-left: 2em">至近世用其詞入樂府者集爲一編</span>  
<span style="margin-left: 1em">陳都官集三十卷廬山記五卷陳舜俞著</span>  
<span style="margin-left: 2em">陳氏曰都官員外郎陳舜俞令舉嘉祐四年制科以</span>  
<span style="margin-left: 2em">言新法謫官南康與劉凝之騎牛游廬山詩畫皆傳</span>  
<span style="margin-left: 2em">於世初從安定胡先生學熙寧中六客其一也</span>  
<span style="margin-left: 2em">晁氏曰先是劉焕嘗爲廬山記令舉因而增廣之又</span>  
<span style="margin-left: 2em">爲俯視圖紀尋山先後之次云劉焕凝之李常公擇</span>  
<span style="margin-left: 2em">皆爲之序令舉熙寧中謫居所作</span>  
<span style="margin-left: 1em">廣孟子說養氣論三篇毛詩訓解二十卷孟子講義十</span>  
<span style="margin-left: 1em">四卷文集五十卷史贊論五卷朝奉大夫李撰著</span>  
<span style="margin-left: 1em">梁溪集一百二十卷李忠定公奏議靖康傳信錄梁溪</span>  
<span style="margin-left: 1em">易傳外篇宋丞相李綱著</span>  
<span style="margin-left: 2em">鄭太史鄤序畧曰李忠定治兵之畧與武侯同而所</span>  
<span style="margin-left: 2em">遭際與鄴侯同決策內禪捍守京城時方爲太常非</span>  
<span style="margin-left: 2em">有特達之知也故虜騎未退而斥逐隨之至軍民爲</span>
