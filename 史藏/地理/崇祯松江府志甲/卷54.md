## 崇祯松江府志卷之五十四　著述

<span style="margin-left: 3em">著述</span>  
<span style="margin-left: 1em">班孟坚创艺文志列名氏不录其文盖文不可胜载也</span>  
<span style="margin-left: 1em">吾郡自汉魏以来作者代兴岂不家金铸而户丝绣哉</span>  
<span style="margin-left: 1em">惜秘藏于笥椟而漏落于谁何手者未能一一访求耳</span>  
<span style="margin-left: 1em">嗟乎著述如野烧草灰而根存亦复如夜书烛灭而字</span>  
<span style="margin-left: 1em">在故艺文不胜录而录著述之名氏焉读其书知其人</span>  
<span style="margin-left: 1em">矣</span>  
<span style="margin-left: 1em">浑天图注易释玄汉郁林太守陆绩著</span>  
<span style="margin-left: 1em">言道审几娱宾九思近百篇西州清论吴散骑常侍陆</span>  
<span style="margin-left: 1em">喜著</span>  
<span style="margin-left: 2em">陈氏曰喜吴人也生平慕诸葛孔明故西州清论借</span>  
<span style="margin-left: 2em">其名以行</span>  
<span style="margin-left: 1em">陆士衡集十卷晋陆机著</span>  
<span style="margin-left: 2em">晁公武读书志曰机少有异才文章冠世所著文章</span>  
<span style="margin-left: 2em">凡三百余篇今存诗赋论议笺表碑诔一百七十余</span>  
<span style="margin-left: 2em">首以晋书文选校正外余多舛误</span>  
<span style="margin-left: 1em">陆士龙集十卷陆云著</span>  
<span style="margin-left: 2em">晁氏曰云六岁能属文与机齐名虽文章不及而持</span>  
<span style="margin-left: 2em">论过之所著文章三百四十九篇新书十篇宋华亭</span>  
<span style="margin-left: 2em">令徐民瞻重刻二陆集于华亭有序</span>  
<span style="margin-left: 1em">文笔数十卷季鹰张翰著</span>  
<span style="margin-left: 1em">玉篇三十卷舆地志三十卷符瑞图十卷顾氏谱传十</span>  
<span style="margin-left: 1em">卷分野枢要一卷续洞冥记一卷玄象表一卷通史要</span>  
<span style="margin-left: 1em">略一百卷国史记传二百卷顾野王著</span>  
<span style="margin-left: 2em">上玉篇启昔者庖牺始成八卦暨乎苍颉肇创六爻</span>  
<span style="margin-left: 2em">政罢结绳教兴书契天粟昼零市妖夜哭繇来尚矣</span>  
<span style="margin-left: 2em">爰至玄龟龙马负河洛之图赤雀素鳞标受终之命</span>  
<span style="margin-left: 2em">凤羽为字掌理成书岂得人功亦犹夫授故能传流</span>  
<span style="margin-left: 2em">奥典钩深至赜扬显圣谟耀光洪范文遗百代则礼</span>  
<span style="margin-left: 2em">乐可知驿宣万里则心言可述授民轨物则县方象</span>  
<span style="margin-left: 2em">魏兴功命众则誓威师旅律存三尺政仰八成听称</span>  
<span style="margin-left: 2em">责于附别执士师于两造勒功名于钟鼎颂美德于</span>  
<span style="margin-left: 2em">神祇故百官以治万民以察雕金镂玉升崧岱而告</span>  
<span style="margin-left: 2em">平汗竹裁缣写宪章而授政莫不以版牍施于经纬</span>  
<span style="margin-left: 2em">文字表于无穷者矣所以垂帷闭户而觌遐年之世</span>  
<span style="margin-left: 2em">藏形晦迹而识远方之风遵览篆素以测九垓则靡</span>  
<span style="margin-left: 2em">差肤寸详观纯录以游八裔则不谬毫厘鉴水镜于</span>  
<span style="margin-left: 2em">往谟遗元龟于今体仰瞻景行式备音文戒慎荒邪</span>  
<span style="margin-left: 2em">用存古典故说教施法无以尚兹经世治俗岂先乎</span>  
<span style="margin-left: 2em">此但微言既绝大旨亦乖故五典三坟竞开异义六</span>  
<span style="margin-left: 2em">书八体今古殊形或字各而训同或文均而释异百</span>  
<span style="margin-left: 2em">家所谈差误不少字书卷轴舛错尤多难用寻求易</span>  
<span style="margin-left: 2em">生疑惑猥承明命预缵过庭总会众篇校讐群籍以</span>  
<span style="margin-left: 2em">成一家之制文字之训备矣而学惭精博闻见尤寡</span>  
<span style="margin-left: 2em">才非通敏理辞弥踬既谬先踪且乖圣旨谨当端笏</span>  
<span style="margin-left: 2em">拥篲以俟嘉猷</span>  
<span style="margin-left: 2em">窃闻两仪俶启九皇始君情性初动有巢肇制三圣</span>  
<span style="margin-left: 2em">代立十绝递兴龙牒浮河龟书起洛八卦既陈六爻</span>  
<span style="margin-left: 2em">攸叙篆素之流是焉而出至于精课源妙求其本始</span>  
<span style="margin-left: 2em">末学肤浅诚所未详虽复研考六经校讐百氏殊非</span>  
<span style="margin-left: 2em">庸菲所能与夺谨依条例同异具以上呈伏惟圣皇</span>  
<span style="margin-left: 2em">驭㝢膺箓受图德尚昊轩功造妫姒通妙广运乃圣</span>  
<span style="margin-left: 2em">乃神经天曰文止戈为武百工维理庶绩咸熙劝以</span>  
<span style="margin-left: 2em">九歌㧑之八柄修文德以来要服舞干戚以格有苗</span>  
<span style="margin-left: 2em">是故仁风所扇九服蒙灵正朔可班四荒怀德取衣</span>  
<span style="margin-left: 2em">雒树则肃慎识受命之兴夷波海水则越裳知圣人</span>  
<span style="margin-left: 2em">之德岂但中和乐职近播岷峨德广所覃旁流江汉</span>  
<span style="margin-left: 2em">殿下天纵岳峙叡哲渊凝三善自然匪须勤学六行</span>  
<span style="margin-left: 2em">前哲宁以劳喻是以声覃八表誉决九垓规范百司</span>  
<span style="margin-left: 2em">陶钧万品犹复留心图籍俛情篆素纠先民之积缪</span>  
<span style="margin-left: 2em">振往古之重疑简册所传莫今比盛野王沾濡圣道</span>  
<span style="margin-left: 2em">沐浴康衢不揆愚浅妄陈狂狷徒梦收肠终当覆瓿</span>  
<span style="margin-left: 2em">空思朱墨惧必无传悚悸交心罔知攸错</span>  
<span style="margin-left: 1em">礼疏一百卷禇辉著</span>  
<span style="margin-left: 1em">五经微旨十四卷孟子义音三卷张镒著</span>  
<span style="margin-left: 1em">逋翁集二十卷顾况著</span>  
<span style="margin-left: 2em">皇甫湜序云吴中山泉气状英淑怪丽太湖异石洞</span>  
<span style="margin-left: 2em">庭朱实华亭清唳与虎丘天竺诸佛寺钧锦秀绝君</span>  
<span style="margin-left: 2em">出其中间翕轻清以为性结泠汰以为质喣鲜荣以</span>  
<span style="margin-left: 2em">为词偏于逸歌长句骏发踔厉往往若穿天心出月</span>  
<span style="margin-left: 2em">脇意外惊人语非寻常所能及最为快也李白杜甫</span>  
<span style="margin-left: 2em">已死非君将谁与哉湜以童子见君扬州孝感寺君</span>  
<span style="margin-left: 2em">披黄衫白绢鞳头眸子了然烱烱清立望之真白珪</span>  
<span style="margin-left: 2em">振鹭也既接欢然以我为扬雄孟轲顾恨不及见三</span>  
<span style="margin-left: 2em">十年于兹矣知音之厚曷尝忘诸</span>  
<span style="margin-left: 2em">陈氏曰湜尝言吾自为顾况作序未常许他人况在</span>  
<span style="margin-left: 2em">唐为人推重如此集本一十五卷今止五卷</span>  
<span style="margin-left: 1em">礼志十卷丁公著著</span>  
<span style="margin-left: 1em">陆宣公奏议十三卷唐陆贽著<sub class="note-yuan">别有集古验方</sub></span>  
<span style="margin-left: 2em">晁氏曰旧翰苑集外有牓子集五卷议论集三卷元</span>  
<span style="margin-left: 2em">祐中苏子瞻乞校正进呈改从今名疑是时裒诸集</span>  
<span style="margin-left: 2em">以成云</span>  
<span style="margin-left: 2em">东坡苏氏乞校正陆贽奏议札子曰臣等猥以空疎</span>  
<span style="margin-left: 2em">备员讲读圣明天纵学问日新臣等才有限而道无</span>  
<span style="margin-left: 2em">穷心欲言而口不逮以此自媿莫知所为窃谓人臣</span>  
<span style="margin-left: 2em">之纳忠譬如医者之用药药虽进于医手方多传于</span>  
<span style="margin-left: 2em">古人若以经效于世间不必皆从于己出伏见唐宰</span>  
<span style="margin-left: 2em">相陆贽才本王佐学为帝师论深切于事情言不离</span>  
<span style="margin-left: 2em">于道德智如子房而文则过辩如贾谊而术不疎上</span>  
<span style="margin-left: 2em">以格君心之非下以通天下之志但其不幸仕不遇</span>  
<span style="margin-left: 2em">时德宗以苛刻为能而贽谏之以忠厚德宗以猜疑</span>  
<span style="margin-left: 2em">为术而贽劝之以推诚德宗好用兵而贽以消兵为</span>  
<span style="margin-left: 2em">先德宗好聚敛而贽以散财为急至于用人听言之</span>  
<span style="margin-left: 2em">法治边驭将之方罪己以收入心改过以应天道去</span>  
<span style="margin-left: 2em">小人以除民患惜名器以待有功如斯之流未易悉</span>  
<span style="margin-left: 2em">数可谓进苦口之药石针害身之膏肓使德宗尽用</span>  
<span style="margin-left: 2em">其言则贞观可得而复臣等每退自西阁即相与告</span>  
<span style="margin-left: 2em">言以陛下圣明必喜贽议论但使圣贤之相契即如</span>  
<span style="margin-left: 2em">臣主之同时昔冯唐论颇牧之贤则汉文为之太息</span>  
<span style="margin-left: 2em">魏相条晁董之对则孝宣以致中兴若陛下能自得</span>  
<span style="margin-left: 2em">师莫若近取诸贽夫六经三史诸子百家非无可观</span>  
<span style="margin-left: 2em">皆足为治但圣言幽远末学支离譬如山海之崇深</span>  
<span style="margin-left: 2em">难以一二而推择如贽之论开卷了然聚古今之精</span>  
<span style="margin-left: 2em">英实治乱之龟鉴臣等欲取其奏议稍加校正缮写</span>  
<span style="margin-left: 2em">进呈愿陛下置之坐隅如见贽面反复熟读如与贽</span>  
<span style="margin-left: 2em">言必能发圣性之高明成治功于岁月</span>  
<span style="margin-left: 2em">陈氏曰权德舆为之序称制诰集十三卷奏章七卷</span>  
<span style="margin-left: 2em">中书奏议七卷今所存者翰苑集十卷牓子集十二</span>  
<span style="margin-left: 2em">卷序又称别集文赋表状十五卷今不传</span>  
<span style="margin-left: 2em">朱子语录曰陆宣公奏议极好看这人极会议论事</span>  
<span style="margin-left: 2em">理委曲说尽更无渗漏虽至小底事被他处置得亦</span>  
<span style="margin-left: 2em">无不尽如后面所论二税之弊极佳人言陆宣公口</span>  
<span style="margin-left: 2em">说不出只是写得出今观奏议中多云今日早面奏</span>  
<span style="margin-left: 2em">圣旨云云臣退而思之云云疑或然也</span>  
<span style="margin-left: 2em">杨诚斋跋云陆宣公之贬也杜门集古方书而已或</span>  
<span style="margin-left: 2em">曰避谤者欤或曰穷而不怨也杨子曰宣公之心利</span>  
<span style="margin-left: 2em">天下而已矣其用也则医之以奏议其不用也则医</span>  
<span style="margin-left: 2em">之以方书有用有不用者宣公之身也宣公之心亦</span>  
<span style="margin-left: 2em">有用有不用乎哉</span>  
<span style="margin-left: 1em">笠泽丛书陆龟蒙著<sub class="note-yuan">别有小名录三卷松林集十卷</sub></span>  
<span style="margin-left: 2em">自序云丛书者丛脞之书也丛脞犹细碎也细而不</span>  
<span style="margin-left: 2em">遗大可知其所容也乾符六年春卧于笠泽之薮败</span>  
<span style="margin-left: 2em">屋数间盖蠧书十余箧帕<sub class="note-yuan">集作伯</sub>男儿裁三尺许长䃣</span>  
<span style="margin-left: 2em">齿犹未遍教以药剂象梧子大小外研墨泚笔供纸</span>  
<span style="margin-left: 2em">札而已体中不甚<sub class="note-yuan">集作堪</sub>羸耄时亦隐几强坐内壹郁</span>  
<span style="margin-left: 2em">则外扬为声音歌诗赋额铭记传叙往往杂发不类</span>  
<span style="margin-left: 2em">不次浑而载之得称为丛书自当<sub class="note-yuan">去声</sub>谖<sub class="note-yuan">集作缓</sub>忧之一</span>  
<span style="margin-left: 2em">物非敢露世家耳目凡所讳其中畧无避焉</span>  
<span style="margin-left: 2em">晁氏曰龟蒙以末世有官名小名之别自秦至隋编</span>  
<span style="margin-left: 2em">而记之至于神仙玉女之名妇人臧获之字亦无弃</span>  
<span style="margin-left: 2em">焉龟蒙世称其博然此书特杂取于史传间尔无异</span>  
<span style="margin-left: 2em">闻也</span>  
<span style="margin-left: 2em">晁氏曰唐陆龟蒙与皮日休酬唱诗凡六百五十八</span>  
<span style="margin-left: 2em">首</span>  
<span style="margin-left: 1em">朱倣诗一卷唐朱倣著</span>  
<span style="margin-left: 2em">朱倣字长通襄阳人隐居剡溪后流寓云间嗣曹王</span>  
<span style="margin-left: 2em">臯镇江西辟节度参谋贞元初召为拾遗不就顾况</span>  
<span style="margin-left: 2em">有序</span>  
<span style="margin-left: 1em">渔歌碑传集录玄真子著</span>  
<span style="margin-left: 2em">陈氏曰玄真子渔歌世上传诵其西塞山前一章而</span>  
<span style="margin-left: 2em">已尝得其一时唱和诸贤之辞各五章及南卓柳宗</span>  
<span style="margin-left: 2em">元所赋通为若干章因以颜鲁公碑述唐书本传以</span>  
<span style="margin-left: 2em">至近世用其词入乐府者集为一编</span>  
<span style="margin-left: 1em">陈都官集三十卷庐山记五卷陈舜俞著</span>  
<span style="margin-left: 2em">陈氏曰都官员外郎陈舜俞令举嘉祐四年制科以</span>  
<span style="margin-left: 2em">言新法谪官南康与刘凝之骑牛游庐山诗画皆传</span>  
<span style="margin-left: 2em">于世初从安定胡先生学熙宁中六客其一也</span>  
<span style="margin-left: 2em">晁氏曰先是刘焕尝为庐山记令举因而增广之又</span>  
<span style="margin-left: 2em">为俯视图纪寻山先后之次云刘焕凝之李常公择</span>  
<span style="margin-left: 2em">皆为之序令举熙宁中谪居所作</span>  
<span style="margin-left: 1em">广孟子说养气论三篇毛诗训解二十卷孟子讲义十</span>  
<span style="margin-left: 1em">四卷文集五十卷史赞论五卷朝奉大夫李撰著</span>  
<span style="margin-left: 1em">梁溪集一百二十卷李忠定公奏议靖康传信录梁溪</span>  
<span style="margin-left: 1em">易传外篇宋丞相李纲著</span>  
<span style="margin-left: 2em">郑太史鄤序畧曰李忠定治兵之畧与武侯同而所</span>  
<span style="margin-left: 2em">遭际与邺侯同决策内禅捍守京城时方为太常非</span>  
<span style="margin-left: 2em">有特达之知也故虏骑未退而斥逐随之至军民为</span>  
<span style="margin-left: 2em">公伏阙乃益蹈至危之机及乎虏退公可以行而公</span>  
<span style="margin-left: 2em">弗为也迎銮一事学术全本邺侯而上与下之疑皆</span>
