## 崇祯松江府志卷之三十一　宦绩四（国朝名宦）

<span style="margin-left: 3em">国朝名臣宦绩一</span>  
<span style="margin-left: 1em">正己率属察吏安民此台察座右铭也经师易得人师</span>  
<span style="margin-left: 1em">难求此博士座右铭也苟存心于爱物虽一命必有所</span>  
<span style="margin-left: 1em">济此幕尉座右铭也郡邑长何铭乎阳道州曰抚字心</span>  
<span style="margin-left: 1em">劳然不若抚字心闲行所无事则闲矣曰催科政拙更</span>  
<span style="margin-left: 1em">不若催科政巧知所先后则巧矣神而明之有先朝已</span>  
<span style="margin-left: 1em">事在</span>  
<span style="margin-left: 1em">汤和字鼎臣凤阳人洪武初年以信国公奉</span>  
<span style="margin-left: 1em">命治海务先是屡有倭警　上因方亚关献议命和缘</span>  
<span style="margin-left: 1em">海一带相度要冲建立卫所以防倭松江建金山卫于</span>  
<span style="margin-left: 1em">浙直交关处又迤东建青村所又东北建南汇所府城</span>  
<span style="margin-left: 1em">亦增守御千户所调发留都官军屯守旷处立墩堡遇</span>  
<span style="margin-left: 1em">警举烽传报络绎策应无令首尾疎虞二百余载来永</span>  
<span style="margin-left: 1em">赖其功<sub class="note-yuan">亚关方国珍次子也既归顺后献三郡海船水手数万因请缘海备御建设卫所延亘万里如金山青村等处皆其议云</sub></span>  
<span style="margin-left: 2em">和以春秋高思归故乡尝进对　上前从容乞骸骨</span>  
<span style="margin-left: 3em">上嘉之赐钞万锭俾建第于凤阳且谓和曰日本</span>  
<span style="margin-left: 2em">小夷屡扰濒海之民卿虽老强为朕一行视其要害</span>  
<span style="margin-left: 2em">地筑城增兵以固守备和奉　旨即行自闽越并海</span>  
<span style="margin-left: 2em">之地筑数十城而归至是新第成和率妻子陛辞往</span>  
<span style="margin-left: 2em">居之按信国之功于吾松为大若苏之卫所非其建</span>  
<span style="margin-left: 2em">也故上海报功之典当以信国为第一</span>  
<span style="margin-left: 1em">祝挺字正夫江西鄱阳人吴元年知上海县事会逆民</span>  
<span style="margin-left: 1em">钱鹤臯倡乱拘囚守令劫掠乡城挺怀印走府谋诛凶</span>  
<span style="margin-left: 1em">叛忽闻府城已陷乃仰天叹曰此我死所也效死弗去</span>  
<span style="margin-left: 1em">无何为贼所执正色谕之曰汝乃我之编民敢逼我耶</span>  
<span style="margin-left: 1em">吾有头在勿复言贼知不可屈释之乃密与主簿郑著</span>  
<span style="margin-left: 1em">李从吉等谋起义兵身自披坚执锐追斩伪总兵姚万</span>  
<span style="margin-left: 1em">户金于西沟函其首以献时主帅议罪胁从慷慨进言</span>  
<span style="margin-left: 1em">曰彼皆良民一时为其所逼奈何并诛之愿以身代罪</span>  
<span style="margin-left: 1em">复上状中书省反侧借以自安男女老幼驩呼踊跃提</span>  
<span style="margin-left: 1em">壶浆燃香烛拜伏道左迎公以归又明年司臬者毛责</span>  
<span style="margin-left: 1em">细故停其治三月士庶老稚日夜号泣走　阙下恸哭</span>  
<span style="margin-left: 1em">请命　上惊曰祝挺者向吾特选以治海邦而司臬敢</span>  
<span style="margin-left: 1em">忘之覆罪司臬挺复进用至今人犹思祝大夫后擢户</span>  
<span style="margin-left: 1em">部主事晋郎中</span>  
<span style="margin-left: 2em">杨维祯撰活民碑　上海淞附庸邑也其地薄海斥</span>  
<span style="margin-left: 2em">卤氓过半自有元百年教养之泽深民之为俗慕仁</span>  
<span style="margin-left: 2em">义者十室而九遂号善地丁未三月晦日邑忽有变</span>  
<span style="margin-left: 2em">大姓钱氏乌合起剪竿而槊结帨而斾斩关入淞城</span>  
<span style="margin-left: 2em">首杀长吏分遣其党率火伍犯邑请先杀邑长祝挺</span>  
<span style="margin-left: 2em">钱怒曰今日愤兵为翼虎殪吾民者起邑长祝使君</span>  
<span style="margin-left: 2em">我生身父母不翅敢有伤之者斩党又为诱语请侯</span>  
<span style="margin-left: 2em">见总兵所侯咈然曰吾有吾头请以头往尔氓独不</span>  
<span style="margin-left: 2em">闻我单骑入虎牙营不动声色祝奉使乎卒不为屑</span>  
<span style="margin-left: 2em">侯揣知乌合必溃乃自为教密遣人布长里者曰逆</span>  
<span style="margin-left: 2em">顺祸福非天也人自取也有能为我擒贼复县者吾</span>  
<span style="margin-left: 2em">上汝功教至巨室匿备械舣大艘渡侯黄龙东植义</span>  
<span style="margin-left: 2em">旗率民听约束民皆啮指血誓効顺党亦投戈于地</span>  
<span style="margin-left: 2em">羝跪义旗下请死罪邑治遂复时四月五日也党率</span>  
<span style="margin-left: 2em">其众东奔海复䜤叛矣遣唐翌等追斩之适谍报骠</span>  
<span style="margin-left: 2em">骑既克松江将东兵屠海邑民震慴无所于遁侯即</span>  
<span style="margin-left: 2em">函首献俘骠骑所曰贼擒而邑治复民已悉定矣无</span>  
<span style="margin-left: 2em">劳大兵凡三往返三未止会钱忿邑不附者悉指为</span>  
<span style="margin-left: 2em">逆党凡若干人骠骑逮捕甚急且以窘侯侯潜遣吏</span>  
<span style="margin-left: 2em">报克复功于右相国相国惊曰吾以老祝死矣老祝</span>  
<span style="margin-left: 2em">精神尚尔耶吾骠骑直儿戏耳卒以侯上功状按问</span>  
<span style="margin-left: 2em">得实奉旨谕还邻邑以诖误死者相枕籍而海邑毛</span>  
<span style="margin-left: 2em">草不动斥卤氓有不利于侯夺印章掠乘马者禽以</span>  
<span style="margin-left: 2em">献侯笑而遣之一无所问海父老相与燃臂香告天</span>  
<span style="margin-left: 2em">诣侯以谢居有间又群走予邸次曰吾邑匪侯邑血</span>  
<span style="margin-left: 2em">沼也久矣计转死而生者数千万齿吾子与邻邑冯</span>  
<span style="margin-left: 2em">华亭属比其事于石上不信吏文而信子片石吾祝</span>  
<span style="margin-left: 2em">父功德尤硕于冯子不书乎披邑士赵越所述为之</span>  
<span style="margin-left: 2em">跃然喜亟援笔以书侯名挺字正夫鄱阳人南坡藏</span>  
<span style="margin-left: 2em">室其故山读书之所也通春秋经博学平生慕诸葛</span>  
<span style="margin-left: 2em">武侯韩魏公之为人葛曰鞠躬尽瘁死而后已韩曰</span>  
<span style="margin-left: 2em">天下事见得理便做勿计生死祸福侯书其言于斋</span>  
<span style="margin-left: 2em">阁故凡遇所当为既慷慨以前不以祸福为后顾君</span>  
<span style="margin-left: 2em">子谓侯当大任即葛韩相臣匹也在邑驭民未尝厉</span>  
<span style="margin-left: 2em">声色事来断制剖决如神明系之辞曰海之虞海啸</span>  
<span style="margin-left: 2em">呼海弗虞遵归虚而尾闾大夫度也海如大夫之德</span>  
<span style="margin-left: 2em">海涵濡千蛟万虺起须叟一蛟得万虺化为鱼嗟嗟</span>  
<span style="margin-left: 2em">兮大夫神明予父母予嗟嗟兮大夫</span>  
<span style="margin-left: 1em">冯荣乌江人洪武初知华亭县莅任甫三月海滨盗起</span>  
<span style="margin-left: 1em">染及华亭荣言于统兵者请罪渠魁而贷其良民之诖</span>  
<span style="margin-left: 1em">误者统兵然之脱死者数万口既而兴学校劝农乘辨</span>  
<span style="margin-left: 1em">寃枉均繇役政教一新故老至今能道之</span>  
<span style="margin-left: 2em">初徐达攻苏州松江府守臣王立中以城降达令立</span>  
<span style="margin-left: 2em">中就摄府事既而　上命荀玉珎代之未几达檄各</span>  
<span style="margin-left: 2em">府验民田征砖甃城鹤臯不奉令欲倡乱因号于众</span>  
<span style="margin-left: 2em">曰吾等力不能办城不完即死曷若求生路以取富</span>  
<span style="margin-left: 2em">贵众皆从之遂结张士诚故元帅府副使韩复春施</span>  
<span style="margin-left: 2em">仁济聚众至三万余人攻府治开库庾剽掠财物通</span>  
<span style="margin-left: 2em">判赵敬仓卒不能敌驱妻子十八人赴水死荀玉珎</span>  
<span style="margin-left: 2em">弃城走盗追杀之鹤臯自称行省左丞署旗为元字</span>  
<span style="margin-left: 2em">刻石为印伪署官属以姚大章为统兵元帅张思廉</span>  
<span style="margin-left: 2em">为参谋施仁济谷子盛为枢密院判令其子遵义率</span>  
<span style="margin-left: 2em">小舟数十走苏州欲归张士诚以求援至是达遣骁</span>  
<span style="margin-left: 2em">骑将军葛俊讨之兵至连湖荡望见遵义所率众皆</span>  
<span style="margin-left: 2em">操农器知其无能为也乃于荡东西连发十余砲盗</span>  
<span style="margin-left: 2em">皆惊溃溺死者不可胜计兵及城鹤臯闭门拒守俊</span>  
<span style="margin-left: 2em">攻下之获鹤臯槛送大将军斩之仁济等率余党遁</span>  
<span style="margin-left: 2em">去俊怒华亭人从乱欲屠其城华亭知县冯荣初不</span>  
<span style="margin-left: 2em">屈于鹤臯为贼缚置狱中至是始出即争于俊曰反</span>  
<span style="margin-left: 2em">者钱鹤臯耳余皆良民纵有从者皆由迫胁将军必</span>  
<span style="margin-left: 2em">欲加兵荣请先死有邑无民何以为治俊从之华亭</span>  
<span style="margin-left: 2em">赖以安<sub class="note-yuan">实录</sub></span>  
<span style="margin-left: 1em">文原吉官治书侍御史洪武二年巡按谢恕按治松江</span>  
<span style="margin-left: 1em">欺隐官租逮系一百九十余人至京师多有称寃者原</span>  
<span style="margin-left: 1em">吉等以其事闻　上命召数人亲问之悉得其情乃责</span>  
<span style="margin-left: 1em">恕曰御史耳目之官当与民辨是非明曲直不使寃抑</span>  
<span style="margin-left: 1em">方为称职今尔为御史不能为民理枉反陷民无辜朝</span>  
<span style="margin-left: 1em">廷耳目将何赖耶于是尽释其人命下恕吏原吉等不</span>  
<span style="margin-left: 1em">蔽聪明赏彩币有差</span>  
<span style="margin-left: 2em">文原吉非宦于江南以其有禆松人故载之</span>  
<span style="margin-left: 1em">陈宁初名亮茶陵人元末为镇江小吏从军至金陵代</span>  
<span style="margin-left: 1em">诸将言事英辩叠出　高皇帝异之赐名宁授江南行</span>  
<span style="margin-left: 1em">省掾吏历中书省参议凡朝廷制度咸预稽详吴元年</span>  
<span style="margin-left: 1em">出知广德州岁大旱奏免租弗允宁躬赴阙上言天灾</span>  
<span style="margin-left: 1em">民饥催租太急是为张士诚驱民也　上曰尔乃胆大</span>  
<span style="margin-left: 1em">敢为此言耶竟从之迁浙江按察使洪武元年召入为</span>  
<span style="margin-left: 1em">司农卿迁兵部尚书二年出知松江府政尚严明人呼</span>  
<span style="margin-left: 1em">为陈烙铁复拜中书省右丞三年又出知苏州府迁浙</span>  
<span style="margin-left: 1em">江行省参知政事复召为御史中丞六年同宋濂拜甘</span>  
<span style="margin-left: 1em">露之赐一日率侍御史商暠等入奏　上御东阁免冠</span>  
<span style="margin-left: 1em">而栉遣人止之移入便殿栉已正冠方召见其以严见</span>  
<span style="margin-left: 1em">惮如此</span>  
<span style="margin-left: 1em">蒋惠鄱昜人洪武十一年知华亭县先是县诬平民李</span>  
<span style="margin-left: 1em">秀三等三十人为强盗惠察其无辜俾以更生仍密授</span>  
<span style="margin-left: 1em">方畧获真盗马胡等十八人正其罪他如毁淫祠以正</span>  
<span style="margin-left: 1em">人心去奸顽以植良善及民之惠实多焉祀先贤祠</span>  
<span style="margin-left: 1em">黄辂字子威进贤人后以字行洪武间繇吏员荐署屯</span>  
<span style="margin-left: 1em">田主事历刑科给事中擢松江知府值饥疫交作发廪</span>  
<span style="margin-left: 1em">蠲税民困以甦沈女妙兰尝出肝活母江都令任子英</span>  
<span style="margin-left: 1em">妻曹秀直北兵至欲污之不屈死俱为奏表其门尝以</span>  
<span style="margin-left: 1em">事如嘉兴归老穉数十各携蔬果奔趋至舟投之呼笑</span>  
<span style="margin-left: 1em">而去宣德间年七十恳乞致仕寿八十余卒在松二十</span>  
<span style="margin-left: 1em">余年五去政四保留松民以为自来郡守廉能明断未</span>  
<span style="margin-left: 1em">有及者至今祠祀焉</span>  
<span style="margin-left: 2em">南昌名臣传云黄子威永乐中知松江府时吴淞大</span>  
<span style="margin-left: 2em">涝蹇夏二公交荐擢任首蠲秋税跋履乡邑出廪赈</span>  
<span style="margin-left: 2em">给民赖以苏部符发松江市贾往浙右铸钱公请罢</span>  
<span style="margin-left: 2em">役第收故钱如数以输诏可及具材若干万输京缮</span>  
<span style="margin-left: 2em">造复疏免之宣德初以夏去松民乞留巡抚胡槩以</span>  
<span style="margin-left: 2em">闻　上诏蹇尚书曰朕闻松江烦剧难治渠遂能得</span>  
<span style="margin-left: 2em">人心如此其从之后以诖误谪戍边民复请得宥还</span>  
<span style="margin-left: 2em">职</span>  
<span style="margin-left: 2em">公在松循行阡陌驺从四五人访问民间疾苦课农</span>  
<span style="margin-left: 2em">桑勤惰又好礼贤士时俞主政允为诸生相与唱和</span>  
<span style="margin-left: 2em">造其庐式焉</span>  
<span style="margin-left: 1em">萧九万江西南昌人岁贡洪武间为诸暨丞博学能词</span>  
<span style="margin-left: 1em">翰尝书容忍思虑四字疏其义揭门屏间百姓以讼至</span>  
<span style="margin-left: 1em">者必谆谆以诲之迁知华亭疏民弊五事忤　旨被逮</span>  
<span style="margin-left: 1em">临刑啮指血录诗以报母有微臣斩首丹心在尚有英</span>  
<span style="margin-left: 1em">魂返故乡之句</span>  
<span style="margin-left: 1em">李浩字师孟直隶保定人归附初同知府事均赋役平</span>  
<span style="margin-left: 1em">出纳明黜陟慎兴革严关津清狱讼时称为循吏未几</span>  
<span style="margin-left: 1em">召置机近法从杨铁崖有赠叙</span>  
<span style="margin-left: 1em">王文贞洪武六年以府同知署华亭县事时兵后教弛</span>  
<span style="margin-left: 1em">文贞复学故址筑射圃建观德堂举行乡射礼又时临</span>  
<span style="margin-left: 1em">讲堂以勉诸生议者方之文翁</span>
