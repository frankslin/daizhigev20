## 崇禎松江府志卷之三十一　宦績四（國朝名宦）

<span style="margin-left: 3em">國朝名臣宦績一</span>  
<span style="margin-left: 1em">正己率屬察吏安民此臺察座右銘也經師易得人師</span>  
<span style="margin-left: 1em">難求此博士座右銘也苟存心於愛物雖一命必有所</span>  
<span style="margin-left: 1em">濟此幕尉座右銘也郡邑長何銘乎陽道州曰撫字心</span>  
<span style="margin-left: 1em">勞然不若撫字心閒行所無事則閒矣曰催科政拙更</span>  
<span style="margin-left: 1em">不若催科政巧知所先後則巧矣神而明之有先朝已</span>  
<span style="margin-left: 1em">事在</span>  
<span style="margin-left: 1em">湯和字鼎臣鳳陽人洪武初年以信國公奉</span>  
<span style="margin-left: 1em">命治海務先是屢有倭警　上因方亞關獻議命和緣</span>  
<span style="margin-left: 1em">海一帶相度要衝建立衛所以防倭松江建金山衛于</span>  
<span style="margin-left: 1em">浙直交關處又迤東建青村所又東北建南滙所府城</span>  
<span style="margin-left: 1em">亦增守禦千户所調發留都官軍屯守曠處立墩堡遇</span>  
<span style="margin-left: 1em">警舉烽傳報絡繹策應無令首尾疎虞二百餘載來永</span>  
<span style="margin-left: 1em">賴其功<sub class="note-yuan">亞關方國珍次子也既歸順後獻三郡海船水手數萬因請緣海備禦建設衛所延亘萬里如金山青村等處皆其議云</sub></span>  
<span style="margin-left: 2em">和以春秋高思歸故鄉嘗進對　上前從容乞骸骨</span>  
<span style="margin-left: 3em">上嘉之賜鈔萬錠俾建第於鳳陽且謂和曰日本</span>  
<span style="margin-left: 2em">小夷屢擾瀕海之民卿雖老强爲朕一行視其要害</span>  
<span style="margin-left: 2em">地築城增兵以固守備和奉　旨即行自閩越並海</span>  
<span style="margin-left: 2em">之地築數十城而歸至是新第成和率妻子陛辭往</span>  
<span style="margin-left: 2em">居之按信國之功于吾松爲大若蘇之衛所非其建</span>  
<span style="margin-left: 2em">也故上海報功之典當以信國爲第一</span>  
<span style="margin-left: 1em">祝挺字正夫江西鄱陽人吳元年知上海縣事會逆民</span>  
<span style="margin-left: 1em">錢鶴臯倡亂拘囚守令劫掠鄉城挺懷印走府謀誅凶</span>  
<span style="margin-left: 1em">叛忽聞府城已陷乃仰天嘆曰此我死所也效死弗去</span>  
<span style="margin-left: 1em">無何爲賊所執正色諭之曰汝乃我之編民敢逼我耶</span>  
<span style="margin-left: 1em">吾有頭在勿復言賊知不可屈釋之乃密與主簿鄭著</span>  
<span style="margin-left: 1em">李從吉等謀起義兵身自披堅執鋭追斬僞總兵姚萬</span>  
<span style="margin-left: 1em">户金于西溝函其首以獻時主帥議罪脅從慷慨進言</span>  
<span style="margin-left: 1em">曰彼皆良民一時爲其所逼奈何併誅之願以身代罪</span>  
<span style="margin-left: 1em">復上狀中書省反側藉以自安男女老幼驩呼踴躍提</span>  
<span style="margin-left: 1em">壺漿燃香燭拜伏道左迎公以歸又明年司臬者毛責</span>  
<span style="margin-left: 1em">細故停其治三月士庶老稚日夜號泣走　闕下慟哭</span>  
<span style="margin-left: 1em">請命　上驚曰祝挺者向吾特選以治海邦而司臬敢</span>  
<span style="margin-left: 1em">忘之覆罪司臬挺復進用至今人猶思祝大夫後擢户</span>  
<span style="margin-left: 1em">部主事晋郎中</span>  
<span style="margin-left: 2em">楊維禎撰活民碑　上海淞附庸邑也其地薄海斥</span>  
<span style="margin-left: 2em">鹵氓過半自有元百年教養之澤深民之爲俗慕仁</span>  
<span style="margin-left: 2em">義者十室而九遂號善地丁未三月晦日邑忽有變</span>  
<span style="margin-left: 2em">大姓錢氏烏合起剪竿而槊結帨而斾斬關入淞城</span>  
<span style="margin-left: 2em">首殺長吏分遣其黨率火伍犯邑請先殺邑長祝挺</span>  
<span style="margin-left: 2em">錢怒曰今日憤兵爲翼虎殪吾民者起邑長祝使君</span>  
<span style="margin-left: 2em">我生身父母不翅敢有傷之者斬黨又爲誘語請侯</span>  
<span style="margin-left: 2em">見總兵所侯咈然曰吾有吾頭請以頭往爾氓獨不</span>  
<span style="margin-left: 2em">聞我單騎入虎牙營不動聲色祝奉使乎卒不爲屑</span>  
<span style="margin-left: 2em">侯揣知烏合必潰乃自爲教密遣人布長里者曰逆</span>  
<span style="margin-left: 2em">順禍福非天也人自取也有能爲我擒賊復縣者吾</span>  
<span style="margin-left: 2em">上汝功教至巨室匿備械艤大艘渡侯黃龍東植義</span>  
<span style="margin-left: 2em">旗率民聽約束民皆嚙指血誓効順黨亦投戈于地</span>  
<span style="margin-left: 2em">羝跪義旗下請死罪邑治遂復時四月五日也黨率</span>  
<span style="margin-left: 2em">其衆東奔海復鿁叛矣遣唐翌等追斬之適諜報驃</span>  
<span style="margin-left: 2em">騎既克松江將東兵屠海邑民震慴無所於遁侯即</span>  
<span style="margin-left: 2em">函首獻俘驃騎所曰賊擒而邑治復民已悉定矣無</span>  
<span style="margin-left: 2em">勞大兵凡三往返三未止會錢忿邑不附者悉指爲</span>  
<span style="margin-left: 2em">逆黨凡若干人驃騎逮捕甚急且以窘侯侯潛遣吏</span>  
<span style="margin-left: 2em">報克復功于右相國相國驚曰吾以老祝死矣老祝</span>  
<span style="margin-left: 2em">精神尚爾耶吾驃騎直兒戲耳卒以侯上功狀按問</span>  
<span style="margin-left: 2em">得實奉旨諭還鄰邑以詿誤死者相枕籍而海邑毛</span>  
<span style="margin-left: 2em">草不動斥鹵氓有不利於侯奪印章掠乘馬者禽以</span>  
<span style="margin-left: 2em">獻侯笑而遣之一無所問海父老相與燃臂香告天</span>  
<span style="margin-left: 2em">詣侯以謝居有間又群走予邸次曰吾邑匪侯邑血</span>  
<span style="margin-left: 2em">沼也久矣計轉死而生者數千萬齒吾子與鄰邑馮</span>  
<span style="margin-left: 2em">華亭屬比其事于石上不信吏文而信子片石吾祝</span>  
<span style="margin-left: 2em">父功德尤碩於馮子不書乎披邑士趙越所述爲之</span>  
<span style="margin-left: 2em">躍然喜亟援筆以書侯名挺字正夫鄱陽人南坡藏</span>  
<span style="margin-left: 2em">室其故山讀書之所也通春秋經博學平生慕諸葛</span>  
<span style="margin-left: 2em">武侯韓魏公之爲人葛曰鞠躬盡瘁死而後已韓曰</span>  
<span style="margin-left: 2em">天下事見得理便做勿計生死禍福侯書其言於齋</span>  
<span style="margin-left: 2em">閣故凡遇所當爲既慷慨以前不以禍福爲後顧君</span>  
<span style="margin-left: 2em">子謂侯當大任即葛韓相臣匹也在邑馭民未嘗厲</span>  
<span style="margin-left: 2em">聲色事來斷制剖決如神明係之辭曰海之虞海嘯</span>  
<span style="margin-left: 2em">呼海弗虞遵歸虛而尾閭大夫度也海如大夫之德</span>  
<span style="margin-left: 2em">海涵濡千蛟萬虺起須叟一蛟得萬虺化爲魚嗟嗟</span>  
<span style="margin-left: 2em">兮大夫神明予父母予嗟嗟兮大夫</span>  
<span style="margin-left: 1em">馮榮烏江人洪武初知華亭縣蒞任甫三月海濱盗起</span>  
<span style="margin-left: 1em">染及華亭榮言于統兵者請罪渠魁而貸其良民之詿</span>  
<span style="margin-left: 1em">誤者統兵然之脱死者數萬口既而興學校勸農乘辨</span>  
<span style="margin-left: 1em">寃枉均繇役政教一新故老至今能道之</span>  
<span style="margin-left: 2em">初徐達攻蘇州松江府守臣王立中以城降達令立</span>  
<span style="margin-left: 2em">中就攝府事既而　上命荀玉珎代之未幾達檄各</span>  
<span style="margin-left: 2em">府驗民田徵磚甃城鶴臯不奉令欲倡亂因號于衆</span>  
<span style="margin-left: 2em">曰吾等力不能辦城不完即死曷若求生路以取富</span>  
<span style="margin-left: 2em">貴衆皆從之遂結張士誠故元帥府副使韓復春施</span>  
<span style="margin-left: 2em">仁濟聚衆至三萬餘人攻府治開庫庾剽掠財物通</span>  
<span style="margin-left: 2em">判趙敬倉卒不能敵驅妻子十八人赴水死荀玉珎</span>  
<span style="margin-left: 2em">棄城走盗追殺之鶴臯自稱行省左丞署旗爲元字</span>  
<span style="margin-left: 2em">刻石爲印僞署官屬以姚大章爲統兵元帥張思廉</span>  
<span style="margin-left: 2em">爲參謀施仁濟谷子盛爲樞密院判令其子遵義率</span>  
<span style="margin-left: 2em">小舟數十走蘇州欲歸張士誠以求援至是達遣驍</span>  
<span style="margin-left: 2em">騎將軍葛俊討之兵至連湖蕩望見遵義所率衆皆</span>  
<span style="margin-left: 2em">操農器知其無能爲也乃於蕩東西連發十餘砲盗</span>  
<span style="margin-left: 2em">皆驚潰溺死者不可勝計兵及城鶴臯閉門拒守俊</span>  
<span style="margin-left: 2em">攻下之獲鶴臯檻送大將軍斬之仁濟等率餘黨遁</span>  
<span style="margin-left: 2em">去俊怒華亭人從亂欲屠其城華亭知縣馮榮初不</span>  
<span style="margin-left: 2em">屈於鶴臯爲賊縛置獄中至是始出即争於俊曰反</span>  
<span style="margin-left: 2em">者錢鶴臯耳餘皆良民縱有從者皆由迫脅將軍必</span>  
<span style="margin-left: 2em">欲加兵榮請先死有邑無民何以爲治俊從之華亭</span>  
<span style="margin-left: 2em">賴以安<sub class="note-yuan">實錄</sub></span>  
<span style="margin-left: 1em">文原吉官治書侍御史洪武二年巡按謝恕按治松江</span>  
<span style="margin-left: 1em">欺隱官租逮繫一百九十餘人至京師多有稱寃者原</span>  
<span style="margin-left: 1em">吉等以其事聞　上命召數人親問之悉得其情乃責</span>  
<span style="margin-left: 1em">恕曰御史耳目之官當與民辨是非明曲直不使寃抑</span>  
<span style="margin-left: 1em">方爲稱職今爾爲御史不能爲民理枉反陷民無辜朝</span>  
<span style="margin-left: 1em">廷耳目將何賴耶于是盡釋其人命下恕吏原吉等不</span>  
<span style="margin-left: 1em">蔽聰明賞綵幣有差</span>  
<span style="margin-left: 2em">文原吉非宦于江南以其有禆松人故載之</span>  
<span style="margin-left: 1em">陳寧初名亮茶陵人元末爲鎮江小吏從軍至金陵代</span>  
<span style="margin-left: 1em">諸將言事英辯疊出　高皇帝異之賜名寧授江南行</span>  
<span style="margin-left: 1em">省掾吏歷中書省參議凡朝廷制度咸預稽詳吳元年</span>  
<span style="margin-left: 1em">出知廣德州歲大旱奏免租弗允寧躬赴闕上言天災</span>  
<span style="margin-left: 1em">民飢催租太急是爲張士誠驅民也　上曰爾乃膽大</span>  
<span style="margin-left: 1em">敢爲此言耶竟從之遷浙江按察使洪武元年召入爲</span>  
<span style="margin-left: 1em">司農卿遷兵部尚書二年出知松江府政尚嚴明人呼</span>  
<span style="margin-left: 1em">爲陳烙鐵復拜中書省右丞三年又出知蘇州府遷浙</span>  
<span style="margin-left: 1em">江行省參知政事復召爲御史中丞六年同宋濂拜甘</span>  
<span style="margin-left: 1em">露之賜一日率侍御史商暠等入奏　上御東閣免冠</span>  
<span style="margin-left: 1em">而櫛遣人止之移入便殿櫛已正冠方召見其以嚴見</span>  
<span style="margin-left: 1em">憚如此</span>  
<span style="margin-left: 1em">蔣惠鄱昜人洪武十一年知華亭縣先是縣誣平民李</span>  
<span style="margin-left: 1em">秀三等三十人爲强盗惠察其無辜俾以更生仍密授</span>  
<span style="margin-left: 1em">方畧獲真盗馬鬍等十八人正其罪他如毁淫祠以正</span>  
<span style="margin-left: 1em">人心去姦頑以植良善及民之惠實多焉祀先賢祠</span>  
<span style="margin-left: 1em">黃輅字子威進賢人後以字行洪武間繇吏員薦署屯</span>  
<span style="margin-left: 1em">田主事歷刑科給事中擢松江知府值飢疫交作發廪</span>  
<span style="margin-left: 1em">蠲稅民困以甦沈女妙蘭嘗出肝活母江都令任子英</span>  
<span style="margin-left: 1em">妻曹秀直北兵至欲污之不屈死俱爲奏表其門嘗以</span>  
<span style="margin-left: 1em">事如嘉興歸老穉數十各攜蔬果奔趨至舟投之呼笑</span>  
<span style="margin-left: 1em">而去宣德間年七十懇乞致仕壽八十餘卒在松二十</span>  
<span style="margin-left: 1em">餘年五去政四保留松民以爲自來郡守廉能明斷未</span>  
<span style="margin-left: 1em">有及者至今祠祀焉</span>  
<span style="margin-left: 2em">南昌名臣傳云黃子威永樂中知松江府時吳淞大</span>  
<span style="margin-left: 2em">澇蹇夏二公交薦擢任首蠲秋稅跋履鄉邑出廪賑</span>  
<span style="margin-left: 2em">給民賴以蘇部符發松江市賈往浙右鑄錢公請罷</span>  
<span style="margin-left: 2em">役第收故錢如數以輸詔可及具材若干萬輸京繕</span>  
<span style="margin-left: 2em">造復疏免之宣德初以夏去松民乞留巡撫胡槩以</span>  
<span style="margin-left: 2em">聞　上詔蹇尚書曰朕聞松江煩劇難治渠遂能得</span>  
<span style="margin-left: 2em">人心如此其從之後以詿誤謫戍邊民復請得宥還</span>  
<span style="margin-left: 2em">職</span>  
<span style="margin-left: 2em">公在松循行阡陌騶從四五人訪問民間疾苦課農</span>  
<span style="margin-left: 2em">桑勤惰又好禮賢士時俞主政允爲諸生相與唱和</span>  
<span style="margin-left: 2em">造其廬式焉</span>  
<span style="margin-left: 1em">蕭九萬江西南昌人歲貢洪武間爲諸暨丞博學能詞</span>  
<span style="margin-left: 1em">翰嘗書容忍思慮四字疏其義揭門屏間百姓以訟至</span>  
<span style="margin-left: 1em">者必諄諄以誨之遷知華亭疏民弊五事忤　旨被逮</span>  
<span style="margin-left: 1em">臨刑嚙指血錄詩以報母有微臣斬首丹心在尚有英</span>  
<span style="margin-left: 1em">魂返故鄉之句</span>  
<span style="margin-left: 1em">李浩字師孟直隸保定人歸附初同知府事均賦役平</span>  
<span style="margin-left: 1em">出納明黜陟慎興革嚴關津清獄訟時稱爲循吏未幾</span>  
<span style="margin-left: 1em">召置機近法從楊鐵崖有贈叙</span>

<span style="margin-left: 1em">來邏者獲之　上召爲兵部右侍郎上疏犯輔臣改南</span>  
<span style="margin-left: 1em">工部晋右都御史撫南畿折豪强植貧弱禁私驛革工</span>  
<span style="margin-left: 1em">作廷舉長身而瘠面如削瓜衣敝帶穿不修藻餙神采</span>  
<span style="margin-left: 1em">英毅志識雄偉言行必自信人鮮能奪之視財利如糞</span>  
<span style="margin-left: 1em">土妻子冒飢寒而施予不較有無轉南大司空即疏歸</span>  
<span style="margin-left: 1em">歸二年卒所居湫隘卒之日無衣以斂無棺以殯都御</span>  
<span style="margin-left: 1em">史姚鏌營辦之謚曰清惠</span>  
<span style="margin-left: 2em">在太學南城羅玘四十餘以貲貢吳公悦其文奇兄</span>  
<span style="margin-left: 2em">事之病痢其僕疫而死吳公爲煮粥負之登厠一晝</span>  
<span style="margin-left: 2em">夜十數次病瘥同登進士語人曰玘四十前生我者</span>  
<span style="margin-left: 2em">父母四十後獻臣生我也公好讀書無不窺索積至</span>  
<span style="margin-left: 2em">萬卷見薛敬軒胡敬齋錄采其要言作詩效陳白沙</span>
