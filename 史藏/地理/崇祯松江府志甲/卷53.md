## 崇祯松江府志卷之五十三　道观

<span style="margin-left: 3em">道观</span>  
<span style="margin-left: 2em">华亭<sub class="note-yuan">新隶青浦附</sub></span>  
<span style="margin-left: 1em">僊鹤观府南朝真桥东始创在桥之西年月无考宋绍</span>  
<span style="margin-left: 2em">兴三十一年处州天真观道士叶太真复建请于朝</span>  
<span style="margin-left: 2em">即晋废观旧额赐今名元至正中道士吴大亨重修</span>  
<span style="margin-left: 3em">国初以其地设太平南仓道士陆允中始迁于此</span>  
<span style="margin-left: 2em">其地故张氏祠堂也观虽小为府境琳宫第一道纪</span>  
<span style="margin-left: 2em">司治焉归并院七庵堂四</span>  
<span style="margin-left: 2em">邵亨贞记畧　松江府治以南二百步有观曰仙鹤</span>  
<span style="margin-left: 2em">为一郡道家之总会其始建岁月盖不可考迹其可</span>  
<span style="margin-left: 2em">知者宋绍兴年间处州天真观道士叶太真来为之</span>  
<span style="margin-left: 2em">主始克充广之叶有道行善役鬼神尝奏章与蜀某</span>  
<span style="margin-left: 2em">道士胥会天关事闻于朝乾道间进士陈箎朱飞卿</span>  
<span style="margin-left: 2em">郑澭等归其资叶乃朴斵梓材于其乡浮之瀛海以</span>  
<span style="margin-left: 2em">至为寥阳殿前设三门旁立两庑翼以经钟二楼后</span>  
<span style="margin-left: 2em">建昊天宝阁又后为主者之居学者讲习栖息之所</span>  
<span style="margin-left: 2em">以至庖藏湢溷一一完美请于朝赐东晋废观旧额</span>  
<span style="margin-left: 2em">始以仙鹤称继嗣失守至正四年掌教天师择天台</span>  
<span style="margin-left: 2em">吴大亨居之吴通于鬼神水旱疾疫有祷辄应尤善</span>  
<span style="margin-left: 2em">拔致魂爽得其教中所谓济生度死法者每盛服事</span>  
<span style="margin-left: 2em">帝必有鸾鹤翔舞而至有感人心相与兴起益旧址</span>  
<span style="margin-left: 2em">崇簷楹视昔加高广壮丽增置雷霆之殿将卫之居</span>  
<span style="margin-left: 2em">建祖师施主等祠皆列栖两庑天人之像金碧焕耀</span>  
<span style="margin-left: 2em">端严雍穆落成之明年芝草生殿陛间是观为斯郡</span>  
<span style="margin-left: 2em">之甲其有裨于国与民者无穷矣观旧有田若干顷</span>  
<span style="margin-left: 2em">自宋至今特蠲其赋役尊道教也</span>  
<span style="margin-left: 2em">蓬莱道院在东门内元至正中道士李德安建国朝</span>  
<span style="margin-left: 2em">洪武庚申道士金志信等重修东庑有梓潼神旧祠</span>  
<span style="margin-left: 2em">于县学祠后有竹林大比岁以笋迸室中卜荐士之</span>  
<span style="margin-left: 2em">多寡近神坐则占前名其验如响成化庚寅提学陈</span>  
<span style="margin-left: 2em">选以神道家者流非学所当祀道士李朝阳因请祠</span>  
<span style="margin-left: 2em">于此仍塑吕真人配之万历中建利济侯祠</span>  
<span style="margin-left: 2em">钱文通溥重修碑记畧　府治东百五十步旧有道</span>  
<span style="margin-left: 2em">院曰蓬莱宋绍兴间地生灵芝纯阳显著灵迹因名</span>  
<span style="margin-left: 2em">诚吾松第一山也自元至正间道士李德安复建岁</span>  
<span style="margin-left: 2em">久倾圮　洪武初金志信重修永乐中陆道泓来住</span>  
<span style="margin-left: 2em">持继李朝阳戒行超卓道术高妙常以殿宇卑隘不</span>  
<span style="margin-left: 2em">足以壮观一郡为歉成化初先搆两祠请县学内文</span>  
<span style="margin-left: 2em">昌像奉于左塑纯阳像奉于右勤苦精修不十载四</span>  
<span style="margin-left: 2em">众皈依遂以其徒江守澄竭力经营撤而更之正殿</span>  
<span style="margin-left: 2em">三间高四丈六尺广视高倍五丈一尺深倍广者四</span>  
<span style="margin-left: 2em">丈八尺后殿三间广与高深俱杀焉正殿真武居之</span>  
<span style="margin-left: 2em">后殿老子居之文昌纯阳二祠则徙于后殿前之左</span>  
<span style="margin-left: 2em">右利济侯祠以及山门诸所焕然一新其殿始工之</span>  
<span style="margin-left: 2em">日正余奉勅致仕还家之又明年也越三载而落成</span>  
<span style="margin-left: 2em">朝阳乃谒余请记其事余常闻朝阳教其徒若孙有</span>  
<span style="margin-left: 2em">曰吾辈绝俗之士忠孝大事既不得与亦当以一念</span>  
<span style="margin-left: 2em">不欺为忠一事不苟为孝深窃叹其道家者流本清</span>  
<span style="margin-left: 2em">静无为而朝阳独尚忠孝殆学老而行儒者欤此余</span>  
<span style="margin-left: 2em">于是院所以乐为之记也遂俾录归刻诸石正德三</span>  
<span style="margin-left: 2em">年戊辰夏五月</span>  
<span style="margin-left: 2em">孙文简承恩重修碑记畧　松有蓬莱道院者在郡</span>  
<span style="margin-left: 2em">治东百五十步许地当通衢委巷北折甚幽寂宋绍</span>  
<span style="margin-left: 2em">兴间始创元至正间道士李德安复建岁久而圮成</span>  
<span style="margin-left: 2em">化癸卯李朝阳始改建之易卑为崇廓隘为广辟陋</span>  
<span style="margin-left: 2em">为深中为正殿祀真武祀其师老君于寝殿祀文昌</span>  
<span style="margin-left: 2em">君并唐吕真人于左右庑前建利济侯祠正德己卯</span>  
<span style="margin-left: 2em">秋震雷碎其正殿之二柱江之徒卫大溥者率其徒</span>  
<span style="margin-left: 2em">钟秉彝复修之支倾补弊益以藻饰则陛级峻整丹</span>  
<span style="margin-left: 2em">彩华焕地若拓而益宏殿若升而益崇景若辟而益</span>  
<span style="margin-left: 2em">幽明轩浄牖深院曲房花木葱茸雅洁娟丽若不与</span>  
<span style="margin-left: 2em">市廛接也院未有记无以为山门重抑无以诏后人</span>  
<span style="margin-left: 2em">以缔造之艰且将泯泯以至堕废遂为文以刻石复</span>  
<span style="margin-left: 2em">系之诗曰道原于一浑沦沕穆宰世立极吾道攸属</span>  
<span style="margin-left: 2em">老氏者作同源异曲清静为宗恬澹寡欲阐教传世</span>  
<span style="margin-left: 2em">久益显暴爰有攸处以寄高躅奕奕斯宫松城之隩</span>  
<span style="margin-left: 2em">地僻而𥥆光景清淑复创胜国郡乘可覆明益开拓</span>  
<span style="margin-left: 2em">殿宇高矗于赫圣帝玄衮皂纛金印宝剑龟蛇承足</span>  
<span style="margin-left: 2em">太上高居寝殿严肃文昌纯阳冠弁羽服万灵诃护</span>  
<span style="margin-left: 2em">四众瞻瞩岁在单阏雷斧栋木天威有临若儆玩渎</span>  
<span style="margin-left: 2em">有大羽士戒行贞独值变兢惕忏悔退伏竭力缮治</span>  
<span style="margin-left: 2em">倒廪罄匵藻饰其余罔有弗谷若增而胜丹彩溢目</span>  
<span style="margin-left: 2em">瀛海异境恍在尘陆颇疑其间僊侣栖宿神药灵芝</span>  
<span style="margin-left: 2em">皓鹤玄鹿白云迷户香霭覆屋允惟清虚逈隔凡俗</span>  
<span style="margin-left: 2em">石磬瑶笙玉版金箓考击钟鼓警彻昏旭玄台冥冥</span>  
<span style="margin-left: 2em">丹府煜煜泊然虚无神朗内烛匪兹灵区曷断诸欲</span>  
<span style="margin-left: 2em">思贻厥谋言谨其属爰谒史氏彤管纪录刻之贞珉</span>  
<span style="margin-left: 2em">庸代面告咨尔后人罔敢弗勗精进焚修秉志诚笃</span>  
<span style="margin-left: 2em">毋堕前功殚力继续上祝皇厘下祈民福四气顺布</span>  
<span style="margin-left: 2em">雨旸寒燠以及众生均囿化育嘉靖十有一年壬辰</span>  
<span style="margin-left: 2em">岁秋八月既望</span>  
<span style="margin-left: 2em"><sub class="note-yuan">元张昱诗云近蓬莱蜃气消数峰晴照远相招梁间燕子都归去观里桃花自寂寥盂饭化人忘恋恋院墙篁竹谩萧萧云中何处刘安宅犹有鸡声报午朝</sub></span>  
<span style="margin-left: 2em">八僊祠<sub class="note-yuan">在道院之东偏万历年间有云水道者从东省至憇于佥宪俞公汝为家谈未来语多神异谓云间大郡可无八僊祠俞公倡举之太学生宋启文助建</sub></span>  
<span style="margin-left: 2em">盟素道院府东南旧城隍庙侧元至元二十七年天</span>  
<span style="margin-left: 2em">台桐柏宫祝知观创始至正十二年道士吴蟾友王</span>  
<span style="margin-left: 2em">玄静建　国朝成化己丑旱知府田臻祷而得雨命</span>  
<span style="margin-left: 2em">住院王惟端等重修正德己巳道士王大经建三清</span>  
<span style="margin-left: 2em">阁久圮天启癸亥重建　朝元道院在泖口元大德</span>  
<span style="margin-left: 2em">间道士陆景真建去府<sub class="note-yuan">二十七里</sub></span>  
<span style="margin-left: 2em">朝真道院在干山元至正三年道士郭松溪建万历</span>  
<span style="margin-left: 2em">中重修建餐霞馆</span>  
<span style="margin-left: 2em">明真道院在朱泾镇元泰定中里人陈原𣇄建大兴</span>  
<span style="margin-left: 2em">道院在萧塘镇元至正中道士范道隆建太清道院</span>  
<span style="margin-left: 2em">在俞塘洪武元年道士吴松谷建万历间改太清禅</span>  
<span style="margin-left: 2em">院僧苏湛然重建</span>  
<span style="margin-left: 2em">太古庵宋建在府西三百步</span>  
<span style="margin-left: 2em">施水庵元至元间道士叶云建后唐月心舍地重建</span>  
<span style="margin-left: 2em"><sub class="note-yuan">府东南五十四里</sub></span>  
<span style="margin-left: 2em">上真庵在翁家庄西距府七十里元泰定二年道士</span>  
<span style="margin-left: 2em">萧野云建</span>  
<span style="margin-left: 2em">上真堂在金山卫东门元至元间道士王惟谦建</span>  
<span style="margin-left: 1em">长春道院府城集僊门内桥北元大德十年道士郑道</span>  
<span style="margin-left: 2em">真建为境内全真教祖　国朝归并院七庵堂二</span>  
<span style="margin-left: 2em">浮梁杨载记　余游松江假馆长春道院其主人则</span>  
<span style="margin-left: 2em">钱塘郑君道真君之言曰仆幼时闻北方人为全真</span>  
<span style="margin-left: 2em">教其祖师则长春丘真人得炼气养神之道入火不</span>  
<span style="margin-left: 2em">焦入水不濡出人有无变化不测寿无所止极与天</span>  
<span style="margin-left: 2em">地终始心甚慕焉父故将家将卒千人戍守严陵因</span>  
<span style="margin-left: 2em">病免官其军之大将将以仆名闻朝廷予父旧卒使</span>  
<span style="margin-left: 2em">袭父官仆自念苟学道有功得如丘真人虽贵为王</span>  
<span style="margin-left: 2em">侯犹不足比儗何有于列较哉縻系于此终不得为</span>  
<span style="margin-left: 2em">所欲为者矣遁去至永嘉师受道要居密室中累年</span>  
<span style="margin-left: 2em">一旦心跃然思归不可制止归则父母皆已卒葬慨</span>  
<span style="margin-left: 2em">然叹曰身无却顾之忧吾道其遂成乎于是益务远</span>  
<span style="margin-left: 2em">游至松江松江人无为全真教者非仆客朱氏则俱</span>  
<span style="margin-left: 2em">托于逆旅主人仆遂有志结庵买地二亩筑室四间</span>  
<span style="margin-left: 2em">度弟子朱道本等使嗣守之以待来者仆寻去之丹</span>  
<span style="margin-left: 2em">阳欲渡江不果复还永嘉时邑中大家计肃夏世昌</span>  
<span style="margin-left: 2em">二人志尚清虚雅好道术增地七亩创制为今道院</span>  
<span style="margin-left: 2em">使人招致仆主其事余闻北方人以全真名教始重</span>  
<span style="margin-left: 2em">阳王真人金之衰也诸侯割据山东鼎沸王真人之</span>  
<span style="margin-left: 2em">貌异于常人慨然有拯天下之志天数夺其计其徒</span>  
<span style="margin-left: 2em">壮士叛己因绝食居山中积数年有道为神仙度弟</span>  
<span style="margin-left: 2em">子七人丘真人最后出本朝闻其贤遣臣刘仲禄迎</span>  
<span style="margin-left: 2em">至漠北谓太祖受命于天为万姓除残贼必无多杀</span>  
<span style="margin-left: 2em">上感其言斩刈之威大为衰止繇是山东之人始有</span>  
<span style="margin-left: 2em">生殖之望焉夫为道者无为而无不为而善藏其用</span>  
<span style="margin-left: 2em">则可以功济天下古之人有知之者子房是也今丘</span>  
<span style="margin-left: 2em">真人以度世为业而能尽力匡维有补于万亿年之</span>  
<span style="margin-left: 2em">鸿绪挈功盛大讵让子房哉今为其学者皆绝去嗜</span>  
<span style="margin-left: 2em">好以觕恶为衣食室中徒设榻植坐内踵状类禅定</span>  
<span style="margin-left: 2em">而中有所事事其法具于抱朴子第丘真人之道显</span>  
<span style="margin-left: 2em">重于世故学者推之以为祖焉道院之制为前殿祠</span>  
<span style="margin-left: 2em">事老子其外两庑其后为堂高下降杀与殿相承余</span>  
<span style="margin-left: 2em">所假馆直室之东北隅曲径深窅有池水丛竹之胜</span>  
<span style="margin-left: 2em">郑君之为人无骄气无惰容色常欣欣然如髫龀为</span>  
<span style="margin-left: 2em">童子时乡人化其善贤者乐从之游郑君视之泊然</span>  
<span style="margin-left: 2em">不以系累乎其心有道之候庶几在兹<sub class="note-yuan">至治元年四月十五日又春雨即事呈郑尊师南荣相距数寻间满地春泥隔往还夜雨暗添篱脚水晓云浓掩树头山修篁夹径宜增植细草侵堦莫漫删世虑纷纷无止极敢求大药驻衰颜王逢题长春道院桂风子与朱贞一真人诗仙人桂风子勇别上清君晞发三神日巢松五老云桃椎今问讯奎阁旧论文游幔峰青叠蓬头并鹤群</sub></span>  
<span style="margin-left: 2em">谷水道院在府城西谷水坊内前志云在瑁湖北许</span>  
<span style="margin-left: 2em">尚百咏题有道院注在西湖之西后为延氏蔬圃疑</span>  
<span style="margin-left: 2em">即此地曰谷水者湖之故名也宋宝庆二年道士陆</span>  
<span style="margin-left: 2em">景微建　国朝洪武二十年道士叶云谷增修后毁</span>  
<span style="margin-left: 2em">于火道士黄碧窗里人马骥等重建今湖已湮废院</span>
