## 崇禎松江府志卷之五十三　道觀

<span style="margin-left: 3em">道觀</span>  
<span style="margin-left: 2em">華亭<sub class="note-yuan">新隸青浦附</sub></span>  
<span style="margin-left: 1em">僊鶴觀府南朝真橋東始創在橋之西年月無考宋紹</span>  
<span style="margin-left: 2em">興三十一年處州天真觀道士葉太真復建請於朝</span>  
<span style="margin-left: 2em">即晉廢觀舊額賜今名元至正中道士吳大亨重修</span>  
<span style="margin-left: 3em">國初以其地設太平南倉道士陸允中始遷於此</span>  
<span style="margin-left: 2em">其地故張氏祠堂也觀雖小爲府境琳宫第一道紀</span>  
<span style="margin-left: 2em">司治焉歸併院七菴堂四</span>  
<span style="margin-left: 2em">邵亨貞記畧　松江府治以南二百步有觀曰仙鶴</span>  
<span style="margin-left: 2em">爲一郡道家之總會其始建歲月蓋不可考跡其可</span>  
<span style="margin-left: 2em">知者宋紹興年間處州天真觀道士葉太真來爲之</span>  
<span style="margin-left: 2em">主始克充廣之葉有道行善役鬼神嘗奏章與蜀某</span>  
<span style="margin-left: 2em">道士胥會天關事聞於朝乾道間進士陳箎朱飛卿</span>  
<span style="margin-left: 2em">鄭澭等歸其資葉乃樸斵梓材於其鄉浮之瀛海以</span>  
<span style="margin-left: 2em">至爲寥陽殿前設三門旁立兩廡翼以經鐘二樓後</span>  
<span style="margin-left: 2em">建昊天寶閣又後爲主者之居學者講習棲息之所</span>  
<span style="margin-left: 2em">以至庖藏湢溷一一完美請於朝賜東晉廢觀舊額</span>  
<span style="margin-left: 2em">始以仙鶴稱繼嗣失守至正四年掌教天師擇天台</span>  
<span style="margin-left: 2em">吳大亨居之吳通於鬼神水旱疾疫有禱輒應尤善</span>  
<span style="margin-left: 2em">拔致魂爽得其教中所謂濟生度死法者每盛服事</span>  
<span style="margin-left: 2em">帝必有鸞鶴翔舞而至有感人心相與興起益舊址</span>  
<span style="margin-left: 2em">崇簷楹視昔加高廣壯麗增置雷霆之殿將衛之居</span>  
<span style="margin-left: 2em">建祖師施主等祠皆列棲兩廡天人之像金碧焕耀</span>  
<span style="margin-left: 2em">端嚴雍穆落成之明年芝草生殿陛間是觀爲斯郡</span>  
<span style="margin-left: 2em">之甲其有裨於國與民者無窮矣觀舊有田若干頃</span>  
<span style="margin-left: 2em">自宋至今特蠲其賦役尊道教也</span>  
<span style="margin-left: 2em">蓬萊道院在東門內元至正中道士李德安建國朝</span>  
<span style="margin-left: 2em">洪武庚申道士金志信等重修東廡有梓潼神舊祠</span>  
<span style="margin-left: 2em">於縣學祠後有竹林大比歲以筍迸室中卜薦士之</span>  
<span style="margin-left: 2em">多寡近神坐則占前名其驗如響成化庚寅提學陳</span>  
<span style="margin-left: 2em">選以神道家者流非學所當祀道士李朝陽因請祠</span>  
<span style="margin-left: 2em">於此仍塑呂真人配之萬曆中建利濟侯祠</span>  
<span style="margin-left: 2em">錢文通溥重修碑記畧　府治東百五十步舊有道</span>  
<span style="margin-left: 2em">院曰蓬萊宋紹興間地生靈芝純陽顯著靈跡因名</span>  
<span style="margin-left: 2em">誠吾松第一山也自元至正間道士李德安復建歲</span>  
<span style="margin-left: 2em">久傾圮　洪武初金志信重修永樂中陸道泓來住</span>  
<span style="margin-left: 2em">持繼李朝陽戒行超卓道術高妙常以殿宇卑隘不</span>  
<span style="margin-left: 2em">足以壯觀一郡爲歉成化初先搆兩祠請縣學內文</span>  
<span style="margin-left: 2em">昌像奉於左塑純陽像奉於右勤苦精修不十載四</span>  
<span style="margin-left: 2em">衆皈依遂以其徒江守澄竭力經營撤而更之正殿</span>  
<span style="margin-left: 2em">三間高四丈六尺廣視高倍五丈一尺深倍廣者四</span>  
<span style="margin-left: 2em">丈八尺後殿三間廣與高深俱殺焉正殿真武居之</span>  
<span style="margin-left: 2em">後殿老子居之文昌純陽二祠則徙於後殿前之左</span>  
<span style="margin-left: 2em">右利濟侯祠以及山門諸所焕然一新其殿始工之</span>  
<span style="margin-left: 2em">日正余奉勅致仕還家之又明年也越三載而落成</span>  
<span style="margin-left: 2em">朝陽乃謁余請記其事余常聞朝陽教其徒若孫有</span>  
<span style="margin-left: 2em">曰吾輩絶俗之士忠孝大事既不得與亦當以一念</span>  
<span style="margin-left: 2em">不欺爲忠一事不苟爲孝深竊嘆其道家者流本清</span>  
<span style="margin-left: 2em">靜無爲而朝陽獨尚忠孝殆學老而行儒者歟此余</span>  
<span style="margin-left: 2em">於是院所以樂爲之記也遂俾錄歸刻諸石正德三</span>  
<span style="margin-left: 2em">年戊辰夏五月</span>  
<span style="margin-left: 2em">孫文簡承恩重修碑記畧　松有蓬萊道院者在郡</span>  
<span style="margin-left: 2em">治東百五十步許地當通衢委巷北折甚幽寂宋紹</span>  
<span style="margin-left: 2em">興間始創元至正間道士李德安復建歲久而圮成</span>  
<span style="margin-left: 2em">化癸卯李朝陽始改建之易卑爲崇廓隘爲廣闢陋</span>  
<span style="margin-left: 2em">爲深中爲正殿祀真武祀其師老君於寢殿祀文昌</span>  
<span style="margin-left: 2em">君并唐呂真人於左右廡前建利濟侯祠正德己卯</span>  
<span style="margin-left: 2em">秋震雷碎其正殿之二柱江之徒衛大溥者率其徒</span>  
<span style="margin-left: 2em">鍾秉彝復修之支傾補弊益以藻飾則陛級峻整丹</span>  
<span style="margin-left: 2em">彩華焕地若拓而益宏殿若升而益崇景若闢而益</span>  
<span style="margin-left: 2em">幽明軒浄牖深院曲房花木葱茸雅潔娟麗若不與</span>  
<span style="margin-left: 2em">市廛接也院未有記無以爲山門重抑無以詔後人</span>  
<span style="margin-left: 2em">以締造之艱且將泯泯以至墮廢遂爲文以刻石復</span>  
<span style="margin-left: 2em">繫之詩曰道原於一渾淪沕穆宰世立極吾道攸屬</span>  
<span style="margin-left: 2em">老氏者作同源異曲清靜爲宗恬澹寡欲闡教傳世</span>  
<span style="margin-left: 2em">久益顯暴爰有攸處以寄高躅奕奕斯宫松城之隩</span>  
<span style="margin-left: 2em">地僻而𥥆光景清淑復創勝國郡乘可覆明益開拓</span>  
<span style="margin-left: 2em">殿宇高矗於赫聖帝玄衮皂纛金印寶劍龜蛇承足</span>  
<span style="margin-left: 2em">太上高居寢殿嚴肅文昌純陽冠弁羽服萬靈訶護</span>  
<span style="margin-left: 2em">四衆瞻矚歲在單閼雷斧棟木天威有臨若儆玩瀆</span>  
<span style="margin-left: 2em">有大羽士戒行貞獨值變兢惕懺悔退伏竭力繕治</span>  
<span style="margin-left: 2em">倒廪罄匵藻飾其餘罔有弗穀若增而勝丹彩溢目</span>  
<span style="margin-left: 2em">瀛海異境恍在塵陸頗疑其間僊侣棲宿神藥靈芝</span>  
<span style="margin-left: 2em">皓鶴玄鹿白雲迷户香靄覆屋允惟清虛逈隔凡俗</span>  
<span style="margin-left: 2em">石磬瑶笙玉版金籙考擊鐘鼓警徹昏旭玄臺冥冥</span>  
<span style="margin-left: 2em">丹府煜煜泊然虛無神朗內燭匪兹靈區曷斷諸慾</span>  
<span style="margin-left: 2em">思貽厥謀言謹其屬爰謁史氏彤管紀錄刻之貞珉</span>  
<span style="margin-left: 2em">庸代面告咨爾後人罔敢弗勗精進焚修秉志誠篤</span>  
<span style="margin-left: 2em">毋墮前功殫力繼續上祝皇釐下祈民福四氣順布</span>  
<span style="margin-left: 2em">雨暘寒燠以及衆生均囿化育嘉靖十有一年壬辰</span>  
<span style="margin-left: 2em">歲秋八月既望</span>  
<span style="margin-left: 2em"><sub class="note-yuan">元張昱詩雲近蓬萊蜃氣消數峯晴照遠相招梁間燕子都歸去觀裏桃花自寂寥盂飯化人忘戀戀院牆篁竹謾蕭蕭雲中何處劉安宅猶有鷄聲報午朝</sub></span>  
<span style="margin-left: 2em">八僊祠<sub class="note-yuan">在道院之東偏萬曆年間有雲水道者從東省至憇於僉憲俞公汝爲家談未來語多神異謂雲間大郡可無八僊祠俞公倡舉之太學生宋啟文助建</sub></span>  
<span style="margin-left: 2em">盟素道院府東南舊城隍廟側元至元二十七年天</span>  
<span style="margin-left: 2em">台桐柏宫祝知觀創始至正十二年道士吳蟾友王</span>  
<span style="margin-left: 2em">玄靜建　國朝成化己丑旱知府田臻禱而得雨命</span>  
<span style="margin-left: 2em">住院王惟端等重修正德己巳道士王大經建三清</span>  
<span style="margin-left: 2em">閣久圮天啟癸亥重建　朝元道院在泖口元大德</span>  
<span style="margin-left: 2em">間道士陸景真建去府<sub class="note-yuan">二十七里</sub></span>  
<span style="margin-left: 2em">朝真道院在干山元至正三年道士郭松溪建萬曆</span>  
<span style="margin-left: 2em">中重修建餐霞館</span>  
<span style="margin-left: 2em">明真道院在朱涇鎮元泰定中里人陳原𣇄建大興</span>  
<span style="margin-left: 2em">道院在蕭塘鎮元至正中道士范道隆建太清道院</span>  
<span style="margin-left: 2em">在俞塘洪武元年道士吳松谷建萬曆間改太清禪</span>  
<span style="margin-left: 2em">院僧蘇湛然重建</span>  
<span style="margin-left: 2em">太古菴宋建在府西三百步</span>  
<span style="margin-left: 2em">施水菴元至元間道士葉雲建後唐月心捨地重建</span>  
<span style="margin-left: 2em"><sub class="note-yuan">府東南五十四里</sub></span>  
<span style="margin-left: 2em">上真菴在翁家莊西距府七十里元泰定二年道士</span>  
<span style="margin-left: 2em">蕭野雲建</span>  
<span style="margin-left: 2em">上真堂在金山衛東門元至元間道士王惟謙建</span>  
<span style="margin-left: 1em">長春道院府城集僊門內橋北元大德十年道士鄭道</span>  
<span style="margin-left: 2em">真建爲境內全真教祖　國朝歸併院七菴堂二</span>  
<span style="margin-left: 2em">浮梁楊載記　余游松江假館長春道院其主人則</span>  
<span style="margin-left: 2em">錢塘鄭君道真君之言曰僕幼時聞北方人爲全真</span>  
<span style="margin-left: 2em">教其祖師則長春丘真人得鍊氣養神之道入火不</span>  
<span style="margin-left: 2em">焦入水不濡出人有無變化不測壽無所止極與天</span>  
<span style="margin-left: 2em">地終始心甚慕焉父故將家將卒千人戍守嚴陵因</span>  
<span style="margin-left: 2em">病免官其軍之大將將以僕名聞朝廷予父舊卒使</span>  
<span style="margin-left: 2em">襲父官僕自念苟學道有功得如丘真人雖貴爲王</span>  
<span style="margin-left: 2em">侯猶不足比儗何有於列較哉縻繫於此終不得爲</span>  
<span style="margin-left: 2em">所欲爲者矣遁去至永嘉師受道要居密室中累年</span>  
<span style="margin-left: 2em">一旦心躍然思歸不可制止歸則父母皆已卒葬慨</span>  
<span style="margin-left: 2em">然嘆曰身無卻顧之憂吾道其遂成乎於是益務遠</span>  
<span style="margin-left: 2em">游至松江松江人無爲全真教者非僕客朱氏則俱</span>  
<span style="margin-left: 2em">託於逆旅主人僕遂有志結菴買地二畝築室四間</span>  
<span style="margin-left: 2em">度弟子朱道本等使嗣守之以待來者僕尋去之丹</span>  
<span style="margin-left: 2em">陽欲渡江不果復還永嘉時邑中大家計肅夏世昌</span>  
<span style="margin-left: 2em">二人志尚清虛雅好道術增地七畝創制爲今道院</span>  
<span style="margin-left: 2em">使人招致僕主其事余聞北方人以全真名教始重</span>  
<span style="margin-left: 2em">陽王真人金之衰也諸侯割據山東鼎沸王真人之</span>  
<span style="margin-left: 2em">貌異於常人慨然有拯天下之志天數奪其計其徒</span>  
<span style="margin-left: 2em">壯士叛己因絶食居山中積數年有道爲神仙度弟</span>  
<span style="margin-left: 2em">子七人丘真人最後出本朝聞其賢遣臣劉仲禄迎</span>  
<span style="margin-left: 2em">至漠北謂太祖受命于天爲萬姓除殘賊必無多殺</span>  
<span style="margin-left: 2em">上感其言斬刈之威大爲衰止繇是山東之人始有</span>  
<span style="margin-left: 2em">生殖之望焉夫爲道者無爲而無不爲而善藏其用</span>  
<span style="margin-left: 2em">則可以功濟天下古之人有知之者子房是也今丘</span>  
<span style="margin-left: 2em">真人以度世爲業而能盡力匡維有補於萬億年之</span>  
<span style="margin-left: 2em">鴻緒挈功盛大詎讓子房哉今爲其學者皆絶去嗜</span>  
<span style="margin-left: 2em">好以觕惡爲衣食室中徒設榻植坐內踵狀類禪定</span>  
<span style="margin-left: 2em">而中有所事事其法具於抱朴子第丘真人之道顯</span>  
<span style="margin-left: 2em">重於世故學者推之以爲祖焉道院之制爲前殿祠</span>  
<span style="margin-left: 2em">事老子其外兩廡其後爲堂高下降殺與殿相承余</span>  
<span style="margin-left: 2em">所假館直室之東北隅曲徑深窅有池水叢竹之勝</span>  
<span style="margin-left: 2em">鄭君之爲人無驕氣無惰容色常欣欣然如髫齔爲</span>  
<span style="margin-left: 2em">童子時鄉人化其善賢者樂從之游鄭君視之泊然</span>  
<span style="margin-left: 2em">不以繫累乎其心有道之候庶幾在兹<sub class="note-yuan">至治元年四月十五日又春雨即事呈鄭尊師南榮相距數尋間滿地春泥隔往還夜雨暗添籬脚水曉雲濃掩樹頭山修篁夾徑宜增植細草侵堦莫漫删世慮紛紛無止極敢求大藥駐衰顔王逢題長春道院桂風子與朱貞一真人詩仙人桂風子勇別上清君晞髮三神日巢松五老雲桃椎今問訊奎閣舊論文游幔峯青疊蓬頭並鶴群</sub></span>  
<span style="margin-left: 2em">谷水道院在府城西谷水坊內前志云在瑁湖北許</span>  
<span style="margin-left: 2em">尚百詠題有道院註在西湖之西後爲延氏蔬圃疑</span>  
<span style="margin-left: 2em">即此地曰谷水者湖之故名也宋寶慶二年道士陸</span>  
<span style="margin-left: 2em">景微建　國朝洪武二十年道士葉雲谷增修後燬</span>  
<span style="margin-left: 2em">於火道士黃碧窗里人馬驥等重建今湖已湮廢院</span>
