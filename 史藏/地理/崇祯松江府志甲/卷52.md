## 崇禎松江府志卷之五十二　寺院下（尼寺附）

<span style="margin-left: 3em">寺院<sub class="note-yuan">三</sub></span>  
<span style="margin-left: 2em">上海<sub class="note-yuan">新隸青浦附</sub></span>  
<span style="margin-left: 1em">觀音禪寺在縣西宋崇寧初建淳熙三年賜額慈報禪</span>  
<span style="margin-left: 2em">院從錢參政良臣請也僧覺印開山元燬國朝洪武</span>  
<span style="margin-left: 2em">十六年僧性重建改今額爲縣之首刹前有茂林後</span>  
<span style="margin-left: 2em">有萬工山萬工所成也占地數畝已夷爲田其陂陀</span>  
<span style="margin-left: 2em">古栢即遺址歸併寺二院一菴二</span>  
<span style="margin-left: 2em">教諭尹務厚記畧　觀音寺在上海縣西十八里時</span>  
<span style="margin-left: 2em">有觀音聖像浮海而來咸異之錢參政良臣捨貲禮</span>  
<span style="margin-left: 2em">雲門禪師七世孫覺印創于宋崇寧年爲縣禪宗首</span>  
<span style="margin-left: 2em">刹元季廢爲瓦礫洪武壬戌僧會本源性公與其徒</span>  
<span style="margin-left: 2em">紹一募建法堂前觀音像流寓九峯間見夢於性舟</span>  
<span style="margin-left: 2em">載以復庚午募建殿東西廡三年住持本山甲戌縣</span>  
<span style="margin-left: 2em">尹張守約捐貲建大佛殿丁丑買民房建天王殿及</span>  
<span style="margin-left: 2em">山門庚辰尹杜鎰復營香積廚一所自後法堂鐘樓</span>  
<span style="margin-left: 2em">以次而舉凡立屋若干楹拓地若干畝徵予記之永</span>  
<span style="margin-left: 2em">樂二年十月</span>  
<span style="margin-left: 2em">寧國寺宋隆興元年僧昌月堂建於時有張百五公</span>  
<span style="margin-left: 2em">者富埒公侯寺蓋其經始乾道二年請額寺在烏涇</span>  
<span style="margin-left: 2em">之陽華上兩邑之界與龍華南北相望殿前有羅漢</span>  
<span style="margin-left: 2em">松四株枝幹森矗古色蒼然蓋三四百年物也萬曆</span>  
<span style="margin-left: 2em">丙寅歲張方伯所望創義修復三載始還舊觀</span>  
<span style="margin-left: 2em">黃道婆祠<sub class="note-yuan">烏泥涇鎮人趙如珪建元季兵燬國朝成化間知縣劉琬重建後廢萬曆初張憲幕之象建於張家滨丙寅張方岳所望附建於寺之西偏張之象記云上海西南廿餘里爲烏泥涇故有道婆祠云道婆者姓黃氏本鎮人也初淪落崖州元元貞間附海舶歸閩廣多種木棉織紡爲布名曰吉貝而道婆最善是業州里宗之先此烏泥涇土壤墝瘠民多困貧因謀樹藝以給遂覓種於閩廣間然尚無踏車椎弓之制率用手擘去子線弦竹弧置案間振掉成劑厥功甚艱道婆乃教以製造捍彈紡織之具既以便民矣至于錯紗配色綜綫挈花又各有法故被褥帨帶之類織以折枝團鳳棋局文字粲然若寫土人競相倣習稍稍轉售他方以牟利業頗饒裕未幾道婆卒莫不感恩灑泣而共葬之已立祠歲時享之越三十年祠燬里人趙某再爲立祠今再燬又數十年於兹矣頃歲行游其所求問前所謂道婆祠者業已頽廢鞠爲灌莽撫蹟增感低回歔欷者久之予遂於居舍之東北隅聽鶯橋伴捨地二畝其右爲南北周行乃集里中嘗所稱尚義者凡若干人共圖興復經始方旬而焕然改飭像設具備神有棲憑于是里中庶士咸曰宜之落成之日爰來請記蓋是舉予實倡之也義何可辭先王之制禮也法施于民則祀之吾松之民仰機利以食實此道婆發之苟被其澤者無忘追本之思則道婆祠祀可不廢矣張所望碑吾鄉之祠黃道婆也始自勝國之季而燬於兵其後重建輒復廢而吾家王屋公改祠于張家浜者不三十年亦已化爲榛莽余每過而傷之念昔物壤磽瘠民困無聊生養至今伊誰之賜且輸貢尚</sub></span>  
<span style="margin-left: 2em">方衣被寰宇明德遠矣食報謂何間與里中好事謀所以擬<sub class="note-jiao">校：似當拟字之訛也今改作拟之正體擬]續不朽者竊謂榱棟維新黍離興感昔人所慨諒非無因矧兹數椽越在荒阻地僻則寡助事遠則易忘旋興旋廢勢所必至夫惟金僊氏之教終古尚存而道婆故皈依法門亦諸佛所攝受俎豆于斯庶幾永劫不壞乎衆皆是余言於是議即寧國寺之西偏附建一祠余遂捐資首事屬寺僧董其役就能仁之精藍作報功之福地祠宇既飭遹臻厥成像設莊嚴輪奂輝奕爰易舊額錫以嘉名勒之貞珉是稱黃母蓋衣食之源嫗實開之恩斯勤斯等于育我是所謂衆人之母也而以母道事之誰曰不然余乃躬率里人設蘋藻之奠拜于祠下群情胥懌神用居歆衆乃合詞進曰歲比不登吉貝靡所獲母其陰相我下土令杼</sub></span>  
<span style="margin-left: 2em">軸<sub class="note-jiao">校：柚當軸字之訛也今改]不空民以康乂繼自今祗奉禋祀其無斁皆再拜稽首而退屬余記之如此至其航海來歸教民織作之始末輟耕錄載之已詳兹不重述王逢詩前聞黃四娘後稱宋五嫂道婆異流輩不肯崖州老崖州布被五色繅組霧紃雲粲花草片帆鯨海得風歸千軸烏涇奪天造天孫漫司巧僅解製牛衣鄒母真乃賢訓兒諭斷機道婆遺愛在桑梓道婆有志覆赤子荒哉唐玄萬乘君終靦長衾共昆弟趙翁立祠兵火燬張君慨然繼絶祀我歌落葉秋聲裏薄功厚享當愧死胡芳詩黃婆古廟秋復春不見年來祭賽人當時抛却金梭去誰教吳姬織白雲</sub></span>

<span style="margin-left: 2em">者贖之先是以甲乙住兹山　國朝洪武二十四年</span>  
<span style="margin-left: 2em">清理佛教立爲四方禪林請一公象先董其事三十</span>
