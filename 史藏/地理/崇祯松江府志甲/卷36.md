<span style="margin-left: 3em">賢達</span>  
<span style="margin-left: 1em">初續顧文僖人物自正德己巳至嘉靖止而隆萬則姑</span>  
<span style="margin-left: 1em">有待焉俟論定耳俞彦直計偕歸更分析諸科其列名</span>  
<span style="margin-left: 1em">仕版者改名臣而稱賢達仍王屋張先生上海志之舊</span>  
<span style="margin-left: 1em">也先生曰後輩事鄉先達寧爲春秋調人無爲公穀輸</span>  
<span style="margin-left: 1em">墨正直忠厚劑而衷之庶幾善善長之遺意哉</span>  
<span style="margin-left: 1em">漢</span>  
<span style="margin-left: 1em">陸閎字子春華亭人篤行好學聰明有令德選尚寧平</span>  
<span style="margin-left: 1em">公主辭疾不應爲穎川太守致鳳凰甘露之瑞建武中</span>  
<span style="margin-left: 1em">爲尚書令姿容如玉喜着越布單衣光武升臺見之歎</span>  
<span style="margin-left: 1em">曰南方固多佳人自是常勑會稽郡獻越布焉</span>  
<span style="margin-left: 2em">穎川太守陸宏墓在華亭縣西北四十里按宏績長</span>  
<span style="margin-left: 2em">子官會稽南部都尉其爲穎川太守者曰閎乃宏八</span>  
<span style="margin-left: 2em">世祖耳見姑蘇志雲間舊志亦稱穎川太守宏顧文</span>  
<span style="margin-left: 2em">僖清修郡志改稱南部都尉聞之先輩云職銜不誤</span>  
<span style="margin-left: 2em">乃宏閎音同而誤耳陸墓實閎也</span>  
<span style="margin-left: 1em">陸康字季寧少篤孝悌勤修操行太守李肅舉孝廉肅</span>

<span style="margin-left: 1em">備不虞不得往來長吏新到輒發民繕城郭康至皆罷</span>  
<span style="margin-left: 1em">遣百姓大悦以恩信爲治寇盜亦息州郡表上其狀光</span>  
<span style="margin-left: 1em">和元年遷武陵太守轉桂陽安樂二郡所在稱之時靈</span>  
<span style="margin-left: 1em">帝欲鑄銅人而國用不足乃詔民田畝斂十錢比水旱</span>  
<span style="margin-left: 1em">貧苦康上疏諫內倖因譖康大不敬檻車徵詣廷尉侍</span>  
<span style="margin-left: 1em">御史劉岱陳解免歸復徵拜議郎會廬江賊黃穰等與</span>  
<span style="margin-left: 1em">江夏蠻連結十餘萬人攻破四縣拜康廬江太守康申</span>  
<span style="margin-left: 1em">明賞罰擊破穰等餘黨悉降帝嘉之拜其孫尚爲郎中</span>  
<span style="margin-left: 1em">獻帝即位天下大亂康蒙險遣孝廉計吏奉貢詔書策</span>  
<span style="margin-left: 1em">勞加忠義將軍秩中二千石時袁術屯兵壽春部曲饑</span>  
<span style="margin-left: 1em">餓遣使求委輸兵甲康以其叛逆閉門不通內修戰備</span>  
<span style="margin-left: 1em">將以禦之術怒遣孫策攻康圍城數重康固守二年城</span>  
<span style="margin-left: 1em">陷憤病卒朝廷愍其守節拜子儁爲郎中少子績</span>  
<span style="margin-left: 2em">陸氏居華亭攷劉孝標世說注曰華亭繇拳縣郊外</span>  
<span style="margin-left: 2em">墅也有清泉茂林吳平後陸機兄弟共遊於此陸廣</span>  
<span style="margin-left: 2em">微吳地記云漢廬江太守陸康與袁術有隙使從子</span>  
<span style="margin-left: 2em">遜與其子績將家還吳居於長谷二說各異然士龍</span>  
<span style="margin-left: 2em">集載與陸典書書云華亭之望以大人爲宗主又云</span>  
<span style="margin-left: 2em">想令仁士光令遠公然兄弟屢數嘗存思想則陸氏</span>  
<span style="margin-left: 2em">已聚族居焉斷非始於機雲其謂葬於吳郡之胥屏</span>  
<span style="margin-left: 2em">者吳令烈葬於華亭之崑山者穎川太守閎斯言是</span>  
<span style="margin-left: 2em">也故魏了翁建學記云左太冲所謂高門鼎貴魁岸</span>  
<span style="margin-left: 2em">豪傑虞魏之昆顧陸之裔雖通言吳郡而居華亭爲</span>  
<span style="margin-left: 2em">尤著自士衡士龍以至唐宰相元方象先希聲或隨</span>  
<span style="margin-left: 2em">世以就功名敬輿則巋然三代人物也猗與盛矣</span>  
<span style="margin-left: 2em">陸氏世系攷陸氏出田寬後封於陸鄉因以氏焉齊</span>  
<span style="margin-left: 2em">大夫發生二子曰萬曰臯臯子邕生漢大中大夫賈</span>  
<span style="margin-left: 2em">萬生烈字伯元爲吳令既殁吳人思之迎葬於胥屏</span>  
<span style="margin-left: 2em">亭子孫遂爲吳人十傳而至穎川太守閎字子春賜</span>  
<span style="margin-left: 2em">之子也葬於華亭閎生三子曰卭曰温曰桓號穎川</span>  
<span style="margin-left: 2em">枝桓字叔文生續字知初揚州別駕續生三子曰稠</span>  
<span style="margin-left: 2em">曰逢曰褒號荆州枝續長子稠荆州刺史生二子曰</span>  
<span style="margin-left: 2em">肅曰謙肅丹徒令號丹徒枝續中子逢漢尚書左僕</span>  
<span style="margin-left: 2em">射樂安侯生五子曰涉曰表曰瓊曰吳曰招號樂安</span>  
<span style="margin-left: 2em">枝表生漢海鹽縣令穰字子仁穰生恢晉諫議大夫</span>  
<span style="margin-left: 2em">恢生永興縣令弘號諫議枝續少子褒字叔明生三</span>

<span style="margin-left: 2em">二子曰儁曰績儁郎中績字公紀欝林太守生三子</span>  
<span style="margin-left: 2em">曰宏曰尚曰叡宏會稽南郡都尉尚郎中叡長水較</span>
