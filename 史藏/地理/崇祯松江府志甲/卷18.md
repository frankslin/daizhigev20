## 崇禎松江府志卷之十八　水利下

<span style="margin-left: 3em">水利<sub class="note-yuan">三</sub></span>  
<span style="margin-left: 1em">唐開元元年築捍海塘起杭州鹽官抵吳淞江長一百</span>  
<span style="margin-left: 2em">五十里<sub class="note-yuan">參前志唐書地里志</sub></span>  
<span style="margin-left: 1em">吳越錢氏嘗置都水營田使以主水事募卒爲都號曰</span>  
<span style="margin-left: 2em">撩淺亦謂之撩清</span>  
<span style="margin-left: 1em">宋寶元元年兩浙轉運副使葉清臣開松江盤龍滙按</span>  
<span style="margin-left: 2em">續吳郡圖經盤龍滙介華亭崑山之間步其徑纔十</span>  
<span style="margin-left: 2em">里而迴泬迂緩乃四十里江流爲之阻遏盛夏大雨</span>  
<span style="margin-left: 2em">則汎溢淪稼穡壞室廬殆無寧歲乾興間屢經疏決</span>  
<span style="margin-left: 2em">未得其要范文正公守平江嘗經度之未遑興作至</span>  
<span style="margin-left: 2em">是清臣以太史轉漕本路建議釃爲新渠從滬瀆入</span>  
<span style="margin-left: 2em">海道直流速其患遂弭<sub class="note-yuan">清臣祭龍王文作景祐五年戊寅按戊寅即寶元元年豈改元在其後耶</sub></span>  
<span style="margin-left: 2em">葉清臣祭滬瀆龍王文　清臣叨被朝恩出持使斧</span>  
<span style="margin-left: 2em">觀采風俗詢究利病上分天子之寄下救斯民之瘼</span>  
<span style="margin-left: 2em">職思其守靡敢怠遑眷惟全吳舊多積水加以夏秋</span>  
<span style="margin-left: 2em">霖潦田疇污没浩浩罔濟人無聊生聞諸鄉老之言</span>  
<span style="margin-left: 2em">患在盤龍之滙但陵谷變遷枉直倍差水道回遏湖</span>  
<span style="margin-left: 2em">波壅滯自乾興以來屢經疏決未得其要不免爲沴</span>  
<span style="margin-left: 2em">蘇秀之人皆云神故有廟在江涘錢氏有土祀典惟</span>  
<span style="margin-left: 2em">寅霜星貿移棟宇崩壞官失簡校民無尊奉自時厥</span>  
<span style="margin-left: 2em">後歲亦多水且謂神不血食降災下民清臣躬行按</span>  
<span style="margin-left: 2em">視狥人所欲乘乎農隙釃此江流神果有靈主斯蓄</span>  
<span style="margin-left: 2em">洩敢告無風雪無瘥癘舉臿而土潰決渠而水降改</span>  
<span style="margin-left: 2em">昔沮澤化爲壤田即當嚴督郡縣修復祠貌春秋致</span>  
<span style="margin-left: 2em">饗蘋藻如故若疲吾役夫不能弭患則我躬不閲皇</span>  
<span style="margin-left: 2em">恤於神神惟聰明昭鑒無忽</span>  
<span style="margin-left: 1em">慶曆元年知華亭縣錢貽範開顧會浦章峴有記載宦</span>  
<span style="margin-left: 2em">績中</span>  
<span style="margin-left: 1em">嘉祐三年轉運使沈立開崑山之顧浦五年轉運使王</span>  
<span style="margin-left: 2em">純臣請令蘇湖常秀修作田塍位位相接以禦風濤</span>  
<span style="margin-left: 2em">令縣官教誘殖利之户自作塍岸定其勸課爲殿最</span>  
<span style="margin-left: 2em">六年轉運使李復圭知崑山韓正彦開松江之白鶴</span>  
<span style="margin-left: 2em">滙如盤龍之法崇寧中郟亶又浚治之皆爲民利</span>  
<span style="margin-left: 1em">熙寧元年有詔興修水利七月命雍元直自昭文編校</span>  
<span style="margin-left: 2em">治浙西河渠二年十二月頒農田水利約束六年命</span>  
<span style="margin-left: 2em">校正中書刑房工事沈括相度浙西水利</span>  
<span style="margin-left: 1em">元祐三年常平使者調蘇湖常秀之人濬青龍江分地</span>  
<span style="margin-left: 2em">程役常熟丞郭三益所部前期告辦</span>  
<span style="margin-left: 1em">紹聖中浙部水溢轉運副使毛漸奏請按錢氏有國時</span>  
<span style="margin-left: 2em">故事起長安堰至鹽官徹清水浦入海無錫芙蓉湖</span>  
<span style="margin-left: 2em">武進廟堂港常熟疎涇梅李以入揚子江又開崑山</span>  
<span style="margin-left: 2em">七鴉下張諸浦東北道吳江開大盈顧滙二浦東南</span>  
<span style="margin-left: 2em">浚柘湖新涇下金山小官浦悉入於海自是水不爲</span>  
<span style="margin-left: 2em">患</span>  
<span style="margin-left: 1em">崇寧二年宗正丞徐確提舉常平考三江之說以爲太</span>  
<span style="margin-left: 2em">湖東注於海松江正在下流向來潮泥堙塞水溢爲</span>  
<span style="margin-left: 2em">患請自封家渡古江開淘至大通浦直徹海口七十</span>  
<span style="margin-left: 2em">四里以常平錢米十八萬三千餘充調夫之費因令</span>  
<span style="margin-left: 2em">飢民就食確躬操畚臿以先之水道遂通或言飢民</span>  
<span style="margin-left: 2em">就役多死降三秩確曰使此役不興飢民當駢首就</span>  
<span style="margin-left: 2em">死以此獲愆吾所願也</span>  
<span style="margin-left: 1em">大觀元年中書舍人許光凝奏太湖入海然後水有所</span>  
<span style="margin-left: 2em">歸今吳中積水視去歲損二尺前歲損四尺良繇開</span>  
<span style="margin-left: 2em">松江濬八浦之力吳人謂開一江有一江之利濬一</span>  
<span style="margin-left: 2em">浦有一浦之利願委官詳究利害十一月詔委本路</span>  
<span style="margin-left: 2em">監簡檢按松江古跡疏導三年兩浙監司奏請開濬</span>  
<span style="margin-left: 2em">吳淞江復置十二牐</span>  
<span style="margin-left: 1em">宣和元年兩浙提舉常平趙霖濬松江白鶴滙又役夫</span>  
<span style="margin-left: 2em">八萬三千七百有奇圍裹華亭泖爲田二年八月罷</span>  
<span style="margin-left: 2em">役勾收入吏送平江府右獄磨勘錢物</span>  
<span style="margin-left: 1em">紹興四年鹽官丞王珏開華亭海河二百餘里通漕溉</span>  
<span style="margin-left: 2em">田民享其利</span>  
<span style="margin-left: 1em">十五年通判曹泳重開顧會浦　楊炬記　三江東注</span>  
<span style="margin-left: 2em">震澤介其間潦集川溢畎澮皆盈而浙右數被水患</span>  
<span style="margin-left: 2em">蘇秀湖三州地形益下故爲害滋甚紹興甲子夏大</span>  
<span style="margin-left: 2em">水吳門以東沃壤之區悉爲巨浸部使者飭郡邑詢</span>  
<span style="margin-left: 2em">求故道導源決壅以洩水勢於是監州曹公以身任</span>  
<span style="margin-left: 2em">責慨然興嘆曰吾嘗巡行屬邑講問民瘼亦既有得</span>  
<span style="margin-left: 2em">於此顧未有以發之也觀雲間之爲縣連亘百里彌</span>  
<span style="margin-left: 2em">望皆陂湖沮澤當春農事方興則桔橰蔽野必盡力</span>  
<span style="margin-left: 2em">於積水而後能種藝是宜地勢愈卑當有支渠分導</span>  
<span style="margin-left: 2em">瀦水而納之海乃歷覽川源攷視高下訪於父老謀</span>  
<span style="margin-left: 2em">之邑僚得顧會港自縣之北門至青龍鎮浦凡六十</span>  
<span style="margin-left: 2em">里南接漕渠而下屬於松江按上流得故閘基僅存</span>  
<span style="margin-left: 2em">敗木是爲旱潦潮水蓄洩之限復得慶曆二年修河</span>  
<span style="margin-left: 2em">記於縣圃而知兹河興廢之歲月與夫淺深廣狹之</span>  
<span style="margin-left: 2em">制役徒錢穀之數判然察其惠利之實有在於此矣</span>  
<span style="margin-left: 2em">蓋歷百有六年浦久不濬而淪塞淤澱行爲平陸遂</span>  
<span style="margin-left: 2em">以狀請於朝籍縣之新江海隅北亭集賢四鄉食利</span>  
<span style="margin-left: 2em">之民以疏治之官給錢糧而董以縣令簿尉公偃冒</span>  
<span style="margin-left: 2em">風霜率先僚屬興工自十月二十有六日及三月而</span>  
<span style="margin-left: 2em">河成起青龍浦及於北門分爲十部因形勢上下爲</span>  
<span style="margin-left: 2em">級十等北門之外增深三尺而下至鎮浦極於一丈</span>  
<span style="margin-left: 2em">面横廣五丈有奇底通三丈據上流築兩狹隄因舊</span>  
<span style="margin-left: 2em">基爲閘而新之復於河之東闢治行道建石梁四十</span>  
<span style="margin-left: 2em">六通諸小涇以分東鄉之渟浸不旬浹水落土墳繇</span>  
<span style="margin-left: 2em">是自簳山東西民田數千頃昔爲魚鼇之藏皆出爲</span>  
<span style="margin-left: 2em">膏腴豈不美哉役工二十萬用糧以石計七千二百</span>  
<span style="margin-left: 2em">爲錢以緡計二萬五千若其他凡見於前記者兹不</span>  
<span style="margin-left: 2em">暇錄訖工之辰憲臺以常平官復視公與邑僚泛舟</span>  
<span style="margin-left: 2em">從遊還謂炬當書其實以刻于碑之陰毋事于贅也</span>  
<span style="margin-left: 2em">炬安敢不勉遂識其歲月及其功利而不復爲之文</span>  
<span style="margin-left: 1em">乾道二年轉運副使姜詵開通波大港<sub class="note-yuan">即顧會浦</sub>置張涇堰</span>  
<span style="margin-left: 2em">閘許克昌有記載本傳</span>  
<span style="margin-left: 1em">七年知秀州丘崈修華亭瀕海十八堰遂移新涇堰於</span>  
<span style="margin-left: 2em">運港<sub class="note-yuan">所謂運港大堰</sub>九年置監堰官於亭林按前志華亭東</span>  
<span style="margin-left: 2em">南並海自柘湖湮塞置堰一十八所以禦鹹潮宋政</span>  
<span style="margin-left: 2em">和中提舉常平官興修水利欲涸亭林湖爲田盡決</span>  
<span style="margin-left: 2em">隄堰以泄湖水華亭地勢東南益高西北益卑大抵</span>  
<span style="margin-left: 2em">自三泖五浦下注吳淞江以入海雖決諸堰湖水不</span>  
<span style="margin-left: 2em">可泄鹹水竟入爲害於是東南四鄉爲斥鹵之地民</span>  
<span style="margin-left: 2em">流徙他郡中間州縣官懼其害復故隄堰獨留新涇</span>  
<span style="margin-left: 2em">塘以通鹽運海潮晨夕衝突塘口至闊三十餘丈鹹</span>  
<span style="margin-left: 2em">水延入蘇湖境上<sub class="note-yuan">隆興間言者復請決諸堰以姜詵言而止</sub>是歲八月邑</span>

<span style="margin-left: 2em">諭各裹糧合夫先行掘鑿於是並湖巨浸復爲良田</span>
