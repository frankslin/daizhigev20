## 崇祯松江府志卷之十八　水利下

<span style="margin-left: 3em">水利<sub class="note-yuan">三</sub></span>  
<span style="margin-left: 1em">唐开元元年筑捍海塘起杭州盐官抵吴淞江长一百</span>  
<span style="margin-left: 2em">五十里<sub class="note-yuan">参前志唐书地里志</sub></span>  
<span style="margin-left: 1em">吴越钱氏尝置都水营田使以主水事募卒为都号曰</span>  
<span style="margin-left: 2em">撩浅亦谓之撩清</span>  
<span style="margin-left: 1em">宋宝元元年两浙转运副使叶清臣开松江盘龙汇按</span>  
<span style="margin-left: 2em">续吴郡图经盘龙汇介华亭昆山之间步其径才十</span>  
<span style="margin-left: 2em">里而回泬迂缓乃四十里江流为之阻遏盛夏大雨</span>  
<span style="margin-left: 2em">则泛溢沦稼穑坏室庐殆无宁岁乾兴间屡经疏决</span>  
<span style="margin-left: 2em">未得其要范文正公守平江尝经度之未遑兴作至</span>  
<span style="margin-left: 2em">是清臣以太史转漕本路建议酾为新渠从沪渎入</span>

<span style="margin-left: 2em">职思其守靡敢怠遑眷惟全吴旧多积水加以夏秋</span>  
<span style="margin-left: 2em">霖潦田畴污没浩浩罔济人无聊生闻诸乡老之言</span>

<span style="margin-left: 2em">苏秀之人皆云神故有庙在江涘钱氏有土祀典惟</span>

<span style="margin-left: 2em">后岁亦多水且谓神不血食降灾下民清臣躬行按</span>  
<span style="margin-left: 2em">视狥人所欲乘乎农隙酾此江流神果有灵主斯蓄</span>  
<span style="margin-left: 2em">泄敢告无风雪无瘥疠举臿而土溃决渠而水降改</span>  
<span style="margin-left: 2em">昔沮泽化为壤田即当严督郡县修复祠貌春秋致</span>

<span style="margin-left: 2em">绩中</span>

<span style="margin-left: 2em">患</span>  
<span style="margin-left: 1em">崇宁二年宗正丞徐确提举常平考三江之说以为太</span>

<span style="margin-left: 2em">四里以常平钱米十八万三千余充调夫之费因令</span>  
<span style="margin-left: 2em">饥民就食确躬操畚臿以先之水道遂通或言饥民</span>  
<span style="margin-left: 2em">就役多死降三秩确曰使此役不兴饥民当骈首就</span>  
<span style="margin-left: 2em">死以此获愆吾所愿也</span>

<span style="margin-left: 2em">浦有一浦之利愿委官详究利害十一月诏委本路</span>  
<span style="margin-left: 2em">监简检按松江古迹疏导三年两浙监司奏请开濬</span>  
<span style="margin-left: 2em">吴淞江复置十二牐</span>

<span style="margin-left: 2em">八万三千七百有奇围裹华亭泖为田二年八月罢</span>  
<span style="margin-left: 2em">役勾收入吏送平江府右狱磨勘钱物</span>  
<span style="margin-left: 1em">绍兴四年盐官丞王珏开华亭海河二百余里通漕溉</span>  
<span style="margin-left: 2em">田民享其利</span>  
<span style="margin-left: 1em">十五年通判曹泳重开顾会浦　杨炬记　三江东注</span>  
<span style="margin-left: 2em">震泽介其间潦集川溢畎浍皆盈而浙右数被水患</span>  
<span style="margin-left: 2em">苏秀湖三州地形益下故为害滋甚绍兴甲子夏大</span>  
<span style="margin-left: 2em">水吴门以东沃壤之区悉为巨浸部使者饬郡邑询</span>

<span style="margin-left: 2em">里南接漕渠而下属于松江按上流得故闸基仅存</span>

<span style="margin-left: 2em">盖历百有六年浦久不濬而沦塞淤淀行为平陆遂</span>  
<span style="margin-left: 2em">以状请于朝籍县之新江海隅北亭集贤四乡食利</span>  
<span style="margin-left: 2em">之民以疏治之官给钱粮而董以县令簿尉公偃冒</span>  
<span style="margin-left: 2em">风霜率先僚属兴工自十月二十有六日及三月而</span>

<span style="margin-left: 2em">基为闸而新之复于河之东辟治行道建石梁四十</span>

<span style="margin-left: 2em">为钱以缗计二万五千若其他凡见于前记者兹不</span>

<span style="margin-left: 2em">从游还谓炬当书其实以刻于碑之阴毋事于赘也</span>

<span style="margin-left: 2em">在于谨堤防蓄水泉以备亢旱而已低田易没必藉</span>  
<span style="margin-left: 2em">岸塍以御之永乐中东南大水命尚书夏忠靖公治</span>  
<span style="margin-left: 2em">之其法常以春初编集民夫修筑圩岸取土于附近</span>

<span style="margin-left: 2em">复耕种不为废弛其法密矣为今之计莫若使民于</span>  
<span style="margin-left: 2em">春和之时或取土于田或开濬泾港因土筑岸以固</span>

<span style="margin-left: 2em">于成盖令不严则大户田多者惮于费烦兴浮言以</span>

<span style="margin-left: 2em">一定水乡圩岸之式　高乡田地以河渠为命脉低</span>  
<span style="margin-left: 2em">乡田地以堤岸为命脉而围岸戗岸二者兼举则旱</span>  
<span style="margin-left: 2em">涝有备大凡田之周遭际水处沿河筑岸中为圩田</span>  
<span style="margin-left: 2em">小者数十亩大至数千亩名曰一圩所为圩岸是也</span>  
<span style="margin-left: 2em">或通人烟往来又名官塘但地形不平惟水最平一</span>  
<span style="margin-left: 2em">圩之中必有稍高稍低之处又有最高最低之处而</span>  
<span style="margin-left: 2em">水性就下必就低处若无戗岸则高处常涸低处常</span>  
<span style="margin-left: 2em">溢一圩自分旱涝矣必用戗岸以分之戗者隔别彼</span>  
<span style="margin-left: 2em">此之名圩岸外拒内拦势如城郭当以坚厚为主其</span>  
<span style="margin-left: 2em">厚薄视圩岸之高低而高低随地形之卑亢须详稽</span>  
<span style="margin-left: 2em">涝时水势令圩岸高出一二尺则可无虞矣大约滨</span>  
<span style="margin-left: 2em">大湖处高以丈许为率傍内河处高以五六尺为率</span>  
<span style="margin-left: 2em">高一丈者基阔二丈高五尺者基阔一丈但圩之四</span>  
<span style="margin-left: 2em">围当如一辙若四围皆高而一方独低则全圩皆属</span>  
<span style="margin-left: 2em">无用矣又若四围皆坚而一方独瑕则全圩终被渰</span>  
<span style="margin-left: 2em">没矣然岸基所占之土亦非尽置之无用如高一丈</span>  
<span style="margin-left: 2em">者顶面止阔四五尺其内副岸可阔一丈而副岸视</span>  
<span style="margin-left: 2em">顶面约低二三尺以其毗辅外岸故名副岸俗曰㽘</span>  
<span style="margin-left: 2em">塌又名项头可种菜豆诸杂种是岸基二丈实𢬵废</span>  
<span style="margin-left: 2em">一丈地耳至戗岸但界田间之水不必太高太厚其</span>  
<span style="margin-left: 2em">高约与副岸等如戗岸高五尺岸顶阔半之基与高</span>  
<span style="margin-left: 2em">等而岸顶不系人畜行走处或可种荳此土大都属</span>  
<span style="margin-left: 2em">之无用矣民间惜地不肯分立戗岸者以此不思水</span>  
<span style="margin-left: 2em">发时若有戗岸万一大围溃坏才及一戗则邻戗尚</span>  
<span style="margin-left: 2em">保无虞且浸止一戗众力可戽此家自为守之良法</span>
