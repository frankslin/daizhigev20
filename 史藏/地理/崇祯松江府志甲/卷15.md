## 崇禎松江府志卷之十五　織造　稅課

<span style="margin-left: 3em">織造</span>  
<span style="margin-left: 1em">王者垂衣裳而治天下蓋取諸乾坤尚方天府歲供法</span>  
<span style="margin-left: 1em">服禮也第窮簷絕塞之下不有杼柚其空婦嘆於室者</span>  
<span style="margin-left: 1em">乎又不有卧牛衣之窶士裹鐵衣之邊士乎以此思寒</span>  
<span style="margin-left: 1em">寒可知也頃</span>  
<span style="margin-left: 1em">皇上踐祚初年首停織造三縣額設加編漸可望減</span>  
<span style="margin-left: 1em">聖明儉德普矣哉</span>  
<span style="margin-left: 1em">江南織造惟浙直杭嘉湖蘇松五府設局　祖制差內</span>  
<span style="margin-left: 1em">官一員專任或在杭或在蘇今松有織造局局官司之</span>  
<span style="margin-left: 1em">一曰內號乃　上用袍服常年以春秋二運解進其段</span>  
<span style="margin-left: 1em">之疋數浙直以四六派之而蘇松又以四六分之松局</span>  
<span style="margin-left: 1em">居海隅匠户有逃亡者僅存三百七十餘名分別織挽</span>  
<span style="margin-left: 1em">絡染打線結綜簆七作每遇開造時內中舉選殷實者</span>  
<span style="margin-left: 1em">充堂長之役肩任應辦絲料分發小匠領造段完解京</span>  
<span style="margin-left: 1em">起運之後其價於三縣四司銀解給倘有不敷題留關</span>  
<span style="margin-left: 1em">稅補之逐運清楚縣無欠額匠無罣牽接濟後運從容</span>  
<span style="margin-left: 1em">裕如近來段疋輪運不容遲緩三縣料價拖閣經年充</span>  
<span style="margin-left: 1em">是役者只得捐産揭債賒料　織完及其透價年更有</span>  
<span style="margin-left: 1em">换縣視緩逋煩府行催縣總以新舊托辭千般勒索候</span>  
<span style="margin-left: 1em">得縣中解銀資本先費往例本府發銀便而省費今紊</span>  
<span style="margin-left: 1em">亂舊規解銀監給司房姦蠧任意扣除領銀者十無二</span>  
<span style="margin-left: 1em">三到手復有本監衙門下役皂快門子舍人軍牢班頭</span>  
<span style="margin-left: 1em">轎夫所官跟隨人役蜂屯蟻聚打駡婪詐不遂不已乃</span>  
<span style="margin-left: 1em">致罄身而回宦債不能償商絲不能了東逃西竄涕泣</span>  
<span style="margin-left: 1em">相視而已又如內帑進用之段此係五局總歸蘇杭兩</span>  
<span style="margin-left: 1em">府民匠織造各府堂長出銀隨段解進若有帑銀賫發</span>  
<span style="margin-left: 1em">折本尤可若無帑銀化爲烏有此苦上又苦也又如小</span>  
<span style="margin-left: 1em">匠領一段料舉家驚持妻絡子饋日工夜宿所係者一</span>  
<span style="margin-left: 1em">月四斗口糧先時派米被糧户拖欠續後議以折銀三</span>  
<span style="margin-left: 1em">錢於三縣條編銀內徵解散給此法之至善者也近今</span>  
<span style="margin-left: 1em">又以派發糧户對支與派米無異矣今之停造革除庫</span>  
<span style="margin-left: 1em">役又增一煩守門看庫看機跟官日無暇刻靠此二錢</span>  
<span style="margin-left: 1em">之銀焉能充贍此又苦上又苦也</span>  
<span style="margin-left: 1em">一曰外號歲造段疋向屬有司管理祖制額派每年一</span>  
<span style="margin-left: 1em">千一百六十七疋遇閏月加派淺色素段九十七疋內</span>  
<span style="margin-left: 1em">有大紅織金雲鶴獅子胸背段五十疋每長三十二尺</span>  
<span style="margin-left: 1em">價銀每疋八兩五錢礬紅青黑綠織金犀牛海馬熊羆</span>  
<span style="margin-left: 1em">胸背段四百十疋每長三丈二尺每疋價四兩礬紅青</span>  
<span style="margin-left: 1em">黑綠光素段六百零七疋每長三丈二尺每疋價三兩</span>  
<span style="margin-left: 1em">六錢至萬曆年間奉文將素段一百疋改織大紅織金</span>  
<span style="margin-left: 1em">虎豹胸背段八十三疋每長四丈二尺每價十兩一錢</span>  
<span style="margin-left: 1em">八分礬紅十七疋每價五兩一錢又于天啓四年奉文</span>  
<span style="margin-left: 1em">將素段一百十七疋改織大紅織金斗牛飛魚麒麟等</span>  
<span style="margin-left: 1em">項胸背段丈尺價值與前虎豹段相同其各料價編入</span>  
<span style="margin-left: 1em">三縣會計白銀內徵給先是萬曆三十一年有鎮江府</span>  
<span style="margin-left: 1em">姦民王一卿妄奏每疋段價內扣銀四錢名曰羡餘隨</span>  
<span style="margin-left: 1em">段解進以助大工至四十三年奉文蠲免免徵于民今</span>  
<span style="margin-left: 1em">段價內每疋減銀四錢其扛墊各府每疋一兩一錢本</span>  
<span style="margin-left: 1em">府止得原編六錢段疋解京赴內承運庫交納墊費與</span>  
<span style="margin-left: 1em">各府例不相同有進呈　御覽退駁之虞解户典批揭</span>  
<span style="margin-left: 1em">債賠累告部咨送　撫按轉行道府關防各府相同設</span>  
<span style="margin-left: 1em">處無碍官銀五錢抵給共足一兩一錢之數遵依在卷</span>  
<span style="margin-left: 1em">近又奉文以崇禎元年爲始于扛墊六錢內免茶菓銀</span>  
<span style="margin-left: 1em">九分五厘亦已詳免其大紅段價每兩又減二錢查得</span>  
<span style="margin-left: 1em">先年給銀完段至有侵弊坐問杖配者百名監比二十</span>  
<span style="margin-left: 1em">餘年前歲蒙按院王題豁衆户得生前守許公勒石定</span>  
<span style="margin-left: 1em">規完段給銀官不煩而匠無累此誠良法也又因邇年</span>  
<span style="margin-left: 1em">縣解料銀不足段疋不能完全內庫賞夷缺乏乃有參</span>  
<span style="margin-left: 1em">罰之例且今段疋有司督責抑求精美猶虞交納煩難</span>  
<span style="margin-left: 1em">反將料墊減而又減乃織解兩難之事也</span>  
<span style="margin-left: 1em">一曰急缺又名改造此段五年一坐派專供喜慶頒賞</span>  
<span style="margin-left: 1em">之用其段有紵絲紗羅綾紬絹錦其色有大紅淺色其</span>  
<span style="margin-left: 1em">花樣有彩粧織金閃色蟒龍飛魚斗牛纏身胸背工甚</span>  
<span style="margin-left: 1em">煩瑣料扛蘇松會估相同因無正編惟聽議詳外府四</span>  
<span style="margin-left: 1em">司銀抵織關領有往返之勞守候有盤纏之費</span>  
<span style="margin-left: 1em">一曰綾紗此段十年一派白絲經緯長闊工煩其體式</span>  
<span style="margin-left: 1em">料價浙直相同每長八丈闊三尺二寸其價花者每疋</span>  
<span style="margin-left: 1em">九兩九錢素者每疋九兩七錢供宫殿裱刷窻槅之用</span>  
<span style="margin-left: 1em">紗每長四丈闊與綾同其價每疋一兩七錢供郊社祭</span>  
<span style="margin-left: 1em">祀焚帛之用料扛隨段數之多寡派徵三縣不惟工煩</span>  
<span style="margin-left: 1em">抑且絲價今倍于昔工食物價又倍于昔况絲産于浙</span>  
<span style="margin-left: 1em">地收買易便省盤纏之費吾松隔遠綾價相同亦爲損</span>  
<span style="margin-left: 1em">益交納屬司禮監扛墊每一綾一紗一兩　錢近聞亦</span>  
<span style="margin-left: 1em">議減價亦是兩難之事矣</span>  
<span style="margin-left: 1em">一曰只遜駕衣向無此段近時坐派七百五十副五彩</span>  
<span style="margin-left: 1em">粧花紅淺相半工甚煩瑣每副又有裏絹一疋價彷蘇</span>  
<span style="margin-left: 1em">州銀出外府請詳院道關支不能易於解給</span>  
<span style="margin-left: 1em">今之內外織造皆被中官上下剥削之後小匠悉己困</span>  
<span style="margin-left: 1em">乏今郡侯方公查各年各役所透段價屬縣積逋料銀</span>  
<span style="margin-left: 1em">盡數嚴催解給秋毫不染松局皆沾其惠</span>  
<span style="margin-left: 1em">萬曆□<sub class="note-jiao">校：此處原書作墨丁</sub>年閣臣張居正請罷織造內臣對</span>  
<span style="margin-left: 2em">工部覆禮科左給事中顧九思工科都給事中王道</span>  
<span style="margin-left: 2em">成等疏請罷蘇松及應天織造取回原差內臣　上</span>  
<span style="margin-left: 2em">遣文書官傳諭云　御用袍服緊急織造且未可罷</span>  
<span style="margin-left: 2em">若如部議取回內臣改屬撫按有司則織造不精誰</span>  
<span style="margin-left: 2em">任其責且見有錢糧不必加派先生每擬票來臣與</span>  
<span style="margin-left: 2em">同官二臣持工部疏入見　上於便殿奏云近日蘇</span>  
<span style="margin-left: 2em">松等處水災重大據撫按官奏報及臣等所聞百姓</span>  
<span style="margin-left: 2em">困苦流離朝不謀夕有群聚刼奪者地方錢糧委難</span>  
<span style="margin-left: 2em">措處且自前年星變時親奉　明旨停止織造着孫</span>  
<span style="margin-left: 2em">隆回京至今尚未完報是詔令不信而德澤不宣也</span>  
<span style="margin-left: 2em">臣等謂宜從該部所請以彰　皇上敬天恤民至意</span>  
<span style="margin-left: 2em">民惟邦本願少加聖心　上曰朕未嘗不愛惜百姓</span>  
<span style="margin-left: 2em">但彼處織造不久當完遠不過來春爾臣對言　皇</span>  
<span style="margin-left: 2em">上德意臣民無不欣仰即孫隆在彼亦能仰體聖心</span>  
<span style="margin-left: 2em">安靜行事但地方多一事則有一事之擾寬一分則</span>  
<span style="margin-left: 2em">受一分之賜今彼中織完十未四五物料錢糧尚有</span>  
<span style="margin-left: 2em">未盡徵完者災地疲民不堪催督願　皇上且取回</span>  
<span style="margin-left: 2em">孫隆其應天被災稍輕許坤仍舊可也　上乃許之</span>  
<span style="margin-left: 2em">曰近降去花樣皆御前發出銀兩竝不加派擾民此</span>  
<span style="margin-left: 2em">一件還着織完回京其餘則皆停罷可也臣等頓首</span>  
<span style="margin-left: 2em">曰幸甚蓋是時宫中自大婚以來應受賜者皆籍記</span>  
<span style="margin-left: 2em">以待又當供奉慈寧歲幣益不足盡仰東南織造上</span>  
<span style="margin-left: 2em">心亦難之乃從中發銀五千兩畀孫隆約用盡更請</span>  
<span style="margin-left: 2em">一不以煩百姓外廷莫得知也故上指此爲言因以</span>  
<span style="margin-left: 2em">部疏授臣云先生將去票來又顧臣等云君臣一體</span>  
<span style="margin-left: 2em">今有司通不奉行百姓安得受惠臣等言誠如聖諭</span>  
<span style="margin-left: 2em">臣等今日亦無非推廣　皇上德意而已願　皇上</span>  
<span style="margin-left: 2em">重惜民生保固邦本則百萬生靈仰戴至仁實社稷</span>  
<span style="margin-left: 2em">靈長之慶因叩頭出次日奉　聖旨蘇松地方災傷</span>  
<span style="margin-left: 2em">重大孫隆着查近降花樣御前發去銀兩應織袍服</span>  
<span style="margin-left: 2em">上緊凑織完日即便回京其以前織完的照數解進</span>  
<span style="margin-left: 2em">未完的都着停止物料等項准作歲造段疋支用撫</span>  
<span style="margin-left: 2em">按官還查數明白具奏許坤且着照舊</span>  
<span style="margin-left: 1em">萬曆□<sub class="note-jiao">校：此處原書作墨丁</sub>年閣臣張居正又請酌減增造段疋</span>  
<span style="margin-left: 2em">疏</span>  
<span style="margin-left: 2em">伏蒙　發下工科都給事中王道成等請酌減織造</span>  
<span style="margin-left: 2em">段疋一本臣等查得先該承運庫太監孔成等以賞</span>  
<span style="margin-left: 2em">賜夷人段疋缺乏題請行南京蘇松浙江等處增織</span>  
<span style="margin-left: 2em">於內又將上用袍服等項併請織造共該七萬三千</span>  
<span style="margin-left: 2em">疋奉　聖旨工部知道今科臣王道成等因見東南</span>  
<span style="margin-left: 2em">地方災傷重大民力罷敝恐加派擾民故有此奏臣</span>  
<span style="margin-left: 2em">等看得歲造段疋原有定額祖宗朝計一歲所造賞</span>  
<span style="margin-left: 2em">賚諸費尚有贏餘至嘉靖年間賞賚無時每稱缺乏</span>  
<span style="margin-left: 2em">乃行文於該地方增織謂之急缺段疋然亦間一行</span>  
<span style="margin-left: 2em">之非可爲常例者也今查萬曆三年該庫已稱缺乏</span>  
<span style="margin-left: 2em">請於歲造之外添織九萬有餘其時以大婚禮重賞</span>  
<span style="margin-left: 2em">賜浩繁該部不得已欽遵　明旨設法措處然聞之</span>  
<span style="margin-left: 2em">各地方庫藏搜括已盡經今四年方得織完而添織</span>  
<span style="margin-left: 2em">之旨又下計該庫所開數目度所費非得銀四五十</span>  
<span style="margin-left: 2em">萬不能辦此索之庫藏則庫藏已竭加派小民則民</span>  
<span style="margin-left: 2em">力已疲况今歲南直隸浙江一帶皆有水災頃蒙特</span>  
<span style="margin-left: 2em">恩破格蠲賑又取回織造太監罷困之民方得更生</span>  
<span style="margin-left: 2em">乃又重復加派子惠之恩未洽誅求之令即施非</span>  
<span style="margin-left: 2em">聖慈所以愛養元元培植邦本之意也民窮財盡賦</span>  
<span style="margin-left: 2em">重役繁將來隱憂誠有不可勝計者科臣所奏宜留</span>  
<span style="margin-left: 3em">聖心臣等看得該庫偶因三衛夷人賞賜段疋缺</span>  
<span style="margin-left: 2em">少虎豹一樣服色及近年北虜俺荅欵貢歲增賞賚</span>  
<span style="margin-left: 2em">溢於舊款故題請添織以上二項委不可已至於上</span>  
<span style="margin-left: 2em">供御用等項則近年南京太監許坤蘇杭太監孫隆</span>  
<span style="margin-left: 2em">織進御前者已自足用不必又取辦於歲造矣臣等</span>  
<span style="margin-left: 2em">愚見伏乞聖明再諭該庫查北虜俺荅一宗　賞賜</span>  
<span style="margin-left: 2em">一歲約該幾何及三衛夷人虎豹服色缺少幾何照</span>  
<span style="margin-left: 2em">數行該地方添織即作歲造之數其餘皆可停止惟</span>  
<span style="margin-left: 2em">復俯從科臣之言一槩減半織造其支費銀兩　勑</span>  
<span style="margin-left: 2em">下户工二部酌處免復加派小民庶近日蠲恤之旨</span>  
<span style="margin-left: 2em">不爲虛文罷極之民少得蘇息也臣等職在帷幄蒙</span>  
<span style="margin-left: 2em">皇上心膂之寄豈不知　國用浩繁事在難已敢故</span>  
<span style="margin-left: 2em">爲節省之言以沽違拂之譽但事關邦本不得不爲</span>  
<span style="margin-left: 2em">深長之慮伏望裁酌施行奉</span>  
<span style="margin-left: 1em">聖旨東南地方既有災傷這段疋等項准減半織造其</span>  
<span style="margin-left: 1em">支費銀兩着户工二部措處毋得加派小民欽此</span>
