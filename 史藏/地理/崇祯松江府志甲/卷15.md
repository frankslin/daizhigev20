## 崇祯松江府志卷之十五　织造　税课

<span style="margin-left: 3em">织造</span>  
<span style="margin-left: 1em">王者垂衣裳而治天下盖取诸乾坤尚方天府岁供法</span>  
<span style="margin-left: 1em">服礼也第穷簷绝塞之下不有杼柚其空妇叹于室者</span>  
<span style="margin-left: 1em">乎又不有卧牛衣之窭士裹铁衣之边士乎以此思寒</span>  
<span style="margin-left: 1em">寒可知也顷</span>  
<span style="margin-left: 1em">皇上践祚初年首停织造三县额设加编渐可望减</span>  
<span style="margin-left: 1em">圣明俭德普矣哉</span>  
<span style="margin-left: 1em">江南织造惟浙直杭嘉湖苏松五府设局　祖制差内</span>  
<span style="margin-left: 1em">官一员专任或在杭或在苏今松有织造局局官司之</span>  
<span style="margin-left: 1em">一曰内号乃　上用袍服常年以春秋二运解进其段</span>  
<span style="margin-left: 1em">之疋数浙直以四六派之而苏松又以四六分之松局</span>  
<span style="margin-left: 1em">居海隅匠户有逃亡者仅存三百七十余名分别织挽</span>  
<span style="margin-left: 1em">络染打线结综簆七作每遇开造时内中举选殷实者</span>  
<span style="margin-left: 1em">充堂长之役肩任应办丝料分发小匠领造段完解京</span>  
<span style="margin-left: 1em">起运之后其价于三县四司银解给倘有不敷题留关</span>  
<span style="margin-left: 1em">税补之逐运清楚县无欠额匠无罣牵接济后运从容</span>  
<span style="margin-left: 1em">裕如近来段疋轮运不容迟缓三县料价拖阁经年充</span>  
<span style="margin-left: 1em">是役者只得捐产揭债赊料　织完及其透价年更有</span>  
<span style="margin-left: 1em">换县视缓逋烦府行催县总以新旧托辞千般勒索候</span>  
<span style="margin-left: 1em">得县中解银资本先费往例本府发银便而省费今紊</span>  
<span style="margin-left: 1em">乱旧规解银监给司房奸蠧任意扣除领银者十无二</span>  
<span style="margin-left: 1em">三到手复有本监衙门下役皂快门子舍人军牢班头</span>  
<span style="margin-left: 1em">轿夫所官跟随人役蜂屯蚁聚打骂婪诈不遂不已乃</span>  
<span style="margin-left: 1em">致罄身而回宦债不能偿商丝不能了东逃西窜涕泣</span>  
<span style="margin-left: 1em">相视而已又如内帑进用之段此系五局总归苏杭两</span>  
<span style="margin-left: 1em">府民匠织造各府堂长出银随段解进若有帑银赍发</span>  
<span style="margin-left: 1em">折本尤可若无帑银化为乌有此苦上又苦也又如小</span>  
<span style="margin-left: 1em">匠领一段料举家惊持妻络子馈日工夜宿所系者一</span>  
<span style="margin-left: 1em">月四斗口粮先时派米被粮户拖欠续后议以折银三</span>  
<span style="margin-left: 1em">钱于三县条编银内征解散给此法之至善者也近今</span>  
<span style="margin-left: 1em">又以派发粮户对支与派米无异矣今之停造革除库</span>  
<span style="margin-left: 1em">役又增一烦守门看库看机跟官日无暇刻靠此二钱</span>  
<span style="margin-left: 1em">之银焉能充赡此又苦上又苦也</span>  
<span style="margin-left: 1em">一曰外号岁造段疋向属有司管理祖制额派每年一</span>  
<span style="margin-left: 1em">千一百六十七疋遇闰月加派浅色素段九十七疋内</span>  
<span style="margin-left: 1em">有大红织金云鹤狮子胸背段五十疋每长三十二尺</span>  
<span style="margin-left: 1em">价银每疋八两五钱矾红青黑绿织金犀牛海马熊罴</span>  
<span style="margin-left: 1em">胸背段四百十疋每长三丈二尺每疋价四两矾红青</span>  
<span style="margin-left: 1em">黑绿光素段六百零七疋每长三丈二尺每疋价三两</span>  
<span style="margin-left: 1em">六钱至万历年间奉文将素段一百疋改织大红织金</span>  
<span style="margin-left: 1em">虎豹胸背段八十三疋每长四丈二尺每价十两一钱</span>  
<span style="margin-left: 1em">八分矾红十七疋每价五两一钱又于天启四年奉文</span>  
<span style="margin-left: 1em">将素段一百十七疋改织大红织金斗牛飞鱼麒麟等</span>  
<span style="margin-left: 1em">项胸背段丈尺价值与前虎豹段相同其各料价编入</span>  
<span style="margin-left: 1em">三县会计白银内征给先是万历三十一年有镇江府</span>  
<span style="margin-left: 1em">奸民王一卿妄奏每疋段价内扣银四钱名曰羡余随</span>  
<span style="margin-left: 1em">段解进以助大工至四十三年奉文蠲免免征于民今</span>  
<span style="margin-left: 1em">段价内每疋减银四钱其扛垫各府每疋一两一钱本</span>  
<span style="margin-left: 1em">府止得原编六钱段疋解京赴内承运库交纳垫费与</span>  
<span style="margin-left: 1em">各府例不相同有进呈　御览退驳之虞解户典批揭</span>  
<span style="margin-left: 1em">债赔累告部咨送　抚按转行道府关防各府相同设</span>  
<span style="margin-left: 1em">处无碍官银五钱抵给共足一两一钱之数遵依在卷</span>  
<span style="margin-left: 1em">近又奉文以崇祯元年为始于扛垫六钱内免茶菓银</span>  
<span style="margin-left: 1em">九分五厘亦已详免其大红段价每两又减二钱查得</span>  
<span style="margin-left: 1em">先年给银完段至有侵弊坐问杖配者百名监比二十</span>  
<span style="margin-left: 1em">余年前岁蒙按院王题豁众户得生前守许公勒石定</span>  
<span style="margin-left: 1em">规完段给银官不烦而匠无累此诚良法也又因迩年</span>  
<span style="margin-left: 1em">县解料银不足段疋不能完全内库赏夷缺乏乃有参</span>  
<span style="margin-left: 1em">罚之例且今段疋有司督责抑求精美犹虞交纳烦难</span>  
<span style="margin-left: 1em">反将料垫减而又减乃织解两难之事也</span>  
<span style="margin-left: 1em">一曰急缺又名改造此段五年一坐派专供喜庆颁赏</span>  
<span style="margin-left: 1em">之用其段有纻丝纱罗绫䌷绢锦其色有大红浅色其</span>  
<span style="margin-left: 1em">花样有彩粧织金闪色蟒龙飞鱼斗牛缠身胸背工甚</span>  
<span style="margin-left: 1em">烦琐料扛苏松会估相同因无正编惟听议详外府四</span>  
<span style="margin-left: 1em">司银抵织关领有往返之劳守候有盘缠之费</span>  
<span style="margin-left: 1em">一曰绫纱此段十年一派白丝经纬长阔工烦其体式</span>  
<span style="margin-left: 1em">料价浙直相同每长八丈阔三尺二寸其价花者每疋</span>  
<span style="margin-left: 1em">九两九钱素者每疋九两七钱供宫殿裱刷窻槅之用</span>  
<span style="margin-left: 1em">纱每长四丈阔与绫同其价每疋一两七钱供郊社祭</span>  
<span style="margin-left: 1em">祀焚帛之用料扛随段数之多寡派征三县不惟工烦</span>  
<span style="margin-left: 1em">抑且丝价今倍于昔工食物价又倍于昔况丝产于浙</span>  
<span style="margin-left: 1em">地收买易便省盘缠之费吾松隔远绫价相同亦为损</span>  
<span style="margin-left: 1em">益交纳属司礼监扛垫每一绫一纱一两　钱近闻亦</span>  
<span style="margin-left: 1em">议减价亦是两难之事矣</span>  
<span style="margin-left: 1em">一曰只逊驾衣向无此段近时坐派七百五十副五彩</span>  
<span style="margin-left: 1em">粧花红浅相半工甚烦琐每副又有里绢一疋价彷苏</span>  
<span style="margin-left: 1em">州银出外府请详院道关支不能易于解给</span>  
<span style="margin-left: 1em">今之内外织造皆被中官上下剥削之后小匠悉己困</span>  
<span style="margin-left: 1em">乏今郡侯方公查各年各役所透段价属县积逋料银</span>  
<span style="margin-left: 1em">尽数严催解给秋毫不染松局皆沾其惠</span>  
<span style="margin-left: 1em">万历□<sub class="note-jiao">校：此處原書作墨丁</sub>年阁臣张居正请罢织造内臣对</span>  
<span style="margin-left: 2em">工部覆礼科左给事中顾九思工科都给事中王道</span>  
<span style="margin-left: 2em">成等疏请罢苏松及应天织造取回原差内臣　上</span>  
<span style="margin-left: 2em">遣文书官传谕云　御用袍服紧急织造且未可罢</span>  
<span style="margin-left: 2em">若如部议取回内臣改属抚按有司则织造不精谁</span>  
<span style="margin-left: 2em">任其责且见有钱粮不必加派先生每拟票来臣与</span>  
<span style="margin-left: 2em">同官二臣持工部疏入见　上于便殿奏云近日苏</span>  
<span style="margin-left: 2em">松等处水灾重大据抚按官奏报及臣等所闻百姓</span>  
<span style="margin-left: 2em">困苦流离朝不谋夕有群聚刼夺者地方钱粮委难</span>  
<span style="margin-left: 2em">措处且自前年星变时亲奉　明旨停止织造着孙</span>  
<span style="margin-left: 2em">隆回京至今尚未完报是诏令不信而德泽不宣也</span>  
<span style="margin-left: 2em">臣等谓宜从该部所请以彰　皇上敬天恤民至意</span>  
<span style="margin-left: 2em">民惟邦本愿少加圣心　上曰朕未尝不爱惜百姓</span>  
<span style="margin-left: 2em">但彼处织造不久当完远不过来春尔臣对言　皇</span>  
<span style="margin-left: 2em">上德意臣民无不欣仰即孙隆在彼亦能仰体圣心</span>  
<span style="margin-left: 2em">安静行事但地方多一事则有一事之扰宽一分则</span>  
<span style="margin-left: 2em">受一分之赐今彼中织完十未四五物料钱粮尚有</span>  
<span style="margin-left: 2em">未尽征完者灾地疲民不堪催督愿　皇上且取回</span>  
<span style="margin-left: 2em">孙隆其应天被灾稍轻许坤仍旧可也　上乃许之</span>  
<span style="margin-left: 2em">曰近降去花样皆御前发出银两竝不加派扰民此</span>  
<span style="margin-left: 2em">一件还着织完回京其余则皆停罢可也臣等顿首</span>  
<span style="margin-left: 2em">曰幸甚盖是时宫中自大婚以来应受赐者皆籍记</span>  
<span style="margin-left: 2em">以待又当供奉慈宁岁币益不足尽仰东南织造上</span>  
<span style="margin-left: 2em">心亦难之乃从中发银五千两畀孙隆约用尽更请</span>  
<span style="margin-left: 2em">一不以烦百姓外廷莫得知也故上指此为言因以</span>  
<span style="margin-left: 2em">部疏授臣云先生将去票来又顾臣等云君臣一体</span>  
<span style="margin-left: 2em">今有司通不奉行百姓安得受惠臣等言诚如圣谕</span>  
<span style="margin-left: 2em">臣等今日亦无非推广　皇上德意而已愿　皇上</span>  
<span style="margin-left: 2em">重惜民生保固邦本则百万生灵仰戴至仁实社稷</span>  
<span style="margin-left: 2em">灵长之庆因叩头出次日奉　圣旨苏松地方灾伤</span>  
<span style="margin-left: 2em">重大孙隆着查近降花样御前发去银两应织袍服</span>  
<span style="margin-left: 2em">上紧凑织完日即便回京其以前织完的照数解进</span>  
<span style="margin-left: 2em">未完的都着停止物料等项准作岁造段疋支用抚</span>  
<span style="margin-left: 2em">按官还查数明白具奏许坤且着照旧</span>  
<span style="margin-left: 1em">万历□<sub class="note-jiao">校：此處原書作墨丁</sub>年阁臣张居正又请酌减增造段疋</span>  
<span style="margin-left: 2em">疏</span>  
<span style="margin-left: 2em">伏蒙　发下工科都给事中王道成等请酌减织造</span>  
<span style="margin-left: 2em">段疋一本臣等查得先该承运库太监孔成等以赏</span>  
<span style="margin-left: 2em">赐夷人段疋缺乏题请行南京苏松浙江等处增织</span>  
<span style="margin-left: 2em">于内又将上用袍服等项并请织造共该七万三千</span>  
<span style="margin-left: 2em">疋奉　圣旨工部知道今科臣王道成等因见东南</span>  
<span style="margin-left: 2em">地方灾伤重大民力罢敝恐加派扰民故有此奏臣</span>  
<span style="margin-left: 2em">等看得岁造段疋原有定额祖宗朝计一岁所造赏</span>  
<span style="margin-left: 2em">赉诸费尚有赢余至嘉靖年间赏赉无时每称缺乏</span>  
<span style="margin-left: 2em">乃行文于该地方增织谓之急缺段疋然亦间一行</span>  
<span style="margin-left: 2em">之非可为常例者也今查万历三年该库已称缺乏</span>  
<span style="margin-left: 2em">请于岁造之外添织九万有余其时以大婚礼重赏</span>  
<span style="margin-left: 2em">赐浩繁该部不得已钦遵　明旨设法措处然闻之</span>  
<span style="margin-left: 2em">各地方库藏搜括已尽经今四年方得织完而添织</span>  
<span style="margin-left: 2em">之旨又下计该库所开数目度所费非得银四五十</span>  
<span style="margin-left: 2em">万不能办此索之库藏则库藏已竭加派小民则民</span>  
<span style="margin-left: 2em">力已疲况今岁南直隶浙江一带皆有水灾顷蒙特</span>  
<span style="margin-left: 2em">恩破格蠲赈又取回织造太监罢困之民方得更生</span>  
<span style="margin-left: 2em">乃又重复加派子惠之恩未洽诛求之令即施非</span>  
<span style="margin-left: 2em">圣慈所以爱养元元培植邦本之意也民穷财尽赋</span>  
<span style="margin-left: 2em">重役繁将来隐忧诚有不可胜计者科臣所奏宜留</span>  
<span style="margin-left: 3em">圣心臣等看得该库偶因三卫夷人赏赐段疋缺</span>  
<span style="margin-left: 2em">少虎豹一样服色及近年北虏俺荅欵贡岁增赏赉</span>  
<span style="margin-left: 2em">溢于旧款故题请添织以上二项委不可已至于上</span>  
<span style="margin-left: 2em">供御用等项则近年南京太监许坤苏杭太监孙隆</span>  
<span style="margin-left: 2em">织进御前者已自足用不必又取办于岁造矣臣等</span>  
<span style="margin-left: 2em">愚见伏乞圣明再谕该库查北虏俺荅一宗　赏赐</span>  
<span style="margin-left: 2em">一岁约该几何及三卫夷人虎豹服色缺少几何照</span>  
<span style="margin-left: 2em">数行该地方添织即作岁造之数其余皆可停止惟</span>  
<span style="margin-left: 2em">复俯从科臣之言一槩减半织造其支费银两　勑</span>  
<span style="margin-left: 2em">下户工二部酌处免复加派小民庶近日蠲恤之旨</span>  
<span style="margin-left: 2em">不为虚文罢极之民少得苏息也臣等职在帷幄蒙</span>  
<span style="margin-left: 2em">皇上心膂之寄岂不知　国用浩繁事在难已敢故</span>  
<span style="margin-left: 2em">为节省之言以沽违拂之誉但事关邦本不得不为</span>  
<span style="margin-left: 2em">深长之虑伏望裁酌施行奉</span>  
<span style="margin-left: 1em">圣旨东南地方既有灾伤这段疋等项准减半织造其</span>
