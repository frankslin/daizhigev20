## 崇禎松江府志卷之二十九　宦績二（宋朝名宦）

<span style="margin-left: 3em">歷朝宦績二</span>  
<span style="margin-left: 1em">宋</span>  
<span style="margin-left: 1em">夏侯嶠字峻極其先幽州人弱冠以詞賦稱太平興國</span>  
<span style="margin-left: 1em">初舉進士甲科累遷左補闕直史館真宗時爲侍讀學</span>  
<span style="margin-left: 1em">士咸平二年秋浙江饑命爲江南巡撫使所過疏理刑</span>  
<span style="margin-left: 1em">訟存問耆老務從寬簡采民病二十餘事上之亟詔釐</span>  
<span style="margin-left: 1em">革江南萬姓賴以甦</span>  
<span style="margin-left: 1em">劉惟一天禧初任華亭縣時學舍未立介於梵刹始遷</span>  
<span style="margin-left: 1em">於縣治之東陳執古有遷學記稱其下車而奸盗屏假</span>  
<span style="margin-left: 1em">印而訟獄清胥尹服從閭里競勸</span>  
<span style="margin-left: 1em">葉清臣字道卿長洲人宋進士以策擢高等自清臣始</span>  
<span style="margin-left: 1em">授太常寺奉禮郎旋知秀州寶元初爲兩浙轉運副使</span>  
<span style="margin-left: 1em">並太湖有民田豪右據上游水不得泄民莫敢訴遂請</span>  
<span style="margin-left: 1em">疏盤龍滙滙曲水迂滯開鑿新渠道直流速其患遂弭</span>  
<span style="margin-left: 1em">又建議疏滬瀆入於海人賴其利清臣天資爽邁遇事</span>  
<span style="margin-left: 1em">敢行數上書論天下事陳九議十要五利皆當世可行</span>  
<span style="margin-left: 1em">者有文集一百六十卷</span>  
<span style="margin-left: 2em">皇祐初帝御便殿訪近臣備邊之策清臣上對以爲</span>  
<span style="margin-left: 2em">不患無人患有人而不能用今輔翊之臣抱忠義之</span>  
<span style="margin-left: 2em">深者莫如富弼爲社稷之固者莫如范仲淹諳古今</span>  
<span style="margin-left: 2em">故事者莫如夏竦議論之敏者莫如鄭戩方面之才</span>  
<span style="margin-left: 2em">嚴重有紀律者莫如韓琦臨大事能斷者莫如田况</span>  
<span style="margin-left: 2em">剛果無顧避者莫如劉涣宏達有方畧者莫如孫沔</span>  
<span style="margin-left: 2em">至於帥領偏裨貴能坐運籌策不必親當矢石王德</span>  
<span style="margin-left: 2em">用素有威名范仲淹深練軍政龎籍久經邊任皆其</span>  
<span style="margin-left: 2em">選也狄青范全頗能馭衆蔣偕沉毅有術畧張亢倜</span>  
<span style="margin-left: 2em">儻有膽勇劉貽孫材武剛斷王德基純慤勁勇此可</span>  
<span style="margin-left: 2em">補偏禆者也</span>  
<span style="margin-left: 2em">仁宗朝清臣爲三司使以內東門御厨凡所取索有</span>  
<span style="margin-left: 2em">司不敢問乃爲合同檢其出人令憑此取金銀錢帛</span>  
<span style="margin-left: 2em">於户部而歲取動百萬計年終驅磨則比部郎中赴</span>  
<span style="margin-left: 2em">內東門具位端坐但數璫數㜮從旁算畢令郎中僉</span>  
<span style="margin-left: 2em">見而已太社令葉大廉乞內省取索給憑繇二本一</span>  
<span style="margin-left: 2em">付傳宣使一付本省封付本庫務官驗支訖繳奏合</span>  
<span style="margin-left: 2em">同下户部除破又詔何澹等稽攷內諸司所給賜及</span>  
<span style="margin-left: 2em">營造約爲中制因思周以冢宰制國用如工事蒭秣</span>  
<span style="margin-left: 2em">之式亦與焉其慮深矣<sub class="note-yuan">載吹劍錄</sub></span>  
<span style="margin-left: 1em">毛漸字正仲江山人舉進士累官兩浙轉運使浙部水</span>  
<span style="margin-left: 1em">溢詔賜緡錢二百萬以賑之漸言數州被害即捐二百</span>  
<span style="margin-left: 1em">萬儻仍歲如之將何以繼乃按錢氏有國時故事起長</span>  
<span style="margin-left: 1em">安堰至鹽官徹清水浦入於海開無錫蓮蓉河武進廟</span>  
<span style="margin-left: 1em">堂港常熟疏涇梅里入大江又開崑山七耳茜涇下張</span>  
<span style="margin-left: 1em">諸浦東北道吳江開大盈顧滙柘湖下金山小官浦以</span>  
<span style="margin-left: 1em">入海自是水不爲患</span>  
<span style="margin-left: 1em">吳及字幾道靜海人年十七以進士起家爲侯官尉累</span>  
<span style="margin-left: 1em">遷太常博士皇祐間宰華亭時旱蝗尤甚及禱於横山</span>  
<span style="margin-left: 1em">之神天既大雨蝗亦避境至秋教民預修水利以待淫</span>  
<span style="margin-left: 1em">潦明年大水而阡陌堅完溝洫通利復稔如初比三年</span>  
<span style="margin-left: 1em">歌誦滿路及去父老悲啼攀留不得進至空一邑隨之</span>  
<span style="margin-left: 1em">其後四十餘年猶思之不置初及嘗作亭西湖名曰環</span>  
<span style="margin-left: 1em">碧後令劉鵬因民之思改曰思吳</span>  
<span style="margin-left: 2em">仁宗時天下郡國有災異饑饉而鄰郡多閉糴右正</span>  
<span style="margin-left: 2em">言充秘閣校理吳及奏乞聖旨諸路或有災傷輒敢</span>  
<span style="margin-left: 2em">閉糴科違制之罪上從之初上晚年未有皇子後宫</span>  
<span style="margin-left: 2em">所誕育者皆公主上言陛下左右內臣凡四千餘人</span>  
<span style="margin-left: 2em">是絕人之嗣者多矣久無皇嗣豈非此耶上感寤<sub class="note-yuan">載厚德錄</sub></span>  
<span style="margin-left: 1em">錢貽範彭城人慶曆間知華亭縣搜剔民間利病皇皇</span>  
<span style="margin-left: 1em">如不及調度有章能行所聞而竟其功時康定以來歲</span>  
<span style="margin-left: 1em">旱頻仍貽範惻然憫之議開顧會浦以時蓄泄萬民賴</span>  
<span style="margin-left: 1em">之詳章峴記中</span>  
<span style="margin-left: 1em">陳輔字安國泉州人七歲誦書百卷能爲人言其意登</span>  
<span style="margin-left: 1em">嘉祐二年進士授校書郎屢遷義烏武當吉安令修治</span>  
<span style="margin-left: 1em">潰隄水不爲患出粟食流民所活千計使者知其才命</span>  
<span style="margin-left: 1em">攝華亭且俾求前令張若濟罪狀輔不肯行使者怒徙</span>  
<span style="margin-left: 1em">壽昌去日與其僚飲酒尋山水作詩百篇丞相呂大防</span>  
<span style="margin-left: 1em">范純臣皆欲疏薦重用會以疾致仕</span>  
<span style="margin-left: 2em">鼂補之銘其墓曰以彼其志無不可成命不與期以</span>  
<span style="margin-left: 2em">此其才無不可能位不得爲然有大君子者數人焉</span>  
<span style="margin-left: 2em">皆知之君尚何悲鷄肋集</span>  
<span style="margin-left: 1em">徐確字居易莆田人陳洪進辟掌書記宋初首勸洪進</span>  
<span style="margin-left: 1em">納土洪進欲害之遂走京師元豐五年試禮部第四授</span>  
<span style="margin-left: 1em">江陰尉選知象山縣久之召爲宗正丞出使兩浙提舉</span>  
<span style="margin-left: 1em">常平適大水歲飢確攷禹貢三江之說得吳淞古江以</span>  
<span style="margin-left: 1em">爲太湖東注入海吳淞在下流向者潮泥湮塞水溢爲</span>  
<span style="margin-left: 1em">患請自封家渡古江開淘至大通港直徹海口計七十</span>  
<span style="margin-left: 1em">四里役徒二百二十萬七千餘人以常平錢米一十八</span>  
<span style="margin-left: 1em">萬三千餘貫石充和雇之費水道遂通</span>  
<span style="margin-left: 1em">蘇軾元祐間以龍圖閣學士右朝奉郎知杭州五年五</span>  
<span style="margin-left: 1em">六月間浙西數郡大雨不止太湖泛溢所在害稼八月</span>  
<span style="margin-left: 1em">四日勅中書省知杭州充兩浙西路兵馬鈐轄勘會相</span>  
<span style="margin-left: 1em">度準備賑濟以宜興進士單鍔有水學疏進其議欲開</span>  
<span style="margin-left: 1em">白蜆安亭二江使湖水繇華亭青龍入海以减水患若</span>  
<span style="margin-left: 1em">蘇公者雖暫權浙西鈐轄而宦績不可没矣</span>  
<span style="margin-left: 1em">韓瓘字德全開封人參政億之曾孫從劉安世遊好學</span>  
<span style="margin-left: 1em">博雅元豐間知秀州所至屬邑興利除弊事無壅滯吏</span>  
<span style="margin-left: 1em">不敢欺皆稱有忠獻家法</span>  
<span style="margin-left: 1em">羅拯字道濟祥符人登進士歷知秀州爲人長厚以愛</span>  
<span style="margin-left: 1em">利爲行吏民推戴去之日遠近思之仕至天章閣待制</span>  
<span style="margin-left: 2em">梅聖俞送羅拯知秀州　陸雲嘗誇千里蓴便輕羊</span>  
<span style="margin-left: 2em">酪同埃塵君今得郡正千里己患無羊厭此珍乃知</span>  
<span style="margin-left: 2em">南北各所樂乘舟不如乘馬惡水邊不見秦羅敷縱</span>  
<span style="margin-left: 2em">有西施肌肉薄使君事事未稱意綠水芙蓉定何若</span>  
<span style="margin-left: 1em">李夔字斯和元豐三年進士調秀州華亭尉轉奉議郎</span>  
<span style="margin-left: 1em">除江淮荆浙六路制置發運司勾當公事不赴改授僉</span>  
<span style="margin-left: 1em">書平江軍節度推官常攝郡事適累政因循之後獄繫</span>  
<span style="margin-left: 1em">甚衆夔命數吏分條所犯不日皆決遣之官至京西南</span>  
<span style="margin-left: 1em">路安撫使子綱維綸綱相高宗爲名相贈太師衞國公</span>  
<span style="margin-left: 1em">生於華亭之官舍</span>  
<span style="margin-left: 1em">李餘慶字昌宗連江人判秀州境多鹽盗餘慶作華亭</span>  
<span style="margin-left: 1em">海鹽二監俾業鹽者歲入常緡以杜私販又爲石隄自</span>  
<span style="margin-left: 1em">平望至吳江捍除水患至今賴之</span>  
<span style="margin-left: 1em">張先字子野元豐中倅秀州能以文章飾吏治境無寃</span>  
<span style="margin-left: 1em">民循行屬邑至松江賦詩又郡圃有六客亭先是李公</span>  
<span style="margin-left: 1em">擇守此郡張子野劉孝叔在焉楊元素蘇子瞻陳令舉</span>  
<span style="margin-left: 1em">過之會飲於碧潤堂子野作六客詞後張復守是邦蘇</span>  
<span style="margin-left: 1em">軾曹子方劉景山蘇伯固張秉道來過復爲後六客詞</span>  
<span style="margin-left: 1em">一時風流文雅殆非俗吏可繼也神宗朝擢爲郎中</span>  
<span style="margin-left: 1em">盧秉字仲甫元豐初提點兩浙刑獄會朝廷議鹽法秉</span>  
<span style="margin-left: 1em">謂自錢塘縣楊村場上流接睦歙等州與越州錢清場</span>  
<span style="margin-left: 1em">等水勢稍淡以六分爲額楊村下接仁和縣湯村爲七</span>  
<span style="margin-left: 1em">分鹽官場爲八分並海而東爲越州餘姚縣石堰場明</span>  
<span style="margin-left: 1em">州慈谿縣鳴鶴場皆九分至岱山昌國又東南爲温州</span>  
<span style="margin-left: 1em">雙穟南天富北天富十分著爲定數蓋自岱山及二天</span>  
<span style="margin-left: 1em">富皆取海水煉鹽所謂熬波也自鳴鶴西南及湯村則</span>  
<span style="margin-left: 1em">刮鹻以淋鹵以分計之十得六七鹽官湯村用鐵盤故</span>  
<span style="margin-left: 1em">鹽色青白而官鹽鹽色或少黑繇曬灰故也湯村及錢</span>  
<span style="margin-left: 1em">清場織竹爲盤塗以石灰故色少黃竹勢不及鐵則黃</span>  
<span style="margin-left: 1em">色爲嫩青色爲上色黑多鹵或又有泥石不宜久停若</span>  
<span style="margin-left: 1em">石堰以東雖用竹盤而鹽色光白以近海水鹹故爾若</span>  
<span style="margin-left: 1em">秀州華亭沿海一帶海水隈奥曲折故可成鹽數亦不</span>  
<span style="margin-left: 1em">等唯隈奥多處則鹽多大抵參以前法公私所便後雖</span>  
<span style="margin-left: 1em">小變不可易也<sub class="note-yuan">載西溪叢話及泊宅編</sub></span>  
<span style="margin-left: 2em">盧秉侍郎先爲江南小郡司户參軍於傳舍中題詩</span>  
<span style="margin-left: 2em">曰青衫白髮病參軍旋糶黃糧换酒罇但得有錢留</span>  
<span style="margin-left: 2em">客醉也勝騎馬傍人門王荆公過而見之極稱賞俄</span>  
<span style="margin-left: 2em">薦於朝數年間遂超顯仕</span>  
<span style="margin-left: 1em">李𨗥字叔周徙居洛陽靖康南渡𨗥爲虜所得屈之使</span>  
<span style="margin-left: 1em">拜不得曰吾家世荷國恩肯爲虜屈虜擊之流血死遇</span>  
<span style="margin-left: 1em">天雨得蘇後監秀州華亭稅又監秀州酒被檄視潦舟</span>  
<span style="margin-left: 1em">行民田中所至曰監司圭田也吏側目摇手不敢以潦</span>  
<span style="margin-left: 1em">聞𨗥曰水潦爲患上供且應復况圭田乎盡復其租常</span>  
<span style="margin-left: 1em">平使者聞而奇之又復視經界躬行田畝高下定賦悉</span>  
<span style="margin-left: 1em">得其均士民德之歸日野夫羅拜於道咸執香以送<sub class="note-yuan">見楊誠齋集</sub></span>  
<span style="margin-left: 1em">郭三益字慎求海鹽人元祐三年進士爲常熟丞常平</span>  
<span style="margin-left: 1em">使者調蘇湖常秀四州之人濬青龍江分地程役三益</span>  
<span style="margin-left: 1em">所部前期告辦使者留之俾助他邑之不如期者三益</span>  
<span style="margin-left: 1em">即引所部歸使者怒檄追甚急母周氏謂三益曰青龍</span>  
<span style="margin-left: 1em">之役連數郡其分地程役賦廪食宜皆已上聞今我先</span>  
<span style="margin-left: 1em">畢何名復役之使者倘再思行且悔矣雖然汝不可無</span>  
<span style="margin-left: 1em">會第無以所部從也三益如教已而使檄止丞勿來事</span>  
<span style="margin-left: 1em">亦遂已</span>  
<span style="margin-left: 2em">朱文公集載光堯駐維揚召張浚對便殿慰勞宣諭</span>  
<span style="margin-left: 2em">曰卿在臺中知無不言言無不盡朕將有爲政如欲</span>  
<span style="margin-left: 2em">一飛冲天而無羽翼者卿爲朕留當耑任用張慤及</span>  
<span style="margin-left: 2em">卿浚頓首泣謝又復謂浚曰郭三益可與卿共事</span>  
<span style="margin-left: 1em">劉鵬彭城人元祐庚午爲華亭令甫下車即修庠序立</span>  
<span style="margin-left: 1em">教誡以至簿書期會井井有條精嚴而不紛擾治弦歌</span>  
<span style="margin-left: 1em">堂三山亭艮閣於縣亝之東與士之賢者講論歌咏於</span>  
<span style="margin-left: 1em">中以興起風俗又以前令之政唯靜海吳公第一即以</span>  
<span style="margin-left: 1em">吳公所建環碧亭爲思吳堂從民望也</span>  
<span style="margin-left: 1em">沈遼字叡達錢塘人翰林學士遘之弟熙寧初爲審官</span>  
<span style="margin-left: 1em">西院主簿初受知王安石及安石當國更張新法遼與</span>  
<span style="margin-left: 1em">論事不合罷去久之以太常奉禮郎監杭州軍資庫轉</span>  
<span style="margin-left: 1em">運使使攝華亭縣他使者有宿憾思中以文法因縣民</span>

<span style="margin-left: 2em">信服君喟然曰吾儒者也受子男之封任芻牧之寄</span>  
<span style="margin-left: 2em">詎可以善事上官不得罪巨室爲職業乎去歲夏五</span>  
<span style="margin-left: 2em">月民苦貴糴邑無粒粟斂於諸豪吾愧心焉會常平</span>  
<span style="margin-left: 2em">使者曹公修舊法太守趙公與訔奉新書歲留米五</span>  
<span style="margin-left: 2em">千石於縣華亭於是乎有義倉君曰二公所以惠吾</span>  
<span style="margin-left: 2em">縣者至矣然斂散之權令不得專吾將有以輔之取</span>  
<span style="margin-left: 2em">樽節餘錢一萬緡糴三千石規縣東有屋五楹別儲</span>  
<span style="margin-left: 2em">之華亭於是乎有平糴倉昔王介甫嘗恨士大夫不</span>  
<span style="margin-left: 2em">能講先王之意以合於當世之故余每嘆其言之善</span>  
<span style="margin-left: 2em">而又病其太高夫常平創於漢義倉昉於隋士大夫</span>  
<span style="margin-left: 2em">不能講漢隋之法以合諸當世者有之矣況遠而及</span>  
<span style="margin-left: 2em">於先王之意歟顧壯哉縣生齒之繁貴豪之衆水旱</span>  
<span style="margin-left: 2em">凶荒之備一日不可闕者相承百年莫過而問必待</span>  
<span style="margin-left: 2em">下有賢令上有賢監司太守而後舉行然則民之望</span>  
<span style="margin-left: 2em">治不其愈難哉君既在端平循吏之目滌華亭難治</span>  
<span style="margin-left: 2em">之謗薦墨交上有旨陞擢朞月之間績狀如此使盡</span>  
<span style="margin-left: 2em">其材而究於用其可書者何止一倉余又將秉筆以</span>

<span style="margin-left: 2em">魏了翁撰楊瑾建學記楊瑾自撰閲武亭近民亭記</span>  
<span style="margin-left: 2em">別載於後</span>  
<span style="margin-left: 1em">黃震字東發慈谿人寶祐末調吳縣尉縣界有焚屍亭</span>  
<span style="margin-left: 1em">震白府爲夷狄之法傷敗風俗令勿再置奉府檄攝華</span>  
<span style="margin-left: 1em">亭請罷茶鹽分司及論鹽場利害甚悉又以華亭水鄉</span>  
<span style="margin-left: 1em">大究塞泄之法申府論修田塍萬民賴之提舉常平王</span>  
<span style="margin-left: 1em">華甫辟上管帳司文字時知平江朱燿常州錢庚孫嘉</span>  
<span style="margin-left: 1em">興吳君擢皆倚嬖倖厲民華甫病革强起劾罷三人震</span>  
<span style="margin-left: 1em">贊之也嘗曰非聖之書不可觀無益之詩文不可作居</span>  
<span style="margin-left: 1em">官恒未明視事事至立決自奉儉薄人有急難周之不</span>  
<span style="margin-left: 1em">少吝所著日抄百卷卒門人私謚文潔先生</span>  
<span style="margin-left: 1em">黃崖紹定間任華亭縣於循吏廳東搆堂三楹顔之曰</span>  
<span style="margin-left: 1em">製錦又榜其小室曰無倦爲文記之讀其文想見盡心</span>  
<span style="margin-left: 1em">民隱勤敏職事者也</span>  
<span style="margin-left: 1em">吳柔勝字勝之溧水人舉進士第調華亭下沙鹽場官</span>  
<span style="margin-left: 1em">授嘉興教授浙西使者黃灝委以荒政全活甚衆華亭</span>  
<span style="margin-left: 1em">民得免離殍者柔勝之力也</span>  
<span style="margin-left: 2em">柔勝天性孝友與彭龜年楊簡袁燮相師友每以行</span>  
<span style="margin-left: 2em">事至否爲學力淺深之驗嘗曰士以大節爲本大節</span>  
<span style="margin-left: 2em">苟虧他美莫贖罹黨禍十有餘年不變其操</span>  
<span style="margin-left: 1em">孟文龍字震翁鄒國亞聖公後宋昭慈后五世姪孫初</span>  
<span style="margin-left: 1em">以世賞補將仕郎後中銓試授迪功郎監華亭船場再</span>  
<span style="margin-left: 1em">調兩浙西路安撫司准備差遣時賈似道擅國百僚悉</span>
