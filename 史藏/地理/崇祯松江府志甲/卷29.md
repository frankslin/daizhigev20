## 崇祯松江府志卷之二十九　宦绩二（宋朝名宦）

<span style="margin-left: 3em">历朝宦绩二</span>  
<span style="margin-left: 1em">宋</span>  
<span style="margin-left: 1em">夏侯峤字峻极其先幽州人弱冠以词赋称太平兴国</span>  
<span style="margin-left: 1em">初举进士甲科累迁左补阙直史馆真宗时为侍读学</span>  
<span style="margin-left: 1em">士咸平二年秋浙江饥命为江南巡抚使所过疏理刑</span>  
<span style="margin-left: 1em">讼存问耆老务从宽简采民病二十余事上之亟诏厘</span>  
<span style="margin-left: 1em">革江南万姓赖以甦</span>  
<span style="margin-left: 1em">刘惟一天禧初任华亭县时学舍未立介于梵刹始迁</span>  
<span style="margin-left: 1em">于县治之东陈执古有迁学记称其下车而奸盗屏假</span>  
<span style="margin-left: 1em">印而讼狱清胥尹服从闾里竞劝</span>  
<span style="margin-left: 1em">叶清臣字道卿长洲人宋进士以策擢高等自清臣始</span>  
<span style="margin-left: 1em">授太常寺奉礼郎旋知秀州宝元初为两浙转运副使</span>  
<span style="margin-left: 1em">并太湖有民田豪右据上游水不得泄民莫敢诉遂请</span>  
<span style="margin-left: 1em">疏盘龙汇汇曲水迂滞开凿新渠道直流速其患遂弭</span>  
<span style="margin-left: 1em">又建议疏沪渎入于海人赖其利清臣天资爽迈遇事</span>  
<span style="margin-left: 1em">敢行数上书论天下事陈九议十要五利皆当世可行</span>  
<span style="margin-left: 1em">者有文集一百六十卷</span>  
<span style="margin-left: 2em">皇祐初帝御便殿访近臣备边之策清臣上对以为</span>  
<span style="margin-left: 2em">不患无人患有人而不能用今辅翊之臣抱忠义之</span>  
<span style="margin-left: 2em">深者莫如富弼为社稷之固者莫如范仲淹谙古今</span>  
<span style="margin-left: 2em">故事者莫如夏竦议论之敏者莫如郑戬方面之才</span>  
<span style="margin-left: 2em">严重有纪律者莫如韩琦临大事能断者莫如田况</span>  
<span style="margin-left: 2em">刚果无顾避者莫如刘涣宏达有方畧者莫如孙沔</span>  
<span style="margin-left: 2em">至于帅领偏裨贵能坐运筹策不必亲当矢石王德</span>  
<span style="margin-left: 2em">用素有威名范仲淹深练军政厐籍久经边任皆其</span>  
<span style="margin-left: 2em">选也狄青范全颇能驭众蒋偕沉毅有术畧张亢倜</span>  
<span style="margin-left: 2em">傥有胆勇刘贻孙材武刚断王德基纯悫劲勇此可</span>  
<span style="margin-left: 2em">补偏禆者也</span>  
<span style="margin-left: 2em">仁宗朝清臣为三司使以内东门御厨凡所取索有</span>  
<span style="margin-left: 2em">司不敢问乃为合同检其出人令凭此取金银钱帛</span>  
<span style="margin-left: 2em">于户部而岁取动百万计年终驱磨则比部郎中赴</span>  
<span style="margin-left: 2em">内东门具位端坐但数珰数㜮从旁算毕令郎中佥</span>  
<span style="margin-left: 2em">见而已太社令叶大廉乞内省取索给凭繇二本一</span>  
<span style="margin-left: 2em">付传宣使一付本省封付本库务官验支讫缴奏合</span>  
<span style="margin-left: 2em">同下户部除破又诏何澹等稽攷内诸司所给赐及</span>  
<span style="margin-left: 2em">营造约为中制因思周以冢宰制国用如工事蒭秣</span>  
<span style="margin-left: 2em">之式亦与焉其虑深矣<sub class="note-yuan">载吹剑录</sub></span>  
<span style="margin-left: 1em">毛渐字正仲江山人举进士累官两浙转运使浙部水</span>  
<span style="margin-left: 1em">溢诏赐缗钱二百万以赈之渐言数州被害即捐二百</span>  
<span style="margin-left: 1em">万傥仍岁如之将何以继乃按钱氏有国时故事起长</span>  
<span style="margin-left: 1em">安堰至盐官彻清水浦入于海开无锡莲蓉河武进庙</span>  
<span style="margin-left: 1em">堂港常熟疏泾梅里入大江又开昆山七耳茜泾下张</span>  
<span style="margin-left: 1em">诸浦东北道吴江开大盈顾汇柘湖下金山小官浦以</span>  
<span style="margin-left: 1em">入海自是水不为患</span>  
<span style="margin-left: 1em">吴及字几道静海人年十七以进士起家为侯官尉累</span>  
<span style="margin-left: 1em">迁太常博士皇祐间宰华亭时旱蝗尤甚及祷于横山</span>  
<span style="margin-left: 1em">之神天既大雨蝗亦避境至秋教民预修水利以待淫</span>  
<span style="margin-left: 1em">潦明年大水而阡陌坚完沟洫通利复稔如初比三年</span>  
<span style="margin-left: 1em">歌诵满路及去父老悲啼攀留不得进至空一邑随之</span>  
<span style="margin-left: 1em">其后四十余年犹思之不置初及尝作亭西湖名曰环</span>  
<span style="margin-left: 1em">碧后令刘鹏因民之思改曰思吴</span>  
<span style="margin-left: 2em">仁宗时天下郡国有灾异饥馑而邻郡多闭籴右正</span>  
<span style="margin-left: 2em">言充秘阁校理吴及奏乞圣旨诸路或有灾伤辄敢</span>  
<span style="margin-left: 2em">闭籴科违制之罪上从之初上晚年未有皇子后宫</span>  
<span style="margin-left: 2em">所诞育者皆公主上言陛下左右内臣凡四千余人</span>  
<span style="margin-left: 2em">是绝人之嗣者多矣久无皇嗣岂非此耶上感寤<sub class="note-yuan">载厚德录</sub></span>  
<span style="margin-left: 1em">钱贻范彭城人庆历间知华亭县搜剔民间利病皇皇</span>  
<span style="margin-left: 1em">如不及调度有章能行所闻而竟其功时康定以来岁</span>  
<span style="margin-left: 1em">旱频仍贻范恻然悯之议开顾会浦以时蓄泄万民赖</span>  
<span style="margin-left: 1em">之详章岘记中</span>  
<span style="margin-left: 1em">陈辅字安国泉州人七岁诵书百卷能为人言其意登</span>  
<span style="margin-left: 1em">嘉祐二年进士授校书郎屡迁义乌武当吉安令修治</span>  
<span style="margin-left: 1em">溃隄水不为患出粟食流民所活千计使者知其才命</span>  
<span style="margin-left: 1em">摄华亭且俾求前令张若济罪状辅不肯行使者怒徙</span>  
<span style="margin-left: 1em">寿昌去日与其僚饮酒寻山水作诗百篇丞相吕大防</span>  
<span style="margin-left: 1em">范纯臣皆欲疏荐重用会以疾致仕</span>  
<span style="margin-left: 2em">鼌补之铭其墓曰以彼其志无不可成命不与期以</span>  
<span style="margin-left: 2em">此其才无不可能位不得为然有大君子者数人焉</span>  
<span style="margin-left: 2em">皆知之君尚何悲鸡肋集</span>  
<span style="margin-left: 1em">徐确字居易莆田人陈洪进辟掌书记宋初首劝洪进</span>  
<span style="margin-left: 1em">纳土洪进欲害之遂走京师元丰五年试礼部第四授</span>  
<span style="margin-left: 1em">江阴尉选知象山县久之召为宗正丞出使两浙提举</span>  
<span style="margin-left: 1em">常平适大水岁饥确攷禹贡三江之说得吴淞古江以</span>  
<span style="margin-left: 1em">为太湖东注入海吴淞在下流向者潮泥湮塞水溢为</span>  
<span style="margin-left: 1em">患请自封家渡古江开淘至大通港直彻海口计七十</span>  
<span style="margin-left: 1em">四里役徒二百二十万七千余人以常平钱米一十八</span>  
<span style="margin-left: 1em">万三千余贯石充和雇之费水道遂通</span>  
<span style="margin-left: 1em">苏轼元祐间以龙图阁学士右朝奉郎知杭州五年五</span>  
<span style="margin-left: 1em">六月间浙西数郡大雨不止太湖泛溢所在害稼八月</span>  
<span style="margin-left: 1em">四日勅中书省知杭州充两浙西路兵马钤辖勘会相</span>  
<span style="margin-left: 1em">度准备赈济以宜兴进士单锷有水学疏进其议欲开</span>  
<span style="margin-left: 1em">白蚬安亭二江使湖水繇华亭青龙入海以减水患若</span>  
<span style="margin-left: 1em">苏公者虽暂权浙西钤辖而宦绩不可没矣</span>  
<span style="margin-left: 1em">韩瓘字德全开封人参政亿之曾孙从刘安世游好学</span>  
<span style="margin-left: 1em">博雅元丰间知秀州所至属邑兴利除弊事无壅滞吏</span>  
<span style="margin-left: 1em">不敢欺皆称有忠献家法</span>  
<span style="margin-left: 1em">罗拯字道济祥符人登进士历知秀州为人长厚以爱</span>  
<span style="margin-left: 1em">利为行吏民推戴去之日远近思之仕至天章阁待制</span>  
<span style="margin-left: 2em">梅圣俞送罗拯知秀州　陆云尝夸千里莼便轻羊</span>  
<span style="margin-left: 2em">酪同埃尘君今得郡正千里己患无羊厌此珍乃知</span>  
<span style="margin-left: 2em">南北各所乐乘舟不如乘马恶水边不见秦罗敷纵</span>  
<span style="margin-left: 2em">有西施肌肉薄使君事事未称意绿水芙蓉定何若</span>  
<span style="margin-left: 1em">李夔字斯和元丰三年进士调秀州华亭尉转奉议郎</span>  
<span style="margin-left: 1em">除江淮荆浙六路制置发运司勾当公事不赴改授佥</span>  
<span style="margin-left: 1em">书平江军节度推官常摄郡事适累政因循之后狱系</span>  
<span style="margin-left: 1em">甚众夔命数吏分条所犯不日皆决遣之官至京西南</span>  
<span style="margin-left: 1em">路安抚使子纲维纶纲相高宗为名相赠太师衞国公</span>  
<span style="margin-left: 1em">生于华亭之官舍</span>  
<span style="margin-left: 1em">李余庆字昌宗连江人判秀州境多盐盗余庆作华亭</span>  
<span style="margin-left: 1em">海盐二监俾业盐者岁入常缗以杜私贩又为石隄自</span>  
<span style="margin-left: 1em">平望至吴江捍除水患至今赖之</span>  
<span style="margin-left: 1em">张先字子野元丰中倅秀州能以文章饰吏治境无寃</span>  
<span style="margin-left: 1em">民循行属邑至松江赋诗又郡圃有六客亭先是李公</span>  
<span style="margin-left: 1em">择守此郡张子野刘孝叔在焉杨元素苏子瞻陈令举</span>  
<span style="margin-left: 1em">过之会饮于碧润堂子野作六客词后张复守是邦苏</span>  
<span style="margin-left: 1em">轼曹子方刘景山苏伯固张秉道来过复为后六客词</span>  
<span style="margin-left: 1em">一时风流文雅殆非俗吏可继也神宗朝擢为郎中</span>  
<span style="margin-left: 1em">卢秉字仲甫元丰初提点两浙刑狱会朝廷议盐法秉</span>  
<span style="margin-left: 1em">谓自钱塘县杨村场上流接睦歙等州与越州钱清场</span>  
<span style="margin-left: 1em">等水势稍淡以六分为额杨村下接仁和县汤村为七</span>  
<span style="margin-left: 1em">分盐官场为八分并海而东为越州余姚县石堰场明</span>  
<span style="margin-left: 1em">州慈溪县鸣鹤场皆九分至岱山昌国又东南为温州</span>  
<span style="margin-left: 1em">双穟南天富北天富十分著为定数盖自岱山及二天</span>  
<span style="margin-left: 1em">富皆取海水炼盐所谓熬波也自鸣鹤西南及汤村则</span>  
<span style="margin-left: 1em">刮鹻以淋卤以分计之十得六七盐官汤村用铁盘故</span>  
<span style="margin-left: 1em">盐色青白而官盐盐色或少黑繇晒灰故也汤村及钱</span>  
<span style="margin-left: 1em">清场织竹为盘涂以石灰故色少黄竹势不及铁则黄</span>  
<span style="margin-left: 1em">色为嫩青色为上色黑多卤或又有泥石不宜久停若</span>  
<span style="margin-left: 1em">石堰以东虽用竹盘而盐色光白以近海水咸故尔若</span>  
<span style="margin-left: 1em">秀州华亭沿海一带海水隈奥曲折故可成盐数亦不</span>  
<span style="margin-left: 1em">等唯隈奥多处则盐多大抵参以前法公私所便后虽</span>  
<span style="margin-left: 1em">小变不可易也<sub class="note-yuan">载西溪丛话及泊宅编</sub></span>  
<span style="margin-left: 2em">卢秉侍郎先为江南小郡司户参军于传舍中题诗</span>  
<span style="margin-left: 2em">曰青衫白发病参军旋粜黄粮换酒罇但得有钱留</span>  
<span style="margin-left: 2em">客醉也胜骑马傍人门王荆公过而见之极称赏俄</span>  
<span style="margin-left: 2em">荐于朝数年间遂超显仕</span>  
<span style="margin-left: 1em">李𨗥字叔周徙居洛阳靖康南渡𨗥为虏所得屈之使</span>  
<span style="margin-left: 1em">拜不得曰吾家世荷国恩肯为虏屈虏击之流血死遇</span>  
<span style="margin-left: 1em">天雨得苏后监秀州华亭税又监秀州酒被檄视潦舟</span>  
<span style="margin-left: 1em">行民田中所至曰监司圭田也吏侧目摇手不敢以潦</span>  
<span style="margin-left: 1em">闻𨗥曰水潦为患上供且应复况圭田乎尽复其租常</span>  
<span style="margin-left: 1em">平使者闻而奇之又复视经界躬行田亩高下定赋悉</span>  
<span style="margin-left: 1em">得其均士民德之归日野夫罗拜于道咸执香以送<sub class="note-yuan">见杨诚斋集</sub></span>  
<span style="margin-left: 1em">郭三益字慎求海盐人元祐三年进士为常熟丞常平</span>  
<span style="margin-left: 1em">使者调苏湖常秀四州之人濬青龙江分地程役三益</span>  
<span style="margin-left: 1em">所部前期告办使者留之俾助他邑之不如期者三益</span>  
<span style="margin-left: 1em">即引所部归使者怒檄追甚急母周氏谓三益曰青龙</span>  
<span style="margin-left: 1em">之役连数郡其分地程役赋廪食宜皆已上闻今我先</span>  
<span style="margin-left: 1em">毕何名复役之使者倘再思行且悔矣虽然汝不可无</span>  
<span style="margin-left: 1em">会第无以所部从也三益如教已而使檄止丞勿来事</span>  
<span style="margin-left: 1em">亦遂已</span>  
<span style="margin-left: 2em">朱文公集载光尧驻维扬召张浚对便殿慰劳宣谕</span>  
<span style="margin-left: 2em">曰卿在台中知无不言言无不尽朕将有为政如欲</span>  
<span style="margin-left: 2em">一飞冲天而无羽翼者卿为朕留当耑任用张悫及</span>  
<span style="margin-left: 2em">卿浚顿首泣谢又复谓浚曰郭三益可与卿共事</span>  
<span style="margin-left: 1em">刘鹏彭城人元祐庚午为华亭令甫下车即修庠序立</span>  
<span style="margin-left: 1em">教诫以至簿书期会井井有条精严而不纷扰治弦歌</span>  
<span style="margin-left: 1em">堂三山亭艮阁于县亝之东与士之贤者讲论歌咏于</span>  
<span style="margin-left: 1em">中以兴起风俗又以前令之政唯静海吴公第一即以</span>  
<span style="margin-left: 1em">吴公所建环碧亭为思吴堂从民望也</span>  
<span style="margin-left: 1em">沈辽字叡达钱塘人翰林学士遘之弟熙宁初为审官</span>  
<span style="margin-left: 1em">西院主簿初受知王安石及安石当国更张新法辽与</span>  
<span style="margin-left: 1em">论事不合罢去久之以太常奉礼郎监杭州军资库转</span>
