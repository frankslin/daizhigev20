<span style="margin-left: 1em">嘉禾志序</span>  
<span style="margin-left: 1em">图志之书古史笔也成周职方掌天下之图外史掌四</span>  
<span style="margin-left: 1em">方之志事亦重矣嘉禾为志何昉乎犹记袁似道为郡</span>  
<span style="margin-left: 1em">治中其家富有古书江浙图志无不备独禾兴阙然非</span>  
<span style="margin-left: 1em">阙也禾兴经邑为州才三百载五代至宋初皆倥偬不</span>  
<span style="margin-left: 1em">暇真宗景德四年尝诏诸道修图经仅得海盐一志而</span>  
<span style="margin-left: 1em">已淳熙甲午郡守张元成始延闻人伯纪为郡志此作</span>  
<span style="margin-left: 1em">古也前乎伯纪所谓旧经虽博览之士无所见其简畧</span>  
<span style="margin-left: 1em">可知后乎伯纪郡守岳珂尝命乡先辈关表卿重修且</span>  
<span style="margin-left: 1em">徧檄诸邑摉访古迹可谓劳于用力书未成而勌翁改</span>  
<span style="margin-left: 1em">调上而无纪录之册可参次而无老成之人可质又次</span>  
<span style="margin-left: 1em">而无贤子弟可询其家世其欲正譌补阙岂不难哉仰</span>  
<span style="margin-left: 1em">惟皇帝考图数贡自北而南此不容于浸废往者郡经</span>  
<span style="margin-left: 1em">历单君庆因请重修郡博士徐君硕承命属笔蒐猎散</span>  
<span style="margin-left: 1em">亡其纲正其篇目加多既完矣而毌丘之扳则未也莱</span>  
<span style="margin-left: 1em">山刘公杰来殿是邦路推翟公汝弼启其议诸路官又</span>  
<span style="margin-left: 1em">相其成可谓是书之幸夫图志重事也其存亡夫岂偶</span>  
<span style="margin-left: 1em">然雷次宗非无豫章记洪驹父求之不得见范石湖非</span>  
<span style="margin-left: 1em">不藁吴郡志以妄议而不得刊今嘉禾志阙而全绝而</span>  
<span style="margin-left: 1em">续郡侯其有功矣哉昔窦德玄不能对帝丘之问人到</span>  
<span style="margin-left: 1em">于今陋之今郡人得是书可以不德玄矣余故喜为之</span>

<span style="margin-left: 1em">嘉禾志序</span>  
<span style="margin-left: 1em">郡有志檄九丘遗意也书以志名凡一郡之事皆在所</span>  
<span style="margin-left: 1em">当录岂特土地所生风气所宜而已哉嘉禾在春秋为</span>  
<span style="margin-left: 1em">檇李至吴黄龙三禩以禾生由拳野故名自春秋距今</span>  
<span style="margin-left: 1em">千七百余年其间有沿有革有废有置世道汗隆之故</span>  
<span style="margin-left: 1em">人物盛衰之由与夫山川风景之所以殊郡邑事迹之</span>  
<span style="margin-left: 1em">所以异其可纪者何可胜数而旧志多简畧弗载宋嘉</span>  
<span style="margin-left: 1em">定甲戌郡守岳侯珂悼前闻之遗阙尝命乡先辈关表</span>  
<span style="margin-left: 1em">卿栻任行人子羽之事编藁将止而岳侯去乡论惜之</span>  
<span style="margin-left: 1em">越六十三载皇帝抚有江南寸天尺地无一不入版图</span>  
<span style="margin-left: 1em">内廼至元甲申克斋单公庆来佐郡幕公余过从辄清</span>  
<span style="margin-left: 1em">谈竟日每喟然叹曰图志三岁一上法也此邦自总府</span>  
<span style="margin-left: 1em">开藩亦既数年而郡志未备非阙典欤遂创议檄委郡</span>  
<span style="margin-left: 1em">博士徐君硕重加修纂君承命惟谨网罗散失抉剔幽</span>  
<span style="margin-left: 1em">眇攷古订今裒集会椊曩之为卷者五今之为卷者三</span>  
<span style="margin-left: 1em">十有二曩之为门者三十有五今之为门者四十有三</span>  
<span style="margin-left: 1em">彪分胪列此志得为全书徐君之用功亦劳矣编成而</span>  
<span style="margin-left: 1em">莱山刘侯杰实来一日哕鸾戾泮路推良佐翟公汝弼</span>  
<span style="margin-left: 1em">以是白侯侯喜退而谂于同列同列亦喜亟命工刻之</span>  
<span style="margin-left: 1em">梓时与人会事与机投莫不庆是书之遭昔张茂先志</span>  
<span style="margin-left: 1em">博物士歆其才萧相国收图籍史韪其识向非侯有相</span>  
<span style="margin-left: 1em">国之识思以具知户口为急务则此志编而不刊与不</span>  
<span style="margin-left: 1em">编等徐君虽有茂先之才其何以自见是举也侯既能</span>  
<span style="margin-left: 1em">俾创议者不至为岳之中沮又能俾修纂者不至为关</span>  
<span style="margin-left: 1em">之徒劳侯亦贤矣哉侯不鄙属余序奚敢以老钝辞虽</span>  
<span style="margin-left: 1em">然此一郡事也侯赋政于外屡殿名邦入坐庙堂将以</span>  
<span style="margin-left: 1em">均四海为己任他日志舆地志九域必有能纪侯之勋</span>  
<span style="margin-left: 1em">业者侯其勉之</span>

<span style="margin-left: 1em">则凡守土之臣不待身履其地而古今风土之迹可一</span>  
<span style="margin-left: 1em">览而槩得于中呜呼盛矣哉余忝自内台备员守松获</span>  
<span style="margin-left: 1em">兹披覩知松寔畿内名郡山川人物表于东海当时郡</span>  
<span style="margin-left: 1em">人若学士钱公原溥亲预总裁之列今适归闲于家余</span>  
<span style="margin-left: 1em">尝访公于东郊询所以编纂之详公曰此特其显然者</span>  
<span style="margin-left: 1em">尔若夫隐而未著则莫之详焉松古一华亭在唐属苏</span>  
<span style="margin-left: 1em">在晋宋属嘉元始为郡而又分割苏嘉为之不能无在</span>  
<span style="margin-left: 1em">彼遗此之歉余曰何不会而通之亦足以备一郡之全</span>  
<span style="margin-left: 1em">乎公曰曩者吾友浦公宗源尝索余成此既以费巨辞</span>  
<span style="margin-left: 1em">前守田公至道又尝计其费而成之事方就绪已有山</span>  
<span style="margin-left: 1em">西左参之命寻以病卒今耄日勌于勤矣尚安事于成</span>  
<span style="margin-left: 1em">哉余强之曰此盛举也不可以中沮公乃出诸古志及</span>  
<span style="margin-left: 1em">所摉访论辨属其长子冈编次成集总若干卷名曰云</span>  
<span style="margin-left: 1em">间通志余喜其书之果于成也乃托郡博叶君灿校正</span>  
<span style="margin-left: 1em">而刻焉夫自昔一统之盛盖莫盛于虞夏之世书赞舜</span>  
<span style="margin-left: 1em">德光天至于海隅而继以万邦黎献共惟帝臣又赞禹</span>  
<span style="margin-left: 1em">文命敷于四海而必任土作贡至于山川田赋物产莫</span>  
<span style="margin-left: 1em">不详焉今松虽僻在海隅寔古扬州之域财赋甲于东</span>  
<span style="margin-left: 1em">南而人材之汇征物产之蕃庶亦万邦怀共臣之愿九</span>  
<span style="margin-left: 1em">土极攸同之归也　圣明一统之所繇以盛者不于斯</span>  
<span style="margin-left: 1em">而益验乎既而郡博来请序谨书此复之若夫节俸以</span>  
<span style="margin-left: 1em">助余刻是集者同知河间傅公恺泰和杨公宪通判南</span>  
<span style="margin-left: 1em">雄黄公恭襄陵王公瑄节推壶关杜公矩也</span>  
<span style="margin-left: 1em">成化之年青龙集癸巳中顺大夫直隶松江府知府前</span>  
<span style="margin-left: 1em">广西道监察御史清涧白行中大本谨序</span>  
<span style="margin-left: 1em">松江府志序</span>  
<span style="margin-left: 1em">予往岁忧居郡守今都御史宜春刘侯琬尝属以志事</span>  
<span style="margin-left: 1em">会予北上不果正德己巳予复以忧归明年庚午御史</span>  
<span style="margin-left: 1em">弋阳谢君琛按部来松问府之故病其遗缺嗣守临川</span>  
<span style="margin-left: 1em">陈侯威复举以属予冬始即事而侯以春去予谓其终</span>  
<span style="margin-left: 1em">弗果也会今守内江喻侯时继至力主成之府始为县</span>  
<span style="margin-left: 1em">时有云间志既为府属嘉兴见嘉禾志直隶省后有松</span>  
<span style="margin-left: 1em">江郡志有续志入国朝有松江志有云间通志通志者</span>  
<span style="margin-left: 1em">会诸志而成书者也云间志历岁久远今已无全书其</span>  
<span style="margin-left: 1em">余虽存而后生之得见者已鲜通志所载又间有脱讹</span>  
<span style="margin-left: 1em">更后数十年遗文坠迹将无复讨寻矣故今并取诸本</span>  
<span style="margin-left: 1em">参互考证会以成编而不敢畧焉通志以后则续之事</span>  
<span style="margin-left: 1em">见他书而诸志所未及者补入之其间卷第之先后类</span>  
<span style="margin-left: 1em">目之分合事辞之易置取合伦例与便检阅盖稍异往</span>  
<span style="margin-left: 1em">编而大率皆其故也至于推原变始考见得失因事寓</span>  
<span style="margin-left: 1em">规间亦有之而罔敢以意参焉呜呼郡之志犹国之史</span>  
<span style="margin-left: 1em">也昔人有成论矣史不为天下万世而私于一人是之</span>  
<span style="margin-left: 1em">谓曲笔志不为一乡与后世亦岂能逃士论之公今兹</span>

<span style="margin-left: 1em">参质为艰而梓刻成矣敢述所怀布诸简首后有作者</span>
