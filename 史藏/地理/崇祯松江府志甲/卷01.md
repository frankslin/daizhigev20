<span style="margin-left: 1em">嘉禾志序</span>  
<span style="margin-left: 1em">圖志之書古史筆也成周職方掌天下之圖外史掌四</span>  
<span style="margin-left: 1em">方之志事亦重矣嘉禾爲志何昉乎猶記袁似道爲郡</span>  
<span style="margin-left: 1em">治中其家富有古書江浙圖志無不備獨禾興闕然非</span>  
<span style="margin-left: 1em">闕也禾興經邑爲州才三百載五代至宋初皆倥偬不</span>  
<span style="margin-left: 1em">暇真宗景德四年嘗詔諸道修圖經僅得海鹽一志而</span>  
<span style="margin-left: 1em">已淳熙甲午郡守張元成始延聞人伯紀爲郡志此作</span>  
<span style="margin-left: 1em">古也前乎伯紀所謂舊經雖博覽之士無所見其簡畧</span>  
<span style="margin-left: 1em">可知後乎伯紀郡守岳珂嘗命鄉先輩關表卿重修且</span>  
<span style="margin-left: 1em">徧檄諸邑摉訪古跡可謂勞於用力書未成而勌翁改</span>  
<span style="margin-left: 1em">調上而無紀錄之册可參次而無老成之人可質又次</span>  
<span style="margin-left: 1em">而無賢子弟可詢其家世其欲正譌補闕豈不難哉仰</span>  
<span style="margin-left: 1em">惟皇帝考圖數貢自北而南此不容於浸廢往者郡經</span>  
<span style="margin-left: 1em">歷單君慶因請重修郡博士徐君碩承命屬筆蒐獵散</span>  
<span style="margin-left: 1em">亡其綱正其篇目加多既完矣而毌丘之扳則未也萊</span>  
<span style="margin-left: 1em">山劉公傑來殿是邦路推翟公汝弼啓其議諸路官又</span>  
<span style="margin-left: 1em">相其成可謂是書之幸夫圖志重事也其存亡夫豈偶</span>  
<span style="margin-left: 1em">然雷次宗非無豫章記洪駒父求之不得見范石湖非</span>  
<span style="margin-left: 1em">不藁吳郡志以妄議而不得刊今嘉禾志闕而全絶而</span>  
<span style="margin-left: 1em">續郡侯其有功矣哉昔竇德玄不能對帝丘之問人到</span>  
<span style="margin-left: 1em">於今陋之今郡人得是書可以不德玄矣余故喜爲之</span>  
<span style="margin-left: 1em">辭</span>  
<span style="margin-left: 1em">至元戊子孟夏里人郭晦序</span>  
<span style="margin-left: 1em">嘉禾志序</span>  
<span style="margin-left: 1em">郡有志檄九丘遺意也書以志名凡一郡之事皆在所</span>  
<span style="margin-left: 1em">當錄豈特土地所生風氣所宜而已哉嘉禾在春秋爲</span>  
<span style="margin-left: 1em">檇李至吳黃龍三禩以禾生由拳野故名自春秋距今</span>  
<span style="margin-left: 1em">千七百餘年其間有沿有革有廢有置世道汗隆之故</span>  
<span style="margin-left: 1em">人物盛衰之由與夫山川風景之所以殊郡邑事蹟之</span>  
<span style="margin-left: 1em">所以異其可紀者何可勝數而舊志多簡畧弗載宋嘉</span>  
<span style="margin-left: 1em">定甲戌郡守岳侯珂悼前聞之遺闕嘗命鄉先輩關表</span>  
<span style="margin-left: 1em">卿栻任行人子羽之事編藁將止而岳侯去鄉論惜之</span>  
<span style="margin-left: 1em">越六十三載皇帝撫有江南寸天尺地無一不入版圖</span>  
<span style="margin-left: 1em">內廼至元甲申克齋單公慶來佐郡幕公餘過從輒清</span>  
<span style="margin-left: 1em">談竟日每喟然嘆曰圖志三歲一上法也此邦自總府</span>  
<span style="margin-left: 1em">開藩亦既數年而郡志未備非闕典歟遂創議檄委郡</span>  
<span style="margin-left: 1em">博士徐君碩重加修纂君承命惟謹網羅散失抉剔幽</span>  
<span style="margin-left: 1em">眇攷古訂今裒集會椊曩之爲卷者五今之爲卷者三</span>  
<span style="margin-left: 1em">十有二曩之爲門者三十有五今之爲門者四十有三</span>  
<span style="margin-left: 1em">彪分臚列此志得爲全書徐君之用功亦勞矣編成而</span>  
<span style="margin-left: 1em">萊山劉侯傑實來一日噦鸞戾泮路推良佐翟公汝弼</span>  
<span style="margin-left: 1em">以是白侯侯喜退而諗於同列同列亦喜亟命工刻之</span>  
<span style="margin-left: 1em">梓時與人會事與機投莫不慶是書之遭昔張茂先志</span>  
<span style="margin-left: 1em">博物士歆其才蕭相國收圖籍史韙其識向非侯有相</span>  
<span style="margin-left: 1em">國之識思以具知户口爲急務則此志編而不刊與不</span>  
<span style="margin-left: 1em">編等徐君雖有茂先之才其何以自見是舉也侯既能</span>  
<span style="margin-left: 1em">俾創議者不至爲岳之中沮又能俾修纂者不至爲關</span>  
<span style="margin-left: 1em">之徒勞侯亦賢矣哉侯不鄙屬余序奚敢以老鈍辭雖</span>  
<span style="margin-left: 1em">然此一郡事也侯賦政於外屢殿名邦入坐廟堂將以</span>  
<span style="margin-left: 1em">均四海爲己任他日志輿地志九域必有能紀侯之勳</span>

<span style="margin-left: 1em">書</span>  
<span style="margin-left: 1em">雲間通志序</span>  
<span style="margin-left: 1em">國朝文化丕冒旁洽薄海內外罔非臣土我　列聖嘗</span>  
<span style="margin-left: 1em">采輯天下事實編成大明一統志而　皇上特頒行之</span>  
<span style="margin-left: 1em">則凡守土之臣不待身履其地而古今風土之蹟可一</span>  
<span style="margin-left: 1em">覽而槩得于中嗚呼盛矣哉余忝自內臺備員守松獲</span>  
<span style="margin-left: 1em">兹披覩知松寔畿內名郡山川人物表於東海當時郡</span>  
<span style="margin-left: 1em">人若學士錢公原溥親預總裁之列今適歸閒于家余</span>  
<span style="margin-left: 1em">嘗訪公於東郊詢所以編纂之詳公曰此特其顯然者</span>  
<span style="margin-left: 1em">爾若夫隱而未著則莫之詳焉松古一華亭在唐屬蘇</span>  
<span style="margin-left: 1em">在晉宋屬嘉元始爲郡而又分割蘇嘉爲之不能無在</span>  
<span style="margin-left: 1em">彼遺此之歉余曰何不會而通之亦足以備一郡之全</span>  
<span style="margin-left: 1em">乎公曰曩者吾友浦公宗源嘗索余成此既以費鉅辭</span>  
<span style="margin-left: 1em">前守田公至道又嘗計其費而成之事方就緒已有山</span>  
<span style="margin-left: 1em">西左參之命尋以病卒今耄日勌於勤矣尚安事於成</span>  
<span style="margin-left: 1em">哉余强之曰此盛舉也不可以中沮公乃出諸古志及</span>  
<span style="margin-left: 1em">所摉訪論辨屬其長子岡編次成集總若干卷名曰雲</span>  
<span style="margin-left: 1em">間通誌余喜其書之果於成也乃托郡博葉君燦校正</span>  
<span style="margin-left: 1em">而刻焉夫自昔一統之盛蓋莫盛於虞夏之世書贊舜</span>  
<span style="margin-left: 1em">德光天至於海隅而繼以萬邦黎獻共惟帝臣又贊禹</span>  
<span style="margin-left: 1em">文命敷於四海而必任土作貢至於山川田賦物産莫</span>  
<span style="margin-left: 1em">不詳焉今松雖僻在海隅寔古揚州之域財賦甲於東</span>  
<span style="margin-left: 1em">南而人材之彙征物産之蕃庶亦萬邦懷共臣之願九</span>  
<span style="margin-left: 1em">土極攸同之歸也　聖明一統之所繇以盛者不於斯</span>  
<span style="margin-left: 1em">而益驗乎既而郡博來請序謹書此復之若夫節俸以</span>  
<span style="margin-left: 1em">助余刻是集者同知河間傅公愷泰和楊公憲通判南</span>  
<span style="margin-left: 1em">雄黃公恭襄陵王公瑄節推壺關杜公矩也</span>  
<span style="margin-left: 1em">成化之年青龍集癸巳中順大夫直隸松江府知府前</span>  
<span style="margin-left: 1em">廣西道監察御史清澗白行中大本謹序</span>  
<span style="margin-left: 1em">松江府志序</span>  
<span style="margin-left: 1em">予往歲憂居郡守今都御史宜春劉侯琬嘗屬以志事</span>  
<span style="margin-left: 1em">會予北上不果正德己巳予復以憂歸明年庚午御史</span>  
<span style="margin-left: 1em">弋陽謝君琛按部來松問府之故病其遺缺嗣守臨川</span>  
<span style="margin-left: 1em">陳侯威復舉以屬予冬始即事而侯以春去予謂其終</span>  
<span style="margin-left: 1em">弗果也會今守內江喻侯時繼至力主成之府始爲縣</span>  
<span style="margin-left: 1em">時有雲間志既爲府屬嘉興見嘉禾志直隸省後有松</span>  
<span style="margin-left: 1em">江郡志有續志入國朝有松江志有雲間通志通志者</span>  
<span style="margin-left: 1em">會諸志而成書者也雲間志歷歲久遠今已無全書其</span>  
<span style="margin-left: 1em">餘雖存而後生之得見者已鮮通志所載又間有脱訛</span>  
<span style="margin-left: 1em">更後數十年遺文墜蹟將無復討尋矣故今並取諸本</span>  
<span style="margin-left: 1em">參互考證會以成編而不敢畧焉通志以後則續之事</span>  
<span style="margin-left: 1em">見他書而諸志所未及者補入之其間卷第之先後類</span>  
<span style="margin-left: 1em">目之分合事辭之易置取合倫例與便檢閲蓋稍異往</span>  
<span style="margin-left: 1em">編而大率皆其故也至于推原變始考見得失因事寓</span>  
<span style="margin-left: 1em">規間亦有之而罔敢以意參焉嗚呼郡之志猶國之史</span>  
<span style="margin-left: 1em">也昔人有成論矣史不爲天下萬世而私於一人是之</span>  
<span style="margin-left: 1em">謂曲筆志不爲一鄉與後世亦豈能逃士論之公今茲</span>  
<span style="margin-left: 1em">纂輯蓋歉焉惟淺狹掛漏貽笑於大方是懼日月滋久</span>  
<span style="margin-left: 1em">參質爲艱而梓刻成矣敢述所懷布諸簡首後有作者</span>  
<span style="margin-left: 1em">即其具文加之黼藻以成一郡之書豈惟寡學之幸亦</span>  
<span style="margin-left: 1em">前後諸公所以屬望之心也志爲卷三十二爲目三十</span>  
<span style="margin-left: 1em">一目之下又有目焉凡十有七卷始終暨圖目爲版九</span>  
<span style="margin-left: 1em">百十有六居之郡閣備散逸也同事諸生與郡之僚屬</span>  
<span style="margin-left: 1em">贊襄於是者並列名左方</span>
