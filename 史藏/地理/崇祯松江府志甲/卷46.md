## 崇禎松江府志卷之四十六　第宅　園林

<span style="margin-left: 3em">第宅園林</span>  
<span style="margin-left: 1em">郡內外第宅園林雕峻詭壯力窮而止有秉燭一覽肩</span>  
<span style="margin-left: 1em">輿一登而終身不得住者又有俄轉眼而易姓俄百年</span>  
<span style="margin-left: 1em">而易爲蔓草寒煙者華顛鄰叟慨焉傷懷而後人廣求</span>  
<span style="margin-left: 1em">方幅遑遑問舍如故也今志書所存譬之簷前燕泥雪</span>  
<span style="margin-left: 1em">中鴻爪而已讀平泉遺誡乃知巢公巢壺公壺未爲無</span>  
<span style="margin-left: 1em">見范文正云人苟有道義之樂形骸可外况居室哉志</span>  
<span style="margin-left: 1em">第宅而園林附之</span>  
<span style="margin-left: 1em">孔宅在海隅鄉<sub class="note-yuan">府北六十里前志云宋淳熙間居民浚河得碑云天寶六年黃池縣令朱氏葬于崑山縣全吳鄉孔子宅之西南孔宅之名舊矣今其地有夫子廟在慧日院側又院僧疏廟陾渠得寶玉六事璧三環二簪一舊圖經云昔有姓孔者遊吳居此蓋吾夫子未嘗適吳以闕里譜系考之孔氏二十二代孫潛後漢太子少傅避地會稽遂爲郡人二十九代滔梁海鹽令三十二代嗣哲隋吳郡主簿三十四代禎隋蘇州長史豈孔氏子孫有僑寓宦遊于吳而遂居華亭者邪亦猶建康有孔子巷乃聖亭侯所奉之廟蓋子孫即所居立先聖廟耳今廟側又有梁紇廟其爲子孫奉祀之地明矣所瘞璧簪珮之屬其孔堂之遺寶得非子孫葬先聖衣冠寶璧於是地乎其旁有宰我墩顔淵井今考闕里譜自後漢孔潛僑寓於吳至滔至嗣哲至禎蓋相傳數代爲吳人其地號稱孔宅久矣子姓繁衍占籍廣濶所謂白鶴江去今孔宅僅四五里梁紇廟理應有之非傅會也元至正間里人章弼建講院以集鄉俊之來學者距今凡若干年廟貌剥落墓址蒿萊考其故跡僅十之一二耳萬曆丙午陸應陽錢大復創義重修俞汝楫陸濟賢贊成之申文定公記聖像側有顔曾二像嘉靖間島夷犯境毁曾像俄一人帶兩繯者與戰良久寇遁去人疑子路之靈故塑像以配又萬曆某年土人伐廟樹口鼻流血乃止又殿傍老樹鸛巢其上殿瓦悉污一夕風雨拔樹鸛擊死而片瓦不動</sub></span>  
<span style="margin-left: 1em">陸績宅在長谷<sub class="note-yuan">吳地記云漢廬江太守陸康與袁術有隙使子遜與其子績將家遷于長谷</sub></span>  
<span style="margin-left: 1em">陸遜宅在長谷<sub class="note-yuan">元和郡國志華亭谷在縣西三十五里陸抗宅在其側</sub></span>  
<span style="margin-left: 1em">陸曄宅在崑山<sub class="note-yuan">曄字士光仕晉爲車騎機贈從兄車騎詩云髣髴崑山陰婉孌谷水陽此也</sub></span>  
<span style="margin-left: 1em">陸機宅在崑山平原村<sub class="note-yuan">舊圖經云華亭谷水東有崑山世傳陸機宅又普照寺爲陸氏園亭後捨爲寺然建康亦有陸機宅在秦淮之側李太白王處士水亭序云齊朝南苑是陸機宅按孫皓徙居建康機雲分領父兵爲牙門將軍蓋機仕于朝則居建業華亭乃其里第家在平原村別業在寺址無疑陸機懷土賦云余去家漸久懷土彌篤方思之殷何物不感曲街委巷罔不興詠水泉草木咸足悲焉故述斯賦背故都之沃衍適新邑之丘墟遵黃川以葺宇被蒼林而卜居悼孤生之已晏恨親没之何速排虛房而永念想遺塵其如玉眇緜邈而莫構徒佇立其焉屬感亡景於存物惋頽年於拱木悲顧盻而有餘思俯仰而自足留兹情於江介寄瘁貌於河曲玩通川以悠想撫征轡而躑躅伊命駕之徒勤慘歸途之良難愍栖鳥於南枝吊離禽於別山念庭樹以悟懷憶路草而解顔甘堇荼於飴茈緯蕭艾其如蘭神何寢而不夢形何興而不言唐詢舊牒傳遺址悠然歷祀深人無令威至門異下邽箴谷水當年溜崑山昔日陰魯堂那復見絲竹若爲尋王安石故物一已盡嗟此歲年深野桃自着花荒棘徒生箴芊芊谷水陽鬱鬱崑山陰俛仰但如昨遊踪不可尋梅堯臣我思陸平原廢宅荒草深才高乃速禍事往不可箴饑烏噪樹顛野鼠窟庭陰黃耳亦已死家書無復尋王艮士衡多奇才儒術何困深少年作文賦吐秀視含箴遭讒卒遇禍白日雲爲陰一聞華亭鶴遺址尚可尋段天祐二陸騎鯨去于今歲月深才高多見嫉文好不容箴野水添春漲林煙駐夕陰蕭條讀書處遺跡可能尋</sub></span>  
<span style="margin-left: 1em">陸瑁宅<sub class="note-yuan">在養魚池上故其池相傳爲瑁湖</sub></span>  
<span style="margin-left: 1em">陸錡宅<sub class="note-yuan">在錡湖上湖亦以錡得名</sub></span>  
<span style="margin-left: 1em">顧府君宅<sub class="note-yuan">在亭林鎮地有高丘梁黃門侍郎顧野王於此修輿地志其北有湖湖南有林因呼顧亭林湖亦曰顧亭林宅今爲寶雲寺高丘正當寺後時呼野王讀書堆相傳宅之故垣介一髹甓鍥云東七里西七里祇在七七里厥後或識以爲廋語其在漆裏竊之金也雲間賦云于南迫海野王之所人亡而吾伊聲寂春歸而青深林莽金璧久瘞土頽甲第胡爲七七之說而成他人之利謂此寺有沼深黑冬夏不竭云野王墨池有古松云野王手植蓋附會云錢良臣伊昔邊烽備不虞太平移作梵王居而今江表全無事借我三椽更讀書革猷之六朝代謝與誰論獨有商人舊址存休問當時興廢事淡煙斜日照孤村</sub></span>  
<span style="margin-left: 1em">袁崧宅府西北<sub class="note-yuan">舊經昔袁崧居此因名崧宅按晉史崧陳郡陽夏人則其始未嘗居華亭也隆安四年爲吳郡太守嘗築滬瀆壘以禦孫恩明年遇害于滬瀆或者崧殁後其子孫遂居此乎今其地里曰崧子水曰崧皆其遺跡也</sub></span>  
<span style="margin-left: 1em">顧謙宅在府西北崧子里</span>  
<span style="margin-left: 1em">朱少師宅<sub class="note-yuan">雲間志云在府治後朱家巷後賜第于平江</sub></span>  
<span style="margin-left: 1em">柳侍郎宅在柳家巷<sub class="note-yuan">府治西北</sub></span>  
<span style="margin-left: 1em">衛文節公宅在府東南蕭塘今爲崇福寺<sub class="note-yuan">按蘇志涇之祖闐自華亭徙崑山之石浦故涇以崑山貫登第而前志云涇生於蕭塘淇水流慶錄云本居華亭後遷石浦崇福寺記華嚴可師捨宅建而涇以故第益之然則闐徙崑山僅同寄籍而涇之生長固在華亭及捨宅爲寺則定居於崑矣今鶴城書院以西相傳亦衛氏故宅普照續古錄云宋建炎中寺災至衛宅磚牆始滅近歲居民於古井得巨磚無數皆有衛仲英三字仲英膚敏之子與文節從兄弟也</sub></span>  
<span style="margin-left: 1em">章楶宅在青龍鎮<sub class="note-yuan">楶監華亭鹽寓於此子孫遂家焉建清忠書院</sub></span>  
<span style="margin-left: 1em">燕超堂朱彦美宴息之所<sub class="note-yuan">孫覿記曰中奉大夫直秘閣華亭朱公著名籍於仕版者五十年四持使者節官至上大夫尊顯三朝而被遇於太上皇召見賜帶服進職中秘恩賚光寵一時歆豔以爲榮年七十上書納禄築堂圃中將朝夕游愒於此堂成肅賓客置酒樂之名之曰燕超乃詒書徵余文爲記予曰屬者夷狄之禍蹀血萬里諸戎長騖於通都大邑之中官軍縱掠於深山窮谷無人之境婦被髮過其夫女齧臂號其父草薙而禽獮之盡矣脱復漏網幸而免者而鈎落張設熟視無所向往往飢渴相倚以死幸而不死則蒙霜露披榛莽踐蛇虺嬴身間行力竭氣窮又踣于中道其最幸者不死于兵刃不淪于異域不斃于飢寒不仆于道路間關百難寒暑易節而後得至于此千萬人蓋不一遇焉顧視田廬已爲墟矣追隨妻子則化爲異物矣其左右執事使令之人逃難解散莫知其鄉矣單游羈寓茫無所之於是栖栖然求活于升斗而官冗地褊一官所居常數十人間伺之不幸而立于争地則推而納之穽中且下召焉又瀕于死可悲也已惟朱公聰明敏達見微知著方靖康建炎之亂積六七年兵火被四海衣冠僵仆交迹公家居海上不出閭巷不去墳墓不見一夫疾步急呼之警而又才智絶人自縣令州佐奉使一路名跡偉然常最其列至是潛深伏奥縮手袖間不任一事築舍旁疏池沼蒔花竹幅巾藜杖徜徉其中夫婦偕老歲時坐堂上華髮相映子孫滿前腰綬擁笏奉巵酒爲壽吹竹彈絲極歡而罷得老氏所謂燕處超然者昔楚漢相持跳兵走馬百戰於商之地而中有黃公綺季之閑爰兹屏居謝事浮湛閭里一出而爲景帝畫梁王非望之謀遂亦不免於乎世亂多故士大夫係虜劫資之害溝壑顛仆之憂與夫竄殛流放之厄皆自有以取之惟勝士高人深明去就顯晦之大節俛仰遯世違遠俗患坐視猿猱顛倒罝網中而兩手猶未置所操也兹其所以爲超然者耶覿公夫人之從子也憂患乖離不獲見十年矣其山林之勝輪奂之華今不能言也他日造公之堂尚能援筆賦之公諱彦美字師實華亭縣人既請老自號機山閑人云又詩云海禺納萬艘市區沸百賈黃塵翳白日千騎騰一鼓蛟巢十字路四顧盡曠土蝸角兩大國一怒有漂杵角名昡多盧聚訟分衆楚昏昏氣成霧濯濯汗浹雨朱公誤涉世吏隱寄圭組俗緣墮人境心大接天宇搴芳採蓮舟擷秀藝藥圃山寒石稜紫樹老松鬣古風牽碧羅卷雨壓翠纛舞寧須鳥催酤自有花解語觀魚樂洋洋夢蝶飛栩栩坐令游俠窟化作仙佛土高卧水國秋靜憩月庭午不假壺公龍天上有官府</sub></span>  
<span style="margin-left: 1em">晚風清亭在華亭史氏家園米芾書扁</span>  
<span style="margin-left: 1em">百客堂下沙瞿氏宴享婣黨之室<sub class="note-yuan">瞿別有園池甲於浙西陶南村曰浙西園苑之勝惟松江下沙瞿氏爲最古宋秀州方岳亦有詩留題壁間後紫陽虛谷翁方回來游繼題十絶其一云壁間墨客掃龍蛇所寫詩佳字亦佳忽見一詩增感慨吾家宗伯老秋厓</sub></span>

<span style="margin-left: 1em">熙園<sub class="note-yuan">顧正心居張寶臣記曰園距東郭三里許面水而門門以內爲四美亭啓左扉而北落落長杉瀟瀟疎竹夾植徑中行數十武而危樓翼然榜曰熙園是園之啓途也東入山徑蒼苔碧蘚似武陵道中折而北仰俯盤旋陡入深壑嵌空中時聞淙淙聲疑山背有龍湫焉復折而南踰峻嶺下層巒劃然天門開則流觴曲水在其下駕水爲聽鶯橋花時夫坐睍睆盈耳可當數部鼓吹倚橋面南而臨者芝雲堂也董宗伯書額取仲瑛氏舊題云堂高敞弘麗可容數十座其陽則疏峯萬叠古樹千章蒼茫雲際而下則華沼一曲荷香十里不减太液池頭好事者每欲窮其幽致則入西麓出東隅如登九折坂入五溪洞怪石巃嵸林薄陰翳幽崖晦谷隔離天日自午達晡始得穿竇出客外坐方饑疲欲臥而出者争目眩汗浹魂摇摇不能吐一語也噫觀奇哉其陰則菌閣葯房霓連雲蔓複道相屬行者每失故道商周之鼎彝唐宋之圖畫紛披闐駢其中不可更僕數則主人安神思玄之所非酌霞枕香之友弗能到也憑樓西眺旋臺飛觀隱隱樹杪間冠以玉樹瓊花罨映下方令人可望不可即堂之左爲長廊響屧隔岸土阜蜿蜒雜檀梅杏桃李春華爛發白雪紅霞彌望極目又疑身在衆香國矣繞廊而北度飛虹橋橋平廣滑澤可坐而邀月大士閣兀立橋畔題曰水月如來稍東爲池上亭又東度板橋爲與清軒與土阜之北界接司理徐碩庵先生題額軒臨廣池灝溔潢漾足並瀟湘震澤繡尾銀鱗出没無算巨者齎浪飛𮥋客至舉網擊鮮稱快事遥睇南岸皓壁綺疏隱現綠楊碧藻中其壺瀛宫闕幻落塵界乎繇是陟彼北山平岡逶迤高梧修竹蔭蔽左右西達齊青閣北望平疇綠浄欸乃四起又疑下有朱陳村第少鳴鷄吠犬耳閣前週繞廣除可馳駿足對面翠屏壁立峭崿鬱盤玄裳之客斑衣之友時遊娱其上累數級下依水而屋雕闌繡檻枕飛虹足歌聲時出簾箔中則小秦淮也南遵迴廊數十盤鼻間微聞𣒰檀氣則羅漢堂峙焉堂供薄伽像三旁列五百應真金碧莊嚴鐘梵具設堂後小閣三楹藏貝葉書甚富時倩高緇繙繹聲琅琅出牖外儼然古招提也堂前一巨石高十丈許四面玲瓏真襄陽譜中物初得是石未有磐載至泖涇舟覆石沉牽挽而出先得磐次乃得石合之其舊偶也珠還劍合豈獨神于古哉搆堂時掘地得古鐵缸大可容十斛今以作焚爐亦異物也堂左經關壯繆祠度濯錦梁並步虛廊尋石寶而出則爲芝雲堂之右曠然廣庭而園之觀止矣蓋青宇先生擲數十萬金錢救兩邑瘡痍其胸次真可吞雲夢八九故其規模位置軼前哲無兩而嗣君原之文孫元慶大雅亢宗又皆以繪事擅長臆間具有丘壑其增修點綴俱從虎頭筆端摩詰句中出之宜其勝絶一代也</sub></span>
