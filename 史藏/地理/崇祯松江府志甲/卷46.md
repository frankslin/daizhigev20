## 崇祯松江府志卷之四十六　第宅　园林

<span style="margin-left: 3em">第宅园林</span>  
<span style="margin-left: 1em">郡内外第宅园林雕峻诡壮力穷而止有秉烛一览肩</span>  
<span style="margin-left: 1em">舆一登而终身不得住者又有俄转眼而易姓俄百年</span>  
<span style="margin-left: 1em">而易为蔓草寒烟者华颠邻叟慨焉伤怀而后人广求</span>  
<span style="margin-left: 1em">方幅遑遑问舍如故也今志书所存譬之簷前燕泥雪</span>  
<span style="margin-left: 1em">中鸿爪而已读平泉遗诫乃知巢公巢壶公壶未为无</span>  
<span style="margin-left: 1em">见范文正云人苟有道义之乐形骸可外况居室哉志</span>  
<span style="margin-left: 1em">第宅而园林附之</span>  
<span style="margin-left: 1em">孔宅在海隅乡<sub class="note-yuan">府北六十里前志云宋淳熙间居民浚河得碑云天宝六年黄池县令朱氏葬于昆山县全吴乡孔子宅之西南孔宅之名旧矣今其地有夫子庙在慧日院侧又院僧疏庙陾渠得宝玉六事璧三环二簪一旧图经云昔有姓孔者游吴居此盖吾夫子未尝适吴以阙里谱系考之孔氏二十二代孙潜后汉太子少傅避地会稽遂为郡人二十九代滔梁海盐令三十二代嗣哲隋吴郡主簿三十四代祯隋苏州长史岂孔氏子孙有侨寓宦游于吴而遂居华亭者邪亦犹建康有孔子巷乃圣亭侯所奉之庙盖子孙即所居立先圣庙耳今庙侧又有梁纥庙其为子孙奉祀之地明矣所瘗璧簪珮之属其孔堂之遗宝得非子孙葬先圣衣冠宝璧于是地乎其旁有宰我墩颜渊井今考阙里谱自后汉孔潜侨寓于吴至滔至嗣哲至祯盖相传数代为吴人其地号称孔宅久矣子姓繁衍占籍广濶所谓白鹤江去今孔宅仅四五里梁纥庙理应有之非傅会也元至正间里人章弼建讲院以集乡俊之来学者距今凡若干年庙貌剥落墓址蒿莱考其故迹仅十之一二耳万历丙午陆应阳钱大复创义重修俞汝楫陆济贤赞成之申文定公记圣像侧有颜曾二像嘉靖间岛夷犯境毁曾像俄一人带两缳者与战良久寇遁去人疑子路之灵故塑像以配又万历某年土人伐庙树口鼻流血乃止又殿傍老树鹳巢其上殿瓦悉污一夕风雨拔树鹳击死而片瓦不动</sub></span>  
<span style="margin-left: 1em">陆绩宅在长谷<sub class="note-yuan">吴地记云汉庐江太守陆康与袁术有隙使子逊与其子绩将家迁于长谷</sub></span>  
<span style="margin-left: 1em">陆逊宅在长谷<sub class="note-yuan">元和郡国志华亭谷在县西三十五里陆抗宅在其侧</sub></span>  
<span style="margin-left: 1em">陆晔宅在昆山<sub class="note-yuan">晔字士光仕晋为车骑机赠从兄车骑诗云髣髴昆山阴婉娈谷水阳此也</sub></span>  
<span style="margin-left: 1em">陆机宅在昆山平原村<sub class="note-yuan">旧图经云华亭谷水东有昆山世传陆机宅又普照寺为陆氏园亭后舍为寺然建康亦有陆机宅在秦淮之侧李太白王处士水亭序云齐朝南苑是陆机宅按孙皓徙居建康机云分领父兵为牙门将军盖机仕于朝则居建业华亭乃其里第家在平原村别业在寺址无疑陆机怀土赋云余去家渐久怀土弥笃方思之殷何物不感曲街委巷罔不兴咏水泉草木咸足悲焉故述斯赋背故都之沃衍适新邑之丘墟遵黄川以葺宇被苍林而卜居悼孤生之已晏恨亲没之何速排虚房而永念想遗尘其如玉眇緜邈而莫构徒伫立其焉属感亡景于存物惋颓年于拱木悲顾盻而有余思俯仰而自足留兹情于江介寄瘁貌于河曲玩通川以悠想抚征辔而踯躅伊命驾之徒勤惨归途之良难愍栖鸟于南枝吊离禽于别山念庭树以悟怀忆路草而解颜甘堇荼于饴茈纬萧艾其如兰神何寝而不梦形何兴而不言唐询旧牒传遗址悠然历祀深人无令威至门异下邽箴谷水当年溜昆山昔日阴鲁堂那复见丝竹若为寻王安石故物一已尽嗟此岁年深野桃自着花荒棘徒生箴芊芊谷水阳郁郁昆山阴俛仰但如昨游踪不可寻梅尧臣我思陆平原废宅荒草深才高乃速祸事往不可箴饥乌噪树颠野鼠窟庭阴黄耳亦已死家书无复寻王艮士衡多奇才儒术何困深少年作文赋吐秀视含箴遭谗卒遇祸白日云为阴一闻华亭鹤遗址尚可寻段天祐二陆骑鲸去于今岁月深才高多见嫉文好不容箴野水添春涨林烟驻夕阴萧条读书处遗迹可能寻</sub></span>  
<span style="margin-left: 1em">陆瑁宅<sub class="note-yuan">在养鱼池上故其池相传为瑁湖</sub></span>  
<span style="margin-left: 1em">陆锜宅<sub class="note-yuan">在锜湖上湖亦以锜得名</sub></span>  
<span style="margin-left: 1em">顾府君宅<sub class="note-yuan">在亭林镇地有高丘梁黄门侍郎顾野王于此修舆地志其北有湖湖南有林因呼顾亭林湖亦曰顾亭林宅今为宝云寺高丘正当寺后时呼野王读书堆相传宅之故垣介一髹甓锲云东七里西七里祇在七七里厥后或识以为廋语其在漆里窃之金也云间赋云于南迫海野王之所人亡而吾伊声寂春归而青深林莽金璧久瘗土颓甲第胡为七七之说而成他人之利谓此寺有沼深黑冬夏不竭云野王墨池有古松云野王手植盖附会云钱良臣伊昔边烽备不虞太平移作梵王居而今江表全无事借我三椽更读书革猷之六朝代谢与谁论独有商人旧址存休问当时兴废事淡烟斜日照孤村</sub></span>  
<span style="margin-left: 1em">袁崧宅府西北<sub class="note-yuan">旧经昔袁崧居此因名崧宅按晋史崧陈郡阳夏人则其始未尝居华亭也隆安四年为吴郡太守尝筑沪渎垒以御孙恩明年遇害于沪渎或者崧殁后其子孙遂居此乎今其地里曰崧子水曰崧皆其遗迹也</sub></span>  
<span style="margin-left: 1em">顾谦宅在府西北崧子里</span>  
<span style="margin-left: 1em">朱少师宅<sub class="note-yuan">云间志云在府治后朱家巷后赐第于平江</sub></span>  
<span style="margin-left: 1em">柳侍郎宅在柳家巷<sub class="note-yuan">府治西北</sub></span>  
<span style="margin-left: 1em">卫文节公宅在府东南萧塘今为崇福寺<sub class="note-yuan">按苏志泾之祖阗自华亭徙昆山之石浦故泾以昆山贯登第而前志云泾生于萧塘淇水流庆录云本居华亭后迁石浦崇福寺记华严可师舍宅建而泾以故第益之然则阗徙昆山仅同寄籍而泾之生长固在华亭及舍宅为寺则定居于昆矣今鹤城书院以西相传亦卫氏故宅普照续古录云宋建炎中寺灾至卫宅砖墙始灭近岁居民于古井得巨砖无数皆有卫仲英三字仲英肤敏之子与文节从兄弟也</sub></span>  
<span style="margin-left: 1em">章楶宅在青龙镇<sub class="note-yuan">楶监华亭盐寓于此子孙遂家焉建清忠书院</sub></span>  
<span style="margin-left: 1em">燕超堂朱彦美宴息之所<sub class="note-yuan">孙觌记曰中奉大夫直秘阁华亭朱公著名籍于仕版者五十年四持使者节官至上大夫尊显三朝而被遇于太上皇召见赐带服进职中秘恩赉光宠一时歆艳以为荣年七十上书纳禄筑堂圃中将朝夕游愒于此堂成肃宾客置酒乐之名之曰燕超乃诒书征余文为记予曰属者夷狄之祸蹀血万里诸戎长骛于通都大邑之中官军纵掠于深山穷谷无人之境妇被发过其夫女啮臂号其父草薙而禽狝之尽矣脱复漏网幸而免者而钩落张设熟视无所向往往饥渴相倚以死幸而不死则蒙霜露披榛莽践蛇虺嬴身间行力竭气穷又踣于中道其最幸者不死于兵刃不沦于异域不毙于饥寒不仆于道路间关百难寒暑易节而后得至于此千万人盖不一遇焉顾视田庐已为墟矣追随妻子则化为异物矣其左右执事使令之人逃难解散莫知其乡矣单游羁寓茫无所之于是栖栖然求活于升斗而官冗地褊一官所居常数十人间伺之不幸而立于争地则推而纳之穽中且下召焉又濒于死可悲也已惟朱公聪明敏达见微知著方靖康建炎之乱积六七年兵火被四海衣冠僵仆交迹公家居海上不出闾巷不去坟墓不见一夫疾步急呼之警而又才智绝人自县令州佐奉使一路名迹伟然常最其列至是潜深伏奥缩手袖间不任一事筑舍旁疏池沼莳花竹幅巾藜杖徜徉其中夫妇偕老岁时坐堂上华发相映子孙满前腰绶拥笏奉巵酒为寿吹竹弹丝极欢而罢得老氏所谓燕处超然者昔楚汉相持跳兵走马百战于商之地而中有黄公绮季之闲爰兹屏居谢事浮湛闾里一出而为景帝画梁王非望之谋遂亦不免於乎世乱多故士大夫系虏劫资之害沟壑颠仆之忧与夫窜殛流放之厄皆自有以取之惟胜士高人深明去就显晦之大节俛仰遯世违远俗患坐视猿猱颠倒罝网中而两手犹未置所操也兹其所以为超然者耶觌公夫人之从子也忧患乖离不获见十年矣其山林之胜轮奂之华今不能言也他日造公之堂尚能援笔赋之公讳彦美字师实华亭县人既请老自号机山闲人云又诗云海禺纳万艘市区沸百贾黄尘翳白日千骑腾一鼓蛟巢十字路四顾尽旷土蜗角两大国一怒有漂杵角名昡多卢聚讼分众楚昏昏气成雾濯濯汗浃雨朱公误涉世吏隐寄圭组俗缘堕人境心大接天宇搴芳采莲舟撷秀艺药圃山寒石棱紫树老松鬣古风牵碧罗卷雨压翠纛舞宁须鸟催酤自有花解语观鱼乐洋洋梦蝶飞栩栩坐令游侠窟化作仙佛土高卧水国秋静憩月庭午不假壶公龙天上有官府</sub></span>  
<span style="margin-left: 1em">晚风清亭在华亭史氏家园米芾书扁</span>  
<span style="margin-left: 1em">百客堂下沙瞿氏宴享婣党之室<sub class="note-yuan">瞿别有园池甲于浙西陶南村曰浙西园苑之胜惟松江下沙瞿氏为最古宋秀州方岳亦有诗留题壁间后紫阳虚谷翁方回来游继题十绝其一云壁间墨客扫龙蛇所写诗佳字亦佳忽见一诗增感慨吾家宗伯老秋厓</sub></span>
