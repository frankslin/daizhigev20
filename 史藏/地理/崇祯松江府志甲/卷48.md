## 崇禎松江府志卷之四十八　塜墓

<span style="margin-left: 3em">塚墓</span>  
<span style="margin-left: 1em">墓者暮也長夜不復旦矣古今墓碑纍纍非賢子孫世</span>  
<span style="margin-left: 1em">守之不得跡而跡之村豎田翁之口孰若反而求諸志</span>  
<span style="margin-left: 1em">中之志猶可考也隋楊俊曰人生求名一卷史書足矣</span>  
<span style="margin-left: 1em">何用碑爲若不能保家徒與人作鎮石耳此塚墓所以</span>  
<span style="margin-left: 1em">記之志也</span>  
<span style="margin-left: 3em">古墓存疑</span>  
<span style="margin-left: 1em">三女岡在華亭縣東南八十里<sub class="note-yuan">舊圖經云吳王葬三女于此宋唐詢諸公多題咏詳古蹟又吳越春秋錄異傳有吳王葬女閶門外事吳王夫差小女曰玉年十八歲童子韓重年十九玉悦之私交信問許爲之妻重學於齊魯囑其父母使求婚王怒不與玉結氣死葬閶門外三年重歸問父母父母曰王怒玉結氣死已葬矣重哭泣哀慟具牲幣往弔玉於墓側形見謂重曰昔爾行之後令二親從玉相求謂必從願不圖別後遭命奈何玉左顧延頸而歌曰南山有鳥北山張羅鳥既高飛羅將奈何志願從君讒言孔多悲怨生疾没命黃墟命之不造寃如之何羽族之長名爲鳳凰一日失雄三年感傷雖有衆鳥不爲匹雙故見鄙志逢君輝光身遠心近何當暫忘</sub></span>  
<span style="margin-left: 1em">孔子衣冠墓在郡北六十里海隅鄉慧日院側<sub class="note-yuan">按前志孔氏二十二代孫潛僑寓于吳所瘞璧環簪珮及先聖衣冠處嘉靖間里人夜發孔墓土石堅不可鑿忽聞中隱隱雷轟遂膽落而遁先是墓地向不屬公占世從雷氏輸糧後貧不能支自負聖像至府愬之時賈郡侯惻然不安遂新其像送歸爲免地稅自後此地有麥生兩岐者</sub></span>  
<span style="margin-left: 1em">漢濮陽王墓在小蒸西四里<sub class="note-yuan">高大不生蟻相傳築墳時蒸土爲之地因以名</sub></span>  
<span style="margin-left: 1em">太常劉陽侯潘濬墓郡西北二十里<sub class="note-yuan">通志曰按吳志濬字承明武陵漢壽人弱冠從宋仲子受學爲郡功曹孫權殺關羽于荆上拜爲輔軍中郎將有功遷奮威將軍權即位封劉陽侯遷太常赤烏二年薨</sub></span>  
<span style="margin-left: 1em">笮融墓郡東北四十里<sub class="note-yuan">按吳志云融丹陽人初徐州牧陶謙使督廣陵運漕曹操攻謙徐土蕭條融將男女一百口馬三十疋走廣陵今北亭鄉有笮墓涇涇旁有高隴世稱爲笮墓</sub></span>  
<span style="margin-left: 1em">吳大將軍宛陵侯諸葛瑾墓在十五保塌石橋西<sub class="note-yuan">天啓壬戌鄉民陳廷宇樵于蒿棘之地以所擔杖插于地之隙處隨下入跫然有聲拾之不可得掘而下瞰黑窣茫茫燭以火中多窈曠遂發視有碑碣知爲諸葛瑾墓鄉民急碎之始末無從考中有古器酒鎗之屬壙內四懸而繫以棺事露張郡侯宗衡榜治配之按瑾字子瑜以赤烏四年卒遺命令素棺斂以時服事從省約又按史傳瑾之卒應在公安未知何以葬松郡</sub></span>  
<span style="margin-left: 1em">錢王墓在坐化菴西<sub class="note-yuan">初有一古塚傍水長松五六株相傳爲錢鏐王墓也後錢子孫售其地于范氏掘得一頭顱大如斗許遂夷爲逵道室廬矣按錢武肅王勑葬於安國縣錦衣鄉茅山之原今臨安是也此必錢氏子孫居華亭者誤以爲王墓耳</sub></span>  
<span style="margin-left: 1em">唐蔡侍郎墓在柘林方廣寺側<sub class="note-yuan">按方廣寺記云侍即捨宅爲寺寺有石幢題云唐咸通六年蔡贊造去父母塋九十步去壽塋一十六步三代皆當世文儒貞元唐德宗也咸通懿宗也貞元已有蔡侍郎祠不應咸通始爲壽塋意侍郎之子孫乎</sub></span>  
<span style="margin-left: 1em">顔氏墓在小蒸有古井皆顔魯公石刻梅樹一株蓋數</span>  
<span style="margin-left: 2em">百年物也</span>  
<span style="margin-left: 1em">曹王墳在小蒸其港即以曹墳名</span>  
<span style="margin-left: 1em">五代丞相潘葛妻李夫人墓在郡南四十里潘店北杏</span>  
<span style="margin-left: 2em">涇之左<sub class="note-yuan">有華表石柱石獸石碑碑旁鐫天漢四年葬五字</sub></span>  
<span style="margin-left: 1em">宋林妃墓<sub class="note-yuan">舊傳駱駝墩爲宋理宗林妃葬此即今青浦新江鄉</sub></span>  
<span style="margin-left: 1em">朱氏二夫人墓在莘莊南<sub class="note-yuan">土人稱爲小娘墳者被盜開壙見大鐵索懸一柩得銅鏡金玉有石供臺金罏瓶盒皆金錯成文墓碣題朱氏二夫人之墓</sub></span>  
<span style="margin-left: 1em">黃池縣令朱氏墓在孔宅西南天寶間葬</span>  
<span style="margin-left: 1em">隰州司倉支令問妻曹夫人墓在顧亭林南烽樓之側</span>  
<span style="margin-left: 2em">見法雲寺記</span>  
<span style="margin-left: 1em">丘府君墓在昌唐鄉今名仙山</span>  
<span style="margin-left: 1em">燕胄妻朱氏墓在華亭舊城西一里修竹鄉咸通八年</span>  
<span style="margin-left: 2em">葬宋于酒務得碑詳見古城下<sub class="note-yuan">續志曰嗟乎繇宋及今世代未遠而荒塚殘碑漫不可考叩之亭父落長尚有能道其詳者亦何止朱詹氏四人而已哉皇元應顯之兆華謁猶粲然故得而書之</sub></span>  
<span style="margin-left: 1em">天放老臣吳公墓在干山三高墓前時代無考</span>  
<span style="margin-left: 1em">吳執中墓<sub class="note-yuan">在四十一保濮陽王墓前顔氏居後有一古井其泉甘美故號甘泉中有執中墨刻遺跡故相傳以爲即執中墓</sub></span>  
<span style="margin-left: 3em">名墓辨證</span>  
<span style="margin-left: 1em">漢中大夫嚴助墓葬嚴山<sub class="note-yuan">按吳江志云嚴助葬縣東南百里至今呼其地爲嚴墓則嚴山特其隱居處</sub></span>  
<span style="margin-left: 1em">驃騎將軍顧榮墓<sub class="note-yuan">舊傳集賢鄉有顧公墩按吳地記云在吳縣東南二十里今長洲縣黃天蕩南俗訛稱顧邑墓墓西有祠題曰顧將軍廟謝應方詩云白髮吳儂說姓名將軍墓近闔閭城徵車入𨿅稱三俊割炙知人得再生江月似留揮扇影松風猶作鼓琴聲停舟一酹蘋花渚野鶴飛來躑躅鳴</sub></span>  
<span style="margin-left: 1em">東曹掾張翰墓在横山東五里</span>  
<span style="margin-left: 1em">左將軍袁崧墓在上海西長人鄉<sub class="note-yuan">按山松築滬瀆壘禦孫恩爲賊所害麾下士李祥突白刃收骸歸葬陸廣微吳地記云在横山二里當是蘇州之横山也顧從禮建祠記上海縣西北八十五里新江鄉崧宅里有土山突然高湧横泖之北者世傳爲晉袁崧將軍墓焉因名其里曰崧宅聞其上舊有祠宇頽廢後即章氏之業水鄉泥濘艱得黃土山日削而章之業浸微存糧積其上嘉靖中求售無主先大夫慨然嘆曰忠賢之蹟遂使一旦湮没耶乃捐二十緡錢購得之廣僅二十畝存其遺趾又爲牛羊所蹂踐荒蕪不毛而輸重稅者幾四十年隆慶三年白于監司請得伐石竪其上題曰晉左將軍吳郡太守袁公之墓按晉書列傳袁環字山甫陳郡陽夏人魏郎中令焕之曾孫初奉母避亂求爲江淮間縣拜呂令轉江都因南渡元帝以爲丹陽令歷治書御史廬江臨川太守王敦平爲鎮南將軍蘇峻之難與王舒共起義軍以功封長合鄉侯徵補散騎常侍徙大司農尋除國子祭酒于時喪亂欲振頽風上疏崇儒載興禮樂議論誠讜成帝從之國學之興自環始也卒追贈光禄大夫謚曰恭子喬嗣初拜佐著作郎輔國將軍廣陵相始喬與褚裒友善及康獻皇后臨朝喬與裒書曰皇太后踐祚將軍之于國外姓之太上皇也願將軍怡情無事親仗賢達論者以爲得體遷建武將軍江夏相時桓温謀伐蜀衆方以爲不可喬力勸温曰夫經略大事故非常情所具智者了於胸中然後舉無遺算耳及與温共破蜀進號龍驤將軍封湘西伯尋卒追贈益州刺史謚曰簡子方平嗣亦以軌素自立辟大司馬掾歷義興瑯邪太守卒子山松嗣山松少有才名博學有文章著後漢書百篇衿情秀遠善音樂舊歌有行路難曲辭頗疎質山松好之乃文其辭句婉其節制每因酣醉縱歌之聽者莫不流涕初羊曇善唱樂桓因能挽歌及山松行路難繼之時人謂之三絶時張湛好于齋前種松栢而山松每出游令左右作挽歌人謂湛屋前陳尸山松道上行殯山松歷顯位爲吳郡太守孫恩作亂山松守滬瀆城城陷被害繇是考之袁之在晉可爲世臣其墓之在新江鄉既以名其里曰崧宅又曰墓在長人鄉蓋其鄉之沙岡有築耶城遺跡尚存緣海築壘以禦恩此其一也故緣壘立築耶廟以祀將軍亦後人思慕將軍生多捍衛之功而又死于難故所在立廟祀之以致崇報禮也蘇志曰將軍被害部人海鹽李祥突白刃收骨歸葬墓在横山豈即横泖上之山耶志稱左將軍護國內史本傳亦缺并載碑陰以俟後之君子</sub></span>  
<span style="margin-left: 1em">陳黃門侍郎顧野王墓<sub class="note-yuan">舊傳亭林讀書堆按吳地記云在横山別隅平地不起墳紹興間碑石尚存也又蘇州志云在楞伽山下高啓詩南朝舊碑倒墓近樵蘇道應與讀書堆離離總秋草</sub></span>  
<span style="margin-left: 1em">唐陸宣公贄墓<sub class="note-yuan">按宣公卒於忠州其喪不還忠州圖經云墓在玉虛觀三十步藁葬又虛舟客話云贄墓在蘇州官河之西地名陸塘淳祐中嘗於墓傍得遺刻與所傳合則知忠州特虛塚耳</sub></span>  
<span style="margin-left: 1em">宋錢文惠公良臣墓在靜安寺東<sub class="note-yuan">舊傳盤龍塘普門寺側一古塚爲錢參政墓後爲里人張雕盜發有志石乃參政妹諱惠浄封孺人生一男五女破棺無穢氣顔色如生口脂面澤若初傅者冠服亦不朽腐得金銀飾器皿至有傳玩其繡履者</sub></span>  
<span style="margin-left: 1em">尚書右丞朱諤墓<sub class="note-yuan">按諤賜葬平江陽抱山傍有永慕菴即澄照寺其家所請功德院備載蘇志舊稱佘山普照院西爲諤墓非也乃其贈公所葬地耳</sub></span>  
<span style="margin-left: 1em">衞文節公涇墓<sub class="note-yuan">舊傳玉屏山之麓有衛狀元墓按崑山志云墓在縣東南石浦鎮又按祠堂記云葬湖州之歸安與葉文莊衛族考合蓋歸安亦有一玉屏山也</sub></span>
