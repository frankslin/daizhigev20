## 崇祯松江府志卷之四十八　塜墓

<span style="margin-left: 3em">冢墓</span>  
<span style="margin-left: 1em">墓者暮也长夜不复旦矣古今墓碑累累非贤子孙世</span>  
<span style="margin-left: 1em">守之不得迹而迹之村竖田翁之口孰若反而求诸志</span>  
<span style="margin-left: 1em">中之志犹可考也隋杨俊曰人生求名一卷史书足矣</span>  
<span style="margin-left: 1em">何用碑为若不能保家徒与人作镇石耳此冢墓所以</span>  
<span style="margin-left: 1em">记之志也</span>  
<span style="margin-left: 3em">古墓存疑</span>  
<span style="margin-left: 1em">三女冈在华亭县东南八十里<sub class="note-yuan">旧图经云吴王葬三女于此宋唐询诸公多题咏详古迹又吴越春秋录异传有吴王葬女阊门外事吴王夫差小女曰玉年十八岁童子韩重年十九玉悦之私交信问许为之妻重学于齐鲁嘱其父母使求婚王怒不与玉结气死葬阊门外三年重归问父母父母曰王怒玉结气死已葬矣重哭泣哀恸具牲币往吊玉于墓侧形见谓重曰昔尔行之后令二亲从玉相求谓必从愿不图别后遭命奈何玉左顾延颈而歌曰南山有鸟北山张罗鸟既高飞罗将奈何志愿从君谗言孔多悲怨生疾没命黄墟命之不造寃如之何羽族之长名为凤凰一日失雄三年感伤虽有众鸟不为匹双故见鄙志逢君辉光身远心近何当暂忘</sub></span>  
<span style="margin-left: 1em">孔子衣冠墓在郡北六十里海隅乡慧日院侧<sub class="note-yuan">按前志孔氏二十二代孙潜侨寓于吴所瘗璧环簪珮及先圣衣冠处嘉靖间里人夜发孔墓土石坚不可凿忽闻中隐隐雷轰遂胆落而遁先是墓地向不属公占世从雷氏输粮后贫不能支自负圣像至府愬之时贾郡侯恻然不安遂新其像送归为免地税自后此地有麦生两岐者</sub></span>  
<span style="margin-left: 1em">汉濮阳王墓在小蒸西四里<sub class="note-yuan">高大不生蚁相传筑坟时蒸土为之地因以名</sub></span>  
<span style="margin-left: 1em">太常刘阳侯潘濬墓郡西北二十里<sub class="note-yuan">通志曰按吴志濬字承明武陵汉寿人弱冠从宋仲子受学为郡功曹孙权杀关羽于荆上拜为辅军中郎将有功迁奋威将军权即位封刘阳侯迁太常赤乌二年薨</sub></span>  
<span style="margin-left: 1em">笮融墓郡东北四十里<sub class="note-yuan">按吴志云融丹阳人初徐州牧陶谦使督广陵运漕曹操攻谦徐土萧条融将男女一百口马三十疋走广陵今北亭乡有笮墓泾泾旁有高陇世称为笮墓</sub></span>  
<span style="margin-left: 1em">吴大将军宛陵侯诸葛瑾墓在十五保塌石桥西<sub class="note-yuan">天启壬戌乡民陈廷宇樵于蒿棘之地以所担杖插于地之隙处随下入跫然有声拾之不可得掘而下瞰黑窣茫茫烛以火中多窈旷遂发视有碑碣知为诸葛瑾墓乡民急碎之始末无从考中有古器酒鎗之属圹内四悬而系以棺事露张郡侯宗衡榜治配之按瑾字子瑜以赤乌四年卒遗命令素棺敛以时服事从省约又按史传瑾之卒应在公安未知何以葬松郡</sub></span>  
<span style="margin-left: 1em">钱王墓在坐化庵西<sub class="note-yuan">初有一古冢傍水长松五六株相传为钱镠王墓也后钱子孙售其地于范氏掘得一头颅大如斗许遂夷为逵道室庐矣按钱武肃王勑葬于安国县锦衣乡茅山之原今临安是也此必钱氏子孙居华亭者误以为王墓耳</sub></span>  
<span style="margin-left: 1em">唐蔡侍郎墓在柘林方广寺侧<sub class="note-yuan">按方广寺记云侍即舍宅为寺寺有石幢题云唐咸通六年蔡赞造去父母茔九十步去寿茔一十六步三代皆当世文儒贞元唐德宗也咸通懿宗也贞元已有蔡侍郎祠不应咸通始为寿茔意侍郎之子孙乎</sub></span>  
<span style="margin-left: 1em">颜氏墓在小蒸有古井皆颜鲁公石刻梅树一株盖数</span>  
<span style="margin-left: 2em">百年物也</span>  
<span style="margin-left: 1em">曹王坟在小蒸其港即以曹坟名</span>  
<span style="margin-left: 1em">五代丞相潘葛妻李夫人墓在郡南四十里潘店北杏</span>  
<span style="margin-left: 2em">泾之左<sub class="note-yuan">有华表石柱石兽石碑碑旁镌天汉四年葬五字</sub></span>  
<span style="margin-left: 1em">宋林妃墓<sub class="note-yuan">旧传骆驼墩为宋理宗林妃葬此即今青浦新江乡</sub></span>  
<span style="margin-left: 1em">朱氏二夫人墓在莘庄南<sub class="note-yuan">土人称为小娘坟者被盗开圹见大铁索悬一柩得铜镜金玉有石供台金罏瓶盒皆金错成文墓碣题朱氏二夫人之墓</sub></span>  
<span style="margin-left: 1em">黄池县令朱氏墓在孔宅西南天宝间葬</span>  
<span style="margin-left: 1em">隰州司仓支令问妻曹夫人墓在顾亭林南烽楼之侧</span>  
<span style="margin-left: 2em">见法云寺记</span>  
<span style="margin-left: 1em">丘府君墓在昌唐乡今名仙山</span>  
<span style="margin-left: 1em">燕胄妻朱氏墓在华亭旧城西一里修竹乡咸通八年</span>  
<span style="margin-left: 2em">葬宋于酒务得碑详见古城下<sub class="note-yuan">续志曰嗟乎繇宋及今世代未远而荒冢残碑漫不可考叩之亭父落长尚有能道其详者亦何止朱詹氏四人而已哉皇元应显之兆华谒犹粲然故得而书之</sub></span>  
<span style="margin-left: 1em">天放老臣吴公墓在干山三高墓前时代无考</span>  
<span style="margin-left: 1em">吴执中墓<sub class="note-yuan">在四十一保濮阳王墓前颜氏居后有一古井其泉甘美故号甘泉中有执中墨刻遗迹故相传以为即执中墓</sub></span>  
<span style="margin-left: 3em">名墓辨证</span>  
<span style="margin-left: 1em">汉中大夫严助墓葬严山<sub class="note-yuan">按吴江志云严助葬县东南百里至今呼其地为严墓则严山特其隐居处</sub></span>  
<span style="margin-left: 1em">骠骑将军顾荣墓<sub class="note-yuan">旧传集贤乡有顾公墩按吴地记云在吴县东南二十里今长洲县黄天荡南俗讹称顾邑墓墓西有祠题曰顾将军庙谢应方诗云白发吴侬说姓名将军墓近阖闾城征车入𨿅称三俊割炙知人得再生江月似留挥扇影松风犹作鼓琴声停舟一酹苹花渚野鹤飞来踯躅鸣</sub></span>  
<span style="margin-left: 1em">东曹掾张翰墓在横山东五里</span>  
<span style="margin-left: 1em">左将军袁崧墓在上海西长人乡<sub class="note-yuan">按山松筑沪渎垒御孙恩为贼所害麾下士李祥突白刃收骸归葬陆广微吴地记云在横山二里当是苏州之横山也顾从礼建祠记上海县西北八十五里新江乡崧宅里有土山突然高涌横泖之北者世传为晋袁崧将军墓焉因名其里曰崧宅闻其上旧有祠宇颓废后即章氏之业水乡泥泞艰得黄土山日削而章之业浸微存粮积其上嘉靖中求售无主先大夫慨然叹曰忠贤之迹遂使一旦湮没耶乃捐二十缗钱购得之广仅二十亩存其遗趾又为牛羊所蹂践荒芜不毛而输重税者几四十年隆庆三年白于监司请得伐石竖其上题曰晋左将军吴郡太守袁公之墓按晋书列传袁环字山甫陈郡阳夏人魏郎中令焕之曾孙初奉母避乱求为江淮间县拜吕令转江都因南渡元帝以为丹阳令历治书御史庐江临川太守王敦平为镇南将军苏峻之难与王舒共起义军以功封长合乡侯征补散骑常侍徙大司农寻除国子祭酒于时丧乱欲振颓风上疏崇儒载兴礼乐议论诚谠成帝从之国学之兴自环始也卒追赠光禄大夫谥曰恭子乔嗣初拜佐著作郎辅国将军广陵相始乔与褚裒友善及康献皇后临朝乔与裒书曰皇太后践祚将军之于国外姓之太上皇也愿将军怡情无事亲仗贤达论者以为得体迁建武将军江夏相时桓温谋伐蜀众方以为不可乔力劝温曰夫经略大事故非常情所具智者了于胸中然后举无遗算耳及与温共破蜀进号龙骧将军封湘西伯寻卒追赠益州刺史谥曰简子方平嗣亦以轨素自立辟大司马掾历义兴瑯邪太守卒子山松嗣山松少有才名博学有文章著后汉书百篇衿情秀远善音乐旧歌有行路难曲辞颇疎质山松好之乃文其辞句婉其节制每因酣醉纵歌之听者莫不流涕初羊昙善唱乐桓因能挽歌及山松行路难继之时人谓之三绝时张湛好于斋前种松栢而山松每出游令左右作挽歌人谓湛屋前陈尸山松道上行殡山松历显位为吴郡太守孙恩作乱山松守沪渎城城陷被害繇是考之袁之在晋可为世臣其墓之在新江乡既以名其里曰崧宅又曰墓在长人乡盖其乡之沙冈有筑耶城遗迹尚存缘海筑垒以御恩此其一也故缘垒立筑耶庙以祀将军亦后人思慕将军生多捍卫之功而又死于难故所在立庙祀之以致崇报礼也苏志曰将军被害部人海盐李祥突白刃收骨归葬墓在横山岂即横泖上之山耶志称左将军护国内史本传亦缺并载碑阴以俟后之君子</sub></span>  
<span style="margin-left: 1em">陈黄门侍郎顾野王墓<sub class="note-yuan">旧传亭林读书堆按吴地记云在横山别隅平地不起坟绍兴间碑石尚存也又苏州志云在楞伽山下高启诗南朝旧碑倒墓近樵苏道应与读书堆离离总秋草</sub></span>  
<span style="margin-left: 1em">唐陆宣公贽墓<sub class="note-yuan">按宣公卒于忠州其丧不还忠州图经云墓在玉虚观三十步藁葬又虚舟客话云贽墓在苏州官河之西地名陆塘淳祐中尝于墓傍得遗刻与所传合则知忠州特虚冢耳</sub></span>  
<span style="margin-left: 1em">宋钱文惠公良臣墓在静安寺东<sub class="note-yuan">旧传盘龙塘普门寺侧一古冢为钱参政墓后为里人张雕盗发有志石乃参政妹讳惠浄封孺人生一男五女破棺无秽气颜色如生口脂面泽若初傅者冠服亦不朽腐得金银饰器皿至有传玩其绣履者</sub></span>  
<span style="margin-left: 1em">尚书右丞朱谔墓<sub class="note-yuan">按谔赐葬平江阳抱山傍有永慕庵即澄照寺其家所请功德院备载苏志旧称佘山普照院西为谔墓非也乃其赠公所葬地耳</sub></span>  
<span style="margin-left: 1em">衞文节公泾墓<sub class="note-yuan">旧传玉屏山之麓有卫状元墓按昆山志云墓在县东南石浦镇又按祠堂记云葬湖州之归安与叶文庄卫族考合盖归安亦有一玉屏山也</sub></span>  
<span style="margin-left: 1em">都官陈舜俞墓<sub class="note-yuan">在白牛村按舜俞举制科第一熙宁中以屯田员外郎知山阴诏代还试馆职舜俞力辞后以不奉青苗法上疏恳切责监南康军盐酒税五年卒舜俞常弃官居秀州之白牛村已而复出贬死子瞻为文哭之湖志云墓在苏湾</sub></span>
