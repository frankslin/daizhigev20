## 崇祯松江府志卷之十四　盐政

<span style="margin-left: 3em">盐法</span>  
<span style="margin-left: 1em">洪范五行一曰水润下作咸此管仲煮海富齐之法也</span>  
<span style="margin-left: 1em">吾朝召商种屯实粟于塞下而取偿于盐引则富而兼</span>  
<span style="margin-left: 1em">之以强矣自叶淇倡折色而盐政坏边与腹商与丁皆</span>  
<span style="margin-left: 1em">贫惫莫能支而姑为吾松计恤穷丁清占产均摊偏重</span>  
<span style="margin-left: 1em">偏轻之额而庶乎少救于万一也志盐法</span>  
<span style="margin-left: 1em">盐之旧额</span>  
<span style="margin-left: 1em">宋乾淳间华亭五场祖额一十二万八千袋有奇其后</span>  
<span style="margin-left: 2em">岁办止七万袋<sub class="note-yuan">宋盐五十斤为一石六石为一袋输钞钱十八千</sub></span>  
<span style="margin-left: 1em">景定元年实办盐八万三千袋有奇是岁革罢华亭茶</span>  
<span style="margin-left: 2em">盐分司权买纳官黄震尽蠲逋欠及散还亭户盐本</span>  
<span style="margin-left: 2em">钱并请罢分司</span>  
<span style="margin-left: 1em">元初盐课无额至元十三年两浙通办四万四千余引</span>  
<span style="margin-left: 2em">引价五两十五年始立额一十五万九千余引引益</span>  
<span style="margin-left: 2em">九两元贞以后岁有增益至顺元年办及四十八万</span>  
<span style="margin-left: 2em">引引价三定后至元至正间凡再减盐额两浙通办</span>  
<span style="margin-left: 2em">二十七万引府境五场为额十五万六千余引<sub class="note-yuan">比宋原额增二万八千</sub>实办七万四千九百一十八引有奇<sub class="note-yuan">比宋景定实办减八千八十引有奇</sub></span>  
<span style="margin-left: 2em">下沙场三万三千四百一十五引七十九斤</span>  
<span style="margin-left: 2em">浦东场一万六千六百六十四引一百九十斤</span>  
<span style="margin-left: 2em">横浦场一万二百六引一百八斤</span>  
<span style="margin-left: 2em">青村场一万七十七引二百九十五斤</span>  
<span style="margin-left: 2em">袁部场四千五百五十四引二百七十四斤</span>  
<span style="margin-left: 1em">国朝设两浙都转运盐使司于杭州设松江分司于府</span>  
<span style="margin-left: 2em">境下沙镇以同知或副使一员莅之统新旧八场<sub class="note-yuan">比元制减一增四</sub>二十七团灶户分给柴荡工本钞督办盐课</span>  
<span style="margin-left: 2em">其灶户有滨海水乡其后钞法变更柴价又为总催</span>  
<span style="margin-left: 2em">尅取滨海盐丁日就贫困正统六年巡抚侍郎周忱</span>  
<span style="margin-left: 2em">乃以水乡灶户应纳粮六万余石尽留本府支用节</span>  
<span style="margin-left: 2em">其运耗置赡盐仓分贮各场总三万六千余石用以</span>  
<span style="margin-left: 2em">赈赡盐丁及补逃亡阙课所贴柴价亦贮之各仓官</span>  
<span style="margin-left: 2em">为支给按崔富盐政一览赡盐仓已不见登载而水</span>  
<span style="margin-left: 2em">乡柴价改征为米其后诸人屡有更张具列于后</span>  
<span style="margin-left: 2em">各场灶户共二万七千八百五十三丁柴薪荡五千</span>  
<span style="margin-left: 2em">七十六顷八亩有奇岁给工本钞一万五千三百六</span>  
<span style="margin-left: 2em">十一定一贯九十一文有奇额办盐七万六千八百</span>  
<span style="margin-left: 2em">二引一百三十七斤十一两每引重四百斤<sub class="note-yuan">比元实办数增一千八百八十四引有奇</sub>其盐分二等盐司按岁征办商人执引</span>  
<span style="margin-left: 2em">照支依次递给者谓之常股增直中纳不依资次引</span>  
<span style="margin-left: 2em">到即支者谓之存积<sub class="note-yuan">正统以来常股四分存积六分成化间御史李瑢改常股六分存积四分</sub></span>  
<span style="margin-left: 2em">灶户田地连接民产易为隐蔽滩荡并无塍岸难以</span>  
<span style="margin-left: 2em">丈量册籍顷亩俱是随意捏写以应官司督责若论</span>  
<span style="margin-left: 2em">原有土地十才开报一二自前元时附近大家往往</span>  
<span style="margin-left: 2em">据为私业至于　国朝旧习犹存富家占地万亩不</span>  
<span style="margin-left: 2em">纳粒米而莫能究诘贫弱不取寸草岁输重课而无</span>  
<span style="margin-left: 2em">所控诉由是灶户分为滨海水乡二等</span>

<span style="margin-left: 2em">千八百六十六引三百九十三斤六两三钱</span>

<span style="margin-left: 1em">成化间御史林诚　奏定折征盐课例每三分为率以</span>  
<span style="margin-left: 2em">二分存场给客余一分照商人折支例<sub class="note-yuan">时以无盐给客每引折与银三钱</sub>征银入官送运司转解</span>  
<span style="margin-left: 1em">二十二年知府樊莹议以水乡折盐米均入该县粮耗</span>  
<span style="margin-left: 2em">项下带征白银径送运司交纳原拨草荡价仍与各</span>  
<span style="margin-left: 2em">场征解其纳米灶户还入民伍当差此时若以旬日</span>  
<span style="margin-left: 2em">核实田土计丁均扣收其租利完纳课银当余大半</span>  
<span style="margin-left: 2em">而为沿海富室取　仅扣荡地若干亩每亩槩征草</span>  
<span style="margin-left: 2em">价银若干谓之水乡荡价亏银则加本县秋粮耗米</span>  
<span style="margin-left: 2em">包补谓之水乡盐价</span>  
<span style="margin-left: 1em">弘治十一年御史蓝章复佥水乡户补滨海灶丁后知</span>  
<span style="margin-left: 2em">府刘琬欲并其盐课于秋粮带征不果<sub class="note-yuan">按水乡折盐米前既于秋粮带征则不当重役又于秋粮带征是重征也</sub></span>  
<span style="margin-left: 2em">按原扣水乡丁荡俱在县境纳粮民田之东各塲办</span>  
<span style="margin-left: 2em">课灶地之西外不近海内不傍江岁种花稻豆麦无</span>  
<span style="margin-left: 2em">异负郭膏腴府县盐司两不编差东海士民视为仙</span>  
<span style="margin-left: 2em">境征价之后又不曾坼裂为河陷没为湖正德三年</span>  
<span style="margin-left: 2em">沿海富家忽言水乡荡价内白涂银无征受累赔纳</span>  
<span style="margin-left: 2em">竟为此辈诳说割民间已入黄册科钞分补此外不</span>  
<span style="margin-left: 2em">敷再加县粮耗米包补谓之白涂荡价自是水乡丁</span>  
<span style="margin-left: 2em">荡止征银若干而该县士民岁代各场补纳盐课矣</span>  
<span style="margin-left: 1em">隆庆三年丈田均粮富家将水乡荡或报为科粮民田</span>  
<span style="margin-left: 2em">以绝灶户之告分或指为滨海丁荡以拒县人之丈</span>  
<span style="margin-left: 2em">量俱该场奸人受贿而除富家之额也</span>  
<span style="margin-left: 1em">盐之旧仓</span>  
<span style="margin-left: 1em">西盐仓在旧西湖东宋乾道八年并入北仓置浙西茶</span>  
<span style="margin-left: 2em">盐分司元为浙西盐使司元贞初罢　张之翰浙西</span>  
<span style="margin-left: 2em">盐仓记　自煮海鬻䇲盐利不容废置场籍户盐禁</span>  
<span style="margin-left: 2em">不容弛盖有产则有积入则有出亦变通之权便益</span>  
<span style="margin-left: 2em">之法也故仓不得不设松江枕江负海厥土广潟牢</span>  
<span style="margin-left: 2em">盆之赢实百他郡后升为府仍司浙西盐鹾并浙江</span>  
<span style="margin-left: 2em">东钱清西兴及江北六场隶焉旧有仓归附以来废</span>  
<span style="margin-left: 2em">为瓦砾昭信校尉浙西盐使阿散前任松江府判官</span>  
<span style="margin-left: 2em">有明敏称阅十年来莅是始至之日首以仓为急务</span>
