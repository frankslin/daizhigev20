## 崇禎松江府志卷之十四　鹽政

<span style="margin-left: 3em">鹽法</span>  
<span style="margin-left: 1em">洪範五行一曰水潤下作鹹此管仲煮海富齊之法也</span>  
<span style="margin-left: 1em">吾朝召商種屯實粟于塞下而取償于鹽引則富而兼</span>  
<span style="margin-left: 1em">之以强矣自葉淇倡折色而鹽政壞邊與腹商與丁皆</span>  
<span style="margin-left: 1em">貧憊莫能支而姑爲吾松計恤窮丁清占産均攤偏重</span>  
<span style="margin-left: 1em">偏輕之額而庶乎少救於萬一也志鹽法</span>  
<span style="margin-left: 1em">鹽之舊額</span>  
<span style="margin-left: 1em">宋乾淳間華亭五場祖額一十二萬八千袋有奇其後</span>  
<span style="margin-left: 2em">歲辦止七萬袋<sub class="note-yuan">宋鹽五十斤爲一石六石爲一袋輸鈔錢十八千</sub></span>  
<span style="margin-left: 1em">景定元年實辦鹽八萬三千袋有奇是歲革罷華亭茶</span>  
<span style="margin-left: 2em">鹽分司權買納官黃震盡蠲逋欠及散還亭户鹽本</span>  
<span style="margin-left: 2em">錢并請罷分司</span>  
<span style="margin-left: 1em">元初鹽課無額至元十三年兩浙通辦四萬四千餘引</span>  
<span style="margin-left: 2em">引價五兩十五年始立額一十五萬九千餘引引益</span>  
<span style="margin-left: 2em">九兩元貞以後歲有增益至順元年辦及四十八萬</span>  
<span style="margin-left: 2em">引引價三定後至元至正間凡再減鹽額兩浙通辦</span>  
<span style="margin-left: 2em">二十七萬引府境五場爲額十五萬六千餘引<sub class="note-yuan">比宋原額增二萬八千</sub>實辦七萬四千九百一十八引有奇<sub class="note-yuan">比宋景定實辦減八千八十引有奇</sub></span>  
<span style="margin-left: 2em">下沙場三萬三千四百一十五引七十九斤</span>  
<span style="margin-left: 2em">浦東場一萬六千六百六十四引一百九十斤</span>  
<span style="margin-left: 2em">横浦場一萬二百六引一百八斤</span>  
<span style="margin-left: 2em">青村場一萬七十七引二百九十五斤</span>  
<span style="margin-left: 2em">袁部場四千五百五十四引二百七十四斤</span>  
<span style="margin-left: 1em">國朝設兩浙都轉運鹽使司於杭州設松江分司於府</span>  
<span style="margin-left: 2em">境下沙鎮以同知或副使一員蒞之統新舊八場<sub class="note-yuan">比元制減一增四</sub>二十七團竈户分給柴蕩工本鈔督辦鹽課</span>  
<span style="margin-left: 2em">其竈户有濱海水鄉其後鈔法變更柴價又爲總催</span>  
<span style="margin-left: 2em">尅取濱海鹽丁日就貧困正統六年巡撫侍郎周忱</span>  
<span style="margin-left: 2em">乃以水鄉竈户應納糧六萬餘石盡留本府支用節</span>  
<span style="margin-left: 2em">其運耗置贍鹽倉分貯各場總三萬六千餘石用以</span>  
<span style="margin-left: 2em">賑贍鹽丁及補逃亡闕課所貼柴價亦貯之各倉官</span>  
<span style="margin-left: 2em">爲支給按崔富鹽政一覽贍鹽倉已不見登載而水</span>  
<span style="margin-left: 2em">鄉柴價改徵爲米其後諸人屢有更張具列于後</span>  
<span style="margin-left: 2em">各場竈户共二萬七千八百五十三丁柴薪蕩五千</span>  
<span style="margin-left: 2em">七十六頃八畝有奇歲給工本鈔一萬五千三百六</span>  
<span style="margin-left: 2em">十一定一貫九十一文有奇額辦鹽七萬六千八百</span>  
<span style="margin-left: 2em">二引一百三十七斤十一兩每引重四百斤<sub class="note-yuan">比元實辦數增一千八百八十四引有奇</sub>其鹽分二等鹽司按歲徵辦商人執引</span>  
<span style="margin-left: 2em">照支依次遞給者謂之常股增直中納不依資次引</span>  
<span style="margin-left: 2em">到即支者謂之存積<sub class="note-yuan">正統以來常股四分存積六分成化間御史李瑢改常股六分存積四分</sub></span>  
<span style="margin-left: 2em">竈户田地連接民産易爲隱蔽灘蕩並無塍岸難以</span>  
<span style="margin-left: 2em">丈量册籍頃畝俱是隨意捏寫以應官司督責若論</span>  
<span style="margin-left: 2em">原有土地十纔開報一二自前元時附近大家往往</span>  
<span style="margin-left: 2em">據爲私業至於　國朝舊習猶存富家占地萬畝不</span>  
<span style="margin-left: 2em">納粒米而莫能究詰貧弱不取寸草歲輸重課而無</span>  
<span style="margin-left: 2em">所控訴由是竈户分爲濱海水鄉二等</span>

<span style="margin-left: 2em">千八百六十六引三百九十三斤六兩三錢</span>  
<span style="margin-left: 2em">水鄉竈户九千九百九十九丁該辦鹽二萬七千九</span>  
<span style="margin-left: 2em">百三十五引一百四十四斤四兩七錢共折納米四</span>  
<span style="margin-left: 2em">萬三千四百一十石分貼濱海竈丁代爲辦課<sub class="note-yuan">近歲催日刻取有一丁出米八石至十石或出銀五兩至六兩者</sub></span>

<span style="margin-left: 1em">成化間御史林誠　奏定折徵鹽課例每三分爲率以</span>  
<span style="margin-left: 2em">二分存場給客餘一分照商人折支例<sub class="note-yuan">時以無鹽給客每引折與銀三錢</sub>徵銀入官送運司轉解</span>  
<span style="margin-left: 1em">二十二年知府樊瑩議以水鄉折鹽米均入該縣糧耗</span>  
<span style="margin-left: 2em">項下帶徵白銀徑送運司交納原撥草蕩價仍與各</span>  
<span style="margin-left: 2em">場徵解其納米竈户還入民伍當差此時若以旬日</span>  
<span style="margin-left: 2em">覈實田土計丁均扣收其租利完納課銀當餘大半</span>  
<span style="margin-left: 2em">而爲沿海富室取　僅扣蕩地若干畝每畝槩徵草</span>  
<span style="margin-left: 2em">價銀若干謂之水鄉蕩價虧銀則加本縣秋糧耗米</span>  
<span style="margin-left: 2em">包補謂之水鄉鹽價</span>  
<span style="margin-left: 1em">弘治十一年御史藍章復僉水鄉户補濱海灶丁後知</span>  
<span style="margin-left: 2em">府劉琬欲併其鹽課於秋糧帶徵不果<sub class="note-yuan">按水鄉折鹽米前既於秋糧帶徵則不當重役又於秋糧帶徵是重徵也</sub></span>  
<span style="margin-left: 2em">按原扣水鄉丁蕩俱在縣境納糧民田之東各塲辦</span>  
<span style="margin-left: 2em">課竈地之西外不近海內不傍江歲種花稻豆麥無</span>  
<span style="margin-left: 2em">異負郭膏腴府縣鹽司兩不編差東海士民視爲仙</span>  
<span style="margin-left: 2em">境徵價之後又不曾坼裂爲河陷没爲湖正德三年</span>  
<span style="margin-left: 2em">沿海富家忽言水鄉蕩價內白塗銀無徵受累賠納</span>  
<span style="margin-left: 2em">竟爲此輩誑說割民間已入黃册科鈔分補此外不</span>

<span style="margin-left: 2em">蕩止徵銀若干而該縣士民歲代各場補納鹽課矣</span>

<span style="margin-left: 2em">量俱該場姦人受賄而除富家之額也</span>  
<span style="margin-left: 1em">鹽之舊倉</span>  
<span style="margin-left: 1em">西鹽倉在舊西湖東宋乾道八年併入北倉置浙西茶</span>  
<span style="margin-left: 2em">鹽分司元爲浙西鹽使司元貞初罷　張之翰浙西</span>  
<span style="margin-left: 2em">鹽倉記　自煮海鬻筴鹽利不容廢置場籍户鹽禁</span>  
<span style="margin-left: 2em">不容弛蓋有産則有積入則有出亦變通之權便益</span>  
<span style="margin-left: 2em">之法也故倉不得不設松江枕江負海厥土廣潟牢</span>  
<span style="margin-left: 2em">盆之贏實百他郡後陞爲府仍司浙西鹽鹺併浙江</span>
