## 崇祯松江府志卷之四十五　人物十（方外）

<span style="margin-left: 3em">方外一</span>  
<span style="margin-left: 1em">世网如八阵图逗入辄不能出波波劫劫宁知蕊宫葱</span>  
<span style="margin-left: 1em">岭别有道人在乎吾松向称寂寞之滨往来云水代多</span>  
<span style="margin-left: 1em">灵迹若神与之游际极诣会不啻嚼万年冰也道在世</span>  
<span style="margin-left: 1em">外夫岂欺我志二氏</span>  
<span style="margin-left: 1em">康僧会其先康居国人世居天竺会年十余岁二亲亡</span>  
<span style="margin-left: 1em">服毕出家以吴赤乌十年初达建业会曰如来迁迹忽</span>  
<span style="margin-left: 1em">逾千载遗骨舍利神曜无方昔阿育王起塔及八万四</span>  
<span style="margin-left: 1em">千夫塔寺之兴以表遗化也权以为夸诞乃谓其属曰</span>  
<span style="margin-left: 1em">法之兴废在此一举乃共洁斋静室以钢瓶加几烧香</span>  
<span style="margin-left: 1em">礼请七日期毕寂然无应求申二七日亦复如之权曰</span>  
<span style="margin-left: 1em">此欺诳将欲加罪会更请三七日权又特听会誓曰法</span>  
<span style="margin-left: 1em">云应降而吾等无感何假王宪当以死为期耳三七日</span>  
<span style="margin-left: 1em">暮犹无所见莫不震惧既入五更忽闻瓶中铿然有声</span>  
<span style="margin-left: 1em">会自往视果获舍利权大惊起曰希有之瑞也乃置舍</span>  
<span style="margin-left: 1em">利于铁砧磓上使力者击之砧磓俱陷舍利无损权大</span>  
<span style="margin-left: 1em">嗟伏即为建塔至繇拳吴娄间留像金粟寺时或放光</span>  
<span style="margin-left: 1em">终于晋武太康元年</span>  
<span style="margin-left: 2em"><sub class="note-yuan">乐郊私语云金粟寺有康僧会身像余于至正癸巳始得顶礼明年春翻阅轮藏逾旬偶于晡时作礼像前见像眉间有光须臾若白线袅袅而出盘绕华盖而上余遂鸣钟集众称佛名号礼拜赞颂至暮复从眉间摄入众叹希有</sub></span>  
<span style="margin-left: 1em">文喜御儿人姓朱氏梁开成间尝之五台山礼文殊大</span>  
<span style="margin-left: 1em">士后参仰禅师命为典座一日见文殊跨狮子缘鼎侧</span>  
<span style="margin-left: 1em">文喜诃曰文殊自文殊文喜自文喜遂掌之文殊涌空</span>  
<span style="margin-left: 1em">曰苦瓠连根苦甜瓜彻帝甜修行三大劫都被老僧嫌</span>  
<span style="margin-left: 1em">咸通中筑室千顷山居之</span>  
<span style="margin-left: 1em">船子和尚名德诚节操高邈度量不群自印心于药山</span>  
<span style="margin-left: 1em">与道吾云岩为同道交洎离药山乃谓二同志曰公等</span>  
<span style="margin-left: 1em">应各据一方建立药山宗旨予率性踈野惟好山水乐</span>  
<span style="margin-left: 1em">情自遣无所能也他后知我所止之处若遇伶俐座主</span>  
<span style="margin-left: 1em">指一人来或堪雕琢将授生平所得以报先师之恩遂</span>  
<span style="margin-left: 1em">分擕至秀州华亭泛一小舟随缘度日以接四方往来</span>  
<span style="margin-left: 1em">时人莫知其高蹈因号船子和尚一日泊舟岸边闲坐</span>  
<span style="margin-left: 1em">有官人问如何是和尚日用事师竖桡子曰会么官人</span>  
<span style="margin-left: 1em">曰不会师曰棹拨清波金鳞罕遇师有偈数篇载水志</span>  
<span style="margin-left: 1em">法忍寺道吾后到京口遇夹山上堂僧问如何是法身</span>  
<span style="margin-left: 1em">山曰法身无相曰如何是法眼山曰法眼无瑕道吾不</span>  
<span style="margin-left: 1em">觉失笑山便下座请问道吾某甲适来祗对这僧话必</span>  
<span style="margin-left: 1em">有不是致令上座失笑望不吝慈悲吾曰和尚一等是</span>  
<span style="margin-left: 1em">出世未有师在山曰某甲甚处不是望为指示吾曰某</span>  
<span style="margin-left: 1em">甲终不说请和尚到华亭船子处去山曰此人如何吾</span>  
<span style="margin-left: 1em">曰此人上无片瓦下无立锥和尚若去须易服而往山</span>  
<span style="margin-left: 1em">乃散众束装直造华亭船子才见便问大德住甚么寺</span>  
<span style="margin-left: 1em">山曰寺即不住住即不似师曰不似似个甚么山曰不</span>  
<span style="margin-left: 1em">是目前法师曰甚处学得来山曰非耳目之所到师曰</span>  
<span style="margin-left: 1em">一句合头语万劫系驴橛师又问垂丝千尺意在深潭</span>  
<span style="margin-left: 1em">离钩三寸子何不道山拟开口被师一桡打落水中山</span>  
<span style="margin-left: 1em">才上船师又曰道道山拟开口师又打山豁然大悟乃</span>  
<span style="margin-left: 1em">点头三下师曰竿头丝线从君弄不犯清波意自殊山</span>  
<span style="margin-left: 1em">遂问抛纶掷钓师意如何师曰丝悬渌水浮定有无之</span>  
<span style="margin-left: 1em">意山曰语带玄而无路舌头谈而不谈师曰钓尽江波</span>  
<span style="margin-left: 1em">金鳞始遇山乃掩耳师曰如是如是遂嘱曰汝向去直</span>  
<span style="margin-left: 1em">须藏身处没踪迹没踪迹处莫藏身吾三十年在药山</span>  
<span style="margin-left: 1em">祇明斯事汝今已得他后莫住城隍聚落但向深山里</span>  
<span style="margin-left: 1em">镢头边觅取一个半个接续无令断绝山乃辞行频频</span>  
<span style="margin-left: 1em">回顾师遂唤阇黎山乃回首师竖起桡子曰汝将谓别</span>  
<span style="margin-left: 1em">有乃覆船入水而逝</span>  
<span style="margin-left: 1em">霄韵驻锡松江飘然尘外间以词翰游戏三昧刘禹锡</span>  
<span style="margin-left: 1em">赠其游天台诗云曲江僧向松江见又过天台看石桥</span>  
<span style="margin-left: 1em">鹤恋故巢云恋岫比君犹是不逍遥</span>  
<span style="margin-left: 1em">聪道人姓仰氏名德聪初受戒于梵天寺参请诸方密</span>  
<span style="margin-left: 1em">契心印太平兴国三年结庐佘山之东峰三虎为之卫</span>  
<span style="margin-left: 1em">名大青小青有禅者造之见挂一书于梁间问之曰此</span>  
<span style="margin-left: 1em">佛经也问尝读否曰如人看家书既知之矣何再读为</span>  
<span style="margin-left: 1em">尝曰古人贵行吾何言哉自是问都不答天禧元年七</span>  
<span style="margin-left: 1em">月趺坐而化阅月貌如生即建塔于东峰之麓山民有</span>  
<span style="margin-left: 1em">卜葬于侧者其家夜闻虎啸亟徙去释灵鉴铭志载丘</span>  
<span style="margin-left: 1em">墓</span>  
<span style="margin-left: 2em"><sub class="note-yuan">聪尝住超果寺庆依尊者自杭奉观音像来聪预知之曰三日内当有主公至及期果然今寺奉为开山祖一曰秀道者昔庐北山后建浮屠于山巅工毕遂积薪自焚上有碑铭许尚题辛勤成雁塔俄赴积薪焚静夜沉沉影疑来护刻文</sub></span>  
<span style="margin-left: 1em">长水法师名子璇秀州华亭人有道行注华严经八十</span>  
<span style="margin-left: 1em">一卷过精严寺讲楞严经自作疏疏未作时梦文殊入</span>  
<span style="margin-left: 1em">口既毕梦出于口疏成纸为之贵钱易奏赐号楞严大</span>  
<span style="margin-left: 1em">师后跏趺而寂以两瓮合之葬真如寺宋建炎初金兀</span>  
<span style="margin-left: 1em">术兵至发之见手爪绕身复瘗之而出</span>  
<span style="margin-left: 1em">僧崈古字太初号竹深族姓钱氏邑之仪凤里大族也</span>  
<span style="margin-left: 1em">以诗名有集曰白云谣壮岁弃妻妾出家馆于小蒸曹</span>  
<span style="margin-left: 1em">氏数十年竟守戒行以终</span>  
<span style="margin-left: 2em"><sub class="note-yuan">石屋禅师送松江竹深上人诗云参方礼祖外边事一着工夫在己躬亲觐阿师秋已半树雕叶落露金风</sub></span>  
<span style="margin-left: 1em">妙悟大师讳希最族姓施湖州人其母感异梦而生乳</span>  
<span style="margin-left: 1em">中遇相者曰是子骨法异常勿染于俗因舍出家依松</span>  
<span style="margin-left: 1em">郡之广化寺僧宝新为师四岁祝发受具戒十五学天</span>  
<span style="margin-left: 1em">台教于钱塘师慧才才善之曰宗风不坠矣擢居上首</span>  
<span style="margin-left: 1em">缁流竞号曰义虎治平中来讲秀州青龙镇隆平塔院</span>  
<span style="margin-left: 1em">道俗咸向居累年一日不得意于镇宰即拂衣去之霅</span>  
<span style="margin-left: 1em">川后复买居于胜果寺讲说如初寺僧子云之室夙有</span>  
<span style="margin-left: 1em">祟师乃呪块土掷于怪室中须臾得片纸书曰今被法</span>  
<span style="margin-left: 1em">来遣难舍法力没余当复来于是宁息者累日其后击</span>  
<span style="margin-left: 1em">物飏火变怪大作子云惶怖复请师禳之师至怪所诃</span>  
<span style="margin-left: 1em">之曰汝果何物耶得非未离幽壤之苦将丐慧力以求</span>  
<span style="margin-left: 1em">生耶何为扰人不已汝不闻恼法师者头破七分乎为</span>  
<span style="margin-left: 1em">之讲说轮回因缘仍令众僧声呪以破其罪障俄而空</span>  
<span style="margin-left: 1em">中轰然有声得朱书数十字自称有汉烈士沈光大略</span>  
<span style="margin-left: 1em">悔过谢罪自蒙忏解夜已生他化矣师谓他化天也元</span>  
<span style="margin-left: 1em">祐庚午季夏六日师说法讫作偈颂优游坐逝孟冬十</span>  
<span style="margin-left: 1em">八日阇维得舍利数十莹采陆离腊七十三</span>  
<span style="margin-left: 1em">惟正字焕然华亭黄氏子住余杭功臣山幼孤为童子</span>  
<span style="margin-left: 1em">有卓识词语皆出人意表其师称于人有大檀越奇之</span>  
<span style="margin-left: 1em">以度牒施之跪奉谢而不受自是益奇之年十八果以</span>  
<span style="margin-left: 1em">其志为大僧游方问道三十年乃罢其居功臣山尝跨</span>  
<span style="margin-left: 1em">一黄犊蒋侍郎堂出守杭州与政为方外友每来谒必</span>  
<span style="margin-left: 1em">军持挂角上市人争观之正自若也至郡庭下犊而谈</span>  
<span style="margin-left: 1em">笑终日而去一日郡有贵客至蒋公留政因欵清话留</span>  
<span style="margin-left: 1em">一偈而去矣曰昨日曾将今日期出门倚杖又思惟为</span>  
<span style="margin-left: 1em">僧只合居岩谷国士筵中甚不宜客皆仰其标致冬不</span>  
<span style="margin-left: 1em">拥𬬻以荻花作毬纳足其中客至共之书笔法胜绝如</span>  
<span style="margin-left: 1em">晋宋间风流人尝笑学者临法帖曰彼皆知翰墨为贵</span>  
<span style="margin-left: 1em">者其工皆有意今童子书画多纯笔可法也皇祐四年</span>  
<span style="margin-left: 1em">忽语众云夫动以对静未始有极吾一动十有四年今</span>  
<span style="margin-left: 1em">静无然静动本何有哉语既而瞑尝自赞其像曰貌古</span>  
<span style="margin-left: 1em">形踈倚杖藜分明画出须菩提解空不许离声色似听</span>  
<span style="margin-left: 1em">孤猿月下啼</span>  
<span style="margin-left: 1em">端师子吴兴人始见弄师子者发明心要则以彩帛像</span>  
<span style="margin-left: 1em">其皮时时著之因以为号住西佘山嗣姑苏翠峰月禅</span>  
<span style="margin-left: 1em">师西佘去湖州密迩每雪朝著彩衣入城小儿争哗逐</span>  
<span style="margin-left: 1em">之从人乞钱得即以散饥寒者钱穆父赴官浙东见之</span>  
<span style="margin-left: 1em">约明日饭端黎明独往避雨入道旁人家幼妇出迎俄</span>  
<span style="margin-left: 1em">其夫至诟逐竟为逻卒所收穆父吏速客见之问故曰</span>  
<span style="margin-left: 1em">烦寄声钱公本来赴斋中涂奸情事发请自饭穆父闻</span>  
<span style="margin-left: 1em">之惊且笑顾客曰此僧胸中无一点疑事能诵法华经</span>  
<span style="margin-left: 1em">湖人争延之必得钱五百乃开帙目诵数句即持钱地</span>  
<span style="margin-left: 1em">坐去缺薄者易之而去好歌渔父词月夕必歌之达旦</span>  
<span style="margin-left: 1em">乐元祐初圆照禅师自京师慧林退归姑苏见端于甘</span>  
<span style="margin-left: 1em">露曰汝非端师子乎曰是圆照戏之曰村里师子耳端</span>  
<span style="margin-left: 1em">应声曰村里师子村里弄眉毛与眼一齐动开却口肚</span>  
<span style="margin-left: 1em">里直笼统不爱人取奉直饶弄到帝王宫也是一塲乾</span>  
<span style="margin-left: 1em">打閧圆照称美不悟其讥也端客无锡欲归湖旦行江</span>  
<span style="margin-left: 1em">上问有湖秀便船乎篙师曰我行常润船也端欣然曰</span>  
<span style="margin-left: 1em">亦可乃附船尾高邮秦观少游闻其高道请升座于广</span>  
<span style="margin-left: 1em">慧端以手自指曰天下无双月人间只一僧一堂风冷</span>  
<span style="margin-left: 1em">淡千古意分明少游首肯之端高自称誉吐语奇怪逸</span>  
<span style="margin-left: 1em">人也有牙久不愈谓众曰明日迁化去众以为戏语请</span>  
<span style="margin-left: 1em">说偈端索笔大书曰端师子太慵懒未死牙齿先坏烂</span>  
<span style="margin-left: 1em">二时伴众赴堂粥饭都赶不办如今得死是便宜长眠</span>  
<span style="margin-left: 1em">百事皆不管第一不著看管第二不著吃粥饭五更遂</span>  
<span style="margin-left: 1em">化阅世七十二东吴祠之以为散圣</span>  
<span style="margin-left: 1em">鰕子和尚名智俨居静安寺七月十五日有胥村人来</span>  
<span style="margin-left: 1em">寺斋僧因请同往船行见捕鰕者俨买一斗索水噉之</span>  
<span style="margin-left: 1em">谓渔者曰斋回还汝钱令舟子勿泄登岸前行舟人言</span>  
<span style="margin-left: 1em">其故众人皆厌闻至斋家不请上座令席地一饭而无</span>  
<span style="margin-left: 1em">衬钱还渔者索钱曰无钱还我鰕俨徐云还汝复索水</span>  
<span style="margin-left: 1em">饮随吐出活鰕盈斗人皆以为异将示寂敛蒲草为万</span>  
<span style="margin-left: 1em">余绳悬诸廊庑曰吾将作大缘事继即坐化人竞以钱</span>  
<span style="margin-left: 1em">悬绳绳皆满遂以建佛阁今静安寺有鰕子道塲</span>  
<span style="margin-left: 1em">可观字宜翁别号竹庵华亭戚氏子祝发邑之宝云寺</span>  
<span style="margin-left: 1em">年十一进具戒得法于车溪乡法师叹曰语言文字皆</span>  
<span style="margin-left: 1em">糠粃耳绍兴间主当湖德藏一室萧然人不堪之乃曰</span>
