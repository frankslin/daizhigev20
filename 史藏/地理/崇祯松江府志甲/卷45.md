## 崇禎松江府志卷之四十五　人物十（方外）

<span style="margin-left: 3em">方外一</span>  
<span style="margin-left: 1em">世網如八陣圖逗入輒不能出波波劫劫寧知蕊宫蔥</span>  
<span style="margin-left: 1em">嶺別有道人在乎吾松向稱寂寞之濱往來雲水代多</span>  
<span style="margin-left: 1em">靈跡若神與之游際極詣會不啻嚼萬年冰也道在世</span>  
<span style="margin-left: 1em">外夫豈欺我志二氏</span>  
<span style="margin-left: 1em">康僧會其先康居國人世居天竺會年十餘歲二親亡</span>  
<span style="margin-left: 1em">服畢出家以吳赤烏十年初達建業會曰如來遷迹忽</span>  
<span style="margin-left: 1em">逾千載遺骨舍利神曜無方昔阿育王起塔及八萬四</span>  
<span style="margin-left: 1em">千夫塔寺之興以表遺化也權以爲誇誕乃謂其屬曰</span>  
<span style="margin-left: 1em">法之興廢在此一舉乃共潔齋靜室以鋼瓶加几燒香</span>  
<span style="margin-left: 1em">禮請七日期畢寂然無應求申二七日亦復如之權曰</span>  
<span style="margin-left: 1em">此欺誑將欲加罪會更請三七日權又特聽會誓曰法</span>  
<span style="margin-left: 1em">雲應降而吾等無感何假王憲當以死爲期耳三七日</span>  
<span style="margin-left: 1em">暮猶無所見莫不震懼既入五更忽聞瓶中鏗然有聲</span>  
<span style="margin-left: 1em">會自往視果獲舍利權大驚起曰希有之瑞也乃置舍</span>  
<span style="margin-left: 1em">利於鐵砧磓上使力者擊之砧磓俱陷舍利無損權大</span>  
<span style="margin-left: 1em">嗟伏即爲建塔至繇拳吳婁間留像金粟寺時或放光</span>  
<span style="margin-left: 1em">終於晉武太康元年</span>  
<span style="margin-left: 2em"><sub class="note-yuan">樂郊私語云金粟寺有康僧會身像余于至正癸巳始得頂禮明年春翻閲輪藏踰旬偶於晡時作禮像前見像眉間有光須臾若白線嫋嫋而出盤繞華蓋而上余遂鳴鐘集衆稱佛名號禮拜讚頌至暮復從眉間攝入衆嘆希有</sub></span>  
<span style="margin-left: 1em">文喜禦兒人姓朱氏梁開成間嘗之五臺山禮文殊大</span>  
<span style="margin-left: 1em">士後參仰禪師命爲典座一日見文殊跨獅子緣鼎側</span>  
<span style="margin-left: 1em">文喜訶曰文殊自文殊文喜自文喜遂掌之文殊湧空</span>  
<span style="margin-left: 1em">曰苦瓠連根苦甜瓜徹帝甜修行三大劫都被老僧嫌</span>  
<span style="margin-left: 1em">咸通中築室千頃山居之</span>  
<span style="margin-left: 1em">船子和尚名德誠節操高邈度量不群自印心於藥山</span>  
<span style="margin-left: 1em">與道吾雲巖爲同道交洎離藥山乃謂二同志曰公等</span>  
<span style="margin-left: 1em">應各據一方建立藥山宗旨予率性踈野惟好山水樂</span>  
<span style="margin-left: 1em">情自遣無所能也他後知我所止之處若遇伶俐座主</span>  
<span style="margin-left: 1em">指一人來或堪雕琢將授生平所得以報先師之恩遂</span>  
<span style="margin-left: 1em">分擕至秀州華亭泛一小舟隨緣度日以接四方往來</span>  
<span style="margin-left: 1em">時人莫知其高蹈因號船子和尚一日泊舟岸邊閑坐</span>  
<span style="margin-left: 1em">有官人問如何是和尚日用事師竪橈子曰會麽官人</span>  
<span style="margin-left: 1em">曰不會師曰棹撥清波金鱗罕遇師有偈數篇載水志</span>  
<span style="margin-left: 1em">法忍寺道吾後到京口遇夾山上堂僧問如何是法身</span>  
<span style="margin-left: 1em">山曰法身無相曰如何是法眼山曰法眼無瑕道吾不</span>  
<span style="margin-left: 1em">覺失笑山便下座請問道吾某甲適來祗對這僧話必</span>  
<span style="margin-left: 1em">有不是致令上座失笑望不吝慈悲吾曰和尚一等是</span>  
<span style="margin-left: 1em">出世未有師在山曰某甲甚處不是望爲指示吾曰某</span>  
<span style="margin-left: 1em">甲終不說請和尚到華亭船子處去山曰此人如何吾</span>  
<span style="margin-left: 1em">曰此人上無片瓦下無立錐和尚若去須易服而往山</span>  
<span style="margin-left: 1em">乃散衆束裝直造華亭船子纔見便問大德住甚麽寺</span>  
<span style="margin-left: 1em">山曰寺即不住住即不似師曰不似似個甚麽山曰不</span>  
<span style="margin-left: 1em">是目前法師曰甚處學得來山曰非耳目之所到師曰</span>  
<span style="margin-left: 1em">一句合頭語萬劫繫驢橛師又問垂絲千尺意在深潭</span>  
<span style="margin-left: 1em">離鈎三寸子何不道山擬開口被師一橈打落水中山</span>  
<span style="margin-left: 1em">纔上船師又曰道道山擬開口師又打山豁然大悟乃</span>  
<span style="margin-left: 1em">點頭三下師曰竿頭絲線從君弄不犯清波意自殊山</span>  
<span style="margin-left: 1em">遂問抛綸擲釣師意如何師曰絲懸渌水浮定有無之</span>  
<span style="margin-left: 1em">意山曰語帶玄而無路舌頭談而不談師曰釣盡江波</span>  
<span style="margin-left: 1em">金鱗始遇山乃掩耳師曰如是如是遂囑曰汝向去直</span>  
<span style="margin-left: 1em">須藏身處没踪迹没踪迹處莫藏身吾三十年在藥山</span>  
<span style="margin-left: 1em">祇明斯事汝今已得他後莫住城隍聚落但向深山裏</span>  
<span style="margin-left: 1em">钁頭邊覓取一個半個接續無令斷絶山乃辭行頻頻</span>  
<span style="margin-left: 1em">回顧師遂唤闍黎山乃回首師竪起橈子曰汝將謂別</span>  
<span style="margin-left: 1em">有乃覆船入水而逝</span>  
<span style="margin-left: 1em">霄韻駐錫松江飄然塵外間以詞翰遊戲三昧劉禹錫</span>  
<span style="margin-left: 1em">贈其遊天台詩云曲江僧向松江見又過天台看石橋</span>  
<span style="margin-left: 1em">鶴戀故巢雲戀岫比君猶是不逍遥</span>  
<span style="margin-left: 1em">聰道人姓仰氏名德聰初受戒於梵天寺參請諸方密</span>  
<span style="margin-left: 1em">契心印太平興國三年結廬佘山之東峯三虎爲之衛</span>  
<span style="margin-left: 1em">名大青小青有禪者造之見掛一書於梁間問之曰此</span>  
<span style="margin-left: 1em">佛經也問嘗讀否曰如人看家書既知之矣何再讀爲</span>  
<span style="margin-left: 1em">嘗曰古人貴行吾何言哉自是問都不答天禧元年七</span>  
<span style="margin-left: 1em">月趺坐而化閲月貌如生即建塔於東峯之麓山民有</span>  
<span style="margin-left: 1em">卜葬於側者其家夜聞虎嘯亟徙去釋靈鑑銘誌載丘</span>  
<span style="margin-left: 1em">墓</span>  
<span style="margin-left: 2em"><sub class="note-yuan">聰嘗住超果寺慶依尊者自杭奉觀音像來聰預知之曰三日內當有主公至及期果然今寺奉爲開山祖一曰秀道者昔廬北山後建浮屠于山巔工畢遂積薪自焚上有碑銘許尚題辛勤成雁塔俄赴積薪焚靜夜沉沉影疑來護刻文</sub></span>  
<span style="margin-left: 1em">長水法師名子璿秀州華亭人有道行註華嚴經八十</span>  
<span style="margin-left: 1em">一卷過精嚴寺講楞嚴經自作疏疏未作時夢文殊入</span>  
<span style="margin-left: 1em">口既畢夢出於口疏成紙爲之貴錢易奏賜號楞嚴大</span>  
<span style="margin-left: 1em">師後跏趺而寂以兩甕合之葬真如寺宋建炎初金兀</span>  
<span style="margin-left: 1em">术兵至發之見手爪遶身復瘞之而出</span>  
<span style="margin-left: 1em">僧崈古字太初號竹深族姓錢氏邑之儀鳳里大族也</span>  
<span style="margin-left: 1em">以詩名有集曰白雲謡壯歲棄妻妾出家館於小蒸曹</span>  
<span style="margin-left: 1em">氏數十年竟守戒行以終</span>  
<span style="margin-left: 2em"><sub class="note-yuan">石屋禪師送松江竹深上人詩云參方禮祖外邊事一着工夫在己躬親覲阿師秋已半樹彫葉落露金風</sub></span>  
<span style="margin-left: 1em">妙悟大師諱希最族姓施湖州人其母感異夢而生乳</span>  
<span style="margin-left: 1em">中遇相者曰是子骨法異常勿染於俗因捨出家依松</span>  
<span style="margin-left: 1em">郡之廣化寺僧寶新爲師四歲祝髮受具戒十五學天</span>  
<span style="margin-left: 1em">台教於錢塘師慧才才善之曰宗風不墜矣擢居上首</span>  
<span style="margin-left: 1em">緇流競號曰義虎治平中來講秀州青龍鎮隆平塔院</span>  
<span style="margin-left: 1em">道俗咸嚮居累年一日不得意於鎮宰即拂衣去之霅</span>  
<span style="margin-left: 1em">川後復買居於勝果寺講說如初寺僧子雲之室夙有</span>  
<span style="margin-left: 1em">祟師乃呪塊土擲於怪室中須臾得片紙書曰今被法</span>  
<span style="margin-left: 1em">來遣難捨法力没余當復來於是寧息者累日其後擊</span>  
<span style="margin-left: 1em">物颺火變怪大作子雲惶怖復請師禳之師至怪所訶</span>  
<span style="margin-left: 1em">之曰汝果何物耶得非未離幽壤之苦將丐慧力以求</span>  
<span style="margin-left: 1em">生耶何爲擾人不已汝不聞惱法師者頭破七分乎爲</span>  
<span style="margin-left: 1em">之講說輪迴因緣仍令衆僧聲呪以破其罪障俄而空</span>  
<span style="margin-left: 1em">中轟然有聲得朱書數十字自稱有漢烈士沈光大略</span>  
<span style="margin-left: 1em">悔過謝罪自蒙懺解夜已生他化矣師謂他化天也元</span>  
<span style="margin-left: 1em">祐庚午季夏六日師說法訖作偈頌優游坐逝孟冬十</span>  
<span style="margin-left: 1em">八日闍維得舍利數十瑩采陸離臘七十三</span>  
<span style="margin-left: 1em">惟正字焕然華亭黃氏子住餘杭功臣山幼孤爲童子</span>  
<span style="margin-left: 1em">有卓識詞語皆出人意表其師稱於人有大檀越奇之</span>  
<span style="margin-left: 1em">以度牒施之跪奉謝而不受自是益奇之年十八果以</span>  
<span style="margin-left: 1em">其志爲大僧游方問道三十年乃罷其居功臣山嘗跨</span>  
<span style="margin-left: 1em">一黃犢蔣侍郎堂出守杭州與政爲方外友每來謁必</span>  
<span style="margin-left: 1em">軍持掛角上市人争觀之正自若也至郡庭下犢而談</span>  
<span style="margin-left: 1em">笑終日而去一日郡有貴客至蔣公留政因欵清話留</span>  
<span style="margin-left: 1em">一偈而去矣曰昨日曾將今日期出門倚杖又思惟爲</span>  
<span style="margin-left: 1em">僧只合居巖谷國士筵中甚不宜客皆仰其標致冬不</span>  
<span style="margin-left: 1em">擁鑪以荻花作毬納足其中客至共之書筆法勝絶如</span>  
<span style="margin-left: 1em">晉宋間風流人嘗笑學者臨法帖曰彼皆知翰墨爲貴</span>  
<span style="margin-left: 1em">者其工皆有意今童子書畫多純筆可法也皇祐四年</span>  
<span style="margin-left: 1em">忽語衆云夫動以對靜未始有極吾一動十有四年今</span>  
<span style="margin-left: 1em">靜無然靜動本何有哉語既而瞑嘗自贊其像曰貌古</span>  
<span style="margin-left: 1em">形踈倚杖藜分明畫出須菩提解空不許離聲色似聽</span>  
<span style="margin-left: 1em">孤猿月下啼</span>  
<span style="margin-left: 1em">端師子吳興人始見弄師子者發明心要則以綵帛像</span>  
<span style="margin-left: 1em">其皮時時著之因以爲號住西佘山嗣姑蘇翠峯月禪</span>  
<span style="margin-left: 1em">師西佘去湖州密邇每雪朝著綵衣入城小兒争譁逐</span>  
<span style="margin-left: 1em">之從人乞錢得即以散饑寒者錢穆父赴官浙東見之</span>  
<span style="margin-left: 1em">約明日飯端黎明獨往避雨入道旁人家幼婦出迎俄</span>  
<span style="margin-left: 1em">其夫至詬逐竟爲邏卒所收穆父吏速客見之問故曰</span>  
<span style="margin-left: 1em">煩寄聲錢公本來赴齋中塗奸情事發請自飯穆父聞</span>  
<span style="margin-left: 1em">之驚且笑顧客曰此僧胸中無一點疑事能誦法華經</span>  
<span style="margin-left: 1em">湖人争延之必得錢五百乃開帙目誦數句即持錢地</span>  
<span style="margin-left: 1em">坐去缺薄者易之而去好歌漁父詞月夕必歌之達旦</span>  
<span style="margin-left: 1em">樂元祐初圓照禪師自京師慧林退歸姑蘇見端於甘</span>  
<span style="margin-left: 1em">露曰汝非端師子乎曰是圓照戲之曰村裏師子耳端</span>  
<span style="margin-left: 1em">應聲曰村裏師子村裏弄眉毛與眼一齊動開却口肚</span>  
<span style="margin-left: 1em">裏直籠統不愛人取奉直饒弄到帝王宫也是一塲乾</span>  
<span style="margin-left: 1em">打閧圓照稱美不悟其譏也端客無錫欲歸湖旦行江</span>  
<span style="margin-left: 1em">上問有湖秀便船乎篙師曰我行常潤船也端欣然曰</span>  
<span style="margin-left: 1em">亦可乃附船尾高郵秦觀少游聞其高道請升座於廣</span>  
<span style="margin-left: 1em">慧端以手自指曰天下無雙月人間只一僧一堂風冷</span>  
<span style="margin-left: 1em">淡千古意分明少游首肯之端高自稱譽吐語奇怪逸</span>  
<span style="margin-left: 1em">人也有牙久不愈謂衆曰明日遷化去衆以爲戲語請</span>  
<span style="margin-left: 1em">說偈端索筆大書曰端師子太慵懶未死牙齒先壞爛</span>  
<span style="margin-left: 1em">二時伴衆赴堂粥飯都趕不辦如今得死是便宜長眠</span>  
<span style="margin-left: 1em">百事皆不管第一不著看管第二不著喫粥飯五更遂</span>  
<span style="margin-left: 1em">化閲世七十二東吳祠之以爲散聖</span>  
<span style="margin-left: 1em">鰕子和尚名智儼居靜安寺七月十五日有胥村人來</span>  
<span style="margin-left: 1em">寺齋僧因請同往船行見捕鰕者儼買一斗索水噉之</span>  
<span style="margin-left: 1em">謂漁者曰齋回還汝錢令舟子勿泄登岸前行舟人言</span>  
<span style="margin-left: 1em">其故衆人皆厭聞至齋家不請上座令席地一飯而無</span>  
<span style="margin-left: 1em">襯錢還漁者索錢曰無錢還我鰕儼徐云還汝復索水</span>  
<span style="margin-left: 1em">飲隨吐出活鰕盈斗人皆以爲異將示寂斂蒲草爲萬</span>  
<span style="margin-left: 1em">餘繩懸諸廊廡曰吾將作大緣事繼即坐化人競以錢</span>  
<span style="margin-left: 1em">懸繩繩皆滿遂以建佛閣今靜安寺有鰕子道塲</span>  
<span style="margin-left: 1em">可觀字宜翁別號竹菴華亭戚氏子祝髮邑之寶雲寺</span>  
<span style="margin-left: 1em">年十一進具戒得法於車溪鄉法師嘆曰語言文字皆</span>  
<span style="margin-left: 1em">糠粃耳紹興間主當湖德藏一室蕭然人不堪之乃曰</span>  
<span style="margin-left: 1em">松風山月此我無盡衣鉢時杲大慧自徑山來訪對語</span>  
<span style="margin-left: 1em">終日嘆曰教海老龍也乾道七年丞相魏杞出鎮姑蘇</span>  
<span style="margin-left: 1em">請主北禪入院之辰適值重九指座云胸中一寸灰已</span>
