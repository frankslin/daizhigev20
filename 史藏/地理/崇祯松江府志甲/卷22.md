## 崇禎松江府志卷之二十二　官署二

<span style="margin-left: 3em">官署下</span>  
<span style="margin-left: 1em">雲間舊有勅書樓宣詔頒春二亭東西架閣樓南書院</span>  
<span style="margin-left: 1em">花園讀書林又延桂觀政壺天浄凉藏春竹節等六亭</span>  
<span style="margin-left: 1em">嘉禾志又有燕超堂僊鶴亭皆不見於前志則元貞時</span>  
<span style="margin-left: 1em">已頽毁矣元季屢更兵燹旋復繕治堂宇多經改易惟</span>  
<span style="margin-left: 1em">廳事承宣堂爲貞元重建後志所記凡三十餘所今亦</span>  
<span style="margin-left: 1em">不可問矣蹟雖湮没名留千載並古人之觀遊燕息彷</span>  
<span style="margin-left: 1em">彿貌而親焉名之所關遠矣</span>  
<span style="margin-left: 1em">弦歌堂三山亭艮閤並在舊縣治東宋元祐中令劉鵬</span>  
<span style="margin-left: 1em">建</span>  
<span style="margin-left: 2em">朱之純詩序畧彭城劉侯元祐庚午來宰雲間下車</span>  
<span style="margin-left: 2em">先修庠序次立教戒下至簿書期會各有條理一境</span>  
<span style="margin-left: 2em">告治訟庭清明幾致刑措於是即縣齋之東新其一</span>  
<span style="margin-left: 2em">室一亭一閣堂曰弦歌亭曰三山閣曰艮閣與士之</span>  
<span style="margin-left: 2em">賢者講論歌咏於其中蓋將有志於美風俗也然予</span>  
<span style="margin-left: 2em">嘗思之自浙右爲邑未有繁劇過此者其境東南濱</span>  
<span style="margin-left: 2em">海西北負江帶湖方二百餘里其户口除浮寄浪居</span>  
<span style="margin-left: 2em">而占籍者亦不下數十萬比嘉祐初太常丞吳公所</span>  
<span style="margin-left: 2em">治往往三倍其數故生齒日衆情僞滋多而獄訟少</span>  
<span style="margin-left: 2em">有衰息雖戴星出人日昃不食力愈勞神愈耗而姦</span>  
<span style="margin-left: 2em">宄終不能勝也乃劉侯來未幾而風移俗易詩有之</span>  
<span style="margin-left: 2em">曰豈弟君子民之父母夫爲政者豈弟發於天資平</span>  
<span style="margin-left: 2em">心如鑑之應形接物如鐘之待叩天之高地之厚得</span>  
<span style="margin-left: 2em">所以爲民父母之道則其從之之疾又何怪焉宜其</span>  
<span style="margin-left: 2em">游心三山鳴琴一堂登高而賦之使人知仁義禮樂</span>  
<span style="margin-left: 2em">之意也予圃隱湖西有客見過因問邑之治否誦公</span>  
<span style="margin-left: 2em">豈弟出於自然且曰方周盛時齊人五月報政公猶</span>  
<span style="margin-left: 2em">驚其速况處今之世教化未明而劉君治江海僻陋</span>  
<span style="margin-left: 2em">之地古道復行豈不賢哉噫以客所言證予所聞則</span>  
<span style="margin-left: 2em">君坐斯堂宴斯亭登斯閣也宜無愧於古人矣客退</span>  
<span style="margin-left: 2em">因序其所聞而爲之詩　洋洋百里起謳吟惠化薰</span>  
<span style="margin-left: 2em">陶谷水陰明月詩涵三島秀清風曲奏一堂深武城</span>  
<span style="margin-left: 2em">浪說言游道單父休誇子賤音政敏誰知過齊國想</span>  
<span style="margin-left: 2em">君真得古人心<sub class="note-yuan">弦歌堂</sub>俗易風移古道還縣齋壘石作</span>  
<span style="margin-left: 2em">三山因憐席上紅塵少贏得壺中白日閒想見大鰲</span>  
<span style="margin-left: 2em">擎水下坐看雙寉落雲間何須更叩黃金闕只此幽</span>  
<span style="margin-left: 2em">亭是玉關<sub class="note-yuan">三山亭</sub>畫閣峩然冠翠巒更占艮地特㠝岏</span>  
<span style="margin-left: 2em">曉窻高挹東風暖夜幕低垂北斗寒突兀狀驚青蜃</span>  
<span style="margin-left: 2em">吐徘徊勢若老龍蟠嗟子勁節非徐子那得陳侯一</span>  
<span style="margin-left: 2em">榻看<sub class="note-yuan">艮關</sub></span>  
<span style="margin-left: 1em">東堂即劉鵬三山亭山在水中朱之純所爲賦詩者也</span>  
<span style="margin-left: 1em">紹興間陳祖安爲令温大著改曰貽牟有鳴琴拂榻此</span>  
<span style="margin-left: 1em">游衍作詩何止誇釐牟之句元爲府治東堂</span>  
<span style="margin-left: 1em">思齋堂即舊弦歌堂</span>  
<span style="margin-left: 1em">招鶴亭即舊艮閣</span>  
<span style="margin-left: 1em">盡心堂在府治西偏舊琴堂也宋政和間姚舜明爲邑</span>  
<span style="margin-left: 1em">撫民盡敬以元豐元符斷獄制書揭之獄乾道八年嗣</span>  
<span style="margin-left: 1em">令陳岄移置堂中榜曰盡心取夫子所謂刑者侀也侀</span>  
<span style="margin-left: 1em">者成也一成而不可變故君子盡心焉之義自爲記後</span>  
<span style="margin-left: 1em">葉仲英復改曰琴堂開禧三年令汪立中重立翰林學</span>  
<span style="margin-left: 1em">士樓鑰書榜</span>  
<span style="margin-left: 1em">芳蘭堂亦姚令建自爲記元爲府治中堂</span>  
<span style="margin-left: 1em">製錦堂在府治東舊爲縣令正寢宋紹定令黃崖建前</span>  
<span style="margin-left: 1em">有八亭東爲射圃後改堂曰壺天有池亭曰觀政元爲</span>  
<span style="margin-left: 1em">鎮守萬户府</span>  
<span style="margin-left: 2em">黃崖自記云循治廳而東有堂三楹前此令尹之正</span>  
<span style="margin-left: 2em">寢也風雨漂摇垣壁頽圮四柱屼立屋穿見天地多</span>  
<span style="margin-left: 2em">坎陷移趾輒慮跌予頃攝丞欲葺治之窘事力未果</span>  
<span style="margin-left: 2em">尋誤恩承乏間至其地顧材壯礎堅似可支久坐觀</span>  
<span style="margin-left: 2em">其頽弗忍也幸天與之歲民大和會課賦所入僅不</span>  
<span style="margin-left: 2em">乏供於是樽浮約過銖積寸累一椽片瓦胥致以漸</span>  
<span style="margin-left: 2em">乃涓吉程工翻蓋其上甃砌其下而中飾以丹堊東</span>  
<span style="margin-left: 2em">厦西廡弗改其舊而直南有隙地荆榛蔓生弗可寓</span>  
<span style="margin-left: 2em">目亟芟夷藴崇之斵石爲道環植以花介八亭其間</span>  
<span style="margin-left: 2em">曰歲寒曰雪香曰宜雨曰倚晴曰載春曰棹月曰煙</span>  
<span style="margin-left: 2em">翠曰露紅由南東而北養竹百本夾小逕逕盡又築</span>  
<span style="margin-left: 2em">亭目以勁節又北度小橋顧而西即昔之招鶴亭也</span>  
<span style="margin-left: 2em">亭地勢高歷年久亦葺其廢而新之下植花木堂居</span>  
<span style="margin-left: 2em">其南堂有軒軒數尺外有扉以限園間一啟閉方春</span>  
<span style="margin-left: 2em">秋佳時花卉茂盛風物清楚則中設酒鑪俾邑人往</span>  
<span style="margin-left: 2em">來嬉遊其間以樂太平而歌豐年亦庶幾民和時洽</span>  
<span style="margin-left: 2em">也又東買民地闢爲射圃縱之闊爲尺八十有四衡</span>  
<span style="margin-left: 2em">其長三之經始於紹定元年冬十月竣事於次年三</span>  
<span style="margin-left: 2em">月工以日計者二千四百六十有奇竹木灰瓦磚石</span>  
<span style="margin-left: 2em">悉售以時直錢以緡計者一千二百四十有奇買地</span>  
<span style="margin-left: 2em">之費不預焉既訖工榜其堂曰製錦客有問予所以</span>  
<span style="margin-left: 2em">名堂者則應之曰美錦微物也古之君子猶不使人</span>  
<span style="margin-left: 2em">學製千室之邑其爲錦也不亦多乎予凉於材拙於</span>  
<span style="margin-left: 2em">用弗盡其心則害於而邑豈直一錦之傷而已民隱</span>  
<span style="margin-left: 2em">吾懼其無告而慼也念念而求之吏姦吾懼其乘間</span>  
<span style="margin-left: 2em">以肆也旦旦而警之吾又懼夫勇於爲而舛也則無</span>  
<span style="margin-left: 2em">一事不加謹焉無一物不加察焉公退之暇登斯堂</span>  
<span style="margin-left: 2em">也覩其名惟其義經緯之踈密布置之後先纂緝之</span>  
<span style="margin-left: 2em">勤紉補之工凡可推而達於邑者皆令之所宜深長</span>  
<span style="margin-left: 2em">思也堂後有小室扁以無倦步而入使人肅然敬畏</span>  
<span style="margin-left: 2em">之心生於以滌昬而警惰然則予之所以名者豈苟</span>  
<span style="margin-left: 2em">云乎哉譬如田獵射御貫則能獲禽不然苟一息之</span>  
<span style="margin-left: 2em">間而貽百姓之苦幸一身之免而貽後日之憂是自</span>  
<span style="margin-left: 2em">賊而已矣是賊其民而已矣於錦乎何恤客唯而退</span>  
<span style="margin-left: 2em">因紀其葺理顛末志諸石</span>  
<span style="margin-left: 1em">近民亭舊在府治東偏宋端平間令楊瑾立元爲館驛</span>  
<span style="margin-left: 2em">瑾自記云令最近民紐銅章綰墨綬環百里而撫字</span>  
<span style="margin-left: 2em">者近民之職也對門槐挹庭水萃兩造而聽決者近</span>  
<span style="margin-left: 2em">民之所也若夫堂宇既深令復於暇日度地築亭蒔</span>  
<span style="margin-left: 2em">花植竹以宴息其間時非與民接而亦曰近民可乎</span>  
<span style="margin-left: 2em">余嘗讀書至民可近不可下之訓知古所謂近民非</span>  
<span style="margin-left: 2em">必身相周旋言相唯諾手相授受而後謂近也一絲</span>  
<span style="margin-left: 2em">一粟必思耕織之勞而不盡其財一榱一桷必思斤</span>  
<span style="margin-left: 2em">斧之勞而不盡其力一噐一用必思埏埴之勞而不</span>  
<span style="margin-left: 2em">盡其技痌瘝乃身是以身體民也保若赤子是以子</span>  
<span style="margin-left: 2em">視民也天之聰明自民天之明畏自民是直以天待</span>  
<span style="margin-left: 2em">民矣夫不以民待民而直以天待民則隱微皆著見</span>  
<span style="margin-left: 2em">也屋漏皆神明也不睹不聞皆十手十目也况敢鄙</span>  
<span style="margin-left: 2em">夷之忿疾之而謂不我知不我勝乎近民若此其庶</span>  
<span style="margin-left: 2em">幾矣華亭地廣民繁余兩年間治理無他術唯力行</span>  
<span style="margin-left: 2em">近民之政而征賦樂輸獄訟寖簡民粗相安於無事</span>  
<span style="margin-left: 2em">斯亭之立斯記之作蓋將朝夕觀省無替厥心且樂</span>  
<span style="margin-left: 2em">爲知心者道也</span>  
<span style="margin-left: 1em">閲武亭初在府西北二里舊社稷壇亦楊瑾改建於舊</span>  
<span style="margin-left: 1em">縣學按華亭舊學基即今府學射圃記與續志皆稱以</span>  
<span style="margin-left: 1em">舊學爲閲武亭此也通志以爲鎮守萬户府改創今從</span>  
<span style="margin-left: 1em">記文</span>  
<span style="margin-left: 2em">謹改建自記云華亭壯縣其地北距江西據泖又東</span>  
<span style="margin-left: 2em">南綿亘大海幾二百里雲濤烟葦浩渺無際寇攘草</span>  
<span style="margin-left: 2em">竊隱見不常昔人慮之置鎮一尉一寨四縣又置防</span>  
<span style="margin-left: 2em">城土軍一百五十人令以軍正繫銜亦密矣承平備</span>  
<span style="margin-left: 2em">弛額缺不補防城存者僅三之一端平乙未冬邊境</span>  
<span style="margin-left: 2em">驛騷有旨命漕臣選官屬分行招剌而華亭軍額始</span>  
<span style="margin-left: 2em">盡復舊鎮尉寨亦如之明年秋會縣遷學宫軍相率</span>  
<span style="margin-left: 2em">請曰縣有教場寓於荒僻之野地素卑水潦適至則</span>  
<span style="margin-left: 2em">泥淖没足宜以學舊地改爲焉余聞斯語有契於心</span>  
<span style="margin-left: 2em">乃屬警曹趙君汝墠躬爲相度開道路築垣墻建亭</span>  
<span style="margin-left: 2em">宇軍競協力不月而成其秋大閲旂斾精明鐃皷讙</span>  
<span style="margin-left: 2em">亮觀者曰縣真壯哉禮出征必受成於學反釋奠以</span>  
<span style="margin-left: 2em">訊馘告而夫子則曰我戰則克祭則受福得其道矣</span>  
<span style="margin-left: 2em">夫是道之玅在天爲陰陽在地爲柔剛在人爲仁義</span>  
<span style="margin-left: 2em">擴而充之爲班師振旅爲偃武修文爲滅淮夷興禮</span>  
<span style="margin-left: 2em">樂而周道大治爲却萊夷墮三都而魯國大治今縣</span>  
<span style="margin-left: 2em">因舊學地爲新教場上以副聖天子不忘備禦之實</span>  
<span style="margin-left: 2em">下以慰軍士不忘教閲之心而文事武備若不相期</span>  
<span style="margin-left: 2em">而卒相合者亭既成因論本末刻之石庶後來者有</span>  
<span style="margin-left: 2em">考焉</span>  
<span style="margin-left: 1em">善治堂按圖在佛字橋之東普照寺之西南俗呼善政</span>  
<span style="margin-left: 1em">堂初縣治爲上官所屬縣則僑此視事</span>  
<span style="margin-left: 1em">棲鸞堂在舊簿廳東偏宋乾道元年主簿鄭茂建其地</span>  
<span style="margin-left: 1em">今典史廳也</span>  
<span style="margin-left: 1em">公餘風月在簿廳後宋嘉定九年主簿四明陸垕建今</span>  
<span style="margin-left: 1em">縣治後堂即其地也</span>  
<span style="margin-left: 1em">折桂閣在尉廳宋天聖四年秉義郎縣尉江炳建右文</span>  
<span style="margin-left: 1em">殿修撰李公夔元豐初爲尉時生大丞相忠定公於此</span>  
<span style="margin-left: 1em">因呼爲相公閣淳熙十一年尉巫清允改曰折桂後與</span>  
<span style="margin-left: 1em">尉廳俱廢今地在察院</span>  
<span style="margin-left: 1em">梅館在尉廳宋淳熙四年尉李昌建後廢</span>  
<span style="margin-left: 1em">夢燕堂宋嘉定十二年尉番陽洪僴即相公閣之故基</span>  
<span style="margin-left: 1em">建堂於上取唐張燕公事爲名後廢</span>  
<span style="margin-left: 1em">西亭在尉廳宋皇祐四年秋鄭方平建紹興間大師嗣</span>  
<span style="margin-left: 1em">秀王伯圭爲尉時重建後尉巫清允改曰陽春嘉定間</span>  
<span style="margin-left: 1em">尉洪僴重建後廢</span>  
<span style="margin-left: 1em">逃禪尉巫清允建後廢嘉定十三年尉洪僴闢東廡一</span>  
<span style="margin-left: 1em">室以舊名榜之逮元不存</span>  
<span style="margin-left: 1em">敬齋尉巫清允建後廢亦洪僴闢夢燕堂之西揭以舊</span>  
<span style="margin-left: 1em">名逮元不存</span>  
<span style="margin-left: 1em">思堂在丞廳本宋鹽監廳址章質夫爲監官時作</span>  
<span style="margin-left: 2em">蘇軾思堂記云建安章質夫築室於公堂之西名之</span>  
<span style="margin-left: 2em">曰思曰吾將朝夕於是凡吾之所爲必思而後行子</span>  
<span style="margin-left: 2em">爲我記之嗟夫予天下之無思慮者也遇事則發不</span>  
<span style="margin-left: 2em">暇思也未發而思之則未至己發而思之則無及以</span>  
<span style="margin-left: 2em">此終身不知所思言發於心而衝予口吐之則逆人</span>  
<span style="margin-left: 2em">茹之則逆余以爲寧逆人也故卒吐之君子之於善</span>  
<span style="margin-left: 2em">也如好好色其於不善也如惡惡臭豈復臨事而後</span>  
<span style="margin-left: 2em">思計議其美惡而避就之哉是故臨義而思利則義</span>  
<span style="margin-left: 2em">必不果臨戰而思生則戰必不力若夫窮達得喪死</span>  
<span style="margin-left: 2em">生禍福則吾有命矣少時遇隱者曰孺子近道少思</span>  
<span style="margin-left: 2em">寡慾曰思與慾若是均乎曰甚於慾庭有二盎以畜</span>  
<span style="margin-left: 2em">水隱者指之曰是有蟻漏是日取水一升而置之孰</span>  
<span style="margin-left: 2em">先竭曰必蟻漏者思慮之賊人也微而無間隱者之</span>  
<span style="margin-left: 2em">言有會于余心余行之且夫不思之樂不可名也虛</span>  
<span style="margin-left: 2em">而明一而通安而不懈不處而靜不飲酒而醉不閉</span>  
<span style="margin-left: 2em">目而睡將以是記思堂不以謬乎雖然言各有當也</span>  
<span style="margin-left: 2em">萬物並育而不相害道並行而不相悖以質夫之賢</span>  
<span style="margin-left: 2em">其所謂思者豈世俗營營於思慮者乎易曰無思也</span>  
<span style="margin-left: 2em">無爲也我願學焉詩曰思無邪質夫以之元豐二年</span>  
<span style="margin-left: 2em">正月二十四日</span>  
<span style="margin-left: 2em">章望之思堂記　吾族弟質夫官華亭縣之初治其</span>  
<span style="margin-left: 2em">官寺爲思堂以居予爲述而記之曰君子慮於正小</span>  
<span style="margin-left: 2em">人慮於邪惟邪動罔不兇惟正動罔不吉是宜戒哉</span>  
<span style="margin-left: 2em">戒之哉有攸爲也君子之於是不勤則不成不思則</span>  
<span style="margin-left: 2em">不得故夜思之旦而反覆之盡日以行積日以爲月</span>  
<span style="margin-left: 2em">積月以爲年積年以爲世爲善而無厭然後大善立</span>  
<span style="margin-left: 2em">矣是以君子行務五德四失曰何謂五德道貴有仁</span>  
<span style="margin-left: 2em">貌貴有禮言貴有信心貴有義業貴有學也道貴有</span>  
<span style="margin-left: 2em">仁所以成身也貌貴有禮所以交人也言貴有信所</span>  
<span style="margin-left: 2em">以誠物也心貴有義所以制事也業貴有學所以通</span>  
<span style="margin-left: 2em">理也何謂四失非也過也怨也忿也非無容一過無</span>  
<span style="margin-left: 2em">容再怨無容長忿無容發善在我思必有不善在我</span>  
<span style="margin-left: 2em">思必無思之不可以少已也古之人有立常由此質</span>  
<span style="margin-left: 2em">夫以名進士入官而予於世法所宜尊而畏之視處</span>  
<span style="margin-left: 2em">必志於有爲乃泝其所趨而爲之記</span>  
<span style="margin-left: 1em">亦足堂在造船場宋乾道元年孫紹遠建自爲之記</span>  
<span style="margin-left: 1em">風月堂舊市舶司前瞰瑁湖水光風月在几案間蓋一</span>  
<span style="margin-left: 1em">勝處也宋胡承美取白樂天水檻虛凉風月好之句爲</span>  
<span style="margin-left: 1em">名</span>  
<span style="margin-left: 1em">湖光亭在風月堂西宋范成大詩云微風不動斂濤湍</span>  
<span style="margin-left: 1em">組練晶晶色界寒斜照發揮猶未盡月明殘夜更來看</span>  
<span style="margin-left: 1em">濯纓亭在府南十步宋紹興三年建後爲官酒庫元廢</span>  
<span style="margin-left: 1em">中和樓在普照寺前下臨闤闠民富物華爲一市最佳</span>  
<span style="margin-left: 1em">處宋紹定間邑宰程熹建張即之題額元以其地建官</span>  
<span style="margin-left: 1em">醫提領所後廢</span>  
<span style="margin-left: 1em">環碧亭在瑁湖中洲宋嘉祐中縣令吳及建</span>  
<span style="margin-left: 1em">思吳堂即環碧亭也及有惠政民懷之元祐令劉鵬闢</span>  
<span style="margin-left: 1em">爲堂跨以虹梁因民所譽榜以是名</span>  
<span style="margin-left: 2em">朱之純序云思吳堂者初名環碧亭嘉祐中太常丞</span>  
<span style="margin-left: 2em">吳公幾道所作也公有惠政四十餘年民頌不絕今</span>  
<span style="margin-left: 2em">彭城劉侯來宰雲間採民所譽因至其地見其頽毁</span>  
<span style="margin-left: 2em">蕪没喟然嘆曰昔人思召公愛及甘棠况此亭中冠</span>  
<span style="margin-left: 2em">一湖吳公歲時與民所共樂者最爲勝槩當秋分之</span>  
<span style="margin-left: 2em">月夜湧出金波遇春暮之花時變爲錦水若乃火雲</span>  
<span style="margin-left: 2em">輝空挹清風而愠解凍雲凝地睹白雪以神清有此</span>  
<span style="margin-left: 2em">佳麗荒而不修良可惜也於是增大其址飛出軒宇</span>  
<span style="margin-left: 2em">環以虹梁徘徊煙波之中浩浩乎誠可樂者乃闢其</span>  
<span style="margin-left: 2em">亭爲堂易其名曰思吳得民望也吳公之來余方生</span>  
<span style="margin-left: 2em">七歲其教條治目更歷異政不得其詳然猶彷彿記</span>  
<span style="margin-left: 2em">其去時父老悲啼攀轅不與前進以至空一邑隨之</span>  
<span style="margin-left: 2em">及予壯歲疑其得民如此乃問鄉人長者因語其施</span>  
<span style="margin-left: 2em">設大畧感動冥嘿者二三事焉如浙右旱蝗蘇秀爲</span>  
<span style="margin-left: 2em">甚公方下車克自痛責遂禱横山之神即致甘雨蟲</span>  
<span style="margin-left: 2em">亦避境不食其稼至秋大稔出教條命民預修水利</span>  
<span style="margin-left: 2em">以待滛潦或注達於江海己而大水暴至阡陌堅完</span>  
<span style="margin-left: 2em">溝渠既浚復稔如初比及三年風俗歸厚天無札瘥</span>  
<span style="margin-left: 2em">地無旱潦家給人足歌頌滿路噫此古之所謂遺愛</span>  
<span style="margin-left: 2em">者宜乎去之久而思之深也今劉侯爲政豈弟又且</span>  
<span style="margin-left: 2em">孜孜尋訪吳之政迹欲舉而必行之惟恐後時則名</span>  
<span style="margin-left: 2em">斯堂也豈惟從民之望抑亦見其樂取人以爲善也</span>  
<span style="margin-left: 2em">人有疑其名者告予曰詩人思古皆傷今之不然也</span>  
<span style="margin-left: 2em">今以劉侯之仁民胥樂之又何思吳之有予應之曰</span>  
<span style="margin-left: 2em">人固有遭其虐政而思昔人之賢以哀今之不見者</span>  
<span style="margin-left: 2em">又有遇其善政而思昔人之賢以幸今之復見者思</span>  
<span style="margin-left: 2em">古之說豈一端哉當其男以田功之畢女以織事之</span>  
<span style="margin-left: 2em">休內無饑寒之戚外無賦役之勞思以斗酒相娱樂</span>  
<span style="margin-left: 2em">令於此時爲之命僚佐臨清流設玉斚金皷喧填於</span>  
<span style="margin-left: 2em">波間管絃嘈𡂐於堂下歌者舞者形和聲和以觀遊</span>  
<span style="margin-left: 2em">人士女或三或五溶溶洩洩如鷗鳥之浮川儵魚之</span>  
<span style="margin-left: 2em">戲藻是人之樂也皆相慶曰吳之復來矣若夫政不</span>  
<span style="margin-left: 2em">出此則人不樂生令於此時精耗簿書力疲獄訟事</span>  
<span style="margin-left: 2em">既無窮應亦不暇又何能俯清泠之淵笑談終日與</span>  
<span style="margin-left: 2em">之偕樂耶設有勉强爲之雖撞鐘擊皷人聞其聲將</span>  
<span style="margin-left: 2em">蹙頞而相告曰欲見吳之莫得也然則此堂之作一</span>  
<span style="margin-left: 2em">游一豫足以爲政之勸沮而劉侯之慮有出於此其</span>  
<span style="margin-left: 2em">深得思吳之樂歟荀卿曰欲觀千歲今日是也以劉</span>  
<span style="margin-left: 2em">侯之賢其樂顯前人之善如此則異時此堂復修子</span>  
<span style="margin-left: 2em">將期後民之所思有甚於今日矣堂成劉侯就予索</span>  
<span style="margin-left: 2em">詩於是序其所聞而賦之詩云畫堂重搆一湖中更</span>  
<span style="margin-left: 2em">述民思渤海公自昔三年留惠政至今百里頌清風</span>  
<span style="margin-left: 2em">波間陡覺懽聲別陌上新傳樂事同從此邦人轉懷</span>  
<span style="margin-left: 2em">德悠悠谷水幾時窮</span>  
<span style="margin-left: 1em">泳波亭即舊環碧亭元祐中劉鵬改爲思吳堂紹興間</span>  
<span style="margin-left: 1em">楊壽亨即堂址建亭易是名元元貞中縣丞魏雲翼建</span>  
<span style="margin-left: 1em">於唳鶴灘復榜曰環碧</span>  
<span style="margin-left: 2em">衛謙記　邑西南有湖曰瑁湖相傳爲陸氏魚舍湖</span>  
<span style="margin-left: 2em">雖小介於闤闠民居鱗鱗亭閣相望予猶記從父老</span>  
<span style="margin-left: 2em">杖屨於春風中笙歌載水冠蓋翳陸下至途翁野老</span>  
<span style="margin-left: 2em">攜杖頭百錢所至皆醉鄉陵遷谷變奄如夢遊獨先</span>  
<span style="margin-left: 2em">賢印迹之地輒不與莊生俱冺唳鶴灘其一也灘於</span>  
<span style="margin-left: 2em">湖東南洲與中洲相爲雄長歸於勢家莽爲荆榛今</span>  
<span style="margin-left: 2em">贊府捐俸入得之曰我將園池其上予甚笑其迂人</span>  
<span style="margin-left: 2em">生宦遊如傳舍此不得筐舉而篋將且此邑自昔不</span>  
<span style="margin-left: 2em">易爲號爲能吏劫劫至不敗幸矣而何力之餘公曰</span>  
<span style="margin-left: 2em">不然予家濟南山水窟所至皋石如故人故吾寧一</span>  
<span style="margin-left: 2em">日舍官府之榮而不可廢登臨之適且少從止軒杜</span>  
<span style="margin-left: 2em">翁遊境與心會輙不有一日無吾詩復不可一日無</span>  
<span style="margin-left: 2em">吾友則此園非菟裘私也予心韙其言而邈其事他</span>  
<span style="margin-left: 2em">日過之有亭翼然已大書環碧其上而求記於予予</span>  
<span style="margin-left: 2em">謝不敢以當當時郡守西巖張侯以文名而有聲於</span>  
<span style="margin-left: 2em">述作清思湧泉不擇地而况與贊府所謂草木臭味</span>  
<span style="margin-left: 2em">者耶未幾張侯即世忽忽復逾年公請益力一日復</span>  
<span style="margin-left: 2em">觴客其間臨流有閣椿桂有堂奇峯異卉雲立錦絢</span>  
<span style="margin-left: 2em">此亭不得專此洲矣公曰予戍瓜且熟此與邦人共</span>  
<span style="margin-left: 2em">之子不可以無述也予考郡圖經邑令吳公嘗於中</span>  
<span style="margin-left: 2em">洲築亭亦曰環碧後四十年邦人不勝去思易之曰</span>  
<span style="margin-left: 2em">思吳記思吳者不及親見其人徒採摘想像於萬一</span>  
<span style="margin-left: 2em">猶大書特書以侈其事如僕斯今當何如其喜耶抑</span>  
<span style="margin-left: 2em">公心在民公政在閭閻公不求人思人之思亦不可</span>  
<span style="margin-left: 2em">求而得而人自有不容已者嗚呼公思所以慰邦人</span>  
<span style="margin-left: 2em">之思乎於是乎書而繫之辭曰水環碧兮綠漪山獻</span>  
<span style="margin-left: 2em">翠兮九眉僊人兮璚琚載雲旂兮忘歸海之水兮群</span>  
<span style="margin-left: 2em">飛騎鯨來兮唱吾詩曠萬里兮有期芳滿塘兮菲菲</span>  
<span style="margin-left: 2em">鏗鏗兮叩朱絲絢吾桂兮斑衣褰風月兮追隨將冠</span>  
<span style="margin-left: 2em">佩兮陸離鷗來兮忘機鶴歸兮人未盡非昔環碧兮</span>  
<span style="margin-left: 2em">復見却千歲兮維公之思嗟後之來者視予此辭</span>  
<span style="margin-left: 1em">願匀亭在城隍廟東宣德間户部員外郎同安李賢祐</span>  
<span style="margin-left: 1em">督賦之所歲見東西二鄉非水則旱因以此名亭一時</span>  
<span style="margin-left: 1em">題咏甚富天順間改爲在城社學</span>  
<span style="margin-left: 1em">拱辰樓在守禦千户所後元夏萬户書畫樓也國朝成</span>  
<span style="margin-left: 1em">化八年千户顧禎重修易今名</span>  
<span style="margin-left: 1em">清風亭在察院廳事後弘治甲寅知府劉璟新建</span>  
<span style="margin-left: 2em">錢福記　國朝綱紀宇內以耳目之司任教察院其</span>  
<span style="margin-left: 2em">所由來尚矣若乃兩畿以暨諸藩則歲命御史各一</span>  
<span style="margin-left: 2em">人分按之既父以鹽政易蠱則專一人既又以兵籍</span>  
<span style="margin-left: 2em">易淆則專一人既又以兩畿當嚴慎固之勢也則各</span>  
<span style="margin-left: 2em">從其院舉捕盗者一人皆謂之巡按御史其餘因事</span>  
<span style="margin-left: 2em">而命者弗與焉其所歷官次皆曰察院蓋曰官之臧</span>  
<span style="margin-left: 2em">否事之興廢民之利病悉於是乎察之也松郡之有</span>  
<span style="margin-left: 2em">察院舊矣蒞於是而賢者鼎彝可得而逆數也乃弘</span>  
<span style="margin-left: 2em">治癸丑冬光州劉君廷瓉宗敬奉命至焉百職盡舉</span>  
<span style="margin-left: 2em">吏畏民懷乃退倚北窻進郡守劉璟指地之奥曰吾</span>  
<span style="margin-left: 2em">將於是乎亭焉昔人有云氣煩則慮亂視壅則志滯</span>  
<span style="margin-left: 2em">吾將於是乎清心寧神以與君輩從事焉守奉命唯</span>  
<span style="margin-left: 2em">謹爰謀僚屬擇義官之能且慎者二人俾督厥役亭</span>  
<span style="margin-left: 2em">成亭自院之退食堂簷楹之西少折而北繚垣屈曲</span>  
<span style="margin-left: 2em">不踰數步殆所謂奥如者曰奥宜潛思及亭則翬簷</span>  
<span style="margin-left: 2em">六出欄檻週匝縱目遊神則窪而池砑而石亭而荷</span>  
<span style="margin-left: 2em">洋洋而魚修竹茂林陰晴鯈忽舉輻輳於其間又有</span>  
<span style="margin-left: 2em">所謂曠如者曰曠宜宣志蓋君所授規也君既達觀</span>  
<span style="margin-left: 2em">而喜焉因命之曰清風亭君於是以游以憇以潛以</span>  
<span style="margin-left: 2em">宣以延父老而觀風焉至乃屬予記是爲甲寅夏四</span>  
<span style="margin-left: 2em">月也予復之曰王制五年一巡狩使太師陳詩以觀</span>  
<span style="margin-left: 2em">民風亦其一也故列國之使往來亦各觀風以獻其</span>  
<span style="margin-left: 2em">上至漢始以六條察郡國曰察則以嚴而其所事不</span>  
<span style="margin-left: 2em">越乎簿書期會則所謂風者亦既索然矣吾於是乎</span>  
<span style="margin-left: 2em">有取於君之作是亭也官廨者世之所謂傳舍而非</span>  
<span style="margin-left: 2em">已有也故視民居之堅否去每十倍若察院則又傳</span>  
<span style="margin-left: 2em">舍之傳舍也故視他廨之堅否去又十倍居之者不</span>  
<span style="margin-left: 2em">越旬時無暇慮乎其後奉之者趣具晨夕未嘗預爲</span>  
<span style="margin-left: 2em">其前其所爲美觀不過粉飾華藻之浮而其內不顧</span>  
<span style="margin-left: 2em">也孰有若君之爲百年慮者乎孰有若君之任獨勞</span>  
<span style="margin-left: 2em">而垂永規者乎又孰有若吾郡邑之奉君者乎後有</span>  
<span style="margin-left: 2em">嗣者當無朽矣諸聞者咸曰唯唯匪獨官廨宜爾也</span>  
<span style="margin-left: 2em">使天下之官皆不以傳舍視亦庶幾乎古之風哉時</span>  
<span style="margin-left: 2em">華亭尹李瀚初至遂請刻其言於石以表亭右　謝</span>
