## 崇祯松江府志卷之二十二　官署二

<span style="margin-left: 3em">官署下</span>  
<span style="margin-left: 1em">云间旧有勅书楼宣诏颁春二亭东西架阁楼南书院</span>  
<span style="margin-left: 1em">花园读书林又延桂观政壶天浄凉藏春竹节等六亭</span>  
<span style="margin-left: 1em">嘉禾志又有燕超堂僊鹤亭皆不见于前志则元贞时</span>  
<span style="margin-left: 1em">已颓毁矣元季屡更兵燹旋复缮治堂宇多经改易惟</span>  
<span style="margin-left: 1em">厅事承宣堂为贞元重建后志所记凡三十余所今亦</span>  
<span style="margin-left: 1em">不可问矣迹虽湮没名留千载并古人之观游燕息彷</span>  
<span style="margin-left: 1em">佛貌而亲焉名之所关远矣</span>  
<span style="margin-left: 1em">弦歌堂三山亭艮合并在旧县治东宋元祐中令刘鹏</span>  
<span style="margin-left: 1em">建</span>  
<span style="margin-left: 2em">朱之纯诗序畧彭城刘侯元祐庚午来宰云间下车</span>  
<span style="margin-left: 2em">先修庠序次立教戒下至簿书期会各有条理一境</span>  
<span style="margin-left: 2em">告治讼庭清明几致刑措于是即县斋之东新其一</span>  
<span style="margin-left: 2em">室一亭一阁堂曰弦歌亭曰三山阁曰艮阁与士之</span>  
<span style="margin-left: 2em">贤者讲论歌咏于其中盖将有志于美风俗也然予</span>  
<span style="margin-left: 2em">尝思之自浙右为邑未有繁剧过此者其境东南滨</span>  
<span style="margin-left: 2em">海西北负江带湖方二百余里其户口除浮寄浪居</span>  
<span style="margin-left: 2em">而占籍者亦不下数十万比嘉祐初太常丞吴公所</span>  
<span style="margin-left: 2em">治往往三倍其数故生齿日众情伪滋多而狱讼少</span>  
<span style="margin-left: 2em">有衰息虽戴星出人日昃不食力愈劳神愈耗而奸</span>  
<span style="margin-left: 2em">宄终不能胜也乃刘侯来未几而风移俗易诗有之</span>  
<span style="margin-left: 2em">曰岂弟君子民之父母夫为政者岂弟发于天资平</span>  
<span style="margin-left: 2em">心如鉴之应形接物如钟之待叩天之高地之厚得</span>  
<span style="margin-left: 2em">所以为民父母之道则其从之之疾又何怪焉宜其</span>  
<span style="margin-left: 2em">游心三山鸣琴一堂登高而赋之使人知仁义礼乐</span>  
<span style="margin-left: 2em">之意也予圃隐湖西有客见过因问邑之治否诵公</span>  
<span style="margin-left: 2em">岂弟出于自然且曰方周盛时齐人五月报政公犹</span>  
<span style="margin-left: 2em">惊其速况处今之世教化未明而刘君治江海僻陋</span>  
<span style="margin-left: 2em">之地古道复行岂不贤哉噫以客所言证予所闻则</span>  
<span style="margin-left: 2em">君坐斯堂宴斯亭登斯阁也宜无愧于古人矣客退</span>  
<span style="margin-left: 2em">因序其所闻而为之诗　洋洋百里起讴吟惠化薰</span>  
<span style="margin-left: 2em">陶谷水阴明月诗涵三岛秀清风曲奏一堂深武城</span>  
<span style="margin-left: 2em">浪说言游道单父休夸子贱音政敏谁知过齐国想</span>  
<span style="margin-left: 2em">君真得古人心<sub class="note-yuan">弦歌堂</sub>俗易风移古道还县斋垒石作</span>  
<span style="margin-left: 2em">三山因怜席上红尘少赢得壶中白日闲想见大鳌</span>  
<span style="margin-left: 2em">擎水下坐看双寉落云间何须更叩黄金阙只此幽</span>  
<span style="margin-left: 2em">亭是玉关<sub class="note-yuan">三山亭</sub>画阁峩然冠翠峦更占艮地特㠝岏</span>  
<span style="margin-left: 2em">晓窻高挹东风暖夜幕低垂北斗寒突兀状惊青蜃</span>  
<span style="margin-left: 2em">吐徘徊势若老龙蟠嗟子劲节非徐子那得陈侯一</span>  
<span style="margin-left: 2em">榻看<sub class="note-yuan">艮关</sub></span>  
<span style="margin-left: 1em">东堂即刘鹏三山亭山在水中朱之纯所为赋诗者也</span>  
<span style="margin-left: 1em">绍兴间陈祖安为令温大著改曰贻牟有鸣琴拂榻此</span>  
<span style="margin-left: 1em">游衍作诗何止夸厘牟之句元为府治东堂</span>  
<span style="margin-left: 1em">思斋堂即旧弦歌堂</span>  
<span style="margin-left: 1em">招鹤亭即旧艮阁</span>  
<span style="margin-left: 1em">尽心堂在府治西偏旧琴堂也宋政和间姚舜明为邑</span>  
<span style="margin-left: 1em">抚民尽敬以元丰元符断狱制书揭之狱乾道八年嗣</span>  
<span style="margin-left: 1em">令陈岄移置堂中榜曰尽心取夫子所谓刑者侀也侀</span>  
<span style="margin-left: 1em">者成也一成而不可变故君子尽心焉之义自为记后</span>  
<span style="margin-left: 1em">叶仲英复改曰琴堂开禧三年令汪立中重立翰林学</span>  
<span style="margin-left: 1em">士楼钥书榜</span>  
<span style="margin-left: 1em">芳兰堂亦姚令建自为记元为府治中堂</span>  
<span style="margin-left: 1em">制锦堂在府治东旧为县令正寝宋绍定令黄崖建前</span>  
<span style="margin-left: 1em">有八亭东为射圃后改堂曰壶天有池亭曰观政元为</span>  
<span style="margin-left: 1em">镇守万户府</span>  
<span style="margin-left: 2em">黄崖自记云循治厅而东有堂三楹前此令尹之正</span>  
<span style="margin-left: 2em">寝也风雨漂摇垣壁颓圮四柱屼立屋穿见天地多</span>  
<span style="margin-left: 2em">坎陷移趾辄虑跌予顷摄丞欲葺治之窘事力未果</span>  
<span style="margin-left: 2em">寻误恩承乏间至其地顾材壮础坚似可支久坐观</span>  
<span style="margin-left: 2em">其颓弗忍也幸天与之岁民大和会课赋所入仅不</span>  
<span style="margin-left: 2em">乏供于是樽浮约过铢积寸累一椽片瓦胥致以渐</span>  
<span style="margin-left: 2em">乃涓吉程工翻盖其上甃砌其下而中饰以丹垩东</span>  
<span style="margin-left: 2em">厦西庑弗改其旧而直南有隙地荆榛蔓生弗可寓</span>  
<span style="margin-left: 2em">目亟芟夷蕴崇之斵石为道环植以花介八亭其间</span>  
<span style="margin-left: 2em">曰岁寒曰雪香曰宜雨曰倚晴曰载春曰棹月曰烟</span>  
<span style="margin-left: 2em">翠曰露红由南东而北养竹百本夹小径径尽又筑</span>  
<span style="margin-left: 2em">亭目以劲节又北度小桥顾而西即昔之招鹤亭也</span>  
<span style="margin-left: 2em">亭地势高历年久亦葺其废而新之下植花木堂居</span>  
<span style="margin-left: 2em">其南堂有轩轩数尺外有扉以限园间一启闭方春</span>  
<span style="margin-left: 2em">秋佳时花卉茂盛风物清楚则中设酒𬬻俾邑人往</span>  
<span style="margin-left: 2em">来嬉游其间以乐太平而歌丰年亦庶几民和时洽</span>  
<span style="margin-left: 2em">也又东买民地辟为射圃纵之阔为尺八十有四衡</span>  
<span style="margin-left: 2em">其长三之经始于绍定元年冬十月竣事于次年三</span>  
<span style="margin-left: 2em">月工以日计者二千四百六十有奇竹木灰瓦砖石</span>  
<span style="margin-left: 2em">悉售以时直钱以缗计者一千二百四十有奇买地</span>  
<span style="margin-left: 2em">之费不预焉既讫工榜其堂曰制锦客有问予所以</span>  
<span style="margin-left: 2em">名堂者则应之曰美锦微物也古之君子犹不使人</span>  
<span style="margin-left: 2em">学制千室之邑其为锦也不亦多乎予凉于材拙于</span>  
<span style="margin-left: 2em">用弗尽其心则害于而邑岂直一锦之伤而已民隐</span>  
<span style="margin-left: 2em">吾惧其无告而戚也念念而求之吏奸吾惧其乘间</span>  
<span style="margin-left: 2em">以肆也旦旦而警之吾又惧夫勇于为而舛也则无</span>  
<span style="margin-left: 2em">一事不加谨焉无一物不加察焉公退之暇登斯堂</span>  
<span style="margin-left: 2em">也覩其名惟其义经纬之踈密布置之后先纂缉之</span>  
<span style="margin-left: 2em">勤纫补之工凡可推而达於邑者皆令之所宜深长</span>  
<span style="margin-left: 2em">思也堂后有小室扁以无倦步而入使人肃然敬畏</span>  
<span style="margin-left: 2em">之心生于以涤昬而警惰然则予之所以名者岂苟</span>  
<span style="margin-left: 2em">云乎哉譬如田猎射御贯则能获禽不然苟一息之</span>  
<span style="margin-left: 2em">间而贻百姓之苦幸一身之免而贻后日之忧是自</span>  
<span style="margin-left: 2em">贼而已矣是贼其民而已矣于锦乎何恤客唯而退</span>  
<span style="margin-left: 2em">因纪其葺理颠末志诸石</span>  
<span style="margin-left: 1em">近民亭旧在府治东偏宋端平间令杨瑾立元为馆驿</span>  
<span style="margin-left: 2em">瑾自记云令最近民纽铜章绾墨绶环百里而抚字</span>  
<span style="margin-left: 2em">者近民之职也对门槐挹庭水萃两造而听决者近</span>  
<span style="margin-left: 2em">民之所也若夫堂宇既深令复于暇日度地筑亭莳</span>  
<span style="margin-left: 2em">花植竹以宴息其间时非与民接而亦曰近民可乎</span>  
<span style="margin-left: 2em">余尝读书至民可近不可下之训知古所谓近民非</span>  
<span style="margin-left: 2em">必身相周旋言相唯诺手相授受而后谓近也一丝</span>  
<span style="margin-left: 2em">一粟必思耕织之劳而不尽其财一榱一桷必思斤</span>  
<span style="margin-left: 2em">斧之劳而不尽其力一噐一用必思埏埴之劳而不</span>  
<span style="margin-left: 2em">尽其技痌瘝乃身是以身体民也保若赤子是以子</span>  
<span style="margin-left: 2em">视民也天之聪明自民天之明畏自民是直以天待</span>  
<span style="margin-left: 2em">民矣夫不以民待民而直以天待民则隐微皆著见</span>  
<span style="margin-left: 2em">也屋漏皆神明也不睹不闻皆十手十目也况敢鄙</span>  
<span style="margin-left: 2em">夷之忿疾之而谓不我知不我胜乎近民若此其庶</span>  
<span style="margin-left: 2em">几矣华亭地广民繁余两年间治理无他术唯力行</span>  
<span style="margin-left: 2em">近民之政而征赋乐输狱讼寖简民粗相安于无事</span>  
<span style="margin-left: 2em">斯亭之立斯记之作盖将朝夕观省无替厥心且乐</span>  
<span style="margin-left: 2em">为知心者道也</span>  
<span style="margin-left: 1em">阅武亭初在府西北二里旧社稷坛亦杨瑾改建于旧</span>  
<span style="margin-left: 1em">县学按华亭旧学基即今府学射圃记与续志皆称以</span>  
<span style="margin-left: 1em">旧学为阅武亭此也通志以为镇守万户府改创今从</span>  
<span style="margin-left: 1em">记文</span>  
<span style="margin-left: 2em">谨改建自记云华亭壮县其地北距江西据泖又东</span>  
<span style="margin-left: 2em">南绵亘大海几二百里云涛烟苇浩渺无际寇攘草</span>  
<span style="margin-left: 2em">窃隐见不常昔人虑之置镇一尉一寨四县又置防</span>  
<span style="margin-left: 2em">城土军一百五十人令以军正系衔亦密矣承平备</span>  
<span style="margin-left: 2em">弛额缺不补防城存者仅三之一端平乙未冬边境</span>  
<span style="margin-left: 2em">驿骚有旨命漕臣选官属分行招剌而华亭军额始</span>  
<span style="margin-left: 2em">尽复旧镇尉寨亦如之明年秋会县迁学宫军相率</span>  
<span style="margin-left: 2em">请曰县有教场寓于荒僻之野地素卑水潦适至则</span>  
<span style="margin-left: 2em">泥淖没足宜以学旧地改为焉余闻斯语有契于心</span>  
<span style="margin-left: 2em">乃属警曹赵君汝𫮃躬为相度开道路筑垣墙建亭</span>  
<span style="margin-left: 2em">宇军竞协力不月而成其秋大阅旗斾精明铙皷讙</span>  
<span style="margin-left: 2em">亮观者曰县真壮哉礼出征必受成于学反释奠以</span>  
<span style="margin-left: 2em">讯馘告而夫子则曰我战则克祭则受福得其道矣</span>  
<span style="margin-left: 2em">夫是道之玅在天为阴阳在地为柔刚在人为仁义</span>  
<span style="margin-left: 2em">扩而充之为班师振旅为偃武修文为灭淮夷兴礼</span>  
<span style="margin-left: 2em">乐而周道大治为却莱夷堕三都而鲁国大治今县</span>  
<span style="margin-left: 2em">因旧学地为新教场上以副圣天子不忘备御之实</span>  
<span style="margin-left: 2em">下以慰军士不忘教阅之心而文事武备若不相期</span>  
<span style="margin-left: 2em">而卒相合者亭既成因论本末刻之石庶后来者有</span>  
<span style="margin-left: 2em">考焉</span>  
<span style="margin-left: 1em">善治堂按图在佛字桥之东普照寺之西南俗呼善政</span>  
<span style="margin-left: 1em">堂初县治为上官所属县则侨此视事</span>  
<span style="margin-left: 1em">栖鸾堂在旧簿厅东偏宋乾道元年主簿郑茂建其地</span>  
<span style="margin-left: 1em">今典史厅也</span>  
<span style="margin-left: 1em">公余风月在簿厅后宋嘉定九年主簿四明陆垕建今</span>  
<span style="margin-left: 1em">县治后堂即其地也</span>  
<span style="margin-left: 1em">折桂阁在尉厅宋天圣四年秉义郎县尉江炳建右文</span>  
<span style="margin-left: 1em">殿修撰李公夔元丰初为尉时生大丞相忠定公于此</span>  
<span style="margin-left: 1em">因呼为相公阁淳熙十一年尉巫清允改曰折桂后与</span>  
<span style="margin-left: 1em">尉厅俱废今地在察院</span>  
<span style="margin-left: 1em">梅馆在尉厅宋淳熙四年尉李昌建后废</span>  
<span style="margin-left: 1em">梦燕堂宋嘉定十二年尉番阳洪僴即相公阁之故基</span>  
<span style="margin-left: 1em">建堂于上取唐张燕公事为名后废</span>  
<span style="margin-left: 1em">西亭在尉厅宋皇祐四年秋郑方平建绍兴间大师嗣</span>  
<span style="margin-left: 1em">秀王伯圭为尉时重建后尉巫清允改曰阳春嘉定间</span>  
<span style="margin-left: 1em">尉洪僴重建后废</span>  
<span style="margin-left: 1em">逃禅尉巫清允建后废嘉定十三年尉洪僴辟东庑一</span>  
<span style="margin-left: 1em">室以旧名榜之逮元不存</span>  
<span style="margin-left: 1em">敬斋尉巫清允建后废亦洪僴辟梦燕堂之西揭以旧</span>  
<span style="margin-left: 1em">名逮元不存</span>  
<span style="margin-left: 1em">思堂在丞厅本宋盐监厅址章质夫为监官时作</span>  
<span style="margin-left: 2em">苏轼思堂记云建安章质夫筑室于公堂之西名之</span>  
<span style="margin-left: 2em">曰思曰吾将朝夕于是凡吾之所为必思而后行子</span>  
<span style="margin-left: 2em">为我记之嗟夫予天下之无思虑者也遇事则发不</span>  
<span style="margin-left: 2em">暇思也未发而思之则未至己发而思之则无及以</span>  
<span style="margin-left: 2em">此终身不知所思言发于心而冲予口吐之则逆人</span>  
<span style="margin-left: 2em">茹之则逆余以为宁逆人也故卒吐之君子之于善</span>  
<span style="margin-left: 2em">也如好好色其于不善也如恶恶臭岂复临事而后</span>  
<span style="margin-left: 2em">思计议其美恶而避就之哉是故临义而思利则义</span>  
<span style="margin-left: 2em">必不果临战而思生则战必不力若夫穷达得丧死</span>  
<span style="margin-left: 2em">生祸福则吾有命矣少时遇隐者曰孺子近道少思</span>  
<span style="margin-left: 2em">寡欲曰思与欲若是均乎曰甚于欲庭有二盎以畜</span>  
<span style="margin-left: 2em">水隐者指之曰是有蚁漏是日取水一升而置之孰</span>  
<span style="margin-left: 2em">先竭曰必蚁漏者思虑之贼人也微而无间隐者之</span>  
<span style="margin-left: 2em">言有会于余心余行之且夫不思之乐不可名也虚</span>  
<span style="margin-left: 2em">而明一而通安而不懈不处而静不饮酒而醉不闭</span>  
<span style="margin-left: 2em">目而睡将以是记思堂不以谬乎虽然言各有当也</span>  
<span style="margin-left: 2em">万物并育而不相害道并行而不相悖以质夫之贤</span>  
<span style="margin-left: 2em">其所谓思者岂世俗营营于思虑者乎易曰无思也</span>  
<span style="margin-left: 2em">无为也我愿学焉诗曰思无邪质夫以之元丰二年</span>  
<span style="margin-left: 2em">正月二十四日</span>  
<span style="margin-left: 2em">章望之思堂记　吾族弟质夫官华亭县之初治其</span>  
<span style="margin-left: 2em">官寺为思堂以居予为述而记之曰君子虑于正小</span>  
<span style="margin-left: 2em">人虑于邪惟邪动罔不凶惟正动罔不吉是宜戒哉</span>  
<span style="margin-left: 2em">戒之哉有攸为也君子之于是不勤则不成不思则</span>  
<span style="margin-left: 2em">不得故夜思之旦而反复之尽日以行积日以为月</span>

<span style="margin-left: 2em">仁所以成身也貌贵有礼所以交人也言贵有信所</span>
