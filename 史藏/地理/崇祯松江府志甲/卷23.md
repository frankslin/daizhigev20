## 崇祯松江府志卷之二十三　学政上

<span style="margin-left: 3em">学政</span>  
<span style="margin-left: 1em">三代以后人主武功定天下者往往缓于文事汉历高</span>  
<span style="margin-left: 1em">惠文景而太学未建也宋历太祖太宗真宗而州郡学</span>  
<span style="margin-left: 1em">未建也我</span>  
<span style="margin-left: 1em">圣祖未登极前之三年立郡县学洪武二年诏天下立</span>  
<span style="margin-left: 1em">府州县学八年诏立社学士生斯时不待舍去桑梓斌</span>  
<span style="margin-left: 1em">斌有邹鲁弦诵之风故余著学政并系社学而义塾兼</span>  
<span style="margin-left: 1em">附焉志祖宗初制也</span>  
<span style="margin-left: 3em">府学</span>  
<span style="margin-left: 1em">府学在集僊门西梯云桥北儒林坊南旧华亭县学也</span>  
<span style="margin-left: 1em">宋初先圣庙介于梵刹天禧初刘令唯一始迁于县东</span>  
<span style="margin-left: 1em">时学舍犹未立后六十五年当元丰甲子陈令谧始议</span>  
<span style="margin-left: 1em">兴学县人卫公佐公望献县东南地且独任礼殿之役</span>  
<span style="margin-left: 1em">工未兴而公佐卒历陶令镕至刘令鹏始克就绪公佐</span>  
<span style="margin-left: 1em">子又买国子书以资诸生讲习绍兴间杨令寿亨周令</span>  
<span style="margin-left: 1em">极侍其令铨钱参政良臣杨令潜相继修之而学舍始</span>  
<span style="margin-left: 1em">完整其地则今魁星楼址及射圃是也庆元末徐令民</span>  
<span style="margin-left: 1em">瞻始为堂于学以祀晋陆机陆云名其堂曰二俊嘉泰</span>  
<span style="margin-left: 1em">中嘉兴守钟必万复学田之侵于民者千八百亩有奇</span>  
<span style="margin-left: 1em">县令钱訚因以修学开禧间令汪立中始于学宫行序</span>  
<span style="margin-left: 1em">拜礼端平丙申令杨瑾以学舍庳陋度地鼎新之始迁</span>  
<span style="margin-left: 1em">于今所<sub class="note-yuan">按后建学碑阴记买地旧学之南二十三亩又按石刻绍熙中公文学前有射圃白地一片东至河西至陈宅及浜南彻通行街北至河然则今学基乃旧射圃及陈氏地也</sub>讲堂初名进德</span>  
<span style="margin-left: 1em">前令杨潜易以明伦斋五曰居仁由义隆礼育才养性</span>  
<span style="margin-left: 1em">至是改堂曰明善并斋为四曰体仁集义志道进德是</span>  
<span style="margin-left: 1em">时缙绅助费者钱提举仲虎而下百二十有八人具载</span>  
<span style="margin-left: 1em">碑阴赡学之田为亩万四千四百有奇并房廊邸店等</span>  
<span style="margin-left: 1em">瑾悉镵诸石以记至今存焉淳祐丙午施令退翁重建</span>  
<span style="margin-left: 1em">讲堂改创斋庐中置永仁亭后为观颐堂重立状元坊</span>  
<span style="margin-left: 1em">于学东建小学于斋后咸淳中令赵与伉作魁星楼于</span>  
<span style="margin-left: 1em">梯云桥南<sub class="note-yuan">秘阁张洪记</sub>元至元十四年县升为府因为府学</span>  
<span style="margin-left: 1em">元贞初复行贡举知府张之翰即魁星楼故址作新堂</span>  
<span style="margin-left: 1em">因以贡举名之大成殿后故有藏书阁丙申教授马允</span>  
<span style="margin-left: 1em">中重建二俊堂于阁之西庑以唐宣公贽配享时称为</span>  
<span style="margin-left: 1em">三贤祠皇庆初江南诸道行御史台檄榜讲堂曰明伦</span>  
<span style="margin-left: 1em">斋曰进德育才守中常德<sub class="note-yuan">堂榜绍兴中杨潜所刻朱文公书也</sub>癸丑知府</span>  
<span style="margin-left: 1em">申杲重为缮理延祐中知府汪从善始备大成之乐至</span>  
<span style="margin-left: 1em">正壬午达鲁花赤哈只以庙承邑旧拓其址而新之乙</span>  
<span style="margin-left: 1em">酉知府王至和始制执事者冠服<sub class="note-yuan">唐帽白凉衫黑角束带</sub>庚寅教</span>  
<span style="margin-left: 1em">授倪骏复新学舍撤櫺星门而易以石于是学始巨丽</span>  
<span style="margin-left: 1em">癸巳达鲁花赤哈散沙置新田租以石计者岁三百余</span>  
<span style="margin-left: 1em"><sub class="note-yuan">按叶知本书宋时学校田粮府幕官一人专提调出纳学官专任教养教法每岁春秋有补试中者教官面试能否方许入学行供岁有月试较其优者升为学职月有旬试教官亲书批点以示文法日行两供升堂会食轮差职事监厨正录监书单簿衣冠济济绝无冒滥是时沙侯委府掾总知学廪适合是法积有余镪因以置田云</sub>乙未知府崔思诚改观颐堂为养贤始范金为祭噐</span>  
<span style="margin-left: 1em"><sub class="note-yuan">噐皆精致迄今用之近为有官者易以新铸所存无几矣</sub>岁丙申苗军乱纵火焚学</span>  
<span style="margin-left: 1em">训导胡存道死之贼乃舍去己亥同知顾逖重修改大</span>  
<span style="margin-left: 1em">小学斋为五经斋重建三贤祠于阁之北贡士堂于学</span>  
<span style="margin-left: 1em">之南<sub class="note-yuan">更名宾兴</sub>又作燕居堂于学北邑人姚玉用献私田以</span>  
<span style="margin-left: 1em">益学廪甲辰知府王立中购求十三经等书藏之书阁</span>  
<span style="margin-left: 1em">前守王雍绘训导胡存道像于学立中为求记文立石</span>  
<span style="margin-left: 1em">其所又为胡请谥于行省</span>  
<span style="margin-left: 2em">至圣文宣王庙记　至矣哉先儒之称夫子也子贡</span>  
<span style="margin-left: 2em">则喻诸日月孟子则冠于生民通其祀则韩吏部以</span>  
<span style="margin-left: 2em">社稷为非严无其教则杜子美谓夷狄之不若是皆</span>  
<span style="margin-left: 2em">杰出意表垂范将来抉狂简之肺肝判冥顽之耳目</span>  
<span style="margin-left: 2em">肤浅庸蔽又何加乎若乃诵圣籍以知归服儒衣而</span>  
<span style="margin-left: 2em">不变以严师为己任将尊道为士先苟得其人不系</span>  
<span style="margin-left: 2em">乎位华亭县者嘉禾郡之剧邑也当土敝水烦之地</span>  
<span style="margin-left: 2em">属风颓俗杂之余民无坚正之心世尚剽狡之气淫</span>  
<span style="margin-left: 2em">神以要其福佞佛以逃其祸先生之教咸罔闻知庙</span>  
<span style="margin-left: 2em">貌之灵宜夫委顿自钱氏纳土宋运有开年历寝深</span>  
<span style="margin-left: 2em">邑长相继殊未思政理以五常为本五常繇夫子而</span>  
<span style="margin-left: 2em">明必有所宗是宜崇祀率视如弁髦之敝孰能存爱</span>  
<span style="margin-left: 2em">树之心介于梵刹之隅甚矣郑门之困今天子明神</span>  
<span style="margin-left: 2em">所劳禋享聿修典册攸存牲币靡阙而况褒成教本</span>  
<span style="margin-left: 2em">位极真王通邑之祠不绝如线非所以副国章之举</span>  
<span style="margin-left: 2em">废俾乡挍之知方少傅刘君是以有志于斯也刘君</span>  
<span style="margin-left: 2em">世编宦族代传素风养勇久负于一鸣适道无辞于</span>  
<span style="margin-left: 2em">寸禄下车而奸盗屏假印而狱讼清胥尹服从闾里</span>  
<span style="margin-left: 2em">竞劝当其至止首谒圣师拨蟏蛸而入户庭履蔓艸</span>  
<span style="margin-left: 2em">而升堂陛致美且惭于黻冕改为奚及于缁衣列像</span>  
<span style="margin-left: 2em">򐂖残侍坐跛倚裵徊瞻覩俯仰咨嗟不易新规曷成</span>  
<span style="margin-left: 2em">大壮爰求隙地得于县东营爽垲之基委诸薙氏度</span>  
<span style="margin-left: 2em">中伐之木命以梓人民忘悦使之劳吏谨不愆之素</span>  
<span style="margin-left: 2em">繇是重门秘殿敞大厦以耽耽东序西厢亘文测而</span>  
<span style="margin-left: 2em">翼翼后建殖庭之宇用铺讲艺之筵旅楹既闲陋堵</span>  
<span style="margin-left: 2em">室之非度缩版以载见宫墙之特高而又约奉身之</span>  
<span style="margin-left: 2em">资损计日之俸俨晬容而允穆饰华衮以鲜辉入室</span>  
<span style="margin-left: 2em">之贤侁侁侍坐升堂之众济济负墙置孝爱之一人</span>  
<span style="margin-left: 2em">与配侑而兼列如在之威神备矣致诚之典礼敦焉</span>  
<span style="margin-left: 2em">俎豆尝闻风雨攸除呜呼大道既隐明王不兴儒雅</span>  
<span style="margin-left: 2em">之俦没没无媿矧夫皇猷允塞文令阐扬夫子之英</span>  
<span style="margin-left: 2em">焕焕宜久岂独行于万里长幼之序有俭如能达彼</span>  
<span style="margin-left: 2em">四方齐鲁之风可变执古性惟乐善学媿亲师圣门</span>  
<span style="margin-left: 2em">难言诚甘取诮互乡与进冀许偕行直书内疚于无</span>  
<span style="margin-left: 2em">文不朽幸刊于美石时天禧二年岁次戊午闰四月</span>  
<span style="margin-left: 2em">十有一日陈执古记</span>  
<span style="margin-left: 2em">元祐修学记畧　华亭大县也旁小县皆有学独华</span>  
<span style="margin-left: 2em">亭无之盖浙西善事佛而华亭尤甚民有羡余率尽</span>  
<span style="margin-left: 2em">以施浮屠故其他有所建置莫易以成就先圣庙故</span>  
<span style="margin-left: 2em">在县治侧湫隘卑陋旁不可以为斋馆自吴侯为宰</span>  
<span style="margin-left: 2em">已尝有意迁易而劝导率不就后三十年而陈侯谧</span>  
<span style="margin-left: 2em">复议建学是时邑人卫公佐率先献县之东南地且</span>  
<span style="margin-left: 2em">求独建先圣殿归即筑土治木预为户牖加漆饰以</span>  
<span style="margin-left: 2em">须期会期会未定陈侯以事去议又罢久之浮屠氏</span>  
<span style="margin-left: 2em">从公佐乞所治材为佛宇公佐曰此材可使之朽腐</span>  
<span style="margin-left: 2em">必欲移用则不可相继陶侯镕为政而公佐死浮屠</span>  
<span style="margin-left: 2em">氏又从其子弟求其材为公佐祈福其子弟则今买</span>  
<span style="margin-left: 2em">书者也固执如公佐之意于是邑子朱赓朱伯夔周</span>  
<span style="margin-left: 2em">扬许洙以之干陶侯陶侯使之白州郡监司曰州郡</span>  
<span style="margin-left: 2em">监司见从吾无不从者四人者乃率众士人诣郡太</span>  
<span style="margin-left: 2em">守又诣转运使皆得请遂择日鸠工而四人者实董</span>  
<span style="margin-left: 2em">其役邑人素愿尽力者固己各实其言矣而他无助</span>  
<span style="margin-left: 2em">成其事者故积久卒成于刘侯盖若有待焉夫致治</span>  
<span style="margin-left: 2em">不可不先学较庸人孺子皆知之学士大夫方困布</span>  
<span style="margin-left: 2em">衣必以是说应有司之求及其入官则昔之果何以</span>  
<span style="margin-left: 2em">哉盖上之人所程督者常在狱讼簿书而考绩不急</span>  
<span style="margin-left: 2em">于教化故也以文盛之时建学较于多士之地或有</span>  
<span style="margin-left: 2em">其意而不能遂其议或遂其议而不能致其事或致</span>  
<span style="margin-left: 2em">其事而不能成其功故发记其实以为上下之劝使</span>  
<span style="margin-left: 2em">后之观者知成功如此之难无至于废而不治云刘</span>  
<span style="margin-left: 2em">发记</span>  
<span style="margin-left: 2em">绍兴修学记　华亭于檇李为大邑其地东南滨海</span>  
<span style="margin-left: 2em">无崇山叠嶂坦然如砥数百里间水光接天仙禽唳</span>  
<span style="margin-left: 2em">野钟此粹清异人间出有如二陆顾希冯蜚英千载</span>  
<span style="margin-left: 2em">宜后学追踪可项背相望也奈何学废不修青衿散</span>  
<span style="margin-left: 2em">逸虽有美质奚自而作成邪宣和中舍法罢去重以</span>  
<span style="margin-left: 2em">兵革之艰棘士非里选学闭空屋风揭雨穿日底摧</span>  
<span style="margin-left: 2em">败异时讲贯藏修之地茀榛莽而舞鼪鼬矣上下释</span>  
<span style="margin-left: 2em">奠执事以胥史素木瓠叶何从观礼二十余年阅令</span>  
<span style="margin-left: 2em">凡几其间不无贤大夫以起废动心然迄置不问者</span>  
<span style="margin-left: 2em">得非时有所未遑欤绍兴壬戌之仲夏蜀郡杨侯出</span>  
<span style="margin-left: 2em">宰是邑下车以故事谒先圣于学裵褢聛聣慨然有</span>  
<span style="margin-left: 2em">必葺之志属岁大旱三农废铚艾者十八方抚流亡</span>  
<span style="margin-left: 2em">之不暇奚暇治礼义哉越明年岁得中熟于是斥羡</span>  
<span style="margin-left: 2em">赀鸠长材乘农隙饬工役经始于十四年之正月落</span>  
<span style="margin-left: 2em">成于是岁之杪春殿宇中严萧屏外壮讲有堂居有</span>  
<span style="margin-left: 2em">舍斋宿有位宾谒有次以至帑廪庖馔各有区处帘</span>  
<span style="margin-left: 2em">帟噐皿纤悉毕备其塑绘之不经冕服之非度率按</span>  
<span style="margin-left: 2em">礼象而易之渠渠夏屋轮奂一新观者咸疑其始创</span>  
<span style="margin-left: 2em">信乎宏丽甲于他邑也时朝廷初行乡饮酒礼因得</span>  
<span style="margin-left: 2em">序宾于斯既而兴学之诏颁而华亭之学已成则侯</span>  
<span style="margin-left: 2em">之为政可谓知所先务矣春秋补试粉袍云集按籍</span>  
<span style="margin-left: 2em">得旧赡学田三千亩岁入秔稻七百余斛益以浮屋</span>  
<span style="margin-left: 2em">之租士食霈然呜呼盛哉昔唐韦景骏令于肥乡学</span>  
<span style="margin-left: 2em">庐馆舍皆所缮治他日过之儿曹悉至迎劳而以获</span>  
<span style="margin-left: 2em">见为幸夫景骏所以列于循吏者虽其治状伟然盖</span>  
<span style="margin-left: 2em">亦兴学之有助也今侯之政以宽惠为本委巷细民</span>  
<span style="margin-left: 2em">类能道之观其修学之一端则他可知矣诸君饱侯</span>  
<span style="margin-left: 2em">德求兼记之兼忝僚末义不获辞乃书其事俾镵于</span>  
<span style="margin-left: 2em">石云绍兴十五年五月五日左迪功郎县尉主管学</span>  
<span style="margin-left: 2em">事延平廖兼譔</span>  
<span style="margin-left: 2em">绍兴重修学记　华亭剧邑地东南负海北通江有</span>  
<span style="margin-left: 2em">鱼盐稻蟹之饶多富商大贾俗以浮侈相高不能力</span>  
<span style="margin-left: 2em">本业然衣冠之盛亦为江浙诸县之最虽细家中人</span>  
<span style="margin-left: 2em">衣食才足则喜教子弟以读书为事四方之俊历聘</span>  
<span style="margin-left: 2em">而来受业者云集其中秀民才士往往起家为达官</span>  
<span style="margin-left: 2em">繇是竞劝于学弦歌之声相闻居官者不必以击断</span>  
<span style="margin-left: 2em">鸷猛为治亦可以礼义驯服也往时长吏媮为一切</span>  
<span style="margin-left: 2em">以军旅期会为急应办调发锐于集事上下如束湿</span>

<span style="margin-left: 2em">绍熙修学记　学较为育材之地近代从政者困于</span>  
<span style="margin-left: 2em">簿书期会急于财货源流往往力不暇及春秋较艺</span>  
<span style="margin-left: 2em">朔望讲经徒修故事至于黉宇之简陋骎骎乎颓毁</span>  
<span style="margin-left: 2em">之域则恬不经意吁百工居肆以成其事士子不繇</span>  
<span style="margin-left: 2em">学而望其成就可乎眎欹弗支见漏弗补因循苟简</span>  
<span style="margin-left: 2em">以延岁月则亦终至于颓毁而已云间之学岁在甲</span>

<span style="margin-left: 2em">有廊庑膳羞有厨传虽不能广大前日之规模槩之</span>

<span style="margin-left: 2em">蒲缉柳古不可追若杜纷华甘򐂗盐对圣贤商确古</span>

<span style="margin-left: 2em">以期待诸生者盖不敢不勉故自初严选补谨课程</span>  
<span style="margin-left: 2em">置门籍以司出人限斋宿以紏勤惰甚者虑廪给之</span>  
<span style="margin-left: 2em">不继罢滥竽之员镌与釜之粟亦既三载于兹教养</span>  
<span style="margin-left: 2em">之心未始少忘而作成之效窃有望焉绍熙甲寅季</span>  
<span style="margin-left: 2em">春朔奉议郎知秀州华亭县主管劝农公事兼兵马</span>  
<span style="margin-left: 2em">都监兼盐场主管堰事借绯杨潜记</span>  
<span style="margin-left: 2em">嘉泰修学记　溧阳钱君为县之明年嘅念乡较废</span>  
<span style="margin-left: 2em">久不治焕新堂宇修饰斋庐几席具设庖廪整办合</span>  
<span style="margin-left: 2em">试乡邑人士充弟子员推简贡士次补职秩人以合</span>  
<span style="margin-left: 2em">选之士盖不独课试文艺学政大畧可睹已于是其</span>  
<span style="margin-left: 2em">师生谋伐石以纪其事来谒记于至乃为之言曰人</span>  
<span style="margin-left: 2em">受天地之中以生莫不有秉彜之性圣人君师天下</span>  
<span style="margin-left: 2em">恐其蔽于欲而无以自明也故为之教学以启廸之</span>  
<span style="margin-left: 2em">其序则君臣父子兄弟夫妇朋友其德则仁义礼智</span>  
<span style="margin-left: 2em">而已有诗书六艺之文而优游乎弦诵讲说之中有</span>  
<span style="margin-left: 2em">干戈羽籥以为舞管弦钟鼓之声以为乐而习乎进</span>  
<span style="margin-left: 2em">退之度俯仰之节有释菜宾射养老之事而熟乎等</span>  
<span style="margin-left: 2em">差隆杀之分尊老弟长之义所以开其知识而涤其</span>  
<span style="margin-left: 2em">心志和其血气而增其美质上自天子诸侯之国都</span>  
<span style="margin-left: 2em">下达于党庠衞序自少至长皆入于学走趋升降周</span>  
<span style="margin-left: 2em">旋揖逊其中者无非教也此所以学成于乡化行于</span>  
<span style="margin-left: 2em">国风俗厚而王道易也三代衰先王所以教学者废</span>  
<span style="margin-left: 2em">士习益卑民生益不致于理汉之贤君仅能立学京</span>  
<span style="margin-left: 2em">师一时长吏盖已兴礼殿置较官遣学者受业太常</span>  
<span style="margin-left: 2em">而其人士据经守道虽若专门名家然独行君子皆</span>  
<span style="margin-left: 2em">乡里之诸生伏节死义者是以扶汉鼎之将倾其勉</span>

<span style="margin-left: 2em">兴京师太学以至州县置博士弟子各有差加之以</span>  
<span style="margin-left: 2em">教养或可以复三代之旧然州县博士弟子皆役于</span>

<span style="margin-left: 2em">不如两京纯明亦其植立于乡闾之间唐世传循吏</span>  
<span style="margin-left: 2em">者十四五人无以学较为事者独韩愈延师生兴礼</span>  
<span style="margin-left: 2em">教以餐钱计子本给之他可知已呜呼乡之有学教</span>  
<span style="margin-left: 2em">民之始也先王之所甚重而唐汉忽之其亦不知本</span>

<span style="margin-left: 2em">代厚民之意汉唐千余年间思虑所未及者士生今</span>

<span style="margin-left: 2em">甲于诸县往时士风之盛不止以文章第太常魁多</span>  
<span style="margin-left: 2em">士盖至于学行淑乡里事业在政府杖节不屈于彊</span>

<span style="margin-left: 2em">哉君名訚字子言出于名代耳濡目染故能留意吾</span>

<span style="margin-left: 2em">有学于是县立学宫以附于庙绍兴绍熙虽加缮治</span>

<span style="margin-left: 2em">奸摘隐一年而樽节浮蠧储米三千石为平籴仓又</span>

<span style="margin-left: 2em">乡贤于夹又东甃泮水建讲堂一斋庐八令佐之欵</span>  
<span style="margin-left: 2em">谒有次诸生之养有廪通为垣以宫之翼翼沈沈邃</span>  
<span style="margin-left: 2em">严靖深伻来以图请记成事予惟论学较者未有不</span>  
<span style="margin-left: 2em">伤教法之坏议科举者未有不叹词章之靡经生学</span>  
<span style="margin-left: 2em">士尚论比闾之法庠塾之教则悼王制之不可复呜</span>

<span style="margin-left: 2em">治古终不可复欤曰不然也天命流行发生万物虽</span>  
<span style="margin-left: 2em">五行异质四时异气而仁义礼智之性恻隐羞恶辞</span>

<span style="margin-left: 2em">后世之寒书生独望其以苦节固穷见夫乃非人情</span>  
<span style="margin-left: 2em">乎然则大中丞之学田其关系于士风士气亦甚弘</span>  
<span style="margin-left: 2em">且巨矣虽然易之颐有云观颐吉观其所养也赜贞</span>  
<span style="margin-left: 2em">吉养正则吉也夫士能养正而后始不负大中丞置</span>

<span style="margin-left: 2em">学博士长是岁冬来莅事进诸士剖析四子六经奥</span>  
<span style="margin-left: 2em">义指陈　高皇帝教士功令甚备翕然鼓舞公且瞿</span>  
<span style="margin-left: 2em">然思曰学宫有养贤堂左右斋居庖湢具在堂后杰</span>  
<span style="margin-left: 2em">阁藏书具在而昼掩无问奇者田亩岁入亦具在为</span>  
<span style="margin-left: 2em">骫役所窟穴至无能诘问则司教者之失职谓何即</span>  
<span style="margin-left: 2em">请于当事躬暑雨行阡陌二十余日一旦姧窦尽露</span>  
<span style="margin-left: 2em">于是田还之学食还之士诸生无复以饥寒隳名检</span>  
<span style="margin-left: 2em">而公之教始无不得之士矣是粟也旧为役人半入</span>  
<span style="margin-left: 2em">私槖辄悭其出以抑士而概目之为赈士非贫与死</span>  
<span style="margin-left: 2em">邻弗愿受粟公品予格为三除赀产能供俯仰弗给</span>  
<span style="margin-left: 2em">士有贫而励志节者给勤学问者给有困阨当周者</span>  
<span style="margin-left: 2em">给仍颜其仓曰储士而官为授餐人人视升斗若荣</span>  
<span style="margin-left: 2em">施益砥砺文行期无负公田养云计公所清田合抚</span>  
<span style="margin-left: 2em">台简我徐公所置少司寇徐公陟太守徐公琳及尚</span>  
<span style="margin-left: 2em">宝肇惠所乐助总为亩几九百华亭章侯允儒复请</span>
