## 崇禎松江府志卷之二十三　學政上

<span style="margin-left: 3em">學政</span>  
<span style="margin-left: 1em">三代以後人主武功定天下者往往緩於文事漢歷高</span>  
<span style="margin-left: 1em">惠文景而太學未建也宋歷太祖太宗真宗而州郡學</span>  
<span style="margin-left: 1em">未建也我</span>  
<span style="margin-left: 1em">聖祖未登極前之三年立郡縣學洪武二年詔天下立</span>  
<span style="margin-left: 1em">府州縣學八年詔立社學士生斯時不待舍去桑梓斌</span>  
<span style="margin-left: 1em">斌有鄒魯絃誦之風故余著學政并系社學而義塾兼</span>  
<span style="margin-left: 1em">附焉志祖宗初制也</span>  
<span style="margin-left: 3em">府學</span>  
<span style="margin-left: 1em">府學在集僊門西梯雲橋北儒林坊南舊華亭縣學也</span>  
<span style="margin-left: 1em">宋初先聖廟介於梵刹天禧初劉令唯一始遷於縣東</span>  
<span style="margin-left: 1em">時學舍猶未立後六十五年當元豐甲子陳令謐始議</span>  
<span style="margin-left: 1em">興學縣人衛公佐公望獻縣東南地且獨任禮殿之役</span>  
<span style="margin-left: 1em">工未興而公佐卒歷陶令鎔至劉令鵬始克就緒公佐</span>  
<span style="margin-left: 1em">子又買國子書以資諸生講習紹興間楊令壽亨周令</span>  
<span style="margin-left: 1em">極侍其令銓錢參政良臣楊令潛相繼修之而學舍始</span>  
<span style="margin-left: 1em">完整其地則今魁星樓址及射圃是也慶元末徐令民</span>  
<span style="margin-left: 1em">瞻始爲堂於學以祀晉陸機陸雲名其堂曰二俊嘉泰</span>  
<span style="margin-left: 1em">中嘉興守鍾必萬復學田之侵於民者千八百畝有奇</span>  
<span style="margin-left: 1em">縣令錢誾因以修學開禧間令汪立中始於學宫行序</span>  
<span style="margin-left: 1em">拜禮端平丙申令楊瑾以學舍庳陋度地鼎新之始遷</span>  
<span style="margin-left: 1em">於今所<sub class="note-yuan">按後建學碑陰記買地舊學之南二十三畝又按石刻紹熙中公文學前有射圃白地一片東至河西至陳宅及浜南徹通行街北至河然則今學基乃舊射圃及陳氏地也</sub>講堂初名進德</span>  
<span style="margin-left: 1em">前令楊潛易以明倫齋五曰居仁由義隆禮育才養性</span>  
<span style="margin-left: 1em">至是改堂曰明善併齋爲四曰體仁集義志道進德是</span>  
<span style="margin-left: 1em">時縉紳助費者錢提舉仲虎而下百二十有八人具載</span>  
<span style="margin-left: 1em">碑陰贍學之田爲畝萬四千四百有奇并房廊邸店等</span>  
<span style="margin-left: 1em">瑾悉鑱諸石以記至今存焉淳祐丙午施令退翁重建</span>  
<span style="margin-left: 1em">講堂改創齋廬中置永仁亭後爲觀頤堂重立狀元坊</span>  
<span style="margin-left: 1em">於學東建小學於齋後咸淳中令趙與伉作魁星樓於</span>  
<span style="margin-left: 1em">梯雲橋南<sub class="note-yuan">秘閣張洪記</sub>元至元十四年縣陞爲府因爲府學</span>  
<span style="margin-left: 1em">元貞初復行貢舉知府張之翰即魁星樓故址作新堂</span>  
<span style="margin-left: 1em">因以貢舉名之大成殿後故有藏書閣丙申教授馬允</span>  
<span style="margin-left: 1em">中重建二俊堂於閣之西廡以唐宣公贄配享時稱爲</span>  
<span style="margin-left: 1em">三賢祠皇慶初江南諸道行御史臺檄榜講堂曰明倫</span>  
<span style="margin-left: 1em">齋曰進德育才守中常德<sub class="note-yuan">堂榜紹興中楊潛所刻朱文公書也</sub>癸丑知府</span>  
<span style="margin-left: 1em">申杲重爲繕理延祐中知府汪從善始備大成之樂至</span>  
<span style="margin-left: 1em">正壬午達魯花赤哈只以廟承邑舊拓其址而新之乙</span>  
<span style="margin-left: 1em">酉知府王至和始製執事者冠服<sub class="note-yuan">唐帽白凉衫黑角束帶</sub>庚寅教</span>  
<span style="margin-left: 1em">授倪駿復新學舍撤櫺星門而易以石於是學始鉅麗</span>  
<span style="margin-left: 1em">癸巳達魯花赤哈散沙置新田租以石計者歲三百餘</span>  
<span style="margin-left: 1em"><sub class="note-yuan">按葉知本書宋時學校田糧府幕官一人專提調出納學官專任教養教法每歲春秋有補試中者教官面試能否方許入學行供歲有月試較其優者陞爲學職月有旬試教官親書批點以示文法日行兩供陞堂會食輪差職事監厨正錄監書單簿衣冠濟濟絕無冒濫是時沙侯委府掾總知學廪適合是法積有餘鏹因以置田云</sub>乙未知府崔思誠改觀頤堂爲養賢始範金爲祭噐</span>  
<span style="margin-left: 1em"><sub class="note-yuan">噐皆精緻迄今用之近爲有官者易以新鑄所存無幾矣</sub>歲丙申苗軍亂縱火焚學</span>  
<span style="margin-left: 1em">訓導胡存道死之賊乃舍去己亥同知顧逖重修改大</span>  
<span style="margin-left: 1em">小學齋爲五經齋重建三賢祠於閣之北貢士堂於學</span>  
<span style="margin-left: 1em">之南<sub class="note-yuan">更名賓興</sub>又作燕居堂於學北邑人姚玉用獻私田以</span>  
<span style="margin-left: 1em">益學廩甲辰知府王立中購求十三經等書藏之書閣</span>  
<span style="margin-left: 1em">前守王雍繪訓導胡存道像於學立中爲求記文立石</span>  
<span style="margin-left: 1em">其所又爲胡請謚於行省</span>  
<span style="margin-left: 2em">至聖文宣王廟記　至矣哉先儒之稱夫子也子貢</span>  
<span style="margin-left: 2em">則喻諸日月孟子則冠於生民通其祀則韓吏部以</span>  
<span style="margin-left: 2em">社稷爲非嚴無其教則杜子美謂夷狄之不若是皆</span>  
<span style="margin-left: 2em">傑出意表垂範將來抉狂簡之肺肝判冥頑之耳目</span>  
<span style="margin-left: 2em">膚淺庸蔽又何加乎若乃誦聖籍以知歸服儒衣而</span>  
<span style="margin-left: 2em">不變以嚴師爲己任將尊道爲士先苟得其人不繫</span>  
<span style="margin-left: 2em">乎位華亭縣者嘉禾郡之劇邑也當土敝水煩之地</span>  
<span style="margin-left: 2em">屬風頽俗雜之餘民無堅正之心世尚剽狡之氣淫</span>  
<span style="margin-left: 2em">神以要其福佞佛以逃其禍先生之教咸罔聞知廟</span>  
<span style="margin-left: 2em">貌之靈宜夫委頓自錢氏納土宋運有開年曆寢深</span>  
<span style="margin-left: 2em">邑長相繼殊未思政理以五常爲本五常繇夫子而</span>  
<span style="margin-left: 2em">明必有所宗是宜崇祀率視如弁髦之敝孰能存愛</span>  
<span style="margin-left: 2em">樹之心介於梵刹之隅甚矣鄭門之困今天子明神</span>  
<span style="margin-left: 2em">所勞禋享聿修典册攸存牲幣靡闕而况褒成教本</span>  
<span style="margin-left: 2em">位極真王通邑之祠不絕如綫非所以副國章之舉</span>  
<span style="margin-left: 2em">廢俾鄉挍之知方少傅劉君是以有志於斯也劉君</span>  
<span style="margin-left: 2em">世編宦族代傳素風養勇久負於一鳴適道無辭於</span>  
<span style="margin-left: 2em">寸禄下車而姦盗屏假印而獄訟清胥尹服從閭里</span>  
<span style="margin-left: 2em">競勸當其至止首謁聖師撥蠨蛸而入户庭履蔓艸</span>  
<span style="margin-left: 2em">而升堂陛致美且慚於黻冕改爲奚及於緇衣列像</span>  
<span style="margin-left: 2em">򐂖殘侍坐跛倚裵徊瞻覩俯仰咨嗟不易新規曷成</span>  
<span style="margin-left: 2em">大壯爰求隙地得於縣東營爽塏之基委諸薙氏度</span>  
<span style="margin-left: 2em">中伐之木命以梓人民忘悦使之勞吏謹不愆之素</span>  
<span style="margin-left: 2em">繇是重門秘殿敞大厦以耽耽東序西廂亘文測而</span>  
<span style="margin-left: 2em">翼翼後建殖庭之宇用鋪講藝之筵旅楹既閑陋堵</span>  
<span style="margin-left: 2em">室之非度縮版以載見宫牆之特高而又約奉身之</span>  
<span style="margin-left: 2em">資損計日之俸儼晬容而允穆飾華袞以鮮輝入室</span>  
<span style="margin-left: 2em">之賢侁侁侍坐升堂之衆濟濟負牆置孝愛之一人</span>  
<span style="margin-left: 2em">與配侑而兼列如在之威神備矣致誠之典禮敦焉</span>  
<span style="margin-left: 2em">俎豆嘗聞風雨攸除嗚呼大道既隱明王不興儒雅</span>  
<span style="margin-left: 2em">之儔没没無媿矧夫皇猷允塞文令闡揚夫子之英</span>  
<span style="margin-left: 2em">焕焕宜久豈獨行於萬里長幼之序有儉如能達彼</span>  
<span style="margin-left: 2em">四方齊魯之風可變執古性惟樂善學媿親師聖門</span>  
<span style="margin-left: 2em">難言誠甘取誚互鄉與進冀許偕行直書內疚於無</span>  
<span style="margin-left: 2em">文不朽幸刊於美石時天禧二年歲次戊午閏四月</span>  
<span style="margin-left: 2em">十有一日陳執古記</span>  
<span style="margin-left: 2em">元祐修學記畧　華亭大縣也旁小縣皆有學獨華</span>  
<span style="margin-left: 2em">亭無之蓋浙西善事佛而華亭尤甚民有羡餘率盡</span>  
<span style="margin-left: 2em">以施浮屠故其他有所建置莫易以成就先聖廟故</span>  
<span style="margin-left: 2em">在縣治側湫隘卑陋旁不可以爲齋館自吳侯爲宰</span>  
<span style="margin-left: 2em">已嘗有意遷易而勸導率不就後三十年而陳侯謐</span>  
<span style="margin-left: 2em">復議建學是時邑人衛公佐率先獻縣之東南地且</span>  
<span style="margin-left: 2em">求獨建先聖殿歸即築土治木預爲户牖加漆飾以</span>  
<span style="margin-left: 2em">須期會期會未定陳侯以事去議又罷久之浮屠氏</span>  
<span style="margin-left: 2em">從公佐乞所治材爲佛宇公佐曰此材可使之朽腐</span>  
<span style="margin-left: 2em">必欲移用則不可相繼陶侯鎔爲政而公佐死浮屠</span>  
<span style="margin-left: 2em">氏又從其子弟求其材爲公佐祈福其子弟則今買</span>  
<span style="margin-left: 2em">書者也固執如公佐之意於是邑子朱賡朱伯夔周</span>  
<span style="margin-left: 2em">揚許洙以之干陶侯陶侯使之白州郡監司曰州郡</span>  
<span style="margin-left: 2em">監司見從吾無不從者四人者乃率衆士人詣郡太</span>  
<span style="margin-left: 2em">守又詣轉運使皆得請遂擇日鳩工而四人者實董</span>  
<span style="margin-left: 2em">其役邑人素願盡力者固己各實其言矣而他無助</span>  
<span style="margin-left: 2em">成其事者故積久卒成於劉侯蓋若有待焉夫致治</span>  
<span style="margin-left: 2em">不可不先學較庸人孺子皆知之學士大夫方困布</span>  
<span style="margin-left: 2em">衣必以是說應有司之求及其入官則昔之果何以</span>  
<span style="margin-left: 2em">哉蓋上之人所程督者常在獄訟簿書而考績不急</span>  
<span style="margin-left: 2em">於教化故也以文盛之時建學較於多士之地或有</span>  
<span style="margin-left: 2em">其意而不能遂其議或遂其議而不能致其事或致</span>  
<span style="margin-left: 2em">其事而不能成其功故發記其實以爲上下之勸使</span>  
<span style="margin-left: 2em">後之觀者知成功如此之難無至於廢而不治云劉</span>  
<span style="margin-left: 2em">發記</span>  
<span style="margin-left: 2em">紹興修學記　華亭於檇李爲大邑其地東南濱海</span>  
<span style="margin-left: 2em">無崇山疊嶂坦然如砥數百里間水光接天仙禽唳</span>  
<span style="margin-left: 2em">野鍾此粹清異人間出有如二陸顧希馮蜚英千載</span>  
<span style="margin-left: 2em">宜後學追蹤可項背相望也奈何學廢不修青衿散</span>  
<span style="margin-left: 2em">逸雖有美質奚自而作成邪宣和中舍法罷去重以</span>  
<span style="margin-left: 2em">兵革之艱棘士非里選學閉空屋風揭雨穿日底摧</span>  
<span style="margin-left: 2em">敗異時講貫藏修之地茀榛莽而舞鼪鼬矣上下釋</span>  
<span style="margin-left: 2em">奠執事以胥史素木瓠葉何從觀禮二十餘年閲令</span>  
<span style="margin-left: 2em">凡幾其間不無賢大夫以起廢動心然迄置不問者</span>  
<span style="margin-left: 2em">得非時有所未遑歟紹興壬戌之仲夏蜀郡楊侯出</span>  
<span style="margin-left: 2em">宰是邑下車以故事謁先聖於學裵褢聛聣慨然有</span>  
<span style="margin-left: 2em">必葺之志屬歲大旱三農廢銍艾者十八方撫流亡</span>  
<span style="margin-left: 2em">之不暇奚暇治禮義哉越明年歲得中熟於是斥羨</span>  
<span style="margin-left: 2em">貲鳩長材乘農隙飭工役經始於十四年之正月落</span>  
<span style="margin-left: 2em">成於是歲之杪春殿宇中嚴蕭屏外壯講有堂居有</span>  
<span style="margin-left: 2em">舍齋宿有位賓謁有次以至帑廪庖饌各有區處簾</span>  
<span style="margin-left: 2em">帟噐皿纖悉畢備其塑繪之不經冕服之非度率按</span>  
<span style="margin-left: 2em">禮象而易之渠渠夏屋輪奂一新觀者咸疑其始創</span>  
<span style="margin-left: 2em">信乎宏麗甲於他邑也時朝廷初行鄉飲酒禮因得</span>  
<span style="margin-left: 2em">序賓於斯既而興學之詔頒而華亭之學已成則侯</span>  
<span style="margin-left: 2em">之爲政可謂知所先務矣春秋補試粉袍雲集按籍</span>  
<span style="margin-left: 2em">得舊贍學田三千畝歲入秔稻七百餘斛益以浮屋</span>  
<span style="margin-left: 2em">之租士食霈然嗚呼盛哉昔唐韋景駿令於肥鄉學</span>  
<span style="margin-left: 2em">廬館舍皆所繕治他日過之兒曹悉至迎勞而以獲</span>  
<span style="margin-left: 2em">見爲幸夫景駿所以列於循吏者雖其治狀偉然蓋</span>  
<span style="margin-left: 2em">亦興學之有助也今侯之政以寬惠爲本委巷細民</span>  
<span style="margin-left: 2em">類能道之觀其修學之一端則他可知矣諸君飽侯</span>  
<span style="margin-left: 2em">德求兼記之兼忝僚末義不獲辭乃書其事俾鑱於</span>  
<span style="margin-left: 2em">石云紹興十五年五月五日左迪功郎縣尉主管學</span>  
<span style="margin-left: 2em">事延平廖兼譔</span>  
<span style="margin-left: 2em">紹興重修學記　華亭劇邑地東南負海北通江有</span>  
<span style="margin-left: 2em">魚鹽稻蟹之饒多富商大賈俗以浮侈相高不能力</span>  
<span style="margin-left: 2em">本業然衣冠之盛亦爲江浙諸縣之最雖細家中人</span>  
<span style="margin-left: 2em">衣食纔足則喜教子弟以讀書爲事四方之俊歷聘</span>  
<span style="margin-left: 2em">而來受業者雲集其中秀民才士往往起家爲達官</span>  
<span style="margin-left: 2em">繇是競勸於學弦歌之聲相聞居官者不必以擊斷</span>  
<span style="margin-left: 2em">鷙猛爲治亦可以禮義馴服也往時長吏媮爲一切</span>  
<span style="margin-left: 2em">以軍旅期會爲急應辦調發鋭於集事上下如束濕</span>  
<span style="margin-left: 2em">以故激成頑俗伺吏短長爲嚚訟馴雅之風少衰紹</span>  
<span style="margin-left: 2em">興己卯長興周侯極來宰是邦下車問風俗則曰自</span>  
<span style="margin-left: 2em">吾居鄉時聞此有難治名今固無所用斤斧也廼尊</span>  
<span style="margin-left: 2em">儒生禮賢雋一以文治之先教後罰故習盡革邑以</span>  
<span style="margin-left: 2em">無事顧瞻學宫垣牆圯漏茀穢不除經師倚席不講</span>  
<span style="margin-left: 2em">弟子散在黨巷則喟然曰吾邑多君子而學弊若此</span>  
<span style="margin-left: 2em">顧何以稱父兄之樂育廣師友之淵源且吾所恃以</span>  
<span style="margin-left: 2em">革彊暴揉頑獷省獄訟而優游於此者端在是爾其</span>  
<span style="margin-left: 2em">可緩即選於衆得才敏廉幹之士曰陸南者俾長諸</span>  
<span style="margin-left: 2em">生而會計焉籍贍學之田獲隱没不輸之租甚多度</span>  
<span style="margin-left: 2em">廪給之餘悉取以充費市材具募傭工而悦使之正</span>  
<span style="margin-left: 2em">欹傾補罅漏築夷圯易朽蠹鋤荒纇達堙塞墁堊之</span>  
<span style="margin-left: 2em">丹雘之廊廡脩潔庭户明焕鼎鼎乎硯席之盛也邑</span>  
<span style="margin-left: 2em">人鄭君澭承是美意捐私帑設門戟翼以欄楯而夫</span>  
<span style="margin-left: 2em">子之宫儀制始備廟貌尊嚴過者肅容暨訖功南以</span>  
<span style="margin-left: 2em">事來告且命紀實克昌竊惟老佛之教以崇飾塔廟</span>  
<span style="margin-left: 2em">爲植福之本雖越法踰禮不知涯量然讀其師之書</span>  
<span style="margin-left: 2em">者必能尊其說所至輒能變瓦礫爲金碧更庳陋爲</span>  
<span style="margin-left: 2em">輪奂又常以死生不可億之說駭怖流俗而富家巨</span>  
<span style="margin-left: 2em">室傾貲以助其靡以徼覬身後之福今吾儒不然其</span>  
<span style="margin-left: 2em">宫室有數其噐械有等不傷民財有補於世而爲吾</span>  
<span style="margin-left: 2em">徒者反不能尊其書衛其道視庠序荒涼學徒解散</span>  
<span style="margin-left: 2em">爲吏者則以力不暇給爲託而不知崇儒尚賢爲從</span>  
<span style="margin-left: 2em">政之良策也居家者則以爲無損益於己而不知導</span>  
<span style="margin-left: 2em">子孫學乃無窮之利也一何悖哉今周侯尊吾道不</span>  
<span style="margin-left: 2em">鄙夷其民修學挍以示嚮勸而鄭君欣然附從至出</span>  
<span style="margin-left: 2em">己力而不憚真可使異端退聽儒術增氣然則周侯</span>  
<span style="margin-left: 2em">之於民鄭君之於子弟可謂得爲宰爲父兄之道矣</span>  
<span style="margin-left: 2em">是可書也故樂爲之書紹興庚辰季冬朔左承事郎</span>  
<span style="margin-left: 2em">新差簽書奉國軍節度判官廳公事許克昌譔</span>  
<span style="margin-left: 2em">紹熙修學記　學較爲育材之地近代從政者困於</span>  
<span style="margin-left: 2em">簿書期會急於財貨源流往往力不暇及春秋較藝</span>  
<span style="margin-left: 2em">朔望講經徒修故事至於黌宇之簡陋駸駸乎頹毁</span>  
<span style="margin-left: 2em">之域則恬不經意吁百工居肆以成其事士子不繇</span>  
<span style="margin-left: 2em">學而望其成就可乎眎欹弗支見漏弗補因循苟簡</span>  
<span style="margin-left: 2em">以延歲月則亦終至於頹毁而已雲間之學歲在甲</span>  
<span style="margin-left: 2em">子鼎新於蜀郡楊公壽亨規模雖不偉不壯亦具體</span>  
<span style="margin-left: 2em">而微閲時滋久風雨震凌圯漫不振鄉參錢公復加</span>  
<span style="margin-left: 2em">營繕棟宇爲之增壯自時厥後主盟學事者不爲無</span>  
<span style="margin-left: 2em">人新者渝壯者陋未聞以葺治爲言余眎事是邦日</span>  
<span style="margin-left: 2em">敚丹墨應酬之冗末年始與學長黃樅謀畫去蠧易</span>  
<span style="margin-left: 2em">堅補罅苴漏繪雘從新經始於癸丑嘉平節訖事於</span>  
<span style="margin-left: 2em">甲寅仲春自是堂可以講齋可以誦室可以寢步趨</span>  
<span style="margin-left: 2em">有廊廡膳羞有厨傳雖不能廣大前日之規模槩之</span>  
<span style="margin-left: 2em">舊觀爲差勝所以肄業其間者當如何囊螢牖雪編</span>  
<span style="margin-left: 2em">蒲緝柳古不可追若杜紛華甘򐂗鹽對聖賢商確古</span>  
<span style="margin-left: 2em">今以洗濯塵俗之胸襟磨礱雲霄之事業紆朱芥紫</span>  
<span style="margin-left: 2em">權輿於此可不知勉余舊亦繇學挍叨竊末第則所</span>  
<span style="margin-left: 2em">以期待諸生者蓋不敢不勉故自初嚴選補謹課程</span>  
<span style="margin-left: 2em">置門籍以司出人限齋宿以紏勤惰甚者慮廪給之</span>  
<span style="margin-left: 2em">不繼罷濫竽之員鐫與釜之粟亦既三載於兹教養</span>  
<span style="margin-left: 2em">之心未始少忘而作成之效竊有望焉紹熙甲寅季</span>  
<span style="margin-left: 2em">春朔奉議郎知秀州華亭縣主管勸農公事兼兵馬</span>  
<span style="margin-left: 2em">都監兼鹽場主管堰事借緋楊潛記</span>  
<span style="margin-left: 2em">嘉泰修學記　溧陽錢君爲縣之明年嘅念鄉較廢</span>  
<span style="margin-left: 2em">久不治焕新堂宇修飾齋廬几席具設庖廩整辦合</span>  
<span style="margin-left: 2em">試鄉邑人士充弟子員推簡貢士次補職秩人以合</span>  
<span style="margin-left: 2em">選之士蓋不獨課試文藝學政大畧可睹已於是其</span>  
<span style="margin-left: 2em">師生謀伐石以紀其事來謁記於至乃爲之言曰人</span>  
<span style="margin-left: 2em">受天地之中以生莫不有秉彜之性聖人君師天下</span>  
<span style="margin-left: 2em">恐其蔽於欲而無以自明也故爲之教學以啟廸之</span>  
<span style="margin-left: 2em">其序則君臣父子兄弟夫婦朋友其德則仁義禮智</span>  
<span style="margin-left: 2em">而已有詩書六藝之文而優游乎絃誦講說之中有</span>  
<span style="margin-left: 2em">干戈羽籥以爲舞管弦鐘鼓之聲以爲樂而習乎進</span>  
<span style="margin-left: 2em">退之度俯仰之節有釋菜賓射養老之事而熟乎等</span>  
<span style="margin-left: 2em">差隆殺之分尊老弟長之義所以開其知識而滌其</span>  
<span style="margin-left: 2em">心志和其血氣而增其美質上自天子諸侯之國都</span>  
<span style="margin-left: 2em">下達於黨庠衞序自少至長皆入於學走趨升降周</span>  
<span style="margin-left: 2em">旋揖遜其中者無非教也此所以學成於鄉化行於</span>  
<span style="margin-left: 2em">國風俗厚而王道易也三代衰先王所以教學者廢</span>  
<span style="margin-left: 2em">士習益卑民生益不致於理漢之賢君僅能立學京</span>  
<span style="margin-left: 2em">師一時長吏蓋已興禮殿置較官遣學者受業太常</span>  
<span style="margin-left: 2em">而其人士據經守道雖若專門名家然獨行君子皆</span>  
<span style="margin-left: 2em">鄉里之諸生伏節死義者是以扶漢鼎之將傾其勉</span>  
<span style="margin-left: 2em">於自修篤於爲義如此惜乎無三代教法以成就之</span>  
<span style="margin-left: 2em">也魏晉以來中更多故其爲不足議者至唐文治復</span>  
<span style="margin-left: 2em">興京師太學以至州縣置博士弟子各有差加之以</span>  
<span style="margin-left: 2em">教養或可以復三代之舊然州縣博士弟子皆役於</span>  
<span style="margin-left: 2em">有司名存而實亡失其職業雖唐人絺繪之習行義</span>  
<span style="margin-left: 2em">不如兩京純明亦其植立於鄉閭之間唐世傳循吏</span>  
<span style="margin-left: 2em">者十四五人無以學較爲事者獨韓愈延師生興禮</span>  
<span style="margin-left: 2em">教以餐錢計子本給之他可知已嗚呼鄉之有學教</span>  
<span style="margin-left: 2em">民之始也先王之所甚重而唐漢忽之其亦不知本</span>  
<span style="margin-left: 2em">矣國家上規黨庠術序之制詔立學州縣復頒教養</span>  
<span style="margin-left: 2em">之法於天下凡師生之員與教道之叙試補升進之</span>  
<span style="margin-left: 2em">則堂宇田疇餼廪之數見之大觀政和之書藹然三</span>  
<span style="margin-left: 2em">代厚民之意漢唐千餘年間思慮所未及者士生今</span>  
<span style="margin-left: 2em">時其不能考志厲業者負國家教養多矣華亭之學</span>  
<span style="margin-left: 2em">甲於諸縣往時士風之盛不止以文章第太常魁多</span>  
<span style="margin-left: 2em">士蓋至於學行淑鄉里事業在政府杖節不屈於彊</span>  
<span style="margin-left: 2em">虜擾攘之際争新法不便而槃樂於擯斥之地者可</span>  
<span style="margin-left: 2em">數也嗚呼士有廢於因循習有安於偷懦三二十年</span>  
<span style="margin-left: 2em">來鄉之善士退學於家塾長吏亦視爲迂緩不切之</span>  
<span style="margin-left: 2em">務豈國家所以建學之意歟至生長鄉里進不能盡</span>  
<span style="margin-left: 2em">見前輩之風流退而求益於學較未能也竊聞之問</span>  
<span style="margin-left: 2em">學之道而規矩之守氣質之養而德性之充體有大</span>  
<span style="margin-left: 2em">小而所養之致察事有義利而力辨於毫釐之間過</span>  
<span style="margin-left: 2em">失相規而道義相勉長者有述而少者知敬使風化</span>  
<span style="margin-left: 2em">感於鄉閭而禮遜洽於田野則爲學其庶幾乎令尹</span>  
<span style="margin-left: 2em">能體國家之意矣凡游於學者其亦知所勉耶異時</span>  
<span style="margin-left: 2em">粹學碩德皆出於學風動鄉里而觀示四方顧不偉</span>  
<span style="margin-left: 2em">哉君名誾字子言出於名代耳濡目染故能留意吾</span>  
<span style="margin-left: 2em">道爲俗吏之所謂迂緩不切者其可書云嘉泰三年</span>  
<span style="margin-left: 2em">十二月望日寄理修職郎林至記</span>  
<span style="margin-left: 2em">端平重建學記　華亭故有先聖廟慶曆後郡縣皆</span>  
<span style="margin-left: 2em">有學於是縣立學宫以附於廟紹興紹熙雖加繕治</span>  
<span style="margin-left: 2em">然既數十年矣今令會稽楊君瑾始至振乏逮鰥束</span>  
<span style="margin-left: 2em">姦摘隱一年而樽節浮蠧儲米三千石爲平糴倉又</span>  
<span style="margin-left: 2em">一年度地鳩材遷大成殿前門後閣左右二廡而館</span>  
<span style="margin-left: 2em">鄉賢於夾又東甃泮水建講堂一齋廬八令佐之欵</span>  
<span style="margin-left: 2em">謁有次諸生之養有廪通爲垣以宫之翼翼沈沈邃</span>  
<span style="margin-left: 2em">嚴靖深伻來以圖請記成事予惟論學較者未有不</span>  
<span style="margin-left: 2em">傷教法之壞議科舉者未有不歎詞章之靡經生學</span>  
<span style="margin-left: 2em">士尚論比閭之法庠塾之教則悼王制之不可復嗚</span>  
<span style="margin-left: 2em">呼侯封井牧去籍二千年矣是未可以驟復也雖然</span>  
<span style="margin-left: 2em">治古終不可復歟曰不然也天命流行發生萬物雖</span>  
<span style="margin-left: 2em">五行異質四時異氣而仁義禮智之性惻隱羞惡辭</span>  
<span style="margin-left: 2em">遜是非之情則古今同此民也父慈子孝兄友弟恭</span>  
<span style="margin-left: 2em">夫義婦聽則古今同此心也古之爲教非彊其所無</span>  
<span style="margin-left: 2em">也亦惟即射鄉之會而正齒位所以養其尊賢敬老</span>  
<span style="margin-left: 2em">之良知即歲月之吉而讀教法所以發其尊君親上</span>  
<span style="margin-left: 2em">之深省逮己事而竣也則及諸閭塾所謂家有塾者</span>  
<span style="margin-left: 2em">合二十五家之子弟於閭門之左右而父師少師者</span>  
<span style="margin-left: 2em">爲之左右師以教之民生其間無習而非正人無行</span>  
<span style="margin-left: 2em">而非正道無聞而非正言志一心臧不見異物而遷</span>  
<span style="margin-left: 2em">故曰斯民也三代之所以直道而行也自鄉治廢而</span>  
<span style="margin-left: 2em">民散朝夕無閭塾之教歲時無庠序之屬死徙不相</span>  
<span style="margin-left: 2em">知出人不相友緩急不相赒而爲民父母者沈於簿</span>  
<span style="margin-left: 2em">書期會之衝矹矹辰夜救過不贍於是姦胥亂民緣</span>  
<span style="margin-left: 2em">絕爲欺吏以官爲市民與吏爲讐違其常心以陷於</span>  
<span style="margin-left: 2em">辟是雖曰世降俗敝已非一日獨不思古今一宇宙</span>  
<span style="margin-left: 2em">也而今之民顧不古若豈誠不古若哉而况吳中族</span>  
<span style="margin-left: 2em">姓人物之盛自東漢以來有聞於世逮魏晉而後彬</span>  
<span style="margin-left: 2em">彬輩出左太冲所謂高門鼎貴魁岸豪傑虞魏之昆</span>  
<span style="margin-left: 2em">顧陸之裔雖通言吳郡而居華亭者爲尤著蓋其地</span>  
<span style="margin-left: 2em">負海枕江平疇沃埜生民之資用饒衍得以畢力於</span>  
<span style="margin-left: 2em">所當事故士奮於學民興於仁代生人材以給時須</span>  
<span style="margin-left: 2em">自陸士衡士龍以至唐宰相元方象先希聲僅曰隨</span>  
<span style="margin-left: 2em">世以就功名至敬輿則巋然三代人物也涵養作成</span>  
<span style="margin-left: 2em">此豈一旦之功先正朱文公謂三代而下惟董仲舒</span>  
<span style="margin-left: 2em">諸葛孔明陸敬輿俱有王佐氣象自今觀之其論諫</span>  
<span style="margin-left: 2em">數百如推誠散利等疏無非聖賢之明訓其所闢邪</span>  
<span style="margin-left: 2em">說如寧我負人反經合道凡後世喪邦之說一繩以</span>  
<span style="margin-left: 2em">正嗚呼斯不亦間世之大儒乎乃自近歲遽以華亭</span>  
<span style="margin-left: 2em">爲不易冶令不具官胥横民肆簿書漫漶獄訟繁滋</span>  
<span style="margin-left: 2em">銓曹注擬往往有望望然去之者吁何至是哉記曰</span>  
<span style="margin-left: 2em">凡釋奠者必有合也或謂合他國之先賢而祀之然</span>  
<span style="margin-left: 2em">則是邦有如宣公自可爲人物之標準地靈人傑千</span>  
<span style="margin-left: 2em">古不磨作而興之則非守令事邪唐人詩稱敬輿爲</span>  
<span style="margin-left: 2em">縣人而志不書其何以爲刑善化俗之助楊君建學</span>  
<span style="margin-left: 2em">之初揭堂曰明善合子思孟子相傳之要旨與諸生</span>  
<span style="margin-left: 2em">發明爲己之學冠珮林立聽者皆竦嗚呼千萬人之</span>

<span style="margin-left: 2em">孫承恩府學學田碑記　國家聚俊髦之士於學既</span>  
<span style="margin-left: 2em">制爲廩餼之養而良有司廣上德意則復田焉故田</span>  
<span style="margin-left: 2em">也者所以養士也松爲學雖舊而故無田晉江黃侯</span>  
<span style="margin-left: 2em">潤以夏官正郎來蒞治加意學較而獨以無田病會</span>  
<span style="margin-left: 2em">民有匿田避稅者侯廉得之悉以畀學爲畝凡二百</span>  
<span style="margin-left: 2em">四十有奇於是松之學有田自黃侯始侯既有田以</span>  
<span style="margin-left: 2em">養士矣而養之爲義非可一端盡也頤之彖曰頤貞</span>  
<span style="margin-left: 2em">吉觀頤自求口實養人者與養於人者之自養皆有</span>  
<span style="margin-left: 2em">道矣諸君子其無負侯養之之心哉予樂侯有是舉</span>  
<span style="margin-left: 2em">故以養之大義復諸文學之請</span>  
<span style="margin-left: 2em">陳繼儒五學學田碑記　大中丞徐公鎮江南甫下</span>  
<span style="margin-left: 2em">車檄四郡長吏曰今天下賦煩役重吳爲最吳中民</span>  
<span style="margin-left: 2em">苦田士苦無田坐是日益貧惟四郡爲最此皆我司</span>  
<span style="margin-left: 2em">土者責也甦百姓之困無若清役田欲贍多士之貧</span>  
<span style="margin-left: 2em">無若置學田於是嚴查四郡花詭奉　旨永著爲令</span>  
<span style="margin-left: 2em">勒石成書矣適蘇郡丞許君攝開務得滸墅羡金六</span>  
<span style="margin-left: 2em">千一百有奇牒聞大中丞大中丞質之直指房公薛</span>  
<span style="margin-left: 2em">公曰以此贍士可乎松郡郡守張公受命銀必親發</span>  
<span style="margin-left: 2em">田必躬勘刻畫圖號使售田者不敢借瘠爲腴佃田</span>  
<span style="margin-left: 2em">者不敢隱多爲寡至是而大中丞愛民養士之心始</span>  
<span style="margin-left: 2em">兩快而無遺憾矣古者士有塾塾有田故高才生餼</span>  
<span style="margin-left: 2em">於官者循故額止矣而士之蛙竈不黔螢案不膏鶉</span>  
<span style="margin-left: 2em">衣不結鰥居不伉馬鬣不封者得大中丞而始克有</span>  
<span style="margin-left: 2em">濟善一履畝有籍徵租有程歲出有經歲入有會塞</span>  
<span style="margin-left: 2em">奸詭隱射之門杜豪强兼并之竇善二非贖鍰非没</span>  
<span style="margin-left: 2em">産非强富人之樂輸者取諸榷羡而自足善三以榷</span>  
<span style="margin-left: 2em">羡聞之　朝則恐開增額之漸置之公家則又恐那</span>  
<span style="margin-left: 2em">移飛借或化爲烏有子虛今不惟貧士沾恩抑且大</span>  
<span style="margin-left: 2em">中丞見節善四松學田創自宋泰寧間又再創於郡</span>  
<span style="margin-left: 2em">守黃公潤歲久籍亡不聞有給自大中丞者有之自</span>  
<span style="margin-left: 2em">徐公始善五大中丞起家松司理人疑其義切并州</span>  
<span style="margin-left: 2em">而推之徧及於旁郡邑子弟無公門桃李之私而有</span>  
<span style="margin-left: 2em">萬物一體之量善六一舉而六善具大中丞足以記</span>  
<span style="margin-left: 2em">矣說者曰無恒産而有恒心惟士爲然嗟乎士當以</span>  
<span style="margin-left: 2em">此自責上不當以此責士顔氏之貧也而簞瓢曾子</span>  
<span style="margin-left: 2em">之貧也而肘見子路之貧也而負米聖門且然而况</span>  
<span style="margin-left: 2em">後世之寒書生獨望其以苦節固窮見夫乃非人情</span>  
<span style="margin-left: 2em">乎然則大中丞之學田其關係於士風士氣亦甚弘</span>  
<span style="margin-left: 2em">且鉅矣雖然易之頤有云觀頤吉觀其所養也賾貞</span>  
<span style="margin-left: 2em">吉養正則吉也夫士能養正而後始不負大中丞置</span>  
<span style="margin-left: 2em">田養士之德意請以爲記并以爲松士勸焉時萬曆</span>  
<span style="margin-left: 2em">癸丑</span>  
<span style="margin-left: 2em">張鼐府學清田養士碑記　淮南王公元玉爲吾郡</span>  
<span style="margin-left: 2em">學博士長是歲冬來蒞事進諸士剖析四子六經奥</span>  
<span style="margin-left: 2em">義指陳　高皇帝教士功令甚備翕然鼓舞公且瞿</span>  
<span style="margin-left: 2em">然思曰學宫有養賢堂左右齋居庖湢具在堂後傑</span>  
<span style="margin-left: 2em">閣藏書具在而晝掩無問奇者田畝歲入亦具在爲</span>  
<span style="margin-left: 2em">骫役所窟穴至無能詰問則司教者之失職謂何即</span>  
<span style="margin-left: 2em">請於當事躬暑雨行阡陌二十餘日一旦姧竇盡露</span>  
<span style="margin-left: 2em">於是田還之學食還之士諸生無復以饑寒隳名檢</span>  
<span style="margin-left: 2em">而公之教始無不得之士矣是粟也舊爲役人半入</span>  
<span style="margin-left: 2em">私槖輒慳其出以抑士而概目之爲賑士非貧與死</span>  
<span style="margin-left: 2em">鄰弗願受粟公品予格爲三除貲産能供俯仰弗給</span>  
<span style="margin-left: 2em">士有貧而勵志節者給勤學問者給有困阨當周者</span>  
<span style="margin-left: 2em">給仍顔其倉曰儲士而官爲授餐人人視升斗若榮</span>  
<span style="margin-left: 2em">施益砥礪文行期無負公田養云計公所清田合撫</span>  
<span style="margin-left: 2em">臺簡我徐公所置少司寇徐公陟太守徐公琳及尚</span>  
<span style="margin-left: 2em">寶肇惠所樂助總爲畝幾九百華亭章侯允儒復請</span>  
<span style="margin-left: 2em">發助贍太僕少卿吳公烱捐田租助諸生入試之役</span>  
<span style="margin-left: 2em">割田二百五十畝屬府學半以助養皆感公義而思</span>  
<span style="margin-left: 2em">佐其盛舉也己未三月擢佐南雍教事爲礱石記之</span>
