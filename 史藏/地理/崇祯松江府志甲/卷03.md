## 崇祯松江府志卷之三　镇市　衢巷　坊表　桥梁　堰闸

<span style="margin-left: 3em">镇市</span>  
<span style="margin-left: 1em">民亦所在而聚矣城可暨乎古曰聚唐始曰镇朝前市</span>  
<span style="margin-left: 1em">后斯亦都邑之翼卫也虽然𩦱师驵伯如肆鲍鱼远市</span>  
<span style="margin-left: 1em">习易去市心难古以市朝并称何为哉</span>  
<span style="margin-left: 1em">风泾镇或称枫溪在一保一名白牛市市置邮驿皆以</span>  
<span style="margin-left: 2em">泾名前志桥梁九市南半属嘉兴县东驰泖桥有澄</span>  
<span style="margin-left: 2em">鉴寺楼阁浮屠为襟带之胜今寺存桥断矣</span>  
<span style="margin-left: 2em"><sub class="note-yuan">瞿佑过风泾诗雨余新绿涨横塘红板桥边矮粉墙知是清明时节到秋千一架倚垂杨金景西怀风泾诗白牛塘上酒旗中南北长桥卧绿虹烟寺晓钟蕉叶雨水晴楼槛落花风衣冠文物声名蔼舟楫鱼盐利泽通东望云间酬二陆举杯南向酹宣公贝琼清江集云风泾多荷花周廻三里仿佛有钱塘西湖之胜与筠谷同赋南风隔浦闻花气菡萏红开十里花宫女三更环白帝洞庭千顷落明霞凿池不待烦灵运载酒浑疑过若耶何日与君追胜赏满船</sub></span>  
<span style="margin-left: 2em">明月唱吴娃<sub class="note-jiao">校：詩名篇名原書皆後空以示今一仿前志刪空而框出以下倣此</sub></span>  
<span style="margin-left: 1em">朱泾镇一称珠溪在四保胥浦乡之里古于此置大盈</span>  
<span style="margin-left: 2em">务中有东西法忍寺楼阁翚飞河梁虹峙为镇之胜</span>  
<span style="margin-left: 2em">概昔诗人称为落照湾谓自府望落日于此也东南</span>  
<span style="margin-left: 2em">有溪市二曰吕巷杨巷南遵水道海盐北繇李塔汇</span>  
<span style="margin-left: 2em">而登县</span>  
<span style="margin-left: 1em">亭林镇在十保此地有宝云寺为梁顾野王故居有读</span>  
<span style="margin-left: 2em">书堆烽楼基诸迹旧置金山巡司相传居之故垣介</span>  
<span style="margin-left: 2em">一髹甓锲云东七里西七里秪在七七里厥后或识</span>  
<span style="margin-left: 2em">以为谜辞其在漆里窃之金也云间赋云于南迫野</span>  
<span style="margin-left: 2em">王之所人亡而吚唔声寂春归而青深林莽金碧久</span>  
<span style="margin-left: 2em">瘗土颓甲第何为七七之说而成他人之利</span>  
<span style="margin-left: 2em"><sub class="note-yuan">贝琼亭林漫兴野王读书处一曲锁风烟客记萧梁日僧谈石晋年黄金曾布地沧海复成田遗构丹青落回头一惘然又出亭林道楼台尚自疑无边春草色不定野云姿未就庞公隐空怀惠远期飘飘何所适重拟始茅茨</sub></span>  
<span style="margin-left: 1em">沙冈镇在三十六保前志古冈身凡三所南属于海北</span>  
<span style="margin-left: 2em">抵松江长一百里其二所曰竹冈紫冈与镇所称三</span>  
<span style="margin-left: 2em">相去凡五百里府道上海经焉通志云入土数尺皆</span>  
<span style="margin-left: 2em">螺蚌壳世传海中涌三浪而成今市北数里下皆黄</span>  
<span style="margin-left: 2em">沙乡人甃砌用之</span>  
<span style="margin-left: 1em">莘庄镇一名莘溪在三十六保北邻七宝南近乌泾镇</span>  
<span style="margin-left: 2em">其地产花少稻本瘠土也民居数千指多诗书弦诵</span>  
<span style="margin-left: 2em">之家居然称镇有春申施水二庵皆古迹</span>  
<span style="margin-left: 2em">元叶李赘居莘溪李为叶梦得之孙永乐初叶宗行</span>  
<span style="margin-left: 2em">治水有功擢钱塘令所谓钱塘一叶清者即其后也</span>  
<span style="margin-left: 2em">朱尚书恩自其祖徙居后遂称仕族俞世美赘于周</span>  
<span style="margin-left: 2em">布政可竹亦家于此自号叶竹即奉祀周墓墓在镇</span>  
<span style="margin-left: 2em">西今一抔土耳后俞氏有发科第者墓上必产异草</span>  
<span style="margin-left: 2em">如芝</span>  
<span style="margin-left: 1em">南桥镇一名南梁在十三保缘北有桥俱傍横泾曰北</span>  
<span style="margin-left: 2em">桥与此相峙故名北桥古亦镇也有大冈路直达二</span>  
<span style="margin-left: 2em">桥长四十余里中阻黄浦亦尝搆梁即乡人譌为黄</span>  
<span style="margin-left: 2em">土桥者宋诗人陈藏一常隐于斯置巡税以古盐塲</span>  
<span style="margin-left: 2em">戚漴名境之幽胜有明竹院冠其前萧塘寺屏其后</span>  
<span style="margin-left: 1em">萧塘镇一名萧溪在南桥北镇有崇福寺卫文节之故</span>  
<span style="margin-left: 2em">居也自昔富繁近世宋瑮宋瑛兄弟相继登科故其</span>  
<span style="margin-left: 2em">名益著</span>  
<span style="margin-left: 2em"><sub class="note-yuan">洪武乙丑袁海叟凯偕王叔明王元吉钱伯云张梦辰金彦辰元夕观灯会于萧塘吴隐居景元家举酒属客曰七人四百九十岁为首句以灯字为韵赋诗云七人四百九十岁吴家堂上看花灯皓首庞眉方满座金杯玉碗出清冰三寸黄柑浑似蜜百壶春酒况如渑今日相逢总知己老夫欢喜欲飞腾陶南村过萧塘寺诗不到萧塘寺流光十五朞岸倾街甃裂寺废梵幢欹第宅流荒址垣墉易败篱相知无一在遗迹动伤悲</sub></span>  
<span style="margin-left: 1em">张泾堰镇一名张溪在七保去县南五十里宋人堰海</span>  
<span style="margin-left: 2em">十八所之一也镇故有岳祠重严华好杨竹西有不</span>  
<span style="margin-left: 2em">碍云山楼面海对山浩然清越自府之金山孔道也</span>  
<span style="margin-left: 1em">小官镇一名筿观距张堰南十二里浦东盐司旧在张</span>  
<span style="margin-left: 2em">堰与牢盆相远别建官衙于此俗呼为小官衙镇以</span>  
<span style="margin-left: 2em">是名洪武十九年筑城立金山卫于此以御海寇遂</span>  
<span style="margin-left: 2em">为重地云</span>  
<span style="margin-left: 1em">柘林镇在十二保去县东南七十二里地连柘山王介</span>  
<span style="margin-left: 2em">甫诗所谓柘林著湖山斯名之义也镇有方广院蔡</span>  
<span style="margin-left: 2em">侍郎祠在焉右距戚睦泾曹泾为海人辐辏之步凡</span>  
<span style="margin-left: 2em">浙闽客商贩海木至柘林漴缺地方必繇该堡把总</span>  
<span style="margin-left: 2em">官验放过塘近年进香普陀者岁首多从漴缺取道</span>  
<span style="margin-left: 2em">入洋比之转入浙江定海者虽为便道海舶出没亦</span>  
<span style="margin-left: 2em">禁防疎密之要也</span>  
<span style="margin-left: 1em">青村镇一名青林在十五保嘉禾志村作墩有著姓陶</span>  
<span style="margin-left: 2em">氏家焉俗呼陶家宅头逾南十五里岸海置盐司北</span>  
<span style="margin-left: 2em">负横溪里洪武十九年筑城立千户所于镇以御海</span>  
<span style="margin-left: 2em">寇</span>  
<span style="margin-left: 1em">陶宅镇事见青村亦以陶姓著袁海叟集有兵后大醉</span>  
<span style="margin-left: 2em">陶与权宅此也诗云酒到愁肠味自醇花因白发更</span>  
<span style="margin-left: 2em">精神儿童休笑灯前舞老子今存死后身何处江湖</span>  
<span style="margin-left: 2em">为乐土谁家门户有闲人多情独有陶征士醉过清</span>  
<span style="margin-left: 2em">秋不厌频设有巡简司税课局</span>  
<span style="margin-left: 2em">镇有纯阳庵陶宣差子与权建岁久而圮正统间俞</span>  
<span style="margin-left: 2em">梦梅倡举重新后又改为土谷祠元末有杨渔溪李</span>  
<span style="margin-left: 2em">稼翁华云林姚愚默寓隐于此赋陶宅八景八景为</span>  
<span style="margin-left: 2em">西河晚色南园霁景道院幽栖玄桥纵步东庵华表</span>  
<span style="margin-left: 2em">北宅故墟镇楼更鼓市巷渔灯</span>  
<span style="margin-left: 1em">叶谢镇在八保与萧塘邻以二姓得名通志称居民稠</span>  
<span style="margin-left: 2em">密商贾辐辏有税课局</span>  
<span style="margin-left: 2em"><sub class="note-yuan">顾禄叶谢道中诗云月落鸡鸣酒半消舟人催起趁春潮梅花纸帐山房静输与闲僧睡日高</sub></span>  
<span style="margin-left: 1em">兴塔市在二保去泖桥十里余旧有兴塔院故名谚曰</span>  
<span style="margin-left: 2em">兴塔无塔即其地也</span>  
<span style="margin-left: 1em">杨巷市在五保与吕巷俱称市与朱泾鳞次鼎分旧名</span>  
<span style="margin-left: 2em">镇非也</span>  
<span style="margin-left: 1em">吕巷市一名璜溪在四保元时吕良佐以豪侠闻创应</span>  
<span style="margin-left: 2em">奎文会招来儒彦其子恂从学杨维祯有铁砚斋记</span>  
<span style="margin-left: 2em">故市以吕名有太平寺松风阁玉秀桥皆宋时建</span>  
<span style="margin-left: 2em"><sub class="note-yuan">袁海叟常居璜溪有璜溪寓所诗高林深树气冥冥野色波光更满汀草阁雨晴鸣翡翠花畦风暖入蜻蜓书成已与山公绝赋就惟教阿买听犹未忘情是杯酒尚烦邻里致盆瓶贝琼出璜溪诗白首事章句不登金马门空名苦为累遂枉三聘烦一瓢虽屡空五鼎非所存愿偕田父游卜宅溪南村霜寒收柿栗日暮牧鸡豚去矣从吾好得与巢许论</sub></span>  
<span style="margin-left: 1em">泗泾市一名泗滨在三十七保因泗泾塘故名孙道明</span>  
<span style="margin-left: 2em">其里人也元时水深林茂南浦环其前道明有水光</span>  
<span style="margin-left: 2em">山色舟自号停云子陶宗仪南村草堂在焉隐居于</span>  
<span style="margin-left: 2em">此故称泗滨老人袁海叟望南村诗云野水纵横不</span>  
<span style="margin-left: 2em">计深襍花前后自成园鱼虾欲上人人取鸟鹊归来</span>  
<span style="margin-left: 2em">处处喧但得茆茨容老大即将耕凿付儿孙淮南未</span>  
<span style="margin-left: 2em">定江南乱潦倒无归却断魂即此地也今民居聚商</span>  
<span style="margin-left: 2em">贾集有小武当香火春时甚盛</span>  
<span style="margin-left: 1em">北钱市在四十一保石湖塘上与南钱相望盖一姓分</span>  
<span style="margin-left: 2em">处为市也宋末元兵入华亭南钱犹保聚不下将军</span>  
<span style="margin-left: 2em">杨扫地怒几屠之赖义士殷澄得免澄后自号浪翁</span>  
<span style="margin-left: 2em">杨铁崖撰其碑</span>  
<span style="margin-left: 3em">已上属华亭</span>  
<span style="margin-left: 1em">吴会镇在十六保去上海东南五十四里本吴汇以指</span>  
<span style="margin-left: 2em">吴会于云间语易今名按吴会见曹子建诗云行行</span>  
<span style="margin-left: 2em">至吴会孔明云东连吴会蔡邕传云远纵吴会谢承</span>  
<span style="margin-left: 2em">后汉书施延传云吴会未分吴张纮谓收兵吴会王</span>  
<span style="margin-left: 2em">羲之云赋重役繁吴会尤甚盖吴会亦吴越合称之</span>  
<span style="margin-left: 2em">词耳市置巡司曰郛城有塔庙即今浄土寺地接瓶</span>  
<span style="margin-left: 2em">山山皆瓶砾高楼三十楹许宋酒库所遗也今亡</span>  
<span style="margin-left: 1em">乌泥泾镇在二十六保界华上两县间尝有田父得古</span>  
<span style="margin-left: 2em">碑地名宾贤里通志云宋季著姓张百五居之富埒</span>  
<span style="margin-left: 2em">侯伯至元间张瑄以海漕隆显治第其中后又有张</span>  
<span style="margin-left: 2em">姓者家累千金称张有钱邑之仓廪且贮于兹以故</span>  
<span style="margin-left: 2em">人民盛于他镇迄今所存惟巡税二司南北两闸耳</span>  
<span style="margin-left: 2em">税名芦子者地近沪渎俗所谓芦子城也嘉靖间泾</span>  
<span style="margin-left: 2em">水淤涸寥落益非旧矣</span>  
<span style="margin-left: 2em">王逢避地隐居乌泾得张氏故址辟为最闲园其怀</span>  
<span style="margin-left: 2em">先民赋序云乌泾世儒仅有张氏其先开封人仕高</span>  
<span style="margin-left: 2em">宗仪鸾司门既扈南渡乐是卜居后浸昌大离列苑</span>  
<span style="margin-left: 2em">第曰太祝曰上舍曰进士角德翼义咸负誉望曰骥</span>  
<span style="margin-left: 2em">院质木饶訾益丕拓湖苑属元初官胁售其第为仓</span>  
<span style="margin-left: 2em">征逻司族就衰替十有三世孙隆力田授徒幸延余</span>  
<span style="margin-left: 2em">绪搜攟遗迹疏洿刬莱于是小山平林襟带沟池凡</span>  
<span style="margin-left: 2em">树石岩磴以植以辟积劳于躬粗有成趣至正丙申</span>  
<span style="margin-left: 2em">苗兵毁掠其斋岿存又十年隆尽归之于予乃因其</span>  
<span style="margin-left: 2em">旧稍新之增崇浚<sub class="note-jiao">校：原書作峻當浚訛字今改</sub>深标奇著美更遂</span>  
<span style="margin-left: 2em">号曰最闲园且次其所在用载咏之尤惧事迹渐湮</span>  
<span style="margin-left: 2em">复名其山曰先民一丘沟曰先民一壑立表两间清</span>  
<span style="margin-left: 2em">挹秀粹庶乎见景慕于前修抑示崇广于来裔也</span>  
<span style="margin-left: 1em">下砂镇在十九保去上海东南六十里一名鹤沙俗传</span>  
<span style="margin-left: 2em">县居上洋镇峙南而近海故名旧有盐课司后迁新</span>  
<span style="margin-left: 2em">塲镇而盐仓则自周浦徙居之今亦废宋丞相吴潜</span>  
<span style="margin-left: 2em">侍父读书处镇多巧工精刺绣称下砂绣云时有鹤</span>  
<span style="margin-left: 2em">自海外飞至方顶绿足龟文相传此胎禽也华亭鹤</span>  
<span style="margin-left: 2em">即此</span>  
<span style="margin-left: 1em">新塲镇一名石笋里距下砂九里一名南下砂元初迁</span>  
<span style="margin-left: 2em">盐塲于此故名塲赋为两浙最北桥税司杜浦巡司</span>  
<span style="margin-left: 2em">皆徙居焉四时海鲜不绝歌楼酒肆贾衒繁华县未</span>  
<span style="margin-left: 2em">过也宋元祐初里士瞿时彦尝访吴潜读书处营置</span>  
<span style="margin-left: 2em">义学今废而镇之贾贩犹盛</span>
