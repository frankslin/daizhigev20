## 崇禎松江府志卷之三　鎮市　衢巷　坊表　橋樑　堰閘

<span style="margin-left: 3em">鎮市</span>  
<span style="margin-left: 1em">民亦所在而聚矣城可暨乎古曰聚唐始曰鎮朝前市</span>  
<span style="margin-left: 1em">後斯亦都邑之翼衛也雖然𩦱師駔伯如肆鮑魚遠市</span>  
<span style="margin-left: 1em">習易去市心難古以市朝並稱何爲哉</span>  
<span style="margin-left: 1em">風涇鎮或稱楓溪在一保一名白牛市市置郵驛皆以</span>  
<span style="margin-left: 2em">涇名前志橋梁九市南半屬嘉興縣東馳泖橋有澄</span>  
<span style="margin-left: 2em">鑑寺樓閣浮屠爲襟帶之勝今寺存橋斷矣</span>  
<span style="margin-left: 2em"><sub class="note-yuan">瞿佑過風涇詩雨餘新綠漲横塘紅板橋邊矮粉墻知是清明時節到鞦韆一架倚垂楊金景西懷風涇詩白牛塘上酒旗中南北長橋臥綠虹煙寺曉鐘蕉葉雨水晴樓檻落花風衣冠文物聲名藹舟楫魚鹽利澤通東望雲間酬二陸舉杯南向酹宣公貝瓊清江集云風涇多荷花周廻三里彷彿有錢塘西湖之勝與筠谷同賦南風隔浦聞花氣菡萏紅開十里花宫女三更環白帝洞庭千頃落明霞鑿池不待煩靈運載酒渾疑過若耶何日與君追勝賞滿船</sub></span>  
<span style="margin-left: 2em">明月唱吳娃<sub class="note-jiao">校：詩名篇名原書皆後空以示今一仿前志刪空而框出以下倣此</sub></span>  
<span style="margin-left: 1em">朱涇鎮一稱珠溪在四保胥浦鄉之里古於此置大盈</span>  
<span style="margin-left: 2em">務中有東西法忍寺樓閣翬飛河梁虹峙爲鎮之勝</span>  
<span style="margin-left: 2em">概昔詩人稱爲落照灣謂自府望落日於此也東南</span>  
<span style="margin-left: 2em">有溪市二曰呂巷楊巷南遵水道海鹽北繇李塔匯</span>  
<span style="margin-left: 2em">而登縣</span>  
<span style="margin-left: 1em">亭林鎮在十保此地有寶雲寺爲梁顧野王故居有讀</span>  
<span style="margin-left: 2em">書堆烽樓基諸蹟舊置金山巡司相傳居之故垣介</span>  
<span style="margin-left: 2em">一髹甓鍥云東七里西七里秪在七七里厥後或識</span>  
<span style="margin-left: 2em">以爲謎辭其在漆裏竊之金也雲間賦云於南迫野</span>  
<span style="margin-left: 2em">王之所人亡而吚唔聲寂春歸而青深林莽金碧久</span>  
<span style="margin-left: 2em">瘞土頽甲第何爲七七之說而成他人之利</span>  
<span style="margin-left: 2em"><sub class="note-yuan">貝瓊亭林漫興野王讀書處一曲鎖風煙客記蕭梁日僧談石晉年黃金曾布地滄海復成田遺構丹青落回頭一惘然又出亭林道樓臺尚自疑無邊春草色不定野雲姿未就龐公隱空懷惠遠期飄飄何所適重擬始茅茨</sub></span>  
<span style="margin-left: 1em">沙岡鎮在三十六保前志古岡身凡三所南屬於海北</span>  
<span style="margin-left: 2em">抵松江長一百里其二所曰竹岡紫岡與鎮所稱三</span>  
<span style="margin-left: 2em">相去凡五百里府道上海經焉通志云入土數尺皆</span>  
<span style="margin-left: 2em">螺蚌殻世傳海中湧三浪而成今市北數里下皆黃</span>  
<span style="margin-left: 2em">沙鄉人甃砌用之</span>  
<span style="margin-left: 1em">莘莊鎮一名莘溪在三十六保北鄰七寶南近烏涇鎮</span>  
<span style="margin-left: 2em">其地産花少稻本瘠土也民居數千指多詩書絃誦</span>  
<span style="margin-left: 2em">之家居然稱鎮有春申施水二菴皆古蹟</span>  
<span style="margin-left: 2em">元葉李贅居莘溪李爲葉夢得之孫永樂初葉宗行</span>  
<span style="margin-left: 2em">治水有功擢錢塘令所謂錢塘一葉清者即其後也</span>  
<span style="margin-left: 2em">朱尚書恩自其祖徙居後遂稱仕族俞世美贅於周</span>  
<span style="margin-left: 2em">布政可竹亦家於此自號葉竹即奉祀周墓墓在鎮</span>  
<span style="margin-left: 2em">西今一抔土耳後俞氏有發科第者墓上必産異草</span>  
<span style="margin-left: 2em">如芝</span>  
<span style="margin-left: 1em">南橋鎮一名南梁在十三保緣北有橋俱傍横涇曰北</span>  
<span style="margin-left: 2em">橋與此相峙故名北橋古亦鎮也有大岡路直達二</span>  
<span style="margin-left: 2em">橋長四十餘里中阻黃浦亦嘗搆梁即鄉人譌爲黃</span>  
<span style="margin-left: 2em">土橋者宋詩人陳藏一常隱於斯置巡稅以古鹽塲</span>  
<span style="margin-left: 2em">戚漴名境之幽勝有明竹院冠其前蕭塘寺屏其後</span>  
<span style="margin-left: 1em">蕭塘鎮一名蕭溪在南橋北鎮有崇福寺衛文節之故</span>  
<span style="margin-left: 2em">居也自昔富繁近世宋瑮宋瑛兄弟相繼登科故其</span>  
<span style="margin-left: 2em">名益著</span>  
<span style="margin-left: 2em"><sub class="note-yuan">洪武乙丑袁海叟凱偕王叔明王元吉錢伯雲張夢辰金彦辰元夕觀燈會於蕭塘吳隱居景元家舉酒屬客曰七人四百九十歲爲首句以燈字爲韻賦詩云七人四百九十歲吳家堂上看花燈皓首龐眉方滿座金盃玉碗出清冰三寸黃柑渾似蜜百壺春酒况如澠今日相逢總知己老夫歡喜欲飛騰陶南村過蕭塘寺詩不到蕭塘寺流光十五朞岸傾街甃裂寺廢梵幢欹第宅流荒址垣墉易敗籬相知無一在遺跡動傷悲</sub></span>  
<span style="margin-left: 1em">張涇堰鎮一名張溪在七保去縣南五十里宋人堰海</span>  
<span style="margin-left: 2em">十八所之一也鎮故有嶽祠重嚴華好楊竹西有不</span>  
<span style="margin-left: 2em">礙雲山樓面海對山浩然清越自府之金山孔道也</span>  
<span style="margin-left: 1em">小官鎮一名篠觀距張堰南十二里浦東鹽司舊在張</span>  
<span style="margin-left: 2em">堰與牢盆相遠別建官衙於此俗呼爲小官衙鎮以</span>  
<span style="margin-left: 2em">是名洪武十九年築城立金山衛於此以禦海寇遂</span>  
<span style="margin-left: 2em">爲重地云</span>  
<span style="margin-left: 1em">柘林鎮在十二保去縣東南七十二里地連柘山王介</span>  
<span style="margin-left: 2em">甫詩所謂柘林著湖山斯名之義也鎮有方廣院蔡</span>  
<span style="margin-left: 2em">侍郎祠在焉右距戚睦涇曹涇爲海人輻輳之步凡</span>  
<span style="margin-left: 2em">浙閩客商販海木至柘林漴缺地方必繇該堡把總</span>  
<span style="margin-left: 2em">官驗放過塘近年進香普陀者歲首多從漴缺取道</span>  
<span style="margin-left: 2em">入洋比之轉入浙江定海者雖爲便道海舶出没亦</span>  
<span style="margin-left: 2em">禁防疎密之要也</span>  
<span style="margin-left: 1em">青村鎮一名青林在十五保嘉禾志村作墩有著姓陶</span>  
<span style="margin-left: 2em">氏家焉俗呼陶家宅頭踰南十五里岸海置鹽司北</span>  
<span style="margin-left: 2em">負横溪里洪武十九年築城立千户所於鎮以禦海</span>  
<span style="margin-left: 2em">寇</span>  
<span style="margin-left: 1em">陶宅鎮事見青村亦以陶姓著袁海叟集有兵後大醉</span>  
<span style="margin-left: 2em">陶與權宅此也詩云酒到愁腸味自醇花因白髮更</span>  
<span style="margin-left: 2em">精神兒童休笑燈前舞老子今存死後身何處江湖</span>  
<span style="margin-left: 2em">爲樂土誰家門户有閒人多情獨有陶徵士醉過清</span>  
<span style="margin-left: 2em">秋不厭頻設有巡簡司稅課局</span>  
<span style="margin-left: 2em">鎮有純陽菴陶宣差子與權建歲久而圮正統間俞</span>  
<span style="margin-left: 2em">夢梅倡舉重新後又改爲土穀祠元末有楊漁溪李</span>  
<span style="margin-left: 2em">稼翁華雲林姚愚默寓隱於此賦陶宅八景八景爲</span>  
<span style="margin-left: 2em">西河晚色南園霽景道院幽棲玄橋縱步東菴華表</span>  
<span style="margin-left: 2em">北宅故墟鎮樓更鼓市巷漁燈</span>  
<span style="margin-left: 1em">葉謝鎮在八保與蕭塘鄰以二姓得名通志稱居民稠</span>  
<span style="margin-left: 2em">密商賈輻輳有稅課局</span>  
<span style="margin-left: 2em"><sub class="note-yuan">顧禄葉謝道中詩云月落雞鳴酒半消舟人催起趁春潮梅花紙帳山房靜輸與閒僧睡日高</sub></span>  
<span style="margin-left: 1em">興塔市在二保去泖橋十里餘舊有興塔院故名諺曰</span>  
<span style="margin-left: 2em">興塔無塔即其地也</span>  
<span style="margin-left: 1em">楊巷市在五保與呂巷俱稱市與朱涇鱗次鼎分舊名</span>  
<span style="margin-left: 2em">鎮非也</span>  
<span style="margin-left: 1em">呂巷市一名璜溪在四保元時呂良佐以豪俠聞創應</span>  
<span style="margin-left: 2em">奎文會招來儒彥其子恂從學楊維禎有鐵硯齋記</span>  
<span style="margin-left: 2em">故市以呂名有太平寺松風閣玉秀橋皆宋時建</span>  
<span style="margin-left: 2em"><sub class="note-yuan">袁海叟常居璜溪有璜溪寓所詩高林深樹氣冥冥野色波光更滿汀草閣雨晴鳴翡翠花畦風暖入蜻蜓書成已與山公絶賦就惟教阿買聽猶未忘情是杯酒尚煩鄰里致盆瓶貝瓊出璜溪詩白首事章句不登金馬門空名苦爲累遂枉三聘煩一瓢雖屢空五鼎非所存願偕田父遊卜宅溪南村霜寒收柿栗日暮牧雞豚去矣從吾好得與巢許論</sub></span>  
<span style="margin-left: 1em">泗涇市一名泗濱在三十七保因泗涇塘故名孫道明</span>  
<span style="margin-left: 2em">其里人也元時水深林茂南浦環其前道明有水光</span>  
<span style="margin-left: 2em">山色舟自號停雲子陶宗儀南村草堂在焉隱居於</span>  
<span style="margin-left: 2em">此故稱泗濱老人袁海叟望南村詩云野水縱横不</span>  
<span style="margin-left: 2em">計深襍花前後自成園魚蝦欲上人人取鳥鵲歸來</span>  
<span style="margin-left: 2em">處處喧但得茆茨容老大即將耕鑿付兒孫淮南未</span>  
<span style="margin-left: 2em">定江南亂潦倒無歸却斷魂即此地也今民居聚商</span>  
<span style="margin-left: 2em">賈集有小武當香火春時甚盛</span>  
<span style="margin-left: 1em">北錢市在四十一保石湖塘上與南錢相望蓋一姓分</span>  
<span style="margin-left: 2em">處爲市也宋末元兵入華亭南錢猶保聚不下將軍</span>  
<span style="margin-left: 2em">楊掃地怒幾屠之賴義士殷澄得免澄後自號浪翁</span>  
<span style="margin-left: 2em">楊鐵崖撰其碑</span>  
<span style="margin-left: 3em">已上屬華亭</span>  
<span style="margin-left: 1em">吳會鎮在十六保去上海東南五十四里本吳匯以指</span>  
<span style="margin-left: 2em">吳會於雲間語易今名按吳會見曹子建詩云行行</span>  
<span style="margin-left: 2em">至吳會孔明云東連吳會蔡邕傳云遠縱吳會謝承</span>  
<span style="margin-left: 2em">後漢書施延傳云吳會未分吳張紘謂收兵吳會王</span>  
<span style="margin-left: 2em">羲之云賦重役繁吳會尤甚蓋吳會亦吳越合稱之</span>  
<span style="margin-left: 2em">詞耳市置巡司曰郛城有塔廟即今浄土寺地接瓶</span>  
<span style="margin-left: 2em">山山皆瓶礫高樓三十楹許宋酒庫所遺也今亡</span>  
<span style="margin-left: 1em">烏泥涇鎮在二十六保界華上兩縣間嘗有田父得古</span>  
<span style="margin-left: 2em">碑地名賓賢里通志云宋季著姓張百五居之富埒</span>  
<span style="margin-left: 2em">侯伯至元間張瑄以海漕隆顯治第其中後又有張</span>  
<span style="margin-left: 2em">姓者家累千金稱張有錢邑之倉廪且貯於兹以故</span>  
<span style="margin-left: 2em">人民盛於他鎮迄今所存惟巡稅二司南北兩閘耳</span>  
<span style="margin-left: 2em">稅名蘆子者地近滬瀆俗所謂蘆子城也嘉靖間涇</span>  
<span style="margin-left: 2em">水淤涸寥落益非舊矣</span>  
<span style="margin-left: 2em">王逢避地隱居烏涇得張氏故址闢爲最閒園其懷</span>  
<span style="margin-left: 2em">先民賦序云烏涇世儒僅有張氏其先開封人仕高</span>  
<span style="margin-left: 2em">宗儀鸞司門既扈南渡樂是卜居後浸昌大離列苑</span>  
<span style="margin-left: 2em">第曰太祝曰上舍曰進士角德翼義咸負譽望曰驥</span>  
<span style="margin-left: 2em">院質木饒訾益丕拓湖苑屬元初官脅售其第爲倉</span>  
<span style="margin-left: 2em">征邏司族就衰替十有三世孫隆力田授徒幸延餘</span>  
<span style="margin-left: 2em">緒搜攟遺跡疏洿剗萊於是小山平林襟帶溝池凡</span>  
<span style="margin-left: 2em">樹石巖磴以植以闢積勞於躬粗有成趣至正丙申</span>  
<span style="margin-left: 2em">苗兵燬掠其齋巋存又十年隆盡歸之於予乃因其</span>  
<span style="margin-left: 2em">舊稍新之增崇浚<sub class="note-jiao">校：原書作峻當浚訛字今改</sub>深標奇著美更遂</span>  
<span style="margin-left: 2em">號曰最閒園且次其所在用載詠之尤懼事跡漸湮</span>  
<span style="margin-left: 2em">復名其山曰先民一丘溝曰先民一壑立表兩間清</span>  
<span style="margin-left: 2em">挹秀粹庶乎見景慕於前修抑示崇廣於來裔也</span>  
<span style="margin-left: 1em">下砂鎮在十九保去上海東南六十里一名鶴沙俗傳</span>  
<span style="margin-left: 2em">縣居上洋鎮峙南而近海故名舊有鹽課司後遷新</span>  
<span style="margin-left: 2em">塲鎮而鹽倉則自周浦徙居之今亦廢宋丞相吳潛</span>  
<span style="margin-left: 2em">侍父讀書處鎮多巧工精刺繡稱下砂繡云時有鶴</span>  
<span style="margin-left: 2em">自海外飛至方頂綠足龜文相傳此胎禽也華亭鶴</span>  
<span style="margin-left: 2em">即此</span>  
<span style="margin-left: 1em">新塲鎮一名石筍里距下砂九里一名南下砂元初遷</span>  
<span style="margin-left: 2em">鹽塲於此故名塲賦爲兩浙最北橋稅司杜浦巡司</span>  
<span style="margin-left: 2em">皆徙居焉四時海鮮不絶歌樓酒肆賈衒繁華縣未</span>  
<span style="margin-left: 2em">過也宋元祐初里士瞿時彦嘗訪吳潛讀書處營置</span>  
<span style="margin-left: 2em">義學今廢而鎮之賈販猶盛</span>
