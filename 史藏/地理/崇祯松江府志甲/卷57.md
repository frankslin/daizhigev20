## 崇祯松江府志卷之五十七　志余上（遗事）

<span style="margin-left: 3em">志余<sub class="note-yuan">遗事</sub></span>  
<span style="margin-left: 1em">采书购访以资郡乘不惜轻舟重币求之取信不取诞</span>  
<span style="margin-left: 1em">取常不取怪取其羽翼名教而不取暧昧垢秽之词庶</span>  
<span style="margin-left: 1em">几慎言其余哉昔徐铉好异凡宾客不能自通与失意</span>  
<span style="margin-left: 1em">而见绝者皆诡言以求合洪迈急成夷坚多取旧事改</span>  
<span style="margin-left: 1em">窜首尾年月名氏杂投记中而不自知其厐杂至此也</span>  
<span style="margin-left: 1em">语云食稊者不肥况非梯乎抑亦稗官家者流志如左</span>  
<span style="margin-left: 1em">顾荣与陆机兄弟入洛时号三俊广陵相陈敏反假荣</span>  
<span style="margin-left: 2em">丹阳内史荣以白羽扇麾之其军自溃因名麾扇渡</span>  
<span style="margin-left: 1em">陆纳为吴兴太守先至姑孰辞桓温伺温间因谓曰外</span>  
<span style="margin-left: 2em">有微礼方守远郡欲与公一醉以展下情温欣然纳</span>  
<span style="margin-left: 2em">之时王坦之刁彝在坐及受礼惟酒一斗鹿肉一柈</span>  
<span style="margin-left: 2em">温及宾客并叹其率素</span>  
<span style="margin-left: 1em">陆机尝诣王武子武子置数斛羊酪指示陆云卿江东</span>  
<span style="margin-left: 2em">何以敌此陆云千里莼羹未下盐豉刘孝标云此陆</span>  
<span style="margin-left: 2em">占对之妙</span>  
<span style="margin-left: 1em">德宗召陆贽拜翰林学士呼为陆九而不名居中参议</span>  
<span style="margin-left: 2em">可否时号内相德宗尝谕曰卿清慎太过诸餽遗一</span>  
<span style="margin-left: 2em">皆拒绝恐事情不通如鞭靴之类受亦何妨贽疏云</span>  
<span style="margin-left: 2em">鞭靴不止必及金玉目见可欲能自窒乎</span>  
<span style="margin-left: 1em">唐贞元中陆贽知贡举试明水赋御沟柳诗得韩愈欧</span>  
<span style="margin-left: 2em">阳詹贾棱陈羽等同榜皆天下孤隽伟杰之士号龙</span>  
<span style="margin-left: 2em">虎榜<sub class="note-yuan">氏族大全</sub></span>  
<span style="margin-left: 1em">顾况志尚疏逸近于方外有时宰招致将以好官命之</span>  
<span style="margin-left: 2em">况答以诗曰四海如今已太平相公何事唤狂生此</span>  
<span style="margin-left: 2em">身还似笼中鹤东海沧溟叫数声后吴中皆言况得</span>  
<span style="margin-left: 2em">道解化去<sub class="note-yuan">见尚书故实</sub></span>  
<span style="margin-left: 1em">唐卢从愿为刑部尚书占良田数百顷时号多田翁下</span>  
<span style="margin-left: 2em">沙瞿霆发尝为两浙运使延祐中括田其家有当役</span>  
<span style="margin-left: 2em">民田二千七百顷并佃官田共及万顷浙西有田之</span>  
<span style="margin-left: 2em">家无出其右宋兵部侍郎休宁金安节尝提刑浙江</span>  
<span style="margin-left: 2em">其后万禄昆弟寓居汉成里赀雄于乡人呼为田里</span>  
<span style="margin-left: 2em">金亦此类也孝子子安及著水政录处和皆田里派</span>  
<span style="margin-left: 2em">云<sub class="note-yuan">旧志</sub></span>  
<span style="margin-left: 1em">郑闻游学华亭与钱良臣同舍绍兴间魁南省后与钱</span>  
<span style="margin-left: 2em">并参大政尝题名于学之达材斋后人以碧纱笼之</span>  
<span style="margin-left: 2em">为一时盛事</span>  
<span style="margin-left: 1em">张之翰典郡日门揭春帖云云间太守过三载天下元</span>  
<span style="margin-left: 2em">贞第二年又之翰有镜灯诗云一池铅水藏真火半</span>  
<span style="margin-left: 2em">夜金星犯太阴脍炙人口时呼为张镜灯<sub class="note-yuan">旧志</sub></span>  
<span style="margin-left: 1em">刘宣字伯宣太原人至元中以郎中从伯颜及平章阿</span>  
<span style="margin-left: 2em">术平江南赞画居多除知松江府后同知浙西宣慰</span>  
<span style="margin-left: 2em">司事在官五年威惠并著尝奉诏理算各盐司及财</span>  
<span style="margin-left: 2em">赋府茶塲出纳之数为阿合马嗾党诬搆以死宣素</span>  
<span style="margin-left: 2em">有节操以忠义为世所称时共悼之</span>  
<span style="margin-left: 1em">谢谔字昌国新喻人绍兴二十七年进士调峡州夷陵</span>  
<span style="margin-left: 2em">县主簿改吉州录事参军知袁州分宜县丁忧服阕</span>  
<span style="margin-left: 2em">除干辨行在诸司粮料院迁国子监簿寻擢监察御</span>  
<span style="margin-left: 2em">史奏减袁州分宜及秀州华亭月桩钱<sub class="note-yuan">先哲录</sub></span>  
<span style="margin-left: 1em">张德昭字彦明邢台人至正七年尹华亭尅廉清白妻</span>  
<span style="margin-left: 2em">子皆化之衣粗食淡终三年无怨色会稽杨维祯撰</span>  
<span style="margin-left: 2em">遗爱碑钱衮为刻八字颂于郭门曰公平廉明勤俭</span>  
<span style="margin-left: 2em">慈让云</span>  
<span style="margin-left: 1em">青村陶应炎治生大穰因欲求一官适阙下计会近臣</span>  
<span style="margin-left: 2em">引见世祖命脱帽相之但曰江南富人也赐马湩三</span>  
<span style="margin-left: 2em">金钟而已近臣为之请帝曰议官之未几帝崩大德</span>  
<span style="margin-left: 2em">初始授徽之休宁搉茶提举卜日上官僚吏率音乐</span>  
<span style="margin-left: 2em">欵门迎导至则死矣同邑有曹元珍者由盐司佐史</span>  
<span style="margin-left: 2em">注县吏时吏禄以贿于县尹郭也先不花知元珍久</span>  
<span style="margin-left: 2em">不得赋录遂首拔之元珍喜告祠堂然后出趋事忽</span>  
<span style="margin-left: 2em">中风坠地不能起起而郭去官终其身不得升斗禄</span>  
<span style="margin-left: 2em">右二事绝相类可为不知命者之戒</span>  
<span style="margin-left: 1em">元有谈公绰者以老人尝受宪司命简灾田于松江夜</span>  
<span style="margin-left: 2em">宿华亭富人家富人欲冒作虚数厚欵之宿之密室</span>  
<span style="margin-left: 2em">夜分一女子出其榻后绰惊叩之女曰妾此乡某氏</span>  
<span style="margin-left: 2em">女父贷主人粟经岁积利三十石无偿因以妾贷今</span>  
<span style="margin-left: 2em">夕奉主人命来绰闻之遽起求出而门扃不可启呼</span>  
<span style="margin-left: 2em">主人又弗应乃谕女曰汝良家子也吾安肯污汝张</span>  
<span style="margin-left: 2em">灯坐以待旦既而主人启门入其女以实告主人大</span>  
<span style="margin-left: 2em">惭绰因谓曰所负某当代偿幸以女还其家主人谢</span>  
<span style="margin-left: 2em">曰敢不听命遂焚券而还之<sub class="note-yuan">旧志</sub></span>  
<span style="margin-left: 1em">宋时北桥俞弥恭与子端皆好市义凡售物者自百缗</span>  
<span style="margin-left: 2em">以下一听所邀偿之籴者每百斛必再误唱筹以禆</span>  
<span style="margin-left: 2em">其不足人谓之痴继有孙名彬长身美眉目三十未</span>  
<span style="margin-left: 2em">有子尝谓所亲曰吾志欲得一官而有四子名以英</span>  
<span style="margin-left: 2em">雄俊杰天其可必乎已果生四子至正间三人并位</span>  
<span style="margin-left: 2em">星郎而彬亦贵显卒如其言<sub class="note-yuan">旧志</sub></span>  
<span style="margin-left: 1em">汤文英字孟宽华亭人世笃孝友八世同居至元间诏</span>  
<span style="margin-left: 2em">表其闾</span>  
<span style="margin-left: 1em">徐守忠字子旸冲静寡欲邃周易经纬诸书为分譔注</span>  
<span style="margin-left: 2em">疏幼丧父事母俞尽孝尝慕周道祖禇元璩之为人</span>  
<span style="margin-left: 2em">终身不娶既从黄冠游受金丹内诀精方药累征不</span>  
<span style="margin-left: 2em">就赐号清隐处士</span>  
<span style="margin-left: 1em">元初乌泥泾赵如珪推诚乐善于先茔建归厚僧祠于</span>  
<span style="margin-left: 2em">里中创保和道院自经道府城及浦东皆凿井架庵</span>  
<span style="margin-left: 2em">以憇行旅夏施汤茗以济暍人其子弘毅又辟斋舍</span>  
<span style="margin-left: 2em">延名儒以教乡之子弟未几子廷芝第进士调丞归</span>  
<span style="margin-left: 2em">安来学越人郭性存色目人札剌里丁亦相继登第</span>  
<span style="margin-left: 2em">元世南人登进士自廷芝始</span>  
<span style="margin-left: 1em">元翰林学士高公智耀河西人尝奏崇学校正儒者户</span>  
<span style="margin-left: 2em">籍免徭役后学宫皆像而祀之知府张之翰尝为之</span>  
<span style="margin-left: 2em">赞曰公生西夏遭际圣元力扶吾道名动中原致位</span>  
<span style="margin-left: 2em">内相垂裕后昆德盛日彰身日益尊画像云间在泮</span>  
<span style="margin-left: 2em">之坤香火勿坠埃尘莫昏千百年兮不忘者存<sub class="note-yuan">旧志</sub></span>  
<span style="margin-left: 1em">泰定甲子治书刘公泺源北方学者谒庙日值闰岁詹</span>  
<span style="margin-left: 2em">肖岩讲尧典期三百有六旬有六日以闰月定四时</span>  
<span style="margin-left: 2em">成岁大咈其意以为学校讲说当使执鞭坠镫之人</span>  
<span style="margin-left: 2em">皆能通晓今乃稽算度数何为肖岩由是悒怏而卒</span>  
<span style="margin-left: 2em">至元己卯分宪老老简踏灾伤以复熟粮为急陆宅</span>  
<span style="margin-left: 2em">之讲省刑罚薄税敛一章至变色而作至正辛巳知</span>  
<span style="margin-left: 2em">府杨侯锐意浚河宪佥谒学王玉岩讲禹别九州随</span>  
<span style="margin-left: 2em">山濬川皆归美知府宪佥不悦而罢丁酉张士诚遣</span>  
<span style="margin-left: 2em">苏守周仁来王可耀讲易君子道长小人道消之义</span>  
<span style="margin-left: 2em">周以为讥讪罪及诸职事皆停月廪惟钱伯全为训</span>  
<span style="margin-left: 2em">导日行刑官至讲钦哉钦哉惟刑之恤哉大见称赏</span>  
<span style="margin-left: 2em">前数君子可以为戒要亦所遇之不同也<sub class="note-yuan">旧志</sub></span>  
<span style="margin-left: 1em">萧墅张汉杰伯庸父子与赵屯吴氏有姻契张吴元万</span>  
<span style="margin-left: 2em">户府官吴元年钱鹤臯作乱遣人诣张请为应汉杰</span>  
<span style="margin-left: 2em">父子忿然曰此叛贼也吾从汝反耶大书叛贼二字</span>  
<span style="margin-left: 2em">于背反缚其人叱去之</span>  
<span style="margin-left: 1em">太祖尝登钟山词臣扈从拥翠亭给笔札赋诗应制者</span>  
<span style="margin-left: 2em">八人秦裕伯与焉</span>  
<span style="margin-left: 1em">皇上亲择廷臣二十四人为采访使以顺风谣烛幽隐</span>  
<span style="margin-left: 2em">利民之事得以便宜行之既事还朝卓以政事闻者</span>  
<span style="margin-left: 2em">居其半给事中华亭徐君思勉有闻之最者也　天</span>  
<span style="margin-left: 2em">子以为可用会大同有警复俾持　诏往抚慰兵民</span>  
<span style="margin-left: 2em">思勉清敏劲正所奏皆切时事其能愈彰适山东按</span>  
<span style="margin-left: 2em">察司以缺官告即授佥事将行其僚友喜甚为诗以</span>  
<span style="margin-left: 2em">饯之<sub class="note-yuan">逊志集</sub></span>  
<span style="margin-left: 1em">陆文裕公云宋濂小录所序载止录裕伯家手勑今海</span>  
<span style="margin-left: 2em">滨有二秦氏一秦文解先自邗沟来而裕伯尝寓扬</span>  
<span style="margin-left: 2em">州故当近之一秦钿家收有裕伯上中书书草其始</span>  
<span style="margin-left: 2em">末多不详佃云裕伯竟不出而不知尝为翰林侍读</span>  
<span style="margin-left: 2em">学士又为待制又为治书御史按裕伯在元时北方</span>  
<span style="margin-left: 2em">文书多出其手今见于元文类中俟访其成集以传</span>  
<span style="margin-left: 2em">吾邑志</span>  
<span style="margin-left: 1em">富林焦氏有名伯诚者博学隐居　高皇帝闻其名特</span>  
<span style="margin-left: 2em">聘典试礼闱其后人著有读书乐四首以传</span>  
<span style="margin-left: 1em">老铁隐吾松有草玄阁籍景轩拄颊楼小蓬台后止台</span>  
<span style="margin-left: 2em">上不复下署于门曰客至不下楼恕老懒见客不答</span>  
<span style="margin-left: 2em">礼恕老病客问事不对恕老默发言无所避恕老迂</span>  
<span style="margin-left: 2em">饮酒不辍乐恕老狂</span>  
<span style="margin-left: 1em">陶九成饮泗滨夏氏清樾堂酒半折莲花置小金巵令</span>  
<span style="margin-left: 2em">歌姬行酒客就姬取饮因名解语杯</span>  
<span style="margin-left: 1em">胡秉忠上海人洪武初举人才知行唐县务以礼化俗</span>  
<span style="margin-left: 2em">制祀先孝顺节义教民读书三图名曰谕俗图入觐</span>  
<span style="margin-left: 2em">时以此图献上命颁行天下仍温旨嘉之</span>  
<span style="margin-left: 1em">陈禧字景道号起潜华亭瑶溪里人太学生性素慨慷</span>  
<span style="margin-left: 2em">洪武中直陈时弊论劾权奸　上怒命力士打数瓜</span>  
<span style="margin-left: 2em">不死谪戍云南欣然就道袁季中赠其弟祯诗曰阿</span>  
<span style="margin-left: 2em">兄自是瑚琏器庙堂之上宜先登一朝抗疏犯天怒</span>  
<span style="margin-left: 2em">承恩遣戍云南征士论壮之</span>  
<span style="margin-left: 1em">钟仲明　洪武初以人材举擢言职抗疏忤　旨殒于</span>  
<span style="margin-left: 2em">狱分其尸夫人叶氏陈情乞收骸骨归葬已不可得</span>  
<span style="margin-left: 3em">上怜之赐血衣配葬墓在陶溪</span>  
<span style="margin-left: 1em">洪武十五年十一月以上海训导顾彧为户部侍郎又</span>  
<span style="margin-left: 2em">老人陈原九为松江太守长乐人三十五年以吾松</span>  
<span style="margin-left: 2em">岁贡胡原吉为大理评事马祯都给事中沈绍先监</span>  
<span style="margin-left: 2em">察御史徐谅按察佥事蒋彦英河南参议夏礼御史</span>  
<span style="margin-left: 2em">永乐三十三年以萧余庆为吏部主事正统十四年</span>  
<span style="margin-left: 2em">桑景春为御史王景安刑部主事福建佥事蒋忠礼</span>  
<span style="margin-left: 2em">部主事刘琛礼部郎中俞敏刑部主事俱岁贡</span>  
<span style="margin-left: 1em">永乐十八年特选人材十三人并授方面而华亭七人</span>  
<span style="margin-left: 2em">马麟周恂孙豫奚景周江润皆布政使吴衡陆勉皆</span>  
<span style="margin-left: 2em">参政以布衣而跻外台极品皆能其官以功名终相</span>
