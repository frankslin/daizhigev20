## 崇禎松江府志卷之五十七　志餘上（遺事）

<span style="margin-left: 3em">志餘<sub class="note-yuan">遺事</sub></span>  
<span style="margin-left: 1em">采書購訪以資郡乘不惜輕舟重幣求之取信不取誕</span>  
<span style="margin-left: 1em">取常不取怪取其羽翼名教而不取曖昧垢穢之詞庶</span>  
<span style="margin-left: 1em">幾慎言其餘哉昔徐鉉好異凡賓客不能自通與失意</span>  
<span style="margin-left: 1em">而見絶者皆詭言以求合洪邁急成夷堅多取舊事改</span>  
<span style="margin-left: 1em">竄首尾年月名氏雜投記中而不自知其龎雜至此也</span>  
<span style="margin-left: 1em">語云食稊者不肥況非梯乎抑亦稗官家者流志如左</span>  
<span style="margin-left: 1em">顧榮與陸機兄弟入洛時號三俊廣陵相陳敏反假榮</span>  
<span style="margin-left: 2em">丹陽內史榮以白羽扇麾之其軍自潰因名麾扇渡</span>  
<span style="margin-left: 1em">陸納爲吳興太守先至姑孰辭桓温伺温間因謂曰外</span>  
<span style="margin-left: 2em">有微禮方守遠郡欲與公一醉以展下情温欣然納</span>  
<span style="margin-left: 2em">之時王坦之刁彝在坐及受禮惟酒一斗鹿肉一柈</span>  
<span style="margin-left: 2em">温及賓客並歎其率素</span>  
<span style="margin-left: 1em">陸機嘗詣王武子武子置數斛羊酪指示陸云卿江東</span>  
<span style="margin-left: 2em">何以敵此陸云千里蓴羹未下鹽豉劉孝標云此陸</span>  
<span style="margin-left: 2em">占對之妙</span>  
<span style="margin-left: 1em">德宗召陸贄拜翰林學士呼爲陸九而不名居中參議</span>  
<span style="margin-left: 2em">可否時號內相德宗嘗諭曰卿清慎太過諸餽遺一</span>  
<span style="margin-left: 2em">皆拒絶恐事情不通如鞭靴之類受亦何妨贄疏云</span>  
<span style="margin-left: 2em">鞭靴不止必及金玉目見可欲能自窒乎</span>  
<span style="margin-left: 1em">唐貞元中陸贄知貢舉試明水賦御溝柳詩得韓愈歐</span>  
<span style="margin-left: 2em">陽詹賈稜陳羽等同榜皆天下孤雋偉傑之士號龍</span>  
<span style="margin-left: 2em">虎榜<sub class="note-yuan">氏族大全</sub></span>  
<span style="margin-left: 1em">顧況志尚疏逸近于方外有時宰招致將以好官命之</span>  
<span style="margin-left: 2em">況答以詩曰四海如今已太平相公何事唤狂生此</span>  
<span style="margin-left: 2em">身還似籠中鶴東海滄溟叫數聲後吳中皆言況得</span>  
<span style="margin-left: 2em">道解化去<sub class="note-yuan">見尚書故實</sub></span>  
<span style="margin-left: 1em">唐盧從願爲刑部尚書占良田數百頃時號多田翁下</span>  
<span style="margin-left: 2em">沙瞿霆發嘗爲兩浙運使延祐中括田其家有當役</span>  
<span style="margin-left: 2em">民田二千七百頃併佃官田共及萬頃浙西有田之</span>  
<span style="margin-left: 2em">家無出其右宋兵部侍郎休寧金安節嘗提刑浙江</span>  
<span style="margin-left: 2em">其後萬禄昆弟寓居漢成里貲雄于鄉人呼爲田里</span>  
<span style="margin-left: 2em">金亦此類也孝子子安及著水政錄處和皆田里派</span>  
<span style="margin-left: 2em">云<sub class="note-yuan">舊志</sub></span>  
<span style="margin-left: 1em">鄭聞遊學華亭與錢良臣同舍紹興間魁南省後與錢</span>  
<span style="margin-left: 2em">並參大政嘗題名于學之達材齋後人以碧紗籠之</span>  
<span style="margin-left: 2em">爲一時盛事</span>  
<span style="margin-left: 1em">張之翰典郡日門揭春帖云雲間太守過三載天下元</span>  
<span style="margin-left: 2em">貞第二年又之翰有鏡燈詩云一池鉛水藏真火半</span>  
<span style="margin-left: 2em">夜金星犯太陰膾炙人口時呼爲張鏡燈<sub class="note-yuan">舊志</sub></span>  
<span style="margin-left: 1em">劉宣字伯宣太原人至元中以郎中從伯顔及平章阿</span>  
<span style="margin-left: 2em">朮平江南贊畫居多除知松江府後同知浙西宣慰</span>  
<span style="margin-left: 2em">司事在官五年威惠並著嘗奉詔理算各鹽司及財</span>  
<span style="margin-left: 2em">賦府茶塲出納之數爲阿合馬嗾黨誣搆以死宣素</span>  
<span style="margin-left: 2em">有節操以忠義爲世所稱時共悼之</span>  
<span style="margin-left: 1em">謝諤字昌國新喻人紹興二十七年進士調峽州夷陵</span>  
<span style="margin-left: 2em">縣主簿改吉州錄事參軍知袁州分宜縣丁憂服闋</span>  
<span style="margin-left: 2em">除幹辨行在諸司糧料院遷國子監簿尋擢監察御</span>  
<span style="margin-left: 2em">史奏减袁州分宜及秀州華亭月樁錢<sub class="note-yuan">先哲錄</sub></span>  
<span style="margin-left: 1em">張德昭字彦明邢臺人至正七年尹華亭尅廉清白妻</span>  
<span style="margin-left: 2em">子皆化之衣粗食淡終三年無怨色會稽楊維禎撰</span>  
<span style="margin-left: 2em">遺愛碑錢衮爲刻八字頌于郭門曰公平廉明勤儉</span>  
<span style="margin-left: 2em">慈讓云</span>  
<span style="margin-left: 1em">青村陶應炎治生大穰因欲求一官適闕下計會近臣</span>  
<span style="margin-left: 2em">引見世祖命脱帽相之但曰江南富人也賜馬湩三</span>  
<span style="margin-left: 2em">金鍾而已近臣爲之請帝曰議官之未幾帝崩大德</span>  
<span style="margin-left: 2em">初始授徽之休寧搉茶提舉卜日上官僚吏率音樂</span>  
<span style="margin-left: 2em">欵門迎導至則死矣同邑有曹元珍者由鹽司佐史</span>  
<span style="margin-left: 2em">注縣吏時吏禄以賄于縣尹郭也先不花知元珍久</span>  
<span style="margin-left: 2em">不得賦錄遂首拔之元珍喜告祠堂然後出趨事忽</span>  
<span style="margin-left: 2em">中風墜地不能起起而郭去官終其身不得升斗禄</span>  
<span style="margin-left: 2em">右二事絶相類可爲不知命者之戒</span>  
<span style="margin-left: 1em">元有談公綽者以老人嘗受憲司命簡災田于松江夜</span>  
<span style="margin-left: 2em">宿華亭富人家富人欲冒作虛數厚欵之宿之密室</span>  
<span style="margin-left: 2em">夜分一女子出其榻後綽驚叩之女曰妾此鄉某氏</span>  
<span style="margin-left: 2em">女父貸主人粟經歲積利三十石無償因以妾貸今</span>  
<span style="margin-left: 2em">夕奉主人命來綽聞之遽起求出而門扃不可啓呼</span>  
<span style="margin-left: 2em">主人又弗應乃諭女曰汝良家子也吾安肯汙汝張</span>  
<span style="margin-left: 2em">燈坐以待旦既而主人啓門入其女以實告主人大</span>  
<span style="margin-left: 2em">慚綽因謂曰所負某當代償幸以女還其家主人謝</span>  
<span style="margin-left: 2em">曰敢不聽命遂焚券而還之<sub class="note-yuan">舊志</sub></span>  
<span style="margin-left: 1em">宋時北橋俞彌恭與子端皆好市義凡售物者自百緡</span>  
<span style="margin-left: 2em">以下一聽所邀償之糴者每百斛必再誤唱籌以禆</span>  
<span style="margin-left: 2em">其不足人謂之癡繼有孫名彬長身美眉目三十未</span>  
<span style="margin-left: 2em">有子嘗謂所親曰吾志欲得一官而有四子名以英</span>  
<span style="margin-left: 2em">雄俊傑天其可必乎已果生四子至正間三人並位</span>  
<span style="margin-left: 2em">星郎而彬亦貴顯卒如其言<sub class="note-yuan">舊志</sub></span>  
<span style="margin-left: 1em">湯文英字孟寬華亭人世篤孝友八世同居至元間詔</span>  
<span style="margin-left: 2em">表其閭</span>  
<span style="margin-left: 1em">徐守忠字子暘沖靜寡欲邃周易經緯諸書爲分譔註</span>  
<span style="margin-left: 2em">疏幼喪父事母俞盡孝嘗慕周道祖禇元璩之爲人</span>  
<span style="margin-left: 2em">終身不娶既從黃冠游受金丹內訣精方藥累徵不</span>  
<span style="margin-left: 2em">就賜號清隱處士</span>  
<span style="margin-left: 1em">元初烏泥涇趙如珪推誠樂善于先塋建歸厚僧祠于</span>  
<span style="margin-left: 2em">里中創保和道院自經道府城及浦東皆鑿井架菴</span>  
<span style="margin-left: 2em">以憇行旅夏施湯茗以濟暍人其子弘毅又闢齋舍</span>  
<span style="margin-left: 2em">延名儒以教鄉之子弟未幾子廷芝第進士調丞歸</span>  
<span style="margin-left: 2em">安來學越人郭性存色目人札剌里丁亦相繼登第</span>  
<span style="margin-left: 2em">元世南人登進士自廷芝始</span>  
<span style="margin-left: 1em">元翰林學士高公智耀河西人嘗奏崇學校正儒者户</span>  
<span style="margin-left: 2em">籍免徭役後學宫皆像而祀之知府張之翰嘗爲之</span>  
<span style="margin-left: 2em">贊曰公生西夏遭際聖元力扶吾道名動中原致位</span>  
<span style="margin-left: 2em">內相垂裕後昆德盛日彰身日益尊畫像雲間在泮</span>  
<span style="margin-left: 2em">之坤香火勿墜埃塵莫昏千百年兮不忘者存<sub class="note-yuan">舊志</sub></span>  
<span style="margin-left: 1em">泰定甲子治書劉公濼源北方學者謁廟日值閏歲詹</span>  
<span style="margin-left: 2em">肖巖講堯典期三百有六旬有六日以閏月定四時</span>  
<span style="margin-left: 2em">成歲大咈其意以爲學校講說當使執鞭墜鐙之人</span>  
<span style="margin-left: 2em">皆能通曉今乃稽算度數何爲肖巖由是悒怏而卒</span>  
<span style="margin-left: 2em">至元己卯分憲老老簡踏災傷以復熟糧爲急陸宅</span>  
<span style="margin-left: 2em">之講省刑罰薄稅斂一章至變色而作至正辛巳知</span>  
<span style="margin-left: 2em">府楊侯鋭意浚河憲僉謁學王玉巖講禹別九州隨</span>  
<span style="margin-left: 2em">山濬川皆歸美知府憲僉不悦而罷丁酉張士誠遣</span>  
<span style="margin-left: 2em">蘇守周仁來王可耀講易君子道長小人道消之義</span>  
<span style="margin-left: 2em">周以爲譏訕罪及諸職事皆停月廪惟錢伯全爲訓</span>  
<span style="margin-left: 2em">導日行刑官至講欽哉欽哉惟刑之卹哉大見稱賞</span>  
<span style="margin-left: 2em">前數君子可以爲戒要亦所遇之不同也<sub class="note-yuan">舊志</sub></span>  
<span style="margin-left: 1em">蕭墅張漢傑伯庸父子與趙屯吳氏有姻契張吳元萬</span>  
<span style="margin-left: 2em">户府官吳元年錢鶴臯作亂遣人詣張請爲應漢傑</span>  
<span style="margin-left: 2em">父子忿然曰此叛賊也吾從汝反耶大書叛賊二字</span>  
<span style="margin-left: 2em">于背反縛其人叱去之</span>  
<span style="margin-left: 1em">太祖嘗登鍾山詞臣扈從擁翠亭給筆札賦詩應制者</span>  
<span style="margin-left: 2em">八人秦裕伯與焉</span>  
<span style="margin-left: 1em">皇上親擇廷臣二十四人爲採訪使以順風謠燭幽隱</span>  
<span style="margin-left: 2em">利民之事得以便宜行之既事還朝卓以政事聞者</span>  
<span style="margin-left: 2em">居其半給事中華亭徐君思勉有聞之最者也　天</span>  
<span style="margin-left: 2em">子以爲可用會大同有警復俾持　詔往撫慰兵民</span>  
<span style="margin-left: 2em">思勉清敏勁正所奏皆切時事其能愈彰適山東按</span>  
<span style="margin-left: 2em">察司以缺官告即授僉事將行其僚友喜甚爲詩以</span>  
<span style="margin-left: 2em">餞之<sub class="note-yuan">遜志集</sub></span>  
<span style="margin-left: 1em">陸文裕公云宋濂小錄所序載止錄裕伯家手勑今海</span>  
<span style="margin-left: 2em">濱有二秦氏一秦文解先自邗溝來而裕伯嘗寓揚</span>  
<span style="margin-left: 2em">州故當近之一秦鈿家收有裕伯上中書書草其始</span>  
<span style="margin-left: 2em">末多不詳佃云裕伯竟不出而不知嘗爲翰林侍讀</span>  
<span style="margin-left: 2em">學士又爲待制又爲治書御史按裕伯在元時北方</span>  
<span style="margin-left: 2em">文書多出其手今見于元文類中俟訪其成集以傳</span>  
<span style="margin-left: 2em">吾邑志</span>  
<span style="margin-left: 1em">富林焦氏有名伯誠者博學隱居　高皇帝聞其名特</span>  
<span style="margin-left: 2em">聘典試禮闈其後人著有讀書樂四首以傳</span>  
<span style="margin-left: 1em">老鐵隱吾松有草玄閣籍景軒拄頰樓小蓬臺後止臺</span>  
<span style="margin-left: 2em">上不復下署于門曰客至不下樓恕老懶見客不答</span>  
<span style="margin-left: 2em">禮恕老病客問事不對恕老默發言無所避恕老迂</span>  
<span style="margin-left: 2em">飲酒不輟樂恕老狂</span>  
<span style="margin-left: 1em">陶九成飲泗濱夏氏清樾堂酒半折蓮花置小金巵令</span>  
<span style="margin-left: 2em">歌姬行酒客就姬取飲因名解語杯</span>  
<span style="margin-left: 1em">胡秉忠上海人洪武初舉人才知行唐縣務以禮化俗</span>  
<span style="margin-left: 2em">製祀先孝順節義教民讀書三圖名曰諭俗圖入覲</span>  
<span style="margin-left: 2em">時以此圖獻上命頒行天下仍温旨嘉之</span>  
<span style="margin-left: 1em">陳禧字景道號起潛華亭瑶溪里人太學生性素慨慷</span>  
<span style="margin-left: 2em">洪武中直陳時弊論劾權奸　上怒命力士打數瓜</span>  
<span style="margin-left: 2em">不死謫戍雲南欣然就道袁季中贈其弟禎詩曰阿</span>  
<span style="margin-left: 2em">兄自是瑚璉器廟堂之上宜先登一朝抗疏犯天怒</span>  
<span style="margin-left: 2em">承恩遣戍雲南征士論壯之</span>  
<span style="margin-left: 1em">鍾仲明　洪武初以人材舉擢言職抗疏忤　旨殞於</span>  
<span style="margin-left: 2em">獄分其尸夫人葉氏陳情乞收骸骨歸葬已不可得</span>  
<span style="margin-left: 3em">上憐之賜血衣配葬墓在陶溪</span>  
<span style="margin-left: 1em">洪武十五年十一月以上海訓導顧彧爲户部侍郎又</span>  
<span style="margin-left: 2em">老人陳原九爲松江太守長樂人三十五年以吾松</span>  
<span style="margin-left: 2em">歲貢胡原吉爲大理評事馬禎都給事中沈紹先監</span>  
<span style="margin-left: 2em">察御史徐諒按察僉事蔣彦英河南參議夏禮御史</span>  
<span style="margin-left: 2em">永樂三十三年以蕭餘慶爲吏部主事正統十四年</span>
