## 崇禎松江府志卷之四十二　人物七（文學隱逸藝術）

<span style="margin-left: 3em">文學</span>  
<span style="margin-left: 1em">漢尚經術別有文學掌故其次臠龍虎之章熠鳳鸞之</span>  
<span style="margin-left: 1em">羽抽毫拂簡智思入淵郡不乏才彬彬郁郁於斯爲盛</span>  
<span style="margin-left: 1em">矣宋景濂曰文學之事身任者衆要以聖人之文爲宗</span>  
<span style="margin-left: 1em">濫觴無已軌諸仲尼其在游夏之徒歟</span>  
<span style="margin-left: 1em">宋</span>  
<span style="margin-left: 1em">朱之純元祐進士有文章名淡于時趣作湖齋于谷陽</span>  
<span style="margin-left: 1em">園自號谷陽先生嘗題湖齋志序云予湖上治圃于桃</span>  
<span style="margin-left: 1em">根獲古龜六枚其小如錢又雲間有仙鶴觀每歲中秋</span>  
<span style="margin-left: 1em">夜有仙鶴下觀因得名余治圃谷水鄰詩曰平湖十頃</span>  
<span style="margin-left: 1em">水汪洋得意茅齋且屈藏園種小桃今結子池栽翠芰</span>  
<span style="margin-left: 1em">更聞香六龜已作千年瑞雙鶴看呈八月祥居此翛然</span>  
<span style="margin-left: 1em">忘世味此心猶嬾醉龍陽有詩文集行于世</span>  
<span style="margin-left: 1em">杜可久平章杜祁公衍之後爲青龍直學有文行立日</span>  
<span style="margin-left: 1em">課以訓迪諸生勤敏不倦士友樂之遂家于西霞浦墓</span>  
<span style="margin-left: 1em">在杜村</span>  
<span style="margin-left: 2em">青龍志云今子孫散居華亭海上代有聞人又梧溪</span>  
<span style="margin-left: 2em">集載杜好古名敏宋祁公後世隱青龍累謝徵辟</span>  
<span style="margin-left: 1em">儲泳字文卿上海人有詩名精于陰陽五行通儒玄理</span>  
<span style="margin-left: 1em">其言道家之行持即吾儒之格物行持以正心誠意爲</span>  
<span style="margin-left: 1em">本心不正不足感物意不誠不足通神神運于此物應</span>  
<span style="margin-left: 1em">于彼故雖萬里可驅攝于呼吸間非至神孰能與於此</span>  
<span style="margin-left: 1em">蓋廣大無際者心也隔碍潛通者神也心不存則不明</span>  
<span style="margin-left: 1em">神不養則不靈正以持久而明誠以養極而靈世之學</span>  
<span style="margin-left: 1em">者不務養平時而遽施一旦亦猶汲甘泉于枯井採英</span>  
<span style="margin-left: 1em">華于槁木不可得矣所著有祛疑說人争傳錄弟溒字</span>  
<span style="margin-left: 1em">智卿亦以詩名</span>  
<span style="margin-left: 1em">朱允恭字爾靖與族人藤州守日新號足菴者並以詩</span>  
<span style="margin-left: 1em">名四靈趙天樂選允恭詩二百餘首爲集行世</span>  
<span style="margin-left: 1em">朱象先松陵人東坡稱其能文而不求舉善畫而不求</span>  
<span style="margin-left: 1em">售曰文以達吾心畫以適吾意而已</span>  
<span style="margin-left: 1em">陸霆龍字伯靈華亭人咸淳鄉貢進士宋亡即棲隱講</span>  
<span style="margin-left: 1em">授終其身衣冠不易嘗自贊畫像云勤勤劬劬耽嗜慕</span>  
<span style="margin-left: 1em">悦而不忍舍者聖賢之書趦趦趄趄畏懦退縮而不敢</span>  
<span style="margin-left: 1em">登者世利之途暈輕霞以爲臉縷積雪以成衣衣前後</span>  
<span style="margin-left: 1em">而襜如儼張拱而徐趨獲者見之而指笑此必抱遺經</span>  
<span style="margin-left: 1em">行古道之拘儒</span>  
<span style="margin-left: 1em">許尚號和光老人能詩文有華亭百詠<sub class="note-yuan">見舊志</sub></span>  
<span style="margin-left: 1em">許寔元豐間居吳之笠澤本松江人後乃徙居于婺生</span>  
<span style="margin-left: 1em">許白雲先生謙以理學著稱元世然實本之于寔云寔</span>  
<span style="margin-left: 1em">常受業于胡文昭公瑗學有旨歸持己教人能以師法</span>  
<span style="margin-left: 1em">終始當世翕然稱之</span>  
<span style="margin-left: 1em">胡林卿華亭人淳熙甲科紹熙癸丑新除迪功郎饒州</span>  
<span style="margin-left: 1em">州學教授史彌遠柄國勢燄薰天林卿與同籍終身不</span>  
<span style="margin-left: 1em">登其門及卒有挽詩云有名登相甲無跡到權門丰節</span>  
<span style="margin-left: 1em">𪷤𪷤爲時所重初縣未有志林卿始與知縣楊潛同邑</span>  
<span style="margin-left: 1em">林至朱端常同修爲三卷號雲間志子琚嘉定進士學</span>  
<span style="margin-left: 1em">識該博能詩有靜菴集行于世</span>  
<span style="margin-left: 1em">林至字德久華亭人淳熙釋褐歷官秘書省登晦菴先</span>  
<span style="margin-left: 1em">生之門與晦翁書詞反覆稱其參悟日進晦翁獨好離</span>  
<span style="margin-left: 1em">騷至有釋騷師門之教也文集四卷行世子革世其學</span>  
<span style="margin-left: 1em">登嘉定進士</span>  
<span style="margin-left: 1em">葉汝舟字濟川華亭人登開慶進士有刊行通鑑筆義</span>  
<span style="margin-left: 1em">所著詩文藏於家</span>  
<span style="margin-left: 1em">衛宗武字洪父華亭人以父蔭官省門至常州守別號</span>  
<span style="margin-left: 1em">水北文及翁序其詩文名秋聲集</span>  
<span style="margin-left: 1em">元</span>  
<span style="margin-left: 1em">凌嵒字山英號石泉其先少師哲靖康中自汴隨蹕南</span>  
<span style="margin-left: 1em">遷徙居華亭遂爲邑人嵒少習舉子業會宋亡即卷取</span>  
<span style="margin-left: 1em">藏一放于詩鎔意鑄辭鏘鳴秀拔駸尋大曆有古木風</span>  
<span style="margin-left: 1em">瓢集</span>  
<span style="margin-left: 1em">曾遇字心傳華亭人宋丞相曾公亮之裔博學敏文詞</span>  
<span style="margin-left: 1em">尤攻書學元時以薦授湖州路安吉縣丞致仕與王昭</span>  
<span style="margin-left: 1em">大詹潤徐順齊譽稱爲雲間四俊</span>  
<span style="margin-left: 1em">莊肅字恭叔號蓼塘居於上海之青龍鎮仕宋爲秘書</span>  
<span style="margin-left: 1em">小史宋亡棄去放身海上性嗜書聚書至八萬卷且多</span>  
<span style="margin-left: 1em">手抄者經史子集山經地志醫卜方技稗官小說靡所</span>  
<span style="margin-left: 1em">不具書目以甲乙分十門至正間修宋遼金三史詔求</span>  
<span style="margin-left: 1em">遺書江南藏書多者三家莊其一也命簡討危素購書</span>  
<span style="margin-left: 1em">于其家得五百卷所著有藝經畫繼餘譜傳于時</span>  
<span style="margin-left: 2em">輟耕錄載蓼塘既没子孫不知保惜或爲蟲鼠蝕嚙</span>  
<span style="margin-left: 2em">或爲鄰室盗竊或供飲博之需或應翻覆之用編帙</span>  
<span style="margin-left: 2em">散亂所存無幾至正間詔求遺書有以書獻者予一</span>  
<span style="margin-left: 2em">官繼命危學士來選取其家恐兵遁圖讖干犯禁條</span>  
<span style="margin-left: 2em">悉付祝融氏及收拾燼餘存者又無幾矣其孫群玉</span>  
<span style="margin-left: 2em">悉載入京覬領恩澤宿留日久仍布衣而歸書之不</span>  
<span style="margin-left: 2em">幸如此</span>  
<span style="margin-left: 1em">邵亨貞字復孺其王父桂子有別業于華亭娶曹澤之</span>  
<span style="margin-left: 1em">女因家小蒸遂爲華亭人亨貞博通經史贍于文詞工</span>  
<span style="margin-left: 1em">真草篆隸凡陰陽醫卜佛老之學盡究其奥與陶九成</span>  
<span style="margin-left: 1em">爲莫逆交自號見獨居士當時得其片語寸楮以爲家</span>  
<span style="margin-left: 1em">乘光所著有蛾術稿皆出手筆點畫不苟足爲後學楷</span>  
<span style="margin-left: 1em">式云元末兵燹其家僑居横泖洪武初爲府學訓導卒</span>  
<span style="margin-left: 1em">年九十三子伯宣有學菴集古詩能世其業</span>  
<span style="margin-left: 2em">陶南村贈邵青谿先生藜杖烏紗過百年童顔鶴髮</span>  
<span style="margin-left: 2em">氣泠然窩尊安樂元通譜壺隱虛閑別有天課稼春</span>  
<span style="margin-left: 2em">行黃犢外尋盟時到白鷗前青溪一曲春如許二頃</span>  
<span style="margin-left: 2em">何須負郭田</span>  
<span style="margin-left: 1em">陸鵬南字象翁明毛詩不仕文章勁健邑中推爲鄉先</span>  
<span style="margin-left: 1em">生與陸伯靈齊名鄉里稱爲二陸所著詩文名九峯清</span>  
<span style="margin-left: 1em">氣集</span>  
<span style="margin-left: 1em">章弼字拱辰華亭人識度清遠絶無俗韻聚古經史書</span>  
<span style="margin-left: 1em">潛心篤志亹亹忘倦十歲時即能扁榜大字長益有名</span>  
<span style="margin-left: 1em">真行草篆皆師趙魏公</span>  
<span style="margin-left: 1em">陳宏字君宏號碧壺莆田人徙居華亭初試吏于府不</span>  
<span style="margin-left: 1em">久棄去遂以儒起家同知吳江州事其學邃於易嘗著</span>  
<span style="margin-left: 1em">易象發揮易孟通言童子問並傳于世</span>  
<span style="margin-left: 1em">王昭大字茂卿人稱爲玉岩先生華亭人博綜經傳于</span>  
<span style="margin-left: 1em">易尤精詣耄期始調潮州路學教授不以淹晚概懷繼</span>  
<span style="margin-left: 1em">署鄉邑丞致仕至正間年踰大耋時詔例賜致仕官金</span>  
<span style="margin-left: 1em">文綵幣先生美髯修幹被服恩榮夷猶里陌咸尊禮之</span>  
<span style="margin-left: 1em">詹潤號肖梅以父號梅臞也少有俊氣及壯以文儒爲</span>  
<span style="margin-left: 1em">諸暨州學正秩滿例試藝于路教授始得流品官潤太</span>  
<span style="margin-left: 1em">息曰以我之才試教授耶即日襆被歸鄉梓教授以終</span>  
<span style="margin-left: 1em">徐順孫字子靜父號菊存因自號敬菊經術該用性篤</span>  
<span style="margin-left: 1em">孝痛父母蚤亡誓不娶以見志年四十餘朋曹彊爲娶</span>  
<span style="margin-left: 1em">未幾而卒衆誄而哀之順孫嘗讀秦紀賦詩云大藥若</span>  
<span style="margin-left: 1em">從三島至蒼生能有幾家存時傳誦之</span>  
<span style="margin-left: 1em">王默字子章一字伯靜文澤子長八尺美鬚髯談吐甚</span>  
<span style="margin-left: 1em">高亮少任俠多技藝弱冠更折節讀書書法趙魏公行</span>  
<span style="margin-left: 1em">筆甚健徵至京書金字浮屠經擬官翰林見時運已否</span>  
<span style="margin-left: 1em">力辭歸求書者户滿父殁盡鬻書買山以葬廬墓下者</span>  
<span style="margin-left: 1em">久之尤喜爲人排難解紛奮不顧利害張伯雨稱其豪</span>  
<span style="margin-left: 1em">宕不羈有姜白石風子基洪武初舉孝廉爲潞州判嘗</span>  
<span style="margin-left: 1em">著雪齋明鑒錄秦裕伯亟稱之</span>  
<span style="margin-left: 1em">李介石字守道郡人爲人高爽英邁善祠翰喜與人談</span>  
<span style="margin-left: 1em">詩詩稱能品困約無所遇徽寇陷杭以書見省臣命草</span>  
<span style="margin-left: 1em">符檄遂器重之授爲松江提控案牘從省臣守鎮江兵</span>  
<span style="margin-left: 1em">敗不屈死殆古之節俠士也所居有煮雪虀甕白石窩</span>  
<span style="margin-left: 1em">王逢贈之以詩</span>  
<span style="margin-left: 1em">章瑾字公瑾青龍人莊敏公楶之後徙李墟能詩草書</span>  
<span style="margin-left: 1em">法二王尤長於畫爲人有高致日登山臨水所至成趣</span>  
<span style="margin-left: 1em">遇知己觴咏竟日畫或頃刻可就或數日不著一筆蓋</span>  
<span style="margin-left: 1em">張可觀以後一人而已</span>  
<span style="margin-left: 1em">陸居仁字宅之霆龍子以詩經中泰定丙寅鄉試工詩</span>  
<span style="margin-left: 1em">古文以著作自雄書法精微目中不可一世隱居教授</span>  
<span style="margin-left: 1em">于松松人士翕然宗之與楊維禎錢惟善游殁同葬于</span>  
<span style="margin-left: 1em">干山之北號三高士墓</span>  
<span style="margin-left: 2em">宅之殁王逢挽之曰宅之嘗贊予畫像云辯如懸河</span>  
<span style="margin-left: 2em">思如湧泉斗酒百篇倚馬萬言慷慨如奇材之劍客</span>  
<span style="margin-left: 2em">瀟灑如錦袍之謫仙第未知伏軾而掉三寸擊楫而</span>  
<span style="margin-left: 2em">快一鞭於斯二者子將奚先其愛我如是斯人不可</span>  
<span style="margin-left: 2em">作矣詩以哭之游戲清真帖優長雅頌文世方趨趙</span>  
<span style="margin-left: 2em">孟天竟滯劉蕡教施河汾曲身浮澱泖雲飛花時事</span>  
<span style="margin-left: 2em">革過雁訃音聞有女哀扶襯多予望薦蘋陋容看轉</span>  
<span style="margin-left: 2em">老空辱許奇勛</span>  
<span style="margin-left: 1em">王文澤字伯雨譜稱王茂弘後家華亭風涇遷上海祖</span>  
<span style="margin-left: 1em">大言父京並有文章文澤學尤富落筆不肯蹈襲前人</span>  
<span style="margin-left: 1em">一語所交多當世名士累舉不第爲府學訓導所著有</span>  
<span style="margin-left: 1em">尚書制度圖纂三卷自立齋詩文十卷</span>  
<span style="margin-left: 1em">陸侗字養正詩莊瞻豪偉其題詠景物尤善想像往往</span>  
<span style="margin-left: 1em">出人意表同時若王泳趙鎮殷汝舟姚玭俱能詩文汝</span>  
<span style="margin-left: 1em">舟尤長于經學</span>  
<span style="margin-left: 1em">任暉字東白吳之著姓也祖仁發歷官都水監父子文</span>  
<span style="margin-left: 1em">又繇秘書監遷考城令暉喜文史善賦詩脱去丸近雄</span>  
<span style="margin-left: 1em">健有法度與楊廉夫遊嘗邀至其家校讐詩章累日廉</span>  
<span style="margin-left: 1em">夫極愛重之有東白集</span>  
<span style="margin-left: 1em">彭汝器字宗璉上海人博學有史才嘗評宋史謂杜后</span>  
<span style="margin-left: 1em">遺命立太宗與宋宣公舍其子而立穆公同爲貽亂于</span>  
<span style="margin-left: 1em">後太宗問傳代之事趙普知爲太宗謀而不爲太祖謀</span>  
<span style="margin-left: 1em">欺天之罪不可逭神宗將崩宣仁預製小黃袍以備倉</span>  
<span style="margin-left: 1em">卒云立哲宗稱宋賢后當以宣仁爲冠貝瓊爲撰筆諫</span>  
<span style="margin-left: 1em">軒記深許其識古今得失大義以獲觀爲幸云</span>  
<span style="margin-left: 1em">國朝</span>  
<span style="margin-left: 1em">吳哲字子愚華亭人博學善屬文尤以詩名大爲楊鐵</span>  
<span style="margin-left: 1em">崖錢思復諸名家所賞嘗讀文丞相吟嘯集云忠臣就</span>  
<span style="margin-left: 1em">死古來無丞相謀生脱網羅要爲春秋明漢賊忍題風</span>  
<span style="margin-left: 1em">絮泣山河綱常道在詩千首骨肉情長賦六歌留得精</span>  
<span style="margin-left: 1em">誠等光岳奸魂佞魄奈愁何嘗出佐戎幕歸教授於鄉</span>  
<span style="margin-left: 1em">至老不倦自號澹雲野人</span>  
<span style="margin-left: 1em">陶振字子昌號釣鰲子父依金澤林氏遂家焉受學於</span>  
<span style="margin-left: 1em">楊廉夫通詩書春秋三經洪武初爲吳江訓以仵官房</span>  
<span style="margin-left: 1em">謫戍撰飛龍在天紫金山金水賦三篇表上　高皇帝</span>  
<span style="margin-left: 1em">嘉之去其戎籍得歸隱九峯之間授徒自給一夕爲虎</span>  
<span style="margin-left: 1em">所噬王達善以詩挽之有昔爲海上釣鰲客今作山中</span>  
<span style="margin-left: 1em">飼虎人之句國初法峻以微罪戍遣而又不克令終時</span>  
<span style="margin-left: 1em">論惜之所著有釣鰲集</span>  
<span style="margin-left: 1em">金鉉字文鼎其先汴人宋南渡徙華亭瀟灑絶俗不苟</span>  
<span style="margin-left: 1em">交際性嗜吟咏尤精書畫稱爲三絶洪武中徵居京師</span>  
<span style="margin-left: 1em">奉母行侍養甚適生事死哀一如喪父遇有義舉赴之</span>  
<span style="margin-left: 1em">如不及楊文敏公聞其名寄詩通問竟不一答以是益</span>  
<span style="margin-left: 1em">高之居建業十年作一小樓扁曰清風高人韻士過之</span>  
<span style="margin-left: 1em">必延登觴咏及歸鄉居跡幽遠未嘗一涉塵事亦不濡</span>  
<span style="margin-left: 1em">足公門宣德中以子純貴封中書舍人正統元年卒所</span>  
<span style="margin-left: 1em">著有鳳城稿尚素前集</span>  
<span style="margin-left: 1em">周彦才華亭人清慎有學不樂仕進喜吟咏有灌畦稿</span>  
<span style="margin-left: 1em">藏于家子冕字士瞻號雪舫亦以詩名</span>  
<span style="margin-left: 1em">殷奎字孝章一字孝伯華亭人少從楊維禎授春秋嘗</span>  
<span style="margin-left: 1em">應鄉試不利遂謝去洪武四年以薦赴京試高等例授</span>  
<span style="margin-left: 1em">州縣職因母老請近地便養忤意調陝西咸陽教諭盡</span>  
<span style="margin-left: 1em">心教事在任四年念其母不置鬱鬱而死年止四十有</span>  
<span style="margin-left: 1em">六門人私謚文懿先生奎文章精審有法尤深于性理</span>  
<span style="margin-left: 1em">勤于纂述所著有道學統緒圖家祭儀宦咸陽有咸陽</span>  
<span style="margin-left: 1em">志關中名勝集陝西圖經婁曲叢稿支離稿渭城寐語</span>  
<span style="margin-left: 1em">後徒家崑山有崑山志然祖墓在華亭歲必歸省焉奎</span>  
<span style="margin-left: 1em">二弟璧字孝連箕字孝楊俱明經篤于孝友奎卒璧間</span>  
<span style="margin-left: 1em">關數千里迎其柩歸箕舉秀才試廣西僉事終太平府</span>  
<span style="margin-left: 1em">推官</span>  
<span style="margin-left: 1em">張黻字孟著華亭人書學陳文東勁健有法歷大理寺</span>  
<span style="margin-left: 1em">副至禮部員外郎</span>  
<span style="margin-left: 1em">顧禄字謹中華亭人洪武中爲太常典簿自少才藻豔</span>  
<span style="margin-left: 1em">發能詩善書國初詩人袁景文而下即稱謹中有過鄱</span>  
<span style="margin-left: 1em">陽湖詩其一聯云放歌今日容豪容破敵當年想至尊</span>  
<span style="margin-left: 1em">聞入禁中　太祖命盡選其作一日解縉便殿見　上</span>  
<span style="margin-left: 1em">所嘗御之處有禄詩數帙蓋深喜之也今集名經進以</span>  
<span style="margin-left: 1em">此</span>  
<span style="margin-left: 1em">董紀字良史上海人父成字性存有詩名紀詞翰俱美</span>  
<span style="margin-left: 1em">與袁景文陸宅之吳子愚輩相頡頏洪武初舉任江西</span>  
<span style="margin-left: 1em">僉事尋引疾歸所著有西郊笑端集</span>  
<span style="margin-left: 1em">顧彧字孔文上海人舉明經爲鄉邑訓導詩文豪整奇</span>  
<span style="margin-left: 1em">麗有古作者風與錢鼒賴良結詩盟雄于元季累官至</span>  
<span style="margin-left: 1em">户部侍郎</span>  
<span style="margin-left: 1em">陳璧字文東華亭人以文學知名尤善書篆隸真草流</span>  
<span style="margin-left: 1em">宕快健富於繩墨洪武間以秀才任解州判官調湖廣</span>  
<span style="margin-left: 1em">郴州卒郡人學書者皆宗之</span>  
<span style="margin-left: 1em">陸宗善字尚訥華亭人以碩學高行舉于鄉再令劇邑</span>  
<span style="margin-left: 1em">所至有惠政善書流麗雄偉而不忘規正字畫清勁三</span>  
<span style="margin-left: 1em">衢金實亟稱之子顧言顧行有詩名</span>  
<span style="margin-left: 1em">張璧字景辰夢辰之弟洪武三年開科取士璧即應舉</span>  
<span style="margin-left: 1em">中式與同郡俞嘉言陶南邨李處仁爲文學友仕終蜀</span>  
<span style="margin-left: 1em">府典寶嘗校文福建歸林宗高畫閩溪放棹圖陶南邨</span>  
<span style="margin-left: 1em">送之詩云一棹閩溪下瀨舡千岩萬壑路勾連榕陰處</span>  
<span style="margin-left: 1em">處浮嵐外杜宇聲聲落照邊考試來臨多士上宦遊向</span>  
<span style="margin-left: 1em">在十年前故人分手難分別寫得雲山上蜀牋璧好題</span>  
<span style="margin-left: 1em">詠凡遊卷軸多借以爲重璧每題必署尾曰陳留張璧</span>  
<span style="margin-left: 1em">趙友同字彦如金華人宋荆王元儼之後父良仁博學</span>  
<span style="margin-left: 1em">邃醫遷華亭友同刻志讀書嘗從宋景濂遊攻古文詞</span>  
<span style="margin-left: 1em">及舉子業胡儼爲華亭學教諭舉爲訓導既而浙江聘</span>  
<span style="margin-left: 1em">典鄉試滿九載當遷姚少師言其深于醫遂授御醫又</span>  
<span style="margin-left: 1em">有言其知水事者詔從夏原吉治水後大臣數薦其文</span>  
<span style="margin-left: 1em">學及修永樂大典以本官領副總裁修性理大全亦預</span>  
<span style="margin-left: 1em">焉書成賜金綺將官翰林以母喪去官尋卒八世孫原</span>  
<span style="margin-left: 1em">性重輯趙氏譜</span>  
<span style="margin-left: 1em">黃翰字汝申華亭人永樂壬辰進士授江西僉事陞參</span>  
<span style="margin-left: 1em">議奉璽書與都御史賈諒巡撫江西改參廣東陞山東</span>  
<span style="margin-left: 1em">按察使罷歸卒翰爲人豪上多權略始冠擢第觀政都</span>  
<span style="margin-left: 1em">察院有疑獄一問即決臺中皆驚居官所至能舉職江</span>  
<span style="margin-left: 1em">西人以妖術惑衆廣東畜蠱毒採生殺人皆捕誅之仍</span>  
<span style="margin-left: 1em">刻石著蠱毒及所以解之者自是術不得行俗爲一變</span>  
<span style="margin-left: 1em">常乘白驢入城市詩文操筆立就未嘗起草字畫遒勁</span>  
<span style="margin-left: 1em">錢驥字子良上海漢城里人永樂初以儒士舉任晉府</span>  
<span style="margin-left: 1em">紀善工詩文有砥壘集</span>  
<span style="margin-left: 1em">范鼎字文鉉華亭人生平練衣糲食刻志於學所居密</span>  
<span style="margin-left: 1em">邇關市終日端坐小樓事父兄孝敬讀書味聖賢之言</span>  
<span style="margin-left: 1em">力行不倦遇人有患難必盡力爲拯援諾人一言雖歲</span>  
<span style="margin-left: 1em">更月改必俟復之乃已家雖貧以教授爲業且善屬詩</span>  
<span style="margin-left: 1em">文書法鍾王晚年覃思于易或勸之仕則曰丈夫生世</span>  
<span style="margin-left: 1em">仕孰不願特吾非致用才也以能書膺薦預修　太宗</span>  
<span style="margin-left: 1em">文皇帝實錄書成例將授以官賚白金又懇以疾辭歸</span>  
<span style="margin-left: 1em">正統三年殁其先自宋文正公十一世孫安由蘇之槐</span>  
<span style="margin-left: 1em">里徙居華亭是爲先生六世祖</span>  
<span style="margin-left: 1em">王彦文號益齋華亭人嘗司訓府學教諭嘉興舉修永</span>  
<span style="margin-left: 1em">樂大典領詩經副總裁所著有詩傳旁通行世</span>  
<span style="margin-left: 1em">張璞字廷采居七寶鎮少刻意於學以詩畫名尤邃于</span>  
<span style="margin-left: 1em">易躬耕𤱶畝常袖一編以自隨或肩裝遇佳山水名跡</span>  
<span style="margin-left: 1em">徘徊悲嘯累日不能去踰歲歸以貢入胄監祭酒陳敬</span>  
<span style="margin-left: 1em">宗剛方少許可一見即留置內廂尋授陳州學正興教</span>  
<span style="margin-left: 1em">補敝風采一新少有篤行大父東村翁久病弗治躬理</span>  
<span style="margin-left: 1em">便液蓬垢皸胼自留京還有兄弟同舟病者衆欲置之</span>  
<span style="margin-left: 1em">璞曰置於岸即死遂給其費調護之將分途又探白金</span>  
<span style="margin-left: 1em">資其行竟不問姓名撰易髓一卷及淮陽志若干卷</span>  
<span style="margin-left: 1em">曹安字以寧華亭人正統甲子舉人任鄢陵訓導陞武</span>  
<span style="margin-left: 1em">邑教諭素負才名博學能文章揮毫立就居恒不廢撰</span>  
<span style="margin-left: 1em">著張東海贈之詩云著書只欲明忠義垂槖何曾寄有</span>  
<span style="margin-left: 1em">無其見重如此所作文曰取嗤稿詩曰蟋蟀吟皆失傳</span>  
<span style="margin-left: 1em">獨讕語長語行世</span>  
<span style="margin-left: 1em">朱應祥字岐鳳其先居鳳凰山後應祥秀眉廣口雙瞳</span>  
<span style="margin-left: 1em">烱然邑人徐主事觀家多書嘗從借文獻通考一册經</span>  
<span style="margin-left: 1em">日送還曰已覽遍矣觀疑其妄摘問之應答如響乃大</span>  
<span style="margin-left: 1em">驚盡出所有書借之於是學益閎富滚滚萬言疾如風</span>  
<span style="margin-left: 1em">雨書兼數家遒勁有法度尤長於題壁同時虞山桑民</span>  
<span style="margin-left: 1em">懌虎林張天錫並以文名而未相識一日遊湖上即席</span>  
<span style="margin-left: 1em">賦詩天錫爲之閣筆性豪邁濶畧不能爲細謹成化丁</span>  
<span style="margin-left: 1em">酉始以歲貢薦南畿上春官復不利遂放意文酒著高</span>  
<span style="margin-left: 1em">士巾衣鶴氅衣與名流相倡和未幾卒所著述多軼惟</span>  
<span style="margin-left: 1em">鳳山稿數十篇僅存</span>  
<span style="margin-left: 1em">王一鵬字九萬號西園華亭人弘治中以明經授泰順</span>  
<span style="margin-left: 1em">訓導二年即告歸性寥廓蕭灑綽似晉人工詩善書畫</span>  
<span style="margin-left: 1em">恬淡閑雅成一家言居西塔衖搆小齋几上陳古鼎彝</span>  
<span style="margin-left: 1em">茶鐺酒鎗畢具其供筆硯即小鬟也客至竟日夜爲笑</span>  
<span style="margin-left: 1em">譚或乞詩畫者履常滿户外又精曉音律時持檀板度</span>  
<span style="margin-left: 1em">新聲夷猶泉壑幾九十年未嘗措足名利塲亦不知世</span>  
<span style="margin-left: 1em">間有攢眉事云</span>  
<span style="margin-left: 1em">顧曦字東曙華亭人博學能詩其吊横雲山有玄堂千</span>  
<span style="margin-left: 1em">載寄崇阿石馬無聲墓草多故里尚傳前代事浮萍應</span>  
<span style="margin-left: 1em">落逝川波野人夜黑偷金盌山鬼矢寒泣翠蘿莫問人</span>  
<span style="margin-left: 1em">間興與廢夕陽回首自興歌顧文僖以呈李文正公公</span>  
<span style="margin-left: 1em">曰不意山林乃有此作同時戚龍淵韶張一桂冕與曦</span>  
<span style="margin-left: 1em">孫文簡公合爲三詩翁集</span>  
<span style="margin-left: 1em">高企字進之上海人居唐行鎮年十七喪母往姑蘇求</span>  
<span style="margin-left: 1em">吳文定公墓文以葬文定奇而與之事伯兄如父與人</span>  
<span style="margin-left: 1em">交洞徹肺腑論辨英偉顧文僖公嘗修郡乘田糧水利</span>  
<span style="margin-left: 1em">企考索之力居多企文僖弟子也後邑令鄭洛書嘗以</span>  
<span style="margin-left: 1em">糧額不同欲均之發策以訪衆論企以糧有輕重田有</span>  
<span style="margin-left: 1em">高下即古人則壤成賦之意松之田糧宋初王贄定稅</span>  
<span style="margin-left: 1em">不過每畝一斗今官田有二三斗以至五六斗者皆以</span>  
<span style="margin-left: 1em">元人抄没大户田畝入官仍其租額而取之遂爲官田</span>  
<span style="margin-left: 1em">我　皇祖以蘇松久爲張士誠竊據更新詔令不得開</span>  
<span style="margin-left: 1em">除而科則尤存松人受困于田者已久昔元季亦欲均</span>  
<span style="margin-left: 1em">糧矣集十三郡會議劉總管獨不肯昔周文襄經理東</span>  
<span style="margin-left: 1em">南耆碩杜宗桓亦嘗上書均糧文襄公亦不肯二公必</span>  
<span style="margin-left: 1em">有深見苟爲法便二公當先爲之奚俟今日企乃歷考</span>  
<span style="margin-left: 1em">田糧積重之故各有據實爲田糧策以力陳其不可鄭</span>  
<span style="margin-left: 1em">不然其策浙江水利僉憲朱子和兼理蘇松水利檄有</span>  
<span style="margin-left: 1em">司延企訊之企曰吳淞之水淤於上海者夏忠靖公原</span>  
<span style="margin-left: 1em">吉陳參政禎時疏范家浜接黃浦以入海而吳淞則未</span>  
<span style="margin-left: 1em">及施功坐是日淺而浦奪江權矣黃浦上接嘉湖二郡</span>  
<span style="margin-left: 1em">近城湖泖縱浦横塘各爲灌注皆有脈絡歷歷指陳又</span>  
<span style="margin-left: 1em">詳考宋朝士夫論議及元人論水監敷治之宜爲水利</span>  
<span style="margin-left: 1em">書以上之其書固有存者企少游邑庠垂老一無所遇</span>  
<span style="margin-left: 1em">天性蕭閑喜吟咏詩文高古時探名勝年八十餘能躋</span>  
<span style="margin-left: 1em">山絶頂又三載卒</span>  
<span style="margin-left: 1em">戚韶字龍淵唐行鎮人好古博雅與王良臣張冕並以</span>  
<span style="margin-left: 1em">詩名意氣豪邁其詩亦若燕趙奇士矯抗自信與孫文</span>  
<span style="margin-left: 1em">簡公初不深識作二詩送之北上文簡深銘之韶之没</span>  
<span style="margin-left: 1em">也爲刻其詩以示掛劍之義</span>  
<span style="margin-left: 1em">黃標字良玉上海人藏書甚富繙閲無問寒暑叩之如</span>  
<span style="margin-left: 1em">指諸掌舅陸文裕公深臨文有疑義必屬標考核與人</span>  
<span style="margin-left: 1em">談經濟鑿鑿可行輯古今說海一百四十二卷選陸文</span>  
<span style="margin-left: 1em">裕集一百卷所著有書經異同二十二卷縣志稿十卷</span>  
<span style="margin-left: 1em">俱燬於倭惟戊巳庚子二稿尚存</span>  
<span style="margin-left: 1em">王鑄號毖齋華亭人嘉靖戊子領鄉薦選龍溪令邑學</span>  
<span style="margin-left: 1em">五科不舉鑄乃闢地建坊連舉數人名騰薦剡秩當遷</span>
