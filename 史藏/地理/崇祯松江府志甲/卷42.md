## 崇祯松江府志卷之四十二　人物七（文学隐逸艺术）

<span style="margin-left: 3em">文学</span>  
<span style="margin-left: 1em">汉尚经术别有文学掌故其次脔龙虎之章熠凤鸾之</span>  
<span style="margin-left: 1em">羽抽毫拂简智思入渊郡不乏才彬彬郁郁于斯为盛</span>  
<span style="margin-left: 1em">矣宋景濂曰文学之事身任者众要以圣人之文为宗</span>  
<span style="margin-left: 1em">滥觞无已轨诸仲尼其在游夏之徒欤</span>  
<span style="margin-left: 1em">宋</span>  
<span style="margin-left: 1em">朱之纯元祐进士有文章名淡于时趣作湖斋于谷阳</span>  
<span style="margin-left: 1em">园自号谷阳先生尝题湖斋志序云予湖上治圃于桃</span>  
<span style="margin-left: 1em">根获古龟六枚其小如钱又云间有仙鹤观每岁中秋</span>  
<span style="margin-left: 1em">夜有仙鹤下观因得名余治圃谷水邻诗曰平湖十顷</span>  
<span style="margin-left: 1em">水汪洋得意茅斋且屈藏园种小桃今结子池栽翠芰</span>  
<span style="margin-left: 1em">更闻香六龟已作千年瑞双鹤看呈八月祥居此翛然</span>  
<span style="margin-left: 1em">忘世味此心犹嬾醉龙阳有诗文集行于世</span>  
<span style="margin-left: 1em">杜可久平章杜祁公衍之后为青龙直学有文行立日</span>  
<span style="margin-left: 1em">课以训迪诸生勤敏不倦士友乐之遂家于西霞浦墓</span>  
<span style="margin-left: 1em">在杜村</span>  
<span style="margin-left: 2em">青龙志云今子孙散居华亭海上代有闻人又梧溪</span>  
<span style="margin-left: 2em">集载杜好古名敏宋祁公后世隐青龙累谢征辟</span>  
<span style="margin-left: 1em">储泳字文卿上海人有诗名精于阴阳五行通儒玄理</span>  
<span style="margin-left: 1em">其言道家之行持即吾儒之格物行持以正心诚意为</span>  
<span style="margin-left: 1em">本心不正不足感物意不诚不足通神神运于此物应</span>  
<span style="margin-left: 1em">于彼故虽万里可驱摄于呼吸间非至神孰能与于此</span>  
<span style="margin-left: 1em">盖广大无际者心也隔碍潜通者神也心不存则不明</span>  
<span style="margin-left: 1em">神不养则不灵正以持久而明诚以养极而灵世之学</span>  
<span style="margin-left: 1em">者不务养平时而遽施一旦亦犹汲甘泉于枯井采英</span>  
<span style="margin-left: 1em">华于槁木不可得矣所著有祛疑说人争传录弟溒字</span>  
<span style="margin-left: 1em">智卿亦以诗名</span>  
<span style="margin-left: 1em">朱允恭字尔靖与族人藤州守日新号足庵者并以诗</span>  
<span style="margin-left: 1em">名四灵赵天乐选允恭诗二百余首为集行世</span>  
<span style="margin-left: 1em">朱象先松陵人东坡称其能文而不求举善画而不求</span>  
<span style="margin-left: 1em">售曰文以达吾心画以适吾意而已</span>  
<span style="margin-left: 1em">陆霆龙字伯灵华亭人咸淳乡贡进士宋亡即栖隐讲</span>  
<span style="margin-left: 1em">授终其身衣冠不易尝自赞画像云勤勤劬劬耽嗜慕</span>  
<span style="margin-left: 1em">悦而不忍舍者圣贤之书趦趦趄趄畏懦退缩而不敢</span>  
<span style="margin-left: 1em">登者世利之途晕轻霞以为脸缕积雪以成衣衣前后</span>  
<span style="margin-left: 1em">而襜如俨张拱而徐趋获者见之而指笑此必抱遗经</span>  
<span style="margin-left: 1em">行古道之拘儒</span>  
<span style="margin-left: 1em">许尚号和光老人能诗文有华亭百咏<sub class="note-yuan">见旧志</sub></span>  
<span style="margin-left: 1em">许寔元丰间居吴之笠泽本松江人后乃徙居于婺生</span>  
<span style="margin-left: 1em">许白云先生谦以理学著称元世然实本之于寔云寔</span>  
<span style="margin-left: 1em">常受业于胡文昭公瑗学有旨归持己教人能以师法</span>  
<span style="margin-left: 1em">终始当世翕然称之</span>  
<span style="margin-left: 1em">胡林卿华亭人淳熙甲科绍熙癸丑新除迪功郎饶州</span>  
<span style="margin-left: 1em">州学教授史弥远柄国势燄薰天林卿与同籍终身不</span>  
<span style="margin-left: 1em">登其门及卒有挽诗云有名登相甲无迹到权门丰节</span>  
<span style="margin-left: 1em">𪷤𪷤为时所重初县未有志林卿始与知县杨潜同邑</span>  
<span style="margin-left: 1em">林至朱端常同修为三卷号云间志子琚嘉定进士学</span>  
<span style="margin-left: 1em">识该博能诗有静庵集行于世</span>  
<span style="margin-left: 1em">林至字德久华亭人淳熙释褐历官秘书省登晦庵先</span>  
<span style="margin-left: 1em">生之门与晦翁书词反复称其参悟日进晦翁独好离</span>  
<span style="margin-left: 1em">骚至有释骚师门之教也文集四卷行世子革世其学</span>  
<span style="margin-left: 1em">登嘉定进士</span>  
<span style="margin-left: 1em">叶汝舟字济川华亭人登开庆进士有刊行通鉴笔义</span>  
<span style="margin-left: 1em">所著诗文藏于家</span>  
<span style="margin-left: 1em">卫宗武字洪父华亭人以父荫官省门至常州守别号</span>  
<span style="margin-left: 1em">水北文及翁序其诗文名秋声集</span>  
<span style="margin-left: 1em">元</span>  
<span style="margin-left: 1em">凌嵒字山英号石泉其先少师哲靖康中自汴随跸南</span>  
<span style="margin-left: 1em">迁徙居华亭遂为邑人嵒少习举子业会宋亡即卷取</span>  
<span style="margin-left: 1em">藏一放于诗镕意铸辞锵鸣秀拔骎寻大历有古木风</span>  
<span style="margin-left: 1em">瓢集</span>  
<span style="margin-left: 1em">曾遇字心传华亭人宋丞相曾公亮之裔博学敏文词</span>  
<span style="margin-left: 1em">尤攻书学元时以荐授湖州路安吉县丞致仕与王昭</span>  
<span style="margin-left: 1em">大詹润徐顺齐誉称为云间四俊</span>  
<span style="margin-left: 1em">庄肃字恭叔号蓼塘居于上海之青龙镇仕宋为秘书</span>  
<span style="margin-left: 1em">小史宋亡弃去放身海上性嗜书聚书至八万卷且多</span>  
<span style="margin-left: 1em">手抄者经史子集山经地志医卜方技稗官小说靡所</span>  
<span style="margin-left: 1em">不具书目以甲乙分十门至正间修宋辽金三史诏求</span>  
<span style="margin-left: 1em">遗书江南藏书多者三家庄其一也命简讨危素购书</span>  
<span style="margin-left: 1em">于其家得五百卷所著有艺经画继余谱传于时</span>  
<span style="margin-left: 2em">辍耕录载蓼塘既没子孙不知保惜或为虫鼠蚀啮</span>  
<span style="margin-left: 2em">或为邻室盗窃或供饮博之需或应翻覆之用编帙</span>  
<span style="margin-left: 2em">散乱所存无几至正间诏求遗书有以书献者予一</span>  
<span style="margin-left: 2em">官继命危学士来选取其家恐兵遁图谶干犯禁条</span>  
<span style="margin-left: 2em">悉付祝融氏及收拾烬余存者又无几矣其孙群玉</span>  
<span style="margin-left: 2em">悉载入京觊领恩泽宿留日久仍布衣而归书之不</span>  
<span style="margin-left: 2em">幸如此</span>  
<span style="margin-left: 1em">邵亨贞字复孺其王父桂子有别业于华亭娶曹泽之</span>  
<span style="margin-left: 1em">女因家小蒸遂为华亭人亨贞博通经史赡于文词工</span>  
<span style="margin-left: 1em">真草篆隶凡阴阳医卜佛老之学尽究其奥与陶九成</span>  
<span style="margin-left: 1em">为莫逆交自号见独居士当时得其片语寸楮以为家</span>  
<span style="margin-left: 1em">乘光所著有蛾术稿皆出手笔点画不苟足为后学楷</span>  
<span style="margin-left: 1em">式云元末兵燹其家侨居横泖洪武初为府学训导卒</span>  
<span style="margin-left: 1em">年九十三子伯宣有学庵集古诗能世其业</span>  
<span style="margin-left: 2em">陶南村赠邵青溪先生藜杖乌纱过百年童颜鹤发</span>  
<span style="margin-left: 2em">气泠然窝尊安乐元通谱壶隐虚闲别有天课稼春</span>  
<span style="margin-left: 2em">行黄犊外寻盟时到白鸥前青溪一曲春如许二顷</span>  
<span style="margin-left: 2em">何须负郭田</span>  
<span style="margin-left: 1em">陆鹏南字象翁明毛诗不仕文章劲健邑中推为乡先</span>  
<span style="margin-left: 1em">生与陆伯灵齐名乡里称为二陆所著诗文名九峰清</span>  
<span style="margin-left: 1em">气集</span>  
<span style="margin-left: 1em">章弼字拱辰华亭人识度清远绝无俗韵聚古经史书</span>  
<span style="margin-left: 1em">潜心笃志亹亹忘倦十岁时即能扁榜大字长益有名</span>  
<span style="margin-left: 1em">真行草篆皆师赵魏公</span>  
<span style="margin-left: 1em">陈宏字君宏号碧壶莆田人徙居华亭初试吏于府不</span>  
<span style="margin-left: 1em">久弃去遂以儒起家同知吴江州事其学邃于易尝著</span>  
<span style="margin-left: 1em">易象发挥易孟通言童子问并传于世</span>  
<span style="margin-left: 1em">王昭大字茂卿人称为玉岩先生华亭人博综经传于</span>  
<span style="margin-left: 1em">易尤精诣耄期始调潮州路学教授不以淹晚概怀继</span>  
<span style="margin-left: 1em">署乡邑丞致仕至正间年逾大耋时诏例赐致仕官金</span>  
<span style="margin-left: 1em">文彩币先生美髯修干被服恩荣夷犹里陌咸尊礼之</span>  
<span style="margin-left: 1em">詹润号肖梅以父号梅臞也少有俊气及壮以文儒为</span>  
<span style="margin-left: 1em">诸暨州学正秩满例试艺于路教授始得流品官润太</span>  
<span style="margin-left: 1em">息曰以我之才试教授耶即日襆被归乡梓教授以终</span>  
<span style="margin-left: 1em">徐顺孙字子静父号菊存因自号敬菊经术该用性笃</span>  
<span style="margin-left: 1em">孝痛父母蚤亡誓不娶以见志年四十余朋曹彊为娶</span>  
<span style="margin-left: 1em">未几而卒众诔而哀之顺孙尝读秦纪赋诗云大药若</span>  
<span style="margin-left: 1em">从三岛至苍生能有几家存时传诵之</span>  
<span style="margin-left: 1em">王默字子章一字伯静文泽子长八尺美须髯谈吐甚</span>  
<span style="margin-left: 1em">高亮少任侠多技艺弱冠更折节读书书法赵魏公行</span>  
<span style="margin-left: 1em">笔甚健征至京书金字浮屠经拟官翰林见时运已否</span>  
<span style="margin-left: 1em">力辞归求书者户满父殁尽鬻书买山以葬庐墓下者</span>  
<span style="margin-left: 1em">久之尤喜为人排难解纷奋不顾利害张伯雨称其豪</span>  
<span style="margin-left: 1em">宕不羁有姜白石风子基洪武初举孝廉为潞州判尝</span>  
<span style="margin-left: 1em">著雪斋明鉴录秦裕伯亟称之</span>  
<span style="margin-left: 1em">李介石字守道郡人为人高爽英迈善祠翰喜与人谈</span>  
<span style="margin-left: 1em">诗诗称能品困约无所遇徽寇陷杭以书见省臣命草</span>  
<span style="margin-left: 1em">符檄遂器重之授为松江提控案牍从省臣守镇江兵</span>  
<span style="margin-left: 1em">败不屈死殆古之节侠士也所居有煮雪虀瓮白石窝</span>  
<span style="margin-left: 1em">王逢赠之以诗</span>  
<span style="margin-left: 1em">章瑾字公瑾青龙人庄敏公楶之后徙李墟能诗草书</span>  
<span style="margin-left: 1em">法二王尤长于画为人有高致日登山临水所至成趣</span>  
<span style="margin-left: 1em">遇知己觞咏竟日画或顷刻可就或数日不著一笔盖</span>  
<span style="margin-left: 1em">张可观以后一人而已</span>  
<span style="margin-left: 1em">陆居仁字宅之霆龙子以诗经中泰定丙寅乡试工诗</span>  
<span style="margin-left: 1em">古文以著作自雄书法精微目中不可一世隐居教授</span>  
<span style="margin-left: 1em">于松松人士翕然宗之与杨维祯钱惟善游殁同葬于</span>  
<span style="margin-left: 1em">干山之北号三高士墓</span>  
<span style="margin-left: 2em">宅之殁王逢挽之曰宅之尝赞予画像云辩如悬河</span>  
<span style="margin-left: 2em">思如涌泉斗酒百篇倚马万言慷慨如奇材之剑客</span>  
<span style="margin-left: 2em">潇洒如锦袍之谪仙第未知伏轼而掉三寸击楫而</span>  
<span style="margin-left: 2em">快一鞭于斯二者子将奚先其爱我如是斯人不可</span>  
<span style="margin-left: 2em">作矣诗以哭之游戏清真帖优长雅颂文世方趋赵</span>  
<span style="margin-left: 2em">孟天竟滞刘蕡教施河汾曲身浮淀泖云飞花时事</span>  
<span style="margin-left: 2em">革过雁讣音闻有女哀扶衬多予望荐苹陋容看转</span>  
<span style="margin-left: 2em">老空辱许奇勋</span>  
<span style="margin-left: 1em">王文泽字伯雨谱称王茂弘后家华亭风泾迁上海祖</span>  
<span style="margin-left: 1em">大言父京并有文章文泽学尤富落笔不肯蹈袭前人</span>  
<span style="margin-left: 1em">一语所交多当世名士累举不第为府学训导所著有</span>  
<span style="margin-left: 1em">尚书制度图纂三卷自立斋诗文十卷</span>  
<span style="margin-left: 1em">陆侗字养正诗庄瞻豪伟其题咏景物尤善想像往往</span>  
<span style="margin-left: 1em">出人意表同时若王泳赵镇殷汝舟姚玭俱能诗文汝</span>  
<span style="margin-left: 1em">舟尤长于经学</span>  
<span style="margin-left: 1em">任晖字东白吴之著姓也祖仁发历官都水监父子文</span>  
<span style="margin-left: 1em">又繇秘书监迁考城令晖喜文史善赋诗脱去丸近雄</span>  
<span style="margin-left: 1em">健有法度与杨廉夫游尝邀至其家校讐诗章累日廉</span>  
<span style="margin-left: 1em">夫极爱重之有东白集</span>  
<span style="margin-left: 1em">彭汝器字宗琏上海人博学有史才尝评宋史谓杜后</span>  
<span style="margin-left: 1em">遗命立太宗与宋宣公舍其子而立穆公同为贻乱于</span>  
<span style="margin-left: 1em">后太宗问传代之事赵普知为太宗谋而不为太祖谋</span>  
<span style="margin-left: 1em">欺天之罪不可逭神宗将崩宣仁预制小黄袍以备仓</span>  
<span style="margin-left: 1em">卒云立哲宗称宋贤后当以宣仁为冠贝琼为撰笔谏</span>  
<span style="margin-left: 1em">轩记深许其识古今得失大义以获观为幸云</span>  
<span style="margin-left: 1em">国朝</span>  
<span style="margin-left: 1em">吴哲字子愚华亭人博学善属文尤以诗名大为杨铁</span>  
<span style="margin-left: 1em">崖钱思复诸名家所赏尝读文丞相吟啸集云忠臣就</span>  
<span style="margin-left: 1em">死古来无丞相谋生脱网罗要为春秋明汉贼忍题风</span>
