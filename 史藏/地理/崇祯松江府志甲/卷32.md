## 崇禎松江府志卷之三十二　宦績五（國朝名宦）

<span style="margin-left: 3em">國朝名臣宦績<sub class="note-yuan">二</sub></span>  
<span style="margin-left: 1em">金洪號曰湖浙江鄞縣人成化丁未進士授靖江知縣</span>  
<span style="margin-left: 1em">改吳江陞御史巡按陝西山東裁抑閹宦逆瑾不能堪</span>  
<span style="margin-left: 1em">揭其名於壁使人諷之冀以賂謝卒不爲理乃欲擯之</span>  
<span style="margin-left: 1em">邊郡而吏部持之得補松江瑾怒未解會洪嘗减松江</span>  
<span style="margin-left: 1em">官布價米庫閹不得賂詭以布惡言於瑾械至京賴案</span>  
<span style="margin-left: 1em">牘明甚竟不能害</span>  
<span style="margin-left: 1em">劉璟號怡閒河南鄢陵人成化乙未進士二十二年以</span>  
<span style="margin-left: 1em">刑部郎陞松江知府至弘治七年以憂去在松八載督</span>  
<span style="margin-left: 1em">率吏民勸農桑修水利敦士習勢豪某殺人前守莫能</span>  
<span style="margin-left: 1em">治璟置之法豪右皆斂跡海上有城隍威靈太守廉明</span>  
<span style="margin-left: 1em">之謡郡人張某曾爲鄢陵學諭璟師也致仕家居非公</span>  
<span style="margin-left: 1em">事未嘗一造郡齋璟嘗候之問政有疾璟朝夕往視自</span>  
<span style="margin-left: 1em">進湯藥比卒爲持心喪其第久鬻於人出俸贖歸其子</span>  
<span style="margin-left: 1em">松人至今兩賢之官至太子少保刑部尚書璟性剛直</span>  
<span style="margin-left: 1em">不阿上官幾爲持斧者羅織以墨時有府椽史周禋挺</span>  
<span style="margin-left: 1em">身出白之事載禋傳</span>  
<span style="margin-left: 1em">李充嗣號梧山四川內江人成化丁未進士正德戊寅</span>  
<span style="margin-left: 1em">巡撫南畿己卯加工部尚書治江南水務仍兼巡撫以</span>  
<span style="margin-left: 1em">白茅港吳淞江二派爲諸水之噤喉太湖之尾閭也首</span>  
<span style="margin-left: 1em">興事焉界水道爲井地示以開鑿法户占一區計工刻</span>  
<span style="margin-left: 1em">日先竟者賞後者罰人人樂於趨事凡椿木畚鍤給賞</span>  
<span style="margin-left: 1em">僱直之費皆括諸屬帑羡餘遴選賢能有司以主出納</span>  
<span style="margin-left: 1em">復教設巨筏數百曳木齒隨潮進退以汰沙泥名曰濬</span>  
<span style="margin-left: 1em">川杷又置小艇百餘隨鐵帚于尾以爲疏導名曰鐵掃</span>  
<span style="margin-left: 1em">帚自是潮汐不憂壅塞淫雨不患汎濫蓄洩有道旱澇</span>  
<span style="margin-left: 1em">有恃食其利者甚溥而京儲不至匱乏矣陞南京兵部</span>  
<span style="margin-left: 1em">尚書卒贈太子太保謚康和</span>  
<span style="margin-left: 2em">何良俊曰白茅塘自李充嗣巡撫時曾一開浚是嘉</span>  
<span style="margin-left: 2em">靖初年其所費不貲今吳淞江之費特十之二三耳</span>  
<span style="margin-left: 2em">由海公瑞清白不妄用又用法嚴也然白茅塘不二</span>  
<span style="margin-left: 2em">十年即已湮塞蓋海中皆渾水潮來時渾水湧入潮</span>  
<span style="margin-left: 2em">平後停一時始落渾泥皆淀在河底河焉得不湮塞</span>  
<span style="margin-left: 2em">哉夏忠靖公治水時均徭內原編有淘河夫銀今不</span>  
<span style="margin-left: 2em">知作何項支銷去矣<sub class="note-yuan">叢說</sub></span>  
<span style="margin-left: 1em">何瀞字源清廣東東莞人成化壬辰進士授本府推官</span>  
<span style="margin-left: 1em">明允清慎門無私謁知府王衡贈詩有關門共惜寒儒</span>  
<span style="margin-left: 1em">苦斷獄争誇老吏明之句後陞御史終僉事</span>  
<span style="margin-left: 1em">董鑰字啓之浙江鄞縣人弘治六年尹上海縣明辨善</span>  
<span style="margin-left: 1em">幹理築西鄉田園堤防以捍水患太史錢福爲文記之</span>  
<span style="margin-left: 1em">原應宿陽城人弘治間以鄉舉授府倅署上海縣剛達</span>  
<span style="margin-left: 1em">明果敏于立事其董水利尤力濬堙鑿隘大利農畝而</span>  
<span style="margin-left: 1em">興工給費亦有調度公不匱財民不見病邑人稱之</span>  
<span style="margin-left: 1em">馬騤號梅軒解州夏縣人弘治丙辰進士授行人選兵</span>  
<span style="margin-left: 1em">科給事中馬端肅公見其諫草驚曰董賈未之或先儀</span>  
<span style="margin-left: 1em">觀俊整進退中度　孝宗默眷愛之嘗論李廣之黨宜</span>  
<span style="margin-left: 1em">窮治外戚之權宜禁戢諫官吳舜之狂直宜包容皆時</span>  
<span style="margin-left: 1em">政切要者　武宗即位有白金文綺之賜逆瑾用事騤</span>  
<span style="margin-left: 1em">盡言不少避忌瑾亦多勉從中有附瑾新入爲給舍者</span>  
<span style="margin-left: 1em">對賓僚誇毘甚有矜色騤鄙之以無耻客皆縮舌先是</span>  
<span style="margin-left: 1em">張綵拜瑾爲義父驟入銓衡騤自蜀還與綵父宿同驛</span>  
<span style="margin-left: 1em">館不與交一語綵聞之以爲慢己會時宰夙憾騤搆毁</span>  
<span style="margin-left: 1em">出爲淮安府推官已僅轉同知松江既視篆松松多富</span>  
<span style="margin-left: 1em">室積逋累細民騤廉得之鋭意清理豪不能肆數年逋</span>  
<span style="margin-left: 1em">稅一朝報完會丁外艱去有說騤宜少貶從容者正色</span>  
<span style="margin-left: 1em">曰窮通顯晦命也如命何</span>  
<span style="margin-left: 2em">公初入京主醫張圯館圯卒而無子爲買地以葬後</span>  
<span style="margin-left: 2em">爲松江同知背疽幾危一夕夢圯來視疾明日尋愈</span>  
<span style="margin-left: 2em">人以爲圯之冥祐公爲行人時使蜀館稱多怪人莫</span>  
<span style="margin-left: 2em">敢居徑入夜坐觀書忽壁上如人持挺而擊者二不</span>  
<span style="margin-left: 2em">爲動居父憂廬中磬不扣自鳴燈下見馘影如斗亦</span>  
<span style="margin-left: 2em">不爲動自松歸渡江會大風陡作舟師震懼無人色</span>  
<span style="margin-left: 2em">從容仰天祝曰吾平生或欺君虐民舟當沉否則息</span>  
<span style="margin-left: 2em">俄而風恬浪妥須臾數百里<sub class="note-yuan">湧幢</sub></span>  
<span style="margin-left: 1em">郭經字載道盧龍人弘治十一年知上海縣事簡民安</span>  
<span style="margin-left: 1em">稱爲樂邦以不能阿事上官擢開封二守去之日爲樹</span>  
<span style="margin-left: 1em">碑以頌其德<sub class="note-yuan">上海志</sub></span>  
<span style="margin-left: 1em">王廷相字子衡儀封人弘治壬戌進士選翰林庶吉士</span>  
<span style="margin-left: 1em">授兵科給事中謫判亳州陞高淳知縣授御史巡按山</span>  
<span style="margin-left: 1em">東陝西鎮守廖太監恨其每事禁抑搆下獄謫贛榆丞</span>  
<span style="margin-left: 1em">陞寧國知縣松江同知歷官兵部尚書加太子少師相</span>  
<span style="margin-left: 1em">不事浮躁帝搜玄覽居恒嘗自盟曰大識者外僞不能</span>  
<span style="margin-left: 1em">累大氣者外侮不能動大德者外物不能遷又曰權所</span>  
<span style="margin-left: 1em">以運國勢紀綱所以繫國脉人才所以主國命故國之</span>  
<span style="margin-left: 1em">不亡者三權不下移綱紀不隳不用小人以長國也又</span>  
<span style="margin-left: 1em">曰迂儒强執不識古今之宜鄙儒依阿不顧國家之計</span>  
<span style="margin-left: 1em">俗儒淺陋不達治忽之機皆不堪重任真名言也有識</span>  
<span style="margin-left: 1em">者書之座右</span>  
<span style="margin-left: 1em">傅鼎字用養福建閩縣人弘治己酉解元己未乙榜教</span>  
<span style="margin-left: 1em">諭華亭經學通邃尤長于易所著有易髓八卷其教士</span>  
<span style="margin-left: 1em">一以誠心實德化之人皆悦服嘗爲江西考官郡守之</span>  
<span style="margin-left: 1em">子就試遣吏授以一合啓封乃猪蹄四也蓋隱謎云鼎</span>  
<span style="margin-left: 1em">堅却弗受子亦不舉士論高之在任七年陞知龍川縣</span>  
<span style="margin-left: 1em">歲餘忽傳凶問邑諸生爲位三賢祠下朝夕泣奠絰而</span>  
<span style="margin-left: 1em">入者二十七日見而知其妄也以忤權貴左遷婺源改</span>  
<span style="margin-left: 1em">授吉安卒吉諸生具棺賻贈護其喪歸訃至華亭之泣</span>  
<span style="margin-left: 1em">奠如初遠致賻焉鼎交遊廣取予介其母兄妻子先後</span>  
<span style="margin-left: 1em">卒者六喪貧不能舉華亭周鵷以御史按閩乃克葬之</span>  
<span style="margin-left: 1em">天性孝友外柔內剛動以禮義自將家無餘積晏如也</span>  
<span style="margin-left: 1em">詩文清勁有體裁書亦如之所著有華峯集射禮圖著</span>  
<span style="margin-left: 1em">行于世</span>  
<span style="margin-left: 1em">陳祥號荷峯江西高安人弘治壬戌進士筮仕上虞正</span>  
<span style="margin-left: 1em">德二年補華亭邑令恒敗於利祥以守己廉肅遇事詳</span>  
<span style="margin-left: 1em">明一時稱賢令召爲監察御史歷官巡撫應天等府吏</span>  
<span style="margin-left: 1em">多冒没極力搜剔南畿宴然</span>  
<span style="margin-left: 1em">馮裕號閭山山東臨朐人正德戊辰進士令華亭性篤</span>  
<span style="margin-left: 1em">實薄於自奉廉於取民好執法不肯毫髮少假人劉瑾</span>  
<span style="margin-left: 1em">更張舊法內差添設私員民間大有誅求他令皆通融</span>  
<span style="margin-left: 1em">而裕獨堅挺不應邑大水西田多渰没東田稍收顧歲</span>  
<span style="margin-left: 1em">租不能全蠲尚徵其半適部使者至又加以租外新派</span>  
<span style="margin-left: 1em">民譁言裕加賦於民撫臺張公惑之下裕於獄既而察</span>  
<span style="margin-left: 1em">裕無他改知蕭縣待理時寓居鶴城書院歲餘空囊不</span>  
<span style="margin-left: 1em">充朝夕士大夫往往有饋遺相周者裕日惟賦詩吟咏</span>  
<span style="margin-left: 1em">自得無怨尤不平之意人尤賢之</span>  
<span style="margin-left: 2em">閭山馮公裕治華亭有惠故其去也民爲歌曰大水</span>  
<span style="margin-left: 2em">横發高樹低人死爲魚公悽悲誰使公去傷哉離公</span>  
<span style="margin-left: 2em">去華亭幾四十年其子少洲公名惟訥復來治松請</span>  
<span style="margin-left: 2em">祀公於學宫徐獻忠記畧曰昔在正德己巳公來治</span>  
<span style="margin-left: 2em">民任真履平不事繢餙事有利者即力任之方是中</span>  
<span style="margin-left: 2em">官操竊名器郡長吏有出其門者頗事斂括公不承</span>  
<span style="margin-left: 2em">其意旨遂爲所不樂是歲秋大水自邑以西漭爲巨</span>  
<span style="margin-left: 2em">壑民饑餓死者甚衆而糧額不蠲减監司者又適去</span>  
<span style="margin-left: 2em">任乃不待報請移其稅於高鄉繼而監司者至郡長</span>  
<span style="margin-left: 2em">吏乃從其中搆之幾中於禍民相率聲其寃僅得調</span>  
<span style="margin-left: 2em">蕭縣去</span>  
<span style="margin-left: 1em">徐潭號一軒浙江定海人弘治癸丑進士正德戊辰授</span>  
<span style="margin-left: 1em">上海令其俗區長里魁歲有常例輸官皆斥不取遇歲</span>  
<span style="margin-left: 1em">大祲設法賑濟多所全活先是訟者遣卒逮捕即倚勢</span>  
<span style="margin-left: 1em">需索民不勝苦潭乃造木人於庭有陳訴者即令持至</span>  
<span style="margin-left: 1em">所訴之家其人抱木人自詣無敢後者宿害遂捐邑之</span>  
<span style="margin-left: 1em">豪右率逋官租而區長往往破家以償潭嚴懲其弊植</span>  
<span style="margin-left: 1em">怨豪右會督儲憲臣又索常例不與乃以事中傷改令</span>  
<span style="margin-left: 1em">湘潭官至憲副</span>  
<span style="margin-left: 1em">陳威號畏菴江西臨川人任御史正德五年出守松江</span>  
<span style="margin-left: 1em">時己巳庚午連年水災威下車留心賑恤民賴以甦積</span>  
<span style="margin-left: 1em">雨之後修繕城圃首建郡庠登雲橋樂育坊桂香桃浪</span>  
<span style="margin-left: 1em">二亭凡圯墜者次第一新六年罷任歸其罷也適郡役</span>  
<span style="margin-left: 1em">入都寓於松之宦者宦與瑾有連被收役踰垣去遂疑</span>  
<span style="margin-left: 1em">松守附瑾以求進波及焉乃役所投非威牘也威在事</span>  
<span style="margin-left: 1em">以郡志屬顧文僖清甫輯而罷郡猶貽詩惓惓趣成之</span>  
<span style="margin-left: 1em">文僖別記云周文襄濟農倉嘗積穀二十萬石其後亦</span>  
<span style="margin-left: 1em">不下十萬至是僅千擔威嘗欲補葺未遑及去文襄之</span>  
<span style="margin-left: 1em">舊儲不可問矣</span>  
<span style="margin-left: 2em">公曾孫鍾盛萬曆己未進士天啓丙寅爲郡學博時</span>  
<span style="margin-left: 2em">學西河已堙爲平陸首捐俸開濬重修桃浪桂香二</span>  
<span style="margin-left: 2em">亭又於學之乾隅築土阜上建斗閣下建文昌祠以</span>  
<span style="margin-left: 2em">補公未竟之緒松人士咸慶公有後擢國博以去</span>  
<span style="margin-left: 1em">喻時字子乾四川內江人正德辛未以監察御史出守</span>  
<span style="margin-left: 1em">松江適倭報狎至時焦勞爲民厲兵飭備少詹顧東江</span>  
<span style="margin-left: 1em">清樂居時與之謀戰守之事時管糧馬倅追徵己午逋</span>  
<span style="margin-left: 1em">賊甚峻又欲撤沿城民房合郡騷動時采顧公言移文</span>  
<span style="margin-left: 1em">請之得免夏稅時念郡志久湮特請顧公爲總裁聘文</span>  
<span style="margin-left: 1em">學高企吳稷岳鍷蔣惠等採葺編訂而水利役法尤詳</span>  
<span style="margin-left: 1em">遂成一郡良史</span>  
<span style="margin-left: 1em">王卿號徵菴直隸弘農衛人正德甲戌進士初授德清</span>  
<span style="margin-left: 1em">令後改上海敦厚質實不爲赫赫名上官未之知也卿</span>  
<span style="margin-left: 1em">處之淡然無峻城府人樂親附有以非意干者即瞠目</span>  
<span style="margin-left: 1em">視面頳然變竟不一語其人流汗走　武廟南巡道路</span>
