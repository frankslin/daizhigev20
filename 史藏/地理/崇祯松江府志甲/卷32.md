## 崇祯松江府志卷之三十二　宦绩五（国朝名宦）

<span style="margin-left: 3em">国朝名臣宦绩<sub class="note-yuan">二</sub></span>  
<span style="margin-left: 1em">金洪号曰湖浙江鄞县人成化丁未进士授靖江知县</span>  
<span style="margin-left: 1em">改吴江升御史巡按陕西山东裁抑阉宦逆瑾不能堪</span>  
<span style="margin-left: 1em">揭其名于壁使人讽之冀以赂谢卒不为理乃欲摈之</span>  
<span style="margin-left: 1em">边郡而吏部持之得补松江瑾怒未解会洪尝减松江</span>  
<span style="margin-left: 1em">官布价米库阉不得赂诡以布恶言于瑾械至京赖案</span>  
<span style="margin-left: 1em">牍明甚竟不能害</span>  
<span style="margin-left: 1em">刘璟号怡闲河南鄢陵人成化乙未进士二十二年以</span>  
<span style="margin-left: 1em">刑部郎升松江知府至弘治七年以忧去在松八载督</span>  
<span style="margin-left: 1em">率吏民劝农桑修水利敦士习势豪某杀人前守莫能</span>  
<span style="margin-left: 1em">治璟置之法豪右皆敛迹海上有城隍威灵太守廉明</span>  
<span style="margin-left: 1em">之谣郡人张某曾为鄢陵学谕璟师也致仕家居非公</span>  
<span style="margin-left: 1em">事未尝一造郡斋璟尝候之问政有疾璟朝夕往视自</span>  
<span style="margin-left: 1em">进汤药比卒为持心丧其第久鬻于人出俸赎归其子</span>  
<span style="margin-left: 1em">松人至今两贤之官至太子少保刑部尚书璟性刚直</span>  
<span style="margin-left: 1em">不阿上官几为持斧者罗织以墨时有府椽史周禋挺</span>  
<span style="margin-left: 1em">身出白之事载禋传</span>  
<span style="margin-left: 1em">李充嗣号梧山四川内江人成化丁未进士正德戊寅</span>  
<span style="margin-left: 1em">巡抚南畿己卯加工部尚书治江南水务仍兼巡抚以</span>  
<span style="margin-left: 1em">白茅港吴淞江二派为诸水之噤喉太湖之尾闾也首</span>  
<span style="margin-left: 1em">兴事焉界水道为井地示以开凿法户占一区计工刻</span>  
<span style="margin-left: 1em">日先竟者赏后者罚人人乐于趋事凡椿木畚锸给赏</span>  
<span style="margin-left: 1em">雇直之费皆括诸属帑羡余遴选贤能有司以主出纳</span>  
<span style="margin-left: 1em">复教设巨筏数百曳木齿随潮进退以汰沙泥名曰濬</span>  
<span style="margin-left: 1em">川杷又置小艇百余随铁帚于尾以为疏导名曰铁扫</span>  
<span style="margin-left: 1em">帚自是潮汐不忧壅塞淫雨不患泛滥蓄泄有道旱涝</span>  
<span style="margin-left: 1em">有恃食其利者甚溥而京储不至匮乏矣升南京兵部</span>  
<span style="margin-left: 1em">尚书卒赠太子太保谥康和</span>  
<span style="margin-left: 2em">何良俊曰白茅塘自李充嗣巡抚时曾一开浚是嘉</span>  
<span style="margin-left: 2em">靖初年其所费不赀今吴淞江之费特十之二三耳</span>  
<span style="margin-left: 2em">由海公瑞清白不妄用又用法严也然白茅塘不二</span>  
<span style="margin-left: 2em">十年即已湮塞盖海中皆浑水潮来时浑水涌入潮</span>  
<span style="margin-left: 2em">平后停一时始落浑泥皆淀在河底河焉得不湮塞</span>  
<span style="margin-left: 2em">哉夏忠靖公治水时均徭内原编有淘河夫银今不</span>  
<span style="margin-left: 2em">知作何项支销去矣<sub class="note-yuan">丛说</sub></span>  
<span style="margin-left: 1em">何瀞字源清广东东莞人成化壬辰进士授本府推官</span>  
<span style="margin-left: 1em">明允清慎门无私谒知府王衡赠诗有关门共惜寒儒</span>  
<span style="margin-left: 1em">苦断狱争夸老吏明之句后升御史终佥事</span>  
<span style="margin-left: 1em">董钥字启之浙江鄞县人弘治六年尹上海县明辨善</span>  
<span style="margin-left: 1em">干理筑西乡田园堤防以捍水患太史钱福为文记之</span>  
<span style="margin-left: 1em">原应宿阳城人弘治间以乡举授府倅署上海县刚达</span>  
<span style="margin-left: 1em">明果敏于立事其董水利尤力濬堙凿隘大利农亩而</span>  
<span style="margin-left: 1em">兴工给费亦有调度公不匮财民不见病邑人称之</span>  
<span style="margin-left: 1em">马骙号梅轩解州夏县人弘治丙辰进士授行人选兵</span>  
<span style="margin-left: 1em">科给事中马端肃公见其谏草惊曰董贾未之或先仪</span>  
<span style="margin-left: 1em">观俊整进退中度　孝宗默眷爱之尝论李广之党宜</span>  
<span style="margin-left: 1em">穷治外戚之权宜禁戢谏官吴舜之狂直宜包容皆时</span>  
<span style="margin-left: 1em">政切要者　武宗即位有白金文绮之赐逆瑾用事骙</span>  
<span style="margin-left: 1em">尽言不少避忌瑾亦多勉从中有附瑾新入为给舍者</span>  
<span style="margin-left: 1em">对宾僚夸毘甚有矜色骙鄙之以无耻客皆缩舌先是</span>  
<span style="margin-left: 1em">张彩拜瑾为义父骤入铨衡骙自蜀还与彩父宿同驿</span>  
<span style="margin-left: 1em">馆不与交一语彩闻之以为慢己会时宰夙憾骙搆毁</span>  
<span style="margin-left: 1em">出为淮安府推官已仅转同知松江既视篆松松多富</span>  
<span style="margin-left: 1em">室积逋累细民骙廉得之锐意清理豪不能肆数年逋</span>  
<span style="margin-left: 1em">税一朝报完会丁外艰去有说骙宜少贬从容者正色</span>  
<span style="margin-left: 1em">曰穷通显晦命也如命何</span>  
<span style="margin-left: 2em">公初入京主医张圯馆圯卒而无子为买地以葬后</span>  
<span style="margin-left: 2em">为松江同知背疽几危一夕梦圯来视疾明日寻愈</span>  
<span style="margin-left: 2em">人以为圯之冥祐公为行人时使蜀馆称多怪人莫</span>  
<span style="margin-left: 2em">敢居径入夜坐观书忽壁上如人持挺而击者二不</span>  
<span style="margin-left: 2em">为动居父忧庐中磬不扣自鸣灯下见馘影如斗亦</span>  
<span style="margin-left: 2em">不为动自松归渡江会大风陡作舟师震惧无人色</span>  
<span style="margin-left: 2em">从容仰天祝曰吾平生或欺君虐民舟当沉否则息</span>  
<span style="margin-left: 2em">俄而风恬浪妥须臾数百里<sub class="note-yuan">涌幢</sub></span>  
<span style="margin-left: 1em">郭经字载道卢龙人弘治十一年知上海县事简民安</span>  
<span style="margin-left: 1em">称为乐邦以不能阿事上官擢开封二守去之日为树</span>  
<span style="margin-left: 1em">碑以颂其德<sub class="note-yuan">上海志</sub></span>  
<span style="margin-left: 1em">王廷相字子衡仪封人弘治壬戌进士选翰林庶吉士</span>  
<span style="margin-left: 1em">授兵科给事中谪判亳州升高淳知县授御史巡按山</span>  
<span style="margin-left: 1em">东陕西镇守廖太监恨其每事禁抑搆下狱谪赣榆丞</span>  
<span style="margin-left: 1em">升宁国知县松江同知历官兵部尚书加太子少师相</span>  
<span style="margin-left: 1em">不事浮躁帝搜玄览居恒尝自盟曰大识者外伪不能</span>  
<span style="margin-left: 1em">累大气者外侮不能动大德者外物不能迁又曰权所</span>  
<span style="margin-left: 1em">以运国势纪纲所以系国脉人才所以主国命故国之</span>  
<span style="margin-left: 1em">不亡者三权不下移纲纪不隳不用小人以长国也又</span>  
<span style="margin-left: 1em">曰迂儒强执不识古今之宜鄙儒依阿不顾国家之计</span>  
<span style="margin-left: 1em">俗儒浅陋不达治忽之机皆不堪重任真名言也有识</span>  
<span style="margin-left: 1em">者书之座右</span>  
<span style="margin-left: 1em">傅鼎字用养福建闽县人弘治己酉解元己未乙榜教</span>  
<span style="margin-left: 1em">谕华亭经学通邃尤长于易所著有易髓八卷其教士</span>  
<span style="margin-left: 1em">一以诚心实德化之人皆悦服尝为江西考官郡守之</span>  
<span style="margin-left: 1em">子就试遣吏授以一合启封乃猪蹄四也盖隐谜云鼎</span>  
<span style="margin-left: 1em">坚却弗受子亦不举士论高之在任七年升知龙川县</span>  
<span style="margin-left: 1em">岁余忽传凶问邑诸生为位三贤祠下朝夕泣奠绖而</span>  
<span style="margin-left: 1em">入者二十七日见而知其妄也以忤权贵左迁婺源改</span>  
<span style="margin-left: 1em">授吉安卒吉诸生具棺赙赠护其丧归讣至华亭之泣</span>  
<span style="margin-left: 1em">奠如初远致赙焉鼎交游广取予介其母兄妻子先后</span>  
<span style="margin-left: 1em">卒者六丧贫不能举华亭周鹓以御史按闽乃克葬之</span>  
<span style="margin-left: 1em">天性孝友外柔内刚动以礼义自将家无余积晏如也</span>  
<span style="margin-left: 1em">诗文清劲有体裁书亦如之所著有华峰集射礼图著</span>  
<span style="margin-left: 1em">行于世</span>  
<span style="margin-left: 1em">陈祥号荷峰江西高安人弘治壬戌进士筮仕上虞正</span>  
<span style="margin-left: 1em">德二年补华亭邑令恒败于利祥以守己廉肃遇事详</span>  
<span style="margin-left: 1em">明一时称贤令召为监察御史历官巡抚应天等府吏</span>  
<span style="margin-left: 1em">多冒没极力搜剔南畿宴然</span>  
<span style="margin-left: 1em">冯裕号闾山山东临朐人正德戊辰进士令华亭性笃</span>  
<span style="margin-left: 1em">实薄于自奉廉于取民好执法不肯毫发少假人刘瑾</span>  
<span style="margin-left: 1em">更张旧法内差添设私员民间大有诛求他令皆通融</span>  
<span style="margin-left: 1em">而裕独坚挺不应邑大水西田多渰没东田稍收顾岁</span>  
<span style="margin-left: 1em">租不能全蠲尚征其半适部使者至又加以租外新派</span>  
<span style="margin-left: 1em">民哗言裕加赋于民抚台张公惑之下裕于狱既而察</span>  
<span style="margin-left: 1em">裕无他改知萧县待理时寓居鹤城书院岁余空囊不</span>  
<span style="margin-left: 1em">充朝夕士大夫往往有馈遗相周者裕日惟赋诗吟咏</span>  
<span style="margin-left: 1em">自得无怨尤不平之意人尤贤之</span>  
<span style="margin-left: 2em">闾山冯公裕治华亭有惠故其去也民为歌曰大水</span>  
<span style="margin-left: 2em">横发高树低人死为鱼公凄悲谁使公去伤哉离公</span>  
<span style="margin-left: 2em">去华亭几四十年其子少洲公名惟讷复来治松请</span>  
<span style="margin-left: 2em">祀公于学宫徐献忠记畧曰昔在正德己巳公来治</span>  
<span style="margin-left: 2em">民任真履平不事缋餙事有利者即力任之方是中</span>  
<span style="margin-left: 2em">官操窃名器郡长吏有出其门者颇事敛括公不承</span>  
<span style="margin-left: 2em">其意旨遂为所不乐是岁秋大水自邑以西漭为巨</span>  
<span style="margin-left: 2em">壑民饥饿死者甚众而粮额不蠲减监司者又适去</span>  
<span style="margin-left: 2em">任乃不待报请移其税于高乡继而监司者至郡长</span>  
<span style="margin-left: 2em">吏乃从其中搆之几中于祸民相率声其寃仅得调</span>  
<span style="margin-left: 2em">萧县去</span>  
<span style="margin-left: 1em">徐潭号一轩浙江定海人弘治癸丑进士正德戊辰授</span>  
<span style="margin-left: 1em">上海令其俗区长里魁岁有常例输官皆斥不取遇岁</span>  
<span style="margin-left: 1em">大祲设法赈济多所全活先是讼者遣卒逮捕即倚势</span>  
<span style="margin-left: 1em">需索民不胜苦潭乃造木人于庭有陈诉者即令持至</span>  
<span style="margin-left: 1em">所诉之家其人抱木人自诣无敢后者宿害遂捐邑之</span>  
<span style="margin-left: 1em">豪右率逋官租而区长往往破家以偿潭严惩其弊植</span>  
<span style="margin-left: 1em">怨豪右会督储宪臣又索常例不与乃以事中伤改令</span>  
<span style="margin-left: 1em">湘潭官至宪副</span>  
<span style="margin-left: 1em">陈威号畏庵江西临川人任御史正德五年出守松江</span>  
<span style="margin-left: 1em">时己巳庚午连年水灾威下车留心赈恤民赖以甦积</span>  
<span style="margin-left: 1em">雨之后修缮城圃首建郡庠登云桥乐育坊桂香桃浪</span>  
<span style="margin-left: 1em">二亭凡圯坠者次第一新六年罢任归其罢也适郡役</span>  
<span style="margin-left: 1em">入都寓于松之宦者宦与瑾有连被收役逾垣去遂疑</span>  
<span style="margin-left: 1em">松守附瑾以求进波及焉乃役所投非威牍也威在事</span>  
<span style="margin-left: 1em">以郡志属顾文僖清甫辑而罢郡犹贻诗惓惓趣成之</span>  
<span style="margin-left: 1em">文僖别记云周文襄济农仓尝积谷二十万石其后亦</span>  
<span style="margin-left: 1em">不下十万至是仅千担威尝欲补葺未遑及去文襄之</span>  
<span style="margin-left: 1em">旧储不可问矣</span>  
<span style="margin-left: 2em">公曾孙钟盛万历己未进士天启丙寅为郡学博时</span>  
<span style="margin-left: 2em">学西河已堙为平陆首捐俸开濬重修桃浪桂香二</span>  
<span style="margin-left: 2em">亭又于学之乾隅筑土阜上建斗阁下建文昌祠以</span>  
<span style="margin-left: 2em">补公未竟之绪松人士咸庆公有后擢国博以去</span>  
<span style="margin-left: 1em">喻时字子乾四川内江人正德辛未以监察御史出守</span>  
<span style="margin-left: 1em">松江适倭报狎至时焦劳为民厉兵饬备少詹顾东江</span>  
<span style="margin-left: 1em">清乐居时与之谋战守之事时管粮马倅追征己午逋</span>  
<span style="margin-left: 1em">贼甚峻又欲撤沿城民房合郡骚动时采顾公言移文</span>  
<span style="margin-left: 1em">请之得免夏税时念郡志久湮特请顾公为总裁聘文</span>  
<span style="margin-left: 1em">学高企吴稷岳鍷蒋惠等采葺编订而水利役法尤详</span>  
<span style="margin-left: 1em">遂成一郡良史</span>  
<span style="margin-left: 1em">王卿号征庵直隶弘农卫人正德甲戌进士初授德清</span>  
<span style="margin-left: 1em">令后改上海敦厚质实不为赫赫名上官未之知也卿</span>  
<span style="margin-left: 1em">处之淡然无峻城府人乐亲附有以非意干者即瞠目</span>  
<span style="margin-left: 1em">视面頳然变竟不一语其人流汗走　武庙南巡道路</span>  
<span style="margin-left: 1em">汹汹有缘以为奸利者卿抗诸邀索一不应第曰车驾</span>  
<span style="margin-left: 1em">至日供不供有令也何先事自扰为竟以安堵宁藩犯</span>  
<span style="margin-left: 1em">顺人心骚动谕众曰江海潮汐非贼利也固无虑奈武</span>  
<span style="margin-left: 1em">库何吾且有备乃以告讦人获罪者许以铁赎由是兵</span>
