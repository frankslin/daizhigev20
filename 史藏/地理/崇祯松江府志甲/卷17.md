## 崇禎松江府志卷之十七　水利中

<span style="margin-left: 3em">水利中治策二<sub class="note-jiao">校：中字似脫今補</sub></span>  
<span style="margin-left: 1em">國朝郎中顔如環議開吳淞江畧　吳淞江一帶流至</span>  
<span style="margin-left: 2em">新洋江口夏駕浦口二處交會二處通婁江潮水倒</span>  
<span style="margin-left: 2em">入江內淀積泥沙又因地勢卑近遂引江水順趨北</span>  
<span style="margin-left: 2em">下併入婁江以致吳淞江易成淤淺累經開濬不久</span>  
<span style="margin-left: 2em">復塞或謂此江出海一百餘里累濬累塞而此二處</span>  
<span style="margin-left: 2em">相去婁江不三十里因而流濬深闊使此江中水併</span>  
<span style="margin-left: 2em">入婁江出海似爲便易不知此江爲三江之一與婁</span>  
<span style="margin-left: 2em">江各自通洩當夫旱固可合而爲一及至水溢則婁</span>  
<span style="margin-left: 2em">江自洩所受之水不暇又安能併吳淞江之水而皆</span>  
<span style="margin-left: 2em">洩乎故昔人有言使二江可併爲一則神禹先併之</span>  
<span style="margin-left: 2em">矣何必又有三江此誠不易之論然而先年累次修</span>  
<span style="margin-left: 2em">濬樂簡易而畏煩難以致二處淤塞不通而棄此爲</span>  
<span style="margin-left: 2em">可不必用本職詢訪耆老咸謂當於新洋夏駕口各</span>  
<span style="margin-left: 2em">置一閘冬春常閉夏秋淫澇開之以分洩水勢或旱</span>  
<span style="margin-left: 2em">乾開之以通引灌溉庶幾江流常通旱澇有備又看</span>  
<span style="margin-left: 2em">得夏駕口闊一十六丈深止四五尺潮勢亦緩造閘</span>  
<span style="margin-left: 2em">無難其新洋江口闊四十丈深一丈五尺潮勢頗大</span>  
<span style="margin-left: 2em">難以作堰但事體重大及費用錢糧數多必須委官</span>  
<span style="margin-left: 2em">勘議停當方可施行</span>  
<span style="margin-left: 1em">提督蘇松水利主事姚文灝疏畧　一設導河之夫蘇</span>  
<span style="margin-left: 2em">松常鎮沿江近海諸港浦潮沙之積有常而疏導之</span>  
<span style="margin-left: 2em">功不繼所以患多而利少前代或設潦淺之夫或置</span>  
<span style="margin-left: 2em">開江之卒專一浚治不限時月近歲役夫皆臨期取</span>  
<span style="margin-left: 2em">於里甲而無經制小民勞擾吏緣爲姦富者累年不</span>  
<span style="margin-left: 2em">役貧者無歲不差乞將各府導河夫役悉照江北運</span>  
<span style="margin-left: 2em">河及浙西海塘夫例每年於均徭內定撥專一用工</span>  
<span style="margin-left: 2em">庶幾無患工部覆奏導河夫役宜行巡撫與本官酌</span>  
<span style="margin-left: 2em">量地方緩急僉點備用可省之處不可濫設</span>  
<span style="margin-left: 1em">御史謝琛疏畧　謹按浙西勢本卑下天目諸山西來</span>  
<span style="margin-left: 2em">之水皆歸太湖再流入於陽城昆承澱山三泖等湖</span>  
<span style="margin-left: 2em">其性本皆欲東也故神禹相地分流疏其東北入海</span>  
<span style="margin-left: 2em">者爲婁江東南流者爲東江并淞江爲三江以分洩</span>  
<span style="margin-left: 2em">之自是不聞有水患後世海塘一築其近江淤肥之</span>  
<span style="margin-left: 2em">地悉成腴田而東江之故道塞矣繇是欲使東江之</span>  
<span style="margin-left: 2em">水迤邐北旋會入淞江而趨下之性遲矣故後人於</span>  
<span style="margin-left: 2em">常熟縣之北開二十四浦疏而導之楊子江又於崑</span>  
<span style="margin-left: 2em">山縣之東開一十二浦分而納之海所以補東江不</span>  
<span style="margin-left: 2em">通之力也又慮潮沙易於淤塞各於浦口置立板閘</span>  
<span style="margin-left: 2em">潮來則扄之以禦泥沙歲旱亦扄之以備灌溉又於</span>  
<span style="margin-left: 2em">閘外或設開江之卒或設撩淺之夫皆所以決壅塞</span>  
<span style="margin-left: 2em">而防泛溢也永樂年間尚書夏原吉區畫經度如開</span>  
<span style="margin-left: 2em">劉家白茆二港甚合古人之法自後七八十年朝廷</span>  
<span style="margin-left: 2em">之貢賦不虧百姓賴以安堵弘治七年工部侍郎徐</span>  
<span style="margin-left: 2em">貫亦奉命繼理其事比有通判姚文灝輔之一時疏</span>  
<span style="margin-left: 2em">浚之法亦有次第舊制板閘夫卒之設圍岸之築皆</span>  
<span style="margin-left: 2em">未全備是以迄今十二三年諸浦之壅塞如故近年</span>  
<span style="margin-left: 2em">雖有帶管僉事官既不專名亦虛設以至一二年來</span>  
<span style="margin-left: 2em">水利日廢水患日甚乞命廷臣計議或勅僉都御史</span>  
<span style="margin-left: 2em">兼整前事或選命該部大臣一員前來專理趁今秋</span>  
<span style="margin-left: 2em">收之後訪前代疏浚之規爲來年水患之備或計各</span>  
<span style="margin-left: 2em">府錢糧之空乏也容其借取滸墅北新等關課鈔支</span>  
<span style="margin-left: 2em">用開諸浦以洩諸湖之水復板閘以嚴啓閉之規立</span>  
<span style="margin-left: 2em">夫卒以繼疏浚之功築圍岸以防横流之勢雖曰費</span>  
<span style="margin-left: 2em">用浩大然計被災免徵之費孰爲多寡從可知矣</span>  
<span style="margin-left: 1em">都御史俞諫疏畧　臣遍歷蘇松常鎮杭嘉湖七府所</span>  
<span style="margin-left: 2em">屬地方相形度勢尋源泝委會同巡撫都御史張鳳</span>  
<span style="margin-left: 2em">看得白茆港離海約十五里許旁有姚家浜者舊開</span>  
<span style="margin-left: 2em">通灌支河也東通小湖漕六尺溝至陶涇入海其地</span>  
<span style="margin-left: 2em">形頗下其勢趨東南頗順其水道視舊港頗徑直其</span>  
<span style="margin-left: 2em">去横沙亦遠若因而廣之深闊與白茆稱復疏通障</span>  
<span style="margin-left: 2em">礙分決中流會趨駛疾計必可以滌潮沙而垂久遠</span>  
<span style="margin-left: 2em">此議一出老農漁父皆以爲然隨委官逐一勘量民</span>  
<span style="margin-left: 2em">亦願從欲便起工開浚但蘇松等府倉庫多虛見在</span>  
<span style="margin-left: 2em">堪動官銀不過四千餘兩况地方人民連遭災疫逃</span>  
<span style="margin-left: 2em">亡數多凋瘵之餘瘡痍未復今歲雖得稍收中間尚</span>  
<span style="margin-left: 2em">有包賠荒棄之累加以數年逋負追併一時若又重</span>  
<span style="margin-left: 2em">加派取不無逼民失所致生他患臣等酌量緩急先</span>  
<span style="margin-left: 2em">將高鄉淤塞涇漕浜漊低鄉坍没圩岸堤防逐一查</span>  
<span style="margin-left: 2em">勘照田多寡分派丈尺督令得利之人趁時浚築及</span>  
<span style="margin-left: 2em">將前項諸漊百瀆江塘河港以次開濬隨宜修舉其</span>  
<span style="margin-left: 2em">白茆港等處欲候下年農隙興工</span>  
<span style="margin-left: 1em">王同祖治水議　治水之要其說有三一曰開決三江</span>  
<span style="margin-left: 2em">故道以泄震澤之水二曰浚治諸浦以泄江湖之水</span>  
<span style="margin-left: 2em">三曰疏導涇港以泄田中之水何謂開決三江故道</span>  
<span style="margin-left: 2em">太湖東入淞江出吳江長橋長橋之水未嘗不通而</span>  
<span style="margin-left: 2em">所以爲東吳害者則在下流入海之處淤故積水溢</span>  
<span style="margin-left: 2em">而爲沴耳若復決去長橋使湖流浩至而入海之處</span>  
<span style="margin-left: 2em">又復不疾即吳江崑山常熟三縣之地將爲深淵此</span>  
<span style="margin-left: 2em">長橋不可盡決利害甚明也東江舊跡在大泖西北</span>  
<span style="margin-left: 2em">爲爛路港澱湖西有急水港白蜆江皆東江之西段</span>  
<span style="margin-left: 2em">也澱湖之東有出水港斜瀝口汊港口小漕港大瀝</span>  
<span style="margin-left: 2em">口小瀝口通潮水往來潮退則引湖水下大漕大盈</span>  
<span style="margin-left: 2em">等浦入青龍一龍江而出海皆東江之東段也今諸</span>  
<span style="margin-left: 2em">港皆淺狹壅遏不通潮汐而東江入海之處遂塞東</span>  
<span style="margin-left: 2em">南風水回太湖則湖州諸縣皆泛溢西北風太湖水</span>  
<span style="margin-left: 2em">下澱山泖湖則崑山常熟吳江淞江等處泛溢是皆</span>  
<span style="margin-left: 2em">東江不通之害也今之言東江所以塞而不通者大</span>  
<span style="margin-left: 2em">率歸咎於黃浦奪權海塘障遏而不知江之通塞亦</span>  
<span style="margin-left: 2em">自有時黃浦海塘未必能爲東江害也或以爲東江</span>  
<span style="margin-left: 2em">既塞而澱湖之水繇千墩等浦北入於淞江殊不知</span>  
<span style="margin-left: 2em">澱湖之水自屬東江其北入於吳淞江者但支流耳</span>  
<span style="margin-left: 2em">遂以爲可泄澱湖之水者非也苟能尋東江之舊而</span>  
<span style="margin-left: 2em">疏治之使澱湖所受之水皆得達於東南以入海則</span>  
<span style="margin-left: 2em">松江可通而數百年之害可去萬世之利可興矣何</span>  
<span style="margin-left: 2em">謂濬治諸浦吳郡之地北枕楊子江東通大海西控</span>  
<span style="margin-left: 2em">太湖南襟三江水之發源則自太湖東注三江以入</span>  
<span style="margin-left: 2em">海又其支流北達楊子江以入海故古人於東北沿</span>  
<span style="margin-left: 2em">江海之所濬三十六浦以分三江之勢使同歸於海</span>  
<span style="margin-left: 2em">其常熟之浦二十有四崑山之浦十有二今三十六</span>  
<span style="margin-left: 2em">浦之中入海者惟茜涇七雅白茆楊林爲最大入楊</span>  
<span style="margin-left: 2em">子江者惟福山許浦爲最大吳淞江之南有大浦三</span>  
<span style="margin-left: 2em">十六條東自北平破江艾祁顧會養蠶大盈南澥梁</span>  
<span style="margin-left: 2em">紇石臼分乘趙屯內勳石浦道褐蕭市金竈千墩注</span>  
<span style="margin-left: 2em">浦張潭棠梨同丘諸天張浦帆歸甪直甫里渡頭東</span>  
<span style="margin-left: 2em">齊刹刀界浦浮高順德大姚破墩盞頭吳淞之北有</span>  
<span style="margin-left: 2em">大浦三十二修東自顧會安亭徐公北澥瓦浦三林</span>  
<span style="margin-left: 2em">顧幕金城木瓜夏駕奣浦廣浦社城新洋江馬仁小</span>  
<span style="margin-left: 2em">虞大虞尤涇梁里華翔心瀆樂浦薛莊黃瀆真義界</span>  
<span style="margin-left: 2em">浦下里戴墟上顧青丘奉里任浦其在江之南者則</span>  
<span style="margin-left: 2em">西受陳湖等水南受澱山湖諸水以入吳淞江而達</span>  
<span style="margin-left: 2em">於海其在江之北者則西受陽城湖諸水横絕至和</span>  
<span style="margin-left: 2em">塘以入吳淞江而達於海自新洋夏駕以東則反納</span>  
<span style="margin-left: 2em">吳淞江之水以東北趨於劉家港而入海吳淞江迤</span>  
<span style="margin-left: 2em">東入海之口其南有浜浦一十九條皆通上海華亭</span>  
<span style="margin-left: 2em">縣界其北有浜浦二十二條皆北通嘉定縣界皆近</span>  
<span style="margin-left: 2em">海潮汐往來易於漲塞廣者日狹深者日淺惟千墩</span>  
<span style="margin-left: 2em">一浦南通澱山湖最爲關要浦極深闊與夏駕新洋</span>  
<span style="margin-left: 2em">南北相望水勢相入屢經開濬皆爲民利今宜沿江</span>  
<span style="margin-left: 2em">相度各浦之通塞使湖之水必趨於江而江之水得</span>  
<span style="margin-left: 2em">入於海則郡中東南之水定矣何謂疏導涇港蓋圩</span>  
<span style="margin-left: 2em">田四圍皆涇港環繞或傍江湖或傍浦塘曰涇港者</span>  
<span style="margin-left: 2em">論其槩也涇港之設有公有私今則並通舟楫分利</span>  
<span style="margin-left: 2em">水道旱則引其水以溉田潦則決田之水以入涇港</span>  
<span style="margin-left: 2em">泄諸江湖浦塘使歸於海其利於農田最爲切要故</span>  
<span style="margin-left: 2em">凡緊要圍田水道通行開濬使稍深闊即取其所開</span>  
<span style="margin-left: 2em">之土以修岸塍如是則田間之積水可引入涇港涇</span>  
<span style="margin-left: 2em">港通流可散灌於浦塘浦塘決水可疾趨於江海大</span>  
<span style="margin-left: 2em">小相資首尾相貫又何水之足患乎</span>  
<span style="margin-left: 1em">王同祖工計議　工役計費二事常相須計費足則工</span>  
<span style="margin-left: 2em">役舉故今之言治農田水利者莫急於量財蓋公役</span>  
<span style="margin-left: 2em">之舉歲歲興修則繁而難行數歲不治則廢而難葺</span>  
<span style="margin-left: 2em">故必相其工之大小而爲之制開江濬浦以十年爲</span>  
<span style="margin-left: 2em">率疏決涇港築圩治堰歲歲修補或間歲一葺則工</span>  
<span style="margin-left: 2em">役不繁而民不以爲勞矣計費之出必量其費之多</span>  
<span style="margin-left: 2em">寡而爲之制若開江濬浦疏通涇瀆之大者則官爲</span>  
<span style="margin-left: 2em">之區畫其築圩修堰及疏決涇港之小者則取諸食</span>  
<span style="margin-left: 2em">利佃作之家如此則不煩於公而不傷於民矣</span>  
<span style="margin-left: 1em">工科吳巖疏畧　臣備員該科謹陳東南水利之切要</span>  
<span style="margin-left: 2em">者三事一曰疏濬下流浙西諸郡蘇松最下太湖緜</span>  
<span style="margin-left: 2em">亘數百餘里納諸山溪澗之水散注瀼蕩間繇三江</span>  
<span style="margin-left: 2em">以入於海是太湖者諸鄉之水所瀦而三江又太湖</span>  
<span style="margin-left: 2em">之所繇洩也若下流淤湮滙水泛溢渰没禾稼爲害</span>  
<span style="margin-left: 2em">匪輕今要在相其利害爲之區處如白茆港七浦塘</span>  
<span style="margin-left: 2em">劉家河皆蘇州東北洩水之大川如吳淞江大黃浦</span>  
<span style="margin-left: 2em">是蘇松南北交境洩水之大川而吳淞南北與白茆</span>  
<span style="margin-left: 2em">諸港浦之兩旁又各有支渠引上流諸湖瀼之水以</span>  
<span style="margin-left: 2em">歸其中而並入於海就其中論之蘇之七浦塘劉家</span>  
<span style="margin-left: 2em">河松之黃浦並皆深闊通利惟白茆自弘治七年疏</span>  
<span style="margin-left: 2em">浚之後今入海之處潮沙壅積勢若丘阜而吳淞之</span>  
<span style="margin-left: 2em">旁渠港亦多湮塞今誠能濬白茆一港使之通利如</span>  
<span style="margin-left: 2em">七浦劉家河則蘇州東北之水有所歸而不積矣濬</span>  
<span style="margin-left: 2em">吳淞一江使之通利如大黃浦則蘇松南北兩界之</span>  
<span style="margin-left: 2em">水有所歸而不積矣蘇松之水既各有歸則引吸上</span>  
<span style="margin-left: 2em">源太湖之水不至壅溢而向來瀼蕩沮洳渰没之土</span>

<span style="margin-left: 2em">一日兩潮則一年七百二十箬矣日積一日年厚一</span>  
<span style="margin-left: 2em">年雖欲不淤塞得乎識者云自西徂東開至盡頭處</span>  
<span style="margin-left: 2em">留里許不開以壩海口既無潮退泥留之患又省防</span>  
<span style="margin-left: 2em">鹽防盗之虞若逢水災汹湧請牌開壩衆鍤如雲里</span>  
<span style="margin-left: 2em">許不日可濬水洩復塞何畏海潮何傷風水此開吳</span>  
<span style="margin-left: 2em">淞之妙策也但以銀米召募因救饑貧其利大其功</span>  
<span style="margin-left: 2em">速派撥民夫困累塘長其害大其功遲知此而禹蹟</span>  
<span style="margin-left: 2em">可成海忠介可以並享而血食矣不識東南萬萬姓</span>

<span style="margin-left: 1em">日月河在普照寺南邇年以來漸就湮淤日河之水猶</span>  
<span style="margin-left: 2em">僅通潮月河之迹幾於漫滅日河之工易導使通舟</span>  
<span style="margin-left: 2em">足矣月河之工非廣辟深鑿不能通也立表於河中</span>  
<span style="margin-left: 2em">以稽刻限之程出土於郭外以防復淤之患改板橋</span>  
<span style="margin-left: 2em">之卑陋復勢家之占塞畢工之日乘舟驗視使舊蹟</span>

<span style="margin-left: 1em">肇嘉浜在上海縣治南引浦水繇東水關貫城而西分</span>  
<span style="margin-left: 2em">流支港畜洩賴之因水關啓閉不時且夾闤闠易淤</span>  
<span style="margin-left: 2em">雖歲加濬治而旋塞如故又薛家浜引浦水自東南</span>  
<span style="margin-left: 2em">經縣治而西因築城斷塞水無畜泄積聚穢濁民多</span>  
<span style="margin-left: 2em">疫癘且形家謂水當巽位其通塞係人文盛衰議鑿</span>  
<span style="margin-left: 2em">城復故道邑侯敖選上之不果萬曆丙申邑侯許汝</span>  
<span style="margin-left: 2em">魁始開小南門水關引水通市河東南居民賴之又</span>  
<span style="margin-left: 2em">方浜在肇嘉北繇小東門水關入經城隍廟廣福寺</span>  
<span style="margin-left: 2em">而西亦以築城斷塞其兩崖爲居民所侵僅存一衣</span>  
<span style="margin-left: 2em">帶水邑侯呂濬疏通第近浦多鹽潮淤泥尤易堙積</span>  
<span style="margin-left: 2em">若歲時小疏之力省而利普司牧者宜留意焉</span>  
<span style="margin-left: 2em">郡侯方公重濬鹽鐵塘碑記　吾郡水事之宜興者</span>  
<span style="margin-left: 2em">無如鹽鐵一濬此其利人人能言之然持之數十年</span>  
<span style="margin-left: 2em">而功未奏者何也曰濬塘似難而易築偃似易而難</span>  
<span style="margin-left: 2em">也塘納大浦流蜿蜒旁入所灌溉誠不下數萬頃然</span>  
<span style="margin-left: 2em">潮汐所過下流稍涣砂土立積若專其勢而導之無</span>  
<span style="margin-left: 2em">授以瑕者塘何渠不千祀或曰泖涇闢鹽鐵塞亦若</span>  
<span style="margin-left: 2em">運數使然不當耑咎人事此大不然夫塘以涇濁有</span>  
<span style="margin-left: 2em">濁之者涇不能言如代之言必且曰沃郡壤者盡吾</span>  
<span style="margin-left: 2em">族也今去則疐吾尾而不伸來則扼彼吭而不吐而</span>  
<span style="margin-left: 2em">曰吾嫁之淤吾憤焉塘不能言如代之言亦必曰派</span>  
<span style="margin-left: 2em">別矣何取於强同轍分矣何愛乎來軌若澹吾流於</span>  
<span style="margin-left: 2em">北而澄彼汰於西瑯琊太原不碍爲各宗巨靈丈人</span>  
<span style="margin-left: 2em">無傷於異鎮也惟涇與塘公虛之智不用而反用市</span>  
<span style="margin-left: 2em">人一閧之言於是壟斷者漁壑居間者餌緡湯湯鏡</span>  
<span style="margin-left: 2em">紆鞠爲茂草河渠書與鹽鐵論俱收庋高閣矣亘塘</span>  
<span style="margin-left: 2em">與涇之間而屹然横者曰三里橋橋故有石石或能</span>  
<span style="margin-left: 2em">言即不代之言必且曰平兩家之隙是誠在吾吾軀</span>  
<span style="margin-left: 2em">不厭捐吾漏不厭塞礪吾一剛可致兩柔盍從事乎</span>  
<span style="margin-left: 2em">然必有介如石清如水者而後水言石言俱從百姓</span>  
<span style="margin-left: 2em">之言以奏天實惠吾氓俾方公來聽而績用是始底</span>  
<span style="margin-left: 2em">也公清貞虛淡與道爲體與物無營而壹意氓庶蓄</span>  
<span style="margin-left: 2em">福散疵五年之中利無不宣害無不滌者嘗單車東</span>  
<span style="margin-left: 2em">瞭遺塍畫然立召父老授以成策謂史起之用漳河</span>  
<span style="margin-left: 2em">亦偶通其故耳故跡可因故智可師第無私撓之太</span>  
<span style="margin-left: 2em">守斤斤忍鮭菜不市塵罰鍰不手亦有所用之耳於</span>  
<span style="margin-left: 2em">是乘農暇因人和僝功頃時畚插遍野呼往躍來蕪</span>  
<span style="margin-left: 2em">埆立削舟駛帆疾安行達闠塘既瓴建堰隨轂綰異</span>  
<span style="margin-left: 2em">喙頓息美利克永公未嘗役民民未嘗傳有兹役也</span>  
<span style="margin-left: 2em">水言石言與百姓之言皆寂乎無聲而紀功伐石者</span>  
<span style="margin-left: 2em">乃欲以言推之言何足盡公無己則徵諸劉安氏已</span>  
<span style="margin-left: 2em">往之言乎其言曰水之性淖以清窮谷之污生以青</span>  
<span style="margin-left: 2em">苔不治其性也掘其所流而深之茨其所決而高之</span>  
<span style="margin-left: 2em">使得循勢而行乘衰而止雖有腐髊流漸弗能污也</span>  
<span style="margin-left: 2em">其性非異也通之與不通也風俗猶此也君子之決</span>  
<span style="margin-left: 2em">民善而防民邪其樞恒在水是道也公所用以宜氓</span>
