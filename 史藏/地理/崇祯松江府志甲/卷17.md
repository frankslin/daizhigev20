## 崇祯松江府志卷之十七　水利中

<span style="margin-left: 3em">水利中治策二<sub class="note-jiao">校：中字似脫今補</sub></span>  
<span style="margin-left: 1em">国朝郎中颜如环议开吴淞江畧　吴淞江一带流至</span>  
<span style="margin-left: 2em">新洋江口夏驾浦口二处交会二处通娄江潮水倒</span>  
<span style="margin-left: 2em">入江内淀积泥沙又因地势卑近遂引江水顺趋北</span>  
<span style="margin-left: 2em">下并入娄江以致吴淞江易成淤浅累经开濬不久</span>  
<span style="margin-left: 2em">复塞或谓此江出海一百余里累濬累塞而此二处</span>  
<span style="margin-left: 2em">相去娄江不三十里因而流濬深阔使此江中水并</span>  
<span style="margin-left: 2em">入娄江出海似为便易不知此江为三江之一与娄</span>  
<span style="margin-left: 2em">江各自通泄当夫旱固可合而为一及至水溢则娄</span>  
<span style="margin-left: 2em">江自泄所受之水不暇又安能并吴淞江之水而皆</span>  
<span style="margin-left: 2em">泄乎故昔人有言使二江可并为一则神禹先并之</span>  
<span style="margin-left: 2em">矣何必又有三江此诚不易之论然而先年累次修</span>  
<span style="margin-left: 2em">濬乐简易而畏烦难以致二处淤塞不通而弃此为</span>  
<span style="margin-left: 2em">可不必用本职询访耆老咸谓当于新洋夏驾口各</span>  
<span style="margin-left: 2em">置一闸冬春常闭夏秋淫涝开之以分泄水势或旱</span>  
<span style="margin-left: 2em">乾开之以通引灌溉庶几江流常通旱涝有备又看</span>  
<span style="margin-left: 2em">得夏驾口阔一十六丈深止四五尺潮势亦缓造闸</span>  
<span style="margin-left: 2em">无难其新洋江口阔四十丈深一丈五尺潮势颇大</span>  
<span style="margin-left: 2em">难以作堰但事体重大及费用钱粮数多必须委官</span>  
<span style="margin-left: 2em">勘议停当方可施行</span>  
<span style="margin-left: 1em">提督苏松水利主事姚文灏疏畧　一设导河之夫苏</span>  
<span style="margin-left: 2em">松常镇沿江近海诸港浦潮沙之积有常而疏导之</span>  
<span style="margin-left: 2em">功不继所以患多而利少前代或设潦浅之夫或置</span>  
<span style="margin-left: 2em">开江之卒专一浚治不限时月近岁役夫皆临期取</span>  
<span style="margin-left: 2em">于里甲而无经制小民劳扰吏缘为奸富者累年不</span>  
<span style="margin-left: 2em">役贫者无岁不差乞将各府导河夫役悉照江北运</span>  
<span style="margin-left: 2em">河及浙西海塘夫例每年于均徭内定拨专一用工</span>  
<span style="margin-left: 2em">庶几无患工部覆奏导河夫役宜行巡抚与本官酌</span>  
<span style="margin-left: 2em">量地方缓急佥点备用可省之处不可滥设</span>  
<span style="margin-left: 1em">御史谢琛疏畧　谨按浙西势本卑下天目诸山西来</span>  
<span style="margin-left: 2em">之水皆归太湖再流入于阳城昆承淀山三泖等湖</span>  
<span style="margin-left: 2em">其性本皆欲东也故神禹相地分流疏其东北入海</span>  
<span style="margin-left: 2em">者为娄江东南流者为东江并淞江为三江以分泄</span>  
<span style="margin-left: 2em">之自是不闻有水患后世海塘一筑其近江淤肥之</span>  
<span style="margin-left: 2em">地悉成腴田而东江之故道塞矣繇是欲使东江之</span>  
<span style="margin-left: 2em">水迤逦北旋会入淞江而趋下之性迟矣故后人于</span>  
<span style="margin-left: 2em">常熟县之北开二十四浦疏而导之杨子江又于昆</span>  
<span style="margin-left: 2em">山县之东开一十二浦分而纳之海所以补东江不</span>  
<span style="margin-left: 2em">通之力也又虑潮沙易于淤塞各于浦口置立板闸</span>  
<span style="margin-left: 2em">潮来则扄之以御泥沙岁旱亦扄之以备灌溉又于</span>  
<span style="margin-left: 2em">闸外或设开江之卒或设撩浅之夫皆所以决壅塞</span>  
<span style="margin-left: 2em">而防泛溢也永乐年间尚书夏原吉区画经度如开</span>  
<span style="margin-left: 2em">刘家白茆二港甚合古人之法自后七八十年朝廷</span>  
<span style="margin-left: 2em">之贡赋不亏百姓赖以安堵弘治七年工部侍郎徐</span>  
<span style="margin-left: 2em">贯亦奉命继理其事比有通判姚文灏辅之一时疏</span>  
<span style="margin-left: 2em">浚之法亦有次第旧制板闸夫卒之设围岸之筑皆</span>  
<span style="margin-left: 2em">未全备是以迄今十二三年诸浦之壅塞如故近年</span>  
<span style="margin-left: 2em">虽有带管佥事官既不专名亦虚设以至一二年来</span>  
<span style="margin-left: 2em">水利日废水患日甚乞命廷臣计议或勅佥都御史</span>  
<span style="margin-left: 2em">兼整前事或选命该部大臣一员前来专理趁今秋</span>  
<span style="margin-left: 2em">收之后访前代疏浚之规为来年水患之备或计各</span>  
<span style="margin-left: 2em">府钱粮之空乏也容其借取浒墅北新等关课钞支</span>  
<span style="margin-left: 2em">用开诸浦以泄诸湖之水复板闸以严启闭之规立</span>  
<span style="margin-left: 2em">夫卒以继疏浚之功筑围岸以防横流之势虽曰费</span>  
<span style="margin-left: 2em">用浩大然计被灾免征之费孰为多寡从可知矣</span>  
<span style="margin-left: 1em">都御史俞谏疏畧　臣遍历苏松常镇杭嘉湖七府所</span>  
<span style="margin-left: 2em">属地方相形度势寻源溯委会同巡抚都御史张凤</span>  
<span style="margin-left: 2em">看得白茆港离海约十五里许旁有姚家浜者旧开</span>  
<span style="margin-left: 2em">通灌支河也东通小湖漕六尺沟至陶泾入海其地</span>  
<span style="margin-left: 2em">形颇下其势趋东南颇顺其水道视旧港颇径直其</span>  
<span style="margin-left: 2em">去横沙亦远若因而广之深阔与白茆称复疏通障</span>  
<span style="margin-left: 2em">碍分决中流会趋驶疾计必可以涤潮沙而垂久远</span>  
<span style="margin-left: 2em">此议一出老农渔父皆以为然随委官逐一勘量民</span>  
<span style="margin-left: 2em">亦愿从欲便起工开浚但苏松等府仓库多虚见在</span>  
<span style="margin-left: 2em">堪动官银不过四千余两况地方人民连遭灾疫逃</span>  
<span style="margin-left: 2em">亡数多凋瘵之余疮痍未复今岁虽得稍收中间尚</span>  
<span style="margin-left: 2em">有包赔荒弃之累加以数年逋负追并一时若又重</span>  
<span style="margin-left: 2em">加派取不无逼民失所致生他患臣等酌量缓急先</span>  
<span style="margin-left: 2em">将高乡淤塞泾漕浜溇低乡坍没圩岸堤防逐一查</span>  
<span style="margin-left: 2em">勘照田多寡分派丈尺督令得利之人趁时浚筑及</span>  
<span style="margin-left: 2em">将前项诸溇百渎江塘河港以次开濬随宜修举其</span>  
<span style="margin-left: 2em">白茆港等处欲候下年农隙兴工</span>  
<span style="margin-left: 1em">王同祖治水议　治水之要其说有三一曰开决三江</span>  
<span style="margin-left: 2em">故道以泄震泽之水二曰浚治诸浦以泄江湖之水</span>  
<span style="margin-left: 2em">三曰疏导泾港以泄田中之水何谓开决三江故道</span>  
<span style="margin-left: 2em">太湖东入淞江出吴江长桥长桥之水未尝不通而</span>  
<span style="margin-left: 2em">所以为东吴害者则在下流入海之处淤故积水溢</span>  
<span style="margin-left: 2em">而为沴耳若复决去长桥使湖流浩至而入海之处</span>  
<span style="margin-left: 2em">又复不疾即吴江昆山常熟三县之地将为深渊此</span>  
<span style="margin-left: 2em">长桥不可尽决利害甚明也东江旧迹在大泖西北</span>  
<span style="margin-left: 2em">为烂路港淀湖西有急水港白蚬江皆东江之西段</span>  
<span style="margin-left: 2em">也淀湖之东有出水港斜沥口汊港口小漕港大沥</span>  
<span style="margin-left: 2em">口小沥口通潮水往来潮退则引湖水下大漕大盈</span>  
<span style="margin-left: 2em">等浦入青龙一龙江而出海皆东江之东段也今诸</span>  
<span style="margin-left: 2em">港皆浅狭壅遏不通潮汐而东江入海之处遂塞东</span>  
<span style="margin-left: 2em">南风水回太湖则湖州诸县皆泛溢西北风太湖水</span>  
<span style="margin-left: 2em">下淀山泖湖则昆山常熟吴江淞江等处泛溢是皆</span>  
<span style="margin-left: 2em">东江不通之害也今之言东江所以塞而不通者大</span>  
<span style="margin-left: 2em">率归咎于黄浦夺权海塘障遏而不知江之通塞亦</span>  
<span style="margin-left: 2em">自有时黄浦海塘未必能为东江害也或以为东江</span>  
<span style="margin-left: 2em">既塞而淀湖之水繇千墩等浦北入于淞江殊不知</span>  
<span style="margin-left: 2em">淀湖之水自属东江其北入于吴淞江者但支流耳</span>  
<span style="margin-left: 2em">遂以为可泄淀湖之水者非也苟能寻东江之旧而</span>  
<span style="margin-left: 2em">疏治之使淀湖所受之水皆得达于东南以入海则</span>  
<span style="margin-left: 2em">松江可通而数百年之害可去万世之利可兴矣何</span>  
<span style="margin-left: 2em">谓濬治诸浦吴郡之地北枕杨子江东通大海西控</span>  
<span style="margin-left: 2em">太湖南襟三江水之发源则自太湖东注三江以入</span>  
<span style="margin-left: 2em">海又其支流北达杨子江以入海故古人于东北沿</span>  
<span style="margin-left: 2em">江海之所濬三十六浦以分三江之势使同归于海</span>  
<span style="margin-left: 2em">其常熟之浦二十有四昆山之浦十有二今三十六</span>  
<span style="margin-left: 2em">浦之中入海者惟茜泾七雅白茆杨林为最大入杨</span>  
<span style="margin-left: 2em">子江者惟福山许浦为最大吴淞江之南有大浦三</span>  
<span style="margin-left: 2em">十六条东自北平破江艾祁顾会养蚕大盈南澥梁</span>  
<span style="margin-left: 2em">纥石臼分乘赵屯内勋石浦道褐萧市金灶千墩注</span>  
<span style="margin-left: 2em">浦张潭棠梨同丘诸天张浦帆归甪直甫里渡头东</span>  
<span style="margin-left: 2em">齐刹刀界浦浮高顺德大姚破墩盏头吴淞之北有</span>  
<span style="margin-left: 2em">大浦三十二修东自顾会安亭徐公北澥瓦浦三林</span>  
<span style="margin-left: 2em">顾幕金城木瓜夏驾奣浦广浦社城新洋江马仁小</span>  
<span style="margin-left: 2em">虞大虞尤泾梁里华翔心渎乐浦薛庄黄渎真义界</span>  
<span style="margin-left: 2em">浦下里戴墟上顾青丘奉里任浦其在江之南者则</span>  
<span style="margin-left: 2em">西受陈湖等水南受淀山湖诸水以入吴淞江而达</span>  
<span style="margin-left: 2em">于海其在江之北者则西受阳城湖诸水横绝至和</span>  
<span style="margin-left: 2em">塘以入吴淞江而达于海自新洋夏驾以东则反纳</span>  
<span style="margin-left: 2em">吴淞江之水以东北趋于刘家港而入海吴淞江迤</span>  
<span style="margin-left: 2em">东入海之口其南有浜浦一十九条皆通上海华亭</span>  
<span style="margin-left: 2em">县界其北有浜浦二十二条皆北通嘉定县界皆近</span>  
<span style="margin-left: 2em">海潮汐往来易于涨塞广者日狭深者日浅惟千墩</span>  
<span style="margin-left: 2em">一浦南通淀山湖最为关要浦极深阔与夏驾新洋</span>  
<span style="margin-left: 2em">南北相望水势相入屡经开濬皆为民利今宜沿江</span>  
<span style="margin-left: 2em">相度各浦之通塞使湖之水必趋于江而江之水得</span>  
<span style="margin-left: 2em">入于海则郡中东南之水定矣何谓疏导泾港盖圩</span>  
<span style="margin-left: 2em">田四围皆泾港环绕或傍江湖或傍浦塘曰泾港者</span>  
<span style="margin-left: 2em">论其槩也泾港之设有公有私今则并通舟楫分利</span>  
<span style="margin-left: 2em">水道旱则引其水以溉田潦则决田之水以入泾港</span>  
<span style="margin-left: 2em">泄诸江湖浦塘使归于海其利于农田最为切要故</span>  
<span style="margin-left: 2em">凡紧要围田水道通行开濬使稍深阔即取其所开</span>  
<span style="margin-left: 2em">之土以修岸塍如是则田间之积水可引入泾港泾</span>  
<span style="margin-left: 2em">港通流可散灌于浦塘浦塘决水可疾趋于江海大</span>  
<span style="margin-left: 2em">小相资首尾相贯又何水之足患乎</span>  
<span style="margin-left: 1em">王同祖工计议　工役计费二事常相须计费足则工</span>  
<span style="margin-left: 2em">役举故今之言治农田水利者莫急于量财盖公役</span>  
<span style="margin-left: 2em">之举岁岁兴修则繁而难行数岁不治则废而难葺</span>  
<span style="margin-left: 2em">故必相其工之大小而为之制开江濬浦以十年为</span>  
<span style="margin-left: 2em">率疏决泾港筑圩治堰岁岁修补或间岁一葺则工</span>  
<span style="margin-left: 2em">役不繁而民不以为劳矣计费之出必量其费之多</span>  
<span style="margin-left: 2em">寡而为之制若开江濬浦疏通泾渎之大者则官为</span>  
<span style="margin-left: 2em">之区画其筑圩修堰及疏决泾港之小者则取诸食</span>  
<span style="margin-left: 2em">利佃作之家如此则不烦于公而不伤于民矣</span>  
<span style="margin-left: 1em">工科吴岩疏畧　臣备员该科谨陈东南水利之切要</span>  
<span style="margin-left: 2em">者三事一曰疏濬下流浙西诸郡苏松最下太湖緜</span>  
<span style="margin-left: 2em">亘数百余里纳诸山溪涧之水散注瀼荡间繇三江</span>  
<span style="margin-left: 2em">以入于海是太湖者诸乡之水所潴而三江又太湖</span>  
<span style="margin-left: 2em">之所繇泄也若下流淤湮汇水泛溢渰没禾稼为害</span>  
<span style="margin-left: 2em">匪轻今要在相其利害为之区处如白茆港七浦塘</span>  
<span style="margin-left: 2em">刘家河皆苏州东北泄水之大川如吴淞江大黄浦</span>  
<span style="margin-left: 2em">是苏松南北交境泄水之大川而吴淞南北与白茆</span>  
<span style="margin-left: 2em">诸港浦之两旁又各有支渠引上流诸湖瀼之水以</span>  
<span style="margin-left: 2em">归其中而并入于海就其中论之苏之七浦塘刘家</span>  
<span style="margin-left: 2em">河松之黄浦并皆深阔通利惟白茆自弘治七年疏</span>  
<span style="margin-left: 2em">浚之后今入海之处潮沙壅积势若丘阜而吴淞之</span>  
<span style="margin-left: 2em">旁渠港亦多湮塞今诚能濬白茆一港使之通利如</span>  
<span style="margin-left: 2em">七浦刘家河则苏州东北之水有所归而不积矣濬</span>  
<span style="margin-left: 2em">吴淞一江使之通利如大黄浦则苏松南北两界之</span>
