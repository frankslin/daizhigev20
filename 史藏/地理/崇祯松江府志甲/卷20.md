## 崇禎松江府志卷之二十　壇廟　祠祀

<span style="margin-left: 3em">壇壝廟祀</span>  
<span style="margin-left: 1em">尚巫尊鬼好禮君子所不道也然廟宇壇壝載在秩祀</span>  
<span style="margin-left: 1em">者實有靈德以庇我邦人祈禳報賽昭答如響地而壇</span>  
<span style="margin-left: 1em">屋而廟豈叢祠中無名之土木耶頃鄉氓無知曾不識</span>  
<span style="margin-left: 1em">海忠介瑞周忠介順昌爲何如人而葦航笋輿以迎導</span>  
<span style="margin-left: 1em">之鼔樂繒旗所在而是蓋人心之神即神也昔石慶爲</span>  
<span style="margin-left: 1em">齊相則有石相祠欒布守燕郡則有欒公社今得無類</span>  
<span style="margin-left: 1em">是乎書之勸忠非以語怪</span>  
<span style="margin-left: 1em">社稷壇在通波門外舊志府西北二里後廢爲教塲元</span>  
<span style="margin-left: 1em">貞初知府張之翰祀于西湖道院至大間知府李禄兒</span>  
<span style="margin-left: 1em">移置太平橋西宋造船塲際留倉也　國朝洪武二年</span>  
<span style="margin-left: 1em">遷於此</span>  
<span style="margin-left: 2em">社壇記　華亭壯縣錢穀獄訟簿書視他邑爲劇令</span>  
<span style="margin-left: 2em">自朝至暮或繼以燭猶恐弗給何暇問社稷之祀哉</span>  
<span style="margin-left: 2em">縣社壇在西北隅春秋祈報第舉故事退則未嘗一</span>  
<span style="margin-left: 2em">顧而問焉信安徐民瞻始來領縣事于是召匠計工</span>  
<span style="margin-left: 2em">命僧祖隆視役土木一新越明年畢事二月戊寅社</span>  
<span style="margin-left: 2em">用牲于壇酌奠有位升降有次祝史薦信神明顧歆</span>  
<span style="margin-left: 2em">父老觀瞻莫不歎息以爲前此未之覩也昔唐永徽</span>  
<span style="margin-left: 2em">間州尚淫祀往往不立社稷獨一建州刺史叙立祀</span>  
<span style="margin-left: 2em">塲以取重當世如君又有過人者以日不暇給而能</span>  
<span style="margin-left: 2em">爲人所不爲不忘其本君子於是乎可以觀政矣太</span>  
<span style="margin-left: 2em">常博士鍾必萬記</span>  
<span style="margin-left: 2em">重修壇壝記　社五土祀稷五穀祀皆主生育之神</span>  
<span style="margin-left: 2em">也帝高陽以句龍爲社柱爲稷而社稷之祀始立高</span>  
<span style="margin-left: 2em">辛唐虞夏因之商旱以棄代柱周因之以句龍配社</span>  
<span style="margin-left: 2em">棄配稷主象位置壇土方色玉牲幣樂祭服時日與</span>  
<span style="margin-left: 2em">所立木上下有差而社稷之祀始備然曰配則社稷</span>  
<span style="margin-left: 2em">固有神龍棄特配之之神爾後漢建武二年詔郡縣</span>  
<span style="margin-left: 2em">置社稷太守令長特祠二八月及臘歲三祀而社稷</span>  
<span style="margin-left: 2em">之祀始廣梁加祀靈星風雨師之屬時用春仲秋仲</span>  
<span style="margin-left: 2em">而無臘祀周日用甲隋易以戊今郡縣得春秋仲月</span>  
<span style="margin-left: 2em">上戊日祀社稷風雨之屬實始于漢而備於隋華亭</span>  
<span style="margin-left: 2em">爲東南壯縣生育之功神寔主焉　國朝陞松江府</span>  
<span style="margin-left: 2em">社稷仍舊無變置居城西南陬主象傾欹壇級圮毁</span>  
<span style="margin-left: 2em">地削于民草牧于牛羊滋有年矣職郡者遇當祀夜</span>  
<span style="margin-left: 2em">分一俯伏麗奠而退禳禱并至若無神焉元統甲戌</span>  
<span style="margin-left: 2em">鎮陽申侯來守謁祠下瞻歎怵忸力新祠事取辦于</span>  
<span style="margin-left: 2em">己不傷財勞民衙休必躬督焉未幾傾者樹毁者築</span>  
<span style="margin-left: 2em">削復而牧者屏壇位崇庳一新如式東社西稷雨雷</span>  
<span style="margin-left: 2em">附稷西郊少南主咸北面以東爲右北爲上遵制典</span>  
<span style="margin-left: 2em">也環祠爲屋大小十有七楹繚以周垣神門閽舍幕</span>  
<span style="margin-left: 2em">次庖湢靡不畢具東西爲步二十有八南北四十有</span>  
<span style="margin-left: 2em">七作于至元二年之春正月夏五落成府陰陽教授</span>  
<span style="margin-left: 2em">白公實相厥工有弗祀祀必神歆有弗禱禱必受福</span>  
<span style="margin-left: 2em">自侯來守建風壇飾公館儒而庠校書院神而金山</span>  
<span style="margin-left: 2em">祠武安祠醫而惠民局興墜補弊罔不葺完社稷則</span>  
<span style="margin-left: 2em">報穀育而禳旱溢者也關民命尤急務民義而敬鬼</span>  
<span style="margin-left: 2em">神惟侯有之請述其槩庶幾繼治于後者視侯之功</span>  
<span style="margin-left: 2em">爲法至元丙子八月雲間布衣陸居仁記</span>  
<span style="margin-left: 2em"><sub class="note-yuan">祝文品物資生民乃粒食養育之功司土是賴今兹仲春秋理宜告報祀謹以牲帛醴齊粢盛庶品式陳明薦</sub></span>  
<span style="margin-left: 1em">風雲雷雨境內山川城隍神壇在集僊門外官紹塘上</span>  
<span style="margin-left: 2em">元制風師壇在府治東北清修寺前雷雨壇附于稷</span>  
<span style="margin-left: 2em">右　國朝洪武二年遷于此并山川城隍祀之</span>  
<span style="margin-left: 2em"><sub class="note-yuan">祝文妙用神機生育萬物奠我民居足我民食某等欽承上命忝職兹土今當仲春秋理宜告報祀</sub></span>  
<span style="margin-left: 1em">東海神壇在柘林洪武十六年建</span>  
<span style="margin-left: 1em">郡厲壇在通波門外濠上洪武三年建</span>  
<span style="margin-left: 1em">五土五穀神壇每里一所凡八百四十三所洪武十五</span>  
<span style="margin-left: 1em">年建</span>  
<span style="margin-left: 1em">鄉厲壇今附郭並于土穀壇寓祭</span>  
<span style="margin-left: 1em">上海縣社稷壇在縣西北洪武二年建嘉靖二年重修</span>  
<span style="margin-left: 2em">知縣鄭洛書記　正德十六年上戊上海令莆人鄭</span>  
<span style="margin-left: 2em">洛書肇祀社稷空壇越在草莽敗垣廢屋牛羊來斯</span>  
<span style="margin-left: 2em">弗稱崇奉之意亟以祭之日修之迨秋祭垣屋新壇</span>  
<span style="margin-left: 2em">亦新是年也歲稔人謂鬼神顧歆云嘉靖二年七月</span>  
<span style="margin-left: 2em">立石</span>  
<span style="margin-left: 1em">風雲雷雨境內山川神壇在縣南洪武二年建嘉靖二</span>  
<span style="margin-left: 1em">年重修</span>  
<span style="margin-left: 2em">鄭洛書記　上海山川壇昔者圯官無齋所神若野</span>  
<span style="margin-left: 2em">宿正德十五年冬洛書爲宰明年春顧瞻蕪陋心大</span>  
<span style="margin-left: 2em">弗寧遂以畢祭之日築壇以棲神作室以齋官是秋</span>  
<span style="margin-left: 2em">告訖工擇謹良二人守之俾勿壞壞則聞于官亟修</span>  
<span style="margin-left: 2em">之俾勿壞嘉靖二年時乃考績爰勒所由</span>  
<span style="margin-left: 1em">東海神壇在縣東南長人鄉洪武十六年建</span>  
<span style="margin-left: 1em">邑厲壇在縣治北洪武三年建嘉靖二年重修</span>  
<span style="margin-left: 2em">鄭洛書記　明有鰥寡孤獨幽有厲鬼朝廷矜恤之</span>  
<span style="margin-left: 2em">心何間死生故厲鬼者壇而祀之正德十五年洛書</span>  
<span style="margin-left: 2em">出宰上海越明年清明舉祭則見垣頽址荒雲風蕭</span>  
<span style="margin-left: 2em">颯草木凄其若滯魂號訴無依者亟令工匠治其垣</span>  
<span style="margin-left: 2em">屋更封其壇是秋中元祭告成鬼罔怨恫洋洋如在</span>  
<span style="margin-left: 2em">嘉靖二年八月朔日買石記之</span>  
<span style="margin-left: 1em">土穀神壇每里一所凡七百三十所洪武十五年置</span>  
<span style="margin-left: 1em">鄉厲壇每里一所洪武十五年置</span>  
<span style="margin-left: 1em">青浦縣社稷壇在南門外</span>  
<span style="margin-left: 1em">風雲雷雨境內山川神壇在南門外</span>  
<span style="margin-left: 1em">邑厲壇在北門外</span>  
<span style="margin-left: 3em">廟祀</span>  
<span style="margin-left: 1em">城隍廟舊在府西廣明橋右趙店土地廟之西宋政和</span>  
<span style="margin-left: 1em">間遷於東南盟素道院之側元至正二年守楊伯野台</span>  
<span style="margin-left: 1em">拓地改建丙戍燬于火郡人孫明緒成之　國朝洪武</span>  
<span style="margin-left: 1em">三年守林公慶即興聖殿址作今廟正統九年郡守趙</span>  
<span style="margin-left: 1em">公豫新其門廡景泰庚午又火守黃公平請于巡撫侍</span>  
<span style="margin-left: 1em">郎周公忱重建成化十五年王公衡闢其寢宫于正殿</span>  
<span style="margin-left: 1em">後弘治戊申五月颶風大作殿宇傾圮守劉公璟庀材</span>  
<span style="margin-left: 1em">鳩工廟貌如故正德戊辰再新于翁公理又於廊廡塑</span>  
<span style="margin-left: 1em">二十四司神像嘉靖乙丑復火郡守衷公貞吉邑令聶</span>  
<span style="margin-left: 1em">公廷璧捐俸勸助落成萬曆己亥林冏卿景暘建坊與</span>  
<span style="margin-left: 1em">門丁未建臺軒易木以石邑侯熊公劍化創其事俞僉</span>  
<span style="margin-left: 1em">憲汝爲助成之壬子又兩廡建樓庚戌落成泰昌元年</span>  
<span style="margin-left: 1em">更崇寢殿丹堊歲增壯麗加于昔矣</span>  
<span style="margin-left: 2em">按通志唐李陽冰曰今州縣城隍相傳祀紀信云</span>  
<span style="margin-left: 2em">誥命　制曰帝王受　天明命行正教於天下必有</span>  
<span style="margin-left: 2em">生聖之瑞受命之符此天示不言之教而人見聞所</span>  
<span style="margin-left: 2em">及者也神司淑慝爲天降祥亦必受天之命所謂明</span>  
<span style="margin-left: 2em">有禮樂幽有鬼神天理人心其致一也朕君四方雖</span>  
<span style="margin-left: 2em">明哲弗類代天理物之道實罄於衷思應天命此神</span>  
<span style="margin-left: 2em">所鑒而簡在帝心者君道之大惟典神天有其舉之</span>  
<span style="margin-left: 2em">承事惟謹松江府城隍聰明正直聖不可知固有超</span>  
<span style="margin-left: 2em">於高城深池之表者世之崇於神者則然神受於天</span>  
<span style="margin-left: 2em">者蓋不可知也兹以臨御之初與天下更始凡城隍</span>  
<span style="margin-left: 2em">之神皆新其命睠此郡城明祗所司宜封曰鍳察司</span>  
<span style="margin-left: 2em">民城隍威靈公威則照臨有赫靈則感通無方此固</span>  
<span style="margin-left: 2em">神之德而亦天之命也司於吾民鍳於郡政享兹祀</span>  
<span style="margin-left: 2em">典悠久無疆主者施行<sub class="note-yuan">崇禎庚午年司理徐日曦手書金字榜于儀門之旁</sub></span>  
<span style="margin-left: 2em">景泰六年郡饑撫按奏聞禦製祭文欽頒銀十兩具</span>  
<span style="margin-left: 2em">牲牢香幣致祭　文曰維景泰六年歲次乙亥閏六</span>  
<span style="margin-left: 2em">月乙巳朔越六日庚戌皇帝謹遣都察院左副都御</span>  
<span style="margin-left: 2em">史鄒來學祗奉香幣牲醴之儀專禱祀於松江府城</span>  
<span style="margin-left: 2em">隍廟之神曰恭承　大命重付渺躬民社所依災祥</span>  
<span style="margin-left: 2em">攸繫志恒內省政每外乖或寒燠愆期或雨暘踰度</span>  
<span style="margin-left: 2em">農事失利穀麥不登憂切民心妨及國計水旱疾疫</span>  
<span style="margin-left: 2em">叠見此方飢饉流亡間臻累歲究惟所自良有在兹</span>  
<span style="margin-left: 2em">然因咎致災固朕躬罔避而轉殃爲福實神職當專</span>  
<span style="margin-left: 2em">夫有咎無功過將惟一而轉殃爲福功孰與鈞特致</span>  
<span style="margin-left: 2em">懇禱幸副懸望謹告</span>  
<span style="margin-left: 2em">元吳暾重修記　政治通乎神所教化移乎風俗古</span>  
<span style="margin-left: 2em">人所以先治民而後致力於神也松江瀕海爲郡當</span>  
<span style="margin-left: 2em">衆水積流之滙雨則浸其西陲旱則亢其東境苟非</span>  
<span style="margin-left: 2em">感通以協二氣之和存誠以祈百靈之祐則不足以</span>  
<span style="margin-left: 2em">乘豐穰而安生聚也至元庚辰知府楊公來守此土</span>  
<span style="margin-left: 2em">究心民瘼厲志官政剗奸剔蠧鋤强櫛梗上下胥和</span>  
<span style="margin-left: 2em">遠邇丕變爰相府署大新堂門制度改觀既又念夫</span>  
<span style="margin-left: 2em">明則禮樂幽則鬼神土地人民之衆蒞其上者既有</span>  
<span style="margin-left: 2em">以安其居則隲而相之獨無其神者乃詣城隍祠躬</span>  
<span style="margin-left: 2em">致禱禬以格靈祉而棟宇庳陋衢路逼塞鄰伍湫隘</span>  
<span style="margin-left: 2em">像設漫漶大懼非所報效首揭私帑六千緡售拓基</span>  
<span style="margin-left: 2em">地東西延廣一百尺南北長袤達于通衢凡一百二</span>  
<span style="margin-left: 2em">十尺相舊廟不足以起瞻仰徙爲後寢購工募材營</span>  
<span style="margin-left: 2em">建前殿璇題翬飛觚稜角峙周阿焕彩級陛森嚴拱</span>  
<span style="margin-left: 2em">以序廡繚以閈闥憑附之質揭妥之具丹青彩施金</span>  
<span style="margin-left: 2em">碧動盪儼然監臨如神斯在祀事孔嚴登降有懌經</span>  
<span style="margin-left: 2em">始於至正元年三月以二年正月竣事凡用緡鈔五</span>  
<span style="margin-left: 2em">萬是歲水波减縮歲以大稔田無侵没河不遏淤民</span>  
<span style="margin-left: 2em">用大和官賦早集咸謂神之賜侯之德也侯名伸字</span>  
<span style="margin-left: 2em">公正絳州人是廟故宋楊令瑾建于淳祐丁未九十</span>  
<span style="margin-left: 2em">八年矣今太守爲同姓乃復改大而重建焉蓋亦神</span>  
<span style="margin-left: 2em">之有待數之相符也</span>  
<span style="margin-left: 2em">張犖重修記　吾松有城隍祠以祀威靈公之神其</span>  
<span style="margin-left: 2em">祠初處郡治南東折而入地位偪久不稱瞻仰至</span>  
<span style="margin-left: 2em">洪武初始遷於南地址恢廓堂殿廊廡皆大其規制</span>  
<span style="margin-left: 2em">弘治改元夏五月大雨暴作飄瓦毁垣寢殿門廡皆</span>  
<span style="margin-left: 2em">就傾圮郡守河南劉公修葺祠宇捐己俸爲諸寮倡</span>  
<span style="margin-left: 2em">而華亭尹汪侯贊成之一時義士相率助金遂鳩工</span>  
<span style="margin-left: 2em">集材經始于弘治戊申越明年己酉告畢郡公致禮</span>  
<span style="margin-left: 2em">需予言以識歲月故予叙侯之績又從而歌之曰維</span>  
<span style="margin-left: 2em">神降靈司吾松威光赫赫神之宗國朝祀典加褒崇</span>  
<span style="margin-left: 2em">錫以爵位踰侯封靈祠巍搆擬法宫歲久漫漶凋青</span>  
<span style="margin-left: 2em">紅震風凌雨交相攻聿傾棟宇頽垣墉總有神力難</span>

<span style="margin-left: 2em">錢溥文襄公祠記　大丈夫建功業于時者易而惠</span>  
<span style="margin-left: 2em">澤不忘于人者難蓋不忘于近固難而尤莫難乎愈</span>  
<span style="margin-left: 2em">久而愈不忘之爲難非惠澤入人深者能之乎涉河</span>  
<span style="margin-left: 2em">而思禹詠甘棠而思召伯繪像于蜀而思張方平與</span>  
<span style="margin-left: 2em">吾郡守王侯因民之思而祠文襄廬陵周公同一愈</span>  
<span style="margin-left: 2em">久而愈不忘也夫自太宗文皇帝肇建北京以南京</span>  
<span style="margin-left: 2em">爲留守兩京財賦悉仰于東吳而松爲最松有鹽糧</span>  
<span style="margin-left: 2em">二賦誅求無藝國用日虧而催徵吏絡繹於路徵急</span>  
<span style="margin-left: 2em">而民愈困宣德七年壬子少師楊文貞公薦公自越</span>

<span style="margin-left: 2em">列郡而盡得其病利首立水次倉令民自負載詣納</span>  
<span style="margin-left: 2em">始抵石民以爲怨公曰始試爾不一載積逋悉完而</span>  
<span style="margin-left: 2em">叫呶其村落者一跡不至遂减以十之七民乃大悦</span>  
<span style="margin-left: 2em">善煮海曰滷丁其遠而不善者曰灶户舊以灶户出</span>

<span style="margin-left: 2em">息而鹽商願出於其塗民棄官田而逋者居民亦沾</span>  
<span style="margin-left: 2em">足則執以償其賦雖良田沃壤皆蕪廢不治公乃立</span>  
<span style="margin-left: 2em">召佃法令民任薄賦墾闢而逋者亦轉緣于南畝民</span>  
<span style="margin-left: 2em">有死絕積荒該賠者有馬草夏稅鹽鈔驛騎鋪陳歲</span>

<span style="margin-left: 2em">便于爾耶辭不復理奸弊百出民用滋困松父老請</span>

<span style="margin-left: 2em">枕籍于道雖垂死猶曰安得周公復生以活我耶聲</span>

<span style="margin-left: 2em">祠韓如其去鱷而興學民亦思之如韓今侯能祠公</span>

<span style="margin-left: 2em">之使惠澤不忘于人也有以乎不忘于公亦不忘于</span>  
<span style="margin-left: 2em">侯矣故記其麗牲碑而系以詩曰公昔乘雲朝帝鄉</span>  
<span style="margin-left: 2em">有法無守民遭殃水旱缺食多死亡遺愛在松民不</span>  
<span style="margin-left: 2em">忘聲徹當宁謚文襄民欲祠公嗟未遑吾侯歘來自</span>  
<span style="margin-left: 1em">　　帝傍構祠乃在邑之陽春秋禴祀蘋蘩香公不來</span>  
<span style="margin-left: 2em">予涕泗滂雲車挾鳳驂龍翔一時止淚何洋洋公不</span>  
<span style="margin-left: 2em">肯留惟降康歲無災厲民其昌豈惟成績紀太常祀</span>  
<span style="margin-left: 2em">事與國同休光後其曰歌歌此章</span>  
<span style="margin-left: 2em">祝文<sub class="note-yuan">河渠賦役二公經埋或保其成或聞其始海不揚波民不逋負陽烏攸居福星滿路朝廷得人如公天子無勞東顧今兹仲春秋用仲常祭峯泖不移啟佑爲利</sub></span>
