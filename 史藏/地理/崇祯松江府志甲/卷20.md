## 崇祯松江府志卷之二十　坛庙　祠祀

<span style="margin-left: 3em">坛壝庙祀</span>  
<span style="margin-left: 1em">尚巫尊鬼好礼君子所不道也然庙宇坛壝载在秩祀</span>  
<span style="margin-left: 1em">者实有灵德以庇我邦人祈禳报赛昭答如响地而坛</span>  
<span style="margin-left: 1em">屋而庙岂丛祠中无名之土木耶顷乡氓无知曾不识</span>  
<span style="margin-left: 1em">海忠介瑞周忠介顺昌为何如人而苇航笋舆以迎导</span>  
<span style="margin-left: 1em">之鼔乐缯旗所在而是盖人心之神即神也昔石庆为</span>  
<span style="margin-left: 1em">齐相则有石相祠栾布守燕郡则有栾公社今得无类</span>  
<span style="margin-left: 1em">是乎书之劝忠非以语怪</span>  
<span style="margin-left: 1em">社稷坛在通波门外旧志府西北二里后废为教塲元</span>  
<span style="margin-left: 1em">贞初知府张之翰祀于西湖道院至大间知府李禄儿</span>  
<span style="margin-left: 1em">移置太平桥西宋造船塲际留仓也　国朝洪武二年</span>  
<span style="margin-left: 1em">迁于此</span>  
<span style="margin-left: 2em">社坛记　华亭壮县钱谷狱讼簿书视他邑为剧令</span>  
<span style="margin-left: 2em">自朝至暮或继以烛犹恐弗给何暇问社稷之祀哉</span>  
<span style="margin-left: 2em">县社坛在西北隅春秋祈报第举故事退则未尝一</span>  
<span style="margin-left: 2em">顾而问焉信安徐民瞻始来领县事于是召匠计工</span>  
<span style="margin-left: 2em">命僧祖隆视役土木一新越明年毕事二月戊寅社</span>  
<span style="margin-left: 2em">用牲于坛酌奠有位升降有次祝史荐信神明顾歆</span>  
<span style="margin-left: 2em">父老观瞻莫不叹息以为前此未之覩也昔唐永徽</span>  
<span style="margin-left: 2em">间州尚淫祀往往不立社稷独一建州刺史叙立祀</span>  
<span style="margin-left: 2em">塲以取重当世如君又有过人者以日不暇给而能</span>  
<span style="margin-left: 2em">为人所不为不忘其本君子于是乎可以观政矣太</span>  
<span style="margin-left: 2em">常博士钟必万记</span>  
<span style="margin-left: 2em">重修坛壝记　社五土祀稷五谷祀皆主生育之神</span>  
<span style="margin-left: 2em">也帝高阳以句龙为社柱为稷而社稷之祀始立高</span>  
<span style="margin-left: 2em">辛唐虞夏因之商旱以弃代柱周因之以句龙配社</span>  
<span style="margin-left: 2em">弃配稷主象位置坛土方色玉牲币乐祭服时日与</span>  
<span style="margin-left: 2em">所立木上下有差而社稷之祀始备然曰配则社稷</span>  
<span style="margin-left: 2em">固有神龙弃特配之之神尔后汉建武二年诏郡县</span>  
<span style="margin-left: 2em">置社稷太守令长特祠二八月及腊岁三祀而社稷</span>  
<span style="margin-left: 2em">之祀始广梁加祀灵星风雨师之属时用春仲秋仲</span>  
<span style="margin-left: 2em">而无腊祀周日用甲隋易以戊今郡县得春秋仲月</span>  
<span style="margin-left: 2em">上戊日祀社稷风雨之属实始于汉而备于隋华亭</span>  
<span style="margin-left: 2em">为东南壮县生育之功神寔主焉　国朝升松江府</span>  
<span style="margin-left: 2em">社稷仍旧无变置居城西南陬主象倾欹坛级圮毁</span>  
<span style="margin-left: 2em">地削于民草牧于牛羊滋有年矣职郡者遇当祀夜</span>  
<span style="margin-left: 2em">分一俯伏丽奠而退禳祷并至若无神焉元统甲戌</span>  
<span style="margin-left: 2em">镇阳申侯来守谒祠下瞻叹怵忸力新祠事取办于</span>  
<span style="margin-left: 2em">己不伤财劳民衙休必躬督焉未几倾者树毁者筑</span>  
<span style="margin-left: 2em">削复而牧者屏坛位崇庳一新如式东社西稷雨雷</span>  
<span style="margin-left: 2em">附稷西郊少南主咸北面以东为右北为上遵制典</span>  
<span style="margin-left: 2em">也环祠为屋大小十有七楹缭以周垣神门阍舍幕</span>  
<span style="margin-left: 2em">次庖湢靡不毕具东西为步二十有八南北四十有</span>  
<span style="margin-left: 2em">七作于至元二年之春正月夏五落成府阴阳教授</span>  
<span style="margin-left: 2em">白公实相厥工有弗祀祀必神歆有弗祷祷必受福</span>  
<span style="margin-left: 2em">自侯来守建风坛饰公馆儒而庠校书院神而金山</span>  
<span style="margin-left: 2em">祠武安祠医而惠民局兴坠补弊罔不葺完社稷则</span>  
<span style="margin-left: 2em">报谷育而禳旱溢者也关民命尤急务民义而敬鬼</span>  
<span style="margin-left: 2em">神惟侯有之请述其槩庶几继治于后者视侯之功</span>  
<span style="margin-left: 2em">为法至元丙子八月云间布衣陆居仁记</span>  
<span style="margin-left: 2em"><sub class="note-yuan">祝文品物资生民乃粒食养育之功司土是赖今兹仲春秋理宜告报祀谨以牲帛醴齐粢盛庶品式陈明荐</sub></span>  
<span style="margin-left: 1em">风云雷雨境内山川城隍神坛在集僊门外官绍塘上</span>  
<span style="margin-left: 2em">元制风师坛在府治东北清修寺前雷雨坛附于稷</span>  
<span style="margin-left: 2em">右　国朝洪武二年迁于此并山川城隍祀之</span>  
<span style="margin-left: 2em"><sub class="note-yuan">祝文妙用神机生育万物奠我民居足我民食某等钦承上命忝职兹土今当仲春秋理宜告报祀</sub></span>  
<span style="margin-left: 1em">东海神坛在柘林洪武十六年建</span>  
<span style="margin-left: 1em">郡厉坛在通波门外濠上洪武三年建</span>  
<span style="margin-left: 1em">五土五谷神坛每里一所凡八百四十三所洪武十五</span>  
<span style="margin-left: 1em">年建</span>  
<span style="margin-left: 1em">乡厉坛今附郭并于土谷坛寓祭</span>  
<span style="margin-left: 1em">上海县社稷坛在县西北洪武二年建嘉靖二年重修</span>  
<span style="margin-left: 2em">知县郑洛书记　正德十六年上戊上海令莆人郑</span>  
<span style="margin-left: 2em">洛书肇祀社稷空坛越在草莽败垣废屋牛羊来斯</span>  
<span style="margin-left: 2em">弗称崇奉之意亟以祭之日修之迨秋祭垣屋新坛</span>  
<span style="margin-left: 2em">亦新是年也岁稔人谓鬼神顾歆云嘉靖二年七月</span>  
<span style="margin-left: 2em">立石</span>  
<span style="margin-left: 1em">风云雷雨境内山川神坛在县南洪武二年建嘉靖二</span>  
<span style="margin-left: 1em">年重修</span>  
<span style="margin-left: 2em">郑洛书记　上海山川坛昔者圯官无斋所神若野</span>  
<span style="margin-left: 2em">宿正德十五年冬洛书为宰明年春顾瞻芜陋心大</span>  
<span style="margin-left: 2em">弗宁遂以毕祭之日筑坛以栖神作室以斋官是秋</span>  
<span style="margin-left: 2em">告讫工择谨良二人守之俾勿坏坏则闻于官亟修</span>  
<span style="margin-left: 2em">之俾勿坏嘉靖二年时乃考绩爰勒所由</span>  
<span style="margin-left: 1em">东海神坛在县东南长人乡洪武十六年建</span>  
<span style="margin-left: 1em">邑厉坛在县治北洪武三年建嘉靖二年重修</span>  
<span style="margin-left: 2em">郑洛书记　明有鳏寡孤独幽有厉鬼朝廷矜恤之</span>  
<span style="margin-left: 2em">心何间死生故厉鬼者坛而祀之正德十五年洛书</span>  
<span style="margin-left: 2em">出宰上海越明年清明举祭则见垣颓址荒云风萧</span>  
<span style="margin-left: 2em">飒草木凄其若滞魂号诉无依者亟令工匠治其垣</span>  
<span style="margin-left: 2em">屋更封其坛是秋中元祭告成鬼罔怨恫洋洋如在</span>  
<span style="margin-left: 2em">嘉靖二年八月朔日买石记之</span>  
<span style="margin-left: 1em">土谷神坛每里一所凡七百三十所洪武十五年置</span>  
<span style="margin-left: 1em">乡厉坛每里一所洪武十五年置</span>  
<span style="margin-left: 1em">青浦县社稷坛在南门外</span>  
<span style="margin-left: 1em">风云雷雨境内山川神坛在南门外</span>  
<span style="margin-left: 1em">邑厉坛在北门外</span>  
<span style="margin-left: 3em">庙祀</span>  
<span style="margin-left: 1em">城隍庙旧在府西广明桥右赵店土地庙之西宋政和</span>  
<span style="margin-left: 1em">间迁于东南盟素道院之侧元至正二年守杨伯野台</span>  
<span style="margin-left: 1em">拓地改建丙戍毁于火郡人孙明绪成之　国朝洪武</span>  
<span style="margin-left: 1em">三年守林公庆即兴圣殿址作今庙正统九年郡守赵</span>  
<span style="margin-left: 1em">公豫新其门庑景泰庚午又火守黄公平请于巡抚侍</span>  
<span style="margin-left: 1em">郎周公忱重建成化十五年王公衡辟其寝宫于正殿</span>  
<span style="margin-left: 1em">后弘治戊申五月飓风大作殿宇倾圮守刘公璟庀材</span>  
<span style="margin-left: 1em">鸠工庙貌如故正德戊辰再新于翁公理又于廊庑塑</span>  
<span style="margin-left: 1em">二十四司神像嘉靖乙丑复火郡守衷公贞吉邑令聂</span>  
<span style="margin-left: 1em">公廷璧捐俸劝助落成万历己亥林冏卿景旸建坊与</span>  
<span style="margin-left: 1em">门丁未建台轩易木以石邑侯熊公剑化创其事俞佥</span>  
<span style="margin-left: 1em">宪汝为助成之壬子又两庑建楼庚戌落成泰昌元年</span>  
<span style="margin-left: 1em">更崇寝殿丹垩岁增壮丽加于昔矣</span>  
<span style="margin-left: 2em">按通志唐李阳冰曰今州县城隍相传祀纪信云</span>  
<span style="margin-left: 2em">诰命　制曰帝王受　天明命行正教于天下必有</span>  
<span style="margin-left: 2em">生圣之瑞受命之符此天示不言之教而人见闻所</span>  
<span style="margin-left: 2em">及者也神司淑慝为天降祥亦必受天之命所谓明</span>  
<span style="margin-left: 2em">有礼乐幽有鬼神天理人心其致一也朕君四方虽</span>  
<span style="margin-left: 2em">明哲弗类代天理物之道实罄于衷思应天命此神</span>  
<span style="margin-left: 2em">所鉴而简在帝心者君道之大惟典神天有其举之</span>  
<span style="margin-left: 2em">承事惟谨松江府城隍聪明正直圣不可知固有超</span>  
<span style="margin-left: 2em">于高城深池之表者世之崇于神者则然神受于天</span>  
<span style="margin-left: 2em">者盖不可知也兹以临御之初与天下更始凡城隍</span>  
<span style="margin-left: 2em">之神皆新其命睠此郡城明祗所司宜封曰鍳察司</span>  
<span style="margin-left: 2em">民城隍威灵公威则照临有赫灵则感通无方此固</span>  
<span style="margin-left: 2em">神之德而亦天之命也司于吾民鍳于郡政享兹祀</span>  
<span style="margin-left: 2em">典悠久无疆主者施行<sub class="note-yuan">崇祯庚午年司理徐日曦手书金字榜于仪门之旁</sub></span>  
<span style="margin-left: 2em">景泰六年郡饥抚按奏闻御制祭文钦颁银十两具</span>  
<span style="margin-left: 2em">牲牢香币致祭　文曰维景泰六年岁次乙亥闰六</span>  
<span style="margin-left: 2em">月乙巳朔越六日庚戌皇帝谨遣都察院左副都御</span>  
<span style="margin-left: 2em">史邹来学祗奉香币牲醴之仪专祷祀于松江府城</span>  
<span style="margin-left: 2em">隍庙之神曰恭承　大命重付渺躬民社所依灾祥</span>  
<span style="margin-left: 2em">攸系志恒内省政每外乖或寒燠愆期或雨旸逾度</span>  
<span style="margin-left: 2em">农事失利谷麦不登忧切民心妨及国计水旱疾疫</span>  
<span style="margin-left: 2em">叠见此方饥馑流亡间臻累岁究惟所自良有在兹</span>  
<span style="margin-left: 2em">然因咎致灾固朕躬罔避而转殃为福实神职当专</span>  
<span style="margin-left: 2em">夫有咎无功过将惟一而转殃为福功孰与钧特致</span>  
<span style="margin-left: 2em">恳祷幸副悬望谨告</span>  
<span style="margin-left: 2em">元吴暾重修记　政治通乎神所教化移乎风俗古</span>  
<span style="margin-left: 2em">人所以先治民而后致力于神也松江濒海为郡当</span>  
<span style="margin-left: 2em">众水积流之汇雨则浸其西陲旱则亢其东境苟非</span>  
<span style="margin-left: 2em">感通以协二气之和存诚以祈百灵之祐则不足以</span>  
<span style="margin-left: 2em">乘丰穰而安生聚也至元庚辰知府杨公来守此土</span>  
<span style="margin-left: 2em">究心民瘼厉志官政刬奸剔蠧锄强栉梗上下胥和</span>  
<span style="margin-left: 2em">远迩丕变爰相府署大新堂门制度改观既又念夫</span>  
<span style="margin-left: 2em">明则礼乐幽则鬼神土地人民之众莅其上者既有</span>  
<span style="margin-left: 2em">以安其居则隲而相之独无其神者乃诣城隍祠躬</span>  
<span style="margin-left: 2em">致祷禬以格灵祉而栋宇庳陋衢路逼塞邻伍湫隘</span>  
<span style="margin-left: 2em">像设漫漶大惧非所报效首揭私帑六千缗售拓基</span>  
<span style="margin-left: 2em">地东西延广一百尺南北长袤达于通衢凡一百二</span>  
<span style="margin-left: 2em">十尺相旧庙不足以起瞻仰徙为后寝购工募材营</span>  
<span style="margin-left: 2em">建前殿璇题翚飞觚棱角峙周阿焕彩级陛森严拱</span>  
<span style="margin-left: 2em">以序庑缭以闬闼凭附之质揭妥之具丹青彩施金</span>  
<span style="margin-left: 2em">碧动荡俨然监临如神斯在祀事孔严登降有怿经</span>  
<span style="margin-left: 2em">始于至正元年三月以二年正月竣事凡用缗钞五</span>  
<span style="margin-left: 2em">万是岁水波减缩岁以大稔田无侵没河不遏淤民</span>  
<span style="margin-left: 2em">用大和官赋早集咸谓神之赐侯之德也侯名伸字</span>  
<span style="margin-left: 2em">公正绛州人是庙故宋杨令瑾建于淳祐丁未九十</span>  
<span style="margin-left: 2em">八年矣今太守为同姓乃复改大而重建焉盖亦神</span>  
<span style="margin-left: 2em">之有待数之相符也</span>  
<span style="margin-left: 2em">张荦重修记　吾松有城隍祠以祀威灵公之神其</span>  
<span style="margin-left: 2em">祠初处郡治南东折而入地位偪久不称瞻仰至</span>  
<span style="margin-left: 2em">洪武初始迁于南地址恢廓堂殿廊庑皆大其规制</span>  
<span style="margin-left: 2em">弘治改元夏五月大雨暴作飘瓦毁垣寝殿门庑皆</span>  
<span style="margin-left: 2em">就倾圮郡守河南刘公修葺祠宇捐己俸为诸寮倡</span>  
<span style="margin-left: 2em">而华亭尹汪侯赞成之一时义士相率助金遂鸠工</span>
