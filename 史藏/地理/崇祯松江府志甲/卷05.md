## 崇祯松江府志卷之五　水

<span style="margin-left: 3em">水</span>  
<span style="margin-left: 1em">管子曰水之出于山而流入于海者曰经水入于大水</span>  
<span style="margin-left: 1em">及海者曰枝水吾郡之水上源天日下委海王相距数</span>  
<span style="margin-left: 1em">百里潆洄淜湃其间承受源水之来者为湖为泖而导</span>  
<span style="margin-left: 1em">引委水之去者为浦为江此一郡大脉络也若夫泾渠</span>  
<span style="margin-left: 1em">港渎连贯而分泄其不驶者图经所载五百九十有一</span>  
<span style="margin-left: 1em">日受两潮之灌注沮洳湮塞巨者已失故道况细流乎</span>  
<span style="margin-left: 1em">其亦名存焉尔录之以补桑经庾纪之遗</span>  
<span style="margin-left: 1em">海水江水湖水泖水浦水</span>  
<span style="margin-left: 1em">大海环府之东南春申浦与吴淞江合流跄口以归注</span>  
<span style="margin-left: 2em">焉自金山东过胜山为南洋又东至洋山又东南为</span>  
<span style="margin-left: 2em">南大洋北至高家嘴为苏州洋又东为东大洋潮水</span>  
<span style="margin-left: 2em">北入于江为淞苏州洋西入许山过独山入于江为</span>  
<span style="margin-left: 2em">浙自南大洋又南历闽广通南海自东大洋北历山</span>  
<span style="margin-left: 2em">东过辽海尝登金山南汇诸城极目所至浟湙潋滟</span>  
<span style="margin-left: 2em">浮天无际木玄虚所云波如连山乍合乍散嘘噏百</span>  
<span style="margin-left: 2em">川洗涤淮汉诚宇宙一伟观也南与绍兴宁波相望</span>  
<span style="margin-left: 2em">深夜籁寂越中鸡犬声相闻天空日霁则诸山历历</span>  
<span style="margin-left: 2em">在指顾中矣</span>  
<span style="margin-left: 2em">上海县志云海在县东七十里北起嘉定南抵华亭</span>  
<span style="margin-left: 2em">东接诸番而日本最近宋元间入贡皆繇青龙市舶</span>  
<span style="margin-left: 2em">司后渐徙于四明贡者不复取道沿海皆浅滩不逮</span>  
<span style="margin-left: 2em">闽浙百一俗号穷海独盐利为饶自清水湾以南较</span>  
<span style="margin-left: 2em">川沙以北水咸宜盐近有沙堤壅隔其外水味浸淡</span>  
<span style="margin-left: 2em">而煮海之利亦微</span>  
<span style="margin-left: 2em">论潮源　陆文裕集云闻诸乡父老言潮起于南汇</span>  
<span style="margin-left: 2em">嘴始若涌突旋分两派南派南涨入钱塘江北派北</span>  
<span style="margin-left: 2em">涨入扬<sub class="note-jiao">校：楊字當揚之訛今改</sub>子江南汇嘴者海之一曲也在</span>  
<span style="margin-left: 2em">邑东南百里而海盐志云海潮东北自金山而来西</span>  
<span style="margin-left: 2em">南至浙江名上潭自浙江回历海宁茶湾至澉浦为</span>  
<span style="margin-left: 2em">下潭金山在海中属华亭在南汇之东北又云葫芦</span>  
<span style="margin-left: 2em">山澉浦镇东南六里海上出没潮中如葫芦云澉浦</span>  
<span style="margin-left: 2em">在金山西南疑潮源也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">周繇望海诗苍茫空泛月四顾绝人烟半浸中华岸傍通异域船岛间应有国波外恐无天欲作乘槎客翻然去隔年胡俨积水澉无极归虚那可穷百川宗浩漾一气接洪蒙若木昆仑外扶桑日本东蜃楼冲雾白鲸鬣鼓波红驱石何年到乘槎有路通光分欹落月声急度长风潮汐盈虚候鱼龙变化工修鳞初击水巨翻已抟空河伯心神骇天吴气势雄重渊阴火冷孤屿晓光融方丈瑶台隐珊瑚铁网笼犀灯愁怪室鲛泪泣珠宫凫鸟深藏迹鶢鶋远散氃萧条云送晚倐忽雨飞东卤莽迷寒鹬苍烟锁断虹卢敖游汗漫徐巿绐见童蜑客舟如叶醝翁发似蓬波斯徒窅窅精卫苦匆匆玉帛沉流洁牺牲报祀豊</sub></span>  
<span style="margin-left: 1em">松江禹贡三江之一即笠泽去郡城七十四里入上海</span>  
<span style="margin-left: 2em">境旧名吴淞江以水灾去水亦名松陵江其源出太</span>  
<span style="margin-left: 2em">湖东注于海郦道元云松江自湖东北径七十里分</span>  
<span style="margin-left: 2em">流谓之三江口吴越春秋所载范蠡去越乘舟出三</span>  
<span style="margin-left: 2em">江口入五湖此也松江故道自吴江长桥东流至尹</span>  
<span style="margin-left: 2em">山北流至甫里东北流至淀山北合赵屯浦又东合</span>  
<span style="margin-left: 2em">大盈浦又东合顾会浦又东合崧子浦盘龙浦至宋</span>  
<span style="margin-left: 2em">家桥转东南流与黄浦会而入海凡三百六十里将</span>  
<span style="margin-left: 2em">入海处别名沪渎其别派自吴江分流由急水港钟</span>  
<span style="margin-left: 2em">为大湖曰薛淀范成大云松江为水国之胜当天下</span>  
<span style="margin-left: 2em">第一历代以来相继修凿我　朝自海公瑞开濬后</span>  
<span style="margin-left: 2em">潮汐易灌泈漭之区渐成平壤矣</span>  
<span style="margin-left: 2em">原三江　三江者吴淞江娄江东江也一自太湖从</span>  
<span style="margin-left: 2em">吴县鲇鱼口北入运河经郡城娄门东流入上下雉</span>  
<span style="margin-left: 2em">渎抵昆山至和塘东合新洋江经太仓塘合刘家港</span>  
<span style="margin-left: 2em">入海者为娄江一自太湖从吴江县长桥东北合庞</span>  
<span style="margin-left: 2em">山湖入长洲界过大姚浦抵昆山界分为二南为吴</span>  
<span style="margin-left: 2em">淞江北为勦娘江复合为一东流入嘉定界经上海</span>  
<span style="margin-left: 2em">合黄浦东入海者为吴淞江一自白蚬江从急水港</span>  
<span style="margin-left: 2em">过淀山湖东至华亭合上海黄浦繇黄浦经上海宋</span>  
<span style="margin-left: 2em">家港合吴淞江北入海者为东江太湖泄水川渠非</span>  
<span style="margin-left: 2em">一而三江为大三江并泄湖水而吴淞为经唐宋而</span>  
<span style="margin-left: 2em">下治水使水复焉然时湮时濬害非甚也往夏驾口</span>  
<span style="margin-left: 2em">新洋江之役并引湖水繇娄江入海稍称利便不知</span>  
<span style="margin-left: 2em">娄江之流既驶吴淞之势渐微以故诸境之水吞多</span>  
<span style="margin-left: 2em">泄少迄后岁苦稽天矣</span>
