## 崇禎松江府志卷之五　水

<span style="margin-left: 3em">水</span>  
<span style="margin-left: 1em">管子曰水之出於山而流入於海者曰經水入於大水</span>  
<span style="margin-left: 1em">及海者曰枝水吾郡之水上源天日下委海王相距數</span>  
<span style="margin-left: 1em">百里瀠洄淜湃其間承受源水之來者爲湖爲泖而導</span>  
<span style="margin-left: 1em">引委水之去者爲浦爲江此一郡大脉絡也若夫涇渠</span>  
<span style="margin-left: 1em">港瀆連貫而分洩其不駛者圖經所載五百九十有一</span>  
<span style="margin-left: 1em">日受兩潮之灌注沮洳湮塞巨者已失故道况細流乎</span>  
<span style="margin-left: 1em">其亦名存焉爾錄之以補桑經庾紀之遺</span>  
<span style="margin-left: 1em">海水江水湖水泖水浦水</span>  
<span style="margin-left: 1em">大海環府之東南春申浦與吳淞江合流蹌口以歸注</span>  
<span style="margin-left: 2em">焉自金山東過勝山爲南洋又東至洋山又東南爲</span>  
<span style="margin-left: 2em">南大洋北至高家嘴爲蘇州洋又東爲東大洋潮水</span>  
<span style="margin-left: 2em">北入於江爲淞蘇州洋西入許山過獨山入於江爲</span>  
<span style="margin-left: 2em">浙自南大洋又南歷閩廣通南海自東大洋北歷山</span>  
<span style="margin-left: 2em">東過遼海嘗登金山南滙諸城極目所至浟湙瀲灧</span>  
<span style="margin-left: 2em">浮天無際木玄虛所云波如連山乍合乍散嘘噏百</span>  
<span style="margin-left: 2em">川洗滌淮漢誠宇宙一偉觀也南與紹興寧波相望</span>  
<span style="margin-left: 2em">深夜籟寂越中雞犬聲相聞天空日霽則諸山歷歷</span>  
<span style="margin-left: 2em">在指顧中矣</span>  
<span style="margin-left: 2em">上海縣志云海在縣東七十里北起嘉定南抵華亭</span>  
<span style="margin-left: 2em">東接諸番而日本最近宋元間入貢皆繇青龍市舶</span>  
<span style="margin-left: 2em">司後漸徙於四明貢者不復取道沿海皆淺灘不逮</span>  
<span style="margin-left: 2em">閩浙百一俗號窮海獨鹽利爲饒自清水灣以南較</span>  
<span style="margin-left: 2em">川沙以北水鹹宜鹽近有沙堤壅隔其外水味浸淡</span>  
<span style="margin-left: 2em">而煮海之利亦微</span>  
<span style="margin-left: 2em">論潮源　陸文裕集云聞諸鄉父老言潮起於南滙</span>  
<span style="margin-left: 2em">嘴始若湧突旋分兩派南派南漲入錢塘江北派北</span>  
<span style="margin-left: 2em">漲入揚<sub class="note-jiao">校：楊字當揚之訛今改</sub>子江南滙嘴者海之一曲也在</span>  
<span style="margin-left: 2em">邑東南百里而海鹽志云海潮東北自金山而來西</span>  
<span style="margin-left: 2em">南至浙江名上潭自浙江回歷海寧茶灣至澉浦爲</span>  
<span style="margin-left: 2em">下潭金山在海中屬華亭在南滙之東北又云葫蘆</span>  
<span style="margin-left: 2em">山澉浦鎮東南六里海上出没潮中如葫蘆云澉浦</span>  
<span style="margin-left: 2em">在金山西南疑潮源也</span>  
<span style="margin-left: 2em"><sub class="note-yuan">周繇望海詩蒼茫空泛月四顧絕人煙半浸中華岸傍通異域船島間應有國波外恐無天欲作乘槎客翻然去隔年胡儼積水澉無極歸虛那可窮百川宗浩漾一氣接洪濛若木崑崙外扶桑日本東蜃樓衝霧白鯨鬣鼓波紅驅石何年到乘槎有路通光分欹落月聲急度長風潮汐盈虛候魚龍變化工修鱗初擊水巨翻已摶空河伯心神駭天吳氣勢雄重淵陰火冷孤嶼曉光融方丈瑶臺隱珊瑚鐵網籠犀燈愁怪室鮫淚泣珠宫鳬鳥深藏跡鶢鶋遠散氃蕭條雲送晚倐忽雨飛東鹵莽迷寒鷸蒼煙鎖斷虹盧敖遊汗漫徐巿紿見童蜑客舟如葉醝翁髮似蓬波斯徒窅窅精衛苦匆匆玉帛沉流潔犧牲報祀豊</sub></span>  
<span style="margin-left: 1em">松江禹貢三江之一即笠澤去郡城七十四里入上海</span>  
<span style="margin-left: 2em">境舊名吳淞江以水災去水亦名松陵江其源出太</span>  
<span style="margin-left: 2em">湖東注於海酈道元云松江自湖東北逕七十里分</span>  
<span style="margin-left: 2em">流謂之三江口吳越春秋所載范蠡去越乘舟出三</span>  
<span style="margin-left: 2em">江口入五湖此也松江故道自吳江長橋東流至尹</span>  
<span style="margin-left: 2em">山北流至甫里東北流至澱山北合趙屯浦又東合</span>  
<span style="margin-left: 2em">大盈浦又東合顧會浦又東合崧子浦盤龍浦至宋</span>  
<span style="margin-left: 2em">家橋轉東南流與黃浦會而入海凡三百六十里將</span>  
<span style="margin-left: 2em">入海處別名滬瀆其別派自吳江分流由急水港鍾</span>  
<span style="margin-left: 2em">爲大湖曰薛澱范成大云松江爲水國之勝當天下</span>  
<span style="margin-left: 2em">第一歷代以來相繼修鑿我　朝自海公瑞開濬後</span>  
<span style="margin-left: 2em">潮汐易灌泈漭之區漸成平壤矣</span>  
<span style="margin-left: 2em">原三江　三江者吳淞江婁江東江也一自太湖從</span>  
<span style="margin-left: 2em">吳縣鮎魚口北入運河經郡城婁門東流入上下雉</span>  
<span style="margin-left: 2em">瀆抵崑山至和塘東合新洋江經太倉塘合劉家港</span>  
<span style="margin-left: 2em">入海者爲婁江一自太湖從吳江縣長橋東北合龐</span>  
<span style="margin-left: 2em">山湖入長洲界過大姚浦抵崑山界分爲二南爲吳</span>  
<span style="margin-left: 2em">淞江北爲勦娘江復合爲一東流入嘉定界經上海</span>  
<span style="margin-left: 2em">合黃浦東入海者爲吳淞江一自白蜆江從急水港</span>  
<span style="margin-left: 2em">過澱山湖東至華亭合上海黃浦繇黃浦經上海宋</span>  
<span style="margin-left: 2em">家港合吳淞江北入海者爲東江太湖洩水川渠非</span>  
<span style="margin-left: 2em">一而三江爲大三江並洩湖水而吳淞爲經唐宋而</span>  
<span style="margin-left: 2em">下治水使水復焉然時湮時濬害非甚也往夏駕口</span>  
<span style="margin-left: 2em">新洋江之役并引湖水繇婁江入海稍稱利便不知</span>  
<span style="margin-left: 2em">婁江之流既駛吳淞之勢漸微以故諸境之水吞多</span>  
<span style="margin-left: 2em">洩少迄後歲苦稽天矣</span>
