## 崇禎松江府志卷之二　沿革　分野　形勝　區界　鄉村　戶口

<span style="margin-left: 3em">沿革</span>  
<span style="margin-left: 1em">志不可狹窳也吾松歷禩綿邈分合靡常初曰婁繫婁</span>  
<span style="margin-left: 1em">者則書已更吳郡繫吳郡者則書已更崑山繫崑山者</span>  
<span style="margin-left: 1em">則書已更海鹽嘉興繫海鹽嘉興者則書若僅考松江</span>  
<span style="margin-left: 1em">之故實而舍此不復網羅焉得無有放失於史册見聞</span>  
<span style="margin-left: 1em">之外者乎俞彦直曲引旁搜首拈沿革爲第一義沿革</span>  
<span style="margin-left: 1em">分明則綜叙山川採掇人物或前畧而後詳或今無而</span>  
<span style="margin-left: 1em">古有確見案據非假借而攙入之也此志之權輿也</span>  
<span style="margin-left: 1em">松江古揚州域帝顓頊區天下爲九州自江以南至於</span>  
<span style="margin-left: 1em">海曰揚州唐虞三代因之禹貢在要荒之服</span>  
<span style="margin-left: 2em">松江三江之一水名也未建邦時濱江阻海多水患</span>  
<span style="margin-left: 2em">吳越春秋所謂蛟龍雜處</span>  
<span style="margin-left: 2em">閲古編曰書云濬畝澮距川惟荒度土功弼成五服</span>  
<span style="margin-left: 2em">至於五千州十有二師外薄四海咸建五長各迪有</span>  
<span style="margin-left: 2em">功吾松薄海之區虞夏時五長治之聲教暨焉今在</span>  
<span style="margin-left: 2em">南畿千里之內是侯服地也漢武帝策廣陵王曰大</span>  
<span style="margin-left: 2em">江之南五湖之間其人心輕揚三代不及以政夫禹</span>  
<span style="margin-left: 2em">時會諸侯於塗山執玉帛者萬國其書曰震澤底定</span>  
<span style="margin-left: 2em">厥賦下上錯政孰大於朝覲會同則壤成賦者哉則</span>  
<span style="margin-left: 2em">夏之時固已底定及之矣</span>  
<span style="margin-left: 1em">周泰伯仲雍托採藥而逃荆蠻自號勾吳武王封其孫</span>  
<span style="margin-left: 1em">周章國於吳松江爲吳地</span>  
<span style="margin-left: 2em">史記索隱曰荆者楚之舊號則殷末亦爲荆地吳都</span>  
<span style="margin-left: 2em">賦云至德以創洪業克讓以立風俗故潘尼贈陸機</span>  
<span style="margin-left: 2em">詩曰東南之美曩惟延州又農田餘話云吳自壽夢</span>  
<span style="margin-left: 2em">益昌大始築華亭爲停留宿會之所華亭之名著於</span>  
<span style="margin-left: 2em">斯矣</span>  
<span style="margin-left: 1em">周元王三年越入吳滅之地屬越</span>  
<span style="margin-left: 2em">國語曰勾踐之地北至禦兒禦兒檇李也吳越春秋</span>  
<span style="margin-left: 2em">勾踐五年入臣於吳群臣祖道浙江是浙以西皆入</span>  
<span style="margin-left: 2em">吳境七年厚遺返國夫差悦之賜書增封禦兒復爲</span>  
<span style="margin-left: 2em">越之北鄙吳地記云嘉興縣一百里有語兒亭馮時</span>  
<span style="margin-left: 2em">可云語兒亭在華亭去檇李百里蓋華亭原屬嘉興</span>  
<span style="margin-left: 2em">禦兒之改語兒音之訛耳地之屬越在滅吳後無疑</span>  
<span style="margin-left: 1em">顯王三十五年楚伐越大敗其王無疆盡取其地又屬</span>  
<span style="margin-left: 1em">楚</span>  
<span style="margin-left: 2em">楚滅越封春申君於故吳城鑿浦以消松江水患治</span>  
<span style="margin-left: 2em">水有功是爲春申浦</span>  
<span style="margin-left: 1em">秦併天下罷列侯置會稽郡即今之蘇州領縣二十四</span>  
<span style="margin-left: 1em">松江爲婁縣地</span>  
<span style="margin-left: 2em">郡縣非始於秦周敬王時先置長水縣矣然秦以前</span>  
<span style="margin-left: 2em">縣大於郡晉趙鞅與鄭戰誓衆曰克敵者上大夫受</span>  
<span style="margin-left: 2em">縣下大夫受郡士田十萬又周書作雒篇千里百縣</span>  
<span style="margin-left: 2em">縣有四郡以郡領縣自秦始</span>  
<span style="margin-left: 2em">漢書註云婁有南武城闔閭起以備越莽曰婁治今</span>  
<span style="margin-left: 2em">滬瀆壘東有闔閭城又劉孝標世說註曰華亭吳由</span>  
<span style="margin-left: 2em">拳縣郊外墅也有清泉茂林陸機兄弟共遊於此干</span>  
<span style="margin-left: 2em">寶搜神記云始皇東巡長水望有天子氣令囚徒十</span>  
<span style="margin-left: 2em">萬人掘污其地更名由拳由拳囚倦也然越絶書載</span>  
<span style="margin-left: 2em">由拳塞爲吳備侯之塞其名已在始皇前始皇時長</span>  
<span style="margin-left: 2em">水縣有童謡云城門有血當陷没有老嫗旦旦往窺</span>  
<span style="margin-left: 2em">門者故以狗血塗門水忽至因陷爲谷目爲谷水方</span>  
<span style="margin-left: 2em">輿勝覽曰谷水出吳小湖經由拳故城下則知谷水</span>  
<span style="margin-left: 2em">長水即由拳縣今以嘉禾爲由拳後之徙治耳</span>  
<span style="margin-left: 1em">漢高帝封從兄賈爲荆王更會稽郡爲荆國婁又荆之</span>  
<span style="margin-left: 1em">屬也後以封兄子濞國號吳國除改爲郡</span>  
<span style="margin-left: 2em">孫亮時會稽太守濮陽興問山陰朱育曰漢封諸侯</span>  
<span style="margin-left: 2em">王以何年復爲郡而分治於此育曰劉賈爲荆王賈</span>  
<span style="margin-left: 2em">爲英布所殺又以劉濞爲吳王景帝四年濞反誅乃</span>  
<span style="margin-left: 2em">復爲郡治於吳元鼎五年除東越因以其地爲治并</span>  
<span style="margin-left: 2em">屬於此而立東部都尉</span>  
<span style="margin-left: 1em">順帝永建四年分浙以東爲會稽郡還治山陰浙以西</span>  
<span style="margin-left: 1em">爲吳郡領縣十三婁隸焉</span>  
<span style="margin-left: 2em">山陰人殷重獻策於帝請分江置兩浙詔司空王襲</span>  
<span style="margin-left: 2em">封從錢唐江中向東爲會稽郡向西爲吳郡</span>  
<span style="margin-left: 2em">建安七年孫權表朱治爲九真太守尋封毘陵侯割</span>  
<span style="margin-left: 2em">婁縣由拳無錫毘陵爲奉邑</span>  
<span style="margin-left: 1em">孫皓時分吳郡爲吳興郡晉太康二年又分置毘陵郡</span>  
<span style="margin-left: 1em">東晉改爲吳國置內史宋永初二年仍爲吳郡雖封境</span>  
<span style="margin-left: 1em">名號屢更而婁隸吳如故</span>  
<span style="margin-left: 2em">蘇峻之亂虞潭修滬瀆以防海寇袁崧復增築以備</span>  
<span style="margin-left: 2em">孫恩皆以內史行太守事滬瀆壘在松江郡東北一</span>  
<span style="margin-left: 2em">百十里</span>  
<span style="margin-left: 1em">梁天監六年廢婁縣置信義郡太清三年改吳郡爲吳</span>  
<span style="margin-left: 1em">州又析海鹽縣東北境置前京縣尋廢隋開皇九年罷</span>  
<span style="margin-left: 1em">吳州改吳郡爲蘇州并罷信義而以前京入常熟隸揚</span>  
<span style="margin-left: 1em">州十八年復置崑山縣隸蘇州</span>  
<span style="margin-left: 2em">嘉禾志云信義郡在今華亭之崑山太清二年陷於</span>  
<span style="margin-left: 2em">侯景前京在華亭縣東八十里地近京浦故名其地</span>  
<span style="margin-left: 2em">尚有前京舊城元郡人許尚詩云廬落皆無有依稀</span>  
<span style="margin-left: 2em">古堞存登臨認遺跡林莽暮烟昏陳書以前京屬吳</span>  
<span style="margin-left: 2em">郡隋志則云信義郡所領又梁時有胥浦縣今名胥</span>  
<span style="margin-left: 2em">浦鄉者在華亭西南其地有壇步平江花緒等名侯</span>  
<span style="margin-left: 2em">景嘗以前京並海鹽立武原郡事見梁書大抵土境</span>  
<span style="margin-left: 2em">屢分名號驟易地里之參差未易晰也</span>  
<span style="margin-left: 2em">元陳基曰崑山古婁地今隸華亭機雲故宅在焉士</span>  
<span style="margin-left: 2em">衡詩云婉孌崑山陰髣彿谷水陽縣以此名蓋以人</span>  
<span style="margin-left: 2em">勝也又崑山志云相傳縣治古孟尚書舍地不知何</span>  
<span style="margin-left: 2em">代人郡志無考意者梁隋之間故治在華亭孟公之</span>  
<span style="margin-left: 2em">舍宅疑在是矣恐非今日之縣治後人因襲而祀之</span>  
<span style="margin-left: 2em">耳</span>  
<span style="margin-left: 1em">唐天寶十載蘇州守臣趙居貞奏割崑山南境嘉興東</span>  
<span style="margin-left: 1em">境海鹽北境立華亭縣移崑山縣治於馬鞍山治各兼</span>  
<span style="margin-left: 1em">設而土不相統華亭自爲縣始此</span>  
<span style="margin-left: 2em">唐陸廣微吳地記云華亭縣在郡東一百六十里地</span>  
<span style="margin-left: 2em">名雲間水名谷水天寶五年置蓋晉元假陸遜宅造</span>  
<span style="margin-left: 2em">池亭華麗故名有陸遜陸機陸瑁三墳在東南二十</span>  
<span style="margin-left: 2em">五里横山中有鶴鳴鶴唳玄鶴管鄉二十二户一萬</span>  
<span style="margin-left: 2em">二千七百八十</span>  
<span style="margin-left: 2em">古海鹽縣治在華亭鄉山名槖山林名槖林陷爲湖</span>  
<span style="margin-left: 2em">名槖湖初陷時有女子入湖名三姑神其跡甚異後</span>  
<span style="margin-left: 2em">遷武原鄉復陷爲當湖今平湖尚存華亭鄉係海鹽</span>  
<span style="margin-left: 2em">分隸則居貞所割祗還華亭故地而猶未盡也姑蘇</span>  
<span style="margin-left: 2em">志又云長洲亦割地入華亭</span>  
<span style="margin-left: 1em">黃巢亂僖宗幸蜀海寇王騰據華亭吳越王錢鏐遣顧</span>  
<span style="margin-left: 1em">全斌拔華亭遂取蘇杭奄有兩浙陞蘇州爲中吳而於</span>  
<span style="margin-left: 1em">嘉興置開元府以華亭屬之</span>  
<span style="margin-left: 2em">唐國寶傳王騰據華亭寶練卒自守發杭州兵戍縣</span>  
<span style="margin-left: 2em">鎮乾寧四年丁巳錢鏐遣顧全斌乙未拔松江辛丑</span>  
<span style="margin-left: 2em">拔華亭又吳越備史云先是嘉興海鹽華亭舊有鎮</span>  
<span style="margin-left: 2em">將至是盡有兩浙封吳越王於嘉興之西境義和華</span>  
<span style="margin-left: 2em">亭之南境金山北境之上海青龍海鹽之東境乍浦</span>  
<span style="margin-left: 2em">西境澉浦皆置鎮遏使以是土之豪傑世領之</span>  
<span style="margin-left: 1em">元瓘奉藩於唐後罷開元府華亭復屬中吳後晉天福</span>  
<span style="margin-left: 1em">三年又以嘉興爲秀州華亭屬焉自是不復隸蘇矣</span>  
<span style="margin-left: 2em">捫蘿筆記云中吳節度使錢元璙病支郡多闕而古</span>  
<span style="margin-left: 2em">藩强大始經邑爲州奏嘉興爲秀州絶其華亭海鹽</span>  
<span style="margin-left: 2em">二同地附於州即以屬焉五代時浙西賴錢氏保障</span>  
<span style="margin-left: 2em">民無失業境無棄田嘗置營田數千人於松江闢土</span>  
<span style="margin-left: 2em">而耕又沈氏手鏡云後晉始置秀州以錢元弼爲刺</span>  
<span style="margin-left: 2em">史經營新治屬邑沾其惠愛錢亦鏐之裔也</span>  
<span style="margin-left: 1em">宋太宗興國三年錢氏納土分天下州軍爲十五路時</span>  
<span style="margin-left: 1em">秀州屬浙西路徽宗政和七年改秀州爲嘉禾郡宣和</span>  
<span style="margin-left: 1em">復改爲州寧宗慶元元年本秀州陞嘉興爲府領華亭</span>  
<span style="margin-left: 1em">縣</span>  
<span style="margin-left: 2em">嘉禾志云以是郡爲孝宗毓聖之地陞爲府</span>  
<span style="margin-left: 1em">元至元十四年陞嘉興府爲路置華亭府屬焉</span>  
<span style="margin-left: 2em">宋幼主德祐二年寔元世祖至元十三年也兵下江</span>  
<span style="margin-left: 2em">南嘉興守劉漢傑以城降改嘉興爲安撫司因以劉</span>  
<span style="margin-left: 2em">漢傑爲安撫使仍主鎮守嘉興路達魯花赤管軍上</span>  
<span style="margin-left: 2em">萬户府設兩翼華亭海鹽皆有之上海青龍澉浦皆</span>  
<span style="margin-left: 2em">置鎮遏達魯花赤管軍中萬户府十四年陞嘉興爲</span>  
<span style="margin-left: 2em">路達魯花赤總管府於華亭置華亭府改兵馬司曰</span>  
<span style="margin-left: 2em">錄事司於是本路領府一曰華亭領縣三曰嘉興海</span>  
<span style="margin-left: 2em">鹽崇德</span>  
<span style="margin-left: 1em">十五年改華亭縣爲松江府仍屬嘉興路</span>  
<span style="margin-left: 2em">農田餘話云松江故華亭一縣也宋理宗朝户九萬</span>  
<span style="margin-left: 2em">七千七百有奇元初户版十七萬時江南六府二十</span>  
<span style="margin-left: 2em">萬升爲上路總管府十五萬爲下路府尹秩三品隊</span>  
<span style="margin-left: 2em">使有令字旗藤杖木劍之屬華亭以一邑遂陞爲散</span>  
<span style="margin-left: 2em">府秩四品天朝以錢糧百萬故與蘇嘉大郡同秩</span>  
<span style="margin-left: 1em">至元二十九年割華亭五鄉立上海縣泰定三年罷府</span>  
<span style="margin-left: 1em">以兩縣屬嘉興路立都水庸田司於府治天曆元年罷</span>  
<span style="margin-left: 1em">司復爲府</span>  
<span style="margin-left: 2em">上海故稱華亭海宋末海舶輻輳即其地立市舶提</span>  
<span style="margin-left: 2em">舉司及榷貨塲爲上海鎮從知府僕散翰文議割華</span>  
<span style="margin-left: 2em">亭五鄉置上海縣居海之上洋亦稱上洋誠海道之</span>  
<span style="margin-left: 2em">咽喉也又郟亶水議有上海下海二浦縣之得名以</span>  
<span style="margin-left: 2em">此</span>  
<span style="margin-left: 1em">元末爲張士誠所據</span>  
<span style="margin-left: 1em">國朝遣左丞相徐達討平之知府王立中以府歸附是</span>  
<span style="margin-left: 1em">爲吳元年</span>  
<span style="margin-left: 2em">張士誠據浙西五郡發松嘉湖杭民夫築杭州及松</span>  
<span style="margin-left: 2em">江府松江入　國朝在士誠平後陸子淵以爲在龍</span>  
<span style="margin-left: 2em">鳳年非也</span>  
<span style="margin-left: 1em">洪武改元以松江隸南京巍然自成一雄藩矣嘉靖二</span>  
<span style="margin-left: 1em">十二年復割華亭上海建青浦縣於故青龍鎮次年隨</span>  
<span style="margin-left: 1em">廢萬曆元年用科臣蔡汝賢議復移治唐行鎮</span>  
<span style="margin-left: 2em">松事叢說云青龍自唐宋以來爲東南重鎮宋設水</span>
