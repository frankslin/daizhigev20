## 崇祯松江府志卷之二　沿革　分野　形胜　区界　乡村　户口

<span style="margin-left: 3em">沿革</span>  
<span style="margin-left: 1em">志不可狭窳也吾松历禩绵邈分合靡常初曰娄系娄</span>  
<span style="margin-left: 1em">者则书已更吴郡系吴郡者则书已更昆山系昆山者</span>  
<span style="margin-left: 1em">则书已更海盐嘉兴系海盐嘉兴者则书若仅考松江</span>  
<span style="margin-left: 1em">之故实而舍此不复网罗焉得无有放失于史册见闻</span>  
<span style="margin-left: 1em">之外者乎俞彦直曲引旁搜首拈沿革为第一义沿革</span>  
<span style="margin-left: 1em">分明则综叙山川采掇人物或前畧而后详或今无而</span>  
<span style="margin-left: 1em">古有确见案据非假借而搀入之也此志之权舆也</span>  
<span style="margin-left: 1em">松江古扬州域帝颛顼区天下为九州自江以南至于</span>  
<span style="margin-left: 1em">海曰扬州唐虞三代因之禹贡在要荒之服</span>  
<span style="margin-left: 2em">松江三江之一水名也未建邦时滨江阻海多水患</span>  
<span style="margin-left: 2em">吴越春秋所谓蛟龙杂处</span>  
<span style="margin-left: 2em">阅古编曰书云濬亩浍距川惟荒度土功弼成五服</span>  
<span style="margin-left: 2em">至于五千州十有二师外薄四海咸建五长各迪有</span>  
<span style="margin-left: 2em">功吾松薄海之区虞夏时五长治之声教暨焉今在</span>  
<span style="margin-left: 2em">南畿千里之内是侯服地也汉武帝策广陵王曰大</span>  
<span style="margin-left: 2em">江之南五湖之间其人心轻扬三代不及以政夫禹</span>  
<span style="margin-left: 2em">时会诸侯于涂山执玉帛者万国其书曰震泽底定</span>  
<span style="margin-left: 2em">厥赋下上错政孰大于朝觐会同则壤成赋者哉则</span>  
<span style="margin-left: 2em">夏之时固已底定及之矣</span>  
<span style="margin-left: 1em">周泰伯仲雍托采药而逃荆蛮自号勾吴武王封其孙</span>  
<span style="margin-left: 1em">周章国于吴松江为吴地</span>  
<span style="margin-left: 2em">史记索隐曰荆者楚之旧号则殷末亦为荆地吴都</span>  
<span style="margin-left: 2em">赋云至德以创洪业克让以立风俗故潘尼赠陆机</span>  
<span style="margin-left: 2em">诗曰东南之美曩惟延州又农田余话云吴自寿梦</span>  
<span style="margin-left: 2em">益昌大始筑华亭为停留宿会之所华亭之名著于</span>  
<span style="margin-left: 2em">斯矣</span>  
<span style="margin-left: 1em">周元王三年越入吴灭之地属越</span>  
<span style="margin-left: 2em">国语曰勾践之地北至御儿御儿檇李也吴越春秋</span>  
<span style="margin-left: 2em">勾践五年入臣于吴群臣祖道浙江是浙以西皆入</span>  
<span style="margin-left: 2em">吴境七年厚遗返国夫差悦之赐书增封御儿复为</span>  
<span style="margin-left: 2em">越之北鄙吴地记云嘉兴县一百里有语儿亭冯时</span>  
<span style="margin-left: 2em">可云语儿亭在华亭去檇李百里盖华亭原属嘉兴</span>  
<span style="margin-left: 2em">御儿之改语儿音之讹耳地之属越在灭吴后无疑</span>  
<span style="margin-left: 1em">显王三十五年楚伐越大败其王无疆尽取其地又属</span>  
<span style="margin-left: 1em">楚</span>  
<span style="margin-left: 2em">楚灭越封春申君于故吴城凿浦以消松江水患治</span>  
<span style="margin-left: 2em">水有功是为春申浦</span>  
<span style="margin-left: 1em">秦并天下罢列侯置会稽郡即今之苏州领县二十四</span>  
<span style="margin-left: 1em">松江为娄县地</span>  
<span style="margin-left: 2em">郡县非始于秦周敬王时先置长水县矣然秦以前</span>  
<span style="margin-left: 2em">县大于郡晋赵鞅与郑战誓众曰克敌者上大夫受</span>  
<span style="margin-left: 2em">县下大夫受郡士田十万又周书作雒篇千里百县</span>  
<span style="margin-left: 2em">县有四郡以郡领县自秦始</span>  
<span style="margin-left: 2em">汉书注云娄有南武城阖闾起以备越莽曰娄治今</span>  
<span style="margin-left: 2em">沪渎垒东有阖闾城又刘孝标世说注曰华亭吴由</span>  
<span style="margin-left: 2em">拳县郊外墅也有清泉茂林陆机兄弟共游于此干</span>  
<span style="margin-left: 2em">宝搜神记云始皇东巡长水望有天子气令囚徒十</span>  
<span style="margin-left: 2em">万人掘污其地更名由拳由拳囚倦也然越绝书载</span>  
<span style="margin-left: 2em">由拳塞为吴备侯之塞其名已在始皇前始皇时长</span>  
<span style="margin-left: 2em">水县有童谣云城门有血当陷没有老妪旦旦往窥</span>  
<span style="margin-left: 2em">门者故以狗血涂门水忽至因陷为谷目为谷水方</span>  
<span style="margin-left: 2em">舆胜览曰谷水出吴小湖经由拳故城下则知谷水</span>  
<span style="margin-left: 2em">长水即由拳县今以嘉禾为由拳后之徙治耳</span>  
<span style="margin-left: 1em">汉高帝封从兄贾为荆王更会稽郡为荆国娄又荆之</span>  
<span style="margin-left: 1em">属也后以封兄子濞国号吴国除改为郡</span>  
<span style="margin-left: 2em">孙亮时会稽太守濮阳兴问山阴朱育曰汉封诸侯</span>  
<span style="margin-left: 2em">王以何年复为郡而分治于此育曰刘贾为荆王贾</span>  
<span style="margin-left: 2em">为英布所杀又以刘濞为吴王景帝四年濞反诛乃</span>  
<span style="margin-left: 2em">复为郡治于吴元鼎五年除东越因以其地为治并</span>  
<span style="margin-left: 2em">属于此而立东部都尉</span>  
<span style="margin-left: 1em">顺帝永建四年分浙以东为会稽郡还治山阴浙以西</span>  
<span style="margin-left: 1em">为吴郡领县十三娄隶焉</span>  
<span style="margin-left: 2em">山阴人殷重献策于帝请分江置两浙诏司空王袭</span>  
<span style="margin-left: 2em">封从钱唐江中向东为会稽郡向西为吴郡</span>  
<span style="margin-left: 2em">建安七年孙权表朱治为九真太守寻封毘陵侯割</span>  
<span style="margin-left: 2em">娄县由拳无锡毘陵为奉邑</span>  
<span style="margin-left: 1em">孙皓时分吴郡为吴兴郡晋太康二年又分置毘陵郡</span>  
<span style="margin-left: 1em">东晋改为吴国置内史宋永初二年仍为吴郡虽封境</span>  
<span style="margin-left: 1em">名号屡更而娄隶吴如故</span>  
<span style="margin-left: 2em">苏峻之乱虞潭修沪渎以防海寇袁崧复增筑以备</span>  
<span style="margin-left: 2em">孙恩皆以内史行太守事沪渎垒在松江郡东北一</span>  
<span style="margin-left: 2em">百十里</span>  
<span style="margin-left: 1em">梁天监六年废娄县置信义郡太清三年改吴郡为吴</span>  
<span style="margin-left: 1em">州又析海盐县东北境置前京县寻废隋开皇九年罢</span>  
<span style="margin-left: 1em">吴州改吴郡为苏州并罢信义而以前京入常熟隶扬</span>  
<span style="margin-left: 1em">州十八年复置昆山县隶苏州</span>  
<span style="margin-left: 2em">嘉禾志云信义郡在今华亭之昆山太清二年陷于</span>  
<span style="margin-left: 2em">侯景前京在华亭县东八十里地近京浦故名其地</span>  
<span style="margin-left: 2em">尚有前京旧城元郡人许尚诗云庐落皆无有依稀</span>  
<span style="margin-left: 2em">古堞存登临认遗迹林莽暮烟昏陈书以前京属吴</span>  
<span style="margin-left: 2em">郡隋志则云信义郡所领又梁时有胥浦县今名胥</span>  
<span style="margin-left: 2em">浦乡者在华亭西南其地有坛步平江花绪等名侯</span>  
<span style="margin-left: 2em">景尝以前京并海盐立武原郡事见梁书大抵土境</span>  
<span style="margin-left: 2em">屡分名号骤易地里之参差未易晰也</span>  
<span style="margin-left: 2em">元陈基曰昆山古娄地今隶华亭机云故宅在焉士</span>  
<span style="margin-left: 2em">衡诗云婉娈昆山阴髣佛谷水阳县以此名盖以人</span>  
<span style="margin-left: 2em">胜也又昆山志云相传县治古孟尚书舍地不知何</span>  
<span style="margin-left: 2em">代人郡志无考意者梁隋之间故治在华亭孟公之</span>  
<span style="margin-left: 2em">舍宅疑在是矣恐非今日之县治后人因袭而祀之</span>  
<span style="margin-left: 2em">耳</span>  
<span style="margin-left: 1em">唐天宝十载苏州守臣赵居贞奏割昆山南境嘉兴东</span>  
<span style="margin-left: 1em">境海盐北境立华亭县移昆山县治于马鞍山治各兼</span>  
<span style="margin-left: 1em">设而土不相统华亭自为县始此</span>  
<span style="margin-left: 2em">唐陆广微吴地记云华亭县在郡东一百六十里地</span>  
<span style="margin-left: 2em">名云间水名谷水天宝五年置盖晋元假陆逊宅造</span>  
<span style="margin-left: 2em">池亭华丽故名有陆逊陆机陆瑁三坟在东南二十</span>  
<span style="margin-left: 2em">五里横山中有鹤鸣鹤唳玄鹤管乡二十二户一万</span>  
<span style="margin-left: 2em">二千七百八十</span>  
<span style="margin-left: 2em">古海盐县治在华亭乡山名槖山林名槖林陷为湖</span>  
<span style="margin-left: 2em">名槖湖初陷时有女子入湖名三姑神其迹甚异后</span>  
<span style="margin-left: 2em">迁武原乡复陷为当湖今平湖尚存华亭乡系海盐</span>  
<span style="margin-left: 2em">分隶则居贞所割祗还华亭故地而犹未尽也姑苏</span>  
<span style="margin-left: 2em">志又云长洲亦割地入华亭</span>  
<span style="margin-left: 1em">黄巢乱僖宗幸蜀海寇王腾据华亭吴越王钱镠遣顾</span>  
<span style="margin-left: 1em">全斌拔华亭遂取苏杭奄有两浙升苏州为中吴而于</span>  
<span style="margin-left: 1em">嘉兴置开元府以华亭属之</span>  
<span style="margin-left: 2em">唐国宝传王腾据华亭宝练卒自守发杭州兵戍县</span>  
<span style="margin-left: 2em">镇乾宁四年丁巳钱镠遣顾全斌乙未拔松江辛丑</span>  
<span style="margin-left: 2em">拔华亭又吴越备史云先是嘉兴海盐华亭旧有镇</span>  
<span style="margin-left: 2em">将至是尽有两浙封吴越王于嘉兴之西境义和华</span>  
<span style="margin-left: 2em">亭之南境金山北境之上海青龙海盐之东境乍浦</span>  
<span style="margin-left: 2em">西境澉浦皆置镇遏使以是土之豪杰世领之</span>  
<span style="margin-left: 1em">元瓘奉藩于唐后罢开元府华亭复属中吴后晋天福</span>  
<span style="margin-left: 1em">三年又以嘉兴为秀州华亭属焉自是不复隶苏矣</span>  
<span style="margin-left: 2em">扪萝笔记云中吴节度使钱元璙病支郡多阙而古</span>  
<span style="margin-left: 2em">藩强大始经邑为州奏嘉兴为秀州绝其华亭海盐</span>  
<span style="margin-left: 2em">二同地附于州即以属焉五代时浙西赖钱氏保障</span>  
<span style="margin-left: 2em">民无失业境无弃田尝置营田数千人于松江辟土</span>  
<span style="margin-left: 2em">而耕又沈氏手镜云后晋始置秀州以钱元弼为刺</span>  
<span style="margin-left: 2em">史经营新治属邑沾其惠爱钱亦镠之裔也</span>  
<span style="margin-left: 1em">宋太宗兴国三年钱氏纳土分天下州军为十五路时</span>  
<span style="margin-left: 1em">秀州属浙西路徽宗政和七年改秀州为嘉禾郡宣和</span>  
<span style="margin-left: 1em">复改为州宁宗庆元元年本秀州升嘉兴为府领华亭</span>  
<span style="margin-left: 1em">县</span>  
<span style="margin-left: 2em">嘉禾志云以是郡为孝宗毓圣之地升为府</span>  
<span style="margin-left: 1em">元至元十四年升嘉兴府为路置华亭府属焉</span>  
<span style="margin-left: 2em">宋幼主德祐二年寔元世祖至元十三年也兵下江</span>  
<span style="margin-left: 2em">南嘉兴守刘汉杰以城降改嘉兴为安抚司因以刘</span>  
<span style="margin-left: 2em">汉杰为安抚使仍主镇守嘉兴路达鲁花赤管军上</span>  
<span style="margin-left: 2em">万户府设两翼华亭海盐皆有之上海青龙澉浦皆</span>  
<span style="margin-left: 2em">置镇遏达鲁花赤管军中万户府十四年升嘉兴为</span>  
<span style="margin-left: 2em">路达鲁花赤总管府于华亭置华亭府改兵马司曰</span>  
<span style="margin-left: 2em">录事司于是本路领府一曰华亭领县三曰嘉兴海</span>  
<span style="margin-left: 2em">盐崇德</span>  
<span style="margin-left: 1em">十五年改华亭县为松江府仍属嘉兴路</span>  
<span style="margin-left: 2em">农田余话云松江故华亭一县也宋理宗朝户九万</span>  
<span style="margin-left: 2em">七千七百有奇元初户版十七万时江南六府二十</span>  
<span style="margin-left: 2em">万升为上路总管府十五万为下路府尹秩三品队</span>  
<span style="margin-left: 2em">使有令字旗藤杖木剑之属华亭以一邑遂升为散</span>  
<span style="margin-left: 2em">府秩四品天朝以钱粮百万故与苏嘉大郡同秩</span>  
<span style="margin-left: 1em">至元二十九年割华亭五乡立上海县泰定三年罢府</span>  
<span style="margin-left: 1em">以两县属嘉兴路立都水庸田司于府治天历元年罢</span>  
<span style="margin-left: 1em">司复为府</span>  
<span style="margin-left: 2em">上海故称华亭海宋末海舶辐辏即其地立市舶提</span>  
<span style="margin-left: 2em">举司及榷货塲为上海镇从知府仆散翰文议割华</span>  
<span style="margin-left: 2em">亭五乡置上海县居海之上洋亦称上洋诚海道之</span>  
<span style="margin-left: 2em">咽喉也又郏亶水议有上海下海二浦县之得名以</span>  
<span style="margin-left: 2em">此</span>  
<span style="margin-left: 1em">元末为张士诚所据</span>  
<span style="margin-left: 1em">国朝遣左丞相徐达讨平之知府王立中以府归附是</span>  
<span style="margin-left: 1em">为吴元年</span>  
<span style="margin-left: 2em">张士诚据浙西五郡发松嘉湖杭民夫筑杭州及松</span>  
<span style="margin-left: 2em">江府松江入　国朝在士诚平后陆子渊以为在龙</span>  
<span style="margin-left: 2em">凤年非也</span>  
<span style="margin-left: 1em">洪武改元以松江隶南京巍然自成一雄藩矣嘉靖二</span>  
<span style="margin-left: 1em">十二年复割华亭上海建青浦县于故青龙镇次年随</span>
