## 崇禎松江府志卷之四十三　人物八（賢媛）

<span style="margin-left: 3em">賢媛</span>  
<span style="margin-left: 1em">鳥有鶼失偶則不栖魚有鰈去一則不遊物尚如此而</span>  
<span style="margin-left: 1em">况人乎故郡有節烈婦志不絶書以附於古者哭市崩</span>  
<span style="margin-left: 1em">城投淵化石之後此女中張許也其次養尊嫜扶門祚</span>  
<span style="margin-left: 1em">辛勤數十年手挈六尺之孤復還之亡者此女中李西</span>  
<span style="margin-left: 1em">平郭汾陽也雖然彤管青編必節烈乃錄何異見樹而</span>  
<span style="margin-left: 1em">采其枯見月而取其缺可乎太史公不爲婦人立傳而</span>  
<span style="margin-left: 1em">政姊以俠陵母以智皆得書則史法可知矣</span>  
<span style="margin-left: 1em">漢張白妻陸氏績之女也績爲鬱林守時所生因名鬱</span>  
<span style="margin-left: 1em">生年十三嫁同郡張白白兄温廢徙白死誓不再嫁姚</span>  
<span style="margin-left: 1em">信表之</span>  
<span style="margin-left: 2em">表曰臣聞唐虞之政舉善而教旌德擢異三王所先</span>  
<span style="margin-left: 2em">是以忠臣烈士顯名國朝淑婦貞女表迹家閭蓋所</span>  
<span style="margin-left: 2em">以闡明化業廣殖清風使苟有令性幽明俱著苟懷</span>  
<span style="margin-left: 2em">懿姿士女同榮故王蠋建寒松之節而齊王表其里</span>  
<span style="margin-left: 2em">義姑立殊絶之操而魯侯高其門臣切見故鬱林太</span>  
<span style="margin-left: 2em">守陸績女子鬱生少履貞特之行幼立匪石之節年</span>  
<span style="margin-left: 2em">始十三適同郡張白侍廟三月婦禮未卒白遭罹家</span>  
<span style="margin-left: 2em">禍遷死異郡鬱生抗聲昭節義形于色冠蓋交横誓</span>  
<span style="margin-left: 2em">而不許奉白娣妹險巇之中蹈履水火志懷霜雪義</span>  
<span style="margin-left: 2em">心固于金石體信貫于神明送終以禮邦士慕則臣</span>  
<span style="margin-left: 2em">聞昭德以行顯行以爵苟非名爵則勸善不嚴故士</span>  
<span style="margin-left: 2em">之有誄魯人志其勇杞婦見書齊人哀其哭乞蒙聖</span>  
<span style="margin-left: 2em">朝斟酌前訓上開天聰下垂坤厚裒鬱生以義姑之</span>  
<span style="margin-left: 2em">號以勵兩髦之節則皇風穆暢士女改視矣<sub class="note-yuan">裴松之三國註</sub></span>  
<span style="margin-left: 1em">晉陸氏機雲族女適會稽張茂茂爲吳興太守值王敦</span>  
<span style="margin-left: 1em">問鼎執正不移敦遣沈充攻城殺之陸氏乃傾家資率</span>  
<span style="margin-left: 1em">茂部曲爲先登以討允充敗乃詣闕上書謝茂不克之</span>  
<span style="margin-left: 1em">責詔褒茂夫妻忠烈並加封爵</span>  
<span style="margin-left: 1em">孫氏虞潭母晉成帝二年蘇峻反詔潭督三吳等郡諸</span>  
<span style="margin-left: 1em">軍事與顧衆同討峻潭母孫氏戒之曰我聞忠臣出孝</span>  
<span style="margin-left: 1em">子之門爾當舍生取義勿以吾老爲累乃盡發家僮以</span>  
<span style="margin-left: 1em">助戰貿所服環帶以給軍資潭既平蘇峻又修滬瀆壘</span>  
<span style="margin-left: 1em">以禦孫恩一心報國母之教也朝廷知其憂國忠誠拜</span>  
<span style="margin-left: 1em">武昌侯太夫人加金章紫綬没復賜謚婦人生而封爵</span>  
<span style="margin-left: 1em">死而易名自潭母始</span>  
<span style="margin-left: 2em">孫氏非郡人也潭禦孫恩有功於松皆母之教故特</span>  
<span style="margin-left: 2em">表出之</span>  
<span style="margin-left: 1em">南宋孔夫人顧琛母初顧惔娶於婁之孔氏生琛琛本</span>  
<span style="margin-left: 1em">吳人而爲吳郡太守晉安帝隆安初孔氏年百餘歲矣</span>  
<span style="margin-left: 1em">瑯琊王廞于吳中爲亂以女爲貞烈將軍悉以女人爲</span>  
<span style="margin-left: 1em">官屬以孔氏爲司馬及孫恩亂後東土饑荒人相食孔</span>  
<span style="margin-left: 1em">氏散家糧以賑邑里得活者甚衆生子皆以孔爲名焉</span>  
<span style="margin-left: 1em">唐韋夫人者南康王之女叔也適溧陽令陸偘即宣公</span>  
<span style="margin-left: 1em">贄之母溧陽卒于官夫人訓公成大儒作唐賢相皆夫</span>  
<span style="margin-left: 1em">人之德也德宗勑迎養京師道每置驛時人榮之及卒</span>  
<span style="margin-left: 1em">皇后賻遺因葬洛陽見權德輿所爲文</span>  
<span style="margin-left: 1em">宋湖陰女子姓詹氏秀州華亭人僑寓湖陰其父詹先</span>  
<span style="margin-left: 1em">生老且貧以教授小兒爲業獨與一子一女俱詹氏姿</span>  
<span style="margin-left: 1em">貌甚美以女工給先生朝夕嘗手抄古列女傳至暮夜</span>  
<span style="margin-left: 1em">必熟誦數四而寢雖寒暑不廢也鄉人咸異之淮寇張</span>  
<span style="margin-left: 1em">遇聚黨寖多既屠池陽復寇湖陰邑人皆遁走先生泣</span>  
<span style="margin-left: 1em">謂女曰吾死無恨奈若何女曰父獨何憂吾計久決今</span>  
<span style="margin-left: 1em">日豈得父子俱生耶頃之賊至欲殺其父兄女謂賊曰</span>  
<span style="margin-left: 1em">吾父貧且老君意不在金帛但欲得我耳吾幸得執巾</span>  
<span style="margin-left: 1em">帚以奉君侯請釋父縛不然父子俱死無益也賊命遣</span>  
<span style="margin-left: 1em">之女以手麾其父使急去賊挈女行數里過東市橋躍</span>  
<span style="margin-left: 1em">入水而死後數日其從兄夜夢女曰吾已活吾父兄今</span>  
<span style="margin-left: 1em">來與兄訣兄旦忽忽不樂妻怪問之告之故妻大驚曰</span>  
<span style="margin-left: 1em">吾夜夢小姑如生平亟來相別如君言明日果有告以</span>  
<span style="margin-left: 1em">女子死之狀<sub class="note-yuan">周少隱集</sub></span>  
<span style="margin-left: 1em">練氏適章仔鈞爲統兵官即章楶始祖也嘗出兵有二</span>  
<span style="margin-left: 1em">將後期當斬夫人練氏救之後二將握兵南唐破建州</span>  
<span style="margin-left: 1em">夫人猶在二將使人以金帛遺夫人且授一白旗曰吾</span>  
<span style="margin-left: 1em">屠城夫人植旗于門吾戒士卒弗犯也夫人悉返之曰</span>  
<span style="margin-left: 1em">幸思舊願全此城否則與俱斃耳二將感其言止不屠</span>  
<span style="margin-left: 1em">舊史曰一女子全活數十萬生命其後得象及楶功名</span>  
<span style="margin-left: 1em">顯盛信有天道</span>  
<span style="margin-left: 1em">郭氏光禄大夫郭三益之女孫適雲間葉氏蚤寡因誓</span>  
<span style="margin-left: 1em">節爲尼名正覺居法雲寺能詩有一絶云春朝湖上風</span>  
<span style="margin-left: 1em">兼雨世事如花落又開退省閉門真樂處閑雲終日去</span>  
<span style="margin-left: 1em">還來後人景其志節刻詩于石以銀填之竪于覺骨塔</span>  
<span style="margin-left: 1em">前</span>  
<span style="margin-left: 1em">元管夫人名道昇字仲姬泖西小蒸人今其地尚名管</span>  
<span style="margin-left: 1em">家路歸趙孟頫封吳興郡夫人天姿開朗德容俱備翰</span>  
<span style="margin-left: 1em">墨辭章不學而能嘗手書金剛經至數十卷以施名山</span>  
<span style="margin-left: 1em">天子命夫人書千文勅玉工磨玉軸送秘書監裝池收</span>  
<span style="margin-left: 1em">藏又嘗畫墨竹及設色竹圖以進蒙賜內府上尊酒謁</span>  
<span style="margin-left: 1em">興聖宫皇太后命坐賜食恩意優渥受知兩宫卒年五</span>  
<span style="margin-left: 1em">十八</span>  
<span style="margin-left: 2em">公行狀稱元延祐帝及太后愛公翰墨有應制則命</span>  
<span style="margin-left: 2em">管夫人與仲穆副其體而藏之秘閣曰令後世知子</span>  
<span style="margin-left: 2em">昂父子夫婦皆工八法也</span>  
<span style="margin-left: 1em">陳氏錢塘儒家女其夫縣曹吏因兵亂隸軍籍戍於華</span>  
<span style="margin-left: 1em">亭夫久出不還聞雁有感因題于華亭戍壁曰浪喜燈</span>  
<span style="margin-left: 1em">花落又生夜寒頻放剪刀聲遊鴻不寄征夫信顧影娉</span>  
<span style="margin-left: 1em">婷無限情或勸之曰若質美性慧往富室爲紅女不猶</span>  
<span style="margin-left: 1em">愈守空房<sub class="note-jiao">校：戌當房字之訛今改</sub>忍饑寒乎答曰饑寒小事耳不</span>  
<span style="margin-left: 1em">察而聽汝失節莫大焉或慚而退久之夫還人咸頌之</span>  
<span style="margin-left: 1em"><sub class="note-yuan">梧溪集</sub></span>  
<span style="margin-left: 2em">張洙宗魯和聞雁詩曰青蘋風起別鴻生寒盡春來</span>  
<span style="margin-left: 2em">不寄聲多少離群歸欲盡天涯抛棄獨何情謝嘉維</span>  
<span style="margin-left: 2em">則和云缺月微明瘴霧生兩鄉夢斷玉簫聲無由並</span>  
<span style="margin-left: 2em">跨秦臺鳳夜夜離鴻別鶴情王逢和云江南江北荻</span>  
<span style="margin-left: 2em">花生妾處君邊第一聲何似春風湖上宅銀筝玉柱</span>  
<span style="margin-left: 2em">白頭情</span>  
<span style="margin-left: 1em">翠娥秀李姓趙之娼女也既笄以處子適鎮守松江管</span>  
<span style="margin-left: 1em">軍副萬户石薛徹都爲小婦居數年無子徹都卒秀時</span>  
<span style="margin-left: 1em">年二十五服喪過哀且固護指爪示無他志免喪爪長</span>  
<span style="margin-left: 1em">寸許父母以之歸將怵之改適對曰爪折可也然護之</span>  
<span style="margin-left: 1em">愈嚴薛徹都子世爵事之如母秀復簪珥道裝益明其</span>  
<span style="margin-left: 1em">志年踰八袠爪長尺餘以終</span>  
<span style="margin-left: 1em">劉氏燕山人幼失父母賴兄而贅壻松江人也初不知</span>  
<span style="margin-left: 1em">爲逋亡戍卒而有妻居久之會赦因紿劉曰吾歸省須</span>  
<span style="margin-left: 1em">春復來遂還不復往間數年劉訪抵松壻不之認劉乃</span>  
<span style="margin-left: 1em">仰天捬心痛哭曰良人我棄我將安歸獨有效死渠前</span>  
<span style="margin-left: 1em">爾由是剪髮日誦佛經行丐于市宿昔嫠姥家人多之</span>  
<span style="margin-left: 1em">施倍常丐搆一室製棺夜臥其中殆五十餘年鄰火劉</span>  
<span style="margin-left: 1em">入棺聲呼曰什用願悉取去乞與闔棺以畢吾事救火</span>  
<span style="margin-left: 1em">者從其言與室俱燬</span>  
<span style="margin-left: 1em">顧氏二貞長曰中次曰和顧亨女也胥字而寡中慕古</span>  
<span style="margin-left: 1em">貞烈操非節孝事弗語和剪髮自堅父母議婚皆不聽</span>  
<span style="margin-left: 1em">及卒臨川奉智題其墓曰處士墳吉安楊清爲二貞傳</span>  
<span style="margin-left: 1em">陸貞婦趙氏安吉幕長澤孫女鄞處士陸燾妻至正間</span>  
<span style="margin-left: 1em">兩浙多虞燾辭海寧主塾與趙隱居松之瓢湖丁未夏</span>  
<span style="margin-left: 1em">四月海隅有警兵猝至燾偕趙倉皇赴舟同難者争槎</span>  
<span style="margin-left: 1em">燾竄登岸將復擕趙以行而兵偪之傷刃者三遂仆深</span>  
<span style="margin-left: 1em">淖趙竟自投于淵當時有歌之者曰四月三日兵撓湖</span>  
<span style="margin-left: 1em">婦女多被辱與驅殉節伊誰天水姝</span>  
<span style="margin-left: 1em">任氏青龍任水監月山之女孫以水監廕得官生二子</span>  
<span style="margin-left: 1em">一女至正中北人有楊姓者官于華亭因亂僑居任氏</span>  
<span style="margin-left: 1em">館舍楊即爲其子聘任女其子生而驕初不知也嘗登</span>  
<span style="margin-left: 1em">牆窺所聘女任氏父兄皆惡而侮之欲絶婚不可得遂</span>  
<span style="margin-left: 1em">遷延其婚期楊遂北歸音耗不相聞乃以女復受南鄉</span>  
<span style="margin-left: 1em">某氏聘及親迎船至門女遂剪髮而泣曰奈何以一身</span>  
<span style="margin-left: 1em">而有二夫吾將奉佛終身焉親戚勸諭百方卒不改志</span>  
<span style="margin-left: 1em">久之忽一日傳楊之子已死或有以夫既死再爲勸者</span>  
<span style="margin-left: 1em">愈執不從後爲女冠終<sub class="note-yuan">農田餘話</sub></span>  
<span style="margin-left: 1em">楊節婦龍華人至正丁丑夏彗星現天下童男女訛惑</span>  
<span style="margin-left: 1em">皆成配時楊年十三贅張都水子裕十五生一女十七</span>  
<span style="margin-left: 1em">裕蚤世楊守節五十餘年食淡茹素寢處一室里人呼</span>  
<span style="margin-left: 1em">其室爲楊節婦居王逢過龍華步經其故居感嘆久之</span>  
<span style="margin-left: 1em">曰蘇文忠有林氏媪詩請繼其響詩曰日度虀鹽歲枲</span>  
<span style="margin-left: 1em">麻望中修竹帶藂葭老人爲說眉山叟詩紀青裙紫笑</span>  
<span style="margin-left: 1em">花　十七孀居亂幾更隔溪聞得紡車聲却思臣妾書</span>  
<span style="margin-left: 1em">降表不獨南朝謝道清</span>  
<span style="margin-left: 1em">吳妙寧上海人年二十一贅同里張氏子越四載邑大</span>  
<span style="margin-left: 1em">姓以事變坐連其父寧泣曰吾父苟無地爲解族其赤</span>  
<span style="margin-left: 1em">矣吾不遄死禍延良人悔孰甚遂雉經死未克葬徵繫</span>  
<span style="margin-left: 1em">吏果至聞寧死唶異而去梧溪王逢詩曰紅羊年黑鼠</span>  
<span style="margin-left: 1em">月張婦吳儼遺烈九山風酸泖波月二氣舛錯愁雲結</span>  
<span style="margin-left: 1em">百里泥塗昏墊中梅花一樹驚飄雪我招數十節義魂</span>  
<span style="margin-left: 1em">扁舟今過西新村歲月堂上虛鳴珮煙雨牆角餘繰盆</span>  
<span style="margin-left: 1em">篇詩爲付孝子浩四海薄俗何當敦</span>  
<span style="margin-left: 1em">胡氏姚某婦陳村人十八而嫁生兒未週歲夫死族賂</span>
