## 崇祯松江府志卷之四十三　人物八（贤媛）

<span style="margin-left: 3em">贤媛</span>  
<span style="margin-left: 1em">鸟有鹣失偶则不栖鱼有鲽去一则不游物尚如此而</span>  
<span style="margin-left: 1em">况人乎故郡有节烈妇志不绝书以附于古者哭市崩</span>  
<span style="margin-left: 1em">城投渊化石之后此女中张许也其次养尊嫜扶门祚</span>  
<span style="margin-left: 1em">辛勤数十年手挈六尺之孤复还之亡者此女中李西</span>  
<span style="margin-left: 1em">平郭汾阳也虽然彤管青编必节烈乃录何异见树而</span>  
<span style="margin-left: 1em">采其枯见月而取其缺可乎太史公不为妇人立传而</span>  
<span style="margin-left: 1em">政姊以侠陵母以智皆得书则史法可知矣</span>  
<span style="margin-left: 1em">汉张白妻陆氏绩之女也绩为郁林守时所生因名郁</span>  
<span style="margin-left: 1em">生年十三嫁同郡张白白兄温废徙白死誓不再嫁姚</span>  
<span style="margin-left: 1em">信表之</span>  
<span style="margin-left: 2em">表曰臣闻唐虞之政举善而教旌德擢异三王所先</span>  
<span style="margin-left: 2em">是以忠臣烈士显名国朝淑妇贞女表迹家闾盖所</span>  
<span style="margin-left: 2em">以阐明化业广殖清风使苟有令性幽明俱著苟怀</span>  
<span style="margin-left: 2em">懿姿士女同荣故王蠋建寒松之节而齐王表其里</span>  
<span style="margin-left: 2em">义姑立殊绝之操而鲁侯高其门臣切见故郁林太</span>  
<span style="margin-left: 2em">守陆绩女子郁生少履贞特之行幼立匪石之节年</span>  
<span style="margin-left: 2em">始十三适同郡张白侍庙三月妇礼未卒白遭罹家</span>  
<span style="margin-left: 2em">祸迁死异郡郁生抗声昭节义形于色冠盖交横誓</span>  
<span style="margin-left: 2em">而不许奉白娣妹险巇之中蹈履水火志怀霜雪义</span>  
<span style="margin-left: 2em">心固于金石体信贯于神明送终以礼邦士慕则臣</span>  
<span style="margin-left: 2em">闻昭德以行显行以爵苟非名爵则劝善不严故士</span>  
<span style="margin-left: 2em">之有诔鲁人志其勇杞妇见书齐人哀其哭乞蒙圣</span>  
<span style="margin-left: 2em">朝斟酌前训上开天聪下垂坤厚裒郁生以义姑之</span>  
<span style="margin-left: 2em">号以励两髦之节则皇风穆畅士女改视矣<sub class="note-yuan">裴松之三国注</sub></span>  
<span style="margin-left: 1em">晋陆氏机云族女适会稽张茂茂为吴兴太守值王敦</span>  
<span style="margin-left: 1em">问鼎执正不移敦遣沈充攻城杀之陆氏乃倾家资率</span>  
<span style="margin-left: 1em">茂部曲为先登以讨允充败乃诣阙上书谢茂不克之</span>  
<span style="margin-left: 1em">责诏褒茂夫妻忠烈并加封爵</span>  
<span style="margin-left: 1em">孙氏虞潭母晋成帝二年苏峻反诏潭督三吴等郡诸</span>  
<span style="margin-left: 1em">军事与顾众同讨峻潭母孙氏戒之曰我闻忠臣出孝</span>  
<span style="margin-left: 1em">子之门尔当舍生取义勿以吾老为累乃尽发家僮以</span>  
<span style="margin-left: 1em">助战贸所服环带以给军资潭既平苏峻又修沪渎垒</span>  
<span style="margin-left: 1em">以御孙恩一心报国母之教也朝廷知其忧国忠诚拜</span>  
<span style="margin-left: 1em">武昌侯太夫人加金章紫绶没复赐谥妇人生而封爵</span>  
<span style="margin-left: 1em">死而易名自潭母始</span>  
<span style="margin-left: 2em">孙氏非郡人也潭御孙恩有功于松皆母之教故特</span>  
<span style="margin-left: 2em">表出之</span>  
<span style="margin-left: 1em">南宋孔夫人顾琛母初顾惔娶于娄之孔氏生琛琛本</span>  
<span style="margin-left: 1em">吴人而为吴郡太守晋安帝隆安初孔氏年百余岁矣</span>  
<span style="margin-left: 1em">瑯琊王𫷷于吴中为乱以女为贞烈将军悉以女人为</span>  
<span style="margin-left: 1em">官属以孔氏为司马及孙恩乱后东土饥荒人相食孔</span>  
<span style="margin-left: 1em">氏散家粮以赈邑里得活者甚众生子皆以孔为名焉</span>  
<span style="margin-left: 1em">唐韦夫人者南康王之女叔也适溧阳令陆偘即宣公</span>  
<span style="margin-left: 1em">贽之母溧阳卒于官夫人训公成大儒作唐贤相皆夫</span>  
<span style="margin-left: 1em">人之德也德宗勑迎养京师道每置驿时人荣之及卒</span>  
<span style="margin-left: 1em">皇后赙遗因葬洛阳见权德舆所为文</span>  
<span style="margin-left: 1em">宋湖阴女子姓詹氏秀州华亭人侨寓湖阴其父詹先</span>  
<span style="margin-left: 1em">生老且贫以教授小儿为业独与一子一女俱詹氏姿</span>  
<span style="margin-left: 1em">貌甚美以女工给先生朝夕尝手抄古列女传至暮夜</span>  
<span style="margin-left: 1em">必熟诵数四而寝虽寒暑不废也乡人咸异之淮寇张</span>  
<span style="margin-left: 1em">遇聚党寖多既屠池阳复寇湖阴邑人皆遁走先生泣</span>  
<span style="margin-left: 1em">谓女曰吾死无恨奈若何女曰父独何忧吾计久决今</span>  
<span style="margin-left: 1em">日岂得父子俱生耶顷之贼至欲杀其父兄女谓贼曰</span>  
<span style="margin-left: 1em">吾父贫且老君意不在金帛但欲得我耳吾幸得执巾</span>  
<span style="margin-left: 1em">帚以奉君侯请释父缚不然父子俱死无益也贼命遣</span>  
<span style="margin-left: 1em">之女以手麾其父使急去贼挈女行数里过东市桥跃</span>  
<span style="margin-left: 1em">入水而死后数日其从兄夜梦女曰吾已活吾父兄今</span>  
<span style="margin-left: 1em">来与兄诀兄旦忽忽不乐妻怪问之告之故妻大惊曰</span>  
<span style="margin-left: 1em">吾夜梦小姑如生平亟来相别如君言明日果有告以</span>  
<span style="margin-left: 1em">女子死之状<sub class="note-yuan">周少隐集</sub></span>  
<span style="margin-left: 1em">练氏适章仔钧为统兵官即章楶始祖也尝出兵有二</span>  
<span style="margin-left: 1em">将后期当斩夫人练氏救之后二将握兵南唐破建州</span>  
<span style="margin-left: 1em">夫人犹在二将使人以金帛遗夫人且授一白旗曰吾</span>  
<span style="margin-left: 1em">屠城夫人植旗于门吾戒士卒弗犯也夫人悉返之曰</span>  
<span style="margin-left: 1em">幸思旧愿全此城否则与俱毙耳二将感其言止不屠</span>  
<span style="margin-left: 1em">旧史曰一女子全活数十万生命其后得象及楶功名</span>  
<span style="margin-left: 1em">显盛信有天道</span>  
<span style="margin-left: 1em">郭氏光禄大夫郭三益之女孙适云间叶氏蚤寡因誓</span>  
<span style="margin-left: 1em">节为尼名正觉居法云寺能诗有一绝云春朝湖上风</span>  
<span style="margin-left: 1em">兼雨世事如花落又开退省闭门真乐处闲云终日去</span>  
<span style="margin-left: 1em">还来后人景其志节刻诗于石以银填之竖于觉骨塔</span>  
<span style="margin-left: 1em">前</span>  
<span style="margin-left: 1em">元管夫人名道升字仲姬泖西小蒸人今其地尚名管</span>  
<span style="margin-left: 1em">家路归赵孟𫖯封吴兴郡夫人天姿开朗德容俱备翰</span>  
<span style="margin-left: 1em">墨辞章不学而能尝手书金刚经至数十卷以施名山</span>  
<span style="margin-left: 1em">天子命夫人书千文勅玉工磨玉轴送秘书监装池收</span>  
<span style="margin-left: 1em">藏又尝画墨竹及设色竹图以进蒙赐内府上尊酒谒</span>  
<span style="margin-left: 1em">兴圣宫皇太后命坐赐食恩意优渥受知两宫卒年五</span>  
<span style="margin-left: 1em">十八</span>  
<span style="margin-left: 2em">公行状称元延祐帝及太后爱公翰墨有应制则命</span>  
<span style="margin-left: 2em">管夫人与仲穆副其体而藏之秘阁曰令后世知子</span>  
<span style="margin-left: 2em">昂父子夫妇皆工八法也</span>  
<span style="margin-left: 1em">陈氏钱塘儒家女其夫县曹吏因兵乱隶军籍戍于华</span>  
<span style="margin-left: 1em">亭夫久出不还闻雁有感因题于华亭戍壁曰浪喜灯</span>  
<span style="margin-left: 1em">花落又生夜寒频放剪刀声游鸿不寄征夫信顾影娉</span>  
<span style="margin-left: 1em">婷无限情或劝之曰若质美性慧往富室为红女不犹</span>  
<span style="margin-left: 1em">愈守空房<sub class="note-jiao">校：戌當房字之訛今改</sub>忍饥寒乎答曰饥寒小事耳不</span>  
<span style="margin-left: 1em">察而听汝失节莫大焉或惭而退久之夫还人咸颂之</span>  
<span style="margin-left: 1em"><sub class="note-yuan">梧溪集</sub></span>  
<span style="margin-left: 2em">张洙宗鲁和闻雁诗曰青苹风起别鸿生寒尽春来</span>  
<span style="margin-left: 2em">不寄声多少离群归欲尽天涯抛弃独何情谢嘉维</span>  
<span style="margin-left: 2em">则和云缺月微明瘴雾生两乡梦断玉箫声无由并</span>  
<span style="margin-left: 2em">跨秦台凤夜夜离鸿别鹤情王逢和云江南江北荻</span>  
<span style="margin-left: 2em">花生妾处君边第一声何似春风湖上宅银筝玉柱</span>  
<span style="margin-left: 2em">白头情</span>  
<span style="margin-left: 1em">翠娥秀李姓赵之娼女也既笄以处子适镇守松江管</span>  
<span style="margin-left: 1em">军副万户石薛彻都为小妇居数年无子彻都卒秀时</span>  
<span style="margin-left: 1em">年二十五服丧过哀且固护指爪示无他志免丧爪长</span>  
<span style="margin-left: 1em">寸许父母以之归将怵之改适对曰爪折可也然护之</span>  
<span style="margin-left: 1em">愈严薛彻都子世爵事之如母秀复簪珥道装益明其</span>  
<span style="margin-left: 1em">志年逾八袠爪长尺余以终</span>  
<span style="margin-left: 1em">刘氏燕山人幼失父母赖兄而赘壻松江人也初不知</span>  
<span style="margin-left: 1em">为逋亡戍卒而有妻居久之会赦因绐刘曰吾归省须</span>  
<span style="margin-left: 1em">春复来遂还不复往间数年刘访抵松壻不之认刘乃</span>  
<span style="margin-left: 1em">仰天捬心痛哭曰良人我弃我将安归独有效死渠前</span>  
<span style="margin-left: 1em">尔由是剪发日诵佛经行丐于市宿昔嫠姥家人多之</span>  
<span style="margin-left: 1em">施倍常丐搆一室制棺夜卧其中殆五十余年邻火刘</span>  
<span style="margin-left: 1em">入棺声呼曰什用愿悉取去乞与阖棺以毕吾事救火</span>  
<span style="margin-left: 1em">者从其言与室俱毁</span>  
<span style="margin-left: 1em">顾氏二贞长曰中次曰和顾亨女也胥字而寡中慕古</span>  
<span style="margin-left: 1em">贞烈操非节孝事弗语和剪发自坚父母议婚皆不听</span>  
<span style="margin-left: 1em">及卒临川奉智题其墓曰处士坟吉安杨清为二贞传</span>  
<span style="margin-left: 1em">陆贞妇赵氏安吉幕长泽孙女鄞处士陆焘妻至正间</span>  
<span style="margin-left: 1em">两浙多虞焘辞海宁主塾与赵隐居松之瓢湖丁未夏</span>  
<span style="margin-left: 1em">四月海隅有警兵猝至焘偕赵仓皇赴舟同难者争槎</span>  
<span style="margin-left: 1em">焘窜登岸将复擕赵以行而兵偪之伤刃者三遂仆深</span>  
<span style="margin-left: 1em">淖赵竟自投于渊当时有歌之者曰四月三日兵挠湖</span>  
<span style="margin-left: 1em">妇女多被辱与驱殉节伊谁天水姝</span>  
<span style="margin-left: 1em">任氏青龙任水监月山之女孙以水监荫得官生二子</span>  
<span style="margin-left: 1em">一女至正中北人有杨姓者官于华亭因乱侨居任氏</span>  
<span style="margin-left: 1em">馆舍杨即为其子聘任女其子生而骄初不知也尝登</span>  
<span style="margin-left: 1em">墙窥所聘女任氏父兄皆恶而侮之欲绝婚不可得遂</span>  
<span style="margin-left: 1em">迁延其婚期杨遂北归音耗不相闻乃以女复受南乡</span>  
<span style="margin-left: 1em">某氏聘及亲迎船至门女遂剪发而泣曰奈何以一身</span>  
<span style="margin-left: 1em">而有二夫吾将奉佛终身焉亲戚劝谕百方卒不改志</span>  
<span style="margin-left: 1em">久之忽一日传杨之子已死或有以夫既死再为劝者</span>  
<span style="margin-left: 1em">愈执不从后为女冠终<sub class="note-yuan">农田余话</sub></span>  
<span style="margin-left: 1em">杨节妇龙华人至正丁丑夏彗星现天下童男女讹惑</span>  
<span style="margin-left: 1em">皆成配时杨年十三赘张都水子裕十五生一女十七</span>  
<span style="margin-left: 1em">裕蚤世杨守节五十余年食淡茹素寝处一室里人呼</span>  
<span style="margin-left: 1em">其室为杨节妇居王逢过龙华步经其故居感叹久之</span>  
<span style="margin-left: 1em">曰苏文忠有林氏媪诗请继其响诗曰日度虀盐岁枲</span>  
<span style="margin-left: 1em">麻望中修竹带藂葭老人为说眉山叟诗纪青裙紫笑</span>  
<span style="margin-left: 1em">花　十七孀居乱几更隔溪闻得纺车声却思臣妾书</span>  
<span style="margin-left: 1em">降表不独南朝谢道清</span>  
<span style="margin-left: 1em">吴妙宁上海人年二十一赘同里张氏子越四载邑大</span>  
<span style="margin-left: 1em">姓以事变坐连其父宁泣曰吾父苟无地为解族其赤</span>  
<span style="margin-left: 1em">矣吾不遄死祸延良人悔孰甚遂雉经死未克葬征系</span>  
<span style="margin-left: 1em">吏果至闻宁死唶异而去梧溪王逢诗曰红羊年黑鼠</span>  
<span style="margin-left: 1em">月张妇吴俨遗烈九山风酸泖波月二气舛错愁云结</span>  
<span style="margin-left: 1em">百里泥涂昏垫中梅花一树惊飘雪我招数十节义魂</span>  
<span style="margin-left: 1em">扁舟今过西新村岁月堂上虚鸣珮烟雨墙角余缲盆</span>  
<span style="margin-left: 1em">篇诗为付孝子浩四海薄俗何当敦</span>  
<span style="margin-left: 1em">胡氏姚某妇陈村人十八而嫁生儿未周岁夫死族赂</span>  
<span style="margin-left: 1em">邻妇为富家求婚妇抱儿泣曰不获从夫地下有此儿</span>  
<span style="margin-left: 1em">耳尚乞生图富贵耶族驱迫之妇度不能容乃乞归父</span>  
<span style="margin-left: 1em">母亦怜其少如夫党言妇以死自誓竟完其节</span>  
<span style="margin-left: 1em">韩氏女父华亭豪姓女垂笄上海朱氏以礼聘之未行</span>  
<span style="margin-left: 1em">会壻翁坐死赀籍于官女父遂欲绝其婚而他适女知</span>
