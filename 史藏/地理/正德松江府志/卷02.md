## 正德松江府志卷之二　水上

<span style="margin-left: 4em">水上</span>  
<span style="margin-left: 3em">府境諸水亦自杭天目及蘇之太湖而來渟浸縈</span>  
<span style="margin-left: 3em">迴由松江黃浦而會歸于海土之沃以是而害亦</span>  
<span style="margin-left: 3em">以是其源委之曲折蓄泄之方略非經國者所當</span>  
<span style="margin-left: 3em">知邪庸悉著于篇源起江湖而先海者從其長也</span>  
<span style="margin-left: 3em">浜汊小者不書不可考者附書舉要且傳疑也</span>  
<span style="margin-left: 1em">大海環府之東南二境其東接諸番混茫無際松江與</span>  
<span style="margin-left: 2em">黃浦會而入焉其會處曰蹌口其南與紹興寧波相</span>  
<span style="margin-left: 2em">望耆老云深夜籟寂時越上鷄犬之聲相聞今天日</span>  
<span style="margin-left: 2em">晴明南岸諸山皆歷歷可指<sub class="note-yuan">海人驗候云山擡風潮來海唑風雨多皆不誣擡謂海水擡起常所迷望之山皆在目也此說似怪或云蜃氣爲然唑音鹺俗云萬喙聲也周繇望海詩蒼茫空泛月四顧絶人煙半浸中華岸傍通異域船島間應有國波外恐無天欲作乘槎客翻然去隔年</sub></span>  
<span style="margin-left: 1em">松江在府北七十四里上海縣界府因以名舊名吴淞</span>  
<span style="margin-left: 2em">江後以水災去水從松亦曰松陵江其源出太湖東</span>  
<span style="margin-left: 2em">注于海即禹貢三江之一酈善長水經云松江自湖</span>  
<span style="margin-left: 2em">東北逕七十里分流謂之三江口<sub class="note-yuan">一說吴松江口白鶴江口青龍江口謂之三江口地勢低於震澤三丈潮水來時水高三丈到震澤底定所以謂之平江</sub>庾仲初揚</span>  
<span style="margin-left: 2em">都賦注云松江下七十里水口分流東北入海爲婁</span>  
<span style="margin-left: 2em">江東南入海爲東江并松江爲三江今松江自吴江</span>  
<span style="margin-left: 2em">長橋東流至尹山北流至甫里東北流至澱山北合</span>  
<span style="margin-left: 2em">趙屯浦又東合大盈浦又東合顧會浦又東合崧子</span>  
<span style="margin-left: 2em">浦盤龍浦凡五大浦至宋家橋轉東南流與黃浦會</span>  
<span style="margin-left: 2em">而入海<sub class="note-yuan">自湖至海凡五匯四十二灣五匯者安亭白鶴盤龍河沙顧浦乃江潮與湖水相會合之地也古云九里爲一灣一灣低一尺二百四十里到三江口三百六十里到大海</sub>其將入海</span>  
<span style="margin-left: 2em">處別名滬瀆其別派自吴江分流由急水港鍾爲大</span>  
<span style="margin-left: 2em">湖曰薛澱<sub class="note-yuan">宋葉清臣松江秋泛賦澤國秋晴天高水平遥山晚碧極浦寒清循游具區之野縱汎吴松之𤃩東瞰滄海西瞻洞庭槁葉微下斜陽半明樵風歸兮自朝暮汐溜滿兮誰送迎浩霜空兮一色橫霽景兮千名於時積潦未收長江無際澄瀾方興扁舟獨詣社橘初黃汀葭餘翠驚鷺朋飛別鵠孤唳聽漁桹之遞響聞牧笛之長吹既覽物以放懷亦思人而結欷若夫敵寇既平霸圖初盛均憂待濟同安則病魚貪餌而登鉤鹿走險而忘命一旦辭禄揚舲高泳功崇不居名存斯令達識先明孤風孰競又若金耀不融洛塵其蒙宗城寡捍王國爭雄拂衣洛土震耀江東拖翠綸兮波上膾蟬翼兮柈中倘即時之有適遑我後之爲恫至如著書笠澤端居甫里兩槳汀洲片帆煙水夕醉酒壚朝盤魚市浮游塵外之物嘯傲人間之世富詞客之多才劇騷人之清思緬三子之清徽諒隨時之有宜非才高見棄於榮路乃道大不容於禍機申屠臨河而蹈壅伯夷登山而食薇皆有爲而然爾豈得已而用之別有執簡僊瀛持荷帝柱晨韜史氏之筆暮拂使臣之斧登覽有澄清之心臨遣動光華之賦何從欲之流滋慰遠遊之以懼肇提封之所履屬方割之此憂將濬疏於匯川期拯濟乎畛疇轉白鶴之新渚據青龍之上游濯埃垢於緇袂刮病膜乎昏眸左引任公之釣右援仲由之桴思勤官而裕民乃善利之遠猷彼全身以遠害蓋孔臧於自謀鮮鱗在俎真茶滿甌少回俗士之駕亦未可爲兹江之羞程俱松江賦鴟夷子皮既棄越相乘扁舟携西子泝東流方將家五湖以長邁屣萬鍾而不留放若巨魚縱大壑脱若六驥馳坦道而挾輕輈時則八荒收雲千里一碧狂瀾不興遠岫凝色目盡意往雲天出没引風檣以悲嘯趣煙波而不極於是遇亡是叟而問津焉曰三江之湊實爲五湖地脉四達衍爲松江洶洶渾渾溶溶洋洋孤岑連嶂七十有二眇若散螺黛於微茫五湖之中大曰包山風穴晝暝霜林夏寒暮煙屯其疊翠冬實纍其錯丹麟鶴之所憩蛟鼉之所淵山中之人忘世與年條桑縹緲之下採石明月之灣草衣木茹泊若追羲盤而與還江流之窮是則歸墟王百谷於一吸環齊州於一區大鵬奮翅於泱漭燭龍洗光於咸虞由江而下二百餘里布帆無恙尚可以朝海門而暮方壺雖然善賈者據其會善搏者扼其吭方趣南則遺北既畫圓而失方今子將攬衆物之會莫若遐觀乎中央惟是江湖之接二州相望散荒墟於垤塊識斷岸於豪芒嘗試與子至中流而四望陰霾鬱興不辨雲水天高日出萬頃在目者五湖也岡岫相屬如走如伏冥濛突兀乍見乍失者包山也擁松江之上流窮海道於一葦時矯首而斯盡固可以訪漁樵而種魴鯉亦優游而卒歲矣吾子以爲何如子皮曰然務外游者有待樂內觀者無窮吾方以日月爲燭六合爲宫參天地以爲友從四海之諸公乘雲氣御飛龍指包山於遺礫視五湖於一鍾松江之勝又安能芥蔕於胸中乎後松江賦程子既爲松江賦假鴟夷子皮設亡是叟以爲詞是夜夢有丈夫頎然而長身黧色而修髯叩舷而稱曰松江之勝吾子之詞侈矣然子亦聞吴越之遺事乎唯而答曰長橋卧波截江之衝飛梁疊架排霧橫空萬景所會而垂虹屹立乎其中吾嘗登垂虹顧二渚尚想夫霸國之爭雄方其踐忍鳥喙羌耕石田禍起腋下謀悟機先則吴軍江北越軍江南殺氣朝合軍聲夜嚴銜枚北渡奮爲兩翼方風馳而霧障頓雷轟而電擊吴卒麕潰江流赭赤畢夫椒之世仇儻會稽之膽食於此蓋夫子之雄績乃自太湖過橫山亂越來之溪登姑胥之臺弔亡國於游鹿指血化於黃埃挽艅艎以淩江捲旌旗而南歸則夫子於此退身行意揖句踐而長辭蓋與夫咎犯之貪天子推之獨賢歌龍蛇而激憤塊然與喬木而偕燔者不可同日而言矣間者五季棼亂錢鏐崛興蘇據都會乃淮浙之必爭徐約先拔孫儒繼焚彼得之不能以歲月守我守之不能以歲月寧則江之兩厓相爲二城鎮威武之右境遏淮南之寇兵實用武者之所憑版圖入朝置爲縣治畫井疆設群吏臯畝棊別居廬鱗次帶以千尺之橋捍以百里之塘舟輿所通樓觀相望曾城邑之幾時翳喬木之蒼蒼矣吾嘗歎曰一江方東雖逝不流越世事之萬變去莫知其所遁而來莫知其所由今之松江其昔之松江邪抑夜半之藏舟失萬世於俯仰盡賢愚於一丘夫子亦嘗弔抉眼之忠魂而訪伏劒者之靈游不乎子皮不對顧謂西子援琴而歌歌曰霰雪紛兮雲霏霏帶長鋏而佩寶璐兮子安適而不歸歲婉婉而將暮兮路既壅而中迷嗟二子之不返折疏麻而搴杜若羌摇摇其遺誰餘音未息蘧然而覺掉頭載歌付千古於一笑唐杜牧詩清露白雲明月天與君齊棹木蘭船風波湖雨一相失夜泊橫塘心渺然陸龜蒙詩柳下江飱待好風暫時還得狎漁翁一生無事煙波足惟有沙邊水勃公宋陳堯佐詩平波渺渺煙蒼蒼菰蒲纔熟楊柳黃扁舟繫岸不忍去秋風斜日鱸魚鄉蘇軾與秦觀參寥會于松江吴越溪山興未窮强扶衰病過垂虹浮天自古東南水送客今朝西北風絶境自忘千里遠勝遊難復五人同舟師不會留連意要看斜陽萬頃紅米芾詩柳外艤舟晚醉餘雙眼醒水光涵一氣星彩動圓靈炯炯月初上翛翛風更泠遠山橫秀碧淡墨說吾經元黃溍松江舟中二首山房偶爲故人留又領飛雲過別州白浪千花帆一葉茫茫天地此生浮〇移舟夜泊華亭縣忽聽吴歌思渺然最憶澱山湖北寺白雲堆裏看青天國朝袁凱沙塗行西起吴江東海浦茫茫沙塗皆沃土當時此物不歸官盡養此地飢民户紅尖小麥畝二石荻蘆輪囷竟三尺紛紛赤線何足論瓜芊青秧密如櫛飢民得此不復飢昔無一物今五衣子孫相仍二十載飽暖得與平民齊君恩如天不可負君恩能前不能後力微勢怯官不理一一奄與强家有强家犬馬厭菽粟强家下陳盡珠玉君不聞江頭浦邊三萬家秋雨秋風夜無燭</sub></span>  
<span style="margin-left: 1em">滬瀆江吴郡記曰松江東瀉海曰滬海亦謂之滬瀆滬</span>  
<span style="margin-left: 2em">水名也凡水發源而注海曰瀆陸魯望云列竹于海</span>  
<span style="margin-left: 2em">澨曰滬吴之滬瀆是也皮日休詩全吴臨巨溟百里</span>  
<span style="margin-left: 2em">到滬瀆海物競駢羅水怪爭滲漉即此地也</span>  
<span style="margin-left: 1em">薛澱湖一名澱山湖以中有澱山也在府西北七十二</span>  
<span style="margin-left: 2em">里其源自長洲白蜆江經急水港而來周圍幾二百</span>  
<span style="margin-left: 2em">里實古來鍾水之地北由趙屯浦東由大盈浦瀉于</span>  
<span style="margin-left: 2em">松江東南由爛路港以入三泖舊志云西有小湖又</span>  
<span style="margin-left: 2em">云縣西北有白蜆馬騰谷瑇瑁四湖且謂白蜆越在</span>  
<span style="margin-left: 2em">長洲馬騰谷瑇瑁三湖相去僅五七里而澱湖茫然</span>  
<span style="margin-left: 2em">一壑不復可辨其後又載錡湖云有陸錡宅曰瑁湖</span>  
<span style="margin-left: 2em">曰邢湖曰新湖云皆在西北以今考之澱湖之南有</span>  
<span style="margin-left: 2em">瓢湖其傍有金銀東清東白西陳大葑諸蕩漾北即</span>  
<span style="margin-left: 2em">蔓萊洲<sub class="note-yuan">在長洲界</sub>皆涵浸相屬數十里其西過金澤又有</span>  
<span style="margin-left: 2em">西黿蕩雪落漾諸水而不得其名者尚多古今世殊</span>  
<span style="margin-left: 2em">焉知舊志所書非今之諸蕩邪澱山宋時在水心並</span>  
<span style="margin-left: 2em">湖以北中爲一澳曰山門溜東西五六里南北七八</span>  
<span style="margin-left: 2em">里正當湖流之衝爲古來吞吐湖水之地山門溜之</span>  
<span style="margin-left: 2em">中又有斜路港<sub class="note-yuan">斜路今與崑山磧澳鄰</sub>大石浦小石浦通洩湖</span>  
<span style="margin-left: 2em">流後潮沙淤澱漸成圍田元初湖去西北已五里餘</span>  
<span style="margin-left: 2em">今趙屯大盈去湖益遠顧由何家港及南北曹港受</span>  
<span style="margin-left: 2em">湖水以泄于江水患之多蓋有由矣<sub class="note-yuan">每歲湖人以湖水清渾辨歲之豐凶或清或渾或清渾析清豐渾凶析亦從之宋張擴過澱湖詩昨日過湖風打頭葦蒲深處泊官舟近人烏鳥語聲碎瀕海風煙日夜浮午飯腥鹹半鮭菜客牀顛倒一皮裘平生浪說在家好老向風波未肯休衛涇遊澱湖疏星殘月尚朦朧閑入煙波一棹風始覺舟移楊柳岸直疑身到水晶宫烏鴉天際墨千點白鷺灘頭玉一叢欸乃一聲回首處西山渾在有無中戴表元過澱湖衆澤東南會扁舟西北經雪融湖蕩白春動海山青歲事兼魚歎鄉謡咤蜃靈鴟夷誰羨汝祇合佩笭篂元楊維禎二首半空樓閣澱山寺三面篷檣湖口船蘆葉響時風似雨浪花平處水如天沽來村酒渾無味買得鱸魚不論錢明日垂虹橋下過與君停棹弔三賢〇禹劃三江東入海神姑繼禹澱湖開獨鰲屓贔戴山出三龍聯翩乘女來稽天怪浪俄桑土閲世神牙亦劫灰我憶舊時松頂月夜深夢接鶴飛回</sub></span>  
<span style="margin-left: 1em">趙屯浦在澱山湖北舊直受湖水瀉于松江其闊至五</span>  
<span style="margin-left: 2em">十丈通江五大浦之一也今自北曹港分支北流愈</span>  
<span style="margin-left: 2em">北愈隘浦口束以石梁僅通舟楫而已其接曹港處</span>  
<span style="margin-left: 2em">又名新河其一支東南流入曹港者曰南小趙屯浦</span>  
<span style="margin-left: 2em">一支東北流入江者曰北小趙屯浦南趙屯亦名李</span>  
<span style="margin-left: 2em">墟涇其北爲望湖涇西爲鳥觜塘望湖之北爲孔宅</span>  
<span style="margin-left: 2em">涇又北爲蘇溝並西通趙屯東入大盈浦趙屯之西</span>  
<span style="margin-left: 2em">爲內勛會仙二浦蘇溝之北爲直盧古盤諸浦</span>  
<span style="margin-left: 2em">內勛浦其上流曰古塘其西爲石浦入崑山界</span>  
<span style="margin-left: 2em">會仙浦即內勛之分支王可交遇仙處也</span>
