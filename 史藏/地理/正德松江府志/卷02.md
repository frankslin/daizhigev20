## 正德松江府志卷之二　水上

<span style="margin-left: 4em">水上</span>  
<span style="margin-left: 3em">府境诸水亦自杭天目及苏之太湖而来渟浸萦</span>  
<span style="margin-left: 3em">回由松江黄浦而会归于海土之沃以是而害亦</span>  
<span style="margin-left: 3em">以是其源委之曲折蓄泄之方略非经国者所当</span>  
<span style="margin-left: 3em">知邪庸悉著于篇源起江湖而先海者从其长也</span>  
<span style="margin-left: 3em">浜汊小者不书不可考者附书举要且传疑也</span>  
<span style="margin-left: 1em">大海环府之东南二境其东接诸番混茫无际松江与</span>  
<span style="margin-left: 2em">黄浦会而入焉其会处曰跄口其南与绍兴宁波相</span>  
<span style="margin-left: 2em">望耆老云深夜籁寂时越上鸡犬之声相闻今天日</span>  
<span style="margin-left: 2em">晴明南岸诸山皆历历可指<sub class="note-yuan">海人验候云山抬风潮来海唑风雨多皆不诬抬谓海水抬起常所迷望之山皆在目也此说似怪或云蜃气为然唑音鹾俗云万喙声也周繇望海诗苍茫空泛月四顾绝人烟半浸中华岸傍通异域船岛间应有国波外恐无天欲作乘槎客翻然去隔年</sub></span>  
<span style="margin-left: 1em">松江在府北七十四里上海县界府因以名旧名吴淞</span>  
<span style="margin-left: 2em">江后以水灾去水从松亦曰松陵江其源出太湖东</span>  
<span style="margin-left: 2em">注于海即禹贡三江之一郦善长水经云松江自湖</span>  
<span style="margin-left: 2em">东北径七十里分流谓之三江口<sub class="note-yuan">一说吴松江口白鹤江口青龙江口谓之三江口地势低于震泽三丈潮水来时水高三丈到震泽底定所以谓之平江</sub>庾仲初扬</span>  
<span style="margin-left: 2em">都赋注云松江下七十里水口分流东北入海为娄</span>  
<span style="margin-left: 2em">江东南入海为东江并松江为三江今松江自吴江</span>  
<span style="margin-left: 2em">长桥东流至尹山北流至甫里东北流至淀山北合</span>  
<span style="margin-left: 2em">赵屯浦又东合大盈浦又东合顾会浦又东合崧子</span>  
<span style="margin-left: 2em">浦盘龙浦凡五大浦至宋家桥转东南流与黄浦会</span>  
<span style="margin-left: 2em">而入海<sub class="note-yuan">自湖至海凡五汇四十二湾五汇者安亭白鹤盘龙河沙顾浦乃江潮与湖水相会合之地也古云九里为一湾一湾低一尺二百四十里到三江口三百六十里到大海</sub>其将入海</span>  
<span style="margin-left: 2em">处别名沪渎其别派自吴江分流由急水港钟为大</span>  
<span style="margin-left: 2em">湖曰薛淀<sub class="note-yuan">宋叶清臣松江秋泛赋泽国秋晴天高水平遥山晚碧极浦寒清循游具区之野纵泛吴松之𤃩东瞰沧海西瞻洞庭槁叶微下斜阳半明樵风归兮自朝暮汐溜满兮谁送迎浩霜空兮一色横霁景兮千名于时积潦未收长江无际澄澜方兴扁舟独诣社橘初黄汀葭余翠惊鹭朋飞别鹄孤唳听渔桹之递响闻牧笛之长吹既览物以放怀亦思人而结欷若夫敌寇既平霸图初盛均忧待济同安则病鱼贪饵而登钩鹿走险而忘命一旦辞禄扬舲高泳功崇不居名存斯令达识先明孤风孰竞又若金耀不融洛尘其蒙宗城寡捍王国争雄拂衣洛土震耀江东拖翠纶兮波上脍蝉翼兮柈中倘即时之有适遑我后之为恫至如著书笠泽端居甫里两桨汀洲片帆烟水夕醉酒垆朝盘鱼市浮游尘外之物啸傲人间之世富词客之多才剧骚人之清思缅三子之清徽谅随时之有宜非才高见弃于荣路乃道大不容于祸机申屠临河而蹈壅伯夷登山而食薇皆有为而然尔岂得已而用之别有执简僊瀛持荷帝柱晨韬史氏之笔暮拂使臣之斧登览有澄清之心临遣动光华之赋何从欲之流滋慰远游之以惧肇提封之所履属方割之此忧将濬疏于汇川期拯济乎畛畴转白鹤之新渚据青龙之上游濯埃垢于缁袂刮病膜乎昏眸左引任公之钓右援仲由之桴思勤官而裕民乃善利之远猷彼全身以远害盖孔臧于自谋鲜鳞在俎真茶满瓯少回俗士之驾亦未可为兹江之羞程俱松江赋鸱夷子皮既弃越相乘扁舟携西子溯东流方将家五湖以长迈屣万锺而不留放若巨鱼纵大壑脱若六骥驰坦道而挟轻辀时则八荒收云千里一碧狂澜不兴远岫凝色目尽意往云天出没引风樯以悲啸趣烟波而不极于是遇亡是叟而问津焉曰三江之凑实为五湖地脉四达衍为松江汹汹浑浑溶溶洋洋孤岑连嶂七十有二眇若散螺黛于微茫五湖之中大曰包山风穴昼暝霜林夏寒暮烟屯其叠翠冬实累其错丹麟鹤之所憩蛟鼍之所渊山中之人忘世与年条桑缥缈之下采石明月之湾草衣木茹泊若追羲盘而与还江流之穷是则归墟王百谷于一吸环齐州于一区大鹏奋翅于泱漭烛龙洗光于咸虞由江而下二百余里布帆无恙尚可以朝海门而暮方壶虽然善贾者据其会善搏者扼其吭方趣南则遗北既画圆而失方今子将揽众物之会莫若遐观乎中央惟是江湖之接二州相望散荒墟于垤块识断岸于豪芒尝试与子至中流而四望阴霾郁兴不辨云水天高日出万顷在目者五湖也冈岫相属如走如伏冥蒙突兀乍见乍失者包山也拥松江之上流穷海道于一苇时矫首而斯尽固可以访渔樵而种鲂鲤亦优游而卒岁矣吾子以为何如子皮曰然务外游者有待乐内观者无穷吾方以日月为烛六合为宫参天地以为友从四海之诸公乘云气御飞龙指包山于遗砾视五湖于一钟松江之胜又安能芥蔕于胸中乎后松江赋程子既为松江赋假鸱夷子皮设亡是叟以为词是夜梦有丈夫颀然而长身黧色而修髯叩舷而称曰松江之胜吾子之词侈矣然子亦闻吴越之遗事乎唯而答曰长桥卧波截江之冲飞梁叠架排雾横空万景所会而垂虹屹立乎其中吾尝登垂虹顾二渚尚想夫霸国之争雄方其践忍鸟喙羌耕石田祸起腋下谋悟机先则吴军江北越军江南杀气朝合军声夜严衔枚北渡奋为两翼方风驰而雾障顿雷轰而电击吴卒麕溃江流赭赤毕夫椒之世仇傥会稽之胆食于此盖夫子之雄绩乃自太湖过横山乱越来之溪登姑胥之台吊亡国于游鹿指血化于黄埃挽艅艎以凌江卷旌旗而南归则夫子于此退身行意揖句践而长辞盖与夫咎犯之贪天子推之独贤歌龙蛇而激愤块然与乔木而偕燔者不可同日而言矣间者五季棼乱钱镠崛兴苏据都会乃淮浙之必争徐约先拔孙儒继焚彼得之不能以岁月守我守之不能以岁月宁则江之两厓相为二城镇威武之右境遏淮南之寇兵实用武者之所凭版图入朝置为县治画井疆设群吏臯亩棋别居庐鳞次带以千尺之桥捍以百里之塘舟舆所通楼观相望曾城邑之几时翳乔木之苍苍矣吾尝叹曰一江方东虽逝不流越世事之万变去莫知其所遁而来莫知其所由今之松江其昔之松江邪抑夜半之藏舟失万世于俯仰尽贤愚于一丘夫子亦尝吊抉眼之忠魂而访伏劒者之灵游不乎子皮不对顾谓西子援琴而歌歌曰霰雪纷兮云霏霏带长铗而佩宝璐兮子安适而不归岁婉婉而将暮兮路既壅而中迷嗟二子之不返折疏麻而搴杜若羌摇摇其遗谁余音未息蘧然而觉掉头载歌付千古于一笑唐杜牧诗清露白云明月天与君齐棹木兰船风波湖雨一相失夜泊横塘心渺然陆龟蒙诗柳下江飧待好风暂时还得狎渔翁一生无事烟波足惟有沙边水勃公宋陈尧佐诗平波渺渺烟苍苍菰蒲才熟杨柳黄扁舟系岸不忍去秋风斜日鲈鱼乡苏轼与秦观参寥会于松江吴越溪山兴未穷强扶衰病过垂虹浮天自古东南水送客今朝西北风绝境自忘千里远胜游难复五人同舟师不会留连意要看斜阳万顷红米芾诗柳外舣舟晚醉余双眼醒水光涵一气星彩动圆灵炯炯月初上翛翛风更泠远山横秀碧淡墨说吾经元黄溍松江舟中二首山房偶为故人留又领飞云过别州白浪千花帆一叶茫茫天地此生浮〇移舟夜泊华亭县忽听吴歌思渺然最忆淀山湖北寺白云堆里看青天国朝袁凯沙涂行西起吴江东海浦茫茫沙涂皆沃土当时此物不归官尽养此地饥民户红尖小麦亩二石荻芦轮囷竟三尺纷纷赤线何足论瓜芊青秧密如栉饥民得此不复饥昔无一物今五衣子孙相仍二十载饱暖得与平民齐君恩如天不可负君恩能前不能后力微势怯官不理一一奄与强家有强家犬马厌菽粟强家下陈尽珠玉君不闻江头浦边三万家秋雨秋风夜无烛</sub></span>  
<span style="margin-left: 1em">沪渎江吴郡记曰松江东泻海曰沪海亦谓之沪渎沪</span>  
<span style="margin-left: 2em">水名也凡水发源而注海曰渎陆鲁望云列竹于海</span>  
<span style="margin-left: 2em">澨曰沪吴之沪渎是也皮日休诗全吴临巨溟百里</span>  
<span style="margin-left: 2em">到沪渎海物竞骈罗水怪争渗漉即此地也</span>  
<span style="margin-left: 1em">薛淀湖一名淀山湖以中有淀山也在府西北七十二</span>  
<span style="margin-left: 2em">里其源自长洲白蚬江经急水港而来周围几二百</span>  
<span style="margin-left: 2em">里实古来钟水之地北由赵屯浦东由大盈浦泻于</span>  
<span style="margin-left: 2em">松江东南由烂路港以入三泖旧志云西有小湖又</span>  
<span style="margin-left: 2em">云县西北有白蚬马腾谷瑇瑁四湖且谓白蚬越在</span>  
<span style="margin-left: 2em">长洲马腾谷瑇瑁三湖相去仅五七里而淀湖茫然</span>  
<span style="margin-left: 2em">一壑不复可辨其后又载锜湖云有陆锜宅曰瑁湖</span>  
<span style="margin-left: 2em">曰邢湖曰新湖云皆在西北以今考之淀湖之南有</span>  
<span style="margin-left: 2em">瓢湖其傍有金银东清东白西陈大葑诸荡漾北即</span>  
<span style="margin-left: 2em">蔓莱洲<sub class="note-yuan">在长洲界</sub>皆涵浸相属数十里其西过金泽又有</span>  
<span style="margin-left: 2em">西鼋荡雪落漾诸水而不得其名者尚多古今世殊</span>  
<span style="margin-left: 2em">焉知旧志所书非今之诸荡邪淀山宋时在水心并</span>  
<span style="margin-left: 2em">湖以北中为一澳曰山门溜东西五六里南北七八</span>  
<span style="margin-left: 2em">里正当湖流之冲为古来吞吐湖水之地山门溜之</span>  
<span style="margin-left: 2em">中又有斜路港<sub class="note-yuan">斜路今与昆山碛澳邻</sub>大石浦小石浦通泄湖</span>  
<span style="margin-left: 2em">流后潮沙淤淀渐成围田元初湖去西北已五里余</span>  
<span style="margin-left: 2em">今赵屯大盈去湖益远顾由何家港及南北曹港受</span>  
<span style="margin-left: 2em">湖水以泄于江水患之多盖有由矣<sub class="note-yuan">每岁湖人以湖水清浑辨岁之丰凶或清或浑或清浑析清丰浑凶析亦从之宋张扩过淀湖诗昨日过湖风打头苇蒲深处泊官舟近人乌鸟语声碎濒海风烟日夜浮午饭腥咸半鲑菜客床颠倒一皮裘平生浪说在家好老向风波未肯休卫泾游淀湖疏星残月尚朦胧闲入烟波一棹风始觉舟移杨柳岸直疑身到水晶宫乌鸦天际墨千点白鹭滩头玉一丛欸乃一声回首处西山浑在有无中戴表元过淀湖众泽东南会扁舟西北经雪融湖荡白春动海山青岁事兼鱼叹乡谣咤蜃灵鸱夷谁羡汝祇合佩笭篂元杨维祯二首半空楼阁淀山寺三面篷樯湖口船芦叶响时风似雨浪花平处水如天沽来村酒浑无味买得鲈鱼不论钱明日垂虹桥下过与君停棹吊三贤〇禹划三江东入海神姑继禹淀湖开独鳌屃赑戴山出三龙联翩乘女来稽天怪浪俄桑土阅世神牙亦劫灰我忆旧时松顶月夜深梦接鹤飞回</sub></span>  
<span style="margin-left: 1em">赵屯浦在淀山湖北旧直受湖水泻于松江其阔至五</span>  
<span style="margin-left: 2em">十丈通江五大浦之一也今自北曹港分支北流愈</span>  
<span style="margin-left: 2em">北愈隘浦口束以石梁仅通舟楫而已其接曹港处</span>  
<span style="margin-left: 2em">又名新河其一支东南流入曹港者曰南小赵屯浦</span>  
<span style="margin-left: 2em">一支东北流入江者曰北小赵屯浦南赵屯亦名李</span>  
<span style="margin-left: 2em">墟泾其北为望湖泾西为鸟觜塘望湖之北为孔宅</span>  
<span style="margin-left: 2em">泾又北为苏沟并西通赵屯东入大盈浦赵屯之西</span>  
<span style="margin-left: 2em">为内勋会仙二浦苏沟之北为直卢古盘诸浦</span>  
<span style="margin-left: 2em">内勋浦其上流曰古塘其西为石浦入昆山界</span>  
<span style="margin-left: 2em">会仙浦即内勋之分支王可交遇仙处也</span>

<span style="margin-left: 2em">卢浦</span>  
<span style="margin-left: 2em">古盆浦<sub class="note-yuan">今名古盘</sub></span>  
<span style="margin-left: 2em">南澥浦</span>  
<span style="margin-left: 2em">梁纥浦五浦并自苏沟左右分流入江</span>  
<span style="margin-left: 2em">白鹤江古称白鹤汇自此至蟠龙环曲为汇不知其</span>  
<span style="margin-left: 2em">几水行迂滞溢而为灾宋嘉祐间自其北开为直江</span>  
<span style="margin-left: 2em">径泻震泽之水东注于海自此吴中得免水患今江</span>

<span style="margin-left: 1em">三林塘在周浦北自咸塘西流其南为横袅其北为杜</span>  
<span style="margin-left: 2em">婆泾西入黄浦</span>  
<span style="margin-left: 1em">杨淄港在三林北自北咸塘西流入于黄浦</span>  
<span style="margin-left: 1em">黄淄溇在杨淄北</span>  
<span style="margin-left: 1em">马家浜</span>  
<span style="margin-left: 1em">东沟浦</span>  
<span style="margin-left: 1em">西沟浦在马家浜左右</span>  
<span style="margin-left: 1em">范家浦</span>  
<span style="margin-left: 1em">入海浦在范家北其东为大跄浜自马家浜以下并西</span>  
<span style="margin-left: 2em">入黄浦其东北至界浜嘉定上海分界</span>  
<span style="margin-left: 2em">按顾彧志下沙浦与盐铁塘各为一水其南有新港</span>  
<span style="margin-left: 2em">云瞿知州开又有孔家浜急水港顾家浜王家浜四</span>  
<span style="margin-left: 2em">水黄淄溇之北有白莲泾唐子泾蟹溇俞家浜华漕</span>  
<span style="margin-left: 2em">港杨泾范家浜而新志多阙新志有东奚浦杨木浦</span>  
<span style="margin-left: 2em">下海浦江苎浦椿树浦皆云在高昌乡而旧志不载</span>  
<span style="margin-left: 2em">水道之改易多矣如都台浦乃曹家沟之易名黄浦</span>  
<span style="margin-left: 2em">乃范家浜之故道东沟马家浜本南跄浦支渠其势</span>  
<span style="margin-left: 2em">俱大而南跄反微诸若此者甚众今并存之以俟参</span>
