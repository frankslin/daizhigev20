## 正德松江府志卷之三十　人物四（孝友）人物五（節義）人物六（文學） 人物七（藝術）人物八（隱逸）

<span style="margin-left: 4em">人物四<sub class="note-yuan">孝友</sub></span>  
<span style="margin-left: 1em">唐陸南金字季孫曾祖士季以文學顯祖謀道周王府</span>  
<span style="margin-left: 2em">文學詳正學士父元感建德歷陽二縣令朝散大夫</span>  
<span style="margin-left: 2em">黃州司馬南金貞觀中爲太常奉禮郎歷鄞令築隄</span>  
<span style="margin-left: 2em">爲湖千頃開元初少卿盧崇道抵罪徙嶺南逃還僞</span>  
<span style="margin-left: 2em">稱南金弔客突入其舍而道其情南金匿之俄事覺</span>  
<span style="margin-left: 2em">詔御史捕按南金當重法弟趙璧自言匿崇道者我</span>  
<span style="margin-left: 2em">也請死南金固言弟自誣不情御史怪之趙璧曰母</span>  
<span style="margin-left: 2em">未葬妹未歸兄能辦之我生無益不如死御史驚上</span>  
<span style="margin-left: 2em">狀玄宗皆宥之南金知書史操履謹飭張說陸象先</span>  
<span style="margin-left: 2em">稱其賢由庫部員外郎以疾改太子洗馬卒<sub class="note-yuan">初南金治鄞築隄爲湖宋知州李夷庚葺爲六梁四牐治平中立祠湖上之青山賜號嘉澤廟追封南金爲孚佑侯夷庚爲惠應侯</sub></span>  
<span style="margin-left: 1em">元湯文英字孟寬華亭人世篤孝友自華亭徙吳至文</span>  
<span style="margin-left: 2em">英八世同居至元間表其門閭復其家</span>  
<span style="margin-left: 1em">章夢賢字思齊上海青龍人宋秦國莊敏公楶之後孝</span>  
<span style="margin-left: 2em">友通練喜賔客好施惠元至順初嘗出粟二千餘石</span>  
<span style="margin-left: 2em">賑鄉里辭不受官至元中薦授襄陽等處營田提舉</span>  
<span style="margin-left: 2em">建康等處財賦提舉以父母蚤亡伯兄又多疾即棄</span>  
<span style="margin-left: 2em">官歸終身不仕事其兄如父置義莊以贍宗族建義</span>  
<span style="margin-left: 2em">塾以教鄉黨子弟兄殁撫其孤如子闔門二百餘口</span>  
<span style="margin-left: 2em">未嘗有間言子元澤初爲丞相府舍人累官奉政大</span>  
<span style="margin-left: 2em">夫江浙財賦副總管以母老亦棄官歸養鐵崖楊維</span>  
<span style="margin-left: 2em">禎亟稱之後以朝列大夫彰德路總管府同知致仕</span>  
<span style="margin-left: 1em">杜英發字俊卿上海人祁國公衍九世孫仕爲建寧學</span>  
<span style="margin-left: 2em">正陞教授歸隱西霞浦上號西霞道人初季父某無</span>  
<span style="margin-left: 2em">後嘗養莫氏子爲其幼復以英發爲後及季父殁悉</span>  
<span style="margin-left: 2em">以産歸莫氏子復爲之冠娶待之不異同氣族困於</span>  
<span style="margin-left: 2em">徭役首倡置義田儲粟若干石以資之鄰里婚喪皆</span>  
<span style="margin-left: 2em">有給其勇於義如此其貲産不逾中人云</span>  
<span style="margin-left: 1em">徐初字本道華亭青村人蚤喪母父信後母讒初事之</span>  
<span style="margin-left: 2em">益恭父暑月病疽穢惡流衽席初身自浣滌不解帶</span>  
<span style="margin-left: 2em">者經月父乃悟曰汝吾孝子也後母子亨少鍾愛長</span>  
<span style="margin-left: 2em">不事事初愛之不衰至正丙申浙右警初糾率鄉子</span>  
<span style="margin-left: 2em">弟數千備寇或誣其有異志縛送泖上軍初當鑕厲</span>  
<span style="margin-left: 2em">聲曰吾欲反率斥鹵氓蹈海去矣尚能戴吾頭見將</span>  
<span style="margin-left: 2em">軍乎將軍欲有土有民必歸諸正天下寧有白首賊</span>  
<span style="margin-left: 2em">也帥壯其言釋之且薦以官卒不起</span>  
<span style="margin-left: 1em">徐誠字信之上海人元至正間父爲金玉局大使嘗遇</span>  
<span style="margin-left: 2em">疾醫禱皆弗應乃刲股和藥以進疾尋愈家甚豐而</span>  
<span style="margin-left: 2em">儉獨好施予三族多待以舉火庚午辛未歲大侵爲</span>  
<span style="margin-left: 2em">饘粥以食餓者活萬餘人</span>  
<span style="margin-left: 1em">金子安字幼仁居上海漢成里七歲失怙事母淩氏得</span>  
<span style="margin-left: 2em">其歡心鄉人以孝子稱之母嘗遘疾子安稽顙北辰</span>  
<span style="margin-left: 2em">求以身代母危困中忽甦曰適神語我而子孝加爾</span>  
<span style="margin-left: 2em">壽三十四後母殁乃三十四月也居喪毁瘁哀痛終</span>  
<span style="margin-left: 2em">其身鄉鄰有悖倫者往往感激改行嘗市地於鄰除</span>  
<span style="margin-left: 2em">之得白金一罌亟召其人歸之時又多其義</span>  
<span style="margin-left: 1em">趙恭字思恭上海人家貧好學涉獵經史性尤篤孝母</span>  
<span style="margin-left: 2em">方氏臥疾久不愈恭憂悴不知所爲乃嚙臂肉作羹</span>  
<span style="margin-left: 2em">啖之疾尋愈父通患蠱疾其弟敬刲股肉爲糜以進</span>  
<span style="margin-left: 2em">亦愈時並稱之</span>  
<span style="margin-left: 1em">國朝張榮一華亭人洪武十九年母楊氏病劇榮一禱</span>  
<span style="margin-left: 2em">天剖腹取肝以進母啖之即愈里人以其事聞</span>  
<span style="margin-left: 2em">詔旌表其門繪像城隍廟成化中猶存</span>  
<span style="margin-left: 1em">沈得四上海人洪武十一年祖母張遘疾危殆得四割</span>  
<span style="margin-left: 2em">股肉食之即愈久之祖父病得四又取肝作湯以進</span>  
<span style="margin-left: 2em">隨飲而瘳鄉老陸辛等上其事下　詔旌表仍徵授</span>  
<span style="margin-left: 2em">太常贊禮郎</span>  
<span style="margin-left: 1em">居宗晟華亭人成化中母張患膈氣疾醫禱弗效宗晟</span>  
<span style="margin-left: 2em">剖胸取肝和酒刲股肉爲湯以進母食之尋愈時母</span>  
<span style="margin-left: 2em">年八十宗晟年五十一矣知縣戴冕聞之下里中覈</span>  
<span style="margin-left: 2em">實將聞于</span>  
<span style="margin-left: 2em">朝不果宗晟張榮一同里人也鄉人至今並稱之</span>  
<span style="margin-left: 4em">人物五<sub class="note-yuan">節義</sub></span>  
<span style="margin-left: 1em">宋衛公佐字輔之其先衛州汲縣人後徙居華亭祖至</span>  
<span style="margin-left: 2em">有文行嘗舉進士公佐少亦業舉子以親老棄去力</span>  
<span style="margin-left: 2em">家政旋被恩命授將仕郎守揚州助教母郁蚤卒事</span>  
<span style="margin-left: 2em">繼母陳盡孝族人女有長而貧不能嫁者雖疏遠必</span>  
<span style="margin-left: 2em">爲擇壻歸之聚書數千卷禮四方賢士以訓其子姪</span>  
<span style="margin-left: 2em">縣未有學捐世業地爲之基且獨任禮殿之役熙寧</span>  
<span style="margin-left: 2em">末大疫且饑死者相枕藉公佐施粥給藥請邑僧靈</span>  
<span style="margin-left: 2em">敏輩分拯之瘞殍死及買棺以葬者無慮萬數邑大</span>  
<span style="margin-left: 2em">夫嘉其義將奏言之公佐辭曰某占籍上等恐爲盛</span>  
<span style="margin-left: 2em">德累療病送死僧行頗有力焉請移以薦僧行大夫</span>  
<span style="margin-left: 2em">義而從之元豐中復饑租稅無所出令秩滿代者已</span>  
<span style="margin-left: 2em">至轉運使苛留之使督逋負纍繫盈庭公佐爲出粟</span>  
<span style="margin-left: 2em">代輸釋繫者而舊令始得解去民相與踵門謝曰微</span>  
<span style="margin-left: 2em">君吾屬將死於縲紲矣年五十八無疾而卒先卒一</span>  
<span style="margin-left: 2em">日展先塋且遍謁親舊若與之訣者歸語家人曰吾</span>  
<span style="margin-left: 2em">生樂善而好施不爲不義今也云亡可謂無憾矣弟</span>  
<span style="margin-left: 2em">公亮公望並敦行義其後子孫蕃盛終宋世宦學不</span>  
<span style="margin-left: 2em">絶膚敏仲達文節皆其後也</span>  
<span style="margin-left: 1em">曹應符字泰叔華亭小蒸人少謹身飭行爲鄉里推重</span>  
<span style="margin-left: 2em">宋景定甲子以明詩經入太學內舍節性齋咸淳初</span>  
<span style="margin-left: 2em">兩領鄉薦甲戌登進士第授迪功郎衢州司户參軍</span>  
<span style="margin-left: 2em">會宋亡遂隱不仕族人光遠中丁未進士辟監華豐</span>  
<span style="margin-left: 2em">莊改軍器監簿宋亡衣冠不改人稱爲大頭巾相公</span>  
<span style="margin-left: 2em">云</span>  
<span style="margin-left: 1em">陸霆龍字伯靈咸淳鄉貢進士禮記都魁宋亡即棲隱</span>  
<span style="margin-left: 2em">講授終其身衣冠不易嘗自贊畫像云勤勤劬劬耽</span>  
<span style="margin-left: 2em">嗜慕悦而不忍舍者聖賢之書趑趑趄趄畏懦退縮</span>  
<span style="margin-left: 2em">而不敢登者世利之途暈輕霞以爲臉縷積雪以成</span>  
<span style="margin-left: 2em">衣衣前後而襜如儼張拱而徐趨或者見之而指笑</span>  
<span style="margin-left: 2em">此必抱遺經行古道之拘儒子居仁在文學類</span>  
<span style="margin-left: 1em">謝國光字觀夫號節齋晉太傅安二十六世孫自六世</span>  
<span style="margin-left: 2em">祖隱居華亭南之立極遂爲邑人宋咸淳癸酉領鄉</span>  
<span style="margin-left: 2em">薦明年上春官以所對策剴切主司畏賈似道不敢</span>  
<span style="margin-left: 2em">取例補太學生宋亡遂不仕元治書侍御史程鉅夫</span>  
<span style="margin-left: 2em">奉詔搜賢或以國光薦輒杜門稱疾以經史自娱至</span>  
<span style="margin-left: 2em">正乙酉卒遺命題其墓曰安節表其志云孫晉字彦</span>  
<span style="margin-left: 2em">明善醫有文行</span>  
<span style="margin-left: 1em">趙孟僴號月麓宋之宗室其先家黃巖景定辛酉年十</span>  
<span style="margin-left: 2em">七及胄舉父訓遲赴南宫遂得游謝南齋歐陽巽齋</span>  
<span style="margin-left: 2em">劉須溪朱約山諸公之門文天祥見之曰是子瑚璉</span>  
<span style="margin-left: 2em">器也咸淳乙亥開江東浙西閫天祥以玉垣從事辟</span>  
<span style="margin-left: 2em">之偕行抵吳僅五十日而大事已去天祥見召環衛</span>  
<span style="margin-left: 2em">王邦傑開門降元授邦傑安撫使孟僴吳江邦固以</span>  
<span style="margin-left: 2em">疾辭遂去吳依親友以居越十年爲道士名道淵居</span>  
<span style="margin-left: 2em">松江北道堂又五年爲僧名順昌因自號三教遺逸</span>  
<span style="margin-left: 2em">改道堂爲本一菴子孫遂爲府人所著詩文名湖山</span>  
<span style="margin-left: 2em">汗漫集內有遥祭文丞相文臨終端坐手辭以訣有</span>  
<span style="margin-left: 2em">云文山之客千古忠貞</span>  
<span style="margin-left: 1em">殷澄字公源華亭胥浦人在宋避諱爲戴氏父某宋節</span>  
<span style="margin-left: 2em">幹官家富好施每大雨雪必載薪米遍乞寒餒人死</span>  
<span style="margin-left: 2em">者爲具棺殮人目爲殷佛子澄性介特平生無宿諾</span>  
<span style="margin-left: 2em">事苟涉大義雖委身不顧元兵入華亭澄避地南錢</span>  
<span style="margin-left: 2em">南錢猶保聚未肯下將軍號楊掃地者怒命屠之澄</span>  
<span style="margin-left: 2em">奮曰我其可無一言而死乎我死今日否亦今日遂</span>  
<span style="margin-left: 2em">扣軍門大言曰夫民猶水也水順則流逆則激民順</span>  
<span style="margin-left: 2em">則寧逆則亂今郡縣新附將軍不撫綏招徠以稱上</span>  
<span style="margin-left: 2em">神武不殺之德顧欲盡勦斯民乎楊怒手劒叱之澄</span>  
<span style="margin-left: 2em">正色曰殺我一人活千萬人我死猶生也語益激烈</span>  
<span style="margin-left: 2em">動人楊感悟而止于時全活者以萬計丞相伯顔聞</span>  
<span style="margin-left: 2em">而義之授華亭軍民都總管使守其地澄即棄去曰</span>  
<span style="margin-left: 2em">大宋氏亡吾以親不亡獨不能逸乎遂野服隱居浦</span>  
<span style="margin-left: 2em">上時放浪九峯二泖間慕其人者目爲泖南浪翁云</span>  
<span style="margin-left: 1em">衛謙字有山一字山甫號山齋尚書仲達六世孫知常</span>  
<span style="margin-left: 2em">州宗武子風神都雅進止可觀初登進士第調丞永</span>  
<span style="margin-left: 2em">嘉未行元師及境樞密董公與語奇之版授漳州龍</span>  
<span style="margin-left: 2em">溪尹辭不就鹽丁楊姓者以妖煽衆掠海上分守千</span>  
<span style="margin-left: 2em">户沙全疑邑民反側將併殲之謙亟詣全開譬以身</span>  
<span style="margin-left: 2em">保無虞事遂獲寢陞温州路治中復辭乃立義莊贍</span>  
<span style="margin-left: 2em">宗族及鄉閭之貧者建義塾教願學而無師者同邑</span>  
<span style="margin-left: 2em">錢參政孫女賣謙家爲婢已劑而知之命家嫗教養</span>  
<span style="margin-left: 2em">三年治奩具擇世族子嫁之其爲義多類此翰林鄧</span>  
<span style="margin-left: 2em">善之趙松雪郡守張西巖皆與爲文字交名人韻士</span>  
<span style="margin-left: 2em">游其門者無虛日遠近識不識皆稱爲衛山齋所著</span>  
<span style="margin-left: 2em">有讀易管見三十卷子德嘉字立禮閉户讀書辟舉</span>  
<span style="margin-left: 2em">皆不就妻亡不再娶獨居垂三十年至正間盜起州</span>  
<span style="margin-left: 2em">里解散德嘉不爲動曰吾當守死先祠下耳時人稱</span>  
<span style="margin-left: 2em">其孝子子剛能詩有江水深深碧梨花淡淡明之句</span>  
<span style="margin-left: 2em">楊鐵崖亟稱之</span>  
<span style="margin-left: 1em">元夏侯尚玄字文卿號石巖華亭人也世業儒幼有大</span>  
<span style="margin-left: 2em">志不拘細行凡閲經史不泥古訓好掩卷深思求之</span>  
<span style="margin-left: 2em">意外爲文字下筆成章嘗作中庸管見聚疑原孟等</span>  
<span style="margin-left: 2em">書皆出先儒議論之表時人稱爲小大白云性坦率</span>  
<span style="margin-left: 2em">不事機械釋老醫藥卜筮方伎諸子之書靡不精究</span>

<span style="margin-left: 2em">真珠數琲直千緡候求者還之尤善醫起死者汴人</span>

<span style="margin-left: 2em">死者內之蒸以蔥藥及旦皮腐而氣復大德間召至</span>

<span style="margin-left: 2em">欲官之力辭瞢於政既而乞歸賜號悦道處士</span>

<span style="margin-left: 2em">中書左丞鑿吳松江以策從行功居多大德戊戌庸</span>  
<span style="margin-left: 2em">田使柳公行水復獻窴閼成隄之法民甚德之丁母</span>  
<span style="margin-left: 2em">艱哀毁盡禮服除大府薦教諭崑山意甚不樂遂辭</span>  
<span style="margin-left: 2em">去嘗游京師王侯鉅公多折節與交章辟屢上知白</span>  
<span style="margin-left: 2em">悉辭謝曰吾聞冀北多奇士庶幾見之豈齪齪求官</span>

<span style="margin-left: 2em">畫掀髯長嘯人莫窺其際四方士夫争內屨願交於</span>

<span style="margin-left: 2em">其情焉</span>  
<span style="margin-left: 1em">笴隱生名瑾不知其姓生上海簳山因自號云幼時嘗</span>
