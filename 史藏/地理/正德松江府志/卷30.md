## 正德松江府志卷之三十　人物四（孝友）人物五（节义）人物六（文学） 人物七（艺术）人物八（隐逸）

<span style="margin-left: 4em">人物四<sub class="note-yuan">孝友</sub></span>  
<span style="margin-left: 1em">唐陆南金字季孙曾祖士季以文学显祖谋道周王府</span>  
<span style="margin-left: 2em">文学详正学士父元感建德历阳二县令朝散大夫</span>  
<span style="margin-left: 2em">黄州司马南金贞观中为太常奉礼郎历鄞令筑隄</span>  
<span style="margin-left: 2em">为湖千顷开元初少卿卢崇道抵罪徙岭南逃还伪</span>  
<span style="margin-left: 2em">称南金吊客突入其舍而道其情南金匿之俄事觉</span>  
<span style="margin-left: 2em">诏御史捕按南金当重法弟赵璧自言匿崇道者我</span>  
<span style="margin-left: 2em">也请死南金固言弟自诬不情御史怪之赵璧曰母</span>  
<span style="margin-left: 2em">未葬妹未归兄能办之我生无益不如死御史惊上</span>  
<span style="margin-left: 2em">状玄宗皆宥之南金知书史操履谨饬张说陆象先</span>  
<span style="margin-left: 2em">称其贤由库部员外郎以疾改太子洗马卒<sub class="note-yuan">初南金治鄞筑隄为湖宋知州李夷庚葺为六梁四牐治平中立祠湖上之青山赐号嘉泽庙追封南金为孚佑侯夷庚为惠应侯</sub></span>  
<span style="margin-left: 1em">元汤文英字孟宽华亭人世笃孝友自华亭徙吴至文</span>  
<span style="margin-left: 2em">英八世同居至元间表其门闾复其家</span>  
<span style="margin-left: 1em">章梦贤字思齐上海青龙人宋秦国庄敏公楶之后孝</span>  
<span style="margin-left: 2em">友通练喜賔客好施惠元至顺初尝出粟二千余石</span>  
<span style="margin-left: 2em">赈乡里辞不受官至元中荐授襄阳等处营田提举</span>  
<span style="margin-left: 2em">建康等处财赋提举以父母蚤亡伯兄又多疾即弃</span>  
<span style="margin-left: 2em">官归终身不仕事其兄如父置义庄以赡宗族建义</span>  
<span style="margin-left: 2em">塾以教乡党子弟兄殁抚其孤如子阖门二百余口</span>  
<span style="margin-left: 2em">未尝有间言子元泽初为丞相府舍人累官奉政大</span>  
<span style="margin-left: 2em">夫江浙财赋副总管以母老亦弃官归养铁崖杨维</span>  
<span style="margin-left: 2em">祯亟称之后以朝列大夫彰德路总管府同知致仕</span>  
<span style="margin-left: 1em">杜英发字俊卿上海人祁国公衍九世孙仕为建宁学</span>  
<span style="margin-left: 2em">正升教授归隐西霞浦上号西霞道人初季父某无</span>  
<span style="margin-left: 2em">后尝养莫氏子为其幼复以英发为后及季父殁悉</span>  
<span style="margin-left: 2em">以产归莫氏子复为之冠娶待之不异同气族困于</span>  
<span style="margin-left: 2em">徭役首倡置义田储粟若干石以资之邻里婚丧皆</span>  
<span style="margin-left: 2em">有给其勇于义如此其赀产不逾中人云</span>  
<span style="margin-left: 1em">徐初字本道华亭青村人蚤丧母父信后母谗初事之</span>  
<span style="margin-left: 2em">益恭父暑月病疽秽恶流衽席初身自浣涤不解带</span>  
<span style="margin-left: 2em">者经月父乃悟曰汝吾孝子也后母子亨少钟爱长</span>  
<span style="margin-left: 2em">不事事初爱之不衰至正丙申浙右警初纠率乡子</span>  
<span style="margin-left: 2em">弟数千备寇或诬其有异志缚送泖上军初当锧厉</span>  
<span style="margin-left: 2em">声曰吾欲反率斥卤氓蹈海去矣尚能戴吾头见将</span>  
<span style="margin-left: 2em">军乎将军欲有土有民必归诸正天下宁有白首贼</span>  
<span style="margin-left: 2em">也帅壮其言释之且荐以官卒不起</span>  
<span style="margin-left: 1em">徐诚字信之上海人元至正间父为金玉局大使尝遇</span>  
<span style="margin-left: 2em">疾医祷皆弗应乃刲股和药以进疾寻愈家甚丰而</span>  
<span style="margin-left: 2em">俭独好施予三族多待以举火庚午辛未岁大侵为</span>  
<span style="margin-left: 2em">𫗴粥以食饿者活万余人</span>  
<span style="margin-left: 1em">金子安字幼仁居上海汉成里七岁失怙事母凌氏得</span>  
<span style="margin-left: 2em">其欢心乡人以孝子称之母尝遘疾子安稽颡北辰</span>  
<span style="margin-left: 2em">求以身代母危困中忽甦曰适神语我而子孝加尔</span>  
<span style="margin-left: 2em">寿三十四后母殁乃三十四月也居丧毁瘁哀痛终</span>  
<span style="margin-left: 2em">其身乡邻有悖伦者往往感激改行尝市地于邻除</span>  
<span style="margin-left: 2em">之得白金一罂亟召其人归之时又多其义</span>  
<span style="margin-left: 1em">赵恭字思恭上海人家贫好学涉猎经史性尤笃孝母</span>  
<span style="margin-left: 2em">方氏卧疾久不愈恭忧悴不知所为乃啮臂肉作羹</span>  
<span style="margin-left: 2em">啖之疾寻愈父通患蛊疾其弟敬刲股肉为糜以进</span>  
<span style="margin-left: 2em">亦愈时并称之</span>  
<span style="margin-left: 1em">国朝张荣一华亭人洪武十九年母杨氏病剧荣一祷</span>  
<span style="margin-left: 2em">天剖腹取肝以进母啖之即愈里人以其事闻</span>  
<span style="margin-left: 2em">诏旌表其门绘像城隍庙成化中犹存</span>  
<span style="margin-left: 1em">沈得四上海人洪武十一年祖母张遘疾危殆得四割</span>  
<span style="margin-left: 2em">股肉食之即愈久之祖父病得四又取肝作汤以进</span>  
<span style="margin-left: 2em">随饮而瘳乡老陆辛等上其事下　诏旌表仍征授</span>  
<span style="margin-left: 2em">太常赞礼郎</span>  
<span style="margin-left: 1em">居宗晟华亭人成化中母张患膈气疾医祷弗效宗晟</span>  
<span style="margin-left: 2em">剖胸取肝和酒刲股肉为汤以进母食之寻愈时母</span>  
<span style="margin-left: 2em">年八十宗晟年五十一矣知县戴冕闻之下里中核</span>  
<span style="margin-left: 2em">实将闻于</span>  
<span style="margin-left: 2em">朝不果宗晟张荣一同里人也乡人至今并称之</span>  
<span style="margin-left: 4em">人物五<sub class="note-yuan">节义</sub></span>  
<span style="margin-left: 1em">宋卫公佐字辅之其先卫州汲县人后徙居华亭祖至</span>  
<span style="margin-left: 2em">有文行尝举进士公佐少亦业举子以亲老弃去力</span>  
<span style="margin-left: 2em">家政旋被恩命授将仕郎守扬州助教母郁蚤卒事</span>  
<span style="margin-left: 2em">继母陈尽孝族人女有长而贫不能嫁者虽疏远必</span>  
<span style="margin-left: 2em">为择壻归之聚书数千卷礼四方贤士以训其子姪</span>  
<span style="margin-left: 2em">县未有学捐世业地为之基且独任礼殿之役熙宁</span>  
<span style="margin-left: 2em">末大疫且饥死者相枕藉公佐施粥给药请邑僧灵</span>  
<span style="margin-left: 2em">敏辈分拯之瘗殍死及买棺以葬者无虑万数邑大</span>  
<span style="margin-left: 2em">夫嘉其义将奏言之公佐辞曰某占籍上等恐为盛</span>  
<span style="margin-left: 2em">德累疗病送死僧行颇有力焉请移以荐僧行大夫</span>  
<span style="margin-left: 2em">义而从之元丰中复饥租税无所出令秩满代者已</span>  
<span style="margin-left: 2em">至转运使苛留之使督逋负累系盈庭公佐为出粟</span>  
<span style="margin-left: 2em">代输释系者而旧令始得解去民相与踵门谢曰微</span>  
<span style="margin-left: 2em">君吾属将死于缧绁矣年五十八无疾而卒先卒一</span>  
<span style="margin-left: 2em">日展先茔且遍谒亲旧若与之诀者归语家人曰吾</span>  
<span style="margin-left: 2em">生乐善而好施不为不义今也云亡可谓无憾矣弟</span>  
<span style="margin-left: 2em">公亮公望并敦行义其后子孙蕃盛终宋世宦学不</span>  
<span style="margin-left: 2em">绝肤敏仲达文节皆其后也</span>  
<span style="margin-left: 1em">曹应符字泰叔华亭小蒸人少谨身饬行为乡里推重</span>  
<span style="margin-left: 2em">宋景定甲子以明诗经入太学内舍节性斋咸淳初</span>  
<span style="margin-left: 2em">两领乡荐甲戌登进士第授迪功郎衢州司户参军</span>  
<span style="margin-left: 2em">会宋亡遂隐不仕族人光远中丁未进士辟监华丰</span>  
<span style="margin-left: 2em">庄改军器监簿宋亡衣冠不改人称为大头巾相公</span>  
<span style="margin-left: 2em">云</span>  
<span style="margin-left: 1em">陆霆龙字伯灵咸淳乡贡进士礼记都魁宋亡即栖隐</span>  
<span style="margin-left: 2em">讲授终其身衣冠不易尝自赞画像云勤勤劬劬耽</span>  
<span style="margin-left: 2em">嗜慕悦而不忍舍者圣贤之书趑趑趄趄畏懦退缩</span>  
<span style="margin-left: 2em">而不敢登者世利之途晕轻霞以为脸缕积雪以成</span>  
<span style="margin-left: 2em">衣衣前后而襜如俨张拱而徐趋或者见之而指笑</span>  
<span style="margin-left: 2em">此必抱遗经行古道之拘儒子居仁在文学类</span>  
<span style="margin-left: 1em">谢国光字观夫号节斋晋太傅安二十六世孙自六世</span>  
<span style="margin-left: 2em">祖隐居华亭南之立极遂为邑人宋咸淳癸酉领乡</span>  
<span style="margin-left: 2em">荐明年上春官以所对策剀切主司畏贾似道不敢</span>  
<span style="margin-left: 2em">取例补太学生宋亡遂不仕元治书侍御史程巨夫</span>  
<span style="margin-left: 2em">奉诏搜贤或以国光荐辄杜门称疾以经史自娱至</span>  
<span style="margin-left: 2em">正乙酉卒遗命题其墓曰安节表其志云孙晋字彦</span>  
<span style="margin-left: 2em">明善医有文行</span>  
<span style="margin-left: 1em">赵孟僴号月麓宋之宗室其先家黄岩景定辛酉年十</span>  
<span style="margin-left: 2em">七及胄举父训迟赴南宫遂得游谢南斋欧阳巽斋</span>  
<span style="margin-left: 2em">刘须溪朱约山诸公之门文天祥见之曰是子瑚琏</span>  
<span style="margin-left: 2em">器也咸淳乙亥开江东浙西阃天祥以玉垣从事辟</span>  
<span style="margin-left: 2em">之偕行抵吴仅五十日而大事已去天祥见召环卫</span>  
<span style="margin-left: 2em">王邦杰开门降元授邦杰安抚使孟僴吴江邦固以</span>  
<span style="margin-left: 2em">疾辞遂去吴依亲友以居越十年为道士名道渊居</span>  
<span style="margin-left: 2em">松江北道堂又五年为僧名顺昌因自号三教遗逸</span>  
<span style="margin-left: 2em">改道堂为本一庵子孙遂为府人所著诗文名湖山</span>  
<span style="margin-left: 2em">汗漫集内有遥祭文丞相文临终端坐手辞以诀有</span>  
<span style="margin-left: 2em">云文山之客千古忠贞</span>  
<span style="margin-left: 1em">殷澄字公源华亭胥浦人在宋避讳为戴氏父某宋节</span>  
<span style="margin-left: 2em">干官家富好施每大雨雪必载薪米遍乞寒馁人死</span>  
<span style="margin-left: 2em">者为具棺殓人目为殷佛子澄性介特平生无宿诺</span>  
<span style="margin-left: 2em">事苟涉大义虽委身不顾元兵入华亭澄避地南钱</span>  
<span style="margin-left: 2em">南钱犹保聚未肯下将军号杨扫地者怒命屠之澄</span>  
<span style="margin-left: 2em">奋曰我其可无一言而死乎我死今日否亦今日遂</span>  
<span style="margin-left: 2em">扣军门大言曰夫民犹水也水顺则流逆则激民顺</span>  
<span style="margin-left: 2em">则宁逆则乱今郡县新附将军不抚绥招徕以称上</span>  
<span style="margin-left: 2em">神武不杀之德顾欲尽勦斯民乎杨怒手劒叱之澄</span>  
<span style="margin-left: 2em">正色曰杀我一人活千万人我死犹生也语益激烈</span>  
<span style="margin-left: 2em">动人杨感悟而止于时全活者以万计丞相伯颜闻</span>  
<span style="margin-left: 2em">而义之授华亭军民都总管使守其地澄即弃去曰</span>  
<span style="margin-left: 2em">大宋氏亡吾以亲不亡独不能逸乎遂野服隐居浦</span>  
<span style="margin-left: 2em">上时放浪九峰二泖间慕其人者目为泖南浪翁云</span>  
<span style="margin-left: 1em">卫谦字有山一字山甫号山斋尚书仲达六世孙知常</span>  
<span style="margin-left: 2em">州宗武子风神都雅进止可观初登进士第调丞永</span>  
<span style="margin-left: 2em">嘉未行元师及境枢密董公与语奇之版授漳州龙</span>  
<span style="margin-left: 2em">溪尹辞不就盐丁杨姓者以妖煽众掠海上分守千</span>  
<span style="margin-left: 2em">户沙全疑邑民反侧将并歼之谦亟诣全开譬以身</span>  
<span style="margin-left: 2em">保无虞事遂获寝升温州路治中复辞乃立义庄赡</span>  
<span style="margin-left: 2em">宗族及乡闾之贫者建义塾教愿学而无师者同邑</span>  
<span style="margin-left: 2em">钱参政孙女卖谦家为婢已剂而知之命家妪教养</span>  
<span style="margin-left: 2em">三年治奁具择世族子嫁之其为义多类此翰林邓</span>  
<span style="margin-left: 2em">善之赵松雪郡守张西岩皆与为文字交名人韵士</span>  
<span style="margin-left: 2em">游其门者无虚日远近识不识皆称为卫山斋所著</span>  
<span style="margin-left: 2em">有读易管见三十卷子德嘉字立礼闭户读书辟举</span>  
<span style="margin-left: 2em">皆不就妻亡不再娶独居垂三十年至正间盗起州</span>  
<span style="margin-left: 2em">里解散德嘉不为动曰吾当守死先祠下耳时人称</span>  
<span style="margin-left: 2em">其孝子子刚能诗有江水深深碧梨花淡淡明之句</span>  
<span style="margin-left: 2em">杨铁崖亟称之</span>  
<span style="margin-left: 1em">元夏侯尚玄字文卿号石岩华亭人也世业儒幼有大</span>  
<span style="margin-left: 2em">志不拘细行凡阅经史不泥古训好掩卷深思求之</span>  
<span style="margin-left: 2em">意外为文字下笔成章尝作中庸管见聚疑原孟等</span>  
<span style="margin-left: 2em">书皆出先儒议论之表时人称为小大白云性坦率</span>  
<span style="margin-left: 2em">不事机械释老医药卜筮方伎诸子之书靡不精究</span>  
<span style="margin-left: 2em">其为人绝无崖岸边幅见者皆不意其为儒及即而</span>  
<span style="margin-left: 2em">问焉莫不惊服乐道人之善诲人惟恐其不逮为人</span>  
<span style="margin-left: 2em">谋必尽忠而不求报与人言不问交之浅深辄倾倒</span>  
<span style="margin-left: 2em">肺腑一无所隐颇为险僻者所乘或县计时事必出</span>  
<span style="margin-left: 2em">众见之外或非笑之后果如其言众咸服大德间游</span>

<span style="margin-left: 2em">梦掘地得大小墨数百笏遂善属文长好游名山至</span>  
<span style="margin-left: 2em">正间自具区道毗陵渡江抵淮泗以直言干在位者</span>  
<span style="margin-left: 2em">弗用还读书簳下著史补断丹崖夜啸金声录玉露</span>  
<span style="margin-left: 2em">吟各若干卷一室晏如或劝之仕则曰大丈夫仕当</span>  
<span style="margin-left: 2em">为天下除残刬暴否则不如抱膝坐耳乃终其身</span>  
<span style="margin-left: 1em">陆厚城东人有田十双有宅一区宅东有圃自号东园</span>  
<span style="margin-left: 2em">散人貌古岸长身虬髯博洽经史尤精孙吴氏书方</span>  
<span style="margin-left: 2em">兵变时将官闻其人觅不可得或往来天目灵岩苕</span>  
<span style="margin-left: 2em">霅间兵息返故庐放浪三泖中或竟夕忘返幼时尝</span>  
<span style="margin-left: 2em">遇异人得子午按摩法疗人疾不施针𤋲对坐笑谈</span>  
<span style="margin-left: 2em">顷即脱去未尝受人直或劝之仕不应有诗集若干</span>  
<span style="margin-left: 2em">卷号古渔唱</span>  
<span style="margin-left: 1em">陆泳字伯翔隐居大蒸尽心农事采方言习俗作田家</span>  
<span style="margin-left: 2em">五行以占丰歉杨廉夫陆居仁为叙而传之</span>  
<span style="margin-left: 1em">蔡训字君立号东郊上海仕族子与江阴孙作善元末</span>  
<span style="margin-left: 2em">兵乱变姓名隐吴中事定筑室汉成里扁曰东郊草</span>  
<span style="margin-left: 2em">堂孙作为记称其出人忧患进退从容真知去就早</span>  
<span style="margin-left: 2em">见明识之士云</span>  
<span style="margin-left: 1em">孙稷字长庆郡人言行谨饬尝举为文学官兵兴遂不</span>  
<span style="margin-left: 2em">仕读书卖药于横云山之支陇名其居曰小山招隐</span>  
<span style="margin-left: 2em">江阴王逢为之辞</span>  
<span style="margin-left: 1em">国朝任继祖字季伦松乡先生之曾孙惇重贞悫喜读</span>  
<span style="margin-left: 2em">书于理无所不究笃于践履不尚浮华且勇于为义</span>  
<span style="margin-left: 2em">遇患难辄倾囊济之洪武末以子贵封鄱昜知县进</span>  
<span style="margin-left: 2em">封韶州府同知而布素自如暇日躬灌园植蔬以自</span>  
<span style="margin-left: 2em">适郡大夫数造其庐亦不往见尝谓人曰士之为士</span>  
<span style="margin-left: 2em">无间穷达当审进退不可同流合污以为通不可矫</span>  
<span style="margin-left: 2em">时干誉以为高循其分守其道惟日孳孳毙则斯已</span>  
<span style="margin-left: 2em">舍此则非吾为士者之事与人交善别臧否识萧山</span>  
<span style="margin-left: 2em">魏文靖公于少年期以公辅及卒公为之铭</span>  
<span style="margin-left: 1em">张年字公寿华亭人慷慨高简善为文永乐中再征不</span>  
<span style="margin-left: 2em">起隐于医治疗若神所著有杏园稾时称为杏园先</span>  
<span style="margin-left: 2em">生</span>  
<span style="margin-left: 1em">俞寰字允宁青村人朴愿沉静喜读书工词赋医药卜</span>  
<span style="margin-left: 2em">筮斵琴刻篆无所不通然不求人知甘贫守分终岁</span>  
<span style="margin-left: 2em">不一入城府故人亦少知之者世降俗末士大夫没</span>  
<span style="margin-left: 2em">溺声利以失其真者何限鸿冥陆沉如斯人亦可尚</span>
