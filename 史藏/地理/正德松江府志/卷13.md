## 正德松江府志卷之十三　学校下（书说义塾附）

<span style="margin-left: 4em">学校下</span>  
<span style="margin-left: 1em">华亭县学在府西南徐家桥之东本县人徐进义塾也</span>  
<span style="margin-left: 2em">学始建于宋元祐中在今府学后玉带河之阳尊贤</span>  
<span style="margin-left: 2em">坊内即今射圃魁星楼地端平间迁于河南以其址</span>  
<span style="margin-left: 2em">为阅武亭及学升府学复建县学于旧址<sub class="note-yuan">按杨维祯至正九年记县学本燕居之所则阅武尝为燕居周伯琦府学记十九年作燕居堂于学北不言旧为阅武</sub>元</span>  
<span style="margin-left: 2em">至大初刘尹庆建夫子庙延祐间张尹国英构讲堂</span>  
<span style="margin-left: 2em">至正中楚尹恭张尹德昭继为缮理而学乃粗备丙</span>  
<span style="margin-left: 2em">申毁于兵以其地为府学射圃<sub class="note-yuan">重修学记华亭县学在府治东南二百步按前志繇宋端平县令杨公瑾之所开拓堂殿斋舍廊庑庖廥始具焉至国朝县升松江府学亦升府学土田儒籍皆隶之县复立頖宫于府庠北旧燕居之所也至大初刘某来典邑始构大成殿并仪门两庑延祐己未令张国英复构讲堂及设祭器至正癸未县令楚恭修灵星门缭以崇墉而学之规稍完历年未久而栋宇有弗支者其址尚湫隘周旋升降有弗堪者至正九年春县长养安海涯县令张德昭释菜之际愓然相谓曰学校教之出守令教之行学校废何以资守令之理乎命教谕王伦谋更作之而费未知所出乃告丞簿帖木儿不花兀都马沙俾谕邑士愿新学校者听于是淀山谢庭兰与其姪晋并力从事经始于是年之二月阅三月而告成大成殿增辟后室殿之侧剏学官廨又前后筑石塘以捍水蚀啮于是凡柱石之欹倾者正之椽榈之朽蠧者易之丹青之漫漶者饰之下及庾库庖湢什伯之具无不完整既竣事乃伐石以二侯之命征记于余余尝悼井牧闾师之废而先王之教废后之为治者亦难矣贫富相悬虽使臯陶持刑不能禁彊不侮弱伦理弗明虽使姬旦制礼不能革贱不僭贵此非教何赖哉故朝廷以六事命守令而教为之首然而不知治本者视学校如眡传舍其教民者无实政已职教者又素非冠带之望其佐令者无实教已士之在上者既无躬行实履在下者又可责其有实学乎令无实政师无实教士无实学而望风俗之美人才之兴不亦难乎华亭古号文物之邦而其地卑下沮洳民性轻戾而媮靡易叛于教令邑侯以兴学校为先务师儒以作成士类为急功邑之人士又能不负循令长贤师儒教养为实学吾见华亭复旧时文物之盛而无其轻戾媮靡之风且使他邑于是乎劝礼令之得治名者不在是乎不在是乎遂以复二侯俾刻为记是年五月杨维祯记杜本书篆教谕姜德昭立石</sub></span>  
<span style="margin-left: 1em">国朝洪武三年知县冯荣奉　诏立学始即义塾为之</span>  
<span style="margin-left: 2em">甲寅知县周朗新作大成殿嗣令祝子宪以学舍卑</span>  
<span style="margin-left: 2em">陋廓而新之进子彦裕力任其事于是明伦观頣二</span>  
<span style="margin-left: 2em">堂博文约礼二斋缭垣翼室习射之圃凡学之制悉</span>  
<span style="margin-left: 2em">备丙辰知县朱直新教官廨名其堂曰知本丁卯大</span>  
<span style="margin-left: 2em">成殿坏御史黄克庸新之仍建文昌祠于㦸门之右</span>  
<span style="margin-left: 2em"><sub class="note-yuan">新学记华亭旧学在今府治之南自元至元间县升为府学亦隶焉由是改燕居堂为县学后厄于兵燹今之学则徐氏义塾也初县人徐进始创于县南割私田一万亩有奇招延明师以淑里子弟西建大成殿堂庑戟门春秋祀先圣先师至我朝始更为县学及教谕束宗癸训导胡铉金声朱武李象贤相继而至陋其规模弗称修废举坠思有以作新之志未克就洪武七年春郡守王公文贞祗谒庙庭退而延儒师讲经义诸生升揖拜肩摩踵蹑不容周旋乃与知县祝子宪议廓而新之会部符下郡县以民屋之籍官者修葺庙学将募邑之好义者以相其役进之子彦裕闻而请曰此吾先子志也敢不身任其责郡守喜而义之于是拓学东地重建明伦堂三间夹以翼室则东西斋重门两庑缭以周垣高爽明垲轮奂翚飞论讲有堂肄业有斋藏修有室与夫习射之宫庖湢之庐靡不毕具士之来游来歌者日增月盛未几知县朱直来视事学校之事知无不为作育后进增光前人入其门衿佩之容济济如也登其堂弦诵之音锵锵如也由是华亭之学遂甲于他县矣时教谕曹宗儒训导钱震谢南万权实主之董是役者沈文进也予谓学校之兴废关世运之盛衰曩年学廪充溢悉为游食所蠧职教者鲜有易一椽加一甓者今以枵然之宫而气象一新如此是虽贤守令之所举倡徐氏父子之所经营其亦斯文气运之所关与虽然庠序学校之设自三代以来已然非直为观美而已人伦明于上小民亲于下国家化民成俗之义实原于此故堂以明伦名崇所本也凡师之所以教弟子之所以学舍是其何以哉他日教成德立蒸髦汇升迩之事父远之事君以行其所学无负圣贤垂训则亦无负圣朝乐育人材之意云洪武十年春二月初吉永嘉曹睿记吴兴钱震书并篆额射圃记古者天子之制诸侯岁献贡士于天子天子试之于射宫其容体比于礼其节奏比于乐而中多者得与于祭钦惟圣天子龙飞之明年稽古建学命立射圃学宫之旁华亭旧学毁于兵知县董侯原芳即徐氏义塾为县学拓学东空地为射圃正东而西向焉未几周侯朗踵至创屋一所以为射位布侯栖革翿旌荐俎之属靡不毕具既而祝侯子宪朱侯直相继视事又扩而新之乃扁之曰观德堂于是射圃之规模为称诸生之射始习九年大霖雨自夏四月至于秋九月垣之圮者相属雀鼠之穿墉者不一圃具废矣职教者屡以为言有司以岁荐饥弗暇葺今年春鄱阳蒋侯惠来宰是邑教谕曹宗儒首言及之侯乃集教官耆年考制度定疆界绵亘凡百有余步广如其五之一实其地若干亩白诸府准例蠲租税于是量工命日因故堂更诸爽垲固其版筑正其正鹄居无何民不扰而事集侯乃登其堂招诸生而习射焉绘为图将刻诸石请文以记夫射之有圃所以肄诸生而习礼乐也是故弦木为弓剡木为矢而教以五射之法岂尚一发而已哉弓人有言本心不正则脉理皆邪弓虽劲而发矢不直木之心且不可不正况学者之心乎二三子既勉克勤所事必有见于斯他日贡之朝廷而就试焉其进退必能比于礼其节奏必能比于乐溯流求源正己正人而远近莫不一于正如此始副皇朝兴学之美意则亦无负蒋侯勉励之心云洪武十一年岁次戊午夏六月望日前进士曲江钱惟善记知本堂记嘏之友曹公仲博典教华亭克尽厥心条约之严化道之笃一时鲜俪焉深患学者从事于文辞章句之末而忘反求密察之功不足以知圣贤之渊源精义之攸当也乃取朱子福州经史阁记中语名其燕居之堂曰知本以示警焉间来求文以为记嘏谨告之曰窃观朱子于圣贤之书讲论问辩句而求之本末先后小大精粗毫分缕析无复余蕴及其教人又必使知为学之有本不待求之于外而后可庶几焉则其忧世之意至深切矣盖简册所载宇宙间事皆吾分内事也反而求之不外乎一心学者朝诵暮习精思力究果有能知其心体之大而推致其用者乎察之深养之厚而周流不滞者乎苟于此而致其力焉是则知本之大者彼博文多识之士诵其言辞解其训诂咀咽其查滓研穷其糟粕考据愈详援引愈多而支离愈甚缠绕文字而贼害其本心则自欺自弃之甚者谓之善学可乎昔上蔡谢氏自负记诵该博程伯子谓其玩物丧志及观伯子读史则又不蹉一字是固不可与迂生曲学者论也师弟子登斯堂而游焉息焉观感契会岂无可望者乎知其切己而不厌不倦从容涵泳而有得焉则其所至何可量哉请以是谂诸同志庶乎因余之言而勉之也夫堂作于洪武九年实知县朱侯建教官廨之中一室也侯庐陵人讳直字子良由刑部主事调知广德府建平县事秩满授前职曹公名宗儒其先永嘉人又明年秋七月丁丑松江府儒学训导河东王嘏谨记知松江府华亭县事鄱阳蒋惠书吴兴钱震篆额修殿记华亭学在府治南元末毁于兵今学则徐氏义塾也洪武改元我国家平浙西二年诏兴天下学校三年知县冯荣始迁于此而大成殿庳隘弗称七年知县周朗始命邑民邹德之徐卿而更新之当时亟成不为久远计故不数年而梁栋圮坏而桷腐桡今年春三月十九日风雨大作自中栋庑廊一夕倾圮切近圣座后既责毁则前势愈危懔然有朝夕之忧适监察御史临川黄公克庸以杂事至郡越三日展礼庙下顾而叹曰兹非吾之责邪时邑长贰以下咸缺未几池阳李启先来主簿即命董其事李奉命惟谨虽病弗辍既而知府云南何赐知县刘均俊相继而至各捐己俸以倡而乡之好义者张示周思诚等亦以赀来助于是鸠工聚材倾昃者正之腐桡者易之坏于上者覆之剥于下者甓之漫漶于其间者涂塈而丹艧之至于葺两庑新文昌祠凡昔之未备者今皆完美经始于四月二十日讫工于闰六月十六日诸生以其成之不易也乃具颠末俾凯记之凯时以训导摄学事其敢以荒陋辞窃惟道在天地间亘万古而不易尧舜禹汤文武周公既以之治天下而吾夫子则以之教万世故有天下者必设学校必崇庙庭然后人心有所系属如百工之居肆则志不迁而事可成也奈何向之为政者每以狱讼征科为急风化之所自出者漫不加省遂致零落颓败而不可枝梧是可叹也自非风纪之司临莅于上贤有司倡率于下则何以致轮焉奂焉如此哉虽然非直为观美也自此以往士子来游来歌者睹兹清庙肃瞻圣容其必有得于观感之间而兴起焉者他日礼义兴行贤才辈出使江海之上蔼然有洙泗之风无负国家从来教养之意则自今日始也猗欤盛哉洪武二十年九月吉日训导袁凯为文前承事郎太常典簿顾禄隶古儒士陶九成篆额试知县胡友谅县丞余民德主簿蒋圭典史李杲同立石</sub>永乐丙</span>  
<span style="margin-left: 2em">申学舍坏于风雨丁酉知县高宫重修<sub class="note-yuan">邑人张廷昱出费宣力居多见教谕章鲁先记</sub>宣德丙午大理寺卿胡概改作明伦堂复</span>  
<span style="margin-left: 2em">为堂于其后榜曰进修<sub class="note-yuan">教谕林辅董其役府同知王源记</sub>正统己未</span>  
<span style="margin-left: 2em">推官杨政重建大成殿新㦸门及两庑庚申提学御</span>  
<span style="margin-left: 2em">史彭朂辟射圃于学东隙地<sub class="note-yuan">先是改旧圃以为董漕</sub>癸亥知县</span>  
<span style="margin-left: 2em">李希容作观德亭教谕程完义训导胡穗赵建相其</span>  
<span style="margin-left: 2em">役<sub class="note-yuan">重修殿记洪武戊辰予初典教华亭释菜之日周览学宫自殿宇堂斋以至门庑庖廪之所地位虽非广衍而规制整肃缔构完固称乎育真之区也仰瞻圣殿文采焕然盖予未至前训导李处仁所作袁凯为之记予深有赖焉居六年以内艰去固岿然也自初建立距今五十余年海滨多飓风雷雨震荡拔木飘瓦天地为之昏黯由是昔之岿然者积微至故积故至敝栋桡梁腐桷坠檐摧彩绘漫漶丹漆蒙翳典教事钱唐杨益舜江陈宾庐陵胡穗深以为忧欲有所为顾力不逮庐陵杨君惟敩由监察御史来典松江府刑狱闻之慨然有志更作经营图为者久之乃谋诸郡守赵君于听讼之际简阅平民之延及情有可矜法有所疑悉从宽贷俾就于赎于是其徒乐从积二年凡得材木甎甓若干及工人之费百需之具充充乎其有余矣遂度材庀工经始于正统二年冬之仲月落成于四年十月乙酉殿之崇高加故十尺深广各加八尺规摹改观轮奂一新惟敩与学之师徒谓予昔尝处此求为之记大凡为政欲教化其民者必先用力于学校谓之知本若夫徭赋征输狱讼论决簿书期会一切急于功效者虽曰能事而于政则末矣为学者诵诗读书工于文词朝夕孜孜急于进取一切以就功名虽有近效其为学不亦末乎继自今诸君之从游于斯者于于然雍雍然肃瞻圣容有所观感退而致力端其趋向崇德义以敦实行去枝叶以求本根将见道德明秀之士彬彬然胥此焉出皆能明体适用振声华于当世流惠泽于无穷庶几不负朝廷教育之恩守令作兴之意惟敩奉扬之美予虽衰老与有光荣引领云间寸心千里诸君子幸勗之哉正统四年冬至前三日前史官国子祭酒兼翰林侍讲嘉议大夫太子宾客致仕豫章胡俨撰奉政大夫修正庶尹吏部郎中兼经筵侍书郡人夏衡书丹赐进士出身嘉议大夫行工部右侍郎庐陵周忱篆额知府豫同知高龄通判潘俊经历许诚知事王礼照磨王峘俸华亭县知县县丞童凤邓鼎刘彬典史袁海供匠镌</sub>成化壬辰知县戴冕修殿廊饰</span>
