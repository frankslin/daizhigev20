## 正德松江府志卷之十五　坛庙

<span style="margin-left: 4em">坛庙</span>  
<span style="margin-left: 3em">府境诸神祠自郡邑通祀及先贤外其不应祭法</span>  
<span style="margin-left: 3em">者多矣以所从来久故不得而泯焉亦因以观俗</span>  
<span style="margin-left: 3em">也</span>  
<span style="margin-left: 1em">本府社稷坛在通波门外旧志府西北二里后废为教</span>  
<span style="margin-left: 2em">场元贞初知府张之翰祀于西湖书院至大初知府</span>  
<span style="margin-left: 2em">季禄儿移置太平桥西宋造船场际留仓也</span>  
<span style="margin-left: 1em">国朝洪武二年迁于此<sub class="note-yuan">社坛记华亭在浙东西实一壮县不但称雄于嘉禾而已故钱谷狱讼簿书视他邑为剧令自朝至暮或继以烛犹恐弗给何暇问社稷之祀哉县社坛在西北隅岁久倾圮荒基穨垣祭屋壁立春秋祈报第举故事退则未尝一顾而问嗟夫县盖古子男之邦也古者诸侯始封天子取太社之土按以方色苴以白茅赐之使至国封社遂有其土今此礼虽无此意元末之泯有民社者奈何不敬信安徐民瞻好古之士也始来领县事临阅坛壝兴叹久之于是召匠计工命僧祖隆视役土木一新越明年毕事二月戊寅社用牲于坛酌奠有位升降有次祝史荐信神明顾𢾚父老观瞻莫不叹息以为前此未之覩也亟以书走奉常谒余为记予曰君真所谓不忘其本者昔唐永徽间州尚淫祀往往不立社稷独一建州刺史叙立祀场以取重当世如君又有过人者以日不睱给而能为人所不为不忘其本君子于是乎可以观政矣故书而俾之石刻承议郎太常博士钟必万记太常丞史弥远书并题额重修记社五土示稷五谷示或曰稷五土中原隰之示皆主生育之神也帝高阳以句龙为社柱为稷而社稷之祀始立高辛唐虞夏因之商旱以弃代柱周因之以句龙配社弃配稷主象位置坛土方色玉牲币乐祭服时日与所立本上下有差而社稷之祀始备然曰配则社稷固有神龙弃特配之之神尔后汉建武二年诏郡县置社稷太守令长特祠二八月及腊岁三祠而社稷之祀始广梁加祀灵星风伯雨师之属时用春仲秋仲而无腊祀周日用甲隋易以戊今郡县得春秋仲月上戊日祀社稷风雨之属实始于汉而备于隋也华亭为东南壮县赋产緐阜生育之功神寔主焉国朝升松江府社稷仍旧无变置居城西南陬主象倾欹坛级圮毁地削于民草木于羊滋有年矣职郡者三岁一易任视己寓犹传舍矧社稷疏远乎徒以祀有常宪莫敢废遇当祀夜分一俯伏丽奠而退心神忘斋修之诚牲醴忽芳涤之洁倾毁削牧尚加䘏耶宜神吐而弗歆历数年旱涝无宁秋禳祷弗至若无神焉元统甲戌镇阳申侯来守谒祠下瞻叹怵忸力新祠事取办于己不伤财劳民衙休必躬督焉未几倾者树毁者筑削者复而牧者屏坛位崇庳一新如式东社西稷雨雷附稷西却少南北咸主面以东为右北为上遵制典也环祠为屋大小十有七楹缭以周垣神门阍舍幕次庖湢靡不毕具东西为步二十有八南北四十有七作于至元二年之春正月夏五落成府阴阳教授白公实相厥工图址属曰民非社稷无以爰稼穑社稷微侯罔以安神栖今而后有弗祀祀必神歆有弗祷祷必受福吾惧而民知社稷之功忘侯所以致神之功请记之侯大夫之贤者仆事之久知之深自侯来守建风坛饰公馆儒而庠校书院神而金山祠武安祠医而惠民局兴坠补弊罔不葺完社稷则报谷育而禳旱溢者也关民命尤急务民义而敬鬼神惟侯有之故诺其请而述其概庶几与侯共治于今继治于后者视侯之功为法鍳前之职郡者为戒至元丙子八月云间布衣陆居仁记承直郎松江府判官李希颜书篆奉政大夫松江府达鲁花赤兼劝农事暗都剌等立石</sub></span>  
<span style="margin-left: 1em">风云雷雨境内山川神坛在集僊门外官绍塘上元制</span>  
<span style="margin-left: 2em">风师坛在府治东北清修寺前雷雨坛附稷右</span>  
<span style="margin-left: 1em">国朝洪武二年迁于此并山川城隍祀之</span>  
<span style="margin-left: 1em">东海神坛在柘林洪武十六年建</span>  
<span style="margin-left: 1em">郡厉坛在通波门外濠上洪武三年建</span>  
<span style="margin-left: 1em">五土五谷神坛每里一所洪武十五年建</span>  
<span style="margin-left: 1em">乡厉坛同上今附郭并于土谷坛寓祭</span>  
<span style="margin-left: 1em">城隍庙在谷市桥西兴圣塔院后初在今府治西宋政</span>  
<span style="margin-left: 2em">和间迁于东南今盟素道院之侧元至正二年知府</span>  
<span style="margin-left: 2em">杨伯野台拓地改建丙戌毁邦人孙明绪成之</span>  
<span style="margin-left: 1em">国朝洪武三年知府林庆即兴圣寺殿址作今庙景泰</span>  
<span style="margin-left: 2em">庚午灾知府平重建弘治己酉知府刘璟重修<sub class="note-yuan">元峡州路总管府经历吴暾记政治通乎神明教化移乎风俗古人所以先成民而后致力于神也松江濒海为郡当众水积流之汇雨则侵其西垂旱则亢其东境苟非感通以协二气之和存诚以其百灵之佑则不足以召丰穰而安生聚也况积𡚁之余民浮俗汰仍岁荡沃日虑流散不能以为治至元庚辰知府杨公来守此土究心民瘼厉志官政刬奸剔蠧锄疆栉梗抚靡洗涤刮刷激扬上下胥和远迩丕变爰相府署屋老弗支乃大新治事之堂重葺严更之庋黟垩门庑򐈪甃径术仪容制度阛阓改观既又酾河道以流行壅滞治沟塍以隄防潦溢由是慨念夫明则礼乐幽则鬼神土地人民之众莅其上者既有以安其居则骘而相之独无其神者乃请城隍祠恭致祷禬以格灵祉而栋宇庳陋衢路偪塞邻伍湫隘像设漫患大惧非所报效首揭私帑六千缗售拓基地东西延广一百尺南北长袤达于通衢凡一百一十尺相旧庙不足以起瞻仰徙为后寝购工募材营建前殿璇题翚飞觚棱角峙周阿焕彩级陛森严拱以序庑缭以闬闼凭附之质揭妥之具丹青彩施金碧动荡俨然鍳临如神斯在祀事孔严登降有怿经始于至正元年三月以二年正月竣事凡用缗钞五万是岁水波减缩岁以大稔田无侵没河不遏淤民用大和官赋早集咸谓神之赐侯之德也吏民将镵石实诸庙请予记之予谓县之祀城隍盖古者八蜡祭坊与水庸之遗事意自中都达于天下莫不拜而事之盖人生日用之功近者惟土与水耳筑之而高雉堞连云浚之而深陴濠绕郭皆先王设险为守御之固以其所以养人者卫人然则粲然为国之纪纲者在人隐然为人之藩屏者非神其谁赖然则府公之兴是役也益知理之一致而崇明祀之意深矣郡吏季泰既董其事而郡人陈显悉力赞助且将寿公之祠于侧垂于永久予故为记之公名伸字公正晋宁绛州人慈惠为师恩威相济凡有所为动为世法故民皆勤于趋事可谓治郡之最者矣庙之住持李若东曰是庙故宋杨知县瑾建于淳祐丁未九十八年矣今太守为同姓乃复改大而重建焉盖亦神之有待数之相符也</sub></span>
