## 正德松江府志卷之二十　寺观下

<span style="margin-left: 4em">寺观下</span>  
<span style="margin-left: 1em">上海丛林</span>  
<span style="margin-left: 1em">观音禅寺在县西宋崇宁初建淳熙三年赐额慈报禅</span>  
<span style="margin-left: 2em">院从钱参政良臣请也僧觉印开山元毁</span>

<span style="margin-left: 2em">古柏即遗址也归并寺二院一庵二<sub class="note-yuan">寺记佛氏以慈悲为教欲民趋仁爱同于善不教而善者固为上教而后善者众矣若吴越俗信祥而易杀病且忧则聚巫用卜立神杀牲至再三不可则曰神不置我矣乃饬死事以死故小民户易耗而畜字不孳董之礼则顽惟浮图教慈而语大病且忧有告焉则俾之戒杀以向善可因以佐教化长民者多尚之观音寺在上海县西十八里时有观音圣像浮海而来咸异之无不归仰云门禅师七世孙觉印钱参政舍资创于宋崇宁年为县禅宗首刹元季兵变废为瓦砾洪武壬戌僧会本源性公修举废坠与其徒绍一募建法堂前观音像流寓九峰间梦于性舟载以复庚午性公殁明年一公募建观音殿东西庑法轮宝藏三年住持本山甲戌县尹张守约捐赀建大佛殿丁丑买民房建天王殿及山门庚辰尹杜镒复营香积厨一所自后檀施云集法堂钟楼以次而举像设旛盖靡不悉备凡立屋若干楹拓地若干亩征予记惟一师自受戒具衣不缯纩食不重味晨夕严其道偕耆旧绍圆惟普等誓葺斯寺以复旧观以毕其师之志弘宣其教大劝于时迷者咸赖不命而献力不祈而荐货仅二十余年地得以复其胜教得以弘其化俾人皆去鬼息杀而咸趋于仁爱创业垂绪因果无量是宜碑之以示诸后庶嗣而葺之以垂不朽永乐二年岁次甲申年月日上海县儒学教谕西昌尹务厚撰</sub></span>

<span style="margin-left: 2em">庆重建后废僧善达复新之归并院一庵三<sub class="note-yuan">寺记上海松之属邑法华上海之属寺在邑治之西一十八里宋开宝间僧慧为开山第一代元至大初云翁庆禅师大振土木之功为兹山中兴之祖赵文敏公壻海道千户费雄佐之甚力首建大雄殿赵公书额普应国师中峰和尚三过其寺后废于寺田之多重徭艰役僧皆散去沙门善达叹曰田多则寺废无产则寺兴其兴兆于今乎乃以寺田数十顷悉与佃户故寺无一墢之土庭无一吏之迹屋废者渐兴僧散者复集甍摧栋桡者易以坚木万瓦鳞集四簷翚飞安藏之殿转法之轮售于人者赎之先是以甲乙住兹山国朝洪武二十四年清理佛教立为四方禅林请一公象先董其事三十有二年天台沙门智勇捧檄出住兹山善达念无以延住持造方丈以居之无堂以集云水建僧堂若干楹以栖之达倦于事迺属其孙如䥔以代䥔赞住山如其祖与夫演法之堂庖库湢溷之室凡丛林所宜有者悉备达以俭约自持护常住物如己赀专修浄业临终念佛泊然而逝洪武三十五年夏五月也号西原上海人俗姓金十岁从僧叔能公出家兹寺久之首忏于上天竺复回松之延庆为第二座云䥔苏人也今住山智勇号无敌昔掌竺坟于中天竺为白云禅师说公之嗣其住法华也初获西源力赞继获如䥔股肱故能建诸堂宇轮奂一新永乐癸未达孙维箕募诸施者范铜为钟以割昏晓无敌以状至峰顶乞文为记余尝博观勤旧之于住山不怠则忌怠者不能为窃哂主者之为忌者不复为背憎主者之为况克力赞者乎今观法华诸士慧公竺山为开山之祖庆公云翁为中兴之人达为之兴复䥔为之建造吁寺耆之于住山视怠忌者得无媿乎遂为之记永乐四年岁在丙戌三月既望径山佛幻老人上虞沙门心泰撰</sub></span>

<span style="margin-left: 2em">二<sub class="note-yuan">寺记云间为浙右壮邑乃野畛所建虽下乡僻里海堧江浦之聚亦土壤衍沃民俗蕃庶积帑之家所向而有皆乐善好施以浮屠氏为依倚故幢刹之严参错相望西林去邑不十里东越黄浦又东而汇北其南抵周浦皆不及半舍寺之在周浦者曰永定有黄浦者曰宁国而西林居其中盖所谓江浦之聚也里故无寺绍兴戊寅有比丘师浄行化爰止亟思启导里人培植胜业请于迪功刘均及长者孙氏得地百亩创庵以憇游包未几正信响应乃益自奋厉广求潜度日以增斥为路逮淳熙间而法堂方丈斋庐库藏轮奂一新嘉定初又得永定七古佛就供堂上即之以求福者尤众先是浄梦白莲七枝擢秀于堂之所谂为瑞相拟作大殿于其处未遂而寂其徒道晖嗣之因徐昌纯劝发运属叶君纯裕为大檀越鸠材庀工毕力兴建卒成其师之志以奉所得七佛者前梦至是符焉晖之法兄道全又致叶君亨珉营缔轮藏饰以众宝载三乘法巨镛范金华鲸肖桐诸庄严具靡不称是而寺之全体既先定矣淳祐壬寅始白之礼部甲辰乃符钱唐积善寺废额甲乙焚修式延云水而浄之派孙文暕复募作重门缭垣以谨中外之限绪役悉周遂与永定宁国鼎峙而立大不竞雄小不慊卑翼翼靓深丹碧相辉林烟野霭之中化城倐现眉目一境嘻亦盛矣相厥繇兴固以土俗沃庶大家好施之力有以致之然师浄启导有初志愿坚果安能成就殊胜如此予尝识晖之子文僖于竺峰一日拏扁舟问予泽居谒纪述之文以图不朽夫三世协勤四檀委输载祀九十厥有成绩乃似乃续龛灯炉穟誓以丰年美俗回向盛明其事有可尚者故受简而不辞盖尝论之甲乙序承所以杜外攘毁圮之患也彼其传持之外滥窃成风掩袭而来卷蓄而去视所任之废兴若越人视秦人肥瘠此诚末世丛席之弊至于为甲乙者独无弊哉继已完之业享不为之功有房榻以自安无规级以相持贪营利养则赀益厚而业益增择取便私则身愈佚而行愈玷举前人劳苦之所办适以为容非蕴慝之地曾市区贾肆之不若者则其弊又在此不在彼由之而致覆者辙相蹈也可不切监而痛革之乎予雅有叹于是故因僖之请得诵言以遗之于以贻戒来者其必思经创之艰难念信施之勤厚日夜求其师之所以为教者勉策胜进茂养斯人之善心俾能顺保其沃庶富乐之盛以相与绵及于无穷之众各获其所愿云淳祐庚戌十月既望蒙城高子凤撰</sub></span>

<span style="margin-left: 2em">初名九品观堂元大德中改今额归并寺二庵一<sub class="note-yuan">重建寺记姬运讫录儒牾其时而西域教兴焉教虽兴于西域然与中华诸士尚远绝殊甚至汉明帝始释秘梦以肖其像筑鸿胪外馆以居其徒译梵音以通华言而后天下之趋其教者日新月盛莫究始之所以远且绝者其故何哉盖蠉飞蠕动含生之伦莫不畏苦而趋乐员首方趾最灵之品莫不跂高而好胜故佛氏以大雄笼万物以大觉悟万化以大智空万事鼓性命之说付诸深隐之士倡因果之论精入鬼神之域又况愚昧之徒血气充于内嗜欲惑于外不足而后争有余而后肆欺诬巧伪皆欲弗为而不能自已至虽吾儒圣贤复生而居之莫化一旦闻其祸福利害之说悉欲舍身竭产而皈向恐后呜呼非其教曷足以诱是哉松之吴汇镇有南浄土讲寺盖宋淳祐间创也元末兵毁国朝洪武间宿德相继寺兴而教著宣德间复毁正统初古田基公来行业峻茂无愧诸前闻人而言建殿堂像设供养之具焕然华美有逾于古制作盖与其徒正因等协心于兹十有五寒暑矣乃命因诣僧录乞积中实公为记以镵诸石而里人某等相与议曰吾里中子弟业儒致用者既不乏人然赖其教而破迷涂抉障碍者亦不加少是宜谒吾儒名能者纪之而取其有功于斯土予谓佛去今千有余岁西浄土去中国亦万有余里何以此为浄而今可佛乎彼必曰吾不右是佛而以心为佛不彼为浄而以心为浄故视万古一瞬息也包万土一恒河沙也何有今古亦何有彼此殊不知以此为佛而所见何性以心为浄而所适何土万物并育而无害也万化与俱而无迹也万事一寂而无染也其道又安在彼必有说乎某等咸默然起谢曰吾将扣诸古田而来复翰林院检讨钱溥撰</sub></span>

<span style="margin-left: 2em">焉归并庵二<sub class="note-yuan">石函观音殿记凡神物寄托宇宙间其去来不常显晦有时虽若圣智莫有得其朕者劒埋酆邑气腾斗牛宝发陈仓光集祠宇是皆寓于有形而几于无形者其灵变翕忽犹若此况佛菩萨应身阐化神超像外而不同于一物者乎虽然机感之妙莫测非探颐索隐孰能与于斯淳熙间青龙镇有畦地为圃者中广丈许艺之不生溉之散流夜有祥光上烛遂发之得大石函贮观音像夹纻为质冠衣俨如杨枝浄缾在左右手云披月满姿相殊特见者惊叹寺邻沈氏倾槖赎之奉安明心寺之西坛宝庆丁亥震风发屋像失其蔽既而阴有所启更有金采彰施迎买法堂僧了胜瞻仰欣敬有创殿意蕴而未言淳祐壬寅秋一夕厨钥自开像立于地莫审其故胜独感之礼请归房甲辰春胜故疾作忽梦丽服而璎珠者慈视以拊之既觉失疾所在于是罄赀聚卖衣盂得缗万计为营缔倡其徒忠玉竭力募众佐成之肇自丙午三月洎九月毕工华池涌云雕甍翥空冠三门翼两庑以次具举题璇砌襄涂饰精好一境正信咸获依归凡有祷求犹交臂接耳靡不响答噫嘻异哉盖大士与此土众生有大因缘乘机此感无乎不在方其深閟上中函盖重密若是其晦也而殊祥所形有如酆劒倐尔呈露及具安作绀宇百宝庄严若是其显也而幻相所成又如陈宝不可执然则土木之系性等虚空三身既然四德无减故知其来非显其去非晦无去无来无晦无显又孰得而测之若夫十方刹土之广千万亿生之众不之他所而之明心不属余人而属了胜其与秦文之获张华之逢亦一理也发于不测之谓机契于无私之谓感其若是哉予不识胜与玉而识其孙戒月于谢亭葛井间他日忽欵予泽居持乃祖所授简求文为记莫得而辞故为序次其事并论人物机感之妙用信于后云淳祐十年三月蒙城高子凤记</sub></span>
