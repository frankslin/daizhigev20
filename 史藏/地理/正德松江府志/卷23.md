## 正德松江府志卷之二十三　官迹上

<span style="margin-left: 4em">宦迹上</span>  
<span style="margin-left: 3em">守令有题名矣履历存劝戒昭矣然而劝者非徒</span>  
<span style="margin-left: 3em">以其名而化导旬宣与有功于疆埸者类也故具</span>  
<span style="margin-left: 3em">录其行事如左呜呼百世之下有闻而兴曰斯贤</span>  
<span style="margin-left: 3em">也尝辱莅吾土焉又非徒吏之劝也</span>  
<span style="margin-left: 1em">晋虞潭字思奥会稽余姚人吴骑都尉翻之孙宜都守</span>  
<span style="margin-left: 2em">忠之子也清贞有检操以军功赐爵都亭东乡侯历</span>  
<span style="margin-left: 2em">宗正卿会稽内史征拜尚书进零陵县侯苏峻反潭</span>  
<span style="margin-left: 2em">守吴兴加督三吴晋陵宣城义兴五郡军事与郄鉴</span>  
<span style="margin-left: 2em">王舒协同义举陶侃假潭节监杨州浙江西军事遣</span>  
<span style="margin-left: 2em">督护沈伊距管商于吴县为商所败潭自贬寻而峻</span>  
<span style="margin-left: 2em">平转镇东将军吴国内史以前后功进爵武昌县侯</span>  
<span style="margin-left: 2em">徙会稽内史未发还复吴郡时军荒之后百姓饥馑</span>  
<span style="margin-left: 2em">死亡涂地潭表出仓米赈救又修沪渎垒以防海钞</span>  
<span style="margin-left: 2em">百姓赖之咸康中进卫将军卒赠左光禄大夫谥孝</span>  
<span style="margin-left: 2em">烈孙啸久兄子谷并吴国内史</span>  
<span style="margin-left: 1em">袁崧陈郡阳夏人琅琊太守方平子嗣长合候少负才</span>  
<span style="margin-left: 2em">名博学有文章著后汉书百篇历秘书监吴国内史</span>  
<span style="margin-left: 2em">孙恩作乱吴会承平日久人不习战所在多破亡吴</span>  
<span style="margin-left: 2em">国内史桓谦出奔崧筑沪渎垒缘海备恩明年恩复</span>  
<span style="margin-left: 2em">入浃口转宼沪渎害崧浮海而北刘裕等并军蹑之</span>  
<span style="margin-left: 2em">大破于沪渎恩赴海死<sub class="note-yuan">崧部人海盐李祥突白刃收崧归葬后人表祥居为孝义里</sub></span>  
<span style="margin-left: 1em">唐张聿琅琊人宰华亭治政凛然民吏有犯初必恕之</span>  
<span style="margin-left: 2em">许以自新书姓名罪由于籍名定命录再犯必举籍</span>  
<span style="margin-left: 2em">勘照杖之非死不已每怒则曰县令既谬不柰汝何</span>  
<span style="margin-left: 2em">赖有木县令耳盖谓杖也凡有府吏赋外之需量力</span>  
<span style="margin-left: 2em">受数直榜邑门曰府以某事下县索某物若干期某</span>  
<span style="margin-left: 2em">日齐足县以辞泛数承实目事不虚张期必前办应</span>  
<span style="margin-left: 2em">县管百姓各自度量户口轻重较筭分厘早急送官</span>  
<span style="margin-left: 2em">庶免出吏胥施杖罚民感其诚供输络绎无违拒者</span>  
<span style="margin-left: 2em">人指揭示为赤心榜尝有猾儒以干乞为业入其界</span>  
<span style="margin-left: 2em">闻耕者歌曰华亭君子来及几时老稚免疾苦远近</span>  
<span style="margin-left: 2em">无渴饥安得九重天子知儒曰此政不可挠也遂抵</span>  
<span style="margin-left: 2em">他境<sub class="note-yuan">出王沂公清异录</sub></span>  
<span style="margin-left: 1em">苏籥宰华亭在官简惠莅事公正</span>  
<span style="margin-left: 1em">包某延陵人初辟秀才德宗时宰华亭辟田野僧户口</span>  
<span style="margin-left: 2em">均赋爱人顾况尝记其厅事之壁</span>  
<span style="margin-left: 1em">宋叶清臣字道卿宝元初按漕本路时盘龙汇为患酾</span>  
<span style="margin-left: 2em">为新渠道直流速其患遂弭又建议疏沪渎入海民</span>  
<span style="margin-left: 2em">赖其利</span>  
<span style="margin-left: 1em">吴及字几道皇祐间宰华亭时浙西旱蝗苏秀尤甚及</span>  
<span style="margin-left: 2em">祷于横山之神天即大雨蝗亦避境不食其稼至秋</span>  
<span style="margin-left: 2em">大稔乃教民预修水利以待淫潦明年大水而阡陌</span>  
<span style="margin-left: 2em">坚完沟洫通利复稔如初比三年家给人足风俗归</span>  
<span style="margin-left: 2em">厚歌诵满路及去父老悲啼攀留不得进至空一邑</span>  
<span style="margin-left: 2em">随之其后四十余年犹思之不置初及在官尝作亭</span>  
<span style="margin-left: 2em">于西湖名曰环碧后令刘鹏因民之思改曰思吴详</span>  
<span style="margin-left: 2em">见朱之纯诗序</span>  
<span style="margin-left: 1em">沈辽字叡达杭州钱塘人翰林学士遘之弟自幼挺拔</span>  
<span style="margin-left: 2em">不群长而好学读左氏传班固书模倣辄似因兄任</span>  
<span style="margin-left: 2em">监嘉州酒税熙宁初为审官西院主簿初受知王安</span>  
<span style="margin-left: 2em">石及安石当国更张新法辽与论事不合罢去久之</span>  
<span style="margin-left: 2em">以太常奉礼郎监杭州军资库转运使使摄华亭县</span>  
<span style="margin-left: 2em">它使者有宿憾思中以文法因县民忿争连及下狱</span>  
<span style="margin-left: 2em">夺官流永州更赦徙池州筑室齐山上名曰云巢杜</span>  
<span style="margin-left: 2em">门隐几为文章雄奇峭丽与曾巩苏轼黄庭坚以诗</span>  
<span style="margin-left: 2em">倡酬竟不再起</span>  
<span style="margin-left: 1em">李夔字斯和其先江南人唐末避乱徙邵武家焉元丰</span>  
<span style="margin-left: 2em">三年进士调秀州华亭尉转奉议郎除江淮荆浙六</span>  
<span style="margin-left: 2em">路制置发运司句当公事不赴改授佥书平江军节</span>  
<span style="margin-left: 2em">度推官尝摄郡事适累政因循之后狱系甚众夔命</span>  
<span style="margin-left: 2em">数吏分条所犯不日皆决遣之官至京西南路安抚</span>  
<span style="margin-left: 2em">使子纲维纶纲相高宗赠太师卫国公</span>  
<span style="margin-left: 1em">刘鹏元祐庚午宰华亭下车一日先修庠序次立教诫</span>  
<span style="margin-left: 2em">以至簿书期会各有条理在官不十旬一境告治弦</span>  
<span style="margin-left: 2em">歌堂艮阁三山亭思吴堂皆其所作朱之纯有诗</span>  
<span style="margin-left: 1em">毛渐绍圣中为转运副使浙部水溢被患者数州乃奏</span>  
<span style="margin-left: 2em">疏浙西诸浦浚吴淞江开大盈顾会二浦以入于江</span>  
<span style="margin-left: 2em">自是水不为患</span>  
<span style="margin-left: 1em">郭三益字慎求海盐人家义兴瑑之子也元祐三年进</span>  
<span style="margin-left: 2em">士才高有器识为常熟丞常平使者调苏湖常秀四</span>  
<span style="margin-left: 2em">州之人濬青龙江分地程役三益所部前期告办使</span>  
<span style="margin-left: 2em">者留之俾助他邑不如期者三益即引所部归使者</span>  
<span style="margin-left: 2em">怒檄追甚急三益为戚其母周曰青龙之役连数郡</span>  
<span style="margin-left: 2em">其分地程役赋廪食宜皆已上闻今我先毕何名复</span>  
<span style="margin-left: 2em">役之使者倘再思行悔矣虽然汝不可无会第无以</span>  
<span style="margin-left: 2em">所部从也三益如教已而使檄止丞勿来事遂已</span>  
<span style="margin-left: 1em">姚舜明字廷辉越州嵊县人政和间知华亭县宣和初</span>  
<span style="margin-left: 2em">改知昆山钦宗朝为御史伪楚之际挺节不污南渡</span>  
<span style="margin-left: 2em">后至户部侍郎卒赠太师子宪字令则累官至参知</span>  
<span style="margin-left: 2em">政事</span>  
<span style="margin-left: 1em">丘崈字宗卿江阴军人历国子博士丞相虞允文荐其</span>  
<span style="margin-left: 2em">才迁太常博士知秀州时华亭捍海堰废咸潮岁入</span>  
<span style="margin-left: 2em">坏并海田苏湖皆被其害崈奏创筑三月堰成三州</span>  
<span style="margin-left: 2em">斥卤复为良田除直秘阁知平江改两浙转运副使</span>  
<span style="margin-left: 2em">卒谥忠定</span>  
<span style="margin-left: 1em">龚相字圣任历阳人元祐党人兵部侍郎原之孙父澈</span>  
<span style="margin-left: 2em">通判江宁府相绍兴间知华亭县甚著声绩遂家吴</span>  
<span style="margin-left: 2em">中子颐正有文名尝著中兴忠义录续释常谈皆行</span>  
<span style="margin-left: 2em">于世</span>  
<span style="margin-left: 1em">姜诜为两浙转运副使隆兴中浙西水溢民大饥诜相</span>  
<span style="margin-left: 2em">地便宜浚河置闸邑民德之相与立石以颂详见水</span>  
<span style="margin-left: 2em">类</span>  
<span style="margin-left: 1em">孙岘字举善以词学擢第官中书舍人淳熙初为浙西</span>  
<span style="margin-left: 2em">提举以措置支还亭户本钱及增卖盐袋兴修水利</span>  
<span style="margin-left: 2em">有劳除直敷文阁两浙转运判官</span>  
<span style="margin-left: 1em">王珏字德全荆公安石之孙也绍兴二年起家盐官丞</span>  
<span style="margin-left: 2em">方年壮累行令事邑人安之秀州岁以钱给亭民煮</span>  
<span style="margin-left: 2em">盐至十五年积十九万七千余缗不给民诉于朝除</span>  
<span style="margin-left: 2em">珏提举浙西茶盐逾年尽偿亭民且嬴钜万开华亭</span>  
<span style="margin-left: 2em">海河二百余里盐滋得流通且资以溉田经界法行</span>  
<span style="margin-left: 2em">甚害者三百六十余事其七千二百余户为尤病珏</span>  
<span style="margin-left: 2em">奏除之兼提点刑狱正大辟重而轻者三人死而生</span>  
<span style="margin-left: 2em">者五人移湖南提举官至直敷文阁太府少卿卒于</span>  
<span style="margin-left: 2em">吴县横山之第</span>  
<span style="margin-left: 1em">罗点字春伯抚州崇仁人擢进士第二淳熙中由校书</span>  
<span style="margin-left: 2em">郎除浙西提举规画荒政凡数十奏躬行畎亩实惠</span>  
<span style="margin-left: 2em">甚博先是昆山华亭之间有淀山湖泄诸水道戚里</span>  
<span style="margin-left: 2em">豪彊之家占以为田水由是壅点廉得其实奏请开</span>  
<span style="margin-left: 2em">濬且为图以献上从其言百姓勇于赴功不日而毕</span>  
<span style="margin-left: 2em">所济田百万亩性孝友端介不为矫激或谓天下事</span>  
<span style="margin-left: 2em">非才不办点曰当论其心心苟不正才虽过人何足</span>  
<span style="margin-left: 2em">取后官至签书枢密院卒谥文恭</span>  
<span style="margin-left: 1em">刘颖字公实衢州西安人绍兴二十七年进士历官知</span>  
<span style="margin-left: 2em">铅山常熟二县常熟素繁剧颖降心条理更以治称</span>  
<span style="margin-left: 2em">王佐荐颖为选人日已为刘珙器重改任常熟上应</span>  
<span style="margin-left: 2em">公家之求下抚百姓之隐政声籍甚召监进奏院历</span>  
<span style="margin-left: 2em">大常丞兼兵部郎官提举浙西常平还淀山湖以泄</span>  
<span style="margin-left: 2em">吴松江二水禁民侵筑毋使逼塞大流民田赖之终</span>  
<span style="margin-left: 2em">宝谟阁直学士</span>  
<span style="margin-left: 1em">颜师鲁字几圣漳州龙溪人绍兴中进士历国子丞江</span>  
<span style="margin-left: 2em">东提举改使浙西役法敝甚细民至以鸡豚甖榻折</span>  
<span style="margin-left: 2em">产力遇役辄破家师鲁下教属邑预正流水籍稽其</span>  
<span style="margin-left: 2em">役之序宽比限免代输咸便安之盐课岁百钜万本</span>  
<span style="margin-left: 2em">钱久不给亭灶私鬻禁不可止刑辟日緐师鲁撙帑</span>  
<span style="margin-left: 2em">缗尽偿宿负戒官吏毋侵移比旁路课独最上谓执</span>  
<span style="margin-left: 2em">政曰儒生能办事如此</span>  
<span style="margin-left: 1em">詹体仁字元善建宁浦城人初后其舅张氏既复为詹</span>  
<span style="margin-left: 2em">少有异材乡举第一始冠第进士历泉州晋江丞宰</span>  
<span style="margin-left: 2em">相梁克家荐升太学博士摄金部郎中光宗即位提</span>  
<span style="margin-left: 2em">举浙西常平务为民除害兴利谓浙右之有漕渠非</span>  
<span style="margin-left: 2em">止通馈运资国信往来而已苏秀常润田之高仰者</span>  
<span style="margin-left: 2em">实赖之于是开漕渠浚练湖置斗门为旱潦备</span>  
<span style="margin-left: 1em">徐谊字子宜一字宏父温州人乾道八年进士累官太</span>  
<span style="margin-left: 2em">常丞知徽州移提举浙西常平尝论水利之切于时</span>  
<span style="margin-left: 2em">者曰昔下流不疏而水上溢故凿直曲港还三江故</span>  
<span style="margin-left: 2em">道开宜兴百渎所以顺导下流也惟高原田径乃潴</span>  
<span style="margin-left: 2em">堰之尔昔之言水如单锷郏亶皆是也今开吴松江</span>  
<span style="margin-left: 2em">下流与宜兴百渎属之海者无虑数十百所异时浦</span>  
<span style="margin-left: 2em">港磬折以趋海今近浦之民多取径直疏决苏湖常</span>  
<span style="margin-left: 2em">秀旧为泽国比年雨或后至种且不入盖围田众而</span>  
<span style="margin-left: 2em">疏导多也小人见利不畏其害围于浅水既为高田</span>  
<span style="margin-left: 2em">围于茭荡既为稻田二俱不已复有下脚始之重陂</span>  
<span style="margin-left: 2em">太半为平始之良田背水自晒十日不雨农废作业</span>  
<span style="margin-left: 2em">然且承用旧说又将疏之失利害之实矣故旧田沟</span>  
<span style="margin-left: 2em">浍当濬治围田下脚无辄开已开未填当捺合今之</span>  
<span style="margin-left: 2em">言水者能行是三说则高原旧田还为衍沃而农不</span>  
<span style="margin-left: 2em">病矣入为吏部郎守右司郎中宁宗朝知临安建康</span>  
<span style="margin-left: 2em">隆兴三府卒谥忠文</span>  
<span style="margin-left: 1em">孙子秀字元实绍兴余姚人绍定五年进士调吴县主</span>  
<span style="margin-left: 2em">簿有妖人称水仙太保知府王遂将使治之莫敢行</span>  
<span style="margin-left: 2em">独子秀奋然请往焚其庐碎其像沈其人于太湖曰</span>  
<span style="margin-left: 2em">实汝水之名矣妖遂绝日诣学宫与诸生讨论义理</span>  
<span style="margin-left: 2em">辟淮东总领所中酒库历知衢吉二州开庆初为浙</span>  
<span style="margin-left: 2em">西提举常平先是丞相丁大全以私人为之尽夺亭</span>  
<span style="margin-left: 2em">民盐本钱充献羡之数不足则估籍虚摊一路骚动</span>  
<span style="margin-left: 2em">亭民流亡子秀还前政盐本钱五十余万贯奏省华</span>  
<span style="margin-left: 2em">亭茶盐分司官定衡量之非法多取者于是流散复</span>  
<span style="margin-left: 2em">业</span>  
<span style="margin-left: 1em">黄震字东发庆元府慈溪人宝祐四年进士调吴县尉</span>  
<span style="margin-left: 2em">吴多豪势家告私责则以属尉民多饥冻窘苦死尉</span>  
<span style="margin-left: 2em">卒手震至不受责家告申白提刑孙子秀移文一路</span>  
<span style="margin-left: 2em">禁戢其患县民有小争有司俾尉罗弓矢以捕怨家</span>  
<span style="margin-left: 2em">必曰躬亲而吏卒渔猎以困民又请于知府洪寿自</span>  
<span style="margin-left: 2em">是讼牒无躬亲之文尉廨舍𬯎压震一新之县界有</span>  
<span style="margin-left: 2em">焚人亭为风雷所坏浮屠规欲剙置震白之府谓焚</span>
