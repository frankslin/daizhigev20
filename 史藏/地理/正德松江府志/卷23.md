## 正德松江府志卷之二十三　官跡上

<span style="margin-left: 4em">宦蹟上</span>  
<span style="margin-left: 3em">守令有題名矣履歷存勸戒昭矣然而勸者非徒</span>  
<span style="margin-left: 3em">以其名而化導旬宣與有功于疆埸者類也故具</span>  
<span style="margin-left: 3em">錄其行事如左嗚呼百世之下有聞而興曰斯賢</span>  
<span style="margin-left: 3em">也嘗辱莅吾土焉又非徒吏之勸也</span>  
<span style="margin-left: 1em">晉虞潭字思奥會稽餘姚人吳騎都尉翻之孫宜都守</span>  
<span style="margin-left: 2em">忠之子也清貞有檢操以軍功賜爵都亭東鄉侯歷</span>  
<span style="margin-left: 2em">宗正卿會稽內史徵拜尚書進零陵縣侯蘇峻反潭</span>  
<span style="margin-left: 2em">守吳興加督三吳晉陵宣城義興五郡軍事與郄鑒</span>  
<span style="margin-left: 2em">王舒協同義舉陶侃假潭節監楊州浙江西軍事遣</span>  
<span style="margin-left: 2em">督護沈伊距管商於吳縣爲商所敗潭自貶尋而峻</span>  
<span style="margin-left: 2em">平轉鎮東將軍吳國內史以前後功進爵武昌縣侯</span>  
<span style="margin-left: 2em">徙會稽內史未發還復吳郡時軍荒之後百姓饑饉</span>  
<span style="margin-left: 2em">死亡塗地潭表出倉米賑救又修滬瀆壘以防海鈔</span>  
<span style="margin-left: 2em">百姓賴之咸康中進衛將軍卒贈左光禄大夫謚孝</span>  
<span style="margin-left: 2em">烈孫嘯久兄子谷並吳國內史</span>  
<span style="margin-left: 1em">袁崧陳郡陽夏人琅琊太守方平子嗣長合候少負才</span>  
<span style="margin-left: 2em">名博學有文章著後漢書百篇歷秘書監吳國內史</span>  
<span style="margin-left: 2em">孫恩作亂吳會承平日久人不習戰所在多破亡吳</span>  
<span style="margin-left: 2em">國內史桓謙出奔崧築滬瀆壘緣海備恩明年恩復</span>  
<span style="margin-left: 2em">入浹口轉宼滬瀆害崧浮海而北劉裕等并軍躡之</span>  
<span style="margin-left: 2em">大破於滬瀆恩赴海死<sub class="note-yuan">崧部人海鹽李祥突白刃收崧歸葬後人表祥居爲孝義里</sub></span>  
<span style="margin-left: 1em">唐張聿琅琊人宰華亭治政凜然民吏有犯初必恕之</span>  
<span style="margin-left: 2em">許以自新書姓名罪由于籍名定命錄再犯必舉籍</span>  
<span style="margin-left: 2em">勘照杖之非死不已每怒則曰縣令既謬不柰汝何</span>  
<span style="margin-left: 2em">賴有木縣令耳蓋謂杖也凡有府吏賦外之需量力</span>  
<span style="margin-left: 2em">受數直榜邑門曰府以某事下縣索某物若干期某</span>  
<span style="margin-left: 2em">日齊足縣以辭泛數承實目事不虛張期必前辦應</span>  
<span style="margin-left: 2em">縣管百姓各自度量户口輕重較筭分釐早急送官</span>  
<span style="margin-left: 2em">庶免出吏胥施杖罰民感其誠供輸絡繹無違拒者</span>  
<span style="margin-left: 2em">人指揭示爲赤心榜嘗有猾儒以干乞爲業入其界</span>  
<span style="margin-left: 2em">聞耕者歌曰華亭君子來及幾時老稚免疾苦遠近</span>  
<span style="margin-left: 2em">無渴飢安得九重天子知儒曰此政不可撓也遂抵</span>  
<span style="margin-left: 2em">他境<sub class="note-yuan">出王沂公清異錄</sub></span>  
<span style="margin-left: 1em">蘇籥宰華亭在官簡惠莅事公正</span>  
<span style="margin-left: 1em">包某延陵人初辟秀才德宗時宰華亭闢田野僧户口</span>  
<span style="margin-left: 2em">均賦愛人顧況嘗記其廳事之壁</span>  
<span style="margin-left: 1em">宋葉清臣字道卿寶元初按漕本路時盤龍匯爲患釃</span>  
<span style="margin-left: 2em">爲新渠道直流速其患遂弭又建議疏滬瀆入海民</span>  
<span style="margin-left: 2em">賴其利</span>  
<span style="margin-left: 1em">吳及字幾道皇祐間宰華亭時浙西旱蝗蘇秀尤甚及</span>  
<span style="margin-left: 2em">禱于横山之神天即大雨蝗亦避境不食其稼至秋</span>  
<span style="margin-left: 2em">大稔乃教民預修水利以待淫潦明年大水而阡陌</span>  
<span style="margin-left: 2em">堅完溝洫通利復稔如初比三年家給人足風俗歸</span>  
<span style="margin-left: 2em">厚歌誦滿路及去父老悲啼攀留不得進至空一邑</span>  
<span style="margin-left: 2em">隨之其後四十餘年猶思之不置初及在官嘗作亭</span>  
<span style="margin-left: 2em">于西湖名曰環碧後令劉鵬因民之思改曰思吳詳</span>  
<span style="margin-left: 2em">見朱之純詩序</span>  
<span style="margin-left: 1em">沈遼字叡達杭州錢塘人翰林學士遘之弟自幼挺拔</span>  
<span style="margin-left: 2em">不羣長而好學讀左氏傳班固書模倣輒似因兄任</span>  
<span style="margin-left: 2em">監嘉州酒稅熙寧初爲審官西院主簿初受知王安</span>  
<span style="margin-left: 2em">石及安石當國更張新法遼與論事不合罷去久之</span>  
<span style="margin-left: 2em">以太常奉禮郎監杭州軍資庫轉運使使攝華亭縣</span>  
<span style="margin-left: 2em">它使者有宿憾思中以文法因縣民忿争連及下獄</span>  
<span style="margin-left: 2em">奪官流永州更赦徙池州築室齊山上名曰雲巢杜</span>  
<span style="margin-left: 2em">門隱几爲文章雄奇峭麗與曾鞏蘇軾黃庭堅以詩</span>  
<span style="margin-left: 2em">倡酬竟不再起</span>  
<span style="margin-left: 1em">李夔字斯和其先江南人唐末避亂徙邵武家焉元豐</span>  
<span style="margin-left: 2em">三年進士調秀州華亭尉轉奉議郎除江淮荆浙六</span>  
<span style="margin-left: 2em">路制置發運司句當公事不赴改授僉書平江軍節</span>  
<span style="margin-left: 2em">度推官嘗攝郡事適累政因循之後獄繫甚衆夔命</span>  
<span style="margin-left: 2em">數吏分條所犯不日皆決遣之官至京西南路安撫</span>  
<span style="margin-left: 2em">使子綱維綸綱相高宗贈太師衛國公</span>  
<span style="margin-left: 1em">劉鵬元祐庚午宰華亭下車一日先修庠序次立教誡</span>  
<span style="margin-left: 2em">以至簿書期會各有條理在官不十旬一境告治絃</span>  
<span style="margin-left: 2em">歌堂艮閣三山亭思吳堂皆其所作朱之純有詩</span>  
<span style="margin-left: 1em">毛漸紹聖中爲轉運副使浙部水溢被患者數州乃奏</span>  
<span style="margin-left: 2em">疏浙西諸浦浚吳淞江開大盈顧會二浦以入于江</span>  
<span style="margin-left: 2em">自是水不爲患</span>  
<span style="margin-left: 1em">郭三益字慎求海鹽人家義興瑑之子也元祐三年進</span>  
<span style="margin-left: 2em">士才高有器識爲常熟丞常平使者調蘇湖常秀四</span>  
<span style="margin-left: 2em">州之人濬青龍江分地程役三益所部前期告辦使</span>  
<span style="margin-left: 2em">者留之俾助他邑不如期者三益即引所部歸使者</span>  
<span style="margin-left: 2em">怒檄追甚急三益爲戚其母周曰青龍之役連數郡</span>  
<span style="margin-left: 2em">其分地程役賦廩食宜皆已上聞今我先畢何名復</span>  
<span style="margin-left: 2em">役之使者倘再思行悔矣雖然汝不可無會第無以</span>  
<span style="margin-left: 2em">所部從也三益如教已而使檄止丞勿來事遂已</span>  
<span style="margin-left: 1em">姚舜明字廷輝越州嵊縣人政和間知華亭縣宣和初</span>  
<span style="margin-left: 2em">改知崑山欽宗朝爲御史僞楚之際挺節不污南渡</span>  
<span style="margin-left: 2em">後至户部侍郎卒贈太師子憲字令則累官至參知</span>  
<span style="margin-left: 2em">政事</span>  
<span style="margin-left: 1em">丘崈字宗卿江陰軍人歷國子博士丞相虞允文薦其</span>  
<span style="margin-left: 2em">才遷太常博士知秀州時華亭捍海堰廢鹹潮歲入</span>  
<span style="margin-left: 2em">壞並海田蘇湖皆被其害崈奏創築三月堰成三州</span>  
<span style="margin-left: 2em">斥鹵復爲良田除直秘閣知平江改兩浙轉運副使</span>  
<span style="margin-left: 2em">卒謚忠定</span>  
<span style="margin-left: 1em">龔相字聖任歷陽人元祐黨人兵部侍郎原之孫父澈</span>  
<span style="margin-left: 2em">通判江寧府相紹興間知華亭縣甚著聲績遂家吳</span>  
<span style="margin-left: 2em">中子頤正有文名嘗著中興忠義錄續釋常談皆行</span>  
<span style="margin-left: 2em">于世</span>  
<span style="margin-left: 1em">姜詵爲兩浙轉運副使隆興中浙西水溢民大饑詵相</span>  
<span style="margin-left: 2em">地便宜浚河置閘邑民德之相與立石以頌詳見水</span>  
<span style="margin-left: 2em">類</span>  
<span style="margin-left: 1em">孫峴字舉善以詞學擢第官中書舍人淳熙初爲浙西</span>  
<span style="margin-left: 2em">提舉以措置支還亭户本錢及增賣鹽袋興修水利</span>  
<span style="margin-left: 2em">有勞除直敷文閣兩浙轉運判官</span>  
<span style="margin-left: 1em">王珏字德全荆公安石之孫也紹興二年起家鹽官丞</span>  
<span style="margin-left: 2em">方年壯累行令事邑人安之秀州歲以錢給亭民煮</span>  
<span style="margin-left: 2em">鹽至十五年積十九萬七千餘緡不給民訴于朝除</span>  
<span style="margin-left: 2em">珏提舉浙西茶鹽逾年盡償亭民且嬴鉅萬開華亭</span>  
<span style="margin-left: 2em">海河二百餘里鹽滋得流通且資以溉田經界法行</span>  
<span style="margin-left: 2em">甚害者三百六十餘事其七千二百餘户爲尤病珏</span>  
<span style="margin-left: 2em">奏除之兼提點刑獄正大辟重而輕者三人死而生</span>  
<span style="margin-left: 2em">者五人移湖南提舉官至直敷文閣太府少卿卒于</span>  
<span style="margin-left: 2em">吳縣横山之第</span>  
<span style="margin-left: 1em">羅點字春伯撫州崇仁人擢進士第二淳熙中由校書</span>  
<span style="margin-left: 2em">郎除浙西提舉規畫荒政凡數十奏躬行畎畝實惠</span>  
<span style="margin-left: 2em">甚博先是崑山華亭之間有澱山湖洩諸水道戚里</span>  
<span style="margin-left: 2em">豪彊之家占以爲田水由是壅點廉得其實奏請開</span>  
<span style="margin-left: 2em">濬且爲圖以獻上從其言百姓勇於赴功不日而畢</span>  
<span style="margin-left: 2em">所濟田百萬畝性孝友端介不爲矯激或謂天下事</span>  
<span style="margin-left: 2em">非才不辦點曰當論其心心苟不正才雖過人何足</span>  
<span style="margin-left: 2em">取後官至簽書樞密院卒謚文恭</span>  
<span style="margin-left: 1em">劉穎字公實衢州西安人紹興二十七年進士歷官知</span>  
<span style="margin-left: 2em">鉛山常熟二縣常熟素繁劇穎降心條理更以治稱</span>  
<span style="margin-left: 2em">王佐薦穎爲選人日已爲劉珙器重改任常熟上應</span>  
<span style="margin-left: 2em">公家之求下撫百姓之隱政聲籍甚召監進奏院歷</span>  
<span style="margin-left: 2em">大常丞兼兵部郎官提舉浙西常平還澱山湖以洩</span>  
<span style="margin-left: 2em">吳松江二水禁民侵築毋使逼塞大流民田賴之終</span>  
<span style="margin-left: 2em">寶謨閣直學士</span>  
<span style="margin-left: 1em">顔師魯字幾聖漳州龍溪人紹興中進士歷國子丞江</span>  
<span style="margin-left: 2em">東提舉改使浙西役法敝甚細民至以鷄豚甖榻折</span>  
<span style="margin-left: 2em">産力遇役輒破家師魯下教屬邑預正流水籍稽其</span>  
<span style="margin-left: 2em">役之序寬比限免代輸咸便安之鹽課歲百鉅萬本</span>  
<span style="margin-left: 2em">錢久不給亭竈私鬻禁不可止刑辟日緐師魯撙帑</span>  
<span style="margin-left: 2em">緡盡償宿負戒官吏毋侵移比旁路課獨最上謂執</span>  
<span style="margin-left: 2em">政曰儒生能辦事如此</span>  
<span style="margin-left: 1em">詹體仁字元善建寧浦城人初後其舅張氏既復爲詹</span>  
<span style="margin-left: 2em">少有異材鄉舉第一始冠第進士歷泉州晉江丞宰</span>  
<span style="margin-left: 2em">相梁克家薦升太學博士攝金部郎中光宗即位提</span>  
<span style="margin-left: 2em">舉浙西常平務爲民除害興利謂浙右之有漕渠非</span>  
<span style="margin-left: 2em">止通饋運資國信往來而已蘇秀常潤田之高仰者</span>  
<span style="margin-left: 2em">實賴之於是開漕渠浚練湖置斗門爲旱潦備</span>  
<span style="margin-left: 1em">徐誼字子宜一字宏父温州人乾道八年進士累官太</span>  
<span style="margin-left: 2em">常丞知徽州移提舉浙西常平嘗論水利之切於時</span>  
<span style="margin-left: 2em">者曰昔下流不疏而水上溢故鑿直曲港還三江故</span>  
<span style="margin-left: 2em">道開宜興百瀆所以順導下流也惟高原田徑乃瀦</span>  
<span style="margin-left: 2em">堰之爾昔之言水如單鍔郟亶皆是也今開吳松江</span>  
<span style="margin-left: 2em">下流與宜興百瀆屬之海者無慮數十百所異時浦</span>  
<span style="margin-left: 2em">港磬折以趨海今近浦之民多取徑直疏決蘇湖常</span>  
<span style="margin-left: 2em">秀舊爲澤國比年雨或後至種且不入蓋圍田衆而</span>  
<span style="margin-left: 2em">疏導多也小人見利不畏其害圍於淺水既爲高田</span>  
<span style="margin-left: 2em">圍於茭蕩既爲稻田二俱不已復有下脚始之重陂</span>  
<span style="margin-left: 2em">太半爲平始之良田背水自曬十日不雨農廢作業</span>  
<span style="margin-left: 2em">然且承用舊說又將疏之失利害之實矣故舊田溝</span>  
<span style="margin-left: 2em">澮當濬治圍田下脚無輒開已開未填當捺合今之</span>  
<span style="margin-left: 2em">言水者能行是三說則高原舊田還爲衍沃而農不</span>  
<span style="margin-left: 2em">病矣入爲吏部郎守右司郎中寧宗朝知臨安建康</span>  
<span style="margin-left: 2em">隆興三府卒謚忠文</span>  
<span style="margin-left: 1em">孫子秀字元實紹興餘姚人紹定五年進士調吳縣主</span>
