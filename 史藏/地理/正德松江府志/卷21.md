## 正德松江府志卷之二十一　古迹

<span style="margin-left: 4em">古迹</span>  
<span style="margin-left: 3em">古迹者山川邑里第宅丘园之属皆是也而复出</span>  
<span style="margin-left: 3em">此者旧俗所传不可以附见者也题咏成什者萃</span>  
<span style="margin-left: 3em">之欲见其全也事具别条而诗录于此者明皆古</span>  
<span style="margin-left: 3em">迹可互相考也</span>  
<span style="margin-left: 1em">周公墩府东南捍海塘外俗传府有周公孔子遗迹者</span>  
<span style="margin-left: 2em">谓北有孔宅南有是墩也墩距古金山城不十里当</span>  
<span style="margin-left: 2em">潮势奔猛处云间志华亭襟带江海上而吴晋近而</span>  
<span style="margin-left: 2em">吴越皆筑城垒置防戍所以控守海道者至矣宋元</span>  
<span style="margin-left: 2em">仍旧城墩皆戍以兵然则墩盖古人所筑以防海处</span>  
<span style="margin-left: 2em">或者因康王金山城事而传是名耳今金山营堡犹</span>  
<span style="margin-left: 2em">有以是墩名者青龙南亦有白茅墩其东又有逢阵</span>  
<span style="margin-left: 2em">墩大抵皆烽堠也</span>  
<span style="margin-left: 1em">吴王猎场旧图经在华亭谷东陆龟蒙吴中即事诗五</span>  
<span style="margin-left: 2em">茸春草雉媒骄注谓五茸者吴王猎所茸各有名旧</span>  
<span style="margin-left: 2em">经文云吴陆逊生此子孙常所游猎后人呼陆机茸</span>  
<span style="margin-left: 2em">今其地为桑陆按唐询诗题注华亭谷在县南然则</span>  
<span style="margin-left: 2em">今府城东南皆猎场遗址也</span>  
<span style="margin-left: 1em">三女冈旧图经县东南八十里吴王葬三女于此吴越</span>  
<span style="margin-left: 2em">春秋录异传有吴王葬女阊门外事吴郡图经阊门</span>  
<span style="margin-left: 2em">外有女坟湖枢要云吴王葬妃于此未知孰是明行</span>  
<span style="margin-left: 2em">寺记云寺近三女冈则冈在今南桥镇也</span>  
<span style="margin-left: 1em">秦始皇驰道府西北昆山南四里相传有大堈路西通</span>  
<span style="margin-left: 2em">吴城即驰道也舆地志始皇东游至会稽句章经此</span>  
<span style="margin-left: 2em">汉贾山至言秦皇驰道遍天下东穷燕齐南极吴楚</span>  
<span style="margin-left: 2em">此盖其一也按昆山南四里即古浦塘然则驰道即</span>  
<span style="margin-left: 2em">塘之岸也山之北又有秦皇走马塘</span>  
<span style="margin-left: 1em">赵店在府治西昔未邑之日市东名赵店今有神祠谓</span>  
<span style="margin-left: 2em">之赵店土地</span>  
<span style="margin-left: 1em">八角井前志府南太平桥南今张泾桥西其水通海岁</span>  
<span style="margin-left: 2em">旱投铁简其中云能致雨俗传陆氏外厨井也</span>  
<span style="margin-left: 1em">顾亭林因野王居此得名宝云寺址即其地也<sub class="note-yuan">宋胡松年诗海山荡佳气千载传古居平生读书地竹柏静以疏忠义贯白日名不埋幽墟苗裔今几何谁能补其余</sub></span>  
<span style="margin-left: 1em">读书堆在亭林宝云寺后即野王修舆地志处其高数</span>  
<span style="margin-left: 2em">丈横亘数十亩林樾苍然寺僧尝欲作亭其上以恭</span>  
<span style="margin-left: 2em">野王不果今其后中为居民所侵<sub class="note-yuan">贝琼诗泊舟亭林湖突兀空王宫当时读书处鸟雀呼秋风前瞻两金山抃舞波涛中眷兹一篑力克配千仞崇恐有文字藏中夜飞白虹荒哉梦中语且复诳儿童我亦有书癖玉经老未通草堂可遂结当作两希冯</sub></span>  
<span style="margin-left: 1em">东庵在亭林中有忠烈公像庵地尝裂数尺中有风涛</span>  
<span style="margin-left: 2em">声以物探之则应手火起</span>  
<span style="margin-left: 1em">烽楼在亭林南按法云寺记载唐隰州司仓支令问妻</span>  
<span style="margin-left: 2em">曹氏墓志云葬顾亭林南烽楼之侧其南冈阜相属</span>  
<span style="margin-left: 2em">世传为野王墓非也寰宇记南带海上有烽火楼基</span>  
<span style="margin-left: 2em">吴时望海处今遗迹犹存</span>  
<span style="margin-left: 1em">黄耳冢述异记陆机少好猎在吴日有家客献快犬曰</span>  
<span style="margin-left: 2em">黄耳后仕洛将以自随犬慧黠解人语机尝戏语曰</span>  
<span style="margin-left: 2em">家久无书汝能驰往否犬摇尾作声似应之机为书</span>  
<span style="margin-left: 2em">盛以竹筩系犬颈犬走向吴经水辄依渡者掉尾向</span>  
<span style="margin-left: 2em">之得渡则腾上速去到家得书还驰向洛后死还葬</span>  
<span style="margin-left: 2em">其家村南二百步呼为黄耳冢商芸小说后分华亭</span>  
<span style="margin-left: 2em">南为黄耳村以犬冢为号独刘贡父诗话以黄耳为</span>  
<span style="margin-left: 2em">仆未知何据今冢在城南二里余傍有普宁尼寺守</span>  
<span style="margin-left: 2em">之俗讹为黄泥寺然不闻所谓黄耳村也<sub class="note-yuan">袁凯黄耳墓诗黄耳墓前春日迟柳条花萼正参差高才已逐浮云去异物犹令后代思豢养有恩终不肯交游何事独相欺春风绿酒人皆醉落日孤舟自咏诗</sub></span>  
<span style="margin-left: 1em">钓滩在府西南朱泾镇唐船子和尚垂纶之地今为法</span>  
<span style="margin-left: 2em">忍寺<sub class="note-yuan">船子三诗千尺丝纶直下垂一波才动万波随夜静水寒鱼不食满船空载月明归〇二十余年江上游水清鱼见不吞钩钓竿斮尽重栽竹不计工程得便休〇三十余年坐钓台钓头往往得黄能锦鳞不遇虚劳力收取纶竿归去来宋张商英诗芦苇萧萧江岸秋长天独月向西流离钩三寸无人道笑倚兰桡自点头葛天民诗泽国茫茫水接天孰云无法与人传见成风月难回避尽在华亭一钓船黄庭坚词荡漾生涯身已老短蓑篛笠扁舟小深入水云人不到吟复笑一轮明月长相照谁谓何人来问道一桡直与传心要船子踏翻才是了波渺渺长鲸万古无人钓国朝朱思全诗芦苇萧萧落照湾渔舟一叶水云宽锦鳞未跃波先动玉鉴初圆夜正寒说法何须顽石听竖桡曾与夹山看搆堂已据垂纶地安得当时旧钓竿</sub></span>  
<span style="margin-left: 1em">松泽西亭船子和尚维舟咏歌处后为西亭兰若<sub class="note-yuan">船子词一叶虚舟一副竿了然无事坐烟滩忘得丧任悲懽却教人唤有多端〇一任孤舟正又斜乾坤何路指生涯抛岁月卧烟霞在处江山便是家〇愚人未识主人公终日孜孜恨不同到彼岸出樊笼元来只是旧时翁宋高仪甫诗松泽亭前山色幽朱泾渡口荻花秋离钩三寸无人会一棹东西独未休〇野水闲云无定踪一生空棹月明中锦鳞才得飜船去堪笑家风彻底穷〇西亭无处认遗基烟月空余旧唱辞欲问辞中端的意渚花隄柳可能知〇劈口两桡无剩法点头三下不容声谢师付授从今了一叚风流画不成〇隔水遥山数朵青送人依旧法闲亭此舟未信无重过门枕苹汀夜不扄</sub></span>  
<span style="margin-left: 1em">水陆池在兴圣寺池昔有龟数枚闻讲经声则缘砌而</span>  
<span style="margin-left: 2em">上罢则复去后以其地为棠溪书院今池在院中</span>  
<span style="margin-left: 1em">西庵律师元玮所居其地即接待院也</span>  
<span style="margin-left: 2em">庵堂壁有六祖画像</span>  
<span style="margin-left: 1em">毘卢庵句氏香火院中有御书阁</span>  
<span style="margin-left: 1em">冰檗庵王道人所居</span>  
<span style="margin-left: 1em">泖塔在泖中吴天泽记云观符间老僧如海筑基中泖</span>  
<span style="margin-left: 2em">作井亭施汤茗建塔标灯为往来之望塔凡五层五</span>  
<span style="margin-left: 2em">年而成基广一二亩虽大水不没<sub class="note-yuan">国朝吴爰诗日日春阴今日晴小舟载酒作闲行茫茫白水四邻绝落落青冥一柱擎鸿鴈影沈灯自照鲤鱼风起铎先鸣雪眉禅子忘僧腊坐阅波涛几度平</sub></span>  
<span style="margin-left: 1em">秀道者塔在佘山巅秀昔庐此建塔建毕遂积薪自焚</span>  
<span style="margin-left: 2em">有碑<sub class="note-yuan">许尚百咏题下注秀道者常有二虎侍之疑即佘山聪道人也</sub></span>  
<span style="margin-left: 1em">鲁般殿在法忍寺相传为般所造齐柱累枅为脊鸟雀</span>  
<span style="margin-left: 2em">不栖殿庭双柏古怪亦云般所植病心者掇其皮煮</span>  
<span style="margin-left: 2em">服之今废</span>  
<span style="margin-left: 1em">吕公樟在北道堂即今本一庵也宋有回先生过之手</span>  
<span style="margin-left: 2em">植樟一本于云堂后数年复来问章公何在无有知</span>  
<span style="margin-left: 2em">者时樟已枯瘁回见之而笑取瓢中药一丸瘗诸根</span>  
<span style="margin-left: 2em">下人亦不以屑意一夕乍热多蚊回画一瓢于云堂</span>  
<span style="margin-left: 2em">壁间蚊悉栖其内居者坦然众方异之霍然不见矣</span>  
<span style="margin-left: 2em">尔后樟复荣每叶皆有瓢痕人始悟吕僊也自是云</span>  
<span style="margin-left: 2em">水往来必掇其叶以称奇四方<sub class="note-yuan">陈必达诗云锁虚堂四壁空吕公曾此问樟公如今不见神僊过古树苍苍夕照中</sub></span>  
<span style="margin-left: 1em">异木尝见梦商人自称土地神云祭我令汝宜商自是</span>  
<span style="margin-left: 2em">商人岁祠之祠必以夜半</span>  
<span style="margin-left: 1em">五色泉在西湖超果寺东南相传葛稚川炼丹湖上丹</span>  
<span style="margin-left: 2em">成投水中后常涌五色泉府人士见者必擢高第时</span>  
<span style="margin-left: 2em">又舒光如赤虹贯天<sub class="note-yuan">续志注云湖有漩涡甚急小舟经者或沉焉没而出者舐所濡甘如饴蜜谓其下深可十寻寒若冰雪有橘商舣舟湖上获㦼置于舟左右则欹中而平过洞庭风雨跃去时谓丹化由是漩恬淤仰今府城西南濠西湖境界也犹有漩涡一浴者不敢近有因而溺者近涡城亦善崩但未见所谓五色与赤光耳</sub></span>  
<span style="margin-left: 1em">瑞光井在超果寺西庑下宋太平兴国中僧庆依奉钱</span>  
<span style="margin-left: 2em">王宫中观音像来云间舣舟李塔汇像舒祥光如虹</span>  
<span style="margin-left: 2em">经天下贯此井因名其后浚淤复覩金鳗之异邦人</span>  
<span style="margin-left: 2em">病者多汲饮焉其东一井尤甘冽或曰此真瑞光也</span>  
<span style="margin-left: 1em">罗汉井在南禅寺宋崇宁中僧普愿于此得住世罗汉</span>  
<span style="margin-left: 2em">像寺因以兴故名水甘冽宜茶汲者遇月朔率投以</span>  
<span style="margin-left: 2em">纸钱一陌</span>  
<span style="margin-left: 1em">石幢在华亭县前相传地有涌泉云是海眼大中十三</span>  
<span style="margin-left: 2em">年立此镇之</span>  
<span style="margin-left: 1em">石兽在府东尝为变怪夜则环市而走遂断其一足</span>  
<span style="margin-left: 1em">金山神鱼每岁庙神诞日有鱼名黑隘大者如山群引</span>  
<span style="margin-left: 2em">海族来朝率午方退</span>  
<span style="margin-left: 1em">鹦鹉洲在海中金山下山北古海盐州后沦于海元末</span>  
<span style="margin-left: 2em">潮啮山北岸下瞰桥井犹凿凿有得一碑曰鹦鹉洲</span>  
<span style="margin-left: 2em">界</span>  
<span style="margin-left: 1em">文翚洲黄浦中元末始生王逢登时群雉集故名有诗</span>  
<span style="margin-left: 1em">绫锦墩在盘龙塘上钱全衮种桑之所<sub class="note-yuan">杨维祯诗先生绫锦墩边住日日柴门踏锦沙千古清风高士传一溪流水野人家将军树老秋风里使者槎回碧海涯不鬭金园紫丝障凤笙吹月醉桃华王逢诗华亭东有盘龙塘塘上姓钱人种桑就阳避湿浅布子畦分疃列如针秧封培爱厚长尺许畚锸争移春社雨惰农报德也自奇一本约输双篑土土高过客相指语千绫万锦登城府怀材莫捄时歛徴存心尚念农辛苦侍御题名绫锦墩钱郎笑歌墩树根但愿一丝不到体老著布袍青苎村</sub></span>  
<span style="margin-left: 1em">骆驼墩又呼落弹墩在簳山北任仁发墓在焉新志又</span>  
<span style="margin-left: 2em">云宋理宗妃林氏葬此</span>  
<span style="margin-left: 1em">鹤坡在下沙镇其地出鹤俗又呼鹤窠</span>  
<span style="margin-left: 1em">石笋滩在下沙捍海塘外到海三十余里每二三丈辄</span>  
<span style="margin-left: 2em">有石如笋植立沙中若是者弥望潮汐至此其流遂</span>  
<span style="margin-left: 2em">分本名分水港好事者易以今名创置年月无考</span>  
<span style="margin-left: 1em">古冈身有三曰沙冈竹冈紫冈在府东七十里南属于</span>  
<span style="margin-left: 2em">海北抵松江长百里入土数尺皆螺蚌壳世传海中</span>  
<span style="margin-left: 2em">涌三浪而成其地高阜宜菽麦吴郡图经谓濒海之</span>  
<span style="margin-left: 2em">地冈阜相属谓之冈身此天所以限沧溟而全吴人</span>  
<span style="margin-left: 2em">也<sub class="note-yuan">贝琼过竹冈诗迢遰竹冈路村墟烟火迟地从沧海尽天入大荒垂网集知潮落舟行觉岸移平生贪胜槩随处一题诗</sub></span>  
<span style="margin-left: 1em">赤乌碑在旧静安寺吴赤乌中天竺康僧会始入建业</span>
