<span style="margin-left: 1em">明正德松江府志　　方誌類<sub class="note-yuan">江蘇松</sub></span>  
<span style="margin-left: 8em">　　<sub class="note-yuan">江府部</sub></span>  
<span style="margin-left: 2em">參本</span>  
<span style="margin-left: 3em">明正德七年刻本</span>  
<span style="margin-left: 4em">上海圖書館藏甲本殘本</span>  
<span style="margin-left: 4em">上海圖書館藏乙本殘本</span>  
<span style="margin-left: 4em">上海圖書館藏丙本殘本</span>  
<span style="margin-left: 14em">　　六本合衲</span>  
<span style="margin-left: 4em">上海圖書館藏丁本殘本</span>  
<span style="margin-left: 4em">中國國家圖書館藏殘本</span>  
<span style="margin-left: 4em">上海書店景寧波天一閣殘本</span>  
<span style="margin-left: 2em">谷水道人曰</span>  
<span style="margin-left: 1em">蓋正德舊志年湮代遠諸本漫漶莫辨雖上海府縣舊</span>  
<span style="margin-left: 1em">志叢書嘗加理董然其整理弁言自陳學識未周倉促</span>  
<span style="margin-left: 1em">成篇故棗梨淆亂者臆補闕文可識者反作空缺脫漏</span>  
<span style="margin-left: 1em">連篇魯魚乖謬未契准繩今幸獲新見殘帙秘本爰重</span>  
<span style="margin-left: 1em">事讎校取六本互勘闕文則廣徵他籍補苴訛字校正</span>  
<span style="margin-left: 1em">別撰校記以存文獻之真</span>  
<span style="margin-left: 2em">旹</span>  
<span style="margin-left: 1em"><sub class="note-yuan">道曆四千七百二十二年明崇禎三百九十八年</sub>歲次乙巳閏六月癸丑日</span>  
<span style="margin-left: 1em">谷水道人於湧月書齋沐手謹序</span>  
<span style="margin-left: 1em">明正德七年刊本　　　　　　　　　　　　明刊本</span>  
<span style="margin-left: 1em">四庫全書存目提要</span>  
<span style="margin-left: 1em">明顧清撰清字士廉華亭人宏治<sub class="note-jiao">校：宏治實弘治之諱</sub>癸丑進士</span>  
<span style="margin-left: 1em">官至南京禮部尚書事蹟具明史本傳其書頗詳悉有</span>  
<span style="margin-left: 1em">體稍勝他輿記之宂濫</span>  
<span style="margin-left: 2em">松江府志序</span>  
<span style="margin-left: 2em">予往歲憂居郡守今都御史宜春劉侯琬嘗屬以志</span>  
<span style="margin-left: 2em">事會予北上不果正德己巳予復以憂歸明年庚午</span>  
<span style="margin-left: 2em">御史弋陽謝君琛按部來松問府之故病其遺缺嗣</span>  
<span style="margin-left: 2em">守臨川陳侯威復舉以屬予冬始即事而侯以春去</span>  
<span style="margin-left: 2em">予謂其終弗果也會今守內江喻侯時繼至力主成</span>  
<span style="margin-left: 2em">之府始爲縣時有雲間志既爲府屬嘉興見嘉禾志</span>  
<span style="margin-left: 2em">直隸省後有松江郡志有續志入</span>  
<span style="margin-left: 1em">國朝有松江志有雲間通志通志者會諸志而成書者</span>  
<span style="margin-left: 2em">也雲間志歷歲久遠今已無全書其餘雖存而後生</span>  
<span style="margin-left: 2em">之得見者已鮮通志所載又間有脱訛更後數十年</span>  
<span style="margin-left: 2em">遺文墜蹟將無復討尋矣故今並取諸本參互考證</span>  
<span style="margin-left: 2em">會以成編而不敢略焉通志以後則續之事見他書</span>  
<span style="margin-left: 2em">而諸志所未及者補入之其間卷第之先後類目之</span>  
<span style="margin-left: 2em">分合事辭之易置取合倫例與便檢閲蓋稍異往編</span>  
<span style="margin-left: 2em">而大率皆其故也至于推原變始考見得失因事寓</span>  
<span style="margin-left: 2em">規間亦有之而罔敢以意參焉嗚呼郡之志猶國之</span>  
<span style="margin-left: 2em">史也昔人有成論矣史不爲天下萬世而移于一人</span>  
<span style="margin-left: 2em">是之謂曲筆志不爲一鄉與後世亦豈能逃士論之</span>  
<span style="margin-left: 2em">公今兹纂輯蓋歉焉惟淺狹挂漏貽誚於大方是懼</span>  
<span style="margin-left: 2em">日月滋久參質爲艱而梓刻成矣敢述所懷布諸簡</span>  
<span style="margin-left: 2em">首後有作者即其具文加之黼藻以成一郡之書豈</span>  
<span style="margin-left: 2em">惟寡學之幸亦前後諸公所以屬望之心也志爲卷</span>  
<span style="margin-left: 2em">三十二爲目三十一目之下又有目焉凡十有七卷</span>  
<span style="margin-left: 2em">始終暨圖目爲版九百十有六居之郡閣備散逸也</span>  
<span style="margin-left: 2em">同事諸生與郡之僚屬贊襄于是者並列名左方壬</span>
