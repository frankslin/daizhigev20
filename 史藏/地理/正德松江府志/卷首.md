<span style="margin-left: 2em">谷水道人曰</span>  
<span style="margin-left: 1em">盖正德旧志年湮代远诸本漫漶莫辨虽上海府县旧</span>

<span style="margin-left: 2em">松江府志序</span>  
<span style="margin-left: 2em">予往岁忧居郡守今都御史宜春刘侯琬尝属以志</span>  
<span style="margin-left: 2em">事会予北上不果正德己巳予复以忧归明年庚午</span>  
<span style="margin-left: 2em">御史弋阳谢君琛按部来松问府之故病其遗缺嗣</span>  
<span style="margin-left: 2em">守临川陈侯威复举以属予冬始即事而侯以春去</span>  
<span style="margin-left: 2em">予谓其终弗果也会今守内江喻侯时继至力主成</span>  
<span style="margin-left: 2em">之府始为县时有云间志既为府属嘉兴见嘉禾志</span>  
<span style="margin-left: 2em">直隶省后有松江郡志有续志入</span>  
<span style="margin-left: 1em">国朝有松江志有云间通志通志者会诸志而成书者</span>  
<span style="margin-left: 2em">也云间志历岁久远今已无全书其余虽存而后生</span>  
<span style="margin-left: 2em">之得见者已鲜通志所载又间有脱讹更后数十年</span>  
<span style="margin-left: 2em">遗文坠迹将无复讨寻矣故今并取诸本参互考证</span>  
<span style="margin-left: 2em">会以成编而不敢略焉通志以后则续之事见他书</span>  
<span style="margin-left: 2em">而诸志所未及者补入之其间卷第之先后类目之</span>  
<span style="margin-left: 2em">分合事辞之易置取合伦例与便检阅盖稍异往编</span>  
<span style="margin-left: 2em">而大率皆其故也至于推原变始考见得失因事寓</span>  
<span style="margin-left: 2em">规间亦有之而罔敢以意参焉呜呼郡之志犹国之</span>  
<span style="margin-left: 2em">史也昔人有成论矣史不为天下万世而移于一人</span>  
<span style="margin-left: 2em">是之谓曲笔志不为一乡与后世亦岂能逃士论之</span>  
<span style="margin-left: 2em">公今兹纂辑盖歉焉惟浅狭挂漏贻诮于大方是惧</span>  
<span style="margin-left: 2em">日月滋久参质为艰而梓刻成矣敢述所怀布诸简</span>  
<span style="margin-left: 2em">首后有作者即其具文加之黼藻以成一郡之书岂</span>  
<span style="margin-left: 2em">惟寡学之幸亦前后诸公所以属望之心也志为卷</span>  
<span style="margin-left: 2em">三十二为目三十一目之下又有目焉凡十有七卷</span>  
<span style="margin-left: 2em">始终暨图目为版九百十有六居之郡阁备散逸也</span>  
<span style="margin-left: 2em">同事诸生与郡之僚属赞襄于是者并列名左方壬</span>
