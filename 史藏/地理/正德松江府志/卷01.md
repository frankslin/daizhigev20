## 松江府志卷之一

<span style="margin-left: 3em">沿革</span>  
<span style="margin-left: 2em">吾松見史策以來亭而縣縣而府地望日隆而離合損益之故諸志備矣會而敘諸首使觀國者稽焉</span>  
松江古揚州之域春秋爲吴地吴子壽夢始築華亭蓋亭留宿會之所也吴滅入越越滅入楚秦併天下爲婁縣地屬會稽郡<sub class="note-yuan">會稽治吴今蘇州也</sub>漢興因之順帝永建四年分浙江以東爲會稽郡西爲吴郡是爲吴郡地漢末孫氏霸吴以其地封陸遜爲華亭侯始見之吴志實建安二十四年也梁大同初分婁縣爲崑山是爲崑山地唐天寶十載以吴郡太守趙居貞奏始割崑山南境及嘉興海鹽三縣地立華亭縣仍屬於吴僖宗入蜀時羣盜盤結爲王騰所據吴越王錢鏐遣顧全武拔之遂爲吴越地晉天福五年以嘉興縣爲秀州而割華亭隸焉宋慶元元年秀州陞嘉興府仍屬嘉興元至元十四年陞華亭府<sub class="note-yuan">時以縣五萬户者爲州華亭户登二十三萬故立爲府</sub>十五年改松江府<sub class="note-yuan">以吴松江名</sub>屬江浙行省嘉興路二十九年割華亭東北五鄉爲上海縣直隸省府泰定三年罷以兩縣屬嘉興路立都水庸田使司于府治天曆元年罷司復府元末張士誠據之至正二十七年春正月知府王立中歸附直隸  
京師仍領縣二曰華亭曰上海  
<span style="margin-left: 1em">華亭縣附府城建置沿革具於府初縣之立本割崑山嘉興海鹽三縣地故境與三縣接姑蘇志又云長洲割地入華亭今長洲亦鄰壤也或以縣有華亭鎮印遂謂自鎮爲縣不知鎮者唐因隋制置鎮將副以掌捍防守禦之事特縣之冗職耳祥符圖經載鎮在縣西南二百步元豐九域志始廢不書如自鎮爲縣則郡國輿地諸書不應略而不言也新唐史書望九域志書緊元既即縣爲府因爲屬邑</span>  
國朝因之  
<span style="margin-left: 1em">上海縣在府東北九十里本華亭縣地舊曰華亭海後以人煙浩穰海舶輻輳遂成大市宋於其地立市舶提舉司及榷貨場曰上海鎮其立以爲縣則知府僕散翰文之請也以地居海之上洋故名曰上海亦稱爲上洋云</span>  
<span style="margin-left: 3em">分野</span>  
<span style="margin-left: 2em">歷代星書皆以斗牛爲吴越之分野雖互有同異而大要不出乎此松江本吴地故具列占驗以俟知星者攷焉</span>  
黃帝分星次斗十一度至婺女七度曰須女又曰星紀於辰在丑於律爲黃鐘  
周禮保章氏註星紀吴越也  
爾雅星紀斗牽牛吴分野  
西漢天文志斗江湖牽牛婺女揚州地里志吴地斗分野越地牽牛婺女之分野  
費直起斗十度至女五度爲星紀蔡邕起斗六度至須女二度爲星紀大雪冬至居之吴越之分野  
陳卓范蠡諸人分星次丹陽入斗十六度會稽入牛一度  
晉天文志南斗十二度至須女七度爲星紀吴越之分野  
宋兩朝天文志天市東垣南第六星曰吴越  
左傳昭公三十三年夏吴伐越史墨曰越得歲而吴伐之必受其凶至哀公二十二年越滅吴  
符堅議寇晉太子左衛率石越對曰今歲鎮星守斗牛福德在吴懸象無差未可犯也符融曰歲鎮在<sub class="note-jiao">校：鎮下疑脫在字今補</sub>斗牛吴越之福堅不聽大敗而還  
宋建炎初國步艱虞占者望牛斗間有紫氣既而移蹕維揚是歲冬十月孝宗生於嘉興其驗如此  
<span style="margin-left: 1em">按松江直嘉興之東吴郡之東南先朝爲二郡屬邑相去皆百餘里參考占驗蓋斗之分野云</span>  
<span style="margin-left: 3em">疆域</span>  
<span style="margin-left: 2em">松江雖名富饒郡其實古一縣爾分而爲二庸賦日滋而封域猶故也觀於此可以知民力云</span>  
元嘉興路松江府境東西一百六十里南北一百七十三里<sub class="note-yuan">東至海八十里西至平江路長洲縣界八十里南至海九十里北至平江路崑山縣界八十里東南到海中明州界九十里西南到海鹽縣界六十里到縣一百二十里東北到崑山縣界一百二十里到縣一百三十里西北到崑山縣界一百五十里到縣二百里陸路西南至嘉興縣界六十里水路同東北至青龍鎮五十四里水路自青龍入吴松江同見嘉禾志</sub>  
元直隸松江府境東西一百六十里南北一百七十三里<sub class="note-yuan">東至海八十里西至平江路長洲縣界八十里南至海九十里以小官浦爲界北至平江路崑山縣界八十里東南到海明州界九十里西南到嘉興路海鹽縣界六十里東北到崑山縣界一百十里西北到崑山縣界一百五十里</sub>  
<span style="margin-left: 1em">華亭縣東西一百五里南北一百十六里<sub class="note-yuan">東至烏泥涇四十五里西至楓涇六十里南至金山八十里北至簳山三十六里</sub></span>  
<span style="margin-left: 1em">上海縣東西四十八里南北一百里<sub class="note-yuan">東至江灣一十八里西至烏泥涇三十里南至下沙場五十里北至青龍鎮五十里</sub></span>  
國朝松江府境東西一百六十里南北一百五十二里<sub class="note-yuan">東至大海一百里到海無際西至蘇州府長洲縣界六十里到吴江縣一百二十里南至金山衛七十二里到海無際北至蘇州府崑山縣吴松江北岸界八十里到崑山縣一百三十里東南到青村千户所一百十里西南到嘉興府一百二十里東北到蘇州府嘉定縣一百三十里西北到蘇州府一百八十里自府治至京師三千八百二十五里至南京八百里</sub>  
<span style="margin-left: 1em">華亭縣東西七十八里南北一百二十六里<sub class="note-yuan">東至上海縣語兒涇十八里到上海縣九十里西至蘇州府長洲縣界六十里到吴縣一百二十里南至海七十二里到海無際北至上海縣唐行鎮五十四里到崑山縣一百三十里東南到青村千户所一百一十里西南到嘉興府一百二十里西北到蘇州府一百八十里東北到上海縣九十里</sub></span>  
<span style="margin-left: 1em">上海縣東西一百六十里南北九十里<sub class="note-yuan">東至大海五十里到海無際西至華亭縣界一百一十里到蘇州府一百八十里南至華亭縣界七十二里到下沙場六十里北至嘉定縣界十八里到吴松江巡檢司十二里東南到南匯觜千户所八十里西南到本府九十里東北到嘉定縣江灣巡檢司一十四里西北到嘉定縣界七十二里</sub></span>  
<span style="margin-left: 3em">山</span>  
<span style="margin-left: 2em">府境諸山皆自杭天目而來纍纍然隱起平疇間長谷以東通波以西望之如列宿排障東南涵浸滄海煙濤空翠亦各極其趣焉而九峯之名特著故首列之其次序則見題詠<sub class="note-yuan">九峯中惟天馬佘山最高玉屏斯下矣崑山又下於玉屏此有目所見也舊志稱干山七十丈薛山九十丈崑山乃一百五十丈豈其然乎故不計其丈尺機山最西北云去府二十里細林近東南乃二十五里況竹嶼浮蘇在滄波浩渺中誰能測之故不詳其道里然其概亦略可見矣</sub></span>  
崑山府西北二十三里長谷之東陸氏之先葬此後機雲兄弟有辭學人以爲玉出崑岡因名山形圓秀而潤傍無附麗望之如覆盎然蘇縣名崑山義取乎此因其地有馬鞌山俗誤爲崑松人遂以小崑自名其實非也元淩喦詩<sub class="note-yuan">九峯西峙比崑崙晉代將軍墓尚存今日捫蘿登絶頂桑丘麥壟自村村</sub>錢惟善<sub class="note-yuan">年年載酒酹榆枌征北將軍尚有墳賴得陸家雙白璧自從入洛世無聞</sub>  
橫雲山在崑山東北本名橫山天寶六載易今名或云以陸士龍名也山多古墓勝國時嘗遭發掘獲器物甚多輟耕錄所記古銅水滴號神人獅子者亦出於此蓋陸氏物也其巔有白龍洞潛通澱湖深不可測下有祭龍壇歲旱禱焉宋皇祐中浙西旱蝗華亭令吴及禱于此立致甘澍蝗不入境今山陽采石闕然成窪如失面目近歲府同知張什下令禁之然山民力田不給以石爲生特未能止也淩嵒詩<sub class="note-yuan">七峯崷崪擁層巒偃蓋孤松石上蟠行雨白龍何處去暮雲深鎖洞門寒</sub>錢惟善<sub class="note-yuan">兄弟詞華不世逢青山相對若爲容洞門深鎖煙嵐濕猶指空壇祭白龍</sub>  
小橫山在橫雲東中限一水嶐然而興上多璺石多萬年松俗呼僊人澆酒石由絶頂至東北皆峰巒隱起壁立數仞色盡赭遊人呼爲小赤壁盡壁斬然一罅如虎丘試劒石狀前有石可踞而坐下瞰小澗亦九峯奇絶處也國朝錢溥遊和東坡赤壁懷古念奴嬌詞<sub class="note-yuan">三江既入到今來誰是風塵表物秀列九峯非夏口亦有丹崖翠壁煙鎖平原雲橫積石欲弔情何雪時歸典午可憐失此雙傑　何異孟德當年蒙衝蔽岸一炬東風發萬古功名同一夢祇有文章難滅夜靜江空猶聞鶴唳聳起人毛髮坡仙如在要分兩處風月</sub>  
機山在橫雲後南北相望以陸士衡得名山下有平原村亦以機爲平原內史也前有陂澤人家散布汀岸隱然若圖畫云淩嵒詩<sub class="note-yuan">六峯喬木鎖雲根青接平原數里村此處無人來聽鶴海靈山鬼哭黃昏</sub>錢惟善<sub class="note-yuan">煙逕雲林樹色昏千尋喬木見名門橫峯亦有尚書墓只酹平原內史魂</sub>  
干山在機山東有水紆廻從橫雲來經其間北去西北諸山之最高大者以形如天馬稱爲天馬山其曰干者或傳干將曾此鑄劒舊圖經則云有干姓者居此圓智寺記亦謂山後皆干氏所有故名山上多琳宫梵宇春時遊人甚盛畫船歌吹遥從綠野細水中來纚纚不絶嶽祠之側有來鶴軒其西穿堂當小山石壁若屏障然右瞰泖湖一白萬頃憑高凝竚恍然如隔世外云山頂有雙石魚相傳風雨化去其脅有泉遊人掬以頮面云能明目淩嵒詩<sub class="note-yuan">八峯葱蒨石林幽給事題詩記勝遊昨夜僧歸鐘鼓靜一聲鶴唳海天秋</sub>錢惟善<sub class="note-yuan">干氏千年居此山題詩給事最幽閒春濃海嶽開晴色遊子燒香畫舫還</sub>  
澱山機山西北舊志云在薛澱湖中山形四出如鼇上建浮圖下有龍洞云通太湖山屹立湖中亦落星浮玉之類傍有小山初年僅兩席許久之寖長寺僧築亭其上牓曰明極當時好事者遂即山中所有曰鼇峰塔<sub class="note-yuan">今寺法堂地</sub>曰龍淵橋曰潛龍洞曰通靈泉<sub class="note-yuan">橋在山陽洞在山陰泉在山巔宋慧燈禪師鑿石十六丈得此初名寒穴錢野人袞以名襲金山且下有龍洞因易今名</sub>曰回經石<sub class="note-yuan">相傳有僧西域取經回過湖漂水墮此石上石在山麓洞西</sub>曰白蓮池<sub class="note-yuan">在小山下與洞吞吐</sub>曰三姑祠<sub class="note-yuan">在寺傍</sub>曰一色軒<sub class="note-yuan">寺舊東廡十八間皆粉素故名</sub>曰徹見閣<sub class="note-yuan">在法堂後</sub>并明極爲十景云今山在平田去湖益遠亭宇塔院蕩爲飛灰僅存數棟耳
