## 正德松江府志卷之一　沿革　分野　疆域　山

<span style="margin-left: 4em">沿革</span>  
<span style="margin-left: 3em">吾松見史策以來亭而縣縣而府地望日隆而離</span>  
<span style="margin-left: 3em">合損益之故諸志備矣會而敘諸首使觀國者稽</span>  
<span style="margin-left: 3em">焉</span>  
<span style="margin-left: 1em">松江古揚州之域春秋爲吴地吴子壽夢始築華亭蓋</span>  
<span style="margin-left: 2em">亭留宿會之所也吴滅入越越滅入楚秦併天下爲</span>  
<span style="margin-left: 2em">婁縣地屬會稽郡<sub class="note-yuan">會稽治吴今蘇州也</sub>漢興因之順帝永建四</span>  
<span style="margin-left: 2em">年分浙江以東爲會稽郡西爲吴郡是爲吴郡地漢</span>  
<span style="margin-left: 2em">末孫氏霸吴以其地封陸遜爲華亭侯始見之吴志</span>  
<span style="margin-left: 2em">實建安二十四年也梁大同初分婁縣爲崑山是爲</span>  
<span style="margin-left: 2em">崑山地唐天寶十載以吴郡太守趙居貞奏始割崑</span>  
<span style="margin-left: 2em">山南境及嘉興海鹽三縣地立華亭縣仍屬於吴僖</span>  
<span style="margin-left: 2em">宗入蜀時羣盜盤結爲王騰所據吴越王錢鏐遣顧</span>  
<span style="margin-left: 2em">全武拔之遂爲吴越地晉天福五年以嘉興縣爲秀</span>  
<span style="margin-left: 2em">州而割華亭隸焉宋慶元元年秀州陞嘉興府仍屬</span>  
<span style="margin-left: 2em">嘉興元至元十四年陞華亭府<sub class="note-yuan">時以縣五萬户者爲州華亭户登二十三萬故立爲府</sub>十五年改松江府<sub class="note-yuan">以吴松江名</sub>屬江浙行省嘉興</span>  
<span style="margin-left: 2em">路二十九年割華亭東北五鄉爲上海縣直隸省府</span>  
<span style="margin-left: 2em">泰定三年罷以兩縣屬嘉興路立都水庸田使司于</span>  
<span style="margin-left: 2em">府治天曆元年罷司復府元末張士誠據之至正二</span>  
<span style="margin-left: 2em">十七年春正月知府王立中歸附直隸</span>  
<span style="margin-left: 1em">京師仍領縣二曰華亭曰上海</span>  
<span style="margin-left: 2em">華亭縣附府城建置沿革具於府初縣之立本割崑</span>  
<span style="margin-left: 2em">山嘉興海鹽三縣地故境與三縣接姑蘇志又云長</span>  
<span style="margin-left: 2em">洲割地入華亭今長洲亦鄰壤也或以縣有華亭鎮</span>  
<span style="margin-left: 2em">印遂謂自鎮爲縣不知鎮者唐因隋制置鎮將副以</span>  
<span style="margin-left: 2em">掌捍防守禦之事特縣之冗職耳祥符圖經載鎮在</span>  
<span style="margin-left: 2em">縣西南二百步元豐九域志始廢不書如自鎮爲縣</span>  
<span style="margin-left: 2em">則郡國輿地諸書不應略而不言也新唐史書望九</span>  
<span style="margin-left: 2em">域志書緊元既即縣爲府因爲屬邑</span>  
<span style="margin-left: 1em">國朝因之</span>  
<span style="margin-left: 2em">上海縣在府東北九十里本華亭縣地舊曰華亭海</span>  
<span style="margin-left: 2em">後以人煙浩穰海舶輻輳遂成大市宋於其地立市</span>  
<span style="margin-left: 2em">舶提舉司及榷貨場曰上海鎮其立以爲縣則知府</span>  
<span style="margin-left: 2em">僕散翰文之請也以地居海之上洋故名曰上海亦</span>  
<span style="margin-left: 2em">稱爲上洋云</span>  
<span style="margin-left: 4em">分野</span>  
<span style="margin-left: 3em">歷代星書皆以斗牛爲吴越之分野雖互有同異</span>  
<span style="margin-left: 3em">而大要不出乎此松江本吴地故具列占驗以俟</span>  
<span style="margin-left: 3em">知星者攷焉</span>  
<span style="margin-left: 1em">黃帝分星次斗十一度至婺女七度曰須女又曰星紀</span>  
<span style="margin-left: 2em">於辰在丑於律爲黃鐘</span>  
<span style="margin-left: 1em">周禮保章氏註星紀吴越也</span>  
<span style="margin-left: 1em">爾雅星紀斗牽牛吴分野</span>  
<span style="margin-left: 1em">西漢天文志斗江湖牽牛婺女揚州地里志吴地斗分</span>  
<span style="margin-left: 2em">野越地牽牛婺女之分野</span>  
<span style="margin-left: 1em">費直起斗十度至女五度爲星紀蔡邕起斗六度至須</span>  
<span style="margin-left: 2em">女二度爲星紀大雪冬至居之吴越之分野</span>  
<span style="margin-left: 1em">陳卓范蠡諸人分星次丹陽入斗十六度會稽入牛一</span>  
<span style="margin-left: 2em">度</span>  
<span style="margin-left: 1em">晉天文志南斗十二度至須女七度爲星紀吴越之分</span>  
<span style="margin-left: 2em">野</span>  
<span style="margin-left: 1em">宋兩朝天文志天市東垣南第六星曰吴越</span>  
<span style="margin-left: 1em">左傳昭公三十三年夏吴伐越史墨曰越得歲而吴伐</span>  
<span style="margin-left: 2em">之必受其凶至哀公二十二年越滅吴</span>  
<span style="margin-left: 1em">符堅議寇晉太子左衛率石越對曰今歲鎮星守斗牛</span>  
<span style="margin-left: 2em">福德在吴懸象無差未可犯也符融曰歲鎮在<sub class="note-jiao">校：鎮下疑脫在字今補</sub>斗牛吴越之福堅不聽大敗而還</span>  
<span style="margin-left: 1em">宋建炎初國步艱虞占者望牛斗間有紫氣既而移蹕</span>  
<span style="margin-left: 2em">維揚是歲冬十月孝宗生於嘉興其驗如此</span>  
<span style="margin-left: 2em">按松江直嘉興之東吴郡之東南先朝爲二郡屬邑</span>  
<span style="margin-left: 2em">相去皆百餘里參考占驗蓋斗之分野云</span>  
<span style="margin-left: 4em">疆域</span>  
<span style="margin-left: 3em">松江雖名富饒郡其實古一縣爾分而爲二庸賦</span>  
<span style="margin-left: 3em">日滋而封域猶故也觀於此可以知民力云</span>  
<span style="margin-left: 1em">元嘉興路松江府境東西一百六十里南北一百七十</span>  
<span style="margin-left: 2em">三里<sub class="note-yuan">東至海八十里西至平江路長洲縣界八十里南至海九十里北至平江路崑山縣界八十里東南到海中明州界九十里西南到海鹽縣界六十里到縣一百二十里東北到崑山縣界一百二十里到縣一百三十里西北到崑山縣界一百五十里到縣二百里陸路西南至嘉興縣界六十里水路同東北至青龍鎮五十四里水路自青龍入吴松江同見嘉禾志</sub></span>  
<span style="margin-left: 1em">元直隸松江府境東西一百六十里南北一百七十三</span>  
<span style="margin-left: 2em">里<sub class="note-yuan">東至海八十里西至平江路長洲縣界八十里南至海九十里以小官浦爲界北至平江路崑山縣界八十里東南到海明州界九十里西南到嘉興路海鹽縣界六十里東北到崑山縣界一百十里西北到崑山縣界一百五十里</sub></span>  
<span style="margin-left: 2em">華亭縣東西一百五里南北一百十六里<sub class="note-yuan">東至烏泥涇四十五里西至楓涇六十里南至金山八十里北至簳山三十六里</sub></span>  
<span style="margin-left: 2em">上海縣東西四十八里南北一百里<sub class="note-yuan">東至江灣一十八里西至烏泥涇三十里南至下沙場五十里北至青龍鎮五十里</sub></span>  
<span style="margin-left: 1em">國朝松江府境東西一百六十里南北一百五十二里</span>  
<span style="margin-left: 2em"><sub class="note-yuan">東至大海一百里到海無際西至蘇州府長洲縣界六十里到吴江縣一百二十里南至金山衛七十二里到海無際北至蘇州府崑山縣吴松江北岸界八十里到崑山縣一百三十里東南到青村千户所一百十里西南到嘉興府一百二十里東北到蘇州府嘉定縣一百三十里西北到蘇州府一百八十里自府治至京師三千八百二十五里至南京八百里</sub></span>  
<span style="margin-left: 2em">華亭縣東西七十八里南北一百二十六里<sub class="note-yuan">東至上海縣語兒涇十八里到上海縣九十里西至蘇州府長洲縣界六十里到吴縣一百二十里南至海七十二里到海無際北至上海縣唐行鎮五十四里到崑山縣一百三十里東南到青村千户所一百一十里西南到嘉興府一百二十里西北到蘇州府一百八十里東北到上海縣九十里</sub></span>  
<span style="margin-left: 2em">上海縣東西一百六十里南北九十里<sub class="note-yuan">東至大海五十里到海無際西至華亭縣界一百一十里到蘇州府一百八十里南至華亭縣界七十二里到下沙場六十里北至嘉定縣界十八里到吴松江巡檢司十二里東南到南匯觜千户所八十里西南到本府九十里東北到嘉定縣江灣巡檢司一十四里西北到嘉定縣界七十二里</sub></span>  
<span style="margin-left: 4em">山</span>  
<span style="margin-left: 3em">府境諸山皆自杭天目而來纍纍然隱起平疇間</span>  
<span style="margin-left: 3em">長谷以東通波以西望之如列宿排障東南涵浸</span>  
<span style="margin-left: 3em">滄海煙濤空翠亦各極其趣焉而九峯之名特著</span>  
<span style="margin-left: 3em">故首列之其次序則見題詠<sub class="note-yuan">九峯中惟天馬佘山最高玉屏斯下矣崑山又下於玉屏此有目所見也舊志稱干山七十丈薛山九十丈崑山乃一百五十丈豈其然乎故不計其丈尺機山最西北云去府二十里細林近東南乃二十五里況竹嶼浮蘇在滄波浩渺中誰能測之故不詳其道里然其概亦略可見矣</sub></span>  
<span style="margin-left: 1em">崑山府西北二十三里長谷之東陸氏之先葬此後機</span>  
<span style="margin-left: 2em">雲兄弟有辭學人以爲玉出崑岡因名山形圓秀而</span>  
<span style="margin-left: 2em">潤傍無附麗望之如覆盎然蘇縣名崑山義取乎此</span>  
<span style="margin-left: 2em">因其地有馬鞌山俗誤爲崑松人遂以小崑自名其</span>  
<span style="margin-left: 2em">實非也<sub class="note-yuan">元淩喦詩九峯西峙比崑崙晉代將軍墓尚存今日捫蘿登絶頂桑丘麥壟自村村錢惟善年年載酒酹榆枌征北將軍尚有墳賴得陸家雙白璧自從入洛世無聞</sub></span>  
<span style="margin-left: 1em">橫雲山在崑山東北本名橫山天寶六載易今名或云</span>  
<span style="margin-left: 2em">以陸士龍名也山多古墓勝國時嘗遭發掘獲器物</span>  
<span style="margin-left: 2em">甚多輟耕錄所記古銅水滴號神人獅子者亦出於</span>  
<span style="margin-left: 2em">此蓋陸氏物也其巔有白龍洞潛通澱湖深不可測</span>  
<span style="margin-left: 2em">下有祭龍壇歲旱禱焉宋皇祐中浙西旱蝗華亭令</span>  
<span style="margin-left: 2em">吴及禱于此立致甘澍蝗不入境今山陽采石闕然</span>  
<span style="margin-left: 2em">成窪如失面目近歲府同知張什下令禁之然山民</span>  
<span style="margin-left: 2em">力田不給以石爲生特未能止也<sub class="note-yuan">淩嵒詩七峯崷崪擁層巒偃蓋孤松石上蟠行雨白龍何處去暮雲深鎖洞門寒錢惟善兄弟詞華不世逢青山相對若爲容洞門深鎖煙嵐濕猶指空壇祭白龍</sub></span>  
<span style="margin-left: 1em">小橫山在橫雲東中限一水嶐然而興上多璺石多萬</span>  
<span style="margin-left: 2em">年松俗呼僊人澆酒石由絶頂至東北皆峰巒隱起</span>  
<span style="margin-left: 2em">壁立數仞色盡赭遊人呼爲小赤壁盡壁斬然一罅</span>  
<span style="margin-left: 2em">如虎丘試劒石狀前有石可踞而坐下瞰小澗亦九</span>  
<span style="margin-left: 2em">峯奇絶處也<sub class="note-yuan">國朝錢溥遊和東坡赤壁懷古念奴嬌詞三江既入到今來誰是風塵表物秀列九峯非夏口亦有丹崖翠壁煙鎖平原雲橫積石欲弔情何雪時歸典午可憐失此雙傑何異孟德當年蒙衝蔽岸一炬東風發萬古功名同一夢祇有文章難滅夜靜江空猶聞鶴唳聳起人毛髮坡仙如在要分兩處風月</sub></span>  
<span style="margin-left: 1em">機山在橫雲後南北相望以陸士衡得名山下有平原</span>  
<span style="margin-left: 2em">村亦以機爲平原內史也前有陂澤人家散布汀岸</span>  
<span style="margin-left: 2em">隱然若圖畫云<sub class="note-yuan">淩嵒詩六峯喬木鎖雲根青接平原數里村此處無人來聽鶴海靈山鬼哭黃昏錢惟善煙逕雲林樹色昏千尋喬木見名門橫峯亦有尚書墓只酹平原內史魂</sub></span>  
<span style="margin-left: 1em">干山在機山東有水紆廻從橫雲來經其間北去西北</span>  
<span style="margin-left: 2em">諸山之最高大者以形如天馬稱爲天馬山其曰干</span>  
<span style="margin-left: 2em">者或傳干將曾此鑄劒舊圖經則云有干姓者居此</span>  
<span style="margin-left: 2em">圓智寺記亦謂山後皆干氏所有故名山上多琳宫</span>  
<span style="margin-left: 2em">梵宇春時遊人甚盛畫船歌吹遥從綠野細水中來</span>  
<span style="margin-left: 2em">纚纚不絶嶽祠之側有來鶴軒其西穿堂當小山石</span>  
<span style="margin-left: 2em">壁若屏障然右瞰泖湖一白萬頃憑高凝竚恍然如</span>  
<span style="margin-left: 2em">隔世外云山頂有雙石魚相傳風雨化去其脅有泉</span>  
<span style="margin-left: 2em">遊人掬以頮面云能明目<sub class="note-yuan">淩嵒詩八峯葱蒨石林幽給事題詩記勝遊昨夜僧歸鐘鼓靜一聲鶴唳海天秋錢惟善干氏千年居此山題詩給事最幽閒春濃海嶽開晴色遊子燒香畫舫還</sub></span>  
<span style="margin-left: 1em">澱山機山西北舊志云在薛澱湖中山形四出如鼇上</span>  
<span style="margin-left: 2em">建浮圖下有龍洞云通太湖山屹立湖中亦落星浮</span>
