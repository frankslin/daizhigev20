## 正德松江府志卷之一　沿革　分野　疆域　山

<span style="margin-left: 4em">沿革</span>  
<span style="margin-left: 3em">吾松见史策以来亭而县县而府地望日隆而离</span>  
<span style="margin-left: 3em">合损益之故诸志备矣会而叙诸首使观国者稽</span>  
<span style="margin-left: 3em">焉</span>  
<span style="margin-left: 1em">松江古扬州之域春秋为吴地吴子寿梦始筑华亭盖</span>  
<span style="margin-left: 2em">亭留宿会之所也吴灭入越越灭入楚秦并天下为</span>  
<span style="margin-left: 2em">娄县地属会稽郡<sub class="note-yuan">会稽治吴今苏州也</sub>汉兴因之顺帝永建四</span>  
<span style="margin-left: 2em">年分浙江以东为会稽郡西为吴郡是为吴郡地汉</span>  
<span style="margin-left: 2em">末孙氏霸吴以其地封陆逊为华亭侯始见之吴志</span>  
<span style="margin-left: 2em">实建安二十四年也梁大同初分娄县为昆山是为</span>  
<span style="margin-left: 2em">昆山地唐天宝十载以吴郡太守赵居贞奏始割昆</span>  
<span style="margin-left: 2em">山南境及嘉兴海盐三县地立华亭县仍属于吴僖</span>  
<span style="margin-left: 2em">宗入蜀时群盗盘结为王腾所据吴越王钱镠遣顾</span>  
<span style="margin-left: 2em">全武拔之遂为吴越地晋天福五年以嘉兴县为秀</span>  
<span style="margin-left: 2em">州而割华亭隶焉宋庆元元年秀州升嘉兴府仍属</span>  
<span style="margin-left: 2em">嘉兴元至元十四年升华亭府<sub class="note-yuan">时以县五万户者为州华亭户登二十三万故立为府</sub>十五年改松江府<sub class="note-yuan">以吴松江名</sub>属江浙行省嘉兴</span>  
<span style="margin-left: 2em">路二十九年割华亭东北五乡为上海县直隶省府</span>  
<span style="margin-left: 2em">泰定三年罢以两县属嘉兴路立都水庸田使司于</span>  
<span style="margin-left: 2em">府治天历元年罢司复府元末张士诚据之至正二</span>  
<span style="margin-left: 2em">十七年春正月知府王立中归附直隶</span>  
<span style="margin-left: 1em">京师仍领县二曰华亭曰上海</span>  
<span style="margin-left: 2em">华亭县附府城建置沿革具于府初县之立本割昆</span>  
<span style="margin-left: 2em">山嘉兴海盐三县地故境与三县接姑苏志又云长</span>  
<span style="margin-left: 2em">洲割地入华亭今长洲亦邻壤也或以县有华亭镇</span>  
<span style="margin-left: 2em">印遂谓自镇为县不知镇者唐因隋制置镇将副以</span>  
<span style="margin-left: 2em">掌捍防守御之事特县之冗职耳祥符图经载镇在</span>  
<span style="margin-left: 2em">县西南二百步元丰九域志始废不书如自镇为县</span>  
<span style="margin-left: 2em">则郡国舆地诸书不应略而不言也新唐史书望九</span>  
<span style="margin-left: 2em">域志书紧元既即县为府因为属邑</span>  
<span style="margin-left: 1em">国朝因之</span>  
<span style="margin-left: 2em">上海县在府东北九十里本华亭县地旧曰华亭海</span>  
<span style="margin-left: 2em">后以人烟浩穰海舶辐辏遂成大市宋于其地立市</span>  
<span style="margin-left: 2em">舶提举司及榷货场曰上海镇其立以为县则知府</span>  
<span style="margin-left: 2em">仆散翰文之请也以地居海之上洋故名曰上海亦</span>  
<span style="margin-left: 2em">称为上洋云</span>  
<span style="margin-left: 4em">分野</span>  
<span style="margin-left: 3em">历代星书皆以斗牛为吴越之分野虽互有同异</span>  
<span style="margin-left: 3em">而大要不出乎此松江本吴地故具列占验以俟</span>  
<span style="margin-left: 3em">知星者攷焉</span>  
<span style="margin-left: 1em">黄帝分星次斗十一度至婺女七度曰须女又曰星纪</span>  
<span style="margin-left: 2em">于辰在丑于律为黄钟</span>  
<span style="margin-left: 1em">周礼保章氏注星纪吴越也</span>  
<span style="margin-left: 1em">尔雅星纪斗牵牛吴分野</span>  
<span style="margin-left: 1em">西汉天文志斗江湖牵牛婺女扬州地里志吴地斗分</span>  
<span style="margin-left: 2em">野越地牵牛婺女之分野</span>  
<span style="margin-left: 1em">费直起斗十度至女五度为星纪蔡邕起斗六度至须</span>  
<span style="margin-left: 2em">女二度为星纪大雪冬至居之吴越之分野</span>  
<span style="margin-left: 1em">陈卓范蠡诸人分星次丹阳入斗十六度会稽入牛一</span>  
<span style="margin-left: 2em">度</span>  
<span style="margin-left: 1em">晋天文志南斗十二度至须女七度为星纪吴越之分</span>  
<span style="margin-left: 2em">野</span>  
<span style="margin-left: 1em">宋两朝天文志天市东垣南第六星曰吴越</span>  
<span style="margin-left: 1em">左传昭公三十三年夏吴伐越史墨曰越得岁而吴伐</span>  
<span style="margin-left: 2em">之必受其凶至哀公二十二年越灭吴</span>  
<span style="margin-left: 1em">符坚议寇晋太子左卫率石越对曰今岁镇星守斗牛</span>  
<span style="margin-left: 2em">福德在吴悬象无差未可犯也符融曰岁镇在<sub class="note-jiao">校：鎮下疑脫在字今補</sub>斗牛吴越之福坚不听大败而还</span>  
<span style="margin-left: 1em">宋建炎初国步艰虞占者望牛斗间有紫气既而移跸</span>  
<span style="margin-left: 2em">维扬是岁冬十月孝宗生于嘉兴其验如此</span>  
<span style="margin-left: 2em">按松江直嘉兴之东吴郡之东南先朝为二郡属邑</span>  
<span style="margin-left: 2em">相去皆百余里参考占验盖斗之分野云</span>  
<span style="margin-left: 4em">疆域</span>  
<span style="margin-left: 3em">松江虽名富饶郡其实古一县尔分而为二庸赋</span>  
<span style="margin-left: 3em">日滋而封域犹故也观于此可以知民力云</span>  
<span style="margin-left: 1em">元嘉兴路松江府境东西一百六十里南北一百七十</span>  
<span style="margin-left: 2em">三里<sub class="note-yuan">东至海八十里西至平江路长洲县界八十里南至海九十里北至平江路昆山县界八十里东南到海中明州界九十里西南到海盐县界六十里到县一百二十里东北到昆山县界一百二十里到县一百三十里西北到昆山县界一百五十里到县二百里陆路西南至嘉兴县界六十里水路同东北至青龙镇五十四里水路自青龙入吴松江同见嘉禾志</sub></span>  
<span style="margin-left: 1em">元直隶松江府境东西一百六十里南北一百七十三</span>  
<span style="margin-left: 2em">里<sub class="note-yuan">东至海八十里西至平江路长洲县界八十里南至海九十里以小官浦为界北至平江路昆山县界八十里东南到海明州界九十里西南到嘉兴路海盐县界六十里东北到昆山县界一百十里西北到昆山县界一百五十里</sub></span>  
<span style="margin-left: 2em">华亭县东西一百五里南北一百十六里<sub class="note-yuan">东至乌泥泾四十五里西至枫泾六十里南至金山八十里北至簳山三十六里</sub></span>  
<span style="margin-left: 2em">上海县东西四十八里南北一百里<sub class="note-yuan">东至江湾一十八里西至乌泥泾三十里南至下沙场五十里北至青龙镇五十里</sub></span>  
<span style="margin-left: 1em">国朝松江府境东西一百六十里南北一百五十二里</span>  
<span style="margin-left: 2em"><sub class="note-yuan">东至大海一百里到海无际西至苏州府长洲县界六十里到吴江县一百二十里南至金山卫七十二里到海无际北至苏州府昆山县吴松江北岸界八十里到昆山县一百三十里东南到青村千户所一百十里西南到嘉兴府一百二十里东北到苏州府嘉定县一百三十里西北到苏州府一百八十里自府治至京师三千八百二十五里至南京八百里</sub></span>  
<span style="margin-left: 2em">华亭县东西七十八里南北一百二十六里<sub class="note-yuan">东至上海县语儿泾十八里到上海县九十里西至苏州府长洲县界六十里到吴县一百二十里南至海七十二里到海无际北至上海县唐行镇五十四里到昆山县一百三十里东南到青村千户所一百一十里西南到嘉兴府一百二十里西北到苏州府一百八十里东北到上海县九十里</sub></span>  
<span style="margin-left: 2em">上海县东西一百六十里南北九十里<sub class="note-yuan">东至大海五十里到海无际西至华亭县界一百一十里到苏州府一百八十里南至华亭县界七十二里到下沙场六十里北至嘉定县界十八里到吴松江巡检司十二里东南到南汇觜千户所八十里西南到本府九十里东北到嘉定县江湾巡检司一十四里西北到嘉定县界七十二里</sub></span>  
<span style="margin-left: 4em">山</span>  
<span style="margin-left: 3em">府境诸山皆自杭天目而来累累然隐起平畴间</span>  
<span style="margin-left: 3em">长谷以东通波以西望之如列宿排障东南涵浸</span>  
<span style="margin-left: 3em">沧海烟涛空翠亦各极其趣焉而九峰之名特著</span>  
<span style="margin-left: 3em">故首列之其次序则见题咏<sub class="note-yuan">九峰中惟天马佘山最高玉屏斯下矣昆山又下于玉屏此有目所见也旧志称干山七十丈薛山九十丈昆山乃一百五十丈岂其然乎故不计其丈尺机山最西北云去府二十里细林近东南乃二十五里况竹屿浮苏在沧波浩渺中谁能测之故不详其道里然其概亦略可见矣</sub></span>  
<span style="margin-left: 1em">昆山府西北二十三里长谷之东陆氏之先葬此后机</span>  
<span style="margin-left: 2em">云兄弟有辞学人以为玉出昆冈因名山形圆秀而</span>  
<span style="margin-left: 2em">润傍无附丽望之如覆盎然苏县名昆山义取乎此</span>  
<span style="margin-left: 2em">因其地有马鞌山俗误为昆松人遂以小昆自名其</span>  
<span style="margin-left: 2em">实非也<sub class="note-yuan">元凌喦诗九峰西峙比昆仑晋代将军墓尚存今日扪萝登绝顶桑丘麦垄自村村钱惟善年年载酒酹榆枌征北将军尚有坟赖得陆家双白璧自从入洛世无闻</sub></span>  
<span style="margin-left: 1em">横云山在昆山东北本名横山天宝六载易今名或云</span>  
<span style="margin-left: 2em">以陆士龙名也山多古墓胜国时尝遭发掘获器物</span>  
<span style="margin-left: 2em">甚多辍耕录所记古铜水滴号神人狮子者亦出于</span>  
<span style="margin-left: 2em">此盖陆氏物也其巅有白龙洞潜通淀湖深不可测</span>  
<span style="margin-left: 2em">下有祭龙坛岁旱祷焉宋皇祐中浙西旱蝗华亭令</span>  
<span style="margin-left: 2em">吴及祷于此立致甘澍蝗不入境今山阳采石阙然</span>  
<span style="margin-left: 2em">成洼如失面目近岁府同知张什下令禁之然山民</span>  
<span style="margin-left: 2em">力田不给以石为生特未能止也<sub class="note-yuan">凌嵒诗七峰崷崪拥层峦偃盖孤松石上蟠行雨白龙何处去暮云深锁洞门寒钱惟善兄弟词华不世逢青山相对若为容洞门深锁烟岚湿犹指空坛祭白龙</sub></span>  
<span style="margin-left: 1em">小横山在横云东中限一水嶐然而兴上多璺石多万</span>  
<span style="margin-left: 2em">年松俗呼僊人浇酒石由绝顶至东北皆峰峦隐起</span>  
<span style="margin-left: 2em">壁立数仞色尽赭游人呼为小赤壁尽壁斩然一罅</span>  
<span style="margin-left: 2em">如虎丘试劒石状前有石可踞而坐下瞰小涧亦九</span>  
<span style="margin-left: 2em">峰奇绝处也<sub class="note-yuan">国朝钱溥游和东坡赤壁怀古念奴娇词三江既入到今来谁是风尘表物秀列九峰非夏口亦有丹崖翠壁烟锁平原云横积石欲吊情何雪时归典午可怜失此双杰何异孟德当年蒙冲蔽岸一炬东风发万古功名同一梦祇有文章难灭夜静江空犹闻鹤唳耸起人毛发坡仙如在要分两处风月</sub></span>  
<span style="margin-left: 1em">机山在横云后南北相望以陆士衡得名山下有平原</span>  
<span style="margin-left: 2em">村亦以机为平原内史也前有陂泽人家散布汀岸</span>  
<span style="margin-left: 2em">隐然若图画云<sub class="note-yuan">凌嵒诗六峰乔木锁云根青接平原数里村此处无人来听鹤海灵山鬼哭黄昏钱惟善烟径云林树色昏千寻乔木见名门横峰亦有尚书墓只酹平原内史魂</sub></span>  
<span style="margin-left: 1em">干山在机山东有水纡廻从横云来经其间北去西北</span>  
<span style="margin-left: 2em">诸山之最高大者以形如天马称为天马山其曰干</span>  
<span style="margin-left: 2em">者或传干将曾此铸劒旧图经则云有干姓者居此</span>  
<span style="margin-left: 2em">圆智寺记亦谓山后皆干氏所有故名山上多琳宫</span>  
<span style="margin-left: 2em">梵宇春时游人甚盛画船歌吹遥从绿野细水中来</span>  
<span style="margin-left: 2em">纚纚不绝岳祠之侧有来鹤轩其西穿堂当小山石</span>  
<span style="margin-left: 2em">壁若屏障然右瞰泖湖一白万顷凭高凝竚恍然如</span>  
<span style="margin-left: 2em">隔世外云山顶有双石鱼相传风雨化去其胁有泉</span>  
<span style="margin-left: 2em">游人掬以颒面云能明目<sub class="note-yuan">凌嵒诗八峰葱蒨石林幽给事题诗记胜游昨夜僧归钟鼓静一声鹤唳海天秋钱惟善干氏千年居此山题诗给事最幽闲春浓海岳开晴色游子烧香画舫还</sub></span>  
<span style="margin-left: 1em">淀山机山西北旧志云在薛淀湖中山形四出如鼇上</span>  
<span style="margin-left: 2em">建浮图下有龙洞云通太湖山屹立湖中亦落星浮</span>  
<span style="margin-left: 2em">玉之类傍有小山初年仅两席许久之寖长寺僧筑</span>  
<span style="margin-left: 2em">亭其上牓曰明极当时好事者遂即山中所有曰鼇</span>  
<span style="margin-left: 2em">峰塔<sub class="note-yuan">今寺法堂地</sub>曰龙渊桥曰潜龙洞曰通灵泉<sub class="note-yuan">桥在山阳洞在山阴泉在山巅宋慧灯禅师凿石十六丈得此初名寒穴钱野人衮以名袭金山且下有龙洞因易今名</sub></span>
