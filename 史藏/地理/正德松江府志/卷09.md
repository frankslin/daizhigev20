## 正德松江府志卷之九　城池　坊巷　乡保　镇市

<span style="margin-left: 4em">城池</span>  
<span style="margin-left: 3em">府界海隅古称乐土虽建邦作邑而重险之制阔</span>  
<span style="margin-left: 3em">焉今之治城胜国僭侯之为我役也而濒海之地</span>  
<span style="margin-left: 3em">列筑相望皆自昔所未备者可无述乎</span>  
<span style="margin-left: 1em">府城周围九里一百七十三步高丈有八尺池广十丈</span>  
<span style="margin-left: 2em">深七尺余陆门四水门四东曰披云西曰谷阳南曰</span>  
<span style="margin-left: 2em">集僊北曰通波<sub class="note-yuan">谷阳旧居披云集僊以桥通波以塘并知府陈威题</sub>榜门各有</span>  
<span style="margin-left: 2em">楼楼外为月城元末张士诚据吴时所筑</span>  
<span style="margin-left: 1em">国朝因而葺之其地后殿九峰前襟黄浦大海环其东</span>  
<span style="margin-left: 2em">南三江绕乎西北平畴沃野四望极目东南之重地</span>  
<span style="margin-left: 2em">也城之南为吴王猎场场有五茸俗因呼为五茸城</span>  
<span style="margin-left: 2em">云<sub class="note-yuan">国朝章简诗城郭何年号五茸盘回十里控吴松旌旗晓障芙蓉日鼓角寒生苜蓿风云起北山连雉堞波澄南海熄狼烽登高一望民风厚楼阁重重烟雨中</sub></span>  
<span style="margin-left: 1em">金山卫城在府城南七十二里西连乍浦东接青村周</span>  
<span style="margin-left: 2em">一十二里三百步有奇高二丈八尺池周于城深丈</span>  
<span style="margin-left: 2em">有八尺面广十二丈陆门八水门一门楼四南曰镇</span>  
<span style="margin-left: 2em">海北曰拱北角楼四腰楼八敌台八间以箭楼凡四</span>  
<span style="margin-left: 2em">十八其外营堡烽堠气势联络隐若金汤<sub class="note-yuan">知府樊莹登城楼诗孤城周匝倚江干大海微茫入望宽蜃气半收初霁日潮声渐细已回澜鱼盐有利民空羡谷粟无功我愧飧独喜四夷时贡献将军不用事征鞍</sub></span>  
<span style="margin-left: 1em">青村城在金山城东一百里周围六里高二丈五尺池</span>  
<span style="margin-left: 2em">广二十有四丈深七尺余城门四上各有楼外各有</span>  
<span style="margin-left: 2em">月城角楼四敌台十有一箭楼二十八</span>  
<span style="margin-left: 1em">南汇觜城在青村北五十里周围九里百三十步高二</span>  
<span style="margin-left: 2em">丈二尺池周于城深七尺余广二十有四丈陆门四</span>  
<span style="margin-left: 2em">水门四门楼角楼各四敌台四箭楼四十</span>  
<span style="margin-left: 3em">已上三城俱洪武十九年安远侯筑永乐十五年</span>  
<span style="margin-left: 3em">都指挥谷祥增筑金山城池增筑时指挥侯端等</span>  
<span style="margin-left: 3em">濬治弘治初指挥使翁熊重修</span>  
<span style="margin-left: 4em">附记古城</span>  
<span style="margin-left: 1em">金山城<sub class="note-yuan">按枢要云周康王东游镇大海筑此城南接金山因以为名</sub></span>  
<span style="margin-left: 1em">前京城<sub class="note-yuan">今府东八十五里旧经云地近京浦故名</sub></span>

<span style="margin-left: 1em">胥浦城<sub class="note-yuan">府南四十里梁大通六年立地接胥浦因名</sub></span>
