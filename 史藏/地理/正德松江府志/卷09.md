## 正德松江府志卷之九　城池　坊巷　鄉保　鎮市

<span style="margin-left: 4em">城池</span>  
<span style="margin-left: 3em">府界海隅古稱樂土雖建邦作邑而重險之制闊</span>  
<span style="margin-left: 3em">焉今之治城勝國僭侯之爲我役也而瀕海之地</span>  
<span style="margin-left: 3em">列築相望皆自昔所未備者可無述乎</span>  
<span style="margin-left: 1em">府城周圍九里一百七十三步高丈有八尺池廣十丈</span>  
<span style="margin-left: 2em">深七尺餘陸門四水門四東曰披雲西曰谷陽南曰</span>  
<span style="margin-left: 2em">集僊北曰通波<sub class="note-yuan">谷陽舊居披雲集僊以橋通波以塘並知府陳威題</sub>榜門各有</span>  
<span style="margin-left: 2em">樓樓外爲月城元末張士誠據吳時所築</span>  
<span style="margin-left: 1em">國朝因而葺之其地後殿九峯前襟黃浦大海環其東</span>  
<span style="margin-left: 2em">南三江繞乎西北平疇沃野四望極目東南之重地</span>  
<span style="margin-left: 2em">也城之南爲吳王獵場場有五茸俗因呼爲五茸城</span>  
<span style="margin-left: 2em">云<sub class="note-yuan">國朝章簡詩城郭何年號五茸盤回十里控吳松旌旗曉障芙蓉日鼓角寒生苜蓿風雲起北山連雉堞波澄南海熄狼烽登高一望民風厚樓閣重重煙雨中</sub></span>  
<span style="margin-left: 1em">金山衛城在府城南七十二里西連乍浦東接青村周</span>  
<span style="margin-left: 2em">一十二里三百步有奇高二丈八尺池周於城深丈</span>  
<span style="margin-left: 2em">有八尺面廣十二丈陸門八水門一門樓四南曰鎮</span>  
<span style="margin-left: 2em">海北曰拱北角樓四腰樓八敵臺八間以箭樓凡四</span>  
<span style="margin-left: 2em">十八其外營堡烽堠氣勢聯絡隱若金湯<sub class="note-yuan">知府樊瑩登城樓詩孤城周匝倚江干大海微茫入望寬蜃氣半收初霽日潮聲漸細已回瀾魚鹽有利民空羨穀粟無功我愧飱獨喜四夷時貢獻將軍不用事征鞍</sub></span>  
<span style="margin-left: 1em">青村城在金山城東一百里周圍六里高二丈五尺池</span>  
<span style="margin-left: 2em">廣二十有四丈深七尺餘城門四上各有樓外各有</span>  
<span style="margin-left: 2em">月城角樓四敵臺十有一箭樓二十八</span>  
<span style="margin-left: 1em">南匯觜城在青村北五十里周圍九里百三十步高二</span>  
<span style="margin-left: 2em">丈二尺池周於城深七尺餘廣二十有四丈陸門四</span>  
<span style="margin-left: 2em">水門四門樓角樓各四敵臺四箭樓四十</span>  
<span style="margin-left: 3em">已上三城俱洪武十九年安遠侯築永樂十五年</span>  
<span style="margin-left: 3em">都指揮谷祥增築金山城池增築時指揮侯端等</span>  
<span style="margin-left: 3em">濬治弘治初指揮使翁熊重修</span>  
<span style="margin-left: 4em">附記古城</span>  
<span style="margin-left: 1em">金山城<sub class="note-yuan">按樞要云周康王東遊鎮大海築此城南接金山因以爲名</sub></span>
