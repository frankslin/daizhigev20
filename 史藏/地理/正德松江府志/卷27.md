## 正德松江府志卷之二十七　人物一（名臣）

<span style="margin-left: 4em">人物一<sub class="note-yuan">名臣</sub></span>  
<span style="margin-left: 3em">地之重以人其來尚矣雲間人物唐以前最盛者</span>  
<span style="margin-left: 3em">陸氏而前志或遺焉矧韜光沈馨遯世不見者今</span>  
<span style="margin-left: 3em">之所錄不敢汎亦不敢以略云其所未及則以俟</span>  
<span style="margin-left: 3em">夫後之君子<sub class="note-yuan">前志云雲間人物自東漢有聞焉陸康之祖續以獨行著續祖閎建武中爲尚書令范史稱會稽吳人世爲族姓遡而上之其先十一世祖烈爲吳令豫章都尉葬于胥亭子孫遂爲吳人此則機雲先世也推而下之玩玄孫慧曉仕齊終輔國將軍自玩至其孫萬載世爲侍中皆有名行時人方之金張慧曉之子僚任倕並有美名時稱三陸慧曉兄子閑爲揚州別駕四子厥絳完襄完生雲公中書黃門郎後有瓊瑗瑜玠琛皆閑之裔史各有傳俱稱吳人雖爲陸氏子孫然安知其悉居華亭邪按劉璡至吳聞張融與慧曉並宅其間有池命駕往酌則慧曉已居吳郡矣舊圖經嘉禾志所載人物止及冢墓之在兹邑者而顧野王陸禕乃闕不著今倣其舊而補所遺焉唐錢起考功送陸贄擢第還蘇州詩云鄉路歸何早雲間喜擅名又云華亭養仙羽計日再飛鳴據華亭雲間等語則宣公之先疑亦有華亭居者然宣公生於天寶以後史傳稱嘉興人故不復載云按前志謂陸氏子孫非盡居華亭又不載宣公於策故其說如此然所引錢詩及後載魏了翁學記皆公爲縣人之明證記稱虞魏顧陸通言吳郡而居華亭者尤著亦不謂其子孫盡爲邑人也況元感葬在崑山顧謙卒於崧宅銘誌具存而皆棄不錄故續志補書而通志因之史謂陸烈葬胥亭子孫遂爲吳人又謂陸康使從孫遜與子績將家還吳居於長谷學記所謂居華亭者蓋指康以下而言自此而自則有不可知矣前志叙自康始爲得其實故今從之而餘仍通志云</sub></span>  
<span style="margin-left: 1em">漢陸康字季寧續少子褒之子也少篤孝悌勤修操行</span>  
<span style="margin-left: 2em">太守潁川李肅舉以孝廉肅後坐事誅歛尸送喪還</span>  
<span style="margin-left: 2em">鄉行服以義烈稱刺史臧旻舉茂才除渤海高成令</span>  
<span style="margin-left: 2em">縣在邊陲舊制令户一人具弓弩以備不虞不得行</span>  
<span style="margin-left: 2em">來<sub class="note-yuan">猶往來也</sub>長吏新到輒發民繕修城郭康至皆罷遣百</span>  
<span style="margin-left: 2em">姓大悦以恩信爲治寇盜亦息州郡表上其狀光和</span>  
<span style="margin-left: 2em">元年遷武陵太守轉桂陽樂安二郡所在稱之時靈</span>  
<span style="margin-left: 2em">帝欲鑄銅人而國用不足乃詔民田畝歛十錢而比</span>  
<span style="margin-left: 2em">年水旱傷稼百姓貧苦康上疏諫內倖因譖康大不</span>  
<span style="margin-left: 2em">敬檻車徵詣廷尉侍御史劉岱爲表陳解免歸田里</span>  
<span style="margin-left: 2em">復徵拜議郎會廬江賊黃穰等與江夏蠻連結十餘</span>  
<span style="margin-left: 2em">萬人攻破四縣拜康廬江太守康申明賞罰擊破穰</span>  
<span style="margin-left: 2em">等餘黨悉降帝嘉其功拜康孫尚爲郎中獻帝即位</span>  
<span style="margin-left: 2em">天下大亂康蒙險遣孝廉計吏奉貢詔書策勞加忠</span>  
<span style="margin-left: 2em">義將軍秩中二千石時袁術屯壽春部曲饑餓遣使</span>  
<span style="margin-left: 2em">求委輸兵甲康以其叛逆閉門不通修戰備以禦之</span>  
<span style="margin-left: 2em">術怒遣將孫策攻康圍城數重康固守受敵二年城</span>  
<span style="margin-left: 2em">陷月餘發病卒年七十宗族百餘人遭離飢戹死者</span>  
<span style="margin-left: 2em">將半朝廷憫其守節拜子儁爲郎中少子績</span>  
<span style="margin-left: 1em">績字公紀年六歲於九江見袁術術出橘績懷三枚去</span>  
<span style="margin-left: 2em">拜辭墮地術謂曰陸郎作賓客而懷橘乎績跪答曰</span>  
<span style="margin-left: 2em">欲歸遺母術大奇之孫策在吳張昭張纮秦松爲上</span>  
<span style="margin-left: 2em">賓共論四海未泰當用武治而平之績年少末坐遥</span>  
<span style="margin-left: 2em">大聲言曰昔管夷吾相齊桓公九合諸侯一匡天下</span>  
<span style="margin-left: 2em">不用兵車孔子曰遠人不服則修文德以來之今論</span>  
<span style="margin-left: 2em">者不務道德懷取之術而惟尚武績雖童蒙竊所未</span>  
<span style="margin-left: 2em">安也昭等異焉績容瀉雄壯博學多識星曆筭數無</span>  
<span style="margin-left: 2em">不該覽虞翻舊齒名盛龐統荆州令士年亦差長皆</span>  
<span style="margin-left: 2em">與績友善孫權辟爲奏曹掾以直道見憚出爲鬱林</span>  
<span style="margin-left: 2em">太守加偏將軍績既有躄疾又意在儒雅非其志也</span>  
<span style="margin-left: 2em">雖有軍事著述不廢作渾天圖注易釋玄皆傳于世</span>  
<span style="margin-left: 2em">豫自知亡日爲辭以訣自謂有漢志士吳郡陸績幼</span>  
<span style="margin-left: 2em">勤詩書長玩禮易受命南征罹疾遇戹遭命不幸嗚</span>  
<span style="margin-left: 2em">呼悲隔卒年三十二長子宏會稽南部都尉次子叡</span>  
<span style="margin-left: 2em">長水校尉</span>  
<span style="margin-left: 1em">吳陸遜字伯言少孤隨從祖廬江太守康在官袁術與</span>  
<span style="margin-left: 2em">康有隙將攻康遣遜及親戚還吳遜年長於康子績</span>  
<span style="margin-left: 2em">數歲爲之綱紀門户孫權爲將軍遜年二十一始仕</span>  
<span style="margin-left: 2em">幕府歷東西曹令史出爲海昌屯田都尉并領縣事</span>  
<span style="margin-left: 2em"><sub class="note-yuan">海昌今鹽官縣</sub>縣連年亢旱遜開倉以賑貧民勸督農桑百</span>  
<span style="margin-left: 2em">姓蒙賴時會稽山賊潘臨歷年不禽遜召兵討治所</span>  
<span style="margin-left: 2em">向皆服部曲已有二千餘人鄱陽賊尤突作亂復往</span>  
<span style="margin-left: 2em">討之拜定威校尉軍屯利浦權以兄策女配遜以爲</span>  
<span style="margin-left: 2em">帳下右部督丹陽賊費棧受曹操印綬扇動山越爲</span>  
<span style="margin-left: 2em">內應權遣遜討棧應時破散遂部伍東三郡彊者爲</span>  
<span style="margin-left: 2em">兵羸者補户得精卒數萬人宿惡盪除所過肅清還</span>  
<span style="margin-left: 2em">屯蕪湖會稽太守淳于式表遜枉取民人所在愁擾</span>  
<span style="margin-left: 2em">遜後詣都言次稱式佳吏權曰式白君而君薦之何</span>  
<span style="margin-left: 2em">也遜對曰式意欲養民是以白遜若遜復毁式以亂</span>  
<span style="margin-left: 2em">聖聽不可長也權曰此誠長者事顧人不能爲耳呂</span>  
<span style="margin-left: 2em">蒙稱疾詣建業遜往見之謂關羽矜其驍氣陵轢於</span>  
<span style="margin-left: 2em">人始有大功意驕志逸但務北進未嫌於我今出其</span>  
<span style="margin-left: 2em">不意自可禽制若見至尊宜好爲計蒙至都權問誰</span>  
<span style="margin-left: 2em">可代卿者蒙對曰陸遜意思深長才堪負重觀其規</span>  
<span style="margin-left: 2em">慮終可大任而未有遠名非羽所忌若用之當令外</span>  
<span style="margin-left: 2em">自韜隱內察形便然後可克乃召遜拜偏將軍右部</span>  
<span style="margin-left: 2em">督代蒙遜至陸口書與羽曰前承觀釁而動以律行</span>  
<span style="margin-left: 2em">師小舉大克一何巍巍敵國敗績利在同盟近以不</span>  
<span style="margin-left: 2em">敏受任來西延慕光塵思禀良規又曰于禁等見獲</span>  
<span style="margin-left: 2em">遐邇欣歎以爲將軍之勲足以長世雖昔晉文城濮</span>  
<span style="margin-left: 2em">之師淮陰拔趙之略蔑以尚兹聞徐晃等步騎駐旌</span>  
<span style="margin-left: 2em">闚望麾葆操猾虜也忿不思難恐潛增衆以逞其心</span>  
<span style="margin-left: 2em">雖云師老猶有驍悍且戰捷之後常苦輕敵古人杖</span>  
<span style="margin-left: 2em">術軍勝彌警願將軍廣爲方計以全獨克僕書生疏</span>  
<span style="margin-left: 2em">遲忝所不堪喜鄰威德樂自傾盡雖未合策猶可懷</span>  
<span style="margin-left: 2em">也倘明注仰有以察之羽覽遜書有謙下自托之意</span>  
<span style="margin-left: 2em">意大安無所復嫌遜具啓形狀陳其可禽之要權乃</span>  
<span style="margin-left: 2em">潛軍而上使遜與蒙爲前部至即克公安南郡遜逕</span>  
<span style="margin-left: 2em">進領宜都太守拜撫邊將軍封華亭侯是歲建安二</span>  
<span style="margin-left: 2em">十四年十一月也遜遣將軍李異等將三千人攻蜀</span>  
<span style="margin-left: 2em">將詹晏陳鳳又攻房陵太守鄧輔南鄉太守郭睦大</span>  
<span style="margin-left: 2em">破之秭歸大姓文布鄧凱等合夷兵數千人首尾西</span>  
<span style="margin-left: 2em">方遜復討破布凱布脱走蜀以爲將遜令人誘之布</span>  
<span style="margin-left: 2em">帥衆還降前後斬獲拓納數萬計權以遜爲右護軍</span>  
<span style="margin-left: 2em">鎮西將軍進封婁侯權欲令歷本州舉命乃使揚州</span>  
<span style="margin-left: 2em">牧呂範就辟別駕從事舉茂才黃武元年劉備率大</span>  
<span style="margin-left: 2em">衆來向西界權命遜爲大都督假節督朱然等五萬</span>  
<span style="margin-left: 2em">人拒之備從巫峽建平連圍至夷陵界立數十屯遣</span>  
<span style="margin-left: 2em">吳班將數千人于平地立營欲以挑戰諸將皆欲擊</span>  
<span style="margin-left: 2em">之遜曰此必有譎且觀之備知計不可乃引伏兵八</span>  
<span style="margin-left: 2em">千從谷中出遜曰所以不聽諸君擊班者揣之必有</span>  
<span style="margin-left: 2em">巧故也諸將並曰攻備當在初今乃令入五六百里</span>  
<span style="margin-left: 2em">相銜持經七八月其諸要害皆已固守擊之必無利</span>  
<span style="margin-left: 2em">矣遜曰備更嘗事多其軍始集思慮精專未可干也</span>  
<span style="margin-left: 2em">今住已久不得我便兵疲意沮計不復生乃先攻一</span>  
<span style="margin-left: 2em">營不利諸將皆曰空殺兵耳遜曰吾已曉破之之術</span>  
<span style="margin-left: 2em">乃敕各持一把茅以火攻拔之諸軍同時俱攻斬張</span>  
<span style="margin-left: 2em">南馮習等破其四十餘營備將杜路等窮迫請降備</span>  
<span style="margin-left: 2em">升馬鞍山陳兵自繞遜督促諸軍四面蹙之土崩瓦</span>  
<span style="margin-left: 2em">解死者萬數備因夜遁驛人自擔燒鎧斷後僅得入</span>  
<span style="margin-left: 2em">白帝城其舟船器械水步軍資一時略盡尸骸塞江</span>  
<span style="margin-left: 2em">而下初孫桓別討備前鋒于夷道爲備所圍求捄于</span>  
<span style="margin-left: 2em">遜遜曰安東得士衆心城牢糧足無足憂也待吾計</span>  
<span style="margin-left: 2em">展欲不救安東安東自解及方略大施備果奔潰加</span>  
<span style="margin-left: 2em">拜輔國將軍領荆州牧改封江陵侯備亡子禪襲位</span>  
<span style="margin-left: 2em">諸葛亮秉政與權連和時事所宜權輒令遜語亮并</span>  
<span style="margin-left: 2em">刻權印以置遜所權每與禪亮書常過示遜輕重可</span>  
<span style="margin-left: 2em">否有所不安便令改定以印封行之七年權使鄱陽</span>  
<span style="margin-left: 2em">太守周魴譎魏大司馬曹休休果舉衆入皖乃召遜</span>  
<span style="margin-left: 2em">假黃鉞爲大都督逆休遜自爲中部令朱桓全琮爲</span>  
<span style="margin-left: 2em">左右翼三道俱進果衝休伏兵因之追亡逐北至夾</span>  
<span style="margin-left: 2em">石斬獲萬餘牛馬騾驢車乘萬兩軍資器械俱盡休</span>  
<span style="margin-left: 2em">還疽發背死諸軍振旅過武昌權令左右以御蓋覆</span>  
<span style="margin-left: 2em">遜入出殿門所賜皆御物上珍時莫與比遣還西陵</span>  
<span style="margin-left: 2em">黃龍元年拜上大將軍右都護是歲權東巡建業留</span>  
<span style="margin-left: 2em">太子徵遜輔太子并掌荆州及豫章三郡事董督軍</span>  
<span style="margin-left: 2em">國時建昌侯慮於堂前作鬭鴨欄頗施小巧遜正色</span>  
<span style="margin-left: 2em">曰侯宜勤覽經典以自新益用此何爲慮即時毁撤</span>  
<span style="margin-left: 2em">之射聲校尉松於公子中最親戲兵不整遜對之髠</span>  
<span style="margin-left: 2em">其職吏嘉禾五年權北征使遜與諸葛瑾攻襄陽遜</span>  
<span style="margin-left: 2em">遣親人韓扁齎表奉報遇敵于沔中得扁瑾聞之甚</span>  
<span style="margin-left: 2em">懼書與遜云大駕已旋賊得韓扁具知吾闊狹且水</span>  
<span style="margin-left: 2em">乾宜當急去遜未答方催人種葑豆與諸將奕棋射</span>  
<span style="margin-left: 2em">戲如常瑾曰伯言多智略其當有以自來見遜遜曰</span>  
<span style="margin-left: 2em">賊知大駕已旋無所復戚得專力於吾又已守要害</span>  
<span style="margin-left: 2em">之處兵將意動且當自定以安之施設變術然後出</span>  
<span style="margin-left: 2em">耳今便示退當謂吾怖仍來相蹙必敗之勢也乃密</span>  
<span style="margin-left: 2em">與瑾立計令瑾督舟船遜悉上兵馬以向襄陽城敵</span>  
<span style="margin-left: 2em">素憚遜遽還赴城瑾便引船出遜徐整部伍張拓聲</span>  
<span style="margin-left: 2em">勢步趨船敵不敢干軍到白圍託言住獵潛遣將軍</span>  
<span style="margin-left: 2em">周峻張梁等擊江夏新市安陸石陽市盛峻等奄至</span>  
<span style="margin-left: 2em">人皆捐物入城城門噎不得關敵乃白斮殺己民然</span>

<span style="margin-left: 2em">無非夜光五河吐流泉源如一其弘麗妍贍英鋭漂</span>  
<span style="margin-left: 2em">逸亦一代之絶乎其爲人所推服如此然好游權門</span>
