## 正德松江府志卷之二十七　人物一（名臣）

<span style="margin-left: 4em">人物一<sub class="note-yuan">名臣</sub></span>  
<span style="margin-left: 3em">地之重以人其来尚矣云间人物唐以前最盛者</span>  
<span style="margin-left: 3em">陆氏而前志或遗焉矧韬光沈馨遯世不见者今</span>  
<span style="margin-left: 3em">之所录不敢泛亦不敢以略云其所未及则以俟</span>  
<span style="margin-left: 3em">夫后之君子<sub class="note-yuan">前志云云间人物自东汉有闻焉陆康之祖续以独行著续祖闳建武中为尚书令范史称会稽吴人世为族姓溯而上之其先十一世祖烈为吴令豫章都尉葬于胥亭子孙遂为吴人此则机云先世也推而下之玩玄孙慧晓仕齐终辅国将军自玩至其孙万载世为侍中皆有名行时人方之金张慧晓之子僚任倕并有美名时称三陆慧晓兄子闲为扬州别驾四子厥绛完襄完生云公中书黄门郎后有琼瑗瑜玠琛皆闲之裔史各有传俱称吴人虽为陆氏子孙然安知其悉居华亭邪按刘琎至吴闻张融与慧晓并宅其间有池命驾往酌则慧晓已居吴郡矣旧图经嘉禾志所载人物止及冢墓之在兹邑者而顾野王陆祎乃阙不著今倣其旧而补所遗焉唐钱起考功送陆贽擢第还苏州诗云乡路归何早云间喜擅名又云华亭养仙羽计日再飞鸣据华亭云间等语则宣公之先疑亦有华亭居者然宣公生于天宝以后史传称嘉兴人故不复载云按前志谓陆氏子孙非尽居华亭又不载宣公于策故其说如此然所引钱诗及后载魏了翁学记皆公为县人之明证记称虞魏顾陆通言吴郡而居华亭者尤著亦不谓其子孙尽为邑人也况元感葬在昆山顾谦卒于崧宅铭志具存而皆弃不录故续志补书而通志因之史谓陆烈葬胥亭子孙遂为吴人又谓陆康使从孙逊与子绩将家还吴居于长谷学记所谓居华亭者盖指康以下而言自此而自则有不可知矣前志叙自康始为得其实故今从之而余仍通志云</sub></span>  
<span style="margin-left: 1em">汉陆康字季宁续少子褒之子也少笃孝悌勤修操行</span>  
<span style="margin-left: 2em">太守颍川李肃举以孝廉肃后坐事诛歛尸送丧还</span>  
<span style="margin-left: 2em">乡行服以义烈称刺史臧旻举茂才除渤海高成令</span>  
<span style="margin-left: 2em">县在边陲旧制令户一人具弓弩以备不虞不得行</span>  
<span style="margin-left: 2em">来<sub class="note-yuan">犹往来也</sub>长吏新到辄发民缮修城郭康至皆罢遣百</span>  
<span style="margin-left: 2em">姓大悦以恩信为治寇盗亦息州郡表上其状光和</span>  
<span style="margin-left: 2em">元年迁武陵太守转桂阳乐安二郡所在称之时灵</span>  
<span style="margin-left: 2em">帝欲铸铜人而国用不足乃诏民田亩歛十钱而比</span>  
<span style="margin-left: 2em">年水旱伤稼百姓贫苦康上疏谏内幸因谮康大不</span>  
<span style="margin-left: 2em">敬槛车征诣廷尉侍御史刘岱为表陈解免归田里</span>  
<span style="margin-left: 2em">复征拜议郎会庐江贼黄穰等与江夏蛮连结十余</span>  
<span style="margin-left: 2em">万人攻破四县拜康庐江太守康申明赏罚击破穰</span>  
<span style="margin-left: 2em">等余党悉降帝嘉其功拜康孙尚为郎中献帝即位</span>  
<span style="margin-left: 2em">天下大乱康蒙险遣孝廉计吏奉贡诏书策劳加忠</span>  
<span style="margin-left: 2em">义将军秩中二千石时袁术屯寿春部曲饥饿遣使</span>  
<span style="margin-left: 2em">求委输兵甲康以其叛逆闭门不通修战备以御之</span>  
<span style="margin-left: 2em">术怒遣将孙策攻康围城数重康固守受敌二年城</span>  
<span style="margin-left: 2em">陷月余发病卒年七十宗族百余人遭离饥戹死者</span>  
<span style="margin-left: 2em">将半朝廷悯其守节拜子俊为郎中少子绩</span>  
<span style="margin-left: 1em">绩字公纪年六岁于九江见袁术术出橘绩怀三枚去</span>  
<span style="margin-left: 2em">拜辞堕地术谓曰陆郎作宾客而怀橘乎绩跪答曰</span>  
<span style="margin-left: 2em">欲归遗母术大奇之孙策在吴张昭张纮秦松为上</span>  
<span style="margin-left: 2em">宾共论四海未泰当用武治而平之绩年少末坐遥</span>  
<span style="margin-left: 2em">大声言曰昔管夷吾相齐桓公九合诸侯一匡天下</span>  
<span style="margin-left: 2em">不用兵车孔子曰远人不服则修文德以来之今论</span>  
<span style="margin-left: 2em">者不务道德怀取之术而惟尚武绩虽童蒙窃所未</span>  
<span style="margin-left: 2em">安也昭等异焉绩容泻雄壮博学多识星历筭数无</span>  
<span style="margin-left: 2em">不该览虞翻旧齿名盛庞统荆州令士年亦差长皆</span>  
<span style="margin-left: 2em">与绩友善孙权辟为奏曹掾以直道见惮出为郁林</span>  
<span style="margin-left: 2em">太守加偏将军绩既有躄疾又意在儒雅非其志也</span>  
<span style="margin-left: 2em">虽有军事著述不废作浑天图注易释玄皆传于世</span>  
<span style="margin-left: 2em">豫自知亡日为辞以诀自谓有汉志士吴郡陆绩幼</span>  
<span style="margin-left: 2em">勤诗书长玩礼易受命南征罹疾遇戹遭命不幸呜</span>  
<span style="margin-left: 2em">呼悲隔卒年三十二长子宏会稽南部都尉次子叡</span>  
<span style="margin-left: 2em">长水校尉</span>  
<span style="margin-left: 1em">吴陆逊字伯言少孤随从祖庐江太守康在官袁术与</span>  
<span style="margin-left: 2em">康有隙将攻康遣逊及亲戚还吴逊年长于康子绩</span>  
<span style="margin-left: 2em">数岁为之纲纪门户孙权为将军逊年二十一始仕</span>  
<span style="margin-left: 2em">幕府历东西曹令史出为海昌屯田都尉并领县事</span>  
<span style="margin-left: 2em"><sub class="note-yuan">海昌今盐官县</sub>县连年亢旱逊开仓以赈贫民劝督农桑百</span>  
<span style="margin-left: 2em">姓蒙赖时会稽山贼潘临历年不禽逊召兵讨治所</span>  
<span style="margin-left: 2em">向皆服部曲已有二千余人鄱阳贼尤突作乱复往</span>  
<span style="margin-left: 2em">讨之拜定威校尉军屯利浦权以兄策女配逊以为</span>  
<span style="margin-left: 2em">帐下右部督丹阳贼费栈受曹操印绶扇动山越为</span>  
<span style="margin-left: 2em">内应权遣逊讨栈应时破散遂部伍东三郡彊者为</span>  
<span style="margin-left: 2em">兵羸者补户得精卒数万人宿恶荡除所过肃清还</span>  
<span style="margin-left: 2em">屯芜湖会稽太守淳于式表逊枉取民人所在愁扰</span>  
<span style="margin-left: 2em">逊后诣都言次称式佳吏权曰式白君而君荐之何</span>  
<span style="margin-left: 2em">也逊对曰式意欲养民是以白逊若逊复毁式以乱</span>  
<span style="margin-left: 2em">圣听不可长也权曰此诚长者事顾人不能为耳吕</span>  
<span style="margin-left: 2em">蒙称疾诣建业逊往见之谓关羽矜其骁气陵轹于</span>  
<span style="margin-left: 2em">人始有大功意骄志逸但务北进未嫌于我今出其</span>  
<span style="margin-left: 2em">不意自可禽制若见至尊宜好为计蒙至都权问谁</span>  
<span style="margin-left: 2em">可代卿者蒙对曰陆逊意思深长才堪负重观其规</span>  
<span style="margin-left: 2em">虑终可大任而未有远名非羽所忌若用之当令外</span>  
<span style="margin-left: 2em">自韬隐内察形便然后可克乃召逊拜偏将军右部</span>  
<span style="margin-left: 2em">督代蒙逊至陆口书与羽曰前承观衅而动以律行</span>  
<span style="margin-left: 2em">师小举大克一何巍巍敌国败绩利在同盟近以不</span>  
<span style="margin-left: 2em">敏受任来西延慕光尘思禀良规又曰于禁等见获</span>  
<span style="margin-left: 2em">遐迩欣叹以为将军之勲足以长世虽昔晋文城濮</span>  
<span style="margin-left: 2em">之师淮阴拔赵之略蔑以尚兹闻徐晃等步骑驻旌</span>  
<span style="margin-left: 2em">闚望麾葆操猾虏也忿不思难恐潜增众以逞其心</span>  
<span style="margin-left: 2em">虽云师老犹有骁悍且战捷之后常苦轻敌古人杖</span>  
<span style="margin-left: 2em">术军胜弥警愿将军广为方计以全独克仆书生疏</span>  
<span style="margin-left: 2em">迟忝所不堪喜邻威德乐自倾尽虽未合策犹可怀</span>  
<span style="margin-left: 2em">也倘明注仰有以察之羽览逊书有谦下自托之意</span>  
<span style="margin-left: 2em">意大安无所复嫌逊具启形状陈其可禽之要权乃</span>  
<span style="margin-left: 2em">潜军而上使逊与蒙为前部至即克公安南郡逊径</span>  
<span style="margin-left: 2em">进领宜都太守拜抚边将军封华亭侯是岁建安二</span>  
<span style="margin-left: 2em">十四年十一月也逊遣将军李异等将三千人攻蜀</span>  
<span style="margin-left: 2em">将詹晏陈凤又攻房陵太守邓辅南乡太守郭睦大</span>  
<span style="margin-left: 2em">破之秭归大姓文布邓凯等合夷兵数千人首尾西</span>  
<span style="margin-left: 2em">方逊复讨破布凯布脱走蜀以为将逊令人诱之布</span>  
<span style="margin-left: 2em">帅众还降前后斩获拓纳数万计权以逊为右护军</span>  
<span style="margin-left: 2em">镇西将军进封娄侯权欲令历本州举命乃使扬州</span>  
<span style="margin-left: 2em">牧吕范就辟别驾从事举茂才黄武元年刘备率大</span>  
<span style="margin-left: 2em">众来向西界权命逊为大都督假节督朱然等五万</span>  
<span style="margin-left: 2em">人拒之备从巫峡建平连围至夷陵界立数十屯遣</span>  
<span style="margin-left: 2em">吴班将数千人于平地立营欲以挑战诸将皆欲击</span>  
<span style="margin-left: 2em">之逊曰此必有谲且观之备知计不可乃引伏兵八</span>  
<span style="margin-left: 2em">千从谷中出逊曰所以不听诸君击班者揣之必有</span>  
<span style="margin-left: 2em">巧故也诸将并曰攻备当在初今乃令入五六百里</span>  
<span style="margin-left: 2em">相衔持经七八月其诸要害皆已固守击之必无利</span>  
<span style="margin-left: 2em">矣逊曰备更尝事多其军始集思虑精专未可干也</span>  
<span style="margin-left: 2em">今住已久不得我便兵疲意沮计不复生乃先攻一</span>  
<span style="margin-left: 2em">营不利诸将皆曰空杀兵耳逊曰吾已晓破之之术</span>  
<span style="margin-left: 2em">乃敕各持一把茅以火攻拔之诸军同时俱攻斩张</span>  
<span style="margin-left: 2em">南冯习等破其四十余营备将杜路等穷迫请降备</span>  
<span style="margin-left: 2em">升马鞍山陈兵自绕逊督促诸军四面蹙之土崩瓦</span>  
<span style="margin-left: 2em">解死者万数备因夜遁驿人自担烧铠断后仅得入</span>  
<span style="margin-left: 2em">白帝城其舟船器械水步军资一时略尽尸骸塞江</span>  
<span style="margin-left: 2em">而下初孙桓别讨备前锋于夷道为备所围求捄于</span>  
<span style="margin-left: 2em">逊逊曰安东得士众心城牢粮足无足忧也待吾计</span>  
<span style="margin-left: 2em">展欲不救安东安东自解及方略大施备果奔溃加</span>  
<span style="margin-left: 2em">拜辅国将军领荆州牧改封江陵侯备亡子禅袭位</span>  
<span style="margin-left: 2em">诸葛亮秉政与权连和时事所宜权辄令逊语亮并</span>  
<span style="margin-left: 2em">刻权印以置逊所权每与禅亮书常过示逊轻重可</span>  
<span style="margin-left: 2em">否有所不安便令改定以印封行之七年权使鄱阳</span>  
<span style="margin-left: 2em">太守周鲂谲魏大司马曹休休果举众入皖乃召逊</span>  
<span style="margin-left: 2em">假黄钺为大都督逆休逊自为中部令朱桓全琮为</span>  
<span style="margin-left: 2em">左右翼三道俱进果冲休伏兵因之追亡逐北至夹</span>  
<span style="margin-left: 2em">石斩获万余牛马骡驴车乘万两军资器械俱尽休</span>  
<span style="margin-left: 2em">还疽发背死诸军振旅过武昌权令左右以御盖覆</span>  
<span style="margin-left: 2em">逊入出殿门所赐皆御物上珍时莫与比遣还西陵</span>  
<span style="margin-left: 2em">黄龙元年拜上大将军右都护是岁权东巡建业留</span>  
<span style="margin-left: 2em">太子征逊辅太子并掌荆州及豫章三郡事董督军</span>  
<span style="margin-left: 2em">国时建昌侯虑于堂前作鬭鸭栏颇施小巧逊正色</span>  
<span style="margin-left: 2em">曰侯宜勤览经典以自新益用此何为虑即时毁撤</span>  
<span style="margin-left: 2em">之射声校尉松于公子中最亲戏兵不整逊对之髠</span>  
<span style="margin-left: 2em">其职吏嘉禾五年权北征使逊与诸葛瑾攻襄阳逊</span>  
<span style="margin-left: 2em">遣亲人韩扁赍表奉报遇敌于沔中得扁瑾闻之甚</span>  
<span style="margin-left: 2em">惧书与逊云大驾已旋贼得韩扁具知吾阔狭且水</span>  
<span style="margin-left: 2em">乾宜当急去逊未答方催人种葑豆与诸将奕棋射</span>  
<span style="margin-left: 2em">戏如常瑾曰伯言多智略其当有以自来见逊逊曰</span>  
<span style="margin-left: 2em">贼知大驾已旋无所复戚得专力于吾又已守要害</span>  
<span style="margin-left: 2em">之处兵将意动且当自定以安之施设变术然后出</span>  
<span style="margin-left: 2em">耳今便示退当谓吾怖仍来相蹙必败之势也乃密</span>  
<span style="margin-left: 2em">与瑾立计令瑾督舟船逊悉上兵马以向襄阳城敌</span>  
<span style="margin-left: 2em">素惮逊遽还赴城瑾便引船出逊徐整部伍张拓声</span>  
<span style="margin-left: 2em">势步趋船敌不敢干军到白围托言住猎潜遣将军</span>  
<span style="margin-left: 2em">周峻张梁等击江夏新市安陆石阳市盛峻等奄至</span>  
<span style="margin-left: 2em">人皆捐物入城城门噎不得关敌乃白斮杀己民然</span>  
<span style="margin-left: 2em">后得阖斩获凡千余人所生得皆加营护不令兵士</span>  
<span style="margin-left: 2em">侵侮将家属来者使料视若亡其妻子者给衣粮慰</span>  
<span style="margin-left: 2em">劳遣还有感慕相携而归者邻境怀之六年中郎将</span>  
<span style="margin-left: 2em">周祗乞于鄱阳召募事下问逊逊以为此郡民易动</span>  
<span style="margin-left: 2em">难安不可恐致贼寇而祗固陈取之郡民吴遽等果</span>  
<span style="margin-left: 2em">作贼杀祗攻没诸县豫章庐陵宿恶并应为寇逊闻</span>  
<span style="margin-left: 2em">辄讨皆相率降得精兵八千余人三郡平赤乌七年</span>
