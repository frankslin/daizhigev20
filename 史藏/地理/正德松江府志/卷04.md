## 正德松江府志卷之四　风俗

<span style="margin-left: 4em">风俗</span>  
<span style="margin-left: 3em">吴好劒客而士多创瘢楚好细腰而国多馁死言</span>  
<span style="margin-left: 3em">俗之系乎上也王豹之于淇绵驹之于齐右独无</span>  
<span style="margin-left: 3em">责乎松之风俗见于志者几变矣观其变而世可</span>  
<span style="margin-left: 3em">知岁时节物农圃工技有关于是亦以类附焉</span>  
<span style="margin-left: 1em">松故吴之裔壤僻远之乡也然负海枕江水环山拱自</span>  
<span style="margin-left: 2em">成一都会民生其间多秀而敏其习尚亦各有所宗</span>  
<span style="margin-left: 2em">盖自东都以后陆氏居之康绩以行谊闻逊抗以功</span>  
<span style="margin-left: 2em">业显而机云之词学尤著国人化之梁有顾希冯唐</span>  
<span style="margin-left: 2em">有陆敬舆至宋而科名盛矣故其俗文<sub class="note-yuan">旧志云文贤人物之盛前后相望虞魏之昆顾陆之裔虽通言吴郡而居华亭者为尤著又曰士奋于学民兴于仁</sub>原泽沃</span>  
<span style="margin-left: 2em">衍有鱼稻海盐之富商贾辐辏故其俗多有康僧会</span>  
<span style="margin-left: 2em">船子夹山之遗踪故尚佛有金山柘湖之灵迹故信</span>  
<span style="margin-left: 2em">鬼神好淫祀有三甲五甲之风故或号难理其所由</span>  
<span style="margin-left: 2em">来远矣<sub class="note-yuan">旧志云习俗奢靡淫神以祈福佞佛以避祸濒海之人习水以趋利抚之则易驯扰之则不易治</sub>自版籍归职方士习不变科</span>  
<span style="margin-left: 2em">诏始下人材已彬彬然百余年来文物衣冠蔚为东</span>  
<span style="margin-left: 2em">南之望经学词章下至书翰咸有师法各称名家田</span>  
<span style="margin-left: 2em">野小民生理裁足皆知以教子孙读书为事畏官府</span>  
<span style="margin-left: 2em">贱告讦租税百万如期而集无逾岁者虽词诉盈庭</span>  
<span style="margin-left: 2em">终未尝有一言犯上淫放不孝之刑几措而不举间</span>  
<span style="margin-left: 2em">有犯者至摈而不容于乡新志所谓士皆慕学而乐</span>  
<span style="margin-left: 2em">于仕进者不乏细民虽曰健讼而淳良者居多盖谦</span>  
<span style="margin-left: 2em">辞也夫衣食足则礼义兴文华胜则淳朴散今日之</span>  
<span style="margin-left: 2em">俗识者未尝不喜其盛而忧其弊也知其弊而防之</span>  
<span style="margin-left: 2em">以保其盛实有望于在位之君子云</span>  
<span style="margin-left: 1em">诸州外县多朴质附郭多繁华吾松则反是盖东北五</span>  
<span style="margin-left: 2em">乡故为海商驰骛之地而其南纯事耕织故所习不</span>  
<span style="margin-left: 2em">同如此大率府城之俗谨绳墨畏清议而其流也失</span>  
<span style="margin-left: 2em">之隘上海之俗喜事功尚意气而其流也失之夸</span>  
<span style="margin-left: 1em">尚清雅饰玩好境内皆然而西南为盛畏首事喜随众</span>  
<span style="margin-left: 2em">则府城以之<sub class="note-yuan">谚所谓松江齐者以此</sub></span>  
<span style="margin-left: 1em">四时节物畧与吴门同岁首邻里交贺骑服华焕杂遝</span>  
<span style="margin-left: 2em">街市二四日乃已春日观土牛茹春饼以生菜作春</span>  
<span style="margin-left: 2em">盘七日八日九日士女会佛寺名龙华上旬之暮女</span>  
<span style="margin-left: 2em">子邀厕姑问吉凶男子不得至十有三日家人即灶</span>  
<span style="margin-left: 2em">卜流年事握一秫谷投焦金爆之以花而妍者吉名</span>  
<span style="margin-left: 2em">卜流花<sub class="note-yuan">苏志云爆孛娄亦名米花</sub>女子遂间彩穿花戴于鬓鬟以</span>  
<span style="margin-left: 2em">相夸尚元夕采竹柏结棚于通衢作灯市游人来往</span>  
<span style="margin-left: 2em">达曙是夕燕饮以油䭔珍珠圆子为节食<sub class="note-yuan">灯有满园春众星奉月绣毬鉴装鬬鸡走马诸名色皆刻饰楮帛或琉璃鱼魫竹丝麦秸菩提叶等为之四周县带剪簇彩绘尤极精丽往时一枚有直数十缗者</sub>烟火尤盛<sub class="note-yuan">其制以火药实纸卷中大小数百为一架植巨木县之凡十余层层层施机火至药发光怪百出若龙蛇飞走帘幕灯火星斗人物花果之类粲然若神近岁饥馑相仍此风寥落矣</sub>十七日普照寺作大蜡烛会士女阗</span>  
<span style="margin-left: 2em">咽七日方散<sub class="note-yuan">今不复见</sub>月内家读莲华经谓保安坊市醮</span>  
<span style="margin-left: 2em">章谓禳火寒食日拜扫先墓插竹悬纸钱谓之摽墓</span>  
<span style="margin-left: 2em">清明折柳插簷遨嬉园圃<sub class="note-yuan">元时女子有秋千戏今无</sub>三月载歌咢</span>  
<span style="margin-left: 2em">游礼干山岳祠<sub class="note-yuan">先时巫者舁土偶循门索钱结缕为幡胜云以奉岳神谓之钱幡会</sub>四</span>  
<span style="margin-left: 2em">月八日浮屠浴佛及迎华光会重五军校䄍柳于教</span>  
<span style="margin-left: 2em">场<sub class="note-yuan">东京梦华录以柳枝插于地数骑以刬子箭或弓或弩振策驰而射之谓之䄍柳枝金史及于中元重阳行拜天礼礼毕射柳于毬场斯䄍之所自也</sub>午正贴门符缚艾人系百</span>  
<span style="margin-left: 2em">索噉角黍浮雄黄菖蒲酒夏至复作角黍𥲻新麦特</span>  
<span style="margin-left: 2em">牲祠先于正寝月内廛闬启醮谓禳瘟六月十九日</span>  
<span style="margin-left: 2em">庆观音大士七夕以茜鸡菱藕之类作乞巧会男女</span>  
<span style="margin-left: 2em">罗拜月下<sub class="note-yuan">苏志谓之小儿节</sub>中元祀祖考以素羞僧舍设斋</span>  
<span style="margin-left: 2em">为人荐亡曰盂兰盆会<sub class="note-yuan">苏志云鬼节</sub>八月朔收露水磨墨</span>  
<span style="margin-left: 2em">点小儿女额谓之天灸中秋登楼台赏月观鹤<sub class="note-yuan">前志朱之纯三山亭诗坐看双鹤落云间注华亭每中秋夜有仙鹤下</sub>是月田家祀先农醵</span>  
<span style="margin-left: 2em">钱为会曰青苗社亦曰谢天会九月初市沽新酒名</span>  
<span style="margin-left: 2em">开清<sub class="note-yuan">酒有三等上曰短水中曰九峰下曰清</sub>重阳蒸菊糕<sub class="note-yuan">武林旧事载菊糕以糖肉秫面杂揉为之上缕肉丝鸭饼缀以榴颗标以彩旗</sub>舂红𩜴荐先然后对菊泛</span>  
<span style="margin-left: 2em">茱萸尝新酒十月朔开炉以面裹菠菜为饼献祠堂</span>  
<span style="margin-left: 2em">复拜扫先墓<sub class="note-yuan">苏志云烧衣节</sub>冬至治花糕刲羊豕祀先三日</span>  
<span style="margin-left: 2em">罢市交贺如首岁吹鼓喧窴号豁听更互结宴名分</span>  
<span style="margin-left: 2em">冬酒<sub class="note-yuan">重冬至而畧岁节谚云肥冬瘦年出豹隐纪谈</sub>腊月糳岁计米曰冬舂</span>  
<span style="margin-left: 2em"><sub class="note-yuan">俗云至春舂则耗而多蛀</sub>二十四日暮祠灶谓之送灶妇女不得</span>  
<span style="margin-left: 2em">参祀用粉团糖饼以谓灶神朝天言人过失用糖取</span>  
<span style="margin-left: 2em">胶牙之意<sub class="note-yuan">陆龟蒙祀灶解灶之坏者请新之既成又请择吉日以祀之曰灶在祀典闻之旧矣祭法曰王为群姓立七祀其一曰灶达于庶人庶士立一祀或立户或立灶饮食之事先自火化以来生民赖之祀之可也说者曰其神居人间伺察小过作谴告者又曰灶鬼以时录人功过上白于天当祀之以祈福祥此仅出汉武帝时方士之言耳行之惑也苟行君子之道养老而慈幼寒同而饱均丧有哀祭有敬不忘礼以约己不忘乐以和心室暗不欺屋漏不媿虽岁不一祀灶其诬我乎苟为小人之道尽反君子之行父子兄弟夫妇人执一爨以自糊口专利以饰诈崇奸而树非虽一岁百祀灶其私我乎天至高灶至下帝至尊严鬼至幽仄果能欺而告之是不忠也听而受之是不明也下不忠上不明又果何以为天帝乎</sub>是日扫屋尘曰除残<sub class="note-yuan">苏俗在二十七日</sub>明日举家食赤</span>  
<span style="margin-left: 2em">豆粥云辟瘟出外者亦留与名口数粥及饷亲里之</span>  
<span style="margin-left: 2em">持丧者<sub class="note-yuan">范至能岁暮十事其口数粥行有云家家腊月二十五淅米如珠和豆煮大杓轑铛分口数疫鬼闻香走无处</sub>丐者饰鬼神傩于街市除日奉先暮烧籸</span>  
<span style="margin-left: 2em">盆爆竹<sub class="note-yuan">韵会注籸粉滓也一曰粥凝又岁时杂记除夕作蕡烛以麻籸浓油如庭燎律有元日油籸之文今籸盆是也或作籸俗又呼生盆生气也杀阴生阳也琐碎录岁旦爆竹于庭世谓庭燎之礼非也神异经云西方山中有人长尺余人见之则病寒热名曰山臊以竹著火中爆烞有声则惊遁而去</sub></span>  
<span style="margin-left: 2em">邻互擎炒豆相逆佥搦而交纳之且餐且祈曰凑投</span>  
<span style="margin-left: 2em"><sub class="note-yuan">去声</sub>炳烛爚芗烧苍术辟瘟丹复祀灶谓之接灶仪与</span>  
<span style="margin-left: 2em">送侔田间秉高炬名照田蚕<sub class="note-yuan">田家五行云田蚕看火色以占来年白主水红主旱猛烈主丰萎衰主歉</sub>昏时封井画灰于地象戈矢云以辟邪</span>  
<span style="margin-left: 2em">老幼围炉守岁夜分禬瘟神易门神桃符写春帖五</span>  
<span style="margin-left: 2em">鼓一筹更烛炷香陈果设醊祝冢神参祠堂然后举</span>  
<span style="margin-left: 2em">家东向立自卑而尊饮屠苏酒饮釂尊者就席以次</span>  
<span style="margin-left: 2em">贺毕遂出贺此一岁风俗之大畧也</span>  
<span style="margin-left: 1em">吉凶多沿俗礼冠不备三加婚不亲迎丧事尚佛老用</span>  
<span style="margin-left: 2em">声乐祭多以俗节而婚丧之费尤侈<sub class="note-yuan">上海益甚</sub>士大夫间</span>  
<span style="margin-left: 2em">行古礼闾里亦多慕之然循习既久未能悉变也</span>  
<span style="margin-left: 1em">农家最勤习以为常至有终岁之劳无一朝之余苟免</span>  
<span style="margin-left: 2em">公私之扰则自以为幸无怨尤者前辈士大夫起自</span>  
<span style="margin-left: 2em">田里者亦身亲为之妇女馌饷外耘获车灌率与男</span>  
<span style="margin-left: 2em">子共事故视他郡虽劳苦倍之而男女皆能自立汉</span>  
<span style="margin-left: 2em">志所谓啙窳偷生今无是也</span>  
<span style="margin-left: 1em">农无田者为人佣耕曰长工农月暂佣者曰忙工田多</span>  
<span style="margin-left: 2em">而人少者倩人为助已而还之曰伴工</span>  
<span style="margin-left: 1em">耕作之具视古耒耜经尤悉<sub class="note-yuan">陆龟蒙耒耜经农之言也民之习通谓之犂冶金而为之者曰犂镜曰犂壁斵木而为之者曰犂底曰压镵曰策额曰犂箭曰犂辕曰犂梢曰犂评曰犂建曰犂槃木金凡十有一事耕之上曰墢墢犹块也起其墢者镵也覆其墢者壁也草之生必布于墢不覆之无以绝其本根故镵引而居下壁偃而居上镵表上利壁形其圆负镵者曰底底初实于镵中工谓之鼈肉底之次曰压镵背有二乳系于压镵之两旁镵之次曰策额言可以捍其壁也皆貤然相戴自策额达于犂底纵而贯之曰箭前如桯而樛者曰辕后如柄而乔者曰梢辕有越加箭可弛张焉辕之上又有如槽形亦如箭焉刻为级前高而后庳所故曰箭以其浅深类可否故曰评评之上曲而衡之者曰建建揵也所以柅其辕与评无是则二物跃而出箭不能止横于辕之前末曰槃言可转也左右系以㭴乎轭也</sub></span>  
<span style="margin-left: 2em">辕之后末曰梢中在手所以执耕者也辕<sub class="note-jiao">校：轅字疑訛或爲取]車之胸梢取舟之尾止乎此乎鑱長一尺四寸廣六寸壁廣長皆尺微橢底長四尺廣四寸評底過壓鑱二尺策減壓鑱四寸廣狹與底同箭高三尺評尺有三寸槃增評尺七焉建惟稱轅修九尺梢得其半轅至梢中間掩四尺犂之終始丈有二耕而後有爬渠疏之義也散發去芟者焉爬而有礰礋焉有磣碡焉自爬至礰礋皆有齒磟碡觚稜而已咸以木爲之堅而重者良江東之田器盡於是</sub>无牛犂者以刀耕<sub class="note-yuan">其制如锄而四齿谓之铁搭人日耕一亩率十人当一牛</sub>灌田以水车<sub class="note-yuan">即古桔橰之制而巧过之其制以板为槽长二寻有奇广尺三寸至五寸深五寸许傍夹以栏楯中斵木为鹤膝施楗以联之屈伸回旋用持辐以运水辐之度取槽足以容诸楯之半各施木以隔之其下取辐可以运曰戢辐以竹破而两之施其上以行辐无此则辐陷而不行槽前后各施轴前长而后短各施操以关辐前轴之两端为拨人以足运之轴运则辐转而水升前之安轴者曰眠牛其后附于楯曰鹿耳椓杙于眠牛之两旁施横木以为凭而运车曰车桁高乡之车深八寸广七寸曰水龙凡一车用三人至六人日灌田二十亩</sub>有不用人而</span>  
<span style="margin-left: 2em">以牛运者<sub class="note-yuan">其制为木槃如车轮而大周施牙以运轴而转之力省而功倍</sub>有并牛不</span>  
<span style="margin-left: 2em">用而以风运者<sub class="note-yuan">其制如牛车施帆于轮乘风旋转田器之巧极于是然不可常用大风起亦败车</sub>冬寒为屋以藏牛谓之牛囤即唐人所谓牛宫</span>  
<span style="margin-left: 2em"><sub class="note-yuan">陆龟蒙记牛宫词并序冬十月耕牛违寒筑宫纳而造之建之前日老农请乞灵于土官以从乡教予勉之而为辞四牸三牯中一去乳天霜降寒纳此室处老农拘拘度地不亩东西几何七举其武南北几何丈二加五偶楹当间载尺入土太岁在亥余不足数上缔蓬茅下远官府耕耨何时饮食得所或寝或卧免风免雨宜尔子孙实我仓庾</sub></span>  
<span style="margin-left: 1em">农人占测气候雨旸丰歉多有征验其书谓之田家五</span>  
<span style="margin-left: 2em">行亦参以众说元旦侵晨占风云云青为虫白为兵</span>  
<span style="margin-left: 2em">赤为旱黑为水黄为丰年自元旦至于十二日以瓶</span>
