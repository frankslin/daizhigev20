## 正德松江府志卷之三十二　遺事　祥異

<span style="margin-left: 4em">遺事<sub class="note-yuan">祥異附</sub></span>  
<span style="margin-left: 3em">鄉邦遺事有無所附屬而可以廣見聞示懲勸者</span>  
<span style="margin-left: 3em">類於此災祥變異係境內者附書之備太史之闕</span>  
<span style="margin-left: 3em">遺也</span>  
<span style="margin-left: 1em">陸機初入洛詣侍中王濟濟指羊酪謂機曰卿吳中何</span>  
<span style="margin-left: 2em">以敵此答曰千里蓴羹末下鹽豉時人稱爲名對</span>  
<span style="margin-left: 1em">陸雲與荀隱初未相識嘗會張華坐華曰今日相遇可</span>  
<span style="margin-left: 2em">勿爲常談雲因抗手曰雲間陸士龍隱曰日下荀鳴</span>  
<span style="margin-left: 2em">鶴鳴鶴隱字也雲又曰既開青雲覩白雉何不張爾</span>  
<span style="margin-left: 2em">弓挾爾矢華曰荀何遲隱曰本謂雲龍騤騤今乃山</span>  
<span style="margin-left: 2em">鹿野麋獸微弩强是以發遲華撫掌大笑今華亭稱</span>  
<span style="margin-left: 2em">雲間蓋起於此</span>  
<span style="margin-left: 1em">亭林寶雲寺初名法雲在市西北隅石晉天福五年壞</span>  
<span style="margin-left: 2em">於水開運初始遷於南將成寺僧二人各夢二青衣</span>  
<span style="margin-left: 2em">來云梁朝侍郎至也俄一人紫衣金魚儀狀秀整謂</span>  
<span style="margin-left: 2em">僧曰此地吾之故宅荒廢久矣汝今於此建寺可立</span>  
<span style="margin-left: 2em">吾像吾當護此寺也明日各言所夢尚疑未之信是</span>  
<span style="margin-left: 2em">夕又夢云水際古碑可以爲據明日果獲碑字皆磨</span>  
<span style="margin-left: 2em">滅獨一片分明云寺南高基顧野王曾於此修輿地</span>  
<span style="margin-left: 2em">志僧遂於寺之東偏選材作室并二青衣祠焉今爲</span>  
<span style="margin-left: 2em">寺之伽藍神</span>  
<span style="margin-left: 1em">宋楊備郎中天聖中爲長溪令忽夢作詩云月俸蚨錢</span>  
<span style="margin-left: 2em">數甚微不知從宦幾時歸東吳一片輕波在欲問何</span>  
<span style="margin-left: 2em">人買釣磯意甚異之明道初爲華亭令丁內艱遂家</span>  
<span style="margin-left: 2em">吳中樂其土風安之因悟夢中語嘗效白樂天作我</span>  
<span style="margin-left: 2em">愛姑蘇好十章又作姑蘇百題詩行於世</span>  
<span style="margin-left: 1em">衛仲達字達可秀州華亭人爲館職時因病夢入冥府</span>  
<span style="margin-left: 2em">立庭下伺命有四人坐其上西向少年者呼曰與他</span>  
<span style="margin-left: 2em">檢一檢三人難之少年曰若不檢如何行遣三人曰</span>  
<span style="margin-left: 2em">渠已是合還何必檢恐出手不得耳少年意不可回</span>  
<span style="margin-left: 2em">呼朱衣吏諭意吏捧牙盤而上中置紅黑牌二紅者</span>  
<span style="margin-left: 2em">以金書善字黑者白書惡字少年指黑吏持以去少</span>  
<span style="margin-left: 2em">焉數人捧簿書出盈庭即有一秤横前兩首皆有柈</span>  
<span style="margin-left: 2em">吏舉簿置東柈重壓至地地爲動衛立不能安三人</span>  
<span style="margin-left: 2em">皆失色曰向固云不可檢今果爾奈何少年亦慘怛</span>  
<span style="margin-left: 2em">有悔意須臾曰更與檢善看指金字牌忽西北隅微</span>  
<span style="margin-left: 2em">明如落照狀一朱衣道士捧玉盤出四人皆起立道</span>  
<span style="margin-left: 2em">士至居中而坐望玉盤中文書僅如箸大吏持下寘</span>  
<span style="margin-left: 2em">西柈柈亦壓地而東柈高舉向空大風歘起捲其紙</span>  
<span style="margin-left: 2em">蔽天如烏鳶亂飛無一存焉四人起相賀命席延衛</span>  
<span style="margin-left: 2em">坐衛拱手曰仲達年未四十平生不敢爲過惡何由</span>  
<span style="margin-left: 2em">簿書充塞如此少年曰心善者惡輕心惡者惡重舉</span>  
<span style="margin-left: 2em">念不正此即書之何必真犯然已灰滅無餘矣衛謝</span>  
<span style="margin-left: 2em">曰是則然矣敢問善狀何事也少年曰朝廷興工修</span>  
<span style="margin-left: 2em">三山石橋君曾上書諫此乃奏藁也衛曰雖曾上廈</span>  
<span style="margin-left: 2em">朝廷不從何益於事曰事之在君者盡矣君言得用</span>  
<span style="margin-left: 2em">豈止活數萬人命君當位極人臣奈惡簿頗多猶不</span>  
<span style="margin-left: 2em">失八座勉之遂遣人導歸衛後至吏部尚書</span>  
<span style="margin-left: 1em">華亭尉廳舊有閣李綱父公夔元豐初爲尉綱生於閣</span>  
<span style="margin-left: 2em">下後爲南渡名相因呼爲相公閣</span>  
<span style="margin-left: 1em">吳潛父爲下沙鹽場官潛侍父讀書於此既而魁多士</span>  
<span style="margin-left: 2em">爲開慶名相後人即其地立義塾云</span>  
<span style="margin-left: 1em">鄭聞游學華亭與錢良臣同舍紹興間魁南省後與錢</span>  
<span style="margin-left: 2em">並參大政嘗題名于學之達材齋後人以碧紗籠之</span>  
<span style="margin-left: 2em">爲一時盛事</span>  
<span style="margin-left: 1em">劉璧知華亭日有鸛集堂前悲鳴類有所訴者劉顧而</span>  
<span style="margin-left: 2em">言曰豈非爲人毁汝巢或取汝子乎鸛俯首而聽立</span>  
<span style="margin-left: 2em">遣左右物色之鸛隨以往至普照寺鴟吻聲愈切乃</span>  
<span style="margin-left: 2em">惡少年挾彈斃其雛而鸛悲譟不已寺僮厭其喧聒</span>  
<span style="margin-left: 2em">遂併巢毁之左右還鸛亦隨至劉曰我知之矣便當</span>  
<span style="margin-left: 2em">爲汝追治亦不動少頃捕少年及僮到庭下各杖之</span>  
<span style="margin-left: 2em">然後振翼飛鳴而去<sub class="note-yuan">出夷堅志</sub></span>  
<span style="margin-left: 1em">普照寺有北方天王祠宋時雷震祠柱倒書曰高洞楊</span>  
<span style="margin-left: 2em">雅一十六人火令章凡十一字內令章兩字特奇勁</span>  
<span style="margin-left: 2em">似唐人書<sub class="note-yuan">出筆談</sub></span>  
<span style="margin-left: 1em">盛肇居青龍勝果寺好食牛肉與陳氏子友善陳遣僕</span>  
<span style="margin-left: 2em">約旦日會食視其簡乃匀碧牋一幅內大書曰萬物</span>  
<span style="margin-left: 2em">皆心化唯牛最苦辛君看横死者盡是食牛人肇驚</span>  
<span style="margin-left: 2em">顧呼其僕已不見旦而詢諸陳氏亦未嘗遣也肇自</span>  
<span style="margin-left: 2em">此不食牛<sub class="note-yuan">出夷堅志</sub></span>  
<span style="margin-left: 1em">章生青龍人著羽衣服能作墨有古法其家製墨聚煙</span>  
<span style="margin-left: 2em">列盌三十餘中夕掃煤無一存者明日乃在主翁閨</span>  
<span style="margin-left: 2em">中煤皆成花其三爲壽星長松覆之玉女在傍玄鶴</span>  
<span style="margin-left: 2em">靈芝宛如善繪者所作二爲牡丹五爲禽魚餘爲荔</span>  
<span style="margin-left: 2em">枝胡桃棗杏梨栗咸具焉其家以爲瑞呼道士醮而</span>  
<span style="margin-left: 2em">陳之以答靈貺云<sub class="note-yuan">出鬼董</sub></span>  
<span style="margin-left: 1em">胥浦鄉周氏有女名喜姑嘗救活二雛燕于蛇螫明年</span>  
<span style="margin-left: 2em">女卒春燕來周章哀鳴如欲致報家人告以墓所在</span>  
<span style="margin-left: 2em">燕即飛往死于墓前時惟正禪師寓普照爲作雙燕</span>  
<span style="margin-left: 2em">碑留寺中<sub class="note-yuan">普照寺續古錄</sub></span>  
<span style="margin-left: 1em">元翰林學士高公智耀嘗奏崇學校正儒者户籍免徭</span>  
<span style="margin-left: 2em">役後學宫皆像而祠之知府張之翰嘗爲之贊<sub class="note-yuan">國朝儒者自戊戌選試後數十年間前輩少而後學多所在不務存恤往往混爲編氓至於奉一札十行之書崇學校奬秀藝正户籍免徭役亦學士高公奏陳之力也聞者孰不起敬至元癸巳之翰由翰林知松江見公遺像於廟學之西南隅時木版零落丹青黯淡殆不可復識乃命工繪而新之俾學者知公之有力於吾儒者若此歲時香火其可闕乎公河西人諱智耀官至翰林學士奉議大夫敭歷中外蓋善政非一姑書大者爲之賛曰公生西夏遭際聖元力扶吾道名動中原致位內相垂裕後昆德日益彰身日益尊畫像雲間在泮之坤香火勿墜埃塵莫昏百千年兮不亡者存</sub></span>  
<span style="margin-left: 1em">張之翰典郡日門揭春帖云雲間太守過三載天下元</span>  
<span style="margin-left: 2em">貞第二年是歲之翰卒泰定改元府治春帖云官清</span>  
<span style="margin-left: 2em">瑩徹三江水民樂和薰兩縣春或云如何不見府明</span>  
<span style="margin-left: 2em">年詔罷府立庸田司之翰又有鏡燈詩云一池鉛水</span>  
<span style="margin-left: 2em">藏真火半夜金星犯太陰膾炙人口時呼爲張鏡燈</span>  
<span style="margin-left: 1em">大德間知府捏只回回人也秩垂滿治第府之永安橋</span>  
<span style="margin-left: 2em">將定居焉鑿地得古石刻云此地二百年後胡人居</span>  
<span style="margin-left: 2em">宋末長興人夏杞養金氏子爲子名世昌攜家華亭</span>  
<span style="margin-left: 2em">爲典押元初一再遷爲華亭尹稅第與世昌居寢梁</span>  
<span style="margin-left: 2em">纏錦破上有金填三大字曰金世昌人生萬事信前</span>  
<span style="margin-left: 2em">定也</span>  
<span style="margin-left: 1em">青村陶應炎治生大穰因欲求一官適闕下計會近臣</span>  
<span style="margin-left: 2em">引見世祖皇帝帝命脱帽相之但曰江南富人也賜</span>  
<span style="margin-left: 2em">馬湩三金鍾而已近臣爲之請帝曰議官之未幾帝</span>  
<span style="margin-left: 2em">崩大德初始授徽之休寧搉茶提舉卜日上官僚吏</span>  
<span style="margin-left: 2em">率音樂款門迎導至則死矣同邑有曹元珍者由鹽</span>  
<span style="margin-left: 2em">司佐史注縣吏時吏禄以賄干縣尹郭也先不花知</span>  
<span style="margin-left: 2em">元珍久不得賦禄遂首拔之元珍喜告祠堂然後出</span>  
<span style="margin-left: 2em">趨事忽中風墜地不能起起而郭去官終其身不得</span>  
<span style="margin-left: 2em">升斗禄右二事絶相類可以爲不知命而妄求者之</span>  
<span style="margin-left: 2em">戒而世祖之知人不可及矣</span>  
<span style="margin-left: 1em">普照寺前刀鑷工見道上一荷葉舒卷不已一人拾置</span>  
<span style="margin-left: 2em">懷中去叩之乃至元鈔三十文夏氏僕嘗見小花蛇</span>  
<span style="margin-left: 2em">盤旋道左行人取而藏諸袖問之乃至元鈔二十文</span>  
<span style="margin-left: 2em">右二事亦相類夫三十文二十文直微末耳尚必待</span>  
<span style="margin-left: 2em">主世之積金蓄穀倍息計贏而無厭者能無鑒乎</span>  
<span style="margin-left: 1em">亭場斥鹵之地海潮漸漬水泉鹹苦至正中兩浙鹽運</span>  
<span style="margin-left: 2em">司知事張允分務青村擇地穿井水特演而甘一時</span>  
<span style="margin-left: 2em">亭民博被其利呼爲張公井云允廉政具見袁浦場</span>  
<span style="margin-left: 2em">石刻進士昂吉所爲文</span>  
<span style="margin-left: 1em">宋末北橋俞彌恭與子端皆鬯仁敷惠凡售物者自百</span>  
<span style="margin-left: 2em">緡而下一聽所邀償之糴者每百斛必再誤唱籌以</span>  
<span style="margin-left: 2em">裨其不足人謂之癡繼有孫名彬頎然而長眉目如</span>  
<span style="margin-left: 2em">畫年近三十未有子嘗嘅然謂所親曰吾志欲得一</span>  
<span style="margin-left: 2em">官而有四子名之以英雄俊傑天其可必乎諛者面</span>  
<span style="margin-left: 2em">承而心實哂之已而果得四子一一美如冠玉唯傑</span>  
<span style="margin-left: 2em">夭折餘子至正間並位星郎而彬亦貴顯如其志云</span>  
<span style="margin-left: 1em">元初烏泥涇大姓趙如珪推誠樂善於先塋建歸厚僧</span>  
<span style="margin-left: 2em">祠於里中創保和道院延釋老薰修以資存没自涇</span>  
<span style="margin-left: 2em">道府城及黃浦之東迤邐鑿井架菴以憩行旅夏月</span>  
<span style="margin-left: 2em">施湯茗其子弘毅又闢齋舍延名儒以教諸子生徒</span>  
<span style="margin-left: 2em">自遠至者皆館穀之未幾子庭芝第進士調丞歸安</span>  
<span style="margin-left: 2em">來學越人郭性存色目人札刺里丁亦相繼登第元</span>  
<span style="margin-left: 2em">世南人登進士自庭芝始鄉邦稱之</span>  
<span style="margin-left: 1em">錢袞自爲諸生預庭祭有感於心其奉先尤謹嘗署祠</span>  
<span style="margin-left: 2em">門曰事之如生祭之如在晨謁朔參出人必告有新</span>  
<span style="margin-left: 2em">物不薦不敢嘗飲食必再祭再祝禮祭則前一日具</span>  
<span style="margin-left: 2em">新筆浄硯雖盛暑必衣冠書祝文又繕錄儀式作指</span>  
<span style="margin-left: 2em">掌圖以便誦習且刻梓而博施焉一日時祭屬予婿</span>  
<span style="margin-left: 2em">陳矩來因俾沐浴帷諸門左矩夢冠紳數老人曰汝</span>  
<span style="margin-left: 2em">在門吾儕來赴宴汝未有兒徐當與也明年果生男</span>  
<span style="margin-left: 2em">袞修志自述其事頗詳</span>  
<span style="margin-left: 1em">黃土橋甲姓周保號中正宋敷文閣學士兼潼川等處</span>  
<span style="margin-left: 2em">安撫制置使尹之後也年三十餘未有子保性虔恭</span>  
<span style="margin-left: 2em">樂施夜夢神人授十八味藥方既寤知即五積散曰</span>  
<span style="margin-left: 2em">是諉予施濟人也遂造酒三十石漬藥以施人雖異</span>  
<span style="margin-left: 2em">疾無弗愈者酒盡因繼以藥俾如方湛酒服或施盡</span>  
<span style="margin-left: 2em">無以繼乃爲約朔望日來如約而至者亡慮千萬人</span>  
<span style="margin-left: 2em">十五年保育五男七女身彌康勁咸以爲誠感獲報</span>  
<span style="margin-left: 2em">云</span>  
<span style="margin-left: 1em">泰定間華亭士人李唐卿嘗夜夢卒奉符示己云送而</span>  
<span style="margin-left: 2em">謝質夫杖脊八十覺以語家人家人以言解之不屑</span>  
<span style="margin-left: 2em">意也質夫里之善醫者既而唐卿疽發背求治於質</span>
