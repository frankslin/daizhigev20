## 正德松江府志卷之三十二　遗事　祥异

<span style="margin-left: 4em">遗事<sub class="note-yuan">祥异附</sub></span>  
<span style="margin-left: 3em">乡邦遗事有无所附属而可以广见闻示惩劝者</span>  
<span style="margin-left: 3em">类于此灾祥变异系境内者附书之备太史之阙</span>  
<span style="margin-left: 3em">遗也</span>  
<span style="margin-left: 1em">陆机初入洛诣侍中王济济指羊酪谓机曰卿吴中何</span>  
<span style="margin-left: 2em">以敌此答曰千里莼羹末下盐豉时人称为名对</span>  
<span style="margin-left: 1em">陆云与荀隐初未相识尝会张华坐华曰今日相遇可</span>  
<span style="margin-left: 2em">勿为常谈云因抗手曰云间陆士龙隐曰日下荀鸣</span>  
<span style="margin-left: 2em">鹤鸣鹤隐字也云又曰既开青云覩白雉何不张尔</span>  
<span style="margin-left: 2em">弓挟尔矢华曰荀何迟隐曰本谓云龙骙骙今乃山</span>  
<span style="margin-left: 2em">鹿野麋兽微弩强是以发迟华抚掌大笑今华亭称</span>  
<span style="margin-left: 2em">云间盖起于此</span>  
<span style="margin-left: 1em">亭林宝云寺初名法云在市西北隅石晋天福五年坏</span>  
<span style="margin-left: 2em">于水开运初始迁于南将成寺僧二人各梦二青衣</span>  
<span style="margin-left: 2em">来云梁朝侍郎至也俄一人紫衣金鱼仪状秀整谓</span>  
<span style="margin-left: 2em">僧曰此地吾之故宅荒废久矣汝今于此建寺可立</span>  
<span style="margin-left: 2em">吾像吾当护此寺也明日各言所梦尚疑未之信是</span>  
<span style="margin-left: 2em">夕又梦云水际古碑可以为据明日果获碑字皆磨</span>  
<span style="margin-left: 2em">灭独一片分明云寺南高基顾野王曾于此修舆地</span>  
<span style="margin-left: 2em">志僧遂于寺之东偏选材作室并二青衣祠焉今为</span>  
<span style="margin-left: 2em">寺之伽蓝神</span>  
<span style="margin-left: 1em">宋杨备郎中天圣中为长溪令忽梦作诗云月俸蚨钱</span>  
<span style="margin-left: 2em">数甚微不知从宦几时归东吴一片轻波在欲问何</span>  
<span style="margin-left: 2em">人买钓矶意甚异之明道初为华亭令丁内艰遂家</span>  
<span style="margin-left: 2em">吴中乐其土风安之因悟梦中语尝效白乐天作我</span>  
<span style="margin-left: 2em">爱姑苏好十章又作姑苏百题诗行于世</span>  
<span style="margin-left: 1em">卫仲达字达可秀州华亭人为馆职时因病梦入冥府</span>  
<span style="margin-left: 2em">立庭下伺命有四人坐其上西向少年者呼曰与他</span>  
<span style="margin-left: 2em">检一检三人难之少年曰若不检如何行遣三人曰</span>  
<span style="margin-left: 2em">渠已是合还何必检恐出手不得耳少年意不可回</span>  
<span style="margin-left: 2em">呼朱衣吏谕意吏捧牙盘而上中置红黑牌二红者</span>  
<span style="margin-left: 2em">以金书善字黑者白书恶字少年指黑吏持以去少</span>  
<span style="margin-left: 2em">焉数人捧簿书出盈庭即有一秤横前两首皆有柈</span>  
<span style="margin-left: 2em">吏举簿置东柈重压至地地为动卫立不能安三人</span>  
<span style="margin-left: 2em">皆失色曰向固云不可检今果尔奈何少年亦惨怛</span>  
<span style="margin-left: 2em">有悔意须臾曰更与检善看指金字牌忽西北隅微</span>  
<span style="margin-left: 2em">明如落照状一朱衣道士捧玉盘出四人皆起立道</span>  
<span style="margin-left: 2em">士至居中而坐望玉盘中文书仅如箸大吏持下寘</span>  
<span style="margin-left: 2em">西柈柈亦压地而东柈高举向空大风歘起卷其纸</span>  
<span style="margin-left: 2em">蔽天如乌鸢乱飞无一存焉四人起相贺命席延卫</span>  
<span style="margin-left: 2em">坐卫拱手曰仲达年未四十平生不敢为过恶何由</span>  
<span style="margin-left: 2em">簿书充塞如此少年曰心善者恶轻心恶者恶重举</span>  
<span style="margin-left: 2em">念不正此即书之何必真犯然已灰灭无余矣卫谢</span>  
<span style="margin-left: 2em">曰是则然矣敢问善状何事也少年曰朝廷兴工修</span>  
<span style="margin-left: 2em">三山石桥君曾上书谏此乃奏藁也卫曰虽曾上厦</span>  
<span style="margin-left: 2em">朝廷不从何益于事曰事之在君者尽矣君言得用</span>  
<span style="margin-left: 2em">岂止活数万人命君当位极人臣奈恶簿颇多犹不</span>  
<span style="margin-left: 2em">失八座勉之遂遣人导归卫后至吏部尚书</span>  
<span style="margin-left: 1em">华亭尉厅旧有阁李纲父公夔元丰初为尉纲生于阁</span>  
<span style="margin-left: 2em">下后为南渡名相因呼为相公阁</span>  
<span style="margin-left: 1em">吴潜父为下沙盐场官潜侍父读书于此既而魁多士</span>  
<span style="margin-left: 2em">为开庆名相后人即其地立义塾云</span>  
<span style="margin-left: 1em">郑闻游学华亭与钱良臣同舍绍兴间魁南省后与钱</span>  
<span style="margin-left: 2em">并参大政尝题名于学之达材斋后人以碧纱笼之</span>  
<span style="margin-left: 2em">为一时盛事</span>  
<span style="margin-left: 1em">刘璧知华亭日有鹳集堂前悲鸣类有所诉者刘顾而</span>  
<span style="margin-left: 2em">言曰岂非为人毁汝巢或取汝子乎鹳俯首而听立</span>  
<span style="margin-left: 2em">遣左右物色之鹳随以往至普照寺鸱吻声愈切乃</span>  
<span style="margin-left: 2em">恶少年挟弹毙其雏而鹳悲噪不已寺僮厌其喧聒</span>  
<span style="margin-left: 2em">遂并巢毁之左右还鹳亦随至刘曰我知之矣便当</span>  
<span style="margin-left: 2em">为汝追治亦不动少顷捕少年及僮到庭下各杖之</span>  
<span style="margin-left: 2em">然后振翼飞鸣而去<sub class="note-yuan">出夷坚志</sub></span>  
<span style="margin-left: 1em">普照寺有北方天王祠宋时雷震祠柱倒书曰高洞杨</span>  
<span style="margin-left: 2em">雅一十六人火令章凡十一字内令章两字特奇劲</span>  
<span style="margin-left: 2em">似唐人书<sub class="note-yuan">出笔谈</sub></span>  
<span style="margin-left: 1em">盛肇居青龙胜果寺好食牛肉与陈氏子友善陈遣仆</span>  
<span style="margin-left: 2em">约旦日会食视其简乃匀碧牋一幅内大书曰万物</span>  
<span style="margin-left: 2em">皆心化唯牛最苦辛君看横死者尽是食牛人肇惊</span>  
<span style="margin-left: 2em">顾呼其仆已不见旦而询诸陈氏亦未尝遣也肇自</span>  
<span style="margin-left: 2em">此不食牛<sub class="note-yuan">出夷坚志</sub></span>  
<span style="margin-left: 1em">章生青龙人著羽衣服能作墨有古法其家制墨聚烟</span>  
<span style="margin-left: 2em">列盌三十余中夕扫煤无一存者明日乃在主翁闺</span>  
<span style="margin-left: 2em">中煤皆成花其三为寿星长松覆之玉女在傍玄鹤</span>  
<span style="margin-left: 2em">灵芝宛如善绘者所作二为牡丹五为禽鱼余为荔</span>  
<span style="margin-left: 2em">枝胡桃枣杏梨栗咸具焉其家以为瑞呼道士醮而</span>  
<span style="margin-left: 2em">陈之以答灵贶云<sub class="note-yuan">出鬼董</sub></span>  
<span style="margin-left: 1em">胥浦乡周氏有女名喜姑尝救活二雏燕于蛇螫明年</span>  
<span style="margin-left: 2em">女卒春燕来周章哀鸣如欲致报家人告以墓所在</span>  
<span style="margin-left: 2em">燕即飞往死于墓前时惟正禅师寓普照为作双燕</span>  
<span style="margin-left: 2em">碑留寺中<sub class="note-yuan">普照寺续古录</sub></span>  
<span style="margin-left: 1em">元翰林学士高公智耀尝奏崇学校正儒者户籍免徭</span>  
<span style="margin-left: 2em">役后学宫皆像而祠之知府张之翰尝为之赞<sub class="note-yuan">国朝儒者自戊戌选试后数十年间前辈少而后学多所在不务存恤往往混为编氓至于奉一札十行之书崇学校奖秀艺正户籍免徭役亦学士高公奏陈之力也闻者孰不起敬至元癸巳之翰由翰林知松江见公遗像于庙学之西南隅时木版零落丹青黯淡殆不可复识乃命工绘而新之俾学者知公之有力于吾儒者若此岁时香火其可阙乎公河西人讳智耀官至翰林学士奉议大夫敭历中外盖善政非一姑书大者为之賛曰公生西夏遭际圣元力扶吾道名动中原致位内相垂裕后昆德日益彰身日益尊画像云间在泮之坤香火勿坠埃尘莫昏百千年兮不亡者存</sub></span>  
<span style="margin-left: 1em">张之翰典郡日门揭春帖云云间太守过三载天下元</span>  
<span style="margin-left: 2em">贞第二年是岁之翰卒泰定改元府治春帖云官清</span>  
<span style="margin-left: 2em">莹彻三江水民乐和薰两县春或云如何不见府明</span>  
<span style="margin-left: 2em">年诏罢府立庸田司之翰又有镜灯诗云一池铅水</span>  
<span style="margin-left: 2em">藏真火半夜金星犯太阴脍炙人口时呼为张镜灯</span>  
<span style="margin-left: 1em">大德间知府捏只回回人也秩垂满治第府之永安桥</span>  
<span style="margin-left: 2em">将定居焉凿地得古石刻云此地二百年后胡人居</span>  
<span style="margin-left: 2em">宋末长兴人夏杞养金氏子为子名世昌携家华亭</span>  
<span style="margin-left: 2em">为典押元初一再迁为华亭尹税第与世昌居寝梁</span>  
<span style="margin-left: 2em">缠锦破上有金填三大字曰金世昌人生万事信前</span>  
<span style="margin-left: 2em">定也</span>  
<span style="margin-left: 1em">青村陶应炎治生大穰因欲求一官适阙下计会近臣</span>  
<span style="margin-left: 2em">引见世祖皇帝帝命脱帽相之但曰江南富人也赐</span>  
<span style="margin-left: 2em">马湩三金钟而已近臣为之请帝曰议官之未几帝</span>  
<span style="margin-left: 2em">崩大德初始授徽之休宁搉茶提举卜日上官僚吏</span>  
<span style="margin-left: 2em">率音乐款门迎导至则死矣同邑有曹元珍者由盐</span>  
<span style="margin-left: 2em">司佐史注县吏时吏禄以贿干县尹郭也先不花知</span>  
<span style="margin-left: 2em">元珍久不得赋禄遂首拔之元珍喜告祠堂然后出</span>  
<span style="margin-left: 2em">趋事忽中风坠地不能起起而郭去官终其身不得</span>  
<span style="margin-left: 2em">升斗禄右二事绝相类可以为不知命而妄求者之</span>  
<span style="margin-left: 2em">戒而世祖之知人不可及矣</span>  
<span style="margin-left: 1em">普照寺前刀镊工见道上一荷叶舒卷不已一人拾置</span>  
<span style="margin-left: 2em">怀中去叩之乃至元钞三十文夏氏仆尝见小花蛇</span>  
<span style="margin-left: 2em">盘旋道左行人取而藏诸袖问之乃至元钞二十文</span>  
<span style="margin-left: 2em">右二事亦相类夫三十文二十文直微末耳尚必待</span>  
<span style="margin-left: 2em">主世之积金蓄谷倍息计赢而无厌者能无鉴乎</span>  
<span style="margin-left: 1em">亭场斥卤之地海潮渐渍水泉咸苦至正中两浙盐运</span>  
<span style="margin-left: 2em">司知事张允分务青村择地穿井水特演而甘一时</span>  
<span style="margin-left: 2em">亭民博被其利呼为张公井云允廉政具见袁浦场</span>  
<span style="margin-left: 2em">石刻进士昂吉所为文</span>  
<span style="margin-left: 1em">宋末北桥俞弥恭与子端皆鬯仁敷惠凡售物者自百</span>  
<span style="margin-left: 2em">缗而下一听所邀偿之籴者每百斛必再误唱筹以</span>  
<span style="margin-left: 2em">裨其不足人谓之痴继有孙名彬颀然而长眉目如</span>  
<span style="margin-left: 2em">画年近三十未有子尝嘅然谓所亲曰吾志欲得一</span>  
<span style="margin-left: 2em">官而有四子名之以英雄俊杰天其可必乎谀者面</span>  
<span style="margin-left: 2em">承而心实哂之已而果得四子一一美如冠玉唯杰</span>  
<span style="margin-left: 2em">夭折余子至正间并位星郎而彬亦贵显如其志云</span>  
<span style="margin-left: 1em">元初乌泥泾大姓赵如珪推诚乐善于先茔建归厚僧</span>  
<span style="margin-left: 2em">祠于里中创保和道院延释老薰修以资存没自泾</span>  
<span style="margin-left: 2em">道府城及黄浦之东迤逦凿井架庵以憩行旅夏月</span>  
<span style="margin-left: 2em">施汤茗其子弘毅又辟斋舍延名儒以教诸子生徒</span>  
<span style="margin-left: 2em">自远至者皆馆谷之未几子庭芝第进士调丞归安</span>  
<span style="margin-left: 2em">来学越人郭性存色目人札刺里丁亦相继登第元</span>  
<span style="margin-left: 2em">世南人登进士自庭芝始乡邦称之</span>  
<span style="margin-left: 1em">钱衮自为诸生预庭祭有感于心其奉先尤谨尝署祠</span>  
<span style="margin-left: 2em">门曰事之如生祭之如在晨谒朔参出人必告有新</span>  
<span style="margin-left: 2em">物不荐不敢尝饮食必再祭再祝礼祭则前一日具</span>  
<span style="margin-left: 2em">新笔浄砚虽盛暑必衣冠书祝文又缮录仪式作指</span>  
<span style="margin-left: 2em">掌图以便诵习且刻梓而博施焉一日时祭属予婿</span>  
<span style="margin-left: 2em">陈矩来因俾沐浴帷诸门左矩梦冠绅数老人曰汝</span>  
<span style="margin-left: 2em">在门吾侪来赴宴汝未有儿徐当与也明年果生男</span>  
<span style="margin-left: 2em">衮修志自述其事颇详</span>  
<span style="margin-left: 1em">黄土桥甲姓周保号中正宋敷文阁学士兼潼川等处</span>  
<span style="margin-left: 2em">安抚制置使尹之后也年三十余未有子保性虔恭</span>  
<span style="margin-left: 2em">乐施夜梦神人授十八味药方既寤知即五积散曰</span>  
<span style="margin-left: 2em">是诿予施济人也遂造酒三十石渍药以施人虽异</span>  
<span style="margin-left: 2em">疾无弗愈者酒尽因继以药俾如方湛酒服或施尽</span>  
<span style="margin-left: 2em">无以继乃为约朔望日来如约而至者亡虑千万人</span>  
<span style="margin-left: 2em">十五年保育五男七女身弥康劲咸以为诚感获报</span>  
<span style="margin-left: 2em">云</span>  
<span style="margin-left: 1em">泰定间华亭士人李唐卿尝夜梦卒奉符示己云送而</span>  
<span style="margin-left: 2em">谢质夫杖脊八十觉以语家人家人以言解之不屑</span>  
<span style="margin-left: 2em">意也质夫里之善医者既而唐卿疽发背求治于质</span>  
<span style="margin-left: 2em">夫质夫用匕刺其疽家默策匕数竟符梦杖焉此与</span>  
<span style="margin-left: 2em">括异志之明参政江湖纪闻之王夜叉事正相类皆</span>  
<span style="margin-left: 2em">阴谴也</span>  
<span style="margin-left: 1em">白沙乡有大姓尝私营巨斛受租佃人轧其声威无敢</span>  
<span style="margin-left: 2em">控愬皆饮恨输之重纪至元间白日天地忽暗俄而</span>
