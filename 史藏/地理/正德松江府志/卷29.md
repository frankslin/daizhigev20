## 正德松江府志卷之二十九　人物三（名臣）

<span style="margin-left: 4em">人物三<sub class="note-yuan">名臣</sub></span>  
<span style="margin-left: 1em">国朝全思诚字希贤上海人博学能诗文洪武初以老</span>  
<span style="margin-left: 2em">儒召为文华殿大学士兼左中允赐勑致仕有怀材</span>  
<span style="margin-left: 2em">抱德肩志古人之褒</span>  
<span style="margin-left: 1em">王公亮华亭人世业儒蚤失怙恃大父安之讲授于乡</span>  
<span style="margin-left: 2em">公亮克承厥训以能书举任吏科给事中升应天府</span>  
<span style="margin-left: 2em">丞永乐初擢四川右布政使调广东公亮仪度闲雅</span>  
<span style="margin-left: 2em">居官简静务大体廉重恺悌人皆悦服卒于官孙臣</span>  
<span style="margin-left: 2em">鸿胪序班直内阁升通政司经历卒</span>  
<span style="margin-left: 1em">任勉之字近思其先四明人元松乡先生士林子耜为</span>  
<span style="margin-left: 2em">两浙盐运照磨始占籍华亭勉之登洪武甲戌进士</span>  
<span style="margin-left: 2em">出知饶州府鄱阳县以正民俗为首务令有不便者</span>  
<span style="margin-left: 2em">或为匿名书诋之下令俾勿坏曰告我以过是忠于</span>  
<span style="margin-left: 2em">我也寡妇愬夫兄弗育己公曰汝他适乎乃判其衫</span>  
<span style="margin-left: 2em">背曰饿死事极小失节事极大妇感其言卒不嫁由</span>  
<span style="margin-left: 2em">是邑中风动称为贤令鄱故大邑前官丛脞事剧甚</span>  
<span style="margin-left: 2em">勉之立簿书俾民自为约次第举行不劳而集秩满</span>  
<span style="margin-left: 2em">升知泸州民诣</span>  
<span style="margin-left: 2em">阙借留升其府同知荐为福建右参政左迁右军都</span>  
<span style="margin-left: 2em">督府经历出知徽州府以事谪沧州泰然自处不废</span>  
<span style="margin-left: 2em">著述寻起知蔚州改睢州致仕卒年八十九勉之豪</span>  
<span style="margin-left: 2em">迈英伟长身玉立音如洪钟虽造次语言皆可录或</span>  
<span style="margin-left: 2em">问郡守某何如人曰有治民之才无养民之心时以</span>  
<span style="margin-left: 2em">为确论为文辞雄健赡蔚似杨铁崖书学米南宫而</span>  
<span style="margin-left: 2em">不以自名既老四方求文者无虚日永乐正统之间</span>  
<span style="margin-left: 2em">论文章政事必以勉之为称首云所著有薇庵集若</span>  
<span style="margin-left: 2em">干卷一子肃蚤夭以弟子弘为后孙顺世其学以国</span>  
<span style="margin-left: 2em">子助教升泾府右长史</span>  
<span style="margin-left: 1em">陈祯字景祺华亭南桥人宋康肃公十四世孙也读书</span>  
<span style="margin-left: 2em">好礼喜怒不形于色洪武中以税户子弟举为礼部</span>  
<span style="margin-left: 2em">主事有能声尝大廷议事众不能决祯徐进剖析数</span>  
<span style="margin-left: 2em">言而定</span>  
<span style="margin-left: 1em">上嘉奖而器之俾摄部事谕之曰卿见事敏四司之事</span>  
<span style="margin-left: 2em">宜悉知之祯益谨饬不敢怠坐齐麟事谪戍金齿未</span>  
<span style="margin-left: 2em">几　召还授五军断事官稽仁丁家艰起复上疏乞</span>  
<span style="margin-left: 2em">终制服阕升主客员外郎出知湖广襄阳府时荆土</span>  
<span style="margin-left: 2em">蝗独不入祯境永乐初　召为鸿胪少卿治水东吴</span>  
<span style="margin-left: 2em">升河南右参政黄河决劳来有方民不失业盗发汝</span>  
<span style="margin-left: 2em">宁将窥汴赖以计离其党与困其首张子诚等千人</span>  
<span style="margin-left: 2em">于均山降之兵不血刃而定</span>  
<span style="margin-left: 1em">上嘉之赐勑奖劳秩满乞祭扫陛辞谪知交趾丘温县</span>  
<span style="margin-left: 2em">时方暑南中瘴疠或劝使缓行曰死生命也何瘴疠</span>  
<span style="margin-left: 2em">为至县一月卒年五十</span>  
<span style="margin-left: 1em">上闻而惜之后八年其友胡士文请于掌交趾藩臬事</span>  
<span style="margin-left: 2em">尚书黄公福始获以其丧归祯平居尝曰人惟仰不</span>  
<span style="margin-left: 2em">愧俯不怍而已身之利否何计其行事类此故历官</span>  
<span style="margin-left: 2em">所至并著声绩云四子谟询诰谏</span>  
<span style="margin-left: 1em">询字汝同早失怙事母以孝闻登永乐戊戌进士累官</span>  
<span style="margin-left: 2em">翰林侍读学士出知安陆州景泰初　召复故官升</span>  
<span style="margin-left: 2em">大理少卿巡抚北直隶改太常少卿兼学士终国子</span>  
<span style="margin-left: 2em">祭酒致仕卒年六十六询性峭直寡言笑平居俨然</span>  
<span style="margin-left: 2em">饮酒能多而不乱在官处僚友和而不同人不敢干</span>  
<span style="margin-left: 2em">以私秉道嫉邪盖出天授正统中中宫王振怙宠公</span>  
<span style="margin-left: 2em">卿皆下之刘忠愍李文毅忤之皆得奇祸询绝不与</span>  
<span style="margin-left: 2em">通振衔之故有安陆之谪方是时询直声动天下人</span>  
<span style="margin-left: 2em">皆为危之而询怡然不以为意也编修梁𬤇病语家</span>  
<span style="margin-left: 2em">人曰朋游中惟陈同年汝同心地好且有家法孤子</span>  
<span style="margin-left: 2em">女可托也询闻而诺焉及𬤇卒为经纪其家事无不</span>  
<span style="margin-left: 2em">曲尽至冒谤毁而为之不鹰嫁其女得松人黄瑜后</span>  
<span style="margin-left: 2em">参福建政竟以梁之丧归其乡其笃于友谊如此为</span>  
<span style="margin-left: 2em">文章清劲有气骨类其为人主考两畿判国子奖拔</span>  
<span style="margin-left: 2em">士类甚众若严铨丘濬杨继宗彭韶施槃辈后皆为</span>  
<span style="margin-left: 2em">名臣</span>  
<span style="margin-left: 1em">王钟字公簴华亭人为人寡欲虽富贵不改穷约时平</span>  
<span style="margin-left: 2em">居端厚简默遇事剖决沛然无滞敷奏亦然永乐初</span>  
<span style="margin-left: 2em">侍东宫居守北京甚见亲重累官至户部右侍郎洪</span>  
<span style="margin-left: 2em">熙元年</span>  
<span style="margin-left: 1em">上思旧劳赠　太子太保谥僖敏</span>  
<span style="margin-left: 1em">沈度字民则华亭人竹庭晖之孙苦节先生易之子也</span>  
<span style="margin-left: 2em">易性至孝以易学授徒于家尝辑五伦诗著孝经旁</span>  
<span style="margin-left: 2em">训行于世度少力学善篆隶真行书以荐授翰林典</span>  
<span style="margin-left: 2em">籍累官至学士卒弟粲字民望善真草书飘逸遒劲</span>  
<span style="margin-left: 2em">自成一家尤长于诗有集二千余首累官翰林侍读</span>  
<span style="margin-left: 2em">春坊庶子至大理少卿致仕永乐以来兄弟并在禁</span>  
<span style="margin-left: 2em">林最承恩遇而伯仲同居友弟无间缙绅以为莫及</span>  
<span style="margin-left: 2em">粲尤端厚谦抑好奖予后进至今馆阁犹称为二沈</span>  
<span style="margin-left: 2em">云度子藻亦善书以荫为中书舍人至礼部员外致</span>  
<span style="margin-left: 2em">仕</span>  
<span style="margin-left: 1em">孝宗尤好度书访其后得四世孙世隆即授中书舍人</span>  
<span style="margin-left: 2em">直内阁正德初预修国史以微眚去官卒</span>  
<span style="margin-left: 1em">何广字公远华亭人后迁上海以知县擢御史至陕西</span>  
<span style="margin-left: 2em">按察副使宽厚有容博学多识尤精于律学时变乱</span>  
<span style="margin-left: 2em">成法者当大辟法家因仍凡一政令改易辄以傅议</span>  
<span style="margin-left: 2em">广曰嘻若是则大辟者踵相接矣此但为改定律令</span>  
<span style="margin-left: 2em">者言之盖禁于所不犯也大学士解缙绅览而是之</span>  
<span style="margin-left: 2em">及卒长沙通判俞永状其行曰居乡里则称学者任</span>  
<span style="margin-left: 2em">郡邑则为循吏在风宪有澄清志位藩垣得大臣体</span>  
<span style="margin-left: 2em">时以为实录所著有律解辩疑行于世</span>  
<span style="margin-left: 1em">石璞华亭人永乐中举人任陕西按察使剖决如流吏</span>  
<span style="margin-left: 2em">民畏服得宪臣体</span>  
<span style="margin-left: 1em">夏礼字公立上海唐行人洪武中贡入太学拜监察御</span>  
<span style="margin-left: 2em">史有直声</span>  
<span style="margin-left: 1em">高皇帝为开其军伍尝上疏劾勲贵忤旨出为知县</span>  
<span style="margin-left: 2em">奏减各处均输商税从之永乐初以荐为御史升河</span>  
<span style="margin-left: 2em">南按察副史谪戍武清</span>  
<span style="margin-left: 1em">文皇北巡再　召为御史使至南京值闸坝水溢漂居</span>  
<span style="margin-left: 2em">民亟令有司疏泄</span>  
<span style="margin-left: 1em">上闻而是之复以荐为陕西按察副使积岁疑狱一言</span>  
<span style="margin-left: 2em">而决以内艰去陕西数千人诣</span>  
<span style="margin-left: 2em">阙借留夺情还任卒于官</span>  
<span style="margin-left: 1em">卫青华亭人世力农父炳当元季应募隶水军万户府</span>  
<span style="margin-left: 1em">太祖受命杖劒来归从征讨四方未尝辱人子女掠人</span>  
<span style="margin-left: 2em">财物与妄杀一人有功辄以让同列竟终于行伍青</span>  
<span style="margin-left: 2em">状貌雄伟倜傥有气概勇而善谋洪武末以总旗授</span>  
<span style="margin-left: 2em">蓟州卫百户累升山东都指挥佥事备倭海上永乐</span>  
<span style="margin-left: 2em">中蒲台妖妇唐赛儿自称佛母诱愚民为乱攻安丘</span>  
<span style="margin-left: 2em">甚急青闻率千骑昼夜兼行至城下奋击破之杀二</span>  
<span style="margin-left: 2em">千余人生擒四千人皆斩之而收其孥时城中已不</span>  
<span style="margin-left: 2em">支众谓青至稍缓城必陷已而安远侯柳升至怒其</span>  
<span style="margin-left: 2em">不待己捽辱之青不为屈事闻</span>  
<span style="margin-left: 1em">上切责升降　敕褒美曰卫青进不求名退不避罪惟</span>  
<span style="margin-left: 2em">民是保虽古之名将何以加焉升都指挥使正统初</span>  
<span style="margin-left: 2em">进右军都督佥事仍备倭六月以旱蝗出祷得疾</span>  
<span style="margin-left: 1em">上闻遣医疗之未至二日卒葬济南历城之鹊华乡青</span>  
<span style="margin-left: 2em">幼时尝牧羊马憗寺前有道士见而奇之抚其顶曰</span>  
<span style="margin-left: 2em">儿他日腰金衣紫闻者皆笑之至是果然及卒登莱</span>  
<span style="margin-left: 2em">人为立庙海上事之甚严或见其红袍白马出人庙</span>  
<span style="margin-left: 2em">中云有子十一人长颐袭济南卫指挥使早卒无子</span>  
<span style="margin-left: 2em">次颍嗣余分处济南登莱留华亭者行第九曰显云</span>  
<span style="margin-left: 1em">颍字源正丰颐广颡语音如钟代兄颐为指挥使选督</span>  
<span style="margin-left: 2em">山东漕运领京营操以勇干闻正统己巳之变从山</span>  
<span style="margin-left: 2em">东入勤王建议募勇敢士收合散亡调各都司兵实</span>  
<span style="margin-left: 2em">京城修沿边关隘为战守计当抢攘中意气慷慨筹</span>  
<span style="margin-left: 2em">策整暇人倚以安由署都指挥佥事升同知进都督</span>  
<span style="margin-left: 2em">佥事十月也先入寇颍率兵邀击于黄花镇连战西</span>  
<span style="margin-left: 2em">直门诸处又尾击之于紫荆关以功多升都督同知</span>  
<span style="margin-left: 2em">充总兵官出守宣府还督京营兵</span>  
<span style="margin-left: 1em">英宗复辟升左都督十一月录功封奉天翊卫宣力武</span>  
<span style="margin-left: 2em">臣柱国宣城伯食禄一千一百石　赐铁券子孙世</span>  
<span style="margin-left: 2em">袭寻充总兵官挂平羌将军印守甘肃时羌虏谋入</span>  
<span style="margin-left: 2em">寇众议持重待之颍奋然勒兵而出连十二战大破</span>  
<span style="margin-left: 2em">之虏震骇远遁边人歌之辛巳六月败西番于凉州</span>  
<span style="margin-left: 2em">都督毛忠被围贼势盛监军以下皆震恐颍曰安有</span>  
<span style="margin-left: 2em">贼困我师而不救者遂躬冒矢石战而前贼披靡不</span>  
<span style="margin-left: 2em">敢近卒全师归甲申番族把沙作乱颍率兵深入败</span>  
<span style="margin-left: 2em">之斩获无筭</span>  
<span style="margin-left: 1em">宪宗即位召公还丙戌录功加禄米一百石丁亥挂征</span>  
<span style="margin-left: 2em">虏前将军印镇辽东女直毛邻犯边颍据险设伏连</span>  
<span style="margin-left: 2em">败之获马牛畜产并掠去子女甚众以疾乞归</span>  
<span style="margin-left: 2em">命守备凤阳改南京连上疏请老　诏还之北京俾</span>  
<span style="margin-left: 2em">食其全禄以伯归第颍天性明达遇事有谋而能断</span>  
<span style="margin-left: 2em">尤笃於伦理甫冠都督公卒哭泣几丧明抚其孤弟</span>  
<span style="margin-left: 2em">姪及群从子弟皆有恩意以家在松江而都督公葬</span>  
<span style="margin-left: 2em">历城每遇二邦人如见亲戚存问故旧叙述平生极</span>  
<span style="margin-left: 2em">其欵曲曰吾老矣水木本源之意吾后人安知既谢</span>  
<span style="margin-left: 2em">事角巾私第故时部曲率为显官岁时候问皆拜于</span>  
<span style="margin-left: 2em">床下颍以子弟抚之忠勇之性老而弥笃每三边有</span>  
<span style="margin-left: 2em">警辄扼腕叹息有驰志伊吾之意当一日边报急</span>  
<span style="margin-left: 2em">廷议出师而将臣有称疾卧家者颍喟然谓坐客曰</span>  
<span style="margin-left: 1em">上宽恩至矣客问即真病柰何曰病不至于死行而死</span>  
<span style="margin-left: 2em">于涂可也闻者壮之弘治戊午正月二十八日卒年</span>  
<span style="margin-left: 2em">八十八追封宣城侯谥曰壮勇</span>  
<span style="margin-left: 1em">叶宗行字宗行华亭人宋太学生李之后读书尚气节</span>  
<span style="margin-left: 2em">永乐中东吴大水松江尤甚盖黄浦下流壅塞水无</span>  
<span style="margin-left: 2em">所归宗行上书请弃其故道濬范家浜引浦水以归</span>  
<span style="margin-left: 2em">于海禁近海民无私作坝以遏其流</span>  
<span style="margin-left: 1em">上善其言命从夏尚书原吉来治之水患果息原吉还</span>  
<span style="margin-left: 3em">朝荐其才擢知钱塘县钱塘剧邑民困于徭赋宗</span>  
<span style="margin-left: 2em">行为定役法俾民自占甲乙书于册循次而呼之役</span>
