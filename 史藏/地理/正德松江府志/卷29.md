## 松江府志卷之二十九

<span style="margin-left: 3em">人物三<sub class="note-yuan">名臣</sub></span>  
國朝全思誠字希賢上海人博學能詩文洪武初以老儒召爲文華殿大學士兼左中允賜勑致仕有懷材抱德肩志古人之褒  
王公亮華亭人世業儒蚤失怙恃大父安之講授于鄉公亮克承厥訓以能書舉任吏科給事中陞應天府丞永樂初擢四川右布政使調廣東公亮儀度閒雅居官簡靜務大體廉重愷悌人皆悦服卒于官孫臣鴻臚序班直內閣陞通政司經歷卒  
任勉之字近思其先四明人元松鄉先生士林子耜爲兩浙鹽運照磨始占籍華亭勉之登洪武甲戌進士出知饒州府鄱陽縣以正民俗爲首務令有不便者或爲匿名書詆之下令俾勿壞曰告我以過是忠於我也寡婦愬夫兄弗育己公曰汝他適乎乃判其衫背曰餓死事極小失節事極大婦感其言卒不嫁由是邑中風動稱爲賢令鄱故大邑前官叢脞事劇甚勉之立簿書俾民自爲約次第舉行不勞而集秩滿陞知瀘州民詣  
<span style="margin-left: 1em">闕借留陞其府同知薦爲福建右參政左遷右軍都督府經歷出知徽州府以事謫滄州泰然自處不廢著述尋起知蔚州改睢州致仕卒年八十九勉之豪邁英偉長身玉立音如洪鐘雖造次語言皆可錄或問郡守某何如人曰有治民之才無養民之心時以爲確論爲文辭雄健贍蔚似楊鐵崖書學米南宫而不以自名既老四方求文者無虛日永樂正統之間論文章政事必以勉之爲稱首云所著有薇菴集若干卷一子肅蚤夭以弟子弘爲後孫順世其學以國子助教陞涇府右長史</span>  
陳禎字景祺華亭南橋人宋康肅公十四世孫也讀書好禮喜怒不形于色洪武中以稅户子弟舉爲禮部主事有能聲嘗大廷議事衆不能決禎徐進剖析數言而定  
上嘉奬而器之俾攝部事諭之曰卿見事敏四司之事宜悉知之禎益謹飭不敢怠坐齊麟事謫戍金齒未幾　召還授五軍斷事官稽仁丁家艱起復上疏乞終制服闋陞主客員外郎出知湖廣襄陽府時荆土蝗獨不入禎境永樂初　召爲鴻臚少卿治水東吳陞河南右參政黃河決勞來有方民不失業盜發汝寧將窺汴賴以計離其黨與困其首張子誠等千人于均山降之兵不血刃而定  
上嘉之賜勑奬勞秩滿乞祭掃陛辭謫知交趾丘温縣時方暑南中瘴癘或勸使緩行曰死生命也何瘴癘爲至縣一月卒年五十  
上聞而惜之後八年其友胡士文請於掌交趾藩臬事尚書黃公福始獲以其喪歸禎平居嘗曰人惟仰不愧俯不怍而已身之利否何計其行事類此故歷官所至並著聲績云四子謨詢誥諫  
詢字汝同早失怙事母以孝聞登永樂戊戌進士累官翰林侍讀學士出知安陸州景泰初　召復故官陞大理少卿巡撫北直隸改太常少卿兼學士終國子祭酒致仕卒年六十六詢性峭直寡言笑平居儼然飲酒能多而不亂在官處僚友和而不同人不敢干以私秉道嫉邪蓋出天授正統中中宫王振怙寵公卿皆下之劉忠愍李文毅忤之皆得奇禍詢絶不與通振銜之故有安陸之謫方是時詢直聲動天下人皆爲危之而詢怡然不以爲意也編修梁諲病語家人曰朋游中惟陳同年汝同心地好且有家法孤子女可託也詢聞而諾焉及諲卒爲經紀其家事無不曲盡至冒謗毁而爲之不鷹嫁其女得松人黃瑜後參福建政竟以梁之喪歸其鄉其篤于友誼如此爲文章清勁有氣骨類其爲人主考兩畿判國子奬拔士類甚衆若嚴銓丘濬楊繼宗彭韶施槃輩後皆爲名臣  
王鍾字公簴華亭人爲人寡慾雖富貴不改窮約時平居端厚簡默遇事剖決沛然無滯敷奏亦然永樂初侍東宫居守北京甚見親重累官至户部右侍郎洪熙元年  
上思舊勞贈　太子太保謚僖敏  
沈度字民則華亭人竹庭暉之孫苦節先生易之子也易性至孝以易學授徒于家嘗輯五倫詩著孝經旁訓行于世度少力學善篆隸真行書以薦授翰林典籍累官至學士卒弟粲字民望善真草書飄逸遒勁自成一家尤長於詩有集二千餘首累官翰林侍讀春坊庶子至大理少卿致仕永樂以來兄弟並在禁林最承恩遇而伯仲同居友弟無間縉紳以爲莫及粲尤端厚謙抑好奬予後進至今館閣猶稱爲二沈云度子藻亦善書以蔭爲中書舍人至禮部員外致仕  
孝宗尤好度書訪其後得四世孫世隆即授中書舍人直內閣正德初預修國史以微眚去官卒  
何廣字公遠華亭人後遷上海以知縣擢御史至陝西按察副使寬厚有容博學多識尤精於律學時變亂成法者當大辟法家因仍凡一政令改易輒以傅議廣曰嘻若是則大辟者踵相接矣此但爲改定律令者言之蓋禁於所不犯也大學士解縉紳覽而是之及卒長沙通判俞永狀其行曰居鄉里則稱學者任郡邑則爲循吏在風憲有澄清志位藩垣得大臣體時以爲實錄所著有律解辯疑行于世  
石璞華亭人永樂中舉人任陝西按察使剖決如流吏民畏服得憲臣體  
夏禮字公立上海唐行人洪武中貢入太學拜監察御史有直聲  
高皇帝爲開其軍伍嘗上疏劾勲貴忤旨出爲知縣  
<span style="margin-left: 1em">奏減各處均輸商稅從之永樂初以薦爲御史陞河南按察副史謫戍武清</span>  
文皇北巡再　召爲御史使至南京值閘壩水溢漂居民亟令有司疏泄  
上聞而是之復以薦爲陝西按察副使積歲疑獄一言而決以內艱去陝西數千人詣  
<span style="margin-left: 1em">闕借留奪情還任卒于官</span>  
衛青華亭人世力農父炳當元季應募隸水軍萬户府  
太祖受命杖劒來歸從征討四方未嘗辱人子女掠人財物與妄殺一人有功輒以讓同列竟終于行伍青狀貌雄偉倜儻有氣概勇而善謀洪武末以總旗授薊州衛百户累陞山東都指揮僉事備倭海上永樂中蒲臺妖婦唐賽兒自稱佛母誘愚民爲亂攻安丘甚急青聞率千騎晝夜兼行至城下奮擊破之殺二千餘人生擒四千人皆斬之而收其孥時城中已不支衆謂青至稍緩城必陷已而安遠侯柳升至怒其不待己捽辱之青不爲屈事聞  
上切責升降　敕褒美曰衛青進不求名退不避罪惟民是保雖古之名將何以加焉陞都指揮使正統初進右軍都督僉事仍備倭六月以旱蝗出禱得疾  
上聞遣醫療之未至二日卒葬濟南歷城之鵲華鄉青幼時嘗牧羊馬憗寺前有道士見而奇之撫其頂曰兒他日腰金衣紫聞者皆笑之至是果然及卒登萊人爲立廟海上事之甚嚴或見其紅袍白馬出人廟中云有子十一人長頤襲濟南衛指揮使早卒無子次潁嗣餘分處濟南登萊留華亭者行第九曰顯云  
潁字源正豐頤廣顙語音如鐘代兄頤爲指揮使選督山東漕運領京營操以勇幹聞正統己巳之變從山東入勤王建議募勇敢士收合散亡調各都司兵實京城修沿邊關隘爲戰守計當搶攘中意氣慷慨籌策整暇人倚以安由署都指揮僉事陞同知進都督僉事十月也先入寇潁率兵邀擊於黃花鎮連戰西直門諸處又尾擊之於紫荆關以功多陞都督同知充總兵官出守宣府還督京營兵  
英宗復辟陞左都督十一月錄功封奉天翊衛宣力武臣柱國宣城伯食禄一千一百石　賜鐵券子孫世襲尋充總兵官挂平羌將軍印守甘肅時羌虜謀入寇衆議持重待之潁奮然勒兵而出連十二戰大破之虜震駭遠遁邊人歌之辛巳六月敗西番於涼州都督毛忠被圍賊勢盛監軍以下皆震恐潁曰安有賊困我師而不救者遂躬冒矢石戰而前賊披靡不敢近卒全師歸甲申番族把沙作亂潁率兵深入敗之斬獲無筭  
憲宗即位召公還丙戌錄功加禄米一百石丁亥挂征虜前將軍印鎮遼東女直毛鄰犯邊潁據險設伏連敗之獲馬牛畜産并掠去子女甚衆以疾乞歸  
<span style="margin-left: 1em">命守備鳳陽改南京連上疏請老　詔還之北京俾食其全禄以伯歸第潁天性明達遇事有謀而能斷尤篤於倫理甫冠都督公卒哭泣幾喪明撫其孤弟姪及羣從子弟皆有恩意以家在松江而都督公葬歷城每遇二邦人如見親戚存問故舊叙述平生極其欵曲曰吾老矣水木本源之意吾後人安知既謝事角巾私第故時部曲率爲顯官歲時候問皆拜於牀下潁以子弟撫之忠勇之性老而彌篤每三邊有</span>  
<span style="margin-left: 1em">警輒扼腕歎息有馳志伊吾之意當一日邊報急　廷議出師而將臣有稱疾臥家者潁喟然謂坐客曰</span>  
上寬恩至矣客問即真病柰何曰病不至於死行而死於塗可也聞者壯之弘治戊午正月二十八日卒年八十八追封宣城侯謚曰壯勇  
葉宗行字宗行華亭人宋太學生李之後讀書尚氣節永樂中東吳大水松江尤甚蓋黃浦下流壅塞水無所歸宗行上書請棄其故道濬范家浜引浦水以歸于海禁近海民無私作壩以遏其流  
上善其言命從夏尚書原吉來治之水患果息原吉還  
<span style="margin-left: 1em">　朝薦其才擢知錢塘縣錢塘劇邑民困於徭賦宗行爲定役法俾民自占甲乙書于册循次而呼之役遂以均詞訟亦簡不逾年翕然稱治一日廳事前有蛇蜿蜒若有所告訴宗行諭之曰若豈有冤乎吾爲汝驗之蛇返入餅肆中爐下發之得死屍乃肆主人利其財殺之埋此遂伏誅又嘗江行忽舟重不能進視之一死人罫于柁腰下有石乃里中人殺而沈之者亦伏誅縣故多虎暴宗行爲文祭之虎遂歛迹</span>  
仁宗在東宫聞其治行戒所司不得擅自淩辱按察使周新風采嚴峻尤重之嘗候宗行出潛至其舍視室中惟笠澤銀魚乾一裹新歎息攜少許而去明日召以食曰此君家物也飲之至醉出三品儀仗導之歸宗行辭不許曰此位可至奚辭爲時呼爲錢唐一葉清會  
<span style="margin-left: 1em">朝廷大營建宗行率兩浙工匠赴北京道病卒新泣思累日自爲文以祭錢唐人至今稱之謂不愧古循吏云</span>  
張昕字賔暘以字行宋宰相商英之後先世自杭徒華亭賔暘少穎悟六歲入小學誦禍因惡積二語即知善之當爲與惡之當去孫大雅王叔明一見異之曰將來令器也永樂初尚書夏原吉治水松江舉賔暘自輔建議疏范家浜與葉宗行合原吉從之一境蒙利以薦授户部主事陞員外郎通政趙居任治水浙西民苦其煩苛  
仁宗監國命賔暘來副之時已七月居任猶役民晝夜車水不息賔暘言農事已不及徒勞無益即日散遣之民皆感悦以家素豐在官不受俸既致仕家居一以救貧恤孤爲事鄉人至今稱之  
黃翰字汝申華亭人永樂壬辰進士授江西按察僉事宣德庚戌陞參議奉  
<span style="margin-left: 1em">璽書與都御史賈諒巡撫江西改參廣東陞山東按察使罷歸卒翰爲人豪俊多權略始冠擢第觀政都察院有疑獄一問即決爰辭如老吏臺中皆驚居官所至能舉職江西人以妖術惑衆廣東畜蠱毒採生殺人皆捕誅之仍刻石著蠱毒方及所以解之者自是術不得行俗爲一變然負其才氣不能就矩矱既失官家居頗自恣鄉鄰畏之常乘白騾入城市見者皆歛避焉詩文豪健敏捷如壯游集所載皆操筆立就未嘗起草字畫亦遒勁行草題署皆得名</span>  
陳敏永樂中以能書徵除知四川茂州州境民夷雜處素難治敏宣布德意莫不感化秩滿州人借留陞四川左參政仍掌州事卒民立祠祀之  
錢溥字原溥華亭人正統己未擢進士試薔薇露詩稱  
<span style="margin-left: 1em">　旨命教內書館授翰林檢討擢春坊左贊善仍兼檢討修寰宇通志成陞左諭德兼編修天順丁丑改尚寶司少卿陞侍　讀學士</span>  
<span style="margin-left: 1em">賜二品服充東宫　講讀官壬午奉使安南國</span>  
<span style="margin-left: 1em">賜一品服甲申坐內侍王倫事<sub class="note-yuan">詳見溥歸榮集</sub>出知廣東順德縣成化丙戌復故官間住癸巳起掌南京翰林院事秩滿赴京擢南京吏部左侍郎己亥入賀</span>  
聖節尋乞歸命以本部尚書致仕補一子爲國子生丁未進階榮禄太夫再補一子國子生弘治戊申五月卒年八十一　賜諡文通溥少有文名既擢第聲譽勃起嘗上書楊文貞公論學文貞韙之居父憂與巡撫周文襄公論便民條約復移書侍郎李公論積荒召佃煎鹽水次倉四事多見施行在順德釋繫囚撫流民尤多善政  
英宗復位大臣多受賞溥言于兵部尚書陳汝言曰當時非  
皇太后手詔則曹石二人焉敢提兵入禁宜以功歸諸  
太后上尊號爲宜汝言入言之  
上即舉行已而問知出於溥也故有學士之命使安南與  
<span style="margin-left: 1em">禮部論移文不當與內臣同行禮又與內臣書論</span>

顧純字以正華亭人性介直不隨俗俯仰晚自以少容別號頤弘子蓋矯之也成化中以進士出知高安縣中門內有神樹云能爲禍福吏民賽禱雜庭下長吏莫敢禁純至曰吾在安得爾命伐之諫者旁午不聽已伐果有變曰其本在爾盡斸之乃止自是縣中畏服政行教孚獄訟衰息爲一道最入爲刑部主事進員外郎時大官有以文章自命者衆咸歸之純持正獨無所附麗會攷察京職遂以老疾罷歸時弘治初純年五十餘爾閒居卻掃日端坐一室諸經子史循環玩味晚年所造益深爲文章深厚典則出人今古雖少壯不及尤注意鄉里人材聞後進有好學者引接訓誘無異子弟而必以行檢爲本議論侃侃抑浮予實有前輩風  
孫衍字世延一字延之華亭人父瓛廣信訓導母任氏參政勉之女賢而知書衍承家學弱冠領鄉薦成化戊戌第進士知深沔二州並著聲績弘治初入爲南京職方員外郎進車駕郎中車駕典舟車中官索取無藝衍每裁抑之因構成大獄然卒不能浼陞知延平府有盜殺人劫財縣誤以良民余姓者抵罪衍察其冤潛訪得真盜而出余于獄羅監生者富而彊毆人至死將行賄以圖免衍捕正其罪時人快之閩俗婚嫁論財死輒付之火衍嚴禁止俗爲之變辛酉夏旱徒步行禱烈日中已而得雨卻蓋冒雨歸遂得疾不起閩人感而哀之衍少貧有志操居官廉謹卒之日室無餘財詩文清麗俊逸有雪岑稿若干卷二子承德承恩皆業儒承恩今爲翰林庶吉士  
高祐字天錫上海人本王氏父鉉贅於高因從其姓成化丙戌以鄉貢士授泉州同知泉多山谿民倚險爲梗祐訓以德義首惡皆從化積歲逋欠不督而集凶年貸民粟以山鄉遠召從化者總授而分給之遠邇稱便每出山民扶老攜幼送迎者屬路嘗道漳州宿山間有負豪家債而憤其逼者聚千人期旦日殺豪豪亦號召爲敵祐知之俾館人往諭以禍福片言而散其感人有如此者一日令所部市茶其人密置銀二定以進祐啓之笑曰爾謂我有求邪卻還之屏其人弗復接丁外艱歸部民送者千數争攜金錢跪贐皆不受至泣而退歷廣平東昌二府操履如一晚居邑西一室蕭然晏如也時鄉人議士大夫有三婦之喻獨目君爲節婦云  
張穀字濟民上海人祖衡永樂乙未進士拜監察御史立朝不阿卒貶所穀成化中舉進士甲子適周鄉人以爲異授中書舍人直內閣尋引疾歸弘治初起修  
憲宗實錄錄成同事者皆進官穀止加俸恬無一言又三年乃陞湖廣參議提督太岳泰和山至周覽岳祠謂道流曰汝輩處此非偶然宜勤修以答天貺是夕索浴晨起更新衣出廳事方執筆判署目微瞑扶歸遂卒穀風度清遠眉目秀朗如畫與人言從容簡當雖怒無厲色遽詞事母至孝養二姊終始以禮淳雅恬退望而知爲篤行君子云
