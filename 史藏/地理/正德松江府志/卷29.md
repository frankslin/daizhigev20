## 正德松江府志卷之二十九　人物三（名臣）

<span style="margin-left: 4em">人物三<sub class="note-yuan">名臣</sub></span>  
<span style="margin-left: 1em">國朝全思誠字希賢上海人博學能詩文洪武初以老</span>  
<span style="margin-left: 2em">儒召爲文華殿大學士兼左中允賜勑致仕有懷材</span>  
<span style="margin-left: 2em">抱德肩志古人之褒</span>  
<span style="margin-left: 1em">王公亮華亭人世業儒蚤失怙恃大父安之講授于鄉</span>  
<span style="margin-left: 2em">公亮克承厥訓以能書舉任吏科給事中陞應天府</span>  
<span style="margin-left: 2em">丞永樂初擢四川右布政使調廣東公亮儀度閒雅</span>  
<span style="margin-left: 2em">居官簡靜務大體廉重愷悌人皆悦服卒于官孫臣</span>  
<span style="margin-left: 2em">鴻臚序班直內閣陞通政司經歷卒</span>  
<span style="margin-left: 1em">任勉之字近思其先四明人元松鄉先生士林子耜爲</span>  
<span style="margin-left: 2em">兩浙鹽運照磨始占籍華亭勉之登洪武甲戌進士</span>  
<span style="margin-left: 2em">出知饒州府鄱陽縣以正民俗爲首務令有不便者</span>  
<span style="margin-left: 2em">或爲匿名書詆之下令俾勿壞曰告我以過是忠於</span>  
<span style="margin-left: 2em">我也寡婦愬夫兄弗育己公曰汝他適乎乃判其衫</span>  
<span style="margin-left: 2em">背曰餓死事極小失節事極大婦感其言卒不嫁由</span>  
<span style="margin-left: 2em">是邑中風動稱爲賢令鄱故大邑前官叢脞事劇甚</span>  
<span style="margin-left: 2em">勉之立簿書俾民自爲約次第舉行不勞而集秩滿</span>  
<span style="margin-left: 2em">陞知瀘州民詣</span>  
<span style="margin-left: 2em">闕借留陞其府同知薦爲福建右參政左遷右軍都</span>  
<span style="margin-left: 2em">督府經歷出知徽州府以事謫滄州泰然自處不廢</span>  
<span style="margin-left: 2em">著述尋起知蔚州改睢州致仕卒年八十九勉之豪</span>  
<span style="margin-left: 2em">邁英偉長身玉立音如洪鐘雖造次語言皆可錄或</span>  
<span style="margin-left: 2em">問郡守某何如人曰有治民之才無養民之心時以</span>  
<span style="margin-left: 2em">爲確論爲文辭雄健贍蔚似楊鐵崖書學米南宫而</span>  
<span style="margin-left: 2em">不以自名既老四方求文者無虛日永樂正統之間</span>  
<span style="margin-left: 2em">論文章政事必以勉之爲稱首云所著有薇菴集若</span>  
<span style="margin-left: 2em">干卷一子肅蚤夭以弟子弘爲後孫順世其學以國</span>  
<span style="margin-left: 2em">子助教陞涇府右長史</span>  
<span style="margin-left: 1em">陳禎字景祺華亭南橋人宋康肅公十四世孫也讀書</span>  
<span style="margin-left: 2em">好禮喜怒不形于色洪武中以稅户子弟舉爲禮部</span>  
<span style="margin-left: 2em">主事有能聲嘗大廷議事衆不能決禎徐進剖析數</span>  
<span style="margin-left: 2em">言而定</span>  
<span style="margin-left: 1em">上嘉奬而器之俾攝部事諭之曰卿見事敏四司之事</span>  
<span style="margin-left: 2em">宜悉知之禎益謹飭不敢怠坐齊麟事謫戍金齒未</span>  
<span style="margin-left: 2em">幾　召還授五軍斷事官稽仁丁家艱起復上疏乞</span>  
<span style="margin-left: 2em">終制服闋陞主客員外郎出知湖廣襄陽府時荆土</span>  
<span style="margin-left: 2em">蝗獨不入禎境永樂初　召爲鴻臚少卿治水東吳</span>  
<span style="margin-left: 2em">陞河南右參政黃河決勞來有方民不失業盜發汝</span>  
<span style="margin-left: 2em">寧將窺汴賴以計離其黨與困其首張子誠等千人</span>  
<span style="margin-left: 2em">于均山降之兵不血刃而定</span>  
<span style="margin-left: 1em">上嘉之賜勑奬勞秩滿乞祭掃陛辭謫知交趾丘温縣</span>  
<span style="margin-left: 2em">時方暑南中瘴癘或勸使緩行曰死生命也何瘴癘</span>  
<span style="margin-left: 2em">爲至縣一月卒年五十</span>  
<span style="margin-left: 1em">上聞而惜之後八年其友胡士文請於掌交趾藩臬事</span>  
<span style="margin-left: 2em">尚書黃公福始獲以其喪歸禎平居嘗曰人惟仰不</span>  
<span style="margin-left: 2em">愧俯不怍而已身之利否何計其行事類此故歷官</span>  
<span style="margin-left: 2em">所至並著聲績云四子謨詢誥諫</span>  
<span style="margin-left: 1em">詢字汝同早失怙事母以孝聞登永樂戊戌進士累官</span>  
<span style="margin-left: 2em">翰林侍讀學士出知安陸州景泰初　召復故官陞</span>  
<span style="margin-left: 2em">大理少卿巡撫北直隸改太常少卿兼學士終國子</span>  
<span style="margin-left: 2em">祭酒致仕卒年六十六詢性峭直寡言笑平居儼然</span>  
<span style="margin-left: 2em">飲酒能多而不亂在官處僚友和而不同人不敢干</span>  
<span style="margin-left: 2em">以私秉道嫉邪蓋出天授正統中中宫王振怙寵公</span>  
<span style="margin-left: 2em">卿皆下之劉忠愍李文毅忤之皆得奇禍詢絶不與</span>  
<span style="margin-left: 2em">通振銜之故有安陸之謫方是時詢直聲動天下人</span>  
<span style="margin-left: 2em">皆爲危之而詢怡然不以爲意也編修梁諲病語家</span>  
<span style="margin-left: 2em">人曰朋游中惟陳同年汝同心地好且有家法孤子</span>  
<span style="margin-left: 2em">女可託也詢聞而諾焉及諲卒爲經紀其家事無不</span>  
<span style="margin-left: 2em">曲盡至冒謗毁而爲之不鷹嫁其女得松人黃瑜後</span>  
<span style="margin-left: 2em">參福建政竟以梁之喪歸其鄉其篤于友誼如此爲</span>  
<span style="margin-left: 2em">文章清勁有氣骨類其爲人主考兩畿判國子奬拔</span>  
<span style="margin-left: 2em">士類甚衆若嚴銓丘濬楊繼宗彭韶施槃輩後皆爲</span>  
<span style="margin-left: 2em">名臣</span>  
<span style="margin-left: 1em">王鍾字公簴華亭人爲人寡慾雖富貴不改窮約時平</span>  
<span style="margin-left: 2em">居端厚簡默遇事剖決沛然無滯敷奏亦然永樂初</span>  
<span style="margin-left: 2em">侍東宫居守北京甚見親重累官至户部右侍郎洪</span>  
<span style="margin-left: 2em">熙元年</span>  
<span style="margin-left: 1em">上思舊勞贈　太子太保謚僖敏</span>  
<span style="margin-left: 1em">沈度字民則華亭人竹庭暉之孫苦節先生易之子也</span>  
<span style="margin-left: 2em">易性至孝以易學授徒于家嘗輯五倫詩著孝經旁</span>  
<span style="margin-left: 2em">訓行于世度少力學善篆隸真行書以薦授翰林典</span>  
<span style="margin-left: 2em">籍累官至學士卒弟粲字民望善真草書飄逸遒勁</span>  
<span style="margin-left: 2em">自成一家尤長於詩有集二千餘首累官翰林侍讀</span>  
<span style="margin-left: 2em">春坊庶子至大理少卿致仕永樂以來兄弟並在禁</span>  
<span style="margin-left: 2em">林最承恩遇而伯仲同居友弟無間縉紳以爲莫及</span>  
<span style="margin-left: 2em">粲尤端厚謙抑好奬予後進至今館閣猶稱爲二沈</span>  
<span style="margin-left: 2em">云度子藻亦善書以蔭爲中書舍人至禮部員外致</span>  
<span style="margin-left: 2em">仕</span>  
<span style="margin-left: 1em">孝宗尤好度書訪其後得四世孫世隆即授中書舍人</span>  
<span style="margin-left: 2em">直內閣正德初預修國史以微眚去官卒</span>  
<span style="margin-left: 1em">何廣字公遠華亭人後遷上海以知縣擢御史至陝西</span>  
<span style="margin-left: 2em">按察副使寬厚有容博學多識尤精於律學時變亂</span>  
<span style="margin-left: 2em">成法者當大辟法家因仍凡一政令改易輒以傅議</span>  
<span style="margin-left: 2em">廣曰嘻若是則大辟者踵相接矣此但爲改定律令</span>  
<span style="margin-left: 2em">者言之蓋禁於所不犯也大學士解縉紳覽而是之</span>  
<span style="margin-left: 2em">及卒長沙通判俞永狀其行曰居鄉里則稱學者任</span>  
<span style="margin-left: 2em">郡邑則爲循吏在風憲有澄清志位藩垣得大臣體</span>  
<span style="margin-left: 2em">時以爲實錄所著有律解辯疑行于世</span>  
<span style="margin-left: 1em">石璞華亭人永樂中舉人任陝西按察使剖決如流吏</span>  
<span style="margin-left: 2em">民畏服得憲臣體</span>  
<span style="margin-left: 1em">夏禮字公立上海唐行人洪武中貢入太學拜監察御</span>  
<span style="margin-left: 2em">史有直聲</span>  
<span style="margin-left: 1em">高皇帝爲開其軍伍嘗上疏劾勲貴忤旨出爲知縣</span>  
<span style="margin-left: 2em">奏減各處均輸商稅從之永樂初以薦爲御史陞河</span>  
<span style="margin-left: 2em">南按察副史謫戍武清</span>  
<span style="margin-left: 1em">文皇北巡再　召爲御史使至南京值閘壩水溢漂居</span>  
<span style="margin-left: 2em">民亟令有司疏泄</span>  
<span style="margin-left: 1em">上聞而是之復以薦爲陝西按察副使積歲疑獄一言</span>  
<span style="margin-left: 2em">而決以內艱去陝西數千人詣</span>  
<span style="margin-left: 2em">闕借留奪情還任卒于官</span>  
<span style="margin-left: 1em">衛青華亭人世力農父炳當元季應募隸水軍萬户府</span>  
<span style="margin-left: 1em">太祖受命杖劒來歸從征討四方未嘗辱人子女掠人</span>  
<span style="margin-left: 2em">財物與妄殺一人有功輒以讓同列竟終于行伍青</span>  
<span style="margin-left: 2em">狀貌雄偉倜儻有氣概勇而善謀洪武末以總旗授</span>  
<span style="margin-left: 2em">薊州衛百户累陞山東都指揮僉事備倭海上永樂</span>  
<span style="margin-left: 2em">中蒲臺妖婦唐賽兒自稱佛母誘愚民爲亂攻安丘</span>  
<span style="margin-left: 2em">甚急青聞率千騎晝夜兼行至城下奮擊破之殺二</span>  
<span style="margin-left: 2em">千餘人生擒四千人皆斬之而收其孥時城中已不</span>  
<span style="margin-left: 2em">支衆謂青至稍緩城必陷已而安遠侯柳升至怒其</span>  
<span style="margin-left: 2em">不待己捽辱之青不爲屈事聞</span>  
<span style="margin-left: 1em">上切責升降　敕褒美曰衛青進不求名退不避罪惟</span>  
<span style="margin-left: 2em">民是保雖古之名將何以加焉陞都指揮使正統初</span>  
<span style="margin-left: 2em">進右軍都督僉事仍備倭六月以旱蝗出禱得疾</span>  
<span style="margin-left: 1em">上聞遣醫療之未至二日卒葬濟南歷城之鵲華鄉青</span>  
<span style="margin-left: 2em">幼時嘗牧羊馬憗寺前有道士見而奇之撫其頂曰</span>  
<span style="margin-left: 2em">兒他日腰金衣紫聞者皆笑之至是果然及卒登萊</span>  
<span style="margin-left: 2em">人爲立廟海上事之甚嚴或見其紅袍白馬出人廟</span>  
<span style="margin-left: 2em">中云有子十一人長頤襲濟南衛指揮使早卒無子</span>  
<span style="margin-left: 2em">次潁嗣餘分處濟南登萊留華亭者行第九曰顯云</span>  
<span style="margin-left: 1em">潁字源正豐頤廣顙語音如鐘代兄頤爲指揮使選督</span>  
<span style="margin-left: 2em">山東漕運領京營操以勇幹聞正統己巳之變從山</span>  
<span style="margin-left: 2em">東入勤王建議募勇敢士收合散亡調各都司兵實</span>  
<span style="margin-left: 2em">京城修沿邊關隘爲戰守計當搶攘中意氣慷慨籌</span>  
<span style="margin-left: 2em">策整暇人倚以安由署都指揮僉事陞同知進都督</span>  
<span style="margin-left: 2em">僉事十月也先入寇潁率兵邀擊於黃花鎮連戰西</span>  
<span style="margin-left: 2em">直門諸處又尾擊之於紫荆關以功多陞都督同知</span>  
<span style="margin-left: 2em">充總兵官出守宣府還督京營兵</span>  
<span style="margin-left: 1em">英宗復辟陞左都督十一月錄功封奉天翊衛宣力武</span>  
<span style="margin-left: 2em">臣柱國宣城伯食禄一千一百石　賜鐵券子孫世</span>  
<span style="margin-left: 2em">襲尋充總兵官挂平羌將軍印守甘肅時羌虜謀入</span>  
<span style="margin-left: 2em">寇衆議持重待之潁奮然勒兵而出連十二戰大破</span>  
<span style="margin-left: 2em">之虜震駭遠遁邊人歌之辛巳六月敗西番於涼州</span>  
<span style="margin-left: 2em">都督毛忠被圍賊勢盛監軍以下皆震恐潁曰安有</span>  
<span style="margin-left: 2em">賊困我師而不救者遂躬冒矢石戰而前賊披靡不</span>  
<span style="margin-left: 2em">敢近卒全師歸甲申番族把沙作亂潁率兵深入敗</span>  
<span style="margin-left: 2em">之斬獲無筭</span>  
<span style="margin-left: 1em">憲宗即位召公還丙戌錄功加禄米一百石丁亥挂征</span>  
<span style="margin-left: 2em">虜前將軍印鎮遼東女直毛鄰犯邊潁據險設伏連</span>  
<span style="margin-left: 2em">敗之獲馬牛畜産并掠去子女甚衆以疾乞歸</span>  
<span style="margin-left: 2em">命守備鳳陽改南京連上疏請老　詔還之北京俾</span>  
<span style="margin-left: 2em">食其全禄以伯歸第潁天性明達遇事有謀而能斷</span>  
<span style="margin-left: 2em">尤篤於倫理甫冠都督公卒哭泣幾喪明撫其孤弟</span>  
<span style="margin-left: 2em">姪及羣從子弟皆有恩意以家在松江而都督公葬</span>  
<span style="margin-left: 2em">歷城每遇二邦人如見親戚存問故舊叙述平生極</span>  
<span style="margin-left: 2em">其欵曲曰吾老矣水木本源之意吾後人安知既謝</span>  
<span style="margin-left: 2em">事角巾私第故時部曲率爲顯官歲時候問皆拜於</span>  
<span style="margin-left: 2em">牀下潁以子弟撫之忠勇之性老而彌篤每三邊有</span>  
<span style="margin-left: 2em">警輒扼腕歎息有馳志伊吾之意當一日邊報急</span>  
<span style="margin-left: 2em">廷議出師而將臣有稱疾臥家者潁喟然謂坐客曰</span>  
<span style="margin-left: 1em">上寬恩至矣客問即真病柰何曰病不至於死行而死</span>  
<span style="margin-left: 2em">於塗可也聞者壯之弘治戊午正月二十八日卒年</span>  
<span style="margin-left: 2em">八十八追封宣城侯謚曰壯勇</span>
