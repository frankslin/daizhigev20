## 正德松江府志卷之十二　学校上

<span style="margin-left: 4em">学校上</span>  
<span style="margin-left: 3em">吾松自唐而为县至宋而始有学一方之风气亦</span>  
<span style="margin-left: 3em">以渐而开也自有学以来偾而兴者数矣详书之</span>  
<span style="margin-left: 3em">可以观时政焉非徒为岁月识也书院义塾已废</span>  
<span style="margin-left: 3em">而犹录之盖有望乎云尔</span>  
<span style="margin-left: 1em">府学在集僊门西梯云桥之北儒林坊南旧华亭县学</span>  
<span style="margin-left: 2em">也宋初有先圣庙介于梵刹天禧初令刘唯一始迁</span>  
<span style="margin-left: 2em">于县东时学舍犹未立<sub class="note-yuan">至圣文宣王庙记至矣哉先儒之称夫子也子贡则喻诸日月孟子则冠于生民通其祀则韩吏部以社稷为非严无其教则杜子美谓夷狄之不若是皆杰出意表垂范将来抉狂简之肺肝判冥顽之耳目肤浅庸蔽又何加乎若乃诵圣籍以知归服儒衣而不变以严师为己任将尊道为士先苟得其人不系乎位华亭县者嘉禾郡之剧邑也当土敝水烦之地属风颓俗杂之余民无坚正之心世尚剽狡之气淫神以要其福佞佛以逃其祸先生之教咸罔闻知庙貌之灵宜夫委顿自钱氏纳土宋运有开年历寝深邑长相继殊未思政理以五常为本五常由夫子而明必有所宗是宜崇祀率神如弁髦之敝孰能存爱树之心介于梵刹之隅甚矣郑门之困今天子明神所劳禋享聿修典册攸存牲弊靡阙而况褒成教本位极真王通邑之祠不绝如线非所以副国章之举废俾乡校之知方少傅刘君是以有志于斯也刘君世编宦族代传素风养勇久负于一鸣适道无辞于寸禄下车而奸盗屏假印而狱讼清胥尹服从闾里竞劝当其至止首谒圣师拨蟏蛸而入户庭履蔓草而升堂陛致美且慙于黻冕改为奚及于缁衣列像隳残侍坐跛倚裵徊瞻覩俯仰咨嗟不易新规曷成大状爰求隙地得于县东营爽垲之基委诸薙氏度中伐之木命以梓人民忘悦使之劳吏谨不愆之素由是重门秘殿敞大厦以耽耽东序西厢亘文𢱧而翼翼后建殖庭之宇用铺讲艺之筵旅楹既闲陋堵室之非度缩版以载见宫墙之特高而又约奉身之资损计日之俸俨晬容而允穆饰华衮以鲜辉入室之贤侁侁侍坐升堂之众济济负墙置孝爱之一人与配侑而兼列如在之威神备矣致诚之典礼敦焉爼豆尝闻风雨攸除呜呼大道既隐明王不兴儒雅之俦没没无媿矧夫皇猷允塞文令阐扬夫子之英焕焕宜久岂独行于万里长幼之序有俭如能达彼四方齐鲁之风可变执古性惟乐善学媿亲师圣门难言诚甘取诮互乡与进冀许偕行直书内疚于无文不朽幸刊于美石时天禧二年岁次戊午闰四月十有一日陈执古记</sub>后六十五年当元丰甲子陈令谧始议兴学</span>  
<span style="margin-left: 2em">县人衞公佐公望献县之东南地且独任礼殿之役</span>  
<span style="margin-left: 2em">工未兴而公佐卒历陶令镕至刘令鹏始克就绪公</span>  
<span style="margin-left: 2em">佐子又贾国子书以资诸生讲习绍兴以来杨令寿</span>  
<span style="margin-left: 2em">亨周令极侍其令铨钱参政良臣杨令潜相继修之</span>  
<span style="margin-left: 2em">而学舍始完整其地则令魁星楼址及射圃是也<sub class="note-yuan">县学记元祐五年夏四月辛丑左宣德郎知秀州华亭县事刘侯初视事越三日癸卯谒先圣庙顾新学有左庑而阙右庑食无庖爨居无什伯之器垣墉不立犬彘得以游处而无虞刘侯恻然环视徬徨归则发政以惠民徐以善言风谕邑内邑内欣善莫不奔走以承命于是学始缮完又讽谕得衞氏子买国子监书以资诸生乃属其佐刘发为之记且曰新学之建吾无与也必为记不忘前人之功力尔已而发解官刘侯又以书见速且曰学始谋于陈侯卒建于陶侯无以吾厕于二人之间刘侯之意固忠厚矣而事在众人之耳目非可诬也辄广记而备言之华亭大县也旁小县皆有学独华亭无之盖浙西善事佛而华亭尤甚民有羡余率尽以施浮屠故其他有所建置莫易以成就先圣庙故在县治侧湫隘毕陋旁不可以为斋馆自吴侯为宰已尝有意迁易而劝导率不就后三十年而陈侯谧复议建学是时邑人衞公佐率先献县之东南地且求独建先圣殿归即筑土治木预为户牖加漆饰以须期会期会未定陈侯以事去议又罢久之浮屠氏从公佐乞所治材为佛宇公佐曰此材可使之朽腐必欲移用则不可相继陶侯镕为政而公佐死浮屠氏又从其子弟求其材为公佐祈福其子弟则今买书者也固执如公佐之意于是邑子朱赓朱伯夔周扬许洙以之于陶侯陶侯使之白州郡监司曰州郡监司见从吾无不从者四人者乃率众士人诣郡太守又诣转运使皆得请遂择日鸠工而四人者实董其役邑人素愿尽力者固已各实其言矣而他无物成其事者故积久卒成于刘侯盖若有待焉夫致治不可不先学校庸人孺子皆知之学士大夫方困布衣必以是说应有司之求及其入官则背之果何以哉盖上之人所程督者常在狱讼簿书而考绩不急加教化故也以文盛之时建学校于多士之地或有其意而不能遂其议或遂其议而不能致其事或致其事而不能成其功故发记其实以为上下之劝使后之观者知成功如此之难无至于废而不洽云刘发记修学记华亭于檇李为大邑其地东南滨海无崇山叠嶂坦然如砥数百里间水光接天仙禽唳野钟此粹清异人间出有如二陆顾希冯蜚英千载宜后学追踪可项背相望也奈何学废不修青衿散逸虽有美质奚自而作成邪宣和中舍法罢去重以兵革之艰棘士非里选学闭空屋风揭雨穿日底摧败异时讲贯藏修之地茀榛莽而舞鼪鼬矣上丁释奠执事以胥史素木瓠叶何从观礼二十余年阅令凡几其间不无贤大夫以起废动心然迄置不问者得非时有所未遑欤绍兴壬戌之仲夏蜀郡杨侯出宰是邑下车以故事谒先圣于学裵褱睥晲慨然有必葺之志属岁大旱三农废铚艾者十八方抚流亡之不暇奚暇治礼义哉越明年岁得中熟于是斥羡赀鸠长材秉农隙饬工役经始于十四年之正月落成于是岁之杪春殿宇中严萧屏外壮讲者有堂居者有舍斋宿有位宾谒有次以至帑廪庖馔各有区处帘帟器皿纤悉毕备其塑绘之不经冕服之非度率按礼象而易之渠渠夏屋轮奂一新观者咸疑其始创信乎宏丽甲于他邑也时朝廷初行乡饮酒礼因得序賔于斯既而兴学之诏颁而华亭之学已成则侯之为政可谓知所先务矣春秋补试粉袍云集按籍得旧赡学田三千亩岁入秔稻七百余斛益以浮屋之租士食霈然呜呼盛哉侯秩满将归朝嗣有贤宰能加意是举焉知俊秀不无顾陆之流出乎昔唐韦景骏令于肥乡学庐馆舍皆所缮治他日过之儿曹悉至迎劳而以获见为幸夫景骏所以列于循吏者虽其治状伟然盖亦兴学之有助也今侯之政以宽惠为本委巷细民类能道之观其修学之一端则他可知矣诸君饱侯德求兼记之兼忝僚末义不获辞乃书其事俾镵于石云绍兴十五年五月五日左迪功郎县尉主管学事延平廖兼譔进士洪伯谦书篆修学记华亭剧邑也地东南负海北通江有鱼盐稻蟹之饶多富商大贾俗以浮侈相高不能力本业然衣冠之盛亦为江浙诸县之最虽细家中人衣食才足则喜教子弟以读书为士四方之俊历聘而来受业者云集其中秀民才士往往起家为达官繇是竞劝于学弦歌之声相闻居官者不必以击断鸷猛为治亦可以礼义驯服也往时长吏媮为一切以军旅期会为急应办调发锐于集事上下如束湿以故激成顽俗伺吏短长为嚚讼驯雅之风少衰绍兴己卯长兴周侯极来宰是邦下车问风俗则曰自吾居乡时闻此有难治名今固无所用斤斧也廼尊儒生礼贤隽一以文治之先教后罚故习尽革邑以无事顾瞻学宫垣墙圮漏茀秽不除经师倚席不讲弟子散在党巷则喟然曰吾邑多君子而学弊若此顾何以称父兄之乐育广师友之渊源且吾所恃以革彊暴揉顽犷省狱讼而优游于此者端在是尔其可缓即选于众得才敏廉干之士曰陆南者俾长诸生而会计焉籍赡学之田获隐没不输之租甚多度廪给之余悉取以充费市材具募佣工而悦使之正欹倾补罅漏筑夷圮易朽蠧锄荒颣达堙塞墁垩之丹雘之廊庑修洁庭户明焕鼎鼎乎砚席之盛也邑人郑君澭承是美意捐私帑设门㦸翼以栏楯而夫子之宫仪制始备庙貌尊严过者肃容既讫功南以事来告且命纪实克昌窃惟老佛之教以崇饰塔庙为植福之本虽越法逾礼不知涯量然读其师之书者必能尊其说所至辄能变瓦砾为金碧更庳陋为轮奂又常以死生不可亿之说骇怖流俗而富家巨室倾赀以助其靡以徼觊身后之福今吾儒不然其宫室有数其械器有等不伤民财有补于世而为吾徒者反不能尊其书衞其道视庠序荒凉学徒解散为吏者则以力不暇给为托而不知崇儒尚贤为从政之良策也居家者则以为无捐益于己而不知导子孙学乃无穷之利也一何悖哉今周侯尊吾道不鄙夷其民修学校以示向劝而郑君欣然附从至出己力而不惮真可使异端退听儒术增气然则周侯之于民郑君之于子弟可谓得为宰为父兄之道矣是可书也故乐为之书绍兴庚辰季冬朔左承事郎新差签书奉国军节度判官厅公事许克昌譔左承奉郎太常博士兼权光禄寺丞郑闻书左朝请郎主管台州崇道观借绯朱冠卿篆额修学记学校为育材之地近代从政者困于簿书期会急于财货源流往往力不暇及春秋较艺朔望讲经徒修故事至于黉宇之简陋骎骎乎穨毁之域则恬不经意吁百工居肆以成其事士子不由学而望其成就可乎眎欹弗支见漏弗补因循苟简以延岁月则亦终至于穨毁而已云间之学岁在甲子鼎新于蜀郡杨公寿亨规抚虽不伟不壮亦具体而微阅时滋久风雨震凌圮漫不振乡参钱公复加营缮栋宇为之增壮自时厥后主盟学事者不为无人新者渝壮者陋未闻以葺治为言余眎事是邦日敚丹墨应酬之冗末年始与学长黄枞谋画去蠧易坚补罅苴漏绘雘从新经始于癸丑嘉平节讫事于甲寅仲春自是堂可以讲齐可以诵室可以寝步趋有廊庑膳羞有厨传虽不能广大前日之规橅概之旧观为差胜所以肄业其间者当如何囊萤牖雪编蒲缉柳古不可追若杜纷华甘虀盐对圣贤商确古今以洗濯尘俗之胸襟磨砻云霄之事业纡朱芥紫权舆于此可不知勉余旧亦由学校叨窃末第则所以期待诸生者盖不敢不勉故自初严选补谨课程置门籍以司出人限斋宿以紏勤惰甚者虑廪给之不继罢滥竽之员镌与釜之粟亦既三载于兹教养之心未始少忘而作成之効窃有望焉异时名公巨卿项背相望事掩前闻则余所以拳拳者亦不为无补云绍熙甲寅季春朔奉议郎知秀州华亭县主管劝农公事兼兵马都监兼监盐场主管堰事借绯杨潜记宣议郎秀州华亭县县丞赵伯操书迪功郎秀州华亭县尉巡捉私茶盐矾兼催纲赵炳题额参政大资钱公祠堂记州县官到任诣学谒先圣方许视事法也庆元三年夏四月庚午知华亭县徐民瞻始至遵谒再拜庭下既乃巡庑展诚于先哲之从祀者而西庑有祠堂焉牓曰参政钱公之祠载瞻载仰王立山峙衣冠有严香火之供虔且精因致敬而退越三日更朔修故事帅诸生行奠谒之礼已而升堂诸生以序次第见进之坐语环视内外覃覃整整栋宇翚翼阶廊舒袤窻几明洁讲肄有位职掌有室庖廪有次不侈不陋顾坐者曰美哉斯学之久而新也夫兴事于前者固今之难而成其事以久之者尤不易问其年则曰卜筑于斯土者元祐末岁也后八十有八年缮葺而复以至于斯者淳熙己亥之冬也成己亥之事者乃今祠于西庑参政钱公也公讳良臣字友魏生有嘉闻刻志于学始任戴冠乡里已无能出其右者十七试艺补入学抱负器业日夜勤苦从师友磨琢学广而闻多作为文章霈然有余十九升太学道日尊业日茂名誉日起兀兀十年登进士第而归谒谢先圣先师凡昔从游同舍士在学者摄衣迎拜欢喜道旧顾眄殿堂斋舍椽栋檐楹颇不前日若公蹙然不宁谓同舍士曰去此甫十有二年时异事废何其遽邪彼缁黄外说其徒犹能克壮厥居常整治如初且自谓其所以然者得鱼不敢忘于筌也吾辈奚媿于斯言它日幸宦达凡可致力者宜勉历二十五年公参大政辅明天子钧陶之上万机之密悉预𬣙谟犹念念不置转运司有材木之在华亭者去学不里所公闻之喜曰吾事集矣一日转运使以职事造府公以语之即日悉以木株四千有奇畀学时县令徐君安国借以经营之委诸生以职事莅学者僦工役逾年而克成殿堂廊庑斋室廪库瓦椽就倾檐楹将败者一切起而新之涂塈丹雘辉焕明荡不替于昔由是乡老学士大夫喜学之复兴而感公之不忘本也翕然相劝或遣其子弟肄业如公日同砚席书讲学相师用磨砻浸灌争腾踔于学以取科第者接踵皆公之赐也乡人往往相与请于令君绘公像祠于学宫以报属受代未暇也杨君樗年实继领县事未几学生有上其事者遂堂而祠焉今十有九年矣未有记其事以诏后者先生盍图之它日诣学群以告又数月相与造谒请益力吁公之德在乡里如此其至岂待记而后传而民瞻亦岂记公者哉谨叙其所闻俾学长谕书以刻于石庶来者知公之不忘于学而士大夫之所以不忘公云庆元四年夏五月既望奉议郎知嘉兴府华亭县主管劝农公事兼兵马都监徐民瞻记乡贡进士充县学学长范公衮书国学进士充县学学谕朱允题额司计进士刘成之朱奎监镌</sub>庆元末徐令民瞻始为堂于学以祀晋陆机陆云</span> <span style="margin-left: 2em">亩有奇县令钱訚因以修学<sub class="note-yuan">复学田记合二浙之地为县者以百数华亭最大庆历中诏立学州县华亭之学称其大余昔者读政和学法具载郡县之学详矣弟子员眂它县率一二倍养士之田数倍于它县尝恨生晚不及见一时人士之盛闻之长老往年衣冠合辑弦诵雍容县人倾敬今直异乎所闻矣君子叹学政之堕废而斯道之湮郁也岂其盛衰之势然欤知县事溧阳钱君试补生徒易置职秩兴废补弊百尔具举一日过余曰今学舍一新訚何能焉实太守钟侯之赐也日者丧其腴田几无以为学侯来首治其事遂得从容为教养计此德何可忘也幸以乡校之故书其本末至谢不能不获命则请其所以失所以得者曰学故有僧子韶田一千八百九十三亩为租六百八十三石有奇上连三泖下通松江之潮岁有水旱无乾溢之虞籍于崇宁之初距今百二岁矣有豪民者用其亡忌惮以户绝法请于常平使者不得则以养士奇羡请于户部于御史台又不得则钳制学胥盗其籍攀援中贵人借之声势荐赂宿吏为之道也乘守将交代之际以下贾尽得之具为牍侯来开府属邑得诣府下禀受条教吾邑虽繁剧所白事若干念无急于此者庭参以其状闻之监郡吴君仁杰从旁赞说甚力侯奋而起曰此吾责也即付之有司情得既抵其罪复以田归之学于是人人知侯有意学校豪民奸吏无所容其欺也侯今归仕于朝而訚亦将满罢矣识远缺然后来莫知所稽考而谨守之也呜呼此系风教大矣国家崇儒立学甲令画一豪民奸吏凭借中贵人势轻视学校而夺之田岂所宜有者贤侯布宣教条首及诸此可谓知所务矣然古者党有庠术有序所以风化乡里使趋于善者今州县有学则党庠术序之意也而有冒利于风化之地者乎虽吾乡之民怙富而善争奸义而背法平时趋走达官之门张声援事关节以豪夺武断为富亡餍及于学校可太息已幸而令尹敏于事贤侯主盟斯道否则何有于学哉呜呼其过则有所在矣吾党毋尽求于彼也盍亦反诸本乎衣冠弦诵有如往岁之盛其良者慕其奸者惧而敢肆其窥歈也耶不然小人谋利之心何时无之严其礼教以为风化之本此吾党事也其勉之侯名必万字君禄巴陵郡人今为吏部司封郎中嘉泰三年十二月望日寄理修职郎林至记从事郎监嘉兴府比较务崔端纯书宣教郎新知平江府长洲县主管劝农公事朱端常题额修学记溧阳钱君为县之明年嘅念乡校废久不治焕新堂宇修饰斋庐几席具设庖廪整办合试乡邑人士充弟子员推简贡士次补职秩人以舍选之士盖不独课试文艺学政大畧可睹已于是其师生谋伐石以纪其事来谒记于至乃为之言曰人受大地之中以生莫不有秉彛之性圣人君师天下恐其蔽于欲而无以自明也故为之教学以启迪之其序则君臣父子兄弟夫妇朋友其德则仁义礼智而已有诗书六艺之文而优游乎弦诵讲说之中有干戈羽籥以为舞管弦钟鼓之声以为乐而习乎进退之度俯仰之节有释菜宾射养老之事而熟乎等差隆杀之分尊老弟长之义所以开其知识而涤其心志和其血气而增其美质上自天子诸侯之国都下达于党庠术序自少至长皆入于学走趋升降周旋揖逊其中者无非教也此所以学成于乡化行于国风俗厚而王道易也三代衰先王所以教学者废士习益卑民生益不致于理汉之贤君仅能立学京师一时长吏盖已兴礼殿置校官遣学者授业太常而其人士据经守道虽若专门名家然独行君子皆乡里之诸生伏节死义者是以扶汉鼎之将倾其勉于自修笃于为义如此惜乎无三代教法以成就之也魏晋以来中更多故其为不足议者至唐文治复兴京师太学以至州县置博士弟子各有差加之以教养或可以复三代之旧然州县博士弟子皆役于有司名存而实亡失其职业虽唐人𫄨绘之习行义不如两京纯明亦其植立于乡闾之间唐世传循吏者十四五人无以学校为事者独韩愈延师生兴礼教以餐钱计子本给之他可知已乌乎乡之有学教民之始也先王之所甚重而唐汉忽之其亦不知本矣国家上规党庠术序之制诏立学州县复颁教养之法于天下凡师生之员与教道之叙试补升进之则堂宇田畴饩廪之数见之大观政和之书蔼然三代厚民之意汉唐千余年间思虑所未及者士生今时其不能考志厉业者负国家教养多矣华亭之学甲于诸县往时士风之盛不止以文章第太常魁多士盖至于学行淑乡里事业在政府杖节不屈于彊虏扰攘之际争新法不便而槃乐于摈斥之地者可数也乌乎士有废于因循习有安于偷懦三二十年来乡之善士退学于家塾长吏亦视为迂缓不切之务岂国家所以建学之意欤至生长乡里进不能尽见前辈之风流退而求益于学校未能也窃闻之问学之道而规矩之守气质之养而德性之充体有小大而所养之致察事有义利而力辨于毫厘之间过失相规而道义相勉长者有述而少者知敬使风化感于乡闾而礼逊治于田野则为学其庶几乎令尹能体国家之意矣凡游于学者其亦知所勉耶异时粹学硕德皆出于学风动乡里而观示四方顾不伟哉君名訚字子言出于名代耳濡目染故能留意吾道为俗吏之所谓迂缓不切者其可书云嘉泰三年十二月望日寄理修职郎林至记朝请大夫新权知温州军州事钱仲彪书朝请郎权知蕲州军州事钱蔤篆额</sub>开禧间令汪立中始于学宫行序</span>
