## 正德松江府志卷之三十一　人物九（游寓）人物十（封赠）人物十一（列女） 人物十二（仙释）

<span style="margin-left: 4em">人物九<sub class="note-yuan">游寓</sub></span>  
<span style="margin-left: 1em">宋章楶字质夫子厚之弟其先浦城人有讳仔者事闽</span>  
<span style="margin-left: 2em">为兵官尝出兵二将后期当斩夫人练氏救脱之后</span>  
<span style="margin-left: 2em">二将握兵南唐破建州夫人犹在二将使人以金帛</span>  
<span style="margin-left: 2em">遗夫人且授一白旗曰吾屠城夫人植旗于门吾戒</span>  
<span style="margin-left: 2em">士卒弗犯也夫人悉返之曰幸思旧愿全此城否则</span>  
<span style="margin-left: 2em">与俱毙耳二将感其言遂止不屠君子知其后必大</span>  
<span style="margin-left: 2em">至得象遂相仁宗子孙贵盛终宋世不绝楶其从子</span>  
<span style="margin-left: 2em">也始仕试大理评事监华亭盐乐其土风因家于青</span>  
<span style="margin-left: 2em">龙之崧宅里后官至知枢密院封秦国公谥庄敏青</span>  
<span style="margin-left: 2em">龙之有章氏自此始<sub class="note-yuan">按旧志及书院记皆云而苏志又有南北章之说岂青龙初犹别业后乃定居邪今其子孙在郡中犹众</sub></span>  
<span style="margin-left: 1em">邵桂子字德芳号玄同淳安人宋咸淳进士授处州教</span>  
<span style="margin-left: 2em">授国亡不仕娶华亭曹泽之女因家小蒸为斯文领</span>  
<span style="margin-left: 2em">袖者四十年年八十二卒归葬淳安所著有脞谈脞</span>  
<span style="margin-left: 2em">稿各若干卷子祖义池州学录能诗工篆隶孙亨贞</span>  
<span style="margin-left: 2em">字复孺博通经史赡于文辞工真草篆隶书凡阴阳</span>  
<span style="margin-left: 2em">医卜佛老之学莫不究其奥元末兵燹家破侨居横</span>  
<span style="margin-left: 2em">泖洪武初为府学训导以子累谪戍颍上者久之后</span>  
<span style="margin-left: 2em">终于横泖年九十三所著有蛾术稾若干卷稿皆手</span>  
<span style="margin-left: 2em">笔点画不苟足为后学楷式云</span>  
<span style="margin-left: 1em">元任士林字叔寔家奉化松林乡人称松乡先生其先</span>  
<span style="margin-left: 2em">蜀緜竹人宋少师希夷之后八世祖始来居奉化再</span>  
<span style="margin-left: 2em">徙崎山士林六岁能属文书经耳不忘诸子百家之</span>  
<span style="margin-left: 2em">言靡不周览文章沉厚正大一以理为主不作廋语</span>  
<span style="margin-left: 2em">棘人喉舌而含蓄顿挫使人读之而有余味赵子昂</span>  
<span style="margin-left: 2em">邓善之袁伯长辈咸推其文谓今之柳河东云大德</span>  
<span style="margin-left: 2em">间携家华亭与卫山斋善有访山斋诗及兴圣塔华</span>  
<span style="margin-left: 2em">藏院诸记至太初举为安定书院山长明年卒葬松</span>  
<span style="margin-left: 2em">林乡子耜由松江府史至两浙盐运照磨致仕会天</span>  
<span style="margin-left: 2em">下乱子孙遂家华亭</span>  
<span style="margin-left: 1em">杨维祯字廉夫会稽人泰定间李黼榜进士淹贯经传</span>  
<span style="margin-left: 2em">雄于诗文由天台尹改钱青盐场司令提举杭之四</span>  
<span style="margin-left: 2em">务转建德总管府推官升江西等处儒学提举未上</span>  
<span style="margin-left: 2em">会兵乱携家寓华亭筑室百花潭上号小蓬台洪武</span>  
<span style="margin-left: 2em">庚戌卒年七十五松守林公庆葬之天马山<sub class="note-yuan">详见第宅及冢墓</sub></span>  
<span style="margin-left: 1em">张昱字光弼庐陵人少尝事虞文靖公得其诗法仕为</span>  
<span style="margin-left: 2em">江浙行省员外郎行枢密院判已而弃官号一笑居</span>  
<span style="margin-left: 2em">士元末杨廉夫诸公避地吾松昱往来为文字游郡</span>  
<span style="margin-left: 2em">中名迹题咏殆遍张氏招之辞以诗洪武初　召至</span>  
<span style="margin-left: 2em">京深见温接以老乞归</span>  
<span style="margin-left: 1em">上悯之曰可闲矣厚　赐遣还更号可闲老人年八十</span>  
<span style="margin-left: 2em">三卒</span>  
<span style="margin-left: 1em">钱惟善字思复钱塘人号曲江元乡贡进士寓居华亭</span>  
<span style="margin-left: 2em">经明行修有罗刹江赋著名于时诗法唐人尤极清</span>  
<span style="margin-left: 2em">致</span>  
<span style="margin-left: 1em">贡师泰字泰甫宣城人泰定四年释褐出身至正中自</span>  
<span style="margin-left: 2em">礼部尚书为平江路总管甫视事而淮兵至守将莫</span>  
<span style="margin-left: 2em">能支师泰率义兵出战不敌怀印走松往来江上尝</span>  
<span style="margin-left: 2em">寓静安招提赋八咏诗其沪渎垒一章忠愤之气犹</span>  
<span style="margin-left: 2em">可想见云</span>  
<span style="margin-left: 1em">杨瑀字元诚钱唐人性警敏博学长身紫髯如画天历</span>  
<span style="margin-left: 2em">间召见奎章阁命篆洪禧明仁二玺文称旨署广成</span>  
<span style="margin-left: 2em">局副使擢典簿中瑞司与密谋草诏黜奸臣伯颜超</span>  
<span style="margin-left: 2em">授奉议大夫太史院判寻同签院事江南盗起改建</span>  
<span style="margin-left: 2em">德路总管得谢来松居鹤沙镇追论平贼功升浙东</span>  
<span style="margin-left: 2em">宣慰不赴遂老于鹤沙初瑀在太史时上从容询其</span>  
<span style="margin-left: 2em">乡土对以西湖葛岭之胜御书山居二字赐之因自</span>  
<span style="margin-left: 2em">号山居所著有山居新话卒返葬葛岭云</span>  
<span style="margin-left: 1em">王逢字原吉江阴人才气俊爽弱冠有美名台臣荐之</span>  
<span style="margin-left: 2em">以疾固辞大府交辟皆不就会世乱客游吴中筑室</span>  
<span style="margin-left: 2em">青龙江上以吟咏自娱初逢祖母徐夫人尝手植双</span>  
<span style="margin-left: 2em">梧于故里之横河逢追思之因名所寓曰梧溪精舍</span>  
<span style="margin-left: 2em">所著曰梧溪集鄱昜周伯琦谓其为天随玄真子之</span>  
<span style="margin-left: 2em">流云</span>  
<span style="margin-left: 1em">黄公望字子久号一峰又号大痴莆田巨族一云本常</span>  
<span style="margin-left: 2em">熟陆神童弟出继永嘉黄氏黄父年已九十始得之</span>  
<span style="margin-left: 2em">曰黄公望子久矣因而名字焉性聪敏博学多才自</span>  
<span style="margin-left: 2em">经史百氏九流之术无不习而通之补浙省掾忤权</span>  
<span style="margin-left: 2em">豪弃去黄冠野服往来三吴间开三教堂于苏之文</span>  
<span style="margin-left: 2em">德桥至松寓柳家巷后隐杭之筲箕泉已而归富春</span>  
<span style="margin-left: 2em">年八十六而终公望善画山水初师董源巨然后稍</span>  
<span style="margin-left: 2em">变其法自成一家所著写山水诀至今多宗之与曹</span>  
<span style="margin-left: 2em">知白最善多留小蒸今此地有精九章筭术者葢得</span>  
<span style="margin-left: 2em">其传也<sub class="note-yuan">戴表元画像赞身有百世之忧家无儋石之乐葢其达似晋宋酒徒侠似燕赵劒客至于风雨寒门呻吟磐礴欲援笔而著书又将为齐鲁之学也</sub></span>  
<span style="margin-left: 1em">孙华孙字元实永嘉人寓居华亭孝友文雅善方脉为</span>  
<span style="margin-left: 2em">医学教授自幼得诗名年十七尝赋树谖堂诗云手</span>  
<span style="margin-left: 2em">植忘忧慰母颜每怜寸草报春难谁家人在闲庭院</span>  
<span style="margin-left: 2em">却与儿孙种牡丹乡先生卫山斋亟称赏曰诗意涵</span>  
<span style="margin-left: 2em">蓄有讽有刺率为大篇不可及也子孙遂为邑人</span>  
<span style="margin-left: 1em">吕克勤字勉夫东莱人申国正献公十二世孙也性豪</span>  
<span style="margin-left: 2em">迈不覊学问该博能文章以医名世游松江与邵桂</span>  
<span style="margin-left: 2em">子为文字交子绍闻孙文虎</span>  
<span style="margin-left: 1em">刘世贤字希孟东光人宋丞相忠肃公挚九世孙朔斋</span>  
<span style="margin-left: 2em">中书震孙之曾孙也忠肃善琴子孙世其学其后徙</span>  
<span style="margin-left: 2em">湖州至世贤遂以琴名浙右为人端重持论正大虞</span>  
<span style="margin-left: 2em">文靖公集尝赠以文游松江与曹知白善至正癸巳</span>  
<span style="margin-left: 2em">卒小蒸归葬湖州子孙遂家于松世称善琴而曰鸿</span>  
<span style="margin-left: 2em">者名尤著</span>  
<span style="margin-left: 1em">谢应芳字子兰毗陵人兵乱南迁居吴之葑门转娄江</span>  
<span style="margin-left: 2em">渡吴松寓筿泾年逾八十归老其乡之横山平生博</span>  
<span style="margin-left: 2em">雅好古在乡郡尝请复邹忠公祠寓吴又请复顾元</span>  
<span style="margin-left: 2em">公祠墓所著述有思贤录辩惑编诗有龟巢摘稿昆</span>  
<span style="margin-left: 2em">山卢熊称其在忧患颠沛之中无蹙迫愤懑之辞云</span>  
<span style="margin-left: 1em">杨乘字文载济南滨州人少负气博涉经史由参谋府</span>  
<span style="margin-left: 2em">掾累官监察御史迁浙省员外郎至正壬辰杭州陷</span>  
<span style="margin-left: 2em">非罪被黜依青龙章元泽以居丙申松江陷或传张</span>  
<span style="margin-left: 2em">氏将起公笑曰吾岂事二姓使果至乘知不免以家</span>  
<span style="margin-left: 2em">事属章具礼享先祠毕设饮起行后圃中顾西日晴</span>  
<span style="margin-left: 2em">好慨然曰晚节如是足矣诲其子治畦处置家事如</span>  
<span style="margin-left: 2em">平日夜分就寝遂自缢遗书言死生如昼夜不足介</span>  
<span style="margin-left: 2em">意且以得全臣节为快云乘死二年台臣白其前后</span>  
<span style="margin-left: 2em">事赐谥赠官录其子卣山东宣慰司都事卓清忠书</span>  
<span style="margin-left: 2em">院山长</span>  
<span style="margin-left: 1em">张宪字思廉会稽山阴人家玉笥山自号玉笥生少力</span>  
<span style="margin-left: 2em">学有志既壮负才不覊薄游四方慕鲁连子为人不</span>  
<span style="margin-left: 2em">治产业年四十犹不娶方承平时走京师谒贵人谈</span>  
<span style="margin-left: 2em">天下事众谓之狂及淮西兵起宪首抗大议复不报</span>  
<span style="margin-left: 2em">去入富春山为方外游一旦升高望远若有所覩退</span>  
<span style="margin-left: 2em">谓所亲曰吾亟去汝辈亦慎毋居此众不信俄宼至</span>  
<span style="margin-left: 2em">兵死者五百家孙作大雅谓其闲静寡默在稠人中</span>  
<span style="margin-left: 2em">或被推堕不较及遇事酬酢论兵说劒天下一豪健</span>  
<span style="margin-left: 2em">辩士与缙绅辈为文章谈王道从容礼法虽老儒先</span>  
<span style="margin-left: 2em">生避之尝学于杨廉夫往来郡中最久湖山名迹多</span>  
<span style="margin-left: 2em">见之诗云</span>  
<span style="margin-left: 1em">马麐字公振太仓人元季避兵于郡南园池亭榭幽閴</span>  
<span style="margin-left: 2em">自娱屏绝世虑日诵经史为人不事修饰乐与贤士</span>  
<span style="margin-left: 2em">大夫交杨廉夫深器重之长于诗歌有醉渔草堂二</span>  
<span style="margin-left: 2em">集</span>  
<span style="margin-left: 1em">洪恕字主敬金华人避兵华亭性孝尚气节能诗善行</span>  
<span style="margin-left: 2em">草书以讲授终</span>  
<span style="margin-left: 1em">火鲁忽达汉名鲁得之西域康里人平章冀国公保八</span>  
<span style="margin-left: 2em">子也性重厚安贫好学弱冠为馆甥于小蒸曹氏挈</span>  
<span style="margin-left: 2em">家入燕中乙亥大都乡试以父荫授晋宁治中改监</span>  
<span style="margin-left: 2em">长兴州秩满仍居小蒸历漕运万户浙东元帅入为</span>  
<span style="margin-left: 2em">利用监大卿以卒子企贤由直省舍人仕至吏部尚</span>  
<span style="margin-left: 2em">书</span>  
<span style="margin-left: 1em">迈里古思汉名吴善卿西夏人侨居郡中至正甲午登</span>  
<span style="margin-left: 2em">进士授绍兴路录事司达鲁花赤抚字周至民爱之</span>  
<span style="margin-left: 2em">如父母杭州之克复也左丞杨完者统洞苗恣横劫</span>  
<span style="margin-left: 2em">掠迈里怒叱吏兵歼之苗尽死江南置台于越檄迈</span>  
<span style="margin-left: 2em">里督义兵招果毅军分守要害永康宼起据县迈里</span>  
<span style="margin-left: 2em">谈笑复之除廉访司知事迁建康道经历除行枢密</span>  
<span style="margin-left: 2em">院判官时御史大夫拜住哥统台军三千纪律不严</span>  
<span style="margin-left: 2em">民罹其害迈里辄抑之又不为拜礼或谏之曰吾知</span>  
<span style="margin-left: 2em">上有君下有民耳安问其他拜闻其语衔之会与方</span>  
<span style="margin-left: 2em">国珍部兵战不利驰归遂遇害于拜第民麻跣恸哭</span>  
<span style="margin-left: 2em">从之者万余人事闻赠中大夫佥江浙枢密院事追</span>  
<span style="margin-left: 2em">封西夏侯谥忠勇</span>  
<span style="margin-left: 1em">秦裕伯字景容大名人从父仕元都就学胄监登第累</span>  
<span style="margin-left: 2em">官福建行省郎中会世乱弃官寓扬州避地松之上</span>  
<span style="margin-left: 2em">海以养母时张士诚据姑苏遣人招之拒不纳吴元</span>  
<span style="margin-left: 2em">年</span>  
<span style="margin-left: 1em">上命中书檄下松江起之裕伯对使者曰裕伯受元爵</span>  
<span style="margin-left: 2em">禄二十余年背之是不忠也母丧不终忘哀而出是</span>  
<span style="margin-left: 2em">不孝也不孝不忠之人何益于人国乃上书于中书</span>  
<span style="margin-left: 2em">固辞洪武元年省臣复檄起之称疾</span>  
<span style="margin-left: 1em">上乃手书谕曰海滨之民好鬭裕伯智谋之士而居此</span>  
<span style="margin-left: 2em">地苟坚守不起恐有后悔裕伯拜书遂入　朝裕伯</span>  
<span style="margin-left: 2em">博辩善为辞说</span>  
<span style="margin-left: 1em">上欲命以官屡以故辞后以为待制寻出知陇州</span>  
<span style="margin-left: 1em">国朝陶宗仪字九成其先由闽之长溪徙永嘉陶山再</span>  
<span style="margin-left: 2em">徙台之黄岩始祖泰和宋皇祐里溪都巡检复徙湫</span>
