## 正德松江府志卷之十八　寺观上

<span style="margin-left: 4em">寺观上</span>  
<span style="margin-left: 3em">观楼台半佛宫之诗云间塔庙之盛久矣稽之近</span>  
<span style="margin-left: 3em">志殆有甚焉黄冠少衰栋宇亦且相望司马公云</span>  
<span style="margin-left: 3em">居位者虽不能禁忍助之乎</span>  
<span style="margin-left: 1em">华亭丛林<sub class="note-yuan">称丛林者皆洪武二十四年清理佛教时归并诸小庵院而成其归并三十五年俱令复旧有反盛于丛林者今仍附各丛林下以存旧制道教倣此</sub></span>  
<span style="margin-left: 1em">南禅寺在府学之东宋崇宁中张头陀卜筑于此凿地</span>  
<span style="margin-left: 2em">得住世罗汉像邑人异之遂为施水庵头陀后为僧</span>  
<span style="margin-left: 2em">名普愿请额于朝绍兴二十九年赐名演教禅院后</span>  
<span style="margin-left: 2em">改今额元大德间中书马左丞榜其门曰南山胜地</span>  
<span style="margin-left: 2em">中有绿筠楼雷音堂</span>  
<span style="margin-left: 1em">国朝为在城诸禅之冠僧纲司治焉归并寺一庵二<sub class="note-yuan">南山胜地记佛氏说大因缘举世间事无非前定出世间人无不前知事有远在数百年后而言验于数百年前得道者慧眼一照于未来世或兴或废若蓍蔡于前而符契于后人亦以前知者悟其前定者焉松江府南禅寺为在城诸禅冠唐元和间船子和尚过而合爪曰此地形势最胜愿来兴福时未省其语至宋崇宁有头陀张氏即其地而庐焉掘井得罗汉像十有六颇异之后以掩骼赏不受换牒为僧实名普愿而船子愿来兴福之言始验愿虽草创数椽岁久若废祠败驿岁在绍兴得俊公而复兴焉请于朝为寺南渡百余年寺门终未光显天兵下江南逾三十年住山如寄驿倥偬不暇顾宝公来住此山撙浮苴漏仅仅完备每出人是门徘徊四顾西则儒老二宫颉颃争先寺歛然退后若有物压其首东则墙垣塞路斗绝筑底若有物障其目南则断流如线过桥民居栉比隙不通轨若有物横其臆思欲挈山门而东之规模定在胸中凡三四年始克就绪旧有大石龟蹒跚水涘辇致其左背负崇墉若鼇戴山而前抃也入门不数步东南筑小土山植松其上若虎伏林而旁衞也兑水来其西巽风避其南缭以矮墙夹以佳植委蛇曲折渐入禅境见者生懽喜心咸谓布置之巧独未有颜其门者寳公辄以南山福地四字乞书于中书右丞马公公曰洞天福地乃道家事非禅衲本面采赐钩画易以胜地二字而船子此地最胜之言又验夫地不自胜因人而胜向也行即面墙入即窥室门外曾不容数骑一转移间由南而东举目即见山门由门而入林影阴翳若行诘曲山径间才见有寺地虽胜因人而益胜固无怪也独怪船子和尚距今四百余年前后如此其验安知昔之愿今之宝非船子身后身邪大德改元夷则月望日正奉大夫翰林学士承旨阎复记承直郎前泽州知州兼管本州诸军奥鲁除松江府判官傅大有书篆</sub></span>  
<span style="margin-left: 2em">坐化积庆禅寺本名坐化庵府东南龙门寺相望元</span>  
<span style="margin-left: 2em">至正辛巳邑人陈源为庆禅师舍宅建庆坐化肉身</span>  
<span style="margin-left: 2em">在焉庵因以名归并后佛宇犹存逮正统丁卯僧惠</span>  
<span style="margin-left: 2em">明请今额其后福昭惠日惠义皆相继营建由是壮</span>  
<span style="margin-left: 2em">观比名刹焉</span>  
<span style="margin-left: 2em">四十八愿庵府南六十里元僧宝灯山建</span>  
<span style="margin-left: 2em">仁寿庵府南六十里元僧修建</span>  
<span style="margin-left: 1em">北禅寺在府东北城内宋绍兴间僧法宁建宁先住沂</span>  
<span style="margin-left: 2em">州马𡺸山浄居寺航海至青龙有章氏者迎止于此</span>  
<span style="margin-left: 2em">发地得古碑云大唐禅寺又得金铜天王像因建寺</span>  
<span style="margin-left: 2em">焉县令柳约请名浄居又名马𡺸寺元毁洪武中僧</span>  
<span style="margin-left: 2em">慧海重建领归并院三</span>  
<span style="margin-left: 2em">本一院妙明桥西北旧北道堂也元至元末赵道渊</span>  
<span style="margin-left: 2em">为僧易今名<sub class="note-yuan">院记吾尝爱金僊氏之徒虚己而能让去争而能群人有善言行即尊信悦服若受业于其门者无功缌袒免之戚而相胶结若父子昆弟之慈顺友爱出于天性者无他亦本于能让能群之道而已厥后有嫌忌之隙生斗争之敌立无异于市人之合而离者则其教亦衰矣本一庵者宋乾道中邑人沈氏之所建也岁久业废我朝至元间昌公月麓复其见侵之田撤去旧屋而一新之又虑后之嗣者或相逾越也定为甲乙使主庵事延祐昌寂其徒存礼惧己弗克肩事求其才且贤者主焉时善应庵空林禅师果公行业峻茂有声丛林间礼延置之推居己上事无巨细悉归焉果公度弟子曰浄开浄誉善实等凡十人乃命开以师事己者视礼益相亲睦无间言吾所谓金僊之徒能让能群者不于兹见耶四方叅扣之士闻果公之贤縢屦而至者踵相接也顾旧屋褊隘无以馆学者由是拓易旧制贵富家以钱施者惟恐后乃中为殿立大雄氏像其旁若僧堂筹室山门圆通玄武之殿燕居庖湢之屋靡不完具是虽果公道化之所致然亦誉实佽相之力乃题曰本一院果寂开以次主席谦让不自任一事之微必誉实同决焉又可谓始终能让能群者矣开之后誉继之让实实介予方外友天目首座明公征文以记颠末予来松值兵燹之后求梵刹于城内外不啻百余区匪夷为焦土则穿漏为四虚之亭而独本一者岿然于瓦砾塲中椽瓦不动人以为祖师愿力所致而亦实之材干山门柱石也予信人言之不妄而又重明之请遂为书诸石复喻其徒曰农之为田也其始也垦治之播种之继以薅芸之灌溉之则宜其田愈腴而愈大有成利之获焉今昌之垦治播种亦劳矣果之薅芸灌溉又勤矣腴之大之而收秋获之功不在实乎后之人享有成利者宜思其所由来哉果字空林云间人尝叅天目中峰本禅师机锋相直遂超玄窟实字性空云间人通内外典及世缔人称兰奢云至正十一年夏六月杨维祯记</sub></span>  
<span style="margin-left: 2em">青喦塔院在三十八保元至元二年僧辉建</span>  
<span style="margin-left: 2em">修学院府西北元至元间僧尚建</span>  
<span style="margin-left: 1em">普照讲寺在华亭县治之西唐乾元中僧慧旻建初名</span>  
<span style="margin-left: 2em">大明宋大中祥符元年改今额寺有陆将军祠世传</span>  
<span style="margin-left: 2em">地本陆氏园亭因以祠之嘉禾诗文谓陆机舍宅为</span>  
<span style="margin-left: 2em">寺旧志力辩其妄谓机死于晋而寺建于唐岂得为</span>  
<span style="margin-left: 2em">机舍宅其说当矣然谓机宅不在邑中而断以寺非</span>  
<span style="margin-left: 2em">其地则恐未然寺之侧近多陆氏遗迹如八角井黄</span>  
<span style="margin-left: 2em">耳冢旧志皆云在机宅傍而复云云何也寺旧规弘</span>  
<span style="margin-left: 2em">伟元季毁于兵僧道敏重建佛殿</span>  
<span style="margin-left: 1em">国朝住僧名偁大珹居敬等相继兴复榜其门曰都祝</span>  
<span style="margin-left: 1em">圣道塲每岁正旦冬至</span>  
<span style="margin-left: 1em">圣节习仪于此内有海月堂堂东有秀朵轩涵晖室西</span>  
<span style="margin-left: 2em">有香水海归并寺一庵院二<sub class="note-yuan">重建西方殿记华亭具体兰若莫如普照其间庄严壮丽莫如无量寿殿殿之殊特莫如孟春之月会千万人系惟心自性之念事理冥契人境两忘浙江以西邈然寡俦复道横陈以翼邃严曲尽其巧以尽巧故反见窒隘莲座高广仅觌其趾眉毫宛转鲜克仿佛遂彻其旧别敞修楹前荣轩豁八窻玲珑佛与四象咸得相见如明镜中见其面像又若帝网交光相罗如击其蒙如发其蔀费倍万计谈笑而集真懿大师忠信崇教大师祖祥善巧诱倡徒属各致其力作于嘉定九年正月落成于十二年之四月北磵不起于座而告之曰乡也窒隘而不见佛不见之见初不加损今无窒隘而得见佛所见之见初不加益见见之时虽佛亦物见不能及非物非佛或曰佛固自若也吾见固自若也有见不见也何故则曰罔克在念狂圣由是即见离见徒问傍睨书以授真懿使喻入社之浄信者俾知窒隘宏敞未始二焉北磵记千僧堂记堂容万指尽于某年之寇亦既久矣远人伟其名务先睹为快今也漠然人以其名在而实亡乃与柳柳州铁炉步志同按崇教大师祖祥寺之桢干愧此缺典聚旅而谋曰有志者勇有为乐施者不吝啬吾僧于此逾四纪凡所兴建根椽片瓦罔不与舍我事罔集且吾生平不妄受受则辨礼义而不及私信稍孚将有以相吾志誓鼎新以终吾老市材僦工正信向答输货惟恐后权舆于嘉定庚寅春仲轮奂于辛卯季秋越明年而崇教寂又明年雪脊界天璇题闯簷翼翼前荣设座备物靡所不具嗣孙智渊能继其志而复其旧成不愆期美不逾制惟壮惟固勿事侈靡窻牖洞启床榻衡直匪雕匪琢随宜加饰华鲸吸月巨镛横撞鲐背在前犀颅茁霜旃檀无杂薝卜有序本无位次如法而住十利五观敢忘讲明以福君亲以保兆民谓吾素餐吾餐罔素于昌明时密赞潜辅北磵记藏殿记佛之迹不可得而见所留者言佛之言不可得而闻所存者经自西方教入中国有曰十二部有曰六百五十七卷又有曰五千四十八卷者盖如来四十九年之所说诸菩萨大弟子之所记西天二十八祖此土六祖之所传与古今高僧贤达之所著举而集之愈久愈伙非俱舍何以置梵云俱舍此言藏至博大士作天宫地轮以盛经典令诸有情推转乃谓之轮藏藏之不可废也以此松江普照寺据通阓俯涟漪为群刹冠淳祐间毁于火若厨若廊若大殿由宋季及国朝皆次第崇修稍还旧观惟藏殿一瓦砾塲耳梵修主僧希白居刹之四年慨然有兴复志会郡富室王国英及诸大檀那来助始至元十九年之三月迄三十一年之十一月越十有三载而藏殿成共费钱一十五万殿二十楹藏崇五丈广半之金碧照耀髹漆精明上有飞僊桥中有栖经函傍有铁围山下有香水海每巨植砰轰人运机而神效力如车之旋如风之行如雷霆之惊壮丽杰特虽百岁老人以为希有明年白状始末求予文予曰初经之未广也或以金或以银或以血写者常多及经之既广也印于福印于杭印于苏读者益少今五千四百八十卷贮以五百四十八函而总为一藏以一藏而载之以轮岂徒张皇诡异以夸一方耶抑将见学者朝讲夕诵内有所自得耶昔德山周禅师精究律藏尝赞金刚般若时谓之周金刚温州安禅师得法于天台首阅楞严了义时谓之安楞严二师才了一经已足超诣矧博通三藏者乎如白之裒集经律论诸书包涵万有觉悟群迷使人随取随足其用心固勤矣虽然凡开是藏阅是经曾知夫经自佛口中来藏从人心上转天宫有此法轮人心亦有此法轮龙宫有此海藏人心亦有此海藏白合掌作礼曰闻公之说是人心藏心同一悟转乃藏之无尽者也愿勒石垂不朽故书以授是年重阳日翰林侍讲学士除朝列大夫松江府知府张之翰记集贤直学士除朝列大夫同知济南路总管府事兼诸军奥鲁赵孟𫖯书篆释迦殿记松江普照寺陆士衡别业也自孙氏归晋兄弟入洛以文人膺事任威声权势震动当时倚伏相寻曾未瞬息已有华亭鹤唳之叹而其台榭化为像设研席化为梵呗乃至今存何欤寺北坐九峰层峦叠嶂攅青拥翠相为蔽亏阴阳家者流谓风气藏聚可安千众盖特于佛僧为宜也唐乾元时本号大明寺僧良慧尝剏释迦如来殿逮宋祥符间改赐今额道者严善誓僧宗幸真歇凡三度重建淳祐戊申厄于祝融里人钱武翼仰之首议兴造其事未竟子大信竭力继之使张彦中掌其卖僧祖镜等佐其役威淳甲戌僧慧思与武翼旧念不可废前人功亟劝率捐施以助殿始成众请行超典殿毕涂塈而营像设于是慧辨贤慧悟秀以白镇守沙侯欣然致从吏且厚施之超益倾赀化缘不惮劳费久之而就万瓦鸳浮重檐翼跂加以藻绘金碧交辉中设释迦像若左若右分列八位备极庄严而三世如来圆通大士应真罗汉诸天人之相亦次第而成至于琉璃无尽灯瓜华诸供具莫不完好每岁州侯率其僚属于此建道塲申祝赞而祷水旱禳风灾者亦皆至焉夫成之难则其传之也必久是役也再见丁未甲子复周盖非一手足之力而超成其终功尤多可谓难矣超既寂其孙子闻职是熏修实来霅求文以记曰是固所以久传而不废也予闻万形皆有弊惟理独不朽而佛氏亦曰一切诸法皆有破坏唯有法身常住不灭虽与吾说若不尽同然所谓法身亘古今弥宇宙到处充满亦无杂坏岂拘于形而外于理哉区区言语文字如浮云如空花乍起乍灭了无根蒂反欲取其常住不灭者托文以传闻也果以为能久传不废邪盍亦归求诸己而已乃为之赞曰维昔普照王本自法身出光明摄方寸虚空常独耀尽三千大千无量河沙界皆佛慧照中夫是之谓普众生宿业重展转堕迷误愿佛垂慈悯与除诸障碍譬如摩尼珠烱烱照浊水一作是念己业去障自空而我初不觉心目划开朗稽首释迦尊为我证明之至大元年三月既望前朝奉大夫大理少卿牟𪩘撰集贤直学士赵孟𫖯书江浙等处行中书省右丞廉密知儿海牙篆额重建千僧堂记三代盛时礼乐制度学校修设明备外物莫干其藩厥后寖衰以微东汉明帝时竺法兰摩腾首负四十二章经至白马寺符丈六金身之梦上所崇信趋者澜倒诸儒先生徒持空言以抗曾莫之止日蔓月滋唐会昌五年不啻二十七万余僧宋天禧以后不啻三十九万余僧何其盛也一盛一衰相为消长势使之然昔伊川子程子尝游某寺僧堂见群僧方食叹曰三代威仪尽在是矣彼其拜则膜拜衣则条衣非可比而同之三代程子之言顾若是何欤礼失求之野或者观其会而得其意欤方其于于而来脱履而升临席而坐不语而食蔬食菜羹必祭祭必齐如雍容可观古意犹有存焉者故程子有慨于衷不觉舍然而叹欤礼仪三百威仪三千其目繁多要不必尽同亦取其意之存乎古者而已他可类推也特未知佛所谓三千威仪八万细行者同乎否乎耳维松江普照寺有千僧堂自唐乾元宋淳祐两戊申回禄之厄无复旧观崇教大师祖祥之所建潼川北磵居简之所记者又悉为瓦砾之塲岁在丙子万户沙侯来镇是邑与慧悟兴教大师昙秀相与倡帅首剏钟楼库堂西庑而千僧堂未遑暇也又四年己卯里人赵架阁施所居堂为之因陋就简意未称临化之际专以是事付之后人于是其徒智受铢积寸累且承檀施癸卯于旧址重建是堂宽明周密风日不到设坐备物使僧众得以如法而住繙诵经帙下自己工夫出则听说法申祝赞功德无量因来求文以记逆旅之人当去未去视彼临化洒脱明了办一事大者为何如且彊立文字以传久远海会丛林有具眼者不自献笑乎重说偈言曰盛哉海会千僧之堂是为普照选佛之塲万中选千千中选百于百之中又选其一愈选愈少其义伊何人以为少我犹曰多有如此堂愿力所造窻几靓深床座完好夏有疏簟冬有重席摄衣而起振履而出千僧齐唱一口百声千口万声清彻朗明有大导师默然宴坐忽狮子吼唤醒惽堕闻者震起得大警悟须臾之顷万化咸具凡诸佛子皆得度己稽首普照朝夕弹指至大元年十二月十六日牟𪩘撰奉训大夫太子司经张埜书翰林院待制中宪大夫松江府兼劝农事贾汝舟篆额千佛水陆院记普照寺自唐乾元元年至于宋数百年矣屡兴屡废淳祐戊申迄今又六十年寺之耆宿分任其责山门两庑佛殿次第兴建千佛水陆院地广费巨众请属之惠慈大师志新既领主席于是慨然捐衣盂营檀施寺僧元德为之分干徒弟浄恩浄心闻之为之叶赞大作新之始于戊戌继奉护持之旨其事尤严越丁未乃来求记予尝记释迦殿矣固辞弗克则复之曰善必由积累而后成佛经乃曰不于一佛二佛三四五佛而种善根已于百千万佛而种善根何也夫计亿兆者本于一至寡乃所以为至众也且一者何心是也心以方寸而总万善如木之有根生意涵活千条万干耸壑昂霄皆自此始水陆院之义亦然昔梁武帝尝制水陆仪文三年而成几三千卷其后羞设者以十六位各分八位而为上下召请即通三时法虽简施则博其上八位慈容端相为人敬慕下八位殊形诡状为人恐怖有善有恶有劝有戒大率以忏悔为先有能用意猛烈一悔之间诸恶荡除众善咸具曷尝不本于一哉今惠慈于此二役位置曲当山门两廊壁涌天台圣域五百僊流阁上设西方三圣铜铸千佛阁下设千叶卢舍那佛普贤文殊二大士左右壁涌水陆冥阳三界像间饰以金采眩耀众目辉暎芳池而其池面菡萏敷披飞槛相属生香不断疑从浄土移来此地诸佛子于焉修行莫不超然得大自在皆惠慈十年之间苦心劳形所成就亦其胸中自来积善如木有根故一念所发有此殊胜非徒极庄严事观美也盖欲使生者蠲其罪业日增福祐死者拔其幽滞免堕轮回而已世安有一念之顷不能感动鬼神而能普济含灵功德无量徧周沙界乎惠慈得之矣铭曰我观人心内有善元无恶颠迷彼弗知往往路头错尔时诸天人一切诸菩萨忽现慈善相与众共说法法皆由心造罪亦由心起心空罪亦空各已得度己众生地狱众六道阿修罗随佛登天堂只在一刹那至大二年十月既望牟𪩘撰赵孟𫖯书并篆重修寺记松江为海内名区普照实云间大刹规模宏远有足观瞻皇明混一以来选为祝釐之所恭遇圣节必预习仪冠带缙绅嵩呼于是伛偻提携观礼于是一其向善之心启其尊君之意所系盖甚重矣其地后峙九峰右潴三泖金山按其前沧海环其左阴阳者流谓其风气藏聚可容千众于佛为宜晋陆士衡首创别业未几入洛台榭化为像设抑其验欤自后寺之兴废每系乎人宣德五年住持久缺日渐颓圮僧官仁默庵启东白忧形于色咨诸徒侣咸以前住持上海南广福讲寺敬心渊为荐一闻其名莫不懽喜踊跃谓其必有力量大振山门既至即慨然曰寂灭虚无固当如是然而佛既有像像必有设使不庇风雨奚以像为吾果成佛作祖也固不必像矣未至乎是宁能免乎矧夫三教并存同沾帝力祝颂于此瞻仰于此使人皆知亲上之诚其有益于名教之大者不浅作而新之宜也由是昼积夜勤十有二载罄具衣钵十方人士乐助相成若大觉宝殿若海月法堂若山门若廊庑若绣朵轩若涵辉室巍然焕然郁乎相向非寺之得其人乎得其人则所以为名区之古刹而为祝釐之所也有托矣幸孰大焉落成之日大众懽喜莫不合十皈依叹未曾有而作偈曰卓锡名山修村善行一心如渊含弘止定大阐法门无穷无尽极力庄严有诚有敬暮鼓晨钟上祝明圣亿万斯年永膺天命下愿群生了明真性世世生生悟慈善证心渊闻是偈已作礼而退诸山耆旧请志诸石以告来者心渊讳居敬别号兰雪早于大报恩寺一雨翁会下职知賔后历杭州大集庆寺东源翁会
