## 正德松江府志卷之二十四　官跡下

<span style="margin-left: 4em">宦蹟下</span>  
<span style="margin-left: 1em">國朝祝挺字正夫番陽人洪武初知上海縣時海濱盜</span>  
<span style="margin-left: 2em">起縣民錢鶴臯因煽亂僞總兵姚姓者率衆逼縣治</span>  
<span style="margin-left: 2em">挺懷印走府謀克復聞府已陷乃仰天嘆曰縣我死</span>  
<span style="margin-left: 2em">所也效死弗去首惡者迫使見挺毅然曰汝吾編氓</span>  
<span style="margin-left: 2em">我爾縣長何總兵爲而迫我見邪吾有頭在勿復語</span>  
<span style="margin-left: 2em">盜知不可屈釋之乃密與前主簿鄭著王掎主簿李</span>  
<span style="margin-left: 2em">從吉等謀聚義兵追斬盜首二以獻于主帥或議以</span>  
<span style="margin-left: 2em">兵涉縣境民震懾不寧挺星馳詣帥曰苟降罰罰我</span>  
<span style="margin-left: 2em">如撫民民則定定矣帥猶欲治脅從者挺曰彼詿誤</span>  
<span style="margin-left: 2em">者何罪不則仍罪我帥壯其言而從之方是時他邑</span>  
<span style="margin-left: 2em">死傷相枕籍而上海獨晏然挺之力也初民有不利</span>  
<span style="margin-left: 2em">於挺者及事平皆惴恐挺一不問慰勞而遣之故人</span>  
<span style="margin-left: 2em">情大安不三日皆復業詳見活民碑</span>  
<span style="margin-left: 1em">陳□茶陵人<sub class="note-jiao">校：此處原書作墨丁他書皆不錄</sub></span>  
<span style="margin-left: 1em">高廟爲吳王時在左右性鯁正廷諍大事不以死懼</span>  
<span style="margin-left: 2em">朝章律令皆預參議紏正切劘重一代之制平居談</span>  
<span style="margin-left: 2em">仁履義務以聖賢之學致</span>  
<span style="margin-left: 1em">主堯舜時稱爲社稷臣洪武元年出知松江府未朞月</span>  
<span style="margin-left: 2em">政成遷山西參政<sub class="note-yuan">名見官署事出楊維禎序蘇志茶陵陳寧洪武初自中書出知府事恐即此人</sub></span>  
<span style="margin-left: 1em">李浩字師孟保定人歸附初同知府事均賦役平出納</span>  
<span style="margin-left: 2em">明黜陟慎興革嚴關津清獄訟時稱爲循吏未幾</span>  
<span style="margin-left: 2em">中使至　召置機近</span>  
<span style="margin-left: 1em">馮榮烏江人洪武初知華亭縣莅任甫三月海濱盜起</span>  
<span style="margin-left: 2em">染及華亭榮言於統兵者請罪渠魁而貸其良民之</span>  
<span style="margin-left: 2em">詿誤者統兵然之脱死者數萬口既而興學校勸農</span>  
<span style="margin-left: 2em">桑辯寃枉均繇役政教一新故老至今能道之</span>  
<span style="margin-left: 1em">蔣惠番昜人洪武十一年知華亭縣先是縣誣平民李</span>  
<span style="margin-left: 2em">秀三等三十人爲強盜惠察其無辜俾以更生仍密</span>  
<span style="margin-left: 2em">授方略獲真盜馬鬍等十八人正其罪他如毁淫祠</span>  
<span style="margin-left: 2em">以正人心去姦頑以植良善及民之惠實多焉</span>  
<span style="margin-left: 1em">胡儼字若思江西南昌人博極羣書天文地理律曆醫</span>  
<span style="margin-left: 2em">卜皆通其說洪武丁卯舉于鄉授華亭教諭以內艱</span>  
<span style="margin-left: 2em">去改授長垣縣上疏乞近便養親改饒之餘干自是</span>  
<span style="margin-left: 2em">著爲令以薦陞知桐城縣永樂初召試稱</span>  
<span style="margin-left: 2em">旨授翰林檢討尋陞侍讀直內閣明年春陞春坊諭</span>  
<span style="margin-left: 2em">德九月拜國子祭酒庚寅</span>  
<span style="margin-left: 1em">上北征命以祭酒兼侍講掌翰林院事輔</span>  
<span style="margin-left: 2em">皇太孫監國洪熙初以疾辭加　太子賓客致仕公</span>  
<span style="margin-left: 2em">在華亭時尚少而能以師道自任勸勉諸生講授每</span>  
<span style="margin-left: 2em">至夜分雖隆寒盛暑不廢宰桐城以愛民爲主凡可</span>  
<span style="margin-left: 2em">便民者以身任之民間積欠悉與　奏免邑中虎爲</span>  
<span style="margin-left: 2em">害禱于神虎遂滅迹嘗捕蝗道見饑病者命里胥扶</span>  
<span style="margin-left: 2em">掖就民舍給以藥食是夜大風雨得免暴露存活數</span>  
<span style="margin-left: 2em">百人在內閣間有　顧問必從容商度而後對及兼</span>  
<span style="margin-left: 2em">宫僚在講筵凡古今治亂得失必反復敷陳以圖裨</span>  
<span style="margin-left: 2em">益爲祭酒身率諸生以師道自重</span>  
<span style="margin-left: 1em">文廟亦禮之一時人材翕然從化時國子生有以故告</span>  
<span style="margin-left: 2em">歸者皆謫戍邊公爲言其情乃得免閒居二十餘年</span>  
<span style="margin-left: 2em">日與學者講求性理之學是非利害可否之間必審</span>  
<span style="margin-left: 2em">度以求至當惟恐貽患于人羣論中有不合即引退</span>  
<span style="margin-left: 2em">不與辯故所至能全交</span>  
<span style="margin-left: 1em">甄庸北京人洪武三十二年以户部主事來知府事醇</span>  
<span style="margin-left: 2em">謹嚴重以廉自防雖所得俸貲苟欲易一衣具一食</span>  
<span style="margin-left: 2em">必於他郡營之略不涉於境內嘗曰人非古人其避</span>  
<span style="margin-left: 2em">嫌疑不得不爾也事母至孝仕至工部尚書致仕</span>  
<span style="margin-left: 1em">杜鎰洪武末知上海縣其政以崇節儉黜華靡爲本率</span>  
<span style="margin-left: 2em">之以身故無敢犯者平生廉介自信遇事明果不怵</span>  
<span style="margin-left: 2em">勢利吏畏而民懷之</span>  
<span style="margin-left: 1em">夏原吉字維喆湖廣湘陰人母廖氏夢三閭大夫而生</span>  
<span style="margin-left: 2em">洪武庚午從鄉薦入太學授户部主事擢右侍郎充</span>  
<span style="margin-left: 2em">福建採訪使</span>  
<span style="margin-left: 1em">太宗即位進尚書時蘇松大水</span>  
<span style="margin-left: 2em">命公來治之首　奏罷蠧民妨政十餘事乃詢延故</span>  
<span style="margin-left: 2em">老究水之由晝夜經營雖盛暑不張蓋曰衆赤體曓</span>  
<span style="margin-left: 2em">日吾忍求涼哉以是人人效力於蘇浚白茆塘劉家</span>  
<span style="margin-left: 2em">河於松浚黃浦導淫水以歸于海水患乃息　奏發</span>  
<span style="margin-left: 2em">廩米三十餘萬石以賑饑民全活者衆有欲干澤於</span>  
<span style="margin-left: 1em">上者奏以水退淤肥宜召民佃耕以足國用原吉曰民</span>  
<span style="margin-left: 2em">疲極矣況重役乎即馳　奏車戽則徒勞民力栽種</span>  
<span style="margin-left: 2em">則已失時何益于國</span>  
<span style="margin-left: 1em">上悟事遂寢吳人懷之三年八月　召還掌部事</span>  
<span style="margin-left: 2em">車駕親征兼掌六部都察院大理寺事輔導</span>  
<span style="margin-left: 2em">皇太孫洪熙初進少保兼　太子少傅宣德初與少</span>  
<span style="margin-left: 2em">師蹇義少傅楊士奇楊榮等同心輔政爲國元臣五</span>  
<span style="margin-left: 2em">年春正月有星墜所居西南隅後二日卒贈特進光</span>  
<span style="margin-left: 2em">禄大夫太師謚忠靖原吉治水扁舟單車遍歷遐僻</span>  
<span style="margin-left: 2em">所至多有題詠至松寓超果寺嘗登一覽樓賦詩手</span>  
<span style="margin-left: 2em">迹猶存又嘗有踏車嘆等作至今父老皆稱夏尚書</span>  
<span style="margin-left: 2em">之治水云</span>  
<span style="margin-left: 1em">黃子威江西進賢人洪武末以儒士授長洲丞永樂初</span>  
<span style="margin-left: 2em">擢刑部員外郎二年出知府事公勤剛果不惑憸邪</span>  
<span style="margin-left: 2em">始至郡罹水患</span>  
<span style="margin-left: 2em">朝廷方遣使治之子威跋履鄉邑撫綏賑賚民藉以</span>  
<span style="margin-left: 2em">存活者甚衆三年政通人和上下信服以詿誤及丁</span>  
<span style="margin-left: 2em">母憂去民前後赴愬懇留者千餘人其後郡更三守</span>  
<span style="margin-left: 2em">而民念之猶一日</span>  
<span style="margin-left: 2em">朝廷知之俾復任操履如初甚得時譽</span>  
<span style="margin-left: 1em">魏驥字仲房浙江蕭山人永樂三年舉于鄉明年授松</span>  
<span style="margin-left: 2em">江府學訓導端重祇慎汲汲以成就人材爲事諸生</span>  
<span style="margin-left: 2em">在學居者候更盡必攜茶往視見有書聲者供茶一</span>  
<span style="margin-left: 2em">甌夜過半必攜粥以隨尚有誦書者供粥一盂如此</span>  
<span style="margin-left: 2em">者亦不數間一行之士子皆感激後顯宦甚衆滿九</span>  
<span style="margin-left: 2em">載諸生楊珙等詣</span>  
<span style="margin-left: 2em">闕請留時</span>  
<span style="margin-left: 1em">仁廟監國特　召驥與諸生偕還復教三年兩考江西</span>  
<span style="margin-left: 2em">鄉試十七年吏部尚書師逵薦陞南京太常寺博士</span>  
<span style="margin-left: 2em">宣德初陞行在考功員外郎轉南京太常少卿三考</span>  
<span style="margin-left: 2em">會試正統三年　召試行在吏部左侍郎踰年實授</span>  
<span style="margin-left: 2em">驥在官臞然若不勝衣而清正有聲雖內侍王振亦</span>  
<span style="margin-left: 2em">禮重之呼爲先生贄見惟帕一方振亦不較八年以</span>  
<span style="margin-left: 2em">老辭調禮部復辭乃調南京吏部戊辰乞致仕弗允</span>  
<span style="margin-left: 2em">陞本部尚書景泰改元年七十七請老至京閣老陳</span>  
<span style="margin-left: 2em">循公所取士也來見請曰先生雖位冢宰然未嘗立</span>  
<span style="margin-left: 2em">于朝願少待事在我輩而已驥不從退謂人曰渠將</span>  
<span style="margin-left: 2em">朝廷事爲一己事安得善終</span>  
<span style="margin-left: 1em">憲宗即位進階榮禄大夫家居二十年布袍糲食不別</span>  
<span style="margin-left: 2em">治生爲人以端厚祇慎簡約廉勤爲本好別白君子</span>  
<span style="margin-left: 2em">小人耄年事其兄教諭騏愈恭謹雅好吟咏有南齊</span>  
<span style="margin-left: 2em">集成化七年年九十八御史梁昉言公有德有壽請</span>  
<span style="margin-left: 2em">如漢故事優禮之八月遣行人存問賜羊酒有司月</span>  
<span style="margin-left: 2em">給米三石未至以其年九月己丑卒前夕公覺神思</span>  
<span style="margin-left: 2em">有異口占曰平生不作欺心事一點靈光直上行遺</span>  
<span style="margin-left: 2em">書付其子完勿動擾鄉里經營墳墓時有司以得請</span>  
<span style="margin-left: 2em">如例葬祭完以遺言辭從之蕭山知縣李鞏言驥行</span>  
<span style="margin-left: 2em">應諡法　賜諡曰文靖公德望著海內而得松人心</span>  
<span style="margin-left: 2em">尤深既老猶與松故舊細書往復無倦吾松人雖長</span>  
<span style="margin-left: 2em">子育孫猶曰吾祖吾父魏公門人也及卒皆爲詩往</span>  
<span style="margin-left: 2em">哭之仍祀于先賢祠</span>  
<span style="margin-left: 1em">韓陽字伯陽山陰人永樂十六年以鄉貢士授府學訓</span>  
<span style="margin-left: 2em">導操行清謹善教迪三載以外艱去再教丹陽薦爲</span>  
<span style="margin-left: 2em">監察御史陞湖廣按察司僉事專督學政轉江西按</span>  
<span style="margin-left: 2em">察副使廣東左布政使致仕</span>  
<span style="margin-left: 1em">侯端字敬莊盱眙人永樂乙酉銓授金山衛指揮同知</span>  
<span style="margin-left: 2em">性嚴毅剛勇以金山東南要害修城濠備器械練士</span>  
<span style="margin-left: 2em">卒爲守戰備戊戌倭宼登岸端與同衛事郤某分兵</span>  
<span style="margin-left: 2em">出戰郤出南門全軍皆覆賊遂由南門入城斷橋端</span>  
<span style="margin-left: 2em">孤軍在東門不得入乃引兵至西門橋亦斷仰天嘆</span>  
<span style="margin-left: 2em">曰城亡吾分當死安可偷生遂策馬一躍過河入西</span>  
<span style="margin-left: 2em">門衆不能繼與賊巷戰數十合身被箭如蝟轉戰至</span>  
<span style="margin-left: 2em">衛門賊驚曰好將軍也乃以所掠染家布横于街欲</span>  
<span style="margin-left: 2em">生致之端馳至以一劍挑布一劍截而斷之賊仆地</span>  
<span style="margin-left: 2em">而笑端由是得馳出東門次于楊家橋嗚鼓招散卒</span>  
<span style="margin-left: 2em">得百人令曰今潮退舟膠人持草一束與砲俱進至</span>  
<span style="margin-left: 2em">海灘焚賊船十餘艘賊不得歸遂大敗端有勇力府</span>  
<span style="margin-left: 2em">治石狻猊高四五尺端以一手挽之行十餘步策馬</span>  
<span style="margin-left: 2em">過坊門交手擁楣以足挾其馬而懸之騎射刀槊皆</span>  
<span style="margin-left: 2em">過人故能立功<sub class="note-yuan">端巷戰時一劍忽墜地所乘馬口銜以授端其異如此</sub></span>  
<span style="margin-left: 1em">潘俊字文英順天清河人以鄉貢入成均授本府通判</span>  
<span style="margin-left: 2em">明吏牘書筭清慎慈祥凡劇政理之有餘裕賦役有</span>  
<span style="margin-left: 2em">弗均者審實爲條之一郡歸心焉秩滿郡民擬乞留</span>  
<span style="margin-left: 2em">終惠卒于官士民莫不傷悼</span>  
<span style="margin-left: 1em">方佐四明人宣德初知上海縣明達世務清白愛民民</span>  
<span style="margin-left: 2em">亦愛之</span>  
<span style="margin-left: 1em">趙豫字定素保定安肅人洪武末以生員督賦守城永</span>  
<span style="margin-left: 2em">樂丁亥授泌陽縣主簿未上擢兵部主事陞員外郎</span>  
<span style="margin-left: 2em">丁內艱起復洪熙初陞郎中宣德庚戌奉</span>  
<span style="margin-left: 2em">敕知松江府時戍兵驕甚豫擇其甚者杖而配之邊</span>  
<span style="margin-left: 2em">衆遂帖服於是一意撫循與民休息困窮耄稚至者</span>  
<span style="margin-left: 2em">咸得盡其情擇名家子謹良者爲吏訓以禮法不威</span>  
<span style="margin-left: 2em">而嚴下亦不忍欺寡慾絶游燕母誦范文正先憂後</span>  
<span style="margin-left: 2em">樂之言曰此吾輩所當法也以吳俗尚琴奕喜玩好</span>
