## 松江府志卷之二十四

<span style="margin-left: 3em">宦蹟下</span>  
國朝祝挺字正夫番陽人洪武初知上海縣時海濱盜起縣民錢鶴臯因煽亂僞總兵姚姓者率衆逼縣治挺懷印走府謀克復聞府已陷乃仰天嘆曰縣我死所也效死弗去首惡者迫使見挺毅然曰汝吾編氓我爾縣長何總兵爲而迫我見邪吾有頭在勿復語盜知不可屈釋之乃密與前主簿鄭著王掎主簿李從吉等謀聚義兵追斬盜首二以獻于主帥或議以兵涉縣境民震懾不寧挺星馳詣帥曰苟降罰罰我如撫民民則定定矣帥猶欲治脅從者挺曰彼詿誤者何罪不則仍罪我帥壯其言而從之方是時他邑死傷相枕籍而上海獨晏然挺之力也初民有不利於挺者及事平皆惴恐挺一不問慰勞而遣之故人情大安不三日皆復業詳見活民碑

高廟爲吳王時在左右性鯁正廷諍大事不以死懼  
<span style="margin-left: 1em">朝章律令皆預參議紏正切劘重一代之制平居談仁履義務以聖賢之學致</span>  
主堯舜時稱爲社稷臣洪武元年出知松江府未朞月政成遷山西參政<sub class="note-yuan">名見官署事出楊維禎序蘇志茶陵陳寧洪武初自中書出知府事恐即此人</sub>  
李浩字師孟保定人歸附初同知府事均賦役平出納  
<span style="margin-left: 1em">明黜陟慎興革嚴關津清獄訟時稱爲循吏未幾　中使至　召置機近</span>  
馮榮烏江人洪武初知華亭縣莅任甫三月海濱盜起染及華亭榮言於統兵者請罪渠魁而貸其良民之詿誤者統兵然之脱死者數萬口既而興學校勸農桑辯寃枉均繇役政教一新故老至今能道之  
蔣惠番昜人洪武十一年知華亭縣先是縣誣平民李秀三等三十人爲強盜惠察其無辜俾以更生仍密授方略獲真盜馬鬍等十八人正其罪他如毁淫祠以正人心去姦頑以植良善及民之惠實多焉  
胡儼字若思江西南昌人博極羣書天文地理律曆醫卜皆通其說洪武丁卯舉于鄉授華亭教諭以內艱去改授長垣縣上疏乞近便養親改饒之餘干自是著爲令以薦陞知桐城縣永樂初召試稱  
<span style="margin-left: 1em">旨授翰林檢討尋陞侍讀直內閣明年春陞春坊諭德九月拜國子祭酒庚寅</span>  
上北征命以祭酒兼侍講掌翰林院事輔  
<span style="margin-left: 1em">皇太孫監國洪熙初以疾辭加　太子賓客致仕公在華亭時尚少而能以師道自任勸勉諸生講授每至夜分雖隆寒盛暑不廢宰桐城以愛民爲主凡可便民者以身任之民間積欠悉與　奏免邑中虎爲害禱于神虎遂滅迹嘗捕蝗道見饑病者命里胥扶掖就民舍給以藥食是夜大風雨得免暴露存活數百人在內閣間有　顧問必從容商度而後對及兼宫僚在講筵凡古今治亂得失必反復敷陳以圖裨益爲祭酒身率諸生以師道自重</span>  
文廟亦禮之一時人材翕然從化時國子生有以故告歸者皆謫戍邊公爲言其情乃得免閒居二十餘年日與學者講求性理之學是非利害可否之間必審度以求至當惟恐貽患于人羣論中有不合即引退不與辯故所至能全交  
甄庸北京人洪武三十二年以户部主事來知府事醇謹嚴重以廉自防雖所得俸貲苟欲易一衣具一食必於他郡營之略不涉於境內嘗曰人非古人其避嫌疑不得不爾也事母至孝仕至工部尚書致仕  
杜鎰洪武末知上海縣其政以崇節儉黜華靡爲本率之以身故無敢犯者平生廉介自信遇事明果不怵勢利吏畏而民懷之  
夏原吉字維喆湖廣湘陰人母廖氏夢三閭大夫而生洪武庚午從鄉薦入太學授户部主事擢右侍郎充福建採訪使  
太宗即位進尚書時蘇松大水  
<span style="margin-left: 1em">命公來治之首　奏罷蠧民妨政十餘事乃詢延故老究水之由晝夜經營雖盛暑不張蓋曰衆赤體曓日吾忍求涼哉以是人人效力於蘇浚白茆塘劉家河於松浚黃浦導淫水以歸于海水患乃息　奏發廩米三十餘萬石以賑饑民全活者衆有欲干澤於</span>  
上者奏以水退淤肥宜召民佃耕以足國用原吉曰民疲極矣況重役乎即馳　奏車戽則徒勞民力栽種則已失時何益于國  
上悟事遂寢吳人懷之三年八月　召還掌部事  
<span style="margin-left: 1em">車駕親征兼掌六部都察院大理寺事輔導</span>  
<span style="margin-left: 1em">皇太孫洪熙初進少保兼　太子少傅宣德初與少師蹇義少傅楊士奇楊榮等同心輔政爲國元臣五年春正月有星墜所居西南隅後二日卒贈特進光禄大夫太師謚忠靖原吉治水扁舟單車遍歷遐僻所至多有題詠至松寓超果寺嘗登一覽樓賦詩手迹猶存又嘗有踏車嘆等作至今父老皆稱夏尚書之治水云</span>  
黃子威江西進賢人洪武末以儒士授長洲丞永樂初擢刑部員外郎二年出知府事公勤剛果不惑憸邪始至郡罹水患  
<span style="margin-left: 1em">朝廷方遣使治之子威跋履鄉邑撫綏賑賚民藉以存活者甚衆三年政通人和上下信服以詿誤及丁母憂去民前後赴愬懇留者千餘人其後郡更三守而民念之猶一日</span>  
<span style="margin-left: 1em">朝廷知之俾復任操履如初甚得時譽</span>  
魏驥字仲房浙江蕭山人永樂三年舉于鄉明年授松江府學訓導端重祇慎汲汲以成就人材爲事諸生在學居者候更盡必攜茶往視見有書聲者供茶一甌夜過半必攜粥以隨尚有誦書者供粥一盂如此者亦不數間一行之士子皆感激後顯宦甚衆滿九載諸生楊珙等詣  
<span style="margin-left: 1em">闕請留時</span>  
仁廟監國特　召驥與諸生偕還復教三年兩考江西鄉試十七年吏部尚書師逵薦陞南京太常寺博士宣德初陞行在考功員外郎轉南京太常少卿三考會試正統三年　召試行在吏部左侍郎踰年實授驥在官臞然若不勝衣而清正有聲雖內侍王振亦禮重之呼爲先生贄見惟帕一方振亦不較八年以老辭調禮部復辭乃調南京吏部戊辰乞致仕弗允陞本部尚書景泰改元年七十七請老至京閣老陳循公所取士也來見請曰先生雖位冢宰然未嘗立于朝願少待事在我輩而已驥不從退謂人曰渠將  
<span style="margin-left: 1em">朝廷事爲一己事安得善終</span>  
憲宗即位進階榮禄大夫家居二十年布袍糲食不別治生爲人以端厚祇慎簡約廉勤爲本好別白君子小人耄年事其兄教諭騏愈恭謹雅好吟咏有南齊集成化七年年九十八御史梁昉言公有德有壽請如漢故事優禮之八月遣行人存問賜羊酒有司月給米三石未至以其年九月己丑卒前夕公覺神思有異口占曰平生不作欺心事一點靈光直上行遺書付其子完勿動擾鄉里經營墳墓時有司以得請如例葬祭完以遺言辭從之蕭山知縣李鞏言驥行應諡法　賜諡曰文靖公德望著海內而得松人心尤深既老猶與松故舊細書往復無倦吾松人雖長子育孫猶曰吾祖吾父魏公門人也及卒皆爲詩往哭之仍祀于先賢祠  
韓陽字伯陽山陰人永樂十六年以鄉貢士授府學訓導操行清謹善教迪三載以外艱去再教丹陽薦爲監察御史陞湖廣按察司僉事專督學政轉江西按察副使廣東左布政使致仕  
侯端字敬莊盱眙人永樂乙酉銓授金山衛指揮同知性嚴毅剛勇以金山東南要害修城濠備器械練士卒爲守戰備戊戌倭宼登岸端與同衛事郤某分兵出戰郤出南門全軍皆覆賊遂由南門入城斷橋端孤軍在東門不得入乃引兵至西門橋亦斷仰天嘆曰城亡吾分當死安可偷生遂策馬一躍過河入西門衆不能繼與賊巷戰數十合身被箭如蝟轉戰至衛門賊驚曰好將軍也乃以所掠染家布横于街欲生致之端馳至以一劍挑布一劍截而斷之賊仆地而笑端由是得馳出東門次于楊家橋嗚鼓招散卒得百人令曰今潮退舟膠人持草一束與砲俱進至海灘焚賊船十餘艘賊不得歸遂大敗端有勇力府治石狻猊高四五尺端以一手挽之行十餘步策馬過坊門交手擁楣以足挾其馬而懸之騎射刀槊皆過人故能立功<sub class="note-yuan">端巷戰時一劍忽墜地所乘馬口銜以授端其異如此</sub>  
潘俊字文英順天清河人以鄉貢入成均授本府通判明吏牘書筭清慎慈祥凡劇政理之有餘裕賦役有弗均者審實爲條之一郡歸心焉秩滿郡民擬乞留終惠卒于官士民莫不傷悼  
方佐四明人宣德初知上海縣明達世務清白愛民民亦愛之  
趙豫字定素保定安肅人洪武末以生員督賦守城永樂丁亥授泌陽縣主簿未上擢兵部主事陞員外郎丁內艱起復洪熙初陞郎中宣德庚戌奉  
<span style="margin-left: 1em">敕知松江府時戍兵驕甚豫擇其甚者杖而配之邊衆遂帖服於是一意撫循與民休息困窮耄稚至者咸得盡其情擇名家子謹良者爲吏訓以禮法不威而嚴下亦不忍欺寡慾絶游燕母誦范文正先憂後樂之言曰此吾輩所當法也以吳俗尚琴奕喜玩好見之未嘗一寓目輕徭役節冗費　奏減吏員十五如此者十餘事巡撫侍郎周公忱有所經畫必與之議而後決民陰受其賜而終不自言有及之者則曰此巡撫奉宣</span>  
<span style="margin-left: 1em">德意豫何力之有尤重儒術待學官必以賓禮至要途顯人亦不爲逢迎也滿考吏民數千人請留增秩正三品復任前後十五年清靜如一上下皆化之斷獄大省請謁路絶每視事惟兩吏侍傍數卒肅列階下若僧寺然嘗入京教授廬陵孫鼎畫一鶴爲贐且曰公爲政若大車行乎平陸巨艦汎乎安流信古之所謂長者而循吏也時以爲知言正統十年吏部論天下有司治行尤著者十一人豫在上列</span>  
<span style="margin-left: 1em">詔宴于午門　錫織金衣一襲縉紳榮之及致仕去吏民攀擁不得行留一靴以識遺愛教授王禮作去思文刻石崇德堂上今從祀先賢及配食文襄公祠<sub class="note-yuan">公每見訟者非急事則諭之曰明日來始皆笑之故有松江太守明日之謡不知訟者乘一時之忿經宿氣平或衆爲譬解因而息者多矣比之鉤距致人而自爲名者其所存向啻霄壤</sub></span>  
周忱字恂如江西吉水人永樂甲申進士改庶吉士授刑部主事陞員外郎洪熙時遷　越府長史宣德庚戌擢工部右侍郎巡撫南直隸時蘇松常三府積欠糧以千萬計忱詢問父老知大户不出加耗併累小民又糧長家自徵收斛斗無制取羨由己曰此積欠之由也乃　奏設管糧官定斛斗式立水次倉每府通計一歲田糧及支撥總數以秋糧正米爲則定爲加耗而以各户應納之數寘注由帖而分給之俾户自持帖赴倉輸注不涉里胥又立囤户糧頭與糧長同收互察而管糧官總督之徵收既完如數支撥若干爲存留若干爲起運凡夏稅馬草農桑絲絹逃絶積荒坍江陷海包納之數與夫織造供應軍需等費悉於是取之起運者道途有遠近耗費有多寡各隨其地而給之甚遠者以三致一石其餘遞減而各有定數總會通融以羨補乏於是各府稅糧始以足告又立淮安瓜州交兑法民免長運而軍獲羨餘交便之北京公侯禄米例輸于南京俾自來受石費米六斗忱曰彼能受之于南京獨不可受之於三府乎以便宜言省耗米六十萬乃令諸縣各立倉貯之以備賑貸名曰濟農而糧運遭風失盜修圩濬河工食不給者咸以資之官田稅重輸者不堪而北京文武俸帖賣於南京者苦其太賤<sub class="note-yuan">銀一兩可得米七八石</sub>忱　奏折收金花銀每兩准秋糧四石以給官俸折糧布例重三斤解者率以紗麤驗退忱　奏不拘斤重止取長闊宫得實用民皆便之以至　奏折馬草銀徵馬價米調停轉移咸省大費往歲正糧一石加耗以八斗至抵石而猶不足忱始猶仍舊民以爲怨忱曰姑試爾不一載積逋悉完遂減至七斗其後石止加六而沛然有餘常民歲賦外漠然不見他役之及已而官府無復科率之擾蓋其施於三府者皆然而惠及吾松者尤厚鹽丁附塲者煮海辦鹽而遠鄉者助出柴價此舊例也然煮海者爲總催剋取恒苦乏食而出價者往返病耕忱總計所耕爲糧六萬石盡留本地而節其運耗貯之各塲以足鹽丁之食所出柴價亦貯之於官公爲支遣彼此交便課遂以充民遺官田而逃者居人一沾足則執以償其賦雖良田皆廢而不耕忱　奏立召佃法俾民得開墾而薄收其賦以來之又　奏絶户官田不分古額抄没悉照民田例起稅坍江陷海田　奏除其稅額而以鄰近絶户田召人耕種以足之擇良民諲實者爲田甲使專督其事於是田野日闢流亡來歸忱又開吳松江濬金山濱海河修防倭城堡創金山衛學與凡官府學校橋梁驛傳百廢具舉而公帑民財初不知費蓋其才略超絶善謀果行而簡略勢分集衆自廣故所至有功莅江南十九年民熙然樂生不知苛政横歛之及己災警之爲害其間有竊羨餘互告訐以撓其法者乃歎曰吾反不便於爾邪辭弗復理不一年姦弊百出松父老流涕道路請求復故帖然以寧正統己巳進尚書仍  
<span style="margin-left: 1em">命巡撫景泰二年致仕歸又二年卒謚文襄忱立法因地從宜以便民爲主思慮周詳節目簡易有似疏而實密者如秋糧石加六斗疑偏重官田而銀布輕賫專歸重稅蓋陰以裨之無遺算也其後繼者或知其然而不知其所以然或輕爲論議然守其法則治紊之則亂而松人亦心服焉去之六十年每曰安得周公復來巡撫也近歲乃有盡舉其法而紛更之者弊孔百出資儲一空己巳庚午之災上下束手民益思之不置云</span>  
王琚山西平陽人宣德八年以長史左遷知華亭縣心術明正莅政廉平且簡易近民人心悦服致政去邑民擁抱留其靴城市觀者不忍別相顧失色
