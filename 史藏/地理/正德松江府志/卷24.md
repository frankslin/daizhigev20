## 正德松江府志卷之二十四　官迹下

<span style="margin-left: 4em">宦迹下</span>  
<span style="margin-left: 1em">国朝祝挺字正夫番阳人洪武初知上海县时海滨盗</span>  
<span style="margin-left: 2em">起县民钱鹤臯因煽乱伪总兵姚姓者率众逼县治</span>  
<span style="margin-left: 2em">挺怀印走府谋克复闻府已陷乃仰天叹曰县我死</span>  
<span style="margin-left: 2em">所也效死弗去首恶者迫使见挺毅然曰汝吾编氓</span>  
<span style="margin-left: 2em">我尔县长何总兵为而迫我见邪吾有头在勿复语</span>  
<span style="margin-left: 2em">盗知不可屈释之乃密与前主簿郑著王掎主簿李</span>  
<span style="margin-left: 2em">从吉等谋聚义兵追斩盗首二以献于主帅或议以</span>  
<span style="margin-left: 2em">兵涉县境民震慑不宁挺星驰诣帅曰苟降罚罚我</span>  
<span style="margin-left: 2em">如抚民民则定定矣帅犹欲治胁从者挺曰彼诖误</span>  
<span style="margin-left: 2em">者何罪不则仍罪我帅壮其言而从之方是时他邑</span>  
<span style="margin-left: 2em">死伤相枕籍而上海独晏然挺之力也初民有不利</span>  
<span style="margin-left: 2em">于挺者及事平皆惴恐挺一不问慰劳而遣之故人</span>  
<span style="margin-left: 2em">情大安不三日皆复业详见活民碑</span>  
<span style="margin-left: 1em">陈□茶陵人<sub class="note-jiao">校：此處原書作墨丁他書皆不錄</sub></span>  
<span style="margin-left: 1em">高庙为吴王时在左右性鲠正廷诤大事不以死惧</span>  
<span style="margin-left: 2em">朝章律令皆预参议紏正切劘重一代之制平居谈</span>  
<span style="margin-left: 2em">仁履义务以圣贤之学致</span>  
<span style="margin-left: 1em">主尧舜时称为社稷臣洪武元年出知松江府未朞月</span>  
<span style="margin-left: 2em">政成迁山西参政<sub class="note-yuan">名见官署事出杨维祯序苏志茶陵陈宁洪武初自中书出知府事恐即此人</sub></span>  
<span style="margin-left: 1em">李浩字师孟保定人归附初同知府事均赋役平出纳</span>  
<span style="margin-left: 2em">明黜陟慎兴革严关津清狱讼时称为循吏未几</span>  
<span style="margin-left: 2em">中使至　召置机近</span>  
<span style="margin-left: 1em">冯荣乌江人洪武初知华亭县莅任甫三月海滨盗起</span>  
<span style="margin-left: 2em">染及华亭荣言于统兵者请罪渠魁而贷其良民之</span>  
<span style="margin-left: 2em">诖误者统兵然之脱死者数万口既而兴学校劝农</span>  
<span style="margin-left: 2em">桑辩寃枉均繇役政教一新故老至今能道之</span>  
<span style="margin-left: 1em">蒋惠番昜人洪武十一年知华亭县先是县诬平民李</span>  
<span style="margin-left: 2em">秀三等三十人为强盗惠察其无辜俾以更生仍密</span>  
<span style="margin-left: 2em">授方略获真盗马胡等十八人正其罪他如毁淫祠</span>  
<span style="margin-left: 2em">以正人心去奸顽以植良善及民之惠实多焉</span>  
<span style="margin-left: 1em">胡俨字若思江西南昌人博极群书天文地理律历医</span>  
<span style="margin-left: 2em">卜皆通其说洪武丁卯举于乡授华亭教谕以内艰</span>  
<span style="margin-left: 2em">去改授长垣县上疏乞近便养亲改饶之余干自是</span>  
<span style="margin-left: 2em">著为令以荐升知桐城县永乐初召试称</span>  
<span style="margin-left: 2em">旨授翰林检讨寻升侍读直内阁明年春升春坊谕</span>  
<span style="margin-left: 2em">德九月拜国子祭酒庚寅</span>  
<span style="margin-left: 1em">上北征命以祭酒兼侍讲掌翰林院事辅</span>  
<span style="margin-left: 2em">皇太孙监国洪熙初以疾辞加　太子宾客致仕公</span>  
<span style="margin-left: 2em">在华亭时尚少而能以师道自任劝勉诸生讲授每</span>  
<span style="margin-left: 2em">至夜分虽隆寒盛暑不废宰桐城以爱民为主凡可</span>  
<span style="margin-left: 2em">便民者以身任之民间积欠悉与　奏免邑中虎为</span>  
<span style="margin-left: 2em">害祷于神虎遂灭迹尝捕蝗道见饥病者命里胥扶</span>  
<span style="margin-left: 2em">掖就民舍给以药食是夜大风雨得免暴露存活数</span>  
<span style="margin-left: 2em">百人在内阁间有　顾问必从容商度而后对及兼</span>  
<span style="margin-left: 2em">宫僚在讲筵凡古今治乱得失必反复敷陈以图裨</span>  
<span style="margin-left: 2em">益为祭酒身率诸生以师道自重</span>  
<span style="margin-left: 1em">文庙亦礼之一时人材翕然从化时国子生有以故告</span>  
<span style="margin-left: 2em">归者皆谪戍边公为言其情乃得免闲居二十余年</span>  
<span style="margin-left: 2em">日与学者讲求性理之学是非利害可否之间必审</span>  
<span style="margin-left: 2em">度以求至当惟恐贻患于人群论中有不合即引退</span>  
<span style="margin-left: 2em">不与辩故所至能全交</span>  
<span style="margin-left: 1em">甄庸北京人洪武三十二年以户部主事来知府事醇</span>  
<span style="margin-left: 2em">谨严重以廉自防虽所得俸赀苟欲易一衣具一食</span>  
<span style="margin-left: 2em">必于他郡营之略不涉于境内尝曰人非古人其避</span>  
<span style="margin-left: 2em">嫌疑不得不尔也事母至孝仕至工部尚书致仕</span>  
<span style="margin-left: 1em">杜镒洪武末知上海县其政以崇节俭黜华靡为本率</span>  
<span style="margin-left: 2em">之以身故无敢犯者平生廉介自信遇事明果不怵</span>  
<span style="margin-left: 2em">势利吏畏而民怀之</span>  
<span style="margin-left: 1em">夏原吉字维喆湖广湘阴人母廖氏梦三闾大夫而生</span>  
<span style="margin-left: 2em">洪武庚午从乡荐入太学授户部主事擢右侍郎充</span>  
<span style="margin-left: 2em">福建采访使</span>  
<span style="margin-left: 1em">太宗即位进尚书时苏松大水</span>  
<span style="margin-left: 2em">命公来治之首　奏罢蠧民妨政十余事乃询延故</span>  
<span style="margin-left: 2em">老究水之由昼夜经营虽盛暑不张盖曰众赤体曓</span>  
<span style="margin-left: 2em">日吾忍求凉哉以是人人效力于苏浚白茆塘刘家</span>  
<span style="margin-left: 2em">河于松浚黄浦导淫水以归于海水患乃息　奏发</span>  
<span style="margin-left: 2em">廪米三十余万石以赈饥民全活者众有欲干泽于</span>  
<span style="margin-left: 1em">上者奏以水退淤肥宜召民佃耕以足国用原吉曰民</span>  
<span style="margin-left: 2em">疲极矣况重役乎即驰　奏车戽则徒劳民力栽种</span>  
<span style="margin-left: 2em">则已失时何益于国</span>  
<span style="margin-left: 1em">上悟事遂寝吴人怀之三年八月　召还掌部事</span>  
<span style="margin-left: 2em">车驾亲征兼掌六部都察院大理寺事辅导</span>  
<span style="margin-left: 2em">皇太孙洪熙初进少保兼　太子少傅宣德初与少</span>  
<span style="margin-left: 2em">师蹇义少傅杨士奇杨荣等同心辅政为国元臣五</span>  
<span style="margin-left: 2em">年春正月有星坠所居西南隅后二日卒赠特进光</span>  
<span style="margin-left: 2em">禄大夫太师谥忠靖原吉治水扁舟单车遍历遐僻</span>  
<span style="margin-left: 2em">所至多有题咏至松寓超果寺尝登一览楼赋诗手</span>  
<span style="margin-left: 2em">迹犹存又尝有踏车叹等作至今父老皆称夏尚书</span>  
<span style="margin-left: 2em">之治水云</span>  
<span style="margin-left: 1em">黄子威江西进贤人洪武末以儒士授长洲丞永乐初</span>  
<span style="margin-left: 2em">擢刑部员外郎二年出知府事公勤刚果不惑憸邪</span>  
<span style="margin-left: 2em">始至郡罹水患</span>  
<span style="margin-left: 2em">朝廷方遣使治之子威跋履乡邑抚绥赈赉民借以</span>  
<span style="margin-left: 2em">存活者甚众三年政通人和上下信服以诖误及丁</span>  
<span style="margin-left: 2em">母忧去民前后赴愬恳留者千余人其后郡更三守</span>  
<span style="margin-left: 2em">而民念之犹一日</span>  
<span style="margin-left: 2em">朝廷知之俾复任操履如初甚得时誉</span>  
<span style="margin-left: 1em">魏骥字仲房浙江萧山人永乐三年举于乡明年授松</span>  
<span style="margin-left: 2em">江府学训导端重祇慎汲汲以成就人材为事诸生</span>  
<span style="margin-left: 2em">在学居者候更尽必携茶往视见有书声者供茶一</span>  
<span style="margin-left: 2em">瓯夜过半必携粥以随尚有诵书者供粥一盂如此</span>  
<span style="margin-left: 2em">者亦不数间一行之士子皆感激后显宦甚众满九</span>  
<span style="margin-left: 2em">载诸生杨珙等诣</span>  
<span style="margin-left: 2em">阙请留时</span>  
<span style="margin-left: 1em">仁庙监国特　召骥与诸生偕还复教三年两考江西</span>  
<span style="margin-left: 2em">乡试十七年吏部尚书师逵荐升南京太常寺博士</span>  
<span style="margin-left: 2em">宣德初升行在考功员外郎转南京太常少卿三考</span>  
<span style="margin-left: 2em">会试正统三年　召试行在吏部左侍郎逾年实授</span>  
<span style="margin-left: 2em">骥在官臞然若不胜衣而清正有声虽内侍王振亦</span>  
<span style="margin-left: 2em">礼重之呼为先生贽见惟帕一方振亦不较八年以</span>  
<span style="margin-left: 2em">老辞调礼部复辞乃调南京吏部戊辰乞致仕弗允</span>  
<span style="margin-left: 2em">升本部尚书景泰改元年七十七请老至京阁老陈</span>  
<span style="margin-left: 2em">循公所取士也来见请曰先生虽位冢宰然未尝立</span>  
<span style="margin-left: 2em">于朝愿少待事在我辈而已骥不从退谓人曰渠将</span>  
<span style="margin-left: 2em">朝廷事为一己事安得善终</span>  
<span style="margin-left: 1em">宪宗即位进阶荣禄大夫家居二十年布袍粝食不别</span>  
<span style="margin-left: 2em">治生为人以端厚祇慎简约廉勤为本好别白君子</span>  
<span style="margin-left: 2em">小人耄年事其兄教谕骐愈恭谨雅好吟咏有南齐</span>  
<span style="margin-left: 2em">集成化七年年九十八御史梁昉言公有德有寿请</span>  
<span style="margin-left: 2em">如汉故事优礼之八月遣行人存问赐羊酒有司月</span>  
<span style="margin-left: 2em">给米三石未至以其年九月己丑卒前夕公觉神思</span>  
<span style="margin-left: 2em">有异口占曰平生不作欺心事一点灵光直上行遗</span>  
<span style="margin-left: 2em">书付其子完勿动扰乡里经营坟墓时有司以得请</span>  
<span style="margin-left: 2em">如例葬祭完以遗言辞从之萧山知县李巩言骥行</span>  
<span style="margin-left: 2em">应谥法　赐谥曰文靖公德望著海内而得松人心</span>  
<span style="margin-left: 2em">尤深既老犹与松故旧细书往复无倦吾松人虽长</span>  
<span style="margin-left: 2em">子育孙犹曰吾祖吾父魏公门人也及卒皆为诗往</span>  
<span style="margin-left: 2em">哭之仍祀于先贤祠</span>  
<span style="margin-left: 1em">韩阳字伯阳山阴人永乐十六年以乡贡士授府学训</span>  
<span style="margin-left: 2em">导操行清谨善教迪三载以外艰去再教丹阳荐为</span>  
<span style="margin-left: 2em">监察御史升湖广按察司佥事专督学政转江西按</span>  
<span style="margin-left: 2em">察副使广东左布政使致仕</span>  
<span style="margin-left: 1em">侯端字敬庄盱眙人永乐乙酉铨授金山卫指挥同知</span>  
<span style="margin-left: 2em">性严毅刚勇以金山东南要害修城濠备器械练士</span>  
<span style="margin-left: 2em">卒为守战备戊戌倭宼登岸端与同卫事郤某分兵</span>  
<span style="margin-left: 2em">出战郤出南门全军皆覆贼遂由南门入城断桥端</span>  
<span style="margin-left: 2em">孤军在东门不得入乃引兵至西门桥亦断仰天叹</span>  
<span style="margin-left: 2em">曰城亡吾分当死安可偷生遂策马一跃过河入西</span>  
<span style="margin-left: 2em">门众不能继与贼巷战数十合身被箭如猬转战至</span>  
<span style="margin-left: 2em">卫门贼惊曰好将军也乃以所掠染家布横于街欲</span>  
<span style="margin-left: 2em">生致之端驰至以一剑挑布一剑截而断之贼仆地</span>  
<span style="margin-left: 2em">而笑端由是得驰出东门次于杨家桥呜鼓招散卒</span>  
<span style="margin-left: 2em">得百人令曰今潮退舟胶人持草一束与砲俱进至</span>  
<span style="margin-left: 2em">海滩焚贼船十余艘贼不得归遂大败端有勇力府</span>  
<span style="margin-left: 2em">治石狻猊高四五尺端以一手挽之行十余步策马</span>  
<span style="margin-left: 2em">过坊门交手拥楣以足挟其马而悬之骑射刀槊皆</span>  
<span style="margin-left: 2em">过人故能立功<sub class="note-yuan">端巷战时一剑忽坠地所乘马口衔以授端其异如此</sub></span>  
<span style="margin-left: 1em">潘俊字文英顺天清河人以乡贡入成均授本府通判</span>  
<span style="margin-left: 2em">明吏牍书筭清慎慈祥凡剧政理之有余裕赋役有</span>  
<span style="margin-left: 2em">弗均者审实为条之一郡归心焉秩满郡民拟乞留</span>  
<span style="margin-left: 2em">终惠卒于官士民莫不伤悼</span>  
<span style="margin-left: 1em">方佐四明人宣德初知上海县明达世务清白爱民民</span>  
<span style="margin-left: 2em">亦爱之</span>  
<span style="margin-left: 1em">赵豫字定素保定安肃人洪武末以生员督赋守城永</span>  
<span style="margin-left: 2em">乐丁亥授泌阳县主簿未上擢兵部主事升员外郎</span>  
<span style="margin-left: 2em">丁内艰起复洪熙初升郎中宣德庚戌奉</span>  
<span style="margin-left: 2em">敕知松江府时戍兵骄甚豫择其甚者杖而配之边</span>  
<span style="margin-left: 2em">众遂帖服于是一意抚循与民休息困穷耄稚至者</span>  
<span style="margin-left: 2em">咸得尽其情择名家子谨良者为吏训以礼法不威</span>  
<span style="margin-left: 2em">而严下亦不忍欺寡欲绝游燕母诵范文正先忧后</span>  
<span style="margin-left: 2em">乐之言曰此吾辈所当法也以吴俗尚琴奕喜玩好</span>  
<span style="margin-left: 2em">见之未尝一寓目轻徭役节冗费　奏减吏员十五</span>  
<span style="margin-left: 2em">如此者十余事巡抚侍郎周公忱有所经画必与之</span>  
<span style="margin-left: 2em">议而后决民阴受其赐而终不自言有及之者则曰</span>  
<span style="margin-left: 2em">此巡抚奉宣</span>  
<span style="margin-left: 2em">德意豫何力之有尤重儒术待学官必以宾礼至要</span>  
<span style="margin-left: 2em">途显人亦不为逢迎也满考吏民数千人请留增秩</span>  
<span style="margin-left: 2em">正三品复任前后十五年清静如一上下皆化之断</span>
