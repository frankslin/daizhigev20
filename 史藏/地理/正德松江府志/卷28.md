## 正德松江府志卷之二十八　人物二（名臣）

<span style="margin-left: 4em">人物二<sub class="note-yuan">名臣</sub></span>  
<span style="margin-left: 1em">梁顧野王字希馮吳縣人也祖子喬梁陳中武陵王府</span>  
<span style="margin-left: 2em">參軍父烜信威臨賀王記室兼本郡五官掾以儒術</span>  
<span style="margin-left: 2em">知名野王幼好學七歲讀五經略知大指九歲能屬</span>  
<span style="margin-left: 2em">文嘗製日賦領軍朱异見而奇之年十二隨父之建</span>  
<span style="margin-left: 2em">安撰建安地記二篇及長徧觀經史精記默識天文</span>  
<span style="margin-left: 2em">地理蓍龜占候虫篆奇字無所不通爲臨賀王府記</span>  
<span style="margin-left: 2em">室宣城王爲揚州刺史野王與琅邪王褒並爲賓客</span>  
<span style="margin-left: 2em">王甚愛其才野王又善丹青於東府起齋令野王畫</span>  
<span style="margin-left: 2em">古賢命褒書贊時稱二絶及侯景亂野王丁父憂歸</span>  
<span style="margin-left: 2em">本郡乃召募鄉黨隨義軍援京都野王體素清羸裁</span>  
<span style="margin-left: 2em">長六尺又居喪過毁殆不勝衣及杖戈被甲陳君臣</span>  
<span style="margin-left: 2em">之義逆順之理抗辭作色見者莫不壯之城陷逃會</span>  
<span style="margin-left: 2em">稽陳天嘉中敕補撰史學士太建中爲太子率更令</span>  
<span style="margin-left: 2em">尋領大著作掌國史知梁史事後爲黃門侍郎光禄</span>  
<span style="margin-left: 2em">卿知五禮事卒贈秘書監右衛將軍野王少以篤學</span>  
<span style="margin-left: 2em">至性知名在物無過辭失色其容貌似不能言其厲</span>  
<span style="margin-left: 2em">精力學皆人所莫及所撰玉篇輿地志各三十卷符</span>  
<span style="margin-left: 2em">瑞圖顧氏譜傳各十卷分野樞要續洞冥記玄象表</span>  
<span style="margin-left: 2em">各一卷並行于時又撰通史要略一百卷國史紀傳</span>  
<span style="margin-left: 2em">二百卷未就而卒有文集二十卷<sub class="note-yuan">陳書曰野王博識洽聞侯景之寇郡將袁君正舉兵起援文檄皆以委之口占便就未嘗立草</sub></span>  
<span style="margin-left: 1em">唐陸元感字達禮梁婁縣令慶之曾孫周王府文學詳</span>  
<span style="margin-left: 2em">正殿學士謀道之子生而敏慧謀道善班固漢書元</span>  
<span style="margin-left: 2em">感傳其學解褐參韓王府軍事除婺州龍丘丞遷建</span>  
<span style="margin-left: 2em">德歷陽二縣令咸有善政加朝散大夫護軍行黃州</span>  
<span style="margin-left: 2em">司馬神龍三年卒葬崑山子南金趙璧在孝友類</span>  
<span style="margin-left: 1em">陸贄字敬輿嘉興人秘書監齊望之姪曾孫吏部郎中</span>  
<span style="margin-left: 2em">灞之子十八第進士中博學宏辭調鄭尉罷壽州刺</span>  
<span style="margin-left: 2em">史張鎰有重名贄往見語三日奇之請爲忘年交既</span>  
<span style="margin-left: 2em">行餉錢百萬曰請爲母夫人一日費贄不納止受茶</span>  
<span style="margin-left: 2em">一串曰敢不承公之賜以書判拔萃補渭南尉德宗</span>  
<span style="margin-left: 2em">立遣黜陟使行天下贄說使者請以五術省風俗八</span>  
<span style="margin-left: 2em">計聽吏治三科登俊乂四賦經財實六德保疲瘵五</span>  
<span style="margin-left: 2em">要簡官事時皆韙其言遷監察御史召爲翰林學士</span>  
<span style="margin-left: 2em">會馬燧討賊河北久不決請濟師李希烈寇襄城詔</span>  
<span style="margin-left: 2em">問贄策帝不納從狩奉天機務闐總遠近調發奏請</span>  
<span style="margin-left: 2em">報下詔書數百贄若不經思逮成皆周盡事情衍繹</span>  
<span style="margin-left: 2em">熟復人人可曉旁吏承寫不給他學士筆閣不得下</span>  
<span style="margin-left: 2em">而贄沛然有餘始帝播遷府藏委棄衛兵無褚衣至</span>  
<span style="margin-left: 2em">是天下貢奉稍至乃於行在夾廡署璚林大盈二庫</span>  
<span style="margin-left: 2em">別藏貢物贄上疏諫帝悟即撤其署俄以勞遷諫議</span>  
<span style="margin-left: 2em">大夫仍爲學士孤立爲左右權倖沮短又言事無所</span>  
<span style="margin-left: 2em">回諱陰失帝意久之不得宰相但爲中書舍人母韋</span>  
<span style="margin-left: 2em">猶在江東帝遣中人迎還京師俄以喪解官客東都</span>  
<span style="margin-left: 2em">諸方賵遺一不取唯韋臯以布衣交先以聞故所致</span>  
<span style="margin-left: 2em">皆稱詔受之又詔中人護父柩自吳葬洛陽服除以</span>  
<span style="margin-left: 2em">權知兵部侍郎復召爲學士入謝伏地鯁泣帝爲改</span>  
<span style="margin-left: 2em">容慰撫眷遇彌渥天下屬以爲相而竇參素不平忌</span>  
<span style="margin-left: 2em">之贄亦數言參罪失貞元七年罷學士以兵部侍郎</span>  
<span style="margin-left: 2em">知貢舉明年參黜乃以中書侍郎同中書門下平章</span>  
<span style="margin-left: 2em">事班宏判度支卒贄薦李遜帝漫許之而自用裴延</span>  
<span style="margin-left: 2em">齡贄言延齡僻戾躁妄不可用不聽俄而延齡姦佞</span>  
<span style="margin-left: 2em">得君天下仇惡無敢言贄上書苦諫帝不懌竟以太</span>  
<span style="margin-left: 2em">子賓客罷贄本畏慎未嘗通賓客延齡揣帝意薄讒</span>  
<span style="margin-left: 2em">短百緒帝怒欲誅贄賴陽城等交章論辯貶忠州別</span>  
<span style="margin-left: 2em">駕後稍思之會薛延訥爲刺史諭旨慰勞韋臯數表</span>  
<span style="margin-left: 2em">請贄代領劒南帝猶銜之不肯與順宗立召未至卒</span>  
<span style="margin-left: 2em">年五十二贈兵部尚書謚曰宣始贄入翰林年尚少</span>  
<span style="margin-left: 2em">以材幸天子常以輩行呼而不名在奉天朝夕進見</span>  
<span style="margin-left: 2em">然小心精潔未嘗有過由是帝親倚至解衣衣之同</span>  
<span style="margin-left: 2em">類莫敢望雖外有宰相主大議而贄嘗居中參裁可</span>  
<span style="margin-left: 2em">否時號內相嘗爲帝言今盜遍天下宜痛自咎悔以</span>  
<span style="margin-left: 2em">感人心昔成湯罪己以興楚昭出奔以一言善而復</span>  
<span style="margin-left: 2em">國陛下誠不吝改過以言謝天下使臣持筆亡所忌</span>  
<span style="margin-left: 2em">庶叛者革心帝從之故奉天所下制書雖武人悍卒</span>  
<span style="margin-left: 2em">無不感動流涕後李抱真入朝爲帝言陛下在奉天</span>  
<span style="margin-left: 2em">山南時赦令至山東士卒聞者皆感泣思奮臣是時</span>  
<span style="margin-left: 2em">知賊不足平也議者謂興元戡難功雖爪牙宣力蓋</span>  
<span style="margin-left: 2em">贄有助焉狩山南也道險澀與從官相失夜召贄不</span>  
<span style="margin-left: 2em">得帝驚且泣詔軍中得贄者賞千金久之上謁帝喜</span>  
<span style="margin-left: 2em">見顔間自太子以下皆賀及輔政不敢自顧重事有</span>  
<span style="margin-left: 2em">可否必言之所言皆剴拂帝短懇到深切或規其太</span>  
<span style="margin-left: 2em">過者曰吾上不負天子下不負所學皇它鷹乎既放</span>  
<span style="margin-left: 2em">荒遠嘗闔户人不識其面又避謗不著書地苦瘴癘</span>  
<span style="margin-left: 2em">秖爲古今集驗方五十篇示鄉人云贄論諫數十百</span>  
<span style="margin-left: 2em">篇譏陳時病皆本仁義可爲後世法炳炳如丹所用</span>  
<span style="margin-left: 2em">裁十一耳惜哉族孫扆</span>  
<span style="margin-left: 1em">扆字祥文曾祖禮殿中侍御史祖師德淮南觀察支使</span>  
<span style="margin-left: 2em">父鄯陝州法曹參軍徙家于陝扆本名允迪光啓二</span>  
<span style="margin-left: 2em">年僖宗在興元舉進士第一進翰林學士中書舍人</span>  
<span style="margin-left: 2em">屬辭敏速若注射然一時書命同僚以爲不及昭宗</span>  
<span style="margin-left: 2em">嘗於金鑾作賦詔學士皆和扆先就帝歎曰貞元時</span>  
<span style="margin-left: 2em">陸贄吳通玄善內廷文字後無繼者今朕得卿斯文</span>  
<span style="margin-left: 2em">不墜矣與宗人希載文才重德名冠一時朝中號二</span>  
<span style="margin-left: 2em">陸累爲尚書左丞封嘉興縣男徙户部侍郎貶峽州</span>  
<span style="margin-left: 2em">刺史久之授工部尚書從帝自華州還以工部尚書</span>  
<span style="margin-left: 2em">當國封郡公天復初朱全忠謀去朝廷衣冠貶扆濮</span>  
<span style="margin-left: 2em">州司户殺之于白馬驛年五十九</span>  
<span style="margin-left: 1em">顧謙字自修其先吳郡人丞相季歷之後風神朗秀質</span>  
<span style="margin-left: 2em">性端敏舉明經三禮二科洞達貫穿魏帥何公表謙</span>  
<span style="margin-left: 2em">高才拜貝州宗城令尋棄歸隱居北平鄉崧子里名</span>  
<span style="margin-left: 2em">流高其風操咸就見焉咸通十三年卒</span>  
<span style="margin-left: 1em">宋陳舜俞字令舉登慶曆六年進士嘉祐四年再應材</span>  
<span style="margin-left: 2em">識茂異賢良方正能直言極諫科對策第一文章聲</span>  
<span style="margin-left: 2em">名赫然在人上始授光禄丞簽書壽州判官宰山陰</span>  
<span style="margin-left: 2em">縣秩未滿召試館職不就會行青苗法上書力詆且</span>  
<span style="margin-left: 2em">自劾忤執政貶監星江酒稅退居華亭常騎白牛往</span>  
<span style="margin-left: 2em">來風涇因自號白牛居士今塘市皆以白牛名有文</span>  
<span style="margin-left: 2em">集行於世</span>  
<span style="margin-left: 1em">朱諤初名紱元祐六年進士第二人御筆改今名賜字</span>  
<span style="margin-left: 2em">聖與徽宗時累官御史中丞嘗奏請開內閣延羣臣</span>  
<span style="margin-left: 2em">從容論道如神宗故事又請分命使者刺舉諸道有</span>  
<span style="margin-left: 2em">受令而不行行令而不盡者論其罪庶幾令出而朝</span>  
<span style="margin-left: 2em">廷尊歷禮兵吏三部尚書拜尚書右丞三月卒贈太</span>  
<span style="margin-left: 2em">師岐國公謚忠靖累贈秦國公賜葬平江陽抱山弟</span>  
<span style="margin-left: 2em">紘改名讜字昌言崇寧中進士初諤在位所得恩澤</span>  
<span style="margin-left: 2em">皆分蔭族人及卒子二人猶未禄人以是多之</span>  
<span style="margin-left: 1em">柳約性至孝深于經學大觀中上舍進士爲灞州教授</span>  
<span style="margin-left: 2em">靖康初陞殿中侍御史論三鎮不可棄後以直龍圖</span>  
<span style="margin-left: 2em">閣知嚴州兼浙西兵馬都監時金人大入列郡震恐</span>  
<span style="margin-left: 2em">約屹保孤城境內按堵高宗嘉其忠擢試户部侍郎</span>  
<span style="margin-left: 2em">且將大用當路忌其盡言誣以事罷之</span>  
<span style="margin-left: 1em">衛膚敏字商彦登宣和初進士又中八行科累官校書</span>  
<span style="margin-left: 2em">郎假給事中使金時金人將舉兵大入膚敏論難往</span>  
<span style="margin-left: 2em">復殊不爲屈高宗時拜右諫議大夫后父邢焕除徽</span>  
<span style="margin-left: 2em">猷閣待制太后兄子孟忠厚除顯謨閣直學士膚敏</span>  
<span style="margin-left: 2em">言非祖宗法皆改職勸帝早幸金陵因陳守長江之</span>  
<span style="margin-left: 2em">策帝善其言除刑部侍郎<sub class="note-yuan">高宗批答辭免刑部侍郎詔敕膚敏省所奏辭免尚書刑部侍郎恩命事具悉朕倉卒渡江圖籍散亡深慮吏緣爲奸奏牘稽留平讞失當以卿平日正色侃侃論議堅明據誼守節屢觸權貴必能爲朕分別隱微章明杜直與其殺不辜寧失不經欽哉汝諧毋廢朕命所請宜不允故兹詔示想宜知悉</sub></span>  
<span style="margin-left: 1em">衛仲達初名上達字達可大觀三年登進士第徽宗改</span>  
<span style="margin-left: 2em">今名爲館職日嘗上書諫修三山石橋不報後官至</span>  
<span style="margin-left: 2em">吏部尚書卒</span>  
<span style="margin-left: 1em">任盡言字元受右正言伯禹之孫與兄質言同登紹興</span>  
<span style="margin-left: 2em">二年進士第居下僚好慷慨論事秦檜死朝廷懲言</span>  
<span style="margin-left: 2em">路壅塞之弊召湯鵬舉于外爲臺官盡言投啓賀之</span>  
<span style="margin-left: 2em">有每媿朱雲之請劒未聞林甫之斵棺之語鵬舉袖</span>  
<span style="margin-left: 2em">以白上上意頗回始黜檜姻黨釋趙鼎子汾及李孟</span>  
<span style="margin-left: 2em">堅王之奇等自便公道大明盡言之助也嘗通判平</span>  
<span style="margin-left: 2em">江除京西運判改淮東提舉欽廟上升盡言率縉紳</span>  
<span style="margin-left: 2em">爲位佛宫致哀疏文二通讀者感泣啓與疏岳珂皆</span>  
<span style="margin-left: 2em">載之桯史謂其義不忘君直不蔽姦忠信之至惜不</span>  
<span style="margin-left: 2em">究其用云所著有小醜集行于世</span>  
<span style="margin-left: 1em">錢良臣字友魏幼志于學十九升辟雍登紹興中進士</span>  
<span style="margin-left: 2em">孝宗淳熙五年十一月拜參知政事八年九月罷以</span>  
<span style="margin-left: 2em">正奉大夫知鎮江良臣在朝德望偉然嘗一新縣學</span>  
<span style="margin-left: 2em">舊祠于學之西廡鎮江人亦祠于甘露寺</span>  
<span style="margin-left: 1em">許克昌字上達紹興末舉進士名在第一以有官改第</span>  
<span style="margin-left: 2em">二累官右正言時松江新涇塘爲海潮衝突鹹水延</span>  
<span style="margin-left: 2em">及嘉湖二境克昌請于朝移堰入運港以避潮勢由</span>  
<span style="margin-left: 2em">是三州之田獲免鹹潮之患鄉邦德之</span>  
<span style="margin-left: 1em">蓋經字常父登紹興甲科官至户侍</span>  
<span style="margin-left: 1em">張伯垓字德象<sub class="note-jiao">校：以上二字原闕據宋詩紀事補遺補</sub>登紹興第官至尚</span>
