## 正德松江府志卷之二十八　人物二（名臣）

<span style="margin-left: 4em">人物二<sub class="note-yuan">名臣</sub></span>  
<span style="margin-left: 1em">梁顾野王字希冯吴县人也祖子乔梁陈中武陵王府</span>  
<span style="margin-left: 2em">参军父烜信威临贺王记室兼本郡五官掾以儒术</span>  
<span style="margin-left: 2em">知名野王幼好学七岁读五经略知大指九岁能属</span>  
<span style="margin-left: 2em">文尝制日赋领军朱异见而奇之年十二随父之建</span>  
<span style="margin-left: 2em">安撰建安地记二篇及长徧观经史精记默识天文</span>  
<span style="margin-left: 2em">地理蓍龟占候虫篆奇字无所不通为临贺王府记</span>  
<span style="margin-left: 2em">室宣城王为扬州刺史野王与琅邪王褒并为宾客</span>  
<span style="margin-left: 2em">王甚爱其才野王又善丹青于东府起斋令野王画</span>  
<span style="margin-left: 2em">古贤命褒书赞时称二绝及侯景乱野王丁父忧归</span>  
<span style="margin-left: 2em">本郡乃召募乡党随义军援京都野王体素清羸裁</span>  
<span style="margin-left: 2em">长六尺又居丧过毁殆不胜衣及杖戈被甲陈君臣</span>  
<span style="margin-left: 2em">之义逆顺之理抗辞作色见者莫不壮之城陷逃会</span>  
<span style="margin-left: 2em">稽陈天嘉中敕补撰史学士太建中为太子率更令</span>  
<span style="margin-left: 2em">寻领大著作掌国史知梁史事后为黄门侍郎光禄</span>  
<span style="margin-left: 2em">卿知五礼事卒赠秘书监右卫将军野王少以笃学</span>  
<span style="margin-left: 2em">至性知名在物无过辞失色其容貌似不能言其厉</span>  
<span style="margin-left: 2em">精力学皆人所莫及所撰玉篇舆地志各三十卷符</span>  
<span style="margin-left: 2em">瑞图顾氏谱传各十卷分野枢要续洞冥记玄象表</span>  
<span style="margin-left: 2em">各一卷并行于时又撰通史要略一百卷国史纪传</span>  
<span style="margin-left: 2em">二百卷未就而卒有文集二十卷<sub class="note-yuan">陈书曰野王博识洽闻侯景之寇郡将袁君正举兵起援文檄皆以委之口占便就未尝立草</sub></span>  
<span style="margin-left: 1em">唐陆元感字达礼梁娄县令庆之曾孙周王府文学详</span>  
<span style="margin-left: 2em">正殿学士谋道之子生而敏慧谋道善班固汉书元</span>  
<span style="margin-left: 2em">感传其学解褐参韩王府军事除婺州龙丘丞迁建</span>  
<span style="margin-left: 2em">德历阳二县令咸有善政加朝散大夫护军行黄州</span>  
<span style="margin-left: 2em">司马神龙三年卒葬昆山子南金赵璧在孝友类</span>  
<span style="margin-left: 1em">陆贽字敬舆嘉兴人秘书监齐望之姪曾孙吏部郎中</span>  
<span style="margin-left: 2em">灞之子十八第进士中博学宏辞调郑尉罢寿州刺</span>  
<span style="margin-left: 2em">史张镒有重名贽往见语三日奇之请为忘年交既</span>  
<span style="margin-left: 2em">行饷钱百万曰请为母夫人一日费贽不纳止受茶</span>  
<span style="margin-left: 2em">一串曰敢不承公之赐以书判拔萃补渭南尉德宗</span>  
<span style="margin-left: 2em">立遣黜陟使行天下贽说使者请以五术省风俗八</span>  
<span style="margin-left: 2em">计听吏治三科登俊乂四赋经财实六德保疲瘵五</span>  
<span style="margin-left: 2em">要简官事时皆韪其言迁监察御史召为翰林学士</span>  
<span style="margin-left: 2em">会马燧讨贼河北久不决请济师李希烈寇襄城诏</span>  
<span style="margin-left: 2em">问贽策帝不纳从狩奉天机务阗总远近调发奏请</span>  
<span style="margin-left: 2em">报下诏书数百贽若不经思逮成皆周尽事情衍绎</span>  
<span style="margin-left: 2em">熟复人人可晓旁吏承写不给他学士笔阁不得下</span>  
<span style="margin-left: 2em">而贽沛然有余始帝播迁府藏委弃卫兵无褚衣至</span>  
<span style="margin-left: 2em">是天下贡奉稍至乃于行在夹庑署璚林大盈二库</span>  
<span style="margin-left: 2em">别藏贡物贽上疏谏帝悟即撤其署俄以劳迁谏议</span>  
<span style="margin-left: 2em">大夫仍为学士孤立为左右权幸沮短又言事无所</span>  
<span style="margin-left: 2em">回讳阴失帝意久之不得宰相但为中书舍人母韦</span>  
<span style="margin-left: 2em">犹在江东帝遣中人迎还京师俄以丧解官客东都</span>  
<span style="margin-left: 2em">诸方赗遗一不取唯韦臯以布衣交先以闻故所致</span>  
<span style="margin-left: 2em">皆称诏受之又诏中人护父柩自吴葬洛阳服除以</span>  
<span style="margin-left: 2em">权知兵部侍郎复召为学士入谢伏地鲠泣帝为改</span>  
<span style="margin-left: 2em">容慰抚眷遇弥渥天下属以为相而窦参素不平忌</span>  
<span style="margin-left: 2em">之贽亦数言参罪失贞元七年罢学士以兵部侍郎</span>  
<span style="margin-left: 2em">知贡举明年参黜乃以中书侍郎同中书门下平章</span>  
<span style="margin-left: 2em">事班宏判度支卒贽荐李逊帝漫许之而自用裴延</span>  
<span style="margin-left: 2em">龄贽言延龄僻戾躁妄不可用不听俄而延龄奸佞</span>  
<span style="margin-left: 2em">得君天下仇恶无敢言贽上书苦谏帝不怿竟以太</span>  
<span style="margin-left: 2em">子宾客罢贽本畏慎未尝通宾客延龄揣帝意薄谗</span>  
<span style="margin-left: 2em">短百绪帝怒欲诛贽赖阳城等交章论辩贬忠州别</span>  
<span style="margin-left: 2em">驾后稍思之会薛延讷为刺史谕旨慰劳韦臯数表</span>  
<span style="margin-left: 2em">请贽代领劒南帝犹衔之不肯与顺宗立召未至卒</span>  
<span style="margin-left: 2em">年五十二赠兵部尚书谥曰宣始贽入翰林年尚少</span>  
<span style="margin-left: 2em">以材幸天子常以辈行呼而不名在奉天朝夕进见</span>  
<span style="margin-left: 2em">然小心精洁未尝有过由是帝亲倚至解衣衣之同</span>  
<span style="margin-left: 2em">类莫敢望虽外有宰相主大议而贽尝居中参裁可</span>  
<span style="margin-left: 2em">否时号内相尝为帝言今盗遍天下宜痛自咎悔以</span>  
<span style="margin-left: 2em">感人心昔成汤罪己以兴楚昭出奔以一言善而复</span>  
<span style="margin-left: 2em">国陛下诚不吝改过以言谢天下使臣持笔亡所忌</span>  
<span style="margin-left: 2em">庶叛者革心帝从之故奉天所下制书虽武人悍卒</span>  
<span style="margin-left: 2em">无不感动流涕后李抱真入朝为帝言陛下在奉天</span>  
<span style="margin-left: 2em">山南时赦令至山东士卒闻者皆感泣思奋臣是时</span>  
<span style="margin-left: 2em">知贼不足平也议者谓兴元戡难功虽爪牙宣力盖</span>  
<span style="margin-left: 2em">贽有助焉狩山南也道险涩与从官相失夜召贽不</span>  
<span style="margin-left: 2em">得帝惊且泣诏军中得贽者赏千金久之上谒帝喜</span>  
<span style="margin-left: 2em">见颜间自太子以下皆贺及辅政不敢自顾重事有</span>  
<span style="margin-left: 2em">可否必言之所言皆剀拂帝短恳到深切或规其太</span>  
<span style="margin-left: 2em">过者曰吾上不负天子下不负所学皇它鹰乎既放</span>  
<span style="margin-left: 2em">荒远尝阖户人不识其面又避谤不著书地苦瘴疠</span>  
<span style="margin-left: 2em">秖为古今集验方五十篇示乡人云贽论谏数十百</span>  
<span style="margin-left: 2em">篇讥陈时病皆本仁义可为后世法炳炳如丹所用</span>  
<span style="margin-left: 2em">裁十一耳惜哉族孙扆</span>  
<span style="margin-left: 1em">扆字祥文曾祖礼殿中侍御史祖师德淮南观察支使</span>  
<span style="margin-left: 2em">父鄯陕州法曹参军徙家于陕扆本名允迪光启二</span>  
<span style="margin-left: 2em">年僖宗在兴元举进士第一进翰林学士中书舍人</span>  
<span style="margin-left: 2em">属辞敏速若注射然一时书命同僚以为不及昭宗</span>  
<span style="margin-left: 2em">尝于金銮作赋诏学士皆和扆先就帝叹曰贞元时</span>  
<span style="margin-left: 2em">陆贽吴通玄善内廷文字后无继者今朕得卿斯文</span>  
<span style="margin-left: 2em">不坠矣与宗人希载文才重德名冠一时朝中号二</span>  
<span style="margin-left: 2em">陆累为尚书左丞封嘉兴县男徙户部侍郎贬峡州</span>  
<span style="margin-left: 2em">刺史久之授工部尚书从帝自华州还以工部尚书</span>  
<span style="margin-left: 2em">当国封郡公天复初朱全忠谋去朝廷衣冠贬扆濮</span>  
<span style="margin-left: 2em">州司户杀之于白马驿年五十九</span>  
<span style="margin-left: 1em">顾谦字自修其先吴郡人丞相季历之后风神朗秀质</span>  
<span style="margin-left: 2em">性端敏举明经三礼二科洞达贯穿魏帅何公表谦</span>  
<span style="margin-left: 2em">高才拜贝州宗城令寻弃归隐居北平乡崧子里名</span>  
<span style="margin-left: 2em">流高其风操咸就见焉咸通十三年卒</span>  
<span style="margin-left: 1em">宋陈舜俞字令举登庆历六年进士嘉祐四年再应材</span>  
<span style="margin-left: 2em">识茂异贤良方正能直言极谏科对策第一文章声</span>  
<span style="margin-left: 2em">名赫然在人上始授光禄丞签书寿州判官宰山阴</span>  
<span style="margin-left: 2em">县秩未满召试馆职不就会行青苗法上书力诋且</span>  
<span style="margin-left: 2em">自劾忤执政贬监星江酒税退居华亭常骑白牛往</span>  
<span style="margin-left: 2em">来风泾因自号白牛居士今塘市皆以白牛名有文</span>  
<span style="margin-left: 2em">集行于世</span>  
<span style="margin-left: 1em">朱谔初名绂元祐六年进士第二人御笔改今名赐字</span>  
<span style="margin-left: 2em">圣与徽宗时累官御史中丞尝奏请开内阁延群臣</span>  
<span style="margin-left: 2em">从容论道如神宗故事又请分命使者刺举诸道有</span>  
<span style="margin-left: 2em">受令而不行行令而不尽者论其罪庶几令出而朝</span>  
<span style="margin-left: 2em">廷尊历礼兵吏三部尚书拜尚书右丞三月卒赠太</span>  
<span style="margin-left: 2em">师岐国公谥忠靖累赠秦国公赐葬平江阳抱山弟</span>  
<span style="margin-left: 2em">纮改名谠字昌言崇宁中进士初谔在位所得恩泽</span>  
<span style="margin-left: 2em">皆分荫族人及卒子二人犹未禄人以是多之</span>  
<span style="margin-left: 1em">柳约性至孝深于经学大观中上舍进士为灞州教授</span>  
<span style="margin-left: 2em">靖康初升殿中侍御史论三镇不可弃后以直龙图</span>  
<span style="margin-left: 2em">阁知严州兼浙西兵马都监时金人大入列郡震恐</span>  
<span style="margin-left: 2em">约屹保孤城境内按堵高宗嘉其忠擢试户部侍郎</span>  
<span style="margin-left: 2em">且将大用当路忌其尽言诬以事罢之</span>  
<span style="margin-left: 1em">卫肤敏字商彦登宣和初进士又中八行科累官校书</span>  
<span style="margin-left: 2em">郎假给事中使金时金人将举兵大入肤敏论难往</span>  
<span style="margin-left: 2em">复殊不为屈高宗时拜右谏议大夫后父邢焕除徽</span>  
<span style="margin-left: 2em">猷阁待制太后兄子孟忠厚除显谟阁直学士肤敏</span>  
<span style="margin-left: 2em">言非祖宗法皆改职劝帝早幸金陵因陈守长江之</span>  
<span style="margin-left: 2em">策帝善其言除刑部侍郎<sub class="note-yuan">高宗批答辞免刑部侍郎诏敕肤敏省所奏辞免尚书刑部侍郎恩命事具悉朕仓卒渡江图籍散亡深虑吏缘为奸奏牍稽留平谳失当以卿平日正色侃侃论议坚明据谊守节屡触权贵必能为朕分别隐微章明杜直与其杀不辜宁失不经钦哉汝谐毋废朕命所请宜不允故兹诏示想宜知悉</sub></span>  
<span style="margin-left: 1em">卫仲达初名上达字达可大观三年登进士第徽宗改</span>  
<span style="margin-left: 2em">今名为馆职日尝上书谏修三山石桥不报后官至</span>  
<span style="margin-left: 2em">吏部尚书卒</span>  
<span style="margin-left: 1em">任尽言字元受右正言伯禹之孙与兄质言同登绍兴</span>  
<span style="margin-left: 2em">二年进士第居下僚好慷慨论事秦桧死朝廷惩言</span>  
<span style="margin-left: 2em">路壅塞之弊召汤鹏举于外为台官尽言投启贺之</span>  
<span style="margin-left: 2em">有每媿朱云之请劒未闻林甫之斵棺之语鹏举袖</span>  
<span style="margin-left: 2em">以白上上意颇回始黜桧姻党释赵鼎子汾及李孟</span>  
<span style="margin-left: 2em">坚王之奇等自便公道大明尽言之助也尝通判平</span>  
<span style="margin-left: 2em">江除京西运判改淮东提举钦庙上升尽言率缙绅</span>  
<span style="margin-left: 2em">为位佛宫致哀疏文二通读者感泣启与疏岳珂皆</span>  
<span style="margin-left: 2em">载之桯史谓其义不忘君直不蔽奸忠信之至惜不</span>  
<span style="margin-left: 2em">究其用云所著有小丑集行于世</span>  
<span style="margin-left: 1em">钱良臣字友魏幼志于学十九升辟雍登绍兴中进士</span>  
<span style="margin-left: 2em">孝宗淳熙五年十一月拜参知政事八年九月罢以</span>  
<span style="margin-left: 2em">正奉大夫知镇江良臣在朝德望伟然尝一新县学</span>  
<span style="margin-left: 2em">旧祠于学之西庑镇江人亦祠于甘露寺</span>  
<span style="margin-left: 1em">许克昌字上达绍兴末举进士名在第一以有官改第</span>  
<span style="margin-left: 2em">二累官右正言时松江新泾塘为海潮冲突咸水延</span>  
<span style="margin-left: 2em">及嘉湖二境克昌请于朝移堰入运港以避潮势由</span>  
<span style="margin-left: 2em">是三州之田获免咸潮之患乡邦德之</span>  
<span style="margin-left: 1em">盖经字常父登绍兴甲科官至户侍</span>  
<span style="margin-left: 1em">张伯垓字德象<sub class="note-jiao">校：以上二字原闕據宋詩紀事補遺補</sub>登绍兴第官至尚</span>  
<span style="margin-left: 2em">书</span>  
<span style="margin-left: 1em">朱端常字正父<sub class="note-jiao">校：以上二字原闕據南宋館閣錄補</sub>登淳熙第官至尚书</span>  
<span style="margin-left: 1em">卫泾字清叔其先齐人唐末避乱南迁居秀州之华亭</span>  
<span style="margin-left: 2em">祖阗始占籍昆山之石浦父季敏通判镇江府泾少</span>  
<span style="margin-left: 2em">有异操入行在从永嘉李去智学李卒为制服执丧</span>
