## 正德松江府志卷之十六　第宅

<span style="margin-left: 4em">第宅</span>  
<span style="margin-left: 3em">召伯去而甘棠兴咏商容殁而过者式闾贤者之</span>  
<span style="margin-left: 3em">系人心如此也云间第宅崇丽者何限而志所书</span>  
<span style="margin-left: 3em">有蓁莽而丘墟者矣览者其有兴乎园池亭馆以</span>  
<span style="margin-left: 3em">类附书观其废兴而时亦可知也</span>  
<span style="margin-left: 1em">孔宅府北六十里海隅乡前志云宋淳熙间居民浚河</span>  
<span style="margin-left: 2em">得一碑云天宝六年黄池县令朱氏葬于昆山县全</span>  
<span style="margin-left: 2em">吴乡孔子宅之西南孔宅之名旧矣今其地有夫子</span>  
<span style="margin-left: 2em">庙在慧日院侧又院僧疏庙陾渠得宝玉六事璧三</span>  
<span style="margin-left: 2em">环二簪一今藏县庠旧图经云昔有姓孔者游吴居</span>  
<span style="margin-left: 2em">此盖吾夫子未尝适吴以阙里谱系考之孔氏二十</span>  
<span style="margin-left: 2em">二代孙潜后汉太子少傅避地会稽遂为郡人二十</span>  
<span style="margin-left: 2em">九代滔梁海盐令三十二代嗣哲隋吴郡主簿三十</span>  
<span style="margin-left: 2em">四代祯隋苏州长史岂孔氏子孙有侨寓宦游于吴</span>  
<span style="margin-left: 2em">而遂居华亭者邪亦犹建康有孔子巷乃圣亭侯所</span>  
<span style="margin-left: 2em">奉之庙盖子孙即所居立先圣庙耳今庙侧又有梁</span>  
<span style="margin-left: 2em">纥庙其为子孙奉祀之地明矣所瘗璧簪珮之属其</span>  
<span style="margin-left: 2em">孔堂之遗宝得非子孙葬先圣衣冠宝璧于是地乎</span>  
<span style="margin-left: 2em">其旁有宰我墩颜渊井此则因孔宅之名而迁合傅</span>  
<span style="margin-left: 2em">会未可知也图经又云晋邹湛亦尝居焉又名邹孔</span>  
<span style="margin-left: 2em">宅按邹湛传南阳新野人湛尝见一人自称甄舒仲</span>  
<span style="margin-left: 2em">乃悟曰吾宅西有积土败瓦其中必有死人检之果</span>  
<span style="margin-left: 2em">然厚加歛葬初不言宅在何地湛未尝仕至吴中姑</span>  
<span style="margin-left: 2em">存此以传疑宅后侵于寺<sub class="note-yuan">即慧日院</sub>寺在今孔宅泾北夫</span>  
<span style="margin-left: 2em">子庙在泾之南相去颇远梁纥西去益远疑后人改</span>  
<span style="margin-left: 2em">作也</span>  
<span style="margin-left: 1em">陆机宅在昆山下别宅在谷阳门内今普照寺陆道瞻</span>  
<span style="margin-left: 2em">吴地记海盐县东北二百里有长谷昔陆逊陆凯居</span>  
<span style="margin-left: 2em">此元和郡国志华亭谷在县西三十五里陆抗宅在</span>  
<span style="margin-left: 2em">其侧故逊封华亭侯太平寰宇记二陆宅在长谷吴</span>  
<span style="margin-left: 2em">地记又云汉庐江太守陆康与袁术有隙使从子逊</span>  
<span style="margin-left: 2em">与其子绩将家迁吴居于长谷机赠从兄车骑诗髣</span>  
<span style="margin-left: 2em">髴谷水阳婉娈昆山阴即其地也世又传城中普照</span>  
<span style="margin-left: 2em">寺为陆氏园亭后舍为寺而前志辩以为非谓陆氏</span>  
<span style="margin-left: 2em">家本昆山不在邑中也然末引九域志乃云八角井</span>  
<span style="margin-left: 2em">在机宅之侧志黄耳冢则云在机家村南二百步按</span>  
<span style="margin-left: 2em">八角井在今城西南与普置寺相望可一里许黄耳</span>  
<span style="margin-left: 2em">冢在井之南可二里许如宅不在邑中井安得云在</span>  
<span style="margin-left: 2em">侧冢安得云南二百步邪又况唳鹤滩养鱼池皆陆</span>  
<span style="margin-left: 2em">氏遗迹皆去寺不远乎志又引李太白云齐朝南苑</span>  
<span style="margin-left: 2em">乃陆机宅而谓机仕于朝则居建康华亭谷乃其里</span>  
<span style="margin-left: 2em">第然则安知非谷为里第而寺北其园亭邪今百余</span>  
<span style="margin-left: 2em">之家犹有别业陆氏世封此土而谓其块处一村固</span>  
<span style="margin-left: 2em">矣故今据牟𪩘记定以寺为陆氏别宅云<sub class="note-yuan">陆机怀土赋余去家渐久怀土弥笃方思之殷何物不感曲街委巷罔不兴咏水泉草木咸足悲焉故述斯赋背故都之沃衍适新邑之丘墟遵黄川以葺宇被苍林而卜居悼孤生之已晏恨亲没之何速排虚房而永念想遗尘其如玉眇绵邈而莫构徒竚立其焉属感士景于存物惋颓年于栱木悲顾眄而有余思俯仰而自足留兹情于江介寄倅貌于河曲玩通川以悠想抚归涂而踯躅伊踯躅之徒勤惨归涂之良难愍栖鸟于南枝吊离禽于别山念庭树以悟怀忆路草而解颜甘堇荼于饴茈纬萧艾其如兰神何寝而不梦形何兴而不言赠光车骑诗孤兽思故薮离鸟悲旧林翩翩游宦子辛苦谁为心髣髴谷水阳婉娈昆山阴营魂怀兹土精爽若飞沈寤寐靡安豫愿言思所钦感彼归涂难使我怨慕深安得忘归草言树背与襟斯言岂虚作思鸟有悲音梅圣俞诗晴云唳鹤几千只隔水野梅三四株欲问陆机当日宅而今何地不荒芜沈辽诗朝日欲出已复西人间兴废那可知昆山陵谷久已变水深惟有将军碑</sub></span>  
<span style="margin-left: 1em">草堂在干山圆智寺陆机少日读书于此<sub class="note-yuan">沈辽诗海天辽辽禾黍秋人籁已息烟雾收数声鹤唳草堂静何苦更向咸阳游</sub></span>  
<span style="margin-left: 1em">陆瑁宅在养鱼池上</span>  
<span style="margin-left: 1em">陆锜宅在锜湖上</span>  
<span style="margin-left: 1em">袁崧宅府西北旧经昔袁崧居此因名崧宅按晋史崧</span>  
<span style="margin-left: 2em">陈郡阳夏人则其始未尝居华亭也隆安四年为吴</span>  
<span style="margin-left: 2em">郡太守尝筑沪渎垒以御孙恩明年遇害于沪渎或</span>  
<span style="margin-left: 2em">者崧殁后其子孙遂居于此乎今其地里曰崧子水</span>  
<span style="margin-left: 2em">曰崧皆其遗迹也</span>  
<span style="margin-left: 1em">顾府君宅在亭林镇地有高丘梁黄门侍郎顾野王于</span>  
<span style="margin-left: 2em">此修舆地志其北有湖湖南有林因呼顾亭湖亦曰</span>  
<span style="margin-left: 2em">顾亭林宅今为宝云寺高丘正当寺后时呼野王读</span>  
<span style="margin-left: 2em">书堆相传宅之故垣介一髹甓锲云东七里西七里</span>  
<span style="margin-left: 2em">祗在七七里厥后或识以为廋语其在漆里窃之金</span>  
<span style="margin-left: 2em">也云间赋云于南迫海野王之所人亡而吾伊声寂</span>  
<span style="margin-left: 2em">春归而青深林莽金璧久瘗土颓甲第胡为七七之</span>  
<span style="margin-left: 2em">说而成他人之利谓此寺有沼深黑冬夏不竭云野</span>  
<span style="margin-left: 2em">王墨池有古松云野王手植盖附会云<sub class="note-yuan">钱良臣诗伊昔边烽备不虞太平移作梵王居而今江表全无事借我三椽更读书革猷之诗六朝代谢与谁论独有商人旧址存休问当时兴废事淡烟斜日照孤村</sub></span>  
<span style="margin-left: 1em">顾谦宅在府西北崧子里</span>  
<span style="margin-left: 1em">朱少师宅在府治后朱家巷</span>  
<span style="margin-left: 1em">柳侍郎宅在府治西北柳家巷</span>  
<span style="margin-left: 1em">卫文节公宅在府东南萧塘今为崇福寺按苏志泾之</span>  
<span style="margin-left: 2em">祖阗自华亭徙昆山之石浦故泾以昆山贯登第而</span>  
<span style="margin-left: 2em">前志云泾生于萧塘淇水流庆录云本居华亭后迁</span>  
<span style="margin-left: 2em">石浦崇福寺记华严可师舍宅建而泾以故第益之</span>  
<span style="margin-left: 2em">然则阗徙昆山仅同寄籍而泾之生长固在华亭及</span>  
<span style="margin-left: 2em">舍宅为寺则定居于昆矣今鹤城书院以西相传亦</span>  
<span style="margin-left: 2em">卫氏故宅普照续古录云宋建炎中寺灾至卫宅甎</span>  
<span style="margin-left: 2em">墙始灭近岁居民于古井得巨甎无数皆有卫仲英</span>  
<span style="margin-left: 2em">三字仲英肤敏之子与文节从兄弟也</span>  
<span style="margin-left: 1em">谷阳园在西湖上中有湖斋朱之纯退休之地<sub class="note-yuan">宋蔡肇诗陆机异时宅故物无复迹悠悠谷水阳野水凄余碧我观豪士赋文字岂不白一为功名误末路真可惜至今风雨夜哀鹤鸣不息千秋得吾人浄眼照阡陌结茅风烟际一悟世网窄古今一丘貉贵贱百年客闭门橙橘香隐几冰冻释我慙升斗禄矫首望八极人生劳佚间此殆天所檄鹏翔赤霄动鲸喷碧海折为尔具扁舟送此齿发迫之纯自题湖斋诗平湖十顷水汪洋得意茅斋且屈藏园种小桃今结子池栽翠芰更闻香六龟已兆千年瑞双鹤看呈八月祥居此翛然忘世味此心尤嬾去龙阳予湖上治圃于桃根获古龟六枚其小如钱云间有听鹤观每岁中秋夜有仙鹤下观因得名今余治圃谷水邻其地</sub></span>
